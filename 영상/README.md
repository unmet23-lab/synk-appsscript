# 영상 — 대본을 영상으로 찍어내는 통로

> **여기가 하는 일 한 줄**: `.claude/skills/synk-content/` 의 숏폼 대본을 코드로 읽어
> 세로 릴(1080×1920) mp4 로 굽는다. 편집 프로그램이 없어도, 대본을 고치면 영상이 따라온다.
>
> 착수 근거 = 유호 확정 2026-08-26 「Remotion 을 SYNK 에 들인다 — 대본만 있고 영상이 없던 자리를
> 코드로 찍는 통로로 세운다」. 그날 실측 = **대본 45편 · 영상 1편**.

---

## 유호님이 하실 것 — 세 줄

터미널에서 이 셋만 있으면 됩니다. 첫 줄이 영상을 굽고, 둘째 줄이 «눈으로 볼 그림»을 뽑고,
셋째 줄은 화면에서 직접 만져 보고 싶으실 때만 씁니다.

```bash
node 영상/굽기.js clip-01-1
```

```bash
node 영상/프레임뽑기.js clip-01-1.mp4
```

```bash
cd 영상 && npx remotion studio
```

굽고 나면 영상은 `영상/out/` 에 생깁니다. 세 번째 줄은 브라우저가 열리고, 타임라인을 끌어
아무 순간이나 볼 수 있습니다(고칠 것을 찾을 때 제일 빠릅니다).

**지금 있는 영상**: `clip-01-<화>` · `clip-09-<화>` — 리드크루 클립 **10편**(각 30.00초).
목록을 보시려면 `node 영상/굽기.js --목록`.

## 🔴 「그림이 나왔다」는 통과가 아니다

이 도구는 **폰트를 못 받아도 종료코드 0 으로 끝난다.** 산출물은 「에러」가 아니라
**「서체가 틀린 영상」** 이 되고, 로그에는 노란 경고 한 줄만 남는다(없는 폰트 «이름» 을 쓴
경우엔 경고조차 없다). 그래서 검증이 세 겹이다:

| 겹 | 무엇이 잡나 | 누가 |
|---|---|---|
| ① `굽기.js` 의 실패신호 검사 | 자원이 안 실린 것(`Failed to load resource` 등) · 산출물이 «이번 굽기 것»인지 파일 **시각**으로 | 기계 |
| ② `프레임뽑기.js` | 두부(□□□) · 틀린 서체 · 잘린 구도 | **사람 눈** |
| ③ `synk-brand` + `node tools/몽골어대조.js` | 말투·금칙·몽골어 | 사람 |

②를 건너뛰면 ①이 통과해도 아무것도 증명되지 않는다. 한국어와 **몽골 전용 키릴(Өө Үү)**이
네모칸이 아니라 글자로 보이는지 반드시 눈으로 본다 — 이 저장소가 이미 한 번 겪은 사고다.

## 규율 — 고칠 때 이것만 지키면 된다

**① 색·폰트를 여기서 새로 정하지 않는다.**
정본은 `docs/디자인_토큰.json` 과 `docs/브랜드_폰트/` 하나뿐이다(유호 확정 08-26).
값은 `src/킷/색.ts` · `src/킷/폰트.ts` 를 지나서만 화면에 닿는다. 검사:

```bash
grep -rn "#[0-9A-Fa-f]\{6\}" 영상/src/ | grep -v "킷/색.ts"
```

0건이어야 한다. 그리고 킷이 «쓰지 마라»고 한 색(⏳퇴역 대기 12색 · K-Culture 4색)은
부르면 **던진다** — 조용히 넘어가지 않는다.

**② 자산은 `자산모으기.js` 가 옮긴다. 손으로 복사하지 않는다.**
`public/` 은 통째로 git 밖이고 전부 사본이다. 정본(마스코트·폰트·소리)을 고치면 여기가 낡는데,
`굽기.js` 가 굽기 직전에 항상 다시 맞춘다. 손으로 넣은 파일은 그 규율 밖에 있게 된다.

**③ 대본 문구를 여기서 고치지 않는다 — 이제 손으로 옮기지도 않는다.**
`대본읽기.js` 가 대본 md 를 읽어 `src/클립/생성/대본클립들.ts` 를 쓴다. 그 생성물은 **산출물**이라
손으로 고치면 다음 굽기가 덮는다. 문구를 고칠 일이 생기면 **대본 md 하나만** 고치면 된다.

```bash
node 영상/대본읽기.js --검사
```

굽기가 매번 먼저 부르므로 평소엔 이 줄을 따로 칠 일이 없다. 직접 칠 때는 «무엇이 서고 무엇이
미달인지»를 세는 용도다 — 지금 **45화 = 선 것 10 + 스키마 미달 35**.
⚠ 생성물은 git 밖이다(정본이 둘이 되지 않게). **`npx remotion studio` 만** 처음 한 번
`node 영상/대본읽기.js` 를 손으로 부르고 열어야 한다 — 굽기·시연묶기는 스스로 부른다.

**③-b 대본 한 화가 «서려면» 이 둘이 있어야 한다.**
① `**[훅 자막]**` 다음 줄의 `> 한 문장` ② 아래 여섯 행짜리 표 — 라벨과 순서까지 정확히.

```
| 타이밍 | 자막 |
|---|---|
| 표현 | **안녕하세요** — Сайн байна уу |
| 뜻 | … — … |
| 예문 1 | … — … |
| 예문 2 | … — … |
| 따라하기 | … — … |
| 클로징 | … |
```

한 칸 안에서 **한국어와 몽골어는 「 — 」로 나뉘고, 몽골어 쪽은 키릴로 시작한다.** 키릴이 없으면
몽골어 칸을 **비운다 — 지어내지 않는다**(첫 판이 클로징에 없는 몽골어 한 줄을 지어냈다).
지금 이 꼴을 갖춘 것은 **01편·09편 10화뿐**이고 나머지 35화는 「타이밍 라벨 없는 불릿」이다.

**④ 몽글은 말하지 않는다.**
`synk-brand` 명문: 「장난스럽고 따뜻한 **무언의** 선생님 · 학생과 **대화하지 않는다** —
표정·몸짓이 첫 언어」. 대사를 준다면 «자기 감정과 응원»까지이고 **평가는 금지**다
(「잘했어요」 ✕ / 「와, 나 지금 신났어!」 ○). 소리는 사운드킷의 몽글 목소리 12종이 낸다 —
그건 말이 아니라 «소리»라 무언과 안 부딪힌다.

**⑤ 쓸 수 있는 표정은 셋뿐이다** — 본체 · 눈감음 · 눈웃음.
감정 어휘는 11인데 그림은 3이다. 없는 표정을 부르면 `마스코트자산.js` 가 **던진다**
(조용한 폴백 금지가 의도된 설계다). 연출을 있는 컷 안에서 짠다.

## 알아 두면 한 번 덜 헤매는 것

- **컴포지션 `id` 에 한글을 못 쓴다.** Remotion 이 `a-z A-Z 0-9 CJK -` 만 받는데
  한글 음절이 그 「CJK」에 안 들어간다(실측). **id 만 영문**이고 파일·폴더·화면 글자는 한글 그대로다.
- **`npx remotion render --help` 는 끝나지 않는다**(5분 타임아웃 확인). 도움말은 웹 문서로 본다.
- **하단 210px 는 비워 둔다.** 인스타·틱톡이 그 자리를 자기 UI(계정·캡션·버튼)로 덮는다.
  값은 `src/클립/리드크루클립.tsx` 의 `연출.안전여백아래` 한 곳에 있다.
- **`node_modules` 는 13,581 파일 611MB 다.** `.gitignore` 가 막고 있으니 `git status` 에 안 뜬다.
  뜨기 시작하면 그 규칙이 지워진 것이다.
- **Remotion 무료 자격은 「직원 3명 이하」에 묶여 있다.** SYNK LAB 은 1인이라 지금은 상업적
  사용까지 0원이다. 강사를 채용해 4명이 되는 순간 `remotion.pro` Company License 가 필요해진다 —
  오늘 비용이 아니라 **예약된 비용**이라 채용 판단과 같은 자리에서 다시 본다.
