# yuhobuilds 제작여정 1편 — 장면 소스

- 독립 입구: `entry.tsx`; 기존 `Root.tsx`는 수정하지 않는다.
- 컴포지션: `YuhoJourney01`(1080×1920, 기본 30fps)와 `YuhoJourney01Cover`.
- 입력: `VideoProps`는 `types.ts`에 정의. `timing.scenes`의 start/duration은 프레임, `captions`의 startMs/endMs는 **전체 영상 기준 밀리초**다. 음성 시작 오프셋은 자막을 생성할 때 반영한다.
- 기본값은 무음 임시 19장면이다. 실제 음성과 단어 시각을 만든 뒤 외부 `inputProps`로 덮어쓴다.
- `purpose`는 scene.text에 ‘선생’ 또는 ‘동료’가 있으면 동료 교사 장면을 사용한다. `confusion`은 ‘09’ 또는 초보 설명 문장일 때 개발 도구에 낯설던 장면, 나머지는 설정 장면이다. `lesson`은 ‘15’ 또는 ‘지금 다시 시작’ 문장이면 지금의 학습 제안을 여는 장면, 나머지는 출석 하나부터 시작하는 장면이다. 다른 시각 종류는 `types.ts`의 Visual 목록을 따른다.

필요한 public 자산:

- `yuho-journey-01/receipt.png`: 원본 1532×562. 화면에서는 왼쪽 아래 날짜 영역만 crop한다. **영수증 실제 픽셀 위치를 정지화면으로 확인한 뒤 렌더한다.**
- `yuho-journey-01/felt-dark.webp`: 기존 승인 재질. 밝은 면은 순백색으로 두며 밝은 펠트 파일이나 필터 변형은 사용하지 않는다.
- 실제 음성은 timing.audioFile에 `yuho-journey-01/narration.wav`를 지정. null이면 음성이 없다.
- `폰트/`의 기존 SUIT와 Inter Tight 9벌. `../킷/폰트.ts`의 로더를 그대로 사용한다. 새로운 폰트·패키지·이미지 서비스는 추가하지 않았다.

내용은 회고를 바탕으로 한 설명용 재구성이다. 도구 UI를 실제 6월 캡처처럼 만들지 않았고, 알림 장면은 당시 만들고 싶었던 흐름임을 표시한다. 시간은 사용자 체감 회고이며 문의 개수나 제작 진행률의 실측 수치를 표방하지 않는다.

루트 제작 담당이 자산을 공급하고 실제 타이밍으로 정지화면·영상·자막 영역과 음성을 검수한다. 타입 검사만으로 시청각 검수가 완료된 것은 아니다.
