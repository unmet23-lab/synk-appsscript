# 펠트 엔진 원리 설명 영상

2026-09-12 · 한국어 기계 음성·자막 · 1920×1080 / 30fps / 216.4초

`친구를 만나서 카페에 갔어요`라는 한 문장을 중심으로, 애매한 부분의 보류, 같은 원음의 청취 확인, 도움 뒤 새 발화의 분리, 늦게 안 도움 사실에 따른 관련 판단 정정을 설명한다. 마지막에는 실제 로컬 작업실의 통제 예제 녹화를 연결한다.

## 제작과 범위

- 현재 `tools/patent-studio/core.cjs` 0.4.0, `EXPLAINED.md` §3~10과 대조했다.
- 처음 소리와 받아쓴 글을 구분하고, 확인 후보의 일치만으로 과거형을 자동 반영한다고 설명하지 않는다. 독립 판단·관련 불확실성·도움·순서 조건을 함께 표시한다.
- `기록`은 근거를 쓸 수 있다는 의미다. 정답·숙련도 점수가 아니다.
- 뒤늦은 조사 도움은 **조건을 바꾼 별도 예제**다. 일반 모범 문장 도움을 조사만 돕는 사건으로 바꾸어 설명하지 않는다.
- 실제 UI는 새 로컬 통제 세션에서 실행했다. 제품 전체 통합이나 학생 학습 성과의 증명이 아니다.
- 영상 코드는 공용 Root, 킷, 엔진 코드, 앱 화면을 수정하지 않는다.

## 파일

- `script.json`: 의미 단위 대본. 합성 시 발음용 인용부호 차이가 있을 수 있다.
- `timeline.json`: 채택한 음성의 문장·실측 길이·프레임 배치. 실제 자막의 기준.
- `Film.tsx`, `index.tsx`: 독립 Remotion 진입점.
- `../../특허원리굽기.cjs`: 승인 로고·마스코트, 현행 색·폰트, 음성·실제 UI를 모아 렌더.
- `../../특허원리플레이어.cjs`: 장면 이동·속도 조절이 있는 로컬 HTML 보기 화면.

## 재제작

저장소 루트에서:

```powershell
node 영상/특허원리굽기.cjs --prepare
node 영상/특허원리굽기.cjs --stills
node 영상/특허원리굽기.cjs --video-only
node 영상/특허원리플레이어.cjs
```

음성 원본과 실제 녹화는 `tools/patent-studio/qa-output/engine-video-audio/`, `engine-video-runtime/`을 사용한다. 이 경로의 합성 음성·녹화가 없으면 재렌더에 앞서 복구가 필요하다. 자격증명이나 원본 학생 녹음은 없다. 새 음성 합성은 위 렌더 명령이 자동 실행하지 않는다.

## 확인

33개 음성의 디코딩·음량을 검사하고 별도 로컬 음성인식으로 원문과 비교했다. 혼동이 컸던 5문장을 자연스럽게 다시 합성했다. 직접 청취 평가는 이 환경에서 확인 불가다. 14개 주요 장면의 실물을 직접 검수했고 긴 자막의 한국어 단어 줄바꿈을 수정했다. 최종 MP4 규격·실제 재생·추출 프레임 검수는 산출 폴더의 `검수/`에 기록한다.
