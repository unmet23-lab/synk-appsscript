# 마케팅 실행 영상 — 2026-09-09 독립 entry

이 폴더는 새 실행 패키지의 영상만 등록한다. 기존 `영상/src/Root.tsx`, 16계정 컬렉션, 리드크루 릴·기업 소개 영상, 공용 킷은 수정하지 않는다.

## 입력과 출력

- 원고: `docs/홍보물/마케팅실행_20260909/원고/콘텐츠원고.json`의 영상 7편, `lectures`의 공개수업, `extras`의 가상 클리닉.
- 값: `영상/src/킷/색.ts`·`폰트.ts` 직접 import. SYNK는 중립 먹색 펠트의 무실땀 원본을 사용하고, LAB·SHIFT·PULSE의 고유색과 스티치는 유지한다.
- 그림: 새 패키지의 `assets/`에서 사용 자산만 전용 public 폴더로 준비한다. 구소개서 `shiftpage`를 쓰지 않는다. `paper.webp`는 이름과 달리 독립 사각 오브제라 배경으로 사용하지 않는다.
- 음악: 원천이 확인된 기존 `영상/BGM만들기.js`의 30초·60초 자체 작곡 WAV를 사용한다. 외부 곡이나 실제 라디오 녹음이 아니다.
- 내레이션: 제공자료 담당의 `공개수업/음성/음성명세.json`·`클리닉_음성명세.json`. 실제 WAV와 구술 해시를 대조한다. 원천은 보존하고 렌더에만 음량 여유를 둔다.
- 준비 계획: `영상/public/마케팅실행20260909/plans/*.json`. 실제 음성 길이 + 지정 실습 여유 + 짧은 전환 여유로 장면을 정한다. 구술을 빨리 재생해 고정 길이에 맞추지 않는다.
- 출력: 각 계정 `video.mp4`·`자막.srt`, 공개수업 `수업.mp4`·`수업.srt`·`클리닉.mp4`·`클리닉.srt`.
- 검사: 새 패키지 `_검토/영상_*` 및 `영상프레임-*`에 원천·기계검증·최종 인코딩 프레임을 남긴다.

## 명령

저장소 루트에서 실행한다. 접촉시트에는 현재 런타임의 `sharp`가 필요하다. 최종 렌더는 동시성 2로 진행하며, 다른 제작 작업의 CPU를 보존한다.

```powershell
node 영상/마케팅실행굽기.cjs --prepare
node 영상/마케팅실행굽기.cjs --check
node 영상/마케팅실행굽기.cjs --still --id 04-yuhobuilds-youtube --scene 2
node 영상/마케팅실행굽기.cjs --render --resume
node 영상/마케팅실행굽기.cjs --render --id shift-public-class-01 --resume
node 영상/마케팅실행굽기.cjs --render --id shift-public-clinic-demo-01 --resume
```

`--scene`은 0부터 센다. `--second`로 장면 내부 시각을 정한다. 기본 렌더 대상은 7편의 짧은 영상이고 수업·클리닉은 ID를 지정한다.

기존 영상의 2026-09-10 로고 갱신은 `node 영상/마케팅로고동기화.cjs`를 사용한다. 기존 검증 MP4·계획을 먼저 대조하고 `LogoPlate.tsx`로 SYNK 자리만 렌더하여 원본에 합성한다. 01은 별도 담당 결과를 보존한다. 원본·후보·검증은 `tmp/marketing-logo-rollout-20260910/`에 남으며, 시각 검수 뒤 후보만 실제 제공 MP4에 반영한다. 준비·자막·음성 생성은 실행하지 않는다.

`--resume`은 해당 장면·사용 자산·음성·컴포넌트·킷·렌더러·기존 MP4 해시가 일치하는 성공본만 남긴다. 원고 전체 해시는 보고에 기록하지만, 다른 계정의 설명글이나 자료 연결만 바뀌었다고 같은 화면의 영상을 재제작할 필요는 없다. 영상에 실제 사용되는 장면·오디오는 별도 지문에 포함된다.

## 읽힘과 마무리

짧은 영상의 필수 정보는 x100~920, y260~1530 안에 둔다. 한국어·몽골어 예문은 서로 대등하게 읽히도록 분리하고 첫 장면의 긴 역할 목록은 원문 단어 그대로 세 줄로 배치한다. 소품의 알파 윤곽을 마스크로 자르지 않는다.

강의는 왼쪽 설명과 오른쪽 실물, 아래 구술 자막을 구분한다. 문서를 읽거나 직접 적는 동안 본문을 흔들지 않는다. 일반 모션 스킬의 반복 확대보다 브랜드의 읽힘·실습 목적을 우선해 짧은 등장 뒤 정지한다. PULSE의 01-lab-youtube는 후속 요청으로 `영상/klofi신작굽기.cjs`에 위임한다. 최신 승인 v4 움직이는 무대·까몽 DJ·곡명·61.6초 전곡을 사용하며, 여기의 옛 static night/BGM 분기는 새 제작에 쓰지 않는다.

## 자막과 확인의 경계

모든 자막은 Remotion Caption 형태의 JSON으로 처리하고 SRT로 내보낸다. 짧은 영상은 승인된 화면 문구의 자막이지 음성 받아쓰기가 아니다. PULSE의 `[Instrumental music]`은 음악 설명이다.

음성 있는 수업과 클리닉은 로컬 ASR의 단어 시각을 정본 구술에 자동 대응시킨다. 자막에는 ASR의 잘못 인식된 문장이 아니라 원고를 쓴다. 이는 단순 비례 배분보다 발화 구간에 근접한 자동 추정이며 사람이 듣고 정렬한 자막이라고 주장하지 않는다. 전사 파일의 음성 해시·차이율·시각 범위도 함께 확인한다.

폰트·자원·글자 안전 영역·코덱·길이·음량은 기계 검사다. 프레임 검토는 실제로 본 시점과 MP4 해시를 연결해 별도 기록한다. 기계 전사·음량 수치를 실제 청취나 억양 만족으로 대신하지 않는다. 외부 게시·실제 학습자 사용·사업 성과는 이 로컬 제작의 완료 범위가 아니다.
