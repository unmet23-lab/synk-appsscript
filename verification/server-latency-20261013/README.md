공개 표본은 서로 다른 시점의 짧은 관측이며 지연 속도 개선이나 연속 무중단의 증거가 아니다. HTTP/3 안내 오류는 확인해 수정했지만, HTTP/3를 사용하지 않는 과거 Node fetch의 8초 시간초과 원인으로 입증된 것은 아니다. 합성 부하는 운영의 당시 게시0개·프로젝트5개와 구분한다.

`deploy/ha/plan.json`은 초기 비활성 템플릿과 시험 입력이다. 운영의 현재 릴리스·재무장 상태는 별도 검증 결과를 따르며, 이 파일의 과거 값을 현재 운영 상태로 해석하지 않는다. 개인정보·운영 세션·인증 키·DB·원격 비공개 백업은 이 증거 묶음에 넣지 않았다.

재무장 준비1~3차는 근거의 최신성 조건으로 보류되어 활성화 요청을 보내지 않았다. 최종 준비는 마지막 스냅샷 순서와 수집기의 기존 의존성 확인을 같은 입력에 연결해 로컬 승인 확인의 반복을 줄였고, 기존 전체 근거·원천 보호 조건은 유지했다. 운영 배포 원천을 이 과정에서 변경하지 않았으며, 새 강제 장애 전환 시험은 수행하지 않았다.
