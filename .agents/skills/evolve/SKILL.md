# 지침 진화 (evolve)

> **v1.0 · 2026-07-11** — 이 파일이 지침 진화 절차의 **정본**이다. 공용 지침(`CLAUDE.md`)의 '지침 진화' 섹션에는 요약만 두고 절차를 복제하지 않는다. Codex 미러: `.agents/skills/evolve/SKILL.md`(내용 동일 유지).

공용 작업 지침을 "완성품"이 아니라 계속 진화하는 시스템으로 다룬다. 목표는 완벽에 가깝도록 진단 → 수정 → **압축** → 상호발전을 한 사이클 도는 것 — 이게 유호님이 정의한 "트렌디"의 운영형이다. **한 번에 지침 전체를 다시 쓰지 않는다. 근거 있는 조항만 최소로 손댄다.**

## 실행 순서 (순서 엄수)

1. **신호 수집** — 개정 재료를 모은다.
   - 메모리의 `feedback` 타입 항목(유호님의 교정·거절·승인)과 지침 관련 메모리(master-directive 등) 훑기.
   - `git log`로 `CLAUDE.md`·`.claude/skills/`·`docs/지침_이력.md` 최근 변경 이력 확인.
   - 최근 세션의 마찰(유호님 교정·거절·불만·내 반복 실수)과 유호님이 직접 준 개정 입력.
   - **신호가 하나도 없으면 여기서 멈추고 "개정할 근거 없음"을 보고한다**(억지 개정 금지).

2. **개정 후보 진단** — 조항 단위로 추가/수정/삭제/압축 후보를 만든다.
   - **후보마다 실제 사건·유호님 발언 근거를 붙인다. 근거 없으면 후보 자격 없음**("항상 최선을 다한다" 류 일반론 조항 금지).
   - 추가만큼 **압축**을 본다: 값어치 못하는 조항·중복을 잘라낼 후보도 함께 올린다. 단 진짜 낭비는 문서 길이가 아니라 과잉 검증 습관이니(실측: 지침 52줄을 20% 줄여야 360토큰, 같은 날 심층감사 하나가 600만 토큰), **문구를 줄이려 전투검증 조항(검증 규모·분리 반박·판독 인용·비가역 게이트 등)의 뉘앙스를 깎지 않는다.**
   - `docs/지침_이력.md`의 "재론 금지" 목록과 대조해, 이미 정착·거절된 결정을 새 근거 없이 되살리지 않는다.

3. **분리 반박 패스** — 후보를 공격한다.
   - 생성(2단계)과 **분리된 적대 패스**로 돌린다 — 방어가 아니라 공격만. "애매하면 통과"를 기본값으로 두지 않는다(게이트가 열려 헛돈다).
   - 단 지침·스킬은 **git으로 되돌릴 수 있는 문서**다. CLAUDE.md의 "검증 규모 ∝ 되돌림 비용" 원칙에 따라 **가벼운 반박 1패스면 충분** — 다중 에이전트 심층 검증은 쓰지 않는다(가역 문서에 과잉).

4. **반영** — 살아남은 후보만 적용한다.
   - `CLAUDE.md`를 수정하고 상단 **버전 스탬프를 범프**한다(`vX.Y · 날짜`).
   - `docs/지침_이력.md`에 이번 변경을 **1줄** 추가한다(무엇을 · 왜 = 근거 사건).

5. **사본 동기화** — 정본 변경을 사본 3종에 전파한다. **각 사본의 환경 고유 섹션은 보존한다.**
   - `AGENTS.md`(Codex용) 직접 수정 — 고유 섹션 "새 작업 컨텍스트 복원"과 멀티세션 규약의 Codex 표기를 지운 채로 덮어쓰지 않는다.
   - `docs/COWORK_지침.md`(cowork용) 직접 수정 — forge 절차 본문 서술·"유호님께 모델 권고만"·커넥터 기반 실행 원칙·지침 진화 축약본 등 cowork 조정분을 유지한다.
   - `docs/GPT_지침사본.md` 재생성 — ChatGPT 커스텀 인스트럭션 2칸(칸1=나에 대해 알아야 할 것, 칸2=어떻게 응답할지), 각 칸 공백 포함 **1,500자 이내**, 버전 스탬프 `vX.Y-GPT`.
   - `.claude/skills/`의 스킬을 신설·수정했으면 `.agents/skills/` 미러에도 동일 반영한다(Codex 패리티 — 미러가 없으면 Codex에서 죽은 참조가 된다).
   - **유호님 손이 필요한 재복붙 2건**은 클릭 단위 체크리스트로 보고한다(이건 내가 원격으로 못 함):
     1. claude.ai/cowork → 해당 프로젝트 → 설정 → **프로젝트 지침(Instructions)** 란에 `docs/COWORK_지침.md` 전문을 붙여넣기(기존 내용 전체 교체).
     2. ChatGPT → 설정 → **맞춤 설정(Customize ChatGPT)** → 두 입력칸에 `docs/GPT_지침사본.md`의 [칸1]·[칸2]를 각각 붙여넣기.

6. **기록·마감**
   - 새로 확정된 결정·마찰 신호를 메모리에 갱신한다(다음 진화의 연료 — CLAUDE.md '마찰 신호' 조항과 짝).
   - 멀티세션 중이면 `docs/세션보드.md`를 갱신한다.
   - 문서 변경이므로 `git add` → 커밋 → `git push origin master`로 백업한다. **`/deploy`·`clasp push`는 쓰지 않는다** — 지침은 라이브 Apps Script 코드가 아니다.

## 적용 판단 (트리거)
- **기본은 유호님 호출**("지침 진화"·"지침 다듬어줘"·"/evolve").
- AI는 마찰 신호가 쌓였을 때 **실행을 제안만** 한다 — 자동 실행하지 않는다. 유호님 승인 후 진행.

## 의도적으로 배제한 것 (다시 넣지 말 것)
- **매 세션 자동 실행** — 소음이다. 진화는 신호가 쌓였을 때만 돈다.
- **근거 없는 조항 추가** — 실제 사건 없이 "좋아 보이는" 규칙은 토큰만 먹고 행동을 안 바꾼다(2단계 근거 게이트로 차단).
- **무한 순증가** — 추가만 하고 압축을 안 하면 지침이 비대해진다. 매 사이클 압축 후보를 반드시 검토한다.
- **다중 에이전트 심층 검증** — 지침은 git 가역 문서라 과잉. 되돌림 비용에 안 맞는다.
- **지침 전면 재작성** — 매 사이클 뜯어고치면 정착된 결정이 흔들린다. 근거 있는 조항만 최소로 손댄다.
