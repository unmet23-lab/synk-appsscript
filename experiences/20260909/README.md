# SYNK 새로운 경험의 첫 장

2026-09-09 사용자 요청으로 제작한 세 결과물입니다. 역할과 향후 방향의 정본은 [사업 발전 정본](../../docs/사업발전_정본.md)입니다.

## 열기

이 폴더에서 Node.js 20 이상으로 실행합니다. 실행에 추가 패키지 설치나 API 키가 필요 없습니다.

```text
node server.cjs
```

- 전체 입구: <http://127.0.0.1:4399/>
- 1. 실전 리허설: <http://127.0.0.1:4399/rehearsal/>
- 2. PULSE 〈마지막 불빛〉: <http://127.0.0.1:4399/pulse/>
- 3. 접근성 감상실: <http://127.0.0.1:4399/accessibility/>

이미 사용 중인 포트라면 `node server.cjs --port=4409`처럼 다른 번호를 정합니다. 다른 번호·주소·브라우저는 리허설 저장 공간이 달라질 수 있으므로 옮길 때 기록 JSON을 사용합니다.

친구의 다른 기기와 같은 네트워크에서 체험하려면 `node server.cjs --lan`으로 실행하고 출력된 네트워크 주소를 사용합니다. 방화벽·네트워크에서 이 포트가 허용되어야 하며 인터넷에 공개 배포한 주소가 아닙니다. 방화벽 설정을 자동 변경하지 않습니다. 현재 사용자 기기에서 같은 네트워크의 실제 다른 기기 접속은 별도 확인 대상입니다.

HTML을 파일로 직접 열면 모듈·방 동기화가 정상 동작하지 않습니다. 위 HTTP 서버를 사용하세요.

## 1. 실전 리허설

LAB·SHIFT의 교육 발전 방향 중 첫 실물은 SHIFT의 1인 기업 실습입니다. 가상 공방 고객에 대한 확인 질문, 첫 제안, 예산·범위 변경에 따른 수정 제안과 이유, 다른 고객에게 적용한 결과를 남깁니다. 마지막에 직접 작성한 원문을 비교하고 강사 검토 자료로 내보냅니다.

현재 구현은 독립 실습입니다. LAB 앱·학생 계정·기존 엔진·강사 서버에 자동 연결한 상태가 아닙니다. 다음 발전은 실제 수업 적용과 계약에 맞는 통합입니다. [상세 사용법과 로컬 검증](rehearsal/README.md).

## 2. PULSE 〈마지막 불빛〉

펠트 해안 도시의 협동 이야기 첫 장면입니다. 전차 정비사와 방송 기록원이 필수 역할이며 등대 감시인과 우편 배달인은 선택 역할입니다. 자기 역할의 사물을 살펴보고, 자신의 단서를 공유하고, 불빛을 보낼 곳을 함께 고릅니다. 모두 같은 곳을 고르면 방을 만든 사람이 결말을 엽니다. 세 선택에는 서로 다른 끝맺음이 있으며 사람의 도덕성·실력을 점수로 매기지 않습니다.

각 역할의 비공개 단서는 서버에서 따로 전달합니다. 방 코드만으로 다른 사람의 단서를 읽을 수 없으며 초대 코드는 함께 플레이할 사람에게 공유합니다. 실제 이름은 필요 없습니다. 한 기기에서 두 역할을 체험하는 모드는 혼자 규칙과 흐름을 살펴보는 용도이며 실제 친구들과 재미를 검증한 증거가 아닙니다.

미술 기준 이미지는 [제작 기록](pulse-art-direction.md)에 남겼습니다. 이 이미지와 실제 WebGL 3D 화면은 다른 결과물입니다. Unreal Engine 5·GTA VI는 사용자가 제시한 시각적 야심의 참고이며 이번 구현은 Three.js를 사용하는 브라우저 첫 장면입니다. 대규모 오픈월드·그 작품들과 동급의 완성·프레임 성능을 주장하지 않습니다.

바로 살펴보려면 **한 기기로 두 역할 체험**을 선택하세요. 각 역할의 사물을 조사하고 단서 두 개를 공유한 뒤, 역할을 바꿔 나머지 단서를 공유합니다. 두 역할이 같은 곳을 고르면 정비사 역할에서 결말을 확정합니다. 오른쪽 위 장면 설정에서 화질·움직임을 조절하고 도시만 둘러볼 수도 있습니다.

[실제 3D 거리 화면](pulse/qa/scene-street.png), [전차 근접 화면](pulse/qa/scene-tram.png), [렌더링 관찰 기록](pulse/qa/render-evidence.json). 미술 기준 이미지에 비해 건물 형태·사물 밀도·섬유와 빛의 세밀함에는 차이가 남아 있습니다. 현재의 첫 공간을 기준으로 고유 모델과 재질을 발전시킵니다.

## 3. 접근성 감상실

같은 펠트 장면을 글로 살펴보고, 키보드로 이동하고, 움직임을 조절하는 첫 실물입니다. 브라우저가 한국어 음성을 지원하면 사용자가 선택한 설명을 읽어줄 수 있습니다. 지원되지 않으면 글로 계속 감상할 수 있습니다.

공통 모듈 `accessibility/a11y.js`와 `a11y.css`는 화면의 초점·알림·움직임 선택을 재사용하도록 만든 부품입니다. 자동 검사, 키보드 조작, 브라우저 음성 호출과 실제 사람의 청취·전문 검수·당사자 실사용은 서로 다른 확인입니다. [적용 기준](accessibility/guide.html)과 개별 검수 기록에 미확인 항목도 남깁니다.

## 저장과 운영 범위

- 실습 기록: 사용 중인 브라우저의 localStorage. 당사자가 내려받거나 초기화할 수 있습니다. 실제 학생·고객 식별 정보 없이 체험할 수 있습니다.
- 이야기 방·닉네임·단서 공유·투표: 실행 중인 Node 서버 메모리. 서버 종료 시 사라집니다. 계정 로그인·결제·운영 데이터베이스는 이번 첫 판의 범위가 아닙니다.
- 역할 토큰: 해당 브라우저의 세션 저장소. 다른 사람의 역할을 임의로 열지 못하게 구분합니다.
- 그래픽: 브라우저와 기기 성능에 따라 품질과 프레임이 다릅니다. 동작 감소·정적 장면·글 경로를 함께 제공합니다.
- 외부 공개 게시·광고·판매·실제 교육 효과·재구매·전문 접근성 인증은 이번 로컬 구현과 구분합니다.

위 명령은 저장소 루트에서 실행합니다. 실제 학생·강사 사용, 친구들의 재미와 재구매, 사람의 음성 청취·화면낭독기·전문 접근성 검수는 이번 로컬 시험에 포함하지 않았습니다.

독립 서버 검토에서 두 결함을 발견해 수정했습니다. 네트워크가 한글 한 글자를 여러 조각으로 보낼 때 원문이 깨지는 문제는 바이트를 모아 해석하도록 고쳤습니다. 요청 본문을 받는 중 방에서 제거된 참여자가 행동할 수 있던 문제는 요청 수신 뒤 현재 역할을 다시 확인하도록 고쳤습니다. 두 재현 시험을 추가해 통과했습니다.

독립 플레이 검수에서 모바일 결말의 스크롤, 화면에 보이지 않는 조사 버튼의 키보드 초점, 방에서 나간 뒤 역할을 되찾지 못하는 문제를 발견해 고쳤습니다. 최종 검수 범위에 미해결 지적은 없습니다. 자세한 재현과 확인 범위는 위 검수 기록에 남겼습니다.

제작 판단은 기존 사업의 역량을 키우는 구조와 PULSE의 독립 작품 경험을 결합했습니다. 별도 회사 세 곳을 늘리는 방식, 자동 점수를 학습 효과로 단정하는 방식, 미술 기준 이미지를 실제 3D 품질로 보고하는 방식은 채택하지 않았습니다.

정본 연결은 `authority-links.cjs --apply`, 입구의 브랜드 자원 생성은 `node build-hub.cjs`로 재현합니다. 이 두 제작 도구는 저장소 안에서 사용하는 도구이며, 체험 실행에는 `node server.cjs`만 필요합니다. 정본 연결 도구는 현재 작업에 해당하는 짧은 참조만 추가하고 강제 훅으로 등록하지 않습니다.
