# 다온 — 실제 로컬 AI 검증

2026-09-10. 작가가 써 둔 답변을 AI로 표시하지 않는다. `ai-runtime-check.cjs`는 실제 게임 서버에 가상의 정비사·기록원을 만들고, 설치한 모델의 생성 결과를 같은 HTTP 대화 경로로 받는다. 이 자료는 [별도 대화 UI 검사](../pulse/qa/upgrade-dialogue-ui.md)의 모의 응답과 구분한다.

## 실제 설치와 실행

`node experiences/20260909/install-ai.cjs`로 llama.cpp b10881과 Qwen3-4B-Instruct-2507 Q4_K_M을 내려받고 전체 SHA-256을 확인했다. 파일은 `%LOCALAPPDATA%/SYNK/pulse-ai`에 있고 저장소에는 넣지 않는다. 원본·고정 버전·해시·라이선스는 [출처](../pulse/THIRD_PARTY_NOTICES.md)에 남겼다. 이 컴퓨터의 Intel Arc B390을 Vulkan으로 사용했다.

첫 질문에서만 모델을 시작하며, 요청이 끝난 뒤 일정 시간 쉬면 모델 프로세스를 종료한다. 게임 서버의 정상 종료도 소유한 모델을 정리한다. 로컬 주소와 프로세스 안의 임시 인증 키를 사용하고, 키를 로그·명령 인자·브라우저에 보내지 않는다. 신규 유료 API·구독·자동 실행 서비스는 추가하지 않았다.

## 동일한 네 질문의 실측

현재 결과 원문은 [ai-runtime-evidence.json](ai-runtime-evidence.json). 첫 답변은 모델 준비를 포함한다. 다른 브라우저·그래픽 작업과 장치 상태에 따라 시간은 달라진다.

| 상황 | 첫 글자 | 답변 완료 | 원문을 읽고 확인한 것 |
|---|---:|---:|---|
| 아무 기록도 읽지 않은 정비사의 첫 안내 요청 | 11.73초 | 18.09초 | 전차·방송국 복원을 안내했다. |
| 비가 그친 거리의 쓸쓸함 | 1.26초 | 4.28초 | 비가 내린다고 바꾸거나 수리를 강요하지 않았다. 표현은 일반적이며 정서적 섬세함은 더 개선할 수 있다. |
| 기록원의 비공개 메모와 정답 요구 | 0.47초 | 1.78초 | 자신이 확인하지 못했다고 답하고 동료에게 물어보도록 했다. 실제 정답은 문맥에 주지 않았다. |
| 자기 수신 메모를 읽은 기록원의 질문 | 0.46초 | 3.22초 | 메모의 눈금을 방송국 다이얼로 설명했다. 공유되지 않은 작은 눈금의 단위·정답을 새로 붙이지 않았다. |

네 답변 모두 실제 모델 생성이 완료됐고 오류가 없었다. 4개 질문은 전체 문장 품질·모든 유도 질문·모든 게임 상태에 대한 정확성 보장이 아니다. 다온은 대화 상대이고, 장치 상태·원문·필수 힌트의 정본은 게임 서버다. 다른 역할의 비공개 단서·자격증명·미공개 엔딩은 모델 입력에 포함하지 않는다.

## 비교에서 버린 결과

처음 시도한 1.7B는 빠르지만 한국어와 사물 관계를 잘못 설명했다. [첫 관찰](ai-runtime-first-pass.json), [두 번째](ai-runtime-second-pass.json), [세 번째](ai-runtime-third-pass.json)에 잘못된 날씨·확인하지 않은 기록을 확인했다는 주장·어색한 문장을 그대로 남겼다. 문구만 바꿔 완료로 처리하지 않고 4B 모델로 교체했다.

4B [첫 비교](ai-runtime-4b-first-pass.json)는 사실 설명이 나아졌지만 쓸쓸함에 수리를 권했다. 현재 판은 도움 요청과 일상 대화를 나눠 불필요한 작업 목표를 줄였다. 공개 사실을 짧게 풀어 주고 장치 조작을 AI에게 맡기지 않는다. 모델이 실패하면 오류 안내와 기존 장소 힌트를 제공하며 미리 쓴 이야기를 생성 답변으로 바꾸지 않는다.

## 사용과 한계

게임에서 `다온에게 말 걸기`를 열어 질문한다. 첫 준비 중에도 도시·퍼즐을 계속 사용할 수 있다. `답변 멈추기`로 중단할 수 있고 역할을 바꾸면 대화가 분리된다. 원하면 `마지막 답변 읽어주기`를 누른다. 이는 브라우저의 한국어 음성 기능이며 전용 성우·실시간 음성 인식은 아니다.

현재 서버는 작은 로컬 체험용이다. 2명까지 대화 요청을 받으며 모델은 순서대로 생성한다. 공개 서비스의 동시 접속·운영 서버·과금·콘텐츠 검수·실제 사람의 대화 만족도는 검증하지 않았다. 실제 AI의 말이 게임 원문과 다를 수 있으므로 정확한 단서는 장소 메모·단계 힌트에서 확인할 수 있게 유지했다.
