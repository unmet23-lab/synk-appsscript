## AI가 관찰한 차이와 원인 분석

아래 원인은 AI의 분석이다. 사용자가 특정 퍼즐·구현 기술·음악 형식을 직접 정한 것으로 쓰지 않는다.

|---|---|---|
| 재질·공간 | 이전 3D에 펠트 타일·섬유·반사·안개는 있었지만 사용자에게 충분한 현실감과 재질 디테일로 읽히지 않았다. | 효과의 존재보다 가까운 물성·규모·거리의 설득력이 부족했을 수 있다. 새 장면은 섬유 디테일과 공간 깊이, 더 몽환적인 빛·하늘을 함께 강화한다. 새 화면과 장면 성능 관찰은 아래 최종 검증에 남겼다. |

| AI 대화 | 이전 판에 실시간 상황 대화가 없었다. | 고정된 조사·힌트 외에도 상황에 응답하는 존재가 필요하다는 요청으로 읽었다. 다온의 별도 대화 UI와 서버 문맥 연결을 구현했다. 실제 로컬 모델 설치·응답을 확인했으며 아래에서 모의 UI 응답과 구분한다. |

## 적용 범위와 다시 판단할 조건

이번 PULSE 협동 작품에서는 펠트 물성·현실감과 몽환적인 분위기, 소리, 자유 이동, 최소 안내와 필요시 힌트, 실제 문제 해결, 구체적 끝맺음, AI 상황 대화를 함께 고려한다. 역할별 정보와 사람끼리의 협력을 유지하되 단서 공유 개수·불필요한 수집·도덕 점수·억지 학습 과제를 붙이지 않는다. 혼자와 2–4인, 모바일·키보드·움직임 감소·정지 장면의 동등한 진행 경로를 보존한다.

전선 퍼즐·수신 주파수·다온이라는 이름·합성 음악 방식은 이번 제작 판단이다. 모든 SYNK 작품에 같은 퍼즐·AI·WASD를 강제하는 규칙으로 옮기지 않는다. 다음 회차에서는 실제 플레이어가 처음 목표를 이해하는지, 임의 클릭 대신 관찰과 조작으로 진행하는지, 공간과 소리를 충분히 느끼는지, 결말에 자신들이 한 일이 남았다고 느끼는지를 다시 본다. 다음 사용자 피드백이나 실제 완주 관찰에서 같은 문제가 드러나면 방법을 고친다.
