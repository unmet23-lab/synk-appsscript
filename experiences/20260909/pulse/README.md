# 마지막 불빛 · PULSE 협동 이야기

폭풍 뒤의 펠트 해안 도시에서 끊긴 전원과 방송을 되살리고, 남은 불빛을 어디에 보낼지 함께 결정하는 브라우저 작품이다. 혼자 두 역할을 바꾸거나 2–4명이 협력한다. 두 장치의 복원, 선택에 따른 후속 장면, 함께 남긴 문장과 내려받을 밤의 기록이 한 편으로 이어진다.

**2026-09-10 개정 체험본.** 펠트 장면·WASD 보행·직접 복원·음악과 효과·실제 로컬 AI 대화를 통합했다. [개정 인수 기록](qa/upgrade-20260910.md)에 실제 검증과 남은 한계를 구분했다. 상업 출시와 사용자 만족 검증은 별도다.

## 열기

상위 폴더의 `체험열기.cmd` 또는 `node start.cjs`로 서버를 시작한 뒤 [PULSE 열기](http://127.0.0.1:4399/pulse/)를 사용한다. HTML 파일을 직접 여는 방식으로 방 동기화는 동작하지 않는다. 다른 기기의 친구를 초대할 때는 [상위 실행 안내](../README.md#열기)의 같은 네트워크 실행을 따른다. `127.0.0.1`·`localhost` 초대 주소는 상대 기기에서 이 서버를 가리키지 않는다.

별도 검수는 `node qa/serve.cjs`로 4419 포트를 사용한다. 별도 작업 사본에 상위 서버가 없으면 `SYNK_PREVIEW_SERVER`에 실제 `server.cjs` 경로를 지정한다.

## 처음부터 끝까지

1. **시작:** `혼자 이 밤에 들어가기`를 누르면 정비사·기록원 두 역할로 시작한다. 친구와는 방을 만들고 초대 링크로 합류한다. 정비사와 기록원이 필수이며 감시인·배달인은 선택이다.
2. **살피기:** 첫 화면의 `도시를 살피고 → 전원과 방송을 고쳐 → 한 곳에 불빛을 보낸다`와 진행 중 목표를 확인한다. WASD로 걷고, 드래그로 둘러보며, 가까운 사물은 E로 조사한다. 가까워지면 하단에 E 안내가 나타난다. 장소 표식이나 이름 버튼으로도 같은 장소에 접근해 전체 이야기를 진행할 수 있다. 설정에서 걷기·둘러보기·전체 보기를 바꿀 수 있다.
3. **복원:** 전차의 연결부를 돌려 끊기지 않는 전선 길을 만들고, 방송국의 다이얼을 조율해 목소리를 되찾는다. 두 장소의 순서와 조작할 역할은 자유다. 자기 역할의 메모에서 다른 정보를 찾고, 필요하면 동료에게 말하거나 메모를 공유한다. **단서 공유 개수는 진행 조건이 아니다.** 막히면 `작은 힌트 보기`에서 단계별 도움을 펼친다.
4. **결정:** 전원과 방송을 모두 복원하면 `불빛을 보낼 곳 정하기`가 열린다. 모든 참여자가 같은 곳을 골라야 방장이 확정할 수 있다. 혼자라면 두 역할로 각각 선택한 뒤 정비사 역할에서 확정한다. 불일치하면 이야기한 뒤 다시 고를 수 있다.
5. **남기기:** 세 선택은 각기 다른 후속 장면으로 끝난다. 원하면 각 역할로 한 문장을 남기고, 실제 복원 순서와 함께 밤의 기록을 내려받는다. 방장은 같은 동료로 다시 시작할 수 있다.

친구끼리 쓰는 채팅·음성 통화는 포함하지 않았다. 같은 자리에서 말하거나 기존 통화 도구를 함께 쓴다. 다온의 AI 대화는 각 역할의 개인 대화이며 친구에게 보내는 메시지가 아니다. 잘못된 조작에 시간·전력 벌점을 붙이지 않고, 결말로 사람의 도덕성이나 실력을 평가하지 않는다.

## 소리와 다온

시작 버튼을 누르면 원작 음악과 바다·바람·장소·조작 소리를 재생한다. 앞서 음소거한 선택은 유지한다. 오른쪽 위 `장면 보기 설정`에서 소리를 켜거나 끄고 음악과 환경·효과의 음량을 따로 조절한다. 소리가 들리지 않으면 `소리 켜기`로 재생을 시작할 수 있다. 합성 음악·효과이며 현장 녹음이나 성우 녹음이 아니다. [음악·효과 구현과 출력 검증](qa/audio-readme.md), [42초 샘플](qa/audio-sample.wav).

`다온에게 말 걸기`는 현재 역할이 아는 기록과 복원 상황을 전달하는 독립 대화 창이다. 다른 참여자의 비공개 단서를 문맥에 넣지 않으며 AI가 장치를 조작하거나 투표를 대신하지 않는다. 역할을 바꾸면 대화 로그가 분리되고 미전송 문장은 비워진다. 닫기·Escape·답변 중단을 제공하며 방을 리셋하면 대화도 초기화한다.

이 컴퓨터에는 Qwen3 4B Instruct 2507 모델을 설치하고 실제 응답을 확인했다. 첫 질문은 준비 시간이 있고, 이후에는 생성되는 대사를 바로 표시한다. 원하면 브라우저의 한국어 음성으로 답변을 읽을 수 있다. 다른 Windows 컴퓨터에서는 상위 폴더의 `node install-ai.cjs`로 검증된 실행 도구와 약 2.5GB 모델을 설치한다. 게임이 자동 다운로드하지 않으며 모델이 없어도 장소 힌트로 끝까지 진행한다. [실제 AI 검증과 한계](../qa/ai-runtime.md), [대화 UI 독립 검수](qa/upgrade-dialogue-ui.md). 대사의 자연스러움과 사실 정확성이 모든 질문에서 보장되지는 않는다.

## 장면·접근성·저장

- 미술 기준은 현실감 있는 펠트 물성·섬유 디테일과 더 몽환적인 하늘·빛·깊이를 함께 강화하는 것이다. Unreal Engine 5·GTA VI는 사용자가 제시한 야심의 참고이며 이번 구현은 Three.js 기반 웹 장면이다. 동급 완성도나 성능을 달성했다는 뜻이 아니다.
- WebGL을 사용할 수 없으면 `assets/felt-city.png`를 정지 장면으로 표시한다. 장소 버튼과 글로 같은 이야기 기능을 유지한다. 정지 이미지를 실제 3D의 증거로 쓰지 않는다.
- 장소 버튼, 보이는 키보드 포커스, 공통 움직임 설정을 제공한다. 소리만으로 필수 정보를 전달하지 않는다. 움직임 감소·경량 모드·새 걷기 조작의 [장면 검수](scene-assets/README.md)를 확인했다. 모바일은 장소 버튼·드래그로 진행하며 실제 휴대전화 성능은 미확인이다.
- 방과 닉네임·복원·투표·문장은 실행 중인 서버 메모리에 남으며 서버 종료 시 사라진다. 역할 자격은 해당 탭의 `sessionStorage`에 둔다. 초대 링크·내려받는 기록에는 토큰을 넣지 않는다.
- `이 밤 잠시 접어 두기`는 자격을 유지하고 `이 밤으로 돌아가기`로 재개한다. 일시적 연결 장애에는 기존 방을 유지하며, 실제 방 소실·자격 만료를 확인하면 새 방으로 시작할 수 있다.

## 검증과 원본

현재 개정의 [서사·복원 검수](qa/upgrade-story.md)는 두 장치의 어느 순서 복원, 공유 0개 완주, 두 역할 합의, 새로고침·문장·내려받기와 키보드 조작을 확인했다. 대화 UI 검수는 1440·390·320px와 독립 Chrome 두 참여자를 사용했다. 실제 사람의 재미·난이도·장시간 청취·재방문, 실제 휴대전화·화면낭독기·외부 네트워크는 별도 확인 대상이다. 외부 배포·결제·판매는 이번 로컬 제작과 구분한다.
