# 마지막 불빛 · PULSE 첫 협동 이야기

2–4명이 서로 다른 단서를 읽고 함께 결말을 고르는 브라우저 프로토타입이다. 한 기기에서 두 역할을 바꾸며 끝까지 체험할 수도 있다. 미술 기준 이미지와 실제 3D는 구분한다. 현재 장면은 Three.js로 구현한 실시간 3D이며, 기준 이미지의 영화적 세밀함이나 사용자가 제시한 Unreal 5/GTA급 완성도에 도달했다고 주장하지 않는다.

## 실행과 조작

상위 `experiences/20260909/server.cjs`와 함께 제공한다. 로컬 주소는 `/pulse/`다. 별도 검수 서버는 이 폴더에서 `node qa/serve.cjs`로 실행하면 `http://127.0.0.1:4419/pulse/`를 연다. worktree에 상위 서버가 없다면 `SYNK_PREVIEW_SERVER` 환경 변수에 실제 `server.cjs` 경로를 지정한다. 서버는 방과 자격을 관리하며, 정적 파일만 여는 `file://` 실행으로 협동 이야기가 동작하지 않는다.

- 장면 드래그 / 방향키: 카메라 회전. 휠 / `+`·`-`: 다가가기. `Home`: 거리 시점으로 복귀.
- 장소 표식 또는 오른쪽 장소 버튼: 실제 3D 사물 접근 및 조사.
- 정비사와 기록원은 필수 역할이다. 감시인과 배달인은 선택 역할이다.
- 자신의 역할로 알아본 단서는 공유 전까지 그 역할의 인증 응답에만 들어온다. 필수 두 역할의 네 단서를 공유한 다음 함께 투표한다.
- 참여자 전원이 같은 선택을 고르면 방장이 확정한다. 서버가 고정된 결말을 반환한다. 임의 점수·정답 낙인·무작위 오류가 없다.
- 방 코드 링크에는 자격 토큰을 담지 않는다. 자격은 탭의 `sessionStorage`에 보관한다. 한 기기 모드는 명시적으로 두 자격을 보유하며 선택한 역할의 SSE만 구독한다.
- ‘이 밤 잠시 접어 두기’는 자격을 보존한다. ‘이 밤으로 돌아가기’로 재개할 수 있다. 새로운 밤은 별도 탭에서 열 수 있다.
- 실제 401/404로 자격이나 방이 사라졌음이 확인되면 새 방으로 복구한다. 일시적인 연결 끊김에는 기존 자격을 유지한다.

## 실제로 구현한 3D

전차, 선로, 돌길, 우체통, 구명환, 항구의 배, 등대, 방송국, 전파탑, 건물과 가로등은 기하 구조를 가진다. 가까이 보는 표면은 SYNK 정본 펠트 타일의 색·요철을 사용한다. 실루엣에는 표면 면적에 비례해 추출한 짧은 섬유 선분이 있다. 젖은 길은 현재 장면을 반사한다. 달빛과 가로등, 안개, 화면 발광 효과를 사용한다. 카메라 이동과 시점 전환에 따라 실제 가림과 원근이 달라진다.

생성 미술 `assets/felt-city.png`는 WebGL 사용 불가·컨텍스트 손실 시의 **정지 이미지 폴백**이다. 그 상태를 화면에 명시하며, 장소 버튼을 통해 같은 이야기 기능을 유지한다. 실제 장면의 배경으로 미술 기준 이미지를 붙여서 3D라고 부르지 않는다. UnrealBloomPass라는 의존성 파일명은 Three.js 효과의 원래 이름이며 Unreal 엔진을 사용했다는 뜻이 아니다.

지금은 자유 대화·AI 즉흥 대사·외부 AI 요청·음악·결제·상용 계정이 없는 작가 설계 에피소드다. 작품 분위기와 협동의 재미는 실제 참가자 검증이 남아 있다. 학교·학생의 기록이나 식별 정보를 사용하지 않았다.

## 시점 비교와 채택

- **A · 도시 전체 조망:** `qa/scene-overview.png`. 네 장소와 항구의 배치가 쉽게 보인다. 그러나 물건과 거리가 멀어져 표면 질감과 ‘그 밤에 서 있다’는 느낌이 약해진다.
- **B · 영화적 거리:** `qa/scene-street.png`. 선로가 시선을 전차와 항구로 이끌고, 물웅덩이·전경 가로등·건물 가림이 깊이를 만든다. 이야기의 기본 시점으로 채택했다. 전체 조망은 설정에 남겨 공간 이해를 돕는다.

두 시점을 같은 장면으로 실제 렌더해 비교했다. 처음에는 발광이 과도했고 일부 `m.stone` 재질 참조가 빠져 순백 기본 재질이 생성되었다. 미정의 재질 검출, 광량 조절, 정본 타일, 면적 비례 섬유 추출로 수정했다. 작은 배 부품과 물결을 재질별로 묶어 렌더 호출도 줄였다.

## 성능과 접근성

픽셀 비율은 기기와 화질 설정에 따라 제한된다. 자동 모드는 충분한 프레임 표본에서 지연이 지속되면 경량 모드로 전환한다. 경량 모드는 실시간 반사·실루엣 섬유·발광 후처리를 줄이고 물체와 조사는 유지한다. 이 자동 임계값의 모든 기기 조건을 실험한 것은 아니다.

공통 `../accessibility/a11y.js`의 움직임 선택을 `world.setReducedMotion(boolean)`에 연결했다. 줄이기를 선택하면 파도·배의 흔들림·등대 회전과 카메라 보간이 멈춘다. 카메라의 사용자 지시 이동은 즉시 반영한다. 표시하지 않는 시작 화면 조사 표식은 키보드 탐색에서도 제외한다. 캔버스와 버튼에 보이는 포커스가 있으며, 실제 사물 조사와 동일한 장소 버튼을 제공한다.

최종 렌더 관찰은 `qa/render-evidence.json`에 남긴다. 2026-09-09 14:24 UTC, 1600×1000, 기기 배율 1, 이 Windows 기기의 Chrome headless에서 5.01초간 300프레임을 관찰했다(약 59.88fps, p95 16.9ms). 사용자 모든 기기에서 60fps를 보장하는 자료가 아니다. 호출/삼각형 수는 그림자·반사·후처리를 포함한 프레임 합계다. 경량 모드에서는 호출 245→107, 반사·실루엣 섬유 비활성화와 움직임 줄이기의 실제 적용을 확인했다. 최종 캡처의 콘솔 오류는 0이었다.

기능의 독립 검수는 부모 작업의 `pulse_function_review`가 담당했다. 두 브라우저 컨텍스트의 개인 단서 분리→공유→불일치 투표→재접속→합의→결말→리셋, 320/390px 두 역할 체험을 확인했고, 지적된 결말 스크롤·탭 이탈 자격·숨은 포커스를 수정했다. 수정 후 일시적 연결 장애 회복, 실제 404/401의 새 방 복구, 390px 정지 폴백에서 Tab/Enter만으로 결말 완결까지 재검수했다. 6개 화면 상태의 axe 검사 지적은 0이며 미해결 기능 지적은 없었다. 상세 근거는 상위 `qa/pulse-review/README.md`에 있다. 자동 검사와 실제 사람끼리의 재미 검증을 같은 성공으로 취급하지 않는다.
