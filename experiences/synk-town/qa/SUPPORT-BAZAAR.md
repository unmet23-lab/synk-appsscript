# 읽기 도움과 두 손님 · 로컬 구현 검증

2026-10-09. [첫 하루](DAY.md)에 이어 같은 가상 기록에서 실행한다. 입구는 `http://127.0.0.1:4288/day.html`이며 실제 WORLD 계정과 연결되지 않은 개발 체험이다.

## 플레이에서 달라지는 것

| 흐름 | 실제 행동과 남는 결과 |
|---|---|
| 내 속도 → 짧은 안내문 읽기 | 18개 자체 문항의 세부정보·순서·부정 중 직접 답한 영역만 서버 채점. 힌트와 같은 계열 반복은 독립 수행과 분리한다. |
| 읽기 뒤 설명 제안 | 기존 Core의 영역·난도 1·단일 선택 기록을 재사용한다. 제안을 수락해야 다음 생활에 적용하며, 기록이 없어도 설명 방식과 기획 역할을 직접 고를 수 있다. |
| 하나씩 보여 주기 | 첫 하루에서는 물건 설명 두 단계를 사용자 신호로 진행한다. 두 손님 응대에서는 한 손님의 요청을 듣고 다음 요청을 명시적으로 연다. 진행 중 회차의 모드와 원래 추천 근거는 설정 변경 후에도 보존한다. |
| 서로 다른 두 요청 | 책 손님은 달지 않은 차, 동행 손님은 따뜻한 물을 요청한다. 요청표를 보고 실제 잔과 단맛을 고른다. 잘못 맞추면 소비하지 않고 수정한다. |
| 물부터 또는 함께 제공 | 두 잔의 준비분을 예약하고 준비 3초·제공 2초를 따로 수행한다. 물부터 주면 사용자가 차를 이어 주기 전까지 기다린다. 집에 다녀와도 남은 차만 이어간다. |
| 음식 없는 그림 메뉴 가판 | 그림 먼저/글 먼저가 실제 3D 메뉴판 배치를 바꾼다. 찻집·공방 주민과 손님이 처음 이야기를 나눈 사실을 남기고, 없는 음식 제공·판매·사용자 배치 공로를 만들지 않는다. |

시범·협력·기획과 기획자·관람자·위임은 한국어 설명 길이와 별개다. 생활 수행, 주민의 인지, 결과를 실제 본 사실도 따로 기록한다. 차 1몫·물 1몫의 고정 준비분을 쓰며 취소·재접속·중복 명령으로 늘지 않는다. 이번 두 회차는 정해진 원고를 한 번씩 체험하며, LS02 전체 완결·반복 장터 운영은 아니다.

## 학습 범위와 아직 남은 일

읽기는 **TOPIK I의 짧은 안내문에서 세부정보·부정·순서를 구분하는 연습**을 다룬다. 자체 문항의 실제 응답 기록이며 공식 급수 평가·검증된 난도·학습효과가 아니다. 생활 선택·NPC 반응·제공 성공은 학습 정답으로 쓰지 않는다. 이 로컬 읽기 기록은 WORLD 계정·교사·동기화 기록에 전송하지 않는다.

실제 참가자 **0명**, 실제 휴대폰 **0대**, 공개 배포 **없음**. 휴대폰 폭 에뮬레이션은 실기기 성능·터치·체감 재미 검증을 대신하지 않는다. 소형 3D 장면의 이름표 밀도와 실제 재미·접근 빈도는 [관찰표](DAY-PLAYTEST.md)로 확인해야 한다.

다음 제작 범위는 검증된 WORLD 계정의 개인별 생활 시간·권한·동의에 이 생활 호스트를 연결하는 일, LS02 후속·보답과 다른 장편 확장, 최종 3D 자산이다. 실제 사람·기기 검증과 별도로 진행한다. 열 가지 콘텐츠 전체나 무한 생성 NPC를 완성했다고 주장하지 않는다.
