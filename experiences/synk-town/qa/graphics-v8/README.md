2026-10-09 사용자 「좋아. 전부 지금 해줘」에 따른 로컬 구현·검증이다. 카페 앞을 기준으로 건물·소품·식재·주민 의상·UI를 연결했다. [브랜드 적용 원문](../../../../docs/디자인/게임_풍경과_재질.md#싱크타운-브랜드-미술--2026-10-09-사용자-채택), [로컬 실행 화면](http://127.0.0.1:4288/day.html?play=walk&graphics=v8).

## 적용 내용

- **형태와 공간:** 짙은 기와·밝은 회벽·나무 마루로 건물을 묶고 카페 앞에 공동 마루를 만들었다. 차양 끝의 두 번 굽이치는 완만한 물결, 낮은 담과 열린 식재 간격을 사용한다. 보행 높이·건물/벤치 충돌·길은 그대로다.
- **색의 역할:** 코랄 행동/작은 생활 소품, 청금석 안내/협력, 버터 기억/등불, 메도우 성장, 팝은 작은 개성으로 구분한다. 기존 마스코트의 IP 색·얼굴·팔 없는 몽글 실루엣을 변경하지 않았다.
- **재료와 빛:** 새 면 직조의 색·법선·거칠기 맵을 안내 천·차양·테이블 천·방석에 적용한다. 목재·석재·회벽·도자기·유리는 각자 재료를 유지한다. 조명과 안개는 중립적으로 정리했고 광원·애니메이션 루프·후처리 타깃을 추가하지 않았다.
- **생활의 기억:** 실제로 완료된 도움/차/조율의 planner/delegated 기록을 읽어 장소별 최신 자수 표식을 최대 네 개 보여 준다. 관찰자·혼자 한 도움·미리보기·미완료는 참여 표식이 되지 않는다. 표시 자체는 저장 상태·인벤토리·보상을 바꾸지 않는다. 기록을 비우면 표식도 해제한다.
- **주민:** 카페 앞치마·공방 작업복·독서 손님 카디건·책 손님 니트·동행자 재킷/가방을 같은 색 역할로 연결한다. 교수의 원래 몸·안경·수염·얼굴은 보존하고 얼굴 아래 작은 배지만 추가했다. 여섯 명의 체격·머리·얼굴·리그·움직임은 유지한다. 대체 화면의 여섯 초상도 실제 현재 모델로 다시 렌더링했다.
- **UI:** Paper/Black 읽는 면과 승인된 실제 펠트 부품을 연결했다. 버튼의 위치·크기·조작법은 보존하고 네 대화창의 제목 접근성 연결을 보완했다.

실제 WASD 입력으로 집→카페→온실→공방을 걷고 터치 조이스틱도 확인했다. 공방에서 시작·선택·확인·완료를 차례로 실행해 완료 전 표식 0개, 완료 후 해당 resultId 표식 1개, 새로고침 후 중복 없이 같은 표식 1개를 확인했다. 자동 검증은 별도 임시 포트·일시 저장소만 사용했다. 4288에서는 공개 정적 파일 GET만 했으며 사용자의 기존 저장을 읽거나 초기화하거나 수정하지 않았다.

생활 표식 CPU 검사는 관찰자·혼자 도움·알 수 없는 종류/장소·프로토타입 속성 장소·중복/오래된 기록·전체 기록 초기화도 포함한다. 일시 파일 저장소 재시작 뒤 delegated 완료의 복원을 확인했다. `currentScene`은 완료된 observer 기록도 전달하지만 실제 렌더 함수에서 제외한다. 표시 함수는 독립 인증 경계를 새로 만드는 것이 아니라 기존 서버의 확정 기록을 보여 주는 함수다.

자원 검사는 실제 면 재료의 테이블·방석과 명시적인 **표시 전용 fixture 표식**을 생성한다. 이 표식은 실제 생활 완료 근거로 사용하지 않는다. 정상 해제는 인스턴스 182/182 해제, WebGL 컨텍스트 해제를 확인했다. 원시 버퍼는 1159개 중 1158개 삭제 후 렌더러 내부 버퍼 1개가 남으므로 모든 deleteBuffer 수가 같다고 주장하지 않는다. 조기 해제 사례는 늦은 로드 후 버퍼 24/24·인스턴스 182/182 해제, 컨텍스트 해제 유지였다.

## 성능과 보존 범위

호스트 headless Edge에서 실제 연속 걷기를 10초 이상 기록했다. 처음 500ms를 제외한 완료 렌더 타임스탬프이며 진단 수집 비용도 포함한다.

| 뷰포트 | v7 평균 | v8 평균 | 평균 비율 | v8 간격 p95 | v8 최대 간격 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1280×900 | 57.96fps | 55.66fps | 96.02% | 22.2ms | 59.7ms |
| 390×844 | 59.37fps | 56.93fps | 95.89% | 20.2ms | 520.5ms |

두 크기 모두 검사 기준인 평균 55fps 이상·v7 대비 평균 감소 5% 이내를 통과했다. **390폭에서 이동 중 520.5ms 지연 1회와 50ms 초과 간격 총 2회가 기록됐다.** 이번 기록으로 호스트/진단/제품 중 원인을 분리하지 못했으며 지속 60fps·끊김 없음으로 해석하지 않는다. 실물 휴대폰의 성능/발열 검증도 아니다.

환경 삼각형은 897,727→871,703(-2.90%), 메시 239→247, 기하 93→96, 환경 소유 재질 32개다. [환경 모델](environment-model.json)로 유한 좌표·뒤집힘·장소·타깃·해제를 확인했다. 모바일 균형 모드와 전체 시점은 추가 후처리 버퍼 0개, PC 균형 모드는 기존 8샘플 접촉 음영을 유지한다.

v7 제품 소스 27개를 수정 전 [기준본](baseline-hashes.json)으로 보존했다. 허용된 제품 소스 변경은 `day-materials.mjs`, `day-environment.mjs`, `day-scene.mjs`, `day-residents.mjs`, `day-app.mjs`, `day-style.css`, `day.html`의 일곱 파일이다. 다른 20개와 별도 생활·권한·이동 핵심 10해시는 그대로다. 장면의 카메라/프레임/입력/해제 함수와 주민 동작/얼굴/머리 함수도 정규화 소스 및 AST로 대조했다. 앱 변경은 완료 기록을 장면에 전달하는 한 줄뿐이다.

비트맵은 제품 소스 수와 별도다. 승인 펠트 세 파일 82,504바이트를 원본 해시 그대로 복사했다. 기존 절차형 초상 여섯 장은 [변경 전 기록](portrait-before-hashes.json)과 기준본에 보존하고 현재 모델 PNG로 교체했다. 승인 교수님 2D 원본은 무변경이다. [펠트 대비 표본](ui-contrast.json)은 표면 픽셀 통계이며 전체 WCAG 적합 판정이 아니다.

첫 after 경로 검사는 기존 벤치 충돌 구간을 가로질러 목표에 도착하지 못했다. [첫 경로 결과](route-check-first/after.json)를 보존하고 원래 공방 통로 z=1.7로 검사 경로만 수정해 전체를 다시 통과했다. 제품 충돌/이동 코드는 수정하지 않았다.

## 현재 한계와 다음 미술 작업

타운의 브랜드 기준과 실제 화면 연결은 구현했다. 가까운 흰 차양·테이블 천은 주름/두께/빛 표현을 더 정교하게 만들 여지가 있고 원경 집·나무의 반복도 남는다. 현재 절차형 모델을 최종 미술 마스터로 확정한 것은 아니다. 실제 사용자의 멀미·최종 미술 만족, 실물 휴대폰/게임패드, 실제 WORLD 계정/두 기기, 공개 배포는 이번 검증 범위 밖이다.

재현 명령은 저장소 루트에서 실행한다. GPU 검사는 동시에 실행하지 않는다.

```powershell
node experiences/synk-town/qa-brand-v8.cjs
node experiences/synk-town/qa-residents-ui.cjs --portraits-only --output-dir qa/graphics-v8/portraits
node experiences/synk-town/qa-brand-resources-v8.cjs
node experiences/synk-town/qa/graphics-v8/scope-guard.cjs --final
node experiences/synk-town/qa/graphics-v8/check-served.cjs
node experiences/synk-town/qa/graphics-v8/finalize-verification.cjs
```

초상 명령은 PNG 여섯 장을 현재 모델로 다시 쓴다. 기준선 재취득은 기존 v7 원본에만 수행해야 한다. `before.json`과 `source-before`를 현재 v8로 덮어쓰지 않는다.
