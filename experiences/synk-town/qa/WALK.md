# 직접 걷는 마을 · 구현과 검증

2026-10-09. 사용자가 장소 메뉴 중심 시제품을 **직접 움직이는 자유 탐색 방식**으로 변경했다. [조작 정본](../../../docs/마을_설계.md#town-controls), [첫 경로의 실행 설계](../../../docs/디자인/싱크타운_첫플레이_실행설계.md)를 함께 갱신했다.

## 실제 조작

- 기본 입구: `http://127.0.0.1:4288/day.html`. 전체 화면에 마을을 보여 주고 캐릭터를 따라간다.
- PC: WASD·방향키로 연속 이동, 가까운 장소에서 E 또는 화면 버튼으로 생활 열기. Esc 또는 다시 걷기로 생활 선택창을 닫는다.
- 터치: 왼쪽 가상 조이스틱으로 이동하고 오른쪽 상호작용 버튼을 누른다. 놓기·터치 취소 때 멈춘다.
- 표준 게임패드: 왼쪽 스틱·방향 패드로 이동, A로 상호작용, B로 생활 선택창 닫기. 브라우저의 표준 매핑을 지원하는 패드만 사용한다.
- 동네 보기는 시점만 바꾼다. 장소 메뉴·건물 클릭으로 순간이동하지 않고, 근처에 가는 것만으로 생활을 수락하지 않는다.

길과 열린 건물 앞 공간을 걸어 다니며 집·찻집·공방·온실의 기존 생활을 이용한다. 벽·작업대·화단·벤치·화분·연못과 세계 경계의 충돌을 검사한다. 대각선 속도를 보정하고, 카메라와 캐릭터 사이에 끼어든 건물은 옅게 표시한다. 이동한 위치와 방향은 같은 개발 기록에 저장한다.

대화창·입력란·다른 창으로 초점 이동·숨김 상태에서는 입력을 멈춘다. 돌아왔다고 이전에 누르던 키를 계속 적용하지 않는다. 움직임 줄이기에서도 직접 이동은 유지하고 장식 흔들림을 줄인다. WebGL을 사용할 수 없으면 기존 장소 선택과 텍스트 생활 대안을 명시해서 제공한다.

## 서버와 생활의 연결

`walk.mjs`의 이동·충돌 판정을 서버와 화면 예측이 함께 사용한다. 서버가 최근 실제 시간에서 최대 250ms의 이동 예산을 정하며, 클라이언트가 임의 좌표를 확정하지 않는다. 같은 조작 창의 전경 임대·fence·이전 revision을 확인하고 저장 성공 뒤 위치를 공개한다. 서버 재시작·임대 만료·조작 창 교체는 이전 이동 시간을 따라잡지 않는다.

`DAY_INTERACT`는 가까운 장소에서 기존 방문·귀가 의미만 연결하며 좌표를 바꾸지 않는다. 찻집 자리·두 손님·주민 대화·첫 하루의 행동과 결과 관람도 위치를 확인한다. 다른 곳으로 걸어간 상태에서 원격 제작·제공·관람을 확정하지 않는다. 생활 중단 기록, 읽기 설명, 역할 기억, NPC 예약과 기존 준비 작업은 보존한다.

## 검증 자료

- [전체 코드 검사](walk-runtime.json) · [출력](walk-runtime.txt): **209/209 통과**. Town과 WORLD Town 연결의 회귀 결과, 명령 목록·소스 해시를 기록했다. 걷기 검사는 대각선·충돌·속도 제한·중복 요청·저장 실패·새로고침·비소유 창·원격 상호작용·재개·기존 찻집 이용을 포함한다.
- [직접 입력 화면 검사](WALK-ui.json): **36/36 통과, JavaScript 오류 0**. 실제 키보드, CDP 터치 입력, 합성 표준 게임패드 입력으로 조작을 검사했다. 화면·저장 좌표·카메라, 근접 행동, 320/390px와 텍스트 대안을 함께 확인했다. 실행 전후와 현재 소스 해시가 일치한다. Headless Edge의 실제 탭 전환만으로 초점 상태를 바꾸지 못한 조건은 합성 blur/hidden으로 검사했고 그 한계를 JSON에 남겼다.
- [기존 첫 하루](day-ui.json), [읽기·두 손님](support-bazaar-ui.json) 검사는 `?controls=classic`으로 옛 생활 흐름의 회귀를 검사한다. 직접 걷기의 증거와 구분한다.

실제 화면: [PC 직접 걷기](WALK-follow-desktop.png), [390px 터치](WALK-touch-390.png), [320px 근접 생활](WALK-cafe-320.png). 모바일 자막과 시점 버튼의 겹침도 수정하고 검사했다. 균형/자세히 렌더 간격 제한은 이동 입력에도 적용하며 실제 휴대폰 성능 보장은 아니다.

```powershell
node --test experiences/synk-town/*.test.mjs experiences/teacher-world/town-bridge.test.mjs
node experiences/synk-town/qa-walk-ui.cjs
```

## 현재 범위

직접 걷기와 기존 생활을 연결한 작은 마을 시제품이다. 전체 오픈월드 지도, 모든 건물 실내·고저차·점프·동적 군중 충돌·NPC 실시간 길찾기·멀티플레이는 후속 제작 범위다. 현재 NPC는 작성된 일과와 생활 동선을 사용한다.

실제 플레이 관찰 0명, 실제 휴대폰 0대, 물리 게임패드 검증 0대, 공개 배포 없음. 표준 게임패드 API 입력 검사를 정식 콘솔 플랫폼 지원으로 표현하지 않는다. 데스크톱 에뮬레이션과 합성 입력은 실제 터치감·발열·재미의 검증을 대신하지 않는다. 실기기에서는 이동 속도·카메라 거리·조이스틱 크기·가림과 대화 접근거리를 우선 관찰한다.
