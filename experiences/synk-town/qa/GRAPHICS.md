# 싱크타운 3D 그래픽·근접 시점 검증

2026-10-09 로컬 브라우저 검증. 최초 비교 화면은 변경 전에 보존했으며, 모든 회차는 새 메모리 저장소를 쓰는 임시 서버에서 실행했다. 실제 사용자 저장 파일을 초기화하거나 변경하지 않았다.

최종 그래픽 회차는 05:02:47~05:04:56(KST), **63/63 통과**, 브라우저 JavaScript 오류 0, 변경 후 화면 25장이다. 저장된 걷기 상태로 재입장할 때 초기 초점·소유권을 회복하는 앱 수정과, 근접 가림 메시를 완전히 숨겨 잔상을 없애는 마지막 마감까지 포함했다. 촬영 시작·종료 사이 그래픽/이동/화면/공용 캐릭터 소스 해시도 일치했다. 같은 소스의 [생활·저장·교사 연결 런타임 검사](graphics-runtime.json)는 209/209, [기존 자유 걷기 UI 검사](WALK-ui.json)는 36/36 통과했다.

- 같은 초기 위치 `home / x=-6 / z=1.7`, 같은 기본 따라가기 시점에서 1280×900, 390×900, 320×900을 비교한다.

## 실제로 확인하는 동작

- 새 캐릭터·재질 자산이 준비된 WebGL 화면이며 그래픽 대체 화면이나 자산 실패가 없다.
- 따라가기 → 가까이 → 동네 → 따라가기 전환 중 저장된 위치가 바뀌지 않는다. 이동하면서 시점을 바꾸어도 순간이동하거나 생활 창을 자동으로 열지 않는다.
- 근접 시점에서 카메라 좌표가 유한하고 바닥·플레이어 몸 안으로 들어가지 않으며 플레이어가 화면 안에 있다. 건물 뒤에 실제로 걸어가면 따라가기 시점에서는 가리는 건물이 반투명해지고, 근접에서는 가리는 메시가 완전히 숨는다.
- 플레이어 앞 벤치가 얼굴·몸을 가리는 경우 근접에서는 완전히 숨겨 얼굴·목도리에 잔상이 남지 않는다. 걷기 따라가기에서는 14% 반투명으로 처리하고 그림자를 받지 않는다. 정면을 향해 실제로 조금 걸은 뒤 1280·390·320에서 검사한다. 숨겨진 물체의 이동 충돌은 유지한다.
- 모바일 조이스틱으로 이동하고, 키보드로 집에서 찻집까지 걸어간 다음 실제 상호작용 단추를 눌러 생활 창을 연다. 창을 열어도 플레이어 좌표는 유지된다.
- 320·390·700 세로 화면의 생활 창이 플레이어와 찻집주인 양쪽 얼굴을 가리지 않는다. 320·390에서 창을 닫으면 근접 시점으로 되돌아온다. 844×390의 짧은 창은 스크롤해 실제 집 꾸미기 선택을 확정할 수 있다.
- 데스크톱에서 기존 첫 쉼터 선택·놓기·NPC의 실제 이용·전달을 끝까지 진행한다. 움직임 줄이기 설정에서도 걷기와 시점이 유지된다.
- 조작부가 화면 밖으로 나가지 않고 서로·시점 설명·플레이어 중심과 겹치지 않는다. 브라우저 JavaScript 오류가 없으며 촬영 도중 소스가 바뀌지 않는다.

검수 중 발견한 카메라 단추의 화면 밖 배치, 벤치가 얼굴을 가리는 현상, 세로 생활 창이 플레이어·대화 상대 얼굴을 덮는 현상을 각각 실제 화면으로 재현한 뒤 담당 코드에서 수정했다. 벤치의 틈을 통과하는 단일 메시 광선 판정은 가림 범위를 놓쳤으므로, 최종 회차는 물체 전체 범위와 여러 신체 지점의 판정을 검증한다. 근접에서 반투명 벤치와 그림자가 눈·목도리 위에 남던 잔상은 가림 메시를 완전히 숨겨 제거했고, 따라가기·동네 시점으로 바꾸면 해당 시점의 표시로 복원한다. 생활 창에서는 가까운 두 캐릭터를 실제 빈 공간에 함께 배치하는 카메라 계산을 적용했고, 320·390·700 최신 화면에서 양쪽 얼굴을 직접 확인했다.

## 범위와 남은 검증

이 기록은 코드·브라우저 검증이다. Galaxy S25·iPhone 15 등 실물 기기의 지속 FPS·발열·메모리, 사람의 멀미·재미·미술 만족도, 배포 상태를 보증하지 않는다. 현재 공용 몽글 팩토리는 시제품이며 완성 마스터 자산으로 승인된 상태가 아니다. 화면에 담은 경로와 장면을 넘는 모든 카메라 위치·캐릭터 조합의 시각 검수를 완료했다는 뜻도 아니다.

현재 후 화면은 `node experiences/synk-town/qa-graphics-ui.cjs`로 재현한다. `--before`는 원본 변경 전에만 사용한 비교 기록 생성 옵션이다. 보존된 전 화면을 현재 코드로 덮어쓰지 않는다.
