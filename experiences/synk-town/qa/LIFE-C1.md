# 첫 자율생활 시제품 · GOAL-C1

2026-10-09. **로컬 개발 체험 구현과 자동 검증** 기록이다. 실제 플레이어의 재미 검증·공개 배포 기록이 아니다.

## 플레이할 수 있는 것

`node experiences/synk-town/server.mjs --preview`로 열고 `http://127.0.0.1:4288/preview.html`에 접속한다. 첫 쉼터를 놓고 손님의 이용 장면을 보면 찻집 주인이 자기 잔을 정리하고 쉬는 모습을 볼 수 있다.

1. **주인과 자리 이야기**를 직접 연다. 함께 방향 정하기·보기만 하기·주인에게 맡기기가 있다. 조용히 설정에서도 가능하다.
2. 함께 정할 때 **자리 가까이 / 통로를 넓게**를 고른다. 확정 전에는 원래 물건이 움직이지 않는다.
3. 확정하면 주인이 정리→이동→쉬기를 실제로 실행한다. 아래로 내려가 있었다면 **주인 있는 곳 보기**를 눌러 결과를 본다.
4. **함께한 일**에는 실제 맡은 역할이 남는다. 다시 직접 대화하면 역할에 맞는 지난 일을 회상한다. 결과를 보지 않았던 관람자에게 함께 봤다고 말하지 않는다.
5. 아직 직접 다루지 않은 자리에서는 보통/활발 설정과 안전한 접점, 첫 유효 시간 45초 등의 조건에 맞춰 주인이 먼저 제안할 수 있다. 자동 대화창은 열리지 않는다. 거절·지나침·직접 시작한 같은 이유는 재발급하지 않는다.

시간·접근 상한은 목표 횟수가 아니다. 첫 시제품은 네 좌석 슬롯의 C1 기회와 직접 선택만 담고 있으며 새로운 부탁을 계속 생성하지 않는다. 자리 방향 두 갈래·역할 세 갈래를 새 이야기 여러 편으로 세지 않는다.

## 확인한 결과

- [Node 검사](life-runtime.json): **100/100 통과**, 건너뜀 0. 모든 Town 테스트와 teacher-world Town bridge 회귀를 포함한다. 정확한 실행 명령·소스 SHA-256과 [원출력](life-runtime.txt)을 보존한다.
- [Chromium 실제 버튼 검사](life-ui.json): **23/23 통과**. FT10 시작·기존 표현의 몸체 우선권, 키보드 초점, 자기 일과, 세 역할, 미결정 재개, 화면 밖 미관람, 접점 두 창 중복 방지, 거절 후 새로고침, 움직임 줄이기와 320/390px를 확인한다. 격리 서버·가상 기록만 썼다.
- 화면 직접 검사: [390px](life-ui-390.png), [320px](life-ui-320.png), [데스크톱](life-ui-desktop.png). 글자·펠트 단추·그림 누락·가로 넘침을 확인했다. 실제 휴대폰 측정은 아니다.

UI 검사의 최초 숨긴 Electron 창은 약 1Hz로 렌더되어 FT 관람 시간 시험이 끝나지 않았다. 앱의 관람 조건을 낮추지 않고 offscreen Chromium 렌더링을 사용해 실제 프레임과 화면을 검사했다. 시나리오 선택은 렌더된 단추로 수행했으며 결과 관람은 화면·결과줄 노출을 확인한 뒤에만 기록했다.

## 이번에 고친 경계

| 문제 | 처리와 확인 |
|---|---|
| 안내판만 바꿔도 잔 방향 합의가 사라짐 | 자리 전용 `lifeSeatRevision` 사용. 안내판 설치·삭제는 합의/과거 기억을 유지하고 실제 자리 이동·회수만 현재 합의를 해제 |
| 직접 한 일을 다시 자동 권유 | 실제 자리의 canonical need를 보존. 직접 열면 기존 초대도 닫되 이미 사용한 예산은 환급하지 않음 |
| 관람을 기획 공로로 기억 | 실행한 역할과 실제 관람을 별도 기록. 관람 경로는 기존 배치를 바꾸지 않고 현재 사용 합의를 새로 취득하지 않음 |
| 두 창·재시작으로 시간/제안 복제 | 전경 시간 합집합, 단일 전달 fence, durable 발급 원장. 오프라인 경과 실행 없음 |
| 화면 밖 결과를 함께 본 것으로 기록 | 서버 실행 완료와 화면 1.2초 관람 ACK 분리. 미관람 복귀에서 실제 결과만 회수 |
| 저장 실패 후 진행/발급 일부만 남음 | 시간·접점·역할·Trail 사실을 같은 저장 뒤 공개. 실패 전 상태 유지와 같은 명령 재시도 검증 |
| 매초 갱신이 키보드 초점을 없앰 | 같은 행동/선택이면 버튼 DOM 유지. 기존 FT 버튼 초점 보존 확인 |

## 아직 확인하지 않은 것

- **RH01~20 전체 합격이 아니다.** 접근의 경계 산식·일부 거절/조용히/역할/복귀 규칙을 이 한 구간에서 실행했다. RH02/03의 실제 20/60분 플레이, RH05의 실제 두 기기 계정, 공방·연구원·공개 동의, LS 연속 회차, 전체 콘텐츠 소진/업데이트는 별도다.
- H00, LS01~03 전체, 주민쌍·보답·열 가지 생활·공연·숙련도별 협력 행동은 후속 구현이다. 실제 사용자 관찰 참가자는 **0명**이다.
- 전경은 브라우저의 신고를 사용하고 서버가 시간을 계산한다. 네트워크 끊김 끝단은 최대 3초 임대 범위가 포함될 수 있다. 한 프로세스·한 가상 기록이며 운영 계정 동기화/클라이언트 부정행위 방어를 검증한 것은 아니다.
- 기존 FT10/51의 턴 방식 확정과 신규 C1의 시간 실행이 공존한다. FT10 재료 지급 시점 등 전체 첫 플레이 명세의 남은 변경을 이번에 완료했다고 하지 않는다.
- 기존 2D 곰·사슴은 개발용이다. 최종 WORLD 3D 미술, 실제 앉기/제공 전용 동작·음성, 실기기 성능, 실제 재미·학습효과·서비스 입장 권한·배포는 미검증이다.

다음 구현은 이 한 구간의 플레이 관찰에서 불편을 고친 뒤 첫 집 H00와 공방/연구원의 서로 다른 실제 역할, LS 첫 연결·보답으로 넓힌다. 전체 열 가지 경험의 설계 범위는 유지한다.
