# 첫 하루 플레이 관찰표

2026-10-09. [원본 검증 설계](../../../docs/디자인/싱크타운_생활리듬_검증설계.md#play-observation)의 실행용 기록지다. 현재 실제 참가자 **0명**, Galaxy S25·iPhone 15 실제 검사 **0대**. 아래는 준비한 절차이며 실행 결과가 아니다.

`node experiences/synk-town/server.mjs --preview`로 실행하고 `http://127.0.0.1:4288/day.html`을 연다. 기본 저장은 기기당 가상 기록 한 개다. 실제 학생 계정·동기화가 아니다. 기존 기록을 임의 삭제하지 않으며 참가자별 초기 상태가 필요하면 검사자가 별도 임시 저장 파일로 서버를 연다.

## 참가 전

가명 ID, 빌드/내용 버전, 날짜, 기기·브라우저, 시작 기록, 도움 방식·말 걸기 설정, 기록 동의 범위만 남긴다. 실명·음성·민감한 개인 대화는 기본 수집하지 않는다. 화면의 메모는 자기 점검용이며 참가자 연구로 자동 계산하지 않는다.

|---|---|---|

| 가까이에서 생활 열기 | 자유롭게 돌아다니다 원하는 대상 가까이에서 E·이야기 버튼을 누른다 | 자동 문답 없이 스스로 선택했다고 느끼는지, 거리·안내·닫고 걷기가 명확한지 |

| 작은 그림 가판 | 그림과 글 중 먼저 소개할 것을 고른다 | 선택한 순서를 메뉴판에서 발견하는지, 손님과 공방 주민의 첫 대화가 다음에 궁금할 관계로 느껴지는지 |

| 마침 | “다시 하고 싶은 것과 덜 하고 싶은 것은?” | 자발적 다음 행동·쉬기·나가기, 선택 때문에 바뀐 장면을 자기 말로 설명 |

같은 상태의 복제본에서 다른 선택을 비교할 수 있다. 검사자가 만든 과거를 참가자의 추억으로 설명하지 않는다. 같은 날 빠른 재방문을 장기 복귀 경험으로 기록하지 않는다. 체류 시간·무응답을 재미·거절·언어 능력으로 자동 해석하지 않는다.

여럿의 비율은 반드시 분모를 붙인다. 원본 설계의 6~8명은 형성 평가 출발안이며 통계적 학습효과 입증이 아니다.

## 실제 기기 검사

Galaxy S25와 iPhone 15에서 각각 브라우저·OS·해상도·품질을 남긴다. 집→찻집→공방→온실→귀가, 세로/가로 전환, 백그라운드 복귀, 3D 실패 대안, 터치 크기·글·스크롤, 장시간 프레임/발열/배터리와 끊김을 관찰한다. 개발 안내의 최근 프레임 간격과 CPU 렌더 시간만으로 GPU·발열·배터리 합격을 선언하지 않는다. 데스크톱의 320/390px 검사는 별도 증거다.

한국어에서는 위치·순서·요청/분담 표현을 읽고 행동하는 연습을 관찰한다. TOPIK 읽기의 짧은 지시·순서 이해와 연관된 소재지만, 생활 선택은 채점 문항이 아니며 이 검사로 TOPIK 급수·학습효과를 산출하지 않는다.
