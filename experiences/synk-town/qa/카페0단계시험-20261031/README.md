**산출물(git 밖):** 공용 작업본 `.tmp/town-cafe-0-20261031/` — `판/`(구운 원본 PNG와 굽기 기록), `웹판/`(780px WebP · 목소리 두 줄), `T0/` · `T1/` · `T2/` · `T3/`(시험관 폴더마다 질문.md · 그림 · 답_*.md). 원본 PNG는 원본 창고 묶음이 올린다.

**다시 돌리기:** 그림은 이미 있으니 화면만 다시 그릴 때는 `node <파일>.mjs`(답이 든 시험관 폴더는 덮지 않고 멈춘다). 시험관은 폴더마다 Agent `model: sonnet` · `haiku`에 「그 폴더의 질문.md를 읽고 답 꼴대로만, 폴더 밖은 열지 말 것」으로, GPT는 `node tools/GPT시험관.mjs <폴더>`로 부른다([제작 절차 「시험」](../../../../docs/마케팅/기획장부/제작절차.md)).

**지킬 것:** 인물은 지어낸 인물(태오 · 문 교수 — 드라마 1화 승인 얼굴)이고 학생 얼굴은 그리지 않는다. 손님 목소리는 승인된 1화 녹음(선배 6번 · 교수 9번)을 다시 쓴 것이라 새로 굽지 않았다. 공개 전에는 실존 인물 닮음 대조를 다시 한다. 몽글 카드(T1 무리 M)는 지금 앱 자산을 시험 화면에만 얹은 것이고, 앱에 쓰는 판이 아니다.
