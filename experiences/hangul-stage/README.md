# 한글 단계 · SYNK WORLD (MVP)

한글을 한 글자도 모르는 사람이 혼자 가·나·다를 배우는 WORLD 콘텐츠다. 2026-10-03 유호님 방향 「20개국 정도에 출시할 예정이라 많은 국가들이 필요해. 그래서 일단 한국어로 mvp만 만들어도 괜찮을 것 같아」에 따라 **도움 언어 없이 한국어로만** 만들었다. 글을 못 읽어도 할 수 있게 시범·그림·소리로 이끈다(설계 §2 「보여 주는 안내가 먼저다」). 설계 정본은 [한글 단계 설계](../../docs/한글단계_설계.md)다.

이 판은 **로컬 MVP**다. 운영 배포, WORLD·학습 허브 목록 등록, 학생 효과 확인, 사람 귀로 한 소리 확인은 아직 하지 않았다.

```powershell
node experiences/hangul-stage/server.mjs      # http://127.0.0.1:5240/
node --test experiences/hangul-stage/core.test.mjs
node experiences/hangul-stage/qa/flow.cjs     # 서버를 띄운 뒤, 헤드리스 크롬 화면 점검
node tools/build-hangul-stage.js [--check]    # 한글 층 지도와 학습 묶음 만들기
```

## 들어 있는 것

| 부분 | 내용 |
|---|---|
| 배우는 길 | U1 기본 모음(ㅏㅓㅗㅜㅡㅣ) → U2 자음(ㄱㄴㄷㄹㅁ) → U3 자음(ㅂㅅㅇㅈㅎ) → U4 모음(ㅑㅕㅛㅠㅐㅔ). 22글자. 앞 단원 글자를 다 만나야 다음 단원 새 글자가 나온다. U5~U10은 「준비 중」으로 길에만 보인다 |
| 만나기 카드 | 새 글자가 크게 놓이고 소리가 두 번 난다. 손가락으로 따라 쓰면 실이 놓이고 손을 떼면 매듭이 진다(판정하지 않는다). 그 글자가 든 음절·낱말을 눌러 듣는다. ㅇ은 「첫소리에서 소리가 없다」, ㅐ·ㅔ는 「소리가 같다」를 짚는다 |
| 문항 꼴 넷 | 듣고 고르기 · 보고 고르기(보기를 눌러 듣고 확인) · 음절 만들기(U2부터, 조각을 고르면 글자가 합쳐져 보인다) · 짝 맞추기(소리 카드 ↔ 글자 카드). 2단부터 다 만난 낱말(나무·바다·우유…)이 회차에 두 번까지 섞인다 |
| 시범 | 꼴마다 처음 한 번, 몽글의 손가락(펠트 원)이 소리를 누르고 맞는 것을 고른다. 그 문항은 도움받은 문항으로 남는다. 움직임 줄이기에서는 손가락 없이 차례로 테두리만 보인다 |
| 오늘의 묶음(Core) | 헷갈린 짝·복습할 때가 된 글자 → 새 글자 0~3개(최근 스무 문항의 혼자 맞힌 비율로) → 섞어 연습. 난이도 1~3단(보기 2·3·4개, 닮은 글자·헷갈리는 짝)은 이어서 두 회차 순조로우면 오르고 막히면 내린다. 같은 꼴은 세 번 넘게 이어지지 않는다. 같은 날·같은 회차는 같은 문항(결정적 시드) |
| 틀렸을 때 | 실패음 없이 맞는 것을 보여 주고 고른 소리 → 맞는 소리를 들려준다. 그 글자는 두 칸 뒤에 다른 꼴로 한 번 더 나온다(회차에 두 번까지). 소리 문항을 이어서 두 번 틀리면 「천천히 듣기」를 한 번 권한다(받아들이면 도움받은 문항) |
| 익힘 | 서로 다른 두 회차에 걸쳐 도움 없이 이어서 세 번 맞히면 「익힘」. 틀리면 「익히는 중」으로 돌아가고 다시 만날 때가 당겨진다. 다음 복습은 0·1·2·4·8·16일 |
| 보이는 진도 | 한글 길(단원 표지 열), 글자 상자(만남 크림 · 익히는 중 코랄 글씨 · 익힘 코랄 펠트), 마을 간판 넷(오이·나무·바다·가게 — 글자를 다 익히면 또렷해지고 눌러 듣는다), 「한국어」 명패(받침 칸은 받침 단원에서). 보이는 것은 닿은 가장 높은 상태라 줄지 않는다 |
| 회차 | 5·10·15문제(기본 10, 2~4분). 하루 첫 회차 + 「한 번 더」 두 번. 「한글을 읽을 수 있어요」로 건너뛸 수 있고 언제든 돌아온다 |
| 없는 것 | 점수·등수·연속 기록·목숨·시간 제한·재촉 알림·실패음 |

## 아틀라스 연결

- **Strata 한글 층:** [strata/hangul.json](../../strata/hangul.json)(글자·단원·헷갈리는 짝·닮은 모양)을 [tools/build-hangul-stage.js](../../tools/build-hangul-stage.js)가 [strata/maps/hangul.json](../../strata/maps/hangul.json)으로 만든다. 글자 22개는 `letter` 마디, 단원 순서는 `prerequisite`, 짝은 `contrasts_with`(소리·모양, `by_ear`)다. 능력은 `ko.hangul.sound`(듣기)·`ko.hangul.read`(읽기) 둘이다. 같은 도구가 이 지도와 기존 Atlas 게임 어댑터를 묶어 `atlas-learning.js`를 만든다([learning-entry.cjs](learning-entry.cjs)).
- **기록:** 문항 하나 = 아틀라스 문항 하나(`present → delivery → help → answer`, [learning.mjs](learning.mjs)). 다른 게임과 같은 학습 기록(`synk.atlas.learning.v1.*`)에 남고, WORLD 계정 호스트 안에서 열면 그 계정 기록으로 동기화된다. 소리가 끝까지 난 뒤의 답만 소리 문항의 근거가 되고, 다시 듣기·천천히 듣기·시범은 도움으로 남는다. 짝 맞추기는 짝 하나가 문항 하나다.
- **글자 진도는 따로 둔다:** 아틀라스의 증거 규칙은 문항 묶음의 첫 시도를 세는데, 글자 익히기는 같은 글자를 되풀이하는 일이라 글자별 상태·다음 복습은 이 경험의 판단([core.mjs](core.mjs))으로 둔다. 혼자 열면 이 기기(`synk.hangul-stage.v1`), WORLD 안에서는 그 계정·학습 동의 판의 구역(`synk.account.{id}.r{revision}.hangul-stage.v1`, WORLD 저장소와 같은 접두)이다. 계정을 알 수 없으면 저장하지 않는다. 기기를 넘는 글자 진도 동기화는 아직 없다(아래 남은 일).
- AI·서버 호출은 없다. 사용자 수에 비례해 드는 비용이 없다.

## 소리

2026-09-19 결정은 「글자 소리는 정한 목소리 하나만, 귀로 확인한 파일만」이다. **10-03 목소리는 Typecast로 정했다**(유호님 「다이브 말고 타입캐스트로 바꿨어」 — Typecast API Lite가 결제돼 있다. DIVE는 결제 기록이 없다). 쓸 목소리 하나는 추천 서현이고 유호님 확인 전이다.

- **만들기:** `node tools/한글단계_목소리.cjs`(목소리를 바꾸려면 `--voice tc_… --name 이름`) → http://127.0.0.1:5241 에서 유호님이 기존 Typecast API 키를 붙여 넣는다(키는 메모리에만 2시간, 결제·충전 기능 없음). 그 뒤 이 컴퓨터의 명령으로 `POST /generate {"sample":true}`가 8개를 만들어 한 개당 크레딧 쓰임을 재고, `{"all":true}`가 [pack.mjs](pack.mjs)의 `audioManifest()` 목록(165개 · 214자: 글자 소리·음절·낱말·간판·명패)의 나머지를 만든다. 어림 쓰임이 남은 월 크레딧의 10%를 넘으면 멈추고 묻는다. 감정 normal·빠르기 0.9·ssfm-v30, 앞뒤 무음을 걷은 64k mp3가 `assets/voice/`에, 원본 wav는 저장소 밖 `Documents/synk-vendor/hangul-voice/raw`에 남는다.
- **확인과 승인:** 만든 목록은 `assets/voice/voices.candidate.json`이다. 유호님이 [voice-check.html](voice-check.html)(글자 22 · 음절 표 120 · 낱말)에서 귀로 확인한 뒤 `node tools/한글단계_목소리.cjs --approve "유호님 10-0X 귀 확인"`으로 [voices.json](assets/voice/voices.json)에 옮긴다. 앱은 `approved: true`인 목록만 먼저 튼다.
- 그전과 목록에 없는 소리는 기기의 한국어 음성(브라우저 `speechSynthesis`, 기기 안 음성 우선)으로 낸다. 기기마다 목소리가 달라 들리는 소리가 다를 수 있다. 한국어 음성도 승인된 파일도 없는 기기는 시작 단추를 잠그고 안내한다.

- 2026-10-03 이 PC의 「Microsoft Heami」 실측: 첫 소리는 엔진이 깨는 데 2.1초, 그다음은 0.03~0.13초 뒤 시작. 그래서 「시작」을 누를 때 소리 없이 한 번 깨워 둔다. 사람 귀로 ㅓ/ㅗ·ㅜ/ㅡ가 분명히 갈리는지는 아직 확인하지 않았다(설계 §10 「귀로 확인한 파일만」은 목소리가 정해진 뒤의 일).
- 효과음은 [브랜드 사운드킷](../../docs/브랜드_사운드킷/_사운드킷.md) 그대로다(맞힘 `earn`, 회차 끝 `achieve`). 실패음은 없다.

## 화면 자산

[펠트 부품](../../docs/디자인/펠트부품/README.md)의 실제 펠트(입장 검사의 줄이고 흰 띠를 걷은 사본)만 쓰고, 글자는 굽지 않고 화면 글자(SUIT)로 얹는다. 몽글 컷·글꼴·효과음도 바이트 그대로의 사본이다. 출처와 해시는 [assets/provenance.json](assets/provenance.json). 원본 키트를 고치면 이 사본도 맞춘다. 설계 §10의 「GPT 이미지 2.5로 구운 글자 타일·자수 네 상태·퀼트」는 이 판에 없다 — 자수 상태는 펠트 원의 색(크림 → 코랄 글씨 → 코랄 펠트 + 체크)으로 대신한다.
