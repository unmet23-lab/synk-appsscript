# 한글 단계 노래 — 가사와 Suno 프롬프트

2026-10-04 유호님: 「suno 노래로 확정하고 노래 분위기는 케이팝풍으로 하자. 그리고 노래는 니가 프롬프트 짜서 직접 제작해줘」, 조사 뒤 「그 조합으로 진행해줘」. 근거와 조합은 [학습 방식 조사](../../../docs/한글단계_학습방식_조사_20261004.md)다.

**노래의 역할:** 순서만 외우는 노래가 아니라 글자마다 소리·동작이 붙은 노래다. 처음 온 사람의 입구, 회차 끝 복습·보상, SNS 1분 공유에 쓴다. 실제로 읽게 만드는 것은 앱의 연습(소리-글자 짝·음절 만들기·간격 복습)이다.

- 모음은 몸동작으로 외운다(한글 성인 초급 연구: 모음은 몸동작, 자음은 그림 연상이 가장 잘 배움). 짧은 획이 가리키는 쪽으로 손을 뻗는다. 말이 필요 없어 20개국에 통한다.
- 자음은 합치기로 외운다(찬찬한글의 「그~아 → 가」). 후렴은 누구나 아는 「가나다라마바사」.
- 영어 단어 연상(ㄱ=gun)은 쓰지 않는다.
- 만드는 곳: Suno Premier, 모델 v6, 고급 모드. 앱·게임에 쓸 곡은 Suno 공식 내려받기로 받는다(약관 2026-09-03 시행, [음악 장부](../../../docs/음악자산_장부.md)). 화면에 AI 도구 이름을 쓰지 않는다.

## 2. 그 아 가

자음 소리 + 아 = 음절. ㅇ은 첫소리에서 소리가 없어 「쉿! 아!」다. 둘째 절은 같은 자음에 모음을 바꿔 붙인다(가 거 고 구 그 기 — 모음 댄스와 이어진다).

**스타일:**

```
K-pop dance-pop with rap chant, girl group, cool and playful, call-and-response, crisp clear Korean diction, one syllable per beat, synth brass stabs, claps, 100 BPM, catchy hook
```

**빼는 스타일:** `children's choir, nursery rhyme, ballad, slow`

**가사:**

```
[Intro]
Ready? 한글!
그, 아, 가!

[Verse 1]

드 아 다! 르 아 라!

프 아 파! 흐 아 하!

[Pre-Chorus]

[Chorus]

[Verse 2]

[Outro]
```
