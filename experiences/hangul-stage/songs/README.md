# 한글 단계 노래 — 가사와 Suno 프롬프트

2026-10-04 유호님: 「suno 노래로 확정하고 노래 분위기는 케이팝풍으로 하자. 그리고 노래는 니가 프롬프트 짜서 직접 제작해줘」, 조사 뒤 「그 조합으로 진행해줘」. 근거와 조합은 [학습 방식 조사](../../../docs/한글단계_학습방식_조사_20261004.md)다.

**노래의 역할:** 순서만 외우는 노래가 아니라 글자마다 소리·동작이 붙은 노래다. 처음 온 사람의 입구, 회차 끝 복습·보상, SNS 1분 공유에 쓴다. 실제로 읽게 만드는 것은 앱의 연습(소리-글자 짝·음절 만들기·간격 복습)이다.

- 모음은 짧은 획이 가리키는 쪽으로 손을 뻗는 몸동작, 자음은 그림 연상을 채택했다. 연결된 연구의 대상·과제에서 얻은 근거이며 모든 학습자에게 가장 좋거나 출시국 전체에서 효과가 확인됐다는 뜻은 아니다. 언어 설명을 줄일 수 있는지 실제 초보자 반응으로 확인한다.
- 자음은 합치기로 외운다(찬찬한글의 「그~아 → 가」). 후렴은 누구나 아는 「가나다라마바사」.
- 영어 단어 연상(ㄱ=gun)은 쓰지 않는다.
- 당시 제작 경로: Suno Premier, 모델 v6, 고급 모드. 앱·게임에 쓸 곡은 Suno 공식 내려받기로 받았다(당시 약관 2026-09-03 시행, [음악 장부](../../../docs/음악자산_장부.md)). 새 제작의 요금제·모델·이용 조건은 실행 시 확인하며, 아래 후보·가사·다운로드 수는 제작 이력이다. 화면에 AI 도구 이름을 쓰지 않는다.
- **새 노래·영상은 [노래 영상 가이드](노래영상_가이드.md)를 단계마다 통과시킨다**(10-08 [근거 점검](../../../docs/한글단계_노래영상_근거점검_20261008.md)). 노래 속도에서 원어민 귀에도 갈리지 않는 소리 구별(가·카·까, 받침 ㄱ·ㄷ·ㅂ)은 노래로 만들지 않고 앱의 「여러 목소리로 듣고 고르기」에 맡긴다 — 10-08 받침 둘 노래 후보 넷을 듣고 유호님 「발음이 빨라서 나도 잘 모르겠어」.

## 2. 그 아 가

자음 소리 + 아 = 음절. ㅇ은 첫소리에서 소리가 없어 「쉿! 아!」다. 둘째 절은 같은 자음에 모음을 바꿔 붙인다(가 거 고 구 그 기 — 모음 댄스와 이어진다).

**10-09 v4 — 떠올리기 쉼:** 「그 더하기 아는?」·「느 더하기 아는?」 뒤에 반주만 흐르는 한 마디(2.4초)씩을 끼웠다. 원곡은 물음 뒤 0.3초 만에 답을 불러 생각할 틈이 없었다(겹모음 댄스에서 유호님 「와가 0.1초만에 지나가는데 조금 0.5초는 있어야」 → [노래 영상 가이드](노래영상_가이드.md)의 떠올리기). 앱과 영상 v4가 같은 소리다(85.96초, 원본·스크립트 `Documents/synk-vendor/hangul-songs/geu-a-ga-v4-20261009/`). 앱은 쉼 동안 결과 칸과 가사 줄의 답을 「?」로 둔다.

**10-08 v2 — 줄마다 8음절:** 옛 곡은 후렴 한 줄(7음절)을 한 마디 8박에 맞추느라 Suno가 「가나다라마바바사」「아자차카타타파파하」처럼 음절을 두 번 불렀다. 유호님 「초보들이 이걸 보면 헷갈릴거야」 → 후렴 끝에 「짝!」, 둘째 절 끝에 「짝 짝!」을 넣어 줄마다 8음절로 맞추고(영상의 손뼉과도 이어진다) 다시 만들었다.

## 3. 받침 노래

받침 하나(ㄴ·ㄹ·ㅁ·ㅇ, 앱 6단원). 받침 소리는 「은·을·음·응」으로 부른다(아 + 은 → 안 — 받침 일곱 소리를 「윽 은 읃 을 음 읍 응」으로 가르치는 방식). 1절은 아에 받침을 붙이고(안 알 암 앙), 이어서 진짜 낱말(산 물 밤 강)을 만든다. 「위에선 쉿! 밑에선 응!」은 그 아 가의 「쉿!」(첫소리 ㅇ은 소리 없음)과 받침 ㅇ(응)을 견준다. 후렴 낱말은 모두 6단원 낱말이고 손·별·곰·공은 받침 카드 그림과 같다. 2절은 후렴 낱말을 합치기로 만든다.

## 4. 겹모음 댄스

겹모음(앱 9단원) 가운데 모양과 소리가 맞는 넷 — 오 + 아 = 와, 우 + 어 = 워, 우 + 이 = 위, 으 + 이 = 의. 2절은 자음이 붙어도 같은 합치기다(고 + 아 = 과, 구 + 이 = 귀, 주 + 이 = 쥐, 무 + 어 = 뭐). 소리가 같은 ㅚ·ㅙ·ㅞ와 ㅒ·ㅖ는 노래에 넣지 않았다(앱의 만나기 카드가 「소리가 같아요」로 짚는다). [노래 영상 가이드](노래영상_가이드.md)를 처음 적용한 곡이라 새 음절은 두 박에 셋까지, 후렴은 한 박에 한 음절, 떠올리기(물음 → 쉼 → 답)가 두 곳이다.

## 5. 첫 인사

한글 초보단계 다섯째이자 마무리 편(앱 10단원 「낱말에서 문장으로」). 앞 네 곡에서 배운 글자만으로 처음 「말」을 읽는다 — 원리는 「한 칸씩 읽고 이으면 말이 된다」. 10-10 유호님 「지금은 초보자들 한글 하나도 모르는 사람들을 위한 것들을 만들어야하니까 이런거 잘 체크해서 준비해줘」.

- **글자 검사(`.tmp/hangul-mascot-video-20261006/greeting/check_lyrics.py`):** 음절마다 첫소리(자음 14) · 모음(10 + ㅘㅝㅟㅢ) · 받침(ㄴㄹㅁㅇ)이 배운 것인지, 이어 부를 때 소리가 바뀌는지(연음 · ㅎ 약해짐 · 비음화 · 된소리 · 구개음화)를 기계로 본다. 가사 152음절 문제 0.
- **일부러 뺀 말:** 안녕하세요 · 안녕히 가세요 · 네(ㅔ), 미안해요 · 사랑해요(ㅐ), 감사합니다 · 고맙습니다(받침 ㅂ + [함니다]), 저는 몽글이에요 · 이름이 뭐예요(ㅔ·ㅖ + 연음), 좋아요 · 괜찮아요 · 또 만나요(받침 ㅎ · ㅙ · ㄸ), 천천히 · 글자(이어 부르면 [천처니] · [글짜]).
- **화면 글자도 배운 글자만:** 말풍선은 「이어 봐요!」 · 「뭐지?」 · 「저는 몽글!」(앞 네 곡의 「따라 해요!」에는 ㄸ · ㅐ), 끝 화면 제목은 「이건 뭐?」(앞 네 곡의 「읽어 볼까요?」에는 ㄺ · ㄲ). 위 이름표 「한글 단계」의 계(ㅖ)는 시리즈 이름이라 그대로.
- 「안녕」은 친구 사이 말이라 유튜브 판 뜻 알약에 「hi! (to friends)」로 적는다. 안녕하세요는 ㅐ · ㅔ(모양은 달라도 같은 [에])를 배운 뒤에.

## 6. 애 에

한글 초보단계 여섯째(앱 4단원에서 노래가 없던 ㅐ · ㅔ). 원리 하나는 「ㅐ와 ㅔ는 모양만 다르고 소리는 둘 다 [에]」다 — 「모양만 달라, 둘 다 에!」. 「아 + 이 = 애」로는 부르지 않는다(가이드 1 — 모양은 ㅏ + ㅣ지만 소리는 [에]). 화면은 ㅏ · ㅓ 옆에 기둥(ㅣ)이 붙는 모습만 보이고, 소리가 같다는 것은 같은 인형 동작(귀 뒤에 두 손 「들어 봐」)과 두 칸을 하나로 모으는 괄호로 보인다.

- 10-10 v1 「기둥 둘」 가사를 보고 유호님 「기둥 둘이라는게 좀 어색한데? 가사를 다시 써줘 기둥이 뭐야 ㅜㅜ」 → v2 「모양만 달라, 둘 다 에!」에 「웅 이 가사로 Suno 후보 만들어줘」.
