  - 컴퓨터 1440×900 · 휴대폰 390×844(DPR 2, 터치) · 작은 휴대폰 320×568(DPR 2, 터치) · 움직임 줄이기 1280×800.

  - 입구 시작 단추·게임 조작부(서빙·멈춤·재료·컵 탭·말풍선·작업대)가 네 화면 모두 첫 화면 안, 가로 넘침·휴대폰 축소 없음.

  - 작은 휴대폰 장면 이어서 소리 끔: 주문을 처음부터 글로 보여 주고(글 도움, 평가하지 않음) 다시 듣기를 숨김, 멈춤 창에서 소리를 켜면 다시 듣기가 돌아옴, 그만둔 판은 코인 없음.
- `SYNK_QA_BASE=http://127.0.0.1:5241 node experiences/order-rush/qa/atlas-flow-smoke.cjs`(새 선택자로 맞춤) — 통과. 빨리 맞히는 사람은 「조금 더 까다로운 주문도 들어와요.」→「손님이 조금 더 바빠져요.」(기다리는 시간 42 → 36초), 손님을 놓치는 사람은 「손님이 조금 더 여유 있게 기다려요.」, 정해진 속도는 42·10·3 그대로, 「피곤해요」를 고른 날은 바빠지지 않음. 이 확인 도구는 손님이 없을 때 다음 손님(영업 시간 10초 뒤)과 주문(3~6초)을 15초까지만 기다려 끝까지 듣기 전에 서빙하는 일이 있었다 → 30초로 늘렸다.
- `RUSH_URL=http://127.0.0.1:5241/order-rush/ node experiences/order-rush/qa/verify-assets.mjs` — 합성 음성 15개, 키트·손님·재료·쿠션 그림, 모듈 구문 통과.
- 단위 시험 `node --test experiences/order-rush/*.test.mjs`(파일을 하나씩 적어서) — 30개 통과(새 `cafe.test.mjs` 2개 포함). `node --test experiences/play-common/kit.test.mjs` 통과(kit 사본은 원본과 같다).
- 따로 본 것: WebGL을 끈 크롬에서 평면 작업대(`FlatStage`)로 바뀌고 컵 고르기가 되는 것, 소리 장치가 멈춘 척(첫 재생이 소리 없이 끝나지 않음)하면 끝 신호 지킴이 9.5초 뒤 「소리를 재생하지 못했어요」로 넘기고 다시 듣기로 첫 듣기를 마치는 것, 주문이 막 시작될 때 멈춤 창을 열어도 재생 실패로 잘못 넘기지 않는 것(고치기 전 6번 중 2번 → 고친 뒤 0번, 옛 판에도 있던 경합).

범위: 헤드리스 크롬의 가짜 소리 장치·터치 흉내로 본 것이다. 실제 휴대폰의 터치·성능·소리, 사람이 듣는 음질, 학생 학습 효과는 확인하지 않았다.

## 실제 플레이

- IAB에서 한국어 주문의 재생 중/재생 완료 상태, 커피·차·라테·얼음·설탕·온도 조작과 컵 추가/제거를 확인했습니다. WebGL 작업대 렌더링과 액체·얼음의 상태 변화가 실제로 표시됐습니다.
- 한가한 오픈 8개를 실제 버튼으로 완료했습니다. 첫 주문을 일부러 틀린 뒤 수정했으며, 여섯 번째 주문에 글로 보기를 사용했습니다. 결과는 서빙 8개, 1,130점, 첫 제출 88% (7/8), 글로 확인 1/8, 미응답 0입니다. 이 수치는 제작자의 기능 확인 기록이며 학생 학습 결과가 아닙니다.
- 새 주문 연습 3개를 완료했습니다. ‘대신’, ‘한 잔만 설탕’, ‘둘 다 얼음 없이’를 서로 다른 조합으로 만들었습니다. 결과는 서빙 3개, 360점, 첫 제출 100%, 글로 확인 0/3입니다.
- 러시 모드에서 주문 대기 2명과 3명, 선택 변경 시 따뜻한 라테 제작 상태 보존, 첫 주문 서빙과 영업 조기 종료를 확인했습니다. 결과는 서빙 1개·110점, 글로 확인 1/1, 미응답 3입니다.
- 일시 정지 전후 66s가 유지됐고 재개 후 시간이 다시 흘렀습니다. 서빙 성공 표시 중에도 정지·재개하여 다음 손님으로 이어지는 것을 확인했습니다. 키보드 1·4·Q·Backspace·Space와 버튼 입력을 확인했습니다.

## 범위

합성 주문 음성의 파일·재생 상태를 확인했으며, 사람의 직접 청취에 의한 자연스러움·발음 평가는 하지 않았습니다. 실제 학생의 듣기 향상·다음 날 기억·TOPIK 성적 개선·실물 휴대폰의 터치/지속 성능은 미검증입니다. WebGL을 쓸 수 없을 때의 평면 화면은 구현됐지만 별도 장치에서 재현하지 않았습니다. 학생 데이터와 음성 녹음은 저장하지 않습니다.
