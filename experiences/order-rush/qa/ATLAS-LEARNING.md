# 주문 폭주 Atlas 연결 확인

2026-10-02 로컬 소스 기준. 실제 학생의 효과·시험 준비도 검증과 공개 배포는 포함하지 않는다.

- `core.test.mjs`와 `learning.test.mjs` 16개 통과. 공통 API로 부정 이해의 오답 근거를 만들었을 때 실제 다음 주문이 `o03`으로 바뀌며, 한가한 오픈의 8개 주문·수정 후 서빙·별도 복습 3개를 유지한다.
- 첫 오답 뒤 힌트와 수정 정답은 첫 관측을 덮어쓰지 않는다. 글 도움·음성 미완료/실패는 새로운 독립 성공으로 집계하지 않는다. 결과 화면에서 보이는 주문 전문과 펼친 정답도 도움으로 기록한다.
- 문항과 후보 모두 `cup-compose` 형식을 명시한다. 공통 `atlas-formats.test.js`에서 O/X 성공·오답을 다른 응답 형식에 옮기지 않고, 난도 준비와 근거 스냅샷도 같은 형식만 사용하는지 확인했다. 형식 미지정 이력은 `unknown`으로 보존한다.
- `node experiences/order-rush/qa/atlas-smoke.cjs`: 신규 Chromium 테스트 컨텍스트에서 공용 서버 `http://127.0.0.1:4280`의 주문 폭주→바람길 이동을 검증했다. 사용자 프로필을 사용하지 않았다.
- 주문 음성의 실제 종료 이벤트를 기다린 첫 정답은 독립 근거 1개. 다음 주문에서 글 도움을 쓴 뒤에도 1개. 새로고침 뒤 1개. 바람길로 이동해도 1개이며 바람길의 행동 결과는 평가 제외로 추가된다.
- 1280×900, 390×844 화면 캡처 및 모바일 가로 넘침 없음, 페이지 JavaScript 오류 없음. `atlas-smoke.json`과 `atlas-cafe-*.png`에 결과를 보존한다.

이 확인은 음성 파일 재생 종료·UI·저장 연결의 증거다. 사람이 직접 들은 음질·학생의 언어 이해·다른 기기 동기화는 별도다.
