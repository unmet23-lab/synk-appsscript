# 바람길 v5 · 바람상점 검증

2026-10-02 · 로컬 http://127.0.0.1:4273/ · Codex in-app browser. 사용자 요청한 다섯 종류를 실제 구매·장착·3D 장면에 연결했다. 기존 듣기·Atlas·공통 차고 연결은 보존했다.

## 제공 범위

- 달리기 자취: 꽃잎, 별빛, 폭신 발자국.
- 등불 꾸미기: 꽃등, 반딧불 등불. 부탁 표시선과 성공 등불도 장착한 모양을 사용한다.
- 동행 친구: 작은 참새, 아기 구름.
- 코스 풍경: 벚꽃길, 눈꽃 마을, 달빛 축제. 장애물 판정과 코스 구성은 같다.
- 완주 연출: 꽃비 인사, 별빛 포즈, 축제의 밤. 결과를 열기 전에 1.9초, 동작 감소 설정에서는 0.8초 동안 연출을 보여준다.

구매 상품 13개와 무료 기본 5개. 미리보기는 무료이며, 구매하면 해당 종류를 바로 장착한다. 다른 종류의 장착은 유지한다. 상점을 닫으면 미구매 미리보기 대신 저장한 장착을 적용한다.

첫 저장에 환영 별 60개, 직접 달리며 수집한 별과 90초 완주 보너스 20별을 지급한다. 중간에 처음 화면으로 돌아와도 수집한 별을 정산한다. 같은 회차는 한 번만 정산하고 자동 시연에는 지급하지 않는다. 금전 결제는 연결하지 않았다. `synk.windrun.shop.v1`의 바람길 별은 기존 공통 차고 코인과 별도다.

## 자동 검사

저장소에서 다음 검사를 실행해 **37개 통과**했다.

```powershell
node --test experiences/korean-runner/core.test.mjs experiences/korean-runner/controls.test.mjs experiences/korean-runner/audio.test.mjs experiences/korean-runner/learning.test.mjs experiences/korean-runner/shop.test.mjs experiences/korean-runner/world-cosmetics.test.mjs
node tools/build-game-learning.js --check
```

기존 이동·물리·부정·순서·음성·Atlas 연결 24검사, 환영 별·구매·중복 구매·부족한 잔액·저장 실패 롤백·정산 중복·시연 제외·손상 저장 10검사, 실제 장식 메시·고정 입자 수·플레이 상태 불변 3검사다. `app.js`, `shop-ui.mjs`, `world.mjs` 문법도 통과했다. Node가 기존 Three.js ES 모듈에 내는 패키지 형식 경고는 시험 실패나 브라우저 오류가 아니다.

44개 신규 이미지/모듈 및 기존 연결 번들의 HTTP 200·파일 바이트 일치: [v5-http.json](v5-http.json). 이미지 36개는 승인 펠트 부품의 UI 파생 18개와 새 상품 아이콘 18개다. 아이콘은 builtin imagegen으로 생성했으며 도구가 정확한 모델명은 반환하지 않았다. 원본·프롬프트·변환·해시는 `assets/shop/manifest.json`과 `assets/shop/source/`에 보존한다. 원본을 덮어쓰지 않았고 전달 ZIP에는 런타임 파생 이미지를 넣는다.

## 실제 브라우저 확인

- 첫 진입 60별 → 꽃잎 자취 35별 구매 → 25별과 장착 상태가 새로고침 뒤 유지됨. 구매 전 미리보기·13개 상품 선택은 잔액을 변경하지 않음. 부족한 잔액에서는 구매 버튼을 끄고 필요한 별 수를 표시함.
- 직접 달리기: 중단 시 수집 4별 → 25에서 29별로 한 번 적립. 상점을 열고 닫아도 29별 유지. [v5-partial-reward.json](v5-partial-reward.json).
- 다섯 종류의 복합 장착 검사는 임시 QA 잔액 1000별을 사용해 실제 UI로 별빛 자취·반딧불 등불·참새·달빛 축제·축제의 밤을 구매했다. 합계 395별을 차감해 605별. 자동 시연 완주 뒤에도 605별 유지. 테스트 구매/잔액은 종료 후 원래 환영 별 60개·무료 기본 장착 상태로 복구했고 최종 화면은 참새의 무료 미리보기다. [v5-final-state.json](v5-final-state.json).
- 실제 90초 시연: 90.0012초, 1392m, 부탁 10/10, 표시선 13, 보호 3. 다섯 장식을 함께 적용한 상태에서 음성 16개 준비·수행·이동·생존 진행 확인. 시연은 정답과 동작을 알고 움직이므로 사람의 직접 완주나 학습 효과 증거가 아니다. [v5-demo-complete.json](v5-demo-complete.json).
- 실제 코스에서 자취 입자, 참새, 선택한 표시선 등불과 성공 등불을 확인. 종료 첫 프레임에 `finishVisible=true`, 결과 창 없이 꽃 모양·등불의 축제 연출이 보인 뒤 결과가 열림. [완주 장면](v5-finish-celebration.jpg), [실행 장면](v5-run-cosmetics.jpg).
- 결과 → 상점 → 닫기에서 결과 화면으로 복귀. 카드·종류 선택 후 키보드 초점 유지, Shift+Tab이 상점 안의 마지막 활성 버튼으로 순환, Esc로 닫은 뒤 진입 버튼에 초점 복귀.
- 1280×720, 390×844, 320×668, 844×390 확인. 세로 화면에서는 미리보기 영역을 200px/155px로 확보하고 몽글·친구·등불을 설명과 단추 위에 맞췄다. 상품 목록만 스크롤하며 구매 버튼은 화면 안에 남는다. 가로 결과에서 상점 단추가 잘리던 배치를 수정해 복습·재시작·홈·상점이 모두 보인다.
- 최종 이미지 로딩 실패 0, 브라우저 오류/경고 0. 임시 viewport 설정을 해제했다. 로컬 v5 상점 탭을 사용자 결과로 남겼다.

## 전달과 확인 경계

새 `experiences/korean-runner-play-20261002-v5-shop.zip`을 만든다. [v5-package.json](v5-package.json)에 CRC·현재 소스와 모든 ZIP 항목의 바이트 대조 결과를 남긴다. 기존 v1~v4 전달물을 보존한다. 게임 런타임은 번들로 자립하며 `learning.test.mjs`의 공통 엔진 검사는 저장소에서 실행한다.

꾸미기는 학습·속도·판정·음성 난도를 바꾸지 않는다. TOPIK 연결은 기존 짧은 지시 듣기(방향·동작·부정·순서) 보조 연습이다. 학생 효과·실제 휴대폰 성능·계정/서버 동기화·공개 배포·금전 결제는 이번 로컬 확인에 포함하지 않는다.
