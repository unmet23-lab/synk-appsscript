# 바람길 Atlas 연결 확인

2026-10-02 로컬 소스 기준. 기존 v4 액션 검증은 `LISTENING-V4.md`에 둔다.

- `core.test.mjs`, `controls.test.mjs`, `audio.test.mjs`, `learning.test.mjs` 24개 통과. 공통 추천이 실제 생성되는 부탁을 바꾸며, 16개 지시의 동작·부정·순서와 기존 액션·타이밍·90초 시연을 유지한다.
- 시각 단서로 수행한 성공과 조작 타이밍 실패는 모두 언어 평가 제외. 실제 공통 API로도 독립 근거를 올리지 않는다. 음성 완료는 Web Audio의 실제 종료 이벤트로 기록한다.
- 문항과 후보 모두 `action` 형식을 명시한다. 현재 추천은 노출 이력으로 지시 순서를 조정하는 범위다. O/X·객관식·컵 조합의 정오답으로 바람길의 능력 약점을 확정하지 않으며, 바람길 행동도 독립 능력 근거가 되지 않는다.
- 주문 폭주의 `qa/atlas-smoke.cjs`를 공용 서버 `http://127.0.0.1:4280`에서 실행했다. 신규 Chromium 테스트 컨텍스트에서 주문 폭주의 독립 근거 1개를 만든 뒤 바람길로 이동해도 1개가 유지되며, 바람길 행동은 평가 제외 1개로 추가된다.
- 위 독립 근거 1개는 주문 폭주의 `cup-compose` 관측이 보존된 것이다. 이를 바람길의 `action` 형식에 옮겨 능력이 확인되었다고 해석하지 않는다. 공통의 `atlas-formats.test.js`는 형식 사이 정오답·난도준비가 전이되지 않는지 별도로 확인한다.
- 1280×900, 390×844 화면 캡처 및 모바일 가로 넘침 없음, 페이지 JavaScript 오류 없음. `atlas-runner-*.png`에 화면을 보존하며 수치 기록은 주문 폭주의 `qa/atlas-smoke.json`에 둔다.

다른 포트·기기에는 자동 연결되지 않는다. 학생 계정·공개 배포·학습 효과·시험 준비도 검증은 완료한 것으로 주장하지 않는다.
