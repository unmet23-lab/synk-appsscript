# 바람길 v6 · 실제 휴대폰 확인 절차

2026-10-02 · **실제 휴대폰 플레이·청취·성능은 미검증이다.** PC 브라우저의 작은 화면 확인과 엔진 시뮬레이션은 실기기 검증을 대신하지 않는다. 기기와 브라우저를 확인한 뒤 아래 절차로 직접 점검한다.

## 같은 Wi-Fi에서 열기

1. PC와 휴대폰을 같은 Wi-Fi/로컬 네트워크에 연결한다. PC에는 Node.js가 필요하다.
2. 같은 포트로 실행 중인 기존 서버를 종료하고 저장소에서 실행한다.

   ```powershell
   node experiences/korean-runner/server.mjs --lan
   ```

   전달 ZIP은 압축을 풀고 `korean-runner` 폴더에서 `node server.mjs --lan`을 실행한다. 서버 터미널은 켜 둔다.
3. 터미널의 **‘같은 Wi-Fi 휴대폰: http://PC주소:4273’** 주소를 휴대폰 브라우저에서 연다. 휴대폰의 `127.0.0.1`은 PC 주소가 아니다. 주소가 여러 개면 Wi-Fi/로컬 네트워크의 PC 주소를 선택한다.
4. 열리지 않으면 두 기기의 네트워크·서버 실행 상태·Node.js의 개인 네트워크 접근 허용을 확인한다. 포트가 겹치면 PowerShell에서 `$env:SYNK_RUNNER_PORT='4274'`를 지정하고 다시 실행한다.

기본 `node server.mjs`는 PC 내부 `127.0.0.1`에서만 열린다. `--lan`은 같은 네트워크에서 점검하기 위한 실행 옵션이다. 기기별 지갑·찜·목표·학습 기록은 별도이며 PC 기록과 동기화하지 않는다. 확인을 마치면 Ctrl+C로 서버를 종료한다.

## 직접 점검할 것

- **듣기:** ‘소리·동작 익히기’에서 지시를 직접 듣고, 플레이에서 배경음 때문에 목소리를 놓치는지 확인한다. 음소거·일시정지·다른 앱 전환 뒤 진행과 음성이 함께 멈추고 이어지는지 확인한다.
- **조작:** 좌우 스와이프와 네 터치 버튼을 각각 사용해 양 끝에서 가운데 복귀, 점프·숙이기 타이밍과 입력 지연을 확인한다. 자동 시연과 별도로 사람이 직접 달린다.
- **꾸미기·성능:** 자취·등불·친구·풍경·완주 연출을 함께 적용하고 벚꽃 터널·눈·축제 등불이 장애물과 표시선을 가리는지, 프레임이 끊기는지 확인한다. 균형 그래픽과 동작 감소도 비교한다.
- **상점·저장:** 찜·구매·장착, 구매 버튼의 잘림, 세로/가로 회전, 재접속 뒤 잔액·찜·목표 유지, 수집 별과 목표 보상의 한 번 지급을 확인한다.
- **재화의 체감:** 직접 플레이한 거리·수집 별·수행과 놓친 타이밍을 기록하고, 첫 구매 뒤 찜 상품까지 실제 몇 판 걸렸는지 확인한다. 이 기록으로 가격/목표를 검토하며 코드 전략을 초보자 기록으로 사용하지 않는다.
