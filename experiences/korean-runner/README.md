# 바람길 · SYNK LAB PLAY

2026-10-02 · v6 풍경·여행 목표 로컬 구현. 짧은 한국어 부탁을 **듣고 이동·점프·슬라이딩·가만히 달리기**로 수행하는 생존 액션 게임. 달리는 중에는 지시문·뜻·보기·다시 듣기 버튼을 표시하지 않는다. 글은 시작 전 표현 연습과 종료 후 복습에서 확인한다. 달리며 모은 별로 자취·등불·친구·풍경·마지막 인사를 꾸미고, 찜한 상품과 누적 여행 목표를 홈·결과 화면에서 확인한다.

2026-10-02 공통 목표: [TOPIK I 1~2급 준비](../../docs/미니게임_TOPIK_I_학습기준.md). 바람길은 짧은 지시의 방향·동작·부정·순서 이해를 듣기로 연습한다. 시각 단서·조작·타이밍이 수행에 영향을 주므로 생존과 부탁 성공을 공식 급수·합격 판정으로 사용하지 않는다.

**2026-10-02 소스 대조:** 현재 v6 `app.js`는 듣기 전용으로 시작하고 음성 실패 시 중지한다. 상점과 여행 목표는 꾸미기·수집 보상이며 학습·조작·생존 판정을 바꾸지 않는다. v3의 읽기 모드·음성 실패 시 읽기 전환 검증은 [이전 판의 이력](qa/REDESIGN-V3.md)으로 보존한다. 현재 읽기 추천 후보로 등록하지 않는다. 단독 실행은 브라우저 기기 기록을 사용한다. local-linked WORLD 안에서는 검증된 호스트의 학생별 기록·교사 과제 목표를 사용한다. 정식 SYNK ID·공개 배포·운영 학생 서비스 연결과 구분한다.

## 별도 듣기 확인과 교사 목표 (2026-10-02, 새 확인 문장 2026-10-03)

시작 전이나 달리기 결과에서 **듣기 확인**을 연다. 움직이는 코스와 장애물 없이 MP3를 끝까지 듣고, 들은 행동을 보기에서 고른다. 지시문·뜻은 답한 뒤 공개한다. 달리는 중에는 글을 읽거나 보기를 고르지 않는다. 실행 중에는 OS TTS를 쓰지 않고 미리 만든 MP3만 재생한다.

- 확인 문장 12개는 달리기에서 나오지 않는 새 문장이다(2026-10-03). 세부 4개(별이 있는 길·넓은 길·낮은 울타리·낮은 표지판), 부정 4개(가지 말고·뛰지 않아도 돼요·숙이지 않아도 돼요·가지 마세요), 순서 4개(숙인 다음 뛰어넘기·간 다음·뛰어넘기 전에·간 다음 그냥 달리기)다. 순서는 난도 2, 나머지는 난도 1의 자체 연습 분류다. 정답 자리는 첫째·둘째·셋째 보기에 고루 나뉜다.
- 음성은 달리기 지시와 같은 Windows 음성(Microsoft Heami Desktop)으로 만들었다. `assets/voice/jobs.json`에 문장을 적고 `scripts/build-voice.ps1` → `scripts/build-voice-manifest.py` 순서로 MP3와 목록을 만든다. 확인 음성은 서서 듣는 창에서 재생되므로 길이 상한이 8초이고, 달리기 간격을 정하는 `voice-timing.mjs`에는 들어가지 않는다. 열두 개 모두 로컬 Whisper(large-v3-turbo)로 받아 적어 문장과 글자 그대로 일치함을 확인했다. 사람의 직접 청취 검수는 아직이다.
- 각 확인은 자기 계열 `korean-runner.listening-check.<id>.v1`을 가진다. 달리기·연습에서 같은 문장을 들은 적이 없으므로 달린 뒤 푼 확인의 첫 응답도 독립 근거다. 문장의 TOPIK I 문형(`CHECK_GRAMMAR`: -(으)세요, -(으)니까, -지 않다, -아/어도 되다, -기 전에/-(으)ㄴ 후에)을 conceptIds로 남기고, 시험이 Strata `grammarIn`과 같게 지킨다. '-지 말다'는 Strata 문형 층에 없어 연결하지 않았다.
- `coach.assignment()`가 있으면 서버가 정한 영역·난도·응답 형식·문항/계열 목록 안에서만 최대 3개를 고른다. 자유 연습은 기존 Core 추천과 노출 기록을 사용해 최대 3개를 고르므로 첫 세 문항을 고정 반복하지 않는다.
- 음성 실패·중단 때는 끝까지 듣기 전까지 답을 막는다. 끝까지 들은 뒤의 재생만 재청취(도움)로 남기고, 그 재생이 탭 전환으로 끊겨도 답은 열려 있다. 불러오기에 실패한 뒤의 첫 재생은 도움이 아니라 첫 청취다. 들은 뒤 창을 닫으면 '응답 없음'으로 남긴다(2026-10-03). 조작 수행은 계속 평가 불가다.
- 2026-10-02판 확인은 달리기 지시 16개의 MP3를 다시 쓰고 그 계열(`korean-runner.<id>.v4`)을 나눠 썼다. 그래서 먼저 달린 뒤 푼 확인은 반복으로만 남았고, 10-03에 새 문장·새 음성·자기 계열로 바꿨다.

`listening-check.mjs`/`listening-check-ui.mjs`가 별도 이해 확인을 담당한다. 이는 기존 Atlas 학습 API의 재사용이며 별도 판단 엔진이 아니다. 과제 목표에 맞는 실제 답은 WORLD를 거쳐 교사 앱에 전달되지만, 게임이 보고한 응답으로 표시한다. 공식 TOPIK 채점·학생 학습효과 입증은 아니다.

현재 원문 검토와 순수 모델/목표 선정 시험을 마쳤다. 실제 Electron의 격리된 WORLD에서 듣기 세 영역 각 3문항(총 9문항)을 기존 MP3로 풀어 서버 목표와 교사 제출 결과를 대조했다. [Town과 함께 실행한 목표 UI 검증](../synk-town/qa/targeted-content-ui.json)은 50/50, [음성 실패·재청취 등 보완 검증](../synk-town/qa/linked-content-ui.json)은 14/14다. 실제 휴대폰·사람의 직접 청취 평가·교육 효과는 미검증이다.

## Atlas의 다음 부탁 선택

`learning.mjs`는 16개 부탁을 듣기 세부 정보·부정·행동 순서와 `action` 응답 형식에 연결한다. `RunnerModel`이 지시를 생성할 때 공통 `SynkLearning.recommend`의 선택을 실제 지시에 사용한다. 현재 바람길은 노출 이력에 따라 지시 순서를 조정하고 덜 만난 표현을 우선한다. 코스의 장애물을 만들기 위해 앞으로 나올 일부 지시는 미리 생성한다. 능력 약점을 진단해 다음 지시를 결정하는 기능으로 홍보하지 않는다.

같은 출처의 게임들은 공통 기록을 읽지만 추천 근거는 **능력·언어 난도·응답 형식이 모두 같은 관측**으로 한정한다. O/X·객관식·컵 조합의 정오답을 바람길의 `action` 형식 능력으로 옮기지 않는다. 바람길 행동 자체도 아래 이유로 독립 능력 근거를 만들지 못한다. 다른 포트에서 연 게임은 브라우저 저장 출처가 달라 기록을 공유하지 않는다.

장애물을 보고도 행동할 수 있고 타이밍이 결과에 영향을 주므로 **부탁 성공·실패는 모두 언어 평가 불가로 저장**한다. 조작 결과를 듣기 약점이나 숙달로 바꾸지 않는다. 음성 완료는 실제 재생 종료 이벤트로 기록하고, 소리·동작 익히기에서 공개한 뜻은 도움으로 남긴다. 자동 시연은 학습 기록에 넣지 않는다. 로그인한 학생의 진단이나 TOPIK 합격 준비도 평가는 아니다.

첫 화면과 결과 화면에 다음 연습의 이유를 표시한다. 그래픽 설정에서 ‘이 브라우저의 모든 게임 학습 기록 지우기’를 누르면 같은 출처에 저장된 공통 기록을 초기화한다. WORLD 안에서는 계정 기록이라 이 단추를 숨기고 WORLD 계정 설정을 안내한다. 최고 거리 기록은 별도로 유지한다. 저장을 사용할 수 없거나 엔진을 읽지 못하면 기본 플레이와 기록 불가 안내를 제공한다.

## 나에게 맞춘 바람 · Atlas 순간 맞춤 (2026-10-03)

달리기 속도만 그 사람에 맞춘다(`learning.mjs`의 `FLOW_RUN`, Core `flow.js`). 지시·장애물·학습 기록은 그대로다.

- 손잡이: 처음 달리는 속도(11·12·**13**·14·15)와 갈수록 빨라지는 정도(0·0.025·0.04·**0.055**·0.07). 굵은 값이 원래 게임이고, 처음 오는 사람은 정확히 거기서 시작한다. 최고 속도 19는 그대로라 가장 빠른 설정에서도 지시 음성이 첫 동작 전에 끝난다.
- 엔진에 넘기는 것: 수행한 지시는 성공, 아무 동작 없이 지나간 지시와 지시 밖 장애물 충돌은 시간 부족, 다른 동작·늦은 동작은 시간 안의 실수. 지시 중 충돌은 그 지시의 결과에 이미 들어 있어 따로 세지 않는다. 이 관측은 속도에만 쓰고 언어 기록으로 쓰지 않는다.
- 놓치면 바람이 느긋해지고(“바람이 조금 느긋해져요.”), 연달아 해내면 한 칸씩 빨라진다. 처음 속도는 한 번에 뛰지 않고 1초에 한 칸 미끄러지듯 바뀐다. 다음 달리기는 지난번에 맞춘 데서 이어 간다.
- 맞춤 학습 입구에서 「피곤해요」를 고른 날은 판 안 가속을 0으로 고정하고 아무것도 빨라지지 않는다. 그날의 가벼운 시작은 다음 날로 남지 않는다. 자동 시연은 맞춤을 쓰지 않는다.

`atlas-learning.js`는 공통 원본에서 생성한 번들이다. 저장소 루트의 `node tools/build-game-learning.js`로 생성하고 `node tools/build-game-learning.js --check`로 원본과 대조한다. **단독 배포·ZIP에도 이 파일을 포함**하며 생성 파일을 직접 수정하지 않는다. 선택 주입·시각/조작 오염 제외·실제 공통 API 연결은 `learning.test.mjs`에서 확인한다. [공통 연결 기준](../../docs/미니게임_TOPIK_I_학습기준.md)을 따른다.

## 실행

저장소에서 `node experiences/korean-runner/server.mjs`를 실행하고 <http://127.0.0.1:4273/>을 연다. ZIP은 압축을 풀고 `korean-runner` 폴더에서 `node server.mjs`를 실행한다. Node.js만 필요하며 별도 패키지 설치나 외부 CDN 호출은 없다. 창을 유지한 채 플레이하고 종료할 때 Ctrl+C를 누른다. `file://`는 ES 모듈 제약으로 지원하지 않는다.

포트 변경: PowerShell에서 `$env:SYNK_RUNNER_PORT='4274'`를 지정한다. Atlas 학습 기록과 공통 수집 보상은 아래의 브라우저 저장으로 연결한다. 단독 실행은 정식 학생 계정·교사 화면에 연결하지 않는다. 로컬 WORLD 안에서의 계정 기록·교사 목표는 위 「별도 듣기 확인과 교사 목표」를 따른다.

같은 Wi-Fi의 실제 휴대폰에서 열 때는 기존 서버를 종료하고 `node experiences/korean-runner/server.mjs --lan`을 실행한다. ZIP 폴더에서는 `node server.mjs --lan`이다. 터미널에 나온 **‘같은 Wi-Fi 휴대폰’ 주소**를 휴대폰 브라우저에서 연다. `--lan`은 PC의 네트워크 인터페이스에 서버를 열며, 기본 실행은 `127.0.0.1`에서만 열린다. 기기별 브라우저 저장이므로 PC와 휴대폰은 지갑·목표·학습 기록을 공유하지 않는다. [실제 휴대폰 확인 절차](qa/MOBILE-CHECK.md). 현재 실제 휴대폰 검증은 완료하지 않았다.

## 플레이

- **등불 여행**: 90초. **끝없는 바람길**: 보호가 소진될 때까지 이어진다.
- PC: ←/A, →/D 한 번에 한 칸 이동. 양쪽 끝에서 반대쪽 키를 한 번 누르면 가운데로 돌아온다. ↑/W/Space 점프, ↓/S 슬라이딩, Esc 일시정지.
- 휴대폰 크기: 좌우/상하 스와이프 또는 네 터치 버튼. 실제 휴대폰 검증은 별도다.
- 모든 달리기는 **듣기 전용**이다. 지시문·해설·정답 방향은 달리는 화면에 표시하지 않는다. 작은 스피커, 1/2번째 동작 표시와 접근 막대만 안내한다. 수행 피드백도 체크·실패·보호 아이콘과 소리로 제공한다.
- **소리·동작 익히기**: 시작 전 16개 표현을 넘겨 보며 목소리, 지시문, 뜻과 동작 아이콘을 확인한다. 필수 관문이 아닌 선택 연습이다. 종료 후에는 놓친 표현 우선 최대 4개를 글·뜻·수행 기록과 다시 듣기로 복습한다.
- 부탁 16개: 왼쪽/가운데/오른쪽, 뛰어넘기/숙이기, ‘뛰지 말고’/‘숙이지 말고’, ‘간 다음’/‘넘은 뒤’ 등의 두 동작. 공식 TOPIK 문항은 아니다. 처음에는 단순 동작, 뒤에는 부정과 순서를 만난다. 90초에 16개 전부를 만나는 구조는 아니다.
- 표시선을 지날 때 해당 위치나 동작 상태를 판정한다. 두 동작은 27m 떨어진 두 표시선에서 각각 수행한다. 점프·숙이기 동작은 맞았지만 일찍/늦게 한 경우 ‘타이밍 놓침’으로 남긴다. ‘그대로 달리기’는 표시선 가까운 26m 구간에서 점프나 슬라이딩을 하지 않아야 한다.
- 방향 부탁의 표시선은 세 길에 동일하게 보이며 정답 글자·색·아이콘으로 목적지를 알려주지 않는다. 점프/숙이기는 실제 울타리/표지판도 함께 보여 액션 단서를 제공한다. 장면만 보고 움직일 수 있으므로 수행 기록을 언어 이해의 확정 점수로 사용하지 않는다.
- 부탁 사이에는 일반 장애물이 나온다. 울타리는 점프/옆 회피, 표지판은 숙이기/옆 회피, 전차는 옆 회피. 지시를 듣고 수행하는 접근 구간에는 무관한 장애물을 넣지 않는다.
- 수행한 표시선마다 등불을 밝힌다. 부탁 세 개를 연속 수행하면 충돌 한 번을 막는 바람막을 얻는다. 일반 별 수집·장애물 충돌은 부탁 기록과 별도다. 놓친 부탁은 회차 뒤쪽에 다시 나온다.
- **먼저 구경하기**는 지시와 동작을 알고 자동으로 달리는 시연이다. 배너를 표시하고 최고 거리에 저장하지 않는다. 학습 성과나 사람의 직접 완주 증거로 집계하지 않는다.
- 최고 거리·그래픽 선택·바람상점 소유와 장착은 이 브라우저의 `synk.windrun.*`에 저장한다. Atlas 공통 학습 기록은 별도 공통 키를 사용한다. 회차 안의 재출제는 놓친 부탁을 다시 제시하고, 회차를 넘는 다음 부탁 선택은 Atlas 노출 기록을 참고한다. 이전 단어런 키와 레이싱 기록은 덮어쓰지 않는다.
- 균형/경험 그래픽, 카메라 흔들림 감소, 일시정지를 제공한다. 브라우저의 동작 감소 설정을 기본 반영한다. 다시 듣기는 시작 전·종료 후에만 제공한다.
- 소리를 끄면 달리기도 멈춘다. 소리 켜고 계속 달리기를 누르면 재개한다. 일시정지·설정·창 비활성화 시 게임 시간과 AudioContext를 함께 멈춰, 진행 중인 음성을 처음부터 반복하지 않고 같은 지점에서 이어 듣는다.

## 바람상점

첫 화면의 상점 단추 또는 결과 화면의 ‘모은 별로 바람상점 보기’로 연다. 모든 상품은 구매 전에 3D 장면에서 무료로 미리 볼 수 있다. 구매하면 바로 장착하며, 상점을 닫으면 저장된 장착 모습으로 돌아온다. 각 종류에서 하나씩 골라 함께 사용할 수 있다.

| 종류 | 무료 기본 | 별로 구매하는 상품 |
|---|---|---|
| 달리기 자취 | 자취 없이 | 꽃잎 자취 35 · 별빛 자취 55 · 폭신 발자국 40 |
| 등불 꾸미기 | 한지 등불 | 꽃등 40 · 반딧불 등불 60 |
| 동행 친구 | 혼자 달리기 | 작은 참새 70 · 아기 구름 85 |
| 코스 풍경 | 바람 마을 | 벚꽃길 80 · 눈꽃 마을 95 · 달빛 축제 120 |
| 완주 연출 | 몽글 인사 | 꽃비 인사 45 · 별빛 포즈 60 · 축제의 밤 90 |

무료 기본 5개와 구매 상품 13개다. 첫 방문 시 **환영 별 60개**를 한 번 저장한다. 직접 달리며 모은 별을 종료·홈 복귀 시 지갑에 적립하고, 90초 등불 여행을 완주하면 **20별**을 더 받는다. 중도 종료도 수집한 별은 보관한다. 자동 시연은 별·목표 진행·목표 보상을 지급하지 않고 같은 회차를 다시 정산해도 중복 지급하지 않는다. 상품 가격과 달리기 속도·장애물·지시 판정은 v5에서 유지했다. 실제 돈으로 결제하는 기능은 없다.

**상품 찜:** 구매하지 않은 유료 상품 하나를 찜할 수 있다. 상점의 ‘찜하기/찜 해제’로 선택하고, 홈에서 찜한 상품·잔액·부족한 별을 확인한 뒤 바로 해당 상품의 상점을 연다. 다른 상품을 찜하면 기존 선택을 바꾸며, 찜한 상품을 구매하면 찜을 해제한다. 찜은 별을 쓰지 않는다. 달리는 중에는 찜 설명이나 목표 글을 표시하지 않는다.

**누적 여행 목표:** 직접 달린 누적 거리·직접 수집한 별·90초 등불 여행 완주 횟수로 아래 여섯 목표를 계산한다. 각 목표는 한 번 보상을 지급하며 홈에는 다음 미완료 목표 하나, 결과에는 이번에 받은 목표 보상과 찜 상품까지 남은 별을 표시한다. 거리·수집 별은 중도 종료도 누적하고, 환영 별·완주 보너스·목표 보상은 ‘수집 별’ 목표에 더하지 않는다. 여행 목표를 듣기 실력이나 TOPIK 성취로 해석하지 않는다.

| 여행 목표 | 누적 조건 | 한 번 받는 보너스 |
|---|---|---|
| 첫 발걸음 | 직접 달린 거리 150m | 10별 |
| 작은 별 모으기 | 직접 수집한 별 10개 | 10별 |
| 첫 등불 여행 | 90초 등불 여행 1회 완주 | 15별 |
| 마을 한 바퀴 | 직접 달린 거리 1,500m | 15별 |
| 반짝이는 주머니 | 직접 수집한 별 30개 | 15별 |
| 세 번의 등불 여행 | 90초 등불 여행 3회 완주 | 20별 |

`shop.mjs`가 카탈로그·지갑·소유·장착·찜·누적 목표·회차 정산을 담당하고, 기존 `synk.windrun.shop.v1`에 저장한다. v5 저장의 지갑·소유·장착·정산 이력을 유지하고, 이전에 없던 찜·목표 필드는 빈 진행에서 시작한다. 기록되지 않은 예전 달리기를 소급 집계하지 않는다. 저장이 실패하면 구매·장착 변경·찜 변경·별/목표 보상을 완료로 처리하지 않는다. 브라우저 데이터를 지우면 상점 기록도 지워지며 다른 기기와 동기화하지 않는다. 바람길 별은 `collection.js`의 **공통 차고 코인과 별도**이고 서로 전환하지 않는다. 기존 공통 완주 보상과 배지 연결은 유지한다. 단독 실행 서버·ZIP에는 레이싱 차고 화면이 들어 있지 않으므로 차고 이동은 통합 PLAY 경로에서 사용한다.

`world-cosmetics.mjs`는 자취·동행 친구·등불·마지막 인사를 실제 3D 장면에 넣고 풍경의 색·조명·입자를 바꾼다. v6의 `scenery-details.mjs`는 테마마다 실제 물체를 추가한다. 벚꽃길에는 머리 위 벚꽃 가지 터널·길가 꽃과 덤불, 눈꽃 마을에는 한옥 지붕에 쌓인 눈·길가 눈더미·눈사람, 달빛 축제에는 길 양쪽 등불 기둥·머리 위 등불 줄이 나타난다. 장식은 코스 양옆 또는 5.4m 이상 높이에 배치하며 같은 길·장애물 판정을 유지한다. 테마 물체는 고정된 인스턴스 버퍼를 재사용하고 균형/동작 감소 설정에서 추가 세부 물체 수를 줄인다.

장식은 정답 방향을 드러내거나 속도·생명·바람막·부탁 판정·학습 기록을 바꾸지 않는다. 별도 장식 소리도 추가하지 않는다. 저사양·동작 감소 설정에서는 장식 입자 수를 줄인다.

## 홍보 설명과 TOPIK 학습 연결

사용자가 요청한 원칙: 재미 설명과 함께 **TOPIK의 어느 영역·능력을 연습하는지** 기록하고, 기능이 바뀌면 갱신한다. 아래는 v6 실제 기능 기준이다. 주된 학습 연결은 **짧은 한국어 지시 듣기**다. 꾸미기 상점·찜·여행 목표는 반복 플레이의 수집 보상이며 학습 영역·학습 판정을 늘리지 않는다. 이전 그림/단어 선택, 달리는 중 읽기, 듣고 보며 모드는 현재 플레이에 없다.

| 플레이/표현 | 제공하는 연습 | TOPIK 학습에서의 역할 |
|---|---|---|
| 듣고 움직이는 달리기 | 짧은 한국어 지시를 듣고 동작으로 반응 | 초급 듣기의 행동·방향·위치 표현 이해 보조 |
| ‘뛰지 말고’, ‘가지 말고’ | 해야 할 행동과 하지 말아야 할 행동 구분 | 듣기에 필요한 부정 지시 이해 연습 |
| ‘간 다음’, ‘넘은 뒤’ | 두 동작을 기억하고 두 표시선에서 수행 | 듣기에 필요한 순서 관계 이해 연습 |
| 시작 전 표현 연습·종료 후 복습 | 멈춘 화면에서 소리·지시문·뜻·동작을 함께 확인 | 듣기 표현의 어휘·문장 의미를 확인하는 보조 단계. 달리기 자체의 읽기 훈련으로 홍보하지 않음 |

TOPIK I을 준비하는 초급자의 짧은 지시 듣기 보조 연습이다. 표현 16개를 직접 만들었으며 공식 문항·급수별 교육과정 대응 검수를 완료한 것은 아니다. 대화 전체 듣기, 긴 지문 읽기, 쓰기·말하기, TOPIK II 서술형은 직접 연습하지 않는다.

소리를 의미와 행동에 연결하고, 부정·순서를 구분하며, 놓친 표현을 다시 확인할 기회를 제공한다. 조작 숙련·시각 단서·타이밍도 수행에 영향을 주므로 성공을 한국어 이해의 확정 점수로 해석하지 않는다. 학생의 장기 기억·듣기 실력·TOPIK 점수 변화는 검증하지 않았다.

현 기능에 맞는 홍보 예시:

> “뛰어넘으세요.” “이번엔 뛰지 마세요.” 한국어를 듣고 몸으로 반응하는 생존 액션 게임, 바람길. 방향과 동작, 부정과 순서를 따라 마을의 등불을 밝혀보세요. TOPIK I을 준비하는 초급자를 위한 짧은 한국어 지시 듣기 연습을 담았습니다. 놓친 표현은 달리기가 끝난 뒤 다시 들어보세요.

## 목소리

16개 로컬 MP3를 시작 클릭 뒤 Web Audio로 준비한다. 한국어 OS 음성이 없어도 파일 음성을 재생하며 나레이션 중 배경음을 낮춘다. **전체 파일을 준비하지 못하면 달리기를 시작하지 않고 재시도 화면을 제공한다.** 읽기 모드나 OS TTS로 자동 전환하지 않는다. 재시도는 누락된 파일만 다시 불러온다. 음질 직접 청취/학생 검수는 별도다.

Windows `System.Speech`의 Microsoft Heami Desktop, rate=0 합성 음성. 원고 `instructions.mjs`, 생성 작업 `assets/voice/jobs.json`, 재생 `assets/voice/*.mp3`, 재생성 `scripts/build-voice.ps1`. WAV 원본은 로컬에 보존하며 전달 ZIP에서 제외한다. 파일 길이·크기·해시·코덱은 `assets/voice/manifest.json`에 기록하고 `voice-timing.mjs`로 안내 시점을 조정한다. 재생성 뒤 `scripts/build-voice-manifest.py`를 실행한다. 유료 음성 생성은 사용하지 않았다.
