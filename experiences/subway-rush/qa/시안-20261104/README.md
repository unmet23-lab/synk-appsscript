# 환승 러시 움직이는 시안 (2026-11-04)

[설계](../../설계.md) 8절의 두 그림 길을 같은 장면 · 같은 소리로 돌린다. 입구 → 2호선 안(길 안내 → 차임 → 도착 안내 → 문 열림 → 세 칸) → 시청 환승 통로(달림 → 갈림 입구에서 멈춤 → 일부러 틀림 → 쪽지 → 우회 → 맞음 → 달려 나감). 보기 페이지(비공개): <https://claude.ai/artifact/6yy8pdD6U1ShwoYipqpyUZ>

**목소리는 시안용 임시(edge-tts)다.** 본판은 후보를 들려 드리고 고른 뒤 다시 굽는다.

**잰 값(A 녹화, 구간 평균):** 길 안내 −14dB · 안내방송 −17dB · 레일만 약 −33dB — 첫 판은 레일이 −15.7dB로 안내 음성만큼 커서 낮췄다(설계 「음성보다 16 LU 아래」).

**확인 범위:** 두 시안 모두 처음부터 끝까지 자동 진행(오류 · 실패 요청 0), 보기 페이지 묶음도 로컬 서버에서 상대 경로로 시작까지 확인. 실제 보기 페이지 안의 재생, 휴대폰 실기기, 사람 귀 청취는 아직이다.
