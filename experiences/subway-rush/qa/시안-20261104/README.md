**잰 값(A 최종 녹화, 구간 평균 — ffmpeg volumedetect):** 길 안내 −14.8dB · 안내방송 −17.3dB · 레일만 −37.2dB(음성 뒤 물러났다 돌아오는 자리) · 문 열린 뒤 −40.3dB, 전체 −16.3 LUFS · 봉우리 −0.1dBFS. 첫 판은 레일이 −15.7dB로 안내 음성만큼 커서 낮췄다(설계 「음성보다 16 LU 아래」). 봉우리는 본판에서 더 낮춘다.

**확인 범위:** 두 시안 모두 처음부터 끝까지 자동 진행(오류 · 실패 요청 0), 보기 페이지 묶음도 로컬 서버에서 상대 경로로 시작까지 확인. 실제 보기 페이지 안의 재생, 휴대폰 실기기, 사람 귀 청취는 아직이다.
