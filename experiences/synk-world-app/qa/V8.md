# WORLD 그래픽 v8 · 2026-10-09

한강에 천천히 지나가는 작은 배를 추가하고 가까운 소품의 마감을 보완했다. **로컬 코드·브라우저 반영**이며 설치형 빌드·공개 배포·실물 휴대폰 성능 검증은 포함하지 않는다.

## 화면과 움직임

- 크림·남색 선체, 목재 갑판, 창문·난간이 있는 배 한 척이 한강의 먼 쪽을 지나간다. 교량·집·몽글과 실제 깊이 관계를 가지며 가려진다. PC와 휴대폰은 첫 화면에서 배가 보이도록 같은 노선의 시작 위치를 달리했다.
- 선체의 작은 흔들림, 옅은 선미 물살과 두 갈래 물결, 수면 접촉 음영·짧은 반사를 연결했다. **수면 반사와 접촉 음영은 평면 셰이더 근사**이며 별도 반사 카메라·물리 유체·실시간 반사 렌더가 아니다.
- 기존 30Hz 장면 루프에서만 배와 물살을 갱신한다. 움직임 감소·비활성·화면 밖 홈에서는 멈추며, 사진을 찍을 때 배의 위치와 시간이 바뀌지 않는다. 낮/노을 전환도 이동을 처음부터 시작하지 않는다.
- 러그의 흰 링을 없애고 얇고 닫힌 직조 단면으로 만들었다. 실제 데크 bevel 상면을 측정해 러그 밑면을 0.001 위에 두었다. 첫 수정에서 러그가 데크에 가려진 것을 이미지 검수에서 찾아 바로잡았다.
- 가까운 화분의 림·내벽·몸체·바닥을 하나의 닫힌 회전체로 연결하고 중복 부품을 제거했다. 목재·석재·잎의 normal map 녹색 채널은 CanvasTexture의 V 방향과 맞췄다.

몽글의 얼굴·팔 없는 실루엣·코스튬 ID와 공통 아바타는 유지한다. `graphicsVersion:3` / `visualRevision:environment-v8`이며 새 배는 `river-life-v8.mjs`가 담당한다.

## 렌더 비용과 범위

배 자체는 **5 draw call·1,324삼각형**, 신규 텍스처·광원·렌더 타깃은 0이다. 러그/화분 통합으로 근경 메시 3개와 원본 삼각형 176개를 줄였다.

동일한 PC1400×720 / 휴대폰 크기390×465, 목도리+앞치마, 노을, 균형 모드의 v7 캡처와 비교하면 그림자/AO를 포함한 전체 호출 수는 PC427 / 휴대폰253으로 같다. 전체 삼각형은 PC623,812→625,930(약0.34%), 휴대폰390,270→391,306(약0.27%)이다. [v7 참조](../../synk-world-home/qa/graphics-v8/before-capture.json) · [v8 캡처](../../synk-world-home/qa/graphics-v8/capture.json). 낮과 노을은 태양 그림자의 시야가 다르므로 같은 시간대끼리 비교했다.
