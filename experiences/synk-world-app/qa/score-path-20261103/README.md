# 점수 길 · 굳히기 전 작은 시험 둘 (2026-11-03)

유호님 11-03 「시험부터 돌려」. 같은 날 Claude 판단(TOPIK 영역 진단 아이디어 — 「게임 기록 → 급수」 대신 「다음 급까지 점수를 딸 곳」을 보이고 실제 성적표로 채점받는 예측)의 굳히기 전 시험이다. 근거가 된 기존 결정은 결정 표 10-19 「WORLD 내 위치」(범위 · 근거 수 · 날짜, 게임 점수를 급수로 환산하지 않음), 10-21 「시험 형식 연습(미니 모의)」, 10-28 「WORLD AI 튜터」다.

기준은 돌리기 **전에** 아래에 적었다. 결과는 맨 아래 「결과」에 더한다.

## 시험 ① 쓰기 채점 일치

**묻는 것:** 쓰기 자동 피드백의 범주별 A~F 참고 범위가 다시 돌리거나 모델을 바꿔도 같은 자리에 나오는가. 그렇다면 쓰기도 점수 범위로 보일 수 있고, 아니면 「감점 요인 목록」만 보인다.

- **재료:** 공개 은행(`world-writing-items.json`, 판 `71fc205994dc0b3b`)의 53번 셋(w53-resale · w53-living-cost · w53-clinic)과 54번 셋(w54-translation · w54-car-free · w54-advice). 문항마다 네 편 = 24편 — L1 잘 쓴 글 · L2 말이 약한 글 · L3 내용이 빠진 글 · L4 짜임이 약한 글. 다른 에이전트(Opus)가 [첨삭 기준 §5](../../../../docs/온라인반_TOPIK4급/첨삭기준.md)의 잦은 오류로 썼고, 예시답 · 문제 글에서 어절 6개 넘게 잇따라 가져오지 않았다. 글은 [`essays24.mjs`](essays24.mjs).
- **채점:** 제품과 같은 요청 몸통 — SYNK-talk `lib/world-writing-feedback.js`(지시문 판 `world-writing-feedback-2`)의 `buildRequest`, 설명 언어 ko. Sonnet 5.5 두 번(S1 · S2)과 Opus 5.5 한 번(O)을 서로 모르게 따로 보낸다. 키는 검수 목록(`tools/lib/클로드키.js`, 한도키). 실행 [`채점일치.mjs`](채점일치.mjs), 분석 [`분석.mjs`](분석.mjs).
- **읽는 값:** 범주(내용 및 과제 수행 · 글의 전개 구조 · 언어 사용)마다 범위 [높은 글자, 낮은 글자]. 글자 값 A=5 … F=0, 범위의 가운데 m = (높은 + 낮은) / 2. 한 칸 = 글 하나 × 범주 하나(72칸).
- **기준:**
  1. 재현(S1 대 S2): |m 차이| ≤ 0.5인 칸이 90% 이상.
  2. 모델 사이(S1 대 O): |m 차이| ≤ 1.0인 칸이 90% 이상, ≤ 0.5인 칸이 60% 이상.
  3. 점수로 본 차이(S1 대 O): 공식 배점(53 = 내용 7 · 전개 7 · 언어 16, 54 = 12 · 12 · 26 — 첨삭 기준 §9)에 글자 비율(A 1.0 · B 0.8 · C 0.6 · D 0.4 · E 0.2 · F 0 — **우리 가정, 공식 환산표 아님**)을 곱한 총점의 차이가 53은 3점, 54는 5점 안인 글이 80% 이상.
  4. 겨냥한 범주가 내려가나: 약한 판(L2 → 언어, L3 → 내용, L4 → 전개)마다 겨냥한 범주의 m이 같은 문항 L1보다 1.0 이상 낮은 경우가 세 채점 각각에서 80% 이상이고, 겨냥한 범주의 내림이 나머지 두 범주의 평균 내림보다 크다.
- **판정:** 1 · 2 · 3을 넘으면 「쓰기 점수 범위를 근거 수와 함께 보여도 된다」. 1이나 2를 못 넘으면 쓰기는 「감점 요인 목록」만 보인다. 3만 못 넘으면 범위를 넓혀(글자 두 칸) 보인다. 4는 「쓰기 안에서 무엇이 약한지」를 말해도 되는지를 정한다.
- **한계:** 사람이 매긴 점수가 없어 「맞는가」가 아니라 「흔들리지 않는가 · 겨냥한 곳을 잡는가」만 본다. 같은 Claude 집안 두 모델이라 같은 쪽으로 치우칠 수 있다. 글을 쓴 것도 Claude(Opus)다.

## 시험 ② 점수 길 카드 맹검

**묻는 것:** 같은 진단 숫자를 「영역 판」(듣기 · 읽기 · 쓰기 점수와 가장 부족한 영역 · 장점)으로 보일 때와 「점수 길 판」(다음 급까지 점수를 딸 곳 셋 · 이미 혼자 하는 유형)으로 보일 때, 학습자가 어느 쪽을 더 열어 보고 공부하고 싶어지고 믿는가.

- **재료:** 가상 학습자 셋 — P1 근거 충분 · 4급 근처, P2 3급 경계 · 54번을 안 씀, P3 근거 부족(범위 없음). 사람마다 R(영역 판) · S(점수 길 판) 두 장. 예상 범위 · 근거 수 · 날짜(10-19 결정)와 겉(글꼴 · 색 · 크기)은 두 판이 같고, 다른 것은 정보를 묶는 단위뿐이다. 시간(「몇 시간 더」)은 두 판 모두 넣지 않는다 — 셀 근거가 없다.
- **시험관:** 넷 — Sonnet · Haiku × (몽골 21세 여 · 대학 1학년 · 졸업에 4급 필요 / 베트남 23세 남 · 대학원 진학에 4급 필요). 맥락 · 가설을 알리지 않고, 사람마다 두 장의 X · Y 순서를 섞는다.
- **묻는 것(장마다 1~5):** 다시 열어 보고 싶나 · 공부하고 싶어지나 · 믿기나 · 성적표처럼 무겁나(5 = 아주 무거움). 그리고 「이 카드를 보고 오늘 무엇을 공부하겠나」(한 줄), 「둘 중 하나만 앱에 둔다면」.
- **기준:**
  1. 고르기: S를 고른 판단이 12번 중 8번 이상.
  2. 공부하고 싶어지나 · 믿기나: 둘 다 S 평균이 R보다 0.5 이상 높다.
  3. 무겁나: S 평균이 R보다 0.5 넘게 무겁지 않다.
  4. 할 일: 「오늘 무엇을」 답이 구체적인(문항 유형 · 번호 · 과제를 댄) 비율이 S에서 10/12 이상이고 R보다 높다.
  5. P3(근거 부족): S의 「공부하고 싶어지나」 평균이 3 이상.
- **판정:** 1 · 2 · 3을 넘으면 점수 길 판으로 간다. 4를 못 넘으면 「딸 곳」 문장을 고친다. 5를 못 넘으면 근거 부족 상태 화면을 따로 다시 짠다.
- **한계:** AI 시험관은 실제 학습자가 아니다. 실제 성적표 대조(시험 ③ — 최근 TOPIK II 성적표가 있는 학생 3~5명)는 사람이 있어야 해서 이번에 하지 않는다.
- **2차(1차 결과를 본 뒤 더함):** 1차는 기준 2의 「믿기나」만 못 넘었다(아래 결과). 시험관이 짚은 믿음 문제를 S에서 고친 판(S2)과, 머리 아래 말 · 줄바꿈만 같이 바꾼 R(R2)을 **새 시험관 넷**(T5~T8, 같은 모델 · 사람, X · Y 자리는 다시 섞음)에게 보인다. 기준은 1차와 같고, 장마다 첫 묶음 제목(head)을 적게 해 X · Y 이름이 그림과 맞는지 대조한다(1차의 이름 뒤바뀜 때문). 2차에서도 「믿기나」가 R + 0.5에 못 미치면, 믿음은 카드 문장이 아니라 실제 성적표 대조(시험 ③)로만 올릴 수 있다고 본다.
