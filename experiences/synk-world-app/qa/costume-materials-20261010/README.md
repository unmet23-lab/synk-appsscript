## 로컬 서비스와 기존 기록

무료 첫 컬렉션은 13종이며 첫 문장 놀이 목도리의 참여 조건을 유지한다. 현재 A는 기존 8→14종, B는 초기 7→13종이다. [전후 전체 계정 비교](local-after.json)는 새 6종과 필요한 revision만 제외하고 차림·색·룩북·진행·보상 등 원래 응답이 같음을 확인했다. 저장된 A에는 실제 획득 시각과 revision 한 번, 아직 WORLD 저장 행이 없는 B에는 초기 무료 컬렉션/null 시각·revision0 계약을 적용했다.

같은 db-v1로 서버를 재시작할 때 기존 C18 ledger 값과 현재 기대 checksum이 달라 중단됐다. [읽기 전용 구조 감사](local-schema-audit.json)로 두 dye guard의 본문·속성, 검증된 CHECK와 private 접근 규칙이 동일함을 확인한 뒤, [기존 ledger 한 행만 정리](local-ledger-repair.json)했다. 그 작업은 스키마/게임 기록을 변경하지 않았고 전후 데이터를 대조했다. 원래 데이터 초기화, 원격 DB 변경이나 공개 배포는 없다.

로컬 브라우저·합성 계정·뷰포트 결과다. 정적 native GLB를 새 옷으로 갱신하지 않았으며 최종 마스터 모델·천 시뮬레이션·실물 휴대폰 지속 성능·공개 결과의 증명으로 해석하지 않는다.
