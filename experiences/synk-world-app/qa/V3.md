# WORLD v3 통합 검수 · 2026-10-09

사용자가 선택한 이번 범위는 **코드·브라우저 검증까지**다. 그래픽 방향은 채택했지만 품질에 만족한 것은 아니라는 기준을 유지한다. 이 기록은 로컬 합성 시험 계정과 실제 브라우저 WebGL에 대한 결과이며, 출시·운영 계정·실물 기기 검증과 구분한다.

## 검수에서 수정한 동작

- 응답 유실 시 원래 완료 요청을 재전송하고 목도리가 중복 지급되지 않게 확인했다.
- 비교 화면에서 버전을 연속 전환하면 마지막 선택의 캔버스 하나만 남도록 비동기 초기화를 보강했다.
- 로그아웃 도중 도착한 이전 계정의 차림을 버리고, 401에도 타운의 표시·조작을 함께 해제한다. 조회 중 발생한 최신 차림 알림은 추가 재조회로 반영한다.
- 타운 서버의 오류 코드와 한국어 메시지가 클라이언트에서 사라지던 문제를 고쳤다.
- 타운 재진입 시 부모 버튼에 남은 포커스로 걷기 연결이 끊기던 순서를 타운 담당이 수정했다. 초기 presence 전에 장면 포커스를 받고 이미 켜진 걷기를 중복 활성화하지 않는다. 실제 iframe 재진입까지 통과했다.
- 근접 카메라에서 반투명 벤치·프레임 잔상이 얼굴과 코스튬에 겹쳐, 타운 담당이 해당 시점의 가림 소품을 숨기고 시점 전환 시 복원하도록 수정했다. 실제 타운 12개를 다시 통과했고 PC·390px 최종 정면 캡처에서 얼굴·목도리·앞치마의 잔상이 사라진 것을 직접 확인했다. 모든 위치·카메라 각도에 대한 보장은 아니다.
- Windows 정적 서빙에서 역슬래시와 대소문자 조합으로 서버 소스가 노출되던 경로를 발견해 차단했다. 수정 전 재현을 보존하고 두 우회의 403과 정상 자산의 200을 확인했다.
- 그래픽 직접 검수 후 거친 섬유, 뾰족한 잎 단면, 과도한 수면 가로무늬를 줄였다. 휴대폰 사진 단추는 44px 이상의 터치 영역을 확보했다.
- Unity 미전송 결과를 계정별 파일에 원자적으로 저장하고 재시작 후 같은 답·같은 요청 ID로 재전송하도록 했다. 디스크 저장 실패 시 서버 제출을 시작하지 않는다.

## 남은 범위

설치형 Unity 화면·Editor 의미 컴파일·Windows/Android 빌드, 실제 Google/Apple 인증, iOS 서명, S25/iPhone 15의 지속 FPS·발열·터치, 원격 DB·공개 배포는 실행하지 않았다. 사용자의 이번 범위 선택에 따라 설치·기기 연결은 뒤로 둔다.

GLB는 9 mesh / 8 material / 4 image / 43,252 triangles다. 본·애니메이션은 없고 짧은 펠트 섬유 선과 bump 셰이더는 정적 GLB에 포함하지 않았다. Unity로 같은 촉감을 옮기려면 URP 재질 변환·표면 맵 굽기·리깅이 필요하다. 홈의 PC/휴대폰 draw call·triangle 수는 렌더 통계이며 실제 휴대폰 성능 측정값이 아니다.

이번 결과를 최종 미술 승인이나 ‘레이싱 이상 달성’으로 판정하지 않는다. 최종 조형·재질·코스튬 가림 조합과 실기기 검수는 계속 발전시킬 제작 범위다.
