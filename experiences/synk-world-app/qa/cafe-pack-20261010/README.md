## 수정 전 시험 기록과 한계

`source-r1`~`source-r3`은 기존 튜터 첫 만남을 끝내지 못한 시험 도구 오류였다. `source-r4`는 패널 진입 애니메이션이 끝나기 전 경계를 재어 실패했고, `source-r5`는 영상의 재생 가능 상태보다 앞서 판정했다. `source-r6`은 상단과 하단의 같은 프로필 버튼을 구분하지 못했다. 최종 도구는 실제 튜터 선택 UI를 진행하고, 애니메이션 완료·영상 준비·범위를 정한 프로필 조작을 사용했다. 최종 실행은 오류 없이 정상 종료했다.

최초 독립 홈 검사는 이전 4307 서버가 종료되어 연결을 못 했고, 동일 원본을 제공하는 현재 4313의 독립 경로에서 다시 통과했다. 최초 정적 계정 모의는 진행 저장에 존재하지 않는 전역 revision 필드를 기대해 실패했다. 실제 공식 계약대로 각 변경의 `previous` 값과 요청 ID를 검증하도록 수정했다. 기존 실패 자료는 보존했다.

실물 휴대폰/설치본 성능, 운영 OAuth·원격 저장 왕복, 공개 배포, 교원 난도 검수와 학생 재미/학습 효과는 미검증이다. 현재 카페 입력은 읽기와 선택이며 듣기·발음·말하기 평가가 아니다.
