# WORLD 그래픽 v7 · 2026-10-09

현재 캐릭터 중심 홈의 그래픽을 이어서 발전시켰다. 이번 범위는 **잎의 빛 반응, 강물, 기와와 강변 수관**이며 로컬 코드·브라우저까지 반영했다.

## 구현

- 잎 색의 중복 곱셈으로 검게 뭉치던 부분을 완화했다. 기존 태양 방향을 사용한 얇은 잎의 투광 근사를 더했다. 새 광원 없이 기존 바람과 그림자 변형을 유지한다.
- 강물을 낮은 금속성·물의 굴절률을 사용하는 재질로 조정하고 작은 잔물결이 반사 방향을 바꾸게 했다. 첫 시안의 큰 줄무늬는 크기를 줄여 수정했다.
- 현재 도시 메시의 실제 위치·크기·색을 512×128 이미지에 한 번 기록해 강물의 원경 반사에 사용한다. 카메라 각도와 잔물결에 따라 표본 위치가 바뀐다. **정적인 원경 입면을 근사한 반사**이며 가까운 물체·움직이는 물체의 실시간 반사는 아니다. 새 반사 카메라나 렌더 타깃은 사용하지 않는다.
- 건물·산에는 거리와 높이에 따른 옅은 대기색을 더했다. 색 혼합은 톤매핑 전에 선형 공간에서 한다. 가까운 층은 더 분명하고 먼 층은 넓게 읽히도록 기존 안개 범위를 조정했다.
- 집의 상자형 지붕 이음선을 곡면·밑면·앞뒤 마감이 닫힌 96개 기와 인스턴스로 교체했다. 한 batch를 대체하므로 호출 수는 같다. 강변 수관의 분할을 보완해 큰 각진 윤곽을 줄였다.

몽글의 승인 얼굴·팔 없는 실루엣·코스튬 ID·아바타 재질은 유지했다. `graphicsVersion:3` / `visualRevision:environment-v7`이다. UI와 보상/계정 서버는 이번에 바꾸지 않았다.

## 비용과 남은 범위

같은 1400×720·390×465, 동일 차림·노을·균형 모드의 기존 v6 캡처와 비교하면 그림자/AO 포함 전체 삼각형은 PC 585,088→623,812(약6.62%), 휴대폰 크기 367,526→390,270(약6.19%)이다. 전체 draw call은 PC427 / 휴대폰253으로 같다. 새 반사 이미지는 RGBA512×128+밉맵으로 약0.33MiB이고 신규 화면 버퍼·광원은 0이다. [기존 캡처](../../synk-world-home/qa/graphics-v7/before-capture.json)와 [현재 캡처](../../synk-world-home/qa/graphics-v7/capture.json)를 보존한다.

휴대폰 기본 균형/가볍게는 AO 추가 버퍼0, 3M 픽셀 상한·기본 DPR1.5·그림자1024를 유지한다. 물결 시간은 기존 30Hz 루프에서만 갱신하고 움직임 감소·가려진 홈·비활성 화면에서는 멈춘다. CPU 제출 시간은 GPU FPS나 실제 발열 성능으로 해석하지 않는다.

4296 사용자 자료 초기화·새 이미지 생성·다운로드·유료 호출·공개 배포·Unity 설치는 없었다. 합성 계정 복구는 기존4396 격리 시험 서버에서 확인했다. [v5 실제 미니게임 보상 연결의 남은 계약](V5.md#실제-미니게임-보상은-다음-계약이-필요하다), 정식 환경 자산, 아바타 리깅·의상 가림·URP 이식, S25/iPhone15의 지속 성능 검증은 남아 있다. 최종 품질 승인 또는 레이싱 이상 달성의 증거로 삼지 않는다.
