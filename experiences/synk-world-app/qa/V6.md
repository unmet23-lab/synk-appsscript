# WORLD 그래픽 v6 · 2026-10-09

요청: 현재 방향을 유지하면서 그래픽을 한 단계 더 높인다. 휴대폰 중심·촉감 있는 3D·캐릭터 중심 홈을 유지하고, 이번 범위는 **근경 재질·식물 조형·원경·접촉 음영**이다. 코드와 로컬 브라우저까지 구현했다.

## 화면 변화

- 목재·석재·잎에 색, 법선 요철, 거칠기를 구분한 256px 텍스처 9개를 넣었다. 목재의 중복 색 곱셈으로 탁하던 부분을 정리하고 석재의 작은 기공과 잎맥의 반사를 분리했다. 실행 때 매 픽셀 노이즈를 계산하는 방식이 아니라 처음 생성한 밉맵을 사용한다.
- 가까운 나무는 가늘어지는 줄기와 연결된 잔가지, 비대칭 곡면 잎으로 바꿨다. 줄기·가지를 병합하고 잎은 인스턴스로 묶어 기존 17개 렌더 메시를 2개로 줄였다. UV 고정점과 기존 바람/그림자 변형을 유지한다.
- 원경 건물의 모서리·층진 입면·유리 띠와 수관 군집을 보완했다. 산에 묻혀 창문만 떠 보이던 배치를 수정했다. 산의 분할 수를 수평 능선에 재배분해 추가 삼각형 없이 각진 꼭대기를 둥글게 다듬었다.
- PC 균형·선명 모드와 휴대폰 선명 모드에 좁은 틈의 접촉 음영을 추가했다. **휴대폰 균형·가볍게는 추가 화면 버퍼를 할당하지 않는다.** 사진 하늘에 톤매핑이 두 번 적용되는 문제를 수정했으며, 움직이는 잎에는 정적인 음영을 덧씌우지 않는다.
- 독립 검토에서 초기 자산 로딩 중 WebGL 연결이 끊기면 빈 캔버스가 남던 오류를 재현했다. 초기 렌더 실패 시 자원을 해제하고 오류를 한 번만 전달하도록 수정하고 재검증했다.

승인된 몽글 얼굴·팔 없는 실루엣·코스튬 ID는 유지한다. `graphicsVersion:3`, `visualRevision:environment-v6`로 기존 앱과 호환한다. [v4 정적 아바타 후보](../../synk-world-home/scene-assets/graphics-v4/README.md)는 유효하며, v6 환경 전체를 Unity로 이식한 것은 아니다.

## 비용과 적용 범위

근경 나무만 비교하면 PC 삼각형 42,672→25,350, 휴대폰 구성 24,192→11,916이다. 전체 장면 FPS 개선 수치는 아니다. 원경은 같은 렌더러로 비교할 때 총 삼각형 PC 약3.31%, 휴대폰 약3.49%가 증가한다. 산의 능선 교정 자체는 삼각형 증가가 없다.

접촉 음영을 켠 1280×720 버퍼 추정 비용은 약39.6MiB다. 추가 기하 패스 1회와 화면 패스 4회가 필요하다. 1400×720 최종 캡처에서는 약43.3MiB다. 휴대폰 기본 모드는 추가 버퍼 0이며 선명 모드를 사용자가 고르면 비용이 생긴다. 전체 화면 3M 픽셀, 고해상도 사진 2.6M 픽셀/긴 변1920, 기본 휴대폰 DPR1.5/그림자1024 상한은 유지한다.

v6의 `drawCalls`·`triangles`는 그림자와 선택적 AO를 포함한 프레임 합계이고 `renderStatsIncludeShadows:true`로 표시한다. 이전 v5의 beauty 단일 패스 통계와 직접 비교하지 않는다. CPU 렌더 제출 시간은 GPU 시간·FPS·발열 검증이 아니다.

4296 사용자 자료는 초기화하지 않았다. 계정·복구 검사는 기존 4396 격리 시험 서버를 사용했다. 새 이미지 생성·다운로드·유료 호출·공개 배포·Unity 설치는 없다. 실제 미니게임 공통 보상 연결은 [v5에 기록한 미완료 계약](V5.md#실제-미니게임-보상은-다음-계약이-필요하다)을 유지하며 이번에는 그래픽만 바꿨다.

S25/iPhone 15 실기기 지속 성능, 최종 환경 자산, 아바타 리깅·의상 가림·URP 이식은 아직 확인되지 않았다. 이 결과를 최종 품질 승인이나 레이싱 이상 달성으로 판정하지 않는다.
