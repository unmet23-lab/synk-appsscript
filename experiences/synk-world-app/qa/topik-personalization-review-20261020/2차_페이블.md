## ④ TOPIK 기준 정합성

- **영역**: 1차 §2-2 그대로. 듣기·읽기 배점이 같은데 처방은 듣기뿐(①·③). 영역 합계·균형이 Core에 없다(`learning.js:198-201` 정렬에 영역 항 없음) — 「엔진에 부족한 부분」의 첫째.
- **문항 유형**: 읽기 8항목은 공식 31~70번을 대체로 덮는다(빈칸=낱말·문형, 맞지 않는 것·내용 일치=세부·부정, 중심=핵심, 순서=순서; 「문장 들어갈 곳」·「글의 목적」만 없음). 듣기 7항목은 17~30번(내용 일치·중심·세트)에 치우치고 1~16번이 비어 있다(③-D). 「낱말 듣기(그림)」와 3지·O/X 형식은 TOPIK I이 아니라 TOPIK Basic의 유형·형식이다(외부조사 §1-8, 1-18). 그러므로 정직한 자리는 「TOPIK Basic 수준 입문 진단·연습 + TOPIK I 읽기 일부」이고, 1차의 「입문자 결과에 TOPIK Basic 성취 구간 말을 빌려 쓴다」는 이 자리와 맞는다(설명문만 빌리고 문항은 쓰지 않음).
- **재생 규칙**: TOPIK I은 전 문항 두 번, TOPIK II는 1~20 한 번·21~50 두 번. 우리 진단은 한 번 + 재생은 도움. 1차 판정은 맞되 고칠 층은 호스트(②-20). 학습 모드(게임)는 지금 규칙 유지.
- **쓰기 채점**: 공식 범주(내용·과제 수행 / 전개 구조 / 언어 사용)와 51·52 빈칸당 5점, 53 7·7·8×2, 54 12·12·13×2, A~F 구간(외부조사 §1-4). 작업본 온라인 반은 루브릭 0~2×3을 모든 과제에 같이 쓰고 51·52 빈칸별 칸·글자 수·시간이 없다(B 노트 §11, 작업본). 1차 제안 11에 「규칙으로 잡히는 감점(종결형·개조식·제목·분량·베끼기)은 자동, AI 총점은 참고 범위, 교사 표본으로 보정」을 더하면 된다. IBT 쓰기 3문항 사양은 미확인이라 PBT 4문항 기준으로.
- **등급**: 앱은 급수를 내지 않는다(§1 준수). 「예상 급수」 칸만 약속이 앞섰다(②-4). 범위를 보일 때 PBT/IBT를 적는다(③-E).
- 1차가 지나친 곳: #14·#19(근거 없음), #2·#20의 원인(엔진이 아니라 WORLD 층·호스트). 모자란 곳: ③-A~D.

## ⑤ 학생 만족·트렌드 관점의 화면·과정 설계

지키는 선: 3칸(혼자 해냄·연습 중·아직) 유지, 급수 환산 없음, 연속 기록·죄책감 없음, 펠트·「월드 시그널」, 마스코트는 장면과 함께 새로 굽기, 한 자리 한 언어, 도구 이름 없음, 새 문항은 초안 표시(자료에 `reviewStatus:'draft'`, 결과 화면에 「일부 문항은 검토 중인 초안이에요」 한 줄).

### 1) 목표 설정(학습 목표 창)
- 구성: 배우는 이유(그대로). 「시험·자격 준비」를 고르면 바로 아래 펼침 — 시험 종류(TOPIK I / TOPIK II / 사회통합 / 아직 몰라요) · 목표 급(선택) · 시험일(선택, 월 단위 허용) · 방식(PBT / IBT / 아직). 저장 스위치는 「저장하기」 단추 바로 위로 옮기고 안내문을 스위치 이름과 맞춘다. 펠트 나침반 포스터는 유지하되 시험을 고르면 나침반 옆에 작은 시험지 소품을 둔 장면으로 새로 굽는다.
- 상태: 처음(이유만) / 시험 고름(펼침) / 시험일 지남(「시험은 어땠어요? 다음 목표를 정할까요」) / 저장 안 함(「저장하지 않으면 오늘만 써요」).
- 문구 원칙: 목표는 길잡이, 판정 아님. 시험일은 「n월 n일 시험」으로 쓰고 「D-n」·「n일 남음」은 쓰지 않는다.
  - 예: 「목표는 연습을 고르는 길잡이예요. 급수를 매기지 않아요.」 「TOPIK I 2급 · 1월 11일 시험」
- 계약: `personalization.js` FIELDS에 `examType·targetGrade·examDate·examMode`를 선택 응답으로 더하는 r2(추천에만 씀, 능력 아님).

### 2) 진단(짧은 진단)
- 구성: 진행 막대·항목 이름(유지) + TOPIK I형 4지 보기(새 문항) + 듣기는 「두 번까지 들을 수 있어요」(TOPIK I 규칙) + 「답을 기록했어요」(정오를 바로 안 알리는 것은 유지).
- 흐름: 항목당 1문항 → 틀린 항목만 쉬운 난도로 1문항 더(최대 22문항, 6~8분). 게임 지시문·소리만 있는 O/X는 진단에서 빼고 말 랠리·카페 응답·새 대화형 초안으로 바꾼다.
- 상태: 처음 / 진행 중 / 소리 못 들음(건너뛰기 → 평가 불가, 약점 아님) / 끝.
- 끝 화면: 항목별 맞음·틀림(유지) + 틀린 문항 「해설 보기」(풀의 `explanation`) + 항목마다 「이 항목 연습하기 →」(연결된 활동이 있을 때만) + 「내 위치 보기」.
  - 예: 「틀린 건 약점이 아니라 다음에 볼 자리예요.」 「해설 보기」 「읽고 이유 이해하기 연습하기 →」
- 벤치마크: 「내 답 설명」은 무료 기본(Duolingo 2026-01, LingoDeer Tell Me Why). 산타식 「문제마다 바뀌는 예상 점수」는 넣지 않는다(10-19 결정).

### 3) 내 위치(약점이 보이게)
- 구성: 3칸 합계(유지) → 그 아래 영역 막대 둘(「듣기 혼자 해냄 2/7 · 읽기 5/8」, 배점이 같다는 한 줄) → 「먼저 볼 항목」 카드(practice 또는 checking+틀림, 최대 3, 각 「연습하기 →」) → 항목 행(칩 3칸 유지 + 부제 한 줄로 Core 상태: 「먼저 보기 · 틀림 1」 「확인 중 · 맞음 1」 「도움 받음」 「다시 확인할 때 · 10월 10일 혼자 해냄」) → 근거 펼침(유지) → 예상 급수 칸.
- 예상 급수 칸: 연습이 없는 동안 막대 없이 「TOPIK 형식 연습은 준비 중이에요」 한 줄. 연습이 열리면 「근거 n/30 · 듣기 a/10 · 읽기 b/10 · 갱신 10월 20일」. 범위를 보일 때는 「1급 근처 · 근거 32문항 · 10월 20일 · 바뀐 이유: 읽기 10문항이 더해졌어요 · PBT 기준」(DET식 범위 + 산타 불만 해소).
- 상태: 처음(모두 아직 → 진단 권유) / 근거 부족(checking만 → 「확인 중 n개」) / 약점 있음(「먼저 볼 항목」 카드가 맨 위) / 오래됨(review → 부제 「다시 확인할 때」, 칩 색만 다르게; 3칸 합계는 결정대로) / 목표 근처(영역마다 혼자 해냄 ≥5 → 「TOPIK 형식 연습으로 확인할 때」).
- 문구 원칙: 횟수·날짜 같은 사실만, 능력·성격 단정 없음(기존 원칙 유지).

### 4) 오늘의 처방(홈 카드)
- 구성: 튜터 한마디(유지) + **이유 한 줄을 보이게**(`.home-tutor-context` 표시) + 「맞춤 연습 시작」 + 「다른 것 고르기」 칩 2개(그중 1개는 다른 영역) + 분량 「5문항 · 3분」.
- 처방 규칙: Core 순위를 쓰되 같은 tier에서는 목표 급의 약한 영역 우선·영역 번갈아(듣기 다음엔 읽기). Core에 영역 균형 설정을 더하는 것이 정석이고(`recommendActivities` 정렬에 영역 항, 시험 포함), 급하면 WORLD 층의 작은 규칙(이어 하기·한글 선행과 같은 자리 `world-learning-plan.mjs:188-197`)으로 시작한다.
- 상태: 처음(「짧은 진단부터 3분」) / 진행 중(이어 하기 우선, 유지) / 근거 부족(「확인 중인 항목을 짧게」) / 약점 있음(먼저 볼 항목 + 이유) / 목표 근처(「TOPIK 형식 연습 10문항」) / 소리 없음(읽기 + 「소리를 못 쓰는 날이라 읽기로 골랐어요. 듣기가 약하다는 뜻은 아니에요」).
  - 예: 「읽고 이유 이해하기를 어제 2번 놓쳐서 오늘은 여기부터.」 「고른 목표(TOPIK I)와 이어지는 연습이에요.」

### 5) 결과·진행(활동 뒤)
- 구성: 이번 혼자 맞힘·도움·틀림 수 → 바뀐 칸 한 줄(「듣고 세부 정보 찾기: 확인 중 → 혼자 해냄」) → 틀린 것 해설 → 다음 한 걸음(처방 카드로) → 보상(코인 잔액 표시·옷장 연결; 생활 레슨 완료 보상 추가).
  - 예: 「오늘 혼자 맞힌 새 문항 6개. 읽고 이유 이해하기가 ‘연습 중’에서 ‘확인 중’으로 올라왔어요.」
- 읽기 짧은 연습의 실행기는 진단 실행기(`createDiagnosticSession`·`renderDiagnosticItem`)를 재사용하고 답마다 정답·해설만 더한다 — 새 게임을 만들지 않아도 읽기 처방이 돈다.

### 6) 다음에 다시 오게 하기
- 알림은 결정대로 주 1~2회·학습 일만: 「다시 만날 표현이 돌아왔어요」 「읽기 새 문항 5개가 준비됐어요」. 시험일을 적은 학생은 2주 전·1주 전 「TOPIK 형식 연습으로 확인해 볼까요」를 그 두 번 안에서.
- 앱 안: 「어제/지난번」 인사 유지 + 돌아온 날 첫 줄은 「바뀐 것 하나」(복습 n개 도래, 새 문항). 연속 기록·에너지 없음(Duolingo 에너지 반발 사례).
- 가져올 것: 목표 급·시험일 계획(Migii·MyTOPIK), 틀린 영역 추가 연습(LingoDeer), 범위 표시(DET), 공식 TOPIK Basic의 성취 구간 설명문(입문 결과). 피할 것: 기출 사용, 실시간 예상 점수, 「AI가 선생님을 대신」 메시지, 음성 인식 실패를 약점으로 세기.
