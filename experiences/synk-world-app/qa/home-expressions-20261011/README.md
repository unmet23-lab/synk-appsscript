## 실제 확인한 흐름

기존 `life-tutor.mjs`는 축하나 깜빡임 중 화면을 비활성화하면 복귀 타이머만 취소하고 얼굴을 남겼다. 특히 움직임 감소 상태에서는 다시 활성화해도 기본 얼굴로 돌아오지 않았다. 화면을 멈추거나 다시 시작할 때 기본 얼굴·몸 반응을 함께 정리하도록 수정했다. 열린 도움/연습 중에는 자동 깜빡임을 쉬고 닫으면 재개하며, 운영체제의 움직임 감소 변경도 반영한다. 세 마스코트 정본·대사·학습 기록은 유지했다.

- 새 격리 게스트에서 튜터 선택 → 홈 인사와 자연 깜빡임.
- 생활 한국어 첫 문제의 실제 오답 → 홈 기억 추천 → 다른 상황 재연습의 오답/정답 → 홈 축하 → 기본 표정 복귀.
- 오늘 돌아보기 열기 → 오늘 마무리 축하 → 닫기 → 다시 열기·재방문. 돌아보기 종료 뒤 모달은 제거되고 홈 튜터는 하나만 남았다.
- 깜빡이는 순간 놀이 패널 또는 오늘 돌아보기에 들어갔다 돌아오면 즉시 기본 표정으로 복귀한다.
- 390×844, 320×568, 844×390에서 홈·돌아보기와 가로 넘침/제목 위치를 확인했다. 별도 1440×900 실제 fine-pointer 컨텍스트에서 인사·깜빡임도 확인했다.
- 홈에서 자연 발생하지 않는 놀람·민망·으쓱은 `explicit` 파일명으로 구분해 동일 홈 portrait에 sprite만 지정했다. 이것을 자연 행동 검증으로 세지 않는다.

## 시각 비교와 판정 범위

동일 sprite의 **양눈 타원 ROI**를 실제 마스크 화면과 마스크를 제거한 화면에서 비교했다. 최종 최대 RGB 채널 차이는 **2/255**, 기준은 2 이하다. 미간·주변 털·얼굴 전체까지 일치한다는 판정은 아니다. 몸 하단 28%를 기본 몸 렌더와 비교한 최대 차이는 **1/255**였다. 정적 픽셀 비교 때만 뒤쪽 마루 영상을 정지해 투명 외곽에 영상 움직임이 섞이지 않게 했다.

실제 축하를 누른 뒤 애니메이션을 허용한 page screenshot으로 중간 프레임을 캡처했다. `*-0ms/80ms/180ms/350ms/700ms/1100ms`는 JavaScript 시험 시계의 누적 진행값이며 정확한 촬영 경과 시간은 아니다. CSS 애니메이션의 `currentTime`과 실행 상태는 보고서 `frames`에 별도로 기록했다. 마린의 눈 밝기 반응, 까몽의 약한 회전, 몽글의 짧은 점프가 실행되는 구간이 모두 포함되어 있다.

직접 본 최종 홈 축하·돌아보기·깜빡임 확대에서 눈 잘림, 기본 눈의 흰 테두리 비침, 얼굴과 몸의 분리, 몸 재질 밝기 튐은 발견하지 못했다. 몽글은 웃는 자수 눈과 점프 후 기본 복귀가 자연스럽게 이어졌으며 320 화면 돌아보기에서도 얼굴과 제목이 함께 보인다. 마린의 꽃 모양 눈웃음과 렌즈 밝기, 까몽의 스티치 눈웃음은 기존 승인 표현을 유지한다.
