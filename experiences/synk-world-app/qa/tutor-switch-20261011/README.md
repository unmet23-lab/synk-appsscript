## 발견한 문제와 반영

교체된 새 튜터가 어제 다른 튜터와 했던 연습을 자신의 경험처럼 말하는 문구를 읽기 검토에서 발견했다. 기존 guided 기록에 있는 `tutorId`를 하루 기록의 표시값에 전달하고, 실제로 함께한 튜터가 다르면 그 이름을 말하도록 `home-tutor-days.mjs`와 `home-tutor-lines.mjs`를 수정했다. assisted 기록처럼 누구의 도움인지 알 수 없으면 “도움과 함께”로 표현한다. 하루 마무리 후 교체 인사도 이미 끝난 학습을 새 튜터가 함께했다고 단정하지 않게 바꿨다.

| 상황 | 수정 전 | 실제 최종 화면 |
|---|---|---|
| 마린과 연습한 다음날 까몽 선택 | “어제 … 나랑 같이 봤지?” | “어제 「주스는 품절이에요.」, **마린과 같이 봤지?** 오늘은 네가 먼저 골라 봐. 이 몸은 여기 있을게.” |
| 하루 완료 후 까몽으로 교체 | “오늘 기록은 이 몸과 다 봤지.” | “오늘은 마무리까지 했군. …푹 쉬어. 더 하고 싶으면 이 몸도 같이 가 줄게.” |
| 완료된 하루의 돌아보기 | “이 몸과 오늘도 해냈군.” | “오늘 기록을 다 확인했군. …이 몸도 네 끈기는 인정하지. 푹 쉬어!” |

저장 스키마와 진도 쓰기는 바꾸지 않았다. 실제 브라우저에서도 교체·기억 읽기 전후 학습 snapshot이 동일하고 이전 guided 기록의 튜터가 그대로 보존되는 것을 확인했다.

추가로 다음날 기억 안내와 홈 버튼의 연결을 [별도 6개 검사](recall-action/report.json)로 확인했다. 실제 버튼 textContent와 추천 label은 모두 **“오늘의 복습 시작”**, kind는 `recall`, command는 `review`였고 16초 정기 갱신 뒤에도 일치했다. 직접 눌러 복습 소개와 실제 전이 문항까지 들어갔다. [버튼 확대](recall-action/next-day-action.png)와 [실제 복습 문항](recall-action/actual-review-question.png)을 확인했으며 “학습 시작”으로 잘못 연결되는 문제는 재현되지 않았다. 제품 수정은 추가하지 않았다.

## 검증 범위

- 교체마다 홈의 선택 ID·프로필·기억 안내가 현재 튜터와 일치한다. 홈 대사는 `homeTutorLine`의 현재 기록 기반 결과와 정확히 비교했다.
- 생활 한국어는 실제 첫 오답을 남기고 두 번째 문항에서 도움을 본 상태로 재개했다. 도움 대사와 이전 표현의 재연습 오답 대사를 `lifeTutorLine`과 정확 비교했다. 기존 첫 답을 다시 채점하지 않았다.
- 카페는 품절 메뉴를 잘못 주문한 repair 상태에서 재개했다. 실제 재확인 반응·재연습 오답·재연습 성공 모두 새 튜터 ID와 대사를 사용했다. 첫 오답·도움 여부·주문 단계는 그대로다.
- 다른 카페 방문에서 실제 선택한 **화분 옆 자리**를 모든 교체 뒤 보존하고, 마지막 마린으로 실제 테이블 화면을 재개했다.
- 얼굴과 몸의 URL prefix가 매번 현재 튜터인지 확인했다. 재연습 오답/성공은 현재 프로필에 명시된 표정 파일과 버전 hash도 비교했다.
- 까몽 선택 후 확인 화면에서 최종 확정 없이 취소하면 마린 선택과 진도 전체가 유지됐다. 마지막 마린 선택은 새로고침 후에도 복원됐다.
- 오늘 완료 후 까몽 교체, 다음날 실제 저장소를 유지한 재방문에서 이전 마린과의 연습을 올바르게 언급했다. 날짜만 격리 시험 페이지의 시계로 하루 진행했다.
- 이야기 속 고정 배역은 바꾸는 대상이 아니다. 별도 AI 튜터 카드와 표현 연습 dialog를 비교했다.

390×844 로컬 Edge 화면을 직접 확인했다. 까몽 홈 안내, 몽글 생활 힌트·카페 재확인, 마린 재연습·보존된 화분 자리, 완료 후 까몽 안내와 다음날 기억에서 얼굴·이름·대사가 맞았다. 이 작업에서 전체 반응형·애니메이션 검사를 반복하지 않았으며 이전 [홈 표정 검수](../home-expressions-20261011/README.md)와 범위를 구분한다.
