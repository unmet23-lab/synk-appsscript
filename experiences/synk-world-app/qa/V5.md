# WORLD 그래픽 v5 · 2026-10-09

요청: 앞 작업을 이어서 하고 그래픽도 더 높인다. 사용자 선택인 **캐릭터 중심 홈·촉감 있는 3D·휴대폰 우선**을 유지했다. 이번에도 코드와 로컬 브라우저 범위다.

## 바뀐 화면

- 원경의 회색 반복 건물을 높이·깊이가 다른 70동의 도시로 바꿨다. 옥상 녹지, 강변 산책로와 계단, 교각·아치·난간, 세 겹의 산과 수목을 보완했다. 창문은 얇은 면, 수목·반복 구조는 인스턴싱으로 묶는다.
- 가까운 집에 주름진 리넨 커튼과 목재 격자, 종이등을 넣고 읽는 자리에 직조 러그·술·책 속지·도자기 받침을 더했다. 실제 화면에서 바닥에 묻힌 러그와 점처럼 보이는 화분 장식은 다시 수정했다.
- 직사광을 조금 낮추고 그늘의 반사광을 보완했다. 노을의 주황 반사를 완화하고 대기 안개를 조절했다. 글자 뒤 페이드를 좁혀 재질과 공간이 더 드러난다.
- 잎 끝만 아주 작게 움직인다. 그림자에도 같은 변형을 사용하며 움직임 감소·가려진 화면에서는 멈춘다. 새 후처리 패스나 실시간 조명은 추가하지 않았다.
- **가까이 / 기본 시점** 버튼을 추가했다. 드래그는 정원을 통째로 돌리는 대신 카메라를 움직여 실제 원근을 바꾼다. 가까운 시점에서는 제목을 숨기고 휴대폰 조작부를 위로 옮겨 얼굴과 옷감을 드러낸다. 놀이·사진·옷장 행동은 유지한다.
- 시간·차림 재조회로 사용자가 돌려 놓은 카메라가 정면으로 초기화되던 동작을 독립 코드 검토 후 수정했다.

캐릭터의 승인 얼굴·실루엣·아바타 재질과 서버 아이템 ID는 바꾸지 않았다. `graphicsVersion:3`와 기존 모듈 경로는 호환을 위해 유지하며 `visualRevision:environment-v5`로 구분한다. [v4 정적 GLB/Blender 후보](../../synk-world-home/scene-assets/graphics-v4/README.md)는 그대로 유효하다. v5 환경 전체를 Unity 자산으로 내보낸 것은 아니다.

## 비용과 경계

같은 아바타·기본 시점·선명도·뷰포트의 v4 기록과 비교하면 PC 전체 삼각형 246,708→258,724, draw call 156→166이다. 휴대폰 크기는 202,020→209,740(약 3.8%), draw call 128→132다. 기본 휴대폰 DPR 최대 1.5와 그림자 1024, PC DPR 최대 2와 그림자 2048, 3M 픽셀 상한을 유지했다. [현재 캡처 수치](../../synk-world-home/qa/graphics-v5/capture.json)와 [v4 수치](../../synk-world-home/qa/graphics-v4-environment/capture.json)를 구분한다. CPU 제출 시간은 병행 작업의 영향을 받으므로 GPU 성능·실제 FPS 개선으로 보고하지 않는다.

4296의 사용자 계정 자료는 초기화하지 않았다. 합성 계정/복구 검사는 기존 QA 데이터의 별도 4396 서버, 보상 검사는 일회성 격리 데이터와 HTTP 서버를 사용했다. 이번 작업에 새 이미지 생성·다운로드·유료 호출·공개 배포·Unity 설치는 없다.

## 실제 미니게임 보상은 다음 계약이 필요하다

이 절은 10월 9일 v5 로컬 시점의 제약과 후속 후보를 보존한다. 이후 공통 게임 계정·코인·구매품 연결은 [운영 결과](../../beginner-games/qa/account-sync/README.md), 현재 제품 범위는 [제품 README](../README.md)에서 확인한다. 아래 후보를 현재 구현이나 새 실행 지시로 간주하지 않는다.

이번에는 지급 코드를 임의로 붙이지 않고 현재 서버가 바람길/리듬 완료 요약·점수·소유자 바꾸기·타계정 run을 거부하고 동시/재전송을 한 번만 반영하는지 검사했다. **현재 공통 코스튬 보상은 여전히 시험용 3문항 놀이에 연결돼 있다.**

바람길은 Atlas가 문항·속도를 바꾸고 물리가 가변 시간 간격으로 진행된다. 서버에는 고정 3문항 SQL 제약과 계정당 active run 하나, 요청 fingerprint 8KB 제한이 있다. 최소 후속 작업은 다음과 같다.

1. 서버가 보상용 코스 seed·문항순서·속도 규칙과 run을 발급한다. `korean-runner/app.mjs`의 시작·완료·입력 및 `core.mjs`를 서버와 재생 가능한 순수 규칙으로 나눈다.
2. 고정 tick 입력을 재생해 완료·충돌·자동모드와 정답을 서버가 다시 계산한다. 입력 재현은 정합성 검사이며 사람이 직접 플레이했다는 증명은 아니다.
3. `SYNK-talk/lib/world-v1-server.js`의 계정 잠금·완료·영수증 transaction을 재사용해 아이템을 한 번만 지급한다. 기존 migration 대신 후속 migration으로 새 run 계약을 넣는다.
4. 계정별 미전송 영수증, 중단·만료·재시작, 로그아웃 격리를 함께 연결한다.

최종 몽글 리깅·의상 가림·거리별 LOD·URP 재질 이식과 S25/iPhone 15의 장시간 발열/터치 검증도 남아 있다. 이번 결과는 그래픽 발전본이며 최종 품질 승인 또는 레이싱 이상 달성 판정이 아니다.
