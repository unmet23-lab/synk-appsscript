## 저장 범위와 남은 확인

이 절의 튜터 선택 기기 저장은 10월 12일 최초 설치·검증 당시의 범위다. 같은 날 이후 [튜터 선택 계정 저장과 웹↔PC 실제 확인](../tutor-selection-20261012/README.md)에서 선택 동기화를 추가했으므로, 아래를 현재 저장 범위로 해석하지 않는다.

튜터 선택·안내 연습 기억은 **이 기기에서 계정별 저장**이다. 브라우저와 PC 앱 사이 또는 다른 기기로 선택 튜터가 동기화되는 기능은 아니다. 생활 학습 완료·표현·복습 일정은 **SYNK 계정 서버 저장**이다.

최초 실제 계정 로그인·완료·재로그인 검사는 Chrome의 공개 WORLD에서 수행했다. 이어 이 PC의 설치된 WORLD 0.4.2에서도 정상 UI로 계정 복원 → 까몽 선택 → 로그아웃 → 동일 계정 로그인까지 확인했다. 로그아웃 시 0/22와 튜터 미선택으로 분리됐고, 재로그인 후 까몽·완료 1/22·오늘의 표현 3개·다음 학습 「이름표를 찾아서」가 복원됐다. 생활 화면에서도 「첫 인사 세 마디」 완료와 SYNK 계정 저장 상태를 확인했다. [실제 PC 관찰과 화면](native-real-account/observations.json), [재로그인 홈](native-real-account/after-relogin-home.png).

PC의 튜터 선택은 로그인 완료 후 직접 선택했다. 브라우저 선택이 PC로 동기화된 것으로 해석하지 않는다. 개인 프로필·토큰을 읽거나 디버거로 주입하지 않았고 실제 게임 완료의 서버 저장, 다른 실물 PC·휴대폰은 별도 확인 범위다. 위의 까몽 PNG는 격리 PC 검사, `native-real-account/`의 PNG는 이번 실제 설치본 검사다.

실제 PC 로그인 완료 뒤 로그인 안내창이 남는 문제를 발견해 `restoreConnectedHome`에서 검증된 계정 복원이 끝나면 현재 로그인 안내창만 닫도록 고쳤다. 도중에 계정이 바뀌거나 다른 화면으로 이동했다면 닫지 않는다. 공개 `24c360f2259142dd4a67d34fb031c6605e2125ed`의 `world/app-shell.mjs` 한 파일만 갱신했고 [HTTPS 바이트](native-real-account/public-http.json), [Pages·공개 CI 성공](native-real-account/public-checks.json)을 확인했다. 관련 계정·문서 검사 18/18과 별도 코드 검토도 통과했다.

마지막 설치본 확인은 중간에 사용자 Esc로 멈췄다가 후속 요청으로 재개했다. 앱 완전 종료·재실행 후 까몽과 1/22가 유지됐으며, 다시 로그아웃·동일 계정 로그인 후 안내창이 자동으로 닫히고 까몽·완료 1/22·오늘의 표현 3개·「이름표를 찾아서」가 복원됐다. 이때 안내창 닫기를 직접 누르지 않았다. 설치 파일을 추가 교체하지 않았고 기존 0.4.2가 갱신된 공개 화면을 사용했다. [최종 실제 PC 화면](native-real-account/postfix-relogin-home.png).

TOPIK 관련 구현 범위는 인사·감사·자기소개 표현을 상황에 맞게 선택하는 기초 한국어 연습이다. 실제 학습자 효과나 시험 점수 향상은 확인하지 않았다.
