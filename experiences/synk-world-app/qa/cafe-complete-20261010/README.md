## 완료된 흐름

- 음료·온도·수량의 12조합 → 문장/컵/얼음/잔 수 변경 → 실제 최초 주문 조합 기록 → 잘못 주문한 내용 수정 → 직원의 수량 확인 → 매장 이용·자리 → 명시적 수령.
- 일부만 고른 주문, 듣기 완료 여부, 글자 도움과 주문 수정/수령 상태를 저장한다. 세 문항을 마쳤어도 받기 전에는 완료가 아니다.
- 듣기 모드는 질문 글자를 숨기고 실제 재생 종료 후 응답을 연다. 회전 중 재생은 이어지고 일시정지는 같은 음성 위치에서 재개한다. 단위 시험은 화면 숨김·질문 변경·계정/화면 종료의 이전 콜백 폐기도 확인했다.
- 음성 요청 실패를 실제 브라우저에서 주입했다. 미청취 상태로 완료를 만들지 않고 새 오디오로 재요청했다. 은행 목록이 준비되지 않았을 때도 기존 듣기 진도를 유지하며 명시적 글자 도움을 제공한다. 그 응답은 `heard:false/textShown:true/helped:true`로 남는다.
- 기존 21레슨/복습의 의미·ID는 [이전 서명](previous-lessons.json)과 일치한다. 저장 키/진도 판 1은 유지하고 새 직접 주문의 내부 체크포인트만 판 2다. 기존 계정 지갑·보유품·타운 권한은 바꾸지 않았다.

## 음성 경로와 확인 범위

사용자가 **Typecast 하나, 직원 15줄, 기존 월 제공 크레딧 최대 329, 추가 결제/충전 없음**을 승인했다. 기존 음성 도구의 요청/캐시/잔량 보호를 사용했고 캐시를 재사용했다. 최초 새 요청 293자·수량 질문의 쉼 보강 17자, 합계 310자로 상한 안이다. 미니게임 원고·배역을 수정하거나 다른 게임에 들어 보기 파일을 적용하지 않았다.

- [첫 대본](staff-lines.json) · [첫 계획](voice-plan-r1.json) · [생성 요청](voice-generation-request.json) · [수량 질문 보강 요청](voice-clarity-generation.json) · [최종 경로/설정/원본](staff-voice-sources.json).
- 15개·650,100바이트, MP3 모노 24kHz 96kbps, 메타데이터 제거, 완전 디코딩·길이/피크/형식 검사. 생성 경로·제작 도구·음성 ID는 내부 QA에만 둔다. 공개 후보에는 파일/글/길이/SHA만 들어간다.
- 최종 파일을 이미 캐시된 두 로컬 음성 인식 모델로 대조했다. 숫자로 인식한 `2잔`과 한국어 `두 잔`만 정규화하며 현재 SHA가 맞는 결과를 사용한다. 최초 짧은 수량 확인이 `2점`으로 인식되어 쉼을 보강했고 최종 파일은 `두 잔`으로 대조되었다. [처음 인식](speech-transcription-r1.json) · [최종 전체 인식](speech-transcription-small.json).
- 자동 인식/디코딩/재생은 사람의 귀로 자연스러움·억양을 승인한 결과가 아니다. 직접 소리를 들었다고 보고하지 않는다. 교원의 난도·발음 판단과 실제 학생의 학습 효과는 미검증이다.

- 첫 후보 `r1`의 정적 참조 검사는 통과했지만 동적으로 여는 음성 폴더의 복사 필터가 전체 경로를 받는 것을 발견했다. 파일명 기준으로 고쳐 `r2`의 실제 계정 브라우저에서 음성 목록까지 확인했다.

- 캐시된 medium 음성 인식 모델은 가중치가 없어 사용할 수 없었다. 모델을 다운로드하지 않고 이미 있는 두 모델로 최종 대조했다. 해당 실패 로그도 보존했다.

현재 연결된 안드로이드 기기는 없었고 사용자도 **지금은 검수 기기 없음**으로 답했다. 공개 배포·운영 OAuth/원격 DB 왕복·실물 휴대폰/네이티브 설치본 성능·사람의 귀 승인·학생 효과는 별도다. 현재 연습은 단어 선택으로 주문 구성과 직원 질문에 대한 응답 선택이며 학생 음성 녹음/STT/발음 평가를 추가하지 않았다.

최종 재고정 `r3`은 동시에 추가된 홈의 튜터 복습 스타일/지원 모듈 3개도 포함한다. 원래 임시 연결 설정이 정리되어 앞서 검증한 고정 앱의 공개 설정을 다시 검증해 사용했다. 최신 계정 브라우저 26항목과 카페 소스/음성 해시를 다시 확인했다.

## 사용자 요청으로 커밋·종료

2026-10-10 사용자 「커밋하고 종료해줘」에 따라 오프닝·마루·생활/카페 구현과 관련 검수·동봉 음성을 보존한다. 공용 파일의 별도 옷장·튜터 변경은 작업본에 남기고 이번 연결만 부분 커밋한다. 기존 대용량 생성 원본·중간 후보와 다른 작업은 삭제하지 않는다. 공개 배포·푸시는 하지 않는다.

재개는 이 폴더와 [콘텐츠 계약](../../LIFE-CONTENT.md)에서 시작한다. 남은 확인은 실물 휴대폰/설치본과 사람의 귀로 듣는 억양·자연스러움이다. 사용자는 현재 기기가 없다고 답했다. 로컬 미리보기 서버와 사용자의 진행 기록은 유지한다.

커밋할 부분 스냅샷에서도 단위/로컬 SQL 57개와 계정 카페 브라우저 26항목을 다시 통과했다. [커밋 전 단위 검사](commit-close-unit-tests.txt)·[부분 스냅샷 카페 흐름](../cafe-pack-20261010/commit-close-static/report.json). 계정 응답은 앞선 검수와 같은 모의 공급자다. 함께 개발 중인 튜터·확장 옷장·타운 전체 배포 빌더와 대용량 생성 원본/중간 후보는 공용 작업본에 보존하고 이번 커밋 범위에서 제외했다.
