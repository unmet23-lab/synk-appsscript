# SYNK WORLD 작업 종료 · 2026-10-09

사용자 요청: 이번 작업을 푸시하고 종료한다. 운영 배포·DB 적용·앱 설치·스토어 제출은 이번 종료 범위가 아니다.

## 이번에 보존한 작업

- 휴대폰·PC 홈, 첫 진입·시험 계정·보상·옷장·사진, 타운 연결을 `../synk-world-home`과 이 폴더에 보존했다. 한강의 배와 근경 마감까지 반영한 최신 검수는 [V8](qa/V8.md)이다. 그래픽 방향 채택과 최종 품질 만족은 구분한다.
- 공통 서버 계약의 코드·브라우저 검증용 백엔드는 형제 저장소 `SYNK-talk`의 `lib/world-v1-*`, `tools/world-v1-*`, WORLD 함수·마이그레이션·관련 시험에 있다. 실제 SYNK ID와 운영 DB에 적용한 결과가 아니다.
- [Unity 프로젝트](../../unity/SynkWorld/README.md)는 코드 준비 단계다. Editor 의미 컴파일·네이티브 렌더·Windows/Android/iOS 실행과 기기 검증은 남아 있다.
- [정시 버스](../../docs/마을_설계.md#town-bus), [지역 전용 재료](../../docs/디자인/싱크타운_생활경제와_상품_설계.md#regional-materials), [펫](../../docs/마을_설계.md#town-pets), [생활 비서](../../docs/마을_설계.md#world-life-assistant), [낚시](../../docs/마을_설계.md#town-fishing)를 설계했다. 세 콘텐츠는 사용자 요청대로 설계만 진행했으며 새 실행 코드·자산을 만들지 않았다. 종·수치·가격·출시 편성은 제안/미정이다.

## 다시 시작할 위치

1. 홈·공통 그래픽: [실행 안내](README.md), [V8 검수와 남은 범위](qa/V8.md). 정식 캐릭터·리깅·코스튬 가림·URP 이식과 Galaxy S25/iPhone 15의 지속 성능을 확인한다.
2. 보상·앱: [실제 미니게임 보상 연결의 남은 계약](qa/V5.md#실제-미니게임-보상은-다음-계약이-필요하다). 합성 시험 계정의 첫 참여 선물을 실제 게임 완료 보상으로 확대해 보고하지 않는다.
3. 여행·생활 확장: [확장 제작 순서](../../docs/디자인/싱크타운_출시와_후속콘텐츠_편성.md#pet-assistant-fishing). 구현 승인 뒤 비서 기본 안내, 펫 한 종의 집/산책, 낚시 한 자리의 조작/놓아주기/기록, 버스의 임시 목적지 왕복을 각각 독립적으로 검증한다.

공용 작업본의 다른 세션 수정과 미푸시 커밋은 보존한다. 공유 설계 문서는 이번 추가 범위와 필요한 조작 계약을 분리해 저장하며, 타운 담당 세션의 전체 출시 원고·구현 준비 초안을 대신 완료하거나 배포하지 않는다. 로컬 DB·인증 자료·의존성 설치본·동영상 사본은 Git에 넣지 않는다. 노래 영상은 기존 `prepare-assets.cjs`와 `asset-sources.json`의 원본 위치에서 준비한다.
