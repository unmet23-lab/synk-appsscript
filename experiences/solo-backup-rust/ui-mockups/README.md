## 1. 두 시안 — 뼈대가 다르다

| | A 확인서 | B 눈금 |
|---|---|---|
| 무대(DESIGN G02) | 곧은 종이 「보호 확인서」 한 장 — 마지막 확인 · 지키는 폴더 · **되살려 본 날**이 찍혀 있고, 밑에 지난 장들이 겹쳐 있다. 상태 도장(잉크가 고르지 않게 찍힌 결)은 늘 확인서 끝에 | 지난 7일 × 24시간 눈금 — 켜져 있던 시간마다 한 칸, 쉰 칸은 짧게, 꺼져 있던 시간은 점, **되살려 본 칸**은 길게 |
| 겹(위 → 아래) | 위 막대 → [왼쪽] 상태 한 줄 · 큰 제목 · 뜻 한 줄(확인서에 적힌 시각은 되풀이하지 않는다) · 채운 알약 「파일 되살리기」 + 밑줄 글자 「새 PC로 옮겨 오기」(드문 일) / [오른쪽] 회색 책상 위 종이. 좁은 창에서는 확인서를 요약해(폴더 줄 · 뒷장 숨김) 되살려 본 날 · 도장까지 첫 화면에 | 위 막대 → 상태 한 줄 + 읽음값 + 오른쪽 세 줄(위아래 선이 맞는다) → (확인할 일이 있으면 띠) → 시간 눈금 → 할 일 건반 둘(채운 건반 + 선 건반, 위와 같은 7 : 5). 좁은 창에서는 건반이 눈금보다 먼저 |
| 흐름 화면 | 같은 펼친 두 쪽 — 고를 것 · 대조할 것은 늘 오른쪽 종이(옮겨 놓이는 도식이 든 고르는 종이 두 장, 목록 안에서 더하는 보호 범위, 장부, 확인서, 인쇄할 복구 코드). 진행은 제목 옆 네 칸 | 단계 눈금 → 제목(결정을 돕는 숫자가 있을 때만 큰 숫자) → 자료 판 → 창 바닥에 붙는 결정 막대 |
| 바탕 · 글 | 흰 종이 + 중성 회색 책상(크림 · 베이지 없음), 검정 글. 숫자 · 글이 든 종이는 기울이지 않고 빈 뒷장만 기운다 | 근사 검정, 흰 글. 밤 · 낮 판은 고른 뼈대에 둘 다 붙일 수 있다 |
| 포인트 색(한 자리) | 도장 하나 — 기본 화면의 낱말은 안전(메도우 그늘) · 주의(버터 그늘) · 경고(코랄 그늘) · 옮김 넷으로 고정(「확인」 도장은 「확인함」으로 읽혀 뺐다), 흐름 화면은 일의 이름(대조 끝 · 되돌림 · 신고). 테두리 글은 늘 「업무 백업 · 보호 확인」이고 뜻은 확인서 줄에 둔다. 도장 없는 흐름 화면은 그래프 막대나 결과 한 줄 | 상태 한 줄 + 같은 뜻의 눈금 칸(안전이면 「되살려 봄」 칸, 지워짐이면 그 시간 칸). 큰 숫자 · 띠 · 꼬리표는 잉크 |
| 주인공 글자 | 56 · 600 한 문장(「안전합니다.」) | Inter Tight 168 · 500 읽음값 「14시 02분」(단위는 작은 회색 글 — 시계가 아니라 기록으로 읽히게). 도는 중이면 진행률, 한꺼번에 지워지면 지워진 수 |
| 움직임 | 확인서가 아래에서 올라와 놓이고 도장이 한 번 찍힌다(열 때 한 번) | 눈금이 왼쪽부터 자란다(열 때 한 번), 도는 중 점만 깜박 |
| 시간 표기 | 오후 2:02 | 14:02 |

같이 쓰는 것: SUIT(줄인 판 이름 SYNK Sans) + 숫자 Inter Tight, 크기 13 · 15 · 17 · 22 · 34 · 56(+ 주인공 숫자), 굵기 400 · 600 · 700, 영문 대문자 꼬리표 · 모노 눈썹 없음, 주 행동 알약 한 화면에 하나 + 선 알약 + 밑줄 글자, 위 막대 단추는 테두리 있는 작은 글자 알약(「설정」 · 「뒤로」 · 「닫기」), 화살표는 긴 선 하나, 문장을 줄표로 잇지 않는다. 계정 주소는 정체를 밝혀야 하는 자리(설정 서랍 · 복구 코드 · 웹 기기 카드)에만. 기본 화면에 restic · 스냅샷 · 버킷 · 출입증 · 저장소 · pack · prune이 없고(설계 T18), 시범 측정 한 줄은 첫 화면 아래 · 보호 범위 확인 · 설정 서랍에만 있다(4.9 · 4.12). 그래프는 0부터 세는 양이라 빗금 막대.

참고한 것(원리만 — 남의 화면은 저장소에 넣지 않는다): Ramp 「가장 지루한 확인을 화면이 대신 · 큰 숫자 하나 + 색 하나」, Paper 「가는 제목 + 회색 둘째 줄」, Nothing 「숫자 · 상태를 계기처럼」, Linear 「첫 화면이 곧 제품 화면 · 색은 결정에만」, Recent 11-10 「구겨지는 영수증 · 증서 · 눈금 하나하나가 해인 시간축」, Recent 11-13 「Prefer — 큰 글을 검정 · 회색 두 단으로」.

## 5. Tauri로 옮길 때

- 고른 판의 뼈대 · 글 · 값을 그대로 옮긴다. 0.5.0 `experiences/solo-backup/ui/`의 겹(탭 · 카드 쌓기)은 남기지 않는다.
- Tauri CSP(`default-src 'none'; script-src 'self'; style-src 'self'`)라 이 시안의 인라인 `<style>` · `<script>` · `style=""`은 파일과 클래스로 옮기고, 글꼴은 로컬 woff2로 싣는다.
- 화면 글 검사(T18)는 기본 화면 여섯 상태(`home*`) 전부에 건다.
- 움직임은 열 때 한 번과 누를 때뿐이고, Windows 「애니메이션 효과」 끔(`prefers-reduced-motion`)에서는 멈춘다.
- 날짜 · 시각 · 남은 날은 실제 값에서 계산한다(마감일은 T + 29일, 요일은 날짜에서).
- 넓은 창에서는 왼쪽 면(글 · 할 일)을 창에 붙이고 오른쪽 종이만 길어지게 하고, 높이 860 아래(기본 창 820)에서는 여백 · 제목을 줄인다 — 시안의 두 규칙 그대로.
- 시안에는 입구만 있는 것: 「복구 코드로 되살리기」 입력(파일 열기 · 글자 넣기), 「붙들어 둔 판에서 꺼내기」 목록(붙들어 둔 판이 있을 때만 — 지난 판을 고르는 목록은 유료 구간 후보라 기본 상품에 그리지 않는다, 결정 11-12), 되살릴 「자리 바꾸기」, 「지금 한 번 더 백업」의 진행, 「지워진 3,980개 보기」 목록, 복구 코드 「글자 보기」 · 다시 깔 것 「인쇄」. 옮길 때 같은 뼈대로 그린다.
- 아직 없는 화면(Fable F3 · F26 · F33 · 다시 확인 R2): 웹 — 「끊기」를 누른 뒤 남은 Google 걸음(`lost-2`의 종이 · 걸음 그대로)과 휴대폰에서 여는 분실 신고(남은 기기가 없을 때 신고 → Google 걸음 → 새 PC에서 이어 감 — 설계 2.4-1 · 2.4-5, PC 한 대뿐인 손님에게는 이 길 하나뿐), 새 PC의 갈래 「이 계정에 백업이 있습니다」(옮겨 오기 / 파일이 그대로 남은 PC / 사고 전으로 되돌린 뒤 옮겨 오기 — 설계 2.3), 증명 줄의 다른 결과(「23개 가운데 21개 같음 · 2개는 그 뒤 고쳐 견주지 못함」 · 표본 없음 — 4.7), 설정 › 내 기기(「나머지는 필요 없음」 · 다른 기기 분실 신고 입구), 손상 확인 화면, 용량 화면, 되돌린 뒤 멈춘 기본 화면. 옮길 때 이 넷 이상을 같은 뼈대로 먼저 그려 뼈대가 새 상태를 받는지 본다. 끊은 뒤 다시 깔 것 목록을 어디서 다시 여는지도 그때 정한다.
- 설계에 넘길 문장(설계 문서 주인 몫): 4.8에 「메일 링크의 「모르는 기기 끊기」는 분실 신고와 같은 처리(쓰기 · 읽기 출입증 즉시 삭제, 전에 받은 복구 코드 못 씀)」 한 줄(웹 화면이 그렇게 적는다), 4.12 「한 화면에 … 만」을 「… 와 그 증거(확인서)만」으로. 앞 줄이 「끊기는 쓰기 연결만」으로 다르게 정해지면 웹 화면의 「전에 받은 복구 코드도 쓸 수 없게」와 상자의 「새로 맡길 복구 정보」도 같이 고친다 — 옮길 때 Fable 검수는 이 줄부터 본다(다시 확인 R3).
