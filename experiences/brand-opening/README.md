# SYNK 공통 브랜드 오프닝 — Omni v9

2026-10-10 현재 웹 적용본은 **새 Omni v9 영상에 배경 고정 마감을 한 버전**이다. 사용자가 v6의 전체 화면 떨림을 지적하고 새 생성·검수·적용을 요청해 교체했다. 회사 로고 2.6초 뒤 세 친구와 한국 풍경의 영상으로 이어진다. 화면 전체 터치/클릭으로 시작하며, 작은 안내·소리 아이콘·© 2027 SYNK는 유지한다. 공개·설치형 배포는 하지 않았다.

## 현재 영상과 마감

Google Cloud `gemini-omni-1.1-flash-preview`로 세로 1080×1920·가로 1920×1080, 각각 초기 최대 10초·24fps·240프레임을 새로 생성했다. 기존 배 없는 구도를 첫·끝 이미지로 지정하고 삼각대 고정·배의 오른쪽→왼쪽 이동·인물 형태 보존을 프롬프트에 명시했다. 새 원본도 배경에 미세한 떨림이 남아 **그대로 적용하지 않고 후처리했다**.

새 영상 자체의 첫 프레임에 화면을 정렬한 뒤 지붕·타워·도시·마루는 고정하고, 생성된 세 친구 전체 영역·물결과 배·하늘·잎·등 내부는 움직이도록 마감했다. 가로 영상의 날리는 잎은 밝은 끝과 모션블러까지 원본 영역으로 보존했다. 캐릭터 얼굴·머리·배를 각각 따로 붙이지 않았다. 확대·크롭·역재생·속도 변경·정지 꼬리 연장은 없다.

- 실제 웹 영상: `assets/world-menu-{mobile,desktop}-omni11-v9-web.mp4`
- 모션 감소용 포스터: `assets/felt-world-scene-{mobile,desktop}-v9.webp`
- 생성 원본: `raw/felt-trio-v9/{portrait,landscape}-omni11-1080p-v9.mp4`
- 마감 원본: 같은 폴더의 `*-v9-locked.mp4`
- 프롬프트·실제 모델·사용량: `raw/felt-trio-v9/omni.prompt.txt`, `*.job.json`
- 마감 코드: [lock-opening-background.py](processors/lock-opening-background.py)
- [시각 검수](qa/felt-v9/visual-review.json) · [출처·해시](asset-sources.json)

**10초 전체를 반복**하며 마지막 초에도 캐릭터·물결 움직임이 남는다. 몽글의 입과 마린의 새 검은 눈·속눈썹·이중 머리는 검수 표본에서 발견되지 않았다. 가까운 수목이 먼 배를 가리는 순서도 확인했다. 움직이는 펠트 결·물결·잎은 첫/끝에서 픽셀 단위로 일치하지 않으므로 완전 무결점 루프로 설명하지 않는다.

웹 사본은 마감 원본과 같은 해상도·프레임·속도의 H.264이며 배경 소리는 무음이다. 생성 원본의 자연음은 별도로 보존한다. 소리 아이콘은 기존 0.38초 회사 소리 후보를 켜고 끈다.

## 시작 화면 조작

사용자가 정리한 UI를 유지했다. ‘영상 멈추기’·‘바로 시작’·‘게임 스타트’는 없다. 화면 전체 터치/클릭 또는 Enter/Space로 시작하고, 가는 WORLD와 작은 부제·안내를 표시한다. 초기 자동 포커스 장식은 없고 키보드로 이동했을 때 표시한다.

오른쪽 위 소리는 기존 펠트 스피커의 켜짐·꺼짐 이미지와 48px 조작 범위, 상태별 접근성 이름으로 제공한다. 아이콘을 눌러도 게임은 시작하지 않는다. 모션 감소에서는 포스터를 유지하고, 탭을 숨기면 쉬었다가 복귀하면 재생한다. 실제 `playing` 이후 영상을 표시한다. 저작권은 **© 2027 SYNK**다.

## 검수 근거

고정 구조물 세로 7곳·가로 8곳을 **각 240프레임 전체**와 반복 경계에서 추적했다. 15곳 모두 프로젝트 기준(인접 이동 P95 ≤0.35px, 최대 ≤0.75px, 누적 이동 ≤1px, 유효 표본 ≥95%)을 통과했다. 고정 지점의 공통 인접 이동 P95는 세로 0.0062px·가로 0.0003px다. 이는 선택한 고정 배경의 측정값이며 움직이는 물체까지 멈췄다는 의미가 아니다. [세로 기록](qa/felt-v9/portrait/static-plate-web.json) · [가로 기록](qa/felt-v9/landscape/static-plate-web.json).

각 방향 21개 장면·얼굴·강 표본, 원본 해상도 경계, 가로 6.5초 잎의 3배 확대 대조를 독립 검수했다. 전 구간 디코드와 매초 움직임 검사도 통과했다. [시각 검수 범위와 한계](qa/felt-v9/visual-review.json).

현재 영상으로 실행한 [브라우저 검사](qa/felt-v9/browser-result.json) **100개 통과**, 정상 JS 오류·정적 자료 실패 0. 실제 소스·포스터, 네 화면 크기, 삭제 문구 부재, 소리 아이콘 독립 동작, 화면 전체·키보드 진입, 모션 감소, 앱 연결을 확인했다. [자연 반복 검사](qa/felt-v9/full-loop-playback.json)는 비율별 seek 없이 23.5초 재생해 **전체 반복 두 번씩 통과**, 45/45 측정 간격에서 프레임 변화를 확인했다. 영상/상위 화면의 위치·크기 변화는 세로 1,416회·가로 1,405회 측정에서 0px, 소스·변형·화면 크기 전환도 없었다. 브라우저 누락 프레임은 세로 1/569·가로 0/566이다. [모바일 실제 화면](qa/felt-v9/mobile390-title-minimal.jpg) · [PC 실제 화면](qa/felt-v9/desktop-title-minimal.jpg).

이번 실제 재생 검사는 Edge에서 수행했다. Codex 내장 브라우저는 탭 연결이 완료되지 않아 그 안의 v9 재생은 확인하지 못했다. 물리 휴대폰·공개 서비스·스피커 품질도 미검증이다.

이번 생성 작업의 기록 사용량 기준 예상 비용은 **약 $6.12**다. 폐기한 v7 두 건과 선택한 v9 두 건, 사용량이 기록된 실패 요청을 포함하며 실제 청구·크레딧 잔액은 미확인이다. [사용량별 계산과 공식 요금 출처](qa/felt-v9/generation-cost.json). 기존 이미지를 재사용했고 새 이미지 생성은 없다.
