## 게임 안에서 함께하는 튜터

2026-10-10 후속 요청. 고른 마린·까몽·몽글이 **바람길·말의 리듬·한글 만나기·첫 문장 놀이**까지 따라온다. 게임마다 캐릭터의 말투로 조작법 세 가지를 알려 주고, 실제 판정에 따라 얼굴과 말풍선이 바뀐다. 일반 박자·충돌 반응과 듣기 답의 판정을 구분하고, 답의 반응이 일반 노트에 즉시 덮이지 않게 했다. 반복 성공·재도전에는 다른 대사가 돌아온다.

- 마린은 짧은 수칙·확인 보고와 잠깐 밝아지는 렌즈, 까몽은 허세·으쓱함과 실토가 새는 재도전, 몽글은 호기심·감탄·같이 하자는 말로 반응한다. [말투 원문](../../docs/캐릭터/가이드_정본.md)과 기존 승인 표정/비언어 소리를 사용한다.
- 처음에는 아래 조작 연습으로 시작하고, ‘조작법’에서 설명을 다시 보거나 직접 다시 연습할 수 있다. 다시 보기에서 바람길은 모델/지시 음성, 말의 리듬은 공통 오디오 시계를 멈춘다. 설명만 닫으면 기존 ‘이어 하기’를 사용하며, 직접 연습을 마치면 같은 판으로 이어간다. 한글은 현재 문항과 재생 중인 글자 소리를 멈춘 자리에서 유지한다. 설명 확인은 현재 브라우저 세션의 계정/캐릭터/게임별로 나눈다.
- 기본 몸과 알파는 고정하고 얼굴만 바꾼다. 반응 → 기본 복귀·눈 깜빡임을 연결하며, 움직임 감소에서도 표정과 대사는 남는다. 소리를 켜도 실제 놀이 중에는 튜터의 비언어 소리를 쉬어 기존 나레이션을 가리지 않는다. 닫기·숨김에서 반응 타이머와 소리를 정리한다.
- 첫 문장 놀이는 서버가 종료 후 채점하는 기존 계약을 유지한다. 선택 때는 선택에만 반응하고, 결과의 ‘함께 답 확인하기’에서는 서버가 확인한 정답/오답에 반응한다. 바람길의 별도 ‘듣기 확인’에도 실제 답의 반응을 연결했다.
- `game-tutor.mjs`/`.css`가 동행 화면, `game-tutor-lines.mjs`가 게임별 대사, `game-tutor-channel.mjs`/`game-tutor-contract.mjs`가 프레임 연결이다. 같은 출처의 현재 프레임·게임·버전만 받아들이며 계정 정보·학생 식별자·채점 권한은 건네지 않는다. 기존 학습·보상 계약을 그대로 사용한다.

[게임 동행 검수와 화면](qa/game-tutors-20261010/README.md). 로컬 브라우저의 합성 입력·계정으로 확인하며 실물 휴대폰, 운영 선택 동기화, 유료 AI 대화·교정, 공개 배포는 별도다.

## 튜터와 직접 하는 조작 연습

2026-10-10 후속 요청. 처음 고른 게임에서 **튜터 시범 → 내 차례 → 직접 성공 → 본 게임 시작**으로 이어진다. 설명 확인만으로 다음 단계가 열리지 않는다. 연습장은 고른 튜터의 승인 몸·표정으로 이동과 입력을 보여 주며, 게임과 같은 키/터치 대응을 쓴다. 시범 중 입력과 중복 키 입력은 다음 단계로 넘어가지 않는다.

- 바람길: 왼쪽·오른쪽·점프·숙이기, 마지막에는 기존 짧은 MP3 부탁을 끝까지 듣고 움직인다. 화면 단추, 실제 키보드, 손가락 밀기를 지원한다.
- 말의 리듬: F/J·←/→·터치 단추, 소리 뒤 O/X 선택, 노트가 크림색 선에 닿을 때 누르기를 연습한다. 조작용 부탁 MP3를 재사용하며 본 게임의 채점 문항을 먼저 보여 주지 않는다. 이르거나 늦게 누르면 다음 노트에서 다시 시도할 수 있다.
- 한글: 승인된 글자 MP3를 듣고 아/어를 고른 다음 ‘다음’을 누른다. 소리를 불러오지 못하면 답을 열지 않고 다시 시범을 들을 수 있다. 기기 TTS를 새 연습에 추가하지 않는다.
- 첫 문장: 연습용 인사를 고르고 다음으로 넘어간 뒤, 원래 서버 문항으로 이어진다. 연습 선택은 서버 답으로 제출하지 않으며 실제 문장 정오답은 종료 후 서버 결과를 따른다.

마린은 수칙·확인과 숨은 칭찬, 까몽은 시범을 자기 공으로 돌리는 허세·으쓱함, 몽글은 감탄·공감·같이 하자는 말로 시범/오입력/성공을 다르게 반응한다. 기본 몸과 얼굴 컷을 분리하며 움직임 감소에서도 시범의 최종 자세·선 표시·대사는 남는다.

완료는 마지막 시작 단추에서만 `synk.world.tutor.practice.v1:<owner>:<tutor>:<game>`에 저장한다. 비회원/계정·튜터·게임별로 나누고, 중간에 나가면 완료로 쓰지 않는다. 저장이 막혀도 이번 페이지에서는 성공한 연습을 반복시키지 않는다. 조작법의 ‘직접 다시 연습하기’는 실제 진행을 멈추고, 진행 중이었다면 새 판을 만들지 않고 기존 판/문항으로 돌아온다. 입구나 종료 뒤의 연습은 본 게임 시작으로 이어진다. 닫기·숨김은 타이머·키 상태·소리를 정리하며 미완료 청취를 성공으로 바꾸지 않는다.

`tutor-practice-core.mjs`가 단계·입력·완료 저장, `tutor-practice.mjs`/`.css`가 시범과 연습장, `tutor-practice-lines.mjs`가 캐릭터 대사다. 학습 점수·급수·언어 평가·코인은 생성하지 않는다. [조작 연습 검수·화면·재현 명령](qa/tutor-practice-20261010/README.md).

## 게임 관찰에 따른 힌트와 어려웠던 곳 다시 연습

2026-10-10 후속 요청. 고른 튜터가 실제 게임 판정의 근거를 받아 **조작·타이밍·문장 뜻·응답 없음·소리 미확인**을 구분한다. 힌트가 있는 경우 게임 바의 ‘힌트’에서 최근 어려웠던 부분만 열 수 있다. 움직이는 중에는 짧은 대사로 반응하고, 자세한 문항 해설과 재연습은 실제 게임을 멈춘 뒤 연다.

- 바람길: Core의 `timing`은 동작 입력이 맞았지만 표시선에서 실행되지 않은 경우다. `different`/`missed`는 동작을 다시 확인한다. 달리기 수행만으로 한국어 문장을 오해했다고 판정하지 않는다. 일반 울타리/표지판/전차 충돌은 해당 조작을 안내한다. 별도의 듣기 확인에서 실제 틀린 선택은 원래 문장·고른 행동·맞는 행동·기존 교정 해설로 다시 연습한다.
- 말의 리듬: 실제 O/X 정오답과 노트의 타이밍 품질을 따로 받아들인다. 맞은 답의 박자 놓침은 문장 오답으로 바꾸지 않고, 문장과 박자를 모두 놓치면 두 부분을 남긴다. 긴 노트의 조기 해제는 끝까지 누르기로 연습한다. 무응답·명시적인 소리 중단은 문장 오해로 만들지 않는다. 결과의 변형 문장에는 그 변형 문장의 실제 내용을 사용한다.
- 한글: 실제 선택·음절 조합·짝 맞추기에서 고른 글자와 맞는 글자를 비교한다. 소리 완료를 확인하지 못했으면 소리부터 다시 듣는다. 기존 Core의 재출제와 첫 답/도움 기록은 유지한다.
- 첫 문장: 서버가 종료 후 확인한 답에서만 힌트를 만든다. 상황과 정확한 정답 표현을 보며 다시 고르고, 첫 문장 서버 제출을 반복하지 않는다.

조작 재연습은 전체 첫 튜토리얼 대신 그 동작 한 단계만 연다. 가운데로 이동·가만히 기다리기·긴 노트 유지도 지원하며 타이밍 재연습에는 새 문장을 끼우지 않는다. 문장 재연습은 이미 답한 문항의 기존 녹음을 실제 끝까지 듣고 다시 고른다. 원래 선택과 문항 해설은 비교 자료로 보존하며 새로운 독립 수행이나 코인으로 세지 않는다. 성공한 도움은 ‘함께 연습 완료’이고 원래 오답과 점수는 그대로다. 완료/취소/페이지 숨김에서는 소리를 멈추며, 재연습을 마치면 진행 중인 판으로 돌아간다. 입구·결과에서 다시 연습한 것으로 새 판을 시작하지 않는다.

최근 도움 12개를 `synk.world.tutor.support.v1:<owner>:<tutor>:<game>`에 기기 안에서 저장한다. 계정/비회원·튜터·게임을 나누고 저장 불가 시 이번 페이지에서 유지한다. 학생 식별자나 계정 권한은 프레임에 전달하지 않고, 현재 같은 출처/프레임/게임/버전과 판정 이벤트에서 온 짧은 자료만 받아 글자로 그린다. 마린의 보고·까몽의 실토/허세·몽글의 공감/같이 하기 말투와 승인 표정을 사용하며, 학생이 왜 그 답을 골랐는지는 추정하지 않는다.

`game-tutor-support.mjs`는 기존 게임의 관찰을 표시하고 최근 도움을 보관하는 UI 모듈이다. 별도 Atlas 평가 엔진이나 유료 AI 호출이 아니다. `tutor-review.mjs`/`.css`는 이미 답한 내용의 도움 연습을 담당하고 `tutor-practice-core.mjs`의 제한된 동작 단계를 재사용한다. [검수·실제 화면·재현 명령](qa/tutor-hints-20261010/README.md).

## 생활·카페에서도 동행하는 튜터

같은 날 함께 확인한 표현은 새로고침 뒤에도 기억한다. 홈의 하루 마무리에서 고른 튜터가 혼자 맞힌 말·함께 확인한 말·다시 볼 말을 짚어 주고, 다음 방문에는 실제 학습 날짜와 표현으로 어제/지난번을 구분해 반긴다. 마무리 뒤에도 하던 학습을 이어갈 수 있으며 한국 시간 기준의 하루 기록은 기존 계정/게스트 진도에 저장한다. ## 가로·세로 지원 확정 · v4

사용자의 「둘 다 준비해서 원하는 모드로」 요청으로 설정 → 화면 방향에 **자동·세로·가로**를 추가했다. 선택은 `synk.world.maru.orientation`에 저장한다. 게임 내용·계정·진도를 방향별로 복제하지 않는다.

이후 사용자가 가로·세로 동시 지원을 확정하고 플레이 중 회전 검수를 요청했다. v4에서는 실제 한 판을 끝까지 진행하며 문제·점수·음성·필기·선택 답·완료 기록을 확인했다. 작은 가로에서 게임 무대와 답 버튼이 가려지던 배치, 회전 중 손을 떼면 잘못된 동작이 들어가던 바람길 입력을 수정했다. [최신 시나리오·결과·한계](qa/maru-v4/README.md).

- 자동은 현재 화면 방향을 따른다. 휴대폰에서는 기기를 돌리면 배치와 해당 방향의 v9 영상/포스터가 바뀐다.
- PC의 충분한 창에서는 세로를 고르면 세로 프레임, 가로를 고르면 넓은 프레임으로 바로 바뀐다. 좁은 미리보기는 휴대폰과 같은 동작이다.
- 휴대폰에서 선택과 실제 방향이 다르면 회전 안내와 ‘자동으로 보기’를 표시한다. 지원되는 브라우저에서는 선택 동작에 따라 `screen.orientation.lock()`도 시도하지만, 실패해도 현재 화면은 사용할 수 있다. 전체화면을 강제하거나 성공하지 않은 잠금을 완료로 표기하지 않는다.
- 방향 변경은 열려 있는 게임 iframe을 제거하거나 다시 만들지 않는다. 게임 문서와 게임 내 상태를 유지하면서 실제 표시 크기를 바꾼다.
- 회전 검수 중 발견한 실제 게임 결함도 수정했다. 바람길·말의 리듬은 계정 안내와 게임이 `100dvh`를 나눠 쓰게 해 아래 조작부가 밀리지 않게 했다. 한글 따라쓰기는 고정 좌표에 획을 기록하고 ResizeObserver에서 크기·해상도·그림을 갱신해 기존 선과 새 입력 위치를 보존한다.
- 브라우저의 방향 잠금은 지원 및 전체화면 조건이 다르다. 설치형 앱/PWA라는 이유만으로 잠금을 보장하지 않는다. [MDN lock()](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock), [W3C 전체화면 상호작용](https://www.w3.org/TR/screen-orientation/#interaction-with-fullscreen-api). 물리 기기/네이티브 앱 잠금은 별도 확인 대상이다.
