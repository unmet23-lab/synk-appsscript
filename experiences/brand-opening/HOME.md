## 화면과 첫 행동

한강 풍경과 까몽·몽글·마린이 화면을 채운다. 위에는 나의 마루와 설정, 아래에는 **다음 학습**, 생활 팩·복습·이야기와 마루·놀이·옷장·나 메뉴를 둔다. 홈은 스크롤하지 않는다. 주 버튼은 현재 계정의 다음 생활 학습을 열고, 놀이 메뉴에서는 생활 콘텐츠와 바람길·한글 만나기·말의 리듬을 선택한다.

휴대폰의 동적 높이와 안전 여백을 반영했다. 가로에서는 가로 풍경으로 바꾸고, 오른쪽 캐릭터를 가리지 않도록 조작부를 왼쪽 아래에 둔다. 기존 승인 펠트 판·아이콘·브랜드 서체를 사용하며 임의의 코인·출석·진도 수치를 만들지 않는다.

## 가로·세로 지원 확정 · v4

사용자의 「둘 다 준비해서 원하는 모드로」 요청으로 설정 → 화면 방향에 **자동·세로·가로**를 추가했다. 선택은 `synk.world.maru.orientation`에 저장한다. 게임 내용·계정·진도를 방향별로 복제하지 않는다.

이후 사용자가 가로·세로 동시 지원을 확정하고 플레이 중 회전 검수를 요청했다. v4에서는 실제 한 판을 끝까지 진행하며 문제·점수·음성·필기·선택 답·완료 기록을 확인했다. 작은 가로에서 게임 무대와 답 버튼이 가려지던 배치, 회전 중 손을 떼면 잘못된 동작이 들어가던 바람길 입력을 수정했다. [최신 시나리오·결과·한계](qa/maru-v4/README.md).

- 자동은 현재 화면 방향을 따른다. 휴대폰에서는 기기를 돌리면 배치와 해당 방향의 v9 영상/포스터가 바뀐다.
- PC의 충분한 창에서는 세로를 고르면 세로 프레임, 가로를 고르면 넓은 프레임으로 바로 바뀐다. 좁은 미리보기는 휴대폰과 같은 동작이다.
- 휴대폰에서 선택과 실제 방향이 다르면 회전 안내와 ‘자동으로 보기’를 표시한다. 지원되는 브라우저에서는 선택 동작에 따라 `screen.orientation.lock()`도 시도하지만, 실패해도 현재 화면은 사용할 수 있다. 전체화면을 강제하거나 성공하지 않은 잠금을 완료로 표기하지 않는다.
- 방향 변경은 열려 있는 게임 iframe을 제거하거나 다시 만들지 않는다. 게임 문서와 게임 내 상태를 유지하면서 실제 표시 크기를 바꾼다.
- 회전 검수 중 발견한 실제 게임 결함도 수정했다. 바람길·말의 리듬은 계정 안내와 게임이 `100dvh`를 나눠 쓰게 해 아래 조작부가 밀리지 않게 했다. 한글 따라쓰기는 고정 좌표에 획을 기록하고 ResizeObserver에서 크기·해상도·그림을 갱신해 기존 선과 새 입력 위치를 보존한다.
- 브라우저의 방향 잠금은 지원 및 전체화면 조건이 다르다. 설치형 앱/PWA라는 이유만으로 잠금을 보장하지 않는다. [MDN lock()](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock), [W3C 전체화면 상호작용](https://www.w3.org/TR/screen-orientation/#interaction-with-fullscreen-api). 물리 기기/네이티브 앱 잠금은 별도 확인 대상이다.

## 구현 범위

- `preview.mjs`: 독립 오프닝의 시작·건너뛰기 뒤 `home.html`로 연결한다. 회사 단독 시안은 기존 완료 흐름을 유지한다.
- `home.html`, `home.css`, `home.mjs`: 전체 화면 로비, 아래에서 열리는 놀이·옷장·내 공간·설정 창, 실제 게임 iframe, 닫기·초점 복원, 움직임 감소 설정이다.
- 풍경은 기존 **v9 배경 고정 마감 영상**을 그대로 재사용한다. 추가 이미지·영상 생성과 과금 호출은 없다. 다른 패널·탭 숨김에서는 배경 동영상을 쉬게 하고, OS/사용자 움직임 감소에서는 포스터를 쓴다.
- 게임은 로컬 `korean-runner`, `hangul-stage`, `korean-rhythm`의 실제 입구다. 닫으면 iframe을 제거해 놀이와 소리를 정리하고 로비 영상과 초점을 복원한다.
- 구현된 연습 영역은 바람길의 짧은 지시 듣기, 한글 만나기의 소리·글자 연결, 말의 리듬의 내용 일치 O/X 판단이다. TOPIK의 기초 듣기 준비와 연결되는 연습이며, 이번 UI 검수로 실제 학습 효과나 점수 향상이 검증된 것은 아니다.
- 실제 앱에서는 옷장·나의 공간이 앱 셸의 기존 계정·서버 보유품 화면을 내부 패널에 연다. 독립 미리보기에서는 기존 `mobile.html?opening=off` 연결을 유지한다. 새 홈이 인증·차림·진도 데이터를 별도로 만들지 않는다.
- **2026-10-10 실제 앱 통합:** `server.mjs`와 정적 앱 빌드는 같은 `document.mjs`를 사용해 마루를 기본 홈으로 연다. `app-shell.mjs`는 검증된 계정·게임/학습 host·옷장·타운을 소유하고, 마루는 표시와 패널 생명주기를 맡는다. [통합 검수](../synk-world-app/qa/maru-integration-20261010/README.md). 공개 배포·실물 기기 확인은 별도다.
