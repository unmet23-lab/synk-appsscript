# 마린·까몽 정본 대조와 3D 재조형 · 2026-10-12

사용자가 이전 3D 홈의 마린·까몽 외형을 기각했다. 기능 검사 통과를 조형 승인으로 취급하지 않고, 승인된 4K 본체·좌34 이미지와 실제 렌더를 나란히 비교하며 수정했다. 결과는 로컬 코드·브라우저 확인이며 공개 배포나 최종 미술 승인이 아니다.

## 최신 상태 · 까몽 몸통 전체 재구축

사용자는 아래 기록의 `rounded-clumped-fleece-v8`도 몸통과 인상이 다르다며 기각했다. **v8 및 다섯 차례 수정의 화면을 현재 승인 결과로 사용하지 않는다.** 최신 작업은 [본체 재구축 기록](rebuild-kkamong/README.md)과 [현재 비교 화면](http://127.0.0.1:4323/)이다. 꼬리를 포함한 경계 대신 이마→배 끝을 맞추며, 털 없는 형태와 정본 겹침을 별도로 검사한다. 마린과 원본 4K 정본은 이번 재구축에서 변경하지 않는다.

## 후속 요청 · 다섯 차례 연속 수정

사용자가 다시 까몽의 거친 털과 몸 형태, 마린의 비율·디테일 차이를 지적해 5차례를 연속 진행했다. [차례별 실제 화면](http://127.0.0.1:4323/five-passes/index.html)과 [현재 정본 비교](http://127.0.0.1:4323/)를 제공한다. `five-passes/pass{1..5}-{kkamong,marin}-{front,angle}.png`는 매 차례 직접 확인한 20개 캡처다. 같은 폴더에 해당 소스 사본도 보존했다.

| 차례 | 까몽 | 마린 | 대조에서 확인한 것 |
|---|---|---|---|
| 1 | 몸·귀·상향 접힘, 눈 위치 | 하부 투구 폭, 눈 실측, 몸의 앞뒤 위치 | 실루엣 개선, 재질 차이는 큼 |
| 2 | 굵은 삼각 털 대신 곡선 섬유 다발 실험 | 투구 깊이, 두꺼운 밑단, 솜결·끈 | 까몽은 젖은 털처럼 보여 기각, 마린 눈은 너무 옅어짐 |
| 3 | 짧고 부푼 다발, 깊이 처리·속표면 | 노랑 복원, 주머니 입구·꽃·접힌 밑단 | 까몽 검은 카드 면·축소 시 털 소실을 찾아 기각 |
| 4 | 카드 제거, 독립된 뿌리의 가는 3D 섬유 | 부드러운 골 음영, 패널 봉제, 크림 솜결 | 까몽의 부드러운 부피와 미세한 외곽 회복 |
| 5 | 국소 털 흐름·밀도·길이, 하복부·귀끝·꼬리 | 볼록한 노란 솜, 품질별 밀도, 재질 분리 | low/PC 홈 대조, 접지와 공유 Texture Source 부작용 보정 |

마린 사선의 이전 캡처에 정면 이미지가 남던 문제는 실제 이미지 로딩 뒤 별도 캡처로 방지했다. 까몽은 좌34 원본이 마린과 반대 방향을 보므로 비교 모델의 회전 방향을 맞췄다. 단순 파일명의 각도만 믿고 비교하지 않았다.

## 원본과 측정

### 5차 이후 사용자 재지적 · 둥근 몸과 선명한 정본 후보

- 사용자는 5차 까몽의 빗질처럼 매끈한 털과 긴 몸을 다시 기각했다. 이후 몸을 짧고 넓게 다시 조형하고 여러 크기의 털뭉치/속털을 재구성했다. 중간 결과의 단단한 혹·다각형 균열·평평한 단색을 실제 정면/사선 화면에서 찾아 추가 보정했다. 최신 화면은 `new-renders/kkamong-3d-{front,angle}.png`와 현재 비교 페이지다. 이전 1~5차 캡처는 과거 기록으로 유지한다.
- 마린은 정본 머리 높이 비율을 유지하면서 좁은 몸·팔을 넓히고 배·발의 연결을 채웠다. 회전 AABB 대신 실제 정점 투영으로 측정한 몸+팔/머리 폭은 정본 .8621, 수정 모델 .8570이다. 투구 꼭대기와 밑단 곡률·꽃 위치도 보정했다. 최신 화면은 `new-renders/marin-3d-{front,angle}.png`다.
- 원본 흐림을 조사한 결과 `tools/마스코트4K굽기.js`의 까몽 생성 지시에 외곽 털의 초점 흐림이 있었고, 과거 외곽 매트 복원도 겹쳐 있었다. 동일 캐릭터를 즉시 대체할 더 선명한 기존 원천은 찾지 못했다.
- 세 마스코트를 built-in `image_gen`으로 다시 렌더해 [원본/새 후보 비교](http://127.0.0.1:4323/new-renders/index.html)에 보존했다. [프롬프트](new-renders/prompts.json), [원본·후보 알파 감사](new-renders/alpha-audit.json). 원본 정면을 입력으로 얼굴·형태·소품 유지, 전체 초점·깨끗한 투명 배경을 요청했다. 도구가 모델 선택을 제공하지 않아 특정 모델/max 설정을 보장하지 않는다.
- 후보는 **1254×1254**이며 코어 알파 중앙값은 253이다. 기존 4K 50개 표정·각도 및 1024/480/SNS 파생본을 교체하지 않았다. 처음 생성한 몽글의 가짜 체크 배경은 재생성으로 없앴다. 까몽 실땀은 원본 확대/픽셀 검사 결과 **4개**로 확인했고, 잘못 세어 3개로 만든 수정 후보는 기각했다.
- 새 후보는 정면 그림이며 게임의 3D 모델로 대체하지 않았다. 완전한 정본 교체에는 표정·각도 세트와 눈 마스크·의상 정렬·파생 자산을 함께 맞춰야 한다. 새 PNG가 3D 메시·털 구조를 자동으로 개선하지 않는다.
- 최종 까몽 `rounded-clumped-fleece-v8`은 몸의 반복용 갈색 털 재질(얼굴/몸 사진 아님), 부풀어 오른 바탕과 독립 가닥, PBR 조명을 결합한다. 중앙은 털결이 보이게 가닥 알파를 낮추고 외곽은 볼륨을 유지한다. 가닥을 인덱스로 공유해 CPU 털 배열 111MB→78.9MB, low 생성 시 처음부터 33.93MB로 줄였다. GPU 복제·텍스처·나머지 몸은 이 수치에 포함하지 않는다.
- 새 재질은 로드 성공/실패 후 정적 화면도 갱신하고, 모델 해제 뒤 늦게 완료되어도 다시 렌더하지 않는다. 유한 좌표·법선·인덱스, 실제 몸 접지, 소유 자원의 1회 해제와 공유 자원 보존을 검증했다. 정본보다 털 조직이 정돈되고 하부 명암이 강한 차이는 남아 있다.

- 기준: `docs/캐릭터/정본_4K/{마린,까몽}_{본체,좌34}.png`. 원본 변경 없음.
- [실측 JSON](canonical-measurements.json) · [재현 스크립트](measure-canon.py). `python -X utf8 experiences/brand-opening/qa/companion-canon-20261012/measure-canon.py`로 재현한다. Pillow·NumPy·SciPy가 필요하다.
- 마린 기존 전체 알파 경계는 몸 아래 분리 픽셀을 포함했다. 연결된 실제 몸은 2011×2781px, 폭/키 .7231, 투구 높이 70.30%, 눈 중심은 위에서 46.81%다. 1024 파생본도 발 아래 단 한 픽셀로 694px가 789px가 됐다. 정본 이미지를 변경한 것이 아니라 측정 오류를 교정했다.
- 9/15 반눈은 기업 홈페이지 단체 장면 범위다. 이번 본체는 온전한 무광 노랑 렌즈이며 동공·흰 반사를 붙이지 않는다.
- [비교 화면](http://127.0.0.1:4323/)은 같은 몸 높이·발선에 원본 4K를 그대로 표시한다. `node experiences/brand-opening/qa/companion-canon-20261012/serve.mjs`로 실행. 원본 참조 4개와 검수 정적 파일만 localhost에서 읽으며 계정 API가 없다.

## 변경

- 마린: 넓은 둥근 돔, 짧은 크림 몸·팔다리, 실제 봉제선과 펠트 말림, 큰 무광 렌즈와 안쪽 쿠션, 사각 꽃주머니. 얼굴·투구·몸에 곡선 섬유를 붙였다.
- 까몽: 몸·귀·옆 접힘을 하나의 닫힌 입체 표면으로 연결. 올리브 홍채와 유리 동공, 굵은 곡선 꼬리와 코랄/갈색 끝, 실제 실땀. 최신 5차는 굵은 삼각 털·노이즈 셸·털 카드를 제거하고 약 14만 개 독립 뿌리의 가는 입체 섬유를 사용한다. low에서도 약 6만 가닥을 고르게 남긴다.
- 각 모델은 전체 3D이며 정면 이미지를 붙인 평면이나 영상이 아니다. 기존 몽글의 옷방 모델·의상·염색 코드는 유지했다.
- 실제 몸 높이 기준으로 크기를 맞췄다. 모바일에서는 선택한 친구를 앞에 두고 옆 친구 얼굴이 보이도록 조정했다. 문·액자 버튼도 얼굴을 덜 가리는 위치로 옮겼다.
- 장식용 털이 1m 범위의 광선을 가로채던 문제를 제거했다. 실제 액자 중앙을 눌러 액자 패널이 열리는 것을 확인했다. 꼬리의 최저점이 바닥 아래로 들어가지 않도록 모델 발선을 보정했다.
- 비교 화면은 원본의 매달린 꼬리 자세다. 실제 홈은 같은 모델의 `floor-rest` 자세로 꼬리를 옆에 놓는다. 접지점은 긴 잔털의 최저점이 아닌 실제 몸의 바닥으로 정하며, 아래쪽 잔털과 꼬리 자세도 바닥에 맞춘다.

## 확인한 것

- PC 1280×800·모바일 390×844, 정면·34도 비교, high/low 실제 WebGL 렌더. 콘솔의 셰이더 오류 없음.
- 큰 몽글·까몽·마린의 실제 몸을 각각 직접 눌러 해당 캐릭터 대사가 뜨는 것 확인.
- 시험 계정에서 까몽 선택→홈 진입, 기존 마린으로 복원, 홈 사진 촬영→앨범/액자 저장 확인. 운영 사용자 계정 검증은 아니다.
- 패널 열기와 움직임 감소에서 렌더 정지. 움직임 감소 800ms 동안 프레임 1309→1309. 기존 설정으로 되돌렸다.
- 각 모델 정점·법선·UV 유한값, 까몽 닫힌 망(열린 모서리 0), low/balanced/high draw range, 반복 dispose와 공유 재질 보존을 확인. 최신 독립 섬유의 소유 geometry/material을 각 1회 해제하며 공유 재질·텍스처는 해제하지 않는다. 마린 크림 맵은 별도 Texture Source를 사용해 머리·렌즈에 보정이 번지지 않는다.
- 기존 시작/선택/기억/사진/계정 경계 관련 Node 검사 **53/53 통과**. 이는 조형 유사도 점수가 아니다.
- 최신 공개용 로컬 패키지 1936파일(새 털 재질 포함), 누락 참조 0·원본 변경 0·비공개 자산 포함 0·이전 출력 유지. [빌드 결과](build-result.json). 배포하지 않았다.
