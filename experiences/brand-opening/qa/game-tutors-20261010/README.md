## 확인한 동작

- 세 캐릭터 × 바람길·말의 리듬·한글 만나기, 9개 실제 입구에서 선택한 친구의 조작법과 동행 초상을 확인했다.
- 바람길은 기존 QA 운전이 실제 모델 입력으로 성공·놓침을 만들고, 캐릭터의 얼굴/대사와 완료 반응을 확인했다. 조작법을 여는 동안 모델 시간이 그대로였고 이어 하기 후 같은 판을 계속했다. 별도의 MP3 듣기 확인에서도 실제 오답·정답에 반응했다.
- 말의 리듬은 기존 QA 재생 시각 이동과 실제 입력으로 O/X 오답·정답을 만들었다. 일반 박자와 언어 답을 구분하고, 안내 중 공통 오디오 시계가 그대로 멈춘 뒤 이어졌다.
- 한글은 `?qa=silent`로 기존 실제 보기 단추를 눌러 오답·정답을 만들고, 문항과 기본 몸을 유지한 채 얼굴/대사가 바뀌는 것을 확인했다. 이는 음질 청취 검사와 구분한다.
- 첫 문장 놀이는 로컬 합성 계정으로 세 답을 제출하고 실제 서버의 종료 결과에서 오답·정답에 반응했다. 선택 순간에 정답을 꾸며 말하지 않는다. 계정의 까몽과 비회원의 마린 선택은 격리되고 로그아웃에서 비회원 선택으로 돌아왔다.
- 반응 소리를 실제로 켠 뒤 놀이 중에는 재생을 쉬는 것을 확인했다. 종료/닫기에서 동행 리소스를 제거한다. 움직임 감소에서도 대사·표정을 유지하고, 일반 움직임에서는 까몽의 성공 동작이 실행된다.
- 320×668, 390×844, 740×320, 844×390, 1440×900에서 동행과 실제 조작부가 화면 안에 들어온다. 작은 가로는 부모의 닫기 버튼을 튜터 줄에 모아 게임 공간을 확보한다.
- 연결 계약은 현재 프레임·같은 출처·게임 이름·버전을 확인하고 계정 식별자와 임의 문구를 받지 않는다. Node 검사는 캐릭터 말투, 승인 표정 유효성, 선택 범위와 기존 판정/음성 규칙도 확인한다.
