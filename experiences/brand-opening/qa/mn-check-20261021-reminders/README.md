# 학습 알림 몽골어 검문 (2026-10-21)

WORLD 학습 알림 화면 글(`experiences/brand-opening/world-strings.mjs`의 `reminder.*`)의 몽골어를 세 겹으로 쟀다 — ① 역번역 대조(원문 한국어와 뜻이 같은지) ② 교정(화면 최종 검수) ③ `node tools/몽골어대조.js --파일 <묶음> --구독`의 문법 판정과 맞춤법 사전(spellcheck.mn). 줄마다의 결과는 [`../../world-strings-check.json`](../../world-strings-check.json)에 키·몽골어 해시·마지막 묶음으로 남는다.

묶음(`*.txt`)·결과(`*.result.txt`)·키 목록(`manifest*.json`)은 qa 결과 규칙(2026-10-20, 루트 `.gitignore`)대로 작업한 PC에만 두고, 판정은 아래에 적는다.

| 묶음 | 줄 | 문법 | 맞춤법 | 처리 |
|---|---|---|---|---|
| `reminders-01` | 15 | 정상 | 의심 0 | 그대로 |
| `reminders-02` | 19 | 어색 — `богино шалгаад`(짧게 점검), `Хоёр хүртэл удаа`(두 번까지), 접속 없이 이은 시각 안내 | 의심 0 | `товч шалгаад` · `Дээд тал нь хоёр удаа` · `харин`으로 고침 |
| `reminders-03` | 5 | 어색 — 수식어 없는 `Тоо`(수) | 의심 0 | `Давтамж`(빈도)로 고침 |
| `recheck-01` | 5 | 정상 | 의심 0 | 고친 다섯 줄 |
| `final-02` · `final-03` | 19 · 5 | 정상 | 의심 0 | 고친 줄이 든 묶음 전체를 다시 |
| `recheck-02` | 3 | 정상 | 의심 0(사전 시간당 한도로 한 시간 뒤 다시) | 시험 점검 시트 글 세 줄(`exam.body`에서 「짧게」를 뺌 · 새 `exam.mock` · 교정에서 `эхлэх` → `эхлүүлэх`로 고친 `exam.start`) |

- 역번역 대조: 40줄 모두 한국어 원문과 뜻이 같다(값 자리 `{date}`·`{time}`·`{when}`은 실제 값을 넣어 쟀다).
- 교정: 첫 검수에서 `reminder.exam.start`를 기존 `position.diagnostic.start`와 같은 꼴(`эхлүүлэх`)로 맞췄고, 재확인에서 바꾼 세 줄은 그대로 통과했다.
- 재지 않은 줄: `reminder.push.title`(SYNK WORLD)·`reminder.when`(날짜·시각 꼴) — 몽골어 낱말이 없다.
