# 마린·몽글 표정 자산 검수 — 2026-10-11

`audit.cjs`·`detail.cjs`와 `*-canonical-*`, `*-runtime480-full.png`, `pixel-report.json`, `detail-report.json`은 **교정 전** 자산을 읽은 근거다. 마린 14컷·몽글 15컷을 읽었다. 각도 컷은 포함하지 않는다.

- 교정 전 표정은 몸 하단이 같았으나, 두 눈을 포함한 얼굴의 넓은 영역과 알파가 달랐다. 마린 미간 ROI 240×450px와 몽글 미간 ROI 300×420px도 거의 전부 달랐다. 원본·WORLD WebP의 SHA는 당시 `sources.json` 기록과 모두 일치했다.
- 마린의 기존 집중·졸림은 남색 털이 렌즈를 덮는 눈꺼풀처럼 보였다. 승인된 꽃 눈웃음은 별개의 유지 대상이다.
- 몽글의 기존 눈·자수 표현은 유지 대상으로 판단했다. 새 기쁨 표정을 만들지 않았다.

`candidates.cjs`와 `마린-candidates-*.png`, `몽글-candidates-*.png`은 **교정 후 후보** 14개를 실제 WORLD 480 크기에서 배치·확대한 검수본이다. 마린·몽글 각각 7개의 전체·얼굴 시트를 직접 확인했다. 닫힌 몽글 눈에 남던 구슬 반사는 원래 구슬의 좁은 볼록 외곽을 채우는 보완 후 제거했다.

최종 입력 백업·생성 원본·개별 눈 마스크·4K/480 후보·적용 여부·해시는 [`docs/캐릭터/마린몽글표정교정_20261011/정본.json`](../../../../../docs/캐릭터/마린몽글표정교정_20261011/정본.json)에 있다. 생성기는 `tools/튜터표정정본.js`이다. 14개 모두 4K 및 실제 WORLD crop을 재현한 무손실 480에서 허용 눈 윤곽 밖 RGBA 차이 0, 전체 알파 차이 0이다. 480 비교는 두 번의 Lanczos 축소에 따른 최대 5px 경계만 허용한다. 손실 WebP와 브라우저 전환 검수는 별도 결과다.
