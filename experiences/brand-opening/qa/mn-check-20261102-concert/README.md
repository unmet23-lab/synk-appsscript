# WORLD 펠트 안녕 콘서트 타이틀 몽골어 검문 (2026-11-02)

/world 첫 화면 펠트 안녕 콘서트 타이틀(`experiences/brand-opening/opening.mjs`, 결정 11-02)의 새 화면 글 `world-strings.mjs` 두 줄을 세 겹으로 검문했다 — `node tools/몽골어대조.js --파일 <묶음> --구독`(문법 · 직역 역번역 · spellcheck.mn 맞춤법). 한 줄(`opening.concert.line`)은 11-01 입구 판에서 검문을 마친 `opening.entrance.subtitle`과 같은 문장이라 다시 재지 않았다([11-01 검문](../mn-check-20261101-entrance/README.md)).

묶음(`*.txt`)과 결과(`*.result.txt`)는 qa 결과 규칙(루트 `.gitignore`)대로 작업한 PC에만 두고, 판정은 아래에 적는다. 줄마다 기록은 `../../world-strings-check.json`.

| 묶음 | 줄 | 문법 | 맞춤법 | 처리 |
|---|---|---|---|---|
| `concert-01` | 사진 설명 · 언어 단추 | 어색 — 둘 다 직역투, 언어 단추는 서술어 없이 쉼표로 이음 | 의심 없음 | 두 줄 모두 고침 |
| `concert-02` | 사진 설명 · 언어 단추 | 사진 설명만 어색 — 속격 다섯 번 겹침, 「단어」와 「글자」를 잇는 동사 없음, `тоглолт хийж`보다 `үзүүлбэр үзүүлж`. 언어 단추는 자연스러움 | 의심 없음 | 언어 단추 확정(`Дэлгэцийн хэл солих. Одоогийн хэл: {lang}`), 사진 설명은 다시 고침 |
| `concert-03` | 사진 설명 | 정상 | 의심 없음 | 확정(`Хан мөрний эрэг дээр концерт болж байна. Тайзан дээр солонгосоор «сайн уу» гэж бичсэн том эсгий үсгүүдийн өмнө таван хүн үзүүлбэр үзүүлж, үзэгчид гэрэлт саваа барьж байна`) |

- 뜻 대조: 한국어 원문과 직역 역번역을 Claude가 견줬다. 사진 설명은 「한강 기슭에서 콘서트가 열리고 있다. 무대 위에 한국어로 «안녕»이라고 쓰인 큰 펠트 글자들 앞에서 다섯 사람이 공연을 보여 주고, 관객들이 빛나는 막대를 들고 있다」, 언어 단추는 「화면의 언어 바꾸기. 현재의 언어: 몽골어」로 원문과 뜻이 같다. 도구의 종합 「사람 검수 필요(공식 앱 뜻 검토 대기)」는 이 대조를 사람이 하라는 뜻이다.
- `opening.concert.lang`의 `{lang}` 자리는 실물 문장(「… Одоогийн хэл: Монгол」)으로 넣어 쟀다. 한국어 · 영어 줄도 같은 두 문장 꼴로 맞췄다(「화면 언어 바꾸기. 지금 언어: {lang}」 · 「Change screen language. Current: {lang}」).
- 몽골어 화면의 실제 모양은 브라우저 확인(`../verify-concert-title.cjs`, 390 · 1440 몽골어 캡처)과 검수 묶음 `world-concert-title-20261102` 캡처로 봤다.
