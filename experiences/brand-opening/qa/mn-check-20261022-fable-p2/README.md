- 역번역 대조: 바꾼 37줄 모두 한국어 원문과 뜻이 같다(직역이라 높임·어미만 다르다). `Багш`(튜터)·`Сургалтын мэдээлэл`(학습 기록)·`бүртгэл`(계정)·`Манай хотхон`(우리 동네)은 표에 이미 있는 말을 그대로 썼다.

- `account.recoveryRejected`는 `account.recoveryChoose`와 같은 줄(「이어 갈 기록을 골라 주세요」)이 되어 그 줄의 검문을 잇는다. 던지는 곳이 없어진 `msg.entryAccount`는 표와 기록에서 지웠다.
