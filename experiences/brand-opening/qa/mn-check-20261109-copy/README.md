- 뜻 대조(Claude): 한국어 원문과 직역 역번역을 줄마다 견줬다 — 「처음 보는 문항에 혼자 낸 첫 답만 내 위치에 반영해요」 ↔ 「이전에 보지 않은 질문에 도움 없이 준 첫 번째 답변만이 여기에 계산된다」, 「같은 방식의 새 문항으로, 시간이 지나도 기억하는지 봐요」 ↔ 「동일한 형태의 새로운 과제로 시간이 지난 후에 기억하고 있는지 여부를 본다」, 「다시 확인 일정」 ↔ 「다시 확인할 일정」, 「한 번에 20분쯤」 ↔ 「한 번에 20분 정도」, 「잘 기억한 표현은 더 오래 있다가 돌아와요」 ↔ 「잘 기억한 표현은 더 오랜 기간 후에 다시 나타난다」, 「이번 주 계획 · 0/3」 ↔ 「계획 · 0/3」(몽골어만 짧은 꼴), 「학습 목표」 ↔ 「목표」, 「먼저 만날 표현」 ↔ 「먼저 반복할 표현」, 「기록이 있는 항목 1 / 8」 ↔ 「등록된 능력 1 / 8」, 「다음 레슨을 열어 확인하기」 ↔ 「다음 수업을 열어 확인하기」, 「연습용 문항이라 내 위치에 반영하지 않았어요」 ↔ 「연습의 질문이므로 여기에 계산하지 않았다」, 「계획 밖에 한 것」 ↔ 「계획 밖에서 한」, 「아직 혼자 푼 새 문항이 없어요」 ↔ 「스스로 대답한 새로운 질문이 아직 없다」. 어긋난 뜻 없음.
- `review-02`의 몽골어는 「새 장면에 맞는 표현을 다시 고른다」로 목적어를 넣었다. 한국어 화면 글(`life.reviewSubScenes` · `life.reviewSubFirst`)은 「새 장면 N개에서 다시 골라요」로 더 짧다 — 고르는 것이 표현이라는 뜻은 같다.
- 옛 글 `life.reviewSubDue` · `plan.week.sessions`는 공개본의 예비 생활 묶음이 아직 불러 그대로 남겼다(몽골어도 앞 검문 그대로).
- 같은 검수 묶음의 아르곤 · Fable이 이 줄을 diff로 다시 본다(현지어 확인 세 겹 — 결정 표 10-19 · 11-02).
