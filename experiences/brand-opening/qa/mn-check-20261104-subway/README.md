# 환승 러시 화면 글 몽골어 검문 (2026-11-04)

앱 「놀이」에 환승 러시를 넣으며 생긴 화면 글 `world-strings.mjs` 세 줄을 `node tools/몽골어대조.js --파일 <묶음> --구독`으로 검문했다. 잠김 자리는 이미 있는 `play.where.lesson`을 쓴다. 묶음(`*.txt`)과 결과는 qa 결과 규칙대로 작업한 PC에만 두고, 판정은 아래에 적는다. 줄마다 기록은 `../../world-strings-check.json`.

| 묶음 | 줄 | 문법 | 처리 |
|---|---|---|---|
| `subway-01` | 게임 이름 `Шилжих шуурга` | 어색 — 「이동할 폭풍」으로 읽힌다 | 버림 |
| `subway-02` | 게임 이름 `Метроны шилжилт` | 어색 — `шилжилт`은 체제 · 상태의 전환 | 버림 |
| `subway-03` | 게임 이름 `Метроны шуурга` | 어색 — 「지하철의 눈보라」 | 버림 |
| `subway-04~07` | 게임 이름 `Метро солих` · 설명 줄 `зарлал` · `мэдээлэл` · `сольж суугаад` 판 | 어색 — `солих`는 교체 · 교환의 뜻이 강하고, `зарлал`은 눈으로 읽는 공고에 가깝다 | 버림 |
