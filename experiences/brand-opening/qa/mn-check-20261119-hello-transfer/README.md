# 인사 레슨 「새 상황 복습」 인사 문항 몽골어 검문 (2026-11-19)

synk.im LAB 「직접 풀어 보기」의 둘째 문제가 `life.greetings-expressions-hello-transfer`다. 처음 보는 학생이 옛 상황 글(「아직 도움을 받거나 헤어지는 상황은 아니에요」)을 장면으로 읽지 못해, 앱의 상황 글과 발문을 고쳤다. 문항 2중 검수의 1차가 해설이 한 문장뿐이라고 고침을 내서 해설도 고쳤다(검수 보고서 `experiences/topik-items/review/reports/life-hello-transfer-20261119.md`).

`node tools/몽골어대조.js … --구독`이 이번에는 「agy가 빈 답을 냈다」로 끝나, 현장 노트(AI_CLI 「`몽골어대조.js --구독`이 같은 묶음에서 …」)대로 같은 카본(gemini-4-carbon high)에 스키마 없이 · 한도 900초로 물었다. 맞춤법은 같은 자(`tools/lib/몽골어맞춤법.js`)로 쟀다. 결과 파일은 그 답 그대로다.
