# 시작 이후 3D 홈 검증 · 2026-10-12

> **후속 정정:** 사용자가 이 기록의 마린·까몽 조형 품질을 기각했다. 아래 결과는 기능 연결 검사이며 미술 품질 승인이 아니다. [정본 대조·재조형 검수](../companion-canon-20261012/README.md)가 현재 그래픽 기록이다.

사용자가 타이틀의 영상은 시작 전만 남기고 옷방의 3D로 홈을 만들며 제안 네 항목을 모두 반영하도록 요청했다. 결과 원문은 [HOME.md](../../HOME.md)다.

## 실행 범위

- 로컬 `http://127.0.0.1:4322/mobile.html?opening=off`, 합성 계정 DB `.local/stable-scene-20261012`.
- 브라우저 1280×800, 390×844, 844×390. 실제 휴대폰 하드웨어·운영 로그인 왕복·공개 배포·설치본 교체는 하지 않았다.
- 몽글은 실제 옷장과 같은 아바타/의상 모듈, 까몽·마린은 정본 특징에 따른 실시간 절차 모델. 타이틀의 고해상도 마스터와 같은 완성 에셋이라는 뜻은 아니다.

## 실제 화면에서 확인

1. 미선택 사용자는 시작 후 곧바로 선택 창. X로 취소하면 타이틀 복귀, 다시 시작 가능.
2. 몽글 선택 저장 후 홈 진입, 새로고침 시 선택 창 없이 복원. 새 합성 계정에서는 별도로 마린 선택, 재로그인 시 선택 단계 생략.
3. 홈의 `<video>` 수 0, 실제 WebGL renderer 1. 세 친구 인사에 각각 정본 대사와 몸짓. 마린 선택 시 가운데로 재배치.
4. 책 → 첫 인사 학습, 카페 → 구름 한 잔, 동네 → 기존 입장/개발 미리보기 경로.
5. 첫 인사에서 실제로 ‘안녕하세요.’를 고르고 저장. 게스트 액자에 오늘의 정본 표현 표시. 계정 전환 후 다른 소유자에게 섞이지 않음.
6. 기존 옷방에서 보유한 버터빛 니트 조끼·청금석 니트 머플러를 저장. 홈 몽글의 실제 3D에 두 슬롯 모두 표시, 새로고침 후 유지.
7. 방의 카메라로 캡처 → 기존 기기 앨범에 저장 → 액자에 사진 표시. 새로고침 후 사진 복원, 로그아웃하면 사진과 차림이 즉시 지워지고 게스트 표현/튜터 복원.
8. 움직임 감소: 800ms 관측 동안 추가 렌더 0. 패널 열림: 600ms 동안 추가 렌더 0. 데스크톱 정상 상태: 900ms 동안 27프레임 진행. 이는 이 PC 브라우저의 관측이며 실물 휴대폰 FPS 보장이 아니다.

검수 중 계정 알림보다 학습 알림이 먼저 오는 순서에서 표현이 지워지는 문제와, 사진 저장 완료가 사용자가 새로 연 패널을 덮는 문제를 발견해 수정했다.
