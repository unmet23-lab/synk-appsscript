# 몽글과 바람의 정원 — Loom 실시간 장면

2026-09-13 · 몽글 한 명과 기존 배경 한 장으로 검증하는 로컬 장면이다. 사용자가 요청한 Loom 업그레이드의 첫 구현이며, SYNK-talk 학생 앱 배포나 1년 스토리 기능 구현은 포함하지 않는다.

## 실행

완성된 자산이 들어 있으므로 다음 명령으로 바로 시작할 수 있다. 서버는 숨김 창으로 실행되며 이미 실행 중이면 재사용한다.

```powershell
powershell -File experiences/loom-living/start.ps1
```

원본에서 자산을 다시 준비하거나 터미널에서 서버를 직접 실행할 때는 저장소 루트에서 실행한다.

```powershell
node tools/loom-living-build.cjs
node tools/loom-living-server.cjs
```

[로컬 장면 열기](http://127.0.0.1:4319). 서버는 `127.0.0.1`에만 연결한다. 빌더는 형제 `SYNK-talk`의 `sharp`, 눈감음 자산과 눈 영역 자료를 사용한다. 새 이미지·영상 생성이나 외부 모델/API 호출은 하지 않는다. 패키징을 다시 하면 자산·색 토큰·깊이 정보·출처 지문이 갱신된다.

## 구현과 경계

| 부분 | 실제 위치와 역할 |
|---|---|
| 공통 움직임 | [loom-scene.mjs](../../tools/lib/loom-scene.mjs): 장면 시간, 공유 바람, 시선 뒤 몸의 지연 반응, 최대 4% 눌림, 깜빡임과 휴식 |
| 웹 표시 | [loom-scene-webgl.mjs](../../tools/lib/loom-scene-webgl.mjs): 카메라·배경은 고정하고 몽글의 상체와 씨앗에 장면 값을 전달. 실제 접점 세 곳의 그림자와 원래 풀의 겹침을 합성 |
| 장면 조작 | [scene.mjs](scene.mjs): 포인터·인사·바람·정지·소리·전체 화면과 공통 움직임의 연결 |
| 자산·설정 | [scene.json](scene.json), [provenance.json](provenance.json): 사용 파일, 눈 영역, 깊이 격자, 원본 및 출력 SHA-256 |
| 재생성 | [loom-living-build.cjs](../../tools/loom-living-build.cjs): 기존 자산 축소·WebP 변환, 색 토큰 반입, 깊이 격자 생성 |

원본은 `docs/캐릭터/정본_4K/몽글_본체.png`와 `docs/라디오/무대/dream_field.png`다. 눈감음은 SYNK-talk의 기존 표정에서 지정된 눈 영역만 잘라 합성한다. 원본 파일은 수정하지 않으며, 출력은 크기 조정·압축·화면의 미세한 조명 보정을 거친다. 따라서 원본 파일의 바이트나 화면 픽셀 전체가 같다는 뜻은 아니다. 눈 영역 밖 합성 변화와 알파 변화는 실행 중 `eyeAudit`에 별도로 기록한다.

현재 방식은 **2.5D**다. 그림에 깊이와 변형 가능한 격자를 붙여 입체감을 내며, 실제 옆면·뒷면과 뼈대를 가진 3D 모델은 만들지 않았다. 깊이는 기존 `tools/lib/깊이격자.js`의 형태 근사다. 모든 나무·소품을 자동으로 분리하거나 임의의 이미지를 완전한 움직이는 캐릭터로 변환하는 기능도 아니다.

카메라·수평선·땅·나무와 전체 밝기는 고정한다. 한 장면의 바람을 몽글의 상체와 작은 씨앗이 공유한다. 눈은 관심 대상을 먼저 따라가고 몸은 작게 따라간다. 바람 버튼은 씨앗 사건도 시작하며, 자연 발생 간격은 20~32초다. 시선은 다시 쉬는 자세로 돌아온다. 독립된 나뭇가지 관절이나 실제 공기·광선 물리 시뮬레이션은 없다.

2026-09-13 사용자의 「살짝 멀미날 것 같은 느낌」과 「배경이랑 몽글이 따로 노는 느낌」에 따라 수정했다. 기존 배경 변형·시선에 따른 배경 이동·전체 밝기 진동·17개 상시 부유 입자를 제거했다. 회전 상한 .12→.055라디안, 기울기 .035→.012, 호흡 .004→.0012로 줄였다. 바닥 좌표는 유지하고 UV y=.83 아래를 고정했다. 알파 실측 접점 세 곳 (.237,.8444), (.488,.8515625), (.737,.84049)에 얇은 그림자를 넣고 원본 땅의 섬유가 밑단 일부에 겹치게 했다. 몽글의 화면 색에는 고정된 주변광·하단 음영을 적용한다. 수정 사실과 사용자가 편안하다고 느끼는지는 별개이며 후자는 아직 확인되지 않았다.

정지·화면 숨김·운영체제의 움직임 줄이기 설정은 현재 자세를 멈춘다. 복귀 직후의 긴 시간 간격은 버린다. 공통 코어의 `reading` 입력은 읽는 동안 바람·호흡을 낮추고 시선을 중립으로 돌리는 통로이며, 이 장면에는 별도 읽기 화면이 없다. 소리는 기본 꺼짐이고, 사용자가 켰을 때 브라우저에서 만든 합성 바람 소리를 재생한다. 녹음 파일이나 외부 음성 서비스는 사용하지 않는다.

## 검증

```powershell
node --test tests/loom-scene.test.mjs
```

2026-09-13 코어 시험 6/6 통과: 30·60·120Hz 입력에 같은 결과, 큰 시간 간격과 비정상 입력 방어, 정지 및 복귀, 공유 돌풍, 시선과 몸의 지연·눌림 복원, 깜빡임 간격과 휴식. 이는 장면 수학과 상태 전환 확인이며 실제 화면 품질·휴대전화 성능을 입증하지 않는다.

이번 수정의 브라우저 검증 결과는 [qa/report.json](qa/report.json)에 있다. 강한 시선·눌림·돌풍 입력 전후 배경 세 영역 약 82만 픽셀의 채널 변화는 0이었다. Windows의 Codex 브라우저에서 렌더 오류, 눈 영역 합성, 정지, 430×932 화면의 버튼·넘침과 수정 영상 재생을 확인했다. 눈 영역 밖 합성 변화와 알파 변화는 각각 0이었다. 실제 관찰 상태와 프레임 간격은 보고서에 기록하며 사용자의 편안함을 입증하는 값으로 해석하지 않는다. 최초 구현의 전체 화면·움직임 줄이기·그래픽 복구 확인은 Git 507b64f06의 검증 기록이다.

[데스크톱](qa/desktop.png) · [휴대폰 크기](qa/mobile.png) · [눈감음](qa/blink.png) · [시선 회전](qa/turn.png) · [16초 미리보기](qa/preview.mp4). 영상은 실제 캔버스를 녹화한 무음 H.264 파일(2358×980, 15.93초)이며 브라우저에서 재생도 확인했다. `qa/filmstrip.jpg`는 중간 프레임 확인용이다. 생성 모델이 만든 영상은 아니다.

`window.loomScene.snapshot()`은 장면 상태·눈 영역 합성 검사·렌더 정보·프레임 간격을 제공한다. 브라우저 화면 크기 변경은 실제 모바일 기기 검증과 구분한다. 네이티브 앱 반입·학생 사용·발열·배터리·장기 학습효과는 이번 완료 범위 밖이다. 보고서에 증거가 없는 범위는 미확인이다.

재검증 시에만 `LOOM_CAPTURE=1`로 서버를 켜면 동일 출처의 지정된 파일명으로 화면·영상을 저장할 수 있다. 기본 서버는 저장 요청을 받지 않는다. 원본 WebM은 로컬 중간 파일이며 최종 MP4를 버전 관리한다.

## 다른 자산으로 확장할 때

먼저 이 장면의 실제 재생과 상호작용을 확인한다. 다음 자산은 같은 공통 코어를 쓰되 원본·깊이·눈 영역·고정점과 움직임 상한을 그 자산에 맞춰 준비한다. 색·질감·큰 회전에서의 찌그러짐을 다시 확인하며, 현재 몽글의 눈 좌표나 깊이를 다른 캐릭터에 그대로 적용하지 않는다. 큰 회전·손발 동작이 필요한 주요 캐릭터의 진짜 3D는 별도 검증 단계다.
