# 입문 3종 자체 검수 · 2026-10-09

> 자체 검수 당시 발견과 제안을 보존한 기록이다. 아래 PNG 안내·무료 축제 변주·발견/듣기 표시 및 재방문 제안의 후속 구현은 [재방문 마감](../return-finish-20261009/README.md), 그 변경과 장면 보관함의 공개 근거는 [공개 후속](../scene-keepsake-release-20261009/README.md)을 따른다. 이 목록 전체를 현재 미해결 항목으로 다시 등록하지 않는다.


사용자 「지금 검수 받을 필요 없어. 한번 니가 직접 검수하고 어떤거 더 하면 좋을지 알려줘」에 따라 현재 화면과 코드를 직접 확인했다. 외부 공식 모델은 호출하지 않았다. 아래는 수정 후보와 제품 제안이며, 제품 코드 변경·공개 배포·공식 검토 PASS를 뜻하지 않는다.

## 확인 범위

- 새 localhost 출처의 비회원 체험. 허브 입구, 마법 두 표현 안내와 첫 퍼즐의 무효 행동 피드백, 첫 가게 시범과 상점, 우주선 두 탭 생성·초대·준비·색 튜토리얼·설명서/조종판 첫 화면, 허브 복귀를 직접 조작했다.
- 기본 데스크톱 화면과 390×844 브라우저 표시를 확인했다. 물리 휴대폰이나 실제 두 사람의 플레이가 아니다. 상점 document 폭375/viewport390, modal 내부340. 마지막 상점/두 번째 탭에서 수집한 console error는 0이었다.
- 세 게임의 현재 시작·진행·결과·복습·상점 코드와 허브를 읽었다. 진행/보상 문제는 아래 [순수 함수 재현](source-checks.json)과 원문을 함께 확인했다. 별지도 다운로드 문제는 해당 분기를 읽고 자동 클릭이 무시되는 메모리 mock에서 재현했다. 실제 Chrome/Safari 차단 빈도를 측정한 것은 아니다.
- 기존 MP3 재생 버튼과 완료 후 UI 전환을 사용했다. 실제 음성을 직접 듣고 자연스러움·발음을 검수한 결과는 아니다. 생성·재녹음은 0이다.
- 실제 계정·DB·운영 함수·SSO·공개 사이트를 변경하지 않았다. 검수용 비회원 진도와 localhost 방만 사용했으며, 생성한 방은 종료했다. 모든 게임 완주와 저장 복원을 새로 실행한 검수는 아니다.

## 가치가 큰 추가 개선 순서

1. **갖고 싶은 보상 → 지금 할 수 있는 학습 한 판.** 상점은 부족한 코인을 알려 주지만 지급 가능한 다음 행동으로 연결하지 않는다. 첫 가게의 최초 시범10회·실전27회 뒤에는 완주 코인을 한 번 받고, 축제/러시/소풍 반복은 추가 코인이 없다(`beginner.mjs:236,249`, `beginner-shop.mjs:71`). 코인을 부족하게 남긴 이용자에게 현재 입문 수준과 실제 보상 조건에 맞는 다음 놀이를 연결하는 것이 우선이다. 이미 받은 완주 보상·오늘 한도를 확인하고 가능한 보상만 안내해야 한다. 무제한 반복 보상을 제안한 것은 아니다.
2. **다음 방문의 선택형 30초 기억 놀이.** 마법의 기존 장 끝 확인, 우주선 결과 직후의3문항 회상은 이미 있다. 다음 날 혼자 돌아온 입구에서 이를 바로 이어 가고, 가게에서 놓친 수량/요청1–2개를 다른 손님에게 다시 써 보게 한다. 기존 승인 음원을 재사용하고 첫 답 전에 정답 그림·철자·뜻을 숨기며 답 뒤 교정한다. 강제·감점 없이 복습으로 표시하고 익숙한 문항의 재답을 새로운 숙달로 부풀리지 않는다.
3. **실제로 완성한 장면을 내 기록으로 남기기.** 우주선 별지도와 자유 실험 사진은 이미 있다. 마법 각 장 완료에서 찾은 소품은 기존 자유 실험 소품과 겹쳐 새 사용 능력이 생기지 않는다(`content.mjs:11–13,38`, `app.mjs:178,215`). 무료 기본 소품을 잠그지 않고 실제 해결한 장면의 작은 기념사진/스탬프를 보관해 ‘내가 끝냈다’는 변화가 남게 하는 제안이다.
4. **협동 전송 버튼의 의미 표지 일관성.** 색 튜토리얼에는 그림과 `red/blue`가 이미 있고 필수로 먼저 진행한다. 실제 설명서의 전송 버튼에서는 한글과 공통 `Send`만 남는다(`spaceship-coop/app.mjs:142`). 초보자 지원을 보강한다면 설명서 역할에만 작은 의미 그림/영어 또는 보내기 전 소리 미리듣기를 제공하는 선택지가 있다. 또 하나의 필수 튜토리얼은 우선 제안에서 제외했다. 조종판에는 친구의 정답 목표를 보여 주지 않고, 도움 사용은 계속 구별한다.

이미 있는 목표 선택/변경/해제, 실제 상품 미리보기, 구매 뒤 즉시 사용, 보유품 바로가기, 무료 기본 복귀, 소풍 변주, 탐험 보관, 첫 응답과 도움 분리는 추가 기능으로 반복 제안하지 않았다. 위 설계가 재참여·기억·재미를 개선한다는 효과는 실제 참가자 확인 전의 판단이다.
