1440 또는 1280px, 390px, 320px에서 실제 Chrome 캡처를 비교했다. 마법은 DPR 2도 확인했으며 논리 좌표와 저장 사진의 960×612 크기를 유지한다. 수정 후 대표 화면을 통합 담당도 독립적으로 열어 확인했고, 작은 화면의 첫 조작 위치·보조 단추의 늘어남·상점 썸네일 비동기 대기를 추가로 바로잡았다. 상점 썸네일은 6개 `data-ready` 및 이미지 decode 완료 뒤 확인한다.

## 변경 후 기능 검증

- 선택 단위·회귀 검사 **114/114**: 공통 음성/허브 서버/키트/컬렉션/차고47, 마법15, 주문39, 우주선13.
- 마법: 최종 상자 자산을 적용한 320px의 18퍼즐·6개 실제 MP3 확인 전체 완주. 독립 듣기의 동일한 사전 시각 조건, 오답/도움 분리, 기록 복구, PNG, 45코인과 재방문 중복 방지를 확인했다. `../../../word-magic/qa/play-small.json`.
- 각 상점 실제 UI **50개 항목**: 마법24, 주문8, 우주선18. 미리보기·구매·장착·부족분·무료 복귀·재로드·저장 실패·키보드를 포함한다.
- 주문 기존 마감8항목 재통과. `../../../order-rush/qa/beginner-polish/results.json`.
- 우주선 두 브라우저의 실제 음성·18수리·역할 교대·이륙·개인 회상·완주 보상 등79체크. `../../../spaceship-coop/qa/ui-results.json`.
- 허브/게임 입구와 복귀6흐름: [통합 결과](../integration.json).
- 게임 간 지갑/보유품/칭호 보존과 두 탭 동시 구매의 1회 차감6흐름: [상점 통합 결과](../shops-integration.json).
- 우주선 그래픽의 정답 그림 분리·음성 완료 잠금·구매/장착에 대한 독립 읽기 검토에서 확정된 회귀를 발견하지 못했다.

기본 Chrome 자동 재생 정책을 사용했다. 상점 시험용 코인은 별도 격리 브라우저에만 넣었다. 새 그래픽 제작 도구와 정확한 프롬프트·원본 위치·런타임 파일은 [로켓 기록](art-source.json), [상자 기록](chest-art-source.json)에 있다. 내장 도구의 정확한 모델·품질 설정은 확인할 수 없었다.

현재 로컬 구현과 브라우저 검증 결과다. 공개 배포·실물 휴대폰·외부 네트워크 두 사람 사용·학생 재미/학습 효과는 확인 범위가 아니다. 기존 별도 검사 실패는 상위 README의 기록을 유지한다.
