## 공통 기준

- 배울 표현을 먼저 보여 주고, 한글을 읽지 않아도 그림·행동·소리로 시작한다.
- 처음부터 시간 제한을 걸지 않는다. 도움과 다시 듣기를 제공한다.
- approved 음성 전체가 준비되기 전 정식 듣기를 시작하지 않는다. 기기 음성으로 대체하지 않는다.
- 퍼즐 조작·협동 성공·그림 체험은 독립적인 듣기 정답의 증거로 기록하지 않는다.
- 로그인한 WORLD의 코인·구매품·지원되는 게임 기록은 계정 저장을 사용한다. 비회원 체험 기록과 전송 대기 초안은 해당 브라우저에 보관한다. 운영 반영·실제 기기 복원과 장기 기억·TOPIK 점수 향상은 각각 별도로 검증해야 한다.
- 실제 펠트 자산, 휴대폰 표시, 키보드, 움직임 감소, 음성 실패·중단, 마지막 화면을 확인한다.
- 학습 허브에서 세 게임을 찾을 수 있게 한다. 두 사람 게임은 혼자 시작하는 첫 경로와 구분한다.

## 각 게임의 상점 · 2026-10-08

| 상점 | 실제 바뀌는 곳 | 입구 |
|---|---|---|
| 마법 상점 | 장면 배경 3종·저장 사진틀 3종 | `/word-magic/?shop=1` |
| 첫 가게 꾸미기 | 가게 간판 3종·서빙 쟁반 3종 | `/order-rush/beginner.html?shop=1` |
| 내 우주선 꾸미기 | 우주 배경 3종·개인 우주선 장식 3종 | `/spaceship-coop/?shop=1` |

각 6개에는 무료 기본 모습 2개가 포함된다. 15/20/35/40 공통 코인으로 꾸미기를 모으며, 미리보기·구매·장착·보유·무료 기본 복귀가 실제 화면에 연결된다. 마법은 사진틀이 다운로드 PNG에도 반영된다. 친구 화면과 듣기 문제의 색상 단서는 꾸미기로 바뀌지 않는다. 모든 학습 내용은 그대로 무료다.

레이싱 차고·말 랠리의 공통 지갑과 실제 장비 적용을 기준으로 비교했다. 기존 허브의 상품/칭호 정의가 공통 원본과 어긋난 점을 복구해, 세 상점과 기존 게임을 오가며 코인·차량·라켓·카페 꾸미기·칭호를 보존한다. [공통 원본·보상 규칙](../play-common/README.md).

상점 반영 후 선택 검사114/114(공통·게임 회귀109 + 우주선 상점·음성5), 실제 상점 UI 50흐름(마법24·주문8·우주선18), 게임 간 거래/저장 통합6흐름과 두 탭 동시 구매1회차감 통과. 마법 전체 완주45코인과 우주선 공동 이륙15코인·재방문 중복 지급 방지도 확인했다. 상점 구매 시험은 격리 브라우저의 시험용 코인으로 진행했다. 게임별 실제 UI 검사와 완주 보상 검증은 `qa/verification.json`의 `shops` 및 개별 `qa/`에 연결한다. 현재 로컬 구현이며 계정별 원격 지갑이나 공개 배포는 아니다.

## 학습한 말로 다시 놀기 · 2026-10-09

상점 상품의 가치를 `구입 → 실제 사용 → 내가 만든 결과`로 연결했다. 목적은 플레이어가 다음 놀이를 스스로 기대하게 하는 것이며, 재미나 학습 효과가 증가했다고 입증한 결과는 아니다.

| 새 상품 | 가격 | 구매 후 실제 행동 | 무료로 남는 것 |
|---|---:|---|---|
| 말의 마법사 — 소풍 실험 세트 | 20코인 | 곰·튜브·간식·상자를 익힌 6개 말로 바꾸고 장면·사진 만들기 | 18퍼즐·6듣기 확인·원래 자유 실험·사진 저장 |
| 첫 가게 — 소풍 친구 초대 세트 | 15코인 | 세 친구의 주문을 듣고 음식을 건네 소풍 장면 완성 | 본편 4가게·27주문·도움·급행·기존 복습 |
| 협동 우주선 — 우리의 탐험 별지도 | 30코인 | 실제 끝낸 18수리를 3개 별자리로 모으고 PNG 기념사진 저장 | 2인 전체 탐험·회상·기본 완료 기록·7개 표현 다시 듣기 |

마법은 첫 장 보상 15코인에 선택 실험 5코인을 더하면 소품을 살 수 있다. 선택 실험은 무료 기본 소품에서도 가능하다. 소리 재생 뒤 서로 다른 주문-물체 조합 3개를 실제로 바꾸되 주문 2종·물체 2종 이상을 쓴다. 같은 단추만 누르거나 미리보기로 코인을 받지 못한다. 서울 날짜 기준 하루 한 번이며 기존 공통 코인 보상 10회 안에 포함한다. 코인을 다 받아도 자유 실험은 계속한다.

주문은 첫 본편을 도움받아 끝내도 받는 최소 15코인으로 구매할 수 있다. 이미 익힌 범위의 주문을 사용하고, 본편 시작 전에는 물·빵을 따라 해 보는 시범으로 표시한다. 소풍의 별도 코인·정답 성적은 없으며 세 친구에게 음식을 건넨 장면 자체가 완성 보상이다. 우주선은 공동 이륙 두 번의 30코인으로 목표에 도달한다. 최근 6개 실제 탐험만 보관하고 탐험 ID로 중복을 막으며, 방 코드·연결 토큰을 수집품에 담지 않는다. 상점 예시는 실제 완료 기록으로 저장하지 않는다.

각 상품은 목표로 직접 고르거나 바꾸고 해제할 수 있다. 상점·결과·허브에서 같은 지갑의 현재 부족분/구매 가능/수집 완료를 보여 주고, 구매 후 바로 실제 놀이로 이어진다. 기간 한정·랜덤 보상·연속 출석 손실은 추가하지 않는다. 꾸미기 상품도 어디에서 쓰이는지 설명하고, 학습 단서나 성공 확률을 유료로 바꾸지 않는다.

구현된 연습은 **TOPIK I에 앞선 크기·위치·색·수량의 기초 어휘와 짧은 부탁 듣기**다. 소풍 상황의 표현 재사용과 협동 표현 회상은 가능하지만, 안내를 따른 조작·함께 해결한 수리·구매나 사진 저장을 독립적인 듣기 정답으로 계산하지 않는다. 재참여율·지연 회상·재미 평가는 실제 초보 학습자로 별도 확인해야 한다.

설계 근거: [Ryan·Rigby·Przybylski(2006)](https://selfdeterminationtheory.org/SDT/documents/2006_RyanRigbyPrzybylski_MandE.pdf)의 선택권·유능감·관계성과 게임 즐거움/재참여 연구를 참고해, 직접 고르는 목표·내가 만든 결과·함께한 기념품으로 구현했다. [Sailer·Homner(2020)](https://link.springer.com/article/10.1007/s10648-019-09498-w)의 메타분석에서는 동기·행동 효과가 엄격한 연구에서 덜 안정적이었으므로, 이 상품 설계를 검증된 학습 효과로 소개하지 않는다.

## 구매 뒤 다시 놀기와 소중한 기록 · 2026-10-09 후속

- **소풍 재도전:** 같은 학습 진도에서도 직전과 다른 물건 순서·친구 순서를 만든다. 이미 익힌 표현과 승인 MP3만 쓰며, 첫 시범은 물·빵의 그림 안내를 유지한다. 별도 방문 기록으로 재로드 뒤 변주가 이어지고 기존 본편 기록·코인은 바꾸지 않는다. 저장 실패 시 현재 페이지의 변주는 계속하고 재로드 후 이어짐이 제한됨을 안내한다.
- **탐험 보관:** 최근 6개와 별도로 소중한 탐험을 보관한다. 보관 해제는 즉시 삭제하지 않고, 다음 새 완주에서 최근 6개 정책을 적용한다. 완료 날짜를 그대로 유지한다. 기존 V1 기록을 읽고, 탐험별 보관 데이터와 Web Lock으로 다른 탭의 새 기록이 보관품을 덮어쓰지 않게 한다. 무료 기록/소리와 소유자의 별지도·PNG 구분은 유지한다.
- **보유품 바로가기:** 허브 카드에서 상점과 ‘내 놀이’를 분리했다. 마법은 `/word-magic/?play=lab&item=magic-toys-picnic`, 소풍은 `/order-rush/beginner.html?play=picnic`, 별지도는 `/spaceship-coop/?collection=starbook`으로 연결한다. 게임이 보유를 다시 확인하고 준비 화면의 실제 클릭 후 음성을 시작한다. URL만으로 구매·해금·차감하지 않는다. 기존 `shop=1`은 그대로다. 마법의 중단한 본편과 주문의 체크포인트, 우주선의 현재 방을 보존한다.

게임 코드 회귀 86개와 실제 연결·모바일·실패 상태를 확인했다. [최신 후속 검증](qa/return-play/RESULTS.md). 허브의 현재 없는 일곱 여정 모듈 요청도 실제 공통 완료/칭호 기록으로 교체해 404 없이 연결한다.

## 그래픽 재구성 · 2026-10-08~09

- **말의 마법사:** 늘어난 펠트 판으로 채운 장면을 실제 원경·작은 작업대·접촉 그림자가 있는 무대로 바꿨다. 아치의 통과 가능 여부가 축소 전후에 분명히 보이게 조정하고, 문·책 구조와 전용 보물상자 두 상태를 연결했다. 고해상도 Canvas를 지원하면서 저장 PNG는 960×612를 유지한다. 상점의 여섯 썸네일도 상품이 적용된 실제 장면이다.
- **주문 폭주 입문:** 거친 전체 질감과 카페를 가리던 덮개를 걷고 승인 카페 원본, 손님, 카운터를 배치했다. 주문표와 읽기 면을 분리하고 모바일 실제 주문 무대를 160px로 줄여 첫 재료 선택이 화면 안에 들어온다. 필수 번역·안내는 12px 이상이며 키보드와 기록 설명은 접어 둔다.
- **협동 우주선:** 네모 쿠션 몸체를 전용 펠트 로켓으로 바꾸고, 승인 몽글·개인 배지를 별도로 얹었다. 행성·도킹 장면과 실제 엔진/안테나/연료 수리 진행계, 상태에 따른 반응을 연결했다. 친구의 정답 그림과 듣기 조작 잠금은 유지한다.
- **허브·상점 모음:** 크게 늘어난 쿠션 카드 대신 각 놀이의 장면을 먼저 보여 주고, 설명은 흰 면에서 읽도록 바꿨다. 같은 놀이의 입구와 상점에 같은 그림을 사용한다.

새 로켓과 보물상자는 내장 `image_gen`으로 만들었다. 도구가 세부 모델·품질 설정을 노출하지 않아 특정 모델 사용으로 보고하지 않는다. 승인 마스코트·음성은 재생성하지 않았다. 원본·파생 경로와 실제 프롬프트: [로켓](qa/graphics/art-source.json), [보물상자](qa/graphics/chest-art-source.json). 각 게임의 `qa/`에는 동일 크기의 수정 전후 화면이 있으며 통합 확인은 [그래픽 검증](qa/graphics/RESULTS.md)에 둔다.

## 음성 준비

`voice-request.json` → 기존 `node tools/미니게임_목소리.cjs --dry-run --game beginner-games`로 비용·캐시를 점검한다.
기존 Typecast 도구의 월 크레딧 확인·캐시·중단 정책을 재사용한다. 여기서 별도 결제나 합성을 실행하지 않는다.
원본·제작 설정은 저장소 밖 캐시와 `qa/voice.source.json`, 게임용 파일에는 문구·경로·길이만 둔다.

세 게임 목록(`word-magic/audio/manifest.json`·`order-rush/assets/beginner/voices.json`·`spaceship-coop/assets/audio/manifest.json`)은 synk.im에 그대로 공개되므로 승인 칸 `provider`에 만든 서비스 이름 대신 중립 값 `approved-voice-v1`을 둔다(2026-10-19, 옛 값은 서비스 이름 `typecast`). 만든 길: Typecast API로 해설(10-08 서현)을 `tools/미니게임_목소리.cjs`로 굽고, `node experiences/beginner-games/sync-banks.cjs`가 세 게임에 복사하며 이 값을 쓴다. 이 값을 승인 조건으로 보는 곳은 주문 폭주 입문 `beginner-core.mjs`(`validateVoiceManifest`)·우주선 `audio.mjs`·SYNK-website 출시 도구 `prepare-play-candidate.mjs`(`inspectVoices`)라, 바꿀 때는 목록과 함께 셋을 같이 바꾼다. `voice.test.cjs`가 세 목록의 값과 도구·목소리 이름이 없음을 본다.

## 로컬 실행

`node experiences/learning-hub/server.mjs`의 학습 허브에서 입장한다. 현재 준비·검증 상태는 `qa/verification.json`에 남긴다.

개별 원문: [말의 마법사](../word-magic/README.md), [주문 폭주 입문](../order-rush/README.md), [협동 우주선](../spaceship-coop/README.md).
입문 카드에서 두 솔로 게임을 먼저 고를 수 있고, 협동은 두 사람이 같은 서버 주소에 접속한다. localhost 주소는 현재 컴퓨터용이며 공개 서비스 주소가 아니다.

## 검증 명령과 경계

2026-10-08 후속 마감에서 첫 선택의 한영 안내, 소리 필요 조건, 두 사람·두 화면 안내와 게임 사이 이동을 보강했습니다. 마법의 물체·주문의 쟁반을 중간 저장하고, 재생·오답·다음 화면 전환에서 키보드 초점과 휴대폰 스크롤을 복구합니다. 우주선은 복사 권한 실패 안내를 바로잡고, 한 사람이 새 탐험을 열어도 상대가 결과를 계속 볼 수 있게 했습니다.

상점 추가 전 마감에서는 선택 검사 **83/83**, Atlas 사본 일치, 허브 1280/390/320px 및 세 게임 입구 6개 검사를 통과했습니다. 마법은 320px에서 18퍼즐·확인 6개를 재완주하고 복귀 마감 5흐름을 확인했습니다. 주문은 실제 음성 마감 8흐름과 결과 화면 3크기를 확인했습니다. 우주선은 상점 연결 후 두 브라우저의 실제 18수리·3문항 회상·완주 보상까지 79체크를 통과했습니다. 최신 상점 검사 합계는 위 상점 절을 따릅니다. 각 `qa/` 원문은 전체 완주와 필요한 장면의 저장 fixture 사용, 실제 뒤로가기와 합성 페이지 복귀 이벤트를 구분합니다.

- `node --test experiences/word-magic/core.test.mjs experiences/spaceship-coop/server.test.mjs experiences/order-rush/beginner.test.mjs` — 게임 상태·학습 판정·협동 권한.
- `node --test experiences/beginner-games/voice.test.cjs experiences/learning-hub/server.test.mjs experiences/play-common/kit.test.mjs` — 음성 무결성·실제 허브 연결·비공개 서버 파일·공통 키트.
- `node experiences/beginner-games/qa/integration.cjs` — 기본 주소 4340, 1280/390/320px 허브 및 세 게임 입구.
- `node experiences/beginner-games/qa/voice-check.cjs` — 설치된 로컬 음성 인식만 사용, 네트워크·추가 비용 없음. 26개 요청 의미와 받아쓰기 대조. 사람의 청취 확인과는 구분한다.

각 게임 `qa/`에는 실제 MP3를 재생한 완주와 오류·재접속·저장 시험 및 화면을 둔다. 소리가 끝났다는 브라우저 기록은 사람의 청취·학습 효과·재미 검증을 대신하지 않는다.

## 실제 초보자 확인에 남은 일

아래는 아직 수행하지 않은 관찰 절차다. 운영 반영과 실제 계정 복원을 확인한 뒤 한국어를 처음 배우는 참가자에게 진행한다. 개발자가 대신 조작하거나 합성 진도·시험 코인을 넣은 결과와 구분한다.

| 확인할 점 | 참가자가 하는 일 | 남길 관찰 |
|---|---|---|
| 처음 시작하기 | 허브에서 혼자 할 게임을 골라 안내를 듣고 첫 행동을 한다. 진행자는 먼저 조작법을 설명하지 않는다. | 첫 행동까지 걸린 시간, 멈춘 화면, 요청한 도움. 소리를 못 들은 경우와 뜻을 모른 경우를 구분한다. |
| 배운 말로 행동하기 | 말의 마법사와 주문 입문에서 처음 보는 문제를 듣고 직접 조작한다. | 첫 응답, 다시 듣기, 그림·문자 도움 사용 여부. 도움을 받은 성공은 독립 듣기 성공과 따로 적는다. |
| 상점의 동기 확인 | 원하는 상품을 스스로 고르거나 아무것도 고르지 않고, 얻은 코인으로 구매 여부를 결정한다. | 고른 이유, 가격/부족분 이해, 구매 후 실제 사용, 다음 놀이를 스스로 시작했는지. 구매를 권유하지 않는다. |
| 함께 놀기 | 두 초보자가 각자 화면에서 역할을 바꾸며 우주선을 수리한다. | 한 사람이 대신 해결했는지, 전달과 듣기 중 막힌 지점, 재접속 후 이어지는지. 공동 완주를 개인 듣기 성적으로 바꾸지 않는다. |
| 다시 기억하기 | 다음 날 배웠던 표현을 한글·기존 정답 배치의 도움 없이 듣고 의미를 고른다. | 표현별 첫 응답과 자신감, 재시도 여부. 새 음성 제작 없이 승인된 음성을 사용한다. |

기록에는 참가자 이름·로그인 토큰 대신 익명 번호, 기기/언어 환경, 게임, 관찰한 행동과 참가자의 말만 남긴다. 소규모 관찰의 정답 수·재방문 의향으로 장기 학습 효과나 TOPIK 점수 향상을 입증했다고 보고하지 않는다. 반복해서 막히는 조작·안내·상품 사용 지점부터 고치고 다시 확인한다.

실제 기기 검증은 별도로 같은 계정의 PC→휴대폰 구매품·잔액·진도·즐겨찾기 해제 복원, 로그아웃 뒤 이전 계정 접근 차단, 서로 다른 네트워크의 협동 연결을 확인한다. 자동화된 브라우저 두 컨텍스트 결과로 대체하지 않는다.

공통 범위를 넓혀 검사했을 때 기존 `learning-hub/catalog.test.mjs`의 입장 검사 문항 가족 목록 1건, `tests/미니게임_목소리.test.cjs`의 리듬 문구/녹음 원고 불일치 2건이 남았다. 새 입문 게임이 수정하지 않은 영역이다. 리듬 새 문구의 재녹음 대기는 `docs/_ops/트랙.md`의 10-08 기록에 이미 별도로 남아 있다. 전체 저장소 검사 통과로 보고하지 않는다.
