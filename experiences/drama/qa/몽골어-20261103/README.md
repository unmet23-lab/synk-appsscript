**일부러 남긴 것:** ① 「Драмаар ярих」 — 제품 이름이고 유호님이 승인한 참여 안내(설계 §B)와 같다. ② 뜻 글 속 「«선배» · «선배님»」 — 두 말의 차이가 1화에서 배우는 것이라 한글 그대로 따옴표 안에 둔다(문법 층은 「파손」으로 본다). ③ 「Дубль」 — 맞춤법 사전에 없는 외래어(화면 말 「테이크 2」). ④ 6판 문법 층이 함께 짚은 「Зүгээр дээ, юу ч биш」(「에이, 뭘요」의 뜻 글 — 입말 그대로) · B 카드의 「өөр нэг оюутнаас」(「다른 선배」가 과제) · 단추 이름 «Өөр үгээр дахиад нэг»(화면 단추 글 그대로).

**문법 층은 여기서 닫는다(11-04):** 7판의 고친 다섯 줄 다시 확인에서 나온 지적을 위 칸에 반영했다. 뒤는 화면 검수 `drama-mn-ui-20261104`(아르곤 → Fable)와 공개. 390폭 캡처(틀 시험 · WORLD 언어 mn): 첫 화면 · 받아쓰기 안내 · 대사 카드에서 넘침 없음 — 칩 글이 길어 언어 단추가 밀려나던 것은 칩을 「Бичвэр: асаалттай」로 줄여 고쳤다.
