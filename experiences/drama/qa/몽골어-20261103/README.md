**일부러 남긴 것:** ① 「Драмаар ярих」 — 제품 이름이고 유호님이 승인한 참여 안내(설계 §B)와 같다. ② 뜻 글 속 「«선배» · «선배님»」 — 두 말의 차이가 1화에서 배우는 것이라 한글 그대로 따옴표 안에 둔다(문법 층은 「파손」으로 본다). ③ 「Дубль」 · 「клубуудын」 — 맞춤법 사전에 없는 외래어.

**남은 것:** 5판의 3층 다시 확인(바뀐 줄만, 통로 실패 묶음 셋 포함). 그 뒤 화면 검수(아르곤 → Fable — 언어 고르기 · 뜻 · 카드 글이 바뀌므로 Fable 최종까지)와 공개. 390폭 캡처(틀 시험 · WORLD 언어 mn): 첫 화면 · 받아쓰기 안내 · 대사 카드에서 넘침 없음 — 칩 글이 길어 언어 단추가 밀려나던 것은 칩을 「Бичвэр: асаалттай」로 줄여 고쳤다.
