# 드라마 말하기 — 운영 왕복 확인 (2026-11-11)

몽골 학습자 시범([설계](../../../../docs/드라마말하기_몽골시범_20261103.md) §7 ③ · ⑧)의 출발 전 확인이다. 공개본 `synk.im/world/?drama=1`을 ego 브라우저의 실제 로그인 계정(유호님 시험 계정)으로 열고, 합성 마이크로 **장면 → 코치 노트 → 한 번 더 → 새 상황**을 돌린 뒤 운영 서버 기록을 집계 도구로 읽었다. 받아 적기가 운영에서 실제 계정으로 돈 첫 확인이다(11-04 왕복은 크레딧이 없어 받아 적기 없이 돌았다).

**결과: 통과. 고친 것 하나 — 집계 도구가 운영이 아니라 리허설 DB를 읽고 있었다.**

## 본 것

| 단계 | 화면에서 본 것 |
|---|---|
| 첫 실행(새 기기 꼴) | 언어 → 한글 물음 → 튜터 고르기 → 「SYNK ID로 로그인하기」가 비밀번호 없이 끝남(SYNK ID 세션이 살아 있을 때). 로그인 뒤 주소에서 `?drama=1`이 빠져 링크를 다시 열어야 드라마 창이 뜬다 — 가입 안내 그림의 「링크 다시」 그대로 |
| 계정 기록 | 로그인하자 계정 기록이 서버에서 내려옴. 학습 통로 `SYNKLearningHost.status()` = `synced · queued 0 · durable` |
| 받아쓰기 | 「장면 시작」 → 첫 상대 대사 뒤 「내 목소리를 받아 적어 볼까요?」 → 「보내고 받아 적기」 → 칩 「받아쓰기 켜짐」 |
| 장면(판정 갈래) | 모범 소리는 「Nice」와 함께 빈칸이 채워짐(7 · 8번 줄). 반말 소리(6번 줄 「응, 맞아. … 헤맸어.」)는 되묻기 → 대사 보임 → 세 번째에 다음 줄로 |
| 코치 노트 | 장면 끝 「코치 노트 — 처음 만난 선배에게는 끝에 '요'를 붙여 봐요. 맞아 → 맞아요」 |
| 한 번 더(테이크 2) | 모범 소리로 다시 → 「받아 적은 글: 네, 맞아요. 길을 잃어서 한참 헤맸어요. 이번에는 받아 적은 글에서 그 부분이 들렸어요.」 |
| 노트 없는 판 | 줄마다 마지막 판정에 노트가 없으면 「다른 말로 한 번 더」(교정이 아니라 연습) — 한 번 더 뒤 「받아 적은 글에서 대사의 중요한 말을 찾았어요」 |
| 새 상황(t9) | 「받아 적은 글: 선배님, 이 근처에 편의점 있어요? 받아 적은 글에서 장소와 묻는 말을 찾았어요.」 → 「마치기」 → 오늘 기록(장면 3줄 중 3줄 · 새 상황은 모범을 보지 않고 첫 시도) |
| 서버 | 단계마다 `synced · queued 0`, 서버 순번이 테이크만큼 올라감 |

테이크는 장면 두 판 + 한 번 더 둘 + 새 상황 하나로 13번을 썼다(하루 30번 안). 소리는 11-10 [합성 기준선](../리허설-20261110/README.md)의 것이다 — 모범 읽기 6 · 7 · 8, 6번 줄 「요 빠짐」, 새 상황 t9 허용 변형.

## 집계 도구로 읽은 서버 기록

`node tools/드라마시범집계.mjs --참가 <시험 계정 한 줄> --관리`(읽기 전용, 설계 §8 ⑦ 승인 범위) — 숫자만:

- 계정 찾음 1 · 학습 기록 동의 1 · 드라마 기록 있음 1
- (가) 장면을 끝낸 사람 1명 중 1명 · 노트를 받은 사람 1명 중 1명(끝맺음 1) · **고친 사람 1명 중 1명**
- (나) B를 본 사람 1명 · B 첫 판정 테이크 0 — 이 계정은 11-03에 받아 적기 없이 t9를 먼저 봐서 「판정 없이 지나감」으로 남는 것이 맞다(설계 §7 ③). **새 계정의 B 첫 판정 → 8일 뒤 C 사슬은 이 확인으로 보지 못했다** — 첫 참가자(또는 유호님 실기 한 바퀴)가 첫 실측이다.
- 인식: 판정 보류 1(일부러 다른 줄 소리를 넣은 테이크), 장면 시작 → 첫 테이크 12초

판정 갈래(`choice`) · 코치 노트(`explanation`) · 테이크 2 판정이 운영 서버에 남고 집계가 그것을 읽는다는 것까지가 이번에 확인한 범위다. 합성 소리로 본 것이라 학습자 성과가 아니다.

## 고친 것 — 집계 도구가 리허설을 읽었다

처음 돌린 집계는 방금 기록을 남긴 계정을 「계정 없음(none)」으로 냈다. `--관리`가 talk `.env`의 `SUPABASE_PROJECT_REF`를 따라갔는데 그 기본값이 리허설 프로젝트다. 그대로 두면 11-19부터 저녁 집계가 참가자 전원을 「없음」으로 낸다. `--관리`는 늘 운영을 읽게 고쳤다(`managementTarget`, 환경 변수로 직접 준 값만 바꾼다) — 읽는 곳을 한 줄 찍고, 목록에 사람이 있는데 계정을 하나도 못 찾으면 주의 줄을 찍는다. 시험 `tests/drama-pilot-tally.test.mjs` 9/9.

## 다시 돌리는 법

1. ego로 `https://synk.im/id/`를 열어 「로그인됐어요」를 본다(없으면 유호님 로그인 한 번 — 비밀번호는 넣지 않는다).
2. `https://synk.im/world/?drama=1` → 처음 여는 작업 공간이면 「CLICK TO START」 → 언어 → 한글 물음 → 튜터 → 「SYNK ID로 로그인하기」 → 같은 주소를 다시 연다. 드라마 창은 부모 문서 안 같은 출처 틀(`iframe[src$="/world/drama/"]`)이다.
3. [`왕복도우미.mjs`](왕복도우미.mjs)를 ego 스크립트에서 불러 쓴다(각 함수는 11-11에 이 꼴로 돌았고, 한 파일로 묶어 처음부터 끝까지 한 번에 돌린 적은 없다 — 단계마다 화면을 읽고 다음으로 간다).
   - `injectSynth(page, { 이름: base64 })` — 틀이 열린 뒤, 소리 파일을 Node `fs`로 읽어 넘긴다.
   - `clickFrame(page, '장면 시작')` → 첫 차례 전 대화 창에서 `clickFrame(page, '보내고 받아 적기')`.
   - `runScene(page, pick)` — `pick(panel)`이 화면 대사를 보고 소리 이름을 고른다. 노트 길을 보려면 한 줄에 세 번 다 틀린 소리를 준다(노트는 줄마다 **마지막** 판정 테이크로 정해진다 — 첫 판에서 다음 줄 소리를 넣어 노트가 안 나왔다).
   - `clickFrame(page, '한 번 더 하기')` → `take(page, '<모범 소리>')` → `clickFrame(page, '새 상황으로')` → `take(page, '<t9 소리>')` → `clickFrame(page, '마치기')`.
   - 단계마다 `readFrame(page)`와 부모 창 `SYNKLearningHost.status()`(`synced · queued 0`)를 본다.
4. 서버 기록은 시험 계정 한 줄짜리 목록(비공개 보관함, 저장소 밖)으로 `node tools/드라마시범집계.mjs --참가 <목록> --관리`.

소리 원천: 모범 읽기는 `experiences/drama/s1/소리/ep01-model-0N.mp3`, 틀린 소리 · t9는 공용 작업본 `.tmp/drama-rehearsal-20261110/`(git 밖, `takes.json`에 줄 · 말 · 기대).
