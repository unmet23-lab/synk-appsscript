# 문지영 교수 새 얼굴 (2026-11-05 ~ 06)

**왜:** 11-05 밤 유호님 「지금 교수님 얼굴이 예전버전이야 제미나이로 새로 뽑아야지 지금 GPT로 만든 슬롭처럼 생겼어」. 10-30 승인 판(1화 연구실 `office-real`, GPT Image 2.5)은 매끈한 화보 결이고, 11-04 실존 인물 대조에서 아르곤 「높음」 · GPT 「중간」으로 걸려 다시 굽기로 정해져 있었다([결정](../../../../docs/_ops/결정.md) 11-04 「싱크타운 카운터 · 문지영 교수 얼굴 다시 굽기」).

**지금 쓰는 곳:** 공개 화면에는 교수님 얼굴이 없다. 옛 얼굴은 제2의 나 시험 결과 페이지(T-A 첫 3분 판)와 싱크타운 카페 카운터 시안(12/1 시연 · 사업계획서용, 11-04부터 쓰지 않음)에 있다.

**굽는 법:** 나노바나나 2.1(Gemini Ultra 웹 「4 Argon」 · 사고 수준 높음). 옛 얼굴은 참고로 넣지 않고 글로만 새로 굽는다. 틀은 유호님이 고른 태오 「덧니 선배」와 같다(`../쇼케이스-20261031/새얼굴후보.mjs` — 얼굴마다 꼭 보일 특징 둘). 11-05 로맨스 지적(「앵글이 슬롭 · 맹해」)대로 얼굴을 가운데서 비키고, 한쪽 창빛 · 녹은 배경 · 말을 꺼내는 순간을 지시문에 적는다. 옛 얼굴에서 걸린 넷(새치 섞인 단발 · 아치형 눈썹 · 짙은 쌍꺼풀 · 도톰한 입술)은 어느 후보도 쓰지 않는다.

```
node experiences/drama/qa/문교수얼굴-20261105/후보.mjs            # → 공용 작업본 .tmp/prof-face-nb/jobs.json
bash .tmp/prof-face-nb/돌림.sh "prof-gb:1 prof-na:1 …"           # 공용 차례(gemini)를 잡고 굽는다, 뒤에서
PROF_NOGLASS="prof-gb_g1" node experiences/drama/qa/문교수얼굴-20261105/후보.mjs   # 안경 뺀 사본 일감을 더한다(역검색 전용)
node experiences/drama/qa/제2의나-20261102/조각/실존대조.mjs 렌즈 prof-x=<그림>…   # 실존 인물 대조 — 절차는 조각 README
node experiences/drama/qa/제2의나-20261102/조각/실존대조.mjs 모델 <묶음> prof-x=<그림>…
```

실행기(`gem21.mjs` · `take.mjs` · `run.sh` · `차례.sh` · `돌림.sh`)는 조각 실행기 `.tmp/me2-20261102/piece-nb/`를 경로만 바꿔 옮긴 것이다. 그림 · 고르기 판은 모두 git 밖 `.tmp/prof-face-nb/`(`out/` · `고르기판*.jpg`)이고, 대조 기록은 `.tmp/me2-20261102/piece-check/prof-*`다. 실존 인물의 이름 · 사진은 저장소에 적지 않는다.
