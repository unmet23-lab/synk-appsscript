# 「제2의 나」 셀카 한 장면 시험 (2026-11-02)

유호님 질문: 「태오가 유저에 반응하면서 실제로 같이 셀카 찍는 것처럼, 배경도 자연스럽게 할 수 있을까? 유저는 실제 얼굴이 아니라 게임 속 캐릭터로.」 같은 날 유호님은 [결 시안](../결/README.md) 「엔진 B 얼굴 고정 시험」의 B 원본 2판을 「가장 자연스럽게 잘생겼다」고 보셨고, 이 시험을 「시험해 봐」로 맡기셨다. [제2의 나 설계](../../../../../docs/제2의나_설계_20261102.md) 4절 「10% 콘텐츠」 가운데 학생증 셀카를 한 장면짜리 흐름으로 만들어 본다.

**흐름(1화 식당 끝, 20초쯤):**
1. 태오가 먼저 제안한다(「바트에르덴, 첫날 기념으로 한 장 찍자!」).
2. 앞카메라 미리보기가 뜬다 — 「준비」 사진, 태오가 화면을 보며 앞머리를 만진다.
3. 학생이 포즈 셋 중 하나를 고른다. 포즈마다 외치는 말이 하나씩 붙는다: 「김치!」(브이) · 「한 입만!」(김치 내밀기) · 「파이팅!」(주먹).
4. 하나 · 둘 · 셋 뒤 셔터가 터지고, 태오가 그 포즈에 맞춰 반응한 사진이 나온다(손하트 · 받아먹기 · 어깨동무).
5. 「한 장 더!」를 누르거나 단톡방에 올린다.
6. 단톡방에서 교수님 · 선배가 반응한다.
7. 사진이 추억 앨범에 담긴다.

사진은 모두 조각마다 미리 굽고, 「준비 → 찰칵」 두 장을 바꿔 끼운다(11-01 카페 손님 표정과 같은 방식). 학생 얼굴은 처음에 고른 조각(T-C 몽골 남 `mn-m`)이고 실제 얼굴은 받지 않는다.

**굽기:**
