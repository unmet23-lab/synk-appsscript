## 돌리는 법

```
node 굽기.mjs 줄                 # 20줄 보기(네트워크 없음)
node 굽기.mjs 견적               # 힉스필드 견적(크레딧 안 나감)
node 굽기.mjs 굽기 --하나        # 한 줄만 굽고 실제로 빠진 크레딧 확인
node 굽기.mjs 굽기 [--상한 40] [--이번상한 2]   # 나머지(이미 받은 줄 · 접수한 줄은 다시 내지 않음, 이번 실행 몫을 넘으면 멈춤)
node 굽기.mjs 맞추기             # 1화 승인 녹음 평균 크기(LUFS)로 맞춘 사본
node 굽기.mjs 받아쓰기           # OpenAI gpt-transcribe(월 크레딧 키 차례, 바닥이면 멈춤)
py -3 -I -X utf8 듣기재기.py     # 로컬 받아쓰기 둘 + 쉼 · 빠르기 · 음높이 재기
node 굽기.mjs 표                 # 표.md · 표.json · 듣기.html
```

작업 폴더 기본값은 공용 작업본 `.tmp/me2-20261102/T-B/`(git 밖): `받은/`(받은 그대로) · `맞춘/`(크기 맞춘 사본) · `기록.json`(작업 번호 · 접수 시각 · 거래 · 잔액) · `재기.json` · `표.md` · `표.json` · `듣기.html`(20줄과 1화 견본을 나란히 듣는 로컬 쪽).

굽는 길은 1화 목소리 후보와 같다 — 힉스필드 founder 계정 CLI `elevenlabs_v4`, `--dialogue` 한 줄 · `voice_type: preset` · `--stability 0.5`, 접수는 `--wait` 없이 하고 `generate wait`로 따로 기다린다. 줄마다 접수 시각 뒤의 「Eleven v4」 거래를 찾아 실제 크레딧을 적는다.

## 2판 — 선배가 「아/야」 없이 부르기(11-02)

막힌 이름 넷(마이 · 투안 · 자수르 · 엥흐진)을 Julian이 「○○! 여기야!」로 한 줄씩(`줄.mjs`의 `이름만`, 파일 `맞춘/<번호>-선배이름만-<이름>.mp3`). 꼬리표는 부르는 힘이 나게 1화 줄 가운데 사람을 부르는 말에 쓴 `[cheerful]`(감독 「자, 리딩 들어갑니다.」) — Julian 자기 줄의 꼬리표에는 부르는 말이 없다. `node 굽기.mjs 굽기 --이번상한 2`로 4줄 0.92크레딧(줄당 0.23, founder 168.97 → 168.05). 크기 · 받아쓰기는 첫 판과 같다. 꼬리표와 「아/야」를 함께 바꿨으므로 둘 중 무엇이 차이를 냈는지는 가르지 못한다.

| 이름 | 아/야 판(friendly) → 이름만 판(cheerful), 주 귀 / 다른 귀 | 음높이 폭(10~90%) | 높은 음(90%) |
|---|---|---|---|
| 마이 | 「마야」 틀림 / 틀림 → 「마이」 **맞음 / 맞음** | 2.0 → 10.3반음 | 223 → 312Hz |
| 투안 | 「트완아」 틀림 / 틀림 → 「스완 · 수완」 틀림 / 틀림 | 6.3 → 7.6반음 | 220 → 310Hz |
| 자수르 | 「자수류야」 틀림 / 틀림 → 「자수르」 **맞음** / 「사수루」 틀림 | 5.0 → 2.6반음 | 211 → 299Hz |
| 엥흐진 | 「앵회진아」 틀림 / 맞음 → 「앵그진 · 앵그즌」 틀림 / 틀림 | 4.7 → 14.8반음 | 201 → 313Hz |

- 맞게 들림(주 귀) 0/4 → 2/4, 두 귀 중 하나라도 1/4 → 2/4. 「아/야」가 이름 끝과 뭉개지던 마이 · 자수르는 살아났다.
- 투안 · 엥흐진은 「아/야」를 빼도 이름 자체가 다르게 들린다 — 「투」가 반모음 · ㅅ으로 줄고, 「엥흐」의 ㅎ이 ㄱ으로 들린다. 같은 이름의 교수 줄(「투안 씨」 · 「엥흐진 씨」)은 맞게 들렸으니 Julian이 빨리 · 세게 부를 때의 문제로 보인다.
- **`[cheerful]`은 Julian을 크게 높였다**: 최고 음이 298~314Hz로 1화 Julian 승인 일곱 줄의 최고 음(163~280Hz, 가장 높은 「선배님은 좀 부담스러운데…」 280Hz — `tools/목소리엉킴.py`)보다 1~2반음 위이고, 중앙 기본음(자기상관)도 150~170 → 222~244Hz로 승인 줄(127~190Hz)보다 한참 높다. 부르는 힘은 생겼지만 1화 Julian과 다른 사람 · 과한 연기로 들릴 수 있다 — 귀로 볼 것. 이름 부분도 3.6~4.4음절/초로 길게 끈다(멀리 부르는 말이면 자연스러울 수 있음).
- 음높이 폭은 끝 한두 프레임에 끌리지 않게 10~90% 사이로 쟀다(`듣기재기.py` `폭p10p90반음`). 끝과 끝 폭은 `재기.json`의 `폭반음`.
