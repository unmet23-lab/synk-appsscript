# 「제2의 나」 사진 아바타 — 자체 GPU + 오픈 모델 견주기 (2026-11-03)

11-03 유호님 「시범은 api로 … 나중에는 자체 gpu + 오픈모델로」([결정](../../../../../docs/_ops/결정.md) 11-03). 옮기기 전에 같은 대상 · 같은 숫자 · 같은 Fable 검사로 견준다는 약속대로, [사진시험](../사진시험/README.md)의 GPT 이미지 2.5 판과 같은 입력 · 같은 지시문으로 오픈 편집 모델을 구웠다.

## 어떻게 구웠나

- **어디서:** 집 GPU(RTX 5090 노트북 24GB)는 11-03 저녁 아이돌 LoRA 학습 사슬(f11 뒤로 일곱 줄, 한 번 약 2시간 20분)이 잡고 있어 「바쁘면 ZeroGPU로」(현장노트 영상 · 렌더 장비)에 따라 허깅페이스 ZeroGPU에서 돌렸다. 유호님 사진이 닿으므로 남의 데모가 아니라 우리 비공개 Space 넷(`q121235/me2-qwen2511` · `me2-firered11` · `me2-longcat` · `me2-longcat-turbo`, 코드 [space/app.py](space/app.py) — 모델만 불러 받은 지시문 그대로)에서, 한 번 부를 때마다 `tools/허깅페이스.py` 한도지키기로. 현금 0.
- **GPU:** ZeroGPU는 RTX Pro 6000(96GB) 반쪽(48GB)이 기본이고, Qwen 계열 bf16 묶음(57.7GB)은 반쪽에 안 들어 온쪽(xlarge, 한도 2배)으로 돌렸다. 그래서 아래 「GPU 초」는 그대로 「회사에 RTX Pro 6000 한 장(또는 반쪽)을 두면 걸릴 시간」으로 읽힌다(허깅페이스 Jobs 대여가 RTX PRO 6000 96GB 시간당 $2.75 — [크레딧](../../../../../docs/AI_계정과_크레딧.md#허깅페이스)).
- **같은 입력:** 사진시험과 같다 — 올린 사진 셋(유호님 `ref_pro01_face` · 대역 u1 · u2)으로 기준 「강」, 지어낸 36 · 45 · 52세로 나이 「강+」(늘 19~20살 + 「열아홉 얼굴」 단락), 옷장은 GPT 「강」 기준 판에 머리 둘 · 옷 · 액세서리(편집 능력만 견주려고 GPT와 같은 입력 판).
- **같은 지시문:** Qwen 계열은 GPT에 넣은 지시문 파일 그대로(1024토큰 안), LongCat은 512토큰 제한이라 줄마다 뜻을 그대로 두고 겹친 말만 덜어 낸 짧은 판([굽기.py](굽기.py) `짧게`)과 따옴표를 뺀 옷장 지시문. seed 42 한 장씩.
- **설정:** 본판은 공식 데모 기본값(Qwen-2511 40스텝 · CFG 4, FireRed 30스텝 · CFG 4, LongCat 50스텝 · CFG 4.5), 빠른 판은 8스텝 증류 · CFG 1(Qwen · FireRed는 Lightning LoRA, LongCat은 Turbo).
- **같은 잣대:** [재기.py](재기.py)가 사진시험 `닮음.py`(YuNet + SFace)를 그대로 불러 GPT 판과 함께 다시 잰다. [시트.py](시트.py)는 GPT와 오픈 판을 줄마다 섞어 A~D로만 적은 눈가림 모아보기(열쇠는 git 밖)를 만들고, Fable이 결함 · 합성 티 · 보이는 나이를 본다.

```
python -I -X utf8 experiences/drama/qa/제2의나-20261102/오픈모델/굽기.py <qwen2511|firered11|longcat|longcat_turbo> [--만 base,age,wd] [--빠르게]
python -I -X utf8 experiences/drama/qa/제2의나-20261102/오픈모델/재기.py
python -I -X utf8 experiences/drama/qa/제2의나-20261102/오픈모델/시트.py
```

**Fable 눈가림 — 빠른 판 기준 · 나이(GPT 판과 섞어 A~D):**
- 기준: 20대 대역 둘은 Qwen 빠른 판이 1등(둘 다 「분명 · 결함 없음」, 본판과 같은 결과). 유호님은 GPT가 1등(「분명」), 오픈 셋은 모두 「아마」 — FireRed 빠른 판은 폰 든 손이 끼어듦(P1), Turbo는 닫은 입 웃음(P2), Qwen 빠른 판은 머리를 올려 다른 인상(P2). u2는 Turbo가 도서관 배경 · 피부를 그대로 둠(P1), FireRed 빠른 판은 또 폴로(P1).
- 나이: 오픈 빠른 판 아홉 가운데 여덟이 「나이 거의 그대로」(P1 — 33~57살로 보임, 차 머리받침 · 교실 장 · 콧수염 같은 원본 소품까지 남음). Qwen 빠른 판 45세만 24살로 내려 1등이었지만 Fable도 「아마」, 닮음은 0.289. GPT는 36 · 52세 1등(27 · 24살로 보임), 45세 3등(「아마(낮음)」 27살).
- 실험 줄(36 · 52세): Qwen 「강」은 성별은 지키지만 34 · 48살로 보여 P1(나이가 거의 안 바뀜). 「같은 성별」 줄을 넣은 강+ 판은 셋 다 남성(P0) — 본판 강+보다도 나쁘다. 같은 실험 줄에서도 1등은 GPT 「강」 판이었다.
- 정리: 오픈 모델은 「젊게」와 「같은 사람」을 한 번에 못 한다 — 세게 밀면(강+) 성별 · 사람이 바뀌고, 약하게 두면(강 · 빠른 판) 나이가 그대로다. 열아홉까지 내린 판은 GPT를 포함해 없었다(GPT도 24~27살에서 멈춤).

| 얼굴 「아마」(나머지는 「분명」) | 0 | 0 | 1 | 3 |
| 출고 검사 숫자 문턱(옷 · 목걸이 0.90, 머리 · 안경 · 모자 0.75, 설계 10절) | 11/12 | 9/12 | 10/12 | **12/12** |

- P0는 넷 다 없다. 옷장은 Turbo와 FireRed 빠른 판이 GPT와 같은 급이고, Qwen 빠른 판은 맞잡은 손 · 팔짱을 새로 그리는 버릇이 가장 큰 흠이다. 흔한 실패는 바꿀 것을 이웃한 것으로 바꾸기(쉼표머리 → 커튼 앞머리, 레이어드 단발 → 긴 생머리, 연청 → 중청, MA-1 → 민짜 재킷)와 염색 색 어긋남(밝은 갈색 → 구릿빛)이다.
- Turbo는 큰 편집(데님 재킷 · 조끼 · 염색)에서 얼굴이 「아마」로 흔들린 줄이 셋이라, 출고 검사의 눈 검사 몫은 그대로 둔다.

## 판단(Claude, 11-03)

- **기준 사진(올린 사진 → 19~20살 웃는 기준)은 API에 둔다.** 오픈 모델 셋 다 「젊게 + 같은 사람」을 함께 못 했고(나이 판 성별 바뀜 · 나이 그대로), 실제 사람(유호님)에서 GPT만 「분명」이었다. 20대 지어낸 얼굴은 Qwen-2511이 GPT와 같거나 나았지만, 실제 사람 한 명이 「다른 사람 · 아마」로 갈려 아직 나눠 쓸 근거가 못 된다.
- **옷장 편집(기준 → 머리 · 옷 · 액세서리)은 먼저 옮길 수 있는 첫 후보가 있다 — LongCat-Image-Edit-Turbo**(Apache 2.0, 반쪽 RTX Pro 6000에서 8스텝 8~9.5초 · 온쪽 대여값으로 셈해도 장당 약 0.6센트, Fable 1등 7/12 · 출고 검사 숫자 문턱 12/12). 옷장은 학생 한 명이 계속 사는 몫이라 장수의 대부분이 될 쪽이다. 다만 시범이 OpenAI 월 크레딧(무료) 안에서 도는 동안은 옮길 값 이득이 없으니, 크레딧을 넘는 규모가 되면 옷장부터 회사 GPU로 옮긴다(금액은 그때 유호님께).
- 옮기기 전에 할 것: 옷장 카탈로그 전체를 조각 20개 피팅 모델에 Turbo로 입혀 90% 통과 확인(설계 10절의 출시 전 피팅 그대로), 우리 입력 · 출력 거르기, 집 GPU · 회사 GPU에서 한 장 시간 재기. 새 상업 사용 오픈 편집 모델이 나오면 이 폴더의 같은 18장 + 동의한 실제 사람 서넛으로 다시 잰다(ZeroGPU 몫 안, 한 시간 남짓).
