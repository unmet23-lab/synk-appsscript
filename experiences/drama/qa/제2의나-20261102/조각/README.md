## 실존 인물 대조 절차 (`실존대조.mjs`)

설계 5절 「얼굴 조각은 지어낸 사람이다」를 돌릴 수 있게 만든 것이다. 조각마다 세 겹으로 보고 한 줄을 남긴다. 현금은 0이다(구글 렌즈 무료 · Gemini 웹 구독 · ChatGPT 구독).

1. **역검색** — 얼굴만 잘라(전신을 올리면 렌즈가 옷을 잡는다) ego 브라우저로 구글 렌즈에 올리고, 「전체」 탭의 시각 일치 카드 60~80장의 썸네일을 받아 조각 얼굴과 SFace로 견준다(`렌즈.mjs` · `실존대조_얼굴.py`). 렌즈는 웹 전체에서 가장 닮은 얼굴을 모아 오므로 스톡 · AI 그림 · SNS 일반인 사진이 0.50~0.60까지 나온다. 그래서 판정은 공인 출처 카드(배우 프로필 · 위키 · 영화 DB · 소속사 · 선수 기록 등)로만 한다.
   - 걸림: 공인 카드 하나가 0.55 이상(셀카 속 같은 사람의 가장 낮은 값 0.56 언저리), 또는 0.40 이상인 공인 카드가 같은 얼굴(서로 0.55 이상)로 둘 넘게 모임.
   - 살핌: 공인 카드 하나가 0.40 이상 — 나란히 놓고 눈으로 정해 적는다.
2. **판별 모델 둘** — 같은 얼굴을 Gemini 4 Argon(`tools/아르곤웹.js`)과 GPT(`tools/codex계정.js exec -i`)에 따로 묻는다. 「공인과 대조해 떠오르는 사람을 대라」는 GPT가 「실존 공인과 얼굴 대조는 도와드릴 수 없음」으로 거절했다. 그래서 누구인지는 역검색이 맡고, 모델에는 이름 · 비교 없이 「유명인 본뜨기로 오해받을 만큼 특정한 인상인가」(흔함 · 중간 · 높음 + 그렇게 본 생김새)만 묻는다. 첨부 이름은 번호만 써서 조각 id가 판정을 이끌지 않게 한다.
3. **판정** — 하나라도 걸림(렌즈 걸림 · 모델 하나라도 높음 · 두 모델 모두 중간)이면 **다시 굽기**다. 얼굴 특징 둘 이상(얼굴형 · 눈 · 눈썹 · 코 · 입 · 머리)을 바꿔 다시 굽고 처음부터 다시 돌린다. 렌즈 살핌이나 한 모델만 중간이면 **살핌**이라, 나란히 놓고 눈으로 정해 적는다.

실존 인물의 이름 · 사진은 git 밖(`.tmp/me2-20261102/piece-check/`)에만 두고, 이 저장소 기록에는 숫자 · 판정만 쓴다.

```
node experiences/drama/qa/제2의나-20261102/조각/실존대조.mjs 렌즈 <id=그림>…          # 자르기 + 렌즈 + 닮음
node experiences/drama/qa/제2의나-20261102/조각/실존대조.mjs 모델 <묶음> <id=그림>…    # 10장까지, GPT · Gemini
node experiences/drama/qa/제2의나-20261102/조각/실존대조.mjs 표 <id>… --md             # 조각마다 한 줄
```

## 지킬 것

조각은 지어낸 사람이고, 공개 전 이 대조를 통과해야 한다. 조각에는 학생 사진을 넣지 않는다 — 학생 사진은 사진 아바타 길에서만 다루고 그쪽 규칙(동의 · 한 장 · 기준 뒤 바로 삭제 · OpenAI 길만, 설계 원칙 4 · 10절)을 따른다. 그림은 구독 경로만 쓰고, 판은 손질하지 않으며, 못 쓰는 판은 지시문을 고쳐 다시 굽는다. 그림 속 읽히는 글자 · 상표 · 마스코트는 없어야 한다.
