# 「제2의 나」 사진 아바타 — 일괄 처리 검사 · 모의 (2026-11-03)

실제 서버 구현은 talk 함수 `me2-photo`다(11-04, 설계 13절) — 이 폴더는 만들기 전의 본보기로 남긴다. 설계는 [일괄 처리 설계](../../../../../docs/제2의나_사진아바타_일괄처리_설계_20261103.md)에 있다. 이 폴더는 그 설계의 출고 검사 숫자를 코드로 둔 본보기와, 실제 OpenAI를 부르지 않고 흐름을 끝까지 돌려 보는 모의다.

| 파일 | 하는 일 |
|---|---|
| `출고검사.py` | 받기(얼굴 하나 · 크기 · 흐림 · 밝기 — 막지 않고 손보거나 물어봄) · 기준(강 · 약 · 강+ ↔ 올린 사진, 기본 판 정하기) · 셀카(학생 ↔ 기준, 태오 ↔ 장면 판의 태오) · 룩(옷 · 머리 칸). 문턱 아래는 학생을 돌려보내지 않고 저절로 다시 굽는다(11-03 유호님 「사진을 고르는건 자유 … 엄격하면 스트레스」). 「누가 나예요?」로 고른 얼굴 상자(`--얼굴`)를 기준 검사에 넘기고, 셀카의 학생 자리는 태오 점수로 정한다(Fable 설계 검토 8). YuNet + SFace, 점수만 낸다 |
| `일괄모의.mjs` | 가짜 OpenAI(Files · Batches · 결과 받기 · 지우기)로 받기 → 기준 묶음(강 · 약 · 강+) → 검사 → 원본 · OpenAI 파일 지우기 → 룩 · 추억 사진 묶음을 돌린다. 부르기는 `tools/lib/오픈AI키.mjs` 용도 「사진」(받아 적기 몫을 남긴 만큼만), 묶음에는 `metadata` · `output_expires_after` 25시간을 달고 결과 · 오류 파일까지 지운다. 몫이 넉넉한 판과 빠듯한 판을 둘 다 돌린다 |

```
python -I -X utf8 experiences/drama/qa/제2의나-20261102/일괄처리/출고검사.py 기준 <올린 사진> <강> <약> [<강+>]
node experiences/drama/qa/제2의나-20261102/일괄처리/일괄모의.mjs      # → .tmp/me2-20261102/일괄모의/결과.json
node --test tests/오픈AI키_사진몫.test.mjs                             # 키 통로의 사진 몫 지키기
```

  - 룩 12칸 · 추억 사진 셋이 통과했다.

  - 룩 10 · 추억 사진 3은 「배송 지연」으로 남았다.
- 숫자는 설계 10절에 있다.
