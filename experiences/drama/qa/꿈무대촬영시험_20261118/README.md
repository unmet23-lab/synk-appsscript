# 꿈 무대 — 옥상 장면을 학생이 직접 찍는 시험판 (2026-11-18)

유호님 「더 많이 대사를 주고받고 해야 재밌지않을까?」, 「응, 견적 뽑아 줘」, 「480p로 구워」(11-18)로 시작했다. 기획과 대본 초안, 견적은 [꿈 무대 기획안](../../../../docs/꿈무대_기획안_20261117.md)의 「11-18 유호님 물음」 아래에 있다. 앞선 옥상 영상과 엔딩은 [꿈무대영상-20261117](../꿈무대영상-20261117/README.md)에 있다.

학생 영화 「안녕, 서울」의 옥상 장면에서 상대역(배역 이름 「친구」)이 일곱 번 묻고, 학생이 마이크로 답한다. 감독이 한마디 주문하면 학생이 다시 말하고, 「컷, 오케이!」 뒤에 학생의 목소리가 든 장면이 처음부터 흐른다.

## 이 폴더

- `컷표.json`과 `이미지지시문/`(git 무시, 원문은 `컷표_원문.md` · `컷표모음.py`로 다시 만듦): 새로 굽는 12컷(친구 대사 7, 끝 반응 1, 듣는 친구 2, 감독 2)의 콘티. 검사는 `python -I -X utf8 tools/컷연속성검사.py experiences/drama/qa/꿈무대촬영시험_20261118/컷표.json`이다.
- 그림과 영상은 git 밖 공용 작업본 `.tmp/꿈무대촬영시험_20261118/`에 둔다. 상대역 얼굴 후보는 `.tmp/꿈무대영상-20261117/상대역/`에 둔다.
- 상대역 얼굴 후보 지시문은 `../꿈무대영상-20261117/지시문/상대역/F1~F3`이다.

## 차례

1. 상대역 얼굴 후보 세 방향(앞머리, 무쌍, 주근깨)을 Seedream 5.5 무제한으로 굽고 유호님이 고르신다.
2. 컷마다 시작 그림을 Seedream 5.5 무제한으로 굽고 이미지 콘티 검수를 받는다.
3. 시댄스 2.5 빠른 판 480p로 굽는다(unmet23, 12컷 480크레딧, 다시 굽기까지 최대 약 690). 친구 목소리 참고는 11-17 넓은 컷 V1d에서 Demucs로 뗀 목소리(`.tmp/꿈무대영상-20261117/상대역/목소리/친구_목소리_V1d.mp3`, 1.6초)로 시작하고, 첫 컷이 나오면 그 목소리를 이어지는 컷의 참고로 쓴다.
4. 마이크로 말하고 다시 찍는 웹 시험판을 만든다.

## 대사 시험(T21)

원고를 화면 없이 글로만 맥락 없는 눈(Claude 하위 에이전트, Sonnet)에게 주고 줄마다 판정을 받았다. 처음 판에서 둘이 「생각」으로 나와 고쳤다.

| 처음 줄 | 판정 | 고친 줄 | 판정 |
|---|---|---|---|
| 아… 그거 진짜 어렵죠. | 생각(「그거」가 무엇인지 앞말을 못 들으면 모름) | 아, 맞아요. 서울 생활, 처음엔 다 어렵죠. | 바로 |
| 컷! 좋아요. 마지막 줄만 한 번 더. 조금 더 설레게. | 생각 | 컷! 좋아요. 마지막 대사만 한 번 더, 더 설레는 목소리로요. | 바로 |

「아, 맞아요. 처음엔 다 어렵죠.」도 무슨 일인지 모른다는 까닭으로 「생각」이었다. 학생이 무엇을 답하든 받을 수 있게 「서울 생활」을 넣었다.

## 웹 시험판

`시험판/원고.htm`이 화면 원고이고, `node experiences/drama/qa/꿈무대촬영시험_20261118/시험판/시험판짓기.cjs`가 브랜드 서체를 심어 git 밖 `.tmp/꿈무대촬영시험_20261118/시험판/index.html`로 쓴다. 새로 구운 컷이 없으면 11-17 옥상 컷을 자리 표시로 넣는다. 보기는 `node tools/지면서버.js 4911 .tmp/꿈무대촬영시험_20261118/시험판`(launch.json 「꿈무대촬영시험판」)이다.

차례는 친구의 질문 → 내 차례(듣는 컷을 되풀이로 틀고 마이크로 말함, 들어 보기 · 다시 말하기) → … → 일곱째 답 → 친구의 끝 반응 → 감독 「한 번 더」 → 다시 말하기 → 두 테이크 고르기 → 「컷, 오케이!」 → 내 목소리가 든 장면을 처음부터 튼다. 11-18에 자리 표시 영상과 가짜 마이크 소리로 처음부터 끝 장면 재생까지 넘어가는 것을 브라우저에서 확인했다. 실제 마이크와 사람 귀로는 아직 해 보지 않았다.

## 상대역 얼굴 후보(11-18 저녁, 진행 중)

지시문은 `../꿈무대영상-20261117/지시문/상대역/`(원문은 그 폴더의 `지시문_모음.md`)이고, 받은 그림은 `.tmp/꿈무대영상-20261117/상대역/`에 둔다. 모두 드리미나 웹 Seedream 5.5 무제한으로 구웠고, 크레딧 표시는 16.8K 그대로였다. 참고 그림은 넓은 컷 R1d(옷과 머리)와 남자 얼굴 컷 R2g(빛과 결) 두 장이다. 실존 인물 대조는 [새 여자 선배](../새여자선배-20261117/README.md)와 같은 절차(`../제2의나-20261102/조각/실존대조.mjs`)다.

| 방향 | 역검색(공인 최고 · 같은 공인 무리 → 판정) | 눈으로 본 것 | 쓰나 |
|---|---|---|---|
| F1 가 · 앞머리 | 0.515 · 2 → 걸림 | 앞머리 긴 생머리의 드라마 배우 사진들로 모였다 | 안 씀, 특징 둘을 바꿔 F4로 |
| F3 다 · 주근깨 | 0.443 · 2 → 걸림 | 같은 사진 한 장이 두 번 잡혀 묶였다. 규칙대로 다시 굽는다 | 안 씀, 특징 둘을 바꿔 F5로 |
| F2 나 · 무쌍 | 0.501 · 1 → 살핌 | 긴 생머리와 웃는 얼굴 유형만 같고 얼굴형과 눈매가 다르다 | 눈으로 통과 |
| F4 가2 · 옆가르마 | 0.509 · 1 → 살핌 | 위와 같다(0.51 카드는 단발의 다른 얼굴) | 눈으로 통과 |

**후보끼리 너무 닮았다.** SFace로 재니 F2 · F3 · F4가 서로 0.75~0.77이었다. 한 방향 안의 세 장끼리(0.67~0.78)와 같은 정도라 고를 거리가 되지 않는다. 남자 참고 그림이 섞인 것은 아니다(남자 얼굴과 0.26~0.33). 「흔한 20살 한국 여성, 따뜻한 인상」이라는 글이 Seedream의 한 얼굴로 모인 것으로 보인다. 그래서 얼굴형 · 눈 · 눈썹 · 코 · 입을 따로 적은 F6(긴 얼굴, 무쌍, 곧은 눈썹, 가는 입술)과 F7(하트형 얼굴, 큰 눈, 짧은 눈썹, 도톰한 입술)을 더 굽는다. F5(둥근 얼굴, 주근깨, 가는 아치 눈썹)도 굽는 중이다.

**드리미나 대기열.** 무제한 판은 「High demand」 대기열에서 한 판에 10~40분이 걸렸고, 같은 계정의 다른 세션이 굽는 순간에 낸 판은 거절됐다(크레딧은 나가지 않음). `~/ego/dream-stage-20261118/run3.sh <판>`이 거절되면 3분 뒤 다시 내고, 줄에 서면 그 판이 나올 때까지 기다려 받는다.
