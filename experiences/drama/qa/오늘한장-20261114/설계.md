# 「오늘」 한 장 — 설계 · 실행법 (2026-11-14, Opus · 깃발 뒤 최소 판 · 설계 세션 검수 반영)

> 맡긴 방향: Atlas 설계 세션(Fable) — 「앱이 본 것 → 그래서 고른 것 → 달라진 것」. [현황](현황.md) · [까닭 문장 표](까닭문장.md). **공개하지 않는다**(몽골 시범 11-19~11-30이 끝난 뒤 따로 정한다). 깃발이 없으면 드라마는 한 글자도 다르지 않다.

## 1. 흐름

둘째 학습일부터(학습일은 새벽 4시에 바뀐다) 드라마 틀을 `?today=1`로 열면 첫 화면 대신: 태오(듣는 고리 영상 — 손 인사) + 장면을 되부르는 한 줄 + 단추 하나 「오늘 시작 · N분」 + 세 줄과 까닭(누르면 근거 한 줄이 펼쳐질 뿐, 따로 여는 길은 없다 — 하루 권함은 단추 하나) → 누르면 고르는 화면 없이 차례로(다시 만날 말 → 새로 할 것 → 확인할 곳) → 끝 화면 「오늘 달라진 것」(전 → 후) · 「내일 돌아올 것」. 첫날(오늘 전 드라마 기록 없음)은 지금 첫 화면 그대로.
- 태오 한 줄은 틀마다 목소리 · 입 맞는 영상을 끼울 자리(`content.mjs` `TAEO_MEDIA` → `{ video }`)가 있다. 채우면 그 영상을 소리 내어 한 번 틀고(막히면 · 끝나면 듣는 고리로), 비어 있으면 지금처럼 듣는 고리 + 글.

- 다시 만날 말 · 새로 할 것: 드라마 새 상황 화면(`runTransfer('today')`) — 받아쓰기 · 판정 · 기록은 지금 드라마 그대로(차례마다 Atlas 보임 · 시도). 처음 보는 대사의 모범은 원고 글(녹음 없음). 짝 상황을 이미 해 봤으면 그 장면 줄을 테이크 2처럼(`runRetake`).
- 확인할 곳: C면 드라마 안에서, 입장 검사면 부모 창 통로 `SYNKTodayHost.open({ game: 'entry' })`로 같은 자리에 그 게임을 열고 「오늘로 돌아가기」로 돌아온다. **이 통로는 시연 대역에만 있다** — WORLD app-shell에 잇는 것은 공개 결정 때.
- 중간에 나가면: 버튼을 누른 때의 「오늘」과 마친 차례가 이 탭(sessionStorage `synk.drama.today.run`)에 남아, 다시 열면 남은 차례가 「이어서 · N분」으로 뜬다.

## 2. 파일

| 파일 | 하는 일 |
|---|---|
| `pilot/today/plan.mjs` | 순수 함수 — 사건 목록 → `today` · `after` 계약. 화면은 이 꼴만 읽는다(뒤에 새 엔진 「오늘 할 것」으로 갈아 끼우는 자리) |
| `pilot/today/content.mjs` | 처음 보는 대사 표(원고와 같은지 시험이 본다) · 다시 만날 말 짝 · 새로 할 것 차례 · '요' 줄 · 태오가 되부르는 말 · 목소리 · 영상 자리 · 결과 글 |
| `pilot/today/gather.mjs` | 기록을 모으는 한 겹 — 드라마 사건(계정 학습 호스트) · C 차례(기록기) · 입장 검사 재방문 맞춤(그 게임 엔진 · 문장 그대로, 근무지 이름은 WORLD 판) |
| `pilot/today/screen.mjs` · `today.css` | 화면 · 차례 잇기(A안 · B안 겉 — `&look=b`) |
| `pilot/pilot.mjs` | 깃발 `TODAY` · `startToday` · 새 상황 흐름의 `today` 갈래(모두 `S.today`가 있을 때만) |
| `qa/오늘한장-20261114/` | 심기(실제 기록기로 지난날 기록) · 뽑기(Node에서 today · after) · 오늘시험(WORLD 대역 판) · 흐름시험(가짜 마이크 크롬) · 시안짓기 |
| `tests/drama-today.test.mjs` | 계약 · 사실에서만 짓기 · 끝 화면 · 원고 대조 · 답 낱말 없음 · 깃발 없으면 그대로 |

공개 빌드(`tools/build-world-app-public.mjs`)는 드라마에서 정해진 파일만 싣고 `today/`는 싣지 않는다. 깃발을 공개본에 붙여 열어도 `today/`가 없어 지금 첫 화면으로 간다.

## 3. 실행

```
node experiences/drama/qa/오늘한장-20261114/오늘시험.mjs            # http://127.0.0.1:8798/?s=A (기록 A) · ?s=B · ?s=F(첫날) · &look=b · &miss=1
node experiences/drama/qa/오늘한장-20261114/흐름시험.cjs            # 끝까지 따라가며 찍기(.tmp/today-20261114/흐름)
node --test tests/drama-today.test.mjs
```

- 대역은 틀시험(`../WORLD올리기-20261102/틀시험.mjs`)과 같은 부모: 합성 계정 학습 호스트(이 창 localStorage, 서버로 안 보냄) · 드라마 통로(talk와 같은 판정기, 받아 적은 글만 정해 둠) · 놀이 호스트 대역(입장 검사 진도) · 「오늘」 통로. 열 때마다 기록을 비우고 시나리오를 다시 심는다(`&keep=1`이면 이어서).
- 받아 적은 글은 줄마다 정해 둔 말이고 판정은 talk 판정기 그대로다. 녹음은 실제로 4초쯤 말해야 빠르기 검사에 걸리지 않는다.

## 4. 한계(솔직히)

- 받아 적은 글 · 빠진 낱말은 기록에 없어 「내가 한 말」은 다음 날 못 보인다.
- 새 처음 보는 대사가 여섯 줄뿐이다(2화 없음). 바닥나면 「새로 할 것」 줄이 사라진다.
- 처음 보는 대사 t1 · t2 · t3 · t4 · t7 · t8의 상황 글 · 영어 설명 · 결과 글은 이번 초안(검수 전, 한국어 화면만). WORLD talk가 강의 밖 줄의 테이크를 받는지는 확인 안 함.
- 태오 한 줄은 목소리 없이 글로만(힉스필드 잔액 0 — 같은 Julian 목소리 길 막힘). 끼울 자리는 있다.
- 강의 밖 줄을 실제 talk 서버가 받는지(`ITEM_NOT_OPEN`) 확인 전이라, 이번 판은 시연용 판(대역)에서만 연다.
- 입장 검사 통로는 대역에만. 「장면 끝까지」 줄은 지금 장면 흐름으로 넘기고 끝 화면으로 돌아오지 않는다.
