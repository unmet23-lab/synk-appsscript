# 드라마 「오늘」 화면 다시 짓기 — 둘째 묶음 시안 설계 (2026-11-18 밤)

유호님 말씀: 「지금 이 프론트로 내보내면 정말 최악이야. 하나도 눈에 안들어오고 모션그래픽도없고 이걸 왜 봐야하는지 모르겠어. 재미도없고 감동도없고 그냥 너무 다 불편해. 가시성도 안좋아. 강조할부분이랑 프론트로 눈길을 사로잡을대랑 이런걸 체계적으로 구성해줘야지 … 빨랫줄로 카드형식으로하는것도 나쁘지않은데 이 기능 (본질적인)에 더 어울리는 프론트 디자인이 있는지 디자인사이트 참고해서 다시 만들어」

## 본질 한 문장

드라마가 어제의 나를 기억하고, 오늘 내가 다시 들어갈 장면을 골라 준다. 사람(태오)이 먼저 나를 부른다.

## 강조 순위(세 시안 공통)

1. **첫 1초: 태오가 나를 보고 말한다** — 움직이는 얼굴과 목소리, 자막. 이 화면을 왜 보는지가 여기서 풀린다(「어제 그 장면, 오늘 한 번 더 해요」).
2. **다음: 오늘 고칠 한마디** — 「한참 헤맸어요」의 「요」 한 글자. 크게, 노랑 표시로.
3. **그다음: 시작 단추(5분)** — 화면에서 가장 밝은 단추 하나.
4. 물러서는 것: 장면 셋의 목록(어디 · 누구 · 할 일), 날짜.

## 순간마다 볼거리와 소리

- A: 위아래 검은 띠가 열림(whoosh) → 태오 영상이 화면 가득 천천히 다가옴, 이름표 아래 대사가 낱말마다 올라옴 → 「요」에서 노랑 번쩍(underline) → 어제 한 말 「한참 헤맸어」가 글자마다 떨어지고 끝의 「요」가 도장처럼 찍힘(tick · stamp) → 장면 세 장이 필름처럼 아래에서 밀려 올라옴(slide · flip) → 「장면 1부터 말해 보기」 단추가 숨 쉬듯 빛남. 다른 장면을 고르면 제목과 단추가 그 장면으로 바뀜.
- B: 테이프 세 개가 하나씩 떨어져 쌓임(clipsnap) → 1번 테이프가 빠져나와(slide) 화면(TV)에 꽂힘(press) → 지지직 뒤 태오 재생, 이름표 「「한참 헤맸어요」 끝까지 다시 말하기」의 「요」에 노랑 형광 줄(underline) → 다른 테이프를 누르면 그 장면이 미리 보이고 단추가 「3번 테이프부터 말해 보기」로 바뀜.
- C: 「태오 선배」 줄이 내려옴(notify) → 동그란 영상 메시지가 화면 가운데에서 톡 하고 커짐(pop), 둘레의 고리가 말하는 동안 차오름 → 다 말하면 동그라미가 머리의 얼굴 자리로 날아감(whoosh · clipsnap) → 입력 중 점 → 어제 내가 한 말 「한참 헤맸어요」를 인용한 말풍선(흐린 「요」) → 「이번엔 「요」까지 또렷하게 해 봐요」와 함께 흐린 「요」가 또렷해지며 노랑 줄(stamp) → 장면 사진 세 장이 부채처럼 펼쳐져 도착(whoosh · flip) → 답장 단추 「좋아요, 시작할게요 · 5분」. 넓은 화면에서는 태오가 가운데에서 말하고, 다 말하면 왼쪽으로 비키며 듣는 얼굴로 남고 대화가 오른쪽에 들어옴.

## 지키는 것

- 촬영장 말(테이크 · 통과 · 노트)을 화면에 쓰지 않는다. 새 상황 줄의 답 낱말(편의점 · 어디에 있는지 …)을 보이지 않는다.
- 자료는 기록 A(어제 6번 줄 끝맺음 · 오늘 공부는 같은 과 선배에게 길 묻기 · 입장 검사 중앙도서관)를 쓴다.

## 맹검으로 고친 것(GPT 눈 세 번 · 마지막 확인 한 번)

- 세 시안 모두 단추의 재생 삼각형을 마이크로 바꾸고 「말해 보기」를 붙였다. 재생 삼각형은 「본다」로 읽혔다.
- A: 제목 「끝에 「요」까지」는 어느 말의 끝인지 몰랐다 → 어제 한 말 「한참 헤맸어요」를 그대로 제목으로 세웠다. 가운데 흰 자막은 숏폼 기본 자막 같았다 → 이름표를 단 왼쪽 정렬 대사로 바꿨다. 노란 칸 테두리와 금빛 단추 테두리가 노랑을 나눠 가졌다 → 노랑은 「요」에만 쓴다. 넓은 화면의 흐린 영상 바탕은 자동 채우기 같았다 → 어두운 무대 빛으로 바꿨다.
- B: 「요」에 노란 자막과 붉은 동그라미가 겹쳤다 → 노랑 형광 줄 하나로. 뒤 테이프의 이름표가 가려졌다 → 아래 테이프가 앞에 오게 쌓았다. 「1번 테이프」가 화면 어디에도 없었다 → 재생 화면과 이름표에 번호를 적고, 단추가 지금 테이프 번호를 따른다.
- C: 머리의 작은 얼굴과 큰 동그란 영상이 같은 얼굴을 두 번 보였다 → 머리는 이름 첫 글자로 시작하고 영상이 끝나면 동그라미가 그 자리로 날아간다. 말풍선이 기본 메신저 같았다 → 어제 내가 한 말을 인용한 말풍선을 넣었다. 사진 위 흰 글씨가 묻혔다 → 글을 사진 아래 흰 띠로. 보는 동안 아래 절반이 비었다 → 영상을 가운데에 두고 아래에 「다 보면 오늘 할 장면 셋이 와요 · 5분 / 건너뛰기」. 넓은 화면은 휴대폰 판을 큰 창에 띄운 꼴이었다 → 태오와 대화를 두 칸으로.
- 공통: 게임 장면의 할 일을 「손님 표와 짐 맞춰 보기」로, 「입장 검사 게임」을 「도서관 직원 되기 게임」으로 풀어 썼다. 장면 칸의 시간은 사진 위 작은 표로 옮겼다.

## 남은 것

- 태오 영상은 앱의 작은 동그라미에 맞춰 480p로 구웠다. A와 B, C의 넓은 화면처럼 크게 보이면 얼굴 결이 뭉개진다(맹검 K48). 이 판을 고르면 남은 열한 줄을 720p로 구워야 하고 크레딧이 더 든다.
