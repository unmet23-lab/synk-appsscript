# 우리 동네의 드라마 입구 시안 셋 (2026-11-19)

유호님의 「드라마 말하기를 어디서 여는거야? … 없으면 니가 만들어볼래 ?」와 「시안부터 만들어」로 지은 시안이다. 둘째 날부터 태오 선배의 영상 메시지가 우리 동네에 도착하고, 누르면 「오늘」 메신저 화면이 열린다. 본질 한 문장, 강조 순위, 참고 작품, 순간마다의 소리는 [설계.md](설계.md)에 있다. 라이브 앱은 바꾸지 않았다.

- [e1.html](e1.html) 위에서 내려오는 알림: 검은 알약이 태오 얼굴이 든 카드로 부풀었다가, 위 막대 가운데의 작은 얼굴 동그라미와 빨간 1로 접힌다.
- [e2.html](e2.html) 버스 정류장에 온 태오 선배: 정류장 위에 태오 얼굴 이름표와 흰 말풍선이 뜨고, 몽글 카드의 흰 단추가 그 메시지를 연다.
- [e3.html](e3.html) 몽글 카드 위 메시지: 메시지 카드가 몽글 카드를 덮고 올라와, 입력 중 점 뒤에 한 줄이 도착한다.

셋 다 누르면 밝은 메신저 바탕이 누른 얼굴에서 동그랗게 열리고, 얼굴이 [today.html](today.html)(움직임 시안 C에 앱 문구를 맞춘 사본)의 영상 메시지 자리로 커진다. 동네 바탕(그림 · 이름표 · 위 막대 · 몽글 카드 · 탭)은 [동네.js](동네.js)와 [동네.css](동네.css)에 지금 앱의 값으로 옮겼다.
