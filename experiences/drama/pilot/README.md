# 1화 드라마 말하기 시범판

기존 「개강 첫날」의 식당 대사 일부와 승인된 태오 실사·Julian/Hana 음성을 사용한 **이PC 체험용 시범판**이다. 새 인물·목소리·영상을 생성하지 않았다. 기존 제품의 계정·결제·운영 데이터는 바꾸지 않는다.

## 실행

저장소 루트에서 Node 24와 ffmpeg/ffprobe를 사용한다.

```powershell
node tools/build-drama-pilot-assets.mjs
node tools/drama-pilot.mjs
```

[시범판 열기](http://127.0.0.1:8794/) → 「장면 시작」 → 받아쓰기 사용 여부 선택 → 마이크 허용. 다른 포트는 `node tools/drama-pilot.mjs --port 8795`. 서버 종료는 실행한 터미널에서 Ctrl+C다. 이 주소는 실행 중인 같은 PC에서만 열린다.

재생용 미디어는 승인 원천에서 로컬로 만든다. 기본 원천은 사용자 Documents의 `synk-vendor/drama-showcase-20261031` 폴더다(11-03부터 — 태오 = 덧니 선배, 정지 사진은 `taeo-still.png` = C4 끝 그림, 쇼케이스 C1~C4는 원래 녹음을 얹은 판). 다른 위치는 빌드에 `--쇼케이스원천 <폴더>`를 준다. 원천을 덮지 않으며, 재생 사본 `media/`는 Git 이력에 중복 추가하지 않는다. 1화 원래 소리와 SUIT 글꼴도 재사용한다.

## 체험 범위

1. 선배와의 장면에서 길을 잃은 이야기·도서관 위치 묻기·감사 인사, 세 줄을 말한다. 상대가 듣는 동안에는 학생 모범 소리가 나오지 않는다.
2. 장면이 끝나면 노트 하나를 고르고, 해당 줄과 직전 선배 대사만 다시 시도한다. 확실한 교정 후보가 없으면 「다른 말로 한번 더」라는 연습으로 안내한다.
3. 새 상황: 오늘 처음 인사한 같은 과의 다른 선배에게 편의점 위치를 묻는다(검수 통과 처음 보는 대사 `s1e01-t9`, 11-03 — 11-02에는 복사실 `s1e01-t4`, 그 전에는 검수 전 편의점 예시). 상황 카드(영어 · 한국어)에는 한국어 모범 · 첫 글자 · 핵심 말이 없다. 모범을 본 사실과 첫 시도 이후 재시도를 구분한다.
4. 테이크를 들어보고 오늘 기록을 확인한다. 점수·등급·공식 시험 결과·장기 숙련 판정은 없다.

## 장면 화면 — 시네마 자막 (11-02)

겉은 [장면 화면 정본](../../../docs/디자인/드라마_장면/README.md)(결정 11-02 「드라마 말하기 · 장면 화면 = 시네마 자막」)대로다. 흐름(장면 안에서는 되묻기만 · 노트는 장면 뒤 · 「다른 말로 한번 더」 · 새 상황)은 그대로 두고 겉만 바꿨다.

- 장면 사진 · 영상이 화면 위쪽에 밝게 놓이고, 선배 · 코치 대사는 그 아래 어두운 자리의 자막(낱말마다 떠오름, 되묻기는 톡 튀어 들어옴)이다. 선배 대사는 소리가 쉬는 자리에서 다음 화면으로 넘어간다([자막 규칙](../../../docs/디자인/드라마_장면/README.md#자막-규칙-2026-11-05-확정), `content.mjs` `SUB_CUES`). 아래는 유리 대사 카드, 그 아래 음성 구. 넓은 화면에서는 가운데 세로 화면 하나로 선다.
- 녹음은 음성 구를 눌러 시작하고 다시 눌러 끝낸다. 구는 [Orbloom](https://github.com/rickybharti/orbloom) 0.1.0(MIT)을 esbuild로 한 파일로 묶은 `orbloom.mjs`(고치지 않은 사본, 머리에 MIT 고지)다 — 시범판 CSP가 바깥 스크립트를 막아 서버가 이 파일을 낸다. 구의 소리 세기는 녹음 스트림에서 이 창 안에서만 잰다(마이크를 따로 열지 않는다).
- 크롬 칩 · 불꽃은 해낸 순간에만 — 장면에서 되물은 뒤 스스로 고쳐 통과한 줄, 테이크 2 통과, 새 상황 통과. 첫 시도 통과는 빈칸에 낱말이 넘겨 들어가기만 한다.
- 글꼴: 한글 SUIT, 영문 Inter Tight, 고정폭 영문 라벨(`YOUR TURN` · `EP.01 · SCENE 2` · 구 상태)만 DM Mono — 빌드가 영문만 남긴 woff2로 만든다(python fontTools 필요 — 없으면 빌드가 그 글꼴을 건너뛰고, 화면은 Inter Tight 대신 SUIT · DM Mono 대신 브라우저 기본 고정폭으로 보인다. 그때 브라우저 콘솔에 글꼴 404가 남는다). 한글은 고정폭에 넣지 않는다.
- 움직임 줄이기 설정이면 움직임을 모두 멈춘다.
- 정본 겹 4의 「받아 적은 내 말」 말풍선(타자 · 틀린 낱말 물결선)은 장면 안에 두지 않았다 — 물결선은 판정 표시라 「장면 안에서는 판정을 말로 보여 주지 않는다」(되묻기만) 원칙과 맞지 않는다. 받아 적은 글은 장면 뒤(테이크 2 결과 · 새 상황 결과)에서만 보인다. 물결선 없는 타자 말풍선을 장면 안에 둘지는 실제 학습자 시범 뒤 정한다.

## 바깥 틀 — 이야기 속 유학생과 이야기 밖 코치 (11-02)

결정 10-31 「싱크타운 다시 짜기」 ③대로 학생은 이야기 속 유학생 주인공이고, 고칠 점은 이야기 밖 코치가 장면이 끝난 뒤 준다. 화면 말·목소리에 감독·촬영·컷을 쓰지 않고 「테이크 2」만 화면 말로 남겼다. 인물 표시는 「지어낸 인물」, 첫 화면 알림은 「인물은 지어냈고, 목소리는 모두 합성했어요.」다(도구 이름·「AI로 만든」 표기 없음).

- **코치 목소리:** 감독으로 골랐던 Harrison(일레븐 v4)으로 세 줄을 11-03에 한 번에 굽고 줄 사이에서 잘랐다 — 끝맺음 노트 「끝에 '요'를 붙여 봐요. 이 장면을 다시 해 볼까요?」 · 다른 노트 「이 장면을 다시 해 볼까요?」 · 마침 「오늘은 여기까지! 수고했어요.」(`content.mjs` `COACH_VOICE`, `s1/소리/ep01-coach-01~03.mp3` · `ep01-coach.json`). 감독 녹음 넷(`ep01-director-*`)은 컷·촬영·「지난번엔」을 말해 쓰지 않는다.
- **노트 글:** 끝맺음 노트는 쇼케이스에서 검수한 첫 안 「처음 만난 선배에게는 끝에 '요'를 붙여 봐요.」 + 받아 적은 끝말로 「헤맸어 → 헤맸어요」다. 「요」만 붙여 맞는 꼴이 아니면(「어디야」 등) 고칠 꼴 대신 「이 장면을 다시 해 볼까요?」를 보인다(`strings.mjs` `endingFix`).
- **쇼케이스 영상(11-03):** 영상판은 이 시범판 화면을 녹화해 만든다([콘티](../qa/쇼케이스-20261031/콘티.md)). 덧니 선배로 식당에서 구운 한 테이크 C1 · C3 · C2 · C4(시댄스 2.5 · 720p, [지시문](../qa/쇼케이스-20261031/지시문.mjs) · [웹 꾸러미](../qa/쇼케이스-20261031/웹꾸러미.mjs))에 원래 녹음(Hana · Julian)을 문장 시작에 맞춰 얹은 판이 `synk-vendor/drama-showcase-20261031/C1.mp4`…에 있고, 그 판에서 잰 구간이 `content.mjs` `SHOWCASE_CUTS`다. C1 → 선배 1, C3 → 6번 줄 첫 시도의 듣는 고리 + 첫 되묻기, C2 → 되물은 뒤 6번 줄 듣는 고리 + 선배 2(테이크 2는 `retakeFrom` 2.0초 — 웃음 뒤 「여기」부터), C4 → 7번 줄 듣는 고리 + 선배 3. C4 영상에는 선배 대사 가운데 「도서관?」 한 마디가 없어 얹은 원래 녹음에서도 뺐다(자막 글은 대본 그대로). 옛 얼굴 원테이크 대답(`taeo-reply.mp4`)은 빌드가 지운다.
- **오늘 기록(11-03):** 쇼케이스 콘티 「오늘의 끝」대로 맨 위에 다음 회 예고(칸 15 그림 `next-fair.webp` — 빌드 원천 `칸15_박람회.webp`, 태오 없음), 그 아래 태오 메모 · 오늘 배운 표현, 체크 목록, 접힌 내 녹음 순서다. 첫 시도 통과는 1.2초, 되물은 뒤 스스로 고친 통과는 2.0초 머문다(「요」 강조를 볼 시간).
- 코치 녹음 · 쇼케이스 영상을 넣고 빌드한 뒤에는 **시범판 서버를 다시 띄운다** — `content.mjs`가 서버 시작 때 한 번만 사본이 있는지 본다.

입 모양이 맞는 영상은 선배 1 · 2 · 3과 첫 되묻기에 쓴다. 나머지 선배 대사(선배 4 · 두세 번째 되묻기)는 같은 인물 정지 사진(C4 끝 그림)과 그 대사의 원래 녹음으로 재생한다. 1화 전체 장면을 새 립싱크 영상으로 제작한 결과가 아니다. 새 상황은 11-03부터 ep01 처음 보는 대사 `s1e01-t9`(AI 2중 검수 통과)를 그대로 쓴다 — 11-02에는 `s1e01-t4`(복사실), 그 전에는 검수 전 연습 예시였다. 몽골어 자막·7일 뒤 C 과제·학생 학습효과 측정은 이번 범위에 포함하지 않았다.

## 학습 기록 (11-02)

테이크마다 학습 기록(Atlas Trail, 응답 꼴 `spoken`)을 남기는 길을 이었다 — 차례 하나 = 보임 하나, 테이크 하나 = 시도 하나, 「혼자 해 봄」은 서버가 테이크 응답의 `trail`로 정한다. WORLD 게임과 같은 계정 학습 호스트(`SYNKLearningHost`)가 있을 때만 남고 학습 기록 동의가 켜진 계정만 서버로 보낸다. 이 PC 시범은 로그인이 없어 **기본 실행에서는 아무것도 남기지 않는다.** 받아 적은 글 · 소리는 사건에 들지 않는다. 묶음은 `learning-entry.cjs`를 고친 뒤 `node tools/build-drama-learning.js`로 다시 만든다(`atlas-learning.js`, 생성물). 합성 계정 왕복 실측과 리허설 실행법은 [학습 기록 리허설](../qa/학습기록-20261102/README.md).

**11-03 더함(몽골 시범 §7 ① · ④):** 테이크마다 규칙 판정의 갈래를 시도의 `choice` 칸에(pass · note-ending · note-length · note-missing · hold · unclear), 장면 뒤 코치 노트를 그 줄 보임의 도움 `explanation`으로 남긴다. 장면 · 테이크 2는 그대로 판정 없음이다. 새 상황(B)은 받아 적기까지 간 첫 테이크가 올 때만 기록에 남고(`lazy: 'transcribed'`), 받아쓰기를 못 쓰는 동안에는 B를 열지 않고 「나중에 다시」로 남겨 첫 화면 카드로 다시 내민다. 자세한 꼴과 시험은 [학습 기록 리허설](../qa/학습기록-20261102/README.md#11-03).

## WORLD 안 (11-02)

같은 화면이 `synk.im/world/?drama=1`(WORLD 게임 틀, SYNK ID 로그인 뒤)에서도 돈다 — 설계 · 검토는 [WORLD 올리기](../qa/WORLD올리기-20261102/설계.md).

- 강의는 정적 `world-lesson.json`(생성물 — `node tools/build-drama-world.mjs`, 대사별 녹음 상한 · talk 대사 은행 지문을 함께 싣고 판정 명세는 싣지 않는다).
- 받아쓰기 · 판정은 부모 창의 드라마 통로(`SYNKDramaHost`, app-shell이 드라마 틀을 연 동안만 둔다)로 계정의 talk `world-speaking` `take`를 부른다(하루 30번 · 드라마 스위치). 이 창은 계정 토큰을 모른다. 「혼자 해 봄」은 `takes.mjs` 규칙으로 이 창이 정하고, 다른 날 본 문항은 Atlas가 계정 이력으로 거른다.
- 학습 기록은 WORLD 계정 학습 호스트가 받는다(동의 켠 계정만 서버로). 처리방침 링크는 동의 창에 있다.
- 공개는 `tools/build-world-app-public.mjs`가 `drama/`에 싣는다(재생 사본은 manifest와 대조, `content.mjs`는 안 실음). 공개본을 틀 밖에서 바로 열면 「WORLD에서 열기」만 보인다.
- 리허설: `node experiences/drama/qa/WORLD올리기-20261102/틀시험.mjs [--후보 <공개 후보 …/world>]` — 부모 대역(합성 계정 호스트 + talk와 같은 판정기로 답하는 통로), `?world=1`은 WORLD 계정 묶음을 부모로, `?world=live`는 공개본 WORLD 위에 후보를 얹은 판.

## 음성과 비용

받아쓰기 사용에 동의했을 때만 녹음을 기존 OpenAI API 키 통로의 `gpt-transcribe`로 보낸다. 이 시범 서버는 음성 원본·받아쓴 글을 파일로 보관하지 않는다. 녹음 재생은 브라우저 메모리에서 하며 「녹음 비우기」·다시 시작·창 닫기로 비운다. 브라우저에는 키를 주지 않는다. 외부 분석을 끄면 녹음·듣기·스스로 확인으로 진행한다.

한 녹음은 20초·2.5MB 이하, 외부 분석은 한 번에 하나, 서버 실행당 예상 $0.05/30회 이내다. 서버에서 실제 해독한 음성 길이로 제한한다. 호출 수·길이·예상 사용료만 `.tmp/drama-pilot-runtime/`에 기록한다. 분당 $0.0045를 곱한 예상 사용료이며 청구서 대조 금액이 아니다. 오류·취소 뒤 과금 여부가 불명확한 요청도 예산에서 되돌리지 않는다. 재시작으로 초기화되는 시범 보호장치이며 상품의 월 한도는 아니다.

제작 시간·개발/검수 크레딧·재사용 자산·실제 API 왕복 근거는 [제작 기록](../qa/시범판-20261031/제작기록.md)에 정리한다. 브라우저 녹음·실제 받아쓰기 시험은 승인 모범 음성의 합성 스트림으로 진행했으며, 실제 학생·실제 장치 마이크의 학습 성과 시험과 구분한다.
