# 1화 드라마 말하기 시범판

기존 「개강 첫날」의 식당 대사 일부와 승인된 태오 실사·Julian/Hana/Harrison 음성을 사용한 **이PC 체험용 시범판**이다. 새 인물·목소리·영상을 생성하지 않았다. 기존 제품의 계정·결제·운영 데이터는 바꾸지 않는다.

## 실행

저장소 루트에서 Node 24와 ffmpeg/ffprobe를 사용한다.

```powershell
node tools/build-drama-pilot-assets.mjs
node tools/drama-pilot.mjs
```

[시범판 열기](http://127.0.0.1:8794/) → 「촬영 시작」 → 받아쓰기 사용 여부 선택 → 마이크 허용. 다른 포트는 `node tools/drama-pilot.mjs --port 8795`. 서버 종료는 실행한 터미널에서 Ctrl+C다. 이 주소는 실행 중인 같은 PC에서만 열린다.

재생용 미디어는 승인 원천에서 로컬로 만든다. 기본 원천은 사용자 Documents의 `synk-vendor/drama-taeo-onetake-20261031` 폴더다. 다른 위치는 빌드에 `--원천 <폴더>`를 준다. 원천을 덮지 않으며, 재생 사본 `media/`는 Git 이력에 중복 추가하지 않는다. 1화 원래 소리와 SUIT 글꼴도 재사용한다.

## 체험 범위

1. 선배와의 장면에서 길을 잃은 이야기·도서관 위치 묻기·감사 인사, 세 줄을 말한다. 상대가 듣는 동안에는 학생 모범 소리가 나오지 않는다.
2. 장면이 끝나면 노트 하나를 고르고, 해당 줄과 직전 선배 대사만 다시 시도한다. 확실한 교정 후보가 없으면 「다른 말로 한번 더」라는 연습으로 안내한다.
3. 다른 선배에게 편의점 위치를 묻는다. 최초 상황 카드에는 한국어 모범·첫 글자가 없다. 모범을 본 사실과 첫 시도 이후 재시도를 구분한다.
4. 테이크를 들어보고 촬영 기록을 확인한다. 점수·등급·공식 시험 결과·장기 숙련 판정은 없다.

입 모양이 맞는 승인 영상은 해당 대답 구간에만 사용한다. 나머지 선배 대사는 같은 실사 정지 사진과 그 대사의 원래 녹음으로 재생한다. 1화 전체 장면을 새 립싱크 영상으로 제작한 결과가 아니다. 새 상황은 검수 전 연습 예시이며 몽골어 자막·7일 뒤 C 과제·학생 학습효과 측정은 이번 범위에 포함하지 않았다.

## 음성과 비용

받아쓰기 사용에 동의했을 때만 녹음을 기존 OpenAI API 키 통로의 `gpt-transcribe`로 보낸다. 이 시범 서버는 음성 원본·받아쓴 글을 파일로 보관하지 않는다. 녹음 재생은 브라우저 메모리에서 하며 「녹음 비우기」·다시 시작·창 닫기로 비운다. 브라우저에는 키를 주지 않는다. 외부 분석을 끄면 녹음·듣기·스스로 확인으로 진행한다.

한 녹음은 20초·2.5MB 이하, 외부 분석은 한 번에 하나, 서버 실행당 예상 $0.05/30회 이내다. 서버에서 실제 해독한 음성 길이로 제한한다. 호출 수·길이·예상 사용료만 `.tmp/drama-pilot-runtime/`에 기록한다. 분당 $0.0045를 곱한 예상 사용료이며 청구서 대조 금액이 아니다. 오류·취소 뒤 과금 여부가 불명확한 요청도 예산에서 되돌리지 않는다. 재시작으로 초기화되는 시범 보호장치이며 상품의 월 한도는 아니다.

제작 시간·개발/검수 크레딧·재사용 자산·실제 API 왕복 근거는 [제작 기록](../qa/시범판-20261031/제작기록.md)에 정리한다. 브라우저 녹음·실제 받아쓰기 시험은 승인 모범 음성의 합성 스트림으로 진행했으며, 실제 학생·실제 장치 마이크의 학습 성과 시험과 구분한다.

## 확인

```powershell
node tools/build-drama-pilot-assets.mjs --확인
node --test tests/drama-pilot.test.mjs tests/드라마판정.test.mjs tests/드라마대본.test.mjs
```

화면은 Claude, 서버·검증은 GPT가 맡았다. 사전 Fable 설계 검토, 백엔드 GPT+Claude 교차 검수, 화면 아르곤·Fable 검수의 실제 결과는 제작 기록을 따른다.
