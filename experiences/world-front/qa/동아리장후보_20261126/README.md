# 한국어 동아리장 후보 — 얼굴, 목소리, 이름 (2026-11-26)

서울행 내 길에서 학생에게 먼저 말을 거는 한국어 동아리장이다([동아리 알림 설계](../동아리알림시안_20261123/README.md) 7절 3번). 지금 쓰는 「민우」 얼굴과 이름은 임시다. 유호님 「네, 후보 만들기」(11-26)로 시작했다. [새 여자 선배](../../../drama/qa/새여자선배-20261117/README.md) 때와 같은 절차(얼굴 기준 사진, 실존 인물 대조, 목소리 오디션, 이름 검색)를 거쳐 유호님이 고르신다. 이 폴더에는 지시문과 절차만 두고, 그림과 소리는 git 밖(공용 작업본 `.tmp/senior-f-face/out/chd-*` · `.tmp/club-head-voice/` · `.tmp/club-head-pick/`)에 둔다.

인물은 4학년이고 새로 온 유학생 이름을 첫날 다 외우는 수다스럽고 따뜻한 선배다. 학생에게 반말로 말한다(몽골어는 동아리장만 чи).

## 얼굴

`후보.mjs`가 지시문을 만들어 `.tmp/senior-f-face/jobs.json`에 `chd-*` 작업으로 넣는다. 참고 그림 없이 글로만 Gemini 웹 「카본」 + 사고 수준 「높음」으로 굽는다(구독 안, 현금 0). 굽기는 `bash .tmp/senior-f-face/돌림_동아리장.sh "<id…>"`(Gemini 번호표 줄 a · b · e).

- 지금 얼굴(`club-head`)은 11-24 실존 대조를 통과했다. 그 셀카 틀(동아리방 문간, 손 인사, 초록 맨투맨과 목걸이 명찰, 밝은 앞빛과 금빛 역광)은 그대로 두고 얼굴 글만 세 방향으로 바꿨다. 옷 · 방 · 빛이 같아야 얼굴만 견줄 수 있다.
- 세 방향은 「가 · 펌 머리」(반곱슬 펌, 초승달 눈웃음, 다정한 형), 「나 · 짧은 머리」(이마를 드러낸 투블럭, 굵은 눈썹, 활발한 형), 「다 · 둥근 얼굴」(짧게 민 머리, 동그란 볼, 푸근한 큰형)이다. 방향마다 두 판을 구웠다.
- 겹치지 않게 본 얼굴은 태오(갈색 앞머리, 덧니), 지호(안경), 지금 얼굴(옆 가르마 짧은 머리, 네모난 얼굴)이다. 안경, 수염, 점은 넣지 않았다.
- 얼굴 글은 실존 대조를 통과한 순서 「그 나이 한국 사람의 흔한 얼굴(작은 어긋남 포함) → 매력 → 꼭 보일 것 둘」로 썼다. 새여자선배 4차의 교훈대로 다듬어진 생김새 글(갸름한 턱, 곧은 콧대, 긴 눈매)은 넣지 않았다.

## 목소리

`목소리.mjs`가 굽는다. 새 배역이라 일레븐 v4를 일레븐랩스 공식 계정에서 굽는다([계정 문서](../../../../docs/AI_계정과_크레딧.md#일레븐랩스)).

- 후보는 공유 목소리 가운데 한국어가 모국어이고 v4로 검증된 젊은 남성(공지 기간 730일) 182개에서 대화 · 캐릭터 쪽 열셋을 추렸다. 한국어 미리듣기의 음높이(중앙값)를 재서 낮은 쪽부터 높은 쪽까지 여섯을 남겼다(KO 126Hz, Chris 135Hz, Mike 142Hz, Deoksu 160Hz, Krys 168Hz, Taehyung 169Hz).
- 대사는 처음 만남에서 동아리장이 실제로 하는 반말 네 줄이다(`world-front/club.mjs` m1 · m2 · m3_none · m4 · m5). 이름은 아직 정하지 않아 넣지 않았다.
- 꼬리표와 안정도(0.5)는 여섯이 같다. 줄을 0.6초 쉼으로 이어 −18 LUFS로 맞춘 한 개를 듣기 판으로 쓴다.
- `받아쓰기.py`가 줄마다 받아 적어 대본과 견준다. 여섯 모두 일치 0.97 이상이고 꼬리표를 소리 내 읽은 줄은 없다.
- 쓴 양은 일레븐랩스 474크레딧이다(Creator 월정액 안, 남은 양 약 7.8만).

```
node experiences/world-front/qa/동아리장후보_20261126/목소리.mjs 줄
node experiences/world-front/qa/동아리장후보_20261126/목소리.mjs 굽기
node experiences/world-front/qa/동아리장후보_20261126/목소리.mjs 맞추기
python -X utf8 experiences/world-front/qa/동아리장후보_20261126/받아쓰기.py
```

## 이름

조건은 셋이다. 받침 없이 끝나 「○○야」로 소개한다. 처음 배우는 학생이 읽고 말하기 쉬운 소리다. 서하, 하린, 지호, 태오, 유나와 소리가 겹치지 않는다. 후보는 민우(지금, 강민우), 시우(오시우), 건우(정건우)다. 성까지 같은 유명인이 있는지는 11-26에 웹 검색으로 봤고 셋 다 검색되지 않았다. 「유시우」(가수)와 「윤시윤」(배우)이 비슷해서 시우의 성은 「오」로 했다. 「남현우」(배우)가 있어 현우는 뺐다.
