# AI 커뮤니티·거래 내부 시범판

기획 원문: [준비안](../../docs/AI_커뮤니티마켓/README.md). 이번 작업의 GPT 기획·화면 작성은 사용자 명시 예외에 따른다.

이 폴더는 외부 고객에게 배포하는 제품이 아니라 운영자가 흐름을 검토하는 내부 시범판이다. 실제 회원·메시지·결제·PG·AI 추천·파일 업로드·외부 제출은 연결하지 않았다. 생성한 HTML은 오프라인에서도 열 수 있다.

## 만들기

```powershell
node experiences/ai-market-prep/build.cjs "C:/원하는/출력/시범화면.html"
node --test experiences/ai-market-prep/core.test.cjs
```

생성 HTML은 본 작업의 비공개 꾸러미에만 두고 저장소에 중복 저장하지 않는다. SUIT는 기존 `tools/lib/브랜드폰트.js`의 검증된 자산을 재사용한다. 원고·CSS·화면 코드·합성 데이터는 이 폴더, 양식과 실제 기록 기반 원고는 문서 폴더가 원천이다.

## 해 볼 것

1. 발견 → 사례 → 제작자·관련 상품 → 요청서로 이동한다.
2. 요청서를 비워 제출해 오류를 보고, 예시를 채워 예산·날짜 미정과 후보를 확인한다.
3. 예산·날짜를 맞지 않게 정해 후보 없음 안내를 본다.
4. 검토 뒤 내 작업에 초안을 보관하거나 JSON으로 내려받는다.
5. 판매자 등록 양식에서 직접 역할·사례 링크·제공 방식·참여 의사를 확인한다.
6. 커뮤니티에서 기존 작업 기록에 근거한 원고 20편과 공개 전 조건을 읽는다.
7. 운영 화면에서 거래 금액·비용·건수를 바꿔 공헌이익과 손익분기점을 확인한다.

폼 입력과 보관한 초안은 열린 창의 메모리에만 있다. 새로고침하면 사라진다. 내려받은 JSON은 사용자의 기기에 저장되므로 실제 개인정보를 넣지 않는다. 모든 합성 판매자·상품에는 예시 표시를 두고, 0건인 실제 응답·참여 상태를 실적으로 채우지 않는다.

실제 서비스 구현은 이 검토 뒤 별도 범위로 진행한다. 계정·권한·DB·개인정보 수집·실제 추천 공유·결제·지급을 연결할 때는 원문의 검수·출시 조건을 충족해야 한다.
