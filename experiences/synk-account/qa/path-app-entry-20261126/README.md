# 웹 플랫폼과 PATH 소개 쪽을 PATH 앱으로 잇기 (2026-11-26)

유호님 11-26 「네, 이어줘」. 웹 플랫폼(synk.im/account)의 PATH 칸이 옛 60~90초 취업 면접 연습을 열었고, PATH 소개 쪽(synk.im/path/, /en/path/)에는 PATH 앱 링크가 없었다. PC 앱은 범위 밖이다(PC 화면에는 PATH가 없다).

## 바꾼 것

- **웹 플랫폼:** 「시작할 서비스 선택」의 PATH(설명 「한국 유학 준비」), 내 홈 선반, 둘러보기, 앱 소개(`#app/path`), 회원 성향의 「PATH 열기」가 모두 `https://synk.im/path/app/`를 연다. 앱 소개 글은 PATH 앱(대학 비교, 서류 준비, 입학 면접 연습, 이용 안내)으로 바꿨다. 옛 면접 연습은 앱 소개 안의 「취업 면접 연습 열기」 링크로 남겼다.
- **PATH 소개 쪽:** 첫 화면 글에 PATH 앱 링크를 넣고, 길 지도의 「유학 준비」 칸을 열림으로 바꿔 「PATH 앱 열기」를 달았다. 검색 설명과 「지금 열린 것은 셋」도 맞췄다. 이 쪽의 정본은 공개본이다.

## 이 폴더

| 파일 | 하는 일 |
|---|---|
| `patch-live.mjs` | `node patch-live.mjs <공개본 폴더> <master 새 빌드 platform.js> <후보 폴더>`. 공개본 `account/dist/platform.js`는 master 빌드와 구성이 달라 통째로 덮지 않고 조각 14개만 얹는다. 소개 쪽 두 장도 같은 식이다. 조각마다 공개본에서 한 번만 맞는지, 되돌리면 공개본과 바이트까지 같은지 본다. |
| `check.mjs` | `node check.mjs <후보 폴더 \| -> <캡처 폴더>`. 공개 주소를 열고 후보만 끼워 1440 · 390에서 포털 · 내 홈 · 둘러보기 · 앱 소개 · 소개 쪽을 찍고 넘침 · 오류 · 링크 목적지를 잰다. `-`는 끼우지 않고 공개본을 잰다. |

- synk.im 공개 synk-policy `b40192f2`. 바이트 4/4 같음, 배포 점검 45713456745 통과(새 치명 · 심각 접근성 위반 0, 기준 그림이 달라진 쪽은 이번에 손대지 않은 쪽). 공개 뒤 끼우기 없이 `check.mjs -`로 1440 · 390 모두 넘침 0 · 오류 0, 포털의 PATH가 PATH 앱으로 간다.
