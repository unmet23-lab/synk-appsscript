# 웹 플랫폼 글꼴·회원 혜택 그림 가볍게 · 2026-10-13

유호님 「남은거 전부 진행해」(10-13). PATH 면접실 최적화 보고에서 남긴 「웹 플랫폼 첫 화면의 공용 큰 파일」을 줄였다. 화면·번들(JS)·데스크톱 앱은 그대로이고, `platform.css`의 글꼴 선언과 글꼴·그림 파일만 바꿨다. 공개 synk-policy `68e631a`(10-13 02:32 KST, Pages 성공).

## 바꾼 것

- **SUIT → SYNK Sans 두 조각:** 플랫폼에서 보이는 글(페이지·스타일·번들이 실제로 묶는 모든 모듈 — esbuild 입력 목록 — 과 지금 공개된 번들)에 나오는 글자 869자 조각(178KB)과 나머지 2,064자 조각(484KB). 나머지는 사용자 이름·작품 제목처럼 화면판에 없는 글자가 나올 때만 받는다. SUIT OFL의 예약 이름 때문에 글꼴 이름을 SYNK Sans로 바꿨다(저작권·라이선스 문구 그대로). 도구 `tools/build-platform-fonts.py`, 결과와 설명 [docs/브랜드_폰트/플랫폼_웹](../../../../docs/브랜드_폰트/플랫폼_웹/README.md).
  - 처음에는 `src/` 글자만 읽어 공개 번들의 회원 혜택 문구 등 60자가 빠졌다(번들이 `desktop/renderer/benefits.mjs` 등 src 밖 모듈 여덟 곳을 묶는다). esbuild 입력 목록과 공개 번들 글자를 함께 읽게 고쳤다. 지금 공개 `account/`에서 화면판 밖 글자는 플랫폼이 쓰지 않는 `assets/scrapbook.css` 주석뿐이다.
- **SYNK Arrow:** 화살표 네 글자(U+2190-2193)만 쓰는 면이 Inter Tight Medium TTF 전체(전송 155KB)를 받던 것을 그 네 글자 1KB로 줄였다.
- **Inter Tight 400·500, DM Mono:** TTF를 WOFF2로(Inter Tight는 글자·힌팅 그대로, DM Mono는 CSS 범위만).
- **회원 혜택 그림:** 이름·형식은 그대로(번들과 데스크톱 앱이 같은 이름을 쓴다) 가장 크게 보이는 곳에 맞췄다. care-note 209KB→45KB(같은 크기, WebP q90), fortune-star 518KB→74KB(960px AVIF), teacher-cover 1.55MB→554KB(720px PNG). 256색 PNG(73KB)는 바닥 그림자에 계단이 생겨 쓰지 않았다. [만든 법](../../../../docs/디자인/플랫폼_시그널/웹그림/README.md).
