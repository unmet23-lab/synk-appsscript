# 회원 혜택 후속 초기 개발 · 2026-10-05

## 구현 범위

중요한 대화 리허설과 가족 이야기 앨범의 로컬 MVP를 만들고 설치형·웹 플랫폼의 공통 회원 혜택 카탈로그에 연결했다. 기존 플레저는 유지한다. 웹 실행 링크는 HTTP loopback에서만 나타나며 설치형 소스는 별도 제품 프로필·권한·고정 포트·파일 다운로드 계약을 사용한다.

리허설은 준비된 상황에서 3턴 직접 작성 → 선택에 따른 다음 장면 → 재연습 원문 비교 → 첫 문장/메모 → 다음 방문 이어 연습이다. 앨범은 사진·본문·원래 음성 → 직접 답한 세부 기억 → 출처 있는 가족 기억 추가 → 보관/파일 왕복이다. Core Ask/Domain 원본의 재사용이며 자유 서술이나 음성을 생성형 AI가 해석한 결과는 아니다.

합계 **291개 통과**. 서버 공개 파일 목록·다른 출처 거부, Core의 명시 답/건너뜀, 자료 크기·형식·위장 파일 거부, 저장 실패와 비동기 경쟁을 포함한다. 검수에서 발견한 홈 이동 중 메모리 소실, 미디어 제거 후 늦게 다시 나타나는 문제, 기록 전환 시 편집 소실, 늦은 가져오기의 현재 화면 덮어쓰기, 저장 중 취소 오해를 수정했다. 마지막 앨범 수정 뒤 해당 앱 전체 20개를 다시 확인했다.

설치형은 이번 변경의 자동 검사 결과다. 앞선 소개 화면 검증의 Electron 화면/bridge 결과를 새 두 앱의 네이티브 실행·다운로드 완료 증거로 재사용하지 않는다.

## 실제 브라우저 확인

Codex 내장 브라우저의 실제 UI를 조작했다. 최초 두 앱의 기록이 비어 있음을 확인하고 가상 인물·이야기와 저장소의 승인 자산만 사용했다. 실제 가족 사진·통화 녹음·사용자 계정 자료는 사용하지 않았다.

### 대화 리허설

1. 거절 상황, 검증용 동료, 추가 업무를 맡기 어렵다는 목표로 3턴을 작성했다.
2. 첫 답 뒤 ‘부담스러운 반응에 답하기’를 고르면 두 번째 상대 대사가 ‘딱 이번 한 번만 안 될까요?’로 바뀌는 것을 확인했다.
3. 첫 턴을 다시 쓰고 자기평가를 개선했다. 처음 쓴 답과 다시 쓴 답이 함께 남고, 다음 방문에는 아직 막힌 두 번째 턴이 선택됐다.
4. 첫 문장·메모 편집과 기기 저장 후 새로고침 복원, 실제 `synk-rehearsal.json` 다운로드·읽기·가져오기 병합을 확인했다. 같은 ID는 현재 기록을 유지하며 1회가 중복되지 않았다.
5. 390px 화면의 가로 넘침이 없고 입력·재연습·저장 설정을 읽을 수 있었다. [완성 결과](rehearsal-result-390.jpg), [파일 복원 뒤 결과](rehearsal-restored-390.jpg).

### 가족 이야기 앨범

1. 가상의 가족 여행 이야기, 날짜·인물·기록 출처, 승인 카메라 WebP와 기존 합성 학습 MP3를 첨부해 한 장을 완성했다.
2. 장소 질문에 답하고 계기 질문을 건너뛰면 다음 질문이 바뀌었다. 다른 기억을 출처와 함께 더하고 홈 이동·기기 보관·새로고침 뒤에도 모두 유지됐다.
3. 플레이어에서 오디오 길이 6.864초와 오류 없음, 재생 버튼 클릭 후 재생 상태를 확인했다. 실제 청취 품질과 마이크 장치 녹음은 검사하지 않았다.
4. 실제 `synk-family-album.json`을 내려받아 원본 사진·음성의 SHA-256을 비교했다. 두 파일의 바이트가 일치했다. 삭제 후 되돌리기와 파일 불러오기 후 사진·음성·기억·질문 답/건너뜀 복원도 확인했다. [내보내기 확인 기록](export-verification.json).
5. 320px 화면의 가로 넘침·누락 이미지 없이 조작 가능했다. [320px 결과](album-result-320.jpg), [PC 결과](album-result-desktop.jpg).

검수 후 두 앱의 기기 저장을 꺼 검수용 디스크 사본을 제거했다. 새로 연 두 체험은 0개 기록과 저장 꺼짐으로 시작한다. 검수 화면과 내보낸 파일은 별도 증거이며 제품 기본 예시 데이터가 아니다.

### 플랫폼 연결

기존 `4280/synk-account/platform.html#benefits`를 최신 빌드로 새로고침했다. 두 서비스 상세가 ‘개발 미리보기’와 실제 제공 범위를 표시하며, 실행 링크 클릭 뒤 `4297/` 리허설과 `4298/` 앨범 첫 화면이 각각 새 탭으로 열리는 것을 확인했다. [앨범 상세 실행 입구](platform-album-detail.jpg).
