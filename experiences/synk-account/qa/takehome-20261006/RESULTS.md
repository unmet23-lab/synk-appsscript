# 회원 혜택 소장 경험 · 2026-10-06

## 구현

- 가족 앨범: 인쇄용 책 미리보기, 원본 사진·음성과 복원 JSON을 포함한 ZIP 다운로드.
- 대화 리허설: 완료한 최근 10회 기록의 처음/다시 쓴 답·실제 분기·자기평가·첫 문장을 독립 HTML 작품집으로 내보내기와 인쇄.
- 우리 집 손맛: 앨범 안에 배운 출처·분량·재료·순서, 직접 만들어 본 날짜와 메모, 마지막 기록 뒤 수정 표시. 소장본과 JSON에 포함.
- 상세 화면의 질문·요리 메모·가족 기억을 폼별로 보존. 다른 폼을 저장하거나 보관 설정을 바꿔도 미저장 입력을 복원하고, 화면 이탈/새로고침을 알린다.
- 플랫폼 공통 소개와 설치형 다운로드 계약에 결과물·파일명·MIME·크기 한도 반영.

기존 Core Ask/Domain 재사용이다. 사용자 원문을 자동으로 해석하거나 새 Atlas 엔진을 추가하지 않았다. 유료 AI·외부 전송·운영 권한 변경·배포는 실행하지 않았다.

## 실제 브라우저와 파일 확인

검증용 가상 인물·가상 가족 이야기·가상 조리 메모와 저장소의 기존 카메라 WebP/합성 학습 MP3만 사용했다. 실제 가족의 자료나 조리 결과는 사용하지 않았다.

1. 10-05에 UI로 내보낸 앨범/리허설 JSON을 실제 파일 선택 UI로 불러왔다. 기존 사진·목소리·가족의 기억·질문 답과 대화 원문/재연습·자기평가를 확인했다.
2. 새 손맛 페이지를 UI로 작성해 저장했다. 처음에는 미시도, 날짜/메모를 직접 저장한 뒤에는 시도 1회, 만드는 순서를 수정한 뒤에는 ‘마지막 기록 뒤 레시피를 수정했어요’가 표시됐다. 양에 답하면 다음 질문이 불 세기로 바뀌었다.
3. 소장 화면에 이야기 2장·사진 1개·목소리 1개가 나타나고 레시피·시도·수정·질문 답이 책에 함께 담겼다. 목차를 누르면 해당 글로 이동하며 `#takehome` 경로를 유지했다.
4. 실제 UI에서 `synk-family-album.zip`(1,023,099바이트)과 `synk-rehearsal-book.html`(당시 873,849바이트)을 내려받았다. ZIP을 Python 표준 zipfile로 열어 CRC 오류 없음·한글 안내 파일명·여섯 항목을 확인했다. 추출한 사진·음성 모두 복원 JSON 및 최초 JSON의 원본 데이터와 바이트가 같다. [바이트 비교](archive-checks.json).
5. 기기 보관을 켜고 새로고침/새 탭에서 이야기와 손맛 기록이 복원됐다. 초안 수정판에서는 작성 중인 요리 메모를 둔 채 다른 질문에 답을 저장했고, 해당 메모가 유지되는 것을 실제 입력 칸에서 확인했다.
6. 390px 앨범 소장 화면에서 글·버튼이 표시되고 문서 폭 375px로 가로 넘침이 없었다. [모바일](album-takehome-mobile.jpg), [PC](album-takehome-desktop.jpg), [성장 작품집](rehearsal-book-desktop.jpg).
7. 플랫폼을 최신 빌드로 새로고침해 성장 작품집과 가족의 책·우리 집 손맛 소개가 나타나는 것을 확인했다.

소장 ZIP과 추출 폴더는 `synk-family-album.zip`, `album-archive/`에 있다. 작품집 예시 `synk-rehearsal-book.html`은 인쇄 문단 수정 후 같은 원본 JSON을 최종 `createBook` 함수로 다시 생성한 873,945바이트 파일이다. 자동 생성된 검증 예시이며 실제 사용자의 기록이 아니다.

## 인쇄와 브라우저 검수 한계

앱의 인쇄 CSS로 CDP `Page.printToPDF`를 실행해 앨범 5쪽·작품집 3쪽을 만들었다. Poppler/PDFium으로 렌더한 모든 페이지를 확인했다. 앨범의 표지·목차·레시피·사진·본문·출처가 잘리지 않고 표시됐다. 실제 프린터로 종이를 출력한 것은 아니다.

작품집의 짧은 마지막 안내가 다음 쪽으로 갈라지는 것을 발견해 최종 CSS에서 짧은 대화 턴/마지막 문장 묶음을 같은 쪽에 배치하도록 수정했다. 긴 답변은 고정 높이·숨김 없이 이어진다. 자동 검사는 통과했으며 `rehearsal-print.pdf`와 PNG는 이 문단 수정 **전**의 검수 증거다. 최종 PDF 재출력은 아래 브라우저 제약으로 완료하지 못했다.

- 내장 브라우저가 `file://` 방문을 허용하지 않아 추출한 HTML을 파일 주소로 직접 열어 듣는 오프라인 재생은 확인하지 않았다. 외부 리소스가 없는 독립 파일 구성·CSP·포함 경로와 원본 바이트는 자동/파일 검사로 확인했다. 허용되지 않은 주소를 우회하지 않았다.
- 미저장 상태의 화면 이탈에서 ‘작성 중인 내용을 닫고 이동할까요?’ 확인창이 나타난 뒤 브라우저 도구의 취소/닫기 처리가 멈췄다. 이후 직접 취소·복원 JSON의 추가 UI 재가져오기·최종 PDF/리허설 모바일 재확인은 미완료다. 사용자에게 해당 확인창의 취소를 요청했다. 확인창 취소 시 초안 보존은 자동 검사로 확인한 범위다.
- 이번 가상 앨범은 검수 브라우저의 기기 보관이 켜져 있다. 제품에 기본 데이터로 삽입한 것이 아니며 내보낸 예시와 구분한다.

운영 회원 인증·계정별 동기화·온라인 가족 공유·실물 제작/배송·다른 브라우저/실기기·장기 보관·실제 청취 품질·새 설치본 실행과 공개 출시는 별도 후속이다. 이 결과는 사람의 대화 능력 향상이나 가족의 만족도를 입증하지 않는다.
