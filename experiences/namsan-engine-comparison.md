# 남산 네이티브 엔진 비교

2026-09-19. 사용자가 Unity URP와 Unreal 5 두 버전을 모두 구현해 비교하도록 요청했다. 최종 서비스 엔진을 고른 결정은 아니다.

이 문서는 **9월 19~20일 이전 노트북에서 수행한 비교·설치 이력**이다. 아래 로컬 주소·설치 경로·미완료 항목은 당시 상태이며 새 노트북의 설치 상태나 지금의 작업 순서를 뜻하지 않는다. Unity의 후속 컴파일·렌더 성공은 아래 9월 20일 기록을 따른다. 현재 WORLD의 [3D 그래픽 방향](../docs/디자인/게임_풍경과_재질.md)과 [2D 화면 기준](../docs/디자인/월드_시그널/README.md)은 담당 원문에서 확인한다.

## 눌러서 열기

2026-09-20, 문서 대신 열 수 있는 [Unity 실행 준비 화면](http://127.0.0.1:5195/unity)과 [Unreal 실행 준비 화면](http://127.0.0.1:5195/unreal)을 추가했다. 당시 Windows PC에서 서버를 켜면 열리는 로컬 주소다. 최초 준비 단계에는 엔진 본체와 게임 빌드가 없어 버튼이 Unity 공식 설치 창 / Epic Games Launcher를 열었다. 이후 Unity 연결은 아래 기록처럼 갱신했다. 엔진 게임의 실제 플레이 링크나 웹 이식판은 아니다. [기존 웹 남산](http://127.0.0.1:5194/namsan.html)도 로컬 서버가 필요하다.

실행 화면은 고정 경로의 게임 빌드 → 에디터 → 설치 준비 순으로 연결 대상을 확인한다. 재부팅 후 다시 켜는 방법과 검증 범위는 [실행 허브 안내](namsan-launcher/README.md)에 있다.

## 비교 화면

실제 엔진이 실행된 뒤 전체 정원·몽글 근접·전망 위치를 1600×1000으로 촬영한다. Unity 수직 화각 52°를 Unreal 수평 화각으로 환산한다. Unreal의 PC 조명 기능을 모바일 결과로 표현하지 않는다. 단순 FPS 설정과 실제 측정값도 구분한다.

## 현재 실행 장애

2026-09-20 후속: Unity 에디터가 `C:/Program Files/Unity 6000.3.24f1/Editor/Unity.exe`에 설치된 것을 확인하고 실행 링크에 연결했다. 사용자 Personal 약관 동의 후 Unity Hub3.21.3을 공식 winget 패키지로 추가 설치하자 에디터가 라이선스를 인식했다. 패키지·URP 설정 오류를 고친 뒤 실제 컴파일·장면 생성·렌더3장이 성공했고 정원 반전 오류도 실제 렌더에서 확인해 수정했다. Epic은 캐시를 복구용 보관 후 갱신하자 5.8 설치 선택과 가격·라이선스 수락창이 나타났다. Unreal 약관은 사용자 확인 대기이며 본체 설치·실행은 아직 미완료다. 아래 설치 실패 내용은 이전 이력이다.

Unity CLI 설치와 계정 로그인은 확인했다. Editor 4,127,507,400바이트 다운로드와 서명 검증 후 설치 단계에서 실패했다. 기본 Program Files 경로의 권한 오류는 확인됐으나 사용자 경로의 내부 오류는 로그만으로 확정되지 않았다. 직접 실행 시 Windows가 작업 취소를 반환했다. 라이선스 활성화·Editor 실행은 아직 확인되지 않았다.

Epic Games Launcher는 사용자 Windows 승인 후 설치됐다. Unreal Engine 본체 설치와 Epic 로그인은 아직 확인되지 않았다. C++ 빌드 도구·플랫폼 SDK도 준비 상태를 확인해야 한다. 로그인·보안 권한·사용자 자격 판단이 필요한 약관은 사용자 직접 확인 대상으로 남겨 둔다.

그 밖의 소스 준비는 진행했지만 **두 버전을 실행 가능한 완성본으로 인수한 상태는 아니다.** 기존 `dokkaebi-express/namsan.html`은 변경하지 않았다.

## 다음 실제 작업

아래는 당시 남겼던 연구 과제다. Unity의 컴파일·렌더는 위 후속 기록에서 완료됐으며, 새 작업을 시작할 때는 현행 제품 우선순위와 해당 PC의 실제 상태를 먼저 확인한다.

1. Windows 설치 권한과 엔진 계정·라이선스 단계를 완료한다. 최신 환경 상태는 [로컬 확인 결과](namsan-urp/QA/native-engine-environment.json)에 별도 기록한다.
2. Unity C#·셰이더 및 Unreal C++를 실제 컴파일하고 오류를 수정한다.
3. 같은 자산을 임포트한 실제 게임 화면에서 축·크기·원경·노출·섬유·의상 관통을 확인하고 조정한다.
4. PC 이동/꾸미기/문제와 모바일 UI를 확인한 뒤, 실물 Android/iPhone에서 프레임·메모리·발열을 측정한다.

정원 High는 869,762삼각형, Mobile은 235,764삼각형이며 원본 보행면을 유지했다. 이 감축 수치가 목표 미술 품질이나 모바일 FPS를 입증하지는 않는다. 16명 접속·소속 권한·서버 저장은 아직 연결하지 않았다.
