## 재현과 전달

`node tools/package-path-interview.mjs --pages`의 `.tmp/path-interview-pages/public/`만 공개 저장소에 배치한다. 감사 manifest는 그 상위에 남긴다. 기본 standalone 묶음 및 `--mount /path/` 출력은 기존 개발/다른 호스트용이며 공개 PATH 소개를 대신하지 않는다.

Quest에서는 위 HTTPS 주소를 브라우저로 열고 마이크로 답변→한국어 음성 준비→마이크 확인→VR 입장 순서다. 현재 공개 Whisper Base q8의 최초 모델·런타임 준비에는 약103MB 다운로드가 필요하다. 기존3D 시제품용 Vosk 약89MB는 별도로 보존한다. 현재 기기에 VR이 없으면 지원 불가로 표시하며 PC 둘러보기·글 입력 연습을 사용할 수 있다.

사용자 첨부의 회색 중앙 영역을 기존 공개판에서 두 질문 완료→처음 방 둘러보기로 재현했다(`room-preview-fix-before.png/json`). 정지된 영상으로 새 VideoTexture를 만들 때 프레임 업로드를 예약하지 않았고, 완료 뒤 화질을 바꿔 영상 버퍼가 비워지면 시작 이미지도 숨겼다. 이미 디코딩된 첫 프레임만 즉시 업로드하고, 완료 상태의 빈 버퍼에는 시작 이미지를 복원했다. 영상 재생·원본 자산·질문 분기·30도 조작·드래그 기본 꺼짐·XR 추적은 유지한다.

수정 전 두 회귀시험 실패, 수정 후 방 공간·VR 관련39/39 통과. 공개 커밋 `aa0af0e87cc5b2eb58967d41cf5969536d23fe25`의 room-space 한 파일만 반영했으며 실행 패키지53개 다른 파일은 동일하다. 실제 공개판에서 완료 뒤 최초 둘러보기·닫고 재진입·화질 변경 뒤 둘러보기의 인물 표시를 확인했다(`room-preview-fix-public.json`, `room-preview-fix-public-after.png`). 실제 Quest 착용 검증은 추가하지 않았다.


## 면접 중 둘러보기 전환 검수

기존 공개판에서 답변 중 둘러보기→Esc를 누르면 미리보기만 닫히지 않고 면접까지 일시정지되는 동작을 재현했다(`live-preview-before.json/png`). document의 Escape 핸들러가 window의 미리보기 닫기보다 먼저 실행되는 원인이었다. 미리보기 중에는 닫기만 처리하고 키 반복을 무시하며, 기본 화면의 Escape 일시정지는 유지했다.

실제 등록 핸들러를 실행하는 두 회귀시험은 수정 전 실패했다. 수정 후 면접 UI·세션·방·VR 관련63/63 통과. 공개 `328895304cf1298e0f5ba21bf43d9318df9cc1a3`는 rehearsal.mjs 하나만 변경하고 나머지 실행 패키지53파일은 동일하다. 새 영상 생성·자산·카메라 변경은 없다.

로컬4K 및 실제 공개 브라우저에서 질문·경청·후속 질문 중 열기/닫기/재진입, 좌우30도·Home 복귀를 수행하고 면접 종료까지 확인했다. 미리보기 Esc 뒤 답변 시간과 영상 재생이 이어지고, 인물이 빈 화면으로 바뀌는 현상은 관찰되지 않았다. 기본 화면 Escape 일시정지도 로컬에서 확인했다. 공개 실로드 SHA와 화면·미디어 상태는 `live-preview-loaded-source.json`, `live-preview-public.json`, `live-preview-public-after.png`에 있다. PC 드래그 기본 꺼짐·저감도·무관성·XR1:1 추적은 유지한다. 실제 Quest 착용·마이크·기기 프레임 성능·멀미 감소 효과는 이번에 확인하지 않았다.
