# 일터 체험 상향판 기준

2026-11-21 유호님: 「호텔 프런트, 면세점 판매, 해외영업·무역사무, 의료 코디네이터, 고객상담의 하루 — 이거 지금 전부 만들어줘. 다만 퀄리티 좋아야해. 지금처럼 요양원에서 한 차원 더 발전한 버전이 필요해」.

다섯 일터는 이 기준으로 만든다. 첫 판 「요양보호사의 하루」(`jobs/care-home/`)가 바닥이고, 아래 여섯 가지가 그 위에 더하는 것이다. 바닥의 규칙(점수 없음, SYNK가 고용주에게 보내지 않음, 멀미 아홉 규칙, 현지어 절차, 검수 사슬)은 [진행기 설계](진행기_설계.md)와 [README](../README.md)를 그대로 따른다.

## 이름

- 제목은 「○○의 하루」다. 학생이 그 일에 이미 붙었다고 전제하는 「첫 출근」은 쓰지 않는다. 이 체험은 가기 전에 하루를 겪어 보고 나와 맞는지 고르는 것이다.
- 체험 안의 대사에서는 학생이 그날 처음 온 신입으로 나와도 된다.

## 여섯 가지

### 1. 그 일의 도구를 직접 다룬다

- 그 직업이 하루 종일 보는 화면, 서류, 전화를 학생이 직접 다룬다. 예약 화면에서 방 번호 찾기, 여권과 면세 한도 확인, 견적서의 숫자 확인, 문진표 받기, 상담 기록 남기기 같은 일이다.
- 한 편에 셋 이상 둔다. 장면 다섯 가운데 셋 이상에 하나씩 들어간다.
- 걸음 종류는 `work`다(아래 「새 걸음」). 화면과 서류는 그림이 아니라 장면표의 글로 적고 엔진이 그린다. 그림 속 한글이 뭉개지지 않고 힌트 언어로도 읽힌다.
- 사실을 찾는 일이라 맞고 틀림이 있다. 화면이 「정답」이라고 표시하지 않는다. 동료가 사실대로 반응한다(「302호 맞아요」, 「한 번 더 볼래요? 이름이 달라요」). 기록에는 어떤 도구를 다뤘는지만 적고 맞힌 수는 적지 않는다.

### 2. 모국어가 일의 힘이 되는 장면

- 학생과 같은 말을 쓰는 손님, 환자, 바이어, 고객이 나온다. 학생은 그 말을 듣고 한국어로 동료에게 전하거나, 한국어 안내를 그 사람에게 전한다. 회사가 외국인을 뽑는 까닭을 학생이 직접 겪는다.
- 한 편에 하나 이상 둔다.
- 걸음 종류는 `relay`다. 외국인의 말은 장면표에 힌트 언어마다(mn, vi, en) 적고, 화면은 학생이 고른 힌트 언어로 보인다(고르지 않았으면 en). 그 사람의 영상은 말하지 않는 경청 영상을 쓰고, 말은 말풍선으로 보인다. 학생의 답은 한국어로 말하거나 쓴다.
- 외국어 문장은 현지어 절차(역번역 대조, 교정, 카본 문법 채점)를 똑같이 거친다.

### 3. 하루가 이어진다

- 앞 장면의 선택이 뒤 장면의 사건을 바꾸는 곳이 둘 이상 있다. 예: 아침에 되묻지 않고 넘어간 일이 오후에 손님 불만으로 돌아온다.
- `when`과 `requires`로 적는다. 요양보호사 편은 저녁 보고 한 곳뿐이었다.
- 바뀐 결과도 벌로 보이지 않게 쓴다. 그 일에서 실제로 일어나는 일로 보인다.

### 4. 화면이 살아 있다

- 자리는 다섯 곳, 가리킬 점은 열두 개 이상이다. 점 이름은 그 일터에서 실제 쓰는 말이다.
- 인물 영상은 컷 크기, 높이, 방향을 섞는다. 감정이 오가는 자리는 얼굴을 가깝게 잡는다. 가까운 컷끼리도 크기와 방향을 다르게 한다(유호님 11-19, 11-20).
- 정면 중간 샷 일색을 쓰지 않는다. 두 사람이 함께 나오는 자리를 하나 이상 둔다. 카메라는 고정이다(멀미 규칙).
- 그림은 Seedream 5.5, 영상은 Flow Omni 최신 판이다. 첫 컷 하나로 먼저 확인한 뒤 묶음을 낸다.

### 5. 이 일로 가는 길

- 맺음에 그 직업의 실제 길을 보인다. 비자 종류, 학위, 자격, 추천 기관, 임금 하한, 한도를 적는다.
- 근거는 [조사 C](../../../../docs/PATH_일터체험_조사/C_비자경로_직업소개법.md)와 그 출처 원문이다. 쓰기 전에 현행 원문과 대조하고, 대조한 날을 맺음 출처 칸에 적는다.
- 준비 사다리의 칸을 그 길의 단계로 만든다. 예: 학위, 자격, TOPIK, 추천.

### 6. 그 일터의 말

- 그 일터에서 실제 쓰는 말을 서른 개 이상 대사, 점 이름, 도구에 싣는다(「체크인 도와드리겠습니다」, 「여권 보여 주시겠어요?」).
- 높임은 그 자리의 관계에 맞춘다. 손님과 환자에게는 하십시오체와 해요체, 동료와 상사에게는 해요체를 쓴다.
- 대본은 직접 쓴다. 공공기관 교재와 매뉴얼 문장은 옮기지 않는다.

## 새 걸음(엔진, 「PATH 일터 체험 개발」 세션이 넣는다)

일터 세션은 엔진과 화면 코드를 고치지 않는다. 아래 꼴로 장면표를 쓰고, 엔진이 들어오면 그대로 돈다. 꼴을 바꿔야 하면 개발 세션에 알린다.

```jsonc
// 일의 도구: 화면이나 서류를 보고 고른다. 고른 것마다 이어지는 걸음이 있다.
{ "type": "work", "id": "find-room", "record": "예약 화면에서 방 번호를 찾는 차례",
  "tool": { "kind": "screen",            // screen(업무 화면) | paper(서류) | phone(전화) | chat(채팅)
            "title": "예약 조회",
            "rows": [["손님", "BATBAYAR / 바트바야르"], ["객실", "302 · 디럭스 트윈"], ["숙박", "11.21 ~ 11.23 (2박)"]],
            "note": "조식 포함" },          // rows, lines(글 줄), note 가운데 쓰는 것만
  "prompt": "손님의 방 번호를 골라요.",
  "options": [ { "id": "302", "label": "302호", "then": [ { "type": "line", "who": "senior", "text": "네, 302호 맞아요." } ] },
               { "id": "320", "label": "320호", "then": [ { "type": "line", "who": "senior", "text": "한 번 더 볼래요? 숫자 순서가 달라요." } ] } ],
  "hint": { "mn": "…", "vi": "…", "en": "…" } }

// 모국어로 잇기: 외국인의 말을 학생이 고른 힌트 언어로 보이고, 학생이 한국어로 전한다.
{ "type": "relay", "id": "guest-relay", "record": "손님의 말을 한국어로 전하는 차례",
  "who": "guest",                         // 경청 영상 clip을 쓸 수 있다
  "foreign": { "mn": "…", "vi": "…", "en": "…" },
  "meaning": "방이 추워서 담요를 하나 더 받고 싶대요.",   // 한국어 뜻. 예시 답과 검수에 쓴다
  "prompt": "손님의 말을 선배에게 한국어로 전해요.",
  "example": "선배님, 손님이 방이 추워서 담요를 하나 더 받고 싶으시대요.",
  "listen": "guest-listen",
  "hint": { "mn": "…", "vi": "…", "en": "…" } }
```

- `work`에도 `when`을 붙일 수 있다. 맺음의 갈림길(`closing.forks`)은 지금처럼 `say`의 보기만 쓴다. `work`는 가치의 갈림길이 아니다.
- 대사 걸음(`line`)에 `"channel": "phone"`을 적으면 화면이 전화 통화로 보인다. 그 사람의 영상이 없어도 된다.

## 다 됐다고 말하기 전에

- 위 여섯 가지를 하나씩 대조한 표를 그 직업의 제작 기록(`jobs/<id>/production/제작기록.md`)에 남긴다.
- 낯선 눈 둘에게 보인다. 하나는 그 나라 유학생의 눈으로 「이 일을 해 보고 싶어지거나 나와 맞지 않음을 알게 되는가」를 묻는다. 다른 하나는 그 직업 현직자의 눈으로 「현장과 다른 곳」을 묻는다. 답과 반영을 제작 기록에 적는다.
- 고객 화면 검수 사슬(카본, Fable 최종)을 거친 뒤 공개한다. 실기(Quest, 실제 휴대폰)를 확인했다고 쓰지 않는다.
