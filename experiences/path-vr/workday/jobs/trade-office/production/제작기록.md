## 2. 장면 설계

화장품 수출 중소기업 해외영업팀에서 신입으로 하루를 보낸다. 다섯 장면과 맺음이다.

| 장면 | 자리 | 하는 일 |
|---|---|---|
| 아침 회의 | 회의실(팀장과 대리 두 사람) | 자기소개, 호칭 카드, 처음 듣는 말(FOB, 반입 마감) 갈림길, 사무실 둘러보기 |
| 견적서 | 내 자리(대리가 서서) | 영어 메일에서 바이어가 바라는 것 찾기(work), 견적서 숫자를 팀장 메모와 맞추기(work), 결재 알리기 |
| 바이어 전화 | 내 자리(대리 가까이) | 같은 말을 쓰는 바이어의 말을 대리에게 한국어로 전하기(relay in, 전화), 바이어에게 답하기 갈림길 |
| 오후 | 탕비실 → 대리 자리 | 학교 선배의 가격표 부탁 갈림길(전화), 출항 일정표에서 배 고르기(work) |
| 서류와 하루 보고 | 출고 창고 → 팀장 자리 | 인보이스와 패킹 리스트 맞추기(work), 포워더 전화, 팀장에게 하루 보고, 팀장의 말을 바이어에게 모국어로 전하기(relay out, 전화) |

## 4. 낯선 눈 둘

설계 검토를 반영한 장면표와 사진 열 장을 Fable 5.2 두 개가 따로 읽었다(11-22, 영상 전).

### 몽골·베트남 유학생의 눈 — 「해 보고 싶어지거나 맞지 않음을 알게 되는가」

- 답: 「이 일이 어떤 일인지」는 알게 되지만 「나와 맞는지」는 반쯤만 알게 된다. 바이어의 말을 한국어로 전하는 차례에서 「여기서 쓸모 있겠다」는 느낌이 처음 들고, 날짜 넷을 맞추는 배 고르기에서 이 일의 머리 쓰는 맛을 알았다. 어려운 자리(재촉하는 바이어, 거절하기 어려운 선배)가 한 번에 풀려 「나는 못 하겠다」를 느낄 틈이 없다.
- 반영: 대리가 통화 전에 답을 미리 말하지 않게 하고, 바이어가 「오늘 안 되면 다른 회사에도 물어봐야 해서요」로 한 번 더 민다. 선배는 거절 뒤 「한 장인데 그것도 안 돼?」를 한 번 더 한다. 팀장의 보고 물음을 「오늘 있었던 일」로 넓히고, 빼고 보고했을 때의 말을 「대리한테 들었는데」로 바꿨다. 「결재·결제」, 「인도 조건」, T/T와 PCS·CTNS를 「견적서의 말」 알림 글로 풀었다. 「달래요」를 「달라고 해요」로. 맺음 「이 일로 가는 길」을 채용 공고에서 볼 두 가지로 시작하고, 오늘 한 일 가운데 어디까지가 해외영업원의 일인지 적었다. 베트남어 호칭(신입은 em, 대리는 chị)과 몽골어 낱말 둘을 둘째 교정에서 고쳤다. 탕비실 창밖을 겨울로 다시 구웠다.
- 엔진 몫으로 개발 세션에 알림: 맺음의 힌트 언어 풀이 칸, work의 한 번 더 고르기, 보고 항목별로 갈리는 반응.

### 중소 수출기업 해외영업 과장의 눈 — 「현장과 다른 곳」

- 답: 뼈대(결재선, 단가는 팀장·날짜는 생산, 확인 뒤 답하기, 안 좋은 소식 먼저, 금액의 영 하나와 30ml·50ml 실수)는 현장과 맞다. 다른 곳은 FOB인데 우리가 배와 포워더를 정하는 모습, 주문 확정(발주서, 선금) 없이 생산 날짜가 서는 것, 「70% after shipment」, 수출 신고·B/L·원산지 증명서가 나오지 않는 것, 가격표를 보낸 길의 팀장 말이 가벼운 것, 30명 규모에서 「생산팀」, 시차 설명이 유럽·미국 이야기인 것, 사진(탕비실 여름 나무, 화인 없는 상자).
- 반영: 포워더는 「바이어 쪽에서 정한 포워딩 회사」, FOB 알림에 바다 없는 나라 한 줄, 생산은 「공장 말로는, 이번 주에 발주서랑 선금이 들어오면」, 결제 조건은 「70% before shipment」, 「선적 서류」 알림 글(인보이스, 패킹 리스트, 수출 신고, B/L, 원산지 증명서), 팀장 말은 「영업 비밀이에요. 밖으로 보낸 게 있으면 지금 말해 줘요. 같이 회수해요」, 통화 뒤 메일로 남기기(확인 쪽 예시와 원칙), 맺음에 「메신저와 시차」, 클레임과 대금, 「작은 회사에서는」을 더했다. 상자 점은 「화인 자리」로 고쳤다.
- 반영하지 않음: 첫날 신입이 바이어 전화를 받지 않는다는 지적은 장면의 뼈대(회사가 외국인을 뽑는 까닭)라 두고, 통화 뒤 메일로 남기는 일을 넣었다. 몽골 바이어의 연말 행사에 10일 배가 늦다는 지적은 바이어가 「다시 잡을게요」로 받는 것으로 두었다.

## 5. 설계 검토

Fable 5.2가 장면표 초안을 읽기 전용으로 검토했다(11-22, 18건, P1 둘). 검토 답 원문은 이 세션 scratchpad의 `fable-설계검토-trade-office.md`(git 밖)다.

| 번호 | 지적 | 처리 |
|---|---|---|
| D1 P1 | 한 거래가 하루에 견적에서 선적 예약까지 간다 | 반영. 견적은 승인 뒤 보냄, 생산 날짜는 「지금 주문하면」, 오후 서류는 지난달 주문 건, 포워더는 예약이 아니라 자리 확인 |
| D2 P1 | 바이어가 한국어로 말하는 것처럼 보인다 | 반영. 바이어 전화 대사를 line의 `foreign`으로(개발 세션의 새 꼴), 둘째 질문을 대사로 꺼냄, relay에 `channel: phone` |
| D3 | 메모에 금액이 없어 물음과 답이 어긋난다 | 반영. 메모에 합계 USD 8,400 |
| D4 | 서류가 한국어로만 적혀 있다 | 반영. 견적서, 인보이스, 패킹 리스트의 칸을 영어와 한국어로 |
| D5 | 결재선 고르기는 찾을 사실이 없다 | 반영. 이 걸음을 영어 메일 읽기로 바꾸고 결재 순서는 대리의 대사로 |
| D6 | 전하는 말의 예시가 길고 딱딱하다 | 반영. 세 문장으로 나눔 |
| D7 | 선배 부탁의 끌림이 약하고 뒤가 끊긴다 | 반영. 「취업 때 도와준 선배」, 다음 부탁 예고, 보고 뒤 팀장의 한마디(가격표를 보냈을 때) |
| D8 | 「했으면」이 어색하다 | 반영. 팀장 대사 둘을 고침 |
| D9 | 숫자가 든 대사의 초가 모자란다 | 반영. 지시문에 읽는 소리를 적고 그 소리로 초를 셈 |
| D10 | 시작 그림의 눈길과 입 | 반영. desk-close, desk-daeri를 다시 구움 |
| D11 | 모니터가 실제 프로그램 화면, 탕비실과 달력의 글자 | 반영. 모니터는 민무늬 표, 탕비실과 팀장 자리를 다시 구움 |
| D12 | 고용주 쪽 조건이 없다 | 반영. 맺음 「회사의 조건」 |
| D13 | 탁상 달력의 붉은 고리 | 반영. 작은 네모 표시로 다시 구움 |
| D14 | 팔레트 점 위치 | 반영 |
| D15 | 낱말과 높임 | 반영. 핸드 팔레트(자키), 포워딩 회사, 항만 창고와 클로징, 팀장의 「이다은 대리가」, FOB 알림 한 줄 |
| D16 | 하루의 날짜가 없다 | 반영. 메일 화면에 「오늘은 11월 23일 월요일」 |
| D17 | 확인과 넘어감이 같은 대사를 받는다 | 반영. 넘어간 쪽에 따로 한 줄 |
| D18 | 빛과 계절 | 반영. 팀장 자리 두 장을 아침 빛과 늦은 오후 빛, 겨울 창밖으로 |
