## 2. 설정을 바꾼 까닭

조사에서 E-7-2 고객상담 사무원은 「국제용역, 해외영업에 한하여」 해외에 있는 외국인 고객을 상대하는 일로 정해져 있음을 확인했다(법무부 체류민원 자격별 안내 매뉴얼 2026-11-16판). 텔레마케터는 빠지고, 회사는 상시근로자 500명 이상·국제용역 매출 50억 원 이상·직접 고용이다. 그래서 첫 초안의 「국내 통신사 고객센터」를 「해외 이용자를 둔 한국 구독 앱(드라마·웹툰) 회사의 해외 고객 상담팀」으로 바꿨다. 회사와 앱 이름(윤슬플러스), 요금, 규정은 지어낸 예시라고 장면표 `reviewNote`와 결제팀 답장에 적었다.

## 4. 검토와 낯선 눈

### 설계 검토(Fable, 11-22)

30건(P1 10, P2 16, P3 4). 원문은 이 세션 기록에 있다. 처리:

| 번호 | 지적 | 처리 |
|---|---|---|
| D1 | 보고의 key가 팀장이 이미 아는 일 | 반영. key를 「그 전화 뒤로 다음 전화를 받을 때 긴장이 됐습니다」로, 팀장 답 둘과 맺음 문장을 바꿈 |
| D2 | 짐작 길에 결제팀 답장이 묻지도 않았는데 옴, 답할 걸음 없음 | 반영. 항의 → 선배 「같이 물어봐요」 → 답장 → 사과하고 바로잡는 말하기. 확인 길에도 답을 전하는 말하기 |
| D3 | 기술지원팀 회신 시각이 갈래마다 다르고 재문의에 답할 걸음 없음 | 반영. 회신 13:40으로 같게, 재문의 13:10, 안내하는 말하기 추가 |
| D4 | 성별·발신 번호로 본인 확인을 추리 | 반영. 「가족(대리인) 등록」 칸을 찾는 물음으로 바꾸고 성별 칸 삭제 |
| D5 | 본인 확인을 묻는 말이 없음 | 반영. 「본인 확인을 위해 생년월일과 가입하신 휴대폰 끝 번호를…」 말하기와 고객 답 |

### 낯선 눈 둘(11-22)

두 눈 모두 장면표만 읽었다. 첫 시안을 고친 뒤 다시 보이지는 않았다.

**한국어 2~3급 유학생의 눈.** 물음: 처음 읽는 사람이 무슨 일인지, 왜 그렇게 해야 하는지 알아듣는가.

| 걸린 곳 | 고친 것 |
|---|---|
| 해외 고객 팀인데 고객이 한국어로 말하는 까닭을 모름 | 조회 대사 「우리 팀 고객은 해외에 사는 이용자예요. 한국어로 묻는 분도 많아요」, 공지 첫 줄 「우리 팀 고객」 |
| 「마침 같은 나라 분」이 우연처럼 읽힘 | 팀장 「모국어 대기열로 전화가 들어왔어요. 앞으로 직접 맡을 전화예요」 |
| 모국어로 말하는 차례가 없고 한국어로 전하기만 함 | 고객님께 모국어로 여쭙고 전하는 걸음 둘(`ask-native`, `tell-native`, relay out) |
| 16:00, 간편결제, 해지 금액이 숫자로 와닿지 않음 | 힌트에 「오후 네 시」와 간편결제 풀이, 결제팀 답장에 이 고객님 숫자(60달러, 석 달, 27달러 빼고 33달러) |
| 마감 보고의 key 문장이 무엇을 말하는지 흐림 | 「오후 그 전화가 아직 마음에 남아 있습니다」, 맺음 문장도 같게 |
| 몽골어 이름 표기 Жиһүн, 베트남어 「Không phải cô」 | 현지어 교정에 넘김 |
| 조건 칸에 외국인 상담사 숫자가 없음 | 임금과 감정노동 칸에 「외국인 상담사만 따로 낸 자료는 찾지 못했어요」 |

**현직 상담사(파트장)의 눈.** 물음: 이 하루가 실제 현장과 다른 곳은 어디인가. 총평은 「다섯 원칙과 갈림길은 현장과 맞고, 본인 확인 순서, 폭언 뒤 끝내는 방식, 이력을 쓰는 때, 고객의 언어가 다르다」였다.

| 걸린 곳 | 고친 것 |
|---|---|
| 계정이 먼저 떠 있고 확인은 생일과 끝 번호뿐 | 계정을 찾은 방법 줄(가입 이메일), 본인 확인을 성함·생년월일과 가입 휴대폰 인증번호로. 휴대폰을 잃어버린 고객은 문자 인증을 못 하니 생년월일과 끝 번호로 잠그고, 풀 때는 새 휴대폰에서 본인 인증 |
| 「팀장님께 연결해 드리겠습니다」가 고객 요구를 들어주는 꼴 | 자제 요청 → 종료 예고 → 종료 안내 순서로 바꾸고 상담사가 끝낸 뒤 팀장에게 알림. 「멈춘다」를 「끝낸다(종료)」로. 참는 길에서도 팀장이 듣다가 넘겨받음 |
| 외국인 상담사는 자기 언어 고객을 주로 받음 | 모국어 대기열로 바꾸고, 한국어 고객이 많은 것은 연습을 위한 설정이라고 `reviewNote`에 적음 |
