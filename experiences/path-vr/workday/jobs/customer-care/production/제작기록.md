## 2. 설정을 바꾼 까닭

조사에서 E-7-2 고객상담 사무원은 「국제용역, 해외영업에 한하여」 해외에 있는 외국인 고객을 상대하는 일로 정해져 있음을 확인했다(법무부 체류민원 자격별 안내 매뉴얼 2026-11-16판). 텔레마케터는 빠지고, 회사는 상시근로자 500명 이상·국제용역 매출 50억 원 이상·직접 고용이다. 그래서 첫 초안의 「국내 통신사 고객센터」를 「해외 이용자를 둔 한국 구독 앱(드라마·웹툰) 회사의 해외 고객 상담팀」으로 바꿨다. 회사와 앱 이름(윤슬플러스), 요금, 규정은 지어낸 예시라고 장면표 `reviewNote`와 결제팀 답장에 적었다.

## 3. 상향판 여섯 가지 대조

| 기준 | 이 편 |
|---|---|
| 1. 도구를 직접 다룬다(셋 이상, 장면 셋 이상) | work 9개가 장면 넷에 있다. 상담 화면(가족 등록 확인, 가입자 본인 확인, 결제 내역, 잠글 계정), 이관 양식, 채팅 창, 상담 이력 메모와 다음 조치(욕설 통화의 세 갈래). 동료와 고객이 사실대로 반응하고 정답 표시는 없다 |
| 2. 모국어가 일의 힘이 되는 장면 | 모국어 대기열 전화에 relay 다섯. 고객의 말을 팀장에게 한국어로 전하는 셋(분실 사정, 본인 확인 정보, 새 휴대폰 질문)과 팀장의 말을 고객에게 모국어로 전하는 둘(본인 확인 여쭙기, 잠금 푸는 법). 끝 번호는 고객에게 되읽어 확인한다. 팀장 「고객님이 모국어로 말하니까 훨씬 편해하셨어요」 |

## 4. 검토와 낯선 눈

### 설계 검토(Fable, 11-22)

30건(P1 10, P2 16, P3 4). 원문은 이 세션 기록에 있다. 처리:

| 번호 | 지적 | 처리 |
|---|---|---|
| D1 | 보고의 key가 팀장이 이미 아는 일 | 반영. key를 「그 전화 뒤로 다음 전화를 받을 때 긴장이 됐습니다」로, 팀장 답 둘과 맺음 문장을 바꿈 |
| D2 | 짐작 길에 결제팀 답장이 묻지도 않았는데 옴, 답할 걸음 없음 | 반영. 항의 → 선배 「같이 물어봐요」 → 답장 → 사과하고 바로잡는 말하기. 확인 길에도 답을 전하는 말하기 |
| D3 | 기술지원팀 회신 시각이 갈래마다 다르고 재문의에 답할 걸음 없음 | 반영. 회신 13:40으로 같게, 재문의 13:10, 안내하는 말하기 추가 |
| D4 | 성별·발신 번호로 본인 확인을 추리 | 반영. 「가족(대리인) 등록」 칸을 찾는 물음으로 바꾸고 성별 칸 삭제 |
| D5 | 본인 확인을 묻는 말이 없음 | 반영. 「본인 확인을 위해 생년월일과 가입하신 휴대폰 끝 번호를…」 말하기와 고객 답 |
| D6 | 금액을 알려 줄 때 선배가 그냥 넘김, 오후가 벌처럼 읽힘 | 반영. 선배가 그 자리에서 말하고 「이따 팀장님께 같이」, 오후에는 학생이 사과하고 팀장이 같이 받음 |
| D7 | 전화 고객의 목소리가 없음 | 남김. 엔진에 소리 칸(`audio`)을 개발 세션에 청했고, 목소리는 Flow가 다시 열린 뒤 만든다 |
| D8 | 채팅 줄이 말하는 인물로 보임 | 개발 세션에 `channel: "chat"` 청함 |
| D9 | 장면 분이 짧음 | 반영. 4·5·6·7·8분, 합 30분, 직업 32분 |
| D10 | 칸막이 너머 팀장 표정이 굳음 | 반영. 렌즈를 보는 걱정하는 얼굴로 다시 구움 |
| D11 | 오후가 한 틀 | 반영. 마감용 두 사람 컷(저녁 빛)을 새로 구워 마감 대사를 옮김 |
| D12 | 휴게실 선배가 상담석과 같은 크기·방향, 웃는 얼굴 | 반영. 더 가깝게, 반대 방향, 미소 없이 다시 구움 |
| D13 | 휴게실에 안내문이 없음 | 반영. 글자 없는 A4 안내문을 넣어 다시 굽고 점을 옮김 |
| D14 | 회사 이름, 끝인사, 보류 뒤 인사 없음 | 반영. 「윤슬플러스 고객센터 상담사 (이름)입니다」, 끝인사 말하기 |
| D15 | 현장 말 대신 풀어 쓴 말 | 반영. 이관(넘김), 대기 콜, 스크립트(상담 매뉴얼), 후처리(상담 이력 정리), 상태 버튼 점 추가 |
| D16 | 「네 시 전」의 근거가 화면에 없음 | 반영. 이관 뒤 화면 문구 「회신: 한국 시간 오늘 16:00 전」을 물음에 넣음 |
| D17 | 가족 갈림길이 한쪽으로 쏠림 | 반영. 「오늘까지라 금액만」 압박, ask 길의 기다림, 선배 「잘 물었어요」 삭제 |
| D18 | 학생이 말하기 전에 폭언, 깃발을 쓸 자리 없음 | 반영. 먼저 사과하는 말하기, 셋째 보기 「도움 요청 깃발」, 팀장 「더 일찍 못 와서 미안해요」 |
| D19 | 첫 모국어 말이 길고 되전하기 없음 | 반영. 둘로 나눔(사정 / 본인 확인 정보). 되전하기는 팀장 대사 「…라고 전해 줘요」로 둠 |
| D20 | 설정이 비자 길과 다를 수 있음 | 반영. 2절의 설정 변경 |
| D21 | 「오전에는 옆에서」와 「다음부터 혼자」가 어긋남 | 반영. 「다음 전화도 제가 옆에 있을게요. 이번에는 먼저 해 봐요」 |
| D22 | 하루의 결제 문의가 한 번도 풀리지 않음 | 반영. 결제 내역 화면에서 늘어난 까닭(웹툰 코인) 찾기 |
| D23 | 힌트가 화면 낱말을 풀지 않음, 숫자 | 반영. 도구 힌트에 낱말 풀이, 금액은 「29달러(이십구 달러)」 |
| D24 | 상담 이력을 팀장 자리에서 쓰고 한 일이 없음 | 반영. 상담석으로 옮기고 욕설 통화 갈래마다 「한 일」 칸 |
| D25 | 조건 칸이 빔 | 반영. 해외 고객, 감정노동, 실적과 모니터링, 임금, 비자 다섯 칸과 출처 |
| D26 | 원칙 record에 짝 갈림길이 없음 | 참고. 상담 이력 메모 도구가 그 원칙을 다룬다. 보고의 「이렇게 말해요」는 D1에 맞춰 고침 |
| D27 | 엔진 꼴 확인 | work id는 맺음 갈림길에 들지 않음을 개발 검증기로 확인. relay 전화 표시는 개발 세션에 청함 |
| D28 | 사실 보기가 늘 첫 칸 | 반영. 순서를 섞음 |
| D29 | 교육실 alt가 사진과 다름 | 반영 |
| D30 | 점검 중 다른 결제 수단, 규정은 지어낸 것 | 반영. 「간편결제는 됨」, 결제팀 답장에 「이 회사의 예시예요」 |

### 낯선 눈 둘(11-22)

두 눈 모두 장면표만 읽었다. 첫 시안을 고친 뒤 다시 보이지는 않았다.

**한국어 2~3급 유학생의 눈.** 물음: 처음 읽는 사람이 무슨 일인지, 왜 그렇게 해야 하는지 알아듣는가.

| 걸린 곳 | 고친 것 |
|---|---|
| 해외 고객 팀인데 고객이 한국어로 말하는 까닭을 모름 | 조회 대사 「우리 팀 고객은 해외에 사는 이용자예요. 한국어로 묻는 분도 많아요」, 공지 첫 줄 「우리 팀 고객」 |
| 「마침 같은 나라 분」이 우연처럼 읽힘 | 팀장 「모국어 대기열로 전화가 들어왔어요. 앞으로 직접 맡을 전화예요」 |
| 모국어로 말하는 차례가 없고 한국어로 전하기만 함 | 고객님께 모국어로 여쭙고 전하는 걸음 둘(`ask-native`, `tell-native`, relay out) |
| 16:00, 간편결제, 해지 금액이 숫자로 와닿지 않음 | 힌트에 「오후 네 시」와 간편결제 풀이, 결제팀 답장에 이 고객님 숫자(60달러, 석 달, 27달러 빼고 33달러) |
| 마감 보고의 key 문장이 무엇을 말하는지 흐림 | 「오후 그 전화가 아직 마음에 남아 있습니다」, 맺음 문장도 같게 |
| 몽골어 이름 표기 Жиһүн, 베트남어 「Không phải cô」 | 현지어 교정에 넘김 |
| 조건 칸에 외국인 상담사 숫자가 없음 | 임금과 감정노동 칸에 「외국인 상담사만 따로 낸 자료는 찾지 못했어요」 |

**현직 상담사(파트장)의 눈.** 물음: 이 하루가 실제 현장과 다른 곳은 어디인가. 총평은 「다섯 원칙과 갈림길은 현장과 맞고, 본인 확인 순서, 폭언 뒤 끝내는 방식, 이력을 쓰는 때, 고객의 언어가 다르다」였다.

| 걸린 곳 | 고친 것 |
|---|---|
| 계정이 먼저 떠 있고 확인은 생일과 끝 번호뿐 | 계정을 찾은 방법 줄(가입 이메일), 본인 확인을 성함·생년월일과 가입 휴대폰 인증번호로. 휴대폰을 잃어버린 고객은 문자 인증을 못 하니 생년월일과 끝 번호로 잠그고, 풀 때는 새 휴대폰에서 본인 인증 |
| 「팀장님께 연결해 드리겠습니다」가 고객 요구를 들어주는 꼴 | 자제 요청 → 종료 예고 → 종료 안내 순서로 바꾸고 상담사가 끝낸 뒤 팀장에게 알림. 「멈춘다」를 「끝낸다(종료)」로. 참는 길에서도 팀장이 듣다가 넘겨받음 |
| 외국인 상담사는 자기 언어 고객을 주로 받음 | 모국어 대기열로 바꾸고, 한국어 고객이 많은 것은 연습을 위한 설정이라고 `reviewNote`에 적음 |
| 개인정보를 잘못 알린 일을 「이따」 보고 | 「통화 끝나면 바로 팀장님께 같이 보고해요」 |
| 3시 12분 통화 이력을 5시에 씀 | 쉬고 돌아와 다음 전화 전에 쓰게 옮기고 「다음 조치」 칸을 더함. 공지 17:00은 「미결 건 확인」 |
