## 현재 화면

### WORLD 옷장 연결 v3 — 2026-10-09

기존 [WORLD 웹 옷장](../synk-account/src/wardrobe-view.mjs)에 선택형 **3D 시험 보기**를 연결했다. `node experiences/learning-hub/server.mjs`로 실행해 `/synk-account/preview.html?account=world#world-wardrobe`에서 확인한다. 이번 검증 서버는 4294번이다. 합성 미리보기의 저장은 페이지 안에서만 유지되며 새로고침하면 초기화된다.

- 기존 `kkamong-basic / kkamong-scarf / kkamong-apron` ID와 배경·소유권·저장 계약을 그대로 쓴다. 저장한 차림을 다시 입으면 같은 의상과 배경을 3D에 반영한다. 다른 캐릭터·헤드폰·델은 원본 그림으로 표시하고 미지원임을 알린다.
- 정면·옆·뒤, 앞발 인사, 균형/경험, 현재 장면의 3D PNG 다운로드를 제공한다. 미획득 의상은 보기만 가능하며 착용·저장·촬영은 기존 보유권을 따른다.
- 3D 사진은 현재 canvas 해상도의 별도 PNG이다. 촬영 이미지·저장 링크를 보여 주며 기존 ID 기반 원본 그림 앨범과 구분한다. 회전·포즈·품질은 저장된 차림 데이터에 추가하지 않는다.
- Three는 버튼을 누를 때 별도 ESM 번들로 불러온다. 옷장 재표시 시 canvas 하나를 유지하고, 원본/미지원 전환·계정 종료 시 해제한다. 화면 밖·숨긴 탭에서는 렌더를 멈춘다.
- [까몽 시제품 v1 계약](three/character-contract.mjs)에 몸·기본 포즈·부착점·의상 호환을 모았다. renderer가 실제 사용하지만 **최종 마스터 몸·전문 스키닝·GLB 규격 확정은 아니다.**

검증: `qa/wardrobe-v3/validation.json`, 다운로드한 PNG·320/390px 화면. adapter 회귀 13개와 서버 6개, 기존 측정 8개·렌더러 수명 5개 통과. 실제 계정·실기기·네이티브 3D·새 홈/타운 통합·공개 배포는 미확인이다. 원본 대조에서 몸 하단 폭, 짧고 넓은 귀, 눈높이·홍채가 우선 보정 대상으로 확인됐다.

### 독립 재질 시험실 v2

- 3D가 주 화면이다. 이전 Live2D 조사는 아래 링크의 **비교 기록**으로 보존했다.
- 몸은 펠트, 목도리는 니트, 앞치마는 면으로 구분한다. 재질별 표면 결·법선·거칠기와 빛 반응을 나눈다. 작은 표면 정보에 2D 텍스처를 쓰며 몸과 옷은 실제 메시다.
- 앞치마는 앞뒷면·옆 마감이 있는 두께와 큰 주름, 입체 주머니·봉제선을 가진다. 몸털이 옷을 뚫는 범위는 착용 중 가리고 벗으면 복구한다.
- 바닥의 나무 받침은 천과 다른 재료의 예다. 양쪽 품질 모드에서 기본 그림자를 유지한다.
- `전체 보기 / 옷 가까이`는 시점, `균형 / 경험`은 품질이다. 서로 독립적으로 조작하며 옷과 동작은 유지한다.
- 기본·목도리·앞치마, 정면·옆·뒤·연속 회전, 호흡·깜빡임·앞발 인사와 실행 기록 다운로드를 제공한다.

구현: [renderer.mjs](three/renderer.mjs), [materials.mjs](three/materials.mjs). 재질팩에 포함한 가죽·도자기는 후속 제작용이며 현재 화면에 사용한 재료라고 보고하지 않는다.

## 확인 범위와 남은 일

`qa/material-v2-validation.json`과 `qa/material-v2-*.jpg/json`은 이 버전의 실제 화면·실행 기록이다. 기존 `qa/validation.json`과 `three-*.jpg/json`은 이전 구조 시험 기록으로 보존한다.

- 측정값은 브라우저 requestAnimationFrame 콜백 간격이다. GPU 실행 시간·전력·발열·화면에 표시된 모든 프레임을 측정하지 않는다.
- 320/390px 화면 확인은 실물 휴대폰 성능을 뜻하지 않는다. 현행 품질 검증 대상은 **Galaxy S25·iPhone 15 기본형**이며 지속 성능·발열·조작 검증은 남아 있다.
- 까몽은 승인 4K PNG를 참고한 절차적 형상이다. 시제품 부착점은 v3 계약으로 추출했지만 승인 외형을 정확히 재현한 최종 모델·전문 스키닝·모든 캐릭터의 공통 규격은 미완성이다. 몽글의 ‘팔 없는 실루엣’ 조건을 까몽 앞발에 혼동해서 적용하지 않는다.
- 새 의상마다 모델링·몸 맞춤·표면·조합별 관통 검수가 필요하다. 이번 앞치마 가림 처리는 범용 천 시뮬레이션이 아니다.
- 웹 옷장의 3D 시험 연결은 v3에서 추가했다. 네이티브 홈·게임·타운의 같은 아이템·착용 상태 연결은 별도 이관해야 한다.

## 이전 Live2D 비교

[공개 모델 실제 시험과 출처](live2d/README.md). Kumakumasu의 커스텀 픽시에서 귀·모자·목 장식·옷 색 변경 및 재생 유지를 확인했다. 까몽 Live2D 원본은 없으며 사용자가 별도 원본 부재를 확인했다. 이 기록을 까몽 Live2D 제작 완료나 같은 캐릭터 성능 비교로 읽지 않는다. 이 시험실의 후속 구현은 위 3D 시제품으로 이어졌다.

## 회귀 확인

```powershell
node experiences/mascot-render-lab/qa/measurement-check.mjs
node experiences/mascot-render-lab/qa/renderer-lifecycle-check.mjs
```

첫 검사는 실제 lab 모듈을 합성 DOM·엔진·시계에서 실행해 탭 숨김, context loss, 일시정지, 표본 부족, 취소된 콜백과 뒤로가기 캐시 수명을 검증한다(8개). 둘째 검사는 실제 Three 객체와 재질·렌더러·천 형상 코드를 쓰고 WebGL/DOM을 대체해 재질 맵, 독립된 상태, resize/DPR, 복구, 자원 해제를 검증한다(5개). 봉제선 InstancedMesh의 GPU 자원 해제 누락을 이 검사로 찾아 수정했다. 실제 GPU 손실·실기기 검증은 아니다.

원본 자산·기존 보상/계정 데이터 계약은 보존했다. 설치, 유료 생성, 모델 구매, 공개 배포는 수행하지 않았다.
