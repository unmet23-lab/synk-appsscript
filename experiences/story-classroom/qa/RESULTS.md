## 확인 결과

- Node 의미/진행 검사 **14/14 통과**. 대상·장소·순서, 실제 오답 이동, 되돌린 뒤 최초 응답 보존, 힌트 사용, 새 글의 변경, 모든 대사/행동 단계 저장 복원을 확인했다.
- 실제 Chrome UI 검사 **통과**. 디버그 자동 풀이 함수 없이 대사 버튼과 캐릭터·물건·장소 버튼을 눌러 이야기 부탁 6개와 새 글 3개를 완료했다.
- 종이를 쓰레기통에 버리는 오답, 되돌림과 수정, 마지막 정답의 되돌림, 편지를 꽃보다 먼저 붙이는 순서 오답, 힌트, 도중 새로고침/이어 하기, 완료 상태 이어 하기, 아까의 답을 새 글에 적용한 오답을 확인했다.
- 390px의 터치 버튼과 실제 포인터 드래그로 종이를 서랍에 옮겼다. 소리를 끈 상태에서 9개 부탁을 완료했다. `prefers-reduced-motion` 설정을 적용했다.
- 1024px에서 Tab/Enter/Space/Esc로 캐릭터·물건·장소와 수첩을 조작했다. 손상된 초기 저장은 무시하고 새 게임으로 시작했다. 780·320px에서도 재시작 취소와 첫 부탁 수행을 확인했다.
- 1440·1024·780·390·320px에서 가로 넘침 **0**, 깨진 이미지 **0**, JavaScript/콘솔 오류 **0**, 자산 실패 **0**. 실제 로컬 폰트 로드를 확인했다.
- 별도 디자인 검사에서 1440·390·320px의 첫 화면·시작 대사·부탁·선택·끝화면을 실제 캡처하고 9개 부탁을 UI 키보드로 완료했다. 모바일 부탁 본문은 **18px/1열**이며 장면 바로 아래에 배치한다.
- 배경·투명 교사·소품·마스코트가 합성된 실제 화면을 확인했다. 생성 원본, 알파, 승인 자산 원천/해시를 보존했다.
- 실제 Chrome 54초 스테레오 음향 렌더에서 BGM peak −28.99dBFS, 대표 효과음 혼합 peak −10.25dBFS, 클리핑 **0샘플**. 대사 넘김은 무음이다. 음향 수치 확인이며 직접 청취나 스피커 재생 확인은 아니다.

전체 UI 결과: [browser-results.json](browser-results.json). 음향 측정: [audio-levels.json](audio-levels.json). `verify-browser.mjs`로 UI 검사를 재현한다.

마지막 시각 마감 뒤 1440·320px에서 선택 취소와 종이 이동을 다시 눌러 확인했다. 물건을 드는 중의 앞 레이어와 배치, 넘침/오류 0을 [final-smoke.json](final-smoke.json)에 실제 코드 해시와 함께 기록했다. 독립 ZIP의 모든 파일은 [package-results.json](package-results.json)에서 현재 소스와 해시를 대조한다.
