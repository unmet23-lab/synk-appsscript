# 펠트 UI 마감 확인 · 2026-10-02

`node qa/felt-verify-ui.mjs`를 실제 Google Chrome에서 실행했다. 1440×1000, 390×844, 320×800 세 화면에서 시작 → 이야기 → 부탁 → 완료 배지 → 엔딩 → 읽은 표현 수첩을 실제 버튼으로 진행했다. 결과는 세 화면 모두 통과이며 캡처 21장은 `felt-<폭>-<상태>.png`에 있다.

- 가로 넘침 0px, 보이는 글자 11px 미만 0개, 본문 읽기 18px.
- 깨진 이미지·폰트·페이지 오류·HTTP 오류·화면에 표시된 내부 오류 0개.
- 실제 펠트 완료 체크 표시, ‘이 부탁 듣기’ 112×44px 보조 단추, 글로만 연습 시 음성 단추 비활성 확인.
- 승인 펠트 부품 10개를 원본 그대로 복사했다. 원천·크기·SHA-256은 `../assets/ui/provenance.json`에 있다.
- 교실·승인 캐릭터·기존 미니어처 소품은 보존했다. 종이 읽기 면, 수첩, 엔딩 세 읽기 영역은 평평하고 충분한 줄 간격을 유지했다.
- 납작한 테이프와 점 컨페티를 제거하고, 축하 리본은 기존 실제 소품 이미지로 마감했다.

검증 당시 소스 해시와 개별 화면 수치는 `felt-verification.json`에 기록했다. 이 확인은 직접 청취한 음성 품질, 인증한 WORLD 계정의 원격 동기화, 학생 학습 효과, 실물 기기 성능을 증명하지 않는다. 해당 기능 검증은 담당 결과를 따로 확인한다.
