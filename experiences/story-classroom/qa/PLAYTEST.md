# 선생님이 돌아왔다 · 사람과 기기 확인표

2026-10-02 이야기 v2 / 음성 90문장. 아직 실제 참가자의 결과를 적은 문서가 아니다.

## 초급 학습자 플레이

교사가 답을 알려 주지 않은 상태에서 이야기를 시작한다. 첫 판은 음성 포함, 새 판은 ‘글로만 연습’을 선택한다. 진행 기록에서 각 판을 구별한다. 이름·학생번호·녹음은 수집하지 않는다.

| 확인 | 관찰할 것 | 아직 결과 |
|---|---|---|
| 처음 조작 | 설명을 읽고 친구→물건→장소를 스스로 찾는가 | 미확인 |
| 부탁의 의미 | 친구·물건·장소 중 어디에서 실수하는가 | 미확인 |
| 부정 | 종이를 버리지 말라는 문장을 행동으로 바꾸는가 | 미확인 |
| 순서 | 꽃→편지, 케이크→리본을 이해하는가 | 미확인 |
| 새 글 | 이전 답을 외워 누르거나 바뀐 친구/장소를 읽는가 | 미확인 |
| 실패 반응 | 웃거나 다시 시도하는가, 원인을 알 수 있는가 | 미확인 |
| 이야기 | 생일 파티의 비밀을 언제 알아차리는가 | 미확인 |
| 계속할 이유 | 다음 이야기도 하고 싶은지, 이유가 무엇인지 | 미확인 |

마친 뒤 “어느 장면이 재미있었나요?”, “무엇을 하라는지 어려웠던 문장은?”, “소리가 너무 빠르거나 어색한 곳은?”만 짧게 묻는다. 자동 정답 완주와 첫 판/둘째 판 차이를 실제 학습 향상으로 단정하지 않는다.

## 한국어 교원 검수

`story.mjs`의 9부탁과 설명, `STORY-REVIEW.md`, `assets/voice/manifest.json`을 함께 확인한다. 초급 어휘·조사·‘-지 말고/아니라/뒤/다음’의 이해 부담, 캐릭터 구어체, 그림과 문장의 일치, 이야기 흐름을 검수한다. 각 문장의 목표 수준은 공식 급수로 자동 대응하지 않는다. 수정하면 텍스트 판본을 올리고 해당 MP3와 manifest를 함께 재제작한다.

## 실물 휴대폰과 직접 청취

- iPhone Safari / Android Chrome: 첫 클릭 음성 시작, 다음 문장 취소, 음소거, 다시 듣기, 백그라운드 복귀, 이어 하기.
- 작은 화면·가로 화면에서 부탁을 읽는 동안 캐릭터·물건·목표를 조작하고 가림/드래그/스크롤/장시간 발열을 확인한다.
- 스피커와 이어폰으로 실제 음성 90개를 듣고 발음·끊어 읽기·캐릭터 차이·BGM/효과음 균형을 확인한다. 수치·디코딩 성공은 이 검사를 대신하지 않는다.

## 실제 WORLD 연결

현재 `synk-account/config.json`과 실제 OAuth/학습 API 구성은 이 게임 작업에서 확인하지 못했다. 준비된 환경에서는 본인 로그인·학습기록 동의 후 WORLD 목록에서 게임을 연다. 수행→다른 기기 기록 조회→오프라인/재연결→계정 전환/로그아웃→동의 철회를 확인한다. 비회원 진행을 계정에 가져오지 않는지 함께 본다. synthetic 테스트를 실계정 결과로 보고하지 않는다.
