# 선생님이 돌아왔다 · SYNK LAB PLAY

이야기를 읽고 마린·까몽을 움직여 교실을 정리하는 한국어 읽기 미니게임. 선생님이 나타난 소동이 생일 파티로 이어진다. 2026-10-02 로컬 제작판.

공통 코인(`play-common`, 2026-10-04): 이야기를 끝까지 마치면 완주 15 + 도움 없이 첫 시도에 옮긴 부탁의 비율 × 10을 한 번 받는다. 한 판의 번호를 저장에 남겨 다시 열거나 결말을 다시 그려도 두 번 받지 않는다. 시작 화면에 잔액, 결말에 받은 코인과 차고 링크가 있다([공통 컬렉션](../play-common/README.md)).

## 실행

현재 미리보기: <http://127.0.0.1:5213/>. 다른 게임과 공통 기록을 쓰는 입구: <http://127.0.0.1:4280/story-classroom/>. WORLD 계정에서는 WORLD의 게임 목록에서 연다. 교사 목표로 열면 목표 부탁이 있는 장면에서 시작하고(그 장면의 앞 부탁은 순서 조건이라 함께 한다), 목표 부탁이 없는 장면과 마지막 복습은 건너뛰어 목표만 하고 끝난다(2026-10-03, 전에는 첫 목표 장면 뒤의 모든 장면과 복습을 지나야 끝났다). 복습에 목표 부탁이 있으면 복습까지 간다.

저장소 루트에서 다음 명령으로 다시 실행한다. Node.js 20 이상이 필요하다.

```powershell
node experiences/story-classroom/server.mjs
```

독립 패키지는 압축을 풀고 `Start-Game.cmd`를 실행한다. 브라우저가 먼저 열리면 서버가 준비된 뒤 새로고침한다. 서버를 실행하는 동안 콘솔을 열어 둔다. HTML 파일을 직접 여는 방식은 ES 모듈과 음향 파일 로딩 때문에 지원하지 않는다.

## 플레이

1. **이야기를 읽는다.** 시간 제한 없이 다음 대사를 넘긴다. 선생님과 세 마스코트가 각자 다른 반응을 한다.
2. **부탁을 행동으로 바꾼다.** 친구 → 물건 → 놓을 곳을 누른다. 친구를 고른 뒤 물건을 끌어 놓아도 된다.
3. **실수한 장면도 이어 간다.** 엉뚱한 친구가 옮기거나 종이를 버리면 실제 장면이 바뀐다. 피드백을 읽고 되돌리거나 다시 옮긴다.
4. **비밀을 완성한다.** 정리 → 편지 발견 → 생일 파티, 세 장면의 부탁 6개를 풀면 이야기가 끝난다.
5. **새 글을 읽는다.** 마지막에는 담당 친구와 놓을 곳이 달라진 부탁 3개를 푼다. 처음 답을 그대로 외우면 풀리지 않는다.

선택 취소·되돌리기·작은 힌트·이야기 수첩·음소거·이어 하기를 제공한다. 기본은 대사·부탁을 한국어 음성으로 재생하며, 각 텍스트를 다시 들을 수 있다. **글로만 연습**은 자동·수동 음성을 모두 끈다. 소리를 꺼도 지시와 사건은 모두 글로 이해할 수 있다.

자동 읽기의 처음 값은 맞춤 학습 입구에서 고른 도움 방식을 따른다(단계별·그때그때·안 고름 = 자동, 혼자 = 누를 때만). 2026-10-03부터 WORLD의 읽기 과제는 읽기 확인이라, 단계별을 고르지 않았다면 부탁을 누를 때만 읽어 준다. 전에는 과제가 자동 읽기로 열려 첫 응답이 모두 '도움 받음'이 되고 교사 결과의 혼자 해낸 응답이 늘 0이었다. 게임 안의 단추가 언제나 이긴다. 입구는 단계별 도움을 고른 사람에게 이 게임을 글로만(`?reading=1`)으로 열지 않는다.

브라우저 진행과 Atlas 연습 기록을 저장한다. 4280의 공통 입구에서는 다른 게임과 같은 기기 기록을 쓴다. 5213 독립 미리보기는 다른 origin이므로 기록이 별도다. WORLD 안에서는 기존 계정·동의·동기화 호스트를 통해 기록하며 비회원 기록을 계정에 자동으로 합치지 않는다. 실제 OAuth/학습 API 설정과 로그인·동의가 준비돼야 서버에 연결된다. 이 저장소의 `synk-account/config.json`은 현재 없으므로 실계정 연결을 완료했다고 보고하지 않는다. 공유를 끈 계정의 이야기 진행은 이번 창에서만 이어간다.

키보드: Tab으로 버튼 이동, Enter/Space로 선택. Esc는 수첩 닫기 또는 물건 선택 취소. 마우스와 터치는 같은 버튼을 사용하며 물건 드래그를 추가 지원한다. 좁은 화면은 장면 다음에 큰 글씨의 부탁을 배치한다. 동작 줄이기 설정을 반영한다.

## 홍보 설명과 TOPIK 학습 연결

**홍보 문구:** 선생님이 돌아왔다! 마린은 무엇을 치우고, 까몽은 어디에 놓아야 할까요? 부탁을 읽고 친구를 움직이면 엉망이던 교실의 비밀이 드러나요. TOPIK I 준비를 위한 대상·위치, 부정 표현, 행동 순서 읽기를 연습합니다.

공통 목표는 [TOPIK I 1~2급 합격 준비](../../docs/미니게임_TOPIK_I_학습기준.md)다. 자체 창작한 초급 생활 문장과 짧은 이야기이며 공식 기출 문제나 검수된 급수별 문항은 아니다.

| 구현된 행동 | 입력에서 이해할 것 | 읽기 연습 범위 |
|---|---|---|
| 마린/까몽·물건·장소 선택 | 누가 무엇을 어디로 옮기는지 | 문장의 대상·위치·요청 이해 |
| 종이를 쓰레기통 대신 서랍에 보관 | “버리지 말고” | 부정 표현과 지시 이해 |
| 꽃→편지, 케이크→리본 | “놓은 뒤”, “놓은 다음” | 짧은 글의 행동 순서 이해 |
| 다른 친구/장소의 마지막 정리 | “이번에는”, “서랍이 아니라 상자” | 새 문장의 정보 변경 이해 |

모든 놓을 곳을 선택할 수 있어 문장 의미가 성공 조건이 된다. 등장인물·물건 이름은 초급 조작을 돕기 위해 표시한다. 결과에는 부탁 수행, 새 글 수행, 도움 없는 최초 응답 수를 따로 표시한다. 최초 정답은 글 힌트와 음성 도움을 모두 받지 않은 경우에만 독립 수행으로 센다. 실제 음성이 시작될 때 도움을 기록하며 실패한 다운로드는 도움으로 세지 않는다. 첫 응답 뒤의 도움은 최초 기록을 소급 변경하지 않는다. 힌트 이전/이후·오답 종류·수정·되돌림·같은 글 재시도도 보존한다. 이 기록은 이번 문항의 수행이며 TOPIK 점수나 급수 판정이 아니다.

Atlas는 `ko.reading.detail/negation/sequence`와 `action` 형식으로 기록한다. 읽기 기록을 사용해 지금 수행 가능한 부탁 중 먼저 연습할 부탁을 추천하며, 행동 순서의 선행 조건을 지킨다. 끝화면에는 세 영역의 연습 상태와 공통 학습 입구를 보여 준다. 독립 처음 응답·도움받은 응답·반복 글·변경된 새 글을 구분한다. 저장이나 계정 연결이 불확실할 때 독립 새 정답을 만들어 내지 않는다.

대상·위치·부정·순서를 반복해서 읽고 행동에 반영하는 연습 기회를 제공한다. 주제·이유·긴 글 이해, 전 범위 충족, 장기 기억, 실제 읽기 향상과 합격 효과는 검증하지 않았다. 교원 문형/난도 검수와 실제 학생 플레이가 다음 확인 대상이다.

## 시각·소리

원근과 빛이 있는 미니어처 배경에 투명 소품과 승인 캐릭터를 배치한 2D 장면이다. 마린·까몽의 전신/표정, 몽글, LAB 로고, 서체, 실땀은 기존 승인 자산을 사용한다. 마스코트 원본을 새로 그리지 않았다.

교실·가상의 선생님 NPC와 펠트/나무/종이 소품은 이 게임을 위해 생성했다. 선생님은 시제품의 이야기용 인물이며 회사 캐릭터 정본에 추가한 인물이 아니다. 생성 원본을 보존하고 WebP로 제공한다.

- [승인 자산 출처·해시](assets/provenance.json)
- [교실·선생님 생성 프롬프트와 출처](assets/art-provenance.json)
- [소품 atlas 생성·추출·해시](assets/props-provenance.json)
- [실제 펠트 UI 원천·해시](assets/ui/provenance.json)
- 마감(2026-10-05): 주 단추의 옛 규칙(색 그러데이션과 결 그림으로 펠트를 흉내 내던 `.button-primary` 바탕·그림자)은 사진 펠트 판이 모든 속성을 덮어 쓰이지 않던 것이라 지웠다(화면은 그대로). 휴대폰에서 줄바꿈이 숨겨져 「친구와교실의」로 붙던 첫 화면 문장에 띄어쓰기를 넣었고, 휴대폰 첫 장면에서 리본에 가려지던 「쓰레기통」 이름표는 통 윗부분에 걸쳐 둔다(좁은 휴대폰에서 문가의 선생님 발을 가리지 않게).

비언어 효과음과 72BPM의 작은 오리지널 배경곡을 사용한다. 음성 중에는 배경곡을 낮추며 한 번에 한 문장만 재생한다. 다음 대사·다른 글·음소거·글로만 연습·탭 숨김은 이전 음성을 중단한다. 음성 실패는 한국어 안내와 다시 듣기로 처리하고 글 플레이는 계속할 수 있다.

### 스토리 확정 뒤 반영할 음성 · 2026-10-02 사용자 요청

처음에는 구현을 보류하라는 요청으로 저장했다. 이후 사용자의 **“전부 진행해줘”** 승인에 따라 자체검토한 이야기 v2를 기준본으로 고정하고 음성을 연결했다. 사용자 최종 품평이나 교원 검수를 대신 확정한 것은 아니다. [대사·문형 자체검토](STORY-REVIEW.md).

대사·내레이션·부탁·설명·성공과 실수 반응 **90문장 / 약 9분 3초**를 한국어 neural 합성 음성으로 제작했다. 실제 한국인 성우 녹음은 아니다. 선생님/이야기는 SunHi, 마린은 InJoon, 까몽은 Hyunsu, 몽글은 SunHi의 밝은 톤을 사용한다. 처음 실행 이후 서비스에 텍스트를 보내거나 브라우저 기본 TTS에 맡기지 않고 포함한 MP3를 재생한다. 문장·화자·판본과 파일 SHA-256을 검증한다.

- [문장별 파일·목소리·음량·길이·해시](assets/voice/manifest.json)
- 저장소 루트에서 재제작: `node experiences/story-classroom/scripts/export-voice.mjs` → `python experiences/story-classroom/scripts/generate-voice.py` (설치된 edge_tts·ffmpeg 필요)
- 음성 파일 최대 peak −2.86dBFS, 24kHz mono/96kbps. 실제 Chrome에서 90개 모두 해시/디코딩 검사, 대표 대사·부탁의 원래 속도 재생 완료를 확인했다. 직접 청취와 초급자 발음/속도 품평은 별도다.

## 구현과 확인

`story.mjs`는 대사·부탁·설명, `core.mjs`는 의미 판정과 되돌림/저장, `stage.mjs`는 장면·이동·드래그, `app.mjs`는 사용자 흐름이다. `voice-lines.mjs`·`voice.mjs`는 텍스트와 음성, `learning.mjs`·생성된 `atlas-learning.js`는 공통 연습 기록, `audio.mjs`는 비언어 소리, `index.html`/`style.css`는 화면을 맡는다. 런타임은 외부 패키지/CDN 없이 로컬 파일로 실행한다. 구버전 이야기 진행은 새 대사/기록 schema와 섞지 않고 새 판으로 시작한다.

```powershell
node --test experiences/story-classroom/core.test.mjs experiences/story-classroom/voice.test.mjs experiences/story-classroom/learning.test.mjs
node experiences/story-classroom/qa/verify-browser.mjs
node experiences/story-classroom/qa/verify-voice-browser.mjs
```

브라우저 검사는 이 PC의 번들 Playwright와 설치된 Chrome을 사용한다. 테스트는 디버그 자동 정답 함수 없이 실제 대사·캐릭터·물건·장소 버튼으로 진행하며, 읽기 전용 개발 상태로 결과를 확인한다. [검증 기록](qa/RESULTS.md)과 [브라우저 결과 원본](qa/browser-results.json)에 실제 확인 범위를 둔다. [학생·교원·실기기 확인표](qa/PLAYTEST.md)를 준비했다. 공개 배포와 실물 휴대폰 플레이, 실제 학생 재미/학습 효과는 별도다.
