# 선생님이 돌아왔다 · SYNK LAB PLAY

이야기를 읽고 마린·까몽을 움직여 교실을 정리하는 한국어 읽기 미니게임. 선생님이 나타난 소동이 생일 파티로 이어진다. 2026-10-02 로컬 제작판, 2026-10-06 SYNK LAB PLAY 키트로 화면을 다시 만들었다(아래 「화면」).

공통 코인(`play-common`, 2026-10-04): 이야기를 끝까지 마치면 완주 15 + 도움 없이 첫 시도에 옮긴 부탁의 비율 × 10을 한 번 받는다. 한 판의 번호를 저장에 남겨 다시 열거나 결과를 다시 그려도 두 번 받지 않는다. 입구에 잔액, 결과 화면에 받은 코인과 차고 링크가 있다([공통 컬렉션](../play-common/README.md)).

## 화면 · 2026-10-06 다시 만듦

유호님이 옛 화면(흰 편집 지면, 휴대폰에서 네 화면 높이 — 교실 그림 위 작은 이름표 14개 → 부탁 카드 → 선생님 대사와 큰 단추 셋 → 도구 다섯 → WORLD 판, 부탁을 읽다가 그림을 누르려면 위아래로 오가야 했다)을 마음에 들어 하지 않아 [SYNK LAB PLAY 키트](kit/README.md)로 말 랠리와 같은 한 벌로 다시 만들었다. 공통 뼈대(입구·게임 바·멈춤·결과·코인 줄·펠트 부품·글꼴)는 `kit/`(사본, 직접 고치지 않음), 이 게임만의 것(입구의 교실 그림, 교실 무대, 이야기·부탁 종이 판, 수첩, 결과의 부탁 목록)은 `style.css`에 있다.

- **입구**: 코랄 펠트 머리 면(제목·종이 액자 속 펠트 교실과 마린·까몽) → 오늘의 이야기(이야기 시작·이어 하기, 대사 음성 자동·글로만 연습, 공통 코인 줄) · 하는 방법 셋 → TOPIK 안내와 WORLD 계정 줄.
- **게임은 한 화면**(스크롤 없음): 게임 바(장면·부탁 알약, 멈춤) 아래 위는 교실, 아래(넓은 화면은 오른쪽 칸)는 종이 판. 이야기 중에는 판에 말하는 사람(펠트 원 속 얼굴·펠트 이름표)과 대사·다음, 부탁 중에는 부탁 탭(부탁 1·2·3) · 큰 부탁 한 문장 · 친구 → 물건 → 놓을 곳(고른 것의 그림으로 채워지는 펠트 원) · 다시 듣기·힌트·되돌리기. 넓은 화면은 그 장면의 앞 대사와 다른 부탁도 판에 보인다.
- **교실 무대**(`stage.mjs`): 교실 그림을 무대에 꽉 채우고 칠판·문은 그림 속 자리를 따라간다. 가구·소품·친구는 무대 크기로 계산한 세 줄 배치(휴대폰 세로 `tall`, 작은 화면 `compact`, 넓은 화면 `wide`)에 놓고, 모든 단추에 크림 쿠션 펠트 이름표(13px 이상)를 단다. 가구 위 물건은 이름표 실제 폭으로 나란히 놓아 이름표끼리 닿지 않는다. 고르면 크림 칼선 스티커와 분홍 이름표, 물건을 든 동안만 놓을 곳이 금빛으로 빛난다.
- **판의 문장은 고른 것과 맞춘다**(10-06 리드 검토): 친구·물건을 고르면 그 둘을 모두 쓰는 열린 부탁이 딱 하나일 때 그 탭으로 넘어간다(여럿이면 보던 탭 그대로). 맞는 부탁이 없으면 탭은 두고 고른 것 위에 「지금 고른 것」을 단다. 맞게 옮기면 친구 선택도 비워 다음 부탁을 친구부터 고른다.
- **틀리면** 교실이 실제로 바뀌고(엉뚱한 친구가 옮김, 종이를 버림) 판에 종이 쪽지가 나온다: 교실에서 일어난 일 한 문장 + 반응한 인물의 대사 + 고치는 법 한 줄. 빨간 X는 없다. 쪽지는 안쪽 스크롤 없이 판에 다 보이게 잰다(`fitNote`): 넘치면 짧은 판(반응 대사 → 고치는 법 한 줄, 일어난 일은 교실 그림이 보여 줌), 그래도 넘치면 글자를 조금 줄인다. 넓은 화면은 다른 부탁 목록을 먼저 접는다. 키 640px 이하 화면은 판을 244px로 둔다(320×568에서 두 줄 부탁 + 가장 긴 쪽지 실측). **맞으면** 그 부탁 탭에 펠트 체크 배지, 교실에 「부탁 완료!」, 판은 바로 다음 부탁을 보여 준다.
- **결과**: 첫 시도에 해낸 부탁 수·별·도움 없이 처음 해낸 부탁·힌트·음성 도움, 공통 코인, 부탁 목록(첫 시도는 펠트 체크 배지, 다시 해서 해낸 것은 몇 번째인지와 해설, 다시 듣기), 읽기 연습 기록(아틀라스), 한 번 더 놀기·처음으로. 결과 화면에서 다시 듣는 것은 복습이라 도움으로 세지 않는다.
- **멈춤 창**: 이어서 읽기, 소리·대사 음성 자동·글로만 연습, 이야기 수첩(읽은 대사와 듣기), 처음부터(확인 한 번), 처음으로.
- 움직임은 한 번 미끄러지기·나타나기뿐이다(친구가 물건 앞으로 가서 옮기고 제자리로, 선생님 등장, 펠트 반짝이, 파티 리본 줄). 걷기 흔들림·흔들기 효과는 없앴다. 움직임 줄이기 설정에서는 바로 자리를 바꾼다.
- 부탁 글은 탭 하나로 볼 수 있게 두고, 학습 기록(아틀라스 `present`)은 전처럼 그 장면의 부탁을 모두 보여 준 것으로 연다. 보이지 않던 부탁에 먼저 답하면 기록의 시도 번호가 어긋나 저장이 멈추기 때문이다.

## 실행

현재 미리보기: <http://127.0.0.1:5213/>. 다른 게임과 공통 기록을 쓰는 입구: <http://127.0.0.1:4280/story-classroom/>. WORLD 계정에서는 WORLD의 게임 목록에서 연다. 교사 목표로 열면 목표 부탁이 있는 장면에서 시작하고(그 장면의 앞 부탁은 순서 조건이라 함께 한다), 목표 부탁이 없는 장면과 마지막 복습은 건너뛰어 목표만 하고 끝난다(2026-10-03, 전에는 첫 목표 장면 뒤의 모든 장면과 복습을 지나야 끝났다). 복습에 목표 부탁이 있으면 복습까지 간다.

저장소 루트에서 다음 명령으로 다시 실행한다. Node.js 20 이상이 필요하다.

```powershell
node experiences/story-classroom/server.mjs
```

독립 패키지는 압축을 풀고 `Start-Game.cmd`를 실행한다. 브라우저가 먼저 열리면 서버가 준비된 뒤 새로고침한다. 서버를 실행하는 동안 콘솔을 열어 둔다. HTML 파일을 직접 여는 방식은 ES 모듈과 음향 파일 로딩 때문에 지원하지 않는다.

## 플레이

1. **이야기를 읽는다.** 시간 제한 없이 다음 대사를 넘긴다. 선생님과 세 마스코트가 각자 다른 반응을 한다.
2. **부탁을 행동으로 바꾼다.** 친구 → 물건 → 놓을 곳을 누른다. 친구를 고른 뒤 물건을 끌어 놓아도 된다.
3. **실수한 장면도 이어 간다.** 엉뚱한 친구가 옮기거나 종이를 버리면 실제 장면이 바뀐다. 피드백을 읽고 되돌리거나 다시 옮긴다.
4. **비밀을 완성한다.** 정리 → 편지 발견 → 생일 파티, 세 장면의 부탁 6개를 풀면 이야기가 끝난다.
5. **새 글을 읽는다.** 마지막에는 담당 친구와 놓을 곳이 달라진 부탁 3개를 푼다. 처음 답을 그대로 외우면 풀리지 않는다.

선택 취소(든 물건을 다시 누르거나 판의 물건 원을 누르기, Esc)·되돌리기·작은 힌트·이야기 수첩·음소거·이어 하기를 제공한다. 기본은 대사·부탁을 한국어 음성으로 재생하며, 다시 듣기는 지금 보는 부탁(쪽지가 있으면 그 말)을 다시 읽는다. **글로만 연습**은 자동·수동 음성을 모두 끈다. 소리를 꺼도 지시와 사건은 모두 글로 이해할 수 있다.

자동 읽기의 처음 값은 맞춤 학습 입구에서 고른 도움 방식을 따른다(단계별·그때그때·안 고름 = 자동, 혼자 = 누를 때만). 2026-10-03부터 WORLD의 읽기 과제는 읽기 확인이라, 단계별을 고르지 않았다면 부탁을 누를 때만 읽어 준다. 전에는 과제가 자동 읽기로 열려 첫 응답이 모두 '도움 받음'이 되고 교사 결과의 혼자 해낸 응답이 늘 0이었다. 게임 안의 단추가 언제나 이긴다. 입구는 단계별 도움을 고른 사람에게 이 게임을 글로만(`?reading=1`)으로 열지 않는다.

브라우저 진행과 Atlas 연습 기록을 저장한다. 4280의 공통 입구에서는 다른 게임과 같은 기기 기록을 쓴다. 5213 독립 미리보기는 다른 origin이므로 기록이 별도다. WORLD 안에서는 기존 계정·동의·동기화 호스트를 통해 기록하며 비회원 기록을 계정에 자동으로 합치지 않는다. 실제 OAuth/학습 API 설정과 로그인·동의가 준비돼야 서버에 연결된다. 공개·계정 연결의 확인 범위는 [공통 계정 운영 기록](../beginner-games/qa/account-sync/README.md)을 따른다. 로컬 `synk-account/config.json`의 존재만으로 이 게임의 실계정 왕복을 확인했다고 보고하지 않는다. 공유를 끈 계정의 이야기 진행은 이번 창에서만 이어간다.

키보드: Tab으로 버튼 이동, Enter/Space로 선택. Esc는 든 물건 내려놓기, 들고 있지 않으면 멈춤 창(창이 열려 있으면 닫기). 마우스와 터치는 같은 버튼을 사용하며 물건 드래그를 추가 지원한다. 물건을 든 채 가구 위의 다른 물건을 누르면 그 가구에 놓는다. 동작 줄이기 설정을 반영한다.

## 홍보 설명과 TOPIK 학습 연결

**홍보 문구:** 선생님이 돌아왔다! 마린은 무엇을 치우고, 까몽은 어디에 놓아야 할까요? 부탁을 읽고 친구를 움직이면 엉망이던 교실의 비밀이 드러나요. TOPIK I 준비를 위한 대상·위치, 부정 표현, 행동 순서 읽기를 연습합니다.

공통 목표는 [TOPIK I 1~2급 합격 준비](../../docs/미니게임_TOPIK_I_학습기준.md)다. 자체 창작한 초급 생활 문장과 짧은 이야기이며 공식 기출 문제나 검수된 급수별 문항은 아니다.

| 구현된 행동 | 입력에서 이해할 것 | 읽기 연습 범위 |
|---|---|---|
| 마린/까몽·물건·장소 선택 | 누가 무엇을 어디로 옮기는지 | 문장의 대상·위치·요청 이해 |
| 종이를 쓰레기통 대신 서랍에 보관 | “버리지 말고” | 부정 표현과 지시 이해 |
| 꽃→편지, 케이크→리본 | “놓은 뒤”, “놓은 다음” | 짧은 글의 행동 순서 이해 |
| 다른 친구/장소의 마지막 정리 | “이번에는”, “서랍이 아니라 상자” | 새 문장의 정보 변경 이해 |

모든 놓을 곳을 선택할 수 있어 문장 의미가 성공 조건이 된다. 등장인물·물건 이름은 초급 조작을 돕기 위해 표시한다. 결과에는 부탁 수행, 새 글 수행, 도움 없는 최초 응답 수를 따로 표시한다. 최초 정답은 글 힌트와 음성 도움을 모두 받지 않은 경우에만 독립 수행으로 센다. 실제 음성이 시작될 때 도움을 기록하며 실패한 다운로드는 도움으로 세지 않는다. 첫 응답 뒤의 도움은 최초 기록을 소급 변경하지 않는다. 힌트 이전/이후·오답 종류·수정·되돌림·같은 글 재시도도 보존한다. 이 기록은 이번 문항의 수행이며 TOPIK 점수나 급수 판정이 아니다.

Atlas는 `ko.reading.detail/negation/sequence`와 `action` 형식으로 기록한다. 읽기 기록을 사용해 지금 수행 가능한 부탁 중 먼저 연습할 부탁을 추천하며, 행동 순서의 선행 조건을 지킨다. 끝화면에는 세 영역의 연습 상태와 공통 학습 입구를 보여 준다. 독립 처음 응답·도움받은 응답·반복 글·변경된 새 글을 구분한다. 저장이나 계정 연결이 불확실할 때 독립 새 정답을 만들어 내지 않는다.

대상·위치·부정·순서를 반복해서 읽고 행동에 반영하는 연습 기회를 제공한다. 주제·이유·긴 글 이해, 전 범위 충족, 장기 기억, 실제 읽기 향상과 합격 효과는 검증하지 않았다. 교원 문형/난도 검수와 실제 학생 플레이가 다음 확인 대상이다.

## 시각·소리 · 기존 구현의 출처

아래는 10월 2~6일 제작·구현 이력이다. 새 마스코트 장면 제작은 [AI 운영 원칙](../../docs/AI_운영원칙.md)의 10월 14일 기준을 따른다.

원근과 빛이 있는 미니어처 배경에 투명 소품과 승인 캐릭터를 배치한 2D 장면이다. 마린·까몽의 전신/표정과 몽글은 기존 승인 자산을 사용한다(투명 캔버스 그대로, 보이는 상자만 CSS로 맞춤). LAB 로고·서체·펠트 부품은 2026-10-06부터 키트(`kit/brand`·`kit/fonts`·`kit/felt`)를 쓰고, 게임에 따로 두던 사본(옛 글꼴 7개·`brand-lab.webp`·`felt.webp`·실땀 `thread*.webp`·`assets/ui/`)은 지웠다. 마스코트 원본을 새로 그리지 않았다.

## 구현과 확인

`story.mjs`는 대사·부탁·설명, `core.mjs`는 의미 판정과 되돌림/저장, `stage.mjs`는 교실 무대(자리 계산·이름표·고르기·드래그·옮기는 움직임), `app.mjs`는 화면과 흐름이다. `voice-lines.mjs`·`voice.mjs`는 텍스트와 음성, `learning.mjs`·생성된 `atlas-learning.js`는 공통 연습 기록, `audio.mjs`는 비언어 소리, `index.html`·`style.css`(키트 `kit/lab.css` 다음)는 화면을 맡는다. 런타임은 외부 패키지/CDN 없이 로컬 파일로 실행한다. 구버전 이야기 진행은 새 대사/기록 schema와 섞지 않고 새 판으로 시작한다.

WORLD 교사 화면 시험(`experiences/teacher-world/qa-*.cjs`)이 읽는 것은 그대로 둔다: `window.__storyState`·`__storyVoice`·`__storyLearning`(읽기 전용), 단추 `#start`·`#reading-mode`·`#dialogue-next`, 교실 단추의 `data-actor`·`data-object`·`data-destination`. 공개 묶음(SYNK-website `sync-play-games.mjs`)이 바꾸는 문자열 — `index.html`의 `#account-panel`과 WORLD 계정 링크, `app.mjs`의 4280 계정·학습 입구 주소 — 도 같은 글자로 남겨 두었다.

```powershell
node --test experiences/story-classroom/core.test.mjs experiences/story-classroom/voice.test.mjs experiences/story-classroom/learning.test.mjs experiences/story-classroom/assignment-target.test.mjs experiences/story-classroom/grammar-links.test.mjs
# experiences 폴더를 정적 서버로 띄운 뒤(기본 http://127.0.0.1:5251/story-classroom/, STORY_URL로 바꿈)
node experiences/story-classroom/qa/play.cjs          # 컴퓨터·휴대폰·320px·움직임 줄이기, 한 판 전체
node experiences/story-classroom/qa/play.cjs sweep    # 여덟 화면 크기(320×568~1280×720)에서 교실 배치·쪽지를 모든 상태마다 빠르게(sweep small처럼 한 크기만도)
```

`qa/play.cjs`는 이 PC의 번들 Playwright와 설치된 Chrome(헤드리스)으로 한 판을 실제로 한다: 대사 음성 자동을 끄고 → 이야기 → 1장에서 마린(과자 부탁 탭으로) → 종이(맞는 부탁 없음: 탭 그대로·「지금 고른 것」) → 까몽(종이 부탁 탭으로) → 쓰레기통(교실이 바뀌고 쪽지) → 힌트 → 되돌리기 → 서랍 → 2장 꽃 부탁은 다시 듣기로 들은 뒤 → 나머지는 친구 → 물건 → 놓을 곳을 눌러서(휴대폰은 새 글 하나를 끌어 놓기, 컴퓨터는 1장 뒤 새로고침해 이어 하기) → 결과 → 처음으로 → 멈춤 창·수첩. 고를 때마다 판의 문장과 고른 것이 맞는지, 쪽지(틀림·힌트·되돌림·맞음)가 판에 다 보이는지(안쪽 스크롤 없음), 게임 화면이 한 화면인지(스크롤 없음)·가로 넘침·교실 단추가 교실 안에 있고 판에 가리지 않는지·이름표가 덮이거나 서로 겹치지 않는지(13px 이상, 누를 곳 36px 이상)·결과(첫 시도 8/9, 도움 없이 7)·공통 코인 `+23 · 보유 23`·학습 기록·콘솔 오류 0을 본다. 사진은 `qa/shots/`(git 밖), 결과 원본은 [`qa/play-results.json`](qa/play-results.json). `?qa`일 때만 `window.__story`(상태 읽기, 지금 부탁을 화면과 같은 길로 풀기)가 생긴다.

옛 검사(`qa/verify-browser.mjs`·`verify-voice-browser.mjs`·`felt-verify-ui.mjs`·`final-smoke.mjs`·`verify-navigation.mjs`)와 그 기록([검증 기록](qa/RESULTS.md), [브라우저 결과 원본](qa/browser-results.json))은 2026-10-05까지의 옛 화면 것이라 지금 화면의 단추 이름과 맞지 않는다(기록으로 남김). [학생·교원·실기기 확인표](qa/PLAYTEST.md)를 준비했다. 공개 배포와 실물 휴대폰 플레이, 실제 학생 재미/학습 효과는 별도다.
