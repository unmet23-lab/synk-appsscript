# 〈선생님이 돌아왔다〉 이야기·문장 자체 검토 기준본

2026-10-02 · 구현 대사 v2 (`classroom-birthday-2`) · 음성 텍스트 v1 (`classroom-birthday-2-voice-1`)

사용자의 전체 진행 요청에 따라 현재 구현과 음성 제작에 사용할 문장을 고정했다. 이 문서는 제작자의 자체 검토 기록이다. 한국어 교원·외부 전문가의 검수, 학생 평가, 사용자의 최종 품평 확정을 뜻하지 않는다.

실제 이야기와 정답 원문은 [story.mjs](story.mjs), 실제 음성 제작용 문장과 안정 ID는 [voice-lines.mjs](voice-lines.mjs)에 있다. 화면 피드백도 음성 텍스트와 같은 원문을 사용한다. 음성 파일 생성·실제 발음·청취·브라우저 재생은 이 자체 검토와 별도로 확인한다.

## 독자가 이 이야기를 하는 이유

친구들과 선생님 사이에 무슨 일이 생겼는지 알고 싶어서 읽는다. 처음에는 엉망인 교실을 정리하는 것처럼 보이지만, 하트와 별 장식, 편지, 케이크가 차례로 나타나 선생님의 생일 파티였다는 사실이 드러난다. 글을 이해한 행동이 교실의 모습을 바꾸고 이야기를 진행시킨다.

선생님의 첫 반응은 놀람이다. 벌·혼내기·감점·시간 압박을 이야기의 동력으로 쓰지 않는다. 잘못 옮기면 물건이 실제로 다른 곳에 남고 친구가 짧게 반응한다. 물건을 다시 선택해 옮기거나 되돌릴 수 있다.

## 이야기와 장면의 정합성

| 단계 | 읽고 하는 행동 | 이야기가 이어지는 이유 |
|---|---|---|
| 첫 장면 | 책상 위 과자, 바닥의 종이와 리본, 상자의 케이크, 선반의 꽃, 서랍의 편지 | 쉬는 시간에 파티를 준비하던 교실이다. 정답은 그림의 위치나 색으로 지정하지 않는다. |
| 1막 | 마린: 과자→상자. 까몽: 종이를 버리지 않고→서랍 | 종이는 쓰레기가 아닌 장식이어서 보관한다. 보관 뒤 하트·별 모양이 이야기의 작은 단서가 된다. 두 부탁은 어느 순서로 해도 된다. |
| 2막 | 마린: 꽃→책상. 꽃을 놓은 뒤 까몽: 편지→칠판 | 꽃과 편지를 보여 주는 준비가 이어진다. 편지를 펼쳐 읽으며 선생님의 생일이 밝혀진다. |
| 3막 | 까몽: 케이크→책상. 케이크를 놓은 다음 마린: 리본→칠판 | 숨긴 케이크와 남은 장식을 꺼내 파티를 완성한다. |
| 새 글 | 까몽: 과자→선반. 마린: 종이를 서랍이 아닌→상자. 과자를 옮긴 뒤 마린: 케이크→선반 | 완성한 같은 교실에서 담당 친구·장소·앞뒤 관계가 달라진다. 이전 정답을 반복하는 것과 새 글을 이해하는 것을 구분한다. |

물체의 원래 위치를 글의 필수 조건으로 고정하지 않았다. 앞 막에서 다른 물건을 잘못 옮겼더라도 뒤 막의 부탁을 읽고 다시 옮길 수 있다. 순서를 틀려 먼저 옮긴 편지·리본·케이크는 앞의 일을 나중에 완료해도 자동 정답이 되지 않는다. 새로 직접 행동해야 완료된다.

## 초급 읽기 문장 검토

평가 대상으로 쓰는 부탁은 친숙한 생활 물건과 `은/는/이`, `을/를`, `안에/위에`, `넣다/놓다/붙이다`를 중심으로 구성했다. 다음 단계에서 `-지 말고`, `-을 놓은 뒤`, `-은 다음`, `아니라`를 사용한다. 글을 계속 볼 수 있으며, 조작 속도를 읽기 능력으로 채점하지 않는다.

| 문항 ID | 실제로 확인하려는 이해 |
|---|---|
| `cleanup-snacks` · `clue-flowers` · `surprise-cake` | 누가 어떤 물건을 어디로 옮기는가 |
| `cleanup-paper` | 버리지 말라는 부정 조건과 서랍이라는 목적지 |
| `clue-letter` · `surprise-ribbon` | 앞의 일을 마친 뒤 뒤의 일을 한다는 순서 |
| `review-snacks` | 바뀐 담당과 목적지 |
| `review-paper` | 서랍이 아니라 상자라는 변경·부정 |
| `review-cake` | 바뀐 담당과 앞뒤 행동 관계 |

세 영역을 각각 읽기 대상·위치, 부정·변경, 행동 순서 연습으로 설명한다. 이 게임이 TOPIK I 공식 문항이거나 1급·2급의 모든 어휘·문형을 충족한다고 주장하지 않는다. 이야기의 이유와 생일 반전은 읽는 동기이지만, 현재 행동 정답만으로 이유·주제·긴 글 이해를 별도 측정했다고 표시하지 않는다.

정확한 목표 급수 대응과 학습 효과를 판단하려면 한국어 교원의 문항 적합성 검수, 처음 보는 문장에서의 수행, 일정 간격 뒤 재확인, 실제 학습자 관찰이 더 필요하다.

## 캐릭터 대사와 v2 교정

[캐릭터 가이드 정본](../../docs/캐릭터/가이드_정본.md)의 기준은 캐릭터가 직접 말하는 문장에 적용했다.

- 몽글: 발견과 궁금함, 물음·감탄, 함께 다시 해 보자는 반응을 유지한다.
- 까몽: `내가/이 몸/내`로 자기를 내세우고, 말줄임 뒤 실토와 챙김이 드러난다. `맛은 안 봤ㅇ…`처럼 초급자가 읽기 어려운 분리 자음은 자연스러운 문장으로 고쳤다.
- 마린: 물음표·느낌표 없이 확인·보고·완료와 짧은 다정을 쓴다. 음성은 자연스럽고 차분한 한국어로 읽으며 문장을 로봇 음성처럼 과장하는 기준을 두지 않는다.
- 선생님: 놀란 뒤 부탁하고 파티를 알아차린다. 아이들을 벌주거나 협박하지 않는다.
- 실제 소품에는 글자가 없는 하트·별 종이가 있으므로 첫 막의 단서를 모양으로 교정했다. 꽃은 실제 소품의 세 송이에 맞췄다. 편지는 펼쳐 읽는다는 사건을 문장에 명시했다.

## 음성 텍스트 기준본과 도움 기록

`VOICE_LINES`는 안정 ID를 가진 90개 문장이다. 이야기·나레이션 26개, 부탁 9개, 해설 9개, 피드백 46개를 포함한다. 모든 인물·물건·도착지 조합에서 나오는 런타임 피드백이 이 목록의 문장을 사용한다. 해설·성공·오류 문장을 별도 TTS 전용 표현으로 바꾸지 않는다.

음성은 도움을 켠 연습에 사용할 수 있다. 부탁 또는 해설을 소리로 제공한 수행은 글만 보고 처음 이해한 수행과 구분한다. 자동 이야기 음성도 직접적인 정답 단서를 말하는 다음 줄은 해당 부탁의 음성 도움으로 기록한다.

| 음성 ID | 연결된 부탁 | 직접 제공하는 정보 |
|---|---|---|
| `dialogue-cleanup-intro-03` | `cleanup-paper` | 종이를 버리면 안 된다는 조건 |
| `dialogue-clue-intro-02` | `clue-flowers` | 마린과 꽃의 관계 |
| `dialogue-surprise-intro-03` | `surprise-cake` | 까몽과 숨긴 케이크의 관계 |

일반적인 등장·감정·파티 설명은 부탁의 행동 정답을 주지 않아 도움 연결이 비어 있다. 빈 연결 `[]`는 현재의 모든 부탁을 표시하라는 뜻이 아니다. 공개한 해설과 피드백의 음성은 명시한 해당 부탁에만 연결한다.

호스트는 음성이 실제로 재생을 시작했을 때 다음 API를 호출한다. 음성 파일 오류·음소거·재생되지 않은 클릭은 도움 기록으로 만들지 않는다.

```js
game.markAudioHelp(line.assistanceMissionIds, {
  source: 'dialogue', // 'mission' | 'explanation' | 'feedback'도 허용
  voiceId: line.id,
});
```

`markAudioHelp()`의 반환값은 표시한 부탁 ID 배열이다. 명시 ID·ID 배열을 받으며, 인자를 생략하면 현재 미완료 부탁을 표시한다. 본문을 읽는 일 자체는 도움이 아니다. 기존 `helpUsed/firstHelpUsed`는 추가 글 해설 도움으로 남긴다.

- 음성 기록: `audioHelpUsed`, `audioBeforeFirst`, `firstAudioHelpUsed`, `audioHelpCount`, `audioHelps[{source, voiceId, beforeFirst, afterAttempts}]`
- 각 응답의 당시 조건: `responses[].helpUsed`, `responses[].audioHelpUsed`
- 첫 독립 정답: `firstCorrect && !firstHelpUsed && !firstAudioHelpUsed`

첫 응답 뒤 음성을 들었거나 수정했더라도 그 이전 응답의 도움 여부를 소급 변경하지 않는다. 되돌리기는 장면과 완료 상태를 복구하지만 첫 응답·도움·시도 사실을 지우지 않는다. 재시작은 회차 기록을 초기화한다.

로컬 진행 저장 형식은 v2다. 이야기 v1 저장은 새 음성 조건을 알 수 없어 자동으로 독립 수행으로 옮기지 않는다. 인증된 학생 계정 기록·다른 기기 동기화·교원 평가 기록과는 별개다.

## 이번 확인 범위

`node --test experiences/story-classroom/core.test.mjs`의 20개 시험으로 장면 이동, 복구, 순서, 첫 응답과 글·음성 도움의 분리, 전체 단계 저장 복원, 모든 런타임 피드백의 음성 텍스트 연결을 확인했다. 이는 로컬 코드와 대사 기준본의 검증이다. 실제 음성 청취·발음 품질, 브라우저 플레이, 교원 검수, 학생 학습 효과·TOPIK 합격 준비도의 검증을 대신하지 않는다.
