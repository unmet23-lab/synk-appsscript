# 탐험 별지도와 수집 목표 · 2026-10-09 로컬 검증

상품 `ship-keepsake-starbook`은 30코인 영구 소유 수집품이다. 기존 하늘·배지 장착과 분리했다. 공통 `setBeginnerGoal`/`beginnerProgress`를 사용해 한 가지 목표 선택·변경·해제, 현재 부족분, 구매 후 목표 보존과 실사용을 연결한다. 가격·소유·코인 규칙은 생성 `collection.js`의 공통 원문을 쓰며 게임 안에서 복제하지 않는다.

`starbook.mjs`는 완료 상태에서 서버가 투영한 18수리 기록을 검증한다. 각 별자리의 여섯 점은 해당 시스템의 여섯 수리이며, 표현 순서에 따라 점 높이가 달라진다. 실제 표현 횟수와 완료 날짜를 함께 보여 준다. 최근 여섯 탐험과 별도로 보관 표시한 소중한 기록을 멱등 저장하고 토큰/방 코드/친구 이름을 보관하지 않는다. 기본 기록·일곱 표현 듣기·기존 세 문항 회상은 계속 무료다. 구매 전 미리보기 모형과 실제 탐험을 구분한다.

## 소중한 기록 보관과 허브 바로가기 · 같은 날 후속

기존 V1 최근 배열을 읽을 때는 변경하지 않는다. 보관한 실제 탐험은 독립 `:kept:<expeditionId>` 키에 저장하며 새로운 완주가 최근 여섯 개를 정리해도 남는다. 해제는 원래 완료 시각을 유지해 최근 배열에 기록을 먼저 확보한 다음 보관 키를 지운다. 읽기·재로드·같은 완료 재수신에서는 여섯 개로 자르지 않으며 다음 새 완주 저장 때만 정책을 적용한다. 브라우저 변경은 Web Locks로 직렬화하고, 보관 키를 분리해 최근 배열 갱신과 분리한다. 키·값이 일치하지 않거나 손상된 보관 항목은 다른 정상 기록을 가리지 않는다.

`node experiences/spaceship-coop/qa/favorites.cjs`: **25항목 통과, 페이지 오류 0**. 서버 `project()` 계약으로 만든 **12개의 완료 fixture**를 브라우저에 넣은 기록 보존 시험이다. 사람이 열두 번 플레이했다고 주장하지 않는다. 상품 소유 확인에는 **30코인 테스트 잔액**으로 실제 구매 API를 사용했다.

- 무료/소유 320px 실제 화면, 한영 문구·실제 펠트 보관 단추, 키보드 초점·선택한 탐험 유지, 가로 넘침 없음.
- 기존 여섯 기록의 바이트 보존, 열 번째 기록까지 추가 후 첫 보관 기록+최근 여섯 개 유지, 해제 후 즉시·재로드·동일 완료 때 유지, 다음 새 완료에서만 정리.
- 같은 컨텍스트의 실제 두 탭에서 서로 다른 두 기록 동시 보관, 새 완주와 보관 동시 실행. 즐겨찾기 두 개/세 개 모두 유지.
