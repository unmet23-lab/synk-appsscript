# 그래픽 마감 v2 · 2026-10-08

## 실제로 바꾼 것

- 네모 쿠션 몸체 → 전용 펠트 로켓 스프라이트. 청금석 노즈/날개, 크림 동체, 버터 창문, 금속 리벳/유리의 원본 재질을 보존한다. 로켓 안의 몽글 표정은 기존 승인 자산을 별도로 얹었다.
- 펠트 우주 배경에 차분한 색층과 광량 차이를 주고 실제 펠트 원/고리로 행성, 실제 펠트 원판으로 착륙판을 만들었다. 밝은/밤하늘에서 알파 가장자리를 확인했다.
- 각 6장치를 수리할 때 엔진/안테나/연료 진행계가 차오른다. 한국어/영어 표기는 최소 12/11px, 접근성 그룹/수리 수를 함께 제공한다. 엔진 불꽃, 통신등, 수리/실수/이륙 반응은 실제 상태를 따른다.
- 그림 설명서의 부품명과 수리 번호, 목표 펠트 받침, 수신 대기 상태, 조작 타일의 접촉 그림자/눌림, 성공/재시도 피드백을 재구성했다.
- 상점은 본 게임과 동일한 장면을 사용한다. 장면 위의 장식 캡션이 모바일 로켓에 겹치지 않게 정리했다.

`assets/art/felt-rocket-v2.webp`는 통합 담당이 만든 생성 원본의 768×1152 알파 보존 파생본이다. 프롬프트/원천 기록은 입문 게임 통합 그래픽 기록을 따른다. 이 담당 작업에서는 추가 이미지/음성 API를 호출하지 않았다.

## 전후 비교

`node experiences/spaceship-coop/qa/graphics.cjs`는 별도 로컬 서버와 두 Chrome 페이지에서 실제 음성을 준비하고 튜토리얼을 끝내 설명서/조종판까지 연다. `SHIP_GRAPHICS_STAGE=before`가 수정 전, `after`가 수정 후다. before를 현재 코드로 다시 굽지 않는다.

| 화면 | 수정 전 | 수정 후 |
|---|---|---|
| 입구 PC | `graphics-before-entry-1440.png` | `graphics-after-entry-1440.png` |
| 설명서 PC | `graphics-before-game-1440.png` | `graphics-after-game-1440.png` |
| 설명서 모바일 | `graphics-before-game-390.png` | `graphics-after-game-390.png` |
| 조종판 모바일 | `graphics-before-controls-390.png` | `graphics-after-controls-390.png` |
| 상점 320px | `graphics-before-shop-320.png` | `graphics-after-shop-320.png` |

입구·설명서·상점에는 각각 1440/390/320px 사본이 모두 있다. `graphics-after-results.json`은 9개 너비/화면 조합에서 가로 넘침·깨진 이미지 없음, 시스템 글자 최소 11px를 확인한다. `shop-desktop.png`는 밤하늘+고리 미리보기, `shop-320-preview.png`는 노을과 320px 화면 확인에 썼다.
