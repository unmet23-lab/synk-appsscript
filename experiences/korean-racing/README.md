# SYNK LAB PLAY · 한국어 레이싱 시안

현재 로컬은 v10 주행 흐름까지 반영했다. 정답 뒤 최소 4초의 질주 구간을 두고 부스터를 6초(3콤보 이상 6.8초)로 늘렸다. 문제 대기는 부스터를 소모하지 않으며 선택 후 진입 속도를 복원한다. 마지막 문제의 해설을 들으며 SYNK 시티팝 「해안선」 드라이브로 이어진다. 186개 검사와 실제 주행·패키지 확인은 [v10 검증 기록](qa/PACING-V10.md), 그래픽·모바일 크기·4K 확인 범위는 [v9 기록](qa/GRAPHICS-V9.md)을 따른다.

2026-10-01 사용자 요청: 모바일에서도 돌아가는 고품질 그래픽의 한국어 학습 게임. 레이싱·생존 달리기·리듬 세 가지 새 방향 중 먼저 짧은 레이싱 체험을 만들고 홈페이지에 소개할 수 있도록 준비한다.

2026-10-02 공통 목표: [TOPIK I 1~2급 준비](../../docs/미니게임_TOPIK_I_학습기준.md). 레이싱은 단어·짧은 문장·대화의 듣기와 조사·연결 표현·안내문·메모의 읽기를 함께 맡는다. 현재 단계·메달·4/5 통과는 게임 진행 기준이며 공식 급수·합격 판정이 아니다.

## 이번 결과

후속 로컬 개선: [단계와 성취 설계](DESIGN-PROGRESSION.md). 6단계·12도전·60개 문장/대화/안내문 문항과 문제·해설 음성120개를 추가했다. 4/5 통과로 다음 코스 개방, 학습 메달·콤보·개별 해설·문장 오답 복습을 제공하며 기존400 어휘 스테이지와 기록은 보존한다. 옆면/앞뒤 차량 접촉·겹침 분리·감속·접촉음·스파크를 추가했다. 꽃빛 해안·섬과 항구·노을 만의 세 풍경은 같은 도로 지형을 공유한다. 2026-10-02에는 큰 중앙 문제창을 없애고 음성 중심 HUD로 바꿨다. 문제·차선별 보기·답과 이유를 음성으로 재생하고 지문·보기는 요청할 때 펼친다. 이 후속 개선은 아래의 직전 홈페이지 게시와 별개인 로컬 시제품이다.

- 5문제씩 실시간 3D 해안도로 레이싱. 직접 조작 / 자동 시연. 문제 음성을 끝까지 듣거나 다시 들으면 통과 직전에 차가 잠깐 기다리므로 고정 시간 제한은 없다.
- 한국어 음성 문제 → 그림 또는 단어 글자 게이트 선택 → 정답 부스터 → 실제 주행 거리로 추월·순위 계산.

- 키보드 A/←: 화면 왼쪽, D/→: 화면 오른쪽. W/↑ 또는 아래의 ↑ 출발 버튼으로 현재 차선을 선택해 가운데 길도 그대로 진행할 수 있다. 음성이 끝나기 전에는 선택해도 게이트 앞에서 기다린다. 휴대폰 좌우 누르기 조작. 일시정지·재개·다시하기·발음 듣기.
- 평소에는 도로 중앙을 비우고 작은 다시 듣기·지문/보기·자막 조작만 남긴다. 왼쪽→가운데→오른쪽의 보기와 위치를 실제로 섞인 차선 순서에 맞춰 음성으로 안내한다. 지문/보기를 펼치면 차와 상대가 기다리며, 보기3개 중 하나를 누르면 창을 접고 해당 차선으로 이동한다. 정답 판정은 차가 게이트를 통과할 때 한다. 읽기 문항은 지문을 자동으로 펼치고 정답 제출 전에는 지문 음성을 재생하지 않아 읽기 응답을 듣기와 분리한다.

## Atlas 맞춤 출제 · 2026-10-02 로컬 구현

- `personalization.js`는 60개 문항을 듣기/읽기와 세부 능력에 연결한다. 공통 `atlas-learning.js`의 추천을 받아 다음 5문항을 실제 구성한다. 추천 코스는 기존 해금 순서와 별개로 열리며 수동 코스 선택과 메달 기록은 유지한다.
- 브라우저의 공통 Atlas 기록에 최초 응답·문항군·도움·음성 전달을 남긴다. 자막/지문 열람·다시 듣기, 이미 응답한 문항군, 완료하지 못한 음성, 선택 의도와 주행 결과가 불분명한 응답을 독립 이해 근거에서 제외한다. 보기를 직접 누르거나 ↑ 현재 차선 선택을 해야 조작만으로 통과한 응답과 구분할 수 있다. 자동 시연은 공통 기록을 만들지 않는다.
- 읽기 문항은 텍스트를 입력으로 사용한다. 실제 세 보기 선택을 `single-choice`로 전달하며 O/X 응답 근거와 구분한다. 듣기와 읽기를 같은 점수로 합치거나 TOPIK 급수로 환산하지 않는다. 현재 문항 태그/난이도는 제작용이며 교원 검수와 학생 평가 전이다.
- '이 기기의 공통 학습 기록 지우기'는 해당 origin의 네 게임 공통 기록을 초기화한다. 기존 레이싱 메달/완주 기록은 별도다. 공용 origin의 브라우저 기록이며 학생 로그인·교사 보고·다른 기기 동기화가 아니다. 여러 학생이 함께 쓰는 기기를 학생별 계정으로 간주하지 않는다.
- 공용 허브의 `?learning=reading` 또는 `?learning=listening` 링크는 첫 맞춤 코스의 실제 5문항을 해당 영역으로 한정한다. 2026-10-03부터는 준비가 끝나면 기본 시작 단추도 그 맞춤 코스를 달린다(전에는 여정 카드에서만 적용돼 '읽기부터'로 들어와도 첫 듣기 코스가 시작됐다). 이후에는 직접 다른 코스를 고를 수 있다.
- 2026-10-03: 문항을 들려준 뒤 판정 전에 홈·다시 하기·코스 변경으로 나가면 그 문항을 '응답 없음'(평가 안 함)으로 닫는다. 열린 채 두면 다음에 같은 문항이 처음 보는 문항으로 세져 독립 근거가 됐다. WORLD 안에서는 계정 기록이라 지우기 단추를 숨기고, 지우기가 거절되면 '지웠어요' 대신 계정 설정을 안내한다.
- 소스와 `site-package/`를 갱신했다. 공개 홈페이지·기존 ZIP은 갱신하지 않았다. 검증은 [맞춤 출제 확인 기록](qa/PERSONALIZATION-20261002.md)에 구분한다.

## 순간 맞춤 · 2026-10-03

- 두 가지가 그 사람에게 맞춰 움직인다(`personalization.js`의 `FLOW_RACE`, 공통 `coach.live`): 달리는 속도(72~115km/h 다섯 칸, 원래 94km/h)와 맞춤 5문항이 고르는 문항 단계(1~3단계, LEVEL 1~2·3~4·5~6 코스의 문장). 보기 수와 문제 사이 거리는 개인별로 바꾸지 않는다. 2026-10-04부터 공통 게이트 간격은435m이며, 문항 안내220m·음성/선택 대기65m는 유지한다.
- 넘기는 응답: 보기를 직접 고른 답만 넘긴다. 정답·오답과 함께, 문제를 끝까지 듣거나(읽기·소리 끔은 보인 때) 고를 때까지 쓴 시간의 비율을 압박으로 넘긴다. 문장 코스는 차가 멈춰 기다리므로 이 속도에서 설계한 접근 시간(155m)을 기준으로, 낱말 코스는 남은 길을 기준으로 잰다. 경주에는 늦은 답이 없으므로 비율은 1에 닿지 않게 두어 틀린 답은 늘 문항에 대한 근거로 남는다. 의도와 다른 길로 들어간 답은 아무것도 움직이지 않는다.
- 문장 코스는 차가 멈춰 기다리므로 속도가 고를 시간을 줄이지 않는다. 속도는 문제 사이를 달리는 박자를 그 사람이 고르는 빠르기에 맞춘다. 낱말 코스는 차가 기다리지 않아 속도가 실제로 고를 시간을 바꾼다. 경쟁 차도 같은 비율로 빨라지거나 느려져 순위는 답과 부스터로 정해진다.
- 문항 단계는 Core가 앞세운 후보 안에서만 고른다. 교사 목표가 있으면 Core가 고른 그대로 둔다. 판 안에서 바뀐 단계는 다음 맞춤 5문항부터 쓰이므로 판 안에서는 속도 변화만 한 줄로 알리고(정답 알림이 끝난 뒤), 결과 화면에 '이번 주행에서 맞춘 것'으로 둘 다 적는다. 단계는 방향만 말한다(소리를 끄면 읽기 문항뿐이라 2단계가 없다).
- 피곤한 날은 시작 속도가 느긋해질 수 있고(처음 달리는 사람은 한 칸), 판 안에서는 빨라지지도 어려워지지도 않는다. 자동 시연과 첫 조작 연습은 맞춤 없이 원래 속도다.
- 확인: 실제 엔진 시험 9개(`tests/flow.test.mjs`) — 빨리 맞히면 속도가 한 칸씩 오르고 다음 맞춤 5문항이 같은 기록에서 Core만 고른 것보다 높은 단계, 오래 걸리면 속도만 느긋해짐, 틀리면 단계가 내려감, 조작 답은 무변화, 피곤한 날, 교사 목표, 압박 계산, 결과 문구, 모든 코스 통과 뒤 추천. 헤드리스 Chrome으로 맞춤 5문항을 두 판씩 실제로 달렸다. 바로 고르면 94→104km/h, 다음 판 104→115km/h와 '조금 더 어려운 문장도' 안내. 7.5초씩 기다려 고르면 94→83→72km/h, 다음 판은 72km/h로 시작. 페이지 오류 없음.
- 모든 코스를 통과한 뒤의 추천은 마지막 코스 고정이 아니라 가장 덜 익숙한 코스(점수가 낮은 것, 그다음 덜 달린 것)다. 마지막 코스를 마친 결과 화면은 막다른 '마지막 코스예요' 대신 '맞춤 5문항 달리기'를 권한다.
- WORLD 듣기 목표인데 소리를 꺼 두었으면 '지정 문항을 준비하지 못했어요' 대신 '이번 목표는 듣기 문항이에요. 소리를 켜면 바로 시작할 수 있어요.'라고 안내한다(목표 카드·코스 목록·시작 단추).

## 배경 개선 · 2026-10-01

사용자가 배경이 습기 차고 뿌옇게 보인다고 지적하여 맑은 해안 드라이브 방향으로 수정했다.

- 가까운 지형을 씻어내던 지수 안개와 바다의 흰 안개색을 줄였다. 먼 섬에만 약한 대기 원근을 적용한다.
- 해안도로를 약23m 높이로 올리고 완만한 높낮이를 넣어 바다와 절벽을 내려다보도록 구성했다.
