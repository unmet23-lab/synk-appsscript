# City v9 — 근경 주택·재질·정원 마감

2026-10-04 로컬 소스 검증. 담당 범위는 `cityscape.js`, `city-materials.js`, `tests/cityscape.test.mjs`다. 실제 브라우저 장면·4K 캡처·전체 게임 검수는 상위 통합 작업에서 확인한다.

## 변경

- s498/551/609의 기존 해안 주택 3채 위치·크기·지붕·발코니를 보존하고, 전면 및 도로를 향한 측면에 18개 실제 창/문 개구부를 구성했다. 벽을 개구부 주변으로 나누고 유리를 24cm 후퇴시켰다. 유리 두께를 포함해 보이는 앞면은 외벽 기준 21.25cm 안쪽이다. 목재 프레임·창턱·멀리언도 해당 구멍에 맞춘다.
- 주택 외벽은 연속된 석회 미장 질감으로 바꾸어 상업 건물의 큰 패널 분할과 구분한다. 유리는 기존 하늘 반사를 사용하며, 켜진 방을 선별하고 전체 외벽이 밝은 격자처럼 보이는 정도를 줄였다. 실내 분석 교차 계산은 근거리·중간 이상 품질에 한정한다.
- 기존 현관 계단에서 이어지는 지형 밀착 진입로 9구간, 낮은 정원 담 9구간, 크기가 다른 관목 9군을 추가했다. 담에는 출입구가 있고 동선과 겹치지 않는다. 정원도 기존 식생의 제외 영역에 들어가므로 길이나 담에 나무가 생성되지 않는다.
- 담은 지형을 따르는 연속 표면으로 마감했다. 중단 시점의 개별 상자 담 대비 내부 중복면·묻힌 바닥면을 제거해 720 triangles를 절약했다. 관목 밑면은 지면에 조금 묻어 떠 보이지 않게 했다.
- 프레임마다 도시 블록의 상점 수를 다시 `filter`하던 연산·배열 생성을 초기 구성 때 한 번으로 옮겼다. 기존 거리별 세부 생략·카메라 프러스텀 컬링·재질 배치를 보존한다.
- 새 조명, 투명 유리 렌더 패스, 반사 카메라, 다운로드 텍스처를 추가하지 않았다. 도로·보행자 활동 앵커·상점 22채·타워 12채의 배치도 보존한다.

## 기하 예산

카메라 컬링 없이 s0–2250을 5m 간격으로 전수 샘플링한 도시 모듈의 최대치다. 실제 GPU 시간이나 휴대폰 FPS 측정은 아니다.

| 품질 | v8 최대 triangles | v9 최대 triangles | 최대 draw calls |
| --- | ---: | ---: | ---: |
| high | 21,636 | 24,634 | 61 → 61 |
| balanced | 15,610 | 18,608 | 44 → 44 |
| low | 10,356 | 12,130 | 33 → 33 |

전체 저장 기하는 30,780 → 33,778 triangles(+2,998). 개구부·정원 형상을 실제 기하로 추가했으므로 기하 비용은 증가했다. 최대 draw calls 및 저품질 그림자 draw calls 0은 유지한다. 가까운 마감 부품은 low에서 숨기고 재질의 실내/미세 요철 연산도 끈다.

## 검사

`node --test tests/cityscape.test.mjs` — **12/12 통과**, 실패/건너뜀 없음.

- 모든 실제 정점은 도로 반대편을 유지하고 최소 도로 중심 이격은 9.2999967m다.
- 근·중·원 품질 전환은 기존 geometry 객체를 재사용한다. 각 지점의 low 기하량은 high 이하이고 low 그림자 draw calls는 0이다.
- 18개 개구부를 외부에서 raycast했을 때 low에서도 모두 유리에 먼저 닿으며 외벽이나 내부 상자가 창을 덮지 않는다.
- 진입로 샘플은 지형 위 약 6.30–7.13cm에 놓이고, 위에서 raycast하여 실제 위쪽 면이 존재함을 검사했다. 모든 담과 충분한 보행 폭을 유지한다. 담의 연속 상단도 실제 raycast로 확인했다.
- 기존 계단 지지면, 주택 간 이격, 발코니·지붕의 식생 제외, 보행자 발·의자·테이블 앵커, 자원 해제 검사도 통과했다.

브라우저 셰이더 컴파일과 실물 화면의 미감, 장시간 실제 휴대폰 성능·발열은 이 파일의 Node 검사 결과에 포함되지 않는다.
