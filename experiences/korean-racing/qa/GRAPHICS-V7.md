# 그래픽 마감과 시작 최적화 v7 · 2026-10-03

v6의 열린 바다·요트·노을 방향을 유지하며 세부 마감과 첫 화면 준비를 개선했다. 로컬 5197 및 정적 전달 패키지에 반영했으며 공개 홈페이지에는 배포하지 않았다.

## 화면 마감

- 스캔 암반의 사각형 절단 테두리를 불규칙한 타원 형태로 낮춰 물속에 감췄다. 중심의 스캔 요철과 UV를 보존하고 변형에 맞춰 법선을 보정했다. 젖은 표면과 환경광 반응도 조정했다. 가까움/멀리 모델 모두 같은 경계 형태를 사용한다.
- 수면의 반복적인 수평 반사 띠를 교차 파도로 분산하고, 화면에서 너무 작아지는 잔무늬와 반짝임을 픽셀 크기에 맞춰 완화했다. 하늘과 전체 색 방향은 유지했다.
- 하늘 반사 회전의 삼각함수를 픽셀마다 계산하던 부분을 테마 변경 시 계산하는 값으로 옮겼다. 물결 계산값을 재사용하고 먼 포말·깊은 물의 불필요한 계산을 건너뛴다.
- 추가 삼각형·텍스처·실시간 반사 카메라 없음. 수면은 기존 2삼각형/1패스, 암반은 가까움10,491/멀리2,298삼각형이다. 저사양 수면 detail0·먼 암반 모델·배 항적0을 브라우저에서 확인했다. FPS 향상률 측정은 아니다.

## 첫 화면 준비

`startup.js`로 텍스처11개와 차·드라이버 재질·암반 요청을 함께 시작한다. 자산 실패 처리는 즉시 연결한다. 큰 월드 생성 단계 사이에 4번 브라우저에 실행을 양보하고, `compileAsync`와 실제 첫 렌더가 끝난 뒤 시작 단추를 푼다. 그동안 코스·품질·캐릭터·크기가 바뀌면 최신 선택으로 다시 준비한다. 로딩 중 레이스 메뉴로 미완성 차량을 초기화하던 진입도 막았다.

동일 PC의 Codex 브라우저에서 일반 새로고침을 측정했다. 캐시를 비운 비교가 아니며 네트워크·GPU 캐시·동시 작업의 영향이 있다. 공개판 18.4초/19.0초 측정과 직접 비교하지 않는다.
