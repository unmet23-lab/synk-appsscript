## 음성 중심 화면 · 2026-10-02

- 중앙의 큰 문제/보기 카드를 기본 화면에서 없앴다. 질문·왼쪽/가운데/오른쪽의 보기·정답과 해설을 사전 생성 음성으로 안내한다. 183개 새 보기/차선 MP3의 길이·신호 RMS 확인 통과(2,057,892bytes, 최소 RMS705). 문제/해설120개와 기존 어휘 음성은 보존했다.
- 실제 인앱 브라우저 자동 시연: 짧은 문장5문제 130.801초, 5/5 정답, 출제·차선·보기·해설·완주52클립 모두 `completed=true`. 시연 전후 저장 기록은 rounds1/cleared1로 동일했다. 발음 자연스러움의 직접 청취와 실기기 재생 평가는 별도 미검증이다.
- 실제 배치 `worldOrder=[빵, 물, 우유]`에 대해 음성은 왼쪽/우유→가운데/물→오른쪽/빵 순서였다. 다시 듣기 중 재호출하면 기존 문제 클립 `completed=false`로 취소하고 같은 순서를 처음부터 재생했다. 읽기 패널에서 오른쪽/빵을 선택하자 창을 닫고 실제 게이트 통과 때 정답으로 판정했다.
- 지문/보기는 요청할 때만 펼친다. 펼친 동안 차가 감속 후 정지하고 상대도 기다린다(확인 속도 약0). 조건 지문 코스012에서도 기본 창 숨김·음성 출제·선택 자막 최대3줄을 확인했다. 음소거하면 지문/보기를 자동으로 열고, 소리를 다시 켜면 접고 음성을 반복했다. 전체 음성 파일 실패 상황의 브라우저 재현은 이번에는 수행하지 않았다.

## 건물 재질·인물 동작 v5 · 2026-10-02

사용자 요청 「건물 재질이랑 인물 동작 많이 다듬어줄래」에 따라 기존 도시/44명 배치를 유지하고 표면과 움직임을 개선했다. `city-materials.js`의 실제 면별 미터 UV·재질별 roughness/미세 normal·유리 Fresnel/청록 흡수·가까운 창문 실내 시차를 사용한다. 실내는 책선반/카운터/커튼/바 선반의 셰이더 표현이며 실제 출입 가능한 공간은 아니다. 첫 GPU 확인에서 과하게 밝고 동일했던 회색 방을 낮추고 반사·실내 변형을 보강했다. high/balanced의 먼 창문은 실내 상자 교차와 가구 계산을 건너뛰며 low는 시차/미세 요철을 생략한다.

인물은 세계 좌표에 지지발을 고정하고 반대 발의 스윙을 별도로 계산한다. 팔/다리 2관절 IK, 골반/어깨 역회전, 대화 차례와 듣는 고개 반응, 잔 들기/입 접촉 유지/내림/휴식, 접근 응원의 완만한 전환과 개별 타이밍을 추가했다. 실제 화면에서 발견한 서 있는 사람의 과한 무릎 굽힘과 짧은 체형의 방향 전환 때 정강이가 늘어나는 문제를 수정했다. 손·엄지·눈·둥근 신발·피부/옷/머리의 표면 차이를 더했다.

최종 `node --test tests/*.test.mjs`: **109/109 통과**, 실패/취소/건너뜀0, 7703.636ms. 도시·인물 집중검사18/18도 통과했다. 새 검사는 실제 창문 정점 거리와 UV 미터 거리, 재질 화질 복귀·동일 기하학, 지지발 세계 좌표 고정, 고정 관절 길이, 잔 입구와 입 접촉, 한 프레임 손 위치 도약을 확인한다. app/city-life/city-materials 구문 검사 통과. 같은 저장소의 별도 변경에서 추가된 기존 검사도 포함한 전체 결과이며 레이싱 이외의 엔진 원문은 수정하지 않았다.

### 비용과 화면 확인 범위

[전 코스 5m 표본 예산](city-life-v5-budgets.json)은 카메라 제외 컴포넌트별 최대다. 도시 high18,796삼각형/51호출, balanced12,770/34, low9,444/27로 v4와 같다. 새 UV 메타데이터 버퍼는1,005,840bytes이며 새 텍스처·추가 도시 draw call·삼각형·실시간 반사 카메라는0이다. NPC 공유 기하학458삼각형, 전 코스 최대11명·28,422삼각형/9호출·동적 그림자0회다. NPC 제출량은 v4의21,630보다 늘었고 가까운 인물은 세 화질이 같은 최대값을 사용한다. 전체 게임 FPS 개선이나 실제 휴대폰 성능 수치로 해석하지 않는다.

내부 근접 화면에서 건물/좌석/인물 동작을 확인했다. 같은 하늘 셰이더로 만든 PMREM을 사용하지만 평면 바닥·별도 카메라/조명의 QA 환경이며 실제 게임 플레이 화면과 구분한다. 동작 줄이기 체크 전후가 아닌 체크한 뒤 두 시점의 전체 pose JSON이 동일했고, low 전환에도 포즈는 유지되며 animatedActors=0이었다. low→high 복귀와 노을 재질 전환, GPU 콘솔 오류/경고0 확인. 테라스·보행의 WebM은 실제 QA canvas 기록이며 모델을 따로 합성한 영상이 아니다. 원본 프레임과 전체 디코드/프레임 수를 확인했으며 오디오나 전체 플레이 완주 검증을 의미하지 않는다.
