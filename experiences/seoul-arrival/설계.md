# 서울행 → 실제 WORLD 첫 실행 — 설계 (2026-11-05, Claude)

> 범위: 유호님이 15판까지 다듬어 승인한 단일 HTML 시안(원본 공용 작업본 `.tmp/dream-path-20261102/`)을 synk.im/world의 새 학생 첫 실행으로 옮긴다. 근거 결정은 [결정 표](../../docs/_ops/결정.md) 11-02(구조 · 순서 · 범위) · 11-03(거울 · 인쇄 · 쪽지) · 11-04(객석 · 세 친구) · 11-05(씨앗 넷), 줄기는 [시즌 1 지도](../../docs/시즌1_이야기지도_20261104.md) 7절이다. **시범판 `experiences/drama/pilot/`와 1화 대사 · 영상은 한 글자도 고치지 않는다.**

## 1. 목적과 성공 기준

새 학생이 `/world/` 타이틀을 누르면 설치 없이 곧바로 이야기가 이어져, 꿈 · 이름 · 나라 · 부르는 말 · 얼굴을 이야기 안에서 정하고 학생증을 받아 1화에서 말해 본 뒤 내 객석에 불이 켜지는 것을 본다.

성공 기준: ① 입구부터 1화 끝 쪽지까지 끊기지 않고 지나간다 ② 어느 자리에서 닫아도 다시 들어오면 이어진다 ③ 어느 단계가 실패해도 지금의 앱 입구(언어 → 한글 → 튜터 → 우리 동네)로 떨어지고 막히지 않는다 ④ 돌아온 학생 · `?drama=1` 몽골 시범 · 메일의 `?exam=` 링크는 지금과 똑같다.

## 2. 사용자 흐름

```
타이틀(지금 그대로, 같은 사진) ─ 누름 ─┬ 언어를 안 골랐고 기기가 한국어가 아니면 → 언어 판
                                      └→ 서울행 층
서울행 층(앱 위 전체 화면 틀): 내 방 → 거울 앞 꿈 → 책상 · 「가」 → 합격 → 짐 → 엄마 → 기내 → 입국심사 → 서울의 첫 아침
  → 정문 → 부스(이름 · 나라 · 부르는 말) → 얼굴 고르기 → 학생증 인쇄 → 내 길
내 길 ─ 「1화 시작」 ─┬ 손님 → 로그인 판(이 판 위) → 돌아오면 내 길에서 다시 「1화 시작」
                     └ 로그인 → 장면 카드(식당 소리 · 이모) → /drama/ 틀 → 오늘 기록 → 「내 객석으로」
  → 객석(세 박자) → 내 길 → 엄마 쪽지 → 내 길 ─ 「우리 동네로」 → 지금의 입장 관문(한글 · 튜터) → 우리 동네
```

| 갈래 | 동작 |
|---|---|
| 프롤로그 건너뛰기 | 시안 그대로. 꿈을 안 골랐으면 거울 앞으로, 골랐으면 정문으로 |
| 질문마다 「나중에 말할래요」 | 시안 그대로. 빈 칸은 학생증에 이름 첫 글자 대신 기본 표시 |
| 프롤로그 중간에 닫고 다시 옴 | 틀의 자체 시작 화면(같은 사진 · 「화면을 눌러 시작」). 꿈을 골랐으면 「이야기 건너뛰고 정문부터」도 보인다. 소리에 누름이 필요해 시안의 입구 화면을 이 자리에 남긴다 |
| 학생증 뒤에 닫고 다시 옴 | 타이틀 → 곧바로 내 길 |
| 「우리 동네 먼저 둘러보기」(내 길) · 1화 끝난 뒤 | 끝난 것으로 적고 입장 관문으로. 다음부터 타이틀 → 우리 동네, 내 길은 우리 동네의 문 하나로 다시 연다 |
| 돌아온 학생(튜터 기록 있음 · 서울행 기록 없음) | 서울행을 띄우지 않는다. 지금과 같다 |
| `?drama=1` · `?exam=` · `?cafe=1` · `?wardrobe=1` · `?tutor=choose` · `?opening=off` | 서울행을 띄우지 않는다 |
| `?seoul=1` | 누구든 처음부터 연다(유호님 확인 · 돌아온 학생용 다시 보기) |
| 틀 불러오기 실패 · 저장 실패 | 틀을 닫고 지금의 입장 관문으로. 저장 실패는 기기 사본으로 이어 가고 막지 않는다 |

## 3. 어디에 넣나 (설계 ①)

- **새 폴더 `experiences/seoul-arrival/`**(공개 `/world/seoul-arrival/`) — 시안을 거의 그대로 옮긴 독립 화면이다. 입구 `experiences/brand-opening/`에도 드라마 `experiences/drama/`에도 넣지 않는다. 입구는 회사 공용 타이틀이고(`mountBrandOpening`은 product를 받는 공용 부품), 드라마 폴더는 시범판과 묶여 공개 빌드가 파일을 이름으로 고른다.
- **같은 출처 틀(iframe) + 전체 화면 `<dialog>`** — 앱의 다른 게임과 같은 방식이다. 시안 CSS 600줄(`.screen` · `.panel` · `.sheet` · `.stage`)과 전역 함수가 앱과 부딪히지 않고, 시안에서 잰 움직임 · 소리 값을 그대로 지킨다. 끝나면 틀을 지워 메모리도 돌려준다. 드라마는 부모가 곧 앱 창이어야 하므로(계정 호스트를 `window.parent`에서 찾는다) 서울행 틀 안에 넣지 않고, 앱의 게임 판(`launchGame`)으로 서울행 층 위에 띄운다.
- **앱 쪽 새 모듈 `experiences/synk-world-app/seoul-entry.mjs`** — 새 학생 판별, 틀 올리기, 부모 통로 `window.SYNKSeoulHost`(`read · save · startEpisode · leave · reduced · lang`, 드라마의 `SYNKDramaHost`와 같은 꼴), 드라마 끝 지켜보기. `app-shell.mjs`의 `startOpening`에서 `opening.done`과 `entryGate.start()` 사이 한 곳에서만 부른다.
- **타이틀과 잇기** — 시안 입구 그림과 앱 타이틀은 같은 사진이다. 새 학생이면 타이틀이 떠 있는 동안 그 아래 틀을 미리 올려 두고(`showModal` 순서로 타이틀 아래에 깐다), 타이틀 누름 안에서 틀의 소리를 깨운다. `opening.mjs`에 선택 인자 `onTap`(동기, 참이면 꽃가루 0.65초 없이 바로 닫음) 하나만 더한다 — 없으면 지금과 똑같다. 그러면 사진이 그대로인 채 곡 · 번쩍임 · 다가가기로 이어진다. PC는 타이틀이 가로 사진이라 번쩍임으로 잇는다.
- **기능 스위치** — `features.worldSeoul`(`operating-mode.mjs` FEATURES에 한 줄). 꺼져 있으면 `?seoul=1`로만 열린다. 켜지 않은 채 공개해 라이브에서 먼저 확인하고, 유호님이 보신 뒤 설정만 바꾼다.

## 4. 그림 · 소리 (설계 ②)

16MB 단일 파일의 내용을 파일로 나눈다.

| 무엇 | 어디 | 크기 | 언제 받나 |
|---|---|---|---|
| 화면 코드 · 자리표 데이터 | `seoul-arrival/{index.html,style.css,app.mjs,strings.mjs,data.mjs,watch.mjs}` | 약 0.3MB | 타이틀이 떠 있는 동안(새 학생일 때만) |
| 첫 컷 그림(room · drama) · 시작 곡 앞부분 | `assets/img`, `assets/snd` | 약 0.2MB + 스트리밍 | 타이틀이 떠 있는 동안 |
| 프롤로그 그림 · 짧은 효과음 | 〃 | 약 1.8MB | 누른 직후 차례로. 컷을 바꾸기 전에 `decode`를 기다린다(최대 3초, 넘으면 그냥 넘어가고 소리 · 글은 이어짐) |
| 부스 · 얼굴 12장 | 〃 | 약 2.1MB | 정문 전, 거울을 고른 뒤 |
| 고른 꿈의 객석 · 쪽지 · 내 길 | 〃 | 0.3~0.7MB | 내 길에 올 때. 고르지 않은 꿈의 객석은 받지 않는다 |
| 곡 셋 | `assets/snd/bgm_*.mp3` | 5.5MB | 그때그때 스트리밍(`<audio>`) |

- 저장은 **이 공개 저장소의 게임 폴더**다 — 다른 게임과 같고, 그림 39장 4.7MB · 소리 6.2MB로 [Git 자산 보관](../../docs/_ops/github-storage/README.md)의 새 파일 하나 10MiB · 합 50MiB 안이며 webp · mp3는 금지 형식이 아니다. PNG 원판(약 100MB)과 `.tmp`의 제작 재료는 Git에 넣지 않고 `SYNK_원본창고`에 옮겨 둔다.
- 공개 빌드 `tools/build-world-app-public.mjs`에 `copyTree` 한 줄 + `seoul-entry.mjs` 한 줄, 로컬 `server.mjs` `allowedGames`에 한 줄.
- 글꼴은 앱 `brand-opening/assets`의 SUIT · SYNK Latin · SYNK Cyrillic · DM Mono를 상대 경로로 쓴다(Noto Serif 링크는 안 쓰여 뺀다).

## 5. 저장 (설계 ③)

- **계정:** 생활 기록(`synk.life-korean.progress.v1`)의 선택 칸 `arrival` — 튜터 `tutor` · 화면 언어 `display`와 같은 자리다. talk `synk-play`는 값을 글자로만 받고 키 목록에 이 기록이 이미 있어 **서버 변경이 없다**(읽어서 확인: 상한 2MiB). 옛 판 화면은 모르는 칸을 그대로 보존한다.
- **손님:** 기기 `localStorage['synk.world.arrival.v1:guest']`. 생활 기록에 섞지 않아 「기기 기록 옮기기」 판과 얽히지 않는다.
- **칸:** `{version:1, stage:'prologue'|'dream'|'card'|'left', dream, name, nameEn, from, call, look, lights, scenes:[{id,at,lines?}], momAnswer, momAt, updatedAt}`. 이름 · 나라는 40자로 자르고, 모르는 값은 그 칸만 없는 것으로 읽는다(전체를 거절하지 않는다). `scenes`는 200개까지.
- **손님 → 계정:** 「1화 시작」에서 로그인 판을 열 때 이 탭에 표시(`sessionStorage`, 30분)를 남긴다. 로그인 뒤 표시가 있고 계정에 `arrival`이 없을 때만 손님 사본을 계정에 쓰고 지운다. 표시가 없으면(같은 기기를 쓰는 다른 사람) 옮기지 않는다. 계정에 이미 있으면 계정이 이긴다.
- **언제 쓰나:** 꿈 확정 · 정문 답 · 얼굴 · 학생증 · 내 길 나감 · 장면 끝 · 쪽지 답.
- **사진:** 서울행은 **준비된 얼굴 id만** 저장한다. 시안의 「내 사진」 칸과 동의 판은 옮기지 않는다 — 사진 길은 곁 세션(`me2-photo`, 초대한 성인 · `?me2=1` · 내 정보 시트 · 가지 `claude/inspiring-visvesvaraya-a388cc`, 아직 master 밖)이 맡고, 그 결과는 시범 대상에게 내 정보에서 열린다. 나중에 잇는 자리: 얼굴 고르기 레일 맨 앞 칸, 조건은 `me2Allowed()` + status ok. 시안의 「사진이 휴대폰 밖으로 안 나가요」 문구는 어디에도 남기지 않는다.
- **처리방침:** 「SYNK 계정과 학습 기록」의 「직접 고를 때만」 묶음에 한 줄을 더한다(첫 이야기에서 직접 적은 이름 · 나라, 고른 꿈 · 부르는 말 · 얼굴, 장면을 끝낸 때 · 말한 줄 수 — 학생증과 이야기에만 쓰고 계정 삭제 때 함께 지움). 한 · 영. 스위치를 켜기 전에 게시한다(`worldFeedback` · `worldPush`와 같은 순서).

## 6. 가짜 장면 세 번 → 실제 1화 (설계 ④)

**실물:** WORLD `/drama/`의 1화는 **식당 장면 하나**(학생 줄 셋) → 테이크 2 → 새 상황 → 오늘 기록이다. 시안 장면 1(연구실)은 대본만 있고 영상이 없으며, 시안 장면 2 · 3이 곧 이 실물이다. 시안 내 길도 이미 「1화 · 학생 식당에서 길 묻기」라고 적혀 있어 어긋나지 않는다. 연구실은 만들지 않고(1화 시험 전 고치지 않음), 영상이 생기면 `scenes` id만 늘린다.

| 시안 | 실제 앱 |
|---|---|
| 「1화 시작」 → 장면 카드 3번 | 카드 한 번. 첫 판만 식당 소리 + 이모의 빠른 말(5초), 다시 하기는 2초. 끝나면 `launchGame('drama')`(튜터 관문 건너뜀) |
| 장면 끝 → 객석 → 내 길 → 이어서 (3번) | 시범판을 끊을 수 없으므로 **회 끝에 한 번, 세 박자로.** 지도 7절 「매 회 끝 객석 · 쪽지 · 예고」와 같고, 첫 판 15초 안쪽 · 두 번째부터 바로 건너뛴다 |
| +2 · +2 · +2 (가짜) | **실제로 말한 줄:** ① 장면에서 소리 내어 말한 줄 n ② 테이크 2를 했으면 +1 ③ 새 상황을 말했으면 +1. 최대 5 |
| 첫 보상은 사람만, 둘째 · 셋째에 한 마리씩 | 그대로. 자리 순서를 사람 3 → 친구 → 친구 → 사람…으로 맞춘다. 줄 수가 적으면 그만큼만 앉는다(지어내지 않는다) |
| 「도움 없이 말한 줄 2개」 | 「소리 내어 말한 줄 n개」 — 시범판 밖에서 줄마다 도움 여부를 읽을 수 없고, 결정 11-02의 핵심은 「실제로 말한 줄만 셈」이다. 0줄이면 불 없이 「오늘은 들어 본 날이에요」 |
| 다음 장면 수 | 「쇼케이스 오디션까지 · 2화 다음」, 내 길 2화는 「곧 열려요」 |
| 쪽지 · 내 길 | 그대로. 쪽지는 객석 뒤 내 길에서 한 번. 정답 표시 없음. 답은 `momAnswer`에 남긴다(2화 쪽지 재료) |

**시범판을 고치지 않고 끝을 아는 법:** 틀이 같은 출처이므로 부모(`watch.mjs`)가 `MutationObserver`로 읽기만 한다 — 단계 꼬리표(`EP.01 · Take 2` · `New situation` · `EP.01 · Today`)가 바뀔 때 장면 끝 기록을 쓰고, `.wrap`이 나오면 `.log`에서 말한 줄 수와 테이크 2 · 새 상황 표시를 읽는다. 언어와 상관없게 숫자 둘 가운데 작은 값을 말한 줄로 본다. 틀 아래에 앱 쪽 띠 「내 객석으로」를 붙이고 틀 높이를 그만큼 줄여 시범판 단추를 가리지 않는다. 시범판이 바뀌어 못 읽으면 띠는 그대로 나오고 불빛만 0이다(막지 않음). 시험이 실제 시범판 판을 띄워 이 읽기를 지킨다. `?drama=1`로 온 학생에게는 지켜보기를 달지 않는다.

**장면 끝 기록(결정 11-02):** `scenes`에 `{id:'s1e01.scene'|'s1e01.take2'|'s1e01.transfer'|'s1e01.wrap', at, lines}`. 복습 기록(Atlas)은 시범판이 그대로 남기고 이것과 섞지 않는다.

## 10. 벤치마킹 근거

새 조사 없이 이미 있는 근거를 쓴다. 11-03 모션 조사(게임 12개 리뷰): 손으로 하는 연출 · 누르면 바로 답하는 것은 호평, 못 건너뛰는 반복 연출은 불평 → 건너뛰기 · 다시 볼 때 짧게. 지도 8절 · 맹검 21명: 꿈 줄기와 엄마 쪽지. 트이다 리뷰 「첫 레슨 직후」 · 「말하게 만든다」: 첫 실행이 곧 말하기로 닿아야 한다 → 내 길에서 바로 1화. 확인할 결과는 1화 시험의 「어느 순간 계속하고 싶었나」와 `scenes`로 본 단계별 이탈이다.

## 11. 위험

- **아이폰 소리:** 틀 안 소리는 같은 출처면 부모 누름으로 깨울 수 있다(사용자 활성화가 같은 출처 하위 틀에 전파). 누름 안에서 곡 요소 셋을 모두 한 번 깨운다. 실기기 확인은 유호님 몫으로 이미 남아 있다.
- **틀 안 안전 영역:** iOS에서 틀 안 `env(safe-area-inset-*)`가 0일 수 있어 부모가 재서 CSS 변수로 넘긴다.
- **새 학생의 로그인 벽:** 1화 직전에 로그인이 있다(자동 판정은 로그인 계정만, 기획 §7). 이야기 말로 「학생증을 계정에 저장하고 1화를 시작해요」로 열고, 돌아오면 내 길 그대로다.
- **튜터 고르기:** 우리 동네에 들어갈 때 지금처럼 펠트 튜터를 고른다. 서울행 뒤에 결이 튀지만 앱 구조 일이라 이번에 안 바꾸고 보고에 적는다.
- **겹치는 곳:** `app-shell.mjs` · `build-world-app-public.mjs`는 다른 세션도 자주 고친다. 줄을 작게 더하고 공개 때 3방향으로 맞춘다.
