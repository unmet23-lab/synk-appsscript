# PATH 통합 앱

해외에서 한국 유학을 준비하는 사람, 한국에서 유학 중인 사람, 취업을 준비하는 사람이 첫 실행에서 지금 필요한 도움을 고르는 화면이다. 사용자 분류는 현재의 주목표이며 신분·입학·취업·체류 자격 판정이 아니다. 여러 목표가 겹칠 수 있고 나중에 바꿀 수 있다.

## 이번 범위

`path-app` 폴더는 첫 진입, 목표별 홈, 준비 작성·본인 확인, 도움, 계정 설정을 제공한다. 가입·로그인은 기존 SYNK ID를 재사용하며 PATH 전용 브라우저 클라이언트를 `platform` 제품으로 등록한다. 기존 `resource: path`는 VR 기록용으로 유지하고 이 앱은 `scope: synk-path`, `resource: path-app`을 사용한다.

로그인 전에는 현재 탭에 보관하고, 로그인 후에는 계정별 문서를 revision 조건부 저장으로 동기화한다. 게스트 자료는 사용자가 명시적으로 가져올 때에만 비어 있는 계정에 반영한다. 충돌 시 로컬·원격 자료를 보존하고 내보내기와 원격 다시 불러오기를 제공한다. 브라우저의 탭 복원으로 기록이 남을 수 있어 종료 시 삭제를 보장하지 않으며, 공유 기기에서는 게스트 자료를 직접 지운다.

공고 연동 코드는 Moloco·Coupang의 공개 Greenhouse 채용 API에서 한국 근무 공고의 제목·회사·위치·원문 링크만 읽는다. 제공처별 갱신 상태와 확인 시각, 저장·검색·준비 연결을 구현했다. 다만 **2026-11-10 BM v1.16·v1.17 결정에 따라 법 확인이 끝날 때까지 공개판의 공고 연동은 OFF**다([결정](../../docs/_ops/결정.md)). 서버의 `SYNK_PATH_JOBS_ENABLED`가 정확히 `true`일 때만 켜지며, 기본 OFF 응답은 `availability: disabled`, 빈 공고·출처 배열이고 외부 공고 요청을 보내지 않는다. 화면은 준비 중 안내와 공식 정보 입구를 보여 준다. 기존 개인 저장 기록은 유지한다.

외국인 지원 가능 여부·비자 지원·마감일을 추정하지 않는다. 학업·생활 과정 및 여섯 합성 공고는 별도의 연습 예시다. 준비 완료는 기관 제출·채용 접수와 다르다. 채용 본문 복제·지원서 대리 제출·기관 접수·Atlas 효과 보장은 포함하지 않는다.

## 로컬 미리보기

저장소 루트에서 실행한다.

```powershell
node experiences/path-app/server.mjs
```

기본 주소는 `http://127.0.0.1:4326/`다. 설정 없는 화면 미리보기는 `PATH_APP_PORT`로 포트를 바꿀 수 있다. 계정과 공고를 연결하려면 `--config <공개 설정 JSON>`을 명시하며 등록된 4326 포트만 사용한다. 서버는 계정 비밀값을 읽지 않고 허용된 공개 설정과 화면 묶음만 제공한다. 운영 비공개 API의 CORS는 `https://synk.im`만 허용하므로 실제 계정 동기화 검증은 공개 주소에서 한다.

서버는 파일별 허용 목록으로 화면 소스와 승인된 글꼴만 제공한다. `server.mjs`·시험·기록·비밀 설정은 제공하지 않는다. 외부 폰트 요청은 없다. SUIT Variable은 승인 원본, Inter Tight는 승인된 Regular 400 파일을 별칭으로 제공한다. 두 글꼴의 OFL 라이선스도 별도 정적 경로로 제공한다.

```powershell
node --test experiences/path-app/state.test.mjs experiences/path-app/document.test.mjs experiences/path-app/account.test.mjs experiences/path-app/jobs-ui.test.mjs experiences/path-app/app.test.mjs experiences/path-app/server.test.mjs tests/prepare-path-app-public.test.mjs
```

## 첫 진입과 보관 기준

- 주목표 하나로 첫 홈과 첫 행동을 고른다. 보조목표는 접근 범위를 제한하지 않는다.
- 둘러보기는 목표가 없는 중립 홈으로 연결하고 미응답을 임의로 추정하지 않는다.
- 한국어·영어를 바꾸어도 현재 목표·작성 중인 준비를 보존한다.
- 목표를 바꾸어도 다른 목표의 초안을 숨기거나 삭제하지 않는다.
- 예시 자료와 공식 정보 링크를 자료 유형으로 구분한다. 예시의 금액·마감·비자 조건을 만들지 않는다.
- 저장 실패·손상 데이터·미지원 판본에서는 성공으로 표시하거나 기존 내용을 자동 덮어쓰지 않는다. 게스트는 탭별 세션이며 계정 자료와 서로 바꾸어 넣지 않는다.
- 본인이 내용을 확인한 뒤에만 준비 완료로 표시하며 수정하면 다시 확인한다. 외부 링크 클릭은 제출·접수 기록을 만들지 않는다.

## 초기 프론트 확인 기록

2026-11-10 로컬 Chromium에서 확인했다. 단위·회귀 검사 39개 통과, 실제 브라우저 시나리오 6묶음 통과. 320·390·1440px와 한국어·영어를 포함한 40개 화면 조건에서 가로 넘침 0, 콘솔 오류 0, 실패 요청 0이었다.

- 세 유형·건너뛰기·선택 항목·이전·취소, 목표·언어 변경과 새로고침 후 초안 보존.
- 최대 3개 비교, 직접 확인 후 준비 완료, 수정 시 재확인, 입력 문자열의 HTML 실행 방지.
- 손상·미지원 판본·알 수 없는 출처의 저장 원문 보존. 읽기·삭제 실패 시 덮어쓰기와 거짓 성공 안내를 막는 회귀 검사.
- 원자료: 작업본 `.tmp/path-app-20261109/final-unit-tests.tap`, `browser-qa-result.json`, `browser-qa.cjs`, `captures/qa-*.png`.

위 수치는 계정·공고 연결 전 초기 프론트 판의 기록이다. 실제 휴대폰·화면 읽기 도구·사용자 만족도·취업 및 정착 효과를 검증한 결과는 아니다.

첫 판의 아르곤 코드 검수 2건(P2)을 모두 반영했다. 위치·주제 선택창의 정렬과 입력 후 남는 오류 문구를 고쳤고, 수정 부분 12개 화면 조합과 실제 입력을 다시 확인했다(`targeted.json`). 그 판의 P0·P1 지적은 없었다. 검수 묶음은 `.tmp/검수/path-app-first-20261109`다.

첫 판의 미학 맹검(`path-app-first-20261110`)은 세 장 모두 기각이었다. 기본 설문처럼 보이는 선택지, 모바일의 잘린 장식 띠, 홈의 긴 개발 안내와 외부 링크 나열을 지적했다. Claude가 두 번째 판에서 숲색·아이보리 화면, 선택지별 그림, 모바일 장식 제거, 목표별 기회 예시와 준비의 세 걸음으로 바꾸고 기존 여행·면접 링크를 도움으로 옮겼다. 두 번째 판도 자동 검사 39개·브라우저 6묶음·40개 화면 조건을 통과했다. 증거는 `v2-unit-tests.tap`, `browser-qa2-result.json`, `captures/qa2-*.png`이며 두 번째 미학 맹검은 `path-app-second-20261110`이다. 육안 후속(P2): 데스크톱 왼쪽 제목의 짧은 마지막 줄을 더 다듬을 수 있다.

## 계정 연결판 확인 기록

- SYNK ID에 PATH 클라이언트와 로컬·공개 콜백을 등록하고 읽어 대조했다. 기존 클라이언트 23개, 포털 항목 19개의 설정은 보존했다. 실제 브라우저에서 PATH의 가입·로그인 버튼 → 기존 SYNK ID 로그인 → 이메일 가입 폼까지 확인했다. 시험 계정 생성·메일 전송은 하지 않았다.
- 실제 서버의 PATH 전용 저장소 마이그레이션과 비공개 함수 배포를 확인했다. 계정·resource 격리, revision 조건부 저장, 삭제 tombstone, RLS·삭제 연결을 시험했다. 로그인하지 않은 요청은 401, 허용되지 않은 비공개 출처는 403이었다. 실제 사용자 로그인 후 브라우저에서 원격 저장·복원하는 종단 검증과 구분한다.
- 최초 서버 연결 검사에서 공개 채용 API 2곳의 공고 357건을 읽었다. 이후 BM 결정에 맞춰 공개 연동을 기본 OFF로 바꿨다. 최초 성공 응답을 현재 공개 공고 제공의 근거로 쓰지 않는다.
- 브라우저에서 불필요한 `x-synk-contract` 헤더가 공개 공고 요청의 CORS를 막는 문제를 발견해 제거했다. 계정 로드 오류 재시도, 초안 손실 없는 로그아웃 제한, 손상된 게스트 원문 보존, 빈 계정으로 명시적 가져오기, 검색어 유지와 읽기 전용 동작을 회귀 검사한다.
- 연결판 최종 회귀 120/120 통과. 최종 실제 브라우저 캡처 16장(390px 7장·1440px 9장), 320px 온보딩·찾기·내 정보·편집기의 가로 넘침 0을 확인했다. 운영 OFF 응답은 GET 200·OPTIONS 204이며 최종 재진입에서 CORS 실패 0이었다. 최초 320px 넘침과 CORS 실패 영수증도 보존한다. 중앙 계정의 Google 버튼은 로그인·가입 화면에서 상태가 달라 실제 인증 가능 여부를 확정하지 않았다.
- 첫 통합 화면 아르곤 검수 `path-live-ui-20261110`: 23건 중 반영 18·일부 1·후속 2·재현 안 됨 1·미반영 1. 후속은 중복 지적인 공고 수정일 표시이며, 읽기 전용의 별도 화면 언어 설정은 일부 반영 항목의 후속이다. 데이터 저장 범위·읽기 전용 동작·복구 오류는 반영했다. Fable 최종 검수 사슬은 `path-live-ui-20261110` → `path-live-ui-r2-20261110` → `path-live-ui-r3-20261110`이며 총 8건 중 반영 5·재현 안 됨 2·후속 1이다. P0·P1은 없고 최종 소스·공개 후보 해시 대조를 통과했다. 후속 1건은 최초 복구 배너와 확인창의 안내 표현 정렬이다. 원본 시험·검수·캡처·등록·배포 영수증은 공용 작업본 `.tmp/path-live-20261110`, `.tmp/path-provision-live-20261110`, `.tmp/검수/`에 보관한다.
