# 공통 미니게임 컬렉션

## SYNK ID 계정 저장 · 2026-10-09

사용자 확정: 코인·구매품·게임 진도는 로그인한 SYNK 계정에 귀속하고 다른 기기에서 복원한다. 2026-10-09 **운영 DB·Edge·기능 플래그·OAuth·웹 반영을 완료**했다. 실제 계정으로 상점 목표 저장·새 WORLD 탭 복원·해제까지 확인했고 코인·구매품·게임 진도는 바꾸지 않았다. 물리 PC↔휴대폰 왕복은 미검증이다. 아래의 브라우저 전용 지갑 설명은 이전 구현 기록이고, 계정 모드에는 이 절이 우선한다.

- 기존 WORLD OAuth·네이티브 로그인을 사용한다. `account-host.mjs`가 인증된 계정의 저장을 소유하며 게임 iframe에는 제한된 저장·거래 기능만 제공한다. 로그인 토큰은 게임에 전달하지 않는다.
- 코인·구매·장착·목표·완주 보상은 SYNK-talk의 `synk-play` 서버가 공통 `garage-core.js` 규칙과 서버 날짜로 처리한다. 계정 행 잠금과 명령별 영수증으로 동시 구매·응답 유실 재시도의 중복 차감을 막는다. 레이싱은 `racing-command.mjs`가 실제 코스 자료와 계정 진도를 함께 사용한다. 완료·정답 보고 자체는 클라이언트 입력이며 별도의 부정행위 방지 평가 시스템은 아니다.
- `play-data.mjs`의 허용 목록에 있는 입문 3종 진도·소풍·별지도와 즐겨찾기, 레이싱 진도·안내, 기존 미니게임 기록을 복원한다. Atlas 학습 기록의 동의·서버 연결은 기존 통로를 유지한다. 이야기 교실의 동의 버전별 체크포인트, 리듬 기기 지연 보정, 우주선 방 입장 토큰은 이 저장 계약에 넣지 않는다.
- 게임 진입 전에 계정 복원을 기다린다. 다른 기기에서 같은 진도가 바뀌면 이전 값 대조로 충돌을 알리고 사용할 진도를 선택한다. 선택 전 초안은 보존하고, 코인·구매품은 서버 기록을 유지한다. 즐겨찾기 해제도 삭제로 전달한다.
- 연결이 끊기면 계정별 전송 대기 기록을 보관하고 재연결 시 같은 명령으로 재시도한다. 저장 중·완료·실패를 구분하며 로그아웃 후 남은 게임 참조는 저장할 수 없다. 로컬 전송 대기는 서버 저장 완료를 뜻하지 않는다.
- 직접 연 체험 게임에는 로그인 입구를 표시한다. 과거 브라우저 기록은 자동 합치지 않고, 빈 계정에서 사용자가 명시적으로 가져올 때만 옮긴다. 원본은 남기며 두 지갑의 코인을 더하지 않는다.

`node experiences/play-common/build-collection.mjs`는 계정 연결 코드·공통 경제 규칙·어댑터를 묶어 레이싱을 포함한 11개 게임/허브에 동일한 `collection.js`를 복사한다. `node tools/build-synk-account.js`로 WORLD 연결 화면도 갱신한다.

[계정 저장과 실제 운영 검증](../beginner-games/qa/account-sync/README.md). 서버 DB 마이그레이션 → `synk-play` Edge와 기능 켜기 → 웹 반영 순서로 완료했다. 네이티브 설치는 조율된 플랫폼 담당이 수행했다. 로컬 합성 계정 시험과 실제 계정의 같은 기기 새 탭 복원은 실물 두 기기 복원 증거가 아니다. 추가 공식 검토는 사용자의 명시적 지시에 따라 당시 유예한 이력이다. 현재 작업의 검증 범위는 [AI 운영 원칙](../../docs/AI_운영원칙.md)을 따르며 과거 고정 모델 검토를 새 필수 관문으로 적용하지 않는다.

## 놀이가 이어지는 상품과 직접 고르는 목표 · 2026-10-09

입문 상품 원본은 이제 22개(무료 7·구매 15)다. 기존 배경·사진틀·간판·쟁반·하늘·장식은 유지하고, 마법 소풍 실험 세트 20코인, 주문 소풍 친구 초대 세트 15코인, 협동 탐험 별지도 30코인을 추가했다. 학습 본편·기본 자유 실험·다시 듣기·도움은 무료다. 세트는 이미 배운 표현으로 하는 선택 놀이이며, 별지도 구입 없이도 완료 기록과 표현 소리를 확인한다. 상세한 실제 사용과 학습 범위는 [입문 게임 원문](../beginner-games/README.md)의 최신 절을 따른다.

`setBeginnerGoal(game,itemId|null)`과 `beginnerProgress(game)`가 명시적으로 선택한 상품, 실제 잔액, 부족분, 구매 가능·수집 완료 상태를 낸다. 목표는 자동 지정하지 않는다. `beginnerWishes`로 저장해 기존 주문 폭주의 `gameWishes`를 덮어쓰지 않는다. 구매 후에도 목표를 유지해 실제 사용으로 이어지고 언제든 바꾸거나 지울 수 있다. 소풍 초대와 별지도는 `ownershipOnly` 상품이라 장착 슬롯을 바꾸지 않으며 `equip`은 `use-in-game`을 반환한다.

`awardPractice`는 말의 마법사 자유 실험에서 실제 소리 재생 뒤 유효한 변화를 만든 서로 다른 주문-물체 쌍 3개(최소 주문 2종·물체 2종)를 받아 5코인을 준다. 무료 소품으로도 가능하며 미리보기·같은 변화 반복·오디오 실패는 인정하지 않는다. 서울 날짜 기준 하루 한 번, 기존 전체 게임의 코인 보상 10회 한도 안에서 지급한다. 이후에도 실험은 계속된다. 정확도·TOPIK·학습 성과 장부는 바꾸지 않는다. 이는 로컬 게임 흐름의 기록이며 서버 검증 화폐는 아니다.

구매·목표 변경·실험 보상 모두 같은 Web Lock을 사용한다. 저장 실패 때 차감·소유·목표·지급 성공을 표시하지 않는다. 무료 실험 소품만 이전 지갑에 기본 추가하고, 기존 코인·상품·장비·칭호·학습 기록을 보존한다. `beginner-motivation.test.mjs`와 `collection.test.mjs`가 조건·중복·날짜 경계·공통 한도·마이그레이션·저장 실패를 검사한다. 실제 탭/페이지 연동은 [motivation-integration](../beginner-games/qa/motivation/integration.json)에 남긴다.

## 입문 상점 연결 · 2026-10-08

말의 마법사·주문 폭주 입문·협동 우주선에 각 2개 꾸미기 종류, 무료 기본 2개와 구매 상품 4개를 연결했다. 배경/간판/하늘은 15·35코인, 사진틀/쟁반/우주선 장식은 20·40코인이다. `korean-racing/beginner-catalog.js`가 18상품의 원본이고 같은 `SYNK_PLAY_COLLECTION_V1` 지갑을 쓴다. 문제·힌트·음성·난이도는 구입 없이 모두 이용한다.

기존 레이싱 차고의 구매·장착 분리와 말 랠리의 실제 장비 적용을 비교해 구현했다. 미리보기는 아직 구매하거나 장착한 결과가 아니다. 구입한 꾸미기는 실제 장면과 PNG 사진(마법 사진틀)에 적용하며, 재입장·무료 기본 복귀·저장 실패 상태를 각 게임에서 다룬다. 바람길의 예전 상점은 현행 README에서 종료된 기능이므로 복원하지 않았다.

허브의 `collection.js`에만 남아 있던 일곱 게임의 50개 상품과 28개 칭호 정의를 `korean-racing/play-catalog.js`로 옮겨 기존 원본의 차량·라켓·공과 합쳤다. `normalizeGarage`가 기존 `gameEquipment/gameStats/achievements/gameWishes`를 보존한다. 생성기는 입문 두 게임과 허브도 같은 코드로 갱신하므로, 새 상점을 열어 저장해도 이전 꾸미기와 칭호를 잃지 않는다. 아래 초기 기록의 사본 목록·번들 크기보다 이 최신 목록이 우선한다.

마법은 장별 사건 6개와 소리 확인 2개를 끝낸 첫 완주에 15코인씩, 우주선은 서버가 부여한 고유 탐험 ID로 공동 이륙 후 브라우저별 15코인을 지급한다. 그림 체험·미완료에는 지급하지 않는다. 주문 입문의 기존 완주 보상은 유지한다. 모두 기존 하루 10회 한도와 중복 완주 장부를 공유하며, 코인은 놀이 보상이다. 구입과 지급은 Web Locks가 있는 브라우저에서 같은 origin의 탭끼리 직렬화한다. 지원하지 않는 브라우저에서는 동기 읽기/쓰기로 처리하며 다중 탭 원자성을 보장하지 않는다.

검증: `collection.test.mjs`와 레이싱 `tests/garage.test.mjs` 26/26을 포함해, 세 게임·공통 자산·서버 선택 검사114/114(109 + 우주선 상점·음성5). 실제 Chrome의 게임별 구매 단추와 적용·재로드 50흐름, 허브/다른 게임 왕복, 두 탭 동시 구매 차감 1회를 확인했다. [통합 검증](../beginner-games/qa/shops-integration.json). 구입 시험은 격리 브라우저에 시험용 잔액을 넣어 진행하며 사용자의 실제 지갑을 수정하지 않는다. 공개 배포·실물 기기·계정 지갑 동기화와는 별개다.

레이싱·말의 리듬·바람길·빈칸 베기·입장 검사·선생님이 돌아왔다(이야기 교실)·말 랠리·주문 폭주는 같은 브라우저 origin에서 `SYNK_PLAY_COLLECTION_V1`을 함께 사용한다. 소유·장착·지갑·미니게임 지급 규칙의 원본은 `../korean-racing/garage-core.js`이고, 레이싱의 오늘 미션·레이스 지급은 그 위의 `../korean-racing/garage.js`가 더한다(레이싱이 쓰는 이름은 그대로다). 개인 계정·다른 기기와 동기화하는 지갑은 아니다.

`node experiences/play-common/build-collection.mjs`는 `garage-core.js`만 기존 로컬 esbuild로 묶고, `collection-adapter.js`를 붙여 classic script인 `collection.js`를 만든다. 생성본은 리듬·바람길·빈칸 베기·입장 검사·이야기 교실·말 랠리 폴더에 같은 바이트로 복사한다(시험이 같은지 본다). 레이싱의 코스·낱말 자료를 묶지 않아 약 12.5KB다(2026-10-04 전 347KB). 미니게임은 레이싱 미션을 다시 만들 수 없으므로 저장된 미션을 모양만 확인해 그대로 둔다(`keepMission`). 레이싱이 열 때 자기 자료로 다시 확인한다. 원본 규칙을 바꾼 뒤에는 빌드를 다시 실행하고, 생성본을 직접 편집하지 않는다.

지급은 그 게임의 「한 판을 끝까지 마쳤다」 조건 뒤에만 한다: 리듬은 곡 끝, 바람길은 90초 등불 여행 완주, 빈칸 베기는 한 판 끝, 입장 검사는 근무 끝, 이야기 교실은 이야기 끝, 말 랠리는 한 판(12번 주고받기) 끝, 주문 폭주는 본 영업(한가한 오픈 8개·점심 러시 90초) 끝(3개짜리 새 주문 연습은 받지 않음, 2026-10-06). 완주 15 + 정답 비율 × 10(반올림)이라 문장·손님 수가 많은 판이 더 받지 않고, 다 맞힌 판은 어느 게임이든 25다(2026-10-04 전 「정답 1개당 2」와 리듬 다섯 문항에서는 같다). 이야기 교실의 정답은 도움 없이 첫 시도에 옮긴 부탁 수다. 말 랠리의 정답은 결과 화면의 맞힌 수 그대로다(다시 듣기·글로 보기를 쓴 답과 소리를 끄고 한 판도 센다 — 코인은 놀이 보상이고, 도움은 학습 기록이 따로 가린다). 연습 공은 세지 않고, 그만두기로 나간 판은 받지 않는다. 자동 시연·중도 종료·충돌 종료·입장 검사의 연수 근무(안내를 따라 찍은 도장)는 지급하지 않는다. WORLD 과제 판도 끝까지 마치면 받는다(코인은 놀이 보상이고 과제 결과와 따로 남는다). 모든 게임이 공통 하루 10회 완주 지급 한도와 중복 완주 장부를 쓰며, 한도를 넘으면 「오늘의 완주 코인 10회분을 모두 받았어요」라고 말한다. 이야기 교실은 한 판의 번호를 저장에 남겨 다시 열거나 결말을 다시 그려도 두 번 받지 않는다. 미니게임은 레이싱의 첫 통과·오늘의 미션·오답 교정 기록을 바꾸지 않고, 게임 조작 결과를 한국어 이해도나 TOPIK 성적으로 해석하지 않는다. 코인은 학습 기록에 쓰지 않는다.

꾸미기 종류(2026-10-07): 레이싱의 차량·도색·휠·부스터·배지에 말 랠리의 라켓(`racket`)·공(`ball`)을 더했다. 기본은 무료(코랄 라켓·크림 공, 원래 모습)이고 펠트 색 셋씩을 35~50코인에 판다. 그전에 저장한 지갑은 새 종류만 무료 기본값을 받는다(`normalizeGarage`가 칸마다 따로 되살림). 어댑터는 `buy(itemId)`(레이싱 차고와 같은 `buyItem` 규칙, 맞는 구매만 저장)와 `equip(itemId)`를 낸다. 저장 공간을 읽을 수 없으면 둘 다 `storage-unavailable`이다(빈 지갑으로 읽어 ‘코인 부족’이라 하지 않게). 레이싱 차고에는 「말 랠리」 칸으로 나온다.

코스트 챔피언 배지는 실제로 소유하고 장착한 경우에만 그 이름을 작은 글자로 보인다(그림 기호를 쓰지 않음). 시작 화면에는 공통 코인 잔액과 차고 링크를 한 줄로, 결과 화면에는 받은 공통 코인과 차고 링크를 표시한다. 저장 공간에서 잔액을 읽을 수 없으면 `코인저장불가`를 표시하고, `collection.js`를 읽지 못한 화면은 코인 줄을 숨긴다. 기존 학습 기록 초기화는 차고 소유품·코인을 지우지 않는다.

같은 origin 경로: 레이싱 로컬 서버의 `/play/rhythm/`·`/play/runner/`, 통합 패키지의 `/배포위치/play/rhythm/`·`/배포위치/play/runner/`, 공개 사이트의 `/try/rhythm/`·`/try/runner/`, 학습 허브의 `/korean-rhythm/`·`/korean-runner/`·`/blank-slice/`·`/entry-check/`·`/story-classroom/`(차고 링크는 옆의 `/korean-racing/?garage=1`). 내장 게임의 차고 링크는 `/배포위치/?garage=1`로 돌아간다. 말 랠리는 공개 사이트의 `/try/talk-rally/`에서 같은 지갑을 쓴다(2026-10-05). 학습 허브에는 아직 없지만, 들어가면 `/talk-rally/` 옆의 레이싱 차고로 이어지게 경로 규칙에 넣어 두었다. 서로 다른 포트로 실행한 독립 게임은 저장 공간도 서로 다르다.

## 목소리 — Typecast로 다시 굽기(2026-10-07 준비, 게임 소리는 아직 옛 목소리)

유호님 「미니게임 지금 레이싱이랑 이것저것 … 저렴한 품질의 목소리가 많이 적용되어 있는데 전부 타입캐스트로 바꿔줘」(10-07). 일곱 게임(레이싱·입장 검사·이야기 교실·말의 리듬·말 랠리·바람길·주문 폭주) 2,856줄 · 22,206자를 `tools/미니게임_목소리.cjs` 하나로 다시 굽는다. 글은 바꾸지 않는다.

- 미리보기: `node tools/미니게임_목소리.cjs --dry-run [--game korean-runner,talk-rally] [--json]` — 게임·배역별 줄과 글자, 같은 목소리·설정·글을 한 번만 부를 때의 글자(크레딧 어림), 출력 경로가 지금 파일과 같은 이름인지, 길이 한도에 걸릴 수 있는 줄. Typecast를 부르지 않는다.
- 만들기: `node tools/미니게임_목소리.cjs` → http://127.0.0.1:5245 에서 유호님이 기존 API 키를 붙여 넣는다(이 프로세스 메모리에만 2시간, 파일·채팅에 남지 않음). 「샘플 만들기」(배역마다 두 줄 — 후보 목소리까지도) → 화면에서 듣고 필요하면 「이 목소리로 바꾸기」 → 「전부 만들기」(게임마다 또는 전체 — 새로 받을 줄·글자·어림 크레딧을 먼저 보여 주고 한 번 더 묻는다). 월 제공 크레딧이 모자라거나 오류가 세 번 이어지면 멈추고, 결제·충전은 하지 않는다. 같은 일을 이 컴퓨터의 명령으로도 한다(`POST /generate {"mode":"sample"}` 등, 파일 머리말).
- 배역: `tools/minigame-voice-casting.json` — 배역마다 기본 목소리와 후보 둘, 공식 미리듣기 주소, 미리듣기에서 잰 음높이·밝기·빠르기(참고값), 고른 까닭. 해설(서현)·바람(혜리)은 유호님이 고른 목소리다. 같은 동물은 입장 검사와 주문 폭주에서, 몽글은 말 랠리와 이야기 교실에서 같은 목소리다.
- 원본(Typecast wav)은 저장소 밖 `Documents/synk-vendor/minigame-voice/raw/<목소리>/<요청 해시>.wav`에 둔다. 목소리·설정·글이 같으면 다시 사지 않는다. 샘플·후처리 무대도 같은 폴더 아래다. 받아 둔 원본만으로 후처리를 다시 할 때는 `--apply <게임|all>`(유료 호출 없음).
- 후처리는 게임마다 지금 파이프라인과 같은 이름·형식·표본율·크기·앞뒤 여백이다(`tools/lib/미니게임목소리_게임.cjs` 머리말과 `--dry-run`의 「후처리」). 자르기·크기 맞추기가 있던 게임은 그 필터 그대로, 옛 합성 음성을 그대로 쓰던 게임은 지금 파일을 재서 같은 앞뒤 여백과 통합 음량으로 맞춘다(예: 바람길 끝 0.74초는 말이 끝난 뒤 움직일 시간이다).
- 한 게임의 모든 줄이 그 게임의 검사(바람길 부탁 5.3초 미만, 말 랠리 몽글 2.5초 미만·안내 4.5초 이하와 음량, 리듬 0.5~14초, 주문 폭주 1~15초, 형식)를 통과해야 게임 폴더에 넣는다. 넣을 때 게임이 읽는 목록(레이싱 `assets/narration/*manifest.json`, 입장 검사 `voices.json`, 이야기 교실·말 랠리 `manifest.json`, 리듬 `manifest.json`·`narration.mjs`, 바람길 `manifest.json`·`voice-timing.mjs`)을 지금 스크립트와 같은 방식으로 고친다. 게임이 읽는 파일에는 제작 도구·목소리 이름을 넣지 않고, 만든 설정은 `*.source.json`과 게임마다 `qa/voice.source.json`에만 둔다(공개 묶음에서 빠짐).
- 바꾼 뒤: 게임별 시험과 qa(말 랠리 `qa/sound.cjs` → `narration.test`, 주문 폭주 `qa/verify-assets.mjs` 등)를 다시 돌리고 귀로 듣는다. 게임 README의 목소리 설명도 그때 고친다. 옛 생성 스크립트(레이싱 `scripts/synthesize-*.ps1`·`encode-narration.py`, 바람길 `scripts/build-voice.ps1`, 주문 폭주 `qa/generate-voice.ps1`, 입장 검사 `art-source/voice.mjs`, 이야기 교실·말 랠리 `scripts/generate-*.py`, 리듬 `scripts/build-narration.py`)는 옛 목소리로 되돌리므로 그 뒤에는 쓰지 않는다.
