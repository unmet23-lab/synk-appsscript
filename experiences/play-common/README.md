# 공통 미니게임 컬렉션

레이싱·말의 리듬·바람길·빈칸 베기·입장 검사·선생님이 돌아왔다(이야기 교실)·말 랠리·주문 폭주는 같은 브라우저 origin에서 `SYNK_PLAY_COLLECTION_V1`을 함께 사용한다. 소유·장착·지갑·미니게임 지급 규칙의 원본은 `../korean-racing/garage-core.js`이고, 레이싱의 오늘 미션·레이스 지급은 그 위의 `../korean-racing/garage.js`가 더한다(레이싱이 쓰는 이름은 그대로다). 개인 계정·다른 기기와 동기화하는 지갑은 아니다.

`node experiences/play-common/build-collection.mjs`는 `garage-core.js`만 기존 로컬 esbuild로 묶고, `collection-adapter.js`를 붙여 classic script인 `collection.js`를 만든다. 생성본은 리듬·바람길·빈칸 베기·입장 검사·이야기 교실·말 랠리 폴더에 같은 바이트로 복사한다(시험이 같은지 본다). 레이싱의 코스·낱말 자료를 묶지 않아 약 12.5KB다(2026-10-04 전 347KB). 미니게임은 레이싱 미션을 다시 만들 수 없으므로 저장된 미션을 모양만 확인해 그대로 둔다(`keepMission`). 레이싱이 열 때 자기 자료로 다시 확인한다. 원본 규칙을 바꾼 뒤에는 빌드를 다시 실행하고, 생성본을 직접 편집하지 않는다.

지급은 그 게임의 「한 판을 끝까지 마쳤다」 조건 뒤에만 한다: 리듬은 곡 끝, 바람길은 90초 등불 여행 완주, 빈칸 베기는 한 판 끝, 입장 검사는 근무 끝, 이야기 교실은 이야기 끝, 말 랠리는 한 판(12번 주고받기) 끝, 주문 폭주는 본 영업(한가한 오픈 8개·점심 러시 90초) 끝(3개짜리 새 주문 연습은 받지 않음, 2026-10-06). 완주 15 + 정답 비율 × 10(반올림)이라 문장·손님 수가 많은 판이 더 받지 않고, 다 맞힌 판은 어느 게임이든 25다(2026-10-04 전 「정답 1개당 2」와 리듬 다섯 문항에서는 같다). 이야기 교실의 정답은 도움 없이 첫 시도에 옮긴 부탁 수다. 말 랠리의 정답은 결과 화면의 맞힌 수 그대로다(다시 듣기·글로 보기를 쓴 답과 소리를 끄고 한 판도 센다 — 코인은 놀이 보상이고, 도움은 학습 기록이 따로 가린다). 연습 공은 세지 않고, 그만두기로 나간 판은 받지 않는다. 자동 시연·중도 종료·충돌 종료·입장 검사의 연수 근무(안내를 따라 찍은 도장)는 지급하지 않는다. WORLD 과제 판도 끝까지 마치면 받는다(코인은 놀이 보상이고 과제 결과와 따로 남는다). 모든 게임이 공통 하루 10회 완주 지급 한도와 중복 완주 장부를 쓰며, 한도를 넘으면 「오늘의 완주 코인 10회분을 모두 받았어요」라고 말한다. 이야기 교실은 한 판의 번호를 저장에 남겨 다시 열거나 결말을 다시 그려도 두 번 받지 않는다. 미니게임은 레이싱의 첫 통과·오늘의 미션·오답 교정 기록을 바꾸지 않고, 게임 조작 결과를 한국어 이해도나 TOPIK 성적으로 해석하지 않는다. 코인은 학습 기록에 쓰지 않는다.

꾸미기 종류(2026-10-07): 레이싱의 차량·도색·휠·부스터·배지에 말 랠리의 라켓(`racket`)·공(`ball`)을 더했다. 기본은 무료(코랄 라켓·크림 공, 원래 모습)이고 펠트 색 셋씩을 35~50코인에 판다. 그전에 저장한 지갑은 새 종류만 무료 기본값을 받는다(`normalizeGarage`가 칸마다 따로 되살림). 어댑터는 `buy(itemId)`(레이싱 차고와 같은 `buyItem` 규칙, 맞는 구매만 저장)와 `equip(itemId)`를 낸다. 저장 공간을 읽을 수 없으면 둘 다 `storage-unavailable`이다(빈 지갑으로 읽어 ‘코인 부족’이라 하지 않게). 레이싱 차고에는 「말 랠리」 칸으로 나온다.

코스트 챔피언 배지는 실제로 소유하고 장착한 경우에만 그 이름을 작은 글자로 보인다(그림 기호를 쓰지 않음). 시작 화면에는 공통 코인 잔액과 차고 링크를 한 줄로, 결과 화면에는 받은 공통 코인과 차고 링크를 표시한다. 저장 공간에서 잔액을 읽을 수 없으면 `코인저장불가`를 표시하고, `collection.js`를 읽지 못한 화면은 코인 줄을 숨긴다. 기존 학습 기록 초기화는 차고 소유품·코인을 지우지 않는다.

같은 origin 경로: 레이싱 로컬 서버의 `/play/rhythm/`·`/play/runner/`, 통합 패키지의 `/배포위치/play/rhythm/`·`/배포위치/play/runner/`, 공개 사이트의 `/try/rhythm/`·`/try/runner/`, 학습 허브의 `/korean-rhythm/`·`/korean-runner/`·`/blank-slice/`·`/entry-check/`·`/story-classroom/`(차고 링크는 옆의 `/korean-racing/?garage=1`). 내장 게임의 차고 링크는 `/배포위치/?garage=1`로 돌아간다. 말 랠리는 공개 사이트의 `/try/talk-rally/`에서 같은 지갑을 쓴다(2026-10-05). 학습 허브에는 아직 없지만, 들어가면 `/talk-rally/` 옆의 레이싱 차고로 이어지게 경로 규칙에 넣어 두었다. 서로 다른 포트로 실행한 독립 게임은 저장 공간도 서로 다르다.
