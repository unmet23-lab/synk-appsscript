# 공통 미니게임 컬렉션

레이싱·말의 리듬·바람길은 같은 브라우저 origin에서 `SYNK_PLAY_COLLECTION_V1`을 함께 사용한다. 구매·소유·장착·지급 규칙의 원본은 `../korean-racing/garage.js`다. 개인 계정·다른 기기와 동기화하는 지갑은 아니다.

`node experiences/play-common/build-collection.mjs`는 원본을 기존 로컬 esbuild로 묶고, `collection-adapter.js`를 붙여 classic script인 `collection.js`를 만든다. 생성본은 리듬·바람길 폴더에 같은 바이트로 복사한다. 게임 HTML은 해당 폴더의 생성본을 불러오므로 독립 패키지에서도 지급 기능이 외부 모듈 요청에 의존하지 않는다. 원본 차고 규칙·학습 문항을 바꾼 뒤에는 빌드를 다시 실행한다. 생성본의 규칙을 직접 편집하지 않는다.

리듬은 곡을 끝까지 연주한 결과에서, 바람길은 90초 등불 여행을 완주한 결과에서만 완주 15 + 정답 또는 수행한 부탁 1개당 2코인을 모은다. 자동 시연·중도 종료·충돌 종료·결과의 추가 듣기는 지급하지 않는다. 세 게임은 공통 하루 10회 완주 지급 한도와 중복 완주 장부를 사용한다. 리듬·바람길은 레이싱의 첫 통과·오늘의 미션·오답 교정 기록을 바꾸지 않는다. 게임 조작 결과를 한국어 이해도나 TOPIK 성적으로 새롭게 해석하지 않는다.

코스트 챔피언 배지는 실제로 소유하고 장착한 경우에만 작은 표식으로 보인다. 시작 화면에는 공통 코인 잔액과 차고 링크를 한 줄로, 결과 화면에는 받은 공통 코인과 차고 링크를 표시한다. 저장 공간에서 잔액을 읽을 수 없으면 `코인저장불가`를 표시한다. 기존 학습 기록 초기화는 차고 소유품·코인을 지우지 않는다.

같은 origin 경로: 레이싱 로컬 서버의 `/play/rhythm/`·`/play/runner/`, 통합 패키지의 `/배포위치/play/rhythm/`·`/배포위치/play/runner/`, 공개 사이트의 `/try/rhythm/`·`/try/runner/`, 학습 허브의 `/korean-rhythm/`·`/korean-runner/`. 내장 게임의 차고 링크는 `/배포위치/?garage=1`로 돌아간다. 서로 다른 포트로 실행한 독립 게임은 저장 공간도 서로 다르다.
