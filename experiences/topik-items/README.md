# TOPIK 문항 묶음

TOPIK I·II 연습 문항(모두 자체 창작)과 그 AI 2중 검수 기록을 두는 곳이다. 2026-10-20 결정([결정 표](../../docs/_ops/결정.md) 10-20 「교원 검수를 AI로」·「TOPIK II 범위」)에 따라 만든다.

- `review/existing-verdicts.json` — 기존 게임·진단 문항(빈칸 베기·입장 검사·싱크타운 읽기 등)의 검수 판정. WORLD는 `verdict: "pass"`인 문항만 연습에 낸다(허용 목록). 비어 있으면 아직 판정 전이다.

스키마·대응표·검수 절차는 이어서 이 문서에 적는다.
