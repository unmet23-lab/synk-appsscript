# 실시간 음성 상황극 — 팬사인회 시제품 (2026-10-30)

학습자가 말하면 가상 아이돌 「하온」(GPT-Live · cedar)이 바로 받아치고, 끝나면 전사로 글 피드백(미션 판정 · 잘한 말 · 고칠 말 · 다음에 써 볼 말)을 주는 **로컬 시제품**이다. 학생에게 여는 배포가 아니다(유호님 말씀 뒤에만). 설계와 Fable 설계 검토 반영은 [설계.md](설계.md), 엔진 · 목소리를 고른 근거는 [조사 · 듣기 시험](../synk-world-app/qa/realtime-roleplay-20261029/조사.md)과 [결정 표](../../docs/_ops/결정.md) 10-30.

## 쓰는 법

```
node experiences/realtime-roleplay/server.mjs
```

→ 브라우저로 `http://127.0.0.1:5250/` → 「하온에게 말 걸기」 → 마이크 허락. 헤드폰을 쓰면 하온 목소리가 마이크로 다시 들어가지 않는다. 키는 서버만 쥔다(`~/SYNK_보안/openai_키목록.json`, synk.yuh 먼저).

- `?길=gpt-live|realtime-mini|글` — 예산 계량기 대신 길을 고정한다(시험용).
- `?시험=1` — 마이크 대신 견본 학습자 소리 3줄(`public/견본/`, 듣기 시험의 TTS)을 넣고 재생은 음소거한다. 받은 · 보낸 소리 바이트와 사건 기록(`__상황극기록`)이 남는다.
- 환경 변수: `SYNK_ROLEPLAY_BUDGET_USD`(기본 50) · `SYNK_ROLEPLAY_RESET_DAY`(예산 주기 시작 날, 기본 1 — 구독 결제일에 맞춘다) · `SYNK_ROLEPLAY_LEDGER`(장부, 기본 `.tmp/realtime-roleplay/예산장부.jsonl`) · `PORT`.
- 시험: `node --test tests/실시간상황극.test.mjs`(예산 문턱 · 주기 · 끝 없는 세션 · 크레딧 바닥 · 자막 차례 나누기 · 취소된 답 지우기 · 피드백 검사 · 서버 길과 키 값 노출 없음, 가짜 OpenAI).

## 10-30 끝까지 시험(이 노트북, ego 브라우저 · 견본 소리)

| 길 | 결과 | 쓴 값 |
|---|---|---|
| GPT-Live cedar | 하온이 먼저 인사 → 세 줄 모두 자연스럽게 받아침(학습자 쉼에 「응응.」 맞장구), 53초, 끝 `close_requested`, 미션 5/6(끝 인사는 견본에 없음) · 잘한 말 3 · 버림 0 | 세션 $0.044 + 피드백 $0.002 |
| Realtime 2.1 mini | 연결 · 인사 · 받아쓰기 · 피드백까지 됨. 답이 덜 자연스럽다(「볼러루야」 · 맥락 없는 말 한 줄) — 예산 70% 넘을 때의 내려가는 길로만 | $0.017 |
| 글(gpt-6-luna) | 6/6 미션, 하온이 마무리 인사를 한 번 더 되풀이함(다음 판에서 지시 손질) | $0.0004 |

- 받아쓰기는 견본 TTS 「볼로르」를 「볼롤」로 적었다 — 억양 있는 실제 학습자에서는 더 틀릴 수 있어 돌아보기에 「받아 적은 글은 다를 수 있어요」를 둔다.
- 처음 두 판은 시험 트랙이 완전한 무음이라 GPT-Live 시간이 흐르지 않아 첫 인사가 안 나왔다 → 시험 모드는 아주 작은 바탕 소리를 흘린다([현장 노트 AI CLI](../../docs/현장노트/AI_CLI.md#openai-실시간-음성gpt-live--realtime)).
