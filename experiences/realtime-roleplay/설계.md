# 실시간 음성 상황극 — 한 장면 시제품 설계 (2026-10-30)

> **10-30 오후부터 기본 길은 Gemini 3.8 Live Kore다(§10, 결정 「MVP 모델」).** §1~9는 GPT-Live로 처음 만든 판의 설계이고 그 길은 몫이 막힐 때의 다음 길로 그대로 남는다.
>
> 유호님 10-30 「시제품 먼저」(GPT-Live cedar로 팬미팅 장면부터). 근거: [조사 · 듣기 시험](../synk-world-app/qa/realtime-roleplay-20261029/조사.md), [결정 표](../../docs/_ops/결정.md) 10-30 「상대역 목소리 귀 평가」. **로컬 시제품이다 — 학생에게 여는 배포는 유호님 말씀 뒤에만.**

## 1. 목적과 성공 기준

- 학습자가 마이크로 말하면 가상 아이돌 「하온」(GPT-Live · cedar)이 바로 받아치는 팬사인회 상황극을 한 장면 끝까지 해 보고, 끝나면 전사로 글 피드백(표현 · 문법 · 역할 수행)을 받는다.
- 성공 기준: ① 유호님이 이 노트북 브라우저에서 처음부터 피드백까지 막힘없이 끝낸다 ② 상대역이 학습자 쉼에 끼어들지 않고 1~2초 안에 받아친다(듣기 시험 GPT-Live 1.2초) ③ 피드백에 발음 점수 · 「지금 기분」 추론이 없다 ④ 공급사(엔진)를 설정 한 줄로 바꿔 끼운다 ⑤ 예산이 70%를 넘으면 mini, 95%를 넘으면 글 상황극으로 저절로 내려간다.

## 3. 사용자 흐름(한 화면, 상태 다섯)

1. **준비:** 장면 카드(팬사인회 · 상대역 하온 · 나는 몽골에서 온 팬), 미션 여섯(인사 · 이름 · 어디서 왔는지 · 좋아하는 것 · 사인 부탁 · 끝 인사, 영어 뜻 한 줄씩 — 몽골어는 현지어 검수 뒤), 「헤드폰을 쓰면 더 잘 들려요」, 예산 계량기(이번 달 쓴 값 · 지금 길: 음성 / 가벼운 음성 / 글), 「시작」.
2. **연결 중:** 마이크 허락 → 서버가 세션을 만든다 → 하온이 먼저 인사한다.
3. **대화 중:** 하온 · 나의 자막이 실시간으로 쌓인다, 미션 칸이 대화 뒤 판정 전까지는 비어 있다(실시간 판정 안 함), 「힌트」(지금 남은 미션의 예문 한 줄), 「끝내기」. 3:40에 브라우저가 데이터 채널로 마무리 지시(`session.instructions.append`)를 보내고, 그 뒤 하온 작별이 끝나고 2.5초 조용하면 저절로 끝낸다(하온이 스스로 마무리 인사를 해도 같다 · 작별에 학습자가 답하면 그 말이 멎고 2.5초 — §10.11). 4:15에는 무조건 끝낸다 — 서버는 세션에 손이 없다(데이터 채널은 브라우저 ↔ OpenAI).
4. **끝내는 중:** `session.close` → `session.closed`(쓴 초) → 서버가 장부에 값을 적고 피드백을 만든다.
5. **피드백:** 미션 판정(해냄 · 아직), 잘한 표현 2~3, 고칠 말(내 말 → 더 자연스러운 말 · 이유 한 줄) 최대 3, 다음에 써 볼 말 2, 전사 전체. 「다시 하기」.

글 상황극(95% 넘음): 같은 화면에서 마이크 대신 입력창 — 하온이 글로 답하고, 끝나면 같은 피드백.

## 4. 구조 — 얇은 연결 층과 예산 계량기

```
브라우저(public/)                         로컬 서버(server.mjs, 127.0.0.1)                 공급사
 연결층.mjs ── 시작(sdp) ──────────────▶ POST /api/연결 ── 길 고르기(예산) ──▶ gpt-live-1  POST /v1/live/sessions(JSON)
   ├ 음성: WebRTC 트랙(마이크 ↔ 상대역)                                         gpt-realtime-2.1-mini POST /v1/realtime/calls(multipart)
   ├ 자막: 데이터 채널 이벤트 → 공통 꼴로                                        (키는 서버만 — openai_키목록.json, 값은 찍지 않음)
   └ 끝: session.close → 쓴 초 ───────────▶ POST /api/끝 ── 장부 적기 · 피드백(gpt-6.1-terra) ──▶ /v1/responses
 글 상황극 ───────────────────────────▶ POST /api/글차례 ── gpt-6-luna ──▶ /v1/responses
```

- **연결 층 인터페이스(브라우저):** `연결 = 열기({길, 오디오입력})` → `연결.on('자막', {누가:'상대'|'나', 글, 끝})` · `on('상태', …)` · `on('끝', {초, 사용})`, `연결.끝내기()`. 길마다 다른 것은 표 하나(`공급사표`): 서버 길 이름, 자막 이벤트 이름(GPT-Live `session.output_transcript.delta`/`session.input_transcript.delta`, Realtime `response.output_audio_transcript.delta`/`conversation.item.input_audio_transcription.completed`), 시작 명령(GPT-Live는 `session.instructions.append`로 첫 인사, Realtime은 `response.create`), 끝 명령. 새 공급사는 이 표에 한 줄 + 서버 `공급사.mjs`에 세션 만들기 함수 하나.
- **서버 공급사(`공급사.mjs`):** `세션만들기(길, sdp, 장면)` → `{세션, sdp답}`. GPT-Live는 `{session:{model, instructions, input:[developer 첫 인사], audio:{output:{voice:'cedar'}}, delegation:{type:'client'}}, transport:{type:'webrtc', sdp}}`. mini는 multipart(`sdp`, `session`). 둘 다 `OpenAI-Safety-Identifier` 머리(시제품은 고정값), Responses는 몸통 `safety_identifier`.
- **예산 계량기(`예산.mjs`):** 장부 `.tmp/realtime-roleplay/예산장부.jsonl`. `/api/연결`이 「세션시작」(GPT-Live는 15초 선과금)을, `/api/끝`이 같은 세션의 나머지를 적고 두 번째 끝은 거절한다. 끝 보고가 없으면(탭 닫힘은 sendBeacon으로 지난 초를 보냄, 새 연결이 오면 지난 세션을 지난 시간으로 닫음) 5분 뒤 상한+15초로 센다. 주기는 리셋 날(`SYNK_ROLEPLAY_RESET_DAY`, 구독 결제일) 기준. 429 `credit_balance_exhausted`면 「크레딧바닥」을 적고 그 주기는 글 길. 예산 B는 `SYNK_ROLEPLAY_BUDGET_USD`(기본 $50 — synk.yuh 크레딧 $60은 광고 콘티와 나눠 쓴다). 쓴 값 < 70% → `gpt-live`, 70~95% → `realtime-mini`, ≥ 95% → `글`, ≥ 100% → 글도 하루 10차례까지. 값: GPT-Live 분당 $0.05(WebRTC 시작 때 15초 선과금은 진행 초에서 빠짐 — 세션 최소 15초로 셈), mini 음성 입력 $10 · 출력 $20 /100만, 글 모델 토큰 값. **이 장부는 이 서버로 돈 세션만 센다** — 조직 전체 사용량은 제한 키로 읽을 수 없다(설계 한계, 화면에 적는다). 시험용 `?길=gpt-live|realtime-mini|글` 강제.
- **피드백(`피드백.mjs`):** 전사(나 · 상대 차례 목록)만 `gpt-6.1-terra`(Responses, JSON 스키마 출력)에 넣는다. 서버가 검사한다: 미션 「해냄」은 전사에 있는 내 말 인용이 있어야 함, 「잘한 말 · 고칠 말」의 내 말은 전사에 실제로 있는 글이어야 함, 설명 칸(왜 · 한마디)에 발음 · 억양 · 점수 · 기분 · 감정 추론 꼴이 있으면 버림(학습자가 실제로 한 「기분이 좋아요」 인용은 둔다), 받아쓰기 차이(받침 · 모음 하나)는 고칠 말로 고르지 않게 지시, 각 칸 최대 개수. 실패하면 「피드백을 만들지 못했어요」와 전사만.
- **장면(`장면.mjs`):** 팬사인회 — 하온(가상 아이돌, 실존 인물 아님), 연기 지시, 미션 다섯 · 예문(힌트), 첫 인사, 4분 상한. 지시문: 한국어만 · 한 번에 1~2문장 · 쉬운 말(TOPIK 1~2) · 쉼에 끼어들지 않기 · 틀려도 고치지 말고 자연스럽게 받기 · 못 알아들으면 더 쉽게 다시 · 미션 쪽으로 자연스럽게 이끌기 · 이름과 나라 말고 개인 정보 묻지 않기 · 실존 아이돌 흉내 금지 · 끝나면 마무리 인사.

## 5. 데이터 · 개인정보

- 소리는 저장하지 않는다(WebRTC로 브라우저 ↔ OpenAI). 전사는 피드백을 만드는 동안 서버 메모리에만 두고 장부에는 시간 · 값만 적는다. OpenAI API는 기본으로 학습에 쓰지 않고 남용 감시 기록 30일(조사.md). 학생 계정 · 나이 확인 · 동의는 학생에게 열 때의 일(만 14세 미만은 무보관 승인 먼저 — 조사 위험).
- 서버는 127.0.0.1에만 열고 `Origin` 검사를 한다(다른 사람에게 열 때는 계정 확인 · 요청 한도가 먼저).

## 9. 설계 검토 반영(Fable 10-30, 12건)

| # | 지적 | 처리 |
|---|---|---|
| 1 P1 | GPT-Live 전사에 차례 끝 표시가 없다 · Realtime 취소 응답 | 연결층이 화자 교대 + 같은 사람 1.3초 넘는 쉼(세션 시각 ms)으로 줄을 닫고, 늦게 온 조각은 시각 자리에 넣는다. Realtime `response.done` cancelled 응답의 자막을 지운다. 시험 둘 |
| 2 P1 | 장부가 끝에서만 적힌다 | 연결 때 세션시작 줄 · 끝에 나머지(같은 세션 두 번 거절) · sendBeacon · 새 연결 때 지난 세션 닫기 · 5분 뒤 상한+15초. 시험 |
| 3 P1 | 4분 상한의 서버 지시는 불가능 | 브라우저 3:40 마무리 지시 → 말 멎으면 끝 · 4:15 강제 끝(§3) |
| 4 P1 | mini 세션 설정 · 값 | 세션 JSON에 semantic_vad low · 받아쓰기 ko · voice, response.done(취소 포함) usage 누적 + 받아쓰기 분당 어림 |
| 5 P1 | 시험 모드가 Chromium에서 멈춤 | AudioContext는 클릭 안에서 만들고 resume, 시험은 getUserMedia 안 부름, 받은 소리 크기 + 자막이 멎은 뒤 다음 줄, getStats 받은 · 보낸 둘 다 |
| 6 P2 | 실제 데모(스피커 · 마이크 · 첫 인사 잘림) | 에코 제거 제약, 마이크 막대, NotAllowed/NotFound 안내, ICE 붙은 뒤 첫 인사. 마이크 고르기 · TURN은 다음 판 |
| 7 P2 | 받아쓰기 오류가 학습자 탓 | 피드백 지시에 받아쓰기 차이 규칙, 미션은 인용 필수, 돌아보기에 「받아 적은 글은 다를 수 있어요」 한 줄(「제 말과 달라요」 단추는 다음 판) |
| 8 P2 | 감정 거름망이 너무 날카롭다 | 거름은 설명 칸에만, 추론 꼴 · 점수 · 발음으로 좁힘, 하온 지시에 기분 짐작 금지 |
| 9 P2 | 모국어 · 막힘 · 카드 뜻 | 「○○라고 말해 봐요」 한 문장 · 8초 말 없으면 쉬운 질문 · 영어 뜻 · 별명도 괜찮아요 |
| 10 P2 | 예산 주기 · 크레딧 바닥 | 리셋 날 설정 · 크레딧바닥 줄 → 그 주기 글 길. 시험 |
| 11 P3 | safety id 자리 · 미션 수 · 로그 | Responses는 몸통 칸, 미션 여섯으로 고침, 서버 로그에 전사 안 찍음 |
| 12 P3 | mini는 줄여도 된다 | 코드는 두고 끝까지 시험은 한 판만(성공 기준 ④는 gpt-live ↔ 글로 증명) |

## 10. Gemini 3.8 Live 길 — MVP 기본 길(10-30 오후)

> [결정 표](../../docs/_ops/결정.md) 10-30 「MVP 모델」: 유호님 「지금은 mvp단계니까 … 일단 이대로 진행해」 — MVP 상대역은 귀 평가 1위 **Gemini 3.8 Live Kore**. GPT-Live cedar · Realtime mini · 글 길은 연결 층에 그대로 두고, Gemini 무료 몫(429)이 막히면 GPT-Live로 넘긴다. 출시 때 그때 가장 좋은 모델로 다시 고른다.

### 10.1 목적 · 성공 기준

- 유호님이 `node experiences/realtime-roleplay/server.mjs` → 「하온에게 말 걸기」만 누르면 Kore 하온과 대화하고 돌아보기까지 받는다(길을 고르지 않는다).
- 기준: ① 표준 키는 서버만 쥐고 브라우저에는 1회용 임시 토큰만 간다 ② 첫 인사 2초 안팎, 학습자 쉼을 1초 기다린다(듣기 시험 설정 그대로 — 끼어듦 0) ③ 자막 · 미션 판정 · 피드백 · 장부는 다른 길과 같은 꼴 ④ 무료 몫 429면 저절로 GPT-Live ⑤ 기존 시험 9개 그대로 통과 + 새 시험.

### 10.3 실측(10-30 이 세션, 무료 키 · 노드 WebSocket에 브라우저 Origin)

- 토큰 만들기 200 · 0.45~0.5초, 답은 `name`(`auth_tokens/…`)뿐. 제한 소켓(v1beta) `setupComplete` 1.1~2.0초, 글 차례 첫 인사 소리는 그 뒤 0.5~0.8초, 24k PCM.
- 토큰에 넣은 설정이 브라우저 setup을 덮는다 — 브라우저가 다른 지시 · Puck을 보내도 토큰의 지시대로 답하고 음높이 220Hz(Kore 단독 192Hz, 여성대). 브라우저가 `setup: {}`만 보내도 된다. `fieldMask`를 일부 칸만 주면 400.
- 같은 토큰 두 번째 연결은 `1011 Token has been used too many times`.
- 자막 글은 소리보다 몇 초 먼저 다 온다(`generationComplete` 3.3초 · `turnComplete` 7.9초 — 소리는 거의 실제 속도로 흐른다). → 자동 끝내기는 자막 시각이 아니라 **재생이 끝난 시각** 기준.
- 서버가 `voiceActivity`(`ACTIVITY_START` · `ACTIVITY_END`)를 따로 보낸다. 학습자 받아쓰기(`inputTranscription`)는 말이 끝날 때 한 번에 오고 답 소리와 거의 같이 온다 → 말 시작 신호에 학습자 줄 자리를 먼저 놓는다(Realtime의 `speech_started`와 같은 셈).
- 대화 중 `clientContent`(`turnComplete: false`)로 마무리 지시를 넣어도 소리 대화는 멈추지 않고, 다음 답에서 「오늘 와 줘서 진짜 고마워요. 다음에 또 만나요, 약속!」이 나왔다.
- `usageMetadata`는 차례마다 온다(맥락이 쌓여 입력 927 → 1,965), 생각 토큰(`thoughtsTokenCount`)도 있다.

### 10.5 장부 · 계량

- 길 고르기: Gemini 무료 키가 있고 최근 10분 안에 Gemini 「몫바닥」 줄이 없으면 `gemini-live`(무료라 예산 비율과 상관없이 먼저). 아니면 지금 규칙(< 70% GPT-Live · < 95% mini · 글). 10분 뒤에는 다시 Gemini를 먼저 해 본다(하루 몫인지 분당 몫인지 닫힘 까닭으로 가리지 않는다 — 실패 한 번이 1~2초라 다시 해 보는 편이 싸다).
- 줄: 세션시작 `{길:'gemini-live', 세션, USD:0}` · 세션 `{…, 초, 사용, USD:0, 유료였다면USD, 등급:'무료'}` · 몫바닥 `{길:'gemini-live', USD:0, 까닭}`. 끝 보고 없는 Gemini 세션은 0원이라 덧셈 없음.
- 유료였다면 값: 글 입력 $0.75 · 음성 입력 $3 · 글 출력(생각 포함) $4.50 · 음성 출력 $12 /100만(듣기 시험과 같은 표).
- **무료 등급은 보낸 소리 · 글이 구글 제품 개선(학습)에 쓰인다** — 유호님 시험에만 쓴다. 학생에게 열기 전 유료 등급으로(돈이라 유호님 결정) — 그때 유료 키로 바꾸고 USD를 실제 값으로 센다.
- `/api/넘김`(몫 · 연결 실패 알림)은 브라우저 말만 믿는다(127.0.0.1 · Origin 검사 안이라 괜찮다 — 거짓이면 10분 동안 GPT-Live로 돈이 나갈 뿐).

### 10.7 시험 계획

- 단위: 공급사표 Gemini 사건 → 자막(말 시작 자리에 늦게 온 받아쓰기가 들어감 · interrupted면 그 답 지움 · 생각 · 사용 더하기), 몫 닫힘 까닭 가르기(「Token has been used too many times」는 몫이 아님), `gemini값`, 계량(키 있으면 gemini · 키 없음 · 몫바닥 10분 안 · 10분 뒤 · 예산 넘어도 gemini).
- 서버(가짜 Gemini): 토큰 요청 몸통(uses 1 · 만료 둘 · 설정 잠금 · 모델 · Kore · 지시문 · 전사 설정) · 키는 머리로만 · 응답 · 장부에 키 없음 · 세션시작 0원 · /api/끝 0원 + 유료였다면 · 같은 세션 두 번 끝 409 · 토큰 429 → 몫바닥 줄 + 428 gpt-live · 강제 길이면 넘기지 않음 · /api/넘김 뒤 다음 연결은 GPT-Live · 몫 말고 다른 토큰 실패는 연결실패 줄만.
- 기존 서버 시험은 Gemini 키 경로를 없는 파일로 두어 그대로 돈다.
- 끝까지: ego 브라우저 `?시험=1&길=gemini-live`(견본 3줄) → 자막 순서 · 받은/보낸 소리 · 장부 · 돌아보기 · 콘솔 오류 0, 이어서 `?시험=1`(기본 길이 Gemini인지), 1440 · 390 캡처.

### 10.11 검수 뒤 고침(10-30 새벽, Claude — 커밋 62b7358cd를 다시 돌려 봄)

| 고침 | 다시 돌린 결과 |
|---|---|
| 자동 끝 = 상대 소리 끝과 **학습자 마이크 말소리 끝(화면 마이크 재기 RMS 0.02 — 연결 층 침묵 재기와 같은 문턱) 중 늦은 쪽**에서 2.5초. 4:15 무조건 끝은 그대로(바탕 소리가 문턱을 늘 넘는 방이면 거기까지 간다) | Gemini 상한 40: 셋째 줄까지 받아 적고 하온이 받아 준 뒤 2.5초에 1000 닫힘(55~60초). GPT-Live 회귀 상한 40: 같음, `close_requested`, 콘솔 오류 0 |

### 10.12 유호님 첫 판 · 준비 직후 끊김과 OpenAI 크레딧 바닥(10-30 오후, Claude)

유호님이 크롬에서 처음 해 본 판(16:14, 마이크 허락 16:14:35)이 Gemini 준비(setupComplete) 0.5초 안에 끝났다. 장부에는 `세션시작` 2초 뒤 `초 0 · 끝확인 false` 세션 줄만 남았고, 화면은 「내가 한 말이 들리지 않아 돌아볼 것이 없어요」라 끊긴 것으로 보이지 않았다. 닫힘 코드는 화면 기록에만 있다 사라져 까닭은 모른다 — 가짜 마이크(`--use-fake-device-for-media-stream`)로 같은 실제 마이크 길을 헤드리스로 돌리면 늘 잘 된다.

| 고침 | 확인 |

### 10.13 실제 마이크로 두 판(10-30 밤, Claude)

유호님 「이어서 해」 뒤, §10.12의 0.5초 끊김을 진짜 마이크로 재현해 보려고 가짜 장치 플래그 없이 돌렸다. 설치된 크롬 156(그날 20:21 업데이트) 헤드리스 · 새 프로필 · 마이크 허락은 `grantPermissions`. 서버는 시험 스크립트 안에서 5251로 따로 열고 장부도 따로 두었다(부모 세션이 유호님용으로 켜 둔 5250 서버 · 장부는 건드리지 않음).

| 판 | 결과 |
|---|---|
| 크롬 소리 끔 · 20초 | 마이크 `기본값 - 마이크 배열(Realtek(R) Audio)` 48 kHz · 모노 · 메아리 제거 켜짐 → 16k 일꾼. 토큰 0.5초 → 준비 → 하온 첫 소리 약 1초 뒤 → 인사 → 8초 침묵 도움 → 끝내기. 끊김 없음, 장부 17초 · 끝확인 true · 0원(유료였다면 $0.0032) |
| 크롬 소리 켬 · 하온 인사 뒤 학습자 견본 한 줄을 스피커로 · 30초 | 같은 흐름에 끊김 없음(27초 · 끝확인 true · 유료였다면 $0.0067). 다만 노트북 스피커가 음량 0% · 음소거였다(마이크는 82% · 켜짐). 하온 소리도 학습자 줄도 방에 나가지 않아 받아쓰기 0 — 메아리와 실제 말 받아쓰기는 재지 못했다 |

- 0.5초 끊김은 진짜 마이크로도 재현되지 않았다. 유호님 판과 남은 차이는 유호님 크롬 프로필(확장), 그때 판이던 크롬 155, 서버 쪽 일시 끊김이다. 다음에 또 끊기면 그 세션 줄의 `까닭` · `기록`에 닫힘 코드가 남고, 첫 말 전이면 화면이 한 번 다시 잇는다(§10.12).
- 유호님 음량은 바꾸지 않았다. 스피커 판은 스피커가 켜져 있던 10-31 저녁에 다시 쟀다(아래).
- 학습자 줄이 없어 돌아보기는 부르지 않았다(OpenAI 0원).

10-31 저녁(토 19:09), 스피커가 27%로 켜져 있어 다시 쟀다. 하온이 말을 마칠 때마다 학습자 견본 줄을 노트북 스피커로 하나씩 틀었다(크롬 소리 켬 · 86초).

|---|---|

- 같은 노트북 스피커로 학습자 소리를 넣는 시험은 이 노트북에선 안 된다. 실제 말 받아쓰기 품질은 학습자 녹음을 가짜 마이크(`--use-file-for-fake-audio-capture`)로 넣어 잰다. 장부 세션 줄에는 받아쓴 글이 남지 않으므로 장부로는 말 시작 감지 · 차례 수까지만 보인다.
