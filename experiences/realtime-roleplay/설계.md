# 실시간 음성 상황극 — 한 장면 시제품 설계 (2026-10-30)

> 유호님 10-30 「시제품 먼저」(GPT-Live cedar로 팬미팅 장면부터). 근거: [조사 · 듣기 시험](../synk-world-app/qa/realtime-roleplay-20261029/조사.md), [결정 표](../../docs/_ops/결정.md) 10-30 「상대역 목소리 귀 평가」. **로컬 시제품이다 — 학생에게 여는 배포는 유호님 말씀 뒤에만.**

## 1. 목적과 성공 기준

- 학습자가 마이크로 말하면 가상 아이돌 「하온」(GPT-Live · cedar)이 바로 받아치는 팬사인회 상황극을 한 장면 끝까지 해 보고, 끝나면 전사로 글 피드백(표현 · 문법 · 역할 수행)을 받는다.
- 성공 기준: ① 유호님이 이 노트북 브라우저에서 처음부터 피드백까지 막힘없이 끝낸다 ② 상대역이 학습자 쉼에 끼어들지 않고 1~2초 안에 받아친다(듣기 시험 GPT-Live 1.2초) ③ 피드백에 발음 점수 · 「지금 기분」 추론이 없다 ④ 공급사(엔진)를 설정 한 줄로 바꿔 끼운다 ⑤ 예산이 70%를 넘으면 mini, 95%를 넘으면 글 상황극으로 저절로 내려간다.

## 3. 사용자 흐름(한 화면, 상태 다섯)

1. **준비:** 장면 카드(팬사인회 · 상대역 하온 · 나는 몽골에서 온 팬), 미션 여섯(인사 · 이름 · 어디서 왔는지 · 좋아하는 것 · 사인 부탁 · 끝 인사, 영어 뜻 한 줄씩 — 몽골어는 현지어 검수 뒤), 「헤드폰을 쓰면 더 잘 들려요」, 예산 계량기(이번 달 쓴 값 · 지금 길: 음성 / 가벼운 음성 / 글), 「시작」.
2. **연결 중:** 마이크 허락 → 서버가 세션을 만든다 → 하온이 먼저 인사한다.
3. **대화 중:** 하온 · 나의 자막이 실시간으로 쌓인다, 미션 칸이 대화 뒤 판정 전까지는 비어 있다(실시간 판정 안 함), 「힌트」(지금 남은 미션의 예문 한 줄), 「끝내기」. 3:40에 브라우저가 데이터 채널로 마무리 지시(`session.instructions.append`)를 보내고, 하온 말이 1.3초 멎으면 저절로 끝낸다(하온이 스스로 마무리 인사를 해도 같다). 4:15에는 무조건 끝낸다 — 서버는 세션에 손이 없다(데이터 채널은 브라우저 ↔ OpenAI).
4. **끝내는 중:** `session.close` → `session.closed`(쓴 초) → 서버가 장부에 값을 적고 피드백을 만든다.
5. **피드백:** 미션 판정(해냄 · 아직), 잘한 표현 2~3, 고칠 말(내 말 → 더 자연스러운 말 · 이유 한 줄) 최대 3, 다음에 써 볼 말 2, 전사 전체. 「다시 하기」.

글 상황극(95% 넘음): 같은 화면에서 마이크 대신 입력창 — 하온이 글로 답하고, 끝나면 같은 피드백.

## 4. 구조 — 얇은 연결 층과 예산 계량기

```
브라우저(public/)                         로컬 서버(server.mjs, 127.0.0.1)                 공급사
 연결층.mjs ── 시작(sdp) ──────────────▶ POST /api/연결 ── 길 고르기(예산) ──▶ gpt-live-1  POST /v1/live/sessions(JSON)
   ├ 음성: WebRTC 트랙(마이크 ↔ 상대역)                                         gpt-realtime-2.1-mini POST /v1/realtime/calls(multipart)
   ├ 자막: 데이터 채널 이벤트 → 공통 꼴로                                        (키는 서버만 — openai_키목록.json, 값은 찍지 않음)
   └ 끝: session.close → 쓴 초 ───────────▶ POST /api/끝 ── 장부 적기 · 피드백(gpt-6.1-terra) ──▶ /v1/responses
 글 상황극 ───────────────────────────▶ POST /api/글차례 ── gpt-6-luna ──▶ /v1/responses
```

- **연결 층 인터페이스(브라우저):** `연결 = 열기({길, 오디오입력})` → `연결.on('자막', {누가:'상대'|'나', 글, 끝})` · `on('상태', …)` · `on('끝', {초, 사용})`, `연결.끝내기()`. 길마다 다른 것은 표 하나(`공급사표`): 서버 길 이름, 자막 이벤트 이름(GPT-Live `session.output_transcript.delta`/`session.input_transcript.delta`, Realtime `response.output_audio_transcript.delta`/`conversation.item.input_audio_transcription.completed`), 시작 명령(GPT-Live는 `session.instructions.append`로 첫 인사, Realtime은 `response.create`), 끝 명령. 새 공급사는 이 표에 한 줄 + 서버 `공급사.mjs`에 세션 만들기 함수 하나.
- **서버 공급사(`공급사.mjs`):** `세션만들기(길, sdp, 장면)` → `{세션, sdp답}`. GPT-Live는 `{session:{model, instructions, input:[developer 첫 인사], audio:{output:{voice:'cedar'}}, delegation:{type:'client'}}, transport:{type:'webrtc', sdp}}`. mini는 multipart(`sdp`, `session`). 둘 다 `OpenAI-Safety-Identifier` 머리(시제품은 고정값), Responses는 몸통 `safety_identifier`.
- **예산 계량기(`예산.mjs`):** 장부 `.tmp/realtime-roleplay/예산장부.jsonl`. `/api/연결`이 「세션시작」(GPT-Live는 15초 선과금)을, `/api/끝`이 같은 세션의 나머지를 적고 두 번째 끝은 거절한다. 끝 보고가 없으면(탭 닫힘은 sendBeacon으로 지난 초를 보냄, 새 연결이 오면 지난 세션을 지난 시간으로 닫음) 5분 뒤 상한+15초로 센다. 주기는 리셋 날(`SYNK_ROLEPLAY_RESET_DAY`, 구독 결제일) 기준. 429 `credit_balance_exhausted`면 「크레딧바닥」을 적고 그 주기는 글 길. 예산 B는 `SYNK_ROLEPLAY_BUDGET_USD`(기본 $50 — synk.yuh 크레딧 $60은 광고 콘티와 나눠 쓴다). 쓴 값 < 70% → `gpt-live`, 70~95% → `realtime-mini`, ≥ 95% → `글`, ≥ 100% → 글도 하루 10차례까지. 값: GPT-Live 분당 $0.05(WebRTC 시작 때 15초 선과금은 진행 초에서 빠짐 — 세션 최소 15초로 셈), mini 음성 입력 $10 · 출력 $20 /100만, 글 모델 토큰 값. **이 장부는 이 서버로 돈 세션만 센다** — 조직 전체 사용량은 제한 키로 읽을 수 없다(설계 한계, 화면에 적는다). 시험용 `?길=gpt-live|realtime-mini|글` 강제.
- **피드백(`피드백.mjs`):** 전사(나 · 상대 차례 목록)만 `gpt-6.1-terra`(Responses, JSON 스키마 출력)에 넣는다. 서버가 검사한다: 미션 「해냄」은 전사에 있는 내 말 인용이 있어야 함, 「잘한 말 · 고칠 말」의 내 말은 전사에 실제로 있는 글이어야 함, 설명 칸(왜 · 한마디)에 발음 · 억양 · 점수 · 기분 · 감정 추론 꼴이 있으면 버림(학습자가 실제로 한 「기분이 좋아요」 인용은 둔다), 받아쓰기 차이(받침 · 모음 하나)는 고칠 말로 고르지 않게 지시, 각 칸 최대 개수. 실패하면 「피드백을 만들지 못했어요」와 전사만.
- **장면(`장면.mjs`):** 팬사인회 — 하온(가상 아이돌, 실존 인물 아님), 연기 지시, 미션 다섯 · 예문(힌트), 첫 인사, 4분 상한. 지시문: 한국어만 · 한 번에 1~2문장 · 쉬운 말(TOPIK 1~2) · 쉼에 끼어들지 않기 · 틀려도 고치지 말고 자연스럽게 받기 · 못 알아들으면 더 쉽게 다시 · 미션 쪽으로 자연스럽게 이끌기 · 이름과 나라 말고 개인 정보 묻지 않기 · 실존 아이돌 흉내 금지 · 끝나면 마무리 인사.

## 5. 데이터 · 개인정보

- 소리는 저장하지 않는다(WebRTC로 브라우저 ↔ OpenAI). 전사는 피드백을 만드는 동안 서버 메모리에만 두고 장부에는 시간 · 값만 적는다. OpenAI API는 기본으로 학습에 쓰지 않고 남용 감시 기록 30일(조사.md). 학생 계정 · 나이 확인 · 동의는 학생에게 열 때의 일(만 14세 미만은 무보관 승인 먼저 — 조사 위험).
- 서버는 127.0.0.1에만 열고 `Origin` 검사를 한다(다른 사람에게 열 때는 계정 확인 · 요청 한도가 먼저).

## 9. 설계 검토 반영(Fable 10-30, 12건)

| # | 지적 | 처리 |
|---|---|---|
| 1 P1 | GPT-Live 전사에 차례 끝 표시가 없다 · Realtime 취소 응답 | 연결층이 화자 교대 + 같은 사람 1.3초 넘는 쉼(세션 시각 ms)으로 줄을 닫고, 늦게 온 조각은 시각 자리에 넣는다. Realtime `response.done` cancelled 응답의 자막을 지운다. 시험 둘 |
| 2 P1 | 장부가 끝에서만 적힌다 | 연결 때 세션시작 줄 · 끝에 나머지(같은 세션 두 번 거절) · sendBeacon · 새 연결 때 지난 세션 닫기 · 5분 뒤 상한+15초. 시험 |
| 3 P1 | 4분 상한의 서버 지시는 불가능 | 브라우저 3:40 마무리 지시 → 말 멎으면 끝 · 4:15 강제 끝(§3) |
| 4 P1 | mini 세션 설정 · 값 | 세션 JSON에 semantic_vad low · 받아쓰기 ko · voice, response.done(취소 포함) usage 누적 + 받아쓰기 분당 어림 |
| 5 P1 | 시험 모드가 Chromium에서 멈춤 | AudioContext는 클릭 안에서 만들고 resume, 시험은 getUserMedia 안 부름, 받은 소리 크기 + 자막이 멎은 뒤 다음 줄, getStats 받은 · 보낸 둘 다 |
| 6 P2 | 실제 데모(스피커 · 마이크 · 첫 인사 잘림) | 에코 제거 제약, 마이크 막대, NotAllowed/NotFound 안내, ICE 붙은 뒤 첫 인사. 마이크 고르기 · TURN은 다음 판 |
| 7 P2 | 받아쓰기 오류가 학습자 탓 | 피드백 지시에 받아쓰기 차이 규칙, 미션은 인용 필수, 돌아보기에 「받아 적은 글은 다를 수 있어요」 한 줄(「제 말과 달라요」 단추는 다음 판) |
| 8 P2 | 감정 거름망이 너무 날카롭다 | 거름은 설명 칸에만, 추론 꼴 · 점수 · 발음으로 좁힘, 하온 지시에 기분 짐작 금지 |
| 9 P2 | 모국어 · 막힘 · 카드 뜻 | 「○○라고 말해 봐요」 한 문장 · 8초 말 없으면 쉬운 질문 · 영어 뜻 · 별명도 괜찮아요 |
| 10 P2 | 예산 주기 · 크레딧 바닥 | 리셋 날 설정 · 크레딧바닥 줄 → 그 주기 글 길. 시험 |
| 11 P3 | safety id 자리 · 미션 수 · 로그 | Responses는 몸통 칸, 미션 여섯으로 고침, 서버 로그에 전사 안 찍음 |
| 12 P3 | mini는 줄여도 된다 | 코드는 두고 끝까지 시험은 한 판만(성공 기준 ④는 gpt-live ↔ 글로 증명) |
