# 첫 등록과 문구 검색 · 2026-10-08

상태: **사용자의 이번 범위 검수 예외·배포 진행 지시에 따라 공개 반영 완료.** 공개 커밋은 `b4791ae`이다. Claude 최종 검수는 한도로 미완료이며 성공으로 표시하지 않는다. 기존 예외를 확장하지 않고 이번 대화의 진행 지시와 해석을 user-review-exception.json에 기록했다.

## 이번 사용 흐름

- 신규 사람 등록은 이름만 필수로 받는다. 날짜와 자세한 정보는 접어서 보여 주며, 저장하면 해당 사람의 첫 안부를 바로 준비한다. 날짜를 함께 입력하면 해당 행사 문구를 준비한다.
- 기존 사람의 정보 수정은 작성 중인 글과 기억 선택을 유지한다. 다른 사람으로 이동을 취소하면 새 사람은 수첩에 남고 기존 초안은 유지된다. 계정·선택 사람이 바뀌거나 기기 저장이 실패하면 자동 준비와 성공 안내를 중단한다.
- 지난 일회성 일정은 저장한 뒤 ‘기억할 날’에서 확인하도록 안내한다. 예정 회차가 없는 행사에 다른 상황의 초안을 만들지 않는다. 접힌 항목 안의 입력 오류는 해당 항목을 펼쳐 보여 준다.
- 문구 보관함에서 전체 본문을 검색하고 즐겨찾기만 볼 수 있다. 기존 행사 종류·안부 목적 범위와 함께 적용한다. 결과 수·빈 결과 안내·초기화를 제공하며 사람·계정·행사 종류·안부 목적이 달라지면 조건을 초기화한다.
- 검색은 NFC 정규화·앞뒤 공백 제거·대소문자 구분 없는 문자 그대로의 포함 검색이다. 입력은 100자까지이며 초안·수첩·저장 시각을 바꾸지 않는다.

기존 문장 틀·Vellum 표현 검사·SYNK 계정 저장을 재사용하는 화면 개선이다. 새 엔진 능력, 의미 검색, 만족도 효과를 입증한 결과로 주장하지 않는다.

## 최종 검수 상태

공식 Claude Code에 `--model claude-opus-5-5 --effort max`를 명시했다. 실제 응답은 **429 usage_limit_reached**, 안내된 초기화는 **10월 12일 19시(한국 시간)**였다. 입력·출력 토큰 0으로 최종 검수는 수행되지 않았으며 모델을 대체하지 않았다. claude-review.json·claude-process.json·claude-prompt.txt에 근거를 남겼다.

당시 AI 운영 원칙에 있던 ‘라이브 배포·공개 게시로 나가는 결과만 Claude가 최종 검수’, ‘Claude 최종 검수는 Opus 5.5 · 최대 추론’ 규정에 따른 검수 예외·배포 여부를 사용자에게 설명했고, 남은 작업을 다시 안내한 뒤 받은 ‘이어서 해’를 이번 범위 진행 지시로 받아 공개했다. 이를 실행 전 사용자에게 명시했다. 정확한 대화 근거는 user-review-exception.json을 따른다. 이는 당시 승인 이력이며 현재 역할·검토 기준은 [현행 AI 운영 원칙](../../../../docs/AI_운영원칙.md)을 따른다.
