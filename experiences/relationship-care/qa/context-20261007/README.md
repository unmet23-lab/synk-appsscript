# 연락 전에, 우리 이야기 · 2026-10-07

후속 챙김에서 실제 연락을 준비하는 흐름을 다듬었다. 기존 맥락 카드를 초안 준비 앞에 놓고 마지막 실제 챙김, 날짜를 정한 후속, 근거가 남아 있는 기억, 지난 선물·경조금, 복사 문구를 구분한다. 별도 생성 AI나 의미 추론을 추가하지 않는다.

- ‘지금 챙기기’와 홈 추천은 날짜 없는 안부 준비로 연결한다. 고른 후속의 제목·날짜·근거는 표시하고 문구에 자동으로 넣지 않는다.
- 같은 사람의 수정 중 안부 초안을 유지한다. 일정 초안을 바꾸거나 기억을 적용하여 새 초안을 만들 때는 기존 확인을 거친다.
- 기억 카드에서 원문·용도 확인으로 이동한다. 사용자가 ‘이 기억으로 준비’를 누를 때 기존 개인화 경로를 재사용한다.
- 선택 후속은 계정 epoch, 사람, 항목·원문의 fingerprint를 다시 확인한다. 다른 사람·일정·계정, 완료·삭제·변경 이후에는 연결을 해제한다.
- ‘직접 챙겼어요 · 이 챙김 완료’는 후속 완료만 기록한다. 연락 활동을 중복 추가하지 않는다. 복사는 완료가 아니며 완료 항목은 우리의 기록에서 날짜·제목과 함께 확인한다.
- 최근 기억 3개, 후속 최대 3개, 주고받음 최대 3개를 꺼내며 나머지는 기존 전체 기록에서 본다. 날짜 기준은 한국 날짜이며 같은 날짜 안의 미래 시각까지 배제하는 정책은 아니다.

## 확인

- [Care 자동 검사](tests-care.txt): 228/228. 새 맥락 테스트 15개는 원문 철회·소유자, 미래 날짜, 한국 자정, 정렬, 복사/실제 기록 구분, 입력 불변성과 실제 기록·완료의 정확한 동반 관계를 검증한다.
- [브라우저 검증](browser-verification.json): 합성 계정과 합성 수첩으로 실제 클릭·입력. 기억 연결과 취소 시 초안 보존, 복사 후 pending 유지, 완료 표시, 같은 사람 초안 유지, 로그아웃 뒤 맥락 비움 확인.
- 375px 및 320px 가로 넘침 없음. 기록 본문 16px, 날짜·보조 안내 14px, 펼침 조작 49.5px. [최종 375px 실제 화면](context-final-375.png).
- 독립 코드검토에서 발견한 기존 후속 완료 버튼의 화면 갱신 누락을 수정하고 실제 UI로 재확인했다.
- Chrome의 일부 캡처/마우스 응답 장애 뒤 인앱 브라우저에서 시각 검증을 완료했다. 브라우저 증거의 `initialCandidate`는 초회 v2, `finalCandidate`는 검수 수정 뒤 v6다. 홈에서의 완료 즉시 반영과 다른 사람을 거쳐 복원한 일정 초안의 단일 확인·취소 보존을 v6에서 재확인했다.
- 공식 Claude Code `claude-opus-5-5 --effort max` [최종 재검수](claude-delta-review.json): 남은 P0·P1·P2 없음. 실제 모델·정상 종료·최종 소스 9개 SHA 일치를 [모델 증거](claude-model-proof.json)에 남겼다.

## 공개 반영

policy `eb9e55b3b126dfbc45caaa176395c4a677e89f67`로 공개 파일 6개를 반영했다. [배포 변경 목록](release.json). 기존 공개 의존 파일 42개와 계정·서버 설정은 유지했다. [48개 공개 파일](public-verification.json)의 SHA/MIME이 일치하고 Pages 배포가 성공했다. [Pages·전체 사이트 CI](deployment-ci.json)가 통과했다. 전체 사이트 검사는 Care 파일이 완전히 동일한 후속 커밋 `ba3b77a`에서 최종 성공한 결과다. [최종 완료 범위](completion.json).

전체 사이트 CI 초회는 바뀐 6파일·23페이지×2기기 검사를 통과한 뒤, 변경하지 않은 LAB 게임의 `stage.js` 단일 HTTP 503으로 실패했다. 해당 파일의 200 정상 응답을 확인하고 코드 변경 없이 실패한 작업을 한 번 재실행했다. 재시도는 다른 작업의 후속 배포 때문에 취소됐고, 후속 `ba3b77a`의 Care tree가 배포본과 완전히 동일함을 확인했다. [초회 실패와 재시도 범위](ci-retry.json)를 최종 결과와 함께 보존한다.

[실제 공개 브라우저](public-browser.json)에서도 예시 수첩의 최근 연락 메모→후속 챙김→일정 초안 변경 확인→안부 준비→직접 완료→제목·날짜 있는 기록을 확인했다. 375px 가로 넘침 없음, 주요 기록 본문 16px, 콘솔 오류 0건. [공개 후속 준비 화면](public-followup-375.png). 시험은 비회원·기기 저장 꺼짐 상태였고, 새로고침하여 합성 자료가 남지 않은 것을 확인했다. 공개 홈을 복원하고 임시 화면 크기 설정과 로컬 QA 서버를 해제했다.

실제 사용자 계정 자료를 수정하거나 메시지를 전송하지 않았다. 물리 휴대폰 왕복은 사용자 요청으로 보류하며 닫힌 앱 푸시 실수신은 이번 확인 범위가 아니다.
