목표와 중요한 경계:
- https://synk.im/care/에 별도 public OAuth client 한 개만 추가하고 API product는 platform입니다. 기존 운영 19개 매핑을 보존한 뒤 20개가 됩니다.
- 기존 로컬 browser/native client, journal.bindings·attempted, 로컬 설정 3개를 덮어쓰지 않습니다. 기존 공개 /id/config.json의 19개 동의 항목을 보존하며 새 public client만 더합니다. 교사 browser 등 미구현 연결을 추가하지 않습니다.
- dry-run은 remote mutation 없음, 실제 매핑 digest·Fortune 보존·기존 callback 정합을 읽어 확인했습니다. 실제 create/update에는 명시 --apply와 canonical shared lock/journal을 사용합니다. create ACK 또는 mapping ACK 유실 시 정확한 공급자 결과 확인 없이 중복 생성/덮어쓰지 않아야 합니다.
- 공개 빌드는 새 .tmp 하위 디렉터리의 고정 39파일입니다. 원본/개인자료/로컬 상태/.env/서버/QA를 복사하지 않고 명시 검증한 public config만 넣습니다. 상대 import closure, /care/ 하위 URL, CSP/referrer, configUrl의 same-origin 제한을 확인하세요.
- 공개 웹에서 녹음은 파일 선택·재생은 가능하지만 PC loopback Whisper 받아쓰기 API를 요청하지 않아야 합니다. 앱 종료 후 자체 푸시나 자동 외부 발송은 추가하지 않습니다.
- 공개 client 매핑 secret을 바꾼 뒤 기존 검수 릴리스 adbcfa3(제품 source285bf9)와 동일 코드의 synk-account, synk-learning, synk-care, synk-personal 네 함수를 재배포할 계획입니다. 이 후보 단계에서는 신규 공개 client/secret/website의 원격 변경은 아직 없습니다. 이 검수에서 배포 명령을 실행하거나 backend를 확장해서 읽지 마세요.
