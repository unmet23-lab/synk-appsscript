# 남산 실행 화면

2026-09-20 사용자가 문서 대신 눌러 열 수 있는 링크를 요청해 만든 **당시 Windows 컴퓨터 전용 실행 허브**다. 새 노트북에서 엔진·실행 파일·설치기의 존재를 확인한 상태는 아니다. 현재 WORLD의 제품 입구는 [앱 README](../synk-world-app/README.md)이며, 이 비교용 허브의 준비를 필수 작업으로 두지 않는다.

- Unity: http://127.0.0.1:5195/unity
- Unreal: http://127.0.0.1:5195/unreal
- 기존 웹 남산: http://127.0.0.1:5194/namsan.html

엔진 본체와 게임 실행 파일의 유무는 실행 페이지에서 현재 로컬 상태를 확인한다. 이 링크를 Unity/Unreal 완성 게임이나 브라우저 이식판으로 소개하지 않는다. 목표 풍경 그림에는 참고용 표시를 붙인다.

## 버튼 동작

1. 게임 빌드가 있으면 해당 실행 파일을 연다.
2. 엔진만 설치됐다면 준비된 프로젝트를 에디터에서 연다. 컴파일·장면 생성·Play 검증이 끝났다는 뜻은 아니다.
3. 둘 다 없으면 이미 받은 Unity 공식 설치 파일 또는 설치된 Epic Games Launcher를 연다. Windows 승인·계정 로그인은 사용자가 직접 진행한다.

페이지 진입만으로 프로그램을 실행하지 않는다. 사용자가 버튼을 눌렀을 때만 실행하며, 상태는 5초마다 현재 파일 존재 여부로 갱신한다. 새 버전/다른 경로에 엔진을 설치한 경우 `server.mjs`의 명시적 경로 목록에 추가해야 한다.

## 실제 렌더 갤러리

`/api/renders`는 Unity의 `namsan-urp/QA/Unity/render-validation.json`과 세 PNG,
Unreal의 `namsan-unreal/QA/Unreal/render-report.json` 또는
`namsan-unreal-art/QA/Unreal/render-report.json`과 세 PNG를 확인한다.
Unity는 저장씬 재로드·재질 연결·프레임 안정성 성공, Unreal은 오류 없는 엔진 렌더 보고서가 있어야 한다.
세 파일은 1600×1000 PNG여야 하며 보고서가 해당 파일을 포함해야 한다. 준비되지 않았으면
갤러리에 `실제 렌더 준비 중`으로 표시한다. 보고서에 적힌 임의 파일 경로는 제공하지 않는다.

정원·몽글·전망대 이미지는 엔진별 열에 모으고, 좁은 화면에서는 세로로 배열한다.
클릭하면 실제 PNG를 크게 연다. 파일 수정 시각을 URL에 포함해 새 렌더를 불러온다.
목표 그림의 참고 표시, PC 에디터 렌더와 휴대폰/플레이 검증의 구분을 유지한다.
이 변경은 실행 버튼 동작·설치 프로세스를 바꾸지 않는다.

2026-09-20 갤러리 추가: 기존 실행 보안 검사와 실제 보고서/3PNG 게이트 검사 포함 **7개 통과**.
실행 중인 5195 서버 재시작은 이 하위 작업에서 수행하지 않았다.

## 다시 켜기

```powershell
./experiences/namsan-launcher/Start-Launcher.ps1
```

이 스크립트는 백그라운드에 로컬 실행 허브(5195)와 기존 웹 체험 서버(5194)를 시작한다. 이미 사용 중인 포트의 프로세스를 종료하거나 바꾸지 않는다. 재부팅 후에는 다시 시작해야 한다. 공개 배포·자동 시작 등록·방화벽 변경은 하지 않았다.

## 접근 범위와 검증

서버는 127.0.0.1에만 바인딩한다. 실행 요청은 현재 페이지 Origin과 세션 토큰, 두 엔진 이름만 받는다. 요청에서 파일 경로나 명령 인수를 받을 수 없으며, 고정된 파일 목록만 제공한다. Windows 확인창이 대기 중이면 다른 실행 요청을 막는다.

`node --test experiences/namsan-launcher/server.test.mjs`로 Origin/Host/토큰 거절, 임의 명령 금지, 중복 실행 방지, 취소 오류 표시 등 6개 시험을 수행한다. 시험의 프로그램 실행 함수는 mock이며 실제 엔진 실행 성공을 입증하지 않는다.

2026-09-20 검증: 위 6개 시험 통과. 실제 로컬 서버의 두 경로, 준비 상태 API, 기존 웹 남산 HTTP 응답 확인. 브라우저에서 Unity/Unreal 링크 전환·제목·선택 표시·설치 설명 펼치기·새로 확인을 점검했다. 1280px·390px·320px 화면에서 배치와 버튼 표시를 확인했고 좁은 두 폭에서 가로 넘침이 없었다. 브라우저 오류 로그는 없었다. 이는 실행 허브 검사이며 Unity/Unreal 게임 실행, 휴대폰의 네이티브 실행 또는 설치 완료 검증은 아니다.
