# 말의 마법사 · 내가 만든 마법 장면

## 결과

기존 `synk.word-magic.progress.v1`의 선택형 `keepsakes`로 이름 붙인 작품 최대 6개를 무료 보관합니다. 저장·이름 변경·명시적 삭제·직접 고른 작품 교체·다시 실험실에서 놀기를 구현했습니다. 기존 계정 bridge storage를 사용하며 새 저장 키, 픽셀/Base64 저장, 파일 업로드, 이미지/음성 생성, backend 변경은 없습니다.

작품을 열 때는 현재 지갑의 소풍 세트 소유를 확인합니다. 미보유·소리 준비 실패·닫힌 화면·계정 종료·다른 소유자 상태에서는 장면을 시작하지 않습니다. 계정 저장 대기/오프라인/충돌/저장 실패를 저장 완료로 표시하지 않습니다. 소유자가 바뀌거나 계정 연결이 종료되면 보관함 DOM·작품·입력을 비웁니다. 오프라인은 자기 작품을 유지합니다.

보관함 조작과 작품 재열기는 본편 진행·`resume`·`adventureResume`·최신 실험실·듣기 확인·Atlas·지갑을 바꾸지 않습니다. 꺼낸 작품은 임시 실험실에서 변형하고, 원할 때 새 작품으로 직접 간직합니다. 배경/사진틀은 현재 장착 상태를 유지한다고 안내합니다. 모험 초기화도 보관한 작품을 지우지 않습니다.

## 발견·보존한 실패

독립 검토에서 초기 작품 병합 방식이 최신 계정 원문을 읽은 뒤 오래된 본편을 저장할 수 있음을 찾았습니다. 현재는 초기/직전 저장 원문과 최신 원문의 작품 외 부분을 비교해, 진도가 바뀌었다면 이 창의 저장을 중단하고 새로고침을 안내합니다. 초기화 저장이 중단되면 이 창의 원래 진행도 되돌립니다. 작품만 바뀌었다면 최신 작품을 유지하고 자기 진행을 저장합니다. 독립 검토와 위 actual-app 시험의 정상/차단 양쪽에서 수정 후 확인했습니다. 이 결함은 공개 전에 수정했습니다.

`persist-guard.test.cjs`의 마지막 시험은 관찰한 이전 위험 분기를 재현한 축약본이며, frozen 원문이라고 표시하지 않습니다. 이전 분기의 최신 6개 사건→캐시 1개로 승인된 덮어쓰기와 현재 함수의 전송 0을 구분합니다.

`failure-*.json/png`는 합성 계정 fixture의 reload 뒤 `__wordMagic` 확인을 너무 일찍 해 ReferenceError가 난 첫 시험을 보존합니다. 제품 오류로 분류하지 않았으며 guard 있는 대기와 올바른 reload로 고쳤습니다. actual-app 초기화 시험의 첫 VM fixture에는 `initialProgress`가 누락되어 ReferenceError가 났고, 실제 초기값/함수를 제공한 뒤 38개 모두 통과했습니다.

## 경계와 결과 파일

`before-manifest.json`과 `source/*.before`는 작업 시작 원문, `source-manifest.json`과 `source/*.after`는 freeze한 원문입니다. `completion.json`은 검증/미검증 구분, `artifact-manifest.json`은 증거 파일 SHA입니다. 공통 collection·상점·backend·ops·공용 4340 서버·공개 저장소는 이 agent가 수정하지 않았습니다. 독립 정적 서버 4436과 검사 브라우저를 종료하고 `cleanup.json`에 기록했습니다.
