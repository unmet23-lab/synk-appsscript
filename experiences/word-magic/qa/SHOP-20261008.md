# 마법 상점 · 2026-10-08 로컬 검증

`http://127.0.0.1:4340/word-magic/`의 설치된 Chrome으로 확인했습니다. 새 AI 이미지·음성·외부 유료 호출은 없습니다.

## 실제 상점 조작

`node experiences/word-magic/qa/shop.cjs` → `shop-results.json`, `shops/*.png`

- 1280px와 320px 두 화면에서 각각 12개 흐름 통과, 페이지·HTTP 오류 0, 가로 넘침 0.
- 기본 무료 2개 + 유료 4개, 소유·장착 표시, 부족한 차액, 한영 전환.
- 공통 API로 테스트 코인을 넣은 별도 브라우저 프로필에서 구매·장착 → 잔액 차감 → 재로드 유지 → 기본 무료 복귀 → 소유품 무료 재장착. 이 테스트 코인은 학습자 플레이로 얻었다고 보고하지 않습니다.
- 미리보기는 본 게임 Canvas를 바꾸지 않음. 실험실에서 실제로 만든 사진의 크기 960 × 612 확인, 코랄/크림 장착 변경이 내보낸 PNG 픽셀에 반영됨.
- `Storage.setItem`을 거부한 상태에서 코인 차감·장착을 성공으로 처리하지 않음. 정상화 후 같은 구매 재시도 가능.
- Enter로 상점 열기, Tab의 대화상자 안 초점 이동, Escape로 닫기와 원래 입구 단추로 초점 복귀. `?shop=1` 직접 진입 자동 열기 확인.
- `shops/equipped-top-320.png`, `equipped-320.png`, `equipped-top-1280.png`에서 실제 펠트 배경·글자 배치·아래 닫기 버튼을 육안 확인. 코랄 면은 작은 결 조각 확대 대신 승인된 넓은 펠트 판으로 마감.
