# 말의 마법사 · 이어 하기와 선택형 기억 놀이

## 변경

모험 카드의 사건 발견 6개와 소리 확인 2개를 별도 표시하고, 남은 소리 확인으로 직접 이어 갑니다. 이전 첫 응답과 보기 순서를 보존하며, 기존 사건 6개의 다음 장 해금 조건은 바꾸지 않습니다. `?chapter=0..2`는 시작 클릭 뒤 정확한 장의 미완료 사건·확인·완료 보상 재시도로 연결합니다.

입구의 30초 기억 놀이는 `introduced`에 있는 표현 중 두세 개만 고릅니다. 기존 `checks`의 놓친 첫 응답이 있으면 우선하되, 새 평가나 숙달을 쓰지 않습니다. 기존 MP3와 승인 곰·책·사진기를 사용하며, 답 전에는 두 변화 그림만 표시합니다. 정답 장면·목표·한국어 철자·영어 뜻은 첫 응답 뒤에 공개합니다. 오답에는 실제 올바른 변화를 교정으로 보여 주고 다음으로 갈 수 있습니다.

기억 놀이의 결과·도움·재청취 구분은 방문 메모리에만 있습니다. 계정 진행 키·스키마·원격 DB·공통 코인·Atlas 기록을 추가하지 않습니다. 본편 변형과 첫 응답은 유지하며 새로고침 뒤에는 입구에서 다시 선택합니다. 기존 자유 실험실·사진·상점·하루 복습 코인·마지막 장면은 유지합니다.

## 확인과 한계

- `node-tests.txt`: core/practice/audio/새 recall 검사 23개 통과. 발견/소리 확인 분리, 이전 버전 첫 응답 호환, 도입된 표현만 사용, 놓친 표현 우선, 답 전 중립 상태와 교정 공개를 확인했습니다.
- `browser-results.json`: 새로운 흐름의 격리 비회원 Chrome 검사. 320/390px, 기존 실제 MP3, 미확인 표현 직접 진입, 첫 응답·중단 상태 복원, 무료 다음 장 해금 유지, 완료 링크 중복 지급 방지, 그림만 있는 기억 놀이, 오답 교정, 재청취·도움·새로고침, 기록/지갑 불변을 확인합니다. 완료 여부는 이 파일과 `completion.json`을 기준으로 읽습니다.
- `shop-focus-after-browser.json`: root가 변경한 상점 소스를 추가 확인한 기존 focus 회귀 12/12 통과. 원래 QA 파일과 결과는 덮지 않았습니다. 검사에 필요한 비회원 지갑 100코인은 합성 fixture이며 실제 학습·계정 구매 기록이 아닙니다. 오류·음성·외부·쓰기 HTTP 요청 0입니다.
- `play-small.json`, `atlas-small.json`, `shots/`: 기존 본편 전체 회귀의 별도 사본. 18개 사건+6개 MP3 확인, v2 최초 응답/도움 분리, 실험실·실제 PNG·새로고침·그림 체험 격리·완주/복습 보상을 320px에서 확인했습니다. 원래 결과는 보존했습니다.
- 실제 참가자 0, 물리 휴대폰 0, 사람의 스피커 음질 평가 0입니다. 재미·기억 향상·TOPIK 점수 효과와 다른 물리 기기의 로그인 복원을 확인했다는 뜻이 아닙니다. 구현된 학습 범위는 이미 소개된 기초 표현의 소리-뜻 연결을 다른 사물에 적용하는 짧은 듣기 복습입니다.

## 보존한 실패와 재확인

- `setup-connection-failure.txt`: 처음 지정한 4340 서버가 없었습니다. 제품 소스를 고치지 않고 기존 정적 서버를 별도 포트로 실행한 뒤 root의 49321 서버에서 진행했습니다.
- `first-browser-failure.txt`: 첫 fixture가 저장 정규화의 기본 필드를 생략해 단순 raw JSON 비교가 실패했습니다. 제품의 변형·진도는 동일했습니다. 테스트를 기존 `restoreProgress`의 정규화 결과 비교로 고쳤습니다.
- `browser-first-pass.json`: 첫 UI 11개 흐름 통과. 직접 캡처를 보고 기억 놀이 그림이 작아 보여 보기 Canvas 폭을 290→145로 바꿨습니다. 승인 이미지는 바꾸지 않았습니다. `recall-small-pictures-before-390.png`와 최종 `recall-0-before-390.png`로 크기를 비교할 수 있습니다.
- `browser-failure-*.txt`: 최종 시각 재검사 도중 3문항 fixture의 음성 완료 대기 timeout을 보존했습니다. 단독 `three-question.cjs`로 다시 확인해 MP3 6개/manifest HTTP 200, AudioContext running, 음성 완료·놓친 표현 우선·도움·재방문 상태 통과를 기록했습니다. 동시 시험 부하가 원인이라고 확정하지 않습니다. 자동 재녹음·TTS 대체·자동재생 허용 플래그는 사용하지 않았습니다.

## 작업 경계

이 agent의 제품 수정은 `app.mjs`, `core.mjs`, `index.html`, `style.css`, 새 `recall.mjs`·`recall.test.mjs`, 이 폴더와 자체 README입니다. `shop.mjs`와 공통 `collection.js`는 root 담당입니다. 이 작업에서 음성 재녹음·이미지 생성·공식 모델 호출·배포·계정 DB 쓰기를 하지 않았습니다. `before-manifest.json`과 `source/*.before`는 기존 공용 변경을 포함한 작업 시작 시점의 원문을 보존합니다.
