# 말의 마법사 · SYNK WORLD

> 현재 계정 코인·진도·작품 보관함 연결은 [공통 컬렉션](../play-common/README.md), 10-10 후속 공개는 [입문 게임 원문](../beginner-games/README.md)을 따른다. 아래 10-08~09의 브라우저 전용 상점·로컬 미검증 범위는 당시 작업 기록이며 현행 전체의 미구현을 뜻하지 않는다. 학습 기록·그림 체험·명시 저장·실학생/실기기 미검증 경계는 유지한다. 새 자산 제작은 [AI 운영 원칙](../../docs/AI_운영원칙.md)의 최신 방향을 따른다.
한국어를 처음 배우는 사람이 소리를 듣고 사물의 **크기·열림·위치**를 바꾸는 작은 퍼즐 모험입니다. 시간 제한·생명·오답 감점이 없고, 3장 × 6개 사건 뒤에도 자유 실험실에서 계속 놀 수 있습니다. 로컬: `node experiences/word-magic/server.mjs` → http://127.0.0.1:4316/. 저장소 공통 서버에서는 `/word-magic/`으로 엽니다.

## 실제 플레이

1. **먼저 가르칩니다.** 각 장에서 표현 두 개를 실제 한국어 MP3와 사물 변화 시범으로 만납니다. 두 표현을 모두 눌러야 장면 모험이 열립니다. 처음 누른 것이 반대 표현이어도 시범은 항상 변화 전 상태에서 시작합니다.
2. **소리 → 사물 → 변화.** 표현을 고르면 소리가 나고, 물건을 누르면 실제 장면 속 물건이 커지고 작아지거나, 문·상자·책이 열리고 닫히거나, 선반 위아래로 움직입니다. 여러 물건에 자유롭게 적용할 수 있습니다. 장면 위의 작은 그림은 완성할 모습입니다.
3. **18개의 사건.** 토끼 때문에 막힌 통로, 의자를 계단으로 쓰기, 소풍 크기 맞추기, 곰의 튜브, 엉뚱한 사진, 단체 사진 / 극장 문·바람·선물 상자·서프라이즈·이야기책·커튼콜 / 가방 배달·토끼 내려오기·엇갈린 소포·우산 배달·사진기 구조·마지막 단체 사진. 일부 사건은 서로 다른 두 물건을 반대로 바꿔야 끝납니다. 해결하면 몽글이 통로를 지나고, 의자에 올라가고, 튜브가 곰에게 이동하고, 여우가 열린 문으로 들어가는 등 장면 자체도 바뀝니다.
4. **듣기 확인은 따로 합니다.** 각 장 뒤 두 번, Korean MP3를 끝까지 듣고 두 변화 그림 중 알맞은 것을 고릅니다. 답하기 전에는 실제 물체의 크기·개폐·위치와 목표를 보여 주지 않는 동일한 중립 장면을 씁니다. 선택 카드는 의미 그림·영어 이름만 표시하며 접근성 이름에도 한국어 철자를 넣지 않습니다. 한국어 단어와 변형 결과는 첫 응답 뒤 공개합니다. 두 표현이 모두 나오도록 문항 순서와 각 문항의 보기 위치를 독립적으로 섞고, 다시 듣거나 화면을 갱신할 때는 그 위치를 유지합니다. 최초 응답만 학습 기록으로 남기고, 재청취·힌트·오답 뒤 수정은 구분합니다. 먼저 익힌 표현을 짧게 다시 떠올리는 연습이며, 처음 보는 한국어의 무힌트 측정이나 숙달 판정이 아닙니다.
5. **쉬는 마무리.** 장을 끝내면 찾은 사진기·이야기책·우산을 보여 주고 직접 다음 모험을 선택합니다. 마지막 장 뒤에는 자유 실험실로 이어집니다. 자동으로 다음 장을 시작하거나 시간으로 재촉하지 않습니다.

### 이어 하기와 30초 기억 놀이 · 2026-10-09

- 모험 카드에 **사건 발견 0–6개**와 **소리 확인 0–2개**를 따로 보여 줍니다. 사건을 모두 찾았지만 소리 확인을 하지 않았다면 `소리 확인 2개 남음`에서 바로 이어 갑니다. 중단한 확인 문항은 기존 보기 순서·첫 응답을 유지하고 다시 들어야 고를 수 있습니다. 소리 확인 개수는 첫 응답이 남은 표현의 수이며, 정답률이나 숙달 개수가 아닙니다. 앞 모험의 사건 6개로 다음 모험이 열리는 기존 조건은 유지합니다.
- `/word-magic/?chapter=0`부터 `chapter=2`까지 특정 모험으로 연결합니다. 소리 준비는 **모험 이어 하기**를 누른 뒤 시작합니다. 미완료 사건은 첫 미완료 사건, 사건 6개 뒤에는 남은 소리 확인, 이미 둘 다 끝난 모험의 이 링크는 완료 화면과 기존 보상 저장 재시도로 이어집니다. 미해금 장을 링크로 열어도 해금을 건너뛰지 않습니다. `shop=1`과 `play=lab` 진입은 기존 동작을 우선합니다.
- 두 표현을 소개받은 뒤에는 입구에 선택형 **30초 기억 놀이**가 나타납니다. 이미 소개된 표현만 두세 개 고르고, 앞 확인에서 놓친 표현이 있으면 먼저 만납니다. 기존 6개 MP3를 곰·책·사진기처럼 다른 물건에 적용해 봅니다. 30초는 짧은 놀이의 안내이며 제한 시간·실패 조건이 없습니다.
- 기억 놀이의 첫 답 전에는 정답 장면·목표·한국어 철자·영어 뜻을 숨깁니다. 두 가지 변화 그림 중 하나를 고른 뒤 한국어와 뜻, 실제 변화를 함께 보여 줍니다. 오답이어도 바로 교정하고 다음 소리로 갈 수 있습니다. 재청취·도움·첫 응답은 이번 방문의 메모리에서만 구분합니다.
- 기억 놀이는 새로운 숙달·Atlas 평가·해금·코인으로 계산하지 않습니다. 기존 계정 진행 키와 스키마에 필드를 더하지 않고 `introduced`, `checks`를 읽기만 합니다. 하던 본편의 변형·첫 응답 상태는 유지하며, 새로고침하면 입구로 돌아와 짧은 놀이를 다시 선택합니다. 자유 실험실의 기존 하루 한 번 복습 코인은 별도 동작으로 유지합니다.

[이어서 하기·기억 놀이 QA](qa/return-memory-20261009/README.md): 격리 비회원 Chrome의 합성 진행으로 확인한 범위이며 실제 초보자의 재미·기억 향상, 물리 휴대폰 스피커·계정 왕복 확인을 대신하지 않습니다.

## 자유 실험실

각 장을 배운 뒤 그 장의 두 표현이 해금됩니다. 토끼·상자·책·우산 네 물건에 배운 표현을 조합합니다. 토끼를 키웠다 줄이고, 상자를 열어 펭귄을 만나고, 책을 펼치고, 물건을 위아래로 이동합니다. 생물이나 우산에는 여닫을 곳이 없다고 안내하며, 크기/위치 마법은 모든 물건에 적용됩니다. 마지막 변형 상태는 다음 방문에도 복원됩니다. 소풍 세트를 장착하면 곰·튜브·간식·상자로 실제 물건이 바뀌고, 기본/소풍 세트의 변형은 각각 저장됩니다. 기본 세트로 언제든 무료로 돌아올 수 있습니다.

**사진 저장**은 현재 Canvas에 그려진 실제 변형 장면을 960 × 612 PNG로 만듭니다. 사진 미리보기에서 파일을 내려받을 수 있습니다. 웹 캔버스에 외부 URL을 섞지 않아 CORS 때문에 사진이 막히지 않습니다. 그림 파일을 서버에 전송하지 않습니다.

### 내가 만든 마법 장면 · 2026-10-09

실험실의 **이 장면 간직하기**, 사진 미리보기의 **이 장면을 간직하고 다시 놀기**, 처음 화면의 **내 장면 보관함**을 같은 보관함으로 연결합니다. 이름 붙인 작품을 무료로 최대 6개 간직하고, 이름 변경·다시 놀기·선택한 장면 삭제를 할 수 있습니다. 가득 찼을 때는 사용자가 교체할 작품을 직접 고릅니다. 새 작품을 만든다는 이유로 기존 작품을 자동 삭제하지 않습니다.

- 기존 `synk.word-magic.progress.v1` 안의 선택형 `keepsakes` 배열을 사용합니다. 이전 진행에는 빈 보관함을 복원합니다. 물체 ID·크기·개폐·위치, 기본/소풍 세트 ID와 이미 소개된 표현만 저장합니다. 이미지 픽셀·Base64·파일 URL을 저장하거나 업로드하지 않고, 승인 물체와 기존 Canvas 렌더러로 썸네일을 다시 그립니다.
- 저장은 기존 `SynkPlayAccount.storage()`를 통합니다. 계정 저장 대기·오프라인·충돌·실패를 완료로 표시하지 않습니다. 로그인 전 체험은 비회원 브라우저 기록임을 안내합니다. 계정 연결이 종료되거나 소유자가 바뀌면 대화상자와 이전 계정 작품·입력을 비우고, 늦은 저장/썸네일/열기 응답을 현재 화면에 적용하지 않습니다.
- 작품을 다시 열면 저장 당시의 물체 변형으로 자유롭게 놀 수 있습니다. 현재 장착한 배경과 사진틀을 유지한다는 안내를 보여 줍니다. 소풍 작품은 현재 지갑의 소풍 세트 보유를 먼저 확인하며, 미보유라면 장면 조작을 열지 않습니다. 아직 배운 표현이 없는 경우 무료 모험의 첫 두 표현을 먼저 익혀야 합니다.
- 보관함 조작과 작품 재열기는 본편 `resume`·`adventureResume`·듣기 확인·최신 실험실 상태·Atlas·지갑을 바꾸지 않습니다. 꺼낸 작품에서 하는 실험은 별도 방문 상태이며 새 작품으로 직접 보관할 수 있습니다. 이후 실제 소리를 듣고 변형하는 기존 하루 복습 코인의 조건은 그대로 적용합니다. 모험 진행 초기화도 보관한 작품을 지우지 않습니다.
- 다른 탭이나 기기에서 작품만 바뀌었다면 최신 작품을 유지하고 자신의 진행을 저장합니다. 작품 외 진도가 바뀌었다면 이 창의 오래된 진행을 덮어쓰지 않고 저장을 중단합니다. 최신 진행은 새로고침으로 불러와야 하며, 중단한 초기화는 이 창의 원래 진행으로 되돌립니다.

[보관함 QA](qa/scene-keepsake-20261009/README.md)에 기존 계정 저장 계약의 합성 왕복·충돌, 정확한 app 저장 함수의 덮어쓰기 방지, 320/390/1200px·한영 화면과 실패/늦은 응답 확인 범위를 기록합니다. 실제 학생 효과·물리 두 기기의 계정 복원·사람이 들은 음질 평가는 별도입니다.

## 마법 상점 · 공통 코인

처음 화면, 각 장의 완료 화면, 자유 실험실에서 **마법 상점**을 엽니다. `/word-magic/?shop=1`은 상점으로 바로 들어갑니다. 레이싱 차고·말 랠리와 같은 `SynkPlayCollection` 지갑의 잔액·구매·소유·장착 계약을 사용합니다. `collection.js`는 공통 빌드 생성본이며 직접 수정하지 않습니다.

허브의 보유품 사용 링크는 `/word-magic/?play=lab&item=magic-toys-picnic`입니다. `item`을 빼면 현재 장착한 실험실을 사용합니다. 준비 카드에서 실제 보유품을 확인하고 **이 소품으로 놀기**를 눌러야 음성 준비와 장착을 시작합니다. 보유한 마법 배경·사진틀도 같은 방식으로 적용합니다. 미보유·잘못된 상품은 구매/차감/학습 해금 없이 무료 기본 소품과 상점 선택을 안내합니다. `shop=1`과 함께 오면 기존 상점이 우선합니다. 미완료 본편 장면은 별도 보관하고 실험실의 **하던 모험으로 돌아가기** 또는 처음 화면의 이어 하기로 물체 변형·확인 문제 첫 응답 상태를 복원합니다. 음성 준비 실패 시 진행과 장착을 유지하고 다시 눌러 시도할 수 있습니다.

| 종류 | 무료 기본 | 코인으로 고르는 상품 | 실제 적용 |
|---|---|---|---|
| 소품 세트 | 토끼·상자·책·우산 | 곰의 소풍 실험 세트 20 | 자유 실험실 물건을 곰·튜브·간식·상자로 전환, 배운 크기·개폐·위치 표현 적용 |
| 장면 배경 | 모험의 하늘 | 복숭아 노을 15 / 라피스 저녁 35 | 게임과 실험실의 Canvas 배경 |
| 사진틀 | 크림 | 코랄 20 / 라피스 40 | 내려받는 960 × 612 PNG의 실제 테두리 |

- 상품 그림을 누르면 별도 실험실 장면으로 미리 봅니다. 구매하거나 장착하기 전에는 본 게임 장면·정답·진행·잔액이 바뀌지 않습니다. 배경 색은 듣기 문제의 정답과 연동하지 않습니다.
- 소유품 재장착과 무료 기본으로 돌아가기는 코인을 쓰지 않습니다. 잔액이 모자라면 필요한 차액을 보여 주고 구매를 막습니다. 구매 성공 후 장착 저장이 실패하면 보유 상태를 알리고 무료로 재장착하게 합니다.
- 한 장의 사건 6개와 소리 확인 2개를 모두 마친 완료 화면에서 **완주 코인 15개**를 한 번 지급합니다. `word-magic:chapter:<chapter-id>`로 새로고침·다시 열기·진행 초기화 뒤 중복 지급을 막습니다. 정답률 보상이 아니며 공통 일일 완주 보상 한도를 따릅니다. 그림 체험에는 지급하지 않습니다.
- 모든 표현·18개 문제·기본 실험실은 무료입니다. 상품 구매가 학습 해금이나 정답률에 영향을 주지 않습니다. 코인·구매·장착은 이 브라우저의 공통 저장소에 남으며 원격 계정 동기화는 이 범위에 포함하지 않습니다.
- 갖고 싶은 유료 상품을 **내 목표**로 직접 고르고, 변경·해제할 수 있습니다. 완료 화면과 실험실에 남은 코인/구매 가능 상태/달성 상태를 보여 줍니다. 구매 뒤에도 목표를 유지하며 실제 사용으로 연결합니다. 자동 목표 설정은 하지 않습니다.
- 구매 후 **실험실에서 바로 사용**으로 들어갑니다. 아직 배운 표현이 없으면 두 표현 튜토리얼을 먼저 거치고 **내 소품으로 놀기**로 구매한 세트에 바로 진입합니다. 이 진입 의도도 튜토리얼 중 새로고침 뒤 복원합니다.
- 실험실에서 **소리를 끝까지 듣고, 서로 다른 표현-물건 3쌍을 실제로 변경**하면 하루 한 번 **복습 코인 5개**를 받습니다. 최소 표현 2종·물건 2개가 필요합니다. 같은 상태를 다시 누른 것·소리 실패·그림 체험·튜토리얼은 제외합니다. 세트를 바꿔도 중복 지급되지 않으며, 서울 날짜와 공통 일일 보상 10회 한도를 따릅니다. 학습 정답률/Atlas 평가 이벤트로 올리지 않는 참여 보상입니다. 소리를 들은 증거는 이번 방문의 메모리에만 남고 새로고침으로 복원하지 않습니다. 저장 실패는 실제 증거를 유지한 채 재시도할 수 있습니다.
- 한영 안내, 320px, 키보드 Tab·Enter·Escape, 닫은 뒤 원래 단추로 초점 복귀, 저장 거부 안내와 재시도를 확인했습니다. [상점 QA](qa/SHOP-20261008.md)와 [소품·목표·복습 QA](qa/MOTIVATION-20261009.md)에 실제 확인 범위를 기록했습니다.

## 언어·입력·접근성

- 기본 조작 안내는 영어입니다. 상단의 `한국어`/`English`로 바꿀 수 있습니다. 배울 한국어 표현은 두 언어 모두 한국어 원문과 실제 한국어 소리를 유지합니다.
- 터치/마우스: 표현 → 물건. 키보드 A/S(실험실은 A/S/D/F/G/H)로 표현 선택, 1–4로 물건, R 다시 듣기, Esc 처음으로. 탭 이동과 Enter/Space도 됩니다. 한글 자판에서도 키 위치(`code`)를 사용합니다.
- 모든 사물에는 접근 가능한 이름과 실제 버튼이 있습니다. Canvas와 같은 위치의 버튼이 움직인 결과 위치도 따라갑니다. 작은 사물도 최소 44px 누름 영역을 가집니다.
- 동작 줄이기 설정에서는 크기/위치 전환과 해결 연출을 즉시 끝 상태로 보여 줍니다. 장식 반복 애니메이션·점멸·배경 음악은 없습니다.
- 진행 초기화는 확인 창을 거칩니다. 말의 마법사 진행만 지우며 다른 게임과 Atlas 공통 학습 기록을 삭제하지 않습니다. 저장을 사용할 수 없을 때는 이번 방문 동안 계속 플레이할 수 있다고 표시합니다.
- 다른 탭으로 이동하면 소리를 끊습니다. 끝까지 못 들은 확인 문항은 들었다고 처리하지 않으며 다시 듣기를 할 수 있습니다.

## 소리 준비와 그림 체험

`audio/manifest.json`과 여섯 MP3를 검증하고 디코딩한 뒤 듣기 모험을 시작합니다. 파일 누락·디코딩 실패·승인되지 않은 manifest면 시작을 막고 다시 시도할 수 있습니다. Windows/브라우저 TTS나 다른 목소리로 대체하지 않습니다.

첫 시작 클릭의 동기 실행 구간에서 AudioContext 생성·재개를 먼저 요청하고, 그 뒤 장면·manifest를 기다립니다. 이미 준비된 소리라도 컨텍스트가 멈췄으면 다시 재개합니다. 브라우저 자동 재생 허용 플래그 없이 첫 클릭 → 실제 튜토리얼 음성이 끝나는 경로를 검사하며, 실제 iPhone/Safari 스피커 검증을 대신한 것으로 보고하지 않습니다.

현행 음성은 2026-10-08 Typecast **서현** 6개입니다. 정확한 원문: `커져요`, `작아져요`, `열어요`, `닫아요`, `위`, `아래`. 파일별 길이와 SHA-256은 manifest, 원본 생성·후처리 증거는 `../beginner-games/qa/voice.source.json`에 있습니다. manifest의 `provider`는 공개 파일이라 만든 서비스 이름 대신 중립 값 `approved-voice-v1`입니다(2026-10-19, [입문 게임 원문 「음성 준비」](../beginner-games/README.md#음성-준비)). 효과음은 마법·해결 뒤 짧은 Web Audio 음이며 한국어 음성과 별도입니다.

음성을 사용할 수 없거나 먼저 화면을 둘러보고 싶으면 **그림으로 체험**을 선택합니다. 이 경로는 음성 없이 진행한다는 표시를 유지하고, 학습 기록을 만들지 않으며 정식 해금·진행·실험실 저장과 섞지 않습니다. 18개 사건을 체험하면 별도 임시 실험실에 들어갈 수 있습니다. 처음으로 돌아오면 정식 진행으로 복귀합니다.

## 학습 범위와 Atlas

`learning.mjs`는 기존 `SynkLearning` 계약을 사용합니다. `ko.listening.word`, 언어 난도 1, 듣기, 응답 형식 `action`입니다. 음성 전달 완료 → 최초 응답을 저장하고 `replay`, `text`, `hint`를 공통 기록에 따로 남깁니다. 정답을 알아보기 전 중단한 문항은 평가하지 않습니다. 퍼즐의 물건 조작·문제 해결·해금·실험실·사진 저장을 언어 정오로 올리지 않습니다. 공유 기록이 없어도 게임의 기본 모험은 계속합니다.

2026-10-08 최종 검토에서 확인 장면의 물체가 정답과 반대 상태라 시각만으로 답을 추론할 수 있던 점을 고쳤습니다. 수정 문항은 의미별 `word-magic.size.grow.v2` 같은 itemKey와 familyKey를 사용합니다. 이전 시각 단서가 있던 v1 문항과 동일한 독립 문항으로 취급하지 않습니다. 로컬 확인 결과도 `version:2`를 남깁니다.

TOPIK I의 기초 어휘·짧은 표현 듣기를 준비하는 연습입니다. 전체 시험, 말하기·쓰기, TOPIK 급수나 점수, 학생 대상 기억 향상·재미의 효과를 검증했다는 뜻이 아닙니다. 6개 확인 문항은 이 콘텐츠 안의 소리-뜻 연결 관측입니다.

`atlas-learning.js`는 `node tools/build-game-learning.js` 생성본, `kit/`은 `node experiences/play-common/build-kit.mjs`의 원본 복사본입니다. 둘 다 직접 수정하지 않습니다. 라이브 배포·계정별 원격 학습 동기화는 이 폴더의 로컬 검증 범위에 포함하지 않습니다.
