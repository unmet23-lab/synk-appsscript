# SYNK WORLD 홈 — 실제 3D 미술 시제품

이 문서는 2026-10-09의 3D 홈 시제품을 설명한다. `../scene.mjs`는 이 시제품의 실제 WebGL 장면이며 완성된 타운·캐릭터 자산을 대신하지 않는다. 현재 WORLD의 [3D 그래픽 방향](../../../docs/디자인/게임_풍경과_재질.md)과 10-14 이후 [2D 화면 기준](../../../docs/디자인/월드_시그널/README.md)을 구분해 적용한다.

- 승인 참조: `docs/캐릭터/화면_1024/몽글_본체.webp`. 팔·귀·입 없이 종형 몸, 검은 두 눈, 물결 밑단과 봉제선을 구현했다. 본체는 LatheGeometry 기반 변형 메시다.
- 나무 데크·벤치, 테라코타 화분, 잎, 돌 탁자, 도자기와 차, 입체 원경을 재료별로 구분했다. 몽글은 승인된 `assets/felt-coral.webp` 표면을 입체 메시의 색·요철 맵으로 쓰며, 절차적 재료와 짧은 3D 섬유도 사용한다. 표면 파일이 없으면 절차적 펠트로 대체한다.
- `mountHomeScene` 반환 API: `setOutfit('none'|'scarf'|'apron')`, `setTime('day'|'sunset')`, `greet()`, `capture()`, `dispose()`, `metrics()`.
- 휴대폰 DPR 1.5 / 넓은 화면 2 상한, 정적인 홈의 30 Hz 애니메이션 상한, 화면 밖·백그라운드 정지, 움직임 감소 설정, 크기 관찰, 키보드 좌우/Home/Enter와 좌우 드래그를 지원한다.
- 장면은 새 미술 시제품이며 승인 원본의 최종 게임 모델이 아니다. 아티스트의 모델·섬유·착용 변형 확정, 본 제작용 뼈대·LOD·최적화가 남아 있다. 실제 S25·iPhone 15 지속 성능·발열을 측정했다는 뜻이 아니다.
- Three.js는 저장소의 MIT 라이선스 배포본을 자체 호스팅한다. `THREE-LICENSE.txt`를 보존했다. 별도 유료 모델 생성·외부 이미지 의존성은 없다.

## 로컬 검수

2026-10-09 Edge headless에서 1000×480과 390×400을 렌더하고 `scene-desktop.png`, `scene-mobile.png`, `scene-sunset.png`를 직접 확인했다. 과노출·가려진 데크·접촉 그림자·코스튬 색과 실제 펠트 표면을 수정한 뒤 재검사했다. 검사 페이지 JavaScript 오류는 없었다. `verify.cjs`는 독립 장면 확인용이며 앱 전체·실기기 검사를 대신하지 않는다.

2차 합성 검수에서는 눈의 투영 위치를 올리고, 정면 3개의 물결 밑단과 봉제선을 맞췄다. 펠트 범프 0.012·짧은 섬유 투명도 0.15·중성 광원으로 거친 반짝임과 주황 과포화를 줄였다. 잎은 실제 곡면 격자·중앙맥·작은 잎으로 보완했고 그림자를 더 부드럽게 했다. `scene-ui-desktop.png`(1440×1100)와 `scene-ui-mobile.png`(390×844)는 실행 중인 4295 앱 합성 캡처다. 캔버스는 투명하고 전경 바닥은 페이드된다. UI의 연결 배경은 낮 `#e9efeb`, 노을 `#eddbcd`다. 사진 저장은 현재 시간의 불투명 하늘색을 포함한다.
