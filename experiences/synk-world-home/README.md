# SYNK WORLD 메인 화면

2026-10-09 사용자가 승인한 [공통 3D 그래픽 방향](../../docs/디자인/게임_풍경과_재질.md#world-graphics-20261009)을 적용한 로컬 프런트 시제품이다. 휴대폰과 PC를 각각 설계하고, 실제 3D 장면과 기존 콘텐츠를 연결했다.

**후속 발전 기준으로 채택(2026-10-09):** 사용자가 완성 화면을 확인하고 「훨씬 괜찮네. 고생했어. 앞으로 이 방향을 발전시키는거로 하자」고 확정했다. 캐릭터 중심 홈·촉감 있는 3D 재질·휴대폰 우선 구성을 유지하며 이 구현을 발전시킨다. 최종 캐릭터 모델과 본 제작 엔진의 확정은 별도다.

**현행 그래픽 v3(2026-10-09):** 사용자는 그래픽의 방향만 맞으며 아직 품질에 만족한 것은 아니라고 명확히 했다. 이에 [v3 공통 몽글·재질·풍경](scene-assets/graphics-v3/README.md)을 기본 홈에 적용했다. `graphics.html`에서 v1/v2/v3를 비교하며 `?graphics=1`, `?graphics=2`로 이전 화면도 볼 수 있다. 짧은 펠트 결·개별 실땀, 두께와 주름이 있는 코스튬, 건물 모서리와 곡면 잎, 도시의 깊이·수면 반사를 개선했다. 레이싱 이상 품질 달성이나 최종 마스터 승인으로 해석하지 않는다. 첫 진입·계정·보상·사진과 타운 연결은 [4296 앱 개발판](../synk-world-app/README.md)이 담당한다.

**추가 개선 v4(2026-10-09):** 호환되는 `scene-v3.mjs`·`avatar-v3.mjs` 경로를 유지하며 환경 revision `environment-v4`, 캐릭터 재질 revision 4를 기본으로 올렸다. 펠트 색과 미세 요철을 분리하고 니트·면·접촉 음영·햇빛과 재료 차이를 보완했다. 선명도 3단계, 가려진 홈 정지, 그래픽 연결 손실 복구, 고해상도 사진과 로딩 기한도 반영했다. [현재 화면·검수·남은 일](../synk-world-app/qa/V4.md)이 최신 기록이다. 비교 화면의 세 번째 `촉감과 빛`이 이 개선본이다.

**추가 개선 v8(2026-10-09):** 한강을 천천히 지나는 배와 물살·접촉 음영·근사 반사를 추가했다. PC/휴대폰의 초기 가시성, 기존 움직임 정지·사진·복구 연결을 검사했다. 러그의 데크 접촉·직조 단면, 화분의 연속 내벽·림과 목재/돌/잎의 요철 방향을 다듬었다. [현재 화면·검수](../synk-world-app/qa/V8.md)가 최신 기록이다.

**추가 개선 v7(2026-10-09):** 얇은 잎의 빛 반응, 도시 배치를 사용한 가벼운 강물 반사·잔물결, 거리/높이 대기색과 곡면 기와·강변 수관을 보완했다. 새 화면 버퍼·광원 없이 기존 움직임 정지/사진/복구 경로를 이어간다. [v7 검수](../synk-world-app/qa/V7.md)는 이전 기록이다.

**추가 개선 v6(2026-10-09):** 목재·석재·잎의 색/요철/거칠기를 분리하고 연결된 잔가지·비대칭 잎, 건물 입면·수관·부드러운 산 능선을 구현했다. PC에는 접촉 음영을 더했으며 휴대폰 균형/가볍게는 추가 렌더 버퍼를 쓰지 않는다. 초기 렌더 실패 자원 정리까지 재검수했다. [v6 화면과 검수](../synk-world-app/qa/V6.md)는 이전 기록이다.

**추가 개선 v5(2026-10-09):** 층진 강변 도시·수목·교량과 산의 거리감, 창가 커튼·종이등·직조 러그 등 근경 마감을 보완했다. 직사광/반사광과 글자 뒤 페이드를 정리하고, 그림자와 일치하는 작은 잎 움직임을 추가했다. 홈의 **가까이 / 기본 시점**과 실제 카메라 회전이 동작한다. [v5 화면·검수·보상 연결의 남은 계약](../synk-world-app/qa/V5.md)은 이전 기록이다. 공통 아바타 자산 자체는 v4 후보를 유지한다.

## 실행과 화면

저장소 루트에서 실행한다.

```powershell
node experiences/synk-world-home/server.mjs
```

- 휴대폰: <http://127.0.0.1:4295/mobile.html> — PC에서 열어도 휴대폰 폭으로 표시한다.
- PC: <http://127.0.0.1:4295/desktop.html> — 넓은 장면과 왼쪽 탐색 메뉴를 사용한다.
- 자동 반응형: <http://127.0.0.1:4295/>

계정과 보상이 연결된 현재 작업 화면은 **4296**이다. 위 4295 서버는 독립 미리보기용이며 따로 실행해야 한다.

서버는 이 컴퓨터의 127.0.0.1에만 바인딩한다. 외부 공개나 실제 휴대폰 접속용 배포는 아니다. 포트 변경은 `SYNK_HOME_PORT` 환경변수를 사용한다.

## 구현된 동작

- 실제 3D 테라스: 팔 없는 몽글, 펠트 표면과 봉제선, 나무 데크·벤치, 돌 탁자, 도자기, 화분, 산과 도시 원경. 낮·노을 전환, 인사, 좌우 보기.
- 옷장: 기본 차림·목도리·앞치마를 3D 메시로 교체한다. 차림과 시간대는 로컬에 저장한다.
- 공통 캐릭터: `avatar-v3.mjs`의 한 factory를 홈과 타운에서 사용한다. `avatar-contract.json`이 몽글·몸/목 슬롯·서버 아이템 ID를 명시한다. 독립 미리보기는 로컬 차림, 4296은 서버가 확인한 보유품과 차림을 표시한다.
- 사진: 현재 3D 장면과 차림·시간대를 실제 PNG로 저장한다. 비회원 사진은 미리보기임을 표시하며 계정 연결판에서는 서버 상태를 확인한 뒤 촬영한다.
- 미니게임: 기존 바람길·말의 리듬을 모달 안에서 실행한다. 해당 게임 원본은 수정하지 않았다.
- 노래로 배우기: 기존 모음 댄스·그 아 가·받침 노래 MP4를 선택할 때 불러와 재생한다. 닫으면 재생기를 제거한다.
- 싱크 타운: 입장 조건과 미리보기를 안내하고 기존 한글 단계로 연결한다. 실계정 학습 기록이나 이용권이 확인된 것처럼 표시하지 않는다.
- 휴대폰 하단 탐색, PC 왼쪽 탐색, 화면 설정·움직임 감소, 키보드 포커스 복귀, WebGL을 사용할 수 없을 때 승인 몽글 이미지 표시.

승인 이미지·펠트 부품·서체와 기존 콘텐츠의 복사 출처는 `asset-sources.json`, 복사 절차는 `prepare-assets.cjs`에 있다. 신규 이미지·영상 생성은 하지 않았다. Three.js MIT 라이선스는 `scene-assets/THREE-LICENSE.txt`에 보존했다.

## 검수와 개선

1차 화면 검수 뒤 휴대폰 버튼 줄바꿈·작은 보조 글자·옷장 이미지 크기·3D와 배경의 경계를 수정했다. 몽글의 눈 위치·물결 밑단·봉제선·펠트 요철·광원과 잎·그림자도 다시 다듬었다. 독립 검수에서 발견한 휴대폰 화면 설정 진입 누락을 보완했다.

`qa/verification.json`: Edge 브라우저 자동 검증 **32개 통과, JavaScript 오류 0개**. 1440px PC, 390px·320px 휴대폰 뷰포트, PC 안 휴대폰 표시, 이미지·서체 로딩, 초기 영상 요청 지연, 코스튬·조명 상태와 실제 장면 연결, 설정, 포커스, 새로고침 유지, 영상 3편의 디코딩·진행·탐색·닫기, 타운 안내, WebGL 대체 화면을 확인했다. 기존 게임 실행은 독립 검수의 `qa/review-agent-interaction.json`에 기록했다.

최종 화면: `qa/desktop-final.png`, `qa/mobile-final.png`, `qa/mobile-small-final.png`, `qa/mobile-wardrobe-final.png`, `qa/mobile-video-final.png`. 화면을 직접 확인하고 마감을 수정한 결과다. 검증 스크립트 `qa/verify-home.cjs`는 현재 로컬 Playwright·Edge 경로를 사용한다.

위 32항목과 화면은 최초판 기록이다. v3의 현재 앱 화면은 [통합 검수](../synk-world-app/qa/V3.md), [PC](../synk-world-app/qa/v3-final-pc.png), [390px](../synk-world-app/qa/v3-final-phone.png)를 본다. 기본 v3·세 버전 전환·네 차림·시간대·움직임 감소·연속 전환·실제 캔버스 표시 29항목, 앱 흐름 35항목을 별도로 확인했다.

## 남은 제작 범위

이번 결과는 Three.js로 동작하는 웹 프런트와 3D 미술 시제품이다. Unity + URP 제작 권고를 바꾸거나 Unity 네이티브 앱 구현을 완료한 결과가 아니다. 몽글은 승인 이미지를 참조해 만든 절차적 모델이며, 최종 승인된 게임용 마스터 모델은 아직 없다.

현재 공통 몽글의 정적 원본 후보는 [mongle-v4.glb와 Blender 파일](scene-assets/graphics-v4/README.md)이다. 새 미세 normal·AO/roughness·정점 색을 보존해 GLTFLoader 82항목과 Blender 가져오기를 확인했다. 리깅·애니메이션·URP용 재질 변환과 Unity 렌더는 아직 없다. 코스튬의 실제 소유권·획득 연결 범위는 4296의 합성 시험 계정이며 운영 SYNK ID 전체 연결과 구분한다. 본 제작에는 최종 모델 조형·리깅·추가 의상 조합과 가림 처리, Galaxy S25·iPhone 15의 지속 성능·발열·터치 검수가 남는다. 사용자의 이번 범위는 코드·브라우저 검증까지다. 영상은 기존 파일의 재생을 확인했으며 전편 음성 청취 검수는 별도다.
