# 홈 환경·렌더 수명 개선 · 2026-10-09

이번 결과는 v3의 환경 렌더와 수명 관리를 개선한 로컬 구현이다. 승인된 그래픽 방향을 발전시키는 중이며 완성품 승인이나 레이싱 이상의 품질 판정은 아니다. 캐릭터 조형 작업과는 편집 범위를 나누었다.

## 화면 변화

- 햇빛을 옆에서 받도록 조정하고 전체를 고르게 밝히던 빛을 줄였다. 낮의 따뜻한 면과 차가운 그늘, 노을의 따뜻한 면과 회보라색 그늘을 구분했다.
- 바닥·석재·회벽·목재·도자기의 색과 거칠기에 작은 차이를 주고 유리와 도자기의 반사를 분리했다.
- 가구·화분·건축 바닥의 접촉 음영은 **512px 고정 atlas 한 장**을 한 번 만들고 바닥 재질에서 읽는다. 화면 전체 SSAO 패스나 화분마다 추가 그림자 평면을 만들지 않았다. 마당을 회전해도 같은 자리에 붙는다.
- 화분은 직선 원뿔에서 가운데가 미세하게 부푼 곡면으로, 쿠션은 눌린 구체에서 모서리가 부푼 형태로 수정했다. 지붕 이음은 인스턴스 한 묶음이다.
- 먼 산은 메시 밀도를 줄이는 대신 계곡 굴곡과 숲·능선의 색 차이를 보완했다. 먼 도시의 창 대비와 높이를 다양하게 조정했다.

실제 PC·390px 낮/노을을 보고 한 번 더 수정했다. `capture.cjs`와 `preview.html`은 런타임을 직접 렌더하며 최종 캡처와 값은 `capture.json`에 있다. `before-*`는 비교를 위한 이전 코드/화면이며 앱에서 쓰지 않는다.

## API 호환과 추가

`graphicsVersion: 3` 및 기존 메서드는 유지한다. `metrics.visualRevision`은 `environment-v4`다.

- `mountHomeScene(container, {quality:'balanced'})` / `setQuality('balanced'|'detail'|'light')`: 장면을 다시 만들지 않는다. 휴대폰 DPR은 각각 1.5 / 2 / 1, PC는 2 / 2 / 1.25까지이며 장면의 실제 그리기 픽셀은 최대 3M이다. 그림자 맵은 균형 1024/2048, 선명 1536/2048, 가볍게 512/1024다. 화면 크기를 바꿔도 정책을 다시 적용한다.
- `setActive(false)`는 애니메이션 프레임을 취소한다. `true`로 재개한다. 모달 뒤나 타운을 보는 동안의 홈 정지는 앱이 이 메서드로 지정한다.
- `setReducedMotion(bool)`는 전체 장면을 다시 생성하지 않고 동작한다. 운영체제의 움직임 줄이기를 함께 존중한다.
- `capture({highResolution:true})`는 촬영 때만 최대 긴 변 1920, 2.6M 픽셀, DPR 4까지 올린다. 사진을 얻은 뒤 `finally`에서 원래 해상도로 복귀한다. 기본 `capture()`는 기존 옷장 미리보기 해상도를 유지한다.
- 비활성 장면의 한 장 촬영은 허용한다. 해제·WebGL context loss·셰이더 실패 상태에서는 빈 PNG를 반환하지 않고 오류를 던진다. 셰이더 실패는 `onError`로 알리고 초기 실패 시 준비 완료 콜백 없이 장면을 해제한다.
- 선택 텍스처는 요청당 12초 기한이 있다. 지연된 텍스처가 뒤늦게 도착하면 해제한다. 실패는 `metrics.assetFailures`에 기록하며 기본 재질/환경광으로 렌더할 수 있다.

## 실제 검사와 예산

`verification.json`에는 품질 3단계, 정지·재개, 고해상도 사진과 해상도 복귀, 런타임 reduced motion, WebGL loss, 해제, 12초 텍스처 지연 및 뒤늦은 해제, 잘못된 GLSL 주입 결과를 기록했다. 390×465 장면의 사진은 **1476×1760**으로 생성했다.

`budget.cjs`는 같은 브라우저 문서에서 같은 아바타 모듈을 재사용하면서 이전/현재 환경을 비교한다. 당시 아바타 파일 해시는 `budget.json`에 보존한다.

| 동일 아바타·픽셀 비교 | 이전 | 환경 개선 후 |
|---|---:|---:|
| PC 삼각형 | 265,336 | 246,708 |
| 휴대폰 삼각형 | 221,224 | 202,020 |
| PC draw calls | 155 | 156 |
| 휴대폰 draw calls | 127 | 128 |
| PC 렌더 제출 CPU 중앙값, 9회 | 2.5ms | 2.1ms |
| 휴대폰 렌더 제출 CPU 중앙값, 9회 | 3.4ms | 3.5ms |

이 CPU 시간은 `renderer.render` 호출의 벽시계 시간이며 GPU 타이머·FPS가 아니다. 브라우저의 휴대폰 크기 검수는 S25·아이폰 15 실물의 지속 성능/발열 검증을 대신하지 않는다. 30Hz 상한과 비활성 탭·화면 밖 정지는 유지했다. 실제 기기의 예산 판정은 별도다.

새 외부 패키지·다운로드·이미지 생성·유료 API 없이 기존 재질과 직접 만든 메시/셰이더를 사용했다. 런타임 접촉 음영과 셰이더는 GLB의 제작용 노멀·AO·거칠기 굽기를 대체한 최종 자산이라고 주장하지 않는다.
