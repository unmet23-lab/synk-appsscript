## 검수 후 수정

목도리의 니트·처짐·끝 술, 타일 베벨, 그림자면의 반사광, 도시의 접지, 실제 깊이가 있는 산, 식물의 잎 크기와 줄기를 다듬었다. PC 글자 뒤에 밝은 면을 확보하고 휴대폰은 캐릭터와 시작 버튼에 맞춰 장면 높이를 조절했다. 320×740에서 시작 버튼이 하단 탐색에 가려지는 문제를 수정했다.

반복 비교 시 인스턴스 버퍼와 그림자 렌더 타깃의 해제 누락을 발견해 고쳤다. 폐기한 WebGL 컨텍스트도 반납한다. [독립 검수](disposal-verification.json)에서 네 차례 생성→동시 착용→낮/노을→캡처→이중 dispose를 확인했고, 각 회차 컨텍스트 해제·캔버스 제거, 남은 캔버스 0개·경고/오류 0건이었다.

세로 높이를 줄이는 CSS가 있는 화면의 full-page 캡처 중 3D가 빈 캡처가 한 번 있었다. 실제 320×740 뷰포트에서는 재현되지 않았다. full-page 캡처가 높이 미디어쿼리를 바꾸며 정지된 WebGL 캔버스를 리사이즈한 것으로 추정한다. 검수는 실제 뷰포트 캡처와 캔버스 픽셀 검사를 함께 사용한다.

## 측정의 범위

비교 페이지 낮·동시 착용의 한 프레임 기준 PC 129 draw calls / 205,402 triangles, 390px 88 / 173,070, 320px 80 / 172,794였다. 카메라와 화면에 따라 수치는 달라지며 이 수치로 실제 프레임·발열을 판정하지 않는다.

실물 S25/iPhone 15, Unity 네이티브 빌드, 장시간 성능, 최종 모델·모든 의상 조합, 실계정 보상/기기 간 저장은 이번 그래픽 검수 범위 밖이다. 기존 계정·보상 연결의 별도 검수 기록을 대체하지 않는다. 이 결과는 미술 개선 시제품이며 레이싱 이상의 최종 품질을 달성했다고 판정하지 않았다. 다음 우선순위는 [정식 몽글·의상 자산과 장면 제작](../../scene-assets/graphics-v2/README.md)이다.
