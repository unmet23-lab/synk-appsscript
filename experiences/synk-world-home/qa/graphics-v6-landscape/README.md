# 강변 원경 v6 — 형태와 입면 개선

2026-10-09. `scene-v3-garden.mjs`의 `makeLandscape`만 수정했다. 건물 70동·수관 185개는 유지하고 반복 창문 상자와 구형 수목의 조형을 개선했다. 새 런타임 import, 다운로드, 이미지 생성, 후처리 패스는 없다.

- 건물 본체는 모서리 면과 상단 베벨을 가진 공통 메시를 사용한다. 하부의 정점 색은 접촉 음영이며 낮/노을의 방향광은 실제 면의 노멀로 받는다. 길게 늘어나는 산책로·교량은 별도 상자 메시를 유지한다.
- 유리 탑은 연속된 수직 유리 띠와 높이별 반사 색, 주거동은 창과 돌출 층판을 쓴다. 건물마다 작은 회전을 적용해 측면이 보이게 했다. 먼 건물은 창문 행 수를 줄여 격자 노이즈와 삼각형을 회수했다. 창문 면은 2,872→1,270개다.
- 강변 수관 82개는 네 개의 비대칭 잎 군집, 먼 숲 수관 103개는 두 군집을 사용한다. 수관 아래의 줄기·분기와 어두운 하부 정점 색을 더해 떠 있는 한 덩어리 구형을 바꿨다. 깊이별 형상 분할이며 런타임 거리에 따라 바뀌는 LOD 시스템이라는 뜻은 아니다.
- 검수에서 발견한 맨 뒤 건물과 산 지형의 교차를 수정했다. 산에 가려 창문만 떠 보이던 배치를 산의 앞쪽으로 옮겼다.
- 최종 합성 화면에서 각진 산 꼭대기를 재검수했다. 지형을 96×16→256×6으로 재분할해 동일한 삼각형 수를 수평 능선에 집중하고, 날카로운 계곡 형태는 사면 중심으로 낮췄다. 넓은 입체 산을 유지하며 꼭대기가 긴 직선으로 이어지는 인상을 줄였다.
- `group`, `ridgeMaterials`, `buildingMaterials` 반환과 공통 수면 재질은 유지한다. 승인 몽글·코스튬과 근경 정원은 이 작업에서 수정하지 않았다.

## 고정 조건 A/B

실행: `node experiences/synk-world-home/qa/graphics-v6-landscape/compare.cjs`

v5의 작업 시작 소스는 `before-garden.mjs`, 당시 이미지 참고는 `reference-v5-*.png`로 보존한다. 실제 비교 캡처는 같은 현재 scene·근경 정원·캐시된 아바타를 사용하고 `makeLandscape`만 v5/v6로 교체한다. 따라서 병행한 조명·근경 식물 변경을 원경 비용에 섞지 않는다. 소스 SHA는 `comparison.json`에 기록한다.

| 전체 렌더 패스 합계 | v5 원경 | v6 원경 |
|---|---:|---:|
| PC 삼각형 | 575,540 | 594,596 |
| PC draw call | 417 | 423 |
| 휴대폰 크기 삼각형 | 364,330 | 377,034 |
| 휴대폰 크기 draw call | 245 | 249 |

최종 렌더러 통계는 그림자와 선택적 AO를 포함한다. 같은 렌더러에서 원경만 교체한 총 삼각형은 PC +3.31%, 휴대폰 크기 +3.49%다. 신설된 두 batch는 베벨 건물 본체와 깊이별 수관이며, 기하 패스마다 두 번의 호출이 추가되어 PC 3패스에서 +6, 휴대폰 2패스에서 +4가 된다. 검사도 전체 삼각형 +4%, 기하 패스당 batch +2를 기준으로 한다. 이전의 beauty 단일 패스 통계와 총합 수치를 직접 비교하지 않는다.

15개 검사 통과: 런타임·셰이더 오류 0, 캔버스 하나, 정점·노멀·행렬 유효값, 결정적 seed, 공통 물 재질, 삼각형·draw call 예산, 건물/수관 개수 유지와 창문 수 감소. PC 1400×720와 휴대폰 크기 390×465의 낮/노을 전후 캡처 8개를 보존했다. 마지막 PC 낮·휴대폰 노을 캡처를 직접 확인했다. `node --check`, 범위 지정 `git diff --check`도 통과했다.

산만 수정한 비교는 `node experiences/synk-world-home/qa/graphics-v6-landscape/compare.cjs --ridge`로 실행한다. `before-ridge-v6.mjs`, `ridge-*.png`, `ridge-comparison.json`을 보존했다. 두 버전의 건물·수관 코드는 바이트 단위로 동일하고, PC 594,596 삼각형/423 calls와 휴대폰 377,034/249가 전후 동일하다. 15개 검사가 통과했으며 PC 낮과 휴대폰 노을 이미지를 직접 확인했다.

CPU 제출 시간은 각 JSON의 진단값으로만 기록한다. 이는 헤드리스 PC 브라우저의 수치이고 GPU 시간·FPS·Galaxy S25/iPhone 15의 지속 성능을 입증하지 않는다. 정식 환경 자산·휴대폰 발열과 장시간 검수는 남아 있다. 병행한 조명/근경 개선까지 포함한 최종 화면 판단은 루트 작업의 통합 캡처를 따른다.
