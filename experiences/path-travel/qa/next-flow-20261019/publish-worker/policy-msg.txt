perf(travel): show change previews without waiting for the follow-up question, and ask it after the change is taken

PATH planner from synk-appsscript d141520fb (origin master), applied on top of the live
files only: planner-ui.mjs takes the change as the same path rewrite as before.

- Quick changes, answers, adding or swapping a place and the rest-of-the-day replan now
  compute their preview without the "which way fits better" question, so the preview shows
  right away (on the live page the less-walking preview: about 0.9 s before, about 0.3-0.5 s
  with this file).
- When a preview is taken, the question is asked from the module worker with the same time
  and conditions written down with the preview; the remaining-day replan passes only the picks
  the planner actually used. Without a worker the page computes it as before and leaves one
  console warning.
