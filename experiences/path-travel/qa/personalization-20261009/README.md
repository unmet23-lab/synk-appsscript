# PATH 여행 v4 후속 개인화·장소 자료 보강

2026-10-09. 사용자 “이어서 해”에 따라 **세부 취향과 실제 장소 정보**를 먼저 보강했다. 로컬 구현과 공개 후보 묶음까지 완료했으며 원격 배포·실계정 사용·현장 여행 만족도 검증은 하지 않았다.

## 바뀐 사용자 흐름

- 선택형 추가 입력으로 면 요리·만두·국물·사찰음식·시장음식·커피·베이커리·전통차를 선호/회피/이번 여행 미지정으로 구분한다. 총 19개 의미 조건을 보관·철회할 수 있다. 자료가 없는 특성은 회피 조건 충족으로 표시하지 않는다.
- 기존 총도보 상한에 더해 한 구간 도보 상한을 따로 지킨다. 약 30~180분 간격의 5~30분 쉬는 여유는 실제 체류와 종료·폐관 시각에 반영한다. 보행 중에는 다음 장소에서 쉬도록 배치하며 좌석·쉼터는 미확인이다.
- 결과를 바꿀 추가 질문만 보여 주고 양쪽 답의 실제 장소·시간·도보·확인된 비용 부분합을 비교한다. 비교 후 수락해야 적용한다. 질문은 기존 Core Ask를 재사용하고 PATH 결정 signature를 실제 일정 내용으로 고쳤다.
- 식음료 8곳, 공식 출처 17개, 메뉴 19개 중 표시금액 9개를 메뉴 단위·확인일·출처와 함께 보여 준다. 단위 불명 코스 가격을 성인 인원수로 곱하지 않는다. 공식 운영 충돌은 미확인으로 유지한다. 프릳츠 메뉴는 2023년 소개라는 한계를 카드와 상세에 표시한다.
- 사진 없는 식음료 카드에는 확인된 메뉴를 보여 준다. 기존 실제 사진 11개는 유지했고 신규 사진은 미채택했다. [사진 조사와 보류 사유](photo-research.json).
- 평소 취향 변경 시 이전 질문·대안·적용 대기안을 무효화하고 현재 일정을 유지한다. 방문 기록 수정 후 새 기록 ID를 사용해 후속 취향 확인을 복구했다. 예시 조건을 누르면 수정 상태가 되어 과거 대기안이 덮어쓰지 못한다.

## 검증

- 여행 전체 자동 검사 **228/228**: [실행 기록](tests.tap).
- 공개 후보 빌드 **7/7**, 정확한 71개 런타임 파일: [실행 기록](build-tests.tap).
- SYNK-talk 개인자료·미디어·여행 검사 **21/21**와 최신 생성본 --check 통과. 원격 DB·운영 등록은 수행하지 않았다.
- 실제 자료 8개 세부 취향의 선호/회피 16개 결과 및 OSM 계산에서 장소가 달라짐, 미확인 회피를 보장하지 않음, 질문 미리보기와 수락 결과 일치, 구간 상한·휴식·폐관·교체 검사를 포함한다.
- 실제 브라우저는 사용자 저장본과 분리한 localhost:4305에서 1280·390·320px로 확인했다. 만두 선호+커피 회피+한 구간20분+1시간마다10분 휴식 → 실제 일정, 질문 비교→수락, 보관동의→새로고침 후 조건·시간표 복원, 만두 회피 변경 후 다른 식당 선택, 메뉴 가격·근거·예약 안내, 모바일 질문 카드와 가로 넘침 없음 확인. PC의 화면 크기 검사이며 실기기 여행 검증은 아니다.
- 자동 검사는 한 번 출처 대장이 저장되기 전 ENOENT 1건으로 실패했다. 대장 완성 후 같은 전체 검사를 재실행해 228/228 통과했으며 검사 완화는 없다.
- 최종 브라우저 콘솔 error/warn은 없었다. 검증용 4305 저장본은 UI에서 초기화했고 검증 탭·서버를 종료했다. 사용자 4304 기록은 변경하지 않았고 최신 입력/메뉴가 있는 원래 화면과 health 응답을 확인했다.
