## 왜 엉망으로 보였나

공개본(`https://synk.im/try/travel/`)과 로컬은 빌드 경로 말고 같은 판이었다(10-19 대조).

- 한글 라벨에 DM Mono가 들어가 띄어쓰기가 모노 칸으로 벌어졌다(「한  끼의  즐거움」).
- 펠트 그림을 단추 크기로 통째 늘려(`background-size:100% 100%`) 단추마다 찌그러지거나 납작하게 늘어났다.
- 장소 카드마다 영문 사진 출처 세 줄. 사진 없는 12곳은 큰 글자 상자였고 휴대폰에서 숙소 이름이 상자 밖으로 넘쳤다.
- 결과에서 조건 폼이 옆에 붙어 위가 잘린 채 보였고, 지도는 양옆이 빈 가로 띠, 일정은 그 아래 따로 쌓였다. 장소마다 펠트 단추 셋.
- 한글 10~12px, 굵기 750~800, 왼쪽 색 막대 상자.

## 새 구조

- **첫 화면**: 왼쪽 큰 북촌 사진(제목·장소 수·「내 하루 만들기」를 사진 위에) → 실제 사진으로 된 예시 하루 셋 → 「실제 장소로만 · 시간표와 걷는 길 · 고쳐 쓰는 하루」 | 오른쪽 조건 카드. 자세한 조건 여섯 묶음은 「조건 더 맞추기」 하나로 접는다.
- **결과 화면**: 위에 붙은 조건 막대(적용한 조건 칩 + 「조건 고치기」로 같은 폼을 세 칸으로 펼침) → 왼쪽 일정(출발 → 걷기 → 번호 카드, 이름·사진을 누르면 상세, 단추는 「이곳은 유지」·「다른 곳으로 바꾸기」·조용한 「자세히」) | 오른쪽 화면 높이 지도(붙어 따라옴, 번호 범례를 지도 위에). 「여행 중이라면 →」은 출발 줄에.
- **휴대폰**: 일정 기본 + 아래 가운데 떠 있는 「하루 일정 / 지도 보기」, 빠른 바꾸기 2×2, 조건을 고칠 때 만들기 단추가 화면 아래에 붙는다.
- **사진 없는 곳**: 다른 곳 사진을 빌리지 않고 분야 색 정보 카드(바느질 점선) — 확인한 메뉴, 없으면 「지역 · 공식 안내로 확인」. 「모두」에서는 사진 둘 · 정보 하나 순으로 섞는다. 사진 출처는 상세와 「사진 출처 보기」, 지도 출처는 지도 아래 늘 보인다.
- **펠트 부품**: 아홉 조각(`border-image`)으로 써서 바느질 테두리가 늘어나지 않는다.
- **글자**: 큰 제목 680 · 카드 제목 650 · 강조 600 · 라벨 550 · 본문 450, 한글 13px 이상(공용 계정 카드 12px도 이 화면에서만 13.5px로), 한글 라벨 모노 없음, 영문 눈썹 글은 한국어로, 왼쪽 막대 대신 LED 점 안내 상자.
