## 진행 기록 (본 순서대로)

### 1. board-pc.jpg / board-m.jpg (비교판)
- PC 첫 화면: 뼈대가 실제로 바뀜(왼쪽 큰 사진+제목 / 오른쪽 조건 카드). 원래의 「제목 → 폼 왼쪽 길게」 겹이 사라짐. 좋음.
- PC 결과: 왼쪽 시간표 | 오른쪽 지도 2단. 조건 칩 막대 위. 원래의 「폼 옆에 잘려 붙음」 문제 해소.
- PC 결과 눈에 띄는 점: 빠른 바꾸기 단추 5개가 2줄로 꺾여 「여행 중 · 남은 일정 맞추기」 하나만 둘째 줄에 외톨이. 1번 장소 카드에 「차와 카페」 펠트 칩이 사진 자리(썸네일 자리)에 들어가 있음(=사진 없는 곳 정보 카드인 듯). 지도 아래 「1 프린츠 원서 2 어니언 안국 3 오설록…」 범례가 지도 위 번호와 동일.
- 지도 범례: 「번호 범례를 지도 위에」라고 했는데 보드에서는 지도 하단 띠 안.
- PC 결과 왼쪽 열 폭: 시간표 쪽이 지도보다 좁아 보임(약 45:55?). Wanderlog 벤치마킹은 일정 55%.
- 휴대폰 첫 화면: 큰 사진 위 제목 + 「내 하루 만들기 ⌄」 단추. 예시 하루 가로 스크롤(2번째 카드 잘림=스크롤 힌트). 「가입 없이 시작 · 서울 종로권 실제 장소 25곳」이 「이런 하루는 어때요?」 밑에 붙어 어색(그 문장은 CTA 밑에 있어야 자연스러움).
- 휴대폰 결과: 조건 칩 막대가 「조건 고치기」 단추에 가려 「안국역」 칩이 잘림(그라데이션 없음). 「여행 가져가기」 펠트 단추가 제목 아래에 따로 떨어져 있음. 빠른 바꾸기 칩 가로 스크롤인데 「비가 와요 · 실내 위주」가 오른쪽에 잘림(힌트로 볼 수도).
- 휴대폰 결과: 「하루 일정 / 지도 보기」 떠 있는 전환이 1번 장소 카드 「차와 카페」 칩과 겹쳐 있음(스크롤 위치 문제일 수 있으나 하단 패딩 확인 필요).
- 휴대폰 결과 빠른 바꾸기 칩: 원래는 2열 펠트 단추 4개 + 큰 노란 하나. 새 판은 한 줄 가로 스크롤 — 눌러 볼 선택지가 숨음.

### 2. new-pc-1start-00~02 (PC 첫 화면 위쪽)
- 00: 1440×900 첫 뷰에 보이는 것 = 사진+제목 / 오른쪽 조건 카드(날짜~선호 칩까지). **주 CTA 「내 조건으로 하루 만들기」는 01 조각 맨 위(≈ y 1130)** → 첫 뷰에 행동 단추가 하나도 없음. 원래 판은 y≈340에 「내 하루 만들어 보기」가 있었음. 조건 카드가 왼쪽 열(사진+예시+세 줄)보다 길어서 01 조각 왼쪽이 ~200px 비어 있음.
- 00: 「가입 없이 시작 · 서울 종로권 실제 장소 25곳」이 「이런 하루는 어때요?」 제목 오른쪽에 붙음 — 신뢰 문구인데 예시 제목 옆이라 맥락이 어긋남. CTA 아래 「실제 장소 25곳 · 지도 기반 예상 이동으로 비교해요」와 중복.
- 00: 「무엇을 받는지」 세 줄 아이콘 — 앞 둘은 펠트 원(돋보기·시계), 셋째 「고쳐 쓰는 하루」는 납작한 회색 원 + ↺ 글자. 셋 중 하나만 다른 재질.
- 00: 조건 카드 「걷기는 출발점·방문 장소·고른 마지막 도착점 사이의 예상 합계예요…」 설명 3줄이 「이동하며 걷기」 아래에 길게 — 조건 카드가 길어지는 원인 중 하나.
- 01: 「PLACES IN JONGNO」 영문 모노 눈썹 글. 고객 화면에 영문 눈썹은 원래 판 버릇 그대로(원래 「MAKE IT YOUR DAY」·「SEOUL FIELD NOTES 01」). 뼈대 바꾸면서 남은 흔적.
- 01: 정보 카드(사진 없는 곳) — 「확인한 메뉴」 라벨과 메뉴 두 줄 사이 ≈150px 빈 공간. 숙소 카드는 「공식 안내」 라벨 + 장소 이름만 들어 있고 바로 아래 제목에 같은 이름이 또 나옴(「나인트리 바이 파르나스 서울 인사동」 ×2, 「오라카이 인사동 스위츠」 ×2). 빈 칸 채우기로 보임.
- 01: 4열 그리드에서 정보 카드 4장이 한 줄에 몰림(개성만두 궁·발우공양·경인미술관 전통다원·오설록) → 첫 줄이 통째로 사진 없는 색 상자. 정렬 순서 문제.
- 02: 「예전에 소개된 메뉴」(프린츠 원서) 라벨 — 정직한 표기, 좋음. 사진 카드에 출처 글 없음(상세로 이동) — 깔끔.

### 4. new-pc-2result-00~01 (PC 결과 위쪽)
- 00: 조건 칩 막대(이번 여행의 조건 + 칩 7개 + 「조건 고치기」) — 읽기 쉬움, 좋음.
- 00: 왼쪽 열 폭 ≈ 560/1360 ≈ 41%, 지도 ≈ 59%. 시간표 글이 좁아 빠른 바꾸기 5개가 4+1로 꺾이고 「여행 중 · 남은 일정 맞추기」만 외톨이. Wanderlog 기준(일정 55%)과 반대.
- 00: 「실내 선호를 확인된 장소 특성과 비교했어요. 차와 카페 선호를 확인된 장소 특성과 비교했어요.」 같은 틀 문장 반복(원래 판 그대로) — 한 문장으로 합칠 것.
- 00: 안내 상자 = LED 점 + 「확인이 남은 여행 초안」 + 설명 — 기준대로. 좋음.
- 00: 시간표 썸네일 자리에 사진 없는 곳은 「차와 카페」 점선 상자. 3곳 모두 「차와 카페」라 똑같은 상자 셋이 세로로 — 자리 채우기로 보임. 첫 화면 정보 카드는 「확인한 메뉴」를 보여 주는데 시간표는 분류만 보여 줌(정보량 후퇴).
- 00: 장소마다 단추 = 「이곳은 유지」「다른 곳으로 바꾸기」(흰 알약) + 「자세히」(글자) + 「운영 안내와 비용 근거」(글자 링크). 펠트 단추와 흰 알약 두 체계가 한 화면에 섞임. 「자세히」와 「운영 안내와 비용 근거」가 둘 다 상세를 여는 거면 중복.
- 00: 토스트 「예시 조건을 채웠어요. 날짜·인원·예산을 확인해 주세요.」가 화면 왼쪽 아래 고정 → PC에서는 내용이 있는 왼쪽 열(장소 단추) 위를 덮음. 그리고 **결과 화면이 이미 떠 있는데 「조건을 확인해 주세요」라고 말함** — 예시를 고르면 바로 결과를 만드는 흐름인지 코드 확인 필요(메시지와 흐름이 어긋남).
- 00: 지도 — 범례(1·2·3 이름) 지도 안 왼쪽 아래, 「이동 경로」 라벨, +/− 단추, 갈색 점선=미확인 구간 설명이 지도 아래에 늘 보임. 출처 「지도 © OpenStreetMap contributors · ODbL」 + 「지도 자료 받기」. 좋음.
- 01: 「다른 방향의 하루도 있어요」 2장 + 「하나만 더 알려주세요」 비교 카드. 비교 카드의 작은 썸네일(점선 상자 안 장소 이름 3줄)이 매우 작음 — 한글 13px 기준 확인 필요.

### 6. st-pc-b-scrolled / st-pc-c-conditions / st-pc-sheet / st-m-sheet
- b-scrolled: 스크롤 중 조건 막대 + 지도 고정, 왼쪽 시간표가 흐름. 지도 높이 = 뷰포트 안. 좋음. 조건 막대 위에 헤더가 안 보임 → 헤더는 스크롤 아웃, 조건 막대만 sticky. 적절.
- c-conditions: 「조건 고치기」 → 3단 폼 펼침, 선호 칩 선택 상태(노랑) 보임, 「내 조건으로 하루 만들기」 + 「닫기」. 좋음. 다만 3단째 「조건 더 맞추기」가 접혀 있어 펼치면 어떻게 되는지 미확인.
- pc-sheet(왼쪽, 장소 상세): 맨 위에 「예전에 소개된 메뉴」 정보 카드가 ≈130px 높이로 거의 빈 채 놓임(사진 자리 대체). 상세 대화상자 안에서는 빈 공간이 더 두드러짐. 표 형식(어디에·운영 안내·비용·나에게 맞는 점·기본 안내 확인) 좋음. 단추 셋: 「공식 안내·예약 확인 ↗」「지도에서 보기 ↗」(펠트) + 「이곳을 넣어 여행 만들기」(검정). **일정에 이미 들어 있는 1번 장소(프린츠 원서)의 상세인데 CTA가 「이곳을 넣어 여행 만들기」** → 맥락 어긋남(원래 판도 같은지 코드 확인).
- pc-sheet(오른쪽, 바꾸기): 「SAME DAY. A NEW POSSIBILITY.」 영문 모노 눈썹 글. 후보 2곳 + 「이곳으로 비교」. 후보 썸네일도 「차와 카페」 글자 상자.
- m-sheet 1(결과 맨 위): 조건 칩 「안국역」이 「조건 고치기」 단추 밑으로 잘려 들어감(마스크/그라데이션 없음). 「여행 가져가기」 펠트 단추가 제목 아래 외따로. 썸네일 상자가 모바일에서는 오른쪽. 떠 있는 「하루 일정/지도 보기」가 1번 카드 단추를 덮음.
- **m-sheet 2(「지도 보기」라고 한 장면): 전환 단추는 「지도 보기」가 켜진 상태인데 화면 내용은 「다른 방향의 하루도 있어요」「하나만 더 알려주세요」 — 지도가 아님.** 모바일 지도 전환이 실제로 지도를 보여 주지 않거나, 스크롤 이동 방식인데 캡처가 중간인 것. 코드 확인 필수(P1 후보).
- m-sheet 3(조건 펼침): 폼이 세로로 길게, 「닫기」. 만들기 단추는 화면 밖(스크롤 필요) — 모바일에서 조건 고친 뒤 적용 단추를 찾기 어려울 수 있음.
- m-sheet 4(장소 상세): 맨 위 정보 카드 ≈200px이 거의 비어 있음(모바일에서 첫 화면의 1/4). 단추 셋이 2줄로 꺾임.
- m-sheet 5(바꾸기): 후보 이름이 2줄로 꺾이고 「이곳으로 비교」 단추가 오른쪽에 붙음. 영문 눈썹 글.

### 7. nsheet-m-start-0~2 / nsheet-m-result-0~2 (휴대폰 전체)
- 시작: 사진 제목 → 「내 하루 만들기 ⌄」 → 예시 가로 스크롤 → 세 줄 → 조건 카드(폼 전체) → 2열 장소 그리드 → 사진 출처 → 마무리 → 계정 → 바닥. 흐름은 자연스러움.
- 시작 전체 캡처에서 사진 카드 여럿이 빈 회색(서울역사박물관·경희궁·조계사·대한민국역사박물관) → 지연 로딩이 전체 캡처에서 안 돈 것. 대한민국역사박물관만 모든 캡처에서 빔.
- 결과: 조건 막대 → 제목 → 「여행 가져가기」 → 요약 3칸 → 문장 → 안내 상자 → 빠른 바꾸기(가로 스크롤) → 시간표(썸네일 오른쪽) → 다른 방향 → 하나만 더 → 추천에 반영한 조건 → 장소 그리드 → … 바닥. **전체 캡처 어디에도 지도가 없음** → 모바일은 지도가 기본 숨김이고 전환으로만 보임. 그 전환이 실제로 지도를 띄우는지 코드 확인.
- 결과 panel 1 바닥에 토스트 「예시 조건을 채웠어요…」 — 모바일에서도 결과 위에 뜸.
- 모바일 요약 3칸에서 「시설 안 걷기는 별도」가 2줄로 꺾여 칸 높이 들쭉날쭉.

## 코드 확인

# 정리

## 1. 판정: **다듬고 넓힘**
- 뼈대(사진+예시 | 조건 카드 → 조건 막대 / 시간표 | 고정 지도, 모바일 목록+지도 전환)는 의도대로 서 있고 원래 판의 「폼이 옆에 잘려 붙는」 겹 문제가 실제로 사라졌다. 색만 바꾼 판이 아니다.
- 다만 결과 화면의 「조건 고치기」 폼이 다단 넘침으로 모바일에서는 만들기 단추가 아예 화면 밖에 있어(PC도 묶음을 펼치면 같음) 지금 상태로 넓히면 사용자가 막힌다. CSS 몇 줄 문제라 구조를 다시 짤 일은 아니다.
- 그 밖에는 채움의 문제(PC 첫 뷰에 행동 단추 없음, 시간표의 「차와 카페」 상자 3연속, 빠른 바꾸기 외톨이 줄, 상세의 빈 정보 카드)라 다듬으면 된다.
