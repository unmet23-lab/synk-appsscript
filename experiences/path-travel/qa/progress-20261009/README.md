# 여행 중 남은 일정 조정 · 2026-10-09

로컬 v4 후속 구현과 검증이다. 원격 배포·실제 여행자의 사용·만족도 효과를 뜻하지 않는다. 브라우저의 여행 날짜·진행 시각·방문·예산은 검사자가 입력한 가상 시나리오다.

## 구현

- `planner.mjs`의 `replanRemainingTravel`이 명시한 현재 시각·출발점·남은 예산·도보 상한으로 남은 1~5곳을 비교한다. 기본 하루 계획은 기존 2~5곳을 유지한다.
- 다녀온 장소와 건너뛴 장소는 제외하고 해당 장소의 유지 설정을 해제한다. 완료한 분야의 필수 포함은 충족된 것으로 보되 선호·회피는 보존한다. 건너뛰기는 필수 분야를 충족시키지 않는다.
- UI에서 비교 후 수락해야 새 계획과 진행 기록을 함께 반영한다. 취소·입력 오류·결과 없음은 적용된 계획과 진행 기록을 보존한다.
- ‘오늘은 여기서 마치기’, 진행 정정과 여행 재개를 지원한다. 종료 후에도 미방문 유지 장소를 정정할 수 있고 미적용 주폼 입력으로 재개가 막히지 않는다.
- 선택적 `memory.progress`를 브라우저 저장·JSON 검증·공유용 일정에 연결했다. 이전 v4 파일은 그대로 허용한다. 완료 자기보고는 별점·만족도·확인한 평소 취향을 만들지 않는다.
- 기존 Core Domain·Ask와 여행 계산, Trail·Temper 연결을 재사용한다. 새 Atlas 엔진이나 별도 실행 하네스를 만들지 않았다.

## 자동 검사

- 여행 관련 18개 검사 파일 **246/246 통과**: [실행 로그](tests.log). 추천·조건·길망·저장·계정·UI 상태 회귀를 포함한다.
- UI 컨트롤러 **16/16 통과**. 추가로 종료 후 주폼 수정, 종료 후 미방문 잠금의 건너뛰기, 진행 복원의 재추천 금지, 원래 필수 분야의 보존과 수정 경계를 확인했다.
- 홈페이지용 여행 빌드 **7/7**, 정확한 **72개 실행 파일**과 최종 원본 해시를 확인했다. [빌드 로그·파일 대장](../../../../SYNK-website/qa/travel-progress-20261009/README.md). 공통계정 서버 개인자료 관련 검사 **21/21**과 생성본 검사는 담당 에이전트 실행 결과다. 로컬 검사만으로 계정 운영 등록이나 배포를 완료했다고 보지 않는다.

## 실제 브라우저 조작

별도 포트 `127.0.0.1:4305`에서 IAB로 확인했다. 기존 사용자 `4304` 탭의 여행 상태는 수정하지 않았다.

1. 10월 9일 기본 하루 생성 → 서울공예박물관·발우공양·조계사.
2. 공예박물관 완료, 발우공양 건너뜀, 13:00 공예박물관 출발, 남은 예산 20,000원, 도보 30분, 최대 1곳 → 운현궁, 예상 도보 7~13분, 종료 13:58.
3. 비교 취소 → 원래 3곳과 진행 기록 없음 유지. 같은 입력을 다시 비교·수락 → 완료 1곳, 건너뜀 1곳, 남은 운현궁 1곳.
4. 보관 동의 후 새로고침 → 같은 완료/건너뜀·시각·출발점·남은 일정 복원. 진행 기록을 새 추천으로 자동 바꾸지 않음.
5. 운현궁 유지 후 15:00에 여행 마치기 → 종료 화면·계획 없음. 새로고침 후에도 종료 상태 유지.
6. 종료 상태에서 주폼 예산 9,999원으로 미적용 수정 → 재개 입구에서 저장된 20,000원으로 복원하고 진행 대화상자 열림. 미방문 잠금 운현궁도 표시됨.
7. 빈 남은 예산은 오류. 공예박물관 완료를 후보로 정정, 운현궁 건너뜀, 15:10·10,000원·도보 0분 → 결과 없음, 종료 상태 유지. 도보 30분으로 변경 → 정정한 공예박물관을 다시 후보로 추천, 종료 16:29. 수락 후 여행 재개.
8. 새 여행 만들기 → 진행 기록 삭제, 기본 하루의 2~5곳 선택 복원.
9. 기본 데스크톱·390px·320px 화면 확인. 320px에서 시간 입력 두 칸이 잘리는 문제를 한 열로 수정한 뒤 재확인. 페이지·대화상자 가로 넘침 없음. 최종 탭 콘솔 오류/경고 0건.

검사 초기에 IAB 연결이 클릭을 전달하지 않아 CUA 세션을 초기화했다. 복구 후 위 흐름을 실제 버튼·입력으로 수행했다. 검증용 보관 데이터는 UI 전체 초기화로 제거했고 테스트 탭과 4305 서버를 닫았다.

## 남은 범위

현재 출발지는 대표 역 또는 등록 장소를 직접 고른다. GPS·실제 방문 감지·실제 지출 수집·예약 가능 여부·실시간 영업/교통은 연결하지 않았다. 남은 예산을 이전 예상 비용에서 자동 차감하지 않는다. 다음 제품 검증은 실제 여행자의 사용성과 추천 만족도 확인이며, 운영 계정·원격 공개는 별도 작업이다.
