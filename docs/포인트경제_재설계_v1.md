# 포인트와 선택 보상 — 현행 범위와 보존할 계산 원칙

> 2026-10-17 본문 정리. 07~08월 Apps Script 포인트·리그·월드레이드의 단가표와 복원 지시는 종료된 시스템의 기록이다. 현행 상품 범위는 [BM 목록](BM_목록.md), 학원 혜택은 [오프라인 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md)을 따른다.

## 지금 적용할 범위

- **숙제 포인트와 옷 가게 동전·흥정은 2026-09-20 결정으로 보류**다. 이 문서의 옛 지급표를 현재 앱·숙제·출석에 연결하지 않는다.
- 즉시 자동 포인트 적립과 22종 상점을 전교 공통 기본혜택으로 약속하지 않는다. 게임·앱의 선택 보상 개발 자체를 취소한 것은 아니다.
- **승인된 장학·과잠 등 학생 복지는 유지한다.** 07-31에 정한 과잠의 12개월 수강생 무료 지급은 포인트 상점 구매와 구분한다. 실제 자격·누적 확인·재원·재고·담당을 학생 복지 원문과 맞추며, 옛 1,200P·1,700P 수치를 새로운 자격 조건으로 부활시키지 않는다.
- TOWN의 부분 무료·구독·선택 아이템 등은 BM 원문에서 관리한다. 실제 가격·제공 범위가 확정되지 않은 것을 이 문서의 과거 가격으로 채우지 않는다.
- 폐기된 7단계 캐릭터 진화·GAS 리그·레이드와 연결된 상수·시험·시트는 [10-02 옛 시스템 정리](_ops/옛시스템_정리목록_20261002.md)의 대상이다. 옛 기능의 스위치를 켜는 작업 목록으로 사용하지 않는다.

## 다시 설계할 때 가져갈 원칙

| 항목 | 유지할 판단 기준 |
|---|---|
| 지급 총량 | 단일 행동의 단가뿐 아니라 참여 빈도·전체 지급 경로를 합쳐 월간 분포를 계산한다. 실제 참여 자료와 가정을 구분한다 |
| 적립과 잔액 | 누적 학습 기록·수혜 자격과 사용 가능한 재화 잔액을 구분한다. 재화를 썼다고 학습 이력이나 이미 얻은 자격을 지우지 않는다 |
| 비용 | 제작·배송·교환·재고·지급 대상 수를 포함해 감당할 수 있는 비용을 계산한다. 과거 단가를 현재 견적으로 쓰지 않는다 |
| 기록 | 실제 확인된 활동과 지급·사용·취소를 연결한다. 중복 요청·재전송으로 반복 적립되지 않게 하고 정정 이력을 남긴다 |
| 학습 가치 | 빠른 클릭·출석 순서·접속량을 실력이나 성실성 순위로 바꾸지 않는다. 과제·보상 참여를 강요하거나 결석을 인격 판단으로 해석하지 않는다 |
| 전달 | 적립 계획·코드 구현·실제 지급·학생 수령을 각각 확인한다. 화면 숫자만으로 실물 지급 완료라 하지 않는다 |

새 재화·가격·구매·보상 조건은 해당 제품과 학생 복지 원문에서 결정한 뒤 적용한다. 현재 학생 수가 적다는 이유로 기존 약속·기록을 무비용으로 바꿀 수 있다고 보지 않는다.
