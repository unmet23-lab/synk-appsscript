## 증빙으로서 무엇을 말해 주나 (실측)

- **브랜드 각인** — 썸네일 2장 실측(#11·#5): 둘 다 화면 상단에 **Skyline Edu 로고**가 박혀 있다. #11 은 배경이 **한글 판서가 남은 교실 칠판**, #5 는 **학원 실내**다. 「어디서 찍었는지」가 이미지 자체에 들어 있다.
- **한국어 학원임이 화면에 있다** — #5 자막이 **몽골어와 한국어 두 줄**이다(`100% УНЭГҮЙ ШУУ!` / `100% 무료입니다`). 업종을 말로 주장할 필요가 없다.
- ⚠ **학생은 안 보였다**(연 2장 기준) — 둘 다 진행자 1인 촬영이다. 그래서 대외 메일에서도 «학생이 보인다»는 쓰지 않았다. 나머지 9장은 안 열어봤다.
- **시기 정합** — 캡션의 모집 일정(6월 1일·15일·29일)이 유호님 재직기간 **2026-02~07** 안에 정확히 든다.
- **업종 정합** — 전부 한국어 교육·TOPIK·한국 유학 모집물이다. 우리가 울란바토르에서 열려는 것과 **같은 업종·같은 도시**.
- ⚠ **못 말하는 것**: 이 자료는 «학원이 이런 광고를 냈다»를 보이지, «유호님이 부원장이었다»를 문서로 증명하지 않는다. 그 칸은 **관청이 무엇을 대체 증빙으로 받는지**에 달렸고, 그것을 ATS 에 물어둔 상태다(§8-5 편지 2(b)).
