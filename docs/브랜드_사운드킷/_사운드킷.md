## 두 가족 — 규칙 4는 UI 킷의 규칙이다 (2026-08-28 정리)

| 가족 | 소리 | 문법 |
|---|---|---|
| **UI 킷** (규칙 4 적용) | 획득 · 성취 · 알림 | 사인 · 400ms 이하 · C 펜타토닉 · 실패음 없음 |
| **가이드 목소리** | 몽글 12(08-25 「맑은판」) · **까몽 3 · 마린 3**(08-28 톤 확정) | **캐릭터의 «악기»가 문법을 이긴다** — 몽글 = 사인 옹알이(숨·떨림) · 까몽 = 생동감 아기 용(도톰 배음 4층 · 각 그로울 그르렁 · 247~554Hz) · 마린 = T 골렘(홀로우 1.5배음 8층 · 링모드 22Hz 금속통 · 평평 억양·메트로놈·낮은 마침표) |

목소리 가족은 규칙 4의 ①③④ 밖에 선다(마린 완수 700ms · 배음 합성/링모드) — ② 실패음 없음만 전 가족 공통이다. 까몽·마린 확정 경위 = 상황 6종은 첫 픽(08-28 「까몽 2·5·9, 마린 1·2·5」)이 정했고, 악기는 3~7차 귀검수 재작업으로 유호 확정 08-28 「이제 목소리는 좋아」: ①「몽글이 성대모사한 느낌」 → **「목소리를 가르는 것은 값이 아니라 악기다」** ②「모기·벌레 소리」 → 곤충 재료(고음 버즈·지터·디튠 맥놀이) 금지 ③「무전 소리 시끄럽다」 → **가이드 목소리에 밴드패스 노이즈 전량 금지**(유호님 귀에 전부 무전 잡음) ④몰래기쁨의 높은 순사인 꼬리 「들키는 느낌」 → 티는 로봇 문법 «안»에(마린 유일의 상행 종지). ⚠ 목소리 g 에는 판정장 RMS 균형 배율이 접혀 있다 — 재조정 금지(밸런스는 파일에 이미 있다).

## 렌더 사양

44.1kHz · mono · 16bit PCM WAV · 노멀라이즈 = **닻 고정**(k = −3dBFS ÷ 닻피크 상수 — 08-28 수리:
구판 「세트 최대 피크」 방식은 소리 하나가 커지는 순간 손 안 댄 파일까지 전부 다시 구워졌다) ·
상대 밸런스는 시청 그대로 · 감쇠 지수 램프→0.0008 · 꼬리 20ms.

## 앱 반입 (SYNK-talk · UI 단계)

- `expo-av`(또는 `expo-audio`)로 WAV 그대로 재생 — 변환 불필요, 3파일 합계 ~64KB.
- 재생 볼륨은 OS·사용자 설정에 맡긴다(코드에서 이벤트별 게인 재조정 금지 — 밸런스는 파일에 이미 있다).
- 새 이벤트 소리가 필요해지면: 토큰 「사운드」에 값 추가 → 재생성 → 유호님 시청 확정. 이 순서 밖으로 만들지 않는다.
