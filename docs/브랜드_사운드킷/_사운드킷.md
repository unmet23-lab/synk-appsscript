## 렌더 사양

44.1kHz · mono · 16bit PCM WAV · 세트 공통 노멀라이즈 피크 −3dBFS(세 소리의 상대 밸런스는
시청 후보 그대로 — 절대 레벨만 배포 관례로 올림) · 감쇠 지수 램프→0.0008 · 꼬리 20ms.

## 앱 반입 (SYNK-talk · UI 단계)

- `expo-av`(또는 `expo-audio`)로 WAV 그대로 재생 — 변환 불필요, 3파일 합계 ~64KB.
- 재생 볼륨은 OS·사용자 설정에 맡긴다(코드에서 이벤트별 게인 재조정 금지 — 밸런스는 파일에 이미 있다).
- 새 이벤트 소리가 필요해지면: 토큰 「사운드」에 값 추가 → 재생성 → 유호님 시청 확정. 이 순서 밖으로 만들지 않는다.

## 재생성

```
node tools/사운드킷빌드.js          # 토큰 「사운드.이벤트」 전량 → WAV (개수는 --check 가 센다)
node tools/사운드킷빌드.js --check  # 정합 검사 (CI)
```
