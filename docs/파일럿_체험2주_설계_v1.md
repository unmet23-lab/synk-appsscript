# LAB 개원 전 운영 시험과 공개 체험 설계

2026년 10월 2일 현행화. 과거12월 코호트·2월11일 체험/25일 개원·온라인1기·주말 동등녹화 상품의 고정 실행표를 제외했다. 실제 공간과 서비스가 준비된 뒤 직원 폐쇄 시험과 공개 체험을 구분해 진행한다. [현행 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md)을 따른다.

## 먼저 필요한 입력

적합한 매물/공사 권한·안전/법정 적용·실측 설계/견적·우선 레벨 교재·강사/직원 근무·현행 가격/계약·동의/기록·실제 사용할 기기가 필요하다. 날짜·참가 수·시간표·공개 무료 기간은 미확정이며 과거 날짜를 자동 재개하지 않는다.

## 직원 폐쇄 시험

한 주의 실제 수업·업무를 시험한다. 공간/장비 준비 계획의 마지막 직원 인수 기간은 공개 체험과 별도다.

| 시험 | 확인할 실제 결과 |
|---|---|
| 한국어 수업 | 90분 블록·개인 책상/그룹30분·시야/교사 접근·실출석 조편성/16명 접점·교재/과제 |
| 등하원 | 외투/가방·화장실·교대·조기 도착/마지막 인계·보호자·실제 최대 재실과 대체 담당 |
| 예약 자습 | 하루약2~3시간 예상의 실제 빈 시간을 확인. 예약/취소·입퇴실·촬영 중지·수업 복구 |
| 댄스 | 신청25명·32세트 수납/전환·패널 취급/잠금·감독·강사·귀가/이웃 소음·복구의 실시간 |
| 상담/체험 | iPad 이전 자료 초기화·상담/VR 시간 분리·감독/위생·포토 대표 월1회/오류 복구 |
| 기록/부모 | 실제 학생/보호자 권한·납부/환불·담당 보고/몽골어 감수·수신자/미수신·처리 시간 |
| 기기/촬영 | 자료 캡처+교사/마이크·영상/음성·동의/반사·권한·실제 녹화 종료·망/정전 대안 |
| 보호/마감 | 원장 외 접수/대체·제한 기록·최종 인계·시설/물/전원·백업/격리 복구 |

그림·데모·설계 문서의 존재를 위 시험 통과로 세지 않는다. 안전/동의·개인정보·실제 공급·감독/인계가 안 되면 원인과 보완을 기록하고 해당 서비스를 먼저 모집하지 않는다.

## 공개 체험

직원 시험을 통과한 공간/서비스·담당만 공개한다. 참가/보호자·회차/정원·동의/권한·무료/유료 범위·기간·실제 가격/환불을 확인한 뒤 안내한다. 삭제된 크루카드/옛 온라인 폼을 현재 접수창구로 쓰지 않는다.

문의→예약→참석→상담→유료 등록→재등록을 실제 제공 상품 기준으로 측정한다. 참석50%·전환25%·월 신규25명은 예전 가설이며 목표 달성이나 수요 실측이 아니다. 결과로 실제 공급/가격·반 수·근무/업무·혜택/원가를 조정한다. TOPIK 합격/진도 단축 효과를 짧은 체험 결과로 입증했다고 안내하지 않는다.
