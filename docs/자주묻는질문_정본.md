# 자주 묻는 질문 정본

2026년 10월 2일 현행화. 학생·보호자·직원에게 안내할 수 있는 현재 조건을 관리한다. [대외 FAQ](<정본/SYNK/SYNK FAQ.txt>), [오프라인 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md), [수강 약관](수강약관_초안_v1.md)을 함께 따른다. 취소된 온라인1기와 삭제된 Apps Script 상담/학원 기능의 과거 판번호·완료 표기를 현재 증거로 쓰지 않는다.

✅는 현재 방향과 조건을 설명할 수 있다는 뜻이며 실제 운영 완료가 아니다. ⛔는 공개 확정 전이라 담당자에게 연결하고, ⚠는 조건/한계를 함께 설명한다. 공개 봇·메뉴·몽골어 자료·홈페이지는 이 조건을 반영한 실제 기능/번역 검수 후 사용한다.

## 학부모와 등록 상담

### ⛔ Q1. 수강료가 얼마인가요?

공개 가격은 아직 확정 전이다. 실제 상품·제공량·기간권·혜택 원가·환불·법적 조건을 맞춰 함께 공개한다. 과거 내부 월42만₮ 등 계산값을 현재 수강료로 안내하지 않는다.

### ⛔ Q2. 학원이 어디에 있나요?

울란바토르에서 공간을 찾고 있다. 주소·전용면적·임대료는 미확정이다. 옛 임대 계약 완료 문구를 재사용하지 않는다.

### ⛔ Q3. 언제 문을 여나요?

공간·공사·운영 자격·교재·직원 시험·계약/서비스가 준비된 뒤 날짜와 모집 방식을 공개한다. 과거12월/2월 날짜는 현재 일정이 아니다.

### ⚠ Q4. 한 반에 몇 명인가요?

개인 책상16석을 설계 목표로 소그룹 수업을 준비한다. 실제 가구·동선·조별 활동·환기/피난 확인 후 모집 정원을 안내한다. 댄스는 신청25명 정원 요구이며 한국어 반 정원과 다르다.

### ⛔ Q5. 수업은 무슨 요일, 언제 하나요?

정규 한국어는90분·기본 평일주5회 모델이다. 교대·준비·직원 근무를 넣은 실제 시간표가 확정되면 안내한다. 토90분+녹화만으로 평일 동등 진도를 제공하는 주말 상품은 개원 모집대상에서 제외했다. 별도 상품은 공급 검증 후 검토한다.

### ✅ Q6. 한국어를 하나도 모르는데 괜찮은가요?

처음 시작하는 레벨을 준비한다. 한 레벨은8주 계획이며 기간을 채웠다고 자동 승급하지 않고 목표에 도달했는지 확인한다. 우선 열 레벨과 반 배정은 실제 모집 안내에서 확인한다.

### ⚠ Q7. 부모가 자녀의 학습을 알 수 있나요?

권한/학생/수신자를 확인한 담당자의 몽골어 보고를 준비한다. 주간 보고의 실제 작성·감수·전달/미수신 업무를 시험하고 등록 때 범위를 안내한다. 자동 부모앱3화면·모든 기록 즉시 조회·자동 발송 완료는 현재 제공 약속이 아니다.

### ⚠ Q8. 한국인 선생님이 있나요?

원어민 회화·글로벌 영어는 실제 강사·시간·제공량을 확보한 등록 구성에서 참여하도록 준비한다. 모든 정규 한국어 등록에 포함된다고 설명하지 않는다. 내부 상위 등록 이름 대신 실제 공개 상품과 포함량을 안내한다.

### ⚠ Q9. 얼마나 다니면 한국어를 할 수 있나요?

6레벨·레벨당8주를 기본으로 열두 달 콘텐츠를 계획한다. 승급은 도달 기준이고 개인마다 속도가 다르다. 재회전/휴학이 있을 때의 재원 기간·반·비용/수료는 현행 계약을 따른다. 특정 개월 안의 급수 달성을 약속하지 않는다.

### ✅ Q10. TOPIK 급수를 딸 수 있나요? / 한국 유학에 도움이 되나요?

정규 열두 달 과정의 목표는 TOPIK4급이다. 성실히 참여한 학생이 과정을 마치고 처음 보는 TOPIK에서4급에 도달하지 못하면 수강 종료 후 앱 계정·숙제를 포함한 온라인 학습을6개월 무료 연장한다. 한국에 간 뒤에도 같은 조건이다. 학생에 따라5급까지 학습할 수 있지만 모든 학생에게 같은 결과를 보장하지 않는다.

승인 조건은 열두 달 과정을 마친 뒤 첫 시험, 앱·숙제를 포함한 온라인 학습6개월이다. 등록 후1년 이내 시험·무기한/오프라인 연장·비자/다른 급수 보장으로 바꾸지 않는다. 실제 접수/판정·담당·권한·비용은 이 조건에 맞춰 준비한다.

### ⚠ Q11. 숙제는 어떻게 봐주나요?

학생이 쓴 한국어를 검토하고 다음 연습과 몽골어 설명을 제공하도록 준비한다. 실제 과제/피드백·담당·앱 기능이 연결된 범위만 안내한다. 자동 AI 처리·품질·시간이 이미 검증됐다고 말하지 않는다.

### ⛔ Q12. 무료 체험과 레벨 테스트는 어떻게 신청하나요?

직원 시험 뒤 실제 참가·공간·강사·동의·안전·가격/일정을 확정해 공개한다. 옛 파일럿 날짜·폐기된 폼/크루카드·취소한 온라인1기 모집을 신청 창구로 안내하지 않는다.

### ⛔ Q13. 형제 할인이 있나요?

현재 공개 조건 미정이다. 담당자에게 연결하며 할인액을 만들지 않는다.

### ⚠ Q14. 중간에 그만두면 환불되나요?

기존 내부 정책은 시작 전과 첫2주 전액, 이후 `등록금×50%×남은 기간/전체 기간`을 반환하는 안이다. 몽골 적용 기준과 실제 기간권/납부·할인·정산·지급 절차를 확인하기 전 이 비율을 적법한 확정 계약/자동 답변으로 게시하지 않는다. [약관](수강약관_초안_v1.md)의 공개 관문을 따른다. 취소된 한국 온라인1기 보증/환불 조건을 현재 상품에 섞지 않는다.

### ⛔ Q15. 결석하면 보강이 되나요?

보강·휴학/복귀·재회전은 실제 반/좌석/강사 공급과 계약에 맞춰 안내한다. 모든 결석의 무제한 무료1:1 보강을 약속하지 않는다. 승인된 연1회 최대2주 일시정지 방향과 일반 결석은 구분한다.

### ⛔ Q16. 몇 살부터 다닐 수 있나요?

현재 공개 연령 조건은 미정이다. 청소년·성인 상담을 준비하며 미성년 보호자 절차와 실제 시간/귀가 조건을 확인한 뒤 안내한다.

## 학생이 묻는 것

### ✅ S1. 재미있는 활동도 있나요?

한국어 수업 안에서 짝/조 대화와 작은 프로젝트를 한다. 무료 문화 댄스는 신청25명 정원의 가능한 고정 회차다. 매일 모든 수업 전후 무제한 자유 참여는 아니다.

### ⚠ S2. 앱이 있나요?

학생 학습 앱은 SYNK WORLD이고 SYNK 플랫폼은 별도 공통 입구다. 실제 기능·로그인·학원 기록 연결·출시는 담당 검증에서 확인한다. 학생전용 Glide·옛 Apps Script 앱이 이미 운영된다고 설명하지 않는다.

### ✅ S3. 처음인데 따라갈 수 있나요?

현재 개설 레벨에 맞춰 시작한다. 개인 책상을 쓰며 실제 출석 인원에 맞춰 짝/조를 나누고 담임의 주간 개인 접점을 준비한다.

### ✅ S4. 틀리면 창피할 것 같아요.

어떤 상황이 걱정인지 듣고 다시 연습할 방법과 실제 받을 도움을 설명한다. 타 학생과 순위 비교하거나 고정 구호를 강요하지 않는다.

### ✅ S5. K-pop 댄스도 하나요?

신청25명 무료 문화 회차로 준비한다. 실제 공간/강사·전환·감독·소음 조건이 맞는 회차만 제공하며 모든 한국어반 앞뒤의 상시 수업을 약속하지 않는다.

### ✅ S6. 시험이 많나요?

목표에 도달했는지 확인해 승급한다. TOPIK 성과 지원은 Q10의 조건으로 설명하고 실제 성과 사례가 있다고 만들지 않는다.

### ⚠ S7. 원어민 선생님과 말할 수 있나요?

원어민 회화가 포함된 등록의 실제 공급과 담당을 확인해 안내한다. 일반 등록 모두에 포함된다고 하지 않는다.

### ⛔ S8. 친구와 같은 반을 할 수 있나요?

레벨과 실제 좌석/시간표를 확인한 뒤 담당자가 안내한다. 원하는 반에 무조건 함께 배정한다고 약속하지 않는다.

### ⚠ S9. 얼마예요? 등록하고 싶어요.

공개 가격/납부는 Q1과 약관 기준을 따른다. 미성년자일 수 있으면 보호자 문의 절차를 안내하고 연락처·계좌/결제 정보를 먼저 캐묻지 않는다.

### ✅ S10. 무료 자습은 어떻게 하나요?

전용 자습실 대신 빈 강의실 좌석을 예약해 무료로 이용한다. 하루약2~3시간의 빈 시간을 예상하지만 실제 수업/직원 시간에 맞춰 가능한 시간만 공개한다. 담당자의 예약/입퇴실 확인을 받고 수업 준비 전에 종료한다. 상시 입실·매일 최소시간·모든 교실 개방은 아니다.
