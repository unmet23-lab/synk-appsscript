## 0. 한 줄

**학생이 매일 한 줄을 남길 수 있는 자리를 열고, 그 기록을 학생에게 돌려준다.**
섞여 들어오는 세 언어는 문제가 아니라 자료다.

## 1. 유호님이 정하신 열 (결정.md · 09-05)

| | 확정 |
|---|---|
| 빈도 | 강제 없이 **열어둔다.** 안 쓴 날은 결손이 아니다 |
| 물음 | 사소한 일상 — 「오늘 점심은 뭐 먹었어요?」 |
| 목적 | **학생 자신의 기록.** 성향은 덤 |
| 자리 | **내 방 책상 위 «일기장» 물건**(✅ 유호 확정 09-05 저녁 · 엔진 v3 D29 B · 09-05 낮 「아래 탭 하나」를 대체 · 조건 = 오늘 카드가 끝난 직후 일기장으로 가는 손잡이 하나 · 펼치면 날짜 목록 · 쓰는 자리 = 다시 보는 자리 · 살아 있는 자리로 읽으면 일기장은 «물건») |
| 답하는 법 | 말하기 + 글(선택) |
| 쓴 뒤 | 쌓이는 것 보여주기 + **AI 맞장구**(🔴 고치지 않는다 · 🚫 평가도 안 한다) |
| 맞장구 아래 | **낱말 카드 하나** (§7㉤) |
| 다시 보기 | 날짜 목록 + 시즌 끝 종이 |
| 소리 | **무기한 보관** · 언어 감지를 켜고 전사 · 한국어만 엔진에 |
| 언어 | **구간별로 적는다** (§3) |

🚫 배지 · 연속 일수 · 달력 없음.

## 2. 🔑 섞인 언어는 버릴 것이 거의 없다

> "오늘 학원 yavsan, 너무 sonirholtoi했다" (yavsan = 갔다 · sonirholtoi = 재미있는)

| 구간 | 어디에 쓰나 |
|---|---|
| 한국어 | 교정·어휘 엔진 (실력 자료) |
| 몽골어·영어 | **「여기서 막혔다」의 증거** — 모국어로 넘어간 자리가 곧 모르는 낱말이다 |
| 못 가른 구간 | 표시만 남긴다 |

🔴 **오답 노트는 「틀린 것」을 보고 이것은 「말하고 싶었는데 못 한 것」을 본다.**
축이 다르고, 학생이 자기 의지로 쓴 글에서만 나오므로 우리만 모을 수 있다.

🔑 담을 칸이 이미 있다 — `submissions.code_switch_spans` 는 만들어만 두고 생산자가 0곳이었다.

## 3. 언어 값록 — 못 가르는 것을 「모른다」로 적는다

| 값 | 무엇 | 어떻게 |
|---|---|---|
| `ko` | 한국어 | 한글 자모 |
| `mn-Cyrl` | 몽골어(키릴) | 키릴 글자 |
| `roman` | **로마자 — 아직 못 가름** | 몽골어 로마자와 영어가 같은 글자를 쓴다 |
| `num` | 숫자·기호 | 언어가 아니다 |
| `unknown` | 못 정함 | 소리만 낸 날 등 |

🔴 `roman` 을 `mn`·`en` 으로 **지어 내리지 않는다.** 몽골어 로마자 사전이 서는 날 내린다.

### 글과 소리가 할 수 있는 것이 다르다

| | 구간을 가르나 | 왜 |
|---|---|---|
| 글 | ✅ | 글자가 그대로 남는다 |
| 소리 | ❌ | **한국어 전사가 몽골어까지 한글로 음차한다**("yavsan" → 「야브산」) |

⇒ 소리는 주 언어만 적고 **「구간은 못 갈랐다」를 행에 명시**한다.

## 4. 어디에 앉히나

**기존 `engine.submissions` 표에 앉되 사건 이름이 다르다.**

```
learning_events   ├─ submission.created   ← 과제
                  ├─ diary.opened         ← 물음을 띄웠다
                  ├─ diary.written        ← 일기를 남겼다
                  └─ diary.acknowledged   ← 맞장구 (서버 사건)
```

| 기존 칸 | 일기가 넣는 것 |
|---|---|
| `task_type` | `일기` |
| `task_ref` | `diary:{prompt_id}` |
| `task_snapshot` | 물음 스냅샷 + `diary_date` |
| `body_original` · `audio_ref` · `audio_duration_sec` · `capture_meta` | 기존 규율 그대로 |
| `code_switch_spans` | **구간별 언어** (생산자 신설) |
| `input_lang` | 주 언어 (열 신설) |

🔑 `learner_id` 를 이 표에 안 넣는다 — L0 가 「같은 행에 학생을 두 번 적으면 사건과 표가
다른 학생을 가리킬 수 있다」는 이유로 뺀 자리다.

⚠ **이 자리는 판마다 뒤집혔다** — 새 표(v3·v4) → 기존 표(v5~) 로 갔는데, v7 심문에서 GPT 가
다시 새 표를 권했다. **지을 때 다시 판정할 자리**다(§10-1).

## 5. 날짜와 물음의 정본

**정본 = `diary.opened` 의 payload.** 물음을 띄운 그 순간이 「무엇을 언제 물었나」가
확정되는 유일한 자리다. `diary.written` 이 `diary_id` 를 되싣고 스냅샷을 복사해 굳힌다.

⚠ 오프라인에서 `diary.opened` 가 유실되면 앱이 만든 것을 그대로 쓰고 `opened_missing: true`
를 적는다. 🔴 그래서 `diary_id` 는 **외래키가 아니다**(FK 를 걸면 그날 일기가 통째로 실패한다).

## 6. 계약 개정 — 아홉 자리

| # | 무엇 |
|---|---|
| 1 | `event_type` +3 · 2 | `task_type` +1 · 3 | payload 화이트리스트 + `source_kind` 매핑 |
| 4 | `앱사건`·`사건출처`·생산자·엔진도달 장부 |
| 5 | `submissions` 열 +1(`input_lang`) · `code_switch_spans` 생산자 신설 |
| 6 | `pipeline_jobs` 열 +1(`job_kind`) + 유일 제약 교체 + **기존 행 이행** |
| 7 | DB CHECK 제약 판 접미 전량 교체 |
| 8 | 배포 사후검사 — **종류별로** 센다 |
| 9 | 🔴 **기존 교정 워커의 잡 선별 질의** — 열을 더하는 것과 그 열을 «읽게 하는 것»은 다른 일이다 |

## 7. 맞장구

### ㉠ 사건

`diary.acknowledged` · 부모 = 그 `diary.written` · 멱등키 `diary-ack:{written_event_id}`
(일기 하나당 답 하나를 물리로 막는다).

### ㉡ 통로

트리거가 `job_kind='diary_ack'` 잡을 만들고 **새 함수**가 집는다(기존 교정 워커가 아니다).
🔴 과제 교정이 먼저다 — 일기는 마감이 없고 과제는 있다.

### ㉢ 「고치지 않고 평가하지 않는다」를 구조로 막는다

낱말 목록으로는 안 된다(「문법이 완벽합니다」는 통과하고 「잘 들었어요」는 폐기된다).

1. 모델에게 **반응 갈래를 고르게** 한다(되묻기·공감·이어 말하기). 자유 서술이 아니면 평가가 덜 낀다
2. **한 문장** 상한 — 길어지면 설명이 되고 설명은 평가로 흐른다
3. 금지 **문형** — 「~가 맞아요」·「~네요(실력 평가)」·「~하세요(지시)」
4. 🔴 걸러진 답을 **조용히 넘기지 않는다** — `ack_kind='fallback'` 으로 적어 「자주 걸린다」가 보이게

### ㉣ 전사 실패

`ack_kind='received'` 로 받았다는 표시만. 그때 `model`·`prompt_ver` 가 **없는 것이 정직하다.**

### ㉤ 🆕 낱말 카드 — 「고치지 않는다」와 「한국어에 도움」이 부딪치던 자리

맞장구 본문 아래에 **카드 하나**를 띄운다.

```
학생: 오늘 학원 yavsan, 너무 sonirholtoi했다

맞장구:  학원 갔구나! 뭐가 제일 재미있었어?
─────────────────────────
   갔다  ·  yavsan
```

**규율 넷** (+ 09-06 한 줄)

| | |
|---|---|
| ⓪ | **음성으로만 낸 날도 카드를 낸다** — STT 전사에서 모국어로 넘어간 자리를 같은 규칙으로 고른다(09-06 · 철학 4회차 심문 A7: 음성만 낸 날 카드가 안 나오면 그날 한국어 도움 경로가 0 이고 예외 목록에도 없었다). 전사가 못 잡은 몽골어 조각은 «없음»이 아니라 «못 잼»으로 남긴다 |
| ① | 카드는 **하나**만. 여럿이면 첨삭이 된다 |
| ② | 「틀렸다」가 아니라 **대응만** 적는다. 판정하지 않는다 |
| ③ | 못 고르면 **카드 없음.** 빈 카드를 안 낸다 |
| ④ | 소리만 낸 날은 구간을 못 가르므로 카드가 안 나온다(§3) — 정직하게 그대로 둔다 |

🔑 **이것이 「고치는 것」이 아니라 「알려 주는 것」이라 유호님 확정을 안 깬다.** 그리고
판단 정본 게이트 ① 「실제로 사용할 수 있는 한국어에 도움이 되는가」를 이 자리가 진다.

🔑 **어휘 지도(이해 대장 ㉠)에 닿는 첫 자리이기도 하다** — 학생이 모국어로 넘어간 낱말이
곧 모르는 낱말이고, 그것이 가르쳐야 할 낱말이다.

⚠ 대응 낱말을 누가 만드나 — 사전이 있으면 사전, 없으면 AI 가 맞장구와 같은 호출에서 만든다.
AI 가 만든 것은 틀릴 수 있으므로 **단정하지 않는 문구**로 내고 강사가 나중에 볼 수 있게 남긴다.

## 8. 축

`diary.written` 만 센다. `diary.opened` 는 **분모가 아니다**(안 쓴 날이 점수를 깎지 않는다).
다만 사건은 남긴다 — 「열고 안 썼다」와 「아예 안 열었다」는 다르고, 물음 품질을 보는 자료다.

**세는 것 넷** — 남긴 수 · 길이(글자 수 / `audio_duration_sec`) · 시각대(몽골 달력 네 띠) ·
매체(글·소리·둘 다).

🔴 상태 계산에 넘기는 조회에 네 칸을 더해야 한다(지금은 `task_snapshot` 만 간다).

## 10. 🔨 지을 때 정할 것

**계약 파일을 실제로 고치면서 정해지는 것들**이라 문서로 더 못 내린다.

1. **어디에 앉히나를 다시 판정** — 기존 표(§4) vs 새 표. 판마다 뒤집혔다
2. 🔴 **㉡ 사람 이해를 무엇으로 채우나** — 후보마다 「정의 · 소비자 · 회수 시점」 셋
3. **계약 필드의 물리 위치** — 최상위인가 payload 안인가(`output_text` 자리)
4. **`pipeline_jobs` 기존 행 이행** — `legacy` 로 옮길 때 정상 교정 잡이 안 죽게
5. **유일 제약 교체와 트리거** — `ON CONFLICT` 대상이 사라지면 모든 제출이 롤백된다
6. **`code_switch_spans` 물리 규격** — 오프셋 단위(UTF-16 코드 유닛), 판, 대응 낱말 칸
7. **몽골어 로마자 사전** — `roman` 을 내려 가르는 열쇠
8. **맞장구 언어** — 몽골어는 감수자가 한 분뿐이다
9. **화면 규격** — 첫 화면 문안, 글/소리 고르기, 저장·실패 상태, 목록 상한, 종이 표현
10. **하루 여러 장의 중복과 의도** — 두 기기가 각자 초안을 만들면 둘 다 선다
11. **최신 수단 정찰** · **참여율·녹음 길이 실측**

## 11. 잰 것과 안 잰 것

| 잰 것 | 값 |
|---|---|
