## 0. 이 표가 왜 필요한가 — 팩에 초안을 못 적기 때문

발주 §3 이 **「확정 전 `mn` 병기 금지」**를 못박고 있습니다(빈 칸 `mn: ''` 도 금지 — 「모른다」와 「없다」가 섞입니다).
그래서 **AI 초안 칸이 없습니다.** 주간 리포트 검수표(21조각)에는 초안 칸이 있는데 여기엔 없는 것은 실수가 아니라
그 두 발주의 규칙이 다르기 때문입니다 — 저쪽은 초안을 명시적으로 허용했고, 이쪽은 명시적으로 금지합니다.

검수자는 **한국어 원문에서 바로** 몽골어를 씁니다.

## 1. 검수자가 할 일 — 셋

**① 번역 (40조각)** — §2 표의 「몽골어」 칸.

| 종류 | 개수 |
|---|---|
| 상황문 틀 | 5 |
| 지시문 틀 | 5 |
| 사유 변주 | 15 (문항당 3) |
| 세부 변주 | 15 (문항당 3) |
| **합계** | **40** |

🔴 **핵심 어휘(괄호 안 한국어 낱말)는 번역하지 마세요.** 지시문 끝의 `(핵심 어휘: 마감 · 연장 · 제출)` 은
**학생이 한국어로 써야 하는 목표 낱말**입니다. 몽골어로 바꾸면 문제가 사라집니다. 괄호 앞부분만 번역하고
낱말은 한국어 그대로 두세요.

**② 조립 확인 (5문장)** — §3. **이게 이 검수의 급소입니다.**
문항은 「틀 + 빈칸」이라 조각을 따로 번역해 기계가 합칩니다. 한국어에서는 `{사유}` 자리에
`-아서/-어서`·`-느라`·`-다가` 꼴이 들어가 자연스럽게 붙지만, **몽골어에서 그 조각이 그대로 붙는다는 보장이 없습니다.**
그래서 문항마다 **합친 문장 1개씩**을 실제로 읽고 어색하면 고쳐 주세요.

**③ 문화 적합성** — §2 각 문항의 「검수자께」 메모. 몽골 유학생이 **실제로 겪는 상황인가**를 봐 주세요.
안 겪는 상황이면 문장을 다듬는 게 아니라 **그 문항을 통째로 바꿔야 합니다** — 그렇게 적어 주시면 됩니다.

## 2. 문항 5벌

### g1t01 · 과제 기한 부탁

| 자리 | 한국어 원문 | **몽골어** ← 검수자가 씀 |
|---|---|---|
| 상황문 | `전공 수업 과제 마감이 어제까지였는데, {사유} 과제를 내지 못한 상황이에요.` | |
| 지시문 | `교수님께 메일을 써서 사정을 말씀드리고, {세부}만 더 달라고 부탁해 보세요. (핵심 어휘: 마감 · 연장 · 제출)` | |
| 사유 1 | `갑자기 몸이 아파서` | |
| 사유 2 | `가족 일로 고향에 다녀오느라` | |
| 사유 3 | `컴퓨터가 고장 나서` | |
| 세부 1 | `3일` | |
| 세부 2 | `5일` | |
| 세부 3 | `일주일` | |

> **검수자께**: 몽골 유학생이 한국 교수에게 **마감 연장을 부탁하는 일이 실제로 있는지**, 그리고 그 부탁이
> 무례하게 읽히지 않는 표현인지 봐 주세요. 몽골 대학에서 이 요청이 아예 성립하지 않는다면 알려 주세요.

| 사유 1 | `비자 서류 접수 예약이 있어서` | |
| 사유 2 | `병원 진료 예약이 있어서` | |

> ⚠ 이 문항은 상황문에 빈칸이 **두 개**입니다 — §3 조립 확인에서 특히 중요합니다.

### g1t03 · 파일 다시 제출

| 자리 | 한국어 원문 | **몽골어** ← 검수자가 씀 |
|---|---|---|
| 상황문 | `과제는 기한 안에 냈는데, {사유} {세부} 파일을 잘못 첨부한 상황이에요.` | |
| 지시문 | `교수님께 메일을 써서 상황을 말씀드리고, 파일을 다시 제출하게 해 달라고 부탁해 보세요. (핵심 어휘: 첨부 · 초안 · 재제출)` | |
| 사유 1 | `서두르다가` | |
| 사유 2 | `파일 이름이 비슷해서` | |
| 사유 3 | `휴대폰으로 내다가` | |
| 세부 1 | `완성본 대신 초안` | |
| 세부 2 | `다른 과목 과제` | |
| 세부 3 | `지난주 과제` | |

> **검수자께**: `초안`·`재제출` 이 몽골어 학사 용어로 자연스러운지 봐 주세요.
> ⚠ **사유 1·3(`서두르다가`·`휴대폰으로 내다가`)은 「~해서」가 아니라 「~하다가」 꼴입니다** — 이유가 아니라
> **하던 중에 벌어진 일**을 뜻합니다. 몽골어에서 이 둘은 다른 구문일 수 있으니 사유 2와 같은 틀로 옮기지 마세요.
> ⚠ 이 문항도 빈칸이 두 개이고, **둘이 나란히 붙어 있습니다**(`{사유} {세부} 파일을`).

## 3. 🔴 조립 확인 — 문항마다 1문장 (이게 이 검수의 급소)

번역한 조각을 기계가 이렇게 합칩니다. **합친 결과를 소리 내어 읽어 보고**, 어색하면 그 자리에서 고쳐 주세요.
고치신 문장이 §2 의 조각과 어긋나면 **§2 쪽을 고치는 게 맞습니다**(조각이 정본이고 이건 검산입니다).

| # | 합친 한국어 (사유 1 · 세부 1 기준) | **합친 몽골어가 자연스러운가** ← 검수자가 씀 |
|---|---|---|
| A | `전공 수업 과제 마감이 어제까지였는데, 갑자기 몸이 아파서 과제를 내지 못한 상황이에요.` | |
| B | `비자 서류 접수 예약이 있어서 다음 주 월요일 수업에 갈 수 없는 상황이에요.` | |
| C | `과제는 기한 안에 냈는데, 서두르다가 완성본 대신 초안 파일을 잘못 첨부한 상황이에요.` | |
| D | `자료를 찾아봐도 방향이 안 잡혀서 발표 주제를 정하기 어려운 상황이에요.` | |
| E | `교환학생을 신청하게 되어서 교수님 추천서가 필요한 상황이에요. 제출 기한은 다음 달 15일이에요.` | |

⚠ **한 문항이라도 「조각을 그대로 붙이면 몽골어가 깨진다」가 나오면, 그 문항은 번역만으로 안 끝납니다** —
틀의 구조를 바꿔야 하고 그건 팩 개정(`g1문항.v2`)입니다. **그 사실만 적어 주시면 나머지는 저희가 합니다.**

## 4. 확정 커밋 때 필요한 것 (개발 쪽 메모 — 검수자와 무관)

확정 커밋은 **세 가지가 한 벌**입니다(발주 §3): `mn` 병기 + `검수확정 = true` + 문항판 `g1문항.v1` → `g1문항.v2`.

⚠ **`mn` 키의 «모양»이 아직 어디에도 안 정해져 있습니다.** 조각이 4종(상황틀·지시문틀·사유 배열·세부 배열)이라
키도 4벌이 필요한데, 정하지 않은 채 검수본이 도착하면 **확정 커밋에서 즉석으로 짓게 됩니다.**
▶ **판정안**(확정 아님 · 착수 전 확인 필요): `상황틀_mn` · `지시문틀_mn` · `사유_mn`(3벌 배열 · 순서가 `사유`와 1:1) ·
`세부_mn`(3벌 배열 · 순서가 `세부`와 1:1). 배열 순서 결속은 **회귀로 못박아야 합니다** — 순서가 어긋나면
「사유 2에 사유 3의 번역」이 붙고, 그건 어느 화면에서도 안 보입니다.

**기록(P0 아님)**: 회귀 `tests/교수멘탈문항.test.js:126` 의 사유 꼴 검사는 `/(서|느라|다가)$/` 라 **세 꼴을 허용**하는데,
팩 주석과 발주 §2 는 「이유절(-아서/-어서 꼴)만 앉는다」라고 **더 좁게** 적고 있습니다. 데이터는 넓은 쪽(-느라 1 · -다가 2)을
쓰고 있으니 **깨진 것은 데이터가 아니라 산문**입니다. 검수자에게는 §2 g1t03 메모로 이미 실물을 알렸습니다.

## 5. 안 하는 것

- 🚫 **몽골어 AI 초안을 팩에 넣기** — 발주 §3 · 이 표에 초안 칸을 안 둔 이유.
- 🚫 **핵심 어휘 번역** — 학생이 한국어로 써야 하는 목표 낱말이다(§1 ①).
- 🚫 **`요구문형`(인사·사과·이유·요청·맺음) 번역** — 화면 비노출 내부 재료다(발주 §2).
  검수자가 「이 상황이 그 문형을 실제로 끌어내는가」를 판단할 참고로만 쓴다.
- 🚫 **급수별 분화·TOPIK 문항 번호 대응·NPC 대사** — 전부 다른 트랙 몫(발주 §5).
