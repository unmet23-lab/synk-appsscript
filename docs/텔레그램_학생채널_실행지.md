> **상태**: ✅ 유호 확정 09-02(마케팅 정찰 A8 「전부 지원」). **판정 자 = 첫 달 가입 수** — 몽골 텔레그램 도달은 공식 수치가 0 이라(정찰 §3) 한 달 실측 뒤 «이어갈지»를 다시 판정한다.

> 🔒 **첫 게시물을 «올리는» 손은 유호님**이다(09-06 확정 · 계정 설정은 내 몫이고 발행만 유호님). 문안·버튼·반복 메시지는 여기 준비해 둔다.

## 1. 유호님 폰 클릭 단위 (5분) — ⚠ 메뉴 이름은 2026-09 추정 · 다르면 그 자리에서 말씀

1. 텔레그램 → 오른쪽 아래 **연필** → **「새 채널」** → 이름 **`SYNK LAB`** → 설명 = 아래 §3 ①.
2. **공개 채널** → 링크 후보 **`t.me/synkmn`**(안 재봤다 · 막히면 `synklabmn` → `synk_lab`). ⚠ 인스타 규칙과 같다 — 진짜 판정은 그 화면에서 난다.
3. 프로필 사진 = **펠트 몽글 눈웃음** — `docs/SHIFT/프로필/synklab_프로필.png`(페북·인스타와 같은 얼굴 · 09-02 통일).
4. 채널 설정 → **「환영 메시지」**(2026-08 신기능 — 새 멤버에게 자동으로 한 번 간다) = §3 ②.
5. 채널 설정에 **「번역」** 스위치가 있으면 켠다(2025-05 채널 자동 번역) — 한국어 포스트를 몽골어로 읽게 된다. 없으면 몽골어로만 낸다.
6. 첫 게시물 = §3 ③ → **고정**.
7. 개설 링크를 제게 주시면 → 저는 인스타 소개·페북 페이지·홈페이지·라디오 설명에 그 링크를 건다(관리 위임 09-01).

## 3. 문안 — ⚠ 몽골어는 감수 전 · 명사구와 단문만 · `node tools/몽골어대조.js` 로 잰다


(한국어 짝: 안녕하세요! 저는 몽글이라고 해요. 여기에 매일 한국어 한 문장이 옵니다. 아래 버튼을 눌러 세 문항으로 시작해요.)

**③ 첫 고정 게시물 — 버튼 퀴즈 세 문항 (메시지 속 버튼 · 2026-08 신기능 · 퀴즈형)**

## 4. 자 — 한 달 뒤 무엇으로 판정하나

| 자 | 값 |
|---|---|
| 가입 수(30일) | 숫자 그대로 — 과녁 없음(첫 실측이라) |
| 버튼 퀴즈 응답률 | 가입자 중 누른 비율 |
| 「어떻게 알았어요?」에 텔레그램이 나오는 횟수 | 상담 통로 실측(최종표 3순위 눈금) |

가입이 0 에 가깝고 응답이 없으면 **접는다** — 앱이 서면 이 자리는 앱이 진다. 살아 있으면 앱 출시 알림 채널로 남긴다.
