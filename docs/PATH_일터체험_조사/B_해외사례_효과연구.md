# 조사 B — 해외 VR 직업 체험·직무 훈련 사례와 효과 연구

> [PATH 일터 체험 설계](../PATH_일터체험_설계.md)의 근거 조사 원본이다(2026-11-20, Claude의 하위 에이전트가 조사). 설계 문서에 옮긴 것 가운데 Claude가 원문으로 다시 확인한 것은 설계 문서 5절에 「직접」으로 표시했다.

- 읽은 날짜: 모든 항목 2026-11-20.
- 근거 등급
  - 「원문」: 논문 본문이나 기관·회사 페이지를 직접 열어 읽었다.
  - 「초록」: 초록만 읽었다. 초록에 없는 숫자는 적지 않았다.
  - 「기사」: 언론 기사나 저자가 쓴 요약 글을 읽었다.
  - 「검색 요약」: 페이지를 열지 못했다. 검색 결과 요약만 보았다.
  - 「찾지 못함」: 두 번 이상 검색했지만 해당 사례나 연구가 나오지 않았다.
- 회사가 낸 수치는 한계 칸에 「회사 발표」라고 적었다.
- 인용문은 옮기지 않고 뜻을 풀어 적었다.

## 0. 먼저 볼 결론

1. 외국인에게 일터를 VR로 미리 보여 주고 취업 성과까지 잰 통제 연구는 찾지 못했다. 가장 가까운 것은 일본의 외국인 介護 VR(CareVR)과 독일 PflegeDigital 2.0이다. 둘 다 이해도·지식까지만 쟀다.
2. VR 훈련은 평균적으로 비교 훈련보다 약 0.5 표준편차 낫다는 메타분석(Howard 외 2021)과, 일반 훈련과 차이가 없다는 메타분석(Kaplan 외 2021)이 함께 있다. 「VR이라서 더 잘 배운다」보다 「현장에 갈 수 없을 때 대신 쓸 수 있다」가 안전한 주장이다.
3. 현실적 직무 미리보기는 기대를 낮추고 회사가 정직하다는 느낌을 높인다. 이직 감소 효과는 작다. 지원 의욕도 함께 낮춘다. VR·360도 미리보기를 대조군과 비교한 연구는 찾지 못했다.
4. 멀미는 「조이스틱으로 미끄러지듯 이동」과 「카메라 흔들림」에서 커진다. 앉은 자세 자체보다 인위적 이동을 없애는 것이 핵심이다. 10분 무렵부터 증상이 오른다.
5. 작업 표본 기록의 직무 성과 예측 타당도는 최신 추정으로 .33이다(예전 .54). 집단 간 점수 차이도 작지 않다(흑백 d 0.67). 언어 능력이 점수에 섞이는 문제를 잰 연구는 찾지 못했다.

## 5. 설계에 옮길 근거

| 설계 결정 | 근거 |
|---|---|
| 앉아서 본다. 사용자를 미끄러지듯 이동시키지 않는다. 장소는 컷, 페이드, 텔레포트로 바꾼다. | Saredakis(컨트롤러 이동 32.55, 제자리 28.04), Caserman(앉아서 조이스틱 연속 이동이 가장 나쁨), Prithul(멀미를 비교한 9편 중 7편에서 텔레포트가 낮음), Meta 문서, Zielasko(앉은 쪽이 편안·안전). |
| 360도 영상은 고정 촬영이나 흔들림 없는 촬영만 쓴다. | Litleskare(흔들림만 줄여도 멀미 점수 33.66→18.70). |
| 한 장면 3~5분, 한 번 착용 10분 안쪽. 2D 화면 학습 사이에 짧게 끼운다. | Saredakis(10분 미만 23.47, 10분 이상 33.42), Dużmańska(10분 무렵 첫 상승), Switchboard(평균 6.8분, 편안함 5점 중 4), PflegeDigital(VR 너겟), 독일 직업 영상(3~5분). |
| 처음 쓰는 날은 더 짧게 하고 여러 날에 나눈다. | Dużmańska(반복 노출로 적응). |
| 프레임율을 일정하게 지킨다. | Meta 문서. Wang(120fps 문턱, 단 빠른 물체 과제·기기 한 종). |
| 모국어 음성과 글, 그림 기호를 함께 쓴다. 평가도 모국어로 한다. | PflegeDigital(다섯 언어 음성·글, 시험지 모국어), CareVR(모국어와 일본어 병행), 群馬(말보다 도형 기호), 대만·일본 안전 VR(세 언어판), Switchboard(통역 필수), Stargatt(비영어권 배경에서 VR 이득이 더 큼). |
