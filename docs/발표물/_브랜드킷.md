# 발표물 브랜드 키트 — 인쇄물 10종 공통 (v1.0 · 2026-08-04)

> 발표물 HTML은 **자립형 1파일** 규칙이라 CSS를 외부 파일로 뺄 수 없다.
> 그래서 이 문서가 정본이고, 각 HTML 상단 `:root` 블록이 그 사본이다.
> **여기를 고치면 발표물 전 파일의 `:root`를 같이 고친다.**

## 1. 색 — 어디서 가져오나

| 역할 | 이름 | HEX | 출처 |
|---|---|---|---|
| 주조 | 루미너스 블루 | `#3D5AFE` | 발표물 정본 ■9 |
| 신호 | 에너지 오렌지 | `#FF6D00` | 발표물 정본 ■9 |
| 보상 | 크라운 골드 | `#FFC400` | 발표물 정본 ■9 |
| 바탕 | 웜 화이트 | `#FDFCF8` | 발표물 정본 ■9 (순백 금지) |
| 잉크 | 딥 네이비 | `#1A237E` | 발표물 정본 ■9 (순검정 금지) |
| **반전면** | **미드나잇 블루** | **`#0B1A2E`** | **디자인 컨셉 정본 v1.2** |

🔴 **반전면 색이 두 정본에서 갈린다 — 디자인 컨셉 정본이 이긴다.**
발표물 정본 ■9는 미드나잇을 `#101528`로 적었는데, 디자인 컨셉 v1.2가 그 값을
**실측으로 탈락시켰다**(채도 43%라 축소하면 순검정과 구별되지 않는다 —
인스타 썸네일·저가 안드로이드 화면에서 색조가 살아남느냐가 판정 기준이었다).
디자인 컨셉 정본은 「표지·간지는 이 정본 우선」을 §4에 명시해 뒀고,
발표물 정본의 디자인 잠금값은 **덱 본문 기준**이라고 같은 자리에 선제 보완돼 있다.
표지·머리 띠·챕터 브레이크 = 반전면이므로 `#0B1A2E`를 쓴다.

- 한 지면에 주조+신호+보상 **3색 초과 금지**(바탕·잉크·반전면 제외).
- 신호색(오렌지)은 **아껴 쓴다.** 지면에서 오렌지가 차지하는 면적이 커지면
  신호가 아니라 배경이 된다 — 한 지면에 오렌지 강조는 최대 2곳.

## 2. 서체 — 건드리지 않는다

디자인 컨셉 정본 R3: **타이포는 절대 건드리지 않는다.** 위계는 폰트 수가 아니라
**밀도(크기·웨이트·여백)**로 만든다(R2).

| 용도 | 서체 | 폴백 |
|---|---|---|
| 한글 | SUIT Variable | 시스템 고딕 |
| 라틴·키릴(몽골어) | Inter Tight — 스택에서 SUIT보다 **앞** | system-ui |
| 워드마크·시스템 라벨·숫자 | DM Mono | ui-monospace |

- 웨이트: 본문 500 · 헤드/워드마크 800 (영문·몽골어 전용 헤드만 700).
- 🚫 **DM Mono에 한글·키릴 금지** — 글리프가 없어 넣는 순간 깨진다.
  로마자·숫자·기호 전용. (린트가 검사한다)
- 몽골어가 한국어와 대등하게 병기되는 자리는 몽골어 글자 크기에 **1.04배** 광학 보정.

## 3. 워드마크 락업 — 로고가 도착하면 여기만 바꾼다

현재 저장소에 **로고·심볼 파일이 0건**이라, 심볼 자리에 임시 도형(시냅스 노드 3점)을
넣어 두었다. 로고를 받으면 각 HTML의 `<!-- LOGO SLOT -->` 구간만 교체한다.

받아야 할 것 3종:
1. **가로형 워드마크** — 머리 띠용
2. **심볼 단독** — 정사각(도장·앱 아이콘 자리)
3. **반전용 흰색 버전** — 표지·머리 띠가 `#0B1A2E`라 어두운 로고는 안 보인다

형식: **SVG 우선**(인쇄 무한 확대·자립형 1파일 규칙에 그대로 맞음).
없으면 PNG 투명배경 가로 2000px 이상 → data URI로 심는다.

## 4. 모티프 — 시냅스 노드

브랜드 고유 자산이다. 앱의 몬스터 진화(뉴로 → 스파키 → 링커 → 서킷 → 미엘로 →
플로우 → 싱크마스터)가 이미 신경 계열이고, 이름 SYNK 자체가 **동기화**다.
그래서 여정선·관문·연결선을 **노드와 링크**로 그린다 — 장식이 아니라 이름의 그림이다.

🚫 **게르 천창(몽골 상징) 모티프는 쓰지 않는다.** 상업 사용 범위가 유호님 판단
대기 상태이고 원어민 검수가 선행 조건이다(디자인 컨셉 정본 미해결 3건 중 ①).
결정 나기 전까지 대외 인쇄물에 넣지 않는다.

## 5. 대상별 밀도 — 학부모물은 촘촘하게

디자인 컨셉 정본의 미해결 리스크: 몽골 학원 광고는 정보가 빽빽하고 화려해서,
흑백 여백 미학은 10~20대에겐 세련돼 보여도 **학부모에겐 「내용 없음」으로 읽힐 위험**이 있다.
처방은 규칙 3개는 유지하고 **밀도만 분리**하는 것이다.

- **학부모·상담 대면물(발표물 대부분)** = 밀도 높게. 여백으로 멋 부리지 않는다.
- SYNK FIELD 표현 모드(디더·리소 2도)는 이 인쇄물들에 **적용 제외**다
  (디자인 컨셉 정본 「적용 제외(불가침)」에 학부모 신뢰 문서 본문·몽골어 정보 화면이 명시).

## 6. 인쇄 규격 — 전 산출물 공통

- `@page { size: <용지>; margin: 0 }` — 여백 0으로 잠가 크롬이 머리글에 날짜·URL을 찍는 것을 차단.
- `print-color-adjust: exact` — 배경색을 인쇄에 살린다.
- 외부 링크·이미지·폰트 CDN **0건**(자립형 1파일).
- 흑백 복사 대비: 구분은 **색 + 패턴 이중 표기**. 색으로만 구분되는 정보를 만들지 않는다
  (몽골 현지에서 재복사될 것을 전제한다).
- 화면 편집용 표시(가이드선·설명)를 인쇄면에 남기지 않는다.
- 미확정은 지어내지 말고 「____」로 비우고, 산출물 끝에 「채워야 할 칸」으로 모은다.
