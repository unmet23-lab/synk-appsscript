# 발표물 브랜드 키트 — 인쇄물 10종 공통 (v1.0 · 2026-08-04)

> 발표물 HTML은 **자립형 1파일** 규칙이라 CSS를 외부 파일로 뺄 수 없다.
> 그래서 이 문서가 정본이고, 각 HTML 상단 `:root` 블록이 그 사본이다.
> **여기를 고치면 발표물 전 파일의 `:root`를 같이 고친다.**

## 1. 색 — 어디서 가져오나

| 역할 | 이름 | HEX | 출처 |
|---|---|---|---|
| 주조 | 루미너스 블루 | `#3D5AFE` | 발표물 정본 ■9 |
| 신호 | 에너지 오렌지 | `#FF6D00` | 발표물 정본 ■9 |
| 보상 | 크라운 골드 | `#FFC400` | 발표물 정본 ■9 |
| 바탕 | 웜 화이트 | `#FDFCF8` | 발표물 정본 ■9 (순백 금지) |
| 잉크 | 딥 네이비 | `#1A237E` | 발표물 정본 ■9 (순검정 금지) |
| **반전면** | **미드나잇 블루** | **`#0B1A2E`** | **디자인 컨셉 정본 v1.2** |

🔴 **반전면 색이 두 정본에서 갈린다 — 디자인 컨셉 정본이 이긴다.**
발표물 정본 ■9는 미드나잇을 `#101528`로 적었는데, 디자인 컨셉 v1.2가 그 값을
**실측으로 탈락시켰다**(채도 43%라 축소하면 순검정과 구별되지 않는다 —
인스타 썸네일·저가 안드로이드 화면에서 색조가 살아남느냐가 판정 기준이었다).
디자인 컨셉 정본은 「표지·간지는 이 정본 우선」을 §4에 명시해 뒀고,
발표물 정본의 디자인 잠금값은 **덱 본문 기준**이라고 같은 자리에 선제 보완돼 있다.
표지·머리 띠·챕터 브레이크 = 반전면이므로 `#0B1A2E`를 쓴다.

- 한 지면에 주조+신호+보상 **3색 초과 금지**(바탕·잉크·반전면 제외).
- 신호색(오렌지)은 **아껴 쓴다.** 지면에서 오렌지가 차지하는 면적이 커지면
  신호가 아니라 배경이 된다 — 한 지면에 오렌지 강조는 최대 2곳.

## 2. 서체 — 건드리지 않는다

디자인 컨셉 정본 R3: **타이포는 절대 건드리지 않는다.** 위계는 폰트 수가 아니라
**밀도(크기·웨이트·여백)**로 만든다(R2).

| 용도 | 서체 | 폴백 |
|---|---|---|
| 한글 | SUIT Variable | 시스템 고딕 |
| 라틴·키릴(몽골어) | Inter Tight — 스택에서 SUIT보다 **앞** | system-ui |
| 워드마크·시스템 라벨·숫자 | DM Mono | ui-monospace |

- 웨이트: 본문 500 · 헤드/워드마크 800 (영문·몽골어 전용 헤드만 700).
- 🚫 **DM Mono에 한글·키릴 금지** — 글리프가 없어 넣는 순간 깨진다.
  로마자·숫자·기호 전용. (린트가 검사한다)
- 몽골어가 한국어와 대등하게 병기되는 자리는 몽골어 글자 크기에 **1.04배** 광학 보정.

## 3. 로고 — 2026-08-04 유호님 확정

**메인 = `W5`(축약) + `W1`(풀).** 나머지는 자리에 맞춰 꺼내 쓰는 보조 라이브러리다.
전체 후보와 근거 = `docs/발표물/로고/후보시트.html` (브라우저로 열면 됨).

🔑 **로고는 그림이 아니라 글자다.** `syn<` = s·y·n·`<`, 심볼 = `~ ^ ^ <` 넉 자(= s·y·n·k).
전부 타이핑 가능한 글자라 **벡터 도형으로 다시 그렸다** — 외부 이미지 0건이라
자립형 1파일 규칙을 그대로 지키고, 인쇄에서 무한 확대해도 안 깨진다.

### 어느 자리에 무엇을 쓰나

| 자리 | 쓰는 것 | 왜 |
|---|---|---|
| 인쇄물 머리 띠 · 명함 · 앱 상단 · 도장 | **W5** (`syn<`) | 가장 깔끔하고 가로가 짧다. 기본값이다 |
| 표지 · 배너 · 챕터 간지 (가로 넉넉) | **W1** (`syn< //`) | 슬래시까지 들어가야 브랜드가 완성된다 |
| 위 둘을 **밝은 바탕**에 | W5-L · W3 | 슬래시 색만 바뀐다(아래 규칙 ②) |
| 정사각 자리 · 워터마크 · 앱 아이콘 | S1(어두움) · S4(밝음) | 심볼 단색 |
| 복사·팩스·1도 인쇄 | W6 | 색 없이 형태만으로 성립 |
| 가로로 긴 사인 · 이메일 서명 | L1 | 심볼 + 구분선 + 워드마크 |
| 인쇄물 머리 띠 풀 락업 | L3 | W5 + 「SYNK LAB」 + 슬로건 |

### 색 규칙 — 두 줄

① **`<`는 언제나 에너지 오렌지 `#FF6D00`.** 밝은 바탕·어두운 바탕 양쪽에서 다
   살아남는 유일한 강조색이라 배경을 안 탄다.
② **`//`는 바탕을 따라간다** — 어두우면 크라운 골드 `#FFC400`, 밝으면 루미너스 블루 `#3D5AFE`.
   한 색으로 통일하면 둘 중 한 배경에서 반드시 사라진다.

대비 실측(WCAG 상대휘도 · 후보시트가 페이지에서 직접 계산한다):

| | 미드나잇 `#0B1A2E` | 웜 화이트 `#FDFCF8` |
|---|---|---|
| 골드 `#FFC400` | **10.94:1** ✅ | 1.56:1 ✗ 사라짐 |
| 블루 `#3D5AFE` | 3.41:1 ✗ 묻힘 | **5.00:1** ✅ |
| 오렌지 `#FF6D00` | 6.19:1 ✅ | 2.75:1 ✅ |

`syn` 글자색: 어두운 바탕 = 웜 화이트 `#FDFCF8` / 밝은 바탕 = 딥 네이비 `#1A237E`(순검정 금지).

### 도형 정본 — 복붙하지 말고 이걸 붙인다

각 HTML의 `<!-- LOGO SLOT -->` 자리에 아래를 넣는다. 좌표는 **한 곳에서만** 고친다 —
처음에 카드마다 path를 복붙했다가 심볼 간격을 넓히자 락업 두 개가 조용히 깨졌다.

```html
<!-- W5 축약 워드마크 · 어두운 바탕 -->
<svg viewBox="-8 -2 181 116" role="img" aria-label="SYNK">
  <text x="0" y="86" font-family="Inter Tight, system-ui, sans-serif"
        font-size="72" font-weight="600" letter-spacing="-1" fill="#FDFCF8">syn</text>
  <path d="M138 44 L112 66 L138 88 L150 88 L124 66 L150 44 Z" fill="#FF6D00"/>
</svg>

<!-- W1 풀 워드마크 = W5 + 슬래시(어두운 바탕은 골드, 밝은 바탕은 #3D5AFE) -->
<!-- viewBox 를 "-8 -2 296 116" 으로 넓히고 아래 두 줄을 더한다 -->
<path d="M196 92 L216 40 L228 40 L208 92 Z" fill="#FFC400"/>
<path d="M234 92 L254 40 L266 40 L246 92 Z" fill="#FFC400"/>

<!-- S1 심볼 ~^^< (= s·y·n·k) · 어두운 바탕. 밝은 바탕은 stroke 를 #1A237E 로 -->
<svg viewBox="0 0 240 110" role="img" aria-label="SYNK">
  <g fill="none" stroke="#FDFCF8" stroke-width="11" stroke-linecap="butt" stroke-linejoin="miter">
    <path d="M10 62 C17 50, 29 50, 36 60 C41 67, 48 67, 52 58"/>
    <path d="M68 68 L88 34 L108 68"/>
    <path d="M124 68 L144 34 L164 68"/>
    <path d="M228 22 L186 52 L228 82"/>
  </g>
</svg>
```

⚠ **viewBox 여백을 깎지 말 것.** 획 두께(11)의 절반과 글자 사이드베어링이 여기 들어간다.
줄이면 `<`의 아래팔과 `s`의 왼쪽이 잘린다(실측으로 두 번 겪었다).

### 남은 것

- ⏳ **원본 벡터 파일(.ai/.svg)이 있으면 그게 가장 정확하다.** 지금 `syn`은 서체로 조판한
  것이라 Inter Tight가 없는 기기에서는 자형이 미세하게 달라진다.
  `<`·`//`·심볼은 순수 도형이라 이 문제가 없다.
- 🔴 **서체 정본과 충돌 1건** — 브랜드 폰트 정본은 「워드마크 = DM Mono」로 잠겨 있는데
  실제 로고는 모노스페이스가 아니라 그로테스크다. **실물 로고가 규칙보다 뒤에 나왔으니
  로고가 이긴다.** 폰트 정본의 그 줄은 「워드마크는 로고 정본을 쓴다」로 고쳐야 한다.

## 4. 모티프 — 시냅스 노드

브랜드 고유 자산이다. 앱의 몬스터 진화(뉴로 → 스파키 → 링커 → 서킷 → 미엘로 →
플로우 → 싱크마스터)가 이미 신경 계열이고, 이름 SYNK 자체가 **동기화**다.
그래서 여정선·관문·연결선을 **노드와 링크**로 그린다 — 장식이 아니라 이름의 그림이다.

🚫 **게르 천창(몽골 상징) 모티프는 쓰지 않는다.** 상업 사용 범위가 유호님 판단
대기 상태이고 원어민 검수가 선행 조건이다(디자인 컨셉 정본 미해결 3건 중 ①).
결정 나기 전까지 대외 인쇄물에 넣지 않는다.

## 5. 대상별 밀도 — 학부모물은 촘촘하게

디자인 컨셉 정본의 미해결 리스크: 몽골 학원 광고는 정보가 빽빽하고 화려해서,
흑백 여백 미학은 10~20대에겐 세련돼 보여도 **학부모에겐 「내용 없음」으로 읽힐 위험**이 있다.
처방은 규칙 3개는 유지하고 **밀도만 분리**하는 것이다.

- **학부모·상담 대면물(발표물 대부분)** = 밀도 높게. 여백으로 멋 부리지 않는다.
- SYNK FIELD 표현 모드(디더·리소 2도)는 이 인쇄물들에 **적용 제외**다
  (디자인 컨셉 정본 「적용 제외(불가침)」에 학부모 신뢰 문서 본문·몽골어 정보 화면이 명시).

## 6. 인쇄 규격 — 전 산출물 공통

- `@page { size: <용지>; margin: 0 }` — 여백 0으로 잠가 크롬이 머리글에 날짜·URL을 찍는 것을 차단.
- `print-color-adjust: exact` — 배경색을 인쇄에 살린다.
- 외부 링크·이미지·폰트 CDN **0건**(자립형 1파일).
- 흑백 복사 대비: 구분은 **색 + 패턴 이중 표기**. 색으로만 구분되는 정보를 만들지 않는다
  (몽골 현지에서 재복사될 것을 전제한다).
- 화면 편집용 표시(가이드선·설명)를 인쇄면에 남기지 않는다.
- 미확정은 지어내지 말고 「____」로 비우고, 산출물 끝에 「채워야 할 칸」으로 모은다.
