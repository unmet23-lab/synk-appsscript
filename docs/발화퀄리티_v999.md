## 1. 진단 — 병목은 시간이 아니라 피드백 커버리지

정원 16명, 소그룹 20분, 4인 1조 × 4조 병렬.

| 항목 | 값 | 함의 |
|---|---|---|
| 학생 1인당 이론 최대 발화 | **5분** | 20분 ÷ 4인 (동시 병렬이라 시간은 나눠지지 않는다) |
| 강사가 한 조에 붙을 수 있는 시간 | **5분** | 20분 ÷ 4조 — 강사는 1명이다 |
| 교정 없이 흘러가는 발화 | **약 3/4** | 나머지 15분간 그 조의 문장은 아무도 듣지 않는다 |

여기에 4인 조는 균등 분배가 되지 않아 말수 적은 학생의 실제 발화는 2분 밑으로 떨어진다.
**틀린 문장을 20분간 아무 저항 없이 반복하면 그건 연습이 아니라 오류의 고착이다.**

그래서 v9.99가 손댄 것은 "20분을 늘리는 것"이 아니라 **그 20분의 밀도와 커버리지**다.

## 2. 바뀐 것 다섯

### ① 20분 타임박스 — 과업만 주고 시간 배분을 안 주면 20분은 "말 많은 학생의 20분"이 된다

```
1분 계획(말 없이 메모만) → 1R 4분 → 2R 3분 → 3R 2분 (라운드마다 짝 교대) → 조별 정리 → 발표
```

- **계획 1분**: 하위권의 침묵은 할 말이 없어서가 아니라 **조립할 시간이 없어서** 생긴다. 20분에서 1분을 떼면 남은 19분의 밀도가 오른다.
- **4/3/2**: 같은 과제를 짝을 바꿔 세 번. 반복할수록 인지 여유가 정확도로 넘어간다.
- ⚠ **Lv1~3 유창성 차시 기준.** 상급은 내용 깊이가 목표라 3회 반복이 폭을 줄인다 — 강사가 끄는 것은 재량(매뉴얼 §6-2 "블록 내 활동 선택은 강사 재량").

상수 = `TALK_PLAN_MIN` · `TALK_ROUNDS`. 테스트가 **합 ≤ 20분**과 **라운드가 점점 짧아지는 것**을 기계 검사한다.

### ② 역할 발화 의무 — 저발화 역할에도 발화를 심는다

역할 로테이션 주기가 4차시라, 학생은 **4차시 중 2차시를 저발화 역할(기록·질문)로 보낸다.**

| 역할 | 가중 | 새로 붙은 의무 | 왜 |
|---|:--:|---|---|
| 🎯 진행 | 2 | **한국어 유지 감시** | 소그룹 20분의 최대 실패 모드는 침묵이 아니라 **모국어 이탈**. 강사는 4조를 동시에 못 듣는다 |
| ✍️ 기록 | 1 | **마지막 30초 요약** | 받아쓰기만 하면 20분을 침묵으로 보낸다 |
| 📢 발표 | 2 | 조 결론 발표 | (기존) |
| ❓ 질문 | 1 | **고칠 문장 1개** | 강사가 못 듣는 3/4 구간에 심는 **학생 상호 교정** |

⚠ `ROLE_TALK` 가중치는 **바꾸지 않았다.** 의무 발화는 30초·1문장이고 진행·발표는 활동 내내 말한다 — 격차는 줄지만 남으며, 가중을 평탄화하면 편성의 '말수 섞기' 기준이 무의미해진다.

### ③ 3라운드 짝 — 같은 상수, 새 의미

`PAIR_PATTERNS`(v9.80)는 원래 "차시마다 짝 1조합"이었다. 이걸 **"한 차시에 3조합 전부"**로 다시 읽으면 4/3/2의 상대가 라운드마다 바뀐다. 새 데이터 0, 새 시트 0.

- 강사: 조 편성표에 `짝 1R 바트–사란/뭉흐–오윤  2R …  3R …`
- 학생: **profiles `오늘의만남`(DY129)** — "🤝 오늘 세 번 만나요 — 1R 바트 · 2R 사란 · 3R 뭉흐"

앱은 v9.80부터 매 차시 짝을 계산해 왔지만 **학생은 그걸 본 적이 없었다.** 훈련 장치(반복)가 그대로 서사가 되는 지점.
테스트가 **"3라운드 안에 나머지 셋을 정확히 한 번씩 만난다"**와 **짝의 대칭성**을 기계 검사한다.

### ④ 발화 지수 — v9.80이 약속만 하고 만들지 않았던 것

**08-01 발견:** `ROLE_TALK` 상수는 선언만 되고 코드 어디서도 참조되지 않았다. v9.80 헤더가 약속한 「발화량 추정」이 **주석으로만 존재**했고, 역할 로테이션이 만드는 발화량 편차를 아무도 측정하지 않고 있었다.

```
발화 지수 = 실제 출석한 차시의 역할 가중 합 − (미발화 기록 × 최고 가중)
```

역할은 좌석·차시의 결정론이라 개근하면 전원이 거의 같아진다. **벌어지는 원인은 셋뿐이고 셋 다 강사가 눈으로는 못 본다:**

1. **결석** — 그날 배정됐던 역할(진행·발표일 수도)을 통째로 못 받았다
2. **3인 조** — 역할이 3개만 돌아 '질문'이 없다
3. **미발화 기록**(차시 마감폼) — 자리는 받았는데 실제로 말하지 않았다

그래서 하위권 = **"구조적으로 말할 차례를 덜 받은 학생"**이고, 지명은 인상이 아니라 이 순서로 간다.
4주차 침묵 명단(시즌 1회·이진)의 **상시·연속값 짝** — 그쪽이 경보라면 이쪽은 계기판이다.

주간 교안 §12 지명 계획이 스스로 적어 뒀던 프록시("발화 실측 전 — 최근 2주 포인트 무활동 대체")를 **실측으로 승격**했다. 편성 전·1주차엔 기존 프록시로 조용히 폴백한다.

### ⑤ 정밀 청취 로테이션 — 순회 지도를 버린다 (도전안 채택)

**통념:** 소그룹 중 강사는 조를 돌며 골고루 봐준다.
**실상:** 4조 × 5분 = 모든 조에 얕게. 어느 학생의 오류도 정확히 못 잡는다. 그래서 `student_errors`가 빈 채로 남고, **그 시트가 비면 반 브리핑 '연습 포인트'·AI 개인화·3주차 오류 톱10이 전부 빈 껍데기로 돈다** — 체인 전체가 강사의 실측 입력 한 칸에 물려 있다.

**바뀐 것:** 한 차시에 **한 조(4명)만** 20분 내내 붙어 실제 문장을 받아적는다. 나머지 3조는 역할·타이머로 자율 운행.

- 순환 = `(차시 − 1) % 4 + 1` → **4차시면 전원 1회전**, 8주 시즌 2회전(주말반 1회전)
- **1~2주차는 지정하지 않는다** — 조가 아직 자율 운행을 못 하는 구간에서 3조 방치는 통제 리스크
- 노출: 조 편성표 `🎧`, HUD는 해당 조 행을 강조

## 4. ▶ 유호님이 하실 것

**배포는 이미 끝났습니다.** 아래는 라이브에서 눈으로 확인하는 절차입니다.

### (1) Apps Script에서 조 편성표 한 번 보기 — 2분

1. 스프레드시트 → 상단 메뉴 **확장 프로그램 → Apps Script**
2. 상단 함수 드롭다운에서 **`groupBoardNow`** 선택 → **▶ 실행**
3. 아래 **실행 로그**에 조 편성표가 뜹니다. 확인할 것:
   - `짝 1R … 2R … 3R …` 세 줄이 조마다 나오는가
   - `⏱ 소그룹 20분 — 1분 계획 → 1R 4분 → 2R 3분 → 3R 2분` 이 있는가
   - `🔈 오늘 지명 우선:` 이 있는가

> **개원 전이라 "편성 없음"이 정상입니다.** 시즌 시작일(`setSeasonStart`)과 조 편성(`assignGroupsAll`)이 없으면 조용히 비어 나옵니다 — 이건 결함이 아니라 설계입니다.

### (2) 학생 화면 카드 조립 (Glide) — 개원 전 아무 때나

profiles에 **`오늘의만남`** 열(DY, 129번째)이 새로 생깁니다. 첫 `calcAll` 실행 후 Glide에서:

1. Glide → 학생 앱 → **홈 화면** 편집
2. **+ Add component → Text** 추가
3. 데이터 소스에서 **오늘의만남** 선택
4. 우측 **Visibility** → `오늘의만남` **is not empty** 로 설정
   → 수업 없는 날·편성 전에는 카드가 통째로 숨습니다

### (3) 강사 교육에 넣을 것 — 개원 부트캠프 M5(모의수업)

프로토콜은 **앱이 매 차시 화면에 띄우므로 외울 필요는 없습니다.** 다만 부트캠프에서 한 번은 몸으로 돌려봐야 합니다:

- 20분 타임박스로 모의 소그룹 1회(타이머 실제로 켜고)
- 🎧 정밀 청취 = "한 조만 듣고 받아적기" 실습 → 약점 메모 폼에 넣기까지
- 역할 의무 4개 암기 — 특히 **질문 = 고칠 문장 1개**(학생 상호 교정의 전부)

## 5. 이번 작업에서 뺀 것 (정직 고지)

**녹음 → AI 첨삭**은 넣지 않았습니다.

강사가 못 듣는 3/4 구간을 **완전히** 닫으려면 결국 녹음입니다. 그런데 그건 이미 별도 트랙(**음성 AI 튜터** — `voice-ai-tutor-2026-07-29`, 유호님 프로토타입 승인 대기)이고, **음성 동의 보관기간**이 미정인 채로 녹음 레일을 열면 소급 불가 원칙(v9.84 교훈: "소급 불가 선언은 코드 게이트로 잠근다")을 어깁니다.

v9.99는 그 대신 **학생 상호 교정('질문' 역할)** 과 **정밀 청취 로테이션**으로 커버리지를 올렸습니다. 녹음은 유호님이 음성 AI 튜터 트랙을 열 때 이 위에 얹으면 됩니다 — 그때 **"소그룹 3라운드 중 마지막 2분만 녹음"**이 자연스러운 접점입니다.

## 6. 회귀 장치

`tests/발화퀄리티.test.js` 16검사. 그중 시스템 결함을 겨냥한 둘:

- **「선언만 하고 아무도 안 쓰는 상수가 없다」** — v9.80이 `ROLE_TALK`를 선언만 하고 참조 0으로 둔 사고의 회귀 장치. 주석을 걷어낸 코드에서 참조를 세므로 "주석으로만 존재하는 기능"이 다시 생기면 즉시 실패한다.
- **「20분 프로토콜이 조 편성표가 나가는 모든 경로에 실린다」** — 화면 하나만 고치고 나머지가 낡는 표류를 막는다(브리핑·HUD·교안 3면 동시 검사).
