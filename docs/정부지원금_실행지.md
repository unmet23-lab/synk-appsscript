# 정부 지원금 — 현재 신청 상태와 다음 행동

> 2026-09-11 정리. 현행 신청·문의는 아래 **§12-2-26의 19건**, 모두의 창업은 **§12-2-27의 일반/기술 재제출 완료 상태**를 읽는다. 19건은 관리 범위이며 모든 건의 현재 접수완료를 뜻하지 않는다. 크립톤 전북 IR·롯데 청년기업가대상·전주 경진대회 신규 접수와 하남 자격문의 발송을 반영했다. 창업진흥원 정책 아이디어 공모전은 1차 미선정으로 활성 목록에서 제외하고 제출·결과 이력은 보존했다.

- **신청·기관 회신·선정·약정·금액 수령**을 구분한다. 실제 상태와 마감은 해당 공식 포털·기관 회신으로 확인한다.

일반/기술 3R 후속사업화의 사업자등록 시점은 예비창업자는 협약기간 종료 2개월 전까지, 기창업자는 3R 선정 후 협약체결 이전 이종창업 등록이다. 로컬 2R의 등록 조건을 일반/기술에 옮기지 않는다. 2027년 다른 사업의 예비창업자 자격은 당시 등록 상태와 해당 연도 공고로 판단한다.

근거는 [중기부 제2026-511호 공식 공고](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1070586&cbIdx=310&parentSeq=1070586) 3-13·17-18쪽과 9/10 기존 공식 브라우저 작업 상태다. 세부 대조는 [공식자료 재검증 기록](../tmp/modoo_tech_20260910/official_audit.md)에 남겼다. 본문에 남은 9/3·9/7·9/9 로컬 평가·접수 내용은 과거 경위다.

### 12-3. 🔑 겹침 규칙 — 과거 해석 (현행은 §12-2-26·§12-2-27·개별 공고)

§12-3~5는 당시 비교·제외 이유다. 아래의 ‘전부 가능’·소득/등록 조건·금액·공고월을 현재 자격이나 2027년 확정 일정으로 적용하지 않는다. 새로운 신청에는 개별 현행 공고·약정과 최신 정정을 대조하며, §12-6의 미확인 질문은 확인 대상으로 남긴다.
- **모두의 창업이 막는 것은 「2026년 중기부 사업화 자금 직접지원」뿐이다.** 원문: 「본 공고와 '**동일연도**'에 지원하는 창업 사업화 지원사업이 **아닌** 경우 **또는 지자체 지원사업**은 협약 잔여기간과 관계없이 신청 가능」 ⇒ 12-2 의 교육·컨설팅·법률·IP·전북 사업은 **전부 신청 가능**. 🚫「모두의창업 넣었으니 다 막힌다」 재사용 금지.
- **철회한 과거 해석:** 사업자등록과 관계없이 소득만으로 국취 지속 여부를 판단한다는 설명은 재사용하지 않는다. 9월 법인 설립 계획의 실제 참여·수급 영향과 신고 의무는 담당 기관 확인 전 미확인이다.
- 🔴 **출국선**: 2027년 사업은 대부분 3~12월 협약이라 국내 상주·집행증빙을 요구하고, 정책자금은 몽골에 못 넣는다(§8-3). ⇒ **2027년 사업은 「㈜싱크시프트 법인이 신청 주체가 되는가」로 갈린다 — 유호님 판정 자리**([[korea-ai-education-corp-naming]] ⑧과 같은 칸).
