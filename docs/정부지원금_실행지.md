## 🔴 0-A. 긴급 재정렬 (유호 2026-08-12 「지금 돈이 없다 · 취업 예정이다」)

**전제가 바뀌었다.** ①유호님은 **한국에서 취업할 의사가 실재**한다(내 「취업 의사 없음」 추정은 **오판 · 철회**) ②**당장 생계 자금이 필요**하다.
→ 우선순위 축을 **「금액」이 아니라 「현금이 얼마나 빨리·반복해서 들어오는가」**로 바꾼다.

### 🔑 1번이 왜 가장 빠른가
**폐업이 긴급복지의 명시적 위기사유다** — *「주소득자 또는 부소득자의 휴업, 폐업 … 실질적인 영업이 곤란하게 된 경우」*. 그리고 이 제도는 **선지원 후심사**라 요건 심사를 기다리지 않는다. **☎129는 무료·24시간이고 전화로 바로 접수된다.**
- 요건: 중위소득 **75% 이하** (유호님 소득 0 → 충족)

### 🔑 2번 요건 (유호님 충족)
15~69세 · 가구 중위소득 **60% 이하**(1인 약 153만원) · 재산 4억 이하. **청년은 중위 120%·재산 5억으로 완화** — 유호님은 청년 해당이 보조금24 조회로 확인됐다. **소득 0이므로 여유롭게 충족.**
- 절차: 고용24 가입 → **구직등록 먼저** → 국민취업지원제도 참여 신청
- 폐업 소상공인 **연계수당(월 20만)**은 소상공인시장진흥공단 **추천서**가 추가로 필요하다(기본 구직촉진수당은 추천서 없이 진행 가능).

### ⚠ 확인할 것 하나
**긴급복지 생계지원과 구직촉진수당의 중복 수급 가능 여부**는 확실하지 않다. **129 상담에서 반드시 물어본다** — 시기를 나누면(긴급복지 먼저 → 국취) 되는 경우가 많다. 🚫추측으로 둘 다 신청해 두고 나중에 반환당하지 않는다.

## 1. ⭐ 보조금24 — 먼저 이것부터

2. 메인에서 **[보조금24]** → **[나의 혜택]**

## 3. 희망리턴패키지 (새출발 희망 프로젝트) — 금액이 가장 크다

**폐업한 소상공인의 재취업·재창업을 지원하는 제도.** 유호님이 정확히 대상이다.

| | |
|---|---|
| 창구 | **hope.sbiz.or.kr** (소상공인시장진흥공단) |
| 규모 | **2025-07-11 이후 폐업 = 최대 600만원** (그 이전 폐업은 400만원) → **유호님은 2026-08-12 폐업이라 600만원 구간** |
| 대상 | 사업 운영 **60일 이상**인 폐업자 또는 폐업 예정자 |
| 구성 | 사업정리 컨설팅 · 법률자문 · 채무조정 신청지원 · 점포철거비 · **전직장려수당 100만원**(심화교육 수료 60만 + 취업 후 근속 40만) |

**유호님 케이스에서 짚을 것**
- ⚠ **점포철거비는 해당 없을 가능성**이 높다 — 온라인 사업이라 철거할 점포가 없다
- ✅ **재창업 트랙이 맞다** — ㈜싱크시프트 한국 법인 설립과 몽골 학원 창업이 **실재**하므로 「재창업」 요건이 정당하게 성립한다
- ⚠ 지역별·연도별 공고가 따로 있다(예: 전북 새출발 재기지원). **주소지 관할 공고를 같이 본다**

**먼저 하실 것**: hope.sbiz.or.kr 접속 → 현재 열린 공고 확인. 상담 신청부터 하면 담당자가 해당 여부를 판정해 준다.

## 4. 🔴 국민취업지원제도 — 권하지 않는다 (정직하게)

금액만 보면 가장 크다:
- 구직촉진수당 **월 60만원 × 6개월 = 360만원** (2026년부터 50→60만 인상)
- \+ 폐업 소상공인 **국민취업 연계수당 월 20만원 × 6개월 = 120만원**
- **합계 최대 480만원**

**그런데 요건이 「취업 의사」다.** 신청하려면 소상공인시장진흥공단 이사장의 **추천서**를 받아야 하고, 그 전제가 *「취업 의사가 있음이 확인되는 자」*다.

🔴 **유호님은 2027년 2월 몽골로 나가 학원을 창업하신다. 한국에서 취업할 의사가 없다.** 없는데 신청해 수당을 받으면 **부정수급**이고, 반환 + 제재 대상이다. 금액이 커도 이건 아니다.

**다시 열리는 조건**: 출국 계획이 바뀌어 한국에서 실제로 취업을 알아보게 되는 경우. 그때는 정당한 대상이다.
