## 1. ⭐ 보조금24 — 먼저 이것부터

「어디에 뭐가 있는지 모르겠다」에 대한 **정답 그 자체**다. 중앙부처·지자체·공공기관의 **1만여 개 혜택 중 유호님이 받을 수 있는 것만** 골라 보여준다.

1. **www.gov.kr** 접속 → 간편인증(카카오·PASS)으로 로그인
2. 메인에서 **[보조금24]** → **[나의 혜택]**
3. 목록이 세 칸으로 갈린다:
   - **「확인하세요」** — 요건을 더 봐야 하는 것
   - **「신청하세요」** — 지금 바로 받을 수 있는 것 ← **여기가 핵심**
   - **「받고 있어요」** — 이미 받는 중
4. ⭐ **「국민비서(구삐)」 알림 설정** — 새로 받을 수 있는 혜택이 생기면 **문자로 자동 통보**된다. 유호님이 기억할 필요가 없어진다
5. 인터넷이 번거로우면 **신분증만 들고 읍·면·동 행정복지센터** 방문으로도 된다

**소요 10분. 로그인만 해주시면 제가 읽고 정리해 드립니다.**

## 2. 🔴 근로장려금 — 기한이 있다

### 상황
- **2025년 귀속분**의 정기 신청(2026년 5월)을 **놓쳤다**
- **기한 후 신청 창구가 2026-06-02 ~ 11-30 열려 있다**
- **11월 30일이 지나면 접수 자체가 불가능**하다 — 그냥 0원이 된다

### 조건
| | |
|---|---|
| 감액 | 정기 대비 **5~10%** (자료가 갈린다 — 신청 화면에 표시되는 값이 정본) |
| 지급 | 신청일로부터 **약 4개월 이내** |
| 요건 | **소득·재산 기준.** 🔑**폐업은 불리하게 작용하지 않는다** — 소득이 적을수록 받는 제도라 오히려 유리 |

### 신청
- **홈택스**: `장려금·연말정산·기부금 → 근로·자녀장려금 → 근로·자녀장려금 정기 신청 → 기한 후 신청`
- **손택스**(모바일 앱)로도 된다 — 오히려 이쪽이 안정적일 수 있다
- ⚠ 2026-08-12 실측: 홈택스 웹의 장려금 화면이 **빈 페이지로 뜨는 현상**이 있었다. 안 열리면 **손택스**나 **국세상담센터 126**으로.

### 같이 볼 것
- **자녀장려금** — 부양 자녀가 있으면 같은 신청서에서 함께 처리된다

## 3. 희망리턴패키지 (새출발 희망 프로젝트) — 금액이 가장 크다

**폐업한 소상공인의 재취업·재창업을 지원하는 제도.** 유호님이 정확히 대상이다.

| | |
|---|---|
| 창구 | **hope.sbiz.or.kr** (소상공인시장진흥공단) |
| 규모 | **2025-07-11 이후 폐업 = 최대 600만원** (그 이전 폐업은 400만원) → **유호님은 2026-08-12 폐업이라 600만원 구간** |
| 대상 | 사업 운영 **60일 이상**인 폐업자 또는 폐업 예정자 |
| 구성 | 사업정리 컨설팅 · 법률자문 · 채무조정 신청지원 · 점포철거비 · **전직장려수당 100만원**(심화교육 수료 60만 + 취업 후 근속 40만) |

**유호님 케이스에서 짚을 것**
- ⚠ **점포철거비는 해당 없을 가능성**이 높다 — 온라인 사업이라 철거할 점포가 없다
- ✅ **재창업 트랙이 맞다** — ㈜싱크시프트 한국 법인 설립과 몽골 학원 창업이 **실재**하므로 「재창업」 요건이 정당하게 성립한다
- ⚠ 지역별·연도별 공고가 따로 있다(예: 전북 새출발 재기지원). **주소지 관할 공고를 같이 본다**

**먼저 하실 것**: hope.sbiz.or.kr 접속 → 현재 열린 공고 확인. 상담 신청부터 하면 담당자가 해당 여부를 판정해 준다.

## 4. 🔴 국민취업지원제도 — 권하지 않는다 (정직하게)

금액만 보면 가장 크다:
- 구직촉진수당 **월 60만원 × 6개월 = 360만원** (2026년부터 50→60만 인상)
- \+ 폐업 소상공인 **국민취업 연계수당 월 20만원 × 6개월 = 120만원**
- **합계 최대 480만원**

**그런데 요건이 「취업 의사」다.** 신청하려면 소상공인시장진흥공단 이사장의 **추천서**를 받아야 하고, 그 전제가 *「취업 의사가 있음이 확인되는 자」*다.

🔴 **유호님은 2027년 2월 몽골로 나가 학원을 창업하신다. 한국에서 취업할 의사가 없다.** 없는데 신청해 수당을 받으면 **부정수급**이고, 반환 + 제재 대상이다. 금액이 커도 이건 아니다.

**다시 열리는 조건**: 출국 계획이 바뀌어 한국에서 실제로 취업을 알아보게 되는 경우. 그때는 정당한 대상이다.
