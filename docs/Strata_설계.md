# SYNK Strata — 배울 것의 지도

> 2026-09-19 · 여덟째 엔진. 새 엔진으로 세우는 것과 이름은 사용자 확정이다([결정](_ops/결정.md)). 이 문서는 Strata의 설계 정본이고, 고리 전체의 구조는 [아틀라스 설계](아틀라스_설계.md) §9-1, 작업 묶음은 [구현 명세](아틀라스_구현명세.md) WP11이다. 구현은 GPT가 맡는다. **구현 전**이며 재설계 내용은 사용자 검토 전이다.
> 표시: **[확인]** = 2026-09-19 코드·계약에서 직접 본 사실 · **[제안]** = 만들기 전에 실물과 대조해 고친다 · 「설계값」 = 출발값이며 자료가 생기면 고친다.

## 1. 무엇이고 무엇이 아닌가

아틀라스가 도달하는 높이는 「그 사람을 얼마나 아는가」와 「가르칠 것을 얼마나 잘게 고를 수 있는가」의 곱이다. 앞쪽은 이해 봉투가 맡고, **Strata는 뒤쪽**을 맡는다: 배울 수 있는 것을 마디로 나누고, 무엇이 무엇 위에 놓이는지, 어느 급수인지, 어떤 목표로 가는 길 위에 있는지, 교정의 어떤 오류가 어느 마디를 가리키는지를 한 자리에 둔다.

| Strata가 맡는 것 | 맡지 않는 것 |
|---|---|
| 배울 내용의 마디·관계·급수·난이도·짓는 재료 | 학생별 상태(이해 봉투의 일) |
| 과목마다 한 장의 지도(한국어 · 영어 · AI 활용 · 면접 준비) | 평가 기준과 채점(사람의 일) |
| 학생에게 그대로 보여 줄 수 있는 자료 | 집단 분포(Prism의 일 — Strata는 그 결과 중 **난이도 값만** 받는다) |

**층은 배울 내용의 층이다.** 학생을 층이나 등수로 가르는 데 이 엔진을 쓰지 않는다. 이름은 `Strata` 하나이며 「배울 것의 지도」는 역할 설명이다.

## 3. 자료 모양 [제안]

지도 한 장 = 파일 하나. 자리: appsscript `strata/maps/<과목>.json`(첫 장 `ko.json`). `atlas/`와 같은 순수 모듈 규율이며 소비 저장소에는 같은 방식으로 사본을 맞춘다.

```json
{
  "map_ver": "strata-ko-0.1.0", "subject": "ko", "built_at": "…", "sources": { "GRAMMAR_BANK": "<지문>", "skills": "<지문>", "tags": "<지문>" },
  "nodes": [
    { "id": "skill-ko-grammar-honorific", "kind": "skill", "label_ko": "높임 — -(으)시-·어휘 높임", "label_mn": null,
      "level": { "intro": 2, "basis": "grammar_bank" },
      "difficulty": { "authored": null, "measured": null, "n": 0 },
      "material": { "target_forms": ["-(으)시-"], "frames": [] } },
    { "id": "G211", "kind": "grammar_point", "label_ko": "…", "level": { "intro": 2, "basis": "grammar_bank" } },
    { "id": "sit-professor-email", "kind": "situation", "label_ko": "교수님께 메일 쓰기" }
  ],
  "edges": [
    { "from": "G211", "to": "skill-ko-grammar-honorific", "type": "part_of", "confidence": "authored" },
    { "from": "skill-ko-grammar-particle-topic", "to": "skill-ko-grammar-honorific", "type": "prerequisite", "confidence": "ai_draft", "reviewed": false }
  ],
  "links": {
    "tags":  [ { "tag": "높임:주체", "node": "skill-ko-grammar-honorific", "fit": "full" }, { "tag": "어미:연결어미", "node": null, "fit": "none" } ],
    "goals": [ { "goal": "study_abroad", "nodes": ["sit-professor-email", "skill-ko-grammar-honorific"] } ]
  }
}
```

- **id는 새로 짓지 않는다.** 기술은 `skill_id`, 문법은 `G###`을 그대로 쓴다. 상황만 `sit-…`로 새로 붙인다.
- 마디 종류: `skill` · `grammar_point` · `expression` · `situation`. 관계 종류: `part_of`(문법 코드 → 기술, DB `parent_id`와 같은 뜻) · `prerequisite`(먼저 알아야 함) · `contrasts_with`(헷갈리기 쉬운 짝).
- 급수가 없는 마디는 `level: null`이다. 없는 급수를 지어내지 않고, 「없음」을 「범위 밖」과 합치지 않는다 **[확인: `lib/문법급수.js`의 원칙]**.
- 모든 관계와 연결에는 **믿음 등급**이 있다: `authored`(기존 정본에서 옴) · `measured`(자료로 잼) · `ai_draft`(AI 초안) — 그리고 사람이 봤으면 `reviewed: true`.
- `engine.skills` 표는 이 지도에서 **씨를 뿌린다**(지도가 원천, 표가 파생). 지금처럼 문항 팩에서 뿌리는 것과 결과가 같아야 첫 판이 통과한다(§8).

## 4. 읽는 함수 [제안]

전부 순수 함수다. 학생 자료를 받는 것은 `다음후보` 하나뿐이고, 그것도 봉투의 **줄**만 받는다.

| 함수 | 돌려주는 것 | 지키는 것 |
|---|---|---|
| `마디(id)` | 마디 하나 | 없는 id는 `null` — 비슷한 것으로 메우지 않는다 |
| `선행(id, {최소믿음})` | 먼저 알아야 하는 마디들 | 믿음 등급으로 거를 수 있다 |
| `태그로(tag)` | 그 오류 유형이 가리키는 마디 또는 「대응없음」 | 23개가 빠짐없이 둘 중 하나로 나뉜다 |
| `급수로(level)` | 그 급에 도입되는 마디 · 급이 없는 마디 · 범위 밖 — **세 칸** | 세 칸을 합치지 않는다. 고르는 것은 소비자 몫이다 |
| `목표로(goal, level)` | 그 목표로 가는 길 위의 마디 | 목표를 평가하지 않는다 |
| `길(지금 마디들, 목표)` | 남은 마디를 선행 순서로 편 목록 | 순환이 있으면 오류 — 조용히 끊지 않는다 |
| `다음후보(줄들, 목표, {개수})` | 겨냥 후보와 각 후보의 `targets`(이해 줄 열쇠) | 같은 `map_ver`와 같은 줄이면 같은 결과 |

`다음후보`의 결과가 아틀라스 본체 `core.aim` 손잡이의 선택지가 된다(구현 명세 §4-1). 지도가 비어 있으면 빈 목록을 돌려주고, 고리는 지금의 회전으로 돈다.

## 5. 사람 손 없이 자란다

지도를 사람이 손으로 다 그리기를 기다리면 고리가 멈춘다. Strata는 **스스로 자라고, 사람은 있으면 더 확실하게 해 줄 뿐이다**([아틀라스 설계 §3](아틀라스_설계.md#3-자동-맞춤의-범위--옛-금지의-재검토)).

1. **기계 조립.** §2의 재료를 도구가 읽어 첫 판을 만든다. 같은 재료면 같은 지도가 나온다. 재료의 지문을 `sources`에 남긴다.
2. **AI 초안.** 비어 있는 곳 — 오류 유형 15개가 가리킬 마디, 선행 관계, 상황과 마디의 연결, 짓는 재료 — 을 AI가 **후보 판**으로 제안한다. 초안은 `ai_draft`로 표시되고 원본 지도를 덮지 않는다.
3. **자동 검증.** 후보 판은 아래를 통과해야 한다. 사람의 승인은 필수 단계가 아니다.
   - 선행 관계에 순환이 없다. 고아 마디가 없다.
   - 선행을 따라가면 급수가 내려가지 않는다(먼저 배우는 것이 더 높은 급이면 그 관계를 버린다).
   - 오류 유형 23개가 「이어짐/대응없음」으로 정확히 나뉜다. **억지로 잇지 않는다** — `fit: "full"`이 아니면 「대응없음」이다.
   - 기존 `authored` 관계를 뒤집지 않는다.
   - 시험장(구현 명세 §6-2)에서 후보 판으로 고리를 돌렸을 때 건강 지표가 나빠지지 않는다.
4. **부드러운 선행.** `ai_draft` 관계는 **막는 데 쓰지 않는다.** 겨냥 후보의 점수를 조금 낮추는 데만 쓴다. `authored`·`measured`이거나 사람이 본 관계만 「선행이 비었으니 아직 아니다」로 쓸 수 있다. 틀린 초안 하나가 학생의 길을 막지 못하게 하는 장치다.
5. **자료로 고친다.** 학생 자료가 쌓이면 Prism이 마디별 난이도와 「이 선행이 실제로 도움이 되는가」를 재서 `measured`로 올린다. 조건(독립 학생 수·표본)은 Prism의 규칙을 따른다. 그 전에는 `null`이다.
6. **넓혀 가기와 되돌리기.** 새 판은 아틀라스의 규칙 판과 같은 길로 간다(작은 몫 → 전체, 급락하면 자동으로 이전 판). 지도를 바꾸면 실행판이 오른다.

사람이 있을 때: 강사나 내용 담당자가 관계를 보고 `reviewed: true`를 찍으면 그 관계는 더 세게 쓰인다. 몽골어 이름(`label_mn`)의 원어민 검수도 같은 방식의 **더하기**다. 없어도 지도는 자란다.

## 6. 누가 읽나

| 읽는 쪽 | 쓰는 것 |
|---|---|
| Core | `다음후보`로 겨냥을 고르고, `길`로 본인 목표까지 남은 것을 안다 |
| Vellum | 이유 한 줄과 질문에 쓸 **사람의 말**(`label_ko`·`label_mn`). 마디 id는 화면에 나오지 않는다 |
| Loom | 「내 지도」 — 자기가 지나온 마디가 채워지는 화면. **자기 것만** 보이고 다른 학생·평균·등수는 없다 |
| Trail | 어디까지 왔는지를 마디로 말한다 |
| Prism | 마디별 분포를 재서 난이도를 돌려준다 |
| Temper | 결과를 마디 단위로 잇는다 |
| 생성(AI) | 마디의 `material`(겨냥할 형태·예문의 틀)을 입력으로 받는다 |

## 7. 과목마다 한 장

지도는 과목마다 따로이고 읽는 함수는 같다. LAB의 과정(한국어 · 영어와 회화 · AI 활용 · 비자 면접 준비)은 각각 한 장이 된다. 다른 사업은 Strata를 **단독**으로 쓸 수 있다 — 학생 자료 없이 지도만으로 과정 안내나 교재 구성을 만들 수 있다. 새 과목을 여는 일이 지도 한 장을 세우는 일이 되고, 고리의 나머지는 그대로 돈다.

바깥 기준(예: 국립국어원의 한국어 교육과정 자료)을 재료로 쓸 때는 출처·판·이용 조건을 확인하고 `sources`에 적는다. 이용 조건은 아직 확인하지 않았다.

## 8. 첫 판 만들기 — 인수 기준

| 단계 | 하는 일 | 끝났다는 증거 |
|---|---|---|
| ① 조립 | 도구(제안 `tools/strata-build.js`)가 §2의 1~6을 읽어 `strata/maps/ko.json`을 만든다 | 기술 30 · 문법 코드 91 · 오류 유형 23이 전부 들어 있고, 다시 돌려도 같은 파일이 나온다 |
| ② 대조 | 지도에서 뿌린 `engine.skills` 씨와 지금의 씨가 같다 | 기술 30개의 id·이름·영역이 글자까지 같다 |
| ③ 급수 | 마디의 급수가 `GRAMMAR_BANK`의 도입급과 같고, 축이 없는 마디는 `null`이다 | `lib/문법급수.js`의 기존 시험과 같은 답 |
| ④ 나눔 | 오류 유형 23개가 이어짐 8 · 대응없음 15로 나뉜다(지금과 같다) | `tests/태그기술표.test.js`와 같은 성질 |
| ⑤ 읽기 | §4의 함수와 시험 | 빈 지도에서 고리가 지금처럼 돈다 · 순환은 오류로 드러난다 · 같은 판과 같은 줄이면 같은 후보 |
| ⑥ 자라기 | §5의 2~4 — 후보 판과 자동 검증 | 일부러 넣은 순환·급수 역전·억지 연결을 검증이 잡는다 · `ai_draft` 선행이 후보를 막지 못한다 |

첫 판의 목표는 **새로 짓는 것이 아니라 한 자리에 모으는 것**이다. ④까지는 동작이 하나도 바뀌지 않아야 한다. 오류 유형 15개가 가리킬 마디를 만드는 일은 ⑥부터다.

## 9. 지키는 선

- 학생별 상태를 두지 않는다. 지도에는 개인정보가 없다.
- 평가 기준을 두지 않는다. 「이 마디를 익혔다」의 판정은 Strata의 일이 아니다.
- 뜻이 온전히 겹칠 때만 잇는다. 빈 연결은 비워 둔다.
- AI 초안은 막는 데 쓰지 않는다(§5-4).
- AI 초안을 부르는 일은 지킴이의 비용 한도 안에서만 돈다(구현 명세 §6-3). 한도를 넘으면 그날의 자라기만 쉰다.
- 학생에게 보이는 것은 자기 지도뿐이다.
- 계약 JSON·`GRAMMAR_BANK`·문항 팩은 각자의 정본으로 남는다. Strata는 그것을 **읽어 모으고**, 거꾸로 덮어쓰지 않는다. 정본을 Strata로 옮길지는 첫 판이 돈 뒤에 정한다.

## 10. 상태

설계만 있다. 코드·자료 파일·DB 변경은 없다. 엔진 소개서와 엔진 v3 표의 「엔진 7종」 표기는 그대로이며 고치는 시점은 사용자 판단이다. 홈페이지의 여덟 엔진 소개는 09-19에 다른 세션이 게시했다(트랙 기록 기준 · 공개 `7b94794` · Strata는 「추가 예정」으로 표시) — 소개가 게시됐다는 것이지 이 엔진이 구현됐다는 뜻이 아니다. 이름의 몽골어 원어민 검수는 하지 않았다(몽골어 대사전 mongoltoli 자동완성에서 `страта`는 미등재였다).
