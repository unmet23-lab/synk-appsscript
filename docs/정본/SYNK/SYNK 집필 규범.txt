# 이전 집필 규범의 사실 참조 자료

2026-09-17 사용자 요청으로 전사 문체·금칙어·서사·문장부호·형식·글쓰기 프롬프트 규칙을 삭제했다. 이 파일은 더 이상 글쓰기 기준이 아니다. 남은 내용은 이전 문서의 사실 참조 기록이며, 현재 회사·제품·수치·권리는 각각의 담당 정본에서 확인한다.

## §1. 브랜드 계층 (고정)

| 층 | 이름 | 무엇 |
|---|---|---|
| 상위 | **SYNK** | 한 사람을 깊이 이해하는 교육 시스템을 짓는 회사 |
| 브랜드 | **SYNK LAB** | 한국어 어학원 — 지금 여는 것 |
| 브랜드 | **SYNK STUDIO** | 콘텐츠·기록 — 지금 쌓는 것 |
| 레이어 | **SYNK IP** | 교재·커리큘럼·콘텐츠 자산 |
| 레이어 | **COMMON SYSTEM** | 앱·자동화 엔진·데이터 |
| 공간 | **메인 룸** | 댄스·촬영 스튜디오. 별도 서브브랜드 없이 SYNK로 통합 |

**조직 표기는 조직도가 아니라 로드맵이다** — 「지금 여는 것 / 지금 쌓는 것」 두 칸이 전부다. 투자자에게는 「브랜드가 몇 개 있다」보다 「무엇을 언제 여는지 안다」가 1인 창업자의 신호로 세다.

**노출 규칙**

- 고객·학부모 대면 문서에는 **SYNK LAB 하나만** 노출한다.
- 제품 라인(의류·굿즈·식품)은 2026-08-16 **철회**됐다. 투자자·파트너 자료에도 쓰지 않는다 — 「준비중」 라벨을 붙일 대상 자체가 없다. ⚠ 앱 포인트 상점의 의류·굿즈·간식 **품목**은 그대로 간다. 그건 동기부여 장치지 제품 라인이 아니다.

## §3. 4대 철학과 그 프로그램 (이름 고정)

| 철학 | 프로그램 | 산출물 |
|---|---|---|
| 목적이 먼저다 | **나침반** 세션 (입학·시즌마다 목적·로드맵 워크숍) | 드림맵 카드 |
| 몸이 깨어날 때, 뇌는 가장 깊이 배운다 | **K컬처 워밍업** (매일 · 100% 한국어 신체활동) | — |
| AI가 대체하기 어려운 사람 | **싱크 크루** 프로젝트 (시즌마다 팀이 기획→도전→다시→완성) | 시즌당 포트폴리오 1건 |
| 실질적 결과 | **싱크 포트폴리오** | 드림맵 + 프로젝트 결과물 + TOPIK 급수 누적 |


대외 문구는 반드시 이 셋이다. 구 표현(감응력·협응력·공감능력)은 철학 심층부 전용이고 대외물에는 쓰지 않는다 — 학부모·학생용만이 아니라 투자자·파트너 대면물까지.

1. **질문하는 힘** — 무엇이 진짜 문제인지 스스로 묻고 정의하는 힘
2. **스스로 하는 힘** — 시키지 않아도 먼저 움직이고 끝까지 해내는 힘
3. **마음을 끄는 힘** — 여럿의 생각을 하나로 모아 해내며 자신감과 사람을 함께 얻는 힘

- 항상 셋을 함께 쓴다. 하나만 떼어 쓰지 않는다.
- 각 힘 옆에 그 힘이 자라는 실물 하나를 반드시 붙인다(나침반 세션 / 싱크 크루 / 반 레이드·발표). 근거 없는 역량 선언 금지.
- **「이 힘을 길러 드립니다」가 아니라 「이 힘이 자랄 경험을 설계합니다」.**
- 급수·성적과 대립시키지 않는다. 「이 힘이 자라면 한국어 실력도 더 단단해진다」는 순서로만 쓴다.

## §4. 세계와 실물 — 지어내지 않는다

### 세계관 — 이름 없는 땅

이 땅의 것들은 **아직 이름이 없어 흐릿하고 조용하다.** 한국어로 부르면 또렷해지고 소리가 돌아온다. 세계의 동력이 「말」이라, 학원의 핵심 행동(말하기)이 곧 세계를 바꾸는 행위가 된다. 펠트가 이 세계의 물질이다.

이 설정이 제약을 흡수한다 — 가이드는 말하지 않고, 적이 없고, 학생끼리 비교하지 않는다. 이것들은 규칙이 아니라 세계의 성질이다.

**앱 첫 시작**은 이 세계관의 5.4초 튜토리얼이다: 어둠 → 흐린 형체 → 「이곳의 것들은 아직 이름이 없어요」 → 학생이 누름 → 코랄이 번지며 또렷해짐 → 「몽글」 이름이 뜸 → 기호 `<` → 로그인. 주변의 흐린 것 넷은 끝까지 또렷해지지 않는다 — 나머지는 학생의 말로 또렷해진다. 학생·강사·원장이 같은 화면을 지난다 — 역할은 서버가 가르므로 한 곳만 고치면 셋이 받는다. **이 5.4초에 학부모는 없다**(학부모 앱은 첫 시작을 안 지나고 별건으로 선다 · 유호 확정 2026-08-26). `[짓는 중]`

### 가이드 셋 — 학생이 고른다

학생이 자기 가이드를 **고른다.** 셋은 외모가 아니라 **학생을 대하는 방식**으로 갈린다.

| 가이드 | 대하는 방식 |
|---|---|
| **몽글** | 같이 한다 |
| **까몽** | 허세로 가르친다 (잘난 척 · 실은 겁쟁이) |
| **마린** | 임무를 준다 |

- 한 학생에게 가이드는 하나. 고른 결과 자체가 그 학생을 이해하는 재료가 된다.
- **셋 다 무언이다.** 말은 말풍선이 하고 소리는 효과음이 한다. TTS 0 · 낱말 소리 0. 「AI가 말을 걸어 준다」식 카피를 쓰지 않는다.
- 마린은 변신이 아니라 독립 캐릭터다. 이름과 표정을 가진 마스코트는 **셋이 상한**이고, 얼굴 없는 존재(보풀·핀·골무)와 NPC는 이 정원에 세지 않는다.
- 약점의 삼각형이 셋을 잇는다 — 몽글은 매운 걸 못 먹고, 까몽은 매운 라면을 좋아한다. 까몽은 젓가락질을 못 하고, 마린은 손이 정확하다. 마린은 농담을 못 알아듣고, 몽글이 설명해 준다.
- 학생이 **한국어 이름**을 짓고 가이드가 그 이름을 부른다(가이드를 고르는 첫 주). 몽골 이름에 호격 「야/아」가 안 붙는 문제의 해법이다.
- 정본 = `docs/캐릭터/가이드_정본.md`. 몽글 정본 이미지 = 펠트코랄_0815.

### 가이드가 자란다 — 세 축 `[짓는 중]`

**학생이 고른 가이드 하나가 그 학생의 상태를 비춘다.** 별개의 캐릭터를 따로 키우지 않는다.

- **가까이 온다**(크기) ← 학생이 **자기 손으로** 맞힌 말이 늘 때. 반 전체에 한꺼번에 준 것은 안 센다
- **또렷해진다**(맑기) ← 학생이 **처음 해 보는 일**을 할 때. 같은 일을 백 번 한 것은 이해가 아니다
- **밝아진다**(빛) ← 학생이 자기 목표를 말하고, 그 목표가 실린 과제를 **스스로** 냈을 때

🔑 **셋 다 안 떨어진다.** 못 온 날에도 못한 날에도 화면은 잘한 날과 같다 — 재촉하는 장치를 쓰지 않는다.
🔑 **단계·등급·숫자를 화면에 쓰지 않는다.** 「3단계」도 「67%」도 없다. 설명문 없이 눈으로 안다.
🔑 **계기판이 아니라 친구다**(유호 교정 2026-08-13). 상태를 비추는 세 축은 그 친구가 **나를 알아봐 주는 방식**이지 학생이 읽어야 할 계기판이 아니다.
⚠ **몸통 크기를 따로 쓰지 않는다** — 몸통은 폰을 나란히 놓는 순간 견줄 수 있어서, 「비교는 어제의 그 아이와만」이 화면이 아니라 몸에 새겨진다. 그래서 크기는 **거리와 한 값**이다.

⚠ **구 「7단계 진화」(뉴로 → … → 싱크마스터)는 2026-08-26 유호 확정으로 은퇴했다.** 라이브 계산은 아직 돌고 있고 소각이 진행 중이다 — 그때까지 **새 글에 쓰지 않는다.**
문서·학부모 접점 표기는 **가이드**다. 「몬스터」는 앱 내부 기능명·시트 열 키로만 산다(개명하면 라이브가 끊긴다).

### 부르는 이름

- 학생 = **크루**, 운영진 = **크루 / 리드크루**.
- 노력의 증표 = **오늘의 도전 · 오늘의 성장**(기준 충족 전원 · 학생당 하루 각 1회), 포인트, 반 레이드, 스트릭(연속출석), 칭호, 월간 리포트카드. 누적은 **도전 기록 · 성장 기록**으로 따로 센다.
- 위성 프로그램 = 정규 수업 옆에 **자유 참여로 여는 곁수업**(댄스·보컬·뷰티·원어민 회화·글로벌 영어). 출석 체크가 없다.

### 엔진 일곱과 SYNK Atlas

| 줄 | 엔진 | 한 줄 |
|---|---|---|
| 닿는 셋 | **Core** | 두뇌 — 이해하는 엔진 (비출시 내부 엔진) |
| | **Loom** | 몸과 감각 — 회사 전용 재질 펠트를 어느 지면에서든 같은 색·결·빛·소리·만짐으로 재현 |
| | **Vellum** | 닿는 면 — 관계 엔진. 그 위에 앉는 얼굴이 가이드다 |
| 쌓는 셋 | **Trail** | 발자취 — 목표와 실제 도착지를 한 사람으로 잇는 관측 |
| | **Prism** | 지도 — 화자 일반의 오류 분포. 비식별 집계층 |
| | **Temper** | 의술 — 가르치는 법을 배운다. 개입과 효과를 짝으로 |
| 자리를 만드는 하나 | **Reed** | 떨림판 — 24시간 라디오와 앱 자습 소리. 가르치지 않는다 |

- **여섯 엔진이 만드는 제품의 이름 = SYNK Atlas** — 학생 한 명분의 축적된 이해. Reed는 Atlas에 기여하지 않는다.
- Atlas 안의 층 이름 둘도 정본: **Amber**(Vellum 안 · 굳힌 순간) · **Patina**(Loom 안 · 익은 결).
- 「제2의 뇌」로 부르지 않는다. 그건 다른 회사가 정한 이름이고, 그 낱말을 쓰는 순간 우리는 그들과 같은 종목에 선다.
- 개수를 과녁으로 적지 않는다. 1년차 목표는 「엔진 여섯 완성」이 아니라 **㉡ 사람·㉢ 삶이 엔진에 닿는 것 + 학생 한 명분 세로줄 1회 관통**이다.
- 소개서 실물 = `docs/엔진/` (엔진 지도 + 소개서 6벌). 각 소개서가 「지금 어디까지 왔나」를 정직하게 싣는다.

### 실제 인프라

Google Form → 상담 시트 → 자체 개발 Apps Script 자동화 엔진 → profiles DB → **학생 앱 SYNK-talk(Expo + Supabase)**. 데이터 스택 = 핵심 원본은 Supabase + Postgres 하나 · Google Sheets 는 운영·리포트 파생층 · 자동화는 n8n / Apps Script.

**「출시」의 정의 = 스토어 정식 등재(App Store · Google Play)**, 시점은 2027-02로 **정식 개원 전**이다. 쓰는 사람은 학원 관계자만(student_code 발급) — 공개가입 없음, 다른 학원에 파는 학원관리 상품 없음. 출시 조건은 「기능 완성」이 아니라 **하루 루프가 안 끊기는 것**(숙제 → 제출 → 교정 → 답장)이다.

학부모 소통은 몽골 현지 특성상 페이스북 메신저 중심이다.

**자동으로 도는 것** `[이미 돈다]` — 상담 수집 · 백업 · 동기화 · 원장 브리핑 · 포인트 재계산 · 미납/재등록/헬스체크 · 칭호·성장 스냅샷. 이상 감지 시 동기화를 자동 보류하고 원장에게 알린다. 시각표·주기 상세는 05 운영 시스템이 정본이고 여기 사본을 두지 않는다.

### 24시간 라디오

유튜브 라이브 라디오의 학원화다. 채팅창이 곧 수집면이고(`!출석`·`!목표`·`!질문`), 음악과 오버레이는 그 수집기를 매일 돌게 하는 통로다. 확정된 연출 다섯 — 미니퀴즈는 화면이 아니라 **채팅**으로 / DJ는 말하지 않고 효과음만 / DJ 교대를 보이게 / 「지금 몇 명이 같이 공부 중」을 숫자가 아니라 **작은 불빛 몇 개**로 / 「이 노래는 SYNK가 만들었습니다」를 구석에 티 안 나게.

🔴 **송출은 아직 켜져 있지 않다.** `[개원과 함께]` 「이미 방송 중」으로 읽힐 문장을 대외물에 쓰지 않는다.

## §5. 커리큘럼 고정값

- **6레벨 = 시냅스 코어 6권**(자체 제작) + 회화 시냅스 톡 **2권**. [09-04 유호 확정] 회화가 4권에서 2권으로 압축 · 톡1 = TOPIK 1~2급 · 톡2 = 3~4급. ⚠ Lv6(4~5급)의 5급 구간에는 대응 회화 교재가 없다.
- **1권 = 1시즌 = 8주 = 달력 두 달**(월 모듈 2개 + 8주차 승급 평가). 연 6시즌 = 수업 48주 + 휴업 4주 = 12개월에 6권 한 바퀴.
- 🔴 **학원이 제공할 수 있는 최대 기간은 1년이다.** 1년 이상 제공할 커리큘럼은 없다. 1년 다녀서 TOPIK 최소 3~4급, 권장 4~5급까지 도달하게 하는 것이 우리가 제공하는 전부다. 귀결: 1기 졸업은 **2028-02**.

### 레벨 ↔ 급

| | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 | Lv6 |
|---|---|---|---|---|---|---|
| TOPIK | 1급 | 2급 | 2~3급 | 3급 | 3~4급 | 4~5급 |
| CEFR | A1 | A2 | A2~B1 | B1 | B1~B2 | B2~C1 |

급이 겹치는 칸(Lv3·Lv5)은 오기가 아니라 **설계**다. TOPIK 급이 넓어 한 급을 두 관문에 걸쳐 다진다. 「중복이니 정리하자」는 제안을 받지 않는다.

### 나머지 고정값

- **승급은 도달제.** 8주차 승급 평가 통과 시 승급, 미달이면 **다시 도전**(재회전).
- **기간 단정 금지** — 「8주면 몇 급」·「12개월이면 몇 급」은 광고·상담에서 쓰지 않는다. 허용 표현은 「정규 과정 = 12개월 6시즌 구성」까지.
- **⚠ 「정규 과정」은 2026-08-28부터 «가격 티어» 이름이기도 하다**(구 「스탠다드」 · 유호 확정 「정규 과정이라는 어감이 스탠다드보다 더 좋다」). 한 낱말이 «과정 길이»와 «기간권» 둘을 이고 있으므로, 값과 붙일 때는 **반드시 「~권」을 단다** — 「정규 과정 **6개월권** 기준 월 42만₮」 ○ / 「정규 과정 6개월 42만₮」 ✗. 뒤엣것은 바로 윗줄의 「12개월 6시즌」과 부딪혀 **과정이 6개월짜리로 읽힌다.** 「권」 한 글자가 그 둘을 가른다.
- 진도 예시는 **최단 기준**으로만: 3급 약 8개월 · 4급 약 10개월 · 5급 도전선 약 12개월. 반드시 「개인별 도달제」 헤징을 같은 크기로 붙인다.
- **자체 콘텐츠는 TOPIK 5급까지. 6급 반은 열지 않는다.** 공식 문구 = 「정규 과정 Lv1~6 전 구간을 우리 교재 시냅스 코어 6권으로 완주합니다(TOPIK 5급까지)」. 상한이 5급인 이유는 한국 학부 입학선이 3급, 졸업·전공선이 4급이라 실수요 위쪽을 덮기 때문이다(한국 취업은 별도 시험 EPS-TOPIK).
- **교재 진행 상태**(과장 금지): 🔴 **[09-04 유호님 통보] 문법 시냅스 코어 6권과 회화 시냅스 톡 2권이 «모두 만들어져 있다».** ⚠ 「만들어졌다」와 「원어민 검수를 마쳤다」는 다른 층이다 — 검수 상태는 따로 확인하고, 확인 전에는 「검수 완료」·「검수 중」으로 앞당겨 쓰지 않는다. 옛 값(코어 6권 골격·요목 확정 / 1권 원고 완성(v2) / 2~6권 집필 중 / 톡 «4»권 설계 단계 / 「교재 완성」 금지)은 이날 통째로 갈렸다. ⚠ [09-04 정정] 여기 옛 값을 「톡 2권」으로 적었던 것은 역사를 왜곡한 것이다 — 압축 «전»은 4권이고 2권은 압축 «뒤» 값이다(결정.md 09-04 「4권에서 2권으로 압축」).
- 크루 캡스톤 공개일은 매 시즌이 아니라 **반년마다(세 시즌마다) 1회.**
- **반 구조**: 코어(정규/집중 구분 없음) = 출석·앱 전 기능 대상 / 위성 = 자유 참여, 출석 체크 없음. 주말은 토요일만(일요일 휴무). ⚠ 반 수·정원·좌석·증설 단계 숫자는 여기 적지 않는다 — §9가 가리키는 반편성 정본에서 읽는다.
- **위성 프로그램은 개원과 함께 댄스·회화부터 열고** 나머지는 준비되는 순서대로 더한다. 전부 첫날부터 열린다고 쓰지 않는다.
- **반 이름 표기 3층**: 문패(고정 명칭) = 몽골 별자리 이름 / 표시명 = 학생들이 지은 반 작명 / 내부 키는 대외물에 노출하지 않는다. 세 층을 섞어 쓰지 않는다.
- **주말반(토요일만) = 정규 트랙.** 축소판·맛보기가 아니다.
  - 대면 토 1회 90분 + 평일 수업 녹화분 제공
  - 커리큘럼·시즌·승급 기준은 평일과 같다
  - 가격은 평일과 동일. 주말생에게 올액세스는 판매하지 않는다(정본 = 급여 인센티브 정본 · 반편성 정본)
  - 상담 고지 문구: 「같은 커리큘럼, 대면이 주 1회이고 나머지는 온라인. 온라인을 안 들으면 진도가 따라오지 않습니다」

## §8. 과학 주장

**허용된 것만 쓴다. 반드시 출처를 귀속한다.** 정본(철학 v1.15 파생 게이트)의 허용은 아래 2~4 의 셋이고, 1 핀란드는 정본 목록 밖이라 **판정 대기**다(강사훈련 [확인 필요 #3] · 유호님 자리) — 정해질 때까지 새 대외물엔 넣지 않는다(09-02: 실험은 이름과 숫자로 · 네이퍼빌은 사례로 · 17%·TIMSS 순위는 쓰지 않는다).

1. 핀란드 **움직이는 학교(Liikkuva koulu)** 국가 프로그램 — 참여 교사들의 집중력 향상 보고, 학생 다수 「학교가 더 즐거워졌다」 응답 (핀란드 정부 보고서 귀속).
2. **운동→학습 무작위 실험** — 「짧고 강한 달리기 뒤에 새 어휘를 20% 더 빨리 익혔다」(Winter 외 2007 · Neurobiology of Learning and Memory · 27명 무작위 교차 · 8개월 추적) · 「학교 신체활동이 학업 성취를 작지만 유의하게 올린다」(He 외 2025 · Frontiers in Public Health · 무작위 실험 17개 · SMD 0.22) — 「~라고 보고됐습니다」로만.
3. **하버드 의대 존 레이티 『운동화 신은 뇌(Spark)』의 네이퍼빌 0교시 체육** — «사례»로만: 「이 원리를 학교의 하루에 넣은 가장 알려진 사례」. 17%·TIMSS 순위 숫자는 쓰지 않는다(대조군 없는 학교 안 실험 · TIMSS 1999 는 0교시 체육 2005 이전 결과).
4. **막스플랑크 연구소 등 독일 인지신경과학 연구** — 제스처 동반 어휘 학습의 기억률 우위. 「최대 2배까지 보고된」 수준으로만 표현.

**수정 필수**

- 「MIT·하버드·스탠퍼드 공동연구」 같은 뭉뚱그림 → 「다중감각 학습에 관한 연구들」로 일반화.
- 숫자는 반드시 「~로 보고되었습니다」 + 출처 귀속. **새 숫자 창조 절대 금지.**
- **보장 표현**: 광고 카피에선 몽골 광고법·소비자보호법 자문 전까지 보류. 철학·상담·설명회에선 「책임지고 만든다」는 태도는 쓰되 과정 낱말로 쓴다. 소개서류에는 「보장」 낱말을 넣지 않는다. **단 하나의 예외** — **「TOPIK은 확실하게 준비시킵니다」 계열은 학부모 대면물에서 유호님이 확정한 의도된 표현이다.** 있는 그대로 유지하고 완화 제안을 하지 않는다.
- **AI 활용(바깥 AI) 축의 확정 어휘 = 네 낱말 「맡기기 · 부탁하기 · 가려보기 · 책임지기」**(정본 = `docs/AI활용_가이드_v2.md` · 철학 Ⅱ-9). 이 축을 쓰는 문서는 네 낱말을 그대로 쓴다 — 다른 말로 바꿔 짓지 않는다.

### 포인트 경제 — 값을 여기 적지 않는다

**적립 단가의 유일한 정본은 `Code.js` 의 `PT` 상수 블록이고, 교환 상품은 `store` 시트다.** 상점은 22종(간식·문구·굿즈·가족·촬영 체험 포함). 쓸 때마다 거기서 읽는다 — 이 표를 여기 복사했던 동안 코드와 세 칸이 갈라졌다.

여기 두는 것은 **코드가 표현하지 못하는 규칙 셋**뿐이다.

- **과잠은 스토어 상품이 아니라 자격이다** — 재원 12개월 + 누적 포인트 충족 시 무료 지급. 포인트로 사는 물건이 아니다.
- 대외 문서에는 **「시즌별 소폭 조정 가능」**을 병기한다.
- **소멸·양도 규정은 미확정이다.** 구 「종료 후 6개월 소멸 · 양도 불가」는 코드에 없다 — 운영 정책 확정 전까지 대외 인용 금지.

## §12. 비노출 잠금 — 고객·학부모 대면물에서 지킨다

- **SYNK STUDIO는 언급하지 않는다.** 고객이 만나는 브랜드는 SYNK LAB 하나다(투자자·파트너 대면물은 예외 — 해당 프롬프트에 명시돼 있을 때만).
- 제품 라인(의류·굿즈·식품)은 어느 대면물에도 쓰지 않는다. 비노출이 아니라 **철회**다 — 예외 자리가 없다.
- 장학 제도의 인원수를 쓰지 않는다. 「매월 선정」까지만.
- 소개·안내물에 가격 수치를 넣지 않는다. 「상담에서 안내」로 넘긴다.
- 성과·합격 보장 표현을 쓰지 않는다(§8의 TOPIK 예외 포함, 이 자리에도 그대로 적용).
- **학생의 사진·영상은 언제나 사전 동의 전제이며 철회 가능하다**는 원칙을 학부모 대면물에서 빼지 않는다.

## §13. 디자인 잠금 — 색·서체는 킷 사슬이 정본이다

**색 hex 를 이 규범에 적지 않는다.**

| 무엇 | 정본 |
|---|---|
| 발표물·인쇄물의 색 (표·대비·로고·인쇄 규격 포함) | `docs/발표물/_브랜드킷.md` |
| 원천 사슬 | `docs/디자인_컨셉_정본_v1.md` (역할·조항) + `docs/디자인_토큰.json` (hex 기계 원천) |
| 서체 | `docs/브랜드_폰트_정본.md` |
| 로고 실행 | `tools/lib/로고정본.js` — 이 하나가 정본 |
| 교재(권1~) 층 | `docs/_archive/교재_권1_디자인시스템_v1.md` — ⚰**보관됨**(유호 확정 09-03 · 교재는 재헌님 몫). 규칙은 그대로다: 발표물 산출물에 교재 팔레트를 끌어오지 않는다 |

- **한 지면의 색 = 바탕 + 잉크 + 신호 1점.**
- 서체 3종 잠금: SUIT Variable · Inter Tight · DM Mono. DM Mono 는 워드마크·라벨·숫자 전용이고 본문·한글·키릴에 쓰지 않는다. 몽골어 병기는 1.04배 광학 보정.
- **로고는 두 락업이다** — 대외 `synk`(어센더 k) · 앱/내부 `syn<`(꺾쇠). 색갈래 셋: 코랄(기본) · 단색 · 알록. 앱 스플래시는 알록판.
- **앱 배경 정본은 다크**(어두운 펠트 작업대). 밝은판은 학부모 리포트 인쇄물·PDF 같은 문서 갈래의 재료다.
- **앱 화면 도해는 CSS 목업이 아니라 펠트 실물 오브젝트로 간다**(Loom). 문서에 싣는 앱 이미지는 굽힌 실물을 쓴다.
- 표지·챕터 브레이크는 다크 반전면을 기본형으로 한다.
- **이모지를 그대로 인쇄하지 않는다.** 단색 라인 아이콘(2pt 스트로크, 잉크 단색)으로 치환한다. 오픈소스 기반.
- 일러스트가 필요하면 두들 + 플랫 혼합(선 2.5pt · 잉크 단색 + 신호 1점). 실존 인물·캐릭터·타사 IP 를 쓰지 않는다.
- 마스코트 이미지는 **정본 사진**을 쓴다(몽글 = 펠트코랄_0815). 새 캐릭터를 지어내지 않는다.
- 발표물 산출 검사: `node tools/발표물린트.js docs/발표물/*.html`
