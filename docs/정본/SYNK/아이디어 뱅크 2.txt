이 파일은 외부 AI가 낸 초안이며 SYNK 정본과 대조하지 않았다.
읽는 것은 자유지만, 여기서 문장·숫자·이름을 가져다 쓰지 않는다.
아이디어 축적의 정본은 「SYNK 아이디어 보드」다.

정본과 충돌하는 것 다섯 가지 — 이걸 알고 읽어야 한다

  1. 신규 브랜드 일곱 개를 확정처럼 제안한다
     (Synk Korean · Academy · Korea Pathway · Assessment ·
      Skills Passport · Work · Global Talent OS)
     → 정본은 브랜드 넷(LAB·STUDIO·Wear·Pantry) + 레이어 둘이다.
       기업마스터 제8조 — 독립된 고객·상품·운영·수익구조가 실제로
       생겼을 때만 브랜드를 만든다.

  2. 경쟁 사이클을 하나 더 만든다
     (Learn → Assess → Prove → Study → Move → Work → Reskill)
     → 정본 사이클은 Learn → Plan → Experience → Record 넷뿐이다.

  3. 출처 없는 점수를 쓴다 (추천도 10/10, 장기 사업성 9.5/10 등)
     → 에디토리얼 브리프 §8 — 출처 없는 숫자는 쓰지 않는다.

  4. 가상 학생 실명과 점수표가 있다 ("바트 에르덴" 등)
     → 실존 인물로 오인될 수 있는 형식이다. 대외로 나가면 안 된다.

  5. 판번호·날짜·상태·담당·게이트가 하나도 없다
     → 아이디어 보드가 세운 축적 규칙을 따르지 않는다.

1. 최종 사업 방향
==================================================

SYNK의 장기 목표는 단순한 한국어 교육 앱 회사가 아니다.

최종 목표는 외국인이 언어를 배우고, 자신의 실력을 증명하고,
대학·취업 기회를 얻고, 새로운 국가에 정착하는 전 과정을
연결하는 글로벌 인재 플랫폼을 만드는 것이다.

전체 발전 과정:

AI 한국어 회화
→ 개인 맞춤 학습
→ 실전 능력평가
→ 유학 준비
→ 한국 입국 및 정착
→ 직무교육
→ 취업
→ 경력관리
→ 평생 재교육

장기 비전:

Learn
→ Assess
→ Prove
→ Study
→ Move
→ Work
→ Reskill

학습
→ 평가
→ 능력 증명
→ 유학
→ 국가 이동
→ 취업
→ 재교육


==================================================
2. 앞으로 중요해질 교육의 변화
==================================================

AI가 발전하면 다음 서비스는 점점 저렴하고 흔해질 가능성이 크다.

- 일반적인 AI 회화 챗봇
- 단순 번역
- 문제 자동 생성
- 강의 요약
- 일반적인 교육 콘텐츠
- 단순 자기소개서 작성
- 단순 대학 정보 제공

반대로 다음 영역은 계속 중요해질 가능성이 높다.

- 실제로 무엇을 할 수 있는지 평가하는 시스템
- 신뢰할 수 있는 능력 증명
- 학생 개인별 장기 학습 데이터
- 대학·기업과의 연결
- 유학·취업·정착 지원
- 직무별 실전 훈련
- AI 결과와 본인의 실력을 구분하는 평가
- 사람의 검수와 책임이 필요한 서비스

따라서 SYNK는 단순히 콘텐츠를 제공하는 회사가 아니라
학생의 실력을 측정하고, 증명하고, 기회와 연결하는 회사가 되어야 한다.

4. 장기 사업 아이디어 2
AI 실전 능력평가·시뮬레이션 플랫폼
==================================================

추천도: 9.5/10

앞으로는 학생이 무엇을 알고 있는가보다
실제 상황에서 무엇을 할 수 있는지가 중요해진다.

AI가 자기소개서, 숙제, 번역, 코딩 등을 대신할 수 있기 때문에
결과물만 보고 개인의 실력을 판단하기 어려워질 수 있다.

따라서 실제 상황을 제시하고,
학생이 음성·행동·문제 해결로 대응하게 하는 평가가 필요하다.

한국어 평가 항목:

- 발음
- 유창성
- 문법
- 어휘
- 질문 이해
- 대화 지속능력
- 존댓말 사용
- 문화적 적합성
- 상황 해결능력

대학생활 평가 항목:

- 교수님에게 질문하기
- 발표하기
- 조별과제 참여
- 학과 사무실 문의
- 대학 공지 이해
- 자신의 의견 설명
- 질문에 즉시 대응하기

직장 능력평가 항목:

- 상사의 업무지시 이해
- 동료와 협업
- 고객 응대
- 실수 보고
- 안전규칙 이해
- 문제 상황 판단
- 직장 내 존댓말
- 갈등 해결

예시 시뮬레이션:

상황:
호텔 고객이 예약과 다른 객실을 배정받아 화가 났다.

평가 목표:
1. 고객의 문제 확인
2. 적절하게 사과
3. 가능한 해결책 제시
4. 관리자에게 보고

평가 결과 예시:

- 한국어 의사소통: 78/100
- 고객 응대: 72/100
- 문제 해결: 69/100
- 감정 대응: 81/100
- 규정 준수: 64/100

수익모델:

- 평가 건당 결제
- 기업 채용 평가
- 대학 입학 전 평가
- 학원 월 구독
- 직무별 시뮬레이션 판매
- 기업 맞춤형 평가 제작비

14. 20년 뒤 비전
==================================================

20년 뒤의 정확한 기기를 예측하기는 어렵다.
따라서 특정 기술보다 변하지 않는 문제를 해결해야 한다.

장기적으로 변하지 않을 가능성이 높은 문제:

- 사람은 계속 새로운 기술을 배워야 한다.
- 기업은 실제로 일할 수 있는 사람을 찾아야 한다.
- 대학은 학생의 능력과 가능성을 평가해야 한다.
- 외국인은 언어·문화·제도에 적응해야 한다.
- 국가 간 학력·능력 인정이 어렵다.
- AI가 만든 결과와 개인의 실력을 구분하기 어렵다.
- 고령화 국가에는 외국 인력이 필요하다.

2046년 목표:

개인의 학습·능력·유학·국가 이동·취업을 연결하는
글로벌 인재 인프라를 구축한다.

사용자 경험 예시:

몽골에서 한국어 학습
→ AI가 능력과 관심 분야 분석
→ 적합한 전공과 직업 추천
→ 실전 상황 훈련
→ 능력평가
→ 검증된 포트폴리오 생성
→ 대학·기업 매칭
→ 유학 또는 취업
→ 입국 후 정착
→ 직장 적응
→ 추가 교육
→ 새로운 직업 또는 국가로 이동

20. 최종 핵심 원칙
==================================================

AI 모델 자체는 장기적인 경쟁력이 아닐 수 있다.
미래에는 여러 회사가 비슷한 AI 모델을 사용할 수 있기 때문이다.

SYNK가 장기적으로 가져야 할 경쟁력은 다음과 같다.

- 학생별 장기 학습 데이터
- 실제 성과와 연결된 평가 데이터
- 대학·생활·직장 시뮬레이션
- 신뢰할 수 있는 능력평가
- 대학·기업·지자체 네트워크
- 외국인의 유학·정착·취업 전체 경험
- 학생과 기관이 신뢰하는 브랜드

최종 목표:

10년 뒤에는 한국어 교육회사가 아니라
외국인 인재의 학습·평가·유학·정착·취업을 연결하는 회사가 된다.

20년 뒤에는 개인의 평생 능력을 검증하고,
국가·대학·기업을 연결하는 글로벌 인재 인프라가 된다.

VR·AR·스마트글라스는 플랫폼을 사용하는 수단이다.
진짜 핵심은 학생 데이터, 평가 엔진, 실전 시뮬레이션,
그리고 대학·기업 네트워크다.
