# SYNK 한국어 회화 AI — 현재 설계 연결

2026-10-17 정리. 이 문서는 회화 AI의 데이터·평가 설계에서 남길 원칙과 담당 원문을 잇는다. 2026-07~08의 업체 조사·개원 달력·학원 시트판 실행 지시는 현행 안내에서 분리했다. 한국어 교육은 SYNK 개인화 엔진의 첫 적용 분야이며 회사 전체를 몽골 학원용 챗봇 사업으로 한정하지 않는다.

## 현재 원문

- 사업·제품 순서와 재사용 조건: [제품 방향](../../제품방향.md), [비전](../../비전_정본.md).
- Atlas 8개 엔진의 역할과 실제 코드: [담당 원문·코드](../../엔진8종_상향설계_v3.md#engine-owner-sources). 회화 표현·튜터 연결은 해당 Vellum 계약, 학습자 판단·기록은 Core 및 각 담당 계약에서 확인한다. 별도 상위 엔진이나 LLM 선택기를 이 문서로 만들지 않는다.
- 학습 원본·기계 전사·사람의 확인·교정·권한: [코어엔진 설계](../../코어엔진_설계.md)와 그 문서가 연결하는 SYNK-talk 계약. 과거 시트판을 원본 저장소로 복구하지 않는다.
- 현재 제품·공개 상태: [철학 실물현황](../../철학_실물현황.md), 실제 운영·공개 여부는 담당 결과 기록과 대조한다.
- 계정과 학습 기록 안내: [개인정보처리방침 v1](../../개인정보처리방침_초안_v1.md). [v2](../../개인정보처리방침_초안_v2.md)는 미게시 초안이다. 제목에 ‘초안’이 있다는 이유로 두 문서의 게시 상태를 같게 취급하지 않는다.
- 제작·역할·비용: [AI 운영 원칙](../../AI_운영원칙.md). 7월의 업체 배치표나 특정 모델·계정·무료/유료 등급을 그대로 재사용하지 않는다.

## 남길 데이터·평가 설계

1. **학생이 지금 얻는 도움을 먼저 완성한다.** 대화·숙제의 기록은 향후 재사용 가능한 구조로 남기되, 기록 수집 자체를 학습 효과나 개인화 완료로 표시하지 않는다.
2. **서로 다른 근거를 구분한다.** 허용된 원음, 기계 전사, 사람이 실제로 듣고 확인한 전사, 교정문, 도움 제시와 재응답은 출처와 판본을 보존한다. 기계 전사를 정답 전사로 자동 승격하거나 ASR 오류를 학생의 문법 오류로 단정하지 않는다.
3. **원본과 파생 결과를 연결한다.** 문항·수준·시점·지원 조건을 담당 계약에 맞춰 기록한다. 저장 규격과 보관 기간은 제품·동의 계약을 따르며 옛 FLAC 권장이나 ‘원음을 버릴 이유가 없다’를 전 제품의 무기한 보관 규칙으로 적용하지 않는다.
4. **대화 품질과 평가 품질을 따로 확인한다.** 발화 인식·교정의 정확도와 지연·자연스러움·학생의 다음 행동을 구분해 검증한다. 특정 직결/조립 방식이나 업체를 고정하기 전에 실제 대상 음성·기기·비용으로 비교한다.
5. **합성 시험과 실제 학습을 구분한다.** 통제된 문장으로 기술 계약을 검증할 수 있지만 실제 몽골 억양·교실 잡음·대화·학습 효과의 증거가 되지는 않는다. 평가 자료의 출처·사람 확인 범위·사용 조건을 남긴다.
6. **학생 수준과 요청에 맞춘다.** 허용 어휘·문법·상황, 짧은 도움과 의미 있는 재시도, 끝나는 조건을 실제 학습 흐름에 맞춘다. 오래된 일률적인 ‘한 턴 교정 하나’나 전 제품 고정 페르소나를 공통 지침으로 복원하지 않는다.
7. **수집·보관·훈련·공개는 각각 확인한다.** 수집 동의나 학습 기록 저장 선택이 모델 훈련·외부 업체 전송·공개의 자동 허용은 아니다. 가명 코드만 붙였다고 익명 데이터나 회사가 자유롭게 소유한 자료로 단정하지 않는다.

교실 녹음·강사 설명·별도 음성 평가셋은 목적, 동의, 담당 업무와 실제 품질을 확인할 때 검토할 수 있는 재료다. 대화만 하면 수집·검수 비용이0이 되거나 20~100시간·2~4개월이면 성능이 확보된다는 계산은 현재 약속에서 제외한다. 학생 수·녹음 품질·권한·전사 검수·인프라 비용은 실제 조건에서 확인해야 한다.

마스코트의 상주 비언어 반응과 학습 음성·회화 튜터는 [캐릭터 가이드](../../캐릭터/가이드_정본.md)의 해당 범위를 따른다. 과거 ‘TTS0’ 설명을 노래·학습·광고 음성 전체의 금지로 확대하지 않는다.
