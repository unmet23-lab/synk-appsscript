# SYNK 사업계획서

2026년 10월 2일 현행화. SYNK LAB 오프라인 검수와 사용자의 최신 요청을 반영했다. 무료 자습은 빈 강의실 예약제로 운영하며, 시설·인력·상황상 제공하기 어려운 상시 서비스 약속을 개원 기본 구성에서 뺐다. 임대·자금·모집·앱 운영의 미확정 상태를 완료로 쓰지 않는다.

이 문서는 회사의 사업 역할과 LAB 개원 실행 기준을 연결한다. 세부 운영은 [오프라인 운영 기준](../../오프라인_공간설계/오프라인_운영기준_20261002.md), 교육·비용·계약은 각 담당 원문을 따른다. 기존 시나리오의 가격·급여·384석·손익은 현재 실측이나 계약 상태가 아니다.

## 1 회사의 방향과 네 브랜드

SYNK는 개인화 엔진을 만드는 기업이다. 한국어 교육, 기업의 AI 활용, 콘텐츠, 유학·취업 준비는 이 기술이 쓰이는 분야다. 회사 전체를 한국어 학원 하나로 정의하지 않는다.

| 브랜드 | 사업 역할 | LAB 오프라인과의 접점 |
|---|---|---|
| SYNK LAB | 한국어 학습과 한국에서의 공부·생활 준비 | 교실 수업·담임 관리·예약 문화 체험·학습 콘텐츠 |
| SYNK SHIFT | 기업·기관의 AI 교육/컨설팅과 브랜딩 | 필요한 사업 운영·AI 활용 교육을 별도 범위로 연결 |
| SYNK PULSE | 자체 음악·영상·캐릭터 IP와 의뢰 광고/브랜드필름·AI 모델·룩북 제작 | 동의와 별도 제작 계획에 따른 콘텐츠/홍보. 모든 수업을 공개 촬영물로 사용하지 않음 |

Atlas는 Core·Loom·Vellum·Trail·Prism·Temper·Reed·Strata, 기존8개 엔진의 총칭이다. 별도 회사 런처나 새로운 상위 엔진의 이름으로 쓰지 않는다. 학생 앱은 SYNK WORLD, 회사 브랜드 런처는 SYNK 플랫폼이다. 사내 메신저와 WORLD의 계정 권한·자료는 구분한다.

## 3 대상과 판매할 상품

LAB은 한국어를 배우며 한국 학업·생활·진로를 준비하려는 청소년과 성인을 대상으로 한다. 정확한 연령·보호자 절차·학교/직장 시간과 통학 수요는 실제 상담과 파일럿에서 확인한다. 확인하지 않은 시장 인구·경쟁 가격·점유율·진도 단축 효과를 실측값으로 안내하지 않는다.

### 3-1 정규 한국어

- 한 차시90분, 기본 평일주5회 모델이다. 실제 요일·시작 시각·휴무·교대·운영 반 수는 방별 시간표를 작성한 뒤 등록 조건으로 고지한다.
- 6레벨·레벨당8주를 기본으로 열두 달 과정의 콘텐츠를 계획한다. 기간을 채워 자동 승급하지 않고 실제 도달 기준으로 판단한다.
- 목표는 TOPIK4급이며 자체 콘텐츠의 상한은5급이다. 6급반과 특정 기간 내 모든 학생의 급수 달성 보장은 제공하지 않는다.
- 담임의 개인 접점, 과제와 피드백, 실제 제공 가능한 학습 콘텐츠를 묶는다. 게임·AI의 설계/개발과 학습 효과를 구분하고, 현재 연결되지 않은 자동 평가를 수강료의 완료 서비스로 안내하지 않는다.
- 재회전과 휴학으로 재원 기간이 콘텐츠의 기본12개월 계획을 넘을 수 있다. 반 배정·기간권·비용·수료 처리의 현행 계약 조건을 등록 전에 정한다.

### 3-2 추가 학습과 문화 혜택

원어민 회화·글로벌 영어는 실제 강사·교실·시간을 확보한 등록 구성에서만 제공한다. 기존 상위 등록의 방향을 유지하되 제공 횟수·시간·담당이 비어 있는 상품을 먼저 팔지 않는다. 기존 내부 수강료는 가격 검토 자료이며 공개 가격 확정 상태가 아니다.

무료 문화 프로그램은 신청25명 댄스의 제공 가능한 고정 회차를 중심으로 구성한다. 정규 수강과 신청 대상·예약/취소/대기·제공 횟수를 안내한다. 정원 확인 명단은 학습 성적이나 출석 보상과 구분한다. 모든 수업 앞뒤에 자유 참여 문화수업이 항상 열리거나 다른 언어 수업과 음악이 동시에 가능하다고 약속하지 않는다.

보컬·뷰티의 상시 개원 편성, 토90분+평일 녹화만으로 평일과 동등 진도/말하기/승급을 보장하는 주말 상품은 개원 판매대상에서 제외한다. 실제 공급표·담당·비용·동의/권한·학생 학습 시험을 통과한 경우에만 별도 상품을 검토한다. 온라인 학습 앱 자체의 개발을 폐기하는 뜻은 아니다.

### 3-3 가격과 등록 조건

현재 공개 확정 가격은 없다. 기존 정규/상위 등록의 내부1·3·6개월 가격표를 지금의 확정 상품으로 재인용하지 않는다. 실제 제공량·혜택 원가·환불·납부/할인·현지 법률·몽골어 감수와 맞춰 한 가격/계약판으로 공개한다. 가격을 임의로 새로 정하거나 과거 숫자로 당장의 흑자를 계산하지 않는다.

## 4 공간과 예약 운영

최신 A+B 모듈의 열린 공간은13.2×11m=145.2㎡ 비교안이다. 닫힌 A와 B의16석씩, 나머지 C/D와 각 지원 공간을 유지한다. 전체 전용약102~104평은 면적 프로그램의 비교값이며 실제 매물에 들어가거나 허용 정원을 충족한다는 결론이 아니다.

칸막이 패널·레일·구조 지지/보강·씰·상부 우회음·보관 포켓·잠금·취급 교육을 포함해 견적한다. A/B가 닫히면 독립 출입·조명·전원·환기와 일반 말소리 수업이 가능해야 한다. 댄스 때는 책상/의자32세트와 이동 화면을 활동/피난 영역 밖의 검증된 수납에 넣는다. 수납12~16㎡ 후보에 패널 포켓까지 이미 포함됐다고 계산하지 않는다.

공기청정기·가습기는 일반7실의 배치 방향을 유지하며 실제 제품·전원/물·세척·건조·필터·담당을 정한다. 화장실 디퓨저와 은은한 향은 환기나 위생을 대신하지 않는다. 민감한 학생에게 강한 향을 노출하는 상시 향 서비스는 약속하지 않는다.

### 4-1 무료 자습

현재 재학생에게 빈 강의실 좌석 예약을 무료로 제공한다. 하루약2~3시간의 빈 시간을 예상하지만 실제 시간표·좌석·현장 담당을 확인한 시간만 공개한다. 모든 교실의 매일2~3시간 보장이나 상시 입실은 아니다.

수업·보강·청소·가변 전환·촬영 준비·학생 대기를 예약과 중복하지 않는다. 담당 접수/예약표로 날짜·방·시작/종료·좌석·입퇴실을 확인하고 앱은 실제 구현 후 연결한다. 기존 책상·의자·Wi-Fi·사용 가능한 전원을 활용하며 자습 중 학생 촬영/녹음을 하지 않는다. 수업 준비 전에 종료하고 다음 반 입실과 마감을 확인한다.

### 4-2 댄스와 교대

초기에는 댄스 음악과 다른 한국어 수업 시간을 분리한다. 마지막 정규 수업 뒤 또는 가능한 주말 고정 회차를 비교한다. 야간 시각은 학생 귀가·강사/직원 근무·건물 허용과 이웃 소음 조건이 맞을 때만 선택한다.

댄스40분·준비20분·복구30분은 미측정 비교이고 확정 회차가 아니다. 실제 전환, 감독 가능한 대기, 보호자 인계, 교사 휴게와 복구를 시간표·근무·비용에 넣는다. 같은 학생은 중복 집계하지 않고 외부 참가/조기 도착·늦은 하원·보호자·직원을 더해 최대 재실을 확인한다. 모든 반을 같은 시각에 교대시키거나 교대0분으로 편성하지 않는다.

### 4-3 작은 발표와 별도 행사

해당 반 수업 안의 작은 발표·프로젝트 공유를 기본으로 한다. 앞뒤 기수와 학부모가 동시에 모이는 내부 정례 광장/공개 무대는 기본 상품에서 삭제한다. 별도 행사에는 출연/관람/보호자 수, 좌석·대기·감독·피난·시간표·비용을 먼저 정한다. 시설이 맞지 않으면 여러 회차나 외부 장소를 비교하며 행사 전용 방을 자동 증설하지 않는다.

개인 책상은 유지한다. 실제 출석1명은 교사와 짝,2~4명1조,5~8명2조,9~12명3조,13~16명4조를 기본으로 조 크기와 역할·청취 순환을 맞춘다. 교실에서 화면 보기·가방/의자 인출·학생 교대·교사 접근을 시험한다. 움직임이 필요하면 수업 시간에 포함하고 다음 블록 시작에 복구한다.

16명 개인 접점은 주간 명단으로 확인한다. 주5차시의3·3·3·3·4명 예시처럼 전원에게 돌아가야 한다. 인사와1:1 보충·진로 검토는 다른 노동이므로 별도 시간을 배정한다.

교재는 문법6권·회화2권 원고가 있다는 것과 원어민 검수·인쇄·학생 사용 인수가 완료됐다는 것을 구분한다. 먼저 열 레벨의 학생본·교사본·평가·과제/영상·몽골어 안내를 한 묶음으로 인수한다. 실제 수업 기록으로 평가/개인화의 효용을 확인하고 진도 개월 수·합격률·학습 효과를 사전 실측처럼 공개하지 않는다.

## 7 혜택과 학생 계약

## 8 촬영과 부모 서비스

온라인 영상의 기본은 TV/전자칠판/교재를 카메라로 다시 찍는 방식 대신 자료 원본 캡처를 메인으로 하고, 교사를 작은 화면으로 합성하는 것이다. 발음 설명에서 교사 크게, 자료 집중에서 교사 숨김은 보기 구성의 설계이며 학생별 실제 실시간 선택 기능은 개발/운영 인수 후 제공한다.

## 9 PATH와 PULSE를 연결하는 범위

LAB의 무료 진로 검토1회와 PATH의 수속/한국 현지 지원을 구분한다. 학교·전공 선택, 직접 작성한 서류·발표/프로젝트의 검토는 실제 담당 시간으로 제공한다. 수속·공항·기숙사·체류/정착·인턴/취업 연결은 확정 파트너와 기간·가격·역할·종료 조건을 별도 계약에 적는다.

실제 매물과 최대 재실에 맞게 충족하거나 그 매물을 선택하지 않는 조건이다. 소화기3대 초안·남녀각1기구·예약25명·공기청정기·향이 적법성과 안전을 대신하지 않는다. 현지 적용·검토·시험·완료 자료를 인수하기 전 완료로 표기하지 않는다.

## 13 기술과 IP의 확인 범위

회사의 엔진·앱·콘텐츠는 현재 코드와 담당 문서로 확인한다. 예전Apps Script의판번호·CONTENT_EXPECT·자동화 목록을 전체 회사 기술 재고의 증거로 쓰지 않는다. 기존8개 엔진의 원문/코드, WORLD·플랫폼·교사 화면·계정/학습 서버의 구현·배포·기능 스위치·실제 로그인/효과를 단계별로 기록한다.

교재 원고·소스·승인 브랜드 자산·상표 출원·특허 작업 자료가 있다는 사실을 등록완료·권리범위 확정·학습 효과·독점 자산 가치와 동일하게 안내하지 않는다. 기존SYNK 상표1건은 납부 기록과 출원번호가 있으나 류/상태 확인이 필요하다. 양국 법인·상표·저작권·음원/앱 출시·촬영/초상/음성·개발/제작 계약은 담당 비용/권리 원문과 증빙으로 닫는다.

상담·수업·학생 작품의 허용된 기록은 현재 학생 도움을 위해 사용한다. 운영 수집이 연구/모델 학습·공개 홍보·회사 전사 공유를 자동 허용하지 않는다. 별도 목적·권한·동의·보관/삭제와 실제 소비를 확인한다. 기반이 있다는 것으로 훈련·성능 향상·학생 효과를 완료로 보고하지 않는다.
