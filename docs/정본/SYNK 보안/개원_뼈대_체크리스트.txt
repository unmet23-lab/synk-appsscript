개원 전 뼈대 체크리스트

───────────────────────────────────────

읽는 법: 문서·시스템·콘텐츠처럼 AI가 만들 수 있는 뼈대는 대부분 서 있습니다. 아래는 유호님의 결정·발품·계약으로만 서는 것들이고, "즉시"에 있는 항목은 하루 미루면 뒤 일정이 하루씩 통째로 밀리는 달력 비가역 항목입니다.


◆ 즉시 착수 (7월 — 달력 비가역)

1. FB 페이지 신규 생성 + 광고계정 개설 + 결제 실측
   계정 통화는 생성 시 1회 영구 고정이니 신중히. 국제카드 소액 결제가 실제 승인되는지 먼저 실측.
   오가닉 참여자 1,000명(리타겟팅 최소선)까지 2~3개월 — 지금 시작해야 10월 유료 단계가 섭니다.
   성과보증형 카피가 없는 소재는 지금 집행 가능(보증형 카피만 변호사 확인 게이트에 걸림).

2. 콘텐츠 발행 시작
   주간팩 스케줄 0건(07-19 실측) — 재고 57편은 있으니 "만들기"가 아니라 "내보내기"부터.
   발행 속도는 12개월 캘린더 기준으로 고정(주간팩 속도로 돌리면 캐러셀 ~5주 만에 소진).
   10월 유료 광고 전에 광고용 CTA 배리언트·카드뉴스 보강 필요.

3. 몽골어 감수자 확정 (에리카쌤 후보)
   콘텐츠 57편 + 플래그십 문서 번역이 전부 이 1인에 물려 있음. 발행 D-3 감수 완료 원칙.

4. Glide 조립 마무리 + 요금제 판정
   사람 몫 4건: 상담시트 반 배정 · 강사 class_name · parent_of · P02 이메일 → preflight ⚠0 → 조립.
   조립 전에 앱 언어 정책(2축 차등안) 확정.
   그리고 재적 84~92명 기준 월 500 업데이트 실측 → Maker 한도 초과면 플랜/출석 방식 결정.
   (월 500 제약은 출시 최대 리스크로 기록된 항목입니다.)


◆ 8월 — 몰아서 닫는 달

5. 변호사 미팅 1회로 5건 일괄
   ① 성과보증 카피 적법성 — 대상은 보증형 카피를 쓰는 소재와 구 학부모 안내문 잔존 문구
      (새 소개서 축은 이미 무보증 스탠스라 대상 아님)
   ② 선납 환불 강행규정 → 확인 직후 환불정책 확정 (계약서의 전제)
   ③ 노동법 정합 (크루 핸드북 확정 전)
   ④ 인허가 — 형태 + 신청 절차와 취득 리드타임 + 공간 주소가 선행 요건인지
      (주소 선행형이면 공간 계약 뒤에야 신청 가능 = 개원 직전 병목. 별도 마일스톤으로.)
   ⑤ 사회보험 13%·외국인 고용부담금 면제 경로의 서면 확인 (비공식 면제는 노동허가 리스크)
   + 학원 배상책임보험 요건·현지 상품 확인 (매일 몸 쓰는 워밍업이 도는 학원)

6. 교재 실사
   시냅스 코어 1~6권·시냅스 톡 원고의 실제 완성도 확인 → 커리큘럼 정본과 실라버스 매핑
   → 10월 인쇄 발주(오픈 2주 전 입고 역산). 파일럿용은 11월 소량 제본 별도.

7. 기존 학원 실데이터 추출
   재학생 수·객단가·월 이탈률·재등록률·상담→등록 전환율 — 재무 가정의 앵커 교체.

8. 가격카드 최종 채택 (8월 말 데드라인)
   비용·BEP는 잠금 완료(전 직원 11명·번 개원 4,051/만석 4,413만₮·BEP 107/117명 — 정본 = 급여 인센티브 정본 v1.1, 07-29 잠금).
   남은 것은 가격카드(2티어 + 애드온) 채택 선언 1건 — 계약서·안내문·파일럿 모집·유료 광고가
   전부 이 뒤에 섭니다. 레벨 대응표(Lv1~6=교재 권수 연동 유력안)도 함께 채택하면 한 번에 끝.


◆ 9~10월 — 실물 계약의 달

9. 강사 채용·계약 (11월 부트캠프의 전제)
   계약서에 급여 개시일을 명시해 계약 시점과 분리할 것 — 6인 급여가 매출 0 구간에
   3~5개월 흐르면 선행 지출이 재산정 추정(3,000~4,000만₮)을 크게 넘습니다.

10. 공간 계약 (10월 말 데드라인 — 11월 착공 역산)
    계약과 함께 보증금·CAPEX 실규모 확정 → 러너웨이 재산정 완결.
    혹한기(12~1월) 인테리어 시공 가능 여부는 발품으로 사전 확인.

11. 등록 계약서·약관 개정
    기존 등록신청서 기반 + 신가격 + 환불정책(8월 확정분) + 초상권·데이터 동의서 양식.
    (동의·철회 "원칙"은 문서에 있으나 서명할 "양식" 실물이 아직 없습니다.)

12. 수납 실무
    수납 채널(계좌이체/QPay 단건/현금) + 몽골 전자영수증(ebarimt) 발행 의무 확인
    + 선수금(이연수익) 장부 처리 방식.


◆ 11월 → 개원

11월  강사 부트캠프 · 인테리어 착공 · 몽골어 자료 배포 · 파일럿용 교재 소량 제본
12월  파일럿 코호트 — 형태(무료 2주 전환형 / 가격 실측형)는 유호님 결정 대기 항목.
      어느 쪽이든 10~11월 모집 착수와 장소(기존 학원 공간?) 사전 확정이 공통 전제.
1월   파일럿 피드백 튜닝 · 오픈 캠페인 준비 · 개원 리허설(D-2주)
      리허설 = 첫 주 흐름 통돌이: 레벨테스트(실물 문항 필요)→반 배정→나침반 1회차
      (드림맵 카드 인쇄물 필요)→앱 온보딩. 11월 부트캠프(교수법)와는 별개의 실전 점검.
2월   개원.
