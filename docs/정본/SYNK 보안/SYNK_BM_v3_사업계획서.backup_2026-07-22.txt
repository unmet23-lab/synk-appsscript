 1. SYNK는 무엇을 만드는가
================================================================

 1-1. 조직 계보 (2026-07-17 확정 정본)

 3브랜드
  - SYNK LAB    : 한국어 어학원. 그룹의 코어 엔진, 현금흐름 원천
  - SYNK STUDIO : 기록·콘텐츠. 학생의 경험을 이야기로 남기고,
                  그 기록이 마케팅 자산이 된다
  - SYNK LIFE   : 제품 공개 전까지 비공개 트랙

 2레이어 (브랜드를 떠받치는 공통 기반)
  - IP            : 교재 '시냅스 톡' 시리즈, 커리큘럼, 게임화 세계관
  - COMMON SYSTEM : 자동화 엔진 v9.x + 학생 앱 + 계측 파이프라인

 사이클: Learn -> Plan -> Experience -> Record
 (배우고, 설계하고, 경험하고, 기록한다 — 학생 여정과 사업
  구조가 같은 사이클을 돈다)

 SYNK라는 이름은 학습과 목적 발견의 동기화(synchronize)를
 뜻한다. 기존 어학원의 순서가 "언어 학습 -> 자격증 -> 이제
 뭐 하지?"라면, SYNK의 순서는 "목적 발견 x 언어 학습 ->
 자격증 -> 자격증 활용"이다.

 1-2. 철학 4기둥 = 실물 프로그램 4종 (전부 설계·구축 완료)

  1) 목적이 먼저다
     -> 나침반 세션(입학+시즌마다 목적·로드맵 워크숍)
  2) 몸이 깨어날 때, 뇌는 가장 깊이 배운다
     -> K컬처 위성 수업(무료·자유참여 — 4-1 참조)
  3) AI가 대체하기 어려운 사람(감응력·협응력·공감)
     -> 싱크 크루 프로젝트(시즌 팀 프로젝트)
  4) 실질적 결과
     -> 싱크 포트폴리오(드림맵+프로젝트 결과물+TOPIK 누적)

 1-3. 교육 -> 기록 -> 데이터 플라이휠

  교육(LAB)    : 매일의 수업·위성·시그니처가 경험을 만든다
  기록(STUDIO) : 그 경험을 콘텐츠로 남긴다 — 위성 촬영 ->
                 주 3~5개 릴스. 콘텐츠가 CAC를 5~10만₮로
                 누른다 [추정]
  데이터(엔진) : 엔진 v9.46 + 앱이 출석·포인트·이탈률·전환율
                 자동 계측. 데이터가 리텐션·가격·확장을 지배
  다시 교육    : 실측 이탈률·전환율이 다음 코호트 설계에 반영

 세 바퀴 중 어느 것도 계획이 아니다. 엔진은 가동 중이고,
 앱은 운영 중이며, 콘텐츠 57편은 기제작 상태다(11장).
 이 문서에서 "플랫폼"은 비전이 아니라 재고 목록이다.

 2. 왜 몽골, 왜 지금 — 그리고 어려운 진실 4가지
================================================================

 2-1. 시장의 크기 (실측 우선)

  - 울란바토르 인구 약 170만 명 [실측]
  - UB 유료 지불 가능 진지 학습층 연 1.5만~2.5만 명 [추정]
  - SYNK 만석 220명의 시장 점유 약 1% [산식]
  - 세종학당(무료) UB 연 수용 약 2,000명 — 수요 대비
    사실상 대기열 [실측+추정]
  - 로컬 학원 가격 월 13~28만₮ [실측]
  - 몽골->한국 유학생 연 1.3만~1.6만 명, 연 15%± 성장
  - 한국 체류 몽골인 3.7만~5만 명 [실측]

 시장 크기는 제약이 아니다. 만석이어도 시장의 1%다.
 제약은 1) 인지도 2) "저 가격을 낼 이유"의 전달 3) 이탈률이다.

 가격 지형: 세종학당 무료(대기열) / 로컬 13~28만₮ /
 SYNK 42~69만₮ — 시장 최고가이고, 숨길 생각이 없다.
 성립 근거는 4-4에서 5가지로 제시한다.

 2-2. 어려운 진실 4가지

 진실 1. 우리는 시장 최고가다.
  로컬의 2~3배. 이 문장은 광고 카피가 아니라 리스크 항목이다.
  가격으로 싸우지 않는다 — 속도(6개월 252만₮은 한국 취업
  첫 달 월급의 절반), 성과 보증, 희소자원(한국인 원어민+앱+
  시스템)으로 싸운다.

 진실 2. E-9 쿼터가 줄고 있다.
  한국 고용허가제 글로벌 쿼터 2024년 16.5만 -> 2026년 8만
  [실측]. EPS 단일 카피에 성인 모집을 걸면 축소되는 시장을
  향해 쏘는 것이다. 방어: 성인 동기를 D-4/D-2 어학연수·
  E-7 전문직·한국계 기업·K컬처 정체성으로 분산, M1부터 적용.

 진실 3. 겨울이 온다.
  UB의 1월은 영하 40도, 겨울 대기오염은 세계 최악 수준
  [실측]. 겨울 리스크는 등록 감소가 아니라 출석률 붕괴로
  먼저 온다. 여기에 난방 피크 약 +200만₮/월. 영하 40도는
  마케팅으로 해결되지 않는다. 현금으로 해결된다(8장).
  상품 차원 방어 = 12~2월 하이브리드 모드(주5일 중 2일
  온라인·앱 미션 전환) 내장.

 진실 4. 여름은 성수기가 아니다.
  몽골의 여름은 한국의 방학 특강 시즌이 아니다. 7월 나담과
  시골 친척 방문·캠프 이주로 도시 수요가 빠진다. 진짜
  성수기는 9~11월(신학년)과 2월말~4월(봄·TOPIK). 그래서
  만석을 개원 후 16~18개월(2028 중반)로 잡았다. 달력에
  정직한 계획이 달력에 낙관한 계획을 이긴다.

 2-3. 그럼에도 왜 지금인가

  - 무료 경쟁자(세종학당)는 공급 부족 대기열. "지금 시작"을
    파는 사업자가 없다
  - UB 학교는 2~3부제 [실측]. 1부제 학생의 평일 낮이 통째로
    비는데 이 슬롯을 정규로 건드리는 경쟁자가 없다 — 확정
    시간표는 14:00·15:30 코어로 이 낮 시간대를 정조준했다
  - 교육서비스 VAT 면세 + 소기업 법인세 특례 가능성 [실측,
    인허가 형태 확인 전제]. 세제는 순풍
  - 자산이 이미 있다: 엔진·앱·교재·콘텐츠 57편·확정 시간표
    (11장) — 개원 전에 이미 절반이 실물이다

 3. 누구에게 파는가
================================================================

 타겟 정의(명문화):
 "상위 20~25% 소득 가구의 청소년 + 목적 확실한 성인.
  중위소득층은 고객이 아니라 세종학당의 몫."

 중위임금 100만₮ 가구에 월 42만₮은 가구소득의 40%+ —
 수학적으로 고객이 될 수 없다 [실측+산식]. 반면 몽골 교육
 지출은 극단적 상위 편중이다(대입 상위 10개교 중 9곳 사립).
 우리의 서사는 "만석 1위"가 아니라 "프리미엄 니치 1위"다.

 페르소나 A — 청소년: 팬덤이 조르고, 부모가 승인한다
  - 16세, 1부제 재학(이른 하교). K팝 팬덤이 동기의 출발점
  - 의사결정: 자녀가 조르고 부모가 승인 [추정] — 한국과 역방향
  - 지불자: 부모(맞벌이 합산 350~450만₮ 가구 [추정]).
    월 42만₮ = 가구소득의 10~12% — 한국 학부모의 학원비
    비중과 유사 [산식]
  - 퍼널 이원화: 자녀용 후킹(틱톡·챌린지·무료 위성 체험) +
    부모용 승인 자료(TOPIK 성과·안전·통학·교사 신뢰, 몽골어)
  - 겨울 통학 = 부모 픽업 전제 -> 입지에 픽업 동선 포함
  - 차강사르 = 순증 0의 수성기이자 친족 구전 시즌

 페르소나 B — 성인: 가격을 투자수익으로 계산한다
  - 20대 후반, 한국 취업·유학·커리어 목적
  - 월 42만₮을 "소득 대비 %"가 아니라 "한국행이 앞당겨지는
    속도"로 평가. 6개월 252만₮ = 한국 취업 첫 달 월급의 절반
  - E-9 축소를 정면 반영, 동기 포트폴리오 분산(진실 2)
  - 주력 시간대: 오전 11:00 / 주말반

 두 페르소나는 카피도 채널도 시간표도 다르다. 그러나
 리텐션 엔진(앱·담임·스트릭)과 계측은 공유한다 — 고정비를
 나눠 쓰는 두 개의 수요 축이다.

 8-1. 용어부터 — 이 문서에 배당 약속은 없다

  매출과 이익과 현금은 다르다. 기간권 선납 구조상 현금은
  매출을 선행한다(선수금). 그 시차가 겨울 방어의 재료다
  (9~10월 선수취 -> 12~2월 소진). "지분 1%당 월 얼마" 식의
  배당 산수는 이 문서에 없다.

 8-2. 자금 2.4억₮ — 조달이 아니라 조건 (정의 확정)

  2.4억₮ = CAPEX + 보증금 + 운영버퍼 전부 (창업자 확정,
  이미 준비됨)

  러너웨이 산식 [CAPEX·보증금 합계 X 확정 시 갱신]:
   잔여 운영버퍼 = 24,000만₮ - X - 선행 번(임대 개시~개원,
   약 3,000~4,000만₮ [추정])
   러너웨이(매출 0 최악 가정) = 잔여 버퍼 / 3,922만₮

   예시: X = 4,000만₮ -> 약 4.2개월
         X = 8,000만₮ -> 약 3.2개월
  구 번(6,100) 기준 2.1~2.8개월에서 3~4개월+ 로 개선 —
  같은 돈이 더 긴 활주로가 됐다. 실제로는 M1부터 매출이
  흐르므로 실질 버퍼는 이보다 길다.

 8-3. 첫 겨울 현금 시간표 (새 달력)

  2027.9~11 (M7~9)   신학년 성수기 + 6개월권 선수취 창.
                     겨울 현금을 가을에 받는 유일한 창
  2027.12~2028.2     첫 겨울. 손익 -870~+520만₮/월(재적
  (M10~12)           70~100 구간별). 선수금 소진 + 버퍼
                     3,000만₮ 방어. 하이브리드 모드 ON
  2028.3~ (M13~)     봄 성수기 신규 수납 재개

  발생 기준으로 첫 겨울이 적자인지 흑자인지는 M7~9 선수취
  성과가 결정한다. 이 시차 설계가 무너지는 경우는 하나 —
  가을 판매의 전제인 전환율이 틀렸을 때다. 그래서 파일럿의
  임무가 매출이 아니라 실측이다(9-1).

 9. 리스크 레지스터
================================================================

 9-1. 사인(死因) 1위 — 전환율 미실측 낙관 x 첫 겨울

  v3에서 BEP가 내려와 치명도가 완화됐지만, 구조는 그대로다:
  1) 겨울은 확률이 아니라 일정이다(발생 100%)
  2) 전환율 실측은 가장 늦게 확정된다 — 겨울 버퍼의 충분
     여부를 겨울 직전에야 알게 되는 시간 구조 자체가 함정
  3) 현금이 마르면 다른 모든 리스크가 증폭된다

  방어(개원 전 두 가지, 둘 다 조건):
  - 현금 2.4억₮ 확보 상태로만 개원한다 (확정: 준비됨)
  - 2주 무료 파일럿(2026.12~2027.1)을 매출이 아니라 전환율
    실험으로 설계한다. 체험->등록 25% 가정의 생사를 개원
    전에 판정하고, 실패 시 플랜B(가격·램프 조정)를 개원
    전에 발동한다

 9-2. 리스크 시나리오 (트리거 -> 방어)

  1) 첫 겨울 x 현금 (사인 1위)
     12월은 반드시 온다 -> 2.4억 조건화 + 9~11월 선수취 +
     하이브리드 모드
  2) 전환율 붕괴(25 -> 12%)
     첫 90일 실측치 -> 파일럿 조기 발견, 플랜B 발동
  3) 법정 비용 미해결 (v3 신규 — 최우선 확인)
     사회보험·고용부담금 "해결 가능" 전제가 무산 ->
     번 +385만₮·BEP 93명 재산정. 계획은 깨지지 않으나
     합법 면제 근거의 서면 확보가 조건. 비공식 처리에
     기대는 순간 노동허가 취소 = 원어민 전원 리스크
  4) 핵심 강사 이탈
     코어 4인(인우·수길·에리카·댄스쌤)이 각자 최대 타임 —
     결원 시 대타 여력 0 -> 표준교안 + 합반 SOP + 원장
     대타 1순위 + 급여 외 처우(성과연동·콘텐츠 출연) 설계
  5) 급여 100 균일의 이탈 압력 (v3 신규)
     특히 원어민에게 100만원은 한국 최저임금 미만 —
     장기 지속 불가 전제로 성숙기 인상 로드맵을 미리 설계,
     파트타임은 시급 후대 + 정규 전환 트랙
  6) 키맨 유호 다운
     회화·주말·대타·경영 과적재 -> 운영 지식의 코드화
     (엔진·표준교안·SOP) — 사람이 아니라 시스템이 기억한다
  7) 가격전쟁·미투
     로컬의 카피 -> 가격 불응전. 경쟁 자산은 계측 시스템·
     콘텐츠 아카이브·성과 데이터 — 카피에 시간이 걸리는 실물
  8) 거시 (환율·난방 인상·E-9 축소)
     외생 -> 성인 동기 분산, 청소년 비중 확대, 예비비,
     버퍼 재산정
  9) 부분 유료화 역풍 (회화·영어 유료에 기존생 반발)
     grandfathering — 기존생 무료 유지, 신규 코호트부터 적용

 9-3. 킬 스위치 — 멈춤 규칙을 숫자로 미리 박는다

  1) 월 이탈률 8% 2개월 연속 -> 마케팅 증액 금지, 리텐션
     수술 우선. 밑 빠진 독에 예산을 붓지 않는다
  2) 첫 90일 전환율 20% 미만 실측 -> 가격 플랜B 발동
  3) 사회보험·부담금 서면 확인 실패 -> 번 4,307 기준으로
     전 재무 재산정 후 개원 (개원 중단 사유는 아님)
  4) 2호점 게이트 미충족 -> 검토 자체 금지
  5) 온라인 게이트 미충족 -> 투자 0
  6) 위성 확장: 개원 1단계는 코어 전 슬롯 + 위성 2종
     (댄스·회화)만 개방 — 등록 데이터 확인 후 확장

 9-4. 계측 인프라 — 장님 비행 방지는 코드로 존재한다

  킬 스위치는 지표가 실시간으로 보일 때만 작동한다. SYNK는
  이탈률·전환율 자동 계측 파이프라인(v9.26)을 이미 구축
  완료했다. 파일럿 실측과 주간 대시보드 5지표는 수기가
  아니라 자동 산출이다. 계획이 틀렸을 때 가장 먼저 아는
  사람이 우리 자신이라는 것 — 이것이 이 리스크 레지스터의
  마지막 방어선이다.

 10. 실행 로드맵 — 검증 게이트식
================================================================

 각 단계의 진입 조건은 의지가 아니라 숫자다.

 Gate 0 — 개원 전 (2026.7~2027.1)
  [ ] 사회보험·외국인 고용부담금 해결 경로 서면 확인 (최우선)
  [ ] 인허가 형태 확정(VAT 면세·법인세 특례 + 외국인 고용
      허가 주체 적격성을 한 번에 설계)
  [ ] 노동허가 리드타임 역산(재헌, 처리 15~30영업일·1년 갱신)
  [ ] 임대 계약(약 200제곱미터·3실, 겸용 3전제: 가구·거울·
      방음) + CAPEX·보증금 합계 X 확정 -> 러너웨이 정밀 산출
  [ ] 마케팅 활주로 가동(채널 세팅 + 콘텐츠 57편 배포 개시)
  [ ] 2026.12 2주 무료 파일럿 — 전환율·CAC 실측
  [ ] setupSchedule 1회 실행으로 16반 시간표 라이브 반영
  [ ] 파트타임 2인(보컬·뷰티) 채용 — 시급 후대 + 콘텐츠
      출연 + 정규 전환 트랙 제시

 Gate 1 — 1년차 (2027.2~2028.2): 생존과 실측
  진입: Gate 0 전 항목 완료
  목표: 전환율 25% 사수 / M7~9(2027.9~11) BEP 85~94명 통과 /
  6개월권 선수취 성공 / 재등록률 70%+ / 이탈률 5% 이하 /
  첫 겨울 버퍼 소진 3,000만₮ 이내
  유학: 협약 3~5개 + 사례 3건 + 송출 8~15명

 Gate 2 — 2년차 (2028.2~2029.2): 만석과 첫 확장 검토
  진입: 전환율 실측 확인 + 첫 겨울 통과 + 재등록률 70%+

  유학: 25~40명 / 온라인: 게이트 판정

 Gate 3 — 3년차: 복제 가능성의 증명
  2호점 게이트 3조건 판정(7-3) / 유학 50~90명 / 교재

 Gate 4 — 4년차: 그룹 구조 완성
  그룹 월 매출 1.5~2억₮, 마진 20~30% / 유학 100~180명 /

 11. 왜 SYNK인가 — 계획서의 절반은 이미 실물이다
================================================================

 투자자가 사업계획서에서 가장 의심해야 할 것은 "할 것입니다"
 라는 서술어다. 아래 목록의 서술어는 전부 "있다"이다.

 운영 중인 학원
  - 울란바토르에서 한국어 학원을 이미 운영 중, 재학생
    [■ 기입]명의 실데이터가 엔진·앱에 흐른다
  - 신규 전원이 61문항 상담을 거쳐 목적·유학 의향·소비
    성향이 DB화 — 이 계획서의 단가 감각과 수요 신호는
    추정이 아니라 운영 데이터에서 출발했다

 자동화 엔진 v9.46 — 가동 중
  - 상담 자동 수집 / 매일 백업·동기화·아침 브리핑 / 포인트·
    게이지 재계산 / 미납·재등록·헬스체크 / 월간 아카이브
  - 이탈률·전환율 자동 계측(v9.26) — 킬 스위치가 작동하는 이유
  - 확정 시간표 16반이 코드 정본(setupSchedule)으로 존재 —
    재해 복구 시 시간표가 코드에서 되살아난다. 주말반(토)
    요일 로직 보정 완료(v9.46)
  - 매일 새벽 3시, 원장이 자는 동안 시스템이 전체 백업을
    뜬다. 이 회사에서 가장 부지런한 직원은 사람이 아니다

 학생 앱 — 운영 중
  - 몬스터 진화 7단계·왕관·스트릭·포인트·반 레이드·월간
    리포트카드. "게임화 리텐션"이 기획서 단어가 아니라
    학생 손안의 화면이다

 브랜드·콘텐츠·문서 자산 — 완비
  - 조직 계보 정본(3브랜드 2레이어) + 소개서 8종 + 기업 철학
  - 리드크루 라이브러리 57편 기제작 — 개원 첫날부터 콘텐츠
    공장이 재고를 갖고 시작한다
  - 자체 교재 IP '시냅스 톡' 시리즈 — 개발 예정이 아니라
    보유·사용 중
  - 커리큘럼 정본(6레벨)·강사 교수법 매뉴얼·평가 루브릭

 확정된 운영 설계
  - 공간 200제곱미터·3실 / 시간표 16반 220석 / 강사 8인
    편제 / 가격 2티어 + 주말반 — 전부 이 문서 이전에 결정
    문서로 존재한다

 남은 것은 세 가지다
  1) 법정 비용(사회보험·부담금) 해결 경로의 서면 확인
  2) CAPEX·보증금 합계(X) 확정 -> 러너웨이 정밀 산출
  3) 전환율 25%의 파일럿 실측
  시스템·브랜드·콘텐츠·조직·시간표는 준비가 끝났다.
  계획의 나머지는 확인과 데이터가 채운다 — 그리고 그
  확인 전에는 확정 선언을 하지 않는 것이 이 문서의 원칙이다.
