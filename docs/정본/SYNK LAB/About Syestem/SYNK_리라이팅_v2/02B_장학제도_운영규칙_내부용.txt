# SYNK LAB 장학 제도 운영 규칙

내부 전용. 크루·리드크루가 장학금을 공정하고 지속가능하게 운영하기 위한 기준이다. 학생·학부모용 안내문과 별개 문서다. 2026-10-02 [오프라인 운영 기준](../../../../오프라인_공간설계/오프라인_운영기준_20261002.md)을 반영했다. 승인된 장학·TOPIK·과잠·진로 최종본·안심 중지·온라인 성과 지원은 유지하며 실제 기록·담당·재원은 개원 전에 연결한다. Google AI Pro 계정 제공은 기본 복지에서 제외한다.

## §1. 기본 원칙

**1. 출발점이 아니라 성장을 본다.**
성적의 절대 수준보다 어제보다 나아진 정도, 학습 태도를 우선한다.

**2. 누구나 장학생이 될 수 있다.**
특정 학생에게 몰아주지 않는다. 되도록 여러 학생에게 기회가 가도록 운영한다.

**3. 지속가능성을 지킨다.**
정해진 인원·예산을 넘기지 않는다. 한번 정한 혜택은 함부로 늘리지도, 줄이지도 않는다.

## §2. 규모 — 이 문서가 쥔 값

혜택 금액·주기의 정본은 **02 학생 복지 프로그램** 「현재 정리된 학생 복지안」과 해당 상세 설명이다. 어긋나면 02가 이긴다. 02가 바뀌면 §5 예산표와 해당 운영 기준을 함께 갱신한다.

성장 인정상은 2026-09-29 사용자 선택에 따라 각 반에서 매월 1명을 선정한다. 기존 학원 전체 월 3명 상한은 적용하지 않는다. 교통비 세이브 장학의 인원 상한은 기존 내부 기준을 유지한다.

**① 성장 인정 = 각 반 월 1명 · ③ 교통비 세이브 = 월 3명**

- ①③은 CU카드(문화상품권)로 지급한다. 현금이 아니라 상품권이다. 금액은 02가 정본이다.
- 성장 인정 장학금과 기념 선물은 별개다. 장학금과 별도로, 성장 인정 수여자에게 SYNK가 직접 만든 기념 선물 1점을 함께 지급한다. 선물 원가는 장학 예산이 아니라 굿즈 생산 예산에서 관리한다(§5).
- TOPIK 응시료 금액은 현지 기준 확인 후 확정한다(크루·접수처 문의).

## §3. 공통 운영 규칙

### 3-1. 자격 조건

- 등록 첫 달은 대상에서 제외한다. 둘째 달부터 장학금 대상.
- 첫 달은 적응 기간이다. 실제 성장과 태도를 평가할 시간을 확보하기 위한 규칙이다.

### 3-2. 중복 수혜 금지

- 한 학생은 같은 달에 하나의 장학금만 받을 수 있다. 예: 성장 인정 수여자는 같은 달 교통비 세이브 대상에서 제외.
- 예외는 ④ TOPIK 성취 보상 하나다. 시험 성취에 대한 별도 보상이므로 다른 장학금과 중복 수혜가 된다.
- 6개월 이상 수강자의 TOPIK 응시료 지원은 장학 4종과 별도 복지다. ④와 같은 시험의 응시료를 중복 지급하지 않는다.

### 3-3. 선정·지급 기록 (의무)

- 모든 수여 내역은 장학 내역 관리표에 기록한다.
  - 관리표 실위치와 접근 권한 = 🔴 **개원 전 운영 담당이 확정** (§8). 과거 시트나 삭제된 학원 운영 코드가 기록을 자동 보장하지 않는다
- 기록 항목: 수여일 / 대상 / 종류 / 금액 / 사유 / 담당 리드크루.
- 누가 왜 받았는지 근거를 남긴다. 공정성 문의는 언젠가 반드시 온다 — **기록이 답변이다.**

### 3-4. 지급 시점과 방법

| 종류 | 언제 · 어떻게 |
|---|---|
| ①③ CU카드 | 선정 월의 마지막 수업일에 대면 전달 |
| ② 분기 최우수 장학 | 할인 적용 기간과 선결제 학생 정산 방식 확정 전 |
| ④ TOPIK 환급 | 공식 성적 확인 후 14일 이내, 등록된 보호자 계좌로 |

전달자는 담당 리드크루이며, 전달 즉시 관리표에 기록한다.

### 3-5. 이의 제기

- 선정 결과에 이의가 있으면 발표일로부터 7일 이내에 원장에게 제기한다.
- 원장은 관리표의 기록(§3-3)으로 답변한다. **기록에 없는 사유는 답변 근거가 되지 않는다.**
- 재심 결과는 서면으로 통보하며, 그것으로 종결한다.

### 3-6. 중도 퇴소 시 처리

- 이미 지급된 CU카드·응시료 환급은 회수하지 않는다.
- ② 분기 최우수 장학의 할인 적용·선결제 정산·중도 퇴소 시 처리는 시행 전에 정한다. 기존 다음 달 프리패스의 소멸·차감 규칙을 새 혜택에 자동 적용하지 않는다.
- 환불 계산 초안은 `docs/수강약관_초안_v1.md`에 있다. 현재 공개 가격·기간권, 몽골 법정 반환 기준과 몽골어 감수를 확인한 현행 계약판을 시행 전에 확정한다. 장학 할인·선납 정산·퇴소 처리를 그 계약판과 맞추며 이 문서에서 새 공제·회수 예외를 만들지 않는다.

## §4. 종류별 선정 기준

### ① 성장 인정 장학금 (핵심 제도)

| 칸 | 값 |
|---|---|
| 필수 조건 | 출석률 90% 이상 / 등록 후 1개월 초과(첫 달 제외) |
| 핵심 평가 | 개인의 이전 기록에 비춘 성장과 학습 과정 — 시도·피드백 반영·수업 참여·노력 |
| 선정 방식 | 담당 리드크루가 각 반에서 매월 1명 선정. 반 평가 절대 점수 1등 기준은 사용하지 않는다 |
| 측정 원천 | 출석률 = 담당자가 확인한 현행 출결 기록 / 성장·태도 = 담당 리드크루 추천 기록 (사유는 관리표 §3-3에 남긴다) |

성적이 낮아도 진심으로 노력하고 성장한 학생이면 대상이 된다. **이것이 이 제도의 존재 이유다.**

### ② 분기 최우수 장학금

| 칸 | 값 |
|---|---|
| 필수 조건 | 해당 분기 공식 모의평가 응시. 기존 출석·첫 달 제한 적용 여부는 시행 전에 확정 |
| 선정 방식 | 분기별 모의평가 학원 전체 1등 1명. 수준별 시험 비교·동점 처리 방식은 시행 전에 확정 |
| 혜택 | 수강료 100% 할인. 적용 기간과 선결제 정산 방식 미정 |
| 측정 원천 | 해당 분기 모의평가 공식 점수. 점수 기록 위치와 비교 기준 미정 |

기존 두 시즌(16주) 회고 기반 프리패스 선정은 이번 분기 모의평가 기준으로 대체한다. 시즌 회고 자체의 기록·학습 기능은 별도 설계에 따른다.

### ③ 교통비 세이브 장학금

| 칸 | 값 |
|---|---|
| 필수 조건 | 출석률 90% 이상 / 첫 달 제외 |
| 선정 지표 | 직전 월말 평가 점수 |
| 선정 방식 | 반별 월말 평가 상위 20% 중에서, 통학 거리가 먼 순으로 3명. 거리는 등록 시 기입한 거주지 기준. (성장 인정 수여자와 중복되지 않게) |
| 판정 불가 시 | 동점이면 출석률이 높은 학생을 우선한다 |
| 측정 원천 | 출석률 = 담당자가 확인한 현행 출결 기록 / 월말 평가 점수 = 🔴 **미정** (§8) / 거리 = 등록 시 기입 거주지 |

### ④ TOPIK 성취 보상

| 칸 | 값 |
|---|---|
| 대상 | SYNK LAB 정규반 수강 후 목표한 TOPIK 급수를 공식 취득한 학생 전원 |
| 혜택 | 응시료 100% 환급 |
| 목표 급수 기준 | 등록 시 상담 기록(TOPIK 목표·목표기한) 기준 — 사후 분쟁 방지 |
| 지급 시점 | 공식 성적 확인 후 지급 |
| 측정 원천 | 급수 취득 = 공식 성적표 확인 / 목표 급수 = 등록 시 상담 기록 |

### 추가 복지 — 2026-09-27~29 사용자 선택

- **TOPIK 응시료 지원:** SYNK LAB 수강기간이 6개월 이상인 학생에게, 조건 충족 후 응시하는 공식 TOPIK 시험 1회의 응시료를 전액 지원한다. 목표 급수 취득은 조건이 아니다. 동일 시험에 ④ TOPIK 성취 보상은 중복 지급하지 않는다. 수강기간 합산·접수증빙·지급 시점·현지 응시료 단가는 시행 전에 확정한다.
- **한국 유학·진로 준비권:** 1년 정규 과정 학생에게 연 1회, 본인의 목표에 맞춘 자기소개서·포트폴리오·면접 준비 자료를 1:1로 검토하고 학생이 직접 만든 내용을 함께 다듬은 최종본을 제공한다. 담당자·예약 방식·검토 시간·최종본의 형식은 시행 전에 정한다. 입학·취업 결과를 보장하지 않는다.
- **안심 수강 일시정지:** 질병·가족 사정 등으로 수강이 어려울 때 연1회, 최대2주 일시정지를 제공하고 실제 중지한 기간만큼 수강기간을 연장한다. 신청·연간 횟수 기준·재개 시 반 배정·중지 기간의 출결 및 앱 권한 처리는 시행 전에 정한다. 중도 해지·환불은 현행 수강 계약을 따른다.
- **성과 지원:** 열두 달 과정을 마친 성실 참여자가 첫 TOPIK에서4급 미달일 때 앱 계정·숙제를 포함한 온라인 학습6개월 무료 연장. 한국에 간 뒤에도 같은 조건이며 무기한/오프라인 연장이 아니다. FAQ Q10의 승인된 대상·시험 시점·수단·기간을 유지하고 담당 업무·계정 기간·원가를 산정한다.

## §5. 예산 관리

**매월 CU 카드 지출** — 성장 인정상은 운영 반 수에 따라 계산한다(금액 정본 = 02 · §2).

| 항목 | 계산 | 월 |
|---|---|---|
| 성장 인정 | 50,000₮ × 운영 반 수(각 반 1명) | 50,000₮ × 운영 반 수 |
| 교통비 세이브 | 50,000₮ × 3명 | 150,000₮ |
| **월 합계** | | **50,000₮ × 운영 반 수 + 150,000₮** |

24반 과거 모델에 대입하면 CU 카드만 월1,350,000₮다. 과거 급여 손익모델의 장학·복지1,280,000₮를 이미70,000₮ 넘으므로 현재 운영 반 수와 약속한 혜택으로 재산정한다. 실제 반 수와 비용은 아직 미확정이다.

위 지출은 CU 카드만 집계한 것이다. 성장 인정 수여자에게 별도로 주는 기념 선물은 월 운영 반 수만큼 자체 제작 굿즈(비품 CAT5)에서 충당하며, 원가는 굿즈 생산 예산에 포함해 별도로 관리한다.

**비정기 지출**

| 항목 | 주기 | 예산 |
|---|---|---|
| 분기 최우수 장학 | 분기별 모의평가 전체 1등 1명 | 할인 적용 기간·실제 수강료·선결제 정산 방식 확정 후 산정. 기존 월 환산 예산은 사용하지 않음 |
| TOPIK 환급 | 시험 시즌 취득자 수에 따라 변동 | 상한 없음 (아래 ⚠) |
| 6개월 이상 수강자 TOPIK 응시료 지원 | 대상자의 조건 충족 뒤 공식 시험 1회 | 현지 응시료·대상 인원 확인 후 산정. 동일 시험의 성취 보상과 중복 없음 |
| 한국 유학·진로 준비권 | 1년 정규 과정 학생 연 1회 | 개별 검토에 필요한 담당자 시간 산정 전 |
| 안심 수강 일시정지 | 연1회·최대2주 | 연장 수업·반 배정 비용과 앱 이용기간 처리 산정 전 |
| 6개월 온라인 성과 지원 | 열두 달 과정 뒤 첫 TOPIK4급 미달인 성실 참여자 | 승인 기준 유지. 앱 계정·숙제/교정·담당 업무와 실제 대상자 수로 산정 전 |
| 12개월 과잠 | 승인된 수강 자격 | 장학 CU 카드와 분리해 제작·재고·운송/세금·코호트별 지급 시점 산정 |
| 포인트 굿즈/보상 | 개원 공통 기본 혜택에서 제외. 향후 별도 운영 검토 | 적립/교환·예산·재고/품절·권한·담당·오류 복구를 검증한 경우만 별도 대상/기간/규칙과 비용 산정 |

- 분기 최우수 장학의 할인 적용 기간을 먼저 정하고, 해당 학생의 실제 수강료와 선결제 정산 기준으로 예산을 계산한다. 평일·주말반이나 납부 방식에 따른 기존 추정 금액을 확정 혜택 금액으로 사용하지 않는다.
- ⚠ TOPIK 성취 환급과 6개월 이상 수강자의 응시료 지원은 대상 인원·응시료 단가에 따라 비용이 달라진다. 같은 시험에는 한 번만 지급한다. 응시료 단가가 확정되면 분기 예산 상한을 정한다. 그 전까지는 매 시험 시즌 전에 원장이 예상 인원 × 단가를 계산해 승인한다.

| 비율 | 판정 |
|---|---|
| 2% 이하 | 건전. 그대로 운영한다 |
| 2% 초과 ~ 3% 이하 | 주의. 다음 달 인원을 늘리지 않는다 |
| 3% 초과 | 재조정. §6 재검토 트리거 발동 |

학생 수가 크게 늘면 이 비율을 기준으로 인원을 재검토한다.

## §6. 재검토 트리거

아래 상황 중 하나라도 발생하면 인원·기준을 재조정한다.

| 트리거 | 무엇 |
|---|---|
| 재원생 급변 | 재원생 수가 크게 변동할 때 (예: 2배 증가) |
| 수요 쏠림 | 특정 장학금에 신청·기대가 몰릴 때 |
| 예산 초과 | 장학 지출이 매출의 3%를 넘어설 때 |

혜택 축소는 §1의 지속가능성 원칙에 따른 최후 수단으로만 쓴다. **축소하는 경우에도 이미 선정·통지된 수혜에는 소급 적용하지 않는다**(§3-6과 같은 원칙).

## §7. 대외 커뮤니케이션 원칙

- 학생·학부모용 안내문에는 혜택 중심으로 전달한다.
- 월간 성장 인정상의 「각 반 월 1명」은 학생 복지 안내에 표시한다. 기존 별도 장학의 내부 인원 상한과 상세 심사 기록은 공개하지 않는다.
- 이 문서의 수치·기준은 내부 전용이다.

## §8. 실행 점검 — 지금 굴릴 수 있나

원천이 없으면 규칙은 글자다. 빨간 칸이 남아 있는 동안 그 제도는 매월 선정 자체가 불가능하다.

| 자리 | 필요한 원천 | 상태 |
|---|---|---|
| ① 성장 인정 | 현행 출결/리드크루 추천 기록 | 🔴 담당·기록 위치·권한 연결 확인 전 |
| ② 분기 최우수 장학 | 공식 모의평가 점수 / 비교·동점 기준 / 할인 적용·정산 방식 | 🔴 운영 기준·점수 기록 위치 미정 |
| ③ 교통비 세이브 | 현행 출결 / 월말 평가 점수 / 등록 시 거주지 | 🔴 담당·평가 기록 위치·거리 산정과 접근 범위 미정 |
| ④ TOPIK 성취 보상 | 공식 성적표 / 등록 시 목표 상담 기록 | 🔴 실제 증빙 확인·기록·지급 담당 연결 전 |
| 6개월 이상 수강자 TOPIK 응시료 지원 | 누적 수강기간 / 공식 시험 접수·응시료 증빙 | 🔴 기간 합산·증빙·지급 방식 미정 |
| 한국 유학·진로 준비권 | 1년 정규 과정 등록·수강 기록 / 개별 검토 예약 | 🔴 담당자·예약 방식·검토 시간 미정 |
| 안심 수강 일시정지 | 신청·횟수 기록 / 중지·재개일 / 수강 종료일 | 🔴 신청·기간 계산·재개·출결·앱 권한 방식 미정 |
| 전 제도 공통 | 장학 내역 관리표와 접근 권한 | 🔴 현행 기록 위치·담당 미확정. 선정·지급·이의 답변이 같은 근거를 참조해야 함 |
| 6개월 온라인 성과 지원 | 과정 수료·첫 TOPIK·성실 참여/결과·지원 시작/종료·앱 권한 | 🔴 승인 기준은 유지. 실제 증빙·담당·기간 처리를 연결해야 함 |

기록 위치만 적는 것으로 실행 확인이 끝나지 않는다. 담당·접근 권한·실제 원천 기록·지급/정산과 이의 답변을 시험하고 공개 혜택과 같은 기준인지 대조한다.
