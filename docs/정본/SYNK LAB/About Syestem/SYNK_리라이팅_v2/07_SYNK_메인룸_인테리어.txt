# SYNK 메인 룸 인테리어 설계서

한 공간이 수업실이자 무대이자 스튜디오다. 그래서 설계 기준은 처음부터 끝까지 하나다 — **「카메라에 담겼을 때 전문 스튜디오급인가.」**

## 30초 안에 찾으실 것

- **업체에 넘길 것** → 「시공 명세」부터 문서 끝까지. 그 위는 내부용이라 발주서에 넣지 않는다.
- **지어 넣으면 안 되는 칸** → `[실측 후 확정]` · `[현지확인필요]`. 빈칸인 채로 견적을 내지 않는다.
- **아직 못 정한 것** → 네온사인 색. 실물 시안을 보고 정한다(4번 「벽에 굽는 색」).

## 차례

이 방이 해야 할 일(내부용) · 시공 명세 → 1 바닥 · 2 전면 풀월 미러 · 3 조명 · 4 벽 넷 · 5 촬영 장비 · 6 케이블·전원 · 7 음향·공조·전기 부하 · 8 단계별 구축 · 9 몽골 현지 대응 · 시공 전 합의할 다섯

## 이 방이 해야 할 일 — 내부용

**브랜딩 원칙(확정): 메인 룸에 별도 서브브랜드를 만들지 않는다.** 네온사인·로고·해시태그 등 공간에 새기는 모든 브랜드 요소는 SYNK 하나로 통합한다. 그래서 여기서 나갈 수업 영상·챌린지·포트폴리오에 담기는 이름도 하나다.

- **매일** — 100% 한국어로 여는 K컬처 워밍업을 개원과 함께 이 방에서 연다. 몸이 깨어날 때 뇌가 가장 깊이 배운다고 여러 나라의 연구가 보고해 왔다.
- **시즌마다** — 싱크 크루 팀이 공연·영상 프로젝트 하나를 여기서 **기획 → 도전 → 다시 → 완성**으로 끝낼 것이다.
- **항상** — 학생의 성장 순간을 콘텐츠로 남기는 촬영 스튜디오가 될 것이다.

설계 3원칙

1. **안전한 탄성 바닥** — 매일 신체활동이 일어나는 공간이다. 학생의 관절이 1순위.
2. **촬영 우선** — 수업 영상·SNS 콘텐츠·유학 포트폴리오가 전부 여기서 나온다.
3. **모드 전환은 버튼 하나** — 수업 → 촬영 → 무대를 강사 한 명이 바꾼다.

완성하면 이 방 하나가 네 몫을 한다 — 수업실 · 무대 · 촬영 스튜디오 · 온라인 강의실. 상담하러 온 학생이 「한국 아이돌 연습실 같다」고 말하는 순간, 등록 결정은 거기서 난다.

# 시공 명세

여기부터 문서 끝까지가 업체 전달분이다.

**수치 원칙 둘.**

- **범위값을 남기지 않는다.** 「6~8m」로 넘기면 업체는 최저값으로 잡는다. 미확정 수치는 `[실측 후 확정]` 기입란으로 두고, 실측·현지 확인이 끝난 값만 발주서에 올린다.
- **수치를 지어 넣지 않는다.** 실측·현지 확인이 끝난 값만 기입하고, 기입 전에는 발주하지 않는다.

## 1. 바닥

안전과 촬영 품질의 기초다. 아래 4층을 순서대로 시공한다.

| 층 | 하는 일 | 자재 | 조달 |
|---|---|---|---|
| 1층 (기초) | 평탄화 | 기존 콘크리트 수평 작업 | 현지 시공업체 |
| 2층 (완충) | 충격 흡수 | 고무 매트 또는 EVA 폼 | 중국 수입 또는 현지 체육용품점 |
| 3층 (구조) | 탄성 + 안정성 | 12mm 합판 2겹 교차 | 현지 목재상 |
| 4층 (마감) | 슬라이딩 + 촬영 | 무광 PVC 시트 | 한국/중국 댄스 전용 자재 수입 |

- **색** — 다크 그레이 또는 라이트 우드. 촬영 시 인물이 돋보이는 톤.
- **마감** — 반드시 무광(Matte). 유광 바닥은 카메라 앞에서 조명을 되쏘는 순간 촬영본을 망친다.
- **센터라인** — 흰색 테이프로 중앙선 + 포지션 그리드.

## 2. 전면 풀월 미러

| 항목 | 사양 |
|---|---|
| 크기 | 가로 `[실측 후 확정 — 벽 전체 폭]` × 세로 2.4m. 이음새 최소화 |
| 재질 | 5mm 강화유리 + 비산방지 필름 — 겨울 온도차 대응 |
| 설치 | 바닥에서 15cm 띄움 — 충돌 안전 + 청소 편의 |
| 추가 처리 | 김서림 방지 코팅 — 격렬한 운동 중 시야 확보 |

울란바토르 유리 전문업체를 쓴다. 울란바토르의 겨울은 유리에게도 시험이다 — 겨울철 온도차를 고려한 신축 여유를 반드시 확보한다.

1·2번이 1순위다. 단계 1에서 바닥과 거울부터 놓고, 나머지는 그 위에 올라간다.

## 3. 조명 — 세 모드

세 모드는 완전히 분리한다.

| 모드 | 빛 | 쓰임 |
|---|---|---|
| 연습 | 밝고 균일한 화이트 | 기본 수업 |
| 촬영 | 링라이트 + 소프트 조명 | 콘텐츠 제작 |
| 무대 | RGB 컬러 + 무빙라이트 | 퍼포먼스 |

| 장비 | 수량 | 자리 · 메모 | 조달 |
|---|---|---|---|
| LED 평판등 | `[실측 후 확정 — 천장 면적 기준]` | 천장 균일 배치. 그림자 없는 기본 조명 | 현지 전기상 |
| RGB LED 바 | 6개 | 벽면 상하단. 무드 컬러 | 현지 전기상 |
| 무빙헤드 라이트 | `[실측 후 확정 — 천장 모서리 배치 기준]` | 천장 모서리. 무대 모드 전용 — 색과 방향이 움직이는 조명 | 현지 전기상 |
| 링라이트 18인치 | 1개 | 이동식 삼각대. 개인 촬영용 | 현지 주문 |
| 컨트롤러 | 1개 | 벽면 설치. 세 모드를 버튼 하나로 전환(스마트폰 앱 연동) | 현지 주문 |

빛을 잡는 규칙 셋 — 인물은 정면 + 측면 보조 / 배경 벽(거울 반대편)은 다크 톤 마감 / 반사는 바닥 무광 + 벽면 흡음재로 죽인다.

## 4. 벽 넷

| 벽 | 역할 |
|---|---|
| 전면 | 전체 거울(풀월 미러) + 커튼 — 댄스 수업 외 시간에는 거울을 가린다 |
| 좌측 | 브랜딩 월 |
| 우측 | 포토존·촬영 존 |
| 후면 | 메인 촬영 배경 + 네온사인 |

**후면 벽 (메인 촬영 배경)**

- 배경 컬러 — 딥 블랙 또는 다크 그레이. 인물이 돋보이고 깊이가 산다.
- SYNK 네온사인 — 중앙 배치. **색은 아직 정하지 않았다**(아래 「벽에 굽는 색」).
- 질감 — 흡음 패널 또는 템바보드. 음향이 좋아지고 시각적 깊이가 생긴다. 면적은 7-1 흡음재와 함께 확정.

**좌측 벽 (브랜딩 월)**

- SYNK 대형 로고(무광 처리) + 슬로건 또는 비전 문구.
- 포인트 컬러 — **Coral `#F96859`** 한 곳만. 면적 5% 미만.

**우측 벽 (포토존)**

- K문화 테마 배경 또는 그래피티풍 벽화 — **도안은 시공 전에 우리가 지정한다.** 업체 임의 해석 금지.
- 고정 링라이트 설치.
- 해시태그 부착 — 문구는 공식 SNS 계정명 확정 후(예: #SYNK).

**천장** — 블루투스 스피커 마운트. 수량·출력은 7-1에서 확정.

### 벽에 굽는 색 — 시공 전 반드시 확인

벽에 새기면 되돌림 비용이 가장 큰 항목이다.

- **색값의 정본은 `docs/디자인_토큰.json` 하나다.** 이 설계서의 옛 판(v4.1까지)이 들고 있던 오렌지·웜크림과 그 전의 골드·퍼플은 전부 폐기색이라 현행 킷 41색에 없다. 옛 색값이 적힌 인쇄물·견적서가 업체 손에 있으면 회수한다.
- **브랜딩 월 포인트 컬러 = Coral `#F96859`** — 킷의 브랜드 기본색.
- **네온사인 색은 실물 시안을 보고 정한다.** 두 안을 메인 룸 위에 얹어 굽고 눈으로 고른다. 네온 발주는 이 판정 뒤다.
  - ㉠ 코랄 네온 `#F96859` + 크림 `#FBF7F0`
  - ㉡ 코랄 네온 `#F96859` + Ink Deep `#080605` 벽

## 5. 촬영 장비

- 짐벌 + 삼각대
- 링라이트 `[구매 시 확정 — 16 또는 18인치]` · 색온도 5000K 내외 화이트 + 밝기 조절
- 보조 조명 `[실측 후 확정]` — 소형 LED 패널
- 무선 핀마이크

## 6. 케이블·전원

- 천장 케이블 트레이 — 선 정리
- 바닥 케이블 덕트 — 안전 동선 확보
- 전용 분전반 — 용량은 7-3 부하 합산 후 확정. 최소 30A 이상

## 7. 음향 · 공조 · 전기 부하

### 7-1. 음향

| 항목 | 값 | 조건 |
|---|---|---|
| 메인 스피커 | 대수 · 출력 W | `[실측 후 확정 — 룸 면적·천장고 기준]`. 천장 마운트(4번 블루투스 스피커와 통합 검토) |
| 앰프·믹서 | | `[현지확인필요 — 스피커 사양 확정 후]` |
| 흡음재 | ㎡ (후면·측면 벽) | `[실측 후 확정]`. 온라인 강의 녹음 품질을 좌우한다 — 디자인 요소 겸용(합의 4) |

### 7-2. 공조 (에어컨·환기)

| 항목 | 조건 |
|---|---|
| 냉방 용량 | `[현지확인필요 — 실면적·정원·조명 발열 합산 기준으로 업체 산정]` |
| 설치 위치 | 촬영 배경(후면 벽)을 피해서 — 카메라 프레임 밖 |
| 환기 | `[현지확인필요 — 격렬한 신체활동 공간. 환기량 관련 현지 규정 확인]` |
| 소음 | 촬영 모드 중 공조 소음이 녹음에 걸리는지 시운전으로 확인 — 걸리면 촬영 중 정지 절차를 운영 규칙에 넣는다 |

### 7-3. 전기 부하

| 항목 | 조건 |
|---|---|
| 합산 부하 | 조명 + 음향 + 공조 + 촬영 장비 = kW `[현지확인필요]` |
| 분전반 | 합산 부하 확정 후 용량 기입 (6번 — 최소 30A) |
| 회로 분리 | 조명 / 음향 / 공조 별도 회로 `[현지확인필요]` |
| 전력 품질 | 정전·전압 변동 대비 안정화 장치 사양 `[현지확인필요]` |

## 8. 단계별 구축

| 단계 | 시점 | 비중 | 무엇 | 누가 |
|---|---|---|---|---|
| 1 | 오픈 전 필수 | 60% | 바닥 + 거울 + 기본조명 + 음향·공조(7번) | 현지 시공업체 중심 |
| 2 | 오픈 전 권장 | 25% | RGB조명 + 네온사인 + 브랜딩 + 락커 | 현지 시공업체 중심 |
| 3 | 오픈 후 1개월 | 15% | 무빙라이트 + 촬영장비 + 포토존 | 한국 수입 또는 현지 설치 |

## 9. 몽골 현지 대응

| 항목 | 대응 |
|---|---|
| 극한 온도차 | 온도차 대응 자재 선정 — 특히 미러 신축 여유 |
| 먼지 | 출입구 이중문 또는 에어커튼 여부 + 공조 필터 청소 주기 `[현지확인필요 — 구체 사양은 업체 견적으로 확정]` |
| 건조한 기후 | 가습 장비 용량·대수 `[현지확인필요]` — 비품 체크리스트의 가습기(P0) 항목과 연동 |
| 전력 품질 | 7-3 참조 — 안정화 장치 사양 `[현지확인필요]` |

## 시공 전 합의할 다섯

1. 카메라에 찍히는 후면 벽은 다크 톤 + SYNK 네온사인 중앙 배치.
2. 조명은 [수업용 밝은 빛 / 컬러 댄스용 / 무대용] 세 모드 완전 분리.
3. 바닥은 탄성 처리 + 절대 무광 마감. 조명 반사 금지.
4. 온라인 강의용 흡음재를 디자인 요소로 쓴다.
5. `[실측 후 확정]` · `[현지확인필요]` 항목은 견적 전에 실측값·사양을 먼저 채워 회신할 것 — **빈칸인 채로 견적을 내지 않는다.**
