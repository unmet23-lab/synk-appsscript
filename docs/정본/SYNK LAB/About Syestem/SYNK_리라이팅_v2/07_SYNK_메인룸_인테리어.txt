# SYNK LAB 메인 룸 인테리어 설계서

2026-10-02 현행안. [오프라인 운영 기준](../../../../오프라인_공간설계/오프라인_운영기준_20261002.md)·[공간과 촬영 통합 설계](../../../../오프라인_공간설계/평면도_20260929/공간과_촬영_통합설계.md#flex-classroom-20261002)·[방별 마감](../../../../오프라인_공간설계/방별_인테리어_디자인_20260929.md)을 함께 따른다. 기존 v7의 거울/커튼·무광 탄성 바닥·어두운 촬영 배경·Coral 승인 채널LED·분리 조명·현지 조달 방향을 계승한다. 과거20평·원본 바닥 두께/물량·버튼 하나 전환·항상 촬영/매일 문화수업은 현재 시공/운영 약속에서 제외한다.

공간은 미선정이다. 이 문서는 견적 검토 방향이며 시공 CAD·구조/전기 계산·발주 사양·새 전체3D·업체 검증 완료가 아니다. 실제 수업·안전·전환·청소에 맞는 공간을 우선하고 승인 자산의 형태/색을 보존한다.

## 1. 구획과 사용

| 상태 | 후보 | 운영 |
|---|---|---|
| 닫힌 A | 8.4×11m=92.4㎡·약27.95평 | 개인 책상16석 목표. 서측 거울/커튼·이동 화면 정면·독립 문·촬영·공조 |
| 닫힌 B | 4.68×11m=51.48㎡·약15.57평 | 개인 책상16석 목표·북측 화면·독립 문·촬영·공조 |
| 열린 A+B | 13.2×11m=145.2㎡·약43.92평 | 무료 신청25명+강사1명 댄스 회차. 다른 한국어 수업과 음악 시간 분리 |
| 가구 수납 | 외부12~16㎡ 비교 후보 | 책상32·의자32+이동 화면의 실물 보관/회전·운반. 패널포켓은 별도 미확정 |

그림의25개 학생 아이콘·치수는 안전한 활동/피난 정원 증명이 아니다. 안무·팔/대형 전환·장비 돌출·짐·출입·층 전체 재실로 확인한다. 닫힌 강의실4곳을 유지하고 전용 자습실/라운지를 만들지 않는다. 빈 강의실 자습은 담당 가능한 예약 시간만 공개하며 하루 약2~3시간은 예상이다.

## 2. 벽·브랜드

- **서측 전면:** 풀월 안전 거울과 중립 커튼. 거울 폭·높이·체결·모서리 보호·커튼 모임/레일·창/급배기·카메라 반사를 실측한다. 수업 때 커튼으로 가리고 이동 TV/전자칠판을 앞 기준점에 고정한다. 춤 때 화면과 선을 지정 위치로 정리한다.
- **동측 경계:** 가변 칸막이. 중립 무광면·직선 경계를 비교하고 자동 작동/특수 마감은 기본 구매에서 제외한다. 상부 구조 지지·씰/우회 전달·패널 보관/잠금·끼임/정비·바닥 돌출 레일 없는 활동면을 제품/현장으로 검토한다.
- **촬영 배경:** Black 기준 차콜/검정 무광 패널과 승인 SYNK 채널LED. 새 문/패널포켓/창/피난을 피하는 벽 구간을 선정하며 옛 남벽 좌표로 고정하지 않는다. 흡음과 차음은 다르다.
- **나머지 면:** 밝은 중립 도장과 얕은 섬유 패널·소수 교체 작품. 로고/슬로건/해시태그·그래피티와 고정 링라이트를 각 벽에 반복하지 않는다. 포토부스는 별도 작은 공간에서 한다.

메인 룸에 새 서브브랜드를 만들지 않는다. 사인의 승인 범위는 SYNK 워드마크·**Coral #F96859 단색, 아크릴 채널 글자+LED**다. 제작 견본의 꺼짐/점등·실제 카메라 노출을 확인한다. 현지 업체명/전화/공개 목록은 현재 수주·가격·색 맞춤의 증거가 아니며 완성 견적·보증/수리·납기를 확인한 뒤 발주한다.

## 3. 바닥·거울·가구

A+B 전체는 열린 춤 공간과 닫힌 교실에서 쓰는 연속된 무광 탄성 바닥을 검토한다. 색은 밝은~중간 중립 회색 후보, 목재 질감은 책상/수납에 사용한다. 현지 대체재도 충격·접지/미끄럼·청소·바퀴/가구하중·층간 영향의 요구 성능을 확인한다.

기존 콘크리트 평탄화→완충층→합판→PVC 구상은 기술 검토 출발점이다. **12mm 합판2겹·완충재 종류/두께를 그대로 발주 사양으로 쓰지 않는다.** 구조/바닥·활동·층고·문/턱·기둥·칸막이 높이와 방화/자재 적용을 현지 업체가 확인해 전체 단면과 물량을 작성한다.

개인 책상/의자는 실제32세트 제품의 접힘·허용 적층·운반·전도·수납·회전·복귀를 확인한다. 이전A16세트 내부카트 도킹으로 두 방 가구를 보관했다고 하지 않는다. 복도·상담/VR·C/D의 수업 바닥을 창고로 중복 계산하지 않는다. 외투/실내화25명 수요도 검토한다.

## 4. 조명·촬영·음향

| 용도 | 현재 범위 | 실제 인수 |
|---|---|---|
| 수업 기본광 | 밝은 중립 천장·균일한 책상/얼굴광. 약4000K는 샘플 출발점 | 책상/자료 읽힘·눈부심·거울/화면 반사·발열·디밍·피난등 간섭 |
| 교사 촬영광 | 교사 앞/옆 확산 보조광. 약5000K는 시험 출발점 | 실카메라 노출/화이트밸런스·플리커·휴대폰 자료/얼굴 가독성 |
| 코랄 사인/선택 무대광 | 별도 회로. 일반 수업 움직이는 색광 끔 | 사인 점등 견본·스위치·정비. RGB/무빙 기본 패키지 구매 없음 |
| 수업 영상 | A서향·B북향 천장/구조 고정 각1대, C/D 포함총4대 | 브래킷/낙하방지·케이블/패널/공조 간섭·구도·장시간 시험. 중앙 바닥 삼각대 없음 |
| 자료/음성 | 자료·전자판서 직접 캡처+교사 합성, 착용 마이크→수신/PC/OBS | 실제 필기/넘김·영상/음성 지연·예비 경로·4실 채널/송출. TV 재촬영 아님 |
| 음향 | 실제 말소리/댄스·천장/덕트/문 전달을 구분 | 닫힌 A/B 정상 수업 차음, 단독 댄스 이웃 발구름/저음·건물 허용 시험 |

수업 녹화·제한 제공·공개 홍보·라이브는 각각 동의/접근·비노출/반사·업로드 승인·철회/삭제가 필요하다. 항상 학생을 촬영하는 운영은 하지 않는다. 콘텐츠 촬영은 실제 빈 시간과 담당/구도를 따로 예약한다. 학생별 화면 선택은 별도 데이터/플레이어 구현이며 OBS 단일 합성 YouTube 화면만으로 구현됐다고 하지 않는다.

## 5. 공조·환경·전기

- 실제 열린A+B·닫힌A/B 각각의 최대 인원·조명/PC발열·겨울 난방·외기/배기·필터·창/차광·결로·정비를 산정한다. 촬영 품질 때문에 필요한 환기를 계속 끄는 운영은 삭제한다. 저소음 설비·마이크 위치·방진부터 시험한다.
- 각 일반실의 공청/가습은 사용 요청을 유지하되 새 면적·소음·흡배기/분무 이격·급수/세척·건조 시간을 제품으로 확인한다. 공청·가습·향이 환기를 대신하지 않는다.
- 합산 부하·전압/전력 품질·분전/접지·회로/보호·안전 콘센트·정전 복구를 업체가 산정한다. 옛 최소30A를 현장 계산 없이 쓰지 않는다.
- 천장 트레이/벽 경로로 선을 정리하고 활동/출입 바닥을 가로지르는 덕트·케이블을 만들지 않는다. 조명·카메라·스피커·환기·가변 벽 지지/레일·소방이 서로 정비를 막지 않는 종합도를 만든다.

## 6. 전환과 직원 근무

1. 촬영/수업 종료와 학생 퇴실·인계 확인.
2. 실제 지정32세트 수납, TV/케이블 정리, 칸막이 개방/잠금, 거울 커튼 열기.
3. 활동 바닥·문/피난·패널/가구·기기 안전 확인 후 예약25명 입실.
4. 수업 후 학생 인계·가구/패널/TV·각 교실 자료/마이크·공조 복구와 마감.

강사 한 명이 버튼 하나로 가구·패널 이동·학생 감독·촬영을 동시에 바꾼다는 설명은 삭제한다. 실제 제품·직원 수로 준비/복구·감독/대체·휴식·마감을 측정해 시간표와 유급 근무에 넣는다. 매일 모든반 앞뒤 문화 워밍업·공간 무제한 이용·두 기수/학부모 내부 대형 무대는 기본 제공 약속에서 제외한다. 반별 작은 발표·예약 댄스·실제 가능한 촬영은 유지한다.

## 7. 견적과 인수 순서

현지 조달·설치·수리가 가능한 사양을 우선 비교한다. 현지 대체가 어려운 장비는 운송·통관/세금·설치·보증/수리·예비 경로/소모품의 완성 비용과 납기를 비교한다. 새로운 결제/발주를 실행하지 않는다.

먼저 실측/임대 조건·피난/구조/전기·환기/위생·칸막이/바닥·가구/수납을 확정하고, 거울/커튼·기본광·교실 화면/촬영/마이크·필수 사인을 실제 사용으로 인수한다. 선택 무대광·추가 장식/장비는 기본 개원 물량에서 제외한다. 이전60/25/15% 단계별 배분과14주·81평 예산은 새공사 확정값이 아니다.

견적 입력에는 패널+레일+구조/보강+상부 차음/씰+포켓+운송/설치/세금+유지보수,32세트 수납, 거울/커튼·바닥/층간 영향·문/피난·환기/난방·전기/조명·교실 장비를 누락하지 않는다. 실제 담당과 제조사 자료·시험/인수 결과를 연결하며 미확정을0원/빈 완료 칸으로 처리하지 않는다.

색/재료는 [방별 디자인](../../../../오프라인_공간설계/방별_인테리어_디자인_20260929.md), 구매 묶음은 [비품 체크리스트](06_비품_체크리스트.txt), 반수/정원은 [반편성](../../../../반편성_정본_v2.md), 비용/기간은 [개원 예산](../../../../유지비_BM/학원_개원_예산과_준비기간_20261001.md)을 담당 원문으로 둔다.
