# SYNK LAB 장학 제도 운영 규칙 (내부용)

> 용도: 크루·리드크루가 장학금을 공정하고 지속가능하게 운영하기 위한 내부 기준. 학생·학부모용 안내문과는 별개 문서다.

---

## 1. 기본 원칙

| 원칙 | 의미 |
|------|------|
| **출발점이 아니라 성장을 본다** | 성적의 절대 수준보다 어제보다 나아진 정도, 학습 태도를 우선한다. |
| **누구나 장학생이 될 수 있다** | 특정 학생에게 몰아주지 않는다. 되도록 여러 학생에게 기회가 가도록 운영한다. |
| **지속가능성을 지킨다** | 정해진 인원·예산을 넘기지 않는다. 한번 정한 혜택은 함부로 늘리지도, 줄이지도 않는다. |

---

## 2. 장학 4종 — 규모 요약

| 장학금 | 혜택 | 인원 | 주기 |
|--------|------|------|------|
| ① 성장 인정 장학금 | CU카드 50,000₮ | 3명 | 매월 |
| ② 전액 프리패스 장학금 | 다음 달 수강료 100% 면제 | 1명 | 분기별 |
| ③ 교통비 세이브 장학금 | CU카드 50,000₮ | 3명 | 매월 |
| ④ TOPIK 성취 보상 | 응시료 100% 환급 | 취득자 전원 | 시험 시 |

- ①③의 CU카드는 현금성 문화상품권 개념으로 지급한다.
- **성장 인정 장학금과 한정판 굿즈는 별개다.** 장학금(CU카드 50,000₮)과 **별도로**, 성장 인정 수여자에게 SYNK 자체 제작 한정판 굿즈 1점을 함께 지급한다. 굿즈 원가는 장학 예산이 아니라 굿즈 생산 예산에서 관리한다(§5 참고).
- TOPIK 응시료 금액은 현지 기준 확인 후 확정한다 (크루/접수처 문의).

## 3. 공통 운영 규칙

### 3-1. 자격 조건
- 등록 첫 달은 대상에서 제외한다. **둘째 달부터 장학금 대상.**
- 첫 달은 적응 기간이다. 실제 성장과 태도를 평가할 시간을 확보하기 위한 규칙이다.

### 3-2. 중복 수혜 금지
- 한 학생은 같은 달에 **하나의 장학금만** 받을 수 있다.
- 예: 성장 인정 장학금 수여자는 같은 달 교통비 세이브 대상에서 제외.
- **예외: ④ TOPIK 성취 보상.** 시험 성취에 대한 별도 보상이므로 다른 장학금과 중복 수혜 가능.

### 3-3. 선정·지급 기록 (의무)
- 모든 수여 내역은 **장학 내역 관리표**에 기록한다.
- 기록 항목: 수여일 / 대상 / 종류 / 금액 / 사유 / 담당 리드크루.
- 누가 왜 받았는지 근거를 남긴다. 공정성 문의는 언젠가 반드시 온다 — 기록이 답변이다.

## 4. 종류별 선정 기준

### ① 성장 인정 장학금 (핵심 제도)

| 구분 | 기준 |
|------|------|
| 필수 조건 | 출석률 90% 이상 / 등록 후 1개월 초과 (첫 달 제외) |
| 핵심 평가 | **성장** — 어제보다 오늘, 지난달보다 이번 달 나아진 정도 (성장폭 기준) |
| | **태도** — 성실함, 수업 참여도, 노력하는 자세 |
| 선정 방식 | 담당 리드크루가 매월 후보 추천 → 최종 3명 선정 |

> 성적이 낮아도 진심으로 노력하고 성장한 학생이면 대상이 된다. 이것이 이 제도의 존재 이유다.

### ② 전액 프리패스 장학금

| 구분 | 기준 |
|------|------|
| 필수 조건 | 출석률 90% 이상 / 해당 분기 정상 수강 |
| 선정 방식 | 분기별 종합 평가 최우수자 1명 |
| 혜택 | 다음 달 수강료 100% 면제 |

### ③ 교통비 세이브 장학금

| 구분 | 기준 |
|------|------|
| 필수 조건 | 출석률 90% 이상 / 첫 달 제외 |
| 선정 방식 | 정기 평가 상위 학생 중 3명 (성장 인정 수여자와 중복되지 않게) |

### ④ TOPIK 성취 보상

| 구분 | 기준 |
|------|------|
| 대상 | SYNK LAB 정규반 수강 후 목표한 TOPIK 급수를 공식 취득한 학생 전원 |
| 혜택 | 응시료 100% 환급 |
| "목표 급수" 기준 | 등록 시 상담 기록(TOPIK 목표·목표기한)을 기준으로 한다 → 사후 분쟁 방지 |
| 지급 시점 | 공식 성적 확인 후 지급 |

## 5. 예산 관리

### 매월 고정 지출

| 항목 | 계산 | 금액 |
|------|------|------|
| 성장 인정 | 50,000₮ × 3명 | 150,000₮ |
| 교통비 세이브 | 50,000₮ × 3명 | 150,000₮ |
| **월 고정 합계** | | **300,000₮** |

> 위 고정 지출은 **현금성 지급(문화상품권)만** 집계한 것이다. 성장 인정 수여자에게 별도로 주는 **한정판 굿즈(월 3점)**는 자체 제작 굿즈(비품 CAT5)에서 충당하며, 원가는 굿즈 생산 예산에 포함해 별도로 관리한다.

### 비정기 지출

| 항목 | 규모 |
|------|------|
| 전액 프리패스 | 분기 1명 (수강료 1명분, 월 환산 약 12만₮ 내외) |
| TOPIK 환급 | 시험 시즌 취득자 수에 따라 변동 |

**건전성 기준**: 매월 장학 지출이 월 매출의 약 1~2% 수준이면 건전하다. 학생 수가 크게 늘면 이 비율을 기준으로 인원을 재검토한다.

---

## 6. 재검토 트리거

아래 상황 중 하나라도 발생하면 인원·기준을 재조정한다.

| 트리거 | 상황 |
|--------|------|
| 재원생 급변 | 재원생 수가 크게 변동할 때 (예: 2배 증가) |
| 수요 쏠림 | 특정 장학금에 신청·기대가 몰릴 때 |
| 예산 초과 | 장학 지출이 매출의 3%를 넘어설 때 |

**혜택 축소는 신중히.** 한번 준 것을 빼는 일은 주는 일보다 열 배 어렵다.

## 7. 대외 커뮤니케이션 원칙

- 학생·학부모용 안내문에는 매력적인 혜택 중심으로 전달한다.
- **인원수(월 3명 등)와 세부 자격·선정 기준은 대외 문서에 노출하지 않는다.** "매월 선정" / "상담 시 안내"로 표기한다.
- 이 문서의 수치·기준은 내부 전용이다.
