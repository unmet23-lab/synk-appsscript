## 3. 4대 철학 × 시그니처 프로그램 (이름 고정)

1. **목적이 먼저다** (Purpose Before Credentials) → 시그니처: **「나침반」 세션**(입학+시즌마다 목적·로드맵 워크숍) → 산출물: **드림맵 카드**
2. **몸이 깨어날 때, 뇌는 가장 깊이 배운다** → 시그니처: **K-컬처 워밍업**(매일, 100% 한국어 신체활동)
3. **AI가 대체하기 어려운 사람** — 감응력·협응력·공감능력 → 시그니처: **「싱크 크루」 프로젝트**(시즌마다 팀이 기획→도전→다시→완성) → 시즌당 포트폴리오 1건
4. **실질적 결과** (Define→Build→Execute) → 시그니처: **「싱크 포트폴리오」**(드림맵+프로젝트 결과물+TOPIK 급수 누적)

체인: 나침반=Define, 크루=Build, 포트폴리오=Execute. 매일의 워밍업이 엔진.
SYNK 이름의 뜻: 학습과 목적 발견의 **동기화(synchronize)**.

## 4. 세계관 & 실존 시스템 (지어내지 말 것 — 아래는 실제로 구축·운영 중)

- 학생 = **크루**, 운영진 = 크루/리드크루
- 성장 = **몬스터 진화** 7단계: 뉴로→스파키→링커→서킷→미엘로→플로우→싱크마스터
- 노력의 증표 = **왕관**(MVP 왕관·시냅스 왕관), **포인트**, **반 레이드**, **스트릭(연속출석)**, **칭호**, **월간 리포트카드**
- 실제 인프라: Google Form → 상담시트 → **자체 개발 Apps Script 자동화 엔진(v9.x)** → profiles DB → **Glide 학생 앱** + **Notion 크루 DB**(정량+정성 통합 허브)
- 자동화 실제 동작(사실): 10분마다 상담 신청 자동 수집 / 매일 03:00 전체 백업(30일 보관) / 매일 07:00 데이터 동기화+생일·상담지연 체크 / 매일 08:00 원장 아침 브리핑 메일 / 매일 2회 포인트·게이지 재계산 / 매주 월 미납·재등록·시스템 헬스체크+노션 동기화 / 매월 칭호·성장 스냅샷·아카이브 / 데이터 이상 감지 시 동기화 자동 보류+원장 알림 / 동기화 실패 시 원장 즉시 메일
- 학부모 소통: 몽골 현지 특성상 **페이스북 메신저 중심**

## 5. 보이스

- **학생 대상**: 친근한 친구 톤. 에너지. 읽으면 힘이 나야 한다.
- **학부모 대상**: 따뜻하고 정중. 솔직한 현실 인정 → 명확한 해법.
- **내부/파트너 대상**: 단정하고 자신감. 프로페셔널.
- 짧고 리듬감 있게. 이모지는 절제(섹션 포인트만). 뇌과학 은유(시냅스·미엘린·회로)는 양념처럼 — 어렵지 않게.
- 유머: 자기확신형 위트, 몽골 생활 디테일(혹한, 믹스커피, 율무차) 활용 가능. **타 학원 비하 금지**(구조 비교는 OK). 학생을 깎는 유머 절대 금지.

## 6. 🚫 금칙어 정책

- **학생이 읽는 문서**(02 복지 등): `패배·졌다·실패·불운·하락·부족·안 됨·늦었다` → **0개**. 실수·어려움은 반드시 리프레이밍("틀린 문제 = 내일의 필살기").
- **학부모·철학 문서**: "실패"도 쓰지 않는다 — 프로그램 성장 서사는 확정 표기 **「기획→도전→다시→완성」**만 사용(구 표기 '기획→실패→재도전→완성'은 2026-07-10 잠금 결정으로 폐기). 학생·학부모 대면에서는 항상 **'다시'**로 부른다. 그 외 부정어는 회피. (시스템 동작 기술의 '동기화 실패 메일' 같은 내부 기술 용어는 예외.)
- 남과 비교해 기죽이지 않기 → **"어제의 나"** 와만 비교. 모든 학생이 주인공.
