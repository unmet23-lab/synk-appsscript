## 30초 안에 찾으실 것

- 지금 몇 분이고 무엇을 하고 있어야 하나 → **1장 90분 표**
- 인원이 16명이 아닌데 조를 어떻게 짜나 → **4장 실제 출석1~16명 조 구성**
- 결석한 학생에게 뭐라고 보내나 → **6장 연락 템플릿 두 장**

# 1. 90분 표

순서와 시간은 모든 반, 모든 차시가 같습니다.

| 시간 | 블록 | 하는 것 |
|---|---|---|
| 5분 | ① 열기 | 실제 출석 확인 · 오늘 목표 판서 · 지난 차시를 한 문장으로 |
| 20분 | ② 제시 | 오늘의 문법·어휘. 새 어휘 7개 + 새 문법 1개가 상한 |
| 15분 | ③ 통제 연습 | 전체 반복 → 짝 연습. 이 블록 안에 **전원 1회 발화** |
| **30분** | **④ 소그룹 발화** | 의견 준비·대화·조율·이유 설명. 학생별 말할 차례 확인(4장) |
| **10분** | **⑤ 공유** | 조별 발표 최대1분30초씩, 공통 질문·피드백과 다음 표현 정리 |
| 10분 | ⑥ 닫기 | 전원 한 문장 · 숙제 안내 · 다음 차시 예고 |
| 수업 후 별도 | 마감·교대 | 판서 세 줄·진도·발화 확인·특이사항 기록. 퇴실과 다음 반 준비 시간을 실제 측정 |

합계는5+20+15+30+10+10=90분입니다. ④ 그룹 발화30분과⑤ 공유10분은 별도 블록이며, 그룹30분을 학생1인당 발화량으로 계산하지 않습니다.

## 시간이 모자랄 때 — 버리는 순서

1. ③ 통제 연습 후반
2. ② 제시의 예문 수 (예문 2개가 하한)
3. ⑤ 공유의 발표 조 수 (4조 → 2조)

④ 소그룹30분과⑥ 닫기10분은 버리지 않습니다. 조 수가 적어도⑤10분은 발표 뒤 질문·공통 피드백에 씁니다.

정해두지 않으면 사람은 항상 뒤에서부터 자릅니다. 닫기가 사라지면 숙제 안내가 사라지고, 다음 차시 준비율이 무너집니다.

## ① 열기 · 5분

- 실제 입실·결석·지각을 명부에서 확인합니다. 기록 입력 시각과 실제 도착 시각을 구분하며, 필요한 업무 시간은 시범 수업에서 측정합니다.
- 오늘 목표를 교안에 인쇄된 문장 **그대로** 칠판 왼쪽에. 자기 말로 바꾸면 반마다 도달 기준이 달라집니다.
- 학생은 지난 차시 배운 것을 한 문장으로. 교재를 덮고.
- **사전 지식 30초** — 새 주제 전에 "이거 아는 사람?" 하고 아는 단어를 꺼내게 합니다. 빈 머리에 넣는 것보다 있는 것에 붙이는 편이 빠릅니다.

## ② 제시 · 20분

- 몽골어와 **같은 점을 먼저**(어순·조사), 다른 점을 나중에(발음·한자어·화계). 예문은 학생 생활에서.
- **상한은 어휘 7개 + 문법 1개.** 넘치면 다음 차시로 넘기고 마감폼에 「이월」을 찍습니다. 이월 = 못 나간 진도를 다음 차시로 넘겼다는 표시입니다.
- **90초 먼저 틀리기** — 설명 전에, 그 문법이 필요한 문장을 학생이 먼저 만들어 보게 합니다. 90초 뒤 곧바로 정답 형태를. "지금은 틀리는 시간"이라고 매번 말해 줍니다. 그 말이 없으면 아무도 손을 들지 않습니다.
- **몸짓 연동** — 새 어휘 5개 중 2개 이상은 동작을 붙여. 몸짓을 곁들이면 외국어 단어 기억에 도움이 된다는 연구가 보고되어 있습니다(막스플랑크 제스처 연구).
- **한자어는 묶음으로** — Lv3부터 급증합니다. 낱개 대신 어원 묶음으로(생 = 살다 → 생활·학생).
- **시선 목적지는 최대 두 곳** — 교재·화면·판서를 동시에 보게 하지 않습니다. 세 곳이 되는 순간 초급 절반이 쪽수를 찾다가 설명을 놓칩니다. 교재를 펼 때는 쪽수를 칠판 가운데에 큰 숫자로.

## ③ 통제 연습 · 15분

이 블록이 끝나기 전 16명 전원이 최소 1회 발화합니다. 조용한 학생을 먼저, 짧은 문장부터.

- **3초를 센다** — 질문하고 속으로 셋. 바로 답을 주거나 다른 학생을 지명하면 느린 학생은 영영 말하지 못합니다. 신규 강사가 가장 많이 하는 실수입니다.
- **고친 말을 듣고 넘어갑니다** — 요구는 한 번까지. 안 되면 강사가 정답을 말하고 통과시킵니다. 두 번 이상은 반 전체가 그 학생을 보게 만듭니다.
- **성공률 80%** — 10개 중 8개를 맞히는 난이도로. 다 맞히면 지루하고, 절반 이하면 포기합니다. 3개 이상 틀리면 그 자리에서 한 단계 쉽게.
- **난이도 계단** — 조용한 학생은 단어 하나로 답할 것, 보통은 문장으로, 빠른 학생은 "왜?"를 붙여 확장. 한 명도 "나는 못 한다"고 느끼지 않게.
- **확장 3문항은 같은 종이 아래쪽에** — 별도 프린트는 준비 부담 때문에 3주 뒤 사라집니다. 확장은 「더 어려운 것」이 아니라 「같은 문법으로 더 긴 문장」이어야 합니다.

## ⑤ 공유 · 10분

담임이 발표 순번표를 관리합니다. 최대4조의 발표를 각1분30초 이내로 진행하면6분이며 남은4분은 질문·공통 피드백에 씁니다. 8주 동안 학생별 대표 발표 최소2회를 배정하고 실제 수행을 확인합니다. 결석한 차례는 다시 배정하며 앱 자동 편성을 운영 중으로 설명하지 않습니다.

- **발표자는 소그룹 시작할 때 미리 알려줍니다.** 예고 없이 새로 지명하지 않습니다. 예측 가능성이 불안을 낮추는 가장 값싼 방법입니다.
- **두 조 이상에서 나온 오류만** 전체에게 다룹니다. 한 조에서만 나온 오류는 그 조에게 이미 말했으므로 공개적으로 다시 꺼내지 않습니다. 예외는 3주차 「오류 톱10」 — 몇 조에서 나왔든 즉시.
- **시즌 첫 2주는 발표 중 형태 교정 0회.** 내용에만 반응합니다. 조가 8주 고정이라, 시즌 초에 공개 교정이 붙으면 그 회피가 시즌 내내 굳습니다. 놓친 오류는 다음 차시 ③에서.

## ⑥ 닫기 · 10분

- 학생이 오늘 배운 것을 한 문장으로 말하고 나갑니다. 전원.
- 숙제와 다음 차시를 안내하고 앱에서 확인할 내용을 알려 줍니다. 틀린 부분은 무엇을 다시 연습하면 되는지 설명합니다.
- **안 보고 3문장 (주 3회)** — 교재를 덮고 3문장을 앱에 씁니다. 펴 놓고 옮겨 적으면 손만 움직입니다. 매 차시로 늘리면 닫기 10분이 넘칩니다.
- **담임 개별 접점** — 정원16명·주5차시는4·3·3·3·3명으로 나누어 짧은 피드백을 배정합니다. 실제 출석과 완료 기록을 확인하고 결석자는 다음 출석 때 우선 배정합니다. 닫기 안의 한마디와 별도1:1 보충 상담을 구분합니다. 주간 차시 수가 줄면 순환 기간을 다시 계산합니다.

## 수업 후 · 차시 마감과 교대

칠판 왼쪽 위에 반 코드 / 오늘 마지막 지점 / 다음 차시 시작 지점을 남깁니다. 출석·진도·발화 확인·필요한 도움을 기록하고 인계합니다(5장). 마감30초나 교사 행정 전체2분을 보장하지 않습니다. 교대·휴식 시간을 확보한 뒤 실제 방별 시작 시각을 확정합니다.

# 2. 외울 것 일곱 개

이것만 외우고 세부 절차는 주간 교안과 담당자의 수업 기록에서 확인합니다.

**1. ④소그룹30분과⑤공유10분을 구분해서 지킨다.**
학생별 말할 차례를 확인합니다. 교사의 자세를 강제하거나 시간 미준수에 따른 학습 손실을 임의 숫자로 단정하지 않습니다.

**2. 시작 40분이 되면 진도가 남았어도 ④로 넘어간다.**
"조금만 더 하면 끝나는데"가 매 차시 5분씩 밀려 8주차에 두 차시 분량이 사라집니다. 그리고 사라진 그 두 차시가 하필 승급 평가 범위입니다. 남은 것은 다음 차시 ② 앞 5분으로 넘기고 「이월」을 찍습니다. 시즌에 이월이 4회를 넘으면 강사 문제가 아니라 교안이 과적재된 것이고, 원장에게 알려집니다.

**3. 질문하고 3초를 센다.**
느린 학생은 그 3초 안에 문장을 조립합니다.

**4. 한 번에 교정 하나.**
지적이 쌓이면 학생이 입을 닫습니다. 인정도 하나씩 같이. 나머지 오류는 적어 두었다가 ⑤에서.

**5. 몽골어를 제지하지 않는다. 한국어 한 문장으로 바꿔 되돌려주고, 한 번 따라 말하게 한다.**
두 방향 다 잘못됩니다. "한국어로 말하세요"는 그 학생을 그날 내내 침묵시키고, 그냥 두면 소그룹30분이 통째로 몽골어 잡담이 됩니다. **조용해서 잘 굴러가는 것처럼 보이는 것이 함정입니다.** 한 학생당 한 차시 1회까지만. 문법 설명이 3분 넘게 막히면 몽골어 30초를 허용하되 반드시 한국어 예문 하나로 닫습니다.

**6. 비교는 '어제의 자신'과만.**
다른 학생·다른 조와 비교하지 않습니다. 학생 본인의 이전 수행과 현재 수행을 근거로 설명합니다.

**7. 확인한 학습 결과와 필요한 도움을 설명한다.**

어디에서 틀렸는지, 어떤 연습이 필요한지 학생이 이해할 수 있게 설명합니다. 학생을 탓하지 않는다는 이유로 실제 결과를 감추거나 고정 대체 문구로 바꾸지 않습니다. 별도 금칙어·대체어 표는 적용하지 않습니다.

이 일곱 개는 앱이 확인해 주지 않습니다. 측정할 수 없어서 사람에게 남긴 것들입니다.

# 3. 그룹 발화30분의 의미

그룹 활동 안에서 자신의 의견을 준비하고 서로 듣고 조율하며 이유를 설명합니다. 준비·짝 교대·정리도 포함하므로30분을 인원수로 나눈 값이 실제 개인 발화량은 아닙니다. 기존2.8분→7~8분 추정치를 성과나 보장으로 사용하지 않습니다. 첫 시범 수업에서 학생별 차례와 실제 발화를 관찰하고 난이도·역할을 조정합니다.

# 4. 소그룹30분

## 기본 책상과 조 편성

개인책상을 기본으로 유지합니다. 통로·화면 시야·의자 회전이 가능한 가까운 자리끼리 묶습니다. 고정4인 섬4개를 필수 배치로 요구하지 않습니다. 담임이 수준·말수·관계와 실제 출석을 보며 조와 역할을 정하고, 시즌의 기본 조는 가능한 유지하되 결석·전입·안전상 필요하면 조정합니다.

## 30분 배분

| 시간 | 하는 것 |
|---|---|
| 2분 | 각자 의견·낱말 준비와 역할 확인 |
| 6분 | 1라운드 — 서로 묻고 답하기 |
| 6분 | 2라운드 — 짝/역할을 바꿔 다시 설명 |
| 6분 | 3라운드 — 다른 이유·정보를 확인 |
| 6분 | 조별 조율 — 선택과 이유를 서로 설명 |
| 4분 | 산출물 정리·발표 준비 |

합계30분입니다. 상급반은 세 라운드의 내용을 깊게 조정할 수 있으나 준비·대화·조율·이유 설명과 전체30분은 유지합니다. 개인별 연속 발화30분을 뜻하지 않습니다.

## 실제 출석1~16명 조 구성

| 출석 | 조 구성 |
|---|---|
| 16 | 4·4·4·4 |
| 15 | 4·4·4·3 |
| 14 | 4·4·3·3 |
| 13 | 4·3·3·3 |
| 12 | 4·4·4 |
| 11 | 4·4·3 |
| 10 | 4·3·3 |
| 9 | 3·3·3 |
| 8 | 4·4 |
| 7 | 4·3 |
| 6 | 3·3 |
| 5 | 3·2 |
| 4 | 4 |
| 3 | 3 |
| 2 | 2 |
| 1 | 교사와 짝 활동; 학생 조는1명 |

모든 학생을 한 번씩 배정하고 학생 조는4명을 넘기지 않습니다. 결석으로2인 조가 생겨도 옆4인 조에 붙여6명으로 만들지 않습니다. 실제 출석으로 표를 다시 적용하고 변경을 남깁니다. 소수 인원이 지속되는 반은 반 통합·시간표 조정을 상담하되 자동 통합하거나 수업을 일방 취소하지 않습니다.

- 4인: 진행·기록·발표·질문을 차시별 순환합니다. 짝은1R A-B/C-D,2R A-C/B-D,3R A-D/B-C로 돌립니다.

# 9. 교실과 앱이 같은 낱말을 씁니다

아래는 학습 앱의 설계 방향입니다. 현재 화면·실제 학생 계정·기록 연결을 검증한 기능만 안내하며 개원 필수 기록을 대신하는 자동화 완료로 읽지 않습니다.

학생이 앱에서 보는 것과 강사가 교실에서 부르는 이름이 다르면, 학생은 그 둘을 다른 제도로 여깁니다.

| 앱에 있는 것 | 교실에서 |
|---|---|
