▣ T-01  인물 카드 채우기
   유형: 정보 차 · 준비: 인물 카드 4장 (제작 필요) · 산출: 정보표 1장
   배분: 계획 1분 → 4/3/2 짝을 바꿔 묻고 받아적기 → 정리: 표 완성

   왜 말하게 되나
     자기 카드는 남이 못 봅니다. 물어봐야만 알 수 있습니다.

   진행
     1. 각자 다른 인물 카드 1장을 받습니다 (남에게 안 보임)
     2. 진행자가 질문 순서를 정합니다
     3. 돌아가며 묻고, 기록자가 빈 표를 채웁니다
     4. 발표자가 완성된 표를 읽습니다

   Lv1  -이에요/예요 · 어디 · 몇 살
        → 인물 4명의 이름 · 나라 · 나이 · 직업
   Lv2  -에서 왔어요 · -고 있어요 · -(으)ㄹ 거예요
        → 인물 4명의 출신 · 현재 하는 일 · 계획


▣ T-02  그림 설명하기
   유형: 정보 차 · 준비: 그림 1장 (제작 필요) · 산출: 그린 그림 3장
   배분: 계획 1분 → 1R 설명 4분 → 2R·3R 설명자 교대 + 질문으로 좁히기
        → 정리: 그림 대조

   왜 말하게 되나
     한 명만 그림을 보고, 나머지는 말만 듣고 그립니다.
     설명이 부정확하면 그림이 달라집니다.

   진행
     1. 설명자만 그림을 봅니다 (나머지는 백지)
     2. 설명자가 말로 설명합니다 (손짓 금지)
     3. 나머지 셋이 듣고 그립니다. 질문은 의무 — 1인 1회 이상
     4. 2R·3R에서 설명자를 바꿉니다. 백지 3장은 자리에 그대로 두고
        사람만 옮깁니다. 새 설명자는 원본을 보고 「아직 안 맞은
        부분」만 설명합니다
     5. 그린 그림 3장과 원본을 비교하고 어디서 어긋났는지 찾습니다

   ※ 세 판이라 네 명 중 셋만 설명자를 합니다. 못 한 학생이
     다음 차시 T-02의 1R 설명자입니다 (T-20과 같은 규칙 —
     기록자가 교안 회고에 이름 하나만 적어 둡니다).

   Lv1  위·아래·옆 · 있어요/없어요 · 색깔
        → 방 안 물건 배치 그림
   Lv2  -고 있어요 · -(으)ㄴ · 개/명/마리
        → 사람들이 무언가를 하고 있는 장면


▣ T-03  다른 점 찾기
   유형: 정보 차 · 준비: 비슷한 그림 2종 × 2장 (제작 필요) · 산출: 차이 목록
   배분: 계획 1분 → 4/3/2 짝 대조 (라운드마다 상대 교대) → 정리: 차이 5개 확정

   왜 말하게 되나
     그림을 서로 보여주면 안 되니 말로 대조해야 합니다.

   진행
     1. 두 명씩 짝을 지어 A그림 / B그림을 받습니다
     2. 서로 안 보여주고 말로 비교합니다
     3. 다른 점 5개를 찾아 기록자가 적습니다
     4. 그림을 펼쳐 확인합니다

   Lv1  있어요/없어요 · 색깔 · 숫자
        → 물건 배치가 조금 다른 방 그림
   Lv2  -는데 · 반면에(도입) · 더/덜
        → 두 사람의 하루 일과 그림


▣ T-04  일정 맞추기
   유형: 정보 차 · 준비: 일정표 4장 (제작 필요) · 산출: 모두 가능한 시간
   배분: 계획 1분 → 4/3/2 짝을 바꿔 일정 묻기 → 정리: 모두 되는 시간 확정

   왜 말하게 되나
     넷의 일정이 다 다르니 맞추려면 서로 물어야 합니다.

   진행
     1. 각자 다른 일주일 일정표를 받습니다
     2. "언제 시간 있어요?"로 서로 묻습니다
     3. 네 명 모두 되는 시간을 찾습니다
     4. 발표자가 "우리는 ___에 만나요"라고 발표합니다

   Lv1  시간 표현 · 요일 · 있어요/없어요
        → 같이 밥 먹을 시간 정하기
   Lv2  -(으)ㄹ 수 있어요 · -기 전에/후에 · -(으)면
        → 같이 여행 갈 날짜 정하기


▣ T-05  길 안내하기
   유형: 정보 차 · 준비: 지도 2종 (제작 필요) · 산출: 표시된 지도
   배분: 계획 1분 → 1R 안내 4분 → 2R 역할 교대 3분 → 3R 확인 2분 → 정리: 지도 대조

   왜 말하게 되나
     목적지를 아는 사람이 모르는 사람을 말로 데려가야 합니다.

   진행
     1. 두 명은 목적지 표시된 지도, 두 명은 빈 지도
     2. 아는 쪽이 길을 설명합니다
     3. 모르는 쪽이 지도에 경로를 그립니다
     4. 비교하고 역할을 바꿔 한 번 더

   Lv1  -(으)세요 · 오른쪽/왼쪽 · 에서
        → 학원에서 편의점까지
   Lv2  -아서/어서 · -(으)면 · -(으)ㄴ 다음에
        → 울란바토르 시내 관광지까지

▣ T-06  순위 정하기
   유형: 합의 · 준비: 항목 카드 5장 (제작 필요) · 산출: 순위표 + 이유
   배분: 계획 1분 → 4/3/2 짝 토론으로 이유 교환 → 정리: 조 합의 순위

   왜 말하게 되나
     합의가 목적이라 반드시 이유를 말해야 설득됩니다.

   진행
     1. 다섯 개 항목을 놓습니다 (음식·도시·직업 등)
     2. 각자 자기 1위를 말하고 이유를 붙입니다
     3. 조가 합의해 1~5위를 정합니다
     4. 발표자가 순위와 이유를 발표합니다

   Lv1  좋아해요 · 제일 · 왜냐하면(도입)
        → 좋아하는 한국 음식 5개 순위
   Lv2  -아서/어서 · -(으)니까 · -는 게 좋아요
        → 살고 싶은 도시 5개 순위
   Lv3  -(으)ㄹ수록 · -기는 하지만 · 반면에
        → 한국 유학 준비에서 중요한 것 5개 순위


▣ T-07  하나만 고르기
   유형: 합의 · 준비: 상황 카드 (제작 필요) · 산출: 선택 + 근거 3개
   배분: 계획 1분 → 4/3/2 짝을 바꿔 설득 → 정리: 하나로 합의 + 버린 이유

   왜 말하게 되나
     하나만 고를 수 있으니 버리는 이유도 말해야 합니다.

   진행
     1. 상황을 줍니다 ("무인도에 하나만 가져간다면")
     2. 각자 하나를 고르고 이유를 말합니다
     3. 조가 하나로 합의합니다 (버린 이유도 말합니다)
     4. 발표자가 "우리는 ___를 골랐어요. 왜냐하면…"

   Lv1  -고 싶어요 · 필요해요 · 때문에(도입)
        → 무인도에 가져갈 물건 하나
   Lv2  -(으)ㄹ 수 있어요 · -아서/어서 · -(으)면
        → 한 달 동안 하나만 쓸 수 있다면


▣ T-08  예산 나누기
   유형: 합의 · 준비: 가격표 · 예산 금액 (제작 필요) · 산출: 구매 목록
   배분: 계획 1분 → 4/3/2 짝끼리 목록 조정 → 정리: 최종 목록·합계

   왜 말하게 되나
     돈이 모자라니 무엇을 빼고 넣을지 협상해야 합니다.

   진행
     1. 예산 10만 투그릭과 물건 가격표를 줍니다
     2. 각자 사고 싶은 것을 말합니다
     3. 예산에 맞게 조가 목록을 조정합니다
     4. 발표자가 최종 목록과 합계를 발표합니다

   Lv1  얼마예요 · 숫자 · 사고 싶어요
        → 교실 파티 준비물 사기
   Lv2  -(으)ㄹ까요 · -는 게 좋겠어요 · 대신
        → 조별 여행 예산 짜기


▣ T-09  찬반 나누기
   유형: 의견 차 · 준비: 논제 카드 (제작 필요) · 산출: 찬반 근거 각 2개
   배분: 계획 1분 → 1R 같은 편 근거 4분 → 2R·3R 반대편과 맞대기 → 정리: 근거 정리

   왜 말하게 되나
     자리에 따라 입장이 강제되니 반대편도 말해야 합니다.

   진행
     1. 논제를 줍니다 (교복·휴대폰·아르바이트 등)
     2. 두 명은 찬성, 두 명은 반대를 맡습니다 (선택 아님)
     3. 각 편이 근거 2개씩 만듭니다
     4. 발표자가 양쪽 근거를 정리해 발표합니다

   Lv1  좋아요/싫어요 · -고 싶어요 · 왜냐하면
        → 교복을 입는 게 좋다
   Lv2  -아서/어서 · -지만 · -(으)면 좋겠어요
        → 학생이 아르바이트를 해도 된다
   Lv3  -(으)ㄴ/는 반면에 · -(으)ㄹ 뿐만 아니라 · -다고 생각하다
        → 온라인 수업이 대면 수업을 대체할 수 있다


▣ T-10  조건 붙여 고르기
   유형: 합의 · 준비: 선택지 4개 + 조건 카드 (제작 필요) · 산출: 선택 + 조건
   배분: 계획 1분 → 4/3/2 조건 맞대기 → 정리: 네 조건 만족안 확정

   왜 말하게 되나
     조건이 서로 다르니 조율하려면 계속 말해야 합니다.

   진행
     1. 각자 다른 조건 카드를 받습니다 (돈 없음·시간 없음 등)
     2. 선택지 4개 중 자기 조건에 맞는 것을 주장합니다
     3. 네 조건을 다 만족하는 답을 찾습니다
     4. 발표자가 "우리 조건은…, 그래서 ___를 골랐어요"

   Lv1  안 돼요 · 못 해요 · -고 싶어요
        → 주말에 같이 할 활동 정하기
   Lv2  -(으)면 · -(으)ㄹ 수 있어요 · -지만
        → 조별 과제 방식 정하기

▣ T-11  역할극 4줄
   유형: 창작 · 준비: 상황 카드 (제작 필요) · 산출: 대화 4줄 + 시연
   배분: 계획 1분 → 1R 대사 만들기 4분 → 2R·3R 연습 두 번 → 정리: 시연 준비

   왜 말하게 되나
     네 명이 한 줄씩 맡으므로 빠질 수 없습니다.

   진행
     1. 상황 카드를 뽑습니다 (식당·가게·병원)
     2. 대화 4줄을 만듭니다 (한 사람이 한 줄씩 맡음)
     3. 두 번 연습합니다
     4. 조 전체가 앞에 나와 시연합니다

   Lv1  -주세요 · 얼마예요 · -이에요/예요
        → 식당에서 주문하기
   Lv2  -아/어 주시겠어요 · -(으)ㄹ게요 · 죄송한데
        → 물건 교환하러 가기


▣ T-12  이야기 이어 만들기
   유형: 창작 · 준비: 첫 문장 (칠판 제시) · 산출: 8문장 이야기
   배분: 계획 1분 → 1R 첫 바퀴 4분 → 2R 둘째 바퀴 3분 → 3R 다듬기 2분 → 정리: 낭독 준비

   왜 말하게 되나
     앞사람 문장을 들어야 이을 수 있습니다.

   진행
     1. 첫 문장을 줍니다 ("어제 저는 시장에 갔어요")
     2. 시계 방향으로 한 문장씩 이어 붙입니다
     3. 두 바퀴 돌아 8문장을 만듭니다
     4. 발표자가 처음부터 끝까지 읽습니다

   Lv1  -았/었어요 · 그리고 · 그런데
        → 어제 있었던 일
   Lv2  -고 나서 · -는데 · 갑자기 · 그래서
        → 이상한 하루


▣ T-13  안내문 만들기
   유형: 창작 · 준비: 상황 (칠판 제시) · 산출: 안내문 1장
   배분: 계획 1분 → 4/3/2 항목 제안·합의 → 정리: 안내문 완성

   왜 말하게 되나
     한 장을 같이 쓰려면 문장마다 합의해야 합니다.

   진행
     1. 상황을 줍니다 (교실 규칙·행사 안내)
     2. 넣을 항목을 각자 하나씩 제안합니다
     3. 기록자가 안내문 형태로 적습니다
     4. 발표자가 읽고 다른 조가 질문합니다

   Lv1  -(으)세요 · -지 마세요 · 하고
        → 우리 반 규칙 5개
   Lv2  -아/어 주세요 · -(으)면 안 돼요 · -기 바랍니다
        → 학원 행사 안내문


▣ T-14  계획 세우기
   유형: 창작 · 준비: 상황 + 제약 (칠판 제시) · 산출: 일정표
   배분: 계획 1분 → 4/3/2 제안하고 순서 배열 → 정리: 일정표 완성

   왜 말하게 되나
     시간과 순서를 정하려면 서로 제안하고 조정해야 합니다.

   진행
     1. 상황을 줍니다 (하루 여행·파티 준비)
     2. 각자 하고 싶은 것을 하나씩 냅니다
     3. 시간 순서로 배열하고 기록자가 적습니다
     4. 발표자가 시간대별로 발표합니다

   Lv1  시간 표현 · -고 · 다음에
        → 주말 하루 계획
   Lv2  -(으)ㄹ 거예요 · -기 전에/후에 · -(으)려고
        → 한국 여행 3일 계획


▣ T-15  광고 만들기
   유형: 창작 · 준비: 물건·장소 카드 (제작 필요) · 산출: 광고 문구 3줄
   배분: 계획 1분 → 4/3/2 좋은 점 모으기 → 정리: 3줄로 압축

   왜 말하게 되나
     설득하는 말을 만들어야 해서 형용사·이유가 쏟아집니다.

   진행
     1. 물건이나 장소 카드를 뽑습니다
     2. 좋은 점 4개를 각자 하나씩 냅니다
     3. 광고 문구 3줄로 압축합니다
     4. 발표자가 광고처럼 말합니다 (다른 조가 점수)

   Lv1  좋아요 · 맛있어요 · 싸요 · 아주
        → 우리 동네 식당 광고
   Lv2  -아서/어서 · 제일 · -(으)ㄹ 수 있어요
        → 울란바토르 여행 광고

▣ T-16  인터뷰 후 보고
   유형: 조사 · 준비: 질문 3개 (칠판 제시) · 산출: 조원 4명 요약
   배분: 계획 1분 → 4/3/2 짝을 바꿔 인터뷰 → 정리: 조 요약 문장

   왜 말하게 되나
     자기 얘기가 아니라 남의 얘기를 전해야 해서
     3인칭·간접 표현이 강제됩니다.

   진행
     1. 질문 3개를 줍니다
     2. 조원끼리 서로 묻고 기록자가 적습니다
     3. 발표자가 조 전체를 요약합니다
     4. "저는…"이 아니라 "○○ 씨는…"으로 말합니다

   Lv1  -았/었어요 · 뭐 · 어디
        → 주말에 뭐 했어요?
   Lv2  -(으)ㄴ 적이 있어요 · -고 싶어 해요 · -(이)라고 했어요
        → 가장 기억에 남는 일
   Lv3  -다고 하다 (간접화법) · -(으)려고 하다 · -기 위해서
        → 졸업 후 진로 계획 인터뷰


▣ T-17  조사 후 통계
   유형: 조사 · 준비: 조사 항목 (칠판 제시) · 산출: 숫자 + 문장
   배분: 계획 1분 → 4/3/2 짝을 바꿔 조사 → 정리: 숫자 문장 만들기

   왜 말하게 되나
     세어서 말해야 하니 숫자 표현이 반복됩니다.

   진행
     1. 조사 항목을 줍니다 (아침 먹는 사람·운동하는 사람)
     2. 조원 넷에게 묻고 기록자가 셉니다
     3. "네 명 중 세 명이…" 형태로 문장을 만듭니다
     4. 발표자가 발표하고 다른 조 결과와 비교합니다

   Lv1  숫자 · 명 · 있어요/없어요
        → 우리 조 아침 식사 조사
   Lv2  -는 사람이 많아요 · 대부분 · 반 정도
        → 우리 조 여가 시간 조사


▣ T-18  경험 모으기
   유형: 조사 · 준비: 주제 (칠판 제시) · 산출: 경험 목록 4개 + 순위
   배분: 계획 1분 → 4/3/2 짝을 바꿔 경험 나누기 → 정리: 하나 골라 다듬기

   왜 말하게 되나
     각자의 경험은 남이 모르니 반드시 말해야 합니다.

   진행
     1. 주제를 줍니다 (실수했던 일·놀랐던 일)
     2. 각자 자기 경험을 30초씩 말합니다
     3. 조에서 가장 재미있는 것을 하나 고릅니다
     4. 발표자가 그 사람 경험을 대신 이야기합니다

   Lv1  -았/었어요 · 그때 · 아주
        → 처음 한국어를 배운 날
   Lv2  -(으)ㄴ 적이 있어요 · -는데 · -아/어서 놀랐어요
        → 한국 문화 때문에 놀란 일

▣ T-19  문제 만들어 내기
   유형: 산출 · 준비: 없음 · 산출: 문제 3개 + 정답
   배분: 계획 1분 → 4/3/2 짝끼리 문제 초안·검토 → 정리: 3개 확정 후 옆 조와 교환

   왜 말하게 되나
     문제를 만들려면 문법을 정확히 알아야 하고,
     조원끼리 정답을 검토하며 논쟁이 생깁니다.

   진행
     1. 오늘 문법으로 빈칸 문제 3개를 만듭니다
     2. 조가 정답을 합의합니다
     3. 옆 조와 문제를 바꿔 풉니다
     4. 서로 채점하고 틀린 이유를 설명합니다

   Lv2 이상 권장 (Lv1은 문제 만들기가 어렵습니다)
   Lv2  그 주 문법 아무거나
        → 빈칸 3개 + 정답 + 왜 그 답인지 한 줄


▣ T-20  열 번 안에 맞히기 (스무고개 변형)
   유형: 게임 · 준비: 정답 카드 (제작 필요) · 산출: 질문 목록
   배분: 계획 1분 → 1R 한 판 4분 → 2R·3R 진행자 바꿔 한 판씩 → 정리: 질문 목록 남기기

   왜 말하게 되나
     질문만으로 알아내야 해서 의문문이 대량 반복됩니다.

   진행
     1. 진행자만 정답 카드를 봅니다 (사람·물건·장소)
     2. 나머지 셋이 "예/아니요" 질문만 합니다 — 1인 1회 이상
     3. 열 번 안에 맞힙니다
     4. 진행자를 바꿔 세 판을 돕니다 (1R·2R·3R)

   ※ 20분에 들어가는 판은 세 판이라 4명 중 1명은 진행자를
     못 합니다. 못 한 학생이 다음 차시 T-20의 1R 진행자입니다
     — 기록자가 교안 회고에 이름 하나만 적어 둡니다.
     원래 이름이 「스무고개」인 놀이지만 4분 한 판에 20문항은
     Lv1·2에서 불가능해 열 번으로 줄였습니다. 규칙이 정본입니다.

   Lv1  있어요? · -이에요? · 커요/작아요
        → 교실 안 물건 맞히기
   Lv2  -(으)ㄹ 수 있어요? · -는 거예요? · 보통
        → 직업 맞히기

  ▣ 2. 소재를 몽골 현지로 바꾸기

    교재 소재보다 학생이 아는 것이 발화를 늘립니다.
      한국 음식 → 몽골 음식
      서울 지하철 → 울란바토르 버스
      한국 명절 → 나담 축제
    → 같은 틀, 완전히 다른 수업


  ▣ 3. 레벨 올리기

    Lv3 이상은 소재를 추상화합니다.
      T-09 찬반: 교복 → 온라인 수업 → 인공지능
      T-16 인터뷰: 주말 → 진로 → 사회 문제


  ▣ 4. 부트캠프에서 강사들과 만들기 (권장)

    2026-11 부트캠프에서 몽골쌤 8명이 각자 5개씩 만들면
    한 번에 40개가 늘어납니다.

    ★ 만드는 과정 자체가 교수법 훈련입니다.

  Q. 20분이 남으면요?
  A. 타임박스(계획 1분 → 4/3/2 → 정리)를 쓰면 대개 남지 않습니다.
     남으면 같은 과업을 소재만 바꿔 한 번 더 합니다.
     새 과업을 시작하지 않습니다 — 설명하는 데 시간이 다 갑니다.

  Q. 20분이 모자라면요?
  A. 그대로 끊고 ⑤공유로 넘어갑니다.
     미완성이어도 발표합니다. 시간을 넘기지 않습니다.

  Q. 조가 몽골어로 말해요.
  A. 과업이 어렵다는 신호입니다.
     한 단계 쉬운 것으로 바꾸거나, 필요한 표현을 칠판에 씁니다.
     진행 역할에게 「한국어 유지 감시」 의무를 상기시킵니다.
     혼내지 않습니다.

  Q. 한 명이 다 해버려요.
  A. 앱 역할 화면을 확인하세요 — 역할은 차시마다 자동으로 돕니다.
     역할과 다르게 움직이고 있으면 역할 발화 의무(진행=한국어
     감시 · 기록=30초 요약 · 질문=고칠 문장 1개)를 다시 알려줍니다.

  Q. 조용한 학생이 계속 조용해요.
  A. 발표 차례는 앱 로테이션이 어차피 가져다줍니다.
     앱 역할 화면에서 그 학생의 다음 발표 차시를 확인하고,
     그 전까지는 지명 발화로 끌어냅니다 — 브리핑의
     「지명 우선 3명」 명단이 그 순서입니다.

  Q. 매번 같은 틀을 쓰면 지루하지 않나요?
  A. 학생은 틀에 익숙해질수록 활동에 집중합니다.
     설명 시간이 줄어 실제 말하는 시간이 늘어납니다.
     한 시즌에 5~6개 틀을 돌려 쓰는 것이 적정합니다.
