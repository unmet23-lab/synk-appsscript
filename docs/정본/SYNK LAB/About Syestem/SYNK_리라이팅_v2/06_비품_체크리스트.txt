# SYNK LAB 비품 체크리스트

2026-10-02 현행화. [오프라인 운영 기준](../../../../오프라인_공간설계/오프라인_운영기준_20261002.md)의 제공 범위에 필요한 것만 준비한다. 울란바토르 공간·개원일·실제 인력/정원·제품은 미정이다. 계획 수량은 구입/설치 완료가 아니며 안전·필수 수업 준비보다 장식·선택 장비를 먼저 발주하지 않는다.

## 수량과 구매 기준

- 닫힌 강의실4곳·개인 책상16석씩은 목표다. 64세트는 동시4실 가동 시 비교 수량이며 최종 정원/개방실·제품을 확인해 발주한다. 과거24반384석은 책걸상 구매 수량이 아니다.
- A+B 전환은 두 방 책상32+의자32의 외부 수납·이동을 실제 제품으로 확인한다. 별도 수납12~16㎡는 후보이며 패널 포켓은 별도 미확정이다.
- 사무실6~8개인 자리는 동시 상주 자리 요구다. 직원13명 채용·명함13명분을 확정 구매하지 않는다.
- 무료 자습은 기존 빈 강의실 예약이다. 하루 약2~3시간은 예상이고 전용 자습실·라운지·백색소음·상시 스낵바를 위한 가구/기기는 추가하지 않는다.
- [개원 예산](../../../../유지비_BM/학원_개원_예산과_준비기간_20261001.md)과 [예산 엑셀](../../../../유지비_BM/SYNK_울란바토르_인테리어_비품_예산_20261001.xlsx)은 이전81평 산정 이력이다. 새 A+B·전환·근무·서비스 범위를 다시 견적하며 미견적을0원으로 두지 않는다.
- 발주표에는 규격·제품/업체·수량·세금/운송/설치 포함 여부·보증/수리·납기·인수 담당과 검증 결과를 연결한다. 기존 재고와 기본 동봉품을 확인해 중복 구매를 뺀다.

## 1. 임대 전에 확인할 시설·안전 조건

소방/피난·구조·전기·환기·위생·접근성은 시설 제약을 이유로 삭제하지 않는다. [소방과 필수설비 점검](../../../../오프라인_공간설계/소방과_필수설비_점검_20261001.md)의 기존6안 표시는 조사 초안이다. 실제 용도·최대 재실·현장 설계와 관할 적용 확인을 거쳐 수량/형식을 확정한다.

| 항목 | 실제 확인/준비 |
|---|---|
| 실외까지 피난·문/출구·계단 | 교실·A+B 개방/폐쇄·층 전체 인원과 보호자/방문자, 문 후퇴·폭·방향·거리·장애 없는 경로 |

| 감지·경보·비상전원 | 건물 수신반/보호 범위·실제 연동, 정전/고장 인수 시험 |

| 칸막이·천장 고정 | 구조 지지/하중·레일·씰·포켓·잠금·낙하/손 끼임·점검·취급 교육 |

| 비상 운영 | 실제 책임자/연락·학생 인계·사고/대피·정기 점검/훈련·고장 대안 |

장비를 샀다는 이유로 인허가 적합성을 완료로 표시하지 않는다. 기존 CCTV안은 수업 촬영4대와 별개이고 법정 필수로 임의 지정하지 않는다. 상담/화장실의 촬영 장비를 추가하지 않는다.

## 5. 현재 기본 구매에서 제외한 것
