# 2부. 교육·문화·공간

## 코어 수업

90분은 열기5·제시20·통제연습15·그룹발화30·공유10·닫기10으로 맞춘다. 기본 개인책상과 언어수업 정원16명 목표를 유지한다. 실제 출석1~16명은 강사 규칙의 예외표로 조 구성·역할·청취 차례를 맞춘다.16명·주5차시 개별 접점은4·3·3·3·3명으로 배정하고 실제 완료를 확인한다. 별도1:1 보충·채점·교안·결석 연락 시간은 별도로 근무표에 확보한다.

코어6권·톡2권 원고는 존재하지만 원어민 검수·실물 인쇄·레벨별 교사본/학생본·평가 자료의 인수는 미완료다. 먼저 열 레벨·반수와 실제 인쇄면수/부수·평가 기준·과제 제공표를 확정한다. 여섯 레벨의 교육 방향은 유지하며12개월 완주나 특정 급수·비자 결과를 보장하지 않는다.

교안·과제·발표 차례·진도·결석 연락·월간 리포트는 담당자가 작성·확인한다. 실제 출석·과제·평가·관찰을 근거로 학생/보호자에게 개별 전달한다. 자동 생성·채점·몽골어 발송을 가동 중으로 설명하지 않는다.

## 무료 문화와 예약 자습

- 무료 문화 혜택은 제공 가능한 예약 회차로 유지한다. 신청 댄스 정원25명, A+B가변 방향은 유지한다. 학습 성적/출결과 안전용 예약·입실 확인을 구분한다.
- 옛10·13·17시 무제한 자유 입실·한국어 수업 동시 문화수업·추가인력0명/추가노동0원을 삭제한다. 초기 댄스는 다른 한국어 수업과 시간을 분리하고 강사·전환/복구·감독·야간 근무를 실제 시간표와 예산에 넣는다.
- 원어민 회화·글로벌 영어는 등록 구성과 담당 가능 시간·실제 예약 제공표를 따른다. 뷰티·보컬을 포함한 모든 프로그램을 개원과 동시에 무제한 제공한다고 안내하지 않는다.
- 전용 자습실·로비 라운지는 없다. 무료 자습은 빈 강의실 예약제다. 하루 약2~3시간 비는 것을 예상하되 매일2~3시간을 보장하지 않는다. 실제 방별 시간표·좌석·담당 가능한 시간만 공개한다. 수업·댄스 전환·관리 시간과 겹치지 않게 입퇴실을 확인한다.
- 프로젝트는 반 안에서 짧게 공유한다. 두 기수의 크루 광장·대형 학부모 공개 무대는 정기 제공 약속에서 제외한다. 별도 장소/여러 회차의 행사는 예약 인원·감독·피난·동의·실제 노동/대관비를 확인한 뒤 별도 확정한다.

## 상담iPad·포토·VR

상담용iPad1대는 첫 상담의 전용 도구로 준비하고 교실 송출용과 공유하지 않는다. 실제 브로셔 열기·상담 입력/제출·오프라인 종이 대안·잠금·자동 잠금·이전 상담자의 임시 입력/파일 비움까지 확인한다. 승인된 보관 기록과 단말 임시 정보 삭제를 구분한다.

포토부스는 재학생 월1회·촬영을 시작한 대표 학생만 차감한다. 동반 친구 차감·얼굴 인식·자동SNS게시를 추가하지 않는다. 재학 자격·월 변경·동시 요청·장비/인화/네트워크 실패 복구·사진 접근/만료·다음 사용자 초기화를 실제 부스에서 검증한다. 수동 대안에도 같은 사용 기록을 남긴다. 구현·인수 전에는 자동 이용권이 운영 중이라고 안내하지 않는다.

서서 움직이는VR은 상담과 다른 예약 시간에 운영한다. 실제 기기·콘텐츠 이용권·안전 구역·팔 뻗음/출입·감독·세척·충전·멀미 중단·다음 사용자 초기화와 비용을 확인한다. 도면의2×2m 표식만으로 적합성이나 서비스 완료를 주장하지 않는다.

# 3부. 앱·기록·Atlas

SYNK WORLD의 학습 앱과 SYNK 플랫폼의 계정/연결 개발은 담당 원문을 따른다. 가이드·과제·학습 게임·학생 기억·소리/경험의 설계는 유지한다. 검증된 도구는 실제 학생/교사 흐름에서 저장·조회·권한·오프라인/실패 복구를 확인한 범위부터 연결한다. 학생 대상 시험·학습 효과·실제 학원 자동화는 로컬 화면 시연과 구분한다.

Atlas는 Core·Loom·Vellum·Trail·Prism·Temper·Reed·Strata, 기존8개 엔진의 총칭이다. 독립 판단 엔진이나 별도 하네스를 추가하지 않는다. 현재 역할·원문·코드는 [엔진8종 상향설계](../../../../엔진8종_상향설계_v3.md)에서 확인한다. 이 문서가 엔진 전체나학원 자동화의 구현·배포 완료를 선언하지 않는다.

기록의 최소 접근권한·백업 주기·복원 담당·실제 복구 시험을 개원 전 정한다. 매일03시 자동백업·30일보관이 현재 동작한다고 안내하지 않는다. 시험용 데이터와 실학생 기록을 구분하고 시연이 실데이터를 바꾸지 않게 확인한다. 토큰·API키는 코드/공개 문서에 넣지 않는다.

# 4부. 녹화·라이브·주말/온라인

## 촬영 방향과 인수

강의실4곳은 교재/필기 원본을 메인으로 직접 캡처하고 교사 카메라를 합성하는 방향을 유지한다. 교사 착용 마이크·수신기·PC/OBS·유선망·로컬 저장을 연결하고 실제 필기·전환·동작·음성/화면 동기·4실 동시 송출/저장·복구를 검증한다. 학생별 화면 선택은 별도 스트림과 앱 기능 검증이 필요하며 단일YouTube 합성 영상으로 학생마다 레이아웃을 바꿀 수 있다고 안내하지 않는다.

핀마이크는 교사 음성용이며 모든 조의 학생 발화를 명료하게 담는다고 보장하지 않는다. 촬영 자료만으로 그룹 발화·실제 상호작용·교사의 개인 피드백을 공급한 것으로 계산하지 않는다.

녹화 선택·부분 편집·검수·목차·권한·업로드·저장·삭제·장애 처리 노동을 실제 측정해 담당 시간과 비용에 넣는다. 별도 스튜디오를 안 쓰더라도 총 제작 노동이0원은 아니다.

## 동의와 학생 보호 — 개원 조건

교육용 녹화, 제한된 수강 자료, 공개 홍보, YouTube 라이브의 이용 목적과 접근범위를 구분한다. 학생·보호자 동의/선택, 거부 학생의 동등한 수업과 화면·음성·거울 반사 제외, 승인·철회·보관·삭제 담당을 갖춘 뒤 촬영/게시한다. 사후 동의나 사후 편집으로 라이브 제외를 대신하지 않는다. 동의·구도·음성·권한이 확인되지 않으면 송출하지 않는다.

## 현재 판매·보강 범위

- 토90분+평일 녹화+앱만으로 평일과 동등한 진도·발화·피드백·승급을 보장하는 주말 상품은 개원 판매대상에서 제외한다.

- 무료 공개분은 권리·동의·검수·제작 담당이 확보된 자료만 별도 승인 후 게시한다. 자동 레벨테스트 채점·리드 편입·홍보 게시를 가동 중으로 설명하지 않는다.
- 온라인 앱·학습 기록·콘텐츠 개발은 계속할 수 있으며 검증 전 상품 판매 약속과 구분한다.
