◆ 0. 전제

학생 데이터 파이프라인 · 매일 백업 · 포인트 재계산 · 원장 브리핑 ·
스토리북 발간 · AI 숙제 첨삭 — 전부 자체 개발 Apps Script 자동화
엔진(판번호는 머리의 기준 버전) 위에서 이미 자동으로 돌고 있습니다.
외부 자동화 구독 없음.

문서 구성:
  1부  엔진 — 데이터가 흐르는 길과 자동화 달력
  2부  앱 — 역할별(학생·학부모·강사·원장) 전 기능과 콘텐츠 자산
  3부  교재 × 커리큘럼 × 앱 — 삼각 상호작용
  4부  온라인 강의 연계
  5부  운영 6개 시스템 — CRM부터 위기 대응까지

◆ 1. 운영 스택 한눈에 — 데이터가 흐르는 길 [가동]

  [Google Form] 상담 신청 · 레벨 테스트 · 출석 · 결석 신고 · 문의
        ·  10분마다 자동 수집 · 학생ID 자동 채번
        v
  [상담 스프레드시트]  상담·수강·납입 원장
        ·  매일 07:00 자동 동기화 (Layer 1)
        v
  [profiles DB]  학생 마스터 + 포인트·게이지·급수 계산열
        |----------> [Glide 앱]  학생·학부모·강사·원장 4역할 화면  ⛔08-05 폐기(낙하산 존치)
        ·  매주 월 07:00 자동 동기화 (Layer 2)
        v
  [Notion 크루 DB]  정량(앱 데이터) + 정성(인터뷰·메모) 통합 허브

핵심은 2단 동기화 구조입니다.

  Layer 1   상담시트 → profiles   매일 07:00
            학생 마스터 데이터 갱신. 퇴소자는 앱에서 제외하되 이력 보존.
  Layer 2   profiles → Notion     매주 월 07:00
            학생별 업서트(있으면 갱신, 없으면 생성). 엔진은 정량 항목만
            쓰고, 노션의 정성 기록은 건드리지 않음.

그리고 엔진에는 데이터 사고를 막는 가드가 내장돼 있습니다.

- 이상 감지 시 자동 보류 — 학생 수가 0이 되거나 30% 넘게 급감하면
  덮어쓰기를 멈추고 마지막 정상 상태를 유지, 원장에게 알림.
- 동기화 실패 시 즉시 메일 — 소스 시트에 접근하지 못하면 기존 데이터를
  보존하고 원장에게 실패 메일. (내부 기술 용어입니다)
- 시스템 워치독 — 시트·콘텐츠·트리거 상태를 정기 점검해 빠진 것을
  스스로 알아챕니다.
- 메일 쿼터 가드 — 알림이 폭주해 정작 중요한 메일(미납·브리핑)이
  죽는 일이 없도록 발송량을 자동 관리합니다(알림 다이어트).
- 시크릿 분리 보관 — 외부 연동 토큰·API 키는 코드·저장소 밖(스크립트
  속성)에 보관. 유출 경로를 원천 차단.


◆ 2. 자동화 트리거 달력 — 엔진의 하루·일주일·한 달 [가동]

사람이 잊어도 엔진은 잊지 않습니다.
아래 일정이 전부 현재 자동 실행 중입니다.

  매 10분          상담·리드 폼 응답 수집 → 시트 기입 + ID 채번
  매일 (새벽)      03:00 전체 데이터 백업 (30일 보관)
  매일 (아침)      07:00 상담시트 → profiles 동기화 + 생일·상담지연 체크
                   08:00 원장 아침 브리핑 메일
                   웰컴 임명장 메일 (신규 등록 + 학부모 이메일 확인 시)
                   AI 데일리 생성 — 오늘의 한 문장·약점 맞춤 퀴즈
  매일 (낮·밤)     14:00 / 22:00 포인트·성장 게이지 재계산 (하루 2회)
                   AI 숙제 첨삭 배치 (제출분 비동기 처리)
  매주 월          07:00 profiles → Notion 동기화 + 미납·재등록·
                   헬스체크 + 주간 통합 리포트(AI 해설 포함)
  매주 (주간)      레이드 주간 결산 발간 · 칭찬 태그 다이제스트
                   (크루의 눈)
  매월 1일         칭호 부여 · 성장 스냅샷 · 아카이브 · 스토리북 발간 ·
                   AI 월간 4종(하이라이트 메일·미래의 나 편지·유니크
                   칭호·SNS 초안 3편) · 경영 월보 메일
  수시             이상 감지 시 동기화 자동 보류 + 원장 알림

새벽 3시에 백업이 도는 동안 사람은 잡니다. 그러라고 만든 엔진입니다.
그리고 AI 기능은 전부 안전판이 있습니다 — API 키가 없거나 응답이
막히면 앱은 기존 화면(폴백)으로 조용히 돌아갑니다. AI가 죽어도 앱은
멈추지 않습니다.

2부. 앱 — 역할별 전 기능
───────────────────────────────

같은 앱에 로그인하면 역할(학생·학부모·강사·원장)에 따라 전혀 다른
화면이 열립니다. 아래는 화면에 실제로 배치된 기능의 전수 목록입니다.

◆ 3. 학생 앱 — 탭 5개, "공부가 게임의 리듬으로" [가동]

3-1. 홈 — 매일 아침 열게 되는 화면

- 출석 히어로 버튼 — GPS 셀프 출석. 학원 위치에서 누르면 출석 기록과
  포인트가 즉시 적립(적립 수치는 SYSTEM 3 참조). 구글폼 출석 경로도
  병행 — 앱 사용량 한도를 보호하는 이중화 설계입니다.
- 온보딩 카드 — 처음 로그인한 크루에게 세계관과 첫 임무를 안내.
- 오늘의 알림 배너 — 진화·도전·성장·생일 등 오늘 나에게 생긴 일. 진화한
  날은 AI 내레이터가 그 학생만의 진화 서사를 써 줍니다.
- 오늘의 한 문장 — AI가 학생의 레벨·약점·최애(좋아하는 아이돌·배우)를
  반영해 매일 새로 써 주는 개인화 한국어 문장.
- 오늘의 숙제 — 요일제 자동 게시. 숙제 뱅크 210개(요일당 30개,
  30주 무반복 로테이션), 주말은 토요일만 게시.
- 오늘의 퀴즈 — 3난이도. 퀴즈 뱅크 100문항(TOPIK I 필수 문법 +
  TOPIK II 진입 문법) 위에, AI가 학생별 취약 문법으로 문제와 해설을
  맞춤 생성.
- 나의 여정 카드 — 이번 주 퀘스트 결산, 성장 전/후 비교(첨삭 기록이
  3주 이상 벌어지면 자동 등장), 이달의 AI 유니크 칭호.
- 학업 추세 — 월말 평가·모의고사 흐름 그래프.
- 캐릭터 한마디 — 내 캐릭터가 상태(진화 임박·도전·성장·생일)에 맞춰 건네는
  대사. 한국어·몽골어 대역.
- 드림한줄 입력 — "5년 뒤 나"를 한 줄로. 나침반 세션의 드림맵과
  이어지고, 매월 '미래의 나 편지'의 재료가 됩니다.
- 내 기록 상세 — 기록실·플레이스타일·케미·매치업. 내 학습 스타일을
  게임 프로필처럼 보여줍니다.

3-2. 도감 — 성장이 캐릭터로 보이는 곳

- 캐릭터 7단계 도감: 뉴로 → 스파키 → 링커 → 서킷 → 미엘로 → 플로우 →
  싱크마스터. 도달 전 단계는 잠금 카드(???)로 궁금증을 남깁니다.
- 진화 조건은 하이브리드 — 누적 포인트 임계값 + 단계별 문법 게이트.
  문법 게이트 뱅크 72문항, 단계당 12문항 중 9문항(75%) 숙달 시 통과.
  "캐릭터는 공부로만 자란다"가 코드로 강제돼 있습니다.
- 대표 캐릭터 선택, 캐릭터 이름 짓기, 숨 쉬는 캐릭터 애니메이션.

3-3. 스토어 — 포인트가 실물이 되는 곳

- 보유 포인트로 즉시 교환(스토어 19종 · 간식 40 ~ 촬영 체험 2,000.
  과잠은 판매가 아니라 재원 12개월+누적 1,200P 무료 지급 자격 —
  단가 정본 = 앱 store 시트·집필 규범 §9).
- 찜하기 + 목표 진행바 — "과잠까지 640P" 같은 남은 거리가 보입니다.
- 잔액 게이트 — 포인트가 모자라면 구매 버튼이 잠깁니다.

3-4. 소식 — 싱크 스토리의 무대 (학생 콘텐츠의 심장)

여기가 SYNK 세계관이 매달 살아 움직이는 곳입니다. 반 전체가 같은
이야기를 공유하기 때문에, 소식탭은 혼자 보는 알림함이 아니라 우리 반의
연재 만화책처럼 작동합니다.

- 이달의 보스 카드 — 시즌 보스 12종(몽골의 계절을 반영해 월별 고정).
  우리 반의 출석·과제가 보스 HP를 깎는 공격이 됩니다.
- 주간 레이드 결산 — 매주 우리 반의 전투 기록이 이야기로 발간됩니다.
- 월간 스토리북 「싱크 스토리」 — SYNK 콘텐츠의 간판.
  · 매월 1일, 그 달의 실제 데이터(리그 명승부·진화한 크루·이달의 스타)를
    등장인물로 삼아 표지 + 프롤로그 + 4장 + 에필로그의 소설 한 편이
    자동 발간됩니다. 주인공이 남이 아니라 우리 반입니다.
  · 독서 분량은 5~15분으로 자동 보정 — 너무 짧으면 엔진이 감각 묘사를
    보강해 "읽을 만한 한 편"을 보장합니다.
  · 교육 장치가 숨어 있습니다: 매월 TOPIK 3~4급 핵심 문형 4개가 문장
    골격으로 깔리고(연 48개 문형), 막마다 한국어 감정 관용구 배지가
    붙습니다. 재미로 읽었는데 중급 문형이 눈에 익는 구조.
  · 한국어·몽골어 대역 — 문형은 한국어를 유지하고 의미를 몽골어로.
  · 발간과 동시에 삽화용 12씬 프롬프트가 저장됩니다. 영상·일러스트
    제작 루틴이 시작되면 스위치 하나로 영상팩 메일이 켜집니다. [대기]
- 이달의 카드 — 스토리북과 짝을 이루는 수집 카드. 0P '다음 달 주인공
  예약' 카드로 다음 호 참여를 걸어둡니다.
- 여행지도 — 12칸 도장 그리드. 스토리북이 발간될 때마다 그 달의
  무대에 도장이 찍히고, 미발간 칸은 ???로 남아 1년짜리 수집 여정이
  됩니다.
- 명예의 전당 · 리그 역사 — TOPIK 합격자, 시즌 우승 반의 영구 기록.
- 공지 — 한국어·몽골어 병행.

3-5. 랭킹 — 노력의 전시장

- 포인트·스트릭 랭킹, 업적, 칭호 컬렉션(칭호마다 세계관 설명 lore),
  도전·성장 컬렉션(오늘의 도전·오늘의 성장 — 따로 셈).
- 규율: 비교의 프레임은 언제나 노력 지표입니다. 성적 등수를 박제하는
  화면은 없습니다 — 시험 결과는 리포트카드(학부모)와 본인 추세
  그래프로만 갑니다.

3-6. 학생 콘텐츠 자산 총량 (코드 실측)

◆ 9. 상호작용의 원칙 — 커리큘럼이 정본, 교재와 앱이 따른다

1. 커리큘럼 → 교재 (커리큘럼-우선)
   주차·차시 교안을 국제통용 표준 요목에서 직접 도출하고, 시냅스 코어
   각 권의 목차는 그 교안에서 역으로 뽑습니다. 교재가 커리큘럼을
   기다리는 순환 대기를 끊은 구조 — 자체 교재라서 가능한 설계입니다.

2. 교재 ↔ 앱 (이원 설계 — "얇은 교재 + 두꺼운 앱")
   · 종이 = 수업 코어만. 1과(1주) 표준 16페이지: 시즌 서사 도입 →
     코어 어휘 25~30개 → 문법(몽골어 대조 팁 박스) → 발음 코너(권1~2)
     /한자어 어원 코너(권3~) → 통합 과업 → 자가 점검(can-do 체크 +
     "다음에 맞힐 문제" 칸).
   · 앱 = 워크북 전체. 반복 드릴은 숙제 뱅크(210)와 퀴즈 뱅크(100)가,
     채점·피드백은 AI 첨삭이, 어휘 롱테일은 교재 속 QR로 연결된 앱
     콘텐츠가 맡습니다. 어학당식 "교재+워크북 2권"을 "얇은 교재+앱"으로
     대체한 구조라, 하루 30분의 앱 자습까지가 커리큘럼의 정식
     일부입니다.

3. 커리큘럼 ↔ 앱 (리듬 동기화)
   · 주간 교안이 그 주의 숙제·퀴즈를 참조 지정 → 앱이 요일제로 자동
     게시 → 제출이 lesson_log·mastery(학습 추적)에 쌓여 진도 기록의
     축이 됩니다. 차시 단위 실적은 차시 마감폼(§5)이 30초에 봉합니다.
   · 월 모듈 = 월말 평가 = 월간 배치(칭호·스냅샷·스토리북)가
     같은 달력 위에서 돕니다.
   · 시즌(8주) = 교재 1권 = 시즌 서사 = 8주차 승급 평가. 연 6시즌이
     12개월에 정확히 들어가고, 6개월권(26주)이 세 시즌과 맞물립니다.
     크루 캡스톤 공개일은 반년마다 1회(세 시즌마다). 교재의 과 도입부에
     실리는 시즌 스토리 비트와 앱 소식탭의 보스·스토리북이 같은 세계관을
     공유합니다.
   · 단, 몬스터 진화 축은 커리큘럼과 1:1로 묶지 않습니다 — 진화는
     노력(포인트+문법 게이트)의 축, 승급은 실력(도달제)의 축. 빠르게
     노력한 Lv1 크루가 Lv3 크루보다 몬스터가 높을 수 있고, 그래야
     초급생에게도 매일의 동기가 살아 있습니다.

4. 남은 배선 [구축]
   · 교안 확정 후 앱 데이터화(contents_curriculum.js) — 레벨별 퀴즈
     증설 포함.
   · 시냅스 톡 실물 권별 수록 범위 확정 시 톡↔레벨 매핑 1:1 조정.

◆ 10. 확정된 것과 남은 것

스코프 잠금: 자체 온라인 콘텐츠도 교재·앱과 같이 TOPIK 5급까지.

형태 확정(급여 정본 v1.3): 녹화 강의는 따로 제작하지 않습니다.
평일 수업을 녹화해 잘 된 것만 골라 올립니다 — 스튜디오 별도 제작 없음,
제작 인건비 0.

용도 세 가지:

1. 주말반 = 정규 트랙 [확정]
   주말반은 평일의 축소판이 아니라 정규 트랙입니다(급여 정본 1장 —
   현행판). 같은 6권 커리큘럼 · 같은 8주 시즌 · 같은 승급 기준.
   대면 토요일 90분 + 녹화 강의 + 앱 자습의 블렌디드.
   가격은 평일과 같은 스탠다드(55/47/42만₮), 주말생에게 올액세스는
   팔지 않습니다.
   · 상담 고지 문구(확정): "같은 커리큘럼, 대면이 주 1회이고 나머지는
     온라인. 온라인을 안 들으면 진도가 따라오지 않습니다"
   · 온라인 수강 이력은 앱이 추적합니다(v9.106) — 승급 도달제 판정이
     대면 90분만 보고 내려지지 않게.
   · 녹화 강의는 별도 매출을 만들지 않습니다(주말반 가격에 포함).
     따라서 **5층 자격 확장**(온라인 강의 수수료)의 대상이 아닙니다 —
     5층은 유료 온라인 상품이 생길 때 삽니다. 요율의 정본은 급여 정본
     8-2장이고 이 문서에는 적지 않습니다(「크루 핸드북 5층」은 없는
     좌표였습니다 — 핸드북 5장은 「금지 행위와 징계」입니다).
2. 결석·혹한 보강 — 겨울 모드(12~2월): 주 5일 중 2일을 온라인·앱

  │             예정자 / TOPIK 응시 예정자 / 입시 준비생
  ├ 교육 자료   커리큘럼 로드맵 Level 1~6 / 수업 계획서 / 문제 은행 /
  │             강사 매뉴얼
  ├ 마케팅      콘텐츠 캘린더 / SNS 트래커 / 브랜드 에셋 / 광고 기록
  ├ 재무        월별 손익 / 예산 / 비품 재고
  └ 법무·규정   사내 규정 / 계약서 양식 / 개인정보 처리 방침

크루 DB는 엔진이 매주 정량 데이터(포인트·왕관·스트릭·급수·몬스터
단계)를 자동으로 채우고, 사람은 그 위에 인터뷰·정성 메모를 쌓습니다.
숫자와 이야기가 한 페이지에서 만나는 구조입니다.


◆ 12. 오픈 전 구축 우선순위

엔진·앱·콘텐츠가 이미 돌고 있으므로, 남은 구축은 "현장과 사람"에
집중됩니다.

  1단계  오픈 전         입소 계약서·상담 도구 / 온라인 결제·납부
                         알림 / 인사카드·온보딩·업무 루틴 / 출석 방식
                         최종 판정(한도 실측) / 굿즈 초도 제작 /
                         SOP 인쇄·CCTV·구급함 / 수업 녹화 동의 v18.7
                         수취(§10) / 온라인 업로드 플랫폼·공개 범위
                         확정
  2단계  오픈 후 1개월   재등록 D-단계 시나리오 / 시험 운영 체크리스트
                         정착 / 콘텐츠 캘린더 가동 / 메신저 자동 응대
                         (Meta 직결)
  3단계  오픈 후 3개월   강좌·캠페인 수익성 분석 고도화 / 노션 지표

                         검증) / 교안 앱 데이터화
