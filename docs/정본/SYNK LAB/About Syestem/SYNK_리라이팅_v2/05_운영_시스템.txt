# SYNK 운영 시스템

학원을 돌리는 기계의 실물 대장이다. 무엇이 이미 돌고, 무엇을 짓는 중이고, 무엇이 개원과 함께 서는지를 한 곳에서 센다 — 내부 운영진용.

## 30초 안에 찾는 것 셋

| 묻는 것 | 가는 곳 |
|---|---|
| 지금 몇 개가 도는가 | 「세어 본 결과」 |
| 오늘 새벽에 무엇이 돌았나 | 1-3 자동화 달력 |
| 이 숫자의 정본은 어디인가 | 「값의 정본 지도」 |

## 이 문서가 지금 못 답하는 것 — 다섯

1. **출석 방식 최종 판정.** 폼 출석 경로를 둔 원래 근거는 구 노코드 웹앱의 월 업데이트 한도였고, 그 웹앱은 2026-08-05에 폐기됐다. 폼 경로 자체는 오프라인·저사양 대비로 쓸모가 남지만, 근거는 새 스택 기준으로 다시 세워야 한다.
2. **포인트 경제 수치.** 적립 기준과 상점 단가의 정본은 코드와 라이브 시트다. 지속가능성 재검증은 급여 정본 현행판 가격으로 다시 돌려야 한다 — 구 검증치는 폐기된 기준이라 걷었다.
3. **보스·레이드 서사와 세계관.** 「이름 없는 땅」 정본은 「적이 없다」인데, 게임화 실물에는 시즌 보스 12종과 반 레이드가 있다. 어느 쪽으로 가를지는 유호님 판정 자리다.
4. **강사·원장 화면 정본.** 펠트 앱 화면 14벌 중 채택된 것은 학생 4벌이다. 학부모 3벌은 별건 트랙으로 섰고, 강사 4·원장 3은 판정 대기다.
5. **온라인 강의의 업로드 플랫폼·공개 범위.** 확정되면 4부의 상태 표시가 바뀐다.

## 상태 표시 — 세 종류만 쓴다

| 표시 | 뜻 |
|---|---|
| **[이미 돈다]** | 사람 손 없이 지금 자동으로 실행되는 것 |
| **[짓는 중]** | 코드·설계·화면은 섰지만 아직 사람에게 안 닿은 것. 스위치만 켜면 도는 것도 여기다 |
| **[개원과 함께]** | 학생·교실·행사가 있어야 시작되는 것 |

어느 표시를 쓸지는 취향이 아니라 대장이 정한다 — 시제 정본은 `docs/SYNK_철학.md` §0 과 부록 A다. 오늘 학생은 0명이고 개원은 2027-02-25다.

낱말 하나만 주의한다. 이 문서는 앱에 실제로 있는 기능명을 그대로 적는데, 시트 열 이름과 코드 키에는 옛 이름이 남아 있다. 대외 문서로 그대로 옮기지 않는다.

## 세어 본 결과

| 갈래 | 이미 돈다 | 짓는 중 | 개원과 함께 | 합계 |
|---|---|---|---|---|
| 1부 엔진 | 3 | 1 | 0 | 4 |
| 2부 앱 | 34 | 14 | 0 | 48 |
| 3부 교재·커리큘럼 | 0 | 2 | 1 | 3 |
| 4부 온라인 강의 | 2 | 2 | 3 | 7 |
| 5부 운영 여섯 갈래 | 41 | 24 | 4 | 69 |
| **합계** | **80** | **43** | **8** | **131** |

세는 법은 본문에 붙은 상태 표시를 갈래별로 세는 것이다. 절 제목에 붙은 표시 하나가 그 절의 항목 여럿을 덮는 자리도 있어서, 1부의 4가 2부의 48보다 적은 일이 생긴다 — 항목 수가 아니라 «표시가 붙은 자리»의 수다. 6부와 7부는 구조 설명과 순서라 표시를 쓰지 않는다. 본문을 고치면 이 표도 같은 편집에서 다시 센다.

## 값의 정본 지도 — 이 문서가 «안 적는» 것

수치는 이 문서에 적지 않는다. 적는 순간 사본이 되고, 사본은 갈라진다.

| 값 | 정본 |
|---|---|
| 수강료·급여·고정비·BEP·정원 | 「SYNK LAB 급여 인센티브 정본」 |
| 근태 배점 | 급여 정본 7장 |
| 온라인 강의 수수료율 | 급여 정본 8-2장 |
| 엔진 판번호 | `Code.js` 의 `SYNK_VERSION` |
| 포인트 적립 기준·상점 단가 | 라이브 시트 |
| 과잠 지급 자격 조건 | 「SYNK 집필 규범」 §9 |
| 반·강의실 배정 | 반편성 정본 |
| 시즌 평가 기준 | 「SYNK 크루 핸드북」 |
| 엔진 일곱의 정의와 상태 | `docs/엔진/SYNK_엔진_지도.html` |
| 시제 판정 | `docs/SYNK_철학.md` 부록 A |
| 커리큘럼 급수 매핑 | `docs/커리큘럼_정본_v1.md` |

참조는 판번호가 아니라 이름으로만 한다. 판번호를 박아 두면 정본이 다섯 판 앞서갈 때까지 이 문서만 그 사실을 모른다.

# 1부. 엔진

## 1-1. 데이터가 흐르는 길 [이미 돈다]

- Google 폼 — 상담 신청 · 레벨 테스트 · 출석 · 결석 신고 · 문의
- 10분마다 자동 수집, 학생ID 자동 채번
- 상담 스프레드시트 — 상담·수강·납입 원장
- 매일 07:00, 1층 동기화
- profiles DB — 학생 마스터 + 포인트·게이지·급수 계산열
- 매주 월 07:00, 2층 동기화
- 정량(앱 데이터)과 정성(관찰 한 줄·인터뷰)이 만나는 허브 — 강사 화면 ②「학생」이 받는다(6부) **[짓는 중]**

핵심은 2단 동기화다.

- **1층 · 상담시트 → profiles, 매일 07:00.** 학생 마스터를 갱신한다. 퇴소자는 앱에서 빼되 이력은 남긴다.
- **2층 · 정량 집계, 매주 월 07:00.** 학생별 포인트·도달·스트릭·급수를 다시 셈한다. 사람이 적은 정성 기록은 엔진이 건드리지 않는다.

profiles 를 읽어 화면을 그리는 접점 앱은 2부에서 따로 센다 — 계산과 화면은 지금 서로 다른 층에 있다.

## 1-2. 사고를 막는 가드 다섯 [이미 돈다]

- **이상 감지 시 자동 보류** — 학생 수가 0이 되거나 30% 넘게 급감하면 덮어쓰기를 멈추고 마지막 정상 상태를 유지, 원장에게 알림.
- **동기화 실패 시 즉시 메일** — 소스 시트에 접근하지 못하면 기존 데이터를 보존하고 원장에게 실패를 알린다.
- **시스템 워치독** — 시트·콘텐츠·트리거 상태를 정기 점검해 빠진 것을 스스로 알아챈다.
- **알림 총량 조절** — 알림이 폭주해 정작 중요한 메일(미납·브리핑)이 묻히지 않도록 발송량을 자동 관리한다.
- **시크릿 분리 보관** — 외부 연동 토큰과 API 키는 코드·저장소 밖(스크립트 속성)에 둔다.

## 1-3. 자동화 달력 [이미 돈다]

사람이 잊어도 엔진은 잊지 않는다. 아래가 전부 지금 자동으로 실행된다.

| 언제 | 무엇 |

| 매일 08:00 | 원장 아침 브리핑 메일 |
| 매일 | 오늘의 한 문장 · 약점 맞춤 퀴즈 생성 |
| 매일 | 웰컴 임명장 메일 (신규 등록 + 학부모 이메일 확인 시) |
| 매일 14:00 / 22:00 | 포인트·성장 게이지 재계산 |
| 매주 월 07:00 | 미납·재등록·헬스체크 + 주간 통합 리포트 + **반별 주간 교안 초안 생성**(Drive `SYNK_교안초안`)(AI 해설 포함) |

새벽 3시에 백업이 도는 동안 사람은 잔다. 그러라고 만든 엔진이다.

달력에 아직 없는 칸이 하나 있다. **숙제 첨삭 답장** — 제출된 숙제를 비동기로 첨삭해 되돌려 주는 자리다. 레일은 섰고 운영 배포가 남았다. **[짓는 중]**

실제로 걸린 트리거 목록의 정본은 라이브 스크립트다. 이 표와 어긋나면 라이브가 맞다.

# 2부. 앱

## 2-1. 두 층으로 갈라 읽는다

운영 엔진이 계산하고 발송하는 것과, 학생이 손으로 만지는 화면은 다른 층이다. 구 노코드 웹앱이 2026-08-05에 폐기되면서 이 둘이 갈라졌다 — 계산은 그대로 돌고, 화면만 네이티브(Expo)로 다시 짓는다.

그래서 이 부는 「기능 목록」이 아니라 「어느 층까지 왔나」로 적는다.

- 계산·집계·발송 — 자체 Apps Script 운영 엔진 **[이미 돈다]**
- 학생·강사·원장이 보는 화면 — SYNK-talk(Expo + Supabase) **[짓는 중]**
- 학부모 화면 — 별건 트랙으로 선다 **[짓는 중]**

## 2-2. 학생 — 엔진이 이미 만들어 두는 것 [이미 돈다]

학생이 볼 화면은 다시 짓는 중이지만, 그 화면에 실릴 «내용»은 이미 매일 생산된다.

- **캐릭터 7단계 진화** ⚠**은퇴 중** — 2026-08-26 유호 확정으로 폐지가 정해졌고 라이브 계산은 아직 돈다(소각 진행 중). 조건은 누적 포인트 임계값 + 단계별 문법 게이트(뱅크 72문항, 단계당 12 중 9문항 숙달 시 통과)였다. 🔑 **살려서 가져가는 것 하나 = 「공부로만 자란다」가 코드로 강제된다**는 것 — 뒤를 잇는 가이드 세 축도 같은 규율 위에 선다(집필 규범 §4).
- **오늘의 도전 · 오늘의 성장** — 기준을 채운 전원에게, 학생당 하루 각 1회. 누적은 도전 기록·성장 기록으로 따로 센다.
- **스트릭 · 칭호 · 성장 스냅샷 · 포인트 재계산**(하루 2회).
- **오늘의 한 문장** — 학생의 레벨·약점·최애를 반영해 매일 새로 쓴다.
- **오늘의 숙제** — 요일제 자동 게시. 주말은 토요일만.
- **오늘의 퀴즈** — 3난이도. 뱅크 위에 학생별 취약 문법으로 문제와 해설을 맞춤 생성한다.
- **월간 스토리북 「싱크 스토리」** — 매월 1일, 그 달의 실제 데이터(그 달 새 장면이 열린 크루 · 그 달 칭호를 받은 학생)를 등장인물로 삼아 표지 + 프롤로그 + 4장 + 에필로그의 소설 한 편이 자동 발간된다. 주인공이 남이 아니라 우리 반이다. 반 전체가 같은 이야기를 공유하기 때문에, 소식은 혼자 보는 알림함이 아니라 우리 반의 연재 만화책처럼 작동한다.
  - 독서 분량은 5~15분으로 자동 보정된다. 너무 짧으면 엔진이 감각 묘사를 더해 읽을 만한 한 편으로 채운다.
  - 교육 장치가 숨어 있다. 매월 TOPIK 3~4급 핵심 문형 4개가 문장 골격으로 깔리고(연 48개 문형), 막마다 한국어 감정 관용구 배지가 붙는다. 재미로 읽었는데 중급 문형이 눈에 익는 구조다.
  - 한국어·몽골어 대역 — 문형은 한국어를 유지하고 의미를 몽골어로 옮긴다.
  - 발간과 동시에 삽화용 12씬 프롬프트가 저장된다.
- **시즌 보스 12종** — 몽골의 계절을 반영해 월별로 고정된다. 주간 레이드 결산이 매주 발간된다.
- **여행지도 12칸 도장 · 이달의 카드 · 공지**(한국어·몽골어 병행).

규율이 하나 있다. **비교의 프레임은 언제나 노력 지표다.** 성적 등수를 박제하는 화면은 없다 — 시험 결과는 리포트카드(학부모)와 본인 추세 그래프로만 간다.

## 2-3. 학생 — 새 앱에서 서 있는 것 [짓는 중]

화면 정본 넷이 채택됐다(2026-08-23). **오늘 · 나의 성장 · 소식**, 그리고 조합판(퀴즈). 세 탭을 가른 잣대는 시제다 — 과거의 누적 / 현재의 할 일 / 밖에서 온 것. 「나의 성장」의 게이지는 몽골에서 한국까지 여섯 칸을 가는 여행 게이지이고, 꿰맨 단추의 켬·끔으로 도달을 표시한다.

코드까지 선 것은 이렇다.

- **말하기 숙제** — 녹음 · 자동 전사 · AI 교정 답장. 실기기 관통은 끝났고 파일럿 전이다.
- **나침반 3문항 · 시즌 목표 · 드림맵 카드 · 시즌 회고** — 표·통로·화면이 서고 운영까지 배포됐다. 남은 것은 코드가 아니라 첫 학생의 첫 답이다.
- **미니게임 네 벌** — 서류관문 · 알바변명 · 보고서교정 · 교수멘탈. 코드와 화면까지 섰고 자동 배정은 둘까지 왔다. 몽골어 검수 확정 전.
- **복습 스케줄러(FSRS-6)** — 계산기 완료. 목표 기억률 0.9, 최대 간격 60일.
- **가이드 선택제** — 학생이 몽글·까몽·마린 셋 중 자기 가이드를 고른다. 셋은 외모가 아니라 학생을 대하는 방식으로 갈린다: 몽글은 같이 하고, 까몽은 지켜보고, 마린은 임무를 준다. 한 학생에게 가이드는 하나이고, 고른 결과 자체가 그 학생을 이해하는 재료가 된다. 셋 다 말을 하지 않는다 — 말은 말풍선이 하고 소리는 효과음이 한다.
- **앱 첫 시작** — 「이름 없는 땅」 세계관의 5.4초 튜토리얼. 어둠에서 시작해 학생이 한 번 누르면 코랄이 번지고 형체가 또렷해지며 가이드의 이름이 뜬다. 학생·강사·원장이 같은 화면을 지난다. 시연 실물이 섰고, 착수는 펠트 화면 트랙이 닫힌 뒤다 — 먼저 하면 두 번 짓는다.
- **화면 재질** — 앱 UI는 준비되는 대로 펠트 실물 오브젝트로 대체한다. 지금의 CSS 목업은 임시 비계다.
- **영상팩 메일** — 스토리북 12씬 프롬프트를 영상으로 잇는 자리. 스위치만 켜면 돈다.

# 3부. 교재 × 커리큘럼 × 앱

## 3-1. 교재 라인업

| 라인 | 역할 |
|---|---|
| 시냅스 코어 1~6권 | 문법 본줄기. 1권 = 1레벨 = 1시즌(8주). 전 6권으로 TOPIK 5급까지 — 이것이 과정 상한이다 |
| 시냅스 톡 1~2권 | 회화 트랙. 톡1 = TOPIK 1~2급(Lv1~2) · 톡2 = TOPIK 3~4급(Lv3~5). 유호 확정 09-04 로 4권에서 2권으로 압축. ⚠ Lv6 의 5급 구간에는 대응 회화 교재가 없다 |

제작 상태는 이렇다. 문법 6권과 회화 2권 원고가 모두 완성됐고, 원어민 검수는 아직이다. 「검수 완료」라고 쓰지 않는다. **[짓는 중]**

시냅스 톡은 책장에만 있지 않다. 시간표의 원어민 회화 슬롯이 「회화(시냅스 톡)」·「회화(시냅스 코어)」로 편성되어, 책에서 배운 단원을 원어민 앞에서 바로 소리 내는 동선이 된다. **[개원과 함께]**

## 3-2. 상호작용의 원칙 — 커리큘럼이 정본이고, 교재와 앱이 따른다

**1. 커리큘럼 → 교재.** 주차·차시 교안을 국제통용 표준 요목에서 직접 도출하고, 시냅스 코어 각 권의 목차는 그 교안에서 역으로 뽑는다. 교재가 커리큘럼을 기다리는 순환 대기를 끊은 구조 — 자체 교재라서 가능한 설계다.

**2. 교재 ↔ 앱 — 얇은 교재 + 두꺼운 앱.**

- 종이는 수업 코어만 담는다. 1과(1주) 표준 16페이지: 시즌 서사 도입 → 코어 어휘 25~30개 → 문법(몽골어 대조 팁 박스) → 발음 코너(권1~2) 또는 한자어 어원 코너(권3~) → 통합 과업 → 자가 점검(can-do 체크와 「다음에 맞힐 문제」 칸).
- 앱이 워크북 전체를 맡는다. 반복 드릴은 숙제·퀴즈 뱅크가, 채점과 피드백은 첨삭이, 어휘 롱테일은 교재 속 QR 로 연결된 앱 콘텐츠가 맡는다. 어학당식 「교재 + 워크북 2권」을 「얇은 교재 + 앱」으로 대체한 구조라, 하루 30분의 앱 자습까지가 커리큘럼의 정식 일부다.

**3. 커리큘럼 ↔ 앱 — 리듬 동기화.**

- 주간 교안이 그 주의 숙제·퀴즈를 참조 지정하고, 앱이 요일제로 자동 게시하고, 제출이 학습 추적에 쌓여 진도 기록의 축이 된다. 차시 단위 실적은 차시 마감폼이 30초에 봉한다.
- 월 모듈 = 월말 평가 = 월간 배치(칭호·스냅샷·스토리북)가 같은 달력 위에서 돈다.
- 시즌(8주) = 교재 1권 = 시즌 서사 = 8주차 승급 평가. 연 6시즌이 12개월에 정확히 들어가고, 6개월권(26주)이 세 시즌과 맞물린다. 크루 캡스톤 공개일은 반년마다 한 번이다. 교재 도입부의 시즌 스토리 비트와 앱 소식탭의 보스·스토리북은 같은 세계관을 공유한다.
- 단, **가이드가 자라는 축은 커리큘럼 급수와 1:1로 묶지 않는다.** 둘은 주인이 다르다 — **급수는 바깥 세계(TOPIK)가 주는 자**이고 끝이 있다(여행 게이지 여섯 칸이 그린다). **가이드 세 축은 우리 사이에서 나는 자**이고 끝이 없다. 여행 게이지가 지도라면 가이드는 같이 걷는 동행자다.
- 🔑 **그리고 매일 움직이는 층이 반드시 하나 있어야 한다.** 급수는 몇 주에 한 번 움직인다 — 그 사이가 비면 초급생에게 오늘 온 보람이 없다. 가이드 세 축이 그 자리를 맡는다(구 7단계 진화가 하던 일이고, 그것이 커리큘럼과 안 묶여 있던 까닭이다).
- ⚠ 이 자리에 **학생끼리 견주는 문장을 쓰지 않는다.** 구판은 「빠르게 노력한 Lv1 크루가 Lv3 크루보다 단계가 높을 수 있다」로 적었는데, 2026-08-20 확정(「학생끼리 비교하지 않는다」)과 어긋난다.

## 3-3. 남은 배선 [짓는 중]

- 교안 확정 후 앱 데이터화 — 레벨별 퀴즈 증설 포함
- ✅ [09-04 확정] 시냅스 톡 권별 급수 매핑이 정해졌다 — 톡1 = TOPIK 1~2급 · 톡2 = TOPIK 3~4급(4권에서 2권으로 압축). 🔴 Lv6 은 4~5급인데 톡2 가 4급까지라 «5급 구간엔 대응 회화 교재가 없다» — 인쇄물에도 그 공백을 적는다
- 문법 게이트 72문항과 교안 문법 요목의 정합 검사

# 4부. 온라인 강의 연계

스코프 잠금 — 자체 온라인 콘텐츠도 교재·앱과 같이 TOPIK 5급까지다.

형태 확정 — 녹화 강의는 따로 제작하지 않는다. 평일 수업을 녹화해 잘 된 것만 골라 올린다. 스튜디오 별도 제작이 없으니 제작 인건비가 0이다.

## 4-1. 용도 셋

**1. 주말반 = 정규 트랙. [개원과 함께]**

주말반은 평일의 축소판이 아니라 정규 트랙이다. 같은 6권 커리큘럼, 같은 8주 시즌, 같은 승급 기준. 대면 토요일 90분 + 녹화 강의 + 앱 자습의 블렌디드다.

- 가격은 평일과 같은 등급이고, 주말생에게 올액세스는 팔지 않는다. 금액 정본은 급여 정본이다.
- 상담 고지 문구(확정): 「같은 커리큘럼, 대면이 주 1회이고 나머지는 온라인. 온라인을 안 들으면 진도가 따라오지 않습니다」
- 온라인 수강 이력은 앱이 추적한다 — 승급 도달제 판정이 대면 90분만 보고 내려지지 않게. **[이미 돈다]**
- 녹화 강의는 별도 매출을 만들지 않는다(주말반 가격에 포함). 따라서 온라인 강의 수수료의 대상이 아니다 — 그 자리는 유료 온라인 상품이 생길 때 산다.

**2. 결석·혹한 보강. [개원과 함께]**

겨울 모드(12~2월)는 주 5일 중 2일을 온라인·앱 미션으로 전환하는 하이브리드이고, 상품에 내장돼 있다. **영하 40도는 마케팅이 아니라 설계로 받는다.**

**3. 무료 공개분 = 유입 퍼널.**

무료 온라인 강의를 페이스북에 공개하고, 온라인 레벨 테스트(자동 채점 → 몽골어 진단 리포트 → 리드 자동 편입)와 연결해 「무료로 배움 → 내 레벨 확인 → 상담」의 깔때기를 만든다. 관문 쪽인 레벨 테스트와 리드 편입은 이미 코드로 돈다 **[이미 돈다]**. 공개분 제작은 **[개원과 함께]**.

## 4-2. 개원 전 필수 [짓는 중]

수업 녹화 동의 v18.7 — 수집 항목 「수업 영상」, 제공 목적 「주말반 학습 자료」, 법정대리인 동의, 거부 학생 화면 제외, 소급 불가. **동의 없이 녹화 게시는 하지 않는다.**

업로드 플랫폼과 공개 범위는 판정 대기다 **[짓는 중]**. 확정되는 대로 이 절의 표시가 바뀐다.

# 6부. 운영의 본부는 어디인가

**노션은 2026-08-04에 워크스페이스째 삭제됐다.** 앱→노션 자동 동기화 코드도 2026-08-26에 걷었다(179줄). 여기 적혀 있던 여섯 갈래가 지금 어디 있는지를 대신 적는다 — 다섯은 이미 자리를 찾았고, 하나가 열려 있다.

| 갈래 | 노션이 맡기로 했던 것 | 지금 어디 |
|---|---|---|
| 교육 자료 | 커리큘럼 로드맵 Lv1~6 · 수업 계획서 · 문제 은행 · 강사 매뉴얼 | **저장소** — 커리큘럼 정본 · 교수법 매뉴얼 · 교재 6권 골격 · 숙제 뱅크 |

## 정량과 정성이 만나는 자리 — 열려 있는 하나

크루 DB의 설계는 이랬다: 엔진이 정량(포인트·도전 기록·성장 기록·스트릭·급수)을 자동으로 채우고, 사람이 그 위에 인터뷰와 정성 메모를 쌓는다 — 숫자와 이야기가 한 페이지에서 만난다.

**둘 다 살아 있다.** 정량은 `profiles`가 전부 쥐고 있고, 정성은 2026-08-26에 「관찰 한 줄」이 강사의 매일 필수로 확정되면서 매일 쌓인다. **없어진 것은 그 둘이 만나는 «한 페이지»뿐이다.**

그 자리는 새 도구가 아니라 **강사 화면 ②「학생」**(한 사람을 보는 자리)이 받는다. 정량은 엔진이 채우고, 관찰 한 줄이 그 옆에 쌓인다 — 강사가 두 곳을 안 봐도 된다. **[짓는 중]**

⚠ 그때까지 **이탈위험 상·중·하는 계산은 되는데 갈 곳이 없다.** 원장 아침 브리핑이 임시 통로다.

# 7부. 개원까지 남은 순서

엔진과 콘텐츠는 이미 돌고 있다. 남은 것은 「현장과 사람」, 그리고 「학생이 만질 화면」에 몰려 있다.

**1단계 · 개원 전**

- 강사·원장 화면 정본 판정 → 펠트 화면 트랙 → 앱 첫 시작 튜토리얼
- 숙제 첨삭 답장 운영 배포
- 11월 강사 부트캠프 · 12월 파일럿 코호트 — 교실을 엔진에 잇는 첫 벌(관찰 태그와 서클 20분)
- 입소 계약서와 상담 도구 / 온라인 결제와 납부 알림 / 인사카드·온보딩·업무 루틴
- 출석 방식 최종 판정 / 굿즈 초도 제작 / SOP 인쇄 · CCTV · 구급함
- 수업 녹화 동의 v18.7 수취 / 업로드 플랫폼과 공개 범위 확정

**2단계 · 개원 후 1개월**

- 재등록 D-단계 시나리오 / 시험 운영 체크리스트 정착 / 콘텐츠 캘린더 가동 / 메신저 자동 응대

**3단계 · 개원 후 3개월**

- 강좌·캠페인 수익성 분석 고도화 / 포인트 경제 수치 확정(운영 검증) / 교안 앱 데이터화

파일럿은 2027-02-11에 2주 무료로 시작해 2027-02-25 정식 개원으로 이어진다. 첫 시즌은 유료 구간이 6주라, 매출 계산을 정상 시즌과 같게 잡으면 안 된다.
