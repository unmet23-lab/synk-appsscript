# SYNK LAB 주간 교안 양식

한 주 5차시를 한 장으로. 월요일 아침에 앱이 만들어 둔 초안을 열어, 강사 몫만 채웁니다.

## 30초 안에 찾으실 것

- 초안이 어디 있나 → **1. 월요일 아침에 와 있습니다**
- 이 칸에 뭘 적나 → **3. 열네 칸**
- 다 채우면 어떻게 생겼나 → **5. 견본 · Lv1 1주차**

수업 규칙 = 그릇(90분을 어떻게 쓸지) · 주간 교안 = 내용(그 안에 무엇을 담을지). 1시즌 = 8주 = 교안 8장 = 40차시.

---

# 1. 월요일 아침에 와 있습니다

매주 월요일 아침, 앱이 **반별로 교안 초안 문서를 만들어 Drive 폴더 `SYNK_교안초안`에 넣습니다.** 백지에서 시작하지 않습니다.

**앱이 이미 채워 놓는 것**

| 칸 | 앱이 넣는 값 |
|---|---|
| 머리 | 기간 · 반 · 인원 · 담당 강사 · 몇 주차인지 |
| 지난주 이월 | 마감폼에 「이월」로 찍힌 항목 (이번 주 첫 차시 앞 5분) |
| 지난주 배운 것 | 마감폼 기록에서 |
| 9. 예상 오류 | 3주차부터 — 최근 21일 실측 「오류 톱10」 |
| 12. 지명 계획 | 2주차부터 — 발화 지수 하위 3명 |
| 6. 소그룹 과업 | 차시별 추천 ID (바꿔도 됩니다) |
| 조 편성 | 조·역할·3라운드 짝·오늘 정밀 청취 조 |

같은 문서가 이미 있으면 앱은 다시 만들지 않습니다. 강사가 쓴 것을 덮어쓰지 않는다는 뜻입니다.

**나머지가 강사 몫입니다.**

- 작성 시간은 30분을 넘기지 않습니다. **완벽한 교안보다 채워진 교안이 낫습니다.**
- 해당 없는 칸은 "해당 없음"이라고 적습니다. 빈칸은 "안 정했다"와 "필요 없다"를 구분하지 못합니다.
- 다음 시즌에 같은 레벨을 맡으면 그대로 재사용합니다. 고칠 곳만 고쳐 씁니다.
- 주말반은 토 1차시 + 녹화 강의입니다. 6번 차시표는 토요일 한 행만 채우고, 나머지는 녹화 강의와 앱 자습이 메웁니다.
- 초안이 아직 안 나오는 때(부트캠프·시즌 시작 전)에는 3장 열네 칸을 그대로 문서에 옮겨 씁니다.
- 제출처와 마감 시각은 반 배정 때 원장이 알려 줍니다. 제출은 문서 링크를 붙여넣는 방식입니다.

교안 제출 여부는 시즌 등급 심사의 「자격·성장」 항목에 반영됩니다(배점은 급여 정본 7장). ⚠ 이 항목의 집계는 **수동**입니다 — 앱이 자동으로 세지 않습니다. 안 챙기면 0점이 아니라 «기록 없음»으로 남으니, 제출한 뒤 원장에게 링크를 전달하는 데까지가 한 벌입니다.

---

# 2. 빠뜨리면 안 되는 세 칸

**2번 — 별표는 반드시 하나.**
진도가 밀리면 무언가는 버려야 합니다. 무엇을 버릴지 강사가 그때그때 정하면 반마다 다른 것이 버려집니다. 8주차에 A반은 되고 B반은 안 되는 항목이 생기고, **학생들은 그걸 서로 비교해서 압니다.** 별표가 둘 이상이면 이 장치는 그 자리에서 무력해집니다.

**13번 — 더 다질 학생 이름을 적습니다.**
이름을 적는 순간 다음 주 계획이 생깁니다. 적지 않으면 그 학생은 조용한 채로 시즌을 보내고, 어느 날 안 나옵니다. 이게 재등록률로 이어집니다.

**14번 — 수업 끝나고 바로.**
교안은 한 번 쓰고 버리는 게 아닙니다. 같은 레벨을 다시 맡으면 그대로 꺼내 쓰는 자산입니다. 수업이 끝난 직후 3분만 적어두면 다음 시즌에는 15분 만에 교안이 완성됩니다. 안 적으면 매 시즌 처음부터 다시 씁니다.

---

# 3. 열네 칸

머리 칸(레벨 · 교재 권·과 · 담당 · 반 · 기간 · 지난주 이월)은 앱 초안이 채워 옵니다. 아래 열넷이 강사 몫입니다.

### 1. 이번 주 목표 — "…할 수 있다" 한 줄

매 차시 칠판 왼쪽에 **그대로** 씁니다. 자기 말로 바꾸면 반마다 도달 기준이 달라집니다.
예) "-는데를 안다"가 아니라 **"-는데로 이유를 말할 수 있다"**

### 2. 문법 — 2개 (상한 3개)

각각 예문 하나씩. 예문은 학생 이름·동네·좋아하는 것으로. 차시당 새 문법은 1개까지.
**별표는 하나만.** 진도가 밀려도 이것만은 다룹니다(2장).

### 3. 어휘 — 주제 1개, 차시당 7개 이하

주제 한 줄 + 단어 목록. 그중 **몸짓을 붙일 단어 2개 이상**을 표시합니다.
상한은 차시당 새 어휘 7 + 새 문법 1. 넘치면 「이월」입니다.

### 4. 발음 포인트 — 몽골 학습자 난점

받침 / 경음·격음 / 유음화 / 화계 중에서 이번 주 집중할 것 하나. 그리고 구체적으로 무엇을 어떻게 할지 한 줄.

### 5. 한자어 — Lv3 이상만

어원 묶음 하나. 예) 생(살다) → 생활 · 학생 · 생일

### 6. 차시별 5행 — 두 칸만 채웁니다

| 차시 | ②제시에서 다룰 것 | ④소그룹 과업 |
|---|---|---|
| 1 | 문법① 제시 | T-__ |
| 2 | 문법① 연습 + 확장 | T-__ |
| 3 | 문법② 제시 | T-__ |
| 4 | 문법①② 통합 연습 | T-__ |
| 5 | 주간 산출 과업 + 점검 | T-__ |

오른쪽 열은 앱이 추천 ID를 넣어 옵니다. 바꾸고 싶으면 「소그룹 과업 은행」 T-01~T-20에서 골라 번호만 적습니다.
나머지 블록(①③⑤⑥)은 수업 규칙이 이미 정해 두었으므로 교안에서 다시 쓰지 않습니다. 조 편성·역할·발표 순번도 앱이 짭니다. 그래서 교안이 얇아지고, 강사는 진짜 준비가 필요한 곳에만 시간을 씁니다.

### 7. 시선 목적지 — 차시당 최대 2곳

판서 / 화면 / 교재 중 **둘까지.** 교재를 쓰는 차시 번호를 적습니다(차시당 2회까지).
세 곳이 되는 순간 초급 절반이 쪽수를 찾다가 설명을 놓칩니다.

### 8. 확장 3문항 — 빠른 학생용

③통제연습에서 쓰는 **같은 종이 아래쪽**에 넣습니다. 별도 프린트는 준비 부담 때문에 3주 뒤 사라집니다.
「더 어려운 것」이 아니라 **「같은 문법으로 더 긴 문장」**입니다.

### 9. 예상 오류 + 대응 — 3개

「이렇게 틀릴 것 → 이렇게 잡는다」 세 쌍. 출처가 내 예상인지 앱 오류 톱10인지 표시합니다.

1~2주차에는 직접 예상해서 씁니다. 3주차부터는 앱이 실제 오류를 모아 톱10을 초안에 실어 옵니다. 예상보다 실측이 정확하고, 비원어민 강사에게는 특히 그렇습니다. **예상과 실측이 다르면 실측을 따릅니다.**

미리 적어 두는 이유는 ⑤공유에서 다룰 「교정 하나」를 그 자리에서 고를 수 있기 때문입니다.

### 10. 숙제

차시별 하나 + 주말 하나. 앱 연동은 퀴즈 번호 / AI 첨삭 과제 / 없음 중에 표시합니다.
앱 제출 숙제는 문법 도달·캐릭터 진화가 자동 판정됩니다. 강사가 따로 채점하지 않습니다.

### 11. 준비물

인쇄물 몇 장 · 그림·사진 · 실물 · 음원·영상. 없을 때의 대체 플랜은 수업 규칙 8장 표에 있습니다.

### 12. 이번 주 지명 계획

앱이 발화 지수 하위 3명을 초안에 실어 옵니다. 그 학생들을 **5주차 안에 각 3회** 지명하고, 어느 차시에 할지 적습니다.
정답을 묻지 않고 경험을 묻습니다. 4주차 전이면 "해당 없음".

### 13. 주말 점검 — 목표에 도달했는가

도달 기준 한 줄 + **더 다질 학생 이름** + 다음 주에 어떻게 할지.
(학생 앞에서는 "지금은 실력을 다지는 시간이에요"라고 말합니다. 수업 규칙 2장 규칙 7.)

### 14. 다음에 고칠 것 — 수업 끝나고 바로

잘 된 것 / 안 된 것 / 다음 시즌에 바꿀 것.

# 4. 8주가 어떻게 흐르나

| 주차 | 내용 | 교안에서 달라지는 것 |
|---|---|---|
| 1주 | 조 편성 · 진단 | 9번은 직접 예상 (3차시까지 조 확정) |
| 2주 | | 9번 직접 예상 · 12번에 발화 지수가 뜨기 시작 |
| 3주 | 오류 톱10 발표 | 9번을 앱 톱10에서 옮겨 적음 |
| 4주 | 중간 점검 | 12번 지명 계획 시작 |
| 5주 | | 12번 실행 |
| 6주 | | |
| 7주 | 복습 · 산출 집중 | 새 문법을 넣지 않음 |
| 8주 | 승급 평가 | 5차시가 평가 · 마지막 ⑤는 산출물 전시 |

8주차 5차시가 승급 평가입니다(커리큘럼 정본). 승급 결과는 그 자리에서 말하지 않고 앱이 일괄 발표합니다.

# 5. 견본 — Lv1 · 시즌 1주차

일반적인 예시입니다. 실제 차시 배분은 시냅스 코어 1권 목차를 따릅니다. 담당·반·기간은 반마다 달라 비웠습니다.

**레벨** Lv1 · 시즌 1주차 / 8주 · **교재** 시냅스 코어 1권 1과 · **지난주 이월** 없음(시즌 첫 주)

**1. 목표** "한국어로 이름·나라·직업을 말하고 물을 수 있다"

**2. 문법**
① -이에요/예요 — 저는 학생이에요. **(별표)**
② 은/는 — 저는 몽골 사람이에요.

**3. 어휘** 주제: 자기소개 — 이름 · 나라 · 사람 · 학생 · 선생님 · 친구 · 직업
몸짓: 안녕하세요(인사 동작) · 반갑습니다(악수)

**4. 발음** ㅓ/ㅗ 구별 — 최소 대립쌍 연습(어/오 · 거기/고기)

**5. 한자어** 해당 없음 (Lv1)

**6. 차시별**

| 차시 | ②제시 | ④소그룹 |
|---|---|---|
| 1 | -이에요/예요 제시 | T-01 |
| 2 | -이에요/예요 연습·확장 | T-01 (소재: 우리 조) |
| 3 | 은/는 제시 | T-20 (질문은 -이에요?) |
| 4 | ①② 통합 연습 | T-01 (소재: 유명인) |
| 5 | 주간 산출 — 우리 조 소개표 | T-01 (진짜 정보) |

**7. 시선** 판서 + 교재 / 교재 쓰는 차시: 1 · 3

**8. 확장**
① 저는 몽골 사람이에요. 지금은 학생이에요. (두 문장 잇기)
② 가족 한 명을 두 문장으로 소개
③ 짝의 정보를 "○○ 씨는 …이에요"로 소개

**9. 예상 오류** (출처: 내 예상)
① 모음 뒤에도 "이에요" (친구이에요) → 받침 유무 규칙 재제시 + 짝 대조 연습
② 받침 뒤에 "예요" (학생예요) → ①과 같은 대조 연습으로 묶어서
③ 은/는 선택 (저은) → 받침 유무 규칙을 ①과 같은 틀로 제시

**10. 숙제** 차시별: 자기소개 3문장 쓰기(앱 제출) / 주말: 가족 1명 소개 2문장 / 앱 연동: AI 첨삭 과제

**11. 준비물** 인쇄물 20장 (인물 카드 4장 × 4조 + 스무고개 정답 카드)

**12. 지명** 해당 없음 (4주차 전)

**13. 점검** 도달 기준: 교재를 덮고 자기소개 3문장 (주말에 기입)

**14. 회고** (수업 후 기입)

## 이 문서가 답하지 않는 것

- 90분을 **어떻게** 쓰나 → 「SYNK LAB 강사 수업 규칙」
- ④소그룹 과업 T-01~T-20이 **각각 무엇인가** → 「SYNK LAB 소그룹 과업 은행」
- 「자격·성장」 항목의 **배점** → 「SYNK LAB 급여 인센티브 정본」 7장
- 각 레벨이 **몇 권 몇 과를 언제** 나가나 → 커리큘럼 정본
