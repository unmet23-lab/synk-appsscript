# SYNK LAB 주간 교안 양식

2026-10-02 현행 교육 기준 반영.

한 주5차시를 한 장으로. 담당 강사가 실제 제공표·지난 진도·학생 관찰을 확인해 작성합니다. [오프라인 운영기준](../../../../오프라인_공간설계/오프라인_운영기준_20261002.md)과 그룹30분·공유10분의 강사 규칙을 따릅니다.

## 30초 안에 찾으실 것

- 초안이 어디 있나 → **1. 담당자가 준비합니다**
- 이 칸에 뭘 적나 → **3. 열네 칸**
- 다 채우면 어떻게 생겼나 → **5. 견본 · Lv1 1주차**

수업 규칙 = 그릇(90분을 어떻게 쓸지) · 주간 교안 = 내용(그 안에 무엇을 담을지). 1시즌 = 8주 = 교안 8장 = 40차시.

# 1. 담당자가 준비합니다

매주 시작 전 담당 강사가 실제 제공표·교재·지난 차시 기록을 보고 같은 양식으로 작성하고 지정 경로에 보관합니다. 자동 Drive초안·조 편성·발화 지수·브리핑이 이미 만들어져 있다는 설명은 삭제합니다.

| 머리/참조 | 확인할 내용 |
|---|---|
| 반·기간·담당 | 실제 개설 반·수업일·학생 수와 담당 근무 |
| 지난주 이월 | 실제 미실시/이월 항목,첫 차시 안의 우선 배분 |
| 지난주 배운 것 | 차시 기록과 산출물 |
| 예상 오류 | 예상과 실제 관찰을 구분한 공통 연습 |
| 지명·접점 | 발화 차례·대표 발표·개별 접점의 실제 완료/결석 |
| 과업·조 편성 | ID·실제 출석1~16명 예외표·역할·짝·청취 순환 |

- 주5차시를 기준으로5행을 쓰되 실제 수업 수가 다르면 행과 제공량을 맞춥니다.
- 교안·인쇄/카드 준비·채점·학생 피드백의 실제 시간을 측정해 근무표와 예산에 넣습니다.30분 작성·교사 행정2분을 보장하지 않습니다.
- 해당 없는 칸은「해당 없음」으로 표시하고 다음 시즌에는 검증한 자료를 재사용합니다.
- 제출/검토 담당·보관 경로·마감은 실제 반 배정 때 정합니다. 급여평가 자동 집계를 전제하지 않습니다.
- 토90분+녹화+앱만으로 평일 동등 진도/승급을 보장하는 주말 상품은 개원 판매대상에서 제외합니다. 향후 검증된 별도 상품은 그 실제 제공표에 맞춰 교안을 작성합니다.
- 앱·온라인 개발은 유지하며, 검증된 제출/조회 기능이 준비되면 담당 수동 기록과 일치하는지 확인한 뒤 연결합니다.

# 2. 빠뜨리면 안 되는 세 칸

**2번 — 별표는 반드시 하나.**
진도가 밀리면 무언가는 버려야 합니다. 무엇을 버릴지 강사가 그때그때 정하면 반마다 다른 것이 버려집니다. 8주차에 A반은 되고 B반은 안 되는 항목이 생기고, **학생들은 그걸 서로 비교해서 압니다.** 별표가 둘 이상이면 이 장치는 그 자리에서 무력해집니다.

**13번 — 더 다질 학생 이름을 적습니다.**
이름을 적는 순간 다음 주 계획이 생깁니다. 적지 않으면 그 학생은 조용한 채로 시즌을 보내고, 어느 날 안 나옵니다. 이게 재등록률로 이어집니다.

**14번 — 수업 끝나고 바로.**
교안은 한 번 쓰고 버리는 게 아닙니다. 같은 레벨을 다시 맡으면 그대로 꺼내 쓰는 자산입니다. 수업이 끝난 직후 3분만 적어두면 다음 시즌에는 15분 만에 교안이 완성됩니다. 안 적으면 매 시즌 처음부터 다시 씁니다.

# 3. 열네 칸

머리 칸(레벨·교재 권/과·담당·반·기간·지난주 이월)은 담당 강사가 실제 기록을 보고 채웁니다. 아래 열넷과 실제 출석 조 편성·필요한 도움을 함께 확인합니다.

### 1. 이번 주 목표 — "…할 수 있다" 한 줄

매 차시 칠판 왼쪽에 **그대로** 씁니다. 자기 말로 바꾸면 반마다 도달 기준이 달라집니다.
예) "-는데를 안다"가 아니라 **"-는데로 이유를 말할 수 있다"**

### 2. 문법 — 2개 (상한 3개)

각각 예문 하나씩. 예문은 학생 이름·동네·좋아하는 것으로. 차시당 새 문법은 1개까지.
**별표는 하나만.** 진도가 밀려도 이것만은 다룹니다(2장).

### 3. 어휘 — 주제 1개, 차시당 7개 이하

주제 한 줄 + 단어 목록. 그중 **몸짓을 붙일 단어 2개 이상**을 표시합니다.
상한은 차시당 새 어휘 7 + 새 문법 1. 넘치면 「이월」입니다.

### 4. 발음 포인트 — 몽골 학습자 난점

받침 / 경음·격음 / 유음화 / 화계 중에서 이번 주 집중할 것 하나. 그리고 구체적으로 무엇을 어떻게 할지 한 줄.

### 5. 한자어 — Lv3 이상만

어원 묶음 하나. 예) 생(살다) → 생활 · 학생 · 생일

### 6. 차시별 5행 — 두 칸만 채웁니다

| 차시 | ②제시에서 다룰 것 | ④소그룹 과업 |
|---|---|---|
| 1 | 문법① 제시 | T-__ |
| 2 | 문법① 연습 + 확장 | T-__ |
| 3 | 문법② 제시 | T-__ |
| 4 | 문법①② 통합 연습 | T-__ |
| 5 | 주간 산출 과업 + 점검 | T-__ |

오른쪽 열은 담당 강사가 「소그룹 과업 은행」 T-01~T-20에서 골라 적고, 카드·문장·정보 수를 실제 조원 수에 맞춥니다.
나머지 블록(①③⑤⑥)은 수업 규칙의90분 표를 따릅니다. ④그룹 발화30분과⑤공유10분은 별도입니다. 조 편성·역할·발표 순번·청취 대상은 담당자가 실제 출석1~16명 예외표와 기록으로 정합니다. 자동 편성이 가동 중이라는 전제로 교안을 생략하지 않습니다.

### 7. 시선 목적지 — 차시당 최대 2곳

판서 / 화면 / 교재 중 **둘까지.** 교재를 쓰는 차시 번호를 적습니다(차시당 2회까지).
세 곳이 되는 순간 초급 절반이 쪽수를 찾다가 설명을 놓칩니다.

### 8. 확장 3문항 — 빠른 학생용

③통제연습에서 쓰는 **같은 종이 아래쪽**에 넣습니다. 별도 프린트는 준비 부담 때문에 3주 뒤 사라집니다.
「더 어려운 것」이 아니라 **「같은 문법으로 더 긴 문장」**입니다.

### 9. 예상 오류 + 대응 — 3개

「이렇게 틀릴 것 → 이렇게 돕는다」 세 쌍. 출처가 예상인지 실제 청취/과제 관찰인지 표시합니다.

1~2주차에는 직접 예상하고,3주차부터는 실제 청취·과제에서 확인한 공통 오류를 참고합니다. 자동 오류 톱10을 전제하지 않습니다. **예상과 실제 관찰이 다르면 확인한 관찰을 우선합니다.**

미리 적어 두는 이유는 ⑤공유에서 다룰 「교정 하나」를 그 자리에서 고를 수 있기 때문입니다.

### 10. 숙제

차시별 하나와 필요한 주말 복습을 정합니다. 검증된 앱 과제/퀴즈·담임 피드백·종이/파일 대안 중 제공 경로를 표시합니다. 숙제 제출만으로 문법 도달이나 승급이 자동 판정된다고 안내하지 않습니다. 실제 수행·채점·피드백 담당과 시간을 확보합니다.

### 11. 준비물

인쇄물 몇 장 · 그림·사진 · 실물 · 음원·영상. 없을 때의 대체 플랜은 수업 규칙 8장 표에 있습니다.

### 12. 이번 주 지명 계획

담임이 실제 발화·차례 기록에서 도움이 필요한 학생을 확인합니다.5주차까지 추가 발화 차례를 배정하고 어느 차시에 할지 적습니다. 자동 발화 지수/하위3명 명단을 전제하지 않습니다. 대표 발표·개별 접점은 순번표에서 별도 완료 확인합니다.
정답을 묻지 않고 경험을 묻습니다. 4주차 전이면 "해당 없음".

### 13. 주말 점검 — 목표에 도달했는가

도달 기준 한 줄 + **더 다질 학생 이름** + 다음 주에 어떻게 할지.
(학생 앞에서는 "지금은 실력을 다지는 시간이에요"라고 말합니다. 수업 규칙 2장 규칙 7.)

### 14. 다음에 고칠 것 — 수업 끝나고 바로

잘 된 것 / 안 된 것 / 다음 시즌에 바꿀 것.

# 4. 8주가 어떻게 흐르나

| 주차 | 내용 | 교안에서 달라지는 것 |
|---|---|---|
| 1주 | 조 편성 · 진단 | 9번은 직접 예상 (3차시까지 조 확정) |
| 2주 | 발화 기회 확인 | 9번 예상과 실제 관찰 · 12번 필요 학생 기록 |
| 3주 | 공통 오류 연습 | 9번을 실제 청취/과제 기록에서 정함 |
| 4주 | 중간 점검 | 12번 지명 계획 시작 |
| 5주 | | 12번 실행 |
| 6주 | | |
| 7주 | 복습 · 산출 집중 | 새 문법을 넣지 않음 |
| 8주 | 승급 평가 | 5차시가 평가 · 마지막 ⑤는 산출물 전시 |

주5차시·40차시 계획에서는8주차5차시를 승급 평가로 잡습니다. 휴업·결석·미실시를 반영한 실제 제공표를 확인합니다. 결과는 채점/검토 후 안내한 개별 경로로 전달하고 앱 자동 일괄 발표를 전제하지 않습니다. 반별 공유는10분 안에서 진행하며 공개 대형행사로 확장하지 않습니다.

# 5. 견본 — Lv1 · 시즌 1주차

일반적인 예시입니다. 실제 차시 배분은 시냅스 코어 1권 목차를 따릅니다. 담당·반·기간은 반마다 달라 비웠습니다.

**레벨** Lv1 · 시즌 1주차 / 8주 · **교재** 시냅스 코어 1권 1과 · **지난주 이월** 없음(시즌 첫 주)

**1. 목표** "한국어로 이름·나라·직업을 말하고 물을 수 있다"

**2. 문법**
① -이에요/예요 — 저는 학생이에요. **(별표)**
② 은/는 — 저는 몽골 사람이에요.

**3. 어휘** 주제: 자기소개 — 이름 · 나라 · 사람 · 학생 · 선생님 · 친구 · 직업
몸짓: 안녕하세요(인사 동작) · 반갑습니다(악수)

**4. 발음** ㅓ/ㅗ 구별 — 최소 대립쌍 연습(어/오 · 거기/고기)

**5. 한자어** 해당 없음 (Lv1)

**6. 차시별**

| 차시 | ②제시 | ④소그룹 |
|---|---|---|
| 1 | -이에요/예요 제시 | T-01 |
| 2 | -이에요/예요 연습·확장 | T-01 (소재: 우리 조) |
| 3 | 은/는 제시 | T-20 (질문은 -이에요?) |
| 4 | ①② 통합 연습 | T-01 (소재: 유명인) |
| 5 | 주간 산출 — 우리 조 소개표 | T-01 (진짜 정보) |

**7. 시선** 판서 + 교재 / 교재 쓰는 차시: 1 · 3

**8. 확장**
① 저는 몽골 사람이에요. 지금은 학생이에요. (두 문장 잇기)
② 가족 한 명을 두 문장으로 소개
③ 짝의 정보를 "○○ 씨는 …이에요"로 소개

**9. 예상 오류** (출처: 내 예상)
① 모음 뒤에도 "이에요" (친구이에요) → 받침 유무 규칙 재제시 + 짝 대조 연습
② 받침 뒤에 "예요" (학생예요) → ①과 같은 대조 연습으로 묶어서
③ 은/는 선택 (저은) → 받침 유무 규칙을 ①과 같은 틀로 제시

**10. 숙제** 차시별: 자기소개3문장 쓰기 / 주말: 가족1명 소개2문장 / 제공: 검증된 앱 또는 종이/파일,담임 확인·피드백

**11. 준비물** 16명일 때 인물 카드4장×4조+맞히기 정답 카드. 실제 출석과 조 수에 맞춰 수량을 조정하고 예비본·보관 위치를 확인

**12. 지명** 해당 없음 (4주차 전)

**13. 점검** 도달 기준: 교재를 덮고 자기소개 3문장 (주말에 기입)

**14. 회고** (수업 후 기입)
