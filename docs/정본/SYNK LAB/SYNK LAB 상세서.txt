한 줄 정체성
한국어 실력만 가르치는 학원이 아니라, 학습 목적과 실제 경험과 성장
기록을 함께 연결하는 교육 시스템. 그룹의 코어 엔진이자 현금흐름의
원천. 여는 순서에서 「지금 여는 것」 칸에 홀로 들어 있는 브랜드 —
회사가 지금 열어 둔 유일한 얼굴이다(기업마스터 제4조).


◆ 뼈대 — 4영역이 사이클·철학·시그니처와 1:1:1:1

  영역        사이클       철학                시그니처
  Language    Learn        몸이 깨어날 때      K컬처 워밍업
  Path        Plan         목적이 먼저         나침반 세션·드림맵
  Project     Experience   AI가 대체하기 어려운 사람   싱크 크루
  Record      Record       실질적 결과         싱크 포트폴리오

  이 표가 SYNK 전체의 정리축이다. 어떤 기획이든 이 네 줄 중
  어디에 속하는지부터 정하면 절반은 끝난다.
  Path에는 유학·취업·진학 로드맵이 포함된다(구 SYNK ABROAD를
  조직 폐기하고 기능만 흡수). 유학 컨설팅은 별도 회사가 아니라
  LAB Path 위에서 자라는 두 번째 매출 축이다.

◆ 커리큘럼과 교재

  - ★ 레벨과 권은 **다른 축이다**(v1.3에서 분리 — 섞으면 아래
    두 줄이 서로를 부정한다).
      · 레벨 사다리(요목 축) = SYNK Lv1~6 = TOPIK 1~5급 =
        CEFR A1~C1. 레벨별 can-do·어휘 누적 사다리
        (국제통용 표준)·문법 요목·평가 루브릭까지 설계 완료.
        이건 "무엇을 가르치는가"의 눈금이다.
      · 교재 권 대응(콘텐츠 축) = 권1·2=1·2급 / 권3·4=2~3급 /
        권5=4급 / 권6=4급 완성+5급 선별. **6권 완주 = 4급 확실·
        5급 도전선**이다. 이건 "우리가 만든 것이 어디까지
        데려다주는가"의 눈금이다.
      → 그러므로 "1권 = 1레벨 = TOPIK 1급"은 틀린 읽기다.
        1권 = 1시즌 8주(진도 단위)이지 1급 = 1권이 아니다.
        정본 대응표 = repo docs/교재_6권_목차골격_v1.md ①표.
  - ⚠ 스코프 잠금(2026-08-04 갱신): 자체 콘텐츠(교재·커리큘럼·
    온라인·앱)는 TOPIK 5급까지이고 6급 반은 열지 않는다 — 전 6권이
    자체 교재 안에 들어온다. 구 "코어 N권 = TOPIK N급" 1:1 대응과
    "6급 = 외부 전문 교재 마스터 트랙"은 둘 다 폐기.
    대외 문구는 "정규 과정 Lv1~6 전 구간을 자체 교재 시냅스 코어
    6권으로 완주"가 공식 방향(상한 5급 — 한국 학부 입학선이 3급,
    졸업·전공선이 4급이라 실수요 위쪽을 덮는다).
  - 진도 구조: 1권 = 1시즌 8주 = 40차시(8주차 5차시가 승급 평가).
    연 6시즌 = 48주 수업 + 휴업 4주 → 6권 1회전 = 12개월 고정.
    승급은 도달제 — "8주면 몇 급" 류 기간 단정은 상담·광고 금지.
  - 교재 실제 진행: 시냅스 코어 6권 골격·요목 확정 / 권1 원고
    완성(원어민 검수를 앞두고 있음) / 권2~6 집필 중 / 회화
    시냅스 톡 4권은 설계 단계. 대외 문서에 "6권 완성"으로
    쓰지 않는다.
  - 평가: 첫날 레벨테스트로 시작 위치 배정 → 매달 월말 평가 →
    월간 리포트카드(숫자+서술) → 시즌 포트폴리오로 누적.

     500 한도 때문에 있었는데, 그 근거는 Glide 와 함께 죽었다 —
     출석 방식 판정은 새 스택 기준으로 다시 세운다.


◆ 돈 — 재무 정본 = 「SYNK LAB 급여 인센티브 정본.txt」 (항상 최신판)

  이 문서는 재무 숫자를 복사하지 않는다. 비용·BEP·ARPU·배분의
  정본은 전부 급여 정본 0~4장이고, 여기는 뼈대만 남긴다.

     좌석        384석 (평일 256 + 주말 128) · 전 직원 13명
     고정비      월 5,065만₮ (임대 실계약가 1,500만₮ 확정 반영)
     손익분기    재원생 119명 = 좌석의 31%

  읽는 법: 좌석의 31%만 채우면 손익분기다. 3실 시절(288석 ·
  좌석 대비 41%)보다 빈자리 여유가 커진 것이 이번 개정의
  핵심 변화다 — 주말반이 정규 트랙이 되며 단가가 올라 고정비
  증가를 상쇄했다(급여 정본 0장·4장).

  가격 지형: 세종학당 무료(대기열) / 로컬 13~28만₮ /
  SYNK 42~69만₮ — 시장 최고가. 가격이 아니라 속도·성과·시스템
  으로 싸운다.

  ⚠ 남은 최대 위험은 매출이 아니라 0원으로 계상한 법정 비용
    (사회보험 13%·외국인 고용부담금)의 실제 면제 확인 —
    개원 전 최우선 서면 확인 과제(급여 정본 12장).

  [재산정 대기] 개원 조건 현금 · 만석 도달 시점 · 가격 표기 —
    4실 384석 기준으로 아직 재산정하지 않았다.


◆ 고객 — 누구에게 파는가

  타겟 명문화: 상위 20~25% 소득 가구의 청소년 + 목적 확실한
  성인. 중위소득층은 고객이 아니라 세종학당의 몫.
  - 페르소나 A 청소년: 팬덤이 조르고 부모가 승인(한국과 역방향).
    지불자는 부모, 월 42만₮ = 가구소득의 10~12%. 퍼널 이원화 —
    자녀용 후킹(틱톡·챌린지·무료 위성 체험) + 부모용 승인 자료
    (TOPIK 성과·안전·통학, 몽골어).
  - 페르소나 B 성인: 가격을 투자수익으로 계산. E-9 쿼터 축소를
    감안해 동기를 D-4/D-2 어학연수·E-7·한국계 기업·K컬처
    정체성으로 분산.
  - 차강사르 = 순증 0의 수성기이자 친족 구전 시즌.


◆ 학생 유지 장치

  - 장학 4종(대외 표기는 '매월 선정', 인원은 내부 문서만) +
    포인트 상점 + 한정판 굿즈(장학 예산과 분리).
  - 신입 14~45일 리텐션 위험 구간을 앱이 자동 추적.
  - 이탈·전환율·재등록은 엔진이 자동 계측(경영계기판).


◆ 개원 전 필수 게이트 — 수업 녹화 동의 v18.7

  평일 수업을 녹화해 주말반 학습 자료로 제공하는 구조는 현행
  동의 v18.6(수집 「목소리만」·제3자 제공 「없음」)의 범위 밖이다.
  이 시스템의 설계 원칙은 소급 동의 불가 — 녹화를 시작한 뒤에
  받은 동의로는 그 이전 영상을 못 쓴다. 따라서 첫 학생 등록
  전에 동의 문항을 v18.7로 올려야 한다.

    · 수집 범위에 「수업 영상(모습 포함)」 추가
    · 제공 범위에 「같은 학원 주말반 수강생에게 학습 자료로
      제공」 명시
    · 미성년자는 법정대리인 동의
    · 거부 학생이 화면에 안 나오는 운영 규칙
      (자리 배치 / 카메라 각도 / 편집 시 제외)

  지금은 재원생 0명이라 이 수정 비용이 0이다.
  상세 = 급여 정본 8-2장·12장 1번.
