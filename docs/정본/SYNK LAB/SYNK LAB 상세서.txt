# SYNK LAB 상세서

소개서가 «안 다루는» 것을 적는 내부 문서 — 원장의 머릿속 백업본.

**SYNK LAB이 무엇인가** — 한국어 학습 목적과 실제 경험·성장 기록을 연결하는 교육 사업이다. 울란바토르 오프라인은 개원 준비 중이며 현재 현금흐름이 확보된 학원으로 설명하지 않는다. SYNK의 LAB·SHIFT·PULSE·PATH 역할과 플랫폼/앱의 구현 상태는 현행 사업계획과 담당 원문을 따르고 회사 전체를 LAB 하나로 축소하지 않는다.

**30초 안에 찾을 것 셋**

- 좌석·슬롯·정원·반 이름 → 「수업 구조 — 축과 위성」
- 비용·가격과 손익 입력 → 「돈 — 견적과 손익을 함께 연결한다」. 공개 가격·새 총예산은 미확정이며 급여 정본0~4장의 과거 모델은 확정 손익이 아니다.
- 아직 안 닫힌 것 → 바로 아래 「지금 못 답하는 것」

**현행 기준 — 2026-10-02.** [오프라인 운영 기준](../../오프라인_공간설계/오프라인_운영기준_20261002.md)을 따른다. 실제 공간·임대·개원일·채용 인원은 미확정이다. 옛 Apps Script 학원 운영 코드는 삭제됐으며 과거 `[이미 돈다]` 표기는 현재 서비스 완료 증거가 아니다.

- `[운영 방향]` 사용자 선택과 상품 설계. 실제 제공 시간·담당·비용을 확정해야 한다.
- `[준비 중]` 원문·시안·일부 구현이 있으나 학원 실운영 검증 전이다.
- `[별도 검토]` 초기 모집과 기본 혜택에 포함하지 않으며 공급 검증 뒤 검토한다.

현재 개원과 모집은 준비 중이다. 재원·납부·성과의 실제 기록은 별도로 확인하며 과거 학생0명 기록을 최신 실측으로 대신하지 않는다.

## 2. 소개서와의 분담

이 문서와 「SYNK LAB 소개서」는 운영 범위를 공유하되 독자가 다르다. 소개서는 학습 장면·강사 방향·학생과 보호자의 질문을 대외 문장으로 설명하고, 이 문서는 실제 제공 조건을 관리한다. 소개서의 과거 연구 수치는 원문·적용 범위를 다시 대조하기 전 대외 효과 근거로 쓰지 않는다.

- **여기만 있는 것** — 재무 뼈대 · 좌석·단계 개방 · 반 이름 3층 · 앱 기능군 · 페르소나·소득분위 · 녹화 동의 관문 · 열린 결정 · 정본 지도
- **함께 맞출 블록** — 교재 진행 상태 · 4영역 사이클 · 한국어16명/4인4조 방향 · 신청형25명 무료 댄스 · 예약 자습 · 레벨↔급 대응 · 기록/부모 보고의 실제 제공 방식 · 승급 도달제. 주말 녹화 동등진도와 자동화 완료 설명은 현행 기본 상품에서 제외한다.

교집합에서는 **이 문서가 원장**이고 소개서가 대외 문장으로 옮겨 적는다. 한쪽만 고치면 대외 문서가 거짓말이 된다.

## 4. 현재 개원 구조

### ① 초기 모집은 실제 공급할 정규 한국어 수업부터 `[운영 방향]`

한국어 수업은 16명·90분을 설계 기준으로 두고 방별 실제 교대 시간과 근무표를 확정한다. 토요일90분+평일 녹화로 평일과 같은 진도·승급을 제공하는 주말 상품은 초기 모집에서 제외한다. 영상·과제·말하기·피드백·누락 대체와 접근권한을 검증한 뒤 별도 상품으로 검토한다. 별도 스튜디오 촬영이 없더라도 선별·편집·동의 확인·업로드 노동은 남는다.

### ② 반 이름 3층 분리 `[운영 방향]`

| 층 | 무엇 | 제공 조건 |
|---|---|---|
| 운영 키 | 반·담당·실제 시간표를 연결하는 내부 식별자 | 현재 운영 도구에서 중복 없는 방식 확정 |
| 문패 | 교실 안내 이름 | 실제 방 위치·수업 방향 확정 후 제작 |
| 표시명 | 학생들이 정하는 반 이름 | 반별 작은 작명/발표와 기록으로 진행. 전 기수 집합 행사와 앱 자동 반영을 보장하지 않음 |

### ③ 단계 개설과 가변 교실 `[운영 방향]`

강의실4개를 유지하되 A+B는 닫으면 각16석 한국어 교실, 열면 신청25명 댄스 공간으로 검토한다. 실제 개설 반 수는 모집·교사·준비/복구·공간 적합성을 확인해 정한다. 옛12→18→24반/384석 모델과 자동 시간표 전환을 현재 판매 좌석 또는 구현 완료로 쓰지 않는다. 임대료와 공과금은 실제 통계약 범위·개시일로 계산하며 방을 늦게 열었다고 자동 절감하지 않는다.

## 5. 수업 구조 — 축과 위성

공간은 아직 정하지 않았다. A+B 가변안, C/D, 사무실6~8개 개인 자리, 상담/iPad·VR, 포토/음료, 남녀 화장실 기능을 함께 검토한다. 전체 전용 약102~104평은 비교 프로그램이고 확정 임대 면적·정원이 아니다. 전체 3D와 XLSX의 이전6안은 가변안으로 재견적·상세화해야 한다.

### 축 — 정규 한국어 `[운영 방향]`

- 개인 책상16석·90분은 설계 목표다. 실제 가구 배치·조별 활동·강사 접근·환기/피난과 교대를 확인한 뒤 모집 정원을 안내하며, 조는 실제 출석 인원에 맞춰 편성한다.
- 시간표·개설 반·현재 재학생·출결·보강/재개는 담당자가 현행 운영 도구에 기록한다. 앱 자동 편성/집계는 실사용 검증 전 완료로 안내하지 않는다.
- 옛11·14·15:30·18시 슬롯은 참고 이력이다. 14시90분 수업과15:30반 사이0분 교대를 그대로 개원표에 쓰지 않는다.
- 방별 종료·교대·가구 이동·댄스·복구·대기·상담/자습을 넣은 실제 주간표에서 판매 가능한 좌석을 계산한다.

### 위성 — 신청형 무료 문화수업 `[운영 방향]`

댄스는 신청한25명 정원의 무료 문화수업으로 유지한다. A+B를 여는 방향으로 설계하고, 초기에는 다른 한국어 수업과 음악 시간을 분리하는 안을 우선 비교한다. 회차·연령·예약 대상/취소·대기자와 담당 근무를 확정해 제공표에 적는다. 학생 전원이 매 수업 앞뒤에 함께 춤추거나10·13·17시마다 자유롭게 입장하는 상품은 운영하지 않는다.

학습 출결/성적 평가와 예약 명단·실입실 인원 확인은 구분한다. 원어민 회화·글로벌 영어는 확보된 강사·공간·시간을 가진 등록 구성에서만 안내한다. 보컬·뷰티는 상시 개원 편성에서 제외하며 별도 워크숍의 담당·회차·장비·비용을 먼저 확정한다. 추가 채용0명이나 모든 위성 슬롯 개설을 먼저 약속하지 않는다. 짧은 K컬처 워밍업은 각 한국어반의 수업 안에서 할 수 있는 크기로 설계하며25명 댄스와 별개다.

### 반별 발표와 예약 자습

반 이름 정하기·작은 발표·프로젝트 공유는 각 반의 수업 범위에서 진행한다. 토13시 두 기수 전원 집합·정례 학부모 대형 발표회는 내부 기본 혜택에서 제외한다. 별도 행사 수요가 있으면 출연/관람 인원·감독·현장 적합성과 대관비를 따로 검토한다.

빈 강의실 예약 자습은 하루 약2~3시간을 예상해 시간표를 검토한다. 실제 빈 시간·좌석·감독자·충전/인터넷·마감이 확보된 회차만 공개하며 매일 또는 상시 사용을 보장하지 않는다. 전용 라운지·자습실은 만들지 않는다. 준비된 음료·다과는 예약 자습 운영 중 안내한 범위로 제공하며 상시/무제한 스낵바는 약속하지 않는다.

### 겨울 운영 `[준비 중]`

온라인 자료·앱 미션은 실제 공급·피드백·권한·학생 기기와 회선을 검증해 활용한다. 주말 녹화 상품이 겨울 학습을 자동 충당하거나 주5일 중2일 온라인 전환이 이미 제공된다고 안내하지 않는다. 통학·결석/보강·예외 절차는 실제 겨울 시간표와 계약에 맞춘다.

## 6. 커리큘럼과 교재

### ★ 레벨과 권은 다른 축이다

섞으면 아래 두 줄이 서로를 부정한다.

- **레벨 사다리(요목 축)** = SYNK Lv1~6 = TOPIK 1~5급 = CEFR A1~C1. 레벨별 can-do·어휘 누적 사다리(국제통용 표준)·문법 요목·평가 루브릭까지 설계를 마쳤다. 이건 "무엇을 가르치는가"의 눈금이다.
- **교재 권 대응(콘텐츠 축)** = 실제 원고가 다루는 범위다. 현재 레벨·TOPIK·CEFR·시냅스 코어/톡 대응은 `docs/커리큘럼_정본_v1.md` §2-1에서 확인한다. 사라진 옛 목차 골격의 표를 최신 원문으로 안내하지 않는다.

한 급이 여러 레벨에 걸치는 것은 설계다. **1권 = 1시즌 8주(진도 단위)**이며 권수와 TOPIK 급수를 일대일로 대응하지 않는다. 실제 목차·단원별 수록 내용과 원어민 검수 상태는 교재 원고에서 확인한다.

### 스코프 잠금

자체 콘텐츠(교재·커리큘럼·온라인·앱)는 **TOPIK 5급까지**이고 6급 반은 열지 않는다. 전 6권이 자체 교재 안에 들어온다. 대외 문구는 "정규 과정 Lv1~6 전 구간을 자체 교재 시냅스 코어 6권으로 완주"가 공식 방향이다.

정규 목표는 TOPIK 4급이고 자체 콘텐츠 상한은 5급이다. 대학·과정별 입학과 졸업 요건은 별도로 확인하며 모든 대학의 공통 급수 요건으로 단정하지 않는다.

**정규 콘텐츠는 12개월 6시즌의 설계다.** 승급은 도달로 정하며 모든 학생의 급수나 도달 시점을 보장하지 않는다. 학생의 실제 재원 기간과 재회전·일시정지/재개는 현행 계약에서 구분한다. 승인된 성과 지원은 열두 달 과정을 마친 성실 참여자가 첫 TOPIK에서 4급 미달일 때 앱 계정·숙제를 포함한 온라인 학습 6개월 무료 연장이다. 한국에 간 뒤에도 같은 조건이며 무기한·오프라인 수업 연장이 아니다. 이 지원을 1년 상한 문구로 취소하지 않는다.

### 진도 구조

1권 = 1시즌8주 = 40차시(8주차5차시는 승급 평가)라는 콘텐츠 설계다. 연6시즌 = 수업48주+휴업4주 = 52주로6권1회전은12개월을 기준으로 둔다. 실제 개원·휴업·수료 일정은 공간과 운영표가 정해진 뒤 공개한다.

승급은 도달제다. "8주면 몇 급" 류 기간 단정은 상담·광고에서 금지한다. 허용은 「정규 과정 = 12개월 6시즌 구성」까지.

어휘는 이원화한다 — 교재 1회전 코어 목표가 누적 약 6,800개이고 표준 사다리의 5급 누적은 8,055개다. 격차는 재회전과 앱 자습이 흡수한다. **교재는 코어, 앱이 롱테일이다.**

### 교재 실제 진행 `[짓는 중]`

문법 시냅스 코어 6권과 회화 시냅스 톡 2권 원고 모두 완성 / 원어민 검수는 아직. 대외 문서에 "검수 완료"로 앞당겨 쓰지 않는다.

### 평가 `[개원과 함께]`

첫날 레벨테스트로 시작 위치 배정 → 매달 월말 평가 → 월간 리포트카드(숫자 + 서술) → 시즌 포트폴리오로 누적.

## 8. 엔진 여덟과 그 위의 것들

| 엔진 | 맡는 역할 |
|---|---|
| **SYNK Core** | 학습 기록과 목표를 바탕으로 지금 필요한 도움을 고른다 |
| **SYNK Loom** | 재질·빛·배치·움직임으로 실제 화면과 장면을 표현한다 |
| **SYNK Vellum** | 확인된 맥락에 맞는 말·안내·몸짓을 사람에게 전달한다 |
| **SYNK Trail** | 목표와 경험, 확인된 이후의 결과를 시간에 따라 잇는다 |
| **SYNK Prism** | 여러 학습 경험에서 반복되는 어려움을 집계해 교육 재료를 개선한다 |
| **SYNK Temper** | 어떤 도움 뒤 무엇이 달라졌는지 조건과 근거를 대조한다 |
| **SYNK Reed** | 음악·소리·방송과 소리가 놓이는 경험의 규격을 맡는다 |
| **SYNK Strata** | 배울 내용·선행 관계·급수·상황을 연결한 학습 지도를 맡는다 |

**SYNK Atlas는 기존 여덟 엔진의 총칭이다.** 그 위에 별도의 판단 시스템을 추가하지 않는다. 각 엔진은 담당 원문·코드의 역할을 맡고, 학생 한 명분의 축적된 이해는 여러 엔진이 만드는 결과 중 하나다.

Reed는 음악과 소리의 층으로 참여하며 개인 청취를 학습자 수집으로 강제하지 않는다. Strata는 사람의 성향이 아니라 배울 내용의 지도를 맡는다. Amber는 Vellum 안의 개념이고 Patina는 Loom 안의 개념이며 별도 엔진으로 세지 않는다.

역할 정의와 실제 구현·배포·효과는 구분한다. Strata는 TOPIK I 지도와 공개 학습 콘텐츠의 소비 연결이 진행됐다. 현재 범위는 [8개 엔진 담당 원문](../../엔진8종_상향설계_v3.md)과 [실물 현황](../../철학_실물현황.md)을 따르며 9월 21일 엔진 지도는 당시 이력이다.


### 세계관 — 「이름 없는 땅」 `[짓는 중]`

이 땅의 것들은 아직 이름이 없어 흐릿하고 조용하다. 한국어로 부르면 또렷해지고 소리가 돌아온다.

학원의 핵심 행동인 말하기가 세계를 바꾸는 행위가 되는 첫시작 시안이다. 학생끼리 비교하기보다 자기 성장을 비추는 방향을 유지한다. 가이드는 말풍선으로 소통하며, 캐릭터·소품의 촉감과 WORLD의 2D 조작 화면은 [현행 디자인](../../../DESIGN.md)을 따른다. 이 시안을 모든 게임과 화면의 공통 규칙으로 확대하지 않는다.

앱 첫 시작 5.4초가 이 세계관을 연다 — 어둠 → 흐린 형체 → 「이곳의 것들은 아직 이름이 없어요」 → 학생이 누름 → 코랄이 번지고 또렷해짐 → 이름이 뜸 → 기호 `<` → 로그인. **주변의 흐린 것 넷은 끝까지 안 또렷해진다**(나머지는 네 말로 또렷해진다). 학생·강사·원장이 같은 화면을 지난다. **학부모에게 이5.4초나 전용 앱3화면을 기본 제공한다고 약속하지 않는다** — 자녀 자료는 권한과 수신자를 확인한 정기 전달 방식으로 준비한다.

시연 실물 = `docs/캐릭터/세계관_첫시작_시연_0826.html`. 이는 8월 26일 시안이며 당시 Loom 트랙 대기를 지금의 공통 착수 조건으로 쓰지 않는다. 현재 WORLD 화면과 우선순위는 제품 원문을 따른다.

### 가이드 선택제 `[콘텐츠 개발 방향 — 실제 연결 검증 후 제공]`

학생이 몽글·까몽·마린 셋 중 자기 가이드를 **고른다.** 셋은 외모가 아니라 «학생을 대하는 방식»으로 갈린다.

| 가이드 | 대하는 방식 |
|---|---|
| 몽글 | 같이 한다 |
| 까몽 | 허세로 가르친다 (잘난 척 · 실은 겁쟁이) |
| 마린 | 임무를 준다 |

- 한 학생에게 가이드는 하나다. **고른 결과 자체가 사람 이해 층의 재료**다(코칭 스타일 선호를 학생이 직접 말한 셈이니까)
- 셋 다 각자의 성격에 맞게 말을 걸고 응원한다. LAB 앱 상주 반응의 말은 말풍선, 소리는 비언어 목소리다. 학습 음성·노래·광고의 승인된 음성 제작까지 금지하는 규칙은 아니다
- 얼굴과 이름을 가진 마스코트는 **셋이 상한**이다(넷째는 개원 후 판정)
- 학생이 수업에서 쓸 한국어 이름을 직접 고르는 방향이다. 실제 선택·저장·호칭과 제공 시점은 검증한 기능을 기준으로 안내한다

### 라디오와 학습 기록의 경계 `[준비 중]`

라디오를 듣거나 공개 채팅을 남긴 사실을 학원 출결·목표·학생 개인정보 수집으로 자동 연결하지 않는다. 실제 방송 상태와 학원에서 제공할 청취/학습 기능은 담당 원문에서 확인한다. 공개 채널 계정은 재학생 식별과 보호자 권한 확인을 대신하지 않는다.

방송의 현재 상태를 이 과거 개원 문서의 완료/미송출 표기로 단정하지 않는다. 학교에서 사용할 음악/콘텐츠의 범위·권한·학생 경험을 실제 제공표에 따로 적는다.

라디오 확정 다섯:

1. 미니퀴즈를 방송 «화면»에서 «채팅»으로 내린다 — 공부하려고 켠 학생에게 정각마다 문제를 들이대면 배경음악이 아니라 수업이 된다
2. DJ는 말하지 않는다 — 효과음만, 가끔씩만
3. DJ 교대를 보이게 한다
4. 「지금 몇 명이 같이 공부 중」을 숫자가 아니라 작은 불빛 몇 개로 — **라디오가 파는 것은 음악이 아니라 혼자가 아니라는 느낌이다**
5. 「이 노래는 SYNK가 만들었습니다」를 화면 구석에 티 안 나게 — 광고가 아니라 증명

## 9. 돈 — 견적과 손익을 함께 연결한다

급여 인센티브 정본의 과거254.5㎡·13명·24반384석 손익모델은 현재 임대·채용·판매 좌석의 증거가 아니다. 공간은 미선정이고 사무실의 상주6~8자리는 전체 채용 인원과 다르다.

현재 비용 입구는 `docs/유지비_BM/학원_개원_예산과_준비기간_20261001.md`와 법인·권리·출시 문서다. 시설/장비, 보증금과 공사 중 임대, 준비 인력, 개발, 실제 월 임대/급여/법정 부담, 복지와 선수금/환불을 월별 현금에 연결한다. A+B 가변안과 변경한 실제 수업 슬롯으로 손익을 재계산해야 한다.

주말반 매출·단가와384석을 기본 판매량에 넣지 않는다. 초기 체험/무료 기간과 첫 유료 수업은 확정 실시일 기준으로 계산한다. 옛2027-02 일정 때문에 첫 시즌 유료6주라고 고정하지 않는다. 가격과 학생의 실제 지불의사도 모집 조건과 파일럿에서 확인한다.

## 10. 고객 — 누구에게 파는가

우선 검토하는 고객은 청소년과 보호자, 학습 목적이 뚜렷한 성인이다. 상위 20~25% 소득 가구라는 기존 시장 가정은 현재 소득 분포·가격·실제 지불의사로 검증해야 하며, 다른 소득층을 일괄 제외하는 확정 모집 조건으로 쓰지 않는다.

### 페르소나 A — 청소년

청소년은 학생의 관심과 보호자의 판단을 함께 확인한다. 과거 월42만₮과 가구소득350~450만₮로 계산한9~12%는 당시 가격 검토 가정이다. 현재 공개 수강료·소득분포·실제 지불의사를 확인한 값이 아니며 개원 가격이나 매출을 확정하는 근거로 쓰지 않는다.

그래서 설득 경로를 둘로 나눈다.

- **아이를 끌어당기는 쪽** — 틱톡·챌린지·무료 위성 체험
- **부모를 납득시키는 쪽** — TOPIK 성과·안전·통학, 전부 몽골어로

### 페르소나 B — 성인

한국 유학·취업 준비·현재 업무·K컬처 등 학생이 직접 밝힌 목적과 준비 조건을 확인한다. 과거 비자 쿼터 조사만으로 현재 수요를 단정하지 않으며 실제 지원 시 자격·일정·비용을 확인한다.

### 차강사르 (몽골 설)

신규가 거의 안 들어오는 달이다. 이 시즌에는 새 학생을 세지 않는다 — **있는 학생을 지키고, 친척이 모이는 자리에서 말이 돌게 한다.**

## 11. 학생 유지 장치

- 승인된 성장 인정·분기 장학·교통 지원·TOPIK 지원/성취 보상,12개월 과잠·진로 최종본·안심 중지를 유지한다. 자격·수량·원가·지급 시점은 학생 복지/장학 규칙과 현행 계약에서 확인한다. 포인트 상점은 기본 혜택에서 제외하고 별도 운영으로 검토한다.
- Google AI Pro 계정 제공은 기본 혜택에서 제외한다. 몽골 계정의 실제 제공 가능성과 원가 확인 전 선결제 유인으로 쓰지 않는다.
- 출결·참여·결석 연락·재등록을 담당자가 확인하며 자동 이탈 경보/경영 계기판이 이미 작동한다고 약속하지 않는다.
- 일시정지/복귀와 승인된6개월 온라인 성과 지원은 개인의 실제 계약/종료일·권한과 연결한다. 새 방이나 무기한 오프라인 연장으로 확대하지 않는다.

## 12. 개원 전 필수 관문 — 촬영·학생 보호

교육용 녹화·제한된 수강생 제공·공개 홍보·YouTube 라이브의 목적과 접근 범위를 구분한다. 과거 동의판 번호나 삭제된 코드의 문항을 현행 동의 완료로 쓰지 않는다. 첫 촬영 전에 실제 사용할 양식·보호자 권한·수집/제공/보관/철회를 확인하며 소급 동의로 과거 촬영을 사용하지 않는다.

- 미성년자의 필요한 법정대리인 동의와 실제 권한을 확인한다.
- 거부 학생은 동등한 수업을 받으며 얼굴·목소리·거울 반사가 촬영/송출되지 않도록 실제 자리·구도를 확인한다.
- 라이브는 사후 편집으로 거부 학생을 제거할 수 없으므로 시작 전에 참여 범위를 확인한다.
- 촬영·선별·동의 확인·업로드 승인·철회/삭제·보관과 백업 처리 담당을 근무표에 넣는다.
- 학생 보호 신고는 원장 외 접수 역할과 대체자를 두며 개원 전에 실제 연락창구를 게시한다. 인물·연락처는 임의로 만들지 않는다.

주말 녹화 상품이 초기 모집에서 제외돼도 교육/프로젝트/홍보 촬영의 필수 보호 조건은 유지한다.

## 13. 현재 유지하는 결정과 제외한 약속

2026-10-02 사용자 요청으로 구조상 공급되지 않는 기본 약속을 삭제하고 현재 운영 범위를 맞췄다. 과거 문서의 일정·자동화·임대/채용 완료는 현행 상태로 승계하지 않는다.

|---|---|
| 강의실4개·개인 책상·사무실6~8자리·로비 라운지 제외 | 실제 매물·실측·근무표·시공 견적 |
| 신청형25명 무료 문화 댄스·A+B 가변 사용 | 예약/인원·전환·감독·음악 시간 분리·현장 적합성 |
| 한국어16명·90분·TOPIK5급까지 자체 콘텐츠 | 실제 개설 반/슬롯·교재/평가 인수 |
