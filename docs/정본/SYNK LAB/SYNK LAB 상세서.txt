한 줄 정체성
한국어 실력만 가르치는 학원이 아니라, 학습 목적과 실제 경험과 성장
기록을 함께 연결하는 교육 시스템. 그룹의 코어 엔진이자 현금흐름의
원천. 여는 순서에서 「지금 여는 것」 칸에 홀로 들어 있는 브랜드 —
회사가 지금 열어 둔 유일한 얼굴이다(기업마스터 제4조).


◆ 뼈대 — 4영역이 사이클·철학·시그니처와 1:1:1:1

  영역        사이클       철학                시그니처
  Language    Learn        몸이 깨어날 때      K컬처 워밍업
  Path        Plan         목적이 먼저         나침반 세션·드림맵
  Project     Experience   AI가 못 하는 사람   싱크 크루
  Record      Record       실질적 결과         싱크 포트폴리오

  이 표가 SYNK 전체의 정리축이다. 어떤 기획이든 이 네 줄 중
  어디에 속하는지부터 정하면 절반은 끝난다.
  Path에는 유학·취업·진학 로드맵이 포함된다(구 SYNK ABROAD를
  조직 폐기하고 기능만 흡수). 유학 컨설팅은 별도 회사가 아니라
  LAB Path 위에서 자라는 두 번째 매출 축이다.


◆ 수업 구조 — 축·위성 모델 (2026-07-19 확정)

  코어(축) = 전 반 동일 정원 16명. 출석·스트릭·레이드·앱 전 기능의 대상.
    - 코어 18반: 평일 12반(3실 × 4슬롯) + 주말 6반(3실 × 2슬롯)
                 전 반 16명 균일 · 정규/집중 구분 없음
    - 좌석 288석 = 평일 192 + 주말 96
    - 코어 슬롯 11:00 · 14:00 · 15:30 · 18:00
    - 3실 병렬 운영, 주말은 토요일만(일요일 휴무 확정)
    - 14:00·15:30 코어 = UB 1부제 학생의 빈 낮을 정조준한
      슬롯(2~3부제 학제의 블루오션)

  위성(리듬) = 댄스·보컬·뷰티·원어민 회화(시냅스 톡/코어)·
    글로벌 영어. 출석 체크 없음, 앱·시트 미등록, 자유 참여.
    학생은 코어 하나를 축으로 앞뒤 위성을 자기 리듬으로 채운다.
    위성은 무료 개방형이라 체험 유입구이자 촬영 무대를 겸한다.

  개원 초는 단계 개방: 코어 전 슬롯 + 위성 2종(댄스·회화)만
  열고, 등록 데이터 확인 후 확장(풀 시간표는 상담실 비전 게시용).

  겨울 모드(12~2월): 주 5일 중 2일을 온라인·앱 미션으로 전환하는
  하이브리드가 상품에 내장돼 있다. 영하 40도는 마케팅이 아니라
  설계로 받는다.


◆ 커리큘럼과 교재

  - 6레벨 커리큘럼 정본 v1: SYNK Lv1~6 = TOPIK 1~6급 = CEFR
    A1~C2. 레벨별 can-do·어휘 누적 사다리(국제통용 표준)·문법
    요목·평가 루브릭까지 설계 완료.
  - ⚠ 스코프 잠금(2026-07-22): 자체 콘텐츠(교재·커리큘럼·온라인·
    앱)는 TOPIK 5급까지. 6급은 외부 전문 교재 마스터 트랙.
    구 "코어 N권 = TOPIK N급" 1:1 대응은 폐기 — 신 권-급 대응표는
    repo docs/교재_6권_목차골격_v1.md ①표(권1·2=1·2급 / 권3·4=
    2~3급 / 권5=4급 / 권6=4급 완성+5급 선별. 6권 완주 = 4급 확실·
    5급 도전선). 대외 문구는 "정규 과정은 5급까지 우리 교재로,
    6급은 전문 교재로 마스터"가 공식 방향.
  - 진도 구조: 1권 = 1시즌 8주 = 40차시(8주차 5차시가 승급 평가).
    연 6시즌 = 48주 수업 + 휴업 4주 → 6권 1회전 = 12개월 고정.
    승급은 도달제 — "8주면 몇 급" 류 기간 단정은 상담·광고 금지.
  - 교재 실제 진행: 시냅스 코어 6권 골격·요목 확정 / 권1 원고
    완성(원어민 검수 중) / 권2~6 집필 중 / 회화 시냅스 톡 4권은
    설계 단계. 대외 문서에 "6권 완성"으로 쓰지 않는다.
  - 평가: 첫날 레벨테스트로 시작 위치 배정 → 매달 월말 평가 →
    월간 리포트카드(숫자+서술) → 시즌 포트폴리오로 누적.


◆ 앱과 게임화 (라이브 v9.50)

  - 몬스터 7단계 진화: 뉴로→스파키→링커→서킷→미엘로→플로우→
    싱크마스터. 진화 임계값은 코드 실측으로 문서화돼 있다.
  - 포인트 경제(검증 완료, 1P≈18.6₮):
    적립 — 출석10 · 정시+5 · 과제15 · 모의고사20 · 월말합격100
           · 분기합격300 · 친구소개500 · 이벤트30
    상점 — 소품200 · 모자/양말600 · 텀블러700 · 반팔800
           · 과잠2,000 · 할인권2,500 · 문화체험5,000
  - 왕관·스트릭·반 전체 레이드·월드 클리어, GPS 출석,
    AI 첨삭(숙제 피드백), AI 스튜디오 기능군, 스토리북.
  - 학부모 화면은 몽골어 완결(고정 템플릿, 번역 API 비의존).
  - 운영 자동화: 새벽 3시 전체 백업(30일 보관)·아침 원장 브리핑
    메일·데이터 이상 감지 가드·포인트 재계산 하루 2회.
  - 제약 1개는 기억할 것: Glide Maker 월 500 업데이트 한도.
    재적이 BEP 구간에 오르면 출석만으로 초과 가능 — 실측 후
    플랜/출석 방식 판정이 개원 전 과제로 걸려 있다.


◆ 돈 — 잠금 숫자 (급여 인센티브 정본 v1.1 · 2026-07-29 기준)

  단계를 둘로 나눠 읽는다. 개원 = 1·2실, 만석 = 3실.

  1) 월 번 — 개원 4,051만₮ / 만석 4,413만₮(약 1,724만원).
     인건비 = 전 직원 11명(원장 2·댄스 1·몽골쌤 6·뷰티 1·보컬 1),
     기본 시급 15,000₮ = 몽골 최저임금 4,714₮의 3.18배.
  2) BEP — 개원 107명 / 만석 117명.
     좌석 대비 가동률 개원 56% / 만석 41%에서 손익분기.
  3) 실효 ARPU — 평일 44.6만₮ / 주말 24.7만₮
     (평일:주말 2:1 믹스 = 37.97만₮).
  4) 좌석 288석(평일 192 + 주말 96).
     만석 매출 월 10,934만₮ · 만석 이익 5,217만₮ ·
     현실 상한(85% 충원) 재적 245명.
  5) 개원 조건 현금 — ⚠ 재산정 대기.
     구 2.4억₮은 번 3,922만₮ 전제라 운영버퍼가 부족하다.

  ⚠ 2026-08-01 갱신 — 구 BM v3 세트(번 3,922만₮ · BEP 85~94명 ·
    좌석 220석 · 정규직 6인+파트 2인 · 실효 ARPU 46.4/42.0만₮ ·
    이론 상한 9,100만₮)는 폐기했다.
    「만석 2028년 중반」도 좌석이 220 → 288석으로 늘어
    만석의 정의가 바뀌었으므로 재추정 대상이다.

  가격 지형: 세종학당 무료(대기열) / 로컬 13~28만₮ /
  SYNK 42~69만₮ — 시장 최고가. 가격이 아니라 속도·성과·시스템
  으로 싸운다(6개월 252만₮ = 한국 취업 첫 달 월급의 절반 논리).

  ⚠ 이 계획의 남은 최대 위험은 매출이 아니라 0원으로 계상한
  법정 비용(사회보험 13%·외국인 고용부담금)의 실제 면제 확인.
  개원 전 최우선 서면 확인 과제.


◆ 고객 — 누구에게 파는가

  타겟 명문화: 상위 20~25% 소득 가구의 청소년 + 목적 확실한
  성인. 중위소득층은 고객이 아니라 세종학당의 몫.
  - 페르소나 A 청소년: 팬덤이 조르고 부모가 승인(한국과 역방향).
    지불자는 부모, 월 42만₮ = 가구소득의 10~12%. 퍼널 이원화 —
    자녀용 후킹(틱톡·챌린지·무료 위성 체험) + 부모용 승인 자료
    (TOPIK 성과·안전·통학, 몽골어).
  - 페르소나 B 성인: 가격을 투자수익으로 계산. E-9 쿼터 축소를
    감안해 동기를 D-4/D-2 어학연수·E-7·한국계 기업·K컬처
    정체성으로 분산.
  - 차강사르 = 순증 0의 수성기이자 친족 구전 시즌.
