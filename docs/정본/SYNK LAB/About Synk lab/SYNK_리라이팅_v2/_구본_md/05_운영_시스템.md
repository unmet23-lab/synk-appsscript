# SYNK 운영 시스템 — 이미 가동 중인 자동화 엔진과 6개 시스템

> 내부 운영진·파트너용 · 운영 인프라의 현재 상태와 오픈 전 구축 계획

---

## 0. 전제 — "만들겠습니다"가 아니라 "돌고 있습니다"

대부분의 신생 학원은 시스템을 약속합니다. SYNK는 시스템을 먼저 만들고 문을 엽니다.

학생 데이터 파이프라인, 매일의 백업, 포인트·성장 게이지 재계산, 원장 아침 브리핑 — 전부 **자체 개발 Apps Script 자동화 엔진(v9.x)** 위에서 이미 자동으로 돌아가고 있습니다. 외부 자동화 구독 없이, 우리 코드로.

이 문서는 두 가지를 명확히 구분합니다. **✅ 이미 가동 중**인 것과, **🔧 오픈 전 구축**할 것.

## ✅ 1. 운영 스택 한눈에 — 데이터가 흐르는 길 

```
[Google Form] 상담 신청
      │  10분마다 자동 수집 · 학생ID 자동 채번
      ▼
[상담 스프레드시트]  상담·수강·납입 원장(原帳)
      │  매일 07:00 자동 동기화 (Layer 1)
      ▼
[profiles DB]  학생 마스터 + 포인트·게이지·급수 계산열
      ├──────────▶ [Glide 학생 앱]  실시간 화면 구성
      │  매주 월 07:00 자동 동기화 (Layer 2)
      ▼
[Notion 크루 DB]  정량(앱 데이터) + 정성(인터뷰·메모) 통합 허브
```

핵심은 **2단 동기화** 구조입니다.

| 구간 | 주기 | 역할 |
|------|------|------|
| **Layer 1** 상담시트 → profiles | 매일 07:00 | 학생 마스터 데이터 갱신. 퇴소자는 앱에서 제외하되 이력은 보존 |
| **Layer 2** profiles → Notion | 매주 월 07:00 | 학생별 업서트(있으면 갱신, 없으면 생성). 엔진은 정량 항목만 쓰고, 노션의 정성 기록은 건드리지 않음 |

그리고 엔진에는 **데이터 사고를 막는 가드**가 내장돼 있습니다.

- **이상 감지 시 자동 보류** — 학생 수가 0이 되거나 30% 넘게 급감하면 덮어쓰기를 멈추고 마지막 정상 상태를 유지, 원장에게 알림.
- **동기화 실패 시 즉시 메일** — 소스 시트에 접근하지 못하면 기존 데이터를 보존하고 원장에게 실패 메일.
- **시크릿 분리 보관** — 외부 연동 토큰은 코드·저장소 밖(스크립트 속성)에 보관. 유출 경로를 원천 차단.

## ✅ 2. 자동화 트리거 달력 — 엔진의 하루·일주일·한 달 

사람이 잊어도 엔진은 잊지 않습니다. 아래 일정이 전부 **현재 자동 실행 중**입니다.

| 주기 | 시각 | 자동으로 하는 일 |
|------|------|------------------|
| 매 10분 | 상시 | 상담 신청 폼 응답 수집 → 상담시트 기입 + 학생ID 채번 |
| 매일 | 03:00 | 전체 데이터 백업 (30일 보관) |
| 매일 | 07:00 | 상담시트 → profiles 동기화 + 생일·상담지연 체크 |
| 매일 | 08:00 | 원장 아침 브리핑 메일 |
| 매일 | 14:00 / 22:00 | 포인트·성장 게이지 재계산 (하루 2회) |
| 매주 월 | 07:00 | profiles → Notion 동기화 + 미납·재등록·시스템 헬스체크 |
| 매월 1일 | 05:00~07:00 | 칭호 부여 · 성장 스냅샷 · 아카이브 |
| 수시 | 이상 감지 시 | 동기화 자동 보류 + 원장 알림 / 실패 시 즉시 메일 |

새벽 3시에 백업이 도는 동안 사람은 잡니다. 그러라고 만든 엔진입니다.

## SYSTEM 1 | 학생 CRM 및 소통 관리

### 1-1. 입학 및 상담 프로세스

문의부터 상담·등록·재등록/이탈까지, 학생의 전 과정을 하나의 파이프라인으로 추적합니다. 데이터 기반(✅)은 이미 깔려 있고, 그 위에 얹을 시나리오(🔧)만 남았습니다.

- **✅ 상담 신청 자동 수집** — Google Form 응답이 10분마다 상담시트로 자동 정렬·기입되고, 학생ID가 자동 채번됩니다. 문의가 새벽에 와도 아침이면 이미 시스템 안에 있습니다.
- **✅ 상담지연 자동 체크** — 매일 07:00, 응답이 늦어지는 상담 건을 엔진이 잡아 원장에게 보고합니다.
- **✅ 심층 상담 설문 고도화** — 레벨·입학 목적·희망 자격증·성격·긴급연락처·희망 대학·유학 가능성.
- **✅ 입소 계약서 + 상담 도구** — 오프라인 브로셔(종이 설명용) + 아이패드 디지털 카탈로그.

### 1-2. 학생 개인 관리
- **✅ 학생 마스터 DB(profiles)** — 이름·반·연락처·보호자 정보·한국어 수준·핵심 비전이 매일 자동 갱신.
- **✅ 이탈위험 신호** — 상담 데이터 기반 위험 표시(상/중/하)가 노션 크루 DB에 자동 반영. 원장·리드크루 전용 화면이며 학생·학부모에게는 노출되지 않습니다.
- **✅ 담당 강사 배정 · 1:1 맞춤 스케줄 문서 · 정기 피드백 폼 · 이탈 분석표**(시기/사유: 수업 퀄리티·유학·금전·동기 저하 등).

### 1-3. 재등록 파이프라인
- **✅ 재등록 예정자 주간 자동 리포트** — 매주 월요일, 엔진이 재등록 대상자를 추려 보고합니다.
- **🔧 D-단계별 시나리오** — D-30 담당 강사 상담 지시 → D-14 1:1 상담 배정+혜택 안내 → D-7 포인트 보너스 안내 → D-Day 미재등록 리스트 → D+7 사유 조사·재유치. 데이터 기반은 이미 있으므로, 시나리오만 얹으면 됩니다.

### 1-4. 학부모 소통 (몽골 현지 특화)
- **✅ 생일 자동 체크** — 매일 아침 엔진이 알려주면, 축하는 사람이 합니다. 역할 분담이 정확합니다.
- **✅ 월간 학습 리포트 발송** — 출석률/성장 변화/강사 코멘트/다음 달 목표. 데이터는 월간 스냅샷으로 이미 쌓이고 있습니다.
- **🔧 분기별 학부모 상담의 날** — 대면·화상 + 유학 진로 상담 연계.
- **🔧 커뮤니티 채널** — 몽골 현지 특성상 **페이스북 메신저 중심**. 학생 전용 방 + 전체 통합 방.

### 2-2. 지출 및 수익성 분석

- **🔧 캠페인별 성과 분석표** — 이벤트·장학금·체험 수업의 유입/전환/ROI 기록.

### 2-3. 핵심 지표
- **✅ 원장 아침 브리핑** — 매일 08:00, 운영 핵심 현황이 메일로 도착합니다.
- **✅ 노션 지표 대시보드** — 월 신규 등록 / 재등록률 / 평균 출석률 / 레벨업 비율 / 채널별 유입.

## SYSTEM 3 | 스마트 출석 및 포인트 리워드

여기가 SYNK 세계관의 심장입니다. 그리고 이 심장은 이미 뛰고 있습니다.

### 3-1. 출석과 성장 엔진
- **✅ 포인트·게이지 자동 재계산** — 매일 2회(14시/22시). 학생 앱의 숫자는 항상 최신입니다.
- **✅ 몬스터 진화 7단계** — 뉴로 → 스파키 → 링커 → 서킷 → 미엘로 → 플로우 → 싱크마스터. 성장이 눈에 보이는 캐릭터로 나타납니다.
- **✅ 왕관·스트릭·칭호** — MVP 왕관·시냅스 왕관, 연속출석 스트릭, 매월 1일 칭호 자동 부여와 성장 스냅샷.
- **✅ QR 출석 현장 동선** — 강의실 앞 QR 스캔 → 출석 기록 → 포인트 적립. 계산 파이프라인은 엔진에 이미 있으므로, 현장 세팅만 남았습니다.
- **✅ 직원·학생 통합 출퇴근 기록** — 학생 출석과 직원 근태를 한 기록기로 통합 관리. 크루 핸드북의 근태 인센티브(완전출근) 산정 근거가 됩니다.

## 7. 학생 앱 — 화면에서 성장이 보인다 ✅

Synk world 앱은 profiles DB를 직접 읽어, 엔진이 하루 2회 갱신한 숫자를 그대로 보여줍니다.

- **홈** — 내 몬스터 현재 단계(뉴로~싱크마스터), 보유 포인트, 연속출석 스트릭, 오늘 수업.
- **성장 현황** — 진화 게이지, 왕관 획득 기록(MVP·시냅스), 월간 리포트카드.
- **포인트 & 리워드** — 보유 포인트 / 적립 내역 / 교환 상점 즉시 교환.
- **출석** — 출석 기록과 이번 달 출석률, 스트릭 현황.

"열심히 하면 좋아진다"는 말은 어느 학원이나 합니다. SYNK에서는 그 말이 매일 앱 화면에 숫자와 캐릭터로 증명됩니다.

## 8. 노션 워크스페이스 「SYNK LAB HQ」 구조

```
SYNK LAB HQ
├─ 운영 관리 — 주간 회의록 / 오늘의 할일 / 직원별 업무 현황판 / 목표 트래커
├─ 학생 관리 — 크루 DB(정량+정성 허브) / 케어 필요 학생 / 재등록 예정자
│              / TOPIK 응시 예정자 / 입시 준비생
├─ 교육 자료 — 커리큘럼 로드맵 Level 1–6 / 수업 계획서 / 문제 은행 / 강사 매뉴얼
├─ 마케팅   — 콘텐츠 캘린더 / SNS 트래커 / 브랜드 에셋 / 광고 기록
├─ 재무     — 월별 손익 / 예산 / 비품 재고
└─ 법무·규정 — 사내 규정 / 계약서 양식 / 개인정보 처리 방침
```

크루 DB는 엔진이 매주 정량 데이터(포인트·왕관·스트릭·급수·몬스터 단계)를 자동으로 채우고, 사람은 그 위에 인터뷰·정성 메모를 쌓습니다. 숫자와 이야기가 한 페이지에서 만나는 구조입니다.
