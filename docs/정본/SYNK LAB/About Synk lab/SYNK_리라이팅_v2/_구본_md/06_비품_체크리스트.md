# SYNK LAB 비품 체크리스트

> 내부 실무용 — 오픈 준비 구매·조달 기준 문서. 담당자는 구매 시 체크박스와 조달·비고란을 갱신할 것.

## 우선순위 태그

| 태그 | 기준 |
|------|------|
| **P0** | 오픈 전 필수 — 이것 없이는 첫 수업·첫 상담이 안 돌아간다 |
| **P1** | 오픈 전 권장 — 첫인상과 운영 완성도를 좌우한다 |
| **P2** | 오픈 후 1~3개월 — 운영 데이터를 보고 결정해도 늦지 않다 |

원칙은 하나다. **P0가 100% 채워지기 전에는 P1·P2에 예산을 쓰지 않는다.**

## 운영 메모

1. **P0 완료 확인이 오픈 조건이다.** 오픈 D-7에 P0 전 항목 최종 점검을 한 번 더 돈다.
2. 구매 즉시 이 문서의 체크박스와 조달·비고란을 갱신한다 — 기억은 휘발되고 기록은 남는다.
3. 소모품(A4·간식·차·휴지·소독제)은 보충 담당과 점검 주기를 정해 리스트 밖에서도 굴러가게 한다.
4. 굿즈 초도 물량·재제작 시점은 포인트 상점 교환 데이터를 보고 결정한다.
