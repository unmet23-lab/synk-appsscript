# 정본 폴더 — 원본 자료 안내

> 2026-09-09 · 자료를 찾는 출발점은 [문서 지도](../문서_지도.md), AI 작업의 현행 기준은 [공통 운영 원칙](../AI_운영원칙.md)이다. 이 폴더의 원본과 관련 제품 계약을 운영 지침 사본으로 대체하지 않는다.

- 이 폴더의 소개서·규범·운영 원본은 각 문서의 적용 범위와 상태를 확인해서 사용한다. 편집 전 현재 변경을 확인하고 남의 미커밋은 보존한다.
- 라이브에는 안 올라간다 — `.claspignore` 허용목록 방식이라 Apps Script는 이 폴더를 모른다.
- 자격증명은 저장소 밖에 보관하고 답·파일·로그에 복사하지 않는다. `.gitignore`의 제외 규칙만으로 비밀 보호가 보장된다고 가정하지 않는다. 계정·학생 데이터 처리 기준은 공통 운영 원칙을 따른다.
