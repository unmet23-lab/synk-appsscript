## 🔴 여기 없는 것 — 자격증명

**자격증명(`로그인.txt`)은 git 눈 밖에 둔다.** 내용과 무관하게 원칙이다:

> **git 이력은 영구적이고 repo는 복제·백업·공유되는 물건이다.** 한 번 커밋된 자격증명은 나중에 파일을 지워도 이력에 남는다. 되돌릴 방법은 이력 재작성뿐이고, 그때는 이미 늦다.

`.gitignore`에 `**/로그인.txt` 등을 넣어 **실수로도 못 들어가게 기계로 막았고**, 실제로 차단되는지 테스트 사본으로 확인했다(`git check-ignore` 통과 후 사본 제거).

- **[2026-08-03] 자격증명 폴더는 repo 밖 `C:\Users\q1212\SYNK_보안\`으로 이동 완료**(유호님 승인·해시 대조 후 원본 삭제). 저장소 「안」에 있으면서 ignore로만 가려지는 상태가 가장 위험해서다 — `.gitignore`는 git 눈만 가리고, **폴더를 읽는 도구·상시 서비스(헤르메스 등)는 못 막는다.** 무시 규칙은 재유입 방지용으로 유지한다.
- 장기적으로는 파일이 아니라 **비밀번호 관리자**로 옮기는 편이 맞다(파일은 백업·동기화·화면 공유로 새어나간다).
