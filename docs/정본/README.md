이 파일들은 `Desktop\SYNK LAB\`·`Desktop\SYNK\`에 있었다. repo 밖이라 **git이 아무것도 못 봤다**:

- **충돌 감지 없음** — 두 AI 세션이 같은 파일을 동시에 열면 나중에 저장한 쪽이 앞의 것을 통째로 덮는다
