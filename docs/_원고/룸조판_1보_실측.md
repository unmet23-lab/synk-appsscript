## 구현 당시 확인한 것

제목·지면·출력 경로를 머리말에 쓰고 본문에 문단·목록·표를 적으면, 절 번호와 화면·인쇄 구성을 생성했습니다. 구조 왕복, 원고 줄 회수, 부품 적용, 잉크 가독성, 자립형 출력과 지면방 등재를 검사하는 통로를 만들었습니다. 이런 검사는 사용자 미감의 만족이나 실제 독자의 이해를 대신하지 않습니다.

초기 히어로수의 레진 표현은 사용자 의견으로 걷었습니다. 원고에 남긴 힌트로 선택을 재현한다는 생각과 거절된 표현의 경위는 기록으로 유지합니다.

## 현재 확인할 곳

현재 생성기와 지원 형식은 `tools/룸조판.js`의 `--규격`, 설계는 `docs/Loom_엔진_설계.md`의 조판 절을 봅니다. 다른 발표·영상·캐러셀의 제작 통로는 `DESIGN.md`에서 찾습니다. 이 문서에 적혔던 덱·캐러셀의 다음 보 계획은 자동으로 재개할 작업 목록이 아닙니다.

힌트의 종류를 임의의 숫자로 제한하던 주장은 현재 규칙에서 제외했습니다. 지원하지 않는 입력을 조용히 버리지 않고 오류를 밝히며, 기존 결과를 바꿀 때 원고와 출력을 함께 맞춘다는 기준을 유지합니다.
