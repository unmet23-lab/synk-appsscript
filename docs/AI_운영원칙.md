# SYNK 작업의 공통 기준

> 2026-09-18 · 사용자의 현재 요청이 작업 범위를 정한다.

- 이번 일에 필요한 현재 파일·자료만 확인한다. 과거 결정·사례·기억은 배경 자료이며, 예전의 말투·작업 순서·모델 역할·연출 방식을 새 요청에 자동 적용하지 않는다.
- 다른 작업의 미커밋 변경·원본을 보존한다. 자격증명과 학생 식별 정보를 출력·공유하지 않는다. 신규 결제·구독·자동충전은 하지 않는다.
- 요청된 일을 실행하고 필요한 범위에서 확인한다. 확인하지 않은 실행·게시·효과를 완료로 보고하지 않는다.

## 자료 위치

회사·제품 사실은 [문서 지도](문서_지도.md), 로고·서체·마스코트 원본은 [DESIGN](../DESIGN.md), 계정·채널은 [마케팅 정본](마케팅_정본.md)에서 필요한 항목만 찾는다. 이 링크들은 모든 작업에서 전부 읽으라는 목록이 아니다.

기존 일을 이어갈 때만 [트랙](_ops/트랙.md)의 해당 항목과 현재 실물을 대조한다. 확정 변경은 담당 원문에 반영한다. 별도 승인 단계·검사표·자동 훅을 새로 만들지 않는다.
