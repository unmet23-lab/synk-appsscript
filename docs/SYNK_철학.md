> 2026-09-18 · 축약 전의 철학과 데이터·사업 기준을 복구했습니다. 이 문서는 제품의 목적과 설계 기준이며 산출물의 말투를 지정하지 않습니다.

> v2.1 · 2026-09-13 사용자 수정안 반영. §1·§4의 회사별 철학을 갱신하고 기존 완성 기준·제품 약속·데이터와 선택의 경계를 보존했다. 목적·책임·판단 기준을 정한다. 제품 계약은 실제 동작과 데이터 규격을, 적용 기준은 현재 설계 선택을, 운영 원칙은 일하는 방법을 맡는다. 현재 사용자 요청과 최신 확정 결정이 과거 기록보다 우선한다.

## 1. 한 사람을 깊이 이해한 개인화 시스템을 만듭니다

무엇이 필요하고 무엇을 할 수 있는 사람인지 이해합니다. 그 이해 위에 기술을 더해, 그 사람에게 맞는 도움을 정확하게 내놓습니다.

**사람은 바뀝니다.** 처음 파악한 것에 머물지 않고, 겪은 일과 고른 선택을 보며 계속 다시 이해합니다. 그 이해가 바뀌면 받는 도움도 함께 바뀝니다.

**시간은 되돌아오지 않습니다.** 목표에 닿는 길에도 배움과 재미, 기억에 남을 순간을 담습니다. 삶을 대신 정하지 않습니다. 스스로 방향을 찾고, 고르고, 바꾸도록 돕습니다. 기술로 아낀 시간은 더 좋은 경험으로 돌려드립니다.

LAB은 삶의 방향과 배움의 길을 연구하고, SHIFT는 기업·기관의 AI 교육·컨설팅과 브랜딩을 돕습니다. PULSE는 음악·영상·캐릭터와 이야기의 콘텐츠·IP를 발전시키고, PATH는 외국인의 유학·취업 준비와 기관 연결을 지원하는 체계를 준비합니다.

**지키는 선** — 개인화라는 이름으로 이해가 완성됐다거나 모든 사람에게 정확하다고 말하지 않는다. 교육에서 얻은 방법을 다른 사업에 옮길 수는 있어도, 학생 데이터 수집이나 TOPIK 목표를 전사 공통 조건으로 삼지는 않는다.

## 2. 맡은 목적의 마지막 단계까지 완성한다

LAB 학습은 TOPIK에 도움이 되는지만이 아니라, 학생이 지루해하지 않는지도 확인합니다.

**처음 온 사람이 헤매면 아직 덜 만든 겁니다.** 뭘 할 수 있는 곳인지, 뭘 누르면 되는지 바로 보여야 합니다.

기능만 돌아간다고 끝이 아닙니다. 화면과 안내, 다 쓰고 난 뒤의 마무리까지 갖춰야 하나가 완성됩니다. 만든 사람만 아는 상태, 시험만 통과한 상태는 아직 완성이 아닙니다.

| 하는 일 | 완성에서 확인할 것 |
|---|---|
| LAB 학습·게임 경험 | 재미·실제로 쓸 한국어와 학생 목표에 대한 도움·신선함. 수집한 반응을 학습·개인화에 쓰면 아래 네 단계도 적용 |
| 수집·개인화·엔진 발전 기능 | 모였나 → 닿았나 → 달라졌나 → 누구에게 돌아갔나 |
| 홍보·모집 | 상대가 받을 가치와 약속이 정확히 읽히고, 제시한 제공물·신청·이용 경로가 실제로 이어지는가 |
| 학습 소식·안내·상태 알림 | 필요한 내용을 정확한 상대에게 제때 전하고, 의미와 필요한 행동을 이해하게 하는가 |
| SHIFT 회사 제작 이야기·AI 작업 공개 | 실제 문제·시도·실패·수정·선택·결과를 따라갈 수 있고, 과정에서 나온 판단과 방법을 가져갈 수 있는가 |
| SHIFT 기관 강의·기업 컨설팅·실습·납품 | 고객이 자기 일에 적용할 방법과 결과를 받고, 직접 쓰고 이어갈 수 있는가 |
| PATH 유학·취업 연계 | 교육기관·기업·개인의 역할과 조건이 명확하고, 맡은 준비·연결·인계가 확인되는가. 체험·훈련을 실제 근무 경력으로, 연계를 입학·취업 보장으로 바꾸지 않는가 |
| PULSE 음악·영상·작품 | 감상과 표현 자체가 완결되고, 소리·화면·재생·마무리와 다시 찾을 자리가 준비되었는가 |
| 내부 도구·저장·운영 기반 | 맡은 동작이 실제 환경에서 이어지고 실패를 알 수 있으며 필요한 복구가 가능한가 |

**지키는 선**

LAB 앱의 숙제·퀴즈·발화 등 기존 학습 산출물은 계약대로 수집하며 아래 네 단계를 적용한다. 수집 의무를 명시하지 않는 방식으로 기존 학습 기능의 완결 조건을 피하지 않는다.

**수집을 원료로 쓰겠다고 정한 기능은 네 단계를 각각 확인한다.** ① 모였나: 필요한 원본과 맥락이 실제 저장되었는가. ② 닿았나: 엔진이 사람의 옮겨 적기 없이 읽고 소비하는가. ③ 달라졌나: 그 사용으로 이해·판단·다음 과제나 답장이 실제로 달라지는가. ④ 누구에게: 그 변화가 학생·강사·학부모·운영자 중 약속한 수혜자에게 어떤 모습으로 돌아가는가.

저장만 된 재료, 사람이 옮겨야 이어지는 연결, 소비해도 아무 출력이 달라지지 않는 경로는 미완성이다. 미래에 쓸 수 있다는 설명이 현재 소비자의 부재를 대신하지 않는다. 기존의 ‘늘었나’도 행 수 증가가 아니라 이 변화와 이해의 진전을 뜻한다. ‘미구현·부분 구현·확인 불가’를 완료와 구분하고, 기존 작업 결과·시험·트랙에 단계별 증거를 남긴다.

홍보·안내·학부모 소식·알림·감상 작품에는 학습 응답이나 엔진 수집을 공통 의무로 붙이지 않는다. 학부모 학습 소식은 아이와 대화할 재료를 줄 수 있지만 모든 소식에 말하기 과제를 강제하지 않는다. 접점 안에서 새 응답을 받아 개인화에 쓰겠다고 약속했다면 그 수집 부분에만 네 단계를 적용한다. 광고 반응이나 감상을 학생 성향으로 자동 합치지 않는다.

실제 학생이 없어도 합성 입력으로 저장·소비·출력 변화는 확인한다. 이는 구현 증거이며 학생의 실력 향상 증거는 아니다. 실제 효과는 실제 자료로 따로 확인한다. 해당 기능이 만들기로 한 변화가 내부 운영에만 돌아가는 경우도 목적에 맞으면 유효하다. 학생에게 돌려주기로 한 가치를 내부 집계만으로 대체하지 않는다.

## 3. 사람·기록·약속의 경계를 지킨다

**학생이 남긴 말은 학생의 것입니다.** 직접 한 말과 고른 답, 우리가 눈으로 본 사실을 원래대로 보존합니다. AI가 고친 것과 짐작한 것은 따로 표시해, 나중에 무엇을 근거로 그렇게 판단했는지 되짚을 수 있게 합니다.

**지키는 선**

학생의 원래 말·답·선택과 직접 관찰한 사실을 보존한다. 원본·교정·AI 추정·학생 확인을 구분하고 당시 출처와 기준을 되짚어 다시 계산할 수 있어야 한다. AI가 도운 답을 학생의 독립 실력으로 배우지 않는다. 처음 받아야만 남는 기록은 해당 실제 데이터를 받기 전에 준비한다.

학생을 식별하는 데이터는 외부 모델·도구·사람에게 처리용으로 내보내지 않는다. 이름 제거만으로 비식별이라고 단정하지 않으며 원문 속 이름과 학교·날짜·맥락의 조합도 본다. 비식별 학습 원문은 허용 범위 안에서 활용할 수 있다. 원본 음성은 목소리가 남으므로 기존 승인 처리 통로와 계약을 따른다. 통제 가능한 저장소에 보관하는 것, 수신자에게 서비스를 전달하는 것, 외부 모델 입력으로 보내는 것은 서로 다른 용도다. 같은 벤더라는 이유로 허용 범위가 합쳐지지 않는다.

개인용 원본·회사 비식별 집계·훈련·평가·공개는 자동 전환하지 않는다. 용도별 허용 범위와 동의·반출 규칙을 적용하고 철회는 원본과 파생의 관계를 따라 처리한다. 원본 보존은 필요한 철회·파기를 막는 이유가 아니다. 학생 기록을 홍보 재료로 쓰는 것은 학습 이용과 별개이며 [적용 기준 §4](철학_적용기준.md#4-대외-사용과-근거)를 따른다.

계획·설계·구현·배포·실제 사용·효과를 구분해 말한다. 옛 현재형이나 표의 도장은 오늘의 운영 증거가 아니다. 약속의 범위와 조건은 고객이 읽는 문장에서도 알 수 있어야 한다. 연구의 결과, 우리의 설계 판단, 우리 고객의 실측을 구분한다. 사람을 주어로 따뜻하게 설명하되 없는 능력이나 결과를 지어내지 않는다.

현재의 상품 약속과 보호 경계를 기술 개선이라는 이유로 조용히 바꾸지 않는다. 검토 기준이 달라져도 이미 받은 요청의 범위와 제품 계약을 따른다. 상세 데이터 기준은 [제품방향](제품방향.md)과 [코어엔진 설계](코어엔진_설계.md), 일하는 권한·도구는 [AI 운영 원칙](AI_운영원칙.md)이 맡는다.

## 4. 사업마다 같은 철학을 다르게 실현한다

### SYNK LAB

**삶의 방향을 구체화하며, 배움과 경험의 최적화된 경로를 설계합니다.**

어디로 가고 싶은지 정해지면, 거기 닿으려면 무엇을 배우고 어떤 경험을 쌓아야 하는지 연구합니다. 길이 여럿일 때는 각각의 조건과 가능성을 견주어, 고를 근거와 실제로 걸어갈 수 있는 순서를 내놓습니다.

**지키는 선** — 최적화와 성과는 각자가 바라는 삶, 현재 조건, 실제 배움과 경험을 기준으로 연구한다. 하나의 보편적인 정답이나 성과 보장을 뜻하지 않으며, 방향을 선택하고 바꾸는 주체는 당사자다. 현재 한국어 교육에서는 실제로 쓰는 한국어와 TOPIK 목표를 기본으로 책임지고, 합격의 과정에 재미·추억·신선함을 담는다. 운동 뒤 학습 능률을 높이는 원리를 K컬처·댄스의 즐거운 신체활동으로 풀어 수업에 연결하는 핵심 교육 방식은 보존한다. 연구의 조건과 수치는 근거 자료에서 관리하며 다른 대상의 효과를 우리 학생의 실측처럼 쓰지 않는다.

정규 오프라인 과정은 1년이며 TOPIK 4급을 목표로 한다. 과정 후 첫 시험에서 4급에 미달하면 학원 앱 계정을 6개월 무료 연장하여 온라인으로 지속 케어한다. ‘4급 취득까지 계속 케어’는 이 약속을 뜻한다. 지원 기간을 없애거나 오프라인 수업을 연장하는 약속으로 확대하지 않는다. 개원 전 온라인 반의 별도 상품 조건은 [판매 설계](개원전판매_설계_v1.md)를 따른다.

## 6. 새로운 근거로 방법을 발전시킨다

특정 AI보다 실제 경험의 원본, 도움이 통했던 기록, 다음 도움으로 이어지는 구조에 공들인다. 모델과 도구는 교체 가능한 부품으로 둔다. 새 기술이 우리 일을 더 잘하는지는 대표 작업의 결과·오류·소요 시간으로 확인한다. 성능을 먼저 보고, 사실상 동등하다는 증거가 있을 때 비용을 비교한다. 낮은 성능으로 바꿨다면 숨기지 않는다. 데이터 전달·저장 같은 기반 기능에 ‘AI가 좋아지면 같이 좋아지나’를 억지로 묻지 않는다.

과거 기각은 당시 목적·근거·조건과 함께 읽는다. 같은 근거의 제안을 이름만 바꿔 반복하지 않는다. 그러나 사용자 요청·사업 대상·모델 능력·실물·계약·새 증거가 달라졌다면 같은 제목도 다시 판단한다. 재검토에는 **당시 이유 / 달라진 전제 / 지금 증거 / 바꾸려는 범위**를 짧게 남긴다. 제목 일치나 기억 속 금지 문장만으로 새 근거를 배제하지 않는다. 실제 승인·데이터 보호 절차를 우회하는 허가는 아니다.

명품과 속도를 함께 추구한다. 기능·디자인·사용 뒤 마무리가 갖춰진 실제 흐름을 하나씩 완성하고 연결한다. 품질을 낮추는 대신 중복 작업·낡은 절차·불필요한 문서를 줄인다. [명품 기준](명품_기준_v1.md)의 해당 항목을 적용하며 매번 전사 검문·새 장부·강제 훅을 만들지 않는다.

화면 수·상태값·카드 횟수·대사 비율·모델 배치·검사 주기·구현 수량은 철학의 불변 조건이 아니다. 해당 설계에서 현재 선택과 바꾼 근거를 관리한다. 본문 밖으로 옮긴 것은 폐기한 것이 아니다. 관련 설계를 바꾸기 전에는 현재 적용 기준을 따른다.

새 작업은 관련 절과 연결 계약부터 읽는다. 추출 도구는 위 의미 구간의 시작·끝 표식으로 읽으며, 필수 구간 누락·중복·잘림을 온전한 전달로 세지 않는다. 정본 개정 시 영향받는 파생을 실제 읽고 수정한다. 읽지 않은 문서에 최신 확인 도장을 찍지 않는다. 과거 구절 인용은 보존본에서 뜻을 찾되 현재 판단에는 이 문서와 적용 기준을 사용한다.
