# Loom 실시간 장면 표현 기준

2026-09-13 · 현재 재사용 기준. 사용자 원문: 「앞으로 이 방식을 잘 저장해서 다음에 LOOM엔진을 쓸때 이렇게 표현되게 만들어줘」. 기준 실물은 Git `8d1e99bfe`의 [몽글과 바람의 정원](../experiences/loom-living/README.md)이다. 사용자는 같은 요청에서 눈 깜빡임을 「훌륭한데」라고 평가했다.

## 적용 범위

다음 Loom **실시간 펠트 장면**은 이 실물의 표현과 공통 코드를 출발점으로 삼는다. 사용자가 새 방향을 정하면 그 요청을 우선한다. 문서·인쇄물·정적 화면에는 재질과 디테일을 참고하되 바람·타이머를 넣지 않는다. 현재 구현은 원본 그림을 국소 변형하는 2.5D다. 임의의 한 장을 자동 분리해 완전한 3D로 바꾸는 기능은 아니다.

## 유지할 표현

| 요소 | 다음 제작의 기준 | 현재 실행 원천 |
|---|---|---|
| 장면 | 카메라·수평선·지면·광원 위치·전체 노출을 고정한다. 움직임은 관심 대상과 작은 영역에 둔다. | [웹 표시기](../tools/lib/loom-scene-webgl.mjs) |
| 바람 | 기본 15초 중 12초는 풀 정지, 3초만 바람. 시작 2초에 최대, 마지막 1초에 0으로 복귀한다. 수동 바람도 같은 길이이며 활성 중 재클릭으로 연장하지 않는다. | [공통 시간과 행동](../tools/lib/loom-scene.mjs)의 `CONFIG`, `stepScene` |
| 풀 | 뿌리를 고정하고 끝이 움직인다. 바람 밖에는 풀 변형 표시를 생략한다. 이삭의 윤곽과 이동 여유를 포함하는 영역은 같은 변위를 유지하고 바깥에서 잦아들게 한다. 원본과 이동본을 겹쳐 뭉개지게 하지 않는다. | 표시기의 `preserveContour`와 [환경 설정](../experiences/loom-living/environment.json) |
| 불빛 | 그림에 있는 불빛 중심에서 따뜻한 중심광과 은은한 번짐을 천천히 변화시킨다. 화면 전체의 밝기를 흔들지 않는다. | 표시기의 `renderEnvironment` |
| 몽글 | 승인 원본의 털·몸·색·조명·알파를 유지한다. 깜빡임은 기존 눈 영역만 바꾸며 시선이 먼저 반응하고 몸이 작게 따라간다. | [장면 자산](../experiences/loom-living/scene.json), [표정 재질 고정](캐릭터/캐릭터_생명감_설계.md#1-a-표정-전환의-재질-고정) |
| 그림자 | 본체 윤곽의 부드러운 투영과 바닥 접점 음영을 한 번에 합성해 땅의 질감을 남긴다. | 표시기의 그림자 처리 |
| 말풍선 | 몽글의 구름형, 천의 두께·잔결, 실땀의 그림자·밝은 결·매듭, 이름 표식을 이어 쓴다. 글자는 읽기 쉽게 둔다. 다른 마스코트는 해당 캐릭터의 말풍선 정본을 따른다. | [말풍선 부품](../experiences/loom-living/felt-dialogue.mjs), [캐릭터 가이드](캐릭터/가이드_정본.md) |
| 휴식 | 기본 무음, 정지·화면 숨김·움직임 줄이기와 긴 복귀 간격 처리를 이어 쓴다. | 공통 시간과 [장면 연결](../experiences/loom-living/scene.mjs) |

숫자의 실행 원천은 위 코드다. 별도 타이머나 복제한 움직임 코드로 다시 만들지 않는다. 현재 풀 상한 9CSSpx와 윤곽 보존 경계 16CSSpx는 현재 표시기의 설정이며, 크기가 다른 물체에 같은 이동량을 강제하지 않는다. 새 장면에서도 실루엣이 찌그러지거나 경계의 원본 좌표가 접히지 않도록 이동량과 영역을 함께 확인한다.

`preserveContour`는 현재 오른쪽 전경 풀 한 곳에 적용되어 있다. 새 풀을 만들 때에는 이 윤곽 보존 방식을 우선 검토하고 해당 그림의 실루엣·이동 여유를 실제 크기로 확인한다. 다른 풀 전체가 이미 같은 방식으로 교체됐다고 해석하지 않는다.

## 기존 경로로 재사용

1. [DESIGN](../DESIGN.md)에서 이 기준과 기준 실물을 확인하고, [마스코트 자산 코드](../tools/lib/마스코트자산.js)가 가리키는 현재 승인 원본을 사용한다.
2. `loom-scene.mjs`의 `createScene`·`stepScene`, `loom-scene-webgl.mjs`의 `LoomSceneRenderer`, 기존 말풍선 부품을 재사용한다. 기본 바람 설정은 이미 15초/3초/2초다.
3. 새 배경의 불빛 중심·풀 뿌리·끝·윤곽과 캐릭터 접점을 지정한다. 정원의 14개 불빛·5개 풀 개수나 좌표를 다른 그림에 복사하지 않는다. [현재 빌더](../tools/loom-living-build.cjs)는 이 정원 전용이므로 새 장면의 자산·출력 경로를 맞춘 뒤 쓴다.
4. 실제 배경과 크기에서 정지·바람 최대·복귀·깜빡임·상호작용을 확인한다. 정지 컷과 반복 재생을 함께 보며, 새 장면의 확인 결과를 남긴다. 기존 검증을 새 자산의 품질 보증으로 이어 쓰지 않는다.

원본과 파생 자산은 [provenance.json](../experiences/loom-living/provenance.json), 현재 풀 윤곽은 [비교 그림](../experiences/loom-living/qa/grass-contour.png)과 [검증 기록](../experiences/loom-living/qa/grass-contour.json), 바람 시간은 [wind.json](../experiences/loom-living/qa/wind.json), 말풍선은 [dialogue.json](../experiences/loom-living/qa/dialogue.json)에 각 버전의 확인 범위가 있다. 로컬 웹 장면 확인과 학생 앱 배포·실제 기기·학생 반응은 구분한다.

## 표정 상호작용은 다음 검토 사항

같은 요청의 「인사할 때나 바람 볼 때 표정이 상호작용할 수 있게 하면 어떨까?」는 의견 요청이다. 현재 저장 승인을 새로운 표정의 제작·적용 완료로 확대하지 않는다. 깜빡임을 보존하며, 인사에는 반가움, 바람에는 호기심이 드러나는 짧은 사건 반응을 검토한다. 구체 표정·시간·자산 선택은 아직 확정하지 않았다. 승인 원본에 없는 입·코를 추가하거나 표정 때문에 몸 전체의 털을 갈아끼우지 않는다는 기존 기준을 따른다.
