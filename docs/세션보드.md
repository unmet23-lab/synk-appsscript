# 세션보드 — 여기가 아니다

> **정본은 `docs/_ops/보드/<지문>.md` 의 세션별 파일이다** (2026-08-08 · 마찰 F250 · 유호님 지시).
>
> 한 파일을 상시 3~7개 세션이 함께 고치면서 장부에 마찰 **14건**이 쌓였고, 그 처방이 전부
> 「가드가 남의 줄을 재지 않게」 하는 특례였다(`board-guard` 편집 전 판 대조 · `git-scope-guard`
> 상시공유 목록 · `track-collision`·`handoff-store` 제외 목록 · `auto-commit` 금지 목록).
> CLAUDE.md 신뢰성 조항의 **3번째 = 원인을 쓸 수 없게 만든다** 가 이 이주다.
>
> 합쳐진 표는 **디스크에 없다.** 파생 파일을 git 에 두면 충돌이 자리만 옮기기 때문이다 —
> 인계문이 세션별로 갈리고도 파생 목차 `docs/_ops/인계문.md` 에서 그대로 충돌하는 것이 그 실물이다.

## 어디로 가나

| 하려던 것 | 지금 방법 |
|---|---|
| 전체 표 보기 | `node tools/board.js` |
| 내 줄 선언·갱신 | `docs/_ops/보드/<내 지문 8자리>.md` 를 직접 편집 |
| 완료 줄 이관 | `node tools/board-move.js "문구"` |
| 과거 이력 전문 | `docs/세션보드_아카이브.md` (읽지 않는 파일) |

내 지문 = `$CLAUDE_CODE_HOST_SESSION_ID` 에서 접두(`local_` 등)를 뺀 **앞 8자리**.
보드 줄 안에 적는 지문과 같은 규칙이라(`\.claude/hooks/lib/board-id.js`) 파일명과 내용이 갈라지지 않는다.

이 파일에 표 행을 쓰면 `board-guard` 가 막는다 — 조립된 표에 안 실려 아무도 안 읽기 때문이다.
