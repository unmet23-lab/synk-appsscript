synk / palette applied · v.06

synk

를 같은 트렌디 미니멀 시리즈에 입혔습니다. 우상단 버튼으로 두 팔레트를 전환해 보세요 — 색 외의 모든 픽셀은 동결입니다. 각 컨셉을 왼쪽: 모노(Ink/Paper) — 오른쪽: 로 나란히 놓아, 같은 마크에서 색이 어떤 온도를 바꾸는지 바로 비교할 수 있게 구성했어요.

Red는 단서(signal)의 역할입니다. 뉴런 발화의 순간, vesicle이 방출되는 그 0.5초만 red로 표시하고, 나머지는 그대로 조용한 잉크로 둡니다. 마지막 섹션에 장단점 매트릭스 + 최종 추천이 있어요.

6개 컨셉을 확장성 / 각인력 / 미니사이즈 / 색-감도 / 서사 다섯 축으로 저울질했습니다. 결론부터: 심볼 하나만 고른다면 02 emission (red core), 워드마크 전용이 필요하다면 06 wordmark (red //), 그리고 이 둘을 시스템으로 함께 운영하는 것이 최적입니다.

final recommendation · 최종 추천

emission + wordmark
as one system.

하나만 고르지 않기를 권합니다. Synk는 심볼과 워드마크의 역할이 서로 다른 브랜드예요.

02 emission 은 앱 아이콘, 파비콘, 소셜 아바타, 모션 인트로 — 이미지가 필요한 자리의 얼굴. 중심의 red 코어가 "지금 발화하는 뉴런"을 명확히 표현하고, 대칭 구조라 어느 사이즈에서도 무너지지 않아요.

06 wordmark (synk //) 은 문서 헤더, 서명, 프로덕트 UI 좌상단 — 문장 안에 놓이는 자리의 얼굴. red는 // 두 획에만 얹혀서, 브랜드가 계속되고 있음(continuation)을 조용히 신호합니다.

Red 사용량은 전체 면적의 5% 이하로 제한하세요. 이 팔레트에서 red는 "뭔가가 방금 일어났다"는 신호이지, 배경이 아닙니다.

08mono · vs · red

모노톤 vs 레드 액센트

Which coloring wins?

Red 팔레트가 확정된 만큼, 완전 모노톤과 red 액센트 적용 중 어느 톤을 시스템의 기본형으로 삼을지도 정리했어요.

A · 모노 온리

mono only

synk

장점 — 극도로 조용하고 지적. Notion·Linear·Arc 같은 미니멀 프로덕트 톤과 결이 맞음. 인쇄·타 브랜드 협업 시 무례하지 않음.

단점 — 확정된 red 팔레트를 거의 안 쓰게 됨. 브랜드가 눈에 걸리는 순간이 부족해 "잘 만든 티가 안 남". 스크롤 안에서 미끄러짐.

★ B · red 액센트 · 추천

with synk red

synk

장점 — Red가 정확히 한 지점에만 놓여 "발화의 순간"이라는 서사와 100% 맞물림. 확정 팔레트를 낭비 없이 사용. UI 안에서 즉각 인지됨.

단점 — 절제가 없으면 red가 곳곳에 번져 싸구려가 됨. 반드시 "단 하나의 발화점" 규칙을 지켜야 함 (전체 면적의 5% 이하).

rules · red 사용 규칙

Red는 단 하나의 발화점에만. 한 화면/한 마크에 red 도트는 1-2개, 전체 면적의 5% 이하. // 이나 마침표(.) 같은 부호에 얹는 것은 예외적으로 허용.

system · 02 + 06

Symbol은 02 emission, Wordmark는 06 synk //. 둘은 서로를 대체하지 않고, 상황이 어느 얼굴을 부를지 정합니다. 아이콘 자리 → emission, 문장 자리 → wordmark.
