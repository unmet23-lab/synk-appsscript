# SYNK 로고 — 현재 원본과 사용 기준

> 2026-09-09 사용자 승인 색 정책 · 2026-09-10 SYNK 실땀 제거 사용자 승인. 새 제작·재제작과 기존 단독·사업명 조합 로고의 갱신에 적용한다. 정책 확정과 실제 자산·게시 반영은 구분하며, 수정일이 가장 최근인 시험 파일을 승인본으로 삼지 않는다.

## 색과 형태

밝은 바탕의 SYNK는 Ink `#2B2320`, 어두운 바탕은 Paper `#FBF7F0`다. **2026-09-10 사용자 승인 범위는 SYNK 네 글자의 스티치(실땀)만 제거하는 것이다.** 단독 SYNK와 SYNK-LAB/SHIFT/PULSE 조합의 SYNK 부분에 모두 적용한다. 기존 펠트 섬유·두께·그늘·중립색·형태를 유지하고, 솟은 k, 내려가는 y, 자간과 비율을 바꾸지 않는다.

LAB 코랄·SHIFT 파랑·PULSE 베리의 사업명은 승인된 고유색·스티치·형태를 그대로 유지한다. SYNK의 실땀 제거를 사업명이나 마스코트·UI의 스티치 제거로 확대하지 않는다. 펠트 섬유·두께·그늘을 한 색으로 덮거나 평평하게 만들지 않는다. 금박·광택·외곽선 추가나 새로운 서체 조립으로 명품화를 대신하지 않는다.

## 용도별 원천

| 용도 | 선택 |
|---|---|
| 기업 웹·소개·홍보에서 재질을 보여주는 로고 | [사진형 펠트 킷](홍보물/마케팅실행_20260909/브랜드킷/index.html)의 `배치용/` 완성 조합. 단독 SYNK 또는 SYNK-LAB/SHIFT/PULSE 전체를 사용하며 09-10 실땀 정책의 실제 반영을 확인 |
| 파비콘·작은 인쇄·정확한 도형/단색이 필요한 자리 | 같은 킷의 `SYNK-Ink-정밀.svg`·`SYNK-Paper-정밀.svg` |
| 벡터 생성·내부 이름·기호·도장 | `tools/lib/로고정본.js`. 대외 `신호:'k'`는 단색 기본, 내부 `신호:'꺾쇠'`는 기존 코랄 기본 |

[사용규칙](홍보물/마케팅실행_20260909/브랜드킷/사용규칙.md)과 [배치명세](홍보물/마케팅실행_20260909/브랜드킷/배치명세.json)의 파일·치수·내용 지문으로 선택한 원본을 확인한다. 완성된 사업명 조합을 일반 글자로 다시 만들지 않는다. 웹용 압축·축소가 필요하면 비례를 유지하고 원본과 파생 파일을 구분한다.

기존 자료의 ‘사진형 스티치 킷’은 앞으로 **사진형 펠트 킷**으로 설명한다. 재질은 공통으로 유지하되 SYNK는 무실땀, 사업명은 기존 스티치를 유지한다. 기존 킷 링크·파일명·배치명세가 있다는 사실만으로 새 정책의 실물 반영을 완료로 판단하지 않는다.

사진형은 기존 양모 워드마크를 참조한 재질 파생물이며 원본과 픽셀·벡터가 동일하다는 뜻이 아니다. 정밀 도형은 실행 코드가 맡는다. SYNK의 실땀만 제거하고 펠트 표면을 유지하며, 벡터 생성기의 작은 크기 민판 규칙을 사진형 전체에 적용하지 않는다. 작은 자리에서 재질이 뭉개지면 실제 크기로 비교해 정밀 SVG나 적절한 표시 크기를 고른다.

## 조합과 배경

SYNK 실제 폭을 1로 볼 때 사업명 사이 간격 0.075, 실제 대문자 높이 0.222로 조합된 승인 자산을 사용한다. 광학 중심과 내장 여백을 유지하고 늘이거나 압축하지 않는다. 본문·소품을 로고 여백에 겹치지 않는다.

어두운 바탕에서도 사업명 색은 유지한다. 작아서 흐려지면 밝은 패널에 전체 조합을 놓고 사업명만 임의로 밝히지 않는다. 철자·윤곽의 읽힘이 재질 과장보다 먼저다.

## 적용 확인

1. 선택한 파일을 현재 배치명세와 대조한다. 파생 파일은 사용한 원본과 변환을 기록한다. 단독·사업명 조합의 밝은/어두운 배경용 SYNK에 실땀이 남지 않았는지 확인하고, 기존 펠트 섬유·두께·그늘·중립색·형태가 보존됐는지 원본과 비교한다.
2. LAB·SHIFT·PULSE 사업명의 고유색과 스티치 보존을 따로 확인한다. 실제 배경·표시 크기에서 투명 알파, k 위·y 아래 여백, s/n 내부 공간, 큰 파임·섬유 잘림, SYNK와 사업명 읽힘을 확인한다.
3. 완성 결과와 게시된 결과를 구분해 확인 범위를 남긴다. 원본을 읽은 사실이나 압축 성공만으로 화면 반영을 완료했다고 하지 않는다.

이전 소개서·시안은 판단 사례이며 신규 제작에는 위 원천 중 09-10 정책의 실제 반영을 확인한 파일을 쓴다. 내부 꺾쇠·학생 앱 신호·마스코트 의상까지 중립색이나 무실땀으로 바꾸지 않는다. 이 문서는 정책과 검수 범위를 정하며, 실제 로고 파일·생성기·과거 제작물·게시된 서비스의 갱신 완료를 뜻하지 않는다. 실제 적용과 남은 범위는 해당 결과물의 검증 기록에서 확인한다.
