# SYNK 로고 — 현재 원본과 사용 기준

> 2026-09-09 사용자 승인 색 정책 · 2026-09-10 사용처 정리. 새 제작·재제작에 적용한다. 수정일이 가장 최근인 시험 파일을 승인본으로 삼지 않는다.

## 색과 형태

밝은 바탕의 SYNK는 Ink `#2B2320`, 어두운 바탕은 Paper `#FBF7F0`다. LAB 코랄·SHIFT 파랑·PULSE 베리의 승인 자산을 유지한다. 펠트·실땀·섬유·그늘을 한 색으로 덮지 않는다. 솟은 k, 내려가는 y, 자간과 글자 형태를 보존한다. 금박·광택·외곽선 추가나 새로운 서체 조립으로 명품화를 대신하지 않는다.

## 용도별 원천

| 용도 | 선택 |
|---|---|
| 기업 웹·소개·홍보에서 재질을 보여주는 로고 | [현행 사진형 킷](홍보물/마케팅실행_20260909/브랜드킷/index.html)의 `배치용/` 완성 조합. 단독 SYNK 또는 SYNK-LAB/SHIFT/PULSE 전체를 사용 |
| 파비콘·작은 인쇄·정확한 도형/단색이 필요한 자리 | 같은 킷의 `SYNK-Ink-정밀.svg`·`SYNK-Paper-정밀.svg` |
| 벡터 생성·내부 이름·기호·도장 | `tools/lib/로고정본.js`. 대외 `신호:'k'`는 단색 기본, 내부 `신호:'꺾쇠'`는 기존 코랄 기본 |

[사용규칙](홍보물/마케팅실행_20260909/브랜드킷/사용규칙.md)과 [배치명세](홍보물/마케팅실행_20260909/브랜드킷/배치명세.json)의 파일·치수·내용 지문으로 선택한 원본을 확인한다. 완성된 사업명 조합을 일반 글자로 다시 만들지 않는다. 웹용 압축·축소가 필요하면 비례를 유지하고 원본과 파생 파일을 구분한다.

사진형은 기존 양모 워드마크를 참조한 재질 파생물이며 원본과 픽셀·벡터가 동일하다는 뜻이 아니다. 정밀 도형은 실행 코드가 맡는다. 벡터 생성기의 작은 크기 민판 규칙을 사진형 전체에 적용하지 않는다. 작은 자리에서 재질이 뭉개지면 실제 크기로 비교해 정밀 SVG나 적절한 표시 크기를 고른다.

## 조합과 배경

SYNK 실제 폭을 1로 볼 때 사업명 사이 간격 0.075, 실제 대문자 높이 0.222로 조합된 승인 자산을 사용한다. 광학 중심과 내장 여백을 유지하고 늘이거나 압축하지 않는다. 본문·소품을 로고 여백에 겹치지 않는다.

어두운 바탕에서도 사업명 색은 유지한다. 작아서 흐려지면 밝은 패널에 전체 조합을 놓고 사업명만 임의로 밝히지 않는다. 철자·윤곽의 읽힘이 재질 과장보다 먼저다.

## 적용 확인

1. 선택한 파일을 현재 배치명세와 대조한다. 파생 파일은 사용한 원본과 변환을 기록한다.
2. 실제 배경·표시 크기에서 투명 알파, k 위·y 아래 여백, s/n 내부 공간, 큰 파임·섬유 잘림, SYNK와 사업명 읽힘을 확인한다.
3. 완성 결과와 게시된 결과를 구분해 확인 범위를 남긴다. 원본을 읽은 사실이나 압축 성공만으로 화면 반영을 완료했다고 하지 않는다.

이전 소개서·시안은 판단 사례이며 신규 로고의 원천은 위 현행 킷이다. 내부 꺾쇠·학생 앱 신호·마스코트 의상까지 중립색으로 바꾸지 않는다. 과거 파일이나 실서비스 전체를 자동 갱신했다는 뜻도 아니다.
