# SYNK 로고 중립색 정본 v1

2026-09-09 · 유호님 승인 · 최신 색의 역할과 이번 적용 범위

## 하나의 중심, 각 사업의 성격

- 밝은 바탕: SYNK 네 글자 몸체는 따뜻한 Ink `#2B2320`.
- 어두운 바탕: SYNK 네 글자 몸체는 Paper `#FBF7F0`.
- LAB 코랄, SHIFT 파랑, PULSE 베리의 기존 승인 자산은 유지한다. 색·도형을 다시 생성하지 않는다.
- 펠트·실땀·섬유·그늘은 남긴다. 모든 픽셀을 한 색으로 덮는 단순 채우기를 뜻하지 않는다.
- k의 솟음, y의 내려감, 자간과 기존 도형을 자산으로 존중한다.

목적은 코랄 자산을 버리는 것이 아니라 강조할 자리를 사업명·소품·행동으로 정확히 나누는 것이다. 금박, 광택, 테두리, 과도한 장식으로 명품화를 대신하지 않는다.

## 실행 원천

1. 정확한 도형: `tools/lib/로고정본.js`. 대외 `신호:'k'`의 기본 색갈래는 `단색`, 내부 `신호:'꺾쇠'`는 기존 `코랄`. 기존 SYN/K/CHEV 경로와 재질 함수를 유지한다.
2. 사진형 재질 변형: [이번 브랜드 킷](홍보물/마케팅실행_20260909/브랜드킷/index.html). 기존 `docs/Loom_자산/구움/양모워드마크_누끼.png`를 참조해 Higgsfield GPT Image 2.5 Sunburst로 Ink/Paper 2종 제작. 생성물은 인식 가능한 형태와 재질을 계승한 파생물이지 픽셀 동일본이 아니다.
3. 조합: 이번 킷 `조립.cjs`가 기존 LAB/SHIFT/PULSE를 크기와 광학 간격만 조정해 조합한다. 출력 명세의 해시로 인수한다.
4. 명확한 색/작은 인쇄: 정밀 SVG를 선택한다. 사진형의 자연스러운 명암을 색상 오류로 보고 균일하게 칠하지 않는다.

## 조합의 기준

SYNK 폭을 1로 볼 때 사업명 사이 간격 0.075, 사업명 실제 대문자 높이 0.222를 출발점으로 사용했다. 광학 중심 보정이 포함되며 도형을 늘이거나 압축하지 않는다. 로고 주변 여백에는 본문·소품을 겹치지 않는다.

어두운 바탕에서 짙은 사업명은 작을수록 읽힘을 다시 확인한다. 흐려지면 밝은 패널에 전체 로고를 배치하며 사업명 색을 임의로 밝히지 않는다. 작은 마크에서는 재질 과장보다 철자와 윤곽이 먼저다.

## 기존 파일과의 관계

새 콘텐츠와 재제작물은 이 규칙을 기본으로 한다. 이전 소개서·16계정 결과물·계보·시안은 역사 원본으로 보존하며 이번 요청으로 모든 과거 파일이나 실서비스 배포까지 완료했다고 주장하지 않는다. 이번 현재 실물은 19계정 실행 컬렉션이다. 다음 소비자 재생성 시 중립색 기본값을 받는다.

학생 앱의 내부 꺾쇠·피드백·신호 색이나 마스코트 의상까지 검정으로 바꾸는 요청이 아니다. 색 토큰 45개와 사업별 팔레트를 삭제하지 않는다.

## 검수

투명 알파, k 위·y 아래 여백, s/n 내부 공간, 큰 파임·섬유 잘림, 밝고 어두운 바탕, 실제 작은 표시 크기에서 SYNK와 사업명 모두 읽히는지 본다. 영상·문서·자료 전달까지 같은 기준을 적용하되 제작 검수와 실제 게시·성과는 구분한다.
