# 현장 노트

> 2026-10-17 시작. GPT와 Claude가 같이 읽고 같이 고치는 도구 함정 노트다. 그전에는 같은 내용이 Claude 개인 메모에만 있었다(10-17 [참고 카드](../참고카드/카드/2026-10-17_universal-modder_현장노트.md)).

도구가 예상과 다르게 움직인 일을 다음 AI가 다시 겪지 않게 남긴다. 무엇을 만들고 어떻게 만들지는 담당 원문이 정한다 — 역할·비용은 [AI 운영 원칙](../AI_운영원칙.md), AI 영상·이미지 방법은 [만족 사례 장부](../마케팅/제작양식/만족사례_장부.md), 제품은 각 설계·README. 여기는 셸·git·시험·그림·영상·배포·브라우저·AI CLI 도구가 실제로 하는 일과 그 함정만 둔다.

## 찾는 법

1. 도구를 쓰기 전에 아래 표에서 그 도구 파일을 열어 맨 위 「먼저 볼 것」과 목차만 읽는다(처음 30줄 안팎). 파일을 통째로 읽지 않는다.
2. 걸리는 절이 있으면 `rg -n "^###" docs/현장노트/<파일>.md`로 항목 제목을 보고 그 항목만 읽는다. 증상이 보이면 오류 문구 일부나 낱말로 찾는다(지난 기록까지 같이 찾는다). 예: `rg -n "index.lock|CRLF" docs/현장노트`, `rg -n "UNABLE_TO_GET_ISSUER_CERT|unexpected EOF|422" docs/현장노트`.
3. 맞는 항목을 찾으면 그 항목의 「다시 확인」을 먼저 돌려 지금도 맞는지 본다. 도구 판이 바뀌어 결과가 달라졌으면 그 자리에서 항목을 고친다(10-17 새 노트북에서 Git Bash 시각·Node 인증서 항목이 그렇게 바뀌었다).

## 항목 틀

- 파일 머리에 판(도구와 버전, 이 PC 설정)을 적는다. 머리의 「마지막 확인」·「쓴 AI」 줄은 2026-10-20부터 고치지 않는다 — 항목을 더하는 세션마다 같은 줄을 고쳐 서로 부딪히는 자리였다. 언제·누가는 항목 제목 끝의 「(날짜 AI)」와 git 이력이 맡는다.
- 머리 아래에 「먼저 볼 것」(자주 걸리거나 걸리면 손해가 큰 함정 10개 안팎, 한 줄씩 항목 링크)과 목차(`##` 절 링크)를 둔다.
- 도구가 이제 자동으로 막아 주는 함정, 지금은 안 쓰는 옛 PC·판·절차 이야기, 다시 오지 않을 한 번의 일은 [지난기록](지난기록/) 폴더의 같은 이름 파일로 옮긴다(지우지 않는다). 다시 겪으면 원래 파일의 맞는 절로 되돌린다. 옮길 때 항목 속 상대 링크는 한 단계 깊어지니 `../`를 하나 더 붙이고, 되돌릴 때는 뺀다.
- 항목 하나는 증상을 한 줄로 쓴 제목과 네 줄이다.

  ```markdown
  ### <증상을 한 줄로>
  - 증상: 보인 그대로(오류 문구, 숫자, 언제·어떤 작업에서).
  - 원인: 도구가 실제로 한 일. 「깨졌다」가 아니라 왜 그렇게 됐는지. 모르면 모른다고 쓴다.
  - 고침: 그때 통한 방법.
  - 다시 확인: 지금도 맞는지 볼 수 있는 명령이나 관찰 한 줄.
  ```

- 영상·이미지 방법이 장부 사례와 겹치면 그 방법은 옮겨 적지 말고 사례 번호(예: 장부 S17)만 가리킨다. 방법의 정본은 장부다.

## 쓰는 때

- 일을 끝냈을 때와 막혔을 때 둘 다 쓴다. 풀지 못한 막다른 길도 남긴다 — 고침 줄에 「막다른 길: 시도한 것 …, 아직 못 찾음」으로 쓴다.
- 같은 함정이 이미 있으면 새 항목을 만들지 말고 그 항목의 증상·다시 확인을 고친다. 틀린 항목은 고치거나 지운다.
- 새 항목은 파일 끝이 아니라 맞는 `##` 절 끝에 넣는다. 맞는 절이 없으면 새 절을 만들고 목차에 한 줄 더한다. 자주 걸리거나 손해가 큰 함정이면 「먼저 볼 것」에도 한 줄 올리고, 10개 안팎을 넘기면 덜 중요한 줄을 내린다.
- 새 항목 제목 끝에 「(날짜 AI)」를 붙인다(예: 「(2026-10-20 Claude)」). 머리의 「쓴 AI」·「마지막 확인」 줄은 고치지 않는다.
- 기록은 그 작업과 같은 커밋으로 올린다(워크트리에서 `node tools/바로올리기.js <작업 경로…> <노트 경로> -m … --실행`). 기록만 따로 올리는 커밋을 만들지 않는다.
- 계정 이메일·키·토큰·개인 폴더 경로는 적지 않는다. 경로는 저장소 기준(`tools/…`, `.tmp/…`, `../SYNK-talk/…`)이나 `%USERPROFILE%`·`~`로 쓴다.
- 이 노트에 있는 내용을 개인 메모(Claude 메모, Codex 메모)에 다시 늘리지 않는다. 개인 메모에는 노트 경로만 둔다.
