# 제품 방향

## 로드맵

LAB은 한국어 교육과 개인화 학습, SHIFT는 교육·컨설팅·브랜딩과 유학·취업 연계, PULSE는 문화 작품을 다룬다. 현재 요청에 필요한 실제 흐름부터 만든다.

## 제품 계약

상품 조건은 [철학](SYNK_철학.md)과 [온라인 과정 제안](1기_제안문안_v1.md)에 있다. 비전·후보안을 판매 중인 서비스로 표현하지 않는다.

원본·교정·추정·확인과 출처·기준판을 구분한다. 동의·철회·반출은 [개인정보 방침](개인정보처리방침_초안_v1.md)을 따른다. 기존 데이터의 뜻과 저장 규격은 해당 스키마와 코드에서 확인한다.

## 엔진

[역할과 연결](엔진7종_상향설계_v3.md). 수집을 사용하는 기능은 저장 → 자동 소비 → 출력 변화 → 수혜자 전달까지 확인한다. 합성 시험은 실제 학습 효과의 증거가 아니다.
