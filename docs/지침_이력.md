# SYNK 공용 작업 지침 — 변경 이력

> **목적**: 각 조항이 *왜* 생겼는지(근거 사건)를 Claude 메모리 밖(Codex·cowork·GPT 세션)에서도 볼 수 있게 남긴다. 정착된 결정과 거절된 제안을 다시 논쟁하지 않기 위한 것 — 새로 참여하는 세션은 이 파일을 먼저 읽고 "이건 왜 이래?"를 여기서 확인한다.
> 정본 = repo `CLAUDE.md`. 개정 절차는 `/evolve` 스킬. 새 버전을 올릴 때마다 이 파일에 1줄을 추가한다.

## 버전별 요지

- **v3.0 (2026-07-10)** — 공용 작업 지침 최초 확정. 7섹션(역할분담·소통·냉철 진단·자기검증 루프·제안 동반·선제 보완·실행 원칙). 자기검증 루프는 처음엔 **5회**. 자기검증 루프 워크플로(유호 페르소나 + 프롬프트 엔지니어 2렌즈) 5라운드로 47건 이슈를 정제해 제작.
- **v3.1 (2026-07-10)** — 루프 **5→3회**로 축소(과잉적용 방지, 유호 직접 판단). 콘텐츠·기획안 산출물은 루프 대신 **forge 스킬** 신설(A/B 병렬 → 하드 게이트 → 병합). 하위 작업 **모델 라우팅** 조항 추가(코드=Opus급/콘텐츠=Sonnet급/기계적=Haiku급). + 멀티세션 규약·`/deploy` 스킬을 인프라로 도입.
- **v3.2 (2026-07-10)** — 46에이전트 적대적 감사가 잡은 치명 결함 4건 수정: ①루프 보고를 "자기검증을 거쳤다"(자기기만 유도) → **"실제로 잡아 고친 것 1개 명시"**로 교체 ②제안 반복 금지를 "같은 대화" → **"제안하는 순간 즉시 기록"**으로 확장(기억 단절로 반복이 새어 나옴) ③**Fable(모델명) 예외 삭제** — "검증이 가장 필요한 순간에 검증이 꺼지는" 역설 ④**버전 스탬프 도입**(사본 드리프트 탐지, forge 절차 정본은 SKILL.md 한 곳).
- **v3.3 (2026-07-10)** — 조항 감사 후 3개 추가: ①**분리 반박 패스**(비판을 초안 추론과 분리, "애매하면 통과" 기본값 금지 — 실제로 15건 중 0건 탈락하며 헛돈 사건) ②**판독 인용 + 자진 정정**(유호가 못 읽는 스크린샷·코드 근거는 원문 인용 + "~로 보인다", 오독 판명 시 첫머리 철회) ③**비가역 외부 실행 게이트**(메일·발행·대량삭제는 실행 직전 승인). **거절**: "무거운 작업 사전 규모 고지" = 유호가 예고를 소음으로 판단 → **재제안 금지**.
- **v3.4 (2026-07-10)** — **"검증 규모는 결정의 되돌림 비용에 비례시킨다"** 도입. 실측 근거: 지침 52줄을 20% 줄여야 360토큰인데 같은 날 심층감사 하나가 600만 토큰을 태움 — 진짜 낭비는 문서 길이가 아니라 과잉 검증 습관이었다. 가역(git 복구 가능)=가벼운 반박 1패스, 비가역(돈·계약·외부 발행)=심층 검증.
- **v3.5 (2026-07-10)** — "트렌디"의 정의를 지침에 명시: 유행을 **좇는** 게 아니라 **되는** 것(끊임없는 개선의 결과). 유호가 AI의 틀린 이분법("유행에 밝은 게 아니라 개선")을 바로잡은 데서 출발.
- **v3.5 후속 (2026-07-11, 버전 무범프)** — Codex CLI 패리티: `AGENTS.md` 신설(고유 섹션 "새 작업 컨텍스트 복원")·`.agents/skills` 스킬 미러링. ChatGPT용 지침 사본(v3.5-GPT) 제작·배포(ChatGPT Pro = "비서" 역할 확정과 함께).
- **v4.0 (2026-07-11)** — 진화 메커니즘을 지침 골격으로 승격. ①**'지침 진화' 섹션 신설** + `/evolve` 스킬(절차 정본) — 지침·스킬·메모리 전체를 진단→수정→압축→상호발전 사이클로 다룸(유호가 정의한 "트렌디"의 운영형) ②**사본 지도**를 헤더에 명시(정본 ↔ AGENTS.md·COWORK·GPT 사본 — 버전 범프 시 무엇을 같이 갱신할지 모든 세션이 알게, AGENTS.md의 "정본은 AGENTS.md" 자기참조 드리프트 해소) ③**마찰 신호 기록** 조항(유호의 교정·거절·불만·내 실수 중 **굵직하거나 반복되는 것**은 즉시 기록 = 다음 진화의 연료, 제안 기록과 대칭) ④**압축·재편**: 냉철 진단 → 판정·검증에 흡수, 제안 동반 + 선제 보완 병합, 실행 원칙 압축 — 전투검증 조항 10건 의미 전부 보존, "묶음당 1회" 배치 검증 규칙 유지 ⑤`docs/지침_이력.md` 신설(이 문서). 제작: forge(A/B 병렬 + 분리 게이트)로 도출, 게이트가 잡은 결함(외부 공개물의 루프/forge 이중 분류, 배치 규칙 유실, 마찰 기록 무한정 발동)을 수정해 확정.

## 재론 금지 — 정착·거절된 것 (근거는 위 버전 항목)
- 자기검증 루프 **3회**(5회 아님), 모델명 기반 루프 생략 **금지**, "자기검증했다" 문구 대신 **잡아 고친 것 1개**.
- **"무거운 작업 사전 규모 고지"** 조항 — 거절됨(소음). 새 근거 없이 재제안 금지.
- 이 지침의 절차 정본은 **스킬 파일 한 곳**에만 둔다(forge=SKILL.md, 진화=evolve SKILL.md). 다른 문서엔 요약만 — 절차 본문 복제 금지.
- 마찰 신호 기록은 **굵직하거나 반복되는 것만** — 사소한 교정 1건마다 기록하는 무한정 발동은 v4.0 게이트에서 과잉적용으로 기각됨.
