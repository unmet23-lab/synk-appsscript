# SYNK 공용 작업 지침 — 변경 이력

> **목적**: 각 조항이 *왜* 생겼는지(근거 사건)를 Claude 메모리 밖(Codex·cowork·GPT 세션)에서도 볼 수 있게 남긴다. 정착된 결정과 거절된 제안을 다시 논쟁하지 않기 위한 것 — 새로 참여하는 세션은 이 파일을 먼저 읽고 "이건 왜 이래?"를 여기서 확인한다.
> 정본 = repo `CLAUDE.md`. 개정 절차는 `/evolve` 스킬. 새 버전을 올릴 때마다 이 파일에 1줄을 추가한다.

## 재론 금지 — 정착·거절된 것 (근거는 위 버전 항목)
- 자기검증 루프 **3회**(5회 아님), 모델명 기반 루프 생략 **금지**, "자기검증했다" 문구 대신 **잡아 고친 것 1개**.
- **"무거운 작업 사전 규모 고지"** 조항 — 거절됨(소음). 새 근거 없이 재제안 금지.
- 이 지침의 절차 정본은 **스킬 파일 한 곳**에만 둔다(forge=SKILL.md, 진화=evolve SKILL.md). 다른 문서엔 요약만 — 절차 본문 복제 금지.
- 마찰 신호 기록은 **굵직하거나 반복되는 것만** — 사소한 교정 1건마다 기록하는 무한정 발동은 v4.0 게이트에서 과잉적용으로 기각됨.
- **07-27 외부 진단 5건 — 기각(근거 게이트 미통과)**: ①`CLAUDE.md`에 '새 작업 컨텍스트 복원' 절 추가 — AGENTS.md 고유 섹션은 v3.5 후속의 **의도적 설계**이고 evolve SKILL이 보존을 명시, 실제 사건 근거 없음 ②응급복구 절차를 지침에 연결 — 런북 경로는 **월간 복구 리허설 메일**이 이미 안내(AI 조항보다 유호님께 직접 도달) ③사본 동기화 해시 검사 — 실측 드리프트 **0**(CLAUDE↔AGENTS 차이는 의도적 델타, 스킬 미러 차이는 줄바꿈), 예방 논거뿐 ④`Code.js` 크기 상한 조항 — 관찰(948KB)뿐이고 크기에 기인한 실제 사건 없음 ⑤docs 아카이브를 지침 조항으로 — `docs/문서_지도.md`가 정본/폐기를 이미 관리. 전부 **새 근거(실제 사건) 없이 재제안 금지**.
