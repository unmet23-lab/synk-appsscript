# 개원 전 온라인1기 — 현재 판매안 종료

2026년 10월 2일 현행화. 기존 한국 온라인1기는 현재 모집·판매·개원 매출 계획에서 제외했다. 이 경로는 과거 설계의 상태를 확인하는 입구이며 모집 안내, 결제 링크, 개강 예정표로 사용하지 않는다. 당시 문서의 계획은 실제 발송·결제·수업 완료를 뜻하지 않는다.

## 현재 기준

- 울란바토르 공간·공개 수강료·모집일·개원일은 미확정이다. 공개 체험과 등록은 실제 공간·강사·시간표·제공 서비스·안전·계약이 준비된 뒤 안내한다.
- 토90분과 평일 녹화만으로 평일 동등 진도·말하기·승급을 보장하는 주말 상품도 개원 판매대상에서 제외했다. 새 온라인 상품은 실제 공급·과제·피드백·앱 기능·동의/권한·가격·원가·계약을 검증한 뒤 별도로 결정한다.
- SYNK WORLD·교사 앱·플랫폼의 학습/계정 개발과 승인된6개월 온라인 앱 학습 지원은 유지한다. 이 온라인1기의 종료를 모든 온라인 학습 취소로 확대하지 않는다.
- 과거 제안이 실제 발급되거나 납부된 기록이 있다면 당시 조건과 개별 기록을 따로 확인한다. 이 문서 변경을 이미 발급한 조건의 일방 변경이나 미지급 환불의 완료 증거로 쓰지 않는다.

현재 준비 순서는 [오프라인 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md), [파일럿·체험의 선행 조건](파일럿_체험2주_설계_v1.md), [FAQ 공개 조건](자주묻는질문_정본.md)을 따른다. 실제 기록과 앱 기능은 담당 구현/인수 증거로 확인한다.
