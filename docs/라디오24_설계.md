# 라디오24 — 송출·화면·채팅 운영 설계

> 현행 코드·문서 대조 · 2026-10-08. 유튜브 라디오의 음악·송출·화면·인사 반응 경계를 정한다. 곡 제작·편성은 [Reed](Reed_설계_v0.1.md), 새 시각 장면은 [Loom 표현 기준](Loom_실시간장면_표현기준.md)을 따른다. 이번 대조는 로컬 검증이며 현재 방송 수신·청취를 새로 확인한 결과가 아니다.

## 0. 현재 범위와 확인된 실물

라디오는 음악을 편안하게 감상하고 곁에 둘 수 있는 자리다. 라디오 퀴즈·학습 사건 승격·채팅 원장 수집은 2026-10-03에 삭제했다. 음악 편성과 화면 인사 반응은 남아 있으며, 이를 학생 학습 기록 수집으로 해석하지 않는다.

- **마지막 승인·공개 확인:** 10-05 최종 결과는 [이전 한옥 마당 복원·22곡 재개명](라디오/배경제목재수정_20261005/README.md)이다. 사용자가 같은 날 앞서 만든 반딧불 들판 배경과 첫 제목안을 거절해 `still-dusk-kite-20260919-3d54fb291a54.mp4` 원본(60초·720p·12fps)으로 되돌렸다. 세 친구가 영상에 포함되어 별도 마스코트 층은 제외한다. 앞선 [음원 복구](라디오/송출복구_20261005/README.md)의 원곡 61.6초와 22곡 약 70분 2초 시간표 경계는 유지하고, 첫 곡 표시 제목은 「오늘 밤은 너와」로 바꿨다. 소개·썸네일·공개 수신 확인은 최종 복원 기록을 따른다. [YouTube 라이브](https://www.youtube.com/@synkkorean/live)의 현재 상태는 다시 확인해야 한다.
- **곡 제목·모음집 (2026-09-27):** 현재 곡을 화면 오른쪽 위에 상시 표시하고 실제 송출 시각에 맞춰 바꾼다. [19곡 일부공개 모음집](https://youtu.be/_eZztHpxPeI)에 곡별 시간 링크·챕터를 넣어 라이브 설명란과 연결했다. [반영·공개 수신 검증](라디오/곡제목_모음집_20260927/README.md).
- **앱 경계:** 09-06 확정대로 앱 안 자습 재생기·개인 청취 수집은 접었다. 앱에는 유튜브 라디오 링크·안내를 두며, 곡 수·학생 수를 이유로 앱 재생기를 자동 재개하지 않는다.
- **현재 곡 선택:** 09-08 확정 Suno 승인곡과 [음악 자산 장부](음악자산_장부.md)를 따른다. 과거 합성·Minimax 곡 생산 계획은 현재 지시가 아니다.
- **현재 관측:** 위 보고는 당시 반영 증거다. 지금의 정상 송출·계정 상태는 현재 도구로 다시 확인한다. 장시간 청취·무중단은 아직 별도 검증 대상이다.

## 1. 설계 원칙

승인된 음원·배경·곡 경계를 보존하고 실제 출력 시각·재생·공개 수신으로 확인한다. 파일 목록이나 프로세스가 살아 있다는 사실만으로 청취 성공을 선언하지 않는다. 공개 라디오에서 학생 개인 약점·성적·순위를 드러내지 않는다.

앱 개인 청취·정서·성향 수집과 학생 연결은 현행 기능이 아니다. 음악·인사 반응을 변경할 때 폐기한 학습 봇이나 라디오 DB 원장을 의존성으로 되살리지 않는다.

## 2. 현재 실행 원천

| 기능 | 현재 코드 원천 | 계약상 구분 |
|---|---|---|
| 음악 블록 순서·목록 생성 | SYNK-talk [라디오곡차례.js](../../SYNK-talk/lib/라디오곡차례.js), [재생목록.js](../../SYNK-talk/bots/송출/재생목록.js) | 번호와 장르 블록 순서를 분리하고 알 수 없는 트랙도 누락하지 않음 |
| 현재 곡 표시 | [현재곡.js](../bots/오버레이/현재곡.js) | 실제 인코더 `out_time`과 목록 SHA·시간표를 연결. 실행 중 제목만 갱신 |
| 소리·무대·오버레이 송출 | [겹쳐송출.js](../bots/오버레이/겹쳐송출.js) | 음원·무대를 따로 읽어 FFmpeg로 합성. 화면 사건을 기존 BroadcastChannel로 전달 |
| 출력 정체·복구 판정 | [송출진척.js](../bots/오버레이/송출진척.js) | 시작 유예와 실제 출력 시각의 전진을 확인. 느린 진행과 정체를 구분 |
| 공개 채팅 인사 반응 | `겹쳐송출.js`의 `채팅감시` | 자격이 있을 때 새 발화자의 화면 인사. 프로세스 메모리의 중복 방지이며 학생 원장·학습 승격이 아님 |

### 2-1. 실제 전달의 확인

곡 제목은 CDP 호출이 반환돼도 `exceptionDetails`가 있으면 미전달로 두고 재시도한다. 이것은 브라우저 실행 경계 확인이며 공개 화면 도달·청취는 별도로 확인한다. 인사 반응의 현재 운영 여부도 자격·서버 실행·화면 수신을 대조하며 코드 존재로 대신하지 않는다.

### 2-2. 폐기한 학습 명령

옛 답·빗소리/asmr·슬럼프·출석·목표 명령과 학생 사건 승격은 10-03 삭제 범위다. `라디오채팅파서.js`·`라디오수집.js`·`라디오출제.js`·`라디오승격.js`·퀴즈용 `라디오편성.js`를 현재 코드 입구로 안내하지 않는다. 음악 순서 회귀는 이 모듈들 없이 실행되는지와 실제 목록 생성 결과를 확인한다.

## 3. 공개 반응과 개인 기록의 경계

- 공개 채팅·오버레이에 학생 코드·실명·급수를 올리지 않는다. 표시 가능한 닉네임도 실명·학생 식별정보가 섞였는지 기존 필터로 확인한다.
- YouTube 채널 ID·표시명을 학생 ID나 학습 근거로 사용하지 않는다.
- 현재 인사 코드가 사용하는 채널별 중복 방지와 닉네임 표시를 개인 청취 이력·동의·학습 원장으로 확대하지 않는다.
- 새로운 수집·학생 연결이 필요하면 현재 요청·목적별 동의·제품 호스트의 권한 계약부터 다시 정한다. 옛 승격 설계는 구현 지시가 아니다.

## 4. 삭제한 저장·승격 경로

SYNK-talk의 라디오 퀴즈·수집·승격 함수와 봇은 2026-10-03에 삭제했고, 옛 `radio` 테이블 여섯 개는 10-06 정리했다. 적용 근거와 남은 운영 사항은 [트랙의 talk 서버 정리](_ops/트랙.md)에서 확인한다. 과거 마이그레이션 파일이나 Git 밖의 함수 폴더 잔여물은 현재 실행·배포 대상이 아니다.

현재 방송 변경에 학생 연결·퀴즈 원장·집단 문항 추첨을 필수로 붙이지 않는다. 옛 설계의 링크/동의 이력·원문 승격 규격은 [정리 전 기록](https://github.com/unmet23-lab/synk-appsscript/blob/f657502b1c85/docs/%EB%9D%BC%EB%94%94%EC%98%A424_%EC%84%A4%EA%B3%84.md)에 보존하며 현행 기능으로 설명하지 않는다.

## 5. 방송 파이프라인

현재 실물은 브라우저에서 장면·표정·오버레이를 그리고 FFmpeg로 곡과 합성해 송출한다. 배경은 매체·자산에 따라 영상 또는 실시간 장면을 사용한다. 09-09 연속 소리는 FLAC 원본을 연속 디코딩해 반복 경계 틈을 줄였다. 사전 인코딩 `-c copy`만 허용하던 옛 발주와 고정 팩 길이는 현재 방식의 개선을 막는 조건이 아니다.

현재 배치·설정·서버 파일은 최종 반영보고와 좁은 반영 도구에서 확인한다. 자격증명 파일을 덮어쓰지 않고 필요한 칸만 갱신하며 값은 출력·기록하지 않는다. 인사 반응의 방송 재발견·채팅 ID 재연결·호출 간격은 `겹쳐송출.js`가 실제 API 응답과 설정으로 관리한다. 곡 제목 시계는 벽시계 대신 실제 인코더 출력 시각을 사용한다.

## 6. 운영에서 확인할 것

송출 프로세스가 살아 있는 것과 유튜브가 수신·공개 재생하는 것을 함께 확인한다. 방송 출력 시간의 전진, 캡처 오류·연결·자동 재시작을 본다. 실패 회차를 정상 재생으로 숨기지 않고 기존 복구 장치를 사용한다. 새 중앙 감시 체계·강제 훅을 이 문서 정리의 일부로 만들지 않는다.

학생 얼굴 실황·학생 개인 데이터 공개·자동 공개 AI 답변은 현재 라디오 범위로 자동 추가하지 않는다. 감상·채팅 참여를 학생 집중·감정·교육 효과로 단정하지 않는다. 실제 플랫폼·계정·비용 조건이 필요한 변경은 실행 시 현재 상태로 확인한다.

## 7. 결정과 남은 일

남은 일은 [트랙](_ops/트랙.md)의 라디오 항목에서 유지한다. 10-05 최종 재시작 이후 당시 자동 복구 0회와 앞선 별도 디버거 연결 직후 2회를 구분한다. 앞선 정체의 근본 원인은 미확정이며 차단한 라이브 디버거 검사 스크립트는 재실행하지 않는다. 현재 공개 수신·곡 전체 청취·음량/이음새·장시간 무중단은 각각 새 증거로 확인한다.

## 8. 화면의 목적

음악과 무대·마스코트가 편안하게 함께 보이게 한다. 퀴즈·합산 수치·타이머·광고를 화면에 전부 상시 붙이지 않는다. 기능을 제공할 때 현재 목적에 필요한 안내를 읽히게 하고 결과는 실제 재생으로 판단한다.

### 8-2. 표면 규격

기본은 음악·빛·무대·마스코트와 작은 출처 표기다. 승인 자산·로고·문면은 현재 디자인 원천과 실제 제작 코드에서 읽는다. 모든 지원 매체에 [Loom 표현 기준](Loom_실시간장면_표현기준.md)을 적용하되 모든 요소를 상시 흔들지는 않는다.

#### 8-2-1. 마스코트와 배경

라디오 DJ는 현재 무언이 기본이며 필요 순간의 기존 효과음을 드물게 쓴다. 표정 전환은 [공통 털 바탕·눈 영역 기준](캐릭터/캐릭터_생명감_설계.md#1-a-표정-전환의-재질-고정)을 따른다. 09-10 실물은 기본·눈감음·눈웃음 세 그림으로 여러 사건 표정을 연결했다. 이것을 모든 캐릭터의 표정 수 제한으로 쓰지 않는다.

#### 8-2-2. 사건 연출

인사·DJ 교대·축하는 읽기와 감상을 방해하지 않게 짧게 나타났다 돌아온다. 같은 영역의 연출이 겹치면 기존 순서 처리로 정리한다. 특정 초·큐 크기·트랜스폼 전용 규칙은 담당 코드의 현재 선택이며 다른 매체의 금지가 아니다.

#### 8-2-3. 채팅 안내

채팅에서 제공하는 명령과 화면에서 권하는 명령을 구별한다. 현재 목적에 맞는 안내를 적게 제시한다. 공개적으로 민감한 감정·개인 사정을 말하도록 압박하지 않는다. 명령 개수 자체를 고정하거나 무용한 기능을 남기는 이유로 쓰지 않는다.

## 9. 검증

관련 변경에 맞춰 SYNK-talk `tests/라디오곡차례.test.js`와 이 저장소의 `tests/현재곡.test.js`·`tests/라디오송출진척.test.js`·오버레이/차림 시험을 실행한다. 곡 순서 시험은 폐기한 퀴즈 모듈 없이 동작하는 것과 실제 ffconcat·편성표 생성 결과를 함께 확인한다. 출력 변경은 실제 브라우저와 유튜브 수신·청취로 확인한다. 로컬 시험 통과나 문서 정리를 실서비스 변경·학생 사용 검증으로 보고하지 않는다.
