# 마케팅 확장안 — SHIFT의 중심을 1인 기업 수업으로

> 2026-09-09 · [마케팅 정본](마케팅_정본.md)의 후속 편성안. 사용자 확정과 AI 추천을 구별한다. 아래 신규 콘텐츠·자료실·채널은 제작/개설 완료가 아닌 설계다. 제작 속도·요소·브랜드 킷 부족은 우선순위나 추가 배제의 이유로 사용하지 않았다.

## 1. 결론과 확정 범위

**추천하는 방향: ‘우리가 얼마나 잘 만드는지 보여주는 회사’에서 ‘내 사업을 더 잘 만들 수 있게 가르쳐 주는 회사’로 중심을 옮긴다.** 홍보물의 완성도는 그대로 유지하고, 공개 강의·자료·후속 도움을 더해 실제 쓸모가 축적되게 한다.

| 사용자 확정 | 이번 AI 추천 — 아직 확정하지 않은 것 |
|---|---|
| SHIFT의 주력은 1인 기업 브랜딩 및 강의 | 첫 독자를 한국어권 성인 지식·서비스형 1인 기업자로 좁히기 |
| 홍보성 릴스는 유지, 메인은 1인 기업에 필요한 것을 주는 콘텐츠 | 공개 수업·자료실·클리닉·검색 글·후속 편지를 한 학습 흐름으로 연결 |
| 끝의 참여 안내에도 관련 정보·꿀팁을 편성 | 아래 연재명·자료명·비율·빈도·첫 4주 구성 |
| 제작 속도를 병목으로 삼지 않음 | 네이버 블로그·카카오톡 채널·Pinterest 등 추가 채널의 역할별 추천 |

기존 유학·대학 알선/협력·기관 강의·강사 에이전시·제작 서비스는 남긴다. 피드의 첫 독자와 앞에 놓는 문제를 바꾸는 것이지 사업·계약 주체를 지우는 결정이 아니다. 국가·업종·가격·개강·지원 기간·광고비·새 계정 개설은 이번에 확정하지 않는다.

제작 의뢰를 안내할 때도 기존 **제작 PULSE / 계약·청구·고객 관계 SHIFT**의 구분을 유지한다. 콘텐츠의 주력 변경으로 책임 주체나 납품·이용 조건을 바꾸지 않는다.

## 2. 추가하면 가치가 큰 여덟 가지

순서는 제작 난이도가 아니라 **실제 도움 → 다시 찾기 → 맞는 강의 선택**의 연결에 따른 추천이다. 서로 필요한 자료를 연결하면서 병렬 준비할 수 있다. 효과는 아직 가설이며 조회수 상승이나 매출을 보장하지 않는다.

| 추천 | 추가할 것 | 기존 구성에서 더해지는 역할 | 첫 실물 예시 |
|---|---|---|---|
| 1 | **1인 기업 공개 수업 시리즈** | 짧은 관심을 체계적으로 배우는 경험으로 연결 | 한 문장 소개 → 상품 한 장 → 콘텐츠 → 문의·납품의 순서가 보이는 재생목록 |
| 2 | **상황별 실무 자료실** | 흩어진 게시물을 실제 쓰는 자산으로 바꿈 | ‘소개를 못 쓰겠어요 / 상품 설명이 막혀요 / 문의 대응이 반복돼요’로 고르는 서가 |
| 3 | **검색해서 들어오는 글** | 피드를 넘기는 사람 외에 지금 문제를 찾는 사람의 입구 | ‘1인 강사 소개서 구성’, ‘첫 서비스 제안서에 넣을 것’, ‘고객 문의 답변 정리’ |
| 4 | **공개 브랜드 클리닉** | 팁이 내 상황에서는 어떻게 달라지는지 보여줌 | 같은 서비스 소개를 고객별 세 상황으로 고쳐 보는 실연과 작업지 |
| 5 | **선택형 후속 편지** | 자료를 받은 뒤 실제로 쓰다 막히는 지점까지 연결 | 시작법 → 적용 예외 → 수정판·다음 수업. 기존 Substack 창업 갈래 활용 |
| 6 | **다른 전문가와 공동 수업** | 우리 채널 밖의 적합한 청중을 만나고 판단의 깊이를 더함 | 강사·디자이너 등과 공개용 예시 하나를 각자의 전문성으로 완성 |
| 7 | **강의 적합성 체험과 명확한 과정 안내** | 관심은 있지만 나에게 맞는지 모르는 사람의 선택을 도움 | 미니 실습 1개·결과 견본·선수조건·다루는/다루지 않는 문제 |
| 8 | **사용 뒤 개정판과 작업물 아카이브** | 캠페인마다 사라지는 자료 대신 돌아올 이유를 축적 | ‘수정 요청을 받은 뒤 바뀐 한 줄’, 버전·사용법·권리가 붙은 결과물 |

자료실은 다른 플랫폼 계정이 아니라 **기존 웹 안의 목적별 도착 페이지**를 우선 추천한다. 게시물에서 약속한 파일로 바로 도착하고, 검색·짧은 영상·수업에서 같은 원본을 참조하게 한다. 소개 홈으로만 돌려보내거나 모든 자료를 하나의 ZIP에 숨기지 않는다.

## 3. 새 채널은 이 역할로 추가한다

| 채널 | 추천 정도·대상 | 구체적인 내용 | 구분할 조건 |
|---|---|---|---|
| **네이버 블로그** | 한국어권 SHIFT 타겟을 택할 경우 우선 추천 | 한 질문의 답·작성 예시·실습 안내가 완결되는 검색형 글. 최신 원본 자료는 웹에 연결 | 기존 계획에서 신규 후보이며 개설 기록·현재 상태 미확인. 이미지 카드만 붙이지 않는다. 검색 노출·문의 증가 보장은 없음 |
| **카카오톡 채널** | 한국어권 성인에게 강의·브랜딩을 안내할 때 추천 | ‘배우고 싶음 / 제작 의뢰 / 기관 강의’ 입구와 실제 제공 범위에 관한 문의 | 자료 다운로드에 채널 추가를 강요하지 않음. 기존 Telegram 연락과 역할을 합의하고 안내·응답 조건을 정한 뒤 개설 |
| **Pinterest** | SHIFT 시각 브랜딩·PULSE 작품 탐색의 별도 시험 후보 | 완성 브랜드 지면·재질·편집 예시를 용도별 보드로, 관련 실습/작품 페이지에 연결 | 한국어 강의 구매자와 일치하는지는 미확인. 시각 발견에 맞는 콘텐츠만 시험하고 실적·유입을 따로 확인 |
| **기존 YouTube 안의 수업 재생목록·라이브** | 새 계정 없이 적극 강화 | 단계별 공개 수업, 완결 실습, 공개 클리닉 | 별도 ‘1인 기업’ 계정을 또 만들기보다 현재 yuhobuilds의 정체성을 강화하는 편을 추천 |
| **기존 Substack 창업 갈래** | 새 발행물보다 목적 명확화 우선 | 자료 활용·개정·다음 실습에 대한 후속 편지 | LAB 교육 구독자를 자동 전환하지 않음. 수신 목적·갈래·해지 안내와 실제 설정 확인 |

네이버는 중요한 정보를 본문 텍스트로 제공하고 주제·경험·출처를 일관되게 유지하라고 안내한다. 이는 웹 콘텐츠 일반 지침이지 블로그 개설 시 상위 노출을 보장하는 규칙이 아니다. [네이버 원문](https://searchadvisor.naver.com/guide/content-basic), [Google의 사람 중심 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).

카카오 공식 가이드는 이용자가 먼저 시작하는 1:1 채팅과 채팅 가능 시간 설정을 설명한다. 문의 창구 제안은 이 기능을 활용하자는 것이며, 실제 계정 지원·메시지 과금·광고성 안내 조건을 확인하기 전 자동 발송이나 즉시 응답을 약속하지 않는다. [카카오 공식 가이드](https://kakaobusiness.gitbook.io/main/channel/run/chat).

Pinterest는 이미지·영상 Pin에서 사이트로 연결할 수 있다고 설명한다. 우리의 시각 자료와 맞을 수 있다는 **전략적 추론**이며 한국의 강의 수요를 입증한 것은 아니다. [Pinterest 공식 안내](https://business.pinterest.com/how-to-make-pins/).

오프라인 LAB은 실제 고객을 만나는 장소·권한·운영 정보가 준비되었을 때 지도 검색 프로필도 검토할 만하다. 반대로 온라인 전용 SHIFT를 주소만으로 지도 업체에 등록하자는 제안은 하지 않는다. Google은 온라인 전용 사업을 Business Profile 비대상으로 명시한다. [자격 조건](https://support.google.com/business/answer/13763036?hl=en).

## 4. SHIFT의 첫 독자와 콘텐츠 기둥

처음에는 **전문성은 있지만 고객에게 설명하고 상품·수업·납품으로 잇는 체계가 부족한 1인 사업자**를 추천한다. 강사·컨설턴트·디자이너·교육/콘텐츠 제작자가 첫 예시다. 쇼핑몰·매장업·모든 부업을 한 번에 대표하지 않는다. 나이·매출로 성격을 단정하지 않고 지금 해야 할 일로 나눈다.

| 지금 상태 | 실제로 필요한 것 | 콘텐츠 기둥·제목 방향 | 제공물 |
|---|---|---|---|
| 내 전문성은 있는데 설명이 막힘 | 누구의 어떤 문제를 푸는지 | **브랜드** — ‘소개 첫 줄에 남길 세 가지’ | 한 문장 작업지 + 업종별 채운 예시 |
| 무엇을 팔지 정리되지 않음 | 고객·결과·포함/제외·전달 방식 | **상품** — ‘서비스를 한 장으로 설명하기’ | 상품 구성표·선택 기준. 임의 매출·가격 보장 없음 |
| 올릴 것은 많은데 사업과 연결되지 않음 | 고객 질문을 콘텐츠로 바꾸는 법 | **콘텐츠** — ‘상품 하나에서 열두 개 질문 꺼내기’ | 콘텐츠 지도·도입부 예시·관련 자료 연결표 |
| 문의 뒤 같은 설명을 반복함 | 대상·사용처·범위 확인과 다음 안내 | **영업 접점** — ‘문의가 왔을 때 먼저 물을 세 가지’ | 상담 전 질문·한 장 제안·후속 안내 예시 |
| AI 도구를 써도 일이 흩어짐 | 업무 입력·결과·사람 확인의 연결 | **운영** — ‘도구 셋을 한 업무로 묶기’ | 업무 지도·입력 예시·결과 점검표. 내부 엔진/학생 자료는 공개 안 함 |
| 전문성을 강의로 만들고 싶음 | 수강자가 직접 끝낼 실습과 확인법 | **강의 설계** — ‘듣고 끝나지 않는 한 수업 만들기’ | 시작 파일·완성 예시·과제·자기 점검 |

무료와 유료는 정보의 정직함이나 기본 품질로 가르지 않는다. **무료는 문제 하나를 온전히 해결**, 체계적 강의는 문제들을 순서대로 연결하고 실제 제공 가능한 피드백·적용 지원을 더하는 방향이다. 유료 과정의 세부 지원은 계약 전 확정할 사항이며 현재 제공한다고 말하지 않는다.

## 5. 명품 기준을 적용한 네 가지 연재 장치

아래 명칭은 작업명이며 새 공식 상품명·상표가 아니다. 기존 명품 기준의 선택·고유한 표현·완결성·사용 뒤 책임을 구현하는 편집안이다.

1. **공개제작실:** 빈 화면부터 도구를 훑지 않고 완성 결과와 고객 문제를 먼저 보여준다. 왜 그 한 줄·순서를 택했는지 실제 판단과 검사를 수업으로 만든다.
2. **사업 한 칸:** 시청자가 볼 때마다 자기 사업의 한 부분을 완성한다. 한 문장 소개, 상품 한 장, 문의 답변, 납품 안내가 차례로 쌓인다. 영상만 보아도 한 가지를 해볼 수 있어야 한다.
3. **같은 일, 다른 조건:** 강사·디자이너·컨설턴트가 같은 틀을 어떻게 다르게 쓰는지 보여준다. 단순 색 교체가 아니라 고객과 사용처 때문에 달라지는 판단이다.
4. **사용 뒤 개정판:** 실제 질문이 생기면 자료를 고치고 수정 이유를 남긴다. 실제 질문이 없을 때는 ‘공개 예시 점검’이라고 표시한다. 질문·후기·학생 성과를 만들어내지 않는다.

Loom·기존 폰트·회사별 스티치 로고·고해상도 소품은 이 네 형식의 표정과 읽는 순서를 유지하는 데 쓴다. 자료도 **채운 예시 + 편집 가능한 원본 + 바꿀 곳 표시 + 검사법 + 이용 조건·수정일**을 갖춘다. 명품화는 전편에 적용하되 전편을 같은 미니멀 구도로 복사하지 않는다. 양모 이미지는 연출 자산이며 실제 손바느질 작업처럼 소개하지 않는다.

최근 [스티치 적용 기록](홍보물/계정별콘텐츠_20260909/_개선/스티치_적용기록.md)과 [명품 기준](명품_기준_v1.md)을 이어 쓴다. 새 로고 스타일·팔레트·마스코트 정본을 이번 전략으로 다시 만들지 않는다.

## 6. 마지막 참여 안내 — 다음 자료도 같은 문제를 풀어준다

CTA는 콘텐츠 끝의 **다음 행동 안내**다. 순서는 `본편에서 팁 제공 → 관련 자료를 직접 써보기 → 원할 때 후속 수업/편지 → 맞는 강의 안내`다. 전부 거쳐야 하는 가입 절차가 아니며 자료실과 수업에 바로 들어갈 수도 있다.

| 편의 주제 | 마지막에 실제로 보여줄 팁 | 뒤에 편성할 자료 | 안내 문구 초안 — 자료가 실제 공개된 뒤에만 사용 |
|---|---|---|---|
| 브랜드 소개 | ‘누구에게 / 무엇을 / 어떤 결과로’를 확인 | **1인 기업 소개문 작업지** | ‘방금 세 칸으로 내 소개도 써보세요. 채운 예시와 수정 원본은 자료실에 있습니다.’ |
| 상품 구성 | 고객이 받는 결과와 포함하지 않는 범위를 분리 | **첫 서비스 한 장** | ‘이번에는 내 서비스의 결과·포함·제외를 채워보세요. 같은 구조의 예시를 함께 뒀습니다.’ |
| 콘텐츠 기획 | 고객 질문 하나에서 제목과 적용 예시를 뽑음 | **상품 하나, 콘텐츠 지도** | ‘내 고객이 먼저 물을 질문부터 적어보세요. 질문을 꺼내는 작업지로 이어집니다.’ |
| 문의 대응 | 사용처·원하는 결과·필요 시점부터 확인 | **문의 답변 세 줄** | ‘문의가 오면 이 세 가지부터 확인하세요. 상황별 답변 예시도 볼 수 있습니다.’ |
| AI 운영 | 입력·완성 결과·사람이 확인할 곳을 한 줄씩 적음 | **혼자 쓰는 업무 지도** | ‘자동화할 도구보다 확인할 지점을 먼저 정해보세요. 한 업무 예시를 함께 공개했습니다.’ |
| 브랜딩 홍보 릴 | 실제 사용 크기에서 첫 읽힘 한 가지 확인 | **내 브랜드 접점 점검표** | ‘예쁜지 보기 전에 처음 읽히는 뜻을 확인해보세요. 이 결과에 쓴 점검 질문을 공개했습니다.’ |

핵심 팁을 전부 가입 뒤로 숨기지 않는다. 자료 링크와 전달 기능을 실제 확인하기 전 ‘드릴게요’·‘댓글 달면 자동 발송’이라고 하지 않는다. 공개 댓글의 전화번호·이메일·고객 자료·매출 화면 수집, 친구 태그·불안·가짜 마감은 쓰지 않는다. 자발적인 적용 질문은 받을 수 있으며 자료 열람 조건과 분리한다.

기본 자료는 댓글·팔로우·이메일 제출 없이 열고, 후속 구독은 별도 선택으로 둔다.

**플랫폼 경로:** YouTube Shorts의 관련 영상은 같은 채널의 영상에 연결하는 기능이다. synkbrief Shorts에서 yuhobuilds 본편으로 직접 설정할 수 있다고 안내하지 않는다. Shorts 설명·댓글 URL은 클릭 링크로 쓰지 않고 실제 프로필·지원되는 관련 영상으로 안내한다. 엔드스크린의 외부 사이트 링크도 계정 자격 확인 없이 기본값으로 삼지 않는다. 상세 조건과 공식 출처는 [기능·하드게이트 검토](_ops/마케팅확장_20260909/검토.md)에 있다.

## 7. 첫 4주 편성 — 순서 제안, 출시 일정 아님

시작 비율은 **실용 수업/팁 70 · 실제 제작 판단 20 · 순수 브랜드/강의 홍보 10** 정도를 추천한다. 최적 비율을 실증한 수치가 아니며 기획 주제의 주된 목적을 분모로 본다. 채널별 재게시 횟수로 부풀리지 않는다. 홍보 편에도 해당 주제의 실용 CTA는 넣는다.

| 주 | 공개 수업의 중심 | 짧은 콘텐츠·실제 판단 | 그 주의 자료 | 후속 참여 |
|---|---|---|---|---|
| 1 | 내 전문성을 고객이 이해하는 브랜드 문장으로 | 대상이 바뀔 때 첫 줄 3안, 소개서 실제 편집 이유 | 소개문 작업지·채운 예시 | 내 상황으로 바꾸기·관련 적용 질문 |
| 2 | 서비스를 한 장의 상품 설명으로 | 포함/제외 구분, 문의에 앞서 확인할 질문 | 첫 서비스 한 장·문의 답변 예시 | 공개 클리닉의 예시 함께 고치기 |
| 3 | 상품에서 고객에게 필요한 콘텐츠 꺼내기 | 고객 질문→도입부, AI 초안의 실제 확인법 | 콘텐츠 지도·업무 입력/확인 예시 | 적용 예외를 다루는 후속 편지 |
| 4 | 소개·상품·문의·납품을 한 경험으로 잇기 | 인수 방식, 실제 브랜드 홍보 릴과 점검 팁 | 첫 달 자료 묶음·인수 안내 | 미니 강의 체험·준비 상태가 표시된 과정 안내 |

**발행 리듬 가안:** 공개 본수업 주 1편, 짧은 실습/판단 영상 주 3편, synkbrief 적용형 캐러셀 주 2편, 후속 편지 주 1편, 공개 클리닉 월 2회. 본수업은 12~20분을 시작 가안으로 하되 완결 실습에 맞춰 조정한다. 신규 별도 제작도 가능하며 격주 본편·재활용 전용을 상한으로 두지 않는다. 이 빈도를 사용자 확정·발행 중·청중에게 약속한 일정으로 쓰지 않는다.

기존 16개 계정용 컬렉션은 이전 완성본으로 보존한다. 다음 편성에서 소개서·캐릭터·인수 콘텐츠를 1인 기업자의 작업으로 연결하며, 대학 비교 콘텐츠는 기관/유학 자료 갈래로 둔다. 이번 요청만으로 이미 만든 MP4·원고·ZIP을 전부 덮어쓰지는 않는다.

## 9. 해볼 만한 다음 확장과 판단 기준

강의 주제와 적합한 청중이 확인되면 실제 전문직·창업 커뮤니티와 **공동 실습회**, 공개 가능한 성인 작업물의 **편집 전후 전시**, 필요한 자료의 **업종별 판본**을 추천한다. 협업·작업물 공개 동의와 실제 제작 여부를 확인하며 고객 자료는 기본적으로 사용하지 않는다. 동의받은 공개용 별도 예시를 새로 준비하는 방식이 기본이다.

유료 광고나 재방문 광고는 성인 대상·실제 과정·동의·예산이 준비되면 별도 후보로 검토할 수 있다. 이번 제안은 기존 LAB 광고비를 SHIFT로 옮기거나 광고 지출·추적 도구 설치를 승인하지 않는다.

좋은 방향인지는 자료를 자기 상황으로 바꿔 써보는가, 다음 수업을 찾는 이유가 구체적인가, 문의의 대상·문제·원하는 결과가 맞는가로 본다. 다운로드·구독·조회는 참고이며 고객·숙련·매출과 동일하지 않다. 제작량이 아니라 **시청자에게 생긴 일의 변화와 실제로 약속을 이어갈 수 있는가**를 확인한다.
