# 디자인 명품화 기준

> 2026-09-18 · 사용자 요청으로 디자인 기준을 복구한다. 홈페이지·앱·영상·캐러셀·문서·인쇄물·브랜드 자산 등 디자인 작업에 해당 항목을 기본 적용한다. 매번 별도 명품화 요청을 기다리지 않는다.

## 적용 범위

명품화는 재질과 표현의 정밀함, 읽힘, 자연스러운 움직임, 사용성과 마감을 뜻한다. 말투·문장 어미·캐릭터 대사 패턴·고정 카피·판매 화법은 이 기준에 포함하지 않는다. 글자의 시각적 위계·서체·줄바꿈과 대상 언어의 읽힘은 디자인 범위다. 자산·색·서체는 [DESIGN](../DESIGN.md), 대상·언어는 [채널](마케팅/채널과_발행.md)의 현재 원문을 따른다.

## 제작에 적용할 기준

2026-09-27 사용자 추가 기준: 시청자에게 보여주는 결과물은 [볼 이유·정보·재미·친절한 설명](마케팅/콘텐츠_제작양식.md#시청자가-볼-이유부터-정하기)을 먼저 설계한다. 애니메이션·내레이션·효과음과 모든 세부 마감은 그 목적을 실제로 전달하도록 다듬으며, 작동 성공이나 장식의 양으로 콘텐츠 품질을 대신하지 않는다.

펠트는 SYNK의 물건·캐릭터·장면에서 드러나는 재질이다. 펠트와 실땀을 쓰는 자리에서는 섬유·꼬임·접촉 그림자와 모서리를 실제 크기에 맞춘다. 2026-09-18의 재질 방향을 모든 구분선·단추의 고정 모양으로 적용하지 않는다. 플랫폼·WORLD의 최신 시그널 화면은 단색 면·얇은 선·알약 조작과 펠트 사진을 함께 쓴다.

양식은 산출물별 최신 원문을 고른다. [플랫폼 시그널](디자인/플랫폼_시그널/README.md), [WORLD 시그널](디자인/월드_시그널/README.md), [SNS 키트](디자인/SNS키트/README.md), [펠트 스크랩북](디자인/펠트스크랩북/README.md)은 적용 범위가 다르다. 2026-09-29 스크랩북을 모든 새 앱의 출발점으로 강제하지 않는다. 승인된 제품별 구성을 공통 양식에 맞추려고 되돌리지 않는다.

유리는 해당 제품에서 채택한 자리에서 두께·가장자리 반사·접촉 그림자를 다듬는다. 글자를 가리는 반사광과 과한 테두리를 줄이고, 단색 카드까지 모두 유리로 바꾸지 않는다. 3D 공간·펠트 사진·UI의 재질 역할을 나눠 실제 표시 크기에서 확인한다.

| 영역 | 적용 |
|---|---|
| 구성 | 목적·사용 크기·구도·정보 순서·여백을 첫 제작부터 구체화한다. 핵심이 먼저 보이게 하고, 관련 정보의 정렬·간격·줄바꿈을 다듬는다. 과밀은 묶음과 단계로 해결하며 필수 내용을 무작정 없애지 않는다. |
| 재질 | 펠트 섬유·두께·가장자리·접촉 그림자를 실제 크기에 맞춘다. 확대해 굵어진 노이즈·얼룩·과한 보풀을 디테일로 대신하지 않는다. Resin·Glass 등은 각 재질의 빛 반응을 유지한다. |
| 빛과 색 | 광원·그림자 방향·물체 간 접촉을 일관되게 한다. 과한 채도·광택·후보정으로 형태와 재질을 덮지 않는다. 렌더러의 현재 승인 설정과 실물을 대조한다. 금박·검은 배경 자체를 명품화로 간주하지 않는다. |
| 브랜드 | 현재 승인 로고·서체·색·비율·자간·투명 영역을 유지한다. SYNK 네 글자는 무실땀, 사업명은 기존 고유색·실땀을 유지한다. 과거 사례를 참고하며 옛 로고나 폐기 자산은 되살리지 않는다. |
| 글자 | 실제 표시 크기에서 제목·본문·예문·번역의 위계, 대비, 행간과 줄바꿈을 확인한다. 한국어·몽골어의 글리프와 실제 로드 서체를 확인한다. 모든 지면을 동일한 중앙 정렬·여백 비율로 고정하지 않는다. 물체의 이름을 표현할 때는 그림 위에 무관한 글자 버튼을 덧씌우지 않는다. 자수·각인처럼 재질에 통합해 제작하거나, 조작부와 설명을 이미지 바깥에 배치한다(2026-09-19 사용자 피드백). |
| 캐릭터와 장면 | 승인 원본은 생김새 참고로 보존한다. 2026-10-14부터 새 마스코트 그림은 해당 장면과 한 장으로 생성하며 정본 누끼를 장면 위에 얹지 않는다. 원본의 정체성과 캐릭터 비율을 확인하고, 기존 표정 파일 유지보수에서는 몸·털·옷·알파의 일관성을 확인한다. 기존 깊이 시차·표정·몸짓·Loom 장면 기능은 목적에 맞게 활용한다. |
| 동작 | 손발이 닿는 거리, 소품의 수·무게·이동 경로·접촉·행동 전후 상태를 설계한다. 팔 늘어남·물체 융합·위치 도약·떠 보임을 실제 결과에서 고친다. 움직이는 부품마다 의미가 있어야 한다. |
| 영상 | 장면의 행동·초점·카메라·소리와 연결·끝맺음을 함께 편집한다. 빠른 전환을 정보 과밀로 바꾸지 않고 읽어야 할 자막은 여러 컷에 유지할 수 있다. 컷 길이는 현재 요청을 따른다. 고정 8초·고정 카메라·특정 분위기를 강제하지 않는다. |
| UI·접근성 | 첫 행동, 버튼·입력·초점·로딩·빈 화면·오류·완료 상태까지 같은 수준으로 마감한다. 키보드 조작·움직임 감소·대비·대체 설명·자막을 용도에 맞게 제공한다. 장식이 조작과 읽힘을 방해하지 않게 한다. |
| 전체 마감 | 대표 화면뿐 아니라 작은 요소·마지막 장면·모바일·내보낸 파일까지 확인한다. 좋은 기존 결과와 같은 크기로 비교해 읽힘·재질·자연스러움이 후퇴했으면 교정한다. 승인 사례의 배치를 모든 매체에 복제하지 않는다. |

세부 기준의 복구는 별도 승인 단계·자동 훅·새 유료 도구·무제한 재생성을 추가하는 뜻이 아니다. 긴 지시문이나 장식의 양을 품질로 판단하지 않는다.

## 실제 결과

화면·인쇄물은 사용 크기에서 읽힘과 잘림을 확인한다. 영상은 재생으로, 소리는 청취로 확인한다. 기능이 있는 결과물은 요청한 동작을 직접 실행한다. 코드 검사만으로 이 확인을 대신할 수는 없다.

<a id="4-일을-시작하고-마칠-때"></a>
확인한 결과와 남은 문제를 작업 규모에 맞게 알린다. 실제 사용자 반응이나 성과는 측정 자료가 있을 때만 판단한다.
