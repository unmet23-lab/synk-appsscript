# 명품 기준 — SYNK 작업의 판단 기준

> 현행 2026-09-10 정리. 기획·콘텐츠·시각물·제품·교육·고객 응대·납품에 필요한 항목을 상시 적용한다. 사용자에게 매번 명품화를 다시 요청하게 하지 않는다. 이 문서는 브랜드 값·사업 계약을 새로 정하지 않는다.

고객·제공물은 [마케팅 정본](마케팅_정본.md), 색·서체·재질·현재 자산은 [DESIGN](../DESIGN.md)을 따른다. 명품 사례에 관한 근거와 추론은 [조사 원문](명품브랜딩_조사_2026-09-09.md)에 둔다.

## 1. 우리가 지향하는 것

**처음 보고, 직접 쓰고, 다시 찾을 때까지 같은 수준의 품질과 배려를 경험하게 한다.**

| 원칙 | 작업에서 지킬 것 |
|---|---|
| 실체가 약속을 받친다 | 제공물·현재 상태·증거를 연결하고 시안·계획·구현·실제 운영을 구분한다. |
| 고유한 표현을 쌓는다 | 승인 자산과 문법을 이어 쓰며 목적에 맞게 배치를 편집한다. |
| 읽는 순서가 보인다 | 하나의 핵심이 이끌게 하고 필수 설명을 숨기지 않는다. |
| 사람을 존중한다 | 의미와 다음 행동이 분명하게 한다. 우월감·불안·가짜 마감으로 밀지 않는다. |
| 즐거움과 관점이 있다 | 재미·쓸모·감정 중 무엇이 남는지 정한다. 작품마다 판매 요청을 붙이지 않는다. |
| 사용 뒤를 책임진다 | 문의·오류·수정·인수·마무리도 현재 가능한 지원 범위로 완성한다. |
| 증거에 맞춰 판단한다 | 기계 검사·실물 검수·실제 사용자 반응을 나눠 보고한다. |

펠트나 절제만으로 명품성·독점성·인지도를 증명하지 않는다. 화려함과 유머도 목적에 맞게 쓸 수 있다. 자산 일관성과 사람들이 알아보는지는 별개의 검증 대상이다.

## 3. 제출할 때 확인하는 것 — 공통 검사표 정본

해당 항목을 실제 결과로 확인한다. 다른 문서에 이 표를 복제하지 않는다.

| 확인 | 확인할 결과 |
|---|---|
| 목적과 상대 | 누구에게 무엇이 남는지 핵심 메시지와 사용 목적으로 설명되는가. |
| 실체와 정직함 | 약속이 원자료·현재 조건·작동 결과로 뒷받침되는가. 계획과 추론을 구분했는가. |
| 첫 읽힘 | 실제 사용 크기에서 제목·본문·예문·번역이 경쟁하지 않고 핵심이 먼저 보이는가. |
| 배치와 밀도 | 관련 정보의 묶음·정렬·줄바꿈·간격이 이어지는가. 잘림이 없어도 과밀하면 편집했는가. |
| 고유한 표현 | 현재 승인 원본·색·서체·조합이 실제 결과에 적용되었는가. |
| 재미와 참여 | 관찰·선택·청취·따라 하기 등 목적에 맞는 경험이 남는가. |
| 뜻과 다음 행동 | 필요한 설명을 읽고 다음 동작을 할 수 있는가. 감상만으로 충분한 작품에 행동을 강요하지 않는가. |
| 세부와 마무리 | 떠 보임·부자연스러운 테두리·겹침을 실제 사용 상태에서 고쳤는가. 오류·끝 화면·문의·인수까지 화면 렌더·청취·직접 실행으로 확인했는가. |

**기술 검사 통과는 디자인·교육 효과·브랜드 인식의 합격 판정이 아니다.** 미확인 범위를 합격으로 세거나 자동 수치로 사용자의 불편을 반박하지 않는다.

### 3-1. 캐러셀·영상·화면의 편집

- 한 화면의 핵심이 이끌게 한다. 제목·상황·예문·번역·설명을 모두 별도 강조 블록으로 만들지 않는다.
- 광고·릴·숏폼·긴 영상·뮤직비디오·웹 영상 등 시간이 흐르는 온라인 콘텐츠는 **지루함을 방치하지 않는 것**을 원칙으로 하고 한 샷 **1.5~3.0초**를 기본 호흡으로 삼는다. 한 샷에는 정보나 행동 하나를 맡긴다.
- 3초는 기계적인 상한이 아니다. 감정·실제 행동·증명·읽기에 그 시간이 꼭 필요할 때만 넘기며, 샷 안의 표정·행동·초점·카메라·소리가 계속 역할을 해야 한다. 빠른 컷을 정보 과밀로 바꾸지 않고, 자막·설명은 여러 샷에 걸쳐 유지할 수 있다. 내용을 없애서 속도만 맞추거나 편집 편의를 위해 같은 화면을 늘이지 않는다.
- 겹치는 설명은 걷고 부가 설명은 다음 장이나 캡션으로 옮긴다. 이해·선택에 필요한 내용은 남긴다.
- 한국어·몽골어는 독자의 목적에 맞게 짝짓는다. 같은 설명을 두 언어로 과도하게 반복하거나 몽골어 독자의 필수 안내를 한국어로만 두지 않는다.
- 좋은 앞 판과 같은 크기로 비교해 더 읽기 어려워졌으면 되돌린다. 복잡한 자료는 필요한 내용을 없애기보다 단계와 묶음으로 읽게 한다.
- 과밀한 캐러셀의 기각을 모든 지면의 중앙 정렬·고정 여백 비율·글자 축소 규칙으로 확대하지 않는다.

## 4. 일을 시작하고 마칠 때

**시작:** 상대·실제 제공물·비교할 실물을 정하고 현재 자산·약속·작업 범위를 확인한다. 새 주장이나 달라진 외부 조건만 추가 조사한다.

**제작:** 승인된 자산과 기존 제작 통로를 사용한다. AI 초안의 일반적 문구·잘못된 번역·반복 배치를 편집한다. 디자인·콘텐츠의 부자연스러운 배치와 경계는 사용자의 지적을 기다리지 않고 실제 산출물에서 확인해 [DESIGN §6](../DESIGN.md#6-완성도와-확인)에 따라 교정하고, 교정으로 완성할 수 없으면 같은 기준의 확인된 통로와 사용자 허용 범위에 따라 재제작한다. AI 이미지를 실제 수작업 공정으로 제시하지 않는다.

**완료:** 사용 원본과 실제 적용 지점을 연결해 §3을 확인한다. 검증된 교정·재제작 결과는 담당 정본·제작 경로·관련 현재 산출물까지 반영한다. 게시가 범위에 있으면 게시된 결과도 확인한다. 기존 결과 문서에 변경·검수 증거·남은 범위를 남기며, 매번 별도 검사표나 승인 단계를 사용자에게 요구하지 않는다.

작업별로 영상·음악은 재생·청취·끝맺음, 웹·앱은 첫 행동·상태·오류 복구, 수업은 이해·제출·피드백 근거, 상담은 현재 질문과 지원 범위, 납품·인쇄는 실제 크기·인수 후 사용까지 확인한다. 내부 문서는 고객에게 생길 차이와 검증·복구가 분명하면 되며 불필요하게 장식하지 않는다.

### 4-1. 접근성을 제작에 함께 넣는다

키보드·초점·입력 안내·움직임 감소, 이미지의 동등한 설명, 영상·소리의 자막·필요한 음성 해설을 목적에 맞게 적용한다. [사업 발전 정본 §4](사업발전_정본.md#4-접근성을-전사-제작에-적용하는-방법)와 기존 검사기를 사용한다. 자동 검사·실사용·전문 검수의 범위를 구분하며 자동 통과로 접근성 전체를 인증하지 않는다.

## 5. 확인 범위

기준 연결·파일 제작·화면 적용·게시·사용자 반응은 각각 확인한다. 이미 존재하는 앱·계정·음원·현장 전체를 고쳤다고 보고하지 않는다. 범위 밖의 문제는 위치와 다음 행동을 남긴다.

고객 인지도·만족·학습 효과·전환은 실측 전까지 미확인이다. [명품 눈금](명품눈금_v1.md)의 관찰 항목은 개선 대상을 찾는 도구이며 인증이나 사업 성과의 인과 증명이 아니다.
