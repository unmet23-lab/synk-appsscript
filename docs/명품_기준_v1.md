## 5. 아직 확인하지 않은 것

기준을 연결한 것과 모든 기존 실물을 고친 것은 다르다. 이미 존재하는 화면·계정·음원·현장 전체를 일괄 개선했다고 보고하지 않는다. [회사별 실행 순서](명품마케팅_회사별_v1.md)의 해당 작업을 수행할 때 위 기준을 적용하고, 범위 밖에서 발견한 문제는 위치와 다음 행동을 남긴다.

고객 인지도·읽힘·만족·학습 효과·전환의 관계는 실측 전까지 미확인이다. [명품 눈금](명품눈금_v1.md)의 관찰 항목은 개선 대상을 찾는 도구이며, 명품 인증이나 사업 성과의 인과 증명이 아니다.
