## 0-1. 제품 스택 — 앱이 서는 곳 (2026-08-05 유호님 확정)

> 유호님 원문: **핵심 원본 데이터 = Supabase + Postgres** · **운영·리포트·수동 검토 = Google Sheets** · **자동화 = n8n 또는 Apps Script** · **앱 = Expo**.

| 층 | 부품 | 상태 · 요점 |
|---|---|---|
| **원본 데이터 (정본)** | **Supabase (Postgres)** | 🆕 필수 신규. 데이터 정본은 **여기 하나**. L0 데이터 계약 = Postgres DDL(스키마 감사 v9.187 산출물이 씨앗) · 엔진 이름공간 `engine.*` 예약 |
| ├ 인증 | Supabase Auth | **기본후보**(무료 5만 MAU) — Glide가 대신하던 로그인의 빈자리. ⚠유호님 명시 확정은 아직(3택: 자체 토큰/Supabase Auth/구글 계정) |
| └ 서버 함수 | Supabase Edge Functions | **AI 게이트웨이 권장 자리**(코어 엔진 A-2: 모델 호출은 서버측만 · 앱 번들에 API 키 금지) |
| **운영·리포트·수동 검토** | Google Sheets | 가동 중 · **파생 층**(정본 아님). 동기화는 단방향(Supabase→시트) — 시트→원본 되쓰기는 **L0 계약에 규격 있을 때만**(P0 계약 조항) |
| **자동화** | Apps Script · n8n | AS = 가동 중(엔진 23,746줄 자동화층으로 존속 · 실측 천장: 실행 6분·트리거 90분/일·메일 100/일) · **n8n = ⚠새 부품, 호스팅·비용 미확정**(설계 시 건별 확정) |
| **앱** | **Expo (SYNK-talk) + EAS** | repo `Documents\SYNK-talk`(PRIVATE) · CI 초록 · EAS projectId 연결·첫 빌드 트리거·`EXPO_TOKEN` 완비. **푸시 무료·초당 600건** → 알림 86곳 메일→푸시 이전(네이티브 전환의 숨은 배당) |
| **코어 엔진** | 4부품: 지식 그래프 · 학습자 모델 · 오류/교정 말뭉치 · AI 게이트웨이 | **E0(지금) = 계약 조항만** → E1 지식층+RAG(상담AI 로그 쌓인 뒤) → E2 학습자 모델 → E3 봇 팩토리(3~4년차). 정본 = `docs/코어엔진_설계.md` |

**제품 스택 원칙**
1. **데이터는 AI가 아니라 저장소에.** 모델·벤더는 갈아끼우고 데이터는 안 움직인다 — 3년차 봇의 훈련 재료는 지금 Supabase에 쌓이는 행이다.
2. **화면은 백엔드를 모른다** — `계약/` + 어댑터 1층으로 교체 비용 격리. C0 계약은 Codex **소비자 승인** 후 동결.
3. **전환은 단계식, 빅뱅 ✗.** 현행 AS+시트 운영은 새 앱 파일럿 게이트까지 그대로 돌고, Glide는 신규 투자 0의 비상 낙하산(실물 제거는 게이트 뒤 별도 승인).
4. 지식 주입 = **RAG**(파인튜닝 ✗ — 틀린 지식을 못 지운다) · 벡터 RAG ✗(지식 총량이 컨텍스트 상한 안일 동안 — 넘는 시점이 자동 재판정 조건).
5. **엔진이 죽어도 앱은 돈다** — AI 기능마다 강등 경로를 P0 기능표에 명시(단일 장애점 금지).

**층이 5개다** — 도구를 늘릴 때 「어느 층인가」부터 묻는다. 같은 층에 둘을 두면 정본이 갈라진다.

| 층 | 하는 일 | 누구 |
|---|---|---|

| **두뇌** | 기획·판정·정본·배포 + 코딩 L0·L1·L3·L4 | 클로드 ×3 |
| **구현 파트너** | **L2 Expo 화면 주력**(닫힌 명세 발주 — 발주·리뷰·병합은 클로드) | GPT 코덱스 |
| **검사** | 백지 적대 리뷰(설계·코드) + 배포 검수 파이프라인 + 몽골어 검문 | GPT 코덱스 · 제미나이 API · 🔒**제미나이 3.5 Flash Cyber**(코드 보안 리뷰 전용 — 아직 못 켠다 §1-5) |
| **감각·정찰** | 밖에서 재료를 물어온다 · **클로드의 결손을 메운다** | 제미나이·제미나이LM |

**원칙 5 — 전부 여기서 나온다**
1. **만드는 곳은 병렬, 라이브는 한 줄.** 배포·정본(메모리·문서) 쓰기는 클로드 계정1만.
2. **이종(GPT)은 비교가 아니라 검사.** 결과 둘을 놓고 고르는 게 아니라, 기억·테스트·가드를 기준으로 공격시킨다. 구현을 나눠도 **심판은 기계 3겹**(pre-commit·CI·교차 검수)이다.
3. **지휘층(헤르메스)은 읽기 전용** — 프로즈가 아니라 **기계로** 그렇게 만들었다(§1-4).
4. **정찰층이 물어온 것은 재료지 판정이 아니다.** Spark·Deep Research가 물어온 경쟁사 표는 클로드가 기억·수치와 대조한 뒤에야 결정 재료가 된다.
5. **기억이 어디 사느냐가 배치를 정한다.** 기획·판정은 기억(재제안 금지 목록·실측치)이 사는 클로드에, 백지가 무기인 검증은 GPT에, 클로드가 원천적으로 못 하는 것만 제미나이에.

**월 비용**: 유료 = 클로드 맥스 ×2 + Pro ×1 + GPT **Plus($20)** + **Google AI Pro($19.99)**. **제품 스택 신규분은 전부 무료 시작** — Supabase Free·EAS Free·시트·AS 0원(n8n만 ⚠미정 — 셀프=서버비/클라우드=구독, 설계 시 확정). 유료 전환은 사용량이 실측으로 요구할 때만.

## 0-3. 코딩 레인 분할 (2026-08-05 유호님 채택 "나눠서 하자")

기획 = 유호님 1인 · 설계 = 정본 1곳·펜은 클로드·Codex 적대 검수·확정은 유호님 · 코딩 = 레인 분할. 실행 정본 = SYNK-talk `docs/개발_분업.md` **v3.2**(엔진 역할분배 v3 — 의미 펜=클로드·물리 펜=GPT·거부권 대칭 · §8-1-a). ⚠아래 레인 표의 「L2=Codex 주력」은 **F133 해소 후의 정상 상태**다 — 해소 전 화면 구현은 「클로드 구현→코덱스 검수」 순서(유호님 확정 08-06 · §1-2 ③).

| 레인 | 내용 | 담당 |
|---|---|---|
| L0 | 데이터 계약(Postgres DDL·수집_교정_계약) | 클로드 |
| L1 | 백엔드(Supabase·AS 연동) | 클로드 |
| **L2** | **Expo 화면** | **Codex 주력** — 공통 앱 기반(F0: 내비·상태·API층·토큰)은 Codex 단일 소유 선행, 토큰 값은 브랜드 킷 정본 구속 |
| L3 | 교정 프롬프트·콘텐츠 | 클로드 정본 + 제미나이 몽골어 검문(기존 배선) |
| L4 | 통합·배포·CI | 클로드 |

- 완성 단위 = 층이 아니라 **기능별 수직 슬라이스**(P0 제품계약 → F0 기반 1회 → C0 계약 동결 → S1~Sn 관통·즉시 통합). S1 = 실측 게이트 겸임.
- 검수는 전수가 아니라 **위험도 기반**(계약·인증·전역상태·배포설정만 전수 교차) · 발주서는 구현 전 Codex 검수(작성자·검수자 분리).
- **첫 사이클 = 실측 게이트**: 리뷰 반려 횟수·재작업 왕복·완성 시간·한도 잔량 → 레인 재배치. 같은 기능 2회 제작 ✗.
- ⛔ **라이브 repo(SYNK-appsscript)에 Codex 불입 금지 유지**(훅 무효 + 라이브 시트 접근). Codex의 일터는 SYNK-talk뿐(AGENTS.md·pre-commit 완비).
- ⚠ 「효율 2배」는 기대치 — 병렬 이득은 화면 구간 한정, 상류(계약·설계)는 직렬 + 이종 왕복 +5~8분/사이클 실측 · GPT 한도 정책 변동성 주의.

## 2. 역할 — 왜 이렇게 나눴는가

축은 **능력 비교가 아니라 "기억이 어디 사느냐"**다. 이 시스템의 기획·판정 품질은 모델 지능이 아니라 축적된 기억(재제안 금지 목록·실측치·판정 이력)에서 나오고, 그 기억은 전부 클로드 쪽에 산다.

| 일의 성질 | 가는 곳 | 이유 |
|---|---|---|
| 기억이 필요한 일 (기획·판정·정본·배포·데이터 계약) | 클로드 계정1 | 기억이 여기 산다 |
| 손이 많이 가는 병렬 생산 | 클로드 계정2 | 같은 기억·같은 하네스 |
| **코드**가 맞는지 배포 전에 재기 (**①배포 검수** · §1-2) | GPT 코덱스 | 기억이 **없어야** 잘하는 일 — 백지는 심문자의 무기 |

**기본값: 무엇이든 일단 클로드.** 예외만 외우면 된다:
