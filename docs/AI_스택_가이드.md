**NotebookLM에 판정 이력을 넣을 때 조건 3 (이게 없으면 오히려 사고다)**
- ⛔ **읽기 전용 — 거기서 결정하지 않는다.** 답은 재료지 판정이 아니다(Manus 조건과 같은 축).
- ⛔ **사본에 만든 날짜를 박는다.** 안 박으면 정본이 두 곳으로 갈라진다 — 유호님이 가장 크게 데인 사고 유형(브랜드 색 hex 원천 혼동 계열). 사본을 손으로 관리하지 않는다: **생성기**로 뽑는다.
- ⛔ 넣는 것 = `memory`(판정 이력) + `docs`뿐.

✅ **생성기 = `node tools/notebooklm-export.js`** (08-04 신설 · 회귀 `tests/노트북LM묶음.test.js` 21건). 조건 3을 프로즈가 아니라 **기계로** 지킨다 — 바탕화면 `SYNK_노트북LM`에 **196개 자료 + 올리는 방법**이 생성되고, 모든 파일 머리에 만든 날짜·원본 경로·「여기서 결정하지 않는다」가 박힌다. 돌릴 때마다 폴더가 통째로 새로 만들어진다(사본이 스스로 낡음을 말한다).

⛔ **이 묶음은 외부(구글 계정)로 나간다 — 다른 생성기와 위험의 층이 다르다.** 그래서 이름이 아니라 **본문까지** 검사한다: 전화번호·주민번호·카드·제3자 이메일·API 키·봇 토큰이 한 줄이라도 있으면 **그 파일을 통째로 뺀다**(빠진 목록은 묶음 안 `_빠진_파일.md`에 남는다 — 「자료가 없어서 못 답한 것」과 「일부러 뺀 것」을 구분하려고). `_archive`·`_구본`·`SYNK 보안`은 아예 수집하지 않는다(낡은 판이 출처로 찍히는 것이 이 묶음의 최대 위험).
- 📌 **08-04 실측 = 1건 제외**: `docs/GLIDE_조립가이드_v947.md`(제3자 계정 이메일 3개). 안전한 값으로 판명되면 생성기의 `ALLOW`에 **값 단위로** 추가한다 — 파일 단위 예외를 만들면 그 파일에 나중에 들어올 진짜 개인정보까지 함께 통과한다.

- ❌ 셋 다(제미나이·NotebookLM·Veo) **학생 개인정보·학생 데이터 업로드 금지**(동의 범위 밖).
- ⚠ **미확인 1건**: 개인 계정에서 시트 `Ask Gemini`가 실제로 뜨는지 **육안 확인 대기**(공식 문서상 Google AI 플랜이면 열린다 · Gmail 쪽은 미국에서 빠졌다는 보도가 있으나 시트는 해당 없음).

### 1-6 Manus — 정찰(경쟁사 조사) 전용 · 유호님 결정(08-03)

- **역할 = 몽골 현지 경쟁 학원의 페이스북·인스타그램 공개 활동 조사.** 몽골 소셜은 Meta가 지배하고 유호님 상담의 90%+가 거기서 오므로, **경쟁사가 무엇을 어떻게 올리는지가 곧 시장 정보**다.
- 📌 사실 정정 하나: **Manus는 Meta 소속이 아니다.** Meta가 2025-12 인수했다가 **2026-04 규제로 인수가 원상복구**됐다(개발사 = 중국 창업·싱가포르 본사 Butterfly Effect). 조사 **대상**이 Meta 플랫폼인 것이지 도구가 Meta 것은 아니다 — 이 도구를 쓰는 근거는 「Meta 계열이라서」가 아니라 아래 3가지다.

**Manus가 이 일에 잘 맞는 이유 (내 판단)**
1. **자율 다단계 브라우징** — 페이지를 열고 스크롤하고 모으고 표로 정리하는 것을 **혼자 끝까지** 한다. 클로드의 브라우저는 내가 한 걸음씩 몰아야 해서 같은 일에 유호님·내 시간이 든다.
2. **유호님 PC를 안 쓴다** — 자기 클라우드 샌드박스에서 돈다. 헤르메스·오르카와 달리 **PC가 꺼져 있어도** 돌고, 오래 걸리는 조사가 데스크톱을 붙잡지 않는다.
3. **산출물이 파일로 나온다** — 경쟁사 비교표·리포트 형태라 그대로 결정 재료가 된다. 채팅 답변을 다시 정리할 필요가 없다.
4. **반복 가능** — 「월 1회 경쟁사 스윕」처럼 같은 조사를 주기로 돌릴 수 있다. 시계열이 쌓이면 **가격·이벤트·개강 주기의 패턴**이 보인다(1회성 조사로는 안 보이는 것).

**규칙 4가지 (이건 지켜야 한다)**
- ⛔ **유호님 페이스북·인스타 계정으로 로그인시키지 않는다.** 자격증명이 제3자 인프라로 가고, 자동화 접속은 계정 정지 사유다. **로그아웃 상태에서 보이는 공개 페이지만** 조사한다.
- ⛔ **학생 데이터·상담 내용을 넣지 않는다**(동의 범위 밖 + 제3자 관할권). 경쟁사 공개 정보만 다루면 08-02에 Manus를 기각했던 관할권 우려는 **이 용도에선 성립하지 않는다** — 그래서 이 역할은 그때 기각과 충돌하지 않는다(기각은 「상담 자동화 대체」 역할에 대한 것이었고, 그 자리는 이미 `상담AI.js`가 있다).
- ⚠ **크레딧제라 비용이 예측되지 않는다** — 복잡한 과제 1회에 500~900 크레딧. **조사 범위를 먼저 좁혀서** 시키고(예: 「경쟁사 5곳 · 최근 30일 게시물만」), 무제한 탐색을 시키지 않는다.
- 🔑 **결과는 재료지 판정이 아니다.** 표를 받으면 클로드에게 넘겨 우리 수치(BEP·정원·가격 정본)와 대조한다 — 경쟁사 가격표 하나로 우리 가격을 움직이지 않는다.

**첫 과제 추천**: 「울란바토르 한국어 학원 5곳의 FB 페이지 — 최근 30일 게시 빈도·콘텐츠 유형·광고 여부·댓글 반응」 한 표. 이걸로 도구의 실제 품질을 재고 나서 범위를 넓힌다.

## 2. 역할 — 왜 이렇게 나눴는가

축은 **능력 비교가 아니라 "기억이 어디 사느냐"**다. 이 시스템의 기획·판정 품질은 모델 지능이 아니라 축적된 기억(재제안 금지 목록·실측치·판정 이력 109건)에서 나오고, 그 기억은 전부 클로드 쪽에 산다. 그래서 —

| 일의 성질 | 가는 곳 | 이유 |
|---|---|---|
| 기억이 필요한 일 (기획·판정·정본·배포) | 클로드 계정1 | 기억이 여기 산다 |
| 손이 많이 가는 병렬 생산 | 클로드 계정2 | 같은 기억·같은 하네스 |
| 기억이 **없어야** 잘하는 일 (백지 검증) | GPT | 백지는 심문자의 무기 |
| 기억을 유호님 눈에 보이게 | 옵시디언 | 이미 옵시디언 문법(109개 노트) |
| 클로드가 **못 하는 것** (라이브 시트·오디오·영상 생성·한도) | 제미나이·NotebookLM | 능력 경쟁이 아니라 **결손 보전**(§1-5) |
| 유호님 폰과 시스템 사이의 문 | 헤르메스 | 상시로 떠 있는 유일한 층 |
| (추후) 병렬 레인의 교통정리 | 오르카 | 이종 병렬이 생기는 순간부터 |

**금지선 — 이것만 안 넘으면 시스템은 안 깨진다**
- ❌ GPT에 기획 **초안**을 맡기기 (기억이 없어 기각안을 재생산 → 큐만 증가)
- ❌ GPT에 상시 지침·커스텀 인스트럭션 심기 (사본은 스스로 낡는다)
- ❌ GPT 검증을 이어지던 대화에서 하기 → **매번 새 대화** (기억이 남으면 백지 검증이 깨진다)
- ❌ 헤르메스에게 코드·파일 수정 시키기 (가드 0인 층)
- ❌ 제미나이·NotebookLM에 학생 데이터 넣기
- ❌ **NotebookLM 답을 그대로 결정 근거로 쓰기** (사본은 낡는다 — 재료지 판정이 아니다)
- ❌ 옵시디언에서 memory 폴더 이동·개명·대량 편집
- ❌ 오르카를 창고 착수 전에 만지기

## 3. 사용법 — 유호님의 라우팅 규칙

**기본값: 무엇이든 일단 클로드.** 예외만 외우면 된다:

| 이런 순간 | 여는 곳 |
|---|---|
| **라이브 시트에 뭐가 들었는지 궁금하다** | **시트 안 `Ask Gemini`** — 클로드는 이걸 못 본다 |
| **클로드 한도가 찼는데 더 하고 싶다** | **NotebookLM**(조회) · 또는 계정을 바꾼다 |
| 유튜브·영상·이미지를 판독하고 싶다 | 제미나이 |
| 짧은 영상 소재가 필요하다 | 제미나이 **Veo** |
| 자료를 통독·듣고 싶다 (교재·정본) | NotebookLM |
| 경쟁사가 뭘 하는지 알고 싶다 | Manus (범위를 좁혀서 · §1-6) |
| 넓고 빠른 웹 조사 | 제미나이 Deep Research ／ **정확도가 걸리면 GPT** |
| "예전에 뭐라고 정했더라?" | 옵시디언 `Ctrl+Shift+F` (또는 클로드에게 질문) |
| 폰으로 결정 처리 | **`@synk_queue_bot`** (매일 9시 · 그 방에 답하면 끝) |

### GPT 검증 흐름 — 붙여넣기 2회

1. 굵직한 확정 전, 클로드에게: **"이거 GPT 검증 받자"** → 붙여넣기용 브리핑 1장이 나온다 (배경·제약·공격 포인트 포함)
2. ChatGPT **새 대화**에 붙여넣기 ①
3. GPT의 공격을 복사해 클로드에게 붙여넣기 ② → 반영/기각을 갈라 최종안

적용 급 = **되돌리기 어려운 결정·외부 공개물**. 일상 작업까지 돌리면 검증이 아니라 큐가 된다.

### 도전안 — 반응형 대신 리듬형 (선택)

도구를 "생각나면 여는 것"에서 "요일에 붙은 것"으로: 월요일 제미나이 트렌드 30분 · 굵직한 확정 전 GPT · 일요일 옵시디언 그래프 10분. 채택은 유호님 자유 — 자동화 선호에 맞는 쪽이라 기록해 둔다.
