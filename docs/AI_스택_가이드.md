## 0. 한눈 지도

```
                유호님 (결정만 한다)
                   │ 폰·텔레그램
                   ▼
             [헤르메스]  지휘 · 읽기 전용            [옵시디언]
                   │                                 판정 이력을
                   ▼                                 눈으로 (그래프)
      ┌──── [클로드 계정1 · 데스크톱] ────┐               │
      │  허브: 기획·판정·정본·리뷰·배포    │───────────────┘
      ▼                 ▼               ▼
[클로드 계정2]     [GPT 코덱스]     [제미나이+NotebookLM]
 웹·폰 병렬 생산    검증·적대 리뷰     영상·이미지·듣기 (무료)

      (창고 착수 후: [오르카]가 클로드+코덱스 병렬 레인 관리)
```

**원칙 3 — 전부 여기서 나온다**
1. **만드는 곳은 병렬, 라이브는 한 줄.** 배포·정본(메모리·문서) 쓰기는 클로드 계정1만.
2. **이종(GPT)은 비교가 아니라 검사.** 결과 둘을 놓고 고르는 게 아니라, 기억·테스트·가드를 기준으로 공격시킨다.
3. **지휘층(헤르메스)은 읽기 전용.** 폰에서는 결정만 하고, 실행은 클로드가 한다.

**월 비용**: 유료 = 클로드 맥스 ×2 + GPT Pro($100)뿐. 옵시디언·헤르메스·제미나이·NotebookLM·오르카 = **0원**.

### 1-1 클로드 코드 맥스 ×2 — 계정을 기기로 가른다

- **계정1 = 이 데스크톱.** 허브. 라이브 repo·배포·정본을 만지는 유일한 곳.
- **계정2 = 두 번째 창구.** claude.ai(웹·폰)에 로그인해 둔다.
- 계정2를 쓰는 순간은 둘뿐: ①계정1이 주간 한도에 막혔을 때 이어받기 ②오래 걸리는 병렬 일감(대량 콘텐츠·조사)을 던져둘 때.
- 계정2에서 repo가 보이는지는 **첫 사용 때 확인**한다 — 안 보이면 그 자리에서 "계정2 연결해줘" 한마디(연결 절차는 그때 안내).
- ⏳ **게이트(결정 대기)**: 다음 결제일 전에 하나만 자문 — "계정 1개만으로 한도에 막힌 적 있나?" 없으면 계정2는 해지 후보.

### 1-2 GPT Pro 코덱스 — "안 하는 것"이 세팅이다

- 실측: Codex CLI 설치·ChatGPT 구독 로그인 완료. 추가 설치 0.
- 유호님이 확인하실 것 **1가지**: ChatGPT 화면 → 설정 → 구독이 **Pro**인지. (창고 착수 전까지 용도가 리뷰뿐이면 Plus $20로 충분하다는 게이트가 기록돼 있다 — 티어는 유호님 선택.)
- ❌ **커스텀 인스트럭션·프로젝트에 SYNK 지침을 심지 않는다.** GPT는 일부러 백지로 둔다. 매 검증마다 클로드가 **브리핑 1장**을 만들어 주기 때문이다 — 심어둔 사본은 낡지만, 일회용 발주서는 낡을 수 없다.

### 1-3 옵시디언 — 완료. 쓰는 법만

- 볼트 = 클로드 memory 폴더(판정 노트 109개, 전부 서로 링크됨). 08-03 연결 완료.

### 1-4 헤르메스 — 선행 1건 + 유호님 5분 + 나머지는 클로드

- ⛔ **선행 1건(이것이 열쇠)**: 자격증명 폴더(`docs/정본/SYNK/SYNK 보안/`)를 repo 밖으로 이동. 상시 서비스에게 이 저장소 근처를 보여주기 전에 반드시. 제안 위치 = `C:\Users\q1212\SYNK_보안\`. **"자격증명 이동 진행해"** 한마디면 클로드가 이동+참조 깨짐 검사까지 수행.

### 1-5 제미나이 + NotebookLM — 열면 끝

- 세팅 없음. `gemini.google.com` / `notebooklm.google.com`에 구글 로그인.
- 제미나이 용도(무료): ①**유튜브 링크 영상 분석**(클로드는 영상을 원천적으로 못 본다) ②이미지·스크린샷 2차 판독 ③(추후) 음성 수집 착수 때 API 종량 — 그때 클로드가 세팅.
- NotebookLM: **유호님 개인 학습 전용** — 교재 원고·정본 문서를 넣고 오디오 오버뷰로 듣기. 시스템 연결 없음(API가 없어서 원천 불가).
- ❌ 둘 다 **학생 개인정보·학생 데이터 업로드 금지**(동의 범위 밖).

### 1-6 오르카 — 봉인. 트리거 = 창고 착수

## 2. 역할 — 왜 이렇게 나눴는가

축은 **능력 비교가 아니라 "기억이 어디 사느냐"**다. 이 시스템의 기획·판정 품질은 모델 지능이 아니라 축적된 기억(재제안 금지 목록·실측치·판정 이력 109건)에서 나오고, 그 기억은 전부 클로드 쪽에 산다. 그래서 —

| 일의 성질 | 가는 곳 | 이유 |
|---|---|---|
| 기억이 필요한 일 (기획·판정·정본·배포) | 클로드 계정1 | 기억이 여기 산다 |
| 손이 많이 가는 병렬 생산 | 클로드 계정2 | 같은 기억·같은 하네스 |
| 기억이 **없어야** 잘하는 일 (백지 검증) | GPT | 백지는 심문자의 무기 |
| 기억을 유호님 눈에 보이게 | 옵시디언 | 이미 옵시디언 문법(109개 노트) |
| 기억이 필요 없는 감각 (영상·이미지·듣기) | 제미나이·NotebookLM | 클로드가 원천적으로 못 하는 것 |
| 유호님 폰과 시스템 사이의 문 | 헤르메스 | 상시로 떠 있는 유일한 층 |
| (추후) 병렬 레인의 교통정리 | 오르카 | 이종 병렬이 생기는 순간부터 |

**금지선 — 이것만 안 넘으면 시스템은 안 깨진다**
- ❌ GPT에 기획 **초안**을 맡기기 (기억이 없어 기각안을 재생산 → 큐만 증가)
- ❌ GPT에 상시 지침·커스텀 인스트럭션 심기 (사본은 스스로 낡는다)
- ❌ GPT 검증을 이어지던 대화에서 하기 → **매번 새 대화** (기억이 남으면 백지 검증이 깨진다)
- ❌ 헤르메스에게 코드·파일 수정 시키기 (가드 0인 층)
- ❌ 제미나이·NotebookLM에 학생 데이터 넣기
- ❌ 옵시디언에서 memory 폴더 이동·개명·대량 편집
- ❌ 오르카를 창고 착수 전에 만지기

## 3. 사용법 — 유호님의 라우팅 규칙

**기본값: 무엇이든 일단 클로드(계정1).** 예외는 4개만 외우면 된다:

| 이런 순간 | 여는 곳 |
|---|---|
| 유튜브·영상·이미지를 판독하고 싶다 | 제미나이 |
| 자료를 통독·듣고 싶다 (교재·정본) | NotebookLM |
| "예전에 뭐라고 정했더라?" | 옵시디언 `Ctrl+Shift+F` (또는 클로드에게 질문) |
| 폰으로 결정 처리 | 헤르메스 (세팅 후) |

### GPT 검증 흐름 — 붙여넣기 2회

1. 굵직한 확정 전, 클로드에게: **"이거 GPT 검증 받자"** → 붙여넣기용 브리핑 1장이 나온다 (배경·제약·공격 포인트 포함)
2. ChatGPT **새 대화**에 붙여넣기 ①
3. GPT의 공격을 복사해 클로드에게 붙여넣기 ② → 반영/기각을 갈라 최종안

적용 급 = **되돌리기 어려운 결정·외부 공개물**. 일상 작업까지 돌리면 검증이 아니라 큐가 된다.

### 도전안 — 반응형 대신 리듬형 (선택)

도구를 "생각나면 여는 것"에서 "요일에 붙은 것"으로: 월요일 제미나이 트렌드 30분 · 굵직한 확정 전 GPT · 일요일 옵시디언 그래프 10분. 채택은 유호님 자유 — 자동화 선호에 맞는 쪽이라 기록해 둔다.

## 4. 말 한마디 명령표 — 다음 단계는 전부 이 문장들로 굴러간다

| 하고 싶은 것 | 클로드에게 하실 말 |
|---|---|
| 자격증명 폴더 이동 (헤르메스 선행) | "자격증명 이동 진행해" |
| 헤르메스 텔레그램 연결 | (봇 토큰+숫자 ID 주시며) "헤르메스 이어서 세팅해줘" |
| GPT 검증 | "이거 GPT 검증 받자" |
| 계정2 첫 연결 확인 | "계정2 연결해줘" |
| 창고 착수 (오르카 포함) | "창고 착수하자" |
| 음성 수집 시작 (제미나이 API) | "음성 수집 착수" |

**권장 순서**: 자격증명 이동 → 헤르메스 → (창고 착수) → 오르카 → (음성 착수) → 제미나이 API. 옵시디언·제미나이·NotebookLM은 이미 오늘부터 쓸 수 있다.
