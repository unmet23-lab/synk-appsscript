## STEP 2. 선택 클릭 (각 1~5분, 안 해도 무방)

1. **운세 카드 라벨**: 학생 홈 운세 컴포넌트의 제목 텍스트를 "오늘의 한 문장"으로 변경(내용은 이미 자동 대체됨).
2. **최애 입력(A4 재료)**: 학생 프로필 화면에 Text Entry 컴포넌트 → Set Column → profiles **최애(DA)**. (드림한줄과 같은 방식)
3. **F1 레벨 테스트 개통**: 에디터에서 `createLevelTestForm` ▶ 1회 → 로그의 URL을 FB 페이지·상담에 배포. 응답은 밤마다 자동 채점→몽골어 진단 리포트 발송→leads 편입.

## STEP 3. 사람 몫 메모 (원어민·검수)

- **몽골어 검수 1회**: `HL_TPL`(하이라이트 템플릿 5문장, Code.js에서 검색)과 레벨 테스트 리포트 샘플 1통 — 에리카 선생님 등 원어민 확인 권장.
- **레벨 테스트 15문항**: `LEVEL_TEST_Q`(Code.js) — 커리큘럼 기준으로 작성했으나 유호님 눈으로 1회 검수 권장.
- **A1/A2 초기 검수**: 첫 1~2주는 `ai_daily` 시트에서 퀴즈 품질 표본 확인(첨삭의 hw_feedback 검수와 같은 요령).
