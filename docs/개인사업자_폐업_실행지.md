## 1-A. 「어디에 뭐로 등록됐는지 모른다」 — 조회가 폐업의 앞 단계다 (유호 질의 08-12)

폐업신고서에는 **등록번호와 관할 관청**이 필수 칸이라, 모르는 채로는 신고서를 못 쓴다.
⚠ **모르는 것 자체는 이상한 게 아니다** — 쇼핑몰 창업 때 대행업체가 일괄 처리한 경우가 흔하다.

| 대상 | 확인 통로 | 로그인 |
|---|---|---|
| **화장품책임판매업** | **[의약품안전나라 업체정보](https://nedrug.mfds.go.kr/pbp/CCBBA01)** → 「구분」=**화장품책임판매** → 「업체명」에 상호 → 검색 · **공개 DB** ✅2026-08-12 실측 | **불요** |
| **건강기능식품판매업** | 관할 **시·군·구청 보건위생과** 또는 **보건소** 전화 — 사업자등록번호·성함으로 확인. (일반판매업은 소매라 공개 DB에 잘 안 잡힌다.) 관할 = **사업자등록증의 사업장 주소** 기준 | — |
| **둘 다 / 가장 빠름** | 서류철의 **등록증·신고증 실물** — 번호와 발급 관청이 적혀 있다. 통신판매업 신고증과 함께 보관됐을 가능성이 높다 | — |

> 🔑 화장품 조회 결과에 **사업장 주소**가 나오면 그 주소로 건기식 관할 구청이 특정된다 — 한 번 조회가 둘을 푼다.

**질문에 대한 답: 둘 다 폐업신고하면 그 위에 더 건드릴 것은 없다.** 단 **「접수」와 「수리」는 다르다** — 수리 결과 서류가 §2-3의 홈택스 첨부 증거이므로 각 단계마다 결과 PDF를 저장한다.

## 1-B. 화장품책임판매업 유지 비용 (유호 질의 08-12 · 조회 결과 **등록 살아 있음** 확인)

| 항목 | 금액 | 언제 |
|---|---|---|
| **등록면허세** | **18,000~67,500원**(지자체 인구 규모별 차등) | **매년 1월 자동 부과**(지방세법 §38) |
| **책임판매관리자 보수교육** | **80,000원**(한국의약품수출입협회 온라인 6시간 · 2026-08-12 실측) | 최초 교육일 기준 **매년 1회** |
| 생산·수입실적 보고 | 0원 | 매년 **2월 말**까지 (의무) |
| 교육 미이수 과태료 | **500,000원** | 미이수 시 |

→ **가만히 둬도 연 10만원 안팎 + 매년 6시간. 안 챙기면 50만원.**

- 🔴 **등록면허세는 «자동 부과»다** — 신청이 아니라 매년 1/1 기준으로 나온다. 고지가 재개발 예정지로 가는 중이라 **체납이 쌓였을 수 있다**. → [위택스](https://www.wetax.go.kr)에서 원격 조회.
- 🔴 **소재지가 등록사항이다** — 사업장 주소 변경 시 변경등록 의무인데 그 건물은 철거 예정. 폐업이 이걸 닫는다.

### ⭐ 시점 — **2026년 안에** 끝내면 둘이 동시에 닫힌다
① 등록면허세는 **1/1 기준 갱신** → 올해 안 폐업이면 **2027년 1월분이 안 붙는다**
② **폐업한 해는 그 해 교육이 면제** → 2026년 교육 8만원도 안 낸다
→ **지금 하면 최소 10만원 + 6시간을 바로 아낀다. 미루면 정확히 그만큼씩 붙는다.**

### 유지 검토 → 기각
나중에 **한국 화장품을 몽골에서 판매**할 계획이 있어도 유지 근거가 안 된다: ①화장품책임판매업은 **한국 내 유통**을 위한 등록이라 몽골 판매엔 몽골 쪽 자격이 필요하다 ②그때가 오면 **개인이 아니라 ㈜싱크시프트 법인 명의**로 등록하는 게 맞다 ③등록은 며칠짜리라 미리 들고 있을 이유가 없다. 🚫「나중에 쓸지 모르니 유지」 재제안.

## 2. ⚠ 되돌릴 수 없는 것 셋 — 순서가 여기서 나온다

1. **재고를 못 판다** — 폐업일 이후 세금계산서·현금영수증 발행 불가. 게다가 **화장품·건기식은 인허가가 죽으면 판매 자체가 위법**이 된다(재고 처분 통로가 이중으로 닫힌다).
2. **잔존재화 부가세** — 폐업일에 남은 재화·감가상각 자산의 시가에 10% 과세. 안 팔았는데 판 것으로 본다.
3. **국세청이 인허가 폐업 «증거»를 요구한다** — 국세청 공식 안내: 인허가 사업자가 폐업신고를 할 때는 *「관할관청에 폐업신고를 한 사실을 확인할 수 있는 서류」* 첨부가 필요하다.
   → 홈택스를 먼저 누르면 이 서류가 아직 없다. **인허가 셋이 먼저다.**

## 3. ✅ 통합폐업신고는 쓰지 않는다 (검토 후 기각)

「시군구 또는 세무서 중 한 곳에 통합폐업신고서를 내면 한 번에」라는 제도가 실제로 있다(138개 업종). 그런데 **유호님 케이스에선 쓰지 않는 게 낫다**:

- 통합폐업신고는 **방문 접수만** 된다(시청·구청·보건소 민원실). 온라인 창구가 없다.
- **화장품책임판매업은 지방식약청(국가기관) 소관**이라 시군구 통합 대상에 안 들어간다 → 어차피 따로 해야 한다.
- 즉 **「방문 1회 + 식약청 1회」 vs 「온라인 4회」** — 유호님은 원격이 기본이고 곧 출국하시므로 온라인이 이긴다.

> 🚫 이 판단을 뒤집을 조건: 정부24 온라인 신고가 반려되어 방문을 요구받는 경우.

## 4. 단계별 실행

### 0단계 — 전자송달 신청 ⭐ 이번 건의 진짜 급소

**왜 먼저인가**: 폐업해도 **고지서는 2027년 5월 종소세까지 계속 온다.** 폐업하면 사업장 주소가 없어져 고지서는 **주민등록 주소**로 가는데 유호님은 2027-02에 몽골로 나가신다 → **못 받는다 → 모르는 채 체납.** 지금 사업장 주소(재개발 예정지)도 이미 같은 문제라 메모리에 🔴🔴로 잡혀 있다.

1. 홈택스 로그인
2. **My홈택스** → **전자고지·송달** (또는 검색창 「전자송달」)
3. **전자송달 신청** — **이메일 + 휴대전화** 둘 다 등록
4. ⚠ **사업자 기준 말고 「개인(주민등록번호)」 기준으로도 신청** — 사업자 기준만 하면 폐업과 함께 끝나서 정작 종소세 고지를 못 받는다

> 답이 무엇이든 손해가 없는 유일한 단계. **오늘 해도 된다.**

### 1단계 — 재고·자산 확인 (유호님 답 = 「모르겠다」)

**확인법 (전부 홈택스에서 원격)**
1. 홈택스 → **세금신고** → **부가가치세 신고** → **신고서 조회** → 가장 최근 확정신고서를 연다
2. 매입 내역에서 **재고 매입**과 **고정자산 매입(노트북·집기)** 을 본다
3. 같이 볼 것: **전자세금계산서 조회** → 최근 매입분 · **사업용 신용카드 매입** 내역

**판정 기준**
- 화장품·건기식은 **유통기한**이 있다. 사업을 접은 지 오래면 이미 폐기 대상 → 시가 0에 가까워 간주공급 부담이 작다.
- 고정자산(노트북 등)은 취득 후 경과에 따라 간주시가가 체감한다. 오래됐으면 부담이 작다.
- **재고가 실제로 팔 만한 상태로 남아 있을 때만** 폐업일을 미룬다.

---

### 2단계 — 통신판매업 폐업신고 (정부24)

1. **www.gov.kr** → 로그인(간편인증)
2. 검색창 **「통신판매업 폐업」** → **통신판매업 휴업·폐업·영업재개 신고** → **신고하기**
3. 입력: **통신판매업 신고번호**(신고증 좌측 상단, `제20XX-지역명-XXXXX호`) · 상호 · 사업자등록번호 · **폐업일**
4. 제출 → **3영업일**(접수일 제외)
5. ⭐ 처리 완료 후 **결과 통지를 PDF로 저장** — 5단계에서 국세청에 낼 증거다

> 법정 기한은 **폐업 5일 전**. 대부분의 가이드가 안내하는 「홈택스 먼저」 순서를 따르면 이 기한을 이미 어긴 상태가 된다.

---

### 3단계 — 건강기능식품판매업 폐업신고 (정부24)

1. **www.gov.kr** → 검색창 **「건강기능식품판매업 폐업신고」**
2. 서식: **건강기능식품영업 폐업신고서** [별지 제14호서식]
3. 첨부: **영업신고증**
   - 🔑 **분실했으면 분실사유만 적으면 된다** — 신고증 없이도 진행된다
4. 수수료 **0원** · 처리 **즉시(근무시간 내 3시간)**
5. 처리 결과 PDF 저장

---

### 4단계 — 화장품책임판매업 폐업신고 (의약품안전나라)

1. **nedrug.mfds.go.kr** 접속 → 로그인
2. **전자민원 신청** → 화장품 → **(폐업·휴업·재개) 신고**
3. 서식: **[별지 제11호서식] 화장품 제조업·화장품책임판매업·맞춤형화장품판매업 (폐업·휴업·재개) 신고서**
   - 관할 지방식약청 공지에서 hwp 서식을 내려받아 작성 후 첨부
4. 진행 확인: **나의민원 → 민원신청내역**에서 접수번호로 조회, **처리공문 출력**
5. 처리공문 PDF 저장

> ⚠ 유통 중인 화장품이 남아 있으면 회수·처리 의무가 걸린다 → 1단계 재고 확인이 여기서도 값을 한다.
> 문의: 관할 지방식약청 (경인청 운영지원과 02-2110-8100)

---

### 5단계 — 홈택스 폐업신고 ★ 본체

**메뉴 경로 (2026-08-12 홈택스 라이브 실측)**

```
hometax.go.kr 로그인
 → 상단 [전체메뉴]
 → [증명·등록·신청·사업장현황]        ← ⚠ 블로그들이 쓰는 「국세증명·사업자등록·세금관련 신청/신고」가 아님
 → [사업자등록 신청·정정·휴폐업]
 → [휴·폐업·재개업 신고]
 → [휴업·폐업 신고]                    (내부 메뉴코드 4306060100)
```

**입력**
| 칸 | 값 |
|---|---|
| 사업자등록번호 | 목록에서 선택 → 인적사항 자동 조회 |
| **폐업일자** | §6 참조 |
| **폐업사유** | 「사업부진」 등 해당 항목 선택 |
| **첨부** | 2~4단계의 **인허가 폐업 확인 서류** (국세청 요구사항) |
| 사업자등록증 | 온라인 신고는 **반납 불요**(전자 제출) |

- **사업자 2개를 각각** 해야 한다 — 한 번에 안 묶인다.
- 제출하면 **사업자등록 말소는 자동** — 별도 말소 신청 없음.

> 💡 대안 통로: **부가가치세 확정신고서에 폐업연월일·폐업사유를 적고 사업자등록증을 첨부**하면 별도 폐업신고서 제출이 **불요**하다(국세청 공식). 5·6단계를 한 번에 끝내는 길 — 다만 부가세 신고 기한까지 기다려야 하므로, 인허가가 이미 죽은 상태를 오래 끌지 않으려면 §3 순서대로 따로 하는 편이 낫다.

### 6단계 — 부가가치세 확정신고 ⚠ 폐업신고와 «별개 의무»

**가장 많이 놓치는 자리다.** 폐업신고를 했다고 세금 신고가 끝난 게 아니다.

- **기한 = 폐업일이 속한 달의 다음 달 25일**
- 8월 중 폐업 → **2026-09-25까지**
- 대상 기간 = **2026-07-01 ~ 폐업일** (제2기 과세기간 시작일부터)
- 매출이 0이어도 **「무실적 신고」**를 해야 한다
- 안 하면: 무신고가산세 + 납부지연가산세

경로: 홈택스 → **세금신고** → **부가가치세 신고** → **폐업확정신고**

## 4-A. 자격증·교육 수료증은 어떻게 되나 (유호 질의 08-12)

**「영업」과 「자격·교육」은 다른 층이다.** 폐업으로 없어지는 것은 **영업신고**뿐이다.

| | 폐업신고 O | 폐업신고 X (현재) |
|---|---|---|
| **영업신고증**(건기식 일반판매업) | **말소** | 살아 있음 |
| **자격·교육 수료증** | **그대로 남음** | 그대로 남음 |
| **매년 교육 의무** | **끝남** (폐업한 해는 면제) | **계속** — 실제 영업 여부와 무관 |
| 미이수 과태료 | 없음 | 🔴 **건기식 1차 200만 / 2차 이상 300만** · 화장품 책임판매관리자 **50만** |

- 🔑 **자격증을 「삭제」하는 절차는 존재하지 않는다.** 그건 유호님이 교육을 받았다는 이력일 뿐이라 등록·유지비가 붙지 않는다. **남는 게 이득이다** — 나중에 한국 건기식·화장품을 다시 취급할 때 경력으로 인정된다.
- 🔴 **끊어야 하는 것은 자격이 아니라 「의무」다.** 교육 의무는 *실제 영업 여부가 아니라 「영업이 등록된 상태」*로 발생한다 → **폐업신고만이 그걸 끊는다.**
- **화장품책임판매관리자**: 자격 자체는 폐업으로 소멸하지 않는다. 재등록 시 「화장품 제조 또는 품질관리 업무 2년 이상 경력」으로 인정될 수 있다.
- ⚠ 별도 대상인 경우: **제조업 등 다른 등록증**이 있으면 그건 창구가 하나 더 늘어난다. 민간자격증(건강기능식품관리사 등)은 폐업과 완전히 무관.

> 📌 **건기식 교육 미이수 과태료 200만원은 등록면허세 4만원의 50배다.** 고지가 재개발 예정지로 갔을 테니 실제 부과 여부는 미확인 — 이것이 이번 정리를 서둘러야 할 진짜 이유이자, 0단계 전자송달이 급소인 이유다.

## 4-B. 지방세 — 홈택스에 «안 나오는» 층 (유호 질의 08-12 「위택스 꼭 봐야 하나」)

**판정: 봐야 한다. 5분.** 단 근거는 「세금이 많아서」가 아니다.

- 🔑**등록면허세는 소득세가 아니라 「면허를 갖고 있는 것」에 붙는다** — 매출 0원이어도 매년 자동 부과된다. 따라서 **「수입이 적었다」는 방어가 안 된다.** 유호 실측: 3~4년 합산 수입 몇백만원 미만 → 그럼에도 면허세는 그대로 나갔다.
- 📏규모: 통신판매업 40,500 + 화장품 18,000~67,500 + 건기식 = **연 10만원 안팎** → 3~4년 **30~40만원 + 가산금**.
- **국세는 걱정 없다**(실측): 홈택스 미납 0원 · 종소세 70,940 **환급** · 부가세는 무실적이면 0.
- 🔴**그래도 봐야 하는 진짜 이유 셋**: ①지방세 체납은 **압류**로 간다(몽골 체류 중이면 대응 불가) ②체납이 있으면 **지방세 납세증명서가 안 나온다** → ㈜싱크시프트의 **교육청·대학 수탁·조달 계약에서 대표자 개인 체납이 걸린다** ③**폐업해도 이미 부과된 것은 소멸하지 않는다**(앞으로 안 붙을 뿐).

### ⚠ 창구가 갈린다 — 「0원」을 분모와 함께 읽어야 하는 자리
| 사업장 주소 | 창구 |
|---|---|
| **서울** | **[ETAX](https://etax.seoul.go.kr)** — 서울시 지방세는 **위택스에 안 잡힐 수 있다** |
| 그 외 | **[위택스](https://www.wetax.go.kr)** |

> 등록면허세는 **사업장 주소 관할** 지자체가 부과한다(= 폐업한 재개발 예정지 주소). 위택스만 보고 0원이어도 서울이었다면 「없다」가 아니라 **「거기서 안 보인다」**다.
