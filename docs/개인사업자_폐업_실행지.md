# 개인사업자 폐업 실행지

> 작성 2026-08-12 · 대상 = 유호님 개인사업자 2개 · 홈택스 메뉴는 **2026-08-12 라이브 실측**(블로그 안내와 메뉴명이 다름)
> 관련 판정: 메모리 `korea-mongolia-tax-structure` §「개인사업자 2개」 3번 — 「출국 전 정리 목록」의 그 항목을 이 문서가 집행한다.

---

## 0. 한 줄 판정

**폐업 방향은 맞다.** 다만 **홈택스 폐업신고를 먼저 누르면 안 된다** — 그 버튼이 눌리는 순간 되돌릴 수 없는 것이 셋 생긴다(§2). 순서는 §3.

### 제가 할 수 있는 것 / 못 하는 것

| | |
|---|---|
| ❌ **제가 못 함** | 홈택스·정부24 **로그인**(간편인증=유호님 폰 생체·공동인증서 비밀번호) · **최종 제출 버튼**(국세청에 내는 비가역 공적 신고) |
| ✅ **제가 함** | 화면 경로·입력값 전부 확정 · 폐업일 판정 · 세금 달력 · 놓치는 별도 신고 발굴 · **유호님이 로그인만 해주시면 그 뒤 화면 읽기·칸 채우기를 제가 원격으로**(제출 직전에 멈춰 유호님께 넘김) |

## 1. 먼저 답이 필요한 것 3개 (이게 순서를 바꾼다)

| # | 질문 | 왜 중요한가 |
|---|---|---|
| ① | **재고·사업용 자산이 남아 있나?** (화장품·건기식 재고, 매입세액 공제받은 노트북·비품 등) | 남아 있으면 폐업일에 **「잔존재화 간주공급」**으로 **부가세가 과세**된다 — 안 팔았는데 판 것으로 본다. 폐업 후엔 세금계산서를 못 끊어 **처분 자체가 막힌다.** |
| ② | **통신판매업 신고증이 있나?** (신고번호 = 제20XX-지역-XXXXX호) | 있으면 **홈택스와 별개로 정부24에 폐업신고**를 따로 해야 한다. 안 하면 **등록면허세 40,500원이 매년 계속 부과**된다(폐업신고 전까지). |
| ③ | **화장품·건기식이 「종목」뿐인가, 「인허가」까지 받았나?** | 화장품책임판매업 **등록**(지방식약청) / 건강기능식품 일반판매업 **신고**(관할 보건소·구청)가 있으면 그것도 각각 폐업신고 대상. 사업자등록증 종목에만 적혀 있는 것이면 불요. |

> ③ 확인법: 사업자등록증을 보고 종목만 있으면 대개 불요. 신고증·등록증을 따로 받은 기억이 있으면 그 관청에 폐업신고가 필요하다.

---

## 2. ⚠ 눌리면 되돌릴 수 없는 것 셋

1. **재고를 못 판다** — 폐업일 이후 세금계산서·현금영수증 발행 불가. 재고가 있으면 **폐업 전에** 처분한다.
2. **잔존재화 부가세** — 폐업일 기준 남은 재화·감가상각 자산의 시가에 10% 과세. 폐업일을 정하는 순간 확정된다.
3. **통신판매업은 「폐업 5일 전」이 법정 기한** — 대부분의 인터넷 가이드가 「홈택스 먼저」로 안내하는데, 그 순서를 따르면 이 기한을 **이미 어긴 상태**가 된다.

---

## 3. 🔥 순서 — 통념을 뒤집는다

> **통념**: 홈택스 폐업신고 → 그 다음 인허가 정리.
> **여기서는 반대다**: 홈택스가 **마지막에서 두 번째**다. 근거 = §2의 셋.

```
0단계  전자송달 신청          ← 가장 먼저. 이유는 §4-0 (급소)
1단계  재고·자산 처분          ← 있으면. 없으면 건너뜀
2단계  통신판매업 폐업신고     ← 정부24 · 폐업 5일 전
3단계  (해당 시) 화장품·건기식 인허가 폐업신고
4단계  홈택스 폐업신고         ← 여기서 사업자등록 말소(자동)
5단계  부가세 확정신고         ← 폐업일 다음 달 25일까지 (별개 의무!)
6단계  폐업사실증명원 발급 → 건보공단·국민연금공단
7단계  2027년 5월 종합소득세 신고  ← 마지막 매듭
```

---

## 4. 단계별 클릭

### 0단계 — 전자송달 신청 ⭐ 이번 건의 진짜 급소

**왜 먼저인가**: 폐업해도 **세금 고지서는 2027년 5월 종소세까지 계속 온다.** 폐업하면 사업장 주소가 없어져 고지서는 **주민등록 주소**로 가는데, 유호님은 2027-02에 몽골로 나가신다 → **못 받는다 → 모르는 채 체납.** 지금 사업장 주소(재개발 예정지)도 이미 같은 문제라 메모리에 🔴🔴로 잡혀 있다.

1. 홈택스 로그인
2. 상단 **전체메뉴** → **My홈택스** → **전자고지·송달** (또는 검색창에 「전자송달」)
3. **전자송달 신청** — 수신 수단에 **이메일 + 휴대전화** 둘 다 등록
4. ⚠ **사업자 기준 말고 「개인(주민등록번호)」 기준으로도 신청** — 사업자 기준으로만 하면 폐업과 함께 끝나서 정작 종소세 고지를 못 받는다

> 몽골에서도 받는 유일한 통로다. 이거 하나가 §7의 체납 리스크를 통째로 닫는다.

---

### 1단계 — 재고·자산 처분 (해당 시)

폐업 전에 판다. 못 팔면 폐업일 기준 시가로 부가세를 낸다.
- 감가상각 자산(노트북·집기 등)은 취득 후 경과 기간에 따라 간주시가가 줄어든다 — 오래됐으면 부담이 작다.
- 재고를 **개인 용도로 가져가는 것도 「공급」**으로 본다(면제 아님).

---

### 2단계 — 통신판매업 폐업신고 (정부24)

1. **www.gov.kr** 접속 → 로그인(간편인증)
2. 검색창에 **「통신판매업 폐업」** → **통신판매업 휴업·폐업·영업재개 신고** → **신고하기**
3. 입력: **통신판매업 신고번호**(신고증 좌측 상단) · 상호 · 사업자등록번호 · **폐업일**
4. 제출 → 처리 **3영업일**(접수일 제외)

> 놓치면: 등록면허세 40,500원이 **매년 1월 1일 자동 갱신**돼 계속 부과된다. 몽골에 계신 동안 체납으로 쌓인다.

---

### 3단계 — 화장품·건기식 인허가 폐업 (§1-③에서 「있다」인 경우만)

| 인허가 | 폐업신고처 |
|---|---|
| 화장품책임판매업 **등록** | 관할 **지방식품의약품안전청** |
| 건강기능식품 일반판매업 **신고** | 관할 **시·군·구청(보건위생과)** 또는 보건소 |

> 온라인 창구는 지자체마다 갈린다. 「정부24 → 해당 민원 검색」으로 먼저 보고, 없으면 관할 관청 전화가 빠르다.

---

### 4단계 — 홈택스 폐업신고 ★ 본체

**메뉴 경로 (2026-08-12 홈택스 라이브 실측)**

```
hometax.go.kr 로그인
 → 상단 [전체메뉴]
 → [증명·등록·신청·사업장현황]        ← ⚠ 블로그들이 쓰는 「국세증명·사업자등록·세금관련 신청/신고」가 아님
 → [사업자등록 신청·정정·휴폐업]
 → [휴·폐업·재개업 신고]
 → [휴업·폐업 신고]                    (내부 메뉴코드 4306060100)
```

**입력**
| 칸 | 값 |
|---|---|
| 사업자등록번호 | 목록에서 선택 → 인적사항 자동 조회 |
| **폐업일자** | 실제 사업을 그만둔 날. §5 참조 |
| **폐업사유** | 「사업부진」 등 해당 항목 선택 |
| 사업자등록증 | 온라인 신고는 **반납 불요**(전자 제출) |

- **2개를 각각** 해야 한다 — 한 번에 묶이지 않는다.
- 제출하면 **사업자등록 말소는 자동** — 별도 말소 신청 없음.

---

### 5단계 — 부가가치세 확정신고 ⚠ 폐업신고와 «별개 의무»

**가장 많이 놓치는 자리다.** 폐업신고를 했다고 세금 신고가 끝난 게 아니다.

- **기한 = 폐업일이 속한 달의 다음 달 25일**
- 8월 중 폐업 → **2026-09-25까지**
- 대상 기간 = 2026-07-01 ~ 폐업일 (제2기 과세기간 시작일부터)
- 매출이 0이어도 **「무실적 신고」를 해야 한다**
- 안 하면: 무신고가산세 + 납부지연가산세

경로: 홈택스 → **세금신고** → **부가가치세 신고** → **폐업확정신고**

---

### 6단계 — 폐업사실증명원 → 건보·연금

1. 홈택스 → **증명·등록·신청·사업장현황** → **민원증명** → **폐업사실증명** → 발급(PDF 저장)
2. **국민건강보험공단**(1577-1000) — 지역가입자 전환 + **소득 없음 조정 신청**(안 하면 폐업 전 소득 기준으로 보험료가 계속 나온다)
3. **국민연금공단**(1355) — 소득 정지·납부예외 신청

> ⭐ **PDF로 반드시 저장해 두세요.** 출국 후 공동인증서가 만료되면 홈택스 접근 자체가 막힐 수 있고, 이 서류는 몽골 거주허가·비거주자 판정 자료로도 쓰입니다.

---

### 7단계 — 2027년 5월 종합소득세

- 2026-01-01 ~ 폐업일까지의 소득 전체를 **2027년 5월**에 신고
- 폐업했다고 면제되지 않는다. 소득이 0이어도 신고
- 이때 유호님은 **몽골에 계신다** → 0단계 전자송달이 여기서 값을 한다

## 5. 폐업일을 언제로 적을 것인가

| 안 | 내용 | 판정 |
|---|---|---|
| **오늘(2026-08-12)** | 가장 단순 | 부가세 신고 9/25 · **재고가 있으면 처분할 시간이 없다** |
| **소급** (실제 중단일) | 이미 몇 달 전 사업을 멈췄다면 그날로 | 등록면허세·무실적 신고 부담이 줄지만, **그 이후 발행한 세금계산서·매입세액이 부인**된다. 거래가 정말 0이었을 때만 |
| **며칠 뒤** | 재고 처분·통신판매업 5일 전 기한을 맞춤 | **재고가 있으면 이것** |

**권고**: §1-① 답이 「재고 없음」이면 **오늘**, 「있음」이면 **처분 완료일 + 통신판매업 신고 5일 뒤**.

## 6. 곁가지로 확인할 것

- **노란우산공제** 가입돼 있나 → 폐업은 정당한 공제금 수령 사유. 소득공제를 유지한 채 받을 수 있다. 미가입이면 해당 없음.
- **사업용 신용카드** 홈택스 등록 → 폐업 시 자동 정리. 손댈 것 없음.
- **직원** 있었나 → 있으면 4대보험 상실신고 별도. 1인 사업자면 불요.
- **체납·미수령 고지** → 폐업 «전»에 홈택스에서 확인. 메모리 §「송달장소」 항목과 같은 축.

## 7. 이 폐업이 다른 트랙에 미치는 영향

| 트랙 | 영향 |
|---|---|
| **㈜싱크시프트 법인 설립** | **영향 없음 · 병행 가능.** 법인은 별개 인격이라 개인사업자 폐업이 설립을 막지 않는다. 다만 첫 계약(2026-09)을 법인으로 받아야 하므로 **법인 설립이 더 급하다** — 폐업은 이것과 경쟁하지 않는다 |
| **상표 `40-2026-0165300`** | **영향 없음.** 개인(자연인) 명의 출원이라 사업자등록과 무관 |
| **몽골 FDI·거주자 판정** | **유리해진다.** 개인사업자는 「국내에서 직업을 영위」 증거라 비거주자 판정에 불리했다 — 그 축을 제거한다 |
| **몽골 ODI 신고** | 사업자등록증 사본 용도가 있었다면 폐업 «전»에 사본을 확보. (지렛대로 쓰는 것은 이미 🚫 기각) |

## 8. 지금 유호님이 할 것 — 딱 3줄

1. **§1의 세 질문에 답한다** (재고 / 통신판매업 신고증 / 인허가 여부)
2. **0단계 전자송달**을 먼저 신청한다 — 이건 답과 무관하게 지금 해도 된다
3. 답을 주시면 폐업일을 확정하고, 원하시면 **로그인 후 화면을 제가 원격으로 채워 제출 직전까지** 끌어다 드린다
