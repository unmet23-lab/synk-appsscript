처음에 이렇게 적었다: **「색인이 «어디를 고치나»를 안 적어서 한 줄을 재려면 며칠이 든다.」**
표본 셋(동의문 주어·동의문 낱말·자정 넘김)을 재려다 실물을 못 찾아 멈춘 것이 근거였다.

**틀렸다.** 재료 `docs/_ops/소급불가_울트라/전량.json` 을 열어 보니 **194건 전부에 `source` 칸이
있고 파일·줄까지 적혀 있다**(100%). 색인 마크다운이 세 칸(마감·임자·무엇이 사라지나)만 옮기고
그 칸을 버린 것이다.

| 무엇 | 색인 마크다운 | 재료 json |
|---|---|---|
| 마감 사건 | 있다 | 있다 |
| 임자 | 있다 | 있다 |
| 무엇이 사라지나 | 있다 | 있다 |
| **어디를 고치나(`source`)** | **없다** | **194건 전부** |

🔑 **내가 밟은 것** — 옮겨 적은 판(마크다운)만 보고 「없다」로 판정했다. 원재료를 안 열었다.
    표본 셋이 «못 찾겠다»를 냈을 때 그것을 「색인에 자리가 없다」로 읽었는데, 실은 «내가 안 본
    칸에 있었다»였다. 자를 의심하기 전에 원본을 먼저 여는 것이 순서다.
