### A-1. 퀴즈가 학생 한 명당 **평생 1건**만 남는다 → ✅ 해소 [v9.188]

```
Code.js:3922       quizFormUrlOf_(…, sid, pq ? 'AIQ' : qPick.id)   ← 개인 AI 퀴즈 ID가 상수
엔진_수집.js:787   const key = qid + '|' + sid;  if (seen[key]) return;   ← 중복으로 판정해 버림
```

매일 밤 AI가 그 학생의 약점을 겨냥해 개인 퀴즈를 만들어 보내는데, **퀴즈ID가 날짜와 무관하게 항상 `'AIQ'`**다. 그래서 `AIQ|SYNK-001`이 첫 제출에서 굳고 **둘째 날부터 모든 응답이 영구 폐기**된다. 게다가 그 첫 1행마저 `qMap['AIQ']`가 없어 **문제·정답이 빈칸**이고 채점은 `판정보류`다.

- **판정: 재설계.** 퀴즈ID를 `AIQ-{yyyyMMdd}` 이상으로 채번 + 문제·정답을 `ai_daily`에서 스냅샷해 행에 박는다.
- ⚠ **`tests/수집.test.js:459`가 `"pq ? 'AIQ' : qPick.id"` 문자열을 회귀로 못박고 있다** — 버그가 사양이 돼 있어 고치면 배포 게이트가 막힌다. 회귀를 함께 고쳐야 한다.
- **소급**: ❌ 영구 불가(안 받은 응답은 없다). 실학생 0명인 지금이 손실 0인 마지막 구간.

### A-2. 개인 맞춤 문제가 매일 밤 삭제된다 → ✅ 해소 [v9.188]

`엔진_콘텐츠AI.js:1856-1863` — `ai_daily`(student_id·날짜·한문장·퀴즈문제·해설)를 **오늘·어제만 남기고 `clearContent`**. 아카이브 없음.

- **운영 기능**(출석·급여·수납·리포트카드·결석·문의) — 데이터를 안 남겨도 정당하다.

- **라이브 실측 전량** — 크롬 브리지가 타계정이라 차단(`memory/chrome-bridge-account-pairing`). Glide에 수집 버튼 3개가 실제로 붙었는지, `outcome_log` 라이브 열 수, `hw_feedback` 실제 열 수 전부 코드층 판정이다.
- **Glide 플랜 다운그레이드의 실제 영향** — Explorer 기간에 시트 연결이 어떻게 되는지 공식 문서에 없다.
- **Apps Script 실행 계정** — `ADMIN_EMAIL='unmet23@gmail.com'`은 알림 수신 주소이지 트리거 소유 계정이 아니다. 편집기에서만 확인 가능.
- **건당 API 실지연** — 계측이 없어 배치 상한의 실제 여유를 모른다.
- **현재 트리거 총 실행시간 소비량** — `parentSweep` 144회/일이 최대 소비자인데 측정된 적 없다.
