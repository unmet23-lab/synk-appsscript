## ① 몬스터 7단계 임계값 표 (코드 실측)

출처: `setupMonsters()` — 콘텐츠 시트 `contents`의 `monster` 행 6번째 필드(F열)가 **누적 포인트 임계값**. (`엔진_콘텐츠AI.js:32` — 파일 분리로 Code.js에서 이동)

> **"알"은 별도 단계가 아니다(유호님 확인 2026-07-12):** 첫 단계 **뉴로(0포인트)가 곧 "알" 상태**다 — 도감 서사가 "알 속에서 소리를 엿듣는 아기 뉴런 🥚, 첫 단어를 말하면 껍질에 금이 간다". 학생은 등록 즉시 뉴로(알)로 시작해 첫 진화 때 부화한다. 그래서 시작을 알로 세면 8개처럼 느껴지지만 **명명 단계는 7개(뉴로~싱크마스터)가 맞다.**

| 단계(idx) | ID | 이름 | 누적 P 임계값 | 캐릭터 서사(도감) |
|---|---|---|---|---|
| 1 | M01 | 뉴로 | **0** | 알 속에서 소리를 엿듣는 아기 뉴런 🥚 |
| 2 | M02 | 스파키 | **100** | 첫 신호를 쏜 꼬마 ⚡ |
| 3 | M03 | 링커 | **250** | 단어를 잇는 연결쟁이 🔗 |
| 4 | M04 | 서킷 | **500** | 회로를 두른 꼬마 발명가 💡 |
| 5 | M05 | 미엘로 | **900** | 촛불 든 배움의 순례자 🕯️ |
| 6 | M06 | 플로우 | **1500** | 양손에서 빛이 흐르는 현자 ✨ |
| 7 | M07 | 싱크마스터 | **2400** | 빛나는 지혜의 관과 황금 홀을 든 시냅스의 왕 👑 |

- 임계 수열 **0 / 100 / 250 / 500 / 900 / 1500 / 2400** — 코드 헤더 주석(L171)의 설계 의도와 일치: "첫 진화 3주 내(훅), 최종 = 성실 9개월". 숙제 10P 기준 단위(L170).
- **임계값이 재는 것 = "획득 누계 포인트"(P열/`total`)**, 스토어 잔액(AQ열)이 아니다. 스토어 소비가 진화를 깎지 않도록 v7.1에서 성장(P·earned)/잔액(AQ) 분리(L174~175, L1150, L1546 `const t = total[id]`). 획득 누계는 양수+정정만 반영.
- 런타임에서 임계값은 하드코딩이 아니라 **콘텐츠 시트에서 로드**된다: `calcAll` 내 `stages` 배열이 `monster` 행의 이름·임계(th)·이미지를 읽어 th 오름차순 정렬(L1178~1182). 즉 setupMonsters가 시트에 심은 값이 정본이고, 위 표는 그 시드값.

## ② 진화 트리거 로직

### 2-1. 기본 판정 — `monsterOf(pts)` (`Code.js:2318`)
```
누적포인트 pts >= stages[i].th 를 만족하는 가장 높은 단계를 현재 단계로.
pct(진행률) = floor((pts - cur.th) / (next.th - cur.th) * 100)  // 0~100 클램프
rem(다음 진화까지 남은 P) = max(next.th - pts, 0)
반환: { stage, pct, rem, idx(1~7) }
```
- 순수 임계 비교. 최고 단계 도달 시 pct=100·rem=0.

### 2-2. 진화 게이트 (v9.36) — `gatedIdx_` (`Code.js:2357` · 적용은 `calcAll` 내 클램프 삽입점)
포인트로 단계에 도달해도 **해당 단계의 문법 숙달(mastery_log '도달') 수가 부족하면 단계 진입을 보류**(클램프)한다.
- 필요 수: `GRAMMAR_GATE_NEED = { 2:0, 3:9, 4:9, 5:9, 6:9, 7:9 }` (`엔진_콘텐츠AI.js:55`). 즉 **뉴로→스파키(2단계) 첫 진화는 무게이트**, 3단계 이후는 각 단계 문법 12개 중 **9개(75%) 도달** 필요. 단 `Math.min(GRAMMAR_GATE_NEED, 실제 뱅크 수)`로 뱅크가 9 미만이면 그만큼만 요구(L1228, L1561).
- 문법 단계 판정: `grammarStageOf_` — 문법 ID `G[2-7]xx` 의 숫자가 게이트 단계(L6088). 뱅크 수 = `grammarBankCounts_`(L6089).
- **3중 안전장치**(L1223~1233): ①`mastery_log` 기록이 없는 학생은 게이트 미적용(신규생 보호) ②전회 단계(prevIdx) 아래로 강등 금지 ③반 문법태그가 최근 60일 없으면(`classTagFresh` false) 게이트 자동 해제.
- 게이트로 막히면(`gateBlocked`) 게이지는 가득(pct=100·rem=0)으로 표시하고 "에너지 충전 완료" 프레임 + "📖 문법 N개만 익히면 …단계 진화!" 긍정형 문구(L1558, L1566 — '부족·실패' 금칙 준수).

### 2-3. 진화일 기록 BB열(54) (L1692~1696)
`calcAll`이 단계 **상승만** 감지해 오늘 날짜 기록: `prevN >= 1 && newN > prevN` 조건 → 신규생 첫 계산·하락은 제외. Glide 홈 3일 축하 카드용.

### 2-4. 대표몬스터/액자 (참고)
- BC(55) 대표몬스터: 학생이 도감에서 선택하되 `calcAll`이 임계 검증해 미도달 선택은 자동 무효화(L363~364 주석).
- 액자 `FRAME_CSS` 7종(L895~903): 새싹→스파크→링크→서킷→불씨→빛→**금빛 액자**(#F5A623 골드) — AP단계(1~7)에 대응, 하강 없음. 스킨=취향(가로), 액자=성장(세로).

## ④ 스트릭(연속출석) 규칙

### 4-1. 현재 연속출석 — `streakOf(sid)` (`Code.js:2397`)
- **수업일 기준**(달력일 아님): 평일반은 주말을 건너뛰어 세므로 주말에 스트릭이 안 끊긴다(L1245, `isClassDayOf` L1253~1258 — 반 타입 '주말'/'평일'을 시간표에서 판별).
- 오늘이 수업일인데 아직 출석 전이면 어제부터 카운트(L1270~1272). 최대 370일 가드(L1273).

### 4-2. 최고 스트릭 — 최고스트릭 AB열(28)
- 헤더 보장 L1316. `records[sid].maxStreak`는 달력일 연속 최댓값을 출석 이력에서 계산(L1535~1541, 여기선 달력 msPerDay 기준).
- 업적용 `best = max(연속출석 r[20], 최고스트릭 r[27])`(L4673) → 스트릭 배지: `한 달의 약속`(≥30)·`두 달의 전설`(≥60)·`100일의 기적`👑(≥100)(L4678~4680).
- 나의 여정/기록실에 "🔥 최장 연속출석 N일" 표시(L1080, L1690 — ⚠기록실 카드 BG는 v9.147 off, 나의 여정만 노출). Notion "최장연속출석"(L8570).

### 4-3. 스트릭과 진화의 관계
**스트릭은 몬스터 진화 트리거가 아니다.** 진화는 오직 누적 포인트(+문법 게이트). 스트릭은 업적 배지와 이탈위험(QUIET_DAYS 7일 무포인트 경보, L577)만 구동. 출석 자체 포인트가 누적 P에 들어가 간접 기여할 뿐 스트릭 일수가 직접 임계를 움직이지 않는다.
