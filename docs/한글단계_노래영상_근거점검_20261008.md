# 한글 노래 영상 근거 점검 — 가나다도 모르는 외국인에게 실제로 도움이 되나 (2026-10-08)

> 10-08 조사·후보 청취·제안과 같은 날 사용자 결정을 보존한 기록이다. §3의 떠올리기 쇼츠 제안은 §4-1에서 채택하지 않았으며 새 제작 지시가 아니다. 예약 상태·목소리 비용·앱 음성 준비 상태도 당시 값이다. 연구의 적용은 대상·원문 확인 한계를 따르며, SYNK 영상의 실사용 효과나 지금의 게시·제작 승인을 증명하지 않는다. 현재 산출·제작 범위는 [노래 README](../experiences/hangul-stage/songs/README.md)와 [가이드](../experiences/hangul-stage/songs/노래영상_가이드.md)를 따른다.

유호님 10-08, 받침 둘 노래 후보 넷을 듣고: 「발음이 빨라서 나도 잘 모르겠어. 이거 도움되는거 맞긴 해?」. 이어서: 「초보자들에게 검증된 방법으로 도움이 되는걸 제작하는거잖아. 이 컨텐츠는 지금 가나다라마바사 이것도 모르는 외국인들을 위해 만들고있는 컨텐츠니까 다시 조사해보고 보강해야할부분이 뭔지 체크하고 만들어야할 가이드도 다시 조사해서 전체적으로 검증된 방법으로 보강해서 만들어나가자.」

10-04 [학습 방식 조사](한글단계_학습방식_조사_20261004.md)의 결론은 그대로다. 노래는 입구·복습·보상이고, 실제로 읽게 만드는 것은 글자-소리·합치기를 직접 가르치는 연습이다. 이번에는 그 조사가 다루지 않은 두 가지를 찾았다.

- 노래와 영상을 어떻게 만들어야 효과가 나는가.
- 어떤 내용을 노래에 맡기면 안 되는가.

만들 때 쓰는 기준은 [노래 영상 가이드](../experiences/hangul-stage/songs/노래영상_가이드.md)로 옮겼다.

## 결론

1. **검토한 가사 회상 실험에서는 느린 속도가 이점의 중요한 조건이었다.**
   - 노래로 들은 가사를 더 잘 기억했지만, 말로 들려주는 속도를 노래만큼 늦추자 차이가 사라졌다.
   - 같은 음절을 늘 같은 가락으로 부르면 낱말을 더 잘 갈라 들었다.
   - 그래서 새 글자는 느리게, 빠른 줄은 이미 나온 것의 복습에만 쓴다.
2. **노래 속도에서 원어민 귀에도 갈리지 않는 소리 구별은 노래에 맡기지 않는다.**
   - 받침 ㄱ·ㄷ·ㅂ(윽·읃·읍)이 그렇다. 유호님도 노래에서는 못 가렸다.
   - 가·카·까의 예사소리·거센소리 구별도 그렇다. 말할 때는 주로 뒤 모음의 음 높이로 갈리는데, 노래에서는 멜로디가 음 높이를 정한다.
   - 이런 구별은 효과가 확인된 「여러 목소리로 듣고 고르기」(HVPT) 연습으로 앱에서 가르친다.
3. **당시 세 영상(모음 댄스·그 아 가·받침 노래)은 핵심 설계 근거와 비교해 예약 유지 의견을 냈다. 실제 효과 검증은 아니다.**
   - 맞는 점: 글자-소리·합치기, 음절 덩어리, 글자 모양과 같은 뜻의 몸동작, 글자 모양이 든 그림, 소리와 같은 순간에 켜지는 글자, 한글 뒤에 작게 나오는 로마자.
4. **빠진 것은 두 가지다.**
   - 글자를 먼저 보고 소리를 떠올려 보는 순간.
   - 노래에 없던 음절을 읽어 보는 「옮겨 읽기」 확인.
   - 새 영상부터 넣는다. 이미 만든 세 편은 짧은 떠올리기 쇼츠로 보강하자고 권한다.
5. **남은 노래는 겹모음 댄스 하나다(모두 네 곡).**
   - 세 소리(가·카·까)와 받침 둘(ㄱ·ㄷ·ㅂ)은 노래로 만들지 않는다. 앱 연습이 맡는다.
   - 10-08 「세 곡 더」 답을 고친 것이다.

## 2. 지금 세 영상 점검

유튜브 판 화면을 6초 간격으로 뽑아 보고, 노래 시각 표([songs.mjs](../experiences/hangul-stage/songs.mjs))로 속도를 쟀다.

| 기준 | 모음 댄스(10/9 공개) | 그 아 가(10/10) | 받침 노래(10/11) |
|---|---|---|---|
| 글자-소리·합치기를 직접 | ✓ 모음마다 소리와 동작 | ✓ 그 + 아 = 가 | ✓ 아 + 은 = 안 |
| 음절 덩어리를 크게 | △ 가운데는 자모(ㅏ), 음절(아)은 위 가사 줄에서 빨갛게 | ✓ | ✓ |
| 동작이 글자 모양과 같은 뜻 | ✓ 짧은 획 쪽으로 뻗기 | ✓ 팔 방향은 모음에만 | ✓ 손바닥 아래 = 받침 자리 |
| 글자 모양이 든 그림 | — 모음은 동작이 맡음 | ✓ 1절 자음 위 | — 낱말 그림(뜻) |
| 새 글자의 속도 | ✓ 모음 하나에 약 1.1초 | ✓ 합치기 셋이 두 박(초당 2.5음절) | ✓ 합치기 셋이 두 박(초당 2.6음절) |
| 빠른 줄은 복습에만 | △ 둘째 후렴 「아 야 어 여 … 이」 열 음절이 2.2초(초당 4.5음절). 방금 배운 ㅑㅕㅛㅠ가 바로 이 속도 | ✓ 후렴 초당 3.3음절, 1절에서 다 나온 음절 | ✓ 후렴 초당 3.4음절, 1절에서 다 나온 음절 |
| 노래 속도에서 귀로 갈리는 소리 | ✓ 모음은 길게 끌 수 있음 | △ 가/카·다/타·바/파·자/차가 한 노래에 나옴. 글자와 그림은 다르지만 소리 구별은 노래가 가르치지 못함 | △ 후렴의 안/앙이 빠름(원어민에겐 갈림) |
| 소리와 글자가 같은 순간 | ✓ 소리를 재서 맞춤 | ✓ ±0.07초 | ✓ ±0.07초 |
| 로마자 | 없음 | ✓ 0.15~0.3초 뒤 작게, 첫 등장만(ra = ㄹ은 영어 r과 다른 소리) | ✓ 같은 방식 |
| 떠올리기(먼저 보고 소리 내 보기) | ✗ 따라 하기만 | △ 「그 더하기 아는?」에 답 칸 ?(쉼 길이는 Suno가 정함) | ✗ |
| 옮겨 읽기(노래에 없던 음절) | ✗ | ✗ | ✗ |
| 소리 순간의 장식 | ✓ 「아!」마다 펠트 점이 터지지만 짧은 획 끝과 인형 손에서 터져 방향을 짚는 신호로 작동. 모음마다 바뀌는 바탕색은 옅음 | ✓ 적음 | ✓ 적음 |
| 미리 보여 주기 | ✓ 첫 화면에 열 모음 | ✓ 열네 자음 | ✓ 안 알 암 앙 |

공개를 미룰 만큼 근거와 어긋나는 것은 없다. △·✗는 새 영상부터 가이드로 막고, 이미 만든 세 편은 아래 보강으로 채운다.

## 3. 보강할 것

| 차례 | 무엇 | 왜 | 비용 |
|---|---|---|---|
| 1 | 가이드를 기준으로 고정한다: 주제 고르기·가사·화면·검수 | 이번처럼 들어 보고 나서야 버리는 일을 막는다 | 없음 |
| 2 | 겹모음 댄스부터 가이드를 적용한다. 모양과 소리가 맞고 서로 또렷이 갈리는 넷(와·워·위·의)만 합치기로 부르고, 낱말(과·귀·쥐·뭐)로 한 번 더 부른다. 떠올리기 한 번, 끝에 옮겨 읽기를 넣는다. 소리가 같은 묶음(ㅐ·ㅔ, ㅚ·ㅙ·ㅞ, ㅒ·ㅖ)은 앱 만나기 카드의 「소리가 같아요」가 맡는다. | 결론 1·2·4 | Suno 만들기 몇 번 |
| 3 | 세 영상마다 짧은 「떠올리기 쇼츠」를 붙인다(15~20초). 노래에 없던 음절 셋을 보여 주고, 한 박 쉬고, 소리로 답한다. 본 영상 다음 날에 올린다. | 간격을 두고 다시 떠올리기. 옮겨 읽기로 정말 읽는지 확인한다. | 답 소리 목소리(앱 목소리 파일 또는 Typecast 몇 글자) |

## 5. 확인 못 한 것

- Brennan & Heneman-Lee 2025, Language and Speech 2019, HVPT 메타분석은 초록·검색 요약만 읽었다. 세부 설계와 수치는 원문으로 다시 확인해야 한다.
- 참여 신호·세서미 스트리트 계열 연구는 아이 대상이다. 청소년·성인에게는 떠올리기 효과(Szpunar 2013)를 근거로 쓴다.
- Schön 2008이 다시 재현됐는지는 확인하지 못했다.
- 노래 영상 자체가 외국인 초보의 한글 읽기를 늘린다는 통제 연구는 이번에도 찾지 못했다(10-04와 같음). 우리 영상의 효과는 보강 5의 전후 퀴즈로만 확인할 수 있다.
