### 3-3. 권한 — ★Row Owner의 구조적 딜레마 (정직 판정 · v9.42)
**중요 발견**: profiles에 Row Owner를 켜면 각자 **자기 행만** 기기로 받습니다 → **랭킹 목록·강사의 학생 리스트·케미·리그가 전부 빈 화면**이 됩니다(강사 이메일은 학생 행에 없으므로). 저번 조립에서 화면이 비었던 숨은 원인 후보입니다. Glide의 예외 기능(Roles)은 상위 플랜 전용이라 Maker에선 양자택일:

| | A. Row Owner ON | **B. Row Owner OFF (권장)** |
|---|---|---|
| 보안 | 최상(남의 행 미전송) | 화면엔 안 보여도 기기엔 내려감 |
| 랭킹·강사 리스트·케미·리그 | ❌ 전멸 | ✅ 전부 작동 |
| 조건 | — | 민감열 비바인딩 + 개원 전 분리 |

**B로 조립하고, 대신 아래 3개를 지킵니다:**
1. Settings → Privacy → **"Users must sign in" ON** + Users table 매핑(3-2). profiles email에 Row Owner는 **걸지 않음**.
2. 모든 탭·컴포넌트 Visibility = role 조건. 역할값 정확히 `student` / `parent` / `teacher` / **`director`** (admin 아님!)

### 4-1c. 터치 감성 5원칙 (전 화면 공통)
1. **한 화면 = 주인공 1명**: 화면마다 큰 카드(또는 버튼)는 하나. 나머지는 보조 크기 — 전부 크면 전부 안 보임.
2. **누르는 것만 Accent 채움**: Primary 버튼(채움)은 화면당 1개, 나머지는 아웃라인/텍스트 버튼. "누를 곳"이 한눈에.
3. **상태가 즉시 바뀌는 손맛**: 출석 버튼→완료 배지, 교환→잔액 숫자, 찜→목표 카드. 누른 결과가 같은 화면에서 보이게 배치.
4. **빈 화면에도 감정**: 모든 Collection의 Empty state에 세계관 문구 — "아직 조용하네… 첫 이야기를 기다리는 중 📖" (기본 회색 "No items" 금지).
5. **이모지는 시스템**: 탭 아이콘=Glide 아이콘(이모지 금지) / 카드·버튼 안=이모지 1개(코드 카드와 동일 규칙). 섞이면 조잡.

### 4-2. 탭 아이콘·이름 규칙 (센스의 8할)
- 탭 이름은 **2~4글자 한국어**로 짧게: `홈` `도감` `스토어` `소식` `우리 아이` `반` `콕핏`
- 아이콘은 **같은 스타일 계열**(Glide 아이콘 팩에서 라인이면 전부 라인, 필드면 전부 필드)로 통일. 탭마다 스타일이 섞이면 그게 "투박함"의 정체.
- 이모지 탭 이름(예: "🏠 홈")은 금지 — 아이콘과 중복돼 촌스러움. 이모지는 카드 안에만.

### 4-3. 컴포넌트 여백 리듬
- 카드(Rich Text) 사이에 **Separator를 넣지 않기** — 카드 자체에 그림자·여백이 있어 이중 구분선이 되면 투박해짐.
- 컬렉션 스타일: 학생·학부모 목록 = **Card** 스타일(이미지 크게), 데이터성 목록(출결 보드·리그) = **Compact/Table**.
- 목록 이미지가 없는 행이 섞이면 Glide가 회색 사각형을 그림 — 이미지 없는 컬렉션은 스타일에서 이미지 슬롯 자체를 끄기.

### 4-4. 색 사용 절제
- Accent 외 색은 **카드가 이미 들고 있음** — Glide 쪽에서 버튼 색·배경색을 개별 지정하지 말 것(통일감 파괴).
- 버튼은 기본 Accent 채움(Primary) 1종 + 아웃라인(Secondary) 1종만.

- **리그 관리**: league_pairs — 이번 주(week 최신) 행 목록. **반A/반B 편집 허용**(Edit form — 이 2열만) = 원장 수동 매칭 오버라이드. 상태·결과는 편집 금지.
- **반 레이드 현황**: raid — 이번 주 행(week 최신): 반별 목표 HP·달성포인트·상태 읽기. (학생용 연출은 class_stats 레이드카드가 담당 — 이건 원장 숫자 뷰)
- **월드 레이드**: world_raid — 월·보스명·HP·누적데미지·상태 읽기. (연출용: 진행중 행을 Progress로 — 누적데미지/HP)
- **특별 칭호 부여**: manual_titles **Form** — student_id·칭호·부여자·날짜. 원장이 이벤트성 칭호를 직접 수여(다음 계산 때 현재칭호 AC에 합류).
- **보스 휴식주 지정**: 앱 아님 — 시트 `app_state`에 key=`보스휴식주`, value=그 주 아무 날짜(`2026-08-11`, 여러 주는 쉼표). 방학·나담 휴강 주에 보스 소환을 쉬게 함(🏖️ 휴식 스토리 자동).
- **시간표 변경**: 앱 아님 — 시트 `schedule` 탭에서 직접(반·요일유형·시작시간). ⚠ 반 이름을 바꾸면 profiles class_name도 같이 바꿔야 함.
- **공지 쓰기**: notices **Form** — `title_ko`·`body_ko`만 입력(몽골어는 10분 내 자동 번역). 학생·학부모 소식탭에 즉시 노출.
- **명예의 전당 등재**: hall_of_fame Form — 연도·이름·반·업적·한마디·사진URL.
- **크루 프로젝트**: crew_projects Form — 시즌·반·프로젝트명·한줄소개·결과물링크·사진URL·공개일·참여크루. (시즌 K-컬처 프로젝트 포트폴리오 — 학생 소식탭에도 읽기 노출 가능)
- **강사 지표**: teacher_stats 읽기 — 케어지수·지난달왕관·왕관편중%(60%↑면 편중 주의).
- **문의함**: inquiries — 상태 편집 허용('접수'→'처리완료').
- **퇴소 로그**: exit_log 읽기.

### 9-4. 탭 「경영」 (선택 — 시트 직접 관리와 병행)
