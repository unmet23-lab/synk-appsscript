# 마린·몽글 튜터 표정 교정

2026-10-11. 사용자 요청에 따라 까몽과 같은 기준으로 마린·몽글의 표정 전환을 점검한다. 범위는 WORLD 튜터가 실제로 읽는 기본 차림의 고유 표정 14개와 선택·게임·생활·카페 화면이다. 기본 몸과 캐릭터의 기존 표정 어휘를 보존한다.

## 확인한 문제

- 마린의 놀람 렌즈가 기존 화면 마스크의 흐린 경계에 걸려 위·바깥쪽이 눌렸다. 실제 화면과 마스크 없는 같은 이미지의 눈 부분은 RGB 최대 210 차이가 났다. 몽글은 같은 원인의 작은 경계 차이(최대 7)가 있었다.
- 두 캐릭터의 기존 정본에는 눈을 넘어 미간·이마를 포함한 얼굴 사각 영역과 알파가 바뀌는 부분이 있었다. 몸 하단의 위치·색은 유지되므로 얼굴 재질과 눈 합성 범위를 바로잡는다.
- 마린의 집중·졸림은 남색 털이 렌즈를 덮는 눈꺼풀처럼 보였다. 렌즈가 감기지 않는 캐릭터 원칙에 맞춰, 온전한 타원 안의 빛만 바꾼다. 승인된 꽃 모양 눈웃음은 유지한다.

수정 전 화면과 원본 대조는 [감사 자료](../../../experiences/brand-opening/qa/mascot-expressions-20261011/)에 둔다.

## 원본과 제작 방식

- 마린 집중: 타원 전체를 유지하고 가운데 빛이 부드럽게 모인다. [내장 ImageGen 결과](마린_집중_생성원본.png).
- 마린 졸림: 타원 전체에 어두운 금빛이 남는다. [내장 ImageGen 결과](마린_졸림_생성원본.png).
- 두 편집 모두 승인된 `정본_4K/마린_본체.png`를 입력으로 사용했다. [실제 생성 프롬프트](생성요청.json)를 보존하며 도구에서 선택할 수 없는 모델 세부 버전·품질값을 보장하지 않는다.
- 생성 이미지 전체를 정본으로 덮지 않는다. 새 렌즈와 기존 승인 눈·꽃·자수는 각각 좁은 눈 윤곽 안으로만 옮겨, 원래 4096px 본체의 몸·옷·털·전체 알파를 고정한다.
- 마린은 눈감음·눈웃음·놀람·집중·몰래기쁨·민망·졸림, 몽글은 눈감음·눈웃음·놀람·윙크·으쓱·졸림·민망을 다룬다. 튜터가 쓰지 않는 다른 감정·각도·의상 세트는 이번 수정 범위에 넣지 않는다.

## 화면 합성

선택 화면과 동행 튜터는 눈별 마스크를 공유한다. 정사각형 이미지 좌표의 SVG를 `contain`·가운데 정렬로 표시해, 가로 화면 등 비정사각형 초상 칸에서도 실제 그림과 눈 마스크가 함께 맞춰진다. SVG는 눈 그림을 새로 그리는 자산이 아니라 기존 표정 이미지의 표시 범위를 정하는 코드다.

## 정본 반영

`tools/튜터표정정본.js --apply`로 14개 정본과 공용 1024px 파생을 반영했다. [정본.json](정본.json)에 각 원본·백업·출력 SHA256과 눈 마스크, `applied:true`를 기록했다. 실제 정본 파일 14개의 해시가 결과와 일치한다.

- 14개 모두 4K에서 허용 눈 윤곽 밖 RGBA 변경 0·전체 알파 변경 0이다.
- WORLD 공통 crop을 재현한 무손실 480px에서도 눈 영역 밖 RGBA 변경 0·전체 알파 변경 0이다. 두 차례 크기 변환에 따른 최대 5px 경계를 명시했다.
- 몽글의 감은 눈 위에 남던 기본 구슬 반사는 원래 구슬의 좁은 외곽을 채우는 마스크 보완으로 제거했다.
- 기본 본체·까몽·미사용 표정 등 대상 외 정본과 공용 파생 72개, 색인 항목 36개는 그대로임을 해시로 확인했다.
- 새 집중·졸림은 내장 ImageGen의 1254px 결과에서 렌즈만 4K 본체에 맞췄다. 네이티브 4K 생성으로 표기하지 않는다. 이전 정본은 `이전_*.png`로 남겼다.

```powershell
node tools/튜터표정정본.js --apply
node experiences/brand-opening/prepare-tutors.cjs
```

## 최종 검수와 결과 위치

[실제 화면 검수](../../../experiences/brand-opening/qa/mascot-expressions-20261011/final/README.md)는 **575/575 통과**했다. 마린 8개·몽글 9개 프로필 표정의 직접 자산 검사와, 선택·게임·생활·카페의 실제 반응을 구분해 기록했다. 648px·390px 선택 화면, 320×568 세로·844×390 가로 화면도 확인했다.

79개 반응 화면에서 양눈 타원 영역과 고정된 몸 하단의 RGB 차이가 모두 0이었다. 눈 타원 밖 사각 영역 모서리는 최대 18이므로 전체 이미지가 동일하다는 뜻은 아니다. 페이지 오류·자산 누락·외부 요청·서버 쓰기는 0이며, 격리 게스트 브라우저에서 검수하고 종료했다. 관련 Node 시험도 8/8 통과했다.

로컬 동결 빌드는 `.tmp/world-app-mascot-expressions-20261011/world`에 있다. 1,819개 파일·185,842,584바이트이며 누락·빌드 중 소스 변경·비공개 자료 혼입은 0, 재사용한 이전 빌드는 변경되지 않았다. 브라우저 검수 대상은 `127.0.0.1:4314`의 로컬 소스 서버다. 공개 배포와 공개 사이트 검수는 하지 않았다.
