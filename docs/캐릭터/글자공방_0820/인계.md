## 2. 이식할 것 — 실험사본에서 정본으로

### 형태 함수 (실험사본의 해당 def 그대로)
- `글자곡선표본(본문, 크기, 간격)` — 글리프 베지어를 균일 간격 땀 자리로. **어떤 한글이든 자수 경로 자동.**
- `유리글자(본문, 크기, 위치, 재질, 돌출, 베벨)` — 범용 오브제 글자(이름과 달리 재질 무관).
- `자수글자3` — 밤천(Ink) + 코랄 아플리케 + 손 지터 땀. **복셀 리메시(0.018) 필수**(아래 함정 ①).
- `레터프레스4` — 다린천 불리언 눌림 + 먹 상감(거칠기 0.85) + 천 수신 글자등.
- `라벨태그4` — 직조라벨 + 손 지터 테두리 + 코랄 3 진행 숫자 + 천 수신 글자등.
- `글자등(받는것들, 위치, 크기, 힘)` — 라이트 링킹 보조광(`light_linking.receiver_collection`).
- 조명 변주 `결광2`·`스침` (조명 분기부).

### 굽기 인자
- `등힘=` — 글자등 힘 덮어쓰기 (레터 90 · 라벨 80 이 채택값).

## 3. 함정 각주 — 재현으로 확인된 것들 (같은 구덩이 금지)

1. **텍스트 변환 메시에 바로 퍼 심기 금지** — 법선·밀도가 들쭉날쭉해 털이 제멋대로 뻗친다(2회 재현).
   복셀 리메시(0.018) 후 심는다. ⚠획이 가는 글자는 0.018 이 획을 뭉갤 수 있음 — 글자별 확인.
2. **불리언 커터에 베벨 금지** — 획 모서리 자기교차로 천이 통째로 사라진다(2회 재현).
3. **어두운 글자(먹·코랄 3·양모 실)에 글자등 직사 금지** — 바래서 죽는다. **천만 수신**으로 뒤집는다.
   규칙: 밝은 글자는 글자를, 어두운 글자는 바탕을 비춘다.
4. **조명을 옮겼으면 노출을 다시 계산한다** — 결광 키가 1.5배 가까워져 역제곱으로 2배 세게 때렸다
   (950@3.4 ≈ 2050@5.1). 분홍 씻김의 진범. 거리 보정값 = 650.
5. **스침광은 33°가 하한** — 14°는 코사인 소멸로 면이 꺼진다.
6. *(클라우드 이식 08-20 추가)* **`fonts.load` 는 없는 경로에도 예외 없이 «깨진 폰트»를 돌려준다** —
   ERROR 리포트만 남고 글리프는 시스템 대체 사슬로 빠진다(윈도 경로를 리눅스에서 그대로 시도한
   자리에서 재현). 후보 사슬은 `os.path.isfile` 로 실존을 먼저 재야 다음 칸으로 넘어간다.
7. *(클라우드 이식 08-20 추가)* **Noto CJK(CFF 계열)는 Blender 가 글리프를 1/3 스케일로 읽는다**
   (「가」 크기 1.0 실측 0.30 — ttc·추출 otf 동일). 클라우드 대역은 wqy-zenhei(0.73 · 정상)로 —
   대역판은 시안 급이고 정본 글리프 확정은 본가(맑은고딕 볼드)에서 굽는다.
