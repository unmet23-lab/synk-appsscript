# 까몽 네 표정의 눈 교정

2026-10-11. 사용자가 튜터 선택 화면의 웃는 표정과 반쯤 뜬 눈 후보의 희번뜩임을 지적해 **눈웃음을 스티치로 표현**하도록 수정했다. 같은 기준으로 민망의 반눈·흰 반사와 놀람의 과한 반사를 교정한다. 입·코·눈썹을 추가하지 않는다.

| 표정 | 눈의 표현 | 내장 ImageGen 생성 원본 |
|---|---|---|
| 눈웃음·으쓱 | 촘촘한 이끼색 실땀의 닫힌 ∩형 눈. 두 컷은 같은 눈을 공유하고 대사·몸짓으로 성격을 구분한다. | [까몽_스티치눈웃음_생성원본.png](까몽_스티치눈웃음_생성원본.png) |
| 민망 | 두 눈 모두 내려앉은 U형 이끼색 자수. 흰 반사·반쯤 뜬 눈을 남기지 않는다. | [까몽_스티치민망_생성원본.png](까몽_스티치민망_생성원본.png) |
| 놀람 | 균일하게 둥근 검정 동공과 이끼색 테두리. 반사는 작고 차분하게 남긴다. | [까몽_차분한놀람_생성원본.png](까몽_차분한놀람_생성원본.png) |

생성 원본 세 장은 모두 **1254×1254**다. 기존 4096×4096 본체에 생성한 눈만 합성하며 네이티브 4K 생성물로 표기하지 않는다. 합성 결과와 무손실 사용 크기 검수본은 이 폴더의 `까몽_{표정}_4K.png`·`까몽_{표정}_480.png`에 저장한다. `눈웃음`·`으쓱`의 출력 SHA256은 기존 스티치 판 `b688c1b1b90bb1205cbd619a377438f1f7da903d4a3a4862d646101eb1a0de57` 그대로다.

- 기본 본체는 유지한다. `tools/까몽웃음정본.js`가 네 표정 모두 원래 눈 중심의 좁은 타원 마스크에 눈만 맞추고, 나머지 RGBA를 남긴다. 새 코·미간·볼·몸·꼬리는 복사하지 않는다.
- [정본.json](정본.json)에 입력/출력 SHA256·눈 마스크·검증 결과와 `applied`를 기록한다. 네 합성본 모두 4K에서 마스크 밖 RGBA 변경 0·전체 알파 변경 0이다. 무손실 480px에서도 리샘플링 경계 3px를 제외한 밖 변경 0·알파 변경 0이다. 이 수치와 손실 압축된 앱 화면 검수는 구분한다.
- `--apply`로 `../정본_4K/까몽_{표정}.png` 네 파일과 공용 `화면_1024` 파생·판.json을 갱신했다. 교체 전 정본은 `이전_까몽_{표정}.png`로 보존했다. `정본.json`의 `applied:true`와 실제 정본 해시로 적용 결과를 확인한다.
- `prepare-tutors.cjs`로 WORLD 480px WebP·sources.json을 갱신했다. WORLD의 `기쁨`도 `눈웃음` 원본을 사용하므로 함께 갱신했다. 이미지 URL에 출력 해시를 붙여 새로고침 후 옛 얼굴이 캐시에 남지 않게 한다.
- 사용자가 거절한 두 번째·세 번째 반쯤 뜬 눈 시안의 생성 원본 두 장과 프로젝트 사본 두 장은 삭제했다. 현행 생성기·정본·앱은 해당 파일을 참조하지 않으며 **다시 후보로 사용하지 않는다**.
- 실제 WORLD 화면에서 기존 얼굴 마스크가 눈보다 아래·오른쪽에 있어 왼눈의 기본 구슬 반사가 비치는 문제도 확인했다. 선택 화면과 게임·생활·카페 공통 마스크를 튜터 파생의 실제 눈 위치(x 약 30/51%, y 31%)에 맞췄다. 새 자산의 눈 영역이 완전히 덮이므로 자수 위로 이전 눈이 섞이지 않는다.

## 생성 요청과 방식

세 원본 모두 내장 **ImageGen** 편집으로 만들었다. 승인된 `정본_4K/까몽_본체.png`를 기준으로 눈의 형태와 재질을 요청하고, 생성 결과에서 눈만 가져온다. 모델 세부 버전·품질 설정은 이 도구에서 선택하지 않았다.

민망·놀람의 실제 편집 프롬프트 전문은 [생성요청.json](생성요청.json)에 남겼다.

- **스티치 눈웃음 요청 요지:** 열린 눈을 닫힌 행복한 ∩형 자수 눈 두 개로 교체한다. 촘촘하고 연속적인 이끼색 실땀과 실 섬유를 살리고, 구슬·점·고무선·반눈·눈꺼풀 덩어리는 넣지 않는다.
- **민망 생성 프롬프트 요지:** 두 눈을 모두 내려앉은 U형 이끼색 자수로 표현한다. 한쪽만 열리거나 반쯤 뜬 눈, 흰 반사, 유리 구슬처럼 번쩍이는 부분을 없애고 부드러운 민망함을 남긴다. 결과는 `docs/캐릭터/표정교정_20261011/까몽_스티치민망_생성원본.png`에 저장했다.
- **놀람 생성 프롬프트 요지:** 두 눈의 검정 동공을 균일하게 둥글게 만들고 이끼색 테두리를 유지한다. 반사는 작고 차분하게 제한해 과하게 희번뜩이지 않는 놀람을 표현한다. 결과는 `docs/캐릭터/표정교정_20261011/까몽_차분한놀람_생성원본.png`에 저장했다.

공통 요청은 입·코·눈썹을 추가하지 않고 몸·털·자세·조명·투명도를 유지하는 것이다. 생성 과정에서 달라질 수 있는 눈 밖 영역은 위 합성 단계에서 원래 본체로 고정한다.

```powershell
node tools/까몽웃음정본.js --apply
node experiences/brand-opening/prepare-tutors.cjs
```

기존 스티치 눈웃음·으쓱 검증은 [기존 화면 검수](../../../experiences/brand-opening/qa/kkamong-stitch-20261011/)에 있다. 새 민망·놀람과 얼굴 마스크의 [최종 화면 검수](../../../experiences/brand-opening/qa/kkamong-expressions-20261011/README.md)는 선택 390/648px·게임·생활·카페·재연습에서 158/158 통과했다. 22개 반응 화면의 양쪽 눈이 같은 크기의 마스크 없는 원본 렌더와 RGB 차이 0이며, 오류·누락·외부 요청·서버 쓰기는 모두 0이다. 격리 게스트로 확인했고 1817파일 최종 로컬 빌드도 통과했다. 공유 의상 전체·형제 앱의 이미 배포된 사본·외부 공개 사이트는 이번 갱신 범위 밖이다.
