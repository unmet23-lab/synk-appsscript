# 교수 연구실 · 현재 원천

교수님의 안경 아래에 작은 펠트 콧수염을 더한 현재 장면이다. [정본.json](정본.json)이 선택한 `research.png`와 `research-blink.png`를 사용한다. 두 파일 모두 실제 1672×941이며 확대하거나 4K 생성이라고 표기하지 않는다.

내장 ImageGen으로 콧수염을 만든 뒤 동일 좌표의 좁은 영역만 원래 연구실에 반영했다. 안경·몸의 윤곽·방·조명·화폭을 유지한다. 눈감음 원천도 같은 콧수염을 쓰며, 앱에서는 안경 안 두 눈만 겹친다. 콧수염은 깜빡일 때 사라지지 않는다.

`입력/`의 원래 연구실·눈감음·콧수염 생성 그림은 재현 재료이며 현재 화면 원천으로 직접 선택하지 않는다. 실제 생성 요청·원래 생성 위치·입력 지문·합성 범위·현재 원천 지문을 정본에 기록한다.

재현은 SYNK-talk에서 `node tools/교수콧수염반영.js` 다음 `node tools/교수장면자산반입.js`. 후자는 현재 교수 원천과 현재 봉투 원천을 각각 읽으며 예전 임시 연구실이나 봉투로 되돌리지 않는다.
