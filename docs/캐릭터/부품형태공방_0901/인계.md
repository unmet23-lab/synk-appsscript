## 2. D(태그 세 겹)의 배선 — border-image 회귀를 지키며

- 🔴 **회귀 「구움표는 border-image 를 안 쓴다」는 유효하다**(08-16 실측: 9분할은 늘 각진 사각 —
  둥근 칩·카드에서 «글자 아래 어긋난 검은 사각»이 됐다. loom-page-propagation 그 자리).
- 다시 여는 조건이 곧 이 굽기다 — **세 겹 배경**: `background: url(왼) left/contain no-repeat,
  url(오른) right/contain no-repeat, url(가운데) center/auto 100% repeat-x`. 마구리가 라운드를
  «그림으로» 쥐므로 border-radius 를 CSS 가 흉내 낼 필요가 없다.
- 배선 자리 = `tools/lib/loom.js` `잔부품()`의 태그 + `구운재질.json` 에 세 키(태그_왼·태그_중·태그_오른).
- 검증 = 헤드리스 렌더 전/후 대조(회귀·린트는 액자 어긋남을 못 본다 — 08-16 그대로) + `--분모` 흉내 1→0.

### 2-b. 🔴 이음매를 «재봤다» — 기하를 맞춰도 0 이 아니다 (09-01 · 프로토타입 실측)

⚠ **이 절은 옆 세션이 세운 `태그왼·중·오른` 과 «다른 판»에서 잰 값이다**(같은 날 두 세션이 같은 일을
각자 지었고, 채택된 것은 그쪽이다 — 여기 남기는 것은 **그 판에도 그대로 걸리는 물리**다).
잰 것은 폭 2.40(=0.24×10)으로 크롭한 가운데 타일의 **왼끝 3px 열 ↔ 오른끝 3px 열**이다.

🔑 **기하를 맞추는 것으로는 «절반»만 닫힌다.** 창·거리·땀 격자를 공유해도 남는 것이 있다:
| 무엇 | 평균 \|Δ\| | 최대 |
|---|---|---|
| 격자를 0 에 맞췄을 때(첫 판) | 24.29/255 | 142 |
| **반 칸 민 뒤(현행)** | **21.92/255** | **102** |
| 검산 — 무관한 캡 끝과 대조 | 146.41/255 | — |

🔑 **남은 것은 «구조 어긋남»이 아니라 «밝기 기울기»다** — 같은 타일의 왼끝 162.07 ↔ 오른끝 147.99
(**좌우 차 14.07/255**). 키 라이트가 한쪽에서 오니 프레임을 가로질러 밝기가 눕는다. 반 칸 밀기가
최대치를 142→102 로 깎은 것은 이음매가 «실땀 위»에서 «맨 천 위»로 옮겨졌기 때문이고, 기울기 자체는 남는다.
▶ **배선할 때의 처방, 값싼 순서로**:
① **대개는 안 겹친다** — 칩 폭이 타일보다 짧으면 `repeat-x` 가 한 번도 안 반복되어 이음매가 아예 안 생긴다. 먼저 실제 칩 폭으로 확인한다.
② 반복이 필요하면 **거울 타일**(자산 단계에서 `[크롭 | 좌우 뒤집은 크롭]`으로 붙인다) — 양 끝이 같은 열이 되어 이음매가 **원리적으로** 사라진다.
   ⚠단 미러 타일은 넓은 면에서 반복 무늬가 드러난다(`loom-bake-lessons`) — 칩의 짧은 띠라 괜찮지만 넓은 면에 재사용하지 않는다.
③ 그래도 모자라면 **직교 카메라 + 대칭 필 라이트**로 원천을 고친다(전역 조명·카메라 규약을 건드리므로 마지막 수단).
🚫 「가운데를 늘려 쓰기」(`background-size:100% 100%`)는 **안 된다** — 천의 결이 늘어나 재질이 거짓말을 한다.

## 3. 물려받는 함정 (전부 실측 출신)

- 굽는 크기 = 쓰는 크기(«혹시 몰라» 키운 여유가 GPU 12분을 먹었다). 불릿 7px·링크점 3px 는
  **줄여도 실루엣이 사는가**가 판정 축 — 판정 지면에 128px·실크기 축소줄을 나란히 세운다.
- XY 평면에 짓고 «세운다»(XZ 로 지으면 결이 1차원 줄무늬 · 정면 카메라가 옆을 본다).
- `blender -b -P` 는 스크립트가 죽어도 exit 0 — **판이 디스크에 있는지**로 성패를 센다.
- 출력 경로는 언제나 절대 경로(상대는 드라이브 루트로 샌다).
- 대조판은 조건 하나만 바꾼다(둘 바꾸면 판정이 안 선다 — F045).
- 명품 렌더 4계: 대비는 재료가 · 가장 밝은 것은 하나 · 어둠을 두려워 않기 · 눈보다 계산.
