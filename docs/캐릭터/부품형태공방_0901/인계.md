> 설계 정본 `docs/Loom_엔진_설계.md` §3-4b D 가 남긴 자리 — *「렌더 값의 끝이 가깝다. 남은 최대
> 지렛대는 **형태 자체** — 지금 부품은 «구»다」*. 이 공방은 그 형태의 **판정 재료**를 굽는다.

## 0. 가르는 원칙 — 무엇을 굽고 무엇을 안 굽나

- **1축 = 공방화.** 유호 확정 08-19 「모든 디자인이 이 요소들로(양모공방)」 + 실물 증거: 체크·별·
  하트·도장·말풍선이 08-22 에 이미 레진 구슬 → **자수 아플리케**로 갈아탔다(요소사전 §3). 남은
  유리·레진 구슬 부품(불릿·번호 원판·링크점·태그)을 같은 방향으로 재해석한 후보를 굽는다.
- 🚫 **히어로수는 안 굽는다** — 요소사전 경계 「레진 = 1점 액센트 존속」이 확정이다. 지면당 1점의
  가장 무거운 자리는 레진이 맞다(빛을 «가둔다»가 뜻인 유일한 본문 부품).
- **현행도 나란히 세운다** — 유리 원판·레진 구슬을 지우는 판정이 아니라 **눈이 고르는** 판정이다.
  «정보 판 적재적소»(09-01 · DESIGN.md §2-d)와 같은 결: 은퇴가 아니라 자리 가르기일 수 있다.

## 1. 굽는 판 — 판마다 «조건 하나만» 다르다 (현행 ↔ 후보 · 같은 구도·조명·크기)

| 판 | 현행 | 후보 | 재료(전부 `tools/요소굽기.py` 에 실재) |
|---|---|---|---|
| **A 불릿** | 레진구_무채(7px 로 축소돼 쓰임) | ㉮ **매듭**(소형 — 실을 한 번 묶은 점) ㉯ **프렌치노트**(감아박기 자수 점) | `매듭()` 재활용 · ㉯는 `땀하나()` 변형(감은 실 3~4바퀴) |
| **B 절번호** | 유리 원판 + CSS counter 숫자 | ㉮ **4구 단추 + 자수 숫자** ㉯ **직조 라벨 + 숫자** | `단추토글()`의 단추 몸 재활용 + 자수 숫자(뱃지 1·3·12 규정 확장) · `직조라벨()` |
| **C 링크점** | 유리구(3px 코랄) | **코랄 땀 하나**(러닝 스티치 한 땀) | `땀하나()` |
| **D 태그** | 칩 CSS 흉내(분모의 유일한 흉내 1) | **직조 라벨 «세 겹»** — 왼 마구리 · 가운데(가로 타일) · 오른 마구리를 **따로** 굽는다 | `직조라벨()` 3분할 — §2 참조 |

⚠ **D 는 형태 판정이 아니라 §2-업 ③(전파 마감)의 실행분**이다 — 같은 밤에 굽는 것이 효율일 뿐,
A~C 가 유호님 판정 대기로 남아도 D 는 배선까지 간다.

## 2. D(태그 세 겹)의 배선 — border-image 회귀를 지키며

- 🔴 **회귀 「구움표는 border-image 를 안 쓴다」는 유효하다**(08-16 실측: 9분할은 늘 각진 사각 —
  둥근 칩·카드에서 «글자 아래 어긋난 검은 사각»이 됐다. loom-page-propagation 그 자리).
- 다시 여는 조건이 곧 이 굽기다 — **세 겹 배경**: `background: url(왼) left/contain no-repeat,
  url(오른) right/contain no-repeat, url(가운데) center/auto 100% repeat-x`. 마구리가 라운드를
  «그림으로» 쥐므로 border-radius 를 CSS 가 흉내 낼 필요가 없다.
- 배선 자리 = `tools/lib/loom.js` `잔부품()`의 태그 + `구운재질.json` 에 세 키(태그_왼·태그_중·태그_오른).
- 검증 = 헤드리스 렌더 전/후 대조(회귀·린트는 액자 어긋남을 못 본다 — 08-16 그대로) + `--분모` 흉내 1→0.

## 3. 물려받는 함정 (전부 실측 출신)

- 굽는 크기 = 쓰는 크기(«혹시 몰라» 키운 여유가 GPU 12분을 먹었다). 불릿 7px·링크점 3px 는
  **줄여도 실루엣이 사는가**가 판정 축 — 판정 지면에 128px·실크기 축소줄을 나란히 세운다.
- XY 평면에 짓고 «세운다»(XZ 로 지으면 결이 1차원 줄무늬 · 정면 카메라가 옆을 본다).
- `blender -b -P` 는 스크립트가 죽어도 exit 0 — **판이 디스크에 있는지**로 성패를 센다.
- 출력 경로는 언제나 절대 경로(상대는 드라이브 루트로 샌다).
- 대조판은 조건 하나만 바꾼다(둘 바꾸면 판정이 안 선다 — F045).
- 명품 렌더 4계: 대비는 재료가 · 가장 밝은 것은 하나 · 어둠을 두려워 않기 · 눈보다 계산.
