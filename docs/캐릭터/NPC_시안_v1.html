SYNK NPC 시안 v1 — 현실층 사람들

미니게임 4모듈의 상대역 — 유호님 확정 「새 NPC 계열 신설」(08-10)의 ㉮ 판정 재료다. 로스터 3역(교수님·사장님·심사관)과 상태 3단(평온→기울어짐→돌아섬)은 게임층 설계 §4의 확정 규격이고, 이 페이지가 유호님께 여쭙는 것은 시각 수위 · 이름 체계 · 성격 가안 세 축이다. 전부 SVG — 킷 밖 색 0.

00 · 매인 정본 — 이 시안이 안 정하는 것

정본 = 미니게임_게임층_설계.md §4(로스터 3역+⏳1 · 상태 3단 · 현실층 경계) · 발주서 §6-5 #3(이름·일러스트 확정 = 유호님 브랜드 몫). 여기 그린 것은 전부 후보다 — 채택·수정·전부 기각 다 열려 있다. 기각된 안은 다시 안 그렸다: 몬스터 재사용(폐기) · 실루엣 NPC(안 고르심).

01 · 시각 수위 3후보 — 같은 교수님을 세 온도로

학생 캐릭터(코랄 유리 유령)와 어떻게 갈리는가가 이 축의 본질이다. 세 후보 모두 공통: 몸에 코랄 0(녹음 신호 보호 — G3는 녹음 화면이다) · 부유하지 않고 땅에 선다(유령=부유·환상층 / NPC=접지·현실층 — 모션이 세계관 경계를 진다) · 질감은 유리가 아니라 종이(크루 도시에 킷의 서류 세계 — 4모듈이 전부 격식·서류 상황이라 서사가 맞물린다).

수위 A 「몽글 이웃」1.5-HEAD · BLUSH 점눈+볼터치 — 학생 문법 그대로
수위 B 「종이 이웃」 ★권고2-HEAD · NO BLUSH 점눈은 공유 · 볼터치 없음 · 복장이 어른을 말한다
수위 C 「잉크 초상」LINE EYES · FORMAL 선눈·절제 — 격식 최대
후보얻는 것대가
A세계가 한 결로 귀엽다학생 주인공 문법(볼터치·등신)과 층이 안 갈린다 — §4 규격 2의 경계가 흐려지고, 기울어짐·돌아섬 연출이 귀여워서 압박이 안 읽힌다
B ★귀엽되 어른으로 읽힌다 · 자세 3단이 잘 읽힌다 · 점눈 하나로 앱 전체가 이어진다중간값이라 첫눈의 개성은 A·C보다 약하다 — 개성은 역별 소품(책·앞치마·도장)이 진다
C압박·격식이 가장 진짜같다벌 없는 세계(실패음 없음·리프레이밍)와 온도가 어긋날 위험 — 무섭게 읽히면 「마음을 얻는 게임」이 「검사받는 게임」이 된다

02 · 로스터 3역 — 권고 수위(B)로 그리면

역할은 §4 규격 5 확정분: G1 교수님 · G3 사장님 · G4 심사관. 얼굴 문법은 같고(점눈·종이 피부) 정체성은 소품이 진다 — 안경과 책 · 앞치마와 어깨 수건 · 사원증과 도장. 진화·포인트 요소 0 · 앱에서는 기존 몬스터 액자 프레임에 담긴다(새 프레임 없음).

교수님G1 · 격식 메일 안경 · 희끗한 옆머리 · 책 — 원칙은 단단하고 회복은 빠르다
사장님G3 · 알바 변명 앞치마 · 어깨 수건 · 콧수염 — 무뚝뚝하지만 진심에 약하다
심사관G4 · 서류 관문 올림머리 · 사원증 · 도장 — 감정이 아니라 절차
(참고) 상급자G2 · ㉯ⓐ를 고르실 경우 넥타이 · 태블릿 — ㉯ⓑ(교수님 공유)면 이 자리는 없다

03 · 상태 3단 — 평온 → 기울어짐 → 돌아섬 (사장님 시연)

§4 규격 3 확정: 계열 공통 3단이고 숫자·퍼센트는 어디에도 없다(모호함이 설계다). 입력 중 실시간 전환은 G3뿐 — G1·G4의 표정은 판 시작·판정 화면 같은 상태 전이 자리에서만 바뀐다.

① 평온CALM 정면 · 온화 — 기본값은 늘 열린 문
② 기울어짐LEANING 팔짱 · 손목시계 흘긋 · 몸이 7° 기운다
③ 돌아섬TURNED 뒤태 — 단 고개는 반쯤. 문은 아직 안 닫혔다
  • 돌아섬에도 귀가 이쪽을 향한다 — 완전한 등이 아니라 고개 9°. 「설득할 수 있는 상대」라는 게임 약속(§4 규격 1)을 실루엣이 지킨다.
  • ②의 손목시계는 바늘만 있고 숫자가 없다 — 시계 보기(원안 문구)는 살리고 숫자 금지는 지킨다.
  • ①→② 전환 모션은 구현 몫(emil 원칙 — 빈도 높음·목적=경고이므로 짧고 절제). 이 페이지는 상태의 정지 규격만 정한다.

04 · 이름 체계 후보 3

후보모양판단 재료
㉠ 직함만 ★권고교수님 · 사장님 · 심사관님한국에선 직함으로 부르는 것 자체가 규범이라 호칭 학습이 곧 실사용(철학 게이트 ①) · 콘텐츠 문항 속 인물명과 충돌 0 · 몽골어 검수 부담 최소
㉡ 성+직함김 교수님 · 박 사장님현실감은 오르나, 문항 콘텐츠(콘텐츠 팩 발주 몫)가 다른 성을 쓰는 날 세계가 갈라진다 — 정하면 콘텐츠 발주에 성씨 고정을 같이 실어야 한다
㉢ 별칭 세계관형예: 「도장 선생」재미는 있으나 현실층 원칙(개인 서사 없음 · §4 규격 2)과 긴장하고, 실생활에서 쓸 호칭과 어긋난다

05 · 성격 가안 — 1줄씩 (전부 [제안])

  • 교수님 — 원칙은 단단하고 회복은 빠르다. 멘탈 게이지(필수 5칸)가 채워질 때마다 표정이 눈에 띄게 풀린다 — 게이지의 사람판.
  • 사장님 — 바쁘고 무뚝뚝하지만 솔직함에 약하다. 변명보다 진심이 담긴 사과에 몸이 다시 이쪽으로 돈다.
  • 심사관 — 감정이 아니라 절차. 3역 중 유일하게 표정 변화가 거의 없다(압박은 창구 대기줄 게이지가 진다) — 그래서 통과 도장의 미소 한 번이 가장 크게 읽힌다.
  • ⚠ 대사는 이 시안 밖이다 — prompt_seed 템플릿(LLM 호출 0 · 발주서 §6-6 ③)이고, 학생 접점 문구라 한·몽 병기 = 몽골어 검수 선행(착수 조건 §7).

06 · 이 시안이 지킨 경계 (전부 정본 승계)

  • 몸에 코랄 0 — 코랄은 녹음 버튼 전용 신호(G3 화면 보호). 라임도 0 — 성장·획득 색은 학생 것이라 NPC 카드에 싣지 않는다.
  • 부유 없음 · 그림자 접지 — 학생 유령(부유·유리)과 층이 모션에서 갈린다. 숨쉬기만 4.4s(유령 3.6s보다 느리게 — 어른의 호흡).
  • 상태에 숫자·퍼센트 0 · 진화·포인트 요소 0 · 개인 서사 0(성격 1줄은 반응 규칙이지 성장 서사가 아니다).
  • 실루엣 아님(얼굴 있음) · 몬스터 재사용 아님 · 프레임은 기존 액자 재사용 전제.
  • 킷 밖 색 0 — Paper·Cream 3형·Navy 3형·Slate·Wash(A 볼터치뿐)만. prefers-reduced-motion 전부 정지.
