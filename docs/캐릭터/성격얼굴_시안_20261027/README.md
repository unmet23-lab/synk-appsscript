# 까몽 · 마린 성격 얼굴 시안 (2026-10-27)

유호님 「셋 정본이 뭔가 다 너무 착해 보이는데 이게 최선일까? 마린이나 까몽이는 완전 장난꾸러기나 말괄량이로 보이게 … 마린 눈이 ㅡㅡ나 무서운(무섭지만 귀여운) 표정 … 냉정하게 말해 줘」 → Claude: 셋이 같은 결이면 부딪칠 게 없어 약점이 맞다, 몽글은 다정한 중심으로 두고 까몽은 장난꾸러기(송곳니는 시안으로), 마린은 시큰둥 · 무심, 무서운 얼굴은 기본이 아니라 표정 한 장으로, 성격 한 줄 → 시안 → 낯선 사람 시험 순서 → 유호님 「몽글이는 냅두고 까몽이랑 마린은 니가 말한 대로 가자」(10-27, [결정](../../_ops/결정.md)).

## 성격은 이미 정본에 있다

[가이드 정본](../가이드_정본.md) §2-2: 까몽은 「용은 멋있어야 한다 — 그런데 불이 안 나온다」(허세쟁이 겁쟁이, 「이 몸」 · 「훗」), 마린은 「세어 두면 잃지 않는다」(보고체, 감탄사 · 느낌표 0, 표정 대신 렌즈가 어휘 — §10). 시안은 새 성격을 지어내지 않고 이 성격의 얼굴을 찾았다 — 까몽은 「훗, 이 몸은」 허세, 마린은 「흠. 확인.」 무심.

## 낯선 사람 시험 (10-27)

맥락 없는 새 에이전트에게 여덟 장을 이름 없이 섞어 보이고, 얼굴에서 읽히는 성격 · 10살 학습자가 공부 친구로 다가가고 싶은 정도(1~5) · 걸리는 점을 물었다.

| 시안 | 읽힌 성격 | 다가가고 싶음 | 걸리는 점 |
|---|---|---|---|
| 까몽 기본 | 순하고 놀란 듯 귀여움 | 5 | 없음 |
| K1 훗 | 시큰둥 · 의심 | 2 | 「나를 못마땅해하는 공부 친구」 |
| K2 훗 + 송곳니 | 비웃는 · 건방진 | 1 | 악당 · 흡혈박쥐로 읽힘, 여덟 장 중 유일하게 「못돼 보임」 |
| K3 꾀 + 송곳니 | 놀리는 장난꾸러기 | 2 | 비꼬는 듯, 「나만 아는 게 있지」 |
| 마린 기본 | 호기심 · 무던함 | 4 | 헬멧이 조금 가면 같음 |
| M1 반눈 | 졸림 · 지루함 · 무심 | 3 | 감정이 잘 안 읽힘 |
| M2 가는 눈 | 잠듦 · 명상 | 3 | 반응 없어 보일 수 있음 |
| M3 한쪽 반눈 | 엉뚱 · 애매 | 3 | 윙크인지 비꼼인지 헷갈림 |

- 의도한 성격은 읽힌다(K1 · K3 허세 · 장난, M1 무심). 대신 **기본 얼굴로 쓰면 다가가고 싶음이 까몽 5 → 1~2, 마린 4 → 3으로 떨어진다.** 송곳니 + 반눈(K2)은 못돼 보인다.
- 가장 기억에 남는 것은 마린(어두운 헬멧 속 큰 노란 눈의 실루엣). 까몽 기본은 「귀엽지만 흔한 인형」으로 읽혔다.
- 한 에이전트의 한 번 시험이라 사람 대상 시험만큼 단단하지는 않다.

## 고르시기

유호님 차례 — [트랙 §1](../../_ops/트랙.md). Claude 추천은 기본 얼굴은 지금처럼 다정하게 두고, 성격 얼굴(까몽 K3에서 송곳니 뺀 꾀 · K1 훗, 마린 M1 반눈)을 **표정 세트의 대표 표정**으로 더해 쉬는 때 · 혼잣말 · 짧은 영상에서 자주 쓰는 것.
