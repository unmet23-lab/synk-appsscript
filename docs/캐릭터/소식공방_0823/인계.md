# 소식 공방 인계 — 「소식」 탭 v1 시안 (2026-08-23 · ⏳유호님 판정 대기)

> 트랙 §2-A 「소식 탭 ⛔ 미착수」의 집행이다. 유호 지시 08-23 「소식 탭 이어서 하자」.
> **학생 탭 셋의 마지막**이다 — 조합판(퀴즈)·성장판(나의 성장)·오늘판에 이은 네 번째 화면.
> 렌더 = `소식판_v1.png`(본문 얹은 판) · `소식판_v1_그릇만.png`(굽기 원판) · 칸 좌표 = `*.png.칸.json`
> 세 탭 나란히 = `탭셋_나란히.png`
> 굽기 — ⚠**출력은 절대 경로로 준다**(§3-1):
> `blender -b -P tools/요소굽기.py -- 형태=소식판 비율=1.9 샘플=128 너비=1080 장치=GPU 출력=<절대경로>`
> 글자 = `python 소식덧씌움.py 소식판_v1_그릇만 [없음|층별|전면]`

## 1. 무엇을 굽고 무엇을 안 굽나

**세 탭의 시제가 갈린다.** 이것이 이 화면을 지은 유일한 잣대다 —
성장판은 «어디까지 왔나»(과거의 누적), 오늘판은 «오늘 무엇을 하나»(현재의 할 일),
소식판은 **«밖에서 나에게 온 것»**(도착물). 셋이 겹치면 탭이 셋일 까닭이 없어진다.
⇒ 여기엔 내가 «할» 것을 두지 않고 **남이 «준» 것만** 둔다.

| 자리 | 부품 | 근거 |
|---|---|---|
| 상단 | **새 첨삭 카드** — 가장 값진 도착물 | 학2(AI 첨삭). 오늘공방 인계가 이 자리를 미리 지목했다(「첨삭 도착(학2)은 소식 탭 몫」) |
| 카드 안 | **코랄 실** 한 도막 — 화면의 유일한 신호 | 오늘판·성장판과 같은 예산(하나) |
| 목록 | **소식 넷** | 우리 반(학24→N19 학생 뷰) · 원장 공지(부6) · 선생님 칭찬 = 오늘의 성장(학19) · 명예의 전당(학32 「전당 노출은 talk 소식 탭으로」) |
| 각 줄 왼쪽 | **꿰맨 단추의 켬/끔** — 읽었으면 X, 안 읽었으면 빈 구멍 | 단추토글(유호 픽 08-19) |
| 각 줄 오른쪽 | **날짜** — 이 화면에만 있는 열 | 소식이 소식인 까닭의 절반이 «언제 왔나»다 |
| 바닥 | **탭바** — 지금 탭이 «소식»이라 밑줄이 **셋째** 칸 | 전수분석 §1 「탭 3개」 |

**새 부품이 0개다** — 네 화면째 그렇다. 꿰맴의 «뜻»도 안 바꿨다: 오늘 탭에서 「했다」였고
여기서는 「읽었다」인데 둘 다 «처리됐다»의 한 뜻이라 학생이 규칙을 새로 익히지 않는다.

🔑 **오늘 탭과 이 화면을 실제로 가르는 것은 날짜 열인데, 그것을 굽지 않았다.**
   부품이 아니라 «본문»이라 PIL 층이 붙인다. 이 세계가 싸게 넓어지는 방식이 그것이다.
🔑 **새 것이 위에 쌓인다** — 안 읽은 둘이 위, 읽은 둘이 아래. 목록의 자연 규칙이라 설명이 필요 없다.
   상태를 글로 또 쓰지 않는다(「안 읽음」 금지): 빈 단추가 이미 그 말을 하고, 글은 **밝기**로만 거든다
   (안 읽음 = Oat·굵게 / 읽음 = Stone·보통).

## 2. 채택값

| 자리 | 값 |
|---|---|
| 첨삭 카드 | 반크기 `1.21 × 0.09 × 0.70` · z `1.32` · 크리스 0.80 · 레벨 4 — **오늘판 도전 카드와 완전히 같다** |
| 코랄 실 | x `−0.89 … +0.01`(왼쪽 정렬) · z `카드z − 0.48` · 깊이 0.40 · 7땀 — 오늘판과 같다 |
| 소식 줄 | 반크기 `1.21 × 0.08 × 0.19` · z `0.06 / −0.42 / −0.90 / **−1.38**` · 크리스 0.66 |
| 줄 단추 | r `0.085`(오늘판·게이지와 같다) · 깊이 `0.405` · 꿰맴 = (✗ ✗ ✓ ✓) |
| 탭바 | 성장판·오늘판과 **완전히 같다** · 밑줄만 **셋째 칸**(x +0.78)으로 |
| 배경천·조명·카메라 | 조합판 v1 그대로 — 네 화면이 한 세계로 읽히려면 여기가 안 갈려야 한다 |

본문(`소식덧씌움.py`): 카드 안여백 `124`(앞 두 화면과 같은 선) · 큰 줄 56px 행간 `84` ·
시작 줄은 **코랄 밑줄 76px 위** · 소식 줄 이름 40px · **날짜 28px 오른쪽 정렬**
(오른쪽 여백 = 왼쪽 단추까지의 거리와 같은 선 — 좌우가 같은 숨).

**대비 실측: 18블록 전부 AAA**(9.47 ~ 17.92 : 1).

## 3. 함정 각주 — 이 화면에서 실제로 밟은 것들

1. 🔴 **블렌더는 상대 출력 경로를 «드라이브 루트»로 해석한다.**
   `출력=docs/캐릭터/…` 로 주었더니 렌더가 **`C:\docs\캐릭터\…`** 에 떨어졌다(실측 08-23).
   더 고약한 것은 **칸 JSON 은 제자리에 생긴다**는 점이다 — 파이썬 `open()` 은 cwd 기준이라
   맞게 가고 렌더만 엉뚱한 데로 간다. 그래서 「JSON 은 있는데 PNG 가 없다」로 나타난다.
   ⇒ **출력은 언제나 절대 경로로 준다.** (곁들여 `C:\docs\` 에 옛 굽기가 쌓여 있어 같이 치웠다 —
     플레이팅_0821 두 장도 거기 있었다. 이 함정은 처음이 아니었다는 뜻이다.)
2. ⚠**또 없는 것을 봤다 — 이 공방에서 두 번째다.**
   렌더를 보고 「상단에 탭 글자가 한 벌 더 찍혔다」고 판단했는데, 상단 150px 을 재니
   **최대 밝기 17/255 · 110 넘는 화소 0개**였다(그릇판·본문판 둘 다). 오늘 탭 1판에서
   **똑같은 착시**를 겪고 각주까지 적어 뒀는데 그대로 반복했다.
   ⇒ 명품 4계 ④(눈보다 계산을 먼저 의심한다)는 «알고 있는 것»으로는 안 지켜진다.
     **어두운 판에서 무언가 보이면 재는 것을 절차로 박는다.**
3. **줄이 넷이라 세로 예산이 오늘판(셋)과 다르다.** 줄 반높 0.19 · 간격 0.48 →
   넷째 줄 z `−1.38` · 아래끝 `−1.57`. 탭바 윗면이 `−1.80` 이므로 남는 숨은 `0.23` —
   줄 사이 빈틈(0.10)의 2.3배라 «목록 아래 여백»으로 읽힌다.
   🔑 소식은 «쌓이는» 것이라 목록이 긴 게 정체다 — **줄 수가 탭의 성격을 그린다.**

## 4. 안 한 것 · 판정 대기

- **문안은 표본이다.** 「어제 쓴 3문장에 / 선생님 첨삭이 왔어요」·소식 넷의 제목·날짜 문구는
  실데이터 배선 전이다. 브랜드 보이스 검수(`synk-brand`)와 몽골어 검수는 아직 — 키릴 줄은 **검수 전 표본**.
- **날짜 표기 규칙 미정** — 지금은 「오늘 / 어제 / 3일 전 / 지난주」 상대 표기다. 절대 날짜로 갈지,
  며칠부터 절대로 바꿀지는 실데이터 배선 때 정한다.
- **읽지 않은 것의 개수(배지)를 탭바에 안 붙였다** — 새 부품이 되고, 이 화면의 코랄 예산이
  이미 카드에 있다(4계 ②). 유호님이 원하시면 코랄 단추 한 점으로 낸다.
- **상태(누름·읽음 전환 애니메이션)는 안 그렸다** — HTML/Expo 층 몫이다.
- **본문 층이 1080px 절대값에 묶여 있다** — 앞 세 화면과 같은 기술 부채다(트랙 §6).
- 📌 **오늘 탭의 하단 여백이 나란히 놓으니 더 두드러진다.** 소식 탭은 줄 넷으로 바닥까지 찼는데
  오늘 탭은 할일2 아래 259px 이 비었다(⏳유호 판정 중인 그 자리). 판정 재료가 하나 늘었다 —
  나란히 보시고 정하시면 된다(`탭셋_나란히.png`).
