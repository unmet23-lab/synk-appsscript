# 의상 제작 — GPT Image 2.5만 사용

2026-09-09 유호 확정: 현재 마음에 드는 의상 입히기 방식을 유지하며 앞으로 의상은 **GPT Image 2.5만 사용한다. GPT Image 2.0은 사용하지 않는다.** 2.5를 쓸 수 없으면 다른 모델로 대체하지 않고 해당 생성을 멈춘다.

## 모델과 실행 범위

- 기본 실행 ID: **`gpt-image-2.5-sunburst`**. 사용자 선택인 2.5 계열 안에서, 원본 보존이 중요한 의상 편집에 맞춰 Sunburst를 지정했다. [OpenAI 모델 문서](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst), [이미지 편집 안내](https://developers.openai.com/api/docs/guides/image-generation)를 09-09 실제 열어 확인했다.
- 의상 단품·입힌 모습·조합·시안을 새로 생성할 때 적용한다. 모델을 고를 수 없는 통로는 2.5라고 추정하지 않는다. 2.5 사용을 확인할 수 있는 통로에서만 진행한다.
- 기존 도구 [옷GPT굽기.js](../../tools/옷GPT굽기.js)의 요청 모델을 고정했다. `--설정`은 모델만 조회하며 자격증명·생성·파일 가공에 닿지 않는다. 2.0 지정은 거절하고 오류 시 대체 모델 호출은 없다.
- 2.5는 모델 버전이다. 2.5K(2560픽셀)라는 이미지 크기와 구분한다. 기존 도구에 적혀 있던 `gpt-image-2`를 근거로 사용자의 ‘2.5’를 해상도로 단정했던 설명은 정정한다.
- **이미 만족한 의상은 그대로 보존한다.** 이번 결정이 기존 파일을 전부 다시 굽거나 4K 몸 정본을 교체하라는 요청은 아니다. 과거 결과의 생성 모델 이름을 소급해 2.5로 고치지 않는다.

## 그대로 유지할 입히는 방식

1. 몸은 [마스코트 자산 통로](../../tools/lib/마스코트자산.js)가 가리키는 승인 4K 정본에서 가져온다. 기존 몸의 얼굴·눈·실루엣·털·자세는 바꾸지 않는다.
2. 몸 참조와 입힐 옷 참조를 함께 준다. 옷의 모양·색·펠트 결·바느질을 유지하면서 몸 곡면을 따라 감기고, 닿는 곳의 털 눌림·접촉 그림자·같은 조명이 보이도록 한다. 참조용 흰 바탕은 작업 입력이지 브랜드 지면의 배경 규칙 변경이 아니다.
3. 옷 한 조합의 기준 그림을 만든 뒤 표정마다 몸과 옷을 다시 생성하지 않는다. [옷표정얹기.py](../../tools/옷표정얹기.py)로 정본의 눈 영역을 정렬해 바꾸고 옷·안경 테·왕관 등은 보존한다.
4. 표정 검사 → 배경 제거 → 기존 4K 틀 맞춤 → AVIF 사용본의 후처리 흐름을 유지한다. **4K 틀에 배치한 것을 4K로 새로 생성한 원본이라고 부르지 않는다.** [기존 후처리 안내](../_ops/인계_옷조합_GPT정액.md)를 참고한다.
5. 새 결과는 지금 승인한 의상과 실제 사용할 크기로 비교한다. 착용감·원본의 얼굴과 비율·표정 전환·의상 경계·잘림을 확인한다. ‘모델이 2.5다’만으로 완성 판정을 하지 않는다. 구체 치수는 [마스코트 치수 정본](마스코트_치수_정본_v1.md), 품질은 [명품 기준](../명품_기준_v1.md)을 따른다.

## 원본·비용·기존 결정

4K 마스코트 정본과 의상이 아닌 자산의 기존 제작 방침은 바꾸지 않는다. CPU 3D 시험 후보는 의상 제작의 입력이나 새 몸 정본으로 쓰지 않는다. 기존 몽글·마린 의상을 즉시 전량 재생성하지 않는 09-08 결정도 유지하며, 이후 새 의상 생성은 이 모델 규칙을 따른다.

구독 포함 경로와 종량제 API는 별개다. 모델 고정은 신규 결제·API 지출·대량 생성을 승인하는 것이 아니다. 기존 허용 범위와 비용 조건을 지키되, 구독 경로에서 정확한 2.5 사용을 확인하지 못하면 2.0이나 미확인 모델로 대신 굽지 않는다. 기존 장당 비용은 구버전 실측이므로 2.5 비용으로 재사용하지 않는다. 도구의 사용량 기반 요율 참고값도 실제 청구액과 구분한다.

기존 크기 2560×2560와 참조·지시문을 유지했다. 공식 안내는 2560×1440 초과 해상도를 실험적 지원으로 표시하므로, 다음 실제 생성에서 결과를 확인한다. 2.5 계정 접근·실제 생성 품질·장당 비용은 이번 설정 변경만으로 검증되었다고 말하지 않는다.

## 이번 반영의 확인

설정·실제 전송 폼·2.0 거절·2.5 오류 시 대체 호출 없음·읽기 전용 목록을 모의 API로 검사했다. 새 시험 5개와 기존 옷 경로 시험 7개, 합계 **12개 통과**. 구문 검사와 로컬 문서 링크 6개도 통과했다. 새 이미지 생성·유료 API 요청·앱 배포는 이번에 수행하지 않았다. 확인 명령은 다음과 같다.

별도 검토자가 코드·시험·이 문서와 공식 모델 문서를 대조하고 같은 12개 시험을 재실행했다. 수정이 필요한 실제 문제는 발견하지 않았으며, 계정 접근·실제 생성 품질·비용은 미검증으로 남겼다.

```powershell
node tools/옷GPT굽기.js --설정
node --test tests/옷모델고정.test.js tests/옷경로.test.js
```

## 라디오 후속 검수 — 09-09

의상 재고와 모든 표정·동작의 자연스러움은 따로 확인한다. [세 캐릭터 검수 결과](../_ops/의상라디오검수_20260909/검수보고.md)와 [직접 조작 화면](../_ops/의상라디오검수_20260909/검수보기.html)에 확인 범위·수정·남은 결함을 모았다.

- 기존 까몽 129차림에서 라디오용 8표정씩을 별도 1024 WebP 검수후보로 파생했다. 원본 4K·승인 의상은 교체하지 않는다.
- 반투명 털에 알파를 두 번 곱하던 틀 맞춤 계산을 수정했다. 초록 새싹을 눈으로 취급하던 표정 보호도 수정하며, 기존 눈·몸을 보존한 국소 후보로 대조한다.
- 몽글·마린은 옷 조각이 있지만 의상1+악세1 통합 표정 세트가 없고 얼굴 가림·원본 잘림도 확인됐다. 기존 조각 전체를 완성 착용품으로 승인하지 않는다.
- 후보는 실제 방송 채택이 아니다. 표정 파일·겹침·동작·사용 크기·송출 화질을 구분해 통과시킨다. 새 생성이 필요하면 위의 GPT Image 2.5 전용·비용 조건을 그대로 적용한다.
