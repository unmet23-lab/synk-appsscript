## ⚠ `재염색_본체.png` 알파 수리 (2026-08-19)

누끼가 **구슬 눈의 하이라이트를 배경으로 오인해 뚫었다.** 몸 «안»에 투명 구멍
**114px**(x398~600 · y403~413 = 좌·우 하이라이트 정중앙). 자수 눈 2컷은 구슬이 없어 0px.

라이트 지면(Paper #FAFAF9)에서는 흰 하이라이트 자리에 흰 바탕이 비쳐 **안 보인다.**
어두운 지면에 얹으면 그 자리가 뚫려 눈이 곰보로 보인다 — 그래서 여태 아무도 못 봤다.
⇒ 이웃 하이라이트 픽셀의 중앙값으로 메웠다(구멍이 하이라이트 «안»이라 주변이 곧 정답).
검산: 바깥에서 flood fill 해 「몸 안 구멍」 재측정 = **0px**.

## 🔧 `재염색_놀람.png` — 합성물이다 (원본 렌더 아님)

유호 지시 08-19 「펠트코랄 표정의 놀람, 비니를 구현해볼래?」에 대한 **후보**다.

- **만든 법**: `재염색_본체.png` 의 **자기 구슬을 1.35배로 키워** 같은 자리에 다시 얹었다
  (중심 좌 (415,423)·우 (609,423) · 위로 6px). 그림을 «그리지» 않았다 —
  하이라이트·접지 그림자·구슬을 넘어오는 펠트 올이 전부 원본 픽셀이라 재질이 안 갈린다.
- **왜 키우기인가**: 이 세트의 표정 어휘는 둘이다 — 구슬(기본)과 자수(눈감음·눈웃음).
  놀람을 자수로 그리면 «내가 그린 실»이 되고, 구슬을 키우면 원본 물성이 그대로 산다.
- ⚠ **합성이라 유호님 판정 전까지 «정본»이 아니다.** 진짜 렌더가 오면 이 파일을 갈아끼운다.

## 🚫 비니는 여기 없다

정본 펠트코랄 세트에 비니(니트 모자) 컷이 없다. 만들 수 있는 길은 셋인데 이 환경에선 다 막혔다:
1. **새로 굽기** — `tools/재질굽기.js`(Gemini). 키가 `GEMINI_KEY_PATH`(윈도 경로)라 클라우드에 없다.
2. **구판에서 모자만 오려 얹기** — 그 모자는 퇴역한 체리 세트 픽셀이고(유호 확정 08-19 「아예 안 쓴다」),
   채도로 갈라지지 않아(모자 0.33~0.53 vs 몸통 0.50~0.68) 자동 분리도 안 된다.
3. **손으로 그리기** — 니트 리브·방울을 지어내는 것이라 「펠트 정본」이 아니게 된다.
⇒ **안 만들었다.** 유호님 기계에서 ①로 굽는 것이 정답이다.
