## 고르시면

1. 고른 판을 새 까몽 정본으로 올리고(정면 · 좌34부터, 기존 4K 정본은 보관), 결정 표에 한 행.
2. 그 그림으로 WORLD 집 3D 까몽을 몽글처럼 펠트 재질로 다시 만든다(털 겹 대신 펠트 결 · 짧은 보풀 · 크림 홈질).
3. 표정 · 각도 세트는 그다음.
