# 까몽 펠트 정본 후보 (2026-10-27)

유호님 「몽글이랑 마린은 표현이 귀엽게 잘 됐는데 까몽이가 문제네. 어떻게 하면 좋을까? 아예 정본을 바꿔 버릴까?」 → Claude 추천: 생김새는 그대로 두고 **재질만 몽글 · 마린과 같은 니들펠트로** 바꾼 정본을 만든다(까몽 정본은 셋 가운데 혼자 긴 솜털을 사진처럼 그린 그림이라, 실시간 3D로 옮기기 가장 어렵고 펠트 마을에서도 혼자 다른 재료다) → 유호님 「2번을 한번 해보자」. 고른 판과 그 뒤에 바꾼 꼬리 · 날개는 맨 아래 「채택」.

## 만든 법

GPT 이미지 2.5(굽기 계정 bake2), 판마다 한 번. 참고: ① 지금 까몽 정본 정면(흰 바탕 1024) ② 몽글 정본 ③ 마린 정본 (+ 좌34는 ④ 지금 까몽 좌34). 지시문은 [지시문/](지시문/), 굽는 도구는 `node docs/캐릭터/까몽_펠트정본_후보_20261027/지시문/굽기.cjs <지시문> <이름> <참고…>`(원본 PNG 1254²는 git 밖 `.tmp/townstyle-20261026/판/`).

## 채택 — C 울 로빙 + 용 꼬리 + 용 날개 (10-27)

유호님 「C 울 로빙으로 새 정본 하고, 집 3D 까몽도 그걸로 다시 만들어 줘」 → 이어서 꼬리 사진을 보이며 「꼬리에 이거 이제 없애는 게 나을 것 같아. 꼬리를 용처럼 귀엽게 다시 만들어 줘」 → 위로 든 팔이 날개처럼 보여 「팔인지 날개인지 헷갈리는데 어떻게 하면 좋을까?」 → Claude 추천(팔 자리를 날개로) → 유호님 「② 팔 자리를 날개로 바꾸는 안으로 해 줘」.

- **새 정본:** [채택_정본_정면_좌34.jpg](채택_정본_정면_좌34.jpg) = `docs/캐릭터/정본_4K/까몽_본체.png` · `까몽_좌34.png`. C 울 로빙 몸에 ① 코랄 천 조각 · 홈질 · 잎 끝을 뺀 **용 꼬리**(굵은 뿌리에서 가늘어지는 S자, 등에 산호색 펠트 가시 다섯) ② 위로 든 팔 자리에 **작은 용 날개**(갈색 펠트 뼈대 · 둥근 팔꿈치 혹 · 갈비살 하나, 산호색 펠트 막, 아래 가장자리 둥근 물결). 고양이 귀 · 구슬 눈 · 몸은 그대로.
- **용 꼬리 시안:** [용꼬리_시안.jpg](용꼬리_시안.jpg)(왼쪽부터 D1 갈색 가시 · **D2 산호색 가시(채택)** · D3 스페이드 끝, 위 정면 · 아래 좌34). D2는 옛 꼬리의 코랄을 이어 가고, 집 화면처럼 작게 봐도 가시가 읽힌다.
- **팔 · 날개 시안:** [팔날개_시안.jpg](팔날개_시안.jpg)(① 팔답게 — 둥근 손 · 발바닥 무늬 · **② 날개로(채택)** · ③ 앞 손 + 등 날개). ②는 손이 없어 물건 들기 대신 날개 파닥임으로 표현한다.
- **만든 법:** 꼬리 · 날개 모두 앞 판 사진을 참고 1로 넣고 「그 부분만 바꿔」로 GPT 이미지 2.5에 다시 구웠다(지시문 [D*](지시문/) · [W*](지시문/), 좌34 날개 판은 정면 날개 판을 참고 2로). 흰 바탕 오리기(`tools/펠트_흰바탕오리기.py`) 뒤, 어두운 펠트 밑면이 그늘로 반쯤 깎여 남은 네모 턱을 몸 밑 곡선에 맞춰 잘라 냈다([현장 노트](../../현장노트/그림_굽기_오리기.md)). 1254² 판을 옛 정본의 테두리 상자에 맞춰 4096² 투명 PNG로 키웠다(×2.9 · ×2.8 — 원래 4K로 그린 그림이 아니다).
- 옛 털 정본은 [보관_털판_20261027](../정본_4K/보관_털판_20261027/)에 있다.

## 날개 · 가시 올리브 + 표정 세트 (10-27)

유호님 「지금 날개랑 꼬리 쪽이 코랄이잖아. 몽글이랑 겹치는 것 같아서 걱정인데 냉정하게 뭐가 더 좋을까?」 → 집 장면에서 산호 · 올리브(까몽 눈 색) · 버터를 나란히 놓고([날개색_시안.jpg](날개색_시안.jpg)) Claude 추천 올리브 — 세 식구가 산호 / 갈색 + 올리브 / 남색 + 노랑으로 갈리고, 초록 날개 · 가시는 용으로 바로 읽힌다(버터는 마린 노란 눈과 겹치고 벽 · 바닥에 묻힘) → 유호님 「까몽 날개 · 꼬리 가시는 눈 색 올리브로 바꿔 줘. 정본 · 표정 · 집 3D 모두」. 이어서 「까몽 표정 14장과 우34도 새 정본으로 다시 만들어 줘」(표정은 13장, 우34까지 14장).

- **정본 16장:** [채택_올리브_정본16장.jpg](채택_올리브_정본16장.jpg) = `docs/캐릭터/정본_4K/까몽_*.png`(본체 · 좌34 · 우34 · 표정 13장). 날개 막 · 꼬리 가시는 말차빛 올리브 펠트, 날개 뼈대는 갈색 그대로.
- **표정:** 옛 표정판의 눈 표정만 옮겼다 — 뜬 구슬 눈(감동은 유리 눈물방울, 궁금함 위로, 놀람 동그랗게, 뾰로통 옆 눈길, 응원 반짝), 감은 눈은 올리브 실을 수놓은 선(눈감음 · 눈웃음 · 으쓱 · 민망 · 안도 · 졸림 · 집중), 윙크는 한쪽만. 민망은 볼에 옅은 분홍. 옛 판 몇 장에 있던 작은 코는 정본대로 뺐다.
- **만든 법:** 먼저 산호 판을 「눈만 옛 판처럼」으로 굽고(참고: 산호 정면 + 옛 표정판 흰 바탕 JPEG, 지시문 [E_*](지시문/)), 색이 정해진 뒤 「날개 막 · 가시만 올리브로」로 다시 구웠다(참고: 그 표정판 + 올리브 정면, 지시문 [O_*](지시문/)). 오린 뒤 밑면의 그늘 턱을 몸 밑 곡선으로 자르고 턱 가장자리의 가는 틈을 메워, 옛 판의 테두리 상자에 맞춰 4096²로 키웠다(×2.9 · 우34 ×3.1).
- **아직 옛 털 판:** `docs/캐릭터/화면_1024/`의 까몽과 이를 쓴 파생 그림(튜터 · 레이싱 · 이야기 교실 등).
