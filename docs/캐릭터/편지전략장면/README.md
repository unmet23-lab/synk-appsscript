# 마린의 편지 전략 장면

사용자가 2026-09-11 요청한 **선택의 뜻을 캐릭터의 표정·자세·소품으로 보여 주는** 현재 장면이다. [정본.json](정본.json)이 선택별 원본·생성 요청·참조 자산·지문을 관리한다. 개별 장면에 대한 사용자 만족 확인과 제작·앱 적용을 구분한다.

| 선택 | 현재 원본 | 행동과 감정 |
|---|---|---|
| 다른 방법을 제안한다 | [marin-plan.png](marin-plan.png) | 고개를 기울여 달력과 계획을 살펴보고, 할 수 있는 방법을 찾는다. |
| 사정을 솔직히 말한다 | [marin-notes.png](marin-notes.png) | 시선을 공책으로 낮춰 집중하며 차례대로 기록한다. |
| 짧게 사과하고 부탁한다 | [marin-letter.png](marin-letter.png) | 부드러운 렌즈 표정으로 봉투를 두 손에 들고 진심을 전한다. |

현재 마린 본체와 사용자가 만족한 편지 작업실의 재질·조명을 참조해 내장 ImageGen으로 제작했다. 세 장의 실제 크기는 **1536×1024**이며 확대하지 않았다. 기록·편지 장면의 표정은 ImageGen으로 따로 다듬고 렌즈의 좁은 영역만 원 장면에 합쳤다. 해당 영역 밖의 픽셀은 원 장면과 동일하다. 팔 둘, 손과 소품의 접촉, 완전한 봉투 가장자리, 앱 표시 크기에서의 읽힘을 확인한다.

SYNK-talk `tools/마린전략자산반입.js`가 이 정본을 검증하고 `assets/교수작업실/marin-*.webp`와 `마린전략출처.json`을 만든다. 재생성은 현재 원본에서 하며 기본 마린 그림으로 조용히 대체하지 않는다. 다른 친구 선택에는 해당 친구를 유지한다. 이 장면들은 전역 마스코트 본체·감정 목록의 교체가 아니다.

‘지금 내 상황’에는 [marin-sad.png](marin-sad.png)의 슬픈 렌즈·눈물을 사용한다. 실제 1254×1254 RGB 원본은 눈 주변의 제작 재료이며 배경을 포함한 전체 그림을 앱에 띄우지 않는다. `tools/가이드장면표정반입.js`가 원본의 눈 위치를 현재 본체에 맞춰 좁게 반입한다. 기존 본체·의상·외곽 투명도는 고정하고 렌즈 모양으로 속상함을 드러낸다. 표정 층과 출처를 같은 경로에서 교체해 앞선 단순 눈물 표현을 현재 사용처에 남기지 않는다.

적용·검수 상태는 SYNK-talk `docs/교수멘탈_UI_20260911.md`에 남긴다. 운영 배포·실제 학생 사용 결과를 뜻하지 않는다.
