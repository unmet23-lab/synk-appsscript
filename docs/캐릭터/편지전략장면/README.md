# 세 친구의 편지 상황·전략 장면

사용자가 2026-09-11 요청한 **선택의 뜻을 캐릭터의 표정·자세·소품으로 보여 주는** 현재 장면이다. [정본.json](정본.json)이 선택별 원본·생성 요청·참조 자산·지문을 관리한다. 개별 장면에 대한 사용자 만족 확인과 제작·앱 적용을 구분한다.

| 화면의 선택·상황 | 현재 원본 | 행동과 감정 |
|---|---|---|
| 제가 할 수 있는 일을 말씀드려요 | [몽글](mongle-plan.png) · [까몽](kkamong-plan.png) · [마린](marin-plan.png) | 고개를 기울여 달력과 공책을 살펴보며 앞으로 할 일을 찾는다. |
| 무슨 일이 있었는지 설명해요 | [몽글](mongle-notes.png) · [까몽](kkamong-notes.png) · [마린](marin-notes.png) | 공책을 내려다보며 사정을 차분히 기록한다. |
| 짧게 사과하고 부탁해요 | [몽글](mongle-letter.png) · [까몽](kkamong-letter.png) · [마린](marin-letter.png) | 봉투를 몸 가까이 두고, 조심스럽고 다정한 표정과 작은 움직임으로 부탁한다. |
| 갑자기 몸이 아파 과제를 못 낸 상황 | [몽글](mongle-sick.png) · [까몽](kkamong-sick.png) · [마린](marin-sick.png) | 담요를 덮고 쉬면서 아직 내지 못한 과제를 걱정한다. 다른 사유의 과제에는 이 그림을 얹지 않는다. |

각 친구의 본체와 편지 작업실의 재질·조명을 참조해 내장 ImageGen으로 제작했다. 행동 장면 9장과 아픈 상황 3장의 실제 크기는 **1536×1024**이며 확대하지 않았다. 몽글·까몽은 정본의 **작고 둥글고 애매한 밑단·뒤 접힘**을 소품 가까이 살짝 움직여 사용한다. 무슨 생명체인지 상상할 여지가 있는 원형과 사용자가 좋아한 표정·기존 말투를 유지하며, 이번 장면은 동작이 조금 어색해도 귀여운 첫인상을 우선한다. 팔·손을 추가하거나 동물의 해부학적 형태로 과장한 중간판을 현재 제작 기준으로 재사용하지 않는다. 담당 원천은 [가이드 정본의 몸짓·소품 형태 기준](../가이드_정본.md#anatomy-actions)이며, 실제 반영·검수 상태는 아래의 앱 UI 기록에서 확인한다.

마린 기록·편지 장면의 표정은 렌즈의 좁은 영역만 원 장면에 합쳤고 해당 영역 밖 픽셀은 원 장면과 같다. 마린은 기존 두 팔과 두 손을 쓴다. 검수는 정본의 둥근 실루엣·작은 접힘과 밑단의 자연스러움, 소품 접촉, 완전한 봉투, 흰 매트가 없는 털 경계, 실제 크기의 표정과 읽힘을 확인한다.

SYNK-talk `tools/가이드장면자산반입.js`가 이 정본을 검증하고 `assets/교수작업실/{mongle,kkamong,marin}-*.webp`와 `가이드장면출처.json`을 만든다. 선택 카드와 선택 뒤 말풍선은 같은 캐릭터·같은 행동 그림을 읽는다. 미지원 이름·선택에는 다른 친구를 대신 넣지 않는다. 본문은 읽을 수 있는 실제 텍스트로 두고 기존 캐릭터 말투와 ‘제목 → 안내 → 말투 예시’ 순서를 유지한다. 옛 마린 전용 반입기·출처는 세 친구를 지원하는 현재 경로로 교체했다. 이 장면들은 전역 마스코트 본체·감정 목록의 교체가 아니다.

아픈 과제의 ‘지금 내 상황’에는 세 친구 모두 방·담요·휴지·못 낸 과제 공책을 포함한 상황 그림을 쓴다. 마린은 [marin-sick.png](marin-sick.png)의 처진 노란 렌즈·눈물·기울인 자세로 감정을 드러낸다. 한 손은 휴지를 들고 다른 손은 공책에 놓이며 기존 두 팔을 유지한다. 단독 프로필만 두었던 이 상황의 이전 배치를 교체했다.

[marin-sad.png](marin-sad.png)는 다른 속상함 표정 사용처의 눈 주변 제작 재료로 보존한다. 실제 1254×1254 RGB 원본 전체를 앱에 띄우지 않으며 `tools/가이드장면표정반입.js`가 눈과 눈물만 좁게 반입한다. 이 렌즈 재료와 현재 아픈 상황 전체 그림을 구별한다.

적용·검수 상태는 SYNK-talk `docs/교수멘탈_UI_20260911.md`에 남긴다. 운영 배포·실제 학생 사용 결과를 뜻하지 않는다.
