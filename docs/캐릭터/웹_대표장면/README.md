# 기업 홈의 세 친구 장면

`정본.json`이 현재 기업 홈의 장면과 파일 지문을 지정한다. 현재 버전은 `20260915-felt-seoul`, 파일은 `세친구_20260915_한강과남산.png`다. 기본 ImageGen으로 만든 1586×992 RGB 이미지다.

2026-09-15 사용자 요청으로 세 친구가 선 배경을 넓은 판타지 펠트 서울로 확장했다. 노을빛과 푸른 저녁, 한강을 흐르는 물결, 금빛 다리와 배, 겹겹의 산과 먼 남산타워, 양모 안개와 따뜻한 강변을 하나의 수공예 미니어처 장면으로 엮었다. 실제 지리를 정확히 재현한 사진·지도라는 뜻은 아니다.

몽글의 눈웃음, 까몽의 초록 눈과 짧게 든 팔, 마린의 차분한 반눈과 가슴꽃, 셋의 상대 크기와 접지는 이전 장면을 기준으로 유지했다. 독립 이미지 검토에서도 추가 사지·눈에 띄는 합성 경계·잘린 발을 찾지 못했다. 미세한 털과 풍경은 재생성됐으므로 픽셀 동일성을 주장하지 않는다.

- 현행 사용처: `SYNK-website/dist/index.html`, 공개 `synk-policy/index.html`의 대표 장면·공유 이미지.
- 파생: `SYNK-website/sync-mascot-assets.mjs` → `dist/assets/companions-scene.webp`. 정본 지문·버전·크기·대체 설명·사전 로드 주소를 함께 반영한다.
- 배치: `SYNK-website/dist/hero-scene.css`. 데스크톱은 메인 열의 약60%, 1100px 미만은 지면 폭 전체. 이미지는 원본 비율 그대로 표시하고 자르지 않는다. 밝은 펠트 테두리는 얇게 남긴다.
- 생성 통로: 기본 ImageGen, 정확한 모델 버전은 노출되지 않았다. 현재 프롬프트는 `생성프롬프트_20260915_한강과남산.txt`다.
- 입력: `세친구_20260915_마린반눈.png`는 현재 표정·정체성 참조로만 보존한다. 옛 아이보리 배경 버전을 현행 표시 자산으로 선택하지 않는다.
- 범위: 기업 홈 통합 장면. 개별4K 본체·표정과 편지 게임의 상황별 장면은 별도다.

공개 반영·화면 검증은 기업웹 제작 결과와 `SYNK-website/qa/RESULTS.md`를 따른다. 제작 요청을 최종 이미지에 대한 사용자 만족으로 기록하지 않는다.
