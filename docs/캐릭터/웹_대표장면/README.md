# 기업 홈의 세 친구 장면

`정본.json`이 현재 기업 홈의 장면과 파일 지문을 지정한다. 현재는 `세친구_20260914_함께.png`, 기본 ImageGen으로 편집한 1586×992 RGB 이미지다. 4K나 투명 PNG로 표시하지 않는다.

09-14 사용자가 까몽이 혼자 뒤에 떨어져 보인다고 지적했다. 까몽을 몽글 곁의 앞쪽으로 당기고 몸 밑단·겹침·바닥 그림자를 함께 조정했다. 몽글의 크림 실땀, 마린의 꽃과 짧은 사지, 세 캐릭터의 표정·재질을 원본과 직접 비교했으며 주담당·독립 시각 검토에서 적용 가능으로 판단했다. 이미지 편집으로 미세한 털 결은 다른 캐릭터도 재생성됐으므로 부분 픽셀 동일성을 주장하지 않는다. 최종 수정본에 대한 사용자 만족은 아직 확인하지 않았다.

- 현행 사용처: `SYNK-website/dist/index.html`, 공개 `synk-policy/index.html`의 대표 장면 및 공유 이미지.
- 파생: `SYNK-website/sync-mascot-assets.mjs` → `dist/assets/companions-scene.webp`. 생성기가 정본의 버전·크기·공유 이미지 주소도 함께 반영한다.
- 표시: 최대 600px, Paper 바탕과 multiply 합성. 흰 스튜디오 바탕을 투명 컷아웃처럼 사용하지 않는다. 실제 화면의 겹침·경계·접지를 확인한다.
- 편집 입력: `이력/세친구_20260910.png`. 구 프롬프트도 `이력/`에 보존하며 현행 표시 원천으로 재사용하지 않는다. 당시 정확한 생성 지문 기록은 Git의 이전 `정본.json`에 남는다.
- 범위: 기업 홈 장면만 수정한다. 개별 4K 본체·표정, 앱, Field Notes와 별도 비공개 Sites의 09-11 검토 스냅샷을 교체한 뜻이 아니다.

도구는 기본 ImageGen이며 정확한 모델 버전은 노출되지 않았다. 생성 요청은 `생성프롬프트_20260914.txt`, 검수·공개 반영은 기존 기업웹 제작 결과 및 SYNK-website `qa/RESULTS.md`에서 확인한다.
