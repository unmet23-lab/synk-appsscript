# 기업 홈의 세 친구 장면

`정본.json`이 현재 기업 홈에서 사용하는 장면과 원본 지문을 지정한다. `세친구_20260910.png`는 기본 ImageGen으로 다시 만든 1586×992 RGB 장면이다. 4K나 투명 PNG로 표시하지 않는다.

몽글 왼쪽의 불투명한 흰 분홍색 잔류가 까몽과 겹칠 때 드러나, 세 캐릭터를 같은 빛·바닥·접촉 그림자로 통합했다. 사용자의 재제작·반영 지시에 따른 웹 장면이며, 개별 캐릭터의 4K 본체·표정 정본을 대체하는 자산이 아니다. 원본과 비교하면 털과 봉제선의 세부는 재생성된 장면이다.

- 사용처: `SYNK-website/dist/index.html`, `synk-policy/index.html`의 기업 홈 대표 장면.
- 배포: 기존 비공개 검토 홈과 `https://synk.im/`.
- 파생 경로: `SYNK-website/sync-mascot-assets.mjs` → `dist/assets/companions-scene.webp`.
- 표시: Paper 바탕 위에 multiply 합성. 흰 스튜디오 바탕을 새 투명 컷아웃으로 변환하지 않고, 실제 화면에서 경계·겹침·접지를 함께 확인한다. 어두운 배경에 그대로 사용하지 않는다.
- 후속 변경: 이 장면 또는 참조 캐릭터가 바뀌면 실제 비교 후 장면·정본 기록·웹 파생물·두 게시본을 함께 갱신한다. 파일 지문 확인만으로 시각 검수를 대체하지 않는다.

생성 통로는 기본 ImageGen이다. 호출에서 정확한 모델 버전 선택 기능은 없었으므로 ‘GPT 2.5’로 표기하지 않는다. 원 요청·원인·화면 검수·게시 확인은 기존 기업웹 제작 결과에 기록한다.
