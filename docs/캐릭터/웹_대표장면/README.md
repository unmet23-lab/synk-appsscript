# 기업 홈의 세 친구 장면

`정본.json`이 현재 기업 홈의 장면과 파일 지문을 지정한다. 현재 버전은 `20260915-felt-smiles`, 파일은 `세친구_20260915_표정과펠트.png`다. 기본 ImageGen으로 편집한 1586×992 RGB 이미지이며, 4K나 투명 PNG로 표시하지 않는다.

09-14에는 뒤에 떨어져 보이던 까몽을 몽글 곁의 앞쪽으로 당겼다. 09-15에는 사용자가 몽글을 조금 줄이고 까몽·마린을 키워 달라고 요청해, 셋이 가까이 선 구도와 접지를 유지하며 상대적인 크기를 조정했다. 프롬프트의 몽글 약 15% 축소·까몽 약 10% 확대·마린 약 15% 확대는 편집 의도이며, 결과에서 그 비율을 정밀 실측한 수치가 아니다.

09-15 원본과 수정본을 직접 비교한 독립 시각 검토에서는 몽글의 존재감이 줄고 까몽·마린이 더 잘 드러나는 변화를 확인했다. 까몽의 초록 눈과 짧게 든 팔, 몽글의 검은 눈과 크림 실땀, 마린의 파란 머리·노란 눈·꽃·짧은 사지, 연결된 바닥 그림자를 확인했으며 공개 적용을 막을 형태·표정·재질·접지 결함은 발견하지 않았다. 미세한 털 결·눈 반사·꽃 세부는 재생성됐으므로 부분 픽셀 동일성이나 단순 비율 변환만 수행했다고 주장하지 않는다. 이 판단은 해당 기업 홈 구도의 검토이며, 개별 캐릭터의 전사 공통 비율 변경이나 최종 수정본에 대한 사용자 만족을 뜻하지 않는다.

- 현행 사용처: `SYNK-website/dist/index.html`, 공개 `synk-policy/index.html`의 대표 장면 및 공유 이미지.
- 파생: `SYNK-website/sync-mascot-assets.mjs` → `dist/assets/companions-scene.webp`. 생성기가 정본의 버전·크기·공유 이미지 주소도 함께 반영한다.
- 표시: 프레임 최대 600px, 이미지 normal 합성. 아이보리 펠트 배경과 실제 접촉 그림자를 포함한 장면이며 투명 컷아웃처럼 사용하지 않는다. Paper/Oat 공통 펠트 타일을 옅게 적용한 주변 면과 이어진다.
- 현행 편집 입력: `이력/세친구_20260915_균형.png`, 개별 정본의 `몽글_눈웃음.png`와 `마린_눈웃음.png`. 앞선 이미지·프롬프트는 `이력/`에 보존하며 현행 표시 원천으로 재사용하지 않는다. 현재 이미지와 입력의 지문은 `정본.json`, 앞선 지문 기록은 Git의 이전 `정본.json`에서 확인한다.
- 범위: 기업 홈 장면만 수정한다. 개별 4K 본체·표정, 앱, Field Notes와 별도 비공개 Sites의 09-11 검토 스냅샷을 교체한 뜻이 아니다.

후속 요청으로 몽글의 눈웃음과 마린의 노란 꽃눈을 실제 표정 PNG에 맞추고, 아이보리 펠트 바닥·배경을 더했다. 입을 추가하지 않았으며 까몽의 초록 눈, 기존 상대 크기, 짧은 사지와 마린의 가슴꽃을 유지한 모습을 독립 시각 검토했다. 꽃 형태는 정본 설명의 꽃잎 수를 추정해 다시 그리지 않고 실제 참조 PNG를 따른다. 데스크톱과 모바일에서 표정·외곽·접지를 확인했다.

도구는 기본 ImageGen이며 정확한 모델 버전은 노출되지 않았다. 현재 생성 요청은 `생성프롬프트_20260915_표정과펠트.txt`다. 이전 균형 조정 공개본은 ad12f8b이며, 현행 표정·펠트 후속본의 게시 상태와 파일 대조는 기업웹 제작 결과 및 SYNK-website `qa/RESULTS.md`를 따른다.
