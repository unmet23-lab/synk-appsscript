# 기업 홈의 세 친구 장면

`정본.json`이 현재 기업 홈의 장면과 파일 지문을 지정한다. 현재 버전은 `20260915-calm-marin`, 파일은 `세친구_20260915_마린반눈.png`다. 기본 ImageGen으로 편집한 1586×992 RGB 이미지다.

2026-09-15 사용자 첨부의 차분한 반눈을 기준으로 마린의 꽃눈을 교체했다. 파란 윗눈꺼풀 아래 노란 반원 눈, 몽글의 눈웃음, 까몽의 초록 눈, 기존 크기 균형과 짧은 사지, 마린의 가슴꽃, 아이보리 펠트 배경·접촉 그림자를 실제 이미지에서 확인했다. 독립 검토에서도 눈 주변의 눈에 띄는 붙임 경계나 꽃눈 잔여를 찾지 못했다. 미세한 털은 재생성됐으므로 눈 밖 픽셀 동일성을 주장하지 않는다.

- 현행 사용처: `SYNK-website/dist/index.html`과 공개 `synk-policy/index.html`의 대표 장면·공유 이미지.
- 파생: `SYNK-website/sync-mascot-assets.mjs` → `dist/assets/companions-scene.webp`. 정본 지문, 버전, 크기, 대체 설명과 사전 로드 주소를 함께 반영한다.
- 표시: 최대 600px의 장면, normal 합성. 주변 Paper/Oat 펠트 면에 연결한다.
- 생성 통로: 기본 ImageGen. 정확한 모델 버전은 노출되지 않았다. 현재 프롬프트는 `생성프롬프트_20260915_마린반눈.txt`, 사용자 참조는 `마린반눈_사용자참조_20260915.png`다.
- 이전 `세친구_20260915_표정과펠트.png`는 이번 편집의 입력과 이력으로만 보존한다. 현행 표시 자산으로 선택하지 않는다.
- 범위: 기업 홈 통합 장면. 개별 4K 본체·표정이나 편지 게임의 상황별 장면을 전역 교체하는 요청으로 확대하지 않았다.

공개 반영과 데스크톱·모바일 검증 증거는 기업웹 제작 결과와 `SYNK-website/qa/RESULTS.md`를 따른다. 최종 수정본에 대한 사용자 승인을 임의로 기록하지 않는다.
