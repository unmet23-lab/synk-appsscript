# 재질 가족 제안 — 「양모 공방」 (2026-08-19 · **자수 ✅채택** · 털실 진행바 ▶실물화 — 유호 픽 08-19)

> 유호님 물음 08-19: 「퍼 말고 다른 실제같이 느껴지는 게 뭐가 있을까? 펠트 재질이 될 수도 있고 자수 같은 느낌이 될 수도 있고.」
> 같은 날 확정 반영: **UI 요소 = 짧은 퍼 · 마스코트 = 니들펠트 정본 유지**(컨셉 정본 조항 ⓘ 「결 길이 확정」).
> 이 문서는 **제안 기록**이다 — 채택·기각은 유호님 픽. 기록해 두는 이유 = 세션 너머 재제안 방지.

## 잣대 넷 (아이디어를 거른 기준)

1. **사람이 만든 것** — 펠트 직책의 뜻 그대로. 손이 간 흔적이 「공들임」으로 읽혀야 한다.
2. **몽골 양모 서사** — 학생·학부모가 아는 재료일수록 실감이 산다(양모·펠트·자수는 몽골 생활 재료다).
3. **기존 3직책과 안 싸움** — 유리(담는다·정보 층)·레진(가둔다·히어로 1점)은 그대로. 섬유 가족은 «사람 손» 층만 진다.
4. **킷 색·대비 물리 호환** — 염료는 킷 「이름」 참조. 글자에는 재질을 안 입힌다(타이포 불가침).

## 요소 아이디어 — 「손이 지나간」 계열 (유호 지시 08-19 「비슷한 느낌 많이」 · 전부 시안 후보)

> 재질이 아니라 **요소 단위**의 은유다 — 각각 UI 의 실제 자리 하나에 꽂힌다. 굽는 순서는 유호님 픽.

| # | 요소 | UI 자리 | 은유 |
|---|---|---|---|
| 1 | **털실 진행바** ▶실물화 중 | 학습 진행·XP 바 | 「실이 감긴다」 — 진행 = 감아온 길이. 앱 성장층은 Lime 실 변형 후보 |
| 2 | **꿰맨 단추(4구)** | 토글·라디오·설정 스위치 | 켬 = 실이 X 로 꿰매짐 / 끔 = 빈 구멍 — 상태가 «바느질 유무»로 보인다 |
| 3 | **와펜(자수 패치)** | 성취 뱃지·레벨 표장·TOPIK 급수장 | 교복 와펜 문법 — 획득 = 「달아 준다」. 자수 채택의 연장 |
| 4 | **블랭킷 스티치 테두리** | 카드·패널 모서리 감침질 | 카드 규격 자체가 «감쳐진 천 조각»이 된다(자수 채택의 면 버전) |
| 5 | **폼폼(털실 방울)** | 알림 점·뱃지 카운터·불릿 상급판 | 3px 코랄 점의 실물화 — 흔들리는 모션 여지(감각 §8 300ms 상한 안) |
| 6 | **시침핀** | 지도 핀·현재 위치·북마크 | 바늘머리 구슬 = 레진 1점과 자연 결합(꽂는 행위 = 저장) |
| 7 | **밑그림 점선** | 스켈레톤 로딩·빈 상태 | 「아직 안 꿰맨 밑그림」 — 로딩이 미완성 자수 도안으로 보인다 |
| 8 | **실패(보빈) 스피너** | 로딩 스피너 | 실패가 돌며 실이 풀린다 — 기다림 = 실을 푸는 시간 |
| 9 | **바늘땀 페이지 점** | 페이지네이션·온보딩 단계 점 | 지나온 쪽 = 꿰맨 땀 / 남은 쪽 = 빈 바늘구멍 |
| 10 | **라벨 태그(직조 라벨)** | 카테고리 칩·태그 | 옷 안쪽 라벨 문법 — 로고 미니 직조(로고 정본 W5 축소판) |
| 11 | **매듭 오너먼트** | 챕터·시즌 구분 장식 | 한국·몽골 매듭 — 「한국적 표현」 트랙(자개 등)과 접점. 큰 자리 1점 전용 |

- 공통 규율: 글자 불가침 · 유채 실 = 신호 1점 셈 · 굽는 자 = `tools/요소굽기.py` 형태 추가로.
- ⚠5·8 처럼 «움직임»이 낀 요소는 정지 렌더 먼저, 모션은 감각 §8(300ms·transform/opacity)로 별도.

## 기각 (재제안 방지 — 근거 1줄씩)

- **금사(금실) 자수** — DESIGN.md §4 「골드 복귀 금지 · 두 번째 액센트는 없다」에 정면 충돌.
- **가죽·스웨이드** — 양모 가족 이탈. 온기의 결이 다르고(동물 가죽) 몽골 서사에서도 «양모 공방»과 톤이 갈린다.
- **세라믹·도자** — 유리·레진의 「담는·가두는」 직책과 혼선. 깨지는 물성은 브랜드 온기와 반대축.
- **벨벳** — 짧은 퍼와 시각 구분이 안 된다(중복 재질은 위계만 흐린다).

## 도전안 (기록)

**화면·PDF 한 장을 통째 Blender «장면»으로 굽기** — 요소 사이 그림자·빛이 실제로 이어져 참조 ②(겹침 그림자)의 깊이가 화면 전체에 선다. 대가: 장당 굽는 시간 + 글자는 HTML 층 유지 규율. 룸굽기 「합주」 부품이 표지에서 이미 쓰는 방식의 확장.
