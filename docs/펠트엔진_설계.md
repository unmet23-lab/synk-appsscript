# SYNK 펠트 그래픽 엔진 — 설계 정본 (v0.1 · 2026-08-15)

> **유호 지시 08-15**: 펠트는 SYNK «회사 전용 재질»이다. 브랜드킷 등재를 넘어, 이 재질을 기능적으로
> 어느 회사보다 잘 구현하기 위한 그래픽 엔진을 세팅해 나간다. 앞으로 디자인할 것이 많다.
> 값의 정본 = `docs/디자인_토큰.json` 「재질」 축 · 실측 근거 = memory `mascot-felt-liveness` · `image-pipeline-api-switch`.

## 0. 한 문장

어느 지면(2D 컷 · 3D 모션 · UI 오브젝트 · 인쇄 · 영상)에서든 SYNK 펠트를
**같은 색(램프) · 같은 결(사진 섬유) · 같은 빛(조명 레시피)**으로 결정론 재현하는 **사진 기반 재질 시스템**.
게임 엔진이 아니라 «재질 파이프라인»이다 — 정본(값) + 통로(도구) + 검증(자)의 세 다리로 선다.

## 1. 헌법 — 실측이 세운 제약 (재론 금지 · 근거는 각 메모리)

1. **결은 사진 픽셀에서만.** 프로시저럴 노이즈는 매끈한 왁스로 읽혀 기각됐다(probe2 08-15).
   엔진의 섬유는 전부 정본 사진의 울 패치에서 잘라 온다 — 색·결이 자동 일치한다.
2. **색은 낱말이 아니라 참조·연산.** 프롬프트에 색 이름·hex 를 적으면 중간값에 착지한다(문장 ΔH 16 → 참조 ΔH 1.8).
   색 갈이는 재염색(선형광 채널 게인 · `tools/펠트색갈이.py`) 또는 참조 이미지가 진다.
3. **킷 hex 정확 일치는 불가능이 정상.** 결 있는 표면의 평균은 색역 끝(R 255)에 못 닿는다.
   코어색 숫자를 인용할 땐 **잰 자 이름**을 함께 적는다(F456 — 자간 ΔE 3.62 실측).
4. **생성 모델에 마스코트 통째 ✗ · 생성 텍스처 기각.** SynthID·재해석(코어 H8°→21°·섬유 소멸) 실측.
   생성은 «참조를 받는 굽기»(nano-banana 류)와 «형상만»(Hunyuan3D shape)으로 제한한다.
5. **조명 레시피 = 사진에 구워진 조명 보존.** 재조명 최소(키 120 · 필 35) + 방출 0.55 이 색을 진다.

| **L3 검증층** | `브랜드렌더린트.js`(바닥 계산·의상 합집합) · `마스코트램프.py`(램프 자·--검증 재현) · `상태컷정합.py` | ✅ 부분 |

## 3. 짓는 순서 (막힘과 함께)

1. ✅ 설계 정본 + L0 토큰 등재 (08-15 이 커밋)
2. **L2-모듈 추출** — ⛔ `마스코트인형리깅.py` 는 `177ef8bf` 트랙(anim2 좌턴 미착지) 선언 파일. 착지 후.
   추출 때 **셰이딩 값을 토큰에서 읽게 배선**한다 — 그 전까지 값 개정은 토큰↔코드 **두 자리 동시 이동**.
3. **L2b 패치 라이브러리** — 신규 파일이라 자유. 모듈과 한 벌이 자연스러움.
4. **첫 비마스코트 실증 = 녹음 오브 펠트 3D** — 죽은 `1cfa648d` 트랙의 「UI 오브젝트 재질 슬롯」을 여기서 흡수.
5. **텍스처·멀티뷰 층(뒤태 해결)** — ⏳유호(HF PRO $9/월) 또는 무료 몫(하루 ~300초) 배분.
   ¾ 컷을 멀티뷰 입력으로(`--좌/--우/--뒤` · 누끼 선행) — 모델이 옆면을 상상 대신 «본다».

## 4. 도전안 — 실시간 웹 펠트 (Three.js · 시기 보류)

앱 안에서 마스코트가 **실시간으로** 산다(교대 mp4 가 아니라 연속 관절 — 「살아있는 캐릭터」 상시 지시의 종착).
사진 베이크 텍스처를 넘기면 헌법 1과 충돌 없다. **시기 = Expo 앱 화면 작업이 열릴 때** —
지금은 오프라인 엔진이 자산 생산의 병목이고, 실시간은 소비 지면이 서야 잰다. 지금 짓지 않는다.

## 5. 대가 — 틀릴 때의 모습

- **정본 사진이 바뀌면 전 층이 낡는다** (사진 기반의 대가). 정본 교체 = 램프 재실측 + 패치 재절단 + `--검증` 재통과가 한 벌.
- **울패치 타일의 벽은 뒤통수(180°)** — 가로 스미어 실측. 3-5 텍스처 층이 닫을 때까지 큰 턴은 좌 +75° / 우 -28° 안.
- **토큰↔코드 값 이중 상주** (3-2 배선 전까지) — 갈라지면 「맞는 얼굴로 틀린 값」이 된다. 닫을 것 = 3-2 배선 그 자체.
