# SYNK Loom L1 재질 시스템 — Felt 프로필

2026-09-13 · 펠트는 별도 엔진이 아니라 [Loom](Loom_엔진_설계.md)의 재질 프로필이다. 파일명은 기존 참조를 위해 유지한다. 사진 패치·3D 실험의 상세값은 [정리 전 원문](https://github.com/unmet23-lab/synk-appsscript/blob/8b80a507168d/docs/펠트엔진_설계.md)에 남긴다.

## 0. 목적

승인된 색·잔섬유·두께·바느질·빛을 매체가 달라도 같은 세계로 표현한다. 수공의 미세한 불균일을 유지하고 매끈한 왁스·플라스틱처럼 변하지 않게 한다. 값은 [디자인 토큰](디자인_토큰.json), 승인 자산 선택은 [DESIGN](../DESIGN.md)이 담당한다.

## 1. 정체성과 품질

사진 패치·승인 참조 생성·3D 렌더 등 필요한 제작법을 사용한다. 과거 생성 모델·프로시저럴 실험의 실패를 영구 도구 금지로 고정하지 않는다.

승인 마스코트의 몸·색·의상·표정을 보존한다. 표정은 [좁은 변화 영역 밖 재질 고정](캐릭터/캐릭터_생명감_설계.md#1-a-표정-전환의-재질-고정)을 따른다. 승인 원본 교체와 새 용도 장면 제작을 구분하고 의상 생성은 [담당 정본](캐릭터/의상제작_정본.md)의 사용자 지정을 따른다.

색은 참조와 실제 출력으로 확인한다. 색차를 인용할 때 조명·색 변환·측정 조건을 함께 기록하며 한 실험의 허용 오차를 모든 재질의 면책 범위로 쓰지 않는다.

## 2. 구현 원천

| 구분 | 원천 |
|---|---|
| 값·참조 | 디자인 토큰, 마스코트 자산 모듈, 해당 용도 정본 |
| 사진 패치·재염색 | [펠트패치.py](../tools/펠트패치.py), [펠트색갈이.py](../tools/펠트색갈이.py), 패치 장부 |
| 3D 부품·자산화 | [룸장면.py](../tools/룸장면.py), [룸굽기.js](../tools/룸굽기.js), [룸자산화.py](../tools/룸자산화.py) |
| 살아 있는 장면 | [현재 표현 기준](Loom_실시간장면_표현기준.md), 공통 움직임·표시기 |
| 만짐·재질음 | [감각 프로필](펠트엔진_감각층_설계.md), [소리 합성](../tools/감각층소리합성.js) |
| 적용·확인 | [굽기 규약](Loom_굽기규약.md), [앱 연결](Loom_앱반입_설계_v1.md), 관련 검사 |

패치의 원료·공용·마스코트 전용 역할은 실제 장부와 도구를 따른다. 원료 크롭을 공용 완성 재질로 노출하지 않는다. 옛 F0~F5는 프로필 내부 구분이며 별도 엔진이나 필수 개발 순서가 아니다.

## 3. 재현 가능한 원본

원본·참조·레시피·파생본·소비 위치를 남긴다. 기준 자산을 교체하면 패치 좌표·색·알파·치수와 소비자를 대조한다. 원천 값만 바꾸고 소비 코드가 옛 값을 읽는 상태를 피한다.

## 4. 실시간 표현

이미 구현된 정원 장면을 기준으로 재질·접지·윤곽을 보존하며 움직인다. “Expo 전에는 실시간 금지”, “VR 때만 다시 연다”는 옛 순서를 현재 Loom에 적용하지 않는다. 보류된 리깅 시제품을 새 실시간 방식의 유일한 경로로 삼지 않는다.

## 5. 도구 발전

새 모델·셰이더·렌더러는 같은 승인 참조로 실제 결과를 비교한다. 별도 모델 지정·지출 조건은 담당 정본을 따른다. 공급자·무료 몫·대기 트랙·옛 장비 성능을 전 층의 불변 조건으로 두지 않는다.

## 6. 축적할 것

승인 정체성, 재현 가능한 자산·레시피, 실제 크기의 품질 판단, 장면·상호작용 어휘를 축적한다.

### 6-1. 원천과 경계

재질·캐릭터·렌더러·감각을 분리해 발전시킨다. 직접 제작하거나 사용 권리를 확인한 자료를 원천으로 쓰고 타인의 작품을 참고한 것과 반입 권한을 구분한다. 학생의 관찰 사실과 AI 해석을 분리하며 없는 성취·관계를 만들지 않는다. 옛 장기 RPG 구상은 자동 착수 의무나 새 요청 금지 근거가 아니다.

## 7. 실패를 확인하는 자리

타일 반복·조명 얼룩·암부 섬유 소실·스미어·누끼 구멍·표정 전환의 털 교체·접지 분리를 실제 출력에서 확인한다. 과거 특정 회전각·조명값을 다른 자산·도구의 상한으로 복제하지 않는다.
