# 조립 증분 v9.81 — 리그 카드·반 목록 카드·총원 필 (유호님 실행지)

> 2026-07-31 유호님 지적 3건(랭킹 탭 후짐 · 강사 반 리스트 후짐 · 반 상세 총원 부재)의 화면 반영 절차.
> 서버는 이미 준비 완료(코드 v9.81 배포 + calcAll이 열을 만들어 채움). **Glide에서 남은 건 아래 두 화면뿐.**
> 소요: 총 ~10클릭. ③총원은 **할 일 없음**(자동).

---

## 준비 확인 (1분)

Glide 편집기 → 상단 **Data** → `profiles` 시트에 **DO열 「랭킹보드HTML」**, `class_stats`에 **15열 「반카드요약」·16열 「반몬스터이미지」** 가 보이면 준비 끝.
안 보이면 아직 **코드가 라이브에 배포되기 전**입니다 — 배포 전에는 `calcAll`을 눌러도 열이 생기지 않습니다(구버전이 돌기 때문). "v9.81 배포 완료" 보고를 받은 뒤 `calcAll` ▶ 1회 → Glide Data 새로고침 순서로.

---

## ① 학생 「랭킹」 탭 — 리그 보드 얹기 (6번 지적)

1. **Layout** → 왼쪽 탭 목록에서 학생 **「랭킹」** 탭 클릭.
2. 왼쪽 컴포넌트 목록 상단 **+** → **Rich Text** 추가.
3. 오른쪽 패널 DATA → 소스 열 = **랭킹보드HTML** (profiles · User's row).
4. 왼쪽 목록에서 방금 만든 Rich Text를 **맨 위로 드래그** (기존 랭킹 Collection 위).
5. 기존 랭킹 Collection(이름·포인트 리스트)은 그대로 둡니다 — 리그 카드가 TOP10, 컬렉션이 "전체 상세" 역할.
   - (선택) Collection 제목을 `전체 순위 (상세)` 로 바꾸면 역할이 더 분명해집니다.

**확인**: Preview as DEMO-01 → 랭킹 탭 최상단에 다크 카드 「SYNK LEAGUE · 7월 리그」 + 포디움(👑 1위)이 뜨고,
자기 순위 행에 주황 「나」 칩이 보이면 성공.

## ② 강사 「반」 탭 — 반 목록을 카드로 (7번 지적)

1. **Layout** → 강사 **「반」** 탭 → 반 목록 **Collection** 클릭.
2. 오른쪽 패널 **STYLE** → **Card** 선택 (List/Compact였던 것을 교체).
3. 같은 패널 ITEMS DATA:
   - Title = `class_name` (그대로)
   - **Description = `반카드요약`** ← 새 열 (👥 총원 · 반몬스터 · 보스 상태 한 줄)
   - **Image = `반몬스터이미지`** ← 새 열
4. (선택) STYLE에서 Image shape·크기는 취향대로 — 몬스터가 크게 보이는 쪽 권장.

**확인**: Preview as SYNK-T01 → 반 목록이 몬스터 이미지 + 「👥 n명 · 몬스터 · ⚔️ 보스 HP」 카드로 보이면 성공.
(contents monster E열에 이미지 URL이 없는 단계는 이미지가 비어 텍스트 카드로만 나옵니다 — 정상.)

## ③ 반 상세 총원 (8번 지적) — **할 일 없음**

반 상세 HUD(반상세HTML 14열)는 이미 바인딩돼 있어, 다음 calcAll(14·22시 자동)부터
헤더 우측에 **「👥 12명」 총원 필**이 자동으로 나타납니다. 즉시 보려면 `calcAll` ▶ 1회.

- 리그 카드는 **모두 같은 보드**를 보되 내 행만 다르게 칠합니다(전교 공개 정보 = 이름·포인트뿐, 개인정보 없음).
- 넛지의 "숙제 n번" = 포인트 차 ÷ 10P(숙제 1회) — 격차를 행동으로 번역하는 장치.
- 순위 소스는 기존 월간랭킹(R열)과 **완전 동일**(rankMap) — 컬렉션과 카드 순위가 어긋날 수 없습니다.
