# 글라이드 이관 대장 — 사람 손이 쓰던 입력 칸 전수

> v1.0 · 2026-08-31 · 감사 S4-3 시공. **Glide 는 08-05 폐기됐다**(Code.js 「Glide 는 08-05 폐기라 버튼 계약도 죽었다」).
> 그날 이후 「Glide 소유」로 설계된 입력 칸들은 **쓰는 손이 사라진 채** 엔진에 남아 있다 — 읽는 코드는 살아서 영영 빈 칸을 기다린다.
> 이 대장은 그 칸 전부에 하나씩 판정을 붙인다. **주인 없는 칸을 「이관 예정」으로 포장하지 않는다 — 잇는 화면이 없으면 「끊김」으로 정직하게 적는다**(talk-migration-tail-rule).

## 자(무엇으로 셌나)

- **분모** = 엔진 7파일(`Code.js`·`엔진_수집.js`·`엔진_궤적.js`·`엔진_셋업확장.js`·`엔진_폼리포트.js`·`엔진_콘텐츠AI.js`·`엔진_운영배치.js`) `grep -i glide` **184줄**(08-31 실측) 중 «학생·학부모·강사·원장 손이 쓰던 입력 칸» 전수. 나머지 줄은 표시·바인딩·쿼터·역사 서술이라 입력 칸이 아니다.

## 대장 밖 — 이관이 필요 없는 입력 통로(전수의 나머지)

184줄 중 입력 칸이되 위 표에 없는 것들은 전부 **구글 폼·웹앱·시트 수기 경로**라 Glide 사망과 무관하게 산다:
출석 폼 · 숙제 제출 폼 · 퀴즈 응답 폼 · 대화 폼 · 강의 확인 폼 · 약점 메모 폼(student_errors) · 학업 기록 폼(academic_log 는 시트 직접 입력 겸용) · 차시 마감폼(lesson_close) · 결석 팔로업 폼 · 크루카드 웹앱 · crew_projects(시트 수기).
나머지 glide 줄은 표시(Rich Text·ITE·Visibility)·쿼터 설계·Row ID 보호·역사 서술이다 — 손이 아니다.
