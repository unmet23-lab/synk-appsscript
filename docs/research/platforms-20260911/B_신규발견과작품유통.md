## 1. 핵심 판정

**새로 더할 가치가 가장 분명한 것은 SHIFT의 Behance 포트폴리오와 PULSE의 음원 유통이다.** 전자는 이미 만든 실물을 디자인·제작 의뢰의 맥락에서 발견하게 하고, 후자는 작품을 청취자의 음악 보관함에 넣는다. 음원 3곳을 매일 운영할 SNS 3개로 계산하지 않는다. GitHub와 커뮤니티는 기능이 준비됐을 때 쓰는 제공·참여 통로로, 게임과 앱스토어는 제품 배포로 분리한다.

### 3-2. ‘Suno 유료’에서 빠뜨리면 안 되는 조건

[Suno 약관, Intellectual Property Rights / Permitted Commercial Use](https://about.suno.com/terms)
2. **유통사 수락:** DistroKid는 AI 도구 음악을 수락하지만 필요한 권리 100%, 무단 사칭 금지, 대량 스팸 금지, 비침해를 요구한다. 매장별 거절·삭제 가능성도 명시한다. **유통사 수락은 각 매장 수락 보장이 아니다.** 기존 선택과의 연결이 있어 비교 기준으로 검토한 것이며 가입·요금제 선정은 하지 않았다. 3. **게시 표시와 음원 납품:** 현재 YouTube 안내는 AI 생성 음악을 공개 표시가 필요한 예에 넣고 `AI use` 설정을 설명한다. 이는 직접 올리는 영상의 표시 요구이며, 유통사의 YouTube Music 납품 절차·표시가 완료됐다는 뜻은 아니다. [YouTube GenAI 표시](https://support.google.com/youtube/answer/14328491?hl=en)
4. **권리 자동 주장:** Content ID는 다른 업로드와 소리를 대조해 권리를 주장하는 별도 기능이며 독점적 권리 등이 필요하다. 일반 스트리밍 허용과 동일하지 않다. LAB·SHIFT의 기존 영상 사용에 잘못된 권리 주장이 생기지 않도록 실제 이용권·유통사의 처리 범위를 확인해야 한다. [YouTube Content ID 적격 콘텐츠](https://support.google.com/youtube/answer/2605065?hl=en)

**현재 자료의 기술 주장 중 바로잡아 읽을 부분:** 음악 장부·09-07 결정의 “DistroKid는 MP3/M4A를 받지 않는다”는 표현은 현행 공식 문서와 맞지 않는다. DistroKid는 WAV·MP3·M4A·FLAC·AIFF·WMA를 받는다. 좋은 원본을 보존하기 위해 WAV/FLAC을 택하는 품질 판단과 접수 가능 형식은 다르다. [DistroKid 허용 파일 형식](https://support.distrokid.com/hc/en-us/articles/360013647753-What-Audio-File-Formats-Can-I-Upload)

장부의 과거 요금·최저가·정산 속도·무료 요금제·나중 법인 명의 이전 가능성도 이번 선택의 확정 근거로 재사용하지 않았다. 현재 곡에 맞는 요금·추가 옵션·납품 취소·정산 요건을 비교할 때 다시 확인할 항목이다. 사용자의 한 파일 범위에 따라 **이 지적을 장부나 결정 원문에 직접 수정하지 않았다.**

## 4. SHIFT — 포트폴리오와 회사 확인 경로

### Behance: 현재 가장 먼저 제안할 추가 접점

**공식 사실:** Behance는 AI 생성 아트 프로젝트를 허용하되 커뮤니티 지침과 이용약관을 따르도록 하며, 사용한 도구의 태그·표시를 권장한다. 생성 허용은 타인의 권리까지 해결해 주는 허가가 아니다. [Behance / Adobe Firefly FAQ](https://help.behance.net/hc/en-us/articles/13850092907931-Behance-and-Adobe-Firefly-FAQ), 문서 갱신 2023-03-21, 원문 접근 2026-09-11.

**AI 판단:** 첫 프로젝트는 **‘AI와 함께 SYNK 소개서를 만들고, 읽히도록 고친 과정’**이 적합하다. 최신 09-11 소개서의 실제 지면 → 누구에게 무엇을 설명하려 했는지 → 남겨 둔 실제 이전 결과 → 사람의 수정 이유 → 완성본의 사용 장면·제공 범위를 보여준다. 4개 브랜드별 계정으로 나누기보다 유호/SHIFT의 제작 포트폴리오 한 자리 안에서 사례를 구분하는 제안이다. 명의·기존 계정 여부는 실행 때 확인한다.

타겟은 디자인 결과를 비교하는 창작자, 교육·브랜딩·콘텐츠 제작 협업 상대다. ‘AI가 예쁜 것을 만들었다’만으로 끝내지 않고 수정·선택·인수 품질을 보여주면 SHIFT의 현재 목적을 유지할 수 있다. 완성 소개서가 있다고 고객 매출 효과나 공개 납품 실적으로 표시하지 않는다. 까몽 3D 비채택 사례는 이후 **실험/비채택 표시가 있는 과정 사례**로 적합하다.

초기 부담은 기존 지면·공개 가능한 전후·권리·크레딧을 한 프로젝트로 정리하는 일이며 중간 수준으로 판단한다. 유지 부담은 새 사례·수정·실제 문의가 생길 때 갱신하는 정도다. 포트폴리오의 감상/저장, 실제 제공 페이지 방문, 사례를 이해한 구체적 협업 문의를 구분해서 본다. 조회·좋아요만으로 영업 효과를 선언하지 않는다. 첫 작품을 읽을 수 있는 무료 공개 전시와 유료 의뢰 접수는 별도 준비 단계다.

### Dribbble: AI 작업 전체를 금지한다고 확대하지 않되 현재는 보류

**공식 사실:** 전부 AI로 생성한 콘텐츠를 공유하지 말라고 하며 AI 보조 작업은 기여 표시를 권장한다. Shot에는 디자인 작업을 올리며 홍보 영상·광고·튜토리얼, 상품/서비스 광고와 설명 안의 외부 URL도 제한한다. [Dribbble Guidelines](https://dribbble.com/guidelines), 접근 2026-09-11.

**AI 판단:** 현재 SHIFT의 ‘실제 회사 제작 과정·방법·실물 연결’을 담을 때 제약이 크다. 인간의 디자인 결정·구현이 분명한 UI·타이포그래피·편집 디자인을 해당 규칙에 맞는 독립 작품으로 내고 디자인 의뢰자를 만날 목적이 생기면 재검토할 수 있다. 생성 이미지에 작은 편집을 했다는 이유만으로 허용 범주라고 보증하지 않는다. 첫 제공물은 그 조건을 충족하는 디자인 한 사례이고, 측정은 실제 디자인 의뢰·협업 적합성이다.

### LinkedIn 회사페이지: 개인 프로필을 보완할 조직 안내

**공식 사실:** 무료 Company Page를 만들 수 있고 개인 프로필에서 관리하며, 조직을 대표할 권한을 확인해야 한다. 기존 페이지가 있는지도 먼저 확인하라는 안내가 있다. 페이지 생성과 검증 배지는 다른 상태다. **AI 판단:** 기관·협업 담당자가 저장하거나 내부 공유할 조직 설명이 필요해질 때 **SYNK SHIFT 1개 회사페이지**를 우선 제안한다. 유호 개인 프로필은 작업·사람의 판단을, 회사페이지는 현재 사업 범위·대표 사례·담당·공개된 문의 도착지를 맡는다. SYNK 전체와 LAB/PULSE용 페이지까지 동시 생성하지 않는 이유는 현재 추가 대상과 안내의 차이가 불명확하기 때문이다.
