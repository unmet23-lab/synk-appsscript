# SNS 게시 업무 분담 — 사용자 확정

2026-09-10 KST. 조사 결과 설명 후 유호님이 워크플로우에 동의하고, "네이버 블로그 카카오톡은 예약등록으로 확정하고 이 워크플로우 기억해줘"라고 요청했다.

| 대상 | 준비·검수·게시 분담 |
|---|---|
| 네이버 블로그·카카오톡 채널 | AI가 게시용 본문·이미지·영상·설정 안내를 준비한다. 유호님이 최종 검수한 뒤 공식 편집기/관리자센터에 본문·파일을 넣고 **예약 등록을 직접 수행**한다. |
| Instagram 전문 계정·Facebook 페이지·Threads·YouTube·LinkedIn·Telegram | 공식 연결의 권한·심사·지원 형식을 충족한 체계를 구축한 뒤 최종 콘텐츠 검수 이후 업로드·예약·결과 확인을 자동화하는 방향이다. |

서비스가 직접 요구하는 본인 인증·계정 연결 동의·권한 재승인 등은 필요한 경우에만 유호님이 처리한다. 기존 로그인과 허용된 연결은 재사용한다.

## 적용 범위와 현재 상태

이 문서가 처음 확정됐을 때에는 게시 업무 분담만 정해졌고 자동 업로드 체계·계정 연결·실제 예약·게시 완료는 아니었다. 이후 같은 날 유호님의 후속 요청으로 [검수형 자동발행 시스템](자동발행_구현.md)을 구현했다. 구현 완료는 게시 완료와 다르며, 콘텐츠 해시와 연결된 최종 승인 없이는 발행하지 않는다.

네이버·카카오·Substack은 플랫폼의 공식 편집기/관리자센터에서 최종 검수·예약 등록하는 경계를 유지한다. 자동화 시스템은 이 세 채널의 계정별 본문·미디어·설정값을 묶고 공식 화면을 여는 데까지 맡는다. 새 유료 도구 구매나 무검수 발행의 승인으로 확대하지 않는다.

공식 연결 조건과 정책은 구현할 때 최신 원문 및 실제 계정으로 다시 확인한다. 연구 기준일은 2026-09-10이며 [비교 보고서](보고서.md)와 각 플랫폼 근거 파일에 판단 범위가 있다. 연구 보고서의 당시 권고와 이 문서의 후속 사용자 확정을 구분한다.

현재 직접 연결이 확인된 계정, 추가 인증이 필요한 계정, 수동 예약 경로는 [구현 기록](자동발행_구현.md)의 관측일 기준 표를 따른다. 연결되지 않은 계정을 연결됐다고 세거나 로컬 발행 계획을 실제 게시물로 세지 않는다.
