## 1. 달력 재배치 (M1 = 2027.3 보수 기준 · 2월 소프트오픈이면 전체 1개월 앞당김)

|---|---|---|---|

## 2. 현금 구조 — 2.4억₮의 새 정의

유호님 확정: **2.4억 = CAPEX + 보증금 + 운영비 전부.** 원 산식(2.4억 = 러너웨이 4개월 + 겨울버퍼 3,000~4,800만₮, CAPEX 제외)과 정의가 다르므로 러너웨이는 아래 변수식으로 계산한다:

```
잔여 운영버퍼 = 24,000만₮ − CAPEX·보증금(X) − 선행 번(≈3,000~4,000만 추정)
러너웨이(매출 0 가정, 만재 번 기준) = 잔여 운영버퍼 ÷ 6,100만₮/월
```

예시(X를 모르므로 구간으로): X=4,000만이면 러너웨이 ≈ 2.8개월 / X=8,000만이면 ≈ 2.1개월 — **원 계획이 요구한 "러너웨이 4개월 + 겨울버퍼"에 미달할 수 있다.** 단 이것은 "매출 0" 최악 가정이고 실제로는 M1부터 매출이 흐르므로 실질 버퍼는 더 길다. **X(CAPEX·보증금 합계)를 알려주시면 v2에서 정확히 산출** — 유호님이 이미 감안해 준비하셨다면 숫자 확인만으로 끝나는 항목.

## 3. 가격 시나리오 — G29의 답에 따라 BEP가 갈린다

| 시나리오 | 상품 구조 | 실효 ARPU(누수 10% 반영) | **BEP** | 비고 |
|---|---|---|---|---|
| **A. 확정 가격카드** | 정규 55/47/42만₮ + 회화·영어 유료 애드온 | 46.4만₮ | **131명** | 현 재무의 전제(2026-07-10 잠금) |
| **B. 커리큘럼 문서의 44만 통합** | 44만₮에 영어·원어민 회화 포함 | 44 × 0.9 = 39.6만₮ | **≈154명** (+23명, 설계석 180의 86%) | 애드온 업셀 소멸. 검산: 6,100÷39.6=154.0 |
| **C. 통합 유지 + 가격 조정** | 통합 상품 ~52만₮ | 52 × 0.9 = 46.8만₮ | **≈130명** | BEP 131 유지선. 검산: 6,100÷46.8=130.3 |

**판정**: B(44만 통합)는 BEP를 23명 밀어올려 여름 비수기 통과 체력을 크게 깎는다 — **44만이 실판매가라면 하지 마라.** 통합 상품의 소구력을 원하면 C(~52만 통합)가 BEP 중립이고, 확정 카드(A)를 유지하면 커리큘럼 문서의 비교표만 수정하면 된다. **결정은 유호님 몫** — 문서 자체에 "비교표 금액은 예시, 실제 시세로 유지하라"는 각주가 있어 (a)일 가능성이 높아 보이나 단정하지 않는다.

## 4. 확인 필요 3건 (이것만 오면 v2 확정)

1. **CAPEX + 보증금 합계(X)** — §2 러너웨이 산출용.
2. **임대(공간 계약) 개시 시점** — 개원 몇 개월 전? 선행 번 [추정 3,000~4,000만]을 실측치로 교체.
3. **G29 가격·상품 구조 답** — §3의 A/B/C 중 택1.

> 부수: 겨울 적자 확정치(−1,000~−1,740만₮/월)는 원 감사 정정값을 그대로 사용. 새 달력에서는 첫 겨울(2027.12~2028.2)에 적용되며, 그 시점 재적이 원 계획 겨울 시점보다 높아 실제 적자 폭은 이보다 완화될 가능성이 크다(램프 실측 후 갱신).
