## 2. 현금 구조 — 2.4억₮의 새 정의

유호님 확정: **2.4억 = CAPEX + 보증금 + 운영비 전부.** 원 산식(2.4억 = 러너웨이 4개월 + 겨울버퍼 3,000~4,800만₮, CAPEX 제외)과 정의가 다르므로 러너웨이는 아래 변수식으로 계산한다:

```
잔여 운영버퍼 = 24,000만₮ − CAPEX·보증금(X) − 선행 번(≈3,000~4,000만 추정)
러너웨이(매출 0 가정, 만재 번 기준) = 잔여 운영버퍼 ÷ 6,100만₮/월
```

예시(X를 모르므로 구간으로): X=4,000만이면 러너웨이 ≈ 2.8개월 / X=8,000만이면 ≈ 2.1개월 — **원 계획이 요구한 "러너웨이 4개월 + 겨울버퍼"에 미달할 수 있다.** 단 이것은 "매출 0" 최악 가정이고 실제로는 M1부터 매출이 흐르므로 실질 버퍼는 더 길다. **X(CAPEX·보증금 합계)를 알려주시면 v2에서 정확히 산출** — 유호님이 이미 감안해 준비하셨다면 숫자 확인만으로 끝나는 항목.

## 5. 세 레버 논리 — 급여·코어 인원·가격 (가격_수업표 v3에서 흡수 · 2026-08-09)

> 원문·계산 전문 = `docs/_archive/가격_수업표_추천_v3.md`(2026-07-12 잠금값 기준 — 그 수치는 전부 급여 인센티브 정본 v1.6이 대체). 여기 남기는 것은 **수치가 바뀌어도 유효한 구조 논리**다. 현재 값(고정비·BEP·좌석·ARPU)은 항상 정본에서 읽고, 이 절에는 수치를 다시 적지 않는다.

1. **급여 레버는 분모와 같이 읽는다.** 급여를 낮추면 번(월 고정비)이 내려가 손익분기 하한이 풀리는 것은 맞다. 그러나 코어 강사를 적게 시작하면 재적 천장(분모)이 함께 줄어, 번이 낮아져도 안전마진은 생기지 않는다. 급여·인원·재적 천장은 한 식 안에서만 판정한다.
2. **코어 강사 +1의 값어치는 분자가 아니라 분모에 있다.** 강사를 1명 늘리면 번(분자)이 늘지만 재적 천장(분모)이 더 크게 열려 손익분기 하한 ARPU가 내려간다 — v3 계산에서 안전마진을 구조적으로 만든 유일한 레버였고, 겨울·최악 시나리오 생존을 가른 것도 이것이다. 단 **선확정 금지**: 강사 인건비는 재적이 붙기 전에 먼저 나가는 고정비라, 파일럿에서 오후·저녁 순증 수요가 실측된 뒤에 붙인다(수요 없이 붙이면 빈 좌석 위에서 번만 태운다).
3. **가격으로는 안전마진을 만들 수 없다.** 하한 ARPU에 목표 마진을 얹어 가격을 역산하면 대표 상품이 지불의사 이론 상단을 넘는다(v3에서 실제로 초과가 나 그 역산을 폐기했다). 인상은 WTP 실측(파일럿) 후에만, 인하는 캐파 확장과 세트로만 발동한다 — 미실측 상태의 인상은 BEP 인원을 줄이는 대가로 수요를 깎는 도박이다.
4. **쿠션은 충원율 가정의 중앙·하단에서도 잰다.** 「현실 재적」을 캐파 범위 상단으로 잡으면 상단에서만 흑자인 구조(만석 의존)가 건강해 보인다. 겨울(−40°C 출석 붕괴)은 정상 누수와 별도 시나리오로 재고, 방어는 가격이 아니라 선수취 창(§1 달력)·온라인 전환·캐파 레버로 설계한다.
