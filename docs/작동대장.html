Ⅷ안 잰 축 — 이 화면이 «모르는» 것

0 과 「안 쟀다」는 다르다. 여기 적힌 것은 이 판에서 일부러 빼거나 못 잰 축이다 — 화면의 초록을 이 목록과 함께 읽는다.
  1. 부품 47줄의 개별 작동 — 「부품 → 파일」 자동 매핑이 안 선다(대장의 «최근» 버전 태그로 커밋을 못 찾는다 · 실측 08-17: v9.245 실패). 그래서 다섯 통은 장치 층만 본다.
  2. 형제 저장소(SYNK-talk)의 엔진 도달 — 일부러 안 읽는다. 그 저장소의 작업본을 물면 값이 진동한다(F537 의 원인 후보). 읽어야 할 때는 git show origin/master: 로만.
  3. 훅·도구의 실제 발동 횟수 — tools/훅발동.js 가 따로 잰다. 그 값은 transcript 시각에 의존해 이 판에 섞으면 수렴이 깨진다.
  4. 「부른다/지킨다」의 정확도 — 이름 일치라 스쳐 지나간 언급도 센다. 그래서 이 화면은 초록 쪽을 근거로 안 쓰고 0 인 쪽만 신호로 쓴다(거짓 초록보다 거짓 빨강이 안전하다).
  5. 「오래 안 봤다」 시간 축 — 일부러 뺐다. 「낡음」은 시간이 아니라 지금 방향과의 정합이다(유호 확정 08-17). 「마지막 손댐」 열은 참고이지 판정이 아니다.
  6. 「학생이 실제로 더 잘하게 됐나」 — 학생 0명이라 못 잰다(철학 정본이 같은 이유로 게이트에서 뺐다).
