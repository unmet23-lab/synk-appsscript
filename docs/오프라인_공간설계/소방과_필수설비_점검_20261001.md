## 꼭 필요한 현장 확인 — 추가 장식 구매보다 먼저

1. **임대 전**: 합법적인 교육/댄스 용도, 사용 승인 자료와 층 전체 실측, 보호된 계단/지상 출구, 난방·외기·배기·화장실 배관·전력 용량, 건물 기존 경보/소화/방화 구획 자료와 임대인의 공사 승인. 구조/소방상 해결이 어려운 물건은 예쁜 평면보다 먼저 걸러낸다.
2. **설계 견적 전**: 현지 자격 있는 건축·전기·기계·소방 설계자가 정원·용도·문·출구·거리·소방 설비·접근성을 검토한다. 증설과 임대인 부담 범위를 계약서에 명확히 두고, 기존 설비를 사용할 수 있다는 구두 설명만으로 견적을 줄이지 않는다.
3. **벽·천장 닫기 전**: 회로/접지·배관 누수·실외 배기, 방화 구획 관통부, 커튼/패널 화재 시험자료, 상부 장비 앵커와 안전 와이어, 차폐된 감지/스프링클러가 없는지 확인한다. 가습기/커피 전열기는 PC·음향 회로와 부하를 함께 계산한다.
4. **인수 전**: 정전 시 비상조명/표지·잠금 해제와 내부 퇴실, 수신반/발신기/감지기 시험, 닫힌 교실·댄스 음악·VR 중 경보 인지, 실제 사람이 모든 사용 모드에서 출구까지 이동하는 시험. 필요한 관할 검사·사용 승인·시험성적/설치 기록을 인수한다.
5. **운영**: 매일 출구/통로·장비/케이블·소화기 접근·수신반 이상·누수를 확인한다. 연2회 이상 대피 교육/훈련과 기록. 담당자·대피 후 집결/인원 확인·방문자 안내를 정한다. [NEMA 2026-09-08 안내](https://nema.gov.mn/post/179775)의 화재101은 개원 전에 주소·연락망과 함께 재확인한다.

공기청정기는 외기 환기를 대체하지 않는다. 기존 C26 환기·C29 난방·C31 설비 시험 예산을 먼저 실제 성능으로 검증한다. AED·방마다 새 CCTV·CO₂ 측정기·탈출 사다리를 법정 필수라고 임의 추가하지 않았다. 건물 유형상 요구되거나 실제 결함을 해결할 때 별도 근거와 견적으로 추가한다.

## 예산 반영과 완료 범위

- 예산 수정4: 세부 품목159행, 운영대조140행. 기존 분말2대 계획액은 유지, **추가 소화기1대는 가격 미정**이다. SITE-FIRE에 경보·유도·비상조명·피난/출입문·방화 검토 범위를 명시하고 추가개원자금 K08의 검토 적용을 필수로 바꿨다.

- 구급함·위생 비품·디퓨저·환기/조명은 기존 예산 범위의 기능을 3D에 표시했다. 모델에 새로 그렸다는 이유로 같은 물품을 다시 구매 합계에 넣지 않았다. 실제 제품이 벽걸이 형태를 지원하지 않으면 접근성을 유지하는 배치와 차액을 재견적한다.

현재3D에 창문은 미반영이며 실제 현장 존재/개폐는 미확인이다. 전실 외기 공급·회수/배기·실외 흡배기·풍량·동결/결로·소음·정비는 기존 C26 계획을 실제 설계/시운전으로 검증한다. [방별 디자인의 창문·환기·향 후속 검토](방별_인테리어_디자인_20260929.md#창문방별-환기은은한-향--2026-10-01-후속-검토)를 함께 본다. 향은 환기·냄새 원인 제거의 대체가 아니다. 전실 비누향 희망은 기록하되 제품/설치/추가비 확정 전이며 교육 공간 무향을 권장하고 민감 사용자 발생 시 제거한다.
