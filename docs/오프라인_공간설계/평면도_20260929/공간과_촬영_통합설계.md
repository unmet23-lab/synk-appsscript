# SYNK LAB — 공간과 촬영 통합 설계

2026-10-02 현행화. [오프라인 운영 기준](../오프라인_운영기준_20261002.md)을 공간·시설·촬영에 적용한다. **닫힌 강의실4곳, 열린 A+B의 신청25명 댄스, 빈 강의실 예약 자습**을 현재 방향으로 삼는다. 울란바토르 공간은 미선정이며 임대면적·시공·허가·정원·새 전체3D·CAD·견적은 미확정이다.

## 1. 현재 A+B 가변 교실 후보

큰 강의실과 작은 강의실 사이의 가변 칸막이를 구체화한다. 25명 신청 댄스와 닫힌 강의실4곳을 유지하고, 초기 댄스는 다른 한국어 수업과 음악 시간을 분리한다. 자동 칸막이·특수 마감은 기본 구매로 잡지 않는다. 정상 수업의 말소리 차음, 패널 지지·잠금·보관과 이웃 진동 검토는 필요하다.

## 3. 빈 강의실 무료 자습

현재 재학생이 **실제로 비는 교실의 좌석을 예약**해 이용한다. 하루 약2~3시간은 예상이며 방별·매일 제공 보장이 아니다. 전용 자습실·K라운지·백색소음·상시 스낵바는 만들지 않는다.

- 방·일자·시작/종료·좌석·학생을 담당자 예약표로 확인한다. 앱 예약은 후속 구현·권한/중복/취소 시험 뒤 연결한다.
- 수업·보강·청소·촬영 준비·가구/칸막이 전환·학생 인계 시간에는 예약하지 않는다.
- 현장 담당자가 있는 시간만 공개하고 다음 수업 전에 종료한다. 기존 책상·의자·Wi-Fi·안전한 전원을 사용하며 바닥 충전선과 음식으로 통행을 막지 않는다.
- 자습 중 학생을 촬영·녹음하지 않는다. 물·준비된 다과는 공용 코너의 실제 운영 범위다.
- 예약 변경·취소·입퇴실·다음 반 준비를 실제로 시험한다. 무제한 입실·대기 공간·조용함을 보장하는 새 서비스를 추가하지 않는다.

## 4. 시간표와 소음

25명 댄스는 모든 한국어 수강생의 자동 참여가 아니라 **신청 정원 회차의 무료 문화 혜택**이다. 보컬·뷰티 상시 운영, 하루10/13/17시 무제한 문화 참여와 여러 기수·학부모가 모이는 내부 정례 대형 행사는 기본 운영안에서 삭제한다. 발표는 해당 반 수업 안의 작은 작품 공유로 한다.

초기 댄스는 다른 한국어 수업이 없는 고정 시간에 잡는다. 가구32세트 전환·입실/하원·강사·감독·복구·근무를 모두 배정해야 한다. 19:50 댄스/21시 마감은 비교 이력이며 확정 시간표가 아니다. 실제 동작·겨울 짐·의자/카트로 전환 시간을 측정하고 휴식·교대0분인 시간표를 쓰지 않는다.

닫힌 A/B의 두 한국어 수업은 동시에 말하므로 정상 말소리 차음과 틈/천장/덕트 우회 전달을 확인한다. 음악 시간을 분리해도 아래층·이웃의 발구름·저음 문제는 남는다. 거울 커튼·흡음 패널이 차음/진동 공사를 대체한다고 계산하지 않는다. 현장과 임대 조건이 맞지 않으면 해당 매물/사양을 수정하고 실제 외부 스튜디오 고정 회차의 비용·인계도 비교한다. 25명 정원을 임의 축소하지 않는다.

전체 재실은 실제 명단으로 중복을 뺀다. 4반×16명=64명인 비교에서 같은25명이 남으면 학생64명 이내이고, 다른25명이 조기 도착하면89명까지다. 직원·보호자·상담 방문은 별도다. 예약25명과 건물 최대 인원은 다르다. 복도·계단·건물 밖을 상시 대기실로 쓰지 않는다.

## 5. 방별 마감과 필수 설비

[방별 디자인 원문](../방별_인테리어_디자인_20260929.md)의 승인 요소를 계승한다. A는 서측 거울+커튼·이동 화면·무광 탄성 바닥·어두운 촬영 배경·코랄 승인 사인·분리 조명, B/C/D는 같은 중립면/목재/패브릭과 좁은 실색 표식으로 묶는다. 실제 거울 폭과 패널/문/창·조명 위치는 새 매물에서 확정한다.

일반7실(교실4·사무실·상담실·사진/음료)에 공기청정기·가습기 각각1대씩, 총7대씩을 기본 계획 수량으로 둔다. 용량과 청소·급수·건조·필터 교환은 새 면적/인원으로 선정한다. 화장실2곳은 독립 배기·급기이며 각1개 총2개 디퓨저는 건식 기존 상판에 둔다. 일반실의 비누향은 실제 제품과 민감한 이용자의 무향 선택을 확인한 뒤 적용하며 전실 디퓨저7개를 필수 구매로 자동 추가하지 않는다.

**창과 환기:** 현재 실제 외벽/창은 확인하지 않았다. 일반 교실·사무실·상담실은 외벽 접근과 자연광/외기 경로가 좋은 매물을 우선 검토한다. 필요한 외기량·배기·겨울 난방·결로·운전 소음을 인원과 현장 설비로 산정한다. 공기청정기·가습기·향은 환기를 대신하지 않는다. 창이 없는 방을 도면의 창 기호만으로 해결하지 않는다.

**안전/위생:** [소방과 필수설비 점검](../소방과_필수설비_점검_20261001.md)의 기존6안 소화기3대·문/비상등 등은 이전 초안이다. 새 최대 재실·실측에 맞춰 감지/경보·유도/비상조명·외부까지 피난·문/출구·소화기 종류/수량/위치를 현지 설계와 인수로 확정한다. 구조 지지·전기/접지·접근성·화장실 기구·방수·바닥/소음·근로/보험/허가 적용·학생 보호 조건을 비용 때문에 삭제하지 않는다.
