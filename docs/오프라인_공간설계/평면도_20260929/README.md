# SYNK LAB 평면 설계 입구

2026-10-02 현행 기준은 [오프라인 운영 기준](../오프라인_운영기준_20261002.md)과 [공간·촬영 통합 설계](공간과_촬영_통합설계.md#flex-classroom-20261002)다.

- 닫힌 강의실4곳, A+B 각 개인16석 목표·열린신청25명 댄스, 사무실6~8개인 자리·iPad상담/예약VR·사진/음료·남녀화장실을 계획한다.
- 무료 자습은 빈 강의실 좌석 예약이며 하루 약2~3시간은 예상이다. 실제 시간표·현장 담당 가능 시간만 제공한다. 전용 자습실/로비 라운지·무제한 문화/다과·내부 대형 행사는 기본 운영에 넣지 않는다.
- 새 A+B13.2×11m·145.2㎡는 모듈 비교안이다. 가구32세트 수납12~16㎡·패널 포켓/구조·환기·출입·소음·전체 약102~104평의 매물 적합성은 미확정이다.
