# SYNK LAB 이전6안 입체 개념 보기

2026-10-02 안내 현행화. **이 전체3D는 이전81평·A20평 형상이며 현재 A+B 가변 교실/신청25명 댄스가 미반영이다.** 현재 기준은 [운영 기준](../오프라인_운영기준_20261002.md)·[A+B 공간/촬영 설계](../평면도_20260929/공간과_촬영_통합설계.md#flex-classroom-20261002)다. 새모듈 열린145.2㎡·전체 약102~104평은 비교, 실제 매물·정원·시공CAD·새전체3D·견적은 미확정이다.

무료 자습은 기존 빈 교실 예약이며 하루 약2~3시간은 예상이다. 새자습실/라운지·무제한문화·내부대형행사 공간을 추가하지 않는다. 아래 모형은 이전 방/가구/시설을 살펴보는 이력이고 현재 공간 적합성의 증거가 아니다.

## 이전 모형과 검증의 범위

6안의 좌표를 읽어 만든 회전·확대 가능한 3D 개념 배치다. 남자 화장실과 여자 화장실을 별도로 두고, 기존 남측 방들을 재배치했다. 실측 모델, 시공 CAD, 설치 도면이나 제품 선정 결과가 아니다.

- 보기: [synk-academy-3d-preview.html](synk-academy-3d-preview.html)
- 좌표 원본: [공간과_편의시설_좌표_6안.json](../평면도_20260929/공간과_편의시설_좌표_6안.json). 3D 빌드는 원본을 수정하지 않는다.
- 검사 결과: [verification-3d.json](verification-3d.json)
- 재생성: `node docs/오프라인_공간설계/입체개념_20260929/build-3d.cjs`
- 표시·조작 재검사: `node docs/오프라인_공간설계/입체개념_20260929/verify-3d.cjs`

전체와 9개 방, 입구·복도를 선택할 수 있고, 드래그로 회전하거나 휠·두 손가락으로 확대한다. 첫 화면은 큰방 A의 **댄스·전면 거울 열림**이다. 큰방의 수업/댄스와 상담실의 VR/4인 상담을 각각 바꿀 수 있다. 각 화장실 보기에는 접근통로와 독립 출입구를 함께 보여 준다. Three.js `0.180.0`, OrbitControls, Reflector를 jsDelivr CDN에서 읽으므로 **인터넷 연결과 WebGL 지원 브라우저가 필요**하다. 좌표는 HTML에 포함되어 있으며 외부로 전송하거나 별도 API에서 읽지 않는다. 외부 라이브러리는 고정 버전의 코드 리소스다.

## 좌표와 표현 범위

- 외곽 19 × 14.1 m, 267.9㎡, 약 81.0평. 강의실 4개, 사무실, 상담실, 사진·편의실, 남자·여자 화장실과 주복도 1.6 m, 화장실 접근통로 1.2 m를 표시한다. 북측 A/B/C와 주복도는 5안과 같다.
- 개인 학습 책상은 교실마다 16개로 총64개, 업무 책상은8개. 공기청정기 AP와 가습기 H는 기존 7개 방에1대씩 총14대다. 화장실에는 AP/H와 카메라를 추가하지 않는다.
- D는 5.75 × 5.20 m, 사무실은 4.00 × 5.20 m로 바뀌었다. D 학생 좌석은 서쪽 화면을, 사무실 8개 좌석은 양측 벽면 모니터를 향한다. 의자 등받이와 모니터 방향은 좌표 원본의 `facing`을 사용한다.
- 좌표 JSON의 평면 위치·폭·깊이를 사용했다. 높이는 실물이 아닌 형상을 이해하기 위한 가정치다.
- **벽 전체 높이2.8 m는 미측정 가정**이다. 바닥과 가구를 보기 위해 벽은 하부0.96 m까지만 불투명하게 그리고, 위쪽은 선으로 위치를 표시했다. 낮은 벽을 시공한다는 뜻이 아니다. 천장은 생략했다. A의 거울은 잘린 일반 벽과 구별되도록 가정 높이2.4 m 전체를 표시한다. 문이 있는 벽 구간은 원안대로 열려 있다.
- 바닥은 밝은 중립 회색, 벽은 흰색, 가구는 오크 계열의 개념 색이다. 중립 조명으로 배치를 읽는 용도이며 실제 재료·조명 시뮬레이션은 아니다. 앱 다크모드에서 화면 대비를 조정한다.
- 작은방은 최신 방별 디자인과 동일하게 B Lapis, C Meadow, D Butter를 중립 패브릭의 작은 봉제 표식으로만 표현한다. 이전 청록·베이지·라벤더 색과 벽 전체 길이의 색띠는 제거했다.
- 카메라C는 기존 중앙통로 상부 고정 후보를 표시한다. 모형의 카메라·브래킷 높이는 **위치 관계를 보여주는 상징적 높이**이며 안전 높이나 얼굴 구도를 결정한 값이 아니다. 화면 캡처가 수업 자료의 원본이며, 카메라는 교사를 향한다.
- A 전면 거울·커튼과 이동형 화면 후보, 후면 다크 배경·코랄 사인 위치를 구분했다. 수업에서는 북벽 거울 앞 커튼을 닫고 개인 책상·의자16개씩과 전면 TV를 표시한다. 댄스에서는 커튼을 양끝으로 걷고, TV를 동쪽 도킹 후보로, 책상·의자를 동쪽 수납 후보로 옮긴다. 거울은 폭9.4 m·높이2.4 m의 모형이며 패널 이음과 3D 장면 반사를 보여 준다. 이는 실제 거울 제작높이나 반사 시야·왜곡·촬영 품질을 검증한 결과가 아니다.
- A 댄스 수납은 **책상카트2개 × 접은 책상8개, 의자묶음4개 × 의자4개**로 총16개씩을 모형에 남긴다. 책상은 두께0.12 m로 접힌다는 가정에 따라 수평 적재하고, 빈 카트2개도 수업 모드의 동측에 표시한다. TV 도킹의 전체 후보 외곽과 받침은 좌표 원본을 따라 표시한다. 2열 수납의 꺼내는 순서, 실제 하중·접힘·적재높이·전도 방지·카트 회전·TV 이동 경로는 미검증이다. **화면상의 커튼·TV·가구 모드 전환은 확인했으나 실제 수납 성립이나 댄스 활동정원·안전 여유를 확정하지 않았다.**
- 상담실 VR 비움은 2 × 2 m 바닥 영역이다. 테이블과 의자4개를 북측에 접어 보관하고 상부 선반을 둔 가정이다. 실제 접이 제품의 묶음 크기·선반과 가구의 수직 간섭·전도 방지·VR 기기/콘텐츠별 경계와 활동 여유를 검증한 것은 아니다.
- 사진실 앞1.5 m는 커피·다과/출입, 뒤3.7 m는 사진·정비 용도다. 추가된 뒤쪽1.1 m는 소모품장과 정비 여유이며 별도의 방이나 분리벽을 추가하지 않았다. P는 분리판 뒤 고정면의 카메라·조작패널 후보이며 바닥 키오스크의 점유는 포함하지 않았다. 실제 촬영거리·렌즈·공동촬영 구도·프린터 급지·배출·점검 공간 및 고정면 구조는 미검증이다.
- 남녀 화장실은 각각 2.15 × 2.475 m의 1인 잠금실 초기안이다. 양변기와 세면대를 각1개씩 표시하며 두 변기는 가운데 공유 배관벽을 등진다. 접근통로에서 각 실로 독립 출입하고, 문은 벽 안으로 들어가는 미닫이 후보다. 문 수납선, 변기·세면대·거울·닫힌 상부 소모품장을 표시했다. 양변기/세면대는 기호형 모형이며 제품을 선정한 것이 아니다.
- 화장실 바닥의 지름1.5 m 원은 제안 기구 외곽과의 회전 여유를 살피는 표시다. 실제 접근성, 변기 측면 이동, 손잡이, 무릎 공간, 기구 수 적정성이나 법규 충족을 인증하지 않는다. 배수·급수·외부 배기·방수·구배·점검구는 실측과 현지 설비 설계가 필요하다. 벽 안 문 수납이나 공유 배관벽 두께도 미확정이다.
- 공기청정기·가습기는 미선정 단순 모형이며 성능, 흡배기, 급수, 청소와 제조사 이격 기준을 반영하지 않았다. 분무는 전자기기나 사람을 직접 향하지 않도록 실물 선정 후 확인한다.

- 좌표 원본의 `operations`를 직접 읽어 바닥 가구14개, 상판·내부 소품6개, 벽 안내·충전 항목13개와 바닥 표시2개를 반영한다. 방별 설명에도 해당 시설을 표시한다. 각 물체는 원본 ID를 한 번만 렌더링한다.

- 교실별 교사 장비함과 마이크 충전 자리4곳을 추가한다. B/C AP는 북서쪽, H는 북동쪽으로 옮긴 최신 좌표를 따른다. 실제 물기 이격과 전기·통신 설치는 기기 선정 후 검토한다.
- 상담실 뒤쪽의 세척대는 높이1.85 m **닫힌 관리장 내부**에 상판0.9 m로 계획한 후보다. 옆 잠금 청소장과 함께 표시하며 상담/VR 종료 후 사용한다. 3D에서는 닫힌 외관을 보여 주므로 내부 배관이나 세척 구조를 검증한 것이 아니다. 댄스 수업은 갈아입고 오는 운영이며 상담실을 탈의실로 전환하지 않는다.
- 사무실 남쪽에 낮은 재고장과 A4 복합기, 각 업무석에 작은 서랍을 둔다. 프린터는 상판 소품1대로만 표시해 중복 배치하지 않는다.
- 사진·편의실에는 정수기·커피머신·물병 놓는 면·소량 포장 다과·하부 컵 수거와 우산 물받이를 표시한다. 하부 수거함은 편의대 안에 들어가는 개념이며 외부에서 내부 전부가 보이는 모형은 아니다. 앞쪽0.75 × 1.10 m는 1인 이용 검토 외곽선이고 실제 매트나 추가 가구가 아니다. 북쪽 문은 **동쪽 포켓으로 수납하는 수평 미닫이 후보**로 바뀌었으며 유효폭0.85 m는 제품 미선정 가정이다.
- 입구·복도에는 평탄 매트, 오늘 수업 안내, 문 옆 상태 표시, ‘지나간 말들’의 얕은 카드 패널만 둔다. 복도 바닥에 행거·카트·수납장을 추가하지 않는다. 벽체 상부 생략 때문에 패널 일부가 떠 보일 수 있으나 실제 부착 위치를 표현한 것이다.
- 신설 시설의 높이·제품 적재량·문 인출·공조·급배수·설비 정비·동시 사용은 미확정이다. 외곽 배치 대조와 실제 설치·운영 검증을 구분한다.

## 등하원·출퇴근 후속 보완

기본 보기는 수납을 닫아 단정하게 유지한다. 해당 방의 **수납 내용 보기**를 켜면 장을 반투명으로, 벽을0.24 m까지 낮춰 내부의 위치를 보여 준다. 실제 문이 열리는 모습이나 인출 가능성을 재현한 것은 아니다. 끄면 기존 불투명 장과0.96 m 벽 표현으로 돌아간다.

- 추가 바닥 가구0개, 기존 바닥 가구14개 유지. `containedItems`16개는 대여 펜 트레이4곳(펜2개씩 총8개), 일반 분실물함1개, 잔음료통1개, 물통 세척·건조 도구1세트와 기존 장 내부의 용도 구획이다. 용지·학생 서류·귀중 분실물·토너·밀폐 다과와 청소 도구 구획은 선으로 구분하며 새로운 가구/구매 수량으로 합산하지 않는다.
- 사무실 분실물 상자와 귀중 분실물·학생 서류의 잠금 구획을 분리한다. 편의대 하부는 기존 빈 컵통과 잔음료통을 서로 다른 위치에 표시한다. 물통 전용 도구는 상담실 청소장 상부에1세트이며 약품·청소용 물받이와 분리한다. 실제 물통7개를 동시에 건조할 수 있다는 뜻은 아니다.
- 직원 책상8개의 좌표상 높이0.72 m를 사용한다. `staffCompartments`24개를 **8자리의 가방·잠금 서랍·PC 후보**로 묶는다. 기존 임의 서랍을 제거하고 원본 내부 좌표로 바꿨다. 가방칸과 접은 외투는 대체 사용 가정이다. PC는 실제 본체가 아닌 외곽선, 무릎·발 후보는 초록 바닥 표시다. 상판0.05 m와 모서리 지지부는 도형 가정이며 실제 책상 구조·의자 자세·레일·열배출·케이블 여유를 확인한 결과가 아니다.
- 운영 표식은 기존 장의 작은 문자 계획으로만 설명하며 새 입간판이나 바닥 물체를 추가하지 않는다. 교실별 대여·반납, 분실물/서류, 잔음료/빈 컵, 물통용/청소용 구분을 짧게 표시한다. 교대·관리·개점/마감은 설명이며 출결·예약·전원을 자동 처리하는 시스템 구현이 아니다.
- 숨겨진 소품의 위치·수량은 해당 방의 펼침 설명에서 확인한다. 방을 바꿔도 수납 보기 선택을 유지하며 기본 초기값은 닫힘이다. 호환되는 기존 사용자 선택만 복원한다.

## 검증 근거

실제 Microsoft Edge의 WebGL 화면으로 전체/방9개/입구·복도를 폭780·390·320 px에서 확인했다. 33개 기본 캡처와 폭별 상담 모드3개, 다크모드 캡처를 저장했다. 글자 최솟값12 px, 가로 넘침 없음, 브라우저 오류·경고·CDN 요청 실패0을 확인했다. 방9개·책상72개·AP/H14대·수업카메라4대·양변기2개·세면대2개 개수와 화장실별 AP/H·카메라0을 검사한다. 각 화장실 보기에서 양변기·세면대·독립 출입 라벨 및 접근통로를 확인했다. 상담 모드 전환, 마우스 회전·휠 확대, 교실 상부 카메라C 및 사진실P/사진영역 라벨도 검사한다. 실제 픽셀 읽기로 빈 WebGL 캔버스가 아님을 확인했다. 전체·남녀 화장실·D·사무실·사진실 캡처를 직접 보고 새 좌표와 기구 방향을 확인했다. 운영 보완에서는 모든 선택 화면의 시설 ID가 원본과 일치하며 누락·중복이 없는지 추가 검사하고, 상담실·사진실·사무실·교실 외투장·복도 안내를 실제 캡처로 대조했다. 시공 가능성, 실제 광학, 사람 통행·피난·VR 안전 검증과는 별개다.

큰방 후속 수정에서는 같은3개 폭에서 수업/댄스6개 화면을 추가 확인한다. 거울 전체 라벨·커튼 상태·전면 수업석16개↔동측 책상16개/의자16개 수납 합계·TV 도킹·초기 A 댄스 보기를 검사하고 다크모드 A도 확인한다. 이전 모형의 거울은 하부1.05 m만 불투명하고 상부1.35 m가18% 투명인 낮은 회청색 면이라 일반 벽처럼 보였다. 이를 전체 높이의 거울과 명확한 사용 모드로 교정했다. 이전 저장상태에 큰방 사용 모드가 없으면 새 초기 보기를 적용하며, 새 사용 모드를 포함한 선택만 복원한다.

수납 보완에서는 A·사무실·사진실·상담실의 내용 보기를3개 폭에서 열고 닫아 **12개 추가 캡처**를 확인한다. 내부16항목과 직원24구획이 원본과 일치하며 중복 렌더링되지 않는지 검사한다. 내용 설명의 가로 넘침, 소품 표시/숨김, 방 전환 시 선택 유지와 화장실에서 수납 효과가 적용되지 않는 것도 확인한다. 기본 보기의 A 거울/수업, 상담/VR, 문, 방 수와 주요 장비 수량 회귀 검사도 통과했다. 반투명 장 속 분실물·물통 도구, 편의대의 잔음료/빈 컵, 교사 장의 펜과 직원 구획을 실제 캡처로 확인했다.
