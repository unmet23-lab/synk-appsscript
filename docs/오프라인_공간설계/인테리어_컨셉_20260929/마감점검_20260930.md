## 유지한 배치와 마감

- 5안 좌표의 TV·책상·의자 방향은 서로 맞는다. A/B/C는 북쪽, D는 서쪽을 수업 정면으로 사용한다.
- 네 교실은 내부 통로 상부의 수업 카메라 후보를 유지한다. 교사의 설명 위치를 향하며 바닥 삼각대로 바꾸지 않았다.
- 사무실의 개인 업무 자리, 중앙 통행, 닫힌 서류 수납은 이번 검수에서 새로 확인된 시각적 오류가 없어 유지했다.
- 메인룸의 밝은 수업면·어두운 촬영면, 원본 코랄 사인, 로비 없음, 약74.7평,5안 가구·기기 좌표와 수량을 유지했다.

## 실제 공간에서 확인해야 하는 부분

1. A 책상·의자16세트와 이동형 화면의 수납/도킹. 생성 이미지의 적재 모습은 수납량 증거가 아니다.
2. 상담실 VR2×2m 비움과 팔·컨트롤러의 주변 여유, 접은 가구·AP/H와 실제 문 사용. 실측·기기 선정 전 성립 여부를 확정하지 않는다.
3. 착석·기기 가동 중 실제 통행과 필터/물 보충 접근. 좌표상 외형 비충돌과 서비스 공간 확보는 다르다.
4. 교실 카메라의 실제 렌즈·높이·상반신 구도, 화면 반사와 얼굴광. 원근 이미지로 화각을 확인할 수 없다.
5. 생성 이미지에 남는 섬유·바닥의 잔질감. 실제 사양은 무늬 없는 중립 패브릭과 균일한 무광 바닥이며 샘플을 대조한다. 일부 사진의 보이는 좌석 수·문 위치·장비 크기도 배치 근거는 아니다.
