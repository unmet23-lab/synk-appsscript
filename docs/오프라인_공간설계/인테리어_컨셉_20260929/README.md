# SYNK 방별 인테리어 컨셉 이미지

2026-10-02 안내 현행화. 색·재료·조명과 승인 자산은 계승하고 [현재 운영 기준](../오프라인_운영기준_20261002.md)·[A+B 가변 공간](../평면도_20260929/공간과_촬영_통합설계.md#flex-classroom-20261002)을 따른다. **AI 이미지·전체81평6안 도면·전체3D는 이전 형상/분위기 비교 자료이며 현재 A서측 거울·A+B32세트 수납/25명댄스의 완성 사진이 아니다.** 디자인북의 상세 원문은 최신화하고 이전 전체도/방 이미지의 범위를 표시한다. 실측CAD·시공·장비/예약 운영 완료로 사용하지 않는다.

사진 프레임의 전환만 이 디자인북에서 작동한다. 월 이용권·로그인·촬영·파일 저장·인화·SYNK WORLD 연동은 구현하지 않았고 없는 주소로 연결하는 QR은 넣지 않았다. 디지털 저장/QR 전달과 인화의 실제 제공 방식은 미정이다. `YYYY.MM.DD`·`2026.10.DD`는 촬영일 입력 자리로 표시했으며 실제 촬영 날짜가 아니다.

[운영시설 장](디자인북.html#operations)은 방별 상세 원문의§18 외투·가방·급수·청소·출력·장비 보관과§20 모드 전환·개원 전 사용 확인을 접이식 상세로 함께 보여 준다. 이전6안 좌표·도면은 비교 이력으로 표시하며 실제 가구 수납량·배관·환기·관리 동작은 실측과 제품 확인에서 검증한다.

## 하루 운영

[하루 운영 장](디자인북.html#daily)은 방별 상세 원문의§21 학생 등하원, §22 직원 개점·식사·교대·마감, §23 최소 준비물을 연결한다. 학생/직원 버튼은 설명 흐름만 바꾸며 출결·출퇴근·예약 시스템이 아니다. 일반 반 교대10분·기존A16세트 전환20분은 과거 일정 가정이고 현재A+B32세트/패널 전환·복구는 다시 측정하며 실제 인원·가구를 사용한 측정 후 조정한다.

주소·연락처·날짜·담당자는 미입력 상태이고 가짜 지도/QR을 넣지 않았다. 직원용 개점·마감 카드는 기존 장 안쪽에 두는 시안이며 입구A3판과 별개다. 빈 확인란은 사용 전 양식이고 실제 운영·개원 검증 완료 기록이 아니다. 일반 수업은 일괄 신발 교체를 의무로 두지 않고 매트에서 정리하는 초기안, 댄스는 깨끗한 개인 실내 운동화 초기안으로 바닥·현지 조건 확인을 남겼다. 실제 실물 시험·학생 관찰·구매 완료 결과는 아직 없다.

최신 원고를 `node build-designbook.cjs`로 반영한 뒤 `node verify-designbook.cjs --day-only` 검사를 통과했다. 320/390/1280폭에서 두 흐름6상태와 카드·준비물15보기를 확인했고, 빈 확인란12칸·미입력 방문 안내6항목·준비물5묶음·원문 상세 펼침·상단 메뉴·로컬 링크에서 오류가 없었다. 위 모바일/데스크톱 캡처 중6개를 직접 열어 글씨·빈칸·여백·잘림을 확인했다. 이전 방별 전체 검사는 [검증 기록](디자인북-검증.json)에 보존하고, 이번 검사 범위는 `dailyOperations`에 구분했다. 실제 인쇄물·현장 운영 시험은 하지 않았다.

AI 이미지의 가구 개수·문 위치·기기 비례는 구매/시공 근거로 쓰지 않는다. [6안 좌표](../평면도_20260929/공간과_편의시설_좌표_6안.json)와 입체 보기는 외곽 19×14.1 m, 267.9㎡·약81.0평 제안이다. 각 교실 개인 책상16개, 사무실 개인 책상8개, 비화장실7곳 공청7대·가습7대를 배치하고, 남녀 화장실은 별도 독립 배기를 계획한다. 화장실에 카메라나 가습기를 추가하지 않았다.

6안에서 D·사무실·상담·포토실의 치수와 일부 출입·가구 배치가 달라졌다. D는 북서쪽 출입, 사무실은 양 벽4석씩, 상담실은 2.6×5.2 m, 포토실은 앞1.5 m와 뒤3.7 m의 촬영·수납·정비 구획으로 제안한다. 기존 여덟 공간의 이미지는 마감 분위기를 이어 보기 위한 자료다. 새 화장실 두 이미지 역시 생성 모델이 표현한 변기·세면대 방향을 정확한 좌표 렌더로 보지 않는다. 실제 의자 사용 영역·가구 수납·제품 이격거리, 화장실 배관·배기·방수·접근성·필요 기구 수는 실측과 제품·현지 설계 확인이 필요하다.

메인 A의 이전 대표 이미지는 **거울 앞 커튼을 닫은 수업 장면과 반대쪽 후면 촬영 벽만** 보여 줘 거울이 없는 공간처럼 보였다. 새 대표 이미지는 커튼을 열어 북쪽 전면 거울을 사용하는 댄스 모드다. 기존 수업·후면 촬영 비교 이미지도 선택해서 볼 수 있게 유지했다.

메인 A 장면들은 마감·운영 모드 비교이며 정확히 같은 좌표의 렌더가 아니다. 그림 속 적재량이나 비어 있는 바닥으로 책상16개·의자16개의 보관 가능성, 이동 보드 도킹과 활동 정원을 판단하지 않는다. 수납 후보·실제 가구 크기·적재 방식·주변 여유를 도면과 제품으로 확인한다. 코랄 사인은 승인 워드마크를 참조한 생성 근사 표현이며 제작할 때는 정밀 원본을 쓴다.

## 이전 시안

`방별_재질과분위기_컨셉.png`는 TV 위 웹캠, VR 매트/옆벽 수납, 포토 바닥 삼각대 등 옛 표현이 남아 있어 **현재 디자인북의 소개에서 제외했다.** 최신 방별 이미지로 만든 HTML 타일이 이를 대체한다. 20260930 접미사가 없는 교정 대상 이미지도 이력이며, 사무실 이미지만 현재 사용한다.

이전 전체 복도 이미지의 임의 문 개수·끝문과 무표기 사인은 실제 배치로 보지 않는다. 최신 복도 이미지는 마감만 검토하는 부분 장면이다. 전체 공간과 출입문은6안 평면/입체 보기로 확인한다. 이전5안 파일은 이력으로 보존한다.
