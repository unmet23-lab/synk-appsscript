# SYNK LAB 오프라인 운영 기준

2026년 10월 2일 사용자 요청으로 사업계획·학생 안내·교육·인력·공간의 기준을 통일했다. 무료 자습은 빈 강의실 예약제로 바꾸고 시설·운영 구조로 제공하기 어려운 상시 약속은 현재 운영안에서 삭제한다. 이 문서는 운영 방향의 현행 기준이며 임대·공사·인허가·채용·기능 개발 완료를 뜻하지 않는다.

## 현재 상태

- 울란바토르 공간은 미선정이다. 주소·월세·개원일·최종 공사 범위·모집 정원·현재 확보현금은 아직 확정 자료가 없다.
- 닫으면 강의실4곳, 열면 A+B를 합쳐 신청 학생25명과 강사1명의 댄스를 계획한다. 사무실은 개인 책상6~8자리, 상담실은 iPad 상담과 예약 VR, 사진/음료 공간과 남녀 화장실을 둔다.
- 최신 A+B 모듈은13.2×11m·145.2㎡ 비교안이다. 전체 전용 약102~104평은 이전 방 크기를 유지한 면적 비교이며 매물 적합성·필수 임대 면적·허용 정원이 아니다. 별도 가구32세트 수납12~16㎡와 칸막이 보관/구조 지지를 실측해야 한다.
- 정규 교실의16석은 설계 목표다. 실제 가구·조별 활동·출입·환기·피난을 확인한 뒤 모집 정원을 공개한다. 과거24반×16석=384석은 등록 편제 비교값이고 동시 재실 정원이 아니다.
- 새 전체 평면·3D·시공 CAD·확정 견적은 아직 완성되지 않았다. 이전6안 전체3D·가격표는 비교 자료로만 사용한다.

## 빈 강의실 무료 자습

**전용 자습실과 라운지는 만들지 않는다. 현재 재학생이 비어 있는 강의실의 좌석을 예약해 무료로 이용한다.**

1. 하루 약2~3시간의 예약 가능한 빈 시간을 예상한다. 모든 교실이 각각2~3시간 비거나 매일 이용시간을 보장한다는 뜻은 아니다. 실제 방별 수업 시간표와 직원 근무를 확인한 뒤 가능한 시간만 안내한다.
2. 수업·보강·상담 행사·청소·가구/칸막이 전환·촬영 준비·학생 인계/대기에 배정된 시간은 자습 예약에 중복 사용하지 않는다.
3. 담당자가 교실·날짜·시작/종료·사용 좌석·학생을 예약표로 확인한다. 초기에는 담당 접수와 접근 제한된 예약표를 쓰고, 앱 예약은 실제 구현·검증 후 연결한다. 예약이 없거나 교실이 준비되지 않은 상태에서 임의 입실하지 않는다.
4. 교실의 기존 개인 책상·의자·Wi-Fi·사용 가능한 전원으로 조용히 공부한다. 전용 가구·백색소음 시스템·상시 스낵바를 추가하지 않는다. 통로를 가로질러 충전선을 놓지 않는다.
5. 현장 담당자가 있고 안전하게 입퇴실을 확인할 수 있는 시간만 공개한다. 정규 수업 준비 전에 종료하고 학생 인계·마감을 확인한다. 자습 이용 중 학생 촬영·녹음은 하지 않는다.
6. 물과 준비된 음료·다과는 기존 공용 코너의 실제 운영 범위에서 제공한다. 무제한 공급·상시 음식 이용권·공부 좌석의 식음료 제공을 약속하지 않는다.
7. 시간 변경이 필요하면 담당자가 예약자에게 알리고 취소/다른 가능한 시간을 안내한다. 수업이나 피난 공간을 자습 자리로 중복 계산하지 않는다. 실제 시행 전 예약 확인·취소·입퇴실·다음 수업 준비를 시험한다.

## 학생 혜택과 상담

- TOPIK 응시료 지원,12개월 과잠, 장학, 안심 수강 일시정지, 연1회1:1 진로 준비와 함께 다듬은 최종본은 해당 복지/계약 조건을 유지한다. 시설이 작다는 이유로 취소하지 않는다. 실제 지급 대상·누적 방식·담당·원가·지급 시점을 연결한 후 등록 때 안내한다.
- 승인된 성과 지원은 열두 달 정규 과정을 성실히 마친 학생이 이후 첫 TOPIK에서4급에 도달하지 못했을 때 앱·숙제를 포함한 온라인 학습을6개월 무료 연장하는 것이다. 대상·시험 시점·기간·수단을 변경하지 않고 비용과 운영 책임을 반영한다. 무기한 또는 오프라인 수업 무료 연장으로 확대하지 않는다.
- 즉시 자동 포인트 적립·22종 상점을 전교 공통 기본혜택으로 제공한다는 약속은 삭제한다. 승인된 장학/과잠 등은 유지하고 관련 학습 기록·누적 확인·재원/교환·재고·담당을 먼저 검증한다. 게임·앱 콘텐츠와 검증 후의 선택 보상 개발은 취소하지 않는다.
- 외부 사업자의 AI Pro 계정을 모든 대상에게 무조건 제공한다는 약속은 기본 혜택에서 삭제한다. 몽골 제공 가능성·계정 소유/회수·기간·비용을 확인한 경우에만 별도 혜택을 검토한다. WORLD의 한국어 학습·AI 개발 방향을 삭제하는 뜻이 아니다.
- 상담은 iPad로 진행하며 이전 학생 자료가 다음 방문자에게 남지 않게 한다. 상담과 서서 움직이는 VR을 동시에 운영하지 않는다. VR은 기기/콘텐츠·경계·감독·위생·초기화 시험을 통과한 예약 회차만 제공한다. 상담실을 상시 놀이방으로 쓰거나 독립 VR실을 추가하지 않는다.
- LAB의 무료 진로 준비1회와 PATH의 유학 수속·한국 현지 관리는 별도 서비스다. 확정되지 않은 대학 커미션, 현지 파트너, 공항/기숙사/취업 연결,4년 상시 관리와24시간 대응을 기본 포함 서비스로 안내하지 않는다. 확정된 단계·담당·기간·비용·종료 조건만 별도 계약에 넣는다.
- 포토부스는 대표 학생만 월1회 이용권을 차감하고 동반 친구는 차감하지 않는다. 현재 재학 확인·중복 제한·오류 복구·사진 접근/보관/삭제·다음 사용자 초기화를 실기기로 인수하기 전 자동 운영 완료로 안내하지 않는다.

## 사람과 기록

- 실제 교직원 수와 근무는 모집 반 수·판매 가능한 시간표·업무량으로 정한다. 사무실6~8자리는 동시 업무 자리 요구이며 과거13명 편제의 채용 완료나 최종 직원 수가 아니다.
- 수업, 가구32세트 전환, 학생 대기 감독, 인계, 상담, 보고서, 촬영 업로드, 시설 관리와 마감을 동시에 한 사람에게 배정하지 않는다. 담당·대체자·유급 준비/복구·휴게·늦은 귀가를 근무표와 비용에 넣는다.
- 학원 운영 Apps Script의 자동 출결·부모 리포트·편성·급여 평가 등이 현재 이미 작동한다는 표기를 삭제한다. 새 플랫폼/WORLD/교사 앱은 담당 구현 기록의 범위만 안내한다. 은퇴한 학원 코드를 복원하거나 모든 앱 개발을 중단하지 않는다.
- 개원에 필요한 학생/재학·반/시간표·납부/환불·출결/인계·혜택·상담·보호자 권한·전달·백업/복구는 최소 기록과 담당제로 먼저 확인한다. 앱 기능은 실제 연결·권한·장애 대안 시험 후 사용한다. 개인정보와 민감한 상담 기록은 일반 회사 대화·공용 폴더에 섞지 않는다.
- 학부모 보고는 권한과 수신자를 확인한 담당자의 작성·몽골어 검수·안전한 전달 방식으로 계획한다. 주간 보고의 실제 업무량과 대체자·미수신 처리를 시험하고 등록 때 제공 주기/범위를 명시한다. 보호자 전용 앱 화면3종·자동 발송 완료·행정 하루2분을 약속하지 않는다.
- 수업 녹화, 제한된 온라인 제공, 공개 홍보, 라이브는 목적과 접근범위를 분리한다. 동의 거부 학생의 동등 수업·구도/반사/음성·업로드 승인·철회/삭제 담당을 먼저 확보한다. 녹화 선별·편집·업로드 노동을0원으로 계산하지 않는다.
- 학생 보호는 원장 외 지정 접수 역할과 대체 역할을 두고 개원 전에 실제 담당자·연락창구를 학생/보호자에게 게시한다. 원장이 당사자인 신고는 원장에게만 접수하지 않으며 접근 제한된 기록과 필요한 현지 대응을 연결한다.

## 삭제하지 않는 개원 조건

소화기·감지/경보·비상조명/유도·외부까지의 피난, 전기/접지·구조 지지·칸막이 보관/잠금, 외기 환기/배기·난방·화장실 위생·음악/진동, 근로/보험/허가 적용·세금·반환 기준·개인정보/동의는 시설 제약을 이유로 삭제하지 않는다. 실제 매물과 운영에 맞게 충족하거나 해당 매물을 선택하지 않는 조건이다. 공기청정기·향·예약 정원이 이 조건을 대신하지 않는다.

확정 공급견적이 없는 비용을0원으로 채우거나 이전81평 시설예산을 새 가변안의 최종 총예산으로 쓰지 않는다. 현재 사용할 수 있는 현금, 출자금 사용 조건, 월별 공사/임대/준비/운영 지급과 최저 잔액을 확인한다. 기본 혜택에서 뺀 선택 서비스의 절감액도 견적 없이 만들어 빼지 않는다.
