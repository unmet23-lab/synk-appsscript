# SYNK 온라인 강의 촬영 설계

> 2026-10-02 제공 범위 갱신: [현재 운영 기준](../오프라인_공간설계/오프라인_운영기준_20261002.md)을 따른다. 교실4곳의 디지털 원본 캡처+교사 합성은 유지한다. 주말 녹화만으로 평일 동등 진도/말하기/승급 상품을 개원 판매하지 않으며 학생별 화면 선택·송출/영상 권한·업로드는 실기기/기능 검증 후 제공한다. 녹화 노동0원과 자동 운영 완료를 기본 가정으로 쓰지 않는다.

2026년 10월 1일 기준. 학생이 글자를 선명하게 읽고, 필요할 때 교사의 입 모양과 동작을 크게 보는 수업을 목표로 한다. 앞서 비교한 촬영 방법을 보존한 제안 문서이며 장비 구매·프로그램 개발·실제 송출이 완료된 상태는 아니다.

**자료는 디지털 원본으로 캡처하고 교사는 별도 카메라로 찍는 구성이 가장 적합하다.** 전자칠판과 고급 카메라는 현장 수업과 촬영을 편하게 하는 대체 장비다. 화면을 카메라로 다시 찍는 방식은 반사·글자 손실·깜빡임을 시험해야 한다.

## 참고 영상과 SYNK 방식의 비교

사용자가 보여 준 영상은 강사와 큰 자료가 함께 보이는 형태다. 사진만으로 실제 대형 화면 앞 촬영인지 배경 합성인지, 사용 제품이나 해상도는 확인할 수 없다. 손의 리모컨은 슬라이드 조작 도구이며 선명한 자료 화면을 만드는 핵심은 아니다.

| 구성 | 장점 | 운영상 제한 |
|---|---|---|
| 실제 칠판과 교사를 함께 촬영 | 교사가 자료를 직접 가리키는 장면이 자연스럽다 | 교사가 글자를 가리거나 카메라에 화면 반사·각도·노출 문제가 생길 수 있다 |
| 자료 원본 위에 교사 영상 합성 | 작은 글자도 자료 원본 수준으로 유지하고 배치를 바꾸기 쉽다 | 판서·교사 영상·소리의 동기화와 합성 운영이 필요하다 |
| 자료와 교사를 각각 보관하고 플레이어에서 선택 | 학생이 자료·발음·동작에 맞춰 보기 방식을 고를 수 있다 | 별도 영상·공통 시각·재생 동기화·접근권한·저장 및 전송비가 필요하다 |

권장 방향은 두 번째 구성을 먼저 안정화한 뒤 세 번째 기능을 연결하는 것이다. 현장에서는 화면 앞에서 자연스럽게 가르치고, 온라인에서는 판서가 포함된 디지털 원본을 직접 내보낸다. 전자칠판에 쓴 내용이 캡처 출력에 실제 포함되는지는 제품과 앱 조합으로 시험한다.

## 방마다 필요한 신호 연결

```text
교실 PC의 자료·판서 원본 ─────────┐
고정 PTZ 카메라의 교사 영상 ──────┼→ 교실 송출 PC → 합성 화면 → YouTube
교사 착용 마이크 → 무선 수신기 ────┘           └→ 로컬 녹화

자료·교사 영상 각각 녹화 + 공통 시각 → SYNK WORLD 재생 기능 개발
학생 계정·수강권·촬영 권한 → SYNK 플랫폼의 계정/권한 체계
```

강의실4곳에 수업 촬영용 카메라를1대씩 고정한다. 통로 바닥에 삼각대를 세우지 않고 후벽 상단 또는 통로 위 천장 고정을 현장 시야에 맞춰 정한다. 광학 줌, 렌즈의 실제 화각, 교사 이동 범위와 전신 프리셋을 실측해 선택한다. 상담실·사무실·화장실을 수업 카메라 촬영 범위로 추가하지 않는다.

교사에게는 착용 마이크와 자료 넘김 리모컨, 자료·발음·댄스 모드 버튼을 제공한다. 무선 수신기를 송출 PC 또는 오디오 인터페이스에 연결하고 실제 촬영 영상에 맞춰 소리 지연을 보정한다. 송신기 자체 녹음은 무선 끊김에 대비하는 백업 후보이며, 후반 보정용 녹음 형식을 사용해도 이미 깨진 라이브 소리를 자동 복구하는 것은 아니다.

## 장비 선택과 예산 경계

| 항목 | 현재 예산의 기본안 | 고급 대체안과 확인할 비용 |
|---|---|---|
| 자료 표시·입력 | TV와 교실 PC, 펜태블릿 | 4K 터치 전자칠판. 실제 판서 캡처·앱·출력·이동 거치대·보증 확인 |
| 교사 촬영 | 기존 FHD PTZ 후보 | 4K PTZ, 광학 줌·자동 추적·교사 잠금 후보. 카메라와 캡처 카드·신호 케이블의4K 지원을 함께 확인 |
| 녹화·합성 | OBS 기반 합성 운영 검토 | 입력별 독립 녹화가 가능한 시스템. vMix 등 유료 라이선스는 별도 견적 |
| 리모컨·버튼 | 자료 넘김과 장면 선택 | 분실·충전·호환성·리모컨 조작이 판서 앱에서도 작동하는지 시험 |
| 마이크 | 교사 착용형 무선 | 자체 백업 녹음, 충전 보관, 예비 라발리에와 수신기 연결 확인 |
| 학생 보기 선택 | 단일 합성 영상 | SYNK WORLD 다중 영상 재생·실시간 동기화·수강권·모바일 검증 및 서버 비용 |

[Move4K 제조사 사양](https://ptzoptics.com/ptz-cameras/move-4k-12x)은 최대4K60과12배 광학 줌을 안내하지만 HDMI는4K, SDI는FHD다. ‘4K 카메라’만 사면 전체 연결이4K가 되는 것은 아니다. 전자칠판 후보는 [BenQ RP05 공식 자료](https://www.benq.com/en-us/education/benq-board-interactive-displays/rp05-pro-series-board.html)에서 검토하되 현지 판매가·수리·설치 하중·판서 출력은 확인 전이다.

[vMix 공식 에디션 안내](https://www.vmix.com/knowledgebase/article.aspx/48/which-edition-of-vmix-do-i-need)는 독립 카메라 녹화·4K·PTZ 제어 등에4K/Pro/Max 에디션을 안내한다. OBS 기본 녹화의 여러 오디오 트랙을 여러 영상 원본 녹화와 혼동하지 않는다. 실제 자료 소스 녹화,4실 동시 부하, 저장장치와 라이선스 대수는 도입 전에 시험한다.

기존 [예산 엑셀](SYNK_울란바토르_인테리어_비품_예산_20261001.xlsx)에 고급 대체안을 그대로 추가 합산하지 않는다. 교실별 기존 TV·펜태블릿·카메라·거치대 등 대체되는 금액을 차감한 뒤 신품·운송·세금·설치·SW·개발비 차액을 구한다. 우선1실에서 시험한 뒤4실 도입 여부를 정하는 것은 제안이다.

## 수업과 학생의 보기 선택

| 수업 | 교사가 송출하는 기본 화면 | 학생 선택 기능의 목표 |
|---|---|---|
| 문법·읽기 | 자료 크게, 교사 작게 | 자료 집중 또는 교사 함께 보기 |
| 발음·말하기 | 얼굴과 입 모양 크게 | 얼굴 확대와 자료 사이 전환 |
| 댄스·움직임 | 교사 전신과 시범 공간 | 전신 보기. 작은 얼굴 프리셋으로 대체하지 않음 |

AI 추적은 교사를 프레임에 유지하는 보조 기능으로 쓴다. 수업 유형과 장면 전환은 교사가 버튼으로 선택하고 필요하면 직원이 보조한다. 자동 추적이 발음·댄스의 적절한 구도를 스스로 결정한다고 가정하지 않는다.

**학생별 실시간 변경은 아직 구현된 기능이 아니다.** 일반 YouTube 단일 합성 송출에서는 학생이 교사 영상만 독립 확대하거나 합성 위치를 바꿀 수 없다. 이를 제공하려면 동기화된 별도 영상 소스와 SYNK WORLD 플레이어가 필요하다. 독립 녹화만으로 실시간 선택이 완성되지 않는다. 상용 다중 영상 플랫폼도 라이브/VOD 각각의 기능과 계약 범위를 확인해야 한다.

## 송출과 운영 비용

고화질 로컬 녹화와 라이브 해상도를 분리한다. 인터넷과 학생 기기 상태에 맞춰1080p·1440p·4K를 정하며,4K를 모든 수업의 기본 송출로 강제하지 않는다. [YouTube 공식 설정](https://support.google.com/youtube/answer/2853702?hl=en)은4K에 낮은 지연 설정을 제공하지 않으며, 연결 속도와 실제 움직임·소리 시험을 권한다.4실 동시 업로드와 다른 업무의 인터넷 부하를 함께 측정한다.

예산에서 빠뜨리지 않을 비용은 다음과 같다.

- 최초: 전자칠판·카메라 대체 차액, 신호 캡처·장거리 배선, 교사 조명·음향 보완, 동기화·학생별 재생 개발, 초기 설정과 직원 교육.
- 반복: 실제 인터넷 요금, 영상 저장·백업·전송, 필요 SW 갱신, 자막·번역 이용량, 마이크 소모품과 수리 충당.
- 업무: 교사의 장비 착용·충전·모드 전환, 녹화 확인·삭제·권한 관리, 자료와 얼굴을 가리지 않는 자막 위치 검수.

[YouTube 자막 안내](https://support.google.com/youtube/answer/6373554?hl=en)에 따르면 라이브 자동 자막은 영어만 지원한다. 한국어·몽골어 라이브 자막을 제공하려면 별도 서비스와 정확도 검토가 필요하다. 업로드 영상의 자동 자막 지원과 라이브 지원을 구분한다.

개원 전에 실제 모바일 기기로 작은 한글 글자, 입 모양, 전신 동작, 음성 지연, 무선 끊김, 충전 누락, 인터넷 단절 후 로컬 녹화 복구와4실 동시 운영을 확인한다. 계정·동의·접근권한과 사진·수업영상 보관기간도 같이 정한다. 이 문서는 구매 상한을 확정하지 않으며 미견적 비용은 [개원 예산과 준비기간](학원_개원_예산과_준비기간_20261001.md)에 이어 입력한다.
