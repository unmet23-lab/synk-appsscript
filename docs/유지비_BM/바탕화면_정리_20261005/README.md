## 보존·검증

정리 전 35파일(Word21, HTML2, 바로가기1, MD/TXT11)은 `99_이전자료/20261005_정리전`에 원래 상대 경로로 보존한다. `original-manifest.json`의 크기·SHA-256으로 대조한다. V1 Word 두 파일은 `99_이전자료/20261006_첫정리본`에 보존한다. 원본은 삭제하거나 과거 숫자를 고쳐 쓰지 않는다.

V2 PDF는 ReportLab으로 제작하고 SUIT·Inter Tight·DM Mono를 실제 임베딩했다. 모든 쪽을 이미지로 렌더해 확인했으며 표·본문의 하단 범위, 글리프, PDF 텍스트, 출처 링크와 산술을 검사한다. 국가군 기호가 빠져 보이는 문제를 발견해 A군/B군/C군으로 고쳤다. PDFium 전체 렌더와 Poppler 최종 국가군 지면을 대조했다.

V1의 `build.py`, `content.json`, `final/`, `qa-final/`은 이력이다. V1 문서 스킬 렌더러는 번들 LibreOffice 부재로 실패했고 기존 Word COM으로 출력했다. 당시 렌더 차이는 V2 품질의 근거로 쓰지 않는다. V2 Word의 실제 출력 검증은 해당 빌더와 `v2` 검증 기록을 따른다.

V2 Word는 실제 Word에서 14쪽·편집 가능(ReadOnly=False)·원고 누락0을 확인했다. Inter Tight는 문서에 임베딩했다. SUIT의 보기·인쇄용 임베딩 설정을 바꾸지 않고 수정 가능성을 유지하기 위해 승인 원본의 정적500/800 두 파일을 현재 사용자 Fonts와 HKCU에 `SUIT BM`으로 등록했다. 경로·SHA·실제 출력 글꼴 검사는 `v2/output/docx_qa/final_content_font_check.json`에 있다. 다른 PC에서 편집할 때는 해당 승인 글꼴이 필요하며 읽기용 PDF는 글꼴을 포함한다.

외부 공급자 요금·환율·현행 법률·실제 계약·청구를 새로 조사한 작업은 아니다. 원문에 없는 신규 판매가나 매출 실적을 만들지 않았다. 다음 갱신은 실제 가격·제공시간·청구·견적으로 계산 입력을 바꾸는 일이다.
