## 3. 공통 규칙

- **상태 표시:** 기존(이미 있던 상품·가격) / 새로(이번에 넣음) / 다시 열기(전에 뺀 것을 다시 여는 것 — 유호님이 정함) / 바꾸는 제안(이미 정한 값을 바꿈).
- **다시 열기 하나:** TOPIK 4급 온라인 반(10-02 「1기 온라인 과정은 열지 않는다」). 10-19 판의 나머지 둘은 10-22 SHIFT 결정으로 풀렸다 — SHIFT 입구 상품은 둘째 BM 흐름의 반나절 진단이 됐고(워크숍은 첫째 BM 강의로), 디지털 상품의 온라인 유료 강의는 강의 제한이 철회돼 다시 열기가 아니게 됐고, 10-22 유호님이 출강 자료·채널이 쌓인 뒤 열기로 정했다. **바꾸는 제안:** 성과급 경계(08-09 「119·200·300명」 → 손익분기 배수), PULSE 10-18 진단의 가격·납기 표시(10-08 기준), 10-03 「한국 법인 … 영업은 개원 뒤」를 PULSE·SHIFT 2027-02 판매로(그대로 지키면 2029 영업이익 3.08억원), 10-02 운영기준 「주말 상품 개원 판매 제외」를 08-01 4실 설계의 토요일반으로.
- **돈을 받는 때:** 원화 매출은 한국 법인이 선 뒤(준비안 C면 2027년 1월 초)부터다. 몽골 쪽 돈은 몽골 법인(2027-05 공사 전 설립)이 받는다. 설립 시점은 유호님이 정한다.
- **약속하지 않는 것:** 입학·비자·취업·급수·기간 보장, 합격 가능성 숫자, 광고 성과·자동 최적화, 「무제한」, 할인액, 실제 사례 없는 후기.
- **부르는 말:** 회사는 「개인화 엔진(Atlas)을 만드는 기업」이고 한국어 교육은 첫 적용 분야다. PATH 독립 채널을 만들지 않는다. 사이트·SNS에 AI 도구 이름을 쓰지 않는다(PULSE 「AI로 만든 모델입니다」 고지는 남긴다).
- **새 상품 기록:** 사업발전 정본의 확장 기록 형식(첫 실험의 범위·담당·기간·비용 한도, 진행·중단 조건)을 각 문서 끝에 적었다. 확정되면 담당 제품 문서로 옮긴다.
