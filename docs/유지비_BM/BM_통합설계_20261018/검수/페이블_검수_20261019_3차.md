## 지적(페이블 원문 요약)

- **[P1] 담당자 조기 채용의 이점은 회화 65시간 전제에서만 맞다.** 고정 일 190~200시간의 3분의 1이 유호님 회화인데, 이 상품의 회사 이익 기여는 거의 0이다. 회화 0반 + 담당자 수요 채용이면 2029년 말 현금이 오히려 많다. → 발견 2에 전제를 밝히고, 결정 2와 9를 한 항목으로 묶고, 9-2절에 줄을 더하라.
- **[P2] 보수 가정 「D안(관문→C안)」과 「C안」의 차이는 생활비 동결 차이다.** 같은 C안을 다른 생활비로 견줬다. → 같은 조건으로 돌려 「관문에 걸린 D안 = C안」을 밝혀라.
- **[P2] 관문 숫자와 순서가 어긋난다.** 6월 125건이면 규모 축소인데 150건 못 미치면 C안(가벼운 조치가 더 낮은 문턱), 장소 공개 전인데 6월에 체험 신청 40명을 요구. → 6월 문턱 하나로, 체험 신청은 8월 지표로.
- **[P2] 기본 가정이 자기 2027-06 점검을 겨우 넘고, 그것도 디지털 상품 덕이다.** → 그 사실과 점검에 걸렸을 때의 값을 적어라.
- **[P2] README 3-2 「SYNK반 넓히기 | 고정비·손익분기 같음」이 틀렸다**(교실 3개부터 운영 담당 전일).
- **[P2] 기관 계약이 일방적 옵션 묶음이고 받아들일 이유가 숫자로 없다.** 이전 꼬리 5%×6개월은 약하다. C안 전환은 기관 동의 조건과 거절 때의 길이 필요하다. 고용 대행도 견줘라.
- **[P2] 관문→C안일 때 유호님 역할이 정해지지 않았다.** 계산은 이주비·생활비·회화 65시간을 그대로 두고, C안 PATH 수금 주체가 빈칸이다.
- **[P3]** 기관이 받는 돈 두 값(PATH 몫 포함 여부), 거래 비교표의 보수·상방 칸이 거래 모양을 구분하지 못함, TOPIK 특강·IBT 모의고사 달이 2027 시험 일정과 어긋남, 편의점 두 체인을 한 체인처럼 씀, MUST 선례의 전후 관계 근거 없음, README 2절 #17 「따로 사면 352만₮」, 10-03 「영업은 개원 뒤」를 바꾸는 것이 13절에 없음, 4급 반 10명 대 계산 6명, 교재 원고 대가 0원, 이전 꼬리가 새 등록에도 붙음, 개원 전달 운영 담당 전일, 답사 시간 미반영, 이전 때 이탈 0, 위성 13:30 슬롯, 첫 특강 재원생 15%, 사업방안 README의 PATH 「0원이면」 칸, 2027-06~07 일 몰림.
- **확인해서 이상 없던 것:** 계단형 몫·고정 임대·최소 보장·교실 하나씩·손익분기 캐시·관문·거래 비교·기관 수입 식·민감도 줄, 「읽는 법」 차이값, 다시 열기 셋·바꾸는 제안 둘·PATH 독립 채널 없음·AI 도구 이름·동의·법인 전 매출·보장 문구. copy3 재계산은 원본과 바이트 동일.
- **잘 된 점:** D안을 「기본 구조」로 솔직히 자리매김하고 관문·C안 전환·이전 조건을 한 계약서에 묶은 것, 협상에 바로 쓸 거래 비교·기관 수입 표, 여덟 문서의 한 틀과 「지금 있는 것은 0」을 먼저 밝힌 것.
