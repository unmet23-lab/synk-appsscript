## 지적

### [P2-1] 우즈베키스탄 `passMix`에 개원 한 해 뒤(2030-09) 둘째 계단이 없다 — `inputs.mjs:148`
- 깨지는 동작: 몽골(`:217` 2027-09 → 2028-09)과 베트남(`:127` 2028-09 → 2029-09)은 개원 한 해 뒤 9월에 기간권 비중이 「1·3개월권 위주」에서 「6·12개월권이 늘어난 비중」으로 바뀌는데, 우즈베키스탄은 `[ { from: '2029-09', … } ]` 한 계단뿐이다. 2029-12까지 셀 때는 상관없었지만 2030으로 늘리면서 유일하게 이 일정만 T+12에 이어지지 않는다(물가 계단·부가 상품·labConvFrom은 모두 T 기준으로 이어 넣었다).
- 크기(탐침 `uzPassMixExperiment`, 둘째 계단을 2030-09에 넣고 다시 돌림): 성공적 2030 우즈베키스탄 LAB 매출 31,145만 → 30,854만(−291만), LAB 이익 −10,851만 → −11,134만, 영업이익 152,696만 → 152,414만(−282만), 12월 선수금 2,721만 → 3,701만(+980만), 연말 현금 +740만. 결론은 안 바뀐다.
- 고칠 방법: `passMix: [ { from: '2029-09', v: {…} }, { from: '2030-09', v: { m1: 0.25, m3: 0.35, m6: 0.30, m12: 0.10 } } ]`로 몽골·베트남과 같은 꼴로.

### [P3] 추가 확인·다듬기(글이 계산과 어긋나거나 읽기를 흐리는 곳)
1. **AI바우처 2030 = 0건은 「사실」이 아니라 「넣지 않은 가정」이다** — `틀/README.md:43`(0-1 「2030년」) 「AI바우처는 2029년 한 건뿐이라 2030 SHIFT 이익이 조금 준다」, `inputs.mjs:85`. 기본 가정의 `shift.voucher.perYear['기본'] = { 2029: 1 }`은 기간이 2029에서 끝나던 때 적은 값이고 2030 칸이 없어서 0이 된 것이다(계산은 의도대로 0). 탐침(`voucher2030`): 2030에 한 건 넣으면 보수적 2030 영업이익 90,707만 → 93,062만(+2,355만), SHIFT 이익 4,632만 → 6,672만, PULSE 광고 이익 1,576만 → 1,998만. 같은 뿌리로 PULSE 광고 이익도 2029 1,752만 → 2030 1,576만으로 주는데(한국 담당자 월 450만원이 PULSE·SHIFT 시간 비율로 나뉘어, SHIFT 시간이 줄면 PULSE 몫이 커진다) 글은 SHIFT만 적었다. 「2030 AI바우처는 넣지 않았다(한 건이면 +2,355만원)」처럼 가정으로 적고 PULSE 광고도 함께 준다고 쓰는 편이 맞다. 「PULSE 광고·SHIFT … 계획은 2029년 고객 수 그대로」도 SHIFT 운영 고객은 쌓여(3.5 → 5.1곳) 운영료가 2,577만 → 4,165만으로 느는 점을 한 마디 붙이면 읽기가 분명하다.
2. **08 §0 표의 베트남 법인세 「17%」**(`틀/사업방안/08_진출나라.md:11`, `pct(CF('vn').taxRate)`)가 README 0-2 표 「17% → 2030 20%」와 다르다. 같은 문서가 2030까지 보여 주므로 `taxByYear`를 같이 찍거나 「17%(2030부터 20%)」로.
3. **08 §1 「베트남 한 해 계약이 우즈베키스탄의 약 2.8배」**(`:22`, `CF('vn').demand2029 / CF('uz').demand2029` = 34,520 / 12,244 = 2.82)는 바로 위 §0 표가 2030 숫자(36,246 · 13,224 → 2.74배)로 바뀐 뒤 근거 해가 표에서 사라졌다. `demandBy[LY]`로 바꾸면 「약 2.7배」.
4. **README 0절 2 「그 10%(약 3,625건)만으로 평균적의 영업이익이 2029 54.82억원 · 2030 63.46억원이 된다」**(`틀/README.md:24`) — 3,625건은 2030 건수이고 2029는 3,452건이다. 「(2029 약 3,452건 · 2030 약 3,625건)」처럼 해를 나눠 적는다.
5. **README 0-5 「유학 10%는 몽골 한 해 새 유학생(약 10,355명)의 열에 하나다」**(`:85`, `demand2029`)에는 해가 없고, 바로 아래 베트남 줄은 「약 3,625건(2030)」이다. 2029 비교 맥락이면 「(2029 약 10,355명)」으로 해를 적는다.
6. **results.md 「나라 가정」 표의 「유학 계약(한 해, 10%)」 칸이 2029로 박혀 있다**(`model.mjs:1150` `2029 - inpC.market.baseYear` · `(2029)`) — 같은 절의 다른 표는 2030까지 보여 준다. `lastY`로 바꾸면 표끼리 해가 맞는다(표시용이라 계산 영향 없음).
