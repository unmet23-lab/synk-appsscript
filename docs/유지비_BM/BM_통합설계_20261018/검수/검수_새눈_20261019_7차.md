## 지적(우선순위 순)

### P2-1 아직 정하지 않은 몽골 운영 계획을 「확정」 꼬리표 아래 둠

- **어디:** README.md 62(틀/README.md 53)의 「**운영 계획(10-19 유호님 확정):** … 몽골·학원 80%·WORLD는 세 지표와 같고」.
  - README.md 160(틀 111)과 사업방안/08 101(틀 87)의 줄 「**운영 계획 · 새 나라 1.5%(10-19 확정)**」. 이 줄의 보수적 칸은 몽골 80%·10% 값이다.
  - results.md 65~67(model.mjs 1152)의 「### 운영 계획 … (10-19 유호님 확정)」·「몽골·학원 80%·WORLD는 세 지표 그대로다」. 몽골은 정하지 않았다는 말이 없다.
  - 페이지 build_page_v7.mjs 148의 숫자 카드 「2030 영업이익 · 보수적 · 운영 계획 9.07억원」과 133의 줄 꼬리표.
- **깨지는 것:** 유호님 결정 원문은 「10%는 투자 자료의 성공 시나리오로만」이다. 그런데 운영 계획 판에 몽골 유학 10%가 그대로 들어 있고 「확정」으로 읽힌다. 특히 「보수적 운영 계획」(README.md 18, 페이지 맨 위 카드)은 통째로 정하지 않은 몽골 값이라, 읽는 사람은 몽골 운영 계획까지 정해진 것으로 받아들인다. 정할 것 ②(README.md 48)와 0-5 마지막 줄(README.md 165)에만 「아직 안 정함」이 있다.
- **고칠 방향:** 운영 계획 표·카드·results.md 머리 가까이에 「몽골 줄은 정할 것 ② 전까지 세 지표 값」을 한 줄 넣는다. 「(10-19 확정)」은 「새 나라 1.5%」에만 걸리게 줄인다.

### P2-2 README 머리글이 10% 판을 「본 계산」이라고 함

- **어디:** README.md 6(틀/README.md 5)의 「**10-19 오후 둘째 요청으로 본 계산은 진출 나라 세 지표(… 나라마다 학원 4실 정원의 80% · 유학 수요의 10% …)다(0절).**」
- **깨지는 것:** 결정 뒤 10% 판은 투자 자료의 성공 시나리오이고 운영 계획은 따로 있다. 그런데 문서 첫 굵은 문장이 여전히 10%를 본 계산으로 소개한다.
- **고칠 방향:** 「유학 몫은 두 판(운영 계획: 새 나라 1.5% · 투자 자료 성공 시나리오: 10%)」을 같은 문장에 넣는다.

### P2-3 08 문서는 6절 전까지 10% 판만 보여 줌

- **어디:** 사업방안/08_진출나라.md 16(틀 15)의 「세 지표에서 나라마다 … 유학은 … 10%를 맡는다고 셌다」. 운영 계획 이야기는 없다.
  - 60(틀 57)의 「## 4. 나라별 숫자(성공적 지표)」. 10% 값(베트남 3,625건·상담 57명·54.26억원)이 「투자 자료 · 성공 시나리오」 꼬리표 없이 이 나라의 숫자로 나온다. 운영 계획의 나라별 값은 6절 글 한 줄(105)에만 있다.
  - 4(틀 3)의 상태 줄 「나라 순서는 유호님 확정, 나머지는 Claude 설계안」은 6절 제목의 「(10-19 확정)」과 엇갈린다.
- **고칠 방향:** 0절에 두 판을 한 줄로 적고, 4절 제목에 「투자 자료 · 성공 시나리오」를 단다. 할 수 있으면 README 0-3처럼 운영 계획 나라별 표를 같이 둔다. 상태 줄에는 유학 몫 확정을 더한다.

### P2-4 페이지 현실성 점검에 결정 전 글이 남음

- **어디:** build_page_v7.mjs 233의 소제목 「유학 몫을 낮추면(같은 세 지표에서 유학 몫만 바꿈)」.
  - 같은 파일 235의 「새 나라는 첫해 베트남에서 가장 큰 유학원 수준(1.5%)을 목표로 두고, 상담 인원을 뽑을 수 있는 만큼 몫을 올리는 쪽을 권한다.」(test_v7 본문 189·195줄)
  - 둘 다 v6 그대로다.
- **깨지는 것:**
  - 표는 이제 운영 계획(1.5%)을 바탕 줄로 두고 「3%로 올리면」 줄도 있다. 그런데 소제목은 「낮추면」이다. README는 같은 자리를 「유학 몫에 따라」로 고쳤다(README.md 155).
  - 「권한다」는 결정 전 제안이다. 「첫해 … 목표」도 확정 내용(운영 계획은 1.5%부터 시작)과 다르다.
- **고칠 방향:** README 0-5 마지막 줄(165)과 같은 내용으로 바꾼다.

### P2-5 페이지 「세 지표」 기준 절에 운영 계획 정의가 없음

- **어디:** build_page_v7.mjs 162의 표. 유학 칸이 세 줄 모두 「나라마다 한 해 새 한국 유학생의 10%」다.
  - 165의 「유학(PATH): … 10%를 개원 다음 달부터 맡는다」, 166의 「2030년: … 학원 80%·유학 10%를 지키며」(test_v7 본문 34~39줄).
- **깨지는 것:** 페이지 맨 위 카드와 첫 그래프·표는 운영 계획(새 나라 1.5%)이다. 그런데 정의를 적는 절에는 10% 규칙만 있어 두 판이 섞여 읽힌다. README는 0-1에 운영 계획 줄(62)을 더했다.
- **고칠 방향:** README 62와 같은 줄을 기준 절 목록에 넣는다. 2030 줄에는 「(세 지표 기준)」을 단다.

### P3-1 「확정」 꼬리표가 결정에 없는 「올리는 기준」까지 덮음

- **어디:** README.md 165(틀 115)의 「10-19 유호님 확정대로 … 1.5%에서 시작해 사증 결과와 상담 인원을 뽑는 속도를 보며 올린다」.
  - 08 105(틀 90)의 「**10-19 유호님 확정:** … 사증 결과(비자 실패율)와 상담 인원을 뽑는 속도를 보며 몫을 올린다」.

### P3-2 운영 계획은 2030년까지 1.5% 그대로라는 말이 표 곁에 없음

- **어디:** model.mjs 1083, runPlan newOnly. 2028~2030 내내 1.5%로 고정돼 있다.
- **설명:** 결정은 「1.5%부터 시작」이다. 그런데 운영 계획 표·카드는 올리지 않은 값이고, 이 점은 0-1 줄의 「1.5%로 둔다」에서만 미루어 알 수 있다.
- **고칠 방향:** 표 곁에 「2030년까지 1.5% 그대로, 올리는 것은 넣지 않음(3%는 0-5 견주기)」을 적는다. 유호님이 운영 계획에 올림 계단을 기대하는지는 추가 확인이 필요하다.
