## 1. 먼저 증거 한 편

지금 팔 수 있는 증거가 없다. 10-17 하린 시험 영상은 「딱 봐도 ai같은데」였다. 그래서 순서는 증거 → 입구 → 정기 묶음이다.

1. **지유 스킨케어 광고(가상 브랜드 「맑음 MALGEUM」 토너 15초, 10-18 시작)** 를 끝낸다. 제작 규칙대로 사람 장면은 AI로, 제품은 블렌더 렌더, 글자·로고는 후반에서 넣는다. 영상 모델은 처음 고른 하나로 끝까지 간다. 결과는 Fable 검수 → 유호님 확인 뒤에만 사례로 쓴다.
2. 함께 만들 부속물: 상세페이지 컷, 납품물 AI 표시 문구 견본, 사용권 확인서 견본(10-18 진단 제안).
3. 두 번째 사례는 실제 의류를 재현한 모델·룩북(10-01 우선순위 2번).

사례 설명은 6항목(문제·아이디어·한 일·받는 것·정확도·확인 범위)으로 쓴다. 제작 중 컷이나 거절된 컷을 완성 사례로 넣지 않는다. 「AI로 만든 모델입니다」 고지는 모델 목록에 남긴다.

- **입구 상품(#25):** 크몽에서 판다. 고객이 준 사진을 캐스팅·홍보에 다시 쓰지 않는다. 크몽 등록·판매 시작은 법인이 선 뒤 유호님이 말할 때.

- **몽골 기업 대행(#29):** 몽골 진출 때 현지에서도 광고 사업을 해 본다는 계획(10-02)의 첫 모양이다. 울란바토르 제작팀(2027-10~)이 생긴 뒤에 본다. 계약 명의는 한국 법인으로 계산했다.

## 4. 고객을 데려오는 길

- **증거 한 편이 나온 뒤:** 스마트스토어·자사몰 셀러에게 「제품 사진 → 하루 안에 정지 시안 3장」을 제안한다(10-18 진단). 무료 시안은 한 달 10건까지로 묶는다(대표 시간 상한).
- **통로:** 크몽(입구), @yuhobuilds 댓글 DM 자료 전달, 영업 명단(`docs/영업_명단.md`). 메시지·메일을 보내는 일은 유호님이 말한 뒤에 한다.
- **고객 화면:** 지금은 초대 뒤 6단계 협업이다. 진단대로 「주소·사진 → 시안 → 승인 → 결제 → 납품」으로 줄인다.

## 6. WORLD 구독(#30)

- **잴 것:** 무료 → 유료 전환율, 유료 월 유지율, 사용자 1명의 AI 비용. 사용자 1명 AI 비용이 구독료의 40%를 넘으면 제공량을 고친다.
- **PATH로 잇기:** 본인이 유학·취업을 목표로 고른 사용자에게만 PATH 대상 국가 온라인 상담([03](03_PATH.md) #21)을 한 번 알린다. 본인이 신청하기 전에는 어떤 자료도 PATH로 넘어가지 않는다.

## 7. 학원·학교 좌석(#31)

- 학기 단위 계약, 웹에서 결제, 최소 30석이나 카드 결제. 교사는 담당 반 학생 자료만 본다. 계산은 WORLD 구독 곡선 안에 이미 들어 있어 따로 더하지 않았다.
- 앱 심사: 웹에서 산 좌석은 앱 안 결제로도 살 수 있어야 하고(Apple 3.1.3(b)), 자체 코드로 유료 기능을 여는 길은 쓰지 않는다(3.1.1). 「학원 코드 = 연결 열쇠」가 「기능을 여는 코드」로 읽힐 위험은 아직 확인 못 했다.

## 8. 접객 기업 좌석 + 접객 한국어(#32)

- **누구에게:** 몽골의 호텔·여행사·한식당·병원·한국 편의점 체인. 한국인 방몽객은 2025년 182,507명, 2026년 1~9월 148,054명이고 성수기는 6~9월이다. 현지 여행사는 3년 사이 30곳 안팎에서 200곳 넘게 늘었다는 업계 말이 있고, 한국어 가이드가 모자라 서로 데려간다는 보도가 해마다 나온다.
- **무엇을:** 직원 10명분 WORLD 좌석 + 접객 한국어 묶음(인사·주문·안내·응급 표현), 회사당 월 30만₮. 직원 반이 필요하면 LAB 기업 단체반(#10, [02](02_LAB_교실_부가상품.md))으로 잇는다.
- **비교 상대:** 몽골 관광교육센터(2025-05 개관, 한국 원조 55억원, 가이드·접객·식당 서빙 과정)가 같은 사람을 가르친다. 경쟁보다는 「센터 수료 뒤 현장 복습용 좌석」으로 제안해 본다.
- **지킬 선:** 회사 전용 공간을 새로 만들지 않는다(10-02). 좌석은 일반 WORLD 계정 묶음으로 판다. 직원의 학습 기록·평가를 회사에 자동으로 넘기지 않는다.
- **계산:** 기본 가정 2028-03부터 두 곳, 2029-03부터 네 곳. 2029년 {{eok(ysum('기본',2029,(r) => r.pulse.worldCorporate))}}.
- **멈출 때:** 2028-09까지 유료 1곳도 없으면 영업을 멈추고 관광교육센터와의 협력만 남긴다.
