## B-3. 회사·브랜드를 부르는 말과 표시
- 회사 정의: 「SYNK는 개인화 엔진(Atlas)을 만드는 기업」, **회사 전체를 한국어 교육 회사·한국어 학원 하나로 소개하지 않음**, 회사 소개 예시가 한 나이대(예: 유학생)만 전제하지 않게(결정:354 · 마케팅정본:21 · 사업계획서:9). 홈페이지 첫 문장은 「SYNK는 한국어 교육에서 시작한 개인화 기술 회사입니다」(실물:14).
- **「새로 떠오르는 개인화 엔진 회사」 문구는 뺐음**(결정:203).
- 비전 문장은 비전 정본 그대로(LAB·SHIFT·PULSE·PATH 전면 비전, 비전:1~51). SHIFT 옛 문장 「기업과 기관이 AI를 자기 일에 활용하고…」는 은퇴(결정:41).
- **사이트·화면·글에 AI 도구 이름과 「AI 생성」 표기를 쓰지 않음**(10-02 원칙, 결정:248·358이 가리킴), 공개 그림의 C2PA 출처 표시도 제거(결정:200). **예외**: PULSE 모델 목록 「AI로 만든 모델입니다」 고지 유지(결정:358), 유튜브 「변경되거나 합성된 콘텐츠」 표시는 AI 음악 중심 영상에 켬(결정:248), 베트남 진출 때 AI법 표시 확인(마케팅정본:31). 고객 광고 납품물의 AI 표시 문구(10-18 진단 제안)는 사이트 규칙과 따로 판단.
- **새 회사·브랜드·로고·독립 사이트를 늘리지 않음**(결정:285 · 마케팅정본:7). 「SYNK반」은 BM README가 만든 이름 — 별도 브랜드처럼 쓰지 말고 LAB 안의 반 이름으로(추론). 상품 판매는 SYNK 홈페이지 상품 메뉴.
- **PATH 독립 마케팅 채널을 만들지 않음**(마케팅정본:23). 유학 정보는 PATH 자료로 보내되 채널은 LAB·SYNK 쪽(SHIFT.md:125·129).
- **비공개 내부 연구개발 내용은 대외 자료에 넣지 않는다.** 상세 결정과 근거는 비공개 보관본에서 확인한다.
- 시청자 메시지·화면에 D0008 같은 내부 번호·내부 용어 금지(메모 10-18, 결정:24 「자료 번호는 사람에게 보이지 않게」).
- Atlas는 기존 8개 엔진의 총칭, 별도 회사 런처나 새 상위 엔진 이름으로 쓰지 않음, 학생 앱 = SYNK WORLD, 회사 런처 = SYNK 플랫폼(사업계획서:18). 새 중앙 판단 엔진·자체 AI 하네스 추가 금지(사업발전:24 · AGENTS.md).
- 「AI 7개라서 뛰어나다」 같은 표현으로 교육 신뢰를 대신하지 않음(LAB.md:79). 교재 원고·상표 출원·특허 자료를 등록 완료·학습 효과·독점 자산 가치처럼 안내하지 않음(사업계획서:211).

## B-4. 상태(준비/운영/효과)를 적는 말
- 단계 구분: 설계 방향 / 로컬 구현·시험 / 운영 설정·배포 / 실제 사용자 인수 / 실제 효과 — **앞 단계가 있다고 뒤 단계를 완료로 적지 않음**(사업계획서:38). SHIFT도 공개 예시 → 시연 샘플 → 계약 준비된 서비스 → 실제 고객 운영 → 확인된 결과(SHIFT.md:168).
- **단순 문의 창구나 설계 문서만으로 「유학 지원 중」·「강사 다수 보유」·「협력 대학 네트워크」·「공인 기준」이라 쓰지 않음**(SHIFT.md:168). 학교 로고·장학금·정원은 실제 권한 확인 전 「확보」 표시 금지(SHIFT.md:187).
- PULSE의 이미 시작한 일(광고·모델 영상 제작)은 「준비합니다」가 아니라 「하고 있는 일」(결정:389) — 단 완성 광고 0편·주문 0건이라 사례·실적은 만들지 않음(PULSE.md:508). 제작 중·거절 컷은 완성 사례로 넣지 않음(PULSE.md:143).
- **후기를 미리 만들지 않음**(LAB.md:71), 질문이 없으면 가짜 질문 생성 금지(SHIFT.md:127), 실제 성과 사례가 있다고 만들지 않음(FAQ:99), 각색·재현을 실제 기록처럼 제시하지 않음(SHIFT.md:131), 가짜 후기인 대신 가상 모델임을 밝힌 캐릭터로(PULSE.md:524), 번역 AI 검토를 원어민 감수로 표시하지 않음(SHIFT.md:154).
- 「온라인 마케팅으로 사람을 안정적으로 공급한다」고 말할 수 없음 — 「공급 통로를 만들었고 재기 시작했다」까지(README:369). 기존 게시물·계정 목록은 성과의 증거가 아님(마케팅정본:37).

## B-5. 학생·고객 자료와 동의
- **학생 동의 없이 자료를 넘기지 않음**(README:39). 앱 → PATH는 본인이 신청하기 전 어떤 자료도 넘기지 않음(BM_목록:136). 협약 대학 자료 전달은 학생에게 알리고 동의(README:196).
- **이해관계 고지:** 제휴 여부와 추천 이유 구분, 협력 학교만 비교하면 비교 범위를 밝힘, 학생·학교 중 누가 비용을 내는지 계약 전에 설명(SHIFT.md:187). 여행은 예약 수수료가 추천 순위를 바꾸지 않게(PATH여행:253).
- 학생의 얼굴·이름·학습 원문을 영업 견본으로 쓰지 않음(SHIFT.md:189), 학생 기록·얼굴/음성·프로젝트 공개를 등록 강제 조건으로 만들지 않음(사업계획서:167), 고객 원본을 PULSE 캐스팅·홍보에 재사용하지 않음(PULSE.md:186), 고객사 자료·상담 기록·직원 평가를 다른 회사나 개인 계정에 자동 합치지 않음(SHIFT.md:32).
- 성인 학습 기록을 부모에게 자동 전송 금지, **개인의 학업·체류 상황을 광고 타겟 분류나 공개 사례로 캐내지 않음**(LAB.md:81) — TOPIK 4급 졸업 요건반 모집 문구에 특히 해당.
- 미성년: 보호자는 구매자이지만 학생의 꿈을 대신 정하는 주인공이 아님(LAB.md:28), **생계·비자·취업 수익을 청소년의 흥미 장치로 쓰지 않음**(LAB.md:73), 연락처·계좌/결제 정보를 먼저 캐묻지 않음(FAQ:111), 공개 연령 조건 미정(FAQ:73), 앱 가입은 만 14세 이상(결정:416).
- 나이·성별·국적으로 능력·성격을 단정하지 않음, 맞춤 입력에 쓰지 않음(비전:70 · 실물:44 · 결정:349). 순위 비교·고정 구호 강요 금지(FAQ:91).
- 운영 수집이 연구/모델 학습·공개 홍보·전사 공유를 자동 허용하지 않음(사업계획서:213), 동의 거부 학생도 동등 수업(사업계획서:157).

## B-6. 판매 방식·시점
- **WORLD 앱에서 하지 않는 것**: 뽑기·확률형, 가짜 할인 시계, 「지금 안 사면 사라진다」, 연속 기록·목숨·에너지 판매, 주민·마스코트의 구매·구독 권유 대사, 갑작스러운 구매 창, 학습 통과·숙련 판매(BM_목록:36~43). 가구 가격은 실제 돈으로(BM_목록:113).
- **모의시험 문항은 전부 자체 제작, 기출을 쓰지 않고 AI에 넣지 않음**, 등수 없음, 점수를 수준 올리기 근거로 쓰지 않음(BM_목록:82). AI 채점은 「AI가 본 것」·공식 점수 아님(BM_목록:105).
- 앱스토어: 자체 코드로 유료 기능을 여는 길 금지(3.1.1), 웹에서 산 좌석은 앱 안 결제로도 살 수 있어야(3.1.3(b))(BM_목록:290~292).
- **유료 판매는 법인과 회사 개발자 계정 뒤**(결정:315 · BM_목록:278). 한국 법인 추천안 C면 **2027년 1월 전에는 사업 매출을 받지 않음(홍보는 가능), 결제는 법인 전까지 열지 않음**(한국법인:16·28) — 설립 시점은 미정.
- 온라인 1기의 옛 가격·보증·신청 경로·진단 링크·폼·크루카드를 쓰지 않음(약속과실행:4 · FAQ:57 · 1기제안:14), 과거 12월/2월 날짜를 일정으로 복원하지 않음(사업계획서:195).
- 환불 비율을 몽골 기준 확인 전 확정 계약/자동 답변으로 게시하지 않음(FAQ:65). 선수금은 향후 수업/환불 의무와 함께 관리(사업계획서:187).
- 상품 판매는 SYNK 홈페이지 상품 메뉴, 확인되지 않은 시설·장비·제휴처·요금·예약·주문·결제 운영을 약속하지 않음(마케팅정본:7).

## B-7. 광고·영상 제작
- AI 광고·홍보영상은 **전부 AI(실촬영·화면녹화 없음)**, **제품·로고·글자·앱 화면은 AI로 그리지 않음**(제품은 블렌더 렌더, 글자·로고는 후반)(제작규칙:3·9). 같은 사람으로 보이는지가 성패(제작규칙:7).
- 영상 모델은 넷(로컬 H3·Wan 3.0·Seedance 2.5·Omni 1.1 Flash) 중 하나로 시작해 끝까지, Veo 3.1 Quality는 우리 인물 얼굴 없는 장면만(결정:19). 나레이션은 Typecast 범수, Gemini TTS 안 씀(결정:48·39).
- 마스코트는 정본을 그대로 얹지 않고 장면마다 GPT 이미지 2.5로 새로 굽기(결정:98 · AGENTS.md).
- CF 형식 포트폴리오를 방송 심의·송출 완료 증거로 쓰지 않음(PULSE.md:30). 영상 글에 「어제 공개한」 같은 상대 날짜 금지(메모).
- 큰 크레딧은 컷 수·비용을 먼저 보여 드리고 승인(메모·결정:19), 힉스필드 크레딧은 최대한 안 씀(메모).
