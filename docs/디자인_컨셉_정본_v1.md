# SYNK FIELD — 디자인 컨셉 정본 v1

> **확정일 2026-07-28 · 유호님 확정** — 색상 키트 확정 후 시각 문법 정의. 이 문서가 정본이며, 캐러셀·앱·교재·발표물의 디자인 판단은 전부 여기를 따른다.
> 상위 문서: 브랜드 2층 구조(겉=우주 / 속=뇌과학 / 교육 IP=시냅스) · 슬로건 「점수를 넘어, 삶을 설계합니다」
> 제품 UI(Glide 앱 화면)는 **이 문서의 적용 대상이 아니다** — v9.79 미니멀 스킨(흰 카드+소프트 섀도)이 별도 정본. 둘은 다른 층이다.

---

## 0. 한 줄 정의

**흑백만 쓴다. 그래서 색 한 점이 형광펜 열 자루 값을 한다.**

이게 이 컨셉을 채택한 이유이자, 어길 수 없는 단 하나의 이유다. 컬러를 늘리는 순간 이 컨셉은 존재 가치를 잃는다.

## 1. 공통 규칙 3개 — 모든 표현이 예외 없이 지킴

| # | 규칙 | 판정 기준 |
|---|---|---|
| **R1** | **2색 원칙** — 잉크·바탕 2색만. 신호색은 화면당 **면적 5% 미만**<br>단 **모드 C(겹침)는 예외 규정 적용** — 아래 참조 | 눈을 가늘게 뜨고 봤을 때 색이 한 덩어리로만 보이면 통과 |
| **R2** | **위계는 밀도로** — 크기·굵기·색이 아니라 점의 밀도와 여백이 시선을 이끔 | 요소 3개 이상이 동시에 "나를 봐"라고 하면 실패 |
| **R3** | **타이포는 절대 건드리지 않는다** — 글자에 그레인·왜곡·투명도·그림자 금지. 항상 100% 크리스프 | 거친 배경 ↔ 완벽히 깨끗한 글자. 이 대비가 무너지면 촌스러워짐 |

R3이 생사를 가른다. 이 스타일이 싸구려로 보이는 경우는 거의 전부 글자를 건드렸을 때다.

**R1의 모드 C 예외** — 겹침 모드는 2도 잉크 자체가 화면의 주인공이므로 "신호색 5% 미만"이 적용되지 않는다. 대신 이렇게 읽는다: **종이 + 잉크 2색, 끝.** 겹친 자리에 생기는 세 번째 톤은 두 잉크가 만든 것이므로 허용하지만, 잉크 2색 외에 신호색을 따로 얹는 것은 금지한다. 겹침 모드에서는 잉크가 곧 신호다.

## 2. 표현 모드 3개 — 채널에 따라 골라 씀

### 모드 A · 디더 (Dither)
- **바탕** 검정 `#08080B` / **잉크** 웜크림 `#F5F1E8`
- **형태는 구조로** — 랜덤 흐름 금지. 게르 천창(тооно) 구조 = 직조 격자 + 방사형 살 + 외곽 링
- 살 개수에 의미를 실을 수 있음(예: 반 정원 12 → 살 12개)
- **쓰는 곳**: 캐러셀 1장, 앱 시즌 오프닝, 영상 인·아웃트로, 발표물 표지
- **주의**: 흐름형(플로우 필드) 디더는 이미 흔함. 우리는 구조형만 쓴다

### 모드 B · 타이포 (Type)
- **바탕** 웜 화이트 `#FDFCF8` / **잉크** `#101014`
- **이미지 0.** 글자와 여백만으로 화면을 만든다
- 상단 인덱스(11px 트래킹) → 중앙 대형 카피 → 하단 구분선 + 메타
- **쓰는 곳**: 캐러셀 2~4장, 문서·소개서, 정보 전달 화면, 발표물 본문

### 모드 C · 겹침 (Riso / 물성)
- **바탕** 종이 `#F7F4EC` / 잉크 2도 `#3D5AFE` + `#FF6D00`, 블렌드 = multiply
- **의도적 미스레지스트레이션** — 두 판을 1~2mm 어긋나게. 겹친 자리가 진해지는 것이 핵심
- **쓰는 곳**: 캐러셀 마지막 CTA, 교재 챕터 간지, 상담지, 포스터, 인쇄 발표물
- **왜 우리만 되나**: 교재를 실제로 인쇄하므로 진짜 2도 인쇄가 가능하다. 디지털 온리 브랜드는 흉내만 낸다. 2도 스팟 인쇄는 4도보다 오히려 저렴

## 3. 캐러셀 문법 (확정)

| 장 | 모드 | 역할 |
|---|---|---|
| 1 · 표지 | **A 디더** | 시선 고정. 카피 1개 + 신호색 1점(막대) |
| 2 · 문제 | B 타이포 | 공감. 큰 문장 하나 |
| 3 · 근거 | B 타이포 | 숫자·구조. 숫자 일부만 신호색 |
| 4 · 방법 | B 타이포 | 단계·목록. 마지막 항목만 신호색 |
| 5 · CTA | **C 겹침** | 손 내밀기. 온기·실물감 |

**차가움(디더) → 정보(타이포) → 온기(겹침)** 순서가 서사를 만든다. 첫 장에서 멈추게 하고, 가운데에서 설득하고, 마지막에서 부른다.

- 장수가 3장이면 1(A) → 2(B) → 3(C)
- 장수가 7장 이상이면 B를 늘린다. A와 C는 각각 1장씩 고정
- **A를 두 번 쓰지 않는다.** 반복하면 시선 고정 효과가 사라진다

## 4. 적용 지도

| | 채널 | 근거 |
|---|---|---|
| **쓴다** | 인스타 캐러셀·릴스 인아웃트로, 앱 시즌 오프닝·로딩·빈 화면, 진화/보스 격파 연출, 교재 챕터 간지·다크 스프레드, 발표물 PDF 표지·간지, 상담지 표지, 모집 포스터 | 감성이 일하고 정보 밀도가 낮은 자리 |
| **안 쓴다** | 교재 본문 학습 지면, 가격·성적·리포트 등 학부모 신뢰 문서 본문, 리드크루 콘텐츠(학생 얼굴이 주인공), 몽골어 정보 전달 화면, 강사 운영 화면, Glide 앱 UI 전반 | 가독성 · "실체 없음"으로 읽힐 위험 · v9.79 미니멀 스킨 불가침 |
| **경계선** | 앱 히어로 헤더 | 헤더 한 칸까지만. 카드 영역 침범 금지 |

**발표물 9종 프롬프트와의 관계** — 「SYNK 발표물 제작 프롬프트 v1」(2026-07-28, Desktop)의 디자인 잠금값(6색 HEX·3색 초과 금지)은 **덱 본문 기준**이다. 표지·간지·챕터 구분면에는 이 문서가 우선한다. 프롬프트 세트는 이 정본보다 먼저 만들어져 SYNK FIELD를 모르므로, 발표물 제작 시 표지·간지 지시를 이 문서에서 가져와 덧붙일 것.

## 5. 금지 사항

1. 컬러를 3색 이상 쓰는 것 (R1 위반 = 컨셉 소멸)
2. 글자에 그레인·투명도·그림자·왜곡 (R3 위반)
3. 흐름형 랜덤 디더 (구조 없는 노이즈 = 상위 20% 클리셰)
4. 캐러셀에서 디더 모드 2회 이상
5. 맥시멀리즘·글리치 콜라주·스티커 (2026 유행이지만 프리미엄 교육 브랜드 신뢰를 깎음)
6. **검증되지 않은 숫자를 카피에 넣는 것** — 재등록률·합격률 등은 실집계 전까지 사용 금지

## 6. 대상별 밀도 분기

같은 규칙 3개를 지키되 정보 밀도만 나눈다.

- **10~20대 학생**: 여백 위주. 화면당 메시지 1개
- **학부모**: 같은 흑백에 정보 밀도를 올리고, 숫자를 신호색으로. 여백이 과하면 "내용이 없다"로 읽힐 수 있음

몽골 현지 학원 광고는 대체로 정보가 빽빽하고 화려하다. 그 사이에서 흑백·여백은 학생에겐 세련됨으로, 학부모에겐 공백으로 읽힐 위험이 있다.

## 7. 검증 계획 (미실행)

추측으로 끝내지 않는다. 페이스북 페이지 A/B로 판정한다.

- **A안** SYNK FIELD 흑백 캐러셀 1점
- **B안** 기존 컬러 캐러셀 1점
- 같은 예산·같은 시간대·같은 카피
- **판정 지표**: 저장률·공유율 우선, 도달은 참고만
- 개원(2027-02) 전이라 실패 비용이 거의 0

## 9. 미확정 · 유호님 판단 대기

1. **몽골 상징 사용 범위** — 게르 천창(тооно)은 국장에도 쓰이는 세속 상징으로 보이나, 상업 브랜드 사용에 대한 현지 정서는 원어민 검수 필요. 종교 상징(불교 문양)은 차용하지 않는다는 선은 유지
2. **컨셉명 표기** — 대외 표기를 SYNK FIELD로 할지, 한국어 「시냅스 필드」로 할지, 아니면 내부 코드명으로만 둘지
3. 검증 계획(§7) 착수 시점
