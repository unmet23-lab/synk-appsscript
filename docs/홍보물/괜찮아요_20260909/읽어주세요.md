# SYNK LAB 캐러셀 시안

> **초기 비교판 보존.** 후속 제작에서 승인된 현재 출발점은 [브랜드 소개·캐러셀](../브랜드소개_20260909/읽어주세요.md)입니다. 이 폴더는 과밀했던 중간 판과 읽힘을 비교한 기록으로 남깁니다.

- 주제: “괜찮아요”를 상황에 맞게 읽기.
- 구성: 일곱 장. 01.png부터 07.png까지 순서대로 봅니다.
- 크기: 각 1080×1350 픽셀.
- 전체보기.png는 확인용 모음입니다.
- 제작 상태: 완성 이미지가 있는 시안. 게시하지 않았습니다.

## 검수

- 일곱 장 중 일곱 장에서 화면 밖 글자, 한국어와 마스코트의 겹침, 서체·이미지 로딩을 확인했습니다. 전체 모음도 눈으로 확인했습니다.
- 몽골어 대조에서 의미의 큰 차이는 없다고 나왔습니다. 조건형 제목에 붙인 마침표가 어색하다는 지적을 받아 제목을 “Кофе авах”로 다듬었습니다.
- 맞춤법 서비스는 시간당 한도를 소진해 검사하지 못했습니다. 수정한 제목과 캡션을 포함한 원어민 감수가 남았습니다. 검문 통과본으로 취급하지 않습니다.
- 공용 제작 도구와 기존 원고는 변경하지 않았습니다. 만들기.cjs가 기존 펠트 제작 도구를 불러 이 시안을 재현합니다.

## 보존과 재현

PNG·원고·생성기·검사 기록을 저장합니다. 큰 내장 자산 HTML과 ZIP은 생성 결과의 중복이라 Git에서 제외합니다. 저장소 루트에서 `node docs/홍보물/괜찮아요_20260909/만들기.cjs`로 HTML을 다시 만들 수 있습니다. 이미지와 전체보기는 그대로 열 수 있습니다.

## 한국어 확인

1. 커피를 권했는데 “괜찮아요.” 마신다는 뜻일까요?
2. “커피 드릴까요?” → “아니요, 괜찮아요.” 정중하게 사양하는 말입니다.
3. 받고 싶다면 “네, 주세요.”라고 말하면 뜻이 분명해집니다.
4. “늦어서 미안해요.” → “괜찮아요.” 상대를 안심시키는 말입니다.
5. “괜찮아요?” → “네, 괜찮아요.” 상태를 묻고 답하는 말입니다.
6. “더 드릴까요?” 배가 부르다면 A “네, 주세요.”와 B “아니요, 괜찮아요.” 중 무엇을 고를까요?
7. 정답은 B. 뜻은 상황과 앞뒤 말에 따라 달라집니다. 커피를 권받으면 뭐라고 답할까요? 몽골어로 답해도 좋습니다.
