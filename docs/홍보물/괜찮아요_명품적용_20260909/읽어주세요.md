# 괜찮아요 — 명품 브랜딩 적용 시안

> **기각된 비교판 보존.** 후속 제작에서 승인된 현재 출발점은 [브랜드 소개·캐러셀](../브랜드소개_20260909/읽어주세요.md)입니다.

**상태: 유호님 기각(2026-09-09).** 정보가 빽빽하고 배치가 어수선하다는 피드백을 받았습니다. 새 제작의 좋은 예시나 발행용으로 재사용하지 않습니다. 이전 괜찮아요_20260909를 읽힘·배치의 비교 기준으로 삼습니다. 몽골어 원어민 검토도 남아 있습니다.

기존 SYNK 펠트 배경·실땀·마스코트·서체와 이전 시안의 HTML 바탕을 재사용했습니다. 문안, 학습 흐름, 지면 배치를 이번에 다시 구성하고 PNG 7장을 새로 렌더링했습니다. 기존 완성 이미지를 가져온 결과물이 아닙니다.

## 적용한 원칙

- 직접 답을 고르는 첫 장 → 상황 비교 → 새 장면 적용 → 저장용 문장으로 연결합니다.
- 한국어 문장 바로 아래 몽골어 뜻을 배치합니다.
- 기존 브랜드 자산과 절제된 색을 쓰고, 장마다 내용에 맞춰 배치를 달리합니다.
- 실제 성과·학생 사례·자동 진단 기능을 주장하지 않습니다.

## 한국어로 보는 구성

1. 커피를 마시고 싶어요. '커피 드릴까요?'에 '괜찮아요'와 '네, 주세요' 중 무엇으로 답할까요?
2. 받고 싶다면 '네, 주세요.' '괜찮아요'만 말하면 사양으로 들릴 수 있어요.
3. 이번에는 커피를 마시지 않아요. '아니요, 괜찮아요. 감사합니다.'
4. 친구가 책상에 물을 쏟았어요. '미안해요.' → '괜찮아요. 닦으면 돼요.'
5. 앞의 말과 상황에 따라 같은 '괜찮아요'의 뜻이 달라져요.
6. 물을 받고 싶다면? '물 드릴까요?' → A '네, 주세요.'
7. 받을 때·사양할 때·사과에 답할 때 쓸 세 문장을 저장해 두세요.

- 독립 검수자가 A/B 한국어 문안의 사실성과 과장 여부를 검토했습니다.
- 7/7장의 글자 안전영역, 마스코트 겹침, 서체 로딩, 이미지 로딩 검사를 통과했습니다. 전체보기와 비교 카드를 육안 확인했습니다.
