## 어디서 받나 — 확인한 곳 넷

| 곳 | 링크 | 특징 |
|---|---|---|
| **유튜브 오디오 보관함** | `studio.youtube.com` → 왼쪽 메뉴 **오디오 보관함** | 유호님 계정에서 바로. 장르·분위기·길이로 거른다 |
| **Pixabay Music** | https://pixabay.com/music/ | 계정 없이 바로 내려받기. 크레딧 표기 요구가 없다 |
| **Uppbeat** | https://uppbeat.io/ | 무료 갈래는 **설명란에 크레딧 한 줄**을 넣어야 한다 |

## 왜 이 폴더가 git 안에 있나

이 저장소는 「다시 구우면 되는 것」과 「잃으면 끝인 것」의 규칙이 다릅니다(커밋 `2c06e7a8`).
받아 온 음악은 **다시 못 만드는 것**입니다 — 사이트가 곡을 내리면 끝입니다.
그래서 `.gitignore` 가 막지 않고 git 이 쥡니다. 옆의 `BGM_개정판_깔림만.wav` 도 같은 까닭으로 여기 있습니다.

## 기계가 하는 일 (참고)

- `node 영상/자산모으기.js` 가 이 폴더의 음악 파일을 `영상/public/소리/받은BGM/` 로 옮깁니다.
- 어느 곡을 쓸지는 `영상/src/클립/연출.tsx` 의 `배경음악` 한 곳에서만 정해집니다.
- 곡의 **어느 지점부터** 쓸지도 거기서 정합니다(`시작초`) — 받은 곡은 앞이 인트로라 밋밋한 경우가 많고,
  릴은 30초라 «제일 좋은 30초»를 골라 써야 합니다.
