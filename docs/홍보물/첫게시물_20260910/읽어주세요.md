# SYNK · 첫 만남

> **현재 음성: 전량 교체 대기.** 2026-09-10 사용자 추가 지시로, DIVE와 유호 본인 목소리의 새 적용 기준이 준비되면 기존 내레이션·대사·안내를 교체합니다. 로고 반영·기존 음성 보존 검사 통과는 목소리 품질 승인과 별개입니다. 그전에는 기존 음성을 추가로 보정하거나 생성하지 않습니다.

## 2026-09-10 승인 로고 반영

현재 업로드 영상 7편, 이미지 48장, 자료 PDF 7개와 로고 자산 8종을 현행 승인본으로 갱신했습니다. SYNK는 무실땀 펠트이고 LAB·SHIFT·PULSE의 색과 스티치는 유지합니다. 01 음악 장면과 05 소개서 화면 안의 로고도 포함합니다. 직접 작성 화면 캡처 원본 2개와 이를 쓰는 04·07·11 정적 카드도 갱신했습니다. 04·07 영상은 캡처 상단 로고가 잘린 입력칸·결과 영역을 사용하므로 현재 헤더 로고 교체본을 보존합니다.

영상 7편은 기존 AAC 음성 데이터가 동일하고 길이·장면·승인 엔딩을 보존했습니다. 실제 프레임과 등장·퇴장·배경 경계를 확인하고 전 구간 디코드를 통과했습니다. [현행 로고 검증](_검토/로고반영/최종검증.json)이 현재 파일 해시의 기준이며 아래 이전 음성·표정 검토 기록은 당시의 근거로 보존합니다. 동반 6편의 새 브랜드 음성·엔딩 선정은 별도 대기 상태입니다. 이 반영은 SNS 게시 완료를 뜻하지 않습니다.

19개 계정의 첫 게시물을 회사의 브랜드 구조에 맞춰 모았습니다. 게임은 제외했습니다. 각 게시물은 **누구를 위한 계정인가 → 지금 받는 작은 경험 → 만드는 기준 → 앞으로 기대할 것**으로 이어집니다.

## 올릴 때

1. 원하는 계정 폴더의 **업로드안내.md**를 먼저 읽습니다.
2. 영상 계정은 `video.mp4`, 이미지 계정은 `upload-01.jpg`부터 번호순 파일을 사용합니다. LinkedIn은 `게시할자료.pdf` 5쪽을 하나의 문서 게시물로 사용합니다.
3. **게시문안.txt**는 공개 본문, **제목.txt**는 제목 입력란용입니다. Substack·Naver Blog는 **본문.md**의 실제 글을 편집기에 넣고 이미지를 직접 첨부합니다. HTML 파일은 검토용입니다.
4. 영상의 **자막.srt**와 **자막.vtt**를 함께 제공하며, LAB에는 몽골어와 한국어 파일도 따로 있습니다. 영상에 들어간 예문·본문과 자막의 역할을 구분했습니다.
5. **대체텍스트.txt**는 이미지 설명을 지원하는 곳에서 사용합니다. 지원하지 않는 플랫폼에서도 핵심 예시와 설명을 게시 본문으로 읽을 수 있습니다.

YouTube 긴 영상 2편은 16:9, Shorts·Reels·TikTok용 5편은 9:16입니다. Instagram 이미지 묶음은 4:5, Kakao 공개 소식 이미지는 정사각형, Pinterest는 2:3 단일 이미지, Substack 표지는 3:2입니다. 모든 플랫폼의 최신 최대 규격을 확인했다고 주장하지 않으며, 공식적으로 확인한 기능과 보수적으로 선택한 제작 규격은 [플랫폼 조사](https://support.google.com/youtube/answer/13748639?hl=en) 및 내부 `_기획/플랫폼과계정.md`에 구분했습니다.

## 자산과 첫 편의 관계

공통 SYNK는 현재 승인된 Ink/Paper 로고, 사업명은 각 고유색과 스티치를 사용합니다. 승인 마스코트의 본체·표정, 소품, 실제 소개서, 실제 작성 화면, 음악 영상의 실제 장면을 역할에 맞춰 골랐습니다. 캐릭터의 털·얼굴·의상을 새로 변형하지 않았습니다.

K-LOFI24 구간은 기존 ‘오늘 밤 제일 환한 사람’ 61.6초 전곡을 사용합니다. AI 음악 제작은 Suno, 장면·편집은 SYNK PULSE로 표시합니다. 01은 “같이 들을까요? → 이 노래는 어때요? → 좋아요. 같이 들어요.”로 곡을 권하는 대화에서 감상으로 이어집니다. 대화 때부터 같은 음악 공간을 보여주고, 그 장면이 확대되며 원곡이 작게 시작합니다. 원곡 61.6초는 모두 유지하며, 곡이 끝나면 어두운 펠트와 승인 로고의 7초 엔딩으로 마칩니다. 첫 화면의 몽글이는 눈을 깜빡이며 웃고 저장된 “먀앙” 소리로 짧게 반응합니다. 음성은 사용자 선택 B의 밝은 톤·말끝을 바탕으로 48kHz WAV로 다시 생성했고 이후 피드백에 따라 영상 속 한국어 음량을 직전본에서 30% 더 낮췄습니다. 말이 끝난 뒤 장면이 머무는 시간도 약 30% 줄였고 말하는 속도는 유지했습니다. voice-studio.wav는 따로 들을 수 있는 무손실 음성입니다.

학습·설명 구간의 배경음악도 사용자가 제공한 Suno 선곡에서 골랐습니다. LAB은 `따뜻_118`, SHIFT는 `시티팝_147`을 사용하며, 설명 음성 아래에서 작게 들리도록 조절했습니다. SHIFT의 긴 영상에는 곡의 끝과 시작을 겹쳐 연결한 버전을 사용합니다. 음악 출처와 처리 내역은 `_검토/배경음악.json`에 남겼습니다.

SHIFT의 화면은 가상 교육용 사례와 실제 제작한 자료의 시연입니다. 대표자의 육성·실제 고객 성과로 표현하지 않습니다. 일반 합성음성을 사용하며, 음성·자막 검사의 방법과 남은 한계는 검증 기록에 적었습니다.

## 제작과 게시 상태

SNS 게시, 새 계정 개설, 구독 메일 발송, 광고 집행은 수행하지 않았습니다. Threads 2개·SYNK Instagram·Naver Blog·Kakao Channel·Pinterest는 준비 계정 기록을 기준으로 제작했으며, 실제 계정·핸들·업로드 화면은 게시할 때 확인합니다. 확보하지 않은 핸들과 설정하지 않은 프로필 링크를 공개 이미지에서 약속하지 않습니다.

타겟의 세부 상황은 현행 마케팅 정본에서 가져온 기획 가설입니다. 실제 인터뷰·등록·문의·매출 효과를 검증한 결과로 세지 않습니다. 몽골어 독립 AI 의미 대조와 사람 원어민 감수도 구분합니다.

원고·렌더·현재 파일 검증의 최종 상태는 **검증결과.md**와 `_검토/납품실물검증.json`을 따릅니다. 제작 중의 파일 존재만으로 최종 검수 통과를 뜻하지 않습니다.
