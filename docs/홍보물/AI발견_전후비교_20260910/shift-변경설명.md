# SHIFT 비교판 변경 설명

2026-09-10. 같은 가상 고객 사례에서 발견과 자료 사용 안내만 좁게 바꾼 비교 원고입니다. 원본 콘텐츠와 작성 자료는 수정하지 않았습니다.

## 바꾼 곳

- 1번 카드: 휴대폰 이미지에서 A4 배포물로 바뀐다는 실제 상황과 1인 사업자 실습이라는 용도를 먼저 드러냈습니다.
- 6번 카드: 네 줄의 항목명을 캡션과 맞추고, 본문에서 완성 예시와 틀을 복사할 수 있게 안내했습니다.
- 캡션: 처음 제안을 추가해 전후를 본문만으로 비교할 수 있게 하고, 작성 자료의 정확한 이름을 밝혔습니다.
- 웹 제목·설명: 실제 내용인 고객 요청 변경, 휴대폰 이미지, A4 PDF를 사용했습니다. 새 사업·기관 키워드는 넣지 않았습니다.

## 유지한 것

2~5번 카드, 6장 구성, 소품·레이아웃, 가상 고객 표시, 세 확인 질문, PDF 한 쪽이라는 결과, 인쇄·현장 배포의 담당과 출력 확인 기준을 유지했습니다. 제목 원형 ‘한 줄 바뀐 요청, 어디를 고칠까?’도 유지합니다.

## 실제 자료 연결

작성 자료는 기존 docs/홍보물/회사별콘텐츠_20260910/02-shift/material.md입니다. 비교 페이지에서 ‘요청이 바뀐 뒤, 제안 네 줄’이라는 동일한 링크 이름으로 이 파일이나 검증된 보기 페이지를 연결해야 합니다. JSON의 nextResource는 원본 값 material.md를 유지했으므로 새 비교 폴더 기준의 상대주소로 무작정 연결하지 마세요. 새 공개 URL을 만들거나 공개 자료실에 게시했다고 쓰지 않았습니다.
