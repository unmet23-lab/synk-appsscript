요청이 바뀐 뒤, 제안 네 줄

고객의 사용처가 달라졌을 때 무엇을 고치고 무엇을 유지할지 정리하는 1인 기업 실습입니다. 한 줄의 변경 요청을 읽고, 확인 질문·수정 제안·수정 이유·다른 상황 적용을 남깁니다.

이 자료의 고객·요청·답변은 전부 가상입니다. 실제 서비스 판매 조건·고객 성공 사례·계약서가 아닙니다. 공개해도 되는 별도 예시로 연습합니다. 준비물은 메모할 화면이나 종이 한 장이며 유료 도구와 고객 원본 파일이 필요하지 않습니다.

자료는 자기 업무 정리·공개 예시 실습에 복사하고 수정할 수 있습니다. 브랜드 로고·소품은 편집 예시를 위한 표시이며 별도 재배포 허락으로 확대하지 않습니다. 수정일: 2026-09-10.

1. 처음 요청과 첫 제안을 남겨둡니다

고객의 처음 요청: “모임에서 할 일을 한눈에 보여 주세요. 휴대폰으로 읽는 안내 이미지 한 장이 필요해요.”

첫 제안 예시: “확정 문구와 제공 로고를 사용해 휴대폰으로 읽는 안내 이미지 한 장을 제작합니다. 모임에서 할 일과 연락 정보를 먼저 읽히게 정리합니다.”

변경 요청: “이번에는 현장에서 A4 종이로 나눠 줄게요.”

사용처가 휴대폰 화면에서 현장 종이 배포로 바뀌었습니다. 제목만 바꾸기 전에 결과물 형식·읽는 크기·맡을 범위를 확인합니다.

2. 바로 고치기 전에 세 가지를 묻습니다

  1. 같은 내용을 인쇄하나요?
  2. 배포할 최종 문구와 로고가 정해졌나요?
  3. 파일 제작과 인쇄 중 어디까지 필요하신가요?

가상 고객 답변: “내용은 같습니다. 확정 문구와 로고를 드릴게요. 인쇄와 배포는 직접 하겠습니다.”

답변을 근거로 분리해 적어봅니다.

확인한 것 이번 답
내용 이전과 같음
문구·로고 고객이 최종본 제공
내가 맡을 결과 A4 안내 파일 제작
고객이 맡을 일 인쇄·현장 배포
추가 확인 배포일, 파일 전달일, 로고 사용 권한

확인하지 않은 항목은 빈칸이나 ‘추가 확인’으로 남깁니다. 일정·금액·지원 횟수를 임의로 채우지 않습니다.

3. 수정한 제안 — 완성 예시

“확정 문구와 제공 로고를 사용해 A4 안내 PDF 한 쪽을 제작합니다. 인쇄와 현장 배포는 고객이 맡습니다. 배포일·파일 전달일·최종 문구·로고 사용 권한을 확인한 뒤 작업을 시작합니다. 실제 크기로 한 쪽을 출력해 작은 글자와 연락 정보가 읽히는지 확인하고 전달합니다.”

실제 업무에서는 종이·인쇄 방식·파일 요구 조건이 추가될 수 있습니다. 바뀐 범위 때문에 비용·일정이 달라지는 경우에는 별도 합의할 항목으로 남겨둡니다. 이 예시는 특정 인쇄 업체의 규격이나 법적 계약 조항을 대신하지 않습니다.

4. 어디를 왜 고쳤는지 남깁니다

부분 전 후 고친 이유
사용처 휴대폰 화면 현장 A4 종이 배포 고객이 읽는 장소와 매체가 바뀜
결과물 휴대폰 안내 이미지 1장 A4 안내 PDF 1쪽 고객이 인쇄할 파일로 전달
제작 재료 확정 문구·제공 로고 동일 고객 답변에서 내용이 같다고 확인
담당 범위 안내 이미지 제작 파일 제작 / 인쇄·배포는 고객 새 요청의 일을 누가 맡는지 구체화
확인 화면에서 읽기 실제 크기 출력 후 읽기 종이에서 작은 글자와 정보 확인

제안을 더 길게 만드는 것이 목적은 아닙니다. 바뀐 조건이 실제 결과와 확인 방법에 반영됐는지 보는 연습입니다.

6. 스스로 확인합니다

  • 처음 요청과 바뀐 요청을 각각 남겼는가?
  • 고객의 답변에서 확인된 내용과 내가 추정한 내용을 구분했는가?
  • 달라진 사용처가 결과물 형식·읽는 크기·확인 방법에 반영됐는가?
  • 내가 맡는 일과 고객이 맡는 일을 같은 뜻으로 읽을 수 있는가?
  • 인쇄·배송·배포 같은 일을 답변 없이 새로 약속하지 않았는가?
  • 변한 일정·금액·권한 중 더 합의할 항목을 남겼는가?

이 기준은 자기 점검용이며 계약 적합성·판매 성과·전문 자격을 보증하지 않습니다.

이 예시는 정답 하나가 아닙니다. 행사 영상이 필요한 경우나 원본 파일 전달 권리가 다른 경우에는 질문과 결과가 달라집니다. 이번에 배운 ‘사용처→결과→범위→확인’을 다른 조건에 적용했는지 설명하는 것이 핵심입니다.

8. 더 긴 실습으로 연결

기존 ‘첫 제안의 리허설’은 가상 공방의 조건 변경과 다른 고객에게 적용하는 연습을 다룹니다. 이번 자료만으로 연습을 마쳐도 됩니다. 더 긴 실습의 실제 접속 방법은 운영자 안내에서 연결합니다.

확인 상태: 원고가 현재 마케팅 방향·사업 발전 정본과 연결되는지, 예시가 허구로 표시되는지, 없는 고객 성과·가격·일정을 발명하지 않았는지 자체 대조했습니다. 실제 고객 사용·학습 효과·공개 게시·원격 실습 연결은 이번 원고 제작의 확인 범위가 아닙니다.
