# 같은 이야기, 두 가지 안내

2026-09-10 · LAB·SHIFT 기존판과 새 마케팅 기준판의 비교 후보. 각 6장, 게시 문안, 자료 읽기·직접 작성 페이지를 준비했다. SNS 게시·공개 웹 배포·AI 추천 효과 실험은 수행하지 않았다.

## 보는 순서

1. `index.html`에서 LAB 또는 SHIFT를 선택한다. 컴퓨터에서는 전후를 나란히, 휴대폰에서는 기존판·새 기준판 버튼으로 비교한다.
2. ‘바뀐 장 보기’는 1장과 6장을 오간다. 게시 문안 비교의 LAB 한국어 뜻·몽골어를 전환할 수 있다.
3. ‘자료까지 직접 확인’에서 예시를 읽고 빈 틀을 작성한 뒤 TXT 파일을 받는다. 입력은 서버로 전송하거나 자동 저장하지 않는다.
4. 최근 네 편 전체 보기는 기존 LAB·SHIFT·PULSE·SYNK 결과물로 연결한다.

## 두 편의 변경

| 콘텐츠 | 기존판 | 새 기준판 | 보존 |
|---|---|---|---|
| LAB ‘내일까지? 몇 시까지?’ | 시간을 묻고 답하는 예문, 날짜 바꾸기 | 친구와 준비할 때 한국어로 시간을 확인하는 용도, 질문·들은 시간·확인 답을 채우는 본문 연습, 몽골어 안내 페이지 | 카드 2~5, 핵심 한국어·몽골어 예문, 순서·소품·색·폰트 |
| SHIFT ‘한 줄 바뀐 요청, 어디를 고칠까?’ | 휴대폰 안내 이미지가 A4 배포물로 바뀌는 가상 실습 | 첫 장에서 사용처 변경을 구체화, 처음 제안을 본문에 추가, 마지막 카드와 본문 네 줄 틀의 명칭 일치 | 카드 2~5, 고객 확인 질문, 파일·인쇄 담당 구분, 가상 상황 |

차이가 크게 보이게 만들기 위해 브랜드 방향을 바꾸지 않았다. 새 기준판이 반드시 더 좋은 후보라는 판정도 아니다. 첫 장의 매력, 무엇을 얻는지 이해되는 정도, 본문 길이와 실습 편의로 비교한다. 검색·AI 언급은 실제 게시와 공개 자료 연결 이후 따로 관측할 항목이다.

## 사용 파일

- `lab/`, `shift/`: upload-01~06.jpg는 1080×1350 카드. 게시문안.txt, 제목.txt, 대체텍스트.txt, 업로드안내.md가 함께 있다.
- `비교판_업로드.zip`: 두 편의 게시용 이미지·문안·원본 실습 자료. 비교 웹 전체를 담은 배포 ZIP이 아니다.
- `lab.json`, `shift.json`: 비교판 문안과 변경 근거. discovery의 한국어는 내부 설명이며 LAB 공개 페이지에는 titleMn·descriptionMn을 사용한다.
- 원본 `../회사별콘텐츠_20260910/`을 수정하지 않았다. baseline은 비교 원본이며 편집 대상이 아니다.

## 기준과 검토 범위

- 현행 `docs/마케팅_정본.md` §7-4: 현재 고객·제공물을 유지하고 상황·내용·자료 연결을 명확하게 한다. 기관·대학·글로벌 앱을 새 주력으로 추가하지 않는다.
- 콘텐츠 원본: `docs/홍보물/회사별콘텐츠_20260910/content-b.json`, 같은 폴더의 카드·edition.css·assets·material.md. 작업 시작 기준 커밋 `95d463fdc6c16000d9c4e718554e9b4dce4067e1`. 실제 파일 내용 지문은 `_검토/원본지문.json`이다.
- 참고한 기존 사용자 방향: 기존 마케팅 의도를 흐리지 않는 비교를 요청했다. 원래 소재와 디자인을 고정한 것은 이 요청에 대한 제작 판단이며 새 결과 승인으로 기록하지 않는다.
- LAB·SHIFT 원고를 별도로 작성하고 다른 검토자가 원본과 새 문안·실습 자료·몽골어 UI를 대조했다. AI의 언어 대조이며 사람 원어민 감수는 미확인이다.
- 제한적 공개 검색에서 비교 가능한 SNS 게시물 두 개의 팔로워·반응 수를 검증하지 못했다. 기존 형식을 유지한 비교 후보이며 반응이 검증된 형식으로 부르지 않는다.
- 실제 검증 결과는 `_검토/QA.json`, `_검토/렌더.json`, `_검토/ZIP검증.json`에 기록한다. 예시 고객은 가상이며 실제 의뢰·납품·인쇄 검증 결과가 아니다.
- 완료 확인: 변경 카드 4장 저장·시각 확인, 기존 카드 8장 동일 지문, 원본 27파일 지문 보존, 웹 7페이지의 1440·390px 읽힘, 로컬 연결 60곳, LAB·SHIFT 작성문 TXT 다운로드의 줄바꿈·문자 일치, ZIP 24항목 재열기·내용 지문 대조를 통과했다. 독립 문안 검토에서 구체적 수정 결함은 발견하지 못했다. Codex 브라우저에서 비교 화면이 실제 열림을 확인했다.
- 저장 공간 부족 시 원본과 내용이 같은 baseline·CSS·자산은 디스크의 동일 파일을 참조하는 하드 링크로 중복을 줄였다. 원본과 비교용 참조 파일 모두 수정하지 않으며, QA는 양쪽 지문을 재확인한다. 새 카드 이미지는 독립 파일이다.

공용 작업 기록 갱신은 남았다. 이 작업에서 수정하지 않은 `docs/_ops/트랙.md`가 04:29 KST 확인 시 0바이트여서, 기존 본문이 없는 채로 이번 한 줄만 쓰거나 HEAD로 덮어쓰지 않았다. 원인과 다른 작업의 미커밋 기록 유실 여부는 확인 불가다. 기록할 내용: ‘LAB·SHIFT 새 마케팅 기준 비교 후보 2편 제작, 1·6장과 본문·자료 안내 보완, 원본 보존·로컬 QA 완료, 실제 게시·추천 성과·사람 원어민 감수는 미확인.’

## 다시 열기·재현

`node docs/홍보물/AI발견_전후비교_20260910/serve.cjs`를 저장소에서 실행하면 이 컴퓨터 전용 주소를 출력한다. 브라우저에서 그 주소로 연다.

빌드·검토는 제공된 Node 패키지 경로를 NODE_PATH에 지정한 뒤 `node .../build.cjs --render`, `python .../pack.py`, `node .../qa.cjs` 순서로 수행한다. 필요한 패키지는 playwright·sharp·marked이며 기존 설치를 사용한다. 원본 CSS·자산과 기준 파일의 내용이 달라졌으면 빌드는 비교 기준을 덮어쓰지 않고 멈춘다.
