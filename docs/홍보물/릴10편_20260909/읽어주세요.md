## 구성과 파일

[모아보기](index.html)에서 영상·표지·제공 카드·설명글을 함께 확인한다. 최종 출력 상태는 [제작검사](제작검사.md)의 실제 파일 검사 결과를 따른다.

편당 30초, 1080×1920, 30fps. 5구간 구성으로 첫 질문 → 뜻 확인 → 쓸 표현 → 다른 상황에서 쓰기 → 실제 카드 안내 순서다. `영상/`은 MP4, `표지/`는 PNG, `제공자료/`는 한몽 카드 PNG, `게시문안/`은 설명글과 수동 답글 원문이다. 카드 10장에 한몽 짝 46항목을 담는다.

자막·배경음악 형식이다. 한국어 내레이션이나 발음 음성은 넣지 않았다. 승인 마스코트 원본과 소품을 사용했고 몸·눈·입을 인위적으로 흔들지 않는다. 교실·방·소품은 연출 자산이며 실제 학원·학생·시설 사진이 아니다.

## 참여와 제공 운영

- 영상 자체에서 답과 쓸 표현을 먼저 준다. 댓글을 달지 않아도 설명글에서 카드의 모든 문장·주의사항을 읽고 가져갈 수 있다.
- 키워드는 카드 이미지를 원하는 사람의 요청이다. 공개 댓글·친구 태그·연락처·학교·DM 보호 설정 해제를 학습 내용의 접근 조건으로 삼지 않는다.
- 게시 후 SYNK 계정 운영자가 해당 `제공자료/gift-XX-resource-1.png`를 실제로 첨부할 때만 준비된 답글을 사용한다. ‘여기 있다’는 답글만 보내고 파일을 빼먹지 않는다. 자동 DM이나 즉시 응답은 구현·약속하지 않았다.
- 이미지 전달이 가능한 자리에서 요청한 카드만 제공한다. 해당 계정의 메시지 보호 설정 등으로 전달이 안 되면 이를 바꾸라고 요구하지 않고 이미 공개된 설명글 전문을 안내한다. 플랫폼의 실제 첨부 기능·게시 계정은 게시할 때 확인한다.
- `게시문안`의 수동 답글 구분선 아래는 설명글과 함께 한 번에 게시하는 내용이 아니다. 모아보기의 ‘설명글 복사’는 게시할 설명글만 복사한다.

이번 요청에서는 파일을 제작했다. 공개 게시·예약 발행·학생에게 발송·새 수집 양식·자동 응답 연결·광고 집행은 하지 않는다. 자료에 없는 추가 서비스나 혜택을 약속하지 않는다.

## 몽골어 방침과 검토

한국어를 문장별로 직역하는 대신 장면과 의도에서 몽골어를 작성했다. 자연스러운 문장을 우선하되 사실, 조건, 말하는 사람과 받는 사람, 제공 약속은 보존한다. 몽골어만 보는 검토 다음에 별도 한몽 뜻 대조를 진행했다. AI 언어 검토를 인간 원어민 감수로 표현하지 않는다.

검토 근거: [기획 독립검토](독립검토.md), [번역 검토](번역검수.md), [시각 검토](시각검수.md). 실제 학생의 재미·활용·반응은 게시 전 제작 검토로 검증할 수 없다. 조회수·댓글수의 성과를 만들어 적지 않았다.

`synk-brand`의 청소년에게 어린아이 말투를 쓰지 않는 원칙과 `synk-content`의 실제 제공물 검증을 적용했다. `forge`의 두 기획안과 별도 사실 검토를 통합했고, `synk-design`의 승인 자산·색·서체 및 Remotion 지침에 맞춰 제작했다.

## 게시 뒤 바꿀 여지

우선 01~03의 반응을 보며 이후 편의 순서·설명·자료를 조정할 수 있다. ‘45편을 다 올려야 한다’는 제작 부채나 새 고정 발행 달력을 만들지 않는다. 확인할 것은 학생이 무엇을 받는지 이해했는가, 자료를 실제 상황에 맞게 바꿔 썼는가, 헷갈린 표현이 무엇인가이다. 필요한 반응만 비식별로 기록한다.

## 다시 만들기

원본은 `대본.json`, 편집 코드는 저장소 `영상/src/릴10편/`, 출력 도구는 `영상/릴10편굽기.cjs`다. 옛 45편 원본·과거 검토는 삭제하지 않고 보관한다.

```powershell
node 영상/릴10편굽기.cjs --검사만
node 영상/릴10편굽기.cjs --편 gift-01
node docs/홍보물/릴10편_20260909/모아보기만들기.cjs
```

전체 제작은 `node 영상/릴10편굽기.cjs`. `--그림만` 또는 `--영상만`을 선택할 수 있고, `--재개`는 같은 소스·자산·문안과 실제 영상 해시가 일치하는 파일만 재사용한다. 문안을 바꾸면 번역·그림·영상·설명글을 함께 다시 확인한다.
