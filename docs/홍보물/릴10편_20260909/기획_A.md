# 릴 10편 기획 A — 한국에서 바로 꺼내 쓰는 작은 메모

2026-09-09 · 독립 A안 / 한국어 기획·제공자료 원고 / 몽골어 확정 전

이 안의 목표는 몽골 10대 후반·20대가 재미있는 상황을 보고, 그 상황에서 쓸 말을 바로 가져가는 것이다. 정확히 10편이며 마스코트별 복제판을 따로 늘리지 않는다. 한 편은 24~28초를 기본으로 잡고, 몽골어 자막의 실제 읽힘에 따라 조정한다.

사용자 최신 지시를 적용했다. 모든 편에 실제 제공자료를 붙인다. 기존 45편 계획과 `주는것_설계_v1.md`의 ‘자료 제공은 일부 편만’ 규칙은 이 안의 근거로 사용하지 않는다. 비용·비자·급여·학습 성과의 최신 숫자나 새 상담 약속은 만들지 않는다.

## 학생이 받는 방식

각 편에서 중요한 답을 영상 안에 먼저 준다. 같은 게시물의 설명글에는 아래 제공자료 본문을 **전부** 넣는다. 댓글·팔로우·개인정보를 먼저 내야 핵심 답을 얻는 구조로 만들지 않는다. 별도 카드가 함께 올라가는 경우에만 ‘카드에서도 가져갈 수 있어요’라고 안내한다.

키워드는 자료를 찾거나 공개 답글로 위치를 알려줄 때 쓰는 식별자다. 아래 한국어 키워드는 기획용이며, 최종 몽골어에서는 현지 학생이 짧게 입력할 자연스러운 낱말로 정한다. ‘댓글을 달면 자동으로 보내요’ 문구는 실제 자동 발송이 없으므로 쓰지 않는다. 마지막의 질문을 기계적으로 강제하지 않는다.

제공자료는 저장·복사한 다음 사용할 수 있어야 한다. 실사용 문장을 주는 칸은 한국어와 몽골어를 짝짓고, 바꾸는 자리 `[메뉴]`·`[이름]` 등은 학생이 무엇을 채울지 몽골어로 설명한다. 자동 답장·외부 링크·미발행 자료가 있어야만 성립하는 안내는 넣지 않는다.

## 번역 발주에 함께 넘길 조건

- 한국어의 문장 구조를 옮기지 않고, 아래 장면·말하는 의도·학생이 얻을 것을 보고 몽골어 안내를 직접 짓는다.
- 몽골어만 읽는 검토에서 상황과 다음 행동이 즉시 이해되는지 먼저 본다. 이어서 한국어 학습 문장과 제공 약속이 같은 뜻인지 따로 확인한다.
- 가르치는 한국어 표현, 숫자 예시, 질문과 답의 대응, 자료 수량·받는 곳은 유지한다. 유머의 표현·순서·어감은 자연스러운 몽골어에 맞춰 바꾼다.
- 몽골 학생을 한국어 미숙함으로 웃음거리 삼지 않는다. 재미는 짧아지는 메모, 뜻이 드러나는 문자, 바뀌는 사진 구도처럼 사물·정보의 변화에서 만든다.
- 한국어 학습 문장은 화면에서 눈에 띄게, 몽골어는 상황을 이해하고 자료를 쓰는 데 필요한 만큼 둔다. 두 언어로 긴 설명을 동시에 반복하지 않는다.

## 01. 커피 한 잔인데, 질문은 왜 계속 오죠?

- 문제: 음료 이름은 준비했는데 온도·장소 질문이 이어질 때 말이 길어진다.
- 훅: **“커피 한 잔 시켰는데, 질문이 또 와요?”**
- 핵심 한국어: **“아이스 라테 한 잔 주세요. 포장해 주세요.”**
- 제공자료: **내 주문 4칸 메모** / 기획 키워드 `커피`
- 재미 장치: 주문 창의 작은 빈칸들이 한 문장으로 착착 합쳐진다. 마스코트는 큰 주문 종이를 접어 휴대폰 크기 메모로 만든다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 컵 하나에 ‘아이스? / 몇 잔? / 여기서?’ 질문 카드가 붙는다. 훅 표시. | 여러 질문이 이어지는 장면을 즉시 알아보게 한다. |
| 4~11초 | `아이스` + `라테` + `한 잔` → `아이스 라테 한 잔 주세요.` | 선택한 조각이 실제 주문문이 되는 재미. |
| 11~19초 | 컵의 이동 방향 두 가지. 매장: `여기서 마실게요.` / 밖: `포장해 주세요.` | 머무는 장소를 말하는 두 표현. 두 문장을 한꺼번에 읽히지 않고 차례로 보여준다. |
| 19~26초 | 실제 주문 메모 미리보기. `온도·음료·수량·장소를 골라 쓰는 메모 / 설명글에서 바로 가져가세요.` | 무엇을 얻는지 실물로 보여준다. |

제공자료 본문 — 원하는 선택만 골라 한 문장으로 이어 쓰세요.

| 내 선택 | 꺼내 쓸 한국어 |
|---|---|
| 차가운 음료 | 아이스로 주세요. |
| 따뜻한 음료 | 따뜻한 걸로 주세요. |
| 메뉴·수량을 골랐어요 | `[메뉴]` `[한 잔 / 두 잔]` 주세요. |
| 매장에서 마실 거예요 | 여기서 마실게요. |
| 가지고 나갈 거예요 | 포장해 주세요. |

완성 예: **아이스 라테 한 잔 주세요. 포장해 주세요.** 메뉴마다 온도 선택이 가능한지는 매장에서 확인한다. ‘아아’ 같은 줄임말 없이도 주문할 수 있게 만든다. 이 자료는 매장 서비스 가능 범위를 보장하지 않는다.

출처·리스크: 자체 학습 예문. 사례 1·2는 생활 장면 선택의 참고이며 개별 문장의 권위 근거가 아니다. 음료 주문을 어학당 총비용으로 갑자기 연결하지 않는다.

## 02. ‘덜 맵게’는 ‘맵지 않게’일까요?

- 문제: 매운 정도를 낮추고 싶은데 요청의 뜻이 섞인다.
- 훅: **“‘덜 맵게’ 주문하면, 매운맛이 없어질까요?”**
- 핵심 한국어: **“덜 맵게 해 주세요.”**
- 제공자료: **내 입맛 주문 메모** / 기획 키워드 `맵기`
- 재미 장치: 고추 그림의 개수가 줄지만 마지막 하나는 남는다. 고추가 폭발하거나 사람이 고통받는 장면 없이 뜻의 차이를 보여준다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 주문표 `덜 맵게` 옆에 고추 세 개. 훅. | 결과를 먼저 예상하게 한다. |
| 4~11초 | 고추 세 개→한 개. `덜 = 원래보다 적게` | ‘덜’을 양의 변화로 이해한다. |
| 11~19초 | `맵지 않은 메뉴가 있어요?`와 메뉴판. | 매운맛이 없는 음식을 원할 때는 다른 질문이 필요함을 알려준다. |
| 19~27초 | 식당에서 꺼내 볼 메모 실물. `맵기·소스·추천을 묻는 문장 / 설명글에서 가져가세요.` | 실제로 쓸 추가 도움을 제시한다. |

제공자료 본문 — 원하는 정도를 먼저 묻고, 가능한 주문을 골라 보세요.

| 원하는 도움 | 꺼내 쓸 한국어 |
|---|---|
| 먼저 맵기를 확인해요 | 이거 많이 매워요? |
| 원래보다 덜 맵게 부탁해요 | 덜 맵게 해 주세요. |
| 매운맛 없는 메뉴를 찾아요 | 맵지 않은 메뉴가 있어요? |
| 소스를 따로 받을 수 있는지 물어요 | 소스를 따로 주실 수 있어요? |
| 순한 메뉴를 추천받아요 | 덜 매운 메뉴를 추천해 주세요. |

기억할 것: **‘덜 맵게’는 원래보다 덜 맵게 해 달라는 뜻이다.** 가게·메뉴마다 조절 가능한 정도가 다르다. 영상에서도 ‘덜 맵게=맵지 않음’으로 그리지 않는다.

출처·리스크: 자체 학습 예문. 맵기 표현의 의미만 다루며 알레르기 안전·건강 효과·특정 제품 맵기 수치는 다루지 않는다.

## 03. 세 번 ‘네?’ 대신, 필요한 부분만 다시 듣기

- 문제: 길게 들은 말 중 시간이나 장소 하나만 다시 확인하고 싶다.
- 훅: **“시간만 다시 듣고 싶은데, 처음부터 또요?”**
- 핵심 한국어: **“몇 시라고 하셨어요?”**
- 제공자료: **필요한 부분만 다시 묻는 5문장** / 기획 키워드 `다시`
- 재미 장치: 긴 문장에서 필요한 `3시` 조각만 돋보기로 확대한다. 학생을 멍한 인물로 연기하지 않는다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 예시 약속 메모: `내일 / 3시 / 도서관 앞`. 시간만 가려진다. | 듣고 싶은 정보 한 조각을 보여준다. |
| 4~11초 | `몇 시라고 하셨어요?` → `3시요.` | 질문이 답을 정확히 줄이는 변화를 보여준다. |
| 11~19초 | 장소만 가려짐. `어디라고 하셨어요?` → `도서관 앞이요.` | 같은 기능을 다른 정보에 적용한다. |
| 19~27초 | 다섯 문장 카드. `시간·장소·속도, 필요한 도움을 골라 말해요 / 설명글에 있어요.` | 복사할 자료의 용도를 분명히 한다. |

제공자료 본문 — 상대가 해 줄 수 있는 행동을 골라 요청하세요.

| 지금 필요한 도움 | 꺼내 쓸 한국어 |
|---|---|
| 문장 전체를 한 번 더 들어요 | 한 번만 더 말씀해 주세요. |
| 속도를 천천히 해 달라고 해요 | 조금 천천히 말씀해 주세요. |
| 시간만 확인해요 | 몇 시라고 하셨어요? |
| 장소만 확인해요 | 어디라고 하셨어요? |
| 글로도 확인해요 | 적어 주실 수 있어요? |

‘네?’도 되묻는 표현이다. 이를 틀렸다고 가르치지 않는다. 위 문장들은 **어떤 부분을 다시 듣고 싶은지 더 구체적으로 알려주는 선택지**다.

출처·리스크: 자체 학습 예문. `3시`와 `도서관`은 예시 약속이며 실제 일정이 아니다. 따로 읽을 연습 시간을 둔다.

## 04. 한국 친구의 ‘ㄱㅅ’, 무슨 단어일까요?

- 문제: 친구 메시지에서 자음만 있는 짧은 답을 읽기 어렵다.
- 훅: **“친구가 ‘ㄱㅅ’만 보냈어요. 무슨 뜻일까요?”**
- 핵심 한국어: **“ㄱㅅ → 감사 → 고마워.”**
- 제공자료: **친구 채팅 초성 메모 5개** / 기획 키워드 `채팅`
- 재미 장치: 자음 사이로 빠진 글자가 나타나 메시지 뜻이 열린다. 암호 해독 연출을 하되 ‘마법·치트키’라는 이름은 붙이지 않는다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 가상 채팅 `자료 보냈어요.` → `ㄱㅅ`. 훅. | 사용할 장면이 먼저 보인다. |
| 4~11초 | `ㄱㅅ` → `감사` → 친구에게 `고마워!` | 초성을 일상 뜻으로 연결한다. |
| 11~19초 | 생일 케이크 옆 `ㅊㅋ` → `축하`. 그다음 `친구끼리 편하게 쓰는 말` | 모든 상대에게 같은 표현을 쓰지 않도록 범위를 둔다. |
| 19~26초 | 5개 메모 실물. `초성 + 뜻 + 길게 쓰는 말 / 설명글에서 가져가세요.` | 자료의 추가 쓸모를 제시한다. |

제공자료 본문 — 아래 풀이는 친구 채팅에서 쓰이는 예다. 앞뒤 내용도 함께 보세요.

| 친구가 보낸 글 | 이 장면에서의 뜻 / 길게 쓰기 |
|---|---|
| ㅎㅇ | 하이, 가벼운 인사 / 안녕! |
| ㄱㅅ | 감사 / 고마워! |
| ㅊㅋ | 축하 / 축하해! |
| ㅇㅋ | 오케이 / 알겠어! |
| ㅂㅂ | 바이바이, 대화를 마치는 인사 / 잘 가! 또는 나중에 봐! |

이 자료는 **가까운 친구의 채팅을 읽기 위한 것**이다. 처음 연락하는 사람이나 선생님께는 `안녕하세요`, `감사합니다`, `알겠습니다`처럼 풀어 쓴다. 초성은 문맥에 따라 다른 말을 가리킬 수도 있다.

출처·리스크: 자체 채팅 예시. 최신 유행 순위나 ‘한국인은 모두 쓴다’는 주장을 하지 않는다. 한국어 초성은 몽골어 번역에서도 그대로 보존한다. 학생에게 존댓말로 안내하되 친구 예문 내부의 반말은 상황 표시와 함께 쓴다.

## 05. 처음 보내는 메시지, 인사 다음엔 뭘 쓰죠?

- 문제: 처음 연락할 때 ‘안녕하세요’만 보내고 용건을 잇기 어렵다.
- 훅: **“첫 메시지, ‘안녕하세요’ 다음은요?”**
- 핵심 한국어: **“오늘 수업에서 만난 [이름]이에요.”**
- 제공자료: **빈칸만 바꾸는 첫 연락 3종** / 기획 키워드 `연락`
- 재미 장치: 인사만 있던 말풍선에 ‘누구→어디서→용건’ 작은 쪽지가 들어오며 읽을 수 있는 메시지가 완성된다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 가상 휴대폰의 `안녕하세요.` 뒤에 입력 커서. 훅. | 실제 멈추는 자리를 보여준다. |
| 4~11초 | `오늘 수업에서 만난 [이름]이에요.` | 상대가 누군지 기억할 실마리를 준다. |
| 11~19초 | `아까 말씀하신 자료를 보내 주실 수 있어요?` → 한 메시지 완성. | 필요한 도움을 한 번에 밝힌다. |
| 19~28초 | 친구·선생님·동아리 첫 연락 세 장. `빈칸만 바꿔 쓰는 첫 연락 / 설명글에서 복사해요.` | 자료를 받으면 바로 할 수 있는 행동이 보인다. |

제공자료 본문 — 대괄호 안을 내 상황에 맞게 바꾸세요. 실제로 나눈 이야기와 용건만 적습니다.

| 연락할 장면 | 그대로 복사해 바꿔 쓸 문장 |
|---|---|
| 수업에서 만난 사람에게 자료를 부탁해요 | 안녕하세요. 오늘 `[수업 이름]` 수업에서 만난 `[이름]`이에요. 아까 말씀하신 자료를 보내 주실 수 있어요? 감사합니다. |
| 선생님께 과제를 확인해요 | 선생님, 안녕하세요. `[수업 이름]`을 듣는 `[이름]`입니다. 오늘 과제는 `[과제 내용]`이 맞나요? 감사합니다. |
| 동아리 모임을 문의해요 | 안녕하세요. `[동아리 이름]`에 관심이 있는 `[이름]`입니다. 다음 모임은 언제인가요? 처음 가도 참여할 수 있나요? |

짧은 조립 순서: **인사 → 내가 누구인지 → 필요한 질문 한 가지.** 선생님께 쓰는 `입니다`와 처음 만난 또래에게 쓰는 `이에요/예요`는 둘 다 존댓말이다. 문장을 외우기보다 실제 만난 상황을 넣어 쓰도록 안내한다.

출처·리스크: 실제 학생 이름·연락처·대화를 넣지 않는 자체 예문. 회신이나 동아리 참여 허용을 보장하지 않는다. 이 콘텐츠의 DM은 학습 장면이며 실제 학생에게 메시지를 발송하라는 운영 지시가 아니다.

## 06. ‘괜찮아요’가 두 번 나오는데, 뜻은 달라요

- 문제: 같은 말이 안부에 대한 답과 제안을 사양하는 답으로 쓰인다.
- 훅: **“물 줄까요? ‘괜찮아요.’ 그럼 준다는 뜻일까요?”**
- 핵심 한국어: **“아니요, 괜찮아요. 감사합니다.”**
- 제공자료: **제안에 답하는 선택 메모** / 기획 키워드 `대답`
- 재미 장치: 같은 말풍선이 질문 카드 위로 이동하자 장면이 달라진다. ‘괜찮아요’ 하나를 무조건 거절이라고 박지 않는다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 물컵을 권하는 손. `물 드릴까요?` → `괜찮아요.` 훅. | 실제로 애매할 수 있는 답을 보여준다. |
| 4~11초 | 받고 싶을 때 `네, 주세요. 감사합니다.`와 컵을 받는 손. | 의도를 분명히 하는 답. |
| 11~19초 | 사양할 때 `아니요, 괜찮아요. 감사합니다.`와 컵이 머무는 손. | 단독 답의 모호함을 줄인다. |
| 19~28초 | 선택 메모 실물. `받기·사양하기·다른 것 부탁하기 / 설명글에 다 있어요.` | 억지 반응보다 실제 대답을 돕는다. |

제공자료 본문 — 질문과 내 의도를 보고 답을 고르세요.

| 내 의도 | 꺼내 쓸 한국어 |
|---|---|
| 제안을 받아요 | 네, 주세요. 감사합니다. |
| 정중히 사양해요 | 아니요, 괜찮아요. 감사합니다. |
| 다른 것을 부탁해요 | 물로 주실 수 있어요? |
| 조금 있다 받고 싶어요 | 조금 있다가 받을게요. |
| 걱정하는 사람을 안심시켜요 | 네, 괜찮아요. 걱정해 주셔서 감사해요. |

마지막 문장은 `다친 데 없어요?`, `괜찮아요?`처럼 상대가 걱정하는 상황의 예다. 제안에 사양하는 답과 같은 장면으로 섞지 않는다. **‘괜찮아요’는 질문·표정·말투를 함께 보고 이해한다.**

출처·리스크: 자체 대화 예문. 원래 표현을 오답으로 지정하지 않는다. 응급상황 안내나 상태 판단 자료로 확장하지 않는다.

## 07. 같은 역인데 친구가 안 보여요: 출구까지 약속하기

- 문제: 약속 장소를 역 이름만 정해서 서로 다른 곳에 서 있다.
- 훅: **“우리 둘 다 같은 역인데, 왜 못 만났죠?”**
- 핵심 한국어: **“몇 번 출구에서 만날까요?”**
- 제공자료: **만날 장소 완성 메모** / 기획 키워드 `만남`
- 재미 장치: 같은 역 이름이 적힌 지도에서 두 점이 서로 다른 출구에 있다가, 출구 번호를 넣으면 한 점으로 모인다. 실제 지도처럼 오인되지 않게 단순 예시 지도를 쓴다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 가상 역의 두 출구, 양쪽에서 손을 흔드는 캐릭터. 훅. | 학생의 말실수 대신 위치 차이를 웃음으로 쓴다. |
| 4~11초 | `몇 번 출구에서 만날까요?` → `2번 출구 앞이요.` | 빠진 정보를 넣는다. |
| 11~19초 | `역 이름 / 출구 번호 / 안·밖` 세 칸이 완성된다. | ‘앞’만으로 모호할 때 안팎도 확인한다. |
| 19~27초 | 장소 완성 메모. `어디에 서 있는지 보내는 문장까지 / 설명글에서 가져가세요.` | 도착 뒤 연락까지 이어진다. |

제공자료 본문 — 아래 빈칸에 실제 장소를 넣으세요.

| 정할 것 | 꺼내 쓸 한국어 |
|---|---|
| 어느 역에서 만나요? | `[역 이름]`역에서 만날까요? |
| 출구를 정해요 | 몇 번 출구에서 만날까요? |
| 출구 밖인지 확인해요 | `[출구 번호]`번 출구 밖에서 만나요. |
| 내 위치를 알려요 | 저는 `[가게·건물 이름]` 앞에 있어요. |
| 위치를 더 확인해요 | 지금 있는 곳 사진을 보내 주실 수 있어요? |

완성 예: **`[역 이름]`역 `[출구 번호]`번 출구 밖에서 만나요. 저는 `[가게 이름]` 앞에 있을게요.** 집 주소처럼 공개할 필요 없는 정보는 공개 댓글에 적지 않는다. 이 메모는 이미 약속한 상대와 연락할 때 쓴다.

출처·리스크: 자체 예시 지도·학습 문장. 실제 역의 구조·출구 운영·최단 경로를 안내하지 않는다. 친구 위치를 몰래 추적하는 기능을 제안하지 않는다.

## 08. 옷은 마음에 드는데, 입어 보고 싶어요

- 문제: 옷가게에서 사이즈·착용 가능 여부를 짧게 묻고 싶다.
- 훅: **“마음에 드는 옷, 사이즈 두 개 중 어떤 걸 입어 보죠?”**
- 핵심 한국어: **“입어 봐도 돼요?”**
- 제공자료: **옷가게에서 고르는 5문장** / 기획 키워드 `옷`
- 재미 장치: 같은 상의가 실제 몸이 아닌 옷걸이 두 개에서 크기만 달라진다. 체형 평가·몸 비교는 하지 않는다. 훅의 몽골어는 ‘사진이나 눈대중만으로 사이즈를 결정하기 애매한 장면’에서 다시 짓는다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 같은 디자인, 다른 크기의 옷 두 벌. 훅. | 사람의 몸이 아니라 옷 선택을 보여준다. |
| 4~11초 | `입어 봐도 돼요?`와 탈의실 방향 표시. | 먼저 착용 가능 여부를 묻는다. |
| 11~19초 | `한 사이즈 큰 것도 있어요?`와 더 큰 옷걸이. | 선택을 바꾸는 실제 표현. |
| 19~27초 | 다섯 문장 메모. `사이즈·색·입어 보기 / 설명글에서 골라 쓰세요.` | 구매 강요 없이 선택을 돕는다. |

제공자료 본문 — 원하는 도움을 골라 직원에게 물어보세요.

| 원하는 도움 | 꺼내 쓸 한국어 |
|---|---|
| 입어 보고 싶어요 | 입어 봐도 돼요? |
| 더 큰 사이즈를 찾아요 | 한 사이즈 큰 것도 있어요? |
| 더 작은 사이즈를 찾아요 | 한 사이즈 작은 것도 있어요? |
| 다른 색을 찾아요 | 다른 색도 있어요? |
| 조금 더 둘러보고 싶어요 | 조금 더 둘러볼게요. 감사합니다. |

매장과 상품마다 입어 보기 가능한 범위가 다르므로 질문형을 유지한다. `큰 것`과 `작은 것`은 옷의 크기다. 사람의 체형을 좋고 나쁨으로 나누는 설명을 붙이지 않는다.

출처·리스크: 자체 학습 예문. 반품 권리·환불 가능 여부·특정 매장 규칙을 새로 약속하지 않는다.

## 09. ‘내일까지’는 알겠는데, 몇 시까지죠?

- 문제: 날짜만 들은 과제나 약속에서 시간을 더 분명히 확인하고 싶다.
- 훅: **“‘내일까지’면, 내일 몇 시까지요?”**
- 핵심 한국어: **“몇 시까지 보내면 돼요?”**
- 제공자료: **과제·모임 일정 확인 메모** / 기획 키워드 `시간`
- 재미 장치: `내일`이라는 큰 날짜 카드 안에서 시계 바늘이 계속 움직인다. 질문이 들어오면 예시 `오후 3시`에서 멈춘다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 가상 대화 `내일까지 보내 주세요.`와 움직이는 시계. 훅. | 날짜와 시각이 다른 정보라는 발견. |
| 4~11초 | `몇 시까지 보내면 돼요?` → 예시 `오후 3시까지요.` | 끝나는 시점을 구체적으로 묻는다. |
| 11~19초 | `오후 3시까지 보내면 되죠?`와 완성 메모. | 들은 조건을 한 번 확인한다. |
| 19~27초 | 일정 메모 실물. `날짜·시간·보내는 곳을 확인하는 문장 / 설명글에 있어요.` | 혼자 바로 쓸 도구로 닫는다. |

제공자료 본문 — 아직 정해지지 않은 정보만 골라 물어보세요.

| 확인할 정보 | 꺼내 쓸 한국어 |
|---|---|
| 날짜와 마감 시점을 물어요 | 언제까지 보내면 돼요? |
| 그날의 시각을 더 물어요 | 몇 시까지 보내면 돼요? |
| 오전·오후를 확인해요 | 오후 `[시각]`시가 맞나요? |
| 보낼 곳을 확인해요 | 어디로 보내면 돼요? |
| 들은 내용을 한 번 확인해요 | `[날짜]` 오후 `[시각]`시까지 `[보낼 곳]`으로 보내면 되죠? |

작성 예: **내일 오후 3시까지 단체 채팅방에 보내면 되죠?** 이 시각은 문장 연습 예시다. 실제 학교·시험·서류의 마감은 담당자가 알려준 날짜와 시간으로 채운다.

출처·리스크: 자체 학습 예문. 서류·비자·시험의 실제 마감일을 제시하지 않는다. 상대가 정하지 않은 시각을 학습자가 임의로 정하는 문장으로 바꾸지 않는다.

## 10. 사진 부탁할 때 ‘전신’ 한마디가 바꾸는 것

- 문제: 사진을 부탁했는데 원하는 구도가 말에 담기지 않았다.
- 훅: **“신발까지 찍고 싶었는데, 사진엔 얼굴만요?”**
- 핵심 한국어: **“전신이 나오게 찍어 주세요.”**
- 제공자료: **원하는 사진 부탁 메모** / 기획 키워드 `사진`
- 재미 장치: 마스코트의 상반신 사진이 아래로 열리면서 발끝까지 보인다. 외모·촬영 실력을 평가하지 않고 구도 차이를 보여준다.

| 시간 | 화면과 글 | 의도 |
|---|---|---|
| 0~4초 | 얼굴만 보이는 사진과 옆에 놓인 신발. 훅. | 원하는 결과와 보이는 결과의 간극을 사물로 만든다. |
| 4~11초 | `전신이 나오게 찍어 주세요.` → 발끝까지 프레임 확장. | 표현의 효과를 즉시 보여준다. |
| 11~19초 | `세로로 찍어 주세요.`와 세로 사진. 촬영 뒤 `감사합니다.` | 원하는 방식과 예의가 함께 있다. |
| 19~27초 | 다섯 요청 메모. `세로·가로·전신·배경 / 설명글에서 바로 가져가세요.` | 여행·친구 만남에 바로 쓸 추가 도움. |

제공자료 본문 — 먼저 사진을 부탁하고, 원하는 구도를 한 가지만 더 말하세요.

| 부탁할 것 | 꺼내 쓸 한국어 |
|---|---|
| 사진 한 장을 부탁해요 | 사진 좀 찍어 주실 수 있어요? |
| 세로 사진을 원해요 | 세로로 찍어 주세요. |
| 가로 사진을 원해요 | 가로로 찍어 주세요. |
| 발끝까지 전신을 담고 싶어요 | 전신이 나오게 찍어 주세요. |
| 뒤의 건물도 담고 싶어요 | 뒤에 건물도 나오게 찍어 주세요. |

완성 예: **사진 좀 찍어 주실 수 있어요? 전신이 나오게 찍어 주세요. 감사합니다.** 사진을 부탁할 수 있는 상황인지 먼저 살핀다. 다른 사람을 몰래 찍거나 촬영 제한을 무시하는 장면은 쓰지 않는다.

출처·리스크: 자체 학습 예문과 승인된 마스코트 이미지로 만든 가상 사진. 실제 학생·행인의 얼굴이나 타인 촬영물을 사용하지 않는다.

## 자료를 찾는 댓글에 보낼 공개 답글 원고

아래는 게시물 설명글에 각 자료 전문이 실제로 들어간 뒤 사용하는 한국어 원고다. 주담당이 최종 몽골어로 짓고 자료 카드와 함께 동봉한다. 자동 발송을 뜻하지 않으며 학생 개인정보를 추가로 묻지 않는다. 댓글은 개인 연락 없이 그 게시물 안에서 답한다.

| 편·기획 키워드 | 공개 답글 원고 |
|---|---|
| 01 · 커피 | ‘내 주문 4칸 메모’를 이 게시물 설명글에 넣어 뒀어요. 온도·음료·수량·장소를 골라 내 주문으로 바꿔 쓰세요. |
| 02 · 맵기 | ‘내 입맛 주문 메모’는 이 게시물 설명글에 있어요. 매운맛 없는 음식을 찾을 때는 ‘맵지 않은 메뉴가 있어요?’를 골라 쓰세요. |
| 03 · 다시 | 다시 묻는 다섯 문장이 이 게시물 설명글에 있어요. 시간만 다시 듣고 싶으면 ‘몇 시라고 하셨어요?’를 꺼내 쓰세요. |
| 04 · 채팅 | ‘친구 채팅 초성 메모 5개’를 이 게시물 설명글에 넣어 뒀어요. 친구가 보낸 글 옆에서 뜻을 하나씩 확인할 수 있어요. |
| 05 · 연락 | 첫 연락 세 가지 완성문이 이 게시물 설명글에 있어요. 실제로 만난 상황과 필요한 질문으로 빈칸을 바꿔 쓰세요. |
| 06 · 대답 | 제안에 답하는 문장을 이 게시물 설명글에 모아 뒀어요. 받고 싶을 때는 ‘네, 주세요. 감사합니다.’로 뜻을 분명히 전할 수 있어요. |
| 07 · 만남 | ‘만날 장소 완성 메모’는 이 게시물 설명글에 있어요. 역 이름에 출구 번호와 안·밖까지 넣어 약속한 상대에게 보내세요. |
| 08 · 옷 | 옷가게에서 쓰는 다섯 문장이 이 게시물 설명글에 있어요. 사이즈와 색을 바꿔 물을 때 골라 쓰세요. |
| 09 · 시간 | 일정 확인 문장을 이 게시물 설명글에 넣어 뒀어요. 담당자에게 확인한 날짜·시간·보낼 곳으로 빈칸을 채우세요. |
| 10 · 사진 | ‘원하는 사진 부탁 메모’가 이 게시물 설명글에 있어요. 먼저 사진을 부탁한 뒤 세로·가로·전신 중 원하는 구도를 한 가지만 더 말해 보세요. |

## A안 인수 확인

- 10편이 서로 다른 생활 문제를 다룬다. 카페 주문 / 맵기 / 되묻기 / 친구 채팅 / 첫 연락 / 제안에 답하기 / 만날 위치 / 옷가게 / 일정 확인 / 사진 구도.
- 모든 편에 3~5개의 완성된 예문 쌍이 있는 제공자료 본문이 있다. 자료를 받기 전에 댓글을 요구하지 않아도 학생이 쓸모를 얻는다.
- ‘누구나 참여한다’, ‘한국인은 모두 이렇게 쓴다’, ‘반드시 답장을 받는다’ 같은 효과 보장은 없다. 조회·참여 효과는 실측 전까지 미확인이다.
- 기획의 장면·한국어 의미·제공 범위를 검토했다. 최종 몽골어, 실제 자막 읽힘, 음성·영상 재생, 게시물 내 자료 배치는 이 문서만으로 확인하지 않았다.
- 공개 전 완성 설명글에 제공자료 전문이 들어갔는지 확인한다. 영상이 약속하는 자료 이름과 실제 자료 제목을 같게 맞춘다. 옛 45편·두 마스코트별 90파일 목표가 활성 제작 목록에 남지 않도록 통합 담당자가 갱신한다.
