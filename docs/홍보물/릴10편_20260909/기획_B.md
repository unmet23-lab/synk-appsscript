# 릴 10편 B안 — 장면에서 발견하고, 실제로 쓸 것을 받는다

작성 2026-09-09. 독립 B 초안. 최종 10편 선정을 위한 한국어 기획과 자료 원고이며 몽골어 확정본·발행본이 아니다. 사용자 최신 지시: 45편을 10편으로 축소하고 매편 재미·쓸모·제공 동기를 갖춘다. 기존 「주는 것은 일부 편에만」 규칙보다 이번 지시가 우선한다.

## 공통 제작 판단

- 핵심 한국어 하나가 실제 선택을 바꾸는 것을 눈앞에서 보여준다. 화자의 잘못을 비웃거나 매번 정답/오답 상황극으로 만들지 않는다.
- 27초 안팎, 4장면. 화면 속 상황·예문은 한국어, 설명·훅·자료 안내는 최종 단계에서 자연스러운 몽골어로 다시 짓는다. 아래 대사는 그 의미를 전달하는 한국어 작업본이다.
- 마스코트는 표정·시선·몸짓으로 재미를 만든다. 설명은 별도 내레이션/자막이 맡는다. 마스코트가 학생을 평가하거나 혼내는 연출은 없다.
- 영상에서 핵심 답을 이미 준다. 자료는 그 답을 복사하거나 실제 상황에서 꺼내 쓸 수 있게 확장한 것이다. 정답을 댓글 뒤로 숨기지 않는다.
- 편마다 안내할 실물은 아래 자료 전문이다. 완성 지면·공개 캐러셀·실제 주소가 준비된 뒤에 「준비했어요」를 발행 문구로 사용한다. 댓글 키워드는 공개 답글로 해당 지면을 찾게 해 주는 보조 통로다. 자동 DM·즉시 답장·개인 감수는 약속하지 않는다.
- 키워드는 한국어 의미를 먼저 정했다. 몽골어 한 낱말은 주담당의 자연스러움 검수 후 확정한다. 여기서 한국어 키워드를 그대로 몽골 학생에게 타이핑시키지 않는다.
- 캡션은 아래 자료 본문 4~5항목을 그대로 활용하여 영상 없이도 쓸 수 있게 완결한다. 해시태그는 0개다. 마지막 질문도 자료 수령이라는 목적을 드러낸다.

## B01 — 커피는 같은데, 다음 행동이 다릅니다

**첫 2초 훅:** 「같은 커피인데, 왜 한 잔은 여기 두죠?」

| 시간 | 화면·행동 | 대사/핵심 자막 |
|---|---|---|
| 0–2초 | 동일한 음료가 의자 쪽과 출입문 쪽으로 갈라진다. 캐릭터 시선도 두 방향을 따라간다. | 같은 커피, 어디서 마셔요? |
| 2–9초 | 카운터 질문이 뜨고 행동만 먼저 2갈래로 보여준다. | 「드시고 가세요?」 여기서 마실지 묻는 말이에요. |
| 9–19초 | 의자 쪽에 「여기서 마실게요」, 문 쪽에 「포장해 주세요」. 두 문장 중 자기 선택 하나를 따라 할 2초를 둔다. | 여기서 마실게요. / 포장해 주세요. |
| 19–27초 | 실제 주문 카드 첫 두 항목을 확대하고 나머지 항목을 넘겨 보여준다. | 카페 질문 5개와 대답을 한 장에 담았어요. 받을 분은 댓글에 [카페 키워드]. |

**자료 이름:** 카페에서 듣는 질문 5개와 내 대답. **키워드 의미:** 카페.

**자료 전체 초안**

카운터에서 내 선택에 맞는 한 줄을 골라 말해 보세요.

1. 「어떤 음료 드릴까요?」 → 「아메리카노 하나 주세요.」 원하는 음료 이름과 개수를 말합니다.
2. 「따뜻한 걸로 드릴까요?」 → 따뜻하게는 「네, 따뜻한 걸로 주세요.」 차갑게는 「아이스로 주세요.」
3. 「사이즈는요?」 → 메뉴판을 가리키며 「이 사이즈로 주세요.」 크기 이름은 가게마다 다를 수 있어요.
4. 「드시고 가세요?」 → 안에서 마시면 「여기서 마실게요.」 가져가면 「포장해 주세요.」
5. 말을 한 번 더 듣고 싶으면 「다시 한번 말씀해 주세요.」 메뉴를 함께 확인하려면 「메뉴에서 보여 주세요.」

**재미/실용성:** 두 잔의 경로를 먼저 보고 그 이유를 해독한다. 단순 단어장 대신 질문→내 선택→응답이 완성된 카운터 카드다.

**사실 근거/범위:** 직접 작성한 일반 회화 예문. 컵 재질·가격·포장 규정은 주장하지 않는다. 특정 매장이 이 질문을 반드시 한다는 뜻도 아니다.

## B02 — 메뉴 이름이 요리 장면으로 바뀝니다

**첫 2초 훅:** 「메뉴 사진 없이, 어떻게 만든 밥인지 보일까요?」

| 시간 | 화면·행동 | 대사/핵심 자막 |
|---|---|---|
| 0–2초 | 「비빔밥 / 볶음밥」 두 글자 덩어리 뒤로 같은 재료가 대기한다. | 밥은 같은데, 만드는 법이 달라요. |
| 2–9초 | 비빔밥 글자가 섞는 움직임으로, 볶음밥 글자가 팬 위로 이동한다. | 비빔밥은 섞고, 볶음밥은 볶아요. |
| 9–19초 | 「덮밥」에서 밥 위에 재료가 내려앉는다. 「이건 어떤 음식이에요?」 문장을 한 번 들려주고 따라 할 자리를 둔다. | 덮밥은 밥 위에 재료를 얹어요. 「이건 어떤 음식이에요?」 |
| 19–27초 | 실제 메뉴 카드의 사진/움직임 대응과 질문 문장을 보여준다. | 메뉴 이름 4개와 물어볼 말을 담았어요. 받을 분은 댓글에 [메뉴 키워드]. |

**자료 이름:** 그림으로 읽는 밥 메뉴 4개. **키워드 의미:** 메뉴.

**자료 전체 초안**

음식 이름에서 만드는 모습을 먼저 찾아보세요.

1. **비빔밥:** 밥에 여러 재료와 양념을 넣어 비벼 먹는 음식. 「비빔밥에는 뭐가 들어가요?」
2. **볶음밥:** 밥을 다른 재료와 함께 볶은 음식. 「이 볶음밥은 매워요?」
3. **덮밥:** 밥 위에 재료를 얹어 내는 음식. 「이 덮밥에는 어떤 고기가 들어가요?」
4. **김밥:** 밥과 여러 재료를 김으로 감싼 음식. 「김밥 한 줄 주세요.」
5. **이름에서 더 확인하고 싶을 때:** 「이건 어떤 음식이에요?」 재료·양념·맵기는 메뉴 이름만으로 전부 알 수 없으니 가게에서 확인해요.

**재미/실용성:** 텍스트가 조리 동작으로 바뀌는 시각적 발견. 익숙하지 않은 메뉴를 자기 취향에 맞게 묻도록 돕는다.

**사실 근거/범위:** 통상 음식 정의를 바탕으로 한 교육 초안. 한국어기초사전 개별 항목 접근을 시도했으나 원문을 열지 못했다. 최종 선정 시 네 단어의 정의만 공식 사전과 대조할 것. 특정 메뉴의 재료·알레르기 적합성은 추정하지 않는다.

## B03 — 「내일까지」에서 찾을 것은 날짜 다음입니다

**첫 2초 훅:** 「같은 ‘내일까지’인데, 마감 시각이 다를 수 있죠?」

| 시간 | 화면·행동 | 대사/핵심 자막 |
|---|---|---|
| 0–2초 | 가상 과제 공지 「내일까지 제출」. 달력은 채워졌는데 시계 칸은 비어 있다. | 내일까지. 몇 시까지? |
| 2–9초 | 달력·시계·제출함 세 칸 중 시계와 제출함이 비어 있음을 발견한다. | 날짜는 알았어요. 시간과 내는 곳도 확인해요. |
| 9–19초 | 「내일 몇 시까지 내면 돼요?」 발화 후 가상 답 「오후 5시까지요」로 시계가 채워진다. | 내일 몇 시까지 내면 돼요? |
| 19–27초 | 실제 제출 확인 카드 4칸을 한 번 채워 보여준다. | 과제 받자마자 확인할 4칸을 담았어요. 받을 분은 댓글에 [과제 키워드]. |

**자료 이름:** 과제 제출 전에 채우는 4칸. **키워드 의미:** 과제.

**자료 전체 초안**

과제 안내를 받으면 이 네 칸을 채워 두세요. 안내에 이미 있으면 그대로 적습니다.

1. **무엇을?** 과제 내용: ______. 「어느 부분까지 하면 돼요?」 예: 책의 페이지 범위, 발표 주제.
2. **언제까지?** 날짜 ______ / 시각 ______. 「몇 시까지 내면 돼요?」 날짜만 보고 시각을 정하지 않아요.
3. **어디로?** 제출하는 곳 ______. 「어디에 내면 돼요?」 예: 수업 페이지, 이메일, 교실.
4. **어떤 모양으로?** 파일 종류·분량 ______. 「파일은 어떤 형식으로 내면 돼요?」 지정된 이름이나 양식이 있으면 함께 적어요.

**재미/실용성:** 학생이 네 칸 중 빠진 정보를 찾는 발견형 화면. 자료가 실제 제출 행동을 조직한다.

**사실 근거/범위:** SYNK가 직접 만든 확인 도구. 학교별 마감 규정을 일반화하지 않는다. 영상의 오후 5시는 가상 예시이며 실제 학교 일정이 아니다.

## B04 — 수업 없는 칸은 같은 뜻이 아닙니다

**첫 2초 훅:** 「둘 다 수업이 비었는데, 한쪽만 공지가 왔어요.」

| 시간 | 화면·행동 | 대사/핵심 자막 |
|---|---|---|
| 0–2초 | 나란한 두 시간표. 하나는 처음부터 빈 칸, 하나는 과목 카드가 빠지며 공지 아이콘이 남는다. | 공강? 휴강? |
| 2–9초 | 두 시간표의 변화만 반복한다. | 원래 수업이 없는 시간은 공강. 예정된 수업을 쉬면 휴강. |
| 9–19초 | 휴강 공지 밑에 보강 안내를 찾는 장면. 핵심 질문을 말하고 잠시 멈춘다. | 「보강은 언제예요?」 빠진 수업을 보충하는 날을 물어요. |
| 19–27초 | 실제 공지 낱말 카드 5개를 한 장씩 넘긴다. | 학교 공지에서 만나는 5개 낱말을 담았어요. 받을 분은 댓글에 [시간표 키워드]. |

**자료 이름:** 시간표와 공지 읽는 낱말 5개. **키워드 의미:** 시간표.

**자료 전체 초안**

수업 일정이 바뀌었을 때 이 낱말과 날짜를 함께 확인하세요.

1. **공강:** 수업이 없는 시간. 「저는 다음 시간이 공강이에요.」
2. **휴강:** 예정된 강의를 쉬는 일. 「오늘 수업은 휴강이에요.」 해당 수업의 공지를 확인해요.
3. **보강:** 빠진 수업을 보충하는 수업. 「보강은 언제예요?」 날짜·시각·장소를 함께 적어요.
4. **강의실 변경:** 수업하는 방이 바뀜. 「강의실이 어디로 바뀌었어요?」 새 건물과 방 번호를 확인해요.
5. **온라인 수업:** 온라인에서 듣는 수업. 「접속 링크는 어디에 있어요?」 참여 방법과 시작 시각을 확인해요.

**재미/실용성:** 같은 빈 칸의 다른 원인을 화면 움직임으로 알아내는 재미. 공지에서 실제 확인할 질문까지 준다.

**사실 근거/범위:** 일반 대학생활 어휘. 공식 사전 원문 접근은 확인하지 못했으므로 최종 선정 시 공강·휴강·보강 3개 정의를 대조할 것. 휴강이면 반드시 특정 방식으로 보강한다는 학교 규칙을 만들지 않는다.

## B05 — 방 사진에 없는 것을 묻는 다섯 문장

**첫 2초 훅:** 「이 방 사진에서, 인터넷 속도도 보이나요?」

| 시간 | 화면·행동 | 대사/핵심 자막 |
|---|---|---|
| 0–2초 | 예쁜 가상 방 사진에 확대경. 책상은 커져 보이지만 Wi-Fi 그림은 물음표다. | 사진으로 보이는 것, 물어볼 것. |
| 2–9초 | 책상·창문·세탁·인터넷의 카드가 나뉜다. 캐릭터가 창문 사진 밖을 궁금해한다. | 방을 고를 때, 쓰는 모습도 확인해요. |
| 9–19초 | 「한번 보여 주실 수 있어요?」 문장이 창문→세탁기→인터넷 항목으로 이동한다. | 「창문 밖을 보여 주실 수 있어요?」 이렇게 구체적으로 물어요. |
| 19–27초 | 실제 방 보기 질문표 앞면/뒷면을 보여준다. | 방 볼 때 꺼내 읽는 질문 5개를 담았어요. 받을 분은 댓글에 [방 키워드]. |

**자료 이름:** 방 보러 갈 때 꺼내 읽는 질문 5개. **키워드 의미:** 방.

5. **안내 근거:** 「이 내용을 확인할 수 있는 공식 안내를 보내 주실 수 있어요?」 기관 ______ / 페이지 또는 문서 ______ / 확인 날짜 ______ / 추가로 물을 것 ______.

**함께 쓸 한 문장:** 「이 금액에 무엇이 포함돼요?」 같은 항목을 두 번 적지 않았는지 보고, 미확인 금액을 임의로 채우지 않아요.

**재미/실용성:** 작은 학비 종이가 펼쳐지며 숨은 비용 숫자를 폭로하는 대신, 내가 직접 채울 생활 항목이 드러난다. 단순 표현집보다 유학 상담에 실제 가져갈 이유가 분명하다.

**사실 근거/범위:** 직접 작성한 정보 수집 양식. 대학별 가격·비자 재정 요건·송금·보증금 반환 규칙을 주장하지 않는다. 기존 비용표의 오래된 숫자도 가져오지 않는다. 이 양식을 완전한 유학 비용 목록이나 재정 조언으로 포장하지 않는다.

## 통합에 권하는 선택

B03(제출 4칸), B05(방 보기), B06(문의 메일), B10(비용 질문표)이 B의 가장 강한 네 편이다. 학생이 실제 한국어를 쓰는 일과 앞으로 준비할 일을 같은 자료로 연결한다. B02(메뉴 움직임)와 B09(다른 출구)는 시각적 재미가 선명하다. B01·B07·B08은 A안과 겹치면 더 완성도 높은 한 편을 남긴다.

본 초안의 남은 검증: B02·B04의 개별 사전 정의 공식 대조, 선택된 10편의 몽골어 재집필·원문 비공개 자연스러움 검수·의도 대조, 실제 27초 읽힘, 자료 실물 제작과 수령 경로 확인. 여기서는 공개 게시나 실제 학생 성과를 확인했다고 보고하지 않는다.
