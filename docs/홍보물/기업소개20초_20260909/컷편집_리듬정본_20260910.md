# SYNK 실사 광고 컷 편집 — 지루하지 않고 고급스럽게

> 조사·적용일 2026-09-10. Galaxy → DaVinci 실사 광고와 유호님이 제공하는 한 영상의 후속 편집 기준이다. 현재 촬영·색관리 값은 `S26Ultra_DaVinci_스튜디오정본_20260910.md`, 공통 호흡은 `docs/명품_기준_v1.md` §3-1을 따른다. 이 문서는 설정값으로 이야기·재미가 자동 완성된다는 뜻이 아니다.

## 사용자가 원하는 것과 편집 판단

사용자 실제 요청은 “화질이 좋아도 컷전환이 너무 느리거나 지루하면 안 된다”, 현재 방법을 조사해 적용하고 다음 편집에도 기억하라는 것이다. 색감 세팅에 대한 긍정은 현재 방향에 대한 평가이며, 아직 받지 않은 촬영본이나 모든 효과에 대한 승인은 아니다.

편집의 목표는 보는 동안 **새 정보·행동·감정이 이어지고, 중요한 장면이 남는 것**이다. 현재 회사 기준인 샷 1.5~3.0초를 기본 호흡으로 삼는다. 3초를 넘는 샷도 행동·표정·증명·읽기에 필요하면 유지한다. 동일 간격 자동 분할이나 전체 배속으로 이 호흡을 맞추지 않는다. 샷 길이는 과학적 보편 최적값이나 플랫폼 알고리즘 요구가 아니다.

TikTok 공식 안내는 도입–본문–마무리와 움직임·글자·소리의 역할을 제시한다. 기업 영상 실무자는 인터뷰에서도 장애물과 변화가 있는 이야기 구조를 먼저 찾는다. 이를 현재 목적에 적용해 **결과 또는 궁금증 → 실제 문제 → 시도/판단 → 증거 → 기억할 마무리**를 출발점으로 사용한다. 실제 발언·사건에 없는 실패나 성과를 만들어 넣지 않는다. [TikTok Creative Codes](https://ads.tiktok.com/business/en-US/creative-codes), [Reuben Evans의 기업 영상 편집 경험](https://blog.frame.io/2018/12/03/remain-sane-cutting-mundane/).

## 컷을 정하는 실전 방법

아래는 재료에 맞게 선택하는 방법들이다. 한 편에 전부 사용하거나 사용 횟수를 채우지 않는다.

| 방법 | 실제로 적용할 순간 | 유호님 영상에서의 예 |
|---|---|---|
| 결과 선공개 | 처음부터 볼 이유가 보일 때 | 가장 좋은 결과 프레임·흥미로운 실제 한마디를 앞에 두고 과정을 설명 |
| 말의 의미 단위 편집 | 반복·말실수·준비 동작이 다음 정보를 늦출 때 | 같은 설명 두 번 중 명료한 한 번을 남김. 부정어·조건·핵심 숨은 보존 |
| 하드 컷 | 새 정보·행동·판단이 시작될 때 | “그래서 바꿨습니다”와 실제 변경 화면을 직접 연결 |
| J컷 | 다음 장면을 소리로 먼저 예상하게 할 때 | 다음 문장이나 현장음을 먼저 듣고 관련 화면으로 전환 |
| L컷 | 말을 듣는 동안 내용을 눈으로 확인하게 할 때 | 유호님 설명은 이어 두고 실제 작업 화면·손·결과물로 전환 |
| 동작 연결 | 손·시선·물체 움직임이 다른 샷으로 이어질 때 | 노트에 손을 뻗는 움직임 중 실제 노트 상세샷으로 연결 |
| 매치 컷 | 형태·방향·소리가 다음 장면과 닮았을 때 | 원형 물체→원형 요소처럼 시선이 찾을 자리를 이어 줌 |
| 보조 장면(B-roll) | 말의 내용을 증명하거나 필요한 생략을 덮을 때 | 실제 전후 결과·화면 기록·물건의 세부를 보여 줌 |
| 의도된 점프 컷 | 시간 생략이나 반응 자체가 재미일 때 | 잠깐의 시행착오와 실제 표정을 남겨 리듬을 만듦 |
| 화면 크기 변화 | 강조점에 가까이 가야 할 때 | 중요한 단어에서만 제한적인 재구도. 같은 얼굴을 계속 확대·축소하지 않음 |
| 시선 연결(eye trace) | 빠른 컷에서도 다음 주제를 바로 찾게 할 때 | 앞 컷의 얼굴·손 위치와 다음 컷의 주목점을 가깝게 맞춤 |
| 빠름–쉼–빠름 | 결과·감정이 묻히거나 속도가 단조로울 때 | 짧은 과정 컷 뒤 핵심 증거·반응을 충분히 보이고 다음 정보로 이동 |
| 질문과 회수 | 뒤를 볼 이유와 납득할 결말이 있을 때 | 도입에 보여 준 실제 문제를 결과 화면에서 해결 |
| 소리의 변화 | 이야기의 전환을 귀로도 느껴야 할 때 | 결정 순간의 음악 여백·실제 동작음·다음 공간의 환경음 |
| 대비와 반응 | 예상과 실제의 차이가 재미일 때 | 실제 기대→실패 화면→유호님 반응. 조작한 반응·뜬금없는 밈은 기본에서 제외 |
| 짧은 마무리·콜백 | 핵심이 끝났는데 로고·설명이 늘어질 때 | 마지막 실제 한마디나 도입의 이미지로 닫고 필요한 행동 안내만 남김 |

J컷은 다음 샷의 소리가 화면보다 먼저 시작하고, L컷은 앞 샷의 소리가 다음 화면에 이어진다. 서로 다른 소리·화면의 연결로 흐름을 만든다. [Adobe J/L컷](https://helpx.adobe.com/kr/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html).

매치 컷은 시각·동작·음향의 공통점으로 장면을 연결하며, 점프 컷은 의도와 전체 톤이 있을 때 선택한다. [Adobe 매치 컷](https://www.adobe.com/in/creativecloud/video/discover/match-cut.html), [Adobe 점프 컷](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/jump-cut.html). 빠른 편집의 주목점 정렬과 4K 원본 재구도는 편집자 Jonny Elwyn의 실무 팁도 참고했다. [Frame.io 편집 팁](https://blog.frame.io/2022/10/03/7-simple-video-editing-tricks/).

## 첫 편집에 사용할 값

수치는 모두 **검토용 시작값**이다. 공식 자료가 보장하는 정답이 아니며 실제 말·움직임·읽힘으로 수정한다. 카메라의 프레임레이트를 빠른 편집 때문에 바꾸지 않는다.

| 항목 | 시작점과 조정 기준 |
|---|---|
| 첫 도입 | 첫 1~2초 안에 주제나 볼 이유를 보이는 안을 시험. 긴 인사·독립 로고 인트로는 생략 후보 |
| 기본 샷 | 현재 회사 기준 1.5~3.0초. 정보·행동 하나를 읽고 다음으로 연결 |
| 짧은 삽입 | 0.5~1초는 이미 이해할 수 있는 동작·디테일에만 시험. 새 설명·작은 화면 글자에는 사용하지 않음 |
| 유지할 샷 | 감정·증거·실제 행동·복잡한 읽기에 필요하면 3초 이상. 그 이유를 편집 메모에 남김 |
| J/L컷 | 0.15~0.5초 겹침부터 들어 봄. 24fps에서 약 4~12프레임. 문장이나 환경음에 따라 훨씬 길어질 수 있음 |
| 무음·숨 | 긴 빈 시간과 중복은 줄이되 고정 dB 문턱으로 일괄 삭제하지 않음. 웃음·호흡·어미·반전 직전의 멈춤은 의미로 판단 |
| 오디오 접합 | 클릭음이 있으면 파형을 보며 아주 짧은 페이드부터 조정. 대사 페이드는 영상 프레임 간격에 강제로 맞추지 않음 |
| 전환 효과 | 하드 컷·J/L컷이 기본. 디졸브는 시간/감정 이동, 동작 전환은 실제 연결 근거가 있을 때만 |
| 음악 박자 | 주요 악센트·구절 전환과 컷을 연결. 모든 비트에 자르지 않고 대사·표정 타이밍을 우선 |
| 화면 글자 | 핵심 구절 단위로 읽을 시간을 확보. 화면이 바뀌어도 자막은 유지 가능. 단어마다 큰 튀는 효과를 반복하지 않음 |
| 마무리 | 마지막 정보·여운·읽힘을 끝낸 뒤 종료. 고정 7초 로고나 억지 무한 루프는 기본값 아님 |

4K 원본을 4K로 납품할 때 확대는 유효 디테일을 줄인다. 1080p 납품에서 확보되는 크롭 여유와 구분하고 피부·머리카락·글자를 최종 해상도에서 확인한다. 24fps를 억지 슬로모션으로 늘리거나 얼굴·손을 보간하는 속도 효과를 기본으로 넣지 않는다.

## 영상 하나로 작업할 때

원본 한 파일만으로 대사 정리, 의미 단위 재배치, 점프 컷, 절제된 재구도, 자막, 소리 연결을 시작할 수 있다. 배경·피부·색 마감도 기존 정본을 따른다. 원본에 다른 각도·동작·실제 결과가 없으면 그 장면이 존재하는 것처럼 만들지는 않는다.

가능하면 촬영 시작·끝에 2초 정도 여유를 두고, 말실수 뒤에는 잠깐 쉬었다 문장을 다시 말한다. 이 여유는 원본의 편집 재료이며 완성본에는 필요할 때만 남긴다. 추가 B-roll은 필수가 아니다. 필요하면 같은 파일 안에 실제 물건·손·작업 동작을 이어 찍어도 된다. 카메라 이동·노출 변경 구간은 완성 컷에서 제외한다.

한 파일에 서로 다른 구도나 무음 구간이 여러 개 있어도 자동 장면 검출 결과를 완성 컷으로 확정하지 않는다. 최종 대본과 말의 의미를 먼저 듣고 쓸 범위를 고른다.

## DaVinci에서 실제 준비하는 것

사용자는 Studio를 보유하지 않는다. 현행 `tools/davinci-s26u-free-prepare.py`는 앱 밖에서 원본 보관·편집 중간본·프록시·이 안내서의 버전 사본을 준비한다. **아래 타임라인/트랙 구조는 일반 Resolve UI로 만든다.** `tools/davinci-s26u-one-video.py`의 프로젝트 자동 생성은 Studio 전용 선택 경로이며 현재 실행하지 않는다. 실행 조건·현재 UI 적용 범위는 [촬영·색관리 정본](S26Ultra_DaVinci_스튜디오정본_20260910.md)을 따른다. 샷 선택·삭제·음성 재생성·일괄 전환 적용은 자동 실행하지 않는다.

- `00_SOURCE_FULL`: 가져온 원본 전체를 놓는 보관 타임라인.
- `01_EDIT_RHYTHM`: 위 타임라인을 복제한 작업 타임라인.
- 기존 영상·음성 트랙을 유지하고 보조 장면, 그래픽, 현장음, 효과음, 음악 트랙을 추가한다. 원본 음성이 여러 트랙이면 모두 유지한다.
- 타임라인 시작 안내 마커에 이번 기준의 위치를 남긴다. 1.5초마다 강제 컷 마커를 만들지 않는다.
- 작업 폴더의 `editorial/`에 이 기준의 내용 지문이 붙은 사본을 보관한다. Free의 실행별 `free-prepare-*.json`은 파일 준비 결과만 기록하며 앱 준비/창작 완성은 false로 남긴다. Studio 도구의 `resolve-setup-report-*.json`과 구분한다.

| 작업 자리 | 사용 방법 |
|---|---|
| Edit 페이지 | 대사와 보조 장면을 함께 보며 조립. 파형을 표시하고 음성–화면 동기 관계를 확인 |
| Ripple Trim | 빈 시간·반복을 줄일 때 사용. 뒤의 대사·자막·음악이 무엇과 함께 이동하는지 확인 |
| Roll Trim | 전체 길이는 유지하며 두 샷의 경계를 옮길 때 사용 |
| Slip Trim | 컷 길이와 자리는 유지하고 더 좋은 표정·동작 범위로 바꿀 때 사용 |
| Linked Selection | 평소 음성–화면 연결 유지. J/L컷에서 필요한 경계만 독립 조정하고 입모양 동기 재확인 |
| 마커 | 실제 원본을 보고 도입 후보·증거·감정·소리 전환·재검토 지점을 표시 |
| Fairlight | 대사 명료도, 현장음의 연속성, 효과음과 음악의 상대적인 크기를 실제로 듣고 조정 |

위 트림·파형·여러 타임라인·트랙 관리 방법은 Blackmagic 공식 Edit 안내에 근거한다. [Resolve Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit). 무료판에서도 파형과 실제 청취로 기본 컷 편집을 진행할 수 있다. 다만 Python으로 이 작업공간을 자동 준비하는 기능은 21.1에서 Studio가 필요하므로 수동 편집 가능과 자동 실행 가능을 구분한다. [Blackmagic 21.1 릴리스 노트](https://www.blackmagicdesign.com/support/content/readme/59dd4eef1f4941c29fb8dc48b33f5c87).

UI 파형 표시·Linked Selection·단축키 같은 앱 화면 상태는 스크립트가 적용했다고 보고하지 않는다. 실제 편집 시 화면에서 확인한다. 설치 파일과 모의 API 검사는 실제 Resolve 실행 성공이나 영상의 재미를 증명하지 않는다.

## 20초 광고의 리듬 예시

아래는 원본이 이런 내용을 담았을 때의 설계 예시이며 고정 템플릿·실제 성과 대본이 아니다.

| 시간 | 보여줄 역할 | 리듬 |
|---|---|---|
| 0~2초 | 실제 결과 일부 또는 흥미로운 한마디 | 첫 장면에 볼 이유 |
| 2~5초 | 왜 어려웠는지 | 한 문장과 증거 컷 |
| 5~10초 | 실제 시도·선택 | 말은 연결하고 의미 있는 동작·화면으로 전환 |
| 10~15초 | 달라진 결과 | 중요한 증거는 충분히 보임. 짧은 컷 수 채우기 금지 |
| 15~18초 | 실제 반응·핵심 가치 | 음악에 여백을 주거나 사람의 반응을 살림 |
| 18~20초 | 마지막 한마디·브랜드·필요한 다음 행동 | 읽고 이해할 수 있게 마무리 |

## 후속 편집자가 진행할 순서

1. 원본을 보고 들으며 목적·실제 핵심·가장 좋은 한마디를 고른다. 타임코드를 기록한다.
2. 말만 들어도 의미가 이어지는 러프 컷을 만든다. 반복을 줄이되 발언의 조건·맥락을 바꾸지 않는다.
3. 처음 10~15초는 도입과 리듬을 비교할 수 있는 짧은 샘플로 확인한 뒤 전체로 확장한다. 매번 별도 승인을 요구하는 절차가 아니라 기존 자연스러운 후보정 흐름의 작업 단위다.
4. 보조 장면·동작·시선·J/L컷으로 그림을 잇는다. 핵심 증거와 표정에는 시간을 준다.
5. 실제 목소리·환경음·음악의 크기와 연결을 듣고, 최종 자막을 붙인다. 현재 승인된 음원·로고·서체를 사용한다.
6. 휴대폰 크기 재생, 소리만 듣기, 무음 자막 읽기로 지루한 구간·말 잘림·읽기 부족·갑작스러운 음량을 확인한다. 어떤 컷을 왜 유지/변경했는지 기존 결과에 짧게 기록한다.

게시 후 데이터가 생기면 이탈 구간을 실제 장면과 대조한다. YouTube의 재시청 상승은 재미뿐 아니라 이해가 어려워 반복 재생한 결과일 수도 있다. 30초 도입 지표나 일부 주요 구간 표시 조건을 20초 광고에 그대로 적용하지 않는다. 아직 게시·측정하지 않은 영상의 유지율 개선을 성과로 기록하지 않는다. [YouTube 시청 지속 시간 안내](https://support.google.com/youtube/answer/9314415?hl=en).
