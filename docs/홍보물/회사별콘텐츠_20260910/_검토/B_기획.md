## 1. LAB — 내일까지? 몇 시까지?

제작 데이터: ../content-b.json 의 lab. 완성 예시·빈 틀·답 변경·자기 점검·다른 상황 적용: ../01-lab/material.md. 신규 몽골어와 한국어 뜻: ../01-lab/translation-ko.md.

한 장면은 친구와 함께 하는 일에 필요한 사진을 보내는 것입니다. ‘내일까지’라는 요청에 추가 질문을 한 뒤 ‘내일 저녁 여섯 시’ 답을 듣고 확인합니다. 사람을 웃기거나 잘못을 지적하는 대신, 필요한 조건을 더 묻는 선택을 보여줍니다.

카드 6장: 요청 → 시간 질문 → 답 → 내 말로 확인 → 날짜 바꾸기 → 저장할 빈 문장. 선택은 ‘내일/금요일/월요일’ 한 곳으로 실제 답을 바꿉니다. 소품은 공책·편지·책·나침반, 문장이 주인공입니다. 별도 얼굴·학교·촬영·가입·공개 댓글 없이 가치가 완결됩니다.

공개 한국어 핵심:
- 내일까지 사진을 보내 주세요.
- 내일 몇 시까지 보내면 돼요?
- 내일 저녁 여섯 시까지요.
- 네, 내일 저녁 여섯 시까지 보낼게요.

게시문안은 몽골어로 전체 예문과 뜻을 제공하며 마지막 선택 질문은 “어떤 날짜를 고를 건가요?”입니다. 실제 신규 번역이므로 사람 원어민 감수 전이고 독립 의미 대조가 필요합니다.

## 3. PULSE — 〈밤의 답장〉, 대사 없는 소품 이야기

이 제목은 이번 작품 가제이며 새 브랜드·가수 이름이 아닙니다. 감상 앞의 이름은 작품명, 제작 크레딧은 SYNK PULSE입니다.

작은 사건: 밤의 책상에서 ‘잘 도착했어요’라는 편지를 읽고 ‘다음엔 같이 가요’라는 답장을 남깁니다. 한 통의 도착이 다음 만남의 답으로 바뀌며 끝납니다. 배우·실학생·고객 이야기가 아닌 창작 장면입니다.

권장 구조는 6장면이며 음악을 실제 들은 뒤 길이를 조절합니다.
1. 닫힌 편지와 어두운 책상. 제목은 작게, 감상 시작을 막는 소개 카드 없음.
2. 봉투에서 꺼낸 편지: “잘 도착했어요.”
3. 편지 곁에 열린 공책. 읽은 뒤의 짧은 머무름.
4. 빈 답장 위에 한 줄: “다음엔 같이 가요.”
5. 답장을 봉투에 넣고 처음 온 편지는 책갈피로 남김.
6. 보낼 편지와 읽던 책이 함께 있는 조용한 끝. 강의·등록·댓글 안내 없음.

시각 경로: 승인 내 방 밤/편지봉투/공책과 연필/책 소품을 읽은 뒤 장면 목적에 맞게 조립합니다. 사진처럼 놓는 물건의 크기·시점·그림자를 맞추기 어렵다면 정직한 탁상 애니메이션으로 연출하며 실제 촬영이나 수공예로 소개하지 않습니다. 마스코트의 얼굴·털·몸을 바꿀 필요가 없습니다. 고유 사건을 만드는 새 이미지가 필요하면 승인 자산을 기준으로 공식 이미지 생성 통로를 사용합니다.

음원 선택의 경계: 기존 파일 영상/public/klofi20260909/song.wav 는 현행 원고에서 61.6초 〈오늘 밤 제일 환한 사람〉으로 확인됩니다. 같은 음원을 쓴다면 새 곡이라고 쓰지 않고 ‘기존 곡에 새 장면을 붙인 영상’으로 명시합니다. B는 실제 청취·권리 재확인을 하지 않았으므로 최종 음악·절단 위치·곡 감정 일치를 확정하지 않습니다. 다른 음원은 담당자가 실제로 듣고 이름·길이·이용권·끝 여운까지 확인한 뒤 정합니다.

공개 캡션 초안:
“편지가 도착한 밤, 책상 위에 답장 한 통이 더 생겼습니다.
〈밤의 답장〉
도착한 말: ‘잘 도착했어요.’
남겨 둔 말: ‘다음엔 같이 가요.’

위 음악 자리의 미확정 문구를 공개 원고에 그대로 남기면 안 됩니다. 감상만으로 한 편을 끝냅니다. 도착하지 않은 후속편·자동 재생목록·효과를 약속하지 않습니다.

## 4. SYNK — 한 편 뒤에, 쓸 수 있는 원본

이 묶음의 실제 인수물을 본체 기록의 소재로 삼습니다. 제작 뒤 파일이 실제 생기고 열리는 것을 확인한 후 다음 문안을 사용합니다. 아직 만든 파일을 확인하지 않았다면 완료형으로 내보내지 않습니다.

5장 제안:
1. “한 편 뒤에, 쓸 수 있는 원본” — 이번 LAB 또는 SHIFT 완성 카드 실물 한 장.
2. “그대로 올리는 파일” — 완성 이미지의 실제 사용 크기와 게시문안 한 줄.
3. “그대로 읽는 글” — 그림 없이도 의미가 이어지는 예문·본문.
4. “내 일에 맞게 고치는 원고” — 완성 예시와 빈 틀의 실제 일부.
5. “다음 사람이 쓸 때까지” — 업로드 이미지·본문·수정 원본을 함께 제공. 실제 게시와 이용자 효과 확인은 별도.

공개 캡션 최종 후보:
“우리는 한 편을 만들 때, 다음 사람이 그 내용을 어떻게 쓸지도 함께 정리합니다.
이번에는 완성 이미지 옆에 그대로 읽을 본문과 고쳐 쓸 원고를 뒀습니다.
LAB에서는 한국어 질문 한 문장을 자기 날짜로 바꾸고, SHIFT에서는 바뀐 요청에 맞춰 제안 네 줄을 다시 씁니다.
이미지는 게시할 때, 글은 내용을 읽고 복사할 때, 원고는 자기 상황에 맞게 고칠 때 쓰도록 나눴습니다.
이번 기록은 공개용 예시와 파일의 제작 기록입니다. 실제 학생·고객의 성과나 SNS 게시 결과를 뜻하지 않습니다.
그 일을 이어 맡는 사람이 쓸 수 있는 자리까지, SYNK.”

카드의 이미지는 이번 실제 산출물을 재사용하고 코드 화면·파일명 목록으로 시각을 대체하지 않습니다. SYNK는 Ink/Paper 중립 로고를 쓰고 LAB/SHIFT는 각 사업명 고유색만 둡니다. 본체 핸들은 아직 희망값일 수 있어 확정하지 않은 링크·QR을 쓰지 않습니다.
