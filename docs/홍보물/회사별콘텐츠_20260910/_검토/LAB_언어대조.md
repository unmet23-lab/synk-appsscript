## 2. 별도 한몽 의미 일치 대조

| 한국어 | 몽골어 | 대조 |
|---|---|---|
| 내일까지 사진을 보내 주세요. | `Зургаа маргааш гэхэд явуулаарай.` | `маргааш гэхэд`가 ‘내일까지’라는 마감, `явуулаарай`가 보내 달라는 요청을 보존. `Зургаа`는 자기 쪽 사진이라는 문맥으로 읽힘. 실제 개인 사진을 제출하라는 뜻은 상황·가상 예시 표시로 제한 |
| 내일 몇 시까지 보내면 돼요? | `Маргааш хэдэн цаг гэхэд явуулах вэ?` | 마감 시각을 묻는 핵심 의도 일치. 한국어 `-면 돼요?`를 단어마다 옮기지 않고 자연스러운 질문으로 처리 |
| 내일 저녁 여섯 시까지요. | `Маргааш оройн зургаан цаг гэхэд.` | 내일·저녁·6시·마감 모두 보존 |
| 네, 내일 저녁 여섯 시까지 보낼게요. | `Тэгье. Маргааш оройн зургаан цаг гэхэд явуулъя.` | 수락하고 자신이 보내겠다고 확인하는 대화 의도 일치. `явуулъя`는 문맥상 화자의 실행 의사이며 여기서 별도 서비스 약속으로 확대되지 않음 |
| 금요일 몇 시까지 보내면 돼요? | `Баасан гарагт хэдэн цаг гэхэд явуулах вэ?` | 금요일과 마감 질문 보존 |
| ___ 몇 시까지 보내면 돼요? | `___ хэдэн цаг гэхэд явуулах вэ?` | 빈자리에 날짜를 넣는 구조 일치. 예시 내일/금요일/월요일의 한국어 조사 없이 쓰는 형태도 문법적으로 가능 |
| 답을 들은 뒤 정한 시간을 다시 말해 보세요. | `Хариуг сонсоод, тохирсон цагийг давтаж хэлээрэй.` | 상대의 답을 듣고 정한 시각을 반복하는 뜻 일치 |
| 연습은 혼자 해도 되고 댓글은 선택이에요. | `Дасгалыг өөртөө хийж болно; сэтгэгдэл бичих шаардлагагүй.` | 기본 내용을 받는 데 공개 댓글이 필요하지 않다는 뜻 일치 |

양쪽 캡션은 문장별 직역문이 아니라 같은 장면과 학습 행동을 설명하는 별도 편집이다. 첫 캡션의 `дуусгах цагаа`는 마칠 시간을 뜻하며 한국어 `마칠 시간`과 대응한다. 다음 문단에서 ‘사진을 보내는’ 상황으로 한정하여 뜻을 구체화한다.

## 3. 수정 요청과 제작 주의

### P2 · 1장 상황이 보내는 날짜를 먼저 확정함

- 위치: `content-b.json:9`, `lab.slides[0].body`.
- 현재: `Хамт хийх ажил байна.\nЗургаа маргааш явуулна.`
- 재현: 몽골어 상황만 읽으면 ‘사진을 내일 보낸다’가 이미 정해진 상태가 된다. 아래 요청은 ‘내일까지’이므로 오늘 보내도 되는 마감이고, 수업에서는 정확한 시각을 아직 묻는 단계다.
- 추천: `Хамт хийх ажил байна.\nЗургаа явуулах хэрэгтэй.`
- 뜻: ‘함께할 일이 있어요. 사진을 보내야 해요.’ 날짜를 앞서 확정하지 않고 요청문에서 마감을 처음 받게 한다.
- 상태: 통합 담당에게 전달. 이 문서 작성 시 대상 원고는 미수정.

### 시각 제작에서 확인할 부분

- 4장 한국어 `네, 내일 저녁 여섯 시까지 보낼게요.`와 몽골어 응답은 다른 장보다 길다. 제목·설명을 작게 만드는 대신 주요 문장을 두 줄로 배치하는 것이 적절하다.
- 제목 `Өдрийг солиорой`, `Цагаа тодруулъя`는 키릴 글자의 실제 폭으로 확인한다. 한글 글자 수만으로 같은 크기를 정하지 않는다.
- 카드 4의 흐름 `Асуулт → хариу → батлах`는 뜻을 전달하는 보조 표시다. 이 줄 때문에 예문을 줄이거나 번역을 생략하지 않는다.
- 제공 학습지·직접 작성 화면은 이 검사 당시 아직 함께 대조하지 않았다. 몽골어 지시문과 날짜 선택, 완료 예시, 실제 내려받는 파일까지 통합본에서 확인해야 한다.
