# 정적 카드 독립 시각 검토

2026-09-10 · 현재 18장 접촉시트와 지정 원본 이미지 확인. 생성 담당과 분리해 눈으로 검토했다.

## 수정 필요한 두 지점

### 1. SHIFT 큰 인용문의 어절 안 줄바꿈 — P2

직접 연 파일: `02-shift/upload-02.jpg`, `upload-03.jpg`, `upload-04.jpg`, `upload-05.jpg`. 1080×1350 출력에서 인용문이 각각 **보여 주 / 세요**, **필요 / 하세요**, **같습 / 니다**, **맡습 / 니다**로 끊긴다. 카드의 가장 큰 정보여서 읽는 흐름과 마감에 영향을 준다. 내용 잘림 검사의 통과 여부와 다른 문제다.

수정 위치: `content-b.json`의 SHIFT 2~5장 `kr` 문자열. 빌더 `build.cjs:23`은 줄바꿈을 `<br>`로 받으므로 문구를 바꾸지 않고 다음 의미 단위로 나눌 수 있다.

- 2: “모임에서 할 일을 / 한눈에 보여 주세요.”
- 3: “파일 제작과 인쇄 중 / 어디까지 필요하세요?”
- 4: “인쇄는 직접 할게요. / 내용은 같습니다.”
- 5: “인쇄와 현장 배포는 / 고객이 맡습니다.”

여기서 `/`는 실제 슬래시가 아니라 줄바꿈 위치다. 수정 뒤 해당 4장의 인용문만 다시 보면 된다.

### 2. SYNK 2장 예시 화면의 읽힘 — P2, 루트가 이미 수정 예정

직접 연 `04-synk/upload-02.jpg`의 아래 문서 화면은 안내·주의문·목차가 작게 담겨, 카드의 ‘완성 예시’가 무엇인지 실제 크기에서 확인하기 어렵다. **수정 제안의 완성 예시를 크게 보여주는 전용 화면**으로 교체하는 루트 계획이 적합하다. ‘바뀐 요청에 답하는 수정 제안’과 ‘가상 교육용 예시’ 문구는 현재 출력에 정확히 반영됐다.

이 이미지를 실제로 제작·인쇄한 A4 안내물의 증거로 설명하지 않는다. 검토 시 출력 SHA: `ca02a6daa93d63ffbac20cfe462752bf39075b564f6d499d94f348831fb5d251`.
