## 검토와 반영

- forge: A와 B를 독립 생성하고 별도 담당이 사실·약속을 검사했다. B의 조건 확인/변경과 A의 전곡 보존을 결합했다. 독립 검토 범위는 하드게이트.md에 있다.
- 언어: 새 LAB 몽골어 단독 읽힘→한몽 의미 대조를 작성자와 다른 담당이 수행했다. ‘사진을 내일 보낸다’를 ‘사진을 보내야 한다’로 고쳐 ‘내일까지’와의 차이를 보존했다. 새 학습지 지시문도 추가 대조했다. 최종 원어민 감수는 전이다.
- 시각: 18장 모아보기, LAB04·SHIFT02~05·SYNK02의 원래 출력에 독립 의견을 받았다. SHIFT 인용문이 어절 안에서 끊기는 문제는 의미 단위 줄바꿈으로 수정했고, SYNK 축소 문서는 읽을 수 있는 제안4줄로 바꿨다. 최종 SHIFT03·SYNK02·모바일 모아보기를 주담당이 다시 직접 확인했다. 전 카드 렌더 안전영역 검사와 시각 의견을 구분한다.
- 이전 사례: 릴10편 읽어주세요.md의 ‘참여 요구에서 실제 자료 제공’ 피드백을 적용했다. 이번 캡션 안에 기본 예문/실습을 완결하고, 파일 원본·직접 작성·확인 기준까지 제공했다. 승인 스티치 로고 유지와 축소 문서/어절 끊김 수정도 반영했다. 사용자 만족·실제 학생 반응은 아직 없다.

## 기계 확인

렌더검증.json: 18장, 1080×1350 출력, 글자 안전영역 벗어남0. 웹파일검증.json: 17HTML의 로컬 참조151개, 1440/390px 가로 넘침0, 실제 TXT 다운로드3건에서 한글·몽골어·줄바꿈 동일. 영상 메타데이터61.6초·1920×1080·제어 가능·자동재생 없음. 초기 검사에서 lazy-loading 이미지를 미로딩으로 잘못 집계한 것은 실제 디코드를 기다리도록 검사 자체를 바로잡았다.

PULSE 시작·중간·끝 화면, 전체 디코드, -15.07 LUFS/-3.75 dBTP 측정은 자산 담당 기록을 따랐다. 숫자 검사를 사람 연속 청취나 작품의 음악적 완성도 판정으로 바꾸지 않았다. YouTube 파일 형식은 [공식 업로드 인코딩 안내](https://support.google.com/youtube/answer/1722171?hl=en)의 MP4/H.264 항목을 확인했다.

소규모 계정의 형식 수요는 몽골 한국어 관련 Instagram/TikTok 좁은 검색에서 비교 가능한 팔로워·조회 수치가 있는 사례2개를 확보하지 못했다. URL·팔로워·반응 수치 모두 검증 못 함. 아웃라이어 검증을 주장하지 않고 한 장면→질문→답→변형→가져갈 문장의 기본 형식으로 제작했다.

압축은 Python zipfile로 만들고 재개봉·파일별 SHA256·한국어 파일명·내부 HTML 참조를 확인했다. 최종 수치와 오류 여부는 압축검증.json이다. 원본/검토 파일이 있는 작업 폴더는 보존하며 업로드 ZIP은 보관용 master PNG와 검사 도구를 제외한다.
