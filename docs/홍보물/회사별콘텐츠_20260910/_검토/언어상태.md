# 신규 LAB 언어 상태

2026-09-10. 신규 한국어·몽골어 문장의 제작 담당 자체 의미 대조를 했습니다. 독립 검토와 사람 원어민 감수·실제 학습자의 첫 독해 확인은 완료되지 않았습니다. 이전 자료의 언어 검토 기록을 이번 문장에 승계하지 않습니다.

공개 카드는 내부 검수 문구를 담지 않습니다. 자료 마지막에는 신규 문구와 사람 원어민 감수 전이라는 한 줄만 남깁니다. 한국어 의도와 몽골어 원문 대조는 ../01-lab/translation-ko.md에서 읽습니다. 자료에 추가된 몽골어 안내는 학습자가 혼자 순서를 따라 하도록 질문·시간 변경·이유·새 상황의 뜻을 설명합니다.

검토 때 ‘몇 시까지’의 마감 뜻, 저녁/오후 구분, 발신 행동의 일치, 날짜 교체 후 문법, 댓글 선택 뜻을 우선 확인합니다. 실제 음성은 이 원고의 검토 범위가 아닙니다.
