# SYNK 회사별 온라인 마케팅 보고

2026-09-10 · 현행 조직·마케팅 정본과 최신 제작물을 대조한 보고. 게임은 다른 세션의 작업으로 두고 이번 제작에서 제외한다.

**LAB은 자기 상황에 쓸 한국어를, SHIFT는 자기 사업에 바로 쓰는 방법과 파일을, PULSE는 처음부터 끝까지 감상할 작품을 제공한다. SYNK 본체는 그 완성물과 끝맺음의 기준을 보여준다.** 관심을 얻은 뒤 무엇을 줄지 정하는 것이 아니라, 먼저 가져갈 것이 분명한 콘텐츠를 만든다.

## 1. 우리 회사 구조와 이번 제작 범위

SYNK는 하나의 회사 구조다. 고객이 만나는 사업 브랜드는 LAB·SHIFT·PULSE 세 곳이며, IP와 COMMON SYSTEM은 세 브랜드를 받치는 공통층이다. 보고에서 쓰는 ‘회사별’은 이 사업·브랜드별 구분이고 법인 네 곳이 운영 중이라는 뜻은 아니다. 실제 계약 주체·등기·인력·매출의 현재 상태는 이번 문서 대조로 새로 확인하지 않았다.

| 자리 | 맡는 일 | 온라인에서 보여줄 방식 |
|---|---|---|
| **SYNK 본체** | 회사가 무엇을 만들고 어떻게 마무리하는지 기록 | 이미 완성된 물건과 결정 하나. 파트너가 관심 사업을 더 확인하도록 연결 |
| **SYNK LAB** | 한국어 학습·목적·실전 활동·본인의 기록 | 한 상황에서 직접 쓰는 표현과 자기 문장, 별도의 보호자·성인 안내 |
| **SYNK SHIFT** | 1인 기업 브랜딩·강의를 주력으로, 방법과 결과물을 제공 | 완성 예시를 보고 자기 업무를 고쳐 쓸 수 있는 수업·자료·검사법 |
| **SYNK PULSE** | 음악·영상·캐릭터·이야기와 브랜드 콘텐츠 제작 | 감상자 앞에서는 상품·작품 이름을 먼저. 회사 소개에서는 제작 역할을 설명 |
| **SYNK IP** | 커리큘럼·콘텐츠·진단·운영·브랜드의 재사용 자산 | 각 결과물의 정확한 출처·편집 원본·사용 범위로 신뢰를 받침. 독립 홍보 계정을 만들 대상은 아님 |
| **COMMON SYSTEM** | 완성·기록·사람의 판단·개인정보·검증·접근성 기준 | 실제 읽힘, 명확한 설명, 파일 접근, 재생 제어와 정확한 상태 표기로 드러냄 |

PULSE가 우리 작품을 만들면 재사용 자산은 IP에 축적한다. 고객사 광고·브랜딩은 **제작을 PULSE가, 계약·청구·고객 관계를 SHIFT가 맡고 고객 소유 납품물은 우리 IP로 올리지 않는다.** 계약·수익 분담은 조직 방향이며 현재 판매 계약이나 별도 법인이 준비되었다는 증거로 쓰지 않는다.

옛 STUDIO는 PULSE로 바뀌었다. ABROAD는 별도 브랜드가 아니라 LAB Path와 SHIFT의 유학 관련 사업 범위에서 읽는다. PUBLISH는 IP와 제작 기능에 흡수되었다. 철회된 의류·굿즈·식품 브랜드를 이번 마케팅 회사 목록에 다시 넣지 않는다.

이번에는 대표 콘텐츠 **4편**을 준비한다. 각 브랜드의 모든 사업을 한 게시물에 담지 않고, 해당 브랜드가 무엇을 제공하는지 실물 하나로 보여준다. 부사업은 아래에서 별도 제공물·안내 경로를 정리한다.

## 2. LAB — 배운 표현을 내 상황에서 쓰게 한다

**주 대상은 한국 유학과 이후 삶을 탐색하는 몽골 10대 후반이다.** 한국어가 초급이어도 생각까지 어린아이처럼 다루지 않는다. 학생이 좋아하는 것·맡고 싶은 역할·다시 확인하고 싶은 말을 먼저 둔다. 보호자는 별도의 결정 참여자이고, 한국 거주 성인은 다른 생활 문제와 과정 안내가 필요한 별도 대상이다.

| 분야·상대 | 먼저 제공할 것 | 콘텐츠의 구체적인 모습 | 다음에 이어줄 것 |
|---|---|---|---|
| Language: 한국어를 직접 쓰려는 학생 | 뜻·상황·예문·변형이 있는 표현 자료 | 못 들은 부분을 짚어 다시 묻기, 주문을 자기 입맛에 맞추기, 일정 다시 제안하기 | 같은 장면의 문장 카드·이어 쓰기 자료 |
| Path: 유학을 탐색하는 학생 | 하고 싶은 하루와 더 알아볼 질문 | 전공을 아직 정하지 않았다고 말하기, 가족에게 내 이유 한 면 쓰기 | 학생 이유와 보호자 확인표를 구분한 현재 과정 안내 |
| Project: 함께할 역할을 고르는 학생 | 참여 방식과 역할을 말하는 문장 | 발표·그림·편집·기획을 대등한 선택지로 두고 “제가 ___ 할게요”처럼 본인 역할 표현 | 촬영 없이도 만들 수 있는 작은 결과, 본인이 고른 다음 연습 |
| Record: 했던 일을 본인 것으로 남기려는 학생 | 무엇을 했고 다음에 어디에 쓸지 정리하는 견본 | 공개용 합성 기록 예시, 자기 문장을 고친 전후와 이유 | 실제 제공 가능한 본인 기록·다음 연습. 미구현 자동 기능은 광고하지 않음 |
| 보호자 | 수업이 어떻게 이어지고 누가 무엇을 책임지는지 | 학생의 선택→수업의 관찰→다음 과제→확인할 비용·시간·지원의 분리된 설명 | 현행 조건의 과정 안내·상담. 없는 시설·지원·기숙사 조건을 채워 넣지 않음 |
| 한국 거주 성인 | 이미 겪는 대학·생활 상황의 표현 | 교수 면담, 수업 질문, 과제 설명, 생활 문자, 다시 설명 요청 | 성인 과정 전용 안내. 학습 기록을 부모에게 자동 연결하지 않음 |

**이번 한 편: ‘뜻을 다시 확인하는 한국어’.** 5~6장 캐러셀에서 허구의 상황과 완성 대화를 먼저 보여주고, 어느 말을 다시 물으면 되는지 짚는다. 독자가 바꿔 쓸 문장과 확인 기준을 함께 제공한다. 기본 표현과 설명은 게시 본문에서도 모두 읽을 수 있게 한다. 공개 댓글·친구 태그·연락처 제출·학생의 얼굴이나 음성을 자료 열람 조건으로 삼지 않는다.

콘텐츠는 한국어 문장과 몽골어 뜻의 역할을 나눠 편집한다. 한국어·몽골어를 둘 다 크게 반복해 한 장에 쌓기보다, 장면·예문·뜻·설명을 각각 읽히게 배치한다. 기존 AI 언어 검토와 사람 원어민 감수를 같은 확인으로 보고하지 않는다.

**발견과 전달:** Instagram/TikTok의 @synk.mn에서는 짧은 상황과 선택으로 발견한다. YouTube @synkkorean의 Shorts도 같은 교육 입구를 맡고, 음악 감상 목록과 구분한다. Instagram 캐러셀은 저장해 변형하는 카드, Telegram @synkmn은 다음 표현과 자료, Facebook synkworld는 보호자·성인의 수업·조건·문의 자리, synk.im은 실제 과정·지원 범위를 이해하는 자리다.

**운영 제안:** 기존 도움 제공형 10편을 재료로 우선순위를 고르고, 같은 장면의 숏폼·카드·이어 쓰기 자료를 역할별로 연결한다. 이번 대표편 뒤에 한 주 단위로 ‘학생이 더 쓰고 싶은 장면’을 골라 순서를 조정한다. 장기 45편 제작이나 신규 고정 발행일을 다시 약속하지 않는다.

**확인할 결과:** 학생이 무엇을 받는지 이해하는가, 예문 한 부분을 자기 상황으로 바꿔 쓸 수 있는가, 어떤 장면에 필요한지 설명하는가. 조회·저장·댓글은 참고이며 한국어 실력 향상이나 과정 적합성의 증거로 대신하지 않는다.

## 3. SHIFT — 1인 기업의 한 일을 끝내는 수업

**현재 주력은 1인 기업 브랜딩·강의다.** 공개 제작 과정을 구경하게 하는 데서 끝내지 않고, 독자가 자기 사업의 문장·상품·문의·콘텐츠·납품을 직접 고쳐 가져가도록 만든다. 처음 독자는 한국어권의 지식·서비스형 1인 사업자, 예를 들어 강사·컨설턴트·디자이너·교육/콘텐츠 제작자를 우선하는 안이다. 이 세부 타겟은 현재 추천이며 실제 수요를 인터뷰로 검증했다는 뜻은 아니다.

| 자기 전문성을 강의로 | 수강생이 직접 만드는 결과부터 수업 구성 | 시작 파일·완성 예시·실습·자기 점검 | 듣기만 해도 끝나는 수업인지, 다른 상황에 적용할 수 있는지 |

**이번 한 편: ‘고객 조건이 바뀌면, 제안도 다시 맞춥니다’.** 6장 캐러셀과 실습자료로 가상 고객의 처음 요청, 추가·변경된 조건, 수정 제안, 고친 이유를 보여준다. 독자는 처음 답과 수정 답을 따로 작성해 비교하고 자기 확인 기준을 가진다. 실제 고객의 질문·납품·성공담으로 꾸미지 않는다.

끝맺음은 **완성 예시 → 고칠 곳과 이유 → 편집 원본/직접 작성 → 스스로 확인 → 막혔을 때 실제 다음 자료**다. 빈 양식만 던지지 않고 완성 답을 먼저 보여준다. 기본 답은 본문 안에도 남기며, 별도 자료실이나 자동 DM이 실제로 연결되었다고 가정하지 않는다.

## 5. SYNK — 끝낸 물건으로 회사의 기준을 보여준다

본체의 상대는 파트너·함께 만들 사람·회사를 검토하는 사람이다. 학생 모집, 실무 팁, 음악을 한 피드에 모두 모으는 것이 아니라, 한 달에 완료한 실물 하나와 그 선택을 설명한다.

**이번 한 편은 ‘인수할 때 확인하는 것’ 5장이다.** 인수란 받는 사람이 파일을 열고 실제 사용을 이어갈 수 있는 상태다. 실제 제작한 파일을 앞에 두고 무엇인지, 어떤 파일을 쓰는지, 어떻게 바꾸는지, 무엇을 확인했는지, 어디까지 제공하는지를 보여준다. 내부 경로·도구 이름을 광고의 주인공으로 만들지 않고 받는 사람의 행동으로 설명한다.

공통 기준은 ‘완성했다’는 말이 아니라 **표지와 본문의 약속이 실제 파일과 맞는가, 파일이 열리고 필요한 내용이 있는가, 다시 쓸 방법이 있는가, 확인한 범위를 정확히 말하는가**다. 실제 고객 작업·회사 자체 제작·가상 교육 예시·AI 합성 시연을 구분한다.

**채널·주기·연결:** 본체 Instagram 월 1회가 현재 기록된 방향이다. 희망 핸들 @synk.im, 대안 @synkim은 이번에 확보를 확인하지 않았으므로 확정 링크·QR로 쓰지 않는다. 관련 사업의 실물 한 곳으로 연결하며 본체 YouTube·TikTok·Threads를 새로 만드는 계획을 덧붙이지 않는다.

**확인할 결과:** 외부인이 이 결과물이 누구에게 왜 필요한지, 현재 어디까지 할 수 있는 회사인지 설명할 수 있는가. 관련 실물을 언급하는 협업 질문이 생기는가. 좋아요 수를 회사 신뢰나 협업 성사로 보고하지 않는다.
