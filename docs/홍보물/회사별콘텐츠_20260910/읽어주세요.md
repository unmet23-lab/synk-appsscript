## 실제 업로드

1. 해당 폴더의 index.html과 업로드안내.md를 엽니다.
2. 카드 게시물은 번호순 upload-XX.jpg를 한 게시물에 넣습니다. 규격은 1080×1350입니다. master-XX.png는 보관 원본이며 업로드 묶음에서는 제외했습니다.
3. 영상은 video.mp4를, YouTube 표지는 thumbnail.jpg를 사용합니다. PULSE upload-01.jpg는 별도 소개용 세로 카드입니다.
4. 게시문안.txt는 공개 본문만 담았습니다. 대체텍스트.txt는 지원되는 이미지 설명 칸에 넣습니다. 해시태그는 넣지 않았습니다.
5. 실제 계정의 게시 미리보기에서 순서·잘림·소리·프로필 연결을 확인합니다. 본체 Instagram은 핸들 확보·개설을 이번에 확인하지 않았습니다.

기본 예문·실습은 게시 본문에서도 완결됩니다. 댓글·팔로우·개인정보 제출을 자료 조건으로 삼지 않습니다. 새 자료를 아직 공개 웹에 올리지 않았으므로, 새 공개 URL이나 자동 전달을 약속하는 문안은 넣지 않았습니다. 파일을 붙일 수 있는 채널에서는 자료 원본을 함께 제공할 수 있습니다.
