## 게시문안 전체의 한국어 뜻

친구와 함께 준비할 때, 마칠 시간을 한 번 더 확인해 보세요.

함께 하는 일에 필요한 사진을 보내는 연습용 상황입니다.

1. 요청을 읽어요.
‘내일까지 사진을 보내 주세요.’
날짜를 들었어요. 이제 시간을 물어볼 수 있어요.

2. 시간을 더 물어요.
‘내일 몇 시까지 보내면 돼요?’

3. 답을 들어요.
‘내일 저녁 여섯 시까지요.’

4. 내가 할 일을 확인해요.
‘네, 내일 저녁 여섯 시까지 보낼게요.’

내 문장:
‘___ 몇 시까지 보내면 돼요?’
내일 / 금요일 / 월요일

날짜 한 곳을 바꿔 말해 보세요. 답을 들은 뒤 정한 시간을 다시 말해 보세요.
저장해 두고 다음에 함께 준비할 때 써보세요. 연습은 혼자 해도 되고 댓글은 선택이에요.
어떤 날짜를 넣어 보고 싶으세요?

## 의미 대조에서 지킨 구분

- ‘내일까지’는 날짜, ‘몇 시까지’는 시간을 묻는 표현입니다. 두 사람이 잘못 알아들었다는 단정을 만들지 않았습니다.
- ‘저녁 여섯 시’를 몽골어에서도 ‘оройн зургаан цаг’으로 유지했습니다.
- 사진을 보내는 한 가지 행동을 묻기→답 듣기→확인하기까지 이어갑니다. 날짜를 바꾸는 연습에서 새 서비스나 자동 전송 약속을 추가하지 않았습니다.
- ‘댓글은 선택’은 ‘сэтгэгдэл бичих шаардлагагүй’로, 댓글을 반드시 쓸 필요가 없다는 뜻을 보존했습니다.
- 한국어 ‘보내면 돼요?’의 허용·마감 문의를 몽골어의 자연스러운 시간 질문으로 옮겼습니다. 음절별 직역 일치가 목표는 아닙니다.

확인하지 않은 것: 사람 원어민의 자연스러움 검토, 실제 몽골 학생의 첫 독해, 한국어 발음 음성, 실제 사용 크기의 카드 검수. 새 독립 검토에서 다른 의미가 발견되면 원고·카드·자료의 같은 문장을 함께 고칩니다.
