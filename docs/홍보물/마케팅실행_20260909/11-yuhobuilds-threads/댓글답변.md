# Threads · 답변 참고

선택형 질문: 내 이름을 가렸을 때도 무슨 일인지 보이나요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 경력을 먼저 요구하는 자리라는 질문

경력이 핵심 확인 정보인 제안서라면 앞에 와도 됩니다. 이 예시는 처음 보는 고객에게 하는 짧은 소개용입니다. 상대가 먼저 판단해야 할 질문에 맞춰 순서를 정해보세요.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
