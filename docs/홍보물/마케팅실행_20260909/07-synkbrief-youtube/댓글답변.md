# YouTube · 답변 참고

선택형 질문: 지금 점검할 것은 새 주장, 제공 범위, 문장의 뜻 중 무엇인가요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. AI가 근거를 있다고 답한 경우

답변 자체를 근거로 삼지 말고, 제공한 원자료에서 그 문장을 뒷받침하는 위치를 직접 확인해 보세요. 확인되지 않으면 표현을 빼거나 미확인으로 남기는 편이 안전합니다.
