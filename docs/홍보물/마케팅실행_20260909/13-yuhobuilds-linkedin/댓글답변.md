# LinkedIn · 답변 참고

선택형 질문: 목차 옆에 어떤 결과물을 놓고 싶으신가요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 기관 공동 수업 문의가 실제 들어왔을 경우

관심 주시는 대상의 상황과 교육 후 남기고 싶은 결과물부터 확인하면 좋겠습니다. 일정·진행 범위·사례 사용 동의는 합의가 필요하며, 이 게시물은 개강이나 제휴 확정 안내는 아닙니다.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
