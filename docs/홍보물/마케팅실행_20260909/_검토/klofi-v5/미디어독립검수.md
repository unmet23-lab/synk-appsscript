- v5 `frame-3.png`, `frame-12.png`, `frame-38.png`, `frame-50.png`, `frame-61.5.png`를 실제로 열었다. 비교용 v4 `frame-3.png`도 같은 크기로 열었다.

- `source.json`에 기록된 배경·곡·원본 WebP 8개·파생 PNG 8개·경계 모듈·승인 기록의 현재 SHA-256을 다시 계산했다.

- Sites·원격 서버·외부 게시에는 접근하지 않았다. 원본·자산·렌더러는 수정하지 않았다.

## 최종 MP4 기술 검사

`ffprobe` 재조회: 파일 9,256,869바이트, H.264 1920×1080 / 30fps / yuv420p / 1,848프레임, AAC 48,000Hz / 2채널. 영상·음성·컨테이너 길이는 모두 61.600000초다.

실행한 전체 디코드: `ffmpeg -nostdin -v error -xerror -i <최종 video.mp4> -map 0:v:0 -map 0:a:0 -f null -` → 종료 코드 0, 오류 출력 없음. 단순 스트림 존재 조회뿐 아니라 영상·음성 끝까지 디코드한 결과다.

기존 `audio.log`의 측정 입력은 -15.07 LUFS, true peak -3.75 dBTP다. 이 로그의 `output_*` 값은 null 출력 분석 필터의 계산값이므로 납품 파일이 해당 출력값으로 재정규화됐다는 근거로 쓰지 않는다. 이번 검수에서는 직접 청취나 가사 대조를 새로 수행하지 않았다.
