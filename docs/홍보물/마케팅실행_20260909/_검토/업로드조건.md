# 오늘 올릴 때 확인할 조건 — 파일과 공개 주소를 구분한다

> 2026-09-09 · 독립 검토. 새 네이버 블로그·카카오톡 채널·Pinterest 개설과 실제 업로드는 유호님이 한다. 검토자는 계정 조작·게시·메시지 발송·외부 모델 전송·결제·커밋을 하지 않았다.
> 확인 범위: 현재 저장소의 계정 기록, 기존 16묶음의 형식, 아래 공식 원문. 실제 계정의 업로드 버튼·권한·현재 공개 URL은 미확인이다. 도구가 원문을 읽지 못한 항목은 최대 길이·개수·용량을 지어내지 않았다.

## 1. 먼저 지킬 전달 원칙

**본문만으로 기본 도움을 끝낸다.** 공개 자료실의 배포와 다운로드를 확인하기 전에는 ‘자료실에 있습니다’, ‘아래에서 받으세요’와 같은 배포 완료 문구를 쓰지 않는다. 문장 틀·채운 예시·해보는 순서를 게시물 본문/캡션 안에 두고, 실제 지원되는 플랫폼에는 같은 PDF를 직접 첨부할 수 있다.

- `C:/...`, 상대경로, `file://`, `localhost`, 로컬 HTML 미리보기는 공개 다운로드 주소가 아니다. `synk.im`이 존재한다고 새 자료 경로가 공개됐다고 추정하지 않는다.
- 실제 공개 URL을 쓰려면 로그인하지 않은 화면에서 같은 자료명·판본·파일이 열리고 기본 자료에 이메일/댓글/팔로우 요구가 없는지 확인한다. 비밀 초안 링크를 정식 자료실 주소로 배포하지 않는다.
- 업로드용 JPG/PNG/MP4/PDF, 편집 원본 DOCX/MD/JSON, 로컬 미리보기 HTML, 전체 인수 ZIP을 구별한다. ZIP 전체를 SNS 게시 파일로 선택하지 않는다.
- 사진 속 URL은 클릭 버튼이 아니다. 채널이 실제 지원하는 프로필 링크·관련 영상·본문 링크·자료 첨부 중 그 지면에 맞는 경로만 설명한다.
- 제출·반응·촬영·학생 이름/학교/음성/얼굴 공개를 자료의 대가로 받지 않는다. 후속 구독은 별도 선택이다. 등록·피드백·응답 시간을 새로 약속하지 않는다.
- 학생용 새 몽골어가 들어간다면 현행 검토 범위를 표시한다. 자체 검토·외부 모델 검토·사람 원어민 감수를 같은 완료로 부르지 않는다. 과거 승인된 짧은 표현을 썼다고 새 문장 전체가 승인된 것은 아니다.

## 3. 플랫폼별 파일·링크 지원과 오늘의 적용

아래 ‘권장 파일’은 이번 인수 묶음을 쓰기 쉽게 정한 선택이며 플랫폼의 전체 허용 확장자 목록이 아니다. 공식 최대치와 사내 출력 규격을 섞지 않는다.

| 네이버 블로그 | 본문 직접 입력+영문/숫자 파일명의 JPG/PNG, 필요한 PDF | 공식 사진 지원은 JPG/GIF/PNG/BMP/WEBP. 사진 버튼으로 첨부하며 HTML 복사/붙이기로 정상 표시를 보장하지 않음. 공식 두 문서가 이미지 20MB/10MB로 달라 이번 파일은 10MB 미만을 권장하는 내부 안전값으로 잡음. 계정 인증에 따른 동영상 한계를 확인하기 전 긴 강의 직접 업로드를 약속하지 않음 |
| 카카오톡 채널 | 공개 **소식** 본문+사진, 또는 링크형/카드뷰 | 소식은 사진·동영상·링크·쿠폰·카드뷰 중 하나의 첨부 종류 선택. 사진과 별도 링크 첨부를 동시에 지시하지 않음. 일반 사진 20MB, 동영상 1개, 아주 긴 사진은 잘림·등록 제한. 링크형은 실제 웹 주소 필요. 카드뷰는 정사각 1:1/세로 3:4 권장 및 버튼 연결을 지원. 소식과 비용/동의 조건이 있는 메시지 발송을 혼동하지 않음 |
| Pinterest | JPG/PNG 이미지 Pin 또는 완성 영상 Pin+설명 | 공식 안내는 이미지/영상 Pin과 실제 사이트 URL 연결을 지원. 아직 공개 URL이 없으면 목적지 없는 원본 이미지·설명에 도움을 담고 새 자료실이 공개된 듯한 CTA를 빼기. 보드 이름은 사용 목적, 계정/주소는 사용자 개설 후 확인 |

**형식 안전값의 뜻:** 예컨대 공통 카드 JPG 1080×1350, 세로 영상 1080×1920, Pinterest용 2:3 그림은 제작자가 고를 수 있는 출력 규격이지 위 모든 플랫폼의 의무 규격/최대치가 아니다. LinkedIn과 카카오 카드뷰처럼 실제 잘림 기준이 있는 지면에는 해당 지면용 파일을 사용한다. 크기를 맞춘 것과 글이 잘 읽히는 것은 별개다.
