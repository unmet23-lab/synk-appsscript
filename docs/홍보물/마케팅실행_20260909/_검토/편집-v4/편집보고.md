## 디자인 기준의 적용과 검토 범위

SYNK 디자인 기준을 따라 자산을 먼저 재사용했다. 장식 글자는 단락마다 한 점으로 제한하고, 제목과 본문은 검색·선택·확대가 가능한 실제 텍스트로 유지했다. 새 글꼴·배경 장식·애니메이션·일러스트를 만들지 않았다.

| 항목 | 확인 | 미확인 |
|---|---|---|
| 글자 | 기존 Inter Tight/SUIT 계열 유지, 제목·본문·보조문구 위계와 크기/행간 소스 확인 | 실제 브라우저 줄바꿈·200% 확대 화면 |
| 표면·배치 | 기존 Loom 색상과 여백, 반응형 1열 규칙, 글자 이미지 비율 유지 | 실제 화면에서의 균형·터치 영역 |
| 움직임 | 신규 움직임 없음, 기존 닫힘·정지 처리 유지 | 실제 브라우저 키보드·미디어 재생 |
| 아이콘·자산 | 기존 숫자 3장의 실제 이미지 확인, 대체 텍스트 중복 읽기 방지 | 실제 화면에서의 축소 인상 |
| 성능 | 신규 숫자 각 100KB 미만, 영상 preload=none, 본문 영상 추가 없음 | 실제 네트워크 속도·기기 체감 |

검토 후 채택하지 않은 방식: 본문까지 이미지로 굽기(확대·검색·접근성 손실), SYNK를 또 다른 색상의 입체 글자로 교체하기(중립 로고 체계와 충돌), 영문 새 표어를 억지로 합성하기(기존 자산의 목적과 제공 가치가 흐려짐).

## 검증과 공개 반영

- 공유 준비 및 빌드: 19개 계정, 6종 자료, 236개 파일, 611개 로컬 연결 확인.
- 브랜드값·폰트 기존 시험 92개 통과.
- 라디오 메뉴 정적 소스·독립 Node 모의 실행 53개 통과. 브라우저 재생 검사가 아니다.
- 독립 검토자는 원본 도우미·Loom·생성된 홈의 정적 소스에서 확정 결함을 발견하지 못함.
- 단락 순서·원고·숫자 자산·영상 동일성: `로컬검증.json`.
- 실제 공개 반영 결과는 `공개반영검증.json`과 `공개반영.json`에 별도로 기록한다. 이 문서만으로 공개 완료를 주장하지 않는다.
- 실제 게시 완료: 2026-09-09 23:20 KST, 기존 공개 주소의 버전 4. 비로그인 HTTP 235/235개 성공, 새 HTML·CSS·숫자 3개 및 보존 영상 2개의 전체 바이트 비교도 통과했다. 공개 문서에 호스팅 서비스가 붙인 확인 스크립트 1개는 별도 기록하고 비교했다.
- SNS 게시·계정 생성·새 수업 제작·실시간 라디오 수정은 수행하지 않았다.
