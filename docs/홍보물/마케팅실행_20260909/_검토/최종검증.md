# 마케팅 실행판 통합 검증

2026-09-09 · 제작과 실제 게시를 분리하는 인수 기록

## 적용

- 기존 16개 계정 자리 + 사용자 개설 신규3 = 19개 패키지. PULSE는 LAB YouTube의 감상 자리이며 20번째 계정으로 중복 집계하지 않았다.
- SHIFT는 1인 기업의 소개·상품 범위·콘텐츠·문의·AI 검수·강의 실습이 중심이다. 홍보 숏폼을 없애지 않되 설명과 자기 적용을 본문 안에서 완료한다.
- forge 독립 A/B 끝맺음을 비교했다. 본문에서 완료 → 자기 점검 → 실제 자료/선택형 질문으로 잇는 B 구조에 A의 채운 예시·수정 가능 원본·조건별 해결을 합쳤다. 가상 클리닉과 후속 편지의 원자료에 없던 제공 약속은 독립 검토 지적으로 고쳤다.
- 명품화는 금박·장식량이 아니라 일관된 색의 역할, 정돈된 글·여백, 실제 사용할 자료와 정직한 응답으로 적용했다. Loom의 기존 색/폰트/지면을 확장했으며 별도 경쟁 디자인 체계를 만들지 않았다.
- 공통 로고의 몸체는 Ink/Paper, 사업명은 기존 고유색. 기존 내부 꺾쇠 신호와 마스코트·다른 색 토큰·옛 파일은 보존했다.

## 영상과 출고의 별도 증거

최종 인코딩 영상9개와 SRT9개, 52장면의 대표105프레임·상세16프레임 검사를 완료했다. 인코딩·자막·음량·대표 프레임은 `영상_종합기계검증.json`, `영상_최종시각검수.md`와 독립 `실물_독립검수.md`에서 파일 지문에 연결한다.

Chrome에서 최종 영상9개를 실제로 열어 무음 재생하고 디코딩된 프레임 콜백·가로세로·길이를 확인했다. 전부 통과했으며 `브라우저영상검증.json`에 남겼다. 이것은 파일 재생 확인이고 사람의 음성 청취를 대신하지 않는다. 전체 `git diff --check`에는 생성 CSS/안내의 줄끝 공백과 일부 영상 소스의 마지막 빈 줄 경고가 남는다. 실행·시각 결함은 아니며 이미 동결·검증된 영상 지문을 공백 정리만을 위해 바꾸지는 않았다.

계정 ZIP19개 + 전체 ZIP1개를 두 차례 생성·전량 재개봉해 한글 파일명과 전체 SHA를 확인했다. 최종 전체 ZIP은 242,588,778바이트, 293멤버(인수파일292+출고목록), SHA-256 `14c7fec34aefa6898c722f5ec94f87007957aae3c25193eba04ad445746df286`. 별도 폴더 정상 추출 후 파일292개의 해시와 내부 연결614곳 누락0, Chrome 주요4화면을 확인했다. 전체 ZIP 안에 계정 ZIP·원시WAV·ASR·실행환경·생성 로그를 중복 수록하지 않았다. 자세한 실제 실행 결과는 상위 `출고검증.md`를 따른다.

## 남은 실제 환경 확인

사람의 음성 청취와 몽골어 원어민 감수는 하지 못했다. 원문 자막·기술 디코드·오프라인 음성인식과 그 의미 대조는 별도로 수행했다. 청취 우선 구간은 사용자 읽어주세요와 공개수업 안내에 표시했다.

몽골어는 현행 적용 기준의 무료·자기 채널·감수 전임을 밝히는 범위로 구분하며 유료 광고에 감수 전 사용하지 않는다. 이 인수판을 사람 감수 승인으로 읽지 않는다.

새 계정 개설·SNS 게시·편지 발송·협업 섭외·자료실 외부 배포·광고비 지출·자동 DM·실제 학습 및 사업 효과는 실행하지 않았다. 사용자에게 실제로 올릴 파일과 원고를 인수하며 없는 공개 주소를 넣지 않는다. 원격 push는 앞선 사용자 거절을 유지한다.
