## 직접 확인한 범위

- PULSE 01: 1초·19.5초·29초. 조용한 방의 창·램프·책상 배치를 보존하고, 교육 CTA·가짜 생방송 문구·추가 로고를 넣지 않았다.
- LAB 03: 5장면 10프레임. 첫 역할 목록은 고정 원문 세 항목을 서로 구분해 읽을 수 있다. 한국어·몽골어 예문과 소품 윤곽이 잘리지 않는다. 새 몽골어를 생성하지 않았다.
- SHIFT 숏폼 04·05·06·07·09: 23장면 46프레임. 소개의 순서, 형용사를 실제 활동으로 풀기, AI 문장과 근거 대조, 조건을 남기는 요청의 차이를 유지했다. 가상 예시와 확인된 범위의 표시는 보존했다.
- 공개수업: 18장면 36프레임. 제목·본문·실물·실습 팁·구술 자막을 분리했다. 소개와 상품 범위의 칸, 미확정 조건, 근거 없는 약속 경고, 개인 정보를 공개하지 않는 끝맺음이 읽힌다.
- 가상 클리닉: 5장면 10프레임. 실제 받은 질문이 아님을 표시한다. 원자료와 고친 문장이 ‘소개문 초안 한 개 작성’으로 일치하며 AI 검사는 시연의 검수 방법으로 분리돼 있다.
- 스티치 로고는 승인된 중립 먹색 SYNK와 해당 사업부 색을 사용한다. 화면 안에 옛 소개서의 평면 로고가 포함된 지면을 넣지 않았다.
- 봉투 윗윤곽·책 윗장·가위 두 칼날과 손잡이 구멍이 온전하다. 소품 마스크를 새로 잘라 부품을 없애지 않았다.
- 접촉시트의 검정처럼 보이는 마지막 빈 셀은 사용하지 않은 투명 칸이다. 영상 속 검정 프레임으로 계산하지 않았다.

## 기계 검사와 음성의 경계

- TypeScript 검사, 렌더러·검수 helper 구문 검사 통과.
- H.264/AAC, 숏폼 1080×1920·수업/클리닉 1920×1080, 30fps, 길이·파일 크기·해시 검사 통과.
- 폰트·이미지 로드 실패와 중요 글자 안전 영역 초과는 렌더 중 오류로 잡도록 했고 최종 로그에 해당 실패가 없다.
- 수업 131개·클리닉 15개 구술 자막은 현재 정본 전체 문장과 공백 정규화 후 일치한다. 최소 표시 길이는 각각 1.10초·1.68초, 최대 자막 글자 수는 64·63이다.
- 구술 자막 시각은 로컬 ASR 단어 시각을 원고에 자동 대응한 추정이다. ASR의 오인식 단어를 화면 문구에 복사하지 않았다. 사람이 듣고 모든 경계를 교정했다고 주장하지 않는다.
- 수업 음량 -18.24 LUFS / True Peak -4.82 dBTP, 클리닉 -18.32 LUFS / -4.76 dBTP. 기술적 측정이며 실제 청취·억양 평가와 다르다. 원천 음성의 세 최대 진폭 샘플이 없었다고 주장하지 않는다.
- 목소리는 일반 한국어 합성 프리셋이다. 유호님의 실제 육성이나 복제 음성이 아니다. 기존 자체 작곡 배경음의 출처는 `영상_원천명세.json`에 있다.
