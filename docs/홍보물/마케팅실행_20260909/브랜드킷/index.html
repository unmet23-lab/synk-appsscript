모양보다 색을 먼저 단정했습니다

기존 로고의 솟은 k, y의 내려가는 획, 둥근 펠트·스티치를 유지합니다. 사진형 질감판은 GPT Image 2.5 Sunburst에서 기존 자산을 참조한 색 변형입니다. 픽셀 단위 동일 도형은 정밀 SVG를 사용하세요. 새로운 서체로 바꾼 로고가 아닙니다.

공간과 크기

공통 SYNK 너비를 1로 볼 때 사업명 사이 여백은 0.075, 사업명 실제 대문자 높이는 0.222를 기준으로 맞췄습니다. 글자 모양에 따라 광학 중심을 보정했습니다. 압축·늘이기·외곽선·반짝이는 금박 효과는 추가하지 않습니다.

밝은 바탕을 기본으로

어두운 바탕에서도 사업명은 기존 색입니다. 색 몸체가 흐려지는 작은 자리에서는 밝은 패널에 전체 로고를 놓으세요. 사업명만 임의로 밝히지 않습니다. 촘촘한 피드에서는 로고 확대보다 여백과 내용의 명료함을 우선합니다.

파일 선택

배치용/에 네 조합 × Ink·Paper PNG 8개가 있습니다. 사진형 원본 PNG 2개는 가로 3840px입니다. 정밀 SVG 2개는 기존 도형을 그대로 사용하는 크기 자유 원본입니다. 카드와 영상에는 배치용 WebP를 사용합니다. 생성 원본과 기존 컬러판은 보존합니다.
