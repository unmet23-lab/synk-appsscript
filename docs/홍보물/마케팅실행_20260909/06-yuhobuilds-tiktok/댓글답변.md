# TikTok · 답변 참고

선택형 질문: ‘맞춤형’ 대신 어떤 활동을 적을 수 있나요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 실습이 아닌 서비스라는 질문

서비스도 같은 방식으로 볼 수 있습니다. 고객이 전달하는 입력과 당신이 돌려주는 결과를 각각 적어보세요. 다만 여기의 수업 문구를 실제 제공 범위 없이 그대로 쓰지는 마세요.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
