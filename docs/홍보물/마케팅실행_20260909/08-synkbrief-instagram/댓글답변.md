# Instagram · 답변 참고

선택형 질문: 가장 설명이 필요한 경계는 포함, 제외, 준비사항 중 어디인가요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 제외를 적으면 나쁘게 보이지 않느냐는 질문

모든 제한을 앞세울 필요는 없지만, 기대가 갈릴 수 있는 지점은 설명해 두는 편이 서로 확인하기 쉽습니다. 포함하는 도움을 먼저 쓰고 그 옆에 경계를 붙여보세요.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
