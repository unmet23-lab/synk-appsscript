## 이 자료의 예시는 누구 이야기인가요

‘처음 기관에 강의를 제안하는 독립 강사의 소개자료를 정리하는 1인 편집자’라는 하나의 가상 사례를 여러 조건으로 펼쳤습니다. 실제 고객·판매 상품·강의 운영·매출 사례가 아닙니다. 03의 질문과 소통 가이드의 대화·편지도 실제 질문이나 발송 이력으로 쓰지 않습니다.

빈 양식만 제공하지 않습니다. 채운 예시를 먼저 읽고, 편집용 원본에서 자기 사실로 바꾸며, 변형이 필요한 이유를 확인합니다. 분야에 따라 타당한 답이 여러 개일 수 있고 문장을 그대로 따라 쓸 필요는 없습니다.

## 파일과 사용 범위

MD는 일반 텍스트 편집기로 고칠 수 있는 원본입니다. [제공자료.json](제공자료.json)은 같은 본문을 통합 지면 제작용으로 묶은 파일입니다. 공개 자료실 URL이 아니며 개인정보를 입력하거나 회원가입할 필요가 없습니다.

자기 소개·상품 설명·콘텐츠·문의·업무·실습을 작성하는 데 사용할 수 있습니다. 가상 사례를 실제 실적·후기처럼 제시하거나 타인의 자료를 허락 없이 넣지 마세요. 원고를 수정한 뒤 실제로 제공하지 않는 서비스·가격·일정·지원이 약속으로 남지 않았는지 확인합니다.

현재 완료 범위는 로컬 원본 제작과 원고·구성 검증입니다. 이 파일만으로 현장 강의, 새 채널 개설, 공개 업로드, 개인 응답·자동 발송, 고객 성과가 완료된 것은 아닙니다. 실제 공개 경로와 운영 조건은 확인 후 안내합니다.

시각 통합은 현행 Loom 토큰과 승인 글꼴, 중립 먹색 SYNK 스티치와 회사색 사업명 스티치를 적용합니다. 이 폴더는 새 폰트·로고·이미지·CSS를 만들지 않습니다. 화면 렌더와 모바일 시각 검수는 통합 제작 단계에서 별도 확인합니다.
