첫 서비스를 설명하는 한 장

SYNK SHIFT · 02 상품한장 · v1.0 · 2026-09-09 · 편집 가능한 한국어 원본

아래 서비스는 가상 교육용 사례입니다. SHIFT의 현재 판매 상품·가격·계약이 아닙니다. 판매 전에 자신의 실제 제공 범위와 거래 조건을 별도로 확인해야 합니다.

1. 무엇이 남고, 어떤 순서로 쓰나요

누가 무엇을 받고, 무엇을 받지 않으며, 사용 뒤 어디까지 이어지는지 설명하는 상품 한 장을 만듭니다. 가격과 일정이 없는 이 교육 예시를 실제 주문 페이지로 사용하지 마세요.

  1. 고객의 출발 상태와 바라는 일을 적습니다.
  2. 실제 인수물과 포함·제외 범위를 나눕니다.
  3. 고객이 준비할 것, 진행 확인 지점, 사용 안내를 붙입니다.
  4. 아직 정하지 않은 판매 조건은 별도 미정 목록으로 남깁니다.
  5. 전체를 읽고 ‘나는 무엇을 받아서 무엇을 할 수 있나?’에 답해봅니다.

2. 채운 가상 예시 — 소개자료 정리 서비스

대상: 처음 기관에 강의를 제안하는 독립 강사. 강의 내용은 준비했지만 설명 자료의 순서를 정리하기 어려운 사람.

이 일을 돕습니다: 교육 담당자가 수업의 대상·실습·결과를 구분해 읽을 수 있도록 강의 소개 내용을 한 장으로 정리합니다.

받는 것: 편집 가능한 소개 원고 한 장, 읽는 순서 안내, 제공 내용과 제외 내용을 적은 인수 메모. 이 예시에서는 시각 디자인 파일·인쇄·게시를 포함하지 않습니다.

포함: 받은 공개용 초안의 정보 분류, 대상·실습·결과의 구분, 문장 중복 정리, 미확인 사실 표시, 고객 확인 내용 반영. 반영 횟수와 추가 작업 기준은 실제 계약 전에 정할 항목입니다.

제외: 강의 내용 제작·전문성 심사, 자격·경력 인증, 기관 섭외, 계약 성사, 실제 수업 운영, 법률 검토, 고객 자료의 외부 공개.

준비할 것: 민감정보를 뺀 강의 개요, 예상 청중, 실습 내용, 수강생에게 남길 결과물. 이름·연락처·실제 수강생 기록은 이 교육 연습에 필요하지 않습니다.

진행 확인: 초안의 사실 확인 → 읽는 순서 선택 → 정리 원고 확인 → 파일과 사용 안내 인수. 실제 납기와 협업 방식은 별도 합의합니다.

사용 뒤: 원고에서 대상·강의 주제·실습 결과가 바뀌면 함께 바꿀 곳을 인수 메모에서 찾습니다. 개별 수정 제공 여부·범위·응답 시간은 이 가상 예시에서 약속하지 않습니다.

판매 전 미정: 가격과 포함 비용, 일정, 실제 수정 범위, 취소·환불·변경 조건, 사용 권리, 문의 창구, 계약 주체. 미정은 0원·즉시 제공·무제한으로 해석하지 않습니다.

3. 왜 이렇게 골랐나요

‘맞춤 브랜딩 패키지’라는 이름만으로는 무엇을 받는지 판단하기 어렵습니다. 그래서 결과물을 먼저 쓰고, 맡지 않는 일을 같은 페이지에서 읽게 했습니다. ‘고객 확인 내용 반영’도 무한 수정이 아니라 별도 범위를 정해야 하는 업무로 표시했습니다.

의뢰 목적과 제공물은 다릅니다. 고객의 목적은 강의 제안일 수 있지만 이 서비스가 넘기는 것은 소개 원고입니다. 제안 채택을 납품 완료 기준으로 삼지 않습니다.

4. 내 것으로 바꾸는 수정 원본

아래는 가상 사례로 채운 편집용 원본입니다. 각 줄을 자신의 사실로 바꾸고 미정 항목은 확정 전까지 남겨두세요.

서비스 이름: 첫 강의 소개자료 정리
누구를 위한 일: 첫 기관 제안을 준비하는 독립 강사
고객의 출발 상태: 강의 내용은 있으나 설명 자료의 정보 순서가 섞여 있음
내가 하는 일: 대상·실습·결과를 나누고 소개 원고의 순서를 정리함
고객에게 남는 것: 편집 원고 한 장 + 읽는 순서 + 바꿀 곳 안내
포함: 정보 분류 / 문장 중복 정리 / 미확인 표시 / 합의한 내용 반영
제외: 기관 섭외 / 계약 성사 / 강의 내용 전문 검증 / 디자인·인쇄·게시
고객이 준비할 것: 민감정보 없는 강의 개요와 청중·실습·결과물 설명
완료 확인: 합의한 사실과 범위가 원고에 있고, 원본과 사용 안내가 열림
판매 전 정할 것: 가격·비용 / 일정 / 수정 / 취소·환불 / 권리 / 연락 / 주체

실제 판매 페이지로 옮길 때는 미정 줄을 지워 숨기지 말고 확인된 조건으로 교체합니다. 업종별로 필요한 계약·거래 조건은 이 작업지가 대신 판단하지 않습니다.

5. 조건이 다르면 이렇게 바꿉니다

문서가 아니라 상담을 제공한다면: ‘편집 원고 한 장’을 상담의 실제 결과로 바꿉니다. 예: ‘소개 초안의 읽는 순서 검토와 본인이 고칠 지점 메모’. 실제로 메모를 주지 않으면 인수물에서 빼야 합니다.

제품 판매라면: 진행 단계보다 구성품·사용 조건·호환 조건·배송/인수·반품 등 해당 상품에 필요한 실제 조건을 먼저 확인합니다. 이 서비스 예시를 그대로 적용하지 않습니다.

기관 담당자가 구매한다면: 학습자와 계약 담당자를 나누고 사전 준비·검수 주체·인수 파일을 명시합니다. 구매자가 배우는 사람과 같다고 가정하지 않습니다.

아직 범위를 정하는 중이라면: ‘판매 중’ 대신 ‘서비스 설명 연습안’으로 보관합니다. 공개 자료를 제공할 수 있는 상태와 주문을 받을 수 있는 상태는 다릅니다.

6. 오판을 막는 확인

  • 고객의 목적과 내가 통제할 수 있는 제공물을 구분했나요?
  • ‘전부’, ‘무제한’, ‘보장’이 실제 조건 없이 들어가 있지 않나요?
  • 포함에서 약속한 파일이 사용 안내에도 같은 이름으로 적혀 있나요?
  • 디자인·배포·사후 수정이 포함인지 제외인지 숨겨져 있지 않나요?
  • 미정인 가격·일정을 이미 확정한 것처럼 안내하지 않았나요?
  • 가상 예시를 실제 주문 안내로 오해할 만한 신청 버튼·마감 표현을 붙이지 않았나요?

7. 쓰다가 막히면

“고객마다 작업이 달라요.” 공통으로 제공하는 것과 확인 뒤 달라지는 것을 나누세요. ‘모든 요청 가능’ 대신 ‘초안 확인 뒤 범위를 안내’라고 적되 실제 확인 절차가 있을 때만 안내합니다.

“제외를 쓰면 덜 팔릴 것 같아요.” 제외 이유를 짧게 설명하세요. 예: ‘기관의 채택은 해당 기관이 결정하므로 계약 성사를 제공물에 포함하지 않습니다.’ 불가능한 일을 더 약속하는 대신 맞는 의뢰인지 판단하게 합니다.

“수정 요청이 새 작업 같아요.” 원래 합의한 대상·결과가 바뀌었는지 보세요. 오탈자 수정과 새 대상용 전면 작성은 구분해 설명하고, 추가 작업은 합의 전 착수한다고 약속하지 않습니다.

“한 장에 안 들어가요.” 첫 장에는 판단에 필요한 핵심과 범위를 두고, 상세 조건은 이어지는 문서로 연결하세요. 필수 조건을 작은 글씨로 숨기는 것은 해결이 아닙니다.
