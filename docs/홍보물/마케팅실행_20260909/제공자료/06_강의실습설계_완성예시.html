연결한 콘텐츠는 같은 원리를 보여주는 별도의 가상 예시입니다. 같은 고객이나 같은 사건의 작업 기록으로 해석하지 않습니다.

배우고 나서 혼자 다시 하는 실습 설계 · 완성 예시

가상 교육용 완성 예시입니다. 실제 고객 납품물·상담 기록·성과 사례가 아닙니다. 기존 자료의 완성 부분을 독립 화면으로 연결했습니다. 아래 예시를 읽은 뒤 자신의 조건으로 바꾸고 원문과 범위를 대조하세요.

2. 채운 가상 수업 설계

제목: 내 일을 설명하는 첫 문장.

청중: 자기 전문성을 서비스로 소개하려는 초기 1인 사업자. 자기 일이 무엇인지는 알고 있으나 고객과 제공 결과가 소개문에 분명하지 않은 사람.

목표: 원본 사실에서 대상·상황·결과를 구분하고, 실제로 맡는 일을 설명하는 소개문과 자기 점검 메모를 작성한다.

시작 자료: 아래 가상 사례 초안. 자기 자료가 준비되지 않았어도 연습할 수 있다.

남길 것: 설명형 소개문 한 개, 짧은 소개 한 개, 두 문장에 같은 제공 범위가 유지되는지 적은 점검 메모.

준비: 글을 읽고 텍스트를 수정할 수 있는 도구. 새 구독·AI 사용·공개 업로드는 필요하지 않다. 기초 글쓰기가 막히면 세 칸의 짧은 메모만 먼저 작성한다.

맡지 않는 것: 고객 반응 검증, 수익 향상, 브랜드 전체 완성, 실제 판매 조건 확정. 개별 지도·응답 시간은 이 자료에서 약속하지 않는다.

진행: 예시 관찰 → 직접 작성 → 근거 대조 → 조건 변경 → 혼자 다시 작성. 정해진 시간에 완료해야 통과하는 실습이 아니다.

7. 내 강의에 옮기는 수정 원본과 조건별 변형

수업 주제: 내 일을 설명하는 첫 문장 — 가상 온라인 자율 실습
청중의 시작 상태: 하는 일은 있으나 고객과 결과가 소개에 분명하지 않음
끝에서 할 수 있을 행동: 원본 사실을 나눠 소개문을 쓰고 범위를 점검함
시작 파일: 대상·실습·결과가 섞인 가상 초안
완성 예시: 설명형 소개 + 짧은 소개 + 점검 메모
연습 과제: 세 칸 분류 → 소개 작성 → 새 고객 조건으로 다시 작성
확인법: 근거 대조 / 새 약속 없음 / 두 소개의 범위 일치
막히면: 문장 대신 세 칸 메모 → 예시 대조 → 한 조건만 바꿔 재시도
남길 파일: 자기 소개 원고와 수정 이유 메모
운영 조건: 자율 연습. 개별 지도·개강·판매·현장 운영은 확정하지 않음.

처음 배우는 사람: 예시의 한 칸을 먼저 채우고 이유를 설명합니다. 모든 전문용어를 알아야 시작하게 만들지 않습니다.

경험이 있는 사람: 예시를 따라 쓰는 과제보다 자신의 조건 두 가지를 비교하게 합니다. 실적 공개가 아니라 별도 가상 입력으로도 충분합니다.
