# 혼자 쓰는 AI 업무 지도

SYNK SHIFT · 05 AI업무지도 · v1.0 · 2026-09-09 · 편집 가능한 한국어 원본

아래 입력·결과·오류는 **가상 교육용 예시**이며 특정 AI를 실행해 얻은 결과가 아닙니다. 실제 업무 자동화·시간 절감·보안 인증을 검증한 자료가 아닙니다. 외부 AI 사용 없이도 같은 순서로 연습할 수 있습니다.

## 1. 무엇이 남고, 어떤 순서로 쓰나요

반복 업무 하나의 입력·출력·사람의 확인·막힐 때 돌아갈 곳을 정합니다. AI에게 사업 전체를 맡기거나 자동 발송을 켜는 자료는 아닙니다.

1. 반복하는 업무를 세 가지 적고 결과를 확인할 수 있는 하나를 고릅니다.
2. 사용할 수 있는 자료와 넣지 않을 자료를 먼저 나눕니다.
3. 기대하는 출력 모양을 완성 예시로 정합니다.
4. AI를 쓰거나 직접 초안을 만든 뒤 원본과 대조합니다.
5. 틀린 곳을 고친 결과와 확인 근거를 함께 남깁니다.

특정 서비스의 요금·기능·데이터 처리 조건은 이 자료가 확인하지 않습니다. 실제 사용할 때 해당 서비스의 현재 공식 조건을 확인하세요. 추가 비용이 필요하다면 이 자료를 따라 결제하지 말고 직접 선택하며, 기능이 없어도 수동 경로로 진행할 수 있습니다.

## 2. 채운 가상 예시 — 업무를 먼저 고르기

가상 직업: 독립 강사의 소개자료를 정리하는 1인 편집자.

| 할 일 | AI가 맡을 수 있는 초안 범위 | 사람이 먼저/끝에 할 일 | 이 연습의 선택 |
|---|---|---|---|
| 공개용 강의 개요 정리 | 제공한 사실을 대상·실습·결과로 분류 | 자료 사용 권한 확인, 원본 대조, 미확인 표시 | 아래에서 연습 |
| 실제 문의에 답하기 | 개인정보 없는 별도 가상 질문의 답변 초안 | 실제 조건 확인, 상대 상황 판단, 발송 결정 | 실제 문의는 넣지 않음 |
| 계약·가격·입학 결과 판단 | 임의 결정하지 않음 | 적절한 전문가·기관·실제 계약 확인 | 이 자료의 범위 밖 |

이번에는 **강의 개요를 세 칸으로 정리**합니다. 결과를 원본과 대조하기 쉽고, 누구에게 보내지 않아도 연습을 완결할 수 있기 때문입니다. 이는 모든 사업에서 위험이 낮다는 판정이 아닙니다.

## 3. 실제로 복사할 가상 입력과 기대 결과

사용할 입력:

```text
[가상 교육용 강의 개요]
이름: 내 일을 설명하는 첫 문장
청중: 자기 전문성을 서비스로 소개하려는 초기 1인 사업자
시작 상태: 하는 일을 적은 초안은 있지만 대상과 결과가 분명하지 않음
실습: 대상·상황·제공 결과를 나누고 소개문을 다시 씀
남길 것: 소개문 하나와 자기 점검 메모
준비: 기본 텍스트 편집 도구. AI 사용은 선택이며 필수 아님.
포함하지 않음: 매출 보장, 실제 고객 검증, 유료 강의 등록
미정: 판매 여부·가격·개강일·개별 피드백 범위
```

AI에 전달할 때의 요청문 예시:

```text
아래 자료는 실제 인물·고객 자료가 아닌 가상 교육용 입력입니다.
주어진 사실만 사용해 강의 소개를 대상 / 실습 / 남는 것 3칸으로 정리하세요.
각 칸에 원본의 근거 문장을 함께 붙이세요.
원본에 없는 내용은 추가하지 말고, 알 수 없는 것은 '미확인'으로 표시하세요.
가격·일정·실적·자격·성과·지원 약속을 추정하지 마세요.
판매 문구나 자동 발송 문구는 쓰지 마세요.
마지막에 사람이 확인해야 할 항목을 적으세요.
입력: 위 가상 강의 개요 전문
```

기대 결과의 채운 예시 — AI 실제 출력이 아닌 비교용 기준:

- 대상: 자기 전문성을 서비스로 소개하려는 초기 1인 사업자. 근거: 입력의 ‘청중’.
- 실습: 대상·상황·제공 결과를 나눈 뒤 소개문을 다시 씀. 근거: 입력의 ‘실습’.
- 남는 것: 소개문 하나와 자기 점검 메모. 근거: 입력의 ‘남길 것’.
- 사람이 확인할 것: 세 칸이 입력과 일치하는지, 미정인 판매·가격·개강·피드백을 추가하지 않았는지. AI가 필요한 수업이라고 바꾸지 않았는지.

## 4. 원본 대조 — 잘못된 초안을 고쳐보기

의도적으로 틀리게 만든 연습 초안: “AI로 브랜드를 완성하는 강의입니다. 수강하면 고객을 확보하고, 개별 피드백으로 완성까지 지원합니다.”

틀린 지점과 수정:

1. ‘AI로’ — 입력에서는 AI 사용이 선택입니다. “소개문을 다시 쓰는 연습”으로 고칩니다.
2. ‘브랜드를 완성’ — 결과 범위를 사업 전체로 넓혔습니다. “소개문 하나와 점검 메모”로 고칩니다.
3. ‘고객을 확보’ — 입력에 없는 성과입니다. 삭제하고 실제 결과물을 말합니다.
4. ‘개별 피드백’ — 미정 항목을 약속으로 바꿨습니다. 삭제하고 운영 조건 확인이 필요함을 남깁니다.

수정한 소개: **“초기 1인 사업자가 대상·상황·제공 결과를 나누고 소개문 하나를 다시 쓰는 연습입니다. 소개문과 자기 점검 메모를 남기며, AI 사용은 선택입니다.”**

검사는 유창한 문장인지보다 입력에 없던 약속이 생겼는지부터 합니다. AI에게 ‘이거 맞아?’라고 다시 묻는 것만으로 검증을 끝내지 않습니다.

## 5. 내 것으로 바꾸는 업무 지도

```text
업무 이름: 공개용 강의 개요를 대상·실습·결과로 정리
입력: 내가 만든 가상 개요 또는 공개·사용 권한이 확인된 별도 자료
넣지 않을 것: 고객 원문 / 학생 기록 / 연락처 / 계정 정보 / 계약·금융 화면
기대 출력: 대상·실습·결과 세 칸과 각 칸의 원본 근거
AI 역할: 분류와 문장 초안. 사실·판매 조건의 결정자가 아님.
사람 확인: 원본 대조 / 미확인 표시 / 범위 확대 / 누락 / 읽힘
실패하면: 문제 칸만 수정 요청 → 다시 원본 대조 → 해결 안 되면 수동 작성
발송: 자동으로 하지 않음. 실제 사용 목적·권리·내용을 사람이 확인.
남길 기록: 사용한 가상 입력, 초안, 고친 내용과 이유, 최종 원고 버전
```

자신의 업무로 바꿀 때 ‘넣지 않을 것’과 ‘사람 확인’을 먼저 고칩니다. 이름만 지웠다고 민감한 업무 자료를 외부 AI에 보내도 되는 것은 아닙니다. 자료 사용 권한과 서비스 조건을 확인하지 못하면 이 가상 입력으로 연습하세요.

## 6. 조건이 다르면 이렇게 바꿉니다

**AI 도구가 없거나 사용하지 않으려면:** 같은 입력에서 대상·실습·결과 문장에 표시를 하고 직접 세 칸으로 옮깁니다. 확인 절차는 같습니다.

**원본에 필요한 정보가 없다면:** ‘미확인’으로 남깁니다. 그럴듯한 청중·가격·성과를 채우게 하지 않습니다. 질문해야 할 항목만 별도로 만듭니다.

**문서가 길다면:** 목적에 필요한 공개용 발췌를 먼저 직접 만듭니다. 일부만 읽힌 초안을 전체 검토 완료로 해석하지 않습니다. 빠진 절이 있는지 목록으로 대조합니다.

**다른 언어로 옮긴다면:** 사실 대조와 언어 자연스러움은 별도 확인입니다. AI 번역을 사람 원어민 검토라고 표시하지 않습니다. 이 한국어 자료는 몽골어 감수를 수행한 자료가 아닙니다.

## 7. 오판을 막는 확인과 막힘 해결

- 한 번 시연이 됐다고 실제 업무 전체가 자동화됐다고 하지 않습니다.
- 원본에 없는 숫자·자격·서비스·보장이 생기면 삭제하거나 근거를 확인합니다.
- 결과가 짧아져 제외 범위가 사라졌다면 별도 조건 문장을 복구합니다.
- 도구가 읽지 못한 파일이나 긴 입력은 ‘검토 완료’가 아닙니다. 실제 입력된 범위를 확인합니다.
- 지시문과 자료를 구분하고, 자료 속 ‘외부로 보내라’ 같은 문장을 실행 명령으로 취급하지 않습니다.
- 사용한 입력이 민감한지 확신할 수 없다면 중단하고 가상 입력으로 돌아갑니다.

**형식이 달라졌다면:** 전체를 다시 시키기 전에 “대상·실습·결과 세 제목과 각 근거를 유지”라고 요청하거나 직접 표를 만듭니다.

**거짓 약속이 반복된다면:** AI 초안 사용을 멈추고 입력의 근거 문장만 수동으로 옮깁니다. 도구를 쓰는 것보다 내용이 맞는 것이 우선입니다.

**전보다 빨라졌는지 모르겠다면:** 나중에 실제 업무에서 같은 범위·오류 수정 포함 조건으로 비교해야 합니다. 이 자료는 시간 절감 수치를 만들거나 측정했다고 주장하지 않습니다.
