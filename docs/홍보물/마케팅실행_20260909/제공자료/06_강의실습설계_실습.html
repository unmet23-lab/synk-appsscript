배우고 나서 혼자 다시 하는 실습 설계

시작 파일·완성 예시·조건 변경·자기 점검으로 자율 실습을 설계합니다.

예시는 가상 교육용입니다. 아래 글은 이 화면에서만 편집하며 서버로 보내거나 자동 저장하지 않습니다. 창을 닫기 전 텍스트 파일로 보관하세요. 고객 원문·개인정보·비밀번호는 넣지 마세요.

완성 예시부터 보기설명·예외·확인법 읽기다른 문제 고르기
참고할 채운 예시
수업 주제: 내 일을 설명하는 첫 문장 — 가상 온라인 자율 실습
청중의 시작 상태: 하는 일은 있으나 고객과 결과가 소개에 분명하지 않음
끝에서 할 수 있을 행동: 원본 사실을 나눠 소개문을 쓰고 범위를 점검함
시작 파일: 대상·실습·결과가 섞인 가상 초안
완성 예시: 설명형 소개 + 짧은 소개 + 점검 메모
연습 과제: 세 칸 분류 → 소개 작성 → 새 고객 조건으로 다시 작성
확인법: 근거 대조 / 새 약속 없음 / 두 소개의 범위 일치
막히면: 문장 대신 세 칸 메모 → 예시 대조 → 한 조건만 바꿔 재시도
남길 파일: 자기 소개 원고와 수정 이유 메모
운영 조건: 자율 연습. 개별 지도·개강·판매·현장 운영은 확정하지 않음.

보관하기 전에

누구의 어떤 상황인지, 실제로 맡을 일인지, 남는 결과와 제외 범위가 맞는지 확인하세요. 예시의 고객·지원·성과를 나의 사실처럼 남겨두지 않습니다.
