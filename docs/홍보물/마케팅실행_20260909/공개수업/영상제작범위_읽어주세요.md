# 공개수업 · 영상 제작 범위

`수업.mp4`는 소개문과 상품 범위 한 장을 직접 적는 녹화형 공개 실습입니다. `클리닉.mp4`는 가상의 소개문에서 확인되지 않은 약속을 덜어내는 시연입니다. 실제 참가자의 질문이나 상담 녹화가 아닙니다.

## 사용할 파일

- `수업.mp4`와 `수업.srt`: 18장, 영상 시간 약 **10분 29초**. 화면에 구술 자막이 이미 포함되어 있으며 SRT도 제공합니다.
- `클리닉.mp4`와 `클리닉.srt`: 5장, 약 **1분 25초**. 화면과 구술에 가상 시연임을 표시합니다.
- 설명글·자료는 이 폴더와 상위 패키지의 해당 안내를 사용합니다. 업로드하지 않은 로컬 파일 경로를 공개 다운로드 링크처럼 붙이지 않습니다.

원고의 13분은 제작 전 가안입니다. 최종 영상은 실제 음성 길이, 직접 적을 여유 37초, 장면 전환 여유로 정했습니다. 연습 시간이 부족하면 영상을 멈추고 자기 문장을 적어도 됩니다. 두 영상은 현장 직접 강의나 실제 개강·상담 일정의 공지가 아닙니다.

## 음성과 자막

한국어 내레이션은 Higgsfield의 Qwen Audio TTS / Kevin 프리셋으로 만든 일반 합성 음성입니다. 유호님의 목소리를 복제하거나 실제 육성인 것처럼 연출하지 않았습니다. 첫 브랜드 발화는 ‘싱크 시프트’로 풀어 읽습니다.

음성 파일의 현재 원고 해시, 파일 디코드, 음량, 로컬 자동 전사 대조는 검사했습니다. 자막에는 자동 전사의 오인식 문구가 아니라 **확정된 원고**를 사용합니다. 단어별 전사 시각에 원고를 자동 대응시켰으므로, 사람이 듣고 모든 자막 시각을 조정한 결과라고 부르지는 않습니다.

사람의 실제 청취와 억양 평가는 아직 완료하지 않았습니다. 이는 출력 파일이나 자막 검증 전체가 실패했다는 뜻이 아닙니다. 자동 전사에서 발음 오인식 후보로 남은 아래 네 구간을 업로드 전 짧게 들어보면 좋습니다.

|---|---|---|
| 01:25–01:29 | 첫 칸 | 자동 전사에서 ‘척하는’으로 인식된 후보 |

위 표는 실제 오발음을 확정한 목록이 아닙니다. 자동 전사 오류인지 발화 문제인지는 청취로 구분해야 합니다. 핵심 부정이나 약속 범위가 뒤집힌 사례는 대조에서 확인되지 않았고 원문 자막을 보존했습니다.

음악은 원천이 확인된 SYNK 로컬 생성기의 자체 작곡 배경음입니다. 원곡 발췌나 실제 라디오 방송 녹음이 아닙니다. 출력에서는 음성에 음량 여유를 두었습니다. 원천 음성에서 발견된 세 개의 최대 진폭 샘플까지 없었다고 주장하지 않습니다.
