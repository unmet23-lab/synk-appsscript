# Substack · 답변 참고

선택형 질문: 소개를 고치며 막힌 곳이 대상·활동·범위 중 어디였나요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 범위가 계속 넓어진다는 실제 답장

이번에 끝까지 제공할 활동 하나와 남길 결과물 하나를 먼저 정해보세요. 나머지는 삭제하는 대신 ‘이번 범위 밖에서 따로 검토할 것’으로 적어두면 구분하기 쉽습니다. 개별 검토 여부는 별도 합의가 필요합니다.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
