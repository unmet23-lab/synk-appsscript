# YouTube · 답변 참고

선택형 질문: 쓰다가 막힌 곳은 대상, 활동, 결과물 중 어디인가요?

공개 답변 전 질문의 맥락을 확인하세요. 자동 응답이나 답변 기한을 약속한 파일이 아닙니다. 실제 개인정보·고객 원본·토큰을 요구하지 않습니다.

## 1. 대상을 못 고르겠다는 질문

직업명보다 이 일이 필요해지는 상황을 먼저 적어보세요. 예를 들어 ‘판매자’에 ‘새 제품 사진을 혼자 준비하는’을 더할 수 있습니다. 가상 예시이니 실제 고객에게 맞는지 확인해 주세요.

운영자가 해당 질문을 실제 받았을 때 골라 쓰는 예시 · 실제 응답 기록 아님
