## 바로 게시하는 순서

1. 갤러리에서 이번에 올릴 계정을 고릅니다. 계정 이름과 로그인한 게시 대상을 대조합니다.
2. 이미지 게시물은 `upload-01.jpg`부터 번호순으로, 영상 게시물은 `video.mp4`를 업로드합니다. `master-*.png`는 로컬 보관용 원본이며 업로드 꾸러미에는 중복 수록하지 않았습니다.
3. `게시문안.txt`를 본문 칸에, `제목.txt`와 `대체텍스트.txt`를 지원되는 해당 칸에 넣습니다. Threads 두 편의 공개 본문은 각각 223자·242자이므로 기본 짧은 글로 사용할 수 있습니다. 블로그·Substack은 긴 글을 텍스트로 넣고 이미지를 별도로 첨부합니다.
4. 연결된 PDF는 해당 서비스의 파일 첨부 기능에서만 사용합니다. 기능이 없으면 본문 자체의 완결된 팁을 먼저 제공합니다. 아직 없는 자료실·신규 계정 URL을 만들어 붙이지 않습니다.
5. 실제 앱 미리보기에서 카드 순서·잘림·자막·소리·자료 접근을 확인한 뒤 발행합니다. 플랫폼별 주의점은 [_검토/업로드조건.md](_검토/업로드조건.md)를 따릅니다.
6. 질문은 계정 폴더의 `댓글답변.md`를 바탕으로 맥락에 맞게 답합니다. 지원 범위 밖의 요청과 추가 확인이 필요한 조건을 분리하고, 답변 기한·개별 첨삭을 임의로 약속하지 않습니다.

계정별 ZIP은 한 계정에 올릴 파일을 추린 묶음입니다. 전체 ZIP은 갤러리·자료실·수업을 함께 여는 묶음이며, 용량 중복을 피하려고 계정 ZIP 자체를 다시 넣지 않았습니다. HTML은 폴더 구조를 유지해야 합니다.
