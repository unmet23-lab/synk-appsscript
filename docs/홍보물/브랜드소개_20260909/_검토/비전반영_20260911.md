# 확정 비전의 소개서·정적 소비처 반영

## 반영과 보존

- 원문: `docs/비전_정본.md`. 네 전면 문장과 전체 서브텍스트는 `tools/lib/비전정본.js`로 읽는다.
- 소개서 제작 입력을 기존 `소개서_문안.json`으로 바꿨다. 과거 원고를 코드 안에서 다시 써서 덮어쓰던 부분을 제거하고, 표지의 비전 두 필드만 정본에서 주입한다.
- 네 표지의 제목·설명 공간과 그림 배치를 조정했다. 기존 내지 16쪽의 원고 및 표지의 자산·캡션·상태 설명을 작업 전 JSON과 대조해 보존했다.
- 소개서 4종의 HTML·PDF, 4K PNG 20쪽, 표지·전체 미리보기, 모아보기, 다운로드 ZIP을 갱신했다. 모아보기에도 전면 문장과 서브텍스트 전체를 제공한다.
- 계정별 콘텐츠의 표지 원천을 현재 `소개서_4K`로 연결했다. 과거 스냅샷을 계속 읽던 경로를 바꿨다. 기존 스냅샷 사본과 실제 자산도 갱신했다.
- `비전파생갱신.cjs`는 현재 카드 HTML을 다시 읽어 영향을 받는 카드 6개만 렌더한다. 기존 문구·배치는 유지한다. 전체·해당 계정 미리보기와 기존 다운로드 묶음도 갱신했다.
- 마케팅 실행판의 현재 전면과 세 사업 소개에 비전 전체를 반영했다. `비전지면.js`를 생성기에도 연결하여 다음 제작에서 정본을 읽게 했다. 전체 오래된 생성기를 다시 실행하여 현행 편집을 덮어쓰지는 않았다.

## 실제 검증

- 네 소개서 표지와 모아보기의 전면·서브텍스트 총 8쌍이 정본과 일치한다.
- 20쪽 지면을 3840×2400으로 출력했다. PDF 4개는 각 5쪽이며, Poppler로 PDF의 20쪽을 다시 PNG로 변환해 제목·설명·이미지·마무리를 눈으로 확인했다. 페이지 밖 잘림은 없다.
- 모아보기는 1440px·390px에서 가로 넘침 0, 이미지·폰트 로드 및 모든 비전의 전체 노출을 확인했다.
- 현재 카드 6개의 HTML 보존·글자 경계·이미지 로드·출력 픽셀을 확인했다. 카드 안 소개서 이미지는 완성 문서의 예시이며, 전체 문장은 원본 소개서와 모아보기에서 읽는다.
- 소개서 ZIP은 중복 이름·CRC·재개봉 후 모든 항목의 SHA-256을 확인한다. 계정별 및 마케팅 실행판 ZIP은 기존 도구의 재개봉 지문·내부 링크 검증을 통과한 결과를 사용한다.
- 정본의 행 끝 공백·마지막 빈 줄 정리 뒤 비전 문구 8쌍을 기존 원고·HTML·렌더 검증 기록과 다시 대조했다. `비전검수.cjs --copy-only`는 현재 원문 지문을 기록하며, 최초 렌더 시점의 원문 지문도 별도 보존한다. 문구와 PDF는 바뀌지 않았다.

기계 확인은 `비전실물검증_20260911.json`, `비전원고보존_20260911.json`, `비전파생검증_20260911.json`, 상위 `PDF검사.json`·`묶음검사.json`에 있다. 실제 검수 화면은 이 폴더의 `비전모아보기-*.png`, `비전파생_모아보기.png` 및 상위 `PDF미리보기/`에 있다.

## 재생성 명령

Node에는 Codex 번들 `dependencies/node/node_modules`를 `NODE_PATH`로 연결한다. Python은 같은 번들의 `dependencies/python/python.exe`를 사용했다.

```text
node docs/홍보물/브랜드소개_20260909/만들기.cjs
node docs/홍보물/브랜드소개_20260909/모아보기만들기.cjs
node docs/홍보물/브랜드소개_20260909/내보내기.cjs --4k
python docs/홍보물/브랜드소개_20260909/PDF만들기.py
node docs/홍보물/계정별콘텐츠_20260909/_개선/지면스냅샷.cjs
node docs/홍보물/마케팅실행_20260909/브랜드킷/소개서스냅샷.cjs
node docs/홍보물/브랜드소개_20260909/비전파생갱신.cjs
node docs/홍보물/브랜드소개_20260909/비전검수.cjs
python docs/홍보물/브랜드소개_20260909/묶기.py
node docs/홍보물/계정별콘텐츠_20260909/묶기.cjs
python docs/홍보물/마케팅실행_20260909/출고도구.py --출고
```

## 공개 자료 사이트 반영

Field Notes의 기존 Sites checkout은 주담당이 수정·배포했다. `tmp/vision-marketing-contribution/site-patch.json`의 원본 지문과 대조한 6개 파일을 적용해 v11로 기존 공개 범위에 게시했다. 전면 SYNK 비전, 기존 세 사업 링크의 전면·전체 설명, CSS, LAB 소개서 이미지, 16번 카드·게시 페이지·JPG가 대상이다.

주담당의 실제 URL 검증 기록 `docs/_ops/비전반영_20260911/marketing-live.json`을 확인했다. [공개 Field Notes](https://synk-field-notes.unmet23.chatgpt.site)의 1440px·390px 화면 모두 네 전면 문장·전체 설명이 일치하며, 가로 넘침과 화면 오류는 0이다. 빌드는 244개 파일과 561개 내부 참조 검사를 통과했다. 이 작업자는 해당 Sites checkout을 직접 편집하거나 배포하지 않았다.

로컬 마케팅 실행판은 실제 존재하는 `#accounts` 구간으로 SHIFT 비전 링크를 연결한다. 별도 공개 Field Notes의 `#making` 구간은 해당 사이트의 현행 구성에 맞게 유지한다.

## 변경하지 않은 범위

- 「괜찮아요」 몽골어 캐러셀은 학습 표현을 설명하는 자료이므로 새 회사 비전의 번역을 넣지 않았다. 원어민 감수 상태도 바꾸지 않았다.
- `계정별콘텐츠_20260909/04-yuhobuilds-youtube`, `05-yuhobuilds-instagram`, `06-yuhobuilds-tiktok`의 영상에는 당시 소개서 장면이 있다. 제목은 각각 「이 소개서는 무엇부터 읽어야 할까요」, 「캐릭터를 덜 넣은 이유」, 「더 넣기 전에, 읽는 순서부터」이며 과거 제작·편집의 사례다. 현재 공식 비전 소개 영상으로 바꾸거나 다시 녹음하지 않았다. 영상 원본과 이전 음성 공급·재제작 보류를 보존했다.
- 현재 Field Notes의 같은 번호 영상은 이후 만든 가상 실습 「첫 소개에서 경력을 한 칸 뒤로」, 「내 이름을 가려도, 무슨 일인지 보이나요?」, 「‘맞춤형’ 다음에 무엇이 바뀌나요?」다. 위 과거 소개서 영상과 같은 파일로 간주하지 않았다.
- 이미 다른 사람에게 보낸 파일·SNS 게시물·인쇄물을 회수하거나 재전달하지 않았다. 외부 실제 시청·학습 효과는 이번 제작 검증에 포함하지 않는다.
- SYNK-appsscript 커밋은 주담당이 통합한다. 별도 Sites 배포·커밋을 이 작업자가 수행했다고 표시하지 않는다.
