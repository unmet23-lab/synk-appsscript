# 제작 확인 기록 — 2026-09-09

## 뜻과 현재 상태

한국어 사업·협업용 소개서 4종 × 5쪽, 몽골 학습자용 캐러셀 7장. 보수적인 사업 설명과 실물 중심의 별도 구성안을 비교하고 결합했다. 독립 검토자는 소개서 문안과 지면 20/20쪽을 확인했다.

반영한 지적: SYNK 4쪽 공책 그림이 실제 교육 과정의 증거로 보이지 않도록 “교육 콘텐츠용 소품”으로 고쳤다. PULSE 3쪽은 차이가 작은 캐릭터 컷을 덜어 두 표정으로 구성했다. 현재 법인·개원 준비 상태, LAB의 학습 예시, PULSE 제작과 SHIFT 계약 구분을 확인했다. 가격·성과 보장·실제 고객 결과를 추가하지 않았다.

## 실제 지면

소개서 20/20쪽을 3840×2400 PNG로 렌더했다. 글자 영역이 지면 밖으로 나가는 문제는 20/20쪽에서 없었다(`지면검사.json`). 눈으로 보고 본문과 예시, 마지막 쪽의 두 설명 사이 간격을 조정했다. PDF 4/4파일의 쪽수는 각각 5쪽이며, Poppler로 PDF 20/20쪽을 다시 이미지로 열어 전체 배치를 확인하고 LAB 2쪽은 1440px 폭에서 글자와 그림을 확인했다.

캐러셀 7/7장의 영역 잘림과 1080×1350·2160×2700 치수를 확인했다. 실제 지면을 펼쳐 왼쪽 정렬과 제목·예문·뜻의 순서를 확인했다. 출력 경계 검사는 시각 품질의 자동 합격 판정이 아니다.

## 자산과 파일

파일명과 실제 그림이 맞지 않는 일부 자산, 장면 안쪽까지 투명해진 자산은 제외했다. 최종 선택한 15/28 파생 자산만 배포 묶음에 넣었다. `night`, `moon` 원본은 2048×2048이며 이를 4K 원본이라 주장하지 않는다. 나머지 자산도 각각의 실제 치수를 `자산명세.json`에 기록했다.

PDF는 4K 페이지 이미지 기반이며 검색·텍스트 편집은 HTML 원본에서 한다. ZIP 2/2개를 다시 읽어 파일 손상이 없음을 확인했다(`묶음검사.json`). 최종 PDF·업로드 PNG·선택 자산·제작 스크립트는 저장소에 보존하고, 고해상도 중복 출력·ZIP·HTML은 재생성 가능한 로컬 결과로 둔다.

## 후속: 사업명 색과 스티치

유호님의 승인에 따라 사업명에 기존 Deep 팔레트 색을 적용하고, 큰 표지에 공통 스티치를 더했다. 기본형은 글자색만 바뀐다. A/B를 독립 설계하고 실제 표지·확대 이미지 2/2판을 별도 검토했다. B의 읽힘을 채택하되 실의 굵기가 이름마다 달라지던 부분을 고쳤다. 최종 조합·검사·투명 로고는 `로고디테일/`에 있다. 기존 문안과 대표 그림은 유지했다.
