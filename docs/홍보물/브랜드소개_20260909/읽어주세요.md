# SYNK 소개서 · 캐러셀 — 2026.09.09

## 현재판 — 2026.09.11 비전 반영

소개서 네 종의 표지에 [확정 비전](../../비전_정본.md)의 전면 문장과 전체 서브텍스트를 함께 반영했습니다. 제목·설명·그림의 공간을 조정하고 기존 내지 16쪽, 표지의 자산·상태·캡션을 보존했습니다. `만들기.cjs`는 현재 `소개서_문안.json`을 읽고 비전만 `tools/lib/비전정본.js`에서 가져오므로 이후 원고 수정이 과거 하드코딩으로 돌아가지 않습니다.

4K 지면 20쪽과 PDF 네 종을 다시 만들었고, PDF 20쪽을 PNG로 재변환하여 읽힘·잘림·이미지 배치를 확인했습니다. 모아보기에서도 네 비전의 전면 문장과 서브텍스트 전체를 읽을 수 있습니다. PDF는 기존과 같은 이미지형 문서이며 직접 텍스트 검색·편집은 지원하지 않습니다.

소개서 표지를 사용하는 계정별 콘텐츠의 카드 5개와 마케팅 실행판 카드 1개, 관련 표지 자산·미리보기·ZIP도 현재 지면을 소비합니다. 카드의 기존 문구와 배치는 보존했습니다. `비전파생갱신.cjs`가 이미 작성된 HTML을 다시 읽어 이 정적 파생만 갱신합니다. Field Notes의 전면 소개와 세 사업 소개는 `비전지면.js`가 같은 정본을 읽습니다.

검증 근거는 `_검토/비전원고보존_20260911.json`, `_검토/비전파생검증_20260911.json`, `비전_반영.json`, `PDF검사.json`, `묶음검사.json`입니다. 주담당이 [Field Notes](https://synk-field-notes.unmet23.chatgpt.site)를 기존 공개 범위의 v11로 게시하고, 실제 주소의 1440px·390px 화면에서 네 비전과 전체 설명, 가로 넘침 0·화면 오류 0을 확인했습니다. 이미 전달한 파일·인쇄물·SNS 게시물을 회수하거나 재전달한 것은 아닙니다.

기존 몽골어 학습 캐러셀은 회사 비전 지면이 아니므로 문안·번역을 변경하지 않았습니다. 과거 제작 과정을 설명하는 영상 안의 옛 소개서 화면은 당시 작업의 기록입니다. 새 비전의 음성·영상 번역이나 재녹음을 이번 정적 지면 갱신으로 완료했다고 표시하지 않습니다.

한국어로 사업·협업 상대에게 보여주는 소개서 네 종과, 몽골 학습자를 위한 「괜찮아요」 캐러셀입니다. 기존 완성본을 가져온 것이 아니라 이번 요청에 맞춰 문안과 지면을 새로 구성했습니다. 캐러셀의 학습 주제·예문은 앞선 시안을 이어 다듬었고, 그림은 보유한 브랜드 자산을 재사용했습니다.

## 보는 법

- `index.html`: 소개서와 캐러셀 모아보기. 압축을 모두 푼 뒤 엽니다.
- `synk.pdf`, `lab.pdf`, `shift.pdf`, `pulse.pdf`: 한국어 사업·협업 소개서, 각각 5쪽입니다.
- `SYNK-LAB-carousel.zip`: 업로드용 1080×1350 이미지 7장과 고해상도 2160×2700 이미지 7장입니다. 파일 번호 순서대로 사용합니다.
- `synk.html`, `lab.html`, `shift.html`, `pulse.html`, `carousel.html`: 문구·배치를 수정할 수 있는 원본입니다. `assets` 폴더와 함께 둡니다.
- `SYNK-division-logos.zip`: 사업별 기본형·표지형 로고 6종. 투명 배경의 가로 3840px PNG와 사용 안내입니다.

소개서는 상대에게 직접 보내거나 설명하며 보여주는 자료입니다. 공개 배포용 연락처는 추가하지 않았습니다. 최종 연락 경로를 정하면 마지막 쪽에 넣을 수 있습니다.

## 이번 판에서 달라진 점

큰 제목 → 핵심 설명 → 대표 실물 순서로 읽히게 구성했습니다. 같은 내용을 한국어와 몽골어로 거듭 설명하던 캐러셀 문장을 덜고, 장마다 한 상황을 보여줍니다. 펠트 소품은 내용과 관련 있는 자리에 배치하고 캐릭터의 반복을 줄였습니다.

후속 디테일 수정: SYNK 원형은 유지하고 LAB 코랄·SHIFT 청금석·PULSE 팝 색을 사업명에 적용했습니다. 표지에서는 사업명 아래에 기존 크림색 실땀을, 내지와 캐러셀에서는 글자색만 사용합니다. 스티치의 굵기는 세 사업에 동일하게 적용했습니다.

- SYNK: LAB·SHIFT·PULSE의 역할과 공통 관점.
- LAB: 한국어 수업의 한 장면, 학생 이해, 학습 흐름과 개원 준비.
- SHIFT: 직접 제작·운영하며 얻은 방법, 광고 콘텐츠 제작과 브랜딩 교육 준비.
- PULSE: 라디오 배경, 캐릭터의 표현, 소품과 제작 협업.

현재 준비 상태와 학습 예시를 밝혔습니다. 학생 성과·고객 실적·실제 시설 사진으로 표현하지 않았습니다. PULSE가 제작하고 계약·권리 범위는 SHIFT를 통해 확인하는 구분을 유지했습니다.

## 품질과 확인 범위

- 소개서 20/20쪽을 3840×2400으로 출력했습니다. 작업 폴더의 `소개서_4K`에 PNG 원판이 있습니다. PDF는 이 지면을 같은 해상도의 고품질 이미지로 담아 공유 용량을 줄였습니다. PDF 안에서 텍스트를 직접 편집하거나 검색하는 방식은 지원하지 않습니다.
- 캐러셀 7/7장의 화면 잘림을 확인했고, 소개서 20/20쪽을 펼쳐 보며 문단 간격·정렬·이미지 배치를 검토했습니다. 기계적인 경계 검사와 눈으로 본 판단을 구분합니다.
- 캐러셀의 몽골어 본문은 문법·역번역·말투·맞춤법·뜻 대조 기계 검문을 마쳤습니다. **발행 전 몽골어 원어민 감수는 남아 있습니다.** 실제 이용자 반응이나 마케팅 성과를 측정한 판은 아닙니다.
- 모든 그림을 4K 원본이라고 부르지 않습니다. 캐릭터·공책·카페·교실은 4096px급 원본이고, 라디오 배경 `night`·`moon`은 2048px 원본입니다. 후자는 원본보다 크게 늘리지 않는 배치로 사용했습니다. 실제 선택·치수·출처는 `사용자산.json`, `자산명세.json`에 있습니다.

## 다시 만드는 순서 — 작업자용

저장소 루트에서 실행합니다. Node 환경에는 Playwright·sharp, Python 환경에는 ReportLab·Pillow·pypdf가 필요합니다. PDF 확인에는 Poppler를 사용합니다. 패키지를 새로 설치하지 않고 Codex의 기존 실행 환경으로 제작했습니다.

1. 선택 자산이 있으면 그대로 사용합니다. 다시 준비하려면 `node docs/홍보물/브랜드소개_20260909/자산준비.cjs`를 실행합니다. 이 단계는 저장소의 기존 고해상도 자산이 필요합니다.
2. `node docs/홍보물/브랜드소개_20260909/만들기.cjs`
3. `node docs/홍보물/브랜드소개_20260909/캐러셀만들기.cjs`
4. `node docs/홍보물/브랜드소개_20260909/모아보기만들기.cjs`
5. `node docs/홍보물/브랜드소개_20260909/내보내기.cjs --4k`
6. `node docs/홍보물/브랜드소개_20260909/캐러셀내보내기.cjs`
7. `python docs/홍보물/브랜드소개_20260909/PDF만들기.py`
8. `node docs/홍보물/브랜드소개_20260909/로고마무리.cjs`
9. `python docs/홍보물/브랜드소개_20260909/묶기.py`

소개서 비전 변경 뒤에는 `node docs/홍보물/브랜드소개_20260909/비전파생갱신.cjs`로 현재 정적 소비처를 갱신하고, 계정별 콘텐츠·마케팅 실행판의 기존 묶음 도구로 다운로드를 다시 만듭니다. 공개 사이트는 이 갱신 결과를 반영한 뒤 현재 URL의 내용과 파일을 대조합니다.

문안을 바꾸면 해당 언어 검문과 지면 확인을 다시 합니다. 공용 제작 도구나 기존 소개서는 덮어쓰지 않았습니다. 배포·게시하지 않았습니다.
