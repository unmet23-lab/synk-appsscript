- 봉투·책·가위는 root가 Paper/Ink 두 바탕에서 승인한 `_개선/봉투-2.5.png`·`책-2.5.png`·`가위-2.5.png`를 직접 복사했다. 이전 손상 자산으로 되돌아가지 않는다. 소품의 투명 윤곽을 둥근 마스크로 자르지 않는다.
- 소개서는 승인 원본의 본문을 유지하고 로고만 바꾼 `_개선/지면스냅샷/{lab,shift,pulse}-1.png`를 사용한다. 04·06은 전체 지면 다음에 실제 제목·설명·실물을 확대한다. 05는 원고가 지목하는 실물에 초점을 맞춘다. 새 문장이나 가상 화면을 만들지 않았다.
- PULSE 지면 확대에서 창과 램프·책상 연결이 잘리지 않도록 별도 영역을 쓴다. 05 마지막 공책은 윤곽 결손은 없었지만 바닥 여백이 좁아, 최종판에서는 원본의 아래 여백을 더 포함했다.
- 등장 이후 소품과 문서는 읽는 동안 멈춘다. 불필요한 반복 이동을 없앴으며, 본문은 기존 브랜드 서체를 유지했다.

## 소리와 남은 확인 한계

기존 `영상/BGM만들기.js`로 이번 전용 폴더에 만든 사인·삼각파 기반 자체 연주곡이다. 실제 라디오 녹음이나 외부 곡 발췌가 아니며, 유호 육성·학생 음성·TTS 발음을 흉내 내지 않았다. 01의 약 -18.17 LUFS / true peak -5.66 dBTP는 조용한 감상물의 기존 음량을 유지했다. 다른 편은 낮은 배경음이며 실제 측정값은 `영상_<id>_audio.log`의 `input_i`·`input_tp`에 있다. `output_i`는 측정 필터의 가정 결과이지 납품 파일에 적용한 음량이 아니다.

**위 검수는 전 장면 대표 프레임의 시각 확인과 기계적 소리 측정이다. 전체 240초 실시간 재생·사람의 실청취를 수행했다는 뜻은 아니다.** 모든 7,200개 영상 프레임을 한 장씩 본 것도 아니다. 실제 기기에서의 재생 체감·음악적 평가·실제 피드 성과는 미확인이다. 몽골어 원문 검증은 문안 담당의 별도 언어 근거 범위이며, 이번 영상 단계에서 문장을 바꾸지 않았다.
