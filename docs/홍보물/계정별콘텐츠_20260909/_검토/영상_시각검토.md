## 직접 본 범위와 고친 점

최종 MP4에서 나온 **53개 프레임 전부를 7개 묶음 이미지로 직접 확인**했다. 별도로 LAB 첫 장면·한국어/몽골어 수업 장면·제작 노트 소개서 지면·긴 인수 제목·수정한 감상 구도를 1080×1920 프레임에서 봤다.

- 01: 첫 판에서 창과 램프의 왼쪽이 잘렸다. root 검토를 반영해 원본 배치 `left: -420`을 `-200`으로 바꾸고 실제 MP4를 다시 렌더했다. 최종 인코딩 3프레임에서 창틀 전체·램프·책상 다리와 바닥의 연결을 확인했다. 원본 그림을 재염색하지 않았다. 감상물의 목적에 따라 화면 자막·캐릭터 동작·카메라 이동을 넣지 않았다.
- 03: 첫 장면의 몽골어 역할 목록이 그림 위를 가로질렀다. 원고의 단어를 바꾸지 않고 자료 찾기·그리기·발표를 같은 크기 세 줄로 나눴다. 한국어 문장 3개와 대응 몽골어, 마지막 선택 장면에 잘림이 없다. 역할 문장은 각각 7초를 확보했다.
- 04: 승인 소개서의 실제 완성 지면 3종과 읽는 순서·다섯 칸 적용 장면을 확인했다. 실제 고객 화면이나 가짜 제작 전후를 추가하지 않았다.
- 05·06: 실제 소개서와 승인 소품을 쓰며, 제목·본문·실물 사이 겹침이 없다. 같은 제작 작업에서 나온 편집본이지 별개의 고객 성과인 것처럼 꾸미지 않았다.
- 07·09: 원본·바꾸는 곳·확인법의 제목과 설명이 안전 영역 안에서 읽힌다. 설계 예시 표시를 남기고 실제 기관/학생 정보를 쓰지 않았다.

## 기계 검사

- scoped TypeScript 검사와 `node --check 영상/계정별굽기.cjs` 통과.
- 7편 모두 H.264·1080×1920·30fps·bt709, AAC 오디오 트랙과 해당 SRT가 있다. 약 0.04~0.06초의 컨테이너 길이 차이는 허용 오차 0.12초 안이다.
- 공용 폰트 9벌의 파일을 정본과 해시로 대조했다. 공용 폰트 사본은 고치지 않았다.
- 승인 자산 18개를 이번 전용 public 폴더에 복사하고 원천·해시를 `영상_원천명세.json`에 남겼다.
- 매 렌더에서 자원 로딩 실패와 필수 텍스트의 잘림/안전 영역 이탈을 검사했다. 기존 Root.tsx·공용 킷·제작 중 릴 10편·기업 소개 20초는 수정하지 않았다.
- 번들 FFmpeg에는 tile 필터가 없어 첫 묶음 이미지 제작이 실패했다. 실제 성공 MP4를 버리지 않고 번들 sharp로 묶음을 만들고 후속 검증을 계속했다.

## 소리와 확인 한계

기존 `영상/BGM만들기.js`로 이번 전용 폴더에 파생한 사인·삼각파 기반 자체 연주곡을 사용했다. 실제 라디오 방송 녹음이나 외부 곡 발췌가 아니다. 가짜 유호 육성·학생 음성·TTS 발음은 넣지 않았다.

01은 약 -18.17 LUFS, true peak -5.66 dBTP로 측정됐다. 조용한 감상물의 음량을 그대로 유지하라는 root의 판단을 반영했다. 나머지는 낮은 배경음으로 사용하며, 편별 실제 수치는 `영상_<id>_audio.log`의 `input_i`·`input_tp`에 있다. `output_i`는 측정 필터가 가정한 변환 결과이지 납품 MP4에 적용된 음량이 아니다.

**프레임의 시각 검수와 기계적 소리 측정을 완료했다. 전체 240초를 실시간 재생해 보거나 사람이 실청취한 것은 아니다.** 따라서 음악적 완성도·체감 음량·실제 피드 반응·원어민 발화 평가까지 통과했다고 말하지 않는다. 몽골어 원문 검증은 문안 담당의 언어 근거 파일과 별도로 이어지는 범위다. 제작 완료와 실제 게시 완료는 구분한다.
