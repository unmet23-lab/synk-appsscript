- 위치: `tools/lib/loom.js:1587`, `.account-collection .headline`의 `font-weight:750`.
- 재현 입력: `04-yuhobuilds-youtube` 또는 `13-yuhobuilds-linkedin`의 한국어 제목. 공통 헤드 규칙이 750을 선택한다.

### 수정 후 차이 확인

- 주담당이 Loom `:1587`의 한국어 공통 헤드를 800으로 수정했다. 실제 생성된 `collection.css:700`도 `font-weight:800`으로 일치한다. Inter Tight는 그대로 실제 700 파일을 사용하며, 새 서체를 만든 것은 아니다.

## 분모·자산·본문 구현 검토

- 분모: `만들기.cjs:21–27`이 입력 16개, 고유 ID, 카드·문안·제목, 영상 장면, 파생 원작 존재를 확인한다. 이번 실물은 13개 기록+3개 준비용이며 16개가 모두 실사된 계정이라는 뜻으로 쓰지 않는다.
- 크롭: `만들기.cjs:90`은 원본 비율을 유지하는 `fit:'inside'`와 확대 금지를 사용한다. 큰 소품·소개서·디프티크는 Loom에서 `object-fit:contain`이다. 모아보기 표지의 `object-fit:cover`는 동일한 4:5 원본과 4:5 박스에 사용되어 이 입력에서는 잘리지 않는다. 스티치 띠의 `cover`는 장식 띠이며 소개서 내용을 자르는 경로가 아니다.
- 원문 보존: `만들기.cjs:68–73`이 전체 캡션·제목·대체 텍스트와 Substack `article` 전문을 별도 파일로 내보낸다. 이미지에서 본문을 덜었다고 자료 전체가 없어지는 구조는 아니다.
- 빈칸: `만들기.cjs:52`가 밑줄 문자만 실제 필기 선으로 바꾸고 질문·칸 제목은 남긴다. worksheet 소품을 생략한 것은 입력 내용을 잃은 것이 아니라 필기 면의 편집 선택이다.
- 글꼴: 폰트 파일을 CSS에 포함하므로 네트워크 부재에 따른 폴백을 피한다. 실제 사용 글꼴 확인도 위와 같이 별도로 수행했다. `document.fonts.check()`만으로 전 글리프의 실제 서체를 증명했다고 보고하지 않는다.

## 반복과 신선함에 대한 판단

승인된 문법을 재사용한 컬렉션이지 26장마다 새 스타일을 발명한 세트는 아니다. 예문·필기 양식·소개서 실물·작품 장면·캐릭터·두 면 전시로 실제 쓰임이 나뉘므로, 모든 계정을 이름만 바꾼 한 장으로 취급할 정도의 동일 반복은 보이지 않는다.

다만 04·06·11·15는 같은 소개서 제작 판단을 채널별로 나눈 한 묶음이고, 07·09·12도 인수 원작의 파생 묶음이다. 이를 16개의 독립 주제나 26개의 새 원본 자산으로 보고하면 과장이다. 현재 원작/파생 표기는 그 관계를 드러낸다. 같은 소개서가 네 번 보이는 것은 실제 확인되는 반복이며, 이번처럼 같은 제작기의 채널별 편집으로는 설명되지만 다음 제작 회차까지 이 표지만 계속 쓰는 기준으로 일반화하지 않는다.

학생은 자기 문장을 적을 수 있고, 실무자는 기록·인수 양식을 복사할 수 있으며, PULSE는 감상으로 끝난다. 파일을 받은 뒤 남는 것이 서로 다르다는 점은 이번 실물에서 확인했다. ‘명품’ 또는 ‘트렌디함’에 대한 실제 청중 반응과 성과는 아직 확인하지 않았다.

## 확인하지 않은 것

몽골어 원어민 감수, 영상 전 프레임·음성·음량·재생, 실제 SNS 앱의 UI 가림과 업로드 재압축, 계정 로그인·권한·발행 기능, 외부 게시·모집·계약·입학 조건, 실제 사용자 반응은 이 정적 검토의 완료 범위가 아니다. 원고나 CSS가 바뀌면 변경 영향을 받는 결과만 재확인한다.
