## 4. 남은 감수와 최종 QA의 경계

두 원천 모두 **인간 원어민 감수 완료 증거는 없다.** 최신 원천의 ‘원어민 감수 전’ 상태를 유지한다. 현재 무료 자기 채널 발행의 예외 조건과 유료 광고의 감수 조건은 철학 19행/마케팅 §10-4를 따르되, 이번 작업 자체는 발행이 아니다. 새 언어 조합·캡션·제공 방식·영상 자막에 기존 통과 도장이 자동으로 옮겨가지는 않는다.

최종 QA에서는 문법만이 아니라 문장과 상황의 대응, 발화 방향, 학생의 선택, 자료를 실제 받는 방식, 읽을 시간, 몽골어/한국어 글리프, 감수 상태 표시를 확인한다. 기존 자료의 번호나 문장 개수를 바꾸면 실제 산출물과 다시 센다. 학생 사례는 허구/시연을 쓰고 식별 기록을 가져오지 않는다.
