## 스티치와 실물 수정

- 사용자 승인에 따라 기존 Higgsfield의 GPT Image 2.5 Sunburst, xhigh, 2k로 **사업명 3종 + 소품 3종 = 6개 자산**을 생성했다. 실제 응답의 `job_type=gpt_image_2_5`, `params.model=sunburst`를 기록했다.
- SYNK는 기존 양모 원본을 무손실 변환했다. 실제 사용 WebP와 원본의 크기·알파·보이는 RGB 차이 0픽셀을 확인했다. LAB·SHIFT·PULSE는 평면 글자+밑줄 대신 글자 자체의 펠트·실땀이다.
- 봉투의 파인 윗선, 책의 지워진 윗페이지, 가위의 사라진 밝은 칼날을 복구했다. 세 소품 모두 Paper/Ink 합성에서 온전한 윤곽·몸체를 확인했다.
- 소개서 사진 안의 평면 로고도 교체한 파생 스냅샷 5장을 만들었다. 원본 HTML 파일·로고 외 본문은 불변이며 전사 공식 소개서 원본은 덮어쓰지 않았다.
- 재사용할 조합 로고 PNG 4종, 개별 배치용 WebP, 생성 PNG 6개와 제작 지시를 `_개선/`에 보관한다. 새 사업명은 이번 납품의 적용 후보이며 전사 공식 로고 신규 승인으로 표시하지 않는다.
- 조합 로고도 Paper/Ink 배경에서 확인했다. 어두운 SYNK 원형을 유지하므로 기본 배치는 Paper이며, Ink 배경용이라고 임의로 밝게 칠하지 않았다.
- 상세 판단과 출처는 [`스티치_적용기록.md`](../_개선/스티치_적용기록.md), 픽셀/알파 대조는 [`스티치_자산검증.json`](스티치_자산검증.json), 소개서 불변 대조는 [`지면 검증`](../_개선/지면스냅샷/검증.json)에 있다.
- 남아 있는 이전 `assets/pulsepage.webp`는 Windows 파일 잠금 때문에 보존했다. 현재 지면과 명세는 `pulsepage-r2.webp`를 사용하며, 최종 ZIP에는 사용 명세에 있는 현재 자산만 넣는다.

Windows tar의 한글 ZIP 항목명이 로컬 문자 인코딩으로 저장되어 휴대성이 떨어지는 문제를 확인했다. .NET 압축 도우미는 PowerShell 스크립트 실행 정책에 막혀 실행되지 않았다. 정책을 변경하지 않고 기존 Python 표준 ZIP 라이브러리로 최종 압축을 생성한다. 실행되지 않은 임시 PowerShell 도우미 소스는 제거하고 Python 도우미를 남겼다.

## 언어·사실·권리

몽골어 자연스러움은 기존 Antigravity 구독의 Gemini 3.1 Pro High로 71개 위치를 검토하여 지적 0개였다. 이후 수정은 한국어에 한정됐고, 검토한 몽골어 71개는 그대로임을 대조했다. [몽골어_검토.md](몽골어_검토.md)에 입력·응답 해시와 범위를 기록했다.

별도의 한몽 의미 대조 모델 전송은 권한 심사에서 거절되어 사용자의 전송 승인 대기다. 같은 자료를 다른 통로로 보내 우회하지 않았다. 로컬 독립 의미 검토를 수행했고, 발견된 14번 한국어 범위 차이를 수정했다. **사람 원어민 감수 완료와 동일한 결과로 보지 않는다.**

실제 고객 성과·학생 후기·합격·비자·판매 강사 풀·대학 협약을 만들어 넣지 않았다. 비교표와 인수표는 빈 양식·설계 예시다. 미성년자의 학교·주소·연락처·사진·음성을 모으는 CTA가 없다. 기존 원본과 새 GPT Image 2.5 연출 자산을 구분한다. 기존 보유 크레딧을 사용했으며 신규 구매·구독·자동충전은 하지 않았다. 음악은 기존 자체 생성 도구로 만든 연주이며 외부 곡·방송 발췌·가짜 유호 음성은 사용하지 않았다.

## 제작 완료와 구별할 남은 범위

1. 오늘의 계정 로그인·게시 가능 여부는 실사하지 않았다. 13개는 저장소 기록이며 Threads 2개와 SYNK Instagram은 준비용이다.
2. 실제 SNS 게시·기기별 재압축·사용자 반응은 확인하지 않았다. 04·07 원작 공개 뒤 해당 파생을 공개해야 문안의 원작 안내가 성립한다.
3. 영상 전체 240초의 실시간 시청과 사람의 실제 청취는 수행하지 않았다. 프레임 시각 검사·음량 수치·오디오 트랙·무음 재생 확인과 구분한다.
4. 추가 한몽 의미 모델 검토는 승인 대기, 사람 원어민 감수는 별도다. 광고 발행 전 조건은 마케팅 정본을 따른다.
5. 로컬 제작물만 완성했다. 원격 저장소 push와 외부 게시를 하지 않았으며, 앞서 거절된 마케팅 원격 공개를 다른 승인 범위로 우회하지 않았다.

## 설계 반영

forge의 A/B안을 독립 사실 검토 후 합쳤다. LAB은 자기 취향·팀 역할·일정을 말하는 언어, SHIFT는 실제 완성 지면과 사용 가능한 업무 양식, PULSE는 감상 자체, SYNK는 교육과 감상의 완성물을 제공한다. 각 계정에 ‘제공물·타겟·명품 기준 적용’을 명시했다. Loom의 선택형 스킨으로 줄바꿈·여백·입력할 공간·실물 배치를 다듬었고, 기존 공용 스킨·승인 원본은 바꾸지 않았다.
