## 최종 원고와 파일

- 원고 SHA-256: `416403fba084500d2d0fa806a343f80ad223dd021318c4c910f40043afcbfcd3`.
- 영상: 1080×1920, 30fps, H.264/AAC 7편. 계획 길이 합계 240초. 컨테이너 길이의 편당 약 0.04~0.06초 차이는 검증 허용 오차 안이다.
- 이미지: 게시용 JPG 26장(1080×1350) + 편집·고해상도 PNG 26장(2160×2700). 같은 지면의 두 출력이므로 독립 콘텐츠 52장으로 세지 않는다.
- 영상 7개와 이미지 출력 52개, 총 59개 납품 미디어의 크기·해시는 [납품_QA.json](납품_QA.json)에 있다.
- SRT 7개는 화면 문구의 시간표다. 말 없는 PULSE의 파일은 무대사 안내이며 학습 자막을 얹지 않았다.
- 전체 꾸러미와 계정별 ZIP 16개를 제공한다. 압축 파일은 UTF-8 이름으로 만들고 모든 항목을 다시 열어 원본 SHA-256과 비교한다. ZIP 자신의 검증 보고서를 자신 안에 넣는 순환을 피하기 위해 최종 `압축검증.json`과 중간 `압축계획.json`은 전체 ZIP 밖의 이 `_검토` 폴더에 둔다.

## 언어·사실·권리

몽골어 자연스러움은 기존 Antigravity 구독의 Gemini 3.1 Pro High로 71개 위치를 검토하여 지적 0개였다. 이후 수정은 한국어에 한정됐고, 검토한 몽골어 71개는 그대로임을 대조했다. [몽골어_검토.md](몽골어_검토.md)에 입력·응답 해시와 범위를 기록했다.

별도의 한몽 의미 대조 모델 전송은 권한 심사에서 거절되어 사용자의 전송 승인 대기다. 같은 자료를 다른 통로로 보내 우회하지 않았다. 로컬 독립 의미 검토를 수행했고, 발견된 14번 한국어 범위 차이를 수정했다. **사람 원어민 감수 완료와 동일한 결과로 보지 않는다.**

실제 고객 성과·학생 후기·합격·비자·판매 강사 풀·대학 협약을 만들어 넣지 않았다. 비교표와 인수표는 빈 양식·설계 예시다. 미성년자의 학교·주소·연락처·사진·음성을 모으는 CTA가 없다. 승인된 소개서 지면과 소품을 사용했고 새 이미지 생성이나 신규 지출은 없었다. 음악은 기존 자체 생성 도구로 만든 연주이며 외부 곡·방송 발췌·가짜 유호 음성은 사용하지 않았다.

## 제작 완료와 구별할 남은 범위

1. 오늘의 계정 로그인·게시 가능 여부는 실사하지 않았다. 13개는 저장소 기록이며 Threads 2개와 SYNK Instagram은 준비용이다.
2. 실제 SNS 게시·기기별 재압축·사용자 반응은 확인하지 않았다. 04·07 원작 공개 뒤 해당 파생을 공개해야 문안의 원작 안내가 성립한다.
3. 영상 전체 240초의 실시간 시청과 사람의 실제 청취는 수행하지 않았다. 프레임 시각 검사·음량 수치·오디오 트랙·무음 재생 확인과 구분한다.
4. 추가 한몽 의미 모델 검토는 승인 대기, 사람 원어민 감수는 별도다. 광고 발행 전 조건은 마케팅 정본을 따른다.
5. 로컬 제작물만 완성했다. 원격 저장소 push와 외부 게시를 하지 않았으며, 앞서 거절된 마케팅 원격 공개를 다른 승인 범위로 우회하지 않았다.

## 설계 반영

forge의 A/B안을 독립 사실 검토 후 합쳤다. LAB은 자기 취향·팀 역할·일정을 말하는 언어, SHIFT는 실제 완성 지면과 사용 가능한 업무 양식, PULSE는 감상 자체, SYNK는 교육과 감상의 완성물을 제공한다. 각 계정에 ‘제공물·타겟·명품 기준 적용’을 명시했다. Loom의 선택형 스킨으로 줄바꿈·여백·입력할 공간·실물 배치를 다듬었고, 기존 공용 스킨·승인 원본은 바꾸지 않았다.
