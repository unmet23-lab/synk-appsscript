# SYNK 계정별 콘텐츠 · 2026.09.09

계정별로 하나씩 쓸 콘텐츠 파일을 모은 컬렉션입니다. **기록상 개설된 13곳 + 개별 프로필 확인 전 준비용 3곳 = 16개 패키지**입니다. 실제 게시하거나 계정을 변경하지 않았습니다.

## 먼저 열기

`index.html`을 열면 브랜드별로 고르고 카드 전량·영상·게시 문안을 볼 수 있습니다. 전체 ZIP을 받았다면 **압축을 모두 푼 뒤** index.html을 여세요. 특정 계정만 필요하면 `packages/계정ID.zip`을 사용합니다.

- `video.mp4`: 완성 세로 영상. 1080×1920, 30fps, H.264, 오디오 포함.
- `upload-01.jpg`부터: 실제 게시용 이미지. 1080×1350, 번호순. 영상 패키지에서는 표지입니다.
- `master-01.png`부터: 2160×2700 고해상도 이미지. 모든 원본이 4K라는 뜻은 아닙니다.
- `게시문안.txt`: 복사할 본문. 학습·실무 자료는 설명글 안에서도 완결됩니다.
- `제목.txt`, `대체텍스트.txt`: 제목과 접근성을 위한 이미지 설명.
- `자막.srt`: 화면 문구의 시간표. 음성 받아쓰기가 아닙니다. PULSE 감상물은 말이 없어 교육 자막을 넣지 않습니다.
- `본문.md`: Substack 창업 섹션의 편지 전문.
- `cards.html`, `collection.css`, `콘텐츠원고.json`: 다시 편집할 지면·스킨·원고. 재생성 스크립트는 SYNK 저장소 안에서 실행합니다.

플랫폼에서 대표 표지를 고르는 방식은 서로 다릅니다. 유튜브 Shorts에 외부 표지를 그대로 업로드할 수 있다고 보장하지 않습니다. 표지는 디자인 원판으로 제공하며 게시 화면에서 지원하는 대표 프레임을 선택합니다.

## 브랜드와 명품 기준을 적용한 방식

마케팅 정본의 타겟별 역할을 실제 제공물로 옮겼습니다. A안의 계정·타겟 정확성과 B안의 완성물·감상 중심 구성을 forge로 비교하고, 독립 사실 검토 뒤 하나로 합쳤습니다.

- **LAB:** 한국을 동경하는 말만 반복하지 않고, 몽골의 자기 취향을 소개하고 팀에 기여하고 자기 일정을 고르는 장면을 제공합니다. 청소년에게 공개 댓글·학교·주소·음성 제출을 요구하지 않습니다.
- **SHIFT:** ‘신뢰할 만하다’고 자칭하는 대신 완성 지면, 입력 가능한 비교표, 인수 기준을 내놓습니다. 개인 기록·실무 정보·기관 협력의 역할을 나눕니다.
- **PULSE:** 등록 안내나 문제를 얹지 않고, 장면과 음악 자체로 끝냅니다. 현재 방송의 발췌가 아닌 이 컬렉션을 위해 만든 짧은 작품입니다.
- **SYNK 본체:** 조직도나 로고 모음을 늘어놓지 않고, 이미 만든 교육 지면과 감상 장면의 쓰임을 보여줍니다.

시각 기준은 `DESIGN.md`와 Loom입니다. 브랜드 색은 토큰에서, 본문 글자는 SUIT·Inter Tight에서 가져왔습니다. SYNK 워드마크는 승인 양모 원본이며, 사업명 3종은 기존 글자·색과 사용자 요청을 바탕으로 만든 스티치 적용안입니다. 정적 스킨은 공용 `Loom.계정컬렉션()`의 명시 호출에만 적용하며 기존 지면의 기본 스킨을 바꾸지 않았습니다. 화면 세부 완성도 스킬을 적용해 줄바꿈·여백·작성 공간·키보드 초점·모바일 버튼 크기를 점검했습니다.

보유 자산을 선별해 사용했습니다. 실제 4K급 원본과 2048px 원본을 구분하며, `사용자산.json`에 출처·치수·해시를 적었습니다. 첫 납품 후 사용자가 지적한 봉투 누끼의 파임과 평면 로고를 다시 검토했습니다. 사용자 승인에 따라 기존 Higgsfield의 **GPT Image 2.5 Sunburst**로 봉투·책·가위 3종과 LAB·SHIFT·PULSE 사업명 글자 3종을 제작했습니다. SYNK는 기존 양모 스티치 원본의 보이는 픽셀을 그대로 사용합니다. 생성 원본·제작 지시·내보내기 명세는 `_개선/`에 있습니다. 신규 구매·구독·자동충전은 하지 않았으며 보유 크레딧을 사용했습니다. 새 사업명은 이번 납품에 적용한 물성 후보이지 전사 공식 로고 정본을 덮어쓴 결과가 아닙니다.

소개서 사진 안에도 옛 평면 로고가 남지 않도록, 원본 HTML의 본문과 시설·준비 상태 안내를 유지하면서 로고만 교체한 3840×2400 파생 지면을 사용합니다. 기존 소개서 원본 폴더는 보존합니다. 세부 변경·검수 범위는 `_개선/스티치_적용기록.md`에서 구분합니다.

## 재사용과 제공 범위

개인 TikTok은 04 제작기의 파생, 정보 TikTok은 07 인수 원작의 파생입니다. 개인 Instagram도 동일 실제 제작 기록에서 구체적인 편집 선택을 꺼낸 Reel입니다. **16개 계정용 패키지가 16개 독립 영상 원작이라는 뜻은 아닙니다.** 기존 장편 본편 운영 계획을 Shorts 계획으로 바꾸지 않습니다.

04와 07을 먼저 공개하고 해당 파생을 공개하면 문안의 원작 안내가 맞습니다. 첫 Substack 발송은 기존 창업 섹션 운영 조건·실제 수신 대상을 확인한 뒤 진행합니다. 이번에는 게시·발송·자동화·새 계정 개설을 하지 않았습니다.

실제 학생 성과·고객 실적·협약 대학·판매 중인 강사 풀을 만들어 넣지 않았습니다. 대학·인수 도구는 **설계 예시와 빈 양식**입니다. 권리·계약·입학 자격·비자 판단을 대신하지 않습니다. 연출 이미지와 실제 완성 소개서의 화면을 실제 시설·학생 사진으로 부르지 않습니다.

## 확인 범위

정적 지면의 26장 경계·이미지 읽기·서체 로딩, 영상의 실제 파일·길이·해상도·오디오 트랙, 게시 문안과 원고 대응을 검사합니다. 최종 수치와 남은 한계는 `_검토/최종검증.md`가 기준입니다. 기계 검사와 눈으로 본 검사, 소리의 수치 검사와 실제 청취를 섞지 않습니다.

**몽골어 사람 원어민 감수 완료를 주장하지 않습니다.** 몽골어 자연스러움은 기존 Antigravity 구독의 Gemini 3.1 Pro High에서 71개 위치 전량 검토, 지적 0개로 완료됐습니다. 별도로 요청한 한몽 의미 대조 전송은 권한 심사에서 막혀 승인 대기입니다. 로컬 독립 의미 검토에서 찾은 ‘약속/다른 일정’의 범위 차이는 한국어를 수정해 맞췄고, 기존 몽골어 문구는 그대로 유지했습니다. 정확한 범위와 해시는 `_검토/몽골어_검토.md`에 있습니다. 광고 발행 전의 추가 감수 조건은 마케팅 정본을 따릅니다.

실제 SNS 업로드 화면, 모바일 기기별 색, 플랫폼 재압축 후 픽셀, 소비자 반응은 확인하지 않았습니다. 게시 성과·매출·학습 효과의 검증 결과물이 아닙니다.

## 다시 만들기

저장소 루트에서, 기존 Node 환경의 `sharp`·`playwright`와 Chrome을 사용합니다. Codex 번들 패키지를 쓰는 환경은 해당 런타임의 `node_modules`를 `NODE_PATH`로 지정합니다. 문구나 자산을 바꾸면 검토와 렌더를 다시 합니다.

1. `콘텐츠원고.json`을 편집합니다.
2. `node docs/홍보물/계정별콘텐츠_20260909/만들기.cjs --render`
3. 최초 자산 준비는 `node 영상/계정별굽기.cjs --prepare`, 특정 영상 재출력은 `node 영상/계정별굽기.cjs --render --id 03-lab-tiktok`처럼 지정합니다. 변경 없는 출력 재사용은 `--render --resume`, 기존 파일 검사는 `--verify`입니다.
4. `node --test tests/계정컬렉션.test.js tests/브랜드값.test.js tests/브랜드폰트.test.js`
5. `node docs/홍보물/계정별콘텐츠_20260909/검증.cjs`
6. `node docs/홍보물/계정별콘텐츠_20260909/묶기.cjs`

공용 영상 Root·진행 중 릴10편·기업소개20초·기존 소개서 원본은 변경하지 않습니다. 기존 전체 영상 파이프라인을 이 파일 때문에 무작정 재실행하지 않습니다.

제작 판형 대조: 이번 YouTube 파일은 세로 60초 이내로 [YouTube의 Shorts 분류 안내](https://support.google.com/youtube/answer/15424877?hl=en) 범위 안입니다. 준비용 Threads 원고는 [Meta의 기본 게시물 안내](https://about.fb.com/news/2023/07/introducing-threads-new-app-text-sharing/)에 있는 500자 이내로 작성했습니다. 실제 게시 UI와 계정별 기능 실사를 대신하지는 않습니다.
