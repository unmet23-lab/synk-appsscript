# 스티치와 실물 마감 · 2026-09-09 수정판

이번 수정의 기준은 사용자가 지적한 ‘로고 글자 자체의 스티치’와 ‘온전한 사진 디테일’이다. 기존 마케팅 타겟·게시 문안은 유지하며, 최초 납품의 시각 검토가 봉투의 원천 알파 손상을 놓쳤음을 인정하고 해당 검수 결과를 최신 결과로 대체한다.

## 실제 모델과 보존한 원본

사용자가 기존 Higgsfield 구독의 GPT 2.5 사용을 명시 승인했다. 실제 실행은 `gpt_image_2_5`, `sunburst`, `xhigh`, `2k`, 투명 배경이다. 내장 이미지 도구를 2.5라고 추정해 부른 것이 아니다. 신규 구매·구독·자동충전은 하지 않는다.

| 대상 | 처리 | 생성 작업 ID |
|---|---|---|
| SYNK | 기존 `양모워드마크_누끼.png`를 무손실 WebP로 내보냄. 보이는 RGBA 픽셀 일치 검사. | 새 생성 아님 |
| LAB | 따뜻한 코랄 펠트 몸체 + 글자 둘레 실땀. 기존 대문자 참고. | `2f43b687-7d88-4b69-86d0-c4a63950ec53` |
| SHIFT | 깊은 파랑 펠트 + 단정한 실땀·기준선. 기존 대문자 참고. | `6c102828-b73e-45b1-b20a-a1b8ac6c6d4e` |
| PULSE | 베리색 펠트 + 부드러운 모서리·차분한 실땀. 기존 대문자 참고. | `f4b7ab78-4f76-4962-b557-30aa7b6a2779` |
| 봉투 | 파인 윗윤곽·몸체 구멍을 복구한 같은 역할의 크림 펠트 봉투. | `e2a24178-db0f-41f2-b117-809245656369` |
| 책 | 지워진 윗페이지와 코랄 표지를 온전하게 복구한 펼친 펠트 책. | `00c56b25-23fe-4ce6-bd49-1544aaa3a471` |
| 가위 | 온전한 기존 사진을 참조하여 두 금속 칼날을 보존한 투명판. | `84ebed23-c82c-4df1-82ad-e7dbe939b8a2` |

실제 생성 설정·해시·해상도는 [자산 생성 명세](자산_생성명세.json), 제작 지시는 이 폴더의 `*-제작지시.txt`, 무수정 생성 원본은 `*-2.5.png`에 있다. 사업명은 기존 형태를 참조한 물성 적용 결과이지, 원본 서체의 수학적으로 동일한 윤곽이나 전사 공식 로고 신규 승인을 뜻하지 않는다. 회사별 지정색을 참조했지만 사진의 빛·섬유에 따라 픽셀 색은 달라진다.

`배치용/`은 SYNK·사업명 개별 투명 WebP, `조합로고/`는 바로 가져다 놓을 수 있는 4종 투명 PNG다. 조합 PNG는 검수한 이미지를 비율 유지 축소·광학 정렬한 것으로 다시 생성하거나 색칠하지 않았다. 원본까지 함께 보관하므로 다른 크기에서도 기존 픽셀을 기준으로 다시 조합할 수 있다.

## 선택한 마감 방향

forge A/B를 나누어 검토했다. A는 기존 문구와 원본을 보존하면서 실제 크기의 스티치·광학 정렬·누끼 수정을 우선한다. B는 같은 원본 기준 위에서 문서 전체를 작게만 보이지 않고 실제 읽는 부위의 확대와 내용에 연결된 소품 배치를 제안했다. 로고 방향은 두 안이 수렴했으므로 별개 로고 시안 두 벌을 만들었다고 세지 않는다.

| 고정 판단 기준 | A | B |
|---|---|---|
| 요청 부합 | 5/5 · 실물 스티치와 원본 결함에 직접 대응 | 5/5 · 같은 대응에 읽는 장면 개선을 더함 |
| 브랜드·철학 | 5/5 · 원본·문구·회사별 색 보존 | 5/5 · 실제 제공물과 쓰는 동작을 강조 |
| 완성도·디테일 | 4/5 · 손상·정렬은 해결하나 영상의 작은 문서 반복은 남음 | 5/5 · 문서 확대와 물체 배치가 정보를 돕는 방향 |

이는 편집 판단 점수이며 고객 효과를 측정한 수치가 아니다. 독립 검토에서 사실·법적 위험에 관한 두 안의 하드 게이트를 통과했다. A의 원본 보존과 B의 읽는 장면 개선을 합쳤다. 새 주장·추가 사례·새 문구는 넣지 않는다. 실제 문서 부분을 확대할 때도 서비스 준비 상태나 필요한 조건을 지워 다른 사실처럼 보이게 만들지 않는다.

## 재사용할 배치 원칙

- SYNK와 사업명을 따로 만든 이미지로 유지하고 원비율을 지킨다. `synk`의 길게 올라간 k·내려간 y 대신 s/n 몸통과 사업명의 중심을 맞춘다.
- 사업명마다 캔버스 여백이 다르므로 같은 이미지 높이가 아니라 **실제 글자 높이**를 맞춘다. 내보내기는 보이는 윤곽 바깥에 24px를 남기며, 글자 내부의 알파값이나 색을 지우지 않는다.
- 기존 밑줄 실 조각은 스티치 로고를 대신하지 않는다. 작은 지면에서도 평면 글자로 바꾸지 않고, 실땀이 보일 크기와 여백부터 확보한다.
- 본문은 기존 SUIT·Inter Tight 활자로 남긴다. 본문 전체를 이미지 모델에 맡겨 오탈자·몽골어 자모·수정 가능성을 잃지 않는다.
- 소개서 안의 로고도 같은 스티치로 보이도록 **이번 컬렉션의 파생 스냅샷만** 교체한다. [지면 검증](지면스냅샷/검증.json)은 원래 HTML 파일과 로고 외 본문이 불변임을 대조한다.
- PULSE 01번은 작품의 고요함을 유지한다. 표지에는 스티치 로고를 쓰고 감상 본편에는 교육·영업 문구를 얹지 않는다.

## 원천부터 납품까지의 검수

파일 존재·픽셀 크기·알파 채널 유무만으로 통과시키지 않는다. 투명뷰, Paper와 Ink 바탕, 실제 카드, 인코딩된 영상 프레임을 구분해 확인한다. 밝은 재료를 배경으로 오인해 지우는 누끼는 재사용하지 않는다.

봉투는 이전 `_누끼.png`가 상단과 몸체를 지웠고, 책은 윗페이지, 가위는 밝은 칼날이 같은 방식으로 손상됐다. 새 생성 결과의 투명뷰에 보이는 RGB 번짐은 실제 알파 합성에서 다시 판단한다. Paper·Ink에서 광륜이나 칼날의 투명화가 보이지 않아야 한다. 미세한 섬유와 대형 파임을 같은 ‘수공예 느낌’으로 취급하지 않는다.

최신 납품 검사 결과는 [최종검증](../_검토/최종검증.md)을 따른다. 이전에 작성한 독립 검토 기록은 과거 검사 근거로 보존하되 새 수정판의 완료 증거로 대신하지 않는다. 외부 게시·원격 push·몽골어 추가 외부 전송은 이번 이미지 생성 승인에 포함되지 않으며 수행하지 않는다.
