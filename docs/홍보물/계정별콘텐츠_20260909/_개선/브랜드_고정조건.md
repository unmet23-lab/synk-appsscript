# 스티치·실물 마감 개선의 고정 조건

2026-09-09 사용자 수정 지시가 옛 '작은 로고는 민판'보다 우선한다. 이번은 새로운 정체성 제작이 아니라 기존 로고와 사업명에 요청된 물성을 적용하는 확장이다.

| 항목 | 상태·근거 | 적용 |
|---|---|---|
| SYNK 철자/글자 | fixed · 사용자 지시/기존 원본 | 대외 `synk`. 양모워드마크_누끼.png의 기존 스티치 원본을 그대로 배치. 새 생성으로 글자 윤곽을 갈지 않는다. |

금지: 잘린 실루엣·가짜 투명 체크무늬·불필요한 양각·금박·왕관·진짜 수공예 제작 기록으로 가장하기·신규 학생/고객 사례·원본 전체의 임의 재염색. 생성 결과는 납품용 적용 후보이며 사용자 검토 전 전사 공식 로고 정본을 덮어쓰지 않는다.

생성 경로는 사용자 명시 승인에 따라 기존 Higgsfield의 GPT Image 2.5 Sunburst다. 신규 구매/자동충전은 하지 않는다. 모델 이름·설정·실제 결과를 실행 기록으로 구별한다.
