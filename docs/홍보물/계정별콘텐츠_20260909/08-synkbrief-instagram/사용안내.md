# Instagram · @synkbrief

대학을 비교할 때, 빈칸부터

- 형식: 캐러셀
- 상태: 개설 기록 있음 · 오늘 로그인/발행 기능 실사 아님
- 원작: 이번 컬렉션 원작
- 받을 사람: 한국 유학 선택지를 정리하는 학생·가족·교육 담당자
- 가져갈 것: 학교 순위를 대신하지 않고 자기 조건·원문·미확인을 구분하는 비교표
- 명품 기준의 적용: 대학 로고와 순위 대신 빈칸을 제공한다. 정보를 채우지 못한 자리를 감추지 않고 실제 선택의 기준으로 남긴다.
- 파일: 번호순 upload-01.jpg부터 사용. 게시문안.txt는 제목/내부 안내를 섞지 않은 복사 본문.
- 고해상도: master-XX.png = 2160×2700. 업로드용: upload-XX.jpg = 1080×1350. 원본 자산의 실제 해상도는 전체 꾸러미의 사용자산.json 참조.
- 언어: 한국어 원고. 청중 반응/사업 성과는 측정하지 않음.
- 외부 게시·계정 수정·광고비 집행 없음.
