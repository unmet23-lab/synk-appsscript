# Threads · @synkbrief

인수할 때 함께 건넬 세 줄

- 형식: 글 + 이미지
- 상태: 준비용 · 개별 프로필/개설 확인 전
- 원작: `07-synkbrief-youtube`에서 파생
- 받을 사람: 업무 결과물을 주고받는 실무자
- 가져갈 것: 본문을 그대로 복사해 쓸 수 있는 인수 메모
- 명품 기준의 적용: 지식을 설명하는 글이 아니라 실제로 채워 쓰는 세 줄을 준다. 개인정보 제출이나 다운로드 동선 없이 끝낸다.
- 파일: 번호순 upload-01.jpg부터 사용. 게시문안.txt는 제목/내부 안내를 섞지 않은 복사 본문.
- 고해상도: master-XX.png = 2160×2700. 업로드용: upload-XX.jpg = 1080×1350. 원본 자산의 실제 해상도는 전체 꾸러미의 사용자산.json 참조.
- 언어: 한국어 원고. 청중 반응/사업 성과는 측정하지 않음.
- 외부 게시·계정 수정·광고비 집행 없음.
