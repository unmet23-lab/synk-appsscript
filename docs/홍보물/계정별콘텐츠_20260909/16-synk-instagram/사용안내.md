# Instagram · SYNK Instagram · 희망 @synk.im / 대안 @synkim

같은 결, 다른 시간

- 형식: 이미지
- 상태: 준비용 · 개별 프로필/개설 확인 전
- 원작: 이번 컬렉션 원작
- 받을 사람: SYNK의 교육·작품이 어떤 관계인지 확인하려는 협업 상대와 브랜드 관심자
- 가져갈 것: 같은 표현 문법이 다른 사람의 시간에 맞게 쓰이는 이유
- 명품 기준의 적용: 교육면과 밤 장면 두 벌만 나란히 둔다. 모든 사업·엔진을 한 장에서 설명하지 않고 서로 다른 쓰임을 보인다.
- 파일: 번호순 upload-01.jpg부터 사용. 게시문안.txt는 제목/내부 안내를 섞지 않은 복사 본문.
- 고해상도: master-XX.png = 2160×2700. 업로드용: upload-XX.jpg = 1080×1350. 원본 자산의 실제 해상도는 전체 꾸러미의 사용자산.json 참조.
- 언어: 한국어 원고. 청중 반응/사업 성과는 측정하지 않음.
- 외부 게시·계정 수정·광고비 집행 없음.
