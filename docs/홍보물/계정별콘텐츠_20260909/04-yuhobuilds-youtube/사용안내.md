# YouTube · @yuhobuilds

이 소개서는 무엇부터 읽어야 할까요

- 형식: 영상
- 상태: 개설 기록 있음 · 오늘 로그인/발행 기능 실사 아님
- 원작: 이번 컬렉션 원작
- 받을 사람: AI로 사업 자료를 직접 만들거나 제작을 맡기는 실무자
- 가져갈 것: 제목·설명·실물의 읽는 순서를 자기 자료에 적용하는 방법
- 명품 기준의 적용: 완성한 지면 자체를 증거로 쓴다. 장식이나 도구 화면이 아니라 실제 읽을 크기와 정보의 순서를 보여준다.
- 파일: video.mp4를 업로드, 카드 이미지는 표지. 게시문안.txt는 제목/내부 안내를 섞지 않은 복사 본문.
- 고해상도: master-XX.png = 2160×2700. 업로드용: upload-XX.jpg = 1080×1350. 원본 자산의 실제 해상도는 전체 꾸러미의 사용자산.json 참조.
- 언어: 한국어 원고. 청중 반응/사업 성과는 측정하지 않음.
- 외부 게시·계정 수정·광고비 집행 없음.
