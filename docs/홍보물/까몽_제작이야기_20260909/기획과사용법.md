# 까몽 제작 이야기 — 전체 마케팅 적용

2026-09-09 · 전략 반영·한국어 원고·텍스트 점검표 준비. 새 영상·카드 이미지 제작, 몽골어 발행본, SNS 게시·성과 검증은 이번 완료 범위가 아니다.

## 무엇을 왜 보여주는가

**까몽을 3D로 만들어 놓고 앱에는 넣지 않은 이유를 보여준다.** 생성 도구를 많이 쓴 이야기가 아니라, 만든 것을 어디에 쓸지 실제로 판단한 이야기다. 주 대상은 SHIFT의 AI 학습자·제작 실무자와 제작을 맡기려는 사람이다. 독자는 자기 결과물에 적용할 세 질문을 얻는다.

원래 까몽은 승인된 2D 캐릭터다. 이번 3D 후보는 그 그림의 고개 돌림에 쓸 깊이 정보를 빌릴 수 있는지 시험한 대상이다. 꼬리 잘림은 고쳤지만 눈 간격 차이와 깊이 표본의 빈자리가 남았고, 같은 움직임 계산에서 기존보다 덜 찌그러진다는 근거를 얻지 못했다. **현 후보는 비채택으로 시험을 닫았고 기존 2D·깊이·앱·옷 자산은 그대로다.**

끝난 실험도 마케팅 소재가 될 수 있다. 다만 ‘엄격한 회사라 믿으라’고 결론을 대신 주지 않는다. 실물·비교 조건·선택 이유·사용 범위를 보여주고 독자가 판단하게 한다.

## 지금 어디에 쓸 수 있나

| 용도 | 구체적으로 남는 것 | 이번 상태 |
|---|---|---|
| 제작 과정 설명 | 원본과 실험 후보, 비교 결과, 비채택 이유 | 자료·한국어 원고 준비. 공개 편집·게시 전 |
| 다음 3D 제작자에게 참고 | 지킬 원본과 이번 후보에서 달라진 부분 | 내부 비교 화면·계측 보고 존재. 완성 모델 납품이나 재사용 권리 보장이 아님 |
| 구도·조명 시안 | 캐릭터가 있을 자리·빛 방향을 시험할 임시 모델 | 가능한 후속 활용. 별도 장면을 이번에 제작·확인한 것은 아님 |
| 앱·학습 콘텐츠·의상 실사용 | 기존 승인 2D 자산과 현행 제작 흐름 | 유지. 이번 3D로 교체하거나 옷 품질을 개선한 일이 아님 |

## 전체 마케팅 안의 위치

전략 정본은 [마케팅 정본 §4](../../마케팅/SHIFT.md#4-3-a-제작-이야기--만든-것과-선택한-이유를-함께-제공한다). 새 채널이나 고정 연재를 만들지 않고 기존 ‘한 일을 끝내는 방법’의 첫 제작 실험 사례로 넣는다.

- **yuhobuilds:** 원본 → 실험 후보 → 실제 비교 → 선택 이유. 기존 본편의 소재 후보이며 이 주제로 장편 한 편을 반드시 추가한다는 뜻은 아니다.
- **synkbrief:** 같은 사례에서 ‘형태·동작·적용 상태’ 세 질문을 뽑는다. 캡션 자체가 제공물이므로 댓글·DM·연락처를 요구하지 않는다.
- **SYNK 본체:** 월간 완료 기록의 한 후보. ‘새 3D 출시’ 대신 ‘시험을 끝내고 기존 까몽을 유지한 결정’으로 요약한다. 본체 계정 확보·개설은 이 작업에서 확인하지 않았다.
- **LAB:** 도움 제공형 릴 10편을 그대로 둔다. 필요할 때 기존 까몽을 유지한 이유를 학생에게 쉽게 설명하되, 기술 제작담이 한국어 표현·자료를 밀어내지 않는다.
- **PULSE:** 제작·비교 자료를 남기는 역할이다. 라디오·음악 감상에 기술 해설을 의무 편성하지 않는다.

후속 소재는 ‘45편 대신 도움 제공형 10편으로 정한 이유’, ‘번역을 장면·의도에서 시작하는 이유’다. 아직 다음 제작 순서·수량·날짜는 정하지 않았다. 이미 끝낸 작업의 실제 증거가 있을 때만 기존 발행 후보에 넣는다.

## 편집할 때의 흐름

1. **사건:** ‘SYNK는 까몽을 3D로 만들어 봤습니다. 앱에는 넣지 않았습니다.’ 원본/실험 후보를 분명히 표시한다.
2. **목적:** 원본 그림을 유지하면서 고개 돌림에 필요한 깊이를 빌릴 수 있을지 알아봤다고 설명한다.
3. **비교:** 잘림이 없는 최종 출력과 원본을 비교한다. 눈 간격과 움직임의 차이를 보여준다. 초기 잘린 출력과 최종 출력을 섞지 않는다.
4. **판단:** 이 후보를 채택하지 않았으며 앱·옷은 바꾸지 않았다고 말한다. 실험 완료와 실사용 완료를 가른다.
5. **제공:** [세 질문 점검표](제공자료_결과물점검표.md)를 글 안에 모두 싣는다. 독자는 자기 결과물에 써보거나 그냥 읽고 나가도 된다.

영상은 이 원고를 바탕으로 추후 편집할 수 있다. 현재 렌더·음성·자막 파일은 새로 만들지 않았다. 인물이 필요한 편집을 한다면 유호의 실제 촬영·실제 발언을 확인하며, 원고를 실제 인터뷰 인용으로 포장하지 않는다. 까몽에게 기술 보고를 말시키거나 음성 대사를 붙이지 않는다.

바깥선 겹침 **IoU 95.4813%**는 두 영역의 교집합을 합집합으로 나눈 값이며 **완성도·정확도·학습 효과 점수가 아니다.** 숫자가 꼭 필요한 설명에서만 비교 방법과 함께 쓴다. 표지에는 숫자보다 실제 사건을 둔다. 깊이 52/246점 미커버에는 털 제외·외곽 불일치도 포함되어 ‘몸이 21% 틀렸다’고 말하지 않는다. 기존보다 개선됐다는 증거가 없다는 판단을 ‘모든 3D는 쓸모없다’로 확대하지 않는다.

이번 시연은 앱과 같은 계산을 별도 브라우저에 옮긴 비교다. 실제 휴대전화 검증·공개 서비스 적용·고객 효과로 쓰지 않는다. 내부 HTML·소스·로그·계정·학생 자료를 홍보 링크나 배포 묶음에 그대로 넣지 않는다. SNS에는 공개용으로 분리한 그림과 문안만 사용한다. 새 공개 GitHub 반영이나 앱 배포 범위를 이 문서가 넓히지 않는다.

## 언어와 다음 확인

SHIFT 원고는 한국어다. 학생용 몽골어 발행본을 이번에 만든 것이 아니다. LAB에 맞춰 새로 쓸 때는 **장면·의도에서 몽골어 작성 → 몽골어만 읽어 자연스러움 확인 → 다른 검토자의 한몽 의미 대조**를 따른다. 사실·조건·행동 주체·제공 약속은 유지하고, 필요한 인간 원어민 감수와 실제 게시 크기 검토를 별도로 마친다. AI 검토를 사람 원어민 검토라고 표시하지 않는다.

검증된 흥행 포맷·실제 고객 반응을 주장하지 않는다. 이번은 저장소의 기존 SHIFT 편집 체계를 실제 내부 사례에 적용한 기획이며, 새 수요 조사·계정 실사·실사용자 반응 시험은 수행하지 않았다. 다음에 보는 것은 조회수만이 아니라 독자가 시안/시험/적용의 차이를 이해하는지, 세 질문을 자기 작업에 적용하는지다. 반응이 아직 없으므로 수치를 만들지 않는다.
