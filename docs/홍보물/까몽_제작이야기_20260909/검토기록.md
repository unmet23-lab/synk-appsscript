# 까몽 마케팅 반영 — 검토 범위

2026-09-09 · 요청: 까몽 3D의 용도와 설명도 SYNK 전체 마케팅에 포함.

## 독립 접근과 판정

forge를 적용해 서로의 원고를 보지 않은 두 제작자가 제안하고 별도 검토자가 사실·과장·공개 위험을 대조했다.

| 접근 | 핵심 | 하드 게이트 | 목적 / 브랜드 / 디테일 |
|---|---|---|---|
| A | 만든 결과 → 비채택 이유 → 독자 점검표. 수치 훅 없이 비교 조건과 실기기 미검증 명시 | 통과 | 5 / 5 / 4.5 (5점 만점, 편집 판단이며 고객 반응 수치 아님) |
| B | 원본/후보 대조 → ‘만들었지만 안 쓴’ 반전 → 적용 질문. 본문에 약 95.5% 제시 | 현 문안 탈락. ‘95.5%가 맞았다’는 설명이 바깥선 IoU를 단순 일치율로 오독하게 함 | 탈락으로 채점 제외 |

**A 단독 채택.** 수치의 계산 오류를 발견한 것은 아니다. B의 수치 설명을 채택하지 않았고, 원고에서 수치를 빼 독자가 실제 비교와 사용 범위에 집중하도록 했다. A의 ‘대응 표면이 없다’도 ‘털을 제외한 측정에서 일부 비교 지점의 깊이를 얻지 못했다’로 한정했다. 확인하지 않은 모든 3D 방식의 품질을 이번 판정으로 대신하지 않는다.

검토자는 [최종 시험 보고](../../_ops/삼디문지기/깊이시험/검증보고.md) 전문과 [마케팅 정본](../../마케팅_정본.md) §4·6·7, 브랜드·품질 기준, A/B 실제 원문을 대조했다. 주담당은 채널 연결·실제 제공 점검표·한국어 원고·정본 반영을 통합했다. 문안의 한국어 읽힘·필요한 조건·사실 범위를 확인한 것이지 흥행이나 고객 신뢰를 검증한 것이 아니다.

## 스킬이 바꾼 부분

- `synk-brand`: 학생에게 기술 설명을 떠넘기지 않고 LAB의 실제 도움·낮은 언어 난도·높은 사고 수준을 유지했다. 이름·행동은 더 최신인 가이드 정본을 우선하며 옛 몽글 단일 설정으로 까몽을 지우지 않았다.
- `synk-content`: 정보는 캡션만으로도 사용 가능하게, 원고는 지정된 references 경로에 보존했다. 이번은 기존 SHIFT 형식의 내부 사례 적용이며 새 수요·흥행 검증은 하지 않았다. LAB 몽골어 발행본을 생성·감수했다고 세지 않았다.
- `forge`: A/B 독립 생성과 별도 사실 검토 후 A만 채택했다. 수치 훅을 제외한 이유를 위에 남겼다.

## 완료와 남은 단계

완료: 마케팅 정본의 제작 이야기 소재 갈래·채널 역할·실험 자산 경계, 옛 회사별 마케팅에서의 진입 링크, 첫 사례의 기획과 사용법, 한국어 원고, 세 질문 텍스트 제공자료.

파일 확인: 이번 여섯 문서의 새 연결을 대상으로 로컬 링크 21개와 사용한 제목 앵커를 조회해 오류 0개, UTF-8 대체문자 0개를 확인했다. 기존 두 정본의 `git diff --check`도 공백 오류 없이 끝났다. 새 시각 산출물이 없어 영상·브라우저 디자인 검사를 이번 마케팅 문안의 검증으로 세지 않았다.

미수행: 새로운 이미지·영상·음성·자막 렌더, 몽골어 학생용 발행본·인간 원어민 감수, 플랫폼 로그인/계정 감사, 공개 편집본 업로드·SNS 게시·고객 반응 시험. 내부 실험 뷰어를 공개 사이트로 전환하지 않았다. 학생 기록·고객 자료를 쓰지 않았고 앱·옷·기존 릴 10편은 변경하지 않았다. 이 반영으로 앱 배포나 공개 GitHub 반영의 범위를 넓히지 않는다.
