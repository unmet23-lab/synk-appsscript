# FB 첫 게시물 「열일곱 번째」 — 올리는 법

> 2026-08-14 · 발행은 유호님이 직접 하십니다(외부 발행은 제가 실행하지 않습니다).
> 파일 = 이 폴더의 **「FB 첫 게시물 티저영상 v4」**(올리는 것) + **「FB 첫 게시물 카드 v4」**(썸네일로 지정할 것).

---

## 1. 올리기 (페이스북 페이지 · PC 크롬 기준)

1. 페이스북에서 **SYNK LAB 페이지**로 들어갑니다.
2. 게시물 입력칸(「무슨 생각을 하고 계신가요?」)을 클릭합니다.
3. 아래 **사진/동영상** 버튼 → **「FB 첫 게시물 티저영상 v4」 (mp4)** 를 고릅니다.
4. 캡션 칸에 아래 4줄을 그대로 붙여 넣습니다(줄바꿈 포함 — 유호님이 확정하신 문장입니다).

```
안녕하세요, SYNK LAB입니다.

세계 어디에도 없던 방식의 한국어 교육이
지금 한국에서 출발합니다.

2027년 2월, 17명의 선생님이 울란바토르에 도착합니다.

왜 17명인지는 — 곧 보여드리겠습니다.
```

5. **⚠ 썸네일을 반드시 바꿉니다.** 영상 미리보기 아래 **「썸네일」**(또는 「미리보기 이미지」) →
   **「이미지 업로드」** → **「FB 첫 게시물 카드 v4」 (png)** 를 올립니다.
   → 안 바꾸면 페이스북이 **첫 프레임(거의 캄캄한 화면)** 을 표지로 씁니다. 이 한 칸이 도달을 가릅니다.
6. **게시**를 누릅니다.
7. 게시 후 그 게시물을 **페이지 상단에 고정**합니다(게시물 오른쪽 «···» → 「페이지 상단에 고정」).

## 2. 며칠 뒤 — 힌트 댓글 (페이지 계정으로 직접)

하루~이틀 간격으로 **한 줄씩** 답글이 아니라 **새 댓글**로 답니다.

```
힌트 1: 열여섯 명은 눈에 보이지 않습니다.
```
```
힌트 2: 한 명은 교실에서 만날 수 있습니다.
```
```
힌트 3: 2월, 울란바토르에서 정답을 공개합니다.
```

## 3. 안 하는 것

- **몽골어를 지금 넣지 않습니다.** 검수해 줄 사람이 없어서, 검수 없는 몽골어는 올리지 않는 게 규칙입니다.
  화면 글자를 한글 인사·로마자 발음·`Улаанбаатар`·숫자만으로 짠 이유가 이것입니다 —
  **`16 + 1` 은 번역이 필요 없습니다.** 한국어 서사는 캡션에 뒀고, 캡션은 페이스북이 자동 번역해 줍니다.
- 광고는 이 게시물에 붙이지 않습니다(첫 게시물은 자연 도달로 둡니다).

---

## 이 게시물이 뭘 말하는가 (내부용 · 게시물엔 안 씁니다)

- 화면의 **빛 16점** = 정원 16명 각자의 선생님. **한가운데 하나** = 교실에서 만나는 사람.
  둘을 더하면 슬로건 「정원은 16명, 선생님은 17명입니다」가 됩니다.
- 영상은 그 순서를 그대로 밟습니다: 어둠 → 열여섯이 하나씩 켜짐 → 그 빛에서 한 명이 맺힘 → `16 + 1` → 2027.02.
- 「AI」라는 낱말은 어디에도 쓰지 않습니다(마케팅 정본 §233 규칙).
