## §0. 한 장 요약 (유호님용)

**앱이 «메뉴»가 아니라 «마을»이 됩니다.** 학생이 앱을 열면 화면 목록이 아니라 자기 방 안입니다. 방문을 나서면 마을 길이고, 길 끝의 옷 가게 문을 열면 종이 울리고 아주머니가 고개를 듭니다. 숙제는 책상에 앉아서 하고, 게임날엔 마을 밖 초원으로 나갑니다. 편지는 문가 우편함에 쌓이고, 해낸 것은 벽의 액자에 걸립니다.

강사는 교무실 책상에 앉습니다. 몽글이 이름을 부르며 맞이하고, 책상 위 쪽지 셋이 「오늘 말 걸면 좋을 아이」입니다. 담당 반 복도를 걸으면 아이들 방문이 있고, 열면 그 아이의 방과 벽에 걸린 이해 지도가 보입니다. 부모는 우리 집 현관입니다. 아이의 마스코트가 오늘 입은 옷 그대로 인사하고, 냉장고 달력에 두 색 스티커가 붙고, 우편함에 월간 편지가 옵니다. 원장은 학원 건물 전체를 다닙니다.

**생명감이 최우선입니다(유호 확정 09-05).** 딱딱하거나 죽어 있는 느낌이면 안 됩니다. 기능이 둘인데 하나만 살아 있게 만들 수 있으면 살아 있는 하나가 낫습니다. 다만 억지로 자리를 만들면 더 느려지는 기능(원장의 운영 화면·연습 판)은 깔끔한 도구로 둡니다.

**소통이 핵심입니다.** 우리가 수집하는 학생 이해(㉠ 실력 · ㉡ 사람 · ㉢ 삶)가 NPC 의 입으로 나옵니다. 마스코트가 「어제 녹음 잘 들었어」 하고, 아주머니가 「다음 주 시험이지? 델 입고 가」 합니다. 그래서 학생은 «이 앱이 나를 알고 챙긴다»고 느낍니다. 앱을 켜면 마스코트가 뛰어와 이름을 부르고, 그날의 «나를 아는 한 줄»을 건넵니다. 재료는 전날 밤에 학생마다 봉투로 구워 두니 AI 비용이 0이고, 미리 써 둔 말만 하니 검문도 필요 없습니다.

**자리마다 여섯을 봅니다.** 누가 있나 · 문이 있나 · 내가 한 일이 물건으로 남나 · 만지면 움직이나 · 시간이 흐르나 · 나를 알고 챙기나. 하나라도 0이면 그 자리는 아직 «화면»입니다.

**돈이 안 드는 방식으로 짓습니다.** 아주머니의 인사와 대화는 미리 써 둔 말을 고르는 방식이라 AI 를 안 부릅니다. 마스코트 챗봇은 유호님이 써 둔 문답을 찾아 주는 방식이 제안입니다.

**급소 하나.** 지금 구운 펠트 그림은 전부 멈춰 있습니다. 살아 있으려면 앱 안에서 움직여야 하는데, 펠트 결이 움직임 속에서 사는지는 아직 안 재봤습니다. 그래서 12월 리허설 전에 「내 방」 하나로 먼저 잽니다.

## §1. 생명감이 최우선 — 소통 규격 (✅ 유호 확정 09-05)

유호님 말(요지): 「생명감이 최우선. 딱딱하거나 죽어 있는 느낌이면 싫다. 생명감이 곧 신선함이고, 재밌는 포인트를 명품답게 구현하는 가장 중요한 해법. 억지로 안 되는 기능까지 이렇게 할 필요는 없지만 가능한 모든 것엔 생명감. 조잡하지 않고 깔끔하게. 소통하는 느낌 — 우리가 수집하는 개인화 데이터 기반으로, NPC 와 모든 기능이 나를 잘 알고 배려하고 챙기고 나를 위한다고 느껴져야. 앱을 켜면 반가워야.」

- **우선순위**: 생명감 > 기능 수. 두 기능이 다투면 살아 있는 하나가 죽어 있는 둘을 이긴다. 철학 게이트 ①「신선」을 지나는 첫째 길이 생명감이다(「생명감이 즉 신선함」).
- **억지 검사**: 자리로 만들면 «더 느려지거나 더 복잡해지는» 기능은 자리로 안 만든다 → 깔끔한 도구로. 축 = 「그 자리에 날마다 «사람»이 서는가」. 지금 판정: 원장 «운영»(창고)·«연습 판»(빈 교실)은 도구(유호님 혼자 쓰는 운영 화면 · §4). 나머지는 §2~§5 대로.
- **깔끔함**: 한 자리에서 동시에 움직이는 것은 셋까지(마스코트 · NPC · 물건 하나). 장식 0 · 반짝이 흩날림 0 · 한 번에 말풍선 하나. 소리는 킷 3종 + 유호 시청 4종만. 조잡함의 정의 = «뜻 없이 움직이는 것».
- **소통 규격 — «나를 아는 말»**: 자리마다 방문당 «나를 아는 말» 하나 이상(상한 = 접점 예산 · 엔진 설계 v2 §6). 재료는 우리가 수집하는 것(이해 대장 ㉠㉡㉢)에서만 오고, **없는 재료로 지어 말하지 않는다**(재료가 없는 날은 감정·응원만 · 생명감 §3).

| 칸 | 재료(출처 · 실물) | NPC 가 하는 말(예 · 템플릿 · 평가어 0 · 숫자 0 · 비교 0) |
|---|---|---|
| 이름 | `learners` | 「○○, 왔네!」 |
| 어제 일 | `submissions`·`corrections`(어제) | 「어제 녹음 잘 들었어」 · 「편지 왔더라!」(우편함 깃발과 같은 순간) |
| 처음 해낸 것 | 첫 제출·첫 녹음·첫 무오류 | 별눈 · 큰 점프(생명감 §2-1 · 하루 1회) |
| 성향(㉡) | 맞아? 카드에서 «맞아»로 확인된 것만(`preference.stated`) | 「너 틀리면 바로 다시 해 보는 편이잖아. 오늘도 그럴 것 같아」 |
| 삶(㉢) | 삶 이해(시험 날짜 · 목표 · 입학 회차 · `docs/삶이해_설계`) | 아주머니 「다음 주 시험이지? 델 입고 가」 · 몽글 「시험 끝났네, 오늘은 놀자」 |
| 옷·차림 | `choice.selected`(구매·착용·배경) | 「지난번에 파란 옷 샀지? 이거랑 어울려」 · 부모에겐 「오늘 새 옷 입었어요」 |
| 오랜만 | 마지막 접속 | 「보고 싶었어」(생명감 §2) · 방의 창이 닫혀 있다가 열린다 |
| 힘든 날 | 오류 많은 답장 · 숙제 밀림 · 결석 | 시무룩 0(생명감 §1-3) · «같이 들여다본다» · 밀림엔 장난 톤 · 결석 뒤엔 「어제 안 보여서 심심했어」 |
| 함께 | 반의 오늘(함께한 날 · 반 재고 「팔렸어」) | 「우리 반 오늘 다 왔대」(이름 0 · 비교 0) |
| 시간 | 시계·계절 | 「늦었다, 오늘은 여기까지」(밤) · 「눈 온다」(겨울) |

- **재료가 오는 길**: 전날 밤 학생마다 «오늘의 재료 봉투»를 굽는다(엔진 설계 v2 §6 U3 companion-bake · 코드 0). 앱은 봉투에 든 것만 말한다 → 오프라인에서도 산다 · LLM 0 · 발화검문 필요 없음(템플릿 + 확인된 재료). 🔴 이것이 이해 대장 ㉡(사람)의 **첫 소비자**다 — 「읽혀서 다음에 줄 것이 바뀐다」가 여기서 처음 선다.
- **반가움(앱 켬)**: 3초 안에 마스코트가 뛰어와 이름을 부르고 «나를 아는 말» 하나 · 방에 불이 켜진다 · 우편함 깃발이 보인다. 매일 똑같으면 죽는다 → 봉투가 날마다 다르게 채운다(어제 일 > 처음 해낸 것 > 삶 > 성향 > 시간 순으로 고른다).
- **강사·부모에게도 같은 결**: 강사의 몽글 = 「어제 ○○ 관찰 남겼지. 오늘 ○○가 처음 녹음했어」 · 부모의 현관 = 아이의 마스코트가 「오늘 새 옷 입었어요」 · 원장 = 도구(억지 검사).

## §1-b. 검사 여섯 + 공통 규칙

| 검사 | 통과의 모습 | 0 인 모습 |
|---|---|---|
| ① 누가 있나 | 그 자리에 마스코트나 NPC 가 있고 나를 알아본다(이름 · 어제 일 · 「어제도 왔지?」) | 아무도 없는 목록 화면 |
| ② 문이 있나 | 자리 사이 이동이 «문을 열고 들어가는 것»으로 보인다(문·길·종·발걸음) | 탭이 바뀌면 화면이 «갈아 끼워진다» |
| ③ 남는 것 | 내가 한 일이 그 자리에 «물건»으로 남는다(옷장의 옷 · 우편함의 편지 · 벽의 액자) | 기록이 표·숫자로만 있다 |
| ④ 만지면 움직이나 | 마스코트·NPC·물건이 만지면 반응한다(2.5D · 펠트 결이 산다) | 그림이 붙어 있을 뿐이다 |
| ⑤ 시간이 흐르나 | 아침·저녁 빛 · 계절 · 좌판이 바뀐다 · NPC 가 시간을 안다 | 언제 열어도 똑같다 |
| ⑥ 나를 알고 챙기나 | 자리마다 «나를 아는 말» 하나(§1 표) · 힘든 날엔 조용히 곁에 | 누구에게나 같은 말 |

공통 규칙(전 자리):
- **문은 짧다.** 첫 방문만 길게(≤1.5초 · 종·발걸음까지), 그 뒤는 0.3초. 매일 여는 문이 느리면 그것이 실패음이다. 탭 한 번으로 건너뛴다.
- **녹음 중엔 전부 멈춘다**(생명감 설계 §1-3 · 소리게이트). 고빈도 입력엔 무반응. `prefers-reduced-motion` 이면 움직임 0 이되 «자리»는 남는다(그림·물건·문은 그대로).
- **말은 미리 써 둔 것만.** NPC 대사 = 템플릿 풀(한·몽 병기 · 몽골어 검수 한 번) + 학생 답 고르기. LLM 0 이라 발화검문이 필요 없다. 평가어 0 · 숫자 0 · 비교 0(생명감 §3 금지 패턴 정규식 재사용).
- **소리.** 지금 소리 킷은 3종뿐이고 새 소리(문·종·발걸음·동전 «톡»)는 토큰→빌드→**유호 시청** 뒤에만 들어간다. 그 전엔 소리 없이 문이 열린다.
- **밤.** 밤 시간대엔 자리마다 등불·달빛(팔레트 «양모 밤» 그대로) · 마스코트 졸림 컷(있음).
- 🔴 마스코트와 «채팅»은 생명감 설계 §4 가 접었던 것을 **유호 확정 09-05 가 열었다**(1:1 학원 챗봇). 무언의 선생님 원칙은 «혼잣말·반응»에 그대로 살고, 채팅은 마스코트를 눌렀을 때만 열리는 별도 층이다(§2 「안내 책」).
