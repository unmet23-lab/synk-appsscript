# 교재연동 실행지 v9.58 — 목소리 타임랩스 + 필살기 노트 (유호님 절차서)

> 2026-07-24 채택 2건(A 목소리 타임랩스·B 필살기 노트)의 사람 몫 절차. 코드는 `교재연동.js` 라이브 배포 완료.
> 원리: **A** = 교재 1·4·8과의 말하기 과업을 폰 녹음으로 제출받아 "처음 vs 오늘" 성장 카드 생성. **B** = 미도달 문법·AI 첨삭을 모아 "교재 몇 과를 다시 펴라" 학생별 노트(일요일 밤 갱신). 둘 다 Glide update 0.

## STEP 1. 목소리 폼 만들기 (구글 폼, ~5분, 1회)

> ⚠️ 파일 업로드 문항은 스크립트가 못 만들어서(구글 제한) 이것만 유호님 손이 필요합니다. 나머지 연결은 전부 자동입니다.

1. `forms.google.com` 접속 → **+ 새 양식**
2. 제목: `SYNK 목소리 미션` / 설명: `Дуу хоолойгоо илгээгээрэй 🎙 폰으로 녹음한 파일을 올리면 끝!`
3. 문항 3개를 순서대로 추가:
   - **문항1** — 유형 **단답형**, 제목 `학생ID`, 필수 ✔ (도움말: "앱에서 열었다면 자동으로 채워져 있어요")
   - **문항2** — 유형 **드롭다운**, 제목 `미션`, 필수 ✔, 보기 4개: `1과 첫 인사` / `4과 나의 하루` / `8과 첫 무대` / `자유 연습`
   - **문항3** — 유형 **파일 업로드**, 제목 `녹음 파일`, 필수 ✔ → "응답자가 Google에 로그인해야 합니다" 안내가 뜨면 **계속** → 파일 형식 **오디오**만 체크, 최대 파일 수 1, 최대 크기 10MB
4. 폼 **편집 화면의 주소창 URL 전체**를 복사해 둔다 (`https://docs.google.com/forms/d/…/edit`)

## STEP 2. 폼 URL 등록 (~1분)

1. 구글시트(SYNK 본 시트) → 하단 탭 **app_state** 클릭
2. 맨 아래 빈 행에: **A열** `목소리폼편집URL` / **B열** 복사해 둔 URL 붙여넣기

## STEP 3. 에디터 ▶ 2회 (~2분)

구글시트 → 확장 프로그램 → **Apps Script** → 상단 함수 드롭다운에서:

1. `voiceFormFinishSetup` 선택 → **▶ 실행** — 응답 탭(`목소리폼_응답`) 연결 + 학생별 미리채움 틀 생성. 로그에 ✅ 확인.
2. `setupTextbookLink` 선택 → **▶ 실행** — voice_log 시트 + profiles 열 3개(DB 목소리폼URL·DC 목소리성장카드·DD 필살기노트) + **야간 트리거(23시)** 설치. 실행 직후 학생별 폼 링크가 바로 채워진다.

## STEP 4. Glide 조립 (3컴포넌트, ~5분)

> Glide 데이터 편집기에서 시트 재동기화(⟳) 후 — profiles 새 열 3개가 잡혀야 한다.

1. **🎙 목소리 미션 버튼** (학생 홈, 출석·숙제 버튼 옆): **Button** → Label `🎙 목소리 미션` → Action **Open Link** → Data = profiles **목소리폼URL**
2. **성장 카드** (학생 「나의 여정」 카드 아래): **Rich Text** → Data = profiles **목소리성장카드** → Visibility: `목소리성장카드` is not empty
3. **필살기 노트** (같은 화면, 성장 카드 아래): **Rich Text** → Data = profiles **필살기노트** → Visibility: `필살기노트` is not empty

## 운영 메모 (미리 아셔야 할 것 3개)

- **구글 로그인**: 파일 업로드 폼은 학생이 구글 계정 로그인 상태여야 제출됩니다. 몽골 학생 폰(안드로이드 절대다수)은 기본 로그인 상태라 실장벽은 낮지만, 상담 시 "구글 계정 필요" 한 줄 안내를 권장합니다.
- **음성 파일 공개 수위**: 성장 카드·학부모 메일에서 재생되도록 제출 파일을 **"링크를 아는 사람만 듣기 가능"**으로 자동 전환합니다. 10초 안팎 학습 음성이라 수위가 낮지만, 학생 동의 문구(폼 설명에 1줄)를 원하시면 폼 편집에서 추가하면 됩니다.
- **포인트**: 제출 +10P, 하루 1회만(여러 번 내도 기록은 전부 남고 포인트만 1회). 배치는 매일 23시 — calcAll(14/22시)과 겹치지 않게 배치했습니다.
