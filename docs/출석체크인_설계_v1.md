# 출석 체크인 — 실제 참석과 학습 기록의 구분

> 2026-10-17 본문 정리. 08-08에 채택한 출석·학습 분리와 QR·보호자 알림 구상은 보존한다. 현재 학원 시간표·조 편성·혜택은 [오프라인 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md)과 [반편성](반편성_정본_v2.md)을 따른다. 폐기된 Apps Script 시트 다리·문자 배치는 현행 구현 명세에서 제거했다.

## 1. 「왔다」와 「했다」를 따로 기록한다

물리적 출석은 실제 참석·수업 운영·보호자에게 전달할 사실을 위한 기록이다. 학습 기록은 무엇을 시도하고 어떤 도움을 거쳐 수행했는지의 근거다. 출석했다고 학습에 성공한 것도, 결석했다고 의지나 실력이 낮은 것도 아니다.

두 기록을 함께 볼 수는 있지만 결석·미제출의 조합만으로 「위험」「이탈 직전」이라는 사람의 상태를 확정하지 않는다. 연락·지원이 필요하면 실제 사유를 확인한다. 출석 순서는 운영 참고 정보이며 학생에게 등수·「1등 입장」 보상으로 제시하지 않는다.

숙제 포인트는 [BM 목록](BM_목록.md)의 보류 결정을 따른다. 출석 보상을 숙제로 옮겼던 08-08 선택을 현재 포인트·스트릭 제공 약속으로 확대하지 않는다. 보상 동기가 줄었다고 인증·권한·중복·허위 기록 확인이 불필요해지는 것도 아니다.

## 2. 보존하는 체크인 구상

| 항목 | 적용할 뜻과 경계 |
|---|---|
| QR 포스터 | 08-08에 선택한 기본 구상. 학생이 자기 계정으로 체크인하고 실제 수업·반·시각과 연결한다. 운영 개시 전 현재 앱에서 확인 |
| 출석 순서 | 필요할 때 실제 기록의 순서를 확인한다. 학습 평가나 공개 경쟁으로 쓰지 않음 |
| 휴대전화가 없거나 실패한 학생 | 실제 참석을 확인해 정정할 수 있어야 한다. 인증 오류를 곧 결석으로 만들지 않음 |
| 정정 | 최초 기록·정정 주체·시각·이유를 구분하고 같은 참석의 중복 적립·알림을 막음 |
| 문화·체험 프로그램 | 본과 학습 출석과 혼동하지 않되 실제 참여 인원·안전 관리에 필요한 확인은 유지 |

08-08에는 회전 PIN·교실 화면 토큰·태블릿 키오스크·매 교시 강사 폰 처리를 채택하지 않았고, 카드 태깅·Wi-Fi BSSID는 보류했다. 그 선택은 변경 이력으로 남긴다. 당시 장치 구상과 현재 앱·현장 조건이 다르면 근거를 확인해 해당 설계를 조정하며, 옛 「재제안 금지」 문구를 모든 후속 개발의 절대 제한으로 두지 않는다. 별도 인증 서버·자체 JWT를 추가하는 명세도 아니다.

## 3. 보호자 알림

08-08의 SMS+링크와 학부모 앱의 후속 구상은 [미성년·보호자 기능](미성년_보호자기능_설계_20261002.md)과 맞춰 이어 간다. 옛 링크·예약 발송 코드가 현재 운영 중임을 뜻하지 않는다.

- 보호자 관계·수신 대상·허용된 연락 목적을 먼저 확인한다. 학습 기록과 출결 사실의 공개 범위를 구분한다.
- 체크인·미확인·결석·정정은 실제 상태대로 전달한다. 미체크인만으로 무단결석을 확정하지 않는다.
- 발송 요청·공급자 접수·전달 실패·재시도와 실제 수신 확인은 다른 상태다. 중복 발송을 막고 실패를 운영 담당이 확인할 수 있게 한다.
- 링크의 인증·접근 권한·만료와 열람 기록의 필요성·보관 기준을 현행 계약에 맞춘다. 「링크 조회는 새 개인정보가 아니다」라는 예전 단정을 적용하지 않는다.
- 채널·비용·자동 발송 시점은 실제 공급자와 운영 검증 뒤 정한다. 옛 문자 단가·월 한도·고정 시각을 현재 계약으로 복사하지 않는다.

## 4. 구현의 담당 원문과 확인

학생·교사 앱의 실제 출석 계약은 [SYNK-talk L0](../../SYNK-talk/docs/L0_데이터계약.md)·[C0](../../SYNK-talk/docs/C0_API계약.md) 및 해당 마이그레이션·코드에서 확인한다. 이 문서의 개념 표는 새로운 DB 필드나 배포 완료 선언이 아니다. 현재 경로와 다른 경우 계약·코드·소비자를 함께 정리한다.

학원 운영 GAS는 [10-02 옛 시스템 정리](_ops/옛시스템_정리목록_20261002.md)로 제거됐다. 시트 이중 쓰기·GPS 폼·옛 SMS 함수·Script Properties·수업 전 자동 예약을 다시 설치하는 단계는 두지 않는다.

운영을 열기 전에 실제 기기의 QR 진입·자기 계정·반 연결·중복/오류·교사 정정·보호자 접근을 확인한다. 합성 시험·로컬 확인·실제 현장 수신을 구분한다. 「원장 업무 0분」이나 특정 개원일에 완료된다는 미검증 수치를 약속하지 않는다.

08-08 선택의 상세 이유, 알림 네 안, 시각·시트·데이터 모형과 옛 시험 목록은 [정리 전 원문](_ops/qa/document-cleanup-20261017/_archive/pass2-originals/docs/출석체크인_설계_v1.md)에 보존한다.
