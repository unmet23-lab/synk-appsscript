# SYNK 기업 홈페이지 — 현재 제작 계약

> 2026-09-16 현행화. 역할·공개 경계·원천을 연결한다. 실행법은 SYNK-website의 README, 실제 확인과 게시 상태는 해당 실행 기록에서 관리한다.

## 1. 홈페이지가 맡는 일

**회사 비전과 실제 경험을 먼저 보여주고, 방문자가 한국어 교육·비즈니스와 커리어·문화 콘텐츠 중 필요한 곳으로 들어가도록 한다.**

대표 장면 → 개인화 철학 → 공개한 경험과 실제 작업 → LAB·SHIFT·PULSE → 사업별 문의 → 공개 자료 질문 안내가 현재 구성이다. 질문창은 공개 설명을 찾아 읽는 보조 경로다. 옛 챗봇 중심 첫 화면은 현재 제작 기준이 아니다.

- LAB은 한국어를 배우고 싶은 모든 사람을 위한 교육과 배움·경험의 경로를 다룬다. 첫 진출 지역과 과정별 모집 조건을 브랜드 전체의 제한으로 쓰지 않는다.
- SHIFT는 기관 강의·기업 컨설팅·브랜딩과 개인의 유학·취업 연계를 다룬다. AI 회사 제작 이야기는 역량과 판단을 보여주는 공개 콘텐츠다.
- PULSE는 음악·영상·캐릭터·이야기와 제작 협업·작품 이용·광고를 다룬다.
- 교수님 편지 체험, 제작 가이드, K-LOFI 감상은 실제 경험의 입구다. 체험·준비·정식 서비스·출시·측정 효과를 구분한다.

사업 조건은 [마케팅 정본](마케팅_정본.md)의 담당 원문에서 확인한다. 입학·비자·취업·학습 성과·치료 효과를 보장하지 않는다. 브랜드의 역할과 실제 계약·청구·권리 주체를 구분한다.

## 2. 문안과 승인 자산

내부 목적·책임·판단 기준은 [철학 정본](SYNK_철학.md), 공식 장기 지향점은 [비전 정본](비전_정본.md)이 맡는다. 외부 독자용 문안은 SYNK-website의 `public-philosophy.json`과 `public-learning.json`에서 관리한다. 내부 정본으로 웹 문안을 통째로 덮어쓰거나 웹 요약을 내부 정본으로 역수입하지 않는다. 현재 원문과 실제 제공 범위를 읽고 공개할 문장만 고른다.

| 요소 | 현재 제작 기준 |
|---|---|
| 대표 장면 | [웹 대표 장면](캐릭터/웹_대표장면/README.md)과 연결된 승인 실물·현재 지문. 옛 개별 캐릭터 배치 설명으로 통합 장면을 재조립하지 않는다. |
| 로고 | [중립색 로고 정본](로고_중립색_정본_v1.md). SYNK 네 글자는 무실땀, 사업명은 승인된 고유색·스티치를 유지한다. |
| 서체·색·재질·움직임 | [DESIGN](../DESIGN.md)의 담당 원천. 실제 크기의 읽힘·대비·초점·움직임 감소를 확인한다. |
| 정보와 경험 | 대상·실물·현재 제공 상태·다음 행동을 연결한다. 자체 제작을 고객 성과로 설명하지 않는다. |
| 완성도 | [명품 기준](명품_기준_v1.md)의 해당 항목을 실제 화면과 동작으로 확인한다. |

## 3. 공개 질문 안내

검수한 공개 답변을 찾아 보여주는 기능이다. 생성형 AI·실시간 검색·모델 학습이나 문의 접수로 소개하지 않는다. 구현 수량은 [README](../../SYNK-website/README.md), 공개 범위·편집 방법은 [공개 안내 지식 유지](../../SYNK-website/docs/public-knowledge-maintenance.md)가 맡는다.

- `dist/knowledge.json`의 모든 필드는 내려받을 수 있다. 내부 원문·자격증명·학생 식별정보를 넣지 않는다.
- 답변의 출처·확인일·관련 질문·다음 행동을 함께 맞춘다. 근거가 없거나 개별 조건이면 확인이 필요하다고 안내한다.
- 답변 링크는 `src/public-actions.js`의 공통 정책으로 표시한다. 로컬 경로·앵커는 실제 도착지를 확인하고 외부 링크는 승인 목록으로 제한한다.
- 질문은 열린 화면 메모리에서 처리하며 서버로 보내거나 브라우저 저장소에 보관하지 않는다. 호스팅 접속 기록·클립보드·외부 링크·문의 양식의 처리는 이 설명과 구분한다.
- 생성형 답변·저장·추적을 도입하면 공개 자료의 전달 범위·거절·출처·개인정보 안내를 함께 검토한다.

Apps Script 상담봇과 기업 홈페이지는 별도 구현이다. 한쪽 지식 갱신을 다른 쪽 반영으로 세지 않는다.

## 5. 언어·문의·상품 조건

한국어 본문과 `/en/`의 영어 개요를 구분한다. 영어 개요가 전체 체험·모집 조건의 다국어 제공을 뜻하지 않는다. 몽골 학부모의 필수 안내는 해당 상품의 언어·감수 기준을 따른다.

웹 문의는 방문자가 열 때 불러오는 Google Forms 양식과 `hello@synk.im` 이메일로 연결한다. 질문창·버튼 클릭·이메일 작성창 열기는 접수가 아니다. 양식의 제출 완료 안내·실제 저장·담당자 전달·후속 응답을 각각 확인한다. 일반 사업 문의와 정식 수강 신청·결제·계약을 구분한다. 자동 발송을 구현한 것처럼 약속하지 않는다.

## 6. 다음 변경의 완료 조건

원천 선택 → 제작 코드·공개 답변 반영 → 재빌드 → 관련 자동 시험과 실제 화면·동작 → 요청 범위의 게시 → 공개 결과 재조회를 잇는다. 재빌드가 이번 수정을 되돌리지 않는지도 비교한다.

실제 앱·음원 출시, 정식 수강 신청, 추가 언어 감수와 고객 효과는 각각 확인한다. 이 문서의 최신화나 과거 시험 통과를 그 완료 증거로 사용하지 않는다.
