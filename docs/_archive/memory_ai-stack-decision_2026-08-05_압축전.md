**2026-07-11 정책 갱신 (유호 명시 지시, 2차 정밀화) — "$0 고정" 폐기 → "작업 스타일 적합성 + 퀄리티 게이트"로 교체**

- **새 기준(정확한 문구로 고정)**: 지출 판단은 두 조건을 **둘 다** 통과해야 함 —
  1. **작업 스타일 적합성**: 유호의 실제 작업 방식(자연어 지시 → 원격 실행·배포, 비개발자, 하네스/기억 의존)에 자연스럽게 맞는가. 안 맞으면 아무리 저렴해도 기각(예: Cursor — 저렴해도 원격 작업 스타일과 충돌해 기각한 07-11 판정 그대로 유효).
  2. **퀄리티/성과의 확실한 상승**: "약간 낫다" 수준이 아니라 **확실히(clearly)** 오르는 것. 애매하면 지출 보류.
  - 둘 다 통과해야 지출 OK. 하나만 통과(싸지만 안 맞음 / 잘 맞지만 상승폭 애매)면 기각.

- **바뀌는 것**: "재제안 금지" 잠금 중 순전히 $0 정책에만 기댔던 것(예: 학원 실운영 전 마케팅/일정관리 SaaS, 콘텐츠 발행 자동화)은 이제 **위 두 조건을 충족하는 근거만 있으면 다시 올려도 됨.**
