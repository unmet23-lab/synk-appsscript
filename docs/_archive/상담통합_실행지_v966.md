# 상담 정본 v18.4 통합 실행지 (v9.66 · 2026-07-26)

> 유호님 지시 "구글폼 + 상담데이터입력 시트 통합"의 실행 결과와, 유호님이 하실 ▶ 클릭 절차.
> 통합의 정의: **온라인 상담폼 = 오프라인 Crew Dossier(v3.3) = 상담데이터입력 시트**가 같은 문항·같은 선택지·같은 표기를 쓰는 단일 정본이 된다. 데이터 입구(폼 제출→시트 62열 자동 기입→ID 채번→아침 동기화→앱→KPI)는 그대로 산다.

- 선택지 증분 1개 → 관심K분야에 **예능**

## 1. ▶ 마이그레이션 실행 (유호님 · 1회 · 2분)

0. 전제: 제 "배포 완료" 보고를 받은 뒤 진행하세요. (함수 드롭다운에 `migrateConsultV184`가 안 보이면 아직 배포 전입니다)
1. 크롬에서 `script.google.com` 접속 → **SYNK 앱데이터 프로젝트** 클릭 → 왼쪽 `< >`(편집기) 클릭.
2. (선택·30초) 함수 **`dumpConsultHeaders`** 선택 → ▶ → 로그에서 60·61·62열이 각각 `학생ID` / `⚠위험신호(자동)` / `반조회순번(숨김)`인지 확인 — 표기가 하나라도 다르면 멈추고 저에게 알려주세요.
3. 상단 함수 선택 드롭다운(디버그 버튼 왼쪽)에서 **`migrateConsultV184`** 선택.
4. **▶ 실행** 클릭 1회. (다시 눌러도 안전 — 이미 있는 건 전부 건너뜁니다)
5. 아래 "실행 로그"에 이렇게 나오면 성공:
   - `시트: 추가 학교명/전공(63열), … 취미관심사(68열)`
   - `폼: 추가 학교명/전공, … SYNK선택이유, 관심K분야+'예능'` — "맨 끝 배치"라는 꼬리표가 붙은 문항이 있으면 저에게 알려주세요(폼 안 위치만 어긋난 것, 데이터는 정상).
   - 같은 내용이 원장 메일로도 1통 옵니다.
6. 상담 스프레드시트를 열어 **63~68열이 화면에 실제로 보이는지** 한 번 확인(숨김 상태로 태어나는 것까지 코드가 강제 해제하지만, 눈 확인이 정석).

## 3. Crew Dossier 새 PDF 뽑기 (유호님 · 2분)

정본 파일: 바탕화면 **「SYNK LAB Crew Dossier (디자인 원본).html」** (v3.3로 수정 완료)

1. 파일을 더블클릭해 크롬으로 열기.
2. `Ctrl + P` → 대상: **PDF로 저장** → 설정 더보기에서 **배경 그래픽 켜기** + **머리글 및 바닥글 체크 해제**(v3.3은 여백 0 잠금이라 어차피 안 생기지만 이중 안전).
3. 저장 전 미리보기에서 ① 날짜·파일 경로 줄이 없는지 ② 맨 끝에 빈 페이지가 없는지 확인 후 저장.
4. 구 PDF(「SYNK LAB · Crew Dossier.pdf」)는 이 새 파일로 교체.

⚠️ 이 HTML이 도시에의 유일한 정본입니다. 디자인 도구에서 다시 내보내면 v3.3 수정(아래 17건)이 사라지니, 앞으로 고칠 일이 있으면 이 파일을 저에게 시키세요.

## 4. 오프라인 상담 → 시트 기입 규칙 (강사·원장 공용)

- **어디에**: 상담 스프레드시트 `상담데이터입력` 탭, 3행부터 빈 행에 기입. 새 6열도 채움 — 도시에 칸과 열 대응:

| 도시에(v3.3) 칸 | 시트 헤더(열) |
|---|---|
| 학교명 / 전공 | 학교명/전공 (63열) |
| 방문 상세 (기간/목적) | 방문상세 (64열) |
| 비자 거절 당시 정황 | 거절정황 (65열) |
| K-POP · 선호 그룹 | 선호그룹 (66열) |
| K-Drama · 인생 작품 | 인생드라마 (67열) |
| 취미 · 관심 분야 | 취미관심사 (68열) |
- **학생ID(60열)**: 상담만 하고 간 사람은 **비워둔다**. 등록 확정 시에만 마지막 SYNK-번호 다음 번호(예: SYNK-013)를 기입 — 그래야 다음 날 아침 앱에 자동 유입.
- **등록일(C열)**: 상담한 날짜. (월별 상담·전환 KPI가 이 날짜로 집계됨)
- **선택지 표기**: 폼과 똑같은 값으로 — 특히 *알게 된 경로*는 8버킷(페이스북/인스타/틱톡/추천/오픈데이/학교제휴/워크인/기타) 그대로.
- **서술형**(다짐·고충·선택이유 등): `📝자유서술→노션` 칸에 `[문항명] 내용` 줄로 모아 적기.
- **도시에 전용 항목**(기타 자산, VS 학습선호 점): 시트 열이 없음 — 학습선호는 점이 왼쪽(1~2번째)이면 혼자집중/이론중심/꼼꼼반복, 오른쪽(4~5번째)이면 반대쪽으로 판정해 해당 열에 기입, 가운데(3번째)면 상담사가 한쪽을 정함.

## 5. 도시에 v3.3에서 고친 것 (17건 요약)

- **문항 정합 13건**: 나의 비전·학습 경로·희망 진학 과정(+편입 추가)·거절 비자 종류·핵심 가치관·조달 주체·강점·관심 K분야 → 전부 폼과 같은 **단일 선택(라디오)** 으로 통일 + "하나만" 안내 문구.
- **알게 된 경로**: 4버킷 → **8버킷**(v9.33 어트리뷰션과 정합 — 유입 KPI가 안 깨짐).
- **개인정보 동의·서명 블록 신설**(마지막 파트 Part 6, 환영 문구 바로 앞): 수집 항목·용도 고지 + 동의 라디오 + 학생·보호자 서명란. *문구는 초안 — 유호님이 한번 읽어보시고 수위 조정.*
- **"100% 반려" → "반려로 직결"** 완화(결과 보장 인상 제거).
- **표지 등록일 "2026" 하드코딩 제거**(연도 무관 서식).
- **인쇄 CSS 신설**: 여백 0 잠금(크롬 날짜·경로 푸터 원천 제거)·다크 배경 풀블리드·페이지 단위 분할.
