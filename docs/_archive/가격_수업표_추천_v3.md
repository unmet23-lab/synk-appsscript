## ⓪ 한눈 결론 — 세 레버(급여·코어인원·가격)의 관계

**정직한 핵심 한 문장:** 급여를 낮추면(150→120→100) 번이 내려가 손익분기 하한이 풀리는 건 맞지만, **base 120만원·코어3에서는 안전마진이 거의 없다.** 왜냐하면 코어를 3명으로 시작하면 재적 천장이 130(현실 110)으로 같이 줄어, 번이 낮아져도 분모가 함께 작아지기 때문이다. **진짜 안전마진은 ①코어 4명(재적 천장 회복) 또는 ②급여 100만원 중 하나가 있어야 나온다.**

## ① 번 급여 민감도 표 (정규직 × 급여 4단 × 유호 부담금 0/1)

**산식(만₮/월):** `번 = 비인건 2,764 + 정규직급여 + 사회보험(13%) + 외국인부담금(158.4×대상수) + 시간제 120`

## ② 손익분기 하한 표 (번 ÷ 현실재적)

**하한 ARPU = 흑자로 들어오려면 필요한 최소 실효 ARPU.** 이 아래로 가격을 내리면 만석(현실재적)이어도 적자. 현실재적: 코어3 = 110(천장130×85%), 코어4 = 128(천장150×85%).

> ⚠️ **충원율 민감도(중요 — 아래 모든 쿠션이 여기 달렸다):** "현실재적"은 캐파 범위 80~85%의 **상단 85%**를 쓴 값이다. 실제로는 이보다 낮을 수 있고, 그러면 코어3는 정상 시나리오에서도 적자가 된다:
> - 충원 85%: 코어3 현실 110 → base 쿠션 **+1**
> - 충원 82.5%(중앙): 코어3 현실 107 → base 쿠션 **−2 (적자)**
> - 충원 80%(하단): 코어3 현실 104 → base 쿠션 **−5 (적자)**
>
> 즉 코어3·120만원은 "만석에 가깝게(85%+) 채워야만 겨우 흑자"다. 코어4는 충원 80%에서도 현실 120 > BEP 116으로 흑자 유지 → **충원율 리스크까지 감안하면 코어4 필요성이 더 커진다.**

| 급여(만원) | 코어3·재헌만 (÷110) | 코어3·양쪽 (÷110) | 코어4·재헌만 (÷128) | 코어4·양쪽 (÷128) |
|---:|---:|---:|---:|---:|
| 100 | 43.6 | 45.0 | **39.7** | 40.9 |
| **120 (base)** | **46.7** | 48.2 | **42.9** | 44.1 |
| 130 | 48.3 | 49.8 | 44.5 | 45.7 |
| 150 | 51.5 | 53.0 | 47.7 | 48.9 |

**한눈에 보이는 것:**
- **급여를 100→150으로 올릴수록 하한이 코어3에서 43.6→51.5만, 코어4에서 39.7→47.7만으로 상승** — 가격 압박이 커진다. 거꾸로 급여를 낮출수록 하한이 풀린다.
- **같은 급여에서 코어4가 코어3보다 하한이 3.8~3.9만 낮다** — 번이 더 큰데도(분자↑) 재적이 훨씬 커서(분모 110→128) 하한이 내려간다. 이게 코어4의 진짜 값어치.
- **base(코어3·120·재헌만) 하한 = 46.7만.** 권장 카드의 실효 ARPU(47.2만, ③)가 이 하한을 **겨우 0.5만 넘는다** → 마진 거의 0. **코어4·120으로 가면 하한 42.9로 떨어져 실효 47.2가 +4.3만 마진**을 만든다.
- 유호 부담금이 붙으면(양쪽) 하한이 코어3 +1.5만·코어4 +1.2만 상승 — 법무 확인이 마진에 직결.

**왜 base 코어3 하한에서 "안전마진 5~6만" 역산이 불가능한가 (⑦ 산식 요지):**

- **결론: 코어3에서 5~6만 안전마진은 가격으로 못 만든다.** 가격을 올리면 WTP 천장을 깨고, 안 올리면 마진이 없다. → **마진은 코어4(하한 42.9, v2가격 실효 47.2 = +4.3만) 또는 급여 100만원(하한 43.6 = +3.6만)에서만.** 이게 이 문서의 가장 중요한 정직이다.

**지불의사·구매력·경쟁가 교차 확인:**
- **경쟁가:** UB 그룹반 실가 16~32만₮. 올액세스 55~69만 = **1.7~4.3배** = 시장 최고가. 정당화는 가치(단품합산 90~155만)·희소자원(한국인 원어민)·시스템이지 실측 WTP 아님.
- **가치 상단:** 이론 상단 70만. 올액세스 1개월 69만이 이 바로 아래(단독 노출 금지, 항상 스탠다드 42~55 병렬 헤지).
- **구매력:** 상위 20~25% 맞벌이 가구(추정 합산 350~450만₮) 대비 올액세스 55~69만 = 가구소득 12~18% = 부담 구간. 상위 실가구소득 **미실측**(파일럿).

**왜 안 올리나:** WTP 미실측 상태에서 인상은 BEP 인원↓의 대가로 도달확률(수요)을 깎는 도박. 가격탄력성 −0.9만 걸려도 +7% 인상→재적 −6%. **인상은 파일럿에서 저항 없음 확인 시에만 발동하는 레버.**
**왜 안 내리나(코어3):** 코어3·120만원에선 v2 가격이 곧 최소가격(하한 46.7, 실효 47.2 = +1명 쿠션). 여기서 내리면 만석에서도 적자. **가격 인하는 코어4와 세트로만** 성립(하한 42.9 → 최대 −9% 여지).

### 3-2. 애드온 (스탠다드 전용 업셀 사다리)

| 애드온 | 월 정액 | 근거 |
|---|---:|---|
| 원어민 회화 | +12만 | 단품가치 15~25만 아래. UB 한국인 원어민 = 희소자원 |
| 글로벌 영어 | +9만 | 보조 모듈 하단. **주간(낮) 한정** — 저녁 고객 부착 불가 |
| TOPIK 집중 | +8만 | 목적성 성인·유학층 |

- **업셀 사다리:** 스탠다드 6개월 풀로딩 = 42+12+9+8 = **71만 > 올액세스 55만** → 올액세스가 16만 싸다 = 구조적 자연 업셀.
- **회화 애드온은 dominated:** 스탠다드 6개월(42)+회화(12)=54 ≈ 올액세스(55). 1만 차이로 전부 주므로 회화 수요는 올액세스로 흡수 → **회화 attach는 BEP에서 0으로 계상**(순수 업사이드는 올액세스 채택률↑).

### 3-3. 기간권·할인·결제

- **기간권 1/3/6개월 선납만** (QPay recurring 불가 → 월 자동결제 상품 없음).
- **6개월권 = 겨울 방어 1순위.** 선수취 창 = 2027.9~11(신학기) → 첫 겨울(2027.12~2028.2) 선현금 통과.

## ④ BEP 시나리오 (base·겨울누수15%·최악 + 캐파 천장 대비)

**공통:** 권장 카드(올50%, attach=0), 실효 = blended×누수계수. 정상 누수 10%(×0.9), 겨울 누수 15%(×0.85), 최악 = 올액세스 채택 38%(blended 50.86)+겨울.

| 시나리오 | 실효 ARPU | **코어3·120 (번5,141)** | **코어4·120 (번5,491)** |
|---|---:|---|---|
| **정상(base)** | 47.2 | BEP **109** · 현실110 **+1** · 천장130 +21 | BEP **116** · 현실128 **+12** · 천장150 +34 |
| **겨울 누수15%** | 44.6 | BEP **115** · 현실110 **−5 ❌** · 천장130 +15 | BEP **123** · 현실128 **+5** · 천장150 +27 |
| **최악(올38%+겨울)** | 43.2 | BEP **119** · 현실110 **−9 ❌** · 천장130 +11 | BEP **127** · 현실128 **+1** · 천장150 +23 |

**정직한 진단:**
1. **코어3·base는 정상 시나리오에서도 쿠션이 +1명(BEP109 vs 현실110)** — 사실상 만석에서만 흑자. 회화 attach=0·올50% 가정이 조금만 흔들려도(올45%면 BEP 110, 올40%면 112) 즉시 적자.
2. **겨울(−40°C·출석붕괴)을 스트레스하면 코어3 BEP 115~119 > 현실재적 110 → 만석이어도 적자.** 이게 몽골 최대 변동변수. 코어4는 겨울에도 BEP 123·최악 127로 현실 128 안에 아슬하게 생존.
3. **천장 대비 마진:** 코어3 천장 130(현실110), 코어4 천장 150(현실128). 코어3은 천장 자체가 낮아 성장 여지도 작다.
4. **방어(가격 인상·할인삭감 아님):** ①6개월권 2027.9~11 선수취(겨울 선현금) ②이탈 압축(리텐션 엔진 5.5→2.5% 시도, 미검증)→누수↓ ③주5 중 2일 온라인·앱 미션 전환(겨울 출석붕괴 완화) ④**+1코어(코어4)로 재적 천장 회복** = 겨울·최악을 흑자권 안으로 끌어들이는 유일한 구조적 방어.

> BEP 표기 유의: 모두 중도이탈·환불·미납 ≤5.5% 전제. "BEP를 증명한다"고 쓰지 않는다 — 모든 채택률·attach·이탈률은 미실측 가정(파일럿 실측 전 헤지).

## ⑥ 코어 4명 대안 (정원↑·하한↓ vs 번+1인) — 나란히 비교

**개원은 3명, +1(4번째 몽골인 코어)은 파일럿에서 오후·저녁 순증 수요 확인 시 즉시.** +1코어 배치 = B룸 슬롯 개방(14:00-B·15:30-B·19:45-B 중 2개) → 8코어 = 평일 130 + 토 20 = 천장 150.

| 축 | 코어3 (base·확정 개원) | 코어4 (+1 몽골인) |
|---|---|---|
| 정규직 | 6인 | 7인 |
| 번(120만원·재헌만) | **5,141만₮** | **5,491만₮** (+350) |
| 재적 천장 / 현실 | 130 / 110 | 150 / 128 |
| 하한 ARPU | 46.7 | **42.9** (−3.8) |
| BEP(실효47.2, 정상) | 109 (쿠션 +1) | 116 (쿠션 **+12**) |
| BEP 겨울/최악 | 115 / 119 (**현실 초과 ❌**) | 123 / 127 (현실 내 생존 ✅) |
| 안전마진 | 사실상 없음 | **실효 +4.3만 (건강)** |
| 최소가격 여지 | v2 그대로(−1%) | **v2 대비 −9%까지 인하 가능** |

**정직한 대조:** +1코어는 번을 350만₮ 늘리지만(급여120·사보), 재적 천장을 110→128로 열어 **하한을 3.8만 낮추고 안전마진을 −0에서 +4.3만으로 뒤집는다.** 코어3의 "번이 낮다"는 장점은 분모(재적)도 함께 작아 상쇄되고, 겨울·최악에서 적자로 떨어진다. **+1코어 = "수요 시 옵션"이 아니라 개원 안전마진 설계의 핵심 결정.** 단, 강사 인건비는 재적이 붙기 전 먼저 나가는 고정비이므로 **선확정 금지** — 파일럿에서 오후 14~17시·저녁 순증 수요가 실측되면 그때 붙인다(수요 없이 붙이면 빈 좌석 위에서 번만 태움).
