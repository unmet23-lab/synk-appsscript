## ⓪ 이 초안이 바꾼 것 — "문법 강조"의 실체

### ⓪-1. 페이지 재배분 (1과 = 1주 = 5차시 = 16p)

**과 유형이 둘이라 배분도 둘이다.** 하나의 표로 뭉뚱그리면 1~2과(한글 완성 주간)에서 지면이 안 맞는다.

| 구성 | 구 설계 | **표준과**(3~8과) | **한글과**(1~2과) | 변경 근거 |
|---|---:|---:|---:|---|
| 도입 스프레드 | 1p | **1p** | **1p** | 유지. 단 하단에 **나선형 복습 띠** 신설(지난 과 문법 1분 점검) |
| 한글·받침 읽기 훈련 | — | — | **2p** | 1~2과 한정 슬롯. 자모·받침은 문법이 아니라 **해독 훈련**이라 별도 지면이 필요하다 |
| 어휘 | 2p | **1.5p** | **1p** | 코어 20~25만 지면, 롱테일은 앱(이원 구조 강화) |
| **문법** | **8p** | **10p** | **8p** | 항목당 **2p 표준 카드**. 1~2과는 문법 항목이 0~3개뿐이라 8p가 상한 |
| 발음 코너(권1~2) | 1p | **1p** | **1p** | 유지 — 몽골 학습자 고정 난점 슬롯 |
| 통합 과업·산출 | 2p | **1.5p** | **2p** | 표준과는 강사 주도라 지면 의존도가 낮고, 한글과는 활동지가 필요 |
| 자가 점검 | 1p | **1p** | **1p** | **문법 자가진단 표**로 성격 전환(can-do 체크 → 항목별 ○△✕) |
| **합계** | 16p | **16p** | **16p** | 총 페이지·집필 물량 무변경 = **8주 진도 무영향** |

> 핵심: **총량은 그대로, 무게중심만 문법으로.** 권1 총 페이지는 ~170p 유지(목차골격 §④ 잠금 준수).
> **"문법 10p"는 표준값이지 모든 과의 고정값이 아니다** — 문법 항목이 3개뿐인 과에 10p를 강제하면 설명이 물을 타게 되고, 그게 바로 ⓪-2가 경계하는 "설명 부풀리기"다.

### ⓪-2. "강조"를 만드는 4개 장치 (설명 길이가 아니라 처리 깊이)

1. **2p 표준 문법 카드** — 형태·의미·몽골어 대조·오류 예측·3단 연습·핵심 한 줄을 고정 슬롯으로. 항목마다 같은 자리에 같은 정보가 있어 학생이 찾는 법을 한 번만 배운다.
2. **활용표를 전면에** — 초급 교재가 흔히 예문으로 흘려보내는 결합 규칙(받침 유무·모음조화)을 **표로 못박아** 시각 기억에 얹는다.
3. **나선형 재출현** — 한 문법을 한 번 가르치고 끝내지 않는다. 도입 띠(1분 점검) → 다음 과 연습 지문에 재출현 → 파이널 종합. 권1에서 **모든 문법이 최소 3회 재등장**한다.
4. **몽골어 거울(⚡)** — 한국어와 몽골어가 **같은 점을 먼저** 보여 자신감을 주고, 다른 점에서 오류를 예측해 미리 막는다. 이 교재의 최대 차별점이자 시장의 일반 교재(영어 기반 설명)가 못 하는 부분.

### ⓪-3. 언어 정책 대응 (G17/G28 미결정 상태에서도 안전한 조판)

학습 대상 언어 = 한국어 전용은 잠금이다. 그러나 **초급 문법 설명을 한국어로만 하면 이해가 불가능**하다. 해소:

- **본문(어휘·예문·연습) = 한국어 전용** — 잠금 준수.
- **설명은 언어가 아니라 도식으로** — 활용표·색·화살표·아이콘. 언어 무관.
- **몽골어는 ⚡거울 박스와 ⚠️오류 박스 안에만** — 물리적으로 분리된 박스라, 만약 "몽골어 전면 배제" 결정이 나면 **박스만 들어내면 한국어 전용판이 즉시 완성**된다(재조판 불필요).

이 설계 덕에 G17/G28 결정을 기다리지 않고 집필을 진행할 수 있다.

## ① SYNK 문법 카드 — 전권 공통 표준 포맷 (2p)

모든 문법 항목이 이 6블록을 같은 순서로 갖는다. 권2~6도 동일(밀도만 상승).

```
┌─ [왼쪽 페이지] ─────────────────────────────┐
│ ① 형태 FORM        — 결합 규칙 활용표(색 구분)   │
│ ② 의미 MEANING     — 한 줄 + 상황 그림 2컷      │
│ ③ ⚡ 몽골어 거울    — 같은 점 / 다른 점          │
│ ④ ⚠️ 이런 실수      — 예측 오류 → 교정 화살표     │
└──────────────────────────────────────────┘
┌─ [오른쪽 페이지] ───────────────────────────┐
│ ⑤ 연습 3단                                  │
│    A 알아보기(인지) — 고르기·연결             │
│    B 만들기(통제)   — 활용·빈칸               │
│    C 내 말로(유의미) — 자기 정보로 산출        │
│ ⑥ 🎯 핵심 한 줄 + 📱 앱 드릴 코드                 │
└──────────────────────────────────────────┘
```

**블록별 집필 규칙(집필자·검수자 공통 기준):**

| 블록 | 분량 | 규칙 |
|---|---|---|
| ① 형태 | ⅓p | 표 필수. 받침 유무·모음조화 등 **선택 조건이 있으면 반드시 2열 이상 표**로. 예문은 표 안에. |
| ② 의미 | ⅙p | **한 줄**. 두 줄 넘어가면 그 항목은 쪼갠다(1카드 1기능 원칙). |
| ③ ⚡거울 | ⅓p | **같은 점 먼저, 다른 점 나중.** 몽골어 문장은 최소화하고 구조 대조 위주. **전량 원어민 검수 대상.** |
| ④ ⚠️오류 | ⅙p | 실제 예측 오류 문장 → 빨간 취소선 → 교정문. 2~3개. |
| ⑤ 연습 | 1p | A:B:C = 3:4:3 비율. **C(내 말로)를 반드시 넣는다** — 통제 연습만 있으면 문법이 시험 지식으로 죽는다. |
| ⑥ 핵심 한 줄 | ⅙p | 학생이 외울 한 줄 구호. 앱 드릴 코드(QR)로 롱테일 연결. |

## ② 권1 문법 지도 (8과 × 항목 — 전체 골격)

목차골격 ①표의 "권1 문법 ~30개"를 실제 항목으로 확정했다. 모듈1(1~4과)은 교안 확정분, 모듈2(5~8과)는 교안 예고(과거·부정·주문·쇼핑·길)에서 도출한 **초안 제안**이다.

| 과 | 주제 | 문법 항목 | 수 | 재출현(나선형) |
|---|---|---|---:|---|
| **1과** | 소리를 얻다 (한글 I) | *문법 규칙 없음* — 통문장 청크 3(안녕하세요/감사합니다/저는 ___이에요) | 0 | — |
| **2과** | 이름을 말하다 (한글 II) | **은/는** · **이에요/예요** · 네/아니요 의문 | 3 | 1과 청크 회수 |
| **3과** | 세계를 가리키다 | 이/그/저 · **이/가** · 있어요/없어요 · 에(위치) · 단위명사(개·명·살) | 5 | 2과 은/는 대조 재등장 |
| **4과** | 하루를 움직이다 | **-아요/어요** · **을/를** · 에 가다(방향) · 시간 표현 | 4 | 3과 이/가 + 신 을/를 대조 |
| **5과** | 어제를 말하다 | **-았/었어요** · 안 부정 · 시간 부사(어제·오늘·내일) | 3 | 4과 활용 규칙 그대로 확장 |
| **6과** | 주문하다 | **-(으)세요** · -고 싶어요 · 얼마예요 · 하고/와과 | 4 | 을/를 + 주세요 결합 회수 |
| **7과** | 길을 찾다 | **에서**(장소) · (으)로(방향) · 못 부정 · -(으)ㄹ까요? | 4 | 3과 에(위치) ↔ 에서 대조 |
| **8과** | 나의 무대 (승급 평가주) | *신규 없음* — 보조사 **도·만** 2항목 + **전 항목 종합** | 2 | **전 22항목 종합 지도** |
| | | **합계** | **25** | |

> **25개 = 목차골격 "~30"의 하단.** 권1은 한글 2주를 포함하므로 문법 밀도가 낮은 게 정상이며, 여유분 5개는 **재회전 학생용 심화 슬롯**(부록 ③)으로 남긴다 — 도달제 재회전 시 같은 교재를 다시 볼 때 새로 얻는 것이 있어야 재회전이 벌이 아니라 심화가 된다.
>
> **조사 4형제 대조 설계(권1 최대 난점)**: 은/는(2과) → 이/가(3과) → 을/를(4과) → 에/에서(3·7과)를 **일부러 흩어 배치**했다. 한꺼번에 가르치면 몽골 학생이 전부 뒤섞는다(⚡거울 참조: 몽골어는 대격·처격이 있으나 **주제 표지가 없다**). 각 과의 ⚡박스에서 **직전에 배운 조사와 1:1 대조**하는 방식으로 누적한다.

### [p5–6] 문법 ① **은/는**

#### ① 형태 FORM

| 앞 낱말 | 붙이는 것 | 예 |
|---|---|---|
| 받침 **있음** | **은** | 이름**은** · 선생님**은** · 몽골**은** |
| 받침 **없음** | **는** | 저**는** · 나라**는** · 의사**는** |

> 표 옆 도식: `받침 O → 은` / `받침 X → 는` (색 구분 — 받침 있는 낱말은 파랑, 없는 낱말은 주황. 이 색 규칙은 권1 전체에서 동일하게 쓴다.)

#### ② 의미 MEANING

**"이것에 대해 말하겠습니다" — 이야기의 주인공을 정하는 표시.**

#### ③ ⚡ 몽골어 거울 〔원어민 검수 필요〕

```
✅ 같은 점
   어순이 같다.  저는 학생이에요.   =  Би оюутан.
                 (나 - 학생)            (나 - 학생)
   → 몽골어를 아는 것이 유리하다. 한국어 어순은 몽골어와 같다.
     (영어는 "I am a student"로 순서가 다르다 — 여러분은 영어 학습자보다 유리하다.)

⚠️ 다른 점 — 이것이 이번 과의 핵심
   몽골어에는 "은/는"에 해당하는 표시가 없다.
   그래서 한국어를 배울 때 "은/는"을 자꾸 빠뜨리게 된다.
   빠뜨려도 뜻은 통하지만, 한국 사람에게는 말이 끊긴 느낌을 준다.
```

> **집필 메모(조판 전 확정 필요)**: 위 몽골어 예문 `Би оюутан`은 계사 없는 기본형으로 썼다. 실제 자연스러운 구어형·격 표기는 **원어민 검수에서 확정**한다. 검수 담당은 에리카 선생님 또는 친구분(교안 실물화 분업 시). 검수 전에는 인쇄하지 않는다.

#### ④ ⚠️ 이런 실수

```
✕ 저 학생이에요.          → ⭕ 저는 학생이에요.
✕ 이름 김민수예요.        → ⭕ 이름은 김민수예요.
✕ 저은 몽골 사람이에요.   → ⭕ 저는 몽골 사람이에요.   (저 = 받침 없음 → 는)
```

### [p7–8] 문법 ② **이에요/예요**

#### ① 형태 FORM

| 앞 낱말 | 붙이는 것 | 예 |
|---|---|---|
| 받침 **있음** | **이에요** | 학생**이에요** · 선생님**이에요** · 회사원**이에요** |
| 받침 **없음** | **예요** | 의사**예요** · 가수**예요** · 친구**예요** |

> **함정 주의(별색 박스)**: 두 낱말이 붙어 있으면 **맨 마지막 글자**의 받침만 본다.
> `몽골 사람` → 마지막 글자 **람**(받침 ㅁ) → 몽골 사람**이에요** ⭕
> `한국 가수` → 마지막 글자 **수**(받침 없음) → 한국 가수**예요** ⭕

**부정형(미리 보기 — 4과에서 정식 학습):** 학생이 **아니에요** / 의사가 **아니에요**

#### ② 의미 MEANING

**"A는 B입니다" — 무엇인지 말하는 가장 기본 문장.**

#### ③ ⚡ 몽골어 거울 〔원어민 검수 필요〕

```
✅ 같은 점
   한국어도 몽골어도 "~이다"가 문장 맨 뒤에 온다.
   저는 학생이에요.   ← 맨 뒤
   (영어는 I "am" a student로 가운데에 온다 — 또 하나의 유리한 점)

⚠️ 다른 점
   몽골어는 "학생이다"를 말할 때 "이다"를 생략할 수 있다.
   한국어는 생략할 수 없다. 반드시 "이에요/예요"를 붙인다.
   → 그래서 "저는 학생." 처럼 끝내는 실수가 자주 나온다.
```

### [p9–10] 문법 ③ **네/아니요 의문** + **② 종합**

#### ① 형태 FORM

| 묻기 | 답하기(긍정) | 답하기(부정) |
|---|---|---|
| 학생이에요**?** (끝을 ↗) | **네**, 학생이에요. | **아니요**, 학생이 아니에요. |
| 몽골 사람이에요**?** | **네**, 몽골 사람이에요. | **아니요**, 몽골 사람이 아니에요. |

> **핵심 도식**: 한국어 의문문은 **낱말 순서를 바꾸지 않는다.** 끝을 올리기만 하면 질문이 된다. `평서문 + ↗ = 의문문`

#### ③ ⚡ 몽골어 거울 〔원어민 검수 필요〕

```
✅ 같은 점
   어순을 바꾸지 않고 묻는 방식이 있다는 점이 한국어와 통한다.
   (영어는 "Are you...?"로 순서를 바꿔야 한다 — 한국어가 더 쉽다.)

⚠️ 다른 점
   한국어의 "아니요"는 질문 자체를 부정한다.
   "학생이 아니에요?"라는 질문에 답할 때 헷갈리기 쉽다 → 6과에서 다시 다룬다.
```

## ④ 문법 카드 변주 샘플 — 4과 「-아요/어요」 (활용형 카드)

> 2과는 "결합형"(받침 유무) 카드였다. 4과는 **활용형** 카드로, 표가 더 커진다. 포맷이 문법 유형에 따라 어떻게 변주되는지 보여주는 샘플이다.

#### ① 형태 FORM

| 어간 끝 모음 | 붙이는 것 | 예 |
|---|---|---|
| **ㅏ, ㅗ** | **-아요** | 가다 → 가**요** · 보다 → 봐**요** · 살다 → 살**아요** |
| **그 밖의 모음** | **-어요** | 먹다 → 먹**어요** · 읽다 → 읽**어요** · 마시다 → 마셔**요** |
| **하다** | **해요** | 공부하다 → 공부**해요** · 운동하다 → 운동**해요** |

> **줄임 규칙(별색 박스)**: 가 + 아요 → **가요** (같은 소리는 겹치지 않는다) · 보 + 아요 → **봐요** · 마시 + 어요 → **마셔요**

#### ③ ⚡ 몽골어 거울 〔원어민 검수 필요〕

```
✅ 같은 점
   동사가 문장 맨 뒤에 온다 — 몽골어와 같다.
   저는 밥을 먹어요.  (나 - 밥 - 먹다)

⚠️ 다른 점
   한국어 동사는 뒤에 붙는 것에 따라 모양이 바뀐다(활용).
   어떤 모음이 오느냐에 따라 -아요와 -어요가 갈린다.
   몽골어에도 모음조화가 있으니 개념 자체는 낯설지 않다 —
   다만 한국어는 "어간의 마지막 모음"만 본다.
```

> **집필 메모**: 몽골어에도 모음조화(남성/여성 모음 대립)가 있다는 점은 이 교재의 강력한 설명 자산이다. 단, 한국어 모음조화와 작동 방식이 같지 않으므로 **"개념은 익숙하되 규칙은 다르다"** 선에서만 쓴다. 과잉 일반화하면 오히려 오류를 유발한다 — 원어민·교사 검수에서 이 수위를 확인할 것.

#### ④ ⚠️ 이런 실수

```
✕ 저는 밥을 먹아요.     → ⭕ 먹어요.      (먹 = ㅓ → 어요)
✕ 저는 공부어요.        → ⭕ 공부해요.    (하다 → 해요)
✕ 저는 학교 가요.       → ⭕ 학교에 가요.  (방향 '에' 필요)
```
