### 🔑 대조표의 「가져올 것이 없다」는 절반만 맞았다

`docs/노션_대조_2026-08-04.md` §4-④는 마케팅 기획 25종을 **"이미 저장소가 더 앞서 있다 · 가져올 것이 없다"**로 판정했다. 실제로 대조해 보니:

- **맞는 쪽** — `.claude/skills/synk-content/references/` 아래 **대본**은 노션보다 확실히 앞서 있다(한·몽 병기·캐논 규칙·개별 편수까지).
- **틀린 쪽** — 노션 기획서가 갖고 있던 **제작·운영 가이드는 저장소에 없다.** 「재미 장치」·「출연·제작 팁」(스타일링·배경·자막 원칙)·「운영 팁」(주 2~3회 업로드·시리즈 넘버링·심화편 확장) — 이 어휘들은 `.claude/skills/` 전체에서 **0건**이다.
- 판정이 갈린 이유 = **주제 이름으로 대조했기 때문이다.** 「리드크루 클립」 폴더가 있으니 있다고 봤는데, 있던 것은 *무엇을 말하는가*(대본)였고 없던 것은 *어떻게 찍는가*(가이드)였다. §2 머리에 적힌 교훈 — 「목록 자체가 든 정보를 빠뜨리지 않는다」 — 이 한 번 더 반복됐다.

✅ **2026-08-04 승격 완료 (유호님 "마케팅 가이드 11건 synk-content로 승격해줘")**
