## ⚠ 유호 확정 필요 리스트

**결정 완료 ✅**

1. 메인 룸 브랜딩 → **SYNK로 통합** (서브브랜드 없음). 네온사인·로고·해시태그 전부 SYNK.
2. 성장 인정 장학금과 굿즈는 **별개** — 장학금 CU카드 5만₮(장학 예산) / 한정판 굿즈는 자체 제작 굿즈에서 별도 지급(굿즈 예산). ☐ 남은 것: 굿즈 월 3점 생산 단가 산정.
3. 포인트 경제 → **검증 완료, 통일안 확정**. 할인권 환급률 매출의 ~2%로 건전. ☐ 남은 것: 개원 후 실제 적립 속도로 재점검.

**입력 필요 (배포 전)**

1. **연락 채널** — 01·09에 상담 문의 블록 삽입 완료(구조). ☐ 유호 입력: ① 페이스북 페이지 URL ② 전화번호 ③ 주소 ④ 상담 시간.
2. '8개 클래스 자유 선택'(01) — 실제 개설 클래스 수와 일치 확인.

**오픈 전 확인**

1. 유학(03) 3트랙 세부 약속(인턴십·오디션·기획사 네트워킹) 이행 가능 범위.
2. 크루 핸드북(04): 주말 당직 보상 명시 여부 / S~D 상대평가가 개원 초기 소수 인원에 현실적인지 / 몽골 노동법 정합.
3. QR 출석(05) — 이미 구현돼 있으면 ✅ 승격.
4. 온라인 결제(05) — QPay 등 몽골 현지 결제 검토.
5. 24시간 플랫폼·실시간 Q&A(02) — 오픈 시점 제공 가능 여부.
6. TOPIK 응시료 현지 금액 확정(02B).

**번역·시공 단계**

1. 프로그램명 몽골어 표기 원칙(음차 vs 의역) — 에리카쌤 검수 전 확정(09).
2. 브랜딩 월 문구 + 브랜드 컬러(골드/퍼플) 공식화(07).
3. 설명회 통역 방식 — 08은 순차통역 전제. 동시통역이면 조정.
