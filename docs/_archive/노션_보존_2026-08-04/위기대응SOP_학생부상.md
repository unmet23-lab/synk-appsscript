# 학생 부상

## 학생 부상

> ⚠️ 부상은 **속도가 생명**입니다. 심각하면 연락보다 응급조치가 먼저입니다.
> 

### ① 즉시 할 일

- [ ]  부상 정도를 **빠르게 판단**한다
- [ ]  **경미** → 구급상자로 응급처치 후 안정
- [ ]  **심각** → 즉시 **103(구급) 호출 또는 병원 이송** (이게 최우선)
- [ ]  동시에 다른 크루가 **보호자에게 연락**

### ② 후속 조치

- [ ]  사고 경위를 상세히 기록 (**시간·장소·목격자·조치 내용**)
- [ ]  보호자에게 상황을 **투명하게** 공유
- [ ]  병원비 등 책임 소재 확인

### ③ 예방

- 등록 시 받은 **보호자·비상 연락처를 항상 즉시 조회 가능**하게 유지
- K-댄스 등 몸을 쓰는 활동은 **준비운동·안전 공간** 확보
- **학원 상해보험** 가입 검토 (몽골 내 가능 여부 확인)
