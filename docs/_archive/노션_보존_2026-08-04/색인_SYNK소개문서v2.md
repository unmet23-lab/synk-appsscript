## 이 판본에서 달라진 것

- **형식**: 메모장 저장을 전제로 한 순수 텍스트 원본(마크다운 기호 없음). 노션 판본은 읽기 편하도록 제목·구분선만 노션 형식으로 옮겼고 **문장은 원본 그대로**입니다. 원본 .txt는 바탕화면 각 브랜드 폴더에 있습니다.
- **목소리**: 딱딱한 기업 문어체 대신 트렌디한 30대 창업자의 말투. 문서마다 유머 1~3회 배치.
- **고객 니즈 중심**: 특히 LAB 소개서는 학부모·학생이 실제로 겪는 다섯 장면을 먼저 보여주고, 각 장면의 결말을 SYNK 방식이 어떻게 다시 쓰는지 1대1로 대응시키는 구조로 재설계했습니다.
- **신규 2종**: FAQ, 읽는 순서.
- **홍보 트리오 교체(2026-07-22, 유호님 확정)**: 대외 문구를 「질문하는 힘 · 스스로 하는 힘 · 마음을 얻는 힘」으로 통일(각각 문제 정의력 · 주도성 · 커뮤니케이션+신뢰관계). 구 3종은 심층 뿌리층으로 이동. 사유 — 감응력·공감능력이 일반 독자에게 겹쳐 들리고, 낯선 한자어라 몽골어 번역 시 구분이 사라지며, 학부모의 실제 불안("스스로 못 하는 아이")에 대응하는 축이 없었다. 생태계 갭 리포트 G24 해소.
- **설득 업그레이드(2026-07-22)**: 뻔한 예시·비유 13곳을 SYNK 실물·몽골 로컬 구체성으로 교체(forge A/B→게이트→병합). 대표: LAB 클로징이 세종학당·가격을 먼저 언급하는 정직 포지셔닝으로, IP 장부는 창업자 자신을 키맨 리스크로 지목, 반 구성에 자유 클래스·2부제 대응 추가.

## 잠근 것 (변경 시 8종 동시 수정)

- **구조**: 3브랜드(LAB·STUDIO·LIFE) + 2레이어(IP·COMMON SYSTEM). 구 6브랜드·'SYNK Studio(기록)' 3계층 표기는 폐기.
- **슬로건**: "점수를 넘어, 삶을 설계합니다" / 코어 메시지 "배움을 방향으로, 경험을 가능성으로"
- **공통 사이클**: Learn → Plan → Experience → Record (화살표 표기로 통일)
- **세 가지 힘**: 질문하는 힘 · 스스로 하는 힘 · 마음을 얻는 힘 (2026-07-22 확정. 회사 공통, 특정 브랜드 소속 아님. 순서 고정 = 정하고→움직이고→얻는다). 구 표현 **감응력·협응력·공감능력은 폐기가 아니라 철학 심층의 뿌리층**으로 이동 — 대외 문서에는 쓰지 않는다. 정본 = repo `docs/홍보_트리오_정본_v1.md`
- **시그니처 4종**: 나침반 세션·드림맵 카드 / K컬처 워밍업 / 싱크 크루 / 싱크 포트폴리오 — 철학 4개와 1대1
- **과학 주장 3건만**: 네이퍼빌 0교시 체육(읽기·이해력 17% 보고) · 존 레이티 『운동화 신은 뇌』 · 막스플랑크 제스처-어휘 연구. 전부 귀속 표현 필수. LAB에 2건, FAQ에 1건으로 분산 배치.
- **금칙어 8종**: 기업마스터 제6조의 정의 줄 1곳만 의도된 예외. 나머지 7종에는 0건.
- **성과 보장 표현 금지**: LAB 소개서가 "성과를 보장한다고 말씀드리지 않겠습니다"로 명문화.
