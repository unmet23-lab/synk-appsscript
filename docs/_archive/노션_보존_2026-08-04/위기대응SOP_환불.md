# 환불

## 💸 환불 요청

### ① 즉시 할 일

- [ ]  환불 사유를 확인한다 (감정적으로 대응하지 않기)
- [ ]  등록 시 서명한 **입소서류의 환불 규정**을 근거로 계산

> **환불액 = (총 결제액 × 50%) × (남은 기간 ÷ 전체 기간)**
> 
> 
> 예: 6개월 600,000₮ → 3개월 후 = (600,000 × 50%) × (3÷6) = **150,000₮**
> 

### ② 후속 조치

- [ ]  계산 내역을 **서명한 서류를 근거로** 명확히 설명
- [ ]  합의 후 환불 처리
- [ ]  **환불 기록 남기기** (언제 / 얼마 / 사유)

### ③ 예방

- 등록 시 환불 규정을 **구두로도 반드시 설명** 후 서명 (분쟁 예방)
- 환불이 잦은 반·시기가 있으면 **원인 분석** (수업 불만? 난이도?)
