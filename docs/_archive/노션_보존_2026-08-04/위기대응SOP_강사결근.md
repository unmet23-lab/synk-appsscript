# 강사 결근

## 리드크루(강사) 결근

### ① 즉시 할 일

- [ ]  결근 리드크루의 **오늘 수업·반**을 확인한다
- [ ]  **백업 리드크루**가 있으면 즉시 대체 투입
- [ ]  대체 불가 시, 해당 반 학생·학부모에게 **최대한 빨리** 휴강/보강 안내
- [ ]  결근 사유(질병 등)를 확인하고 기록

### ② 후속 조치

- [ ]  빠진 수업은 **반드시 보강 일정**을 잡아 학생 손해 방지
- [ ]  잦은 결근일 경우 해당 리드크루와 면담

### ③ 예방

- 리드크루별 **백업 담당**을 미리 지정 (예: 인우쌤 결근 → 재헌쌤 커버)
- 결근 연락 규칙 정하기: **몇 시간 전까지 / 누구에게 / 어떻게**
