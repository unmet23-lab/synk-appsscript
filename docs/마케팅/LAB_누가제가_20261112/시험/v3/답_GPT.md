# GPT 시험관 답 · 구독(Codex) · 2026-11-12T07:27:17.728Z

1. 이 영상이 말하려는 것 — “누가 먹었어?”처럼 사람을 물으면 ‘제가’로 나라고 답하라는 영상이야.

2. 보고 나서 내가 바로 할 수 있게 된 것 — “Who ate the pizza?”에 ‘제가요’라고 따라 답하기.

3. 무슨 말인지 모르겠던 낱말·장면 — 0~3초 손글씨 답의 전체 뜻은 모르겠다. 8.5초 ‘As for me’는 언제 쓰는지, 16.9초 ‘제가요’에는 왜 ‘요’가 붙는지 모르겠다.

4. 넘겼을 것 같은 초와 까닭 — 끝까지. 같은 답인데 하나만 틀린 이유가 궁금하다. 다만 3~7초는 화면 변화가 적어 기다리는 느낌이다.

5. 이해 점수 — 3/5. 이 피자 질문에는 ‘제가’를 쓰겠지만, 다른 대화에서 둘을 고를 자신은 없다.

6. 재미 점수 — 2/5. 빨간 X가 나올 때는 궁금하지만, 이후는 수업 설명 같고 마지막에도 웃을 만한 일을 못 찾았다.

7. 처음 3초만 보고 넘기겠나 — 계속 봄. 똑같이 쓴 답에 정반대 표시가 붙으니 채점 이유를 듣고 싶다.

8. 저장하거나 누구에게 보내겠나 — 저장. 두 표현을 다시 듣고, 질문과 답을 나란히 보며 복습하려고.

9. 비교용 묶음과 견주어 같은 틀인가 — 달라 보임. 앞선 두 편은 인물들이 물건을 오해하거나 다투는 사건 사이에 설명이 들어가고, 농담이나 댓글 요청으로 끝난다. 이번은 시험지 두 답 비교→오답 교정→복습 순서다. 머리 글도 상황극의 대사 대신 퀴즈를 예고한다.
