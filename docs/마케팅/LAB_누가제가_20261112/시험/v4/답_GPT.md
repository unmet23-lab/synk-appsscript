# GPT 시험관 답 · 구독(Codex) · 2026-11-12T07:34:39.923Z

1. 이 영상이 말하려는 것 — 한국어로 “누가 먹었어?”에 “나!”라고 답할 때는 ‘저는’ 대신 ‘제가’를 쓰라는 거야.
2. 보고 나서 내가 바로 할 수 있게 된 것 — “Who ate the pizza?”라는 질문에 “제가!”라고 답하기.
3. 무슨 말인지 모르겠던 낱말·장면 — 0~3초: 한국어 손글씨 문장을 바로 읽기는 어려웠다. 8~12초: ‘about me’와 ‘It was ME!’의 느낌 차이는 알겠는데, 왜 ‘저는’에는 X까지 붙는지 모르겠다.
4. 넘겼을 것 같은 초와 까닭 — 6초쯤. 같은 시험지에 표시만 늘어나서, 처음 생긴 궁금증보다 설명을 기다리는 느낌이 커졌다.
5. 이해 점수 1~5 — 3점. ‘Who? → 제가’는 기억하지만 ‘저는’을 언제 쓰는지는 아직 흐릿하다.
6. 재미 점수 1~5 — 2점. 같은 답에 다른 채점이 나오는 건 궁금했지만, 이후에는 수업 같다. 피자가 줄어드는 건 소소한 장난 정도다.
7. 처음 3초만 보고 넘기겠나 — 계속 봄. 똑같이 썼는데 두 번째만 틀렸다는 반전의 이유가 궁금하다.
8. 저장하거나 누구에게 보내겠나 — 안 함. 기억할 요령은 하나이고, 친구에게 보내고 싶을 만큼 웃기지는 않았다.
9. 비교용 묶음과 견주어 같은 틀인가 — 달라 보임. 이전은 인물 사이에 소품을 놓고 오해를 벌인 뒤 소파 농담이나 이름 질문으로 끝난다. 이번은 시험지 위아래 문장 비교→채점→고쳐 쓰기 순서이며, 규칙을 정리하고 “제가…”로 끝난다.
