# 그록 시험관 답 · 구독(grok CLI) · 2026-11-12T07:37:26.536Z

1. 뭐를 물으면 저는 피자 먹었어요가 맞고, 누가 물으면 같은 말이라도 제가 피자 먹었어요라고 해야 한다는 거야.
2. "누가 피자 먹었어요?"에 "제가 피자 먹었어요"라고 받아 말하는 것. 피자 말고 다른 말은 아직 못 만듦.
3. 4초에서 6초 사이, 말은 "number one, what / number two, who"인데 화면은 아직 same answer 스티커라 어디가 1번인지 바로 안 보임. 8초 화살표는 작아서 못 읽음. 말은 "저는"인데 그 글자는 없음. 10초 손글씨는 흘려서 저는와 제가 중 무엇이 지워진 글인지 못 읽음. 7.95초·9.68초 "저는/제가"는 소리가 비슷해 귀로 구분 못 함. 16초 "제가 = Who? → Me!"는 제가가 누구인지 나인지 모르겠음. 18.3초 "제가...(me...)"가 끝인지 따라 하라는 건지 모름.
4. 끝까지. 1.5초에 같은 답에 X가 나와 이유가 궁금했고, 18초라 길지 않음.
5. 3. 영어 표기로 뭐와 누구가 다르다는 건 알겠는데, 는과 가를 왜 바꾸는지와 끝 공식은 한 번에 안 들어옴.
6. 3. easy 하다가 틀리고 피자를 한 입 베어 문 건 웃기지만, 6초부터 동그라미 설명은 수업이라 친구에게 보여 주고 싶진 않음.
7. 계속 봄. 1.5초에 똑같은 답에 빨간 X가 떠서 이유가 궁금함.
8. 저장. 손글씨를 다시 보려고. 보낼 만큼 재밌진 않음.
9. 달라 보임. 이번 화면은 흰 시험지에 연필과 피자가 놓이고, 틀린 답을 고친 뒤 저는/제가 공식으로 끝남. 말은 맞혔다, 틀렸다, 고친다 순서. 지난 두 편은 사람이 있는 장면 위에 단어 카드를 붙이다가, 하나는 소파 농담으로, 하나는 이름을 묻는 댓글 카드로 끝남.
