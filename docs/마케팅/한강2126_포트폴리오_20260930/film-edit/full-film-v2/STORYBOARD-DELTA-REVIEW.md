# 원래 콘티와 신규 실사 영상 차이

2026-09-30, 사용자 정정 뒤 읽기 검토. 원본 정지 이미지와 실제 신규 영상의 프레임 시트, 제출 프롬프트를 직접 확인했다. 이 문서는 이미지의 승인 범위를 새로 확정하지 않는다. 현재 폴더 밖의 콘티 원문·소스는 수정하지 않았다.

## 유지해야 할 기준

- 첫 주인공 기준: [첫 4컷](../../review/opening-contact-sheet-v1.png). 본인 얼굴, 콘로우 머리, 차콜 셔츠 재킷·흰 티셔츠·검은 가방, 오른손 커피 한 컵·왼손 휴대폰 한 대·VR 한 개·까몽 한 개.
- 실제 얼굴 원본: `../../../LAB_카페_다시말해주세요_20260926/yuho-interview-face/interview-75s.png`, `interview-165s.png`. 처음 프롬프트는 동일 실제 남성의 얼굴 구조를 보존하도록 명시했다.
- 이후 사용자 수정: VR 착용 상태의 게임으로 시작, 휴대폰도 같은 한국어 레이싱, 까몽은 윙크 대신 양눈 깜빡임. 초기 4컷의 이마 위 VR·휴대폰 건물 반사로 되돌리지 않는다.
- 1층: [입장·PULSE·몽글 v4](../../review/entry-pulse-contact-sheet-v4-mongle-robot.png)의 세트·펜 디스플레이·음악 작업·몽글 벽 전시와 소통. PULSE T2V는 사람의 실사 질감 기준이다.
- 2층 활동: [SHIFT 업무 미션](../../review/shift-2126-ai-mission-v1.png). 옛 [계단·창가 네 컷](../../review/stairs-shift-contact-sheet-v3-brand.png)은 이동 구도 참고이며, 노트북 강의·서류 활동으로 회귀하지 않는다.
- 3층 활동·구도: [LAB 미션 v3](../../review/lab-path-2126-language-quest-v3-no-korean-text.png), 동일 구도 질감 후보 [photographic v2](../../review/lab-path-2126-photographic-v2.png). 옛 카페·메뉴판·바인더 활동은 제외한다.
- 순서: VR 게임 → 몸 기울임·충돌·넘어짐·커피 → VR 근접 → 까몽 깜빡임 → 휴대폰 게임 → 건물 입장 → PULSE → 계단 → SHIFT → 창가·유람선 → 아기 수달 → 같은 3층 창 접근 → LAB+PATH → 마무리.

## 확인된 변경

| 구간 | 원래 콘티에서 유지할 내용 | 신규 결과·프롬프트에서 달라진 내용 | 판단 |
|---|---|---|---|
| 오프닝 | 첫 4컷의 본인 얼굴·의상·소품, 충돌·불균형·커피 순간과 근접 구도 | 새 `opening-real-stumble-v2` 프롬프트는 사람 참조를 배제하고 일반적인 한국인 남성으로 명시했다. 실제 프레임은 VR로 얼굴 대부분을 가려 본인 일치가 확인되지 않는다. 0–2초는 걷는 장면이 대부분이고, 낮은 자세·컵 기울임으로 진행해 원래 분명한 넘어짐·커피 호의 구도와 다르다. | 얼굴 입력을 복구하고 기존 구도·행동을 보존한 수정 필요. 질감만 바뀐 결과가 아님. |
| PULSE | 원래 넓은 베리 제작실, 펜으로 만드는 화면·음악 편집·몽글 소통 | 현재 5초 후보는 한 명의 여성 작가 근접 연기 중심이며, 원래 세트와 전체 작업의 대체 컷으로 승인된 기록이 없다. | 질감 참고로만 유지. 이 5초를 자동 삽입하지 않음. |
| SHIFT | 전경 전체의 입체 도시 배송 시뮬레이션, 함께 경로를 바꾸는 3인, 큰 펠트 로고, 마린의 실행 결과 전달 | 신규 영상은 평면 지도 모니터·두 명의 탁자 장면·작은 명패로 바뀐다. 창밖도 원래 미래 정원도시의 곡면 창 전경 대신 현재 아파트형 강변으로 보인다. 새 프롬프트부터 `INSET tabletop display`와 2인 세트로 변경됐다. | 현대적인 도구로 되돌아감. 공간·활동·구도 모두 원본과 다름. |
| LAB | 3인이 함께 파란 퍼즐을 연결, 큰 생태 수로 복원, 시뮬레이션 수달 보상, 앞쪽 몽글의 그림 힌트, 같은 프레임의 LAB/PATH | 신규 영상은 여성·외국인 남성 2인과 세라믹 구형 조각, 작은 직선 탁자 수로로 바뀜. 수달 보상·몽글 힌트·지도자가 빠졌고 배우·옷·배치도 변경됨. 새 프롬프트가 이 변경을 먼저 지시했다. | 협동 미션과 보상이 축소·대체됨. 질감만 수정한 안이 아님. |
| PATH | 같은 생태 공간 뒤 아치에서 전공 체험·생체모사 드론, 전경 LAB과 공간적으로 연결 | 신규 5.5초 이후는 다른 테이블에서 작은 장비를 조작하는 별도 컷. 원래 아치·전경 LAB 관계가 사라지고, 대상 장비도 다른 형태다. | 원본 구도를 먼저 보존한 세트 연속성 복구 필요. |
