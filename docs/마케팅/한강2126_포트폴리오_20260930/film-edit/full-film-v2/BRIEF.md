## Intent

사용자가 “VR 오프닝부터 끝까지 오늘 전부 진행”을 승인했으나, 최신 정정은 **기존 콘티의 구도·행동·순서를 유지하고 주인공은 앞선 4컷의 본인 얼굴을 유지**하는 것이다. 두 번째 PULSE 영상은 실사 질감 기준만 승인됐다. 새 오프닝·SHIFT·LAB이 장면 내용까지 바뀌었으므로 **현재 전체 조립·렌더는 보류**한다. 준비된 편집 도구와 원본은 보존한다. 담당자의 수정된 소스·범위 지시 후 재개한다.

기존 `../`의 58초 중단안과 `../pilot-cut/`은 보존한다. 이 `full-film-v2/`는 준비 상태로 보존하는 편집 프로젝트다. 이전 거절된 LAB 영상이나 새 배우를 원본 콘티의 대체 장면으로 자동 사용하지 않는다.

## Assets

- `../../video/pulse-approved-human-brand-background-with-source-audio-v1.mp4` — PULSE 5초 기술 미리보기에 사용했다. 실사 질감 기준이며 전체 콘티 대체 장면으로 승인된 것은 아니다.
- 신규 약 7초 소스 네 개 — 주 작업자가 생성·검토 후 파일과 범위를 제공한다.
- 기존 VR·마스코트·휴대폰 인서트와 강·수달 소스 — 주 작업자가 QA한 범위만 사용한다.
- `../../inputs/synk-approved-logo.png` — 정본 로고. 끝카드에는 실제 파일을 사용한다.

## Customizations

- 9:16, 1080×1920, 24fps. 전체 목표 약 48–56초이며 최종 구간으로 실제 길이를 계산한다.
- 리드미컬한 컷, 짧은 행동→결과→반응. 불필요한 정지·긴 이동·느린 연기를 편집에서 줄인다.
- 한국어 게임 단서 “학교”가 명확히 들려야 한다. PULSE의 원본 대사는 유지한다.
- 최신 확정: 별도 음악을 추가하지 않고 생성 소리·효과음 중심으로 구성한다. PULSE 원본 대사와 게임의 “학교” 큐를 명확히 유지한다.
- 생성한 한글 이미지 대신 실제 정본 로고를 사용한다. 소스 인물에 새 생성 얼굴이나 임의 얼굴 처리를 적용하지 않는다.
