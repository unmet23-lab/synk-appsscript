## Intent

검토 중인 실제 생성 MP4 다섯 구간을 영화처럼 연결하기 위한 편집 프로젝트다. 이번 작업 범위는 로컬 편집 구성과 자산 연결 준비까지다. 최종 영상 제작이나 렌더 완료가 아니다.

**현재 중단:** 사용자가 Seedance 2.5 LAB 파일럿을 직접 보고 너무 느리고 따분하며 품질이 낮고 AI 티가 난다는 이유로 거절했다. 기존 방향 전체의 최종 조립은 중단한다. 영화 촬영 같은 질감과 짧은 행동→결과→반응의 새 파일럿으로 전면 수정한 뒤 편집 방향을 다시 정한다. 기존 소스는 기록으로 보존하며 최종 채택하지 않는다.

## Assets

- `../video/lab-path-cinema-pilot-10s-seedance25-v1.mp4` — 사용자 거절된 Seedance 2.5 LAB 후보. 비디오 10.041667초, 오디오 포함 파일 10.05초, 1080×1920, 24fps, HEVC+AAC로 확인했다. 기록으로 보존하며 현재 타임라인에서는 제외한다.
- opening 10초, PULSE 12초, SHIFT 12초, river 14초, LAB 10초 — Seedance 2.5 후보 생성·다운로드·내용 검토 후 교체할 예정. 미도착 파일은 가짜 MP4나 정지 이미지로 대체하지 않는다.
- 상위 프로젝트의 `영상_콘티.md` 및 승인 이미지 — 내용과 브랜드의 원문. 여기서는 별도 변경하지 않는다.

## Customizations

- 1080×1920, 24fps, 총 58초는 편집 준비용 잠정 값이다. 실제 소스 길이·동작·컷 연결 검토 후 조정한다.
- 소스 구간을 자르고 hard cut으로 연결한다. 추가 시각 효과·타이틀·자막·확대·속도 변경은 만들지 않는다.
- 마지막은 LAB 안의 배우 반응으로 마친다. 끝카드를 추가하지 않는다.
- 원본 오디오는 별도 트랙에 같은 source in/out으로 연결하되, 듣기 검토와 최종 음향 결정은 아직 하지 않는다.
