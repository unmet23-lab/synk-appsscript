# SYNK 2126 한강 브랜드필름 · 제작 콘티

## 최신 실행 방식 — 인터뷰 원본 + 없는 동작 AI

**후속 품질 판단:** 4초 인터뷰 배경 합성은 사용자에게 인물과 배경이 따로 논다는 이유로 거절됐다. 해당 원본 합성을 본편에 우선 채택하지 않는다. 추가 촬영 불가·기존 인터뷰 활용 가능·짧은 컷 분할은 유지한다. 인터뷰는 Soul ID 학습 후보 사진과 얼굴/연기 참조로 활용하는 경로를 검토하고, 인물과 공간이 같은 조명·렌즈 안에 있는 AI 장면을 우선 시험한다. Soul ID 사용은 의견 제안이며 학습·신규생성 미실행.

2026-10-01 사용자는 전체 장면을 나누는 작업을 요청했고, 추가 촬영은 어려우므로 기존 인터뷰의 쓸 만한 부분을 사용하고 나머지를 AI로 만들도록 확정했다. [47초·25개 분할 콘티](실촬영_분할콘티_20261001.md)가 현재 촬영·편집 실행안이다. 기존 이야기·주연·브랜드를 이어받고, 컷 수와 유료 생성 수는 구분한다.

[4초 표정 보존 시험](video/real-actor-composite-4s-v1/README.md)을 완료했다. 실제 인물 RGB와 미소를 유지한 로컬 배경 합성,480p·무음·96프레임이며 끝 재생 확인. 머리카락 경계·조명은 아직 최종 기준 미달이고 인터뷰 의상도 다르다. 사용자 검토 후 없는 동작을 짧은 AI 컷으로 한 건씩 확인한다. 새 사진 후보에 대한 앞선 미승인을 이 시험 승인으로 확대하지 않는다.

2026-09-30 사용자 승인: 확장 콘티에 대해 “오케이 콘티는 나왔으니 영상 만들어줘”. 이후 비용 확인 뒤 “우선 이미지 시안부터 검토하자”를 선택했고, [첫 4컷 시안](review/opening-contact-sheet-v1.png)의 인물·의상·소품·배경 시각 방향을 승인했다. 당시 추가한 윙크 요청은 최신 답변 **“오케이. 깜빡이는것만 해줘 윙크 대신에”**로 교체됐다. 현재 까몽이 근접 동작은 **양눈을 동시에 짧게 1회 깜빡이기**다. 당시 장면별 이미지 검토를 진행했고, 최신 요청에서는 처음 승인한 남자 얼굴과 기존 콘티를 유지하며 실사 질감을 개선한다. 아직 만들지 않은 장면과 영상의 동작·재생 결과가 승인된 것은 아니다.

## 2026-10-01 실사 촬영감 재설계 제안

**후속 평가:** 새 남자 기준 사진에 사용자는 “좋아졌지만 아직 AI 같아”라고 답했다. 사진은 목표 미달이며 채택하지 않는다. 다음 시험안은 PULSE처럼 소박한 배경·방향성 있는 자연광·작은 시선 반응의 영상 연기를 먼저 확인하는 것이다. 실제 비용 집행·생성은 하지 않았다. 전체 이야기 변경 대신 넘어짐의 원인/컵/발/얼굴 반응을 나누는 촬영 콘티 수정이 필요하다는 판단이며, 세부 컷은 아직 제안이다.

사용자는 후속 480p 영상도 AI 느낌이 많이 남는다며 PULSE 여성 장면 수준의 사람 질감을 다시 요구했다. 이야기·주연 정체성·장면 순서를 유지하면서 **빛·시작 자세·한 컷의 행동 수를 다시 설계**한다. 기존 일러스트 같은 몸·커피·노을까지 픽셀 수준으로 고정하는 것이 얼굴과 콘티 보존을 뜻하지 않는다. 구체적인 컷 변경은 아직 채택 전 제안이다.

- [새 인물 촬영 기준 사진](review/opening-live-action-look-reset-v1.png): 실제 인터뷰를 얼굴 기준, 승인 남자 시안을 의상·VR 기준, PULSE를 촬영 질감 기준으로 만든 한 장. 평범한 서 있는 자세와 컵 안의 커피, 절제된 빛으로 비교한다. VR을 올린 것은 얼굴 평가용이며 본편 오프닝 행동 확정이 아니다. 사용자 미승인.
- 다음 영상의 선행 조건은 짧은 시선 이동·작은 반응의 자연스러움이다. 복잡한 넘어짐·커피·얼굴·이동을 한 번에 재생성하는 대신 원인 동작 → 컵/발 근접 → 얼굴 반응의 컷 분할을 제안한다. 서사의 사건과 속도감은 유지하며 연결은 매치 컷·짧은 시간 강조·가림 전환으로 구성한다.
- 컵 뚜껑·빨대 등 새 이미지의 세부 소품은 연속성 확정값이 아니다. 이번 작업은 이미지 후보 1장이며 영상 연기·VFX 완성이나 최종 실사감 달성으로 표시하지 않는다. Higgsfield 영상 추가 차감 없음.

## 최신 연출 방향 — 시각효과를 적극 활용한 컷 리듬

2026-09-30 사용자 추가 요청: **장면을 만들 때부터 비주얼 이펙트를 적극 활용하고, 컷 편집이 재미있으며 지루하지 않게 구성한다.** PULSE의 실제 영화 같은 인물·빛, 승인된 본인 얼굴, 기존 콘티의 구도·사건·순서는 함께 유지한다. 아래 효과와 시간은 이 방향을 구현할 **구체적인 연출 제안**이며, 생성·편집·재생 검증 완료를 뜻하지 않는다.

### 효과를 많이 쓰면서 실사감과 비용을 유지하는 방법

- **생성 전:** 컷마다 ‘행동 시작 → 효과가 발생할 사건 → 다음 컷으로 넘길 방향’을 적는다. 시작·효과의 정점·도착 장면을 사진 시안에서 확인한다. 카메라가 새로 봐야 할 공간과 가려지는 물체도 먼저 정한다.
- **생성에 맡길 부분:** 실제 몸 움직임, 물체의 낙하, 가상 공간을 통과하는 큰 카메라 이동처럼 소스 자체가 필요한 부분. 한 컷에 여러 개의 복잡한 사건을 동시에 주문하지 않고 필요한 구간부터 만든다.
- **편집에서 만들 부분:** 속도 변화, 짧은 확대, 동작 매치 컷, 전경 가림 전환, 화면 합성, 경로 반응, 효과음. 기존 영상에 가능한 효과를 우선해 전체 재생성을 줄인다. 편집·추적·합성의 작업 시간은 별도다.
- **리듬:** 강한 전환 뒤에는 얼굴·미션 결과·브랜드가 읽히는 짧은 순간을 둔다. 효과의 크기와 속도에 변화를 주고, 같은 확대·흔들림을 모든 컷에 반복하지 않는다. 위 시간은 첫 편집에서 실제 재생으로 조정한다.
- **인물 일관성:** 효과를 배경·게임·소품·카메라에 배치하고 얼굴의 형태가 바뀌는 전환은 사용하지 않는다. 피부·눈·치아·헤어가 변하면 해당 결과를 채택하지 않는다.
- **검토:** 효과 전·정점·후 사진으로 방향과 얼굴을 확인한 뒤 실제 속도로 영상과 소리를 확인한다. 효과를 넣었다는 사실만으로 재미·품질 통과를 선언하지 않는다.
- **비용 범위:** 한 번에 한 컷, 기존 소스 재사용, 표시 비용 확인 방침을 유지한다. VFX 적극 활용 요청은 효과 후보마다 새 유료 영상을 여러 개 생성하라는 지시로 확대하지 않는다. 특정 Higgsfield 프리셋의 실제 지원 여부·가격은 선택 시 확인한다.

## 목적과 제작 상태

- **최신 4초·480p 시험:** [오프닝 v2](video/opening-480p-v2.mp4)를 77 계정에서 한 건 생성했고 실제 12크레딧 차감을 확인했다. [검수 기록](video/opening-480p-v2.status.json). VR은 눈 위에 유지되지만 몸이 공중에 앉아 미끄러지는 느낌과 초반 커피의 굵은 호가 남아 실사 제작 기준 미달·사용자 검토 전이다. 전체 콘티를 바꾸기 전에 같은 인물·세트·구도에서 사고 직전의 지지 자세와 컵 안 커피를 시작 사진으로 준비하는 안을 제안한다. 추가 생성·고해상도 승격은 하지 않았다.

- **최신 얼굴·실사 질감 시안 승인:** 사용자는 [기존 얼굴을 유지한 오프닝 시안 v1](review/opening-identity-preserved-texture-test-v1.png)에 “얼굴도 맞고 질감도 좋음”이라고 명시적으로 승인했다. **이 정지 컷의 얼굴과 실사 질감이 현재 제작 기준**이며 전체 영상·동작·오디오 승인으로 확대하지 않는다. 처음 승인한 4컷의 동일인과 기존 구도·행동·장면 순서는 유지한다. 남은 기존 콘티도 구도·동작을 보존한 실사 사진 시안으로 준비할 예정이며 아직 제작 완료로 표시하지 않는다.

## 전환 리듬 — 최신 사용자 요청

- **이동은 빠르게, 뜻이 읽히는 행동에는 짧게 머문다.** 공간·풍경·로고만 바라보며 느리게 미는 구간은 줄인다. 아직 실제 편집·재생으로 검증한 리듬은 아니다.
- 대부분의 정보 없는 이동·전환은 0.3–1초 안에서 처리하고, 핵심 동작은 대략 1.5–3초 범위에서 읽히도록 시작한다. 구간 총 길이 안에 여러 속도와 행동이 들어가며 장면 전체를 하나의 긴 느린 줌으로 채우지 않는다.
- VR 속 질문 → 선택 → 부스터는 약 3초 안에 읽히게 시작한다. 충돌·커피 물방울에서만 짧은 감속을 쓰고 이후 VR → 까몽이 → 휴대폰을 약 4초 안에 연결한다. 까몽이의 실제 깜빡임은 약 0.15–0.25초 제안값을 유지한다.
- 세 층 모두 입장·간판·전경·실습 순서를 반복하지 않는다. PULSE는 펜 디스플레이에서 만드는 손과 음악 편집, SHIFT는 함께 해결하는 배송 문제와 실행 결과, LAB+PATH는 한국어 요청·협동 조립·복원 보상과 다음 전공 체험으로 역할을 보여준다. 브랜드 벽사인·색은 같은 구도 안에서 읽히게 한다.
- 창문 → 배 → 수달 → 3층 창 접근은 하나의 흐름으로 묶는다. 수달의 얼굴과 목표 창이 읽힐 순간만 짧게 호흡을 주고 곧바로 전진·상승한다. 창 가까이서 살짝 하강해 실내에 안착하며, 높은 공중 와이드·궤도 회전·최고점 정체는 넣지 않는다.
- 음악의 강세와 커피·발걸음·물소리·대화의 시작을 전환 지점에 맞춘다. 다음 공간의 소리를 도착보다 조금 먼저 들려줘 이동을 이어간다. 음악·음향 자산과 실제 박자는 아직 미선정이다.
- 생성 영상에 행동 전후 여유가 필요하면 원본을 길게 확보한 뒤 편집에서 덜어낸다. 사람의 말·손동작·수달 움직임은 자연스러운 속도로 확인하고, 이동 속도 변화는 카메라 구간을 중심으로 적용한다.
- 영상 검토에서는 첫 3초에 질문·선택·보상이 읽히는지, 게임 조향이 현실 사고로 이어지는지, 각 층의 역할을 한 번에 알아보는지, 같은 풍경·행동이 반복되는지, 전환에서 방향을 잃지 않는지 확인한다.

## 층별 브랜드와 펠트 공간 — 최신 사용자 수정

- 사용자는 층별 브랜드의 색·콘셉트·펠트 벽사인이 빠진 점을 지적했다. 이후 **PULSE 펠트 내부 방향은 승인**하고 **첫 건물 외관은 공통 SYNK만** 표시하도록 수정했다. 건물 외부를 PULSE 전용 시설처럼 표시하지 않는다.
