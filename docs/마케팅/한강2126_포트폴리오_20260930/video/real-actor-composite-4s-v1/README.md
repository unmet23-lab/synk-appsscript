## 실제 사용한 원본과 처리

실제 원본: ../../../LAB_카페_다시말해주세요_20260926/performance-references/upload-ready/yuho-genuine-smile-under10s-compatible.mp4 의 **0–4초**. 카메라 원본의 약18:18–18:22에 해당하는 인터뷰 구간이다. 인코딩 원본은 1920×1080, 59.940fps이며 각 출력 시각에 해당하는 프레임을 24fps로 샘플링했다. 느리게 재생하거나 얼굴 동작을 보간하지 않았다.

- 얼굴·눈·입·치아·몸·의상은 원본 RGB. 인물 색보정, 미용 보정, 얼굴 교체, 새로운 미소 생성 없음.
- 캐시된 ISNet으로 마스크만 계산했다. 1px 침식과 0.6px feather, 충분히 불투명한 내부를 alpha1로 고정. 시간 평균은 적용하지 않았다.
- PULSE 빈 배경 한 장을 내장 image_gen으로 준비했다. [원본 plate](pulse-empty-plate.png), [프롬프트](background-prompt.txt). 생성 모델의 정확한 버전은 도구에서 공개하지 않았다.
- 명암·채도·흐림은 배경에만 적용했다. 세로판은 인물과 배경을 각각 crop해 프레이밍했다.
- 얼굴 표정과 경계만 비교하도록 무음으로 출력했다. 원래 인터뷰 파일·음성은 수정하지 않았다.
- 실사 인물 분리·합성은 로컬에서 처리했다. **Higgsfield 영상 생성 0건, 추가 차감 0크레딧.**

## 확인한 것

- 전체 96프레임에서 인코딩 전 불투명 인물 내부 RGB 차이0, 중앙 얼굴 alpha1.
- 무손실5시점 표본도 내부RGB 차이0. H.264 결과는 압축되므로 바이트 단위 원본 동일 파일은 아니다.

## 남은 품질 문제

- 머리카락·땋은 머리 가장자리에 옅은 테두리가 남는다. 경계 마감 합격으로 표시하지 않는다.
- 원본 인터뷰 빛이 평탄하고 부드러워, 승인 PULSE 여성의 방향성 강한 창가 빛과 같은 촬영감은 아니다. 인물의 원래 표정 보존과 PULSE 수준의 영화 촬영감 달성은 별개다.
- 원본 스포츠 상의는 승인 오프닝 의상과 다르다. 이 시험을 그대로 VR 오프닝으로 채택하지 않는다.
- 배경의 대문자 목재형 간판과 미래성은 임시 look plate이며 최종 소문자/펠트 브랜드 사인으로 승인되지 않았다. 세로판에는 간판이 보이지 않는다.
- 원본에 없는 VR·걷기·손·커피·새 대사는 별도 AI 컷 필요. 이번 합성 시험이 그 AI 동작의 품질까지 검증하지는 않는다.
- 상단의 최신 사용자 평가에 따라 이 합성 시험은 미채택 상태다. 당시 후속안은 [47초 분할 콘티](../../실촬영_분할콘티_20261001.md)에 남기며, 새 제작의 채택 경로는 [프로젝트 입구](../../README.md)에서 확인한다.
