## 사진 처리와 검증

- 추가 처리는 **프레임 추출 → 두상·턱·어깨가 남는 크롭 → JPG 저장**뿐이다. 얼굴 재생성, 미백/미용 보정, 눈 키우기, 좌우 반전, 업스케일은 하지 않았다.
- 크기는 840×1000, 840×1050, 880×1050, 920×1040, 930×1080이다. 실제 해상도를 기록하고 4K 사진으로 부르지 않는다.
- 선택 사진 24개의 파일 해시와 원본 카메라 시각이 모두 다르다. 연속 프레임 중복뿐 아니라 시각적으로 비슷한 포즈도 선별 시 줄였다.
- 웹에서 24개 업로드 이미지가 모두 로드됐고, 이름 YUHO 및 Soul Cinema 모델 선택을 DOM과 화면으로 대조했다.
- 재현 스크립트: `extract_candidates.py`, `finalize_selection.py`. 원본 영상은 변경하지 않는다.

## 미채택 결정 전의 후속 제작 계획

1. 승인된 **Soul Cinema 얼굴 학습 1회(실제25크레딧)**가 접수되어 대기 중이다. 완료 상태를 확인하고 재학습 없이 기존 캐릭터를 재사용한다.
2. 학습이 끝나도 얼굴의 닮음·미소·영화 질감이 승인된 것으로 간주하지 않는다. PULSE 여성의 촬영 질감은 스타일 기준, 실제 인터뷰 사진은 동일인 기준으로 구분한다.
3. 먼저 조용한 실내에서 고개를 조금 돌리거나 작은 미소를 짓는 기준 컷 한 개로 검토한다. 인터뷰 의상·실내가 생성 장면에 따라오는지도 확인한다.
4. 영상은 한 번에 한 컷, 짧은 저해상도 시험으로 시작한다. 새 영상 생성은 별도 실행 범위·가격 안에서 진행하며 전체 콘티를 배치 생성하지 않는다.
5. 현재 재료는 앉은 상반신 위주다. 전신·걷기·VR 착용·넘어짐의 실제 연기를 확보한 것이 아니며 해당 동작의 자연스러움은 별도 검증이 필요하다.

## 모델 역할

Soul ID는 얼굴 일관성을 위한 준비다. Soul Cinema에서 인물·빛·공간을 함께 구성하고, 영상 모델에서 움직임을 검토하는 경로를 시험한다. 실제 인터뷰의 표정을 픽셀 그대로 보존하거나 PULSE 수준 자연스러움을 자동 보장하는 기능으로 설명하지 않는다.
