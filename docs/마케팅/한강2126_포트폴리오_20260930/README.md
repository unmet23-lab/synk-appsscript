- 전경 거리에서 보이는 섬유 묶음 300,000개를 추가했다. 길이 55–95mm / 폭 3–7mm는 화면 가독성을 위한 표현값이며 실제 양모 한 올의 물성 수치가 아니다. 정밀 재질 시험 v2는 별도 보존한다.
- **품질 판정: 구조·구도 확인용. 최종 광고 컷으로 미채택.** 나무 겹침과 큰 조명 반사는 해결됐지만, 건물 곡선·펠트 외곽·풍부한 한강 환경·실사 마감은 선택한 이미지 수준에 못 미친다. 이 Blender 전경을 최종 광고 컷으로 사용하려면 해당 차이를 해결해야 한다. 후속 인물 이미지 시안은 선택 이미지 `building-hero-v2.png`를 기준으로 진행했다.
- 원본 장면·이전 시안 보존. 새 제작 스크립트는 `blender/refine_hero.py`, 식생은 `blender/hero_foliage.py`. 반복 실행은 출력 폴더를 새로 지정한다.
- 추가 하늘 자산: [Wasteland Clouds (Pure Sky)](https://polyhaven.com/a/wasteland_clouds_puresky), Jarod Guest / Sergej Majboroda, CC0. 공식 API의 2K HDR 파일 MD5 대조 완료; `blender/assets/wasteland_clouds_puresky.source.json`에 출처와 지문을 기록했다. 환경맵의 기본 좌표는 [Blender 공식 설명](https://docs.blender.org/manual/en/latest/render/shader_nodes/textures/environment.html)을 참조했다.

당시 Blender 후속 과제는 선택 이미지의 둥글게 이어지는 외벽·큰 유리 개구부 모델링과 강변 정원·섬유의 전경 가독성 개선이었다. 이 기록 시점에는 인물 컷이 미착수였으나 이후 첫 4컷 이미지가 생성됐고 시각 방향 승인을 받았다. 현재 진행은 위의 ‘현재 이미지 검토’와 [영상 콘티](영상_콘티.md)를 따른다.

두 PNG 모두 형식·해상도 검증과 실제 시각 검수를 완료했다. 이 수치는 서로 다른 장면을 이용한 CPU/GPU 비교 벤치마크가 아니다. 현재 산출물은 **3D 구조와 재질 시험**이며, 승인된 키비주얼 `building-hero-v2.png`를 대체하는 최종 광고 컷이 아니다. 다음 시각 작업은 우아한 섬유 정돈과 전경의 건축·조명·미래 한강 환경 개선이다. 영상·소리·게시 검증은 아직 없다.

### 비용과 파일 취급

- 사용자 화면의 ZeroGPU `0/40 min`은 일일 GPU 할당량이며 Jobs 유료 잔액과 다르다. [공식 설명](https://huggingface.co/docs/hub/spaces-zerogpu)
- 새 결제·충전·구독·자동충전 변경 없이 ZeroGPU 정지 프레임 두 건을 실행했다. API는 실제 계정 할당량 차감을 반환하지 않으므로 남은 시간을 추정해서 기재하지 않는다.
- 최초 Jobs 시도는 잔액 부족 HTTP 402로 거절되어 원격 작업이 생성되지 않았다. 비공개 기존 버킷에 소스와 공개 로고만 준비되었다. `blender/render_cloud.py`는 이전 Jobs 방식 기록으로 남기며 현재 기본 실행기는 아니다.
- 이번 ZeroGPU Space는 **cpuai가 운영하는 커뮤니티 서비스**다. 본인 소유 Space가 아니다. 업로드한 것은 공개 로고와 절차적으로 만든 건물 장면이며 얼굴·학생·고객 자료는 포함하지 않았다.
- 소스 기준 기본 보관 TTL은 마지막 갱신부터 24시간, 만료 정리는 새 작업 준비 시 수행된다. 즉시 삭제 API는 없다. 운영자는 업로드에 접근할 수 있다.
- 원격 작업 ID는 파일 접근 권한을 겸한다. 원시 응답·다운로드는 `blender/zerogpu/runs/`에 로컬 보관하고 Git에서 제외한다.

### 같은 방식으로 한 컷 렌더하기

저장소 루트의 PowerShell에서, 로그인된 Hugging Face 계정으로 실행한다. 아래 명령은 실제 ZeroGPU 할당량을 사용한다.

```powershell
python 'docs\마케팅\한강2126_포트폴리오_20260930\blender\render_zerogpu.py' 'docs\마케팅\한강2126_포트폴리오_20260930\blender\detail-v2\synk_hanriver_felt_detail.blend' --samples 48
```

1회 실행은 1프레임·GPU 최대 120초다. 완료 응답에서 실제 CUDA/OptiX 장치 사용을 확인한 뒤 결과를 받는다. 최대 시간은 할당량 차감 영수증이 아니다. 출력은 새 타임스탬프 폴더에 보존한다.
