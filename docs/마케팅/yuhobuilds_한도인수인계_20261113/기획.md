## 실화(11-09 기록 — 11-13 이 회차가 다시 읽음)

- 07시에 시작한 AI가 편 둘을 만들다 10:26에 사용 한도로 멈췄다. 편 폴더 둘은 올리지 못한 채 남았고, 시험 폴더에는 질문 · 그림과 일부 답만 있었다. 나머지 답은 멈춘 대화 안에만 있었고, 한 편은 기획서 자체가 없었다.
- 15시에 이어 받은 AI가 지난 대화 기록에서 답 일부만 찾았고 나머지는 다시 받았다. 고침: 답을 받은 자리에서 파일에 적고, 단계가 끝날 때마다 올린다.
- 영상의 종이 수(상자 18장 · 질문지 셋 · 찾은 답 하나)는 그림의 수이고 실제 장수가 아니다 — 화면에 장수 숫자를 적지 않았다.

## 실제 답(11-13 07:5x — 이 대화 맥락이 없는 새 AI에게 「아까 하던 작업 이어서 해 줘」 한 줄만 보냄)

받은 답의 첫 문장: 「「아까 하던 작업」이 어떤 것인지 이 세션에서는 확인할 수 없어 이어서 실행하지 않았습니다.」 — 영상에는 이 한 문장만 이어진 그대로 실었다(뒤 문장은 「이전 대화 기록이 없고 …」). 실제 채팅 화면 캡처는 못 썼다: 앱 안 브라우저 · ego의 그 채팅은 로그인되어 있지 않았고, 로그인된 다른 채팅은 알림 허용 창이 떠 멈췄으며(누르지 않음), 명령줄 계정은 주간 한도였다. 그래서 받은 글을 화면 글로 옮겼다 — 장부 「핵심 칸은 실제 채팅 화면 캡처로」에는 못 미친다(남은 위험).

## 인물 · 감정 설계 — 진행자 없음

- 장부 기본 꼴은 유호 진행자 + 실제 화면(S42)인데 이 편도 Y37 · Y39처럼 진행자 컷 없이 보이스오버(범수) + 움직이는 그림으로 만들었다. 까닭은 같다 — Flow가 자동 접수를 막아 새 진행컷을 못 뽑고, 새 방향 편의 진행자 정면 컷이 맹검 기각의 뿌리였으며, 화면 결이 트랙 §1에 유호님 차례로 걸려 있다. Flow 0크레딧.
- 무대: 어두운 판 위 유리 상자 하나(Y39의 밝은 쪽지 벽, Y41의 영상 가득 판과 다르게). 흰 글 SUIT, 버터색은 「파일」 한 곳.
- 감정 장치: 틱틱 쌓이는 종이 → 쿵 닫히는 셔터와 흔들림 → 비쳐 보이는 갇힌 답 → 타자 소리 뒤 정적 속 답 글 → 한 장만 빠져나옴 → 종이가 나오자마자 파일로 날아듦 → 다시 쿵, 그런데 파일은 빛난다.
