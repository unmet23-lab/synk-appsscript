# LAB · 몽글 아우라 파밍 에딧 (10-13, 게시 전)

트리거: **유행 + 새 도구.** 유호님 10-13 「카타나로 480p로 synkbrief 하나랑 몽글 아우라 파밍 에딧 각각 진행해줘」(편당 150크레딧 상한). 아우라 파밍은 주인공이 말없이 멋있게 서 있는 장면을 음악 박자에 맞춰 잇는 편집 유행이다.

## 결과

- `renders/몽글_아우라_v1_음량맞춤.mp4` — 카타나 결과(`카타나_원본/aura_final.mp4`, 480×854, 13.7초)의 소리만 −14 LUFS로 맞춘 판. 화면은 그대로다. 무음판 `카타나_원본/aura_final_silent.mp4`, 장면 그림 `aura_f1~4.jpg`.
- 흐름: 눈 내린 가로수길 먼 풍경 → 강가 난간 위 몽글(가로줄 눈) → 가로등 역광 → 얼굴 가까이 → 남색 밤으로 넘어가며 구슬 눈 응시 → 윙크 → 검은 화면 「MONGLE」.
- 레퍼런스: 유튜브 dIvAk_VlM3s(Gojo Eyes AMV, 16.35초). 가져온 것은 한 마디에 한 컷씩 먼 풍경에서 주인공으로 다가가는 구성, 차가운 청회색 속 따뜻한 점 하나(원본의 빨간 우산 → 코랄 몽글), 드롭에서 남색으로 넘어가며 눈을 드러내는 반전, 초점이 흐려지며 넘어가는 전환과 마지막 암전. 원곡은 저작권 때문에 쓰지 않았다(소리는 CC0 효과음뿐).
- 비용 **84.24크레딧**(거래 내역 6건 대조): 장소 그림 0.12 × 2, 4컷 12초 36, 다시 생성 6초 18, 구슬 눈 6초 18, 윙크 4초 12. 생성한 28초 중 12초를 썼다.

## 확인할 것(유호님)

- **움직임:** 회전·스핀·손떨림은 없다. 코드로 넣은 움직임은 3~8% 느린 밀어 들어가기뿐이고, 윙크 컷(10.3~11.4초)은 생성 영상 자체에 중간 정도 전진 줌이 있다. 마스코트 움직임은 유호님이 직접 보고 정한다.
- **번쩍임:** 6.9초에 강하게, 8.6·10.3초에 약하게 한 번씩. 요청대로 넣었지만 빛에 민감한 시청자를 생각하면 6.9초를 약하게 줄이는 안도 있다.
- **생김새:** 팔다리·입은 생기지 않았고 표정은 입력 사진의 가로줄 눈·구슬 눈·윙크 셋만 썼다. 밤 장면(6.9~12초)은 달빛 조명 때문에 코랄이 사진보다 어둡고, 첫 컷은 몽글이 점처럼 작다.
- **소리:** 음악 없이 효과음뿐이라 비어 들릴 수 있다. 인스타는 올릴 때 앱 안 음악 목록에서 고를 수 있다(남의 노래 파일을 영상에 굽지는 않는다).
- **화질:** 요청대로 480p. 크게 보일 곳에 올리려면 업스케일(유료)을 따로 정한다.
