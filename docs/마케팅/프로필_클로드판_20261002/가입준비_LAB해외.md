# 해외 LAB 가입 준비 · 아직 안 만든 20개 (2026-10-02)

**계정 만들기는 사용자가 직접 한다**(비밀번호·본인 인증·약관 동의). 가입 화면에 아래 이름·핸들·소개를 그대로 붙여 넣고, 사진은 모두 같은 몽글 [`프로필/avatar-lab.png`](프로필/avatar-lab.png), 웹사이트는 `https://synk.im/lab/`이다. 만든 뒤 알려 주면 공개 화면을 확인하고 장부(`../sns-계정.json`)에 적는다.

- 순서는 9월에 정한 대로 틱톡이 아닌 11개(인스타그램 9·더우인·VK)를 먼저, 틱톡 9개를 마지막에.
- 소개는 AI 작성이고 원어민 확인 전이다. 모든 계정이 「하고 싶은 말, 한국어로」에서 시작한다(유튜브·배너와 같은 문장).
- 핸들은 1순위가 안 되면 다음 후보를 쓴다. 후보가 모두 막히면 `synklab` + 나라 이름 조합으로 정하고 알려 준다.
- 이미 있는 계정(틱톡 베트남·미얀마, 텔레그램 우즈베키스탄, RUTUBE, 페이스북 네팔·캄보디아·스리랑카, 샤오훙수)은 새로 만들지 않는다. 샤오훙수는 계정이 있고 프로필만 비어 있어 앱 「나 → 프로필 편집」에서 넣는다(소개는 `계정별_문구_LAB해외.json`의 lab-cn-xiaohongshu).
- 같은 장부에 있는 @synk.hq(SYNK 인스타그램, 사용자가 만들기로 함)·synkbrief 스레드(만들지 않기로 함 9/14)·yuhobuilds 링크드인(쓰지 않는 중복 계정)은 이 묶음에서 뺐다.
