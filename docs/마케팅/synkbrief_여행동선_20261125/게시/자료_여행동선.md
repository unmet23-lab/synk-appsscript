# 가고 싶은 곳이 너무 많을 때, ChatGPT로 날짜별 동선 짜기

가고 싶은 곳 이름을 모두 붙이고, 아래에 한 줄만 더해요.
「하루에 세 곳만, 이동은 30분 안으로 묶어 줘.」

저희가 부산 열두 곳으로 해 보니, ChatGPT가 아홉 곳을 사흘로 나눠 줬어요. 나머지 세 곳은 왜 뺐는지 까닭도 달아 줬어요. 세 번 보내 두 번은 답에 지도가 같이 나와서 날짜를 고르면 그날 동선이 선으로 보였어요. 지도 없이 온 한 번은 「지도로도 보여 줘.」를 이어 보내 받았어요.
그 동선을 카카오맵 자동차 길찾기로 다시 재 보니, 여섯 구간이 모두 30분 안이었어요. 가장 먼 구간이 21분이었어요.

순서는 네 가지예요.

1. 모으기: 가고 싶은 곳 이름을 한 줄에 하나씩 적어요.
2. 붙이기: 목록 아래에 한 줄을 붙여 보내요.
3. 지도가 안 나오면: 같은 채팅에 「지도로도 보여 줘.」를 이어서 보내요.
4. 다시 재기: 받은 동선을 지도 앱 길찾기로 한 번 더 재요.

아래 내용은 저희가 직접 해 보고 결과를 확인한 것만 적었어요.

---

## 붙여 넣는 글

```
가고 싶은 곳
(장소 이름을 한 줄에 하나씩)

부산 2박 3일이야. 하루에 세 곳만, 이동은 30분 안으로 묶어 줘.
```

「부산 2박 3일」만 내 여행에 맞게 바꿔요. 장소 이름은 지도 앱에 나오는 이름 그대로 적으면 헷갈리지 않아요(예: 「태종대」보다 「태종대유원지」).

---

## 준비물

**가고 싶은 곳 목록**
- 이름만 한 줄에 하나씩 적으면 돼요. 주소는 없어도 됐어요.
- 하루 세 곳 × 날짜 수보다 많이 적으면, ChatGPT가 넣기 어려운 곳을 골라 빼 줘요.

**ChatGPT 앱이나 chatgpt.com**
- 저희는 컴퓨터의 chatgpt.com을 휴대폰 화면 크기로 띄워서, 임시 채팅으로 해 봤어요.
- 저희는 유료 계정(ChatGPT Pro, 모델 「Instant」)으로 해 봤어요. 무료 계정으로는 해 보지 않았어요.

**공식 도움말에서 확인한 것** (OpenAI 「Searching the web with ChatGPT」, 2026-11-25 읽음)
- 웹 검색은 무료(Free)를 포함한 모든 요금제에 있다고 나와 있어요. 검색 횟수는 요금제 한도를 따라요.
- 휴대폰 앱(iOS · 안드로이드)에서는 답에 지도가 함께 나올 수 있다고 나와 있어요. 지도가 어느 요금제에서 나오는지는 도움말에 없었어요.
- 검색 결과는 빠지거나 낡거나 틀릴 수 있다고 적혀 있어요.

---

## 실제로 받은 답(2026-11-25)

보낸 목록: 해운대해수욕장, 광안리해수욕장, 감천문화마을, 자갈치시장, 국제시장, 흰여울문화마을, 태종대, 해동용궁사, 청사포 다릿돌전망대, 송도해상케이블카, 부산엑스더스카이, 이기대 해안산책로(열두 곳)

ChatGPT는 「하루 3곳씩 총 9곳」으로 짜고, 이동은 택시 · 자가용 기준으로 잡았다고 했어요.

| 날 | 동선 | ChatGPT가 적은 이동 시간 |
|---|---|---|
| 1일차 · 해운대 · 광안리 | 청사포 다릿돌전망대 → 해운대해수욕장 → 광안리해수욕장 | 택시 약 10~15분 · 약 20~30분 |
| 2일차 · 감천 · 남포동 | 감천문화마을 → 국제시장 → 자갈치시장 | 택시 약 10~20분 · 걸어서 약 5~10분 |
| 3일차 · 영도 · 송도 | 태종대 → 흰여울문화마을 → 송도해상케이블카 | 택시 약 15~25분 · 약 10~20분 |

뺀 세 곳과 까닭(ChatGPT 답 그대로)
- 해동용궁사: 동쪽으로 더 이동해야 해서 제외.
- 부산엑스더스카이: 전망대 일정이 겹쳐서 제외.
- 이기대 해안산책로: 산책 시간이 길어 여유로운 여행을 위해 제외.

같은 글을 새 임시 채팅에 한 번 더 보냈을 때도 같은 아홉 곳, 같은 세 곳이 빠졌어요(날짜 순서만 달랐어요). 세 번째로 보냈을 때는 첫날 광안리해수욕장 대신 부산엑스더스카이가 들어갔어요(뺀 곳: 광안리해수욕장 · 해동용궁사 · 이기대 해안산책로).

## 이어서 보내 본 말

같은 채팅에 이어서 보냈어요.

**쉬는 시간 넣기**
```
오후에 카페에서 1시간 쉬는 시간도 날마다 넣어 줘.
```
아홉 곳과 순서는 그대로 두고, 날마다 오후 2시쯤에 「카페 휴식」 1시간을 넣어 줬어요. 카페 이름은 정해 주지 않았어요.

**비 오는 날 바꿀 곳**
```
비 오는 날 바꿀 실내 장소도 날마다 하나씩 알려 줘.
```
날마다 바깥 장소 한 곳을 실내 장소로 바꾸는 안을 줬어요(1일차 청사포 대신 씨라이프 부산아쿠아리움, 2일차 감천문화마을 대신 부산근현대역사관, 3일차 태종대 대신 국립해양박물관). 휴관일과 요금도 적어 줬는데, 저희는 그 곳 누리집에서 확인하지 않았어요. 가기 전에 꼭 확인해요.

**지하철 · 버스로 다닐 때**
```
택시 말고 지하철이랑 버스로 다니면 어떻게 바뀌어?
```
ChatGPT가 「30분 이내 조건은 완벽하게 충족하지 못해」라고 먼저 말했어요. 몇 구간은 40분쯤 걸린다고 했고, 목록에 없던 곳(국립해양박물관)을 넣고 송도해상케이블카를 뺐어요. 대중교통으로 다닐 거면 처음 글부터 「이동은 지하철 · 버스로」를 붙이고, 받은 동선을 지도 앱 대중교통 길찾기로 꼭 다시 재요.

---

## 지도가 안 나오면

같은 글을 세 번째 새 임시 채팅에 보냈을 때는 지도 없이 글과 표로만 왔어요(2026-11-25). 같은 채팅에 이어서 보냈어요.

```
지도로도 보여 줘.
```

「부산 2박 3일 여행 코스를 날짜별로 지도에 표시했어요」라는 말과 함께, 날짜별 이동 경로를 고르는 지도가 나왔어요. 앞서 정한 아홉 곳과 순서는 그대로였어요.

---

## 한 줄 없이 보내 보니

같은 열두 곳을 새 임시 채팅에 「부산 2박 3일이야. 동선 짜 줘.」만 붙여 보냈어요(2026-11-25).

- 열두 곳을 하나도 빼지 않고 사흘에 다 넣었어요. 하루에 네 곳씩이었어요.
- 목록에서 가장 먼 해동용궁사도 들어갔어요.
- 그래서 「하루에 세 곳만, 이동은 30분 안으로」가 빼는 일을 맡는 줄이에요.

---

## 지도 앱으로 다시 재기

ChatGPT도 답 끝에 「실시간 길찾기로 검증한 값이 아닌 예상치」라고 적었어요. 저희가 카카오맵 자동차 길찾기로 구간마다 다시 쟀어요(2026-11-25 수요일 아침 7시 50분쯤, 「내비추천」 첫 경로).

| 구간 | ChatGPT | 카카오맵 자동차 |
|---|---|---|
| 청사포 다릿돌전망대 → 해운대해수욕장 | 택시 약 10~15분 | 18분 · 6.2km |
| 해운대해수욕장 → 광안리해수욕장 | 택시 약 20~30분 | 16분 · 5.8km |
| 감천문화마을 → 국제시장 | 택시 약 10~20분 | 10분 · 3.0km |
| 국제시장 → 자갈치시장 | 걸어서 약 5~10분 | 6분 · 1.4km(자동차) |
| 태종대유원지 → 흰여울문화마을 | 택시 약 15~25분 | 21분 · 6.7km |
| 흰여울문화마을 → 송도해상케이블카 | 택시 약 10~20분 | 13분 · 4.6km |

- 여섯 구간 모두 30분 안이었어요. 첫 구간은 ChatGPT가 적은 시간(10~15분)보다 길었어요.
- 걸어서 가는 시간은 재지 않았어요.
- 시간은 요일 · 시간대 · 길 막힘에 따라 달라져요. 여행 날 아침에 한 번 더 재요.

---

## 지킬 것

- 영업시간 · 휴무일 · 요금은 ChatGPT가 틀릴 수 있어요. 그 곳 누리집이나 지도 앱에서 확인해요.
- 「이동 30분」은 ChatGPT가 짐작한 값이에요. 지도 앱 길찾기로 구간마다 다시 재요.
- 숙소 주소처럼 내 위치가 드러나는 정보는 넣지 않아도 동선이 나왔어요.
