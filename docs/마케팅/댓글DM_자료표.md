## 자료 프로그램 사용 확인

10-08 19:02 KST 공개 `/builds/manual/`에서 다섯 질문을 선택해 결과를 만들고, 가상 가게명·정책·오늘 맡길 일을 넣은 **1,548자 요청문 복사**를 확인했다. 선택한 사실·링크·개인정보 검수 기준이 복사 내용에 포함됐다. 공유 링크를 새 탭에 열어 같은 결과 제목을 확인했으며 가게명·정책·오늘 맡길 일은 링크와 새 화면에 포함되지 않았다.

이 도구는 질문 답을 조합해 AI에 붙여 넣을 매뉴얼·요청문을 만든다. 실제 고객 답장을 여기서 AI로 생성하는 것은 아니다. 선택 답·진행 상태 등은 이 브라우저에 저장하며, 결과에서 입력한 가게 정보·오늘 맡길 일은 화면 메모리에만 두고 복사할 때 포함한다. 이번 확인에서는 외부 AI에 입력하거나 새 계정·결제를 만들지 않았다. [브라우저 검증 기록](../../../SYNK-talk/qa/synkbrief-queue-20261008/public-readiness-verification.json).

## Meta 접근 범위 — 확인 한계

10-08 앱 게시 화면은 ‘게시됨’이며 권한 화면의 기본 프로필·댓글·메시지는 모두 ‘테스트 준비 완료’였다. Advanced 승인 표시는 확인하지 못했다. [공식 App Review](https://developers.facebook.com/documentation/instagram-platform/app-review?locale=en_US)와 [Send Messages](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/messaging-api?locale=en_US)는 소유·관리하는 프로페셔널 계정에 Standard Access를 허용한다. 반면 [Webhook Setup](https://developers.facebook.com/documentation/instagram-platform/webhooks/setup?locale=en_US)은 comments 알림에 Advanced Access가 필요하다고 적고 있어 처음에는 자체 운영 예외 범위를 확정하지 않았다.

후속으로 **현재 앱의 Instagram API 설정 → 5. 앱 검수 완료**를 펼쳐, 외부 고객용 솔루션 없이 자신의 Instagram 비즈니스만을 위해 만드는 직접 개발자는 이 단계를 건너뛰라는 안내를 확인했다([실제 화면](../../.tmp/comment-dm/meta-own-business-review-exemption-20261008.png)). 현재 자체 계정 운영에 심사·Tech Provider 전환을 필수 미완료 항목으로 두지 않는다. 외부 고객 계정으로 확장할 때는 적용 요건을 다시 확인한다. [심사 설명·재현 순서 예비 자료](../../../SYNK-talk/qa/synkbrief-queue-20261008/meta-review-preparation.json)는 현재 제출 요청이 아니다.

직접 Instagram 테스터 목록에는 @synk.mn·@synkbrief·@yuhobuilds가 있고 @xi01music·@1101yuh는 없다. Business 앱 할당은 운영자 1명, @xi01music의 활성 앱은 0개였으며 기존 다섯 Instagram 계정은 같은 계정 센터에 연결돼 있다. 직접 테스터 목록 밖 계정의 기존 실제 수신 증거는 유효하고, 다른 소유자의 계정으로 다시 시험하는 것은 현재 완료의 필수 조건이 아니다. 다만 이를 모든 일반 시청자의 실제 수신 보장이나 Advanced 승인 증거로 확대하지 않는다. [기존 계정 확인](../../../SYNK-talk/qa/synkbrief-queue-20261008/account-readiness-verification.json). 이번에는 권한 추가·앱 검수 제출·Meta 설정 변경을 하지 않았다.

대상은 위 릴스, 게시 계정은 @yuhobuilds다. 기존 캡션은 프로필 링크를 안내하지만 댓글 키워드를 설명하지 않아 보조 댓글 1개를 준비했다. 사용자가 정확한 문구·계정·릴스를 제시한 게시 질문에 ‘웅’으로 승인해 10-08 19:18:39 KST 한 번 게시했다. 19:19 KST 작성자·본문·댓글 링크와 전체 댓글 수 5→6을 UI에서 확인했다. 일반 시청자 지원의 위 한계를 감안해 시험 운영으로 안내하고 직접 접근 경로를 함께 제공한다.

> 내 일에 맞는 AI 직원 매뉴얼이 필요하면 댓글에 ‘매뉴얼’을 남겨 주세요. 댓글 DM은 시험 운영 중이에요. DM이 오면 ‘매뉴얼’이라고 한 번 답장하면 질문 5개로 만드는 프로그램 링크를 받을 수 있어요. 팔로우는 필요 없어요. DM이 안 보이면 프로필 링크에서 바로 열 수 있고, ‘중단’을 보내면 DM 안내를 멈출 수 있어요.
