## 올리기 전에 — 이 글이 올라가는 순간 참이어야 하는 것

1. 인스타 @synk.mn 프로필 둘째 링크 «Бичгийн дасгал» `https://synk.im/world/?exam=topik2&lang=mn`이 걸려 있다(① 올리기 전에 첫째 링크와 함께 건다 — ① README).
2. 6장 「20문항 · 하루 3번」을 게시 직전에 공개본에서 다시 확인한다(`synk.im/world/world-writing-items.json` 20개).
3. 대조기(몽골어 1층)가 10-23 저녁 몫 한도로 v2 새 줄 · 댓글 답 초안을 못 봤다 — 몫이 풀리면 `검문/문안_6차_v2새줄.txt`를 돌리고 「정상」을 본 뒤 올린다.

## 올리는 순서(「올려」 뒤)

1. Business Suite → 게시물 만들기 → 인스타 @synk.mn과 페이스북 SYNK(synkworld)를 함께 고른다.
2. 사진 01~06을 순서대로 넣는다(여러 장 게시물). 인스타 · 페북 글을 따로 맞춤 → 인스타는 `캡션_mn.txt`, 페북은 `본문_fb_mn.txt`.
3. 슬롯 시각으로 예약하거나 바로 게시. 게시 · 예약 목록에서 새 줄을 먼저 확인한다.
4. 게시 뒤: 인스타 프로필에서 이 글을 고정하고, ① 반 소식을 고정 해제했다가 다시 고정한다 — 인스타는 최근에 고정한 글이 맨 앞이라 ①이 맨 앞에 오게.
5. 게시 주소를 `게시결과.json`에 적고, 회사 작업실 게시 성과에 「게시 주소로 추가」(연결된 채널이면 자동).
