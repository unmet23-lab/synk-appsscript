## 올리는 순서(「올려」 뒤)

1. Business Suite → 게시물 만들기 → 인스타 @synk.mn과 페이스북 SYNK(synkworld)를 함께 고른다.
2. 사진 01~06을 순서대로 넣는다(여러 장 게시물). 인스타 · 페북 글을 따로 맞춤 → 인스타는 `캡션_mn.txt`, 페북은 `본문_fb_mn.txt`.
3. 슬롯 시각으로 예약하거나 바로 게시. 게시 · 예약 목록에서 새 줄을 먼저 확인한다.
4. 게시 뒤: 인스타 프로필에서 이 글을 고정한다(① 반 소식보다 먼저 고정해 ①이 맨 앞에 오게).
5. 인스타 프로필 링크에 둘째 링크 `https://synk.im/world/?exam=topik2&lang=mn`(이름 «Бичгийн дасгал»)을 더한다(유호님 휴대폰). 6장의 「연습 링크는 프로필에」가 이것이다. 첫째 링크(신청 페이지)는 ①에서 바꾼 그대로.
6. 게시 주소를 `게시결과.json`에 적고, 회사 작업실 게시 성과에 「게시 주소로 추가」(연결된 채널이면 자동).
7. 6장 「20문항 · 하루 3번」은 게시 직전에 공개본에서 다시 확인한다(`synk.im/world/world-writing-items.json` 20개).
