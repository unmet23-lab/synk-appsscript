## 공식 요건과 준비 방향

- 전문가 인증과 프로필 설정이 서비스 등록의 선행 요건이다. 계정의 인증 정보 화면에서 개인 전문가 유형과 수익금 출금 계좌 등록 상태를 확인했다. 개인 식별번호·계좌번호는 기록하지 않았다.
- 공식 자격 확인 대상 목록에 일반 AI 자동화 개발·AI 활용 레슨·AI 이미지 디자인이 별도로 열거되지는 않았다. 따라서 현 시점에 확인한 범위에서는 이 세 상품을 위해 별도의 AI 자격증이 필수라는 근거는 없다. 실제 카테고리 양식과 심사에서 추가 요구할 수 있다.
- 교육 상품의 범위는 AI 도구 활용과 업무 자료 실습이다. 경영 자문·심리상담·투자 자문으로 확장하지 않는다. 경영 자문·운영 지원 등은 크몽 자체 경력 확인 대상이다.
- 제목·설명·범위·가격·납기·수정 조건·필수 선택 항목·대표 이미지를 준비한다. 카테고리별 별표 항목은 실제 작성 양식에서 확인한다.
- 개발·검수·수업 등 약속한 용역 수행에 필수인 비용은 판매가에 포함한다. 납품 후 의뢰인 소유 환경에서 발생하는 API·도구 운영비는 별도이며 주문 전에 설명한다.
- 최상급·매출 보장·무제한 수정·근거 없는 경력 문구와 외부 연락 채널은 넣지 않는다.

## 경력·학력·수상 어필에 필요한 증빙

사용자가 알려 준 이력과 크몽에 제출 가능한 증빙의 확보는 서로 다르다. 홈페이지 소개만으로 크몽의 서류 요건을 충족했다고 판단하지 않는다.

| 이력 | 등록 전 확인할 자료 | 현재 판단 |
|---|---|---|
| 중앙대학교 심리학과 졸업 | 학교·전공·기간·졸업 사실이 확인되는 공식 학력 증빙 | 사용자 진술 확인, 증빙 확보 미확인 |
| SYNK Founder | 대표자 경력에 맞는 사업자등록증 등 공식 증빙 | 사용자 진술 확인, 증빙 확보 미확인 |
| RCA 퍼포먼스 참여 | 실제 역할과 참여 기간이 확인되는 기관 발급 경력·용역 자료 | 홈페이지/사용자 이력과 증빙 심사 구분 필요 |
| 2019 사진상, 2017 MK Challenge | 명칭·발급일·기관·본인 이름이 일치하는 수상 경력 증명 | 사용자 진술 확인, 증빙 확보 미확인 |

증빙이 확인되기 전까지 새 서비스 문안과 대표 이미지에는 해당 학력·수상·기관명을 판매 근거로 넣지 않는다. RCA 종료 월을 임의로 확정해 증명된 날짜로 취급하지 않는다. 기존 프로필의 등록 상태는 이번 서비스 초안 작성과 별도로 점검할 항목이다.

공식 안내상 프로필 증빙은 심사용이며 외부 공개되지 않는다. 디자인·IT 등에 적용되는 안내는 항목당 JPG/PNG 1개, 1MB 이하를 요구한다. 실제 서류의 수집·업로드는 이번 준비 자료 작성만으로 완료된 것으로 보지 않는다.

- 상담 자동화 실제 데모와 의류 원본 대비 결과물은 아직 별도 제작·검증이 필요하다. 일반 이미지나 다른 내부 도구 화면을 해당 작업의 납품 실적으로 사용하지 않는다.
- 의류 서비스의 실제 상품 재현 품질은 고객 제공 또는 사용 권한이 있는 제품 사진을 확보한 후 별도로 검증한다.
