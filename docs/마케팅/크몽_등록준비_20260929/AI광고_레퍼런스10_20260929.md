# AI 광고·영상 레퍼런스 10개와 제작 도구

작품 공개 기준: 2026-09-29 이전. 조사: 2026-09-29~30 KST.

## 조사 범위와 해석

- Instagram 공개 게시물, 제작자 메이킹, 브랜드·제작사 발표를 대조했다. Pinterest도 검색했으나 타인 핀의 조회·저장 수를 일관되게 확인할 수 없어 인기 순위에 사용하지 않았다.
- 전 세계 조회수 상위 10위라는 주장은 검증하지 못했다. 아래 번호는 우리 광고 제작에 참고할 순서이며, 플랫폼 전체 인기 순위가 아니다. 최신 데모·상업 광고·과거 바이럴 영상이 섞여 있다.
- 직접 확인한 UI 수치와 과거 제작자·브랜드 발표를 구분했다. 조회, 좋아요, 댓글, 수상을 동일한 점수로 합산하지 않았다. 광고 집행·협찬·댓글 유도 여부를 별도로 기록했다.
- 분석은 공개 캡션·메이킹·제작 크레딧과 일부 재생 화면을 바탕으로 한다. 10편 모두의 전편 재생·음향 검수를 마쳤다는 뜻은 아니다. 공개되지 않은 도구는 화면만 보고 추측하지 않았다.
- 프로그램은 플랫폼(Higgsfield, Flow), 생성 모델(Seedance, Kling, Veo), 후반 작업 도구를 구분한다. 아래 역사적 작품의 모델 버전은 현재 권장 버전과 다를 수 있다.

## 우리 제작에 권하는 프로그램 구성

1. 이미지 설계: 기존 사용 예정인 GPT Image / Nano Banana에서 장면별 기준 이미지를 만든다. 도구 자체의 우열을 미리 정하기보다 제품 형태·라벨·구도를 기준으로 선정한다.
2. 영상 생성: Higgsfield에서 Seedance 2.5와 Kling 3.0을 같은 핵심 장면으로 비교한다. Flow/Veo 3.1은 기존 계획대로 대안 컷을 만드는 후보로 둔다. 여러 모델의 출력은 최종 편집에서 색·움직임을 맞춘다.
3. 기존 영상 변환: 촬영본이 있을 때 Genjutsu 또는 Runway Aleph를 검토한다. 모든 프로젝트에 추가할 필요는 없다.
4. 완성본 제작: DaVinci Resolve를 편집·색보정·Fusion 합성·Fairlight 음향의 중심으로 삼는다. 필요한 정밀 합성이나 모션그래픽만 After Effects에서 추가한다.
5. 업스케일: 원본에 문제가 없는 경우에만 필요에 따라 비교한다. 확대가 제품 변형이나 잘못된 움직임을 고쳐주지는 않는다.

Higgsfield는 플랫폼이며 Seedance·Kling은 선택 가능한 생성 모델이다. 위 제안은 검증된 기능과 사례를 바탕으로 한 제작 판단이지 모델 화질 순위가 아니다. 설치·구독·유료 생성·게시·크몽 심사 제출은 이번 조사에서 진행하지 않았다.

## 첫 SYNK 광고에 적용할 제안

25초 내외의 세로 서비스 광고를 먼저 설계한다. 첫 3초에 가장 강한 완성 장면, 3~8초에 제품 사진과 결과의 대비, 8~18초에 제품 광고와 모델·패션 장면, 18~22초에 실제 제작 과정, 마지막에 SYNK와 문의 경로를 배치한다. 이 순서와 길이는 제안이며 확정 기획은 아니다.

생성에 앞서 메시지 하나, 사용할 제품·브랜드 자산, 기준 이미지 4~5장을 정한다. 같은 핵심 컷을 후보 모델에 넣어 비교한 뒤 본 제작의 주 도구를 결정한다. 승인된 예산·구독 범위 안에서 진행한다.
