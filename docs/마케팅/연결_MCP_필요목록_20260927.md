## 4. 운영·일정

- **scheduled-tasks(연결됨)**: 월요일 “지난주 측정 기록” 요청, 금요일 “게시 패키지 확인” 알림 같은 루틴을 사용자 승인 후 등록한다.
- **콘텐츠 달력**: 저장소에 `docs/마케팅/콘텐츠_달력.json`(회차·라인·게시 예정일·상태)을 두고 지도 콘텐츠 탭이 읽게 한다. Notion·Airtable은 도구가 분산되므로 권하지 않는다. 표가 필요하면 기존 관리 스프레드시트에 탭을 더한다.
- **소재 조사**: exa(연결, 무료 한도 초과 시 API 키), Hugging Face(연결). vidIQ 커넥터(유료)는 YouTube 구독자가 생긴 뒤 검토.

## 5. 이번 주에 열 순서

1. YouTube OAuth 2개 계정(무료, 10분).
2. Metricool 가입 → 브랜드 3개 연결 → Claude 커넥터 연결. 무료로 시작해 월 20건을 넘기면 Starter.
3. Telegram 봇 생성·채널 관리자 추가.
4. YouTube Analytics 권한 추가와 `채널성과.js` 영상별 칸(도구 수정).
5. 육성 녹음 장비 준비.
6. Higgsfield 크레딧 여부 결정(LAB 상황극 라인의 조건).

## 6. 월 비용 요약

새로 드는 필수 비용은 Metricool Starter 월 $20~25 정도다. 그 밖에는 선택(ElevenLabs $22, X 추가 $10)이거나 편당 크레딧(Higgsfield)이다. 사용자 수에 비례해 새는 비용은 없다. 기존 구독(Typecast·Suno·Higgsfield Plus)은 유지한다.
