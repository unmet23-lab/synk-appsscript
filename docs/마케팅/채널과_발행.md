## 회사·사람 중심 브랜딩

2026-09-19 사용자 확인: 기존 대상·언어·계정 역할을 유지하면서 회사 중심 브랜딩과 사람 중심 브랜딩의 목적을 함께 적용한다. 메인·서브라는 고정 등급이나 별도 계정을 추가하는 결정이 아니다.

- 회사 중심 브랜딩은 누구에게 어떤 가치를 주는지, 어떤 철학으로 선택하는지를 실제 제공 경험·결과와 함께 보여준다.
- 사람 중심 브랜딩은 유호의 경험·판단·제작 과정과 직접 설명하는 모습을 통해 유호를 알고 계속 볼 이유를 만든다. 얼굴 출연 없이 쓴 글도 이 목적을 맡을 수 있다.
- LAB에는 학습자를 이해하고 연습을 돕는 유호, yuhobuilds에는 SYNK를 만드는 유호, synkbrief에는 업무에 적용할 방법을 설명하는 유호가 어울린다. 같은 출연자여도 내용의 도착지는 독자와 목적에 맞춘다.
- yuhobuilds의 전체 역할은 SYNK를 만드는 유호다. 현재 중심 소재는 AI와 회사 제작이며 LAB·PULSE·PATH 관련 실제 제작 경험도 다룰 수 있다.
- 한 게시물이 학습·실무 효용과 회사·인물 브랜딩을 함께 맡을 수 있다. 독자와 목적에 맞으면 같은 게시물·자료를 재사용한다. 출연 여부를 채널 전체의 의무나 금지로 고정하지 않는다.

[첫 게시물과 출연 구성](첫게시물_타깃과_재사용_검토_20260919.md)은 위 방향을 적용한 제작 제안이며, 실제 제작·발행 기록과 구분한다.

## 대상과 언어

문서 초기화 뒤에도 아래 채널 구분은 유지한다. 말투·대본 형식·컷 길이를 고정하는 규칙은 아니다.

| 채널 | 대상과 제작 기준 |
|---|---|
| LAB의 몽골어권 학습 채널 (`@synk.mn`, `synkmn` 등) | 몽골어권 한국어 학습자. 몽골어 상황 설명과 한국어 학습 표현을 함께 제공한다. 한국어만으로 새 대상처럼 제작하지 않는다. 원어민 감수 여부는 실제 확인한 상태대로 표시한다. |
| LAB Facebook·과정 안내 | 수업을 알아보는 성인·보호자도 대상이다. 학습 표현 영상과 등록·과정 안내의 목적을 구분한다. |
| SYNK를 만드는 유호 `@yuhobuilds` | AI와 함께 SYNK를 만드는 과정에 관심 있는 사람. 한국어 중심으로 실제 만든 것과 고친 이유를 공유한다. 현재 중심 소재는 회사 제작과 AI 활용이며 브랜드별 실제 제작 경험도 다룬다. 기관·기업 대상 제공물은 [사업별 대상](../마케팅_정본.md)을 따른다. |
| SHIFT `@synkbrief` / PULSE 감상 채널 | SHIFT 정보 채널과 유호의 제작 기록을 구분한다. PULSE는 음악·영상 감상 및 제작 의뢰 대상이며 LAB 학습 콘텐츠와 구분한다. 언어는 해당 콘텐츠의 독자에 맞춘다. |
