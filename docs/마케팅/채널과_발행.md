## 회사·사람 중심 브랜딩

2026-09-19 사용자 확인: 기존 대상·언어·계정 역할을 유지하면서 회사 중심 브랜딩과 사람 중심 브랜딩의 목적을 함께 적용한다. 메인·서브라는 고정 등급이나 별도 계정을 추가하는 결정이 아니다.

- 회사 중심 브랜딩은 누구에게 어떤 가치를 주는지, 어떤 철학으로 선택하는지를 실제 제공 경험·결과와 함께 보여준다.
- 사람 중심 브랜딩은 유호의 경험·판단·제작 과정과 직접 설명하는 모습을 통해 유호를 알고 계속 볼 이유를 만든다. 얼굴 출연 없이 쓴 글도 이 목적을 맡을 수 있다.
- LAB에는 학습자를 이해하고 연습을 돕는 유호, yuhobuilds에는 SYNK를 만드는 유호, synkbrief에는 AI 소식·스킬과 도구·활용법을 골라 설명하는 유호가 어울린다. 같은 출연자여도 내용의 도착지는 독자와 목적에 맞춘다.
- yuhobuilds의 전체 역할은 SYNK를 만드는 유호다. 현재 중심 소재는 AI와 회사 제작이며 LAB·PULSE·PATH 관련 실제 제작 경험도 다룰 수 있다.
- 한 게시물이 학습·실무 효용과 회사·인물 브랜딩을 함께 맡을 수 있다. 독자와 목적에 맞으면 같은 게시물·자료를 재사용한다. 출연 여부를 채널 전체의 의무나 금지로 고정하지 않는다.

[첫 게시물과 출연 구성](첫게시물_타깃과_재사용_검토_20260919.md)은 위 방향을 적용한 제작 제안이며, 실제 제작·발행 기록과 구분한다.

## synkbrief의 AI 뉴스·추천·활용법

2026-09-19 사용자가 GitHub 스킬 추천과 최신 AI 뉴스도 다루려던 목적을 재확인했다. 이 역할의 중심은 기존 YouTube·Instagram·TikTok `@synkbrief` 3개 계정이다. 대상에게 맞는 같은 영상·자료를 재사용하며 새 계정을 추가하지 않는다.

| 콘텐츠 | 독자가 얻을 내용 |
|---|---|
| 최신 AI 소식 | 무엇이 바뀌었고, 누가 쓸 수 있으며, 어떤 업무에 영향을 주는지 |
| GitHub 공개 스킬·도구 추천 | 어떤 사람·작업에 적합한지, 실제로 무엇을 할 수 있는지, 사용 조건과 한계는 무엇인지 |
| 실무 활용법 | 선택한 도구로 원하는 결과를 만드는 과정과 확인할 결과 |

뉴스는 독자의 업무에 관련된 변화를 골라 공식 발표·릴리스 원문과 날짜·실제 이용 가능 상태를 확인한다. 추천은 직접 사용한 결과와 아직 소개만 확인한 후보를 구분한다. 시연을 하지 않은 도구를 써 본 것처럼 설명하지 않는다.

같은 소재에서 유호 채널은 SYNK에 직접 적용한 경험·선택·수정 이유를, 네이버 블로그는 설치·설정·상세 사용법을, Tistory는 실제 적용기를 다룰 수 있다. Substack은 공통 뉴스레터의 SHIFT 갈래에서 소식·도구·실험을 선별해 정리하고 LAB 학습 자료와 구분한다. 역할에 맞는 파생본만 만들며 모든 뉴스마다 전 채널용 게시물을 의무적으로 만들지는 않는다.

뉴스·추천도 공식 자료와 실제 시연 화면·자막으로 제작할 수 있어 추가 얼굴 촬영이 필요하지 않다. synkbrief의 모든 소재를 유호의 기존 작업에서만 뽑을 필요도 없다. 별도 뉴스·스킬 주제가 독자에게 유용하면 자체 콘텐츠로 제작한다. 이 항목은 역할 정의이며 뉴스 발행·도구 검증·자동 수집을 완료했다는 기록이 아니다.
