### 7-2. 제작 상한 없이, 각 접점의 역할은 다르게

**LAB의 한 장면:** 숏폼은 직접 선택하는 순간, IG 카드 묶음은 변형해서 써볼 자료, Telegram은 다음 표현, Facebook은 해당 경험이 수업에서 어떻게 이어지는지 보호자/성인에게 설명한다. 같은 설명을 네 번 복사하지 않는다.

**SHIFT의 실제 회사 작업 한 건:** yuhobuilds 본편은 유호가 무엇을 만들려 했고 AI와 어떻게 일했으며 어디서 막히고 무엇을 고쳤는지 이야기한다. 공개 가능한 실제 입력·출력·작업 화면·실패와 사람의 수정이 이야기의 근거다. Reels/TikTok은 그 안의 한 사건, synkbrief는 그 사건에서 건진 도구·팁·방법, LinkedIn은 일의 결과와 협업 맥락, Substack 창업 갈래는 후속 진행과 더 자세한 이야기를 맡는다. 좋은 공통 소재는 재사용하되 관련 질문의 전용 제작도 허용한다. 재사용을 ‘비용 0’이라고 주장하지 않는다.

과정 공개는 무편집 전량 공개 의무가 아니다. 실제 순서·실패·수정의 뜻을 보존하면서 편집하고, 재현한 장면은 재현이라고 밝힌다. 모든 본편을 수업·작업지로 바꾸지 않으며, 강의는 쌓인 작업 경험과 타인의 적용·질문에서 구체적인 수요가 드러날 때 연결한다. 강의를 미리 정해 놓고 실제 작업을 그 사례로만 끼워 맞추지 않는다.

까몽 3D는 [SHIFT 제작 이야기](SHIFT.md#4-3-a-제작-이야기--만든-것과-선택한-이유를-함께-제공한다)의 첫 적용 사례다. **같은 실험에서 제작 이야기·점검표·회사 기록을 역할별로 꺼내며**, 모든 채널에 같은 글을 복사하거나 채널 수만큼 신규 제작하지 않는다.

**PULSE 작품 한 벌:** 작품 채널은 감상, 소개물은 작품의 작은 입구, SHIFT는 공개 가능한 제작 판단, SYNK는 완료 기록을 맡는다. 작품마다 LAB 등록으로 끝내지 않는다.

**09-09 후속 요청 우선:** 제작 속도·요소·브랜드 킷 준비량을 이유로 콘텐츠·새 형식·채널의 추가를 배제하지 않는다. 기존 격주/재활용 위주/작업시간 상한은 이번 확장 검토의 제약이 아니다. 추가 여부는 타겟 적합성, 실제 이야기·제공물, 중복되지 않는 채널 역할, 사실·권리·필요한 후속 경험으로 판단한다. 이는 모든 채널의 매일 발행을 자동 확정하거나 광고 예산·가격·개강·응답시간을 변경한다는 뜻이 아니다. 빈도·분량은 실제 사건과 기록에 맞춰 정하며 [과정 공개와 후속 지원](SHIFT_공개수업.md)에 따라 필요한 형식을 고른다. 과거 숫자 가안을 현재 의무로 복원하지 않는다.

### 7-3. 검색·문의·광고·협력

- **검색에서 오래 쓸 자료:** LAB은 실제 문장·상황, SHIFT는 회사에서 실제로 만든 것·겪은 문제·AI와 해결한 과정을 제목과 설명에 정확히 남긴다. 같은 사례의 방법·도구 설명은 관련 이야기와 이어 찾게 한다. 최신성이 중요한 대학 요강·도구 요금은 확인일과 정정 이력을 붙인다. 검색 순위 보장은 하지 않는다.
- **문의:** 자료를 받아본 뒤 자신의 상황을 설명할 수 있도록 질문 틀을 제공한다. 공개 댓글로 연락처·학교·체류정보를 요구하거나 댓글→자동 DM 수집을 기본 경로로 만들지 않는다. 상담 신청과 뉴스 구독은 분리한다.
- **유료 광고:** 기존 성인/학부모 Facebook 계획·예산·현지어 검토·판매 준비 조건을 따른다. 이 정본은 집행·예산 증액·새 결제를 승인하지 않는다. 청소년에게 공개 노출·불안·가족 사정을 이용한 압박 광고를 설계하지 않는다.
- **협력:** 실제 학교·창작자·강사와 할 일이 생기면 각자의 역할과 권리를 확인한 뒤 함께 만든 결과를 보여준다. 먼저 협업 로고를 배열하고 나중에 관계를 만드는 방식은 쓰지 않는다.

| SYNK 협업 상대 | SYNK의 사업 관계, 실제 완료물과 맡는 일 | 정확한 회사 소개·완료 기록·해당 사업의 준비된 안내 |

표의 문장은 **내부 기획·관측 질문**이다. 검색량·고객 발언·지불 의사를 검증한 목록도, 그대로 제목과 해시태그에 반복할 문안도 아니다. 한 콘텐츠에서는 기존 상대와 제공물을 먼저 정한 뒤 실제 내용과 맞는 질문 하나만 연결한다. 학생의 즐거움·유호의 실제 회사 이야기·실습의 충실함·작품 감상을 검색 문구 때문에 약하게 만들지 않는다.

**제작·발행에 함께 적용할 것:** 기존 제목의 장면·목적을 살리고 설명 본문에 필요한 대상·상황·제공 범위를 읽히게 쓴다. 예문·수업의 필수 정보는 이미지나 영상 안에만 가두지 않고 본문·자막·자료 안내에도 맞게 남긴다. 원본 자료와 다음 행동은 실제 열리는 주소·파일로 연결하고 회사명·상품 조건·현재 상태를 일치시킨다. 새 공개 URL·계정·자료 접근은 실제 확인 전 연결 완료로 쓰지 않는다.

공개용 웹의 읽힘·링크·검색 접근을 개선할 수 있으나 비공개 기업 웹을 이 목적만으로 공개하거나 수집 허용을 바꾸지 않는다. 공개 사이트의 접근 허용도 실제 현재 설정을 확인하고 다룬다. SNS 제작본·로컬 자료·공개 웹·실제 게시를 따로 기록한다.

**관측의 순서:** 고객이 무엇을 받는지 이해하고 실제 사용·감상을 이어가는지가 먼저다. 검색·AI의 언급·인용·상품 설명 정확도는 내부 보조 관측이다. 서비스·언어·질문·관측일·실제 검색 실행 여부를 기록하며, 검색 없는 모델 지식과 검색을 실행한 답을 합산하지 않는다. 새 유료 호출·예약·추적 도구·중앙 큐를 이 적용만으로 시작하지 않는다.

**중단·복귀 기준:** 고객이 제공물을 더 자주 오해하거나 관계없는 문의가 늘면 추가한 키워드·연결·설명을 먼저 줄인다. 제목·본문을 바꾸었다면 기간·대상·바꾼 한 요소와 관찰 범위를 남긴다. AI 언급 증가만으로 채택하지 않으며, 작은 표본의 변화나 원래 없던 데이터를 성과·손해로 단정하지 않는다. 기존의 좋은 콘텐츠와 전용 형식을 유지하고 발행량을 임의 비율로 고정하지 않는다.

기관·대학·새 앱·새 작품으로 발견 범위를 넓히는 때에는 해당 고객의 반복 질문, 실제 제공물, 담당·지원 범위, 사용 또는 구매 근거를 먼저 확인한다. 기존 주력 고객과 다른 내용은 맞는 별도 안내에 놓고, 주력 피드의 비중 변경은 그때의 근거로 판단한다. 이 조건은 사업·제작 확장을 일괄 금지하거나 새 승인을 매번 요구하는 규칙이 아니다.

Google의 현행 안내도 고객에게 유용한 독자적 내용과 명확한 웹 구조를 강조하며, AI만을 위한 문체·검색 표현별 대량 페이지를 요구하지 않는다. 이는 Google 검색 안내이며 모든 AI의 내부 추천 공식을 설명하는 것은 아니다. [공식 안내](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide), 2026-09-10 확인.

첫 적용은 [09-10 회사별 대표 콘텐츠의 발행 연결](../홍보물/회사별콘텐츠_20260910/회사별_마케팅보고.md#discovery-application)에 남긴다. 장기 [로드맵 제안](../AI추천_통합마케팅_로드맵_제안_20260910.md)은 이 절의 현재 적용 범위와 구분한다.
