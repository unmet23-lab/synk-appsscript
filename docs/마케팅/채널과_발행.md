## 회사·사람 중심 브랜딩

2026-09-19 사용자 확인: 기존 대상·언어·계정 역할을 유지하면서 회사 중심 브랜딩과 사람 중심 브랜딩의 목적을 함께 적용한다. 메인·서브라는 고정 등급이나 별도 계정을 추가하는 결정이 아니다.

- 회사 중심 브랜딩은 누구에게 어떤 가치를 주는지, 어떤 철학으로 선택하는지를 실제 제공 경험·결과와 함께 보여준다.
- 사람 중심 브랜딩은 유호의 경험·판단·제작 과정과 직접 설명하는 모습을 통해 유호를 알고 계속 볼 이유를 만든다. 얼굴 출연 없이 쓴 글도 이 목적을 맡을 수 있다.
- LAB에는 학습자를 이해하고 연습을 돕는 유호, yuhobuilds에는 SYNK를 만드는 유호, synkbrief에는 AI 소식·스킬과 도구·활용법을 골라 설명하는 유호가 어울린다. 같은 출연자여도 내용의 도착지는 독자와 목적에 맞춘다.
- yuhobuilds는 AI 완전 초보부터 AI를 활용하는 1인 기업가까지를 대상으로, 유호의 실화와 각색을 바탕으로 AI를 활용해 SYNK를 만드는 시행착오를 이야기로 풀어낸다. 친근하고 재미있고 이해하기 쉽게 팁·정보를 전달하며, 당시 막힌 장면에서 필요한 개념·세팅·따라하기를 순차적으로 설명한다. 초급부터 필요한 활용 능력을 쌓고, AI로 자기 일·제품·서비스·사업을 만들고 운영하는 1인 기업가의 역량을 기르는 채널을 지향한다. 필요한 고급 주제도 실제 문제에 맞춰 다룬다. LAB·PULSE·PATH 관련 실제 제작 경험도 다룰 수 있다.
- 한 게시물이 학습·실무 효용과 회사·인물 브랜딩을 함께 맡을 수 있다. 독자와 목적에 맞으면 같은 게시물·자료를 재사용한다. 출연 여부를 채널 전체의 의무나 금지로 고정하지 않는다.

## synkbrief의 AI 뉴스·추천·활용법

### 확정 시리즈 · 뉴스·활용·기초

2026-09-27 사용자 확정: “좋아 훨씬 깔끔하네. 이 내용 저장해줘 앞으로 이렇게 가자.” 앞으로 기획·표지·제목·발행 분류에 아래 세 이름을 사용한다. ‘베네핏’ 대신 **활용**으로 정하고, 도구·스킬 추천과 활용법을 같은 시리즈에 묶는다.

| 시리즈 이름 | 시청자가 보러 오는 이유 | 다루는 내용 |
|---|---|---|
| **synkbrief 뉴스** | AI에 무엇이 달라졌고 나에게 어떤 도움이 되는가? | 최신 소식·업데이트, 실제 사용 조건·이용 가능 여부, 자기 일에 미치는 영향 |
| **synkbrief 활용** | 이 일을 더 쉽게 할 수 있는가? | 도구·스킬 추천과 사용법을 통합. 구체적인 불편 → 적합한 도구와 선택 이유 → 사용 과정 → 결과·전후 차이. 추천 모음도 이 시리즈에 포함 |
| **synkbrief 기초** | 처음인데 어디서부터 시작하는가? | 왕초보가 순서대로 따라 하는 가입·화면 이해·개념·설정·첫 사용. 컴퓨터 선택도 AI를 시작할 때 필요한 판단과 연결 |

- **채널은 시청 목적과 맥락으로 나눈다.** synkbrief는 시청자가 알고 직접 할 수 있게 하는 독립적인 설명·수업, yuhobuilds는 유호가 직접 만들고 도전하며 겪은 문제·선택·해결의 이야기다. 왕초보용 독립 강의는 `synkbrief 기초`에 두고, yuhobuilds에서도 실제 경험 속에 필요한 개념·설정·따라하기를 설명한다. 같은 소재를 각 채널의 맥락에 맞춰 다룰 수 있다.
- **기초는 입문 과정의 순서다.** 뉴스·활용도 초보자가 이해할 수 있게 설명한다. 기초 시리즈를 만든다는 이유로 채널 전체를 왕초보 전용으로 바꾸거나 뉴스·활용을 어렵게 만들지 않는다.
- **시리즈 이름은 작게, 시청자가 얻을 것은 크게.** 표지의 분류 표시에 정확한 시리즈 이름을 쓰고, 본제목에는 구체적인 필요·문제·결과를 담는다. 예: 작은 `synkbrief 기초 · 01` + 큰 `AI 배우려는데, 노트북부터 사야 할까요?`; 작은 `synkbrief 활용` + 큰 `뒤죽박죽 회의 메모, 읽기 쉽게 정리하는 법`. 이는 제목 구성 예시이며 회차나 발행 순서 확정이 아니다.
- **먼저 볼 이유를 정하고 분류한다.** “무엇이 바뀌었나?”는 뉴스, “이 일을 어떻게 해결하나?”는 활용, “시작하기 전에 무엇을 알아야 하나?”는 기초다. 그다음 [공통 제작 기준](콘텐츠_제작양식.md#시청자가-볼-이유부터)에 따라 정보와 재미·이해하는 즐거움, 실제 따라 할 과정과 제공 자료를 준비한다.

아래의 이전 제작 이력·양식 파일명은 보존한다. 현재 시리즈 분류는 위 확정안을 따르며, 시리즈 확정은 개별 원고·영상·게시 일정의 승인을 뜻하지 않는다.

### 처음 보는 사람이 따라 할 수 있는 설명과 제공 자료

2026-09-22 사용자 후속 확정: 결과를 감상하는 영상에 그치지 않고, 초보자에게 가르치듯 사용할 프로그램·입력·조작·작동 결과·필요한 이유·실제 활용까지 연결한다. 회의 메모 v3의 “회의는 끝났는데, 누가 뭘 하죠?” 도입과 결과 중심 15초 구성은 이해와 실행 안내가 부족하다는 피드백을 받았다. 승인된 대표작으로 쓰지 않는다.

- **상황부터:** 시청자가 실제로 하는 일과 불편을 자연스럽게 설명하고, 이번 영상으로 얻는 결과를 구체적으로 보여준다. 도입 문장은 소재마다 쓴다.
- **따라 하는 과정:** 프로그램 이름과 시작 위치 → 어디에 무엇을 입력/선택하는지 → 실행 → 결과 확인 → 자기 업무에서 쓰는 방법을 보여준다. 매 단계의 행동과 필요한 이유를 같은 장면에서 설명한다. 용어는 처음 나올 때 풀어주고, 실제 입력 화면 없이 결과만 움직이는 그래픽으로 대체하지 않는다.
- **빠르되 생략하지 않기:** 기다림·반복·불필요한 전환을 줄여 템포를 높인다. 화면에서 위치를 먼저 짚고 확대하며, 읽고 입력해야 하는 정보에는 시간을 남긴다. 빠른 영상의 세부 내용은 제공 자료에서 다시 따라 할 수 있게 한다.
- **매편 실제 제공물:** 시청자가 보고 따라 할 가이드 PDF 또는 실행에 맞는 파일을 완성해 엔딩에 실제 미리보기와 구성품을 보여준다. 활용법은 단계·복사용 입력·연습 자료·예상 결과·확인법·막힐 때 해결법을 준비한다. 뉴스·추천도 유형에 맞게 적용 조건·실행 방법·비교표·원문 링크 등 행동에 도움이 되는 자료를 제공한다.
- **엔딩:** 얻을 효용 → 실제 자료 내용 → 받는 행동을 연결한다. 예: “회의 정리 템플릿과 따라 하기 PDF가 필요하시면 댓글에 synk를 남겨주세요.” 회차에 맞게 문구를 쓰며, 프롬프트 파일을 설치형 스킬이라고 부르지 않는다.
- **전달 확인:** 파일을 실제로 열고 복사·연습해본 뒤 약속한다. 자료 준비, 공개 다운로드 경로, 댓글에 대한 수동 전달, 자동 DM 연결은 별도 상태다. 댓글 유도 문구만 만들고 자동 전달까지 작동한다고 보고하지 않는다. 게시 전 해당 채널에서 사용할 전달 경로를 확인한다.

### 매편 자료 조사와 설명용 이미지

2026-09-22 사용자 요청: 매편 제작하는 날짜를 기준으로 이해에 도움이 되는 자료를 적극적으로 찾고 반영한다. 필요한 시각 자료는 GPT Image 2.5를 적극 활용해 생성해도 된다. 이 기준은 synkbrief의 뉴스·기능 소개·활용법·도구와 스킬 팁에 공통 적용한다.

- **출처와 반영 위치:** 각 편의 작업 폴더에 링크·발표/업데이트 날짜·실제 확인 날짜·확인한 내용·사용한 장면을 기록한다. 출처가 밝힌 기능과 직접 시연한 결과를 구분한다. 게시 시점에 기능이나 화면이 달라졌으면 해당 부분을 다시 확인한다.
