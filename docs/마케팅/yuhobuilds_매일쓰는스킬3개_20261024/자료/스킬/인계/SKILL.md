# 인계 — 긴 대화를 한 장으로 넘기기

대화가 길어지면 앞에서 정한 것을 놓치고, 같은 것을 다시 묻고, 고친 것을 되돌린다. 그때는 더 버티지 말고 지금까지를 한 장으로 적어 새 대화창에서 이어 간다. 새 창은 앞 대화를 모르니, 메모 한 장만 읽고도 바로 이어 갈 수 있어야 한다.

## 언제

- 사용자가 부를 때.
- 내가 앞에서 정한 것과 어긋나는 말을 했거나, 사용자가 같은 설명을 두 번 했을 때 — 「대화가 길어졌어요. 인계 메모를 써서 새 창으로 넘길까요?」라고 한 번 묻는다.

## 인계 메모 꼴

아래 일곱 칸을 이 순서로, 칸마다 짧게 쓴다. 대화에 없는 것은 지어내지 않는다.

1. **목표** — 사용자가 처음에 바란 것. 사용자 말 그대로 한 줄.
2. **정한 것** — 확정된 것과 그 까닭 한 줄씩. 사용자가 「좋아」 · 「그걸로」처럼 분명히 고른 것만.
3. **한 것** — 끝난 일. 만든 파일 · 결과물은 이름이나 경로까지.
4. **지금 상태** — 하다 만 일이 어디서 멈췄는지.
5. **남은 일** — 다음에 할 일을 순서대로.
6. **하지 말 것** — 사용자가 싫다고 한 것, 해 봤는데 안 된 것.
7. **물어볼 것** — 아직 사용자에게 확인해야 하는 것. 없으면 「없음」.

## 순서

1. 대화를 처음부터 다시 훑어 일곱 칸을 채운다. 사용자가 한 말은 바꾸지 않고 「」로 옮긴다. 중간에 바뀐 결정은 마지막 것만 쓰고, 바뀌었다는 것을 한 줄로 적는다.
2. 메모를 사용자에게 보여 주고 「빠졌거나 틀린 것이 있으면 말씀해 주세요」라고 묻는다.
3. 파일을 만들 수 있는 곳이면 프로젝트 맨 위 `인계/` 폴더에 `YYYY-MM-DD_<한두 낱말>.md`로 저장한다.
4. 새 대화창에 붙여 넣을 첫 글을 만들어 보여 준다. 첫 줄은 이것이고, 그 아래에 메모 전문을 붙인다.

   > 아래는 앞 대화의 인계 메모예요. 먼저 「지금 상태」와 「남은 일」 첫째를 한 줄로 말해 주고, 「정한 것」과 「하지 말 것」을 지키면서 이어서 해 주세요.

## 지킬 것

- 메모는 한 장(40줄 안팎)을 넘기지 않는다. 길면 「한 것」을 줄이고, 「정한 것」 · 「하지 말 것」은 줄이지 않는다.
- 비밀번호 · 키 · 남의 연락처는 메모에 넣지 않는다.
