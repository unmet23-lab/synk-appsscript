# 범용판 스킬 셋 시험 기록 (2026-10-24)

장부 Y1의 「먼저:」 조건 — SYNK 전용 부분(경로 · 계정 · 비밀값)을 걷어낸 범용판을 만들고, 남이 받아 그대로 돌아가는지 새 하위 에이전트로 시험. 시험자는 이 대화 맥락이 없는 새 하위 에이전트(Sonnet)이고, 받은 것은 그 스킬 파일과 임시 프로젝트뿐이다. 임시 프로젝트는 세션 임시 폴더에 두었다(저장소 밖).

셋째 판 영상에는 일상 예시 셋(안내 문자 · 엑셀 · 빵집 인계)을 썼다. 이어서는 이해 시험 두 번에서 「한도 · 창 20개」가 개발자 얘기로 읽혀 영상에서 뺐다. 설치 프롬프트 시험은 이어서 · 다른눈 · 실수노트 첫 판으로 했다(인계와 그 뒤 고친 판은 페이지를 만들지 않아 다시 하지 않음). 처음에는 영상에 일상 예시 둘(안내 문자 · 엑셀)을 쓰기로 했다 — 첫 렌더 이해 시험에서 할인 함수 · 시험 통과 · `###` 표기가 「코딩 용어」로 읽혔다(기획.md 「이해 시험」). 할인 함수 · ffmpeg 시험은 스킬이 코드 일에서도 같게 도는 근거로 남긴다.

- 이어서의 5단계(실제로 보내기)는 시험에서 하지 않았다 — 유호님 창 스무 개를 깨우게 된다. 보내기는 원본 스킬이 같은 도구(`send_message`)로 10-20부터 다섯 번 실제로 했다. 시험이 끝난 뒤 창들의 마지막 활동 시각이 그대로인 것을 확인했다(아무 데도 보내지 않음).
