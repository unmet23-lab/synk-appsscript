# 매일 쓰는 스킬 3개, 파일째 드려요

장부 [Y1](../기획장부/yuhobuilds.md) · 2주 시험(10-26 ~ 11-07) 갈래 「실물 주기」 첫 편 · 만드는 순서는 [제작 절차](../기획장부/제작절차.md). **결론: 버림(10-24)** — 이해 시험 세 번이 모두 떨어졌다(2 · 3 · 3점, 아래). 마지막 판은 셋째 판(이해 시험 두 번이 떨어진 뒤 다시 짠 것 — 아래 「바뀐 까닭」).

## 실제 값

- 문제 · 다른눈 — 범용판 일상 예시 시험(10-24, [시험 기록](자료/스킬/시험기록.md)): 가게 사장님 요청 「10월 28일 수요일 하루 쉬고 … 80자 안으로」에 만든 문자가 「… 10월 27일 화요일 하루 쉽니다 …」(96자) → 새 하위 에이전트가 두 틀림(날짜 · 80자 넘음)을 다 찾음 → 고친 57자 문자에 두 번째 새 하위 에이전트가 막힘 · 틀림 0건. 첫 장면의 문자 본문과 다른눈 장면의 「✗ 날짜가 27일로 틀렸어요 · ✗ 80자를 넘었어요 · 틀린 곳 없음」은 이 값.
- 실수노트 — 범용판 일상 예시 시험(10-24): 「CSV를 엑셀에서 열면 한글이 깨짐」(BOM 없는 UTF-8) 항목을 네 줄로 적었고, 새 대화가 노트 제목 줄만 훑어 그 항목을 열고 처음부터 BOM 있는 UTF-8로 저장했다(직접 확인 `ef bb bf`). 화면의 쉬운 말 네 줄은 그 항목을 풀어 쓴 것.
- 인계 — 범용판 시험(10-24): 빵집 11월 첫 주문 이벤트 대화(15% → 10%로 바꿈 · 「이모지 안 써. 앞으로도」 · 해시태그 다섯 개 이하 · 사진은 내일)를 일곱 칸 메모로 적었고, 앞 대화를 모르는 새 창이 메모만 받고 「남은 일 첫째는 인스타 글 쓰기 … 10% 할인, 11월 1일~10일 … 이모지 없이 해시태그는 5개 이하로」라고 말한 뒤 그대로 썼다(해시태그 넷 · 이모지 없음). 화면의 긴 대화 말풍선 · 메모 일곱 칸 · 새 창의 답은 이 대화 · 메모 · 답을 줄인 것.
- 코드 일 시험(할인 함수 · ffmpeg 노트)과 이어서 미리 보기 시험(42개 중 보낼 창 8개)은 스킬이 개발 일에서도 같게 돈다는 근거로 시험 기록에 남긴다 — 영상에는 안 쓴다.

## 바뀐 까닭

- 첫 판(이어서 · 다른눈 · 실수노트, 할인 함수 · ffmpeg 예시)과 둘째 판(다른눈 · 실수노트 · 이어서, 일상 예시)은 아래 이해 시험에서 떨어졌다. 두 번 다 「한도 · 창 20개」가 「클로드 코드 쓰는 사람 얘기」로 읽혔고, 둘째 판은 0~4초에 「쓸모가 안 와닿는다」였다. 그래서 셋째 판은 문제(다 했다는데 틀림)로 열고, 이어서 대신 누구나 겪는 「대화가 길어지면 앞을 놓친다」의 인계를 넣었다. 이어서 범용판은 시험까지 마친 파일로 `자료/스킬/이어서/`에 두고 이번 페이지에는 싣지 않는다.

## 사실 검수(Fable, 10-24 · 첫 판 콘티)

「고쳐서」 → 반영: 끝 말을 파일이 아니라 받는 곳 링크로(DM은 링크 하나 · 페이지는 붙여 넣는 설치 글), 입력칸 「/이어서 바로」, 한 문장 「처음 보는 AI」, 실제 값 두 숫자 줄, 「다음 날」 띠를 「새 대화」로, 「문제 0」을 「틀린 곳 없음」으로. 캡션 · 페이지로: Code 탭에서만 · 「바로」의 뜻 · 깨우지 않는 창 · 안내 파일 한 줄 · 범용판은 10-24에 새로 만든 파일. 셋째 판은 장면 · 말이 바뀌어 최종본 Fable 검수에서 다시 본다.

## 결론 — 버림(10-24)

제작 절차 「세 번째도 안 되면 장부 줄을 버림」대로 장부 Y1을 「버림」으로 했다. 슬롯 10-26은 비워 둔다(다음 07시 작업이 장부의 다음 「고름」 줄을 만든다). 게시 묶음 · synk.im/prompts 항목은 만들지 않았다.

- **까닭:** 비개발자 시청자에게 30초 안에 「스킬이 무엇이고, 어디에 넣고, 셋이 각각 무엇을 하는지」를 다 알아듣게 하지 못했다. 셋째 판에서 문제(다 했다는데 틀림)는 통했지만(답 1이 한 문장과 같아짐) 셋을 나열하는 순간 「추상적」이 됐다. 하위 에이전트는 사람보다 잘 알아듣는데도 3점이었다.
- **남긴 것:** 범용판 스킬 넷(`자료/스킬/` — 다른눈 · 실수노트 · 인계 · 이어서)과 시험 기록(새 하위 에이전트로 모두 통과, 설치 글은 원본과 글자까지 같은 파일을 만듦), 셋째 판 Remotion 원천(`remotion/` — 다시 만들기: `node 준비.mjs` → `node 음성시각.mjs` → `node 음악.mjs` → `npx remotion render src/index.ts ig out/ig-v5.mp4`), 목소리(`음성/`).
- **다시 한다면(제안, 순위 관문을 거쳐야 함):** 스킬 하나만 — 「다른눈」 한 편으로, 첫 2초 문제(다 했다는데 날짜가 틀림) → 설치 글을 클로드에 붙여 넣는 장면 → 같은 일을 다시 시키면 새 클로드가 먼저 잡는 장면까지. 셋째 시험의 막힌 말(어디에 붙이는지 · 새 클로드를 어떻게 부르는지)이 한 편에 한 스킬이면 풀린다.
