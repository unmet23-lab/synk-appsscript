## A · 인스타 릴스 (결과형 훅)

**캡션**

```
진짜 라볶이 사진을, 빛이랑 배경만 AI로 다듬었어요.

메뉴판에 AI로 만든 음식 사진, 지금은 식당이 따로 표시할 의무가 없대요(과기정통부 관계자, 뉴시스 10.13).
그런데 손님은 "막상 음식이 나왔는데 실제랑 다르면 속은 기분이 든다"고 해요.

그래서 없는 음식을 새로 만들지 말고, 찍은 사진을 다듬는 쪽을 권해요.
사진 편집이 되는 AI(ChatGPT·제미나이 등)에 사진을 올리고 아래 요청문을 붙여 넣으세요. 영상 속 결과는 GPT 이미지로 다듬었어요.

[메뉴 사진 다듬기 요청문]
이 사진 속 음식은 그대로 두고, 빛·색·배경만 다듬어 주세요.
· 음식의 양·재료·모양과 그릇은 바꾸지 마세요. 더하거나 빼지 마세요.
· 창가 자연광처럼 부드럽고 밝게, 색은 실제에 가깝게.
· 가장자리 잡동사니만 정리하고 구도는 그대로.
· 없던 수증기·윤기·글자는 넣지 마세요.
· 국물은 원본처럼 노란빛 도는 주황색 그대로, 더 빨갛게 하지 마세요.
(마지막 줄은 내 음식 색으로 바꿔 쓰세요)

올리기 전 확인 셋
✔ 양: 떡·면·건더기 개수와 크기가 같은지
✔ 재료: 없던 재료가 생기거나 빠지지 않았는지
✔ 색: 원본과 나란히 놓고 색이 같은지

저희도 "색은 실제에 가깝게"라고만 썼다가 국물이 빨개졌어요. 색은 콕 집어 적어야 덜 바뀌고, 그래도 똑같진 않으니 마지막 확인은 꼭 눈으로 해 주세요.

AI 메뉴 사진, 표시해야 할까요? 댓글로 O · X 남겨 주세요.

실제 사진: Theodore Nguyen / Pexels. AI로 다듬은 사진과 AI 생성 예시는 영상 속에 표시했어요.

#AI활용 #메뉴사진 #자영업 #소상공인 #AI사진
```
