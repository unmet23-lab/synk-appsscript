## 그림 · 10-17

유호님 「이 세 관용구로 그림 굽기부터 시작해줘」.

- 굽기: GPT 이미지 2.5(구독 · `node tools/codex계정.js exec … -i 참고 -o 답.txt - < 지시문`, 보조 계정 bake1) 세 번 — 판1 몽글 진행자 여섯 표정(정본 몽글 본체·별눈·놀람·눈웃음을 흰 바탕 JPEG로 참고), 판2 그림 개그 셋 + 뜻 그림 셋(첫 편 오린 그림 모음을 질감 참고로만), 판3 배꼽 다시 굽기(판2의 배꼽은 살구색 공처럼 읽혀 줄무늬 셔츠를 걷어 올린 배로 바꿈). bake1 주간 0 → 1%. 판·지시문은 `판/`.
