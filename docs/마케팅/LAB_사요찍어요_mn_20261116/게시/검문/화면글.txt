🤔 몽골어 「авах」라는 낱말을 한국어로 어떻게 말할까?
붕어빵 사자! (붕어빵 가게 앞에서 친구에게 — 맞는 말)
사진도 사자! (사진 부스를 보고 — 「авах」를 그대로 옮겨 틀린 말)
사진을 사? (친구가 웃으며 되묻는 말)
아, 찍자! (고쳐 말한 맞는 말)
와, 잘 나왔다! (사진이 나오자 친구가 하는 말)
이거, 선물이야! (붕어빵을 건네며 하는 말)
자, 사! (붕어빵을 건네며 「авах」를 그대로 옮겨 틀린 말 — 한국어로는 「돈 내고 사」라는 뜻)
…돈 내라고? (친구가 지갑을 꺼내며 어리둥절해 되묻는 말)
아니, 받아! (다급하게 고쳐 말한 맞는 말)
너도 받아~! (친구가 붕어빵을 먹으며 찍은 사진을 몽글 머리에 얹어 주며 하는 말 — 「받아」를 맞게 씀)
돈 주고 사는 것 → 사다 ✓
⚠️ 사다 = 돈 주고 사는 것만
사진을 찍는 것 → 찍다 ✓
❌ 「사!」 = 「돈 주고 사!」
선물을 받는 것 → 받다 ✓
몽골어 「авах」는 한국어로…
가게에서 사는 것 → 사다
사진 → 찍다
선물 → 받다
몽골어로는 한 낱말, 한국어로는 셋!

Зураг бас авъя!
Зураг худалдаж авна гэж үү?
Аа, зураг даръя!
Вау, гоё гарлаа!
Энэ чамд бэлэг!
За, ав!
…Мөнгө төл гэж үү?
Үгүй ээ, бэлэг шүү — аваарай!
Чи ч бас аваарай~!
худалдаж авах → 사다 ✓
⚠️ 사다 = зөвхөн худалдаж авах
зураг авах → 찍다 ✓
❌ «사!» = «Худалдаж ав!»
бэлэг авах → 받다 ✓
Монголоор «авах» = солонгосоор…
Дэлгүүрээс авах → 사다
Зураг авах → 찍다
Бэлэг авах → 받다
Монголоор нэг үг — солонгосоор гурав!
