## 만든 것

- **틀:** 퀴즈 #2 v5b(100 BPM, 36초, 그림 개그 0초 훅 · 다음 문제 미리보기 · SAY IT + YOUR TURN · 짧은 보기)를 `remotion/`에 복사했다. 문제 순서는 미역국 → 식은 죽 → 김칫국.
- **그림:** GPT 이미지 2.5(ChatGPT 구독 Codex, bake2)로 [판/](판/) 두 판 — 판2 그림 개그·뜻 6개, 판1 몽글 진행자 6컷. 첫 진행자 판(흰 요리사 모자)은 흰 바탕과 함께 깎여 버리고 민트 모자로 다시 구웠다(3장, bake2 주간 10% → 13%). 오리기 `tools/펠트판_칸오리기.py`. 눈 감은 깜빡임 컷은 이번 판에 없다(`motion.ts` HAS_BLINK).
- **나레이션:** 한국어로만, Typecast 하나 목소리([대본_q3.mjs](remotion/대본_q3.mjs) → 판 `q3`). 땡·셋 둘 하나·딩동댕·따라 해 보세요·끝 네 줄은 퀴즈 #2 녹음 캐시를 그대로 쓰고 제목·해요체 여섯 줄만 새로 샀다. 「김칫국 마시지 마요」는 2초라 따라 말할 틈을 먹어 1.25배로 다시 샀다(합계 67자, 남은 113,266 / 200,000 안팎).
- **화면 글:** 몽골어 `src/kids/i18n.ts` MN, 간체·버마어 `src/kids/locales.ts`. 정지 화면 점검 `node 정지컷_q3.mjs`, 렌더 `node 렌더_q3.mjs`(§2-4 올림 화질), 검문 파일 `node 검문파일_q3.mjs`.
- **올림판:** 크롬 확장 10MB 상한 때문에 고화질 원본에서 x264 2패스로 10MB 아래 판을 만들어 올린다(10-19 유호님 「10MB 판으로 제가 올리기」, §2-4 예외).

## 검토

- **제미나이 검문**([게시/검문/](게시/검문/)): 버마어·간체 문법 「정상」, 역번역 뜻 같음. 몽골어는 처음 「어색」 두 곳 — 보기 Төрсөн өдөртэй → Төрсөн өдрөө тэмдэглэх, кимчи шөл → кимчитэй шөл — 고친 뒤 문법 「정상」·맞춤법 사전 의심 0(`mn.결과2.txt`).
- **Fable(10-19):** 「그대로 올림」, 꼭 고칠 것 없음. 고치면 좋은 것 둘을 반영했다 — 버마어 김칫국 딱지 ကင်မ်ချီဟင်း(반찬) → ကင်မ်ချီဟင်းရည်(국물), 예문 형광펜 「[식은 죽 먹기]예요」 → 「[식은 죽 먹기예요]」(띄어 보이지 않게). 간체 「喝海带汤」(먹다 = 吃이지만 중국어로는 喝汤이 자연스러움)과 예문 「마세요」·해요체 「마요」는 그대로 둔다.
- **화면:** 정지 화면 판 `node 정지컷_q3.mjs`(문제마다 4칸 + 끝 3칸)로 세 판 확인. 고친 것 — 버마어 오답 딱지 두 개가 두 줄로 커져 그림을 가려서 줄임, 끝 복습 「김칫국부터 마시 / 다」 → `word-break: keep-all`, 몽골어 셋째 문제 조각이 넘쳐 한국어가 「김칫국부 / 터」로 끊겨서 조각을 кимчитэй шөл + уух로 줄이고 조각 글자에 `white-space: nowrap`.
- **올림 화질:** 세 판 −14.2 LUFS · 최대 −1.2 dBFS, 고화질 원본 `tools/영상사전검사.mjs` 「ready」 문제 0개. 10MB 올림판은 9.2MB(영상 2.02Mbps).
- 원어민 검수는 하지 않는다(10-19 유호님, 결정 표 — 역번역 Opus · Fable · 아르곤이 기준). 올리기 전에 유호님 검수(10-19 「완성되면 바로 올리지말고 나한테 한번 검수 받자」).
