# LAB 캄보디아 틱톡 @synklab.kh (2026-11-19)

쉬던 yuhobuilds 틱톡 계정을 LAB 캄보디아 틱톡으로 바꿨다. 유호님 11-19 말씀은 「yuhobuilds 틱톡을 다른거로 바꾸자. 틱톡은 10대 타겟이니까 아직 국가 설정을 못한 나라로 바꿔도 될것같아. 캄보디아인가 거기로 해도 되고」다. 나라는 조율 세션이 게시 성과 숫자로 캄보디아를 골랐다. 원장 키는 `lab-kh-tiktok`이고, 옛 키 `yuhobuilds-tiktok`은 닫았다.

## 계정 상태

- 웹 TikTok Studio 첫 화면과 콘텐츠 목록에 경고가 없다. 시스템 알림은 이번 로그인 알림 하나뿐이다.
- 11-05에 유호님이 앱 「Account check」를 보셨을 때 전부 체크 표시였다. 오늘은 앱에서 다시 보지 않았다.
- 11-01에 쉬게 된 까닭은 계정 전체 조회 0이었다. 그 뒤 11-05에 시험으로 올린 편(PC 정리)은 조회 213이 나왔다. 그래서 계정 전체가 막힌 상태는 아니라고 본다.
- 11-09에 이메일로 만들다 만 캄보디아 틱톡 계정은 인증 코드 메일만 있고 가입 완료 메일이 없다. 생기지 않은 것으로 본다.

## 소개 말투 검사(세 겹)

1. **카본:** 처음 후보 세 줄을 모두 「어색」으로 봤다. 짧은 장면을 뜻한 「ឈុតខ្លីៗ」 대신 「វីដេអូខ្លីៗ」(짧은 영상)를 권했다. 자막 낱말 「អក្សររត់」은 흘러가는 글자띠라며 「អក្សរខ្មែរ」를 권했고, 첫 절은 「ក៏…បានដែរ」로 이으라고 했다.
2. **Opus 직역(원문 안 봄):** 「ឈុត」가 「옷 한 벌」로 먼저 읽힌다며 「វីដេអូខ្លីៗ」를 권했다. 「អក្សររត់ខ្មែរ」는 크메르어 자막으로 분명히 읽힌다고 봤다.
3. **Fable 5.2:** 「វីដេអូខ្លីៗ」만 받아들이고 후보 B를 통과시켰다. 「អក្សរខ្មែរ」만 쓰면 「크메르 문자」로 읽혀 뜻이 흐려진다. 「ក៏…បានដែរ」는 「한국어로도 말할 수 있다」로 뜻이 물러지고, 태국 · 카자흐 소개의 꼴과도 다르다.
4. **고친 줄 다시 채점:** 카본은 같은 두 가지를 다시 짚었다. 두 번 같은 지적이 나와 11-18 점검 때처럼 Fable 통과판을 걸었다. 문법이 틀린 것이 아니라 말맛 차이다.
