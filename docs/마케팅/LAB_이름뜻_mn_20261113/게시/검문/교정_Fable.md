# 몽골어 교정 — Fable 5.2(11-13 19:10 무렵 · 화면 글 · 게시 글 최종 줄)

종합: 그대로 써도 됨 — 선택 고침 1곳(게시 글 끝 «бичээд өгье» → «бичиж өгье», 「써 드리다」의 표준꼴), 화면 글은 고칠 곳 없음. → 선택 고침도 넣었다.

| 줄 | 판정 | 까닭(요약) |
|---|---|---|
| Таны нэрийн утгыг / солонгосоор юу гэдэг вэ? | 그대로 | 격 어미 · 줄 나눔 자연스러움 |
| Багш: · Хэн бэ? | 그대로 | н 뒤 의문 첨사 бэ |
| нар / сар / ган | 그대로 | ган은 「가뭄」 뜻도 있으나 Болд · 쇳덩이 그림과 함께라 헷갈리지 않음 |
| 씨 = хүндэтгэлийн үг | 그대로 | 「높임말 · 존칭」으로 읽힘(더 정확히는 хүндэтгэлийн дагавар지만 길고 학습자에게 지금 것이 쉬움) |
| 몽글 = солонгос үг | 그대로 | 「한국어 낱말」로 읽힘 |
| хөвсгөр, зөөлөн | 그대로 | 「폭신 · 보송」 — 구름 · 펠트 그림과 맞음 |
| Нэр бүр утгатай · Таны нэр? · Сэтгэгдэлд бичээрэй! | 그대로 | 여격 -д · 권유 -ээрэй |
| 게시: Наран бол нар … Болд бол ган … | 그대로 | |
| 게시: Харин 몽글 бол солонгос үгнээс гаралтай нэр … | 그대로 | 「~말에서 온」의 굳은 표현 |
| 게시: «Монгол»-той дуудлага нь төстэй байгаа биз? | 그대로 | 공동격 모음 조화 · 「~죠?」 어감 |
| 게시: Нэрийн ард залгадаг «씨» бол хүндэтгэлийн үг | 그대로 | 「이름 뒤에 붙이는」이 정확 |
| 게시: … солонгос үсгээр бичээд өгье | 고침(선택) → бичиж өгье | 「써 드리다」는 бичиж өгөх가 표준꼴 |
