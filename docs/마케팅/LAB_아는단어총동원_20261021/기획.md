# LAB 「아는 단어 총동원」 · 2026-10-21

한국 사람이 「한국어 할 줄 알아요?」라고 묻자 학습자(시청자 자신, POV)가 아는 단어를 갈래마다 한 박자씩 쏟아내다(인사 → 숫자 → 도시 → 음식 → 당황), 「천천히 말해 주세요」 한마디로 대화를 잇는다. 남의 밈은 짜임(한 박자에 한 단어, 갈래 사이 반 박 숨, 엇나가는 끝)만 가져오고 영상·소리·말은 모두 새로 만들었다.

- **시청자가 얻을 것(제작 방식 v2 §2-1, 10-20):** 0~3.6초 약속 딱지 「STAY FOR THE 1 PHRASE THAT SAVES YOU」(몽골어판 「ЧАМАЙГ АВРАХ ГАНЦ ХЭЛЛЭГ ТӨГСГӨЛД БИЙ」) → 12초 무렵 달팽이 카드 「천천히 말해 주세요 / Please speak slowly」 → 묻는 사람 「네, 천천히 말할게요」 → 도장 「THIS ONE WORKS!」 → 따라 말하기 2초. 덤으로 14단어(읽는 법·뜻)를 한 번씩 듣는다.
- **학습자를 비웃지 않는다(카드 ②):** 화면의 「나」가 시청자 자신이고, 묻는 사람은 웃음을 참다가 바로 웃으며 들어준다. 발음은 또렷하게(하나 목소리, 낱말 끝 마침표).
- **오늘 고르는 자리는 최종본 하나:** 콘티 단계에서 유호님 답을 기다리지 않았다(1일 1편 운영). 게시·예약은 「오늘 편 게시」 세션이 「올려」를 받은 뒤 한다.

## 만든 것

- **틀:** 퀴즈 #4 `remotion/`을 복사해 색·만화 글자·판(`src/kids/theme.ts`)과 모션 부품(`src/lib/`)만 쓰고 화면은 `src/vocab/`에 새로 짰다 — `data.ts`(화면 글 정본, 영어·몽골어), `schedule.ts`(줄 길이로 낱말 자리), `VocabFilm.tsx`.
- **짜임:** 위 흰 띠(밈 머리글, 끝에는 댓글 질문으로 바뀜) · 묻는 사람(펠트 인형 표정 넷 + 말풍선) · 갈래 알약 + 「WORDS USED n」 · 가운데 같은 자리에서 낱말마다 펠트 그림 + 큰 한글 + 읽는 법·뜻이 바뀐다. 낱말 한 칸은 말 길이 + 0.08초(짧아도 0.56초), 갈래 사이 0.22초. 길게 남는 낱말은 그림이 천천히 다가오고, 「천천히 말해 주세요」·「네, 천천히 말할게요」는 말하는 낱말에 맞춰 한 낱말씩 차오른다(정지 구간 점검).
- **그림:** GPT 이미지 2.5(구독 Codex, bake2) 두 장(질감 참고는 퀴즈 #4 판2를 줄인 JPEG) — [판1 단어 그림 15칸](판/판1_072034.png)(지시문 [판1_단어그림.txt](판/판1_단어그림.txt)) · [판2 묻는 사람 표정 넷](판/판2_072036.png)([판2_묻는사람.txt](판/판2_묻는사람.txt)). 오리기 `tools/펠트_흰바탕오리기.py --판=5x3 · 2x2`, 부산 칸에 끼어든 보물상자 반짝이 둘은 잘라냈다. 확인 [판/오린그림_확인/_모음.jpg](판/오린그림_확인/_모음.jpg).
- **나레이션:** Typecast `tools/나레이션굽기.mjs` · [remotion/나레이션_계획.json](remotion/나레이션_계획.json) 17줄 86자(≈86크레딧). 역할마다 목소리 하나 — 묻는 사람 범수(남자·나레이션 기본), 학습자 하나(낱말이 또렷한 목소리). 학습자 낱말은 1.1배.
- **음악·효과음:** 퀴즈 연재의 100 BPM 키즈 곡(S23) 재사용, 목소리 아래 −16dB. 낱말마다 작은 「톡」, 갈래가 바뀔 때 「휙」.
- **렌더:** `node remotion/렌더.mjs`(PNG 프레임, H.264 12Mbps slow, BT.709) → `마감.mjs`(−14.3 LUFS) → `게시/<판>/video.mp4`·`cover.png`(0.5초). 정지컷 판 `node remotion/정지컷.mjs`.

## 검토

- **사전·표기:** 낱말 14개와 로마자(국어의 로마자 표기법)는 Fable이 하나씩 확인했다. 「화이팅」은 실제 쓰임이 압도적이라 화면은 그대로 두고, 영어 설명글에 「standard spelling: 파이팅」을 붙였다(Fable P2).
- **마감 점검:** `node tools/정지구간.js` — 첫 렌더 19%(떡볶이 뒤·「천천히 말해 주세요」·「네, 천천히 말할게요」 동안 멈춤) → 낱말 차오르기·그림 다가오기·도장 자리 옮김 뒤 3% 통과. 음량 −14.3 LUFS · −1.3 dBFS.
- **받아쓰기:** 최종 영어판을 faster-whisper medium으로 받아써 17줄 모두 대본대로 들렸다(`remotion/out/받아쓰기_en.txt`, git 밖).
- **몽골어 세 겹(v2 §4-3):** ① 아르곤 검문 `node tools/몽골어대조.js --구독` — 첫 판 「어색」 3건(떡볶이 풀이 «халуун ногоотой будааны бялуу» 직역투, 첫 댓글 «дэлгэц», 겹친 소유 어미)을 고친 뒤 바뀐 줄 「정상」([검문/mn.결과.txt](게시/검문/mn.결과.txt) · [mn_바뀐줄.결과.txt](게시/검문/mn_바뀐줄.결과.txt)). ② Opus 직역 역번역(원문 안 보여 줌) — 지적 아홉. ③ Fable 「그대로 올림」 — Opus 지적마다 반영 여부를 판정했고, 반영한 것은 «дэбак»(ㄷ=д 일관), 카운터 «ҮГИЙН ТОО», 띠 «Би: мэддэг бүх үгээ хэлчихлээ». «удаан»(천천히/오래)은 문맥이 고정한다고 봐 그대로 뒀다. 바뀐 세 줄은 다시 검문했다([mn_바뀐줄2.결과.txt](게시/검문/mn_바뀐줄2.결과.txt)). 맞춤법 의심 «токбокки»·«Жэжү»·읽는 법은 외래어·고유명사.
- **Fable 최종 검수:** 「그대로 올림」(P0·P1 없음). P2 가운데 몽골어 셋·웃음 말풍선 0.5→0.8초·무대 40px 위로(쇼츠 가림막과 여유)·설명글 파이팅은 바로 반영했다. 남은 P3: 끝 화면 글 크기 일부(풀이 34px)는 보조 정보라 둠.
