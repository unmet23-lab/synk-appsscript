## 판마다 같은 설정

- 어린이 전용(made for kids) 아님 — 댓글(아는 단어 늘어놓기)이 필요하다.
- AI·합성 표시: 필수 아님. 펠트 그림과 특정인이 아닌 TTS라 사실적인 사람·장면이 없다(관용구 퀴즈 #2 판단과 같음). 참고 카드는 「유튜브 합성 표시는 올릴 때 켠다」고 적었으니, 켤지는 게시 세션이 퀴즈 연재와 맞춰 정한다.
- 언어: 목소리는 두 판 모두 한국어뿐이라 유튜브 동영상 언어 ko, 제목·설명 en. 몽골어판 글 언어 mn.
- 자동 더빙·Meta AI 번역(목소리·입 맞추기)은 끈다. 켜면 한국어 발음이 다른 말로 바뀐다(제작 방식 v2 §4-2).
- 끝 행동 링크 synk.im/try/learning-hub/ — 10-21 07:3x 응답 200(「SYNK LAB PLAY 한국어 놀이」, 한국어·영어 화면). 유튜브는 설명란·고정 댓글, 몽골은 첫 댓글(선택)에만.
- 인스타 해시태그: 캡션 4개 + 첫 댓글 0개 = 4개(5개 이하).
- 올리는 파일은 원본 `video.mp4`(H.264 약 11Mbps · BT.709 · −14.3 LUFS)다. 크롬 확장처럼 10MB 상한이 있는 길로만 올릴 수 있을 때 `upload_10MB.mp4`(x264 2패스)를 쓴다(10-19 유호님 예외).
- 트렌드 편이라 시한은 10-22다(카드의 트렌드 시한 10-22 21:52). 오늘 못 올리면 10-22 같은 시각으로.
