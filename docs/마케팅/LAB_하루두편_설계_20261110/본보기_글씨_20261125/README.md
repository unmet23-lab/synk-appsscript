# LAB 말 글씨 본보기 「튀는 글자」

유호님 11-25 「B로 가자」로 고르신 말 글씨다. 절차는 [제작 절차](../../기획장부/제작절차.md#lab-lettering)의 「말 글씨」다.

- [튀는글자.tsx](튀는글자.tsx)를 편의 `src/film/튀는글자.tsx`로 복사하고, 말풍선 대신 `<튀는글자 w={…} />`를 놓는다.
- 감정은 기쁨 · 당황 · 웃음 · 놀람 · 슬픔 · 화남 · 졸림 · 담담 여덟이다. 배우는 낱말은 `key`에 적고, 그것만 노랑이 된다.
- 배우는 낱말에 뜻 그림을 붙일 때는 `그림: '눈송이'`를 적는다. 낱말이 튀어나온 뒤 마지막 글자 오른쪽 위에 붙는다([뜻그림_눈송이.jpg](뜻그림_눈송이.jpg), 11-26).
- 한글은 폭(`폭`, 안 적으면 900)을 넘으면 저절로 줄어든다. 읽기(`read`)와 뜻(`mean`)은 줄이지 않으니 길면 나눈다.
- 꼬리는 `tip` 쪽으로 78px까지 간다. `tip`은 말한 사람 머리 옆이나 위로 잡아 얼굴을 덮지 않는다. 글자 덩어리도 얼굴 · 손을 덮지 않게 `x` · `y`를 장면마다 정한다.
- 줄 요소의 `data-synk-line`은 지우지 않는다. 없으면 화면 글 검사가 글자 하나를 낱말 하나로 센다.
- [시안비교.jpg](시안비교.jpg)는 지금(말풍선) · B · D를 같은 장면에 나란히 둔 것이다. D(예능 자막)는 쓰지 않는다. [부품확인.jpg](부품확인.jpg)는 이 부품을 실제 편 줄에 넣은 것이다.

확인한 것: 「서비스」 여섯 줄과 긴 문장 · 몽골어 줄에서 폭과 겹침. 첫 두 편(M76 · E50)이 화면 글 검사를 걸림 0으로 넘었다. 미학 맹검(E50)은 말 글씨 꼬리가 스티커 같다고 했다.
