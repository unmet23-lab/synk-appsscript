# LAB 말 글씨 본보기 「온전한 말풍선」

유호님 11-26 「아닌가 말풍선 있는게 더 나은것같기도하고. 아까처럼 말풍선이 조각나서 꺠져보이지만않으면 돼」 → 「서비스」 말풍선 화면을 보내시며 「이런 식으로 안짤리고 잘 나오는거는 이렇게 써줘도 좋을것같아」. 절차는 [제작 절차](../../기획장부/제작절차.md#lab-lettering)의 「말 글씨」다.

- [말풍선.tsx](말풍선.tsx)를 편의 `src/<편>/말풍선.tsx`로 복사하고 `<말풍선 w={…} />`를 놓는다. 「서비스」 편(E64 v5)이 처음 쓴 편이다([본보기.jpg](본보기.jpg)).
- 몸과 꼬리를 한 획의 SVG 길로 그린다. 꼬리가 몸에서 떨어지거나 글자 뒤에 묻히지 않는다. 화면 좌우 28px 밖으로 나가면 몸을 안쪽으로 밀고, 꼬리는 `꼬리x`(말한 사람 쪽)를 그대로 가리킨다.
- `x`는 말풍선 가운데, `y`는 꼬리 끝, `꼬리x`는 꼬리 끝의 x다. 크기는 글에 맞춰 저절로 정해진다.
- 크림색 몸, 먹색 테두리, 한국어는 먹색, 뜻은 파랑이다. 빨강과 초록은 틀린 말과 맞는 말에만 쓴다([맞는 말과 틀린 말](../../기획장부/제작절차.md#right-wrong-marks)).
- 말풍선은 얼굴과 손을 덮지 않게 놓는다. 오른쪽 단추 자리(x 920 넘게)도 피한다. 말풍선이 온전히 들어갈 자리가 없는 칸에는 [튀어나와 바로 서는 글자](../본보기_글씨_20261125/README.md)를 꼬리 없이 쓴다.
- 렌더한 뒤 띠로 처음부터 끝까지 보고, `node tools/화면글검사.js <편 폴더>`와 올리기 전 검사를 넘긴다.
