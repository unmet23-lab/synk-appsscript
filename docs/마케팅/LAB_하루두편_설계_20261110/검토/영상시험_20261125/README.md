# LAB 영상 시험 — Omni 1.2 Flash와 Veo 3.1 Quality(2026-11-25)

유호님이 11-25에 「우리가 이거 만들 때 사진으로 만들고 있잖아. 이걸 똑같은 느낌으로 영상으로 omni 최신버전 써서 만들면 어떠려나?」라고 물으셨고, 이어서 「응, 시험해」라고 하셨다. LAB 칸을 정지 그림 대신 영상으로 만들 때 품질이 나오는지 시험했다.

**결정:** 유호님이 비교 영상을 보시고 「옴니가 나은것같아. 베오는 아예 눈을 바꿔버려서 캐릭터 귀여운 감성을 없애버리네」라고 하셨다. LAB 영상 칸은 Omni 1.2 Flash로 굽고 Veo는 쓰지 않는다([결정](../../../../_ops/결정.md) 11-25). LAB 편에 영상 칸을 넣을지는 아직 정하지 않았다.

## 무엇을 구웠나

- 대상은 「덥다뜨겁다」(`../../../LAB_덥다뜨겁다_mn_20261123`)의 두 칸이다.
  - A(8초): 기준 장면에서 몽글이 계란에 닿고 펄쩍 뛰었다가 내려앉는다. 뒤의 친구들은 놀랐다가 웃는다.
  - B(4초): 닿는 순간을 가까이 찍었다. 몽글이 놀라고 몸을 뒤로 뺀다.
- 시작 그림은 둘 다 그 편의 GPT 판(k1d · k2)을 9:16으로 맞춘 것이다(`labvt_k1d.jpg` · `labvt_k2.jpg`). 기준 장면은 몽글과 그릇이 다 들어오게 줄이고 아래 바닥을 이어 붙였다.
- 같은 지시문(`지시문.json`)으로 Flow(77yuhbs)에서 Omni 1.2 Flash와 Veo 3.1 Quality를 한 판씩 구웠다. 지시문에는 몽글의 입 · 팔다리 없음과 구슬 눈을 적었다.
- 실행기는 광명역 공모 편의 Flow 도구를 세로 판으로 고쳐 썼다. git 밖 `.tmp/LAB영상시험_20261125/flow/`에 있고, 받은 영상과 비교 영상(`보기/비교_Omni_Veo.mp4`)도 같은 폴더에 있다.
- 크레딧은 236을 썼다(6,709 → 6,473). Omni는 8초 24 · 4초 12, Veo는 한 판 100이다. Omni는 한 판에 약 40초, Veo는 약 1~2분 걸렸다.

## 결과

비교 그림은 `비교_두순간.jpg`, 0.5초 간격 띠는 `A_Omni_띠.jpg` · `A_Veo_띠.jpg` · `B_Omni위_Veo아래_띠.jpg`다.

- **Omni가 몽글을 지켰다.** 두 칸 모두 입이 생기지 않았고, 눈은 구슬 눈 그대로였다. 놀람은 > < 꿰맨 눈과 붉어짐으로 보였다. A에서는 닿을 때 김이 터지고, 높이 뛰며 바닥에 그림자가 남고, 내려앉은 뒤 친구들이 웃었다.
- **Veo는 표정이 크지만 몽글이 아니게 됐다.** A에서는 흰자위 있는 눈과 빨간 발 같은 것이 돋았다. B에서는 흰자위 눈에 입을 벌려 비명을 질렀다. 친구들의 웃음 연기는 Veo가 더 자연스러웠다.
- Omni의 흠은 둘이다. A의 떨림 구간에 만화식 떨림 선이 그려졌고, 뛰는 순간 뒤의 친구 하나가 김에 가려 반투명해졌다.
- 11-23 광명역 편에서는 Veo가 인형 얼굴을 더 잘 지켰다. 몽글처럼 입 · 팔다리가 없는 캐릭터에서는 이번처럼 결과가 거꾸로였다.
- Flow 모델 목록에 Veo 3.1 Quality · Veo 3.1 Fast · Omni 1.1 Flash가 「12월 5일에 지원 중단 예정」으로 떠 있다. 그 뒤에 남는 것은 Omni 1.2 Flash와 Veo 3.1 Lite다.

## LAB에 넣은 방식

- 유호님 「아냐 편 전체를 영상으로 원했던거야」(11-25)로 칸 한두 개가 아니라 편 전체를 Omni 샷으로 굽는다. 절차는 [제작 절차](../../../기획장부/제작절차.md#lab-whole-video)의 「편 전체를 영상으로」다.
- 샷 계획 · 굽기 · 띠 · 넣기는 `node tools/플로우영상.js`가 한다. Remotion은 [본보기](본보기_Film.tsx)처럼 샷을 깔고 글과 소리를 얹는다.
- 한 편은 3~10초 샷 4~6개, 75~105크레딧이고 다시 굽기까지 110~160크레딧이다. 나라 판본은 원본 샷을 그대로 쓴다.
- 카메라는 고정하고(11-20 멀미), 지시문에 떨림 선 · 만화 효과를 넣지 않으며, 김이 인물을 가리지 않게 적는다.
