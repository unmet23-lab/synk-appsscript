# LAB 목소리 감정 본보기

유호님 11-26 「목소리가 이게 최선인가? 몽글이 목소리는 마음에 드는데 지금 감정이 좀 너무 별로라고해얄까」에 따라 「추울 때」 일곱 줄을 새로 구웠다. 친구 목소리는 들어 보시고 「A로 하자」로 고르셨다.

**까닭.** 예전 줄은 Typecast smart, 세기 1.0으로 구웠고 감정은 앞뒤 글로만 줬다. 몽글의 「몽골은 영하 삼십 도야.」는 마침표로 끝나 평평하게 읽혔다.

- **친구(20대 남자)는 일레븐 v4로 굽는다.** 목소리는 Taehyung, 안정 0.35이고 줄 앞에 감정 꼬리표를 쓴다(`일레븐.py`). 쉼표와 말줄임표를 많이 쓰면 3~5초로 길어지니 짧게 쓴다. 값은 글자당 약 0.44크레딧이라 열 줄에 200쯤이다.
- **몽글은 소진 그대로 둔다.** 앞뒤 글(`prev` · `next`)에 장면과 웃음을 적고 감탄사(「헤헤,」 「에이~」)를 붙인다. 세기는 1.0이고 `node tools/나레이션굽기.mjs`의 560Hz 경고가 없는 줄만 쓴다. happy와 toneup은 경고가 자주 나거나 점수가 낮았다.
- 말이 길어지면 시작 시각을 당기거나 atempo 1.14까지 올린다.
- **고르는 법.** 이름을 가리고 지금 판과 후보를 AI 귀 둘에게 들려 감정, 사람 같음, 또렷함을 매긴다(`맹검.py`). 두 귀가 갈리면 유호님이 들으신다.

맹검 점수(감정 / 사람 / 또렷, 귀 둘의 합): 친구 다섯 줄은 지금 40 / 47 / 84, A 73 / 68 / 74, B 75 / 72 / 71이었다. 감정은 크게 올랐지만 낱말의 또렷함은 떨어졌다. 「추워」와 「편의점 가자」는 채점 뒤 짧게 다시 구워 그 판은 채점하지 않았다. 사람 귀로 확인한 것은 유호님의 A 고르심뿐이다.
