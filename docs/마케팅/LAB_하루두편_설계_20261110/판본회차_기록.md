LAB 하루 두 편 · 39계정의 나라 판본을 매일 만드는 예약 작업이 회차마다 맨 아래에 한 절씩 더한다(2026-11-13 유호님 「작게 지금 넘기기」). 절차의 정본은 [제작 절차](../기획장부/제작절차.md#lab-two-a-day-20261110) 3과 [판본 시범](판본_시범.md) 「한 판본의 차례」이고, 여기에는 회차가 실제로 한 것 · 든 시간 · 읽은 것만 둔다. 다음 회차는 맨 아래 두 절을 읽고 시작한다.

## 회차 절의 꼴

```
## <YYYY-MM-DD HH:mm> 회차 — 통과 N · 쉬는 M · 남은 줄 K · 든 시간 H

| 편 | 키 | 결과 | 고친 횟수 | 든 시간(분) | 한 줄 |
|---|---|---|---|---|---|

- 고친 줄과 까닭: …
- 쉬는 판본(편 · 키 · 남은 지적 · 해 본 고침): … / 없음
- 돌 원본이 없는 계정: … / 없음
- 막힌 것(GPT 답 대기 · 인사 그림 없음 · 도구 오류): … / 없음
- 다음 원본에서 바꿀 것: … / 없음
- 모델 · 한도: 시험관과 현지어 겹에 실제로 쓴 모델. Fable 한도로 Opus 5.5 대체가 있었으면 그 근거
```

결과는 「통과」 · 「쉬는 판본」 · 「GPT 답 대기」 · 「건너뜀(까닭)」 가운데 하나로 적는다. 든 시간은 그 판본에 손댄 처음부터 올리기까지다.
