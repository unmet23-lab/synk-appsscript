## 목소리 · 대본 전체를 한 번에 읽힌 AI 성우(10-04)

**왜 바꿨나.** 10-03 판은 대사 12줄을 하나씩 따로 만들고 줄 사이에 0.25~0.65초 쉼을 넣어 이어 붙였다. 줄마다 억양이 새로 시작하고 「~했고,」 같은 이어지는 말 뒤에도 쉼이 들어가서 뚝뚝 끊겼다. 10-04부터는 대본 전체를 한 번에 읽히고(테이크 하나), 장면·자막 시각은 그 테이크의 낱말 시각에 붙인다. `voice-plan.json`의 segments는 화면·자막을 나누는 단위일 뿐 따로 만들지 않는다.

- **엔진:** 구글 Gemini TTS(Vertex AI, 이미 쓰던 무료 크레딧 프로젝트). 새 가입·결제 없음. `gemini-3.8-flash-tts`, 비교로 `gemini-2.5-pro-tts`.
- **연출 메모:** 메모와 대본을 머리글로 가른다(`### DIRECTOR'S NOTES` / `### TRANSCRIPT`). 1차 메모는 연출 지점을 대본 문장으로 짚었는데 12개 중 7개가 문장을 건너뛰거나, 없는 말을 지어내거나(「이게 하이라이트였어요 진짜 대단하죠?」), 메모를 소리 내 읽었다. 2차 메모는 대본 문장을 인용하지 않는다 → 18개 모두 문장을 빠뜨리거나 더하지 않았다(낱말 몇 곳의 발음은 받아쓰기로만 확인).
- **후보 30개 측정**([한번에_맞추기.py](음성/한번에_맞추기.py), 로컬 faster-whisper small): 대본 일치, 말 속도, 쉼, 목소리 높이, 잘림. 다섯을 골라 [후보 듣기 페이지](음성/후보_듣기.cjs)로 묶었다(바탕화면 `yuhobuilds_한줄시켰더니/성우_후보_듣기.html`, 마지막 칸은 비교용 10-03 목소리).

- 받아쓰기 small 모델은 「몽골어」를 「몽고로」(실제 발음 [몽고러])로, 「매뉴얼」을 「메뉴얼」로 적어서 일치가 0.94를 넘지 못한다. 대사별로 가장 낮은 곳은 s1(「'내 사진 저장해'로도 읽혀서」)이다.
- **다듬기**([테이크_다듬기.py](음성/테이크_다듬기.py)): Gemini 테이크는 큰 소리 몇 곳의 꼭대기가 잘려 나와서(1번 16표본, 4번 145표본) adeclip으로 되살리고, 0.42초(화제가 바뀌는 s0·i1·c1 앞은 0.6초)보다 긴 쉼만 가운데를 줄이고, 48kHz로 올리고, 큰 소리만 리미터로 눌러 −15 LUFS에 맞춘다. 말소리 자체는 늘이거나 줄이지 않는다.
- **장면 전환:** `voice-plan.json` scenes(그 장면 첫 대사 시작 − lead)로 [넣기.cjs](음성/넣기.cjs)가 계산해 `timing.js`의 `VO.x`에 적는다. 말이 이어져 앞 대사가 그때까지 안 끝나면 앞 대사 끝 − 0.06초로 늦춘다(앞 자막이 말 도중에 잘리지 않게). 효과음·LAB 릴스 영상의 기준점은 `x.s3`처럼 장면 전환에 묶었다.
- **효과음:** 말이 이어지면서 장면 컷·낱말마다 붙던 꾸밈 소리 11개(컷마다 키 누름, 낱말 틱, 문서 카드 팝 둘, 끝 화면 팝 등)를 덜었다. 보냄·체크·지움·거절·완료 같은 사건 소리와 전환 소리 23개는 남기고 조금 작게 했다.
- 첫 줄을 「AI한테 이 한 줄 보냈어요.」 → 「AI한테 이 한 줄 보냈더니,」로 바꿔 다음 줄과 이어지게 했다. 나머지 대사는 그대로다.

## 다시 만드는 법

```bash
node 음성/한번에_생성.cjs --유료-api --voices Charon --tag r3            # 대본 전체 한 번에(Vertex 종량제라 --유료-api)
HF_HUB_OFFLINE=1 STT_MODEL=small python 음성/한번에_맞추기.py 음성/후보/3.8-flash__Charon_r3.wav   # 받아쓰기·낱말 시각
python 음성/테이크_다듬기.py 음성/후보/3.8-flash__Charon_r3.wav          # → 음성/take/take.wav·take.json
node 음성/넣기.cjs --carve ~/.claude/skills/hyperframes-audio/scripts/carve.mjs --core <@hyperframes/core 0.8.114 설치 폴더>
npx --yes hyperframes@0.8.114 check
npx --yes hyperframes@0.8.114 render --quality delivery --output renders/yuhobuilds_한줄시켰더니_A_인스타.mp4
npx --yes hyperframes@0.8.114 render --quality delivery --variables '{"hook":"B"}' --output renders/yuhobuilds_한줄시켰더니_B_유튜브.mp4
node 음성/후보_듣기.cjs 음성/후보/듣기_목록.json --copy <바탕화면 폴더>   # 후보 듣기 페이지
```

- `넣기.cjs`는 테이크의 첫 말소리를 0.3초에 두고, `음성/timing.js`(window.VO: 대사 시작·끝, 낱말 시각, 자막 묶음, 장면 전환 x), `data-anchor`가 달린 효과음·영상의 시각, 영상 길이(마지막 말끝 + 1.6초)를 다시 쓴다.
- 음악(시티팝_147, 48초 지점부터)은 carve(세기 0.6)로 목소리 대역을 비키고, 말하는 동안 −8dB duck. 말이 이어져 0.3초부터 마지막 말끝까지 낮춘 상태다.
- 후보 테이크(`음성/후보/`)는 git 밖이다. 고른 것만 `음성/take/`에 남긴다.
