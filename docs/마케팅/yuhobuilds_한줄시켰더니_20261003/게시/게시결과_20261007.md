## 올리며 알게 된 것

- 크롬 창이 다른 앱에 완전히 가려지면 탭이 `hidden`이 된다. 그러면 유튜브 예약 날짜 칸 같은 팝업이 열리지 않고, 인스타 만들기 화면은 영상을 받아도 다음 단계로 넘어가지 않는다. 게시는 크롬을 화면에 띄워 두고 한다.
- 인스타 웹 만들기의 마지막 화면에 「콘텐츠 예약」 스위치가 있다(10-07 확인). 다음에는 웹에서도 예약할 수 있다.
- 인스타 캡션 칸에서 Escape를 누르면 「게시물을 삭제하시겠어요?」가 뜬다. 「취소」로 살렸다.
- 크롬 확장의 파일 올리기는 한 번에 10MB까지다. 6.7MB 조각 셋을 페이지 안에서 합쳐 원래 파일 칸에 넣고 sha256으로 원본과 대조했다.
