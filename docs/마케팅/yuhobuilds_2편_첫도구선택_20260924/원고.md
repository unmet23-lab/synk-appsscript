# yuhobuilds 2편 — 이름 네 개 앞에서 멈춘 초보

## 내레이션

1. 오늘은 출석 앱을 만들려다, AI 두 명에게 물어보고 더 혼란스러워진 이야기를 해볼게요.
2. 저는 그때 글라이드도, 구글 시트도, 슈파베이스도, 엔에잇엔도 처음 듣는 사람이었어요.
3. 클로드는 “글라이드와 구글 시트로 웹앱부터 만들어 보세요.”
4. 그런데 GPT는 “슈파베이스와 엔에잇엔으로 처음부터 탄탄하게 만드세요.”
5. 잠깐만요. 저는 학생 출석 하나 찍고 싶은데, 모르는 이름이 왜 네 개나 나오는 거죠?
6. 결국 클로드 쪽을 골랐어요. 구글 시트는 출석을 적는 표, 글라이드는 그 표를 보여줄 앱 화면. 초보인 제겐 첫 화면을 빨리 볼 수 있다는 설명이 와닿았거든요.
7. 그런데 앱을 만들기도 전에, 이번엔 클로드 코드 설정에서 멈췄습니다.
8. 검색하고, 다시 보고, 또 설정하고. 제 기억엔 처음 켜는 데만 한 시간쯤 걸렸어요. 출석은 아직 한 번도 안 찍었는데요!
9. 지금 다시 한다면 이렇게 물어볼 거예요. “두 방법을 비교해 줘. 개발 초보가 출석 기록 한 개를 남기는 첫 단계는 각각 뭐야? 낯선 말도 쉽게 풀어 줘.”
10. 그리고 도구를 켜기 전에, 작업을 둘 폴더 하나를 정해요. 앱을 만드는 작업대라고 생각하면 됩니다.
11. 지금 윈도우라면 Claude 데스크톱에서 Code 탭을 열고, Local과 그 폴더를 고르면 돼요. 당시 제 설정 화면을 재현한 건 아니고, 지금 따라 하기 쉬운 방법입니다.
12. 다음 편엔 그 폴더에서 첫 질문을 보내고, 받은 답이 어디에 남는지 같이 볼게요. 제가 헤맨 길, 여러분은 건너뛰세요.

## 편집 의도

- 1편의 ‘괴상한 앱’에서 이어지는 첫 갈림길. 대립의 핵심은 어느 AI가 옳았는지가 아니라 초보에게 필요한 **첫 검증 단위**가 빠졌다는 점이다.
- 3~4번의 AI 대사는 사용자의 회고를 바탕으로 한 **요지 재구성**이다. 실제 채팅 문구가 아니다.
- 구글 시트와 글라이드의 역할은 시청자 이해를 돕는 간단한 설명이다. 현재 Google Sheets 연동은 Glide 요금제에 따라 제한될 수 있어 실제 세팅 화면에는 현행 조건 확인 문구를 둔다.
- 7~8번은 사용자가 클로드 코드 설치/설정에 인터넷 검색을 통해 약 한 시간을 썼다는 회고에 근거한다. 당시 터미널 사용 여부와 정확한 오류는 확인되지 않았으므로 보여주는 설치 화면은 현재 시청자용이다.
- 9~11번은 현재 시청자에게 권하는 방법이며 당시 실제 행동으로 말하지 않는다. Claude Desktop Code 탭의 Local/Project folder 순서는 2026-09-24에 Anthropic 공식 문서에서 확인했다.
- 학원 현장 사용, 학부모 알림 구현, 앱 출시를 암시하지 않는다. 학생 개인정보는 화면에 사용하지 않는다.
