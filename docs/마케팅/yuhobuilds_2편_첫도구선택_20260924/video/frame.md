# 2편 화면 기준

1편의 종이·검정·라피스 파랑(`#FFFFFF`, `#000000`, `#3D6BC9`)과 SUIT 글꼴을 잇는다. 코믹한 실제 얼굴 합성, 두꺼운 검정 테두리, 짧은 파랑 포인트가 이 연재의 얼굴이다. 이번 편의 시각적 소재는 실제 회고에서 나온 **두 AI의 갈림길**, **처음 듣는 이름 네 개**, **아직 출석 0건인데 설정에 쓴 한 시간**, **작업 폴더 하나**다.

세로 1080×1920. 큰 말은 위쪽에서 왼쪽 정렬, 중간은 그림·카드의 움직임, 자막은 아래 안전 영역의 독립된 한두 줄. 한 화면에 긴 원고를 모두 쓰지 않는다. 발화와 핵심어의 등장 시점이 맞아야 한다. 배경 점무늬와 카드 그림자는 1편과 같은 결을 유지하되 모든 장면을 같은 카드 레이아웃으로 만들지 않는다.

현재 따라 하기 화면은 실제 Claude Desktop 화면의 캡처가 아닌 **단순화한 경로 안내**라고 밝힌다. 과거 사건은 `그때`, 현재 가이드는 `지금이라면`으로 분리한다.
