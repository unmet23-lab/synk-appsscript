## 이전 검토본 — 전체 리디자인 V2

[리디자인 영상](yuhobuilds_EP02_v2.mp4) · [컷별 구성](video-v2/STORYBOARD.md) · [전환 간격](video-v2/pacing-check.json) · [검사 결과](video-v2/check-report.json)

사용자가 2편 첫 검토본의 장면 전환이 부족하다고 지적하여, 기존 8장면을 **29개 컷**으로 다시 설계했다. 평균 **2.34초**, 최장 **3.37초**이며 29개 중 27개가 3초 이내다. 전환은 0.233초로 이어지고 얼굴 클로즈업, AI 답변 비교, 큰 숫자, 표와 휴대폰, 폴더와 앱 화면을 번갈아 배치했다. 프롬프트는 부분별 설명 후 전체 질문을 한 번 더 보여준다. 엔딩 문구와 같은 자막은 덜어냈다.

원고·음성·BGM은 첫 검토본에서 재사용했다. 기존 MP4와 `video/`는 보존하며 새 소스는 `build-redesign.cjs`, 새 프로젝트는 `video-v2/`다. 2026-09-24 화면 검사에서 lint·runtime·layout·contrast 오류와 경고 0건을 확인했다. 최종 영상 파일의 재생 검수는 아래 리디자인 검수 기록을 따른다.

2026-09-24 사용자 회고에 따른 검토용 쇼츠. Claude와 GPT의 다른 제안, 처음 듣는 도구 네 개, Claude Code 첫 설정에 약 한 시간이 걸린 경험을 이야기로 엮었다. 마지막에는 시청자가 자기 아이디어로 두 경로의 **첫 결과 한 개**를 비교해 물어보도록 안내한다. 1편의 화면 색·인물 연출·빠른 자막과 리듬을 이어간다.

## 사실과 현재 안내

- [사용자 원문 회고](../yuhobuilds_제작여정_202607-20260922/첫도구선택_사용자회고_20260924.md)를 별도로 보존했다. 당시 AI 대사는 원문 인용이 아니라 요지 재구성이다.
- Claude Desktop의 Code → Local → Project folder는 현재 시청자용 안내다. 과거 설정 화면 재현이 아니며 [Anthropic 공식 안내](https://code.claude.com/docs/en/desktop)를 확인했다. Claude Code를 이용할 수 있는 요금제가 필요하다.
- [Glide 공식 안내](https://www.glideapps.com/data-sources/google-sheets)에 따르면 Google Sheets 동기화에는 요금제 조건이 있다. 당시의 선택을 현재 모든 사람에게 무료인 경로로 설명하지 않는다.
- 음성은 Typecast **정의로 임시 음성**이다. 사용자가 나중에 자신의 목소리를 준비할 예정이다. API 키는 파일에 저장하지 않고 합성 후 로컬 연결을 종료했다.
