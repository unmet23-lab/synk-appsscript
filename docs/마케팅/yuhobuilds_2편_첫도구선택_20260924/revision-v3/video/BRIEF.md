## Intent

1편의 ‘괴상한 앱’ 뒤에 오는 시간순 실화 기반 스토리. Claude와 GPT의 서로 다른 제안, 모두 처음 듣는 도구 네 개, Claude 제안을 선택한 이유, Claude Code 첫 설정에 약 한 시간을 쓴 경험을 유머와 함께 풀고, 현재 초보자가 할 수 있는 작은 다음 행동을 남긴다.

## Assets

- 1편의 유호 얼굴 표정 이미지 — 동일 인물, 이번 편에서도 감정에 따라 변경.
- 1편의 다른 엔딩 사진 — 마지막 장면.
- 기존 시티팝 BGM — 동일 연재의 리듬 유지.
- 새 Typecast 정의로 내레이션 — 임시 음성, 사용자 육성으로 나중에 교체 가능하도록 원고와 분리.

## Customizations

- 화면의 핵심어, 말풍선, 비교 카드, 프롬프트 예시, 단계 안내가 발화와 함께 등장한다.
- 휴대폰에서 읽히는 자막과 빠른 쇼츠 템포. 얼굴은 놀람·난감함·미소로 변화한다.
- 과거 대화의 정확한 문구와 설치 오류는 알 수 없어 재구성 화면으로 처리한다.

## Notes

- 당시 앱 운영·학부모 알림 완성·시간 절감 실측을 암시하지 않는다.
- 현재 Claude Desktop 안내는 2026-09-24 확인한 공식 문서에 근거한다.
