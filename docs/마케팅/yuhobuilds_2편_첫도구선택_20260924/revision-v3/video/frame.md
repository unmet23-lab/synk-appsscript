# 2편 리디자인 화면 기준

SUIT와 흰색·검정·#3D6BC9를 유지한다. 얼굴 클로즈업, 채팅, 큰 숫자, 표, 휴대폰, 비교 질문과 판단 기준을 발화마다 전환한다. 실제 음성에 맞춘 36개의 독립 컷으로 구성하며 평균 2.09초, 최장 3.70초다. 같은 레이아웃에 글자만 바꾸는 리듬을 피한다. 콘텐츠는 1450px 안쪽, 자막은 아래 별도 안전영역. 전환은 0.233초 page-slide를 기본으로 쓰고 장면 의미가 바뀔 때 수직 이동이나 짧은 확대를 넣는다. 도구 이름과 문장 호흡이 끊기지 않도록 자막을 의미 단위로 묶고 두 줄은 균형 있게 나눈다.
