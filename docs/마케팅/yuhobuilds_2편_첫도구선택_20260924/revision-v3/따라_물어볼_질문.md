# 다른 AI 모델에 비교를 부탁할 때

Claude와 GPT 등에서 서로 다른 추천을 받았다면, Gemini 같은 다른 모델의 새 대화에 **자신의 상황과 두 선택지를 함께** 알려주고 비교를 부탁해 볼 수 있다. 어느 모델의 제안인지는 굳이 붙이지 않아도 된다.

## 영상의 예시 질문

나는 초보 개발자야. 지금 학원에서 사용할 출석 앱을 만들려고 해.

1. 웹앱 기반으로 Glide + Google Sheets로 만들기
2. Supabase + n8n으로 만들기

둘 중 어떤 걸 더 추천해?
비용, 난이도, 관리하기 쉬운지도 비교해 줘.
내 상황에서 추천하는 이유를 쉽게 설명해 줘.
판단에 필요한 정보가 부족하면 나에게 먼저 물어봐 줘.

## 답을 받고 직접 판단할 것

- 내가 감당할 수 있는 비용과 만드는 데 쓸 수 있는 시간
- 실제로 꼭 필요한 기능
- 만든 뒤 내가 관리할 수 있을지

다른 모델의 답도 참고 의견이다. 요금과 기능 조건은 해당 도구의 공식 안내를 확인하고, 가능하면 작은 예시를 직접 만들어 본 뒤 선택한다. 이 질문 자체는 Gemini에서 무료 이용 한도 안에서 시도할 수 있다. 앱 개발·배포·운영까지 무료라는 뜻은 아니다.
