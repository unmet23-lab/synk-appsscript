## 사실 확인

- 표준국어대사전에서 내리는 눈은 「눈:」(긴소리), 신체의 눈은 「눈」(짧은소리)으로 적힌다. 「눈사람」은 「눈」(雪) + 「사람」, 「눈물」은 「눈」(目) + 「물」이다.
- 「눈 + 물 = 눈물?」은 몽글의 말장난(눈사람이 녹은 물)이고, 화면은 바로 다음 카드에서 「눈 👁️ + 물 = 눈물」로 진짜 뜻을 보인다.

답 1은 v3에서 sonnet · GPT · 그록이 「눈은 내리는 눈(цас)이기도 하고 신체의 눈(нүд)이기도 하다」로 한 문장과 같았고, haiku는 이야기(눈사람 친구와 다시 만남)만 담았다. haiku 9번은 v2 · v3 모두 「같아 보임」(위 검은 칸에 낱말 공식을 적는 방식이 M43 「붙다」와 같다)이었다.

**v3 뒤 시험 없이 고친 것(v4 · v5 · v6 — 올릴 판):**
- 끝 반전 칸 d8과 「눈물이… 눈이 됐어~!」를 뺐다. 끝은 새 눈사람을 안는 칸과 끝 카드 「눈 ❄️ цас · 눈 👁️ нүд」로 맺는다(시험관 넷과 볼 이유가 같이 짚음).
- 5.6초 봄 칸에 몽글 「봄이다…?!」 / «Хавар боллоо…?!»를 넣고 그 칸을 0.6초 늘렸다(G · K가 두 번 같이 짚음).
- 「눈 + 물 = 눈물?」 카드에 몽글이 「눈에서… 물이 나와…」라고 말하기 직전 빨간 ✗를 찍고, 바로 진짜 뜻 카드 「눈 👁️ + 물 = 눈물 💧 (цас биш!)」로 넘어가게 했다(G · K가 두 번 같이 짚음).
- 배경음을 영상 끝까지 늘였다. 올리기 전 검사 「거의 멈춘 시간 24%」로 멈춘 칸 셋(눈사람 완성 · 꼭 안음 · 다음 겨울)에 천천히 다가가는 움직임을 넣었다(v6).

## 몽골어 세 겹

- 대조기(`tools/몽골어대조.js`, 화면 글을 9줄 안팎으로 나눔): 화면 글 · 캡션 모두 문법 「정상」. 맞춤법 의심은 입말과 한국어 소리 적기(нунсарам · нунмул 같은 키릴 읽기)뿐이다. v5에서 더한 「봄이다…?!」 / «Хавар боллоо…?!»도 따로 돌려 역번역 「봄이 되었다…?!」, 의심 낱말 없음이었다.
- 원문을 숨긴 Opus 직역: 뜻은 모두 맞음. 짚은 것 — 캡션의 «눈»-ийг 두 곳이 모음조화에 어긋남(독자는 «нун»으로 읽으니 -ыг) → «눈»-ыг로 고침. 녹는 장면의 「안 돼~!」 뜻 줄이 「아니에요~!」로 읽히고 끝의 「~」 때문에 가볍게 들림 → «Битгий ээ!»(안 돼!)로 고침. 「눈사람」 [눈ː싸람]의 된소리가 키릴 적기에서 빠짐(우리 키릴 읽기 규칙이 된소리를 따로 적지 않음 — 둠).
