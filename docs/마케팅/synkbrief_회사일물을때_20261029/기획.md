## 사실(공식 원문 — 2026-10-29 17:00 KST ego로 다시 열어 읽음)

OpenAI 도움말 「사용자 데이터가 모델 성능 향상을 위해 활용되는 방식」(https://help.openai.com/ko-kr/articles/5722486, 마지막 수정 9일 전). 영어판(/en/)도 같은 날 읽었다.
