# 게시글 · Y77 「클로드에 PDF 올리기 전에 — 글로 바꾸면 사용량이 얼마나 줄까」

판마다 올라가는 글의 정본은 각 판 폴더의 원고 파일이다. 이 파일은 사람이 읽는 판이다. 인스타 판의 영상은 `최종.mp4`(끝 말 「댓글에 피디에프라고 남기면 보내 드려요」), 나머지 판의 영상은 `최종_게시글판.mp4`(끝 말 「게시글에 다 적어 뒀어요」)다. 주소 https://synk.im/prompts/#pdf-to-text 는 자료 공개 전이다.

## 인스타 릴스

클로드에 PDF 올리기 전에, 이것부터 보세요 👇

같은 8쪽 약관을 클로드에게 두 번 읽혔어요. PDF 그대로는 23,596토큰, 크롬에서 전체 복사한 글은 10,917토큰이었어요. PDF 쪽이 2.2배를 읽었어요.

클로드는 PDF를 쪽마다 글로 한 번, 쪽을 찍은 그림으로 한 번 더 읽어요. 개발자 문서에도 그렇게 적혀 있어요. 그래서 글만 있는 문서도 쪽마다 그림값이 붙어요.

글이 대부분인 문서(약관, 계약서, 규정)라면
1. PDF를 크롬으로 열고
2. Ctrl+A, Ctrl+C
3. 클로드 대화창에 붙여 넣고 질문하세요.

이럴 땐 PDF 그대로 올리세요.
· 그래프나 도표 속 숫자를 물을 때
· 스캔했거나 사진으로 찍은 문서
· 복사한 글에서 숫자가 빠질 때

댓글에 「PDF」라고 남겨 주세요. 바꿔도 되는 문서 고르는 법, 글 바꾸는 순서, 붙여 넣은 글이 온전한지 클로드가 먼저 보게 하는 문장을 DM으로 보내 드려요.

· 클로드 도움말에도 메시지 길이와 첨부 파일 크기가 사용량에 든다고 나와 있어요. 다만 위 숫자는 앱의 사용량 표시가 아니라, 클로드가 읽은 양(토큰)을 잰 값이에요. 2026년 11월 21일에 쟀어요. 앱에서 사용량이 얼마나 덜 줄어드는지는 재지 못했어요.
