## 판매 시작 전에 남은 것

1. 포트폴리오 완성 뒤 동영상 더하기 — 첨벙댕 · 모두의코스(유호님 확인 · 다시 뽑기 뒤). 첨벙댕을 다시 뽑으면 상세 03 · 04 · 05의 컷 수 · 「22초」 · 컷 길이 막대 · 파형이 낡으니 `collect2.py` → `build.cjs`를 다시 돌려 상세 이미지를 바꿔 올린다. 두 편 중 하나라도 기각되면(솔서리처럼) 그 장면을 빼고 다시 굽는다.
2. 닉네임 · 프로필 — 프로필 소개글 원고는 다른 세션이 `docs/마케팅/PULSE_소개글_20261103/`에 쓴다(입력은 유호님 확인 뒤).
3. 사업자 확인 — 법인 C안(법인 전에는 사업 매출을 받지 않음)과 개인 판매가 부딪히는지(다른 세션 안내, 유호님 「사업자는 지금 정보만 기억」).
4. PDF 대표 쪽의 웹드라마 작품명(아는 대로 넣기).
5. 정가로 바꾸는 때: 주문 10건째가 끝난 날 패키지 값 · PDF 가격 쪽(원고의 `internalPriceAfter10Orders`).
6. 「내 제품으로 해 본 증거」(Fable 마케터 판단 — 후기 0 · 가상 브랜드뿐이라 첫 주문을 망설임): 사용 권한이 있는 실제 제품 한 종으로 「보내 주신 사진 → 합성된 광고 컷」 한 쌍을 만들어 상세 05에 더한다. 같은 시험으로 STANDARD 10일 안에 제품 모양 잡기(블렌더 · 사진 합성)가 드는지도 잰다.
