## 예전 초안(9-29, 서비스 #830107)에서 바뀐 것

- 값과 구성: 10초 19.9만 · 15초 39.9만 · 30초 69.9만(영상 + 정지 이미지) → 위 표. 10초 칸을 뺐고, 편집본 · 시리즈를 묶었다.
- **도구 이름을 뺐다.** 예전 본문의 「사용 도구 …」 절은 10-02 「사이트 · 공개 글에 도구 이름 금지」에 걸린다.

- 「오픈 기념 첫 10건」과 정가를 본문에 적었다 — 10건이 차면 패키지 값을 정가로 바꾸는 것을 잊지 않는다.

## Claude가 정한 칸 — 유호님 확인

- 광고 영상 PREMIUM의 「시리즈 3편」 길이를 **30초 이내**로 적었다(가격표에는 길이가 없었다 — 3편 × 30초 광고 59만 = 177만보다 낮게).
- 입구 사진의 **작업일 3일 · 수정 2회 · 비율 4:5 · 1:1 · 16:9 중 하나**(가격표에는 「5장 · 하루 안에 첫 장」만 있었다).
- 화장품 발색 · 사용 전후처럼 「실제로 써 본 효과」 사진은 만들지 않는다고 적었다(10-18 진단 — 실물 촬영 예외는 미결정).
- 광고 영상 PREMIUM의 화면: 60초 필름은 가로 · 세로 둘 다, 시리즈 3편은 편마다 비율 1종 · 편집본 없음. 사진 상품의 첫 장은 「자료와 모델이 정해진 다음 날(평일)까지」.
- 사용 범위는 「온라인 광고 · SNS · 자사몰 · 상세페이지, TV · 옥외 · 인쇄는 주문 전 문의」까지만 적었다 — 「기간 제한 없이」는 목소리 · 음악 약관을 아직 확인하지 않아 넣지 않았다.

## 넣지 않은 것과 까닭

- 세금계산서 — 법인(2027-01) 전이라 끊을 수 없다. 크몽 시작 시점이 정해지면 다시 본다.
- 「승인한 장면과 다르면 다시 만든다」 보증 · 동시 접수 상한 — 10-18 진단의 약속으로 아직 정하지 않았다(트랙 §1).
- 캐스팅북 링크 — 크몽은 외부 링크 · 연락처를 막는다. 모델 13명은 상세 이미지로 보인다.
- 월 묶음(89만) · 기업 캠페인(250만부터) — 직접 계약 상품이라 크몽 글에 적지 않는다(크몽 밖 거래 유도로 읽힐 수 있다).

## 올릴 때 지킬 것(검수 P2 · P3)

- 정가를 취소선 「할인 전 가격」으로 올리지 않는다(판 적 없는 값을 종전 가격처럼 보이면 표시 광고 위험). 패키지 값 칸에는 런칭가만 넣고, 정가는 본문 문장으로만.
- 「첫 10건」은 상품마다 센다(Claude 판단 — 상품마다 후기가 따로 쌓인다). 다르게 하시려면 말씀만.
- 추가 옵션(추가 수정 · 추가 비율 · 제품 추가 · 급행) 칸은 값을 정하기 전까지 비워 두고 「상담 후 맞춤 견적」으로 받는다.
- 첫 답 시간(예: 평일 2시간 안)은 지킬 수 있을 때만 적는다.
- 사진 상품은 실제 손님 제품 사진을 합성한 완성 사례가 아직 없다 — 첫 주문 전에 사용 권한이 있는 실제 제품 한 종으로 「3일 · 5장」이 되는지 시험한다.
- 「PULSE 모델 13명」은 모델을 더하면 숫자를 고친다.
- 상세 이미지 넷(모델 13명 카드 · 패키지 비교표 · 진행 순서 · 납품 전 검수표)을 등록 전에 만든다.
