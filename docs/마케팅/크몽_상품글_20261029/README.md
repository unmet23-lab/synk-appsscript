  5. 크몽 상세 9장 · 동영상 칸을 바꿔 다시 임시저장한다.
  - 고르는 순서: 유호님이 「대표작」이라 한 편 → 15초 세로 견본(STANDARD와 같은 판형) → 업종이 겹치지 않게.
