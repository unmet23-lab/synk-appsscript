# SNS 커버 — 펠트·유리 v4

2026-09-19. 사용자가 승인한 Pinterest의 검정 펠트·흰 자수 synk·파랑 SHIFT·투명 유리 구조를 각 채널에 맞게 확장했다. **로컬 커버 12종 완성, v4 업로드 0건.** 이전 소개·커버의 공개 반영 이력은 상위 `실행상태.json`에 별도로 남겼다.

## 적용 범위

- 23개 운영 계정 중 이번 목록에서 커버 제작 대상으로 정한 11개 계정 + Tistory 모바일 1종. 커버가 없는 나머지 계정에 임의의 이미지 필드를 만들지 않았다.
- 유호 YouTube·X는 실제 제작 기록, 브리핑은 업무 AI 활용, LinkedIn 개인은 기업·기관 협업, 회사는 SYNK 전체 소개, LAB은 한국어 학습, Pinterest·Behance는 디자인 결과물, 두 블로그는 만들고 수정하는 과정을 구분한다.
- 문구는 승인된 `final-review-v2`와 이전 커버 문구를 유지한다. 23개 소개·헤드라인·태그라인·링크·핸들의 무변경을 검사한다. 옛 말투 교본을 복원하거나 새 교본을 만들지 않았다.
- 흰 바탕은 #FFFFFF, 검정 바탕은 기존 승인 펠트 텍스처다. 유리는 로고·소품의 선택적 강조에 쓴다. 글 영역 전체를 유리 상자에 넣지 않았다.
- 브랜드키트 정본·글로벌 색 토큰은 변경하지 않았다. 흰 자수 synk는 사용자 승인에 따른 이번 검정 커버의 표현이며 정본 로고 파일을 덮어쓰지 않았다.

## 마감과 검수

- Pinterest는 승인한 로고·글·펠트 소품을 함께 40px 아래로 이동했다. 내부 간격은 유지했다.
- 나머지는 글꼴 기준선이 아니라 실제 글자 외곽과 로고 영역으로 세로 중심을 계산했다. 이미지·글자 비중첩과 로컬 안전영역을 검사했다.
- YouTube는 전체 2560×1440과 중앙 1544×422 안전영역, 데스크톱 전체 폭을 별도로 만든다. 개인 LinkedIn과 X는 왼쪽 프로필 영역을 비워 둔다.
- Tistory는 상단 메뉴의 로고를 커버에 반복하지 않으며, PC와 모바일을 별도 구도로 만든다.
- 12종의 390px 축소본 또는 큰 표시본을 직접 보았다. YouTube 보조 라벨은 축소 시 작아 보여 28px에서 40px로 늘린 뒤 재생성·재확인했다.
- PNG 크기·용량·SHA-256, 글자 38개와 소품의 영역·겹침, 승인 글꼴, 흰 바탕 픽셀과 로컬 파일 연결은 `검수.json`에 남긴다.
- 이번 검사는 로컬 파일 검사다. 로그인된 플랫폼의 실제 자르기·게시 결과와 브라우저의 HTML 렌더링은 아직 확인하지 않았다. 몽골어는 이전 AI 검토 문구이며 원어민 감수 미완료다.

## 사용 도구와 원본

`synk-design` 스킬로 기존 로고·SUIT·Inter Tight·펠트 원본을 이어 썼다. `imagegen` 스킬과 내장 ImageGen으로 흰 바탕에 쓸 LAB·SHIFT 유리 로고 응용 이미지를 만들었다. 이 도구는 모델 버전을 선택하거나 표시하지 않으므로 GPT Image 2.5 사용을 확정하지 않는다.

최종 커버의 정확한 글자와 플랫폼별 배치는 네이티브 SVG로 합성했다. 이전 승인 펠트 사진과 이번 로고 사진은 참조 자산이며, 새 정본 로고를 설계한 것이 아니다. 생성기 `만들기.cjs`, 글자 외곽 도구 `../커버_문구포함/글자윤곽.py`, 검사 `검수.cjs`를 사용한다.

## Behance 실제 공개 크롭 보정 — 2026-09-19

3200×410 업로드 원본과 달리 실제 헤더는 가로를 자르고 상단 메뉴가 이미지 윗부분을 덮는다. 첫 미리보기에서는 오른쪽 펠트 소품이 잘려 저장하지 않고 취소했다. 기존 승인 자산과 문구는 유지한 채 SVG 생성기의 Behance 배치만 수정했다. 글 폭 1020px, 본문 72px/48px, 유리 로고 180px, 소품 350×190px로 중앙 창 안에 모았고 최종 묶음은 원본 기준 40px 더 내려 실제 노출 영역 중앙에 맞췄다.

이전 Behance 파일 4종과 명세는 `이전_Behance_공개크롭보정전/`에 보관했다. 최종 재생성 후 다른 11개 PNG의 SHA-256이 전부 이전과 같음을 확인했다. 글자 38개·안전영역·로컬 연결 검사도 통과했다. 새 커버는 업로드 후 공개 페이지 새로고침에서 로고·문구·소품 전체와 인물 영역 여백을 확인했다. 사용자가 현재 커버에 만족한다고 응답했다. 새 이미지 생성이나 브랜드키트 정본 수정은 하지 않았다.

이 폴더의 명세는 로컬 생성물만 설명한다. 최신 실제 게시 상태는 `../반영_v5.json`을 따른다.
