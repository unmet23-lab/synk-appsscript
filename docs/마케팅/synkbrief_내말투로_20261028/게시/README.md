## 그대로 붙여 쓰는 요청문(세 판 · 블로그 공통)

```
① 카페 인스타에 올릴 공지 써 줘. ○월 ○일 ○요일 하루 쉬어.
② (답이 나온 뒤, 같은 대화에)
내가 전에 쓴 글이야.
(여러분이 전에 쓴 글 세 줄)
이 말투로 다시 써 줘.
```

실제로 보낸 말은 쉬는 날을 상대 날짜(화요일 하루)로 적었지만, 게시 글에는 상대 날짜를 쓰지 않으니(올리기 전 검사 ⑥) 복사해 쓸 요청문은 ○ 자리로 비웠다. 캡션 「알아 둘 것」 첫 줄(영상 예시 자막은 실제 보낸 말을 줄였다)은 Fable 사실 검수 10-29 P2, 임시 채팅 문장은 10-28 P2-1을 10-29에 다시 확인한 그대로다. 「말투가 똑같아졌다」는 어디에도 쓰지 않는다(첫 줄 「쉬어갑니다」는 공지 말투로 남았다).
