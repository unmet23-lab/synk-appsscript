**제목**

ChatGPT로 쓴 가게 공지에 AI 티가 날 때 — 내 글 세 줄 붙이고 "이 말투로 다시 써 줘"

---

**본문**

ChatGPT한테 가게 공지를 부탁해 보면, 이모지 · 해시태그 · 꾸민 인사가 잔뜩 붙은 글이 올 때가 있어요. 그대로 올리자니 「AI가 썼네」 티가 나고, 손으로 고치자니 처음부터 쓰는 것과 다를 게 없고요.

〔유튜브 쇼츠〕

직접 해 봤어요. 결론부터 말하면, **답이 나온 같은 대화에 내가 예전에 쓴 글 세 줄을 붙이고 "이 말투로 다시 써 줘"라고 보내면 됩니다.** 저희가 해 본 판에서는 이모지랑 해시태그가 다 빠지고, "그때 뵐게요."로 끝나는 담백한 네 줄이 됐어요.

※ 실험은 2026년 10월 28일, ChatGPT 웹 **임시 채팅**에서 했어요. 같은 요청도 할 때마다 결과가 달라요.

## 1. 처음 보낸 요청

새 임시 채팅에 「카페 인스타에 올릴 공지 써 줘.」 한 줄에 쉬는 날(화요일 하루)만 붙여 보냈어요. 여러분이 해 볼 땐 이렇게 쓰면 돼요.

```
카페 인스타에 올릴 공지 써 줘. ○월 ○일 ○요일 하루 쉬어.
```

〔그림 1〕 *처음 보낸 요청과 ChatGPT 답 — 실제 화면(저장한 대화 페이지를 다시 그림)*

온 글은 「☕ 카페 임시 휴무 안내」로 시작해 「안녕하세요! 🤎」, 「더 좋은 커피와 달콤한 디저트로 찾아뵐게요. ☕🍰」, 「감사합니다! 🌿」로 이어지고, 끝에 해시태그 네 개(#카페공지 #임시휴무 #휴무안내 #카페일상)가 붙어 있었어요. 세어 보니 이모지 다섯, 해시태그 넷이었어요. 틀린 말은 없지만, 누가 봐도 AI가 쓴 공지 같았어요.

## 2. 같은 대화에 붙인 세 줄과 한 줄

그 대화에 이어서 이렇게 보냈어요.

```
내가 전에 쓴 글이야.
(내가 전에 쓴 글 세 줄)
이 말투로 다시 써 줘.
```

세 줄은 예시 카페 사장님이 예전에 쓴 글처럼 저희가 지은 글이에요. 비 오는 날 와 준 손님께 「고마워요.」, 다 팔린 스콘은 「더 구울게요.」, 문 앞 화분은 「제가 줄게요. 그냥 두셔도 돼요.」처럼, 손님께 말하듯 짧게 끝나는 세 줄이었어요.

〔그림 2〕 *세 줄을 붙인 뒤 받은 답 — 실제 화면*

이번에 온 글은 네 줄이 다였어요. 「…화요일(11월 3일)은 하루 쉬어갑니다.」 「혹시 오시려던 분들 계시면 헛걸음하지 않으셨으면 좋겠어요.」 「수요일부터는 평소처럼 문 열게요.」 「그때 뵐게요.」

이모지 0개, 해시태그 0개. 붙인 세 줄의 「구울게요 · 줄게요」처럼 끝이 「열게요 · 뵐게요」로 맞춰졌어요. 첫 줄 「쉬어갑니다」는 여전히 공지 말투라, 「똑같아졌다」기보다는 **내 말투에 가까워졌다**에 가까워요.

## 3. 한 번 더 해 보니

우연인지 보려고 새 임시 채팅에서 같은 두 번을 한 번 더 보냈어요. 처음 공지는 「저희 카페를 찾아주시는 모든 분들께 감사드립니다」 같은 줄이 더해져 조금 달랐지만(이모지 여섯 · 해시태그 넷), 세 줄을 붙이자 「혹시」 한 낱말만 빠진 거의 같은 네 줄이 나왔어요.

## 4. 알아 둘 것

1. **같은 대화에서 보내세요.** 처음 답이 나온 그 대화에 이어서 보내야 「무엇을 다시 쓸지」가 남아 있어요.
2. **세 줄은 여러분이 직접 쓴 글로.** 지난 공지 · 게시글 · 손님께 보낸 문자처럼 평소 말투가 드러나는 글이면 돼요. 글 속 날짜 · 가게 이름 같은 건 빼도 괜찮아요.
3. **임시 채팅에서 한 결과예요.** OpenAI 도움말 「Temporary Chat FAQ」에 따르면 임시 채팅은 기본으로 메모리 · 맞춤 지침을 쓰지 않고 대화 기록에도 남지 않아요. 그래서 이번 결과는 저희 계정에 대해 아는 것 없이 그 대화에 있는 글만 보고 쓴 거예요. 시작할 때 「개인 맞춤」을 켜면 기존 메모리 · 맞춤 지침이 함께 쓰여요(저희는 끈 기본 상태였어요). 일반 채팅에서도 같은 방법으로 보내면 돼요.
4. **날짜 · 요일은 꼭 확인하세요.** 답 속 「11월 3일(화)」는 ChatGPT가 정한 거예요. 올리기 전에 달력과 맞춰 보세요.
5. 답이 온 칸은 ChatGPT 화면의 「글쓰기」 칸(writing block — 고쳐 쓸 수 있는 글 상자)이었어요.

## 한 줄 정리

AI 글 티가 나면, 같은 대화에 **내가 쓴 글 세 줄 + "이 말투로 다시 써 줘"**.
