05찾기 · 참조 함수

찾기 · 참조 함수는 표에서 조건에 맞는 값을 찾아 다른 셀로 가져올 때 쓴다. 시험에서는 인수의 순서와 찾기 방법(정확히 일치 · 비슷하게 일치)을 묻는 문제가 자주 나온다.

1. VLOOKUP 함수

=VLOOKUP(찾을 값, 범위, 열 번호, [찾기 방법])
  • 범위의 첫 번째 열에서 찾을 값을 찾은 뒤, 같은 행에서 지정한 열 번호의 값을 돌려준다.
  • 찾기 방법이 FALSE(또는 0)이면 정확히 일치하는 값을 찾는다. TRUE(또는 1)이거나 생략하면 비슷하게 일치하는 값을 찾으며, 이때 범위의 첫 열은 오름차순으로 정렬되어 있어야 한다.
  • 찾는 값이 범위에 없으면 #N/A 오류가 난다.
ABC
1사번이름부서
2A101김민수영업
3A102이서연총무
4A103박지훈기획
5A104최유나영업
예제
=VLOOKUP("A103", A2:C5, 3, FALSE)
→ 결과: 기획
A103을 찾아 셋째 열(부서) 값을 가져온다.

2. HLOOKUP 함수

=HLOOKUP(찾을 값, 범위, 행 번호, [찾기 방법])
  • 범위의 첫 번째 행에서 찾을 값을 찾아, 같은 열에서 지정한 행 번호의 값을 돌려준다. 표가 가로로 놓였을 때 쓴다.

3. INDEX 함수와 MATCH 함수

=INDEX(범위, 행 번호, [열 번호])　 =MATCH(찾을 값, 범위, [찾기 유형])
  • INDEX는 범위에서 지정한 행과 열이 만나는 셀의 값을 돌려준다.
  • MATCH는 찾을 값이 범위에서 몇 번째에 있는지 위치를 돌려준다. 찾기 유형 0은 정확히 일치, 1은 찾을 값보다 작거나 같은 값 가운데 가장 큰 값(오름차순 정렬), −1은 찾을 값보다 크거나 같은 값 가운데 가장 작은 값(내림차순 정렬)을 찾는다.
  • 두 함수를 함께 쓰면 =INDEX(B2:B5, MATCH("A104", A2:A5, 0))처럼 사번으로 이름(최유나)을 찾을 수 있다.
시험에 자주 나와요
  • VLOOKUP은 세로(열) 방향 표, HLOOKUP은 가로(행) 방향 표에서 찾는다.
  • 열 번호는 범위의 첫 열을 1로 센다. 시트의 열 문자(A, B, C)가 아니다.
  • 찾기 방법을 생략하면 TRUE(비슷하게 일치)로 처리된다.
