# SNS 콘텐츠의 BGM과 목소리 제작안

2026-09-19 · 사용자 요청과 현재 준비 상태. 첫 게시물 기획의 오디오 제작 방향이며 실제 BGM·목소리 최종 선택이나 발행 완료 기록은 아니다.

## 사용자 요청

- BGM은 Suno에서 필요한 느낌으로 몇 곡을 제대로 제작하고 여러 콘텐츠에 반복 사용한다. 필요할 때 AI가 목적에 맞게 제작하는 방향을 사용자가 요청했다.
- 사용자가 현재 Suno에서 70곡을 다운로드할 수 있다고 알려줬다. 계정의 실제 잔량·다운로드 권한을 이번 작업에서 조회한 수치는 아니다. 생성 크레딧과 다운로드 잔량을 같은 수치로 취급하지 않는다.
- 목소리가 들어가는 콘텐츠를 적극적으로 만들고 싶지만 목소리는 미정이다. 사용자는 **유호의 목소리를 바탕으로 한 AI 음성과 별도의 AI 내레이터를 짧게 들어보고 선택**하기로 했다.
- 과거 여성·남성 후보 기록을 현재의 최종 선택으로 적용하지 않는다. 기존 앱·캐릭터의 목소리 전체를 이 요청만으로 바꾸지 않는다.

## BGM의 공통 원본

처음에는 다음 세 분위기의 기본 곡을 확보하는 안을 제안한다. 각 분위기에서 후보를 비교한 뒤 사용할 곡을 고르고, 다른 감정이나 리듬이 실제로 필요할 때 추가한다. 70곡을 한 번에 생성·다운로드하는 계획이 아니다.

| 분위기 | 주로 사용할 콘텐츠 | 음악에서 필요한 것 |
|---|---|---|
| 따뜻하고 가벼운 학습 | LAB 학습·자료 안내 | 편안한 리듬, 말과 발음을 가리지 않는 간결한 편성 |
| 차분하게 앞으로 가는 제작 | 유호 작업 기록·제작 과정·회사 소개 | 생각과 설명을 받쳐 주는 움직임, 과한 고조 없이 이어지는 전개 |
| 또렷하고 산뜻한 정보 | synkbrief의 AI 소식·스킬 추천·시연 | 설명의 속도를 받쳐 주는 리듬, 주의를 빼앗는 큰 효과음·급격한 전환 최소화 |

보유 곡 중 맞는 것이 있으면 먼저 활용한다. 새 곡이 필요하면 작업 목적·분위기에 맞춰 Suno에서 제작하고, 쓸 곡과 구간을 고른다. 말 중심 영상은 보컬 없는 반주를 우선하며 실제 대사와 함께 들어서 음량을 맞춘다. 학습자의 발음 연습이나 중요한 설명에서는 음악을 더 낮추거나 비울 수 있다. 고정 볼륨 숫자를 모든 곡에 일괄 적용하지 않는다.

곡 원본과 짧은 영상용 구간·끝맺음 편집은 구분해 보관한다. 동일한 곡을 잘라 쓴 것을 새 원곡으로 세지 않는다. 사용할 때 곡 URL·다운로드 파일·당시 이용 조건을 함께 기록한다. 현행 Suno 도움말은 유료 구독 중 다운로드한 곡의 상업 이용 권한을 안내하며, 실제 사용할 곡과 계정 조건은 제작·다운로드 때 확인한다. [Suno 공식 안내](https://help.suno.com/en/articles/9601665)

이 방향은 제작 중 필요할 때 실행할 작업 범위다. 예약 자동화·백그라운드 무인 생성·Suno API 연결을 설정한 상태는 아니다. 신규 결제나 구독 변경은 이번에 하지 않았다.

## 목소리 비교

자연스러움은 후보 이름이나 공개 순위만으로 확정하지 않는다. 실제 대본에서 발음·억양·문장 끝·쉼·감정의 크기를 비교하고, 유호가 계속 듣고 싶은 목소리를 고른다. 기술적으로 닮은 음색과 자연스럽게 설명하는 전달력은 따로 확인한다.

| 방향 | 어울리는 활용 | 현재 상태 |
|---|---|---|
| A · 유호 목소리를 바탕으로 한 AI 음성 | 직접 겪은 제작 과정·판단을 유호의 목소리로 전달 | 유호의 직접 말하기 원본이 확인되지 않아 새 녹음 필요. 원본 확보 후 짧은 합성 비교 |
| B · 별도의 AI 내레이터 | 설명·뉴스·학습 안내를 일정한 목소리로 전달 | 기존 DIVE 윤기·재현의 짧은 비교 WAV가 있음. 현재 최종 선택은 아님 |
| 추가 여성 후보 · DIVE 나나 | 밝고 또렷한 한국어 안내 후보 | 공식 소개·음색 목록 확인. 2026-09-19 동일 대본 무료 체험은 DIVE 크레딧 부족으로 실패하여 새 음원 없음 |

기존 남성 비교 파일:

- [DIVE 윤기 · 약 9.5초](../브랜드_목소리/20260914_DIVE_남성/윤기_비교원본.wav)
- [DIVE 재현 · 약 8.3초](../브랜드_목소리/20260914_DIVE_남성/재현_비교원본.wav)

이 두 파일은 09-14의 기존 비교 자료다. 오늘 동일 대본으로 새로 생성하거나 유호 목소리와 비교 검증한 결과가 아니다. 나나의 공식 예시는 [Humelo 공식 페이지](https://www.humelo.com/swcc2026)에서 확인할 수 있다.

로컬 조사 범위는 `docs/브랜드_목소리`와 관련 현재 기록이다. 수노 보컬 파일과 이전 말하기 합성 시험은 유호가 직접 읽어 녹음한 깨끗한 원본으로 확인되지 않아 본인 목소리의 참조로 사용하지 않았다.

## 짧은 비교를 위한 녹음

첫 비교에서는 조용한 곳에서 평소 설명하듯 말한 30~60초 정도의 녹음을 준비한다. 휴대전화의 원본 녹음도 출발점으로 사용할 수 있다. 음악·필터·강한 음질 보정 없이 한 사람의 말만 담는다. 이는 후보 비교용 시작 분량이며 모든 엔진의 최적 학습 분량을 뜻하지 않는다. 사용할 모델의 조건에 따라 더 긴 녹음이 필요할 수 있다.

공통 대본:

> 오늘은 만들면서 고친 부분을 보여드릴게요. 처음 결과와 수정한 결과를 나란히 두면 차이가 잘 보여요. 왜 이렇게 바꿨는지, 어디에 써볼 수 있는지도 같이 살펴볼게요.

한 번 자연스럽게 읽고 평소 말투로 작업 이야기를 조금 덧붙여도 된다. 합성 비교에서는 공통 대본 부분을 사용한다. 첫 청음은 BGM과 효과음 없이, 후보끼리 큰 음량 차이가 없도록 하고 과도한 피치·속도 변경을 하지 않는다.

자기 목소리 복제는 원본과 합성 결과를 함께 비교해야 한다. DIVE는 프리셋과 저장 목소리 합성을 구분하고, ElevenLabs도 간단한 참조 기반 복제와 별도 학습을 하는 복제를 구분한다. 어떤 공급자가 가장 자연스러운지는 아직 직접 비교한 결과가 없다. [DIVE API 문서](https://console.humelo.com/docs/dive) · [ElevenLabs 목소리 복제 안내](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning)

## 언어와 콘텐츠 형식

- 한국어 음성이 좋다고 몽골어 발음도 자연스럽다고 가정하지 않는다. LAB의 몽골어 음성은 지원 언어와 실제 청음을 따로 확인한다. 09-19 DIVE 체험 화면에는 한국어·영어 선택이 보였으며 몽골어 지원은 확인하지 못했다. ElevenLabs의 받아쓰기·더빙 언어 목록을 TTS의 지원 언어 목록으로 대신 사용하지 않는다.
- 목소리는 영상·화면 시연·학습용 음성에 우선 넣는다. 글·카드·핀에 소리를 넣기 위해 전부 새 영상으로 바꾸는 것은 별도 제작 선택이다.
- 카드·작업 기록을 나레이션 영상으로 추가 제작해 재사용할 수 있다. 얼굴 촬영 없이 가능하지만, 기존 **출연 없는 12종 중 영상 1편 + 글·카드·프로젝트 11종**에서 영상 편집본 수가 달라지므로 실제 선택 후 다시 계산한다.
- 채널마다 목소리를 새로 정할 필요는 없다. 우선 한국어의 주된 목소리 방향을 고르고, 학습 표현·상황극·몽골어처럼 목적이 달라질 때 필요한 음성을 검토한다.

## 다음 제작으로 이어갈 상태

현재 청취 가능한 자료는 기존 DIVE 남성 후보 2개다. 유호의 실제 말하기 녹음과 이를 바탕으로 한 새 합성본은 미확보이며, A/B 동일 대본 비교는 아직 완료하지 않았다. 새 Suno BGM 생성·다운로드도 이번에 실행하지 않았다. 목소리가 정해지기 전에도 원고·카드·기존 결과 이미지 정리는 진행할 수 있다.
