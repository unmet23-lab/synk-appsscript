# 그록 시험관 답 · 구독(grok CLI) · 2026-11-18T00:14:59.736Z

1. 한국인 룸메이트 쪽지가 「케이크 먹지 마」였는데, cake랑 eat만 읽고 케이크를 다 먹은 뒤에야 맨 끝 「마」가 don't인 걸 알았어.

2. 이 문장에서 케이크=cake, 먹지=eat, 마=don't만 짚을 수 있다. 다른 손글씨까지 읽히진 않는다.

3. 0~6초 「먹지」, 8초 전 「마」는 글자는 보여도 뜻을 몰랐다. 0~4초 케이크는 이미 한 입 나가 있는데 누가 먹었는지는 모르겠다. 7.12초 소리 「먹지 마」는 8초 자막 전엔 못 알아들었다. 작아서 못 읽은 글자는 없다.

4. 끝까지. 1~4초는 연필로 한 글자씩 써서 느렸지만, 6초 빈 접시와 8초 DON'T가 바로 이어서 13초를 넘기지 않았다.

5. 4. 영어 자막으로 실수 이야기는 한 번에 따라간다. 손글씨 뜻은 빨간 영어 다음에야 알았고, 처음부터 베어 먹은 자국은 끝까지 모른다.

6. 3. 딸기 꼭지만 남은 접시는 잠깐 웃겼다. 10~13초는 같은 화면이라 재미는 거기까지다.

7. 계속 봄. 0.5초에 룸메이트 쪽지라고 해서, 케이크 옆의 못 알아듣는 글이 뭔지 보고 싶었다.

8. 저장. 「먹지 마 = don't eat」를 나중에 다시 보려고. 보낼 만큼 웃기진 않다.

9. 달라 보임. 지난 편은 위 제목이 유지되고 대사가 말풍선으로 이어지며, 끝은 단어 카드(셋=three)거나 댓글 질문이다. 이 편은 종이에 글자를 직접 써 가고 머리 글이 바뀌며, 끝은 「Could YOU read this note?」다.
