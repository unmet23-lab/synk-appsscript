# LAB 노래 틀 — 21:00 노래 가사판(2026-11-11)

[리듬 한국어 준비안](../LAB_리듬한국어_준비_20261110/README.md) 「라」 줄. 메들리에서 자른 하루 판 노래 한 곡을 가사판 영상으로 굽는 Remotion 틀이다.

- **짜임은 한글 노래 「첫 인사」 틀, 보이는 꼴은 만족 사례 S16(관용구 퀴즈 Remotion 재구성판)**: 음절마다 한 박(부를 때 코랄로 쾅), 다 부르면 뜻(소리 뒤), 반주만 흐르는 네 차례에 글자가 박마다 코랄로 번쩍. 따뜻한 오프화이트 바탕 · 거의 검정 글자 · 강조색 코랄 하나 · 상자 없는 큰 글자 · 튕김 없는 스프링(S16 theme). 위는 그림이 아래로 바탕에 스며들고, 맨 아래 박 막대가 늘 박을 센다(네 차례엔 손뼉 칠 자리). 글은 y ≤ 1536 · x ≤ 930(S16 안전 영역). 칸 아래 발음 줄 — 나라 문자는 [한글 발음 표기표](../현지화/표기표/README.md) v3의 `음절표기(글, 문자)`(낱말 문맥을 지켜 음절마다, 칸에 홀로 서는 금칙은 로마자로 — `발음줄(글, 문자, { 음절: true })`).
- **언어판 장치는 퀴즈 은행 틀**: `src/lang.ts` · `src/fonts.ts`(언어 프로필 · fitBox · LOC 글꼴)를 그대로 가져왔다. 판본마다 `song.json`의 `loc`만 바뀐다.
- **하루 판의 짜임**: 카운트인 한 마디(다리 글) → 끊어 → 이어(뜻 알약) → 네 차례(손뼉) → 끊어 → 이어 → 진짜 속도 → 네 차례(말하기) → 끝 물음(「너희 말로는 뭐야?」). 시작 · 끝이 같은 박 자리라 되풀이 재생이 박에 맞게 이어진다.
- **진행자(무대)**: `stage.mode` — `mongle`(`stage.img` = 몽글을 장면과 한 장으로 구운 가로 3:2 그림, AGENTS 마스코트 줄) · `plain`(`stage.pic` = 낱말 그림만). `stage.focus`는 그림을 채울 때 기준점. **11-11 유호님이 `mongle`(장면 속 몽글)을 고르셨다** — 첫 비축은 이 꼴로 만든다(결정 표 11-11). `plain`은 틀에 남겨 둔다.

## 한 편 만드는 법

```
python -X utf8 tools/노래검수.py 떼기 <밖>/떼기 <후보.mp3…>                                     # 목소리 · 바탕(GPU 줄)
python -X utf8 tools/노래검수.py 재기 <후보.mp3> --후보 <후보.json> --밖 <밖>/재기 --목소리 … --바탕 …   # 음절 시각 · 발음
python -X utf8 tools/노래검수.py 훅 <밖>/재기/*.검수.json --첫줄 1 7 13 --이름 배고파 잠깐만 진짜        # 훅마다 후보 순서
python -X utf8 docs/마케팅/LAB_노래틀/틀/편만들기.py <검수.json> <후보.mp3> <바탕.wav> <목소리.wav> --첫줄 1 --낱말 배고파 \
    --판본 <판본 글.json> --무대 mongle|plain [--그림 <public 안 그림>] [--줄짜임 4,1,4,1,1] --밖 <밖>/하루판   # 하루 판 곡 · song.json
# 틀/public/에 song.wav · song.json · 그림을 놓고(틀 자리 public은 git 밖 — 글꼴은 퀴즈 은행 틀 public/fonts에서 복사)
cd docs/마케팅/LAB_노래틀/틀 && npx remotion render song out/<이름>.mp4
```

- **끼울 곳 · 끼울 반주(11-12):** 쉼 마디는 앞 줄 끝과 다음 줄 첫 음절 사이 가장 조용한 곳에 끼운다. 재기가 두 음절을 겹쳐 잡아 창이 뒤집히면 다음 줄 첫 음절 앞 0.6초 안에서 찾는다(메들리 A 「진짜」가 「진」 한가운데에 끼워졌던 일). 끼울 반주는 바로 앞 같은 길이가 기본이고, 그 자리에 무음이 있으면(스톱 타임 편곡) 0.1초 창이 모두 −45 dB 위인 가장 가까운 마디를 곡손질 「원천마디 · 원천끝마디」로 떠 되풀이한다. 끝 물음 화면은 2.5초 넘게(모자라면 세 마디 끼움). 현장 노트 [영상 · 쉼 마디](../../현장노트/영상_ffmpeg_자막.md).
- **`--줄짜임`(11-12):** 카운트인 다음 끊어 · 이어 · 끊어 · 이어 · 진짜 속도가 각각 몇 가사 줄인가. 메들리 B처럼 끊어 줄을 한 줄에 한 음절(「가! / 자! / 가! / 자!」)로 적었으면 `4,1,4,1,1`. 끊어 시각은 낱말 음절을 차례로 되풀이한 것만 쓰고(추임새 「짝」은 뺀다) 틀이 음절을 돌려 켠다.

- node_modules는 퀴즈 은행 틀(공용 작업본)의 것을 junction으로 잇는다(`node -e "fs.symlinkSync(<퀴즈 틀 node_modules>, '틀/node_modules', 'junction')"` — cmd `mklink`는 한글 경로를 깨뜨린다).
- 판본 글(`loc`): `lang` · `bridge`(카운트인 동안 다리 글) · `mean`(뜻 알약) · `read`(음절마다 발음) · `clap` · `say` · `real` · `end` + `_원문`(한국어 뜻 — 역번역 대조 기준).
- **글 자리 · 딱지 길이(11-12):** 글은 글자 검사 안전선(오른쪽 920 · 아래 1428 — `tools/올리기전검사.js` SAFE) 안에 둔다 — 음절 글자 상한 230 · 뜻 줄 최대 76 · 글 아래 끝 `SAFE_BOTTOM` 1400, 뜻 줄은 12px만 떠오른다(26px이면 들어오는 동안 아래 캡션 자리를 15px 넘었다). 「진짜 속도」(`real`) 딱지는 화면에 1.3~1.6초뿐이라 짧게(라틴 글 16자 안팎) — 「Natural speed!」류는 무엇의 속도인지 시험관 넷 중 둘 이상이 몰랐다(11개 언어). 그 언어는 「말하는 빠르기」 뜻(「Talking speed!」 · 「É assim que se fala!」 · 「日常语速！」)으로 바꿨다.
- **딱지 · 끝 물음 · 다리 글(11-12 GPT 눈 맹검 뒤):** 딱지(손뼉 · 말하기 · 진짜 속도)는 최대 60px · 음절 위 간격을 두고(「큰 글자 위에 끼워 넣은 주석」), 끝 물음은 최대 92px — 줄을 `\n`에서만 나누는 언어(타이 · 크메르 · 버마어 · 한자 · 가나)는 띄어쓰기와 「、」「，」 뒤에서도 나눠 재고 고른 줄바꿈 그대로 그린다(「작은 검정 한 줄」). 다리 글은 아래 안전선까지 남는 높이의 40%만큼 내려 놓는다(위에 몰린 두 줄 아래가 비어 보임). 그림과 글 사이 번짐 · 몽글 생김새 지적은 v7 결정 그대로 둔다.
- 윈도는 파일 이름 대소문자를 가리지 않는다 — `Song.tsx`와 `song.ts`를 같이 두면 컴포지션이 undefined가 된다(그래서 정본 꼴 파일은 `songDoc.ts`).
