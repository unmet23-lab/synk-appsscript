# LAB 노래 틀 — 21:00 노래 가사판(2026-11-11)

[리듬 한국어 준비안](../LAB_리듬한국어_준비_20261110/README.md) 「라」 줄. 메들리에서 자른 하루 판 노래 한 곡을 가사판 영상으로 굽는 Remotion 틀이다.

- **화면 문법은 한글 노래 「첫 인사」 틀**(가이드 §3 「낱말 노래 틀」): 음절마다 칸 하나, 끊어 부를 땐 한 박에 한 칸, 다 부르면 모두 켜지고 뜻 알약(소리 뒤), 쉼 마디에 「?」가 박마다 톡. 칸 아래 발음 줄(몽골판만 키릴 — 표기표를 검수한 문자만 그 나라 글자).
- **언어판 장치는 퀴즈 은행 틀**: `src/lang.ts` · `src/fonts.ts`(언어 프로필 · fitBox · LOC 글꼴)를 그대로 가져왔다. 판본마다 `song.json`의 `loc`만 바뀐다.
- **하루 판의 짜임**: 카운트인 한 마디(다리 글) → 끊어 → 이어(뜻 알약) → 네 차례(손뼉) → 끊어 → 이어 → 진짜 속도 → 네 차례(말하기) → 끝 물음(「너희 말로는 뭐야?」). 시작 · 끝이 같은 박 자리라 되풀이 재생이 박에 맞게 이어진다.
- **진행자(무대)**: `stage.mode` — `mongle`(몽글을 장면과 한 장으로 구운 그림 위에 칸, AGENTS 마스코트 줄) · `plain`(글자와 낱말 그림만). 첫 시안 두 판을 보시고 유호님이 고르신다.

## 한 편 만드는 법

```
python -X utf8 tools/노래검수.py 떼기 <밖>/떼기 <후보.mp3…>                                     # 목소리 · 바탕(GPU 줄)
python -X utf8 tools/노래검수.py 재기 <후보.mp3> --후보 <후보.json> --밖 <밖>/재기 --목소리 … --바탕 …   # 음절 시각 · 발음
python -X utf8 tools/노래검수.py 훅 <밖>/재기/*.검수.json --첫줄 1 7 13 --이름 배고파 잠깐만 진짜        # 훅마다 후보 순서
python -X utf8 docs/마케팅/LAB_노래틀/틀/편만들기.py <검수.json> <후보.mp3> <바탕.wav> <목소리.wav> --첫줄 1 --낱말 배고파 \
    --판본 <판본 글.json> --무대 mongle|plain [--그림 <public 안 그림>] --밖 <밖>/하루판                   # 하루 판 곡 · song.json
# 틀/public/에 song.wav · song.json · 그림을 놓고(public은 git 밖 — 글꼴은 퀴즈 은행 틀 public/fonts에서 복사)
cd docs/마케팅/LAB_노래틀/틀 && npx remotion render song out/<이름>.mp4
```

- node_modules는 퀴즈 은행 틀(공용 작업본)의 것을 junction으로 잇는다(`node -e "fs.symlinkSync(<퀴즈 틀 node_modules>, '틀/node_modules', 'junction')"` — cmd `mklink`는 한글 경로를 깨뜨린다).
- 판본 글(`loc`): `lang` · `bridge`(카운트인 동안 다리 글) · `mean`(뜻 알약) · `read`(음절마다 발음) · `clap` · `say` · `real` · `end` + `_원문`(한국어 뜻 — 역번역 대조 기준).
- 윈도는 파일 이름 대소문자를 가리지 않는다 — `Song.tsx`와 `song.ts`를 같이 두면 컴포지션이 undefined가 된다(그래서 정본 꼴 파일은 `songDoc.ts`).

## 상태(11-11)

- 틀 · 하루 판 도구 · 자리 그림 렌더(무대 plain, 그림 없음) 확인 — 칸 · 뜻 알약 · 네 차례 「?」 · 진짜 속도 딱지 · 끝 물음이 시각대로 켜진다.
- **첫 시안 두 판**(배고파 — A 장면 속 몽글 · B 글자와 그림만)은 GPT 그림 굽기 계정 셋이 모두 한도라 풀린 뒤 굽는다. 지시문은 `시안/시안A_몽글_지시문.txt` · `시안/시안B_그릇_지시문.txt`(굽기는 `docs/마케팅/LAB_퀴즈은행/틀/굽기.cjs`).
- 판본 렌더 스크립트(판본 지도 · 글자 검사 · 뜻 검사 잇기)는 진행자를 고르신 뒤 퀴즈 · 이야기 편의 `판본렌더.mjs` 꼴로 붙인다.
