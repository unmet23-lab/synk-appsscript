소개 원문은 [해외 LAB 가입 준비](../프로필_클로드판_20261002/가입준비_LAB해외.md)의 일본·우즈베키스탄 문구를 그대로 사용했다. 해당 원문의 원어민 검수 전 상태는 유지하며 이번 작업에서 검수 완료로 올리지 않는다. 일본의 기존 소개 `tgroove`를 대체했다.

사진은 사용자 「기존 승인 SYNK LAB 로고」 선택에 따라 [정본](../../로고_중립색_정본_v1.md)의 배치용 SYNK-LAB-Ink.png를 사용했다. 원본 SHA-256 `7e014c4e4a121ac0ead8168a8b28fcd5c7f0d1353e751d97233b2ff09904d201`을 배치명세와 대조했다. 형태·색·비례를 보존해 가로 440px로 축소하고 흰색 512×512 캔버스 중앙에 배치했다. 파생 파일은 [avatar-lab-logo.png](avatar-lab-logo.png).
