상담 신청을 옮겨 적고, 긴 문의를 읽어 요약하고, 매번 같은 양식으로 보고서를 만드는 업무를 도와드립니다. 현재 사용 중인 구글 설문·시트·문서를 중심으로, 필요한 작업 하나부터 자동화합니다.

구매 전 현재 업무와 입력 예시를 보내주시면 가능한 연결 방식, 결과물, 필요한 계정과 사용료를 먼저 안내합니다. 합의한 범위로 제작한 뒤 예시 자료로 함께 확인하고 사용 방법을 전달합니다.

### 진행 방식과 지원 범위

1. 크몽 메시지로 업무·입력 예시·원하는 결과를 확인한다.
2. 연결 가능성과 계정 준비 상태를 확인하고 범위·처리량·도구 비용·완료 기준을 확정한다.
3. 고객 소유 환경에 설정하고 익명화한 예시 자료로 검수한다. 비밀번호를 받는 대신 고객이 직접 인증·연결한다.
4. 합의한 결과와 실제 동작을 확인한 뒤 사용 안내와 설정·코드를 전달한다.
5. 납품 후 14일 동안 합의한 기능의 재현 가능한 오류를 확인·수정한다. 새 기능, 외부 서비스 정책 변경, 상시 모니터링은 별도 범위다.

수정은 합의한 흐름 안의 요약 문구·분류·표시 조정이다. 새로운 업무·도구·데이터 형식 추가는 별도 견적이다. 합의한 기능이 동작하지 않는 오류는 일반적인 선호 수정과 구분한다.

AI API·유료 도구의 사용료는 고객 부담이며 주문 전 예상 사용 조건을 안내한다. 회원가입·로그인·결제 기능을 갖춘 웹앱 전체 개발, 대량 메시지 발송, 24시간 운영 대응은 이 상품에 포함하지 않는다.

### 상세 설명에 사용할 본문

AI를 써보고 싶지만 내 업무에 어떻게 적용할지 막막하신가요?

실제로 처리하는 문서나 만들고 싶은 결과를 가져오시면, 목적을 정리하고 적절한 도구를 선택한 뒤 함께 실습합니다. 질문을 입력하는 방법뿐 아니라, 결과에서 빠진 내용이나 잘못된 부분을 확인하고 수정하는 방법까지 다룹니다.

수업에서 사용한 프롬프트와 작업 순서, 결과 확인표를 남겨 다음에도 직접 활용할 수 있도록 돕습니다. SYNK의 운영 도구와 콘텐츠를 만들며 겪은 실제 제작·수정 사례를 설명에 활용합니다.

처음에는 온라인 1:1로 진행하며, 구매 전 목표·현재 수준·필요 계정을 확인합니다.

### 선택할 수 있는 실습 주제

1. **문서·회의 메모 정리:** 긴 메모 → 요약 → 해야 할 일 → 담당자·일정 확인. 없는 사실을 만들어 채우지 않는 검수법.
2. **콘텐츠 기획·재구성:** 사업 소개나 경험 1개 → 게시물 초안 → 이미지 방향 → 결과 확인. 여러 채널에 맞게 표현을 바꾸는 방법.
3. **내 업무의 AI 적용 설계:** 현재 업무 분해 → AI를 쓸 단계 선정 → 사람이 확인할 단계 → 작은 실습과 적용 계획. 자동화 프로그램의 개발 납품은 포함하지 않는다.

수업마다 합의한 한 주제를 다룬다. 이미지·영상 생성의 심화 기법은 실제 시연 가능한 범위가 확인된 뒤 주제로 추가한다.

상세 이미지 6장 제안: 수업 대상 → 실습 전후 → 선택 주제 → 수업 진행 예시 → 가격과 제공 자료 → 준비물·예약·질문 범위.

### 상세 설명에 사용할 본문

쇼핑몰과 브랜드 SNS에 사용할 의류 모델컷·룩북 이미지를 제작합니다.

제품 사진과 원하는 분위기를 바탕으로 가상 성인 모델, 배경, 포즈와 구도를 정합니다. 사진·퍼포먼스 경험을 살려 인물의 표현과 전체 분위기를 기획하고, 먼저 대표 시안에서 제품 디테일과 방향을 확인합니다.

구매 전 의류의 정면·후면·디테일 사진을 확인합니다. 작은 로고나 복잡한 패턴처럼 재현이 어려운 요소는 가능 범위를 먼저 안내하며, 실제 옷의 특징과 다른 결과를 그대로 상품 이미지로 전달하지 않습니다.

본 서비스의 기본 납품물은 정지 이미지입니다. 상세페이지 전체 디자인이나 영상 제작이 필요한 경우 별도 범위로 상담합니다.

### 진행 과정과 수정 기준

1. 주문 전 제품 원본과 보존해야 할 디테일을 확인한다.
2. 모델·배경·분위기·사용처·구도를 합의한다.
3. 주문 후 상품별 대표 1컷을 만들어 방향과 제품 표현을 확인한다.
4. 대표 컷 승인 후 나머지를 제작한다.
5. 원본과 비교해 검수하고 최종 파일을 전달한다.

수정 1회는 한 번에 취합한 피드백을 반영하는 단위다. 확정한 방향 안의 밝기·색감·크롭과 합의된 표현을 조정한다. 새로운 모델·의류·배경 콘셉트는 추가 작업이다. 원본 제품이나 합의사항과 다른 오류는 선호 수정 횟수와 구분하여 처리한다.

제품의 실제 착용 핏·정확한 색상·질감·복잡한 프린트를 무조건 동일하게 재현한다고 약속하지 않는다. 상품 설명용 사진으로 적합한지 먼저 판단하며, 대표 컷에서 요구 수준을 충족하지 못하면 나머지 컷 제작을 멈추고 다음 처리를 협의한다. AI 이미지를 실제 촬영·실제 피팅의 증거로 설명하지 않는다.

최종 사용 범위는 선택한 제작 도구의 조건과 고객이 제공한 자료의 권리를 확인해 안내한다. 납품물을 유코의 포트폴리오로 공개할 때는 고객의 동의를 받는다.

### 등록 전 만들 포트폴리오

실제 보유 의류 또는 사용 권한이 있는 제품 사진으로 만든다. 콘셉트 샘플이라는 사실을 표시한다.

1. 단색 티셔츠: 원본과 모델컷 3장 비교. 실루엣·소매·목선 확인.
2. 셔츠 또는 재킷: 앞·옆 구도와 디테일. 버튼·카라·봉제선 확인.
3. 프린트 의류: 로고·프린트 보존을 시험한다. 품질이 충족된 경우에만 제공 가능 사례로 제시한다.

샘플별 생성비·전체 제작시간·수정시간을 기록한다. 현재 실제 의류의 반복 납품 품질은 검증 전이므로 이 과정을 끝낸 뒤 가격·컷 수·납기를 확정한다.
