유호님 「전부 다 진행해줘. 글부터 시안까지 설정까지 전부 부탁해」(10-19). 무엇이 문제였는지는 [점검 결과](../온라인마케팅지도/LAB계정_점검_20261019.md)에 있다.

## 한 것(10-19)

- **유튜브 18개 나라 채널 소개글**
  - 첫 줄을 「3초 퀴즈로 배우는 한국어」로 바꿨다.
  - 10-02판 본문의 「일상 장면·리액션」 말을 지금 올리는 관용구 퀴즈에 맞췄다.
  - 영어·스페인어·포르투갈어권에는 이름 도구(synk.im/nombre/)를 더했다.
  - 소개 끝 링크와 채널 링크는 영어판 LAB 페이지(synk.im/en/lab/)로 바꿨다.
  - Data API로 18/18 일치를 확인했다. 원문은 [문안.json](문안.json) `youtube`.
- **소개글 확인 과정**
  - 순서: Claude 초안 → Fable 교정(스리랑카 두 줄) → 제미나이 검문(`tools/현지어대조.js`, 결과 [검문/](검문/)).
  - 「어색」이 나온 타밀어(어순)·미얀마어(청유형·「ကိုရီးယားလူမျိုး」·높임 맞추기)는 검문이 고친 문장으로 바꾸고 다시 「정상」을 받았다.
  - 싱할라어 ZWJ 지적은 바이트로 확인한 오판이다(10-18과 같다).
  - 원어민 확인은 없다.
- **유튜브 일본:** 비구독자 예고편 칸에 걸려 있던 비공개 개인 영상(자기소개 영상)을 칸에서만 뺐다. 영상은 그대로 있다.
- **텔레그램**
  - 우즈베키스탄: 「자료 준비 중」 문장을 뺐다.
  - 몽골 synkmn: 한국어 본문을 몽골어 두 줄과 링크로 바꿨다.
- **페이스북 몽골 페이지(synkworld)**
  - 소개의 한국어 문장과 「한국 유학」 안내를 몽골어 두 줄로 바꿨다.
  - 분류 「언어 치료사」를 빼고 「교육 웹사이트」를 넣었다(교육 · 교육 웹사이트).
  - 페이지 프로필로 바꿔 고친 뒤 개인 프로필로 되돌렸다.
- **몽골어 문장**
  - 새로 짓지 않았다. 9월부터 채널 이름에 쓰던 「Хөгжилтэй солонгос хэл」과 배너의 「Хангыль · Өдөр тутмын яриа · TOPIK」에 게시물의 「Хэлц үг」만 이었다.
  - 몽골어 검문(`tools/몽골어대조.js --구독`)에서 문법은 「정상」이고, 맞춤법 사전은 외래어 「Хангыль」만 표시했다.
  - 이때 9월 20일부터 @synkkorean 배너에 걸린 「…хөгжилтэй сурья」의 맞춤법 오류(сурья → суръя)를 찾았다.

## 그림 올림(10-19, 유호님 「나머지 자율주행으로 해줘」)

- **@synkkorean 영어 기준 전환**
  - 이름을 「SYNK LAB | Learn Korean」으로 바꿨다.
  - 소개·키워드·링크(「SYNK LAB」 → synk.im/en/lab/)를 영어로 바꿨다.
  - 배너는 19번이다. 결정 표 10-19에 근거를 남겼다.
- **유튜브 19곳**
  - 배너(나라별 18장 + @synkkorean 영어판)와 새 몽글 프로필(800px)을 스튜디오에서 올렸다.
  - Data API로 다시 내려받아 사진 19/19, 배너 19/19가 새 판임을 확인했다.
  - 공개 배너를 띠로 잘라 보니 나라 이름표와 제목 언어가 채널마다 맞았다([공개확인_유튜브_20261019.jpg](공개확인_유튜브_20261019.jpg)).
- **페이스북 4곳**
  - 대상은 몽골 synkworld·네팔·캄보디아·스리랑카다. 커버(1640×596)와 프로필(1080px)을 바꿨다.
  - 페이지마다 그 페이지 프로필로 바꿔 올리고, 끝나면 개인 프로필(양유호)로 되돌렸다.
- **텔레그램 2곳(몽골 synkmn·우즈베키스탄):** 채널 사진을 바꿨다. 채널에 「Channel photo updated」 알림이 남는다.
- **나라별 언어 최종 점검(Fable, 공개 글 기준)**
  - 판정은 「언어 오류 없음」이다. 19채널 이름·소개·배너 제목과 페이스북·텔레그램 소개가 그 나라 말로 맞게 걸렸다.
  - 고친 것은 하나다. 캐나다 소개에 미국·호주판에 있는 앱 소식 줄(영·불)과 불어 이름 도구 줄을 더했다(문안 v4).
  - 의심으로만 남긴 것
    - 브라질 배너 「O que você quer falar, em coreano.」는 명령형이 없어 다른 나라보다 밋밋하다. 틀린 것은 아니다.
    - 스리랑카 첫 줄은 형식이 조금 다르다. 뜻은 같다.
    - 페이스북 스리랑카 소개에는 타밀어 줄이 없다.
- **그대로인 곳**
  - 앱에서만 바뀌는 곳은 붙여 넣기 묶음으로 남겼다: 인스타 @synk.mn, 틱톡 4곳, 샤오훙수.
  - 루튜브는 로그인 보안 문자 때문에 그대로다.

## 시안

- **그림:** GPT 이미지 2.5(ChatGPT 구독 Codex, 보조 계정 bake2)로 다섯 장을 구웠다. 주간 사용률은 6% → 약 10%다. 지시문과 원본은 [굽기/](굽기/)에 있다.
  - A: 몽글 프로필. 큰 구슬 눈 「놀람」에 크림 펠트 바탕(10-02 「LAB 프로필은 몽글」).
  - B·B2: 세 친구 배너. 까몽·마린이 PC 띠와 페이스북 커버 아래에 반쯤 걸려 버렸다.
  - B3: 몽글이 너무 커서 버렸다.
  - B4: 쓰는 판.
- **배너·커버 24장**
  - [배너/out/](배너/out/)에 있다. 짓기 순서: [바탕짓기.py](배너/바탕짓기.py) → [배너_짓기.py](배너/배너_짓기.py) → `tools/SNS키트굽기.js`.
  - 유튜브 18개 나라 + @synkkorean 두 판(영어 / 몽골어) + 페이스북 커버 4장(네팔·캄보디아·스리랑카·몽골).
  - 10-02판의 글 배치와 안전 영역은 그대로 두었다. 바탕만 구운 사진 한 장을 키워 자른 것으로 바꾸고, 누끼와 흰 테두리는 뺐다.
  - 고친 제목: 브라질 「O que você quer falar, em coreano.」, 말레이시아 「Nak cakap apa pun, cakap dalam bahasa Korea.」, 필리핀 「Sabihin ang gusto mong sabihin, sa Korean.」, 파라과이 「Lo que quieras decir, decilo en coreano.」, 멕시코 「Lo que quieras decir, dilo en coreano.」(새로), 몽골 「Хөгжилтэй / солонгос хэл」.
- **프로필:** `프로필_몽글_1080.png`·`프로필_몽글_800.png`. 원으로 잘려 작게 보이니 몽글 폭이 지름의 72%가 되게 구운 사진을 당겨 잘랐다.
- **Git에 넣은 것(저장소 용량 규칙):** 구운 원본 A·B4, 지시문, 짓기 스크립트, `배너.html`, 시트(`배너/out/_시트.png`)·`검사.json`만 넣었다. 장별 배너·커버 24장, `배너/bg_*.png`, `프로필_몽글_*.png`는 Git 밖이고 아래 순서로 다시 만든다. 버린 시안 B·B2·B3 원본은 이 PC에만 있다.
  ```bash
  cd docs/마케팅/프로필_20261019/배너 && python -I 바탕짓기.py && python -I 배너_짓기.py && cd ../../../..
  node tools/SNS키트굽기.js docs/마케팅/프로필_20261019/배너/배너.html --sheet --out docs/마케팅/프로필_20261019/배너/out
  ```
- **Fable 시안 검수(10-19):** 「고친 뒤 올림」. 고칠 것은 하나였다. 미얀마 배너의 노란 강조 띠가 글자 밑에 떠 있었는데(Myanmar Text 아래 여백, 10-02판부터 있던 문제), `[lang="my"]`만 띠 구간을 40~66%로 올려 고쳤다. 제안대로 페이스북 커버 글 상자도 x300 → x340으로 옮겼다. 나머지는 「문제 없음」이었다. 몽글이 바탕과 한 장으로 읽히고, 글은 안전 영역 안에 들어가며, 24~48px 원에서도 몽글로 읽힌다.
