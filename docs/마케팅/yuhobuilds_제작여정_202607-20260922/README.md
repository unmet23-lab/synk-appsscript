# yuhobuilds — 번역을 위한 첫 결제에서 출석 앱으로

2026-09-22 사용자 수정 요청과 직접 회고를 반영한 시간순 연재 작업본. 기존 Behance 커버 수정 영상은 이 연재의 1편으로 채택하지 않는다. 원본은 보존한다. 폴더 이름은 최초 조사 범위를 유지하지만 실제 출발점은 6월 초다.

## 채널이 함께 갈 방향

**AI를 처음 접한 사람이 유호의 고군분투를 친근하고 재미있게 따라보며, AI로 자기 일을 해결하고 제품·서비스를 만들고 운영하는 1인 기업가까지 성장하는 데 도움을 주는 채널.** 실제 이야기 속에서 필요한 팁과 정보를 이해하기 쉽게 풀고, 시청자가 자기 상황에 적용할 수 있게 한다. 기술의 기초부터 제작·고객의 반응·개선·사업 운영의 판단까지 실제 여정과 함께 이어간다. 사업의 결과와 시행착오는 확인된 범위로 이야기한다.

2026-09-26 사용자 재확인: **비개발자에게 필요한 정보를 유호 자신의 이야기로 친근하게 풀어 알려준다.** 코딩·도구 이름을 처음 듣는 시청자가 출발점이다. 각 편에서 유호가 무엇을 하려 했고 어디서 막혔는지, 지금이라면 어떻게 판단할지와 시청자가 직접 해볼 한 가지가 연결되는지 확인한다. 어려운 용어는 그 장면에서 왜 필요한지와 쉬운 예시로 풀고, 실제 회고와 현재의 조언을 구분한다. 장기적으로 초급→중급→고급, AI 활용→제품·서비스 제작과 운영→1인 기업가의 여정으로 이어가는 기존 방향을 유지한다.

## 확정된 방향

- 유호가 **6월 2일 번역을 위해 Claude를 처음 결제한 일**부터, 스카이라인에듀 부원장으로 일하며 출석 웹앱을 만들던 시도와 9월 22일까지의 실제 선택·수정을 시간순으로 이야기한다.
- 1편은 6월의 시작과 첫 시도에 충분히 머문다. 전체 사건을 35초 한 편에 압축하지 않는다.
- 2026-09-22 첫 검토 후 사용자는 3분 영상의 느린 말과 지루한 목소리를 지적했다. 쇼츠에 맞게 빠른 전개와 리듬 있는 BGM을 사용하고, 귀엽거나 코믹하기보다 매력 있는 성인 남성 애니메이션 성우의 느낌을 원한다. 새 후보들도 최종 선호로 채택하지 않았으며, **이번에는 정의로를 임시로 쓰고 추후 사용자 육성으로 교체**하기로 했다. [쇼츠 수정본](../yuhobuilds_1편_쇼츠수정_20260922/README.md)을 현재 작업으로 본다.
- 각 편의 시작에서 오늘 들려줄 일과 당시 상황을 알려준다. 끝에서는 그 편에서 무엇을 바꾸었고 무엇이 남았는지 알 수 있게 한다.
- **실화 기반 스토리 + 각색**이다. 사용자 회고의 흐름 안에서 속말·장면·대사·호흡을 재미있고 공감되게 구성한다. 중요한 사건과 결과가 달라질 때, 또는 연결에 필요한 정보가 없을 때는 사용자에게 묻는다.
- **초보자가 이야기에 이입하고 자기 작업을 따라 해보며 AI 기본기를 배우는 채널**로 만든다. 도구를 여는 법, 파일·폴더, 실행과 오류 등은 실제 막힌 순간에 필요한 만큼 설명한다. 초급부터 중급·고급으로 이어가는 [학습 흐름](초보자_학습흐름.md)을 함께 준비한다. 현재 따라하기와 당시 경험은 구분한다.
- 공개 계정은 기존 yuhobuilds 4곳. 이 작업에서는 게시하지 않았다.

사용자가 확정한 [엔딩 연결과 채널 멘트](엔딩_20260922.md), [추가 인물 사진](근거/인물사진_20260922/README.md), 반복 검토에서 정리한 [1편 피드백과 다음 제작 기준](1편_피드백과_다음제작기준.md)도 다음 제작에서 참고한다.

2편은 [첫 도구 선택과 Claude Code 설정에 대한 사용자 회고](첫도구선택_사용자회고_20260924.md)를 바탕으로 [원고와 영상 작업](../yuhobuilds_2편_첫도구선택_20260924/원고.md)을 만들었다. 당시 제안의 정확한 채팅 문장은 확보하지 못했으며, 현행 설정 안내는 과거 회상과 분리한다.

## 이야기를 계속 쌓는 위치

| 내용 | 보관 위치 | 이어가는 방식 |
|---|---|---|
| 유호가 직접 들려준 경험 | [시작 사용자 회고](시작_사용자회고_20260922.md), 이후 시기·주제별 회고 MD | 원문과 설명을 남긴다. 같은 시기의 후속 회고는 해당 파일에 붙이고, 새로운 시기나 독립된 긴 사건이 생기면 회고 파일을 나눈다. 받은 날짜와 사건이 일어난 때를 구분한다 |
| 이야기로 꺼내 쓸 소재 | [소재 목록](소재_목록.md) | 원문을 반복해서 복사하지 않고, 재미있는 장면·배울 점·사용한 원고·필요한 질문으로 연결한다. 한 소재가 여러 편의 시작·회상·설명에 쓰일 수 있다 |
| 결제 내역·사진·작업 캡처 | [근거 폴더의 자료 목록](근거/자료목록.md), `근거/결제내역/` 등 | 원본을 보관하고 관련 회고·원고를 연결한다. 현재 Claude 청구서 1건을 보관했으며 영상용 편집본과 구분한다 |
| 편집·조사·제작 | 기존 연재 구성안, 월별 조사, 각 편 원고와 읽는 대본 | 조사와 회고에서 필요한 것만 골라 장면으로 쓴다. 각색한 부분은 해당 원고에 남긴다. 읽는 대본은 원고의 낭독 부분을 옮긴 파생본이다 |

지금은 기존 원고·월별 조사 파일을 유지한다. 대화 한 번마다 파일을 새로 만들거나 모든 소재를 별도 문서로 나누지 않는다. 새 회고가 들어오면 관련 원문·소재 항목·영향받는 원고를 함께 갱신한다. 이전 사실이 정정되면 정정 전후와 받은 날을 회고에 남기고, 원고에는 최신 확인 내용을 반영한다. 원고에 새로 만든 대사가 회고 원문으로 되돌아가지 않게 한다.

이 폴더명은 최초 조사 기간을 담은 기존 주소다. 지금은 6월 시작 이야기도 여기에서 관리하며, 새로운 시기의 자료도 같은 입구에서 연결할 수 있다. 다른 기간의 큰 묶음이 필요해질 때 나누고 입구 링크를 유지한다. 이야기를 받는 순서가 뒤섞여도 소재 목록과 연재 구성에서 실제 시점에 맞춰 배치한다.

## 확인한 것과 남아 있는 것

7월 8일 첫 Git 저장본은 이미 v5.3이고, 코드에 7월 7일 표기가 있다. 그 날을 첫 Claude 사용일로 말하지 않는다. 7월 11일의 고정 문서에는 비개발자인 유호가 몽골 한국어 교육 사업을 준비하며 Claude로 설계·제작하던 상황이 남아 있다. 최초 사용자 대화는 현재 로컬 조사에서 확보하지 못했다.

사용자는 6월 2일 Claude를 처음 결제했으며 **그날의 목적은 오로지 번역**이었다고 설명했고 청구서 날짜를 보여줬다. 당시 몽골 울란바토르 스카이라인에듀의 부원장으로 일했고 번역에 가끔 사용하다가 학생 문의가 갑자기 늘어 앞으로의 관리를 걱정하게 됐다. 학생 관리를 편하게 하고, 등하원 알림으로 학부모에게 신뢰를 주며, 동료 교사도 편해지길 바라 출석 웹앱을 Glide와 구글시트로 만들기 시작했다. 친구 없이 심심했던 상황과 AI에 대한 호기심은 개인적인 배경으로 함께 기록한다. 첫 결제와 개발 시작은 구분하며 개발을 시작한 정확한 날짜는 아직 모른다.

추가 회고에서 개발·코딩·Claude Code·Codex 개념을 전혀 모르는 초보였고, 스크린샷을 반복해서 찍으며 도구 설정부터 헤맸다고 확인했다. 수업 시간 외에 하루 17~18시간 앱만 만들었던 것 같다고 회상했다. 개발 중 비자 연장 때문에 한국으로 돌아와 학원에서는 실제로 써보지 못했다. 정확한 귀국 월을 이어 질문했다.

사용자는 이후에도 소재와 인과가 비면 자주 질문해 달라고 했고, 흐름에 맞는 각색을 명시적으로 허용했다. 처음 상황과 추가 경험·각색 선호를 각각 별도 기억 추가 메모에 저장했다. 첫 장면의 속말과 유머는 원문 인용이 아닌 새 대사로 구성한다.

1편은 Typecast 남성 보이스 **윤성**의 `smart` 설정으로 19개 구간·1,330자를 합성하고, **1080×1920·30fps MP4**를 출력했다. 57개 자막과 표지·19장면의 실제 시각 검수를 마쳤다. 음성 재합성 없이 마지막 무음 여백을 줄여 타임라인 **179.9초(5,397프레임)**로 마무리했다(MP4 컨테이너 179.966667초). MP4 규격·전체 디코딩과 720 WebM 생성·전체 디코딩 검사를 통과했다. IAB에서 별도 재생 버튼으로 WebM의 시작·중간·끝 구간 재생을 확인했다. 직접 청취 완료로 기록하지 않으며 외부 게시도 하지 않았다. 최신 파일·검수 결과는 [1편 제작 폴더](../yuhobuilds_1편_20260922/README.md)를 따른다. 이번 Typecast 연결은 합성 후 종료했으므로 새 합성 시 기존 API 키의 로컬 연결이 다시 필요하다. 키는 이 폴더나 기억에 저장하지 않는다.

## 자료의 의미

- 원대화, 당시 AI 요약, 고정 코드·문서, 현재 회고를 구분한다.
- 커밋은 변경 사실의 근거다. 실제 학생 사용, 운영 효과, 공개 게시와 매출의 근거로 바꾸지 않는다.
- 당시 만든 문서의 현재형 표현도 코드·실행·결과와 대조한다. 이후 폐기한 선택은 그때의 선택으로 설명한다.
- 현재 파일에 없는 98개 사건 원문을 읽었다고 주장하지 않는다. 남아 있는 고정 기록으로 다시 조사했다.
- 학생 이름·연락처·자격증명·개인 금융정보는 화면과 대사에 넣지 않는다. 과거 화면이 없으면 작업 재현이라고 표시한다.
