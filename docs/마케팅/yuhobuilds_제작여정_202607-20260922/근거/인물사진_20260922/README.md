# 유호 인물 사진

2026-09-22 사용자가 바탕화면의 추가 사진도 향후 필요할 때 사용하라고 요청했다. 원본 9개를 복사하고 SHA-256 일치를 확인했다. 원래 바탕화면 파일은 유지한다.

이번 1편 얼굴 합성에는 `유호_프로필_800.png`를 사용한다. 후속 작업에서 9장 전체를 미리보기로 비교했고 엔딩에는 웃는 다른 사진 `KakaoTalk_20260908_215815072.jpg`를 사용했다. 촬영 시점과 장소는 추정하지 않는다. 사진 선택 시 실제 구도와 출연 인물을 확인한다.

원본 경로·해시·확인 상태: [목록.json](목록.json). 생성·누끼·합성 파생본은 각 회차 `assets/`에 둔다.
