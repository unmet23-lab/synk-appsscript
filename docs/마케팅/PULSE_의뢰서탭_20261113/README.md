## 무엇을 더하나

의뢰서는 아홉 화면 그대로다. 새 칸은 모두 눌러서 고르고, 고르지 않아도 넘어간다(메모 「손님에게 글로 더 묻지 않는다」 · 「사용자 관문은 엄격하게 막지 않기」).

| | 어느 화면 | 더하는 것 | 지금 | 답 칸(이름 · 값) |
|---|---|---|---|---|
| 하나 | 여섯째 「무엇으로 오래 남을까요?」 | 넷째 줄 「웃음으로 퍼지게」(예시 「매진 임박」 12초) + 칩 「정석대로 · 조금 다르게 · 확 다르게」 | 「이야기로 여운을」 · 「한 장면의 임팩트로」 둘 — 제작 규칙의 이기는 길은 셋(여운 · 공력 · 웃김)이다 | `win: 'laugh'` · `bold: 'safe' \| 'twist' \| 'wild'` |
| 둘 | 다섯째 「화면에 정확히 나와야 할 글자가 있나요?」 | 「광고에 꼭 붙여야 하는 표시가 있는 업종인가요?」 — 업종마다 꺼내는 칩 + 「해당 없어요」 · 「잘 모르겠어요」. 고르면 안내 한 줄과 선택 칸(쓰시는 고지 문구 · 심의 번호), 모니터의 광고 틀 아래에 「고지 문구가 들어갈 자리」 | 피할 말만 받는다 | `notice: '<업종 칩>' \| 'none' \| 'unsure'` · `noticeText` |
| 셋 | 일곱째 「누가 나올까요?」 · 셋째 「이것만 보내 주세요」 | 목소리 칩 「내레이션이 이끌어요 · 모델이 직접 말해요 · 말 없이 음악과 자막으로」(「사람 없이 제품만」이면 둘째 칩은 숨김) + 준비물의 「브랜드 음악 · 로고 소리」 칸(있으면) | 소리에 대해 아무것도 받지 않는다 | `voice: 'narration' \| 'model' \| 'none'` · 파일 칸 `sound` |

보내기 전 확인에는 「꼭 붙일 표시」 · 「얼마나 과감하게」 · 「목소리」 세 줄이 생기고, 비어 있으면 「저희가 제안해요」 · 「저희가 확인해요」가 적힌다. 손님에게 보이는 글 전문 · 업종별 칩 목록은 `시안/make.py`에 있다(그 글이 정본).

과감함이 제작에서 바꾸는 것(제안 — 방향 제안 두 안의 폭): 정석대로 = 두 안 모두 업종의 익숙한 문법 안 · 조금 다르게 = 한 안은 정석, 한 안은 한 군데를 비튼 안 · 확 다르게 = 컨셉 후보를 넓게 뽑고 두 안 모두 비튼 쪽. 무엇을 고르든 제품 사실 · 피할 말은 지킨다.

## 시안을 만든 법

그림판이 아니라 **실제 의뢰서 코드에 얹어 띄운 화면**이다. `시안/make.py`가 고객 앱의 `request-data.mjs` · `request-flow.mjs`를 `시안/over/`에 베껴 정확한 글자 바꾸기로 세 가지를 얹고(원본이 바뀌어 자리를 못 찾으면 멈춘다), `시안/serve.mjs`가 운영 서버 없이 의뢰서만 띄운다(`/before/` = 지금 코드 · `/after/` = 얹은 코드, 답은 화면 메모리에만).

```
python docs/마케팅/PULSE_의뢰서탭_20261113/시안/make.py
node docs/마케팅/PULSE_의뢰서탭_20261113/시안/serve.mjs 4871     # http://127.0.0.1:4871/after/harness.html?step=feel
node docs/마케팅/PULSE_의뢰서탭_20261113/시안/shots.mjs           # 전 · 후 캡처(PC 1680×970 · 휴대폰 390×844, 이 PC의 Edge)
node docs/마케팅/PULSE_의뢰서탭_20261113/시안/shots.mjs 재기      # 작은 창(1440×900)에서 물음 칸이 넘치는 높이
python docs/마케팅/PULSE_의뢰서탭_20261113/시안/page/build.py     # 캡처를 넣은 시안 쪽
```

웃음 예시 영상은 git 밖 완성본의 **자막 없는 화면 판**에서 자른다(자막 있는 판은 휴대폰에서 작품 설명 글과 자막이 겹친다). 처음엔 앱에 있던 640×360 판을 썼는데 큰 화면에서 두 배로 늘어나 버렸다.

```
ffmpeg -ss 5 -t 12 -i <synk-vendor>/homeshopping-horror-20261021/최종/화면.mp4 -an -vf "scale=1280:720:flags=lanczos,fps=24" -c:v libx264 -preset slow -crf 27 -pix_fmt yuv420p -movflags +faststart 시안/over/assets/request/film-maejin-laugh.mp4
ffmpeg -ss 12.6 -i <같은 파일> -frames:v 1 -vf "scale=960:540:flags=lanczos" -c:v libwebp -quality 82 시안/over/assets/request/w-maejin-laugh.webp
```
