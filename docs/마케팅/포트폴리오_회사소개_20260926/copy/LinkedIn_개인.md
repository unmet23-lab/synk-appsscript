# LinkedIn 개인 · 양유호

상태: 검토용 게시 원고 · 외부 미게시

## 게시 본문

SYNK의 SNS 디자인을 정리하면서 먼저 두 가지를 나눴습니다. 여러 채널에서 함께 유지할 것, 그리고 각 채널에 맞춰 바꿀 것이었습니다.

한국어 학습, AI 활용, 제작 기록을 다루는 계정들이 같은 브랜드로 보이면서도 각자 무엇을 제공하는지 설명해야 했습니다.

공통으로 유지한 것은 로고와 펠트·자수·유리 표현이었습니다. 설명할 내용과 소품의 배치는 채널마다 조정했습니다. 방문자가 이곳에서 무엇을 볼 수 있는지 알 수 있도록 문구를 고르고, 실제로 이미지가 보이는 영역에 맞춰 배치했습니다.

제가 맡은 일은 이 방향을 정하고, AI로 생성한 이미지와 기존 자산을 선택해 실제 화면에 맞게 다듬는 것이었습니다.

Behance에서는 첫 업로드 미리보기를 보고 다시 수정했습니다. 오른쪽 소품이 잘리고 상단 메뉴가 커버 일부를 가렸습니다. 저장을 취소하고 로고·문구·소품을 중앙으로 모은 뒤 아래로 옮겼습니다. 다시 업로드하고 새로고침한 화면에서 전체 구성을 확인했습니다.

이 작업에서 제가 배운 것은 원본을 완성한 뒤에도 확인할 일이 남아 있다는 점입니다. 실제로 놓일 화면을 보고 나서야 어떤 요소를 옮기고 무엇을 비워야 할지 더 분명해졌습니다.

여러 채널의 이미지를 정리하고 있다면, 공통으로 유지할 요소와 채널별로 바꿀 요소를 먼저 적어보세요. 이후 실제 업로드 화면을 확인하면 수정할 기준을 잡기 쉽습니다.

AI를 활용해 SYNK의 홈페이지와 콘텐츠를 만들고 있는 양유호입니다. 이곳에는 제가 맡은 작업과 그 과정에서 내린 판단을 기록하겠습니다.

SYNK 소개: https://synk.im/

## 첨부·게시 메모 — 본문에 포함하지 않음

- 이미지 순서: 승인 대표 커버 → 공통 요소·채널별 배치 비교 → Behance 수정 전후 업로드 원본.
- 전후 비교에 `업로드 원본`을 표시한다. 공개 화면 캡처라고 설명하지 않는다.
- SYNK 자체 프로젝트이며 외부 고객 납품이나 성과로 소개하지 않는다.
- 운영 중인 양유호 개인 LinkedIn 프로필에 사용할 원고다. 운영 제외된 옛 yuhobuilds 프로필에는 사용하지 않는다.
