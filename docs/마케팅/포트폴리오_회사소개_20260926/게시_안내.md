## 게시할 때

텍스트의 프로젝트 제목·본문·핀 제목·설명·대체텍스트는 해당 입력란에 나누어 넣습니다. 채널 이름이나 항목 이름을 본문으로 그대로 붙여 넣지 않습니다.

Pinterest 링크는 현재 SYNK SHIFT 소개 페이지입니다. 이번 Behance 프로젝트는 아직 미게시이므로 공개 주소가 없습니다. 프로젝트를 실제 게시한 뒤에만 해당 주소로 교체합니다.

Behance 수정 전후는 실제 업로드용 원본입니다. 플랫폼 화면 캡처가 아닙니다. SYNK 자체 작업이며 고객 납품이나 성과를 뜻하지 않습니다. AI 이미지·기존 브랜드 자산·디지털 합성 제작 크레딧을 유지합니다.

기업·기관 AI 교육·컨설팅·브랜딩과 PATH 서비스의 준비 상태를 유지합니다. 카카오톡 자료는 공개 소식용이며 친구 대상 메시지 발송은 별도입니다.

## 파일 규격

Behance 표지 1616×1264, 본문 폭 1400px. Pinterest 1000×1500. LinkedIn 대표 이미지 1200×1500. 카카오톡 1080×1080. 실제 게시 전 업로드 미리보기에서 최종 잘림을 확인합니다.
