## 판마다 같은 설정

- 어린이 전용(made for kids) 아님 — 점수 댓글이 필요하다(퀴즈 #1~#3과 같음).
- AI·합성 표시: 필수 아님. 펠트 그림과 특정인이 아닌 TTS 진행자라 사실적인 사람·장면이 없다(퀴즈 #2 판단과 같음). 플랫폼이 묻는 칸은 「아니요」.
- 언어: 유튜브 동영상 언어 en(영어 진행), 제목·설명 en. 몽골어·간체·버마어판은 목소리가 한국어뿐이라 동영상 언어 ko, 글 언어는 그 나라 말.
- 자동 더빙·Meta AI 번역(목소리·입 맞추기)은 끈다. 켜면 한국어 발음이 다른 말로 바뀐다(제작 방식 v2 §4-2).
- 학습 허브 링크(synk.im/try/learning-hub/)는 10-20 18:3x에 공개를 확인했다(200, 「SYNK LAB PLAY · 한국어 놀이」, 게임 8개). 유튜브는 설명란·고정 댓글, 몽골은 첫 댓글(선택)에만 둔다.
- 올리는 파일은 원본 `video.mp4`(H.264 약 11Mbps · BT.709 · −14.5 LUFS 안팎)다. 크롬 확장처럼 10MB 상한이 있는 길로만 올릴 수 있을 때는 `upload_10MB.mp4`(x264 2패스 9.4MB)를 쓴다 — 10-19 유호님 「10MB 판으로 제가 올리기」 예외와 같은 경우에만.
- 핼러윈 편이라 10-29(이태원 참사 4주기)에는 다시 올리거나 끌어올리지 않는다(트렌드 스캔 10-19 §8).

영어판은 「CREEPY KOREAN FACT」 + 콩알만 한 간, 몽골어판은 기본 도전 문구 + 떨어지는 간 + 「элэг унах??」(캡션 첫 줄 「간 떨어지다 ≠ элэг унах 😱」). 72시간 판정(10-23 밤) 때 두 판의 첫 화면 넘김(3초 유지·본 비율)을 견준다. 간체·버마어판은 몽골어판과 같은 0초 화면이다.
