### 09-11 자동발행 후속 검수

현재 19개 첫 패키지의 필수 파일은 통과하지만, 기존 09-10 발행 계획은 모든 항목의 원본 지문이 낡았다(이미지 67·PDF 1 변경, 누락 0). 승인·예약은 0개다. 09-11 새 29.4초 유호 첫 영상은 이 계획 밖이며 새 음성 다운로드·삽입은 사용자가 보류했다. 새 BGM 영상과 기존 ZIP의 영상 지문도 다르므로 기존 계획·ZIP을 일괄 발행하지 않는다. Tistory 계정은 있지만 이 옛 19개 계획에는 없다.

연결 점검은 LAB YouTube 1개 연결, 14개 직접 통로 인증 필요, 본체 Instagram 1개 미확정, 수동 편집기 주소 4개 등록이다. 편집기 주소 등록은 로그인 성공이나 게시 완료의 증거가 아니다.

`tools/lib/sns-publisher.js`의 YouTube 부분 실패에서 영상 ID를 보존하고 같은 계획 재업로드를 차단했다. 승인에 실제 본문·계정·미디어·공개범위·예약·TikTok 통제값을 묶고 발행 직전 재검증한다. 잘못된 `--계획` 문서 명령도 수정했다. 주담당이 변경 diff를 읽고 `node --test tests/sns-발행.test.js` **53/53 통과**를 다시 확인했다. 자격 보관소·네트워크는 모의 처리했으며 실제 계획 승인·발행·예약 설치는 하지 않았다.

남은 제한: Instagram 직접 발행 미구현, Threads 첨부용 승인 HTTPS 주소 필요, TikTok 사용자 통제와 최종 게시 상태 확인 필요, YouTube/Facebook 외 예약 미구현, 다른 계획·브라우저 게시·동시 실행의 중복 감지 미지원. 상세는 [자동발행 구현](../research/sns-upload-20260910/자동발행_구현.md)을 따른다.

후속 코드 대조: Threads·Instagram·TikTok의 `--자격-연결`은 공식 OAuth 동의·코드 교환 화면이 아니라 이미 발급된 토큰의 로컬 저장 폼이다. 제출 시 토큰 유효성·실제 계정 소유를 검증하지 않으며 TikTok 갱신 토큰도 자동 갱신하지 않는다. 공식 동의부터 연결 계정 확인까지 구현된 것은 YouTube 전용이다. 따라서 웹 로그인·폼 저장을 자동 발행 연결 완료로 세지 않으며, 인증·검수만 남는 운영은 아직 구현 목표다. 이번에는 자격 폼 열기·자격 저장·콘텐츠 승인·게시·예약을 실행하지 않았다.

### 네이버 빈 화면·가독성 후속 정리

공식 관리자에서 프롤로그·지도·서재를 꺼 저장 성공 안내를 확인했다. 글 0개인 기존 `게시판`을 **작업 기록**으로 바꾸고, 해당 분류의 글 수 표시를 끄며 한 페이지 글 수를 3개에서 1개로 저장했다. 이름 입력의 첫 시도는 유지되지 않아 성공으로 세지 않았고, 실제 키 입력·포커스 이동 뒤 트리 이름 변경과 저장·공개 분류를 다시 확인했다. 글·카테고리 삭제나 새 글 발행은 없다.

블로그씨 ‘오늘의 질문’은 **배달중지**를 저장해 공개 본문의 자동 질문이 사라짐을 확인했다. 공식 리모콘에서 블로그 메뉴 기본/강조색·프로필 내용색·구성 상자 제목/내용색을 브랜드 Ink `#2B2320`으로 지정했다. 편집 중 리모콘 이동으로 달라진 미저장 프로필 스타일은 전부 취소하고 원래 저장본에서 색상만 다시 작업했다. 최종 ‘세부 디자인 적용’까지 처리한 뒤 공개 페이지를 새로고침하여 커버 전체·원래 펠트 도장·2단 배치·짙은 메뉴/소개/카테고리와 **작업 기록**을 시각 확인했다. 공개 DOM 계산색 조회는 본문 요소를 읽지 못했으므로 색상 계산값 검증으로 세지 않는다.

`m.blog.naver.com`은 도구의 사이트 안전 정책으로 접근 거절됐으며 대체 브라우저·사용자 에이전트·간접 요청으로 우회하지 않았다. 모바일 표지는 수정·검증하지 않았다. 데스크톱에서 유지되는 ‘아직 작성된 글이 없습니다’는 첫 글 미발행 상태이며 디자인 오류나 게시 완료로 해석하지 않는다.

Naver 후속 시각 검수: 기존 타이틀 높이 50에서 이미지와 프로필이 겹쳤고, 폭 1180의 이미지 내용은 실제 약 1054px 창에서 왼쪽 로고가 잘렸다. 공식 리모콘에서 높이를 600으로 저장하고, 생성기의 안전 폭을 940으로 줄여 다시 업로드했다. 하단의 중복 `SYNK SHIFT · SYNKSHIFT` 표기도 제거했다. 2단 배치의 적용 확인창까지 처리한 뒤 공개 화면에서 로고·제목·보조문 전체와 프로필 옆 본문을 확인했다. 폭 보정 전 이미지는 `docs/SHIFT/네이버_스타일/synkshift_네이버_스킨.backup_20260911_0323.png`에 보존했다. 외부 브라우저의 기본 가로 스크롤 자체를 없앴거나 모바일 스킨까지 바꾼 것은 아니다.
