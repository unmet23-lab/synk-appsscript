# 그록 시험관 답 · 구독(grok CLI) · 2026-11-13T01:50:01.143Z

1. 이 영상이 말하려는 것 — 한국말로 ‘매우’라는 말이 많이 나와, 인형이 단어에 파묻히고 한국어가 어렵다고 끝난다.
2. 보고 나서 내가 바로 할 수 있게 된 것 — ‘아주’로 ‘အရမ်း’을 말하는 것, 그리고 ‘한국어 진짜 어려워’를 따라 하는 것.
3. 무슨 말인지 모르겠던 낱말·장면 — 1.5~3초 질문 밑줄은 작아 끝이 안 읽혔다. 10~12초 매우·너무·엄청·되게·무척·굉장히·몹시·대단히는 차이가 모르겠고, 12초 밑글자는 작아 일부 못 읽었다. 끝 전에 또 ‘아주’가 들리는데 16초는 ‘진짜’만 남아, 어느 말인지 잠깐 헷갈렸다.
4. 넘겼을 것 같은 초와 까닭 — 끝까지. 0.5초에 내 말로 물어봐 손이 안 갔고, 파묻힌 얼굴이 궁금했다.
5. 이해 점수 — 4. 이야기는 한 번에 알겠다. 한꺼번에 나온 말의 차이는 모른다.
6. 재미 점수 — 3. 끝의 지친 눈 때문에 남았다. 10초부터는 단어 조각만 쌓여 지루했다.
7. 처음 3초 — 계속 봄. 0.5초 질문이 내 말이라서, 1초의 ‘아주’ 뒤에 더 있나 봤다.
8. 저장하거나 누구에게 보내겠나 — 저장. 빨라서 다시 보고 싶다. 보낼 사람은 없다.
9. 비교 — 달라 보임. 하나 전은 공책을 위에서 찍어 칸에 글자를 쓴다. 둘 전은 빨간 글줄과 채팅 아래 사진이다. 이번 건 방에 단어 조각이 쌓이다 ‘한국어… 진짜 어려워…’로 끝난다. 말 순서, 머리 글 자리, 끝 장면이 다르다.
