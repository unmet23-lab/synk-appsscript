# 그록 시험관 답 · 구독(grok CLI) · 2026-11-13T01:03:11.044Z

1. 한국어 ‘很’은 말이 너무 많아서 처음엔 진짜만 외우면 되는데, 끝에 또 아주가 나와 어렵다는 영상이야.
2. 아주=很, 진짜=真的를 읽어서 ‘한국어 진짜 어려워’는 알아듣게 됨. 다른 말은 바로 못 씀.
3. 6초 정말(真)·진짜(真的), 8초 완전(完全)은 1초 아주(很)와 뜻이 달라 같은 말인지 모르겠음. 8초 책 위 작은 글자는 못 읽음. 10초 엄청은 뜻이 안 보임. 8~12초의 매우·너무·굉장히·몹시는 화면 뜻이 없어 모름. 14초 색 조각은 글자가 안 보임.
4. 끝까지. 1.5초 ‘한 단어겠지’ 때문에 답을 보려고 봤고, 중국어 자막이 이어져 20초 안에 끝남.
5. 4. ‘말이 많고 처음엔 진짜만’은 자막으로 알겠는데, 중간 낱말은 한 번에 다 못 외움.
6. 3. 파묻힌 모습과 16초 지친 눈은 귀여움. 6~12초는 카드만 바뀌어 친구에게 보여줄 만큼은 아님.
7. 계속 봄. 0.5초가 내가 찾는 ‘很怎么说’이고, 1.5초에 단어가 하나인지 확인하고 싶었음.
8. 저장. 아주와 진짜를 다시 보려고. 친구에게는 안 보냄. 중간 단어를 설명 못 함.
9. 달라 보임. 이번엔 카드가 쌓인 뒤 가까운 얼굴과 한국어 문장으로 끝남. 지난 건 공책 정리 표로 끝나거나, 두 인물이 인사하는 장면으로 끝남. 말하는 순서도 단어를 쌓다 한숨인지, 글자를 고쳐 쓰는지, 대화를 고치는지가 다름.
