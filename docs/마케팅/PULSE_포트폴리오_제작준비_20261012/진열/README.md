## 3. 굽는 법

```bash
node 굽기.cjs synk <SYNK-website>/dist/assets/v10        # 미리 보기(소리 없음) 큰 줄 1280 · 720, 작은 칸 960 · 540, crf 24 · 포스터(큰 줄 1600 · 900)
node 굽기.cjs app <company>/public/pulse-app              # 소리 있는 1080p 본편(crf 21, 원본 크기) · 포스터(mp4는 git 밖, 회사 이미지 판이 해시로 싣는다)
node 굽기.cjs pc <desktop>/assets/pulse/portfolio         # 4:3 그림(세로 작품은 #111 바탕 가운데)
node 굽기.cjs reel <폴더>                                 # 쇼릴 두 판(1920×1200 · 1080×1920) · 포스터 · reel.json(시각표)
```

쇼릴 컷을 고칠 때: 후보 프레임에 글 자리를 칠해 넓은 화면 · 휴대폰을 따로 본다(둘이 다르면 `tall.in`), 원본 장면 경계를 재서 컷 끝이 다음 장면으로 넘어가지 않게 한다(ffmpeg `-t`는 24fps 프레임으로 올림해서 굽는다 — 시각표도 같은 셈), 구운 뒤 장면 검출 값이 `reel.json`과 맞는지 보고, 공개 전 실제 첫 화면을 컷마다 찍어 본다.

`poster.t`는 편마다 가장 매력적인 장면을 장면 모아보기로 골라 적은 초다(도담 노을 공장의 터빈 · 오미톡 노을의 웃음 · 모두의코스 수영장 · 솜채 문 앞의 빨간 카디건 · 첨벙댕 물 찬 방 · 스나이퍼 팔짱 · 힘껏 네온 터널 · 오미톡 제품 물보라 · 캐스팅북 카페). 모든 결과는 다시 인코딩하고 머리 정보를 비운다(생성 도구 표시가 공개 파일에 남지 않게).
