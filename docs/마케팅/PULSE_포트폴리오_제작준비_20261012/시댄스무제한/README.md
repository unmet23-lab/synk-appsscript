## 지시문 틀(모든 편 같음)

첫 줄 「@이미지 1 is the exact first frame …」(끝 그림이 있으면 「@이미지 2 is the exact last frame」) → 한 샷(ONE SINGLE CONTINUOUS SHOT) 또는 두 샷 머리 → 누구(사람 · 옷 · 소품을 시작 그림 그대로) → ACTION(한 가지 동작, 몇 초 안에) → CAMERA(원본 프레임 실측 숫자 그대로 — 10-26 유호님 「카메라 기법도 원본과 완전히 똑같게」) → LOOK(시작 그림의 빛 · 색을 끝까지, 새 글자 · 사람 금지) → SOUND(소리 없음 — 말 · 음악은 따로). 길이는 쓰는 초 + 0.8초(시댄스가 0.7초쯤 늦게 오는 몫), 최소 4초.

**두 샷 묶기 규칙:** 편집 차례로 붙은 두 컷이 같은 장소 · 같은 시간 · 같은 사람/물건이고 쓰는 초 합이 6초 안팎일 때만. 끝 그림이 있는 컷 · 카메라가 아주 복잡한 컷 · 빛이 바뀌는 컷은 묶지 않는다. 한 판 안에서 같은 사람이 이어지는 이점(일관성)도 있다.

## 대사 목소리 시험(10-29)

유호님 10-29 「견줘 보고 정할게」 — 위 대사 소리 위험을 무제한 날 맨 앞에서 귀로 가른다.

- **두 방식:** 지금 방식(A)은 타입캐스트 대사 줄을 원본 시각에 놓은 mp3(`3_소리.mp3`)를 소리 참고로 넣어 입을 맞추고 최종 목소리는 후시녹음이다. 새 방식(B)은 그 배역의 목소리 견본(`3_목소리견본.mp3` — 같은 타입캐스트 목소리로 다른 문장을 보통 말투 9.5~12초, [견본_계획.json](목소리시험/견본_계획.json), 파일은 git 밖 `synk-vendor/homeshopping-horror-20261021/목소리/견본/`)을 소리 참고로 넣고, 대사는 지시문의 한국어를 그대로 연기하게 해 생성 목소리를 최종으로 쓴다. 목소리 결의 출처가 같아서 두 판의 차이는 「누가 연기하나」뿐이다.
- **순서표:** 맨 앞 목소리 시험 넷(지유 #7 · #12 × A · B) → 시험 넷. 매진 임박 대사 13컷은 A · B 판이 붙어 있고 고른 방식 한 판만 낸다 — 하루 셈은 시험의 B 두 판만 늘어난다(10-29 카메라 손질 뒤 140판 = 주판 98 · 새 방식 13 · 대안 29). - **받은 뒤(Claude):** 계정 기록에서 넷을 `hs-S07.mp4` · `hs-S07-B.mp4` · `hs-S12.mp4` · `hs-S12-B.mp4`로 받아 [듣기판.py](목소리시험/듣기판.py)를 돌리면 ① A 판의 생성 소리 그대로 ② A 판 + 타입캐스트 대사 줄 덮기(지금 계획의 최종 꼴, 받아쓰기로 잰 말 시작에 맞춤) ③ B 판의 생성 소리 그대로를 나란히 보는 페이지(0.5배 단추 · 방식마다 #7 → #12 이어 듣기)가 나온다 — Artifact로 올려 드린다. 10-26 #7 시험 클립으로 미리 돌려 봤다(받아쓰기 「이게 전부예요!」 · 말 시작 1.70초 · 덮은 줄 1.68초 시작). 같이 보일 것: 받아쓰기(대사가 대본대로인지) · #7 ↔ #12 목소리가 같은 사람으로 들리는지 · 입 열림과 소리 크기가 맞는지(입모양 검수표). 고르신 방식은 결정 표에 남기고 7번 숏드라마 입 맞춤 48컷에도 쓴다 — B면 7번 배역 넷의 목소리부터 고른다(아직 안 고름).
