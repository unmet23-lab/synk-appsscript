## 3. 만든 방법

| 구분 | 내용 |
|---|---|
| 얼굴 | 가상 캐스팅 원본(참조 사진)을 기준으로 장면마다 같은 얼굴로 만들고, 대표 사진과 맞대어 확인했습니다. |
| 영상 | 확인받은 정지 그림을 영상으로 이어 만든 뒤 해상도를 높였습니다. |
| 제품 · 글자 | 병은 3D로 렌더했고, 라벨과 엔드카드 글자는 디자인 파일을 그대로 얹었습니다. AI가 그린 글자는 없습니다. |
| 후반 | 색 보정, 얼굴 밝기 부분 보정, 효과음 · 음악 · 내레이션 믹스 |
| 제작 기록 | 장면별 지시문 · 원본 · 검수 기록을 보관하며, 요청하시면 보여 드립니다. |

- 본편 15초: 9:16 · 4:5 · 1:1
