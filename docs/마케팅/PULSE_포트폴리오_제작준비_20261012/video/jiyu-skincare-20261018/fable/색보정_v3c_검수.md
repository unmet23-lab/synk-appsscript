# 지유 스킨케어 색보정 v3c(필름아침 + 부분 보정 + 색 고침) · Fable 확인 (2026-10-19)

검수: Fable(claude-fable-5-1), 파일은 고치지 않고 지적만. 대상: `synk-vendor/…/편집/{본편_9x16,본편_4x5,본편_1x1,훅B_9x16,훅C_9x16}_v3c_필름아침.mp4`, 기준은 같은 이름의 v3b([v3b 재확인](색보정_v3_검수.md#v3b-재확인10-19)). v3c에 넣은 것은 둘이다(유호님 10-19 「이어서 해보자」).

1. 부분 보정: 얼굴이 나오는 컷(1 · 4 · 5 · 7 · 훅 C)에 사람 손 없이 만든 「피부손」 마스크(얼굴 · 목 + 볼에 댄 손 · 팔) 안만 +0.2스톱. 비율 판은 마스크도 그림과 같은 자리로 잘라 입힌다([색감 README](../../색감/README.md) 「부분 보정」).
2. 색 고침: 1단계부터 bt709 행렬로 인코딩한다(v3b는 표시 없이 넣고 2단계에서 bt709로 바꾸며 고르게 어두워졌다, [현장 노트](../../../../../현장노트/영상_ffmpeg_자막.md) bt709 항목).

방법: 열 파일(v3b · v3c 다섯 쌍) 360프레임을 전부 풀어 밝기 · 8×6 격자 · 연속 프레임 차 · 올린 몫(v3c−v3b, 중앙값 뺌)의 넓이와 세기를 재고, 확인 프레임(f24 · 72 · 168 · 216 · 312 · 350)은 yuv420p 원본을 BT.709(방송 범위) 행렬로 직접 풀어 인코딩 전 PNG(`synk-vendor/…/색감/v3c_확인/인코딩전/`)와 견줬다. 입술 · 머리 · 라벨 · 엔드카드는 지난 v3b 재확인과 같은 상자 · 같은 방법. 재생해 본 것은 아니다. 측정 스크립트 · 로그는 Claude 임시 폴더에만 있고, 진행 기록 전문은 `synk-vendor/…/색감/v3c_확인/Fable_v3c_확인.md`.

**판정: 유호님께 v3c를 보여 드려도 됨.** 색 고침은 수치로 완전하고(풀면 넣기 전 색 ±0.3), 부분 보정은 다섯 판 모두 얼굴 · 목 · 손 안에만 들어갔으며, v3b 검수 항목은 하나도 나빠지지 않았다. P0~P2 없음, P3 하나.
