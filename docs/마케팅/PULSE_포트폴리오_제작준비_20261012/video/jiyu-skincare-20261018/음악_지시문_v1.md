# 지유 스킨케어 광고 · Suno 음악 지시문 v1

작성 2026-10-18 · 바탕: [브리프·콘티 v1](브리프_콘티_v1.md) 2절 「소리 먼저」 · 방식: 하린 아이스커피 [음악 지시문](../harin-iced-coffee-h3-20261017/음악_지시문_v1.md)과 같게(장부 S16·S17: Suno 연주곡을 120 BPM으로 뽑아 박을 잰 뒤 필요한 구간을 잘라 붙임) · 상태: 콘티 확인 뒤 생성

Suno 곡은 2~3분으로 나온다. 15초 광고는 곡 하나에서 「한 음 → 들어옴 → 숨 고름 → 후렴 → 끝」에 맞는 구간을 골라 마디 단위로 잘라 붙인다. 120 BPM 하프타임이라 한 마디가 2.0초(24fps 48프레임)이고, 컷 경계를 하린 광고와 같은 2초 격자에 놓는다. 하린(펑크·디스코)과 겹치지 않게 맑고 차분한 아침 소리로 간다.

| 15초 구간 | 초 | 곡에서 가져올 것 |
|---|---|---|
| 훅 | 0–2.0 | 피아노 한 음과 물방울 같은 플럭만 있는 도입 |
| 제품·화장솜 | 2.0 | 베이스와 부드러운 킥이 한 번에 들어오는 자리 |
| 두드림·창빛 | 2–9 | 잔잔한 리듬, **8.5–9.0 한 박 완전히 비움** |
| 제품 둘·엔드카드 | 9.0–15.0 | **9.0초** 귀에 남는 피아노·기타 후렴, **15.0초** 마지막 음 뒤 짧은 여운 |

설정: 연주곡(가사 칸 비움), 모델은 계정 기본 최신판, 생성 두 번(곡 넷). 내려받기는 고른 곡 하나만. 계정은 하린 광고와 같은 Suno 계정을 쓴다(메모 「Suno 만들기 요령」).

## 고르기

곡마다 내려받지 않고 플레이어 소리를 페이지 안에서 재어(현장 노트 `브라우저_게시.md` 「Suno」) 아래를 본 뒤 링크로 보여 드리고, 유호님이 귀로 고른다.
- BPM이 120 근처인가(박이 흔들리지 않는가)
- 한 음 도입, 들어오는 정박, 한 박 멈춤, 후렴, 깔끔한 끝이 실제로 있는가와 그 시각
- 보컬·허밍이 섞이지 않았는가
- 지유 내레이션(타입캐스트 유라)과 겹칠 때 목소리가 묻히지 않는가(중음대가 너무 꽉 차지 않았는가)
