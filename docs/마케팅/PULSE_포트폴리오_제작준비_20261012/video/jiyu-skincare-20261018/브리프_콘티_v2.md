- **본 제작 전 시험**(같은 사람으로 거리·빛이 다른 세 장면)은 10-18 장면 사진으로 갈음한다. B2(근접·아침 창빛), B13(상반신·밤 전구), A3(전신·스튜디오)이 모두 같은 사람으로 나왔다([지유 명세서 6절](../../../PULSE_AI모델_캐스팅_20260930/명세서/F04_지유.md)).
- 규칙은 「생성은 클라우드 최상위 모델로, 노트북을 최종 생성기로 쓰지 않는다」이다. 하지만 10-18 유호님 지시로 영상은 노트북 로컬 H3로 뽑는다. 하린 비교에서 로컬 H3는 클라우드 H3와 동작 성향이 같았고, 해상도가 낮은 만큼 SeedVR2로 키운다. 로컬로 안 되는 컷만 힉스필드를 쓰고, 그때는 먼저 묻는다.
- 480p 고르기 대신, 로컬 H3로 컷마다 한 번 뽑아 보고 안 되면 시드만 바꿔 한 번 더 뽑는다(크레딧 0, 시간만 든다).
- 규칙은 「제품 모델링과 조명은 직접 하거나 외주」이다. 맑음 병을 어떻게 만들지는 유호님이 정한다(5절의 세 안).

## 3. 콘티 (15초, 7컷)

장소는 하나: 햇빛이 드는 하얀 욕실 세면대 앞. 화면 왼쪽에 얇은 흰 커튼이 드리운 창, 흰 대리석 세면대 끝, 작은 초록 화분 하나. 글자가 있는 물건은 두지 않는다.
