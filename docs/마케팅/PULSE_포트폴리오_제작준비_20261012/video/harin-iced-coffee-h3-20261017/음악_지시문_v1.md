# 하린 아이스커피 광고 · Suno 음악 지시문 v1

작성 2026-10-17 · 바탕: [브리프·콘티 v4](브리프_콘티_v4.md) 2절 「소리 먼저」(처음엔 v2로 썼고, 유호님이 v4를 확정해 구간 표를 v4에 맞춤) · 방식: 장부 S16·S17(Suno 연주곡을 120 BPM으로 뽑아 박을 잰 뒤 필요한 구간을 잘라 붙임)

Suno 곡은 2~3분으로 나온다. 20초 광고는 곡 하나에서 「비움 → 들어옴 → 쉼 → 후렴 → 끝」에 맞는 구간을 골라 박 단위로 잘라 붙인다. 그래서 곡에 **조용한 도입, 한 번에 터지는 들어옴, 드럼이 빠지는 쉼과 완전한 멈춤, 귀에 붙는 기타 후렴, 딱 끊기는 끝**이 분명하게 있어야 한다.

| 20초 구간 | 초 | 곡에서 가져올 것 |
|---|---|---|
| 더위 | 0–2 | 낮은 베이스만 있는 도입(매미·먼 차는 효과음으로 따로) |
| 얼음 | 2.0 | 「탁」 한 번에 리듬이 들어오는 자리 |
| 붓기 | 2–6 | 리듬 |
| 한 모금 | 6–10 | 드럼이 빠지고 베이스·건반만 남는 자리, **9.5–10 완전히 비움** |
| 바람·내려놓기 | 10–16 | **10.0초** 기타 후크가 있는 후렴 |
| 엔드카드 | 16–20 | 마무리 한 마디, **20.0초**에 깔끔하게 끝 |

설정: 연주곡(가사 칸 비움), 모델은 계정 기본 최신판, 생성 두 번(곡 넷, 20크레딧). 내려받기는 고른 곡 하나만.
