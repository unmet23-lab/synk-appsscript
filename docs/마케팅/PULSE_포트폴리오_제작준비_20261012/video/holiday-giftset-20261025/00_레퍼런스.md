# 시즌 2 · 홀리데이 기프트 세트 제품 광고 15초 + 6초(세로 · 가로) — 레퍼런스 후보 (2026-10-26)

> [포트폴리오 12편](../../포트폴리오12_20261024.md) 「시즌 4편」 절. 유호님이 고르기 전이다. 보드 `Documents/synk-vendor/pulse-season4-20261025/레퍼런스/보드/s2_레퍼런스보드.jpg`(원본 프레임이 들어가 git 밖). 후보 숫자는 10-26에 유튜브 공식 API로 직접 읽었고, 비교용 숫자 일부(같은 날 쇼츠 · 조말론 15초판)는 웹 조사가 페이지에서 읽은 값이다. 「평소의 몇 배」는 그 채널 최근 업로드(3분 이하) 조회 중앙값과 견준 값이고, 컷 수는 화면이 크게 바뀌는 순간을 프로그램으로 센 것이다(같은 바탕색 전환은 놓쳐 따로 적었다).

가상 뷰티 브랜드의 홀리데이 에디션을 리본이 풀리고 상자가 열리는 블렌더 제품 영상으로 보이는 편이라, 얼굴 없이 제품과 손만 나오는 원본만 골랐다. 브랜드 홀리데이 광고는 대부분 광고비로 튼 조회라(예: 조말론 2025 15초 쇼츠 1,197만 · 좋아요 0.09%) 채널 평소 대비 배수와 좋아요 비율로 반응을 봤다. 도시에 거대한 선물 상자를 놓는 홀리데이 FOOH(엘리자베스 아덴 · 랑콤 · 디올 등)는 3번 편(FOOH)과 겹쳐 뼈대에서 뺐다.
