## 걸린 함정(현장노트 [블렌더_3D](../../../../../현장노트/블렌더_3D.md) 10-29 넷 + 여기)

- 블렌더 접사는 조리개가 과해 바탕이 뭉개진다 → f/12~16.

- numpy 위상장은 느리다 → torch GPU(약 19배). 다른 세션이 GPU를 꽉 쓰면(영상 화질 높이기) 블렌더는 `--cpu`.
- 맑은 유리 단지 속 크림은 「유리 속 흰 상자」 → 남색 불투명. 맑은 앰플 라벨은 뒷면 · 안쪽에서 한 번 더 비친다 → 앞면 하나 + Backfacing엔 잉크 없음으로 줄였지만 가까운 컷엔 아직 겹친다(Fable P1 ③).
- 끝 글을 밝은 아침 서리 위에 얹을 땐 상아색이 묻힌다 → 짙은 남색 · 짙은 금(`시안글.py end_card(ink=…)`).
