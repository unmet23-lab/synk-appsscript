## 3. 리본이 풀리는 장면 — 시험 렌더 · 움직임

진행값 하나(u, 0~1)로 리본이 풀리고, 3판부터 그 뒤에 제품이 떠오른다(`--rise`, 원본 1위 Carolina Herrera의 「병이 하나씩 날아오름」 — 단지가 먼저 7 cm, 앰플이 뒤따라 6 cm)([블렌더/선물상자.py](블렌더/선물상자.py)): 0 묶인 나비 → 0~0.30 나비 고리 · 긴 꼬리가 매듭으로 빨려 들어감 → 0.28~0.55 네 갈래가 **휘어 말리며** 일어섬(뿌리 각 + 끝 처짐 + 끝 말림 + 비틀림 — 어느 프레임에도 곧은 판이 없게) → 0.50~0.78 끝으로 갈수록 조금 더 돌며 바깥으로 쓰러져 물결로 누움 → 0.72~1 **뚜껑 앞이 먼저 5° 들리고** 떠오르며 속에서 금빛 김이 핀다. 물리 시뮬레이션이 아니라 갈래마다 곡선을 먹이는 꼴이라 매 프레임 같은 모양이 나오고, 원본 샷표의 박자에 맞춰 u 곡선만 바꾸면 된다(6초판은 u 0 → 0.3 → 0.8~1만 — Fable). 판당 굽기 10~20초(1280×720 · 96샘플, RTX 5090). 움직임 시험: git 밖 `콘티/holiday-giftset/리본풀림_움직임시험_B_3.1판.mp4`(960×540 · 24장/초 · 120장 = 5초 — 리본 4초 + 제품이 떠오름 1초). 지난 판은 `…_B_3판.mp4` · `…_B_2판.mp4`(640×360 · 96장).

- 1판 시험에서 고친 것: 제품 꼭지가 뚜껑을 뚫음(높이) · 흰 상자가 흰 눈에 묻힘(바탕을 청색 · 남색으로) · 리본이 관처럼 둥글게 보임(모서리 가름 — 현장노트 블렌더_3D) · B판 바닥 눈 판이 바닥을 뚫어 얼룩무늬 · 이름이 리본 띠에 걸림.
- 2판에서 새로 겪은 것: 뚜껑 엠보를 살리려 넣은 스침광이 리본을 크림색으로 날림(뺌) · 금빛 김 부피가 짙어 상자 속이 우윳빛(밀도 3 → 0.35) · 오른쪽 꼬리가 옆면 그늘에서 검은 띠로 보임(뒷면으로) · 제품 접사 카메라가 상자 벽에 막힘 · 초점이 빗나감.
- 3판에서 새로 겪은 것: 홈을 얕게 해도 위에서 내려다보는 열린 상자 컷에서는 유리 옆면이 반사만 보여 크림이 안 보인다(유리 옆면은 비스듬히 볼수록 거울) → 제품이 떠오르는 컷을 눈높이로 따로 · 상자 앞 바닥에 둔 제품 접사는 흰 상자가 화면 한쪽을 하얗게 덮어 상자 없이 서리 바닥과 보케만 · 두꺼운 유리가 가운데를 키워 크림이 흰 공 · 달걀처럼 보임 → 크림을 안쪽 벽까지 채우고 윗면을 낮은 둔덕으로 · 렌즈 앞 눈송이가 단지 앞 얼룩으로 보임(접사에서 렌즈 쪽 눈송이 뺌).
- 3.1판에서 새로 겪은 것: 크림을 안쪽 벽까지 채우고 카메라를 낮춰도 접사의 크림이 반구로 남았다 — 크림과 안쪽 벽 사이 0.1 mm 공기층에서 옆쪽 빛이 전반사돼 가장자리 크림이 안 보였다(크림이 벽을 0.2 mm 파고들게 하자 몸통이 통째로 희게) · 금속에 가까운 공단(0.85)은 면마다 둘레를 다르게 비춰 한 리본이 라메 · 거울 · 무광 베이지 셋으로 보였다(천 공단으로) · 금 뚜껑에 비칠 따뜻한 반사판을 그냥 켜면 바닥 · 뒤가 밝아져 밤 기운이 빠졌다(빛 연결로 금 뚜껑 · 금 목만 받게).
