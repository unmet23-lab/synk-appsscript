# PULSE 색감

PULSE 광고 영상에 이름 붙은 색감을 입히는 공용 도구다. 2026-10-19 유호님 「펄스 클라이언트들이 색감 고르기 편하도록 색감도 추가해보는거 어떨까 · 일단 지유 광고에 색보정 한번 적용도 해보자」로 시작했다. 순서는 팁 장부 8행(「The Process of Color Grading」 릴스의 8단계)을 Rec.709 AI 영상에 맞춘 것이다.

| 색감 | 결 | 어울리는 광고 |
|---|---|---|
| 원본 | 손대지 않음(비교 기준) | — |
| 맑은아침 | 아주 옅은 따뜻함, 밝은 곳이 살짝 번짐 | 스킨케어·생활용품, 지금 화면에 가장 가까움 |
| 필름아침 | 창 쪽 빛·확산·할레이션·옅은 안개·약한 블리치, 그림자는 청록·밝은 곳은 따뜻하게 | 스킨케어·뷰티·카페(지유 광고 첫 적용) |
| 시네마청록 | 청록·주황 색 나눔과 대비를 세게 | 패션·자동차·향수 |
| 따뜻한오후 | 노랗게 따뜻하고 부드럽게 | 음식·여행·가족 |
| 차분한무채 | 채도를 빼고 블리치 바이패스로 단단하게 | 남성 그루밍·테크·금융 |

## 쓰는 법

- 비교표: `python 색감.py 비교 <출력.jpg> <그림…> --이름 컷1,컷2 --제품 1` (줄 = 그림, 칸 = 색감, `--제품`은 제품 접사 줄 번호)
- 광고 편집에 입히기: 편집 스크립트가 컷을 자른 직후 `색감.grade(그림, 이름, product=제품컷인지)`를 부르고, 엔드카드 팩샷·글자는 그 위에 그대로 얹는다. 지유 광고는 `본편_편집.py … --색감 필름아침`.
- 다른 프로그램(다빈치·ffmpeg `lut3d`)용: `python 색감.py 큐브 필름아침 필름아침.cube` — 공간 효과(창 빛·확산·할레이션·안개·가장자리)를 뺀 색 부분만 들어간다.

- 프레임 폴더를 원본으로 주면 `--시작` · `--장수`는 무시되고 폴더의 PNG를 모두 쓴다. 10-19 전에는 `마스크_준비`가 폴더가 바뀌었는지 보지 않아 장수만 같으면 예전 마스크를 그대로 돌려줬다(아래처럼 고침). 컷이 처음부터 끝까지 들어 있는 폴더(지유 `영상_H3/업/<컷>/<컷>`)만 넣고, 프레임을 다시 만들면 보관 폴더를 비우고 다시 만든다([현장 노트](../../../../현장노트/영상_ffmpeg_자막.md) SAM 항목). `마스크_만들기.py`는 10-19부터 폴더 원본도 `잰값.json`에 「원본_지문」(PNG 크기 합 · 가장 늦은 시각 · 장수, 영상은 크기 · 시각)을 적고, `마스크_준비`가 그 지문을 견준다(유호님 10-19 「폴더 지문 고침도 네가 해」). 지문 없는 예전 폴더 기록은 바뀌었는지 알 수 없어 한 번 다시 만든다(컷당 30~60초). 다시 만든 뒤에는 마스크를 읽어 둔 캐시(`_raw`)도 비운다. 전후 시험(`부분보정_시험/폴더지문_전후.py` · `.jpg`): 컷 4 프레임 8장을 좌우로 뒤집어 다시 저장한 뒤 같은 주문으로 부르니, 고치기 전 판은 예전 마스크를 0초 만에 돌려줘 얼굴 대신 머리카락 · 화장솜 쪽을 밝혔고(뒤집은 예전 마스크와 겹침 0.198), 고친 판은 28초 걸려 새로 만들었다. 같은 주문을 바뀐 것 없이 다시 부르면 두 판 모두 바로 돌려준다.

## 지킬 것

- **제품 접사는 색조만**(노출·색온도·채도·색 나눔). 흰 병 위 옅은 라벨은 밝은 곳 눌러 담기·곡선·블리치·확산·안개가 대비를 깎아 지워진다(10-19 지유 컷 2·6).
- 확산은 「흐린 판이 더 밝은 곳만 밝히기」로 한다. 밝은 곳을 더 밝게 하는 방식은 하이키(흰 욕실) 화면 전체를 뿌옇게 띄웠다.
- 거의 흰 곳은 색 나눔에서 뺀다(흰 병·흰 티가 크림색이 되지 않게).
- 붉은 곳(입술·볼)은 채도 빼기·블리치 탈색을 절반만 받는다. 지유 v3에서 입술 채도가 23% 바랬다(10-19 Fable).
- 확산은 머리카락처럼 어두운 곳에 얹지 않는다. 밝은 벽과 맞닿은 윤곽에 회색 빛무리가 생겼다(10-19 Fable).
- 엔드카드처럼 나중에 얹는 제품 팩샷도 같은 색감의 제품 색조를 입힌다(글자는 그대로). 안 하면 앞 제품 컷과 병 색이 다르다.
- 필름 입자는 인코딩 때 한 번(`noise=c0s=3:c0f=t`). 색은 rgb에서 처음 인코딩할 때 bt709 행렬로 바꿔 넣고(`scale=out_color_matrix=bt709:out_range=tv,format=yuv420p`) 표시도 붙인다 — 표시만 붙이면 색이 틀어진다(지유 v3b 고르게 어두워짐, 하린 엔드카드 따뜻하게 뜸, [현장 노트](../../../../현장노트/영상_ffmpeg_자막.md) bt709 항목).
