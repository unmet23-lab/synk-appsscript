## 3. 원본 짜임 — 우리 판이 따를 뼈대

- **세 덩이:** ① 1–4(0–10.0초) 진짜 집에 작은 친구가 나타나 물건 사이를 탐험 → ② 5–8(10.0–19.7초) 게임 화면 속 위험(큰 적)을 진짜 친구들이 보고 겁먹어 상자 뒤로 숨었다 빼꼼 — 게임과 집이 이어지는 웃음 → ③ 9–14(19.7–34.5초) 날아올라 트리에 불을 켜 집을 바꾸고, 모두 모여 사람과 한 화면. 끝 1.57초 표지.
- **소리 곡선:** 조용한 거실 → 게임 화면에서 가장 큼 → 다시 조용해졌다가(8) 날아오르며(9) 음악이 들어와 번쩍임(11)과 함께 터지고 제목까지 이어짐.
- **사람의 자리:** 처음(2)과 끝(14) 두 번, 모두 뒷모습 · 먼 와이드다. 사람은 「이 집의 주인 · 게임하는 사람」이고 연기하지 않는다.
- **전환의 열쇠:** 11번 — 작은 친구가 진짜 물건(전구 줄)에 닿자 집이 바뀐다. 우리 판의 「물건이 펠트로 바뀜」은 이 자리의 일을 키우면 원본 짜임 안에서 된다.
