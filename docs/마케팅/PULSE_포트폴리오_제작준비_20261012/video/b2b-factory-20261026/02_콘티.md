## 4. 노래 — 가사 초안(새로 씀)

원본처럼 기타 한 대와 목소리 하나(우리 판은 남자 목소리). 0초 기타(0.2초 페이드인) → 6.7~6.9초 노래 → 36.4~37.1초 숨 → 37.2초 가장 크게 차오름 → 40.1초 노래 끝(내레이션) → 46.26초 모든 소리 끊김 → 49.95초 기타 저음 한 번 → 52.35초 다시 차오름 → 55.0~55.98초 숨 → 56.0초 한 줄 복귀. 원본 노래는 「떠나는 아이」의 목소리였는데, 우리 노래는 **보내는 쪽(만든 사람)** 목소리로 쓴다. 「돌아가다」를 「(기계가) 잘 돈다」와 겹쳐 쓴다.

```
(6.7–23.5)
불꽃 아래서 너는 처음 눈을 떴지
밤새 조인 나사 하나까지 나는 다 기억해

(23.5–40.1)
무거운 몸 싣고 낯선 데로 가도
아무 일 없단 듯 너는 잘 돌아가겠지

(56.0–58.6)
어디서든 잘 돌아가렴
```

## 5. 소리 설계

- **0~25초 만드는 소리:** 기타 위에 불꽃 · 그라인더(3) · 용접 「치익」(4~6) · 렌치 · 볼트(7 · 14) · 크레인 모터(10) — 노래보다 낮게, 컷마다 한 가지만.
- **25~37초 떠나는 소리:** 트레일러 시동(19) · 엔진 · 에어브레이크(20) · 창밖 바람(21) · 체인(22).
- **37~46초 첫 시험:** 36.4~37.1초 음악이 숨을 고른 뒤 37.2초 24 시험동 컷과 함께 음악이 가장 크게 차오른다 → 관제실 레버 딸깍(26) → 터빈이 돌기 시작해 「우웅」이 커짐(27 · 28 — 음악 크기는 그대로).
- **46.26~48.90초 정적:** 터빈 소리까지 모두 끊는다(원본 −47~−51dB, 방 소리만). 손바닥이 닿는 순간(29 컷 0.26초 뒤)이다.
- **48.9초~ 끝:** 「그리고 오늘,」(음악 없이) → 49.6~49.95초 두 번째 정적 → 49.95초 기타 저음 한 번 → 「이 아이를 보냅니다.」(기타 위) → 52.35초 기타가 다시 차오름 · 노을 바람 · 발소리(33~35) → 55.0~55.98초 음악만 조용한 숨(36 준호 얼굴) → 56.0초 37 컷과 함께 노래 한 줄 → 도시의 먼 소리 → 60.06초 끝.
