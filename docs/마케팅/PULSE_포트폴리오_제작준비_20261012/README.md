# PULSE 포트폴리오 제작 준비 · 2026-10-12

[상세 제작 보고서](index.html) · [기획 원문](plan.json) · [PULSE 공개 기획실](https://workspace.synk.im/pulse-app/production-library/)

사용자가 요청한 모델별 광고·런웨이·목소리·스타일 샘플의 제작 준비안이다. 2026-10-12 후속 요청으로 기획과 콘티의 PULSE 게시가 승인됐다. 공개 반영 여부는 아래 검증 기록에서 구분한다.

## 준비한 내용

- 광고 7편, 각 15초·6장면: 총 42장면 설계. 이안의 삽입컷을 나누면 최소 45개 영상 소스가 필요하다.
- 하린 커피·유나 향수·태준 재킷 광고의 이미지 콘티 3편과 공통 런웨이 이미지 콘티 1편. 합계 24장면의 검토용 이미지다.
- 런웨이 7편의 같은 조건 비교 기준, 새 동일 대사 목소리 21개의 제작 기준, 스타일 참고 사진 최소 119장의 구성.
- 장면별 화면·소리·문구·시간·연결 기준과 대체 컷, 하린 선행 제작부터 확장까지의 순서, 품질 확인과 가안 작업량.

이미지 콘티는 완성 영상이 아니다. 새 광고·런웨이 영상과 동일 대사 음성·스타일 참고 사진은 제작 전이다. 별도로 복원된 승인 사진 7명·기존 음원 21개와 구분한다. 가상 브랜드 광고를 실제 고객 납품이나 매출 효과로 소개하지 않는다.

## 원본과 공개본

`plan.json`이 기획 원문이다. `build.cjs`가 내부 상세 보고서를 만들고, `publish.cjs`가 고객용 기획실과 모델별 연결 목록을 만든다. 내부 보고서는 비용 가안·제작 지시·조사 출처를 포함한다. 고객용 화면은 광고 기획·장면·확인 사항과 다음 제작 과정을 보여준다.

선택 이미지: 커피 v3(종이컵 제거·탄산처럼 보이는 거품 보완), 향수, 재킷, 런웨이 전신 비율 수정본 v1. 2026-10-12 사용자가 런웨이 수정본의 공개 교체를 승인했다. 얼굴·의상·6컷 구성을 유지하면서 전신 4컷의 머리·다리 비율을 다듬은 수정본이며, 손은 각 컷의 자세에 따라 주머니 안팎에 둔다. 이전 PNG와 공개 WebP는 보존한다.

런웨이 수정 PNG는 내용 수정 없이 무손실 WebP로 변환했다. 디코딩한 픽셀과 크기(1572×1001)가 원본과 동일하다. 공개 보드 네 장은 합계 1,566,642바이트(약 1.57MB)이며, 런웨이는 새 파일명 `04-runway-comparison-proportion-v1.webp`를 사용한다. 공개 반영 결과는 검증 기록에서 확인한다.

PULSE의 **제작 설계 → 모델·스타일 고르기 → 광고 기획·콘티 보기**에서 해당 모델 기획을 새 탭으로 연다. 기획을 읽는 것만으로 모델·메모·승인은 바뀌지 않는다. 원하는 선택은 원래 프로젝트에서 제작 설계를 저장한다.

## 검증 기록

### 전신 기준 사진 · 후속 수정

백업에서 일곱 모델의 전신 원본을 복원해 확인했다. 최초 머리 축소 보정 5장은 얼굴이 지나치게 작고 목이 길어지는 문제가 있어 채택하지 않았으며, 공개하지 않았다. 이안·태준은 원본 얼굴과 두상 크기를 기준으로 다시 제작했고 사용자가 “좋아. 이제야 좀 괜챃네”라고 채택했다. 유나·하린·서진·지유·유호는 자연스러운 기존 원본을 유지한다.

채택 이미지와 원본 유지본은 `assets/fullbody/`에 있다. 이안·태준의 생성 PNG도 같은 폴더에 보존했다. [생성 지시와 선택 기록](fullbody-edit-prompts.json)에 내장 image_gen 사용, 거절본과 채택본의 구분, SHA-256과 원본 위치를 남겼다. 공개용 WebP 7장은 크기와 디코딩 RGB가 선택 원본과 같도록 무손실 변환했다. 모델별 전신 참고 카드·확대 링크를 로컬 PULSE에 연결했다.

이 전신 사진 후속분은 아직 운영 배포 전이다. 같은 서버의 HA 복구·복귀 시험이 진행 중이므로 기존 라이브 런웨이 콘티를 유지하며, 배포 전 최신 owner·양쪽 노드·진행 작업 종료를 다시 확인한다. 후보와 확인 자료는 `.tmp/pulse-model-proportions-20261012/`에 있다.

배포 후보와 검증 자료: [PULSE 기획실 검증](../../_ops/qa/pulse-production-library-20261012/README.md). 로컬 화면·배포·공개 확인은 각각 별도로 기록한다. 갤럭시 실기기 설치·푸시 확인은 이전 요청에서 사용자가 나중으로 미룬 항목이며, 이번 화면 크기 검사로 대신하지 않는다.
