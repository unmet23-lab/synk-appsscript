# SHIFT 과정 공개·자료·후속 강의

> 2026-09-10 · [마케팅 정본](../마케팅_정본.md)과 [SHIFT](SHIFT.md)의 실행 상세. 유호가 AI와 실제 회사를 짓는 이야기를 중심으로, 그 과정의 방법·자료·적용 지원·강의를 연결한다. 아래 소재와 연결 방식은 편집 판단이며 실제 게시·수요·매출 검증과 구분한다.

## 현재 방향과 실행 범위

**출발점은 유호가 AI로 회사를 만들고 기업을 발전시키는 실제 과정과 그로써 제공하는 가치다.** 시도·실패·수정·선택·결과를 공개하며 방법과 꿀팁을 나눈다. 이 이야기와 제공 가치로 인지도·신뢰를 쌓고 유호의 AI 강사 활동과 교육·지원으로 이어가는 것이 성장 방향이다. [SHIFT의 뿌리와 마케팅 적용](SHIFT.md)에 따라 기존 명품 브랜딩 기법을 사용한다. 일반 강의 목차를 먼저 정해 실제 작업을 사례로 끼워 넣지 않는다. 홍보 릴스도 유지하며, 관련 자료나 지원은 실제 사건을 더 써보고 싶은 사람에게 연결한다.

자료·온라인 수업·검색 글·클리닉·후속 소통·협업 제안은 필요한 때 준비·적용할 수 있다. 제작 속도·브랜드 자산 준비량을 형식의 일괄 배제 사유로 삼지 않는다. 네이버·카카오·Pinterest는 기존 개설 선택과 [게시 분담](채널과_발행.md)을 따른다. 이 방향으로 가격·개강·지원 기간·협업·광고 지출을 새로 확정하지 않는다. 제작 PULSE / 계약·청구·고객 관계 SHIFT를 유지하며, 실제 제작·게시 상태는 [실행 적용](../홍보물/마케팅실행_20260909/실행적용.md)에서 확인한다.

## 2. 본편과 후속 도움의 관계

실제 사건을 본편으로 만들고 그 사건에서 필요한 파생과 도움을 고른다. 아래 항목을 매번 모두 만들거나 순서대로 거쳐야 하는 것은 아니다. 효과는 아직 가설이며 조회수 상승이나 매출을 보장하지 않는다.

| 자리 | 맡는 일 | 연결할 근거 |
|---|---|---|
| **실제 회사 이야기 — 중심** | 유호가 무엇을 만들고 AI와 어떻게 진행했으며 왜 선택을 바꿨는지 보여줌 | 실제 작업 기록·입력·결과·수정·현재 실물 |
| **짧은 이용법·꿀팁 — 파생** | 그 과정에서 배운 한 가지를 다른 상황에서도 써볼 수 있게 설명 | 본편에서 실제로 사용한 방법과 적용 조건 |
| **관련 파일·검색 글** | 작업을 더 따라 해보거나 막힌 부분을 찾아볼 자료 제공 | 공개 가능한 원본·설명용 예시·사용법·확인한 범위 |
| **후속 이야기·개정판** | 이후 실제 사용·수정·새 질문이 생긴 경과를 이어 보여줌 | 새로 관찰한 일과 기존 판단이 바뀐 이유 |
| **좁은 적용 지원·실습** | 다른 사람이 자기 상황에 옮길 때 반복해서 막히는 문제를 도움 | 실제 요청·사용처와 지금 책임질 수 있는 범위 |
| **체계적 1인 기업 강의** | 반복해서 설명하고 도울 수 있는 방법을 순서 있게 묶음 | 자체 수행과 타인의 적용 경험, 명확한 수강 대상·실습·지원 범위 |

자료실은 다른 플랫폼 계정이 아니라 **기존 웹 안의 목적별 도착 페이지**를 우선 추천한다. 게시물에서 약속한 파일로 바로 도착하고, 검색·짧은 영상·수업에서 같은 원본을 참조하게 한다. 소개 홈으로만 돌려보내거나 모든 자료를 하나의 ZIP에 숨기지 않는다.

## 3. 새 채널은 이 역할로 추가한다

| 채널 | 추천 정도·대상 | 구체적인 내용 | 구분할 조건 |
|---|---|---|---|
| **네이버 블로그** | 한국어권 SHIFT 타겟을 택할 경우 우선 추천 | 실제 작업에서 생긴 질문·시도·수정과 따라 쓸 방법을 읽는 글. 관련 원본 자료는 웹에 연결 | 09-09 사용자 개설 선택. 실제 개설 기록·현재 상태는 실행지 확인. 이미지 카드만 붙이지 않는다. 검색 노출·문의 증가 보장은 없음 |
| **카카오톡 채널** | 한국어권 성인에게 강의·브랜딩을 안내할 때 추천 | ‘배우고 싶음 / 제작 의뢰 / 기관 강의’ 입구와 실제 제공 범위에 관한 문의 | 자료 다운로드에 채널 추가를 강요하지 않음. 기존 Telegram 연락과 역할을 구분하고 현재 안내·응답 조건을 확인 |
| **Pinterest** | SHIFT 시각 브랜딩·PULSE 작품 탐색의 별도 시험 후보 | 완성 브랜드 지면·재질·편집 예시를 용도별 보드로, 관련 실습/작품 페이지에 연결 | 한국어 강의 구매자와 일치하는지는 미확인. 시각 발견에 맞는 콘텐츠만 시험하고 실적·유입을 따로 확인 |
| **기존 YouTube 재생목록·라이브** | 같은 회사 사건의 경과를 따라보는 자리 | 실제 작업의 본편과 후속, 필요한 때 작업 시연·질문에 대한 설명 | 현재 yuhobuilds의 이야기를 잇고 강의는 목적이 확인된 별도 안내로 구분 |
| **기존 Substack 창업 갈래** | 새 발행물보다 목적 명확화 우선 | 공개 뒤의 실제 경과·선택 이유·자료 개정·적용 질문에 대한 후속 편지 | LAB 교육 구독자를 자동 전환하지 않음. 수신 목적·갈래·해지 안내와 실제 설정 확인 |

네이버는 중요한 정보를 본문 텍스트로 제공하고 주제·경험·출처를 일관되게 유지하라고 안내한다. 이는 웹 콘텐츠 일반 지침이지 블로그 개설 시 상위 노출을 보장하는 규칙이 아니다. [네이버 원문](https://searchadvisor.naver.com/guide/content-basic), [Google의 사람 중심 콘텐츠 안내](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).

카카오 공식 가이드는 이용자가 먼저 시작하는 1:1 채팅과 채팅 가능 시간 설정을 설명한다. 문의 창구 제안은 이 기능을 활용하자는 것이며, 실제 계정 지원·메시지 과금·광고성 안내 조건을 확인하기 전 자동 발송이나 즉시 응답을 약속하지 않는다. [카카오 공식 가이드](https://kakaobusiness.gitbook.io/main/channel/run/chat).

Pinterest는 이미지·영상 Pin에서 사이트로 연결할 수 있다고 설명한다. 우리의 시각 자료와 맞을 수 있다는 **전략적 추론**이며 한국의 강의 수요를 입증한 것은 아니다. [Pinterest 공식 안내](https://business.pinterest.com/how-to-make-pins/).

오프라인 LAB은 실제 고객을 만나는 장소·권한·운영 정보가 준비되었을 때 지도 검색 프로필도 검토할 만하다. 반대로 온라인 전용 SHIFT를 주소만으로 지도 업체에 등록하자는 제안은 하지 않는다. Google은 온라인 전용 사업을 Business Profile 비대상으로 명시한다. [자격 조건](https://support.google.com/business/answer/13763036?hl=en).

## 4. 독자와 소재는 실제 회사 사건에서 구체화한다

AI로 자기 일·사업을 만들고 싶은 사람이 실제 과정을 보고 무엇을 얻는지 확인한다. 한국어권 초기 1인 사업자·강사·디자이너 등은 독자 가설이며, 나이·매출·업종만으로 요구를 단정하지 않는다. 아래는 현재 작업 기록을 확인해 고를 소재 예시다. 제목 후보를 실제 사건이나 사용자 반응의 증거로 쓰지 않는다.

| 실제 작업에서 고를 사건 | 본편에서 보여줄 것 | 그 과정에서 꺼낼 방법 |
|---|---|---|
| 까몽 3D를 시험하고 현 후보를 채택하지 않은 일 | 원래 하려던 동작, AI 결과, 실제 비교와 비채택 이유 | 캐릭터를 바꿀 때 형태·동작·적용 상태를 나눠 확인하는 법 |
| 릴 45편 계획을 도움 제공형 10편으로 줄인 일 | 기존 기획, 사용자 교정, 실제로 추가한 표현·자료, 남은 확인 | 제작량보다 한 편에서 실제로 제공하는 것을 확인하는 법 |
| 회사 소개서·브랜드 자산을 AI와 만드는 일 | 보존된 요청·첫 결과·고친 부분·사용처에서 본 결과 | 도구 입력과 결과 선택에 실제로 영향을 준 조건 |
| 앱의 과제 제출과 교정 답장을 연결하는 일 | 현재 기록으로 확인한 흐름, 막힌 곳과 수정, 로컬·실사용의 차이 | 생성된 화면과 실제로 끝까지 돌아가는 동작을 구별하는 법 |

어떤 사건을 다루든 현재 원본과 확인 결과를 다시 읽는다. 자체 시연·로컬 시험·실제 사용자 도달·고객 효과를 나누며, 흥미로운 장면을 만들려고 문제나 고객 반응을 꾸미지 않는다.

## 5. 공개의 깊이와 편집

공개 가능한 실제 프롬프트(AI에 입력한 요청)·도구 선택·결과·실패·수정 전후와 사람의 판단을 보여준다. 판단을 이해하는 데 필요한 일반 작업 화면과 코드도 사용할 수 있다. 전체 대화나 저장소를 그대로 공개할 의무는 없다.

긴 대기·중복·곁가지는 편집해도 된다. 실패를 성공처럼 잇거나 AI가 한 일과 사람이 고친 일을 바꾸지 않는다. 원래 기록·설명용 재현·가상 적용 예시를 구분한다. 아직 해결되지 않은 문제도 현재 상태와 다음에 확인할 것을 밝히며 이야기로 다룰 수 있다.

개인·학생 식별정보, 비밀번호·토큰, 비공개 고객 자료, 공개 권한 없는 코드·자료는 제외하거나 공개용 재현으로 바꾼다. 화면에 잠깐 지나가는 정보와 파일의 내용도 확인한다. 이 보호 범위를 일반적인 AI 이용 과정 전체의 비공개로 확대하지 않는다.

Loom·승인 폰트·스티치 로고·소품은 실제 이야기와 작업 화면을 읽히게 돕는다. 명품 기준의 선택·고유한 표현·완결성·사용 뒤 책임을 적용하되 전편을 같은 구도로 만들지 않는다. 별도 자료를 제공할 때는 그 용도에 맞는 예시·원본·사용법·이용 조건을 갖춘다. 양모 이미지는 연출 자산이며 실제 손바느질 작업처럼 소개하지 않는다.

최근 [스티치 적용 기록](../홍보물/계정별콘텐츠_20260909/_개선/스티치_적용기록.md)과 [명품 기준](../명품_기준_v1.md)을 이어 쓴다. 새 로고 스타일·팔레트·마스코트 정본을 이번 전략으로 다시 만들지 않는다.

## 6. 관련 자료와 다음 행동 — 필요한 사람에게 연결한다

CTA는 콘텐츠 끝의 **다음 행동 안내**다. 한 편의 경과와 배운 점은 본편에서 읽히게 한다. 다음 실제 이야기, 방법을 더 설명한 글, 관련 파일, 질문받는 자리는 해당 사건에 맞을 때 연결한다. 모든 편을 강의 신청이나 자료 작성으로 닫지 않는다. 아래 여섯 자료는 기존에 준비한 자산을 필요한 상황에 재사용하는 목록이며 주력 연재의 목차가 아니다.

| 실제 이야기와 맞는 상황 | 재사용할 자료 | 연결할 내용 |
|---|---|---|
| 회사 소개를 고친 과정 | **1인 기업 소개문 작업지** | 같은 판단을 자기 소개에 옮기는 예시·원본 |
| 실제 서비스의 범위를 정한 과정 | **첫 서비스 한 장** | 고객이 받는 결과·포함/제외를 정리하는 법 |
| 콘텐츠의 목적과 제공물을 고친 과정 | **상품 하나, 콘텐츠 지도** | 자기 고객의 질문과 제공물을 연결하는 법 |
| 공개 가능한 실제 문의·조건 변경 | **문의 답변 세 줄** | 사용처·원하는 결과·필요 시점을 확인하는 예시 |
| AI에 업무를 맡기고 결과를 검토한 과정 | **혼자 쓰는 업무 지도** | 입력·결과·사람이 확인할 곳을 나누는 법 |
| 브랜드 지면·화면을 실제 크기로 확인한 과정 | **내 브랜드 접점 점검표** | 첫 읽힘·필수 정보·사용처를 확인하는 법 |

핵심 팁을 전부 가입 뒤로 숨기지 않는다. 자료 링크와 전달 기능을 실제 확인하기 전 ‘드릴게요’·‘댓글 달면 자동 발송’이라고 하지 않는다. 공개 댓글의 전화번호·이메일·고객 자료·매출 화면 수집, 친구 태그·불안·가짜 마감은 쓰지 않는다. 자발적인 적용 질문은 받을 수 있으며 자료 열람 조건과 분리한다.

기본 자료는 댓글·팔로우·이메일 제출 없이 열고, 후속 구독은 별도 선택으로 둔다.

**플랫폼 경로:** YouTube Shorts의 관련 영상은 같은 채널의 영상에 연결하는 기능이다. synkbrief Shorts에서 yuhobuilds 본편으로 직접 설정할 수 있다고 안내하지 않는다. Shorts 설명·댓글 URL은 클릭 링크로 쓰지 않고 실제 프로필·지원되는 관련 영상으로 안내한다. 엔드스크린의 외부 사이트 링크도 계정 자격 확인 없이 기본값으로 삼지 않는다. 상세 조건과 공식 출처는 [기능·하드게이트 검토](../_ops/마케팅확장_20260909/검토.md)에 있다.

## 7. 실제 회사의 사건으로 편성한다

먼저 현재 회사에서 끝내려는 일과 실제로 달라진 사건을 고른다. 그 사건에 필요한 본편·짧은 이야기·방법 설명·후속을 정한다. 회사 일이 진행되는 맥락을 이어보게 하며, 콘텐츠를 채우려고 새 사업이나 실험을 늘리지 않는다.

발행 빈도·분량·본편과 파생의 비중은 실제 사건·기록·시청 이유에 맞춰 잡는다. 고정 수업 비율이나 4주 강의 목차를 현재의 기본값으로 사용하지 않으며, 새 숫자로 대신 고정하지 않는다. 전용 짧은 콘텐츠도 가능하지만 사건과 관계없는 일반 팁이 본편의 이야기를 밀어내지 않게 한다.

기존 컬렉션·실습·검색 글은 관련된 사건과 사용처가 있을 때 재사용한다. 가상 실습을 유호가 실제로 겪은 고객 사건으로 소개하지 않고, 지난 제작물의 원본·당시 목적·현재 사용 범위를 확인한다. 이 방향의 문서 반영을 기존 영상·게시물의 재제작 완료로 세지 않는다.

같은 목표의 진행을 본 사람이 무엇을 궁금해하고 어디에 적용했는지 보며 후속을 고른다. 시청·구독은 발견과 지속 관심의 참고이고, 타인의 사용·맞는 문의·유료 계약·인수 결과는 각각 다른 증거다.

## 9. 적용 지원과 강의로 이어가는 기준

공개한 방법을 다른 사람이 적용하다 반복해서 막히는 곳, 구체적으로 도움을 요청하는 일을 먼저 본다. 지금 책임질 수 있는 범위를 정해 작은 실습·피드백·제작 지원으로 돕고, 반복해서 설명하고 지원할 수 있는 내용을 체계적인 1인 기업 강의로 묶는다. 고객이나 반복 요청이 없는데 있는 것처럼 편성하지 않는다.

회사의 전체 성공을 강의 시작 조건으로 두지 않는다. 특정 작업에서 실제로 보여주고 도울 수 있는 범위가 있으면 해당 주제의 강의·지원은 시작할 수 있다. 자기 회사의 시도와 타인의 적용 결과를 구분하며, 아직 검증하지 않은 수익·시간 절감·사업 성공을 약속하지 않는다. 무료에서도 사건의 답과 유용한 방법은 완결하고, 유료에서는 순서 있는 적용·피드백·실제 책임 범위를 제공한다. 가격·일정·정원·지원 기간은 상품을 준비할 때 정한다.

필요한 주제와 상대가 확인되면 공동 실습회·업종별 자료·공개 가능한 성인 작업물의 전후 설명도 검토할 수 있다. 실제 협업·권리·공개 동의를 확인하며 비공개 고객 자료를 견본으로 전환하지 않는다.

유료 광고나 재방문 광고는 성인 대상·실제 과정·동의·예산이 준비되면 별도 후보로 검토할 수 있다. 이번 제안은 기존 LAB 광고비를 SHIFT로 옮기거나 광고 지출·추적 도구 설치를 승인하지 않는다.

좋은 방향인지는 유호가 어떤 일을 왜 바꿨는지 이해하는가, 다음 경과를 찾는 이유가 있는가, 방법을 실제로 써보는가, 문의의 대상·문제·원하는 결과가 맞는가로 본다. 다운로드·구독·조회는 고객·숙련·매출과 동일하지 않다. **실제 회사의 진전, 이야기의 관심, 타인의 적용과 사업 결과**를 따로 확인한다.
