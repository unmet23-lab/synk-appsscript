# 첫 편 — 도담중공업 영어 판 (2026-11-17)

PULSE 영어 시험의 첫 편이다. 유호님이 11-17 18시에 「권고대로」로 고르셨다([결정](../../../_ops/결정.md) 11-17). 11-19에 보여 드리고, 좋다고 하시면 11-20(금) 아침 8시(한국 시각)에 올린다.

한국어 판(「이 아이를 보냅니다」, 61초 16:9, 유호님 「이대로 확정」)의 화면을 그대로 쓴다. **다시 구운 영상 판은 없고 크레딧도 쓰지 않았다.** 바꾼 것은 넷이다.

1. **영어 내레이션.** 한국어 판과 같은 아이작 목소리로 원고 전체를 한 번에 굽고, 문장 사이 무음에서 잘라 한국어 판과 같은 자리에 놓았다(만족 사례 S49의 방법). 마지막 줄만 0.5초 당겼다(55.58초). 영어 줄이 2.28초라, 57.97초 마지막 화음 전에 끝나야 곡을 화음 앞에서 다시 올릴 수 있다.
2. **영어 자막.** 한국어 판과 같은 결(명조 44px 한 줄, 마침표와 쉼표 없음, 흐림이 풀리며 올라옴)이다. 말과 자막이 같은 말이라 아래 작은 영문 줄은 뺐다.
3. **영문으로 그린 끝 로고.** 한국어 판 로고와 같은 기하 획(고른 두께, 평평한 획 끝, 35°로 자른 날개 끝)으로 DODAM을 그렸다. 글꼴로 치지 않았다. 표식(두 토막 고리와 점)과 움직임은 한국어 판 그대로다. 시안은 둘이다. A는 DODAM 한 줄이고, B는 그 아래 HEAVY INDUSTRIES 작은 줄이 붙는다. 기본은 B다(이름만으로는 무슨 회사인지 모른다).
4. **SYNK PULSE 끝 화면(3.25초).** 도담 로고가 어두워지는 자리에서 이어 뜬다. 「Every person in this film is AI」, 「A spec film for a fictional brand」, SYNK PULSE 로고(승인 파일 그대로), synk.im/en/pulse가 차례로 올라온다. AI 표시를 구석 딱지로 두지 않고 끝 화면 문구로 두었다.

## 11-17 결과

- 최종본: git 밖 `synk-vendor/pulse-portfolio12-20261024/최종/p10_en/도담_영어_B_아이작.mp4`(64.5초, 1920×1080, 24fps). 폰용 `_폰.mp4`와 0.5초 모아보기 `_반초.jpg`가 옆에 있다.
- 소리: 음량 −14 LUFS, 실제 봉우리 −1.4 dBFS(음량마감 통과). 목소리 띠에서 목소리가 곡보다 +9.8~+10.9 dB 위에 선다(한국어 판이 맞춘 「+10 dB 안팎」).
  영어 첫 판은 다섯 줄이 +7.7~+8.6 dB라 그 줄만 1~2.5 dB 올렸다(영어판.py LIFT).
- 끝 화면 소리: 첫 판은 끝 화면 3.25초가 방 소리뿐이라 최종본검사 「끝소리」에 걸렸다. 필름을 맺은 마지막 화음(57.97초)을 잔향과 함께 한 번 더, SYNK PULSE 로고가 올라오는 61.67초에 놓았다. 새 소리는 들이지 않았다.
- 끝 화면 글자: 첫 판(문구 46 · 작은 줄 20px)은 폰에서 작은 줄이 4px 남짓이라 62 · 26px로 키웠다. 두 판은 [시안](시안/)에 있다.
- 검사: 컷연속성검사 `--영상` 걸림 0(확인 다섯 — 소품 표, 점 시트, 고요 · 지도 칸, 34번 얼굴 옆빛 0.14). 끝판검사 「납작한 판 없음」. 최종본검사는 끝소리 · 조용 · 멈춤 걸림 0이다.
  최종본검사 전체에서는 한국어 판 화면에서 그대로 온 두 가지가 뜬다. 하나는 짧은 사람 컷 15개의 「굳음」(사람 움직임 0.03~0.10, 문턱 0.12)이다. 다른 하나는 35.58초(22번 시험대 틀 → 23번 시험동 입구)의 「같은판」이다. 화면은 유호님이 「이대로 확정」하신 판이라 다시 굽지 않았고, 마감 관문에 함께 넘긴다.
- 컷표: 한국어 판은 컷표 체계 전에 만든 편이라 [컷표_만들기.py](컷표_만들기.py)로 관문용 컷표를 지었다. 기준 그림(ref)은 한국어 판 화면에서 뽑았다.

## 확인하지 못한 것

- 소리를 켜고 처음부터 끝까지 귀로 듣지는 않았다. 소리는 받아쓰기 시각, 줄마다의 목소리 대 곡 크기, 음량, 끝 조용 구간으로만 쟀다.
- 끝 로고 시안 A(DODAM 한 줄)로는 전체 판을 굽지 않았다. 끝 장면 낱장만 [시안](시안/)에 있다.
