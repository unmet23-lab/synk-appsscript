## 상태

| 상태 | 뜻 | 누가 바꾸나 |
|---|---|---|
| 순위 n | 월요일 수요 스캔의 순위 관문(새 Fable)을 지나 유호님께 보낸 기획 | 월요일 작업 |
| 고름 | 유호님이 고르신 기획(화요일 정오까지 답이 없으면 순위 1번만) | 월요일 세션 · 07시 작업 |
| 제작 중 | 07시 작업이 편 폴더를 만들고 만드는 중 | 07시 작업 |
| 완성 | 최종본과 게시 묶음이 다 됐고 유호님 확인을 기다림 | 07시 작업 |
| 게시 | 올라감(주소는 편 폴더 `게시/게시결과.json`) | 게시 세션 |
| 예비 | 근거가 약하거나 조건이 남은 후보 — 고르는 목록에 올리지 않는다 | 월요일 작업 |
| 버림 | 만들지 않기로 한 것(까닭을 메모에) | 누구나 |

## 쓰는 법

07시 작업의 처음부터 끝까지는 [제작 절차](제작절차.md)에 있다.

- **07시 작업**은 자기 브랜드 장부에서 표 순서대로 「고름」이고 편 폴더가 빈 첫 기획을 하나 고른다(LAB은 영어 · 몽골 각각 하나까지). 고르면 상태를 「제작 중」, 편 폴더 칸을 채우고, 그 폴더의 `기획.md`를 한 장 기획 아홉 칸([수요 조사](../시청자수요조사_20261022.md) 6-2)으로 시작한다. 이 장부의 줄은 요약이고, 근거 원문은 수요 조사 원자료다.
- **2주 시험(10-26 ~ 11-07)** 편은 준비.json에 `"시험": {"이름": "2주 시험 10-26", "갈래": "<이 장부의 갈래 칸>"}`을 단다. 슬롯은 같은 계정끼리 이틀 넘게 띄워 계정마다 주 2~3편으로 놓고, 72시간 숫자가 11-07 전에 나오게 11-04까지 올린다.
- 같은 형식은 숫자로 이기기 전에는 계정마다 주 1편, 같은 콩트 구조는 잇달아 내지 않는다.
- 장부를 고친 세션은 그 브랜드 파일만 `node tools/바로올리기.js docs/마케팅/기획장부/<브랜드>.md -m "…" --실행`으로 올린다(공용 작업본이면 `--조각`으로 내 줄만).
