## 고른 여섯 편

- 올리는 순서는 SHIFT 3 → 2 → 1, PULSE 4 → 5 → 6이다. 안내 글(3·6)이 앞 글 주소를 링크로 건다.
- 지킬 것: 「준비 중인 상품 · 의뢰마다 견적」(SHIFT 4-5), PULSE 글에 제작 도구 이름 없음(「AI로 만든 모델」 고지는 둠), 화성 CF는 출품작으로만 적고 시가 맡긴 일처럼 쓰지 않는다. 로고가 든 장면은 정지컷으로 쓰지 않는다(공공누리 제4유형 — 영상은 유튜브 공개본을 그대로 건다).
