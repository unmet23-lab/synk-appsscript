# SYNK PULSE · 45초 앱 데모 영상 구성 시안

> 2026-11-13 수정. 사용자 「이 구성을 전부 담으라는 게 아니야」를 반영한 현재안. 목표는 30~60초 안에서 **실제 앱 조작으로 준비·수정·공유의 편리함을 보여주는 것**이다. 이번 기획은 사용자가 허용한 GPT 직접 작성 범위다. 현재는 구성 시안이며 영상 파일은 아직 제작하지 않았다.

**한 줄 콘셉트: 준비는 간단하게. 완성까지 눈앞에서.**

좋은 광고의 한 장면으로 시선을 잡고, 화면이 빠져나오면 그 광고를 함께 만들고 있는 PULSE 앱이다. 고객의 선택 → 화면의 반응 → 제작진과의 소통 → 완성본이 하나의 흐름으로 이어진다. 45초 중 앱 조작에 약 37초를 쓴다.

## 45초 구성

| 시간 | 실제 화면과 조작 | 짧은 카피 | 전달할 장점 |
|---|---|---|---|
| **0–4초** | 홀리데이 광고에서 얼음 구슬이 깨지고 제품이 드러나는 강한 장면. 2초째 화면이 빠져나오며 같은 장면이 PULSE 플레이어 안에 놓인다. | **이 광고가 만들어지는 곳.** | 첫 화면에서 결과물의 퀄리티와 앱을 연결한다. |
| **4–11초** | 제품 자료가 들어간 의뢰서 → 사용처 선택 → 세로·가로 미리보기 전환. 선택한 답이 의뢰서에 모이는 모습을 빠르게 붙인다. | **준비는 간단하게.** | 자료와 요구사항을 한곳에서 정리해 사전 준비를 줄인다. |
| **11–18초** | 「서리꽃 / 얼음 구슬」 방향안을 바꿔 보고 → 장면 이미지 화면으로 전환 → 아래 컷 03·05·08을 선택할 때마다 큰 그림이 바뀐다. | **보고, 고르면 됩니다.** | 길게 설명하기 어려운 광고 방향과 장면을 눈으로 결정한다. |
| **18–27초** | 선택한 컷의 「고칠 곳이 있어요」를 누른다. 「제품이 조금 더 크게 보이면 좋겠어요」 입력 → 영상 확인 화면에서 0:08을 지정해 의견을 남기는 동작으로 이어진다. | **바꾸고 싶은 곳에, 바로 의견을.** | 컷과 영상 시점에 의견이 붙어 수정할 곳이 명확해진다. |
| **27–34초** | 제작팀이 올린 작업 소식과 작업 중 이미지 → 고객 화면의 일지에 같은 소식이 나타나는 연결. 답변과 새 시안이 같은 기록에 쌓인다. | **진행 상황도, 실시간으로 함께.** | 문의·작업 소식·시안을 같은 앱에서 공유한다. 실제 전송 촬영 조건은 아래에 적었다. |
| **34–41초** | 「나란히 보기」 클릭 → 1차·2차 시안과 「달라진 곳」 구간을 함께 확인 → 선택한 완성 장면이 화면을 채운다. | **달라진 장면까지 한눈에.** | 수정 내용을 확인하고 최종 결과를 고른다. |
| **41–45초** | 첫 장면에서 이어지는 제품의 가장 좋은 마감 컷 위에 승인된 PULSE 로고. 42초부터 로고를 3초 유지한다. | **준비는 간단하게. 완성까지 눈앞에서.** / **SYNK PULSE** | 크몽용 행동 안내는 「싱크펄스에 문의하세요」 한 줄. |

## 움직임과 소리

- **버튼을 누르면 무엇이 바뀌는지**를 한 번에 보여준다. 클릭 직전 약 0.3초, 변화 뒤 약 0.8~1.2초를 확보한다. 전환은 빠르게 하되 선택 결과를 읽을 시간을 남긴다.
- 전체 앱을 계속 작게 보여주지 않는다. 선택할 버튼 → 바뀌는 큰 이미지 → 의견 칸 순으로 시선이 이동하도록 확대하고 이동한다. 원래 앱 배치와 조작 관계를 유지한다.
- 11–18초는 선택하는 재미, 18–34초는 수정과 공유의 편리함, 34–41초는 비교 화면의 시원한 펼침이 각각 한 번씩 눈에 남게 한다. 같은 크기의 캡처를 슬라이드처럼 교체하지 않는다.
- 리듬감 있는 한 곡에 클릭·입력·전환 소리를 맞춘다. 첫 구슬 파열 소리와 마지막 로고의 짧은 한 음을 살린다. 음악·음성은 아직 선택하거나 생성하지 않았다.
- 무음으로도 이해되게 한 화면에는 카피 한 문장만 둔다. 실제 앱 글자는 캡처 원본을 사용한다. 강조 카피는 영상 위에서 별도 레터링 시안을 고른다.
- **짧은 내레이션을 넣는 경우:** “원하는 광고, 눈으로 보며 만드세요. 자료를 모으고, 방향을 고르고. 바꾸고 싶은 곳엔 바로 의견을. 진행 상황도, 달라진 장면도 한눈에. 싱크펄스.” 계속 말하지 않고 조작을 보는 구간에는 여백을 둔다.

## 실제 화면 확인과 촬영 조건

11월 13일 [현재 예시 프로젝트](https://workspace.synk.im/pulse-app/?demo=film)를 직접 조작했다. 데모는 가상 브랜드를 사용하며 실제 요청이나 메시지를 서버로 보내지 않는다. 화면에 있는 이름·가격·일정은 예시이고, 이번 영상의 확정 판매 조건으로 강조하지 않는다.

| 기능 | 확인한 범위 | 촬영할 때 지킬 것 |
|---|---|---|
| 준비 내용과 즉시 미리보기 | 의뢰서에서 제품명·업종을 선택하면 요약에 반영된다. 「유튜브·웹사이트」를 고르자 미리보기가 16:9로 바뀌었다. 자료 업로드 구조는 `request-flow.mjs`에 있다. | 같은 예시 제품을 이어 쓴다. 비율 미리보기 전환을 완성 영상의 즉시 재생성으로 표현하지 않는다. |
| 방향안 전환 | 「서리꽃」에서 「얼음 구슬」로 바꾸면 선택 표시·설명·주요 이미지 구성이 바뀐다. | 2개 안을 보여주고 하나를 고르는 행동에 집중한다. |
| 장면별 의견 | 5번 컷을 열고 「고칠 곳이 있어요」를 눌러 해당 컷의 의견 칸에 입력했다. | 커서와 선택한 컷이 함께 보이게 찍는다. 수정 요청 뒤 곧바로 영상이 생성되는 연출은 쓰지 않는다. |
| 영상 의견과 시안 비교 | 영상의 특정 시점 의견, 1차·2차 선택, 「나란히 보기」, 「달라진 곳 0:06~0:13」을 확인했다. | 데모 두 판의 실제 재생 차이는 아직 전 구간 대조하지 않았다. 실제 수정 전후가 보이는 구간을 확인한 뒤 사용한다. |
| 실시간 소통과 작업 소식 | 현재 배포된 `live.mjs`에서 EventSource 갱신을, `film-views.mjs`에서 작업 중 이미지 표시를 확인했다. 예시 화면에서는 담당자와 나눈 말·새 시안 이력을 직접 확인했다. | 공개 데모 데이터에는 작업 소식 예시가 없다. **27–34초의 새 소식 도착은 별도 테스트 프로젝트에서 제작팀 등록 → 고객 화면 갱신을 실제로 확인한 뒤 촬영한다.** 현재 단계에서는 실시간 도착을 녹화했다고 말하지 않는다. |

여기서 **실시간 수정**은 고객이 미리보기의 선택을 바로 바꾸고, 원하는 수정 의견을 해당 장면에 남기며, 제작진이 올린 새 소식·시안을 함께 확인하는 과정이다. 제작 중 화면 공유는 게시한 작업 이미지와 소식을 뜻한다. AI 영상이 입력 즉시 다시 생성되거나 제작자 화면 전체가 계속 생중계된다고 표현하지 않는다.

## 앞선 안과 기존 영상

110초 철학·경력 설명안은 이번 45초 앱 데모 구성으로 대체한다. 엔터 경력 10년, 광고 철학, 서울로 선정 이력은 이번 영상의 별도 설명 구간으로 넣지 않는다. 좋은 작품과 고객이 직접 조작하는 과정이 중심이다.

9월 29일에 20초 서비스 소개영상을 만들어 크몽 초안에 붙인 기록은 있다([당시 검증](../크몽_등록준비_20260929/ads_intro_video/QA.md) · [콘티](../크몽_등록준비_20260929/ads_intro_video/STORYBOARD.md)). 당시 지정한 MP4는 원래 로컬 위치에서 확인되지 않았다. 이번 구성은 현재 앱의 조작·수정·공유 기능을 보여주는 새 안이다.
