언어: 간체 · 문법 채점 gemini-4-argon(high) · 직역 역번역 gemini-3.8-flash(high) · 구독 문(agy 로그인 계정)

■ 문법·자연스러움 (원문 안 보여 주고 채점)
  판정: 정상 — 제시된 6개 문장 모두 간체 중국어의 문법과 맞춤법에 맞으며, 쇼츠 화면 자막 및 설명 문안으로 자연스럽습니다.

■ 한국어 원문
  1. 이런 말투는 친구에게만 보내요 (첫 카드 까닭)
  2. 「교수님, 안녕~ 내일 수업 몇 시?」 (첫 카드 — 반말 문자의 뜻)
  3. 내일 수업 몇 시예요? → 10시예요 (답장 카드 — 질문과 교수님 답의 뜻)
  4. [게시글 바뀐 줄] 「안녕하세요, 교수님. ○○입니다.」 뜻은 「교수님, 안녕하세요. 저는 ○○예요.」
  5. [게시글 바뀐 줄] ✅ 「안녕하세요, 교수님. 바트입니다. 내일 수업은 몇 시예요?」(교수님, 안녕하세요. 저는 바트예요. 내일 수업은 몇 시예요?)
  6. [게시글 바뀐 줄] 교수님이 답장하면 「감사합니다」(고맙습니다)라고 한마디 보내는 것을 잊지 마세요.

■ 직역 역번역 (다듬기 금지 — 원문과 뜻을 견준다)
  1. 이러한 말하는 방식은 단지 친구에게 보내는 것에만 적합하다
  2. “교수, 안녕~ 내일의 수업 몇 시?”
  3. 내일의 수업 몇 시? → 10시.
  4. “안녕하세요, 교수님. ○○입니다.”（annyeonghaseyo, gyosunim. ○○imnida）뜻은 “교수님, 안녕하세요. 저는 ○○입니다.”이다.
  5. ✅ “안녕하세요, 교수님. 바트입니다. 내일 수업은 몇 시예요?”（교수님, 안녕하세요. 저는 바트입니다. 내일의 수업 몇 시?）
  6. 교수가 회신한 후, “감사합니다”（gamsahamnida，감사드립니다） 한 마디를 회신하는 것을 잊지 마라.

결과: 거름망 통과(확정 아님 — 역번역 뜻 대조는 따로)
