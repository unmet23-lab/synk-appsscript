## 몽골어 세 겹 검수

글 파일 `검문/화면글.txt` · `검문/캡션.txt`(한국어 원문 / --- / 몽골어). 화면 글 정본 `remotion/src/chat/data.ts`, 게시 글 정본 `게시/문안.json`.

- **② 원문을 안 본 새 하위 에이전트(Opus) 직역 역번역 1차 「고쳐서」** — 철자 · 문법은 모두 맞고 чи/Та가 섞이지 않음, 4(сайн уу) · 5(сайн байна уу)가 반말 · 존댓말 대비를 그대로 살림, «багш»는 대학 교수를 부르는 말로 자연스러움(профессор는 직급이라 부를 때 안 씀), мессеж бичих · хариу бичлээ 자연스러움. 꼭 고칠 것: 캡션 ❌ 줄 «найздаа ярьдаг хүндэтгэлгүй хэллэг»가 「친구에게 쓰는 무례한 말」로 읽혀 반말 자체를 무례하다고 가르침 → «найзтайгаа ярьдаг хүндэтгэлийн бус хэллэг. Багшдаа ингэж бичвэл эелдэг бус сонсогдоно.» 권한 것(반영): 이름표 «바트 → өөрийн нэр» → «өөрийнхөө нэрийг бичээрэй», 캡션 감사 줄을 「답장을 받은 뒤」로, 캡션에 「교수님 = 대학교 선생님을 부르는 말」 한 줄. 그대로 둔 것: 끝 줄 «Солонгост сурч байгаа»(원문이 「한국에서 공부하는 친구」라 맞음), бүү мартаарай.
- **① 대조기(`tools/몽골어대조.js --파일 … --구독`)** — 화면 글 1차 「파손」(이름표 줄 «바트 → өөрийн нэр»에 한글이 섞임) → 2차 「파손」(«“바트” гэсний оронд өөрийн нэрээ» — 앞 줄의 키릴 Бат과 안 맞음 · өөрийн + -ээ 겹침, 반말 뜻 줄에 вэ 빠짐) → 3차 · 4차 **「정상」**. 캡션 1차(맞춤법 의심만) · 2 · 3 · 4차 **「정상」**. 맞춤법 의심 넷(аннёнхасэё · гёсуним · имнида · гамсахамнида)은 키릴 읽기라 고치지 않는다(M2와 같은 판단). 결과 `검문/대조_*`.
