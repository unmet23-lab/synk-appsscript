**기본 소개(300자 안 — 크몽 · 숨고 · 드롭샷 소개와 홈페이지 첫 문단의 원천):**

> 싱크펄스는 AI 광고영상을 만듭니다. 영상에 들어갈 모든 컷을, 만들기 전에 장면 이미지로 먼저 보여 드리고 확인하신 컷으로만 만듭니다. 출연자는 이름과 얼굴이 정해진 AI 모델 21명 가운데 캐스팅해 다음 편도 같은 모델로 잇고, 제품·로고·화면 위 글자는 AI로 다시 그리지 않고 보내 주신 실제 파일로 합성합니다. 목소리와 음악을 먼저 만들고 그 박자에 컷을 맞춰, 바로 올릴 수 있는 파일로 드립니다.

**어디서나 지키는 것**

- 앞세우는 다섯은 늘 같은 순서다 — ① 컷마다 장면 이미지 먼저 ② 출연자 캐스팅(모델 21명) ③ 제품·로고·화면 위 글자는 실제 파일 ④ 무엇으로 남길지(이야기 · 임팩트) 먼저 ⑤ 소리부터.

**어디에도 쓰지 않는 것:** 제작 도구 이름 · 최고 · 최초 · 유일 · 1위 같은 말 · 조회수 · 매출 같은 성과 약속 · 무제한 수정 · 「같은 얼굴 보증」 · 「결제 전 장면 확인」 · 납기 보장(10-18 진단의 약속, 아직 정하지 않음 — 트랙 §1) · 크몽에서 모은 숫자(크몽 이용 안내가 수집을 막는다) · 기각한 「솔서리」 · 크몽 · 숨고 안의 외부 주소와 연락처.
