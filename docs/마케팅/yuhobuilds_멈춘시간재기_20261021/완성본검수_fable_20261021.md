## 읽지 못한 범위

- **귀로 듣지 않았다.** 목소리·배경음·효과음은 받아쓰기(small)·낱말 시각·ebur128(−14.6 LUFS)로만 봤다. 「쟀어요」(P3-2)와 배경음 박이 장면과 맞는지는 확인 못 했다. large 모델 받아쓰기는 모델 내려받기가 1GB를 넘어 핫스팟 규칙으로 돌리지 않았다.
- 연속 재생으로 보지 않았다. 0.5초 간격 + 경계·낱말 시각 원본 크기 + f1·f3 세부 띠만 봤다. 0.5초 안에 끝나는 깜빡임은 놓쳤을 수 있다.
- P2-1의 고칠 안(칸 여섯 개 띠·크롭)은 렌더해 보지 않았다. P2-2의 `from={22.3}`은 근거 영상 0.1초 띠와 낱말 시각으로만 맞췄다.
- 요청문을 실제 AI에 붙여 같은 값이 나오는지는 돌리지 않았다. 도구 코드와 글을 견준 판단이다.
- 인스타·유튜브 앱 화면 위에 올려 단추·캡션 띠와 겹치는지는 보지 않았다.
- 콘티 검수를 따로 받지 못한 채 완성본과 같이 봤다. 콘티 단계에서 고를 수 있었던 것(장면 순서·근거 영상 자리)은 위 P2로 적었다.
