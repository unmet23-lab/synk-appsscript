# yuhobuilds 「42초 중 24초가 멈춰 있었다」 · 기획·대본·콘티

## 1. 왜 이 편인가

- **시청자가 얻을 것:** 내 쇼츠가 화면이 멈춰 지루한지 **숫자로 재는 법**(AI한테 시킬 요청문 한 장) + **기준 둘**(멈춘 시간 합 15% 이하, 1.5초 넘는 정지 없음) + **고치는 셋**(멈춘 사진은 천천히 당기기, 말하는 낱말마다 화면 한 곳이 바뀌게, 장면 사이 빈 화면 없애기).
- **실화는 증거로:** 우리 synkbrief 편 고치기 전 휴대폰판 42초 중 24초(57%) → 고친 올림판 2초(5%). 둘 다 같은 도구로 다시 잰 값이다(아래 「사실 대조」). 화면은 전부 우리 렌더와 실제 도구 출력.
- **깨달음 하나:** 목소리가 계속 나오면 만드는 사람은 화면이 멈춘 걸 못 느낀다. 귀로는 안 보이고, 숫자로 보면 보인다.
- **겹침 확인:** 10-21 「트렌디하게」 편은 움직임의 **종류**(무엇을 빼나)이고 이 편은 움직임의 **양**(얼마나 멈췄나)이다. synkbrief 음식 사진 편 화면은 고치기 전·후의 같은 순간을 몇 초씩만 쓴다. 형광펜이 들어간 05 요청문 장면은 첫째 편의 「형광펜 빼기」와 어긋나서 쓰지 않는다.
