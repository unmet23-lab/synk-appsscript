# 다음 제작: SHIFT 영상 2편

2026-09-21 사용자 결정. 이번에는 계획과 기존 작업을 저장하고 종료한다. 아래 두 영상의 새 원고·렌더·업로드는 아직 진행하지 않았다.

## 확정한 구성

| 영상 | 무엇을 보여줄지 | 우선 배포 계정 |
|---|---|---|
| 만들고 고친 과정 1편 | SYNK에서 실제 만든 결과, 처음과 달라진 부분, 고친 이유를 보여준다. | `@yuhobuilds` YouTube·Instagram·TikTok + 네이버 클립: 4곳 |
| 활용법 중심 1편 | 시청자가 자기 작업에 써볼 수 있는 방법을 실제 화면으로 설명한다. 무엇을 준비하고 어떻게 따라 하면 어떤 결과가 나오는지 보여준다. | `@synkbrief` YouTube·Instagram·TikTok: 3곳 |

두 편은 목적이 다른 영상이다. 같은 작업 화면이나 결과물을 재사용할 수 있지만, 동일 영상 한 편을 일곱 곳에 그대로 올리기로 한 것은 아니다. 각각의 세로 영상 원본에 플랫폼별 제목·설명·표지 등을 맞춘다. 블로그·Tistory·Threads 등의 추가 파생본은 필요할 때 따로 정한다.

얼굴 촬영은 필수가 아니다. 우선 실제 작업 화면·전후 비교·자막·필요한 내레이션으로 준비할 수 있다. 이는 채널 전체의 출연 금지 규칙이나 과거 L1/S1 촬영 계획의 일괄 취소가 아니다. 다른 세션에 맡겼던 LAB L1과 유호 S1 출연 영상의 제작 상태는 별도 확인한다.

## 다음에 이어갈 곳

1. 과정 영상부터 실제 사례 한 가지를 고른다. SNS 커버를 만들고 수정한 작업은 후보이며, 최종 주제·제목·원고는 아직 확정하지 않았다.
2. 실제 전후 자료와 수정 이유를 확인하고 한 편의 구성·원고를 먼저 완성한다. 없는 작업 과정이나 성과를 만들지 않는다.
3. 활용법 영상은 직접 재현할 수 있는 방법 하나로 좁힌다. 같은 사례에서 뽑아도 되고 독자에게 더 유용한 별도 도구·기능을 골라도 된다.
4. 한 편씩 검토·제작한다. 완성본 확인 뒤에만 각 채널용 게시 패키지와 업로드를 진행한다.

LAB 카드 제작은 별도 대기 작업이다. 재개할 때는 한국어 학습 초보인 10대 중후반을 대상으로 한국어 원본 한 편을 완성한 뒤 현지화한다. 이번 SHIFT 두 편과 합쳐서 제작 개수를 세지 않는다.

## 계정 작업 인계

- [계정 현황과 콘텐츠 분류](SNS_준비현황과_콘텐츠분류_20260921.md): 운영 대상 확보 47곳. 개인 연락용 Telegram 1곳이 포함되며, 모두 게시 준비가 끝났다는 뜻은 아니다.
- LAB 확장 잔여 20곳은 신규 가입·생성 확인 19곳과 VK 브랜드 커뮤니티 설정 1곳으로 구분한다. VK 개인 계정 생성과 LAB 커뮤니티 완성을 혼동하지 않는다.
- rednote는 로그인·본인 프로필 확인까지 완료한 기록이며 브랜드 이름·소개·사진 적용과 실제 게시 검증은 남아 있다. VK 프로필·커버·러시아어 소개는 로컬 준비본이고 사용자 등록 후 공개 확인이 남아 있다.
- Naver Clip 소개와 Naver 블로그 모바일 배경은 사용자 결정대로 콘텐츠 업로드 시점에 처리한다. 기타 계정별 제한과 다음 조치는 [최신 점검 기록](온라인마케팅지도/intl-social/최종점검_20260920.md)을 따른다.
- 마케팅 지도 화면에는 이전 시점의 집계가 남아 있다. 최신 계정 판단은 [계정 원장](sns-계정.json)과 [실행 원장](온라인마케팅지도/intl-social/execution-20260920.json)을 따른다. 이번 종료 작업에서 새 로그인·게시·지도 재빌드는 하지 않는다.

## 이번 종료의 범위

계정·콘텐츠 담당 문서, 준비한 자산과 제작 소스 중 이번 작업 범위만 커밋한다. 다른 세션의 엔진·앱·공동 운영 문서 변경은 보존한다. 대용량 중복 시안·재생성 가능한 미리보기는 로컬에 그대로 두며 삭제하지 않는다. 커밋은 배포·게시·원격 push 완료가 아니다.
