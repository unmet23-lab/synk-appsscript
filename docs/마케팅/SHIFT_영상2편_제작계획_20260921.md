# 다음 제작: SHIFT 영상 2편

**과정 편 최신 재개 위치:** 3분판에 대한 느린 말·지루한 목소리·음악 피드백을 반영한 [76초 오프닝 모션·자막 마감본](yuhobuilds_1편_쇼츠수정_20260922/README.md). 정의로는 임시 사용이며 사용자가 육성을 준비할 예정이다. 기존 윤성판은 비교용으로 보존한다. 수정본 원고·분리 음원·영상·검수는 새 폴더에서 이어간다. 외부 게시 없음. 100시간 회고는 오프닝으로 옮기고 엔딩에 채널 멘트를 연결했다. 프로필 사진 얼굴을 기존 캐릭터에 합성했다. 지목된 하단 안내 문구는 제거했다.

2026-09-21 사용자 결정으로 시작한 제작 계획. **2026-09-22 후속 요청으로 과정 편은 실제 개인 제작 여정의 시간순 연재로 전환했다.** 출발점은 6월 2일 번역을 위한 Claude 첫 결제다. 이후 스카이라인에듀 부원장으로 일하며 학생 문의가 늘어 관리가 어려워질 것을 예상했고, 학생 관리·학부모 신뢰·동료 교사의 편의를 위해 Glide·구글시트 출석 웹앱을 시도했다는 사용자 직접 회고를 따른다. 개발 시작일은 아직 미확인이다. [현재 연재·원고 진입](yuhobuilds_제작여정_202607-20260922/README.md)에서 이어 만든 [1편 제작본](yuhobuilds_1편_20260922/README.md)은 Typecast 남성 윤성의 `smart` 내레이션 19개 구간·1,330자와 1080×1920·30fps MP4를 제작했다. 57개 자막과 표지·19장면의 실제 시각 검수를 마쳤으며, 마지막 무음 여백 조정과 MP4 규격·전체 디코딩, 720 WebM 생성·전체 디코딩 검사는 완료했다. IAB에서 별도 재생 버튼으로 WebM의 시작·중간·끝 구간 재생을 확인했다. 앞서 만든 [34.57초 Behance 커버 영상](SHIFT_과정1편_20260921/README.md)은 연재 1편으로 채택하지 않고 이전 시안으로 보존한다. 활용법 편은 [별도 제작 기록](synkbrief_회의메모_20260921/README.md)을 따른다. 이 과정 편 작업에서는 외부 업로드를 진행하지 않았다.

**2026-09-22 후속:** 사용자가 활용법 편부터 제작을 요청하고 ‘회의 메모를 AI로 담당자·기한이 있는 할 일 표로 만들기’를 선택했다. [98초 2차 검토본·표지·synkbrief 3곳 게시 문안](synkbrief_회의메모_20260921/README.md)을 제작했다. 기존 48초본에 대한 사용자 피드백에 따라 구체적인 회의 상황으로 시작하고 입력 위치·메모 교체·결과 확인을 상세히 보강했다. 새 가상 메모로 ChatGPT 실제 입력·응답을 확인했고, 목소리·BGM·SNS 게시는 미진행이다. 이전 커버 시안과 활용법 검토본은 별도 파일로 보존하며 둘 다 외부 게시 전이다. 현재 과정 연재의 새 1편은 파일 검사와 IAB의 별도 재생 버튼을 통한 시작·중간·끝 구간 재생 확인을 마쳤으며, 직접 청취는 미확인이다.

## 확정한 구성

| 영상 | 무엇을 보여줄지 | 우선 배포 계정 |
|---|---|---|
| 개인 제작 여정 연재 1편 | 6/2 번역용 Claude 결제에서 출석 앱 시도까지 시간순으로 이야기한다. 초보자가 이입하고 따라 해보도록 실제 막힘에 필요한 기본기와 작은 실습을 연결한다. | `@yuhobuilds` YouTube·Instagram·TikTok + 네이버 클립: 4곳 |
| 활용법 중심 1편 | 시청자가 자기 작업에 써볼 수 있는 방법을 실제 화면으로 설명한다. 무엇을 준비하고 어떻게 따라 하면 어떤 결과가 나오는지 보여준다. | `@synkbrief` YouTube·Instagram·TikTok: 3곳 |

두 편은 목적이 다른 영상이다. 같은 작업 화면이나 결과물을 재사용할 수 있지만, 동일 영상 한 편을 일곱 곳에 그대로 올리기로 한 것은 아니다. 각각의 세로 영상 원본에 플랫폼별 제목·설명·표지 등을 맞춘다. 블로그·Tistory·Threads 등의 추가 파생본은 필요할 때 따로 정한다.

얼굴 촬영은 필수가 아니다. 우선 실제 작업 화면·전후 비교·자막·필요한 내레이션으로 준비할 수 있다. 이는 채널 전체의 출연 금지 규칙이나 과거 L1/S1 촬영 계획의 일괄 취소가 아니다. 다른 세션에 맡겼던 LAB L1과 유호 S1 출연 영상의 제작 상태는 별도 확인한다.

## 다음에 이어갈 곳

1. 과정 편은 [6월의 시작을 다루는 연재 1편 제작본](yuhobuilds_1편_20260922/README.md)에서 이어간다. 사용자 직접 회고를 우선하고, 남아 있는 당시 기록과 이후 결과를 시간순으로 연결한다. 실화 기반 각색은 허용하되 확인하지 않은 사용·성과를 사실로 만들지 않는다.
2. 남성 윤성 내레이션·MP4 제작과 표지·19장면 시각 검수는 마쳤다. 음성 재합성 없이 마지막 무음 여백을 줄인 타임라인 179.9초(5,397프레임)본의 MP4 규격·전체 디코딩과 720 WebM 전체 디코딩 검사를 마쳤다. IAB에서 별도 재생 버튼으로 WebM의 시작·중간·끝 구간 재생을 확인했다. 직접 청취 평가는 아직 미확인이다.
3. 활용법 영상은 [회의 메모를 할 일 표로 만드는 별도 검토본](synkbrief_회의메모_20260921/README.md)을 이어간다. 목소리와 후속 작업은 해당 제작 기록을 따른다.
4. 한 편씩 검토·제작한다. 완성본 확인 뒤에만 각 채널용 게시 패키지와 업로드를 진행한다.

LAB 카드 제작은 별도 대기 작업이다. 재개할 때는 한국어 학습 초보인 10대 중후반을 대상으로 한국어 원본 한 편을 완성한 뒤 현지화한다. 이번 SHIFT 두 편과 합쳐서 제작 개수를 세지 않는다.

## 계정 작업 인계

- [계정 현황과 콘텐츠 분류](SNS_준비현황과_콘텐츠분류_20260921.md): 운영 대상 확보 47곳. 개인 연락용 Telegram 1곳이 포함되며, 모두 게시 준비가 끝났다는 뜻은 아니다.
- LAB 확장 잔여 20곳은 신규 가입·생성 확인 19곳과 VK 브랜드 커뮤니티 설정 1곳으로 구분한다. VK 개인 계정 생성과 LAB 커뮤니티 완성을 혼동하지 않는다.
- rednote는 로그인·본인 프로필 확인까지 완료한 기록이며 브랜드 이름·소개·사진 적용과 실제 게시 검증은 남아 있다. VK 프로필·커버·러시아어 소개는 로컬 준비본이고 사용자 등록 후 공개 확인이 남아 있다.
- Naver Clip 소개와 Naver 블로그 모바일 배경은 사용자 결정대로 콘텐츠 업로드 시점에 처리한다. 기타 계정별 제한과 다음 조치는 [최신 점검 기록](온라인마케팅지도/intl-social/최종점검_20260920.md)을 따른다.
- 마케팅 지도 화면에는 이전 시점의 집계가 남아 있다. 최신 계정 판단은 [계정 원장](sns-계정.json)과 [실행 원장](온라인마케팅지도/intl-social/execution-20260920.json)을 따른다. 이번 종료 작업에서 새 로그인·게시·지도 재빌드는 하지 않는다.
