## 동영상 언어 시험(11-05 유호님 「그 한 편만 시험해」)

- 바꾼 것은 유튜브 판의 동영상 언어 칸 하나다(`게시/01-youtube-en/원고.json` `audioLanguage` ko → en). 영상 · 제목 · 설명 · 고정 댓글 · 시각(11-06 21:00)은 그대로다. 근거는 [현장 노트 · 브라우저 게시](../../현장노트/브라우저_게시.md) 「@synkkorean 쇼츠 — 동영상 언어가 ko인 편은…」 절(ko 일곱 편 11~164회 · 채널 시청자 83% 한국).

- 소리만 다시 담음(11-05): 다시 등록하려니 11-03에 생긴 업로드 소리 하한(스테레오 320kbps)에 옛 판 240.97kbps가 걸렸다. 공용 `음량마감.mjs`는 조용한 펠트 음악이라 210~254kbps에서 멈췄다. 그래서 같은 AAC 인코더에서 M/S · 세기 스테레오 · 잡음 대체만 끄고(`-aac_coder twoloop -aac_ms 0 -aac_is 0 -aac_pns 0 -b:a 384k`) 다시 담았다. 실측 343,481bps, 영상 스트림 MD5 같음, 길이 같음, −14.6 LUFS · 최대 −1.5 dBFS 그대로, 원본과의 빼기 시험 차이 RMS −59.0 dB(본 소리 −17.4 dB). 세 판 모두 같은 방법이고 옛 판은 각 폴더 `video_전_aac241k.mp4`에 있다. 샤오훙수 · 버마어 틱톡은 이미 그 플랫폼에 올려 둔 옛 파일 그대로 나간다(여기 사본만 검사를 위해 바꿈). 올리기 전 검사는 고칠 것 0 · 확인할 것 22(11-02와 같은 항목).
