# LAB 광고 운영 — 승인 예산·실측·문의 연결

> 2026-09-10 · 과거 6개월 세팅서의 유효한 광고 운영 선택을 분리했다. 광고를 켜거나 예산을 바꾼 작업이 아니다. 채널·타겟·무료 콘텐츠는 [마케팅 정본](../마케팅_정본.md), 실제 계정·문안·게시 분담은 [채널과 발행](채널과_발행.md)을 따른다.

## 승인된 예산과 방향

- 준비기간 **미디어비 하루 $5 고정, 동시에 광고세트 하나**(08-26 사용자 확정). 감수·제작 인건비는 별도이며 정상 운영 예산과 섞지 않는다. 옛 최소/권장 예산안·$1~3 워밍업·여러 세트 병렬·자동 증액은 사용하지 않는다.
- 유료는 성인·학부모의 현재 과정 문의에 맞춘다. 청소년 접점은 무료 콘텐츠·오프라인으로 연결한다. 기존 TikTok 유료 미집행 선택을 유지하되 무료 TikTok 콘텐츠를 재활용 전용으로 제한하지 않는다.
- 몽골어 유료 광고는 필요한 원어민 감수 뒤 집행한다. 무료 자기 채널의 현행 AI 대조 허용과 구분한다. ‘광고에 몽골어가 필요’와 ‘원어민 감수를 거칠 것’이라는 회사 품질 선택을 같은 법적 의무로 설명하지 않는다.
- 기존 준비 순서는 감수·판매 준비 전 $0 → 소액 실측 → 조건을 갖춘 리타겟 → 준비된 모집이다. 09~10월 $0, 11월 실측, 12~1월 리타겟, 2월 기존 오디언스 중심이라는 달력은 당시 계획이며 날짜 도착만으로 광고를 자동 시작하지 않는다. 집행 승인·실제 준비·현행 일정이 먼저다.
- 미확인 몽골 CPM/CPC/CPL을 외부 숫자로 가정하지 않는다. 우리 대화당 비용과 자격 리드당 비용을 따로 실측한다. 계정 준비가 플랫폼의 향후 성과를 보장하지 않는다.

## G1~G5 — 내부 준비 기준

다음 수치는 기존 계획의 목표·의사결정 눈금으로 보존한다. **오늘의 Meta 필수요건을 새로 확인한 표가 아니다.** 플랫폼의 학습 단계·타겟 최소 규모·지원 이벤트는 집행할 때 공식 문서와 해당 광고 계정에서 확인한다.

| 기준 | 확인할 결과 |
|---|---|
| G1 계정·결제 | 페이지·IG·비즈니스 연결과 관리자 권한, 실제 청구 성공, 정지/제한 상태, 통화·시간대 확인. 기존 워밍업 60일(여유 90일)은 운영 권장값이지 검증된 안정성 보장 아님. 학습 졸업 또는 아래 대안 분기 기록 |
| G2 오디언스 | 당시 목표는 IG 참여 / FB 참여 / 동영상 25% 이상 시청 중 한 갈래 1,000명, 확장 목표 3,000~5,000명. 세 갈래 동시 달성 조건 아님. 실제 리타겟 자격·나이·규모는 계정에서 확인하며 공개 학생 반응을 부모 명단으로 간주하지 않음 |
| G3 비용과 학습 가능성 | 대화 시작당 비용·자격 리드당 비용의 중앙값과 안정 범위 ±20%를 3주 연속 관찰. 해당 예산에서 목표 이벤트가 충분한지 실측하고 불가능하면 대안 분기. 리드를 값싼 대화와 혼동하지 않음 |
| G4 소재 | 같은 대상·목표 아래 계정 중앙값을 반복해 이긴 후보 3편을 기록. 훅·형식·길이·CTA·대상·기간을 남겨 재현 가능한 사양 1장으로 정리. 작은 표본·계절 차이를 인과 효과로 단정하지 않음 |
| G5 문의 연결 | 광고→실제 메신저/폼→캠페인별 leads 귀속→비용·상담·등록의 집계가 끝까지 이어짐. 코드·필드 존재와 라이브 전달·운영은 별도 확인 |

각 기준의 확인·미확인·문제를 구분하고 막힌 부분부터 해결한다. 다섯 칸을 채웠다는 사실을 광고 알고리즘의 영구 최적화·가입/매출 보장으로 발표하지 않는다.

## 하루 $5에서 판단하는 산수

기존 계획의 **주 50 이벤트**를 목표로 계산하면 주 $35 ÷ 50 = **이벤트당 $0.70**, 필요한 일예산 = 이벤트 단가 × 50 ÷ 7이다. 당시 ₮2,518은 옛 환율의 환산값이므로 현행 통화 금액으로 재사용하지 않는다.

| 실제 이벤트 단가가… | 판단 |
|---|---|
| $0.70 이하 | 기존 주 50 목표를 예산상 시도할 수 있음. 실제 플랫폼 상태와 노출 기회 확인 |
| 대화는 초과하나 상위 이벤트가 이하 | 시청/참여 등 목적에 맞는 상위 이벤트를 검토하고 문의는 별도로 운영. 해당 이벤트도 실제 단가를 측정 |
| 모두 초과 | 학습 미졸업 수용+소량 문의 운영 또는 도달·빈도 목적을 택함. 예산을 자동 증액하지 않음 |

ThruPlay·참여→조건이 준비된 메신저 대화라는 기존 순서를 유지하되 특정 이벤트가 반드시 싸다고 가정하지 않는다. 이 준비 예산에서 자격 리드 최적화·다수 세트 병렬을 기본값으로 삼지 않는다. 120일을 실제 집행하면 $600, 181일이면 $905라는 곱셈은 기간 예시이지 새 지출 승인·확정 달력이 아니다.

## 계정과 문의를 연결할 때

1. 기존 페이지·IG·광고 계정과 실제 관리자 권한·제재·결제 상태부터 확인한다. 중복 계정을 만들거나 정책 제한을 우회하지 않는다.
2. 새 계정이 필요한 경우 표시명 SYNK LAB, 통화 USD, 보고 시간대 Ulaanbaatar라는 기존 설정 선택을 실제 화면에서 확인한다. 계정 통화/시간대의 변경 가능성·결제 지원은 현행 서비스 안내를 따른다. 설명과 화면이 다르면 옛 클릭 순서를 반복하지 않는다.
3. 카드 등록 성공과 실제 청구 성공은 다르다. 승인된 지출 범위에서 실청구를 확인하며 본인 카드의 실제 지원을 확인한다. SocialPay·국제카드의 옛 호환 주장이나 지인 명의 대안을 검증 없이 사용하지 않는다.
4. 성인·학부모 CTM(메신저 대화로 가는 광고)을 기존 첫 문의 경로로 삼고, 추가 폼은 실제 운영과 계정 지원에 맞춰 선택한다. 댓글·자료 다운로드에서 학생·보호자의 연락처를 자동 합치지 않는다.
5. 캠페인 이름은 **채널_퍼널_소재_YYYYMM**으로 구분한다. leads의 캠페인·인지 경로와 실제 폼 입력이 같은 분류인지 확인하고, 등록 전 문의와 등록 후 온보딩을 분리한다. 옛 ‘TikTok 버킷 미사용’을 현행 전체 유입경로에서 틱톡을 지우라는 뜻으로 쓰지 않는다.
6. 웹사이트·픽셀 유무는 실제 선택한 광고 상품과 연결 요건으로 판단한다. 과거 ‘웹사이트가 없다’는 상태를 재사용하거나 추적 도구를 이 문서만으로 추가하지 않는다.

문의는 청중과 메시지가 맞아야 한다. 학생 반응으로 모은 오디언스를 학부모로 간주하지 않으며 미성년에게 유료 리타겟을 기본 설계하지 않는다. 무료 학생 자료·부모가 확인할 조건·성인 과정 안내를 분리한다.

## 소재·언어·운영 리듬

- 기본 내용과 관련 제공물을 완결한 뒤 광고용 마지막 안내를 그 대상의 실제 상담/과정으로 연결한다. 원작과 광고 파생을 구분하며 다른 플랫폼 워터마크를 붙인 복사본 대신 원본에서 채널용 파일을 만든다.
- 감수는 이번 발행분부터 수행한다. 기존 준비 기준 D-3, 촬영 전 대본 D-5를 작업 배정의 출발점으로 쓰되 현재 담당·실제 검수 범위를 기록한다. 감수 SLA를 고객 응답시간 보장으로 바꾸지 않는다.
- 가격·진단·지원·비교는 [약속과 실행](약속과_실행.md)의 현재 원문을 따른다. 실제로 없는 강사·학생 후기·경쟁 우위·과학 효과를 만들지 않는다.
- **관찰은 매일, 변경은 주 1회 한 요소부터**라는 운영 원칙을 유지한다. 예산·대상·소재를 동시에 바꾸지 않는다. 문의 대응은 실제 담당이 제공 가능한 범위로 운영하며 ‘즉시 답장’을 새 약속으로 쓰지 않는다.
- 월간으로 대화/리드 비용·반복 성과 소재·실제 오디언스·상담 수용을 정리한다. 무료 전용 콘텐츠·새 제작량은 광고 예산의 한 세트 제한과 별개다.

## 중단·복구 기준

**실측 벤치마크가 선 뒤 대화당/리드당 비용이 그 중앙값의 1.5배를 3일 연속 넘으면 해당 세트를 중단하고 원인을 확인한다.** 예산 증액으로 덮지 않고 실제 문의 품질·대상·소재·연결·시즌 조건을 본다. 표본·벤치마크가 없으면 정밀한 초과 판정을 지어내지 않는다.

계정 정지·정책 경고는 공식 검토 통로로 해결하고 새 계정으로 우회하지 않는다. 결제 실패는 실제 본인 결제수단·통화·청구 상태를 확인한다. 명절·여름·환율의 영향은 관찰 범위를 붙여 판단하며 옛 법안·인구·도달·CPM 수치로 현재 플랫폼이나 법을 단정하지 않는다. 준비되지 않은 약속·미감수 유료 문안·끊긴 도착지는 수정 후 다시 확인한다.
