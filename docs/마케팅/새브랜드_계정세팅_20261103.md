유튜브 전화 인증 뒤 같은 채널의 스튜디오 「설정 → 채널 → 기능 사용 자격 요건」에서 표준·중급 기능은 「사용 설정됨」으로 확인했다. 고급 기능은 아래 영상 인증 제출 후 「대기 중」이다. 고급 설정의 자동 더빙은 사용 설정되지 않은 상태이며 아동용 여부는 영상별 검토로 확인했다. 거주 국가는 임의로 바꾸지 않았다. 인증 번호·비밀번호는 사용자가 사이트 화면에 직접 입력하며 기록하지 않는다. 영상은 게시하지 않았다.

사용자가 고급 기능 활성화를 요청해 같은 스튜디오에서 경로를 열었다. 해당 채널에는 신분증 확인을 사용할 수 없다는 안내와 영상 인증 링크가 표시됐다. 공식 Google 영상 인증 QR 화면을 준비한 뒤 사용자가 휴대폰에서 본인 영상을 촬영·제출했다. 이후 스튜디오에 재진입해 고급 기능 「대기 중」과 「영상 인증을 검토 중입니다. 대개 24시간이 걸립니다」 안내를 확인했다. 제출 접수는 확인됐으며 고급 기능 활성화 완료는 아직 아니다. 추가 직접 인증 요구는 현재 표시되지 않는다.

로그인·개설·기본 설정·Meta 페이지 연결·게시 엔진 연결·실제 공개는 각각 별도로 확인한다. 이번 결과는 YouTube·Instagram·Facebook 기본 세팅과 Meta 연결까지이며, 16곳의 세팅 완료나 매일 자동 게시 가동을 뜻하지 않는다. 상세 실행 상태와 사용자 인증이 필요한 화면은 저장소 밖 운영 기록에서 이어 간다. 비밀번호·인증 코드·쿠키·토큰은 기록하지 않는다.

임시 이름을 넣은 뒤 1~2일 안에 바꾸는 일정은 변경 제한을 확인한 후 정한다. YouTube 채널 이름·핸들은 각각 [14일에 2회](https://support.google.com/youtube/answer/2657964?hl=ko), Instagram 표시 이름은 실제 설정 화면에서 14일에 2회로 확인했다. Facebook Page 이름은 [변경 요청 방식이며 최근 변경 등에 따른 제한](https://www.facebook.com/help/271607792873806)이 있다. 신규 가입 때의 첫 입력을 변경 횟수에 어떻게 적용하는지는 실제 계정 화면으로 확인하기 전까지 단정하지 않는다.
