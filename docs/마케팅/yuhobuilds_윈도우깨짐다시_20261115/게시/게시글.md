새 SSD 하나 달다가 윈도우가 깨졌어요. 끝나고 보니 오히려 701.9GB를 비웠어요 👇

1TB 옆에 2TB를 더 달다가 원래 윈도우가 깨졌어요. 원래 드라이브를 통째로 새 드라이브에 백업하고 다시 깔아 되살리니(문서 폴더 파일 1,796,647개 · 실패 0) 잃은 파일은 0개.

무거운 자료는 새 드라이브로 옮기고 원래 자리엔 바로가기를 뒀는데, 옮기고 나서 원래 것을 안 지워 원래 1TB 여유는 78.7GB뿐이었어요.

그래서 AI한테 맡겨 「다른 드라이브에 이미 있는 사본」만 골랐어요. 원래 1TB에 남은 옮기기 전 사본은 새 2TB에 옮겨 둔 판이 있는 것만(약 223GB — 새 2TB 쪽이 더 새것이어도 지웠어요), 새 2TB 백업 속 파일은 원래 1TB 같은 자리에 크기 · 수정 시각까지 같은 것만(약 479GB) — 합 701.9GB. 백업 속에서 원래 1TB에 없거나 달라진 79.5GB는 남겼고, 지우는 클릭은 제가 했어요. 여유는 1TB 78.7 → 298.4GB, 2TB 898.7 → 1,383.1GB.

드라이브 정리를 AI한테 맡길 거라면, 그대로 붙여 넣는 요청문이에요(내 PC 파일을 직접 볼 수 있는 AI에게, 【 】 안만 바꿔서). 저는 자리 · 크기 · 수정 시각으로 맞댔고, 옮기기 전 사본은 새 쪽이 더 새것이어도 지웠어요. 요청문은 내용(해시)까지 똑같은 파일만 지우고, 하나라도 다르면 남기게 더 엄하게 썼어요:

【옮길 폴더】를 【새 드라이브】로 옮겨서 원래 드라이브 자리를 비우려고 해. 아래 차례를 지켜 줘. 아무것도 지우지 마.
1) 【옮길 폴더】를 【새 드라이브】로 복사하고, 파일 수와 전체 용량이 같은지 맞춰 봐. 같으면 원래 폴더는 이름 끝에 「.옮김전」을 붙여 남기고, 원래 경로에는 새 위치를 가리키는 바로가기(폴더 링크)를 만들어. 그 폴더를 쓰던 프로그램 하나를 열어 예전 경로로 잘 열리는지 확인해 줘.
2) 지울 후보는 「두 곳에 똑같이 있는 파일」만이야. 「.옮김전」 폴더와 새 위치를 같은 자리끼리 맞대서 이름 · 크기 · 내용(해시)이 모두 같은 파일만 지울 목록에 넣고, 하나라도 다르거나 한쪽에만 있는 파일은 「남김」으로 따로 적어.
3) 표로 보여 줘: 지울 목록의 파일 수 · 용량, 남김의 파일 수 · 용량, 지우고 나면 늘어날 여유.
4) 지우는 명령은 실행하지 말고, 내가 표를 본 뒤 직접 돌릴 한 줄로만 따로 줘.
