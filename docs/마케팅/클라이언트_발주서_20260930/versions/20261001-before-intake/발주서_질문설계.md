# PULSE 영상 제작 브리프 질문 설계

2026-10-01 재구성. 클라이언트가 브랜드를 소개하고, 원하는 영상의 방향을 이해하기 쉬운 언어로 정리하도록 구성한다. 문서는 현재 `src/app.js`·`src/core.js`의 질문과 데이터 구조를 설명하며, 기능·화면 검증 결과를 대신하지 않는다.

## 이용 흐름과 원칙

- 클라이언트의 출발점은 제작 기법이 아니라 **소개할 브랜드, 고객의 궁금증, 제품을 선택할 이유**다. 전문적인 연출과 납품 규격은 뒤에서 필요에 따라 펼친다.
- 필수 답변은 이름과 광고 목적 두 가지다. 목적에는 ‘함께 정하고 싶어요’를 둔다. 예산을 포함한 나머지 항목은 비워둘 수 있다. 직접 입력한 길이와 고정 희망일, 작성한 링크의 형식은 선택한 내용에 맞게 확인한다.
- 일반 선택 질문의 ‘기타’와 항목별 메모를 유지한다. 기존 선택지에 대한 보충 설명과 자료 종류별 메모도 보존한다.
- 미응답은 ‘아직 정하지 않았어요’ 또는 상담할 내용으로 표시한다. 고객 승인, 자료 없음, 제작자의 제안으로 바꾸지 않는다.
- **‘추천받기’ 선택지, 제작 방식 질문, 소리 구성과 그 종속 질문은 넣지 않는다.** 모델의 등장 형태나 화면 자막은 별도 질문으로 유지한다.
- 클라이언트가 남긴 사실과 제작자가 제안할 도입부·콘셉트를 구분한다. 프로그램은 답변을 정리하며 자동으로 콘셉트를 확정하거나 광고 성과를 예측하지 않는다.
- 작성한 방향을 데스크톱 옆 요약과 작은 화면의 펼침 요약에서 확인한다. 마지막 화면에서는 핵심 방향을 먼저, 상세 답변을 나중에 펼쳐보게 한다.

## 6단계

| 단계 | 먼저 보이는 질문 | 필요할 때 펼치는 내용 | 결과에 연결하는 기준 |
|---|---|---|---|
| **1. 브랜드** | 이름, 소개할 대상, 짧은 제품·서비스 소개, 광고 목적, 보여줄 고객 | 영상 형식, 브랜드·제품 링크, 제품 수와 구성 | 무엇을 누구에게 왜 알리는지 정리한다. 고객은 연령뿐 아니라 필요와 사용 상황으로 설명할 수 있다. |
| **2. 고객·강점** | 고객의 사용 상황, 구매 전 궁금증·망설임, 선택할 이유, 보여줄 근거, 핵심 메시지, 원하는 다음 행동 | 고객의 브랜드 인지 정도 | 고객의 질문을 어떤 장점과 실제 자료로 풀어줄지 연결한다. 후기·비교·실사용 등의 근거가 있다는 설명과 원본 첨부는 구분한다. |
| **3. 느낌·장면** | 분위기, 모델 등장 형태, 원하는 장면, 장면별 중요도, 장면 메모 | 장르·색·피할 표현, 참고 링크, 모델 모습·행동, 배경·카메라·유지할 디테일 | 원하는 느낌과 반드시 필요한 내용을 구분한다. 등장 모델에 따라 후속 정보와 사용 허락을 확인한다. |
| **4. 사용 계획** | 사용 채널, 일반 게시·유료 광고 여부, 연결 페이지, 가격·혜택 안내 여부, 확인하고 싶은 변화 | 길이·전달 구성·비율·해상도·자막·추가 결과물, 광고의 목표·기간, 이전 콘텐츠에서 배운 점 | 첫 노출부터 다음 행동까지 연결한다. 제작비와 매체 광고비를 구분하고 필요한 납품 범위를 정리한다. |
| **5. 자료 준비** | 대상에 맞는 자료 종류, 준비 상태와 파일 선택, 제품 기준 사진, 큰 자료 공유 링크, 자료 설명 | 각 자료의 기타·메모 | 현재 첨부, 나중에 전달, 재첨부 필요를 구분한다. 어떤 원본을 색상·핏 등의 기준으로 삼을지 기록한다. |
| **6. 확인·전달** | 핵심 방향 다섯 항목, 장면 중요도, 기준 사진, ZIP 내려받기와 전달 순서 | 예산·일정·담당자·최종 확인 방식, 상세 답변, 참고 링크·자료 목록, 함께 확인할 내용 | 고객이 의도대로 정리됐는지 확인하고 수정할 수 있게 한다. 아직 남은 협의 사항을 감추지 않는다. |

## 조건부 질문

- **가격·혜택·판매 기간:** 안내할 내용이 있다고 하거나 기타를 고른 경우 상세 입력을 보여준다. 별도 혜택 없음으로 바꾸면 이전 상세 내용은 최종 발주서에 넣지 않는다.
- **목표와 확인 기간:** 유료 광고 또는 일반 게시와 광고를 함께 사용하는 경우에만 추가 입력을 보여준다. 일반 게시로 바꾸면 이전 목표·기간은 최종 발주서에서 제외한다. ‘확인하고 싶은 변화’는 일반 게시에서도 남길 수 있다.
- **모델:** 모델이 등장하는 경우에만 모습·행동·인원 질문을 연다. 제공 인물 또는 실제 모델을 고르면 사용 허락 상태를 묻는다.
- **채널:** 여러 채널이면 가장 중요한 채널을 고를 수 있다. TV·옥외·매장·전시 화면을 선택하면 송출 규격 자료를 안내한다.
- **일정·길이:** 희망 날짜가 있다고 선택하면 날짜를, 길이 직접 입력을 선택하면 원하는 길이를 받는다. 선택하지 않은 상태에 답변을 강제하지 않는다.
- **기준 사진:** 제품은 색상·디테일, 의류·패션은 색상·핏·기장·디테일을 지정한다. 다른 광고 대상으로 바꾸면 해당 기준 사진은 최종 발주서에 넣지 않는다.

## 장면의 중요도와 기준 사진

고른 각 장면은 ‘반드시 포함’, ‘가능하면 포함’, 중요도 미정으로 구분한다. 중요도를 지정하지 않았다는 이유로 필수 장면으로 처리하지 않는다. 선택한 장면과 중요도는 최종 검토 화면과 발주서에 함께 담는다.

기준 사진은 5단계 **제품 자료에 실제로 선택한 이미지**에서 파일 이름으로 고른다. 같은 사진을 여러 기준에 지정할 수 있고, 기준별로 다른 사진을 지정할 수도 있다. 기준 사진 설명은 별도 자유 입력으로 받는다. 이미지 미리보기는 파일 확인을 돕고, 기준 지정은 드롭다운에서 수행한다. 사진을 보정·재생성하거나 색상 정확성을 판정하지 않는다.

사진 파일 자체는 기기 임시저장·JSON에 담지 않는다. 기준 지정은 이름·크기·자료 종류의 정보로 보존하며, 원본을 다시 선택하지 않았다면 ‘재첨부 필요’로 표시한다. 지정했던 파일을 현재 자료에서 삭제하면 연결된 기준도 해제한다.

## 핵심 요약과 상세 발주서

핵심 요약의 순서는 다음과 같다.

1. **누구에게:** 대상 고객과 사용 상황
2. **어떤 궁금함을 풀어줄지:** 구매 전 궁금증·망설임
3. **무엇을 전할지:** 핵심 메시지와 제품을 고를 이유
4. **무엇으로 보여줄지:** 사진·후기·사례 등 근거
5. **어떤 행동으로 이어질지:** 원하는 행동과 연결 페이지

각 내용은 클라이언트의 답변으로 구성한다. 빈 항목은 미정으로 남기며 자동으로 사실을 만들지 않는다. ‘한 장 요약’은 핵심 다섯 항목을 한눈에 보여주는 의미다. **상세 발주서나 PDF 전체가 한 페이지라는 뜻은 아니다.**

상세 발주서에는 프로젝트, 고객·강점, 느낌·장면, 사용·결과, 일정·예산·기타, 기준 사진, 참고 자료, 자료 준비 상태, 상담에서 함께 정할 내용을 담는다. 형식·장르·사용처는 서로 다른 정보로 유지한다. 고객이 작성한 메모도 관련 항목에 연결한다.

도입부·콘셉트는 전달된 자료와 요청을 바탕으로 PULSE가 제안할 후속 작업이다. 핵심 요약을 제작자의 확정 기획안이나 승인된 콘티로 표시하지 않는다.

## 자료와 납품 범위

대상에 맞는 제품·서비스·공간 자료를 안내한다. 인물 기준 자료는 해당 모델을 선택했을 때 안내하고, 기존 촬영 원본·참고 이미지와 영상·로고·브랜드 가이드는 현재 제공할 수 있는 범위에서 받는다. 원본이 없는 항목은 준비 상태나 메모로 남긴다.

- 본편 1편, 같은 영상의 도입·문구 변형, 서로 다른 콘셉트 여러 편, 정기 제작을 구분한다.
- 비율 변환, 자막 언어·필수 문구, 자막 없는 버전, 짧은 버전, 썸네일·스틸, 편집 프로젝트 파일은 필요한 범위를 확인한다.
- TV·옥외 송출용 납품은 CF 분위기의 영상과 구분하고 실제 송출처 규격으로 협의한다.
- 기준 사진과 고객의 요청만으로 실제 색상·라벨·핏을 정확히 재현했다고 판단하지 않는다. 제작 결과는 지정 원본과 대조해 확인할 사항이다.

## 저장과 전달의 의미

단일 HTML을 기기에서 실행한다. 답변·메모·파일 목록·기준 사진 지정은 브라우저의 해당 기기에 임시저장하고 JSON으로 별도 저장·불러온다. 원본 파일은 새로고침·재실행·JSON 불러오기 뒤 다시 선택해야 한다.

ZIP은 HTML·TXT 발주서, JSON 작성 데이터, 안내문, **현재 선택한 해당 프로젝트의 원본 자료**로 구성한다. 파일은 원래 이름을 유지하고 자료 종류별 번호 폴더로 구분한다. 메타데이터에만 남은 원본과 재첨부하지 않은 기준 사진은 실제 포함 자료로 표시하지 않는다.

파일당 30MB·전체 80MB·최대 30개는 이 프로그램의 제한이다. 크몽의 첨부 제한으로 안내하지 않는다. 큰 파일은 공유 링크로 받으며 실제 접근 권한은 전달 전에 확인한다.

내려받기 버튼은 다운로드를 시작한다. 사용자가 다운로드 폴더의 ZIP을 확인한 뒤 크몽 대화에 직접 첨부한다. 자동 전송·접수·계약 기능은 없다. 인쇄/PDF에는 발주서 내용을 담고 원본 첨부는 ZIP으로 전달한다.

수신 후에는 요청사항·빠진 자료를 확인하고, 제작 방향·견적·범위·수정 조건·납기를 협의해 작업 시작 여부를 정한다. 작성 완료나 ZIP 다운로드를 발주 확정으로 해석하지 않는다.
