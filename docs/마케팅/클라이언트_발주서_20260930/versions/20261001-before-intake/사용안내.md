# SYNK PULSE 영상 제작 브리프 사용 안내

브랜드의 이야기와 원하는 영상을 편하게 정리하는 프로그램입니다. 정해진 것부터 남기면, 제작자와 이야기할 핵심 방향과 자료가 한곳에 모입니다. 전달받은 HTML 파일을 Chrome 또는 Edge에서 열어주세요. 계정 가입 없이 사용할 수 있습니다.

## 정해진 것부터 차근차근

1. **브랜드** — 이름과 영상의 목적, 보여주고 싶은 고객을 알려주세요. 제품 소개는 짧은 문장이나 키워드도 좋습니다. 영상 형식과 제품 구성은 정해져 있을 때 펼쳐서 적으면 됩니다.
2. **고객·강점** — 고객이 사용하는 상황, 구매 전에 궁금해하는 점, 우리 제품을 고를 이유를 적어주세요. 이를 보여줄 사진·후기·사례가 있는지, 꼭 전할 메시지와 다음 행동도 함께 정리합니다.
3. **느낌·장면** — 원하는 분위기와 모델, 장면을 골라주세요. 고른 장면마다 **‘반드시 포함’ 또는 ‘가능하면 포함’**을 표시할 수 있습니다. 아직 모르겠다면 중요도를 비워두어도 됩니다. 참고 링크, 색상, 피하고 싶은 표현, 배경과 움직임은 필요한 항목만 펼쳐주세요.
4. **사용 계획** — 사용할 채널과 일반 게시물·유료 광고 여부를 알려주세요. 연결할 구매·예약 페이지, 알릴 가격·혜택·기간, 확인하고 싶은 변화도 이곳에서 적습니다. 길이·화면 비율·완성물 구성과 이전 콘텐츠에서 배운 점은 펼쳐서 추가할 수 있습니다.
5. **자료 준비** — 지금 가진 사진·영상·로고를 선택하고, 나중에 보낼 자료는 준비 상태를 알려주세요. 제품 사진 중 **색상·디테일의 기준 사진**을 고를 수 있고, 의류·패션은 **핏·기장 기준**도 지정할 수 있습니다.
6. **확인·전달** — 예산·희망 일정·담당자가 정해졌다면 펼쳐서 남겨주세요. 핵심 방향과 상세 답변, 자료 목록을 확인한 뒤 ZIP을 내려받아 **크몽 메시지에 직접 첨부**합니다.

항상 필요한 답변은 **브랜드·제품·서비스 이름과 광고 목적 두 가지**입니다. 광고 목적이 아직 정해지지 않았다면 ‘함께 정하고 싶어요’를 선택해주세요. 예산을 포함한 나머지 질문은 정해진 만큼만 작성해도 됩니다. 다만 길이를 직접 입력하기로 골랐다면 원하는 길이를, 희망 날짜가 있다고 골랐다면 날짜를 적어주세요.

## 선택지만으로 설명하기 어려울 때

일반 선택 질문에는 **‘기타’와 ‘기타 / 메모 남기기’**가 있습니다. ‘기타’를 고르면 바로 메모칸이 열립니다. 다른 선택지를 고른 상태에서도 보충 설명을 남길 수 있습니다. 자료별 메모에는 파일 용도, 임시본 여부, 나중에 보낼 일정 등을 적어주세요.

‘가격·혜택·기간이 있어요’를 고르면 자세한 내용을 적는 칸이 나옵니다. 유료 광고 또는 둘 다 사용을 고르면 확인할 목표와 기간을 추가할 수 있습니다. 이 항목은 기대하는 결과를 서로 이해하기 위한 내용이며, 광고 성과를 보장하는 약속은 아닙니다.

## 기준 사진을 고르는 방법

5단계에서 제품 사진을 첨부한 다음 **‘이 사진을 기준으로 봐주세요’**에서 각 기준에 맞는 파일 이름을 선택합니다. 같은 사진을 여러 기준으로 골라도 됩니다.

예를 들어 색상은 자연광 사진, 핏과 기장은 정면 착장 사진, 봉제는 확대 사진을 고를 수 있습니다. 사진에서 특히 봐야 할 부분은 아래 설명칸에 남겨주세요. 기준 사진 선택은 제작 시 참고할 원본을 지정하는 것이며, 사진 자체를 수정하지 않습니다.

## 마지막에 받는 것

핵심 요약은 **누구에게 → 어떤 궁금함을 풀어줄지 → 무엇을 전할지 → 무엇으로 보여줄지 → 어떤 행동으로 이어질지** 순서로 정리됩니다. 수정 버튼을 누르면 해당 내용을 작성한 단계로 돌아갈 수 있습니다. 아직 정하지 않은 내용도 그대로 표시되므로 처음부터 모든 답을 채울 필요는 없습니다.

이 안내에서 **‘한 장 요약’은 핵심 방향 다섯 가지를 한눈에 보여주는 요약**을 뜻합니다. 상세 답변과 자료 목록까지 인쇄하면 여러 페이지가 될 수 있습니다.

ZIP에는 다음 파일이 들어갑니다.

- **HTML·TXT 발주서:** 핵심 요약, 상세 답변, 자료 목록과 함께 확인할 내용
- **JSON 작성 데이터:** 나중에 프로그램에서 불러와 수정할 답변
- **지금 선택한 원본 자료:** 파일 이름을 유지하고 번호 폴더로 구분한 첨부파일

ZIP을 내려받은 뒤 열어서 필요한 자료가 들어 있는지 확인해주세요. 프로그램은 크몽이나 제작자에게 자동으로 전송하지 않습니다. 전달 후 제작 방향·견적·일정을 PULSE와 확인하면 됩니다.

## 나중에 이어서 작성하려면

- 답변과 파일 목록, 기준 사진 지정은 **현재 기기에 임시저장**됩니다. 다른 기기·브라우저로 자동 공유되지 않습니다.
- 중요한 내용은 **‘작성 내용만 저장 (.json)’**으로 별도 저장해주세요. 다시 작성할 때 **‘이전 작성 불러오기’**에서 저장한 파일을 선택하면 됩니다.
- **첨부 원본은 임시저장이나 JSON에 들어 있지 않습니다.** 화면을 새로 열거나 새로고침하거나 JSON을 불러온 뒤에는 원본을 다시 선택해주세요.
- 기준 사진도 파일 이름 등의 정보만 저장됩니다. 원본이 다시 선택되지 않았다면 **‘다시 첨부 필요’**로 표시됩니다.
- ‘새로 작성’은 현재 답변과 파일 선택을 초기화합니다. 필요한 내용은 먼저 저장해주세요.

## 파일 크기와 PDF

파일은 **한 개 30MB, 전체 합계 80MB, 최대 30개**까지 선택할 수 있습니다. 이 프로그램의 제한이며 크몽의 첨부 제한을 뜻하지 않습니다. 큰 원본은 공유 링크로 남기고 제작자가 열 수 있는 권한인지 확인해주세요.

PDF가 필요하면 **‘인쇄 / PDF 저장’**을 누른 뒤 브라우저 인쇄 창에서 ‘PDF로 저장’을 선택하세요. PDF에는 발주서 내용이 담기고 원본 자료는 ZIP으로 전달합니다.

발주서 작성과 다운로드는 상담 내용을 준비하는 과정입니다. 접수·계약이나 제작 범위·금액·납기·수정 조건은 제작자와 별도로 확인해주세요.
