# SYNK PULSE 영상 제작 브리프 사용 안내

소개할 대상과 꼭 전하고 싶은 내용을 남겨주세요. **기본 필수는 브랜드·제품·서비스 이름 하나**입니다. 나머지는 정해진 것만 작성하면 됩니다. 제품 페이지나 자료에 이미 있는 설명을 다시 옮겨 적지 않아도 괜찮아요.

## 6단계로 작성하기

1. **제작 대상** — 브랜드·제품·서비스 이름과 링크 또는 대표 사진을 남깁니다. 제품·의류는 색상·모델명처럼 이번에 보여줄 제품을 구분해주세요. 영상 형식을 이미 정했다면 추가할 수 있습니다.
2. **전달할 내용** — 꼭 전하고 싶은 내용과 실제 고객층을 알려주세요. 완성된 광고 문장일 필요는 없습니다. 화면에 그대로 넣어야 하는 문구는 별도 항목에 적어주세요.
3. **참고·요청** — 마음에 드는 영상·이미지와 좋았던 부분, 특별히 원하거나 피할 표현을 남깁니다. 정해 둔 인물이나 장면이 있을 때만 추가 질문을 펼치면 됩니다.
4. **사용·납품** — 사용할 곳과 일반 게시·유료 광고의 사용 범위를 알려주세요. 길이·편수·구성, 비율·해상도·송출 규격은 정해진 요청이 있을 때만 추가합니다. 자막 언어나 추가 결과물도 남길 수 있습니다.
5. **자료** — 현재 가진 사진·영상·로고를 선택하거나 공유 링크를 남기고 사용 권한을 표시합니다. 자료 설명은 필요한 경우만 적으세요. 사진마다 다르게 보일 때만 더 정확한 기준 사진을 지정하면 됩니다.
6. **확인·전달** — 예산·일정·담당자·연락 방법을 남기고 작성 내용과 자료를 확인합니다. 온라인에서는 전송에 동의한 뒤 ‘답변과 자료 PULSE에 보내기’를 누르고 접수번호를 확인해주세요.

길이 직접 입력이나 고정 날짜를 선택했다면 해당 내용을 입력해주세요. 기타·메모에는 선택지만으로 표현하기 어려운 요청을 남길 수 있습니다. 광고 기획·카메라 움직임·성과 측정이나 첫 시안의 확인 기준을 미리 정할 필요는 없습니다.

## 자료를 전달할 때

실제 제품 원본과 분위기 참고 자료를 구분해주세요. 사용 권한을 확인 중인 자료는 그 상태 그대로 표시하면 됩니다. 제품·색상·버전이나 참고할 부분을 파일명만으로 알기 어렵다면 설명을 덧붙여주세요.

사진마다 색상·핏·기장·디테일이 달라 보이면 기준 사진을 선택할 수 있습니다. 원본만으로 명확한 부분은 따로 설명하지 않아도 됩니다. 수치·효과·가격·기간을 화면에 넣는다면 적용 조건과 확인할 자료를 함께 남겨주세요.

## 온라인 접수와 파일 보관

- **온라인 접수 링크:** PULSE가 발급한 링크에서 답변과 원본을 보냅니다. 서버가 저장을 확인한 뒤 접수번호를 보여주며 자료는 비공개 접수함에 보관합니다.
- **오프라인 HTML·ZIP:** 작성과 파일 보관용입니다. 내려받기만으로 접수되지 않으며 전송은 온라인 접수 링크에서 진행합니다.

연결이 준비되지 않았거나 링크가 만료됐다면 PULSE에 새 링크를 요청해주세요. 접수번호가 나오기 전에는 완료로 판단하지 마세요. 접수 완료는 자료가 보관됐다는 뜻이며 분석·계약·금액·납기·수정 조건의 확정이나 유료 생성 시작을 뜻하지 않습니다.

## 끊겼을 때와 수정할 때

- 전송에 실패하면 같은 답변과 원본으로 다시 보내주세요. 이미 받은 파일을 확인해 이어서 전송합니다.
- 링크에는 유효 기간이 있으며 접수 한 건에 사용합니다. 전송을 시작한 뒤 답변·원본을 바꾸거나 완료한 접수를 수정하려면 접수번호와 함께 새 링크를 요청해주세요.
- 완료 후 같은 화면에서 수정한 내용은 아직 전송되지 않은 내용으로 표시됩니다.
- ‘다시 첨부 필요’인 원본은 다시 고르거나 불필요한 파일을 목록에서 제외해주세요. 연결된 기준 사진도 함께 확인합니다.

## 보관과 이어서 작성하기

답변과 자료 목록은 현재 브라우저에 임시저장되며 다른 기기와 자동 공유되지 않습니다. ‘작성 내용만 저장 (.json)’으로 별도 저장하고 ‘이전 작성 불러오기’로 복원할 수 있습니다.

**첨부 원본은 임시저장이나 JSON에 포함되지 않습니다.** 새로고침·재실행·JSON 불러오기 뒤에는 원본을 다시 선택해주세요. 자료 설명과 기준 지정은 답변에 남습니다. ‘새로 작성’은 현재 답변과 파일 선택을 초기화합니다.

보관 ZIP에는 HTML·TXT 발주서, JSON 답변, 제작 검토용 문서와 현재 선택한 원본이 들어갑니다. 제작 검토 문서는 답변을 정리한 자료이며 AI 분석 완료를 뜻하지 않습니다.

## 용량과 PDF

선택 제한은 파일당 30MiB, 전체 80MiB, 최대 30개입니다. 큰 원본은 제작자가 열 수 있는 공유 링크로 남겨주세요. 실제 온라인 처리 범위와 배포·접수 확인 상태는 [검증 기록](검증_기록.md)을 따릅니다.

‘인쇄 / PDF 저장’을 누르면 브라우저 인쇄 창에서 PDF를 저장할 수 있습니다. PDF에 첨부 원본 자체는 포함되지 않으며 문서 전체가 한 페이지로 출력되는 것은 아닙니다.
