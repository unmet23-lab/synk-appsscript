## 4. SHIFT — 1인 기업의 브랜드와 일을 완성하는 수업

### 4-0. 주력과 넓은 사업 범위를 구별한다 — 09-09 후속 결정

**사용자 확정:** 1인 기업 브랜딩 및 강의를 중심에 둔다. 홍보성 릴스도 이어가되 주된 콘텐츠는 1인 기업에 필요한 것을 제공하며, 마지막 참여 안내도 관련 정보·꿀팁·실용 자료로 연결한다. ‘AI를 많이 아는 회사’나 ‘회사를 만드는 과정을 구경하는 채널’에 머물지 않는다. 도구는 1인 기업의 문제를 해결할 때 사용한다.

**편집 기본값:** 한 편에서 실제 문제 하나를 풀고, 독자가 자기 사업에 옮길 방법까지 제공한다. 예쁜 브랜드 소개만 보여주는 것으로 수업을 대신하지 않는다. `독자의 문제 → 실제 예시·판단 → 자기 작업에 적용 → 남는 결과 → 필요할 때 관련 자료/다음 수업` 순서로 편성한다. 참여 안내가 없는 사람도 본편에서 한 가지를 얻어야 한다.

유학·대학교 알선/협력·기관 AI 연수·강사 에이전시·제작 서비스는 폐기하지 않는다. 다만 공개 피드에서 같은 비중으로 번갈아 홍보하지 않고 별도 메뉴·자료·문의 경로로 구분한다. 주력 변경은 계약 주체·협약·강사 풀·개강·강의 판매 준비의 완료가 아니다.

**AI 추천 가정:** 우선 독자는 한국어권 성인 중 자기 전문성을 서비스·교육·콘텐츠로 상품화하려는 초기 1인 사업자다. 이는 사용자에게서 확정받은 국가·연령·업종이 아니며, 실제 문의와 수업 반응으로 조정한다. 업종·세부 편성·새 채널 제안은 [마케팅 확장안](../마케팅/SHIFT_공개수업.md)에 따로 표시한다.

### 4-1. 넓은 사업을 하나의 광고에 섞지 않는다

유학·AI 강의·AI 강사 에이전시·대학 알선/협력을 이번 전략 범위에 포함한다. 기존 첫 상품 방향인 **광고 제작·브랜딩 교육**과 후속 대학 관리·직장 적응 연구도 지우지 않는다. 공통 약속은 ‘복잡한 일을 실제로 정리하고 끝내는 방법’이지만, 첫 화면은 반드시 **누구를 위한 어떤 일인지** 명시한다. 계획한 폭과 지금 계약할 수 있는 폭은 별개다.

### 4-2. 사업별로 신뢰를 실물로 만든다

**유학 — ‘학교를 추천한다’ 앞에 ‘선택을 설명할 수 있게 한다’.** 비교표에는 목표 전공, 지원 자격, 교육 언어, 생활 환경, 확인된 비용 항목, 준비 일정, 원문·확인일, 아직 모르는 것을 둔다. 비용은 같은 기간·포함 범위로 비교하고 미정 항목을 0으로 쓰지 않는다. 학교별 요강을 확인하지 않은 예시는 학교 A/B의 **허구 연습 사례**로 표시한다. 합격·비자·취업 가능성을 숫자로 만들어 팔지 않는다.

대학을 알선할 때는 제휴 여부와 추천 이유를 구분한다. 협력 학교만 비교했다면 비교 범위를 밝힌다. 학생·학교 중 누가 비용을 내는지와 추천에 영향을 줄 수 있는 이해관계를 실제 계약 전에 설명한다. 학교 로고·장학금·정원은 실제 권한과 현재 조건을 확인하기 전에는 ‘확보’로 표시하지 않는다. 법률·비자 판단을 콘텐츠가 대신 확정하지 않는다.

**대학 협력 — 모집 숫자보다 경계에서 끊기지 않는 업무.** 기관 담당자에게 줄 한 장에는 학생이 도착하기 전 필요한 준비, 누가 어떤 정보를 받고 확인하는지, 학기 시작 때의 연결, 문제 발생 시 연락, 계약 종료 때의 자료 인계가 있어야 한다. 학생의 얼굴·이름·학습 원문을 영업 견본으로 쓰지 않는다. 미래 관리 체계는 데모·설계로 보여주고 이탈 예측·대학 인정·취업 연결이 검증된 것처럼 말하지 않는다.

**AI 강의 — 도구 목록보다 가져가는 완성물.** 입문자는 처음의 파일에서 자기 결과물 하나를 만들고, 실무자는 자신이 다시 수행할 입력·검사·수정 방법을 얻도록 설계한다. 교육 목표, 필요한 사전 능력, 도구 접근과 추가 요금 가능성, 쓸 수 없는 민감자료, 실습 결과, 확인법, 질문받는 범위가 안내에 함께 있어야 한다. 한 수업의 시연 성공을 학습자 전원의 숙련·수익·업무 시간 절감으로 발표하지 않는다.

**강사 에이전시 — 유명함이 아니라 청중에 맞는 전달과 마무리.** 프로필은 얼굴·한 줄 경력 뒤에 ‘누구의 어떤 일을 가르치는가 / 본인이 만든 결과 / 공개 가능한 샘플 / 수업 뒤 남는 것’을 붙인다. 팔로워 순위로 강사 우열을 만들지 않는다. 선발은 의뢰 목표와 검증된 수행을 기준으로 한다. 대표가 등장한 광고를 보고 신청했는데 실제 강사가 다르면 계약 전에 분명히 알려야 한다. 대체·취소·정산·교재 권리·질문 대응은 실제 약속 가능한 범위로 적는다.

**제작·브랜딩 — 결과물에 인수 경험을 포함한다.** 인수란 고객이 파일을 받고 실제 사용을 이어갈 수 있는 상태다. 완성본만 보내지 않고 사용처별 파일, 원고·출처·권리, 바꿀 수 있는 범위, 재사용 방법, 수정 요청 통로를 함께 설계한다. 현재 납품하지 않는 파일·기간·지원은 기본 포함이라고 말하지 않는다. 유호 개인 수익이나 내부 금융 화면을 성과 콘텐츠로 쓰는 것과 고객에게 가격·비용을 투명하게 설명하는 것은 별개다.

이 표의 제작 이야기·비교·과정 소개도 **1인 기업자의 어떤 결정에 쓸 수 있는가**를 먼저 밝힌다. AI 뉴스는 도구 업데이트 자체가 아니라 해당 독자의 업무 변화·적용법을 설명할 때 채택한다. 유학·기관·강사 전용 정보는 주력 독자와 구별한다.

**1회 레시피 — 소개서 한 장을 다시 쓸 수 있게 넘기기.** 승인된 09-09 소개서의 완성본을 실제 읽는 크기로 먼저 보여준다. ‘누가 어디서 읽는가’라는 기준으로 선택한 배치 한 가지를 설명한다. 공개 가능한 별도 예시로 정보의 우선순위를 비교하고, 시청자가 자기 자료에서 첫 읽힘·필수 사실·사용처를 적을 빈 작업지를 건넨다. 검증한 것은 읽힘·파일·사용성이고, 문의 증가나 매출 효과는 측정 전이라고 구분한다. 엔진 내부·학생 기록·미공개 고객 자료를 과정 공개의 원료로 쓰지 않는다.

### 4-3-a. 제작 이야기 — 만든 것과 선택한 이유를 함께 제공한다

**2026-09-09 유호 요청 반영:** 까몽 3D처럼 실제로 만든 실험도, 무엇에 쓸 수 있고 왜 채택하거나 남겨 두었는지 설명해 전체 마케팅에 포함한다. 새 연재·편수를 추가하는 것이 아니라 기존 **‘한 일을 끝내는 방법’의 소재 갈래**다. 제작자는 실물과 판단을 보여주고, 독자는 자기 작업에 쓸 기준을 가져간다. 실험을 했다는 사실만으로 교육 품질·고객 신뢰·매출 효과를 주장하지 않는다.

한 사례의 순서는 **실물과 현재 상태 → 시도한 이유 → 실제 비교 → 채택/비채택 판단 → 지금 가능한 사용처 → 독자가 가져갈 한 장**이다. 좋은 결과만 모으거나 미채택을 자랑하는 대신, 그 선택이 사용 목적에 왜 맞는지 설명한다. 내부 보고서를 그대로 공개하지 않고 민감정보와 구현 내부를 걷어낸 편집본을 사용한다.

**첫 사례: 까몽 3D — 만들었지만 앱에는 넣지 않은 이유.** 기존 2D 그림의 고개 돌림에 3D 모델의 깊이를 빌릴 수 있는지 시험했다. 현 후보는 원본과 눈 간격 차이가 남고 같은 움직임 계산에서 개선 근거를 얻지 못해 **비채택으로 시험을 닫았다.** 끝난 것은 후보의 시험·판단이며 실사용 3D 캐릭터 완성이 아니다. 기존 2D 원본·깊이·앱·옷 자산을 유지한다. 실험 설명, 구도·조명 시안, 다음 제작자의 비교 참고에는 활용할 수 있으나 공식 캐릭터를 대체하거나 옷 개선 성과로 홍보하지 않는다. 구도·조명 활용은 가능한 후속 용도이지 이번에 제작한 별도 캠페인 결과가 아니다.

첫 사례의 [기획·사용법](../홍보물/까몽_제작이야기_20260909/기획과사용법.md), [제공 점검표](../홍보물/까몽_제작이야기_20260909/제공자료_결과물점검표.md), [한국어 원고](../../.claude/skills/synk-content/references/까몽_제작이야기_20260909.md)를 연결한다. 사실 근거는 [깊이 시험 보고](../_ops/삼디문지기/깊이시험/검증보고.md), 내부 실물은 [비교 화면](../_ops/삼디문지기/깊이시험/실험보기.html)이다. **이번 반영은 전략·기획·한국어 원고·텍스트 제공자료까지이며 SNS 게시나 새 영상 제작은 아니다.**

다음 소재도 같은 형식으로 고른다. ‘릴 45편을 도움 제공형 10편으로 줄인 이유’와 ‘번역을 직역 대신 장면·의도에서 시작한 이유’는 후속 후보이며 추가 제작 일정이 아니다. 각 사례는 실제 결정·자료·검토 범위가 있어야 하며, 번역 AI 검토를 인간 원어민 감수로 표시하지 않는다. 새로 나가는 몽골어는 장면·의도 작성 → 몽골어 자체 읽힘 → 별도 한몽 의미 대조의 현행 방침을 따르고 발행 전 필요한 언어 검토를 거친다.

### 4-4. SHIFT의 표현 감각과 서비스 분기

사람의 얼굴과 실제 완성물, 명확한 계층, 조건을 읽을 수 있는 여백이 중심이다. LAB의 밝은 참여성과 같은 킷을 쓰되 모든 장면을 마스코트 진행으로 바꾸지 않는다. 친근함은 전문용어를 덜어내고 선택 이유를 설명하는 데서 만든다. 도구 화면을 빠르게 넘기는 ‘기술을 많이 안다’ 연출보다 사용 전후의 차이 한 가지를 보여준다.

기존 계정의 자산과 핸들은 유지하고 역할을 선명하게 한다. **yuhobuilds**는 유호의 실제 작업을 1인 기업자가 적용할 수 있게 가르치는 수업·판단 채널, **synkbrief**는 그 일을 시작하거나 막힌 부분을 푸는 짧은 실용 자료 채널이다. 두 계정을 같은 AI 뉴스 복제본으로 만들지 않는다. 콘텐츠 첫 줄과 도착 페이지에 대상·업무를 표시한다. 새 채널은 제작 속도 때문이 아니라 별도의 발견·검색·관계·문의 역할이 있는지로 추천하며, 개설·발송·광고 집행은 실제 실행 요청과 구분한다.

### 4-5. 준비 단계와 영업 단계의 표현

`만들어 본 공개 예시 → 실제 시연 가능한 샘플 → 범위·책임·계약이 준비된 서비스 → 실제 고객 운영 → 확인된 결과`를 구분한다. 앞 단계에서도 유용한 자료와 방법은 제공할 수 있다. 다만 단순 문의 창구나 설계 문서만으로 ‘유학 지원 중’, ‘강사 다수 보유’, ‘협력 대학 네트워크’, ‘공인 기준’이라 쓰지 않는다. 현재 판매 준비 여부는 [SHIFT 설계](../SHIFT/설계_v1.md)·관련 결정·계약 증거에서 확인한다.

공개 수업의 자료 여섯 가지·4주 편성 가안·확장 방식은 [공개 수업 편성](SHIFT_공개수업.md)에 둔다. 기존 자격 사업은 [SHIFT 설계](../SHIFT/설계_v1.md)에서 유지한다.
