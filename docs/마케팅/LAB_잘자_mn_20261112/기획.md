## 사실 확인

- 「주무시다」는 「자다」의 높임말(표준국어대사전), 「안녕히 주무세요」는 웃어른께 하는 밤 인사(국립국어원 표준 언어 예절). 「잘 자」는 친구 · 아랫사람에게 하는 반말 인사. 어른이 아랫사람에게 「잘 자」라고 하는 것은 자연스럽다.
- 「아이고, 예뻐라」는 어른이 아랫사람의 바른 행동을 귀여워하며 하는 말 — 하숙집 아주머니 말투로 자연스럽다.

## 몽골어 세 겹

검문 파일 `게시/검문/`(한국어 / --- / 몽골어).

- **대조기(카본 · `node tools/몽골어대조.js --구독`):** 화면 글 1차 정상 → 2차 어색(«Юу буруу байсан бэ?» 물음이 무엇이 틀렸는지 흐림) → 3 · 4차 정상 → 5차 어색(v2 흐름 새 줄) → **6차 정상**(최종 data.ts와 같은 줄). 캡션 1차 어색(여격 겹침) → **2차 정상**(게시 캡션과 같은 글).
- **Opus 직역 역번역(원문 안 봄) 두 번:** 둘 다 「자연스러움 · 뜻 같음」. 반영한 것 — ах эгч(손위 형제)가 하숙집 어른으로 안 읽힘 → багш · байрны эзэн, 「잘 자」 읽기 чада → жада(우리 규칙 ㅈ = ж), 뜻 줄의 「=」가 등식처럼 읽힘 → 괄호, унтах → нойрсох(몽골어에도 「자다」의 높임이 있다는 짝).
