# 그록 시험관 답 · 구독(grok CLI) · 2026-11-12T08:49:21.943Z

1. 집 주인 언니한테 «잘 자»라고 보냈더니 틀린 말이고, 친구·동생에게는 «잘 자», 선생님·어른에게는 «안녕히 주무세요»라고 해야 한대.
2. 밤에 친구에게 «잘 자», 어른에게 «안녕히 주무세요»라고 써 볼 수 있게 됨.
3. 0~0.5초 이름 칸은 빨간 줄에 가려 못 읽음. 1초 «하숙집»은 모름. «아주머니»는 몽골어가 없어 배너의 언니와 같은지 모르겠음. 2초 «몽글아 ㅎㅎ»는 누구를 부르는지, ㅎㅎ가 뭔지 모름. 12초 «자다 → 주무시다»는 몽골어가 없어 모름. 14초는 위가 질문인데 아래는 다음 날이라 안 맞았고, 16초에 이해함.
4. 끝까지. 1초에 읽음과 치는 점이 보여 궁금했고, 4초 «뭐가 잘못됐지»의 답을 보려고 남음. 6~8초는 같은 그림이라 길었음.
5. 4. 몽골어로 누구한테 어느 말인지 나와 핵심은 알겠음. 하숙집, ㅎㅎ, 12초 카드는 모르겠음.
6. 3. 웃던 얼굴이 땀 흘리며 굳어 웃음이 났고, 가운데는 글 카드라 재미는 보통임.
7. 계속 봄. 1초에 상대가 읽고 답을 치는 중이고, 3초 안에 고쳐 하라는 말이 나와 이유가 궁금함.
8. 저장. 어른에게 쓸 밤 인사를 나중에 따라 하려고 함.
9. 달라 보임. 물개는 큰 글과 바다 그림, 끝은 박수. 수고하세요는 방 안 두 사람, 얼음, 고르는 칸, 끝은 손 흔듦. 이 영상은 빨간 머리 글 아래 문자창, 가운데 하얀 낱말 카드, 끝은 두 말을 나란히 적은 장면임.
