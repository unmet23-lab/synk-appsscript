## 사실 확인(장부 관문 조건 ⑶)

- Wikipedia 「Jieut」 획순 절: 「some people write like ス in Japanese language」.
- 나무위키 계열 ㅈ 항목(검색 요약): 글씨체에 따라 ㅅ 위에 가로획을 얹는 꼴과 가타카나 ス처럼 꺾어 쓰는 꼴 둘.
- 이 PC 글꼴로 그린 표본(scratchpad, git 밖): 맑은 고딕 · Noto Sans KR = 「ㅡ + ㅅ」, 바탕 · 궁서 · Noto Serif KR = 위 가로가 꺾여 내려가는 꼴. 한국어 손글씨 글꼴(Google Fonts, OFL) 여섯 — 나눔손글씨 펜 · 개구 · 하이멜로디 · 싱글데이는 꺾인 꼴, 감자꽃 · 가난한 이야기는 「ㅡ + ㅅ」.
- 그래서 「두 꼴 다 맞다」는 사실이고, 어느 꼴이 더 많은지는 말하지 않는다.
