## 다음 생성 입력

정지 사진에서 발화 전체를 추측시키는 방식 대신 실제 인터뷰 동영상을 수정 입력으로 사용한다. 카페 기준 이미지는 배경·의상 참조로만 보조한다. 입과 턱의 움직임, 눈매, 얼굴 비율은 실제 동영상이 기준이다. 이 방식의 효과는 아직 생성·검증되지 않았다.

1. Google Vids 동일 제작 프로젝트의 수정 모드.
2. 입력 동영상: 실제 발화 10초 참고 영상.
3. 보조 이미지: `../yuho-interview-face/SYNK_LAB_카페_유호_정면기준_v2.png`.
4. 지시문: `test-08-speaking-motion-prompt.txt`.
