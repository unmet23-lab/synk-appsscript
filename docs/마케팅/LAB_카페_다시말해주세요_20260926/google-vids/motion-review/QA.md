# 표정 보존 시험 비교

`watch.html`에서 실제 원본과 test-10을 나란히 재생한다. 카페 대사 완성본이 아닌 배경 교체·표정 보존 시험이다.

- 왼쪽: `../../performance-references/upload-ready/yuho-genuine-smile-under10s-compatible.mp4`
- 오른쪽: `../test-10-motion-preservation.mp4`
- 기본 원본 소리만 켜짐. 함께 재생·일시정지, 1배/0.5배속, 같은 시점 이동을 제공한다.
- 두 영상의 공통 길이까지만 재생한다. 생성 영상에 시간 변화가 포함돼 있다면 같은 재생 시간이 반드시 같은 표정 단계임을 보장하지는 않는다.

## 파일과 검사

- 원본: 1920×1080, 60000/1001fps, 593프레임, 영상 스트림 9.893217초.
- test-10: 1920×1080, 24fps, 236프레임, 영상 스트림 9.833333초.
- 두 파일 전체 디코딩: FFmpeg 오류 없음, 종료 코드 0.
- 직접 청취와 연속 재생 검토는 이 독립 작업에서 수행하지 않았다. 부모 작업이 비교 페이지에서 연속 재생을 확인한다.

## 같은 시각 확대 비교

`face-comparison-six-times.jpg`는 0.5, 1.5, 2.5, 4, 6, 8초를 비교한다. 각 쌍에서 왼쪽은 원본, 오른쪽은 시험본이다. 첫째 행은 0.5·1.5초, 둘째 행은 2.5·4초, 셋째 행은 6·8초다.

두 소스 모두 같은 crop `x=100, y=60, width=700, height=700`을 적용하고 정사각형 512×512로 축소했다. 얼굴 위치나 형태를 별도로 정렬·변형하지 않았다. 원본 표본은 30/90/150/240/360/480프레임(최대 약 8ms 차이), 시험본은 12/36/60/96/144/192프레임이다. 전체 화면 비교는 `overview-1p5s.jpg`에 있다.

## 시각 관찰

배경은 카페로 바뀌었으나 사람의 위치·자세·입 움직임도 달라져, 배경만 교체된 결과로 볼 수 없다.

- 0.5초: 원본은 입을 거의 다문 작은 미소이고 시험본은 입이 더 열려 있다.
- 1.5초: 원본과 시험본의 입 벌어짐과 고개 기울기가 다르다.
- 2.5초: 눈이 좁아지고 볼이 올라가는 큰 웃음의 흐름은 따라오지만 입꼬리와 치아 노출 형태가 완전히 같지는 않다.
- 4초: 시험본이 원본보다 치아를 더 드러내며 웃는다.
- 6초: 표정의 전체 흐름은 비슷하나 얼굴 위치와 자세가 그대로 보존되지는 않았다.
- 8초: 발화 중 입 모양이 서로 다르다.

이 여섯 표본만으로 전체 연속 동작을 판정할 수는 없다. 다만 사용자의 실제 미소와 웃음을 그대로 유지했다는 승인 근거로는 부족하다. 재생 타이밍 변경과 얼굴 재합성이 함께 영향을 주었을 수 있으며 정밀 입모양 일치는 검증하지 않았다.
