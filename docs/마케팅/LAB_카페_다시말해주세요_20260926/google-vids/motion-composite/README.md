# 실제 표정 보존 합성 시험

2026-09-27. 카페 새 대사 완성본이 아니라, 유호가 실제로 말하고 웃는 원본을 유지한 채 배경만 바꾸는 로컬 시험이다.

## 결과

- `yuho-original-face-cafe-10s.mp4`: 1920×1080, 24fps, 영상 238프레임(9.9167초), 컨테이너/원본 음성 9.92초. 인물의 얼굴·몸·피부색·의상·표정은 원본 RGB를 사용했고 재생성하거나 보정하지 않았다.
- `before-after-5frames-full.jpg`: 원본 0 / 2.5 / 5 / 7.5 / 9.875초와 같은 시점의 합성 비교.
- `report-10s.json`: 독립 검증 결과와 전체 238프레임의 중앙 얼굴 비교 지표.
- `ffprobe-10s.json`, `full-decode-10s.log`: 파일 정보와 전체 영상/음성 디코딩 통과 기록.
- 앞선 1초 시험과 `report-1s.json`은 그대로 보존했다.

## 합성 방법

원본은 `../../performance-references/upload-ready/yuho-genuine-smile-under10s-compatible.mp4`이다. 이미 캐시된 `isnet-general-use.onnx`를 ONNX Runtime CPU 4스레드로 실행해 알파만 얻었다. 높은 확신의 인물 영역은 알파 1로 고정했다. 얼굴·눈·치아·입술의 픽셀을 새로 생성하지 않았다. 프레임마다 별도로 마스크를 계산했고 12fps 보간이나 움직임 워프를 쓰지 않았다.

배경은 `../test-10-motion-preservation.mp4`에서 사람이 없는 `(x=1050,y=200,w=870,h=490)` 부분만 확대했다. 배경에만 약한 흐림(2.2), 채도 0.70, 밝기 0.90을 적용했다. 배경 원본이 9.834초이므로 마지막 2프레임은 마지막 배경을 유지했다. 해당 구간에서도 인물은 계속 원본 프레임을 사용한다. 배경 0 / 2.5 / 5 / 7.5 / 9.75초는 `background-5times-preflight.jpg`에서 사람이 없음을 확인했다.

전체 238프레임 처리에 318.6초가 걸렸다. 평균 마스크 추론 시간은 1.074초/프레임이다. 모델 다운로드·설치·외부 전송·결제를 하지 않았다.

## 검증과 한계

- 전체 영상과 음성 디코딩: 통과, 오류 출력 없음.
- 저장된 무손실 표본 5개의 불투명 인물 내부: 원본 RGB와 차이 0. 중앙 얼굴 알파 255.
- 인코딩 이후 전체 238프레임의 같은 시점 중앙 얼굴 영역 비교: 평균 RGB 절대 오차 1.569/255, 최악 프레임 평균 1.700/255. H.264 압축이 있으므로 최종 파일의 RGB가 원본과 바이트 단위로 같다는 뜻은 아니다.
- 원본 AAC 스트림을 복사했다. 디코딩된 원본/결과 음성 SHA-256이 동일하다.
- 5시점 비교에서는 실제 미소·눈가·치아·말하는 입 모양이 유지된다. 머리카락과 인물 윤곽에 미세한 밝은 테두리가 남아 있으며 합성 마감 완료로 보지 않는다. 부모 작업이 `watch.html`에서 원본과 합성의 1배속 동시 재생을 실행했고, 두 영상 모두 9.92초에 ended=true가 됐음을 확인했다. 근거는 `browser-playback.json`. 직접 청취와 사용자의 자연스러움 승인은 별도다.
- 최초 렌더 끝의 ffprobe 보고서 저장에 Windows cp949 문자 오류가 발생했다. 영상은 정상 완성됐다. `verify_full.py`로 UTF-8 보고서와 전체 디코딩·238프레임 얼굴·음성을 독립 확인했다. 최초 실행의 모든 프레임 알파 배열은 저장하지 않았으므로, 보존된 5개 알파 표본과 전체 인코딩 후 비교를 구분해 기록한다.
- 원본에 없는 새 카페 대사를 말하게 하는 기능은 이 시험에 포함하지 않았다. 정지 사진·텍스트만으로 새로운 말과 미소를 완전히 동일하게 생성했다는 증거가 아니다.

재현: `composite_full.py` / 독립 검증: `verify_full.py`. 출력물을 다시 만들 필요가 없을 때 검증 스크립트만 실행한다.
