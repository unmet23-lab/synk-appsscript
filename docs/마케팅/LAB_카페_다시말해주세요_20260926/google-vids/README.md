## test-09 — 승인한 얼굴 느낌의 카페 대화

2026-09-27, 사용자의 “지금 느낌으로 카페 영상” 승인에 따라 `../performance-references/cafe-expression-references/yuho-smiling-cafe-age-match-v2.png`를 Google Vids Omni 이미지 애니메이션에 업로드했다. 세로 1080p·10초, 기존 계정의 생성 가능 범위 사용. 신규 결제·구독·충전 없음.

- 원본: `test-09-age-match-cafe.mp4` — H.264/AAC, 1080×1920, 24fps, 10.005초, 3,979,371바이트.
- 지시문: `test-09-prompt.txt`. 원래 얼굴과 자연스러운 나이감·주름 대비를 유지하면서 세 대사와 미소를 요청했다.
- 입력 방식: 승인된 정지 이미지 1장. 실제 인터뷰 동작 영상을 입력한 생성은 아니다.
- 자동 받아쓰기: `test-09-age-match-cafe.words.json`. 요청/여자 직원의 응답/감사 인사 확인. 시간 경계는 자동 추정이다.
- 시각 표본: `test-09-age-match-cafe-contact-sheet.jpg`. 8개 프레임에서 발화와 실제 표정 변화, 마지막 미소 확인. 직접 청취·정밀한 입 모양·사용자의 동적 닮음 판단은 별도다.
- 후속 편집: `../rebuild-v4/SYNK_LAB_CAFE_AGE_MATCH_v4.mp4`. 15.208초, 1080×1920, 24fps. 새 영상 전체와 첫 문장 반복, 끝부분 웃음으로 구성하며 이전 잘못된 얼굴의 장면은 쓰지 않는다. 전체 디코딩과 브라우저 끝까지 재생 확인. 세부 검수·한계는 v4 README/qa-report.json에 기록.
