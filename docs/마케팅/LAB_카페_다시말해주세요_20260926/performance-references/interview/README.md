1. 미소가 커지면 실제로 눈이 상당히 좁아지고 눈꼬리에 선이 생긴다. 눈과 눈썹을 거의 움직이지 못하게 고정하는 방식은 실제 웃음과 다르다.
2. 볼이 올라가지만 아래턱 길이가 갑자기 짧아지거나 턱끝이 둥글게 바뀌지 않는다. 웃을 때 얼굴 전체를 둥근 다른 얼굴로 교체하지 않아야 한다.
3. 웃음에서 치아가 얇게 드러나는 높이, 입술의 실제 두께, 입꼬리의 약한 좌우 차이를 보존한다. 넓고 균일한 광고용 치열이나 과도한 잇몸 노출을 새로 만들지 않는다.
