# 카페 한국어 01 — 다시 말해 주세요

한국어 실사 상황극 새 제작본. 생성된 대화 세 장면에 학습·참여 구간을 더한 35.5초 영상이다.

## 결과물

- `SYNK_LAB_CAFE_REAL_v3.mp4`: 배포용 세로 1080×1920, 24fps MP4.
- `SYNK_LAB_CAFE_REAL_v3_preview.webm`: 브라우저 재생용 720×1280 프록시.
- `watch.html`: 실제 영상 파일을 재생하는 검토 페이지.
- `index.html`, `compositions/`: HyperFrames 편집 원본.
- `edit-timeline.json`: 장면과 원본 구간 대응표.

## 제작과 검증

- Google Vids, Omni, 기존 제작 계정의 1080p 사용 범위. 신규 결제·구독·충전 없이 생성했다. 모든 계정이 무료로 1080p를 쓸 수 있다는 뜻은 아니다.
- 승인된 유호 얼굴 기준 이미지를 사용했다. 첫 연장 결과의 인물·머리·의상 변화는 기준 이미지를 첨부한 수정 생성으로 보정했다.
- 최종 사용 원본: 첫 10초 생성, 중간 컷 보정, 마지막 컷 보정. 원본과 실패·보정 전 버전은 상위 `google-vids/`에 보존한다.
- Google 프로젝트는 원본 30초, 로컬 편집본은 학습 구간을 포함해 35.5초다. 아직 SNS에 게시하지 않았다.
- 생성 원본의 워터마크를 보존했다. 본인 음성 복제본이라고 주장하지 않는다.
- 대사와 자막은 로컬 음성 인식 결과로 대조했다. 자동 받아쓰기는 감정 연기와 정밀한 입 모양 일치를 보증하지 않는다.
- `check-final.json`: 런타임·레이아웃 오류 0, 타임라인 15지점 점검, 대비 17건 통과. 로고를 포함한 상단 브랜딩의 편집 구조 경고 1건은 의도된 정적 요소다.
- `animation-review/animation-map.json`: 19개 동작 확인. 실제 대화 중 자막을 가만히 두는 구간과 마지막 읽기 구간은 의도된 정지 구간이다. 동작 지도는 원본 영상 내부 움직임을 세지 않는다. 화면 안 배치는 장면별 스냅샷으로 확인했다.
- 원본 색·피부를 유지하고 대사·카페 환경음을 우선했다. 학습 카드에는 원본에서 추출한 환경음과 핵심 문장 반복을 사용했다.

최종 출력 검증 기록은 `qa-report.json`에 저장한다.
