# SYNK LAB 카페 — 다시 말해 주세요

한국어 표현 하나를 실제 상황에서 익히는 세로 영상. AI 실사 유호와 여성 바리스타가 출연한다. 사용자는 전체 재제작, 최종 영상으로 보기, Google Vids로 본인 얼굴 기준 이미지 업로드와 생성 및 이미지 사용 정책 동의를 승인했다. 추가 결제와 게시 요청은 없다.

## 볼 이유

선택 질문에 너무 자신 있게 '네!'라고 대답하는 짧은 어색함으로 웃음을 만들고, 다시 물으면 대화가 쉬워지는 과정을 눈으로 보여준다. 핵심 표현은 문맥에서 듣고, 따라 말하고, 새 질문에 직접 써 본다.

## 결과물

1080×1920, 24fps. 생성된 실제 대화 길이에 맞춰 약 35~40초. 한국어 원본과 독립 MP4, 브라우저용 미리보기. 기존 몽글판과 원본들은 보존.

## 디자인과 편집

사람의 표정이 중심이다. 원본의 자연광과 피부를 유지하고 가독성이 필요한 위치에만 검은 바탕·흰 글씨를 쓴다. SUIT Variable과 승인 LAB 로고를 사용한다. 중요한 표현은 큰 글씨로 나타나고 따라 말할 시간에는 진행 표시가 줄어든다. 장식용 영상 효과, 과장된 몸짓, 웃음 효과음은 넣지 않는다. 원본의 카페 환경음과 실제 생성 음성을 유지한다.

## 검증

자동 자막만 믿지 않고 원본 파일의 로컬 음성 인식과 대사를 대조한다. 음성 인식은 감정 연기와 입 모양의 품질을 보증하지 않는다. 영상 디코딩, 장면별 스냅샷, 실제 끝까지 재생, 타임라인·자막 가독성을 확인한다. 사용자가 최종 영상까지 맡긴 승인에 따라 추가 렌더 승인 질문 없이 완료한다.
