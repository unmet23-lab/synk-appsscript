# 카페 한국어 · 다시 말해 주세요

승인된 age-match-v2 사진으로 만든 test-09 영상 한 개를 사용한다. 10초 상황을 보고, 같은 발화를 정상 속도로 한 번 더 듣고, 실제 움직이는 미소 화면에서 직접 말해 보는 약 15.2초 영상이다. 기존 v3는 보존한다.

사용자가 완성 영상 제작을 위임했다. 추가 렌더 승인 질문 없이 로컬 결과까지 만든다. 게시·결제는 범위 밖이다.

1080×1920, 24fps. 원본 색·피부·음성을 유지한다. 원본 동영상을 세 구간으로 재사용하고 정지 배경은 쓰지 않는다. SUIT와 기존 LAB 로고를 재사용한다.

## 검증 상태

오프라인 ASR로 대사를 확인했고 원본 8개 프레임을 승인 사진과 비교했다. 최종 편집은 기술 검사·장면별 시각 검사·브라우저 전체 재생을 완료했다. 직접 청취와 사용자의 동적 닮음 승인은 대기다. 자동 인식은 정확한 입모양 또는 연기 품질을 보증하지 않는다. 상세는 qa-report.json과 README.md에 기록한다.
