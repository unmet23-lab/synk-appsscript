# 편집 기준

실제 대화를 보고, 같은 문장을 다시 듣고, 직접 말하는 순서다. 얼굴과 입 모양이 중심이며 새 test-09 동영상만 바탕으로 사용한다.

- 1080×1920, 24fps. 총 365프레임.
- 이전 v3의 SUIT Variable, 승인 LAB 로고, 흑백 자막 스타일을 재사용한다.
- 발화 자막 62px. 학습 안내 39px. 얼굴을 가리지 않고 화면 가장자리에 여유를 둔다.
- 원본 피부색·질감·음성은 유지한다. 색보정·피부 필터·사진 확대·정지 화면은 사용하지 않는다.
- 발화 구간은 정상 속도다. 세 장면은 컷으로 연결하며 장식 효과는 더하지 않는다.
- 마지막 실제 미소 구간의 환경음을 그대로 사용한다. 대사를 덧붙이지 않는다.
