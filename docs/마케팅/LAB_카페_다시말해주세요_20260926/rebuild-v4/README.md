# 카페 한국어 v4 검토본

새 test-09 영상만으로 구성한 365프레임, 약 15.208초 검토본이다. 대화 10초 → 첫 문장 정상 속도 반복 → 움직이는 미소와 직접 말하기 순서다.

- 출력: `SYNK_LAB_CAFE_AGE_MATCH_v4.mp4`
- 편집 원본: `index.html`, `compositions/`
- 재생성: `node build-composition.mjs`
- 검사: `npm run check`
- 출력: `npm run render -- --fps 24 --quality delivery --output SYNK_LAB_CAFE_AGE_MATCH_v4.mp4`
- 시간표: `edit-timeline.json`

## 확인 상태

MP4 출력과 기술 검사를 완료했다. 1080×1920, 24fps, 365프레임, 15.208333초, 18,333,036바이트다. 전체 디코딩 오류가 없고 HyperFrames 0.8.79 검사에서 런타임·레이아웃 오류 0, 대비 6/6 통과를 확인했다. 정적 로고의 편집 구조 경고 1건은 유지한다.

장면 스냅샷 5개와 최종 MP4에서 추출한 8개 프레임을 확인했다. 세 구간 모두 새 동영상이 표시되며 글자가 얼굴을 가리지 않는다. 소스의 드문 키프레임 경고가 있었으나 렌더는 365개 원본 프레임을 추출해 완료했고, 서로 다른 발화·미소 프레임을 최종 출력에서 확인했다.

부모 작업에서 watch.html의 영상 재생 버튼으로 처음부터 끝까지 재생했다. currentTime=duration=15.208333, ended=true, muted=false, readyState=4, video.error 없음, 화면의 '전체 영상 재생 완료' 표시와 마지막 미소·자막을 확인했다. 근거는 부모 작업의 browser-playback.json이다.

직접 청취와 사용자의 동적 닮음 승인은 미완료다. 오프라인 ASR에서 원래 네 대사와 추가 반복 문장을 확인했다. 12.26–12.44초 전환 경계에 원문에 없는 '안녕.'이 신뢰도 0.267로 인식돼 자동 인식 오류 가능성을 기록한다. 청취하지 않았으므로 해당 경계의 실제 소리를 확정하지 않는다.

원본 음성·색·피부를 수정하지 않았으며 생성 워터마크는 보존한다. 본인 음성 복제본이라고 주장하지 않는다. 게시하지 않았다.
