# 카페 상황극 · 음성 수정 2안

사용자 피드백: 대본 낭독이 너무 AI처럼 부자연스럽다. 여자에게 감정을 더 넣고, 이번 버전의 남자 성우는 교체한다.

기존 영상은 보존하고 Typecast 새 음성 14개를 반영한 최종 MP4를 완성했다. 남자 도윤·여자 서현이며, 40.4333초 타임라인에 자막과 표정·쉼을 다시 맞췄다. 사용자는 새 음성 MP3를 듣고 “전보다 훨씬 낫다.”라고 평가했다. 저장 공간을 확보한 뒤 최종 영상 출력을 완료했다.

최종 영상: `SYNK_LAB_카페_몽글_감정연기_v2.mp4` — 1080×1920, 30fps, 40.448초, 약 66.9MB. 상위 폴더의 [미리보기](http://127.0.0.1:5208/)는 새 목소리 버전으로 갱신했다. 이전 영상은 별도 저장 링크로 남겨 두었다.

음성만 듣기: `SYNK_LAB_카페_새목소리_v2.mp3` — 40.4333초, 효과음·연습 시간 포함, 전체 디코딩 통과.

- 남자 성우: Typecast 도윤. 청년 대화체로 당황 → 조심스러운 부탁 → 안도감을 구분하도록 생성했다.
- 여자 성우: Typecast 서현. 첫 질문은 미소, 다시 설명할 때는 배려, 연습 안내는 격려를 담도록 생성했다.
- 같은 “다시 말해 주세요”도 학습 예시·실제 부탁·마지막 자신 있는 부탁의 세 테이크로 생성했다.
- 감정은 대사별 프리셋/강도 또는 앞뒤 대사를 제공하는 Smart Emotion으로 설정한다. 피치를 바꿔 남자 교체로 간주하지 않는다.
- 대사 길이·쉼·자막·표정 전환을 다시 맞췄다. 따라 하기 2.5초와 답을 가린 5초 연습은 유지했다.

`voice-plan.json`은 대사와 연기 지시, `voice-connection.cjs`는 이번 14개 대사만 생성하는 로컬 연결이다. API 키는 메모리에만 두며 2시간 후 지운다. 계정 잔량을 먼저 확인하고 기존 월 제공 크레딧이 부족하면 중단한다. 결제·충전·API 키 생성 기능은 없다.

성우 선정은 보이스 카탈로그의 용도와 감정 지원을 바탕으로 했다. 사용자가 새 음성에 긍정적인 청취 피드백을 주었으며 이 조합을 유지했다. 에이전트가 직접 듣고 자연스러움을 평가했다고 기록하지 않는다.

후속 피드백: 사용자는 아직 약간 어색하며 상황 설명을 함께 주면 더 자연스러워질지 질문했다. 최종 연기 품질 승인으로 보지 않는다. 현재 14개 중 5개만 앞뒤 대사를 넣는 Smart Emotion이고 나머지 9개는 감정 프리셋이다. `direction`은 제작 메모이며 API로 전송된 연기 지시가 아니다. 다음 개선 검토는 성우를 유지하면서 장면의 의도·상대 반응·망설임을 앞뒤 문맥과 대화 간격에 반영하는 방식이다. 아직 추가 테이크는 생성하지 않았다. 공식 근거: https://typecast.ai/kr/learn/typecast-api-ssfm-v30-smart-emotion/

## 검사와 이어가기

- `npm run check` 통과: 오류·경고·레이아웃 문제 0, 글자 대비 15/15 AA.
- 6개 장면 중간과 끝 7개 프레임을 실제 확인했다. 모아보기는 `mongle-video/snapshots/contact-sheet.jpg`. 개별 검사 PNG는 공간 확보를 위해 제거했다.
- 14개 WAV의 성우 ID·대본·타임스탬프를 검증했다. 같은 표현의 세 테이크는 각각 생성했다.
- 최종 MP4와 WebM 전체 디코딩 통과, 검출된 검은 구간 없음. 최종 MP4 음량 -16.03 LUFS, 실제 피크 -1.51 dBTP. 상세는 `validation.json`, `final-media-check.log`.
- 실제 사용자 미리보기에서 새 WebM의 재생 시간이 0.281초부터 40.456초 끝까지 진행됐다. 4.172·22.4·39.2초의 실제 캔버스 프레임을 확인했고, 포스터는 숨김 상태이며 오류 표시는 없었다. HTTP 206 및 video/webm 응답 확인.
- 첫 렌더는 프레임 777/1213에서 디스크 부족으로 중단됐다. 사용자가 공간을 확보한 뒤 재개해 성공했다.
- 이번에 복제한 승인 PNG 8개는 원본과 SHA-256 대조 후 원본을 가리키는 하드링크로 바꿔 162,760,498바이트 중복을 제거했다. 원본 내용과 수정 프로젝트의 파일 경로는 유지했다. 이 PNG 원본에 덮어쓰지 말고 파생 파일을 만든다.
- HyperFrames 0.8.77의 `history` 명령은 지원되지 않아 별도 폴더로 원본을 보존했다.
- 재현: `mongle-video/`에서 `npx --yes hyperframes@0.8.77 render --quality delivery --fps 30 --workers 1 --output '../SYNK_LAB_카페_몽글_감정연기_v2_raw.mp4'`, 이어 `revision-v2/`에서 `node finish-video.cjs`. 영상 스트림을 유지한 채 1.16dB 음량 보정과 AAC 192k를 적용했고, WebM은 720×1280 VP9/Opus다.
- 음성 생성은 완료돼 API 임시 연결에서 키를 지웠다. 영상 출력에는 재연결이 필요 없다.

국가별 번역과 외부 게시 전이다. AI 실사 인물판은 지정 Co-NAI 제작 페이지의 접근 복구가 남아 있다.
