# 구독 무료 기능 실제 확인

2026-09-27. 사용자가 구독에 포함된 무료 기능 사용을 요청해 로그인된 웹 계정에서 확인했다. 새 결제·구독·충전·유료 생성은 진행하지 않았다.

## 활성 무제한 모델

구독 화면은 Plus 월간, 잔액 0.92크레딧이다. 활성 목록에는 이미지 모델 6개가 표시된다.

- FLUX.2 Pro: 1K, 365일 무제한, 활성
- GPT Image: 365일 무제한, 활성. 최신 GPT Image 2/2.5와 동일한 대상으로 단정하지 않는다.
- Seedream 4.5: 365일 무제한, 활성
- Kling O1 Image: 365일 무제한, 활성. Kling 영상과 별도다.
- Nano Banana: 365일 무제한, 활성. Nano Banana 2/Pro와 별도다.
- Seedream 5.0 Lite: 365일 무제한, 활성

`active-unlimited-models.png`에 실제 목록을 저장했다. 이용 내역의 Nano Banana 2 7일/2K 혜택은 9월 8일 시작, 9월 15일 만료, 비활성이었다. 현재 활성 영상 모델은 표시되지 않았다.

## 직접 확인한 생성 화면

Seedream 4.5 이미지 제작 화면에서 Unlimited 스위치를 켰다. WebMCP `get_image_draft`는 `model=seedream_v4_5`, `price.mode=unlimited`, `effective_credits=0`을 반환했다. 실제 생성 버튼도 Unlimited로 바뀌었다. 이번 확인에서는 새 이미지를 생성하지 않았다.

Genjutsu에는 예전에 무료 생성에 쓴 카페 소스 `4d48b380-c888-4ddd-9970-61daf85f90e7`를 넣어도 49크레딧이 표시되며 무료 생성 스위치는 없었다. 새 영상 생성은 하지 않았다. 무료 횟수가 소진된 것인지 구입 시점 혜택 차이인지는 화면으로 확정하지 못했다.

가격표의 신규 연간 Plus는 Genjutsu 무료 3회 등을 광고했으나, 이는 현재 월간 계정에 남은 횟수의 증거가 아니다. 요금제 변경을 하지 않았다.

무료·무제한은 대상 모델의 웹사이트 모드에서 적용된다. API/CLI/MCP의 일반 생성은 별도 과금이다. 웹 초안의 가격 확인 도구와 CLI 생성 제출을 혼동하지 않는다. 공식 무제한 안내는 개인 사용을 전제로 하므로 반복 자동 생성에 사용하지 않는다.

현재 활용 범위는 얼굴 참고 이미지, 장면 시안, 커버/썸네일이다. 영상 얼굴 교체 완료 상태가 아니다.
