## 2026-09-26 릴스의 Astra + Higgsfield 방식 적용

참고: [song_ping7의 소개 릴스](https://www.instagram.com/reel/DdjHfTCBSfM/), [공식 연결 안내](https://higgsfield.ai/mcp), [Open Higgsfield API 시작 안내](https://docs.higgsfield.ai/docs/quickstart). 릴스는 연결 방법을 소개하는 광고이며, 우리 한국어 대화의 연기 품질을 검증한 자료는 아니다.

- Astra가 사용자의 짧은 의도를 장면·인물의 목적·감정 변화·정확한 대사·호흡·카메라 지시로 구체화하고, 연결된 영상 모델에 전달한다. 사용자가 기술 프롬프트를 따로 작성할 필요는 없다.
- 기존 Higgsfield CLI는 지정 제작 계정으로 인증됐고, 실제 모델 목록·스키마 조회에 성공했다. `gemini_omni_flash_1_1`을 텍스트 의도 해석과 대화 연기의 첫 검증 후보로 준비한다. 우리 대본으로 비교 생성한 결과는 아직 없다.
- 구독 경로의 잔액은 0.92 크레딧. 8초·1080p·9:16 텍스트 영상 견적은 36 크레딧으로 생성하지 않았다. 견적 확인은 영상 생성 성공이 아니다.
- 별도 Open Higgsfield API 계정은 사용자 로그인·초기 설정 완료 후, 사용자의 “전용 키 발급하고 연결해줘” 승인으로 `SYNK LAB · Codex` 키를 발급했다. 키는 Windows 자격 증명 보관소에 저장했고 웹에서 Active를 확인했다. API 잔액은 $0.00이다. API 잔액과 구독 크레딧은 별도로 기록한다.
- 저장된 키로 공식 Seedance 2.5 견적 API를 호출해 HTTP 200을 받았다. [검증 기록](open-api-connection-check.json), [상황 문맥을 담은 요청 본문](open-api-pilot-request.json), [활성 상태 화면](api-connected.png). 응답은 고정 금액이 아닌 토큰당 요금 설명이었다. 견적 요청만 실행했으며 영상 생성·지출은 없다.
- Open API의 `Omni` 검색에는 Kling O1만 나왔고 Google Gemini Omni 1.1은 확인되지 않았다. 구독 CLI에서의 Omni 1.1 제공과 혼동하지 않는다. API 연결 시험에 Seedance 2.5를 쓴 것은 실사판의 최종 모델을 바꾸거나 영상 생성을 실행한 결정이 아니다.
- 신규 결제·구독·자동충전은 하지 않는다. 자격증명은 회차 폴더·Git·미리보기 페이지에 저장하지 않는다.

### 당시 연결의 저장·인증 방식

Windows 자격 증명 이름은 `SYNK/SNS/higgsfield/open-api`다. 기존 `tools/sns-자격.ps1`을 사용하되, `get` 결과를 터미널에 출력하지 않고 로컬 Node 자식 프로세스의 반환값으로 받아 메모리 안에서만 쓴다. 형식은 `KEY_ID:KEY_SECRET`, 공식 REST 인증은 `Authorization: Key <값>`이다. [공식 인증 문서](https://docs.higgsfield.ai/docs/authentication)를 따른다. 별도 MCP 서버나 에이전트 실행기는 추가하지 않았다.

API에서 확인한 영상 모델은 `bytedance/seedance-2.5/text-to-video`이며, [모델별 문서](https://console.higgsfield.ai/models/bytedance/seedance-2.5/text-to-video/api-reference)의 해상도는 480p·720p, 길이는 4–30초, 음성 생성은 `generate_audio: true`다. 준비된 요청은 8초·720p·9:16·MP4·음성 포함이다. 견적 주소는 `https://api.higgsfield.ai/estimate/bytedance/seedance-2.5/text-to-video`다. 최종 생성 전에는 실제 잔액·모델 제공 상태를 다시 확인한다. 현재 확인 범위는 키 발급·안전한 저장·인증된 견적 응답까지이며, 완성 영상과 한국어 연기 품질은 아직 검증 전이다.
