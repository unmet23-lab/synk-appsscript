## 이전 버전 편집 원본

`mongle-video/`는 HyperFrames 편집 프로젝트다. `timing.json`은 실제 대사·장면 시간, `captions.ko.srt`는 자막이다. `assets/provenance.json`에 승인 마스코트·로고·서체·생성 배경·음성·효과음의 출처를 적었다. 기존 4K 원본을 변경하지 않았다.

`build-mongle.cjs`가 장면과 자막을 구성한다. HyperFrames 0.8.77에서 `npm run check`, `npx hyperframes render --quality delivery --fps 30 --output '..\SYNK_LAB_카페_몽글_한국어_v1.mp4'`로 원본 렌더를 만든다. 전달 MP4는 원본 영상 스트림을 유지하며 FFmpeg `volume=3.5dB`, AAC 192k, `+faststart`를 적용한 버전이다.

대본 최초 기획은 `대본_초안.md`, 실제 제작 구성은 `mongle-video/STORYBOARD.md`를 참고한다.
