# SYNK LAB · 못 들었는데 “네”부터 나왔다

2026-09-26 · 사용자가 선택한 소재는 **카페에서 “다시 말해 주세요” 배우기**, 형식은 **짧은 상황극 영상**이다. 몽글 캐릭터판과 AI 실사 인물판 모두 제작하며 중간 시안 승인 없이 완성 영상으로 확인하기로 했다. 몽글판은 47.6초 한국어 영상으로 제작됐다. 실사판은 지정 제작 페이지 접근 복구를 기다린다. 아래 예상 시간은 최초 기획 기록이며 실제 몽글판 시간표는 `mongle-video/timing.json`이다. 번역·게시 전이다.

## 이번 편에서 얻는 것

한국어 초급 학습자가 상대의 말을 잘 못 들었을 때 **“다시 말해 주세요.”**라고 부탁한다. 처음부터 모든 대사를 해석하는 수업으로 만들지 않고, 상황과 반응으로 핵심 표현의 쓰임을 보여준다.

한국어 원본을 먼저 검토한다. 국가별 게시본은 원본 확정 후 상황 안내·뜻·참여 안내를 해당 언어로 제작한다. 이번 문서에는 번역 완료나 게시 계정을 가정하지 않는다.

## 대사와 장면

예상 46초, 세로 9:16. 시간은 연출 가늠값이며 음성 제작 후 조정한다. 대사는 손님·직원·안내로 구분한다. 안내는 캐릭터 고유 대사가 아니다.

| 예상 시간 | 대사·소리 | 화면·행동 |
|---|---|---|
| 0–4초 | 직원: “드시고 가세요, 가지고 가세요?” / 손님: “네!” | 카페 카운터. 손님은 반사적으로 한 번 끄덕인다. 직원은 재촉하거나 비웃지 않고 편하게 기다린다. 실제 말하는 대사만 자막으로 표시한다. |
| 4–7초 | 손님 속마음: “어? 나 방금 뭐라고 한 거지?” | 손님의 얼굴 가까이. 고개가 멈추고 시선이 잠깐 옆으로 향한다. 작은 “…?” 말풍선. 학습자에게 오답 표시나 경고음을 붙이지 않는다. |
| 7–11초 | 안내: “잘 못 들었을 땐, 이렇게 말해 보세요.” | 카페 장면의 움직임이 잠깐 멈춘다. 손님의 얼굴과 다음에 할 말에 시선을 모은다. |
| 11–14초 | 손님: “다시 말해 주세요.” | 표현을 실제 발화와 함께 처음 보여준다. “다시 / 말해 주세요”의 두 의미 덩어리를 차례로 강조한다. 음절 단위로 끊어 읽지 않는다. |
| 14–18초 | 안내: “한 번 따라 말해 볼까요?” / 안내가 끝난 뒤 약 2.5초 여백 | 예문을 유지한다. 카운트다운과 채점은 없다. 손님이 편안하게 기다린다. |
| 18–23초 | 짧은 되감기 효과음. 직원: “드시고 가세요, 가지고 가세요?” | 컵과 고갯짓이 짧게 뒤로 움직여 첫 질문으로 돌아온다. 실제 학습 발음에는 되감기·왜곡 효과를 적용하지 않는다. |
| 23–26초 | 손님: “다시 말해 주세요.” | 이번에는 끄덕이기 전에 상대를 보고 부탁한다. |
| 26–31초 | 직원: “여기서 드세요? 가져가세요?” / 손님: “여기서 먹을게요.” | 직원이 카페 자리와 포장 컵을 각각 가리킨다. 손님이 빈 테이블을 가리킨다. 풀이된 질문은 같은 뜻을 더 쉽게 말한 상황 대사다. |
| 31–35초 | 직원: “영수증 드릴까요?” / 안내: “이번엔 직접 말해 보세요.” | 영수증을 살짝 들어 보여준다. 손님은 시청자를 바라본다. 핵심 예문·첫 단어 힌트·뜻을 모두 숨긴다. |
| 35–40초 | 말하기 여백 5초. 낮은 카페 환경음만 유지 | “잘 못 들었어요. 다시 부탁해 볼까요?”라는 상황 안내만 표시한다. 시간 압박 없이 기다린다. |
| 40–43초 | 손님: “다시 말해 주세요.” | 말하기 여백이 끝난 뒤 예문을 다시 보여준다. |
| 43–46초 이후 | 직원: “영수증 필요하세요?” / 손님: “아, 괜찮아요. 감사합니다!” | 손님이 웃으며 작게 손사래를 한다. 승인 LAB 로고로 마무리한다. 실제 발음 길이가 길면 종료 시점을 늘린다. |

## 연출에서 지킬 점

- 웃음은 손님의 반사적인 고갯짓과 잠깐의 멈춤에서 만든다. 서툰 발음이나 외국인 정체성을 웃음의 대상으로 만들지 않는다.
- 직원의 첫 질문은 자연스러운 속도다. 일부러 알아들을 수 없을 만큼 빠르게 하거나 발음을 뭉개지 않는다.
- 핵심 표현은 정중한 부탁의 한 가지 예시다. 다른 자연스러운 표현을 틀렸다고 판정하지 않는다.
- 되감기는 이야기의 두 시도를 잇는 짧은 동작이다. 대사와 자막이 읽히는 동안 과도한 움직임을 넣지 않는다.
- 연습 시간을 확보한다. 실제 음성 길이가 길어지면 영상을 늘리며, 말하기 여백부터 줄이지 않는다.
- 로고·캐릭터는 승인 자산을 사용한다. 한국어는 SUIT, 현지화 글자는 해당 문자를 지원하는 승인 서체를 사용한다.
