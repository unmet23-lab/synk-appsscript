# PULSE AI 프로필 · 크몽 등록 준비

2026-10-01. 사용자 요청: 인터뷰 원본 사진 몇 장으로 현재 PULSE 유호 모델처럼 프로필 사진을 만드는 서비스 추가 준비. 후속 요청에 따라 사진 제작 후 바로 활용할 PPT 양식 제공과 소개 PPT 완성 작업까지 포함한다.

담당 원고는 [service.json](service.json)이다. 가격·구성은 제안이며 실제 판매 조건 확정 전이다. [미리보기](미리보기.html)는 샘플과 판매 구성 검토용이다. 실제 크몽 서비스 입력·임시저장·심사 제출·판매 시작, 자동 생성 웹앱 배포는 하지 않았다.

## 제공 방식

고객이 사진 3~5장, 용도·스타일, PPT에 넣을 소개 내용을 크몽 메시지로 전달 → 얼굴 참조에 적합한 원본 확인 → 실제 AI 도구·사진 처리 조건 안내 → 대표 시안 확인 → 나머지 컷 제작·검수 → 소개 내용을 다듬어 사진과 함께 PPT 배치 → 사진·PPT 취합 수정 → 최종 JPG·크롭·완성 PPTX/PDF·편집용 양식 전달. 고객이 직접 AI 도구를 조작하거나 얼굴 학습 모델을 만들 필요가 없는 제작 대행 서비스다. 실제 촬영은 포함하지 않으며 기존 광고·룩북과 별도 상품으로 준비한다.

| 제안 | 가격 | 콘셉트 | 최종 컷 | 대표 시안 | 완성 PPT | 납기 | 수정 |
|---|---:|---:|---:|---:|---:|---:|---:|
| STANDARD | 39,000원 | 1 | 3 | 2 | 3장 | 3일 | 1회 |
| DELUXE | 79,000원 | 2 | 6 | 4 | 5장 | 5일 | 1회 |
| PREMIUM | 149,000원 | 3 | 10 | 6 | 7장 | 7일 | 2회 |

1명 기준. 콘셉트는 옷·배경·조명 한 조합. 시안 후보는 납품 컷과 별개이며 선택해 완성한 컷만 최종 수량에 포함한다. 정사각형 크롭은 같은 사진의 활용 파일로 최종 컷 수에 더하지 않는다. 납기는 실제 착수일과 피드백 일정을 확인할 때 확정한다.

## PPT 양식과 완성 작업

모든 패키지에 **7가지 편집용 양식**을 제공한다. 완성 작업은 표지 포함 3/5/7장이다. 고객 제공 문구를 짧게 다듬고 확인된 경력·서비스·사례·공개할 연락처와 납품 사진을 배치한다. 없는 항목은 용도에 맞게 다른 장으로 조정한다. 장문 원고 신규 집필·자료 조사·별도 브랜드 디자인·애니메이션·추가 장수는 별도 협의한다. 사진과 PPT 피드백은 같은 수정 회차로 취합한다. 제안 가격은 이전 값으로 유지했으며 PPT 작업 시간을 포함한 실제 원가 확인 전이다.

- [편집용 양식 7장](ppt/output/AI_프로필_소개자료_양식.pptx): 표지·짧은 소개·주요 경력·제공 서비스·작업 사례·진행 방식·연락처.
- [유호 완성 예시 5장](ppt/output/유호_프로필_소개자료_예시.pptx): 이번 AI 사진 3종과 소개 문구를 넣은 내부 예시. 문구와 본인 인상은 공개 전에 확인한다.
- [공유용 PDF](ppt/output/유호_프로필_소개자료_예시.pdf): 글꼴 설치 없이 볼 수 있는 이미지 기반 PDF. 편집과 검색은 PPTX 사용.
- [사용 안내](ppt/output/PPT_사용안내.txt): 글·사진 교체, 장 선택, 페이지 번호, SUIT 글꼴과 라이선스.

16:9, 1280×720 기준. 글은 네이티브 텍스트 상자, 사진과 로고는 개별 그림으로 넣었다. 완성 예시의 글을 이미지로 평면화하지 않았다. 글꼴이 다른 환경에서는 동봉한 SUIT Variable을 설치하거나 PPT에서 사용 가능한 글꼴로 바꿔 줄바꿈을 확인한다. PowerPoint/Google Slides에서 실제 열기·편집은 별도 검증 범위다.

제작은 `ppt/.build/build.mjs`와 번들 `@oai/artifact-tool`, 파일 검증은 스킬 finalizer, PDF와 네이티브 편집 구조 확인은 `ppt/.build/share-and-verify.py`. 검증 영수증·각 장의 렌더는 `ppt/review/`에 있다. 기존 출력 파일을 덮어쓰지 않는 finalizer이므로 디자인 수정 시 새 최종 파일명을 지정한다.

## 샘플과 제작 근거

- 기존 PULSE의 `roster-v2.json`에서 유호가 실존 창업자 기반 모델임을 확인했다. 현재 대표 사진은 `M-yuho-hero-v5.png`다. 과거 README의 후보 5 설명과 최신 roster가 다르므로 실제 선택은 roster를 기준으로 확인했다.
- 2026-10-01 CLI에서 별도 `Yuho-PULSE` Soul 학습 모델은 `queued`였다. 이번 샘플은 이를 사용하거나 다시 학습하지 않았다.
- 이번 입력은 `../PULSE_AI모델_캐스팅_20260930/raw/yuho-ref-0048.png`, `yuho-ref-0112.png`, `yuho-ref-0136.png`의 인터뷰 원본 프레임 3장이다. 이미 생성한 캐스팅 얼굴을 입력하지 않았다.
- **2026-10-01 유호님 결정:** 유호님 얼굴이 나오는 사진·영상은 확정 얼굴만 쓴다([고정 얼굴 세트](../제작양식/실제얼굴_화보_뮤직비디오.md#고정-얼굴-세트)). 이 예시 3장은 인터뷰 원본으로 만들어서 확정 얼굴이 아니다. 공개·판매 자료에 쓰기 전에 확정 얼굴로 다시 만들지 유호님께 확인한다.
- 지시는 [samples.json](samples.json), 실행은 [generate-samples.cjs](generate-samples.cjs), 완료 응답은 `jobs/`, 이미지 원본은 `samples/`에 보관한다. Nano Banana Pro, 3:4, 2K. 스튜디오·비즈니스·크리에이터 3가지 신규 장면이다.
- 내부 시안이며 고객 사례나 유호의 얼굴 동일성 승인으로 표시하지 않는다. 미리보기에는 입력 원본과 신규 결과를 나란히 둔다. 눈매 비대칭·얼굴 폭·코·입·자연스러운 피부와 헤어를 직접 비교하고, 본인 인상에 대한 최종 판단은 유호 피드백으로 확인한다.

## 고객 접수와 운영

크몽 입력용 FAQ 6개와 필수 요청 4개는 `service.json`에 있다. [고객_준비안내.txt](고객_준비안내.txt)는 메시지에 붙일 사진·PPT 자료 준비 안내다. 기존 영상 발주서·온라인 접수·캐스팅북은 수정하지 않았다. 이 폴더는 고객 사진 자동 업로드/생성 앱이 아니다.

얼굴 참조 생성과 개인별 얼굴 학습은 구분한다. 고객 사진을 PULSE 공용 캐스팅·다른 고객 제작·홍보에 재사용하는 동의는 받지 않은 것으로 취급한다. 첫 출시 범위는 성인 1명이다. PPT에는 공개할 이름 또는 활동명과 소개 내용만 받으며 실명 확인은 요구하지 않는다. 생년월일·신분증은 받지 않는다. 연락처는 고객이 공개를 원할 때만 넣는다.

실제 고객용 경로는 현재 쓰는 Google Cloud 이미지 생성 경로를 우선 검토하고, 작업 전 제공사·국외 처리 여부·입력과 결과의 이용/보관 조건·SYNK 보관 및 삭제 시점을 고객에게 안내한다. 아직 고정된 고객 데이터 처리 운영이 있는 것처럼 쓰지 않는다. 무료 소비자 앱과 Cloud API 약관을 혼용하지 않는다.

Higgsfield의 현재 정책 §2.3에는 업로드/입출력을 서비스 개선·AI 모델 학습에 활용할 수 있다는 설명이 있고, §5.9에는 삭제 후 서버/백업 보관 조건이 있다. 따라서 ‘외부 학습에 절대 사용되지 않는다’, ‘도구 서버까지 즉시 완전 삭제’ 같은 문구를 쓰지 않는다. 이번 유호 내부 샘플은 Higgsfield 경로이며 고객용 경로가 확정됐다는 증거가 아니다. Google Cloud의 학습 제한과 보관 예외도 별개여서 ‘학습 제한 = 무보관’으로 해석하지 않는다.

SYNK 직접 보관분은 주문 확인·수정·재전달에 필요한 기간과 삭제 방법을 첫 판매 전에 정하고 기록한다. 현재 자동 삭제 기능을 구현하거나 삭제 실행을 확인한 것은 아니다. 거래 증빙과 이미지 파일 보관은 구분한다. 판매 조건에 삭제 기한을 명시했다면 해당 날짜에 직접 보관 파일과 외부 도구의 삭제 요청 결과를 각각 확인한다.

원가 검증: 제안 가격은 시장 평균이나 수익 보장값이 아니다. 첫 3건에서 상담·원본 확인·후보 생성·검수·소개글 정리·PPT 배치·수정 시간과 도구 사용 비용을 기록한다. 채택하지 않은 재생성도 원가에 포함하고, 플랫폼 수수료는 실제 정산 조건으로 확인한다. 이번 3개 샘플만으로 10컷 주문의 납기·수익성을 검증했다고 하지 않는다.

## 등록 자료와 확인할 것

- 메인이미지: 652×488 PNG, 유색 배경, 주요 요소 50px 이상 여백. 상세 4장: 원본/결과·3가지 용도·진행과 제공 파일·PPT 양식과 완성 작업.
- 카테고리 후보는 `디자인 > AI 디자인 > AI 보정·누끼·합성`. 실제 등록 화면은 확인 전이라 필수 도구 선택지·첨부 규격·제목 제한·시안 입력칸을 확정값으로 쓰지 않는다.
- 제목·패키지·본문·진행·수정·FAQ·사전 요청은 [등록_붙여넣기.txt](등록_붙여넣기.txt)에서 순서대로 복사한다. 최종 등록 때 제안 상태 문구를 실제 확정 값으로 바꾸고, 심사 제출 전에 고객용 사진 처리 안내를 고정한다.
