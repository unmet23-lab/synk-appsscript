SYNK PULSE · AI 프로필 소개 자료

1. 완성 예시
유호_프로필_소개자료_예시.pptx: 사진과 소개글을 넣은 5장 예시입니다.
유호_프로필_소개자료_예시.pdf: 별도 글꼴 설치 없이 볼 수 있는 공유용 5장 PDF입니다. 이미지 기반 PDF이므로 편집과 텍스트 검색은 PPTX를 사용하세요.
유호 소개글은 이번 서비스의 내부 검토용 초안입니다. 공개 전에 본인 인상과 문구를 확인해주세요.

2. 편집용 양식
AI_프로필_소개자료_양식.pptx: 표지 / 짧은 소개 / 주요 경력 / 제공 서비스 / 작업 사례 / 진행 방식 / 연락처의 7가지 양식입니다.
STANDARD 3장 권장: 1·2·7번
DELUXE 5장 권장: 1·2·4·5·7번
PREMIUM 7장 권장: 전체
개인 용도에 맞게 순서를 바꾸고 필요 없는 장은 삭제하세요. 삭제 후 하단 페이지 번호도 바꿔주세요.

3. 글과 사진 바꾸기
대괄호 안 예시 문구를 실제 소개 내용으로 바꾸세요. 글은 클릭해 직접 편집할 수 있습니다.
양식의 사진 자리 상자를 삭제하고 '삽입 > 그림'으로 납품 사진을 넣으세요. 표지 사진은 세로 3:4를 권장합니다.
예시의 사진은 개별 그림으로 삽입되어 있습니다. 사용하는 PowerPoint의 '그림 변경' 기능 또는 삭제 후 그림 삽입으로 교체하세요.
로고와 실땀도 개별 그림입니다. 고객 로고로 교체하거나 원하지 않으면 삭제할 수 있습니다.
슬라이드별 발표자 노트에 권장 문구 길이와 사용 안내가 있습니다.

4. 글꼴
SUIT Variable을 사용했습니다. 글꼴이 대체되면 fonts/SUIT-Variable.ttf를 직접 설치한 뒤 PPT를 다시 열어주세요.
SIL Open Font License는 fonts/LICENSE_OFL.txt에 포함했습니다. 글꼴은 무료 배포 라이선스에 따라 함께 제공합니다.
PPTX에 글꼴을 내장했다고 보장하지 않습니다. 글꼴 설치가 어려우면 PowerPoint에서 맑은 고딕 등 사용 가능한 글꼴로 바꾸고 줄바꿈을 확인해주세요. 즉시 보기·공유에는 PDF를 쓰세요.

5. 서비스 범위
모든 패키지에 편집용 양식 7가지를 제공하며, 제공한 소개 내용과 납품 사진을 배치한 완성 PPT 3/5/7장(표지 포함)을 만들어드립니다.
공개할 활동명·직함·소개글·경력·서비스·작업 사례·연락처를 보내주세요. 없는 항목은 용도에 맞게 조정합니다.
소개글을 짧게 다듬되 경력·자격·성과 수치는 임의로 만들지 않습니다. 장문 원고·자료 조사·추가 장수·별도 브랜드 디자인은 별도 협의입니다.
사진은 AI 생성 이미지이며 실제 고객 납품이나 본인 얼굴 승인 사례가 아닙니다.

확인 범위: 파일 구조·편집 가능한 글과 그림·12개 슬라이드 렌더·PDF 5페이지 확인. 실제 Microsoft PowerPoint와 Google Slides에서의 열기·편집은 별도 확인이 필요합니다.
