## 다시 만들기와 렌더

```bash
cd docs/마케팅/LAB표현소개_아맞다_20260927/kit-v1
node ../../../../tools/SNS키트_영상연결.js .      # 키트 사본(assets/synk-kit/, git 제외)
python 미디어준비.py                               # 소리·Veo 구간·몽글 컷 3장(이미 있으면 같은 결과로 덮어씀)
npx --yes hyperframes@0.8.104 check
npx --yes hyperframes@0.8.104 snapshot --describe false --at 0,1.2,2.5,3.3,5,6.9,8.9,11,13.2,14.8,16.3,18,19.25 --against ../게시/01-lab-youtube/video.mp4
```

렌더(사용자가 미리보기를 보고 렌더하기로 정한 뒤에만):

```bash
npx --yes hyperframes@0.8.104 render --quality delivery --fps 30 --output renders/SYNK_LAB_아맞다_EP01_kit-v1_EN.mp4
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate -of compact renders/SYNK_LAB_아맞다_EP01_kit-v1_EN.mp4
ffmpeg -i renders/SYNK_LAB_아맞다_EP01_kit-v1_EN.mp4 -af ebur128=peak=true -f null -   # v2는 −14.1 LUFS · TP −1.5
```

렌더하면 오디오가 다시 AAC로 인코딩된다. 렌더 뒤 길이(19.3초)와 음량이 v2와 같은지 위 두 줄로 확인한다. 다르면 렌더한 영상에 원본 오디오를 다시 붙인다: `ffmpeg -i <렌더>.mp4 -i assets/media/mix_en.m4a -map 0:v -map 1:a -c copy <최종>.mp4`.

## 사용자가 정할 것 · 남은 것

1. 미리보기를 보고 렌더할지(`npx hyperframes preview --background`로 열 수 있다).
2. 끝 장 나누기: v2는 「Send this to a friend who always forgets」 줄이 16.47초에 같은 화면에 나왔다. 키트판은 5 내 차례(15.77~17.10)와 6 끝(17.10~)으로 나눠 보내기 줄이 17.45초에 나온다. 5장이 1.3초라 빈칸 카드를 읽을 시간이 짧다.
3. AI 표시 문구: 영어판이라 “AI example image”로 적었다. 공통 규칙의 한국어 문구 “AI 예시 이미지”로 바꿀지.
4. 2장 제목 “The moment you remember it”과 라벨들은 v2에 없던 문구다(키트 견본에서 가져옴).
5. 게시 묶음(`../게시/`)과 `계획.json`은 v2 그대로다. 키트판으로 올리려면 렌더 뒤 게시 묶음을 따로 바꿔야 한다.
