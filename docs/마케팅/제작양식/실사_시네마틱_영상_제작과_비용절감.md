# 실사 시네마틱 영상 제작과 비용 절감

## 현재 제작의 입구

현재 AI 영상·이미지는 [만족 사례 장부](만족사례_장부.md)의 가장 가까운 채택 사례에서 시작하고 [AI 운영 원칙](../../AI_운영원칙.md)의 담당·도구·비용을 따른다. AI 광고·홍보영상은 10-16 [전용 제작 규칙](AI광고영상_제작규칙.md)의 전부 AI 방식을 적용한다. 아래 10-04·10-06의 실제 촬영/스톡 우선 절차를 새 광고에 강제하지 않는다.

유호님 얼굴은 장부 S02의 확정 B·C와 실제 사진이 원천이다. `YUHO`·`Yuho-Approved-360` Soul ID는 당시 시도 기록이며 현재 기본 얼굴 제작 경로가 아니다. 실사 시작 그림·마스코트는 장부와 AI 운영 원칙의 이후 결정을 우선한다. 새 작업에서 Soul 학습·유료 구독·클라우드 렌더를 이 문서만 보고 시작하지 않는다.

아래에는 9월 30일~10월 6일의 제작 제안·비교 견적·실제 차감을 보존한다. 빛·연속성·재생·청취의 관찰 기준과 비용 산식은 참고할 수 있지만, 당시 모델·가격·행사·잔액·계정·설치 경로·작업 대기는 현재 상태를 보증하지 않는다. 한강 후속 작품은 [프로젝트 입구](../한강2126_포트폴리오_20260930/README.md)에서 찾는다.

## 2026-10-06 기록 — 광고·모델 영상의 반복 제작 제안

당시 유호님 작업 조건: 월 **6~15편**, 완성본 **20~30초**, 실사/Pexels 참조, GPT·Claude가 감독 역할, 이미지 콘티를 만든 뒤 Wan·Gemini Omni·Seedance로 필요한 컷 생성. 아래는 그때의 제작 제안과 검수 기준이며 현행 제작 통로·담당 배정은 위 원문을 따른다.

**실행 도구:** [실사 영상 제작 체크 열기](../../../tools/film-check/dist/SYNK_실사영상_제작체크.html) · [사용법](../../../tools/film-check/README.md). HTML 한 파일을 브라우저에서 열어 쓴다. 실제 품질의 자동 판정이 아니라, 준비 누락·사람이 남긴 검수·크레딧 기록을 관리한다.

### 실행 순서

| 순서 | 할 일 | 다음 단계로 가기 전 확인 |
|---|---|---|
| 1. 볼 이유 결정 | 시청자, 남길 메시지 한 가지, 얻을 정보·감정, 제품/인물, 비율과 길이를 정한다. | 첫 장면부터 마지막 행동까지 이유가 있는가? |
| 2. 실제 자료 선별 | 실제 촬영·스톡으로 쓸 컷을 먼저 찾는다. 인물/제품 원본과 빛/질감/카메라 참고를 나눈다. | 원본 위치, 참조할 요소, 실제 사용할 구간이 적혔는가? |
| 3. 샷 목록 작성 | 20초는 이야기 묶음으로 보고 필요한 구도로 나눈다. 샷마다 시작 상태 → 주요 행동 → 끝 상태를 쓴다. | 앞뒤 컷의 시선·손·제품 위치와 화면 방향이 이어지는가? |
| 4. 이미지 콘티 승인 | 전체 콘티와 함께 각 샷의 개별 원본 이미지를 준비한다. 인물·제품·빛·구도를 먼저 검수한다. | 시작 자세가 행동 가능한 자세인가? 여러 컷을 붙인 작은 콘티를 입력 원본으로 오인하지 않았는가? |
| 5. 어려운 한 컷 시험 | 손과 제품의 접촉, 얼굴 클로즈업, 걷기 등 실패 시 영향이 큰 컷부터 만든다. | 실제 재생에서 연기·접촉·형태가 성립하는가? |
| 6. 필요한 샷 생성 | 같은 기준 자료와 조건을 이어 쓴다. 후보마다 바꾼 조건과 차감 비용을 기록한다. | 후보 중 쓸 구간을 골랐는가? 고칠 때 원인과 수정 지시가 구체적인가? |
| 7. 편집과 후반 작업 | 동작·시선·리듬을 이어 붙이고 피부색·노출·제품색·질감·음향을 맞춘다. | 서로 다른 모델/실사의 컷이 같은 작품처럼 보이는가? |
| 8. 최종 출력 검수 | 실제 출력 파일 전체를 소리와 함께 정상 속도로 보고, 휴대폰 크기도 확인한다. | 로고·문구·크롭·첫/끝 프레임·오디오가 의도대로인가? |

샷당 4~6초는 작은 행동을 시험하기 좋은 출발점이며 의무가 아니다. 긴 호흡의 연기가 필요하면 긴 샷을 쓴다. 여러 구도는 같은 배우·제품·세트 기준으로 별도 샷을 설계하는 것이 기본이다. 모델의 멀티샷 기능은 실제 동시 촬영이나 완벽한 연속성을 보장하지 않는다.

예: 20초 향수 광고는 `공간 4초 → 제품을 드는 손 5초 → 시선과 작은 반응 6초 → 제품 마무리 5초`처럼 나눈다. 각 숫자는 편집에서 사용할 길이다. 생성 가능 길이에 맞추고 필요하면 앞뒤 여유를 확보한다.

### 자연스러움을 판단하는 관찰 기준

| 관찰 대상 | 확인할 것 | 다시 작업할 신호 |
|---|---|---|
| 빛과 공간 | 주광의 위치·크기·색, 피부와 배경의 노출, 접촉 그림자, 거울·유리·금속 반사 | 얼굴만 다른 방향으로 밝음, 물체가 바닥에서 뜸, 반사가 시간에 따라 사라짐 |
| 카메라와 구도 | 시점·거리·원근·심도, 움직임의 동기, 초점 이동, 모션블러 | 제품 크기가 이유 없이 바뀜, 배경이 늘어남, 초점이 반복적으로 흔들림 |
| 피부와 소재 | 자연스러운 피부 변화, 머리카락의 덩어리와 잔머리, 천·유리·금속의 차이 | 밀랍 피부, 과장된 모공, 플라스틱 천, 모든 표면의 같은 광택 |
| 인물 연기 | 바라보는 대상, 행동 이유, 무게중심, 호흡, 손의 목적, 작은 감정 변화 | 이유 없는 미소·고개 흔들기, 반복되는 눈깜박임, 발 미끄러짐, 손과 소품의 관통 |
| 시간과 연결 | 같은 얼굴·의상·제품, 손가락과 그립, 소품 수, 방향, 컷 전후의 행동 | 중간에 다른 얼굴, 로고 변화, 물건 순간 이동, 연결되지 않는 손 위치 |
| 소리 | 대사 내용·발음·입모양, 물체 접촉음, 공간감, 음악과 대사의 균형 | 입모양과 발음 불일치, 접촉 전에 효과음, 컷마다 공간음 급변 |

`35mm`, `24fps`, `180도 셔터`, 부드러운 빛, 얕은 심도 자체를 합격 조건으로 삼지 않는다. 연출에 맞는 원근·움직임·빛이 **결과 화면에서** 성립하는지가 기준이다. 고해상도·업스케일·그레인만으로 얼굴 변화나 잘못된 물리를 고칠 수는 없다.

이미지 합격과 움직이는 영상 합격은 별개다. 정상 속도로 채택 구간 전체를 보고, 의심 구간만 느리게 보거나 프레임으로 확인한다. `00:03.2 — 오른손 엄지가 병을 관통함`처럼 관찰을 남긴다. 얼굴·제품·물리의 중요한 오류를 다른 항목 점수로 상쇄하지 않는다. 해당 없는 항목은 이유를 기록한다.

### GPT·Claude에게 맡길 감독 지시

> 이 작품의 감독 겸 연속성 검수자로 작업하라. 먼저 시청자가 볼 이유와 남길 메시지를 확인하라. 첨부 자료를 인물·제품의 정체성 원본, 빛·질감 기준, 카메라·동작 참고, 실제 편집 소스로 구분하라. 20초 단위를 필요한 샷으로 나누고 샷마다 목적, 시작 상태, 행동과 감정 변화, 끝 상태, 광원, 구도·이동·초점, 소리, 다음 컷 연결을 작성하라. 승인 원본과 충돌하면 지적하라. 가장 까다로운 한 컷부터 시험하도록 제안하라. 결과는 실제로 본 범위에서만 평가하고, 정지 이미지 확인·영상 재생·음향 청취를 구분하라. 실패 시 타임코드와 현상을 기록하고 다음 후보에서 바꿀 조건을 구체적으로 제안하라. 생성 성공을 자동으로 품질 통과로 처리하지 말라.

앱의 샷별 지시문을 이 공통 지시와 함께 사용한다. 한 샷에 넣을 참조 수·지원 입력·길이·해상도는 선택 모델의 실제 화면에서 확인한다. 프롬프트에 금지 조건을 적었다고 결과가 보장되지는 않는다.

**이 장면은 Soul로 만든 얼굴이라는 근거가 없다.** 본인 얼굴 승인 이미지도 Soul 학습 결과가 아니다. 따라서 비슷한 품질을 얻기 위해 Soul부터 결제·학습할 필요는 없다. 다만 텍스트만으로 새 인물을 만든 방법은 **본인 얼굴 유지**에 그대로 적용할 수 없다. 주연 컷에는 승인 얼굴과 구도 참조를 유지한다.

### 사진에서 가져올 것은 무엇인가

- 창 쪽은 밝고 반대쪽 얼굴은 충분히 어둡다. 얼굴 전체에 균일한 미용 조명을 깔지 않는다.
- 작은 시선 변화와 짧은 미소가 있다. 카메라를 계속 의식하며 웃는 광고 모델 표정이 아니다.
- 피부의 색 차이, 비대칭, 잔머리와 옷의 주름이 자연스럽다. 모공을 과장해서 새기는 것은 목표가 아니다.
- 사람과 배경이 같은 방향의 빛을 받는다. 창가 배경만 화려하고 얼굴이 다른 조명에 떠 있으면 실패다.
- 인물에게 실제 할 일이 있다. 펜을 움직이고 동료를 바라보는 짧은 행동이 공간의 용도를 설명한다.

이것은 이미지 관찰과 제작상의 판단이다. 어느 한 프롬프트 문구가 품질 향상의 원인이라고 분리 실험한 것은 아니다. 필름 그레인·색보정·업스케일은 잘못된 손, 다른 얼굴, 무중력 커피를 고치지 못한다.

| **Soul ID** | 실제 한 사람의 사진으로 반복 사용할 인물 정체성 학습 | 승인 사진만으로 부족하고 여러 각도·여러 작품에 같은 본인이 필요할 때 선택 |
| **Soul 2 / Soul Cinema** | 정지 이미지 생성. Cinema는 영화 프레임 같은 구도와 빛을 위한 후보 | 시작 이미지가 없거나 못 쓸 때. Soul Cinema 자체가 영상 모델은 아님 |
| **이미지 편집 모델** | 기존 구도·얼굴·소품을 유지하며 필요한 부분 수정 | 승인 콘티에서 질감이나 시작 자세만 고쳐야 할 때. 지원되는 참조 편집 기능 사용 |
| **Elements** | 인물·건물·마스코트·소품을 이름 붙여 재사용 | 모델/UI가 지원할 때 필요한 참조만 지정 |

| **Kling 3.0 / Turbo** | 영상 생성의 다른 선택지 | 작은 고개 돌림·손동작 등 단순 컷의 저렴한 비교 후보. 우리 얼굴·질감 기준 통과는 아직 미검증 |
| **Cinema Studio** | 카메라·조명·색·속도·참조를 함께 설정하는 제작 화면 | 촬영 설정을 시각적으로 관리할 필요가 있을 때. 별도의 필수 후처리 단계는 아님 |
| **DaVinci Resolve 무료판 / FFmpeg** | 컷 편집, 리듬, 색, 음향, 로고·게임 화면 합성, 출력 | 생성이 끝난 소스를 작품으로 만드는 단계 |

Astra에서 도구를 연결해 Higgsfield 작업을 준비할 수 있지만 실제 파일 생성은 연결된 도구가 수행한다. **Astra 사용 한도와 Higgsfield 생성 크레딧은 별개**다. 이미 사용하는 대화 환경에서 기획을 끝내면 같은 기획을 유료 에이전트에서 반복할 이유가 줄어든다. [OpenAI 도구 사용 안내](https://developers.openai.com/api/docs/guides/tools)

Soul HEX는 참고 색상을 옮기는 기능이다. 얼굴·표정·연기 복제로 이해하지 않는다. 공식 도움말상 Soul 계열에서는 일반 참조 이미지를 붙이면 프롬프트 입력이 비활성화되는 조합이 있으므로, **원래 콘티 + Soul ID + 긴 수정 프롬프트가 언제나 동시에 되는 것으로 안내하지 않는다.** [Soul 사용법](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-to-generate-images) · [Soul Cinema](https://higgsfield.ai/soul-cinema)

Cinema Studio 4.0 도움말은 Seedance 2.5 기반과 Director’s Panel을 안내한다. 공식 페이지끼리도 최대 길이·해상도 설명이 다르므로 **현재 선택된 모델과 화면의 허용값·비용을 최종 기준**으로 한다. 숫자가 큰 모델이나 4K 설정만으로 더 자연스러운 배우가 만들어지는 것은 아니다. [Cinema Studio 도움말](https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-cinema-studio)

## 3. 가장 적은 추가 비용으로 만드는 순서

### 경로 A — 지금 프로젝트에 우선 적용

**이미 가진 소스 확인 → 승인 얼굴·콘티 재사용 → 필요한 한 컷만 생성 → 합격 구간 편집.**

1. **기존 영상부터 본다.** VR, 까몽, 휴대폰, 한강·수달 등 쓸 수 있는 구간을 먼저 고른다. 이미 만든 4초 중 1초가 좋으면 그 1초도 자산이다.
2. **한 컷의 역할을 한 문장으로 쓴다.** 예: “PULSE 작업자가 펜을 멈추고 동료에게 짧게 시선을 준다.” 장소 소개·웃음·로봇 인사·카메라 대회전을 한 번에 요구하지 않는다.
3. **참조를 나눈다.** 얼굴 = 승인 본인 / 구도 = 원래 콘티 / 질감 = PULSE 승인 영상 / 브랜드 = 해당 층. 각 이미지의 역할을 명시한다.
4. **참조끼리 모순을 없앤다.** VR이 눈을 가린 전신 컷과 이마에 놓인 얼굴 컷은 서로 다른 자세다. 현재 컷의 VR 위치를 정하고 얼굴 참조가 그 위치를 덮어쓰지 않게 한다.
5. **시작 이미지가 이미 적합하면 재생성하지 않는다.** 수정이 필요한 경우에만 이미지 한 장을 먼저 확인한다. 여러 변형을 자동 주문하지 않는다.
6. **불확실한 움직임만 저해상도로 시험한다.** 넘어짐·액체·창문 진입처럼 실패 위험이 큰 컷은 같은 모델의 Draft를 고려한다. 단순하고 이미 검증된 컷에는 초안을 무조건 추가하지 않는다.
7. **계정·참조·옵션·1개 생성·표시 비용을 확인해 한 번만 제출한다.** 대기 중이면 작업 ID로 결과를 확인한다. 늦거나 화면이 멈춘 것처럼 보여도 먼저 재주문하지 않는다.
8. **실제 속도로 끝까지 재생한다.** 얼굴·연기·손·물리·동선·브랜드를 보고 소리는 직접 듣는다. 정지 프레임이 좋아도 영상 전체가 통과한 것은 아니다.
9. **편집으로 해결 가능한 것부터 고친다.** 늘어진 앞뒤, 컷 연결, 색 차이, 음악 타이밍 때문에 전체 영상을 다시 생성하지 않는다.
10. **문제가 구조적일 때 다음 한 컷을 결정한다.** 바뀐 얼굴·추가 손·잘못된 물리·틀린 미션은 편집만으로 해결되지 않을 수 있다. 실패 원인 한 가지와 다음 변경 한 가지를 기록한다.

기존 콘티의 장면과 인물 배치는 그대로다. 복잡한 행동을 짧은 연결 컷으로 나누는 것은 **제안**이며, 구도나 행동이 달라지는 경우 먼저 사진 시안으로 확인한다. 비용 절약을 이유로 다른 주연이나 다른 미션으로 바꾸지 않는다.

### 경로 B — 본인 얼굴·미소를 가장 확실하게 유지할 때

**스마트폰으로 본인 연기 촬영 → 인물 원본 유지 → 필요한 미래 배경만 합성 → 편집.** 이미 가진 장비와 소스로 가능하면 추가 생성 크레딧을 가장 많이 줄일 수 있다. 촬영·마스크 작업 시간은 별도 비용이다.

1. 승인 배경의 창 방향에 맞춰 창가에서 촬영한다. 얼굴 한쪽 그림자를 남기고 미용 필터를 끈다.
2. 카메라를 고정하고 상반신·근접 컷으로 시작한다. 필요한 시선, 짧은 미소, 한 손동작을 직접 수행한다.
3. 시작 전과 끝난 뒤 여유를 포함해 찍는다. 생성 모델에 얼굴이나 미소를 다시 만들게 하지 않는다.
4. 배경만 바꾸고 원본 인물과 음성을 보존한다. 빛의 방향·색온도·인물 크기·접촉 그림자를 맞춘다.
5. 머리카락, 모션블러, 손끝의 경계를 실제 재생 크기에서 확인한다.

이 방식은 근접 표정·짧은 대화에 특히 유리하다. 전신 넘어짐·컵과 액체·바닥 접촉·큰 카메라 이동은 합성 시간이 많이 들 수 있어 항상 가장 싸다고 단정할 수 없다.

SYNK에는 [9.92초 원본 얼굴·음성 보존 합성 시험](../LAB_카페_다시말해주세요_20260926/google-vids/motion-composite/README.md)이 있다. 얼굴 원본을 보존하는 방법의 근거지만 머리카락 테두리 마감은 남았고, 기존 인터뷰를 옮긴 것이므로 새 대사를 연기한 완성본이 아니다.

## 4. 당시 Soul ID 검토 절차 — 현재 얼굴 제작 기본 경로 아님

**사용 조건:** 같은 본인이 여러 장면·각도·의상·후속 작품에 계속 나오고, 기존 승인 이미지 재사용만으로 부족할 때. 이번 프로젝트에서는 아직 학습하지 않았다.

1. 실제 본인 원본 사진을 준비한다. 현재 웹 공식 기준은 **20장 이상, 최대 80장**이다. 다양한 각도·표정, 선명한 얼굴, 전신 최소 1장을 포함한다.
2. 선글라스·얼굴 가림·강한 그림자·거의 같은 사진 반복을 피한다. 위 작은 첨부 스크린샷 하나는 학습 자료가 아니다.
3. 선택한 계정의 학습 비용과 사용 가능 모델을 확인한다. **Soul ID 학습 가격은 이번 조사에서 확인하지 못했다.** 이미지 생성 가격과 학습 가격을 혼동하지 않는다.
4. 한 번 학습하고 중립적인 빛의 얼굴 확인 이미지 한 장을 만든다. 처음 승인한 본인과 눈·코·입·턱·나이·미소가 맞는지 비교한다.
5. 얼굴이 맞으면 인물 Element로 재사용한다. 공식 안내의 Seedance `@ Elements` 연결을 해당 화면에서 확인한다.
6. 필요한 컷의 시작 이미지를 한 장 만든다. 얼굴은 Soul ID, 촬영 지시는 Soul Cinema 등의 지원 입력에 맞춰 적용한다.
7. 시작 이미지 확인 후 짧은 영상 한 컷으로 간다. 영상에서 다시 얼굴과 연기를 확인한다.

**Soul ID는 일관성을 돕지만 픽셀 단위의 동일 인물이나 본인의 고유한 미소를 보장하지 않는다.** 모델 자체의 외부 내보내기는 지원되지 않고 생성물은 내보낼 수 있다. [Soul ID 공식 안내](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character)

로컬 스킬에는 이전 CLI 사진 기준 5–20장이 남아 있어 현재 웹 도움말과 다르다. 웹 작업은 위 최신 웹 기준을 사용하고 CLI 실행 때는 실제 스키마를 확인한다. 생성한 얼굴 여러 장을 다시 학습해 본인 자료로 삼는 방식은 변형이 누적될 수 있어 우선하지 않는다. 이는 제작상 판단이다.

## 5. Astra에 맡길 준비와 바로 쓸 지시문

```text
다음 항목을 한 컷 표로 정리해 줘:
1) 시청자가 이 컷에서 이해할 것과 재미
2) 원래 구도와 시작/끝 상태

한 컷씩 진행한다. 기존 유료 승인 범위를 넘는 추가 생성은 자동 실행하지 않는다.
```

### 영상 프롬프트의 기본 구조

`유지할 대상 → 실제 행동 → 물리 → 시선·표정 → 빛 → 카메라 → 끝 상태 → 제외 요소` 순서로 쓴다. 참조에 없는 외모와 의상을 길게 새로 묘사하면 기존 인물이 바뀔 수 있다.

아래는 PULSE 같은 짧은 사람 연기에 적용할 **미실행 템플릿**이다. 업로드한 참조의 실제 역할과 모델의 참조 문법에 맞춰 바꾼다.

```text
One continuous live-action medium close shot, vertical 9:16, normal real-time motion.
Preserve the person, identity, clothing, framing and set from the approved shot reference.
The separate PULSE reference defines photographic lighting and natural performance only.

The person completes one short pen stroke, pauses at an off-camera colleague's cue,
then glances toward that colleague with a brief, restrained half-smile.
The hand stays in contact with the pen and tablet. The torso settles naturally.
Keep a stable face through the turn, with small breathing and ordinary eye movement.

Window daylight from camera right, with natural shade on the opposite cheek.
Normal skin color variation, ordinary fabric, consistent light on person and background.
Eye-level camera, 50mm-style field of view, very slight operator breathing.
No prolonged smile, repeated nodding, slow motion, beauty smoothing or floating particles.
Do not add people, props, logos, text or extra gestures.
End as the person returns attention to the task, leaving a short editing handle.
```

렌즈 표현은 구도와 심도를 전달하는 촬영 지시다. 실제 광학 렌즈로 찍힌 파일이라는 뜻은 아니다. 불필요한 대사가 없는 컷은 말하게 하지 않는다. 대사가 필요하면 한 줄을 정해 실제 청취로 확인한다.

### 넘어짐 컷에 적용할 보완

최근 77 계정의 한 컷은 얼굴·배경을 일부 유지했지만 **웅크리는 동작이 길고 커피가 한 덩어리의 호로 남으며 VR 위치도 변했다.** 따라서 다음 시도는 단순히 “더 cinematic”을 추가하는 방식으로 해결하지 않는다.

- 원래 콘티에서 허용되는 범위로 **사건 직전 시작 자세**를 준비하는 안을 검토한다. 이미 커피가 공중에 펼쳐진 이미지는 그 형태를 붙잡고 있을 수 있다.
- 발의 걸림 → 중심 이동 → 팔의 반응 → 커피의 분리와 낙하처럼 원인과 결과를 적는다.
- VR 위치, 오른손 커피, 왼손 휴대폰, 가방 까몽 수량을 컷 안에서 고정한다.
- 실패가 계속되면 얼굴 반응·컵·발을 연결하는 짧은 컷 분할 시안을 먼저 본다. 생성 비용을 줄이려고 원래 사건을 없애지 않는다.

물리적 행동을 구체화하는 방향은 [Higgsfield 사람 움직임 가이드](https://higgsfield.ai/blog/realistic-ai-human-movement)도 참고했다. 프롬프트만으로 성공률이 보장되는 것은 아니다.

### Draft는 언제 절약되는가

Seedance 2.5 Draft는 480p로 만든 뒤 선택한 초안을 1080p로 마무리하는 기능이다. 현재 스키마는 완료된 초안 ID와 **7일 내 마무리**를 안내한다. 같은 480p 일반 생성도 이번 조회에서는 12크레딧으로, Draft라는 이름 자체가 480p보다 싼 것은 아니다.

공식 변경 기록은 선택한 초안의 프롬프트·참조·시드·화면비·길이를 이어 사용한다고 설명한다. 픽셀이나 움직임이 완전히 같은 결과라는 보장은 확인되지 않았다. **완료된 Draft ID가 없어 최종 승격 자체의 추가 요금은 조회하지 못했다.** [2026-09-22 공식 변경 기록](https://higgsfield.ai/creator-hub/changelog)

| 조건부 예산 예시 | 계산 | 합계 |
|---|---|---:|
| 1080p로 세 번 시험한 뒤 하나 선택 | 48 × 3 | 144 |
| 480p 초안을 세 번 시험한 뒤 하나 마무리 | 12 × 3 + F | 36 + F |
| 위 최종 요금 F가 48이라고 **가정** | 36 + 48 | 84 |
| 처음부터 1080p 한 번에 통과 | 48 × 1 | 48 |
| 초안 한 번 + 최종 요금 F가 48이라고 **가정** | 12 + 48 | 60 |

세 번 시험한다는 가정에서는 144 대비 84로 **60크레딧, 약 42%**가 줄지만, 처음부터 한 번에 통과하면 초안을 거친 60이 직접 생성 48보다 비싸다. 84/60은 확정 패키지 가격이 아니다. Draft 비용을 최종 비용에서 공제한다는 근거도 없으므로 임의 차감하지 않는다.

### 무료·무제한·오디오에서 주의할 점

- 공식 크레딧 도움말의 웹 전용 혜택 설명과 현재 MCP의 `use_unlim`·`use_free_gens` 지원이 일부 다르다. **해당 계정·모델·통로에서 실제 사용 가능한 혜택과 가격을 확인**한다. 모든 MCP가 유료이거나 모든 웹 생성이 무료라고 일반화하지 않는다. [크레딧 안내](https://higgsfield.ai/creator-hub/help-center/credits/how-credits-work)
- Supercomputer의 Free Mode는 텍스트 대화에 대한 무료 안내다. 이미지·영상 생성까지 무료라는 뜻이 아니며 Astra가 언제나 무료라는 뜻도 아니다. 실제 선택 모드와 표시 비용을 확인한다. [Supercomputer 공식 설명](https://higgsfield.ai/blog/how-we-built-supercomputer)
- Seedance 2.5 1080p 4초는 오디오를 꺼도 이번 견적이 48이었다. Kling Pro는 소리 끔 7, 켬 10이었다. 음소거가 모든 모델에서 절약되는 것은 아니다.
- Higgsfield OpenAPI는 별도 과금 상품이다. 기존 구독 크레딧이 남아 있는 지금 추가 API 충전을 가장 싼 방법으로 권하지 않는다. [공식 출시 기록](https://higgsfield.ai/creator-hub/changelog)
- 프로모션은 특정 계정·기간의 혜택이다. GPT 계정마다 중복 지급된다고 가정하지 않는다. 보너스 소멸을 피하려고 쓸모없는 영상을 만들지 않는다.
- 크레딧의 원화 가격은 구독·보너스·충전 구성에 따라 달라 이번 문서에서 환산하지 않았다.

## 7. 절약 우선순위와 실제 예산 관리

1. **이미 만든 좋은 구간 재사용.** 추가 생성 크레딧 0으로 시작할 수 있는 첫 단계다.
2. **본인 근접 연기는 직접 촬영 검토.** 새 얼굴 생성 실패를 피하되 합성 노동을 함께 계산한다.
3. **승인 이미지 재사용.** Soul 학습과 이미지 재생성을 의무 단계로 만들지 않는다.
4. **영상 전에 모순 제거.** VR 위치·손·캐릭터 수·층수·미션이 틀리면 고해상도로 만들어도 쓸 수 없다.
5. **짧은 한 컷, 한 번만 생성.** 한 번에 여러 모델·여러 장면을 돌리기 전에 대표 컷을 통과시킨다.
6. **초안은 실패 위험이 큰 컷에만.** 다른 저가 모델의 통과가 최종 모델의 얼굴·연기 품질을 증명하지는 않는다.
7. **리듬과 글자는 편집으로.** 컷 길이·음악·간판 철자·폰 게임 화면 때문에 전체 인물을 다시 만들지 않는다.
8. **업스케일은 채택된 마지막 결과에만.** 4K보다 원본 얼굴과 동작의 품질을 먼저 확인한다.

총비용에는 **얼굴 학습 + 이미지 + 버린 영상 포함 모든 생성 + 음성/효과음 + 유료 편집/업스케일**을 포함한다. 비교할 값은 ‘한 번 생성 가격’뿐 아니라 **채택한 한 컷당 비용, 실제 사용 1초당 비용**이다. 예를 들어 48크레딧 영상에서 1초만 쓰면 그 1초를 얻은 생성 비용은 48이다.

현재 사용자 방침은 **한 번에 한 컷, 크레딧 절약**이다. 과거 전체 제작 요청을 근거로 새 배치·재시도·Soul 학습을 자동 실행하지 않는다. 기존 한 컷의 승인과 비용 한도를 존중하고, 다음 실행은 구체적인 시안과 표시 가격을 놓고 결정한다.

기록 표는 다음 정도로 유지한다. 견적과 실제 차감을 분리하면 계정의 다른 작업 비용을 잘못 합산하지 않을 수 있다.

| 컷 | 계정/통로 | 모델·옵션 | 견적 | 실제 차감 | 작업 ID | 결과·사용 구간 | 다음 판단 |
|---|---|---|---:|---:|---|---|---|
| 예: PULSE 시선 | 실행 전 기록 | 4초·1개·선택 해상도 | 조회값 | 완료 후 확인 | 제출 후 기록 | 승인/후보/제외 | 편집/한 가지 수정 |

## 8. 원래 콘티에 적용하는 배치

아래는 기존 이야기를 유지한 **제작 방법 배치**다. 모든 컷을 새로 생성하라는 실행 목록이 아니다.

| 장면 | 유지할 내용 | 우선 사용할 방법 |

재사용 후보는 기존 파일의 대략 **15.25초 분량**이다. 한글 설명을 이미지 모델에 길게 생성시키지 않는다. 꼭 필요한 한국어는 정확한 음성과 편집한 게임 화면으로 전달한다. 브랜드는 펠트 질감·색·공간·작업 행동을 함께 유지하며, 촬영 질감을 바꾼다고 미래 공간을 평범한 사무실로 바꾸지 않는다.

제품 종류·외부 브랜드·모델·길이·편수는 아직 확정하지 않았다. 과장된 제품 성능을 우주·공룡 연출로 주장하지 않으며, 자체 제작이나 가상 브랜드 사례는 그 상태를 표시한다. 두 작품은 추가 후보로 관리하고 기존 기업영상·MV·TVCF의 승인 콘티를 교체하지 않는다.

포트폴리오에는 완성 광고와 함께 실제 사용한 **인물/배경 원본 → CG 층 → 합성 → 색·소리 마감**을 보여주는 짧은 브레이크다운을 붙이는 안을 추천한다. 제작 방법과 통제 능력을 확인할 자료이며, 자체 생성 장면을 실촬영이나 외부 고객 실적으로 소개하지 않는다.

### 11-4. 확인한 기능과 이번 완료 범위

- [Higgsfield Cinema Studio](https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-cinema-studio): 참조·인물·장소·촬영 설정을 활용한 영상 생성. 공식 기능 설명과 우리 결과의 합격 여부를 구분.
- [Higgsfield 3D Jutsu](https://higgsfield.ai/blog/higgsfield-3d-jutsu): 편집 가능한 배치·카메라·애니메이션, 프리비즈를 최종 영상 생성 참고로 활용하는 과정.
- [Blender Cycles](https://www.blender.org/features/rendering/): 물리 기반 재질·빛, 렌더 패스·그림자·마스크·초점·움직임 흐림을 활용할 수 있는 CG 렌더 엔진.
- [Blender VFX](https://www.blender.org/features/vfx/): 영상 합성·OpenEXR·카메라 및 물체 추적.
- [Resolve Fusion](https://www.blackmagicdesign.com/products/davinciresolve/fusion): 마스크·합성·트래킹·2D/3D 작업, 편집·색 작업과의 연결.
- [Resolve Fairlight](https://www.blackmagicdesign.com/products/davinciresolve/fairlight): 효과음·폴리·녹음·음악과 대사의 믹스 및 최종 출력.
- [Houdini Pyro FX](https://www.sidefx.com/products/houdini/vfx/pyro-fx/): 연기·불·폭발 등 추가 시뮬레이션 후보.

2026-10-01 공식 자료와 설치 파일을 확인해 프로그램·순서·작품 후보를 정리했다. 이번에는 새 모델 학습·이미지/영상 생성·3D 자산 제작·렌더·유료 자산 구입·구독·배포를 실행하지 않았다. 공룡이나 우주 광고의 영화 수준 완성은 아직 검증하지 않았다.

### 11-5. 30초 CG 광고의 기획 예산 — 2026-10-01 비용 질문

4~6컷, 기존 PC·설치 프로그램, 기성 3D 자산 활용, 인물은 필요한 컷만 AI로 만드는 경우의 **초기 기획 예산**이다. 직접 제작 노동·기존 PC/구독의 고정비·새 프로그램 라이선스·세금/결제 수수료는 아래 현금 예산에서 제외한다. 고품질 목표의 완성 보장이나 확인한 외주 견적이 아니며 콘티 확정 후 다시 계산한다.

| 30초 작품 | 직접 제작 시 추가 지출을 위한 준비 예산 | 큰 비용 요소 |
|---|---:|---|
| 우주·제품 CG 광고 | 20~50만원 | 필요한 모델·재질, AI 인물/참조 재시도, 필요한 렌더 비용, 음악·효과음, 예비비 |
| 공룡·인물 CG 광고 | 50~120만원 | 상업용 공룡 모델·움직임 자산, AI 인물 재시도, 필요한 렌더 비용, 음악·효과음, 예비비 |

새 장비·실촬영·성우·맞춤 공룡 제작·무거운 파괴/폭발 시뮬레이션은 별도다. 대표 CG 장면을 몇 컷에 집중하는 경우이며, 전 컷에 긴 접촉·달리기·군중·생물 클로즈업이 필요하면 예산과 작업량이 증가한다. 자산을 재사용하면 다음 작품의 구입비를 줄일 수 있다. 보유 크레딧 사용은 추가 결제액을 낮출 수 있지만 이미 지불한 비용까지 사라지는 것은 아니다.

**이번에 확인한 수치와 계산 가정**

- 읽기 전용 MCP 견적: Seedance 2.5, 텍스트 입력, 16:9, 1080p, 높은 비트레이트, 오디오 포함, 일반 크레딧 기준으로 5초60·30초360크레딧. 생성 작업을 제출하지 않았고 참조 미디어를 넘기지 않아 업로드도 없었다. 기존 MCP 연결 계정의 응답이며 작업용 웹 계정의 실제 생성 가격을 보장하지 않는다.
- 30초 분량을 3~5회 생성한다는 단순 가정은 1,080~1,800크레딧이다. 실제로는 컷의 앞뒤 여유·못 쓰는 구간·추가 재시도 때문에 더 들 수 있고, 3~5회 만에 영화 수준을 통과한다는 의미가 아니다. CG 렌더로 만드는 구간은 AI 생성 길이에서 빼고 계산한다.
- [Higgsfield 공식 9월 안내](https://higgsfield.ai/blog/credits-vs-unlimited-ai-video-generation)의 Plus 월 $49/1,000크레딧을 전부 사용하는 배분 가정과 예산환율 $1=1,400원을 적용하면 약68.6원/크레딧, 위 AI 생성분은 약7.4~12.3만원이다. 이는 크레딧 사용분의 배분값이며 현재 충전 팩 결제액·웹 계정 단가·실시간 환율이 아니다. 실제 추가 결제는 플랜/잔여량/충전 팩에 따라 달라진다.
- [제작자 Tyrannosaurus Rex 판매 페이지](https://quijay.gumroad.com/l/ybirop?layout=profile)의 Commercial License는 $250부터, 같은 예산환율로 약35만원이다. 개인용 $35 가격을 광고용 예산으로 사용하지 않는다. 실제 자산·라이선스·동작 적합성 확인과 구입은 아직 하지 않았다.
- [공식 크레딧 안내](https://higgsfield.ai/creator-hub/help-center/credits/how-credits-work)는 모델·해상도·길이·재생성·업스케일의 비용과 생성 직전 표시 가격을 설명한다. 웹의 무제한/무료 혜택을 자동화 비용에 그대로 적용하지 않는다.

**노동을 포함할 때의 계산 예시**: 공간·제품80~160시간, 공룡·인물160~320시간과 시간당5만원을 내부 계획 가정으로 두면 각각400~800만원,800~1,600만원의 노동비에 위 현금 비용이 더해진다. 실제 외주 시장가를 확인한 수치가 아니며 숙련도·장면·자산 준비도에 따라 바뀐다. 최고의 실사 영화 품질을 요청한 만큼 조명·생물 연기·카메라·접촉 그림자·가림·합성·소리의 제작 시간을 생성비와 따로 판단한다.

첫 우주편은30만원, 공룡편은80만원을 초기 준비 예산 후보로 둔다. 대표3~5초의 실제 재생 검수로 가능한 품질·시간·재시도 비용을 먼저 확인하고 본편 예산을 갱신한다. 이 금액은 지출 승인이나 유료 실행 지시가 아니다.
