# yuhobuilds 제작 여정 쇼츠 · 제작 양식 (라인 2)

[운영 체계](../콘텐츠_운영체계_20260927.md) · 2026-09-27 세팅 · 연재의 사실·소재·회고는 [유호 제작 여정](../yuhobuilds_제작여정_202607-20260922/README.md)이 담당하고, 이 문서는 한 편을 만드는 틀을 정한다. [1편 피드백 기록](../yuhobuilds_제작여정_202607-20260922/1편_피드백과_다음제작기준.md)의 확정 사항은 그대로 유효하다.

**시각(2026-10-01):** 표지·카드·첫 프레임·영상 위 글자는 [SNS 제작 키트](../../디자인/SNS키트/README.md)에서 출발한다. 테마 `builds`(검정·버터), 견본 [EP.01](../../디자인/SNS키트/견본/builds_EP01/). 얼굴은 실제 사진이나 10-01 확정 얼굴만 쓰고 합성 얼굴 스티커는 쓰지 않는다.

## 누가 왜 보나

AI 완전 초보부터 AI로 자기 일·제품·사업을 만들려는 1인 기업가까지, 코딩과 도구 이름을 처음 듣는 사람이 출발점이다. 정보는 “그 막힘에서 지금이라면 이렇게 한다”와 “오늘 할 한 가지”, 재미는 “나도 그랬다”는 공감과 시행착오의 웃음, 그리고 실제 화면이 바뀌는 순간의 쾌감이다.

## 한 편의 구조(60~75초)

| 구간 | 내용 | 화면 | 소리 |
|---|---|---|---|
| 0~3초 콜드오픈 | 갈등이나 결과를 먼저. “나 뭐 만들고 있었지?” 같은 한 줄. “오늘은 ~ 이야기를 해볼게요”로 시작하지 않는다 | 그 장면(기능 카드가 출석 버튼을 덮는 화면 등) + 상단 훅 제목 | 육성 첫 문장, 효과음 하나 |
| 3~15초 상황 | 언제·어디서·무엇을 하려 했나 | 실제 화면 캡처 1컷 이상(당시 것이 없으면 ‘재구성’ 표시) | 육성 |
| 15~40초 막힘 | 시행착오. 코믹 각색 허용, 사실은 회고 원문 안에서 | 카드·표정·인터뷰 실제 얼굴 2~3초(라인 1 연결) | 효과음은 이해를 돕는 자리에만 |
| 40~55초 지금이라면 | 현재의 판단 한 가지. 당시와 지금을 구분 | 전후 비교 | |
| 55~70초 오늘 할 한 가지 | 복사용 질문 한 줄이 화면에 타이핑 | 입력창 재현(‘예시’ 표시) | 타건음 |
| 마지막 2초 | “제가 헤맨 길, 여러분은 건너뛰세요.” | 실제 사진 | 음악 페이드 |

컷은 보통 2~3초, 중요한 시연만 5초까지. 같은 문장을 화면과 자막에 중복하지 않는다.

## 화면

- 표지·첫 프레임·끝은 키트 `builds` 테마(검정 면·흰 글자, 강조는 버터), 안쪽 카드는 흰 종이에 버터 형광펜이다. 흰 바탕·검정·파랑 강조였던 기존 EP 디자인은 새 편부터 쓰지 않는다. 유행 템플릿을 쓰지 않는다.
- 실제 화면 캡처를 최소 한 컷 넣는다. 카드 그림만으로 “따라 하기”를 대신하지 않는다.
- 인터뷰 실제 얼굴을 편당 한 번 넣어 실화의 증거이자 라인 1과의 연결로 쓴다. 합성 캐릭터는 보조다.
- 상단 훅 제목·자막·이름표는 라인 1과 같은 키트 `kv-hook`·`kv-cap`·`kv-name`을 쓴다(강조색은 버터). 자막은 낱말 단위로 나타난다.

## 음성 · 육성이 기본

- 유호 육성이 기본이다. 녹음 전에는 Typecast 정의로 검토본만 만들고 게시하지 않는다.
- 녹음: 조용한 방, 스마트폰이나 USB 마이크, 48kHz. 대본을 문장 단위로 끊어 읽고 감정 표기(놀람·한숨·웃음)를 대본에 둔다. 한 문장을 두 번씩 읽어 고른다.
- 대본과 음성을 분리해 두어 재더빙이 가능하게 한다(현재 구조 유지).

## 제공물과 엔딩

편마다 복사용 질문 TXT와 그림 가이드 PDF(현재 pdf-guide 체계). 엔딩은 채널 문장으로 고정하고 자료 안내는 설명란과 고정 댓글에 둔다.

## 채널별 변형

YouTube Shorts·Instagram Reels·TikTok·네이버 클립에 같은 영상. 제목·첫 줄만 채널별로. Tistory 제작기와 Threads 경험담은 [글·뉴스레터](글_뉴스레터.md)로 파생.

## 제작 통로

새 영상은 [영상 도구 선택 기준](../콘텐츠_제작방식_v2_20261002.md#video-tool-selection)에 따라 [만족 사례 장부](만족사례_장부.md)의 가까운 결과물을 만든 방식으로 시작한다. 얼굴은 실제 사진이나 10-01 확정 얼굴만 쓰고, BGM은 기존 시티팝을 쓴다.

EP01 키트판 `yuhobuilds-ep01-rebuild-20260927/kit-v1/`은 2026-10-01 키트판 제작 중(렌더 전)이던 기록이다. HyperFrames는 이처럼 기존 편의 수정·재현에만 참고한다. 그 편의 브리프 → 원고 → narration-script.json → 컴포지션 → 점검·스냅샷 → 렌더 → 검수 경로와 필요한 키트 연결(`node tools/SNS키트_영상연결.js <프로젝트>`, `motion.js`)은 [키트 §9](../../디자인/SNS키트/README.md#9-영상에-적용--모션)를 따른다. 같은 폴더의 GPT 재제작 56초본은 이전 판으로 둔다.
