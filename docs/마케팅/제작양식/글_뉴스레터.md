# 글·뉴스레터 · 제작 양식 (라인 7)

[운영 체계](../콘텐츠_운영체계_20260927.md) · 2026-09-27 세팅 · 2026-09-26 [첫 초안 5종](../글뉴스레터_첫제작_20260926/README.md)은 보고서형이라 볼 이유가 약하다는 평가를 받았다. 이 양식은 그 피드백을 반영한 새 기준이다.

**시각(2026-10-01):** 스레드·X 카드, 블로그 대표 이미지, 뉴스레터 머리 그림은 [SNS 제작 키트](../../디자인/SNS키트/README.md)의 `sq11`·`doc45`·`og` 판으로 만든다. 견본 [인용 카드](../../디자인/SNS키트/견본/builds_EP01/).

## 원칙

- 글은 영상의 텍스트판이다. 라인 1~6에서 나온 문장·장면·질문을 재사용한다. 새 주제를 글에서 먼저 시작하지 않는다.
- 첫 줄이 훅이다. 결과·주장·구체적 숫자 중 하나. “~에 대해 이야기해 보겠습니다”로 시작하지 않는다.
- 한 글에 주장 하나, 상황 하나, 독자가 할 일 하나.
- 이미지는 실제 화면이나 전후 비교 한 장. 링크는 마지막.
- 확인하지 않은 성과·기능·가격을 쓰지 않는다. 회고는 회고라고 밝힌다.

## 회사 색

문장은 유호의 말로 쓴다(인터뷰 문장 재사용이 가장 빠르다). LAB 갈래는 학습자의 순간에서 시작하고, SHIFT 갈래는 독자의 업무에서 시작한다. 편지의 마무리는 “읽고 나서 하나만 해본다면”.

## 제작 통로

회차 폴더 `원고.md` → `게시/<채널>.txt`(본문만) → `sns-발행.js --수동열기`로 공식 편집기와 자료 폴더를 연다(네이버·Tistory·Substack·카카오). Threads·X는 연결 후 직접 발행, 전에는 수동. 카드·대표 이미지는 키트 원고 HTML을 `node tools/SNS키트굽기.js <원고.html> --sheet`로 굽는다.

## 검수·측정

검수: 첫 줄만 읽어도 볼 이유가 있는가, 사실·출처, 글자 수, 이미지 실물 여부. 측정: Threads·X 저장·답글·프로필 방문, 블로그 검색 유입·체류, Substack 열람률·클릭.
