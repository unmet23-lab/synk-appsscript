# synkbrief AI 소식·도구 추천 · 제작 양식 (라인 4)

[운영 체계](../콘텐츠_운영체계_20260927.md) · 2026-09-27 세팅 · 채널 역할은 [synkbrief](../채널과_발행.md#synkbrief의-ai-뉴스추천활용법), 소재는 [아이디어 창고](../synkbrief_아이디어_창고.md).

**시각(2026-10-01):** 표지·카드·썸네일·영상 위 글자는 [SNS 제작 키트](../../디자인/SNS키트/README.md)에서 출발한다. 테마 `brief`(청금석), 견본 [광고 세 컷](../../디자인/SNS키트/견본/brief_광고세컷/).

## 누가 왜 보나

AI를 자기 업무에 쓰려는 한국어 사용자. 정보는 “무엇이 바뀌었고 내 일에 무슨 영향인가, 직접 써보니 어땠나”, 재미는 “이게 된다고?”의 놀람과 실제 화면에서 결과가 나오는 순간이다. 남의 발표를 읽어주는 뉴스가 아니라 써본 사람의 판단이 회사 색이다.

## 한 편의 구조(30~45초)

| 구간 | 내용 | 화면 |
|---|---|---|
| 0~3초 | 결과나 변화 한 장면. “이제 ○○이 됩니다” 또는 “○○을 써봤는데, 이건 됩니다” | 결과 화면 + 상단 훅 제목 |
| 3~12초 | 무엇이 바뀌었나. 공식 발표·날짜 한 줄 | 공식 화면 캡처(출처 표시) |
| 12~30초 | 직접 해본 화면. 입력 → 실행 → 결과 | 실제 UI: 전체 위치 → 확대 → 클릭 반응 |
| 30~40초 | 누가 쓰면 좋고, 조건·한계·비용 | 카드 3줄 |
| 마지막 | 원문 링크·비교표는 설명란, 자료가 있으면 “댓글에 synk” | 엔딩 |

## 사실 규칙

- 제작일 기준으로 공식 문서·발표를 확인하고 날짜를 남긴다. 이용 조건·가격·지역 제한을 말한다.
- 써본 것과 소개만 확인한 것을 구분한다. 시연하지 않은 기능을 써본 것처럼 말하지 않는다.
- 모델 우열을 단정하지 않는다. “이 작업에서는 이랬다”로 말한다.

## 소재 고르기(월요일)

아이디어 창고에서 먼저 고르고, 부족하면 조사한다. 조사 통로: 공식 블로그·릴리스 노트, Hugging Face 트렌딩(연결됨), GitHub 트렌딩, exa 검색. 기준은 “우리 시청자의 이번 주 업무에 바로 쓰이나”. 시의성이 강하면 주말이라도 당겨 게시한다.

## 화면·음성·자막

실제 UI 안내는 [AI 활용법](AI_활용법.md)의 위치→확대→클릭 규칙을 그대로 쓴다. 음성은 Typecast 서현이나 혜리다(10-03 유호님 「서현이나 혜리로 바꿔」 — 차분한 설명은 서현, 밝은 소식·추천은 혜리. 9/24부터 쓰던 은경은 이전 편까지). 자막·제목은 키트 `kv-hook`·`kv-cap`(낱말 단위 자막, 강조는 `brief`의 옅은 버터). 설명용 이미지는 GPT Image로 만들되 실물 캡처와 구분 표시.

## 채널별 변형

synkbrief YouTube·Instagram·TikTok 동일 영상. X·Threads에는 한 줄 소식 + 공식 링크(영상 없이도 됨). 네이버 블로그는 활용법이 붙을 때만.

## 제작 통로

HyperFrames + SNS 제작 키트(`brief` 테마, `motion.js`). 프로젝트에 `node tools/SNS키트_영상연결.js <프로젝트>`로 키트를 넣고 [키트 §9](../../디자인/SNS키트/README.md#9-영상에-적용--모션) 순서(컴포지션 → 점검·스냅샷 → 사용자 확인 뒤 렌더 → 검수)로 만든다. 같은 테마의 본보기는 `synkbrief-ai-angles-20260927/kit-v1/`(2026-10-01 키트판 제작 중(렌더 전))이다. synkbrief v19 파이프라인(content.json → build → render)은 1편의 기록으로만 둔다. 캡처는 실제 계정 화면, 개인정보·키는 가린다.

## 검수·측정·다음 편 기준

검수는 AI 활용법과 같다. 측정은 3초 홀드, 완주율, 저장·공유, 링크 클릭(설명란). 4편 뒤 “결과 먼저” 대 “변화 먼저” 도입을 비교해 기본값을 정한다.

## 첫 적용

창고의 SB-002(FaceSwap)나 이번 주 소식 중 하나. 실제 써본 화면을 먼저 확보한 뒤 원고를 쓴다.
