# 컴퓨터 사기 전 네 가지 선택 · 새 검토본

2026-09-27. 사용자가 정보·재미·배우는 즐거움을 기준으로 전체 재제작을 요청해, 직전 컴퓨터 선택 시안을 재구성했다. 기존 회의 정리 영상 v19의 교체나 채널 전면 전환을 확정한 작업은 아니다.

## 시청자가 볼 이유

컴퓨터를 잘 모르는 사람이 AI나 문서 작업을 시작하려고 구매를 고민한다. 네 가지 선택을 하며 필요한 기준을 배우고, 마지막에 자신의 구매 방향·확인할 순서·상담 문장을 가져간다. 기존 ‘비교해보세요’에서 끝나는 세 질문 시안을 대체하는 검토본이다.

## 새 흐름

1. ‘AI 배우려는데, 컴퓨터부터 사야 할까요?’ → 기기 보유 여부.
2. 웹 질문·문서 / 가벼운 편집 / 무거운 편집·게임·설치형 AI를 구분.
3. 가진 기기의 실제 사용감, 또는 새 기기를 쓸 장소.
4. 가진 기기의 운영체제, 또는 구매 때의 우선순위.
5. 답변을 반영한 결과 + 세 가지 확인 순서 + 매장·상담에 쓸 문장.

선택마다 짧은 이유를 보여주고 읽은 뒤 다음으로 진행한다. 선택 반응·체크 표시·용도별 도식 변경·진행선·장면 이동으로 이해를 돕는다. 자동 타이머·무작위 추천·과장된 절약 금액은 사용하지 않는다. 움직임 감소 설정과 키보드 조작을 지원한다. 이번 버전에는 음성과 효과음을 넣지 않았다.
