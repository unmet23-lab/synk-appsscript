# 그록 시험관 답 · 구독(grok CLI) · 2026-11-14T12:41:10.933Z

1. 만화 카페에서 한 시간만 잔다던 분홍 인형이, 더 있을 거냐는 말에 괜찮다 하고는 네 시간이나 자 버린 이야기야. 「한 시간만요」「아니요, 괜찮아요」도 가르쳐 줘.
2. 「한 시간만요」(han si-gan-man-yo)와 「아니요, 괜찮아요」(a-ni-yo, gwaen-chan-a-yo)는 따라 말할 수 있다. 가게가 어디인지는 모른다.
3. 0–1초 윗줄 버마어는 글씨가 두꺼워 못 읽었고, 아랫줄만 졸린다는 뜻으로 보였다. 2–3초 큰 글은 만화 커피집으로 읽었고, 아래 작은 두 줄은 못 읽었다. 3.6초 「몇 시간 하실 거예요?」는 모르겠고, 밑 글도 작아 시간을 묻는 것 같기만 했다. 8초 윗글은 못 읽었다. 침대인 것은 그림으로 알겠다. 14초 「손님」「하시겠어요」는 모른다. 「연장」만 시간을 더하냐는 말로 보였다. 18초 버마어 한 줄은 못 읽었다.
4. 끝까지. 직원이 커튼 사이로 계속 봐서, 깨우는지 보려고 남았다. 2–3초 단어 카드는 지루했다.
5. 4. 한 시간이 네 시간이 된 이야기는 알겠다. 작은 글과 「손님」「하실 거예요」는 한 번에 못 알았다.
6. 3. 끝의 네 시간은 조금 웃기다. 10초 뒤로는 침대가 거의 같아서, 친구에게 보이긴 약하다.
7. 계속 봄. 0초에 버마어와 졸린 얼굴이 나왔다. 1.5초부터 단어 설명이 나와도 넘기지 않았다.
8. 저장. 「한 시간만요」 발음을 다시 보려고. 보내진 않겠다.
9. 달라 보임. 지난1은 단어 조각이 쌓이다 「한국어… 진짜 어려워…」로 끝난다. 지난2는 공책에 글자를 쓰다 「잘했어!」로 끝난다. 이번 건 화면 위 대사로 가게와 침대를 가고, 잠든 장면 위 「한 시간만요… 4」로 끝난다. 머리 글, 말 순서, 화면 배치, 끝 카드가 다르다.
