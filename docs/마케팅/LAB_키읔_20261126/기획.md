v1은 ④와 ⑨에 걸렸다. 고친 것: 머리 글을 물음 꼴 「Texting a Korean friend… / how many ㅋ? 🤔」로 바꿔 끝 줄 「more ㅋ = more 😂」가 답이 되게 했다. 문자 말풍선 머리를 「Korean friend」 · 「Me」로, 싸늘한 칸 뜻 줄을 「Only ONE ㅋ? = cold 😐」로 바꿨다. 말 순서(모름 → 뜻 → 따라 하다 실수 → 고침)는 원본 뼈대라 두었다.

v2 고친 것: 싸늘한 칸 뜻 줄을 「Just ONE ㅋ = a dry “heh” 😐」로 까닭까지 쓰고, 받기 전 자리 그림을 싸늘해진 끝 그림(`k_coldx`)으로 바꿨다. 첫 화면 머리 글의 쌍점은 화면 글 검사가 「이름표 + 답」으로 읽어 「…」로 바꿨다.

v3(최종본)도 h · G가 14초를 같이 짚어 ④에 걸렸다. 다시 시험 두 번을 다 써서 「매일 한 편」 2대로 이 판을 올린다(관문 못 넘음). 볼 이유 심사(맥락 없는 Opus)는 **3 · 슬롭 아님 · 이야기**였다(LAB 문턱 3). 심사관은 「몽글이 방금 lol을 배웠는데 왜 ㅋ 하나만 보내는지 까닭이 없다 — 짧을수록 쿨해 보이겠지? 같은 착각을 넣으라」고 했다. 그래서 ㅋ 하나 말풍선 뜻 줄을 「just one — cool, right? 😎」로 바꿨다(시험 뒤 고침이라 시험관은 안 봄). 비어 보이는 자리로는 0.5~2초 같은 그림, 2.5~3초 멈춘 얼굴, 8~10초 같은 설명 4초를 짚었다. 앞 둘은 Flow가 막혀 시작 그림으로 메운 칸이다.
