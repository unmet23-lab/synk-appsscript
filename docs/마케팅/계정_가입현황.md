원장과 지도 생성 데이터는 32곳 확보·16곳 미확보로 갱신했다. Data 플러그인 설치는 완료됐지만 1.1.1-exp-components.2의 공식 prepare가 `Invalid prebuilt source path: assets\\visualize-data\\assets\\cdn.json`으로 실패했다. 보호 런타임을 고치거나 다른 빌드로 우회하지 않았다. 기존 dist는 보존했으므로 지도 화면에는 이전 27·21이 남을 수 있다. 현재 수치는 이 표와 원장을 따른다. 공식 런타임 검증 문제가 해결되면 같은 프로젝트를 재빌드·화면 확인한다.
