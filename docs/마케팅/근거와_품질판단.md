### 1-2. 처음 실시할 이해 조사 — 숫자를 만들기보다 실제 장면을 찾는다

**다음 운영의 제안 표본이지 인터뷰 완료 보고가 아니다.** 첫 회차는 학생 6~8명(탐색 중·목표 명확·조용한 참여·쉬었다 재시작을 섞음), 보호자 3~4명, SHIFT 각 우선 구매자 유형 2명부터 시작할 수 있다. 작은 표본이므로 대표성이나 포화에 도달했다고 말하지 않는다. PULSE는 실제 청취 상황이 다른 사람, SYNK는 실제 협업 판단을 해본 사람에게 묻는다. 모집 가능성과 기존 관계를 보고 조정한다.

**학생에게는 답을 유도하지 않는 순서로 묻는다.**

1. 최근 한국 관련해서 직접 찾아본 것은 무엇인가? 보여주고 싶은 자료 하나만 본인이 고른다. 계정·검색 이력 전체를 받지 않는다.
2. 한국에 간다면 관광이 아닌 평일 하루를 어떻게 보내고 싶은가? 누구를 만나고, 어떤 일을 직접 해보고 싶은가?
3. 그 장면에서 지금 한국어로 하고 싶은 말은 무엇인가? 말이 안 나오면 어떤 방법을 쓰는가?
4. 한국에 가는 선택에서 더 알아야 할 것, 아직 가고 싶지 않은 이유도 있는가?
5. 부모에게 설명하고 싶은 것과 먼저 물어보고 싶은 것은 무엇인가? 사적인 갈등을 공개 이야기로 꺼내지 않아도 된다.
6. 공개 촬영 없이도 즐겁게 하고 싶은 역할은 무엇인가? 쓰기·편집·설명·말하기 중 직접 고른다.
7. 반대로 한국 친구에게 몽골의 무엇을 알려주고 싶은가?
8. 예시 콘텐츠를 본 뒤 무엇을 해보고 싶어졌는가? 기억나는 문장이나 선택을 스스로 말해보게 한다. ‘좋죠?’라고 묻지 않는다.

**보호자:** 자녀가 원하는 이유 / 결정 전에 확인할 자료 / 비용·시간·안전·연락의 궁금증 / 지난 교육에서 도움이 된 설명 / 자녀와 같이 읽을 수 있는 한 장을 묻는다. **SHIFT 구매자:** 최근 비슷한 결정을 한 순간 / 내부 승인에 필요한 증거 / 맡기기 어려웠던 이유 / 끝났다고 판정하는 결과 / 수정·지원이 필요한 상황을 묻는다.

기록은 `당사자가 말한 것 / 관찰한 행동 / 우리의 해석 / 반증 / 다음 실험`으로 나눈다. 질문을 건너뛰거나 홍보 사용을 거절해도 교육·체험은 동등하다. 미성년자 조사에는 적절한 안내·보호자 절차·철회 경로를 먼저 갖춘다. 이름·학교·얼굴·음성·가족사·비자·연락처를 공개 댓글, 공개 저장소, 외부 모델에 넘기지 않는다. 원본 저장·접근·삭제는 정해진 교육/조사 운영 자리에서 담당하고 이 정본에는 비식별 결론만 남긴다.

## 9. 철학과 엔진 7종이 마케팅에 나타나는 자리

엔진 이름을 늘어놓는 것이 아니라 타겟이 얻는 경험으로 번역한다. 아래는 **설계상 효용과 필요한 증거**다. 엔진 문서의 완료 표·시험 통과만으로 실학생 효과를 주장하지 않는다. 최신 상태는 코드·배포·실제 사용·도달 증거를 각각 확인한다.

**Core는 엔진이고, Atlas는 Reed를 제외한 여섯 엔진이 함께 만드는 학생 한 명분의 축적된 이해다.** Atlas를 여덟 번째 엔진이나 Core의 다른 이름으로 설명하지 않는다. 학생의 선택·확인된 것·학습 경험을 이어 이해하는 목적을 마케팅의 과장된 성격 진단으로 바꾸지 않는다.

| 엔진 | 밖에서 경험할 가치 | 마케팅에 보여줄 수 있는 증거 형식 | 넘지 않을 선 |
|---|---|---|---|
| **Core** | 내 목표·선택·학습 결과가 다음 도움에 반영 | 허구 학생의 입력과 실제로 달라지는 다음 과제 시연 | 마음을 다 안다·삶의 목표를 AI가 확정한다·7엔진 완성이라는 비약 금지 |
| **Loom** | 어디서 만나도 같은 결, 써볼 수 있는 물건 | 실제 크기의 카드·화면·인수 파일, 승인 원본의 일관성 | 재질 독점·수공예·인지도·관계 자국 구현을 근거 없이 주장하지 않음 |
| **Vellum** | 받은 도움의 뜻을 알고 내 기록에 이의를 낼 수 있음 | 제출→답→다음 행동과 본인의 수정 요청이 반영되는 시연 | 추정 성향을 사실로 고정하거나 캐릭터를 정서 상담사로 만들지 않음 |
| **Trail** | 내가 고른 길과 바꾼 선택이 내 기록으로 남음 | 본인용 기록 견본·선언의 변화·공식 결과와 내부 진단의 분리 | 대학이 인정한 포트폴리오·졸업/취업 실적을 설계만으로 홍보하지 않음 |
| **Prism** | 실제 어려움을 더 잘 묻고 교안을 고칠 연구 | 가설→관찰→수정한 예시와 적용 범위 | 특정 과업·기간의 표본을 몽골어 화자 일반으로 확대하지 않음. 모국어가 원인이라는 확정 금지 |
| **Temper** | 주고 끝내지 않고 도움이 되었는지 다시 확인 | 개입·노출·후속 기회·관측·사람 판단을 구분한 사례 | 전후 변화=우리 인과 효과, 제출 건수=독립 학생 수로 둔갑하지 않음. 학생 수업을 마케팅 A/B 배정에 쓰지 않음 |
| **Reed** | 방해받지 않고 머물 감상과 일관된 소리 | 실제 곡 전환·음량·송출 확인 | 개인 청취를 학습·감정·집중 데이터로 수집하지 않음. 앱 라디오·학생별 곡 사이 낱말 폐기 방향 유지 |

**공통:** 학생에게 먼저 돌아갈 가치가 없는 수집을 ‘더 깊은 이해’라는 말로 정당화하지 않는다. 광고 클릭·댓글·저장·시청을 교육 엔진의 개인 성향으로 자동 합치지 않는다. 미확인·무응답은 0이나 부정적 성격이 아니다. 교사와 학생의 확인, 실제 지원 범위가 마케팅 표현보다 먼저다. 내부 선배 집계·소수 기록·익명처럼 보이는 개인 사례도 재식별과 목적을 검토한다.

## 11. 무엇을 보면 잘하고 있는가

브랜드의 최상 효과는 이 문서만으로 보장할 수 없다. **제작 품질 → 상대가 받은 가치 → 관계/사업 결과**를 따로 본다. 조회·저장·완주·구독은 참고 지표일 수 있으나 학습·신뢰·매출의 대리 증거가 아니다. 기존 [명품 눈금](../명품눈금_v1.md)과 실행 정본의 계약상 판정 기준은 바꾸지 않는다.

| 브랜드 | 먼저 관찰할 가치 | 다음 관계/사업 결과 | 잘못된 성공 판정 |
|---|---|---|---|
| LAB | 자기 말로 바꿔 써보는가, 그 장면이 왜 필요한지 본인이 설명하는가 | 맞는 대상의 과정 문의, 실제 체험 후 선택 이유, 수강 뒤 확인된 변화 | 저장=한국어 실력, 진단 참여=구매 적합, 예문 모방=자유 발화 |
| SHIFT | 자료로 자기 조건을 비교하거나 예시 작업을 다시 할 수 있는가 | 대상·문제·사용처가 구체적인 문의, 실제 계약·인수·후속 질문 | 다운로드=고객, 유명 강사=교육 성과, 시연 성공=전 직원 숙련 |
| PULSE | 실제 듣기에서 거슬리는 순간이 없는가, 어떤 시간에 다시 찾는가 | 자발적 재감상·작품 탐색, 권리가 준비된 뒤의 구체 이용 문의 | 동시 시청자 감소=개인 이탈률, 음악 재생=학습/치유 효과 |
| SYNK | 완료물이 누구에게 왜 필요한지 외부인이 이해하는가 | 관련 실물을 언급하는 협업 질문, 회사 역할에 대한 정확한 이해 | 좋아요=기업 신뢰, 로드맵 열람=협약·채용 성과 |

첫 시험은 한 번에 **제시 방식 하나**만 바꾼다. 예: LAB ‘표현 제목 먼저’와 ‘상황 선택 먼저’ 중 어느 쪽에서 학생이 자기 말을 만들기 쉬운지 관찰한다. 작은 편의 표본·노출 시점 차이·비무작위 배정은 그대로 기록하고 우연을 인과 효과로 발표하지 않는다. 학습 내용·교사 지원을 학생별로 차등 배정하는 실험은 하지 않는다.

기록은 `콘텐츠/대상/기간/접한 사람 수/실제 반응 수/반응 예시/무응답/해석/다음 변경`이면 충분하다. 제출 30건을 학생 30명으로 세지 않는다. 플랫폼별 동일인 중복을 모르면 ‘합산 도달 인원’으로 부르지 않는다. 개인의 민감정보 없이 집계하고 SNS 행동을 학생 학습 기록에 자동 결합하지 않는다.

**수정하는 기준:** 예쁘지만 무엇을 받는지 모르겠다 → 제공물부터 수정. 유용하지만 지루하다 → 선택과 사건을 수정. 재미있지만 우리 역할과 무관하다 → 대상/다음 자리 수정. 관심은 있으나 설명이 계속 필요하다 → 조건·문구·도착 화면 수정. 감상은 좋은데 홍보가 거슬린다 → PULSE의 감상 완결성을 회복한다.
