## 공통

- **세로 영상에서 읽히게 찍는다.** 웹 화면은 휴대폰 폭 540·배율 2(가로 1080, S20 방식), 앱 창은 필요한 칸만 잘라 2배로. 로그·상태 출력은 영상에서 다시 그리므로 원문 글자만 정확하면 된다.
- **창만 찍는다.** 바탕화면·다른 창·알림이 나오지 않게 한다.
- **가린다.** 계정 이메일·이름·아바타·이니셜, 조직 이름, 사용자 폴더 이름(`C:\Users\…`), 계정·조직·세션 ID(앞 4자 + `····`), 사이드바의 세션 제목·폴더와 저장소 이름·브랜치와 워크트리 이름·섹션(그룹) 이름·자식 세션과 예약 작업 이름. 공개해도 되는 것만 남기고 나머지는 흐린다.
- **실제 빈 사이드바는 만들지 않는다.** 미러를 끄고 다른 계정으로 들어가 목록을 비우는 재현은 10-17에 세션 기록이 빠졌던 바로 그 상태라 하지 않는다. 0초의 빈 화면은 ① 캡처에서 줄을 빼는 움직임 + 「재현」 칩이다.
- **명령은 PowerShell로.** Claude 앱 안의 Bash에서 돌리면 앱 데이터 경로가 가상으로 풀려 같은 폴더가 두 번 잡힌다(공개판은 이때 (주의) 줄을 띄운다). 상태 출력·기록은 PowerShell이나 앱 밖 Windows 터미널에서 읽는다.
