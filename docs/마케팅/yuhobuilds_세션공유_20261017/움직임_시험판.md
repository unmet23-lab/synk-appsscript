## 이전 이미지 콘티에서 AI 티가 난 까닭

1. **카드뉴스 기본 틀을 장마다 반복했다.** 위 굵은 제목 + 아래 상자 + 칩. SNS 키트 조사도 이 모양을 2026년 한국 AI 정보 계정의 가장 흔한 모양으로 적었다. Tyler 지시문의 「왼쪽 제목 + 오른쪽 카드 금지」와 같은 문제다.
2. **UI 자리에 회색 막대·빈 상자를 그렸다.** 디자이너들이 말한 「예쁘지만 아무 의미 없는 그래픽」으로 읽힌다.
3. **형광펜·크레용·칩·모서리 표시를 한 장에 겹쳤다.** 장식이 내용보다 앞섰다.
4. **장면마다 새 카드였다(14장).** 이어지는 실마리도 카메라도 없었다.
5. **전환을 여러 종류 섞었다(덮개·실땀·아치·종이).** 하우스 스타일이 아니라 템플릿 묶음처럼 보인다.

## 이 편 금지 목록

- 장면마다 「위 제목 + 아래 상자」를 새로 깔기 → 화면 하나가 계속 변형된다
- 회색 막대·빈 상자로 UI 흉내 → 실제처럼 그린 UI 위에 가림 흐림
- 형광펜 긋기, 크레용 동그라미, 화면 모서리 HUD·타임코드·「FILM 01」 같은 요즘 Claude 영상 꼴
- 페이드·크로스페이드·여러 종류 전환 → 변형, 밀기 하나만
- 튕기는 이징, 펄스, 글로, 파티클, 렌즈 플레어, 장식 그라데이션, 화면 전체 질감
- 0.5초 넘게 멈춘 화면, 박에서 벗어난 사건
- 가운데 정렬 글, 기본 Claude 주황

  - 같은 자리에서 머리글을 바꾸니 나가는 글과 들어오는 글이 겹쳐 깨져 보였다 → 박 4프레임 전부터 6프레임 안에 빼고 다음 글을 넣는다.
  - 5.6배에서 물러나는 동안 위 칸들이 머리글을 덮었다 → 목록 창 마스크.
  - 전환을 위로 밀며 흐림·투명을 같이 줬더니 두 장면이 겹치는 흔한 크로스페이드가 됐다 → 한 장으로 이어 붙여 넘김.
- 남은 것: 유호님 확인. 본편에 넓힐 때는 범수 테이크의 줄 시각으로 장면 시각을 다시 잡고, 이 편 배경음을 정하고, 실제 캡처 ①이 생기면 계정 칩 자리·모양을 대조한다.
