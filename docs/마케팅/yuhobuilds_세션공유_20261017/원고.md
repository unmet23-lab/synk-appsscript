## 형식 · 쇼츠·릴스(10-17 유호님 확정)

유호님 10-17 「형식은 쇼츠·릴스로 가자」. **릴스·쇼츠 50초 안쪽**으로 만든다. 비었던 사이드바가 다시 같은 목록으로 차는 전후가 소리 없이도 0초에 읽히고, yuhobuilds 씨앗 계정이 인스타·유튜브다([v2 §4-1](../콘텐츠_제작방식_v2_20261002.md)). 저장소 링크와 기술 설명은 설명란·고정 댓글·프로필 링크가 받친다.

## 누구 · 볼 이유

- **누구:** Claude를 계정 여러 개로 번갈아 쓰는 사람(5시간 한도), 계정을 바꿨다가 작업하던 세션이 사라져 놀란 사람. yuhobuilds 대상(AI 완전 초보부터 AI로 일하는 1인 기업가까지) 가운데 Claude를 일 도구로 쓰는 쪽.
- **볼 이유:** 작업하던 세션이 「다 사라진」 순간, 꼼수가 막힌 실패담, 고친 결과를 다듬지 않고 보여 준다. 형식 메뉴 「다듬지 않은 제작기」 — 망한 화면은 빈 사이드바, 막힌 순간은 거절 1,086번.
- **깨달음 하나:** 폴더를 한 곳으로 이어 붙이면 앱이 막는다. 폴더는 각자 두고 내용을 똑같이 맞춰야 한다.
- **흔한 오해 하나:** 「세션이 사라졌다 = 대화가 지워졌다」 ✕. 대화 원문은 계정과 상관없이 한 곳(`~/.claude/projects`)에 남아 있고, 그래서 기록을 되살릴 수 있었다.
- **재미 장치:** 실패담(앱이 1,086번 거절), 반전(목록은 보이는데 저장은 안 됨), 전후 비교(빈 사이드바 → 어느 계정이든 같은 목록).
- **행동 하나:** 프로필 링크에서 도구 받기(공개 저장소). 댓글 질문은 영상이 아니라 게시 문구·고정 댓글에 둔다.
- **계정·시험:** yuhobuilds 인스타·유튜브. 팔로워 200명 전이라 훅 두 안을 플랫폼으로 나눈다(인스타 A · 유튜브 E, v2 §2-1). 같은 계정에 같은 영상을 다시 올리지 않는다.

## 게시 문구

> 10-18 본편이 결과 먼저(「Claude 5시간 한도 차서 계정을 바꿔도, 세션이 그대로 이어져요」)로 바뀌고 유튜브도 같은 판을 쓰게 됐다. 그에 맞춰 게시 문구를 다시 썼다(아래 「게시 문구」). 끝은 같은 날 유호님 「좋아. 끝을 댓글 「세션」 + 팔로우로 바꿔줘.」로 바뀌었다 — 인스타는 댓글 DM(아래 「댓글 DM 전달 설정」), 유튜브는 DM이 없어 고정 댓글의 링크로 받는다(고정 댓글 초안 그대로).

### 댓글 DM 전달 설정 초안(인스타 @yuhobuilds)

제작 방식(§3, [제작·게시·등록 연결](../댓글DM_제작게시연결.md))대로 게시 원고와 함께 승인받는다. 아직 게시 묶음을 만들지 않아 `tools/sns-DM준비.js`는 돌리지 않았다. 게시 뒤 등록까지 마쳐야 자동 전달이 시작된다(`state=registered`·D코드·`catchup_verified=true`).

- 키워드: `세션`
- 자료명: 계정 바꿔도 세션 그대로 — claude-session-share
- 자료: 웹 링크 `--자료URL https://github.com/unmet23-lab/claude-session-share`(README에 설치 한 줄·지원 범위가 있다), 상시(`--상시`)
- 첫 안내 문구: 「세션」 남겨 주셔서 고마워요. 계정을 바꿔도 Claude Code 세션 목록이 그대로 보이게 하는 도구예요. 링크의 「빠른 시작」 3단계대로 PowerShell에 한 줄만 붙여 넣으면 돼요(윈도 Claude 데스크톱, Node.js 20 이상). 앞으로도 계속 업데이트할 예정이라, @yuhobuilds를 팔로우해 두시면 새 기능과 다음 도구를 가장 먼저 받아 보실 수 있어요.
- 공개 답글: DM으로 링크 보내 드렸어요 🙌 도움이 됐다면 좋아요, 업데이트 소식은 팔로우로 받아 보세요!
- FAQ(선택, README 사실만): 맥도 되나요? → 지금은 윈도 Claude 데스크톱에서만 확인했어요. / 대화가 지워지진 않나요? → 대화 원문(~/.claude/projects)은 건드리지 않고, 세션 목록 폴더만 계정마다 똑같이 맞춰요.
- 좋아요·팔로우(10-18 유호님 「댓글과 좋아요+ (팔로우 유도) 단 사람한테 알려주는거로」): 좋아요는 캡션·고정 댓글에서 「좋아요 누르고 댓글에 「세션」」으로 부탁하고, 팔로우는 첫 안내·공개 답글·캡션에서 권한다(유튜브는 고정 댓글·설명에서 구독·좋아요). 둘 다 전달 조건으로 검사하지는 않는다 — 인스타는 누가 좋아요를 눌렀는지 알려 주지 않고(10-07 결정 「좋아요는 확인 조건으로 검사하지 않고 부탁만」), 팔로우 확인은 로컬 시험만 했고 운영에는 배포되지 않았다(제작 방식 §3). 그래서 「세션」 댓글을 단 사람은 모두 받는다.

### 게시 문구(10-18 본편 기준)

지금 영상(결과 먼저 · 끝은 댓글 「세션」 + 팔로우)에 맞춰 다시 쓴 판은 [`게시/`](게시/)에 있다: [인스타](게시/instagram_yuhobuilds.txt) · [유튜브 제목·설명](게시/youtube_yuhobuilds.txt) · [고정 댓글(인스타·유튜브)](게시/고정댓글.txt) · 표지 [`게시/표지_1080x1920.jpg`](게시/표지_1080x1920.jpg)(10-18 전후 비교 표지: 「계정 바꿔도 / 세션 그대로」 + 「전 · 다 사라짐」 → 「후 · 그대로」 두 판, 프로필 격자 3:4 안). 10-18 「사라짐 → 그대로」로 여는 판이 돼도 캡션 첫 줄(= sum2에서 「지금은」을 뺀 말)과 표지 제목이 같은 약속이라 캡션은 그대로 둔다. 사실은 위 「사실 대조」 표에서만 가져왔다. `[저장소 링크]`는 「올리자」 때 공개 주소로 채운다. 옛 초안(훅 A·E 기준)은 git 기록에 있다.

**업데이트 안내(10-18):** 유호님 「이 기능은 지속적인 업데이트가 될 예정이고 7일 뒤 유료로 전환 예정이라고 알려줄래 ?」로 캡션·설명·고정 댓글·DM 첫 안내에 업데이트·유료 전환 안내를 넣었다가, 「아니다. 유료 전환 내용은 지금 넣지 말자. 오해 살것같아.」로 유료 전환과 「지금은 무료」는 모두 뺐다. 다섯 곳에는 「앞으로도 계속 업데이트할 예정이에요」만 남겼고, 같은 날 좋아요·팔로우 부탁에 맞춰 그 줄을 팔로우(유튜브는 구독) 권유와 이었다. 영상에는 넣지 않았다.

## 정할 것

1. **형식:** 쇼츠·릴스 50초 안쪽으로 정함(10-17 유호님 「형식은 쇼츠·릴스로 가자」).
2. **목소리:** **범수로 바꿈(결정 표 10-17 「영상 나레이션에 Gemini TTS 안 씀」).** 같은 날 다른 세션에서 노트북 이사 편 Achird 나레이션을 들으신 유호님이 「나레이션이 너무 별론데?」 → 「앞으로 이거 쓰지 마. 범수로 하자.」라고 정하셨고, 이 편의 Achird 선택보다 나중의 일반 규칙이라 범수 판(`음성/범수/`, 1.12배 47.9초)을 쓴다. 범수 판은 받아쓰기에서 「한도가」가 「한두가」, 「클로드」가 「클러드」로 들려 귀로 확인한다. 아래는 그 전 기록이다. 10-17 유호님 「둘 다 한번씩 들어볼수있을까 ?」 → 같은 대본을 둘 다 읽혀 `음성/듣기/`에 뒀다(Achird 56.0초, 범수 1.12배 47.9초). 「니 생각엔 뭐가 나은것같아?」에 Achird를 권했고(이야기형 목소리, synkbrief는 범수라 채널마다 갈림, 고칠 곳 없음, 한 번에 읽어 말이 이어짐), 유호님 「오케이」 → 「그럼 일단 그냥 진행하자」. TTS 비용은 지금처럼 unmet27 구글 클라우드 무료 크레딧으로 나가고, 77yuhbs Ultra에 딸린 클라우드 크레딧 등록은 서버비 결제 계정과 같이 나중에 정한다.
3. **프로필 링크:** 인스타 프로필 링크에 저장소를 하나 더함 / 프로필의 synk.im/builds 첫 화면에 저장소 카드를 둠. 어느 쪽이든 프로필 설정을 바꾸는 일이라 유호님 말씀 뒤에 한다. → 10-18 끝을 댓글 「세션」(인스타 DM)·고정 댓글 링크(유튜브)로 바꿔 꼭 필요하지는 않게 됐다(하면 좋음).
4. **0초의 빈 사이드바:** 실제 사이드바 캡처에서 줄이 빠지는 움직임 + 「재현」 칩(콘티 기본) / 글자 카드. 유호님 「그럼 일단 그냥 진행하자」에 따라 콘티 기본안으로 이미지 콘티를 만든다. 이미지 콘티를 보시고 바꿀 수 있다.
5. **AI가 한 일:** 밝히지 않고 1인칭 그대로 간다(10-17 유호님 「AI 얘기는 빼고 1인칭 그대로 가자」). 훅 E와 t1은 지금 문장 그대로 둔다. 설명란의 「내레이션은 AI 음성이에요」는 이야기가 아니라 플랫폼 표시라 그대로 둔다.
