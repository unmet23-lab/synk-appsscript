## 1. 판정 — 「고쳐서」

뼈대는 시험판 그대로 넓혀졌다. 판 하나가 사이드바 → 폴더 칸 → 로그 창 → 줄 21개 → (밀기) 폴더 셋 → 상태 창 → 칸 → 사이드바 → 로그 창 → (밀기) 종이 → 카드로 52초를 끌고 가고, 숫자·줄은 발췌와 글자까지 같고, 큰 사건이 전부 박이나 낱말 위에 있다. 남은 건 값 문제다 — 10b(계정 넷 모두 76)가 읽히기 전에 넘어가고(높음), 새 장면 네 곳에서 시험판이 금지한 전환(크로스페이드·와이프+페이드인·빈 흰 판)이 다시 나오고, 06 「두 시간」 머리글 지연·07 1.2초 정지·04 같은 그림 6초·05 로그 24px가 남았다. 전부 time.ts·tsx 숫자로 고칠 수 있어 「다시」는 아니다.
