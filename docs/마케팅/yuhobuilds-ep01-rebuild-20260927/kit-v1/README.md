## 목소리 바꾸기(유호님 육성이 오면)

말과 화면을 잇는 자료는 셋으로 나뉘어 있다.

| 파일 | 내용 | 바꾸는 때 |
|---|---|---|
| [data/script.json](data/script.json) | 화면 자막 원고 32구절(`c01`~`c32`), `*강조*`, 질문 창으로 보낼 구절(`hide`) | 대사를 바꿀 때만. 구절 id와 낱말 수가 바뀌면 `data/plan.js`와 `index.html`의 `at('c06.w3')` 같은 낱말 기준점을 같이 본다 |
| [data/timing.js](data/timing.js) | 자동 생성. 구절·낱말마다 시작·끝 시각, 영상 길이 | 녹음이 바뀔 때마다 `tools/make-timing.cjs`로 다시 만든다 |
| [data/plan.js](data/plan.js) | 장면 순서·전환·효과음을 자막/낱말 기준점으로 적은 표. 브라우저와 Node가 함께 읽는다 | 연출을 바꿀 때만 |

순서(이 폴더에서):

```bash
# 1. 받아쓰기(한국어 모델을 꼭 지정한다. 기본 small.en은 한국어를 영어로 번역해 버린다)
npx --yes hyperframes@0.8.104 transcribe <녹음.wav> --model small --language ko
#    → 낱말 [{text,start,end}] JSON. 결과 파일 경로를 아래 --words에 준다

# 2. 녹음을 assets/audio/voice.m4a로 넣고, 대본과 글자 단위로 맞춰 data/timing.js를 만든다.
#    index.html의 길이(data-ep-dur 붙은 루트·음성·음악·효과음 4곳)도 녹음 길이로 고친다
node tools/make-timing.cjs --voice <녹음.wav> --words <transcript.json>

# 3. 효과음을 새 시각으로 다시 깐다(길이가 바뀌었으면 음악도 V2와 같은 처리로 다시 맞춘다)
node tools/make-sfx.cjs

# 4. 음악 깎기(voiceover carve)를 새 목소리 기준으로 다시 쓴다(V2와 같은 세기 0.6)
node ~/.claude/skills/hyperframes-audio/scripts/carve.mjs --comp index.html --bed bgm --voice voice --strength 0.6 --core ..

# 5. 검사와 눈 확인
npm run check
npx --yes hyperframes@0.8.104 snapshot --at <장면 중간들>
```

- 장면 전환·강조·효과음은 모두 기준점으로 계산하므로 1~5만 하면 새 말에 맞춰 함께 옮겨 간다. 자막 글자색(흰 종이 장면은 검정, 검정 면은 흰색)도 그때의 장면으로 다시 고른다.
- `make-timing.cjs`는 받아쓰기와 대본을 글자 단위 편집 거리로 맞춘다. ‘6월/유월’처럼 표기가 달라도 맞고, 못 맞춘 낱말은 앞뒤 사이로 채운다. 녹음에서 대본을 바꿔 읽었으면 `data/script.json`을 실제 말에 맞게 고친 뒤 2번부터 다시 한다.
- 다시 임시 음성으로 돌리려면 `node tools/make-timing.cjs`(인자 없음)가 `../revision-v2/timing.json`의 시각을 그대로 옮긴다.
- 키트를 고쳤으면 먼저 `node tools/SNS키트_영상연결.js <이 폴더>`(저장소 루트에서)로 `assets/synk-kit/`을 새로 복사한다.
