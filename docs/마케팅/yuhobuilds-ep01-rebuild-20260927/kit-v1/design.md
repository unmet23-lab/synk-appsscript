# 디자인 기준

이 프로젝트의 화면·색·서체·부품·움직임은 [SYNK SNS 제작 키트](../../../디자인/SNS키트/README.md)가 원문이다. `assets/synk-kit/`은 `node tools/SNS키트_영상연결.js <이 폴더>`로 복사한 키트 사본이고(저장소에는 올리지 않는다), 고치려면 키트 원본을 고친 뒤 다시 복사한다.

- 계정 테마: `builds`(검정 `#0A0A0A` 면 + 버터 `#F5C445` 강조, 흰 종이 안쪽 장), 흰 펠트 synk 로고
- 서체: SUIT Variable(한글·라틴), DM Mono(라벨·날짜)
- 판: `cover916`, 메타 통합 안전 영역 위 269 · 아래 672 · 옆 65(오른쪽 160은 버튼 자리). 자막은 아래끝 y 1236, 자막이 나오는 장면의 내용은 y 1040까지
- 움직임: 키트 `motion.js`(SynkMotion) 프리셋만. 규칙은 키트 README §9
- 얼굴: 실제 사진(키트 `photo-yuho-interview-front.webp`)과 창업자 인터뷰 v9 촬영 프레임만
- 개념 한 줄: 기능 카드에 묻힌 ‘출석’을 꺼내, 한 줄짜리 완성 기준과 실제로 눌러 본 화면으로 정리한다
