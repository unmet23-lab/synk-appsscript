## 무엇이 달라졌나

“오늘은 AI로 출석 앱 만들다, 정작 출석을 까먹은 얘깁니다.”로 상황과 반전을 함께 연다. 6월의 번역용 결제 → 학생 문의 증가 → 개발 초보의 화면 찍기·질문·따라 하기 → 기능 욕심으로 목표를 놓친 경험을 거쳐, 현재의 조언과 직접 시연으로 연결한다. 추정 절감 시간 숫자 대신 ‘학생 한 명의 출석을 저장하고 다시 확인하기’라는 구체적인 보상을 보여준다.

9개 큰 장면 안에서 기능 카드 누적, 표정 반응, 화면 교체, 선택·저장·목록 생성·재열기, 발화에 맞춘 질문 입력이 이어진다. 새 정의로 음성 18개와 문장 호흡으로 편집한 자막 40개, 타이핑·클릭·전환 등 효과음 46개를 사용한다. 음악은 이전 승인 제작 자산을 재사용하고 목소리와 겹치는 대역을 줄였다.

## 사실과 예시

6월 2일 첫 Claude 결제는 번역용이었다. 몽골 울란바토르 학원 부원장, 학생 문의 증가, 처음 개발을 배우며 출석 앱에 기능을 늘리다 목적을 놓친 과정은 사용자 회고에 따른다. 현재 제안하는 질문·완성 기준과 가상 학생 A 시연은 지금 만든 학습용 예시다. 당시 앱이 학원에서 운영됐다는 의미가 아니다.

실습 파일은 같은 브라우저의 저장 공간만 사용한다. 학원 운영용 서비스가 아니며, 다른 기기로 기록을 동기화하지 않는다. 기존 PDF 가이드는 이전 질문을 다루므로 이번 배포 묶음에 넣지 않았다.

## 확인 범위

HyperFrames 최종 check의 구조·런타임·레이아웃·대비 검사를 통과했다. 실제 출력 프레임을 추출해 도입, 반전, 목표, 시연, 입력, 엔딩을 확인했다. 전체 MP4 디코딩, 1,694프레임, 56.47초, H.264/AAC, 검은 구간과 음량은 [최종 검사 JSON](audit/final-validation.json)에 기록한다. 자막의 전체 문장은 합성 원고와 일치하며, 낱말 하나만 남는 자막과 겹치는 시간은 제거했다.

실습의 실제 JavaScript를 새 페이지 환경과 공유 저장소로 실행해 저장, 다시 읽기, 중복 저장, 초기화, 저장 거부 안내를 확인했다. 로컬 미리보기는 HTTP 200, MP4 구간 요청은 206을 확인했다.

브라우저 연결 도구가 `failed to write kernel assets (os error 3)`로 초기화되지 않아 **실시간 브라우저 재생과 직접 청취, 실습의 브라우저 클릭 검증은 미확인**이다. 자동 검사·출력 프레임 검수와 구분한다. 사용자에게 링크를 여는 요청은 Codex 앱에서 queued로 접수됐다.

## 다음 수정 시

원본 자료는 `narration-script.json`, `audio/narration-*.json`, `timing.json`에 있다. 목소리는 임시 정의로이며 사용자 자기 목소리로 교체할 수 있도록 분리돼 있다. Typecast 키는 파일에 저장하지 않았고 이번 합성 뒤 연결을 해제했다.

화면: `build-scenes.cjs` → `finalize-html.cjs`. 음성·길이를 바꾸면 먼저 `prepare.cjs`를 실행한다(문장별 자막 보정 포함). 재생성 뒤 `hyperframes-audio/scripts/carve.mjs --comp index.html --bed bgm --voice voice --strength 0.6`으로 음악 처리를 다시 적용한다. `index.html`의 carve 속성을 잃지 않도록 순서를 지킨다. `hyperframes check --json`, snapshot, render, `node verify-delivery.cjs`로 확인한다.

GSAP은 공식 CDN 참조를 사용한다. 같은 minified 파일을 로컬 script로 바꾸면 HyperFrames 0.8.78 번들러에서 `Maximum call stack size exceeded`가 재현됐다. CDN 참조로 빌드·렌더는 통과했으며 최종 MP4 재생에는 CDN이 필요 없다.

미리보기 재시작: 이 폴더에서 `node serve.cjs` (4377). 편집기: `npx hyperframes preview --background --port 4380 --no-open`. 서버와 무관하게 MP4를 직접 열 수 있다. 이전 73초 영상·PDF는 기존 제작 폴더에 보존했다.
