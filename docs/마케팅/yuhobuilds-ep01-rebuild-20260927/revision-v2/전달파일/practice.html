저장만 하지 말고,
다시 열어서 확인해 보세요.

영상의 작은 예제를 직접 눌러보는 페이지예요. 목표는 딱 하나: 학생 한 명의 출석을 저장하고, 다시 확인하기.

출석 기록학습용 예시

저장된 기록

가상 학생 A · 06.02는 영상과 맞춘 예시 날짜예요.
이 예제는 지금 만든 학습용 화면이며 실제 학원 앱이 아니에요.

이 순서로 해보세요

  1. 학생 A를 선택하고 ‘출석 저장’
    아래 목록에 이름·날짜·출석 표시가 생겨요.
  2. ‘다시 열어 확인’을 누르기
    페이지가 새로 열려도 기록이 남아 있는지 보세요.
  3. 끝났는지 스스로 판단하기
    저장하고 다시 확인할 수 있으면 첫 목표는 완료예요.

포인트
“앱을 멋지게 만들어 줘”보다, “무엇이 되면 완성인지”를 먼저 정하면 다음에 할 일이 선명해져요.

이 문장을 복사해서 AI에게 보내세요

아래 두 번째 문장을 내가 만들고 싶은 것 + 확인할 수 있는 결과로 바꿔 주세요.

텍스트 파일 받기

다른 아이디어라면 이렇게 바꿔요

가계부: “지출 한 건을 저장하고, 다시 열어 금액을 확인하고 싶어.”
할 일 관리: “할 일 하나를 추가하고, 완료 표시가 남는지 확인하고 싶어.”

AI가 방법을 여러 개 제안하면 “내가 지금 가장 쉽게 시작할 수 있는 하나를 골라, 첫 단계만 알려줘”라고 이어서 물어보세요.

이 예제에서 기록은 어디에 남나요?

이 브라우저의 저장 공간에만 남아요. 다른 컴퓨터나 브라우저에는 보이지 않으며 브라우저 데이터를 지우면 사라져요. 실제 학생 정보를 넣는 운영용 서비스로 쓰는 예제가 아니에요. 지금은 저장과 재확인이라는 작은 원리를 체험하는 단계예요.
