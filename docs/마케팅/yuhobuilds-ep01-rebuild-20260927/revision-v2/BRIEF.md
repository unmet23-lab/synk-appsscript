# EP01 전면 재제작

## V2 후속 요청 · 2026-09-27

사용자가 V1의 표시·자막·템포·모션 마감을 반려했다. 기존 정의로 음성은 음높이를 유지하면서 속도 1.2배로 처리하고 47.07초로 맞춘다. 자막은 32개 고정 구절로 다시 배치하며 6월/1인 숫자 표기, 타이핑 줄 위치, 자막을 덮지 않는 전환을 적용한다. 출력 MP4의 모든 자막과 교체 경계를 추출하여 확인한다. 사용자 주관적 시청 승인과 직접 재생·청취의 미확인을 기술 검사와 구분한다.

사용자 요청: 기존 1편을 새로운 방식으로 전부 재제작. 정보와 재미 모두 충족하고 직관적인 학습의 쾌감까지 제공한다. 전체 영상 제작·렌더는 이 요청으로 진행한다. 외부 게시와 신규 구매는 포함하지 않는다.

## 시청자가 볼 이유

AI에게 물으며 만들지만 기능만 늘고 무엇을 먼저 끝내야 할지 모르는 초보자가, 끝났는지 스스로 확인할 수 있는 첫 목표를 정하는 방법을 배운다.

## 정보와 재미

- 정보: 완성 기준은 행동과 확인 방법을 함께 적는다. 학생 한 명 선택 → 출석 저장 → 다시 열어 기록 확인의 예시, 그대로 바꿔 쓸 질문을 제공한다.
- 재미: 기능 카드가 점점 주인공과 출석 목표를 덮는 과장된 코미디 → 갑자기 멈추고 본래 목적 발견 → 복잡한 카드가 한 줄로 정돈 → 실제 동작하는 예시의 만족스러운 저장·재확인.
- 시청 후 행동: 자기 일에서 첫 번째로 저장·확인할 작은 결과를 한 줄로 쓰고 AI에 질문하기.

## Assets

사용자 얼굴의 승인 파생 표정·사진, 기존 시티팝 음악과 효과음 자산을 재활용할 수 있다. 디자인·타이밍·대사는 새로 만든다. Typecast 정의로 임시 보이스를 기존 구독 크레딧 안에서 사용하며 키는 메모리에만 연결한다.

## Customizations

전체 재구성이라 기존 100시간 오프닝·길어진 탈모 농담·넓은 로드맵 질문은 새 대본으로 대체한다. 몽골 학원에서 번역용 AI→출석 앱으로 시작한 배경은 짧지만 충분히 연결한다. 실제 학원에서 사용했다는 주장은 하지 않는다. 시연은 지금 만드는 가상 학생 예시임을 화면에 간단히 표시한다. 박자는 보통 2~3초, 중요한 시연만 약5초까지 같은 정보를 유지하며 부분 초점·진행으로 장면을 전개한다. 고정 텍스트를 장시간 읽히지 않는다.

## Output

새 원고·소스·음성·1080x1920 MP4·SRT·표지·로컬 재생 페이지·복사용 질문 TXT·직접 해보는 학습용 예시. 이전본은 보존한다. 실제 렌더·디코딩·재생·청취의 확인 범위와 미확인을 구분한다.
