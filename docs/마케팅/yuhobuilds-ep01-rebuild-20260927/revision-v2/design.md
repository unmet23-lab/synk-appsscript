# EP01 · 작은 완성

V2: 47.07초. 1.2배 템포에 맞춰 제목의 줄별 마스킹·짧은 카메라 이동·카드 누적·리액션·실습 클릭 강조를 적용한다. 하단 자막은 한 글자씩 바꾸지 않고 미리 배치된 32개 구절을 교체하며, 전환 패널보다 위에서 읽히도록 한다. 질문 타이핑은 각 글자의 위치를 고정한다.

Concept: 출석 목표를 덮어버린 기능 카드의 혼란이 한 줄의 완성 기준과 작은 작동 화면으로 정리된다. 웃음과 이해의 쾌감이 같은 이야기에서 발생한다.

- 1080×1920, 30fps. 사용자가 원하는 빠른 세로 쇼츠. 장면 안에서 약2~3초마다 초점과 행동이 바뀐다.
- 종이 #F5F3EE, 잉크 #18232D, 코발트 #365EE7. 코믹 오류에만 #E64938, 완료는 #DFFF6A 위 잉크. 따뜻한 밝은 바탕을 기본으로 반전·결론만 잉크 바탕.
- 로컬 SUIT Variable 550~950. 메인 글자90~116px, 본문48~58px, 보조30~34px. 숫자에 generic monospace를 제한적으로 사용.
- 왼쪽64~96px, 오른쪽108px 안전 여백. 메인 y220~1390, 자막 y1460~1615. 하단250px에는 필수 내용을 두지 않는다.
- 카드가 실제 출석 목표와 연결될 때만 사용. 동일 제목+카드의 반복을 피하고 얼굴/기능 더미/명확한 한 문장/실제 출석폼/기록 확인/복사 질문으로 시각 세계를 바꾼다.
- 사용자 얼굴은 승인된 사진 파생 이미지 그대로 사용. 설명용 가상 학생은 ‘학생 A’. 실제 당시 앱·학생 화면으로 오인되지 않게 시연에만 간단한 라벨.
- 움직임: waterfall-entry 텍스트 도착, spring-pop-entrance의 작은 탄성, discrete-text-sequence의 발화 동기 입력, coordinate-target-zoom의 시선 이동. 설치된 text-stagger 및 zoom-through-transition에서 구조를 차용한다. 작은이동에도 상황전후상태가있어야 한다.
- 컷 경계는 짧고 정확하게 연결. 주인공 표정 변화, 혼란→정돈에서만 큰 움직임. 모든 카드가 끝없이 떠다니는 루프 금지.
- 서사1: 오늘은 출석앱 만들다 출석을 놓친 이야기. 서사2: 한 줄이면 덜 헤맬 수 있다는 구체적인 보상. 이후 실제 경험으로 이유를 설명하고 시연과 질문으로 약속을 회수.

## 적용한 보조색과 실제 표시 규격

- UI 테두리·보조 글자·카드 면·그림자에는 위 주요색의 밝기 파생을 사용한다: #18232D, #2444B2, #365EE7, #64717C, #66727B, #9CA8B2, #B0B8BF, #B6C1CF, #D8DDE5, #D9E1F8, #DADFE5, #DFFF6A, #E64938, #E7EDFF, #E8EEFB, #E9EFFF, #ECEFF3, #F5F3EE, #FFFDF8.
- SUIT는 보조 브랜드 500부터 핵심 950까지, 보조 캡션·예시 라벨은 26~44px도 허용한다. 얼굴은 기존 승인 파생 이미지다.
- 타이핑을 제외한 일반 진입은 0.18~0.4초. 긴 타임라인 드라이버는 자막·타이핑·진행률 계산용이며 물체를 계속 움직이는 연출이 아니다.
