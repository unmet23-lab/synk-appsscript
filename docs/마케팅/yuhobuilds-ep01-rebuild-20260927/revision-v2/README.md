## 수정

- 기존 정의로 음성의 음높이를 유지하며 1.2배 속도로 처리했다. 56.47초 → 47.07초. 자막·타이핑·장면·음악·효과음 시점도 함께 조정했다. 추가 음성 합성이나 API 키 연결은 하지 않았다.
- 합성용 발음 표기와 화면 표시를 분리해 화면에는 ‘6월’, ‘1인’을 쓴다. 자막은 문장 호흡으로 묶은 32개 고정 구절이며 한 글자씩 업데이트하지 않는다. 각 줄을 미리 배치해 나타나는 동안 줄바꿈이 흔들리지 않는다.
- 제목의 줄별 등장, 문장 강조에 맞춘 확대·복귀, 카드 누적과 표정 반응, 시연 클릭·기록 강조, 연결선과 완료 표시를 다듬었다. 3곳의 빠른 화면 전환은 자막 아래에서 움직인다.
- 질문 타이핑은 고정된 글자 위치에서 음성에 맞춰 드러나며, 다른 줄이 뒤늦게 밀리지 않는다. 질문과 학습 예시의 의미는 유지한다.

## 검수 범위와 한계

HyperFrames check, 전체 MP4 디코딩·프레임 수·음량·검은 구간 검사, 모든 자막 중간 32장과 교체 전후 115장의 실제 MP4 추출 화면을 확인했다. 자막 문장 전체를 합성 원고와 대조하며 합성용 ‘유월/일인’만 화면의 ‘6월/1인’으로 대응시켰다. −18.3 LUFS/−2.46 dBTP, 검은 구간 없음. 미리보기와 자료 HTTP 200, 영상 구간 요청 206, 전달 ZIP과 원본 영상 해시 일치를 확인했다. 숫자 검사만으로 자막 줄바꿈이나 발화 일치를 검증했다고 간주하지 않는다.

브라우저 연결 도구가 `failed to write kernel assets (os error 3)`로 초기화되지 않아 실시간 브라우저 재생과 직접 청취는 미확인이다. 출력 화면·파일 검사와 이 한계를 구분한다. 미리보기 서버가 없어도 MP4를 직접 열 수 있다. 출력 이미지와 로그는 `audit/`에 둔다.

## 다시 수정할 때

`build-scenes.cjs` → `finalize-html.cjs` → `refine.cjs` 순서로 실행한다. 이후 기존 오디오 carve 처리를 적용하고 check·render·`verify-v2.cjs`·`package-v2.cjs` 순서로 확인한다. 준비 스크립트 `../prepare-revision-v2.cjs`는 V1 빌더와 타이밍을 다시 복사하므로 이 수정본에 무심코 재실행하지 않는다.

`yuhobuilds_EP01_V2_120pct_1080x1920.mp4`는 자막 위로 전환이 덮이던 중간 출력이다. 배포용은 위의 `V2_FINAL` 파일만 사용한다. V1 영상은 상위 폴더에 보존했다. 전후 버전의 공개 게시나 사용자 승인 여부를 혼동하지 않는다.
