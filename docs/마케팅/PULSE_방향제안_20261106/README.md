## 「톡」 도망 결말(11-06, 유호님 「…왜요? 하고 … 농구하다말고 달려오고 주인공은 그때 도망가는거로 (프레임 아웃)」 → 「응, 구워」)

**구운 것:** 「톡」 시작 그림(판 c2) 그대로 시댄스 2.5 8초 두 판(`006_dp-tok-run`, 멈춘 세상 → 한 모금 → 「…왜요?」 → 공이 떨어지고 모두 캔을 봄 → 몰려옴 → 캔을 안고 왼쪽으로 화면 밖 → 사람들이 지나감 → 공만 굴러 멈춤). 두 판 모두 「왜요?」가 들렸다(Scribe 2.2초대).

**맹검 뒤 크레딧 없이 고친 것(A):** 첫 장에 같은 「톡」을 얹었다 — 이 안의 한 문장 「캔 따는 소리 한 번에 코트 전체가 멈춰요」의 까닭이 받은 판에 없어 굳은 뒤 코트가 까닭 없이 보였다(둘 다 「사진에 앞사람만 움직인 AI」). 처음 「톡」과 끝의 화면 밖 「톡」이 짝이 된다. 빈 코트는 3초에서 약 2초로 줄여(Fable 「릴스에선 길다」) 공이 구르는 7.3초에 「톡」과 끝 줄이 오고, 사람들이 빠지는 7.1초부터 코트 소리를 -10dB로 내려 「톡」만 남겼다(현장 노트 영상 · 「화면 밖 멀리서」 효과음). 완성본 9.0초, -14.1 LUFS · 최고 -1.0 dBFS. git 밖 `움직임/받음/_본편/톡_결말A_빈코트.mp4`, 만드는 도구 `움직임/톡편.py`.

**못 고친 것(다시 구워야 함, 둘 다 짚음):**
- **왜 쫓는지 안 읽힌다.** 아무도 캔을 가리키거나 손을 뻗지 않는다. 사람들은 한결이 나간 왼쪽이 아니라 카메라 쪽 · 오른쪽으로 빠진다(Fable).
- **0~2초 뒤 코트가 「멈춘 세상」이 아니라 「사진」으로 읽힌다.** 지시문은 모두가 고개를 돌려 한결을 보게 했지만, 시작 그림의 선수들이 경기 자세라 시댄스가 첫 장을 지켰다 — 시작 그림부터 「모두 한결을 쳐다보며 굳은」 판으로 다시 구워야 한다.
- **끝에 제품이 없다.** 「아니, 잠깐」의 끝 「톡」 컷은 밤 폰 플래시 결이라 노을빛 CF 결인 이 판에 붙이면 다른 영상이 된다. 같은 빛의 캔 컷이 따로 필요하다.
- 4.85~5.15초 몸을 틀며 볼이 눌린 얼굴(0.3초), 사람 컷의 작은 한글 라벨 뭉개짐.

**다시 굽는다면(유호님 결정):** 시작 그림을 GPT 이미지 2.5로 다시(멈춘 선수 전원이 한결의 캔을 쳐다봄, 구독 안) → 8초 두 판(「톡」 → 「…왜요?」 → 한 명이 캔을 가리키며 외침 → 전원 왼쪽으로 뒤쫓고 한 명은 캔 쪽으로 손을 뻗음, 약 300크레딧) → 같은 빛의 끝 캔 컷 4초 두 판(약 150크레딧).

## 안 잰 것

- **움직임 맛보기를 본 손님 반응.** 맹검은 정지 화면만 봤다. 판정은 유호님이 페이지에서 보고 들으신 뒤다(세션 안 재생은 소리가 깨질 수 있어 내려받아 듣는 것이 정확하다).
- **실제 손님 반응.** 심사는 모두 AI이고 실주문은 0건이다. 재기 시작할 것: 방향 선택까지 걸린 시간, 「둘 다 아니에요」 비율, 글 콘티 첫 판 승인율, 수정 회차.
- **환불 규정 · 부가세 표기.** 화면에 없다. 사업자 결정 뒤에 정할 일이고, 결제 시점을 글 콘티 뒤로 두면 그 앞까지는 환불 문제가 없다.
- **실제 앱 연결.** 옛 「콘셉트 비교」 자료(`studio.concepts` · `selectedConcept`)를 쓰면 되는지는 설계 때 본다(Fable 설계 검토 뒤 구현).
