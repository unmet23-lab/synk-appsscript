- **L1. 아래 표시 「실제 화면 · 10-20 17:4x」**는 자리 표시 글이다. 캡처마다 실제 시각으로: 04 「17:48」, 05 틱톡 「17:50」·샤오훙수 「17:51」, 01의 BS 캡처를 쓰면 「17:45」.

- **L3. 03 「실제 API 출력 첫 줄」**: 「SYNK LAB | Learn Korean … 최근 30편」까지만 두고 그 아래 줄은 H3 값으로 흐림. 「private」 글자는 LAB에 비공개 영상이 있다는 뜻이 되지만 제목이 없으면 문제없다.

- **L7. 받아쓰기 확인**: 「에이피아이로」(「API로」로 적히는지), 「레드노트로」, 「샤오훙수는」(「샤오홍수」로 듣기 쉬움 — 머리글이 「샤오훙수」라 뜻은 안전). 「열두 곳을 다 돌고 와서」 쉼표 뒤 숨이 짧으면 Typecast 쉼표를 하나 더.
