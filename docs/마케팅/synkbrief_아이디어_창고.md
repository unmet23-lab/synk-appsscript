# synkbrief · 콘텐츠 아이디어 창고

2026-09-22 생성 · 사용자가 알려주는 재미있는 AI 기능, 소개할 도구·스킬, 뉴스, 활용 아이디어를 계속 쌓는 곳.

[채널 방향](채널과_발행.md#synkbrief의-ai-뉴스추천활용법) · [유형별 제작 양식](콘텐츠_제작양식.md)

## 저장하는 방법

- 사용자가 synkbrief에 소개하고 싶은 기능·도구·소재를 말하거나 링크를 주면 이 파일에 바로 기록한다. “아이디어로 저장해”라는 문구를 매번 붙일 필요는 없다.
- 사용자의 원래 말과 관심 포인트를 보존한다. 내가 보탠 콘텐츠 각도·도입 문구·활용 장면은 제안이라고 구분한다.
- 정보가 적어도 먼저 저장한다. 링크·정확한 기능명·사용 조건이 없으면 미확인으로 남기고, 저장을 위해 질문을 반복하지 않는다.
- 같은 아이디어에 대한 추가 설명은 기존 항목에 날짜와 함께 붙인다. 다른 용도나 시청 상황이면 별도 아이디어로 나눌 수 있다.
- AI 뉴스·새 기능 소개·실무 활용법·도구와 스킬 팁·비교 등으로 가볍게 분류한다. 초보자가 이해할 수 있는 소재도 포함한다. 형식·난이도·길이는 소재를 제작할 때 정한다.
- 상태는 `저장` → `검토` → `제작 중` → `게시 완료`로 기록하고 필요하면 `보류`를 쓴다. 저장만 한 아이디어를 제작 확정이나 게시 완료로 취급하지 않는다.
- 제작으로 이어지면 해당 원고·시연·작업 폴더를 연결한다. 최신 기능·뉴스의 사실과 이용 가능 여부는 제작 시점에 확인한다.

## SB-001 회의 메모를 할 일 표로

- **등록일:** 2026-09-22. 기존 대화에서 선택해 제작하던 소재를 이 창고로 연결한 날짜다.
- **사용자가 선택한 아이디어:** “회의 메모를 AI로 담당자·기한이 있는 할 일 표로 만들기”.
- **시청자가 겪는 상황:** 회의 메모는 있지만 누가 무엇을 언제까지 해야 하는지 다시 찾아야 한다.
- **소개할 포인트:** 원본 메모를 미리 다듬지 않고 AI에게 맡겨 핵심 요약·결정된 내용·할 일·확인할 내용으로 정리한다.
- **2026-09-23 수정:** 사용자가 할 일 표보다 정리 안 된 기록 전체를 보기 좋게 정리하는 효과를 요청했다. 같은 원본과 결과를 나란히 보여주며, 할 일 표는 회의록의 일부로 다룬다.
- **상태:** 제작 중 · [140.33초 v12 여성 내레이션 검토본](synkbrief_회의메모_20260921/video-v12/README.md). 이전 v4는 사용자의 “낫베드” 피드백 뒤 반복 사용·범위 구분·효과음 보강으로 발전했다. 외부 발행 전이다.
- **후속 피드백 반영:** 컴퓨터·메모장·녹음 전사 기록부터 → 원본 그대로 입력·직접 지목하는 안내·같은 기록의 정리 전후 비교 → 프로젝트 개념·채팅과 차이 → 반복 사용을 위한 프로젝트 저장 → 계정 전체와 구분 → 다음 회의 재사용. [10쪽 가이드·처음 쓸 요청문·지침·연습 2종·ZIP](synkbrief_회의메모_20260921/follow-along-v11/README.md)과 댓글 synk 엔딩. 기존 Suno BGM·효과음 포함, 차분하고 부드러운 여성 내레이션을 v12에 삽입했으며 음색·최종 검토 전. 공개 댓글 자료 전달은 아직 설정하지 않았다.
- **작업 자료:** [제작 기록·원고·검토 영상](synkbrief_회의메모_20260921/README.md).

## SB-002 FaceSwap

- **등록일:** 2026-09-22.
- **사용자가 알려준 내용:** “아이디어창고에 faceswap 나중에 이거 진행하자 추가해주고”.
- **소개할 포인트:** 얼굴을 바꾸는 기능을 콘텐츠 소재로 보관. 구체적인 재미 포인트와 시연 방식은 나중에 정한다.
- **유형:** 새 기능 소개·활용법 후보.
- **도구·링크:** 미정. 특정 제품명으로 확정하지 않는다.
- **상태:** 저장 · 나중에 진행. 현재 회의 메모 편과 별도 소재이며 아직 조사·제작에 착수하지 않았다.
