# 실제 제품을 든 시안 3장 · 1차 다섯 명 영상 게이트(2026-10-21)

[로드맵 최종안](../모델확장_로드맵_20261019.md) 7절 7단계(영상 게이트)의 「실제 제품 든 시안 3장」을 만드는 도구다. 사람은 모델 LoRA v2로 뽑고, 손에 든 제품은 AI가 그리지 않고 블렌더 렌더를 얹는다([AI 광고영상 제작 규칙](../../제작양식/AI광고영상_제작규칙.md) 「제품·로고·글자는 AI로 그리지 않는다」).

## 제품

- 로드맵 10절 5번(시안에 들 실제 제품)은 유호님 결정 전이라, 사용 권한이 확실한 우리 가칭 브랜드로 만들었다: 하린 아이스커피 광고의 가칭 커피 브랜드 **MORU**의 「콜드브루 블랙 250 ml」 슬림 캔(지름 53 mm · 높이 134 mm). 워드마크는 그 광고 엔드카드 C안(Inter Tight 700 · 얼음 모양 O)과 같다. 로드맵 Fable 검수가 예로 든 「사용 권한이 있는 실제 캔 음료」 자리다.
- 실제 고객 제품이 정해지면 `캔_라벨.py`의 글자만 바꾸거나 고객 제품 렌더로 `--렌더` 폴더를 바꾸면 같은 사람 사진에 그대로 다시 얹힌다(사람 사진은 다시 뽑지 않는다).

## 순서

1. `python -X utf8 캔_라벨.py <라벨.png>` — 펼친 라벨 2400×1620(크롬).
2. `blender -b --python 캔_장면.py -- --label <라벨.png> --out <렌더 폴더> --elev 0,8,16 --yaw 0 --key L,R --size 600x1200 --samples 48` — 투명 바탕 렌더(카메라 높이 · 큰 빛 방향별).
3. `python -X utf8 시안_작업.py <작업.json>` — `시안_장면.json`(모델마다 장면 셋 × 시드 넷, 896×1184, 손에는 같은 모양의 무지 갈색 캔)을 `C:\SYNK-LoRA\tools\comfy_run.py` 작업 목록으로 바꾼다. 모델을 한 번만 싣게 ComfyUI에 한꺼번에 줄 세운다. 지시문은 명세서 LoRA 「주의」의 낱말(나이 낱말 · 준호 clean-shaven · 은정 진주와 옅은 눈썹 · 채원 주근깨 등)을 넣었다.
4. 장면마다 한 장을 고른다(얼굴 · 손 · 캔이 가늘고 앞을 봄 · 배경에 글자·화면 속 사람 없음).
5. `시안_키우기.py <작업.json> <이름…>` — 같은 LoRA로 1.5배(1344×1776, img2img 0.32). 다른 업스케일러는 주근깨·눈매를 지어내 얼굴 게이트를 흐리므로 쓰지 않는다.
6. `시안_합성.py <키운 사진> <출력> --렌더 <렌더 폴더>`(SAM 가상환경) — SAM 3 글 지정으로 캔·손 마스크 → 캔 축·폭에 맞춰 렌더를 놓고 기울기·가로를 훑어 원래 캔과 가장 잘 겹치는 자리를 찾음 → 어두운 잉크만 원래 캔 밝기에 맞추고(은색 테·크림 글자는 무릎 곡선으로 지킴) 원래 캔의 밝은 반사 색으로 빛 색을 입힘 → 손가락 닿은 곳 그늘 · 잔결 → 원래 캔 자리를 바탕으로 메운 깨끗한 판에 얹고 앞에 나온 손가락은 원래 화소.

## 영상 게이트 뒤 고침(10-21)

[Fable 판정](../fable/1차_영상게이트_20261021.md)의 P1 둘과 합성 P2를 고쳤다. 처리 표는 판정문 「처리」에 있다.

- **채원 주근깨 과잉(P1):** 지시문의 주근깨 낱말을 빼거나(「B」) 「코·광대에만, 이마·턱·목은 맑게」(「A」)로 바꿔 장면마다 시드 8~12개를 뽑았다. 그중 얼굴 피부의 주근깨 점 수([`주근깨_세기.py`](주근깨_세기.py))가 대표 사진(51)에 가까운 판을 골랐다: 강변 B s22 48 · 필라테스 B s16 50 · 캠핑 B s20. 옛 판은 172 · 68 · 129였다. 햇빛이 센 캠핑은 1.5배로 키울 때 주근깨가 다시 짙어졌다(90).
- **준호 S1 수염 그림자(P1):** 장면 빛을 「얼굴에 고르게 닿는 밝은 낮빛」으로 바꿔 시드 넷 × 지시문 둘을 뽑았다. 턱을 2배로 견주어 대표처럼 깨끗한 A s18을 골랐다.
- **Fable 재확인 P2 후보정([`점_다듬기.py`](점_다듬기.py)):** 캠핑은 처음에 키우는 LoRA 세기를 0.6으로 낮춰 주근깨를 줄였다(58). 그런데 피부 결 · 눈꺼풀 · 입술이 다른 두 장과 달라져서, LoRA 1.0 판으로 돌아가 얼굴 주근깨만 주변 피부색 쪽으로 25% 옅게 했다(점 수 90 → 36). 강변 · 필라테스는 목 · 윗가슴 주근깨를 절반으로 옅게 하고, 강변 가슴 가운데 점과 왼쪽 쇄골 점을 지웠다. 준호 S1은 얼굴의 진한 점을 큰 셋만 남겼다(대표는 2~3개). 몸 칸은 목에서 이어진 피부색만 잡는다 — 베이지 텐트 · 재킷의 밝은 곳 · 나무 팔걸이도 피부색 범위라 처음에는 500점을 잡았다.
- **합성(P2, 열다섯 장 모두 다시):** 손가락이 가린 쪽이 SAM 마스크에서 빠져 캔 축이 3~6도 기울어 놓였다. 그래서 무게중심을 축으로 기울기·가로를 훑어 원래 캔과 가장 잘 겹치는 자리에 놓고, 원래 캔 자리를 바탕으로 먼저 메운 깨끗한 판 위에 얹도록 바꿨다(`시안_합성.py` 기본값, [현장 노트](../../../현장노트/그림_굽기_오리기.md#렌더-얹기)). 민재 S2 오른쪽 띠는 어긋남 1596 → 184로 사라졌다. 민재 S1 캔 빛 색은 같은 장면의 회색 후드(빨강 1.067)와 렌더 빛(1.066)이 같아 그대로 뒀다.
