# 보드의 움직이는 사진(10-18)

캐스팅북 2판 보드에서 사진에 마우스를 올리면(휴대폰은 화면 가운데 한 명만) 짧게 도는 영상이다. `catalog.json`의 `models.<코드>.loop`가 이 폴더의 `<코드>.mp4`를 가리키고, 빌드가 `site/video/<코드>-loop.mp4`로 복사한다.

- 방법: 만족 사례 장부 S07(확인한 정지컷 → Wan 이미지→영상 짧게)을 따랐다. 반복이 끊기지 않게 시작 그림과 끝 그림을 같은 대표 사진(`site/img/<코드>/hero.webp` → JPEG 93)으로 잠갔다. Wan 3.0, 4초, 720p, 3:4, 소리 없음. 지시문은 「깜빡임 한 번, 작은 숨, 머리카락 조금, 카메라 고정, 마지막 프레임 = 첫 프레임」이고 표정은 모델마다 절제했다(태준·유호는 미소 변화 없음).
- 비용: 7편 × 7크레딧 = 49크레딧(Higgsfield, 10-18 11:49~11:52, 잔액 1,238.34 → 1,189.34).
- 점검(`.tmp/pulse-loops-20261018/check.py`): 처음·끝 프레임 차이 0.21~0.29(이음매 없음), 얼굴은 네 시점 크롭으로 확인. 유나만 고개 움직임이 조금 크다(첫 프레임과의 최대 차 26, 나머지 8~17).
- 웹용: `ffmpeg -an -vf scale=720:960…crop -c:v libx264 -crf 25 -movflags +faststart`, 합계 1.6MB. 받은 원본(832×1108 30fps)은 `_raw/<코드>_v1.mp4`. mp4는 git에 들어가지 않으니 이 폴더 파일이 원본이다.
