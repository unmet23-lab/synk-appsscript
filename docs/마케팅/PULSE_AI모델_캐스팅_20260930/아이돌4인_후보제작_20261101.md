# 아이돌 4인 그룹 · 신규 다섯 멤버 후보 제작

## 범위와 선택 순서

- 여자 팀: 기존 F08·F09·F10을 유지하고 1명을 추가한다. 남자 팀: 신규 4명.
- 각 신규 멤버당 얼굴 해석 4개, 총 20개 후보를 만든다. 기존 멤버를 새 얼굴의 생성 참조로 넣지 않는다.
- Claude Opus가 설계한 초안은 여자 민트 계열, 남자 코발트·오렌지·라벤더·체리 계열이다. 색뿐 아니라 얼굴형·눈매·입매를 달리한다. 이름·정식 모델 코드는 선택 전 확정하지 않는다.
- 제작 원본과 답 원문: 저장소 밖 `C:\SYNK-LoRA\casting\idol_four_20261101\`. 현재 수신 파일·치수·해시는 그 폴더의 `result.json`, 생성 기록은 `ego/_받기기록.jsonl`로 확인한다.

## 검수 상태와 사용자 승인

- 설계 원문 `design-response.json`: Claude Opus 응답 완료(`end_turn`). 이미지 생성 지시문은 20개다.
- 아르곤 생성 전 검수는 여자 4개·남자 16개 두 묶음 모두 실제 답을 받았다. `argon-prompts-gw.md`, `argon-prompts-boys.md`.
- 여자 속쌍꺼풀·포니테일 여백·민트 색 구분, 세일러 칼라 제거, 남자 가르마·이마/눈썹 노출·멤버별 표정·덧니 좌우 등 지적을 생성 지시문에 반영했다. 명세의 성인 범위에 맞춰 남자 리더 초안의 25세는 24세로 맞췄다.
- 기계 점검 20편의 필수 빠짐·길이 초과는 0편. 기존 대표의 점 허용 목록을 요구하는 주의는 참조 없이 신규 얼굴을 만드는 단계이므로 적용하지 않는다. 생성 결과의 점 검수는 별개다.
- Fable은 여자 후보 지적 본문을 일부 받았으나 토큰 상한으로 끝났고, 전체 검수도 정상 완료하지 못했다. 이어받기 요청은 이유 설명 없는 빈 `refusal`이었다. 완료 검수 또는 지적 0건으로 세지 않는다.
- **유호님 명시 승인:** Fable 검수 전인 현재 5명·20개 후보를 먼저 생성해 보여주되 정식 등록·LoRA 학습은 얼굴 선택과 검수 뒤에 한다는 질문에 「후보 시안부터 생성해 줘」(11-01). 이번 후보 시안 생성에만 적용하며 일반 검수 규칙을 바꾸지 않는다.

## 현재와 남은 단계

Gemini Ultra 웹의 4 Argon·사고 수준 높음으로 후보 20개를 생성하고 원본 20장을 모두 받았다(11-01 17:07). 전부 1792×2400이며, 파일 열림·비율·SHA 중복 검사와 실제 이미지 열기를 완료했다. `verify-results.py --require-all` 결과는 수신 20개·누락 0개다. 선택표 `선택.md`에는 기존 여자 세 멤버와 신규 다섯 자리의 후보 네 장씩을 함께 두었다. 이미지와 답 원문은 저장소 밖 로컬에 보관한다.

원본 다운로드 세 장은 `page.goto`의 기본 load 대기 15초 초과와 그림 대기 실패로 지연됐다. 같은 대화를 다시 열어 원본을 받았으며, 이를 새 이미지 생성이나 검수 통과로 세지 않았다. 상세는 [현장 노트의 대화 주소 받기](../../현장노트/gemini_사진.md#대화-주소-받기의-첫-열기가-빈-화면이면-그림-기다림-5분을-다-쓴다--60초에-끊고-세-번까지-다시-연다-2026-10-25-claude).

**현재는 Fable 검수 전 후보 선택 대기다.** 후보 선택, 정식 세트, Fable 최종 검수, LoRA 학습, 각 팀 4인 단체 컷, 캐스팅북·홈페이지 반영은 아직 완료가 아니다. 파일 검사는 인물 일관성·얼굴 구분·완성도 검수를 대신하지 않는다.
