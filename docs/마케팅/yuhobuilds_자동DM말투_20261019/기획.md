## 2. 0초 훅 다섯 안

1. **(고름)** 「괜찮냐고 물으면, 제 자동 DM은 "아니요"부터 답하게 돼 있었어요」 → 되감아 「지금은 이렇게 답해요」. S22와 같은 문제 → 되감기 → 해결 짜임이고, 소리 없이도 말풍선 두 개로 읽힌다.
2. 「댓글 14개에 DM 14통, 평균 18초. 그런데 "너무 기계 같다"」(결과 + 갈등)
3. 「자동 DM에서 'AI 티' 지운 일곱 군데」(목록)
4. 「"에러 떠요 ㅠㅠ"에 아무 답도 안 하던 자동 DM」(틀린 것)
5. 「제 자동 DM, 이제 제가 답하면 하루 쉬어요」(반전)

- 인스타·유튜브는 같은 판 하나로 간다(세션 공유 편 확정 판처럼). 훅을 나눠 시험할 B판은 이번에는 만들지 않는다. 오늘 게시가 먼저다.

## 5. 끝 행동과 맞춤 프로그램

- 끝 문장은 댓글로 이어지는 질문(「제일 기계 같았던 자동 DM」)이다. 이 편에 붙일 새 맞춤 프로그램은 없다. 트렌드 스캔대로 허브 첫 화면(synk.im/builds/ — 「yuhobuilds 맞춤 프로그램」, 노트북 이사·AI 직원 매뉴얼)을 설명란·고정 댓글에 둔다. 반응이 상위면 48시간 안에 「자동 답장 말투 점검」 편 설정(일곱 갈래를 규칙으로, AI 호출 없이)을 붙인다.
- 이 게시물에는 댓글 DM 자료를 연결하지 않는다. 그래서 영상·글 어디에도 「댓글 달면 보내 드려요」를 쓰지 않는다.

**인스타 캡션**

```
"대화 기록은 괜찮나요?"에 "아니요"부터 답하게 돼 있던 제 자동 DM 😅

지난 영상 첫날 '세션' 댓글 14개에 DM 14통. 댓글에서 답글까지 평균 18초였어요. 빠르긴 했는데, 받는 쪽에서 읽어 보니 너무 기계 같았어요.

· 뜻이 뒤집히는 첫마디("아니요, … 건드리지 않아요" → "걱정하지 않으셔도 돼요")
· 고맙다는 말에 붙던 '그만 받으려면' 꼬리

· "에러 떠요"에 아무 답도 안 하던 것
· 정해진 답에 없는 질문은 이제 Claude가 앞 대화를 읽고 이어서 답하고, 모르는 건 "직접 확인해서 답드릴게요" 하고 저한테 알림이 오게 했어요
· 제가 직접 답한 대화에서는 자동 답이 하루 쉬어요

AI 티는 기능보다, 받는 사람이 읽는 한 줄에서 나더라고요.

여러분이 받아 본 자동 DM 중 제일 기계 같았던 말은 뭐였어요? 댓글로 알려 주세요.

제가 만든 도구들 · synk.im/builds

#자동DM #AI활용 #클로드
```
