## 인물 · 감정 설계 — 진행자 없음

- 장부 기본 꼴은 유호 진행자 + 실제 화면(S42)인데 이 편도 Y37 · Y39 · Y44처럼 진행자 컷 없이 보이스오버(범수) + 실제 앱 화면 캡처 + 움직이는 글로 만들었다. 까닭은 같다 — Flow가 자동 접수를 막아 새 진행컷을 못 뽑고, 새 방향 편의 진행자 정면 컷이 맹검 기각의 뿌리였으며, 화면 결이 트랙 §1에 유호님 차례로 걸려 있다. Flow 0크레딧.
- 무대: 크림 바탕(#F3F0EA) 위 검은 실제 화면 조각 — 지난 편 Y44(어두운 판 · 유리 상자) · Y41(영상 가득)과 다르게(이해 시험 r4에서 셋이 「어두운 바탕 · 가운데 화면 카드」가 Y44와 같다고 짚어 바꿈). 실제 앱 화면 전체가 나오는 승 한 컷만 검은 바탕. 먹색 SUIT, 버터색은 「40만원 · 전부 통과 · 끝자리 있는 값 · 395,000원」 밑줄과 「+5,000원」.
- 감정 장치: 틱틱 쌓이는 통과 체크 → 쳐지는 넣은 값 → 쿵(흔들림 · 번쩍) 「40만원」 + 「+5,000원」 → 어두운 실제 화면에서 값 칸만 밝아짐 → 시험 표의 빈 점선 칸에 값이 쳐지고 ✕ 쿵 → 하얀 글 칸에 한 줄이 쳐짐 → 같은 화면이 395,000원으로 「톡」, 밑줄이 빛남.
