# 녹음을 글로 — 받아쓰기 앱 구독 없이, 클로드에게 내 컴퓨터에서 돌려 달라고 하기

회의나 강의를 녹음한 파일을 글로 바꾸고 싶은데 받아쓰기 앱을 따로 구독하기 싫은 분을 위한 자료예요. 컴퓨터에서 클로드 코드를 쓰고 있다면, 말 한마디로 클로드가 내 컴퓨터의 무료 받아쓰기 프로그램을 돌려 글 파일을 만들어 줘요.

- 저희는 44분 43초짜리 녹음을 이렇게 글로 바꿨어요. 말한 시각이 줄마다 붙은 글 파일이 나왔어요.
- 받아쓰기에는 돈이 들지 않았어요. 녹음 파일은 인터넷 어디에도 올리지 않았어요.
- 원래 대본과 견주니 글자 92.3%가 같았어요. 숫자와 영어 낱말을 쓰는 방식만 다른 자리를 빼면 96.6%였어요.
- 그래픽카드를 쓰지 않고 노트북 CPU로 돌려서 받아쓰기에 51분이 걸렸어요.

아래 숫자와 결과는 모두 저희가 직접 돌려 본 것만 적었어요.

---

## 이런 분께 맞아요

- 컴퓨터(윈도우나 맥)에서 클로드 코드를 쓰는 분
- 회의, 강의, 인터뷰 녹음을 글로 남기고 싶은 분
- 녹음 파일을 받아쓰기 서비스에 올리기 꺼려지는 분

**안 맞는 경우**
- 휴대폰이나 웹(claude.ai)에서만 클로드를 쓰는 분. 클로드가 내 컴퓨터의 프로그램을 돌릴 수 없어서 이 방법이 안 돼요.
- 무료 요금제만 쓰는 분. 클로드 요금 안내에서 무료 요금제의 클로드 코드는 「No」로 나와 있어요(2026-11-23 읽음).

---

## 준비물

**컴퓨터**
- 저희는 윈도우 11 노트북(인텔 코어 울트라 9 275HX · 메모리 64GB)에서 했어요. 맥에서는 해 보지 않았어요.
- 이 노트북에는 엔비디아 그래픽카드가 있지만 쓰지 않았어요. 그래픽카드로 돌리는 데 필요한 프로그램(CUDA 12용 cuBLAS)이 깔려 있지 않았기 때문이에요. 그래서 그래픽카드가 없는 컴퓨터와 같은 길로 돌았어요.

**클로드 코드가 되는 요금제**
- 프로 요금제부터 클로드 코드를 쓸 수 있어요. 프로는 월 결제면 한 달 20달러, 1년 결제면 한 달 17달러(한 번에 200달러)로 나와 있어요(claude.com/pricing, 2026-11-23 읽음).
- 받아쓰기 자체에는 돈이 들지 않지만, 클로드 요금은 따로예요.

**녹음 파일 한 개**
- 저희는 mp3 파일(128kbps, 43MB)로 했어요. 휴대폰 녹음 앱의 m4a 파일로는 해 보지 않았어요.

**저장 공간과 인터넷(처음 한 번)**
- 받아쓰기 모델 파일이 1.62GB예요. 처음 한 번 인터넷으로 받아요.
- 저희 컴퓨터에는 프로그램과 모델이 이미 받아져 있어서, 처음 받는 시간은 재지 못했어요.

---

## 무료로 되는 것과 아닌 것

- 받아쓰기 프로그램 faster-whisper는 MIT 라이선스로 공개된 무료 프로그램이에요. 파이썬 3.9 이상에서 돌고, 그래픽카드 없이 CPU로도 돈다고 적혀 있어요(공식 저장소, 2026-11-23 읽음).
- 그 안에서 쓰는 받아쓰기 모델 Whisper는 오픈AI가 공개했고, 코드와 모델 모두 MIT 라이선스예요(공식 저장소, 2026-11-23 읽음).
- 저희가 쓴 모델은 large-v3-turbo예요. 모델 카드에 MIT 라이선스로 나와 있어요(2026-11-23 읽음).
- 받아쓰기는 내 컴퓨터에서 돌아서 쓴 시간만큼 붙는 요금이 없어요. 클로드 요금(구독)은 따로 들어요.

---

## 1단계 · 클로드에게 이렇게 말하기

클로드 데스크톱 앱의 「코드」 탭(또는 터미널의 클로드 코드)에서 녹음 파일이 든 폴더를 열고, 아래 말을 붙여 넣어요. 【 】 안만 내 파일 이름으로 바꿔요. 저희도 데스크톱 앱의 「코드」 탭에서 했어요.

```
이 폴더에 있는 【녹음 파일 이름】을 내 컴퓨터에서 무료로 글로 바꿔 줘.
인터넷 받아쓰기 서비스나 유료 도구는 쓰지 말고, 말한 시각을 줄마다 앞에 붙여서 같은 폴더에 글 파일로 저장해 줘.
설치할 게 있으면 무엇을 왜 설치하는지 먼저 말하고 진행해 줘.
```

마지막 줄은 꼭 넣어요. 클로드가 내 컴퓨터에 무엇을 까는지 먼저 알 수 있어요.

---

## 2단계 · 클로드가 하는 일

저희가 위 말을 그대로 붙였을 때 클로드가 한 일이에요(2026-11-23, 클로드 코드 · Opus 5.5).

1. 컴퓨터에 이미 깔린 받아쓰기 프로그램(faster-whisper)과 받아 둔 모델(large-v3-turbo)이 있는지 먼저 찾았어요.
2. 이 컴퓨터는 그래픽카드용 프로그램이 없다는 저희 기록을 읽고 CPU로 돌리기로 했어요.
3. 받아쓰는 짧은 파이썬 파일을 녹음 옆에 만들어 돌렸어요. 모델은 인터넷에 닿지 않게 읽었어요.
4. 녹음 옆에 「녹음_받아쓰기.txt」가 생겼어요. 줄마다 `[00:13:59] 이것도요` 꼴이에요.

**설치되는 것과 건드리는 것**
- 프로그램이 없는 컴퓨터라면 클로드가 파이썬 꾸러미 faster-whisper를 깔고, 처음 돌릴 때 모델 파일(1.62GB)을 사용자 폴더의 캐시에 받아요.
- 녹음 파일은 고치지 않아요. 글 파일과 받아쓰는 파이썬 파일이 새로 생겨요.

**중간에 멈춘 것처럼 보이면**
저희 첫 시도는 다른 작업이 컴퓨터를 많이 쓰고 있어서 모델을 읽는 데만 14분쯤 걸렸어요. 그때 이렇게 말했어요.

```
돌려 둔 받아쓰기가 【15】분째 그대로야. 멈춘 것 같으니 끄고, 왜 멈췄는지 찾아서 다시 돌려 줘.
```

클로드는 이 말을 듣고서야 원인을 찾았어요. 뒤에서 돌린 프로그램의 우선순위가 「보통 이하」라서 다른 작업에 밀렸던 거예요. 우선순위를 「보통」으로 올려 다시 돌리자 준비가 14분쯤에서 20초로 줄었고, 그 판으로 끝까지 받아썼어요. 클로드가 스스로 알아채지는 못했으니, 몇 분째 글 파일이 비어 있으면 먼저 말해 주세요.

---

## 3단계 · 결과 확인하기

1. 글 파일을 열어 처음 몇 줄이 녹음과 맞는지 봐요.
2. 이름, 숫자, 금액처럼 틀리면 곤란한 줄은 앞의 시각으로 녹음을 찾아 직접 들어 봐요.
3. 짧은 감탄이나 웃음은 빠질 수 있어요. 저희 녹음에서도 「붙었다…!」 같은 짧은 말 몇 개가 빠졌어요.
4. 누가 말했는지는 나뉘지 않아요. 저희 녹음에는 목소리가 다섯 개 있었지만 글에는 말한 사람이 적히지 않았어요.

---

## 저희가 잰 결과

**녹음**
- 저희가 만든 영상들의 한국어 목소리 줄 821개(AI 목소리 다섯 가지)를 섞어 이은 44분 43초 녹음이에요. 줄 사이에 0.6~1.6초 쉼을 두고 방 소음과 울림을 조금 섞었어요.
- 대본이 있는 녹음이라 받아쓴 글을 정답과 글자 단위로 견줄 수 있었어요.
- 실제 회의처럼 여럿이 겹쳐 말하는 녹음은 아니에요. 사람 목소리 녹음에서는 결과가 더 나쁠 수 있어요.

| 잰 것 | 결과 |
|---|---|
| 받아쓴 줄 | 910줄, 줄마다 말한 시각 |
| 받아쓰기에 걸린 시간 | 51분(노트북 CPU · 8스레드 · int8) |
| 글자 일치(띄어쓰기 · 문장부호 뺌) | 92.3% |
| 숫자 · 영어 표기 차이를 뺀 일치 | 96.6% |

- **표기 차이란:** 대본에는 「에이아이」, 「오십」처럼 한글로 적었는데 받아쓰기는 「AI」, 「50」으로 쓴 자리예요. 뜻은 같아서 따로 셌어요.
- **걸린 시간에 대해:** 재는 동안 같은 컴퓨터에서 다른 작업들이 CPU를 거의 다 쓰고 있었어요. 그래서 이 시간은 한가한 컴퓨터보다 느리게 나왔을 수 있어요. 얼마나 빨라지는지는 재지 못했어요.

**틀린 예**
- 「이 표」를 「2표」로, 「부딪쳤잖아」를 「부딪혔잖아」로 적었어요.
- 「홑꺼풀」을 「홈꺼풀」로, 「제미나이」를 「재미나이」로 적었어요.

## 안 될 때

| 이럴 때 | 해 볼 것 |
|---|---|
| 몇 분째 글 파일이 비어 있다 | 위 「중간에 멈춘 것처럼 보이면」의 말을 붙여요 |
| 그래픽카드로 돌리다 「cublas64_12.dll」 같은 오류가 난다 | 그래픽카드용 프로그램이 없는 거예요. CPU로 돌려 달라고 하면 돼요 |
| 말한 사람을 나누고 싶다 | 이 방법으로는 안 나뉘어요. 저희는 해 보지 않았어요 |

## 확인하지 못한 것

- 여럿이 겹쳐 말하는 실제 회의 녹음, 휴대폰으로 녹음한 m4a 파일
- 맥, 그래픽카드로 돌렸을 때의 시간
- 처음 프로그램과 모델을 받는 데 걸리는 시간
- 받아쓴 글로 회의록을 만드는 요청
