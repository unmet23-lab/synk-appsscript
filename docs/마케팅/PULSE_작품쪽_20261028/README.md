## 왜 따로 플랫폼이 아니라 synk.im/pulse 안의 쪽인가

- 처음 보는 광고주는 회사 사이트에서 작품 → 문의로 넘어간다. 따로 세우면 캐스팅북(/pulse/casting/) · 문의 길(결정 10-26)과 끊긴다.
- 고객 앱의 「완성 광고」(결정 10-22)는 초대받은 손님만 본다. 같은 작품 목록 하나를 공개 쪽과 앱이 같이 읽게 하면 작품 하나 더하기 = 한 곳.

## 시안의 겹

- **작품 목록:** 떠 있는 막대(「제작 문의」 고정) → 머리(제목 · 문단 · 「문의 받는 중」 · 쇼릴/문의 단추) → 쇼릴(눌러야 소리와 함께 재생) → 업종 고르기(개수) → 결과 수 · 화면 비율(세로 9:16 · 가로 16:9) → 고른 띠 격자(가로 · 세로를 자르지 않고 줄 높이만 맞춤, 카드 글 「업종 · 형식 / 제목 / 길이 · 비율 · 모델」, 완성작만 마우스를 올리면 5초 소리 없는 미리보기) → 문의 판(의뢰 양식 여섯 칸) → 바닥. 휴대폰은 아래 고정 「제작 문의」.
- **작품 하나:** 뒤로 → 업종 · 형식 · 제목 · 「과제」 한 문장 · 광고 한 문장 → 플레이어 + 정보 칸(브랜드 · 형식 · 길이 · 화면 · 출연 · 컷 · 만든 곳) → 만든 순서 네 단계(한 문장과 글 콘티 · 배역과 제품 기준 그림 · 이미지 콘티 열 컷 · 영상과 소리) → 비슷한 작품(같은 업종 먼저).
- 디자인 값은 공개 중인 synk.im v10 `site.css` 그대로(흰 판 · 잉크 · SUIT/Inter Tight/DM Mono · 알약 막대 · 제목 굵기 580 · 52px 알약 단추). PULSE 색은 점 하나.

## 벤치마킹에서 가져온 것 · 일부러 안 한 것

- 가져옴: 카드 글 한 줄(MONF · 크몽 · U3), 업종 칩 + 개수(U3 · OURA), 9:16을 자르지 않음(U3), 작품 쪽 「과제」 한 문장 + 메타표 + 만든 순서(U3 · MONF 「THE IDEA & HOW」 · 486), 문의 고정 단추(메타라이브 · U3 · 크몽), AI 고지 한 줄 「작품 속 사람은 모두 AI로 만든 모델입니다」(AI를 숨기면 후보에서 빠진다는 광고주 글 — 캐스팅북 고지와 같은 예외, 도구 이름은 쓰지 않음).
