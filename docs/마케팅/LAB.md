## 3. LAB — 한국에서 하고 싶은 일을 내 말로

회사 소개의 대표 비전은 [SYNK LAB의 전면 문장과 서브텍스트](../비전_정본.md#synk-lab)를 함께 사용한다. 학생을 이해한 결과가 다음 배움에 돌아가는 방향을 아래의 한국어 경험으로 구체화하며, 현재 과정·개인화 제공 범위는 실제 계약과 구현을 따른다.

### 3-1. 누구를 위한 브랜드인가

주 대상은 몽골 10대 후반이다. 핵심 교육 경로는 한국 유학을 준비하고 학업·졸업·이후 진로에서 한국어를 쓰는 삶이다. K-컬처는 관심을 여는 매개이며 **취미 한국어반·EPS로 핵심 상품을 바꾸는 전략은 아니다.** 그러나 모든 게시물이 입시 이야기일 필요도 없다. 오늘 재미있게 써본 한 문장이 먼저 충분한 가치여야 한다.

학생은 한국어 초급일 수 있어도 생각은 고등학생 수준이다. 어린아이 말투·과한 칭찬·발음 실수 조롱·‘한국을 좋아하니 당연히 아이돌 팬’이라는 전제를 쓰지 않는다. 보호자는 구매자이자 결정 참여자지만 학생의 꿈을 대신 정하는 주인공은 아니다. 이미 한국에 있는 몽골 **성인 온라인 과정은 별도 대상과 도착 페이지**로 유지한다.

### 3-2. 학생의 마음을 생활 단위로 세분화한다

각 줄은 고정 성격 유형이 아니라 **지금 필요한 도움에 대한 가설**이다. 한 사람이 여러 줄에 걸치거나 다음 달 바뀔 수 있다.

| 상황 | 원하는 것 / 숨어 있을 수 있는 긴장 | 먼저 제공할 것 | 신선한 표현 방식 | 확인할 질문 |
|---|---|---|---|---|
| 한국 콘텐츠를 보는 사람에서 대화하는 사람으로 | 취향을 나누고 싶다 / 말투가 어색해 내 이미지가 달라질까 | 좋아하는 것과 이유를 말하는 두 표현, 자기 취향으로 바꾸는 빈자리 | 장면을 멈추고 말 하나를 고르면 상대 반응이 달라지는 짧은 이야기 | 최근 끼어들고 싶었던 대화는? |
| 대학 동아리·팀 과제의 일원이 되고 싶음 | 구경꾼이 아니라 기여하고 싶다 / 말 잘하는 사람만 역할을 가질까 | 역할 요청·의견 보태기·다시 확인하기 | 화면 앞 발표와 뒤의 편집·기획 역할을 대등하게 고르는 장면 | 맡아보고 싶은 역할과 싫은 역할은? |
| 창작·전공·일의 가능성을 탐색 | 내가 만든 것을 보여주고 싶다 / 한국어와 내 관심사가 따로 논다 | 그림·게임·음악·과학 등 본인이 고른 결과물 설명 틀 | ‘한국 소개’ 대신 ‘내가 만든 것을 한국어로 소개’하는 작은 전시 | 그 분야 사람의 평일에는 어떤 대화가 있나? |
| 한국 생활을 스스로 해보고 싶음 | 취향과 일정을 직접 선택 / 못 알아듣고 그냥 넘어갈까 | 주문 변경·길 확인·약속 조정·도움 요청 | 잘못된 사람을 웃기는 대신 선택에 따라 달라지는 상황극 | 혼자 해보고 싶은 가장 평범한 일은? |
| 유학할지 아직 결정하지 않음 | 직접 알아보고 내 결정을 하고 싶다 / 나라를 좋아하는 것과 사는 것은 다를까 | 전공·도시·생활·준비의 질문 카드 | 한국의 하루를 여러 버전으로 골라보고 ‘더 알아볼 것’을 남김 | 가고 싶은 이유와 망설이는 이유는? |
| 유학 목표를 가족에게 설명하려 함 | 내 선택을 진지하게 들어주면 좋겠다 / 꿈만 말하는 사람처럼 보일까 | 학생의 이유 한 면 + 보호자의 확인 질문 한 면 | 학생이 채우는 작은 진로 편지와 사실 확인표를 한 세트로 | 부모와 어떤 질문부터 같이 답하고 싶은가? |
| 촬영·공연 없이 조용히 참여하고 싶음 | 내 방식으로 함께하고 싶다 / K컬처라면 꼭 춤춰야 할까 | 대본·편집·의미 비교·구성 역할 선택 | 말하기·쓰기·뒤의 제작을 동등한 입구로 제시 | 공개하지 않아도 해보고 싶은 일은? |
| 바쁘거나 쉬었다가 돌아옴 | 설명·사과 없이 오늘 한 가지 / 밀린 숙제가 취향까지 빼앗을까 | 준비물 없는 한 장면, 이전 선택을 바꿀 권리 | 연속 기록 대신 이번 편만으로 끝나는 짧은 경험 | 빼고 싶지 않은 시간은? 지금도 같은 이유로 배우나? |
| 몽골의 나와 한국의 나를 함께 갖고 싶음 | 내 도시·친구·문화를 설명 / 한국 관심 때문에 내 세계를 지워야 할까 | 몽골의 음식·장소·습관을 한국어로 설명 | 한국을 알려주기만 하던 관계를 뒤집는 ‘우리 동네를 한국어로’ | 한국 친구에게 몽골에서 무엇을 보여주고 싶은가? |

실제 거주 위치·학교·친구 이름은 필요 없다. 빈 카드나 허구 상황으로도 참여할 수 있어야 한다. 부모의 걱정과 학생의 흥미를 같은 광고 한 장에 모두 넣지 않는다.

### 3-3. 무엇을 주고, 무엇으로 이어지는가

### 3-4. LAB의 시그니처 — 매번 새 유행이 아니라, 돌아올 이유가 있는 형식

시그니처는 반복해서 우리 것임을 알아보는 고유 형식이다. 아래 이름은 **내부 가칭**이며 상표·공식 슬로건 신설이 아니다. 모두 동시에 연재하지 않는다. 핵심 하나를 먼저 만들고 보조 형식은 같은 회차 안에서 시험한다.

| 형식 | 한 편의 구성 | 학생이 가져갈 것 | 적합한 자리 |
|---|---|---|---|
| **한국의 하루, 내 대사** — 핵심 | 하고 싶은 장면 → 두 선택 → 반응 차이 → 내 말로 바꾸기 | 바로 쓸 문장과 바꿀 수 있는 한 부분 | TikTok·Reels·Shorts. 캐러셀은 선택지와 변형을 보관하는 별도 편집 |
| **같은 말, 다른 마음** | 같은 표현 → 서로 다른 상황 → 의도 차이 → 다시 선택 | 뜻만 외우지 않고 상황에 맞게 말할 단서 | IG 캐러셀·짧은 연기. 국적 전체의 말투로 단정하지 않음 |
| **우리 동네를 한국어로** | 몽골의 내 취향 → 한국어 설명 → 상대에게 물을 한마디 | 자기 세계를 소개하는 말 | 핵심 연재의 한 회차. 촬영 없는 그림·소품 대안 |
| **집에 가져가는 수업** | 수업에서 한 선택 → 직접 만든 것 → 다음에 쓸 자리 | 학생용 기록 한 장, 보호자용 별도 설명 | 체험·상담·수강 후. 실학생 전에는 합성 예시 표시 |
| **이번에 알게 된 한 가지** | 처음의 생각 → 실제 관찰 → 달라진 과제 → 더 볼 것 | ‘왜 다음 학습이 달라졌는지’ 이해 | 실제 학생·교사 확인 및 [학생 실물 3게이트](제작_인수기준.md)를 통과한 뒤. 후기를 미리 만들지 않음 |

**첫 소재 후보 8개:** 동아리에서 내가 할 일 고르기 / 덜 달게 주문하기 / 못 알아들은 말을 다시 묻기 / 친구 초대에 내 일정 말하기 / 만든 그림·게임 소개하기 / 몽골의 좋아하는 음식을 설명하기 / 전공을 아직 못 정했다고 말하기 / 부모와 한국 생활의 질문 세 개 고르기. 생계·비자·취업 수익을 청소년의 흥미 장치로 쓰지 않는다.

**1회 제작 레시피 — 동아리 첫날의 내 역할.** 허구의 팀 활동에서 시작한다. 앞에 서는 역할과 만드는 역할 중 관객이 고른다. 선택을 짧은 한국어 요청으로 바꾸고 상대가 알아듣는 장면을 보여준다. 끝에는 자기 관심사로 바꿀 빈자리를 남긴다. 승인 교실·공책·몽글 자산을 쓰되 인물이 학생 대신 답하지 않는다. 숏폼은 선택 순간, 캐러셀은 변형해 가져가는 카드, 캡션은 필요한 전체 문장과 설명을 맡는다. 음소거 상태에서도 선택이 읽히고, 소리를 켜면 발음이 정확히 들려야 한다. 게시용 몽골어·한국어는 `synk-brand → synk-content`와 현행 언어 검토를 거친다.

### 3-5. 보호자와 성인에게는 다른 증거를 준다

**보호자용:** 실제 수업이 어떻게 진행되는지 → 무엇을 관찰하고 다음 과제를 어떻게 바꾸는지 → 교사가 책임지는 범위 → 비용·시간·지원·문의 후 절차의 순서다. 학생의 선택도 함께 보여준다. ‘AI 7개라서 뛰어나다’거나 귀여운 캐릭터만으로 교육 신뢰를 대신하지 않는다. 자녀의 사적 상담·타 학생 비교·원본 발화를 기본 첨부하지 않는다.

**한국 거주 성인용:** 대학 수업의 질문, 교수 면담, 과제 설명, 생활 문자, 다시 말해달라는 요청 등 이미 겪는 장면을 출발점으로 한다. 청소년의 한국 방문 희망을 현재 성인의 문제에 덮지 않는다. 개인의 학업·체류 상황을 광고 타겟 분류나 공개 사례로 캐내지 않고, 해당 과정의 현재 계약만 설명한다. 성인의 학습 기록을 부모에게 자동 보내지 않는다.

### 3-6. LAB의 표현 감각

밝은 Paper 위에서 한 장면·한 선택이 먼저 보인다. 펠트 소품은 상황을 이해시키는 물건이며 글자 뒤의 장식이 아니다. 몽글은 함께 보고 반응하는 존재이지 어린아이 교사나 감정 진단사가 아니다. 한국어는 또렷하게, 몽골어는 의미를 돕는 계층으로 배치한다. 쉬운 한국어와 높은 사고 수준을 함께 지킨다. 두 언어가 필요하면 장면·자막·캡션으로 역할을 나누되 안전·조건·핵심 뜻을 생략하지 않는다.

행사와 체험의 선택·참가·권리 기준은 [LAB 행사](LAB_행사.md), 진단·판매 약속은 [약속과 실행](약속과_실행.md)을 이어 읽는다.
