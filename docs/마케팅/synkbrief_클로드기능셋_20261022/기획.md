# synkbrief 기초 · Claude한테 같은 설명, 아직도 매번 하세요? — 반복하는 말로 고르는 기능 셋

> 2026-10-22 07:00 예약 작업 「synkbrief 오늘 편」의 첫 편(상시). 큐에 synkbrief 비축이 0일(10-22·23 승인 대기)이라 첫 빈 날 10-24(토)를 채운다. 기능 고르는 기준은 2주 뒤에도 같아 상시 편이다(요금제별 조건은 게시 전날 다시 확인 — 준비.json `남은위험`).
> 채널은 SHIFT 정보 `@synkbrief`(인스타 릴스 · 유튜브 쇼츠 「SYNK 브리핑」) + SYNK SHIFT 네이버 블로그·티스토리 상세 글. 화면 틀은 앞 편([ChatGPT 대화 잠그기](../synkbrief_ChatGPT대화잠그기_20261021/기획.md))과 같은 Remotion 부품(청금석 무대·위로 밀기·크레용 밑줄·박 착지). 콘티는 Fable 검수를 거쳐 바로 진행하고, 유호님이 고르는 자리는 최종본 확인 하나다.
> 역할: 이번 주(10-19~25)는 남은 빈 날 둘에 빈 역할이 더 많지만, 오늘 찾은 트리거 후보 가운데 시청자 가치가 분명한 것은 이 하나다(Claude Duet 10-21 발표는 미국 대기 명단뿐이라 한국 시청자가 쓸 수 없어 뺐다). 끝에서 바라는 행동이 **저장**(한 장 정리)이라 역할은 권위다.

## 볼 이유

Claude를 쓰는 사람은 대화마다 회사 소개·자료를 다시 붙여 넣고, 보고서 양식을 다시 설명하고, 메일 내용을 복사해 온다. 기능 이름(프로젝트·스킬·커넥터·아티팩트…)은 들어 봤지만 **어느 걸 언제 쓰는지** 몰라 3시간짜리 강의를 찾아본다(위 트리거). 이 편은 기준을 하나로 준다 — **「내가 반복하는 말이 뭐냐」**. 자료를 반복하면 프로젝트, 방식을 반복하면 스킬, 메일·일정을 옮겨 오면 커넥터. 끝에 그 표를 한 장으로 준다.

- 깨달음 하나: 기능을 다 배울 필요 없이, 내가 반복하는 말 하나가 쓸 기능을 정한다.
- 흔한 오해 하나: 「스킬은 코딩할 줄 알아야 만든다?」 ✕ — 「이런 스킬 만들고 싶어」라고 말하면 Claude가 물어 가며 만든다(Anthropic 튜토리얼).
- 바로 해 볼 한 단계: 오늘 Claude한테 두 번 이상 한 말을 하나 골라 표에서 기능을 찾는다.

## 형식과 길이

- 시리즈 `synkbrief 기초`(개념·설정·첫 사용). 형식: N가지 기능(셋) + 기준 한 장 + 흔한 오해 깨기. 세로 1080×1920, 54.6초.
- 훅 시험: 인스타 **A(손해 피하기)**, 유튜브 쇼츠 **B(질문)**. B는 검색어(「프로젝트 스킬 커넥터 차이」)를 그대로 제목·첫 줄에 둔다.
- 화면: Claude 앱 화면 녹화는 하지 않는다(로그인 계정 화면). **SYNK 키트로 그린 예시 그림**(말풍선·폴더·카드)에 「예시 그림 · 실제 앱 화면 아님」을 붙이고, 기능·조건 문구는 Anthropic 공식 도움말 원문(아래 「정보 품질」)만 옮긴다.
- 메뉴 이름은 도움말 영문 표기(Projects · Customize › Skills · Customize › Connectors · Settings › Capabilities)에 뜻을 붙이고 「메뉴 이름은 Claude 도움말 영문 표기 · 한국어 화면은 조금 다를 수 있어요」를 둔다.
- 앱 로고는 쓰지 않는다(Gmail·캘린더·드라이브도 글자 칩). 배경음은 앞 편과 같은 「Building Momentum」, 새 AI 그림 없음.
