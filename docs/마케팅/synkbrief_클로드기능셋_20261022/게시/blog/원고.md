**본문**

Claude를 쓰다 보면 같은 말을 자꾸 하게 돼요. 새 대화를 열 때마다 회사 소개 자료를 다시 붙여 넣고, 주간 보고를 부탁할 때마다 양식과 순서를 다시 설명하고, 메일 내용을 복사해서 가져오죠. 프로젝트, 스킬, 커넥터 같은 기능 이름은 들어 봤는데 언제 뭘 써야 하는지 몰라서, 몇 시간짜리 강의를 찾아보는 분도 많아요.

기능을 다 배울 필요는 없어요. 기준은 하나예요. **내가 Claude한테 뭘 반복하고 있나.** 이 글에서는 그 기준으로 프로젝트·스킬·커넥터를 하나씩 고르는 법과, 무료 계정에서도 되는지, 처음 켤 때 무엇을 먼저 해야 하는지까지 정리했어요. 맨 끝에 한 장 정리가 있어요.

※ 메뉴 이름은 Anthropic의 Claude 도움말(영문) 표기 그대로 적었어요. 요금제나 언어에 따라 화면이 조금 다를 수 있어요.

〔그림 1〕 *내가 Claude한테 뭘 반복하나 — 기준 세 줄*

## 1. 같은 자료를 붙여 넣는다면 → 프로젝트(Projects)

프로젝트는 자료와 지침을 한곳에 넣어 두는 방이에요. 한 번 넣어 두면 **그 프로젝트 안에서 여는 대화는 모두 같은 자료와 지침을 써요.**

- **자료(프로젝트 지식):** 프로젝트 첫 화면 오른쪽의 지식 칸에 문서·텍스트 파일·코드 조각을 올려요. 도움말은 "여기에 올린 것은 그 프로젝트의 모든 대화에서 쓰인다"고 적고 있어요.
- **지침:** 「Set project instructions」로 답하는 방식을 정해요. 예를 들어 "답은 존댓말로, 가격은 표로". 이 지침도 프로젝트 안의 모든 대화에 적용돼요.
- **무료 계정도 돼요.** 프로젝트는 무료 계정을 포함해 모든 사용자가 쓸 수 있고, **무료 계정은 프로젝트를 5개까지** 만들 수 있어요.
- 유료 요금제에서는 자료가 많아 대화 한도에 가까워지면 Claude가 자동으로 RAG 방식으로 바꿔 더 많은 자료를 다뤄요.

만드는 법은 간단해요.

1. 왼쪽 메뉴에서 **Projects**를 열거나 claude.ai/projects로 가요.
2. 오른쪽 위 **+ New Project**를 누르고 이름을 붙여요(이름과 설명은 Claude가 읽지 않아요).
3. 오른쪽 지식 칸의 **+**로 자료를 올리고, **Set project instructions**로 지침을 적어요.

알아 둘 점도 있어요. 도움말은 "프로젝트 안의 대화끼리는 맥락이 이어지지 않는다, 프로젝트 지식에 넣은 정보만 함께 쓴다"고 적고 있어요. 같은 글에 "프로젝트마다 따로 메모리가 있다"는 설명도 있지만, 다음 대화에도 꼭 필요한 내용이라면 대화에 두지 말고 **지식 칸에 넣어 두는 게** 확실해요.

## 2. 같은 방식을 설명한다면 → 스킬(Skills)

스킬은 **일하는 방법**을 가르쳐 두는 기능이에요. 보고서 양식, 정리 순서, 우리 회사 문서 규칙처럼 "이 일은 이렇게 해"를 한 번 담아 두면, Claude가 요청을 보고 필요할 때 그 스킬을 알아서 꺼내 써요.

- **무료 계정도 돼요.** 스킬은 Free·Pro·Max·Team·Enterprise 모든 요금제에서 쓸 수 있어요.
- **먼저 켜 둘 것:** 스킬은 코드 실행이 켜져 있어야 돌아가요. 무료·Pro·Max는 **Settings › Capabilities**에서 **Code execution and file creation(코드 실행·파일 만들기)**를 켜요. Team·Enterprise는 조직 설정(Organization settings › Plugins & skills)에서 관리자가 켜져 있는지 확인해요(Team은 조직에서 기본으로 켜져 있어요).
- **보고 켜고 끄는 곳:** **Customize › Skills**. Anthropic이 만든 예시 스킬(엑셀 표 만들기·워드 문서·파워포인트·PDF)도 여기서 켤 수 있어요. 꺼 둔 스킬은 쓰지 않아요.
- Claude가 스킬을 안 꺼내 쓰면 요청할 때 이름을 불러 주면 돼요. 예: "주간 보고 스킬로 이번 주 보고 써 줘".

### 스킬은 코딩해야 만든다? 아니에요

〔그림 2〕 *스킬은 말로 시켜서 만들 수 있어요(예시 그림)*

Anthropic 튜토리얼 「How to create a skill with Claude through conversation」은 대화로 스킬을 만드는 순서를 이렇게 안내해요.

1. 새 대화에서 만들고 싶은 스킬을 말해요. 예: "주간 보고 스킬 만들고 싶어". 쓰던 양식이나 잘 쓴 예시가 있으면 같이 올려요.
2. Claude가 되물어요. "언제 이 스킬을 쓰나요?", "이런 일에서 잘 된 결과는 어떤 건가요?" 같은 질문이에요. 처음 온 동료가 따라 할 수 있을 만큼 답해 주세요.
3. Claude가 스킬의 지시 파일(SKILL.md)과 필요한 자료를 만들어 스킬 파일 하나로 묶어 줘요.
4. 그 파일을 저장한 뒤 **Customize › Skills**에서 **+** → **+ Create skill** → **Upload a skill**로 올려요(스킬 폴더를 담은 ZIP 파일). 올린 스킬은 스킬 목록에 나타나니 켜져 있는지 확인하세요. 튜토리얼에는 저장한 스킬을 **Settings › Capabilities › Skills**에서 켜고 끈다고도 적혀 있어요 — 화면에 따라 둘 중 한 곳에 있어요.
5. 스킬이 맡을 만한 일을 시켜 보고, 결과가 어긋나면 "스킬을 이렇게 고쳐 줘"라고 다시 부탁해요.

## 3. 메일·일정을 복사해 온다면 → 커넥터(Connectors)

메일 내용을 복사해서 붙여 넣고 있다면 커넥터를 연결할 차례예요. Gmail·Google 캘린더·Google 드라이브를 연결해 두면, **내가 물어볼 때** Claude가 메일을 찾아 읽고, 일정을 보고 빈 시간을 찾고, 드라이브 문서를 찾아요.

- **누가 쓸 수 있나:** Google Workspace 커넥터(Gmail·Google 캘린더·Google 드라이브)는 웹과 데스크톱 앱의 **모든 사용자**가 쓸 수 있어요. Team·Enterprise는 소유자(관리자)가 먼저 켜야 해요.
- **연결하는 곳:** **Customize › Connectors**. 대화 중에는 입력창의 **+** → **Connectors**에서 켜고 끌 수 있어요.
- **먼저 물어보는 일:** 기본 설정에서 Claude는 메일을 **보내기·답장·전달하기 전**, 드라이브 파일을 **공유·이동·휴지통으로 보내기 전**에 승인을 물어요.
- **언제 읽나:** 도움말은 Claude가 "질문하거나 그 정보가 필요한 일을 요청할 때만" 데이터에 접근한다고 적고 있어요.

영상에서는 「같은 자료 → 프로젝트」와 헷갈리지 않게 Gmail·캘린더만 보여 드렸어요. 드라이브 문서를 대화마다 다시 찾는다면 커넥터, 늘 같은 문서를 기준으로 삼는다면 프로젝트 지식 칸에 넣어 두는 쪽이 편해요.

## 4. 문서·슬라이드가 필요하다면 → 그냥 만들어 달라고 하세요

결과물이 문서·슬라이드·디자인이라면 따로 고를 기능이 없어요. 2026년 9월 16일부터 대화 중에 "이 내용으로 슬라이드 만들어 줘"처럼 부탁하면 되고, 아티팩트(Claude Design·Claude Slides·Claude Docs 포함)는 **무료를 포함한 모든 요금제**에서 쓸 수 있어요(Enterprise는 베타, 소유자가 켠 뒤).

## 한 장 정리

〔그림 3〕 *반복하는 말 → 기능, 한 장 정리*

- **같은 자료를 붙여 넣는다** → 프로젝트(Projects) · 무료 5개까지
- **같은 방식을 설명한다** → 스킬(Skills) · 먼저 Code execution and file creation 켜기
- **메일·일정을 복사해 온다** → 커넥터(Connectors) · 보내기 전엔 승인
- **문서·슬라이드가 필요하다** → 그냥 만들어 달라고 하기(아티팩트) · 무료 포함

세 기능 모두 무료 계정에서도 쓸 수 있어요(커넥터는 웹·데스크톱, 팀·기업은 관리자가 켠 뒤).

## 바로 해 볼 한 가지

오늘 Claude한테 두 번 이상 한 말을 하나 골라 보세요. 자료였다면 프로젝트를 하나 만들고, 방식이었다면 "이걸 스킬로 만들고 싶어"라고 말해 보고, 메일이었다면 Gmail 커넥터를 연결해 보세요.

참고로, Pro·Max 요금제에는 2026년 9월 16일부터 채팅과 Cowork를 한 화면으로 합친 새 화면이 차례로 열리고 있어요. 이 화면에서도 프로젝트·스킬·커넥터는 그대로 이어져요. 메뉴 위치가 조금 달라 보일 수 있으니 위의 메뉴 이름으로 찾아 주세요.

여러분은 AI한테 뭘 제일 많이 반복하세요? 댓글로 ① 자료 ② 방식 ③ 메일·일정 ④ 아직 안 써 봤어요 가운데 하나만 남겨 주세요. 같은 내용을 1분 안쪽 영상으로 정리한 쇼츠·릴스는 인스타그램·유튜브 @synkbrief에 있어요.
