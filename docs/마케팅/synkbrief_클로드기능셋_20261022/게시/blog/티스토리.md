## 내가 반복하는 말부터 찾기

〔그림 1〕 *기준은 하나 — 내가 Claude한테 뭘 반복하나*

최근 Claude 대화 몇 개를 열어 보고 스스로 물어보세요.

- 대화를 새로 열 때마다 **같은 파일이나 회사 소개를 다시 올리고** 있나요?
- 같은 종류의 일을 맡길 때마다 **"양식은 이렇게, 순서는 이렇게"를 다시 쓰고** 있나요?
- 메일이나 일정 내용을 **복사해서 붙여 넣고** 있나요?

예라고 답한 줄이 여러분이 먼저 켤 기능이에요.

## 프로젝트 — 같은 자료를 다시 올리고 있을 때

**이럴 때:** 거래처 응대처럼 늘 같은 자료(회사 소개, 가격표, 자주 묻는 질문)를 바탕으로 대화할 때.

**이렇게:** 왼쪽 **Projects**(또는 claude.ai/projects) → 오른쪽 위 **+ New Project** → 이름 붙이기. 프로젝트 첫 화면 오른쪽 지식 칸의 **+**로 문서·텍스트 파일·코드 조각을 올리고, **Set project instructions**에 "답은 존댓말로, 가격은 표로" 같은 지침을 적어요. 이제 그 프로젝트에서 여는 대화는 전부 같은 자료와 지침을 써요. 프로젝트 이름과 설명은 Claude가 읽지 않으니, 알려 줄 내용은 지식 칸이나 지침에 넣으세요.

**조심할 것:** 도움말에 따르면 프로젝트 안의 대화끼리는 맥락이 이어지지 않고, 지식 칸에 넣은 정보만 함께 써요(프로젝트마다 따로 메모리가 있다는 설명도 같은 글에 있어요). 다음 대화에도 꼭 필요한 건 지식 칸에 넣어 두세요. 무료 계정은 프로젝트를 5개까지 만들 수 있고, 유료 요금제는 자료가 많아지면 자동으로 RAG 방식으로 넓혀 줘요.

## 스킬 — 같은 방식을 다시 설명하고 있을 때

**이럴 때:** 주간 보고, 회의 정리, 우리 회사 문서 규칙처럼 "이 일은 이렇게 해"가 정해져 있을 때.

**이렇게:** 먼저 **Settings › Capabilities**에서 **Code execution and file creation(코드 실행·파일 만들기)**를 켜요. 스킬은 코드 실행이 켜져 있어야 돌아가거든요(Team·Enterprise는 조직 설정 Organization settings › Plugins & skills에서 관리자가 켜져 있는지 확인해요 — Team은 기본으로 켜져 있어요). 그다음 **Customize › Skills**에서 스킬을 보고 켜고 꺼요. Anthropic이 만든 예시 스킬(엑셀 표 만들기·워드 문서·파워포인트·PDF)도 이곳에 있어요.

**조심할 것:** Claude는 요청을 보고 필요할 때 켜 둔 스킬을 알아서 써요. 꺼 둔 스킬은 쓰지 않고, 알아서 안 꺼내면 "주간 보고 스킬로 써 줘"처럼 이름을 불러 주면 돼요.

## 커넥터 — 메일·일정을 복사해 오고 있을 때

**이럴 때:** 거래처 메일을 찾아 답장 초안을 쓰거나, 일정에서 빈 시간을 찾을 때.

**이렇게:** **Customize › Connectors**에서 Gmail·Google 캘린더·Google 드라이브를 연결해요. 대화 중에는 입력창 **+** → **Connectors**에서 켜고 끌 수 있어요. 웹과 데스크톱 앱의 모든 사용자가 쓸 수 있고, Team·Enterprise는 소유자(관리자)가 먼저 켜 줘야 해요.

**조심할 것:** Claude는 내가 질문하거나 그 정보가 필요한 일을 부탁할 때만 데이터에 접근해요. 그리고 기본 설정에서는 메일을 보내기·답장·전달하기 전, 드라이브 파일을 공유·이동·휴지통으로 보내기 전에 꼭 승인을 물어요. 늘 같은 드라이브 문서를 기준으로 삼는다면 커넥터보다 프로젝트 지식 칸에 넣어 두는 편이 편해요.

## 자주 하는 오해 셋

〔그림 2〕 *스킬은 말로 시켜서 만들 수 있어요(예시 그림)*

**스킬은 코딩할 줄 알아야 만드나요?**
아니에요. Anthropic 튜토리얼 「How to create a skill with Claude through conversation」대로라면 대화로 만들 수 있어요. 새 대화에서 "주간 보고 스킬 만들고 싶어"라고 말하고(쓰던 양식이나 잘 쓴 예시가 있으면 함께 올리고), Claude가 "언제 이 스킬을 쓰나요?", "잘 된 결과는 어떤 건가요?"라고 되물으면 처음 온 동료도 따라 할 만큼 답해 주세요. Claude가 지시 파일(SKILL.md)과 자료를 스킬 파일 하나로 묶어 주면, 저장해서 **Customize › Skills** → **+** → **+ Create skill** → **Upload a skill**로 올리고, 스킬 목록에서 켜져 있는지만 확인하면 끝이에요(스킬 폴더를 담은 ZIP 파일). 튜토리얼은 저장한 스킬을 **Settings › Capabilities › Skills**에서 켜고 끈다고도 적고 있어서, 화면에 따라 두 곳 중 하나에 있어요. 결과가 어긋나면 "스킬을 이렇게 고쳐 줘"라고 다시 부탁하면 돼요.

**이 기능들, 유료 요금제에서만 되나요?**
아니에요. 프로젝트는 무료 계정을 포함한 모든 사용자(무료는 5개까지), 스킬은 Free부터 Enterprise까지 모든 요금제, Google 커넥터는 웹·데스크톱의 모든 사용자가 쓸 수 있어요. 문서·슬라이드·디자인을 만드는 아티팩트(Claude Design·Claude Slides·Claude Docs 포함)도 2026년 9월 16일부터 무료를 포함한 모든 요금제에서 대화 중에 만들 수 있어요(Enterprise는 베타, 소유자가 켠 뒤).

**커넥터를 연결하면 Claude가 메일함을 마음대로 뒤지나요?**
아니에요. 묻거나 부탁할 때만 찾아 읽고, 메일을 보내거나 파일을 공유하기 전에는 기본으로 승인을 받아요.

## 무료 계정 점검표

1. Settings › Capabilities에서 Code execution and file creation 켜기(스킬용)
2. Projects에서 + New Project로 자주 쓰는 자료 묶음 하나 만들기(5개까지)
3. Customize › Connectors에서 Gmail·캘린더 연결하기
4. "이 일을 스킬로 만들고 싶어"라고 한 번 말해 보기
