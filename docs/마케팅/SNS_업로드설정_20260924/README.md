## 앞으로 게시할 때

1. 원본 파일의 실제 해상도·화면비·프레임률을 확인한다. 낮은 해상도를 억지로 확대해 ‘4K’로 표시하지 않는다.
2. 해당 업로드 기기에서 ‘최고 화질로 업로드’, ‘고화질’, ‘원본’ 옵션이 제공되면 켠다. 재생 화질·자동 재생 옵션과 구분한다.
3. 계정과 공개 범위를 확인하고 댓글·공유·인용 허용 여부를 해당 게시물에 맞춰 확인한다. 아동용·광고·협찬·합성 콘텐츠 표시 등은 실제 내용에 맞춰 지정한다.
4. 제목·설명·카테고리·언어·태그는 내용과 맞춘다. 자막과 썸네일은 실제 모바일 화면에서 읽히는지 확인한다.
5. 업로드 후 처리 완료된 공개 영상을 재생해 해상도·음성·자막·링크를 확인한다. YouTube는 HD/4K 처리 시간이 더 걸릴 수 있다. [YouTube 처리 화질 안내](https://support.google.com/youtube/answer/71674?hl=en)
6. [SNS 성장 기록장](http://127.0.0.1:4188/)에 실제 게시물 URL을 등록하고 같은 시각에 조회·좋아요·댓글·공유·저장·팔로워를 기록한다. 기록 기준과 운영법은 [기록장 안내](../온라인마케팅지도/engagement/README.md)를 따른다.

추천 노출은 시청자의 반응과 만족도 등으로 결정된다. 이 점검에서 추천 성과를 높이는 ‘일괄 최상위 스위치’나 성과 보장은 확인하지 않았다. [YouTube 공식 추천 안내](https://support.google.com/youtube/answer/16533387?hl=en-GB)
