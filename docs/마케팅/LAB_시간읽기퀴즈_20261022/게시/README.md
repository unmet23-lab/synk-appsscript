## 판마다 같은 설정

- 어린이 전용(made for kids) 아님 — 끝 행동이 댓글(내 시각을 한국어로)이다.
- AI·합성 표시: 필수 아님. 펠트 그림과 특정인이 아닌 TTS 진행자라 사실적인 사람·장면이 없다(관용구 퀴즈와 같은 판단).
- 언어: 유튜브 동영상 언어 en(영어 진행 + 한국어 읽기), 제목·설명 en. 몽골어판은 목소리가 한국어뿐이라 동영상 언어 ko, 글 언어 mn.
- 자동 더빙·Meta AI 번역(목소리·입 맞추기)은 끈다(제작 방식 v2 §4-2).
- 끝 행동 링크 synk.im/try/learning-hub/ — 10-22 08:0x 응답 200. 유튜브는 설명란·고정 댓글, 몽골은 첫 댓글(선택)에만.
- 인스타 해시태그: 캡션 4개 + 첫 댓글 0개 = 4개.
- 훅 이름표: 몽골어판 A 질문(「СОЛОНГОСООР ЦАГ ХЭЛЖ ЧАДАХ УУ?」), 영어판 B 갈등(「2 NUMBER SYSTEMS? 1 RULE.」).
