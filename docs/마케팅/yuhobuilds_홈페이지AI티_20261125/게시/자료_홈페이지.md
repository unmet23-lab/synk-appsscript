# 클로드가 만든 홈페이지, AI 티를 빼는 다섯 줄

클로드에게 가게 홈페이지를 맡기는 분을 위한 자료예요. 요청 끝에 아래 다섯 줄을 붙이면, 늘 비슷하게 나오던 분홍 · 카드 상자 · 여러 버튼이 빠진 화면이 나와요.

- 저희는 같은 꽃집 홈페이지 요청을 맥락 없는 새 클로드에게 세 번 맡겼어요. 세 번 모두 같은 크림색 바탕과 거의 같은 분홍이 나왔고, 카드 상자와 버튼 네다섯 개가 붙었어요. 이모지는 두 판에 있었어요.
- 같은 요청 끝에 다섯 줄을 붙여 다시 세 번 맡겼어요. 세 번 모두 흰 바탕에 검정 줄, 강조 한 색, 버튼 하나로 나왔어요.

아래 결과는 모두 저희가 2026-11-25에 직접 돌려 본 것만 적었어요.

---

## 이런 분께 맞아요

- 가게 · 학원 · 1인 사업 홈페이지 첫 화면을 클로드에게 맡기는 분
- 클로드가 만든 화면을 보고 「어디서 본 것 같다」, 「AI가 만든 티가 난다」는 말을 들은 분

---

## 붙여 넣을 다섯 줄

홈페이지를 맡기는 요청 맨 끝에 그대로 붙여요.

```
그리고 아래 다섯 줄을 지켜 줘.
1. 이모지와 장식 아이콘은 넣지 마.
2. 알약 모양 꼬리표, 파스텔 동그라미 같은 장식은 빼.
3. 색은 검정, 흰색, 강조 한 색만 써.
4. 버튼은 하나만, 가장 중요한 일에만 둬.
5. 카드 상자를 나란히 늘어놓지 말고, 글과 가는 줄로 나눠.
```

저희가 시험한 요청 전체는 이랬어요.

```
동네 꽃집 홈페이지 첫 화면을 HTML 파일 하나로 만들어 줘.
가게 이름은 「오늘꽃」이고, 꽃다발 주문과 한 달 정기 배송을 해. 답은 HTML 코드만 줘.

그리고 아래 다섯 줄을 지켜 줘.
1. 이모지와 장식 아이콘은 넣지 마.
2. 알약 모양 꼬리표, 파스텔 동그라미 같은 장식은 빼.
3. 색은 검정, 흰색, 강조 한 색만 써.
4. 버튼은 하나만, 가장 중요한 일에만 둬.
5. 카드 상자를 나란히 늘어놓지 말고, 글과 가는 줄로 나눠.
```

---

## 사진 넣기 — 두 줄 더

다섯 줄 아래에 이 줄을 더해서 맡겨요. 첫 화면에 큰 사진 칸이 생겨요. 두 번 맡겨 두 번 다 생겼어요.

```
6. 첫 화면 오른쪽에 가게 사진이 들어갈 자리를 크게 비워 둬.
```

받은 HTML은 `index.html`로 저장하고, 가게 사진을 같은 폴더에 `shop.jpg`라는 이름으로 둬요. 클로드 코드에서 그 폴더를 열고 이렇게 말해요. 앞의 대화를 모르는 새 클로드에게 한 번 시켜 보니, 사진 칸 한 줄만 바뀌고 사진이 칸에 꽉 찼어요.

```
index.html의 사진 자리에 같은 폴더의 shop.jpg를 꽉 차게 넣어 줘. 다른 것은 그대로 둬.
```

영상에 나오는 꽃 사진은 예시로 만든 그림이에요.

## 저희가 잰 결과

**어떻게 쟀나**
- 날짜와 도구: 2026-11-25, 클로드 코드 명령줄(윈도우 11) · Sonnet 5.5. 앞의 대화를 모르는 새 클로드에게 한 번씩, 다섯 줄 없이 세 번과 다섯 줄을 붙여 세 번 맡겼어요.
- 받은 HTML을 크롬에서 가로 1440px 창으로 열어 찍고, 화면에 보이는 것을 셌어요.

| | 다섯 줄 없이(세 번) | 다섯 줄 붙임(세 번) |
|---|---|---|
| 바탕색 | 세 번 모두 같은 크림색(#FFFAF5) | 세 번 모두 흰색 |
| 강조색 | 세 번 모두 거의 같은 분홍(#D9526B · #D9576B · #D9576B) | 판마다 다른 빨강 한 색 |
| 화면 글 속 이모지 | 2 · 0 · 4개 | 0 · 0 · 0개 |
| 버튼 | 5 · 5 · 4개 | 1 · 1 · 1개 |
| 카드 상자(서비스 상자 + 순서 상자) | 5 · 5 · 6개 | 0 · 0 · 0개 |
| 알약 꼬리표 | 1 · 2 · 0개 | 0 · 0 · 0개 |

- 다섯 줄 없이 받은 세 판 가운데 둘은 큰 제목까지 「오늘 하루에 꽃 한 송이를 더해요」로 같았어요. 다섯 줄을 붙인 세 판도 큰 제목은 서로 비슷했어요. 다섯 줄은 꾸밈을 바꾸고, 글은 바꾸지 않아요.
- 다섯 줄을 붙인 판에는 그림이 하나도 없었어요. 다섯 줄을 붙이니 꽃 그림까지 빠졌어요. 가게 사진을 넣고 싶으면 아래 「사진 넣기」 두 줄을 이어서 써요.

**발표 자료에서는 달랐어요.** 같은 날 발표 슬라이드 한 장도 세 번씩 맡겨 봤어요. 다섯 줄 없이도 세 장 모두 그라데이션과 이모지가 없었어요. 슬라이드에 맞춰 쓴 다른 다섯 줄을 붙여 보니, 세 판 가운데 한 판은 덜 중요한 숫자를 크게 키웠어요. 그래서 이 다섯 줄은 홈페이지에 권해요.

## 채팅 클로드에서 쓰려면

저희는 클로드 코드 명령줄로 쟀어요. 채팅 화면(claude.ai)에서는 해 보지 않았어요. 2026-11-25에 읽은 공식 도움말 내용이에요.

- 화면을 만들어 대화 옆에 띄우는 기능(아티팩트)은 무료 · 프로 · 맥스 · 팀 · 엔터프라이즈 요금제 모두에서 쓸 수 있다고 나와 있어요.
- 무료 요금제에서는 설정 → Capabilities에서 「Create and edit files」(옛 화면에서는 「Cloud code execution and file creation」)를 켜야 한다고 나와 있어요.
- 만든 화면은 대화 옆에 열려요.

---

## 안 될 때

- **그래도 이모지가 나와요.** 「1번을 지켜서 다시 만들어 줘. 이모지가 남아 있어」처럼 어긴 줄 번호를 짚어요.
- **너무 밋밋해요.** 3번의 강조 한 색을 내가 정해 줘요. 예: 「강조색은 #1F6F5B 하나만 써」.
- **글이 너무 길어요.** 「첫 화면 글은 세 줄 안으로 줄여 줘」를 더해요.
