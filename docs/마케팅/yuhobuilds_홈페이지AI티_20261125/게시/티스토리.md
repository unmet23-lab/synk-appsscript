〔유튜브 쇼츠〕

## 무엇을 시켰나

빈 폴더에서 클로드 코드 명령줄을 줄마다 새로 불러, 앞의 대화를 모르는 클로드에게 맡겼습니다. 시험한 요청에는 ○○ 자리에 가게 이름을 넣었습니다.

```
동네 꽃집 홈페이지 첫 화면을 HTML 파일 하나로 만들어 줘.
가게 이름은 「○○꽃」이고, 꽃다발 주문과 한 달 정기 배송을 해. 답은 HTML 코드만 줘.
```

받은 HTML을 크롬에서 열어 찍고, 화면에 보이는 이모지 · 버튼 · 카드 상자 · 알약 모양 꼬리표를 셌습니다.

## 다섯 줄 없이 — 세 번 다 같은 분홍

- 바탕색은 세 번 모두 같은 크림색(#FFFAF5)이었습니다.
- 강조색은 #D9526B · #D9576B · #D9576B로 거의 같은 분홍이었습니다.
- 세 판 가운데 둘은 큰 제목이 글자까지 같았습니다(「… 하루에 꽃 한 송이를 더해요」).
- 버튼은 5 · 5 · 4개, 카드 상자는 5 · 5 · 6개, 화면 글 속 이모지는 2 · 0 · 4개였습니다.

## 붙인 다섯 줄

```
그리고 아래 다섯 줄을 지켜 줘.
1. 이모지와 장식 아이콘은 넣지 마.
2. 알약 모양 꼬리표, 파스텔 동그라미 같은 장식은 빼.
3. 색은 검정, 흰색, 강조 한 색만 써.
4. 버튼은 하나만, 가장 중요한 일에만 둬.
5. 카드 상자를 나란히 늘어놓지 말고, 글과 가는 줄로 나눠.
```

## 다섯 줄을 붙이고 — 세 번 다 버튼 하나

- 바탕은 세 번 모두 흰색이었고, 강조색은 판마다 다른 빨강 한 색이었습니다.
- 버튼은 세 번 모두 1개였습니다.
- 카드 상자, 이모지, 알약 꼬리표는 세 번 모두 0개였습니다.
- 큰 제목은 세 판이 서로 비슷했습니다. 다섯 줄은 꾸밈을 바꾸고, 글은 바꾸지 않습니다.

## 솔직하게 적어 둘 것

- 다섯 줄을 붙인 판에는 그림이 하나도 없었습니다. 다섯 줄을 붙이니 꽃 그림까지 빠졌습니다. 「6. 첫 화면 오른쪽에 가게 사진이 들어갈 자리를 크게 비워 둬.」를 더해 두 번 더 맡기니, 두 번 모두 첫 화면에 큰 빈 사진 칸이 생겼습니다. 받은 화면을 새 클로드에게 다시 주며 「사진 자리에 shop.jpg를 꽉 차게 넣어 줘」라고 하니, 사진이 칸에 꽉 차게 들어갔습니다(한 번 해 봤습니다). 영상에 나오는 꽃 사진은 예시로 만든 그림입니다.
- 같은 날 발표 슬라이드 한 장도 세 번씩 맡겨 봤습니다. 다섯 줄 없이도 세 장 모두 그라데이션과 이모지가 없었습니다. 슬라이드에 맞춰 쓴 다른 다섯 줄을 붙여 보니, 세 판 가운데 한 판은 덜 중요한 숫자를 크게 키웠습니다. 그래서 이 다섯 줄은 홈페이지에 권합니다.
- 시험은 클로드 코드 명령줄로 했습니다. 채팅 화면(claude.ai)에서는 해 보지 않았습니다. 공식 도움말에는 대화 옆에 화면을 만들어 띄우는 기능(아티팩트)을 무료 요금제에서도 쓸 수 있고, 무료에서는 설정 → Capabilities에서 「Create and edit files」를 켜야 한다고 나와 있습니다(2026-11-25 읽음).
