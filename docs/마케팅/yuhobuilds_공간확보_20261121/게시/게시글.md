# 게시글 · Y75 「AI한테 '공간 확보해 줘' 맡겼더니 — 내 작품 작업 파일 1,046개도 내려갔다」

판마다 올라가는 글의 정본은 각 판 폴더의 원고 파일이다. 이 파일은 사람이 읽는 판이다.

## 인스타 릴스 · 유튜브 쇼츠(같은 글)

AI한테 「공간 확보해 줘」 맡길 때, 이 세 마디는 꼭 붙이세요 👇

C드라이브 여유가 줄어서 AI한테 공간 확보를 맡겼더니 52.6GB를 비웠어요. 끝난 작업 복사본, 오래 안 연 작업 폴더, 임시 파일, 오래된 영상 · 그림 · 소리 네 묶음이었어요.

그런데 그 안에 제가 고른 작품 세 편의 작업 파일(컷 그림 · 소리 · 테이크) 1,046개, 7.35GB가 섞여 있었어요. 지운 건 아니고, PC에서 내려 클라우드 보관함에만 둔 거였어요.

폴더마다 옮긴 파일 목록과 되살리는 명령이 남아 있어서, 폴더마다 그 한 줄을 돌려 1,046개를 다 되살렸어요. 빠진 파일은 0개. 기준을 고쳐 다시 세 보니 빼야 할 곳이 28곳(8.49GB) 더 있어서 그것도 되살렸고, 그러고도 35GB 넘게 비웠어요.

그래서 이제 정리를 맡길 때 이 말을 붙여요.

PC 공간을 정리해 줘. 지우거나 옮기기 전에 아래 세 가지를 꼭 지켜 줘.

1. 내가 고른 작업 목록과 겹치는 파일은 먼저 빼 줘. 뺀 파일은 표(폴더 · 개수 · 크기)로 보여 줘.
   내가 고른 작업 목록: 【여기에 폴더 이름이나 목록 붙여 넣기】
2. 옮기거나 지우는 파일은 폴더마다 목록(이름 · 크기 · 옮긴 곳)으로 남겨 줘.
3. 옮긴 파일을 되살리는 명령을 폴더마다 한 줄씩 남겨 줘.

정리가 끝나면 비운 크기와 뺀 크기를 따로 알려 줘.

화면의 숫자는 11월 20일 그 정리의 실제 기록이에요. 폴더 주소와 파일 이름은 가렸어요.

AI한테 정리 맡겼다가 사라진 파일 있어요? 👇
