유호님이 「이 과정을 gpt로 진행할게. 토큰이 없어서 그래」라고 해서 넘긴다. 아래 순서대로 이어 가면 된다.

## 유호님이 원하는 것(10-07 원문)

> 댓글을 확인해서 그 댓글자가 팔로우하고 좋아요 누르고 댓글 달았다면 그걸 알아서 dm으로 먼저 댓글 단 사람에게 보내서 그 사람이 필요한 소스를 전달해주는걸 하고싶은거야. 우리가 준비한 프롬프트나, pdf나, 프로그램있잖아.

**정한 길: 「둘 다」(10-07 유호님 선택).** 외부 DM 자동화 도구로 먼저 쓰고, 직접 만든 것이 Meta 심사를 통과하면 그쪽으로 옮긴다.

## 확인된 사실(공식 문서 기준, 10-07)

- **먼저 DM 보내기는 된다.** 댓글에 대한 「비공개 답장(private reply)」으로 보낸다. 댓글 하나에 DM 1통, 댓글 단 지 7일 안에만 된다. 권한은 `instagram_business_basic` + `instagram_business_manage_comments`(+ 메시지 권한)이다.
- **팔로우 확인은 한 단계를 거치면 된다.** User Profile API의 `is_user_follow_business`로 본다. 다만 상대가 DM을 보내거나 단추(아이스브레이커·메뉴)를 누른 뒤에만 조회된다. 그래서 첫 DM에 「자료 받기」 단추를 두고, 누르면 확인한다. 팔로우했으면 자료를 보내고, 안 했으면 「팔로우하고 다시 눌러 주세요」를 보낸다. [Meta User Profile API](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/messaging-api/user-profile)
- **좋아요 확인은 안 된다.** 공식 API는 좋아요 개수만 주고 누가 눌렀는지는 주지 않는다. 몰래 긁어 오는 방식(비공식 API·스크래핑)은 계정이 막힐 수 있어 쓰지 않는다. 좋아요는 DM 문구로 부탁만 한다. 유호님께도 이렇게 설명했다.
- 단추를 누른 뒤의 일반 DM은 상대의 마지막 메시지에서 24시간 안에만 보낼 수 있다. 팔로우하지 않은 사람에게 간 DM은 메시지 요청함으로 갈 수 있다.
- 직접 만든 앱으로 **아무 계정에게나** 보내려면 Meta 앱 심사(Advanced Access)와 사업자 확인이 필요하다. 심사 전에는 앱에 역할이 있는 계정끼리만 시험할 수 있다. 심사에는 공개된 개인정보처리방침 주소가 필요하다. 지금은 초안이 승인을 기다리는 중이다(트랙 §1).

## GPT 할 일(순서대로)

1. **외부 도구 고르기.** 팔로우 확인이 되는 도구 2~3개를 **공식 요금·도움말 페이지**로 비교해 유호님께 보여 드린다.
   - 볼 것: 팔로우 게이트, 게시물별 키워드, 댓글 공개 답글, Meta 공식 파트너인지, 한국어 DM, 가장 싼 해당 요금제, 해지 방법.
   - 요금이 드니 결제 전에 금액을 알리고 승인을 받는다.
   - 가입·인스타 연결(OAuth)은 유호님이 한다. 설정과 시험은 GPT가 한다.
2. **첫 캠페인을 설정한다.** 위 릴스에 키워드(예: 「매뉴얼」) → 첫 DM(「자료 받기」 단추) → 팔로우 확인 → `https://synk.im/builds/`를 보낸다. 댓글 공개 답글은 「DM 보냈어요 📩」 같은 한 줄로 한다. 문구는 유호님 확인을 받는다.
3. **시험한다.** 다른 계정으로 댓글을 달고, 아래가 실제로 되는지 본다.
   - 팔로우 안 한 상태 → 안내가 오는지
   - 팔로우한 뒤 다시 누름 → 자료가 오는지
   - 같은 사람이 다시 댓글을 달았을 때 중복으로 보내지 않는지
   - 이게 다 확인된 뒤에만 다음 게시물 캡션에 「댓글 달면 보내 드려요」를 쓴다.
4. **자료 표를 만든다.** 게시물마다 키워드와 보낼 자료(프로그램 링크·PDF·프롬프트)를 정한다. PDF는 공개 링크가 필요하다. 표는 `docs/마케팅/` 아래 한곳에 둔다.
5. **직접 만들기를 준비한다(병행).**
   - `엔진_synkbrief.js`를 여러 계정(@yuhobuilds 포함)으로 넓히는 설계를 한다. 비공개 답장 + 단추 + `is_user_follow_business` 확인을 넣는다.
   - 웹훅을 Apps Script에 둘지, talk 함수 쪽에 둘지 정한다.
   - 유호님 몫(트랙 §1에 이미 있음): 회사 명의 Meta 개발자 앱, 사업자 확인, 처리방침 공개 주소.
   - 심사 전에는 앱 역할 계정끼리 끝까지 시험한다.

## 지킬 것

- 가입·로그인·비밀번호·결제·OAuth 승인은 유호님이 한다. 토큰·키 값은 출력하거나 저장소에 쓰지 않는다.
- 공개 게시·답글·캡션 변경은 유호님 승인 뒤에 한다. 유호님이 쓴 공개 문구는 따로 허락받기 전에는 지우지 않는다. 좋아요 스크래핑은 쓰지 않는다.
- Apps Script 라이브 배포는 요청이 있을 때 `deploy` 절차로만 한다. `doGet`은 HtmlService를 돌려주지 않는다.
- 크롬 확장으로 할 때:
  - 크롬 창이 화면에 보여야 한다. 다른 앱에 가려지면 팝업·업로드가 멈춘다. 먼저 「크롬을 앞으로 띄워 주세요」라고 부탁한다.
  - 유튜브 채널을 바꿨으면 SYNK LAB Mongolia로 되돌린다.
  - 인스타 만들기 창에서 Escape를 누르면 게시물 삭제 확인이 뜬다.
- 시각은 PowerShell `Get-Date`로 본다(Git Bash `date`는 UTC).
