# Tistory(yuhobuilds.tistory.com) 적용기 원고 — AI 검수가 초까지 짚은 지적 다섯, 재 보니 다섯 다 사실 아니었다(2026-11-03 만듦 · 슬롯 11-11 영상 뒤)

> 영상과 같은 일을 「무슨 일이 있었나 → 왜 그런가 → 이렇게 바꿨다 → 바꾼 뒤 → 가져갈 줄 · 범위」 순서로. 올리기는 영상이 나간 뒤([장부](../../기획장부/yuhobuilds.md) 머리말 「티스토리 적용기」). 〔유튜브 쇼츠〕 자리에 영상 주소를 넣는다.

**제목**

AI 검수의 확신에 찬 지적, 그대로 믿으면 안 되는 까닭 — 다섯 개를 직접 재 봤다

**카테고리**

막힌 문제 해결

**본문**

올리기 전 영상을 AI에게 검수시키면 편해요. 영상을 소리째 보여 주면 몇 초에 뭐가 이상한지까지 적어 주거든요.

〔유튜브 쇼츠〕

10월 31일, 만들어 둔 짧은 영상 다섯 편을 맡겼더니 답이 이렇게 왔어요. 그중 단정하듯 말한 다섯 개를 하나씩 직접 쟀어요.

1. 「목소리가 심하게 지지직거리며 깨지고 뭉개짐」 → 같은 목소리 여덟 줄의 깨짐 정도가 43~76%인데 그 줄은 65%였어요. 범위 안이에요.
2. 「효과음이 지나치게 크고 날카롭게 튀어 귀를 찌름」 → 그 효과음은 말소리보다 8dB 작았어요.
3. 「목소리 크기가 앞 문장 대비 절반 수준으로 작아짐」 → 앞 문장 −14.7dB, 그 문장 −13.9dB로 같았어요.
4. 「'지어내지'가 '지아내지'로 잘못 적힌 오타」 → 원본 화면을 확대하니 「지어내지」로 맞게 써 있었어요. 압축된 화면을 잘못 읽은 것 같아요.
5. 「화면 전환보다 음성이 1초씩 먼저 나옴」 → 코드상 0.05초 차이였어요.

다섯 다 사실이 아니었어요. 맞힌 건 따로 둘이었어요 — 배경음이 18초쯤 끊긴 것, 휴대폰 진동음이 말을 덮은 것. 이 둘은 고쳤어요.

왜 그런지는 추측뿐이에요. 다만 답이 맞을 때와 틀릴 때 말투가 똑같이 확신에 차 있어서, 읽는 쪽에서는 구분이 안 돼요.

그래서 이렇게 바꿨어요.

- 소리 지적은 그 구간 소리 크기와 파형을 같은 목소리의 다른 문장과 견준다.
- 글자 지적은 원본 화면을 확대해서 본다.
- 뺀 지적도 한 줄씩 기록에 남긴다.

**가져갈 줄**

「AI 검수 지적은 그대로 옮기지 않는다. 소리는 크기 · 파형으로, 글자는 원본 확대로 직접 잰다.」

**범위**

한 AI에게 맡긴 하루치 검수 결과예요. 모든 AI 검수가 틀린다는 말은 아니고, 맞힌 지적도 있었어요. 영상의 진행자 얼굴과 목소리도 AI로 만들었어요.
