# synkbrief 활용 · AI 구독 계정판 — 콘티 v1

> 2026-10-17 유호님 「SHIFT 영상 콘티부터 시작해줘」. [기획](기획.md)의 컷 순서를 실제 화면 기준으로 다시 짰다. 이 단계는 이미지 콘티 확인까지이고, 대사 녹음·렌더·게시는 확인 뒤에 한다.

## 바뀐 점(기획 대비)

- 계정이 6개가 됐다(Claude 3 · GPT · Gemini · Higgsfield). 훅 A의 숫자를 6으로 바꿨다.
- 화면은 개발 창 실제 화면을 휴대폰 폭(540)으로 찍었다. 데스크톱 폭 화면은 세로 영상에서 글자가 너무 작았다. 전체 이메일은 앞부분만 남겼다(`unmet23@···`).
- 「전」 장면(계정마다 다시 로그인)은 아직 글자 카드다. 실제 브라우저에서 계정을 바꾸는 화면을 찍을지는 유호님이 정한다.

## 만드는 방식

- 옷: [SNS 키트](../../디자인/SNS키트/README.md) synkbrief 테마(청금석 색 면 · 흰 종이 · 노란 형광펜), 9:16 `.k-center` 배치, 낱말 단위 자막.
- 움직임: [만족 사례 S16](../제작양식/만족사례_장부.md)에서 시작한다(키네틱 타이포, 강조색 하나, 120 BPM 격자, 장면이 이어서 변형). S16과 달리 주인공은 실제 화면 캡처이고 퀴즈 구조가 없다.
- 소리: 내레이션 범수(Typecast, 다큐·설명형 기본) 한 명, 줄마다 보통. 키트 효과음. 배경음은 Gemini Ultra(Lyria 3.5)로 만든 연주곡 「Building Momentum」(10-17 유호님 「이 곡으로 배경음 쓰자」, [파일](../../홍보물/BGM/SHIFT구독판_BuildingMomentum_gemini_20261017.mp3), 크레딧 0). 실측 122.863 BPM·첫 박 0.054초, 드럼이 빠지는 마디 5.91·37.17초, 조용한 구간 23.49~31.31초, 다시 터지는 박 7.87·31.31·39.12초, 끝맺음 52.80초. 본편은 0~43.03초(22마디) + 끝맺음 52.80~55.6초로 이어 약 45.8초로 쓰고, 조용한 구간에 「흔한 오해」, 31.31초에 공식 프로그램 카드, 39.12초에 「무료」를 맞춘다.
- 마스코트·AI 그림 없음(이 편의 주인공은 실제 화면).

## 모션 v5 (10-17)

유호님 「트렌디한 걸 크롤링해서 … 신뢰감 위주로. 내용은 좋은데 보게 하는 힘이 부족」. 반응 좋은 런치 영상(Linear·Anthropic·Notion, Recent 런치 영상 98편)을 모아 공통 문법을 옮겼다([모션 조사](모션조사_20261017.md)). Fable이 세 번 검수했고 마지막 판정은 「이 판으로 나머지 장면 제작에 들어가도 된다」([검수 기록](모션검수_fable_20261017.md)). 유호님은 v5b를 보고 「확실히 좋아졌네」.

- 무대: 장면마다 흰 종이 대신 청금석 무대 하나(펠트 결, 아주 느린 깊이, 비네트, 실땀 모서리)가 끝까지 이어진다.
- 실제 화면: 계정판은 앱 CSS 그대로 그리고(`zoom`으로 키워 판이 내용을 자르지 않게) 그림자 진 판으로 띄운다. 숫자는 처음부터 실제 값, 움직임은 막대 폭·불투명도·위치에만.
- 훅: 첫 프레임부터 6/6·「지금 확인」 단추·99% 빨간 막대가 보이고, 기운 판이 펴지며 다가온 뒤 막대만 박마다 찬다.
- 지금 확인: 단추 쪽에 1.25배로 붙어 곡선 커서가 누르면 물러나며 읽는다. 읽기 전 줄은 빈 막대, 읽히는 순간 값이 생기고(1/6 = 값 하나) 지금 줄만 밝다. 드롭(7.87초)에 6/6, 한 박 머문다. 클릭 전 문구는 앱 그대로 「「지금 확인」을 누르면 연결한 계정을 한꺼번에 읽어요.」
- 급한 것: 1번 칩이 착지와 함께, 99%가 칩 위로 바로 튀어나오고(제목·1번 칩만 흐림), 같은 줄에 크레용 동그라미, 자막 강조도 같은 줄.
- 전환: 위로 밀어 넘기기 하나(겹침 0, 들어오는 장면이 박에 착지). 카메라 모션 블러는 숫자가 바뀌는 순간 잔상을 남겨 뺐다.
- 나머지 장면으로 넓힐 때 규칙(Fable): ① 장면당 변화 하나, 문구·숫자는 `desktop/renderer/subscriptions.mjs` 그대로, 앱에 없는 상태·문구 금지 ② 사건은 전부 `beat()`, 전환은 밀기 하나, 첫 요소는 착지와 함께·제목·자막은 착지 뒤·결과 한 박 홀드·0.5초 넘는 정지 없음, 끝은 마지막 2초 정지 + 훅 한 줄로 돌아감 ③ 머리줄·제목·숫자는 카메라 밖, 자리 토큰(454/530/640/1416, 84/920) 고정, 펀치는 장면당 하나·1.25 이하·원점은 동작 지점, 강조는 밑줄·동그라미·큰 숫자 각 하나, 튕김·펄스·글로·파티클·크로스페이드 금지, 소리는 사건당 하나.
