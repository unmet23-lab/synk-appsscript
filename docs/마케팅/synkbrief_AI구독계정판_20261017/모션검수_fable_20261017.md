## 최종 판정

**1. 판정** — v4보다 나아졌다. 한 무대 위에서 커서→클릭→줄 읽기→6/6→경고까지 인과가 한 줄로 이어지고, 날짜 도장·「계정 6개 · 14초」·실제 문구가 신뢰 장치로 남았다. 부족한 한 줄: 실제 값이 0에서 셈하듯 올라가고(정지컷마다 21%·0.21·0%가 남음) 장면이 반투명으로 겹쳐 넘어가서 「실제 화면」 감각이 순간순간 샌다.

**2. 고칠 것(우선순위)**

① 숫자 셈 올리기 제거(P1, f062·f240·f300). Hook5 `Math.round(a.weekly*fill)`·`(credits*fill).toFixed(2)`, Check5 같은 식, Attention5 `Math.round(99*fill)` → 전부 상수. 움직임은 막대 폭(`ms-bar>span` width)에만 10~12프레임 EASE_OUT. Check5 완료 줄은 「✓ 초록 글자」 대신 훅과 같은 `ms-bar`+흰 `ms-num`(실제 앱 subscriptions.mjs 237행 「주간 [막대] 38%」). 줄 밝기 .5→1은 6프레임.

② 전환을 밀기로(P1, abs 111~113). 지금은 두 장면의 opacity가 3프레임 겹치는 크로스페이드. 나가는 장면 opacity 고정 1, `len-13→len-7` 6프레임 translateY 0→-1600·blur 0→24(cubic in). 들어오는 장면 5→12프레임 translateY +520→0·blur 24→0(EASE_OUT), opacity는 5프레임부터 1. 겹침 0~1프레임, 박(12프레임)에 착지.

③ HUD를 카메라 밖으로(P1, f125·f140). Check5의 HeadF·「지금 확인」 Lines·`{done}/6`를 zoom div 바깥 형제로(지금 「ef 활용」「금 확인」으로 잘리고 0/6 오른끝 954px·04 950px가 920 안전선 밖). zoom 1.32→1.25, 원점 (806,720)으로 카드 위끝을 제목 아래(608) 밑 620px에. Hook5도 HeadF를 push div 밖으로(f062 머리줄 오른끝 928).

④ 「급한 것」 장면(P2, f268·f300·f355). 카드가 0.5초 빈 채로 도착 → `ATT.chips`를 [10, 20]프레임으로(1번 칩이 착지와 같이). 큰 숫자는 99%로 바로(셈 없음), 굵기 900→800·200px, top 700으로 올려 아래끝이 2번 칩(y 942) 위에. v4 잔재인 740px 막대+모노 라벨 「founder · Claude 주간 한도」 삭제(칩 글자와 겹침). 1번 칩 opacity .08, 2번 칩은 흐리지 않고 또렷하게. 자막 `em`을 「다 써 가는 계정,」으로 — 지금은 동그라미(2번 칩 99%)와 노랑 강조(1번 칩 크레딧)가 다른 줄을 가리킨다.

⑤ 훅 첫 프레임에 값(P2, f000~f030). `shown=6` 고정, 머리글 「마지막 확인 11:45 · 6/6개 읽음」, 줄은 HOOK.rows 박마다 막대만 쓸어 들어옴(틱 유지). 읽는 과정은 지금 확인 장면이 보여 주므로 훅에서 되풀이하지 않고, 6/6→0/6 되감김도 없앤다. 기울기 translateY 210→120, `flat = settle(f, 2, 9)`로 0.45초 안에 펴지게.

**3. 첫 1초** — 제목이 0프레임부터 읽히고 판이 펴지는 움직임은 좋다. 부족한 건 보상: 1.27초까지 스피너 여섯 개뿐이라 첫 프레임(썸네일)이 「로딩 화면」이다. ⑤대로 첫 프레임에 99% 빨간 막대가 보이면 「확인 가능한 숫자」가 훅이 되고, 박마다 막대 쓸기+틱이 1.3~2.5초를 채운다. 제목 크기(100px)는 그대로.

**4. 하지 말 것** — 실제 값 셈 올리기·「0%」 프레임, 앱에 없는 「✓ 초록」 줄 상태, 반투명 겹침 전환, 잘린 머리글, 1.3배 넘는 줌(세 번째부터 「줌 효과」로 읽힘), 900 굵기 큰 숫자. Burst(파티클)·펄스·튕김·흔들림은 지금도 없으니 그대로. 날짜 도장·「계정 6개 · 14초」·실제 문구는 손대지 않는다.

### 2. 남은 것 (우선순위)
- P1 지금 확인 줄 상태(Check5 72~73행, f125·f175): 읽히기 전엔 막대 트랙만·값 없음, 읽히는 순간 값이 생겨야 「1/6 = 값 하나」가 된다. `fill = ok ? ramp(f, CHK.done[i], 10) : 0`; 숫자 span(주간·크레딧 둘 다) `opacity: ok ? interpolate(f, [done[i], done[i]+6], [0,1], clamp) : 0`. 줄 opacity는 지금대로(읽기 전 .5 · 현재 .8+배경 · 읽힌 뒤 1). 이러면 꺼졌다 다시 차는 막대도 사라진다.
- P2 훅 계정판과 지금 확인 계정판 맞추기(Hook5 49행): 머리글 오른쪽 「6/6」 span 자리에 Check5 59행과 같은 `ms-button ms-button-primary` 「지금 확인」. 「클릭 한 번」이 가리키는 단추가 첫 프레임에 보이고 두 판이 같은 화면이 된다. 단추 높이만큼 판이 33px쯤 길어지므로 `top: 905 → 890`.

### 3. 나머지 장면(02 전·03 회원 혜택·06 여유 계정·07 풀리는 시각·08 7일·09 흔한 오해·10 가이드·11 끝)으로 넓힐 때 규칙
1. 내용: 장면마다 바뀌는 것 하나, 문구·숫자는 앱(subscriptions.mjs)에서 그대로, 값은 상수이고 움직임은 막대·불투명도·위치에만. 앱에 없는 상태·문구·장식 UI를 만들지 않는다. 02 전도 실제 화면(탭·캡처)만, 스톡·추상 금지.
