## 근거와 확인

- 받는 곳: 인스타 @synkbrief 프로필 링크는 `synk.im`(10-18 공개 프로필에서 확인). PC 앱 다운로드 단추는 홈페이지 `synk.im/#platform` 구역(「SYNK ID 하나로, 나에게 맞는 SYNK를」)에 있고, Windows·Mac(Apple Silicon·Intel) 0.4.25 설치 파일 링크가 응답 200(10-18 19:5x).
- 공개 0.4.25 설치본의 계정판(`renderer/subscriptions.mjs`·`subscriptions.css`·`src/ai-subscriptions.cjs`)이 master와 바이트까지 같다 — 영상 속 「한눈에 보기」·Max 5x/20x 화면 그대로.
- 혜택 소개 페이지 `synk.im/account/platform.html#benefits/subscriptions`의 「PC 앱 받기 →」는 플랫폼의 「다운로드」 화면(`#downloads`, 0.4.25 Windows·Mac)으로 넘어간다(10-18 다시 확인). 처음엔 누른 직후 화면을 읽고 `#downloads`를 앵커로 잘못 봐 「안 넘어간다」고 적었다 — 틀린 판단이었다(커밋 8eb6b4751 메시지에도 그렇게 남았다). 글은 인스타 프로필 링크와 같은 홈페이지 `synk.im` → 「플랫폼」으로 안내한다(어느 길이든 같은 설치 파일).
- 사실 범위: 무료 조건은 공식 소개 그대로 「SYNK ID로 로그인한 회원」. 자동으로 읽는 건 공식 프로그램(Claude Code·Codex·Antigravity CLI·Higgsfield CLI)을 그 PC에 연결한 계정뿐이고, ChatGPT 쪽 숫자는 Codex 한도다. 「인증 토큰을 복사해 넣지 않는다」는 이 넷에만 말한다(Typecast는 API 키를 붙여 넣는다). 「로그인 정보가 PC 밖으로 안 나간다」처럼 넓히지 않는다. 「기록은 그 PC에만」은 공식 소개 문장.
- 채널 기준: 인스타는 링크를 프로필 링크·고정 댓글에, 해시태그 5개까지. 유튜브는 설명란에 주소. 댓글 DM 전달은 약속하지 않는다. 인스타 웹 댓글 칸은 엔터가 곧 게시라 고정 댓글은 한 줄.
