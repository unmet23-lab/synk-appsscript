- API: `POST https://api.recent.design/rpc/items/list`, 본문은 oRPC 형식이라 `{"json":{feed,format,category,sort,limit,cursor}}`로 감싸야 한다(감싸지 않으면 400 `Input validation failed`).

- 페이지 스크립트(`main-*.js`)의 feed 목록: `all, x, launch-videos, websites, og-images, app-store-screenshots, app-icons, tools, skills`. motion·video·product라는 feed는 없다.
- Design(feed `x`) 분류: branding, illustration, interface, motion, posters, print, web + **launch-videos**(별도 메뉴 「Launch Videos」, `/launch-videos`, 「Product launches, trailers and announcement films.」). launch-videos 유형 태그는 `type:ai|developer|design|productivity|consumer|hardware`. `category=product`는 0건.
- 받은 것:
  - `launch.json` — Launch Videos **98개 전부**(2026-08 1개, 나머지 97개는 2026-10-11~14 한꺼번에 등록). 모두 영상, 가로 1920x1080 위주(세로 2·정사각 5). 노출은 1,300~6,400(Grok Bot 하나만 50,709). 새 메뉴라 노출 절대값이 작다.
  - `xinterface.json` — Interface 302개(2026-06~10), 272개가 영상·gif. 노출 6만~12만. 주로 컴포넌트 단위 마이크로인터랙션.
  - `xmotion.json` — Motion 187개(2026-06~10). 노출 6만~10만. 캐릭터·3D·추상 실험이 대부분이라 앱 소개 영상과는 거리가 있다.
- 「인기순(popular)」은 노출 순서가 아니어서 받은 뒤 `stats.impressions`로 다시 줄 세웠다.
- 태그 빈도: launch-videos는 ai 57·dark 44·minimal 40·light 34·transitions 24·kinetic-type 9·3d 8. interface는 microinteraction 195·minimal 185·clean 160·transitions 106·soft-ui 38·glassmorphism 35.
