# PATH 면접실 두 편 · yuhobuilds 제작기 + LAB 몽골 「면접 도전」

트리거: **실화.** 10-12 공개한 [PATH 실사 면접실](https://synk.im/path/interview/film/rehearsal.html)(요양보호사 면접, 질문 2개, 60~90초, 음성은 기기 안에서 글로 바꿈). 시한은 공개 48시간 안인 10-14다([10-12 트렌드 스캔](../트렌드스캔/2026-10-12.md) 추천 1 = 후보 6 + 후보 3).

## 진짜 한 컷(10-13 직접 재현)

공개 기록([PATH 공개 기록](../../../experiences/path-vr/qa/public-release-20261012/README.md) §소음과 경험 유무 검증)의 합성 음성 시험을 시험용 화면 복사본(`.tmp/path-asr-noise-20261012/flow-video/`, 원본 시험 화면은 그대로)에서 다시 돌려 찍었다.

- 넣은 소리: Microsoft Heami 합성 「저는 직접 돌봄을 해 본 경험이 없습니다.」 + 타이핑 소음(SNR 5dB, 말소리가 소음보다 5dB 큼). 실제 사람 녹음이 아니다.
- 받아 적힌 글(면접 답변, 녹화 로그 `recog`): 「저는 직접 불보물 해 본 경험이 있다고 있습니다.」(같은 소리의 마이크 확인 단계 인식은 「불범을」, 10-12 시험 기록에서는 「브이범을 태풍 경험이 있다고 있습니다」)
- 면접실의 반응: 「애매한 부분 확인」에서 멈추고 「경험이 있다고 있습니다.」 부분만 확인을 물었다 → 「경험이 없습니다.」로 고치고 확인 → 준비 쪽 후속 질문 「현장에 투입되기 전에 무엇을 어떻게 준비하실 겁니까.」로 이어졌다.
- 녹화·캡처: `media/rec-flow.mp4`(1920×1080 녹화에서 면접 화면만 자름), `media/shot-*.png`(2배율 캡처). 면접관 원본: `media/iv-*.mp4`(공개판 4K를 2560으로 줄임, 질문 목소리 포함).

시험 숫자(10-12 기록 `noise-polarity-evaluation.json`): 합성 음성 32번(문장 8개 × 소음 4가지). 판정은 확인 29번(경험 유무 20 · 의미 8 · 세부 1), 자동 진행 3번(모두 구체적인 본인 과거 행동). 「경험 없음」 16번 중 잘못된 후속 질문으로 넘어간 것 0번. 뜻이 뒤집혀 받아 적힌 것은 분명한 1번(위 문장)과, 알아들을 수 없게 깨진 1번.

## ① yuhobuilds 제작기 · 「제가 만든 AI 면접관이 "경험 없어요"를 "경험 있어요"로 받아 적었습니다」

- 누구: AI로 제품을 만드는 1인 창업자·개발자, PATH에 관심 있는 사람. 계정: yuhobuilds 인스타·유튜브(+ LinkedIn 개인).
- 볼 이유: 실패가 먼저 보이는 제작기(다듬지 않은 실패담, 이번 주 작은 채널에서 통한 형식). 얻는 것은 「뜻을 뒤집는 말만 골라 다시 묻는다」는 설계 하나다.
- 행동 하나: synk.im/path에서 직접 면접 연습.

| 시각(어림) | 장면 | 화면 |
|---|---|---|
| 0–3 | 훅: 제가 만든 AI 면접관이 「경험 없어요」를 「경험 있어요」로 받아 적었습니다 | 실제 확인 화면, 「경험이 있다고 있습니다.」 칸에 다가감 |
| 3–8 | 새로 공개한 요양보호사 면접 연습실 | 면접관 원본(질문 목소리) |
| 8–14 | 합성 목소리에 소음 조건(깨끗한 소리 포함 넷)을 바꿔 가며 32번 → 그중 한 문장을 다시 넣으니 거꾸로 | 원래 말 / 받아 적힌 말 두 줄(10-13 재현 기록 그대로) |
| 14–22 | 그래도 면접관은 넘어가지 않았다: 있다·없다처럼 뜻을 뒤집는 말은 그 부분만 다시 묻는다 | 녹화본: 「애매한 부분 확인」 |
| 22–28 | 고치면 준비 계획을 묻는 질문으로 제대로 이어진다 | 녹화본: 정정 → 준비 후속 질문 |
| 28–34 | 「경험 없음」 16번 중 잘못 넘어간 질문 0번(합성 목소리 32번 시험 기준) / 직접 해 보기 synk.im/path + 아직 남은 시험: 진짜 사람 목소리·현장 소음 | 숫자 「0번」, 주소 |

목소리: 우선 자막만(타입캐스트 키는 유호님이 넣어야 함). 원하면 범수(새 나레이션 기본)로 얹는다.

## ② LAB 몽골 · 「60초 한국어 면접, 끝까지 갈 수 있을까?」

- 누구: 한국 취업·요양보호 일을 생각하는 몽골어권 한국어 학습자. 계정: 페이스북 synkworld · 인스타 @synk.mn. 몽골어 자막 + 면접관의 한국어 질문 소리.
- 볼 이유: 실제 면접 질문을 듣고 30초 안에 답해 보는 도전. 얻는 것은 면접 질문 두 개와 꼭 알 낱말 셋(지원하다·경험·준비하다).
- 행동 하나: synk.im/path에서 마이크로 답해 보기(무료·로그인 없음).
- 몽골어 자막: 초안을 `tools/몽골어대조.js`로 1차 점검했다(문법 정상, 역번역 뜻 일치, 맞춤법 1건 секундын → секундийн 고침). 원어민 검수는 사람 몫으로 남는다.

Fable 검수(① P2 2·P3 7, ② P2 2·P3 6, P1 없음)를 반영해 두 편을 다시 렌더했다. 결과: `yuhobuilds/renders/yuhobuilds_AI면접관_거꾸로_v2.mp4`(34초), `lab-mn/renders/LAB몽골_면접도전_v2.mp4`(32초). v1은 비교용으로 둔다.

- ①: 기록 카드 문장을 면접 답변 인식문(「불보물」)으로 맞춤, 「typing · SNR 5dB」, 「깨끗한 소리·소음 세 가지」, 자막 「합성 목소리에 소음 조건을 바꿔 가며 32번」「그중 한 문장을 다시 넣으니」「새로 공개한」(게시일과 무관), 숫자 「16 → 0」을 「0번」 + 「합성 목소리 32번 시험 기준」으로(전후 개선처럼 읽히지 않게, 결과 정지 0.6초), 「아직 남은 시험」 줄을 끝 장면 40px로 옮겨 2.7초, 창 격자 96~944.
