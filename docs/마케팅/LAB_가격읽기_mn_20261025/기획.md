# 가격 읽기 — 12,000원은 「십이천」이 아니라 「만 이천 원」

> 10-25 07시 「고른 기획 제작」 회차. 장부 [LAB.md](../기획장부/LAB.md) 몽골 M5(「고름」 — 숫자 · 가격 읽기 자기 채점). 만드는 순서는 [제작 절차](../기획장부/제작절차.md), 몽골어 규칙은 장부 머리말 「이 브랜드에서만」. 보류한 「시간 읽기」 편의 주제(숫자 읽기)를 여기로 옮겼다([수요 조사 §8](../시청자수요조사_20261022.md)).
