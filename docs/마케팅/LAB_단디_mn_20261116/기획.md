## 사실 확인

- 「단디」는 경상 방언으로 「확실히 · 단단히 · 꼼꼼히」의 뜻이다(매일신문 사투리 해설 등). 표준국어대사전 등재 여부는 확인하지 못했다. 그래서 화면은 「사투리라서 (몽글의) 사전에 없다」로, 캡션은 「사전에서 찾기 어려운 말」로 쓴다.
- 「해래이」는 경상 방언의 다정한 명령형 말끝(-래이)이다. 「해래이」 = 「해라」.
- 「퍼뜩 온나」는 경상 방언으로 「빨리 와(오너라)」다.

v7에서 둘 넘게 같이 짚은 것과 v8에서 고친 것:

- 「사전에 왜 없는지 모르겠다」(G · h) → 빈 쪽 뜻 줄을 «Аялгын үг болохоор толь бичигт байхгүй…»(사투리라서 사전에 없어…)로 바꿨다. 몽골어 교정에서 「аялгын үг」이 감탄사로 읽힐 수 있다고 해 «Нутгийн аялгын үг болохоор…»로 다시 고쳤다(아래 몽골어 세 겹).
- 「해래이 말끝의 뜻을 모르겠다」(G · K) → 귓속말 칸 뜻 줄을 ««Данди» = нямбай / «Хэрэй» = хий»(단디는 꼼꼼히, 해래이는 해)로 낱말마다 풀었다.
- 「작은 발음 글자를 다 못 읽었다」(넷) → 읽기 글자를 48px에서 56px로 키웠다. 「작은 이름표」(G v6 · s v7)는 미학 맹검도 같이 짚어 알약 글자를 40px에서 48px로 키웠다.
- 「서울 · 경상도가 어디인지 모르겠다」(G · h) → 이름표 뜻 줄을 «Сөүлийн аялга (стандарт хэл)»(표준어) · «Кёнсандогийн аялга (Бусан)»으로 바꿨다.

남은 것: haiku 9번 「같아 보임」은 세 판 내내 남았다(v4 끝 질문 → v6 정리 카드 → v7 한 낱말 되풀이). v6과 v7에서 원인을 하나씩 걷었으나 haiku가 매번 다른 곳을 짚었다. 「5~6.5초 「단디 해래이」를 처음엔 몰랐다」는 답은 일부러 둔 반전 자리라 남겼다.

## 몽골어 세 겹

검문 파일은 `게시/검문/`(한국어 / --- / 몽골어)이다.

- **대조기(`node tools/몽골어대조.js`, Gemini):** 화면 글 1~3차 「정상」 → 4 · 5차 「파손」(새 줄의 읽기 «хэрэи»가 몽골 정서법에 없는 꼴 — 우리 표기 규칙대로 «хэрэй»로 고침) → 6 · 7차 「어색」 → 8 · 9차 「정상」. 캡션 1~4차 「정상」. 맞춤법 걸림은 지명과 키릴 읽기(данди · хэрэй · поттык · онна)뿐이다.

### 최종판 두 겹(v8 글 — 11-16 12시)

이해 시험 뒤 새로 쓰거나 고친 화면 글 여섯 줄(이름표 뜻 둘 · 「«Данди» гэж юу вэ?」 · 사전 이유 · 낱말 풀이 · 끝 대사)은 대조기만 거쳤기에, 최종판 전체를 두 겹에 다시 보였다.

- **Fable 5.2 교정:** 꼭 고칠 것 1건 — 7번 «Аялгын үг болохоор»는 몽골 학교 문법에서 「аялга үг」이 감탄사(품사 이름)라 「감탄사라서 사전에 없다」로 읽힐 수 있다 → «Нутгийн аялгын үг болохоор»(지방 말씨라서). 선택 권고 넷 — 8번 «хэрэй» = хий → хий шүү(다정한 당부 말끝), 10번 хийчихлээ → хийчихжээ(결과를 보고 알아차리는 말끝 — 반장님 말에 맞음), 게시글 Тэгү → Дэгү, орчимд очвол их сонсоно → хавьд очвол их сонсогдоно. 아래 「반영」 참고.
- **원문 숨긴 Opus 직역:** 틀린 줄 없음. 7번은 「사투리 말이라서 사전에 없다」로 바로 읽히고 «Нутгийн аялгын үг»로 쓰면 더 분명하다(선택). 8번은 두 풀이를 이으면 «нямбай хий»(꼼꼼히 해)가 되어 잘 짜였다. 6번 «Данди»와 8번 «данди»의 대소문자를 맞추라고 했다. 10번은 꾸중으로 읽히지 않지만, 「-лээ」는 말하는 사람이 직접 겪은 일이라 주어 없이는 몽글의 혼잣말로 먼저 읽힌다 — 반장님 말이면 «-жээ»가 낫다고 했다. 9번 «Нямбай хийсэн шүү!»는 몽글의 뽐냄이면 맞다. 첫 댓글의 «сонсгол, уншлага»는 「청력 · 낭독」으로도 읽혀 조금 어색하다(확신 낮음).
- **반영:** 7번 «Нутгийн аялгын үг болохоор»(두 겹이 같은 꼴을 냄), 8번 대소문자 «Данди» · «Хэрэй», 10번 «Дэндүү нямбай хийчихжээ~»(두 겹 모두 반장님 말이면 -жээ), 게시글 «хавьд очвол их сонсогдоно». 8번 «хий шүү»는 대조기(카본 문법 채점)가 「шүү는 맨 명령형 뒤에 붙지 않는다」고 짚어 넣지 않았다(화면글 10차 「어색」 → 되돌린 11차 「정상」). 게시글 Тэгү → Дэгү는 두 겹의 말이 갈려(Opus는 「Тэгү」가 흔하다고 함) 그대로 두었다. 「Дэндүү」의 칭찬 뜻 겹침은 반장님이 웃으며 엄지를 드는 장면이라 그대로 두었다. 첫 댓글은 LAB 몽골 33편이 같이 쓰는 문구라 이 편만 바꾸지 않았다(아래 남은 것).
- **대조기 마지막:** 화면 글 11차 「정상」, 캡션 5차 「정상」.
