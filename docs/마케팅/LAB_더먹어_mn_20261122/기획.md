- **대조기**(문법 채점 카본 · 직역 · 맞춤법): 1~4차는 구독 통로의 빈 답 · 시간 초과 · 503으로 돌지 않았다. 게시글은 1차 「어색」(직역투) → 5차 「어색」(둘째 문장을 여는 절) → 6차 「정상」이다. 화면 글은 5차 「파손」(✓ 줄의 대상 어구가 빠짐) → 6차 「정상」 → 마지막 글(mn6) 7차 「정상」이다. 맞춤법 층은 5차에서 화면 의심 0, 게시글은 한국어 읽기 «мого» 하나였다. 6 · 7차는 시간당 몫을 넘어 맞춤법을 재지 못했고, 한 시간 뒤 다시 부른 8 · 9차는 구독 통로가 빈 답을 내 돌지 않았다. 그래서 5차 뒤에 바꾼 줄(«гэвэл → нэмж өгнө» · «идэж дууслаа» · «Санаа амарлаа»)은 맞춤법을 재지 않았다.
- **원문 안 본 Opus 직역**(화면 16줄 · 게시글): 받아들인 것 — 6번 «Өө»(놀람으로 읽힘) → «Үгүй ээ», 8번 한국어 어순 «жаахан л ахиад» → «Ахиад жаахан л», 10번 «Сайхан идлээ»(번역투) → «Сайхан хооллолоо», 12번 «Фүү»(외래어 글자) → «Пөөх», 꼬리 «мэндчилгээ»(만남 인사) → 감사의 말.
