### 8-1. 새 제작 기술을 쓰는 기준

기존 자산으로 표현할 수 없는 **실제 장면의 필요**가 있을 때 새 생성·촬영·인터랙션을 검토한다. 이미지·영상 생성은 설치된 해당 스킬과 계정에서 실제 지원되는 공식 통로로 진행한다. 모델이 바뀌어도 승인 마스코트·재질·색·서체를 우선한다. 생성할 수 있다는 이유만으로 새 캐릭터·3D·음악·애니메이션을 한 편에 모두 넣지 않는다. 구독 포함 여부와 신규 지출을 구분한다.

인터랙션은 사용자가 직접 선택해 결과를 바꾸는 조작이다. ‘선택한 역할이 자기 문장에 반영된다’처럼 **참여한 이유가 결과에 보여야** 한다. 버튼 효과만 있는 체험을 개인화라고 부르지 않는다. 계정 없이도 볼 수 있는 카드·저용량 텍스트 등 대안을 먼저 고려하고, 새 웹 체험은 별도 구현·검증 작업으로 남긴다.

## 10. 신선함을 유지하는 제작 방식

### 10-1. 트렌드는 장식 목록이 아니라 시험할 형식의 근거

[TikTok Next 2026](https://ads.tiktok.com/business/library/TikTok_Next_2026_Trend_Report.pdf)의 실제 과정·호기심·선택 이유, [YouTube 2025 창의성 보고서](https://services.google.com/fh/files/misc/trends-25-nextgen.pdf)의 참여 서사·세계관은 실험 아이디어로 참고한다. 플랫폼 자체 자료이며 국가·연령·조사 조건이 섞여 있어 몽골 10대의 취향이나 매출 효과를 증명하지 않는다. YouTube 주요 설문은 미국 표본이다. 빽빽한 편집을 ‘요즘 취향’으로 정당화하지 않는다.

| 시험할 원리 | 우리식 실험 | 신선함이 사라지는 경우 |
|---|---|---|
| 관객의 선택이 내용에 영향을 줌 | LAB 두 역할 중 고르면 말할 문장이 달라짐 | 답은 안 달라지는데 댓글만 요구 |
| 실제 만든 사람의 판단이 보임 | SHIFT 한 결정과 공개 가능한 실물·검증을 연결 | 빠른 도구 화면만 나열하거나 가짜 제작 과정 |
| 익숙한 세계에 새 감정이 있음 | PULSE 같은 장소·소품 속 다른 선택과 곡 | 같은 배경에 음원만 기계적으로 교체 |
| 받은 것을 바로 자기 일에 씀 | LAB 문장 변형 카드, SHIFT 빈 비교/인수 틀 | 연락처를 내도 일반 홍보 PDF만 받음 |
| 문화의 방향이 양쪽임 | 몽골의 내 취향을 한국어로 소개 | 한국에 대한 동경만 모든 학생에게 강요 |

최근 사례를 볼 때 `관찰일·URL·국가/언어/연령·실제 장면·우리와의 관련성·권리·한정 실험·판단일`만 남긴다. 한 번 조회수가 높았다는 이유로 유행을 확정하지 않는다. 유행 소재·도구 기능·학사 정보가 바뀌면 게시 직전 공식 원문을 다시 확인한다. **고유한 재질과 말투는 유지하고, 선택·참여·서사의 방식에 신선함을 준다.**

### 10-2. 다음 제작자에게 건네는 기획서 한 장

다음 12칸은 마케팅 작업의 내용 틀이다. 강제 훅·중앙 큐·자동 차단기를 추가하라는 뜻이 아니다.

1. **브랜드·대상:** 한 사람의 현재 상황. LAB 학생/보호자/성인, SHIFT 구매자 유형을 정확히.
2. **원하는 장면:** 보고 난 뒤 무엇을 해보고 싶거나 결정해야 하는가? 그 내용과 맞는 발견 질문 하나를 내부 기획에 연결하되 공개 문안을 그 질문으로 강제하지 않는다([검색·AI 발견](채널과_발행.md#discovery-with-purpose)).
3. **근거 상태:** 당사자 답 / 실제 관찰 / 공개 조사 / 아직 가설 중 무엇인가? 반증은?
4. **먼저 줄 것:** 등록·댓글·결제 이전에도 남는 한 가지와 그것을 확인할 완성 실물.
5. **현재 약속:** 지금 제공하는 범위와 원천. 계획·예시·실제 운영의 표시.
6. **한 편의 사건:** 시작의 선택 → 직접 해보기/판단 → 남는 결과. 광고 설명만 있으면 사건을 다시 잡음.
7. **채널과 다음 자리:** 이 채널에서 맡는 역할 하나, 끝의 행동 하나, 실제 도착 화면. 본문·자막·자료 설명과 실제 공개 주소/첨부 파일이 같은 제공물을 안내하는지 확인.
8. **자산:** 승인 원본 경로·용도·재사용 부분·새로 필요한 부분. 시각·소리 모두.
9. **문안:** 학생 접점은 브랜드 보이스와 언어 검토, 기관 접점은 원문·확인일·범위. 예시와 실적 구분.
10. **제작·인수:** 원고·출력·사용처·권리·다시 쓰는 법·문의/수정 범위.
11. **확인:** 실제 크기·음소거/실청취·가독성·링크·필수 조건·미성년자 참여 방식.
12. **배운 것:** 관찰한 행동·분모·모르는 것·다음에 바꿀 한 가지. 좋아요나 AI 언급을 효용으로 바꾸지 않음. 기존 고객의 오해·관계없는 문의가 늘었는지도 별도로 확인.

대표 판단 사례는 [참여 요구에서 실제 자료 제공으로](../홍보물/릴10편_20260909/읽어주세요.md#feedback-provision)를 읽는다. 사용자 원문·AI 해석·gift-01의 실제 반영을 구분했다. 새 제공형 작업은 이 사례와 현재 약속을 비교하고, 같은 지적의 재발 여부를 기존 결과 기록에 남긴다. 편수·댓글 방식·제공물을 모든 사업의 영구 규칙으로 확대하지 않는다.

### 10-4. 콘텐츠가 밖으로 나가기 전

실학생 산출물의 공개는 [철학 적용 기준의 학생 실물 공개 기준](../철학_적용기준.md#4-대외-사용과-근거)를 따른다. **비식별, 서면 동의·철회 대장, 학습층과 홍보층의 2층 분리 위 유호 판정 선행**이 필요하다. 동의서 하나나 교사 확인만으로 학습층 원본을 홍보물로 전환하지 않는다. 기본은 공개용 시연이며, 실학생 자료는 해당 게이트를 통과한 범위만 쓴다.

학생 얼굴·음성·기록의 교육 사용과 홍보 사용은 별개의 목적이다. 동의만 받으면 무엇이든 외부 모델에 넣어도 된다고 해석하지 않는다. 합성 시연은 실제 학생·후기가 아니라고 표시한다. 태그·공개 업로드·DM 개방·보호 설정 해제를 참여 조건으로 삼지 않는다. [Instagram Teen Accounts 공식 안내](https://about.fb.com/news/2024/09/instagram-teen-accounts/amp/)처럼 실제 보호 기능과 충돌하지 않는 경로를 설계한다.

입학·비자·취업·자격·보장·가격·일정은 해당 관할/학교/계약의 최신 원문과 실무 확인을 거친다. 법률 자문을 이번 전략이 대신하지 않는다. AI 생성 장면을 실제 수공예·실제 시설·실제 성공 사례처럼 꾸미지 않는다. 없는 고객 질문·후기·협약·마감·대기열을 만들지 않는다. PULSE 감상에는 모든 편의 판매 행동을 강제하지 않는다.

### 10-5. 실물로 확인하고, 자기 일로 가져가게 한다 · 09-09 사용자 요청 반영

설명에 맞는 서비스 영상이나 산출물을 함께 준비하는 방식을 기본으로 한다. 양식만 던져주거나, 준비되지 않은 결과를 예고하는 것으로 끝내지 않는다. 제작 속도 때문에 실물 제공을 생략하지 않는다.

- 교육·서비스 콘텐츠는 **완성 예시 → 고칠 곳과 이유 → 편집 가능한 원본/직접 작성 → 스스로 확인할 기준 → 막혔을 때의 다음 자료**로 연결한다. 영상이 이해를 돕는 곳은 사용법·전후 비교·전체 수행을 보여주는 영상을 붙이고, 문서·표·완성 글이 더 적합한 곳은 그 산출물 자체를 제공한다. 모든 자료를 같은 영상 형식으로 강제하지 않는다.
- LAB은 공개용 학습 시연과 스스로 바꾸는 표현, SHIFT는 실제 써보는 업무 산출물과 적용 과정, PULSE는 완성 작품과 감상 경험, SYNK는 완료된 제작물과 결정의 근거를 보여준다. PULSE 감상에 불필요한 양식·댓글 유도를 붙이지 않는다.
- 명품화는 실물의 읽힘·배치·질감·파일 완결성·도착 화면·사용 뒤 도움까지 적용한다. 보기 좋은 표지만으로 빈 내용이나 동작하지 않는 다운로드를 덮지 않는다.
- **실제 고객 작업 / 회사 자체 제작물 / 가상 교육용 예시 / AI 합성 시연**을 구분한다. 다른 가상 사례가 같은 원리를 설명할 때는 같은 사건·고객의 기록처럼 잇지 않는다. 준비된 예시는 실적·고객 반응·매출 효과를 입증하지 않는다.
- 기존 완성물이 맞으면 연결하고 발전시킨다. 신규 제작분과 재사용분, 확인된 동작과 아직 확인하지 못한 효과는 결과 기록에서 구분한다. 자동 발송·개별 지도·응답 시간을 준비 없이 약속하지 않는다.

## 12. 실행 순서 — 학습 경험의 연결을 기준으로 병렬 준비한다

아래는 착수일부터의 **운영 설계**이며 제작 속도에 따른 착수 제한표가 아니다. 수업·자료실·검색 글·편지·클리닉은 역할이 연결되면 병렬 준비한다. 이번에 게시·인터뷰·서비스 영업을 수행한 일정표는 아니며, 실제 모집·개강·협약·광고 지출·새 계정 개설은 별도로 구분한다. SHIFT의 주력 편성은 [SHIFT 주력 편성](SHIFT.md)과 [공개수업 상세](SHIFT_공개수업.md)을 우선한다.

| 구간 | 우선 실행 | 남는 결과 | 다음 단계 조건 |
|---|---|---|---|
| 첫 1~2주 | 타겟 이해 조사 준비·기존 실물/링크 확인. LAB 핵심 장면 1종과 SHIFT 실제 작업 1건을 시제품으로 | 인터뷰 가설 수정, 기획서·반출물 견본, 쓰는 자산 목록 | 학생/구매자가 무엇을 받는지 실제로 설명할 수 있음. 공개 전 언어·권리·조건 확인 |

**업무 역할:** 주담당은 범위·현재 상태·기획·제작·검증·인수를 통합한다. AI는 공개 자료 조사·초안·편집·기계 검사를 맡을 수 있지만 타겟의 실제 답을 창작하지 않는다. 교사·몽골어 검토자는 실제 언어와 교육 적합성을, 서비스 담당은 조건·권리·응답 범위를, 대표는 새 사업 약속·계약 조건·지출처럼 필요한 결정을 맡는다. 존재하지 않는 직원이나 자동 응답을 담당자로 적지 않는다.

## 실제 적용을 확인하는 방법

기획에 정본을 적었다는 이유로 적용 완료로 세지 않는다. 기존 결과 문서에 **이번에 쓴 현재 승인 원본 / 실제 반영 위치 / 확인한 실물과 배포 범위 / 남은 것**을 남긴다. 파일 지문은 원본과 파생본의 일치를, 화면·재생·다운로드 확인은 고객이 만나는 결과를 증명한다. 브랜드의 품질·타겟의 실제 효용은 별도 판단이다.

기존 승인 사례의 선택 이유와 새 작업의 목적을 비교한다. 도움 제공형 릴의 ‘무엇을 어디서 받는가’, 마스코트 몸짓으로 멀미가 난 숏폼, 홈페이지 최신 사진형 로고의 실제 적용 같은 피드백은 해당 맥락에서 반영하고 모든 장르의 영구 금지로 확대하지 않는다. 원문·AI 해석·적용 범위는 [명품 기준](../명품_기준_v1.md)의 대표 사례에서 찾는다.
