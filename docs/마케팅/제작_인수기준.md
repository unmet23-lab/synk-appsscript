# 콘텐츠 자료의 권리와 현재 상태

> 2026-09-18 · 공개 자료·약속·기존 파일을 확인할 때 필요한 원문 안내.

<a id="8-브랜드-킷과-마케팅-요소--가진-것을-맡은-일에-정확히-쓴다"></a>
## 자산과 제공 범위

로고·서체·마스코트 원본은 [DESIGN](../../DESIGN.md), 회사별 제공 범위는 [마케팅 정본](../마케팅_정본.md), 가격·보장·조건은 [약속과 실행](약속과_실행.md)에서 확인한다.

<a id="10-2-다음-제작자에게-건네는-기획서-한-장"></a>
자료를 제공한다고 안내했다면 공개 주소·첨부 파일에서 안내한 자료를 실제로 받을 수 있어야 한다. 제작 파일의 존재와 게시·서비스 운영 상태는 구분한다.

<a id="10-4-콘텐츠가-밖으로-나가기-전"></a>
## 공개 권리와 학생 정보

실학생 자료의 공개는 [학생 실물 공개 기준](../철학_적용기준.md#4-대외-사용과-근거)에 따른다. 비식별, 서면 동의·철회 대장, 학습층과 홍보층의 분리 및 해당 기준의 판정 범위를 확인한다. 동의서 하나로 학습 원본이나 학생 식별정보를 외부 모델에 전달할 수 있는 것은 아니다.

교육 사용과 홍보 사용은 목적이 다르다. 실제 고객 작업·회사 자체 제작물·교육용 예시·AI 합성 시연을 혼동하지 않도록 표시한다. 사진·음악·납품물의 공개·사용 권리는 해당 계약과 원본에서 확인한다.

입학·비자·취업·가격·일정처럼 바뀌는 조건은 담당 원문으로 확인한다. 실제 고객·후기·협약·성과가 없는 경우 이를 만들어 넣지 않는다.

## 기존 릴을 다시 사용할 때

09-09의 장기 45편 추가 제작은 [도움 제공형 릴 10편](../홍보물/릴10편_20260909/읽어주세요.md)으로 교체된 기록이다. 현재 발행할 편수나 제작 형식은 이번 요청에 따른다.

기존 01·09 시리즈에는 몽글판을 선택한 기록이 있다. 01-5 ‘잘 부탁드려요’와 09-2 ‘주문 도와드릴까요?’는 언어 문제로 제외됐으므로 재사용하려면 수정·언어 확인이 필요하다. 대본 수정과 MP4 반영은 별개이며 실제 파일의 길이·자막·내용을 대조한다.
