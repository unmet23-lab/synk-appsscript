## 1. 왜 이 편인가

- **역할 육성(10-21~ 가설, v2 §6):** 이번 주(10-19~25) yuhobuilds는 자동 DM 말투(10-19) · 첫날 편(10-20) · 트렌디하게(10-22, 권위로 봄) · 멈춘 시간(10-24로 밀림, 권위로 봄)이라 육성·전환이 0편이다. 전환(「AI 직원 매뉴얼」 결과가 훅)으로 이어질 트리거는 이번 48시간에 없어서, 트리거가 있는 이 실화를 육성으로 둔다. 끝에서 바라는 행동은 댓글(「여러분 PC에선 뭐가 제일 많이 쓰던가요?」)과 팔로우.
- **시청자가 얻을 것(0~3초 약속):** 판 아래 표시 「끝에 내 PC에서 찾는 법을 드려요」가 0프레임부터 있고, 3.5초쯤 h2가 말로 약속한다. 끝에서 주는 것: ① 작업 관리자에서 몰래 디스크를 쓰는 프로그램 찾는 법(세부 정보 → 열 선택 → I/O 쓰기 바이트, 메뉴 이름은 이 PC의 Windows 한국어 리소스 `taskmgr.exe.mui`에서 확인) ② 도구를 받은 분은 설치 한 줄을 다시 붙여 넣으면 새 판(README 「설치 한 줄을 다시 실행하면 업데이트입니다」).
- **육성 = 뒷이야기·실수·우리 숫자:** 16배 난 편의 도구를 받은 사람(그 릴스 댓글 46)에게는 직접 알려야 할 소식이고, 처음 보는 사람에게는 「바뀔 때마다 바로 맞추면 좋은 줄 알았다」는 실수담이다.
- **깨달음 하나:** 앱은 로그인할 때만 목록을 읽는다. 그러니 바뀔 때마다 0.15초 안에 28곳으로 옮길 필요가 없었다 — 모아서 옮기고, 로그아웃이 보일 때만 바로 맞추면 된다.
- **재미 장치:** 실패담(내가 나눠 준 도구) + 전후 비교(4,279MB → 94MB) + 반전(29곳 중 진짜는 7곳).
- **정직하게:** 4.3GB는 우리 PC(계정·조직 폴더 29곳, 세션을 여럿 동시에 돌림)에서 바쁠 때 4분 잰 값을 1시간으로 늘린 것이다. 화면에 「제 PC · 폴더 29곳 · 바쁠 때 4분 잰 값」을 둔다. 계정이 둘셋인 분은 훨씬 적었을 것이라 「누구나 4.3GB」로 말하지 않는다.
- **겹침 확인:** 10-17 세션 공유 편은 「계정 바꿔도 세션이 안 사라지게」(도구를 만든 이야기), 이 편은 그 도구가 디스크를 많이 쓴 이유와 고친 셋(뒷이야기). 같은 영상·화면을 다시 쓰지 않는다(그 편 표지만 작은 그림으로 「지난 편」 표시에 쓸 수 있으나 쓰지 않기로 함 — 판 안은 이 편의 실제 코드·기록 줄만). 10-21 「멈춘 시간」 편과 숫자 전후 비교 문법은 같지만 주제가 다르다.
- **공개 확인:** 도구는 10-17부터 공개 저장소(MIT), 고친 판도 origin main `ac13744`까지 공개. 판 안의 기록 줄에서 세션 ID(local_…)·계정 ID·사용자 폴더 경로는 보이지 않게 자른다.
