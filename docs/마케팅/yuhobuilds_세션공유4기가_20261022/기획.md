## 4. 사실 대조

(10-22 판에서 확인한 것 — 이 판의 말 · 화면 · 글은 이 목록 안에서만 쓴다)
- **「한 시간에 4.3GB」** = 10-20 밤 바쁠 때 4분 잰 값을 시간당으로: 쓴 양 4,279MB · CPU 코어 하나의 23.6% · 복사 34,664번 · 상태 파일(340KB) 328번. 측정은 `Win32_Process`의 `WriteTransferCount`·CPU 시간을 0.2초마다. 근거 [현장 노트 윈도우 셸 「세션 공유 미러가 바뀔 때마다 28곳에 복사…」](../../현장노트/윈도우_셸.md), [트랙](../../_ops/트랙.md) 「시스템 효율 점검」.
- 「0.15초 안에 28곳」 = 고치기 전 코드 `const WATCH_DEBOUNCE_MS = 150;`(원본 `d2d7ea0` 39행), 짝 폴더 29곳(지금 계정 + 28).
- 「대화가 한 번 오갈 때마다 통째로 다시 써요」 = 앱은 세션 기록(한 개 약 100KB, 대부분 MCP 도구 목록)을 차례마다 다시 쓰고, 바뀌는 칸은 `lastActivityAt`·`lastTurnEdgeAt` 같은 활동 칸(10-22 이 PC의 세션 기록 한 개를 칸 이름·크기만 읽음: 112,870바이트 중 `remoteMcpServersConfig` 102,332바이트).
- 「앱은 로그인할 때만 목록을 읽는다」 = 같은 항목 「앱은 로그인할 때만 폴더를 읽는다」(v3 설계의 근거).
- 고친 셋 = v3·v3.1: 고쳐 쓴 기록은 5분 모아 마지막 판만(`BATCH_MS` 300000), main.log의 로그인·로그아웃 줄을 보면 바로 전부 맞춤, 로그인 기록 없는 13곳 + 계정을 바꾸며 1~13초만 스친 9곳은 쉬게 → 진짜 짝 7곳. 새 파일·지운 파일은 지금도 바로 옮긴다.
- **「94MB」** = v3.1 설치 뒤 30분 실측(10-20 23:37~00:07): 쓴 양 시간당 94MB · CPU 0.26% · 상태 파일 12번 · 복사 876번. 중간 판 v3(45분): 333MB · 0.93%.
- 「로그아웃이 보이면 바로」 실제 기록 줄 = 2026-10-21 00:10:28.216 KST 「로그아웃 줄을 봄 — 기다리지 않고 바로 전부 맞춤」 → 00:10:28.346 「claude-code-sessions: 7곳 확인, 24개 복사, 0개 삭제」(0.13초 뒤).
- **작업 관리자 메뉴 이름** = `C:\Windows\System32\ko-KR\taskmgr.exe.mui`에 「세부 정보」·「열 선택」·「I/O 쓰기 바이트」가 그대로 있다(10-22 확인). 10-23 같은 파일에서 「작업 끝내기」·「자세히」·「간단히」·「이름」·「PID」·「상태」도 확인(캡션 · 블로그의 끄는 법 · Windows 10 「자세히」 · 열 이름 예). 「I/O 쓰기 바이트」는 그 프로그램이 켜진 뒤 쓴 양의 합이라, 큰 순서로 놓고 빨리 느는 것을 본다. 메뉴 길은 문자열 확인이고 이 PC에서 눌러 본 것은 아니다.
- 설치 한 줄 = README 2번 `irm https://raw.githubusercontent.com/unmet23-lab/claude-session-share/main/install.ps1 | iex`, 다시 붙여 넣으면 「업데이트했습니다.」로 끝난다(README 59·178행).
- 10-23 이 판에서 쓴 말과의 대조: 「실행된 뒤 저장한 양」 = 「켜진 뒤 쓴 양의 합」(「켜다」가 체크하기와 겹쳐 「실행된」으로), 「뒤에서 계속 저장하는」 = 디스크에 쓰기. 「제 피씨에선 … 그랬어요」는 우리 PC가 느렸다거나 작업 관리자로 찾았다고 말하지 않는다(PowerShell로 잼 — 블로그에 적음).

## 6. Fable 사실 검수(10-23 새 대본 · 화면 글)

「고쳐서」(작게 — 화면 글 한 줄). 읽는 말에 근거와 어긋나는 문장은 없다.
- 반영 P1: 막대 둘 아래 「제 PC · 바쁠 때 4분 잰 값을 1시간으로」는 94MB(30분 실측)에 맞지 않는다 → 막대 판 아래 「제 PC · 고치기 전 4분(바쁠 때) · 고친 뒤 30분 잰 값」, 4.3GB 판 안에만 「바쁠 때 4분 잰 값을 1시간으로」.
- 글로 보냄(P2): 1→2번이 「PC가 느렸다」 · 「작업 관리자로 찾았다」처럼 들릴 수 있음(블로그에 PowerShell로 잼), I/O 쓰기 바이트에 네트워크 · 장치 쓰기도 섞이고 정상 쓰기도 있음, Windows 10은 위쪽 탭 · 「자세히」, 4.3GB는 바쁠 때 최고치.
- P3: 메뉴 길은 문자열 확인뿐(눌러 본 기록 없음) · Windows 11 창이 좁으면 왼쪽 목록이 아이콘만 · 처음 누르면 작은 순서일 수 있음(캡션에 「한 번 더 누르기」).
