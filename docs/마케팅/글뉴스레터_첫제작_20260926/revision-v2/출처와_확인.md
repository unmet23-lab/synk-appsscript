- Threads 3편: 각 500자 이하로 작성. X 3편: ASCII 1, 그 밖 2의 보수적 계산으로 각 280 이하. 실제 플랫폼 입력 카운터 검증은 하지 않았다.
- 5채널 9편의 본문·복사용 출력에 내부 편집 메모가 섞이지 않도록 분리했다. Substack 프리헤더도 별도 파일로 제공한다.

- 검토자는 짧은 글·Tistory를 원문과 교차 검토했으며 도구 관계 설명과 시제 두 부분을 수정했다. 담당자는 네이버·Substack의 전체 본문과 예시 정답, 대표 PC·모바일 캡처를 직접 읽고 확인했다.
