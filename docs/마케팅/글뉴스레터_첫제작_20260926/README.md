## 이번 초안의 구성

- 짧은 글은 실제 경험 한 장면에서 시작하고, 독자가 쓸 수 있는 비교 기준으로 끝낸다.
- 네이버 글은 요청문만 던지지 않고 입력 예시, 확인할 결과, 빠졌을 때 다시 묻는 문장까지 제공한다.
- Tistory는 당시 실제 선택과 지금 제안하는 비교 질문을 구분한다. 현재 도구의 가격·우열을 설명하는 글은 아니다.
- 뉴스레터는 LAB과 SHIFT를 별도 제목으로 나누고 각각 짧은 실습으로 끝낸다. 회의 자료는 작동하는 공개 페이지로 직접 연결한다.

이 구성은 첫 검토안이다. 사용자가 확정한 양식이나 모든 글에 의무적으로 적용할 규칙으로 기록하지 않는다.

## 확인한 것과 남은 것

확인: 원문 사실과 초안 대조, 두 번째 검토자의 내용 검토, 이미지 4장 시각 확인과 파일 연결, 네이버·Tistory 복사용 질문, X 본문 길이의 보수적 계산, 공개 자료 페이지·PDF·ZIP의 HTTP 200. 세부 근거는 [출처와 검수](출처와_검수.md)에 있다.

남음: 사용자 원고 피드백, LAB 설명의 몽골어 번역·검수, 발행 직전 ChatGPT 메뉴 재확인, 각 플랫폼 편집기에서 최종 배치 확인. 글·뉴스레터 모두 플랫폼에 저장하거나 게시·발송하지 않았다.

LAB은 기존 결정에 따라 한국어 원본부터 검토한다. 현재 뉴스레터 파일은 몽골어권 독자에게 바로 발송하는 완성본이 아니다. 기존 9월 19일 초안은 보존하며 이번 파일이 사용자 승인 없이 그 원고를 대체하지 않는다.
