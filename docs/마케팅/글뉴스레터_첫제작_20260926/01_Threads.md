# Threads · 출석 앱 하나 만들고 싶었는데

출석 앱 하나 만들고 싶었는데, 모르는 도구 이름이 네 개나 나왔어요.

클로드는 글라이드와 구글 시트, GPT는 슈파베이스와 엔에잇엔을 추천했습니다. 개발을 처음 하는 저는 도구 이름도, 무엇을 비교해야 하는지도 몰랐고요.

결국 “첫 화면을 빨리 볼 수 있다”는 설명이 와닿아서 클로드 쪽을 골랐습니다. 그런데 앱을 만들기도 전에 클로드 코드 설정에서 또 막혔어요. 제 기억엔 처음 켜는 데만 한 시간쯤 걸렸습니다. 출석은 아직 한 번도 안 찍었는데요. 😂

지금 다시 고른다면 두 방법을 다른 AI에도 함께 보여주고, 제 예산과 경험을 적은 뒤 비용·난이도·관리하기 쉬운지부터 비교해 볼 거예요.

답이 하나 더 생긴다고 정답이 되는 건 아니지만, 적어도 무엇을 따져야 할지는 물어볼 수 있으니까요. 마지막 선택은 제가 쓸 돈과 시간에 맞춰서요.
