# synkbrief 회의 메모 편

한국어 초보자가 ChatGPT에서 회의 메모를 할 일 표로 정리하도록 단계와 이유를 설명하는 영상이다. 사용자는 결과만 보여주는 v3를 거절했다. 실제 프로그램·입력·실행·확인·업무 활용과 실물 제공 자료가 필요하다.

이번 출력은 1080×1920 전체 무음 검토본이다. 원문에 없는 담당자와 기한을 확인 필요로 남기고 제안과 확정 업무를 구분한다. 현재 실제 ChatGPT 캡처와 가상 메모·응답, 준비된 PDF·TXT 파일을 사용한다. 편집 그래픽은 실제 UI와 구분한다. 대표작 승인이나 발행 완료를 주장하지 않는다.

Platform: web composition rendered to video.
Stack: HyperFrames 0.8.60, GSAP, Impeccable review. Visual authority: repository DESIGN.md and current design tokens.
