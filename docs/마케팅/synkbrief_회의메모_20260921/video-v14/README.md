## 이번 변경

프로젝트 개념에 앞서 실제 ChatGPT 전체 화면에서 왼쪽 ‘프로젝트’ 메뉴를 확대해 보여준다. 다음 회의 장면은 ‘프로젝트’ 메뉴 → 목록의 ‘회의 정리’ → 프로젝트 이름 아래 ‘새 채팅’ 입력창 → 이번 회의 메모 입력과 ↑ 보내기로 나눴다. 각 클릭 위치를 전체 화면에서 확대하고 화살표·라벨을 붙였다. 일반 사용자의 프로젝트가 ‘고정됨’에 있다고 가정하지 않는다. 이전 채팅을 다시 열 필요가 없다는 설명도 포함했다.

메뉴와 입력창의 기본 배경은 2026-09-23에 확인한 ChatGPT 화면이다. 다음 회의 예시의 프로젝트 목록 한 줄과 지난 채팅 두 줄은 개인 정보를 노출하지 않도록 같은 위치에 재현한 예시다. 영상 안에도 해당 사실을 표시했다. 보이스는 기존 은경 음성을 보존하고, 새 세 장면에만 같은 설정으로 Typecast 음성을 합성했다. 키는 파일에 저장하지 않았고 작업 뒤 로컬 연결을 해제했다.

기존 10쪽 가이드 뒤에 큰 글씨의 다음 회의 4단계 페이지를 추가해 총 11쪽으로 만들었다. 복사용 문장·프로젝트 지침·가상 메모·전후 예시는 ZIP에 담았다. 바탕화면의 최신 세 파일은 SHA-256으로 복사 일치를 확인했고, 이전 파일은 버전 이름으로 보관했다.

## 확인

HyperFrames check 통과, 오류 0. 53개 음성 자막이 해당 장면 안에 표시되고 잘리지 않는지 확인했다. 11개 카메라 장면의 타깃·커서 위치를 검사했다. 최종 MP4 전체 디코드 통과, 검은 화면 탐지 없음. 음량은 -17.05 LUFS / -2.69 dBTP. PC 1280px와 모바일 390px 미리보기에서 재생, 장면 이동, 소리 토글, PDF·ZIP·MP4 다운로드를 확인했다. 마지막 PDF 페이지와 영상의 ‘11쪽 PDF’ 표기도 시각적으로 확인했다. 검사 기록은 `verification/`에 있다.

이 파일은 게시 전 검토본이다. 실제 청취에 의한 최종 음색 승인과 SNS 게시, 댓글 자료 자동 전달은 아직 완료하지 않았다.

## 재제작

기존 음성을 유지하는 수정은 `npm run build` → HyperFrames render → `node build-preview.mjs` 순서다. 새 음성의 원본과 단어 시각은 `audio/repeat-find`, `audio/repeat-new`, `audio/repeat-send`에 보관했다. `assemble-voice-v14.py`는 v13의 다른 장면 음성을 유지하면서 이 세 구간만 조립한다. `prepare-voice.cjs`는 이전 v12용이라 이 버전에서 실행하면 안 된다.
