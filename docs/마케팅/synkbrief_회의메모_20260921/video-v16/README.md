## 이번 수정

프로젝트 이름 입력란 등 ChatGPT 클릭 안내의 굵은 중복 테두리를 얇은 단일 초점선으로 교체했다. 서로 다른 버튼으로 이동할 때 테두리를 잡아 늘리지 않고 각 위치에 맞는 선이 자연스럽게 나타난다. 클릭 반응은 잠깐 밝아지는 방식으로 통일하고, 작은 메뉴는 확대 배율을 제한해 글자가 덜 거칠게 보이도록 했다. 프로젝트 이름을 넣은 다음 누를 ‘프로젝트 만들기’ 버튼도 별도로 지목한다.

장면 상단의 반복 안내는 `전체 화면 → 위치 확대 → 누르기·입력`으로 줄였다. 같은 뜻의 보조 문구는 덜어내고 몇몇 제목도 더 짧게 바꿨다. 시연을 위해 재현한 프로젝트 목록과 지난 대화 목록은 예시 화면임을 남겼다. 내레이션의 내용과 실제 따라 할 순서, 가이드 자료는 그대로다.

## 확인과 상태

HyperFrames 검사, 클릭 위치·장면·음성 자막 검사, MP4 전체 디코드, PC·모바일 미리보기 재생과 다운로드 결과를 `verification/`에 기록한다. 이 영상과 자료는 게시 전 검토본이며 사용자 최종 승인이나 외부 게시는 아직 아니다.

## 재제작

`refine-v16.mjs`는 v15 장면 데이터를 v16 문구와 클릭 위치 표시로 다듬는다. `npm run build`로 화면과 음원 믹스를 조립하고, `npx hyperframes render --quality delivery --output synkbrief-meeting-v16.mp4`로 영상 출력 후 WebM과 미리보기를 갱신한다. Typecast 음성을 새로 합성하지 않는다.
