8개 ChatGPT 조작 장면에 전체 화면 → 위치 표시 → 확대 → 클릭·붙여넣기 → 전체 화면 확인의 카메라 이동을 적용했다. 입력창, 부탁 문장, 회의 기록 단락, 보내기 버튼, 프로젝트 생성, 프로젝트 설정, 지침 입력·저장, 다음 회의 입력이다.

같은 캡처와 테두리·커서를 한 좌표계에서 움직인다. 클릭 때 버튼에 반응을 주고, 붙여넣을 때 실제 캡처의 글을 드러낸다. 클릭·붙여넣기 동작은 교육용 재현이라고 화면에 표시했다. 프로젝트 이름 입력 후 만들기 버튼으로, 지침 입력 후 저장 버튼으로 커서가 이동한다. 메뉴 열린 화면은 실제 전후 캡처를 사용했다.

`content.json`의 camera 설정, `camera-motion.js`와 그 내용이 들어간 `motion.js`, `style.css`가 편집 원본이다. `verify-camera.cjs`가 8장면의 전체·확대·다음 조작·복귀 상태를 검사한다. 원래 v9 가이드의 입력 내용과 사용 순서는 같으므로 PDF·ZIP은 그대로 연결한다.

HyperFrames 0.8.62 → 0.8.64 갱신 후 check 통과. keyframes 정적 CLI는 반복문에서 생성한 선택자를 __unresolved__로 보고하여 해당 --shot을 만들지 못했다. 실제 브라우저의 등록 GSAP 타임라인을 각 시점으로 이동해 캡처와 타깃 영역·카메라 변환을 별도로 검증했다. 검증 근거는 verification/camera-qa.json과 camera-*.png에 있다.

v9와 이전 원본 보존. BGM·효과음 유지, 내레이션 생성·외부 발행·사용자 최종 품질 승인은 아직 하지 않았다.
