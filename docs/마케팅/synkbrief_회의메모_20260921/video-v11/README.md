# synkbrief 01 · v11 프로젝트 개념부터 이해하기

2026-09-23 · 112초·18장면 · 내레이션 전.

62–69초에 프로젝트를 업무별 작업 공간으로 정의하고 ‘회의 전용 폴더’에 비유한다. 폴더 안으로 대화·자료·지침 카드가 차례로 들어오며 각각의 예를 보여준다. 69–75초에는 한 번 저장한 정리 규칙에서 오늘 회의 채팅과 다음 회의 채팅으로 연결선을 그린다. 개념과 사용 이유를 이해한 뒤 기존 프로젝트 만들기 실습으로 이어진다.

PDF 5쪽도 같은 설명으로 바꾸고 채팅과 프로젝트의 차이, 프로젝트를 쓰는 이유를 추가했다. 자료 업로드는 선택 사항이다. 복사용 파일의 내용은 기존 실제 시연 버전과 같다. [확인한 공식 자료와 적용 위치](research-and-review.md).

v10의 8개 조작 장면, 전체 화면 → 위치 표시 → 확대 → 클릭·입력 → 복귀를 유지했다. 캡처 위 클릭·붙여넣기는 교육용 재현으로 표시한다. 원본과 이전 버전은 보존한다.

기존 Suno BGM을 유지하고 늘어난 끝부분에는 같은 음원의 시작 부분을 2초 겹쳐 연결했다. 마지막 3초는 서서히 줄인다. 효과음은 장면 시점에 맞춰 이동했다. 내레이션 생성·외부 발행·최종 사용자 승인은 아직 하지 않았다.

편집 원본은 content.json, style.css, motion.js, build.mjs다. `node build.mjs` 후 HyperFrames로 렌더하고 `node build-preview.mjs`로 미리보기와 자막을 만든다. PDF는 build-guide.py로 생성한다.
