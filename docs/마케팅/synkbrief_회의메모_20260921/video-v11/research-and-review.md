# v11 프로젝트 개념 설명 근거

확인일: 2026-09-23. 클릭 방법에 앞서 기능의 뜻과 쓰는 이유를 알려 달라는 사용자 요청 반영.

- [OpenAI Projects 안내](https://help.openai.com/en/articles/10169521-projects-in-chatgpt): 관련 채팅·파일·지침을 한곳에 모으는 작업 공간. 프로젝트별 지침은 해당 프로젝트에 적용. 영상 62–75초와 PDF 5쪽에 사용.
- [OpenAI 웹 사용 안내](https://learn.chatgpt.com/docs/web): 같은 일의 대화·파일·지침을 프로젝트로 모으는 개념 확인.

‘회의 전용 폴더’는 초보자를 위한 비유다. 실제 파일 폴더와 같다는 의미가 아니다. 자료 업로드는 선택 사항이며, 규칙을 저장했다고 모든 응답의 형식이 보장된다고 설명하지 않는다. 기존 원문 대조·누락 보완 안내를 유지했다.

실제 입력·응답·UI 근거는 [v9 실제 시연 검토](../video-v9/research-and-review.md)를 유지한다. v11에서는 새로운 계정 설정이나 외부 게시를 하지 않았다.
