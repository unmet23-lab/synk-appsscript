# synkbrief 01 · 회의 메모를 할 일 표로

2026-09-21 · 사용자 선택 주제. YouTube·Instagram·TikTok `@synkbrief` 공용 세로 영상 1편.

## 영상의 한 가지 효용

회의 메모를 붙여넣고 할 일·담당자·기한·근거를 추출한다. 없는 정보는 `확인 필요`로 남기고, 제안과 확정된 일을 분리한다.

## 48초 구성

| 시간 | 화면과 큰 글자 | 설명 원고 |
|---|---|---|
| 0–4초 | 회의록은 있는데, / 누가 뭘 하죠? | 회의 메모에서 누가 무엇을 할지 바로 찾아볼게요. |
| 4–10초 | 메모를 붙여넣으세요 · 가상 예시 | 문구 수정은 지수가 맡았고, 설문 초안은 민호가 맡았어요. 그런데 설문 마감은 아직 없네요. |
| 10–17초 | 할 일 / 담당자 / 기한 / 근거 | ChatGPT에 이 네 칸으로 표를 만들어 달라고 요청하세요. |
| 17–25초 | 없는 정보는 / 확인 필요로 | 메모에 없는 정보는 추측하지 말고, 제안만 나온 내용은 따로 분리해 달라고 덧붙입니다. |
| 25–33초 | 실제 응답 · 표의 앞 3열 확대 | 지수의 기한은 9월 23일. 민호의 기한은 확인 필요로 남았어요. |
| 33–42초 | 확인할 건 / 빈칸입니다 | 설문 마감일을 물어보고, 인터뷰를 할지도 정하면 돼요. 근거 문장을 원문과 한 번 더 맞춰보세요. |
| 42–48초 | 메모를 붙여넣고 / 이 문장부터. | 입력문 전체를 게시글에 남겨둘게요. 자신의 회의 메모로 바꿔 써보세요. |

설명 원고는 후속 음성 작업용이다. 이번 MP4에는 음성·BGM을 넣지 않았으며, 위 문장이 실제 내레이션으로 녹음됐다는 뜻은 아니다.

## 실제 시연과 결과

- 서비스: ChatGPT 웹 일반 Chat의 임시 채팅. 새로 작성한 가상 예시만 사용했다.
- 입력 원본: [prompt.txt](prompt.txt).
- 화면: [입력](assets/demo-input.png), [응답](assets/demo-result.png).
- 응답 텍스트: [demo-response.txt](demo-response.txt).
- 지수 / 소개 페이지 문구 수정 / 9월 23일: 원문 일치.
- 민호 / 설문 초안 작성 / 확인 필요: 원문에 기한 없음.
- 고객 인터뷰: 확정 표에서 빠지고 확인할 질문으로 분리됨.
- 다음 회의 9월 25일 오후 2시: 작업 기한으로 사용하지 않음.
- 인터뷰를 진행하기로 한다면 기한도 별도로 확인해야 한다. 실제 응답에 이 질문은 없으므로 응답을 완전한 점검표라고 소개하지 않는다.

결과 한 번의 확인이며, 같은 문장을 입력하면 항상 같은 답이 나온다는 보장은 하지 않는다. 실제 UI 캡처를 부분 확대하고, 화면 밖의 설명 글자는 편집 자막으로 구분한다.

## 복사용 입력문

```text
아래 회의 메모에서 확정된 할 일을 표로 정리해줘.
열은 할 일 / 담당자 / 기한 / 근거 문장.
메모에 없는 담당자나 기한은 추측하지 말고 "확인 필요"로 써줘.
제안만 나온 내용은 확정된 할 일에 넣지 말고, 마지막에 확인할 질문으로 따로 정리해줘.
다음 회의 날짜를 작업 기한으로 사용하지 마.

[여기에 회의 메모 붙여넣기]
```

## 참고

[OpenAI 공식 프롬프팅 안내](https://learn.chatgpt.com/docs/prompting#make-the-result-ready-to-use)는 결과의 용도·형식을 지정하고 담당자·기한·확인 불가 정보 등을 점검하도록 설명한다. 이 자료는 일반 방법의 근거이며, 본편의 결과 근거는 위 실제 시연이다.

제작 범위: 영상 원본 1편, 공통 표지, 플랫폼별 게시 문안 3종. 실제 SNS 게시·예약은 하지 않는다. 최종 음색 선택은 기존 목소리 비교 작업과 별도다.
