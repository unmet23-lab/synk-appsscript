# v9 이해·전후 비교 검토 · 2026-09-23

## 사용자가 요청한 수정

- 도착점은 할 일 표 하나가 아니라 읽기 쉬운 회의록. 할 일은 그중 한 항목이다.
- 원본 메모를 미리 정돈하도록 요구하지 않는다. 정리는 AI에게 맡기고 이름·날짜·미정 내용 확인은 결과 뒤에 한다.
- first-use.txt, practice-1.txt 등의 내부 파일명을 영상에서 없앴다. 입력할 문장을 바로 보여주고 배포 파일도 역할이 드러나는 한국어 이름을 쓴다.
- 입력창과 보내기·지침 칸을 실제 화면에 테두리·화살표·커서로 지목한다.
- 46–56초에 같은 기록의 정리 전 → 부탁할 문장 → 정리 후를 한 화면에 연결한다. 파랑은 결정·업무, 노랑은 미정 내용이다. 표시된 원문·응답은 핵심만 줄인 편집 설명이며 전체는 키트에 제공한다.
- 직접 쓴 메모와 녹음을 글로 옮긴 내용을 모두 설명한다. 모든 음성 파일을 웹 ChatGPT에 바로 올릴 수 있다는 안내는 하지 않는다.

## 실제 시연

새로운 가상 메모와 짧은 요청문을 임시 채팅에 전송해 네 항목 회의록을 얻었다. assets/current/actual-response.txt가 실제 응답이다. 지수의 9월 23일 마감과 민호의 마감 미정, 고객 인터뷰 미정이 분리됐다. 전후 비교는 이 응답에서 만들었다.

기존 실습 프로젝트의 지침도 새 회의록 형식으로 변경했다. 저장 후 페이지를 새로 불러오고 설정에 재진입하여 내용이 유지되는 것을 확인했다. 계정 전체 맞춤 지침은 수정하지 않았다. assets/project/06-instructions.png는 새 지침을 입력한 실제 화면이다.
