원본 기록을 미리 다듬지 않고 AI에게 맡긴다. 입력창을 직접 표시하고, AI에게 보낼 문장을 화면에 바로 보여준다. 영어 파일명과 모호한 ‘이 칸’ 설명을 없앴다. 직접 쓴 메모와 녹음을 글로 옮긴 내용에 같은 경로를 사용한다.

46–56초에는 같은 메모의 정리 전·부탁할 문장·정리 후를 함께 보여준다. 결과는 핵심 요약·결정된 내용·할 일·확인할 내용으로 나뉜다. 파랑과 노랑으로 원문의 내용이 어디로 정리되는지 연결했다. 비교 장면은 실제 응답의 핵심만 줄인 편집이며, 전체 원문과 응답은 배포 자료에 포함한다.

프로젝트 지침을 새 회의록 형식으로 실제 변경하고 새로고침·설정 재진입으로 저장 확인했다. 첫 반복 시험에서 과거 표 형식이 나왔으며 가이드의 보완 문장으로 네 항목을 다시 받았다. 저장만으로 완벽한 응답을 보장하지 않는다.
