# 메모가 정리되는 순간

저장소 DESIGN.md의 흰색·검정·펠트 재질과 실제 서체를 유지한다. 이 파일은 이번 영상의 구도·크기를 정하며 저장소 전체의 디자인 원문을 바꾸지 않는다.

중요한 글자는 76~114px, 표는 42~50px. 양옆 76px와 SNS 조작 영역의 하단 여유를 확보한다. 큰 제목, 손으로 만질 듯한 회의 장면, 메모에서 표로 이동하는 내용이 주인공이다. 의미 없는 장식·동일한 카드 반복·정지 화면의 긴 유지를 피한다.

실제 응답을 편집한 표를 쓰고, 생성 이미지는 회의 후의 상황을 보여준다. 본문 시각화는 선명한 검정 글자·청금석 강조를 쓰며, 미정 기한은 짙은 황갈색 글자와 밝은 노란 면으로 구분한다. 생성 장면의 재질은 텍스트에 덮지 않는다.
