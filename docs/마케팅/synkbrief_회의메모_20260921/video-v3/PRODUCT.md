# synkbrief 회의 메모 편

기존 대화와 채널 원문에 있는 사실을 이번 제작 범위로 연결한다.

- 시청자: AI를 자기 작업에 쓰려는 한국어 사용자. 초보자도 이해할 수 있어야 한다.
- 작업: 회의 메모에서 확정된 할 일·담당자·기한을 정리하고 빠진 정보는 확인한다.
- 실제 근거: 이전 편의 가상 메모를 ChatGPT에 넣어 얻은 보존 응답과 2026-09-22 확인한 공식 자료.
- 현재 산출물: 15초 도입·결과 시각화 검토 샘플. 완결된 사용법 전체나 게시 완료 콘텐츠가 아니다.
- 성공 기준: 처음 보는 사람이 상황과 결과를 빠르게 이해하고 기한 미정의 의미를 알아볼 수 있다. 확정된 대표 디자인은 아직 없다.
- 제작: HyperFrames의 HTML·GSAP, Impeccable의 그래픽 검토 지침. 기존 승인 브랜드 자산과 사용자 피드백을 우선한다.

## Platform
web로 구성해 1080×1920 영상으로 렌더한다.

## Stack
사용자가 적용을 허용한 HyperFrames + Impeccable. 실제 영상 제작에 맞춰 그래픽·타이밍을 설계한다.
