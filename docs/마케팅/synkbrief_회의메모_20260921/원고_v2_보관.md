# synkbrief 01 · 회의 메모를 할 일 표로

2026-09-22 수정 · 사용자 선택 주제. YouTube·Instagram·TikTok `@synkbrief` 공용 세로 영상 1편.

## 영상의 한 가지 효용

회의가 끝난 뒤 메모를 다시 읽으며 누가 무엇을 언제까지 하기로 했는지 찾는 사람을 위한 영상이다. 메모를 할 일·담당자·기한·근거가 있는 표로 정리하고, 정해지지 않은 기한은 참여자에게 물어볼 수 있게 한다.

## 98초 구성

처음 보는 사람이 입력 위치와 다음 행동을 알아볼 수 있도록 11컷으로 구성한다. 아래는 후속 음성 작업용 설명 원고이며, 각 컷의 시간은 98초 렌더 타임라인 기준이다. 시연 장면에는 `가상 회의 메모` 표시를 둔다. 현재 영상은 실제 화면 캡처를 편집한 무음 자막형이며 연속 화면 녹화는 아니다. 영상의 실제 자막과 화면 배치는 `video-v2/scenes.json` 및 `render.cjs`를 따른다.

| 시간·컷 | 화면에서 보여줄 것 | 설명 원고 |
|---|---|---|
| 0–7초 · 1 · 내 상황 알아보기 | 회의 메모에서 이름과 날짜를 다시 찾는 장면. 큰 글자 `회의는 끝났는데… / 누가, 뭘, 언제까지?` | 회의는 끝났는데, 누가 언제까지 뭘 하기로 했는지 다시 찾고 계신가요? |
| 7–13초 · 2 · 얻을 결과 먼저 보기 | 완성된 표의 앞 3열을 확대. `문구 수정 / 지수 / 9월 23일`, `설문 초안 / 민호 / 확인 필요`. | 이렇게 할 일과 담당자, 기한을 한눈에 보는 표로 정리해볼게요. |
| 13–19초 · 3 · 준비하기 | 텍스트로 된 메모와 ChatGPT 새 채팅을 나란히 보여준다. 큰 글자 `회의 메모 + ChatGPT`. | 글로 적어둔 회의 메모를 준비하고, ChatGPT에서 새 채팅을 여세요. |
| 19–29초 · 4 · 입력문 먼저 붙이기 | 게시글의 복사용 입력문에서 다섯 줄과 맨 아래 메모 자리를 함께 선택. 이어서 ChatGPT의 메시지 입력창에 붙여넣은 상태. | 게시글의 복사용 입력문을 전부 복사해, ChatGPT의 메시지 입력창에 붙여넣으세요. |
| 29–39초 · 5 · 내 메모로 바꾸기 | 같은 입력창 안에서 `[여기에 회의 메모 붙여넣기]`만 선택하고 실제 예시 메모로 교체. 위의 요청문은 그대로 남아 있는 모습을 보여준다. | 맨 아래 ‘여기에 회의 메모 붙여넣기’라는 부분을 지우고, 그 자리에 내 메모를 넣습니다. |
| 39–47초 · 6 · 네 칸을 요청하는 이유 | 입력문의 `열은 할 일 / 담당자 / 기한 / 근거 문장`을 확대. 마지막 칸에는 원문 문장을 확인할 수 있음을 보여준다. | 요청한 건 네 칸이에요. 할 일, 담당자, 기한, 그리고 어디에서 가져왔는지 확인할 근거 문장입니다. |
| 47–57초 · 7 · 조건을 확인하고 보내기 | `추측하지 말고 "확인 필요"` 문장을 강조. 요청문과 메모가 한 입력창에 들어간 전체 상태를 짚은 뒤 보내기 버튼을 누른다. | 없는 정보는 ‘확인 필요’로 남기라는 조건도 있어요. 요청문과 메모를 함께 넣었으면 보내기를 누릅니다. |
| 57–69초 · 8 · 두 결과 비교하기 | 실제 응답에서 지수 행을 먼저 확대하고, 다음으로 민호 행의 `확인 필요`를 확대. 각 행에 해당하는 원문을 함께 보여준다. | 지수는 23일까지 문구를 고치기로 했죠. 그대로 나왔어요. 민호는 설문을 맡았지만 마감은 정하지 않았어요. 그래서 ‘확인 필요’입니다. |
| 69–76초 · 9 · 회의 날짜와 마감 구분하기 | 메모의 `다음 회의는 9월 25일 오후 2시`와 민호의 `확인 필요`를 나란히 보여준다. 큰 글자 `다음 회의 날짜 ≠ 작업 마감`. | 다음 회의는 25일이에요. 하지만 그날까지 일을 끝내기로 한 건 아니니, 기한으로 넣으면 안 됩니다. |
| 76–83초 · 10 · 제안은 먼저 확인하기 | 메모의 `고객 인터뷰는 해보자는 의견`과 실제 응답의 진행 여부 질문을 비교. 큰 글자 `인터뷰는 아직 제안`. | 고객 인터뷰는 해보자는 의견만 나왔어요. 확정된 할 일에서 빼고, 진행할지 묻는 질문으로 따로 나왔습니다. |
| 83–98초 · 11 · 확인하고 질문하기 | 표의 근거 문장과 원래 메모를 대조한 뒤, 편집 예시로 `민호님, 설문 초안은 언제까지 가능할까요?`를 보여준다. 마지막에는 `복사용 입력문은 게시글에` 안내. 질문 전송은 하지 않는다. | 근거 문장을 원문과 대조한 뒤, 빠진 기한은 물어보세요. ‘민호님, 설문 초안은 언제까지 가능할까요?’ 복사용 입력문은 게시글에 있어요. 내 메모로 바꿔 써보세요. |

입력 순서는 **복사용 입력문 전체 붙여넣기 → 맨 아래 표시된 자리만 내 메모로 교체 → 같은 입력창에서 한 번에 보내기**다. 첫 문장인 `아래 회의 메모에서`와 메모 위치가 일치한다.

이번 버전은 자막형 검토본으로 준비한다. 설명 원고는 후속 음성 작업에도 사용할 수 있지만, 목소리는 확정되지 않았고 음성·BGM 생성이나 녹음은 하지 않는다. 공개 게시·예약도 하지 않는다.

## 실제 시연과 결과

- 서비스: ChatGPT 웹 일반 Chat의 임시 채팅. 새로 작성한 가상 예시만 사용했다.
- 현재 시연 입력: [prompt-v2-demo.txt](prompt-v2-demo.txt).
- 현재 시연 화면: [입력](assets/v2/03-filled.png), [응답](assets/v2/05-result-desktop.png).
- 현재 결과 설명의 근거: [demo-response-v2.txt](demo-response-v2.txt).
- 지수 / 소개 페이지 문구 수정 / 9월 23일: 원문 일치.
- 민호 / 설문 초안 작성 / 확인 필요: 원문에 기한 없음.
- 고객 인터뷰: 확정 표에서 빠지고 확인할 질문으로 분리됨.
- 다음 회의 9월 25일 오후 2시: 작업 기한으로 사용하지 않음.
- 인터뷰를 진행하기로 한다면 기한도 별도로 확인해야 한다. 실제 응답에 이 질문은 없으므로 응답을 완전한 점검표라고 소개하지 않는다.

2026-09-22 새 임시 채팅에서 위 입력문과 가상 메모를 함께 전송하고 같은 결과를 확인했다. 확인 질문의 표시 순서는 인터뷰 진행 여부 → 인터뷰 담당자 → 설문 마감이다.

결과 한 번의 확인이며, 같은 문장을 입력하면 항상 같은 답이 나온다는 보장은 하지 않는다. 실제 UI 캡처를 부분 확대하고, 화면 밖의 설명 글자는 편집 자막으로 구분한다. 마지막의 민호에게 묻는 문장은 시청자가 활용할 후속 질문 예시이며, 실제 AI 응답이나 이미 전송한 메시지로 표시하지 않는다.

## 복사용 입력문

아래 블록 전체를 ChatGPT 새 채팅의 입력창에 붙여넣는다. 맨 아래 `[여기에 회의 메모 붙여넣기]`만 자신의 메모로 교체하고, 요청문과 메모를 한 번에 보낸다.

```text
아래 회의 메모에서 확정된 할 일을 표로 정리해줘.
열은 할 일 / 담당자 / 기한 / 근거 문장.
메모에 없는 담당자나 기한은 추측하지 말고 "확인 필요"로 써줘.
제안만 나온 내용은 확정된 할 일에 넣지 말고, 마지막에 확인할 질문으로 따로 정리해줘.
다음 회의 날짜를 작업 기한으로 사용하지 마.

[여기에 회의 메모 붙여넣기]
```
