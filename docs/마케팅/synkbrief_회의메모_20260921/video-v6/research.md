# 프로젝트별 회의 지침 · 2026-09-23 확인

## 선택한 방법

ChatGPT 프로젝트에 회의 정리 전용 지침을 한 번 저장하고, 같은 프로젝트에서 회의마다 새 채팅을 연다. 이번 사용 목적과 초보자 따라 하기 난이도를 기준으로 선택했다. 모든 사용자·업무에서 절대적으로 가장 효율적인 기능이라는 주장은 하지 않는다.

| 방법 | 조사 결과와 이번 선택 |
|---|---|
| 프로젝트 지침 | 관련 대화와 자료를 모으고 그 프로젝트의 채팅에서 지침을 재사용한다. 이번 목적에 맞는다. |
| 계정 전체 맞춤 지침 | 일반적인 다른 대화에도 적용된다. 회의 전용 형식·조건을 넣으면 다른 목적의 답변에 영향을 줄 수 있어 이번 지침은 넣지 않는다. 공통 선호를 쓰는 기능 자체를 금지하는 뜻은 아니다. |
| 한 채팅에 계속 회의 추가 | 한 회의의 보완에는 적합하지만 새 회의는 구분해 기록한다. 새 채팅도 같은 프로젝트 내 다른 채팅을 참고할 수 있으므로 이번 메모만 사용하라는 지침과 원문 검토를 병행한다. |
| 커스텀 GPT 새로 만들기 | 현재 공식 도움말은 개인 Free·Go·Plus·Pro 계정에서 새 GPT 생성·게시를 지원하지 않는다고 안내한다. 이번 초보자 신규 설정 경로로 채택하지 않았다. |
| Work + 스킬 | 반복 업무 배포·도구 실행에는 다른 활용 여지가 있지만, 이번 짧은 텍스트 회의 정리에는 설정 단계가 늘어난다. 실제 프로젝트 전용 메모리 화면은 Work 사용 불가라고 표시한다. Work 자체가 사라졌다고 주장하지 않는다. |

## 공식 자료와 반영 위치

- [Projects in ChatGPT](https://help.openai.com/en/articles/10169521-projects-in-chatgpt): 프로젝트 ⋯ → 프로젝트 설정 → 지침, 프로젝트 안의 적용 범위, 프로젝트 전용 메모리 설명. 영상 project/settings/save/next, PDF 1·3·4·7쪽.
- [프로젝트 사용 안내](https://learn.chatgpt.com/docs/projects): 프로젝트 구성과 반복 사용, 고정·다시 열기. 영상 pin/next, PDF 7쪽.
- [Custom Instructions](https://help.openai.com/en/articles/8096356-custom-instructions-for-chatgpt): 계정 전체 지침이 다른 채팅에도 적용되는 범위. 영상 global, PDF 2쪽. 여행 질문에 불필요한 표가 나오는 예시는 적용 범위를 설명하기 위한 가상 상황이며 실제 관찰한 응답이 아니다.
- [Sharing and publishing GPTs](https://help.openai.com/en/articles/8798878-sharing-and-publishing-gpts): 개인 계정 신규 GPT 생성·게시 제한. 방법 선택에 반영하고 본편의 실습 경로에는 넣지 않았다.

## 실제 시연 기록

개인 비공개 프로젝트 `회의 정리 · synkbrief 실습`을 새로 만들었다. 프로젝트 전용 메모리를 선택하고 제공된 project-instructions.txt와 동일한 지침을 저장했다. 설정을 다시 열어 원문이 유지되는 것을 확인했다. 계정 전체 맞춤 지침은 수정하지 않았다. 프로젝트 고정 메뉴가 고정 해제로 바뀌는 것을 확인했다.

1. 첫 메모: 지수·민호. 첫 응답은 세 열이고 근거 열 누락, 미정이라는 표현 사용. 이 실패를 편집으로 숨기지 않고 verify 장면과 PDF 6쪽에 반영했다.
2. 같은 채팅에 repair-format.txt 문구로 보완 요청. 네 열, 근거 문장, 확인 필요, 제안 분리 확인. `assets/project/11-first-result.png`, `first-response.txt` 보존.
3. 같은 프로젝트의 새 채팅에 수진·도윤 메모와 짧은 프로젝트 지침 적용 요청만 입력. 네 열, 수진 10월 2일, 도윤 확인 필요, 근거 인용 확인. 이전 회의 인명·날짜 혼입 없음. 다만 열 이름이 항목/기한·일정으로 바뀌었고 다음 회의를 별도 행으로 포함했다. 모든 문구·섹션 준수를 보장한 결과는 아니며 원문과 형식을 매번 확인하도록 설명했다. `13-second-result.png`, `second-response.txt` 보존.

캡처는 필요한 부분만 자른 실제 UI이며 연속 녹화가 아니다. 큰 설명 카드·강조·포인터는 편집 요소다. 원본 캡처의 개인 사이드바는 공개용 영상·PDF의 잘라낸 영역에서 제외했다. 연습 이외의 대화를 수집하거나 계정 설정을 변경하지 않았다.

## 미디어
