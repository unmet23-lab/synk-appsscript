# synkbrief 01 · v12 여성 내레이션 화면 원고

140.33초 · 18장면 · 실제 음성에 맞춘 47개 낭독 자막.

## 01. 회의할 때 이렇게 기록하죠 (0.00–5.00초)

회의 내용, / 어디에 적어두세요?

내레이션: 회의할 때, 컴퓨터나 메모장에 내용 적어두시죠?

## 02. 기록하는 방법은 여러 가지 (5.00–13.87초)

요즘은 녹음으로 / 기록하기도 하죠.

내레이션: 요즘은 음성으로도 기록해요. 조용하고 목소리가 또렷하면 편리하죠. 필요한 내용은 직접 메모하기도 하고요.

## 03. 오늘은 둘 다 쓸 수 있어요 (13.87–21.33초)

직접 쓴 메모도, / 녹음을 글로 푼 내용도.

내레이션: 직접 쓴 메모든, 녹음을 글로 옮긴 내용이든, 이 방법으로 보기 좋게 정리할 수 있어요.

## 04. 01   기록 준비하기 (21.33–28.63초)

적어둔 내용을 / 그대로 복사하세요.

내레이션: 적어둔 내용을 그대로 복사하세요. 미리 다듬을 필요 없어요. 정리는 에이아이가 할 거예요.

## 05. 02   ChatGPT 열기 (28.63–33.63초)

ChatGPT를 열고 / 표시한 입력창을 누르세요.

내레이션: 챗지피티를 열고, 지금 표시한 긴 입력창을 클릭하세요.

## 06. 03   AI에게 부탁할 문장 (33.63–42.50초)

AI에게 이렇게 / 부탁하면 돼요.

내레이션: 가이드의 복사용 문장을 붙여넣어요. 회의 기록을 요약, 결정, 할 일, 확인할 내용으로 나눠 달라는 부탁이에요.

## 07. 04   회의 기록 붙여넣기 (42.50–51.17초)

그 문장 바로 아래에 / 회의 기록을 붙여넣으세요.

내레이션: 그 문장 바로 아래에 회의 기록을 붙여넣어요. 직접 쓴 메모도, 녹음을 글로 옮긴 내용도 괜찮아요.

## 08. 05   보내기 (51.17–55.40초)

두 내용이 들어갔다면 / 표시한 ↑ 버튼을 누르세요.

내레이션: 두 내용이 들어갔다면, 오른쪽의 위쪽 화살표를 누르세요.

## 09. 같은 기록으로 전후 비교 (55.40–65.40초)

같은 기록, / 이렇게 달라졌어요.

내레이션: 같은 기록인데 차이가 보이죠? 뒤섞였던 내용이 요약, 결정, 할 일, 확인할 내용으로 나뉘었어요. 필요한 내용을 바로 찾을 수 있죠.

## 10. 마지막 확인만 하면 돼요 (65.40–73.33초)

다 정리된 뒤에 / 중요한 내용만 확인해요.

내레이션: 마지막으로 이름과 날짜만 원문과 비교해요. 아직 정하지 않은 기한은, 확인 필요로 남겨둡니다.

## 11. 프로젝트, 처음이라면 (73.33–83.20초)

프로젝트는 / 업무별 작업 공간이에요.

내레이션: 매번 같은 부탁을 쓰기 번거롭죠? 프로젝트를 써보세요. 같은 업무의 대화, 자료, 규칙을 모아두는 전용 폴더 같은 공간이에요.

## 12. 프로젝트와 채팅은 이렇게 달라요 (83.20–92.13초)

규칙은 한 번 저장, / 회의는 새 채팅으로.

내레이션: 채팅은 그 안에서 나누는 대화예요. 정리 규칙을 한 번 저장하면, 다음 회의는 새 채팅에 기록만 넣으면 돼요.

## 13. 06   회의 전용 폴더 만들기 (92.13–99.40초)

프로젝트 → 새 프로젝트, / 이름은 ‘회의 정리’.

내레이션: 왼쪽 프로젝트에서 새 프로젝트를 눌러요. 이름을 회의 정리로 적고, 만들기를 누르세요.

## 14. 07   프로젝트 설정 열기 (99.40–104.40초)

회의 프로젝트의 ⋯ / → 프로젝트 설정

내레이션: 회의 프로젝트의 점 세 개를 누르고, 프로젝트 설정을 여세요.

## 15. 08   규칙 한 번 저장하기 (104.40–113.73초)

지침 입력란에 붙여넣고, / 오른쪽 아래 저장을 눌러요.

내레이션: 가이드에서 프로젝트에 저장할 규칙을 복사해요. 지침 입력란에 붙여넣고, 오른쪽 아래 저장을 누르세요.

## 16. 저장 위치만 주의하세요 (113.73–122.20초)

회의 규칙은 / 계정 전체에 넣지 마세요.

내레이션: 이 회의 규칙은 계정 전체 지침에 넣지 마세요. 여행 질문이나 다른 글쓰기에도 영향을 줄 수 있어요.

## 17. 09   다음 회의에는 (122.20–131.33초)

같은 프로젝트를 열고 / 새 채팅에 새 메모만.

내레이션: 다음 회의도 같은 프로젝트에서 새 채팅을 열어요. 이번 회의도 정리해 줘, 라고 쓰고 새 기록을 붙이면 됩니다.

## 18. 직접 따라 할 자료까지 (131.33–140.33초)

처음부터 따라 하는 / 회의 정리 가이드

내레이션: 따라 할 피디에프와 복사용 문장, 연습 메모까지 준비했어요. 필요하신 분은 댓글에 싱크를 남겨주세요.
