## 이번 수정

다음 회의 안내를 다섯 행동으로 재구성했다. `왼쪽 프로젝트 메뉴 → 같은 회의 정리 프로젝트 → 그 안의 새 채팅 → 이번 회의 기록 입력 → ↑ 보내기` 순서다. 장면마다 전체 화면, 해당 위치 확대, 커서 이동과 클릭 반응, 해당 행동의 큰 제목이 따로 있다. 부탁할 문장과 회의 기록도 여성 내레이션의 두 문맥에 맞춰 차례로 나타난다. 기존 음성을 그대로 사용하며 장면 경계는 발화 사이 쉼에 놓았다.

프로젝트 메뉴와 입력창 배경은 2026-09-23에 확인한 ChatGPT 화면이다. 프로젝트 목록의 `회의 정리 · synkbrief 실습` 한 줄과 지난 대화 두 줄은 위치 안내를 위한 예시로 재현했으며 영상에도 명시했다. 개인용 고정 메뉴가 없어도 찾을 수 있도록 왼쪽 `프로젝트` 메뉴부터 안내한다.

제공 PDF 11쪽도 같은 다섯 단계로 갱신했다. 기존 복사용 요청문, 프로젝트 지침, 연습용 메모와 전후 예시는 ZIP에 포함한다.

## 확인과 상태

HyperFrames 검사, 장면·음성 자막·카메라 클릭 위치 검사, 요청문과 메모의 순차 표시 검사, MP4 전체 디코드, PC·모바일 미리보기 재생과 다운로드 확인 결과는 `verification/`에 기록한다. 이 영상과 자료는 게시 전 검토본이며 사용자의 최종 승인이나 외부 게시를 뜻하지 않는다.

## 재제작

`edit-v15.py`는 v14의 장면과 음성 타이밍을 읽어 v15의 23장면 데이터를 만든다. `npm run build`는 화면과 음원 믹스를 조립한다. `npx hyperframes render --quality delivery --output synkbrief-meeting-v15.mp4`로 영상 출력 후 WebM을 갱신하고 `node build-preview.mjs`로 미리보기 페이지를 다시 만든다. v14용 음성 합성 스크립트는 v15에서 실행하지 않는다.
