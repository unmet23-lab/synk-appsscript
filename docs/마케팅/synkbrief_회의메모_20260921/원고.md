# synkbrief 01 · 회의 메모를 할 일 표로

2026-09-22 후속 수정 · 초보자가 실제로 따라 하는 과정과 이유, 제공 자료를 연결한 원고.
**아래 초안을 바탕으로 [83초 v4 전체 무음 검토본](video-v4/README.md)을 렌더했다.** 사용자는 확정 전 소리를 넣지 않아도 된다고 했으며 v4는 내레이션·효과음·BGM이 없다. 실제 장면·시간·자막은 [v4 장면 데이터](video-v4/scenes.json)가 원본이다. 아래 시간은 제작 전 계획이며, 최종 영상은 빠진 기한 확인 후 표를 복사하는 순서로 다듬었다. 이전 v2 원고는 [보관본](원고_v2_보관.md), v3는 [15초 검토 이력](video-v3/README.md)에 남긴다.

## 시청자가 끝나고 할 수 있어야 하는 일

ChatGPT를 열어 복사용 요청문을 넣고, 메모 자리만 자기 메모로 바꾸고, 나온 표의 근거·담당자·기한을 확인한 뒤 자기 업무 문서에 사용한다. “AI가 표를 만든다”는 결과만 이해하는 것으로 끝내지 않는다.

제공물은 [4쪽 가이드 PDF](output/pdf/synkbrief-meeting-guide.pdf), 복사용 요청문, 가상 연습 메모, 결과 확인 예시다. [한 번에 받을 패키지](follow-along/README.md)를 먼저 완성하고 실제 자료를 엔딩에 보여준다. 설치형 스킬이나 자동 업무 배정 기능으로 소개하지 않는다.

## 새 전개 · 약 80초의 편집 초안

시간은 발화·실제 화면 검토 후 조정할 계획값이다. 컷만 빨리 바꾸지 않고, 기다림·반복을 줄인다. 전체 UI에서 위치를 먼저 알려준 뒤 해당 영역을 확대하고 현재 단계 번호를 유지한다.

| 계획 시간 | 실제로 보여줄 화면·행동 | 말할 내용 | 시청자가 이해할 이유·완료 기준 |
|---|---|---|---|
| 0–7초 | 흐트러진 회의 메모와 공유용 표의 전후. 프로그램 이름 ChatGPT를 즉시 표시 | 회의 메모, 팀에 공유하기 전에 다시 정리하고 계신가요? ChatGPT로 할 일과 담당자, 기한을 표로 정리해볼게요. | 자기 상황과 얻을 결과가 바로 연결됨 |
| 7–13초 | chatgpt.com과 새 채팅. 실제 입력창 위치에 포인터. “1. ChatGPT 열기” | ChatGPT를 열고 새 채팅을 시작하세요. 여기에 요청문과 회의 메모를 함께 넣을 거예요. | 어느 프로그램의 어디서 시작하는지 알 수 있음 |
| 13–21초 | 제공 파일 prompt.txt 전체 선택 → 복사 → 실제 입력창 붙여넣기. 파일과 화면의 같은 문장을 연결 | 함께 드리는 요청문을 전부 복사해 입력창에 붙여넣으세요. 프롬프트는 AI에게 맡길 일을 적은 요청문이에요. | 처음 듣는 용어와 첫 행동을 동시에 이해 |
| 21–29초 | 입력창 맨 아래 메모 자리만 선택하고 연습 메모로 교체. 위 요청문이 남아 있음을 표시 | 맨 아래 ‘여기에 회의 메모 붙여넣기’만 지우고, 그 자리에 내 메모를 넣으세요. 위의 요청문은 그대로 둡니다. | 무엇을 바꾸고 무엇을 남기는지 구분 |
| 29–37초 | 요청문의 네 열 강조. 실제 메모 한 문장과 근거 칸을 연결 | 할 일, 담당자, 기한, 근거 문장. 네 칸으로 요청하는 이유는 표를 읽고, 원래 메모와 맞는지도 확인하기 위해서예요. | 형식의 역할을 결과와 연결 |
| 37–43초 | “없는 정보는 확인 필요” 조건을 크게 확대. 메모의 미정 문장을 바로 옆에 | 정하지 않은 날짜까지 채우지 않도록 ‘없는 정보는 확인 필요로 표시해줘’라는 조건도 넣었어요. | 없는 정보는 따로 확인해야 함. 정확성 보장 표현 금지 |
| 43–47초 | 요청문+메모가 함께 든 입력창 전체 → 실제 보내기 버튼 클릭 → 응답 시작 | 두 내용이 모두 들어갔다면 보내기를 누르세요. | 시청자가 실행할 버튼과 성공 신호를 인지 |
| 47–57초 | 실제 응답 지수 행과 원문 날짜 대조 → 민호 기한 확대 | 지수의 문구 수정 기한은 23일로 나왔죠. 민호는 마감을 정하지 않았으니 ‘확인 필요’예요. 두 값 모두 원문과 맞는지 확인하세요. | 결과값의 출처를 읽고 직접 확인 |
| 57–64초 | 다음 회의 날짜와 작업 기한 구분. 인터뷰가 확정 표 밖의 질문으로 나온 실제 응답 표시 | 다음 회의 날짜를 작업 마감으로 넣으면 안 돼요. 해보자는 의견만 나온 일도 먼저 확인해야 합니다. | 회의 일정·의견·확정 업무의 차이 이해 |
| 64–71초 | 후속 질문 예시와 표 선택·복사 → 팀 문서에 붙여넣는 화면. 전송하지 않는 시연 | 빠진 기한은 담당자에게 물어보고 표를 고치세요. 확인한 표를 팀 문서에 복사하면 회의 후 할 일을 공유할 수 있어요. | 자기 업무에서 쓰는 마지막 행동까지 연결 |
| 71–80초 | 실제 PDF 페이지 미리보기와 파일 구성. 자료명·댓글 키워드 유지 | 이대로 따라 할 PDF와 복사용 요청문, 연습 메모까지 준비했어요. 회의 정리 템플릿이 필요하시면 댓글에 synk를 남겨주세요. | 무엇을 받는지, 무엇을 하면 되는지 이해 |

## 엔딩 실물과 전달 상태

- 제목: **회의 정리, 바로 써보세요**
- 자료명: **회의 메모 → 할 일 표 · 따라 하기 키트**
- 구성: **4쪽 PDF + 복사용 요청문 + 연습 메모 + 결과 확인 예시**
- 행동: **필요하시면 댓글에 synk를 남겨주세요.**
- 자료를 받을 효용: 내 회의 메모로 교체해 같은 순서로 정리하고 확인할 수 있다.
- [엔딩 시안](follow-along/ending.png)은 실제 PDF 페이지를 사용하며 v4의 마지막 8초에 반영했다. 설치형 스킬로 이름 붙이지 않는다.
- 로컬 자료 파일은 준비했다. 공개 다운로드 URL·댓글 수동 전달 경로·자동 DM은 미구축이다. 아직 영상 게시나 댓글 발송을 하지 않는다. 게시 전에 운영할 전달 경로를 실제로 확인한다.

## 이번 수정의 사실 근거

v4 제작에서는 2026-09-22 실제 ChatGPT에서 요청문 붙여넣기·메모 교체·전송·응답·표 복사를 새로 수행했다. [시연 근거와 범위](video-v4/research.md), [실제 복사된 표](video-v4/assets/current/copied-table.txt)를 남겼다. 가상 메모를 사용했으며 영상은 실제 캡처를 확대하고 설명 그래픽을 더한 구성이다. 다른 문서 앱에 붙여넣는 과정은 실제 시연 범위에 포함되지 않는다.

기존 실제 시연의 [입력](prompt-v2-demo.txt), [응답](demo-response-v2.txt), assets/v2의 원본 캡처도 보존한다. 현재 입력문은 [prompt-template.txt](prompt-template.txt)다. PDF는 이전 시연 캡처를 사용한 자료이며 v4 신규 캡처와 구분한다.

공식 문서의 결과 형식 지정·미지정 정보 표시·원문 대조 원칙은 2026-09-22에 다시 확인했다. [공식 프롬프팅 가이드](https://developers.openai.com/cookbook/examples/chatgpt/chatgpt_prompt_guide/chatgpt_prompt_guide), [앞선 조사](video-v3/research.md)를 참고했다. 이 안내서의 문구·구체적인 가상 예시·배치는 이번 회차를 위해 작성했다.

## 다음 영상 제작에서 확인할 것

각 장면에서 “내가 지금 어디를 눌러 무엇을 넣어야 하지?”에 답할 수 있어야 한다. 입력문 전체는 PDF·TXT에 남기되 영상에서는 지금 설명하는 문장에 초점을 둔다. 결과와 원문은 같은 화면에서 대조하고, 상상한 클릭 화면을 실제 앱으로 표시하지 않는다. 실제 화면·대사·자막과 제공 자료의 순서가 일치하는지 확인한다.

2026-09-22 후속 지시에 따라 확정 전에는 무음으로 구성·가독성을 검토한다. 이후 소리를 넣을 때 발화·자막·화면의 타이밍과 음량은 별도로 확인한다. 승인·게시 여부는 렌더 완료와 구분한다.
