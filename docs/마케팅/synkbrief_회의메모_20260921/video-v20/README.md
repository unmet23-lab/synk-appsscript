## 디자인 근거

숏폼디자인 조사(10-13, 출시 영상 인기작·정보형 쇼츠 상위작·화면 녹화 도구 기본값·Screen Studio 4 「Glass Loupe」) 안 1 「흰 무대 · 실제 화면이 주인공」.

- 흰 바탕 + 검정 글자 + 청금석 하나(선택 #3D6BC9, 강조 글자 #24448C, 종이 위 선택 #C5D6F5). 머리줄·쪽수·장식 라벨 없음. 창은 그림자 대신 2px 검정 선, 모서리 24.
- 실제 ChatGPT 캡처를 크게 잘라 넣고, 강조는 실제 글자 선택처럼(청금석 바탕 위 흰 글자) · 조명(나머지를 어둡게) · 키캡(Ctrl+C·Ctrl+V) · 커서 클릭 리플로 한다.
- 카메라는 움직이지 않는다(멀미). 전환은 같은 자리 매치컷(메모 → 회의록, 빈 입력창 → 부탁 문장 → 메모)과 하드컷 + 펀치(1.04 → 1, 0.25초). 결과가 뜨는 순간은 0.75초 정지 + 소리 하나.
- 「짧은 문장 ↔ 실제 화면」 교차: 가운데 큰 글자 박자 한 번(「정리는 AI가 할 거예요」).
- 끝: 자료 셋(따라 하기 PDF 11쪽, 그대로 복사할 문장.txt, 다음 회의 연습 메모.txt) → 「자료 받기 synk.im/brief/meeting」 → synkbrief 서명 + 청금석 실땀.
