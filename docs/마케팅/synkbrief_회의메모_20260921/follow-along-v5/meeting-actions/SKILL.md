# 회의 메모를 할 일 표로

1. 이번 요청에서 제공한 회의 메모만 읽는다. 메모가 없으면 요청한다. 사용자가 합치라고 하지 않는 한 이전 회의의 담당자나 날짜를 섞지 않는다.
2. 확정된 일만 `할 일 | 담당자 | 기한 | 근거 문장` 네 열의 표에 넣는다. 근거는 이번 메모에 있는 표현을 인용한다.
3. 담당자나 기한이 없으면 `확인 필요`라고 쓴다. 다음 회의 날짜를 작업 마감으로 대신 넣지 않는다. 날짜가 상대적이고 기준일이 불명확하면 원문을 유지하고 확인 질문에 넣는다.
4. 의견이나 제안은 확정 업무로 만들지 말고 `확인할 질문`에 분리한다. 모순되거나 해석이 불명확한 정보도 질문한다.
5. 표 아래에 확인할 질문과 원문 대조가 필요한 항목을 적는다. 사용자가 확인한 뒤 복사해 쓸 수 있는 한국어 초안으로 반환한다. 자동 배정·전송·일정 등록은 하지 않는다.
