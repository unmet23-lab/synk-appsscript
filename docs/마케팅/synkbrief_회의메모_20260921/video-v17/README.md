## 이번 수정

관련 설명과 화면 사이의 큰 빈칸을 줄이기 위해 23장면 전체를 다시 배치했다. 제목·내용 묶음·음성 자막을 연결하고, 설명 분량이 적은 카드를 무조건 화면 높이만큼 늘리지 않는다. 입력 기록, 원본과 결과 비교, 검토 이유, 프로젝트 개념, 실제 UI 시연, 자료 안내에 각기 다른 구성을 쓴다.

직접 쓴 메모와 녹음을 옮긴 글은 같은 회의록으로 모이는 도식으로 표현했다. 녹음 변환 안내는 녹음 카드 안에 붙이고 실제 정리 예시를 크게 보여준다. 메모 복사 장면에서는 큰 본문 글자 자체에 선택 표시를 적용했다. 프로젝트 개념은 대화·자료·지침을 한곳에 묶고, 계정 전체 지침과 프로젝트 지침은 적용 범위로 비교한다.

UI 시연은 위치 설명, 프로그램 화면, 지금 할 행동을 같은 패널에 배치했다. 화면 높이에 맞춰 확대·축소 위치를 다시 계산했고, 기존의 얇은 초점선과 클릭 순서는 보존한다. 엔딩의 PDF 이미지는 실제 제공 파일에서 다시 추출하고 자료 구성과 댓글 안내를 이어 붙였다.

전후 비교와 저장 범위 비교는 내용이 나타나기 전의 큰 빈칸도 없앴다. 결과 항목은 처음부터 읽을 수 있고 설명하는 순서에 맞춰 강조가 들어간다.

## 검증과 상태

`verification/`에 23장면의 실제 화면, 화면 안전 영역·내용 넘침 검사, 클릭 위치·53개 음성 자막 검사, HyperFrames 검사, MP4와 PC·모바일 미리보기 검증을 기록한다. 검토본이며 사용자 최종 디자인 승인과 외부 발행 전이다. 이전 버전은 보존한다.

## 재제작

`redesign-v17.mjs`가 v16 장면에서 v17 내용을 만들고, `layout.css`와 `build-v17.mjs`가 새 화면을 조립한다. `npm run build` 뒤 `npx hyperframes render --quality delivery --output synkbrief-meeting-v17.mp4`로 렌더한다. HyperFrames/Core는 0.8.71이며 새 음성 합성 없이 기존 음성을 사용한다.
