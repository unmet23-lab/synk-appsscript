# v17 · 내용이 이어지는 세로 영상

사용자 피드백: 관련 내용 사이의 빈 공간이 너무 커서 화면이 부자연스럽다. 23장면 전체를 다시 배치한다.

- 배경 White, 본문 #111c33, 강조 #315fbe. 기존 SUIT/Inter Tight와 펠트 상황 이미지를 보존한다.
- 고정 top 좌표로 설명을 흩어놓지 않는다. 제목 → 내용 묶음 → 음성 자막의 흐름을 사용한다.
- 공통 설명은 두 입력 자료가 한 회의록으로 모이는 큰 도식으로 표현한다. 녹음 변환 안내는 녹음 카드 안에 붙인다.
- 시연은 위치 설명, 실제 화면, 수행할 행동을 하나의 패널로 연결한다. 확대와 클릭 좌표는 패널 크기에 맞춰 계산한다.
- 비교/검토/프로젝트 개념/엔딩은 각각 다른 내용 구조를 사용한다. 공간을 채우려고 불필요한 장식을 더하지 않는다.
- 기존 발화, 자막 타이밍, 159.47초 길이를 유지한다. 단계 생략 없이 시각적 중복과 간격을 줄인다.
- 23장면 전체와 클릭 전후 프레임, 390px 미리보기, 최종 MP4를 확인한다.
