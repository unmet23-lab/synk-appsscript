# 두서없는 기록을 읽기 쉬운 회의록으로

[10쪽 PDF](synkbrief-meeting-guide-v11.pdf) · [전체 ZIP](synkbrief-meeting-kit-v11.zip)

PDF 1–4쪽은 기록 준비, 입력창, 부탁할 문장, 같은 메모의 정리 전후입니다. 5쪽에서 프로젝트를 ‘회의 전용 폴더’에 비유하고 대화·자료·지침과 채팅의 차이를 설명합니다. 6–8쪽은 프로젝트 만들기와 지침 저장, 9–10쪽은 다음 회의 재사용과 문제 해결입니다.

복사용 파일은 한국어 이름으로 제공하며 내용은 v9에서 실제 시연한 요청문·지침을 유지합니다. 녹음은 기록 앱에서 글로 바꾼 내용을 사용합니다.
