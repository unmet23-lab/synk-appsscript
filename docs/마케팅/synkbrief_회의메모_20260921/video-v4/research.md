## 현재 시연

이번 제작 중 ChatGPT 웹 임시 채팅에서 같은 가상 메모를 다시 입력했다. 입력창 찾기 → 요청문 붙여넣기 → 메모 자리 선택·교체 → 요청문과 메모 전송 → 응답 표와 질문 확인 → 표 복사를 실제로 수행했다.

- 시작·요청문·메모 자리 선택·입력·결과·표 복사 캡처: assets/current/01-start.png부터 06-copied.png.
- 실제 응답의 접근성 텍스트: assets/current/result-ax.txt.
- 실제 표 복사 버튼의 클립보드 결과: assets/current/copied-table.txt.
- 지수 / 소개 페이지 문구 수정 / 9월 23일, 민호 / 설문 초안 작성 / 확인 필요가 원문과 일치했다.
- 고객 인터뷰는 확정 업무 표에 들어가지 않고 진행 여부와 담당자를 묻는 질문으로 나왔다. 다음 회의 날짜는 작업 기한에 쓰지 않았다고 표시됐다.
- 메모 교체 중 붙여넣기 동작의 줄바꿈 처리를 확인하고, 요청문·메모의 줄바꿈을 정리해 전송했다. 전체 요청문 텍스트는 기존 prompt-template.txt와 같다.

영상은 실제 캡처를 편집해 위치를 확대하고 포인터를 얹은 것이다. 연속 녹화나 모델 처리 시간 측정이 아니다. 흰 배경의 표·문장·메모 카드는 이해를 돕는 편집 그래픽이며 실제 앱 화면은 검은 캡처 영역으로 구분한다. 공유용 질문은 예시이고 실제로 전송하지 않았다. 다른 문서 앱에 표를 붙여넣어 저장하는 동작은 이번 시연에서 하지 않았다.

## 제작 도구

v3의 HyperFrames 0.8.58에서 v4는 당시 npm 최신 0.8.60으로 별도 설치하고 실제 check/render를 검증한다. 이전 프로젝트의 의존성은 보존한다. 공식 `hyperframes skills update general-video`는 사용자 범위의 HyperFrames 스킬 11개 및 다른 에이전트 디렉터리 연결도 갱신했다. 이번 동작을 프로젝트 로컬 설치만 한 것으로 기록하지 않는다. Impeccable 검출의 dark-glow 1건은 검은 실제 캡처 영역에 적용된 아래쪽 그림자에 대한 판단이다. 실제 지면은 흰색이고 그림자가 아래로 오프셋되어 있어 광채 장식으로 판단하지 않았다.
