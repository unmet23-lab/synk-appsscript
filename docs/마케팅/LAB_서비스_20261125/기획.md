- **한 문장:** 「서비스」는 사장님이 그냥 주는 공짜다. 돈을 내려 할수록 음식이 더 쌓이고, 공짜인 걸 알고 「서비스 더 주세요」라고 조르면 계산서가 온다.
- **쌓임(셋):** 만두 → 탕수육 → 짬뽕. 상이 차오를수록 몽글의 진땀과 내미는 돈이 커진다(지갑 → 동전 → 동전 더미).
