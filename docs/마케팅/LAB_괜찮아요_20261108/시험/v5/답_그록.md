2. 권유를 받으면 "네, 좋아요"와 "괜찮아요" 중에서 바로 고를 수 있다.

4. 끝까지. 처음에 간식을 놓쳤다고 해서, 다시 먹는 데까지 보고 싶었다.

6. 3. 웃음은 간식을 놓칠 때와 끝의 한 입 부탁, 두 번이다. 가운데 뜻 카드는 조용하다.
