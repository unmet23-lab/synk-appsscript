유호 [@yuhobuilds](https://www.youtube.com/@yuhobuilds)와 [SYNK 브리핑](https://www.youtube.com/@synkbrief)도 최신 v6 소개 전문·각 채널의 승인 커버/프로필·3개 링크를 공개 재확인했다. LAB 마스코트로 덮어쓰지 않았다. 전체 검수는 **YouTube 19개**다.

- 몽골은 기존 `@synkkorean`과 Radio 라이브, 구독자 1명, `https://synk.im/lab/` 링크를 보존했다. 이름은 Studio의 50자 제한에 맞춰 `SYNK LAB Mongolia | Хөгжилтэй солонгос хэл`로 축약했다.
- 일본은 구독자 24명 유지. 첫 더보기의 구버전 소개는 공개 페이지 새로고침 뒤 최신 전문과 일치했다. 추가 저장하지 않았다.
- 15개 커버의 실제 파일 해시·2560×1440 규격·6MB 이하, 까몽 v4 원본 해시, 계정 ID/핸들/이름 원장 대조를 통과했다. 신규 생성 잔여·누락·중복은 0이다.
- 공개 프로필 준비 완료이지 학습 콘텐츠 게시 완료가 아니다. 실제 휴대폰 앱·원어민 감수·국가별 접속·전화 인증·API·게시 예약·앱 출시를 검증한 것이 아니다.
- 소유권·보안·연락처·기존 영상·워터마크를 바꾸지 않았다. 다른 SNS·홈페이지·마케팅 지도 화면의 데이터 연결·커밋·배포도 이번 완료 범위가 아니다.

최신 실행 근거는 [publication.json](publication.json), [설계 실행 원장](../youtube-setup-20260920.json), [계정 레지스트리](../../sns-계정.json)이다.

- `copy.json`: 신규 14개국 + 기존 몽골의 이름·소개·커버 문구. **파일 준비가 실제 게시 완료를 의미하지 않는다.**
- `build.cjs`, `glyphs.py`: 승인 LAB 펠트·글래스 SVG를 현지화한다. 원본 이미지·로고는 재생성하지 않는다. Inter Tight·SUIT를 유지하고, 지원하지 않는 문자만 설치된 언어별 폰트를 명시적으로 사용한다. HarfBuzz로 조합형 문자를 처리하고 경로로 내보낸다. 브랜드 폰트 정본은 변경하지 않는다.
- `manifest.json`: 실제 글리프 폰트·중앙 정렬·안전 영역·파일 해시. 15개 PNG 모두 2560×1440, 6MB 미만.
- `review-sheet.png`: 전체 커버의 시각 검수본. 개별 `.mobile.png`는 390px 안전 영역 미리보기이며 실기기 확인이 아니다.
- `publication.json`: 실제 개설·저장·공개 검수를 구분한 실행 상태. 완료 판단은 이 파일의 채널별 근거와 실제 공개 화면을 함께 확인한다.

## 유지 범위

프로필은 `../jp-vn-profile/kkamong-profile-v4-open-eyes.png`를 공통 사용한다. 기존 마스코트 정본·앱 표정 세트는 수정하지 않는다. 기존 영상·구독자·보안·권한·연락처·워터마크는 보존한다. 국가 타깃이 달라도 운영자의 거주 국가를 허위로 바꾸지 않는다. 유호·브리핑은 LAB 디자인으로 교체하지 않는다.

현지어 문구는 AI 작성·자체 검수 단계다. 원어민 감수·시장 성과 검증은 하지 않았다. 캐나다 소개는 영어·프랑스어, 인도는 힌디어·영어, 필리핀은 자연스러운 Filipino-English 혼합으로 준비했다. 스리랑카는 싱할라어 중심에 타밀어 안내를 포함하며 해당 국가의 모든 언어를 지원한다고 주장하지 않는다.

## 재생성

`python`에 `fontTools`, `uharfbuzz`가 필요하다. `node build.cjs`로 이 폴더의 생성물만 갱신한다. 빌드는 채널 생성이나 업로드를 실행하지 않는다.
