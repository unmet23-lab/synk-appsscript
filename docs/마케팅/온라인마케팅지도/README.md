이 README의 국가·계정 수와 미게시·기록 0건 표시는 9월 지도 스냅샷이다. 10월의 국가 추가·프로필·게시 결과까지 반영한 현재 집계로 쓰지 않는다. 현재 계정은 [SNS 계정 원장](../sns-계정.json), 제작은 [현재 제작 방식](../콘텐츠_제작방식_v2_20261002.md)과 해당 프로젝트, 게시·성과는 [기록장 원문](engagement/README.md)의 실제 기록을 먼저 확인한다. 아래 기술 명령은 지도를 갱신하는 경로이며 이 문서 정리가 실제 원장·화면 재빌드나 SNS 재확인을 뜻하지 않는다.

**2026-09-27 콘텐츠 라인 추가:** 콘텐츠 탭에 [콘텐츠 운영 체계](../콘텐츠_운영체계_20260927.md)의 라인 9개(CL-1~9)를 넣었다. 라인은 계속 만드는 시리즈 단위이며 기존 14건·검토본 2건과 구분한다. 입력은 [inputs/content-lines.json](inputs/content-lines.json), 생성기와 검사를 함께 갱신했고 `dashboard/src/data.json`을 다시 만들었다. `dashboard/dist`는 재빌드하지 않아 로컬 화면에는 아직 반영되지 않았다.

**2026-09-24 업로드 설정 점검:** [46개 계정별 결과·저장한 변경·남은 인증](../SNS_업로드설정_20260924/README.md). 웹 설정 확인 33개(변경 5개 포함), 재로그인·본인 확인 필요 8개, TikTok 사용자 요청 보류 5개다. 모바일·게시별 화질과 YouTube 추가 인증이 남아 있다.
