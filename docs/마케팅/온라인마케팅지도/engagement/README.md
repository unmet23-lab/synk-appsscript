# SNS 성장 현황과 게시 성과 기록

온라인 마케팅 지도의 계정 목록을 읽어, 실제로 확보된 공개 채널별 게시물과 날짜별 반응을 직접 기록하는 로컬 화면이다. [기록 화면](http://127.0.0.1:4188/)은 이 PC에서만 열린다. 원장은 `../dashboard/src/data.json`의 채널 ID와 콘텐츠 ID를 사용한다. 2026-09-23 지도 기준 공개 발행 가능 채널 46곳(기존 22·확장 확보 24)을 선택할 수 있으며, 연락용 개인 계정·보류·운영 제외·확장 미확인 채널은 입력 목록에서 제외한다. 계정 원장이 바뀌면 지도를 재생성한 뒤 기록 화면을 새로고침한다. 원장 파일이 지도를 만든 뒤 바뀌었으면 화면에 경고가 뜬다.

기록 서버를 켜면 [온라인 마케팅 지도](http://127.0.0.1:4188/map/)도 같은 주소에서 열 수 있다.

게시 준비는 [SNS 업로드 설정 점검표](../../SNS_업로드설정_20260924/README.md)에서 계정별 변경·재로그인·인증·모바일 확인 항목을 확인한다. 이 점검표는 실제 성과 수치나 게시 완료 기록과 구분한다.

## 성장 현황에서 보는 것

첫 화면은 **성장 현황**, 일상 입력은 **매일 기록** 탭이다. 첫 화면의 맨 위 **전체 SNS 한눈에**에는 모든 채널의 총 반응·총 조회수·총 팔로워/구독자, 하루 증가량·증가율과 좋아요·댓글·공유·저장·도달 합계가 함께 나온다. 총 반응은 **좋아요 + 댓글 + 공유 + 저장**이며 조회·도달·팔로워는 더하지 않는다. 기준 날짜까지 지표별 최신 확인값을 합산하고, 전일 변화는 동일 게시물의 동일 반응 항목을 두 날짜에 모두 확인한 경우에만 비교한다(당일 새 게시물은 게시 전 0). 새로 입력된 과거 게시물의 미확인 지표를 하루 증가로 잡지 않는다. 반응의 확인 범위는 게시물 × 4개 반응 항목 수로 표시한다.

맨 위 전체 요약은 기준 날짜만 반영하며 **아래 필터를 바꿔도 전체 합계를 유지**한다. 그 아래의 **선택 범위 상세**와 **매일 기록**에는 브랜드·채널·플랫폼·국가 필터를 적용한다. **전체 범위로** 버튼으로 상세 범위를 해제할 수 있다.

- **최근 기록 합계:** 조회·좋아요·댓글·공유·저장·도달·팔로워/구독자 7개 지표. 기준일까지 각 게시물/계정의 마지막 확인값을 한 번씩 합산하며, 당일 확인 대상 수와 이전 날짜 기록 포함 수를 표시한다. 지표 카드를 누르면 아래 분석 지표가 바뀐다.
- **기간:** 최근 7·30·90일 또는 직접 선택(최대 366일). 선택 기간 증가량·증가율, 그 직전 동일 길이 기간, 하루 증가량, 일별 비교 가능 범위를 나란히 표시한다.
- **추이:** 하루 증가 막대와 날짜별 기록 합계 그래프. 점/막대는 키보드나 클릭으로 상세를 열 수 있다. 일부 대상만 확인한 값은 주황색이고, 누락일과 일부 기록값 사이에는 합계 추이선을 잇지 않는다.
- **성장 기여:** 채널·브랜드·플랫폼·국가별 기간 변화 그래프와 상세 표. 증가량·증가율과 비교 대상 수가 함께 나온다. 묶음 이름을 누르면 그 범위로 좁힌다.
- **일별 전체 집계:** 하루를 한 줄로, 모든 지표의 증가량/증가율 또는 당일 누적 합계를 확인한다. 날짜를 누르면 그날의 기록 화면을 연다.
- **게시물별 성과:** 분석 지표의 기간 증가량 순, 제목 검색과 20건씩 보기. 제목을 누르면 조회·좋아요·댓글·공유·저장·도달의 날짜별 원본을 편집한다. 팔로워는 채널 지표이므로 게시물로 나누지 않는다.
- **이 범위 집계 CSV:** 현재 날짜·브랜드·채널·플랫폼·국가 범위를 반영한 전체/일별/현재 묶음/게시물별 7개 지표와 비교 대상 수·계산 정의를 내보낸다. 게시물 표 검색은 그 표에만 적용하며 CSV는 선택한 공통 범위 전체다. 상단 전체 원본 CSV·JSON 백업은 필터와 무관한 원본 전체다.

### 계산 기준

| 항목 | 계산 및 누락 처리 |
|---|---|
| 누적 합계 | 게시물마다 지표별 마지막 확인값을 한 번씩 더한다. 같은 게시물의 여러 날짜 누적값을 합산하지 않는다. 마지막 기록이 기준 날짜보다 오래됐으면 그 사실을 표시한다. |
| 하루 증가 | 정확한 전날과 기준 날짜에 모두 기록한 동일 대상의 차이. 당일 신규 게시물은 게시 전 0을 기준으로 당일 누적값을 포함한다. 기존 게시물의 첫 관측은 하루 성장으로 넣지 않는다. |
| 기간 증가 | 시작일 전날과 종료일에 모두 기록한 동일 대상의 차이. 기간 중 신규 게시물은 게시 전 0을 기준으로 종료일 누적값을 포함한다. 중간 날짜 누락과 관계없이 양 끝 기록이 있으면 기간 차이는 계산 가능하다. |
| 증가율 | 비교 가능한 대상의 증가량 합 ÷ 같은 대상의 기준값 합 × 100. 개별 증가율을 평균하지 않는다. 기준 0 또는 비교 불가일 때 비율은 비워 둔다. |
| 빈 값·감소 | 미확인/미지원 지표는 null, 확인한 0은 0. 취소·정정 등에 따른 감소를 음수로 유지한다. |
| 범위 | 관리 종료 게시물도 과거 성과에 포함한다. 비교 대상 수가 전체보다 적으면 부분 집계다. 직전 기간과 현재 기간의 비교 대상 구성은 달라질 수 있다. |
| 도달·팔로워 | 게시물/계정별 보고값 합계이며 고유 인원으로 중복 제거하지 않는다. 플랫폼별 조회·도달 정의도 다를 수 있다. |
| 시각 | 한국 날짜 기준 수동 관측값. 매일 비슷한 시각에 확인하는 것을 권장하며, 플랫폼의 정확한 24시간 통계와 동일하지 않다. |

## 주·월·분기에서 보는 것

**주·월·분기** 탭은 달력 단위로 최근 6·8·12·24개 기간을 비교한다. 기준 날짜와 브랜드·채널·플랫폼·국가 필터를 적용하며, 진행 중인 기간도 표시 수에 포함한다.

- **주별:** 월요일~일요일. 연도를 포함한 시작 날짜로 주를 식별한다.
- **월별:** 해당 월 1일~마지막 날.
- **분기별:** 1~3월 / 4~6월 / 7~9월 / 10~12월.
- **요약 카드:** 선택 지표의 기간 순증감, 성장률, 직전 기간 대비 차이·비율, 일평균, 계산 가능한 대상 수. 총 반응과 기존 7개 지표를 선택한다.
- **기간별 그래프:** 최신 기간부터 표시하며 감소는 왼쪽, 증가는 오른쪽이다. 부호와 수치로도 구분한다. 진행 중인 막대에는 무늬와 표시를 붙인다.
- **전체 지표 비교표:** 모든 기간 × 총 반응·조회·좋아요·댓글·공유·저장·도달·팔로워. 순증감/성장률, 직전 대비 차이, 종료일 기록 합계로 전환한다. 기간 열과 표 머리글을 고정하고 표 안에서 가로·세로 이동한다.
- **선택 기간 계산 내역:** 시작 기준값, 같은 대상 종료값, 순증감, 일평균, 증가 항목 합/감소 항목 합, 신규/기존 게시물 기여. 별도 표에서 두 기간의 공통 대상 순증감과 직전 대비를 대조한다.
- **채널·게시물 기여:** 채널·브랜드·플랫폼·국가·게시물 단위로 순증감 크기 순 정렬. 게시물 제목은 선택 기간 종료일의 원본 입력으로 연결한다.
- **기간 집계 CSV:** 화면의 기간 수·공통 필터를 적용한 모든 기간과, 선택 기간의 현재 비교 단위를 8개 지표·32개 열로 내보낸다. 실제 비교 날짜와 범위·정의도 포함한다. 표 표시 방식과 무관하게 해당 범위의 계산 항목을 함께 내보낸다.

### 기간별 비교를 읽는 기준

| 표시 | 계산 기준 |
|---|---|
| 기간 순증감 | 시작 전날과 확인 종료일의 누적 차이. 기간 중 새 게시물은 게시 전 0을 기준으로 포함. 양 끝이 미확인인 기존 게시물·지표는 제외한다. |
| 직전 기간 대비 차이 | **두 기간 모두 계산 가능한 같은 게시물·지표**의 이번 순증감 − 직전 순증감. 새 게시물이 직전 기간에 존재하지 않았으면 그 기간 기여는 0이다. 순증감 자체의 대상 수와 공통 비교 수는 다를 수 있다. |
| 진행 중 | 지난 기간의 같은 경과 일수와 비교한다. 이전 월·분기가 더 짧으면 두 기간의 비교 구간만 짧은 쪽 일수로 맞춘다. 기간 순증감은 여전히 기준 날짜까지이며, 잘린 비교 구간은 안내문과 CSV에 명시한다. |
| 완료 | 길이가 달라도 완료된 달력 기간 전체끼리 비교한다. 월/분기별 일수 차이는 일평균과 실제 날짜를 함께 확인한다. |
| 비율 | 성장률은 순증감 ÷ 같은 대상 시작 기준값. 직전 대비율은 순증감 차이 ÷ 직전 공통 대상 순증감. 분모가 0 또는 음수면 비율은 비운다. 개별 비율을 단순 평균하지 않는다. |
| 증가/감소 항목 합 | 각 대상·지표의 양 끝 차이를 양수와 음수로 나눠 더한 값. 두 합을 더하면 순증감이다. 기간 안의 모든 반응 발생·취소 이벤트를 센 총량은 아니다. |
| 신규/기존 기여 | 기간 중 새로 게시한 게시물의 확인된 종료값 / 이전에 게시한 게시물의 확인된 차이. 두 기여를 더하면 순증감이다. 팔로워는 채널 지표이므로 신규 게시물 기여가 없다. |
| 확인 범위 | 총 반응은 게시물 × 반응 4항목, 팔로워는 채널 수, 나머지는 게시물 수. 빈 값은 —, 실제 확인한 0은 0이다. 종료일 기록 합계에는 그 날짜에 확인한 값만 포함한다. |

2026-09-24 기간 기능 검증: 기존 시험을 포함해 19개 통과. 연도·윤년·분기 경계, 진행 중 비교, 이전 월이 더 짧은 경우, 공통 대상 비교, 음수·미확인·신규 기여와 묶음 합계 일치를 확인했다. 별도 임시 저장소의 가상 8개 게시물로 주/월/분기 전환, 12개 분기, 브랜드·채널 필터, 세 가지 비교표, 게시물 원본 이동과 탭 키보드 이동을 확인했다. 브랜드별 12분기 CSV 36,885바이트·129행이 계산 결과와 바이트 단위로 일치했다. 1265px PC 및 390px 요약·상세 표, 320px 감소 그래프를 시각 확인했고 320/390px 페이지 가로 넘침과 브라우저 오류가 없었다. 가상 기록은 실제 저장소와 분리했다.

## 매일 쓰는 순서

1. 실제 게시가 끝난 뒤 **매일 기록 → 게시물 등록**에서 채널·게시 날짜·게시물 주소·제목을 입력한다. 같은 콘텐츠를 여러 플랫폼에 올렸다면 게시물 주소를 플랫폼마다 하나씩 등록한다. 콘텐츠 ID와 형식·메모는 선택 사항이다. 등록은 SNS 게시 동작이 아니다.
2. 날짜를 고르면 관리 기간 안의 게시물이 목록에 나온다. 기본 관리 기간은 게시일부터 14일이며 게시물마다 1~365일로 조정하거나 관리 종료·재개를 할 수 있다.
3. 각 게시물의 **수치 입력**에서 조회·도달·좋아요·댓글·공유·저장의 **그 날짜에 표시된 누적값**을 적는다. 빈칸은 미확인, 0은 확인한 0이다. 같은 날짜를 다시 저장하면 수정된다.
4. 필요하면 아래에서 채널별 팔로워·구독자 수를 기록한다. 게시물 반응과 별도의 날짜별 기록이다.
5. 날짜·브랜드·채널·검색으로 미기록 항목을 찾는다. 전일 기록이 정확히 있는 지표만 **전일 대비**를 표시한다. 중간 날짜가 비어 있으면 증가량을 하루치로 표시하지 않는다.

실제 SNS 수치 자동 수집, 게시 동작, 승인·성과 검증은 연결하지 않았다. 시스템을 만든 시점에는 게시물 기록이 비어 있었다. 화면의 0건은 실제 반응 0이 아니라 아직 입력하지 않았다는 뜻이다.

## 실행과 보관

PowerShell에서 `.\docs\마케팅\온라인마케팅지도\engagement\start-records.ps1`을 실행하면 로컬 서버를 켜고 브라우저를 연다. 직접 실행하려면 저장소 루트에서 `node docs/마케팅/온라인마케팅지도/engagement/server.mjs`를 실행하고 `http://127.0.0.1:4188/`을 연다. 서버는 `127.0.0.1`에만 바인딩한다. 지도 첫 화면과 콘텐츠 탭에도 기록 화면 링크가 있다.

사용자가 입력한 원본은 `data/records.json`에 저장된다. 매번 수정 전 `data/backups/`에 이전 파일을 복사한 뒤 새 파일로 교체한다. 이 `data/` 폴더는 Git에 올리지 않도록 제외했다. 화면의 **JSON 백업**으로 전체 원본을 내려받고, **CSV 내보내기**로 게시물·채널의 날짜별 수치를 확인할 수 있다. 백업 파일은 사용자가 별도로 보관한다. 여러 기기 동기화와 SNS API 연결은 아직 없다.
