03 / VOICE

같은 문장으로 비교하는 목소리

공통 비교 대사

오늘의 선택이, 내일의 장면이 됩니다. 원하는 분위기를 들려주세요. 함께 더 좋은 장면을 만들겠습니다.
  • 현재 모델 선택 화면에 연결된 A/B/C는 기존 목소리 샘플입니다. 아래 같은 대사로 비교하는 새 샘플을 추가 제작할 계획입니다.
  • 한 광고에서는 선택한 음색을 끝까지 유지합니다. 유호의 샘플은 본인의 실제 녹음을 기준으로 합니다.
모델별 A/B/C 목소리 제작 기준
코드모델ABC
M01이안차분한 중저음밝고 다정한낮게 속삭이는
F01유나낮고 세련된밝고 또렷한부드럽게 속삭이는
F02하린맑고 발랄한산뜻하고 가벼운신나고 생기 있는
F03서진또렷하고 단단한맑고 차분한부드럽고 다정한
M02태준거칠고 묵직한단단하고 깊은부드럽고 낮은
F04지유밝고 맑은편안하고 자연스러운따뜻하고 부드러운
M03유호힘주어 말할 때차분하게 설명할 때가볍게 말할 때
  • 같은 문장을 자연스러운 속도로 읽어 전달력·온도·리듬을 비교합니다.
  • 새 비교 샘플은 배경음 없이 준비합니다. 기존 유호 인터뷰 원음에는 배경음이 포함됩니다.

04 / STYLE

한 번에 한 가지를 바꿔 판단합니다.

  • 한 번에 한 요소만 바꿔 비교합니다. 헤어를 비교할 때는 표정·의상·조명을 유지합니다.
  • 얼굴·체격은 모델의 승인 기준을 유지하고, 옷과 액세서리는 같은 구도에서 비교합니다.
  • 스타일 사진은 제작 희망 방향을 전달하는 참고입니다. 모든 선택 조합의 자동 합성 미리보기는 아닙니다.
스타일 참고 이미지 제작 기준
항목구도변형 범위확인 기준
기준판정면 얼굴 / 3/4 얼굴 / 전신모델당 3장동일인·실제 정본 체격·중성 조명
헤어동일 얼굴 정면 또는 3/4기준 1 + 대안 2가르마·헤어라인·귀 형태 유지
메이크업얼굴 근접기준 1 + 대안 2피부 톤을 미백하거나 눈매를 바꾸지 않음
자켓전신 같은 포즈기준 무착용 + 대안 2소매·라펠·체형·아래옷 고정
상의반신/전신기준 1 + 대안 2핏·소재가 읽히고 얼굴 동일
하의전신기준 1 + 대안 2허리·밑위·다리 길이 왜곡 없음
귀걸이같은 쪽 귀 근접없음 + 대안 2귓불 접촉·좌우 정합
반지같은 손등 근접없음 + 대안 2손가락 수·반지 위치·피부 관통

각 모델의 광고 기획에서 전신 기준 사진 한 장씩, 모두 7장을 볼 수 있습니다. 헤어·의상별 비교 사진은 별도 제작 예정이며, 먼저 하린의 스타일 대안부터 준비하고 일곱 모델까지 확장합니다.

최소 검수 기준

  • 얼굴과 체격이 모델의 기준 모습으로 유지되는지 확인합니다.
  • 손·발·제품 접촉과 옷감의 움직임이 자연스러운지 확인합니다.
  • 제품 모양·라벨·글자가 장면마다 정확하게 이어지는지 확인합니다.
  • 휴대폰에서도 핵심 문구와 상품이 잘 보이고 목소리가 또렷한지 확인합니다.

고객이 확인할 것

  • 우리 광고에서 전달할 가치와 어울리는 장면이 있나요?
  • 원하는 모델·색감·표정·속도를 프로젝트의 제작 메모에 남겨 주세요.
  • 자기 브랜드의 실제 상품 사진·로고·참고자료를 함께 전달하면 장면에 반영할 수 있어요.
  • 완성본은 최신 버전에서 수정 의견의 반영 여부를 확인한 뒤 승인해 주세요.

이번 준비안의 범위

  • 이미지 콘티는 색감·구도·흐름을 보는 제작 초안입니다. 완성 영상이나 모든 선택 조합이 반영된 미리보기가 아닙니다.
  • 선택한 모델·스타일과 기타 메모는 원래 프로젝트의 ‘제작 설계 저장’을 눌러야 반영됩니다. 이 자료를 보는 것만으로 선택이나 승인이 바뀌지 않습니다.
