> 확인일: 2026-09-20 · 한국에서 운영하는 SYNK LAB의 일반계정 개설 검토.

### 2026-09-20 후속 실제 가입 확인

**RUTUBE:** 공식 FAQ의 일반 전화번호 안내와 달리, 이번 계정은 공식 홈페이지에서 연결된 **GID 이메일 인증**으로 실제 가입에 성공했다. `synk.yuh@gmail.com`으로 기본 채널 `81398864`에 접근했고, 이름을 `SYNK LAB Russia`로, 소개를 원고의 `bioLong` 265자·3줄로 저장했다. Studio 저장 성공 표시와 [공개 채널](https://rutube.ru/channel/81398864/) 후속 재조회·전체 소개 펼치기로 일치를 확인했다. 전화번호 입력·연결, 새 비밀번호 설정, 광고 수신 선택은 하지 않았다. 이 결과는 해당 계정과 해당 공식 경로의 관찰이며 전체 사용자·다른 지역의 가입 조건을 확정하지 않는다.

- 첫 GID 시도는 코드 발송 화면과 사용자 입력 보고 후 콜백이 만료되어 성공을 확인하지 못했다. 이 시점만으로 이메일 인증·계정 생성을 완료 처리하지 않았다.
- 별도의 직접 RUTUBE 이메일 가입 폼은 `Зарегистрироваться можно по телефону`라는 전화번호 가입 안내를 표시했다. 이는 그 폼의 이력이지 공식 GID 로그인 경로 전체가 불가능하다는 근거가 아니다.
- 이후 공식 홈에서 새 로그인 요청을 시작해 이메일 인증을 완료했고 로그인과 실제 채널을 확인했다. CAPTCHA 답·인증 코드·전화번호·세션 토큰·전체 콜백 URL은 기록하지 않는다.

**Douyin:** 사용자 승인 후 한국 번호를 `+82`로 입력하고 `获取验证码`를 눌렀으나, 입력값이 비워지며 `请使用抖音手机APP登录`(더우인 휴대폰 앱으로 로그인) 안내가 표시됐다. 전화번호 입력·인증 요청 시도는 했지만, 발송 카운트다운·문자 발송 성공·로그인·계정 생성은 확인되지 않았다. 따라서 현재는 앱 로그인 필요 상태이며 실제 번호는 저장하지 않는다.

- 후속으로 공식 홈페이지의 링크에서 [공식 창작자센터](https://creator.douyin.com/)를 확인했다. 국가번호 `韩国 +82`를 선택하고 문자 요청을 한 차례 진행했으나 `访问太频繁，请稍后再试`(접속이 너무 빈번하니 나중에 다시 시도) 안내가 나왔다. 추가 요청·재시도를 중지했으며 제한 우회는 하지 않았다. 실제 발송·수신·인증·신규 개설은 확인되지 않았다.

## 검증 한계

- 초기 조건 조사는 공식 웹 검색·문서 읽기만 수행했다. 후속 실제 실행은 위 별도 절과 실행 원장에서 구분하며, RUTUBE 가입 성공과 Douyin 인증 요청 이후 앱 안내를 기록했다. 결제는 하지 않았다.
- JS 기반 로그인 화면은 웹 도구에 내용이 노출되지 않을 수 있다. 문서에서 못 찾았다는 이유만으로 특정 로그인 방식이 없다고 단정하지 않는다.
- 이 문서는 가입 성공 원장이 아니다. 실제 시도 결과는 `미시도`, `인증 보류`, `가입 완료`, `소개 저장 확인` 등 실물 증거에 맞춰 별도 기록한다.
