# LAB 신규 SNS 소개 원고 · 2026-09-20

남은 **22개국 28개 SNS**의 계정명·핸들 후보·짧은 소개·긴 소개를 [copy.json](copy.json)에 준비했다. `account-setup-proposal.json`에서 YouTube를 제외한 28개와 ID 단위로 대조했다.

**이 문서는 원고 준비 결과이며, 가입·이메일 인증·핸들 확보·저장·공개 반영의 증거가 아니다.** 기존 몽골 계정과 YouTube 소개는 변경하지 않았다.

## 적용할 때

- 이름은 `SYNK LAB + 국가`로 간단히 통일했다. 현지어 표현은 소개에 담았다.
- `bioShort`가 기본 소개 입력란용이다. `bioLong`은 별도 긴 소개란이 있을 때만 쓴다. 긴 소개에는 아직 첫 콘텐츠를 준비 중이라는 현재 상태를 적었다.
- `proposedHandle`은 기존 계정설계의 후보를 보존했다. 사용 가능 여부나 플랫폼별 허용 문자는 검증하지 않았다. 가입 UI에서 실제 확보한 값은 별도 실행 기록에 남긴다.
- 공식 링크는 `https://synk.im/`이며 별도 웹사이트 입력란이 제공될 때 넣는다. 짧은 소개에 일괄 덧붙이지 않는다.
- `KoreanMeaning`에서 짧은 소개와 긴 소개의 한국어 뜻을 각각 확인할 수 있다.
- 문구의 대상은 한국어를 처음 배우는 10대 후반이다. 그 연령이 플랫폼 가입 자격을 충족한다는 뜻이 아니다.

## 언어와 표현

사용자가 고른 **“한국어가 재밌어지는 곳”**, **“배워서 바로 쓰는 한국어”**를 각 언어에서 자연스럽게 읽히도록 풀었다. 인사·음료 주문·소리 내어 말하기처럼 구체적인 첫 연습을 보여 준다. 기관 인증, 유료 수업 운영, 서비스 출시, 실력 향상 수치, 원어민 감수 등을 약속하지 않는다.

전부 **AI 작성·자체 검수 초안**이다. 원어민 감수는 하지 않았으며, 특히 네팔어·크메르어·싱할라어·버마어·중앙아시아 언어의 현지 어감까지 확정된 원고로 취급하지 않는다. 이 파일에 이미 감수했다는 문구는 없다.

중국은 간체, 대만은 번체를 분리했다. 우즈베키스탄은 라틴 문자 우즈베크어, 카자흐스탄은 카자흐어, 키르기스스탄은 키르기스어다. 인도는 힌디어와 영어, 필리핀은 필리핀어와 영어, 캐나다는 영어와 프랑스어를 함께 썼다. 스리랑카는 이번 짧은 소개에 싱할라어를 우선 사용했다. 국가 전체의 언어를 모두 지원한다는 뜻은 아니다.

## 2차 자체 검수 · v2

28개 소개 전체를 다시 읽고, 필요한 14개 원고 항목만 다듬었다. 계정명·핸들 후보와 반영 중인 네팔 Facebook 짧은 소개는 그대로 보존했다.

- 우즈베크어·카자흐어·키르기스어: 한국어의 “~한 곳” 구조를 그대로 옮긴 긴 소개 첫 문장을 자연스러운 참여 문장으로 변경했다.
- 러시아어: 어순과 “표현을 배우다”의 동사를 수정했다. 크메르어는 긴 소개의 수사 어순을 정리했다.
- 필리핀: 짧은 소개에서 불필요한 문장 중간 언어 전환을 줄였다. 긴 소개의 일반적인 Taglish는 유지했다.
- 말레이어: 인도네시아어식으로 읽힐 수 있는 `pemula` 대신 처음 배우는 사람을 풀어 썼다.
- 호주·파라과이: 직역투로 읽히는 긴 소개의 말하기·연습 문제 표현을 다듬었다.
- 캐나다: 짧은 소개의 영어·프랑스어를 줄 단위로 나눴다. 인도·필리핀·캐나다의 복수 언어 코드는 `additionalLocales`로 분리했다.

코드로 대상 일치·글자 수·예상 문자 체계·대체 문자·방향 제어 문자를 재검사했다. 28개 모두 통과했으며, 기관 인증·출시 완료·유료 서비스·보장 성과를 약속하는 문구는 넣지 않았다. 이는 AI 자체 검수이지 원어민 검수 완료를 뜻하지 않는다.
