# S1 · SYNK를 만드는 유호

촬영용 원고 초안. 영상 제작은 다른 세션. 유호 YouTube·Instagram·TikTok·Naver Clip에 같은 핵심 영상을 사용한다.

## 말할 내용

안녕하세요. AI를 활용해서 SYNK라는 회사를 만들고 있는 유호입니다.

홈페이지도 만들고, 학습 자료와 콘텐츠도 만들고 있어요. 여기에는 그 과정에서 직접 해본 것들을 남겨보려고 합니다.

이번에는 SNS 커버를 정리했는데요. 원본에서는 괜찮았던 소품이 Behance에 올리니 잘리더라고요.

그림을 새로 만들기보다 로고와 글자, 소품을 가운데로 모으고 아래로 조금 옮겼습니다. 다시 올린 다음 실제 프로필에서 확인했고요.

커버를 만들고 있다면 세 가지만 확인해 보세요. 중요한 글자가 잘리지 않는지, 프로필 사진이나 메뉴에 가리지 않는지, 작게 봐도 읽히는지요.

앞으로도 완성된 결과와 함께, 어디서 막혔고 어떻게 고쳤는지 보여드릴게요.

## 화면·촬영 구성

| 구간 | 유호 촬영 | 겹쳐 보여줄 실제 자료 |
|---|---|---|
| 소개 | 첫 두 문단. 편하게 말하는 상반신 | 유호 · SYNK, 실제 홈페이지·학습자료 등 공개 가능한 결과. 학생 정보 없음 |
| 문제 | Behance 소품이 잘렸다는 설명 | 수정 전 업로드 원본. ‘수정 전 원본’이라고 표시하며 가짜 플랫폼 UI를 덧씌우지 않음 |
| 수정 | 가운데로 모으고 내려 배치한 설명 | 수정 전후 원본을 같은 크기로 비교. 로고·글자·소품 위치를 보여줌 |
| 시청자가 확인할 것 | 세 항목. 항목마다 잠깐 끊어서 녹음 가능 | 잘림 / 가림 / 작은 화면의 가독성. 세 가지를 한꺼번에 빽빽하게 띄우지 않음 |
| 마무리 | 마지막 문장 | 완성 커버와 실제 계정명. 존재하지 않는 자료 배포·링크 약속 없음 |

## 제목·게시 설명 초안

제목: AI로 SYNK를 만들고 있습니다. 첫 기록은 SNS 커버.

설명: SYNK의 홈페이지와 콘텐츠를 만드는 과정을 기록합니다. 이번에는 SNS 커버를 실제 프로필에 맞춰 다시 배치했습니다. 커버를 올렸다면 글자 잘림, 프로필·메뉴와의 겹침, 작은 화면의 가독성을 확인해 보세요.

- 원본 비교 경로는 [디자인 사실 근거](../../첫콘텐츠_제작_20260919_이전원고보관/copy/shift-evidence.json)의 behance_crop을 따른다. 승인 커버 원본은 `docs/마케팅/프로필최신화_20260919/커버_펠트글래스_v4/`에 있다.
- 창업 전 직업, 수입, 실패담, 창업 계기 등 확인되지 않은 개인 이야기를 넣지 않았다. 유호가 자기 말로 덧붙이고 싶은 계기가 있으면 촬영 전 그 부분만 추가할 수 있다. 지금 원고만으로도 촬영할 수 있다.
- 실제 공개 페이지를 새로 촬영하지 않으면 원본 비교라고 표기한다. 모든 플랫폼 검수가 끝났거나 고객에게 납품한 작업이라고 말하지 않는다.
- 이 세션에서는 촬영·합성·음성 복제·영상 제작을 하지 않는다. 다른 세션에서 촬영본과 실제 낭독을 기준으로 편집한다.
- Naver Clip 소개 후속 수정은 이 영상의 해당 계정 업로드 때 처리한다.
