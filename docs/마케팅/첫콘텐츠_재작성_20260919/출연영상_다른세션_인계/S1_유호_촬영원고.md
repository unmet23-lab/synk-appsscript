# S1 · SYNK를 만드는 유호

2026-09-20 촬영 준비 개정본. 현행 인계 원고를 다듬었다. 실제 유호 촬영본은 아직 전달·확인되지 않았다. 유호 YouTube·Instagram·TikTok·Naver Clip `@yuhobuilds`에 같은 핵심 영상을 사용한다.

## 이번 편의 목적

SYNK를 만드는 사람이 누구이고, 실제 결과에서 무엇을 보고 고치는지 보여준다. 회사의 모든 사업 소개를 넣지 않고, SNS 커버 한 사례로 유호의 역할과 판단을 드러낸다.

## 말할 내용

안녕하세요. AI로 SYNK라는 회사를 만들고 있는 유호입니다.

홈페이지와 학습 자료, 콘텐츠를 만들면서 직접 해본 일들을 여기에 남겨보려고 해요.

이번에 SNS 커버를 만들었는데, Behance 업로드 미리보기에서 오른쪽 소품이 잘리더라고요.

그림은 그대로 두고, 로고와 글자, 소품을 조금 줄여 가운데로 모았어요.

위치도 아래로 조금 옮겼습니다. 다시 올린 뒤 실제 프로필에서도 확인했고요.

커버를 올릴 때는 세 가지만 확인해 보세요.

글자가 잘리지 않는지, 프로필 사진이나 메뉴에 가리지 않는지, 작게 봐도 읽히는지요.

앞으로도 완성된 결과와 함께, 어디서 막혔고 어떻게 고쳤는지 보여드릴게요.

## 유호가 찍을 분량

| 묶음 | 읽을 범위 | 최종 화면 | 촬영 부담을 줄이는 방법 |
|---|---|---|---|
| S1-A | 첫 두 문단 | 유호 얼굴, `유호 · SYNK` | 홈페이지 별도 촬영 없이 소개 |
| S1-B | “이번에 SNS 커버…”부터 “확인했고요.”까지 | 실제 수정 전후 원본 중심 | 같은 자리에서 읽되 화면 전환 뒤에는 목소리만 사용 가능. 잠깐 대본을 봐도 이 부분은 편집 가능 |
| S1-C | “커버를 올릴 때는…”과 세 가지 항목 | 얼굴 또는 원본 비교에 항목을 하나씩 표시 | 항목 사이만 잠깐 쉰다. 손으로 셋을 세는 연기 불필요 |
| S1-D | 마지막 문장 | 얼굴로 돌아와 마무리 | 플랫폼 이름·별도 팔로우 인사 없이 한 번 촬영 |

`SYNK`는 `싱크`, `Behance`는 `비핸스`로 읽는다. 방금 고친 일을 옆 사람에게 설명하는 정도로 읽는다. 네 묶음은 한 파일에 이어 찍어도 된다. [촬영 화면](촬영_리딩.html)에서 말할 문장만 크게 볼 수 있다.

완성 길이는 약 55~75초를 예상한다. 실측 전 가늠값이며 자연스러운 낭독을 기준으로 조정한다. 첫 두 문단과 마지막 문장은 얼굴을 남기고, 가운데 사례는 원본 비교가 잘 보이게 편집한다. 최종 얼굴 노출 길이와 촬영 시간은 같지 않다.

## 제목·게시 설명 초안

제목: AI로 SYNK를 만들고 있습니다. 첫 기록은 SNS 커버.

설명: SYNK의 홈페이지와 콘텐츠를 만드는 과정을 기록합니다. 이번에는 SNS 커버를 실제 프로필에 맞춰 다시 배치했습니다. 커버를 올렸다면 글자 잘림, 프로필·메뉴와의 겹침, 작은 화면의 가독성을 확인해 보세요.

## 근거·제작 메모

- 사실 근거는 [공개 반영 기록](../../프로필최신화_20260919/반영기록_20260919.md)의 Behance 공개 크롭 보정 기록과 [제작기록](../../프로필최신화_20260919/커버_펠트글래스_v4/제작기록.md)이다. 첫 업로드는 미리보기에서 취소한 뒤 수정하여 다시 올렸다. 승인 커버 원본은 `docs/마케팅/프로필최신화_20260919/커버_펠트글래스_v4/`에 있으며 [촬영 준비](촬영준비_20260920.md)에 전후 경로를 명시했다. 이전 게시 원고를 가져오지 않았다.
- 창업 전 직업, 수입, 실패담, 창업 계기 등 확인되지 않은 개인 이야기를 넣지 않았다. 유호가 자기 말로 덧붙이고 싶은 계기가 있으면 촬영 전 그 부분만 추가할 수 있다. 지금 원고만으로도 촬영할 수 있다.
- 실제 공개 페이지를 새로 촬영하지 않으면 원본 비교라고 표기한다. 모든 플랫폼 검수가 끝났거나 고객에게 납품한 작업이라고 말하지 않는다.
- 현재는 원고·촬영 준비 단계다. 촬영본을 받은 뒤 실제 낭독과 화면을 기준으로 편집한다. 본문·화면 위 설명 모두 우선 실제 유호 녹음으로 연결한다. 음성 복제·디지털 트윈은 이번 범위가 아니다.
- Naver Clip 소개 후속 수정은 이 영상의 해당 계정 업로드 때 처리한다.
- 공개 업로드는 최종 영상·계정·설명을 확인한 후 별도로 사용자 확인을 받는다.
