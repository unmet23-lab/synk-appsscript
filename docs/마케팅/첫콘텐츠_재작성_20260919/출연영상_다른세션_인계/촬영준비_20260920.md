# L1·S1 촬영 준비

2026-09-20 · 현행 인계 원고 기준. **촬영본 미전달 / 대본·자료 준비 단계**.

## 유호가 할 일

**같은 자리에서 대본 두 묶음을 찍으면 된다.** 계정 일곱 곳마다 인사를 다시 찍지 않는다. 옷·배경·카메라 위치를 바꿀 필요도 없다.

| 영상 | 읽을 내용 | 완성 길이 가늠값 | 재사용 |
|---|---|---|---|
| [L1 대본](L1_LAB_촬영원고.md) | 카페 상황 → 먼저 시도 → 예문·따라 말하기 → 가게에서 재시도 → 마무리 | 약 55~75초, 학습자 연습 시간 포함 | LAB YouTube `@synkkorean`, Instagram·TikTok `@synk.mn` |
| [S1 대본](S1_유호_촬영원고.md) | 유호 소개 → SNS 커버에서 발견한 문제 → 재배치 → 시청자 확인 항목 → 마무리 | 약 55~75초 | YouTube·Instagram·TikTok·Naver Clip `@yuhobuilds` |

이 길이는 아직 낭독을 듣지 않은 예상이다. 두 편 합계 약 2분 안팎의 완성본을 목표로 하며, 녹화 시간은 실수·쉼·대본 확인 때문에 더 길어진다. 준비와 테스트를 포함해 15~25분 정도를 잡는 일정 제안이다. 정해진 시간 안에 찍어야 한다는 뜻은 아니다.

## 촬영 순서

1. **같은 자리에서 20~30초 테스트.** L1 첫 문단과 예문을 한 번 읽고 잠깐 쉰다. 실제 녹음으로 목소리·입 모양·얼굴 밝기·초점·실내 조명 깜빡임을 확인한다. 테스트가 깨끗하면 해당 구간을 본편에 써도 된다.
2. **L1을 네 문장 묶음으로 읽는다.** 한 번 녹화를 켜고 A→B→C→D로 이어가도 된다. 묶음 사이 1~2초 쉬고 대본을 본 뒤 렌즈로 돌아온다. 학습자가 생각하는 4~6초는 편집으로 넣으므로 그만큼 기다리며 찍지 않는다.
3. **L1 예문 한 문장만 조금 느리게 한 번 더.** “죄송한데, 다시 한번 말씀해 주세요.” 전체 재촬영 대신 이 짧은 예비 녹음만 확보한다. 자연스러운 보통 속도가 좋으면 느린 녹음은 쓰지 않아도 된다.
4. **자리 그대로 S1을 읽는다.** 소개·문제와 수정·확인 항목·마무리로 나눈다. 가운데 문제와 수정 설명에는 전후 이미지를 덮어 편집할 수 있어, 대본을 보는 순간까지 모두 다시 찍을 필요는 없다.
5. **마지막으로 같은 위치에서 5초 조용히 녹음한다.** 주변 소리를 연결·정리하는 데 쓸 수 있다. 실수한 경우에는 해당 문장 시작부터 다시 말하고 나머지는 이어간다.

필요한 본 촬영은 두 대본이다. 예비 녹음·테스트·파일 분할을 별도 콘텐츠나 의무 테이크 수로 세지 않는다. 별도 카페 방문, 가게 촬영, 노트북을 만지는 손 연기, 걷는 모습은 필요하지 않다.

## 화면과 소리

- 이번 두 편은 **세로 9:16** 구도로 촬영한다. 머리 위에 약간의 여백, 얼굴부터 가슴 아래 정도를 담는다. 렌즈는 눈높이에 맞추고 흔들리지 않게 둔다. 얼굴과 입은 가운데 영역에 남겨 자막과 우측 플랫폼 버튼이 겹치지 않게 한다.
- 창가 빛이나 부드러운 조명으로 얼굴이 잘 보이는 자리, 정돈된 배경이면 충분하다. 뒤에 큰 로고나 특별한 세트를 만들 필요는 없다. 대본을 띄울 다른 화면이 있다면 렌즈 가까이 둔다.
- 피부를 매끈하게 바꾸는 효과나 배경을 흐리게 만드는 효과를 새로 켜지 않는다. 녹음은 가까운 위치에서 또렷하게 받고 과한 웃음·높은 텐션을 만들지 않는다. L1은 기다려 주는 수업, S1은 직접 한 일을 설명하는 대화로 읽는다.
- 카메라 기종·앱·기존 프레임레이트·색 설정은 이번 인계에 실제값이 없다. 기존에 잘 쓰던 설정으로 테스트하고, 원본을 받은 뒤 해상도·프레임·색 정보를 확인한다. 새 로그 설정이나 보정 프리셋을 임의로 확정하지 않는다.
- 두 출연 영상은 유호의 실제 동시 녹음이 우선이다. Typecast 구독이 있어도 얼굴에 다른 목소리를 자동으로 붙이지 않는다. 화면 자료 위 설명도 같은 녹음을 이어 쓰면 추가 합성이 필요 없다.
- 배경음은 지금 촬영에 넣지 않는다. L1은 발음과 연습 시간이 선명한지 먼저 듣고 무음 유지 여부를 결정한다. S1도 음성을 편집한 후 필요한 경우에만 BGM을 고른다. 현재 BGM 생성·권리 확인·믹싱은 미실행이다.

## 촬영본을 전달할 때

편집·메신저 압축 전 원본을 그대로 전달한다. 이름을 고른다면 `L1_take01`, `S1_take01`, `L1_예문_느리게` 정도면 충분하다. 하나의 긴 파일에 두 편을 찍었다면 구분되는 위치를 알려주면 되고, 촬영본을 억지로 잘라 다시 내보낼 필요는 없다.

자료를 받으면 원본을 보존하고, 첫 20~30초에서 얼굴·목소리·초점·색·깜빡임을 확인한다. 그다음 실제 발화에 맞춰 컷과 자막을 배치한다. 현재는 원본의 존재나 품질을 검수한 상태가 아니다.

## 이번에 고친 것과 남은 일

- L1: 말하기 쉬운 문장으로 줄이고, 예문 뒤 `따라 말하기` 안내를 추가했다. 몽골어에도 같은 안내와 가게 직원의 말을 놓친 상황을 보완했다. 선시도·예문·전이 순서는 유지했다.
- S1: 긴 문장을 끊고, `업로드 미리보기`로 사실 범위를 정확히 했다. 기록에 있는 크기 축소·중앙 배치·아래 이동을 말로 자연스럽게 연결했다.
- 남은 일: 실제 촬영 → 촬영본 확인 → L1 몽골어 감수·자막 → 영상 편집·청취·실제 재생 검수 → 사용자에게 최종 영상·게시 대상 제시.
- **공개 업로드는 별도 사용자 확인 후 진행한다.** Naver Clip `@yuhobuilds` 소개는 S1을 실제 업로드할 때 기존 계정에서 함께 확인·수정한다. 지금 계정이나 소개를 바꾸지 않는다.
- 얼굴 없는 L2 등 12종의 원고·카드·영상·음성은 다른 작업 담당이며 수정하지 않는다. 이번 요청에 커밋·배포는 포함되지 않았다.
