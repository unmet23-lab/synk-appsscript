## 다른 제작 세션에 전달할 내용

> 이 폴더의 L1과 S1을 출연 영상으로 제작한다. 본문 원고와 화면 구성을 함께 읽고, 실제 유호의 촬영본을 사용한다. 두 편은 같은 자리에서 문장별로 나눠 찍을 수 있다. 계정마다 별도 인사나 촬영을 추가할 필요는 없다. 완성본은 각각 3계정·4계정에 맞춰 제목·표지·링크를 조정한다. AI 디지털 트윈이나 목소리 복제는 별도로 요청된 것이 아니다. 얼굴 없는 12종의 원고·카드·영상은 이 세션의 제작 범위가 아니다. 원고 교체 전 보관본을 사용하지 않는다.

촬영 한 번·원고 두 묶음·편집본 두 편·배포 계정 일곱 곳은 서로 다른 수치다. 실제 낭독과 쉬는 시간을 듣고 길이를 정하며, 아래 초안의 장면 수를 고정된 촬영 테이크 수로 강제하지 않는다.
