# L1 · 카페에서 잘 못 들었을 때

촬영용 원고 초안. 영상 제작은 다른 세션. LAB YouTube·Instagram·TikTok에 같은 핵심 영상을 사용한다.

## 말할 내용

카페에서 주문하는데, 직원의 말을 잘 못 들었어요.

다시 말해 달라고 어떻게 부탁할까요?

먼저 한국어로 한 번 말해 보세요.

[4~6초 정도 기다린다. 이때 화면에 정답을 먼저 보여주지 않는다.]

이렇게 말할 수 있어요.

“죄송한데, 다시 한번 말씀해 주세요.”

[한 번 자연스럽게 말한 뒤, 따라 말할 시간을 둔다. 필요하면 같은 문장을 조금 천천히 한 번 더 녹음한다.]

이번에는 카페가 아니라 가게에 있다고 생각해 보세요.

점원의 말을 못 들었어요. 예문 없이 다시 부탁해 볼까요?

[예문을 가리고 4~6초 정도 기다린다.]

다른 표현으로 말해도 괜찮아요. 막혔다면 앞의 예문을 보고 한 번 더 해보세요.

## 화면·촬영 구성

| 구간 | 유호 촬영 | 화면 자료 |
|---|---|---|
| 상황 | 첫 세 문장, 카메라를 보며 설명 | ‘카페에서 잘 못 들었을 때’ 제목. 하단에 유호 · SYNK LAB. 필요하면 승인 카페 그림 |
| 첫 시도 | 기다리는 표정 또는 장면 자료로 전환 | 상황 안내와 먼저 말해 보라는 문구만. 답·자동 평가 UI 없음 |
| 표현 | 한국어 문장을 또렷하게 말하는 모습 | 실제 말하는 시점부터 한국어 예문과 몽골어 뜻 표시 |
| 다시 시도 | 가게 상황으로 바꾸는 안내 | 정답을 지우고 가게 상황을 글로 안내. 실제 점원 촬영이 있다고 꾸미지 않음 |
| 마무리 | 마지막 안내 | 예문을 다시 볼 수 있는 앞 구간 안내. 과장된 성공 판정 없음 |

## 몽골어 안내 자막 초안

- 상황: Та кафед захиалга өгч байна. Ажилтны хэлснийг сайн сонссонгүй.
- 첫 시도: Дахин хэлж өгөхийг солонгосоор яаж хүсэх вэ? Эхлээд өөрөө хэлж үзээрэй.
- 표현 뜻: Уучлаарай, дахин нэг удаа хэлж өгнө үү.
- 상황 전환: Одоо дэлгүүрт байна гэж төсөөлөөрэй. Жишээг харахгүйгээр дахин хэлж өгөхийг хүсээрэй.
- 마무리: Өөр үгээр хэлсэн ч болно. Гацвал өмнөх жишээг хараад дахин хэлээрэй.

몽골어 원어민 감수 전이다. 별도 몽골어 촬영은 요구하지 않는다. 한국어를 듣기 전에 상황과 해야 할 일을 이해할 수 있도록 안내 자막을 배치한다.

## 게시 설명 초안 · 몽골어

Кафед эсвэл дэлгүүрт ажилтны хэлснийг сайн сонсоогүй бол яах вэ? Эхлээд өөрийнхөөрөө солонгосоор хэлээд үзээрэй. Дараа нь жишээг харж, өөр нөхцөлд дахин хэлээрэй.
