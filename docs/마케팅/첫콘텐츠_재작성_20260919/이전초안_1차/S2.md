# S2 · Threads / X 공통

새 원고 초안 / 외부 미게시. 두 계정에 같은 본문과 전후 이미지를 사용한다.

## 게시 본문

SNS 커버는 원본보다 올린 화면에서 볼 게 많더라고요. SYNK 커버도 글자와 소품이 잘려서 배치를 다시 잡았습니다.

지금 쓰는 커버도 휴대폰에서 열어보세요. 글자 잘림, 프로필과 겹침, 글씨 크기. 이 세 가지부터요.

## 첨부·제작 메모 · 게시 제외

Behance 수정 전후 업로드 원본을 비교한다. 원본 이미지 비교라고 표시하며 실제 플랫폼 캡처처럼 꾸미지 않는다. 이전 카드의 제목·본문은 사용하지 않고 아래 문구로 교체한다.

- 비교 카드 제목: 올렸더니 잘린 커버, 배치를 다시 잡았습니다.
- 왼쪽: 수정 전 원본
- 오른쪽: 수정 후 원본
- 하단: 업로드용 이미지 비교

플랫폼 입력 단계에서 공백·줄바꿈·URL 포함 실제 글자 제한을 재확인한다. 본문에 아직 없는 상세 글 주소를 넣지 않는다.
