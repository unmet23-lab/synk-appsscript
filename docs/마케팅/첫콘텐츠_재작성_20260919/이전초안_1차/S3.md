# S3 · LinkedIn 개인 양유호

새 원고 초안 / 외부 미게시.

## 게시 본문

AI를 활용해 SYNK의 홈페이지와 콘텐츠를 만들고 있는 양유호입니다.

최근에는 SNS 프로필과 커버를 정리했습니다. 같은 브랜드로 보이게 만드는 것도 중요했지만, 막상 올려 보니 플랫폼마다 다르게 손봐야 했습니다.

Behance에서는 오른쪽 소품이 잘리고 위쪽 메뉴가 커버 일부를 가렸습니다. 글자와 소품을 가운데로 모으고 아래로 내려 배치를 다시 잡았습니다. 프로필의 크림색 배경은 흰 페이지와 이어지도록 흰색으로 바꿨습니다. 펠트와 자수, 유리의 느낌은 남겼고요.

이 작업에서 제가 맡은 건 디자인 방향을 정하고, AI로 만든 이미지와 기존 자산을 골라 실제 화면에 맞게 수정하는 일이었습니다. 새 이미지를 만드는 것뿐 아니라 무엇을 남기고 어디를 고칠지 결정하는 시간이 꽤 중요했습니다.

여러 채널의 이미지를 준비하고 있다면 원본을 나란히 보는 것과 별도로, 실제 프로필에서도 확인해 보세요.

- 중요한 글자가 잘리지 않는지
- 프로필 사진이나 메뉴가 내용을 가리지 않는지
- 작은 화면에서도 무엇을 하는 계정인지 읽히는지

같은 이미지를 모든 곳에 넣기보다, 이 세 가지를 맞추면서 브랜드의 재질과 색을 유지하는 쪽으로 정리했습니다.

앞으로도 SYNK를 만들며 시도한 방법과 실제로 고친 부분을 공유하겠습니다. 기업·기관 AI 교육·컨설팅과 브랜딩도 준비하고 있습니다.
