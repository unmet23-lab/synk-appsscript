# 새 원고 12종 · 내용과 검수 결과

2026-09-19. 새로 쓴 원고 12개를 모두 읽고 실제 원자료·대상·문장·효용·중복·마무리를 대조했다. **10개 수정, LAB 2개는 한국어 구성 유지**. 몽골어 원어민 감수, 실제 조판·영상·낭독 검수, 게시 확인은 완료하지 않았다. ‘검수’는 AI가 원고를 읽고 실제 근거와 대조한 편집 검토이며 사람 감수나 성과 측정을 완료했다는 뜻이 아니다.

현재 제작 범위는 얼굴 없는 12종이다. 출연 영상 2편은 [별도 원고 인계](출연영상_다른세션_인계/README.md)로 분리했으며 영상은 다른 세션에서 제작한다.

## 먼저 고친 문제

1. **S3와 S6의 설명이 비슷했다.** 개인 LinkedIn은 맡은 일·공통/개별 디자인 판단, Tistory는 배경·잘림·문구를 실제로 수정한 순서로 나눴다.
2. **S4·S5·C2의 PDF 설명이 코드보다 넓었다.** 행 높이 값을 따로 고친 것처럼 읽히던 부분을 수정했다. 실제 변경은 한 줄 고정·넘침 숨김을 없애고 줄바꿈을 허용한 것이다. 원본 코드, 실제 PDF 렌더, [white-space](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/white-space)·[overflow](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/overflow) 설명을 대조했다.
3. **비교 이미지도 문제가 있었다.** 보관본 `table-after.png`는 ‘02 검수’ 행의 앞부분이 잘린 크롭이었다. 같은 항목의 전체가 보이도록 원본 PDF에서 다시 구성해야 한다. 원고에 사용 금지를 적었으며 새 비교 이미지는 아직 제작하지 않았다.
4. **S7·C1·C2에 내부 안내가 본문처럼 들어갔다.** 수치 집계·서비스 상태에 관한 중복 설명은 줄이고 필요한 사실만 남겼다. 준비 중인 서비스와 디지털 제작 방식은 명확히 표시했다.
5. **C2는 언어와 응답 경로가 불분명했다.** 몽골어 도입·학습·마무리를 연결하고, 확인되지 않은 댓글·이메일 수집 대신 독자가 바로 할 수 있는 연습으로 마무리했다.

## 중복을 줄인 방식

S2·S3·S6·S7·S8은 같은 SNS 디자인 사례지만 각각 **짧은 발견 / 맡은 일과 판단 / 자세한 제작 과정 / 전체 포트폴리오 / 대표 이미지**다. 같은 이야기를 매번 처음부터 소개하지 않는다. S4·S5는 **짧은 시연 / 상세 방법과 요청문**으로 나눴다. L2·L3는 같은 카드를 재사용한다. C2는 전체 내용을 다시 싣는 대신 바로 해볼 샘플을 골라 넣는다.
