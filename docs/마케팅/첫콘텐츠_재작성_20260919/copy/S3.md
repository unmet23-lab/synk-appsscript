# S3 · LinkedIn 개인 양유호

새 원고 초안 / 외부 미게시.

## 게시 본문

AI를 활용해 SYNK의 홈페이지와 콘텐츠를 만들고 있는 양유호입니다.

최근에는 SNS 프로필과 커버를 정리했습니다. 한국어 학습, AI 활용, 제작 기록을 다루는 계정들이 같은 브랜드로 보이면서도 각자 무슨 채널인지 설명해야 하는 작업이었습니다.

먼저 공통으로 유지할 것과 계정마다 바꿀 것을 나눴습니다.

- 공통으로 유지할 것: 로고, 펠트·자수·유리 표현, 흰색과 검정색 바탕.
- 계정마다 바꿀 것: 방문자에게 설명할 내용, 소품, 이미지가 잘리는 영역에 맞춘 배치.

제가 맡은 일은 이 방향을 정하고, AI로 생성한 이미지와 기존 자산을 골라 실제 화면에 맞게 수정하는 것이었습니다. Behance에서는 소품이 잘려 로고와 문구를 중앙으로 모았습니다. 흰 페이지에서 색이 도드라지던 프로필 배경은 흰색으로 바꿨고요.

브랜드 이미지를 여러 곳에 적용할 때는 먼저 이 두 목록을 적어보면 좋겠습니다. 무엇을 통일할지, 무엇은 달라져야 하는지요. 모든 계정의 문구와 배치를 같게 만드는 것만이 통일성을 유지하는 방법은 아니었습니다.

이곳에는 SYNK를 만들면서 맡은 일과 그 과정에서 내린 판단을 기록하겠습니다. 기업·기관의 AI 교육·컨설팅과 브랜딩도 준비하고 있습니다. 관련 협업을 고민하고 계시다면 어떤 일을 만들고 싶은지 이야기 나눠 주세요.
