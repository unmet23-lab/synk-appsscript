## 게시 본문

SYNK의 SNS 커버를 정리하면서 처음부터 잘 맞았던 건 아닙니다. 원본에서는 괜찮아 보이던 이미지도 프로필에 올리면 글자가 위로 몰려 보이거나 소품이 잘렸습니다. 흰 페이지에 놓고 보니 배경이 누렇게 느껴지는 곳도 있었고요.

이번에는 새 그림을 계속 추가하기보다, 만든 이미지를 실제로 올릴 자리에 맞추는 데 집중했습니다.

### 흰 페이지 위에서는 배경 차이가 더 보였습니다

프로필 이미지의 크림색 바탕이 페이지의 흰색과 만나니 경계가 도드라졌습니다. 몽글의 표정이나 구도는 그대로 두고 바탕만 흰색으로 바꿨습니다.

펠트의 색과 질감까지 지울 필요는 없었습니다. 바탕이 정리되니 오히려 캐릭터가 더 분명하게 보였습니다. 아래 두 장은 같은 캐릭터와 배치에서 바탕을 바꾼 원본 비교입니다.

### 커버는 플랫폼에서 잘린 뒤의 모습이 중요했습니다

Behance에 처음 올렸을 때는 오른쪽 소품이 잘렸고, 상단 메뉴도 커버 일부를 가렸습니다. 이미지 파일 전체를 채우는 배치가 실제 화면에는 맞지 않았던 겁니다.

기존 로고와 문구, 소품을 가운데로 모으고 전체 묶음을 아래로 옮겼습니다. 새로운 디자인으로 바꾸기보다 같은 재료의 위치를 조정했습니다.

아래 비교는 실제 플랫폼 화면을 재현한 그림이 아니라, 업로드에 사용한 이미지 원본입니다. 적용 후에는 공개 프로필을 다시 열어 로고와 문구, 소품이 보이는지 확인했습니다.

### 모든 계정에 같은 문장을 쓰지는 않았습니다

한국어 학습 채널과 AI 활용 채널은 방문자가 궁금해하는 내용이 다릅니다. 재질과 로고는 이어지게 만들되, 커버 문구는 각 계정이 무엇을 보여주는지 알 수 있도록 바꿨습니다.

흰색과 검정색 바탕을 나눠 쓰고, 펠트·자수와 유리 표현은 공통으로 남겼습니다. 같은 브랜드라는 느낌은 유지하면서도 계정마다 설명할 내용은 달라야 했습니다.

### 다음 커버를 만들 때도 확인할 순서

1. 이 계정에서 무엇을 볼 수 있는지 짧게 설명합니다.
2. 로고, 글자, 소품 중 꼭 보여야 할 것을 먼저 정합니다.
3. 업로드 미리보기에서 잘리거나 가려지는 부분을 확인합니다.
4. 저장한 뒤 실제 프로필을 다시 엽니다.
5. 휴대폰에서도 문구를 읽을 수 있는지 확인합니다.

지금 쓰는 커버도 실제 프로필에서 열어보세요. 소품이 잘렸다면 위치를, 글이 안 읽힌다면 크기를, 페이지와 경계가 도드라진다면 바탕색을 먼저 살펴보면 됩니다. 이번 작업도 그렇게 문제를 나누고 필요한 부분부터 고쳤습니다.

## 첨부·근거 · 게시 제외
