## 핀 제목

펠트·자수·유리로 만든 SYNK SNS 커버

## 핀 설명

흰색·검정색 바탕, 펠트 소품, 자수 로고, 투명 유리 표현을 조합한 SYNK SNS 디자인입니다. 로고와 재질은 유지하고 계정마다 문구와 배치를 달리했습니다. 여러 채널을 디자인할 때 참고할 수 있도록 밝은 바탕과 어두운 바탕의 조합, 글자 주변 여백, 로고를 강조한 유리 표현을 함께 보여줍니다.

## 첨부·링크 메모 · 게시 제외

승인 커버 대표 이미지를 사용하되, 새 이미지 문구만 추가한다. 글자가 많은 설명형 카드를 별도로 늘리지 않는다. S7의 실제 공개 프로젝트 주소가 생긴 후 해당 주소를 연결한다. 아직 없는 프로젝트 주소를 만들거나 회사 홈페이지를 전체 프로젝트인 것처럼 안내하지 않는다. 이 계정의 독자 행동은 이미지 저장·상세 프로젝트 보기이며 별도 댓글 과제를 붙이지 않는다.
