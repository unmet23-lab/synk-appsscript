2026-09-19 사용자 요청: 앞서 만든 12종 원고는 교체하고 새로 쓴다. 승인 디자인·학습 소재·실제 작업 증거는 보존한다. 문체 교본이나 일괄 문장 치환 규칙을 새로 만들지 않는다.

이 폴더는 **새 원고 초안**이다. 이전 카드·영상에 새 글이 반영된 상태나 외부 발행 완료를 뜻하지 않는다. 다른 작업의 제작·실행 중단 확인 후 기존 제작 묶음을 [이전 원고 보관](../첫콘텐츠_제작_20260919_이전원고보관/)으로 옮겼다. 옛 원고를 현재 게시용으로 사용하지 않는다.

## 재사용 관계

- 완성본 공통 사용: S2는 Threads·X, S4는 synkbrief YouTube·Instagram·TikTok. 12종을 15계정에 배치하는 이유다.
- 같은 자료로 별도 편집: 학습 카드 → L2·L3·C2, SNS 디자인 사례 → S2·S3·S6·S7·S8, PDF 시연 → S4·S5·C2. 독자의 질문이 같으면 새 글을 더 만들 필요가 없다.
- 출연 영상 L1·S1은 사용자 후속 요청에 따라 [다른 세션 인계용 원고](출연영상_다른세션_인계/README.md)만 별도로 작성했다. 두 편의 영상 제작은 다른 세션에서 하며 여기서는 얼굴 없는 12종을 진행한다. 배포는 각각 3계정·4계정이다.

## 확인 범위

- 사실 자료: 현행 마케팅 정본·계정 정본·SNS 반영 기록과 기존 PDF 시연 파일. 고객 실적·조회수·시간 절감·수익은 주장하지 않는다.
- PDF는 글자가 잘리도록 일부러 만든 설명용 예시다. 실제 AI 실패나 고객 문서로 묘사하지 않는다.
- 몽골어는 새 편집 초안이며 원어민 감수 전이다. 한국어 검토문은 게시 본문에 중복 삽입하지 않는다.
- 카드·영상·음성 재제작, 플랫폼 글자 수 실측·입력 확인, 외부 게시 및 이메일 발송은 미완료다.
- 상세 프로젝트가 공개되기 전에는 Pinterest에 가짜 프로젝트 링크나 홈페이지를 전체 프로젝트인 것처럼 연결하지 않는다.
- 이전 제작기의 카드·영상은 이 원고의 첨부 완성본으로 사용하지 않는다. 시각 원본과 검증 자료만 재사용한다.

## 진행 기록

- 2026-09-20 사용자 요청으로 이 작업을 종료한다. 재개 위치는 `원고별_검수와_구성.md`이며 다음 단계는 사용자 문장 피드백, 몽골어 감수, 새 카드·비교 화면·음성·영상 제작이다. 출연 2편은 별도 인계 원고로 다른 세션에서 제작한다. 네이버 모바일 배경·Clip 소개는 각각의 콘텐츠 업로드 때 수정한다. 이번 종료에는 SNS 게시·원격 push·서비스 배포를 포함하지 않는다.

- 「마케팅 SNS 계정 전수 정리」에서 제작 에이전트 3개 중지, 관련 실행 종료, 외부 게시·음성 생성 없음이라는 회신을 받았다.
- 기존 제작 묶음 전체를 `첫콘텐츠_제작_20260919_이전원고보관`으로 이동했다. 원고, 문구가 들어간 카드·영상·검토 페이지, 코드·증거·자산 사본 등 **160개 파일 / 40,619,701바이트**의 이동 전후 SHA-256이 모두 일치했다. 복구 가능한 보관이며 승인 디자인 원본이나 공개 프로필을 삭제한 것이 아니다.
- 새 원고 12종, S4 새 내레이션, LAB 카드 새 문구를 이 폴더에 작성했다. 공개 게시 없음.
- 2차 검수 전 14개 원고·내레이션·카드 문구 파일을 `이전초안_1차/`에 보관하고 SHA-256 일치를 확인했다. `copy/`만 현행이다.
- 출연 영상 2편의 말할 내용과 화면 구성·재사용 대상을 별도 인계 폴더에 작성했다. 촬영·영상 제작 없음.
