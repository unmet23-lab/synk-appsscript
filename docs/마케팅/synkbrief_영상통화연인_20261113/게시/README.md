## 올라가는 글(세 판 같은 본문 — 정본은 판 폴더의 원고.json)

밤마다 세워 둔 택시에서 영상통화를 하는 기사님을 떠올려 봤어요. 「고생했어요」 한마디가 하루의 끝인 사람이요. 실제 사건을 바탕으로, 지어낸 인물로 재연했어요.

[실제로 있었던 일]
· 2026년 1월 울산경찰청 발표예요. 캄보디아에 거점을 둔 조직이 가상의 여성 인물을 만들어 SNS · 채팅 앱으로 접근하고, 매일 대화하며 호감을 쌓은 뒤 주식 · 가상자산 투자를 권한 것으로 경찰은 보고 있어요.
· 남의 SNS 사진을 도용해 딥페이크(AI 합성)로 만든 영상을 쓰고 화상채팅까지 동원했고, 가짜 투자 사이트 · 앱으로 한국인 100여 명에게서 약 120억 원을 가로챈 혐의예요. 83명이 입건돼 57명이 붙잡혔고, 투자 전문가 행세를 한 부부는 구속 상태로 검찰에 넘겨졌어요(재판으로 확정된 것은 아니에요).
· 영상 속 택시 기사 · 수사관 · 화면 속 여성은 모두 AI로 만든 가상 인물이고 장면은 각색이에요. 보도는 「화상채팅」이라고만 전했고, 밤마다 영상통화를 하는 장면 · 같은 얼굴 사진이 여러 장 놓이는 장면 · 보낸 금액은 재연을 위해 지어낸 거예요. 실제 피해자 · 수사관 · 사건 속 인물의 모습이나 목소리가 아니에요.

[지키는 법 — 경찰청 사이버안전지킴이 「로맨스스캠」 예방수칙]
· 인터넷으로만 연락하는 사이라면, 부탁처럼 꺼내는 돈 요구에 입금하지 않아요.
· 이미 보냈다면 입금한 은행에 지급정지 · 반환이 되는지 바로 묻고, 입금 내역 · 대화 내역을 챙겨 경찰서에 신고해요.
· 금융감독원도 SNS에서 접근한 이성이 코인 투자 등을 권하면 「반드시 사기를 의심하세요」라고 안내해요(2025년 7월 보도자료).
· (SYNK 브리핑이 덧붙이는 말) 영상통화로 얼굴을 봤어도 마찬가지예요.

온라인에서만 만난 사람에게 돈 얘기를 들은 적 있나요?
