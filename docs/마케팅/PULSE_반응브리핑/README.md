# PULSE 업종 반응 브리핑

> 2026-10-30 시험. 유호님이 「사람들이 무엇에 관심 있고 무엇에 반응하는지 파악하는 회사 LLM(sLLM)」을 PULSE 고객에게 주고 싶다고 하셨고, Claude는 작은 모델을 따로 만들지 않고 **공개 반응 자료 + Claude 해석 + 광고 제안**으로 PULSE 광고 제작에 붙이는 쪽을 권했다. 이 문서는 그 첫 견본의 결과와 다시 하는 법이다. 상품으로 굳힐지는 아직 정하지 않았다([트랙](../../_ops/트랙.md) §1).

**견본:** [여성 아우터 반응 브리핑](https://claude.ai/artifact/GNzNe7TNPvacyzTHdBL9uJ) — 숫자마다 출처(자료 파일 · 계산)가 붙는 페이지. 비공개라 다른 사람은 페이지의 공유 메뉴에서 공유해야 열린다. 붙인 자료 파일은 페이지를 여는 사람 누구나 읽을 수 있다(공개 자료를 묶은 것뿐, 댓글 원문은 없음).

## 무엇을 주나

| 때 | 이름 | 내용 | 상태 |
|---|---|---|---|
| 만들기 전 | 업종 반응 브리핑 | 누가 사나 · 언제 찾나 · 무엇에 반응했나 · 경쟁 광고가 무엇을 말하나 → 고객이 가려워하는 곳 셋 + PULSE가 만들 광고 셋 | 10-30 견본 하나 |
| 만든 뒤 | 광고 반응 리포트 | 납품한 광고의 숫자 · 랜딩 페이지 반응(어디서 멈추고 나가나) · 댓글 → 다음 편에서 바꿀 셋 | 안 함 — 고객 랜딩 측정 코드와 광고 계정 보기 권한이 있어야 한다 |

분석만 따로 파는 상품이나 고객사 상담 자동화는 기존 나눔대로 SHIFT 몫이다(결정 10-05 「시장조사·제품 테스트는 SHIFT」). PULSE에는 「광고 + 반응」 묶음으로 붙인다.

## 10-30 시험 — 여성 겨울 아우터

받는 사람을 「여성 겨울 아우터를 파는 온라인 브랜드」로 두고, 공개 자료만 썼다. 벽시계 약 45분(자료 길 찾기 포함), 돈 0원(유튜브 Data API 하루 몫의 약 15%).

| 자료 | 범위 |
|---|---|
| 네이버 검색어 트렌드(여성) | 패딩 · 경량패딩 · 롱패딩 · 숏패딩 · 코트, 2023-01-01~2026-10-29 하루 값 |
| 네이버 쇼핑인사이트 | 여성의류 › 아우터 — 인기 검색어(월 · 주 · 연령 · 하위 분야), 연령 · 기기 비중, 주별 클릭 |
| 유튜브 쇼츠 | 검색어 12개, 09-15 이후 · 3분 이하 · 조회 1만 이상 252편(여성 쪽 239편), 채널 평소 대비 배수 |
| 쇼츠 댓글 | 여성 쪽 51편의 상위 댓글 728개(채널 주인 댓글 뺌) |
| 메타 광고 라이브러리 | 대한민국 · 게재 중 · 노출 순, 여성 패딩 · 코트 · 아우터 278개 |

찾은 것(숫자는 견본 페이지가 자료에서 계산해 보인다):

- 패딩 · 코트 검색은 세 해 모두 11월 13~25일 주에 가장 높았고, 경량패딩은 그보다 앞선 10월 16일~11월 4일 주였다. 올해 같은 주 패딩 검색은 작년의 48%다.
- 네이버 쇼핑에서 여성 아우터를 누르는 사람의 73%가 40 · 50대, 91%가 휴대폰이다.
- 나이대를 제목에 건 쇼츠는 84%가 평소보다 3배 넘게 튀었다(전체 55%). 30초 이하가 31초 이상보다 자주 튀었다(70~77% 대 42~48%). 구독 363명 쇼핑몰의 12초 상품 영상이 10만 회를 넘겼다.
- 댓글에서 가장 많은 말은 옷 정보 요청(18%)이고, 좋아요가 몰린 댓글은 옷보다 입은 사람 이야기였다. 가격을 안 적은 영상엔 직접 찾아봤다는 불만에 좋아요가 몰렸다.
- 경쟁 광고 278개 가운데 32%가 테무 계열, 47%가 할인 · 쿠폰을 말하고 나이를 말하는 광고는 1%다. 가장 오래 돈 브랜드 광고(362일)는 고민 공감 → 한 벌 권하기 → 만든 방식 근거 순서였다.

→ 가려운 곳 셋: 나 같은 사람이 입으면? · 그래서 얼마고 어디서 사요? · 싸 보이면 어쩌지? → 제안 셋: 나이 · 키별 착용 비교, 이것 하나만 고르는 광고, 본 그대로 사게 잇기(고정 댓글 · 정해 둔 답).

한계: 유튜브는 조회 높은 순으로 모은 표본이라 튄 비율이 실제보다 높다(각도끼리 견줄 때만). 댓글 주제는 낱말로 나눠 한 댓글이 두 주제에 들 수 있다. 네이버 쇼핑은 40 · 50대 쪽으로 기울어 있어 20대가 많은 브랜드는 다른 쇼핑 앱 자료를 더해야 한다(이번엔 안 봄). 쇼핑인사이트 분류 자료는 2025-12부터만 있다. 견본은 Fable · 아르곤 검수를 받지 않았다 — 계산 36칸은 받은 자료로 다시 돌려 맞췄다(`calc_check.cjs`).

스크립트는 [시험_20261030](시험_20261030/)에 시험 때 그대로 두었다(도구가 대신한다). 안의 임시 폴더 경로와 ego 작업 공간 번호(76)는 그때 것이라 다시 쓸 때 바꾼다. 남의 영상 숫자 · 댓글 원자료는 저장소에 넣지 않는다.

| 5 | `analyze.py` · `meta_parse.py` | 각도 · 길이 · 댓글 주제 · 광고 주제 집계 |
