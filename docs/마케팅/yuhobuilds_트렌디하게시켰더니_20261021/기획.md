# yuhobuilds 「AI한테 "트렌디하게" 시켰더니」 · 기획·대본·콘티

> 10-21 07시 예약 작업 「synk-daily-yuhobuilds」가 만든다. 비축 0일이라 오늘 두 편(이 시의성 편 + 상시 편 하나, [예약큐](../../../tools/예약큐.js)). 만들기와 올릴 묶음까지만 하고, 게시는 14:00 「오늘 편 게시」 세션이 유호님 「올려」 뒤에 한다.

## 1. 왜 이 편인가

- **시청자가 얻을 것:** AI한테 영상 모션을 시킬 때 「트렌디하게」 대신 붙일 **요청 다섯 줄**. 많이 본 영상 네 편과 모션 디자이너들의 평에서 나온 규칙을 AI한테 그대로 줄 수 있는 말로 줄였다. 끝에서 화면에 다섯 줄 전부를 보여 주고(저장용), 캡션·설명에 숫자까지 넣은 긴 판을 둔다.
- **실화는 증거로:** 「트렌디하게」 → AI가 효과를 다 넣음(v7c) → 「완전 AI 같다」 → 많이 본 영상은 반대(글자는 가만히, 화면 속 입력과 카메라가 움직임) → 뺀 판(v8, 어제 공개). 전·후 화면이 다 우리 렌더라 남의 영상은 한 장도 안 쓴다(제목·조회수만 글로).
- **깨달음 하나:** AI는 「트렌디」를 **더하기**로 알아듣는다. 많이 본 영상은 **빼기**였다.
- **대상:** AI로 쇼츠·릴스를 만드는 1인 기업가, 처음 AI한테 영상을 시켜 보는 사람(채널과 발행 문서의 yuhobuilds 대상). 코드를 몰라도 요청 다섯 줄은 그대로 붙이면 된다.
- **겹침 확인:** 최근 편 — 10-17 세션 공유, 10-17 노트북 이사, 10-19 자동 DM 말투, 10-20 SNS 업로드 자동화(v8). 이번 편은 v8의 **움직임을 고친 과정**이 주제라 내용이 겹치지 않는다. v8 화면은 2초 남짓 한 번만 「다시 만든 판」으로 짧게 쓴다(같은 영상을 다시 올리지 않는다). 「AI 티」라는 말은 10-19 편 제목에 있었으므로 이번 제목의 중심 낱말은 「트렌디하게」로 둔다.
- **공개 확인:** v7c는 공개하지 않은 우리 렌더, v8은 10-20 공개본. 유호님 말은 내레이션에서 1인칭(유호)으로 옮기고 원문 메시지 화면은 쓰지 않는다.
