# Tistory(yuhobuilds.tistory.com) 짧은 적용기 원고 — 「트렌디하게」 시켰더니(2026-10-21)

> 영상과 같은 실화를 「AI에게 그대로 붙일 요청문」으로. 올리기는 유호님 「올려」 뒤(이 세션은 올리지 않음). 근거는 [기획](../기획.md) 「사실 대조」와 [모션 조사](../../yuhobuilds_1일1업로드_첫날_20261020/모션조사_20261020.md). 첫머리에 유튜브 쇼츠를 넣는다(공개 뒤).

**제목:** AI한테 "트렌디하게" 시켰더니 더 AI 같아졌다 — 모션 요청 다섯 줄

**본문**

AI로 짧은 영상을 만들다가, 움직임을 "트렌디하게" 바꿔 달라고 했습니다. 돌아온 판은 낱말마다 흐릿하게 튀어나오고, 강조할 낱말마다 형광펜을 긋고, 숫자는 「2편」에서 「3편」으로, 「3시」에서 「7시」로 세어 올라갔어요. 효과 하나하나는 요즘 영상에서 본 것들인데, 한 화면에 다 모이니 보자마자 "더 AI 같다"는 말이 나왔습니다.

## 많이 본 영상은 반대였다

그래서 조회수가 큰 제품 소개 영상을 1초 간격으로 넘겨 가며 봤습니다(유튜브 조회 2026-10-20 기준).

- 노션 3.0 소개(1,575만 회): 머리글은 한 덩어리로 놓이고, 크게 움직이는 글자는 사람이 입력하는 글뿐이었어요. 지금 일하는 판 하나에만 테두리가 켜지고 옮겨 갑니다.
- 커서 2.0 소개(946만 회): 가운데 짧은 문장 카드가 2~3초 머물고, 실제 화면은 컷으로 넘어갑니다. 흐림·튕김·색 강조가 없어요.
- 리니어 Diffs 소개: 화면을 비스듬히 기울여 카메라가 천천히 미끄러집니다. 색은 결정 단추 하나에만.

모션 디자이너 커뮤니티(r/MotionDesign)에는 이런 제목의 글도 있었습니다. "If every word moves, none of the words feel important" — 모든 낱말이 움직이면, 어떤 낱말도 중요해 보이지 않는다.

정리하면, AI는 "트렌디"를 효과를 **더하는** 것으로 알아들었고, 많이 본 영상은 효과를 **빼고** 움직임을 화면 속 동작에 맡겼습니다.

## AI에게 붙이는 다섯 줄

```
1. 글자는 줄 단위로만 — 낱말·글자마다 튀지 않게
2. 강조색은 한 화면에 한 곳 — 나머지 글은 한 색으로
3. 장면 전환은 컷 — 페이드는 끝 화면에만
4. 움직임은 클릭·입력·화면 확대가 맡게 — 글자 대신 화면이 일하게
5. 빼기: 튕김 · 흐림 등장 · 형광펜 · 숫자 세기
```

코드로 영상을 만든다면 숫자까지 붙이면 더 정확해요. 글자 등장은 10프레임(30fps), 곡선은 cubic-bezier(0.23, 1, 0.32, 1), 둘째 줄은 3프레임 늦게, 화면은 장면 내내 1.00 → 1.04배로 천천히 밀기.

## 해 보니

- 글자를 조용히 두니 오히려 화면이 멈춰 보일 수 있어요. 그래서 판(화면) 쪽이 늘 조금씩 움직이고, 말할 때마다 화면 속에서 무언가 하나가 바뀌게 했습니다.
- 다시 만든 판은 유튜브 쇼츠·인스타 릴스로 올렸고, 이 글의 영상에 처음 판과 나란히 붙였습니다.

"트렌디하게" 같은 형용사 한 마디는 AI에게 너무 넓은 지시였어요. 무엇을 빼야 하는지까지 말하는 게 요령이었습니다.
