## 읽지 못한 범위

- **귀로 듣지 않았다.** 목소리 내용은 받아쓰기 `대조-v1.json`(small)과 게시글에 기록된 큰 모델 재확인에 기댔고, 크기는 ebur128 수치로만 봤다. 입·발음·숨 자리, 효과음(체크 틱·누름 톡)의 질감, 기획 §4 「드럼이 빠지는 박」·「다시 터지는 박」이 어디에 걸렸는지는 확인하지 못했다(b1 대사가 바뀌어 기획 §4의 「제가 봐도」 자리는 지금 대본에 없다).
- 연속 재생으로는 보지 않았다. 0.5초 간격 + 장면 경계 원본 + v8 장면 0.1초 + 32.4~32.8초 띠만 봤으므로 0.5초 안에 끝나는 깜빡임은 놓쳤을 수 있다.
- 조회수·날짜는 10-20 모션조사 표와 대조했고 오늘 다시 접속해 확인하지 않았다.
- 실제 인스타·유튜브 앱 화면 위에 올려 단추·캡션 띠 겹침을 보지 않았다(위 「기록만」의 안전 영역 언급은 키트 수치 기준).
- 올리기판은 39.0초 한 장면만 원본 크기로 봤다. 정지 구간과 소리 크기는 게시글 기록과 같은지만 완성본으로 다시 쟀다.
