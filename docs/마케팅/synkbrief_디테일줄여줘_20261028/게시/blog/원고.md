**본문**

AI로 가게 홍보 포스터를 만들어 보면, 글씨 · 배지 · 장식이 잔뜩 들어간 그림이 나올 때가 있어요. 처음부터 다시 쓰자니 막막하고, 어디를 어떻게 고치라고 해야 할지도 모르겠고요.

〔유튜브 쇼츠〕

직접 해 봤어요. 결론부터 말하면, **그림이 나온 같은 대화에 "디테일 줄여 줘" 한 줄만 보내면 됩니다.** 저희가 해 본 판에서는 포스터 속 글씨가 11곳에서 3곳으로 줄고, 잔 하나가 눈에 들어오는 포스터가 됐어요.

※ 실험은 2026년 10월 28일, ChatGPT 웹(일반 채팅 · 메모리가 켜진 계정)에서 했어요. 같은 요청도 계정마다, 할 때마다 결과가 달라요.

## 1. 처음 보낸 요청

새 대화에 이렇게만 보냈어요.

```
카페 신메뉴 딸기라떼 홍보 포스터 만들어 줘
```

30초 안쪽에 그림 한 장이 왔어요(글 답은 없이 그림만). 보기엔 예쁘지만, 가게 벽에 붙이기엔 읽을 게 너무 많았어요.

- 위쪽: 「CAFE NEW MENU」 · 「SWEET MILKY STRAWBERRY」 · 큰 제목
- 가운데: 「NEW MENU」 배지 · 양옆 문구 두 덩어리 · 말풍선 · 작은 「STRAWBERRY LATTE」
- 아래: 재료 소개 띠 세 칸

세어 보니 글씨가 들어간 곳이 **11곳**이었어요. 딸기도 여덟 알 남짓에 그릇 · 행주 · 하트 · 화살표까지 있었고요.

## 2. 같은 대화에 보낸 한 줄

그림이 나온 그 대화에 이어서, 딱 이것만 보냈어요.

```
디테일 줄여 줘
```

〔그림 1〕 *왼쪽이 처음 받은 포스터, 오른쪽이 "디테일 줄여 줘" 뒤 — 실제 ChatGPT 결과*

다시 30초 안쪽에 온 포스터에는 「CAFE NEW MENU」 · 제목 · 부제 한 줄, 이렇게 **글씨 3곳**만 남았어요. 딸기는 두 알, 배경은 빛만 드는 벽이 됐고요. 잔이 한가운데서 눈에 들어와요.

## 3. 한 번 더 해 보니

우연인지 보려고 새 대화에서 같은 두 줄을 한 번 더 보냈어요.

〔그림 2〕 *새 대화에서 다시 한 결과 — 왼쪽 처음, 오른쪽 "디테일 줄여 줘" 뒤*

이번엔 처음부터 꽤 깔끔한 포스터가 나왔어요(글씨 4곳 · 받침 · 딸기 셋). 그래도 "디테일 줄여 줘"를 보내자 받침 · 딸기 · 손글씨를 더 덜어 내고 글씨 3곳 · 잔 하나만 남겼어요. 처음 그림이 늘 복잡하게 나오는 건 아니지만, **복잡하게 나왔을 때 덜어 내는 한 줄로는 두 번 다 통했어요.** (2회차 처음 포스터의 부제에 점 하나가 잘못 들어가 있는데, ChatGPT가 쓴 그대로 뒀어요.)

## 4. 알아 둘 것

1. **같은 대화에서 보내세요.** OpenAI 도움말 「Images in ChatGPT」에 따르면, 그림이 나온 뒤 같은 대화에서 바꾸고 싶은 걸 말하면 고쳐 줘요. 새 대화에서 보내면 줄일 그림이 없어요.
2. **모양이 조금 바뀔 수 있어요.** 저희가 해 보니 잔 모양 · 딸기 자리 · 빛이 조금씩 달라졌어요. 꼭 지켜야 할 부분(가게 이름 · 가격 등)이 있으면 그 말도 같이 적어 주세요.
3. **임시 채팅에선 안 될 수 있어요.** 저희가 해 봤을 땐 임시 채팅에선 "이미지 생성 기능을 사용할 수 없어요"라고 답했어요. 일반 채팅에서 해 보세요.
4. **포스터 속 문구는 꼭 다시 읽어 보세요.** 영상 속 문구는 ChatGPT가 쓴 그대로예요("달콤한 딸기가 만나는 특별한 순간"처럼 조금 어색한 문장도 있어요).
