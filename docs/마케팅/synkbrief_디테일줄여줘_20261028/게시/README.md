# 게시 묶음 — synkbrief 「AI 포스터가 너무 복잡할 때 — '디테일 줄여 줘' 한 줄」 (2026-10-28 제작 · 슬롯 10-29)

> 게시(올리기 · 예약 · 공개)는 유호님 승인(작업실 검토 링크) 뒤 게시 작업이 한 곳씩 한다. 이 폴더는 올릴 파일과 글만 둔다. 저장은 승인이 아니다.
> 기획 · 근거: [기획.md](../기획.md)(결과 화면 먼저 · 이해 시험 v1~v5 · Fable 사실 검수). 올라가는 글의 정본은 판마다 `원고.json`이고 이 파일은 사람이 읽는 판이다.

## 그대로 붙여 쓰는 요청문(세 판 · 블로그 공통)

```
① 카페 신메뉴 딸기라떼 홍보 포스터 만들어 줘
② (그림이 나온 뒤, 같은 대화에) 디테일 줄여 줘
```

「다시 그린다」 · 「임시 채팅은 그림을 못 만든다」는 공식 문서에 없는 우리 실측이라 「저희가 해 보니」로만 쓴다(Fable P2-1 · P2-2).
