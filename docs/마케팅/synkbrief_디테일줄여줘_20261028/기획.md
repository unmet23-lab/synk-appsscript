## Fable 사실 검수(10-28, 콘티 v1)

판정 「고쳐서 진행」 — P0 · P1 없음, 영상의 말 · 큰 글은 그대로. 고친 것은 캡션 문장 둘.

- **P2-1 반영:** 「임시 채팅에서는 그림을 만들지 않는다」는 공식 도움말에 없다(Temporary Chat FAQ는 메모리 · 기록 · 학습만) → 「저희가 해 봤을 땐 임시 채팅에선 '이미지 생성 기능을 사용할 수 없어요'라고 답했어요. 일반 채팅에서 해 보세요.」
- **P2-2 반영:** 「다시 그린다(모양이 바뀐다)」도 공식은 「그림이 나온 뒤 같은 대화에서 고쳐 달라고 할 수 있다」까지 → 「같은 대화에서 고쳐 달라고 하면 돼요. 저희가 해 보니 잔 모양 · 딸기 자리도 조금씩 바뀌었어요.」
- **P2-3 반영:** 2회차 처음 포스터 부제 「달콤한 딸기.가 만난 부드러운 라떼」의 점 하나 — 영상엔 안 나오고, 블로그에 「ChatGPT가 쓴 그대로 뒀어요」.
- P3 확인: 글씨 셈 11 · 3 다시 셈 맞음(제목 두 줄 = 한 덩어리, 아래 띠 셋 — 전후 같은 기준, 빨간 테가 그 기준대로 감싸면 말은 그대로). 입력 칸 띄어쓰기는 녹화 기록의 넣은 글 「디테일 줄여 줘」와 같다. 「잔 하나가 딱 보여요」는 「잔이 딱 보여요」가 더 안전하다는 선택 의견 — 전에도 잔은 하나지만 「하나만 남아 눈에 들어온다」는 뜻이라 그대로 뒀다. 「한 줄이면 이렇게 돼요」는 조건문 + 출처 줄이 있어 지나친 약속 아님. 그림 넷에 사람 · 로고 · 상호 · 연락처 없음, 한국어 문구 깨짐 없음.
- 확인한 원문(2026-10-28): OpenAI 도움말 「Images in ChatGPT」(help.openai.com/en/articles/11084440 — 「After your image is generated, you can ask ChatGPT to make changes in the conversation」, 모든 요금제) · 「Temporary Chat FAQ」(8914046) · 「What is ChatGPT: FAQ」(12677804). help.openai.com은 봇에 403이라 Fable은 검색 도구 본문 사본으로 읽었고, 08:1x 앱 안 브라우저로 「Images in ChatGPT」를 다시 열어 확인했다.
