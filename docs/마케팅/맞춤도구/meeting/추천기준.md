# 회의 기록 맞춤 정리 · 추천 기준

2026-09-29. [제작 절차](../제작절차.md) 2단계의 원문이다. 사실과 출처는 [탐색노트](탐색노트.md)에 있다. 계산은 `rules.js`, 문장과 팁은 `content.js`가 쥔다.

## 1. 사용자 결정과 전제

- 2026-09-29 사용자 요청: “회의 정리 페이지도 같은 틀로 만들어줘.” 컴퓨터 추천과 같은 틀(질문 → 팁 → 개인화 결과 → 가져가기)로 synk.im/brief/meeting/을 다시 만든다.
- 2026-09-27 사용자 요청(제작 절차): 사전 탐색을 길게 하고, 요소마다 왜 필요한지·값·필요 없는 경우·함정·확인법을 팁으로 알려 개인화한다. 추천은 가성비가 먼저다(유료는 필요한 경우에만).
- 영상(synkbrief 01)과 캡션이 약속한 것: 11쪽 PDF, 복사용 문장, 연습 메모. 도구는 이 셋을 첫 화면과 결과에서 바로 받게 하고, GPT가 만든 PDF·ZIP은 바이트 그대로 싣는다(`keep/`).
- 도구는 회의 내용을 받지 않는다. 요청문은 규칙으로 만들고, 실제 정리는 사용자의 AI에서 한다. AI 호출 0.

## 2. 원칙

1. **기록은 다듬지 않고 그대로.** 정리는 AI의 일이다.
2. **지어내지 않게.** 모든 요청문에 ‘없는 건 확인 필요’, ‘다음 날짜를 기한으로 쓰지 않기’, ‘미정은 따로’를 넣는다.
3. **회의마다 칸이 다르다.** 칸 이름이 곧 요청문의 순서다(§4).
4. **쓰던 AI를 그대로.** 바꾸라고 하지 않는다. AI가 없을 때만 고른다(§5).
5. **무료가 먼저.** 유료는 긴 기록·잦은 정리·녹음 파일 직접 업로드처럼 한도에 걸릴 때만 권한다.
6. **민감한 정보는 넣지 않는 게 먼저.** 설정은 그다음이다. 업무 계정은 회사 규칙을 따른다.
7. **보내는 건 사람이.** AI가 대신 보내거나 일정을 등록하지 않게 한다.

## 3. 질문(7~9개)

| 질문 | 선택지 | 쓰는 곳 |
|---|---|---|
| 회의 종류 | 팀 회의 · 고객 미팅 · 1:1 면담 · 수업·스터디 · 모임 | 정리 칸, 기한 규칙 이름, 숫자 규칙 |
| 기록 형태(여럿) | 메모 · 사진 · 녹음 글 · 녹음 파일 · 메신저 · 회의 앱 자동 기록 | 요청문 규칙, 순서, 팁 |
| 녹음 기기·길이(녹음 파일일 때) | 갤럭시 · 아이폰 · 회의 앱 · 기타 / 10분 이하 · 1시간 이하 · 1시간 넘게 | 받아 적는 길 |
| 분량 | 짧음 · 보통 · 김 | 넣는 법(붙여 넣기·나눠 보내기·파일) |
| AI·요금제 | ChatGPT · Claude · Gemini · 없음 / 무료 · 유료 · 회사·학교 | 저장 위치, 한도, 설정 |
| 빈도 | 한 번 · 비슷한 회의 자주 · 여러 종류 자주 | 규칙 저장 여부 |
| 받는 사람(여럿) | 나 · 참석자 · 상사 · 불참자 · 고객 | 보낼 글 요청문 |
| 보내는 곳(받는 사람이 나 말고 있을 때) | 메신저 · 메일 · 공유 문서 | 보낼 글 형식 |
| 민감한 정보 | 없음 · 회사 내부 · 개인정보 · 모름 | 지우기, 임시·시크릿 채팅, 학습 설정 |

## 4. 회의별 정리 칸

| 회의 | 칸 | 확정 칸 / 미정 칸 | 다음 날짜 규칙 |
|---|---|---|---|
| 팀 회의 | 핵심 요약 / 결정된 내용 / 할 일(업무·담당자·기한 표) / 확인할 내용 | 결정된 내용 / 확인할 내용 | 다음 회의 날짜를 할 일의 기한으로 쓰지 않음 |
| 고객 미팅 | 핵심 요약 / 고객 요청 사항 / 우리가 약속한 것 / 숫자·날짜 확인 / 확인할 내용 / 다음 연락 | 우리가 약속한 것 / 확인할 내용 | 다음 미팅 날짜 ≠ 약속 기한 |
| 1:1 면담 | 핵심 요약 / 합의한 것 / 서로 할 일 / 다음에 확인할 것 | 합의한 것 / 다음에 확인할 것 | 다음 면담 날짜 ≠ 할 일 기한 |
| 수업·스터디 | 핵심 내용 / 예시와 설명 / 과제와 마감 / 물어볼 것 / 다음 수업 준비 | (없음) / 물어볼 것 | 다음 수업 날짜 ≠ 과제 마감 |
| 모임 | 결정된 내용 / 역할 / 일정·장소 / 돈 / 확인할 내용 | 결정된 내용 / 확인할 내용 | 다음 모임 날짜 ≠ 역할 기한 |

추가 규칙: 녹음 글·자동 기록이면 이름·숫자·말한 사람 확인 필요, 사진이면 [?] 표시, 메신저면 결정·할 일·약속만, 1:1이면 사적인 이야기·평가 표현 제외, 고객·모임이면 금액·수량·날짜 원문 그대로, 개인정보가 있거나 모르면 ‘(개인정보 생략)’. 여러 종류 회의를 자주 하면 저장할 규칙에 다섯 종류의 칸을 모두 넣고 맨 위에 회의 종류를 적게 한다.

## 5. AI 고르기(없을 때만)

- 녹음 파일만 있고 10분 이하 → **Gemini**(무료로 파일을 바로 받아 받아 적기와 정리를 한 번에).
- 기록이 김(1시간 넘는 녹음 포함) → **Claude**(무료도 한 번에 읽는 양이 최대 1M 토큰, 모델별).
- 그 밖 → **ChatGPT**(영상·11쪽 PDF와 같은 화면, 무료 프로젝트).
- 회사·학교 계정이 있다고 하면 회사가 허락한 AI부터 확인하라고 덧붙인다.

## 6. 넣는 법과 한도

| 경우 | 넣는 법 |
|---|---|
| 긴 기록 · ChatGPT 무료 | 두세 번 나눠 보내기(무료 약 12쪽, 1만 자 넘으면 자동 첨부, 파일 하루 3개) |
| 긴 기록 · Gemini 무료 | 나눠 보내기(32K 토큰) |
| 긴 기록 · Claude | 한 번에 붙여 넣기(무료는 5시간 사용량 주의) |
| 긴 기록 · 그 밖 유료·회사 | 파일로 올리거나 나눠 보내기 |
| 사진만 | 사진 첨부 |
| Gemini + 녹음 10분 이하 | 녹음 파일 첨부 |

나눠 보낼 때는 요청문에 “‘끝’이라고 할 때까지 ‘받았어’라고만”을 넣고, 다음 회의 한 줄에도 같은 말을 넣는다.

## 7. 녹음 파일 → 글

- 갤럭시: 녹음 앱 텍스트 변환 어시스트(One UI 6.1+, 한국어, 국내는 네트워크·삼성 계정).
- 아이폰: 음성 메모 받아 적기(iOS 26, 아이폰 12+, 한국어).
- 회의 앱: 미트(업무 계정·AI Pro, 무료 Gmail 불가) · 팀즈(Premium·Copilot) · 줌(유료, 무료 횟수는 안내가 서로 다름). 없으면 클로바노트.
- 기타 파일: 클로바노트(개인 월 300분 무료, 한 번에 180분).
- 10분 이하면 Gemini 무료 직접 업로드도 안내.

## 8. 저장·정보 보호

- 빈도가 ‘한 번’이면 저장하지 않는다(요청문만).
- 자주 하면 ChatGPT·Claude는 프로젝트 지침, Gemini는 Gem 요청 사항에 저장한다. 메뉴 순서를 AI별로 보여 준다. ChatGPT는 ‘프로젝트 전용 메모리’, Gemini는 11월 스킬 전환을 알린다.
- **민감한 회의(회사 내부·개인정보)를 Claude·Gemini로 자주 정리하면 저장하지 않는다.** 시크릿·임시 채팅에서는 프로젝트·Gem을 못 쓰기 때문이다. 대신 요청문을 메모 앱에 저장해 두고 매번 붙이게 한다(privateMode).
- 민감하면 순서에 ‘넣기 전에 지우기’를 넣고, 보내는 곳을 임시 채팅(Claude는 시크릿 채팅)으로 바꾼다. 업무 계정은 회사 규칙을 따르게 한다.

## 9. 결과 화면의 순서

1. 제목: 저장하면 “○○ 프로젝트·Gem에 규칙을 저장하고, 다음부턴 한 줄로”, 한 번이면 “이번엔 ○○에 요청문 하나면 돼요”, 민감+저장 불가면 “○○ 시크릿·임시 채팅에 요청문을 붙여 정리해요”
2. 알림(민감한 회의의 저장 방식 등)
3. 나의 정리 순서(단계 번호)
4. 가져가기: 처음 요청문 → (저장 시) 저장할 규칙·저장하는 곳·다음 회의 한 줄 → (보낼 사람이 있으면) 보낼 글 요청문
5. 내 상황에 맞춘 설정: AI·요금제(유료가 편한 경우/무료로 충분), 넣는 법, 녹음을 글로, 정리 칸, 규칙 저장, 정보 보호, 보내기
6. 나에게 필요한 팁
7. 보내기 전에 확인할 것
8. 영상 속 자료와 연습(11쪽 PDF, ZIP, 연습 메모)
9. 저장·반응·답 바꾸기·출처

## 10. 시험으로 지키는 약속

- 모든 요청문: ‘확인 필요’, 다음 날짜≠기한, 미정 분리가 들어간다. 회의 종류별 칸 이름이 들어간다.
- 수업: ‘결정된 내용’ 대신 ‘물어볼 것’, ‘다음 수업 날짜를 과제 마감으로 쓰지 마’.
- 한 번만: 저장할 규칙과 다음 회의 한 줄을 보여 주지 않는다. 자주: 보여 준다.
- AI 없음: 녹음 10분 이하만 → Gemini, 긴 기록 → Claude, 그 밖 → ChatGPT.
- 긴 기록 + ChatGPT 무료 → 나눠 보내기와 ‘끝’ 규칙. Claude → 붙여 넣기.
- 민감 + Claude/Gemini + 자주 → 저장 안 함, 메모 앱 방식, 알림 한 줄.
- 녹음 파일/녹음 글 → 녹음 사실 알리기 확인표, recording-consent 팁.
- 고객에게 보냄 → 내부 메모·추측 빼기, 질문으로 바꾸기, 외부 글 확인표.
- 받는 사람 요청문은 반말(“둬”, “써 줘”), 저장할 규칙은 존댓말(“두세요”).
- 결과가 고른 팁은 모두 팁 은행에 있고, 결과가 쓴 출처는 모두 SOURCES에 있다.
