# 회의 기록 맞춤 정리 · 사전 탐색 노트

2026-09-29. [제작 절차](../제작절차.md) 1단계의 결과다. 여기 적은 사실이 `content.js`의 팁·출처와 `rules.js`의 안내 문장이 된다. 표시는 **공식**(회사·정부 문서 원문), **보도·커뮤니티**, **SYNK 판단**이다. 원문은 조사 담당 에이전트 네 갈래가 2026-09-29에 직접 열어 문장을 대조했다(OpenAI 도움말은 WebFetch가 막혀 실제 브라우저로 읽음).

## 1. 이 도구가 풀 질문

“회의 메모·녹음·대화가 흩어져 있는데, 내 회의·내 AI·보낼 사람에 맞게 어떻게 정리하고 무엇을 조심해야 하나?”
출발점은 synkbrief 01 영상과 GPT가 만든 11쪽 PDF·연습 키트(2026-09-24 synk.im/brief/meeting/ 공개, ChatGPT 화면 기준)다. 이 도구는 그 자료를 그대로 싣고, 회의 종류·기록 형태·분량·AI·빈도·받는 사람·민감한 정보에 맞춰 요청문과 순서를 바꾼다.

## 3. 흔한 오해 (팁으로 반드시 짚을 것)

1. “메모를 먼저 깔끔하게 정리해야 AI가 잘한다” → 정리는 AI의 일이다. 다듬다가 기한·담당자를 빠뜨린다(raw-memo).
2. “AI 회의록은 정확하다” → 세 회사 모두 틀릴 수 있다고 안내한다. 담당자·기한을 지어내는 게 가장 흔하다(hallucination).
3. “다음 회의 날짜가 곧 마감이다” → 기록에 없는 기한이다. 요청문 규칙으로 막는다(visual deadline).
4. “녹음만 하면 끝” → 받아 적은 글은 이름·숫자·말한 사람이 틀린다. 네이버·삼성·애플이 직접 초안이라고 말한다(transcript-errors).
5. “긴 녹음 글도 그냥 붙이면 된다” → 한 번에 읽는 양에 한도가 있다. 무료 ChatGPT 약 12쪽, 무료 Gemini 32K(long-record).
6. “회의록 앱을 따로 사야 한다” → 메모·녹음 글이 있으면 쓰던 AI와 요청문으로 충분하다. 받아 적기도 무료 길이 많다(which-ai, audio-route).
7. “규칙은 계정 전체 맞춤 지침에 넣으면 된다” → 모든 대화에 섞인다. 프로젝트·Gem에 넣는다(project-save).
8. “학습을 끄면 대화가 바로 지워진다” → 끈 뒤에도 30일(ChatGPT 임시 채팅·Claude), 72시간(Gemini) 보관된다(privacy-training).
9. “구글 미트 자동 회의록은 누구나 된다” → 무료 Gmail에서는 안 된다(audio-route).
10. “녹음은 무조건 불법이다 / 무조건 괜찮다” → 참여자의 녹음은 위반이 아니지만, 남의 대화 몰래 녹음은 처벌된다. 알리는 게 좋다(recording-consent).

## 5. 쓰지 않은 것과 이유

- **Claude 설정 스위치의 정확한 한국어 이름**: 로그인이 필요해 화면을 못 봤다. 도움말과 보도의 영어 이름이 서로 달라 ‘모델 학습 허용 스위치’로 풀어 썼다.
- **ChatGPT 설정의 한국어 이름**: 도움말 한국어판이 이 환경에서 열리지 않았다. ‘데이터 제어’와 영어 원문 이름을 함께 적었다.
- **Claude 원화 가격**: 한국에서 연 요금제 페이지가 달러만 보여 달러로 적었다.
- **줌 무료 요약 횟수**: 도움말과 제품 페이지가 달라 “내 계정 메뉴에서 확인하라”고만 적었다.
- **Gemini 스킬 전환의 정확한 날짜(11월 17일)**: 보도에만 있어 “2026년 11월”로 적었다. 스킬이 유료 전용인지도 확인되지 않아 쓰지 않았다.
- **다른 나라의 녹음 동의 규칙**: 이번에 원문을 확인하지 않아 쓰지 않았다(“회사·학교 규칙이 따로 있을 수 있다”만).
- **토큰을 쪽수로 바꾸는 계산**: 공식 쪽수가 있는 ChatGPT만 쪽수로, 나머지는 토큰으로 적었다.
