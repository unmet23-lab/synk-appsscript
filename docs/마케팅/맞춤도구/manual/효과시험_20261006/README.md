# AI 직원 매뉴얼 · 효과 시험 기록(2026-10-06)

같은 한 줄 요청을 조건마다 ChatGPT(Codex CLI, ChatGPT 구독)에 맡겼어요. 조건은 매뉴얼 없음, 흔한 역할 프롬프트, 이 매뉴얼의 판별 버전이에요. 결과는 조건을 가린 별도 에이전트가 채점했어요. 방법·결과·결론은 [추천기준 §11](../추천기준.md)에 있어요.

| 폴더 | 내용 |
|---|---|
| `자료/` | 장면 메시지 두 개(인스타 신메뉴 S, 환불 답장 R)와 흔한 프롬프트(B). 4차의 바로 써 보기 메시지(H·I는 써 보기 글 + 이번 일, J는 써 보기 글만 먼저) |
| `지침/` | 조건별 매뉴얼. C 첫 판, D v2, E v2+내 정보, F v3, G v3+내 정보, F4 v4, G4 v4+내 정보(늘 쓰는 정보 포함) |
| `결과/` | `S_A_1`은 장면 S, 조건 A, 첫 번째 시도예요. A·B·C는 1차, D·E는 2차, F·G는 3차 시험이에요(28개). 4차는 F4·G4·H4·I4·J4 세 번씩(30개, J4는 첫 답 `_첫답`도), 5차는 지금 모델의 A4·B4 세 번씩(12개)이에요. |
| `채점/` | 차수별 번호표(가린 번호 → 결과)와 점수. 1차는 A·B·C 12개, 2차는 A~E 20개, 3차는 A·B·F·G 16개, 4차는 F4~J4 30개, 5차는 A4·B4·F4·H4·I4 30개를 채점했어요. |

다시 해 보려면 이렇게 해요.

1. 조건 폴더마다 `지침/…md`를 `AGENTS.md`로 두고, 메시지를 넣어 보내요. 명령은 `codex exec --skip-git-repo-check -C <폴더> -s read-only -c model_reasoning_effort="medium" -o last.txt - < message.txt`예요.
2. 결과를 섞어 번호를 가린 뒤 같은 채점 기준으로 채점해요.

메시지 첫 줄의 「시험 환경 안내」는 세 조건에 똑같이 넣었어요. ChatGPT 프로젝트처럼 도구 없이 대화로만 답하게 하려는 줄이에요.

4·5차(10-06 밤)는 [추천기준 §12](../추천기준.md)에 있어요. 모델을 `-m gpt-6-astra`로 고정하고 Codex 기억을 껐어요(`-c memories.use_memories=false -c memories.generate_memories=false`). 한 번에 보내는 칸은 `--ephemeral`로 대화를 남기지 않았고, J는 `codex exec resume <대화 id>`로 두 번째 메시지를 보냈어요.
