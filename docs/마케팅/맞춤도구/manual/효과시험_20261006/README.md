# AI 직원 매뉴얼 · 효과 시험 기록(2026-10-06)

같은 한 줄 요청을 조건마다 ChatGPT(Codex CLI, ChatGPT 구독)에 맡겼어요. 조건은 매뉴얼 없음, 흔한 역할 프롬프트, 이 매뉴얼의 판별 버전이에요. 결과는 조건을 가린 별도 에이전트가 채점했어요. 방법·결과·결론은 [추천기준 §11](../추천기준.md)에 있어요.

| 폴더 | 내용 |
|---|---|
| `자료/` | 장면 메시지 두 개(인스타 신메뉴 S, 환불 답장 R)와 흔한 프롬프트(B) |
| `지침/` | 조건별 매뉴얼. C 첫 판, D v2, E v2+내 정보, F v3, G v3+내 정보 |
| `결과/` | 결과 28개. `S_A_1`은 장면 S, 조건 A, 첫 번째 시도예요. A·B·C는 1차, D·E는 2차, F·G는 3차 시험이에요. |
| `채점/` | 차수별 번호표(가린 번호 → 결과)와 점수. 1차는 A·B·C 12개, 2차는 A~E 20개, 3차는 A·B·F·G 16개를 채점했어요. |

다시 해 보려면 이렇게 해요.

1. 조건 폴더마다 `지침/…md`를 `AGENTS.md`로 두고, 메시지를 넣어 보내요. 명령은 `codex exec --skip-git-repo-check -C <폴더> -s read-only -c model_reasoning_effort="medium" -o last.txt - < message.txt`예요.
2. 결과를 섞어 번호를 가린 뒤 같은 채점 기준으로 채점해요.

메시지 첫 줄의 「시험 환경 안내」는 세 조건에 똑같이 넣었어요. ChatGPT 프로젝트처럼 도구 없이 대화로만 답하게 하려는 줄이에요.
