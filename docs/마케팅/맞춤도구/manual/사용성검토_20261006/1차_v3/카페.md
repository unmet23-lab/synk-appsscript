“카페 신메뉴 올릴 때 매번 설명 안 해도 되겠네” 싶어서 들어왔어요. 노란 시작 버튼과 선택 표시가 눈에 잘 들어오는 건 좋아요. 그런데 제가 기대한 끝은 **‘인스타 글 하나 만들어 보기’**인데, 실제로는 매뉴얼을 받고 다른 앱에 설치하는 일이 남아 있어요.

**1. 화면을 순서대로 보면서**

- **01 — 첫 화면**  
  설명은 길어서 건너뛰고 ‘질문 5개, 약 1분, 로그인 없음’만 봐요. 일단 **‘내 매뉴얼 만들기’**를 눌러요. ‘지침 칸’이 뭔지는 아직 몰라요.

- **02 — 맡길 일**  
  제가 하는 일이 바로 있어서 **‘SNS 게시물 만들기’**를 골라요. 아래에도 선택지가 있는 것 같은데, 제 건 찾았으니 더 안 내려봐요.

- **03 — 고른 뒤**  
  노란 체크가 생기고 다음 버튼이 검게 바뀌니 선택된 건 확실해요. **‘다음’**을 눌러요.

- **04 — 완성 기준**  
  ‘바로 쓸 수 있는 완성본’과 ‘올리기 직전까지’가 뭐가 다른지 잘 모르겠어요. 사진이랑 글까지 준비해 준다는 뜻인가 싶어서 **‘올리기 직전까지’ → ‘다음’**을 눌러요.

- **05 — 검수**  
  카페 가격 틀리면 곤란하니 ‘사실·숫자’, 글도 자연스러워야 하니 ‘맞춤법·말투’를 골라요. 링크랑 저작권도 필요한 것 같아 화면처럼 체크하지만, 제가 뭘 확인하게 되는지는 모르고 **‘다음’**으로 가요.

- **06 — 사람 차례**  
  돈 쓰거나 게시하는 건 제가 해야 하니 추천대로 전부 둬요. 다만 **‘내가 쓴 글 고치기’도 매번 물어보면 귀찮지 않나?** 싶지만 일단 다음을 눌러요.

- **07 — 쓰는 AI**  
  아는 건 ChatGPT라 그걸 골라요. ‘프로젝트 → 프로젝트 설정’은 처음 보는 메뉴지만, 다음 화면에서 알려주겠지 하고 **‘결과 보기’**를 눌러요.

- **08 — 결과 첫 화면**  
  ‘SNS 게시물’이라고 나오니 제 결과인 건 알겠어요. 그런데 ‘복사 → 지침에 붙이기 → 새 채팅’ 중 가운데를 모르겠고, 아래에 늘 보이는 **‘매뉴얼 복사’부터 누를 것 같아요.**

- **09 — 내 정보 넣기**  
  “아, 가게 이름도 써야 진짜 우리 카페용이 되는구나.” 이미 복사했다면 입력 후 다시 복사해야 하나 헷갈려요. 가게 이름과 하는 일 정도만 적고, 말투 예시는 귀찮아서 비워둘 것 같아요.

- **10 — 매뉴얼 본문**  
  긴 글 상자라 처음 두세 줄만 읽어요. 제가 읽을 설명인지 ChatGPT에 줄 글인지 잠깐 헷갈리지만, 아래 예시를 보고 **‘이번 주 신메뉴 소식…’ 옆 복사**를 누르고 싶어요.

- **11 — 매뉴얼을 넣는 곳**  
  이제 필요한 설명이 나왔는데 ‘사이드바’, ‘프로젝트’, ‘프로젝트 지침’이 다 낯설어요. **ChatGPT 앱을 열어 ‘새 프로젝트’가 있는지 찾아볼 것 같아요.**

- **12 — 요금제**  
  ‘무료로 충분’까지만 보면 안심되는데, 바로 아래 유료·에이전트·클라우드 브라우저가 나오니 “내가 고른 ‘올리기 직전까지’는 돈 내야 하나?” 싶어요. 결제는 하기 싫어서 **일단 아래로 내려요.**

- **13 — 사람 차례 확인표**  
  “아직 ChatGPT에서 아무것도 안 했는데 이걸 지금 체크하라는 건가?” 싶어요. 체크하면 뭔가 완료되는 건지도 모르겠어서 **아무것도 안 누르고 넘겨요.**

- **14 — 나에게 의미 있는 것**  
  매뉴얼 쓰는 방법이 더 있나 봤는데 긴 사례가 펼쳐져 있어요. 지금 카페 글을 만들고 싶어서 사례는 안 읽고 **아래로 내려요.**

- **15 — 사례와 설명 목록**  
  ‘CLAUDE.md’가 나오면 제게 필요한 부분은 아닌 것 같아요. ‘말투는 예시 문장 두세 개로 정해요’는 궁금하지만, 지금은 설치부터 못 해서 **그냥 넘겨요.**

- **16 — 신경 쓰지 않아도 되는 것**  
  무료라는 말은 반갑지만, 이미 본 이야기 같아요. ‘신경 쓰지 않아도 되는 것’도 읽을 게 많아서 **저장하는 버튼이 있는지 더 내려요.**

- **17 — 저장과 의견**  
  ‘내 결과 링크 복사’를 누르면 나중에 돌아올 수 있을 것 같아요. 의견은 **‘너무 많아요’**를 고르겠어요. 매뉴얼 복사는 했지만 실제 사용은 아직 못 했거든요.

- **18 — 답 바꾸기와 맨 아래**  
  이제 끝인데, 여전히 ChatGPT에 제대로 넣었는지는 모르겠어요. 답을 바꿀 생각은 없고 **‘매뉴얼 복사’를 다시 누른 뒤 ChatGPT로 가요.**

- **19 — 마지막 화면**  
  앞 화면과 거의 같아서 새로 할 일은 없어 보여요. 여기까지 읽기 전에 나갔을 가능성이 크고, 남아 있다면 **ChatGPT 앱으로 전환해요.**

**2. 지금 ChatGPT에서 써 보려고 한다면**

제가 이 화면을 보고 시도할 순서는 이래요.

1. 결과 화면의 **‘매뉴얼 복사’**를 눌러요.
2. 인스타그램 안에서 열었던 페이지를 둔 채, 휴대폰 홈 화면으로 나가 **ChatGPT 앱**을 열어요.
3. 평소처럼 채팅 입력창을 눌렀다가 “여기 말고 프로젝트에 넣으랬지?” 하고 멈춰요.
4. 앱 메뉴를 열어 **‘새 프로젝트’**라는 글자를 찾아요. 찾으면 이름을 ‘카페 SNS’로 적어볼 것 같아요.
5. 그다음은 기억이 안 나서 최근 앱 화면으로 인스타그램에 돌아가요. 결과 페이지에서 **11번의 설치 설명**을 다시 찾아요.
6. ‘점 세 개 → 프로젝트 설정 → 지침’을 기억하고 ChatGPT로 돌아가 찾아봐요. 해당 칸을 찾았다면 붙여 넣고 저장하려고 해요.
7. 다시 결과 페이지로 와서 **‘이번 주 신메뉴 소식…’ 예시를 복사**해요.
8. ChatGPT로 돌아가 방금 만든 프로젝트 안에서 새 채팅을 열고, 우리 카페 신메뉴 이름과 가격을 덧붙여 보내요.

**가장 멈추기 쉬운 곳은 4~6번이에요.** 화면 속 안내와 제 앱에서 보이는 메뉴가 조금만 달라도 어디를 눌러야 할지 모르겠어요. 두 번 정도 앱을 오가면 “그냥 평소 채팅에 붙이면 안 되나?” 하고 매뉴얼 전체를 일반 채팅에 붙여버릴 것 같아요.

그리고 7번에서 예시를 먼저 복사하면, 앞서 복사한 매뉴얼 대신 예시 문장이 붙여 넣어질 수 있겠네요. 저는 두 ‘복사’를 순서대로 눌렀을 뿐인데 다시 돌아가야 해요.

- **‘프로젝트’**: 카페 일을 모아두는 방 같은 건가 하고 짐작은 해요. 일반 채팅과 어떻게 다른지는 이 화면만으로 확실히 모르겠어요.
- **‘지침’**: 매뉴얼을 붙이는 칸이라는 건 알겠어요. 하지만 채팅 입력창과 다른 어디에 있는 칸인지, 저장이 됐는지 확인하는 방법은 모르겠어요.

**3. 가장 큰 막힘 세 가지**

| 심각도 | 위치 | 제가 막히는 이유 |
|---|---|---|
| **포기** | **08·11번 — ‘프로젝트의 지침에 붙여 넣기’와 설치 안내** | 복사까진 쉬운데, 낯선 앱 메뉴를 글로만 찾아야 해요. 여기서 실패하면 영상에서 약속한 ‘다음부터 한 줄’까지 못 가요. |
| **한참 헤맴** | **08~18번 — 긴 결과와 여러 복사 버튼** | 매뉴얼, 가게 정보, 예시, 설치법, 확인표가 이어져서 지금 할 일이 흐려져요. 매뉴얼을 복사한 뒤 정보를 적거나 예시를 복사하면 다시 복사해야 하는지도 헷갈려요. |
| **한참 헤맴** | **04·12번 — ‘올리기 직전까지’와 유료 기능 설명** | 제가 받는 게 글인지, 사진까지인지, 인스타 업로드 준비까지인지 모르겠어요. 선택할 때는 가능해 보였는데 결과에서 유료 이야기가 나와 기대가 흔들려요. |

**4. 고치면 좋을 것 세 가지**

1. **결과 첫 화면을 ‘사용 시작’ 순서로 바꿔 주세요.**  
   08번 바로 아래에 가게 정보와 복사를 놓고, 사례·요금제·확인표는 뒤로 접어두면 좋겠어요.

   화면 문구:
   > **이제 ChatGPT에 넣어 볼까요?**  
   > ① 가게 정보 넣기 — 건너뛰어도 돼요  
   > ② 완성된 매뉴얼 복사하기  
   > ③ ChatGPT에 저장하기

   정보 입력 후 버튼은 **‘가게 정보를 넣은 매뉴얼 복사’**, 복사 후에는 **‘복사했어요. 이제 ChatGPT를 여세요’**로 바뀌면 확실해요.

2. **휴대폰에서 누를 곳을 그림으로 보여 주세요.**  
   11번 설명을 결과 위쪽으로 옮기고, 실제 앱 화면에서 눌러야 할 메뉴에 표시해 주세요. 안내는 한 번에 한 단계씩 보고 돌아올 수 있으면 좋겠어요.

   화면 문구:
   > **프로젝트는 카페 일을 모아두는 공간이에요.**  
   > **지침은 그 안에서 AI가 따를 업무 규칙을 저장하는 칸이에요.**  
   > 복사한 매뉴얼은 채팅창이 아니라 이 칸에 붙여 넣으세요.

   단추는 **‘휴대폰에서 넣는 법 보기’**, **‘저장했어요 · 첫 요청 써 보기’**로 해 주세요. 예시 복사는 저장한 다음에 나오면 덜 헷갈려요.

3. **‘올리기 직전까지’가 무엇을 주는지 선택할 때 보여 주세요.**  
   04번 선택지를 카페 SNS 기준으로 구별해 주면 제가 원하는 걸 고를 수 있어요.

   > **글 초안** — 아이디어와 대략적인 문장을 받아 내가 다듬어요.  
   > **게시할 글 완성** — 인스타에 붙여 넣을 글과 해시태그를 받아요.  
   > **게시 준비까지** — 완성된 글에 사진 설명과 게시 시간 제안까지 받아요. 인스타에 올리는 건 내가 해요.

   실제 제공 범위도 이 문구와 맞아야 해요. 12번의 추가 기능 설명은 **‘AI가 화면 조작까지 하게 하고 싶다면’** 안으로 접어두면 좋겠어요.

**5. PDF나 프롬프트 한 장보다 나은가요?**

질문을 고르는 동안은 더 좋아요. ‘카페 SNS 맡기는 용도’로 골랐다는 느낌이 있고, 제가 직접 긴 요청문을 만들 필요도 없으니까요. 그런데 결과에서는 긴 글과 설명이 너무 많아서 결국 **“나한테 맞춘 프롬프트 한 장을 받았는데, 어디에 넣는지는 따로 배워야 하는 상태”**예요. 가게 정보까지 넣고 ChatGPT에서 첫 게시물 하나를 만들어 봐야 차이를 느낄 것 같아요. 지금 화면만으로는 고르는 과정은 PDF보다 편하지만, 실제로 쓰기 시작하는 과정은 아직 어렵습니다.
