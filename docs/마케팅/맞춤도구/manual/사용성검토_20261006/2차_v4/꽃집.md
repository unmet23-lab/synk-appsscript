“꽃집 인스타 글을 매번 쓰는 일을 줄이고 싶어서 들어왔다”는 마음으로 따라갔어요. 고른 답이 눈에 잘 보이는 건 좋았어요. 그런데 결과에서는 **오늘 글을 써 보는 방법보다 설명이 훨씬 많아서**, 영상에서 말한 “한 번 넣어 두기”까지 갈 자신이 없어졌어요.

**1. 화면마다 제가 하려던 일과 다음 행동**

| 이미지 | 제 생각과 다음에 누를 것 |
|---|---|
| **01** | “다섯 개만 고르면 되는구나.” 그런데 ‘매뉴얼’이 제가 읽을 설명서인지, ChatGPT에 넣을 글인지 아직 헷갈려요. **내 매뉴얼 만들기**를 눌러요. |
| **02** | 꽃집 인스타 글을 맡기려니 **SNS 게시물 만들기**가 맞겠어요. 아래 선택지는 떠 있는 이전·다음 단추에 가려져 있지만, 저는 A를 눌러요. |
| **03** | 노란 체크가 생겨서 선택한 건 확실히 알겠어요. 검은색으로 바뀐 **다음**을 눌러요. |
| **04** | 바로 올릴 수 있게 받고 싶은데 ‘바로 쓸 수 있는 완성본’과 ‘올리기 직전까지’가 어떻게 다른지 모르겠어요. 일단 화면처럼 **C를 고르고 다음**을 눌러요. |
| **05** | 꽃 가격·말투·링크는 확인해야겠어요. ‘저작권·초상권’은 꽃 사진에도 해당하는지 모르지만 빼면 안 될 것 같아서 화면처럼 고르고 **다음**을 눌러요. |

| **07** | **ChatGPT**는 알아요. ‘새 채팅’은 해봤지만 ‘프로젝트에 넣어 둔다’는 건 처음 듣는 말이라, 우선 **결과 보기**를 눌러요. |
| **08** | “이제 꽃집 글을 써 주나?” 했는데 가게 정보를 또 적으라고 하네요. 이름은 적겠지만, **써 보기 글 복사**가 매뉴얼을 복사하는 건지 오늘 부탁할 글을 복사하는 건지 망설여요. |
| **09** | 번호대로 하면 되겠네요. 그런데 영상에서 들은 건 ‘한 번 넣어 두기’라서 그 탭도 신경 쓰여요. 일단 쉬워 보이는 **바로 써 보기의 복사 단추**를 누르겠어요. |
| **10** | ‘이번 일:’ 뒤를 제가 바꿔야 한다는 건 여기서 알겠어요. 그런데 새 채팅마다 긴 글을 다시 붙여야 한다니 번거롭네요. **한 번 넣어 두기**를 보려고 위로 돌아가요. |
| **11** | ‘사람 차례 확인표’까지 제가 체크해야 하나 싶어요. “지금 체크할 필요는 없다”니 넘기지만, 아직 사용도 못 했는데 할 일이 많아진 느낌이에요. **아래로 내려요.** |

| **15** | 아직 써 보지도 않았는데 ‘도움이 됐나요?’를 묻네요. 저장 단추도 여러 개라 무엇을 저장해야 할지 모르겠어요. **평가는 건너뛰어요.** |
| **16** | 끝까지 왔는데 제가 원하던 ‘한 번 깔아 두기’는 못 했어요. **처음부터 다시**는 누르기 싫고, 아래 **써 보기 글 복사**로 오늘 한 번만 해보겠어요. |
| **17** | 앞 화면과 거의 같아서 새 안내는 없네요. **ChatGPT 열기**를 누르겠지만, 복사한 내용이 저절로 들어가는지는 모르겠어요. |

**2. 지금 바로 ChatGPT에서 쓰려면 제가 할 순서**

1. 결과 위쪽으로 돌아가 **가게 정보 넣기**에 꽃집 이름과 필요한 안내를 적어요. 선택이라고 되어 있으니 ‘더 적기’는 우선 넘겨요.
2. **바로 써 보기**를 선택하고 **써 보기 글 복사**를 눌러요. 눌렀을 때 “복사됐어요”라는 표시가 있어야 다음으로 갈 수 있겠어요.
3. **ChatGPT 열기**를 눌러요. 앱으로 갈 줄 기대해요. 브라우저에서 다른 ChatGPT 화면이 열리거나 로그인을 요구하면 당황할 것 같아요.
4. 앱이 바로 열리지 않으면 휴대폰 홈 화면으로 나가, 제가 깔아 둔 **ChatGPT 앱**을 직접 열어요.
5. 새 대화를 열고, 아래 입력칸을 길게 눌러 **붙여넣기**를 해요.
6. 붙인 긴 글 맨 아래를 찾아 ‘이번 일:’ 뒤를 바꿔요. 예를 들면 **“첨부한 꽃다발 사진으로 우리 꽃집 인스타그램 글 하나 써 줘. 모르는 가게 정보는 먼저 물어봐 줘.”**라고 적고 사진을 붙여 보내요.
7. 나온 글을 읽고 가격·가게 안내가 맞는지 확인해요. 글을 복사한 뒤 휴대폰의 최근 앱 화면에서 **인스타그램으로 이동**해 게시물에 붙여 넣어요. 올리기는 제가 해요.

제가 가장 먼저 멈출 곳은 **3번, ChatGPT 열기를 눌렀는데 평소 앱과 다른 화면이 나오는 순간**이에요. 그다음은 **6번, 긴 글 속에서 수정할 곳을 찾아야 하는 순간**이고요. 잘못 지울까 봐 그냥 원래 하던 대로 “꽃집 인스타 글 써 줘”라고 물어볼 수도 있어요.

오늘 한 번 쓰는 건 해볼 수 있어도, **다음부터 한 줄로 맡기도록 저장하는 과정은 이 화면들만으로 못 하겠어요.** ‘한 번 넣어 두기’ 탭이 있다는 건 보이지만, 그 안의 설정 화면과 앱에서 누를 위치는 보이지 않아요.

**‘프로젝트’는 꽃집 일을 모아 두는 곳인가 보다 하고 짐작할 뿐이에요. ‘지침’은 이 화면만으로 뜻을 알 수 없어요.** 복사한 매뉴얼을 어디에 넣는지, 채팅에 붙이는 것과 무엇이 다른지도 설명하지 못하겠어요.

**3. 가장 큰 막힘 세 가지**

- **포기 — 09·10·14번, ‘한 번 넣어 두기’와 프로젝트 안내**  
  영상에서 기대한 핵심인데, 제 휴대폰에서 저장을 끝내는 방법까지 이어지지 않아요. “무료로 된다”는 설명만으로는 시작할 수 없어요.

- **한참 헤맴 — 08~10번, 복사 → ChatGPT 열기 → ‘이번 일:’ 수정**  
  복사하면 무엇이 들어오는지, 앱이 열리면 제가 무엇을 해야 하는지 한 번에 연결되지 않아요. 긴 글을 붙이고 맨 아래를 고치는 작업도 휴대폰에서는 부담이에요.

- **한참 헤맴 — 08~17번, 긴 결과와 계속 떠 있는 단추**  
  실제로 써 보는 데 필요한 안내와 나중에 읽을 설명을 구분하기 어려워요. 02·05·06번에서는 아래 선택지가, 결과에서는 본문 일부가 떠 있는 바에 가려져 더 내려야 해요.

**4. 고치면 좋을 것 세 가지**

- **결과 맨 위를 ‘오늘 한 번 써 보기’로 시작해 주세요.**  
  가게 정보 다음에 오늘 맡길 일을 적는 칸을 두면 좋겠어요.

  > **오늘 올릴 게시물은 무엇인가요?**  
  > 예: 오늘 만든 꽃다발 사진으로 인스타그램 글 하나 쓰기  
  > 사진은 ChatGPT 앱에서 함께 붙여 주세요.

  단추는 **“매뉴얼과 오늘 부탁할 일 복사”**로 바꾸고, 복사 뒤에는 이렇게 보여 주세요.

  > **복사됐어요. ChatGPT 앱을 열고 입력칸을 길게 눌러 ‘붙여넣기’를 누른 뒤 보내세요.**

- **‘한 번 넣어 두기’를 휴대폰 설정 안내로 풀어 주세요.**  
  오늘 한 번 써 본 다음, 이렇게 이어지면 이해하겠어요.

  > **다음부터 짧게 부탁하고 싶다면**  
  > ChatGPT에 꽃집 전용 공간을 만들어 이 매뉴얼을 저장해요. 이 공간을 ‘프로젝트’라고 해요.  
  > ‘지침’은 AI가 계속 따라야 할 일하는 기준이에요.

  단추는 **“휴대폰에서 저장하는 방법 보기”**로 하고, 실제 앱 화면에 **누를 곳을 표시한 그림**을 순서대로 보여 주세요. 영어 메뉴가 나오면 그림 옆에 한국어 뜻도 붙여 주세요.

- **긴 설명은 사용 뒤로 보내고, 떠 있는 바를 줄여 주세요.**  
  순서는 **오늘 일 입력 → 복사 → 앱에 붙여넣기 → 다음부터 저장하기 → 추가 설명**이면 좋겠어요. 나머지는 다음 단추 아래에 접어 두세요.

  > **궁금할 때 읽는 설명: 확인할 것·무료 사용·출처**

  질문 화면에서는 마지막 선택지까지 바 위로 완전히 올라오게 해 주세요. 결과에서는 복사 후 큰 바를 작은 **“사용 순서 보기”** 단추로 줄이면 읽기가 편하겠어요.

**5. PDF나 프롬프트 한 장보다 나은가요?**

제 일을 고르면 필요한 기준을 골라 준다는 점은 PDF 한 장보다 좋아요. 모두에게 같은 글을 주는 것보다 제 꽃집에 맞춰지는 느낌도 있고요. 그런데 지금은 질문에 답한 뒤에도 긴 설명을 읽고, 복사하고, 앱을 바꾸고, 붙인 글을 수정해야 해서 쉽게 느껴지지는 않아요. **오늘 꽃집 게시물 하나를 실제로 만들고, 다음번에는 정말 한 줄만 써도 되는 상태까지 안내해 줘야** “PDF보다 낫다”고 느끼겠어요. 지금이라면 한 번은 시도하겠지만, 저장하다 막히면 평소처럼 ChatGPT에 그냥 물어볼 것 같아요.
