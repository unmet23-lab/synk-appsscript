**1. 화면을 따라가며**

- **01** — “우리 카페 인스타 글도 만들어 주겠네” 싶어서 노란 **‘내 매뉴얼 만들기’**부터 눌러요. ‘한 번 넣어 두면’이 뭘 하는 건지는 모르지만, 일단 질문부터 해 볼래요.
- **02** — **‘SNS 게시물 만들기’**를 골라요. 릴스도 포함되는 것 같아요. 아래에 선택지가 더 있는 것 같은데 떠 있는 이전·다음 바에 가려져서, 전부 보진 않고 A를 누를 것 같아요.
- **03** — 체크가 생기고 다음 버튼이 검게 바뀌어서 선택된 건 바로 알겠어요. **‘다음’**을 눌러요.
- **04** — 제가 인스타에 올리기만 하면 되는 걸 받고 싶어서 **‘올리기 직전까지’**를 골라요. 사진, 글, 해시태그 중 어디까지 준비해 준다는 건지는 조금 애매하지만 다음으로 가요.
- **05** — 가격 틀리면 곤란하고 가게 말투도 맞아야 하니 사실·숫자, 맞춤법·말투를 골라요. 링크·저작권도 골라 두지만, 제가 나중에 뭘 확인해야 하는지는 아직 몰라요. **‘다음’**을 눌러요.
- **06** — 처음에는 다섯 개 모두 두라니까 그대로 둬요. ‘사람 차례’라는 표현은 낯설지만, 중요한 버튼 누르기 전에 저한테 물어본다는 뜻으로 이해하고 **‘다음’**을 눌러요.
- **07** — 제가 써 본 **ChatGPT**를 골라요. ‘프로젝트에 넣어 둘 수 있다’는 말은 모르겠고, 새 채팅에서 바로 쓸 수 있다니까 **‘결과 보기’**를 눌러요.
- **08** — “다 됐네. 이제 어디 눌러야 하지?” 싶어요. 가게 이름을 넣으면 더 맞춰 줄 것 같아서 입력하려는데, 아래 떠 있는 복사·열기 버튼이 입력칸 근처를 덮어요. 일단 가게 이름을 적어요.
- **09** — **‘바로 써 보기’**가 선택돼 있어서 이대로 해요. 그런데 복사 버튼이 설명 안에도 있고 떠 있는 바에도 있어요. 같은 글인지 잠깐 망설이다가 가까운 **‘써 보기 글 복사’**를 눌러요.
- **10** — ‘이번 일’을 제가 바꿔 적어야 한다는 걸 여기서 알겠어요. 그런데 새 채팅마다 다시 붙여야 한다네요. 영상에서는 한 번 깔면 된다고 했는데, **‘한 번 넣어 두기’**로 돌아가야 하나 싶어요.
- **11** — 갑자기 확인표가 나와서 “ChatGPT 가기 전에 이것도 체크해야 하나?” 하고 멈춰요. 지금 체크할 필요 없다는 설명을 읽으면 알겠지만, 저는 제목과 동그라미부터 봐요. 일단 아래로 내려요.
- **12** — 확인표가 계속되고 또 설명이 시작돼요. ‘나에게 의미 있는 것’이 뭘 알려 주는지 바로 감이 안 와서 펼치지 않고 넘겨요.
- **13** — 설명 제목이 너무 많아요. 지금 카페 게시물 하나 만들러 왔는데 공부할 게 생긴 느낌이에요. **‘매뉴얼 저장은 무료로 충분해요’**는 궁금하지만, 나머지는 건너뛰어요.
- **14** — 여기서도 ‘프로젝트’가 나오는데 어디 있는 기능인지 모르겠어요. 무료라는 건 반갑지만 제가 눌러야 할 버튼은 안 보여요. 그냥 떠 있는 **‘ChatGPT 열기’**를 누르고 싶어요.
- **15** — **‘이어 보기 링크 복사’**, **‘결과 전체 복사’**, PDF까지 나와서 복사 종류가 헷갈려요. ChatGPT에 넣을 건 결과 전체인가 싶어요. 피드백은 아직 써 보지도 않았으니 넘겨요.
- **16** — 끝까지 왔는데 매뉴얼을 저장한 건지, 만든 것뿐인지 모르겠어요. 답을 바꾸기보다는 떠 있는 **‘써 보기 글 복사’ → ‘ChatGPT 열기’**를 눌러 볼래요.
- **17** — 앞 화면과 거의 같아서 새로 할 일은 못 찾겠어요. Instagram 링크는 이미 거기서 왔으니 누르지 않고 ChatGPT로 가요.

**2. 지금 바로 쓰려면 제가 할 행동**

1. 결과 화면에서 가게 이름과 영업시간 같은 정보를 적어요. ‘더 적기’는 귀찮아서 일단 안 펼쳐요.
2. 떠 있는 **‘써 보기 글 복사’**를 눌러요.
3. **‘ChatGPT 열기’**를 눌러요. 웹으로 열리면, 익숙한 ChatGPT 앱으로 직접 옮겨 갈 것 같아요.
4. ChatGPT에서 새 채팅을 열고 입력칸을 길게 눌러 붙여 넣어요.
5. 붙인 긴 글 끝으로 가서 **‘이번 일: 이번 주 신메뉴 딸기라떼를 인스타에 올리기 직전까지 준비해 줘.’**라고 고쳐 적어요.
6. 사진도 필요하겠다는 생각이 들면 사진을 붙이고 보내요.
7. 결과를 본 뒤 앱 전환으로 인스타그램 안에 열어 둔 이 페이지에 돌아와요. 다음에도 한 줄만 쓰려면 어떻게 저장하는지 다시 찾아요.

**제일 먼저 멈출 곳은 5번이에요.** 긴 글을 붙였는데 끝부분까지 찾아서 고쳐야 하면 “그냥 평소처럼 딸기라떼 홍보 글 써 달라고 할까?” 싶어요.

한 번 써 보는 데 성공해도, **다음부터 한 줄로 쓰는 설정에서 다시 멈춰요.** ‘한 번 넣어 두기’를 눌러 보겠지만, 첨부된 화면에는 그 탭의 내용이 없어서 실제 설정 방법은 알 수 없어요.

**‘프로젝트’는 이 화면만 보고 어디에 만들고 어떻게 들어가는지 모르겠어요. ‘지침’도 무엇을 어디에 붙이는 건지 알 수 없어요.** 둘 다 매뉴얼을 저장하는 것과 관련 있다는 정도만 짐작해요.

**3. 가장 큰 막힘 세 가지**

1. **포기 — 09~10, ‘바로 써 보기’와 ‘한 번 넣어 두기’**  
   저는 “한 번 깔면 다음부터 한 줄” 때문에 들어왔어요. 그런데 기본으로 선택된 방법은 매번 다시 붙이는 방식이에요. 첫 실행에 성공해도 제가 기대한 설정은 끝나지 않아서, 결국 평소처럼 짧게 질문할 것 같아요.

2. **한참 헤맴 — 09·10·15, 여러 복사 버튼**  
   ‘써 보기 글’, ‘매뉴얼 전문’, ‘결과 전체’, ‘이어 보기 링크’가 각각 무엇인지 구분하기 어려워요. 특히 **‘결과 전체 복사’가 더 완전한 매뉴얼인가?** 싶어서 이미 복사하고도 다시 고민해요.

3. **한참 헤맴 — 08~15, 긴 결과와 떠 있는 바**  
   저는 복사해서 쓰러 왔는데 사용법, 확인표, 설명, 요금제, 저장까지 계속 나와요. 떠 있는 바는 찾기 쉽지만 입력칸과 본문 일부를 가려서, 중요한 내용을 놓쳤는지 확인하려고 다시 스크롤하게 돼요.

**4. 고치면 좋을 것 세 가지**

1. **결과 첫 화면에서 두 가지 행동을 바로 고르게 해 주세요.**  
   가게 정보 아래에 다음 문구와 버튼을 두면 좋겠어요.

   > 매뉴얼이 완성됐어요. 먼저 한 번 써 보거나, 다음에도 쓰도록 저장하세요.

   버튼: **‘지금 게시물 하나 만들기’ / ‘다음부터 한 줄로 쓰게 설정하기’**

   각 버튼 아래에는 **‘새 채팅마다 붙여 넣어요’ / ‘ChatGPT에 매뉴얼을 저장해요’**라고 차이를 적어 주세요.

2. **이번에 맡길 일을 이 페이지에서 입력하게 해 주세요.**  
   복사한 긴 글 끝을 휴대폰에서 수정하는 게 제일 번거로워요.

   > 이번에 만들 게시물은 무엇인가요?  
   > 예: 신메뉴 딸기라떼 소개. 가격 6,000원, 금요일 출시.

   버튼: **‘매뉴얼과 이번 일을 함께 복사’**

   복사 후 안내:

   > 복사됐어요. ChatGPT 앱에서 새 채팅을 열고, 입력칸을 길게 눌러 붙여 넣은 뒤 보내세요.

3. **설명은 첫 사용 뒤로 보내고, 복사 버튼 이름을 구분해 주세요.**  
   첫 부분에는 가게 정보와 실행 단계만 두고, 확인표·요금제·긴 설명은 **‘사용법과 주의사항 더 보기’** 안에 넣으면 좋겠어요.

   버튼 이름도 **‘ChatGPT에 붙일 글 복사’**, **‘이 결과 페이지 링크 복사’**, **‘설명까지 전부 복사’**로 바꿔 주세요. 떠 있는 바는 더 얇게 만들면 입력칸과 선택지를 보기 편하겠어요.

**5. PDF나 프롬프트 한 장보다 나은가요?**

제 일을 고르고 가게 정보를 넣을 수 있다는 건 PDF보다 좋아요. 선택하는 것도 어렵지 않았어요. 그런데 결과에 오면 읽을 게 너무 많고, 정작 ChatGPT에 한 번 넣어 두는 방법은 바로 안 잡혀요. 지금 상태라면 “내 카페에 맞춰 주는 질문지는 좋았는데, 쓰는 건 여전히 복잡하네”라고 느낄 것 같아요. 가게 정보와 이번 일을 적고 한 번 복사해서 바로 결과를 받는 데까지 이어지면 확실히 더 좋겠지만, 지금은 잘 만든 프롬프트 한 장을 받아 바로 붙이는 쪽이 더 편할 수도 있어요.
