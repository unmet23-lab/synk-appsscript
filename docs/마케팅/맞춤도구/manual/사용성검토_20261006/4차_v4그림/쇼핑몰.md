저라면 “이번에는 받아만 두는 프롬프트가 아니라 실제로 쓰게 될까?” 하는 마음으로 시작해요. 글씨가 크고 선택한 표시가 뚜렷한 건 좋아요. 다만 제 목표는 **고객 문의 답장 하나를 실제로 만들어 보고, 컴퓨터에서도 계속 쓰는 것**이에요.

**1. 화면을 순서대로 따라가면**

- **01** — “질문 다섯 개, 약 1분”이면 해볼 만해요. 다만 ‘한 번 넣어 둔다’가 어디에 어떻게 넣는다는 건지는 아직 모르겠어요. **‘내 매뉴얼 만들기’**를 눌러요.
- **02** — 고객 답장과 상세페이지 둘 다 필요한데 하나만 고르라네요. 당장 자주 하는 **‘고객 문의 답장’**을 고르겠어요. 상세페이지는 ‘문서·보고서 쓰기’에 들어가는지 애매해요.
- **03** — 테두리와 노란 체크 덕분에 선택됐다는 건 확실해요. 사진에는 SNS가 선택돼 있지만, 저는 고객 문의 답장이 선택됐는지 보고 **‘다음’**을 눌러요.
- **04** — 저는 고객에게 복사해서 보낼 답장이 필요하니 **‘바로 쓸 수 있는 완성본’**을 고르겠어요. ‘올리기 직전까지’와 뭐가 더 들어가는지 잘 모르겠지만, 직접 보내는 건 같다고 하니 일단 다음으로 가요.
- **05** — 고객에게 틀린 배송일이나 가격을 안내하면 안 되니까 **‘사실·숫자’, ‘맞춤법·말투’, ‘링크·주소’**를 고르겠어요. 맨 아래에도 항목이 있는 것 같은데 떠 있는 바에 가려져서, 더 내려 본 뒤 다음을 눌러요.
- **06** — 다섯 개 모두 두라고 하니 그대로 두겠어요. 다만 ‘내가 쓴 글 고치기’까지 매번 물으면 답장 다듬을 때 번거롭지 않을까 싶어요. **아래 마지막 항목을 확인하고 ‘다음’**을 눌러요.
- **07** — **ChatGPT**를 고르면 돼서 여기서는 안 막혀요. ‘새 채팅’은 아는데 ‘프로젝트’는 평소 안 써서 모르겠어요. **‘결과 보기’**를 눌러요.
- **08** — 제 선택이었다면 여기에는 ‘고객 문의 답장’이 나와야겠죠. 제공된 화면은 SNS 예시라 제 업무에 맞는 결과 문구는 확인할 수 없어요. 일단 **‘가게 정보 넣기’ 쪽으로 내려가요.**
- **09** — 가게 정보에 오늘 맡길 일까지 적으려니 “1분은 질문 고르는 시간만이었구나” 싶어요. 그래도 실제 배송 문의 하나를 적고 **‘ChatGPT에 붙일 글 복사’**를 누르겠어요.
- **10** — 복사하고 ChatGPT를 열어 새 채팅에 붙이면 된다는 건 알겠어요. 그런데 ‘새 채팅마다 다시 붙여야 한다’를 보니 영상에서 기대한 방식과 달라서 **‘한 번 넣어 두기 보기’**에 눈이 가요.
- **11** — 한 줄 예시는 이해하기 쉬운데 전부 SNS 쪽이라 고객 답장에는 어떻게 쓸지 제가 바꿔 생각해야 해요. “여기까지만”이라는 문구에서 이제 끝인가 싶고, **더 내리거나 ChatGPT를 열겠어요.**
- **12** — ‘사람 차례 확인표’가 나오니 제가 지금 이것도 다 체크해야 완료되는 건지 잠깐 헷갈려요. 돈 쓰기나 로그인은 이번 답장과 관계없어서 **체크하지 않고 내려요.**
- **13** — 아직 설명이 많이 남았네요. ‘나에게 의미 있는 것’이라고 하지만 지금은 고객 답장부터 보고 싶어서 **펼치지 않고 내려요.**
- **14** — 비슷한 설명 제목이 계속 나와서 이쯤이면 읽는 걸 멈출 것 같아요. Plus를 이미 쓰니 무료 요금제 설명도 급하지 않아서 **빠르게 내려요.**
- **15** — **‘이 페이지 링크 복사’**가 이제야 눈에 들어와요. 평소 컴퓨터로 쓰는 저한테는 이게 중요해서, 복사해 카카오톡 나에게 보내기에 남기겠어요.
- **16** — 아직 ChatGPT에서 써보지도 않았는데 “도움이 됐나요?”는 답하기 일러요. 답 바꾸기는 나중에 쓰고 **아래로 내려요.**
- **17** — 끝까지 봤는데 ‘링크 복사’, ‘붙일 글 복사’, ‘PDF 저장’ 중 제가 무엇을 보관해야 하는지 한 번 정리하게 돼요. 다음에 한 줄로 쓰려면 설정이 필요하니 **위로 돌아가 ‘한 번 넣어 두기’**를 누르겠어요.
- **18** — 여기서 처음으로 “프로젝트는 일 전용 폴더”라는 뜻이 잡혀요. **‘매뉴얼 복사’ → ‘ChatGPT 열기’**를 누르겠지만, 넘어가면 지금 설명을 못 보니 단계를 기억해야 해요.
- **19** — 노란 표시 덕분에 **프로젝트 옆 +, 만든 뒤의 •••와 ‘프로젝트 설정’**을 찾을 수 있겠어요. 다만 실제 앱에서도 같은 위치인지는 가서 봐야 하고, 만들고 나면 이 화면으로 다시 돌아올 것 같아요.
- **20** — 매뉴얼은 ‘지침’ 칸에, 다음 요청은 그 프로젝트 안의 새 채팅에 넣는 거군요. 그런데 **붙인 뒤 저장을 어떻게 마치는지**는 그림에서 확실히 안 보여요. 일단 넣고 안내된 확인 질문을 보내보겠어요.

**2. 지금 휴대폰에서 실제로 쓰려면**

저는 설정부터 끝내기보다 **고객 문의 하나에 답장이 잘 나오는지 먼저 확인**하겠어요.

1. 결과의 ‘바로 써 보기’에서 가게 이름과 필요한 기본 정보를 적어요.
2. ‘오늘 맡길 일’에 실제 문의와 제가 아는 정보를 적어요. 예를 들면 “고객이 언제 출고되는지 물었어. 내일 출고 예정이야. 정중하고 짧은 답장 써 줘.”
3. ‘ChatGPT에 붙일 글 복사’를 눌러요.
4. 아래 ‘ChatGPT 열기’를 눌러요. 저는 지금 인스타 안에서 보고 있으니, 이때 앱으로 갈지 다른 웹 화면으로 갈지는 눌러봐야 알겠어요.
5. ChatGPT 앱이 바로 열리면 새 채팅을 만들어요. 웹 화면이 열리고 로그인을 요구하면, 이미 쓰던 ChatGPT 앱을 직접 열겠어요.
6. 입력칸을 길게 눌러 붙여넣고 전송해요. 답장을 읽고 출고일과 표현을 확인해요.
7. 답장이 괜찮으면 앱 전환으로 인스타의 안내 화면에 돌아와 ‘한 번 넣어 두기’를 봐요.
8. ‘매뉴얼 복사’를 다시 누르고 ChatGPT로 넘어가 프로젝트를 만들어요. 이후에는 안내와 ChatGPT를 오가며 지침 칸을 찾아 붙여넣어요.

**가장 멈추기 쉬운 순간은 7~8번이에요.** 답장 하나는 이미 받았는데, 앞으로 편하게 쓰려면 다시 설정해야 하네요. 휴대폰에서 메뉴 찾고 안내로 돌아오는 게 귀찮아지면 “이건 컴퓨터에서 하자” 하고 링크만 보내둘 것 같아요. 예전에 받은 PDF도 그렇게 미뤘다가 안 썼어요.

또 화면에는 컴퓨터로 보낸 링크에 **가게 정보와 오늘 맡길 일은 들어가지 않는다**고 적혀 있어요. 휴대폰에서 열심히 적은 다음 그걸 알면, “그럼 처음부터 컴퓨터에서 할걸” 싶겠어요.

‘프로젝트’와 ‘지침’은 **18번까지 읽으면 대략 이해할 수 있어요.** 프로젝트는 고객 답장 일을 모아두는 폴더, 지침은 그 폴더에서 AI가 계속 참고할 매뉴얼을 넣는 칸이네요. 07~08번에서 처음 나왔을 때는 거기까지 이해하지 못했어요.

**3. 가장 큰 막힘 세 가지**

| 심각도 | 위치 | 제가 막히는 이유 |
|---|---|---|
| **포기** | **18~20번**, 프로젝트 생성·지침 입력 안내 | 인스타와 ChatGPT를 오가며 여러 메뉴를 찾아야 해요. “컴퓨터에서 나중에 하자”로 미루는 순간 실제 사용으로 이어지지 않을 것 같아요. |
| **한참 헤맴** | **08~10번**, 두 사용 방식과 복사 단추 | 영상에서는 한 번 넣으면 된다고 했는데 기본 화면은 매번 붙여넣는 방식이에요. ‘붙일 글’, ‘매뉴얼’, ‘페이지 링크’가 각각 무엇을 복사하는지, 무엇을 해야 설정이 끝나는지 구분해야 해요. |
| **한참 헤맴** | **08~17번**, 긴 결과와 **10·15번**의 컴퓨터 이동 안내 | 지금 실행할 일, 나중에 읽을 설명, 확인표가 길게 이어져요. 특히 저에게 필요한 ‘컴퓨터에서 이어 하기’를 찾기 전에 휴대폰에서 정보를 입력하게 돼요. |

**4. 구체적으로 고치면 좋을 것 세 가지**

1. **결과 맨 위에서 휴대폰 체험과 컴퓨터 설정을 바로 나눠 주세요.**

   제가 고객 문의 답장을 골랐다면 이렇게 보이면 좋겠어요.

   > **고객 문의 답장 매뉴얼이 준비됐어요.**  
   > 지금 답장 하나를 만들어 보거나, 컴퓨터에서 한 번 설정해 두세요.

   단추는 **‘지금 답장 하나 써 보기’**, **‘컴퓨터에서 설정하기’**로요. 두 번째를 누르면 바로 아래에:

   > **이 결과 링크를 나에게 보내세요.**  
   > 컴퓨터에서 열면 고른 답이 그대로 이어져요. 가게 정보와 고객 문의는 컴퓨터에서 입력하세요.

   그리고 **‘결과 링크 복사’**를 두면 저는 여기서 바로 쓸 것 같아요.

2. **탭과 복사 단추에 ‘어디에 넣는지’를 써 주세요.**

   - ‘바로 써 보기’ → **‘새 채팅에서 한 번 써 보기’**
   - ‘한 번 넣어 두기’ → **‘프로젝트에 저장해 계속 쓰기’**
   - 체험 탭의 ‘붙일 글 복사’ → **‘새 채팅에 붙일 글 복사’**
   - 저장 탭의 ‘매뉴얼 복사’ → **‘지침 칸에 넣을 매뉴얼 복사’**

   복사한 직후에도 다음 행동이 나오면 좋겠어요.

   > **복사했어요. ChatGPT의 새 채팅 입력칸에 붙여넣고 보내세요.**

   저장할 때는:

   > **복사했어요. 프로젝트의 ‘지침’ 칸에 붙여넣으세요.**

3. **‘한 번 넣어 두기’는 실제로 오갈 순서대로 짧게 나눠 주세요.**

   지금은 매뉴얼부터 복사하고 프로젝트를 만들게 돼요. 저는 프로젝트부터 만든 뒤 돌아와 복사하는 편이 덜 헷갈리겠어요.

   > **① ChatGPT에서 ‘고객 문의 답장’ 프로젝트를 만드세요.**  
   > 만든 뒤 이 안내로 돌아오세요.

   > **② 아래 매뉴얼을 복사하세요.**  
   > 프로젝트의 ••• → 프로젝트 설정 → 지침 칸에 붙여넣으세요.

   마지막은 실제 화면의 저장 완료 지점까지 그림으로 보여주고:

   > **③ 그 프로젝트 안에서 새 채팅을 열어 확인하세요.**  
   > “내가 맡길 일과 네가 먼저 물어봐야 할 일을 알려 줘.”

   **‘사용자 지정 지침이 아니라 이 프로젝트의 지침 칸이에요’**라는 문장도 마지막 주의사항보다 ② 바로 옆에 있어야 찾는 중에 도움이 돼요.

**5. PDF나 프롬프트 한 장보다 나은가**

제 일을 고르고, 완성 수준과 확인할 것까지 정한다는 점은 PDF보다 나아요. 특히 실제 고객 문의를 넣어서 바로 답장을 받아볼 수 있다는 건 해볼 이유가 있어요. 그런데 지금 화면은 결과를 받은 뒤 읽고 설정할 일이 많아서, 휴대폰으로 보는 저한테는 결국 또 “나중에 컴퓨터에서 볼 자료”가 될 위험이 커요. **질문 다섯 개를 끝냈다는 것보다, 제 문의로 쓸 만한 답장 하나를 받고 다음에도 어디서 쓰는지 알게 되는 것**이 더 중요해요. 거기까지 이어지면 PDF보다 확실히 낫고, 링크만 저장하고 끝나면 제 입장에서는 별 차이가 없어요.

**6. 18~20번 그림 안내만으로 설정할 수 있을까**

**그림과 비슷한 화면이 나오면 해볼 수는 있겠어요. 다만 휴대폰에서 한 번에 끝낼 자신은 없어요.**

도움이 되는 부분은 구체적이에요.

- **18~19번의 사이드바 여는 단추와 프로젝트 옆 + 표시**: ‘프로젝트를 만들라’는 말만 있을 때보다 어디를 눌러야 할지 명확해요.
- **19번의 프로젝트 이름 입력창과 만들기 단추**: 제가 제대로 찾아왔는지 대조할 수 있어요.
- **19번의 ••• → 프로젝트 설정 그림**: 지침을 찾는 길에서 가장 도움이 돼요.
- **20번의 노란 테두리로 표시한 지침 칸**: 복사한 긴 글을 채팅창이 아니라 여기에 넣는다는 걸 이해하게 돼요.

여전히 막힐 곳은 **붙여넣은 다음의 완료 동작**이에요. 저장 단추를 눌러야 하는지, 그냥 닫아도 되는지 그림만으로는 확신이 안 들어요. 또 다음부터 써야 할 **‘그 프로젝트 안의 새 채팅’ 화면**도 한 장 있으면 좋겠어요. 익숙한 전체 새 채팅을 눌렀다가 매뉴얼이 적용되지 않으면, 저는 설정이 잘못됐다고 생각할 것 같아요.

마지막 확인 질문은 좋아요. 다만 ‘사람 차례가 그대로 나오면 성공’이라고만 하면 앞에서 고른 다섯 가지를 다시 기억해야 해요. **“돈 쓰기·로그인·게시·삭제·내 글 수정 전에 묻겠다고 답하면 확인됐어요”**처럼 제 선택에 맞는 예상 내용을 옆에 보여주면, 설정이 끝났다는 확신이 들겠어요.
