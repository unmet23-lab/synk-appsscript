저라면 **“가게 인스타 글을 다음부터 한 줄로 시키면 되는구나”** 하고 들어왔을 것 같아요. 노란 체크가 생겨서 골랐는지는 잘 보이는데, 결과부터는 읽을 게 갑자기 많아져요.

**1. 화면별로 따라가 보기**

- **01** — “1분이면 된대. 한번 해 보자.” 설명은 대충 보고 **‘내 매뉴얼 만들기’**를 눌러요. ‘한 번 넣어 두면 된다’는 말이 제일 기억에 남아요.
- **02** — 가게 인스타를 맡고 있으니까 **‘SNS 게시물 만들기’**를 눌러요. ‘짧은 영상 문구’도 포함돼 있어서 제 일이 맞다고 생각해요.
- **03** — 노란 체크랑 검은 ‘다음’이 보여서 선택된 걸 바로 알아요. **‘다음’**을 눌러요.
- **04** — 완성본이랑 올리기 직전의 차이를 잠깐 생각해요. “사진이랑 해시태그까지 챙겨 준다는 건가?” 하고 **‘올리기 직전까지’ → ‘다음’**을 눌러요.
- **05** — 가격 틀리면 안 되고 가게 말투도 중요해서 골라요. 링크랑 사진도 해당될 것 같아 체크하지만, **‘저작권·초상권’을 고르면 AI가 뭘 확인해 주는지는 모르겠어요.** 일단 다음으로 가요.
- **06** — 처음엔 다섯 개 모두 두라고 해서 그대로 넘어갈 것 같아요. **마지막 항목은 아래 바에 가려 잘 안 보이는데**, 굳이 확인하려고 내리지 않고 ‘다음’을 눌러요.
- **07** — 써 본 게 ChatGPT라서 바로 골라요. 아래에 ‘프로젝트’가 나오지만 지금은 몰라도 될 것 같아서 **‘결과 보기’**를 눌러요.
- **08** — “만들어졌네. 이제 이거 누르면 되나?” 하고 **떠 있는 ‘붙일 글 복사’**부터 누를 것 같아요. 가게 정보를 적는 칸은 그 아래에 있어서 못 보고 넘어갈 수 있어요.
- **09** — 여기까지 먼저 봤다면 신메뉴 이름과 가격을 **‘오늘 맡길 일’**에 적겠어요. 그런데 본문 복사 단추와 아래 복사 단추가 같은 건지 망설여져요. 입력한 것까지 복사되는지 확인하고 싶어요.
- **10** — 이제 **복사 → ChatGPT 열기 → 붙여넣기**라는 건 알겠어요. 그런데 새 채팅마다 다시 붙여야 한다니, “영상에서는 한 번만 넣으면 된다던데?” 해서 **‘한 번 넣어 두기 보기’**가 눈에 들어와요.
- **11** — 예시를 보니 어떤 식으로 시키는지는 감이 와요. 다만 “지난 게시물 말투 그대로”라고만 해도 지난 게시물을 아는 건지는 모르겠어요. **여기서 설명 읽기를 끝내고 ChatGPT를 열 것 같아요.**
- **12** — 계속 내려왔다면 “이것도 내가 다 체크해야 끝나나?” 싶어요. 질문에서 골랐던 내용이 또 나와서, **체크하지 않고 아래로 넘겨요.**
- **13** — 제목이 많아서 필요한 걸 고르는 것조차 귀찮아져요. ‘말투는 예시 문장 두세 개’는 관심 있지만 지금 글 하나 만들고 싶어서 **펼치지 않고 내려요.**
- **14** — ‘웹페이지 속 숨은 지시’는 무슨 상황인지 모르겠어요. “나한테도 필요한 얘긴가?” 하다가 **‘무료로 충분해요’만 보고 내려요.**
- **15** — **‘이 페이지 링크 복사’**를 보고 아까 복사한 것과 헷갈려요. 이 링크를 ChatGPT에 붙이면 되는 건가 잠깐 생각해요. 휴대폰이라 PDF 저장은 건너뛰어요.
- **16** — 아직 ChatGPT에서 써 보지도 않았는데 도움이 됐는지 물어서 답하기 어려워요. 답을 바꿀 필요는 없으니 **계속 내려요.**
- **17** — 끝까지 왔는데도 매뉴얼을 설치한 건지 아닌지는 확신이 없어요. 결국 가장 눈에 띄는 **‘붙일 글 복사’ 다음 ‘ChatGPT 열기’**를 눌러요.
- **18** — “아, 한 번 넣는 건 이쪽이구나.” 프로젝트를 일 전용 폴더라고 하니 대충 이해돼요. **‘매뉴얼 복사’ → ‘ChatGPT 열기’**를 누르는데, 넘어가면 다음 설명을 못 보니까 외워야 해요.
- **19** — 그림의 노란 **‘+’와 ‘프로젝트 만들기’**는 찾기 쉬워요. 그런데 만들고 나서 다시 이 페이지로 돌아와야 **‘점 세 개 → 프로젝트 설정’**이라는 다음 순서를 확인할 수 있어요.
- **20** — 노란 테두리 덕분에 붙일 칸은 알겠어요. 다만 **붙인 다음 어디를 눌러야 저장이 끝나는지는 그림에서 못 찾겠어요.** 아래 긴 설명은 건너뛰고 ChatGPT로 돌아가 저장할 단추를 찾아볼 것 같아요.

실제로는 09~10쯤에서 ChatGPT로 넘어가고, 11~17은 끝까지 읽지 않을 가능성이 커요.

**2. 지금 바로 써 보려면 제가 할 순서**

1. 이 페이지의 ‘오늘 맡길 일’에 “신메뉴 딸기라떼 인스타 글 써 줘. 6,000원이고 금요일 출시야”라고 적어요.
2. **‘ChatGPT에 붙일 글 복사’**를 눌러요.
3. **‘ChatGPT 열기’**를 눌러요. 저는 앱이 열릴 거라고 기대해요.
4. 웹이 열리고 로그인하라고 하면, 일단 원래 쓰던 ChatGPT 앱을 직접 열어요.
5. 새 채팅을 열고 입력칸을 길게 눌러 붙여넣어요.
6. 붙여진 글이 길면 다 읽지는 않고, 제가 적은 신메뉴 이야기가 있는지 끝부분만 봐요. 사진이 필요하면 사진도 붙이고 보내요.
7. 답변이 나오면 가격과 출시일을 확인하고 가게 인스타에 쓸 문장을 골라요.

**첫 번째로 멈출 곳은 ChatGPT를 여는 순간이에요.** 인스타에서 보던 페이지, 새로 열린 웹, 원래 쓰던 앱 사이에서 어디로 가야 하는지 헷갈릴 수 있어요. 다시 안내를 보려고 돌아왔는데 페이지를 못 찾으면 그냥 ChatGPT에 평소처럼 “딸기라떼 홍보 글 써 줘”라고 할 것 같아요.

두 번째는 **다음번 새 채팅에서도 매뉴얼이 적용되는지**예요. 복사해서 한 번 보냈으니 설치가 끝났다고 생각할 수 있어요. ‘바로 써 보기’에서는 매번 다시 붙여야 한다는 설명을 놓치기 쉬워요.

‘프로젝트’는 18의 **“일 전용 폴더”**를 읽고 나서야 이해돼요. ‘지침’도 그때 **“이 폴더에서 AI가 일할 때 읽는 매뉴얼을 넣는 칸”** 정도로 이해해요. 07~08까지만 봤다면 둘 다 설명하기 어려워요.

**3. 가장 큰 막힘 세 가지**

| 심각도 | 위치 | 제가 막히는 이유 |
|---|---|---|
| **한참 헤맴** | **08~10, ‘바로 써 보기’와 떠 있는 복사 단추** | 저는 ‘한 번 깔기’를 하러 왔는데 기본은 일회용 사용이에요. 복사부터 누르면 가게 정보 입력과 두 방식의 차이를 놓쳐서, 지금 무엇을 완료한 건지 몰라요. |
| **포기** | **18~20, 프로젝트에 넣는 과정** | 한 번 넣어 두는 설정은 여기서 포기할 수 있어요. 두 앱을 오가며 여러 메뉴를 찾아야 하고, 마지막 저장 완료 모습도 안 보여요. 당장 게시물 하나가 필요한 저한테는 일이 커진 느낌이에요. |
| **잠깐 망설임** | **06의 마지막 선택지, 09의 아래 단계, 19~20의 그림·설명 위에 겹치는 바** | 계속 보이는 단추는 편하지만 읽을 부분도 가려요. 특히 06에서는 마지막 선택지 내용을 확인하지 않은 채 넘어갈 것 같아요. |

**4. 고치면 좋을 것 세 가지**

1. **결과 첫 화면에서 두 가지 행동을 먼저 고르게 해 주세요.**  
   긴 소개와 가게 정보보다 먼저 아래 두 단추가 있으면 목적에 맞게 누를 수 있어요.

   - **오늘 글 하나 만들어 보기**  
     “매뉴얼과 오늘 할 일을 복사해 새 채팅에 보내요.”
   - **한 번 설정하고 계속 쓰기**  
     “ChatGPT에 가게 전용 공간을 만들어요. 다음부터는 그 안에서 할 일만 보내요.”

   영상에서 말한 ‘한 번 깔기’가 어느 단추인지 바로 연결됐으면 해요.

2. **복사하기 전에 무엇이 복사되는지 한 줄로 알려 주세요.**  
   ‘오늘 맡길 일’ 바로 아래에 **“매뉴얼과 위에 적은 일을 함께 복사해요.”**를 넣고, 단추는 **‘매뉴얼 + 오늘 할 일 복사’**로 바꿔 주세요. 복사한 뒤에는 이렇게 보여 주면 좋아요.

   **“복사했어요. ChatGPT 새 채팅의 입력칸을 길게 눌러 붙여넣고 보내세요.”**

   이 순서를 본 뒤 ‘ChatGPT 열기’를 누르게 하면 덜 불안해요.

3. **‘한 번 넣어 두기’는 한 단계씩 보고 돌아올 수 있게 해 주세요.**  
   상단에 지금 할 일 하나를 크게 두고, **‘했어요 · 다음 단계’**로 넘기고 싶어요.

   **“1. 매뉴얼을 복사하세요.”**  
   **“2. ChatGPT에서 ‘프로젝트’ 옆 +를 누르고, 이름을 ‘우리 가게 SNS’로 만드세요.”**  
   **“3. 만든 프로젝트의 ⋯ → 프로젝트 설정 → 지침에 붙여넣으세요.”**  
   **“4. 이 프로젝트 안에서 새 채팅을 열면 준비 끝이에요.”**

   3단계에는 **붙여넣은 뒤 저장을 마치는 조작과 완료된 화면**도 보여 주세요. 안내 그림이 아래 바에 가리지 않게 자리도 확보해 주세요.

**5. PDF나 프롬프트 한 장보다 나은가요?**

질문을 고르는 동안은 더 좋아요. SNS 업무를 고르고 가격이나 말투를 확인하라고 정할 수 있으니까 제 용도로 만든다는 느낌이 있어요. 그런데 결과가 나오면 긴 설명을 또 읽어야 해서, 휴대폰으로 빨리 쓰려는 저한테는 다시 숙제가 생긴 느낌이에요. **가게 정보와 오늘 할 일까지 한꺼번에 복사해 바로 괜찮은 글이 나오면 PDF보다 낫다고 느낄 것 같아요.** 반대로 프로젝트 설정에서 막히면 “그냥 복사할 프롬프트 하나 주면 됐던 거 아닌가?” 싶어요. 제일 기대한 건 매뉴얼을 받는 것보다 다음번 일이 쉬워지는 거니까요.

**6. 18~20의 그림만 보고 한 번 넣어 둘 수 있을까요?**

**화면이 그림과 비슷하게 나오면 프로젝트 생성과 붙여넣기까지는 해 볼 수 있어요. 다 끝났다는 확신은 부족해요.**

실제로 도움이 되는 건 다음 부분이에요.

- **18~19의 노란 + 표시:** ‘프로젝트’라는 글자만 찾는 것보다 눌러야 할 자리가 분명해요.
- **19의 프로젝트 이름 예시:** ‘SNS 게시물 직원’처럼 이름을 붙이면 된다는 걸 바로 따라 할 수 있어요.
- **19의 ⋯와 ‘프로젝트 설정’ 표시:** 매뉴얼을 채팅창에 보내는 게 아니라 설정으로 들어가야 한다는 걸 보여 줘요.
- **20의 지침 칸 테두리:** 붙여넣을 곳이 정확히 보여요.

여전히 막히는 건 **안내를 보면서 동시에 ChatGPT를 조작할 수 없다는 점**이에요. `+ → 만들기 → ⋯ → 설정 → 지침`을 한 번에 외우기는 어려워서 계속 돌아와야 해요. 앱 화면이 그림과 다르면 같은 메뉴를 찾는 데 더 오래 걸릴 것 같고요.

마지막에는 붙여넣은 매뉴얼이 실제로 들어 있는 화면과 **“이제 ‘우리 가게 SNS’ 프로젝트 안에서 새 채팅을 여세요”**라는 안내가 크게 있으면 좋겠어요. 지금도 확인용 질문은 있지만 긴 문단 사이에 있어서, 저라면 읽기 전에 설정이 끝났다고 생각하고 나갈 수 있어요.
