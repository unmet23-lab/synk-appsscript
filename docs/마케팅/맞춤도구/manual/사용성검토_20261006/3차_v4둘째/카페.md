질문 고르는 데까지는 해볼 것 같아요. 노란 체크가 뜨면 골랐다는 게 확실해서 좋아요. 그런데 결과에서는 **“그래서 지금 뭘 복사하면 되지?”**부터 헷갈려요. 아래는 제가 이 화면을 휴대폰으로 보고 쓰는 입장에서 적은 반응이에요.

**1. 화면별 반응**

| 이미지 | 실제로 쓰듯이 따라가 본 반응 |
|---|---|
| **01** | 영상에서 말한 제 가게용 매뉴얼을 만들려고 들어왔어요. 설명은 대충 넘기고 노란 **‘내 매뉴얼 만들기’**부터 눌러요. |
| **02** | 가게 인스타를 맡으니까 **‘SNS 게시물 만들기’**를 골라요. 아래에 선택지가 더 있는데 떠 있는 이전·다음 바가 가려서, 다 볼 필요가 있는지는 모르겠어요. |
| **03** | 노란 체크와 검은 ‘다음’ 단추가 생겨서 바로 다음으로 가요. 이 화면에서는 할 일이 분명해요. |
| **04** | 제가 인스타에 올리기만 하면 되는 걸 원해서 **‘올리기 직전까지’**를 골라요. ‘영상 속 실제 사례’가 뭐였는지는 기억 안 나지만 다음을 눌러요. |
| **05** | 사실·숫자, 맞춤법·말투, 링크·주소는 필요해 보여요. 저작권·초상권은 정확히 뭘 확인해 준다는 건지 모르겠지만, 사진을 쓰니까 일단 고르고 다음으로 가요. |
| **06** | SNS 글 만드는 건데 결제·로그인·삭제까지 나오니까 갑자기 복잡해져요. ‘다섯 개 모두 추천’이라고 하니 골라진 걸 그대로 두고 **‘다음’**을 눌러요. |
| **07** | 제가 써본 건 ChatGPT라서 그걸 골라요. ‘새 채팅’은 알겠는데 ‘프로젝트’는 모르겠고, 일단 **‘결과 보기’**를 눌러요. |
| **08** | 매뉴얼이 만들어졌으니 써보려고 해요. 그런데 가게 이름을 쓰기도 전에 아래에 **‘붙일 글 복사’**가 보여서, 먼저 입력해야 하는지 그냥 복사해도 되는지 망설여요. |
| **09** | 가게 정보와 오늘 맡길 일을 쓰는 곳을 발견해요. 딸기라떼 게시물을 부탁하는 내용을 적고 싶은데, 본문에도 복사 단추가 있어서 **아래 떠 있는 복사와 같은 건지** 모르겠어요. |
| **10** | 이제 복사→ChatGPT 열기→붙여넣기라는 건 알겠어요. 그런데 ‘새 채팅마다 다시 붙여야 한다’고 해서, 영상에서 본 **한 번 깔아두기**는 아직 안 된 거구나 싶어요. |
| **11** | 한 줄 예시를 보니 이걸 복사하면 더 빠를 것 같아요. 그런데 매뉴얼부터 넣어야 하는지, 예시만 보내도 되는지 헷갈리고 ‘아래 설명 분량’은 일단 **‘간단히’**를 눌러요. |
| **12** | 동그라미가 있으니 지금 체크해야 하는 것처럼 보여요. 결제나 삭제는 오늘 할 일이 아니라서 넘기는데, **얼마나 더 내려야 끝나는지** 궁금해져요. |
| **13** | ‘나에게 의미 있는 것’이라는데 읽을 게 또 많아요. 제가 원한 건 게시물 하나라서 펼치지 않고 계속 내려요. |
| **14** | 요금제까지 나오니 혹시 쓰다가 돈이 드는 건가 싶어요. **‘무료로 충분’**만 보고 안심하고, 나머지는 넘겨요. |
| **15** | 저장 단추가 세 개라서 뭘 저장해야 하는지 다시 헷갈려요. ‘설명까지 전부 복사’가 매뉴얼 복사인 줄 알았다가, 아래에서 메모용이라는 설명을 보고 멈칫해요. |
| **16** | 아직 ChatGPT에서 써보지도 않았는데 ‘도움이 됐나요?’가 나와서 답할 수 없어요. 답을 바꾸면 처음부터 다시 해야 할까 봐 건드리지 않고 내려요. |
| **17** | 끝까지 왔는데 결국 해야 할 건 위에 있던 복사와 ChatGPT 열기였네요. 아래 바를 누를까 하다가, 영상에서 말한 설치 방법이 궁금해서 **‘한 번 넣어 두기’**로 돌아가요. |
| **18** | ‘프로젝트는 일 전용 폴더’라는 설명은 이해돼요. 하지만 휴대폰 ChatGPT에서 **사이드바와 프로젝트 설정이 어디 있는지** 모르겠어서, ‘매뉴얼 복사’ 후 앱을 열면 여기부터 찾게 될 것 같아요. |
| **19** | 잘 들어갔는지 물어보는 문장은 쓸 수 있겠어요. 그런데 ‘사용자 지정 지침’이라는 비슷한 말까지 나오고 설명도 길어서, 설치는 미루고 **그냥 새 채팅에 붙여 쓰는 쪽**으로 돌아갈 것 같아요. |

**2. 지금 바로 ChatGPT에서 쓰려면**

제가 실제로 시도할 순서는 이래요.

1. 인스타에서 열린 이 페이지의 **‘바로 써 보기’**로 가요.
2. 가게 이름을 적고, ‘오늘 맡길 일’에 **“딸기라떼 출시 게시물 써줘. 6,000원이고 금요일부터 팔아. 사진은 같이 보낼게.”**라고 써요.
3. 본문에 있는 **‘ChatGPT에 붙일 글 복사’**를 눌러요. 아래 바보다 이 단추가 방금 적은 내용과 가까워서 선택할 것 같아요.
4. **‘ChatGPT 열기’**를 눌러요. 앱이 열릴 줄 기대해요. 브라우저의 로그인 화면이 나오면, 그 화면을 나와 제가 쓰던 ChatGPT 앱을 직접 열 것 같아요.
5. ChatGPT에서 새 채팅을 열고 입력칸을 길게 눌러 **‘붙여넣기’**를 해요.
6. 붙은 글이 너무 길면 끝까지 읽지는 않을 것 같아요. 제가 적은 딸기라떼 내용이 있는지만 보고, 사진을 붙여서 보내요.
7. 결과가 이상하거나 제가 적은 일이 안 들어갔다면 앱 전환으로 인스타 쪽 페이지에 돌아와요. 그때 다른 복사 단추를 눌러야 하는 건지 다시 찾아요.

**가장 먼저 멈출 곳은 3번이에요.** 복사 단추가 여러 개라서, 제가 쓴 가게 정보와 오늘 할 일이 어느 단추에 포함되는지 확신이 없어요.

두 번째는 4번이에요. ChatGPT 앱 대신 로그인 화면이 나오면 귀찮아질 것 같아요. 다시 돌아왔을 때 입력한 내용까지 사라져 있다면 그날은 포기할 것 같고요.

‘한 번 넣어 두기’까지 하려면 앱과 안내 페이지를 여러 번 오가야 해요. **ChatGPT 앱에서 ‘프로젝트 설정’을 못 찾으면 설치는 포기하고 한 번 써보는 데서 끝낼 것 같아요.**

- **프로젝트:** 18번을 읽고 ‘이 일을 위한 폴더’라는 뜻은 알겠어요. 실제로 휴대폰에서 어디를 눌러 만드는지는 아직 모르겠어요.
- **지침:** 매뉴얼을 붙여넣는 칸이라는 건 짐작해요. ChatGPT의 어느 화면에 있는 칸인지는 모르겠어요. 19번의 ‘사용자 지정 지침’과 다른 곳이라는 설명까지 읽어야 해서 더 헷갈려요.

**3. 가장 큰 막힘 세 가지**

| 심각도 | 위치 | 막히는 이유 |
|---|---|---|
| **포기** | **18~19번**, 사이드바→새 프로젝트→프로젝트 설정→지침 안내 | 제가 아는 건 채팅 입력칸뿐이에요. 화면 사진 없이 메뉴 이름을 따라 찾아야 하고, 안내를 다시 보려면 앱을 오가야 해요. ‘한 번 깔기’가 생각보다 큰 숙제처럼 느껴져요. |
| **한참 헤맴** | **08~11번·15번**, 여러 복사 단추 | ‘붙일 글 복사’, ‘ChatGPT에 붙일 글 복사’, 예시 ‘복사’, ‘설명까지 전부 복사’가 나와요. **지금 제 일을 시키려면 무엇 하나를 복사해야 하는지** 판단해야 해요. |
| **한참 헤맴** | **08~17번 결과 전체**, 특히 11~14번 | 결과를 받았는데 사용법·예시·확인표·설명·요금제가 계속 이어져요. 중요한 걸 놓칠까 봐 내려보지만, 읽을수록 당장 할 일과 나중에 볼 내용이 섞여요. 떠 있는 위아래 바 때문에 본문을 볼 공간도 줄어요. |

**4. 고치면 좋을 것 세 가지**

**① 결과 첫 화면에서 ‘오늘 할 일 → 복사 → 앱 열기’를 바로 끝내게 해주세요.**

08번의 소개 다음에 바로 이 내용을 넣으면 좋겠어요.

> **첫 게시물부터 만들어 보세요**  
> 오늘 올릴 내용을 적으면, 매뉴얼과 함께 복사돼요.

입력칸 예시:

> 딸기라떼 출시 게시물 써줘. 6,000원, 금요일 출시. 사진은 함께 보낼게.

단추는 **‘매뉴얼 + 오늘 할 일 복사’**, 그다음 **‘ChatGPT 열기’**로 놓아주세요. 복사 후에는 이렇게 보여주면 확실해요.

> **복사했어요. ChatGPT의 새 채팅에 붙여넣고 보내세요.**

입력을 비워도 된다면 입력칸 바로 밑에:

> 비워 두고 복사해도 돼요. ChatGPT가 어떤 일을 맡길지 물어봐요.

**② ‘한 번 넣어 두기’는 휴대폰에서 찾을 메뉴를 한 단계씩 보여주세요.**

탭 이름부터 **‘다음부터 한 줄로 쓰기’**로 바꾸면 제가 얻는 게 보여요. 첫 문장은:

> **매번 매뉴얼을 붙이지 않으려면, ChatGPT에 이 일 전용 공간을 만들어요.**

긴 단계 목록 대신 휴대폰 화면 그림과 함께 한 단계씩 보여주세요. 단추도 **‘매뉴얼 복사하고 ChatGPT 열기’**로 묶으면 좋겠어요.

그 아래에는:

> 설정 메뉴를 못 찾겠다면, 오늘은 ‘바로 써 보기’로 먼저 써보세요.

단추: **‘오늘 한 번 써보기’**

**③ 첫 사용에 필요한 것만 먼저 보여주세요.**

결과 순서를 **오늘 할 일 입력 → 복사·열기 → 다음부터 한 줄로 쓰기**로 잡아주세요. 확인표와 긴 설명, 요금제는 그 아래에서 접어두면 좋겠어요.

펼치는 단추 문구는:

> **사용 전에 알아둘 점 보기**

떠 있는 아래 바도 **‘매뉴얼 + 할 일 복사’ / ‘ChatGPT 열기’**로 본문과 이름을 맞춰주세요. 복사 뒤에는 바 위에 짧게:

> **이제 ChatGPT로 가서 붙여넣으세요.**

이렇게 나오면 더 내려 읽지 않고 바로 앱으로 넘어갈 수 있어요.

**5. PDF나 프롬프트 한 장보다 나은지**

질문을 골라서 제가 맡는 SNS 일에 맞춰준다는 점은 PDF보다 좋아요. 그런데 **만드는 건 쉬웠고, 쓰는 건 아직 복잡해요.** 결과에서 복사할 걸 고르고 설치 메뉴까지 찾아야 한다면, 저는 짧은 프롬프트 한 장을 바로 복사하는 쪽이 더 편할 수도 있어요. 이 화면에서 오늘 게시물 하나를 실제로 만들고, 다음번에는 정말 한 줄만 보내도 된다면 확실히 더 낫다고 느낄 것 같아요. 지금 화면만 봐서는 ‘내 매뉴얼을 받았다’는 건 알겠는데, ‘이제 편하게 쓸 수 있다’는 데까지는 못 갔어요.
