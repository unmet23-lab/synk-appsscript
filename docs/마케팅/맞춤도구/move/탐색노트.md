# 내 PC 이사 목록 · 탐색노트 (2026-10-17)

yuhobuilds 「노트북 이사, AI한테 통째로 맡겨 봤어요」([기획](../../yuhobuilds_노트북이사_20261017/기획.md))의 끝에 붙이는 맞춤 프로그램. 실화는 10-15~17 노트북 교체(옛 노트북 → 새 노트북, Google Drive로 옮김, 10-17 09:43 끝)이고, 일반 사실은 아래 공식 문서로 확인했다. 노트북 값·계정 이름·키 값은 쓰지 않는다. 확인 날짜는 모두 2026-10-17.

## 1. 결정 요소

결과에 들어가는 것: 옮기는 방법(외장 SSD·USB / 클라우드 / 두 PC 직접 연결 / 아직 모름) · 이 컴퓨터로 하는 일(AI 앱 · 코딩 도구 · 영상·디자인 · 사진·영상 파일이 많음 · 회사 보안 프로그램 · 게임 · 문서·웹 위주) · 옛 컴퓨터 처리(바로 초기화·판매 / 2주 보관 / 계속 씀). 여기에 질문 없이 모든 결과에 들어가는 **OneDrive 백업 확인**과 **새 컴퓨터 시계 확인**.

결과의 네 칸: ① 절대 두고 가면 안 되는 것 ② 두고 와도 되는 것 ③ 옮긴 뒤 다시 할 것 ④ 끝났는지 확인하는 법 + 요청문.

## 4. 값을 정하는 것

- **이사 시간 = 옮기는 양 ÷ 가장 느린 구간.** 클라우드는 올리는 속도, SSD는 디스크·USB 속도, 직접 연결은 네트워크. 그래서 다시 받으면 되는 것을 빼는 게 가장 큰 절약이다(실화: 하루 반, 두고 온 107GB).
- **클라우드 무료 용량**: 구글 15GB(Gmail·포토와 나눔), Microsoft 5GB. 옮길 양이 크면 한 달 유료 용량이나 SSD.
- **잃으면 드는 값**: ssh 키는 서버마다 다시 등록, 공동인증서는 재발급, 세이브는 되살릴 수 없음(Steam 공식), 판매 뒤에는 꺼낼 곳이 없음.

## 5. 흔한 오해와 함정

- 「바탕화면은 OneDrive가 알아서 백업해 준다」 → 무료 5GB가 차면 새 파일을 올리지 못한다. 아이콘을 보지 않으면 모른다.
- 「이미 백업돼 있으니 빼도 된다」 → 백업 목록이 오래됐거나 일부만 있을 수 있다. 실화에서 첫 규칙이 그렇게 키·장부를 뺐다.
- 「사용자 폴더를 통째로 복사하면 로그인도 따라온다」 → DPAPI로 묶인 비밀번호·쿠키·자격 증명은 다른 PC에서 안 풀린다.
- 「Windows에 이사 기능이 있겠지」 → 「새 PC로 정보 전송」 문서는 「더 이상 사용할 수 없음」. Windows 백업은 OneDrive 공간이 필요하고 회사·학교 계정은 안 된다.
- 「Path를 옛 값으로 맞추면 똑같이 돈다」 → 새 PC에 깔린 프로그램 경로가 지워진다. setx는 1024자에서 자른다.
- 「USB에 다 들어간다」 → FAT32면 4GB 넘는 파일 하나가 안 들어간다.
- 「게임 세이브는 런처가 알아서」 → 많은 게임이 Steam Cloud를 쓰지 않는다.

## 6. 필요 없는 경우

- 설치한 프로그램·캐시·Temp·node_modules·가상환경·내려받은 모델 → 다시 받거나 다시 만든다.
- 클라우드에만 있는 파일(온라인 전용) → 로그인하면 보인다. 옮기려고 열면 오히려 내려받는다(실화: 클라우드에만 있던 5.1GB는 열지 않음).
- 금융인증서 → 클라우드 보관이라 옮길 필요 없다.
- AI 앱 대화 기록 → 대부분 계정에 있다(SYNK 판단, 공식 출처는 앱마다 달라 쓰지 않음).

## 7. 직접 확인하는 법

- OneDrive: 작업 표시줄 구름 아이콘의 빨간 동그라미·노란 삼각형 → 설정 → 동기화 및 백업 → 백업 관리.
- 시계: 설정 → 시간 및 언어 → 날짜 및 시간.
- 대조: 중요한 폴더의 속성(파일 수·크기)을 두 PC에서 비교. 개발 도구를 쓰면 `robocopy 옛 새 /e /l`로 빠진 파일 목록.
- 공동인증서: 은행 인증센터 → 인증서 관리에서 저장 위치가 하드디스크인지.
- 게임: 상점 페이지의 Steam Cloud 표시.

| 일본 note 글 「PC 이전 때 잊으면 골치 아픈 보이지 않는 것」(10월 초, 검색 결과 요약만) | 브라우저 비밀번호 내보내기를 첫 항목으로 든다 | 원문은 열지 못함 | 보이지 않는 로그인 정보가 가장 잘 빠진다는 같은 결론 → ③ 첫 묶음 |
| 국내 검색(구글, 10-17) | 「공동인증서 복사」 안내가 상위(은행·인증서 판매처·블로그) | 블로그 원문은 열지 않음 | 한국에서만 생기는 빠뜨림 → 모든 결과 ①에 공동인증서 |

표본이 작고 리뷰 원문을 열지 못했으므로 「사용자 반응」은 확인 못 한 것으로 둔다. 이 도구의 사용자 반응은 공개 뒤 결과 화면의 반응 단추(이 기기 Atlas)와 댓글로 본다.

## 9. 쓰지 않은 것과 이유

- 구글 드라이브 하루 750GB 올리기 한도: 공식 문서가 Google Workspace 안내라 개인 계정에 그대로 쓰지 않았다.
- OneDrive에서 지운 파일이 다른 기기에서도 지워지는지: 공식 문서 원문을 찾지 못해(문서 주소 404) 「계속 씀」 팁은 SYNK 판단으로만 썼다.
- 카카오톡 PC 대화 기록·브라우저 비밀번호 내보내기 메뉴 이름: 공식 원문을 열지 않아 쓰지 않았다.
- PCmover 등 유료 이사 프로그램 값·평점: 원문을 열지 못했다.
- AI 앱 이름: 사이트 표기 원칙에 따라 쓰지 않는다(요청문 안의 「AI」 일반 표현만).
