# 카타나 요청문 만들기 · 추천기준

## 1. 사용자 결정

- 2026-10-13 유호님: 「카타나 써봤습니다」에 붙일 「직접 검수해서 전달할 프롬프트나 개인화 프로그램」을 준비해서 영상과 같이 올린다.
- 2026-10-13 유호님: 검수용 새 생성은 하지 않는다(「돌리지 말고 요청문만」). → 요청문은 실제로 결과가 나온 10-13 두 요청(제품 광고·아우라 에딧)의 뼈대를 쓰고, 공식 지침과 그 결과의 아쉬운 점으로 다듬는다.
- 2026-10-13 유호님: 영상에 「카타나에 이렇게 말하면 이렇게 만들어 줘요」로 요청 글과 몽글 아우라 에딧을 넣는다.

## 2. 원칙

1. **상한을 반드시 적는다.** 카타나는 비용을 묻지 않고, 에이전트 작업에는 기본 상한이 없다. 요청문마다 「크레딧은 전부 합쳐 N 안에서」를 넣는다.
2. **화질을 반드시 적는다.** 기본이 720p라 적지 않으면 480p의 2.3배가 든다. 처음은 480p 미리 보기를 권한다.
3. **지킬 것을 주인공에 맞춰 잠근다.** 제품은 로고·글자·색, 캐릭터는 모양(새 팔다리·입 없음), 사람은 얼굴·옷.
4. **음악은 기본으로 막는다.** 카타나는 틱톡·스톡 음원을 고를 수 있다. 「남의 노래 없이 효과음만, 무음판도」를 기본으로 켠다.
5. **보고를 받는다.** 쓴 크레딧, 걸린 시간, 고른 레퍼런스 주소, 새로 생성한 장면과 사진을 움직이거나 합성한 장면의 초.
6. **지나친 규칙은 넣지 않는다.** 카타나의 계획(레퍼런스 고르기·장면 설계)을 대신하는 촬영 지시는 넣지 않는다. 고른 영상 종류의 느낌 한 줄만.
7. AI를 부르지 않는다. 비용 어림은 공개 가격표로 이 화면에서 계산하고, 실제 비용은 카타나의 견적을 따른다고 적는다.

## 3. 질문(6개)

| id | 묻는 것 | 선택지 |
|---|---|---|
| hero | 주인공 | 제품 · 음식·음료 · 캐릭터·인형 · 가게·공간 · 사람 |
| style | 영상 종류 | 제품 광고 · 아우라 에딧 · 가진 클립 편집 · 내가 고른 영상처럼(링크) |
| input | 재료 | 사진 1장 · 사진 여러 장 · 영상 클립 |
| where | 올릴 곳 | 릴스·쇼츠·틱톡 · 상세 페이지 · 가로 영상 |
| quality | 화질 | 480p 미리 보기 · 720p · 1080p 완성본 |
| keep | 꼭 지킬 것(여러 개) | 로고·글자 · 색 · 모양 · 얼굴·옷 · 남의 노래 없이 · 화면 글자 없이 · 회전·흔들림 없이 |

## 4. 비용 어림

- 낮은 어림 = 짧은 길이 × 1.3 × 화질 단가, 높은 어림 = 긴 길이 × 2.5 × 화질 단가 + 장소 그림 2. 화질 단가(초당) 480p 3, 720p 7, 1080p 12.
- 가진 클립 편집은 새로 생성하는 장면이 적어 배수를 0.3~1.0으로 본다.
- 상한 = 높은 어림을 10 단위로 올림. 10-13 두 결과(42.12·84.24, 480p)가 쇼츠 480p 어림(약 39~115, 상한 120) 안에 든다.

| 올릴 곳 | 비율 | 길이 |
|---|---|---|
| 릴스·쇼츠·틱톡 | 9:16 | 10~15초 |
| 상세 페이지 | 1:1 | 6~10초 |
| 가로 영상 | 16:9 | 10~20초 |

## 5. 결정표

- 사진 1장 + 새 장면이 많이 필요한 종류(아우라·제품 광고) → 「사진이 한 장이면 각도가 바뀌는 장면은 새로 그려져요. 2~5장이면 더 닮아요」 팁.
- 클립 편집인데 재료가 사진뿐이면 → 경고: 클립 편집은 영상이 있어야 한다. 요청문은 「사진으로 새 장면을 만들어」로 바뀐다.
- 사람 → 얼굴·옷 잠금을 강제로 켜고, 본인 동의 사진만 쓰라는 경고.
- 1080p → 「처음부터 1080p보다 480p로 방향을 보고, 고른 결과는 업스케일」 팁과 4배 비용 경고.
- 음악 잠금을 끈 경우 → 저작권·쇼츠 1분 규정 경고.
- 회전·흔들림 잠금 → 「번쩍임은 약하게, 화면 회전·스핀·잦은 흔들림 없이」 줄.

## 6. 결과 순서

1. 머리: 내 영상 한 줄 + 어림 크레딧·시간
2. 이 순서대로(연결 → 요금 확인 → 사진 붙이고 /katana → 요청문 → 기다리기 → 확인)
3. 가져가기: 요청문(복사)
4. 어림 비용 카드(화질·길이·배수와 근거)
5. 나에게 필요한 팁
6. 결과 받은 뒤 확인할 것
7. 영상 속 실제 요청 두 개(제품 광고·아우라 에딧)와 결과 숫자
8. 반응 · 답 바꾸기 · 출처

## 7. 시험 약속

- 모든 요청문에 상한(「크레딧은 전부 합쳐」), 화질, 보고 줄이 있다.
- 480p를 고르면 요청문에 480p, 1080p를 고르면 1080p와 4배 경고.
- 「남의 노래 없이」는 질문에서 권하는 표시가 있고(공통 틀에 미리 체크 기능이 없음), 고르면 요청문에 잠금, 안 고르면 경고와 다른 팁(sound-open)이 뜬다.
- 캐릭터는 「팔다리나 입을 새로 붙이지 마」, 제품은 「로고·글자를 지어내지 마」, 사람은 얼굴·옷 잠금과 동의 경고.
- 쇼츠 480p 어림이 10-13 실제 결과(42.12·84.24)를 포함한다.
- 클립 편집 + 사진뿐이면 경고.
- 결과가 고른 팁은 모두 팁 은행에 있다. 제작 절차 검사를 통과한다.
