# 카타나 요청문 만들기 · 탐색노트 (2026-10-13)

synkbrief 뉴스 「카타나 써 봤습니다」에 붙이는 맞춤 도구. 유호님 10-13 「카타나 써봤습니다 >> 니가 직접 검수해서 전달할 프롬프트나 개인화 프로그램 지금 준비해줘 이거 준비해서 올리자」, 이어서 검수용 시험 생성은 「돌리지 말고 요청문만」. 그래서 새 생성 없이 **공식 지침 + 10-13 실제 두 번의 결과**로 요청문을 검수했다.

## 1. 결정 요소

요청문에 들어가는 것: 주인공(무엇을 지킬지) · 영상 종류(제품 광고·아우라 에딧·클립 편집·레퍼런스 따라 하기) · 재료(사진 1장·여러 장·영상) · 올릴 곳(비율·길이) · 화질(480p·720p·1080p)과 크레딧 상한 · 꼭 지킬 것(로고·색·모양·얼굴·음악·글자·흔들림) · 끝난 뒤 받을 보고.

## 2. 공식 자료 (원문으로 확인)

## 3. 실제로 써 본 결과 (SYNK, 10-13, 몽글 사진 5장, 둘 다 480p·상한 150)

| | 제품 광고(모션) | 아우라 에딧 |
|---|---|---|
| 보낸 요청의 뼈대 | 제품 광고 같은 모션(스튜디오 조명·빛 지나가기·질감 가까이·마지막 정면), 9:16, 8~12초, 480p, 상한 150, 몽글 모양 그대로(팔다리·입 없음), 회전·흔들림 없이, 남의 노래 없이 CC0 효과음, 글자 없음 | 아우라 파밍(무심하게 멋있게·바람·역광·비트에 맞춘 컷·플래시), 9:16, 10~15초, 480p, 상한 150, 모양 그대로·표정은 사진 다섯 가지 안에서, 회전·흔들림 없이, 남의 노래 없이, 글자는 마지막 MONGLE 한 단어 |
| 결과 | 10.5초 | 13.7초 |
| 크레딧 | 42.12(영상 한 번 5장면 + 장소 그림 한 장) | 84.24(장소 그림 0.12 × 2, 영상 12·6·6·4초, 생성 28초 중 12초 사용) |
| 시간 | 38분(레퍼런스 찾기·분석 25분, 생성 4분, 합성 4분) | 기록 없음 |
| 레퍼런스 | 카타나가 찾은 제품 광고 쇼츠 | 카타나가 찾은 dIvAk_VlM3s(Gojo Eyes AMV) |
| 잘된 것 | 털·바느질 접사는 사진처럼 | 차가운 풍경 속 코랄 한 점, 남색 반전, 윙크 |
| 아쉬운 것 | **표정이 바뀌는 2.7초는 생성이 아니라 사진 합성** | 밤 장면은 코랄이 어두움, 첫 컷은 몽글이 점처럼 작음, **6.9초 강한 번쩍임**, 윙크 컷 전진 줌 |

두 번 다 상한(150) 안에서 끝났고, 요청한 잠금(모양·음악·글자·회전 없음)을 지켰다. 그래서 도구의 요청문은 이 두 요청의 뼈대를 그대로 쓰고, 아쉬운 점을 막는 줄(합성 구간 알리기, 번쩍임 약하게, 주인공을 첫 컷부터 크게)을 더했다.

## 4. 값을 정하는 것

- 크레딧 ≈ 화면 초 × (생성 배수 1.3~2.5) × 화질 단가 + 장소 그림 몇 장. 10-13 두 결과(42.12 = 10.5초 × 1.3배 × 3, 84.24 ≈ 13.7초 × 2배 × 3)가 이 범위 안이다.
- 화질 단가는 480p를 1로 보면 720p 2.3배, 1080p 4배. 카타나 기본이 720p라 **480p라고 적지 않으면 두 배 넘게 든다**.
- 같은 결과를 크게 만들 때는 다시 생성(다른 영상이 나오고 4배)보다 업스케일이 훨씬 싸다.

## 5. 흔한 오해·함정

- 「무제한 요금제니까 공짜」 → 클로드 연결(MCP)로 만드는 건 요금제와 상관없이 크레딧이 빠진다(도움말).
- 「카타나가 비용을 물어보겠지」 → 묻지 않는다(지침). 에이전트 작업에 기본 상한도 없다(도움말). 상한은 요청문에 직접 적어야 한다.
- 「한 줄이면 된다」 → 한 줄도 돌아가지만, 화질을 안 적으면 720p, 음악을 안 막으면 틱톡 음원이 들어갈 수 있다(지침).
- 「표정이 바뀌는 장면 = 새로 생성」 → 사진을 합성해 바꾼 구간이 있었다(실제 결과). 보고를 받아야 안다.
- 「체험은 무료」 → 카드 등록, 해지하지 않으면 자동 결제.
- 「레퍼런스 영상을 그대로 따라 한다」 → 리듬·전환만 빌린 새 장면이다.

## 6. 필요 없는 경우

- 이미 영상 클립이 있고 자르기·자막만 필요하면 새 생성 없이 편집만 하게 하면 된다(지침의 「붙인 재료 편집」).
- 시안만 볼 때는 1080p가 필요 없다. 480p로 방향을 본다.
- 레퍼런스가 없어도 된다. 카타나가 찾는다(대신 시간이 든다).

## 7. 직접 확인하는 법

- 연결: 클로드 설정 → 커넥터 목록에 Higgsfield가 있는지.
- 비용: 결과를 받은 뒤 힉스필드 거래 내역과 카타나 보고를 맞춰 본다.
- 합성 구간·음악 출처: 요청문 끝의 「보고」 줄로 받는다.

## 8. 쓰지 않은 것과 이유

- 체험 크레딧 수: 공식 도움말에 숫자가 없고, 커뮤니티 글로 알려진 「100」도 원문에서 확인되지 않아 쓰지 않았다.
- 가격은 10-08 관측값이라 「약」으로 쓰고, 실제 비용은 카타나가 계획 때 받는 견적을 따른다고 적었다.
- 카타나 공개일: 공식 발표를 찾지 못해 쓰지 않았다.

## 다시 확인할 때

분기마다, 또는 힉스필드가 요금·커넥터 안내를 바꾸면: 도움말 연결 단계·유료 조건 → 카타나 지침의 진행 방식·음악 규칙 → 가격표 순서로 다시 본다.
