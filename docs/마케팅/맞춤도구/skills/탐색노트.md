# 내 GPTs·젬 옮기기 점검 · 탐색노트 (2026-10-17)

synkbrief 뉴스 「GPTs·젬, 올해 둘 다 사라집니다」([기획](../../synkbrief_GPTs젬_스킬전환_20261017/기획.md))에 붙이는 맞춤 도구. 유호님 10-17 「Synk brief에 올릴 컨텐츠 하나 지금 같이 준비하자」 → 「GPTs·젬 둘 다 사라짐」 선택 → 기획·대사 「이대로 진행」.

사람들이 시간을 잘못 쓰는 곳: ① 젬까지 서둘러 손으로 옮기거나(기다리면 자동), ② GPTs는 알아서 옮겨질 줄 알고 두거나(직접 눌러야 함), ③ 남이 만든 GPT를 내가 옮기려고 찾거나(만든 사람만 됨), ④ 고친 내용을 게시하지 않은 채 옮기거나(게시본만 옮겨짐), ⑤ 외부 연결 액션이 그대로 따라올 줄 안다(안 따라옴).

## 1. 결정 요소

결과에 들어가는 것: 어디에 있나(ChatGPT GPTs·제미나이 젬) · 직접 만들었나(만든 사람만 옮길 수 있음) · 어느 계정에서 만들었나(개인·회사·학교마다 날짜가 다름) · 안에 든 것(지식 파일·액션·공유·게시 안 한 수정 / 젬의 동영상·음악·Canvas·Deep Research) · 옮긴 뒤 비교할 질문.

## 3. SYNK가 직접 본 것

- 제미나이 스킬을 골라 놓고도 다섯 번 중 한 번은 스킬 규칙이 안 붙은 답이 나왔다(10-07, [매뉴얼 추천기준 §12-1](../manual/추천기준.md)). 옮긴 뒤 비교를 권하는 근거로 쓴다.
- 유호님 ChatGPT 계정의 「내 GPT」는 비어 있었고, 시험용 GPT 「회의 메모 정리」를 나만 보기로 게시하자 「플러그인으로 마이그레이션」 단추가 생겼다(10-17). 단추를 누른 뒤 화면은 탭이 닫혀 그날은 못 봤다.
- 10-18 unmet23(Pro, 개인) 계정에 같은 시험용 GPT를 다시 만들어 끝까지 눌러 봤다(컴퓨터 웹, 앱 안 브라우저). 「플러그인으로 마이그레이션」을 누르면 「회의 메모 정리 마이그레이션」 확인 창이 뜬다. 안내는 「이 GPT의 지침과 지식 파일을 사용해 플러그인으로 전환하세요. 플러그인은 처음에는 비공개로 설정됩니다. 전환이 완료되면 원본 GPT를 더 이상 편집할 수 없습니다」, 점검 세 줄은 「지침 및 파일 · 앱 및 액션: 발견된 문제 없음」, 「접근 및 공유: 비공개 플러그인」이다. 아래 단추는 「플러그인으로 마이그레이션」·「나중에 마이그레이션」. 누르면 「마이그레이션 중」이 몇 초 돈 뒤 플러그인 페이지(`chatgpt.com/plugins/plugin_…`)로 넘어가 「플러그인 마이그레이션이 완료되었습니다 · 마이그레이션된 플러그인을 검토하고 테스트하세요」와 「플러그인 편집」·「채팅에서 사용해 보기」가 보인다. 플러그인 안에는 GPT 이름 그대로의 스킬 하나가 들어 있다(기능 skills, 버전 0.1.1).
- 옮긴 뒤 「내 GPT」의 그 GPT 줄은 「플러그인 열기 ↗」 단추와 보기(눈) 아이콘으로 바뀌고 편집(연필)이 사라진다. 휴지통 아이콘은 그대로 보인다(FAQ의 「지울 수 없다」와 다르게 보이지만 눌러 보지 않았다).
- 새 채팅 입력창에 「@회의」를 치면 같은 이름이 「플러그인」 칸과 「맞춤형 GPT」 칸에 둘 다 뜬다. 그 아래에는 Google Drive 파일 같은 개인 항목도 같이 떠서, 캡처는 두 칸만 잘랐다. 캡처 원본 `.tmp/skills-tool-felt-20261017/migrate_flow/`, 도구 그림 `assets/skills-shot-confirm.webp`·`skills-shot-at.webp`.
- 같은 날 크롬(같은 unmet23)에서 액션 하나(인증 없음, `GET /ping` 시험 스키마)를 넣은 「시험용 액션 GPT」를 나만 보기로 게시하고 확인 창만 열었다(「나중에 마이그레이션」으로 닫아 옮기지 않음). 「앱 및 액션」 줄이 주황 「지원되지 않는 액션 ⓘ」로 바뀌고 아래에 「사용자 지정 액션을 사용하는 기능은 플러그인에서 작동하지 않습니다. 해당 액션 없이도 마이그레이션할 수 있습니다.」가 붙는다. 「플러그인으로 마이그레이션」 단추는 그대로 눌린다. 도구 그림 `skills-shot-confirm-action.webp`(제목은 잘라 냄).

## 4. 흔한 오해

| 오해 | 실제 | 팁으로 쓴 곳 |
|---|---|---|
| 둘 다 알아서 옮겨 준다 | 젬은 자동, GPTs는 직접 눌러야 한다 | `gem-auto`, `migrate-how` |
| 종료되면 대화도 사라진다 | GPT 대화 기록은 남는다 | `date-gpt`, `migrate-skip` |
| 남이 만든 GPT도 내가 옮겨 둬야 한다 | 만든 사람만 옮길 수 있고, 쓰는 사람은 할 일이 없다 | `use-others` |
| 고친 내용도 같이 옮겨진다 | 최신 게시본만 옮겨진다 | `migrate-publish` |
| 외부 연결도 그대로 된다 | 맞춤 액션은 안 따라온다 | `carry-action` |
| 옮기면 똑같이 답한다 | 다르게 답할 수 있다. 비교해야 한다 | `test-compare` |
| 11월 17일에 젬이 한 번에 다 바뀐다 | 「이전되기 시작」이다. 그날 바로 안 보여도 기다린다 | `date-gem` |

## 5. 필요 없는 경우

- 젬만 쓰는 개인 계정: 할 일 없음. 미리 써 보고 싶을 때만 손으로 다시 만든다.
- 남이 만든 GPT만 쓴다: 옮길 수 없다. 대체 안내만 본다.
- 한 번 쓰고 만 GPT: 옮기지 않아도 대화는 남는다.

## 6. 쓰지 않은 것과 이유

- Android Authority의 「옮겨진 젬은 스킬 초안이 된다」, 「11-17에 Gems가 설정 패널로 간다」: 공식 도움말에 없다.
- 비공식 블로그의 GPT 일정(9-17·9-25 등)과 모델 이름 차이: FAQ와 다르다.
- 남이 공유한 젬이 어떻게 옮겨지는지: 공식 글에 없다. 결과에는 「아직 안 적혀 있어요」로 둔다.
- 교육(Edu) 워크스페이스의 GPT 날짜: 이 FAQ에는 Enterprise만 있다. 「관리자 안내를 따르세요」로 둔다.
