# 내 이름, 한글로 · 로마자판(synk.im/nombre) · 탐색노트

2026-10-12 · LAB 「내 이름 한국어로」 편에 붙이는 맞춤 도구다. 스페인어·포르투갈어·영어 이름을 외래어 표기법대로 한글로 옮긴다. 몽골어판 [synk.im/name](https://synk.im/name/)(키릴 문자)과 같은 펠트 명찰 재료를 쓴다. 규칙 계산만 하고(AI·네트워크·기록 없음), 화면 언어 고른 것만 그 기기에 남긴다.

## 1. 벤치마킹 요약(2026-10-12, 원자료는 세션 조사 파일 → 아래 표에 옮김)

| 무엇 | 확인한 것 | 이 도구에 반영 |
|---|---|---|
| 큰 학습 브랜드 | KoreanClass101 「Your name in Korean」은 결과를 가입 뒤에만 보여 준다. TTMIK 「My Korean Name Is」는 소리 표기가 아니라 새 한국 이름을 만든다(2025 한글날 캠페인 1만 7천 명 참여, 회사 발표) | 가입·광고 없이 바로. 「내 이름」을 옮기고 새 이름을 만들지 않는다 |
| 규칙형 공개 도구 | 한글라이즈(hangulize.org)만 외래어 표기법을 밝힌다. 영어 미지원, 3.6MB WASM이라 느린 망에서 결과가 안 떴다 | 가벼운 규칙 파일(수십 KB), 영어는 용례 목록 |
| 번역기 | 구글 번역이 João를 「남자」로, Guilherme를 「윌리엄」으로, 포르투갈어 Jorge를 「성 조지」로 냈다(직접 조회) | 「번역이 아니라 소리 옮기기」를 분명히, 언어를 먼저 고르게 |
| 사용자 불만 | 도구·사람마다 답이 다르다, 철자 말고 내 발음대로, 겹글자·ㅆ 질문, 가짜 알파벳 표(「Bro forgot Q,W,X,Y,Z」·「Eso es solo el abecedario」, 10-11~12 댓글) | 두 표기가 갈리면 후보를 보여 주고 본인이 고르게. 글자마다 「왜」 |
| 잘 되는 영상 | 원어민이 댓글 속 이름을 읽어 주는 연재(lavidadesur TikTok PARTE 13~18, 댓글 비율 3~6%), 뜻 맞춘 이름 선물(Jazmín 4.1%). 알파벳 표는 도달이 크지만(12.9만·4.4만 회) 댓글 비율 0.4~0.6%이고 정확하지 않다 | 영상은 「댓글에 이름 → 다음 편에서 읽어 주기」 연재로 |

## 2. 공식 자료(국립국어원 어문 규범, 2026-10-12 원문 대조)

- [외래어 표기법](https://korean.go.kr/kornorms/regltn/regltnView.do?regltn_code=0003)(문화체육관광부 고시 제2017-14호). 제1장 제3항(받침은 ㄱㄴㄹㅁㅂㅅㅇ만), 제4항(파열음에 된소리를 쓰지 않음), 제5항(굳어진 외래어는 관용 존중), 제4장 제1절(인명·지명).
- 에스파냐어: **표 2** 자모와 한글 대조표 + **제3장 제4절** 제1~6항(gu·qu, 겹자음, c·g, x, l, nc·ng). 공식 보기 60개를 규칙으로 모두 재현했다(rules.test.js).
- 포르투갈어: **표 17** + **제3장 제19절** 제1~15항. 「브라질 포르투갈어에서」 조항(제3항, 제5항 2, 제14항, 제15항 2)은 브라질 인명·지명에만 쓴다. 보기 171개를 재현했다(관용 Lisboa 리스보아·Rodrigues 호드리게스는 예외 사전).
- 영어: **제3장 제1절**은 철자가 아니라 발음 기호(표 1)를 입력으로 한다. 그래서 철자 규칙을 돌리지 않고 이름 용례 목록만 쓴다.
- 국립국어원 온라인가나다 답변(2024-11-20, 2025-03-19, 2025-07-17, 2026-01-21): 인명은 국적·언어·본인 발음을 먼저 확인하라고 안내한다. 도구가 언어를 먼저 묻는 근거다.

## 4. 판단(규칙이 갈리는 곳)

| 경우 | 기본 표기 | 후보 | 근거 |
|---|---|---|---|
| 멕시코 이름의 첫 x(Ximena, Xavier) | 규칙 시메나 | 히메나(멕시코 발음) | 표 2·제4항은 ㅅ. 용례 México 멕시코·Oaxaca 오악사카도 철자 규칙. Ximena 용례 없음 |
| 나와틀어 기원 tz(Itzel) | 규칙 이트셀 | 이첼(소리대로) | 표 2에 tz 없음. 용례 없음 |
| -ella·-ello의 ll(Isabella) | 규칙 이사베야 | 이사벨라(이탈리아식으로 읽을 때) | 표 2 ll → 이*. 용례 없음 |
| 포르투갈어 어두 무강세 e(Elisa) | 규칙 일리자 | 엘리자 | 제14항. 용례가 엇갈림(Edmundo 이드문두 / Eduardo 에두아르두) |
| 용례가 규칙과 다른 이름 | 용례(주앙, 에두아르두, 몬세라트, 호드리게스(포), 리스보아, 에르네스투(브)) | 규칙 표기 | 제1장 제5항 관용 존중 |
| 영어 이름 | 용례 표기(세라, 매슈, 대니얼…) | 흔히 쓰는 표기(사라, 매튜, 다니엘) | 용례는 사람마다 심의한 결과 |

- 소사(de·del·da·dos)는 뒤 이름에 붙여 쓴다(용례: 펠리페 데헤수스, 다시우바). 스페인어 접속사 y는 「이」(라몬 이 카할).
- 같은 이름을 다른 언어로 읽은 표기도 한 줄로 보여 준다(José 호세 / 조제, Jorge 호르헤 / 조르지 / 조르즈).

## 6. 하지 않는 것

- 새 「한국식 이름」 만들기(TTMIK형). 원하면 별도 칸으로 나중에.
- 영어 이름 철자 규칙 추정. 목록에 없으면 비우고 안내한다(언어를 바꿔 보라고).
- 이름·결과를 서버로 보내기. 명찰 그림도 브라우저 안에서만 만든다.
