# LAB 행사 — 경험·참가·권리의 현재 선택

> 2026-09-10 · [마케팅 정본](../마케팅_정본.md)의 행사 상세. 08-08 사용자 선택과 고유한 참가·권리 설계를 보존한다. 대외 이름·상·일정·혜택은 해당 행사 준비 때 확정하며 이번 개편이 개최 완료를 뜻하지 않는다.

## 행사에서 지키는 선택

학생에게 새로운 경험·추억·좋은 기억을 주는 것 자체를 높은 가치로 본다. 홍보·안내·감상 모두에 한국어 산출이나 학습자 수집을 요구하지 않는다. 교육·공개 경계는 [철학 적용 기준](../철학_적용기준.md), 상품·체험 일정은 현재 담당 정본을 따른다. 옛 1인 제작량을 전사 확장의 상한으로 쓰지 않는다.

|---|---|

선별은 재미·경험·등록 뒤 학습 연결·한국어 산출·실현 조건을 함께 본다. 경험 가치가 강하면 한국어 산출이 없는 행사도 후보가 된다. 실제 안전·권한·지출·운영이 불가능하면 그 문제를 먼저 해결한다. ‘개원 전 영화제 하나에 서사를 몰기’는 전제 소멸로 폐기됐다.

## 4. ① 영화제 — 첫 회차 상세 (개원 후 · 재학생 대상 · 시즌 2 목표)

> 유호님 판정으로 개원 전 외부 공모는 기각 — 첫 회차는 **재학생(+가족 관람)** 행사다. 외부 공모 확장은 회차 실적을 보고 별도 재론(지금 설계하지 않는다).

### 4-1. 골격

| 항목 | 설계 | 근거 |
|---|---|---|
| 대상 | 재학생 전원(개인 또는 팀 · 신청제) | 「모든 학생이 주인공」 — 선발제 아님(장부 ③ 판정과 같은 축) |
| 형식 | 스마트폰 세로 숏폼 30~60초 · 한국어 대사 필수 · **원창작 대사만 공식 재게시·광고 후보**(§4-3) | 수업의 말하기 산출과 정면 접속 — 자기 상황을 한국어로 |
| 접수 | 수업 내 안내 + 공식 계정 DM(참가 대장에 참가 번호 기입 · 폼 신설 0) | 창구 단일화(08-04) 준수 · 재학생이라 접수 부담 극소 |
| 출품 | 본인(팀) IG 게시+해시태그 또는 **DM 제출만**(비공개 계정·SNS 없는 학생 경로 — 공개를 강제하지 않는다) | 미성년 공개 접점 최소화(심문 채택분) |
| 상영·시상 | **⑥ 가족 발표회와 결합 검토**(같은 시즌 말 무대에서 상영) — 행사 2개를 1개 운영으로 | 1인 캐파 · 가족 관람=경험★ 증폭 |
| 심사 | 한국어 정확도(급수 기준 간이 루브릭·버전 기입) · 창의 · 대중 반응(**공식 계정 소개 게시물 반응만** · 마감 시각 고정 · 동률 규칙) | 개인 게시물 반응은 팔로워 규모에 좌우 — 제외 |
| 상 | 물성 소품 + 공식 계정 피처링 | 🚫포인트·현금(정본) · 사전등록 순번은 추천 전용 자원이라 안 씀 |
| 기록 | 출품작 = 학생 개인에게도 **남는 작품**(경험★) — ⑨ 포트폴리오 북의 재료로 자동 연결 | 경험 축 상시 지시 · ⑨와 접속 |

### 4-2. 시드·게이트 (외부 공모 아닌 재학생 행사라 축소)

- 본보기 출품: 리드 크루 1~2편(참가 대장에 `시드` 표기 · 심사 분모 제외 — 심문 채택분 유지).
- 참가 저조 시: 행사 규모를 참가 수에 맞춰 축소 진행(중단 아님 — 신청한 학생의 무대는 지킨다).

### 4-3. 권리 — 참가 규약 요건 (법무 검토 목록 · ②⑥에도 준용)

- **층 구분 = 크루 채널 정본 §4 계승**: 학생 본인 게시 = 본인(가정) 책임 · **공식 재게시·광고 사용만 학원의 동의 확보 대상**(보호자 서면 · 사용 범위 명시 · 몽골어 병기 선행).
- **사용처 대장**: 어느 산출물이 어느 게시물·광고에 쓰였나 기록 → **철회 절차**(요청→대장 조회→중단→통보).
- **권리 게이트**: 재게시·광고 후보는 원창작 대사 + 허용 음원만.
- ② 메이크오버 준용: 촬영 결과물은 **학생 선물이 기본**(경험★) — SNS·광고 사용은 위 동의 절차를 탈 때만.

## 5. 데이터 — 2층 분리 (심문 확정 구조 · 변경 없음)

- **층1**: 이벤트 데이터 = 마케팅 운영 기록만(참가 대장·심사 기록·권리 대장). 학습자 모델·성향·TOPIK·엔진에 흐르지 않는다.
- **층2**: 등록 학생의 데이터만 기존 교육 계약 통로로 연결한다. 기록이 저장되었다는 사실만으로 학습 적용을 선언하지 않으며, 허용된 후속 수업·피드백이 실제로 그 기록을 사용하는지 확인한다. 비등록 참가자 데이터를 학습 엔진에 넣지 않는다. 심사 점수는 반 편성·레벨테스트를 **대체하지 않는다.**
- 재학생 행사가 되면서 유혹이 커진다 — **출품 발화를 엔진에 넣고 싶어도 층2 통로(수업·앱의 기존 생산자)가 서기 전엔 안 넣는다.** 행사 산출물은 마케팅·경험 층이다.

## 보상과 공개

포인트·현금 상과 출석/숙제의 보상 경제를 섞지 않는다. 물성 소품·피처링은 행사 설계 선택이며 구체 상·문안은 가안이다. 기존 접수 통로를 쓰고 단순 행사 때문에 새 폼·크루카드 문항·학습 데이터 생산자를 추가하지 않는다. 공개하지 않는 참가 경로가 있어야 하며, 미성년자가 보호 설정을 풀거나 DM을 공개해야 참여할 수 있게 만들지 않는다.

실학생 홍보 공개는 비식별·서면 동의/철회·학습과 홍보의 2층 분리 위 사용자 판정이라는 [현행 기준](../철학_적용기준.md#4-대외-사용과-근거)을 함께 적용한다. 옛 행사의 동의 설명만으로 그 기준을 대체하지 않는다. 참가자 개인 게시물 반응을 회사 공식 계정의 광고 오디언스로 간주하지 않는다. 행사 경험의 가치는 모집 전환이나 수집량 없이도 남는다.
