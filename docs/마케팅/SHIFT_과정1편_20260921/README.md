## 음성

사용자가 결제한 Typecast API Lite의 활성 구독과 200,000 기본 크레딧 중 사용 0 상태를 확인한 뒤 생성했다. 이번 작업에서 실제 요청한 음성 합성은 샘플 2건과 본문 1건, 요청 본문 합계 372자다. 서비스 대시보드의 최종 청구 사용량과 같은 수치로 단정하지 않는다.

선택한 시안은 **하나 / ssfm-v30 / happy / 감정 강도 1.5 / 기본 속도와 피치**다. 사용자 요청인 밝고 상큼한 감정 표현에 맞춘 선택이며, 모든 보이스 가운데 최상이라는 평가가 아니다. [하나 샘플](audio/sample-hana.wav)과 [정아 샘플](audio/sample-jeongah.wav)은 같은 문장으로 생성했다. 최종 목소리의 취향과 발음은 사용자 청음으로 확인한다. 제작 도구의 오디오 입력이 지원되지 않아 에이전트가 직접 청취했다고 기록하지 않는다.

Typecast가 반환한 단어별 시간 정보를 해당 음원에 그대로 맞췄다. 원본 [narration-hana.wav](audio/narration-hana.wav)는 보존하고, 최대 음량을 다듬은 [narration-master.wav](audio/narration-master.wav)를 영상에 사용한다. 마스터 실측 -16.8 LUFS, true peak -1.5 dBFS. BGM은 넣지 않았다.

기존 API 키는 사용자가 로컬 연결 화면에 입력했다. 키를 소스·파일·로그에 저장하지 않았고 합성 후 연결 프로세스를 종료했다. 나중에 새 음성을 생성하려면 기존 키를 다시 연결한다.

## 화면과 근거

Behance 커버를 업로드하기 전 미리보기에서 소품이 잘렸고, 저장을 취소한 뒤 배치를 고친 9월 19일 사례다. 당시 실패 미리보기 캡처는 없으므로 실제 업로드 UI를 합성하지 않았다. 전후 PNG는 원본 비교라고 표시하고, 40px 아래 이동 장면은 배치 변화 재구성이라고 표시했다. 공개 프로필 확인은 9월 19일 기록에 근거한 과거 서술이다.

원천·해시는 [제작근거.json](제작근거.json), 실제 컷 길이는 [장면타이밍.json](장면타이밍.json)에 있다. 승인 자산과 공유 Root.tsx는 덮어쓰지 않았다. 새 보이스 시안은 기존 출연 영상이나 전사 캐릭터 음성의 변경을 뜻하지 않는다.

## 다시 렌더

저장소 루트에서 실행한다. 이미 생성한 음원을 사용하며 새 API 호출은 없다.

```powershell
node 'docs/마케팅/SHIFT_과정1편_20260921/align-narration.cjs'
node 'docs/마케팅/SHIFT_과정1편_20260921/render.cjs'
node 'docs/마케팅/SHIFT_과정1편_20260921/finish-preview.cjs'
```

`render.cjs --stills`는 대표 프레임·표지만 다시 만든다. Remotion 소스는 `영상/src/shiftProcess20260921/`에 있다. 재생 화면은 `_src_preview.html`에 `tools/lib/브랜드폰트.js`로 폰트를 심어 `preview.html`로 만든다.

최종 공개 게시와 플랫폼 업로드 화면에서의 표지·설명·AI 콘텐츠 표시 확인은 아직 하지 않았다. 네이버 클립 소개 후속 수정도 업로드 시점에 남아 있다.
