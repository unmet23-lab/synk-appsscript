- **예약 절차(Aside u0):** `C:/Users/q1212/aside/tistory-twoblogs-20261119/`에서 `node mcpd.cjs <그 폴더>`로 상주 실행기를 띄운다. 실행기는 40분 동안 할 일이 없으면 스스로 끝나므로, `mcpd.ready`가 없으면 다시 띄운다. `gen-res.cjs` · `run-res.cjs` · `make-review.cjs`는 저장소 뿌리에서 실행하고, 둘째 주부터는 끝에 첫날 MMDD를 주어 `일주일/<블로그>-<MMDD>.json`을 읽게 한다. `node <그 폴더>/gen-res.cjs <pulse|solio> <차례> dry [MMDD]`로 한 편을 먼저 시험해 「채운 상태 … 맞음 true」와 「발행 전 … ok true」를 본다. 그다음 `node <그 폴더>/run-res.cjs pulse:0,solio:0,… [MMDD]`로 여러 편을 차례로 건다. `go` 스크립트도 채운 값과 예약 칸이 원고와 같을 때만 누르고, 같은 제목이 글 목록에 있으면 멈춘다.
