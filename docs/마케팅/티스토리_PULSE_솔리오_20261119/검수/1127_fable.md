## 편끼리 겹치는 곳과 빠진 것

- solio1은 쓰는 사이에 낡았다. 11-23 20:43에 0.5.9가 공개됐다. 제목과 첫 문단, solio4 · solio7의 「0.5.8을 따릅니다」를 맞췄다.
- pulse3은 앞 글 「AI 영상은 왜 장면 이미지부터…」와 순서 설명이 겹치고 결제 단계가 빠져 있었다. 결제 단계를 한 문장 더했다.
- pulse6-p5 · p9는 앞 글 「출연자는 캐스팅북에서 고릅니다」의 표시 · 전속 문단과 가깝다. solio5는 앞 글 「AI 구독료와 결제일 정리하기」와 소재가 겹쳐, 넣는 자리가 바뀌었다는 한 줄을 더했다.
- 이번 주 안에서 pulse1과 pulse5가 폰 화면을, pulse4와 pulse5가 달력을 되풀이한다.
- AI 도구 · 서비스 · 모델 이름은 14편의 제목 · 태그 · 본문에 없다. 가상 브랜드는 pulse4 · 5 · 7에서 모두 밝혔다. 솔리오 글에 일반 회원에게 안 보이는 기능은 없다.

## 읽지 못한 근거

- github 릴리스 글 0.5.2 · 0.5.8은 열지 않고 코드와 설계 문서로 확인했다.
- 토큰을 세는 도구가 넷에서 셋이 된 판이 어느 판인지는 확인하지 못했다(0.5.8 원천이 셋인 것만 확인). 글은 「지금 판에서는 세 가지」로 고쳤다.
- 앱과 예시 화면을 실제로 띄우지 않았다. 자리는 코드와 CSS로 판단했다.
- git 밖 시험 원답, casting_s1.js, 결정 표의 사용 범위 행은 읽지 않았다.
