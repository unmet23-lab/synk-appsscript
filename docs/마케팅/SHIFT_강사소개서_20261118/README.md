# SHIFT 강사 소개서 — 웹 한 장과 A4 PDF (첫 시안, 2026-11-18)

유호님이 11월 18일에 「AI강사라면 이 사람이 어떤 강의를 하고 어떤 일을 하고있는지 이런 포트폴리오를 클라이언트 입장에서 한눈에 확인할수있게」 만들자고 하셨고, 「오케이 좋아. 만들어줘」로 첫 시안을 만들었다. 교육 담당자에게 링크와 PDF로 보내는 것이 목적이다. 사이트(synk.im/shift)는 이 소개서가 걸리는 주소로 둔다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 웹 한 장(자립형, SUIT 심음). 휴대폰 폭까지 맞췄다 |
| `양유호_AI강사소개서.pdf` | 같은 내용의 A4 세 쪽. 결재 서류에 붙이는 판 |
| `src/소개서.src.html` | 원고. 고칠 때는 이것만 고친다 |
| `src/굽기.mjs` | 원고 → `index.html`(그림 넣기, 글꼴 심기) → 캡처(1440, 390) → PDF. 캡처는 저장소 밖 `.tmp/SHIFT강사소개서_20261118/캡처/`에 둔다 |

다시 굽기: 저장소 뿌리에서 `node "docs/마케팅/SHIFT_강사소개서_20261118/src/굽기.mjs"`.
