## 만든 것

- 그림: `판/몽글_이름_궁금.txt` · `판/몽글_이름_기쁨.txt`(참고 `판/참고/` — 정본 본체 · 눈웃음, 흰 바탕 JPEG) → `판/몽글이름궁금_182833.png` · `판/몽글이름기쁨_182835.png`(세로 2:3, 빈 이름표 — 글은 코드로). GPT 이미지 2.5 굽기 계정 bake2, 두 장 · 다시 구운 것 없음. 굽기 `굽기.cjs`(M15 것을 복사).
- 도구 화면: Edge 헤드리스(playwright · channel msedge)로 synk.im/name을 열어 입력 칸에 한 글자씩 치며 찍음 → `remotion/public/img/tool/t_*.jpg`(Батбаяр 일곱 글자 + 끝) · `c_*.jpg`(Цэцэг 다섯 글자 + 끝), 카드 부분 y 690~1790만 잘라 씀.
- 영상: `remotion/`(M15와 같은 Remotion 4.0.535 설정 · node_modules 연결). 글 정본 · 시간표 `src/name/data.ts`, 화면 `src/name/Film.tsx`. 렌더 `npx remotion render src/index.ts name-mn out/name_v<n>.mp4`.
- 화면을 보며 고친 것: 그림을 1.25배로 가운데만 깔면 오른쪽 이름표가 화면 밖으로 잘려 너비 1080(1.0547배)으로 깔고 위 300px은 벽색으로 이음, SUIT에 「→」가 없어 「>」로 찍혀 화살표는 Inter Tight · Segoe UI로, 끝을 관문대로 실제 도구 화면(빈 입력 칸 · 깜빡이는 커서)으로.

## 몽골어 세 겹 검수
