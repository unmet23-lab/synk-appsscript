## 몽골어 세 겹 검수

글 파일 `검문/화면글.txt` · `검문/캡션.txt`(한국어 원문 / --- / 몽골어). 화면 글 정본 `remotion/src/chat/data.ts`, 게시 글 정본 `게시/문안.json`.

- **① 대조기(`tools/몽골어대조.js --파일 … --구독`)** — 1차 · 2차(고친 글 전체) 모두 문법 · 자연스러움(원문 안 보고 채점, gemini-4-argon) **「정상」**. 직역 역번역 ↔ 원문 뜻은 이 세션이 대조 — 모든 줄 뜻이 같다(за → 「알겠어 · 응」, 말맛 차이만). 맞춤법 의심은 고치지 않는다: чатлахдаа(M2에서 판정한 들어온 말), гырэ · нэ · жоаё(한국어 소리를 적은 읽는 법 — 사전 밖이 맞음, жоаё는 2차에서 빠짐). 결과 `검문/대조_*_1차.txt` · `_2차.txt`, 검문 장부 대상지문(2차 화면 글) 4ccde952c7af.
- **② 원문을 안 본 새 하위 에이전트(Opus) 직역 역번역 — 두 번.** 1차 「고쳐서」: 꼭 고칠 것 둘 — 위 띠 «гэхдээ»가 「하지만」으로 먼저 읽힘, 캡션에 반말 «чинь»와 존대 «Та»가 섞임. 권한 것: «идэцгээе»는 셋 이상 → «идье», «нойрсоорой»는 높임 쪽 → 반말 「잘 자」에 맞게, 「그래~」에 맞춰 «За~», «Багш, ахмад хүнд»는 쉼표 때문에 부르는 말로 읽힘, «энгийн үг»는 경고가 약함, «оюутан»은 대학생만, 한국어 쪽 「좋아요」는 제안에만 맞음. 2차(바뀐 줄) **「그대로」** — 선택 셋(амраарай는 「잘 쉬어」라 унтаарай도 됨 · 캡션 2행 꾸밈말 · ⚠ 줄 хүнд 두 번)은 Fable 2차와 함께 보아 그대로 두었다.
- **③ Fable 교정 — 두 번.** 1차 「고쳐서 올림」 P0 0 · P1 1(캡션 「거의 모든 대답」은 과장 — 그래는 친구 말을 받는 반말 대답, 예/아니오 질문 · 윗사람 자리는 아님 → 「친구 말에 하는」으로 좁힘) · P2 8(гэхдээ · идэцгээе · нойрсоорой → амраарай · 「Солонгос 'за'」는 「한국 за」로 읽힘 → Солонгосоор · 호칭 섞임 → 끝 질문에서 Та를 뺌 · ⚠ 줄을 чи / Та로 풀기 · оюутан → сурагч, оюутнуудад · 「그래, 그래」의 한국어 뜻은 「괜찮아」가 아니라 「알았어, 알았어」) · P3 4(「좋아요」 빼고 「네」만 등). 반영해 2차 **「그대로 올림」**(P0 · P1 · P2 0, 「화면은 과장하지 않는다」). 원어민 검수는 아니다.
- 고친 줄(1차 → 최종): 위 띠 «Солонгосоор 'за' гэхдээ: 그래» → «Солонгосоор 'за' гэвэл — 그래», «Хоол идэцгээе!» → «Хоол идье!», «Сайхан нойрсоорой!» → «Сайхан амраарай!», «그래 = За» → «그래~ = За~», «Солонгос 'за' = 그래» → «Солонгосоор 'за' = 그래», «Багш, ахмад хүнд» → «Багш болон ахмад хүмүүст»(M2 검수 글과 같은 말), «Та өдөрт хэдэн удаа…» → «Өдөрт хэдэн удаа…», 캡션 «найз чинь» → «найз тань» · 둘째 줄 · ⚠ 줄 · 끝 줄.

## 이해 시험

`node tools/낯선이시험.js <영상> --말 시험/말_없음.txt --브랜드 lab-mn`(말 없음)의 `질문.md`를 새 하위 에이전트(Sonnet, 몽골 입문 학습자 역할)에 그대로 줬다(재료 `시험/v2` · `v3` · `v4`).

- **v2(첫 렌더 · 검수 반영, 17.8초)** — 답 1 「몽골어 за를 한국어 그래로 바꿔 쓰면 되고, 억양에 따라 그래! · 그래, 그래 · 그래~로 뜻이 달라진대」 — 앞 절반은 한 문장과 같지만 셋을 억양 차이로 읽음 · 12초 넘김(정리 카드가 글자만 빽빽) · **3점 → 다시**. 짚인 것: 「그래, 그래」를 왜 두 번 쓰는지, 「네」가 뭔지(설명 없음), [гырэ]가 읽는 법인지. 고침: 카드 셋의 대답을 모두 같은 「그래 = За」로(말풍선만 「그래! 😋 · 그래 🙂 · 그래~ 👋」), 정리 카드는 제목을 빼고 「그래 ✗ → 네 [нэ] ✓」, 카드 간격 3.2 → 2.8초.
- **v3(다시 1, 16.8초)** — 답 1 「한국어 "그래"는 친구 사이 "응, 알겠어"이고, 몽골어 за처럼 쓰지만 선생님 · 어른에게는 "네"를 써야 한다」 = 한 문장과 같음 · 8~12초 「답을 알았다」로 넘길 수 있음 · 12초 칸이 빽빽 · **3점 → 다시**. 짚인 것: 「글자 전환이 빨라 읽을 시간이 모자란다」, 「그래~ 👋」의 손 흔들기, 댓글에 무엇을 쓰라는지. 고침: 카드 간격을 3.2초로 되돌림, 정리 카드는 민트 바탕 하나에 친구 줄을 작게 · 「그래 ✗ → 네 ✓」를 크게(네 116px), 「그래~ 🌙」, 끝 카드에 답의 꼴 「10? · 100?」.
- **v4(다시 2 · 올릴 판, 18.2초)** — 답 1 「몽골어로 за라고 할 말을 한국어 친구에게는 그래라고 하면 된다. 단, 선생님이나 어른께는 네」 = 한 문장과 같음 · **끝까지**(「첫 장면부터 내 모국어로 질문하니 바로 이해된다」) · 남은 물음(0초 「'За'」를 숫자 3a로 볼 뻔함, 소리가 없어 [гырэ] 소리를 귀로 확인 못 함, 끝 카드 작은 줄)은 한 문장에 꼭 필요하지 않음 · **4점 → 통과**. 올릴 파일은 v4를 음량마감 · CBR 다시 담기만 한 것(화면 그대로).
