## Intent
synkbrief 활용 한 편. 사용자가 제시한 Instagram 참고 8개의 개선 요소를 적용한 실제 MP4와 따라 할 수 있는 자료를 만든다. 결과를 먼저 보여주고, 제품 사진을 이미지 편집 AI에 넣을 때 무엇을 고정하고 무엇을 바꿀지 친절하게 알려준다.

## Assets
- 직접 생성한 무지 파란 머그컵 원본과 동일 제품을 참조한 전체/디테일/사용 장면. AI 생성 예시임을 표시한다.
- 한국어 합성 여성 내레이션. 기존 Typecast 은경 인증이 현재 연결되지 않아 실제 생성 가능한 SunHi를 이번 편에 사용한다.
- 기존 승인 서체 SUIT/Inter Tight, 보유 음원과 효과음.

## Customizations
- 표지와 영상 전 구간 상단에 정확한 시리즈명 ‘synkbrief 활용’을 작게 표시하고, 시청자가 얻을 결과를 본제목으로 크게 보여준다.
- 결과 먼저, 고정 원본/결과 비교, 화면 확대로 시선 유도, 소품을 이용한 짧은 상황, 큰 제목, 입력 순서 강조, 3개 훅 대안, 친근한 감정의 나레이션.
- 이미지 생성 결과는 실제로 생성하고 검사한다. UI 모형을 실제 앱 녹화로 표현하지 않는다. 프롬프트는 편집 그래픽으로 제시한다.

## Notes
신규 결제·구독·충전 없음. 로컬 제작 및 재생 확인 범위이며 게시 요청은 없다. 실제 영상 시점 변경은 생성하지 않았으므로 이번 편은 사진 편집과 모션 편집을 명확히 구분한다. 영상 시점 생성에서 제품 이미지 예제로 주제를 좁혔다.
