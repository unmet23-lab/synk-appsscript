# synkbrief — 사진 한 장으로 광고 세 컷

2026-09-27. 사용자가 준 8개 참고를 이번 편에 연결한 제작 메모다. 참고 게시물은 화면과 설명을 직접 확인했다. 참고 영상의 음성은 직접 청취하지 않아 목소리·음악의 품질 평가는 하지 않았다. 아래 적용 항목은 제작 지시이며 실제 출력·청취 통과 여부는 최종 검증 기록에서 구분한다.

## 이번 편의 약속

제품 사진 한 장을 바탕으로 AI에서 전체·디테일·사용 장면을 각각 만들고, 제품의 모양과 색이 유지됐는지 확인한 뒤 짧은 광고로 편집하는 방법을 보여준다. 생성 예시는 가상 제품이다. 제품 사진의 배경·구도·상황을 바꾸는 작업이며, 기존 동영상에서 카메라 각도를 자유롭게 바꾸는 기능을 검증한 것으로 설명하지 않는다.

## 같은 본문에 붙일 훅 세 가지

1. 결과형: “사진 한 장으로, 광고 세 컷을 만들었어요.”
2. 문제형: “제품 사진이 한 장뿐이라면, 이 세 컷부터 만드세요.”
3. 실수형: “AI 광고 사진, 멋져 보여도 여기부터 확인하세요.”

각 훅은 같은 원본·같은 본문·같은 엔딩을 사용한다. 실제 게시 후 3초 유지율·완주율·저장·자료 요청을 비교하기 전에는 우열을 단정하지 않는다.

## 출처에서 받아들이지 않은 주장

- Instagram 특정 설정을 켜거나 끄면 도달이 보장된다는 주장.
- AI의 새 각도가 항상 정확하며 화질 손실이 없다는 주장.
- 생성한 광고가 자동으로 성과 좋은 광고가 된다는 주장.
- 특정 음성의 무료 기간이나 요금이 모든 접속 경로에 동일하게 적용된다는 주장.

## 생성 접근 확인

Higgsfield CLI 모델 목록에서 Seedance 2.5와 Genjutsu를 확인했다. 계정 잔액 0.92크레딧으로 새 유료 영상 생성은 진행하지 않았다. 같은 날의 로컬 계정 확인 기록에는 Genjutsu 무료 스위치가 나타나지 않았고, 활성 무제한 모델은 이미지 모델로 한정됐다. 따라서 이번 편은 내장 이미지 생성 도구로 실제 이미지를 만든 뒤 직접 편집하는 범위로 정했다. 새 결제·구독·충전을 하지 않는다.

기존 LAB 실사 카페 영상은 유호 얼굴 재현에 대한 사용자 수정 요청이 남아 있어 이번 편의 성공 사례로 재사용하지 않는다.
