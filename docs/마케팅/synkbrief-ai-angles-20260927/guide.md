# 사진 한 장으로 광고 세 컷 만들기

synkbrief 실습 가이드 · 2026-09-27

제품 사진 한 장을 바탕으로 **전체 모습, 디테일, 사용하는 장면**을 각각 만들고 짧은 광고로 연결해 봅니다. 이미지 편집이 가능한 AI 도구와 제품 사진, 복사용 요청문을 준비하세요. 도구마다 지원 기능과 이용 조건은 다릅니다.

이번 편의 예시는 가상 제품을 사용합니다. 생성 이미지는 실제 제품의 구조·색·기능을 보장하지 않으므로 판매용으로 쓰기 전 원본과 대조해야 합니다.

## 1. 기준 사진을 넣으세요

새 이미지 작업이나 새 대화를 열고 사진 첨부 버튼에서 제품 사진을 넣습니다. 첨부 미리보기에 원하는 사진이 표시됐는지 먼저 확인하세요.

제품 전체가 잘 보이고, 손잡이·뚜껑·모서리 같은 특징이 가려지지 않은 사진이 좋습니다. 직접 찍었거나 사용할 권리가 있는 사진을 사용하세요. 이 실습은 한 장으로 시작하지만, 원본에서 보이지 않는 뒷면이나 내부까지 정확히 복원하는 작업은 아닙니다.

## 2. 유지할 것과 바꿀 것을 함께 적으세요

사진과 함께 아래 요청문을 붙여 넣습니다. 제품 종류와 색은 내 사진에 맞게 바꾸세요. 한 번에 여러 장을 만들기 어려운 도구라면 전체 컷부터 하나씩 요청하면 됩니다.

> 첨부 사진의 제품을 기준으로 광고에 쓸 이미지 3장을 각각 따로 만들어 주세요. 제품의 모양, 비율, 재질, 색, 손잡이와 뚜껑 구조를 유지하세요. 원본에서 확인할 수 없는 부품이나 기능은 새로 만들지 마세요. 무지 제품의 표면은 그대로 비워 두고 글자와 로고를 넣지 마세요. 바꿀 것은 배경, 조명, 제품을 보여주는 각도입니다. 첫째는 전체 형태를 보여주는 컷, 둘째는 실제로 보이는 특징을 가까이 보여주는 디테일 컷, 셋째는 자연스럽게 사용하는 장면입니다. 같은 제품으로 보이도록 통일하고 각 이미지는 세로 9:16으로 만들어 주세요.

전체 복사용 문장과 컷별 요청문은 함께 제공한 `prompt.txt`에 있습니다.

## 3. 세 컷을 따로 만드세요

| 컷 | 보여줄 것 | 요청 예시 |
|---|---|---|
| 전체 | 제품의 모양과 첫인상 | “제품 전체가 보이는 3/4 정면 컷. 단순한 배경, 자연스러운 그림자.” |
| 디테일 | 구매자가 실제로 보고 싶은 특징 | “원본에 보이는 손잡이와 표면 재질을 가까이. 부품의 연결과 비율을 유지.” |
| 사용 장면 | 어떤 상황에 어울리는지 | “밝은 책상에서 성인의 한 손이 제품을 자연스럽게 잡는 장면. 손가락과 접촉 위치가 정확하게.” |

예쁜 이미지 세 장보다 **서로 다른 질문에 답하는 세 장**이 유용합니다. 전체는 “어떤 제품인가?”, 디테일은 “어떻게 생겼나?”, 사용 장면은 “언제 쓰나?”에 답합니다.

## 4. 원본과 나란히 확인하세요

생성 이미지마다 같은 원본 사진을 옆에 놓고 다음을 확인합니다.

- 모양: 손잡이·뚜껑·모서리·개구부의 개수와 연결 위치가 같은가?
- 색과 재질: 다른 색이나 과장된 유광 표면으로 바뀌지 않았는가?
- 비율: 크기와 두께가 컷마다 달라지지 않았는가?
- 손: 손가락 수와 관절, 제품을 잡는 위치가 자연스러운가?
- 문자: 없던 로고·인증·문구가 생기지 않았는가?
- 사실: 실제 없는 기능이나 사용 상황을 사실처럼 보여주지 않는가?

틀린 부분을 발견하면 전체를 막연하게 다시 만들기보다 위치와 고칠 점을 구체적으로 짚으세요.

> 두 번째 결과에서 손잡이가 원본보다 두꺼워졌습니다. 첨부한 원본의 손잡이 두께와 연결 위치로 맞춰 주세요. 나머지 배경과 조명은 유지하세요.

한 장의 사진에서 확인할 수 없는 특징이 필요하면 실제 추가 사진을 준비하는 편이 정확합니다.

## 5. 확인한 컷만 광고로 연결하세요

편집 도구에서 세로 9:16 화면을 만들고 **전체 → 디테일 → 사용 장면** 순으로 이미지를 배치합니다. 각 컷은 1.5~2.5초 정도로 시작해 읽기와 제품 확인 시간을 보면서 조절하세요.

이미지에 약한 확대나 이동을 넣으면 시선이 이어집니다. 이것은 사진을 편집한 움직임이며 새로운 카메라 시점의 동영상을 생성한 것은 아닙니다. 가격·행사·제품명처럼 정확해야 하는 글자는 확인한 정보를 편집 단계에서 추가하세요. AI 이미지 속 작은 글자를 그대로 쓰지 마세요.

## 6. 소리와 출력도 확인하세요

첫 문장은 결과를 보여주면서 짧게 읽습니다. 예를 들어 “사진 한 장으로, 광고 세 컷을 만들었어요.” 다음 행동을 안내할 때는 동작 사이에 짧은 쉼을 두세요. 배경음은 말소리를 가리지 않게 낮춥니다.

1080×1920 MP4로 내보낸 뒤 실제 휴대폰 크기로 끝까지 재생합니다. 글자가 잘리지 않는지, 컷이 너무 빠르지 않은지, 말과 화면이 맞는지 확인하세요. 출력 해상도가 생성 원본의 세부 정보를 새로 만들어 주는 것은 아닙니다.

## 막힐 때

| 문제 | 먼저 해볼 일 |
|---|---|
| 한 이미지에 세 컷이 붙어 나옴 | “콜라주가 아니라 컷별 파일 한 장씩”이라고 적고 한 컷씩 요청합니다. |
| 제품 모양이 바뀜 | 원본을 다시 첨부하고 바뀐 위치 하나를 지정합니다. 확인이 어려운 결과는 제외합니다. |
| 새 컷마다 다른 제품처럼 보임 | 같은 기준 사진과 동일한 제품 설명을 매번 사용합니다. 색·재질·구조 조건을 반복합니다. |
| 글자나 로고가 깨짐 | 이미지 생성에서는 글자를 빼고, 정확한 문구를 편집 단계에서 넣습니다. |
| 손이 어색함 | 잡는 위치를 단순하게 바꾸거나 손이 없는 사용 환경 컷으로 다시 만듭니다. |
| 결과가 세로 화면에 맞지 않음 | 생성 시 9:16을 지정하고, 편집에서 제품이 잘리지 않는지 확인합니다. |

## 내 제품으로 바꿔 보기

제품 한 개를 정하고, 원본 사진을 넣고, 컷별로 보여줄 특징 하나씩만 고릅니다. 생성 뒤에는 반드시 원본으로 돌아와 대조하세요. 짧은 광고의 완성도는 컷 수보다 제품이 정확하고 각 컷의 역할이 분명한지에 달려 있습니다.
