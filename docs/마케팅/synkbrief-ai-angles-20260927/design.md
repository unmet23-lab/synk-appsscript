# Visual direction
표지와 영상 전체 상단에는 `synkbrief 활용`을 작은 시리즈명으로 표시한다. `synkbrief`는 Inter Tight 38px, `활용`은 SUIT 34px·코발트색이며, 결과 중심의 본제목은 크게 유지한다.

파란 도자기 한 개가 광고가 되는 과정을 눈으로 납득한다. 흰 바탕/검정 글씨, 제품의 코발트색을 강조색으로 사용한다. SYNK 정본의 흰색과 서체를 따른다. 큰 숫자 1→3과 사진의 크기 대비로 첫 프레임에서 결과를 읽는다.

광고 사진은 크게, 설명은 짧고 정확하게. 제품을 가리는 모션이나 의미 없는 카드는 피한다. 사진이 중심인 장면과 입력 문장이 중심인 장면을 번갈아 놓아 리듬을 만든다. 참조 사진은 실제 결과와 나란히 고정하고, 모양·색·테두리를 관찰할 때만 작은 표시를 붙인다.

1080×1920. 중요한 문구는 x=80..950, y=220..1560. 하단 자막은 2줄 이내 50~56px, 검정 바탕 흰색. 헤드라인 100~160px, 설명 46~60px. 30fps. 장면6개. 움직임은 사진 리프레임, mask reveal, 명확한 cut, 약한 overshoot를 의미 있는 지점에만.
