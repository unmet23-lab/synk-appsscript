# synkbrief 활용 — 사진 1장으로 광고 3컷 · SNS 키트판(kit-v1)

56.5초 · 세로 1080×1920 · 한국어 내레이션 · HyperFrames. 2026-10-01 「전에 쓰던 양식 이걸로 전부 다 교체해줄래?」에 따라 원본(2026-09-27, [`../README.md`](../README.md))을 [SNS 제작 키트](../../../디자인/SNS키트/README.md)의 모양과 모션으로 다시 만들었다. **렌더 전 상태다.** 사용자가 미리보기를 보고 렌더를 정하기 전이라 승인본이 아니다.

## 원본에서 그대로 둔 것

- 소리: 원본 최종 믹스 `../assets/audio/master.wav`(Edge TTS SunHi 내레이션 + 보유 Suno 음악 + 효과음 넷)를 바꾸지 않고 쓴다. 56.5초, 원본과 같은 시각.
- 장면 순서와 말: 결과 → 사진 올리기 → 바꾸지 않을 것 → 세 컷 따로 → 원본과 비교 → 이어 붙이기·자료 안내. 자막 22줄은 `../captions.srt`와 같은 글이다.
- 사실: 원본·결과 4장은 내장 이미지 생성으로 만든 가상 머그컵이다(`../image-generation.md`). 화면 머리줄에 「AI 예시 이미지」, 사진마다 「AI 예시」를 붙였다. 카메라 화면의 날짜 도장 2026.09.27은 실제 생성일이다. 자료는 실제 `../guide.pdf`(4쪽) 첫 쪽과 `../prompt.txt` 문장만 썼다. 자동 DM은 말하지 않는다.
- 원본 MP4·표지·장면 파일은 손대지 않았다.

## 키트로 바꾼 것

- 6장면 → 키트 장면 17개. 장면은 1.4~5.4초(대부분 3~4초), 화면 변화 간격은 가장 길어도 1.3초, 첫 3초는 0.8초 안이다.
- 0초 화면 = 표지: 청금석 색 면, 실땀 네 모서리, 제목 「사진 1장으로 / 광고 3컷」, 원본 1장 + 결과 3장 콜라주, SHIFT 로고 라벨.
- 자막: 원본의 검은 상자 자막을 키트 `kv-cap`으로 바꿨다. 낱말마다 `../audio-timing.json`의 실제 시작 시각에 튀어나온다(M.caption과 같은 움직임). 강조 낱말은 계정색·형광펜이다. 아래끝은 y 1236이다.
- 유행 장치는 장면마다 하나까지: 카메라 화면(증거) 1번, 옛 창(복사할 요청문) 1번, 컨페티(끝 장) 1번.
- 끝은 따라 하기 자료다. S16에서 guide.pdf 첫 쪽과 맞춤 틀(`[제품]`이 「파란 머그컵」으로 바뀌는 요청문 첫 문장)을 보여 주고, S17 끝 장의 행동은 「댓글에 synk」 하나다.
- 원본 믹스의 효과음 네 개를 새 장면에 맞췄다. 톡(0.30초)은 표지, 딸깍(10.0초)은 「＋ 사진 첨부」 칩이 눌리는 때, 휙(25.43초)은 S7→S8 종이 밀어 올리기의 끝, 차임(46.1초)은 S15 아치가 다 열리는 때다.
- 원본 마지막 장면의 광고 예시 문구(「하루의 파란 쉼표.」)는 넣지 않았다.

## 다시 만들기·렌더

이 폴더에서:

```bash
npm run kit      # assets/synk-kit/ 이 없을 때(키트 사본은 git에 올리지 않는다)
npm run media    # ../assets/audio/master.wav 를 assets/audio/ 로 복사(10.8MB, git 제외)
npm run check    # 오류 0 확인
npx --yes hyperframes@0.8.104 render --quality delivery --fps 30 --output renders/synkbrief-photo-to-3cuts-kit-v1.mp4
```

렌더는 사용자가 미리보기(`npx --yes hyperframes@0.8.104 preview --background`)를 보고 정한 뒤에 한다. 이미지(`assets/images/*.webp`)는 원본 PNG를 품질 92 webp로 옮긴 파생본이다.

## 남은 것·확인할 것

- 사용자 시청과 렌더 결정, 렌더 뒤 실제 휴대폰에서 끝까지 보기.
- 「이미지 편집 AI」: 원본 기록에는 도구 이름이 없다(내장 이미지 생성, 모델 식별자 없음). 키트 견본(캐러셀·모션견본)의 「ChatGPT 이미지 편집」 표기는 근거를 찾지 못해 이 편에서는 쓰지 않았다.
- 내레이션은 「팔로우하시고 댓글에 synk를」로 두 가지를 말하지만 화면의 행동은 「댓글에 synk」 하나만 보여 준다. 댓글 요청을 받으면 자료를 전할 사람이나 확인된 전달 경로가 먼저 있어야 한다(`../copy.md`).
- 효과음은 원본 믹스의 네 개뿐이다. 키트 §9의 스티커·도장 「톡」과 전환용 천 스치는 소리는 아직 없다.
