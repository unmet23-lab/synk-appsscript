# 디자인 기준

이 프로젝트의 화면·색·서체·부품은 [SYNK SNS 제작 키트](../../../디자인/SNS키트/README.md)가 원문이다. `assets/synk-kit/`은 `node tools/SNS키트_영상연결.js <이 폴더>`로 복사한 키트 사본이고, 고치려면 키트 원본을 고친 뒤 다시 복사한다.

- 계정 테마: `brief`(synkbrief, 청금석 `#3D6BC9` 색 면 + 흰 종이, 노란 형광펜). 로고는 흰 라벨(`.k-logo-tag`) 위 원본 SHIFT 펠트 로고.
- 서체: 한글·라틴 SUIT Variable, 라벨·숫자 DM Mono(키트 사본의 `fonts/`).
- 9:16 안전 영역: 메타 통합 기준 위 269 · 아래 672 · 좌우 65, 오른쪽은 단추 자리라 160. 글자는 y 269~1248, 자막이 있는 장면의 내용은 y 1040까지.
- 움직임: 키트 `motion.js`(SynkMotion) 프리셋. 규칙은 키트 README §9.
- 개념 한 줄: 결과를 먼저 보여 주고, 펠트와 실땀이 장면을 꿰매듯 넘긴다.
