# 질문 카드 4개 인계

기존 Resolve 프로젝트에 삽입할 4K60 질문 카드다. 모든 산출물은 이 `revision4/graphics` 폴더에 있으며 기존 영상/프로젝트 파일을 변경하지 않았다.

## 파일

- `question_01_4K60.mov`: 왜 이 시스템을 만들기 시작했나요?
- `question_02_4K60.mov`: 왜 TOPIK 4급이 중요한가요?
- `question_03_4K60.mov`: AI 시대, 어떤 교육 철학이 필요한가요?
- `question_04_4K60.mov`: 기술이 만든 시간을 어떻게 쓰고 싶나요?

각각 3840×2160, 60fps, **정확히210프레임/3.5초**, HEVC Main10/yuv420p10le/hvc1, Rec.709 limited. 음성/음악 트랙 및 알파 채널은 없다. 네 파일 합계205,622바이트다. 인물용 LUT를 적용하지 않는 무등급 클립으로 사용한다.

## 서체와 배치

- 기존 로컬 `graphics/fonts/SUIT-SemiBold.otf` 본문128px, `SUIT-Medium.otf` Q.60px 재사용.
- 4K 기준 본문 줄간격192px. 질문마다 두 줄로 나눈 뒤 완성 문구의 최대폭 기준으로 수평 중앙에 블록을 배치했다. Q.를 포함한 실제 글자 범위의 수직 중심은 약1080px이다.
- 블록 내부는 왼쪽 정렬이다. 각 글자의 최종 좌표를 미리 계산하므로 타이핑 도중 위치가 밀리지 않는다. 한글은 완성 음절 단위로 나타나며 쉼표/물음표는 공통 baseline을 사용한다.
- 배경 RGB0,0,0 불투명 검정. 본문RGB238,238,238, Q. RGB174,174,174. 로고·테두리·커서·추가 장식은 넣지 않았다.

## 타이밍과 사운드 연결

- 로컬F12(0.20초)부터 입력, F90(1.50초)에 마지막 글자가 완전히 표시된다.
- F198(3.30초)까지 유지한 후 사라지며 F209는 완전 검정이다.
- `question_typing_events.json`: `cards[].typing_units`는 모든 글자/공백/줄바꿈의 로컬 시점, `cards[].keystrokes`는 실제 타건음 위치다. 공백과 줄바꿈은 타건에서 제외했다. Q1/Q2 각15회, Q3/Q4 각16회.
- 오디오 담당에게 타이밍을 확정 전달했다. 이 타이밍은 본문84→128px 수정 전후 동일하다.

## 검수

- `question_cards_preview.png`: 모든 카드의1.00초 입력 상태와2.00초 완성 문구 비교.
- `question_cards_decoded_contact.jpg`: 실제 HEVC 결과의 완성 문구4개를 직접 확인한 이미지. 한글/영문/문장부호·줄바꿈·중앙 위치가 정상이다.
- `question_cards_validation.json`: 4파일 전체 디코드, 규격, 정확한 프레임 수 검증 통과.
- `question_cards_pixel_validation.json`: 실제 출력 F0/F120/F209의 검정 배경에서 10bit limited Y=64를 확인했다. 알파 투명 배경이 아니다.
- `question_cards_head_tail_validation.json`: 실제 출력 첫/마지막 프레임의 전체 화면을 축소 디코드해 완전 검정인지 확인한다.

질문 카드의 검정은 의도된 화면이므로 최종 전체영상 blackdetect 검수에서는 확정된 카드 구간과 예상 검정 시간을 구분한다. 네이티브 Resolve 조립 후 자막 중복·질문 직후 연결은 부모 단계에서 확인한다.
