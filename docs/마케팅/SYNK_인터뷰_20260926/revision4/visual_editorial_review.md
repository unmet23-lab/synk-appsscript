# v4 최종 검토

- 검토 대상: 최종 4K MP4, 14,560프레임, 242.666667초.
- 최종 재배열 자막을 다시 읽고 네 질문과 답변의 연결을 검토했다. 만들게 된 이유 → TOPIK 4급의 필요성 및 시스템의 책임 → AI 시대의 교육 철학 → 확보한 시간의 쓰임 순서가 성립한다.
- 세 번째 장은 아날로그 시대의 경험을 서론으로 두고 AI 활용과 비판적 사고로 이어진다. 앞선 두 장보다 설명이 길지만 참조 대상이 사라지는 중대한 연결 오류는 발견하지 않았다.
- 주 검토자는 자막 69개의 중간 프레임과 영상 시작·끝을 확인했다. 독립 검토자는 질문 카드 40프레임 및 32개 화면 경계의 127프레임을 확인했다. 자막 겹침, 뜻밖의 검정 화면, 피부색 급변, 비정상적인 얼굴 변화는 발견하지 않았다.
- 72.600–72.683초의 짧은 홀드는 정확한 프레임과 픽셀 차이로 재확인했다. 72.683초에서만 예정한 각도 전환이 있다. 기존 6개 보완 연결점도 유지됐다.
- 자동 검사: 전체 4K 영상 디코드 통과, 질문 구간 밖 검정 화면 없음, 1초 미만 뜻밖의 장면 후보 없음. 음성 17구간의 원본 믹스 대비 지연은 모두 0샘플. 유지한 대사의 내부 구간은 기존 PCM과 일치한다.
- 범위: 자막의 문맥 검토, 실제 출력의 정지 프레임 검토, 전체 디코드 및 디지털 음성 대조다. 전체 영상을 사람이 연속 시청·청취한 검수로 표기하지 않는다.
