# 리졸브 인터뷰 편집·색보정 기준

2026-09-26 사용자 확정: “앞으로도 다빈치 리솔브로 영상 만들 때 이런 매끄러운 구성을 기억해서 처음부터 이렇게 제대로 만들어줘. 컷편집이든 구성이든 색보정이든 누렇지 않게.” 이번 v4는 승인 사례이며 질문 수·영상 길이·LUT 수치를 모든 영상에 고정하는 템플릿은 아니다.

- 전체 음성과 자막으로 시청자가 이해할 이야기 순서를 먼저 짠다. 원인·구체적인 사례·주장·결론의 관계를 세우고, 반복은 가장 자연스러운 테이크로 정리한다. 앞 문장 없이 등장하는 지시어와 갑작스러운 주제 이동을 점검한다.
- 큰 전환에는 질문 화면을 필요한 만큼 사용한다. 검정 배경, 간결한 글자, 짧고 은은한 타이핑 소리와 읽는 여유를 둔다. 장면마다 질문을 반복하지 않는다.
- 문장 끝·호흡·몸짓이 자연스럽게 이어지도록 자르고 실제 출력에서 잔여 프레임과 순간적인 다른 장면을 확인한다. 자막은 최종 대사 순서와 타이밍에 맞춘다.
- 피부는 밝고 자연스러운 중성톤을 우선한다. 노란색·주황색 기운이 과해지지 않게 각도별 피부와 흰색 물체를 비교하되, 푸른 흰색이나 과도한 미백·뭉개진 질감이 되지 않도록 한다. 눈과 잡티도 본래 인상이 유지되는 수준에서 보정한다.
- 목소리 음질을 소음 제거보다 우선한다. 과도한 제거로 깨지거나 로봇처럼 들리게 하지 않는다. 말소리 크기를 맞추고 BGM·효과음은 대사를 가리지 않게 조절한다.
- 첫 완성본부터 구성·컷·색·자막·소리를 함께 확인한다. 렌더 전체 디코드와 경계·싱크 검사, 실제 화면 확인을 수행하고 확인한 범위를 정확히 보고한다. 원본과 이전 결과물은 보존한다.
