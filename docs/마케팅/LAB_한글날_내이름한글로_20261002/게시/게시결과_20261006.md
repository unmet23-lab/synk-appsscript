## 못 한 것과 이유

- **크롬 연결이 없었다.** Claude in Chrome의 연결된 브라우저 목록이 비어 있었고(`list_connected_browsers` → `[]`), 연결 요청도 「연결할 브라우저가 없음」으로 끝났다. 10-03에 쓴 unmet23 프로필 창(deviceId 147f7161-…)이 열려 있지 않았거나 확장이 붙어 있지 않은 상태였다.
- 그래서 로그인이 필요한 일(AI 표시 켜기, 고정 댓글 달기, 댓글 읽기)은 할 수 없었다. 작업 지침대로 비밀번호·인증 코드는 넣지 않았다.
- 게시 확인은 앱 안 브라우저(로그인 없음)로 공개 페이지를 읽어서 했다. 페이스북 페이지의 「릴스」 탭은 로그아웃 상태에서 「SYNK님의 릴스 0」으로 보이지만, 「동영상」 탭과 릴스 주소(`/reel/1360223745951241/`)에는 올라가 있다. 로그아웃 화면의 표시 한계이지 게시 실패가 아니다.
- 이름이 적힌 댓글은 아직 없어 답글 줄은 만들지 않았다.

## 유호님 몫(남은 것)

1. **AI 표시 켜기(두 곳, 필수).** 사실적인 AI 목소리(Typecast 서현)와 AI 음악이 들어가 Meta 규정상 표시 대상이다.
   - 인스타 앱: @synk.mn → 그 릴스 → ⋯ → 수정 → 「AI 정보」(AI로 만든 콘텐츠 표시) 켜기 → 완료.
   - 페이스북 앱 또는 웹: facebook.com/synkworld → 그 릴스 → ⋯ → 게시물 수정 → AI 정보 표시 켜기. 웹에 없으면 휴대폰 앱에서.
2. **고정 댓글 달기(문구 그대로, [고정댓글.txt](고정댓글.txt)).**
   - 인스타 릴스: `Жишээ нь: Батбаяр → 바트바야르 ✨ Таны нэр хэн бэ? 👇` → 달고 고정.
   - 페이스북 릴스(페이지 이름 SYNK으로): 두 줄 `Жишээ нь: Батбаяр → 바트바야르 ✨ Таны нэр хэн бэ? 👇` / `Өөрөө бичээд үзэх: https://synk.im/name/` → 달고 고정.
3. **인스타 프로필 링크 첫 칸을 `https://synk.im/name/`로.** 휴대폰 앱에서만 된다: 프로필 편집 → 링크 → 외부 링크 추가 → URL `https://synk.im/name/`, 제목 `Нэрээ солонгосоор` → 맨 위로. 인스타 문구·소개글이 「프로필 링크」를 가리키므로 빨리 하는 편이 좋다.
4. **이름 댓글 답글.** 댓글에 이름이 달리면 폴더에서 `node 게시/댓글이름.cjs Батбаяр Оюунчимэг …`로 답글 줄을 만든다. 다는 것은 유호님이 하거나 확인 뒤에.
