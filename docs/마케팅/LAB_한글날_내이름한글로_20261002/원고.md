## 하지 않은 것

- 실존 인물을 지목하지 않는다. 이름은 몽골에서 흔한 이름(Хулан·Мөнх·Болд·Түвшин)이다.
- 몽골어 문장은 도구 페이지의 표현을 최대한 그대로 썼다. 원어민 확인은 아직이다.
- 목소리는 한국어만 넣었다. 몽골어 목소리는 넣지 않았다(몽골어는 화면 글자로).
