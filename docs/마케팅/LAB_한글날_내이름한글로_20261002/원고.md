# LAB · 한글날 · 「이 이름 누구일까요?」 (몽골어, 21초)

> 2026-10-02 사용자 「첫편 하나만 만들어보자」. [제작 방식 v2](../콘텐츠_제작방식_v2_20261002.md)로 만든 첫 편이다.

## v2 점검

| 항목 | 이번 편 |
|---|---|
| 트리거 | **달력**: 10/9 한글날(훈민정음 반포 580돌, 한글날 제정 100주년), 2026 한글주간 10/6~17. 10/6까지 게시 |
| 볼 이유 | 몽골 학습자가 한글로 쓴 몽골 이름을 맞혀 보고, 왜 그렇게 쓰는지 한 번에 알게 된다 |
| 0초 훅 | 질문 「Энэ ямар нэр вэ?」(이 이름 뭘까?) + 큰 한글 「홀란」 |
| 재미 장치 | 맞히기 두 판(3·2·1 → 정답), 몽글 표정 컷, 정답의 이유 칩 |
| 깨달음 | 한글로 쓰면 몽골어 о·у가 둘 다 ㅗ, ө·ү가 둘 다 ㅜ가 된다(「모음 넷이 둘로」) |
| 정보 출처 | synk.im/name 페이지의 설명: 몽골어 한글 표기의 공식 세칙은 없고(국립국어원 외래어 표기법에 몽골어 세칙 없음), 도구는 키릴 자모 소리값·굳어진 표기(울란바토르·칭기즈)·도성경(2023, 『몽골학』 73집)에 기댄다. 예시 변환은 같은 페이지의 `convert()`를 그대로 돌려 확인했다 |
| 진짜 한 컷 | 실제 synk.im/name 화면을 휴대폰 크기로 찍은 사진(입력 한 글자 = 사진 한 장, `녹화_도구화면.cjs`) |
| 맞춤 프로그램 | synk.im/name — 내 이름을 넣으면 한글 표기, 다른 표기, 저장해 스토리에 올리는 펠트 이름 카드 |
| 끝 행동 | 「Нэрээ бичээд үзээрэй」(내 이름 써 보기) → synk.im/name, 댓글에 내 한글 이름 |
| 씨앗 계정 | 페이스북 synkworld + 인스타 @synk.mn(같은 편을 같이) |

몽골어 문장의 뜻: 이 이름 뭘까? / 그럼 이건? / 알아요? 모음 넷이 둘이 돼요 / 몽골어로는 다르고 한글로는 같아요 / 직접 확인해 보세요 · 당신 이름을 한글로? / 이름을 써 보세요 · 그림을 저장해서 스토리에 올리세요 · 당신 이름은 한글로? 댓글에 써 주세요.

## 하지 않은 것

- 내레이션 없음(사실적인 AI 목소리를 넣지 않아 AI 표시 의무 대상이 아니다). 음악은 「아 맞다」와 같은 LAB 곡(Lyria 생성)이다.
- 실존 인물을 지목하지 않는다. 이름은 몽골에서 흔한 이름(Хулан·Мөнх·Болд·Түвшин)이다.
- 몽골어 문장은 도구 페이지의 표현을 최대한 그대로 썼다. 원어민 확인은 아직이다.
