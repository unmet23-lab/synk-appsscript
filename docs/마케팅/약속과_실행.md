## 약속마다 여섯 칸

① 확정된 약속과 원문 → ② 실제 있는 실물 → ③ 확인할 증거 → ④ 상대가 받는 때 → ⑤ 필요한 비용·담당 → ⑥ 무엇이 되면 완료인가를 기존 제작/결과 문서에 함께 적는다. ‘코드가 있다’만으로 상대에게 전달·사용된 상태를 채우지 않는다. 모르는 비용은 0원이 아니고 날짜 가안은 출시 약속이 아니다.

| 결과 공개 | 들어온 수·2주 뒤 남은 수·같은 기준의 내부 진단 상승 수를 분리. TOPIK은 실제 응시 수와 취득 수를 시험일·분모와 함께 별도로 적음. ‘취득했다’는 실제 TOPIK 결과에만 사용 |

| 학생 실물의 대외 사용 | 비식별, 서면 동의·철회, 학습과 홍보의 2층 분리 위 사용자 판정. 자세한 적용은 [철학 공개 기준](../철학_적용기준.md#4-대외-사용과-근거) |

### F1 기록을 옮겨야 하는 경우

웹 진단이 준비되지 않아 F1을 시작 자료로 사용하면 원래 답·문항/보기·시각·연락 통로를 보존한다. 이전 계획의 10-31은 준비 달력의 판단 시점이며 오늘 상태를 대신하지 않는다. **표본급수, 맞힌문형, 다음문형은 비워 둔다.** F1에는 웹 진단 급수·문형 번호가 없기 때문이다. 급수경로·상태에 ‘폼에서 옮김 · 문형 번호 없음’을 남겨 다른 진단과 섞지 않는다. 실제 시작점에 쓰는 경우만 회차 0의 시작 진단으로 연결한다. 이 문서는 이관 완료 증거가 아니다.

F1 문구의 실행 원천은 `F1_설명_KR`·`F1_설명_MN`이다. 확정 언어 수정은 해당 원천을 갱신하고 배포 뒤 `f1폼설명갱신()`으로 이미 열린 폼까지 확인한다. AI 언어 대조·원어민 감수·코드 배포·실제 폼 적용을 분리해 보고한다.

## SHIFT·PULSE·SYNK의 보존 조건

- SHIFT는 내 얼굴·공개 가능한 작업·완성물·일의 수치를 보여주고, 학생 기록·학생/학부모 얼굴·음성·글·내부 엔진·금융 화면·미공개 고객 자료를 영업 재료로 쓰지 않는다. 고객에게 비용·권리를 정확히 설명하는 것은 대표 개인의 수익 과시와 다르다.
- 자격 사업에서 ‘응시자가 적다고 기준을 낮추지 않는다’는 선택을 유지한다. 되묻기·문제 알리기·금지 준수·거절/부탁의 전달이라는 공개 평가 축과 비공개 문항·채점을 구분한다. 등록 전에는 연구용 진단이며 인증서·취업 효과로 과장하지 않는다.
- 귀환자 직장 경험의 회고는 우리 학생 학습 이력과 별개의 자료다. 졸업생 종단 기록은 기존 학생 ID 계약에서 다루며 문의자·고객사가 곧 채용처나 응시자라는 추론을 하지 않는다.
- 제작은 PULSE, 계약·청구·고객 관계는 SHIFT다. 우리 작품·캐릭터 등 재사용 자산과 고객 소유 납품물은 소유권을 구분한다. PULSE 작품의 채널·가수·레이블 명칭은 해당 결정에서 정하며 회사 소개의 PULSE 이름을 모든 작품 간판에 덧씌우지 않는다.
- 라디오 감상 링크와 모집 진단 링크를 구분한다. 앱 라디오·개별 청취 수집·학생별 곡 사이 낱말을 복구하지 않는다. 곡 수·송출 상태·작업 모델·유료 지갑 잔액은 현행 제작·계정에서 확인하며 이 문서에 복제하지 않는다.
- SYNK 본체 IG 월 1회 완료물과 결정 한 가지를 보여주는 선택을 유지한다. 과거의 ‘SYNK 단독 비노출’을 회사 홈페이지·본체 계정 허용보다 위에 두지 않는다.

현재 실행은 [AI 운영 원칙](../AI_운영원칙.md)과 [SNS 게시 분담](../research/sns-upload-20260910/게시워크플로우_확정.md)을 따른다. 과거 ‘AI는 발행 버튼을 못 누른다’는 포괄 제한·고정 모델·제작 시간 상한·완료된 검수 왕복·옛 계정 수를 현재 규칙으로 사용하지 않는다.
