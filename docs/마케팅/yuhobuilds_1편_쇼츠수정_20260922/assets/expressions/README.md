# 대사별 표정과 폭포 눈물

2026-09-22 사용자 요청: 같은 프로필 사진만 반복되어 아쉽다며 대사에 맞는 표정 변화 요청. 이어서 눈 감은 얼굴의 양쪽 눈에서 파란색 폭포 같은 코믹한 ㅠㅠ 눈물을 요청했다. 엔딩에는 바탕화면의 다른 사진도 사용해도 된다고 했다.

내장 ImageGen으로 기존 얼굴의 미소·난감함·놀람·감은 눈 4개 표정을 편집했다. [정확한 프롬프트](prompts.json). 얼굴의 방향·헤어·조명·크기를 유지하도록 요청하고 공통 좌표로 알파 배경을 처리했다. 사진은 AI로 편집된 파생물이며 실제 촬영한 표정이라고 주장하지 않는다. 각 `*-green.png`가 생성 원본이고 이름이 짧은 PNG가 영상용 알파 이미지다.

| 대사 | 표정·효과 |
|---|---|
| 번역을 하려고… 출석 앱까지 | 기본 → 가벼운 놀람 |
| 친구도 없고… | 기본 → 난감한 표정 |
| 학생 문의가 늘었어요. 잠깐… | 놀람 → 고민 |
| 설정부터 막혔죠 | 난감함 → 눈 감기 + 파란 폭포 눈물 |
| 오, 다음 화면! 근데 이건 또 뭐야? | 미소 → 난감함 |
| 심심함은 해결됐습니다. 앱은요? | 미소 → 난감함 |
| 몇 번을 뜯어고쳤는지 깊은 한숨이 잦았답니다 | 감은 눈 + 파란 폭포 눈물 |
| 실제로 탈모 걸린 거 아닌지 가끔 머리를 만져봤어요 | 놀람·느낌표 → 난감함, “탈모빔… 아직이지?” |
| 불편한 일 하나만 골라보세요 | 기본 → 격려하는 미소 |
| 마지막 채널 멘트 | 다른 사진 `ending-portrait.jpg` |

표정 전환은 실제 단어 타임스탬프의 프레임에 맞추고 4프레임 동안 연결한다. 기본 얼굴에는 짧은 눈 깜빡임을 넣었다. 폭포 눈물은 7번 장면의 78프레임에서 시작하며 감은 눈 아래에서 굵은 파란 물줄기·흐르는 밝은 줄무늬·떨어지는 물방울이 움직인다. 다음 장면에서는 끊긴다. 후속 사용자 요청으로 11b 장면의 깊은 한숨에도 97~138프레임 동안 눈물을 적용하고, 138프레임부터 놀란 얼굴과 “탈모빔… 아직이지?”로 전환한다. 느낌표는 153프레임에 나타난다.

기본 Chromium 렌더에서 일부 프레임의 제목·카드가 사라지는 현상을 발견했다. 다중 drop-shadow 제거만으로는 해소되지 않아 렌더 브라우저를 명시적 소프트웨어 렌더링(`swangle`)으로 전환했다. 최종 MP4의 농담 구간 모든 안정 프레임에서 제목이 남아 있는지도 검사한다. 합성된 얼굴과 폭포 효과는 유지한다.

엔딩 사진은 사용자가 바탕화면에 둔 `KakaoTalk_20260908_215815072.jpg`의 동일 파일 복사본이며 별도의 얼굴 생성 편집 없이 카드로 배치했다. 원본과 68초 표정 수정 전 영상은 보존했다.
