# 프로필 얼굴 합성

2026-09-22 사용자 요청: 기존 캐릭터의 얼굴만 본인 프로필 사진으로 합성. 바탕화면에 둔 추가 사진도 이후 필요하면 사용하도록 요청했다.

원본은 `C:/Users/q1212/OneDrive/Desktop/유호_프로필_800.png`. 동일 파일을 연재 자료의 `근거/인물사진_20260922/`에 보존했다. 추가 사진은 아직 시각 검토하지 않았으며 첫 편에는 사용하지 않았다.

내장 ImageGen 편집을 사용했다. 모델 버전은 도구가 확인해 주지 않으므로 특정 버전으로 단정하지 않는다. 얼굴은 사진을 기반으로 생성 편집한 파생물이며 원본 픽셀을 그대로 잘라낸 무손실 누끼는 아니다.

첫 요청: "Create a clean cutout of ONLY this same man's head. Preserve facial identity, skin texture, hairstyle, eye gaze and expression. Include hair, ears and chin; remove background, hand, arm, shirt, shoulders and neck below chin. One photoreal head, no cartoon, no added smile or distortion. Transparent background."

첫 출력은 투명 알파 대신 체크무늬 RGB 배경으로 반환되어 영상에 쓰지 않았다. `yuho-head-first-checkerboard.png`로 보존했다.

후속 최종 요청: "Change ONLY the gray/white checkerboard background to a perfectly flat pure green RGB(0,255,0) chroma key background. Preserve the existing photographed head, face, skin, expression, hair and composition. No shadows, texture, gradients, objects, text or white border."

`yuho-head-green.png`를 내장 ImageGen으로 만든 뒤 `../prepare-head.cjs`에서 초록 배경을 알파로 변환하고 가장자리의 초록 번짐을 낮췄다. 최종 `yuho-head.png`는 840×1100 RGBA이며 알파 0~255 범위를 확인했다. Remotion의 기존 파란 몸체·움직임은 보존하고 머리 영역만 이 자산으로 교체했다. 밝고 어두운 장면에서 외곽과 목 연결을 실제 렌더로 확인했다.

## 대사별 표정 후속 수정

한 사진의 반복을 줄이기 위해 [4개 표정 파생물과 폭포 눈물](expressions/README.md)을 반영했다. 엔딩은 다른 웃는 사진으로 바뀌었으며 정확한 입력·프롬프트·시점은 연결된 기록을 따른다.
