## 바뀐 구성

1. 영상의 첫 질문 장면과 전체 진행 순서를 함께 보여 준다.
2. 자리표시자에서 출석 앱 문장으로 바뀌는 모습과 전송 버튼을 표시한다.
3. AI 답변 예시에서 첫 작업만 강조한다.
4. 막히는 말을 되묻는 질문과 답변을 대화 그림으로 보여 준다.
5. 빈 표와 가상 학생의 출석 기록 한 줄을 비교한다.
6. 같은 흐름을 자기 아이디어에 적용하는 질문과 작성란을 제공한다.

영상의 기존 캡처 `../검수/prompt-complete.png`를 원본 그대로 축소해 삽입했다. 대화와 표는 설명을 위해 직접 구성한 벡터 그림이며, 실제 서비스의 스크린샷이나 실제 모델 답변이 아니다. 해당 화면에 학습용 예시를 표시했다. 브랜드별 메뉴나 요금 안내는 다루지 않는다.

이번 목표는 앱 설치나 구현 완료가 아니라 첫 질문을 보내고 수행할 작업 및 확인할 결과를 이해하는 것이다. 종이 표는 앱 개발 전 기록 항목을 정하는 연습으로 설명한다. 실제 사용 성과를 주장하지 않는다.

## 검수와 재생성

`build-guide.py`로 PDF와 질문 텍스트를 만들고 `verify-guide.py`로 영상 원문 일치, 글꼴 포함과 한글 추출, 여백, 쪽수, v1 원본 보존을 확인한다. 기존 `../pdf-guide-v1/prepare-fonts.py`의 글꼴 준비 결과를 사용한다. 현재 6쪽 전체를 렌더해 실제 배치까지 확인했다.

사용자 검토 대기 상태이며 영상, 엔딩 음성, 공개 업로드는 변경하지 않았다.
