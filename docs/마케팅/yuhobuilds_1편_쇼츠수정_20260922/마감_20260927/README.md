## 이번 수정

결제·학생 문의·부모님 알림·설정 오류·화면 캡처·코믹한 강조·엔딩에 효과음 30개를 추가했다. 기존 내레이션·BGM·타건음을 보존한 믹스에 짧은 효과음을 더했으며, 말할 때 효과음이 낮아지도록 조절했다. 사용 자산과 처리 값은 [효과음 기록](audit/sound-cues.json)에 남겼다.

‘화면 찍고 → 물어보고 → 따라 하고’ 카드 세 장의 등장과 소리를 발화에 맞췄다. 프롬프트 입력은 기존 말끝·타건 동기화를 유지한다. 자막의 등장 이동과 여백도 정리했다. 최근 회고는 ‘기능은 늘고, 출석은 뒷전…’이라는 화면 문구에 반영했다.

내레이션 원본, 55개 자막의 문구·시간, 전체 분량은 유지했다. 9월 26일에 추가한 긴 스토리 대사 초안은 아직 음성에 반영하지 않았다. Typecast 재합성이나 추가 결제는 없었다.

## 편집 원본

기존 Remotion 프로젝트를 유지하고 이번 수정만 `영상/src/yuhoShorts01/finish20260927/`에 분리했다. 기존 소스 사본은 `source-before/`, 실제 편집 입력은 `props.json`, 효과음 원본은 `assets/sfx/`에 보관한다. HyperFrames의 전환·음향 검수 지침과 directional-wipe 참고 컴포넌트를 현재 렌더 구조에 맞춰 적용했다.
