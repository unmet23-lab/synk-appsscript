## 사실과 각색

첫 결제일과 번역 목적, 학원 근무, 학생 문의 증가, 부모 알림의 구상, Glide와 Google Sheets 첫 시도, 코딩을 전혀 모르던 상태와 스크린샷 반복은 사용자 회고에 근거한다. 문의 증가를 등록생 증가로 바꾸지 않는다.

부모 알림과 교사 편의는 당시의 목표다. 앱의 구현 완료나 현장 사용 성과가 아니다. 17~18시간은 주관적 회고이며 권장 학습량이 아니다. 출석 앱 대신 괴상한 것을 만들고 있었다는 표현은 사용자 요청을 다듬은 대사다. 뒤틀린 앱 화면과 심심함 해결은 맥락 안에서 각색한 연출이다. 반복 수정 뒤 한숨과 머리를 확인하는 농담은 사용자가 직접 제안한 코믹 대사이며 실제 탈모 진단을 뜻하지 않는다.

12~14번은 현재 시청자에게 제안하는 방법으로 당시 실제 첫 프롬프트가 아니다. 인물은 사용자가 제공한 유호 프로필 얼굴과 그림 몸체를 합성했다. 작업 화면은 재구성이며 실제 학생 데이터를 표현하지 않는다. 100시간은 처음부터 설정을 알았더라면 시간을 아꼈을 것이라는 개인적 가정으로, 실측 결과나 시청자 절감 보장이 아니다.

## 2026-09-26 · 기능을 늘리다 목적을 놓친 장면 보강 제안

상태: [추가 사용자 회고](../yuhobuilds_제작여정_202607-20260922/시작_사용자회고_20260922.md#기능을-늘리다-출석이라는-목적을-놓치다--추가-회고-2026-09-26)를 반영한 대사 초안. 위 기존 대본 및 업로드 최종본의 음성·자막·영상에는 아직 반영하지 않았다. 08~12 구간을 재구성할 때 활용하며 기존 구간에 전부 덧붙이지 않는다.

### 대사 초안

화면 찍고, 물어보고, 따라 하고!

그런데 만들다 보니 욕심이 나더라고요. 이것도 넣고, 저것도 넣고. 클로드가 알려주는 대로 계속 붙였죠.

기능은 늘었는데, 화면은 점점 조잡해졌어요. 그러다 문득… 잠깐, 나 출석 앱 만들고 있었잖아?

정작 출석은 뒷전이 된 거예요.

지금 다시 시작한다면, 딱 하나부터요. 출석 한 번을 쉽고 확실하게 기록하는 것부터 만들 거예요.

### 이야기와 화면 연결

- 사용자 욕심과 AI의 안내를 따라 기능을 붙이던 선택을 함께 보여준다. AI가 잘못된 기능을 강제로 넣었다고 표현하지 않는다.
- 장면마다 약 2~3초의 변화: 처음 목표 ‘출석 기록’ → 추가 기능 카드가 늘어남 → 복잡해진 화면 → 사용자가 처음 목표를 다시 바라봄. 정확한 길이는 실제 낭독 뒤 정한다.
- 추가 기능은 이름을 지어내지 않은 상징 카드로 표현하고, 당시 앱 화면을 확인한 것처럼 제시하지 않는다. 출석 기능이 실제 삭제됐다는 연출은 피한다.
- UI·UX는 1편에서 용어 설명을 늘리기보다 ‘화면이 보기 쉽고, 출석을 기록하는 과정이 간단한가’로 풀어준다. 이는 현재의 학습 연결이다.
- 기존 한숨·탈모 농담과 장시간 작업 대사는 전체 길이를 보고 압축할 후보로 둔다. 삭제·재합성·재렌더를 완료한 상태는 아니다.
