# 출석 앱 설명의 호흡과 표정 강조

2026-09-22 사용자 요청: “출석 앱을 만들면?”과 “부모님께 등하원 알림도 가고” 사이가 붕 뜨므로 주변과 비슷한 빠른 템포로 연결하고, 감정 표현을 강조할 때 가끔 얼굴 옆 느낌표를 넣기.

기존 정의로 음성을 재사용했다. 원본 `audio/narration-05.wav`와 JSON을 보존하고 편집본을 `audio/edited/`에 만들었다. 새 음성 합성이나 API 키 연결은 필요하지 않았다.

- 1.060~1.500초, 3.075~3.300초의 무음 내부만 제거했다. 단어 타임스탬프와 겹치는 편집은 코드에서 거부한다. 절단 양쪽에는 4ms 페이드를 적용한다.
- 이 구간만 `atempo=1.03`으로 피치 변화 없이 약 3% 빠르게 했다. 원본 구간 4.631초에서 약 3.850초로 줄었다.
- FFmpeg의 -38dB 무음 검사에서 첫 내부 쉼은 약 0.608초 → 0.159초, 두 번째 내부 쉼은 약 0.366초 → 0.137초로 줄었다. 직접 청취 평가를 완료했다는 의미는 아니다.
- 모든 후속 자막·장면·BGM 길이를 다시 정렬했다. 전체 타임라인은 67.100초다. 다른 구간의 발화 속도는 유지한다.

느낌표는 “출석 앱까지”의 놀람, “오, 다음 화면!”의 반가움, “심심함은 해결됐습니다”의 미소에만 각각 약 0.8초씩 얼굴 옆에 나타난다. 세 곳에 파란 느낌표·짧은 등장 탄성·사라짐을 적용하고 기존 폭포 눈물과 엔딩 사진은 유지한다.

편집 설정은 `audio-edits.json`, 재현 코드는 `edit-narration.cjs`와 `prepare-audio.cjs`다. 이전 표정판은 `이전버전/표정판_템포수정전/`에 보존했다. 미리보기의 “수정한 템포” 버튼은 해당 문장의 시작으로 이동한다. 규격·자막·믹스·실제 재생 결과는 `검수/`를 따른다.
