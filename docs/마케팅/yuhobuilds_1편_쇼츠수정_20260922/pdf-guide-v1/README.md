## 구성

1. 내 문제 고르기: 누가 쓰는지, 무엇이 불편한지, 첫 기능 하나를 정한다.
2. 첫 질문 보내기: 영상과 같은 질문에서 만들고 싶은 것만 바꿔 입력한다. 로드맵과 프롬프트 뜻을 짧게 설명한다.
3. 막히면 다시 묻기: 용어 설명, 첫 작업 좁히기, 완료 확인을 위한 후속 질문을 제공한다.
4. 내 첫 계획 남기기: 만들 것, 첫 기능, 지금 할 작업, 확인할 결과를 적는다.

출석 앱 예시를 일관되게 사용한다. 실제 학생 대신 가상 이름으로 연습하며, 빈칸은 메모장이나 인쇄물에 쓰도록 안내한다. 입력 가능한 PDF 양식은 아니다.

## 원문과 검수

영상 예시는 `../검수/업로드_20260926/final-script.json`의 13a 구간과 대조했다. 실제 학원 사용이나 확정적인 시간 절약 성과를 새로 주장하지 않는다.

`validation.json`에 PDF SHA-256, 4쪽 구성, 영상 질문 일치, 한글 텍스트 추출, 글꼴 포함, 여백과 페이지 번호 검사를 기록했다. 최종 PDF를 이미지로 변환해 4쪽 모두 확인했다. 실제 초보자 사용성은 사용자 검토 후 보완한다.

`build-guide.py`가 PDF와 복사용 텍스트를 생성하고 `verify-guide.py`가 검사한다. `prepare-fonts.py`는 기존 브랜드 글꼴에서 필요한 정적 글꼴을 준비한다. 렌더와 글꼴 작업 파일은 저장소의 `tmp/pdfs/yuhobuilds-ep01-v1/`에 둔다.

영상과 공개 배포 주소는 이번 PDF 작성에서 변경하지 않았다.
