## 반영

PDF는 기존 그림 흐름을 유지하고 복사·붙여넣기 안내, 모르는 말과 완료 확인, 막힌 상황을 전달하는 질문을 추가한 9쪽이다. 페이지 번호와 질문 번호를 구분했다. 모든 질문에는 새 대화인지 같은 대화인지, 바꿀 부분, 답을 받은 뒤 할 일을 안내한다.

`prompts.json`의 7개 질문을 PDF와 텍스트에서 함께 사용한다. `프롬프트/`의 개별 TXT에는 제목이나 설명 없이 질문만 담았다. 01·02번 중 하나를 골라 시작하고 03~07번은 필요할 때만 쓰며, 04번은 출석 앱 예시 전용임을 명시했다.

전체 텍스트판에는 PDF 본문 전부와 그림의 설명, 질문별 사용법을 담았다. 질문 모음, 개별 질문 7개, 먼저 읽을 안내, PDF까지 11개 파일을 ZIP으로 전달한다. TXT는 UTF-8 BOM을 사용한다.

## 검수

`build-guide.py`로 만들고 `verify-package.py`로 PDF/개별 TXT/질문 모음/전체 텍스트의 7개 질문 일치, 영상 속 질문 일치, PDF 여백·쪽수·글꼴, UTF-8 왕복, ZIP의 모든 파일 내용 일치를 확인했다. 최종 9쪽 렌더를 모두 육안으로 확인했다. v1·v2 PDF의 SHA-256도 대조해 보존을 확인했다.

영상 변경, 공개 업로드, 사용자 최종 승인은 이번 작업에 포함하지 않는다. 현재 사용자 검토본이다.
