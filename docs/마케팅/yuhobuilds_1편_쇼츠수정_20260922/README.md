## 재제작

기존 Typecast 연결이 있을 때만 synthesize.cjs로 필요한 새 구간을 합성한다. 같은 요청은 재사용하며 키는 저장하지 않는다. prepare-audio.cjs → finalize-docs.cjs → render.cjs → verify.cjs → finish-preview.cjs 순서로 자막·음악·렌더·검수·미리보기를 갱신한다. serve-preview.cjs는 로컬 4374 포트에서만 결과물을 보여준다.

음성 원본은 audio/narration-01~14.wav와 narration-15a.wav, 16~18.wav다. 괴상한 앱 구간은 narration-09a.wav이며 기존 narration-09.wav는 보존한다. 현재 농담 구간은 narration-11b.wav, 로드맵 질문은 narration-13a.wav다. 이전 narration-11.wav·11a.wav·15.wav는 보존한다. narration-only.wav는 음악 없는 연결본, music-bed.wav는 배경음악, narration-master.wav는 최종 믹스다. 육성 교체 시 실제 발화에 맞춰 장면과 자막도 재정렬한다.
