# yuhobuilds 1편 — 오프닝 모션·자막 마감본

2026-09-22. 앞선 59초본의 속도·화면·정의로 임시 목소리는 유지하고, 사용자가 요청한 엔딩 연결과 프로필 얼굴을 반영했다. 현재 원고 741자·18장면·56자막, 타임라인 75.600초다.

## 현재 오프닝 모션·자막 마감 — 2026-09-22

사용자가 지목한 오프닝 카드 안의 “개발을 처음 시작할 때, 이 순서만 알았어도” 중복 문구와 카드 틀을 제거했다. 전용 오프닝에서 제목→막히고·고치고·또 고치고→실제 발화 시점에 등장하는 100시간→결론과 밑줄로 이어진다. 숫자는 글자별로 짧게 시차를 두고 나타나며, 내레이션 뒤 여백을 0.2초 늘려 다음 소개로 연결했다.

전 장면의 제목은 줄별로 드러나고 카드 안 문구는 카드보다 조금 뒤에 들어온다. 자막은 자동 글자 수 나누기 대신 [문장별 편집표](caption-phrases.json)로 56구간을 편집했다. “아꼈을 / 것 같아요” 같은 끊김을 없애고, 줄바꿈·읽는 시간·여백을 맞췄다. 두꺼운 흰 테두리와 파란 그림자를 제거하고 간결한 검은 자막, 약한 그림자와 짧은 상승·페이드, 제한된 핵심어 강조를 적용했다.

현재 MP4 75.648초. [오프닝 모션 미리보기](opening-motion-preview.mp4). 전체 영상 디코딩·규격·원고와 자막 일치·말끝 타이핑 동기화 검사를 통과했다. 새 오프닝 단계별 화면과 전 장면 자막 배치를 확인했다. 직접 청취 여부는 검수 JSON을 따른다. 앞선 버전은 `이전버전/75초_모션자막마감전/`에 보존했다.

## 이전 100시간 오프닝·타건 동기화 수정 — 2026-09-22

“개발을 처음 시작할 때, 이 순서만 알았어도 100시간은 아꼈을 것 같아요.”를 맨 앞에 배치했다. 이어서 오늘의 번역→출석 앱 도전 이야기를 소개한다. 엔딩에서는 100시간 문장을 반복하지 않고 다음 편 설정 예고→제가 헤맨 길→채널 멘트로 마친다. 기존 16번·01번은 보존하고 새 16a·01a 음성만 합성했다.

타이핑은 고정된 0.667초 시작을 없애고 “학원 출석 앱을 만들고 싶어.”의 실제 단어별 타임스탬프에 맞췄다. 입력 안내는 문장 직전까지 남아 있고, 각 글자의 등장과 같은 프레임에 짧은 타건음을 재생한다. 마지막 글자는 발화 끝과 16ms 차이(30fps의 한 프레임 이내)다. 효과음은 직접 합성한 키 누름·떼기 소리이며 외부 샘플을 사용하지 않았다. 최종 믹스에서 내레이션·BGM과 함께 음량을 맞췄다.

현재 MP4 75.456초·48자막, 전체 디코딩·규격·자막 일치 검사 통과. [입력 장면만 보기](prompt-animation-preview.mp4)는 내레이션·타건음이 포함된 현재 장면이다. 전체 미리보기의 **입력 예시** 버튼은 53.367초로 이동한다. 직접 청취 완료는 주장하지 않는다. 앞선 74초본은 `이전버전/74초_100시간오프닝수정전/`에 보존했다.

## 이전 로드맵 질문·타이핑 수정 — 2026-09-22

시청자가 자기 아이디어로 바꿔 쓰도록 “나는 개발이 처음이야. [내가 만들고 싶은 것 입력] 가장 효율적으로 만들 수 있는 로드맵을 추천해 줘.”로 수정했다. 입력칸은 20프레임(0.667초) 뒤 안내 문구가 사라지고, 53프레임(1.767초)까지 “학원 출석 앱을 만들고 싶어.”가 빠르게 입력된다. 예시 표시와 깜빡이는 커서를 둔다.

정의로 내레이션은 “만들고 싶은 걸 넣고, 이렇게 물어보세요.”로 연결한 뒤 완성된 예시를 읽는다. 13a 구간만 합성했으며 기존 농담·엔딩·템포는 유지했다. 당시에는 무음 4초 입력 검토본을 만들었고, 전체 영상의 **입력 예시** 버튼은 47.7초로 이동했다. 현재는 위 동기화 장면으로 대체했다.

당시 MP4 73.813초·47자막. 전체 디코딩·규격·원고와 자막 일치 검사 통과. 입력 전·타이핑 중·완료 화면을 렌더해 배치를 확인했다. 직접 청취 여부는 검수 JSON을 따른다. 이전 71초본은 `이전버전/71초_로드맵수정전/`에 보존했다.

## 이전 대사·표정 수정 — 2026-09-22

사용자가 제안한 “앱은요? 몇 번을 뜯어고쳤는지 깊은 한숨이 잦았답니다. 실제로 탈모 걸린 거 아닌지 가끔 머리를 만져봤어요.”로 11번을 바꿨다. 정의로로 해당 구간만 새로 합성했고, 11b 원본을 보존한 채 앱은요 전후의 무음 총 0.55초만 줄였다.

한숨에서는 감은 눈의 파란 폭포 눈물, 이어지는 농담에서는 놀란 표정·느낌표와 **“탈모빔… 아직이지?”**를 보여준다. 앞선 정신이 혼미해졌다는 제안은 이번 대사로 대체했다. 실제 탈모 진단을 주장하는 내용은 아니다. 당시 미리보기의 **수정한 대사** 버튼은 36.333초로 이동했다.

당시 MP4 71.061초, 자막 45개. 전체 디코딩·규격·자막 검사와 변경 장면 시각 확인을 마쳤다. 직접 청취 여부는 검수 기록을 따른다. 이전본은 `이전버전/템포판_혼미대사수정전/`에 보존했다.

## 이전 템포·강조 후속 수정 — 2026-09-22

“출석 앱을 만들면?” 뒤의 무음을 약 0.608초에서 0.159초로 줄이고 다음 내부 쉼도 줄였다. 해당 문장만 피치 변화 없이 약 3% 빠르게 편집했으며 원본 음성은 보존했다. 자막·이후 장면·음악 길이를 다시 맞췄다. 얼굴 옆 파란 느낌표는 놀람·반가움·미소의 세 순간에만 약 0.8초씩 나타난다. [정확한 편집 구간과 확인](../../템포_강조_수정.md).

## 재제작

기존 Typecast 연결이 있을 때만 synthesize.cjs로 필요한 새 구간을 합성한다. 같은 요청은 재사용하며 키는 저장하지 않는다. prepare-audio.cjs → finalize-docs.cjs → render.cjs → verify.cjs → finish-preview.cjs 순서로 자막·음악·렌더·검수·미리보기를 갱신한다. serve-preview.cjs는 로컬 4374 포트에서만 결과물을 보여준다.

음성 원본은 audio/narration-01~14.wav와 narration-15a.wav, 16~18.wav다. 현재 농담 구간은 narration-11b.wav, 로드맵 질문은 narration-13a.wav다. 이전 narration-11.wav·11a.wav·15.wav는 보존한다. narration-only.wav는 음악 없는 연결본, music-bed.wav는 배경음악, narration-master.wav는 최종 믹스다. 육성 교체 시 실제 발화에 맞춰 장면과 자막도 재정렬한다.
