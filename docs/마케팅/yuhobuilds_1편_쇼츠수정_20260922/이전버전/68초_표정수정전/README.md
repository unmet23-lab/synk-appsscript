# yuhobuilds 1편 — 엔딩·프로필 얼굴 수정본

2026-09-22. 앞선 59초본의 속도·화면·정의로 임시 목소리는 유지하고, 사용자가 요청한 엔딩 연결과 프로필 얼굴을 반영했다. 현재 원고 647자·18장면·43자막, 타임라인 67.867초다.

## 이번 수정

- 다음 편의 도구 실행·설정 예고 → 초보였던 내가 처음부터 알았다면 적어도 100시간은 아꼈을 것이라는 회고 → “제가 헤맨 길, 여러분은 건너뛰세요” → “왕초보에서 1인 기업가까지. 여러분의 시간을 아껴드립니다!”로 이어진다. 숫자만 분리해 보여주지 않는다.
- 첫 14구간 음성은 그대로 재사용하고 엔딩 4구간만 정의로로 새로 합성했다. 사용자가 준비할 육성으로 교체할 수 있도록 [녹음용 대본](육성녹음용_대본.txt)과 분리 음원을 유지한다.
- 사용자 프로필 사진의 머리·얼굴을 내장 ImageGen으로 편집하고 기존 파란 옷 캐릭터에 합성했다. 몸체와 움직임은 보존했다. [사진 파생물과 프롬프트](assets/제작기록.md), [원본 사진 9개 보관](../yuhobuilds_제작여정_202607-20260922/근거/인물사진_20260922/README.md).
- 사용자가 지목한 “실화 기반 · 일부 대사와 화면 재구성 · AI 내레이션” 하단 문구를 영상에서 제거했다. 제작 근거는 [원고](원고.md)에 유지한다.
- 시티팝 BGM, 말할 때 음악을 낮추는 믹스, 빠른 자막·화면 전개를 유지했다. 끝부분에서 음악을 페이드아웃한다.

## 결과와 확인

- [영상 보기](http://127.0.0.1:4374/preview.html), [MP4](yuhobuilds_EP01.mp4): 1080×1920, 30fps, H.264/AAC, 실측 67.925초.
- 표지·18장면·마지막 화면을 렌더해 얼굴 경계, 목 연결, 글자 배치와 하단 문구 제거를 확인했다. MP4 전체 디코딩·규격 검사 통과.
- 43개 자막의 원고 일치와 시간 범위·겹침 검사 통과. 최종 AAC -16.03 LUFS / -2.50 dBTP. 직접 청취 평가 여부는 검수 JSON을 따른다.
- 외부 게시 없음. [수정 전 59초본](이전버전/59초_엔딩수정전/)과 [첫 3분판](../yuhobuilds_1편_20260922/README.md)을 보존했다.

## 재제작

기존 Typecast 연결이 있을 때만 synthesize.cjs로 필요한 새 구간을 합성한다. 같은 요청은 재사용하며 키는 저장하지 않는다. prepare-audio.cjs → finalize-docs.cjs → render.cjs → verify.cjs → finish-preview.cjs 순서로 자막·음악·렌더·검수·미리보기를 갱신한다. serve-preview.cjs는 로컬 4374 포트에서만 결과물을 보여준다.

음성 원본은 audio/narration-01~14.wav와 narration-15a.wav, 16~18.wav다. 이전 narration-15.wav는 보존한다. narration-only.wav는 음악 없는 연결본, music-bed.wav는 배경음악, narration-master.wav는 최종 믹스다. 육성 교체 시 실제 발화에 맞춰 장면과 자막도 재정렬한다.
