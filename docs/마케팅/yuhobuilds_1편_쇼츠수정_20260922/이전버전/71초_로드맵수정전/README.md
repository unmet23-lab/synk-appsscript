# yuhobuilds 1편 — 한숨·탈모빔 대사 수정본

2026-09-22. 앞선 59초본의 속도·화면·정의로 임시 목소리는 유지하고, 사용자가 요청한 엔딩 연결과 프로필 얼굴을 반영했다. 현재 원고 693자·18장면·45자막, 타임라인 71초다.

## 현재 대사·표정 수정 — 2026-09-22

사용자가 제안한 “앱은요? 몇 번을 뜯어고쳤는지 깊은 한숨이 잦았답니다. 실제로 탈모 걸린 거 아닌지 가끔 머리를 만져봤어요.”로 11번을 바꿨다. 정의로로 해당 구간만 새로 합성했고, 11b 원본을 보존한 채 앱은요 전후의 무음 총 0.55초만 줄였다.

한숨에서는 감은 눈의 파란 폭포 눈물, 이어지는 농담에서는 놀란 표정·느낌표와 **“탈모빔… 아직이지?”**를 보여준다. 앞선 정신이 혼미해졌다는 제안은 이번 대사로 대체했다. 실제 탈모 진단을 주장하는 내용은 아니다. 미리보기의 **수정한 대사** 버튼은 36.333초로 이동한다.

현재 MP4 71.061초, 자막 45개. 전체 디코딩·규격·자막 검사와 변경 장면 시각 확인을 마쳤다. 직접 청취 여부는 검수 기록을 따른다. 이전본은 `이전버전/템포판_혼미대사수정전/`에 보존했다.

## 이전 템포·강조 후속 수정 — 2026-09-22

“출석 앱을 만들면?” 뒤의 무음을 약 0.608초에서 0.159초로 줄이고 다음 내부 쉼도 줄였다. 해당 문장만 피치 변화 없이 약 3% 빠르게 편집했으며 원본 음성은 보존했다. 자막·이후 장면·음악 길이를 다시 맞췄다. 얼굴 옆 파란 느낌표는 놀람·반가움·미소의 세 순간에만 약 0.8초씩 나타난다. [정확한 편집 구간과 확인](템포_강조_수정.md).

당시 MP4 실측 67.157초. 당시 미리보기에는 **수정한 템포** 버튼을 제공했다. MP4 전체 디코딩·규격 및 자막 일치 검사를 통과했다. 직접 청취 평가를 완료했다는 의미는 아니다. 이전 표정판은 `이전버전/표정판_템포수정전/`에 보존했다.

## 이전 표정 후속 수정 — 2026-09-22

사용자가 한 사진의 반복을 지적해 대사별 미소·놀람·난감함과 짧은 눈 깜빡임을 반영했다. “설정부터 막혔죠”에는 사용자 요청대로 감은 눈에서 파란 폭포 눈물이 쏟아진다. 실제 발화에 맞춰 전환하고 다음 장면에서 효과가 끊긴다. 마지막은 바탕화면의 다른 웃는 사진으로 교체했다. [표정 자산·정확한 프롬프트·대사별 구성](assets/expressions/README.md).

당시 표정 수정 단계에서는 음성·BGM·원고·자막 길이를 유지했으며 실측 67.925초였다. 표지·18장면·눈 깜빡임·폭포 눈물·웃음/난감함 전환·마지막 사진의 실제 렌더를 확인했다. MP4 전체 디코딩과 규격 검사를 통과했다. 이전본은 `이전버전/68초_표정수정전/`에 보존한다. 직접 청취 및 사용자 최종 승인은 별개이며 외부 게시하지 않았다. 미리보기의 **표정·눈물** 버튼은 현재 22.833초로 이동한다.

## 앞선 엔딩·얼굴 수정

- 다음 편의 도구 실행·설정 예고 → 초보였던 내가 처음부터 알았다면 적어도 100시간은 아꼈을 것이라는 회고 → “제가 헤맨 길, 여러분은 건너뛰세요” → “왕초보에서 1인 기업가까지. 여러분의 시간을 아껴드립니다!”로 이어진다. 숫자만 분리해 보여주지 않는다.
- 첫 14구간 음성은 그대로 재사용하고 엔딩 4구간만 정의로로 새로 합성했다. 사용자가 준비할 육성으로 교체할 수 있도록 [녹음용 대본](육성녹음용_대본.txt)과 분리 음원을 유지한다.
- 사용자 프로필 사진의 머리·얼굴을 내장 ImageGen으로 편집하고 기존 파란 옷 캐릭터에 합성했다. 몸체와 움직임은 보존했다. [사진 파생물과 프롬프트](assets/제작기록.md), [원본 사진 9개 보관](../yuhobuilds_제작여정_202607-20260922/근거/인물사진_20260922/README.md).
- 사용자가 지목한 “실화 기반 · 일부 대사와 화면 재구성 · AI 내레이션” 하단 문구를 영상에서 제거했다. 제작 근거는 [원고](원고.md)에 유지한다.
- 시티팝 BGM, 말할 때 음악을 낮추는 믹스, 빠른 자막·화면 전개를 유지했다. 끝부분에서 음악을 페이드아웃한다.

## 재제작

기존 Typecast 연결이 있을 때만 synthesize.cjs로 필요한 새 구간을 합성한다. 같은 요청은 재사용하며 키는 저장하지 않는다. prepare-audio.cjs → finalize-docs.cjs → render.cjs → verify.cjs → finish-preview.cjs 순서로 자막·음악·렌더·검수·미리보기를 갱신한다. serve-preview.cjs는 로컬 4374 포트에서만 결과물을 보여준다.

음성 원본은 audio/narration-01~14.wav와 narration-15a.wav, 16~18.wav다. 현재 농담 구간은 narration-11b.wav다. 이전 narration-11.wav·11a.wav·15.wav는 보존한다. narration-only.wav는 음악 없는 연결본, music-bed.wav는 배경음악, narration-master.wav는 최종 믹스다. 육성 교체 시 실제 발화에 맞춰 장면과 자막도 재정렬한다.
