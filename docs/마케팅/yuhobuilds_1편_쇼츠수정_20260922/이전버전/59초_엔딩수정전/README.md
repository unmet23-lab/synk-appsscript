# yuhobuilds 1편 — 쇼츠 리듬 수정본

2026-09-22. 사용자는 앞선 3분 영상의 줄거리는 나쁘지 않지만 말이 느리고 목소리와 음악이 지루하다고 평가했다. 과장된 코믹 보이스 대신 매력적인 성인 남성 애니메이션 성우의 음색을 원했다. 세우·주원과 아폴로·정의로·이겸 샘플을 비교했으나 모두 최종 선호는 아니며, **정의로를 임시로 사용하고 추후 유호 육성을 준비**하기로 했다.

## 이번 수정

- 1,330자에서 559자, 3분에서 **58.667초**로 압축했다. 15장면, 37자막. 6월의 상황과 번역용 결제, 학생 문의 증가, 출석 앱의 필요, 초보자의 스크린샷 반복, 첫 질문과 다음 편 예고를 유지한다.
- 정의로 목소리를 새로 합성했다. 구간별 속도 1.20~1.28과 제한된 감정 프리셋을 사용한다. 사용자 선택은 임시 사용이며 음색 최종 승인이 아니다.
- 보유 BGM `docs/홍보물/BGM/시티팝_147.wav`의 25초부터 한 구간을 연속 사용한다. 반복 없이 편집하고, 말할 때 음악을 낮추는 압축을 적용한다. 농담 구간에서는 음악을 크게 내려 대사의 간격을 만든다.
- 장면당 약 2.6~5초. 빠른 카드 등장·스케치 인물의 표정·반복 장면 변화·짧은 강조 자막으로 전개를 바꾼다. 인물과 작업 화면은 설명용 재구성이며 실제 모습이나 당시 앱 캡처가 아니다.

## 육성으로 바꿀 때

`육성녹음용_대본.txt`를 사용한다. 음성 원본 `audio/narration-01.wav`~`15.wav`, 음악 없는 연결본 `audio/narration-only.wav`, 음악 `audio/music-bed.wav`, 최종 믹스 `audio/narration-master.wav`를 분리했다. 새 육성의 실제 발화 시간에 맞춰 자막·장면을 다시 정렬하고 믹스·렌더한다. 기존 영상에 길이가 다른 음성 파일만 덮어쓰지 않는다.

## 다시 만들기

`synthesize.cjs`는 기존 로컬 Typecast 연결이 있을 때만 새 합성을 하며 같은 요청의 파일은 재사용한다. 사용자의 새 음성이 준비되면 API 합성 단계는 건너뛴다. 키는 산출물에 저장하지 않는다.

```powershell
node "docs/마케팅/yuhobuilds_1편_쇼츠수정_20260922/prepare-audio.cjs"
node "docs/마케팅/yuhobuilds_1편_쇼츠수정_20260922/render.cjs"
node "docs/마케팅/yuhobuilds_1편_쇼츠수정_20260922/finalize-docs.cjs"
node "docs/마케팅/yuhobuilds_1편_쇼츠수정_20260922/finish-preview.cjs"
node "docs/마케팅/yuhobuilds_1편_쇼츠수정_20260922/serve-preview.cjs"
```

[공식 Typecast 감정·속도 설정](https://github.com/neosapience/pipecat-typecast)의 필드를 참고했으며 이번 합성의 실제 요청은 각 WAV와 짝인 JSON에 보존한다. 이 페이지의 작업 명령은 외부 게시를 수행하지 않는다.
