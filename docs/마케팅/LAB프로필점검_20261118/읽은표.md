# LAB 39계정 프로필 전수 읽기 · 2026-11-18 아침

유호님 11-18 「각 계정마다 소개글이나 커버사진이나 이런거 한번씩 체크해서 보완할곳있으면 보완한번해야할것같아 … 말투 자연스러운지 각 국가마다 다 전수조사해서」의 LAB 몫이다. 고친 것과 전후 표는 [README](README.md)에 있다.

## 읽은 길

- **유튜브 19곳:** `lab-youtube` 자격으로 Data API `channels?part=snippet,brandingSettings`와 `channelSections`를 읽었다(읽기만). 배너와 프로필 사진은 받은 그림을 한 장에 모아 눈으로 봤다.
- **틱톡 7곳:** 로그인하지 않은 앱 안 브라우저에서 프로필 쪽의 `__UNIVERSAL_DATA_FOR_REHYDRATION__`을 읽었다. curl은 1.4KB 방화벽 화면만 받았다.
- **페이스북 4곳 · 인스타 3곳:** 로그인하지 않은 앱 안 브라우저로 공개 쪽의 글과 `og:` 칸을 읽었다.
- **텔레그램 2곳 · 러튜브:** 공개 쪽 `t.me/<채널>`과 공개 API `rutube.ru/api/profile/user/<id>/`를 읽었다.
- **샤오훙수 · 더우인:** 로그인 없는 쪽이 없어 ego `Profile 5`(Person 1)에서 읽었다.
- **VK:** 로그인 없는 앱 안 브라우저와 로그인된 ego `Profile 5` 모두 「Проверяем, что вы не робот」(로봇 확인)에 막혔다. 로봇 확인은 누르지 않았다. 그래서 11-09 원장 값만 적는다.

## 함께 본 것

- **글자 수:** 유튜브 설명은 168~872자로 한도 5,000자 안이다. 틱톡 소개는 가장 긴 카자흐가 78자로 한도 80자에 거의 닿는다. 그래서 틱톡 글 속 링크는 synk.im/en/lab/(3자 더 김)로 바꾸지 않았다. 틱톡과 인스타의 글 속 주소는 눌리지 않는다.
- **AI 도구 이름 · 내부 번호:** 39곳 어디에도 없다.
- **상대 날짜:** 「오늘」 꼴은 네팔 · 스리랑카 페이스북의 「배운 말을 오늘 바로(आजै · අදම) 말해 보자」뿐이다. 날이 지나도 틀린 말이 되지 않는 권유라 상대 날짜 흠으로 보지 않았다.
- **배너 · 커버:** 유튜브 19장(2560×1440)과 페이스북 4장(1640×596)은 모두 10-19 판이다. 글은 안전 영역 안에 있고 잘리지 않았으며, 제목은 그 나라 말이다.
- **프로필 사진:** 플랫폼마다 다르다. 유튜브 19곳 · 텔레그램 · 페이스북 나라 셋은 몽글(10-02 「LAB 프로필은 몽글」), 11-08 이후 연 계정(틱톡 넷 · 인스타 둘 · 더우인 · VK)은 유호님이 고르신 LAB 로고, 틱톡 미얀마 · 베트남과 러튜브는 까몽이다. 틀린 사진은 틱톡 @synk.mn(사람 사진)과 샤오훙수(기본 그림) 둘이다.
- **같은 언어 묶음:** 영어 유튜브 미국 · 호주 · 뉴질랜드 셋은 설명과 키워드가 글자 하나 다르지 않았다. 스페인어 둘(멕시코 tú · 파라과이 vos)은 서로 달랐다.
- **올라가는 영상과 설명:** 나라별 유튜브 18곳은 설명 첫 줄이 「3초 퀴즈」인데, 퀴즈 줄은 11-10 밤에 멈췄고 11-12부터는 13:00 이야기 편(미안 등급, 물고기 = 물 고기, 4층 없는 엘리베이터, 화날 때 네 마디, 「먹지 마」 이야기)이 올라간다. 퀴즈는 10-18 한 편뿐이다.
