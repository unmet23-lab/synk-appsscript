## 인스타 릴스(@yuhobuilds)

**캡션**

```
GitHub 무료 2,000분이 바닥나자, 자동 검사가 2초 만에 꺼졌어요. 빨간불인데 실패한 단계는 0개.

AI로 코드를 쓰고 GitHub에 올린다면, 올릴 때마다 도는 자동 검사(Actions)가 있을 거예요. 비공개 저장소는 Free 계정 기준 한 달 2,000분이 무료고, 결제 수단이 없으면 다 쓴 순간 검사가 시작도 못 하고 끝나요.

제 경우
· 10월 20일 19:20부터 하루 넘게, 18번이 「단계 0개 · 1~3초」로 끝남
· 메시지: "recent account payments have failed or your spending limit needs to be increased" — 결제 수단도 없었으니 뒤쪽(무료 분 소진)이 맞았어요
· 그사이 올린 코드를 다시 돌려 보니 빨간 시험 16개(그중 3개는 PC 설정 탓)

빨간불 읽는 법: 단계에서 실패했으면 코드부터, 단계 0개 · 몇 초 만에 끝났으면 한도부터.

공짜로 다시 돌리는 길 둘
1. 감출 게 없는 저장소라면 공개로 — 공개 저장소의 표준 실행기는 무료(공개 전에 비밀값·개인정보부터 확인)
2. 비공개로 둬야 하면 내 PC를 자체 실행기로 — 예산 $0에도 잡을 받아 돌았어요(10월 22일 GitHub 문서 기준 무료). 공개 저장소에는 붙이지 마세요.

남은 시간은 GitHub에 로그인한 뒤 설정의 빌링 화면(주소 끝이 settings/billing)에서 봐요. 조직 계정은 조직 설정의 Billing & Licensing. 매달 1일 다시 2,000분.

빨간불이 코드 탓인지 무료 분 탓인지, 코딩 AI가 실행 기록을 보고 갈라 주는 프롬프트도 만들어 뒀어요. 전체 프롬프트는 synk.im/prompts

여러분 Actions 무료 분, 지금 몇 분 남았어요? AI로 코딩하는 친구에게도 보내 주세요.

#GitHub #바이브코딩 #AI코딩 #개발자 #1인창업
```
