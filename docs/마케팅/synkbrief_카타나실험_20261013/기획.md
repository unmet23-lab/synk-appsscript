# synkbrief · 「카타나 써 봤습니다」 (10-13, 게시 전)

트리거: **새 도구.** 유호님이 보낸 인스타 글(힉스필드 카타나를 클로드에서 쓰는 방법) → 10-13 「이 방법을 활용해서 추가로 한 편 더」 → 「카타나로 480p로 synkbrief 하나랑 몽글 아우라 파밍 에딧 각각」(편당 150크레딧 상한).

- 누구: AI로 일하는 직장인·1인 사업자(synkbrief 시청자). 볼 이유: 새 도구를 직접 써 본 결과와 비용·시간·한계를 숫자로.
- 행동 하나: 따로 없음(도구 후기). 끝은 synkbrief 서명.

## 진짜 한 컷

- 클로드(힉스필드 커넥터)에서 `/katana` + 몽글 사진 5장 + 「제품 광고처럼」 → `카타나_원본/synkbrief_motion_final.mp4`(480×854, 10.5초). 레퍼런스는 카타나가 직접 찾은 제품 광고 쇼츠(바블스·디올).
- 비용 **42.12크레딧**(영상 생성 한 번 5장면 + 장소 그림 한 장, 거래 내역과 대조), 시간 **38분**(레퍼런스 찾기·분석 25분, 생성 4분, 합성 4분).
- 솔직 평가: 털·바느질 접사는 사진처럼 나왔다. 표정이 바뀌는 2.7초는 생성이 아니라 입력 사진을 합성한 것이라 영상에서 그렇게 밝힌다.
- 효과음은 카타나가 쓴 CC0 소리(`카타나_원본/sfx_licenses.txt`).

## 영상

`kit-v1/index.html`(숏폼디자인 조사 10-13 안 1 「흰 무대 · 실제 화면이 주인공」), 소리 `소리.mjs`. 34.6초: 결과 먼저(사진 5장 → 광고 영상) → 세 단계 → 실제 결과 10.5초 그대로 → 42크레딧·38분 → 증거 두 장 → 「나한테 해당되나?」(클로드 연결용 3일 무료 체험, 카드 등록·해지 안 하면 자동 결제, 480p는 미리 보기용·1080p는 비용 4배) → synkbrief 서명.

- 렌더: `kit-v1/renders/synkbrief_카타나써봤습니다_v2.mp4`(v1은 비교용).
- v2에서 고친 것: 「어제 나온 클로드 카타나」 → 「클로드에서 쓰는 힉스필드 카타나」(공개일을 확인하지 못해 날짜 표현을 뺐다), 「힉스필드 새 가입은 3일 무료 체험」 → 「클로드 연결용 3일 무료 체험이 있어요」(체험은 MCP 전용 크레딧·카드 필요·해지하지 않으면 자동 결제 — 힉스필드 커넥터 안내문 기준), 음량 −14.7 LUFS.
- 1080p가 4배인 근거: Seedance 2.5 초당 3크레딧(480p) · 12크레딧(1080p).

## v3 (10-13) · 몽글 아우라 에딧 + 「이렇게 말하면 → 이렇게 만들어 줘요」 + 맞춤 도구

유호님 10-13 「카타나 써봤습니다 >> 니가 직접 검수해서 전달할 프롬프트나 개인화 프로그램 지금 준비해줘 이거 준비해서 올리자」 → 검수용 새 생성은 「돌리지 말고 요청문만」 → 「몽글 아우라 에딧을 아까 카타나 구성에 넣어줘. 카타나로 이렇게 말하면 이렇게 만들어줘요. 이런식으로 텍스트랑 몽글 아우라에딧 추가」.

- 영상: `kit-v3/index.html`, 소리 `소리_v3.mjs`, 렌더 `kit-v3/renders/synkbrief_카타나써봤습니다_v3b.mp4`(57초, Fable 검수 반영: 요청 카드 7.6초씩 · 제품 광고 결과는 사진 합성 구간을 포함한 앞 8.4초 · 아우라 결과 앞에 「번쩍이는 장면이 있어요」 · 결과 소리 −3dB · 「조건이 되면 3일 무료 체험」 · 「편집 기능」; v3 56초는 비교용). 결과 먼저(사진 5장 → 영상 두 편) → 세 단계 → **이렇게 말하면**(제품 광고 요청 카드) → **이렇게 만들어 줘요**(실제 결과 10.5초, 사진 합성 2.7초 구간에 표시) → 이렇게 말하면(아우라 요청 카드) → 이렇게 만들어 줘요(실제 결과 13.7초) → 42·84크레딧 → 나한테 해당되나? → 「내 영상에 맞춘 요청문 synk.im/brief/katana」 → 서명.
- **바로잡은 것:** v1·v2의 3단계 「몽글 사진 5장 + 「제품 광고처럼」 한 줄」은 실제와 달랐다. 실제로는 몇 줄짜리 요청(느낌·비율·길이·480p·상한 150·모양 잠금·회전 없이·남의 노래 없이·글자 없이)을 보냈다. v3는 「사진 5장 + 요청문」으로 고치고, 화면의 요청 카드에 그 요청을 줄여 그대로 보인다(맞춤 도구의 `examples`와 같은 글).
- 사진 합성 구간: 결과 영상 4.83~7.50초(장면 전환 검출), v3에서 19.23~21.90초에 「이 2.7초는 사진 합성이에요」.
- **맞춤 도구** `docs/마케팅/맞춤도구/katana/`(→ `synk.im/brief/katana/`, 10-13 공개 synk-policy `942c6d88`): 질문 6개(주인공·영상 종류·재료·올릴 곳·화질·지킬 것) → `/katana` 뒤에 붙여 넣을 요청문(상한·화질·잠금·음악·보고 줄), 어림 크레딧, 순서, 팁, 확인표, 영상 속 실제 요청 두 개. 검수는 새 생성 없이 공식 지침·도움말과 실제 두 결과로 했다(탐색노트). 시험 11개 통과, 휴대폰 375px 넘침 없음.
- 게시 문구: `docs/마케팅/맞춤도구/katana/게시연결.md`.

## v4 (10-13) · 나레이션·배경음·템포

유호님 10-13(v3b를 보고) 「영상 템포가 너~무 느리고 오디오도 없네. tts는 타입캐스트로 넣어주고 배경음도 깔아줘. 그리고 (제품 광고 결과 첫 장면) 나올 때 소리가 엄청 튀어. 이거 약간 조정해줘」.

- 영상 `kit-v4/index.html` → `kit-v4/renders/synkbrief_카타나써봤습니다_v4.mp4`(43.6초, 57초에서 줄임). 나레이션이 장면을 끌고 간다: 요청 카드 약 2.2초씩(글은 그대로, 굵은 곳만 훑게), 제품 광고 결과 0~8.6초, 아우라 결과 4.5~13.65초, 「써 보니 알게 된 것」은 큰 글자 세 박자, 끝은 요청문 주소·체험 조건·서명.
- 나레이션: Typecast 범수(새 나레이션 기본, 결정 표 10-10) 10줄 324자 → **324크레딧**(남은 양 127,154/200,000). `나레이션_v4.mjs`, 소리 파일과 글자 시각 `kit-v4/assets/media/vo/`. 받아쓰기로 발음 확인(「사팔공 피」가 480p로 들림).
- 배경음: Suno 시티팝_147(25초부터, 90Hz·7.5kHz 거름), 나레이션이 나오면 배경음·결과 소리를 함께 낮춘다(사이드체인).
- 튀던 소리: 제품 광고 결과 안의 장면마다 들어간 바람 소리(−22dB, 피크 −11)와 표정이 바뀔 때의 딩 소리(피크 −6)가 v3b에서 조용한 카드 장면(−41 LUFS) 바로 뒤에 나와 27 LU 차이로 튀었다. v4는 결과 소리를 압축(−30dB부터 4:1)·낮춤 + 나레이션·배경음이 깔려 장면 사이 차이가 사라졌다(전체 −14.9 LUFS, LRA 6.2 LU, 0.5초 단위 −10~−21dB).
- 게시 묶음 `게시_v4/`(v3b 묶음은 비교용).
