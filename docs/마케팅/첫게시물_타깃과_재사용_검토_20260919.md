# 첫 게시물의 타깃과 재사용 검토

> 2026-09-19 후속: 사용자가 기존 제작 원고를 교체하고 새로 쓰기로 했다. [현재 원고 12종](첫콘텐츠_재작성_20260919/README.md)은 새 편집 초안이며 외부 미게시다. 이전 원고·카드·영상은 제작 중단 확인 후 복구용으로 보관했다. 아래는 첫 발행의 대상·재사용 관계를 정한 기획 기록이며 예시 문구가 현행 게시 원고는 아니다. 대부분의 학습·정보·제작 콘텐츠는 본문에서 쓸 만한 내용과 예시를 제공하고, 내용에 맞는 연습·적용·경험 공유로 마무리한다. 모든 글에 같은 참여 질문을 의무적으로 붙이거나 회사 소개·포트폴리오에 억지 과제를 넣는 규칙은 아니다.

2026-09-19 · 회사·사람 중심 브랜딩 방향과 아래 첫 발행 구성을 사용자와 확인했다. 출연 A·B 2종은 7계정에, 출연 없는 12종은 15계정에 재사용·배치한다. 오늘 사용자가 곧 시작할 제작 범위는 출연 없는 12종이며, 구체 소재·원고·화면은 제작하면서 확정한다. 이 기획에 따른 게시 원고·영상 제작 및 외부 발행은 아직 하지 않았다.

사용자 기준: 역할은 중복 게시를 막으려고 나눈 것이 아니다. 누구에게 무엇을 줄지를 정하고, 같은 게시물이 그 역할에 맞으면 재사용한다. 역할에 맞지 않으면 필요한 내용을 따로 제작한다. 제작 개수를 먼저 정해 놓고 채널을 끼워 맞추지 않는다.

## 적용할 브랜딩 방향

- 기존 LAB / SHIFT / SYNK·공통의 독자와 효용 구분을 유지하고, 회사 중심 브랜딩과 사람 중심 브랜딩을 함께 더한다.
- 회사 중심 콘텐츠는 제공 가치와 철학을 실제 수업·작품·완성 결과·판단으로 보여준다. 사람 중심 콘텐츠는 유호의 경험과 선택, 직접 설명하는 모습으로 유호를 알고 계속 볼 이유를 만든다.
- LAB에서 유호가 학습을 돕는 영상은 교육 효용과 회사·인물 브랜딩을 함께 맡는다. yuhobuilds는 SYNK를 만드는 유호의 채널이며 SHIFT의 한 출연자로만 한정하지 않는다.
- 기존 계정을 메인·서브 등급으로 고정하거나 계정을 새로 만들지 않는다. 얼굴을 보여야만 인물 브랜딩이 되는 것도 아니다. 유호가 쓴 제작기·첫 편지 역시 사람 중심 콘텐츠가 될 수 있다.
- 첫 LAB 영상에는 유호의 직접 안내를, 유호 첫 영상에는 SYNK를 만드는 개인적인 이유와 실제 작업을, 회사 첫 소개에는 고객에게 줄 가치와 근거를 넣는 방향으로 보완한다.

## 현재 역할의 보완점

사업 구분은 LAB / SHIFT / SYNK·공통의 세 묶음을 유지할 수 있다. 다만 사업명·플랫폼 이름만으로는 콘텐츠를 결정할 수 없다. 아래의 대상은 현재 팔로워 분석 결과가 아니라, 정본의 사업 대상과 공개 소개를 바탕으로 제안하는 우선 독자다.

- **LAB**: 짧은 한국어를 배울 학습자, 수업을 검토하는 성인·보호자, 자료를 계속 받고 싶은 사람을 구분한다. Facebook에도 학습 영상을 재사용할 수 있지만, 첫 편에서 수업 선택을 돕기로 한다면 수업 방식과 실제 학습 예시를 더한다. 수업·교재·앱의 공개 가능 범위는 실제 준비 상태로 설명한다.
- **유호 / synkbrief**: 실제 제작 경험을 따라 보는 사람과 자기 업무의 문제를 해결하려는 사람을 구분한다. synkbrief는 최신 AI 소식의 실무 영향·GitHub 공개 스킬과 도구 추천·활용법을 맡는다. 유호 채널은 직접 SYNK에 적용한 경험과 판단을 중심으로 한다. 두 계정에 같은 완성본이 모두 어울리면 함께 써도 되며, synkbrief의 모든 주제가 유호 작업에서 파생될 필요는 없다.
- **LinkedIn 개인**: 단순 제작 일기보다 담당한 일·판단·완성 결과를 통해 협업 상대가 역량을 이해하도록 보완한다. 유호가 SYNK 전체를 만드는 사람이라는 범위도 열어 둔다.
- **네이버 블로그 / Tistory**: 두 블로그를 모두 보유하는 현재 구성에서는 네이버의 첫 글은 따라 할 방법, Tistory의 첫 글은 제작 선택과 수정 이유로 제안한다. 플랫폼이 요구하는 고정 역할이 아니며, 독자의 목적이 같으면 같은 글을 재사용할 수 있다.
- **Behance / Pinterest**: 핸들은 yuhobuilds·synkshift여도 운영상 둘 다 SHIFT 디자인 작업을 보여주는 자리로 묶는 편이 명확하다. Behance는 프로젝트의 전체 구성·완성도, Pinterest는 대표 디자인의 발견·저장과 상세 프로젝트 방문을 맡긴다.
- **카카오톡 / 유호 Telegram**: 문의할 사람이 준비 중인 제공 범위와 연락 방법을 이해하도록 한다. 카카오톡 공개 소식과 개인 Telegram 연락 프로필은 발행 방식이 다르다.
- **회사 LinkedIn / Substack**: 회사와 협업할 이유와 뉴스레터를 계속 받아볼 이유를 각각 설명한다. 공통 회사 소개 자료를 재사용하되 첫 글의 결론과 다음 행동은 다르게 쓴다. Substack은 LAB·SHIFT 내용을 구분하고 LAB 대상에게 필요한 몽골어 안내를 포함한다.
- **PATH / PULSE**: 독립 계정을 추가하지 않는다. LAB의 한국어·한국 생활 학습과 PATH의 유학·취업 지원 준비를 혼동하지 않는다. PULSE 라디오는 LAB YouTube 공유 계정의 감상 콘텐츠이며 LAB 첫 학습 게시물을 대체하지 않는다.

이 역할은 계정마다 한 종류의 콘텐츠만 올린다는 제한이 아니다. 한 게시물의 주된 독자·얻을 내용·다음 행동을 판단하기 위한 구분이다.

## 이번 첫 발행 제안 — 역할별 완성본 14종, 게시 대상 22곳

세로영상은 L1·S1·S4 **3편**, 글·이미지·프로젝트 중심 발행본은 나머지 **11종**이다. 주요 제작 자료는 LAB·SHIFT·SYNK 세 묶음에서 공유한다. 총 게시 대상은 **3+1+1+4+2+1+3+1+1+1+1+1+1+1 = 22곳**이다.

이 수치는 위에 제안한 첫 편의 목적을 각각 살렸을 때의 작업량이다. 플랫폼의 기술적 최소 요구나 모든 회차의 고정 제작 개수가 아니다. 예를 들어 Facebook에도 L1과 같은 학습 목적의 글을 올리기로 하면 해당 완성본은 합칠 수 있다. 반대로 YouTube에 긴 본편을 추가하거나 언어별 파일을 따로 만들면 편집본은 늘어난다. 이번 계산의 YouTube 영상은 Shorts 시작안이며 긴 본편을 포함하지 않는다.

## 화면 출연이 없는 첫 게시물 구성

여기서 출연은 새 게시물의 본문·이미지·영상 안에 유호의 얼굴이나 몸이 등장하는 것을 말한다. 기존 프로필 사진·작성자 이름, 유호의 목소리 사용 여부는 별도다. 아래는 이번 첫 게시물의 배치이며 채널에 대한 영구적인 출연 금지가 아니다.

| 발행본 | 게시 대상 | 화면 출연 없이 만드는 구성 |
|---|---|---|
| L2 | LAB Facebook `synkworld` — 1곳 | 교육 방식·과정 안내 글과 얼굴 없는 학습 장면·교재 카드. L1의 유호 얼굴 프레임을 그대로 가져오지 않고 해당 자료 부분을 사용 |
| L3 | LAB Telegram `@synkmn` — 1곳 | 환영·자료 사용 안내와 얼굴 없는 학습 카드. L1 출연 영상을 첨부하면 해당 게시물에도 출연이 포함되므로 이 구성에서는 카드 선택 |
| S2 | 유호 Threads·X 각각 `@yuhobuilds` — 2곳 | 유호가 쓴 작업 기록 + 작품·화면의 전후 비교. 얼굴 없이도 사람의 경험과 판단을 전달 |

| S4 | YouTube·Instagram·TikTok 각각 `@synkbrief` — 3곳 | 화면 녹화·실제 예시·자막 중심 방법 영상. 설명 음성은 사용할 수 있으나 유호 얼굴 촬영은 필요하지 않음 |
| S5 | 네이버 블로그 `synkshift` — 1곳 | 방법 설명 글·단계별 화면·완성 예시 |

| S7 | Behance `yuhobuilds` — 1곳 | 디자인 전체·디테일·적용 장면 중심 프로젝트 |

| S9 | 카카오톡 채널 `SYNK SHIFT` · 검색 ID `synkshift` — 1곳 | 준비 중인 제공 범위·문의 방법·서비스 설명 이미지 |

화면 출연 없이 제작 가능한 첫 발행본은 **12종 / 15개 게시 지면**이다. 사람의 존재까지 제거하는 뜻은 아니며 Threads·X·개인 LinkedIn·Tistory·Substack에는 유호의 관점과 경험이 담긴다.

직접 출연을 권장하는 첫 영상은 **L1 LAB 학습 영상 1편(3곳) + S1 유호 제작 영상 1편(4곳) = 2편 / 7개 게시 지면**이다. 두 편도 출연이 기술적으로 필수인 것은 아니다. 브랜딩 방향을 반영한 이번 첫 편의 제안이며, 이후에는 같은 채널에 얼굴 없는 학습·작업 영상도 섞을 수 있다.

따라서 전체는 **출연 권장 2종·7곳 + 얼굴 없이 제작 가능한 12종·15곳 = 14종·22곳**이다. PULSE 라디오의 음악·마스코트 감상 콘텐츠도 유호 출연 없이 운영할 수 있지만 기존 공유 채널의 별도 콘텐츠이므로 이 첫 발행 수에 추가하지 않는다.

## 출연 계정 7개와 촬영 압축안

2026-09-19 후속 사용자 결정: L1·S1 출연 영상은 다른 세션에서 제작한다. [인계용 촬영 원고 2편](첫콘텐츠_재작성_20260919/출연영상_다른세션_인계/README.md)을 별도로 작성했으며, 현재 세션은 얼굴 없는 12종의 검수·제작을 맡는다. 촬영·음성 생성·영상 편집·업로드는 아직 실행하지 않았다.

사용자 요청: 첫 게시물에는 직접 출연할 수 있으나 촬영 부담을 줄인다. 비슷한 목적의 게시물에는 같은 촬영본을 재사용하고, 브랜딩에 필요한 서로 다른 내용은 살린다. 아래는 그 요청을 적용한 촬영 제안이다.

| 플랫폼 | 출연하는 계정 | 사용할 첫 영상 |
|---|---|---|
| YouTube | LAB `@synkkorean` | L1 — 한국어 학습 안내 |
| Instagram | LAB `@synk.mn` | L1 재사용 |
| TikTok | LAB `@synk.mn` | L1 재사용 |
| YouTube | 유호 `@yuhobuilds` | S1 — SYNK를 만드는 유호의 이야기 |
| Instagram | 유호 `@yuhobuilds` | S1 재사용 |
| TikTok | 유호 `@yuhobuilds` | S1 재사용 |
| 네이버 클립 | 유호 `@yuhobuilds` | S1 재사용 |

**한 자리·한 세팅의 촬영 일정 1회에 원고 2묶음을 이어서 찍고, 출연 영상 2편을 7계정에 재사용한다.** 한 번에 모든 대사를 실수 없이 말해야 한다는 뜻은 아니다. 문장별로 끊어 촬영하고 필요한 부분만 다시 찍을 수 있다. 의상·배경·구도를 계정마다 바꾸거나 플랫폼별 인사·엔딩을 따로 촬영할 필요는 없다.

| 촬영 묶음 | 유호가 직접 보여줄 부분 | 추가 인물 촬영 없이 채울 부분 | 따로 살릴 이유 |
|---|---|---|---|
| A · LAB / L1 | 짧은 안내와 한국어 표현 시범. 예: 잘 못 들었을 때 다시 말해 달라고 부탁하는 표현을 직접 말해 주기 | 상황을 설명하는 몽골어 자막·학습 카드·학습자가 직접 말해 볼 시간. 몽골어 안내 때문에 유호의 별도 몽골어 출연본을 요구하지 않음 | 학습자가 누구에게 어떻게 배우는지 느낄 수 있도록 직접 도움을 주는 모습을 보여줌 |
| B · 유호 / S1 | SYNK를 만드는 개인적인 이유와 실제 작업에서 내린 판단 하나 | 승인된 작업 결과·전후 비교·제작 화면. 작업하는 척하는 장면이나 별도 장소 촬영을 추가하지 않음 | 유호가 왜 이 회사를 만들고 어떤 기준으로 결정하는 사람인지 알게 함 |

두 묶음은 같은 날 같은 자리에서 찍되 주된 이야기를 각각 준비한다. LAB 독자는 한국어를 배울 이유를, 유호 채널 독자는 제작자의 선택과 작업을 계속 볼 이유를 찾으므로 각 목적에 맞는 짧은 출연 부분을 남기는 편이 좋다. 공통 자기소개만 반복하는 구성보다 이 두 부분의 브랜딩 가치가 크다는 판단이다. 영상 내내 얼굴이 나올 필요는 없다.

촬영 전에 실제로 공개할 학습 예시 1개와 완성 작업 1개를 고른다. 그 자료를 기준으로 A·B의 말할 부분만 준비하고, 촬영 때 얻은 음성도 설명에 재사용한다. 채널명·저장·구독 등 플랫폼별 안내는 자막·마지막 카드·게시글에서 처리한다.

S4 `synkbrief`는 화면 녹화·자막으로 설명해 **유호의 추가 출연 촬영을 배정하지 않는다**. B와 같은 실제 사례를 다루면 자료를 재사용하고, 별도 GitHub 스킬·도구나 AI 소식을 다루면 해당 공식 자료·시연 화면을 준비한다. 기존 촬영 음성이 설명에도 맞으면 활용하고, 부족한 설명은 화면·자막으로 보완한다. 음성 설명을 추가하기로 하면 녹음 작업으로 따로 계산한다. L2·L3·C2도 얼굴 없는 학습 카드를 선택하며, 다른 글·프로젝트에는 작업 결과와 기록을 재사용한다.

이 계획에서 유호가 준비할 출연 원고는 **2묶음**, 함께 촬영할 일정은 **1회**다. 완성 세로영상은 얼굴이 나오는 L1·S1과 화면 중심 S4를 합쳐 **3편**이며, 글·이미지 등을 포함한 역할별 발행본 **14종 / 공개 게시 22곳**은 그대로다. 촬영 일정·원고 묶음·실제 테이크·완성 편집본·업로드 수를 같은 수치로 세지 않는다. 이후 모든 게시물에 출연해야 한다는 운영 규칙도 아니다.

## 나머지 계정 1개

`yuhobuilds-telegram`은 현행 정본과 확인 기록상 유호의 개인 연락 프로필이다. 위 게시물에서 연결할 문의 통로로 운영하므로 공개 채널의 첫 글 수에 넣지 않았다. Telegram 개인 계정에도 Stories 등의 노출 수단은 있지만, 현재 정한 연락 역할을 바꾸거나 새 채널을 만들 필요는 없다. **23개 계정·채널 관리 = 22곳 공개 발행 계획 + 개인 연락 프로필 1개**다.

## 재사용을 판단하는 방법

1. **그대로 재사용**: 같은 독자에게 같은 효용·다음 행동을 주는 경우. LAB 학습 세로영상 3곳, 유호 제작 세로영상 4곳, brief 방법 세로영상 3곳, 짧은 작업 기록 Threads·X가 이번 제안의 해당 묶음이다.
2. **같은 자료로 별도 편집**: 질문과 다음 행동이 다른 경우. LAB 영상에서 과정 안내·학습자료를 만들거나 SHIFT 작업에서 방법 글·포트폴리오를 만드는 경우다. 처음부터 다른 사례를 새로 만들 필요는 없다.
3. **별도 내용 제작**: 기존 자료가 해당 독자에게 필요한 답을 주지 못하는 경우. 실제 학습 자료가 없는데 채널 이용 안내만 늘리거나, 협업 범위가 없는 글에 문의 버튼만 달아 대신하지 않는다. 부족한 자료·설명을 실제로 준비한다.

같은 소재라도 재생 목적·언어·다음 행동에 따라 편집을 달리할 수 있다. 반대로 플랫폼 이름이 다르다는 이유만으로 다른 이야기를 만들지는 않는다. 배포 파일은 원본에서 내보내고 제목·표지·텍스트·링크·음원의 사용 범위를 각 업로드에 맞게 확인한다.

## 제작 순서 제안

- **오늘 먼저 제작할 범위**: L2·L3·S2·S3·S4·S5·S6·S7·S8·S9·C1·C2의 출연 없는 12종이다. S4 영상 1편과 글·카드·프로젝트 11종을 15계정에 배치한다. A·B의 출연 촬영이나 영상 완성을 기다리지 않고, 같은 학습 예시·실제 작업 기록·결과 이미지를 먼저 확보해 제작할 수 있다. 문서에서 L1·S1 원본을 재사용한다는 표기는 그 기초 자료도 포함한다. 제작 완료·게시 여부는 실제 진행 후 기록한다.
- LAB는 L1의 학습 예시와 실제 사용할 자료를 먼저 정리하고 L2·L3 안내를 만든다.
- SHIFT는 공통 사례의 원본·전후 이미지·제작 기록을 먼저 확보해 출연 없는 발행본부터 만들 수 있다. S1의 촬영·영상 완성은 선행 조건이 아니다. S4에도 맞으면 공유하고, 별도 스킬 추천·뉴스를 선택하면 그 주제의 원문과 실제 시연 자료를 따로 준비한다. 다른 원고와 이미지는 각 역할에 맞는 자료에서 필요한 내용을 뽑는다.
- Behance나 블로그의 상세 결과를 준비한 다음 Pinterest에서 연결한다. 없는 상세 페이지를 약속하지 않는다.
- 회사 소개·Substack은 앞에서 준비한 학습 예시와 작업 결과를 실제 샘플로 가져온다.
- 완성된 발행본마다 해당 역할의 다음 행동이 가능한지 확인한다. 소재·원고 준비는 계정의 로그인·실제 발행 성공과 별도다.
