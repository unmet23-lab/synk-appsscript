  - 맞춤법(spellcheck.mn) 의심 7건 — 고치지 않는다: кы · ын · гамса · окей · гамсахамнида는 한국어 소리를 몽골 글자로 적은 읽는 법(사전 밖이 맞음). чатлахдаа(«чатлах» 채팅하다)는 들어온 말이라 사전에 없을 뿐이고, 사전이 낸 대안(атлах · шатлах …)은 철자 고침이 아닌 다른 낱말이다 — Fable 세 번 · 역번역 세 번이 모두 10~20대가 쓰는 자연스러운 말로 봤다. Хаха는 웃음 소리 감탄사.
  - 판정: **통과** — 세 겹 검수 끝(10-24 12:2x).
- **② 원문을 안 본 새 하위 에이전트(Opus) 직역 역번역 — 세 번.** 1차: 규칙 줄 「Үе бүрийн эхний үсэг」이 「세대마다」로도 읽힘 · ㅇㅋ(오케이)와 규칙이 안 맞음 · 「За юу?」가 「그래, 뭐?」로 먼저 읽힘 · 「мэдэх вэ」보다 「мэддэг вэ」 · 캡션 경고 줄의 공동격(「친구들과 함께 쓴다」로 읽힘) · 「감사합니다」에 읽는 법 없음. 2차(고친 줄): 철자 · 문법 문제 없음, 「юу гэсэн бол?」은 「뭐라고 했을까」(이 편 첫 질문 뜻 그대로라 둠), 경고 둘째 문장의 「бүтнээр нь」 앞에 줄임말이 없어 「ㅇㅋ 대신 감사합니다」로 오독 가능 → 「ㄱㅅ биш」를 넣음. 3차(끝 문제 줄 · 캡션 첫 줄): 문제 없음(끝 문제 줄은 뒤에 뺐다).
- **③ Fable 교정 — 세 번.** 1차: P0 0 · P1 1(ㅇㅋ와 「음절마다 첫 글자」 규칙 불일치 — 한국어 구성) · P2 5(첫 질문 「… бол?」 · ㅇㅇ 「Тийм тийм」 · 「сурч байгаа найздаа явуулаарай」 · 캡션 「найзуудтайгаа л」 · окей 표기 예외) — 「үе + үсэг」이 학습자에게 가장 쉽고 정확하다는 판단(②와 갈린 곳은 ③을 따름), 키릴 읽기 넷(окей · кы кы · ын ын · гамса)은 그대로. 2차: P0 0 · P1 0 · P2 1(캡션 「бичнэ」 → 「бичдэг」 시제 통일, 반영). 3차(끝 문제로 돌린 판): P0 0 · P1 0 · P2 0 — 그 뒤 이해 시험 결과로 끝 문제를 빼고 1 · 2차를 통과한 열린 질문으로 되돌렸다(새 몽골어 줄 없음).

## 이해 시험

`node tools/낯선이시험.js <영상> --말 시험/말_v1.txt --브랜드 lab-mn`(말 없음)의 `질문.md`를 새 하위 에이전트(Sonnet, 몽골 입문 학습자 역할)에 그대로 줬다(재료 `시험/v1` · `v2` · `v3` · `최종`).

- **v1(첫 렌더, 19.5초 · 줄임말 넷)** — 답 1 「채팅에서 ㅇㅋ·ㅋㅋ·ㅇㅇ·ㄱㅅ 같은 자음만 쓴 줄임말은 각각 OK · 하하 · 응응 · 고마워라는 뜻」 · 끝까지 · 4점. ③에 「오 케(이)의 (이)가 왜 흐린지」 · 끝 카드 글자가 작아 댓글에 쓰라는 건지 모름 → **다시**(「이」에 취소선, 끝 글자 키움).
- **v2(다시 1)** — 답 1 같은 뜻 · 끝까지 · **3점 → 다시**. 짚인 것: 규칙 띠가 작아 「어떻게 줄었는지」를 놓침, 첫 2초 질문이 어느 낱말을 묻는지 모름, 「이」 취소선의 뜻, 「감사 위 ㄱ·ㅅ」과 줄임말의 연결. 고침: ㅇㅋ를 풀이에서 빼고 장부 제목대로 ㅋㅋ · ㅇㅇ · ㄱㅅ 셋, 첫 카드 「ㅋㅋ = ?」, 규칙을 위 띠에 크게 남김, 풀이 카드를 「ㅋㅋ = 크 크」 꼴로, 끝을 「ㅇㅋ = ?」 맞히기로(16.2초).
- **v3(다시 2)** — 답 1 「문자에서 ㅋㅋ, ㅇㅇ, ㄱㅅ 같은 자음만 쓴 줄임말은 크크(웃음), 응응, 감사(고마워)를 뜻한다」 = 한 문장과 같음 · 끝까지 · 4점 · ③(끝 문제 ㅇㅋ의 답이 영상에 없음 — 댓글 놀이로 일부러 비움, 내 이모지 말의 뜻, 소리 없이 읽기)은 한 문장에 꼭 필요하지 않음 → **통과**.
- **최종본 확인 1(v7)** — v3 뒤 바꾼 것은 자리뿐(카드 104px 위로, 띠 글 아래로 — 올리기 전 검사의 안전 자리). 올릴 파일로 다시 시험: 답 1 「채팅에서 쓰는 ㅋㅋ·ㅇㅇ·ㄱㅅ 같은 자음 줄임말은 각각 크크(웃음)·응응(맞아)·감사(고마워)를 줄여 쓴 거다」 = 한 문장과 같음, 그러나 끝 「ㅇㅋ = ?」에 답이 없어 「뭘 하라는 건지」 허전하다(v3에 이어 두 번째)며 3점. 끝 맞히기를 1 · 2차 검수를 통과한 열린 질문 «Өөр ямар товчлол мэддэг вэ? / Сэтгэгдэлд бичээрэй 👇»로 되돌리고 글자를 키웠다. ㅇㅋ는 캡션의 덧붙임 줄로만(2차 Fable 「그대로」).
- **최종본 확인 2(v8 → v9)** — 답 1 「문자에서 친구가 ㅋㅋ, ㅇㅇ, ㄱㅅ만 쳐 보내는데, 이게 각각 웃음(크크), 응응, 감사의 줄임말」 = 한 문장과 같음 · 끝까지 · 4점 · 남은 물음(내 이모지 말 ☕?·🎁의 뜻, 끝 작은 줄)은 한 문장에 꼭 필요하지 않음 → **통과**. v9는 끝 카드 알약 글자만 44 → 40px(카드 끝에 붙어 있던 것).
