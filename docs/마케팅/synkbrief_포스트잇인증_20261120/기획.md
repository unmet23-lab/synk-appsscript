# 포스트잇 인증까지 받았는데 — 그 사진이 AI였다

## 무엇으로 이기나

- **한 장면의 임팩트:** 내 닉네임이 적힌 포스트잇 사진이, 판매자 쪽에서는 같은 사진에 포스트잇 글씨만 계속 바뀌며 여러 사람에게 나간다. 「믿었던 증거」가 눈앞에서 찍어 내는 물건으로 바뀌는 한 장면이다.
- 이야기는 짧은 기승전결로 받친다: 인증 사진을 받고 믿고 보냄(기) → 운송장까지 오고 답이 끊김(승) → 판매자 화면에서 닉네임만 바뀌는 같은 사진(전) → 지키는 법 한 줄(결).
- 한 장면: 아래 「한 장면」 절(장면 파일 · 심사 답 · 판정).

- 사진 여덟 장은 Seedream 5.5로 「감자칩92」 판을 참고로 넣고 포스트잇 글씨만 바꿔 구웠다(바뀐 화소 1% 안팎). 「곰돌이빵」 판은 게임기 화면 무늬가 흐려, 같은 자리의 첫 판 화면을 옮겨 붙였다(옛 판 `판/_옛판/N5_화면흐림.png`).
- 첫 컷 판정(`tools/첫컷검사.py` · GPT 눈): v1 「다시」(격자 속 사진이 앞 사진과 다른 구도 · 정지 판 손이 굳음) → 격자를 인증 사진 그대로 다시 구운 판으로 동영상(V3)을 받아 v2 「다시」(4~5.5초 손 자세 그대로) → 손이 마우스에서 떨어지는 V3 6.9초 뒤 구간으로 v3 「확인 완료」(흠만).
- 장면 심사(맥락 없는 Opus · v3 · 휴대폰 크기 0.5초 그림):
  - 답 1 「멈춤 — 같은 상자 · 같은 기계인데 포스트잇 닉네임만 0.5초마다 바뀌어 「물건 하나로 여러 사람에게 인증하나?」 의심이 바로 생긴다」
  - 답 2 「같은 물건 사진에 구매자마다 닉네임 포스트잇만 바꿔 인증 사진을 여러 장 만들었고, 노트북에 그 묶음을 띄워 놓았다」
  - 답 3 「이 사진을 받은 구매자 쪽 — 감자칩92가 인증 사진을 받고 입금하는 순간」
  - 답 4 「노트북 컷이 약하다 — 작은 격자 대신 큰 사진 한 장에서 글자를 바꿔 넣고 딸깍 보내는 순간을 가깝게」 · 볼 이유 3
  - 판정: 답 1 「멈춤」, 답 2가 기획한 일과 같다. 답 3(구매자 쪽)은 본편이 앞뒤로 주는 것(구매자의 송금과 멈칫)이다 — 넘음.
  - 고친 것: 「곰돌이빵」 판의 빈 게임기 화면(심사관이 짚음). 본편 책상 컷은 격자가 화면을 크게 채우는 V3 6.5초 뒤 구간을 쓰고, 손이 떨어지는 그림과 맞지 않는 딸깍은 본편에 넣지 않았다. 노트북 격자 속 사진의 각도가 앞 사진과 조금 다른 것(동영상 모델이 격자를 다시 그림)은 남은 위험에 적는다 — 그 컷을 큰 사진 한 장으로 바꾸면 반전의 「여러 장」이 사라져서다.
