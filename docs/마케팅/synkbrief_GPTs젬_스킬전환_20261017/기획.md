# synkbrief 뉴스 · GPTs·젬, 올해 둘 다 사라집니다

> 2026-10-17 유호님 「Synk brief에 올릴 컨텐츠 하나 지금 같이 준비하자」 → 후보 셋 가운데 「GPTs·젬 둘 다 사라짐」을 고름. 채널은 SHIFT 정보 `@synkbrief`(인스타 릴스·유튜브 쇼츠), 한국어. 제작 기준은 [제작 방식 v2](../콘텐츠_제작방식_v2_20261002.md), 표지·자막은 [SNS 키트](../../디자인/SNS키트/README.md), 양식은 [AI 소식·도구 추천](../제작양식/AI_소식_도구추천.md).

## 볼 이유

GPTs나 젬을 만들어 둔 사람은 「사라진다」는 소식만 듣고 「내가 만든 건 날아가나?」를 모른다. 두 회사가 같은 해에 같은 방향(지침 저장 → **스킬**)으로 바꾸지만 **젬은 알아서 옮겨 주고, GPTs는 내가 직접 옮겨야 한다.** 이 차이 하나를 40초 안에 알게 하고, 내 경우의 날짜와 할 일은 맞춤 프로그램으로 넘긴다.

깨달음 하나: 「젬은 가만히 있어도 되는데, GPTs는 12월 11일 전에 내가 눌러야 한다.」

## 형식과 길이

- 시리즈 `synkbrief 뉴스`. 형식 「흔한 오해 깨기」(v2 §2-3) + 맞혀 보기(O/X). 세로 1080×1920, 40~45초.
- 훅 시험: 팔로워 200명 전이라 플랫폼으로 나눈다(인스타 A안, 유튜브 쇼츠 C안). 같은 계정에 같은 영상을 다시 올리지 않는다.

## 맞춤 프로그램 · 「내 GPTs·젬, 언제까지 뭘 하지?」

허브 synkbrief 「나한테 맞는 AI」에 새 도구 `docs/마케팅/맞춤도구/skills/` → `synk.im/brief/skills/`. [제작 절차](../맞춤도구/제작절차.md)대로 탐색노트·추천기준부터, 화면은 싱ㅋ 시그널 + 카타나 2판 요소. AI 호출 없음, 기록은 그 기기에만.

질문 3~5개(답에 따라 보이는 질문이 줄어든다 — 남이 만든 것만 쓰면 셋). 영상 대사는 「1분 만에」로 고쳤다(10-17, 질문 수가 사람마다 달라서):
1. 어디에 있나요? ChatGPT GPTs / 제미나이 젬 / 둘 다
2. 직접 만들었나요? 내가 만듦 / 남이 만든 것만 씀 / 둘 다
3. 어느 계정에서 만들었나요? 개인 / 회사(워크스페이스·Enterprise) / 학교
4. 안에 든 것(여럿 고르기): 지식 파일 · 외부 연결 액션 · 다른 사람과 공유 · 아직 게시 안 한 수정 · 젬에서 동영상·음악·Canvas·Deep Research 사용
5. 몇 개쯤? 1~2 / 3~9 / 10개 넘게

결과:
- **내 날짜 표**(D-몇): 젬 11-17 또는 회사 2027-03·학교 2027-06, GPTs 12-11 또는 연기 승인 회사 2027-02-11(회사는 「알림을 따르세요」 표시).
- **할 일 순서**(내 경우만): 필요한 수정 끝내고 게시 → 자주 쓰는 질문 3개 적기 → 「플러그인으로 마이그레이션」 → 같은 질문으로 비교 → 공유했던 사람에게 새 플러그인 알리기. 젬만이면 「할 일 없음, 원하면 미리 스킬로 다시 만들기」.
- **안 따라오는 것**(고른 것만): 액션 → 다시 연결해야 함(기술 작업일 수 있음), 공유 → 새로 공유, 초안 → 먼저 게시, 젬 도구 → 스킬에서 아직 안 됨.
- **신경 안 써도 되는 것**: 대화 기록은 남음, 남이 만든 GPT는 옮길 필요 없음, 공개 공유는 필요 없음.
- 비교용 질문 세 칸(이 기기에만 저장) + 복사.

- **문법을 바꾼 이유:** 같은 @synkbrief 채널의 「AI 구독 계정판」은 흰 종이 장면에 「보게 하는 힘이 부족」 → 런치 영상 조사로 v5(청금석 무대 하나·떠 있는 실제 화면·위로 밀기 전환 하나)를 만들었고 유호님이 v5b에 「확실히 좋아졌네」([그 편 콘티](../synkbrief_AI구독계정판_20261017/콘티.md#모션-v5-10-17)). 채널을 맞추려고 이 편도 같은 문법으로 짰다. v2 표의 흰 무대·전환 여러 가지(patch·seam·paper·arch·매치컷)는 쓰지 않는다. 부품은 그 편 `cine.tsx`를 가져왔다(`remotion/src/lib/cine.tsx`).
- **나레이션:** 범수 1.12배, 「GPTs」는 지피티에스. 12줄 339자(339크레딧) + 받아쓰기에서 흐린 두 줄을 다시 구움(45크레딧): 「그럼 젬은요?」 → 「그럼, 제미나이 젬은요?」(받아쓰기 「그럼 쟤는요?」였음), 「젬은 네.」 → 「젬은, 네.」(「재문 내」였음). 낱말 시각은 Typecast 응답에서 `remotion/src/vo.ts`로 뽑았다.
- **시간표:** `remotion/src/timeline.ts`가 나레이션 길이로 장면을 잡는다. 다음 줄은 장면 착지 4프레임 전에 시작, 나가는 장면은 말끝 4프레임 전에 떠난다(말 사이 0.3초 남짓). 처음엔 말 사이가 1초라 44초였다. 머무는 곳은 맞혀 보기 생각 막대·실제 안내 정지·결과 화면·끝 화면뿐.
- **장면(인스타 A / 유튜브 C, 앞 두 장면만 다르다):** 01A 실제 띠 둘 + 「사라집니다」 펀치 / 01C 펠트 상자 + ✕ → 02A O·✕ 카드 + 생각 막대 / 02C 펠트 보석 + O?·✕? → 03-1 실제 젬 띠 선택·조명 + 11.17 도장 → 03-2 보석이 스킬 카드로 + O → 04 실제 「내 GPT」 판, 12.11 도장 → 카메라가 단추로 → 커서 클릭 → 05-1 잠긴 펠트 상자 + 헛클릭 → 05-2 실제 「12월 11일부로 종료」 선택 + 0.6초 정지 → 06 남의 상자가 「만든 사람이 옮김」 쪽으로 → 07 「대화만 남아요」 네 줄(대화 O, 셋 ✕ 도장) → 08 질문 칩 셋(회의 메모 정리해 줘 · 영어 메일 다듬어 줘 · 주간 보고 요약해 줘) → 09 맞춤 프로그램 휴대폰 화면 두 번 눌러 결과 → 10 끝(주소 알약 · 댓글 질문).
- **실제 화면:** 「내 GPT」의 「플러그인으로 마이그레이션」 단추는 넓은 창(1463px)에서도 두 줄로 갈린다 — ChatGPT 한국어 화면의 실제 모습이라 그대로 쓴다. 10-17 캡처에 찍힌 마우스 커서는 지웠고(검은 바탕), 실제 안내 캡처는 반만 든 아이콘 34px를 잘랐다.
