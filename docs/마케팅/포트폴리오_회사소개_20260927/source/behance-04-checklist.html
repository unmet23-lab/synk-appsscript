04 / 저장해 두고 내보내기 전에 확인
이제, 내 디자인에 대입해 보세요.
01
잘리지 않나요?
업로드 미리보기를 열고 로고·제목·소품의 끝을 확인합니다. 잘리면 실제 보이는 영역 안으로 옮깁니다.
02
작게 봐도 읽히나요?
휴대폰에서 확대하지 않고 핵심 문장을 읽어 봅니다. 읽기 어렵다면 보조 설명을 본문으로 빼고 제목을 키웁니다.
03
배경에 자연스럽게 놓이나요?
이미지가 놓일 실제 화면에 올려 경계를 확인합니다. 배경색을 맞추거나 용도에 맞는 투명 파일을 준비합니다.
원본 → 실제 표시 크기 → 업로드 화면 순서로 확인하세요.
