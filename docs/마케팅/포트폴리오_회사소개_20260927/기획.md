# 보는 사람이 직접 확인하는 포트폴리오

2026-09-27 · 사용자 요청에 따른 전면 재제작. 검토본이며 외부 미게시.

## 볼 이유

SNS 이미지나 회사 소개를 직접 만드는 사람은 내보낸 파일과 실제 화면의 차이 때문에 다시 작업한다. 이 콘텐츠를 보면 잘림·작은 글자·배경 경계의 원인을 눈으로 확인하고 자기 작업을 점검할 수 있다. 협업을 검토하는 사람은 SYNK의 실제 수정과 판단을 보고 요청할 분야와 준비할 내용을 파악한다.

## 정보와 재미

- 정보: 중앙 크롭 원리, 실제 크기 읽힘, 배경색 경계. 각각 문제 → 원인 → 수정 → 따라 할 행동을 연결한다.
- 재미: 먼저 어느 부분이 사라질지 선택하고, 같은 창에서 수정 전후를 바꿔 예측을 확인한다. 흰 배경 비교 손잡이를 움직여 작은 색 차이가 경계를 만드는 순간을 본다. 마지막 점검을 직접 완료한다.
- 원본 재사용은 증거를 보존하기 위한 것이다. 기존 13장과 문안의 배치·카피·순서는 재사용하지 않는다.
- Behance는 시각 사례, Pinterest는 독립적으로 저장할 팁, LinkedIn 개인은 실제 판단, 회사는 협업자가 확인할 증거와 역할, 카카오톡은 문제별 문의와 작성 예시로 만든다.
- 영상이 아닌 이미지·글·인터랙티브 사례를 제작한다. 자동 재생·음성 없이 독자의 읽는 속도에 맞춘 조작으로 발견을 만든다. 앱 UI의 상태 전환만 사용한다.

## 증거 경계

- 2026-09-19 Behance 배치 수정 원본과 제작기록을 사용한다. 원본 중앙 64% 창은 크롭 원리 설명을 위한 예시이며 플랫폼의 실제 비율·안전영역·화면을 재현한 것이 아니다.
- 흰 배경 수정 전후 파일은 실제 자산. 흰 페이지에 맞춘 수정이며 모든 배경에 대한 보편 정답으로 설명하지 않는다.
- 40px 아래 이동은 당시 원본의 수정값이다. 보편적인 여백 수치로 가르치지 않는다.
- 새 회사 소개는 교육·AI 활용·콘텐츠·유학 및 취업 준비라는 방향과 자체 제작 증거를 구분한다. 고객 성과·정식 출시·효과 수치를 만들지 않는다.
- 이번 포맷은 자체 사례에서 출발했다. 최신 인기 릴스를 조사했거나 그 효과가 검증됐다고 주장하지 않는다.

## 마감 확인

이미지 전체 육안 확인, 모바일 크기 읽힘, 인터랙티브 답 선택·전후 전환·비교 손잡이·키보드·문의 예문·다운로드, 글꼴 실제 사용, 가로 넘침과 콘솔 오류를 확인한다. 이 확인은 사용자 승인이나 실제 독자 반응을 뜻하지 않는다.
