# 실험 요청문 원문(10-25)

하위 에이전트(클로드 sonnet, 새로 하나씩 · 대화 기록 없음)에 준 글 그대로. 앞의 조건 문단은 모든 판에 같고, 「요청:」 뒤만 판마다 다르다. 결과 HTML은 같은 폴더 `기준/` · `기준2/`(꽃집 기준은 찍은 뒤 `기준/`으로 옮김) · `한줄B/` · `한줄C/`, 파일 이름 `<업종>_s_<번째>.html`.

## 조건 문단(모든 판 같음)

```
이건 실험이다. 조건:
- 어떤 파일도 읽지 말고, 검색하지 말고, 스킬·웹 도구도 쓰지 않는다. 이 컴퓨터의 저장소·문서·메모·디자인 규칙은 무시한다.
- 아래 「요청」을 일반 사용자가 처음 부탁했을 때 평소 하듯 그대로 해 준다.
- 결과 HTML 파일 하나를 Write 도구로 `<임시 폴더>/y5/<판>/<업종>_s_<번째>.html` 에 저장한다.
- 끝나면 저장한 경로만 한 줄로 답한다.
```

## 한계

- 클로드 한 모델(sonnet)만, 판마다 한 번씩. 챗GPT · 제미나이 · 채팅 앱(claude.ai)에서는 해 보지 않았다.
- 하위 에이전트는 이 컴퓨터의 작업 환경(저장소 안내문이 붙는 Claude Code) 안에서 돌았다 — 「저장소 규칙은 무시」로 막았지만 완전히 빈 대화와 같다고 보장할 수는 없다. 처음엔 공식 CLI를 저장소 밖 빈 폴더에서 돌리려 했으나(`../실험.mjs`) CLI 계정이 주간 한도였다.
- 화면은 크롬 1280×800 · 390×844(2배) 첫 화면을 찍은 그대로다(`../찍기.mjs`). 한줄B 세무사 ①의 머리글 사람 이름만 흐림으로 가린 사본(`한줄B/세무사_s_1_폰_가림.png`)을 영상에 쓴다. 사람 이름이 그대로 보이는 캡처(한줄B 세무사 ①② · 기준 세무사 ②)와 1280×800 · 전체 캡처는 저장소에 올리지 않고 이 PC `.tmp/y5_실험_큰화면/`에 두었다 — HTML에서 다시 찍을 수 있다.
