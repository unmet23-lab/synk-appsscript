〔유튜브 쇼츠〕

## 무엇이 똑같았나

같은 요청을 대화 기록 없는 새 창에서 한 번씩 줬습니다.

```
동네 빵집 홈페이지 첫 화면을 만들어 줘. HTML 파일 하나로.
```

빵집 · 필라테스 학원 · 1인 세무사 사무실을 두 번씩, 동네 꽃집을 한 번 — 모두 7번입니다. 휴대폰 폭으로 찍어 보니 7번 모두 같은 틀이었어요.

- 큰 제목 두 줄과 설명 한 문단
- 둥근 알약 모양 버튼(대개 둘 — 색을 채운 것 하나, 테두리만 있는 것 하나)
- 그 아래 카드 줄

색만 업종에 맞춰 바뀌었습니다(빵집 주황, 세무사 남색, 필라테스 초록, 꽃집 분홍). 빵집 두 번은 같은 식빵 그림까지 같았고요. 흔히 말하는 「AI 티」의 보라색 그라데이션은 이번 7번에는 한 번도 없었어요 — 색은 고쳐졌어도 틀은 그대로였던 셈입니다.

## 왜 그럴까

AI는 따로 말하지 않으면 학습 자료에서 가장 흔하고 무난한 모양을 고릅니다. Anthropic도 2025년 11월 12일 글에서 같은 이야기를 했어요 — 방향을 주지 않으면 누구에게도 거슬리지 않는 「안전한」 디자인 쪽으로 몰린다고요. 그래서 고칠 곳은 디자인 실력이 아니라 요청입니다. 무엇을 기준으로 삼을지 하나를 정해 주면 돼요.

## 붙인 한 줄

```
먼저 이 가게에 어울리는 실제 물건 하나(간판, 포장지, 메뉴판 같은)를 정하고, 그 물건의 색과 글씨로 화면을 만들어 줘.
```

위의 요청 끝에 이 한 줄만 붙여서, 같은 업종을 같은 횟수(7번)로 다시 시켰습니다.

## 결과

7번 모두 가게마다 다른 화면이 나왔어요. 대부분은 AI가 화면 코드 안에 고른 물건을 스스로 적어 두었는데, 옮기면 이렇습니다.

- 빵집(두 번 다): 크라프트 빵 봉투 — 「갓 나온 빵을 종이봉투에 담아 드려요」와 영수증처럼 생긴 빵 가격 목록
- 꽃집: 꽃다발을 싸는 크라프트 포장지와 초록 도장 — 손글씨 「꽃 한 다발, 종이에 싸서 드려요」와 가격표
- 세무사: 관공서 누런 서류봉투와 빨간 접수 도장 — 「서류는 봉투째 주세요」
- 세무사(둘째): 진녹색 천 표지의 회계 장부
- 필라테스: 티켓 모양 카드(첫째), 리셉션 벽에 거는 수업 시간표 카드(둘째)

이모지 그림은 한 번도 안 나왔고, 버튼 · 제목 자리도 물건에 맞춰 바뀌었습니다.

## 한계와 쓰는 요령

- 한 AI로, 판마다 한 번씩 해 본 결과입니다. 다른 AI에서는 아직 안 해 봤어요.
- 한 줄을 붙여도 종이 · 크라프트 느낌으로 몰리는 편이었어요(7번 중 6번). 다른 느낌을 원하면 물건을 직접 정해 주세요. 예: 「우리 가게 【네온 간판】의 색과 글씨로 화면을 만들어 줘.」
- 화면 속 가게 이름 · 전화 · 가격은 AI가 지어낸 예시라 실제 가게와는 상관없어요. 쓰기 전에 내 정보로 바꿔야 합니다.

처음부터 통째로 쓰려면 이렇게 붙이면 됩니다(【 】만 내 가게로).

```
【동네 빵집】 홈페이지 첫 화면을 만들어 줘. HTML 파일 하나로. 먼저 이 가게에 어울리는 실제 물건 하나(간판, 포장지, 메뉴판 같은)를 정하고, 그 물건의 색과 글씨로 화면을 만들어 줘.
```

이 한 줄과 다른 편의 프롬프트는 https://synk.im/prompts 에 모아 두었어요. 여러분 가게라면 어떤 물건을 고르실 건가요?
