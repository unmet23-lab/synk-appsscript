3. **수신 거부 해제:** @1101yuh 것 가운데 이 시험에 필요한 행만 CAS(원문 대조)로 푼다(10-19엔 3행). 다른 계정의 수신 거부 · 전체 차단 · 기존 발송 이력은 건드리지 않는다.
4. **댓글 1개:** ego 기본 프로필(지금 @1101yuh)에서 위 릴스에 「한줄」 댓글을 **딱 한 번** 단다. 시작 전에 `instagram.com/accounts/edit/`가 `/1101yuh/`인지 다시 본다. 로그인 · 문자 인증 · 2단계 · 캡차 화면이 뜨면 멈추고, 수신 거부부터 복구한 뒤 유호님께 한 줄로 넘긴다.
5. **받은 것 확인:** 서버에서 첫 DM · 공개 답글이 각 1건 `sent`/HTTP200, 큐 `done`인지 본다. @1101yuh 받은함에서 실제 본문과 https://synk.im/prompts/ 링크를 보고 눌러서 열리는지 확인한다(알림만 보이면 같은 대화만 새로고침하고, 다시 보내지 않는다). 댓글 아래 공개 답글이 보이는지도 본다.

7. **인스타 계정 되돌리기:** 시험이 끝나면(막혀서 멈춰도) ego 기본 프로필 인스타를 「설정」 아이콘 → 「계정 전환」 → **synkbrief**로 되돌리고 `accounts/edit/`가 `/synkbrief/`인지 확인한다. 인증 창이 뜨면 새로고침 한 번, 그래도 뜨면 멈추고 유호님께 넘긴다.
