# 계정 개편 시안 · synkbrief와 yuhobuilds 첫 편(2026-11-20)

유호님 11-20 「팔로워가 거의 멈춰서 컨셉을 아예 바꾸던지 해야할것같아」, 「초보자들 위주로 정말 도움되는 ai llm 활용 지식들을 알려주는 채널로 … 검토도 해줘」, 「두 계정 다」에 따라 만든 첫 시안이다. 올린 것은 없고 기획 장부와 예약된 편은 바꾸지 않았다.

- 보는 판: https://claude.ai/artifact/1sTNSa6s63BazEUt2XoZuy
- 근거: [인스타 AI 계정 벤치마크](벤치마크.md)

## 시안이 바꾸는 것

| | 지금 | 시안 |
|---|---|---|
| 소재 | AI 사고 재연, 실패담 | 그 주에 수요가 확인된 소재를 초보자가 따라 하게. 우리가 직접 돌려 본 것만 |
| 팔로우할 이유 | 없음(11-09에 키워드 DM을 뺌) | 편마다 댓글 낱말로 자료를 DM으로 보냄(10-18 승인 틀) |

- synkbrief 첫 편은 「사진 한 장에 붙여 넣는 요청문 3개」다. 10-27 빈 방 채우기, 10-30 메뉴판 정리, 10-30 옛 사진 복원 편의 요청문과 실제 결과를 묶었다.
- yuhobuilds 첫 편은 「AI한테 일 맡길 때 끝에 붙이는 말 5개」다. synk.im/prompts에 공개된 다섯 항목(`no-made-up-reviews`, `approve-before-post`, `move-dont-delete-cleanup`, `one-object-homepage`, `automation-done-count`)을 묶었다.

## 유호님이 고르실 것

1. synkbrief 표지 A(검정 바탕, 결과 사진이 화면 끝까지)와 B(아이보리 바탕, 둥근 사진). 고르심 장부 묶음 `계정개편표지-synkbrief-20261120`.
2. yuhobuilds 표지 A(진행자 얼굴)와 B(붙이는 말 쪽지 셋). 묶음 `계정개편표지-yuhobuilds-20261120`.
3. 댓글 안내를 「댓글에 남겨 주세요」로 할지 「팔로우하고 댓글에 남겨 주세요」로 할지. 시안은 앞의 것이다.
4. 이 방식으로 4주 시험할지.

## 올리기 전에 남은 일

- 릴스 영상을 만든다.
- synkbrief 3번의 제미나이 요금제와 나이 조건을 공식 도움말에서 다시 확인한다(지금 글은 10-30 확인).
- 자료 주소를 만든다. synkbrief는 synk.im에 새 쪽, yuhobuilds는 synk.im/prompts에 다섯 개만 모은 자리.
- 팔로우를 조건으로 거는 문구가 인스타 정책에 맞는지 확인한다.
- 방향이 정해지면 수요 스캔 설정(`tools/수요스캔/설정/수요_synkbrief.json`, `수요_yuhobuilds.json`)의 「인스타」에 벤치마크의 10만 이상 계정을 넣어 매일 읽게 한다. 지금은 두 브랜드에 인스타 씨앗이 없다.
