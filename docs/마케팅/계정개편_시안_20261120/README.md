## 자료 나눔 편을 만들 때(11-20 유호님 지적)

보낼 자료의 실제 내용을 영상보다 먼저 쓴다. 자료는 영상에 나온 것보다 분명히 많아야 하고, 한 사람의 한 가지 일을 처음부터 끝까지 따라 할 수 있어야 한다. 무료로 되는 범위와 필요한 조건을 자료에 적는다. 이 셋을 답하지 못하면 영상을 만들지 않는다.

## 올리기 전에 남은 일

- 올릴 날과 시각을 정해 준비.json에 넣는다.
- 자료 주소를 만든다. synkbrief는 synk.im에 새 쪽이 필요하다. yuhobuilds 다섯 개는 synk.im/prompts에 이미 공개돼 있어 그 다섯만 모은 자리를 만들면 된다.
- 댓글 낱말(「사진」 · 「한마디」)의 키워드 DM을 등록한다(`node tools/sns-DM준비.js`). 영상의 끝 말이 그 DM을 가리켜서, 등록 전에는 올리지 않는다.
- 팔로우를 조건으로 거는 문구가 인스타 정책에 맞는지 확인한다(4번에서 조건형을 고르실 때).
- 위는 앞 시안 둘을 올릴 때의 일이다. 새 편은 주제가 정해진 뒤 같은 순서를 따른다.
