# 게시 체크리스트 · 창업자 인터뷰 세로 클립 v2 (2026-09-27 기준)

게시는 사용자 승인 뒤에만 한다. 순서는 [바이럴 검토 5절](../../../../바이럴_검토와_보완_20260927.md#5-첫-2주-게시-순서-제안)의 첫 2주 제안을 따른다.

## 공통

- [ ] 영상은 v2 폴더의 파일을 쓴다(v1은 자막이 아래 UI에 가려질 수 있고 −16 LUFS·레벨 5.0이다)
- [ ] 표지: 첫 프레임(제목 + 얼굴)이 그대로 표지가 된다. 프로필 3:4 격자 안에 제목과 얼굴이 모두 들어간다
- [ ] 해시태그 5개까지 — [게시문안.md](게시문안.md)
- [ ] AI 표시는 필요 없다. 실제 촬영한 얼굴과 목소리다
- [ ] 인스타그램 Meta AI 번역(목소리 번역·립싱크)은 선택이다. 켜면 유호님 목소리가 영어 등으로 더빙돼 해외 시청자에게 보인다. 뜻이 미묘한 문장(「사실 쓰레기니까」)은 번역이 어긋날 수 있으니, 켠다면 A나 F 한 편으로 먼저 시험한다
- [ ] 선택: 체험용 릴스로 팔로워가 아닌 사람에게 먼저 보인다
