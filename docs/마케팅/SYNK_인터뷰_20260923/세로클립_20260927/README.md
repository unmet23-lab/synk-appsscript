## 만든 방법

- 화면: 4K 마스터에서 굽힌 자막 띠(4K y≥1743) 위쪽 972×1728 영역을 잘라 1080×1920으로 키웠다(1.11배). 가로 위치는 v9 눈 추적 좌표(`revision9/tracking`)의 홍채 중심을 1초 간격 키프레임으로 뽑아 컷 안에서는 선형 보간, 컷 경계에서는 바로 바꾼다. 클로즈업 컷은 머리 양옆이 잘리는데 16:9 원본을 세로로 자르는 한계라 그대로 뒀다.
- 자막: 승인본 말자막 원문·시간(`revision8/captions.json`)을 그대로 쓰고, SUIT SemiBold 64px·흰색·검정 외곽선으로 화면 아래 1/4 지점에 얹었다. 줄바꿈도 승인본과 같다.
- 제목·이름표: 상단에 SUIT SemiBold 78px 두 줄(둘째 줄 노랑 `#FFD84D`), 처음 4초 “양유호 · SYNK 창업자”. D는 브랜드 엔딩이 시작되면 제목을 내린다.
- 브랜드 엔딩(D): 4K 엔딩의 문구·로고 영역(x1200–2640, y700–1500)을 1080×600으로 줄여 검은 세로 화면 가운데에 놓았다.
- 소리: 승인본 최종 믹스를 그대로 잘라 시작 25ms·끝 80ms 페이드만 넣었다. 컷 위치는 대사 스템(`revision8/audio/dialogue_stem.wav`)의 10ms 에너지로 확인해 말이 시작되기 전·끝난 뒤 지점을 골랐다. 이후 전체 음량만 선형 이득으로 −16 LUFS / TP −1.0 dBFS에 맞췄다(믹스 밸런스 무변경). 승인본 마스터는 −17.6 LUFS다.
- 출력: H.264 1080×1920 30fps, AAC 192k 48kHz, faststart.

## 다시 만들기

`소스/make_clips.py`가 마스터·추적 좌표·자막 데이터를 읽어 `out/clip_<키>.mp4`를 만든다. 실행 폴더에 `fonts/SUIT-SemiBold.otf`·`SUIT-Medium.otf`(`graphics/fonts`에서 복사)가 필요하다. `python make_clips.py A B`처럼 키를 고르고, 자막·제목만 바꿨을 때는 `--remux`로 마지막 합성만 다시 한다. `qa_clips.py`가 검수 수치와 프레임 시트를, `package.py`가 보관·바탕화면·저장소 복사와 파일 지문을 만든다. 구간·제목은 스크립트의 `CLIPS`에 있다.
