# SHIFT 유호 X — 추가 결정과 준비 상태

2026-09-11. 유호 요청 “오케이 X를 추가하자”에 따라 SHIFT 유호 채널 1개를 추가한다. **Chrome에서 Google 로그인과 실제 공개 핸들 `@yuhobuilds`를 확인했고, 승인 얼굴·배너·소개·사이트를 저장한 뒤 첫 텍스트 글을 공개 재조회했다.** X API 연결과 영상 게시는 별도 상태다.

## 역할과 준비값

| 항목 | 값 |
|---|---|
| 내부 계정 키 | `yuhobuilds-x` |
| 로그인 선택 | 사용자 지정 Google 계정 `unmet23` — 09-11 로그인·공개 프로필 확인 |
| 공개 핸들 | `@yuhobuilds` — 09-11 X 프로필에서 실제 확인 |
| 표시명 | 유호 · AI와 회사 만들기 |
| 소개 준비문 | AI와 함께 회사를 만들고 있어요. 직접 해본 방법과 막힌 문제, 고친 과정을 나눕니다. SYNK SHIFT |
| 사이트 | `https://synk.im/` |
| 상대 | AI로 자기 일을 만들거나 개선하는 사람, 실제 제작 과정을 나눌 창작자·사업자 |
| 제공물 | 실제 작업의 문제·입력/출력·비교 장면·사람이 고친 이유·현재 결과 |
| 도착지 | 해당 사례가 실제 공개되면 YouTube 본편·티스토리 상세·공개 실물로 연결 |
| 이미지 | 승인 스튜디오 얼굴과 `docs/SHIFT/배너/yuhobuilds_링크드인.png`; X 공개 화면에서 실제 잘림·가독성 확인 |

첫 고정 소개는 현재 회사 비전과 실제 작업을 연결하고, 그 다음 글은 실물 한 건의 문제·시도·변화를 짧게 나눈다. 한국어로 시작하며 해외 제작자와 나눌 근거가 있는 사례에 영문 요약을 시험할 수 있다. 모든 글의 이중 언어·고정 장문·매일 발행을 의무화하지 않는다.

Threads와 콘텐츠 형식은 겹칠 수 있다. X를 더하는 이유는 **다른 관계와 실제 작업 피드백을 얻을 수 있는지 시험하기 위해서**다. 한국 AI·창업 고객 도달이 더 크다는 통계를 확인한 것은 아니다. 독자가 다른 경우 같은 소재를 쓰되 질문·설명·대화를 그 자리에 맞춘다. `@synkbrief`와 LAB·PULSE·본체 X는 이번 개설 범위가 아니다.

## 운영과 관측 제안

실제 작업이 생길 때 짧은 과정 글·전후 비교·시연을 편성한다. 계정이 열린 뒤 약 4~6주를 첫 관측 구간으로 삼되 고정 발행량이나 무반응 자동 폐쇄를 약속하지 않는다. 목표와 맞는 사람의 구체 질문·재방문·자료 사용·협업/교육 문의와 응대 시간을 함께 본다. 팔로워 수만으로 채택하지 않고, 도달이 너무 적으면 형식·주제·참여 방식을 바꿔 추가 관측한다. 성과·예산·유료 Premium 도입은 아직 확정하지 않았다.

X 공식 도움말은 일반 글의 웹 예약 기능을 안내한다. 처음에는 AI가 검수용 본문·미디어를 준비하고 사용자가 공식 편집기에서 게시·예약하는 경로를 제안한다. 기존 검수형 발행 코드에는 X 이름 인식만 추가했다. **X API 발행·인증 연동을 구현하거나 연결한 것이 아니다.** 현재 계정 항목은 `blocked-no-x-adapter` 상태로 두어 자동 발행 대상으로 취급하지 않는다.

2026-09-11 확인한 X 공식 개발자 안내는 사용량 기반 API 과금을 설명하며, 공식 자동화 규칙은 웹사이트 스크립팅 같은 비 API 자동화를 금지한다. 자동 발행이 필요해지면 당시 공식 연동·권한·비용을 확인한다. 계정 추가만으로 API 크레딧 구입·유료 구독·자동 답글을 시작하지 않는다.

## 현재 실행 증거와 남은 단계

- 09-11 최신 Chrome 확인: 공개 프로필에서 승인 스튜디오 얼굴, `docs/SHIFT/배너/yuhobuilds_링크드인.png` 배너, 표시명 **유호 · AI와 회사 만들기**, 소개, `https://synk.im/` 링크와 게시물 1건을 재조회했다.
- 첫 글은 [공개 주소](https://x.com/yuhobuilds/status/2098402542854275312)에서 다음 문안의 실제 반영을 확인했다: “소개서 한 장부터, AI와 함께 회사를 만드는 유호입니다.”로 시작해 AI 입력·결과·수정 이유와 준비 중인 일을 구분한다. 독립 사실·과장 검토 뒤 텍스트만 게시했다.
- 29.4초 SHIFT 첫 영상은 규격·문안 검토를 통과했지만 정확한 BGM `시티팝_147.wav`의 생성 당시 Pro 구독·공식 다운로드를 잇는 직접 권리 기록이 부족해 X에 첨부하지 않았다. 이 보류를 게시 실패나 X 계정 미완료로 섞지 않는다.
- 아래 09-11 21시 KST 기록은 최신 확인 전의 중간 상태다. 당시 Google 계정 선택 제어가 시간 초과해 X 로그인 첫 화면에 남았으나, 이후 사용자의 가입 진행 뒤 Chrome 공개 프로필 확인으로 대체됐다. 인앱 브라우저의 가입 진행 상태와 Chrome 공개 확인은 구분한다.
- 최신 계정 JSON과 채널 정본에는 `@yuhobuilds` 공개 핸들·프로필 완료·첫 텍스트 게시 주소를 반영했다. 이를 X API 연결이나 영상 게시 완료로 세지 않는다.
- 이번에 선택된 Codex 인앱 브라우저에서 X 공식 홈페이지를 열어 로그아웃 화면을 확인했다. 이 관찰은 다른 브라우저나 휴대폰의 X 계정 부재를 증명하지 않는다.
- 사용자가 “unmet23 이거로 x 연결할게”라고 로그인 계정을 선택했다. 이후 같은 X 탭의 신규 가입 생년월일 입력 화면을 확인했다. 이 화면만으로 Google 계정 연결 완료나 공개 핸들 확보를 증명하지 않는다.
- AI는 생년월일을 추정해 입력하거나 가입 약관 동의·게시를 실행하지 않았다. 사용자가 입력했다고 알리고 아이디를 물어 `yuhobuilds`를 안내했으며, 이후 실제 공개 프로필에서 같은 핸들을 확인했다.
- 공개 핸들과 프로필 단장, 첫 텍스트 글은 실제 화면에서 확인했다. X API·유료 Premium·광고·영상 게시는 실행하지 않았다.
