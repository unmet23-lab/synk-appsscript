# S4 무음 검토 영상

`preview-silent.mp4`는 Typecast 음성을 합성하기 전의 화면·순서·가독성 검토본이다. 최종 발행본이 아니다. 영상 안에도 `무음 검토본 · 음성 합성 전`을 표시했다.

- 1080 × 1920, H.264, 24fps, 45.5초, 6컷, 오디오 스트림 없음.
- 마지막 요청문은 전환 뒤 10.7초 동안 보인다.
- 0.3초 크로스페이드로 연결한 실제 PDF 화면·확대 이미지·설명 자막 편집이다. 실시간 앱 화면 녹화나 AI 자동 수정 화면처럼 연출하지 않았다.
- `render.cjs`가 지면 PNG, 영상, 영상에서 다시 추출한 검수 프레임, 메타데이터를 생성한다.
- `check-playback.cjs`는 Chromium 계열 브라우저에서 정상 속도로 끝까지 재생한 결과를 `playback-qa.json`에 기록한다.

## 사용한 실물

- `../demo-before.pdf` / `../demo-after.pdf`와 각각의 실제 렌더 PNG.
- `../table-before.png` / `../table-after.png`는 전체 표와 설명용 가상 문서 표시를 포함한다.
- 영상의 문장 끝 확대는 원래 PDF를 300dpi로 다시 렌더한 `hires-before.png` / `hires-after.png`에서 잘랐다. 글자를 다시 그려서 바꾸지 않았다.
- 수정 전 오류는 의도적으로 만든 재현 예시다. 해당 사실을 2번째 컷에서 표시한다.
- 승인 `SYNK-Ink.png` 원본 SHA-256을 배치명세와 대조했다. 서체는 SUIT Variable·Inter Tight다.

## 확인한 범위

- 여섯 장면의 폰트 준비 완료, 이미지 로드 실패 없음, 텍스트 안전 영역 이탈 없음.
- 실제 출력된 MP4에서 각 장면 대표 프레임을 추출해 원래 지면과 대조했다.
- 전체 화면 구성, 수정 전·후 비교의 큰 글자, 마지막 요청문의 줄바꿈을 육안 확인했다.
- 사진형 로고를 새 글자로 조립하거나 비율을 바꾸지 않았다.
- PDF 300dpi 변환 중 Poppler가 Type 3 glyph bounding box 경고를 출력했다. 최종 확대 이미지에서 글리프와 문장 끝을 직접 확인했으며, 의도한 수정 전 잘림 외에 잘못 잘린 글자는 남기지 않았다.
- 음성이 없으므로 발음·감정·BGM 균형·음성과 자막의 동기화는 아직 확인 대상이 아니다.

## 음성 합성 후 할 일

`copy/S4-narration.txt`의 실제 오디오 길이에 맞춰 각 컷 길이와 자막 타이밍을 조정한다. 검토본 표기를 제거한 별도 최종 파일을 내보내고, 음성·화면을 함께 재생해 확인한다. 지금 파일 이름을 바꾸는 것만으로 최종 완성 처리하지 않는다.

이 폴더 밖의 루트 `build.cjs`와 `cards/`는 수정하지 않았다. 외부 발행·결제·커밋도 하지 않았다.
