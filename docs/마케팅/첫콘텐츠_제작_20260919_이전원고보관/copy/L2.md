## 제작·검수 메모 · 게시 제외

- 카드 2에서 먼저 말할 시간을 주고 카드 3에서 예문을 확인한다. 본문 앞부분에 예문을 노출하지 않는다.
- 카드 3의 두 문장은 같은 난이도의 정답 두 개가 아니다. 첫 문장은 다시 듣기, 둘째는 말의 속도가 빠를 때 쓰는 추가 요청이다.
- 음성·영상·자동 평가·개인 피드백을 첨부하거나 제공한다고 쓰지 않았다. 이번에 제공하는 것은 실제 카드 연습이다.
- 모집 일정·가격·수업 성과·유학 실적을 추가하지 않는다.
- 몽골어는 편집 초안이며 원어민 확인 완료로 표시하지 않는다. 문맥 검수 우선: `тухайн хүний зорилго, нөхцөлд хэрэг болох`(개인의 목표·상황에 필요한), `жишээг харахаасаа өмнө`(예문을 보기 전에). 교정할 때 한국어 선시도→예문 확인 순서는 유지한다.
- 링크는 현행 채널 정본의 공식 주소다. 이 파일 작성 중 공개 페이지의 게시·자료 업로드 상태를 확인한 것은 아니다.
