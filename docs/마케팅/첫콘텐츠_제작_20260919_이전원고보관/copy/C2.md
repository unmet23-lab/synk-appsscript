### SHIFT · 캐릭터는 그대로, 바탕은 순백으로

LAB의 몽글 프로필을 흰 페이지에 놓고 보니, 크림색 바탕이 주변과 나뉘어 보였습니다. 화면 바탕과 이어지도록 프로필 배경을 조정하기로 했습니다.

수정할 부분은 바탕이었습니다. 펠트의 결, 몽글의 표정과 구도는 원본 그대로 두고 배경을 순백으로 다시 출력했습니다. 위의 전후 이미지에서 바뀐 부분을 볼 수 있습니다. 프로필에 적용한 뒤에는 공개 화면에서도 다시 확인했습니다.

이번 작업은 결과를 어디에 놓고 볼지도 제작의 일부라는 것을 보여줍니다. 다음 작업에서도 새로 만들 부분과 이미 잘 맞는 부분을 먼저 살피려고 합니다.

이 편지의 제작 이야기에서는 완성 화면과 함께, 만들면서 발견한 문제와 고친 이유를 나누겠습니다. AI 도구나 GitHub 스킬도 직접 해 본 작업과 연결해 소개하고, 새로운 AI 소식은 우리 일에서 무엇이 달라지는지 살펴보려 합니다.

## 편집·검수 메모 · 게시 제외

- LAB 카드 `lab-02`는 `먼저 해 보기` 앞, `lab-03`은 `이제 예문을 확인해 보세요` 뒤에 놓는다. 제목·미리보기·첫 이미지에 완성 예문을 노출하지 않는다.
- 완성 예문 전 `죄송한데, …`는 전체 답을 미리 주는 문장이 아니라 시작이 어려운 학습자를 위한 짧은 도움이다. 독자가 먼저 시도하도록 바로 앞 문장을 유지한다.
- SHIFT 전후 비교 이미지를 해당 구획 첫 문단 뒤에 넣는다. 원본은 `docs/마케팅/프로필최신화_20260919/배경_순백_20260919/synklab-profile-before.png`, `synklab-profile-white.png`다. 두 장을 직접 시각 대조했다. 공개 프로필 확인은 이번 제작의 사례 담당자가 대조한 반영 기록에 근거한다. 전체 기기 확인·성과 증가를 주장하지 않는다.
- SHIFT 이미지 대체 텍스트: 같은 산호색 펠트 몽글 프로필의 배경 수정 전후. 왼쪽은 크림색, 오른쪽은 순백색 바탕이며 몽글의 표정과 구도를 유지했다.
- 실제 공개된 상세 제작기 URL이 생기기 전에는 비공개 파일·예정 URL을 독자 링크로 넣지 않는다. 이번 편지는 학습 샘플과 디자인 이미지를 본문에 직접 싣는 구성이다.
- 일간·주간 발행 빈도, 자동 언어 분리, 선택 구독이 설정됐다고 약속하지 않는다.
- 몽골어 원어민 검수 미완료. `AI ашиглан хийж буй ажлынхаа түүх`는 AI를 활용하는 실제 작업 이야기를 뜻하며 AI 개발 기술 전문지라는 의미가 아니다. 유호의 몽골어 표기 `Юхо`는 공개 프로필 표기와 최종 대조한다.
