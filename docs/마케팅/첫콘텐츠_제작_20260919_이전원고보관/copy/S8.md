## 게시 제목

펠트와 투명 유리로 만든 SYNK SNS 커버 디자인

## 게시 설명

펠트 소품과 실, 투명한 유리 로고를 활용한 SYNK의 SNS 커버 작업입니다. 흰 바탕과 검정 펠트 바탕을 함께 쓰고, 같은 재료를 채널마다 다른 구성으로 배치했습니다. 이미지는 AI 생성 자산과 기존 브랜드 자산을 활용하고 글자와 배치는 별도로 마감했습니다.

브랜드 디자인에 펠트와 유리를 함께 쓰는 참고 작업으로 저장해 보세요.

## 이미지 요청 · 제작용, 게시 본문에서 제외

- 이미지 핀 1장. S7 프로젝트 표지와 같은 원본을 재사용한다. 첫 제작 제안 비율은 2:3이며 실제 업로드 조건이나 의무 장수라는 뜻은 아니다.
- 상단 짧은 제목: `FELT & GLASS`. 보조문구: `SYNK · SNS COVER DESIGN`.
- 대표 장면은 기존 `커버_펠트글래스_v4/shift-pinterest.png`의 유리 로고·펠트 소품으로 구성한다. 가로 커버를 무리하게 세로로 잘라 제목이나 소품을 잃지 않도록 원본 일부를 각각 배치한다.
- 흰 여백 위에 실제 흰 커버와 검정 커버 2개를 나란히 또는 위아래로 놓는 S7 표지라면 그 구성을 그대로 사용해도 된다. 새 AI 이미지 생성은 필요하지 않다.
- 이미지 안에 상세 제작기를 이미 공개했다고 표시하지 않는다.
- 대체 텍스트: SYNK SNS 커버의 펠트와 유리 디자인. 투명한 유리 안의 SHIFT 로고와 파란 펠트 웹 화면, 카드, 발표판, 실로 연결된 톱니 소품이 보인다.

## 공개 링크 · 제작용

현재 사용할 수 있는 목적지는 `https://synk.im/`이다. HTTP 200과 회사 페이지 제목을 확인했다. 이 주소는 회사 소개이므로 현재 설명에는 ‘전체 프로젝트 보기’라고 쓰지 않았다.

S6 제작기 또는 S7 Behance 프로젝트를 먼저 공개하면, 실제 생성된 개별 게시 주소로 목적지를 바꾸고 설명 끝에 `전체 작업과 수정 과정은 링크에서 볼 수 있습니다.`를 추가한다. 아직 없는 주소를 미리 만들지 않는다.
