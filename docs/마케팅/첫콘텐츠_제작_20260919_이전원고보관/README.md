## 목소리

사용자는 콘텐츠 성격에 맞는 선택을 제작자에게 위임했고, 상큼하고 맑은 목소리를 원했다. 학습과 브리핑은 맑은 여성 설명 톤, 유호 기록은 맑은 남성 대화 톤을 우선 비교한다. 실제 API 음성 ID와 최종 캐릭터는 아직 고정하지 않았다. 결제 및 API 연결 확인 후 짧은 실제 대본으로 비교하고 선택한다. 유호 본인의 복제 목소리는 제작하지 않았다.

확인한 상품은 Typecast API Lite($15/월, 월 20만 크레딧)이며 Studio와 별개다. 초과 사용은 10만 크레딧당 $9 자동 결제이므로 제작할 때 현재 사용량과 필요 글자 수를 확인한다. 이번 제작에서 Typecast 호출·구독·결제는 0건이다. API 키를 게시용 파일이나 Git에 넣지 않는다. 상세 방향은 `voice-plan.json`.

- Playwright PDF 사례는 오류를 의도해 만든 설명용 재현 예시다. 실제 PDF 출력·이미지 렌더·수정 전후 확인이 있으며 고객 문서가 아니다.
- 몽골어는 자가 문맥 검토 상태이며 원어민 감수 완료는 아니다.
