AI가 만든 PDF, 보내기 전에 이것부터

PDF 파일이 생겼다고 문서가 제대로 보이는 것까지 확인된 건 아니에요.

이번에는 긴 문장이 잘리도록 만든 가상 안내문을 Playwright로 PDF로 저장하고, 페이지 이미지로 확인한 뒤 줄바꿈을 고쳤습니다. 원본과 수정본을 모두 실제로 내보내 비교했어요.

다음 문서 요청에는 “PDF로 저장한 뒤, 모든 페이지를 열어 보고 잘린 부분까지 고쳐 줘”를 덧붙여 보세요. 글자 잘림·표·페이지 끝을 확인하고, 내용의 사실성과 링크 동작도 따로 확인하면 좋아요.

사용 도구와 공식 설명:
- Playwright GitHub: https://github.com/microsoft/playwright
- PDF 출력 API: https://playwright.dev/docs/api/class-page#page-pdf
