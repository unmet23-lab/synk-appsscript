# 오미톡 15초 세로 광고 — 한 문장과 글 콘티 v2

> 손님께 크몽 메시지로 보내 확정받는 판이다(상품 글 진행 절차 2). 만드는 도구 · 경로 · 비용은 손님 판에 쓰지 않고 [README](README.md) 「제작 메모」에 둔다. v1 → v2는 콘티 검수(Fable, `synk-vendor/pulse-rehearsal-20261029/검수/fable_콘티_v1.md` — P0 1 · P1 4 · P2 7 · P3 4, 모두 반영)를 고친 판.

## 한 문장

**운동 끝 첫 모금, 다섯 가지 맛이 톡.**

턱 끝의 땀방울 → 차가운 캔의 물방울 → 입구에서 톡 튀는 탄산 — 물방울 하나가 모양을 이어 가며 「목마름 → 한 모금 → 맛 → 이름」으로 간다. 효능 말은 쓰지 않고, 목마름은 장면 설정으로만 쓴다.
