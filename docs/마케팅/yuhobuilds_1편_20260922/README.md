# yuhobuilds 1편 — 번역하려고 결제했는데, 출석 앱을 만들고 있었다

> 사용자 피드백 후 [59초 쇼츠 수정본](../yuhobuilds_1편_쇼츠수정_20260922/README.md)을 새로 제작했다. 이 3분판은 비교용으로 보존한다. 윤성 보이스는 후속 편의 승인된 목소리가 아니다.

2026-09-22 · 6월의 실제 경험을 바탕으로 만든 시간순 연재의 첫 편. 번역에 쓰던 Claude로 출석 앱을 만들기 시작하고, 도구 설정과 스크린샷 질문을 반복하던 이야기를 담는다. AI를 처음 쓰는 사람도 자기 일의 작은 불편에서 시작해 볼 수 있도록 마무리한다.

**남성 내레이션·음악·자막을 포함한 첫 검토용 MP4를 완성했다.** YouTube·Instagram·TikTok·네이버 클립의 기존 `@yuhobuilds` 4곳에 같은 핵심 영상을 사용할 예정이며 외부 게시는 하지 않았다. [완성 MP4](yuhobuilds_EP01.mp4) · [로컬 재생 화면](http://127.0.0.1:4373/preview.html)

시간과 장면 수는 [장면타이밍.json](장면타이밍.json)의 제작값이며, 최종 MP4 실측은 [영상 규격](검수/영상규격.json)에 기록했다. 첫 출력의 마지막 무음 여백만 1.333초 줄였고 마지막 발화는 179.410초까지 보존했다. 원래 출력은 `검수/before-tail-trim.mp4`로 보존했다. 향후 렌더는 수정된 179.9초 타임라인을 직접 사용한다.

미리보기의 **영상 재생** 버튼을 사용한다. 브라우저 기본 컨트롤의 자동 클릭 중 탭 오류가 한 번 발생했고, 별도 HTML 재생·구간 이동 버튼을 추가한 뒤 실제 영상 진행을 확인했다. WebM은 미리보기용이며 컨테이너 길이 180.033초다. 게시용 원본은 179.966667초인 MP4다. [브라우저 검수 기록](검수/브라우저.json)

## 오디오 구성

보유 음원 [따뜻_118.wav](../../홍보물/BGM/따뜻_118.wav)의 7초 지점부터 60초 구간을 사용한다. 반복 경계는 3초 교차 페이드로 연결하고 낮은 음량으로 내레이션 아래에 섞었다. “심심함은 해결됐어요” 대목은 음악을 더 줄였다. 이는 기존 음원의 구간 편집이며 새 곡 생성이 아니다.

합성 원본과 단어 타이밍은 유지하고, 장면 앞뒤 여백을 넣은 음성·음악·최종 믹스를 분리해 두었다. `narration-only.wav`는 음악 없는 연결본, `music-bed.wav`는 편집한 음악, `narration-master.wav`는 영상에 넣을 최종 믹스다. 일정한 게인 조정으로 음량을 맞췄으며 최종 청취 평가는 남아 있다.

## 다시 만들기

저장소 루트에서 실행한다. 기존 Node·Remotion 의존성과 로컬 `ffmpeg`·`ffprobe`를 사용한다.

새 합성이 필요한 경우에만 기존 Typecast API 연결을 로컬에서 다시 연 뒤 실행한다. 같은 요청의 원본이 있으면 재사용하며, 본문·설정이 바뀌면 기존 파일을 보존한 채 별도 수정본을 준비해야 한다. 키는 이 폴더에 저장하지 않는다.

```powershell
node "docs/마케팅/yuhobuilds_1편_20260922/synthesize.cjs"
```

이미 보존한 19개 원본으로 오디오·음악 믹스·타이밍·자막을 다시 만든다. **추가 API 합성은 하지 않는다.**

```powershell
node "docs/마케팅/yuhobuilds_1편_20260922/prepare-audio.cjs"
```

표지·장면 이미지·콘택트 시트와 MP4를 렌더하고 규격·전체 디코딩을 확인한다. 정지화면만 먼저 만들 때는 `--stills`를 붙인다.

```powershell
node "docs/마케팅/yuhobuilds_1편_20260922/render.cjs"
```

완성 MP4에서 720×1280 VP9/Opus WebM과 SUIT 폰트·자막을 내장한 미리보기 페이지를 만든다. MP4는 다운로드 원본, WebM은 브라우저 재생용이다. 강제 재변환은 `--force`, 페이지만 갱신할 때는 `--html-only`를 붙인다.

```powershell
node "docs/마케팅/yuhobuilds_1편_20260922/finish-preview.cjs"
```

재제작 뒤에는 영상·미리보기 규격 검사와 별도로 실제 화면과 소리를 확인한다. 위 명령은 외부 게시를 실행하지 않는다.
