## A · 인스타 릴스 캡션

```
AI한테 "보고서 써 줘"만 하면, 말하지도 않은 사은품 행사와 예산 200만 원을 지어 넣어요. 회의 메모를 먼저 붙이면 "팀장 확인 예정", "미정"으로 남겨요.

[그대로 붙여 쓰는 요청문]
아래 메모만 보고 보고서 초안을 써 줘. 메모에 없는 내용은 지어내지 말고 '미정'이라고 적어 줘.
(그 아래에 내 메모를 붙여 넣기)
→ 같은 메모로 이 요청문을 직접 돌려 보니 행사명·목적·참석 대상까지 '미정'으로 비워 두고 "메모에 있는 사실만 반영했다"고 적었어요.

[영상 속 실제 결과]
· 메모 없이 "11월 고객 행사 보고서 써 줘": 작성 부서 "영업팀 / 마케팅팀", 행사 내용 "사은품 증정, 특별 프로모션", 예산 표(고객 사은품 100만 원 … 합계 200만 원)
· ChatGPT도 표 아래에 "상기 예산은 예시"라고 적었어요. 그런데 표만 복사하면 그 줄은 빠지고, 사은품·할인 같은 행사 내용엔 예시 표시도 없었어요.
· 메모를 붙이고 같은 한 줄: "행사 예산: 팀장 확인 예정", "세부 프로그램 및 참석 규모: 미정"

[알아 둘 것]
· 같은 질문도 매번 답이 조금씩 달라요. 내 화면에서 다른 숫자가 나와도 정상이에요.
· 메모를 붙여도 "제안 일정"처럼 덧붙이는 게 있어요. 다 쓴 보고서는 메모와 한 줄씩 맞춰 보세요.
· 화면은 휴대폰 크기로 띄운 ChatGPT 웹 임시 채팅(메모리·맞춤 지침 안 씀, 2026.10.24)이에요.

출처: OpenAI 도움말 「Does ChatGPT tell the truth?」 · OpenAI 「Why language models hallucinate」(2025.09) · Anthropic 「Reduce hallucinations」(2026.10.24 확인)

여러분은 AI가 지어낸 거, 그대로 낸 적 있으세요? 댓글로 알려 주세요.

#챗GPT #ChatGPT #AI활용 #보고서 #직장인
```
