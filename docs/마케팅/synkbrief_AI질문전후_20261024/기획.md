## Fable 사실 검수(10-24, 콘티)

판정 「고쳐서 진행」 — P0 없음. 원문 일곱(OpenAI 넷 · OpenAI API 문서 둘 · Anthropic 하나)을 열어 대조했다.

- **P1 반영:** 장면 4 「예산은 팀장 확인 예정, 프로그램은 미정. 메모에 없으니까요.」 — 「메모에 없으니까요」가 예산에도 걸리는데 예산은 메모에 있다 → 「예산은 메모대로 팀장 확인 예정, 메모에 없는 프로그램은 미정.」(Fable이 낸 가장 정확한 판).
- P2 확인: 「없는 내용을 지어냅니다」는 공정하다 — 예시 표시는 예산 · 일정 둘뿐이고 사은품 증정 · 특별 할인 · 「영업팀 / 마케팅팀」 · 「매장 및 주요 고객 접점」은 표시 없이 들어갔다. 조건 「※ 상기 예산은 예시」 줄이 잘리지 않게 → 예산 화면 1.08배 · 끝 화면 1.0~1.1배로 두 줄이 다 보이게 했다(잘리면 P1). 「사은품 행사도, 예산 200만 원도」 사실 맞음. 「써 줘 전에 메모부터」는 OpenAI · Anthropic 문서가 받치는 일반 조언. 출처 줄 넷 다 맞음(임시 채팅은 점선 말풍선과 「최대 30일간 보관」 문구가 증명).
- 캡션 · 블로그로 보낸 것: 예시 표시의 범위와 「표만 복사하면 빠진다」, 다 쓴 다음에 물은 업종 질문, 메모를 붙여도 덧붙인 제안 일정, 같은 질문도 답이 다름, 「휴대폰 크기의 ChatGPT 웹」(「휴대폰에서 찍음」이라 하지 않기), 붙여 쓰는 요청문.
