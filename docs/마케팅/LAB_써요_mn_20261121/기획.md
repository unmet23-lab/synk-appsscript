## 몽골어 세 겹 검수

- **원문 안 본 Opus 직역:** «Мөнгө үрнэ»는 「낭비하다」로 읽힌다 → «зарна». 읽기 «тоныл» → «доныл»(т는 거센소리), «кхопига» → «копига». 훅 «бүгд өөр үг» → «бол өөр өөр үг». 게시글 «шил» → «нүдний шил», «амт гашуун» → «гашуун амттай».
- **교정(3차) Opus — 원문 대조:** 「그대로 올림」. 「앗! 안 보여!」 → «Ай! Юу ч харагдахгүй!»도 「그대로」.
- **대조기(카본 · 구독):** 게시글 「어색」 — «зарна»는 「팔다」로도 읽히고 끝 물음 «юунд … гэж хэлдэг»이 어색하다 → 돈 뜻을 «Мөнгө зарцуулна»로, 물음을 «"써요" гэдэг үгийг өөр юунд хэрэглэдэг вэ? Таагаад коммент дээр бичээрэй»로 고쳤다. 그록 시험관 v1도 «зарна»를 「판다」로 읽어 같은 자리를 짚었다. 화면 글 대조는 구독 통로 빈 답 · 503으로 세 번 다 답을 못 받았다.
