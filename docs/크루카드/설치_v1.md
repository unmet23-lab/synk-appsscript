## 운영 메모
- **입구 배포**: 원격 접수는 접수 주소를 그대로 공유(페이스북·홈페이지 버튼). 현장 태블릿도 같은 주소 북마크 — URL 한 벌 운영이 단순하다. Desktop의 HTML 2종도 같은 주소가 박혀 있어 로컬로 열어도 전송된다.
- **응답 유실 방어**: 모든 응답이 기기(localStorage) 자동저장 — 전송 실패·새로고침에도 남고, 「제출」만 다시 누르면 된다.
- **Serial**: 시트가 정본(같은 날짜 최대값+1). 제출 응답의 번호가 진짜다.
- **재제출**: 새 행 누적(v1 정책) — 상담사는 최신 행 기준.
- **코드 수정 시**: repo `crewcard/`에서 고치고 테스트 통과 후 `clasp push --force` → `clasp deploy --deploymentId AKfycbzzrNG2L1RUX93BN9pUHtrBM0q2cWucLtvD2smQsLz6mj9WPgoqn7xtq4oyFfMg-6ZLhQ` (같은 ID = 같은 URL 유지). 새 배포를 새로 만들면 접수 주소가 갈라진다 — 금지.
- 한도: `크루카드.js` `DAILY_CAP`(기본 300). 남용 시 새 배포로 URL 교체가 대응 절차.
