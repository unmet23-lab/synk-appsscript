몽골 키릴 자형 확인 — Ө · Ү

크루카드 몽골어판에서 Ө·Ү만 다른 서체로 튀어 보이지 않는지 확인하는 페이지입니다.

폰트 확인 중…

Inter Tight 카드 몽골어 본문 — 205곳 전부 이 서체 …

Ө Ү ө ү  О о У у

왼쪽 검정이 확인 대상, 오른쪽 남색이 비교용입니다. Ө는 О에 가로줄 하나, Ү는 U자 모양 — 획 두께와 폭이 옆 글자와 같은 식구로 보이면 정상입니다.

Cormorant 카드 전체에서 이 한 단어에만 쓰입니다 …

Таны

획 끝의 삐침(세리프)이 네 글자에 고르게 붙어 있으면 정상입니다. 이 단어엔 Ө·Ү가 없습니다 — 그래서 Cormorant의 Ө·Ү 자형은 카드에 영영 나오지 않습니다. (앞서 확인 시트가 없는 조합을 지어내 보여드려 혼선을 드렸습니다. 그 줄은 걷어냈습니다.)

폴백 이렇게 보이면 잘못된 것 (비교용)

Ө Ү ө ү

위 두 칸과 모양이 달라 보여야 서체가 제대로 붙은 겁니다. 셋이 똑같아 보이면 폰트가 안 실린 것입니다.

실제 카드 문장 이 문장들이 학생에게 그대로 나갑니다
