# 싱크타운 콘텐츠 제작 패키지

2026-10-02. 사용자 「전부 제대로 설계하고 원고도 해줘」에 따라 **첫 생활 원고, 재방문 편성, 반복 생활 경제, TOPIK 4급 대비 학습, 상품 범위**를 한 제작 단위로 연결한다. 학생에게 줄 가치는 ‘원하는 생활을 하며 내가 만든 변화를 누리고, 익숙한 한국어로 시작해 새로운 상황도 해결하게 되는 것’이다.

**이번 결과는 설계와 제작용 원고다.** 게임 엔진 연결·최종 음성/미술·전체 출시 문항은행·실학생 학습 효과를 완성했다는 뜻은 아니다. 출시 가격과 수량·시간·경제 균형은 검증안이다. 아래 원고로 스토리보드·데이터·장면 제작을 시작할 수 있게 작성했으며, 아직 만들지 않은 수백 장면이 있다고 소개하지 않는다.

## 2 첫 체험부터 다음 생활까지

1. **메인에서 앱 내부 TOPIK 1급+ 통과.** 마을 결제로 학습 조건을 건너뛰지 않는다. 처음 대사는 1~2급이라는 이름 대신 눈앞의 물건·한 행동을 기준으로 짧게 쓴다.
2. **첫 쉼터에서 원하는 하나를 선택.** 자리·메뉴·발견·주민 사연 중 하나만 해도 현재 결과를 확인한다. 다른 세 경로의 숙제를 먼저 요구하지 않는다.
3. **내 선택이 바로 쓰인다.** 만든 자리에서 차를 마시고, 고른 메뉴가 제공되고, 전시 앞에서 주민이 관찰하고, 내가 전달한 초대로 두 사람이 만난다. 도움을 받아도 똑같은 결과다.
4. **나가도 내 결과가 남는다.** 다음 방문에는 현재 배치·현재 재고·현재 전시·함께한 사건을 불러온다. 없는 재고나 치운 물건을 있다고 말하지 않는다.
5. **원할 때 새 역할을 연다.** 제작자에서 안내하는 사람으로, 요리하는 사람에서 소개하는 사람으로, 발견자에서 전시하는 사람으로 변한다. 같은 심부름에 물건 이름만 바꿔 붙이지 않는다.
6. **구독은 다음 생활을 확장한다.** 유한한 첫 챕터의 성취를 끝낸 뒤, 준비된 후속 이야기·반복 생활·학습의 포함 범위를 보고 선택한다. 언어 도움·성과 열람을 선택 상품으로 팔지 않는다.
7. **중급 목표가 생기면 별도 학습을 고른다.** 생활 속 이유·대안·공지 이해에서 긴 듣기/읽기·자료 설명·의견 쓰기로 연결한다. 일상 대화를 모두 시험 길이로 바꾸지 않는다.

## 3 아틀라스를 실제 체감에 연결하는 제작 규칙

타운은 현재 가능한 일을 먼저 정하고, Atlas는 그 안에서 적합한 학습·도움 후보를 고른다. 생활 성공과 학습 근거는 다른 기록이다. 행동/물건/NPC 인지/후속 상태는 [세계 변화 정본](../싱크타운_행동과_세계변화_설계.md)과 [구현 계약](../아틀라스_구현명세.md#town-life-adapter)을 따른다.

**후속 엔진 발전:** 사용자 요청에 따라 이 패키지의 행동·변화·재방문을 [공통 엔진 발전 기준](../아틀라스_설계.md#experience-reaction-loop)과 [실행 흐름·검사 계약](../아틀라스_구현명세.md#town-engine-loop)으로 연결했다. 물건 회수·부분 제공·한쪽 동의·미관람·비공개·반복의 반대 사례를 다른 콘텐츠에도 재사용한다. 엔진 코드는 이번 설계 반영만으로 구현 완료 처리하지 않는다.

| 읽는 근거 | 실제 바꿀 것 | 사용자가 확인하는 결과 | 하지 않는 추정 |
|---|---|---|---|
| 바깥 자리를 만들고 배치 확정 | 해당 차양·서빙 동선·주민 이용·다음 안내 역할 | 내 색과 자리에 주민이 앉음 | 클릭 횟수로 한국어 승급 |
| 받은 딸기로 조리함 / 직접 수확분으로 조리함 | 재료 출처에 맞는 짧은 말·생산 기록 | 어느 재료로 무엇을 만들었는지 맞음 | 나중 수확을 이전 조리 공로로 바꾸기 |
| 카드 관찰 / 실물 표본 선택 | 원래 식물 위치·전시 형태·다음 비교 활동 | 내 방식으로 남은 전시가 다름 | 한쪽을 더 우수한 학습자/착한 사람으로 평가 |
| NPC에게 실제 전달한 초대 | 해당 NPC만 아는 약속·실제 이동·만남 장소 | 전달 전후 행동과 장소가 다름 | 모든 NPC가 내 사연·약점을 앎 |
| 새로운 언어 항목의 독립 수행과 도움 기록 | 다음 장면의 같은 목적을 다루는 표현·도움 제안 | 새 역할을 해 보되 쉬운 방식으로 복귀 가능 | 자동 완성·그림 클릭을 독립 듣기로 인정 |
| 직접 고른 ‘덜 추천’ 또는 도움 설정 | 다음 목록의 노출과 도움 기본값 | 싫다고 한 권유가 바로 줄어듦 | 한 번 거절로 영구 취향 확정 |
| 최근 끝낸 사건의 목적·역할·결과 | 의미가 다른 작성된 후속 우선 | 재료 이름 이상의 다른 일이 생김 | 새 후보가 없는데 무한 신선함 생성 |

**장면을 만들 때 묶어 넘길 것:** 선행 사실, 권한, 자원/소유, 선택 A/B/보류, 기본 쉬운 말, 도움, 실제 완료 명령, 선택별 물건·NPC 동작, 각 NPC가 알게 되는 근거, 재방문 반응, 취소/복원, 다음 후보, 검증할 학습 능력, 데이터 판. 하나라도 빠지면 ‘대사 있음’으로만 표시하고 연결 완료로 올리지 않는다.

현재 Atlas 학습 추천과 타운의 미래 상태 저장을 혼동하지 않는다. 특히 쓰기 평가·TOPIK 급수 판정·의미 단위 이야기 신선도·두 NPC의 동의와 이동·상품 권한은 문서가 있다고 이미 구현된 기능이 되지 않는다. 구현 담당자는 현재 지원 API와 미구현 어댑터를 구분해 작업한다.

## 4 만드는 순서와 넘길 결과

| 순서 | 제작할 결과 | 다음 단계로 넘어갈 근거 |
|---|---|---|
| 1 원고를 장면으로 보기 | 첫 4경로 A/B와 재방문 장면의 간단한 연속 그림. 자막·정지 대안 포함 | 설명을 추가하지 않아도 선택 차이·실제 쓰임을 구분할 수 있음 |
| 2 한 경로를 끝까지 연결 | C01/C02 공통 계약 검사 후 FT10의 준비·배치·이용·복귀 | 자원/소유/현재 배치/NPC 동작/전달 확인이 같은 사건을 가리킴 |
| 3 네 입구와 첫 후속 | FT20·30·40, FT51~54. 도움·말하기 없음·중단·만료 포함 | 다른 분야 선행 없이 각자 끝나고, 첫 챕터가 결제로 중간에 잘리지 않음 |
| 4 재방문·경제·권한 | 작성된 다음 이야기와 반복 생활, 실제 재고, 소유 보존 | 선언한 공급·소비·판매 상한과 실제 변화가 맞고 미제작 장면은 노출하지 않음 |
| 5 한국어 검수와 실제 음성 | 학습 원고의 지문·정답·대안·쓰기 기준 검수, 확정 대사 녹음 및 청취 | 문제풀이가 그림/기억만으로 새 능력 성공을 위장하지 않고 오답/도움의 피드백이 맞음 |
| 6 초급·중급 실제 관찰 | 첫 결과 인지·중단복귀·후속 선택·언어 부담·새 문항 수행 | 불편/잘못 이해한 원인을 고치고 다시 관찰. 소수의 반응을 전체 효과로 일반화하지 않음 |

**지금 작성한 원고의 범위와 출시 분량은 다르다.** 이번에는 첫 체험과 초기 재방문 팩, 커리큘럼의 전 범위 지도와 대표 평가 팩을 준비한다. 장기 정액 상품으로 출시할 때는 실제 완성된 분량·소진 시점·추가 제작 능력을 포함 정보에 정확히 표시한다. 30회 방문 표는 빈 구간을 찾는 검사이며 30회 내내 새로운 이야기를 보장하는 문구가 아니다.

## 5 제작을 마쳤다고 판단할 조건

### 연결과 소유

- 첫 네 경로 각각 A/B/보류로 재료·선택·결과·현재 동선·다음 방문을 대조한다. 어느 하나를 하지 않아도 나머지를 독립적으로 마칠 수 있어야 한다.
- 만들기/인도/확정/이용 연출 각 지점에서 중단하고 재접속한다. 중복 지급·중복 소비·가구 복제·없는 재고의 제공·이미 끝난 의뢰 재수락은 없어야 한다.
- 표본 반환, 차양 회수, 메뉴 품절, 만남 장소 변경 뒤 모든 화면과 NPC의 말이 현재 상태를 따르는지 확인한다.
- 다른 기기·계정 전환·시계 변경·오프라인 복원·구독 종료에서 소유와 학습 통과 기록을 분리해 보존한다. 공용 마을이나 타인 공간으로 개인 선택을 전파하지 않는다.

### 편안함과 내 변화의 인지

- 처음부터 소리 끔, 말하기 없음, 움직임 줄이기, 도움을 많이 쓰는 조건으로 각각 한 경로를 끝낸다. 같은 생활 결과를 받아야 한다.
- 처음 보는 학습자에게 선택 전 설명을 길게 하지 않는다. 완료 후 ‘무엇이 달라졌나요?’를 묻거나 그림을 고르게 한다. **스스로 알아봄 / 도움 뒤 알아봄 / 잘못 연결함 / 발견 못함**을 따로 기록한다.
- 바로 나가거나 며칠 뒤 돌아와도 유지 노동·손실·관계 압박 없이 자기 결과를 누린다. 새 부탁을 거절해도 같은 친절함과 기존 활동을 유지한다.
- 취향별 5·10·30회 편성을 따라 실제 남은 원고를 센다. 할 수 있는 일이 없으면 그 사실을 확인하고 새 이야기 제작량을 조정한다. 언어만 더 어렵게 해서 빈자리를 채우지 않는다.

### 배움과 수익

- 선택만 한 것, 그림/보기 도움, 반복 정답, 새 상황의 독립 수행을 구분한다. 생활 성공률을 TOPIK 예상 점수로 표시하지 않는다.
- 듣기·읽기·쓰기를 각각 검수한다. PBT/IBT 형식과 시험 시간은 공식 기준을 따라 별도 선택 모드에서만 다루고 생활 중 제한 시간을 강요하지 않는다.
- 기본 생활과 공부를 선택 상품 없이 완결할 수 있어야 한다. 무료 사용자가 첫 체감을 보기 전에 구독 안내에 막히는지 확인한다.
- 경제 예시의 수입/소비는 문서 산식과 게임 장부를 대조하고, 구독의 수익성은 실제 제작·운영 비용/유지/환불 자료로 검증한다. 제안 가격이나 계산 예시를 수익 실적으로 보고하지 않는다.

이번 문서 검사로 확인할 수 있는 것은 원고의 연결·분기·숫자·참조다. **학생이 재미와 변화를 체감하는지, 배운 표현을 새 상황에서도 쓰는지는 구현 후 실제 관찰과 학습 평가가 필요하다.** 그 확인을 위해 이제 사용할 장면과 질문, 실패 조건까지 준비한 상태다.
