## 밟은 함정

- Bash 도구의 heredoc 안 JS에서 `\\(` · `\\s`가 벗겨진다 → 고침 스크립트는 Write로 파일에 써서 돌렸다.
- Git Bash의 `grep '[가-힣]'`은 「—」 · 「’」 · 「·」가 든 줄까지 잡는다 → 한글 찾기는 node로.
- `lab()` 안에 지역 변수 `O`가 있어 묶음의 `O`(old 표)를 가렸다 → `N`으로 바꿈. 조립에 새 지역 변수를 둘 때 `K` · `O` · `PRE` · `LANG`을 피한다.
- 주장 줄(`h1 > span`)은 화면 끝까지 가는 블록이라 `getBoundingClientRect`로는 글 폭이 안 나온다 → Range의 `getClientRects`로 잰다(`spans.cjs`).
- `npm run check`는 첫 `node --test`가 깨지면 영어 묶음을 안 돌린다.
- 영어 문자열 치환을 한 스크립트에서 여러 번 걸 때, 긴 문장 치환이 그 문장을 품은 다른 줄(description)을 먼저 바꿔 뒤 치환이 「없음」으로 멈춘다 — 순서를 보거나 품는 쪽을 뺀다.
