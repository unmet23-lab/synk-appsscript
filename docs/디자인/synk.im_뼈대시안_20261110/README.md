## 지은 것

**홈(두 판 공통, 입구 아래):** 회사 한 문장 + 살아 있는 증거 하나(공개본 `#learner` 무대 · 시간 줄 그대로, 밤 바탕이 입구에서 끊기지 않고 이어짐) → 문 넷(제목이 곧 묶음: 「배우는 사람에게도,」 LAB · PATH / 「맡기는 회사에도」 SHIFT · PULSE, 문마다 공개본 무대 · 한 문장 · 「지금」 한 줄) → 최근에 새로 연 것(날짜 줄을 키움) · 지키는 것 셋 · 플랫폼 한 줄(「PC 앱 받기」를 누르면 공개본 내려받기 단추가 펼쳐진다) → 묻기 · 바닥. 상황극 띠 · 여덟 엔진 구역 · 창업자 띠 · 내려받기 구역은 홈에서 뺐다.

- **판 가:** 입구 짜임 그대로(물음 + 문 넷), 한 줄만 「한 사람에게 맞추는 AI를 만듭니다. 한국어 교육에서 시작했습니다.」(한 단계 키우고 또렷하게). 쪽 주장은 입구 바로 아래에 견본선 사이로 놓이고 곧바로 증거가 온다(회사 설명은 증거 제목 오른쪽 받침 글 — 판 나와 같은 머리).
- **판 나:** 문 넷 자리에 회사 문장 하나(쪽 주장) + 「한국어 교육에서 시작했습니다.」 + 단추 하나(「지금 돌아가는 모습 보기」). 입구 아래는 바로 증거이고 회사 설명은 그 오른쪽 받침 글. 방문 집계 안내는 바닥 줄로 옮겼다.

**SHIFT:** 첫 화면(밤 무대) — 「AI 강의가 끝나면, / 결과물 하나가 남습니다」 + 단추 「강의 의뢰 · 자동화 의뢰」 + 큰 예약표(줄 이름은 리라이팅 제안, 「이 예약표를 만들고 돌리는 사람이 직접 강의합니다」로 제목과 표를 이음, 숫자 셋은 문장으로, 주장 띠 오른쪽에 예약표의 시계, 50분 수업 예시에서 남는 것 한 줄) → 강의 방식(세 줄 + 공개된 50분 수업 예시를 분 길이만큼 넓은 칸으로) → 하는 일(서비스 넷을 한 줄씩 + 문의 단추 + 펼치기, 자동화 흐름 넷은 자동화 줄 안에) → 강사(「위 예약표를 만들고 돌리는 사람이 직접 강의합니다」가 제목) → 비용 → 의뢰(밤) → 묻기(질문창만 — 메일 · 양식 줄은 의뢰 띠로 올림) → 알아 두실 것. 「덧붙인 셋(준비 중)」 구역은 빼고 의뢰 띠의 한 줄로. 값 · 범위는 공개본에 적힌 것만 썼다.

**스크립트:** 네 무대의 상영은 `skeleton.js`가 맡는다(공개본 `home-v12.js`는 네 칸이 옆으로 나란한 짜임에 맞춘 것이라 시안에서는 싣지 않는다). 넓은 화면은 차례로, 좁은 화면(문이 세로로 쌓임)은 화면 가운데에 가장 가까운 문 하나만 상영한다 — 1440 · 1024 · 390 폭에서 확인했다.
