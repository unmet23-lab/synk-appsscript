2. **홈 시안 두 판**(다섯 화면 안팎)
   - 판 가: 지금 입구 짜임 그대로(처마 · 싱ㅋ · 견본선 · 「어떤 일로 오셨어요?」 · 문 넷), 입구 한 줄만 새 문장
   - 판 나: 처마 · 싱ㅋ · 견본선은 그대로, 문 넷을 한 화면 아래로 내리고 그 자리에 회사 문장 하나
   - 입구 아래(두 판 공통): 회사 한 문장 + 살아 있는 증거 하나(공개본 `#learner` 30일 체험 실물 그대로) → 문 넷(배우는 사람 LAB · PATH / 맡기는 회사 SHIFT · PULSE, 문마다 그 사업의 실물이 큰 줄) → 최근에 새로 연 것(날짜 줄, 지금보다 크게) → 묻기 · 바닥
   - 홈에서 빠지는 것: 상황극 띠(LAB에 있음) · 여덟 엔진 구역(아틀라스 쪽) · 창업자 띠(11-09 확정) · 플랫폼 내려받기 구역(한 줄 링크로)
3. **SHIFT 시안**(여섯 화면 안팎) — 첫 화면은 새 제목 + 예약표(크게, 설명과 함께, 줄 이름은 리라이팅 제안) + 제목과 맞는 단추(강의 의뢰 · 자동화 의뢰) → 무엇이 남나 → 하는 일(강의 먼저, 서비스마다 다섯 칸 본문 대신 한 줄씩 + 펼치기) → 강사(「위 예약표를 만들고 돌리는 사람이 직접 강의합니다」를 맨 위) → 비용 → 맺음. 제공 범위 · 값은 공개본에 적힌 것만 쓴다(11-10 수업 재설계는 로컬 준비라 공개 확정이 아니다). 수업 장면 · 결과물 그림은 지어내지 않는다 — 공개된 「50분 수업 예시」에서 쓸 수 있는 것만.
4. **재기** — `../synk.im_전체판단_20261110/재기/찍기.cjs`에 `ORIGIN=http://127.0.0.1:<포트>`를 주어 관문 표의 값(크기 · 굵기 가짓수, 영문 대문자 · 모노 덩어리, 화면 수, 「준비 중」 수)을 공개본과 나란히 잰다.
5. **맹검** — 아래 물음 그대로 `node tools/아르곤웹.js 보내기 <작업.json> --이름 <줄 이름>`(한 대화 그림 4장, 화면은 `화면NN.jpg`로 이름을 바꿔 보낸다). 홈은 판마다 따로(컴퓨터 첫 화면 · 휴대폰 첫 화면 · 한 번 내린 자리 · 문 넷 구역), SHIFT는 사업 물음으로.
6. **보이기** — 공개본과 나란히 놓은 비교 쪽(claude.ai 페이지 + 로컬 주소): 전 · 후 그림, 잰 값 표, 맹검 점수 전 · 후. 제목은 낱말이 아니라 실제 화면에 얹은 그림으로 보인다. 고르실 것: 입구 가 · 나, 회사 한 줄.

## 지킬 것

- 처마 입구의 그림(밤하늘 · 처마 · 싱ㅋ · 견본선)과 실물(30일 체험 · 예약표 · 쇼릴 · 상황극 무대 · 캐스팅북)은 다시 굽지 않는다. 입구 스타일(`.gate*`)은 원고에서 sha256으로 잠겨 있다 — 시안은 시안 전용 CSS로 덮고, 잠금 갱신은 공개 때 일이다.
- 홈에 창업자 사진 · 이름을 넣지 않는다(11-09). 사이트에 AI 도구 이름을 적지 않는다. PULSE 제목 · 소개 줄은 확정본 그대로.
- 공개(`tools/공개.js`)와 원고 수정은 하지 않는다. 유호님이 고르신 뒤다.
- 전체 판단 폴더와 트랙 한 줄은 origin에 올라가 있다(`05ecd574c6`, 11-10 05:43). 그때 공용 작업본이 origin을 바로 못 따라가(다른 세션이 올리는 중) 그 폴더가 로컬에서 미추적으로, 트랙이 고친 것으로 보일 수 있다 — 따라가기가 풀어 준다. 이날 새벽에는 PC가 바빠 `바로올리기 --실행`의 관련 시험이 14분 걸렸으니 뒤에서 돌린다.
