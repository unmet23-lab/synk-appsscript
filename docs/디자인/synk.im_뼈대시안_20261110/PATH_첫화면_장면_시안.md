# PATH 첫 화면 장면 시안 (2026-11-13)

조율은 판단 세션(「synk.im 홈페이지 프론트 평가」)이 하고, 이 기록은 그 곁 세션이 남긴다. 틀은 [뼈대.md](뼈대.md), 앞 단계는 [4단계 기록](4단계_기록.md). **공개하지 않았다** — synk-policy에는 아무것도 올리지 않았고, 첫 화면 실물을 바꾸는 일이라 유호님이 시안을 보고 고르신 뒤에만 올린다(10-30 LAB 첫 화면을 구조 승인만으로 바꿨다가 되돌린 일).

## 유호님 말씀

- 11-13, 전후 비교 쪽에서 11-10 PATH 휴대폰 첫 화면을 보고: 「그리고 이 지도 상당히 좋아보이긴하는데 이것도 넣으면 안되려나 ?」
- 같은 날 이어서: 「웅 path 화면 구성이 나쁘다는건 전혀 아니고 지금 첫 화면 시작하자마자 면접관의 얼굴들이 너무 인상이 ㅋㅋㅋ 면접 분위기가 첫 화면에 바로 보이니까 좀 별로야. 그래서 이 장면을 다른 장면으로 바꾸면 어떨까싶어. 면접관얼굴 안보이고 vr 기능을 어필해주든 지금 "한국에 오기 전에,먼저 해 봅니다." 이걸 풀어서 vr기능으로 설명해주는거로 하면 될것같아.」

조율 세션이 둘째 말씀으로 범위를 바꿨다 — 쪽 구성(쪽 주장 → 둘째 화면 서울 하루 → 길 지도)은 그대로 두고, 첫 화면 영상 자리(면접관 셋이 정면으로 보는 영상) 하나만 바꾼다. 지도는 둘째 화면에 그대로 있고, 첫 화면에 걸치는 일은 장면이 정해진 뒤로 미룬다.

## 지금 사실(라이브 · 11-13)

- `synk.im/path/` 첫 화면(`section#top.k-sec.k-night`) = 머리 줄 「한국 유학 · 취업 준비」 → 쪽 주장 「한국에 오기 전에, / 먼저 해 봅니다」 + 받침 글 → 면접 줄 → 면접 무대(면접관 셋이 정면을 보는 듣기 영상 `strict-listening-720p.mp4`, 컴퓨터 1440에서 1360×380 · 휴대폰 390에서 350×219) → 대사 줄 「면접관 세 명이 기다리고 있습니다.」 + 「질문 먼저 들어 보기」 · 「60~90초 면접 시작」.
- 서울 하루 지도는 없어지지 않았다 — 둘째 화면 `section#travel`에 고르는 판 · 세 곳 카드까지 그대로다. 11-10에는 지도가 첫 화면 배경이었고, 맹검이 그 판을 「유학 · 취업 제목 아래 서울 나들이 위젯」으로 읽어(확신 2 · 선도 4) 첫 화면에서 내렸다.

### 맹검이 함께 짚은 것(장면 밖 — 고르시는 것과 따로)

1. **면접 줄의 「PC에서 바로 둘러보고, Quest에서는 목소리로 답합니다」** — 여섯 대화 모두 「나은 쪽의 가장 약한 곳」이나 ⑤의 까닭으로 이 줄을 짚었다(말하기 답은 Quest가 있어야 한다고 읽힘). 라이브는 여섯 가운데 다섯이 ⑤ 「예」. 실제 면접실은 PC에서도 마이크로 답할 수 있어 이 줄은 사실과 어긋난다 — 고칠 글의 꼴은 「PC에서는 글이나 마이크로, Quest에서는 면접실에 앉아 답합니다」처럼 기기마다 하는 일을 적는 쪽(문장은 유호님 확인 뒤).
2. 「한국 유학 · 취업 준비」 머리 아래 첫 연습이 요양보호사 면접 하나라 좁아 보인다(여섯 모두). 없는 연습을 보일 수는 없으니 지금 열린 범위를 말하는 방식의 문제다.
3. 휴대폰에서 바로 쓸 수 있는지 말이 없다(휴대폰 대화 셋). 휴대폰 면접실이 끝까지 되는지는 확인 안 함.

## 추천

**가 「집에서 먼저」.** 셋 가운데 두 기기 맹검에서 모두 라이브보다 낫고 차이가 크다는 답이 나온 판은 이것 하나다. 첫인상이 「긴장 · 압박」에서 「편안 · 기대」로 바뀌었고, 노트북 · 이어폰으로 연습하는 모습이라 기기가 없어도 된다고 읽혔으며(⑤ 아니오 둘), 쪽 주장 「한국에 오기 전에, / 먼저 해 봅니다」를 그대로 그림으로 보인다. 남는 것: 노트북 화면 속 면접관 얼굴이 작게(약 20px) 보인다.

## 고르신 뒤 남은 걸음

1. 고른 판만 남기고 빌드 스위치 · 다른 판의 코드와 그림을 걷는다 → 원고 시험(`npm run check`) → 공개 후보 → 화면 검수(카본 → Fable 5.2) → `tools/공개.js`로 공개 → 라이브 확인.
2. 가를 고르시면: 노트북 화면 속 면접관 얼굴도 흐리게 할지 여쭙고, 그러면 같은 카본으로 한 번 더 굽는다.
3. 면접 줄 글(위 「맹검이 함께 짚은 것」 1) — 장면과 따로 여쭙고 고친다.
4. 영어 PATH(`/en/path/`)는 같은 판을 고르신 뒤에 맞춘다(이번에 손대지 않음).
5. 첫 화면에 지도를 걸치는 일(멈춘 지도 판 가 · 나)은 장면이 정해진 뒤에 다시 본다.
