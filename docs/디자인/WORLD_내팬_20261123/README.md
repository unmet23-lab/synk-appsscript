# 서울행 「내 팬」 시안 (2026-11-23, Claude)

설계는 [팬설계.md](../../../experiences/seoul-arrival/팬설계.md)에 있다. 이 폴더는 휴대폰 크기 시안이다.

- `시안.html`: 누르면 동작하는 시안. 장면 끝에서 팬이 말하는 방식 셋(A 팬 댓글 · B 최애 팬 한 명 · C 객석에서)을 바꿔 볼 수 있고, 「사흘 뒤」 · 「일주일 뒤」로 기다림 알림과 팬레터를 볼 수 있다.
- `img/`: 서울행 `arena-base.webp`에 `arena-seats.webp`의 앞줄 세 사람과 첫 친구를 자리표(`data.mjs` ARENA)대로 얹은 그림, 그리고 그 얼굴을 자른 그림이다. 새로 굽지 않았다.
- `맹검/`: 카본 미학 맹검(`world-fans-20261123`)에 보낸 첫 판 캡처. 네 장 모두 기각(3~4점)이었다. 지적에 따라 어절이 줄 끝에서 끊기던 것, 객석 사진과 같은 얼굴을 옆 사진에 또 쓰던 것, 「팬 4명」과 말한 팬 셋이 어긋나던 것, 「다음 팬」이 단추로 안 보이던 것, 근거를 줄임말 알약으로 적던 것, 튜터 말과 팬 말을 같은 테두리 상자에 담던 것, 내 팬 화면의 막대와 눈금이 어긋나던 것을 고쳐 보였다. 앞줄 열 자리를 얼굴로 채우는 줄이 막대를 대신한다.

글꼴(`fonts/`)과 소리(`snd/`)는 저장소의 원본(`experiences/brand-opening/assets`, `experiences/seoul-arrival/assets/snd`)을 공개할 때 함께 싣는다. 로컬에서는 `.claude/launch.json`의 「내팬시안」이 `.tmp/fan-mockup-1123`(같은 파일을 모은 폴더)을 띄운다.
