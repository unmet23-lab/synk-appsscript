# 브랜드 페이지의 단락별 이미지

2026-09-19 사용자 요청: 한 브랜드 페이지 안에서 큰 설명 이미지가 반복되지 않도록 각각 다른 이미지를 새로 만든다.

- 활성 원본과 프롬프트, 참고 이미지, 사용 위치, SHA-256은 [정본.json](정본.json)에 있다.
- 새 원본 17장: LAB 12장, SHIFT 3장, PULSE 1장, PATH 1장. 기존 대표 이미지와 PULSE의 제주·한옥 캐릭터 장면은 유지한다.
- 같은 단락의 탭들도 각기 다른 이미지를 사용한다. 헤더 로고와 작은 탐색 아이콘의 반복은 이 교체 범위에 포함하지 않는다.
- 제작 경로는 내장 `image_gen.imagegen`이다. 사용자는 GPT 2.5 이미지를 요청했지만 도구에 모델 선택 항목이 없어 특정 모델로 생성했다고 단정하지 않는다.
- 흰 배경, 짧고 촘촘한 펠트 섬유, 바느질, 실제 접촉 그림자를 유지한다. 원본을 덮어쓰지 않고 장면별로 보관했다.
- 한국어 교재와 동작 카드의 글자, 물체의 형태와 접촉, 장면의 용도를 실제 결과로 검토했다. 댄스 장면의 발레 소품이 K-POP에 맞지 않아 운동화·스피커·클래퍼보드로 재생성했다.
- 홈페이지 `sync-section-art.mjs`가 원본 해시를 확인하고 1120px WebP 90으로 내보낸다. `visual-explainers.mjs`에서 각 탭에 연결한다.

이는 학습·업무·음악을 설명하는 펠트 모형 이미지이며 실제 운영 시설이나 실물 제품의 사진은 아니다.
