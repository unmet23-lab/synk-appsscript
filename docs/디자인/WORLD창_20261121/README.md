## 바꾼 짜임

- 창을 「연습」과 「내 SYNK ID」 둘로 나눴다. 첫 화면은 연습이다. 이어서 할 게임 단추 하나, 이번 주 숫자 셋, 연습 방식, 게임 아홉 가지가 있다.
- 「내 SYNK ID」는 줄에 매단 학생증 한 장(강사는 강사증)과 조용한 줄 목록이다. 줄은 학습 기록 연결, 내 반, 내 학습 요약, 마을 기록, 로그인한 곳, 이용 권한, 연습 기록 내려받기다. 로그아웃과 계정 지우기는 맨 아래 글 단추로 둔다.
- 화면에서 뺀 것: 계정 번호(UUID) 원문, 불러온 뒤에도 남던 「계정 정보를 불러오고 있어요」 줄, 줄머리 「-」, 「교사」와 「강사」가 섞이던 이름(「강사」로 하나). 계정 번호는 학생증 뒷면의 「문의할 때 쓰는 번호」로만 보이고 복사할 수 있다.
- 창 제목은 「SYNK ID 로그인」 대신 「SYNK WORLD」다.
