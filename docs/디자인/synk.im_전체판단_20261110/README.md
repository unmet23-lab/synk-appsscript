## 지킬 것 · 문제

**지킬 것:** 처마 입구(「어떤 일로 오셨어요?」 · 문 넷 포함) · PULSE 첫 화면(쇼릴 + 11-07 제목) · 「틀린 말은 1분 뒤에, 맞힌 말은 잊을 때쯤 돌아옵니다」와 30일 체험 · SHIFT 실제 예약표 · LAB 상황극 무대 · 속도와 출시 기록.

**문제(큰 순서):**

1. 홈이 회사를 한 문장으로 말하지 못한다 — 주장 여섯, 그중 「같은 엔진으로 네 가지 일」은 증거가 SYNK WORLD 한 곳뿐이다. 비전을 바꾸자는 것이 아니라 증거가 있는 만큼만 제목으로 말하자는 것.
2. 입구만 SYNK이고 그 아래는 흔한 틀 — [점 + 영문 대문자 꼬리표 + 한글 꼬리표] → 두 줄 제목 → 오른쪽 회색 본문 → 01 · 02 · 03 열 → 알약 단추, 움직임은 떠오르기 하나. 영문 꼬리표는 옆 한글 꼬리표와 같은 말이다.
3. 글자 체계가 없다 — 위 표. 구역을 하나씩 고칠 때마다 가짓수가 늘었다.
4. 방어하는 말이 파는 말보다 많다 — 「준비 중」 31번, 본문 안 면책, 「가상」 11번.
5. 쪽이 무대가 아니라 목록이다 — 휴대폰 LAB 18.9 · PULSE 17.4 · SHIFT 16.3화면, SHIFT는 5,870자에 큰 그림 0.

**사업별:** PULSE — 덜어내기만(「가상」 한 번으로, 값 문장을 첫 화면으로). SHIFT — 첫 화면 뒤 여덟 화면이 글뿐, 제목이 업종 나열, 11-10 방향(교육 먼저)과 쪽의 무게가 다르다. LAB — 무대를 첫 화면으로(11-06에 만족하신 무대 구성은 그대로), 본 쪽은 상황극 1화 + SYNK WORLD만, 과정 · 교재는 따로. PATH — 제목은 유학 · 취업인데 첫 화면은 서울 나들이, 면접 연습을 첫 화면으로. 아틀라스 — 엔진 이름 여덟이 증거 자리에 있다, 30일 체험을 첫 화면으로 · 밖으로는 세 동사(이해 · 맞춤 · 확인), 여덟 이름은 아래 표로.
