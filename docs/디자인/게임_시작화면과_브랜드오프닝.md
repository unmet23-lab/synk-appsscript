# 게임 시작 화면과 SYNK 브랜드 오프닝

> 2026-10-09 · 사용자가 게임 앱의 제작사·사용 엔진 시작 화면을 질문한 뒤 「준비하자」고 요청했다. 공통 자산을 준비하는 결정이며, 아래 첫 연출·소리 후보의 최종 채택과 설치형 출시를 뜻하지 않는다.

## 목적과 순서

앱을 켠 사람이 SYNK가 만든 세계에 들어왔음을 짧게 알아보고, 기다림 뒤 다음 행동을 바로 알게 한다. 회사 소개 문장이나 여덟 엔진 설명을 시작 화면에 늘어놓지 않는다.

| 구간 | 첫 시안 | 다음 행동 |
|---|---|---|
| 제작사 | 검정 바탕, 승인된 Paper 펠트 `synk` 원본. 은은한 배경 광원과 부드러운 정착. `CREATED BY SYNK` | 약 2.6초 뒤 제품 타이틀로 연결. 언제든 건너뛰기 |
| 사용 기술 | 실제 출시판의 구동 엔진 표기를 제품별로 연결하는 자리 | 현재 시안에는 미표시. Unity·Unreal을 사용한 출시판인지 확인 후 해당 표기 기준 적용 |
| 게임 타이틀 | 세 친구가 함께한 실사 펠트 한국 풍경의 Gemini Omni 영상, 로고와 WORLD, 「몽글과, 나의 작은 세계.」 | 화면 전체 터치/클릭·Enter/Space → 한강 마루 → 놀이 선택 |

Atlas는 Core·Loom·Vellum·Trail·Prism·Temper·Reed·Strata의 총칭이다. 넣을 때는 개인화 기술 크레딧으로 역할을 구분한다. 현재 타이틀 배경은 생성한 사진형 펠트 장면이며 게임플레이의 3D 렌더나 Unity·Unreal 렌더로 소개하지 않는다.

## 공통 자산

- 로고 정본: [중립색 로고](../로고_중립색_정본_v1.md)와 사진형 펠트 킷의 `배치용/SYNK-Paper.png`. 네 글자의 비율·색·펠트 섬유·무실땀 정책을 유지한다. 빛은 로고 뒤의 별도 레이어로 둔다.
- 시작 조작: 2026-10-10 사용자 요청으로 「게임 스타트」·「바로 시작」·「영상 멈추기」를 제거했다. 화면 전체가 시작 조작 범위이며 작은 터치/클릭 안내만 남긴다. 소리는 우측 상단 기존 펠트 스피커 아이콘과 48px 조작 범위로 제공하고 별도 동작한다. WORLD는 가는 글자와 넓은 자간으로 정리한다.
- 오프닝 소리: 0.38초의 사인·트라이앵글 C5–G5–C6 후보. WAV·합성 소스·측정값을 준비했으며 [사운드킷](../브랜드_사운드킷/_사운드킷.md)의 확정 이벤트로 등록하지 않았다. 청취 후 채택 여부를 정한다.
- 웹 런타임과 원본 목록: [공통 오프닝](../../experiences/brand-opening/README.md).
- 현재 웹 영상: Google Cloud `gemini-omni-1.1-flash-preview` **v9 새 생성 + 배경 고정 마감**, 세로·가로 각 1080p·24fps·10초. 사용자가 v6의 떨림을 지적해 새로 생성했으며 새 원본에 남은 미세 떨림은 그 영상의 첫 프레임에 맞춰 지붕·타워·도시·마루를 고정하는 후처리로 잡았다. 세 친구 전체·하늘·물결과 배·잎·등은 계속 움직인다. 얼굴·머리·배를 각각 붙이지 않았다. [HyperFrames 소스와 내보내기](../../videos/synk-brand-opening/README.md)의 회사 단독 2.6초는 보존하며, WORLD 합본과 v5 전달 ZIP은 이전 Veo 출력 기록이다. 이번 변경은 웹 공통·모바일·PC 입구와 새 Omni 원본/마감/웹 MP4에 적용했다(2026-10-10).

마린은 머리 하나와 노란 펠트 부분을 유지하고, 몽글에 입을 만들지 않는다. 가까운 나무·잎이 먼 강 위의 배를 가린다. 현재 v9는 **10초 전체를 반복**하고 별도 영상 조작 문구는 표시하지 않는다. 모션 감소 설정은 포스터를 사용한다. 저작권은 **© 2027 SYNK**다. v3 합성 오류, v4 재질 변화, v5 꼬리 반복, v6 떨림, v7 눈 변형·떨림은 제외했다. [실제 v9 점검](../../experiences/brand-opening/qa/felt-v9/visual-review.json). 얼굴·가림·마감 경계는 검수 표본을 통과했으며 움직이는 펠트 결·물결·잎의 첫/끝 픽셀 차이는 남는다.

**실제 앱 연결 · 2026-10-10:** `/`, `/mobile.html`, `/desktop.html`과 정적 `/world/` 빌드의 기본 입구를 한강 마루로 통합했다. 시작 화면의 영상 위치를 마루에 넘기고, 회전 때 방향별 영상을 선택하되 게임 문서는 유지한다. 옷장·첫 문장 놀이·타운·계정별 서버 저장은 기존 앱 계약을 사용한다. 계정 모드 미니게임은 공식 게임/학습 host를 부모 앱에서 준비한 뒤 같은 origin iframe으로 연다. 게임 닫기는 미디어·학습 포트를 정리하고 마루로 돌아온다. [앱 통합 검수](../../experiences/synk-world-app/qa/maru-integration-20261010/README.md). 공개 배포·실물 기기 검증과 구분한다.

회사 오프닝을 미니게임마다 중복 재생하지 않는다. WORLD 안에서 미니게임을 열 때는 해당 게임의 기존 입구를 사용한다. 독립 앱으로 내보낼 때 공통 회사 구간과 그 게임 타이틀을 연결한다.

### 오프닝 다음 홈 · 2026-10-10 시안

사용자가 다음 화면을 만들어 보여 달라고 요청해 [나의 마루](../../experiences/brand-opening/HOME.md)를 구현했다. 이어 「모바일 기준으로, 게임앱처럼」 요청에 따라 카드형 홈을 전체 화면 한강 마루로 바꿨다. 살아 있는 풍경·세 친구 위에 상단 프로필/설정, 하단 ‘놀러 가기’와 네 메뉴를 둔다. 스크롤 없이 머물고, 놀이 선택창이 아래에서 열리며 실제 세 게임에 들어갔다 돌아올 수 있다. 이후 「둘 다 준비해서 원하는 모드로」 요청으로 설정에 자동·세로·가로 선택과 저장을 추가했다. 폰은 실제 기기 방향에 맞춰 배치하고 선택과 다르면 회전을 안내하며, PC는 선택한 비율로 프레임을 전환한다. 게임 iframe은 방향 전환 중 유지한다. 독립 오프닝 시안의 시작 뒤 연결되며, 기존 전체 앱의 3D 홈·계정 연결·운영 게임 분기를 교체한 것은 아니다. 현재 결과를 보고 홈 방향을 판단하는 로컬 시안으로 구분한다.

### 가로·세로 동시 지원 확정 · 2026-10-10

사용자가 「가로세로 둘 다 지원하는 걸로 가자. 게임 중에 돌려도 진행 안 끊기고 화면 안 깨지도록 제대로 검수」를 요청했다. 화면 방향은 같은 게임 상태의 배치만 바꾸며 문제·진도·점수·음성을 새로 시작하지 않는다. 바람길의 회전 중 잘못된 제스처 입력, 작은 가로의 무대 축소, 리듬의 문항/O·X 겹침, 한글의 고정 다음 버튼 가림을 수정했다. 실제 홈 iframe에서 바람길 90초·리듬 202.68초 완주와 한글 두 회차·복습 노래 회전을 검사했다. [v4 시나리오·결과·화면](../../experiences/brand-opening/qa/maru-v4/README.md). 브라우저 검증과 실물 휴대폰/네이티브 앱 검증은 구분한다.

## 시작·복귀·오류

웹에서는 로딩과 계정 복원을 오프닝 뒤에서 진행하고, 시작을 누른 뒤 기존 흐름을 연다. 오프닝이 가리는 동안 홈의 연속 3D 렌더는 정지한다. 건너뛰기·Escape·움직임 감소를 지원하고, 모듈이나 자료를 불러오지 못해도 입구를 영구히 막지 않는다.

첫 실행의 소리는 브라우저의 사용자 조작 뒤 재생한다. 앱의 사운드 설정·OS 볼륨 정책은 실제 네이티브 호스트에서 연결한다. 현재 같은 탭의 재방문 생략은 `sessionStorage`에 비밀이 아닌 표식 하나만 남긴다. 앱 종료 후 재실행·백그라운드 복귀·OS 시작 화면은 실제 앱에서 별도로 검사한다.

설치형 시작 화면에는 먼저 승인 PNG를 사용하고, 이 공통 연출을 이어 붙이는 방향으로 준비한다. 현재 C# 실행·Android/iOS 패키지에 반영된 결과나 실물 기기 성능으로 보고하지 않는다.

## 현재 확인 범위

현재 v9로 **100개 브라우저 검사**를 통과했다. 폭 320·390·1440px와 가로 화면의 문구·진입·소리·키보드·모션 감소·앱 연결을 확인했다. [현재 결과](../../experiences/brand-opening/qa/felt-v9/browser-result.json). 고정 구조물 세로 7곳·가로 8곳을 각각 240프레임 전체와 반복 경계에서 추적해 15곳 모두 프로젝트 기준을 통과했다. 얼굴·배·경계는 방향별 21개 표본과 문제 구간 확대 대조로 독립 검수했다. [시각·떨림 근거](../../experiences/brand-opening/qa/felt-v9/visual-review.json). [자연 반복 검사](../../experiences/brand-opening/qa/felt-v9/full-loop-playback.json)는 비율별 23.5초 재생에서 전체 두 번 반복·프레임 변화·화면 위치 고정을 확인하는 기록이다.

소리의 파일 재생 진행은 확인했으며 청취 취향의 채택·스피커 품질은 확인하지 않았다. 로컬 시안과 공개 배포, 영상 내보내기와 실제 앱 적용, 브라우저 화면과 물리 휴대폰을 구분한다.
