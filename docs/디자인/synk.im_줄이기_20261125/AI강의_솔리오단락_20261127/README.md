# AI 강의 쪽(/ai/)의 솔리오 단락 (2026-11-27, 둘째 판을 보여 드림)

- 11-26 밤: 「ai 강의쪽에서 우리 솔리오 앱을 어필해주는 단락이 하나 있으면 좋겠고」.
- 11-27, 가 · 나 첫 판을 보시고: 「가 가 좋은데 원클릭으로 사업계획서,보안,백업,사무실 이런것까지 전부 신경써서 만들고있는걸 보여줬으면 좋겠어. 지금은 그게 하나도 안보이네 ㅠ」
- 이어서: 「ai 1인 창업가(기업가) 를 위해 필요한 모든것들을 준비하고있다는걸 어필해줬으면 좋겠고 3000시간 및 5천만원으로 지금 ai 경험과 테스트한걸 전부 하네스로 자동 적용해 번거롭지않고 최적의 ai를 활용한 1인기업가를 위한 앱이라는 어필이 간결하고 명료하게 표현되었으면 해」

## 둘째 판

- **자리.** 증거 목록 셋째의 작은 「솔리오 앱」 칸을 걷고, 강사 구역 바로 앞에 단락 하나를 둔다. 바탕은 고르신 가(쪽 바탕 그대로)다.
- **글.** 제목은 「AI 1인 기업가에게 필요한 것을 솔리오 하나에 준비하고 있습니다」, 이끄는 글은 「3,000시간과 5천만 원을 들여 AI로 일하며 시험한 방법을 솔리오가 자동으로 적용합니다. 번거로운 설정 없이 가장 알맞은 AI로 일합니다.」다. 「하네스」는 처음 읽는 사람이 모르는 말이라 「자동으로 적용합니다」로 풀었다.
- **줄 여섯.** 한 번에 처리 · 사무실 · 사업계획서 · 원클릭 백업 · 보안 · 구독을 고르면 그 화면과 한 줄 설명이 바뀐다. 자판은 왼쪽 · 오른쪽 화살표와 Home · End로 옮긴다. 휴대폰에서는 줄이 옆으로 밀린다.
- **젤리 줄(11-27).** 처음에는 칸마다 테두리 알약을 두었다. 유호님이 「ai티나 슬롭티」를 빼고 「3d나 젤리같은걸」 써 보자고 하셨고, 회색 홈 안에 고른 칸만 말랑한 흰 알약이 떠 있는 줄로 바꿨다. 다른 칸을 누르면 알약의 앞쪽 끝이 먼저 닿고 뒤쪽 끝이 따라오며 살짝 눌렸다 돌아온다(0.48초, 닿기까지 약 0.2초). 움직임 줄이기를 켠 사람에게는 바로 옮긴다. 탭마다 3D 물건을 붙이는 길은 솔리오 구의 「대놓고 3d라 촌스러운」 지적과 같은 길이라 쓰지 않았다. 유호님: 「굿 훨씬 낫다.」
- **화면.** 사업계획서만 지금 다듬고 있는 시안(`솔리오_사업계획서_검토화면_20261126/캡처/w05_점수판.png`)이고 그렇게 적었다. 나머지 다섯은 솔리오 PC 앱의 실제 화면이다. `desktop/tools/orb-face-browser-qa.cjs`를 `ORB_QA_ONLY=todo` · `21` · `22` · `18` · `20`으로 돌려 찍었고, 이름과 숫자는 시험 자료의 예시 값이다. 「한 번에 처리」 카드는 그대로 찍으면 앞 장면이 찍혀서, 카드를 연 뒤 3초 기다려 찍었다.
- **사실 확인.** 사무실은 「일 맡기기는 아직 준비 중」이라 맡긴다고 쓰지 않고 「무엇을 하는지, 누가 승인을 기다리는지 보인다」로 썼다. 보안 줄은 앱의 문구(「이 PC에만 암호화해 둡니다」, 「로그인 정보와 사용량은 이 PC 밖으로 나가지 않습니다」)를 따랐다.
- **스타일.** 단락 스타일과 줄 바꾸는 스크립트는 쪽 안에 둔다. 공용 `detail.css`는 건드리지 않는다.

## 짓는 법

```
python -X utf8 짓기.py <작업 폴더>
```

작업 폴더에는 공개본 사본 `live/ai/index.html`과 그림 `img/solio-tour-<열쇠>.webp`(1440×820) · `img/solio-tour-<열쇠>-m.webp`(820×640)가 있어야 한다. 열쇠는 todo · office · plan · backup · safe · subs다. 결과는 `<작업 폴더>/tour/`에 쓴다. 지금 후보는 공용 작업본 `.tmp/공개후보/app-paras-20261127/`이다. 공개본 사본에 `live/en/ai/index.html`이 있으면 영어 쪽도 같은 짜임으로 짓는다. 영어 글은 「Everything a one-person AI company needs, coming together in SOLIO」이고, 그림은 한국어 화면 그대로라 작은 글에 「(in Korean)」을 붙였다. `예시자료.cjs`는 구독 화면에 넣은 지어낸 구독 자료(example.com)다.
