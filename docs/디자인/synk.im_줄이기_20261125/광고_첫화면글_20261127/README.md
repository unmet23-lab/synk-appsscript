# 광고 쪽(/studio/ · /en/studio/) 첫 화면 글 고침 (2026-11-27)

지금 공개본의 「카메라 앞에서 10년, 배우가」를 「한국 엔터테인먼트 산업 현장에서 10년」으로 바꾼다.

## 말씀

부모 세션이 전한 유호님 말씀이다.

- 「한국 엔터테인먼트 산업 현장에서 10년이라고 바꿔줘. 그 아래 내용들도 이걸로 바꿔줘」
- 바닥 방문 집계 한 줄: 「이 내용도 삭제해」

## 바꾼 것

- 첫 화면 제목은 「한국 엔터테인먼트 / 산업 현장에서 10년, / 그 눈으로 AI 모델을 연출합니다」다. 줄은 세 줄로 정해 둔다.
- 세 칸의 「10년」 아래 글은 「한국 엔터테인먼트 산업 현장 경험」이다.
- 연출 칸은 「현장 10년의 눈으로 / AI 모델을 연출합니다.」와 「한국 엔터테인먼트 산업 현장에서 일한 시간이 연출의 기준입니다.」다.
- 쪽 제목과 공유 제목은 「한국 엔터테인먼트 산업 현장 10년의 눈으로 AI 모델을 연출합니다」다. 공유 그림 `og/studio-ko.jpg` · `studio-en.jpg`는 후보 첫 화면을 1200×630으로 다시 찍었다.
- 영어 제목은 「Ten years in Korea’s / entertainment industry, / now directing AI models」다.
- 바닥의 방문 집계 한 줄을 뺐다. 집계 스크립트와 개인정보처리방침 설명은 그대로다.

하늘 판(`../광고_20261127/`)이 공개되면 본문 전체가 바뀐다. 하늘 판의 이끄는 글과 연출 칸도 같은 말로 바꿔 두었다.
