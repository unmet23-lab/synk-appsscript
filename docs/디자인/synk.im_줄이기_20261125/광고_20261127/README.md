## 지은 것

- **쪽.** 공개본 /studio/와 /en/studio/의 머리 · 메뉴 · 바닥은 그대로 두고 본문만 바꾼다. /pulse/는 PULSE 세션이 맡아 그대로 둔다. 새 홈의 광고 칸은 /studio/로 간다.
- **겉.** PULSE 의뢰서 3막의 하늘 결이다. 첫 화면은 시스루 문이 선 낮 하늘, 끝 화면은 「시스루」 뮤직비디오의 밤 장면(빛나는 문)이다. 먹색 `#0b1b30` 글자, 명조 300 제목, 누를 단추는 한 화면에 하나다. 노란 판의 짜임과 글은 그대로 두고 `광고_하늘.css`가 겉만 덮는다.
- **짜임.** 첫 화면(「브랜드를 드라마로 만드는 광고」와 작품 두 편 카드 더미) → 만드는 방식(「이름에서 이야기를 시작합니다」, 실제 영상과 세 칸) → PULSE 앱 단락 → 연출(이력 넷, 모델 열둘) → 의뢰(큰 「PULSE」). 내용은 줄이기 시안 `시안/pulse.html`의 짜임을 이었다.
- **작품 둘.** 도담중공업 「이 아이를 보냅니다」와 「다리가 기억하는 것」만 둔다. 시스루 카드와 고르기 칸은 11-27 밤 말씀으로 걷었다. 끝 화면의 밤 문 장면은 PULSE 의뢰서 3막의 문과 같은 그림이라 그대로 둔다.
- **이름이 나오는 때.** 공개본 영상에서 쟀다. 도담중공업 58.0초(1분 1초 편). 「다리가 기억하는 것」은 공개본이 11-27에 최종본(라x)으로 바뀌어 다시 쟀다. 1970 현수막 8초, 젊은 할머니가 서울에 오는 장면 29초, 제목 173.2초다(누르면 173.3초로 간다).
- **고르는 줄.** 작품 고르기와 앱 화면 고르기는 회색 홈 안에 고른 칸만 흰 젤리 알약이 떠 있는 줄이다(AI 강의 솔리오 단락과 같은 움직임, 「굿 훨씬 낫다」).
- **앱 화면 여섯.** 최신 PULSE 고객 앱(master)을 로컬 회사 서버로 띄워 지어낸 자료로 찍었다. 입장(내 광고 방과 모델 복도), 의뢰서 세 막(고르기 · 적기 · 보내기), 프로젝트 방 둘(모델 확인, 장면 이미지 확인)이다. 찍는 스크립트는 공용 작업본 `.tmp/공개후보/app-paras-20261127/s2/찍기.mjs`이다(`.tmp/pulse-app-rebuild-20261125/preview.mjs`의 방 만들기를 이었다). 장면 이미지 방은 「도담중공업 기업 홍보영상」 방으로 만들고 도담 영상의 자막 없는 세 장면(13초 · 34초 · 46초)을 장면 이미지로 올렸다. 앱의 예시 그림(첨벙댕)이 셋째 작품처럼 보이지 않게 하려는 것이다. 모델 방은 「오미톡 오미자 스파클링」 예시 방이다. 그림 아래에 「프로젝트 이름과 내용은 예시입니다」라고 적었다. 영어 쪽도 같은 한국어 화면이고 「(in Korean)」을 붙였다.
- **공개 때.** 새 입장 화면 · 방 · 세 막 의뢰서가 아직 고객 앱 공개본에 없다(11-27 21:30 `hall.mjs` 404). 회사 묶음에 실린 뒤 라이브에서 확인하고 공개한다. 그래야 「실제 화면」과 「광고 의뢰하기」가 맞는다.
- **글꼴.** SYNK Sans v11은 줄인 판이라 없는 글자 「옛」을 SUIT에서 덧 글꼴(`pulse-y-sans.woff2`, SYNK Sans Y)로 뽑았다. 명조는 이 쪽 글자만 남긴 Noto Serif KR 300(`pulse-y-serif.woff2`)이다. `짓기.py`가 지을 때마다 다시 뽑고, 두 글꼴 어디에도 없는 글자가 있으면 멈춘다.
