## 지은 것

- **쪽.** 공개본 /studio/와 /en/studio/의 머리 · 메뉴 · 바닥은 그대로 두고 본문만 바꾼다. /pulse/는 PULSE 세션이 맡아 그대로 둔다. 새 홈의 광고 칸은 /studio/로 간다.
- **겉.** PULSE 의뢰서 3막의 하늘 결이다. 첫 화면은 시스루 문이 선 낮 하늘, 끝 화면은 「시스루」 뮤직비디오의 밤 장면(빛나는 문)이다. 먹색 `#0b1b30` 글자, 명조 300 제목, 누를 단추는 한 화면에 하나다. 노란 판의 짜임과 글은 그대로 두고 `광고_하늘.css`가 겉만 덮는다.
- **짜임.** 첫 화면(「브랜드를 드라마로 만드는 광고」와 작품 세 편 카드 더미) → 만드는 방식(「이름에서 이야기를 시작합니다」, 실제 영상과 세 칸) → PULSE 앱 단락 → 연출(이력 넷, 모델 열둘) → 의뢰(큰 「PULSE」). 내용은 줄이기 시안 `시안/pulse.html`의 짜임을 이었다.
- **이름이 나오는 때.** 공개본 영상에서 쟀다. 도담중공업 58.0초(1분 1초 편), 「다리가 기억하는 것」 174.0초(2분 58초 편), 시스루 201.8초(3분 27초 편).
- **앱 그림.** 의뢰서 3막 「언제까지 받고 싶으세요?」의 실제 화면이다. 공용 작업본의 고객 앱 코드(커밋 79af7690a)를 로컬 회사 서버로 띄워 찍었다(`.tmp/pulse-app-rebuild-20261125/찍기/appflow.mjs`). 이 의뢰서는 11-28 17시 회사 묶음에서 고객 앱 공개본에 실린다. 그래서 이 쪽은 PULSE 세션의 라이브 확인(11-28 18:13) 뒤에 검수하고 공개한다.
- **글꼴.** SYNK Sans v11은 줄인 판이라 없는 글자 「옛」을 SUIT에서 덧 글꼴(`pulse-y-sans.woff2`, SYNK Sans Y)로 뽑았다. 명조는 이 쪽 글자만 남긴 Noto Serif KR 300(`pulse-y-serif.woff2`)이다. `짓기.py`가 지을 때마다 다시 뽑고, 두 글꼴 어디에도 없는 글자가 있으면 멈춘다.

## 짓는 법

```
python -X utf8 짓기.py <후보 폴더> <공개본 사본 폴더> <그림 폴더>
```

- 공개본 사본 폴더에는 공개본의 `studio/index.html`과 `en/studio/index.html`이 있어야 한다. 공개 직전에 공개본에서 새로 받는다.
- 그림 폴더에는 `pulse-sky.webp`, `pulse-night.webp`, `pulse-app-s.webp`, `pulse-app-s-m.webp`, `pulse-card-{dodam,opalin,bridge}-y.webp`, 공개본 `synk-sans-v11.woff2`가 있어야 한다.
