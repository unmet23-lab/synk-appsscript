# AI 강의 쪽(/ai/ · /en/ai/) 첫 화면과 증거 구역 다시 쓰기 (2026-11-27 시안)

첫 화면은 「AI를 어렵게 익힌 강사진이 쉽게 가르칩니다」로 바꾼다. 유호님 답을 받은 뒤 검수하고 공개한다.

## 말씀

부모 세션이 전한 유호님 말씀이다.

- 첫 화면을 보시고: 「이거 말투가 너무 이상해」
- 증거 구역을 보시고: 「이것도 별로야」
- 바탕 이야기: 「26년 6월 출시하고나서부터 ai가 일반인들에게도 활용할수있게 적용되었다고생각해 … 강사진은 26년 6월부터 오늘 11월 27일까지 … 5천만원 이상의 구독비 + 3천시간 이상의, 말 그대로 밥이랑 잠만 자고 ai만했거든 … 이 경험을 판다고 생각해주면 좋을것같아.」
- 50분 수업 예시 칸을 보시고: 「뭔 내용인지 하나도 이해가 안가. 삭제하던지 다시 만들어야해」
- 바닥 방문 집계 한 줄: 「이 내용도 삭제해」

## 바꾼 것

- 첫 화면 제목은 「AI를 어렵게 익힌 강사진이 / 쉽게 가르칩니다」다.
- 이끄는 글은 「2026년 6월, AI가 처음으로 누구나 쓸 만해졌습니다. 저희는 그때부터 먹고 자는 시간 빼고 AI만 썼습니다.」다.
- 세 칸은 「5천만 원 · 3,000시간」, 「컴퓨터가 낯설어도」, 「수업 뒤 2주」다. 숫자 칸은 읽는 사람이 얻는 것으로 끝낸다.
- 증거 칸은 「가르치는 방법으로 / 회사가 돌아갑니다.」다. 60가지는 창업자 쪽에 공개한 숫자다. 실시간 예약표는 그대로 둔다.
- 50분 수업 예시 칸은 지웠다. 출강은 2027년 2월부터라 실제 강의 결과물이 아직 없다. 강의를 시작하면 실제 결과물로 다시 짓는다.
- 쪽 제목, 설명, 공유 글을 새 글에 맞췄다. 공유 그림은 공개 때 후보 첫 화면을 1200×630으로 다시 찍는다.
- 바닥의 방문 집계 한 줄을 뺐다. 집계 스크립트와 개인정보처리방침의 설명은 그대로다.

## 짓는 법

```
python -X utf8 짓기.py <공개본 사본 폴더> <후보 폴더>
```

공개본 사본 폴더에는 지금 공개본의 `ai/index.html`과 `en/ai/index.html`이 있어야 한다. 시안 캡처는 공용 작업본 `.tmp/공개후보/ai-hero-20261127/캡처/`에 있다.
