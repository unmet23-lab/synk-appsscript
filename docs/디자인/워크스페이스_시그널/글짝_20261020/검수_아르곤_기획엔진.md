# 아르곤 검수 처리 — 기획 엔진 글 (2026-10-21 아침, gemini-4-argon medium · 구독 통로)

묶음 A(엔진 `content-engine.mjs` 짝 180개 + 합성 기획 둘을 내려받은 글, 124KB)·묶음 B(유형 자료 `content-catalog.json`·머리표 `benchmark.js` 짝 64개 + 제작 기준 창·데스크 「유형별 기획 양식」 열 유형의 화면 글, 43KB) 모두 입력 끝 표식까지 읽음. 지적 21건(A 16 · B 5) 중 18건 반영, 3건은 일부만 반영. 반영 짝: `짝/23-argon.json`.

| 지적 | 판단 | 처리·이유 |
|---|---|---|
| A1 「회사 참고 자료의 순서는 1 이상의 정수여야 해요.」에 다음 행동 없음 | 반영 | 조사 자료는 관리자가 올리는 것이라 「…가 아니에요. 관리자에게 조사 자료를 다시 올려 달라고 해 주세요.」 |
| A2 조사 시기를 읽지 못함 | 반영 | 같은 다음 행동. |
| A3 지정 시리즈를 읽지 못함 | 반영 | 같은 다음 행동. |
| A4 입력 칸 이름 「얻어 갈 것」·「끝까지 볼 이유」가 결과 화면 이름과 다름 | 일부 반영 | 「얻어 갈 것」은 결과 화면의 「얻어 갈 정보」로 모두 맞췄다(오류 칸 이름·내려받기 「적은 내용」·도움 축 이유·다음에 할 일·마무리 장면). 「끝까지 볼 이유」는 기획 쓰기 화면의 그 입력 칸 이름이라 입력을 가리키는 두 곳(오류·내려받기 「적은 내용」)에 그대로 두었다. |
| A5 문장형 주제가 낫표 없이 붙어 「…쓸 수 있을까에서」처럼 읽힘 | 반영 | 채울 자리 넷(질문·준비·비유·표현)에 「${주제}」 낫표. |
| A6 「이 유형의 이야기 구성을 찾지 못했어요.」 | 반영 | 「…다른 콘텐츠 시리즈를 골라 주세요.」 |
| A7 내려받기에서 「— 작성됨: 적은 내용(사실 확인 전): …」처럼 쌍점이 겹침 | 반영 | 적은 값 뒤에 「(사실 확인 전)」·「(이 시청자에게 맞는지 확인 전)」. 시험의 「확인 전」 단언은 그대로 통과. |
| A8 고를 쪽마다 나누는 장면에서 구성 방향(`angle`)과 잇는 뜻이 빠짐, 「고를 기준」이 칸 이름과 다름 | 일부 반영 | 뜻은 「이 구성의 방향에 맞춰」로 되살렸다. 구성 문장 전체를 낫표로 넣자는 안은 받지 않았다 — 마침표까지 든 문장이 「「…따라가요.」 방향에 맞춰」처럼 들어가 읽기 어렵고, 그 구성의 방향은 바로 위 구성 고르기 칸에 보인다. 값의 이름은 「상황마다 고를 수 있는 도움」. |
| A9 참고 메모의 「검토 전」·「이 안의 전개로」가 빠짐 | 반영 | 「참고 메모(확인 전) · 도입: … (우리 자료와 이 구성에 맞게 바꿔 쓰기)」 |
| A10 적은 근거 줄마다 「입력 자료, 검토 전」이 빠짐 | 일부 반영 | 줄마다 붙이면 같은 꼬리가 네다섯 번 겹쳐서, 묶음 머리에 한 번 — 화면 「적은 근거 · 확인 전」(`benchmark.js`), 내려받기 「적은 근거(확인 전):」. |
| A11 적은 근거 이름 「얻어 갈 것」「보고 나서 할 일」 | 반영 | 「얻어 갈 정보」「보고 나서 바로 할 일」(칸 이름 그대로). |
| A12 진정성 근거 이름을 줄여 씀(우리 생각·한계·출처와 연출) | 반영 | 「우리만의 생각과 선택」「솔직하게 밝혀야 할 한계」「출처와 연출 표시」. |
| A13 「고를 기준」이 개인화 칸 이름과 어긋남(볼 이유·제작 전 확인·내려받기 대체 문장) | 반영 | 「보는 사람의 상황·상황마다 고를 수 있는 도움·보고 나서 바로 할 일」, 제작 전 확인 이름은 「상황·도움·할 일 잇기」, 개인화 축 다음에 할 일의 「고를 기준」도 「고를 수 있는 도움」. 질문 「…고를 기준과 다음 행동이 실제로 달라지나요?」는 일반 낱말이라 두었다. |
| A14 내려받기 「- 계속 볼 재미: 적어 둔 재미: …」 쌍점 겹침 | 반영 | 「<적은 재미> (이 구성의 재미 제안: …)」, 비었을 때 「<제안> — 이 구성이 제안하는 재미예요. 주제에 맞는 장면과 궁금증이 풀리는 곳을 적어 주세요.」 |
| A15 「누가 왜 볼지 — 작성됨: 적은 시청자: …」 쌍점 세 번 | 반영 | 다른 줄(얻어 갈 정보·계속 볼 재미)처럼 적은 값 그대로, 비었을 때 「<기본 시청자> (이 유형의 기본 시청자)」. |
| A16 「내려받을 기획안을 읽지 못했어요.」 | 반영 | 「…「고쳐서 새로 만들기」로 다시 만든 뒤 내려받아 주세요.」(기획 결과 화면의 단추 이름). |
| B1 「확인 가능한 반응」이 「반응 수」로 좁아짐 | 반영 | 「원문 링크·게시일·확인일과 확인할 수 있는 반응은 따로 봐요.」 |
| B2 「자세한 양식」이 지정 낱말과 어긋남 | 반영(바꿔서) | 「제작 양식」은 트렌드에서 조사로 만든 양식 이름이라, 데스크 쪽 이름으로 「이 유형의 자세한 기획 양식은…」. |
| B3 같은 유형 안에서 「정본」을 「캐릭터 설정」·「정본(생김새 참고)」으로 다르게 옮김 | 반영 | 「그 캐릭터의 정본 설정 안에서」·「정본 그림(생김새 참고)」. |
| B4 데스크 「즐거움: …발견하는 즐거움」처럼 머리말과 끝말이 겹침 | 반영(넓혀서) | 기획안에서도 「이 장면에서 노릴 재미: …되감기의 재미」로 겹쳐서, 「즐거움」「재미」로 끝나던 보상 여섯을 「발견·순간·후련함」으로 끝냈다. |
| B5 「해보는」「써보려는」 띄어쓰기 | 반영 | 「해 보는」「써 보려는」(다른 제목과 같게). |
