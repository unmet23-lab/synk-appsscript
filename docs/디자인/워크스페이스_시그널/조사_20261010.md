# 워크스페이스 리디자인 조사 — Recent(옛 Godly) 외 · 2026-10-10

- 요청: 유호님 10-10 「싱크 메신저(워크플레이스) 앱 디자인 GPT가 만들어줬는데 최악이야 … recent나 godly나 전에 보내준 디자인 사이트 5~6개 지금 크롤링해서 최신 트렌디한 디자인이나 최고 반응 좋은 것들을 추합해서 리디자인」.
- Godly 주소(godly.website)는 지금 `recent.design/?ref=godly`로 넘어간다. 두 이름은 같은 사이트다.
- 같은 날 아침 플랫폼 리디자인 세션이 갤러리 14곳(Recent 인터페이스·앱 화면·웹사이트·제품, Awwwards SOTD·후보, CSSDA WOTD, FWA, Minimal Gallery, SiteInspire, Land-book, Lapa Ninja)과 Recent 상세 118개를 모았다. 그 자료는 읽기만 해서 같이 쓰고, 이번에는 **메신저·업무 화면**(채팅·받은함·사이드바·명령창·대시보드·AI 도우미) 쪽으로 더 모았다.
- 방법: 헤드리스 Chrome(1440×900). 로그인·가입·버튼 누르기 없이 목록을 스크롤해 링크를 모으고 상세 글을 읽었다. 노출 수(Impressions)는 사이트 표시값이다.

## 가져오지 않은 것

- 3D·WebGL 배경, 자동 재생 영상, 흐르는 띠, 스스로 움직이는 무지개 테(Agent Status는 애니메이션이지만 여기서는 쓰는 동안 고정 테로만). 유호님이 화면 움직임에 멀미를 느낀 기록이 있다.
- 본문 판 전체 유리(glassmorphism) — 업무 글을 오래 읽기에 대비가 낮다. 유리는 틀 위 캡슐(검색·계정·주요 공간)과 빠른 검색에만 쓴다.
- 작은 펠트 스티커를 단추·제목 옆에 붙이는 것 — 업무 도구에서는 장식이 정보보다 앞섰다. 펠트는 업무 도우미 마린에만 남긴다.
- 참고 작품의 이미지·코드·고유 배치를 복제하지 않았다. 원리만 SYNK 색·서체로 다시 만들었다.

## 로그인 2판 조사 · 2026-10-10

- 요청: 유호님 「이 부분 제대로 바꿔줘야 할 것 같아. 다시 크롤링해서 이거 힙하고 트렌디하게 바꿔줘. 너무 투박하다」 — 새 판 로그인 오른쪽의 흰 카드.
- 방법: 헤드리스 Chrome(1440×900). 실제 제품 로그인 첫 화면 24곳을 보기만 했다(입력·클릭·쿠키 동의 없음). 21곳이 열렸고 Claude·Cursor·Perplexity는 보안 확인 화면이었다. 함께 Dribbble 「login page」·「sign in」·「dark login」 인기 목록(64·65·64개), Recent 인터페이스 인기 145개·웹사이트 인기 99개에서 로그인 관련 글을 골라 읽었다.

| 사례 | 표시 | 가져온 것 |
|---|---|---|
| [AuthKit](https://recent.design/i/h98y98d-authkit)(Recent 웹사이트) | 노출 119.1K · 바깥 클릭 2.4K · Dark · Minimal | 위에서 떨어지는 빛, 옅은 격자, 유리 판, 위가 밝은 금속빛 제목, `OR` 구분선 |
| [Dark Mode Auth Screens](https://recent.design/i/4c9xsq0-dark-mode-auth-screens)(Recent 인터페이스) | 노출 66.2K · Dark · Minimal · Clean | 순수 검정 바탕 위의 작은 폼, 모노 글자 |
| Railway 로그인 | 실제 화면 | 판 모서리 밖으로 뻗는 1px 안내선 |
| Resend · Raycast 로그인 | 실제 화면 | 카드 없이 어두운 바탕 위 입력, 어두운 채움 입력 칸(흰색 4~5%) |
| Linear · Vercel · Clerk · Cal.com · Slack | 실제 화면 | 바로 들어가기(SSO)가 먼저, `OR` 다음 이메일 |

- 공통점: 흰 카드가 사라지는 중이다. 열린 21곳 가운데 카드를 둔 곳은 6곳(Clerk·Railway·Cal.com·Discord·Mercury·PostHog)이고 나머지는 바탕 위에 입력만 둔다. 어두운 로그인(Resend·Raycast·Railway·Discord)은 모두 입력 칸을 바탕보다 조금 밝은 채움으로 두고 흰 테를 쓰지 않는다. 단추·입력 높이는 40~48px, 둥글기는 8~16px이거나 완전한 알약이다.
- 그래서: 오른쪽 흰 카드를 어두운 유리 판으로 바꾸고, 판 모서리 밖으로 안내선을 뻗게 하고, 판 뒤에 청금석 빛·위에서 떨어지는 옅은 빛·옅은 격자를 깔았다. SYNK ID는 유리 알약 + 싱ㅋ 글자 표시, 아래 한 줄은 상태 등(준비 중 버터 · 쓸 수 있음 초록), 그 뒤 `OR`. 입력은 어두운 채움 칸이고 누르는 동안만 무지개 테가 켜진다. 들어가기는 흰 알약에 검은 동그라미 화살표. 왼쪽 큰 문구는 AuthKit 제목처럼 위가 밝은 금속빛 청금석 글자로 바꿨다. 휴대폰에서는 판을 걷고 Resend처럼 바탕 위에 바로 띄운다.
- 가져오지 않은 것: 움직이는 배경(AuthKit의 스크롤 연출, Discord의 떠다니는 그림), QR 로그인(기능이 없다), 큰 3D 조형. 모두 멈춘 그림으로만 옮겼다.
