## 2차 — 싱ㅋ 시그널 2 (2026-10-10)

> 유호님 「GPT가 만든 플랫폼 앱 디자인이 최악… 클로드로 리디자인 또는 업그레이드. 전에 만든 디자인을 올리거나 Recent·Godly·예전에 보낸 디자인 사이트를 지금 크롤링해 모아도 되고, 둘 다 합쳐도 좋다」 → 1차 문법은 그대로 두고, 그 뒤에 덧붙은 화면(내 홈·계정 이어가기 띠·편의 기능·설정)을 같은 문법으로 다시 그리고, 오늘 8개 사이트에서 모은 흐름을 더했다. 범위는 데스크톱 런처(`desktop/renderer/`)이고 ID·문구·동작은 바꾸지 않았다. 근거는 [2차 조사](조사_20261010.md), 화면은 아래 「2차 기준 화면」.

- **떠 있는 본문 판**: 제목줄·왼쪽 라이브러리는 바탕(책상) 위에 두고, 본문은 둥근 판(`--panel`, 반경 22, 안쪽 1px 테) 하나에 담는다. 목록과 본문이 선 없이 나뉜다.
- **유리 캡슐**: 가운데 메뉴, 오른쪽 이동·검색·알림 묶음, 계정 칩, 아래 상태 알약, 대화창·빠른 검색은 같은 유리(`--glass`·`--glass-edge`·`--blur`)로 만든다. 2026-09-19 「바탕이 있는 조작 요소는 입체적인 투명 유리로」와 같은 방향이다.
- **펠트 물건 포스터**: 사업 색 면 위에 펠트 물건을 **제 색 그대로** 세운다. 그림마다 놓는 법이 셋이다 — 누끼 물건(`world-book`·`laptop`·`care-note`·`fortune-star`·`studio-camera`)은 그림자를 붙여 세우고, 흰 바탕 사진(`path`·`pulse`·`teacher` 표지)은 흰 인화지처럼 −4° 기울여 붙인다. 장면 그림은 1차 이중톤을 쓰는데, 10-10부터 WORLD도 웹과 같은 펠트 책(`world-book.avif`, 원본 `docs/Loom_자산/구움/공방_책.avif`)이라 지금 장면을 쓰는 앱은 없다([전후](화면/시그널2-WORLD책.jpg)). 그림 색은 다시 칠하지 않는다(`.art-cut`·`.art-print`·`.art-scene`).
- **내 홈**: 큰 인사 제목 → 목적 분할 캡슐 → **다음 할 일 포스터**(첫 앱의 사업 색·물건·큰 한글) → **내 앱 포스터 선반**(이 계정에 연결된 앱만, 누르면 기존 앱 소개) → 최근·자주 → 할 일과 결과(앱 색 막대) → 회원 혜택 띠(네 색 스티커).
- **상태 칩**: LED 점 + 짧은 글자를 어두운 알약에 담아 포스터 위에 둔다. 앱 이름이 겹치는 앞부분은 빼고 끝말(「로컬 MVP」 등)만 쓴다. 화면 읽기 프로그램은 전체 상태를 읽는다.
- **계정 이어가기 띠**: 내 홈에서만 보이고, 단추는 펠트 그림 대신 시그널 단추(주 행동은 흰 알약)로 덮는다. 원본 `platform-continuity.css`는 웹 원본에서 만드는 생성 파일이라 고치지 않고 `launcher.css`에서 `#main`으로 지목해 덮는다.
- **설정**: 켜고 끄는 항목은 스위치, 시간·단축키 입력은 같은 입력칸 모양으로 맞췄다.
- **좁은 창(760px 이하)**: 메뉴는 화면 아래 유리 탭 막대가 되고, 상태 알약은 설치가 진행 중일 때만 그 위에 뜬다.
- **스튜디오 조명**: 사업 색 면은 단색 대신 `--studio` 층(왼쪽 위가 살짝 밝고 아래가 살짝 가라앉는 정지 그라데이션, 밝기 16% 이내)을 깐다. 물건이 촬영 배경지 위에 「놓인」 것처럼 보인다. 색 값은 그대로다.
- **구역 번호**: 내 홈 섹션 머리에 홈페이지와 같은 「01 · 제목」 번호를 CSS 카운터로 붙인다(화면 읽기에는 숨김).
- **포스터 대비 규칙**: 큰 한글이 앉는 자리의 장면 그림은 옆과 아래로 걷어 낸다(왼쪽·아래 페이드를 겹침). 물건 상자는 큰 글자 머리보다 위에서 끝나게 아래 여백을 둔다(데스크톱 다음 할 일 포스터 168px, 인화지 176px).

같은 날 Fable 검수(유호님 「페이블로 한번 더 검수 및 업그레이드」): 판정 「지금 판 업그레이드」, P1 2·P2 12·P3 8건을 받아 반영했다. [검수 전문](Fable_검수_20261010.md).

**웹 플랫폼**(`experiences/synk-account/platform.css`·`benefits.css`)에도 같은 2차를 입혔다: 같은 토큰, 떠 있는 판, 판 위에 떠 있는 유리 위쪽 캡슐(sticky), 바로가기 카드를 사업 색 포스터로, 혜택 세 칸 판에 제 색 물건, 스위치, 계정 이어가기 띠는 내 홈·라이브러리·설정에서만 본문 폭으로. 웹은 CSS만 바꿨다. 낮 테마·검색 축소는 같은 날 화면 스크립트(`dist/platform.js`)를 건드리지 않고 `platform.html`·`platform.css`·`theme.js`로 넣었다: 위쪽 캡슐의 테마 단추가 밤(기본)·낮·기기 설정을 차례로 바꾸고(데스크톱과 같은 낮 토큰, 이 기기에 저장), 넓은 창의 검색은 캡슐 안 아이콘으로 줄였다가 누르거나 Ctrl+K·/로 펼친다([낮 화면](화면/시그널2-웹낮.jpg)). 링크·단추 끝의 화살표 글자(←→)는 SUIT가 꺾쇠처럼 그려서, 화살표 글자만 Inter Tight로 그리게 했다(데스크톱 화살표와 같은 굵기·크기, `SYNK Arrow` 글꼴 규칙). 휴대폰(760px 이하)에서는 위쪽 메뉴 캡슐이 스크롤해도 화면 위(8px)에 유리로 붙어 있고, 로고 줄과 검색 줄은 함께 흘러간다(사이드바를 `top:-40px`로 고정). 휴대폰(760px 이하)에서는 라이브러리 분류·컬렉션 알약 묶음을 위쪽 메뉴처럼 한 줄 가로 흐름으로 둔다. 10-10 synk.im 공개(synk-policy `a4c8f92`, [공개 기록](../../_ops/qa/platform-signal2-20261010/README.md)).

## PATH 실사 면접실 (2026-10-12)

> 유호님 「오늘 synk path에 vr기능 추가했는데 프론트가 엉망이야… 기존에 플랫폼 디자인 니가 다시 해줬던것처럼」 → GPT가 만든 면접실(초록 단색 바탕, 기본 라디오·셀렉트, 작은 설명문 여러 덩어리)을 시그널 문법으로 다시 그렸다. 범위는 `experiences/path-vr/interview/film/rehearsal.{html,css}`, 상태 표시용 `rehearsal.mjs` 한 곳, 방 둘러보기 단추와 VR 책상 안내판(`strict-vr.mjs`의 `paintStrictVRHUD`), 웹 플랫폼의 PATH 색·그림이다. 면접 흐름·영상·음성 판정·카메라 수치·ID는 그대로다. 사용 흐름 조사는 [PATH 설계](../../SHIFT/VR직업체험_설계_v1.md#path-room-redesign-20261012).

- **틀:** 플랫폼과 같은 밤 토큰. 위쪽은 유리 캡슐(로고 · 모노 라벨 · 돌아가기 알약), 첫머리는 두 줄 큰 제목(둘째 줄 회색)과 1px 선 계기판(질문 2개 · 60–90초 · 30·25초 · 기기 안).
- **왼쪽 영상 + 오른쪽 준비 패널:** 영상은 16:9 둥근 판(반경 28)이고 위에 유리 칩(상태 점·남은 시간)과 아래 유리 자막을 띄운다. 패널 맨 위는 PATH 포스터(초록 `--studio` 면 + 펠트 VR 고글 누끼를 통째로 −3°로 오른쪽 위에 세움 + 왼쪽 아래 큰 「면접」, 둘은 겹치지 않는다). 휴대폰(600px 이하)은 실제 면접관 영상이 첫 그림이라 포스터를 빼고 시작 단추를 첫 화면에 둔다. 그 아래 상태 → 답변 방식 분할 캡슐 → 흰 주 단추 → 보조 알약 → 화질 → Quest 안내 → 개인정보 세 줄. 안내 카드 세 장은 영상 아래 빈 칸에 둔다.
- **상태 점:** `body[data-phase]`·`[data-mic]`·`[data-urgent]`(표시용)로 회색 대기 · 청금석 면접관 차례 · 초록 내 차례 · 버터 확인 · 코랄 마이크 켜짐. 마이크가 켜지면 영상 판에 코랄 2px 테두리, 마지막 10초는 시간 칩만 버터 테. 깜빡이지 않는다.
- **단추:** 흰 알약 주 단추는 한 화면에 하나. 음성 준비 전처럼 비활성이면 회색 판이 아니라 조용한 선 알약(자리·크기 그대로). 음성 단계와 Quest 입장처럼 「PATH에서 지금 할 수 있는 일」은 옅은 실 테(+ 초록 점).
- **면접 중:** 첫머리·안내·포스터·개인정보·화질을 걷고 영상과 패널만 남긴다. 넓은 화면은 한 줄 격자로 패널 높이를 영상에 맞추고 Quest 안내를 패널 바닥에 붙인다. 끝나면 영상 아래에 PATH 초록 결과 판(내 답변 · 질문 의도 · 후속 질문, 초록 위 작은 글자는 흰색 88%).
- **방 둘러보기·VR:** 둘러보기 창은 밤 판(반경 28) 위에 유리 힌트·닫기·조작 캡슐(드래그 켜짐은 흰 알약). VR 책상 안내판은 부드러운 종이(`#EDEDEB`) + 상태 점 + PATH 초록 주 알약 + 선 알약(나가기)이며 단추 좌표(`BUTTONS`)는 그대로다.
- **웹 플랫폼 PATH:** 그동안 색 규칙이 없어 기본 청금석 면에 WORLD 책이 나왔다. `.app-card.path,.detail-hero.path`에 초록 면·큰 「패스」를 주고 그림을 펠트 VR 고글(`path-vr-felt.webp`, synk.im PATH 첫 화면과 같은 바이트)로 바꿨다.
- **공개 제약:** 면접실 CSP 때문에 CSS `url()`에 data: URI·외부 글꼴을 쓰지 않는다(그레인 생략, 화살표·재생 표시는 인라인 SVG·CSS 도형). 공개 머리글·바닥글은 `tools/package-path-interview.mjs`가 같은 구조로 바꿔 넣는다.

### 글자 2판 (같은 날)

> 유호님(1판 미리보기의 「정하실 것」 상자 캡처와 함께) 「아직 이런데가 밤티나. 크롤링해서 최신 프론트 타이포그래피 감각있게 만들어줘야해. 클라이언트가 주로 볼 기능인데 너무 후져보인다 아직」. 근거는 [조사 §글자 2판](조사_20261013_PULSE고객.md#type-audit-20261013)(참고 32쪽 실측 + 안내 상자 10종).

**1판이 싸 보인 이유**: 거의 모든 글자가 800~900이라 위계가 굵기로 갈리지 않았다(참고 제품 화면의 큰 제목 중앙값 510, 국내 700, synk.im 760). 한글 라벨·상태가 11~12.5px, 영문 모노 라벨 자간 .16em, 손이 필요한 카드마다 왼쪽 베리 막대(참고 10종 중 문서 인용에만 남은 모양), 같은 말을 두 번 하는 카드(수령 확인)와 맨 위에 놓인 계약 주의 문구가 겹쳤다.

- **굵기**: 큰 제목 680 · 카드 제목 650 · 강조 600 · 라벨 550 · 본문 450. 포스터 큰 한글만 900. 같은 제목을 600·680·760·900으로 찍어 골랐다(680이 900보다 정돈되고 synk.im 760과 어울림).
- **크기**: 13(라벨·도움말 작은 글) · 14(도움말) · 15.5(카드 본문·단추) · 16(기본·입력칸) · 17(단계 설명·값·작은 제목) · 20(카드 제목) · 24(블록 머리·대화상자 제목) + 큰 제목 `clamp(32px,3.3vw,46px)`·첫 화면 `clamp(40px,4.4vw,64px)`. 그 사이 값(13.5·14.5·15·18·21·22·26)은 쓰지 않는다. **한글은 13px 밑으로 내리지 않는다.** 프로젝트 이름은 단계 제목과 다투지 않게 한 단계 작게(`clamp(24px,2.2vw,30px)`).
- **서체**: 한글 SUIT Variable, 영문·숫자는 synk.im과 같은 Inter Tight(`SYNK Latin`, 라틴만 unicode-range · 400/600/700 세 파일 각 18KB, 원본 `docs/브랜드_폰트/InterTight`), 가운뎃점 「·」은 한글 높이에 맞는 SUIT로 둔다. 영문 모노 라벨 DM Mono 11.5px 자간 .08em(1판 .16em). 한글이 든 라벨은 모노로 쓰지 않는다(`.eyebrow.ko`).
- **잉크**: synk.im 공개본과 같은 본문 76% · 보조 58% · 흐림 42%.
- **안내 상자(지금 할 일)**: 노란 알약 칩 대신 라벨 한 줄 「● 내 차례 | 05 · 영상 확인」(LED 점 + 600 글자 + 1px 세로선 + 단계 이름) → 제목 21px/650 → 설명 15px. 손이 필요한 카드는 왼쪽 막대 대신 오른쪽 위 노란 LED 점, 단추가 오른쪽에 있는 알림 줄은 제목 앞 점.
- **문단**: 빈 상태는 흰 첫 문장 + 회색 설명 한 문단(Linear·Apple의 두 톤 문장). 짧은 안내문은 `text-wrap: balance`, 본문은 `pretty`, 제목은 `balance`. 제작팀 메모는 상자 대신 라벨 + 왼쪽 1px 선.
- **날짜**: 「10월 13일 오전 8:54」(올해가 아니면 연도), 전달 예정일 「10월 31일 (토)」(`api.mjs`의 `stamp`·`day`). 1판 Fable P3 「날짜 표기 통일」 해결.
- **덜어 낸 것**: 의견 묶음 패널의 계약 주의 문구는 패널 끝 작은 글로, 수령을 마친 뒤의 수령 카드는 체크 + 「수령 확인 완료 · 시각」 한 줄 영수증 + 파일 알약으로, 카드 안 카드는 선 없는 한 단계 밝은 면으로, 설계 확인 기록은 「무엇 · 누가 · 언제」 한 줄씩.

**Fable 검수(2판, 같은 날)**: 판정 「밤티의 원인(900 굵기·노란 알약·ISO 날짜·왼쪽 막대·같은 말 두 번)은 벗었고 PC 첫 화면은 Linear·토스급 정돈에 거의 닿았다. 남은 건 조판 결함 하나, 「네 차례」 신호 중복, 합쇼체 면책 문장, 한 판 뒤처진 휴대폰 첫 화면」. 반영:
- **가운뎃점 줄바꿈**: `keep-all`은 「·」 앞뒤를 지키지 않아 「메시지·근거 / ·행동을」처럼 갈렸다. 단계 설명·계기판 문장은 `keepDots`(api.mjs)로 「·」 덩어리를 `<span class="nw">`(줄바꿈 없음)로 묶는다. 시험이 「·」 문구를 정규식으로 잡는 곳이 있어 보이지 않는 글자(U+2060)는 쓰지 않았다. 두 문장 이상 설명은 `text-wrap: pretty`, `balance`는 한 문장 안내에만.
- **「네 차례」 신호는 한 화면에 한 번씩**: 여정 막대·포스터 칩·내 차례 상자는 두고, 계기판의 「함께 확인 중」 줄(내 차례 상자가 있는 단계에서만 숨김)과 확인·요약 카드의 상태 칩을 뺐다.
- **휴대폰 첫 화면**: 헤더는 로고 + LED + 「앱 설치 · 알림」 + 「알림」만(「연결 닫기」는 알림함 안으로), 새로고침은 13px 글자 단추, 여정 막대는 지금 단계를 왼쪽 흐림(40px) 바로 안쪽에 두고 끝까지 못 밀리는 뒤 단계는 막대 끝에서 멈춘다(반쯤 잘린 단계 이름이 보이지 않게), 계기판은 두 칸 + 확인 범위 한 줄.
- **말투는 해요체 하나로**: 한 문단에 「전달돼요」와 「있습니다」가 섞이던 단계 설명·계기판·확인 카드·설계 기록·납품 규격·의견 패널·알림 안내를 해요체로 다시 썼다. 확인 대화상자의 동의문만 합쇼체.
- **덜어 낸 것(더)**: 확인 카드의 면책 두 문장 → 작은 글 한 문장, 아코디언 제목의 「· 선택」 → 작은 회색 「선택」, 카드 제목 끝 마침표 없앰(두 줄 큰 제목과 빈 상태 문장만 마침표), 05 오른쪽 열 고정 해제, 의견 패널의 중복 소제목은 작은 글로, 보낸 의견이 없으면 「제출한 의견」 구역 숨김, 제작팀 메모의 왼쪽 선도 뺐다. 05 제목은 「이제 영상으로 / 확인해요.」(두 글자 첫 줄이 고아 줄처럼 보였다).
- 남김: 「지금 할 일」 설명이 제목과 어긋나 보이는 경우(합성 프로젝트의 `nextStep` 값 때문), 06 포스터 높이, 같은 날 이력 날짜 묶기.

### 05 영상 확인 다시 짜기 (같은 날)

> 유호님(1판 미리보기의 05 아래쪽 캡처와 함께) 「여기도 디자인이 너무 허접해 .. 제대로 잘 만들어줘야해. 최신 트렌드 반영해서 만들어줘」 → 「하던거 전부 다 마치고 이것도 전부 마무리까지」. 1판은 큰 검은 영상 상자 밑에 버튼 둘·회색 메모 상자·빈 의견 상자, 오른쪽에 승인 카드 + 의견 모으기 양식 + 일정 문의 양식이 쌓여 관리 화면처럼 보였다.

- **무대**: 영상은 제 화면비 그대로 어두운 무대 가운데(`width/height:auto`, 최대 `min(62vh,620px)`), 남는 자리는 검은 띠 대신 무대 색. 기본 컨트롤은 그대로(시험·휴대폰 재생).

- 이전 화면의 촌스러움은 펠트 질감 단추·크림/코랄 바탕·여러 장식이 한 화면에 섞인 데서 왔다. 단추·칩·탭은 선명한 화면 부품으로 바꾸고, 질감은 포스터의 옅은 그레인 하나로 줄였다.

- **선택**: 메뉴·탭·필터는 바탕을 뒤집은 알약(밤엔 흰 바탕에 검정 글자).
- **계기판**: 설치 상태·버전·마지막 실행은 1px 세로선으로 나눈 숫자판. 상태는 LED 점(초록 설치됨·청금석 미리보기·버터 확인 중·회색 준비 중).
- **Atlas 맞춤**: 브랜드 실 네 색 원뿔 그라데이션 점과 옅은 무지개 테두리로 「나에게 맞춘 것」을 표시한다.
- **상태 알약**: 아래 가운데 떠 있는 알약에 설치 진행·실행 환경·설정을 모은다(점 막대 진행률). 600px 이하에서는 바닥에 붙인 막대가 된다.
- **아이콘**: 24px 격자, 1.8px 선의 자체 SVG 묶음(`index.html`의 `<symbol>`). 글자 기호(☆ ↻ ⚙)를 아이콘 대신 쓰지 않는다.

## 2차 다듬기 — Fable 검수 (2026-10-06)

유호님이 「Fable로도 한 번 더 검수」를 요청해 Fable이 플랫폼과 홈페이지를 다시 보고 **방향은 맞고 마감을 다듬을 것(업그레이드)**으로 판정했다. 검수 전문은 [Fable 검수](Fable_검수_20261006.md).

- **이중톤의 그림자 바닥**: 흑백 그림의 가장 어두운 값을 .23으로 막는다. `--shadow-floor: invert(1) brightness(1.3) brightness(.77) invert(1)`은 max(x, .23)이다(중간 값이 0~1로 잘리는 성질을 쓴다. 크롬에서 픽셀로 확인). 곱하기 뒤 그림자가 순검정이 아니라 **면 색의 어두운 판**(면 색 30%, 코랄이면 `#4A1F1B`)이 되어, 밤에는 포스터 모서리가 바탕에 녹지 않고 낮에는 검은 덩어리가 사라진다. 웹 플랫폼도 같은 필터 사슬을 쓴다.
- **포스터 캡션**: 어두운 알약(검정 62% + 흰 글자 + 흐림 8px) 위에 둔다. 그림이 어두운 자리에서도 읽힌다.
- **큰 글자 자간**: `calc(-.085em + 글자 수 × .01em)`. 2글자 −.065em, 3글자 −.055em, 4글자 −.045em. `--len`은 데스크톱은 스크립트가, 웹은 색 묶음(`.benefit-<id>`)이 정한다.
- **메신저 포스터**: 무채색 대신 청금석 빛(흑백 → 세피아 → 채도 → 색상 회전)으로 물들여 밝게(screen) 겹친다.
- **휴대폰(600px 이하)**: 상태 알약은 바닥 막대로 바꿔 포스터 글자를 가리지 않는다. 맞춤 띠는 설명을 숨긴 한 줄로 줄이고, 두 칸 혜택 카드는 번호 알약을 숨겨 단계 스티커만 남긴다.
- 웹 플랫폼 「소중한 순간을, 더 잘.」은 모두 흰 글자로 둔다. 옅은 청금석은 메신저의 글자색이다.

## 홈페이지(synk.im)에 쓴 규칙

홈페이지는 SYNK-website의 `src/homepage.css`·`founder.css` 끝에 덧붙인 「싱ㅋ 시그널」 층으로 밤 바탕이 된다. 아틀라스 페이지는 `atlas-editorial.css`, 첫 화면 전환은 `cosmic-entry.css`·`atlas-portal-arrival.css` 끝에 덧붙인다. 2026-10-07 유호님 승인으로 공개했다(synk-policy `090c2d9`, 원본 SYNK-website `502669a`, 층 파일과 공개 도구는 그 저장소 `qa/signal-redesign-20261006/`). 첫 화면 「싱ㅋ」과 문구는 그대로다.

- **토큰**: 밤으로 뒤집고, 면은 플랫폼 면 1·2·3(`#111215` `#18191D` `#212227`)과 같은 값을 쓴다. 작은 글자의 사업 색은 옅은 실(LAB `#FFB4A9`·SHIFT `#C5D6F5`·PULSE `#F8C7DE`·PATH `#D3E8BE`)로 쓰고, 28px 이상 글자와 면은 원값으로 둔다.
- **위쪽 유리 메뉴**: 밤 유리로 두고, 펠트 로고는 흰 구슬 위에 놓는다.
- **사업 타일**: 색 면은 포스터로 둔다. 펠트 로고는 면 왼쪽 위에 −2.5° 기울인 스티커로 붙이고, 아래 밤 면에는 `01 / LAB` 모노 번호와 설명만 둔다.
- **구역 머리**: 「번호 · 라벨 · 1px 선」. 번호는 페이지마다 01부터 매기고, 아틀라스 페이지의 구역 번호와 같은 모양이다.
- **과정 카드**: 면 2 + 1px 선 위에 펠트 사진을 안쪽 흰 무대(모서리 18, 안쪽 10)로 앉힌다. 링크가 아니므로 손을 올려도 들리지 않는다.
- **지도는 어디서나 흰 종이 카드**(`#f4f4f5`): 회사 메인의 아틀라스 요약 지도와 아틀라스 페이지의 지도에 같이 쓴다. 9월에 물린 「검은 판 위 연결망」과 다르고, 지도 스크립트의 잉크(`#0a0a0a`)를 그대로 쓴다.
- **아틀라스 페이지**: 다른 페이지와 같은 밤 바탕이다. 첫 화면의 ㅇ을 눌러 넘어가는 전환 바탕도 밤색이라 흰 번쩍임이 없다.

## 새 앱·혜택을 더할 때

1. `desktop/renderer/state.mjs`의 `DISPLAY_WORDS`에 `[큰 한글, 타일 한 글자]`를 넣는다(없으면 영문 짧은 이름으로 표시된다).
2. `desktop/renderer/launcher.css`의 사업 색 줄에 `.brand-<id>,:root[data-product=<id>]{--face;--on-face;--glow}`를 더한다.
3. 회원 혜택이면 `launcher.mjs`의 `benefitWords`와 웹 `platform.css`의 `.benefit-<id>{--face;--on-face;--glow;--word}`를 더한다.
4. 포스터 그림은 기존 승인 그림을 그대로 쓴다. 색을 다시 칠하지 않고 화면에서 이중톤으로만 바꾼다.
