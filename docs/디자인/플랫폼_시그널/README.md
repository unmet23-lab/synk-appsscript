## 2차 — 싱ㅋ 시그널 2 (2026-10-10)

> 유호님 「GPT가 만든 플랫폼 앱 디자인이 최악… 클로드로 리디자인 또는 업그레이드. 전에 만든 디자인을 올리거나 Recent·Godly·예전에 보낸 디자인 사이트를 지금 크롤링해 모아도 되고, 둘 다 합쳐도 좋다」 → 1차 문법은 그대로 두고, 그 뒤에 덧붙은 화면(내 홈·계정 이어가기 띠·편의 기능·설정)을 같은 문법으로 다시 그리고, 오늘 8개 사이트에서 모은 흐름을 더했다. 범위는 데스크톱 런처(`desktop/renderer/`)이고 ID·문구·동작은 바꾸지 않았다. 근거는 [2차 조사](조사_20261010.md), 화면은 아래 「2차 기준 화면」.

- **떠 있는 본문 판**: 제목줄·왼쪽 라이브러리는 바탕(책상) 위에 두고, 본문은 둥근 판(`--panel`, 반경 22, 안쪽 1px 테) 하나에 담는다. 목록과 본문이 선 없이 나뉜다.
- **유리 캡슐**: 가운데 메뉴, 오른쪽 이동·검색·알림 묶음, 계정 칩, 아래 상태 알약, 대화창·빠른 검색은 같은 유리(`--glass`·`--glass-edge`·`--blur`)로 만든다. 2026-09-19 「바탕이 있는 조작 요소는 입체적인 투명 유리로」와 같은 방향이다.
- **펠트 물건 포스터**: 사업 색 면 위에 펠트 물건을 **제 색 그대로** 세운다. 그림마다 놓는 법이 셋이다 — 누끼 물건(`world-book`·`laptop`·`care-note`·`fortune-star`·`studio-camera`)은 그림자를 붙여 세우고, 흰 바탕 사진(`path`·`pulse`·`teacher` 표지)은 흰 인화지처럼 −4° 기울여 붙인다. 장면 그림은 1차 이중톤을 쓰는데, 10-10부터 WORLD도 웹과 같은 펠트 책(`world-book.avif`, 원본 `docs/Loom_자산/구움/공방_책.avif`)이라 지금 장면을 쓰는 앱은 없다([전후](화면/시그널2-WORLD책.jpg)). 그림 색은 다시 칠하지 않는다(`.art-cut`·`.art-print`·`.art-scene`).
- **내 홈**: 큰 인사 제목 → 목적 분할 캡슐 → **다음 할 일 포스터**(첫 앱의 사업 색·물건·큰 한글) → **내 앱 포스터 선반**(이 계정에 연결된 앱만, 누르면 기존 앱 소개) → 최근·자주 → 할 일과 결과(앱 색 막대) → 회원 혜택 띠(네 색 스티커).
- **상태 칩**: LED 점 + 짧은 글자를 어두운 알약에 담아 포스터 위에 둔다. 앱 이름이 겹치는 앞부분은 빼고 끝말(「로컬 MVP」 등)만 쓴다. 화면 읽기 프로그램은 전체 상태를 읽는다.
- **계정 이어가기 띠**: 내 홈에서만 보이고, 단추는 펠트 그림 대신 시그널 단추(주 행동은 흰 알약)로 덮는다. 원본 `platform-continuity.css`는 웹 원본에서 만드는 생성 파일이라 고치지 않고 `launcher.css`에서 `#main`으로 지목해 덮는다.
- **설정**: 켜고 끄는 항목은 스위치, 시간·단축키 입력은 같은 입력칸 모양으로 맞췄다.
- **좁은 창(760px 이하)**: 메뉴는 화면 아래 유리 탭 막대가 되고, 상태 알약은 설치가 진행 중일 때만 그 위에 뜬다.
- **스튜디오 조명**: 사업 색 면은 단색 대신 `--studio` 층(왼쪽 위가 살짝 밝고 아래가 살짝 가라앉는 정지 그라데이션, 밝기 16% 이내)을 깐다. 물건이 촬영 배경지 위에 「놓인」 것처럼 보인다. 색 값은 그대로다.
- **구역 번호**: 내 홈 섹션 머리에 홈페이지와 같은 「01 · 제목」 번호를 CSS 카운터로 붙인다(화면 읽기에는 숨김).
- **포스터 대비 규칙**: 큰 한글이 앉는 자리의 장면 그림은 옆과 아래로 걷어 낸다(왼쪽·아래 페이드를 겹침). 물건 상자는 큰 글자 머리보다 위에서 끝나게 아래 여백을 둔다(데스크톱 다음 할 일 포스터 168px, 인화지 176px).

같은 날 Fable 검수(유호님 「페이블로 한번 더 검수 및 업그레이드」): 판정 「지금 판 업그레이드」, P1 2·P2 12·P3 8건을 받아 반영했다. [검수 전문](Fable_검수_20261010.md).

**웹 플랫폼**(`experiences/synk-account/platform.css`·`benefits.css`)에도 같은 2차를 입혔다: 같은 토큰, 떠 있는 판, 판 위에 떠 있는 유리 위쪽 캡슐(sticky), 바로가기 카드를 사업 색 포스터로, 혜택 세 칸 판에 제 색 물건, 스위치, 계정 이어가기 띠는 내 홈·라이브러리·설정에서만 본문 폭으로. 웹은 CSS만 바꿨다. 낮 테마·검색 축소는 같은 날 화면 스크립트(`dist/platform.js`)를 건드리지 않고 `platform.html`·`platform.css`·`theme.js`로 넣었다: 위쪽 캡슐의 테마 단추가 밤(기본)·낮·기기 설정을 차례로 바꾸고(데스크톱과 같은 낮 토큰, 이 기기에 저장), 넓은 창의 검색은 캡슐 안 아이콘으로 줄였다가 누르거나 Ctrl+K·/로 펼친다([낮 화면](화면/시그널2-웹낮.jpg)). 휴대폰(760px 이하)에서는 라이브러리 분류·컬렉션 알약 묶음을 위쪽 메뉴처럼 한 줄 가로 흐름으로 둔다. 10-10 synk.im 공개(synk-policy `a4c8f92`, [공개 기록](../../_ops/qa/platform-signal2-20261010/README.md)).

## 한 줄 원칙

검정(또는 흰) 바탕 위에 **앱마다 사업 색 하나**, 그 위에 **「싱ㅋ」처럼 아주 큰 한글**, 나머지는 **계기판 같은 작은 라벨과 1px 선**으로 조용하게. 2차부터는 **펠트 물건 하나를 제 색으로** 세우고, 조작 부품은 **유리 캡슐**로 띄운다.

## 왜 이렇게 바꿨나

- 이전 화면의 촌스러움은 펠트 질감 단추·크림/코랄 바탕·여러 장식이 한 화면에 섞인 데서 왔다. 단추·칩·탭은 선명한 화면 부품으로 바꾸고, 질감은 포스터의 옅은 그레인 하나로 줄였다.
- 홈페이지 첫 화면의 「싱ㅋ」(큰 굵은 한글, 작은 라벨+가는 선, 크고 가는 글자)를 플랫폼의 기본 문법으로 가져왔다. 앱 이름을 「월드」「메신저」「패스」처럼 한글 포스터로 크게 쓴다.
- 2026년 Recent(옛 Godly) 인기·최신 목록에서 반응이 큰 흐름 — 어두운 고대비 화면, 기기 계기판 같은 숫자·라벨, 아주 큰 글자 포스터, 색 하나만 쓰는 흑백 화면, 떠 있는 상태 알약 — 을 우리 브랜드 색과 서체 안에서만 썼다.

## 부품

- **포스터**: 사업 색 면 + 승인 그림을 흑백으로 바꿔 곱하기(multiply)로 얹은 이중톤 + 옅은 그레인 + 아주 큰 한글(SUIT 900). 큰 글자가 앉는 자리의 그림은 마스크로 걷어 글자 대비를 지킨다. 글자 크기는 포스터 폭(`cqw`)과 글자 수(`--len`)로 정해 넘치지 않는다. 그림자 바닥·자간·캡션은 아래 「2차 다듬기」.
- **스티커**: 단계 표시(개발판·로컬 MVP)는 흰 알약을 살짝 기울인 스티커. 한 화면에 하나만.
- **단추**: 주 행동은 글자색 바탕의 알약(밤엔 흰 단추). 손을 올리면 그 앱 색으로 빛나는 테두리. 보조는 1px 선 알약. 펠트 판 그림을 깔지 않는다.
- **선택**: 메뉴·탭·필터는 바탕을 뒤집은 알약(밤엔 흰 바탕에 검정 글자).
- **계기판**: 설치 상태·버전·마지막 실행은 1px 세로선으로 나눈 숫자판. 상태는 LED 점(초록 설치됨·청금석 미리보기·버터 확인 중·회색 준비 중).
- **Atlas 맞춤**: 브랜드 실 네 색 원뿔 그라데이션 점과 옅은 무지개 테두리로 「나에게 맞춘 것」을 표시한다.
- **상태 알약**: 아래 가운데 떠 있는 알약에 설치 진행·실행 환경·설정을 모은다(점 막대 진행률). 600px 이하에서는 바닥에 붙인 막대가 된다.
- **아이콘**: 24px 격자, 1.8px 선의 자체 SVG 묶음(`index.html`의 `<symbol>`). 글자 기호(☆ ↻ ⚙)를 아이콘 대신 쓰지 않는다.

## 2차 다듬기 — Fable 검수 (2026-10-06)

유호님이 「Fable로도 한 번 더 검수」를 요청해 Fable이 플랫폼과 홈페이지를 다시 보고 **방향은 맞고 마감을 다듬을 것(업그레이드)**으로 판정했다. 검수 전문은 [Fable 검수](Fable_검수_20261006.md).

- **이중톤의 그림자 바닥**: 흑백 그림의 가장 어두운 값을 .23으로 막는다. `--shadow-floor: invert(1) brightness(1.3) brightness(.77) invert(1)`은 max(x, .23)이다(중간 값이 0~1로 잘리는 성질을 쓴다. 크롬에서 픽셀로 확인). 곱하기 뒤 그림자가 순검정이 아니라 **면 색의 어두운 판**(면 색 30%, 코랄이면 `#4A1F1B`)이 되어, 밤에는 포스터 모서리가 바탕에 녹지 않고 낮에는 검은 덩어리가 사라진다. 웹 플랫폼도 같은 필터 사슬을 쓴다.
- **포스터 캡션**: 어두운 알약(검정 62% + 흰 글자 + 흐림 8px) 위에 둔다. 그림이 어두운 자리에서도 읽힌다.
- **큰 글자 자간**: `calc(-.085em + 글자 수 × .01em)`. 2글자 −.065em, 3글자 −.055em, 4글자 −.045em. `--len`은 데스크톱은 스크립트가, 웹은 색 묶음(`.benefit-<id>`)이 정한다.
- **메신저 포스터**: 무채색 대신 청금석 빛(흑백 → 세피아 → 채도 → 색상 회전)으로 물들여 밝게(screen) 겹친다.
- **휴대폰(600px 이하)**: 상태 알약은 바닥 막대로 바꿔 포스터 글자를 가리지 않는다. 맞춤 띠는 설명을 숨긴 한 줄로 줄이고, 두 칸 혜택 카드는 번호 알약을 숨겨 단계 스티커만 남긴다.
- 웹 플랫폼 「소중한 순간을, 더 잘.」은 모두 흰 글자로 둔다. 옅은 청금석은 메신저의 글자색이다.

## 홈페이지(synk.im)에 쓴 규칙

홈페이지는 SYNK-website의 `src/homepage.css`·`founder.css` 끝에 덧붙인 「싱ㅋ 시그널」 층으로 밤 바탕이 된다. 아틀라스 페이지는 `atlas-editorial.css`, 첫 화면 전환은 `cosmic-entry.css`·`atlas-portal-arrival.css` 끝에 덧붙인다. 2026-10-07 유호님 승인으로 공개했다(synk-policy `090c2d9`, 원본 SYNK-website `502669a`, 층 파일과 공개 도구는 그 저장소 `qa/signal-redesign-20261006/`). 첫 화면 「싱ㅋ」과 문구는 그대로다.

- **토큰**: 밤으로 뒤집고, 면은 플랫폼 면 1·2·3(`#111215` `#18191D` `#212227`)과 같은 값을 쓴다. 작은 글자의 사업 색은 옅은 실(LAB `#FFB4A9`·SHIFT `#C5D6F5`·PULSE `#F8C7DE`·PATH `#D3E8BE`)로 쓰고, 28px 이상 글자와 면은 원값으로 둔다.
- **위쪽 유리 메뉴**: 밤 유리로 두고, 펠트 로고는 흰 구슬 위에 놓는다.
- **사업 타일**: 색 면은 포스터로 둔다. 펠트 로고는 면 왼쪽 위에 −2.5° 기울인 스티커로 붙이고, 아래 밤 면에는 `01 / LAB` 모노 번호와 설명만 둔다.
- **구역 머리**: 「번호 · 라벨 · 1px 선」. 번호는 페이지마다 01부터 매기고, 아틀라스 페이지의 구역 번호와 같은 모양이다.
- **과정 카드**: 면 2 + 1px 선 위에 펠트 사진을 안쪽 흰 무대(모서리 18, 안쪽 10)로 앉힌다. 링크가 아니므로 손을 올려도 들리지 않는다.
- **지도는 어디서나 흰 종이 카드**(`#f4f4f5`): 회사 메인의 아틀라스 요약 지도와 아틀라스 페이지의 지도에 같이 쓴다. 9월에 물린 「검은 판 위 연결망」과 다르고, 지도 스크립트의 잉크(`#0a0a0a`)를 그대로 쓴다.
- **아틀라스 페이지**: 다른 페이지와 같은 밤 바탕이다. 첫 화면의 ㅇ을 눌러 넘어가는 전환 바탕도 밤색이라 흰 번쩍임이 없다.

## 새 앱·혜택을 더할 때

1. `desktop/renderer/state.mjs`의 `DISPLAY_WORDS`에 `[큰 한글, 타일 한 글자]`를 넣는다(없으면 영문 짧은 이름으로 표시된다).
2. `desktop/renderer/launcher.css`의 사업 색 줄에 `.brand-<id>,:root[data-product=<id>]{--face;--on-face;--glow}`를 더한다.
3. 회원 혜택이면 `launcher.mjs`의 `benefitWords`와 웹 `platform.css`의 `.benefit-<id>{--face;--on-face;--glow;--word}`를 더한다.
4. 포스터 그림은 기존 승인 그림을 그대로 쓴다. 색을 다시 칠하지 않고 화면에서 이중톤으로만 바꾼다.
