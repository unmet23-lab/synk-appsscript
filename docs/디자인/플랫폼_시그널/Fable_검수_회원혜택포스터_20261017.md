# PC 플랫폼 회원 혜택 포스터 다시 굽기 검수 (Fable, 2026-10-17)

대상: [회원 혜택 포스터 다시 굽기](README.md#member-benefit-objects-20261017) 첫 판(개요 1440 밤·낮, 휴대폰 390, 소개 머리 6 × 밤·낮, 오린 물건 확인 시트). 못 본 것: 휴대폰 소개 머리(첫 판 캡처 없음), 760~1020px 폭 소개 머리, 호버 상태.

## 좋음
- 이전 판의 문제(빌려 쓴 WORLD 책·노트북의 흑백 필터와 꽉 찬 자르기, 같은 메모 두 번, 리허설만 인화지, 240px 카메라, 휴대폰 「나의 성/향」 끊김)는 다 사라졌다.
- 카드 6장·첫머리·소개 머리 4장이 한 규칙으로 읽힌다: 사업 색 면 + 물건 하나(−3°, 같은 바닥선) + 큰 한글 900 + 어두운 알약 칩. 밤·낮 모두 면 색·글자색·칩 대비가 유지된다.
- 가장자리: 1440 캡처에서 물건 7개를 4배로 키워도 흰 테·바탕색 테·얼룩이 없고, 구운 접지 그림자와 CSS 그림자가 한 덩어리로 보인다.
- 글자 2판(라벨 13/550, 제목 20/650, 본문 14/450, 칩 13/550, 모노 번호 11.5px .08em, 큰 글자만 900)이 지켜졌다.

## P1
없음.

## P2
1. 소개 머리 6장 중 성향·구독 두 장이 다른 틀이었다 — 큰 글자가 2/3 크기, 번호 라벨·흰 스티커 없음(「SYNK FOR YOU / ATLAS」는 사용자에게 뜻이 없는 내부 이름), 모노 라벨 11px .12em, 뒤로 가기 단추가 높아 머리가 21px 내려앉음, 구독 설명 줄 14px/650.
2. 소개 머리 물건과 한 줄 제목이 낮은 창(높이 768 이하)에서 겹칠 수 있었다 — 머리 380px까지 줄고 물건 상자 아래가 60%.

## P3
- 휴대폰 플레저 카드: 봉투 아래와 「저」 머리 사이 약 5px.
- 첫머리 선물 상자와 「혜택」 사이 여유 약 10px.
- 760~1020px 폭 소개 머리에서 제목이 세 줄이 되면 물건과 만날 수 있음.
- 성향 소개 머리 큰 글자만 「내 성향」(카드는 「성향」).
- 약속 아래 안내 13.5px, 왼쪽 아래 바로가기 「회원 혜택 둘러보기」 12.5px.
- 계기판·수정 구슬·마이크 받침의 어두운 부분은 알파가 비어 다른 바탕색 포스터에 쓰면 비친다 — 제 사업 색 면에서만 쓴다.

판정: **다듬기 필요(가볍게)** — 개요는 그대로 보여도 되고, 성향·구독 소개 머리의 틀과 물건 높이만 고치면 된다.

## 반영 (같은 날)
- P2-1: 성향·구독 소개 머리도 PC 앱이 넘기는 `poster`(물건·`SYNK FOR YOU · 01 / 06` 라벨·상태 스티커)로 다른 넷과 같은 틀 — 큰 글자 `min(8.5rem,17cqw)`, 라벨 11.5px .08em, 기울인 흰 스티커, 한 줄 제목 650, 설명 줄 15px/550. 뒤로 가기는 여섯 모두 44px 칸·회색 글자로 맞춰 머리 시작 높이가 같다(1440·1366·1280·900·390 폭에서 6개 모두 같은 y로 잼). 웹 플랫폼(그림 없음)은 원래 머리 그대로.
- P2-2: 소개 머리 최소 높이 400px, 물건 상자 6~54%. 1440×900·1366×768·1280×720·900×800에서 물건과 한 줄 제목 사이 18px 이상, 겹침 0(물건 실제 그림 영역으로 잼).
- P3: 휴대폰 카드 물건 상자 20~65%, 첫머리 물건 9~61%, 약속 아래 안내 13px, 바로가기 13px/600. 휴대폰 소개 머리 라벨이 두 줄로 꺾이던 것(nowrap + 스티커 줄바꿈)과 물건이 큰 글자에 붙던 것(아래 여백 4px)도 고쳤다. 「내 성향」은 화면 제목(접근성 제목·웹과 공유)이라 그대로 두었다.
