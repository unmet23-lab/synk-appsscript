# PULSE 고객 작업실 재설계 — 디자인 QA (Fable, 2026-10-13)

본 것: 29장 전부(참고 2장 먼저). 못 본 것: 「제작팀 차례」 상태, 03·02 본문의 접힌 영역, 알림 패널 불투명 수정본 — 이 범위는 지적하지 않는다.

## 1. 판정 — 「다듬기 필요」

플랫폼 홈·카타나 2판 옆에 놓아도 같은 손으로 만든 화면으로 읽힌다. 책상·패널·유리 캡슐, 베리 포스터 + 펠트 물건 + 큰 한글, 두 줄 제목, 모노 라벨, LED 칩, 1px 게이지, 선택 반전까지 언어가 끊기는 데가 없고, 「지금 할 일」 카드와 단계 착지는 전 판의 가장 큰 결함을 실제로 고쳤다. 다만 그 카드의 주행동이 흰 알약이 아니고, 저장 바가 양식 첫 질문을 덮으며, 베리 면이 한 화면에 둘씩 생기는 자리가 있어 「이대로 좋다」로는 못 올린다. P1 둘과 P2 몇 개를 손보면 바로 기준선에 든다.

## 2. 문제 목록

### P1 — 언어가 깨지거나 고객이 잘못 읽는 것

1. **.next-decision 주행동이 어두운 알약** — fresh·strategy·concepts·storyboard·review·delivered 전부(「제작 설계 시작하기」「콘셉트 비교하기」「영상 확인하기」「납품 파일 확인」). 고객이 이 화면에서 해야 할 단 하나의 일인데 「최신 내용 불러오기」와 무게가 같다. 흰 알약=주행동 규칙 위반.
   → `.next-decision .button { background:#fff; color:#0C0D10; border-color:#fff; font-weight:700 }`. 「모두 끝났어요」 상태의 「납품 파일·기록 다시 보기」만 지금 모양 유지.
2. **저장 바가 양식 첫 질문을 덮음** (b-strategy-body y≈585–650) — 「입력한 내용을 저장하면…」 바가 「메시지·근거·행동」 제목과 「기억하게 할 메시지 하나」 라벨 위에 얹혀 무엇을 적는 칸인지 못 읽는다. 「제작 설계 시작하기」로 내려와도 앵커가 바 밑에 떨어진다.
   → 바를 아래 고정으로: `.strategy-save-bar { position:sticky; bottom:16px; top:auto }`. 위 고정을 유지하려면 양식 머리에 `padding-top:72px`, 앵커 요소에 `scroll-margin-top:88px`.

### P2 — 품질

3. **「펄스」가 포스터 밖으로 잘림** (welcome 1440·390) — 「펄」 아래, 「스」 오른쪽이 잘려 깨진 것처럼 보인다. 참고 포스터(월드·카타나)는 단어가 늘 온전하다.
   → 세로 포스터용 `.stage-poster--tall .poster-word { font-size:clamp(120px,12vw,190px); line-height:.9; left:24px; bottom:20px; max-width:calc(100% - 48px) }`.
4. **한 화면에 베리 면이 둘** — strategy 본문 「CASTING & STYLING」 띠, review 본문 「VERSION APPROVAL」 카드, demo 상단 「체험 프로젝트」 배너가 포스터와 경쟁한다.
   → 셋 다 `.panel-card`와 같은 `background:#101115; border:1px solid` 기본선으로 내리고 모노 라벨만 `color:#99295D`. 승인 카드는 베리 1px 테두리까지 허용.
5. **승인 카드가 가장 멀리 있음** (b-review-body) — 오른쪽 열 맨 아래, 두 화면을 내려야 「이 시안 최종 승인」이 보인다.
   → `.approval-card`를 오른쪽 열 첫 자리로(의견 모으기 카드 위). 「일정·기타 문의」는 왼쪽 「이 영상의 의견」 아래로 내려 왼쪽 빈 공간도 채운다.
6. **흰 알약이 한 화면에 셋** — storyboard(「재생」「이 전체 흐름 확인」「이 실제 시험 장면 확인」), review(「이 장면에 의견」「이 의견 보내기」「이 시안 최종 승인」).
   → 「재생」과 「이 장면에 의견」을 어두운 기본 `.button`으로. 글자는 그대로.
7. **끝난 상태의 범위 게이지가 그대로** (received) — 「모두 끝났어요」인데 「지금 확인할 것: 약속한 결과물과 사용 안내」「다음 확인: 파일 수령과 남은 문의」. 수령을 마친 고객에게 「다음 확인: 파일 수령」은 모순.
   → `.production-scope` 문구를 상태별 표로. received는 「보관된 것: 최종 파일·의견 기록·설계 기록」「다음: 남은 문의는 일정·기타 문의로」.
8. **04 카드 부제가 03과 글자 그대로 같음** (storyboard 「참고자료와 꼭 담을 내용을 전해 주세요.」) — 장면 단계에서 참고자료를 보내라는 엉뚱한 지시.
   → 「장면 순서와 문구를 보고 의견을 남겨 주세요.」처럼 단계별 부제.
9. **여정 바 「살펴볼 수 있어요」** — 혼자 문장형이고, 04가 안 끝난 채 05가 「지금 할 일」이라 「4를 빠뜨렸나」 싶게 한다.
   → 「둘러보기」 같은 명사형 + 파란 LED 유지. 카드의 「이 단계」 자리에 「확인 없이 볼 수 있어요」 한 줄.
10. **휴대폰 여정 바 잘림** (strategy·review·received 390) — 왼쪽 「성 / 수 있어요」, 오른쪽 「03」 조각이 보여 깨진 것처럼 읽힌다.
    → `.journey { mask-image:linear-gradient(90deg,transparent,#000 24px,#000 calc(100% - 24px),transparent); scroll-snap-type:x mandatory }`, `.journey-step { scroll-snap-align:start }`.
11. **테두리 색 강조** — delivered 금색, received 초록 테두리 카드. LED 칩이 이미 상태를 말하는데 네 번째 강조 수단이 생겼다.
    → 테두리는 기본 1px로 두고 칩에 맡기거나, 플랫폼 「이어서 할 일」 카드처럼 왼쪽 3px 선 하나.
12. **demo 상태 모순** — 체험 1/7 「원하는 느낌을 골라 보세요」인데 여정 02는 「공유 완료」. 상단 배너와 「내 차례」 카드가 같은 문장을 두 번 말한다.
    → 체험 중인 단계는 「지금 할 일」(노랑). 배너는 플랫폼 「MY LIBRARY」 띠처럼 한 줄 + 알약 하나로.

### P3 — 있으면 좋은 것

13. 「다음 확인」 칸 밑 초록 메모(「제작 설계 v1 확인됨」)는 칸과 무관 → 「확인 범위」 아래 또는 LED 칩으로.
14. 포스터 물건 자리·크기가 단계마다 제각각(전구는 모서리, 과녁은 작음) → 물건 박스를 오른쪽 56% 폭·세로 가운데·높이 78%로 통일.
15. review-direction에서 흰 카드(보는 02)와 베리 원(할 일 05)이 동시에 켜짐 → 보는 카드에 작은 「보는 중」 보조 라벨.
16. 알림 「9」 빨간 원 배지 → 플랫폼처럼 모노 숫자 알약(「08」). 알림 본문이 전부 「프로젝트를 열어…」 → 해당 단계로 가는 글자 단추.

18. 시험 플레이어가 16:9 전폭 → 세로 광고는 `.video-layout video { max-height:480px; width:auto; margin-inline:auto }`.
19. 「의견을 모아 한 번에 전달해요」 설명 6줄 → 한 줄 + 접기. 「제작 설계 확인 이력」 잔글씨 → 1px 게이지 행.
20. 수령 대화상자: 체크 전에도 「수령 확인 남기기」가 켜져 보임 → 체크 전 `opacity:.4; pointer-events:none`.
21. 날짜 표기 둘(머리 `2026-10-31` 모노, 기록 「2026. 10. 13. 오전 8:54」) → 하나로.

## 3. 잘된 점 (지키기)

- 캡슐 헤더·로고 알약·「CLIENT ROOM」 모노, 책상 + 패널 하나 — 플랫폼과 같은 손.
- 단계 포스터 6장: 베리 + 단계별 펠트 물건 + 큰 한글. TV·소포·과녁은 그대로 플랫폼 타일에 넣어도 된다.
- 프로젝트 머리 → 여정 바(활성 흰 반전, LED 넷) → 스테이지 히어로 → 범위 게이지 순서. 고객이 05에 바로 내려앉는 것, 다른 단계를 열어 봐도 「내 차례 · 05 영상 확인」 카드가 돌려보내는 것.
- 「0 / 4 장면 확인」 미터, 납품의 파일 카드 + 수령 영수증 + 타임라인 + 규격 표.
- 두 대화상자(FINAL PREVIEW APPROVAL / DELIVERY RECEIPT): 모노 라벨, 칩, 동의 문구, 어두운 「다시 살펴보기」 + 흰 확정 — 이 언어의 모범.
- 분위기 칩·장면 구간·여정 활성의 「선택=반전」, 모노는 영문·숫자에만.
- 휴대폰에서 포스터가 제목 위로 올라오고 머리·메타가 두 줄로 접히는 것.

## 반영 확인 (fable2 · 13장, 단추 색은 픽셀로 대조)

- P1-1 해결: 「현재 제작 설계 확인」「장면 확인하기」「영상 확인하기」가 흰 알약(250,250,249). 「모두 끝났어요」의 「납품 파일·기록 다시 보기」만 부드러운 알약 — 규칙대로.
- P1-2 해결: 「01 메시지 · 근거 · 행동」 제목과 첫 라벨이 더는 가려지지 않음. 양식 끝에 붙였다는 저장 행은 캡처 밖이라 못 봄.
- P2-3·4·5·7·11·12 해결: 「펄스」가 포스터 안에 온전, 베리 면은 포스터 하나(캐스팅 띠·승인 카드·체험 배너 모두 패널 면), 승인 카드가 오른쪽 열 첫 자리, 끝난 상태의 범위 게이지 숨김 + 「제작 설계 v1 확인됨」이 확인 범위 아래로, 색 테두리 대신 3px 베리 왼선·LED 칩, 체험 단계가 「지금 할 일」이고 중복 카드 숨김.
- P2-6 해결(review): 흰 알약은 「이 시안 최종 승인」 하나, 「이 장면에 의견」·「이 의견 보내기」는 부드러운 알약. storyboard 본문의 「재생」은 새 캡처가 없어 못 봄.
- P2-9 해결: 「확인 가능」. 다만 「확인 완료」와 첫 두 글자가 같아 한눈에 갈리지 않음 — 「둘러보기」가 더 안전(P3).
- P2-10 절반: 18px 페이드는 들어갔지만 그 밖의 조각(review 390 「구성 / 인 가능」)이 그대로 읽혀 여전히 잘린 글로 보임. → 마스크를 48px로 넓히고 활성 단계를 왼쪽 끝에 붙이기(`.journey-step.is-active { scroll-snap-align:start }` + `.journey { scroll-padding-inline:24px }`, 또는 `scrollIntoView({inline:'start'})`).
- 새로 나빠진 것 없음. 남은 것: review 왼쪽 열 아래 빈 공간(P3-19), 체험 화면 히어로 왼쪽이 카드 없이 포스터보다 110px쯤 짧게 끝나는 것(허용), P3 알림 알약·수령 대화상자·참고 카드 단추는 캡처가 없어 미확인.
