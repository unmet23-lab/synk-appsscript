> 대상: [AI 구독 계정판 남은 한도 고리](../../SYNK_플랫폼_계정과_연결_설계.md#member-ai-subscriptions-20261017)(참고카드 [웹 움직임·차트 5곳](../../참고카드/카드/2026-10-17_웹움직임_차트_5곳.md) ②). 캡처는 실제 계정판 값(10-17 15:28 읽음, 시각 고정)으로 찍었다 — [전후](화면/구독고리-전후.jpg) · [휴대폰 390](화면/구독고리-휴대폰.jpg). 1차 P1·P2 전부, P3-1·P3-3·P3-4, 2차 P3(100% 고리 이음매)를 반영했고 P3-2·P3-5는 이유를 적고 두었다. 아래 shots/·review-crops/는 검수 때 작업 폴더의 파일 이름이다.

본 것: shots/compare.png · after-desk.png · after-phone.png · after-roll.png · before-desk.png, subscriptions.css · subscriptions.mjs(읽기만), `node --test tests/subscriptions-view.test.cjs` 10/10 통과. 확대 조각은 review-crops/.

## 판정
**다듬기 필요** — P1 1건(초기화 시각이 어느 기간 것인지 안 보임), 나머지는 문구·휴대폰 순서. 고리 자체는 막대보다 잘 읽힌다. 그대로 보고하면 안 되고, P1·P2 반영 뒤 보고.

## 물어본 네 가지
- **한눈에 얼마 남았나**: 막대보다 낫다. 가운데 큰 숫자 + 「주간 남음」이 한 번에 읽히고, 예전 판처럼 「51%」가 쓴 양인지 남은 양인지 생각할 필요가 없다(compare.png 왼쪽 unmet23 51% ↔ 오른쪽 22% 주간 남음).
- **안·바깥 고리 구분**: 136·104·88px에서는 된다(바깥 메도우 · 안 연두의 명도 차, desk-claude-card·phone-mid). **20px 작은 고리에서는 안 고리가 r 3.5·굵기 3이라 점으로 뭉개져** 고리인지 모른다(desk-rows-gpt-gemini: Gemini는 과녁, GPT는 호 하나) → P3-1.
- **세 상태를 글로도**: 소진 ○(고리 안 「5시간 소진」, 칩 「5시간 소진」, 계정 줄 「5시간 소진」). 여유 ○(숫자 + 남음). **주의 ×** — 「주간 1% 남음」은 숫자와 버터색뿐, 상태를 부르는 말이 없다 → P2-2.
- **휴대폰에서 깨지는 곳**: 없다. 넘침·잘림·겹침 없음, 고리 안 글 13px 유지, 단추는 고리 아래로 잘 떨어짐. 다만 알림 칩이 카드 세 장 아래로 밀린다 → P2-3.

## P1 (기능·읽기 오류)
1. **「초기화까지 …」와 줄 요약이 어느 기간의 값인지 안 보임.** after-desk Gemini 카드: 「5시간 98% 남음」 아래 「초기화까지 1시간 35분」 — 5시간 초기화인데 주간이 1시간 35분 뒤에 초기화되는 걸로 읽힌다. 02 Gemini 줄도 「5시간 98% 남음 … 토 12:06 초기화」로 5시간 %와 주간 초기화 시각이 한 줄에 섞인다(desk-rows-gpt-gemini). 원인: `untilReset`·`serviceBlock`이 `g.focus`를 따르면서 기간 이름을 안 붙임.
   - 카드: `untilReset` → `${WINDOW_NAME[g.focus]} 초기화 <b>${rel(g.resetsAt - now)}</b> 뒤` → 「주간 초기화 1일 20시간 뒤」 「5시간 초기화 1시간 35분 뒤」(계정 줄의 「4일 19시간 뒤」와 같은 말투).
   - 02 줄: 구획이 「주간 한도」이고 옆 칸이 주간 초기화 시각이니 줄 글은 주간으로 고정 — `serviceBlock` status를 `g.weekly ? '주간 ' + leftHtml(g.weekly) : WINDOW_NAME[g.focus] + ' ' + leftHtml(g[g.focus])`. 작은 고리는 그대로 두 겹.

## P2 (품질)
1. **01 설명문 「소진·90% 이상·…」이 쓴 양 기준이라 「남음」으로 통일한 화면과 어긋남**(after-desk 01 머리, 휴대폰 3줄). `attention()`의 `wp >= 90`은 `leftPercent`가 내림이라 「10% 이하 남음」과 정확히 같다. 문구: 「서비스마다 가장 여유 있는 계정의 남은 한도예요(안 5시간 · 밖 주간). 소진·10% 이하 남음·크레딧 부족·3일 안 결제는 아래에 올라와요.」 고리 없을 때 문구도 「소진·10% 이하 남음·크레딧 부족·3일 안 결제만 올라와요.」
2. **주의 상태에 말이 없음**(after-desk 칩 「주간 1% 남음 · founder Claude」, 계정 줄 founder). 다른 칩은 「5시간 소진 ·」「크레딧 부족 ·」처럼 상태말이 앞에 온다. 고리 안에는 넣지 말 것 — 136px 고리 안지름 88px에 「주간 거의 소진」(13px ≈ 85px)은 넘친다.
   - 칩: `attention()` level 1 주간/5시간 항목 앞에 「거의 소진 · 」 → 「거의 소진 · 주간 1% 남음 · founder Claude」.
   - 계정 줄: `accountRow`의 이름 옆 칩에 `gaugeLevel(g[g.focus]) === 'low'`이면 `<span class="ms-chip ms-chip-warn">거의 소진</span>`(기존 「소진」「부족」 칩과 같은 자리).
3. **휴대폰에서 알림 칩이 첫 화면 밖.** after-phone: 01 머리에서 첫 칩까지 약 710px(카드 3장 × 168px), 위에 포스터까지 있으니 「5시간 소진」 칩은 두 화면 아래. 둘 중 하나:
   - (가) 카드를 작게: `@media (max-width:760px){.member-subs .ms-meter{grid-template-columns:96px minmax(0,1fr);gap:14px;padding:14px} .member-subs .ms-meter>.ms-gauge{width:96px} .member-subs .ms-meter .ms-gauge-num{font-size:1.5rem}}` → 카드 ≈ 125px, 세 장 ≈ 400px.
   - (나) 칩을 카드 위로: `.member-subs .ms-section:has(.ms-meters){display:flex;flex-direction:column}` + `@media (max-width:760px){.member-subs .ms-section:has(.ms-meters) .ms-section-heading{order:-2} .member-subs .ms-section:has(.ms-meters) .ms-attn{order:-1;margin-bottom:14px}}` — 이때 설명문 「아래에 올라와요」는 「칩으로 올라와요」로.
   (가)가 구조를 안 건드려 안전.
4. **97% 넘는 고리는 둥근 끝이 시작점과 겹쳐 100%처럼 닫힘**(desk-gemini-card: 바깥 99%·안 98% 모두 12시에 매듭만 남음). 둥근 끝 반지름 4가 둘레의 1.2~1.5%라 양쪽 합 2.4~3%가 더 그려진다. `ringsSvg`에서 `stroke-linecap="${w.left >= 97 ? 'butt' : 'round'}"`를 arc에 인라인으로(CSS의 `stroke-linecap:round`는 지우고).

## P3 (의심·확인)
1. 20px 작은 고리의 안 고리(r 3.5·굵기 3)는 점이라 뜻을 못 전한다. 줄 글이 말하는 기간 하나만 그리기: `miniGauge`에서 `ringsSvg({ ...g, session: g.focus === 'session' ? g.session : null, weekly: g.focus === 'weekly' ? g.weekly : null }, 'mini')`, `RINGS.mini = { weekly: 46, session: 46, width: 20 }`.
2. 「지금 가장 여유」가 synk.yuh(22%)인데 unmet23은 58분 뒤 주간 49%로 가장 여유가 된다. 지금 기준으로는 맞고 칩이 보완하니 그대로 둬도 됨. 바꾸려면 `roomiest`에서 5시간 소진인데 1시간 안에 풀리는 계정은 주간으로 점수.
3. 경계값: `leftPercent`가 내림이라 쓴 양 89.5%도 「10% 남음」인데 버터가 안 된다(`gaugeLevel`·`leftHtml`은 `used >= 90`). `left <= 10`으로 맞추면 문구(P2-1)와 숫자·색이 한 기준.
4. 카드가 눌린다는 표시가 없다(후버만). 줄과 같은 `ms-chev`를 오른쪽에: `.ms-meter{position:relative}` + `<span class="ms-chev" aria-hidden="true"></span>`에 `position:absolute;right:18px;top:50%;margin-top:-4px`.
5. 밝은 테마는 캡처가 없어 못 봤다. 안 고리 `color-mix(메도우 52%, var(--ink))`는 밝은 테마에서 어두운 올리브가 되니 바깥보다 어두워져 구분은 될 듯 — 확인만.

## 확인한 것(문제 없음)
- 값 대조: 예전 판 쓴 양 ↔ 새 판 남은 양 모두 100−x로 맞음(unmet23 51→49, synk.yuh 78→22, founder 99→1, GPT 49→51, Gemini 1→99, Fable 37→63·72→28·78→22).
- 글자 단계: 고리 안 라벨 13px/550, 범례·초기화 14px/450, 카드 제목 15px/600, 숫자 Inter Tight 700 — 기준 안. 포스터 밖 900 없음. 카드 왼쪽 막대 없음(펼침의 세로선은 기존 트리선).
- 움직임: `rollChanged`가 `rolled` 맵으로 처음·값 변화 때만 굴리고, 1분 repaint는 조용함. `data-motion=reduced`는 launcher.mjs:300이 `:root`에 세팅 → CSS 130·253줄과 launcher.css 566줄(모든 animation none)로 숫자 띠·고리 그리기 모두 멈춤. 늘 도는 효과 없음.
- 굴림 프레임(after-roll): 띠가 1.15em 상자 안에만 보이고 「%」·라벨은 고정 — 의도대로. 칩 순서는 소진(level 0)이 맨 앞으로 와서 예전 판보다 낫다.
- 접근성: SVG `aria-hidden`, 띠 `<i aria-hidden>`, 투명 숫자는 접근 트리에 남음. 단추 이름이 길지만 읽힘.

### 남은 것
- P3(신규): **100% 안 고리(Claude 5시간 100%)에 12시 방향 1px 실선**(v2-seam-claude-top · v2-seam-phone-claude-top, 데스크톱 2x·휴대폰 모두). dasharray 100/100의 끝과 시작이 맞닿는 자리에 트랙이 비친다. 고침: `ringsSvg`에서 `w.left >= 100`이면 `pathLength`·`stroke-dasharray`·`stroke-dashoffset`을 빼고 닫힌 원으로 그리기(이음매 없음). 그리기 움직임은 그 고리만 `data-full`로 opacity: `.ms-gauge.is-drawing .ms-arc[data-full]{animation:ms-fade .9s cubic-bezier(.2,.8,.2,1) both}@keyframes ms-fade{from{opacity:0}}`.
- P3-2·P3-5는 안 한 이유 타당(지금 기준 맞음 · 앱은 밝은 테마도 어두운 바탕).
