| P2 오류에 다음 행동 없음(앱 권한·알 수 없는 앱·설치 안 된 앱) | 반영 |
| P2 불러오기 실패 화면의 같은 문장 되풀이 | 반영 — 옆 목록은 「불러오기 실패 · 인터넷 연결을 확인한 뒤…」 |

## B묶음 — 판정 「고친 뒤」, P0 2 · P1 6 · P2 6 → 반영 10 · 일부 2 · 안 함 2

| 지적 | 처리 |
|---|---|
| P0 PULSE 상세에 PATH 글 | 안 함 — 글 뽑기 도구 착각. PULSE는 누르면 전용 창이 바로 열려(10-20 PULSE 창 결정) 상세 화면이 앞 앱(PATH) 그대로 남는다 |
| P0 정식 모드에서 「판: 정식판」인데 버전 줄은 「시험판」 | 반영 — 업데이트 버전 줄도 정식 모드면 「시험판」을 붙이지 않게(지금 공개판은 모두 시험판 모드) |
| P1 설치 창 「…가/를」 조사(「SYNK Platform가」) | 안 함 — 앞 이름이 SYNK·WORLD·워크스페이스(build-signal.cjs shortName)라 「가/를」이 맞다 |
| P1 홈 「앱 정보」라는 이름이 상세의 「앱 정보」 탭과 엇갈림 | 반영 — 「앱 소개」로 |
| P1 계정 창에 「기본 브라우저에서」 설명 세 번 | 반영 — 상태 「아직 로그인하지 않았어요.」, 도움말 한 줄, 작은 글은 보관 안내만 |
| P1 업데이트 오류의 누를 단추가 상황과 다름 | 반영 — 여는 실패는 「설치 단추」, 기본 오류는 「최신 버전 확인」 |
| P1 본체 오류에 다음 행동·이름 | 반영 — 「요청을 처리하지 못했어요. 다시 해 주세요.」, 「무료 운세에서…」, 브라우저 로그인 끝 화면 오류 넷에 「SYNK 앱에서 다시 로그인해 주세요.」 |
| P1 메모 오류에 다음 행동 없음 | 반영 — 「내 홈을 다시 열어 주세요.」 |
| P2 「로그인을 받았어요」 | 반영 — 「로그인 정보를 받았어요.」 |
| P2 「다 만들면 더해요」 | 반영 — 「완성되는 대로 올릴게요.」 |
| P2 「어느 한때」·「학습 효과」 빠짐 | 반영 — 「한 시점의 기록…학습 효과가 다르다는 뜻은 아니에요.」 |
| P2 「다시 시도를 막았어요」 | 반영 — 「다시 설치하지 못하게 막았어요」·「재시도를 멈췄어요」 |
| P2 워크스페이스 한글 표기·탭 되풀이·PATH 머리 되풀이 | 일부 — 둘째 탭은 WORLD에만 남기고(다른 앱은 개요 되풀이라 숨김), 미리보기 앱 개요 머리는 「PATH에서 하는 일」처럼. 문장 속 「워크스페이스」 한글 읽기는 그대로 |
| P2 「이 기기 임시 기록 되살리기 파일」·홈 카드 「SYNK 플레저」 | 일부 — 파일 이름은 「이 PC 임시 기록 보관 파일」로. 앱 이름 「SYNK 플레저」는 SYNK WORLD와 같은 꼴이라 그대로 |
