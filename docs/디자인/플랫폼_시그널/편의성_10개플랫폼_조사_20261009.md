# 주요 플랫폼 10곳의 편의 기능과 SYNK 적용 후보

2026년 10월 9일 구현 전 조사. 당시 **빠른 호출과 이동, 창과 작업 위치 복원, 트레이 바로가기, 알림 제어**를 먼저 보강할 대상으로 정했다. 기존 즐겨찾기·최근 열기·테마·초안 보호·앱별 웹 알림에 연결할 후보를 비교한 기록이다.

## 조사 범위

Discord·ChatGPT·Claude·Slack·Microsoft Teams·Notion·Steam·Epic Games Launcher·Spotify·Visual Studio Code의 공식 도움말과 발표 85개에서 편의 기능 137개 항목을 확인했다. 공통 조사 축은 ①시작·종료·트레이 ②빠른 호출·검색 ③이동·작업 복원 ④초안·저장·복구 ⑤알림·집중 ⑥목록 정리 ⑦진행 작업·업데이트 ⑧오프라인·동기화 ⑨표시·키보드·접근성 ⑩계정·설정·진단이다.

이는 선정한 10개 제품과 조사 영역에 대한 공식 문서 비교다. 로그인한 모든 요금제·OS 화면을 직접 재현한 결과는 아니다. 정확한 게시일이 없는 현행 도움말, 날짜 있는 출시 발표, 베타·점진 배포를 구분했다. 10월 9일 이후 출시된 기능과 SDK 개발 옵션은 집계하지 않았다. 오래된 출시 자료는 도입 근거이며 현재 모든 화면의 배치가 동일하다는 뜻은 아니다. 요금 조건 미기재를 무료 제공으로 해석하지 않는다.

## 당시 후보의 세부 동작 설계

- **창 위치·크기·마지막 화면 복원**: 창 크기·위치·최대화 상태와 마지막 메뉴를 복원한다. 모니터가 빠지면 현재 화면 안으로 이동한다. 사용자 A에서 B로 바뀌면 A의 메모·검색 내용을 보여 주지 않는다.
- **트레이에서 즐겨찾기·최근 앱 바로 실행**: 트레이 메뉴에서 현재 계정에 허용된 즐겨찾기와 최근 앱 3~5개를 연다. 실행 전 권한·설치 상태를 다시 확인한다. 준비 중 앱을 실행 가능한 항목처럼 만들지 않는다.
- **시작·닫기 동작 설정**: 설정에 Windows 로그인 시 실행, 숨긴 상태로 시작, X를 누를 때 트레이로 숨김/완전 종료를 따로 둔다. 자동 시작의 기본값은 꺼짐을 제안한다. 완전 종료는 초안을 보호한다.
- **Ctrl+K 명령 메뉴**: 기존 Ctrl+K를 앱·메뉴·설정·즐겨찾기·최근 메모의 명령 메뉴로 확장한다. ↑/↓·Enter·Esc를 지원하고 한글 조합 중 Enter는 실행하지 않는다. Messenger의 기존 commandModal 동작을 재사용한다.
- **운영체제 전역 호출 단축키**: 다른 앱 사용 중에도 선택한 전역 키로 SYNK 또는 명령 메뉴를 호출한다. 충돌하면 다른 키 선택·해제를 제공한다. 키를 눌렀다고 유료 AI 요청을 시작하지 않는다.
- **뒤로·앞으로·최근 경로**: 메뉴·검색 결과·앱 상세의 방문 이력과 스크롤을 보존한다. Alt+←/→·마우스 뒤/앞을 지원한다. 돌아가기는 조회 위치를 복원하며 저장·발송·결제를 다시 실행하지 않는다.
- **설정 검색·단축키 목록·글자 확대**: 시작·알림·창·보기·연결 설정을 검색한다. 단축키 목록과 확대/축소/초기화를 제공한다. 기존 큰 글자·움직임 감소·기기 테마 설정을 찾기 쉽게 연결한다.
- **앱별 알림함·조용한 시간·일시 정지**: 기존 Messenger·Care 알림에서 실제 이벤트만 받아 앱별 알림함으로 연결한다. 팝업·소리·배지·내용 미리보기, 30분/1시간 중지와 요일별 조용한 시간을 따로 고른다. 지정 시간이 지나면 자동 복귀하고 알림 완료 때 창을 강제로 앞으로 띄우지 않는다.
- **종료·충돌 뒤 초안 복구**: 사용자가 동의한 기기 초안을 암호화·계정별로 보관하고 재시작 때 복구/버리기를 선택하게 한다. 저장된 서버 원본과 초안은 구분하고 만료·로그아웃·계정 삭제 정책을 함께 정한다.
- **설치·업데이트 대기열·재개·예약**: 현재 로컬 설치 복사와 향후 인터넷 다운로드를 구분한다. 진행·대기·완료·실패·결과 위치를 먼저 명확히 한다. 원격 업데이트 채널·서명·무결성이 준비된 뒤 순서·재개·속도·예약을 붙이며 작업 중 강제 종료를 하지 않는다.
- **즐겨찾기 순서·보관함·문맥 메뉴**: 현재 9개 앱에서는 즐겨찾기 수동 순서와 간단 목록을 먼저 제공한다. 우클릭·키보드 문맥 메뉴에 실행·즐겨찾기·앱 정보를 둔다. 폴더·자동 분류·일괄 편집은 항목이 늘어날 때 넓힌다.
- **안전한 오프라인 읽기·진단정보 복사**: 사용자가 고른 메모·자료만 오프라인 보관하며 마지막 저장 시각·로컬 저장·동기화 대기·충돌을 구분한다. 연결 재개가 기존 쓰기 요청을 무조건 반복하지 않게 한다. 진단 복사에는 버전·OS·공개 오류코드만 넣고 자격증명·대화·메모 본문을 제외한다.
- **숨김 상태에서 자원 절약**: 창이 숨겨졌을 때 시각 애니메이션·불필요한 목록 갱신을 쉬게 한다. 실제 다운로드·동기화·알림 처리는 유지한다. 적용 전후 CPU·메모리·복귀 지연을 측정하며 데이터 저장을 끊지 않는다.
- **작은 메모창·라디오 제어창**: 첫 범위를 작은 메모창 또는 라디오 제어창으로 잡고 항상 위에 두기를 사용자가 선택한다. 메인 창과 같은 계정·초안 상태를 유지한다. 모든 앱을 한꺼번에 탭화하는 범위는 별도다.
- **알림·검색 결과에서 정확한 작업 열기**: 검색·저장 항목·알림에서 정확한 메모·대화·자료로 이동한다. 링크를 열 때 현재 계정과 권한을 확인하고 없는 항목에는 복구 가능한 안내를 제공한다. 링크가 발송이나 작업 수행을 자동으로 승인하지 않는다.
- **할 일과 보관 항목 정리**: 기존 할 일·결과 메모 위에 제목 검색, 진행/완료 필터, 기한과 선택 리마인더를 붙인다. 참고 보관과 해야 할 일을 구분하고 기존 기록을 임의로 재분류하지 않는다. 참고 항목 저장만으로 알림을 켜지 않는다.

당시 추천 실행 순서는 **창·위치 복원 → 빠른 호출과 Ctrl+K → 트레이 메뉴와 시작·닫기 설정 → 알림 세부 제어 → 재시작 초안 복구**였다. 이후 같은 날 창·작업 위치 복원, 빠른 검색, 트레이·시작·전역 호출 설정, 실제 설치 결과 알림, 동의·암호화 기반 초안 복구 등을 구현했다. 후보 16종의 실제 적용·축소·미구현 범위는 [구현 대조표](../../_ops/qa/platform-convenience-20261009/README.md#조사-후보와-구현-범위)를 따른다. 아래 원래 제안을 전부 남은 할 일로 다시 등록하지 않는다. 자동 업데이트·후속 설치와 공개 상태는 [데스크톱 원문](../../../desktop/README.md)에서 확인한다. 목록·자료가 늘기 전의 복잡한 폴더 체계, 다중 계정, 전면 탭화, 자동 업데이트 서비스는 후속으로 둔다. 새 음성 제작·AI 자동 실행·외부 서비스 자동 조작은 이 편의성 개선에서 필수 요소가 아니다.
