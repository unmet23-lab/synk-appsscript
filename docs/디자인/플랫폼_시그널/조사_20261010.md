# 플랫폼 2차 업그레이드 조사 · 2026-10-10

- 요청: 유호님 「GPT가 만든 플랫폼 앱 디자인이 최악이다. 클로드로 리디자인 또는 업그레이드. 전에 클로드가 만든 디자인이 좋았으니 그걸 올리거나, Recent·Godly·예전에 보낸 디자인 사이트 5~6곳을 지금 크롤링해 최신·반응 좋은 것을 모아 리디자인. 둘 다 합쳐도 좋다.」
- 판단: 1차 「싱ㅋ 시그널」(10-06, 유호님 「정말 좋아 훨씬 좋아」)을 바탕으로 두고, 그 뒤에 덧붙은 화면을 같은 문법으로 다시 그리고, 오늘 모은 흐름을 더한다(둘 다 합침).
- 대상: SYNK 플랫폼 데스크톱 런처 `desktop/renderer/`. 웹 플랫폼(`experiences/synk-account/platform.html`)은 이번 작업에 넣지 않았다.
- 방법: 헤드리스 Chrome(1440×900)으로 목록을 스크롤하고 상세 글만 읽었다. 로그인·구독·누르기는 하지 않았다. 숫자는 사이트가 보여 준 값(노출 수·점수)이며 실제 인기 순위를 따로 검증하지 않았다. 원자료(이미지·JSON)는 Claude 세션 scratchpad의 `research/`에 있다(7일 뒤 지워질 수 있음).

## 바꾸기 전 화면에서 본 문제

1. **첫 화면 「내 홈」에 얼굴이 없었다.** 글자와 빈 테두리 상자만 있고 사업 색·그림·큰 한글이 없었다. 1차의 장점(사업 색 포스터, 큰 한글)은 앱 상세 안쪽에만 남아 있었다.
2. **「MY LIBRARY 계정으로 이어가기」 띠가 모든 화면 맨 위에 붙어 있었다.** 그 단추 하나만 크림색 펠트 그림(`button-soft.webp`)이라 밤 화면에서 따로 놀았다. 라이브러리 화면은 이 띠, 「무엇부터 시작할까요?」 띠, 포스터가 세 겹으로 쌓였다.
3. **뒤에 더해진 CSS 세 개(내 홈·편의 기능·이어가기)가 크기·반경·입력칸을 각자 정했다.** 입력칸 반경이 10px와 12px로 갈렸고, 체크 상자와 시간 입력은 기본 모양 그대로였다. 같은 앱 안에서 부품이 서로 달라 보였다.
4. 기능과 문구는 문제가 아니었다. 그래서 이번에도 ID·문구·동작은 그대로 두고 모양만 바꿨다.

## 가져오지 않은 것

- 3D·WebGL 배경, 자동 재생, 흐르는 띠, 손을 따라 움직이는 효과. 유호님이 화면 움직임에 멀미를 느낀 기록이 있어 움직임은 손을 올리거나 누를 때의 짧은 전환만 둔다.
- 벤토 격자 전체 배치. 올해 「지친 흐름」으로 자주 꼽혔고(SNS 키트 조사 10-01), 우리 포스터와 겹친다. 포스터 선반은 크기가 같은 격자로 둔다.
- 단추·칩에 펠트 그림을 까는 것. 1차에서 걷어 낸 이유(펠트 단추·여러 장식이 섞여 촌스러움)가 그대로이고, 이번 문제 2도 여기서 왔다. 펠트는 포스터의 물건으로 보여 준다.
- 참고 작품의 이미지·코드·고유 배치를 복제하지 않았다. 원리만 SYNK 색·서체·승인 그림으로 다시 만들었다.
