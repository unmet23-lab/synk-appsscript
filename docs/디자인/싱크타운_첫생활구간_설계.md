# 싱크타운 첫 생활 구간과 아틀라스 연결 설계

2026-10-02. 첫 대표 구간은 **찻집 앞 작은 쉼터**다. 생활 제작·작은 가게·주민 사연·발견 정원을 같은 장소와 주민의 생활로 연결한다. 플레이어는 원하는 경로 하나로 완결된 성취를 만들고, 현재 방문과 다음 방문에 자기 선택의 결과를 알아볼 수 있어야 한다. 콘텐츠 기획·한국어 제작·미술·게임 구현 담당자가 함께 쓰는 원문이다.

사용자 「이렇게 반영해서 지금 연결 확실히되어서 사용자가 체감하고 알아볼수있게 컨텐츠 설계 해」에 따라 네 콘텐츠 방향과 연결 기준을 반영했다. **아래 구체 장면·재료량·시간·후속 구성은 검증할 설계 출발값이다. 엔진 연결·게임 구현·재미나 학습 효과 검증 완료를 뜻하지 않는다.** NPC의 최종 이름·외형·목소리, 상용 가격·재화·상품 범위는 각 정본을 따른다.

공통 원칙은 [행동과 세계 변화](../싱크타운_행동과_세계변화_설계.md), 개별 사건은 [생활사건집](싱크타운_생활사건_설계.md), 실행 경계는 [Atlas 첫 생활 구간 연결](../아틀라스_구현명세.md#town-life-adapter)에 둔다. 이 문서는 사건들 사이의 재료 마련·선택·실제 이용·다음 생활을 맡는다. 동일한 제작·전달을 두 문서의 별도 사건으로 이중 지급하지 않는다.

**2026-10-02 제작 원고 추가:** 사용자 「전부 제대로 설계하고 원고도 해줘」에 따라 [제작 패키지](싱크타운_제작패키지.md)에 첫 장면·재방문·경제·TOPIK 학습·상품 설계를 연결했다. 이 문서의 네 경로는 [실제 대사·선택·동작 원고](싱크타운_첫생활구간_원고.md)로 구체화했다. 반복 공급과 무료/정액 경계는 [생활 경제와 상품](싱크타운_생활경제와_상품_설계.md)의 검증안을 사용한다. 실행·최종 자산·실학생 검증은 별도다.

## 1 첫 구간에서 완성할 경험

처음부터 보기 좋은 집과 산책길, 기본 영업 중인 찻집이 있다. 사장님은 작은 쉼터를 자기 방식으로 더 잘 쓰고 싶어 한다. 공방 주인에게는 작업 사이 잠깐 쉬고 싶은 바람이 있고, 연구원은 산책길의 식물을 관찰해 소개하고 싶어 한다. 주민들은 플레이어가 돕지 않아도 기본 생활을 이어간다.

플레이어는 기존 오른쪽 행동 목록에서 **자리 만들기 / 메뉴 만들기 / 식물 살펴보기 / 주민 이야기 듣기** 중 하나를 고른다. 네 갈래를 모두 끝내는 체크리스트나 공통 진행률은 두지 않는다. 첫 결과를 만든 뒤에는 쉼터를 이용하거나 그냥 나갈 수 있고, 다른 갈래는 나중에 직접 고른다. 소통을 원치 않으면 개인 산책·꾸미기를 계속할 수 있다.

| 범위 | 첫 구간의 기준 |
|---|---|
| 입장과 상품 | 앱 내부 TOPIK 1급+ 통과와 해당 체험·정액 권한을 확인한다. 첫 완결 경로의 준비물·도움·결과 관람을 선택 상품 구매로 막지 않는다. [상품 검증안](싱크타운_생활경제와_상품_설계.md#products)은 네 경로와 각 재료 없는 첫 후속·재방문 결과를 무료 첫 챕터에 포함한다. |
| 개인과 공동 | 첫 쉼터는 **개인 이야기 범위의 편집 슬롯**이다. 공용 마을의 기본 지형·날씨·다른 사람 배치를 변경하지 않는다. 개인 이야기 장면에는 타인의 실시간 캐릭터를 함께 표시하지 않는다. 공동 행사·공개 기여는 C08의 별도 슬롯과 권한을 사용한다. |
| 집과 주민 | C06의 개인 집 초대와 이 쉼터의 주민 만남은 별개다. 쉼터 참여가 집 방문·공개 소개·이웃 공유 동의로 확대되지 않는다. |
| 사용자의 선택 | 직접 고른 활동을 우선한다. 한 번 고른 갈래를 성격이나 영구 취향으로 확정하지 않는다. 관측 추정은 확인 전까지 추천 후보에만 쓰고 경로를 잠그지 않는다. |
| 쉬운 한국어 | 처음에는 물건 하나·행동 하나를 짧게 제시한다. 그림·되묻기·다시 듣기·뜻 도움을 써도 같은 생활 결과를 얻는다. NPC의 따뜻함이나 물건 품질을 언어 정답률로 차등화하지 않는다. |
| 시간과 조작 | 오른쪽 고정 행동 목록과 대상 이름을 사용한다. 동시에 가능한 대상은 숨기지 않는다. 결과를 보려고 현실의 특정 날씨·시각까지 기다리지 않는다. 소리 끔·움직임 줄이기에서도 같은 사실을 확인할 수 있다. |

## 2 네 경로의 선택과 실제 결과

아래 갈래는 제작용 구분이며 사용자에게 코드나 엔진 이름을 표시하지 않는다. 공통 시작은 같아도 바꾸는 대상과 주민 행동이 다르다. 완료 조건은 결과물·사용 가능 상태의 확정이고, 그 결과를 실제 화면에서 본 기록은 별도로 남긴다.

| 경로 | 시작부터 실제 완료까지 | 선택에 따른 현재 차이 | 다음 방문과 자발적 후속 |
|---|---|---|---|
| 생활 제작 | 사장님의 바람 확인 → 재료 마련 또는 기존 물건 활용 → 제작/배치 미리보기 → 소유·소비·유효 배치 확정. C02와 C05의 제작·사용 계약을 재사용한다. | **차양 만들기:** 바깥 대기 자리와 서빙 동선이 생긴다. **기존 처마 좌석 옮기기:** 안쪽에 앉는 자리와 그쪽 서빙 동선이 생긴다. 제작하지 않은 갈래를 제작 공로로 기록하지 않는다. | 같은 배치가 실제로 쓰인다. C02A 받침대 만들기 또는 C02B 안내 그림 고르기를 직접 선택할 수 있다. 두 후속을 모두 요구하지 않는다. |
| 작은 가게 | 딸기 마련 → 차/잼 선택 → 조리 조건 확인 → 한 묶음 제작·인도 확정. C03을 사용하고 실제 재고를 남긴다. | **생과일 차:** 차림표와 과일을 넣는 동작. **잼 곁들임:** 잼 병 진열과 빵·차에 곁들이는 동작. 첫 완성분으로 손님에게 실제 제공한다. | 재고가 있으면 해당 메뉴를 사용하고, 없으면 기본 메뉴로 영업하되 함께 만든 기록은 남는다. C03A 맛 비교 또는 C03B 설명·진열, 이후 C07의 주문 대안을 고를 수 있다. |
| 발견 정원 | 연구원의 짧은 위치 단서 → 산책길에서 식물 확인 → 관찰/허용 표본 중 선택 → C04 인도·전시 → 쉼터의 관찰 자리를 선택적으로 꾸민다. | **관찰:** 원래 식물은 남고 온실에 비교 카드가 놓인다. **표본:** 허용된 표본이 온실에 놓이고 원래 지점은 채집 상태가 된다. 쉼터의 화분은 별도 준비물로 마련하며 관찰 카드에서 식물이 생기지 않는다. | C04A의 다른 특징 관찰 또는 C04B의 안내·배치를 고른다. 화분을 배치했다면 주민이 그 식물을 살펴보는 이용이 이어진다. 새·나비 방문은 별도 검수된 생태 장면이 준비된 뒤 확장한다. |
| 주민 사연 | 사장님과 공방 주인의 바람을 각각 듣기 → 두 사람이 가능한 방법을 확인 → 만날 곳과 역할 선택 → 합의한 실제 이동·차 제공 확정. 합의만으로 만남 완료를 기록하지 않는다. | **공방 주인이 쉼터로 온다:** 기본 좌석 또는 내가 만든 자리에 앉고 사장님이 차를 낸다. **사장님이 공방에 차를 가져간다:** 공방의 기본 받침 자리에서 쉬며 찻집 기본 영업은 보조 주민이 맡는다. 기본 음료·보조 운영이 가능한 제작 장면에서만 제안한다. | 다시 만날 때 합의한 방식의 쉬는 장면이 조건에 맞게 이어진다. 쉼터 장식에 의견을 나누거나, 공방 주인에게 내 집의 작은 받침 배치를 도움받는 다음 이야기를 직접 고를 수 있다. |

발견 경로는 온실 전시와 연구원의 실제 확인만으로 첫 성취를 완결한다. 쉼터 화분까지 해야 앞의 관찰을 인정하는 구조로 만들지 않는다. 사연 경로도 새 가구·새 메뉴를 먼저 만들 필요가 없다. 기본 좌석·기본 음료로 완결하고 다른 경로에서 만든 것이 있으면 실제 사용 가능한 경우에만 연결한다.

첫 쉼터의 C02·C03·C04는 같은 계정의 해당 이야기 인스턴스를 이어 쓴다. 사건집 입구로 먼저 수행했다면 통합 구간에서 다시 소비·지급하지 않고 현재 결과부터 이어 간다. C05는 제작·배치·사용 처리의 재사용이며 공방 가구와 쉼터 차양은 서로 다른 소유물이다. 공방 가구의 완료가 차양 완료를 대신하거나 그 반대로 자동 인정되지 않는다. 사연의 기본 음료 제공도 해당 만남의 실제 제공분과 완료 이력으로 관리하며 장면 재생으로 재고·수익을 생성하지 않는다.

사연 경로의 두 주민은 처음부터 정해진 성격·목표를 가진다. 플레이어에게 맞추려고 취향을 바꾸지 않는다. 서로의 요청은 각각 듣거나 전달받은 경우에만 알고, 플레이어가 하지 않은 전달을 생략된 대화로 만들어 내지 않는다. 뜻이 불확실하면 “여기로 와요?” 같은 확인과 두 장면 그림으로 해결한다. 오답·느린 응답 때문에 합의가 깨지거나 관계·재료가 줄어들지 않는다.

사연의 첫 도움 뒤에는 주민이 플레이어에게도 도움을 준다. 공방 주인의 받침 배치 도움은 **내가 부탁할 때 열리는 선택**이며, 공개 칭찬이나 매일 받는 선물이 아니다. 한 번의 배치 도움과 물건 지급이 있다면 각각의 완료·소유 기록을 분리하고 같은 만남 재생으로 다시 지급하지 않는다.

### 첫 성취 뒤에 이어질 다른 역할

각 경로에는 첫 재료를 다 썼어도 선택할 수 있는 후속 하나를 함께 제작한다. 아래의 기존 안내판·카드·가구는 주민의 기본 비품이며 새 재료 납품을 요구하지 않는다. 후속은 자동 시작하지 않고 사용자가 기존 목록을 열 때 제안한다. 다른 후속은 실제 준비물·언어 변형·동작이 준비됐을 때만 열린다.

| 이미 한 일 | 다음에 직접 고를 수 있는 일 | 새로 달라지는 장면 |
|---|---|---|
| 차양 또는 처마 자리 완성 | C02B에서 기존 안내판의 그림·위치를 고른다. 손님이 어느 자리로 가야 할지 쉽게 알리는 역할이다. | 손님이 안내를 확인하고 선택한 자리로 이동한다. 안내를 바꾸면 현재 동선도 맞춰 바뀐다. |
| 차 또는 잼 메뉴 완성 | C03B에서 기존 주문판에 내 메뉴를 소개하는 그림과 짧은 설명을 고른다. 추가 시식·납품은 필요 없다. | 주인이 해당 소개를 가리킨다. 현재 재고가 없으면 함께 만든 메뉴로 소개하고 판매 가능하다고 말하지 않는다. |
| 표본 또는 관찰 카드 전시 | C04B에서 현재 전시의 안내 그림과 배치를 고른다. 발견한 것을 다른 주민이 알아보게 돕는 역할이다. | 방문 주민이 해당 표본/카드 앞에 멈춰 실제 특징을 살펴본다. |
| 두 주민의 첫 만남 완료 | 다음 쉬는 자리의 방향을 함께 고른다. 쉼터 방문 합의면 기본 의자의 방향, 공방 방문 합의면 기존 받침 자리를 바꾼다. | 두 주민이 바뀐 자리에서 각각 앉거나 차를 놓는다. 다른 장소 갈래의 동작이 섞이지 않는다. |

후속까지 마치면 한동안 익숙해진 공간을 편하게 즐길 수 있다. 더 큰 정원·다른 작물·새 주민의 사연은 제작된 다음 팩의 별도 목표다. 최근 행동을 근거로 같은 일을 더 많이 시키거나 이미 본 후속의 이름만 바꾸지 않는다.

## 3 재료를 기르고 찾고 만드는 과정

### 첫 구간의 공급과 보관

첫 구간은 소수 재료로 모든 갈래를 시험한다. 시작 재료는 **해당 주민이 첫 일을 위해 제공하는 계정별 한정 준비물**로 기록한다. 앱 재설치·재접속·경로 변경·구독 갱신으로 다시 지급하지 않는다. 거절하거나 미완 상태에서 경로를 바꿔도 이미 받은 미사용 재료는 보관하며, 재료를 다시 받으려면 앞의 지급과 남은 수량을 먼저 확인한다.

| 준비물 | 첫 설계 수량과 출처 | 사용과 보존 |
|---|---|---|
| 기본 생활 도구 | 개인 화단과 물뿌리개, 공방 도구 이용권. 최초 한 번 제공하며 내구도 소모 없음 | 적합한 행동에서 자동 선택한다. 도구 구매·수리 때문에 첫 성취가 막히지 않는다. |
| 딸기 모종과 바로 쓸 재료 | 모종 1개와 사장님이 마련한 딸기 1묶음 | 직접 기르기 또는 받은 딸기로 먼저 요리하기를 고른다. 출처를 구분한다. 제공 재료를 써도 재배를 나중에 해볼 수 있다. |
| 목재와 천 | 손질 목재 2개·천 1개를 공방 주인이 제공 | 차양 한 세트에 쓰거나 보관한다. 기존 좌석 이동은 재료를 쓰지 않는다. 첫 지원 재료와 완성품은 이 구간에서 재판매·거래하지 않는다. |
| 관찰 도구와 표본 | 수첩, 개인 관찰 지점의 채집 허용 식물 1개 | 관찰은 아이템을 소모하지 않는다. 표본 인도 뒤 보관함과 원래 장소에서 동시에 소유하지 않는다. |
| 쉼터 화분 | 전시 뒤 연구원이 제공하는 화분 하나를 받을 수 있음 | 관찰/표본 양쪽에 동등하게 제공한다. 원래 식물·온실 표본과 별개 개체다. 받기는 선택이며 계정의 해당 목표당 한 번이다. |

수량은 첫 구간 검증용 출발값이다. 지원물은 기존 보관함의 생활 재료 칸에 자동 정리하고 그 때문에 다른 소유물을 버리게 하지 않는다. 사용하는 화면에서 현재 보유·예약·이번 소비분만 보여 준다. 관찰 카드·레시피·함께한 기록은 소모 재료와 분리한다. 공동 창고·플레이어 거래·판매 재화는 이 첫 구간의 선행 조건으로 두지 않는다.

### 재배

재배는 **모종 고르기 → 개인 화단에 심기 → 성장 확인 → 수확 → 사용처 선택**으로 완결한다. 심기 확정 때 모종을 한 번 소모한다. 첫 설계값은 심은 뒤 120초에 한 번 수확 가능한 딸기 1묶음이며, 물 주기 한 번은 남은 성장 시간을 최대 30초 줄인다. 물을 반복해서 주어 속도나 보상을 계속 늘리지 않는다. 이는 게임의 압축된 성장 시간이고 실제 농업 지식이나 확정 운영 수치가 아니다.

성장은 권위 있는 경과 시간으로 계산하고 미접속 중에도 진행한다. 기기 시계 변경으로 추가 수확을 만들지 않는다. 오프라인 미확정 수확은 공통 저장 규칙에 따라 복원 후 검증하며 확정 재료처럼 거래·공동 제출하지 않는다. 다 자란 작물은 기다리고, 물을 안 주거나 오래 접속하지 않았다고 죽거나 줄어들지 않는다. 남은 시간을 상시 카운트다운으로 압박하지 않고 대상에서 성장 단계와 준비 여부를 볼 수 있게 한다.

사용자는 자라는 모습을 보거나 다른 생활을 하거나 나갈 수 있다. 요리를 바로 끝내고 싶으면 이미 받은 딸기를 쓴다. 그 경우 NPC는 “직접 기른 딸기”라고 말하지 않는다. 첫 수확은 한 번이며 재수확·새 모종의 반복 공급은 운영 팩에서 정한다. 첫 구간만으로 무한 수확·영업 수익이 성립한다고 가정하지 않는다.

### 산책과 발견

첫 단서는 쉬운 말과 위치 그림으로 제공한다. 예를 들어 “다리 옆에 있어요”를 확인하고 짧은 산책길에서 대상의 생김새를 비교한다. 가까이 가면 `[살펴보기]`와 허용 대상의 `[표본 가져가기]`를 구분해 보여 준다. 모르는 표현의 도움은 즉시 볼 수 있고 잘못 찾아가도 도구·재료·관계 손실은 없다.

첫 관찰 대상은 개인 진행에 귀속하며 다른 플레이어의 채집으로 고갈되지 않는다. 같은 지점에 돌아오면 이미 살펴본 대상임을 유지한다. 관찰 카드는 지식 기록이고 화분·작물·판매 자원이 아니다. 표본을 가져갔다가 반환하면 원래 지점과 온실을 함께 갱신한다. 반환·재채집으로 첫 발견·전시·화분 보답을 재발행하지 않는다.

다음 발견은 C04A의 특징 비교처럼 **다른 관찰 내용**이 있을 때 제공한다. 현실의 특정 시각·계절에 맞춰 들어와야만 필수 재료를 얻거나 이야기를 끝내게 하지 않는다. 채집 재생·희귀도·수십 종 도감은 후속 운영 설계이며 첫 지점 재방문을 새 콘텐츠로 계산하지 않는다.

### 제작과 요리

첫 제작은 재료만 모아 제출하고 화면 밖에서 끝나는 방식으로 처리하지 않는다. **용도 선택 → 재료 확인 → 모양/배치 미리보기 → 만들기 → 완성물 확인 → 배치/인도 → 실제 이용**을 연결한다. 반복 망치질이나 빠른 입력을 필수로 하지 않고 재료·용도·위치를 고르는 판단을 남긴다.

| 첫 레시피 | 입력 | 확정 산출물 | 실제 이용 |
|---|---|---|---|
| 작은 차양 | 손질 목재 2개 + 천 1개 | 차양 세트 1개 | C02의 바깥 자리·동선 검사 뒤 주인과 손님이 이용 |
| 생과일 차 | 딸기 1묶음 + 사장님이 제공하는 해당 조리분 기본 재료 | 첫 제공용 차 2인분 | 한 몫은 플레이어, 한 몫은 손님에게 제공. 아직 내지 않은 몫은 중단 후 이어 감 |
| 잼 곁들임 | 딸기 1묶음 + 사장님이 제공하는 해당 조리분 기본 재료 | 첫 제공용 곁들임 2인분 | 첫 시식 몫과 잼 진열/레시피 기록을 구분 |

기본 조리분은 최초 제공 딸기와 최초 수확분을 사용하는 두 제작분까지만 준비한다. 음료/곁들임을 볼 때마다 다시 생성하지 않는다. 직접 생산·제공·구매 경로는 같은 요리 결과를 만들 수 있으나 출처별 공로는 구분한다. 상용 구매 경로는 재화·가격·공급표가 정해진 뒤 연결하며 첫 완결의 유일한 재료 경로가 될 수 없다.

미리보기는 자원을 쓰지 않는다. 만들기 확정 때 보유·예약·사용분을 검증하고 재료 소비와 산출물 기록을 함께 확정한다. 제작 연출 중 나가도 완료 여부를 다시 읽어 이어지며 재료를 두 번 빼지 않는다. 미사용 예약은 취소 시 풀고, 이미 만든 차양은 보관·재배치할 수 있지만 원재료와 동시에 복제하지 않는다. 차양에서 처마 좌석으로 바꿔도 차양 소유는 남고 첫 보상은 다시 생기지 않는다.

첫 제작물은 개인 보관 상태를 거쳐 찻집의 허용 슬롯에 배치한다. 차양은 플레이어 소유·찻집 배치로 기록해 회수할 수 있다. NPC에게 인도해 소유가 바뀌는 물건은 그 범위를 먼저 안내한다. 첫 시식으로 소비된 음료는 취소로 되돌리지 않는다. 언어 선택을 다시 확인하거나 도움받는 것 자체는 재료 소비 명령이 아니다.

### 편해지는 성장과 운영의 경계

같은 준비를 다시 선택하면 이전 레시피와 도움 설정을 불러오고 이번 재료·수량처럼 달라진 조건만 확인한다. 확인한 개인 화단의 수확을 묶어서 처리하거나 기본 조리를 주민에게 맡기는 편의는 후속 생활 팩에서 사용할 수 있다. 처음부터 필요한 접근성·기본 도움을 보상으로 잠그지 않는다. 자동 작업은 생활 결과만 만들며 독립 한국어 수행으로 기록하지 않는다.

이 첫 구간의 완성물·레시피·기념·관계는 재료 공급을 쉬어도 유지된다. 반복 영업은 선택이며 [생활 경제 검증안](싱크타운_생활경제와_상품_설계.md#production)에 가격·매입·판매량·재료 소비·NPC 기본 조달·오프라인 처리 한도를 정했다. 구현에서 이 조건이 준비된 운영 팩만 연다. 게임 생활 재화와 유료 외형 상품을 구분하고 옛 숙제 포인트를 새 경제에 자동 적용하지 않는다. 한정 지원 재료의 재판매와 무한 기본 조달로 수익을 만들지 않는다.

<a id="atlas"></a>
## 4 아틀라스가 읽고 바꾸고 보여 줄 것

마을은 실제 가능한 행동을 먼저 정하고 아틀라스는 그 안에서 다음 경험과 언어 도움을 연결한다. 자동 개인화는 진행 중인 선택을 바꾸지 않고 다음 장면 경계에 적용한다. 사용자가 요청한 도움은 즉시 제공한다. 다음 표의 생활 상태·NPC 기억 연결은 **추가 구현할 계약**이며 현재 학습 API의 지원 필드로 넣지 않는다.

| 단계 | 읽을 근거 | 판단과 소비처 | 사용자에게 남는 결과 |
|---|---|---|---|
| 시작 후보 | 입장 권한, 지금 고른 활동, 대상·재료·배치·NPC 일정, 앞 사건 완료 | 마을이 실행 가능한 경로를 추린다. 기존 행동 목록에서 사용자가 고른다. 제외 이유는 필요한 자리에서 쉬운 말로 안내한다. | 없는 재료나 닫힌 이야기로 유도하지 않고 원하는 활동을 시작 |
| 언어와 도움 | Strata의 검수된 목표, Core의 같은 영역·응답 방식·자체 난도별 필요, Trail의 도움/새 자료 기록 | 준비된 듣기·읽기 후보와 Vellum 도움을 실제 대화·제작·주문 화면에 연결한다. 처음에는 짧은 문장, 이후 검증된 변형을 사용한다. | 뜻을 이해해 선택할 수 있고 도움을 써도 같은 물건과 결과를 얻음 |
| 생활 확정 | 사용자가 확정한 용도·소모·소유·배치·두 주민의 합의 | 마을이 사건과 현재 상태를 저장한다. 학습 정답 점수가 세계를 직접 바꾸지 않는다. | 고른 메뉴·물건·만남 방식이 실제로 남음 |
| 기억과 표현 | 해당 주민이 직접 받거나 보거나 전달받은 사건, 현재 물건 상태, 기존 반응 이력 | 마을의 생활 요약·검수된 반응 후보와 Loom의 실제 동작·정지 대안을 장면이 소비한다. Trail·Vellum에 필요한 생활 기억·반응 확장은 별도 계약으로 구현한다. | 같은 주민이 실제 아는 일을 기억하고 내 물건을 같은 모습으로 이용 |
| 다음 선택 | 완료한 결과, 본인이 원하는 방향, 아직 하지 않은 다른 문제·역할·결과, 미완 약속 | 의미가 다른 후속을 `available`로 둔다. 사용자가 다음 일을 열 때 제안하고 없으면 익숙한 생활을 제공한다. | 이전 선택과 이어지면서도 새 용도나 역할을 스스로 고름 |

Core의 현재 문항 반복 감점은 생활 이야기의 의미 반복 방지가 아니다. 생활 후보에는 원인 사건·문제·선택·결과·NPC 맥락을 따로 붙여 비교한다. 이름만 바꾼 납품을 새 의뢰로 세지 않는다. 하나의 공통 시작에 두세 개의 제작된 해결 경로를 두고 다음 이야기로 합류하되 선택의 물건·메뉴·합의는 보존한다. 무한 생성형 대화를 필수로 하지 않는다.

추천 이유가 필요할 때는 실제 사실만 짧게 전한다. 예를 들어 ‘잼을 만들었으니 설명을 골라 볼 수 있어요’는 완료한 레시피를 근거로 한다. ‘원래 꼼꼼한 사람이니까’처럼 성격을 붙이지 않는다. 오늘 다른 일·덜 추천·추천 제외·취향 추정 정정의 기존 범위와 되돌리기를 유지한다. 한 사람의 비공개 학습 약점을 주민 전체에 전달하지 않는다.

### 같은 생활 목표를 다른 방법으로 배우기

| 연습할 의미 | 제작 경로 | 가게 경로 | 발견 경로 | 사연 경로 |
|---|---|---|---|---|
| 물건과 위치 | “여기에 둬요”를 듣고 받침 자리 고르기 | “여기에 놓아요”를 듣고 제공 자리 고르기 | “다리 옆에 있어요”의 장소 찾기 | “여기로 와요”의 만날 곳 확인 |
| 수량이나 한 가지 조건 | 필요한 재료 수 확인 | 한 주문의 수량 확인 | 검수된 두 관찰 대상의 특징 비교 | 가능한 장소 둘 중 요청에 맞는 곳 확인 |
| 이유와 대안 | 통로를 비우는 다른 배치 제안 | 품절일 때 준비된 대안 안내 | 표본 대신 관찰로 남기는 이유 | 오기 어려울 때 차를 가져가는 방법 조율 |

표는 콘텐츠 제작 목표다. 첫 장면에 모든 행을 동시에 넣지 않는다. 해당 능력의 검수된 문항·음성·응답 방식이 있을 때만 학습 관측으로 연결하고, 단순 재료 전달·자동 조리·그림 따라 하기만으로 독립 숙련을 인정하지 않는다. 듣기 재생 실패와 언어 오류를 구별한다. 이유·중급 담화·쓰기 등 현행 지도 밖의 능력은 추가 교육 검수 대상으로 남긴다. 이 구간만으로 TOPIK 4급 교육과정이나 점수를 충족한다고 표시하지 않는다.

## 5 사용자가 자기 변화를 알아보는 장면

각 경로는 **선택 전 비교 → 현재 방문의 실제 쓸모 → 다음 방문의 지속 → 원할 때 확인하는 원인 기록**을 한 묶음으로 제작한다. 장면이 표시됐다는 로그는 사람이 알아봤다는 증거와 구분한다.

| 시점 | 반드시 보일 것 | 피할 오인 |
|---|---|---|
| 선택 전 | 차양/좌석, 차/잼, 표본/관찰, 방문/차 전달의 서로 다른 결과 그림과 짧은 말 | 화려한 쪽이 정답처럼 보이거나 아직 만들지 않은 물건이 현재 세계에 놓임 |
| 완료 직후 | 플레이어가 고른 색·용도·위치와 같은 대상, 실제 가능한 주민 이용 한 장면 | 기본 물건을 쓰며 내 제작품이라고 말함, 시식 몫 없이 제조만 반복함 |
| 다음 방문 | 현재 남은 배치·진열·표본/카드·합의에 맞는 생활 동작 | 매번 처음 받은 것처럼 감사, 철거·품절·반납을 무시하는 동작 |
| 원할 때 기록 열기 | 기존 이웃 수첩의 ‘함께한 일’에서 실제 행동·출처·현재 결과·대상으로 가기 | 성취 점수판, 원시 로그, 추천 가중치, 남이 만든 결과의 내 공로 표시 |

완료 장면은 사용자가 결과 보기를 고를 수 있게 같은 방문 안에 마련한다. 맑은 날 차양은 실제 그늘 또는 달라진 서빙 동선으로 확인한다. 식물은 연구원이 직접 살펴보거나 돌본다. 사연은 두 주민이 실제로 이동·응대할 수 있는 짧은 합의 장면으로 제작하며, 접근 불가·일정 변경 때 존재하지 않은 만남을 회상으로 대신하지 않는다. 기존 합의의 가능한 대안을 확인하고 원하는 때 이어 간다.

NPC 반응의 원인 한 문장은 완성물 곁에서 짧게 제공한다. 예: “여기에 앉아요”, “이 잼을 써요”, “보내 준 꽃이에요”. 플레이어가 표본 대신 관찰을 보냈다면 마지막 문장은 관찰 기록을 가리키는 표현으로 바꾼다. 대사 최종본은 초급 어휘·주민 설정 검수 후 사용한다. 자막·음성·애니메이션을 모두 봐야만 보상을 받는 조건은 없다.

결과를 보고 나면 자동으로 다음 의뢰·설문·광고를 이어 붙이지 않는다. 후속은 기존 목록에서 직접 고르고, 그냥 머무르는 것도 완결된 플레이다. 오래 쉬었다 돌아오면 현재 결과 하나와 남은 행동 하나만 안내한다. 완료 기록과 보관 물건은 유지하고 밀린 유지보수 과제를 생성하지 않는다.

## 6 연결이 완성됐는지 확인할 기준

다음은 앞으로 구현·콘텐츠 검수·학생 관찰에서 사용할 인수 기준이다. 문서 작성만으로 통과한 것으로 표시하지 않는다.

| 검사 | 비교 상황 | 통과할 때의 실제 증거 |
|---|---|---|
| 네 입구의 독립 완결 | 새 계정으로 한 경로만 선택 | 다른 세 경로의 완료·재화 구매·출석 없이 준비→선택→현재 효용→종료 가능 |
| 선택의 인과 | 같은 초기 상태에서 A/B/아무것도 안 함 | 결과물·동작·후속 조건이 다름. 미참여에는 플레이어 공로 없음 |
| 재배 전 과정 | 심기·물 주기/생략·중단·장기 부재·시계 변경·중복 수확 | 정한 성장·산출만 적용, 작물 손실·시간 조작 추가 수확 없음, 바로 쓸 재료의 출처 정확 |
| 발견과 소유 | 관찰/표본·반환·다른 계정 채집·재방문 | 원래 지점·보관·온실 상태 일치, 관찰 카드의 자원 변환·보답 재지급 없음 |
| 제작과 소비 | 미리보기·확정 응답 유실·연출 중 종료·배치 실패·회수 | 한 번 소비·한 번 산출, 미확정 예약 해제, 재료와 완제품 복제 없음 |
| 두 주민의 이야기 | 전달 전/합의 후/직접 만남/대안 선택 | 각 주민의 인지 근거·이동·차 제공·보조 영업이 일치. 집 초대·공개 동의 확대 없음 |
| 언어와 생활 분리 | 같은 선택을 쉬운 말·도움·독립 수행으로 각각 완료 | 생활 결과와 기본 보답 동일, 학습 근거만 다름. 이해 오류로 재료·관계 손실 없음 |
| 추천과 실제 소비 | 활동 변경·취향 정정·후보 소진·새 학습 기록 | 진행 장면 고정, 다음 장면에 적합한 언어 적용, 존재하는 다른 후속 또는 정직한 기본 활동 |
| 편해지는 성장 | 같은 레시피 재사용·보조 처리·장기 미납품 | 반복 입력이 줄고 성과 유지. 보조 작업을 독립 학습으로 세지 않음 |
| 개인과 공동 | 다른 플레이어 완료·C08 참여·마을 이동·다른 기기 | 개인 성과·학습이 대체되지 않음. 같은 계정의 현재 결과 복원, 새 주민의 허위 기억 없음 |
| 접근성·종료 | 소리 끔·정지 표현·결과 관람 건너뛰기·즉시 종료 | 원인과 대상 구별 가능, 강제 카메라·재촉 없이 확정 성과 보존 |
| 상품·반복 공급 | 체험 끝·구독 만료·재가입·지원물 재요청 | 시작한 체험 인과 묶음의 허용 범위 명시, 보관·기록 보존, 재료/첫 보상 재발급 없음 |

실제 학생에게는 먼저 설명을 더하지 않고 플레이와 재방문을 관찰한다. 이후 “무엇이 달라졌나요?”, “어떤 선택과 이어졌나요?”, “다음에 하고 싶은 일이 있나요?”를 묻는다. 초급자는 말 대신 물건·장면을 가리킬 수 있으며 도움 조건을 기록한다. **자기 결과를 알아봄 / 원인을 잘못 연결함 / 도움 뒤 알아봄 / 발견하지 못함**을 구분한다. 표현 로그·접속 시간·보상 수령만으로 체감 성공을 판정하지 않는다.

처음 고른 활동이 다른 학생, 한국어·게임 경험이 다른 학생의 결과를 구분해 본다. 다른 경로로 같은 생활 목적을 완결할 수 있는지, 쉬었다 돌아와도 성과를 누리는지, 후속이 숙제로 느껴지는지, 이전과 다른 선택을 스스로 찾는지를 확인한다. 특정 경로의 변화가 자주 안 보이면 대사를 늘리기 전에 대상 위치·동작·전후 차이·원인 연결을 고쳐 다시 확인한다. 작은 관찰 결과를 전체 이용자의 만족이나 학습 효과로 일반화하지 않는다.

## 7 제작 순서와 남은 범위

1. 기존 C01과 C02로 사건 확정·실제 동작·기억·복원을 검증한다. 이것은 공통 연결 검증이며 생활 게임 전체의 완성이 아니다.
2. 첫 쉼터에서 제작 경로의 재료 마련→완제품→배치→현재 이용→재방문을 연결한다. 동시에 메뉴·발견·사연 경로의 선행·대안·결과를 콘텐츠 표로 준비한다.
3. 같은 저장·표현 계약으로 나머지 세 입구를 연결하고 각 입구만 선택한 계정으로 완결을 확인한다. 타 분야를 강제로 거치게 되는 의존성을 제거한다.
4. 익숙한 작업의 편의, 주민의 보답, 의미가 다른 후속을 넣고 반복·소진을 검사한다. C08 공동 행사는 개인 완결 뒤 선택적으로 연결한다.
5. 초급 실제 플레이 관찰에서 인과·자율성·언어 부담·재방문을 확인하고 수정한다. 중급 생활과 TOPIK II 학습·평가는 별도 검수된 콘텐츠로 확장한다.

초급 대사·선택·도움·동작·복귀는 [첫 원고](싱크타운_첫생활구간_원고.md), 후속의 실제 분량·편성과 소진은 [재방문 원고](싱크타운_재방문_콘텐츠와_원고.md), 반복 공급·판매·상품 경계는 [생활 경제와 상품](싱크타운_생활경제와_상품_설계.md)에 작성했다. [학습 지도와 창작 과제](싱크타운_TOPIK4_학습설계와_원고.md)는 중급 확장의 제작 기준이다. 출시 전에는 이 원고의 교육 검수·실제 데이터/그림/동작/음성 제작, 저장·권한·기기 성능과 학생 관찰을 마쳐야 한다. 수량·시간·가격은 최종 균형이나 상용 콘텐츠 분량을 보장하지 않는 검증안이다.

## 8 참고작에서 가져온 구조

[기존 Steam 조사](마을_생활경영_스팀조사_20260921.md)의 Stardew Valley 생활 순환, Sandrock의 목적 있는 제작, Parkitect의 배치와 실제 이용, Mistria의 주민 사연을 첫 쉼터에서 연결한다. Farm Together 2의 작업 보조는 편해지는 성장에, Dinkum·Roots of Pacha·Littlewood·Planet Zoo의 공간·기여·주거·관찰 모티브는 발견과 후속 생활에 적용한다. 원작의 전체 콘텐츠·전투·복잡한 공장·모든 경영 지표를 채택한 것은 아니다. 참고작의 평가나 기능은 싱크타운의 만족·학습 효과 증거로 사용하지 않는다.
