# 싱크타운 첫 쉼터 제작 원고

2026-10-02. 사용자가 「전부 제대로 설계하고 원고도 해줘」라고 요청한 범위 중 첫 체험의 실제 장면 원고다. 처음의 재미는 **내가 고른 자리·메뉴·전시·만남을 주민이 실제로 이용하는 모습**이다. 처음부터 네 활동을 전부 할 필요가 없다.

설계 정본은 [첫 생활 구간](싱크타운_첫생활구간_설계.md), 반복 공급·상품은 [생활 경제와 상품](싱크타운_생활경제와_상품_설계.md), 다음 이야기는 [재방문 원고](싱크타운_재방문_콘텐츠와_원고.md), 언어 과제는 [TOPIK 4 학습 원고](싱크타운_TOPIK4_학습설계와_원고.md)를 따른다. **대사·선택·행동·복원까지 작성한 제작용 1차 원고이며, 실제 게임·녹음·미술·교육 검수·학생 효과 검증 완료를 뜻하지 않는다.**

## 1 원고를 읽고 제작하는 기준

표의 화살표는 **다음 말풍선으로 나누어 보여 주는 순서**다. 한 칸의 여러 문장을 한꺼번에 읽히지 않는다. `FT` 식별자와 상태 설명은 제작용이며 화면에 표시하지 않는다. 화면의 대사는 따옴표 안 문구다. 버튼은 대괄호 안 문구다. 본인의 답은 고르기·조립·주제 안 직접 답하기로 바꿀 수 있고, 발화를 요구하지 않는다.

| 역할 | 고정된 바람과 표현 | 첫 장면에서 하지 않는 말 |
|---|---|---|
| 찻집 사장님 | 손님이 편히 쉬고 맛있는 차를 마셨으면 한다. 잔·자리·손짓으로 먼저 보여 준다. 「여기요」, 「같이 마셔요」 | 성적·출석을 평가하는 말, 도와주지 않아 서운하다는 말 |
| 공방 주인 | 오래 앉아 작업해서 잠깐 다른 곳에서 쉬고 싶다. 물건을 직접 써 본다. 「여기 어때요?」, 「편해요」 | 학습자를 떠보는 반말·관용구, 끝없는 납품 부탁 |
| 연구원 | 식물을 정확히 관찰하고 다른 사람에게 보이기를 원한다. 손가락으로 특징을 짚는다. 「잎을 봐요」 | 초급자에게 학술어를 쏟거나 채집을 더 좋은 선택으로 평가하기 |

세 역할의 최종 이름·외형·성우는 별도 제작에서 정한다. 기존 할머니·분식집 사장님·슬의 설정을 이 원고로 덮어쓰지 않는다. 마스코트는 동작·그림 말풍선으로 돕고 새 음성 캐릭터로 만들지 않는다. 녹음용 NPC 대사는 본문 그대로이며 실제 음원은 아직 없다.

**도움 공통 H1.** `[다시 듣기] [뜻 보기] [보기로 답하기] [나가기]`를 유지한다. 뜻 보기는 해당 물건 확대·두 장면 비교·이미 지원하는 보조 언어 뜻을 사용한다. 도움 설정을 열려면 먼저 어려운 한국어를 읽어야 하는 구조를 피한다. 의도를 확신하지 못하면 「이거예요?」와 두 그림을 보여 주고 확인 전에는 생활 명령을 실행하지 않는다. 설명이 길어지면 「그림으로 볼까요?」, `[그림 보기] [계속하기]`로 마친다. 첫 체험에서는 잘못 알아들은 답을 자동 확정하지 않는다.

**언어 공통 L1.** 선택에 정답이 없는 취향·배치·만남은 채점하지 않는다. 실제 듣기·읽기 과제로 등록된 항목만 도움·시각 단서·첫 응답·새 문항 여부를 구분해 관측한다. 그림으로 진행한 성공을 독립 듣기 성공으로 만들지 않는다. 새 말은 한 번에 한 가지를 소개하며, 어느 경로를 오래 했는지로 난도를 올리지 않는다.

**연출 공통 V1.** 대상에 가까워지면 기존 오른쪽 행동 목록을 쓴다. 물건을 정확히 직접 누르는 조작은 필수가 아니다. 선택 전 두 결과를 같은 크기로 미리 보고, 확정 후에는 선택한 물건과 실제 이용 동작이 같은 화면에 들어오게 한다. 카메라 강제 이동·자동 퀘스트 팝업은 없다. 움직임 줄이기는 ‘선택 전 / 지금’ 정지 장면으로, 소리 끔은 짧은 자막과 물건 표시로 같은 결과를 전달한다. 둘 중 하나만 실제로 만들었는데 두 결과를 동시에 현재 모습으로 보여 주지 않는다.

**저장 공통 S1.** 선택 초안, 자원 예약, 실제 확정, 화면 전달을 분리한다. 장면 ID만으로 보상을 다시 주지 않는다. 이 표는 새 구현 계약의 원고이지 기존 Atlas에 이미 있는 저장 필드가 아니다. 상세는 [세계 상태 계약](../아틀라스_구현명세.md#town-world-contract)이다. 완료 안내와 후속 제안은 분리하고 후속은 목록을 직접 열 때만 나타난다.

## 2 도착과 첫 선택 — FT00

**입장:** 앱 내부 TOPIK 1급+ 통과 후. 처음에는 아래의 쉬운 표현으로 시작한다. 구독 여부로 대사의 친절함이나 도움을 바꾸지 않는다. 네 경로와 각 첫 후속은 유한한 무료 첫 챕터에 포함하는 상품 설계안이다.

| 장면 | 보이는 것과 실제 원고 | 선택과 결과 |
|---|---|---|
| FT00.01 도착 | 이미 예쁜 찻집·기본 좌석. 사장님이 손을 흔든다. 「안녕하세요」 | `[안녕하세요] [둘러보기]`. 둘러보기면 인사 답변을 요구하지 않는다. |
| FT00.02 관심 | 사장님 「뭐 할까요?」. 의자·차·잎·두 사람 그림을 각각 표시한다. | `[자리 만들기] [메뉴 만들기] [식물 보기] [이야기 듣기]`. 한 목록에서 모두 볼 수 있다. 쉬운 뜻 도움은 각각 ‘자리 / 차 / 꽃 / 이야기’ 그림이다. |
| FT00.03 자유 | `[산책하기]`를 택하면 길을 열어 둔다. 사장님 「천천히 봐요」 | 목표 미수락 상태. 후속 알림·실패·보상 손실 없음. 돌아오면 FT00.02 목록을 직접 열 수 있다. |
| FT00.04 재방문 | 이미 한 경로는 현재 결과를 보여 준다. 처음 인사·처음 지급을 반복하지 않는다. | `[내 자리 보기]` 등 실제 상태의 행동과 아직 안 한 경로를 표시. 완료율 1/4, 4/4 보상, 모두 하라는 안내 없음. |

## 3 자리 만들기 — FT10 / 기존 C02

**목표:** 바깥 그늘 자리 또는 기존 처마 아래 자리를 만든 뒤 손님이 실제로 앉고 사장님이 차를 가져간다. 차양은 플레이어 소유, 의자·찻집 기본 비품의 소유권은 주민에게 있다. 새 말은 `밖 / 안`을 먼저 그림으로 보여 주고, 차양의 전문 명칭을 읽어야 진행하는 구조로 만들지 않는다.

| 장면 | 대사·그림·행동 원고 | 확정 및 분기 |
|---|---|---|
| FT10.01 부탁 | 사장님이 기본 의자를 가리킨다. 「여기 앉아요」 → 바깥 빈 자리와 안쪽 자리를 보여 주며 「어디가 좋아요?」 | `[밖이 좋아요] [안이 좋아요] [나중에요]`. 앞 두 선택은 미리보기이며 소비 없음. |
| FT10.02A 밖 미리보기 | 현재 날씨 그대로인 바깥 자리에 천 지붕의 반투명 미리보기. 공방 주인 「작은 지붕을 만들어요」. 목재 둘·천 하나 그림. | `[만들기] [다시 고르기]`. 최초 지급 이력 확인 후 목재 2·천 1을 지급. 지급 후 나가도 미사용분 보관. |
| FT10.02B 안 미리보기 | 기존 처마 아래 빈 자리에 의자 실루엣. 사장님 「여기로 옮겨요」 | `[옮기기] [다시 고르기]`. 재료 소비 0. 필요 없는 목재를 먼저 받게 하지 않는다. |
| FT10.03A 만들기 | 공방 주인이 천과 목재를 맞추고 플레이어가 색 견본을 고른다. 「어떤 색이 좋아요?」 | 기본 무료 색 `[초록] [노랑]`. 반복 망치질 없음. 확인판 ‘나무 2 / 천 1 → 작은 지붕 1’. `[만들기]` 때 한 번 소비·차양 1 생성. 색은 한국어 시험이 아니다. |
| FT10.03B 옮기기 | 의자에 손을 대는 동작, 이동 미리보기. 「여기 어때요?」 | 안쪽 허용 위치 두 곳을 그림으로 선택. 의자를 복제하지 않고 기존 배치를 변경한다. |
| FT10.04 자리 확정 | 바깥은 차양 아래 기본 의자, 안쪽은 기존 의자를 배치. 길 위에 놓으면 발자국 그림이 막힌 부분을 표시한다. 「여기는 길이에요」 → 「옆은 어때요?」 | `[옆에 놓기] [직접 고르기]`. 자동 대안도 미리보기 후 `[여기에 놓기]`. 유효 배치·통로를 확인한 뒤 확정. |
| FT10.05 실제 이용 | 손님이 선택된 자리로 걸어와 앉는다. 사장님이 같은 경로로 잔을 놓는다. 손님 「편해요」 | 사용 중인 의자·차양의 실제 개체를 가리킨다. 이용 가능한 배치 확정과 표현 전달 기록은 별개. 접속을 끊으면 미전달 이용 장면부터 보여 준다. |
| FT10.06A 결과 말 | 사장님 「함께 만든 자리예요」 → 「여기서 쉬어요」 | 만든 차양이 현재 배치돼 있을 때만. 햇빛이 실제로 가려진 장면에는 선택 대사 「그늘이 생겼어요」를 쓸 수 있다. 밤·비 장면에는 그늘 효과를 현재 사실로 말하지 않는다. |
| FT10.06B 결과 말 | 사장님 「옮긴 의자예요」 → 「여기서 쉬어요」 | 이동한 의자가 현재 배치돼 있을 때만. ‘만든 그늘’ 대사와 혼용 금지. |
| FT10.07 끝 | `[앉기] [둘러보기] [나가기]` | 첫 목표 완료. 후속은 FT51을 직접 선택할 때 시작한다. |

**현재 결과와 다음 방문.** 바깥을 골랐으면 해당 색 차양과 바깥 서빙 동선, 안을 골랐으면 처마 의자와 안쪽 동선이 남는다. 사장님이 실제 사용 중인 자리를 손으로 보여 주며 「이 자리에 앉아요」. 첫 감사는 반복하지 않는다. 차양을 회수하면 기본 좌석으로 돌아가며 「그늘을 만들었어요」라는 과거 기록은 남아도 현재 그늘을 가리키지는 않는다. 새로 배치하기는 언제든 가능하고 첫 보상·재료가 재생성되지 않는다.

**수첩 문구.** A `찻집 밖에 그늘을 만들었어요.` / B `의자를 안으로 옮겼어요.` + 확정된 물건 그림 + `[지금 보기]`. 읽기는 선택이다. 도움을 쓴 사람의 기록도 같은 성취 문구다.

**중단·자원 예외.** 제작 전 중단은 예약만 해제. 제작 직후 중단은 보관함의 차양부터 배치하며 다시 소비하지 않는다. 이미 차양이 있으면 `[내 그늘 놓기]`; 목재가 부족하면 `[가진 것 보기] [안에 자리 만들기]`. 유료 재료 구매를 유일한 대안으로 내지 않는다. 물건을 놓았지만 이용 장면을 안 봤다면 다음 직접 방문에 현재 배치의 이용을 보여 준다.

## 4 메뉴 만들기 — FT20 / 기존 C03

**목표:** 딸기를 차 또는 잼으로 만들어 실제 두 몫을 제공한다. 어느 쪽이든 레시피와 함께 만든 기록이 남는다. `딸기 / 차`를 먼저 물건으로 소개하고 잼은 선택 화면에서 병·빵 그림과 함께 소개한다. `직접 재배`는 필수 선행이 아니다.

| 장면 | 대사·그림·행동 원고 | 확정 및 분기 |
|---|---|---|
| FT20.01 재료 | 사장님이 딸기를 보여 준다. 「딸기예요」 → 「같이 만들까요?」 | `[만들어요] [나중에요]`. 미수락은 지급/소비 없음. |
| FT20.02 마련 | 딸기가 담긴 바구니와 모종 화단을 같은 크기로 보여 준다. 「여기 딸기가 있어요」 | `[이걸 쓸게요] [길러 볼래요]`. 지급은 계정당 딸기 1묶음+모종 1개, 다시 열어도 잔량만 표시. |
| FT20.03G 심기 | 모종을 빈 개인 화단에 미리 놓는다. 「여기에 심어요」 | `[심기]` 확정 시 모종 1 소비. `[물 주기]`는 선택. 실제 심은 시점부터 120초, 최초 물 주기만 최대 30초 단축. |
| FT20.04G 기다리기 | 싹·꽃·열매의 현재 단계. 「자라고 있어요」 | `[산책하기] [받은 딸기 쓰기] [나가기]`. 물을 안 줘도 자라고 다 자란 뒤 기다린다. 접속 유지·기다림을 완료 조건으로 삼지 않는다. |
| FT20.05G 수확 | 익은 딸기와 `[딸기 따기]`. 확정 뒤 손에 딸기를 든다. | 첫 수확 딸기 1묶음. 받은 재료와 생산 출처를 구분한다. 시계 검증 대기는 공통 예외 FT90.05. |
| FT20.06 메뉴 | 잔과 잼 병·빵을 보여 준다. 사장님 「뭘 만들까요?」 | `[딸기차] [딸기잼]`. 두 결과 모두 선택 가능하고 정답 없음. |
| FT20.07A 차 순서 | 사장님이 손질된 딸기 그림을 짚는다. 「딸기를 넣어요」 → 잔 두 개에 준비된 물을 붓는다. 「물을 넣어요」 | `[만들기]` 확인 전은 미리보기. 확정 때 딸기 1묶음+기본 조리분 1회 소비, 차 2인분 생성. 불 조작·속도 입력 요구 없음. |
| FT20.07B 잼 순서 | 사장님이 작은 냄비를 짚는다. 「딸기를 넣어요」 → 완성된 잼과 빵을 보여 준다. 「빵에 발라요」 | 딸기 1묶음+기본 조리분 1회 소비, 곁들임 2인분 생성. 조리 시간은 강제 대기가 아닌 생략 가능한 연출. 실물 잼 재고와 기념 빈 병 분리. |
| FT20.08 전달 | 사장님 「하나는 여기요」 → 플레이어 자리 그림. 「하나는 손님께요」 → 손님 자리 그림. | 쉬운 대안은 문장을 나누어 각 잔/접시를 차례로 빛낸다. `[놓기]`는 아직 제공하지 않은 몫만 제공·소비. 이해 시험으로 몰래 채점하지 않는다. |
| FT20.09 이용 | 손님이 실제 받은 차를 마시거나 잼 바른 빵을 먹는다. 「맛있어요」. 플레이어는 `[마시기]` 또는 `[먹기]`로 자기 몫을 이용하거나 두고 갈 수 있다. | 손님 1인분 제공 완료로 첫 공동 시식 결과를 확정. 플레이어가 자기 몫을 끝까지 먹어야 완료되는 구조는 아님. 남은 몫 보관/현재 제공 상태 유지. |
| FT20.10 출처 | 받은 딸기: 사장님 「함께 만든 차예요」 또는 「함께 만든 잼이에요」. 직접 수확분: 「기른 딸기예요」 → 「같이 만들었어요」 | 실제 해당 제작 배치의 출처만 사용. 받은 딸기를 쓴 뒤 나중에 수확했다고 과거 조리의 출처를 바꾸지 않는다. |
| FT20.11 끝 | 레시피 그림과 첫 기록이 남는다. `[메뉴 보기] [둘러보기] [나가기]` | 실제 남은 양만 제공 가능으로 표시. 첫 지원/수확 조리분은 판매 금지다. 레시피가 있다고 무한 재고가 되지 않는다. 첫 후속 FT52는 추가 조리분 없이 가능. |

**다음 방문.** 아직 제공되지 않은 음식이 있으면 `[이어 내기]`. 다 썼으면 사장님은 기본 차를 내고, 첫 메뉴의 그림은 ‘함께 만든 메뉴’로 남는다. 쉬운 표시 `지금은 없어요`와 기본 메뉴를 함께 보여 준다. 판매 중 표지와 품절 표지를 겹치지 않는다. 「왜 안 가져왔어요?」 같은 재입고 독촉은 하지 않는다.

**수첩 문구.** `딸기차를 함께 만들었어요.` / `딸기잼을 함께 만들었어요.`. 재배 선택자는 별도 사실 `딸기를 길렀어요.`가 붙는다. 처음 준비된 두 조리분으로 차와 잼을 각각 해 볼 수 있지만 2/2 달성을 요구하지 않는다.

**중단·변경.** 메뉴 선택 중 변경은 소비 0. 조리 확정 뒤 바꾸려면 완성품은 그대로 남기고 남은 재료로 새 배치를 만든다. 두 조리분을 모두 썼으면 레시피 보기·기본 메뉴·FT52는 계속 가능하고 반복 재료는 경제 정본의 별도 생활 활동을 따른다. 손님이 이미 먹은 한 몫을 재접속으로 다시 생성하거나 팔지 않는다.

## 5 식물 보기 — FT30 / 기존 C04

**목표:** 산책길에서 식물을 알아보고 관찰 카드 또는 허용 표본을 온실에 전시한다. 연구원이 실제 특징을 확인하면 끝이다. 식물은 검수 전 가상의 `동그란 잎 식물`로 표시하며 실제 종의 효능·서식 특성을 가르친다고 주장하지 않는다.

| 장면 | 대사·그림·행동 원고 | 확정 및 분기 |
|---|---|---|
| FT30.01 단서 | 연구원이 다리 그림과 동그란 잎 그림을 차례로 보여 준다. 「다리 옆에 있어요」 | `[찾아볼게요] [길을 보여 주세요] [나중에요]`. 길 안내를 고르면 짧은 경로 그림을 먼저 보고 이동 도움을 켤 수 있다. |
| FT30.02 찾기 | 두 식물은 모양이 눈에 띄게 다르고 이름표가 있다. 오른쪽 목록 `[잎 보기]`. 연구원 단서를 언제든 다시 본다. | 엉뚱한 대상도 관찰 가능. 소모·감점 없음. 진행 대상인지 불확실하면 목표 잎 그림을 나란히 보여 준다. |
| FT30.03 발견 | 대상의 동그란 잎 확대. 「잎이 동그래요」. 실제로 한 특징만 짚는다. | `[그림 남기기] [식물 가져가기]`. 후자는 채집 허용 표지가 있는 해당 개인 개체만. 그림 선택은 사진 촬영 권한이 필요하지 않은 관찰 카드다. |
| FT30.04A 관찰 | 수첩에 잎 그림과 관찰 장소가 기록된다. 식물은 땅에 남는다. 「그림이 있어요」 | 관찰 카드 생성 한 번. 식물 아이템/판매 자원 생성 없음. |
| FT30.04B 표본 | 작은 삽으로 허용된 식물을 화분에 옮긴다. 원래 자리는 빈 흔적과 표본 이동 표지가 된다. 「같이 가요」 | 같은 개체의 위치가 보관 상태로 변경. 원래 장소와 온실에 복제 금지. |
| FT30.05 돌아오기 | 온실의 연구원 「보여 주세요」 | `[그림 보여 주기]` 또는 `[식물 놓기]`. 현재 가진 대상만 가능. 물건 전달 확정 전에 소유·위치 재확인. |
| FT30.06A 전시 | 관찰 카드가 온실 받침 위에 놓인다. 연구원이 카드와 잎 그림을 비교한다. 「동그란 잎이에요」 | 관찰 전시 완료. 실제 식물은 산책길에 그대로 있음. |
| FT30.06B 전시 | 표본 화분이 온실 받침 위에 놓인다. 연구원이 같은 개체 잎을 살펴본다. 「여기서 볼 수 있어요」 | 표본 전시 완료. 인도/관리와 회수·반환 가능 범위를 표시. |
| FT30.07 끝 | `[전시 보기] [산책하기] [나가기]`. 연구원 「고마워요」 | 첫 발견 경로 완결. 화분 선물·쉼터 방문·다른 분야 체험은 완료 조건 아님. |
| FT30.08 선택 선물 | 완료 후 연구원 목록에만 `[작은 화분]`을 열어 둔다. 열면 별도 작은 화분을 가리키며 「이건 선물이에요」 | `[받을게요] [나중에요]`. 관찰/표본 똑같이 1개, 목표당 1회. 앞의 식물과 별도 개체로 보관함에 지급. |
| FT30.09 선택 배치 | 쉼터 허용 슬롯에 `[화분 놓기]`. 사장님은 실제 놓는 모습을 본 뒤 「화분을 놓았네요」 | 동선 검증 뒤 배치. 꽃이 없는 식물을 꽃이라고 부르지 않으며 연구원이 그 자리에 온 사실도 자동 생성하지 않는다. |

**다음 방문.** 관찰 선택자는 식물이 원래 자리에 있고 온실 카드가 남는다. 표본 선택자는 온실의 실물과 원래 자리의 현재 상태를 확인한다. 연구원 「여기서 잎을 봐요」는 실제 전시가 있을 때만 쓴다. 표본 반환 후에는 지난 관찰 기록은 남기되 현재 전시를 실물로 표현하지 않는다. 첫 후속 FT53은 카드/표본 각각의 현재 상태를 받아 같은 기본 안내 비품을 쓴다.

**수첩 문구.** A `다리 옆의 잎을 살펴봤어요.` + 현 위치 연결. B `식물을 온실에 놓았어요.` + 현재 보관/반환 상태. 표본을 가져간 선택만 더 높은 발견 점수로 표시하지 않는다.

**중단·반환.** 현장에서 나가면 현재 카드/개체 위치를 유지. 인도 전에 「온실에 놓을까요?」와 전후 그림으로 확인한다. 반환·재채집·전시 방식 변경은 같은 목표의 첫 보답을 반복 지급하지 않는다. 오랜 미접속으로 시들거나 연구원 관계가 떨어지지 않는다.

## 6 이야기 듣기 — FT40

**목표:** 두 주민의 말을 각각 듣고, 동의한 장소에서 실제 쉬는 시간을 연결한다. 다른 세 경로를 먼저 하지 않아도 기본 좌석·기본 차로 완결한다. 공방 방문을 고르려면 보조 주민의 기본 영업과 운반할 기본 차가 준비된 장면이어야 한다.

| 장면 | 대사·행동 원고 | 선택·인지·결과 |
|---|---|---|
| FT40.01 사장님 | 빈 찻잔 둘을 놓으며 「같이 차 마실까요?」 → 공방 그림을 가리키며 「공방에 친구가 있어요」 | `[제가 물어볼게요] [나중에요]`. 앞말은 플레이어에게 함께 묻자는 제안이며 NPC 동의는 아직 없음. |
| FT40.02 공방 주인 | 도구를 내려놓고 기지개. 「잠깐 쉬고 싶어요」 | `[차 마실까요?] [보기로 답하기] [나중에요]`. 여기까지 사장님은 공방 주인의 바람을 모른다. |
| FT40.03 가능성 | 공방 주인 「좋아요」. 밖 벤치와 공방 받침 그림. 「어디가 좋아요?」 | `[찻집에서요] [공방에서요]`. 플레이어의 제안이지 두 NPC의 확정 합의는 아님. |
| FT40.04A 제안 전달 | 공방 주인 「찻집으로 갈게요」. 플레이어가 사장님에게 `[여기로 와요]`를 전달. 사장님 「좋아요」 | 전달을 실제 선택한 후에만 사장님 인지 생성. 기본 자리 또는 실제 유효한 내 자리를 예약한다. |
| FT40.04B 제안 전달 | 공방 주인 「공방에서 마셔요」. 사장님에게 `[공방으로 와요]`를 전달. 사장님 「차를 가져갈게요」 | 보조 주민이 찻집에 나타나 기본 영업을 맡는 장면 확인. 차와 운반 경로를 확보. 불가능하면 FT40.E1. |
| FT40.05 재확인 | A 공방 주인에게 사장님의 동의를 전함: 「좋아요」. B 공방 주인에게 `[차를 가져와요]`: 「여기에 놓아요」 | 상대가 실제로 전달받은 뒤 양쪽 동의 완료. 위치 그림으로 확인할 수 있다. 말하기·긴 문장 암기 요구 없음. |
| FT40.06A 실제 만남 | 공방 주인이 도구를 정리하고 찻집으로 걸어와 앉는다. 사장님이 기본 차를 놓는다. 공방 주인 「편해요」 | 실제 이동·자리에 앉기·음료 제공 확정 후 만남 완료. 제작한 차양이 유효하면 그 아래를 쓰고 없으면 기본 자리. |
| FT40.06B 실제 만남 | 보조 주민이 기본 영업을 이어간다. 사장님이 공방으로 차를 옮겨 받침에 놓는다. 공방 주인 「같이 쉬어요」 | 공방에서 이동·제공 확정 후 완료. 쉼터 갈래의 좌석·감사·동선이 섞이지 않는다. |
| FT40.07 함께 쉬기 | 사장님 「차가 따뜻해요」 → 공방 주인 미소. 대화가 끝나면 배경 생활로 돌아간다. | `[같이 있기] [둘러보기] [나가기]`. 길게 머물거나 차를 마셔야 관계 인정되는 조건 없음. |
| FT40.08 보답의 입구 | 다음에 공방 주인 목록을 열면 `[자리 같이 보기]`가 available. 지금은 새 부탁을 띄우지 않는다. | 기본 첫 후속 FT54. 내 집 도움은 별도 초대 동의가 있는 재방문 원고의 선택 장면으로 연결. |

**다음 방문.** 합의한 장소와 실제 완료된 만남은 유지한다. 두 NPC가 현재 가능한 경우 배경에서 그 방식으로 쉬는 장면을 재사용할 수 있지만 이를 새로운 사건이나 보상으로 세지 않는다. 함께하지 못한 현재 시점에는 사장님은 자기 가게, 공방 주인은 자기 일상에 있다. 「지금 같이 쉬고 있어요」라는 거짓 문구를 내지 않는다. 플레이어가 선택하면 다음 만남 장소를 다시 상의할 수 있다.

**수첩 문구.** A `두 사람이 찻집에서 차를 마셨어요.` / B `두 사람이 공방에서 차를 마셨어요.`. 내 행동은 ‘초대 전달’ 그림으로 짧게 연결한다. 이 개인 사연은 이웃들에게 자동 공유하지 않는다.

**FT40.E1 가능한 장소 변경.** 사장님 「지금은 여기서 만나요」 + 쉼터 그림. `[여기서 만나요] [나중에요]`. 변경이면 공방 주인에게 다시 전달·동의를 받고 A로 진행한다. 자동으로 B를 A의 완료로 바꾸지 않는다.

**중단.** 한쪽에게만 전달했으면 다른 쪽 전달부터 이어 간다. 현재 조건이 바뀌었으면 직전 제안과 가능한 두 그림을 다시 보여 준다. 이미 만났다면 이동·차 소비를 재실행하지 않고 현재 결과를 보여 준다. 두 NPC가 플레이어가 실제로 전달하지 않은 사연·약점·취향을 알고 말하게 하지 않는다.

## 7 첫 성취 뒤의 네 원고 — 새 재료 없는 첫 후속

각 후속은 앞 경로 완료 후 스스로 목록을 열어 시작한다. 무료 첫 챕터에 포함한다. 새로 맡은 역할의 결과물을 주민이 실제로 사용하는 데까지 제작한다. 그림·색을 고르는 선택은 취향의 차이로 보존하고, 배치·방향처럼 기능을 바꾸는 선택은 실제 시선·동선에 반영한다. 모든 꾸미기 선택에 숨겨진 우열이나 기능 차이가 있다고 주장하지 않는다.

### FT51 길을 알려 주는 그림 — C02B

**전제:** 현재 유효한 바깥 또는 안쪽 자리. 기본 안내판 1개를 재사용하고 지급/판매하지 않는다.

1. 사장님 「자리를 알려 줘요」. 손님이 입구에서 안과 밖을 둘러본다. `[그림 고르기] [나중에요]`.
2. 의자 그림과 잔 그림을 비교한다. 「어떤 그림이 좋아요?」. `[의자] [차]`. 양쪽 모두 자연스러운 길 안내이며 정답 없음.
3. 실제 자리 쪽 화살표가 붙은 판을 입구 왼쪽/오른쪽의 유효 위치로 미리 놓는다. 「여기에 놓아요?」. `[놓기] [다시 고르기]`.
4. 손님이 판을 놓은 왼쪽 또는 오른쪽으로 다가가 선택한 그림을 확인한 뒤 **현재 내 자리까지 걸어가 앉는다**. 「여기네요」. 그림 종류는 외형 선택이고 판의 위치가 실제 확인 동선을 바꾼다.
5. 사장님 「그림을 보고 왔어요」. `[자리 보기] [나가기]`. 수첩 `자리로 가는 그림을 골랐어요.`.

**지속/복원:** 다음 방문에도 같은 그림·위치를 쓴다. 주 좌석 이동 시 화살표 목적지를 다시 확인하며 빈 곳으로 안내하지 않는다. 판 미리보기 중 중단은 이전 판 유지, 확정 뒤 중단은 판부터 복원한다. 쉬운 도움은 판→자리의 발자국 그림이고 도움으로 결과 차등 없음.

### FT52 내 메뉴를 보여 주기 — C03B

**전제:** 한 번 완성한 차 또는 잼. 새 음식 소비 없이 기존 주문판에 소개한다. 메뉴마다 동일 목표에서 배치를 고칠 수 있지만 신규 보상 반복 없음.

1. 사장님 「메뉴를 보여 줘요」. `[그림 고르기] [나중에요]`.
2. 현재 레시피에 맞는 그림 두 가지를 보여 준다. 차는 `[딸기 그림] [잔 그림]`, 잼은 `[딸기 그림] [빵 그림]`. 선택한 그림을 같은 기본 판에 넣는다.
3. 짧은 설명을 직접 고른다. 차 `[딸기차예요] [함께 만들었어요]`; 잼 `[딸기잼이에요] [함께 만들었어요]`. 말만 바꾼 것을 새 사건으로 세지 않는다.
4. 실제 주문판 확정. 사장님이 그 그림을 가리키며 방금 선택한 한 문장을 말한다. 손님은 판 앞에서 해당 메뉴를 살핀다.
5. 재고가 있을 때만 「마실 수 있어요」 또는 「먹을 수 있어요」. 없으면 「전에 함께 만들었어요」 + 현재 `함께 만든 메뉴` 칸, 기본 판매 메뉴는 별도 표시.
6. `[메뉴 보기] [나가기]`. 수첩 `함께 만든 메뉴를 소개했어요.`.

**지속/복원:** 판/설명/실재고를 따로 유지. 재고 변경에 따라 현재 제공 가능 문구만 바꾼다. 처음 시식 결과를 새로 생성하지 않는다. 도움은 차·잼 실제 그림이며, 듣기 정답으로 기록하지 않는다.

### FT53 잘 보이는 전시 — C04B

**전제:** 현재 온실의 카드 또는 표본. 주민 비품인 낮은 받침/벽면 안내 자리를 사용한다.

1. 연구원 「잎을 보여 줘요」. `[자리 고르기] [나중에요]`.
2. 카드 경로는 `[가까이] [나란히]` 두 유효 카드 배치, 표본은 `[앞쪽] [옆쪽]` 두 유효 화분 배치를 그림으로 보여 준다. 작은 키 방문객의 시야를 두 안 모두 확보한다.
3. 「이 그림 어때요?」. 동그란 잎 전체 그림/잎 가장자리 확대 그림 중 선택. `[이걸로 해요] [다른 그림]`.
4. 확정 후 방문 주민이 새 전시 위치에 와서 실제 카드나 표본을 바라본다. 「잎이 동그래요」. 연구원이 선택한 안내 그림을 짚는다.
5. `[전시 보기] [나가기]`. 수첩 `잎이 잘 보이게 놓았어요.`.

**지속/복원:** 실제 물건이 반환됐다면 옛 실물 전시를 보여 주지 않고 이미 보유한 관찰 기록의 카드 전시를 제안·확인한다. 방식 변경 자체를 두 번째 발견으로 세지 않는다. 쉬운 도움은 전후 그림이며 화분 선물을 받을 필요 없음.

### FT54 함께 쉬는 자리 — 사연 첫 후속

**전제:** FT40의 실제 만남 완료. 같은 갈래의 현재 조건이 유효할 때 시작한다. 새 가구 지급이나 집 초대 없음.

1. 공방 주인 「어디를 볼까요?」. 쉼터 갈래는 의자 방향 `[길 쪽] [정원 쪽]`, 공방 갈래는 받침 위치 `[창가] [작업대 옆]`을 그림으로 보여 준다.
2. 선택한 방향/위치를 미리 본다. 사장님 「여기 좋아요」. `[여기로 해요] [다시 고르기]`. 양쪽 기본 동선이 확보된 곳만 제안.
3. 확정하면 쉼터에서는 두 주민이 **그 방향으로 앉아 풍경을 보고**, 공방에서는 사장님이 **바뀐 받침에 차를 놓고** 공방 주인이 그 옆에서 쉰다. 새 만남 제공분은 판매 재고가 아닌 해당 장면의 기본 소품이다.
4. 공방 주인 「같이 보니 좋아요」 또는 공방 갈래 「여기서 쉬니 좋아요」. `[같이 있기] [나가기]`.
5. 수첩 `함께 쉬는 자리를 골랐어요.` + 실제 장소 그림. 다음 방문에도 같은 방향/위치를 사용하되 현재 NPC 일정이 맞을 때만 재연한다.

**중단/도움:** 미리보기는 기존 배치를 유지. 확정 상태는 재접속 후 그대로, 미전달 이용은 현재 조건으로 이어 보여 준다. 집 방문 권한으로 확대하지 않는다. 방향 단어가 어려우면 두 풍경 그림으로 답해도 완료와 관계가 같다.

## 8 같은 대사 반복을 피하는 실제 상태별 반응

아래는 랜덤 말바꾸기가 아니라 **현재 참인 조건**으로 고르는 짧은 원고다. 첫 감사는 완료 장면에서 한 번, 이후에는 현재 하는 일이나 플레이어가 직접 연 활동을 말한다. NPC가 보지 못한 사실은 별도 전달 전에는 사용하지 않는다.

| 사실/조건 | NPC 행동과 말 | 다음 선택 |
|---|---|---|
| 차양 제작, 지금 배치되고 실제 이용 중 | 사장님이 그 아래에 차를 놓고 「이 자리에서 쉬어요」. 실제 햇빛이 가려질 때만 「그늘에서 쉬어요」 대안 사용 | `[앉기] [자리 바꾸기]` |
| 차양 보관 중, 기본 좌석 이용 | 사장님이 기본 의자를 가리키며 「여기 앉아요」 | `[앉기] [내 그늘 놓기]` |
| 처음 만든 메뉴 재고 없음 | 주인이 기본 차를 내며 「오늘은 이 차예요」 | `[기본 메뉴] [만든 메뉴 보기]` |
| 관찰 카드만 전시 | 연구원이 카드 속 잎을 짚으며 「이 그림을 봐요」 | `[그림 보기] [산책하기]` |
| 표본 현재 온실에 있음 | 연구원이 실제 잎을 짚으며 「이 잎을 봐요」 | `[잎 보기] [전시 바꾸기]` |
| 사연 전달 한쪽만 완료 | 전달할 대상만 목록에 표시. NPC는 아직 합의를 축하하지 않음 | `[말 전하기] [나중에요]` |
| 함께 쉬는 장소가 공방 | 공방 받침에 차를 놓음. 「여기서 쉬어요」 | `[같이 있기] [자리 보기]` |
| 한동안 안 들어옴 | 해당 주민의 기본 인사 「안녕하세요」. 현재 결과 유지 | 기존 활동과 현재 가능한 새 원고만 제안 |

**언어가 발전했을 때의 세 원고.** 초급 `차 주세요`는 사라지지 않는다. 별도로 수량 이해를 확인하고 학생이 새 표현을 수락하면 `차 두 잔 주세요`, 조건 이해를 배운 뒤에는 `딸기차가 없으면 기본 차 주세요`, 이유 설명을 고르면 `창가가 밝아서 그쪽에 놓고 싶어요`를 준비한다. 단어만 어려워지는 것이 아니라 주문 수량·대안 선택·배치 이유라는 다른 역할을 수행한다. 각 문장의 실제 과제·평가·도움은 학습 원고로 연결하며, 생활 장면을 완료했다는 이유로 이 문장들을 다 안다고 추정하지 않는다.

## 10 제작 자산과 확인할 결과

첫 제작은 동일한 기본 장소를 재사용한다. 기존 승인 자산이 있는지는 실제 제작 시 자산 경로에서 확인하고 새 스타일·마스코트 외형을 임의로 만들지 않는다. 누르는 UI는 [펠트 부품](펠트부품/README.md)의 승인 자산과 마감 기준을 따른다.

| 묶음 | 필요한 실제 자산 | 완료 판단 |
|---|---|---|
| 장소 4영역 | 찻집/바깥·처마 자리, 공방/받침, 다리 산책길, 온실 전시 슬롯. 개인 화단은 기존 집 영역 재사용 | 이동 가능·상호작용 목록·소유 구역 일치 |
| 자리 | 차양 2색, 기존 의자, 유효 배치 2안씩, 안내판 2그림, 실제 서빙 경로 | 선택한 색·위치·NPC 이용 개체가 일치 |
| 메뉴 | 딸기/모종/성장 3단계, 차 2몫/잼 곁들임 2몫, 레시피/재고/기념 표시 | 식품 몫·현재 판매 여부·기념 장식 혼동 없음 |
| 발견 | 모양이 다른 식물 2종, 동일 목표 식물의 현장/보관/온실 상태, 관찰 카드, 별도 선물 화분 | 표본과 카드가 실제로 구분되고 복제 없음 |
| 주민 | 사장님·공방 주인·연구원·손님·보조 주민의 필요한 걷기/앉기/보기/서빙/작업 동작 | 대사 없이도 무엇을 이용하는지 보임 |
| 도움 | 두 결과 비교 그림, 단어 뜻 그림, 한 행동 강조, 방향·자리 정지 대안 | 소리 끔·움직임 줄이기·말하기 없이도 완결 |
| 음성 | 이 원고의 검수 통과한 NPC 대사별 음원과 자막. 배우/도구/비용은 별도 선정 | 원고 확정 후 제작·전 구간 청취. 현재는 원고만 있음 |

**원고 검수 순서:** 먼저 각 경로 A/B/하지 않기를 소리 없는 스토리보드로 비교한다. 자원 지급·소모·물건 위치·현재 이용을 대조하고, 그다음 초급 학습자에게 대사를 읽혀 어려운 단어/복수 지시를 고친다. 자유 입력의 허용 의도와 되묻기는 [대화 인식 검수](../대화_설계.md#11-재는-법과-시험지)를 통과해야 한다. 본 원고가 자유 입력 200개 시험지나 실제 음성을 대신하지 않는다.

**실제 플레이 확인:** 같은 시작 계정에서 네 경로 각각만 완료 → 즉시 나갔다 복귀 → 도움을 전부 쓴 계정과 비교 → 다른 배치/재고/반환으로 현재 상태 변경 → 한쪽만 전달한 사연 복원 → 구독 없이 첫 후속 완료를 확인한다. 학생에게 먼저 정답을 설명하지 않고 ‘무엇이 달라졌는지’ 말하거나 가리키게 한다. 상태 로그 정상과 학생의 체감은 각각 판정한다.
