# SYNK 마스코트 큐브 시안 (2026-11-19)

유호님이 11-19에 말씀하신 생각을 움직이는 시안으로 지은 것이다. 말씀은 이렇다. 「synk 마스코트가 아직 없잖아(몽글이는 synk lab 마스코트). 지금 싱크 플랫폼의 구 모양 말고 하나 더 시안을 만들고 싶어. 네모 모양으로. 큐브 느낌인데 미래에서 온 큐브. 엄청 똑똑한 큐브 느낌으로.」

아직 고르신 것은 없다. PC 앱과 홈페이지에는 아무것도 옮기지 않았다. 지금의 검정 구는 그대로다.

## 보는 법

- 아티팩트: <https://claude.ai/artifact/Fiy4YxsV6oKTDFuZhD68jJ>
- 저장소에서 볼 때는 `node tools/지면서버.js 8765`를 띄우고 `http://localhost:8765/docs/디자인/SYNK마스코트_큐브_20261119/큐브.html`을 연다. 앱 안 브라우저에서는 `.claude/launch.json`의 「시안지면」으로 띄운다.
- 큐브에 손을 올리면 그쪽을 본다. 큐브를 누르면 잠깐 생각한다. 위의 「표정」 막대로 평소, 웃음, 생각 중, 잠을 바꿔 본다. 「평소」에서는 큐브가 12초에 한 번씩 스스로 생각한다.
- 큐브 옆의 작은 그림 셋은 96, 44, 20픽셀로 줄인 모습이다.

## 후보 다섯

바탕, 빛, 글자는 [검정 구 시안](../플랫폼_클라이언트_검정구_20261116/README.md)과 같다. 눈은 검정 구의 점 눈(`desktop/renderer/orb-stage.mjs`)을 옮겼다.

| 마 4차원 큐브 | 선으로만 그린 4차원 큐브. 안쪽 큐브와 바깥 큐브가 자리를 바꾸며 돈다 | 더 빨리 돈다 |

Claude의 예측은 「가」다([고르심 장부](../../_ops/고르심기록.jsonl) 묶음 `SYNK큐브마스코트-20261119`).

## 짜임

`큐브.html` 한 파일이다. 가, 나, 다, 라는 셰이더 하나(WebGL)로 그리고 마는 2D 캔버스의 선으로 그린다. WebGL 문맥은 하나만 만들고, 그린 것을 캔버스마다 옮겨 찍는다. 화면이 버거우면 큰 무대의 해상도를 스스로 낮춘다.

아티팩트에 올릴 때는 문서 뼈대를 벗기고 SUIT를 파일 안에 심는다(`tools/lib/브랜드폰트.js`의 `면()`). 검정 구 시안의 `아티팩트판.cjs`와 같은 방법이다.

## 확인한 것과 못 한 것

11-19에 앱 안 브라우저로 1280과 375 폭에서 다섯 큐브, 네 표정, 생각하는 동작이 그려지는 것을 확인했다. 콘솔 오류와 가로 넘침은 없었다. 확인하는 동안 브라우저 창이 가려져 있어 화면이 1초에 두 번만 그려졌다. 그래서 움직임의 빠르기와 부드러움은 재지 못했다.
