# synk.im 탭 아이콘 (2026-11-28)

synk.im 브라우저 탭의 아이콘을 솔리오 구로 바꾼다. 탭 제목은 그대로 둔다.

**상태:** 솔리오로 정했다. 카본 검수 뒤 공개한다.

## 요청과 결정

- 유호님 11-28: 「우리 홈페이지 그 도메인 사진인데 글귀랑 아이콘 바꿔줘. 솔리오로 바꾸거나 몽글로 바꿔주면 좋을것같아. 그리고 회사를 한마디로 뭐라고 하면 좋을까?」
- 시안을 보신 뒤 유호님 11-28: 「아 그럼 검색에서 불리해지면 탭 제목은 냅두자. 그리고 솔리오로 마스코트 하자」
- 그래서 탭 제목 「SYNK — 한국 유학, AI 강의, 광고」는 그대로다. 회사 한마디 후보(「AI 직원과 일하는 회사」 추천)는 탭에 쓰지 않았다.

## 아이콘

[탭모형.png](탭모형.png)는 밝은 탭과 어두운 탭에 지금 아이콘, 솔리오, 몽글을 나란히 놓은 그림이다.

- **솔리오(공개):** 앱 안 작은 구의 정본 규격(`desktop/renderer/orb-face.css`의 `.ofc-orb`)을 그대로 옮겼다. 새틴 검정 구에 작은 점 눈 둘이다. 어두운 탭에서도 윤곽이 보이게 가장자리 빛을 옅게 넣었다.
- **몽글(고르지 않음):** 정본 `docs/캐릭터/정본_4K/몽글_본체.png`의 실루엣만 따서 납작한 코랄로 채웠다.

그림은 [그리기.py](그리기.py)가 굽고, 탭 모형은 [탭모형.py](탭모형.py)가 그린다. 공개할 파일은 [공개](공개) 폴더에 공개 경로 그대로 있다.
