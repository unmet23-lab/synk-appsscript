# 솔리오 「처음 시작 · AI 팀 고르기」 시안 (2026-11-21)

솔리오를 처음 켜면 사무실에서 일할 AI 팀을 고르는 화면이다. 유호님이 11-21에 「직업 선택처럼 계정을 선택하는 화면」, 「AI 처음 사용하는 유저들에게 이해하기 쉽고 친숙하게」, 「카드 고르는것처럼 세개 골라서 추천해주는 기능」, 「각각 클릭하면 장단점을 쭈르륵 설명하게 애니메이션」이라고 하셨다. PC 앱에는 옮기지 않았다.

## 보는 법

- `node tools/지면서버.js 8765`를 띄우고 `http://localhost:8765/docs/디자인/솔리오_첫계정고르기_20261121/고르기.html`을 연다. 앱 안 브라우저에서는 `.claude/launch.json`의 「시안지면」으로 띄운다.
- 주소 끝에 `#claude`, `#gpt`, `#custom`을 붙이면 그 팀이 무대에 선 채로 열린다. `#quiz`는 추천받기, `#start-gpt`처럼 쓰면 연결 차례로 바로 간다. `#start-gpt-2`는 둘째 차례까지 이은 채로, `#start-gpt-open`은 사무실을 연 뒤로 연다.
- 아래 막대(처음부터, 좁은 창)는 시안을 조작하는 것이고 디자인의 일부가 아니다.
- 캡처는 `캡처/`에 있다.

## 세 팀

화면에서는 「메인 오케스트레이터」를 「팀장」이라고 부른다. 팀장은 사무실의 일감을 받아 나누고, 끝난 결과를 확인한다.

| 팀 | 팀장 | 함께 일하는 AI | 직원이 도는 곳 | 계정 | 앉는 부서 |
|---|---|---|---|---|---|
| 01 팀장 Claude | Claude | GPT, Gemini | 이 PC의 Claude Code와 Codex, Gemini는 API | Claude, ChatGPT 구독 로그인 + Gemini API 키 | 팀장은 기획부, GPT는 개발부, Gemini는 마케팅부 |
| 02 팀장 GPT | GPT | Claude, Gemini | 이 PC의 Codex와 Claude Code, Gemini는 API | ChatGPT, Claude 구독 로그인 + Gemini API 키 | 팀장은 기획부, Claude는 개발부, Gemini는 마케팅부 |
| 03 커스텀 | 내가 고름(없어도 됨) | 부서마다 내가 고름 | 부서마다 고른 곳 | 로그인 또는 API 키 | 고른 부서 |

팀이 바뀐 차례는 이렇다. 11-23 유호님 「그록봇을 빼고 1. (메인 오케스트레이터 클로드) + gpt 2. (메인 오케스트레이터 제미나이) + 클로드+gpt 3. 커스텀」으로 6판을 지었다. 이어서 「gemini는 지금 저렇게하면 정책위험이있다고알고있거든 … 좀 위험해보이면 1. (메인오케스트라 클로드) + gpt + gemini api 2. (메인오케스트라 gpt) + claude + gemini api」라고 하셨다. Gemini 팀장은 고객의 Google 구독으로 솔리오가 Antigravity(agy)를 불러 돌리는 길이다. Google 공식 FAQ는 다른 회사의 에이전트가 agy를 감싸 부르는 쓰임을 개인 요금제에서 지원하지 않는다고 적고 있고, 11-12에 Claude Code가 agy를 여러 개 동시에 돌린 Ultra 계정이 정지된 사례가 있다([결정 11-16](../../_ops/결정.md)). 솔리오에서는 고객 계정이 정지될 수 있어 위험하다고 보고, 7판에서 Gemini를 API 키로만 쓰는 대안으로 바꿨다.

유호님이 「이거 위주로 사무실 직원을 oauth랑 cli mcp 연결을 구상할 계획」이라고 하셨다. 구독 계정은 각 회사의 로그인(OAuth)으로 잇고, 직원은 이 PC의 공식 명령줄 프로그램(CLI)으로 돌고, 솔리오는 팀장에게 MCP로 일감과 부서 폴더를 건넨다. Gemini는 고객이 Google AI Studio에서 만든 API 키로 부른다. 화면에는 이 기술 이름을 쓰지 않는다.

## 유호님 평가

6판을 보시고 11-23에 「너무 훌륭해 깔끔하다」라고 하셨다. 좋게 보신 것은 6판 전체다. 팀 하나가 크게 서는 무대, 같은 검은 구 직원으로 구운 팀별 장면, 연결 차례에서 직원이 사무실 바닥의 자기 부서 자리로 가는 장면, 팀장을 「팀장」으로 부르는 쉬운 말이 들어 있다. 7판은 팀 구성만 바꾸고 이 짜임을 그대로 썼다. 솔리오의 다른 첫 화면을 지을 때 이 판에서 시작한다.

## 짓기 전에 정한 네 가지

1. **한 문장:** 사무실의 첫 팀과 팀장을 고른다.
2. **강조 순위:** 첫 1초에는 무대의 큰 장면 하나가 보인다. 그다음은 맨 위 한 문장과 오른쪽의 팀 이름이다. 그 아래에 고르고 시작하는 단추가 오고, 좋은 점과 아쉬운 점은 단추 아래에 이어진다.
3. **참고:** 짜임은 [참고 사이트 장부 5-2절](../참고사이트/README.md#5-2-앱-화면-견줌2026-11-21-path-유학-앱)의 토스와 당근에서 왔다(화면을 여는 것은 그림 한 장과 문장 하나). 같은 절에서 Flighty의 결정 단추 하나(알약), Wise의 숨기지 않는 내역, Duolingo의 캐릭터와 고르기를 가져왔다. 겉은 [솔리오 사무실 시안](../솔리오_사무실_20261119/README.md)의 검정 방(한 색, 급한 것만 밝음, 직원은 구의 분신)을 잇는다.
4. **순간마다 볼거리:** 아래 줄에서 팀을 누르면 무대의 장면이 바뀌고, 오른쪽 글이 위에서부터 한 줄씩 떨어진다. 추천받기에서는 고른 카드가 위의 손 칸에 들어간다. 연결에서는 차례를 이을 때마다 사무실 바닥에 직원이 나타나고, 마지막 차례에서 각자 부서 자리로 한 번 간다. 소리는 아직 넣지 않았다.

## 담은 것

1. **무대와 팀 줄:** 왼쪽에 고른 팀의 장면이 크게 서고, 그 아래 줄에 세 팀의 작은 그림과 이름이 있다. 처음에는 01이 무대에 서 있다. 오른쪽에는 팀 이름, 누가 팀장인지, 만든 회사, 「시작하기 쉬움」 막대, 일하는 AI, PC를 끄면 일하는지, 드는 돈, 어울리는 분이 있고, 그 아래에 「…을 고르고 시작」 단추가 있다.
   그림은 같은 검은 구 직원으로 구운 3D 장면이다. 1번은 긴 책상 끝의 팀장 구가 양옆의 두 구(노트북, 종이 더미)에게 일을 나눠 주는 장면(`판/gemini_055039.png`, 6판에서 Gemini 팀장 팀에 쓰던 판), 2번은 계획판 옆의 팀장 구가 둥근 탁자의 두 구에게 일을 설명하는 장면(`판/gpt_064916.png`), 3번은 높이가 다른 받침에 앉은 구 셋과 그들을 잇는 조절 다이얼이다. `tools/그림굽기.js`(Codex 그림 도구)로 구웠다. 지시문은 `판/지시문/`, 원본은 `판/`, 화면에 쓰는 판은 `그림/`에 있다. 물건이 뜨지 않게, 노트북 불빛은 쓰는 구에게만, 종이는 평평하게 구웠다. 구의 눈은 꽉 찬 작은 점 둘이고, 고리 · 홈 · 점 격자 무늬는 넣지 않았다.
2. **팀을 바꾸면 쭈르륵:** 오른쪽 글이 위에서부터 한 줄씩 떨어진다(줄마다 0.07초 늦게). 좁은 창에서는 장면, 팀 줄(세 칸), 글 순서로 쌓인다.
3. **카드 세 장으로 추천받기:** 물음 셋(AI를 써 본 적, 이미 쓰는 구독, 일을 맡기는 방식)에 카드를 한 장씩 고른다. 고른 카드마다 팀에 점수가 가고, 같으면 둘째 물음(쓰는 구독)이 가리키는 팀이 이긴다. 「둘 다 쓰거나, 아직 없어요」는 팀장 Claude를 가리킨다. 맨 위 문장이 「팀장 GPT가 잘 맞습니다.」와 그 팀이 해 주는 일을 말하고, 고른 카드 세 장은 그 아래 작은 글로 남는다. 추천받은 팀이 무대에 서고 「추천」이 붙는다.
4. **연결 차례와 자리에 앉는 직원:** 고르고 시작하면 왼쪽에 사무실 바닥(사무실 시안과 같은 일곱 부서와 앞쪽 입구), 오른쪽에 잇는 차례가 나온다. 차례는 팀장 프로그램 설치와 로그인, 다른 프로그램 설치와 로그인, Gemini 키 넣기, 솔리오와 연결이다. 이으면 그 직원이 입구에 나타나고, 마지막 「솔리오와 연결」에서 각자 부서 자리로 한 번 간다. 팀장은 조금 더 크고 이름 옆에 「팀장」이 붙는다. 다 이으면 「사무실 열기」가 켜지고, 열면 직원들이 웃는다. 시안에서는 단추를 누르면 이은 것으로 친다.
5. **글:** AI를 처음 쓰는 분이 읽는 말로 썼다. OAuth, CLI, MCP, 오케스트레이터 같은 기술 이름은 화면에 쓰지 않는다. 프로그램 이름(Claude Code, Codex)과 Google AI Studio는 차례 제목이나 설명에 쓰고 하는 일을 한 줄로 푼다. 무료 Gemini 키로 보낸 글은 Google이 학습에 쓸 수 있다는 점을 아쉬운 점에 적었다.

## 8판: 구를 정본으로(11-24)

- 세 그림(`그림/claude.jpg` · `gpt.jpg` · `custom.jpg`)을 같은 짜임 그대로 두고 구만 바꿔 다시 구웠다. 몸은 「구 가」(결을 깎은 검정 금속, 빛줄기 한 줄)이고, 눈은 세로 알약 둘이다([결정](../../_ops/결정.md) 11-16 「구의 모습」, [검정 구 시안](../플랫폼_클라이언트_검정구_20261116/README.md)).
- 원본은 `판/정본_claude_063834.png` · `판/정본_gpt_063541.png` · `판/정본_custom_063704.png`, 지시문은 `판/지시문/정본_*.txt`다. 바꿀 그림을 첫 장, 정본 구 기준 그림 `판/참고/정본구.png`를 둘째 장으로 주었다.
- 기준 그림은 사업계획서 심사 시안의 블렌더 구(`../솔리오_사업계획서_첫화면_20261123/블렌더/심사무대.py`)에 앱의 점 눈 규격으로 눈을 얹은 것이다.
- 다음에 구울 때 쓰는 공통 지시문(`판/지시문/공통.txt`)의 구 설명도 정본으로 바꿨다.
- 연결 화면 사무실 바닥의 작은 구 눈도 앱이 작은 크기에서 쓰는 꼴(세로로 조금 긴 점)로 맞췄다.
- 8판은 맹검에 내지 않았다.

## 9판: 4판 결로 되돌림(11-25)

8판의 금속 구를 보신 유호님이 4판 그림을 두고 「이 느낌이 맞긴한데」, 금속 구를 넣은 사업계획서 책상 장면을 두고 「완전 대놓고 3d라 오히려 좀 촌스러운」이라고 하셨고, 이어 「4판 결로 맞춰」라고 하셨다. 4판 결은 새틴 검정 구, 작은 둥근 점 눈, 작고 둥근 소품, 넓은 어둠이다. 「구 가」의 금속 결은 앱을 켤 때 뜨는 큰 구에만 쓰고 장면 속 구에는 입히지 않는다.

- 세 그림을 7판 그림으로 되돌렸다. 7판은 4판과 같은 결이고, 유호님이 「너무 훌륭해 깔끔하다」라고 하신 6판과 같은 굽기에서 나왔다. 커스텀은 4판 그림 그대로다. 8판 원본(`판/정본_*`)은 지우지 않았다.
- 공통 지시문(`판/지시문/공통.txt`)도 7판 판으로 되돌렸다. 연결 화면 사무실 바닥의 작은 구 눈은 둥근 점으로 되돌렸다.
- 팀장 Claude와 팀장 GPT 장면을 4판처럼 더 단순하게 다시 구울 지시문은 `판/지시문/4결_claude.txt` · `4결_gpt.txt`다. 4판 그림 둘(`판/duo_024730.png` · `판/custom_024910.png`)을 결 기준으로, 7판 원본을 짜임 기준으로 준다. 11-25 0시에는 굽기 계정 셋이 모두 주간 한도에 걸려 굽지 못했다(가장 이른 풀림 11-28 22:30).

## 미학 맹검

1~3판은 네 장 모두 기각이었다. 1판은 기술 이름과 선 그림, 2판은 흔한 다크 모드 틀, 3판은 카드 세 장과 비교표라는 짜임이 지적의 중심이었다. 짜임은 11-23 유호님 「Yes, rebuild it」로 5판에서 무대와 자리에 앉는 직원으로 바꿨다.
