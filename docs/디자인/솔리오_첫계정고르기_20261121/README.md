# 솔리오 「처음 시작 · AI 팀 고르기」 시안 (2026-11-21)

솔리오를 처음 켜면 사무실에서 일할 AI 팀을 카드로 고르는 화면이다. 유호님이 11-21에 「직업 선택처럼 계정을 선택하는 화면」, 「AI 처음 사용하는 유저들에게 이해하기 쉽고 친숙하게」, 「카드 고르는것처럼 세개 골라서 추천해주는 기능」, 「각각 클릭하면 장단점을 쭈르륵 설명하게 애니메이션」이라고 하셨다. PC 앱에는 옮기지 않았다.

## 보는 법

- `node tools/지면서버.js 8765`를 띄우고 `http://localhost:8765/docs/디자인/솔리오_첫계정고르기_20261121/고르기.html`을 연다. 앱 안 브라우저에서는 `.claude/launch.json`의 「시안지면」으로 띄운다.
- 주소 끝에 `#grok`, `#duo`, `#custom`을 붙이면 그 카드가 펼쳐진 채로 열린다. `#quiz`는 추천받기, `#start-duo`처럼 쓰면 연결 차례로 바로 간다.
- 아래 막대(처음부터, 좁은 창)는 시안을 조작하는 것이고 디자인의 일부가 아니다.
- 캡처는 `캡처/`에 있다.

## 짓기 전에 정한 네 가지

1. **한 문장:** 사무실의 첫 직원을 고른다.
2. **강조 순위:** 첫 1초에는 카드 세 장의 구 직원이 보인다. 그다음은 맨 위 한 문장과 「카드 세 장으로 추천받기」 단추다. 좋은 점과 아쉬운 점은 카드를 누른 뒤에만 나온다.
3. **참고:** 겉은 [솔리오 사무실 시안](../솔리오_사무실_20261119/README.md)의 검정 방(한 색, 급한 것만 밝음, 직원은 구의 분신)을 잇는다. [참고 사이트 장부 5-2절](../참고사이트/README.md#5-2-앱-화면-견줌2026-11-21-path-유학-앱)에서 Flighty의 결정 단추 하나(알약), Wise의 숨기지 않는 내역(좋은 점과 아쉬운 점을 나란히), Duolingo의 캐릭터와 고르기를 가져왔다.
4. **순간마다 볼거리:** 카드를 누르면 그 카드가 떠오르고 나머지는 물러선다. 막대가 왼쪽부터 차고, 좋은 점과 아쉬운 점이 한 줄씩 떨어진다. 추천받기에서는 고른 카드가 위의 손 칸에 들어간다. 소리는 아직 넣지 않았다.

## 담은 것

1. **카드 세 장:** 01 그록 봇(클라우드에서 혼자 일하는 비서), 02 Claude + GPT(내 PC에서 일하는 실무 직원 둘), 03 커스텀(부서마다 내가 고르는 팀). 카드마다 구 직원 그림, 「시작하기 쉬움」과 「맡길 수 있는 일」 막대, PC를 끄면 일하는지, 드는 돈이 있다.
2. **누르면 펼침:** 좋은 점과 아쉬운 점이 한 줄씩 차례로 떨어진다(줄마다 0.08초 늦게). 아래에 어울리는 분, 연결하는 법, 「…을 고르고 시작」 단추가 온다. 좁은 창에서는 누른 카드 바로 아래에 펼친다.
3. **카드 세 장으로 추천받기:** 물음 셋(AI를 써 본 적, 먼저 맡길 일, PC를 꺼도 일해야 하는지)에 카드를 한 장씩 고른다. 고른 카드마다 팀에 점수가 가고, 같으면 둘째 물음(맡길 일)이 가리키는 팀이 이긴다. 결과 카드에 「추천」이 붙고 펼쳐지며, 맨 위 문장이 고른 카드 세 장으로 까닭을 말한다.
4. **연결 차례:** 고르고 시작하면 팀마다 잇는 차례가 줄로 나온다. 줄마다 단추 하나이고, 기술 이름(OAuth, CLI, MCP)은 작은 꼬리표로만 붙인다. 다 이으면 「사무실 열기」가 켜진다. 시안에서는 단추를 누르면 이은 것으로 친다.
5. **글:** AI를 처음 쓰는 분이 읽는 말로 썼다. 기술 이름은 설명 글에 쓰지 않았다.

## 팀과 직원 연결의 짝

유호님이 「이거 위주로 사무실 직원을 oauth랑 cli mcp 연결을 구상할 계획」이라고 하셨다. 시안의 연결 차례는 아래 짝을 따른다.

| 팀 | 직원이 도는 곳 | 계정 | 일을 건네는 길 |
|---|---|---|---|
| 그록 봇 | 그록의 클라우드 | 그록 계정 로그인(OAuth) | 봇의 결과를 솔리오가 받는다 |
| Claude + GPT | 이 PC의 Claude Code와 Codex(CLI) | 각자 Claude, ChatGPT 구독 로그인(OAuth) | 솔리오가 MCP로 일감과 부서 폴더를 건넨다 |
| 커스텀 | 부서마다 고른 곳 | 로그인(OAuth) 또는 API 키 | 업무 도구(메일함, 노션)를 MCP로 잇는다 |

## 아직 확인하지 않은 것

- 그록 봇을 솔리오가 밖에서 부르고 결과를 받는 공식 통로(API, MCP, 웹훅)가 있는지 확인하지 않았다. 지금 아는 것은 grok.com 웹의 「봇」 칸과 CLI Grok Build(`grok -p`)뿐이다([AI 계정과 크레딧 · 그록](../../AI_계정과_크레딧.md#그록)). 통로가 없으면 1번 팀의 셋째 차례 「결과를 사무실로 받기」는 Grok Build CLI로 바꿔야 한다.
- 「월 1만 원 요금제부터」는 11-07 grok.com 요금표(Plus ₩10,000, 세금 별도)에서 왔다. Claude와 ChatGPT의 요금은 적지 않았다.
- 막대 값(쉬움 5·3·1, 맡길 수 있는 일 2·5·5)은 Claude의 판단이다.
