# 홈페이지 만들기

1. **받은 사실을 적어 둔다.** 가게 이름, 하는 일, 주소, 영업시간, 메뉴와 값, 연락 길. 받지 않은 것은 「(… 알려 주세요)」 자리로 둔다. 전화번호 · 후기 · 사진 설명을 지어내지 않는다.
2. **꼴은 가볍게.** 따로 말이 없으면 `index.html` 한 장에 CSS를 함께 넣는다. 설치나 빌드가 필요한 도구를 쓰지 않는다. 바깥 인터넷 주소의 스크립트에 기대지 않아 인터넷 없이도 열리게 한다.
3. **휴대폰 먼저.** `<meta name="viewport" content="width=device-width, initial-scale=1">`를 넣고, 좁은 화면에서 글과 그림이 넘치지 않게 한다. 글자는 읽기 좋은 크기로, 누르는 것은 손가락 크기로.
4. **회원이 고치기 쉽게.** 회원이 자주 바꿀 글(오늘의 메뉴, 공지, 값)은 한곳에 모으고 그 자리에 「여기를 바꾸세요」 같은 주석을 단다. 보고에 그 파일과 찾을 낱말을 알려 준다.
5. **동작하는 것만.** 예약 · 주문 · 문의 폼은 실제로 받을 곳(전화, 메일 링크, 회원이 쓰는 예약 서비스 주소)이 있을 때만 만든다. 없으면 그 자리를 비워 두고 무엇이 필요한지 묻는다.
6. **확인.** 태그가 닫혔는지, 이미지 · 링크 파일이 있는지, 한국어가 깨지지 않게 `<meta charset="utf-8">`가 있는지 본다.
7. **보고.** 지침의 마지막 답 차례를 따른다.
