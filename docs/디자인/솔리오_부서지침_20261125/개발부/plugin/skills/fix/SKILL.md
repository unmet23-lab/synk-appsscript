# 고장 고치기

1. **증상을 숫자와 예로 적는다.** 회원이 든 예(「만원짜리 두 개면 18000원이어야 해요」)를 그대로 쓴다. 예가 없으면 직접 하나 만든다.
2. **다시 일으킨다.** 있는 시험을 먼저 돌린다. 시험이 없으면 그 예를 확인하는 짧은 실행을 만든다. 증상이 재현되지 않으면 고치지 말고 무엇을 해 봤는지 보고한다.
3. **원인을 찾는다.** 증상이 나는 줄까지 따라간다. 겉에서 값을 덧대 맞추지 않는다.
4. **그 자리만 고친다.** 관계없는 정리 · 이름 바꾸기 · 꼴 바꾸기를 섞지 않는다. 시험 파일을 고쳐 통과시키지 않는다. 시험이 틀렸다고 보이면 고치지 말고 보고에 적는다.
5. **확인한다.** 2의 시험과 실행을 다시 돌리고, 비슷한 경우(0, 큰 수, 경계값)도 하나 더 해 본다.
6. **보고.** 지침의 마지막 답 차례를 따르고, 「무엇이 왜 틀렸는지」를 회원 말로 한 줄 적는다.
