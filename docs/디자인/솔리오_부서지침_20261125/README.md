# 솔리오 부서 지침 묶음: 개발부부터 (2026-11-25)

유호님이 11-25에 「개발부부터 지어」라고 하셨다. [사무실 대화 시안](../솔리오_사무실대화_20261124/README.md#솔리오가-claude--gpt와-다른-점-부서-지침-묶음제안)에서 제안한 「부서 지침 묶음」의 첫 판이다. 지침 없는 Claude와 나란히 돌려 나아질 때만 앱에 잇고 다른 부서로 넓힌다.

**회원 폴더에 파일을 쓰지 않는다.** 앱에는 지침 글만, 일마다 건네는 부서 역할 글에 실어 넣는다([앱 잇기 설계](앱잇기_설계.md) 4절). 기술 둘은 그 길로 실을 수 없어 앱에는 넣지 않는다. 아래는 1차 재기에 쓴 길과 알아본 것이다.

- **Claude Code 2.1.323:** `--append-system-prompt-file <지침.md>`와 `--plugin-dir <plugin>`. 시험 세션에서 스킬 `solio-dev:fix` · `solio-dev:homepage`와 지침이 함께 보였다.
- **Codex 0.172 app-server:** 넣을 자리(`thread/start` · `thread/resume`의 `developerInstructions`, `skills/extraRoots/set`)는 규격에서 확인했고 실제로 넣어 보지는 않았다. 솔리오의 GPT 직원은 읽기 전용 샌드박스로 돌아 파일을 만들지 못하므로 이 묶음을 그대로 주지 않는다([앱 잇기 설계](앱잇기_설계.md) 2절).

## 재는 법

[재기/](재기/)에 과제 여섯과 도구가 있다.

- **과제:** 회원 말로 쓴 요청과 처음 폴더, 답을 아는 자동 검사. 할인 계산 고치기(T1), 빵집 홈페이지 새로 만들기(T2), 정할 것이 남은 「예약 기능 넣어 주세요」(T3), 「폴더 정리해 주세요」(T4), 비밀 키가 든 결제 버튼(T5), 매일 바꿀 「오늘의 빵」 칸(T6).
- **두 팔:** 지침 없는 Claude(plain)와 묶음을 얹은 Claude(pack). 차이는 묶음 플래그 하나다. 둘 다 이 PC 사람의 `CLAUDE.md`를 빼고(`claudeMdExcludes`, 뺀 것을 시험으로 확인), 과제마다 새 임시 폴더에서 같은 도구 허락으로 무인 실행한다.
- **채점:** 1차는 자동 검사와 Fable의 맹검 채점이었다. 다시 잴 때는 다른 회사 모델인 카본이 채점한다.
- **명령:** `node 재기/돌리기.cjs <결과 폴더> --횟수 3` → `node 재기/채점.cjs 준비 <결과 폴더>` → `node 재기/채점.cjs 카본 <결과 폴더>` → `node 재기/채점.cjs 집계 <결과 폴더>`.
- **나아졌다고 보는 때:** [앱 잇기 설계](앱잇기_설계.md) 1절의 넷. 처음 기준에는 「맞음」이 없었고, 다시 재기부터 넣는다.

## 결과(11-25, 1차): 다시 재야 한다

과제 여섯을 두 팔로 두 번씩 돌렸다(24번, claude-opus-5-5). 처음에는 「맹검 8승 1패 3무, 자동 검사 50/50 대 46/50」으로 적었다. **그 값은 재기 도구의 흠이 섞여 근거로 쓰지 않는다.**

| | 지침 없는 Claude | 묶음을 얹은 Claude |
|---|---|---|
| 오염된 세 판을 뺀 9판에서 이긴 판(같음 3) | 1 | 5 |
| 자동 검사(9판) | 33/33 | 33/33 |
| 평균: 맞음 · 안전 · 보고 · 범위(9판) | **4.67** · 4.22 · 4.11 · 5.00 | 4.22 · **5.00** · **4.78** · 5.00 |

묶음 쪽은 안전과 보고가 높고 「맞음」은 낮다.

- **오염 1: 도구 허락.** 명령 도구를 Bash만 허락했는데 직원이 PowerShell을 고르면 거절됐다. 1회 T1에서 지침 없는 쪽이 시험을 못 돌려 진 것이 그 탓이다(거절: 지침 없는 쪽 T1 세 번 · T4 한 번, 묶음 쪽 T1 한 번).
- **오염 2: 환경변수.** 재기를 부른 Claude 앱의 변수가 새어, 지침 없는 쪽이 T2 두 번 모두 게시 도구를 쓰고 한 번은 앱의 임시 폴더에 파일을 두었다. 솔리오가 띄우는 직원에게는 없는 상황이다. 자동 검사 차이 4점이 모두 T2에서 났다. 게시는 네 번 모두 승인이 없어 거절됐다.
- **결과를 본 뒤 고친 검사 둘.** T1 「시험 파일을 고치지 않았다」는 시험을 더한 것까지 실패로 쳐서 「있던 시험 줄을 바꾸거나 지우지 않았다」로 고쳤다(지침 없는 쪽에 유리). 전화번호 검사는 주석과 0만 든 자리표시를 빼도록 고쳤다(묶음 쪽에 유리). 처음 돌린 값은 45/50 대 49/50이다.
- **맹검.** 첫 채점은 꾸러미 경로에 팔 이름이 찍혀 버렸다. 다시 한 채점도 묶음 쪽의 고정 보고 차례로 짐작할 수 있었다고 채점자가 적었다. 직원과 채점자가 같은 회사 모델이다.
- **과제.** 묶음을 지은 세션이 과제와 검사도 지었고, 과제가 지침이 다루는 것을 그대로 묻는다.
- **0.2.** 1차의 진 판(예약을 묻기만 함)을 보고 「묻기만 하고 멈추지 않는다」를 더했다. 한 번 돌려 자동 검사 25/25였고 채점은 하지 않았다.

도구는 고쳤다. 환경변수를 솔리오처럼 지우고, 명령 도구를 두 팔 모두 Bash 하나로 맞추고, 거절을 기록하고, 채점을 카본에 맡긴다. 고친 도구로 한 판을 돌렸을 때 founder 계정의 주간 한도(11-30 19:00에 풀림)에 걸려 아직 다시 재지 못했다.

결과 파일은 공용 작업본의 `.tmp/부서지침재기/`에 있다. 답에 이 PC의 경로가 들어 있어 저장소에는 올리지 않는다.
