# 싱크타운 설계 점검 — 범위별 검토 원본 (2026-10-21)

[싱크타운 설계 점검](../../싱크타운_설계점검_20261021.md)의 근거 자료다. 범위를 여섯으로 나눠 Claude 하위 검토자가 읽기 전용으로 쓴 보고서이고, 판정을 바꾸는 근거는 점검 문서에서 Claude가 원문과 코드에서 다시 대조했다. 원본의 P2·P3 지적과 세부 표는 다시 대조하지 않은 것도 있으니, 고칠 때는 해당 원문 줄을 먼저 확인한다.

- **줄 번호:** 2026-10-21 공용 작업본(커밋 e7cf56266) 기준이다. 그 뒤 `docs/마을_설계.md`에 점검을 가리키는 문단 두 줄이 들어가, 마을 설계(약어 V·정본)의 24줄 이후 인용은 지금 두 줄씩 밀려 있다(예: V:517 → 519). 결정 표는 새 줄이 위에 쌓여 더 많이 밀린다 — 날짜와 제목으로 찾는다.
- **IMPL_구현대조의 정정 둘:** 머리의 「17항목: 검증됨 2 · 동작 3 · 뼈대 8 · 없음 4」는 자기 §1 표(19행: 검증됨 2 · 동작 4 · 뼈대 9 · 없음 4)와 맞지 않는다 — 표가 맞다. 「운영은 맥박마다 상태 전체를 두 번 쓴다」는 talk 저장 코드에서 한 행 upsert 한 번이다(그 한 행의 상한은 8MB).
- **살아 있는 마을의 재료:** 「데이터·규칙이 없다」는 결론과 별개로, [주민 설계](../../../주민_설계.md) §7·§8에 첫 주민 셋의 하루·기분과 몸·주민끼리의 사이·마을 연대기가 글([제안])로 있다. D2a는 이 문서를 전부 읽고 「첫 빌드 배역의 표가 없다」고 적었고, 점검 문서 §2도 이 재료를 함께 적는다.
