## 구성

| 차례 | 구역 | 말하는 것 |
|---|---|---|
| 1 | 입구 | 처마 · 싱ㅋ 그대로. 회사 한 줄을 작은 설명에서 쪽 제목으로 키우고, 질문은 작은 안내로, 위 메뉴와 같은 작은 링크 셋은 뺐다 |
| 2 | 왜 시작했나 | 「한 명씩 맞춰 줄 시간이 없었습니다」 + 몽골 학원 이야기(사람의 말이라 명조) |
| 3 | 무엇을 만드나 · 지키는 것 | 쓸수록 나를 아는 AI 엔진, 아틀라스 — 이해하고 · 맞추고 · 확인합니다 / 평균으로 짐작하지 않습니다 · 결정은 본인이 합니다 · 확인한 만큼만 말합니다 |
| 4 | 무엇을 하나 | 네 사업 한 줄씩 + 무대 하나(손을 올리면 바뀐다, 저절로 돌지 않는다). 휴대폰은 줄 아래 옆으로 넘기는 무대 |
| 5 | 어디로 가나 | 지금 → 넓혀 가는 곳 → 지향하는 곳 세 줄 |
| 6 | 소식 · 플랫폼 · 문의 · 바닥 | 공개본 그대로, 제목만 한 단계 작게(찾아 쓰는 자리) |

홈에서 빠지는 것은 사라지지 않는다 — 상황극은 `/lab/`, 「쓸수록 달라지는 것」은 `/atlas/`와 `/lab/`, 여덟 엔진은 `/atlas/`, 예약표는 `/shift/`에 이미 있다. 플랫폼 받기 · 소식은 홈에만 있어 남겼다(`/platform/`은 없다).

글은 지어내지 않았다: 왜 = `/founder/` · 공개 홈 창업자 띠, 세 동사 = 공개 아틀라스 구역 · `/atlas/`, 지키는 것 = [철학](../../SYNK_철학.md) 1 · 2절, 어디로 가나 = [비전](../../비전_정본.md) · [제품방향](../../제품방향.md) 적용 범위, 네 사업 줄 = 공개 각 쪽 제목.

## 회사 한 줄 맹검

`tools/lib/제미나이구독호출.js`(아르곤 · 사고 높음)로 출처를 가리고 세 번 매겼다(1회 후보 서른, 2회 여섯, 3회 넷). 칸: 무슨 회사 · 왜 · 임팩트 · 기억 · 고유함 · 자연스러움(60점). 같은 문장도 회차마다 흔들린다(「학생 한 명 한 명을 챙기려다, … 만들게 됐습니다」 50 → 36) — 판정이 아니라 고르는 근거로만 쓴다.
