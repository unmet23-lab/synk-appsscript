# 솔리오 백업 한 몸 시안 (2026-11-26)

업무 백업에서 손님 눈에 보이는 것을 솔리오 하나로 합친 백업 방의 시안이다. 유호님 11-26 「솔리오 하나로 전부 가능하게 클라이언트 통합해줄수있어?」 → 「응, 그렇게 해」. 설계는 [SOLIO_ONE_CLIENT.md](../../../experiences/solo-backup-rust/SOLIO_ONE_CLIENT.md), 설계 검토 원문은 [설계검토_Fable_20261126.md](설계검토_Fable_20261126.md)다.

## 보는 법

- [디자인 캔버스](https://claude.ai/artifact/TffSFhKQdUd8ZSuEXpZhWm)의 위 판을 눌러 본다. 맨 아래 「시안 조작」 줄에서 시안 가 · 나를 바꾸고, 처음부터(백업 부품 없는 PC) · 지키는 중 · 이미 깐 PC가 넘어옴 · 새 판 나옴 · 알림 누르기 · Mac을 고른다. 조작 줄은 디자인의 일부가 아니다.
- 아래 판은 Windows에서 바뀌는 다섯 곳(바탕화면, 시작 메뉴, 설치된 앱, 따로 뜨는 창, 알림)을 지금과 견준다.
- 원천은 캔버스 자체다. 캔버스의 글꼴은 캔버스에 올린 자산으로 싣기 때문에 `.dc.html`을 저장소에 두면 지면 글꼴 검사를 넘지 못한다. 그래서 저장소에는 이 설명과 검토 원문만 둔다.

두 시안 모두 보호 시작부터 Google 로그인, 지킬 자료 확인, 첫 백업까지 방을 떠나지 않는다. 설치 창과 엔진 창은 뜨지 않고, Windows 확인 창 한 번만 뜬다.

## 정한 것

- 검정 방, SUIT 한 서체, 색은 원클릭 시안의 역할표를 따른다. 청금석은 솔리오가 지금 짚은 곳(하는 차례, 진행 선), 풀빛은 끝남과 통과, 흰 알약은 그 순간의 결정 하나, 알림은 색 없이 느낌표다.
- 엔진 화면의 문구와 흐름은 11-16 검정 말씨 그대로다. 「엔진」, 「엔진 창」이라는 말은 화면에서 뺐다. 설치 · 업데이트 · 지우기 때만 「백업 부품」이라고 쓴다.
- 지금 하는 차례에는 작은 구(솔리오의 분신)가 번호 자리에 앉는다. 큰 움직임은 넣지 않았다.
- Windows 확인 창과 Windows 알림은 실제로 Windows가 띄우는 것을 시안 안에 그린 것이다.
