# synk.im/reserve/ — 게임 화면으로 다시 짓기 (2026-11-24)

유호님 11-23 「여기 사젼예약 페이지인데 게임인지 아무도 모를것같아. 우리 앱 화면이든 뭐든 좀 솔깃하게 만들어주면 좋을것같아」. 원천은 [experiences/synk-reserve](../../../experiences/synk-reserve/README.md)다.

## 보신 화면

유호님이 보신 「지금 시도해 볼 것들 / 오픈 싱크 월드」는 영어 판(`?lang=en`)을 크롬이 한국어로 자동 번역한 화면이었다. WORLD가 영어로 떠 있을 때 출시 안내 띠의 링크가 `lang=en`으로 사전예약 쪽에 보낸다.

## 짓기 전에 정한 것

- 한 문장: 한국 유학을 먼저 살아 보는 한국어 이야기 게임.
- 강조 순위: 첫 1초는 게임 장면과 머리 글. 다음은 장면 순서와 「사전예약하기」. 개인정보 안내와 발은 물러선다.
- 참고: 참고 사이트 장부 5-1(토스 첫 화면 · figure.ai — 화면을 덮는 장면과 문장 하나), 5-2(토스 · 당근 — 그림 한 장과 문장 하나), synk.im 상세 쪽의 휴대폰 틀.
- 움직임: 장면 글을 읽는 대로 옆 휴대폰이 그 장면으로 옅게 바뀐다. 이것을 보고 「이야기가 이 순서로 이어진다」를 안다. 저절로 도는 움직임은 없다.
- 글자: 큰 말 SUIT 400과 굵은 구절 800, 장면 이름 SUIT 700, 장면 번호 DM Mono, 영어 · 몽골어 화면은 Inter Tight.
- 색: 먹은 읽을 글, 흰 글은 밤 무대 위 글, 코랄은 장면 번호 하나, 밤 남색은 게임 화면과 이어지는 바탕, 미색은 사전예약 판.

## 시안과 고르심

| 안 | 짜임 | 미학 맹검(카본) |
|---|---|---|
| A | 밤 바탕 첫 화면 오른쪽에 타이틀 화면 휴대폰, 아래에 휴대폰 여섯 대 줄 | 첫 화면 5점 기각. 쌍 견줌에서 B를 이김 |
| B | 흰 바탕, 휴대폰 한 대가 장면을 한 번 지나가고 장면 목록을 누르면 바뀜 | 3점 기각. 「번호 표 · 회색 카드」가 템플릿 결 |
| C | 타이틀 무대 그림이 첫 화면 전체, 아래는 장면 글을 따라 바뀌는 휴대폰 한 대(좁은 화면은 옆으로 넘김) | 장면 구역 3점 기각(쪽에서 고칠 것은 질문 되풀이 하나 — 고침). 첫 화면 판정은 카본이 막혀 받지 못함 |

A · B의 공통 지적(휴대폰 틀을 늘어놓은 흔한 랜딩 틀, 틀 안 게임 단추와 쪽 단추가 겹침, 「실제 화면입니다」 같은 방어 문장)을 고친 판이 C다. 유호님이 11-24에 「C안으로」 고르셨다. C 맹검이 짚은 개찰구 그림의 결과 게임 안 단추 모양은 WORLD 화면 자체의 일이라 이 쪽에서 고치지 않았다.

시안 원고 · 캡처 · 녹화는 공용 작업본 `.tmp/rsv-sian-20261124/`(git 밖)에 있다. 맹검 기록은 `.tmp/미학맹검/사전예약쪽_시안_20261124/` · `사전예약쪽_시안C_20261124/`다.
