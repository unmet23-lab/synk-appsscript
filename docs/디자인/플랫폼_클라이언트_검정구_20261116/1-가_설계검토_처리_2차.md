## 검토의 「돌려 보지 않은 것」

검토가 코드와 Windows의 알려진 동작으로만 판단한 넷을 설계의 「확인 안 함」에 넣었다. 다른 프로세스의 창을 앱 창 바로 아래에 놓는 것, 앱이 끝날 때 가림막의 입력이 닫히는 때, 창을 보이지 않은 WPF 프로그램의 동작, 창 없는 설치기가 로그오프 때 끝나는 모습이다. 여기에 파일을 바꾸는 한가운데에 사람이 실행 파일을 켜면 무엇이 켜지는지를 더했다. 이것은 지금 엔진에도 있는 틈이다.

- 모습을 미리 굳힌 곳은 새로 만들지 않았다. 새로 넣은 숫자(1.5초, 2초, 10초, 0.5초, 60초, 20초, 사흘)는 모습이 아니라 기다리는 상한과 확인 주기다.
