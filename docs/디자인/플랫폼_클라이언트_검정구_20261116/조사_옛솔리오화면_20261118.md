# 옛 솔리오 화면이 하는 일 — 조사 (2026-11-18)

2단계(솔리오 안쪽)를 새로 지을 때 지금 있는 기능을 빠뜨리지 않으려고, PC 앱의 옛 화면 다섯(AI 구독 관리, 솔리오 홈과 백업 · 복구, 내 계정, 설정, 업데이트 안내)이 실제로 보여 주는 것과 할 수 있는 것을 모았다.

- 조사한 판: origin/master 9b2f32136e 무렵의 `desktop/`이다. 줄 번호는 그 판의 것이라 뒤에 달라질 수 있다.
- 조사한 방법: 시안을 맡은 세션이 읽기 전용 하위 에이전트(Sonnet)에게 맡겼다. 파일을 고치거나 앱을 띄우지 않고 코드만 읽었다.
- 확인 안 함: 시안을 맡은 세션은 이 목록을 줄마다 다시 대조하지 않았다. 구현 설계를 쓸 때 줄 번호로 원문을 확인한다. 조사에서 읽지 못한 곳은 0절에 있다.
- 화면 글은 옛 화면의 말투(해요체) 그대로 옮겨 적었다. 새 얼굴에 옮길 때는 새 얼굴의 말투로 다시 쓴다.

CLI형(Claude, GPT, Higgsfield, Gemini) 단계 네 개:
1. 「요금제 확인」(항상 완료 표시) + 서비스 안내 글 + 「요금제 보기」(브라우저).
2. 「{프로그램} 설치」: 이미 설치돼 있으면 「이 PC에 설치돼 있어요 (버전).」. 아니면 안내 「아래 단추를 누르면 파란 PowerShell 창이 열리고 공식 설치 명령이 실행돼요. 관리자 권한은 필요 없어요. 1~2분 동안 아무 표시가 없을 수 있으니 창을 닫지 말고 기다려 주세요.」 단추 「설치 창 열기」(`install` → 본체가 `powershell.exe -NoExit -NoProfile -ExecutionPolicy Bypass -EncodedCommand`로 공식 설치 명령을 새 창에 실행하고 「설치가 끝나면 이 창을 닫고 SYNK로 돌아가 「다시 확인」을 눌러 주세요.」를 띄움(`ai-subscriptions.cjs:286-303`); 맥은 Terminal로. 토스트 「{도구} 설치 창을 열었어요. 끝나면 「다시 확인」을 눌러 주세요.」), 「설치 끝났어요 · 다시 확인」(`recheck-tools`), 접이식 「직접 붙여 넣고 싶다면」(명령 보기, 「명령 복사」 → 클립보드, 「공식 설치 안내」 → 브라우저). Higgsfield는 Node.js 없으면 「Higgsfield CLI는 Node.js가 먼저 있어야 해요. Node.js(LTS)를 설치한 뒤 이 단계로 돌아오세요.」 + 「Node.js 받기」(브라우저), 본체도 `NODE_REQUIRED`로 설치 거절. 되돌릴 수 없는 일: 외부 프로그램 설치(Windows에서는 관리자 권한 없이 사용자 영역).
3. 「로그인」: 설치 전 「설치가 끝나면 열려요.」 설치 후 세 가지 하위 상태.
   - 아직 로그인 안 함(기본): 설명 + (Claude만) 「연결할 이메일 (선택)」 입력(로그인 화면에 미리 채우는 용도, 형식이 틀리면 `INVALID_EMAIL`) + 단추 「이 PC의 기존 로그인 쓰기」(`useExisting`: 이미 설치된 공식 프로그램의 기존 로그인으로 계정 줄을 만들고 그 계정을 곧바로 읽음. 파일 쓰기: 이 앱 데이터 폴더의 판 파일만. 토스트 「{서비스} 계정을 연결했어요.」) 와 「새 계정 연결」(Gemini는 「Gemini 로그인」).
   - 로그인 진행 중(브라우저 단계): 안내 글 + 브라우저가 안 열렸을 때 「로그인 페이지 다시 열기」(`open-url`)·「주소 복사」(`copy-url` → 시크릿 창에 붙이라는 안내 토스트) + 코드가 필요하면(`needsCode`, Claude만) 「브라우저에 보이는 코드」 입력과 「연결」(`submitCode`, 8자 미만이거나 공백·줄바꿈이 있으면 `INVALID_CODE`) + 「로그인 취소」 + Claude만 「코드가 안 들어가면 · 검은 창으로 로그인하기」(`console-login`). GPT는 「ChatGPT가 휴대폰 인증을 요구하면 안내대로 마쳐 주세요. 끝나면 이 화면이 저절로 넘어가요.」
   - 로그인이 끝난 직후: 성공 글(초록) 또는 오류 글(`login.message`).
   - Gemini는 검은 창(`agy`, 콘솔) 방식이라 하위 단계가 다름(1163-1173줄): 「검은 창이 열렸어요. 아래 순서대로 하면 돼요…」 + 순서 목록(`/logout` Enter, `/login` Enter(이미 다른 계정으로 로그인된 경우), Enter로 「1. Google OAuth」, 브라우저에서 계정 고르기 → 「로그인」, 코드를 「클립보드에 복사」한 뒤 검은 창에 오른쪽 클릭으로 붙여넣고 Enter) + 「로그인 취소」.
4. 「첫 확인」: 「연결하면 바로 사용량을 한 번 읽어요. 다음부터는 한눈에 보기의 「지금 확인」 한 번이면 모든 계정을 다시 읽어요.」
- 본체가 하는 일(`subscription-login.cjs:12-100`): 로그인 시작 시 계정 폴더 `accounts/{서비스}-{난수}`를 만들고(Gemini 제외), 공식 프로그램을 띄워 로그인 주소를 출력에서 찾아 화면에 넘김(`loginUrl`). 비콘솔 방식에서 프로세스가 끝나면 연결을 확인(`verifyLogin`)해 계정 줄을 추가하고 곧바로 그 계정을 읽음(`connected`, 103-120줄). 이미 연결된 메일이 또 붙으면 줄을 겹치지 않고 안내(「이미 연결된 {메일} 계정으로 다시 로그인됐어요. 다른 계정을 더하려면 「주소 복사」로 로그인 주소를 시크릿 창에 붙여 넣고 그 계정으로 로그인해 주세요.」), 넣은 메일과 다른 계정으로 승인되면 그 사실을 오류 글로 알림(「{입력} 대신 브라우저에 로그인돼 있던 {실제} 계정으로 연결됐어요…」). 10분(`LOGIN_TIMEOUT`) 지나면 중단(「10분 동안 로그인이 끝나지 않아 멈췄어요. 다시 시도해 주세요.」). 실패·취소 시 임시 계정 폴더를 지움.
- 결과 갈래(오류 문구 원문, `subscription-login.cjs`): 「로그인 프로그램을 열지 못했어요.」, 「다른 로그인 창이 이미 열려 있어요. 그 창을 닫고 다시 시도해 주세요.」, 「로그인을 확인하지 못했어요. 브라우저에서 연결할 계정이 맞는지 보고 다시 시도해 주세요.」, 「로그인을 마치지 못했어요. 가이드의 「막혔을 때」를 확인해 주세요.」, 「검은 창이 닫혔는데 로그인이 확인되지 않았어요. 다시 시도해 주세요.」, 「AI 구독 관리 파일을 잠깐 열지 못했어요. 잠시 뒤 다시 연결해 주세요.」, 「로그인을 취소했어요.」

Typecast형(`keyGuide` 1137-1143줄) 단계 네 개: 1 「요금제 확인」(완료), 2 「API 키 복사」 + 「API 키 페이지 열기」(브라우저로 studio.typecast.ai/developers/api; 「키를 새로 만들면 예전 키는 더 이상 쓸 수 없어요.」), 3 「키 붙여 넣기」(비밀번호 형식 입력, 「복사한 키를 붙여 넣기 (Ctrl+V)」, 단추 「연결」, 안내 「키는 Typecast에 남은 크레딧을 물을 때만 쓰고 이 PC에 암호화해 둬요. 화면에는 끝 네 글자만 보여요.」), 4 「첫 확인」. 비어 있으면 「복사한 API 키를 붙여 넣어 주세요.」 토스트. 본체(`connectKey`, 264-283줄): 키 형식 검사 → 안전 저장소 사용 가능 확인(`SECURE_STORAGE_UNAVAILABLE`) → Typecast에 실제로 물어 확인(`INVALID_KEY`/`KEY_CHECK_FAILED`/`NETWORK`) → 암호화해 `accounts/typecast-{난수}/key.bin`에 쓰고 계정 줄 만들고 바로 읽음. 같은 키를 두 번 넣으면 같은 줄 하나(지문). 「키 다시 넣기」(줄 ⋯에서)는 그 줄의 키를 교체(`replace`). 성공 토스트 「Typecast 키를 연결했어요. 남은 크레딧을 읽었어요.」

### 7-5. 쓰는 계정을 바꾸는 흐름
- 「쓰는 계정」이라는 선택 기능은 없습니다. 화면은 서비스마다 「추천」 계정을 자동으로 계산해 보여 줄 뿐입니다(`serviceGroups` 277-305줄).
- Gemini만 예외로 「계정 바꾸기」가 있음: 한 번에 계정 하나만 로그인되는 `agy`라서, 블록 단추 「계정 바꾸기」 → 「Gemini 로그인」을 누르면 검은 창을 열고 회원이 직접 `/logout`→`/login`을 침. 창을 연 뒤 다른 계정이 읽히면 연결로 보고, 창을 닫으면 그때 로그인된 계정으로 마침. 10분이 지나도 로그인이 살아 있으면 그 계정으로 마침(`subscription-login.cjs:76-81`, 어댑터 `acceptAtTimeout`). 지금 로그인되지 않은 계정 줄은 「지금 로그인 안 됨」으로 마지막 값만 보임(삭제한 계정은 `geminiHidden`에 적어 자동으로 되살리지 않음, 최대 20개, `subscription-shared-accounts.cjs`).
- Claude의 「다시 로그인」(줄 ⋯ 또는 손볼 띠)는 그 줄의 메일로만 로그인(`loginEmail` 201줄), 로그인 기한이 새로 시작됨(안내 「Claude는 한 번 로그인하면 4주쯤 쓸 수 있어요.」). 브라우저에 다른 Claude 계정이 로그인돼 있으면 그 계정으로 연결된다는 경고 글(1185줄).
- 로그인이 끝나면 `ui.relogin`을 풀어 다음 계정을 「새 계정 연결」로 더할 수 있음(195-197줄).

### 7-6. 계정을 빼는 흐름 (`remove`, 315줄)
- ⋯ 패널의 「지우기」를 한 번 누르면 단추가 「한 번 더 누르면 지워요」로 바뀌고(`removeArmed`, 위험색), 한 번 더 누르면 `save({remove:id})`. 별도 대화상자는 없습니다. 다른 줄의 ⋯을 열거나 화면을 옮기면 확인 상태가 풀림(291, 255줄).
- 본체가 하는 일(`ai-subscriptions.cjs:340-347`): 계정 줄을 판에서 빼고, 그 계정 폴더(`accounts/…`)를 지움(링크를 따라가지 않고 하나씩, 실패하면 1초 간격 10번 재시도, `removeFolder` 244-252줄), Gemini면 숨김 목록에 적고, 사용 기록 `history.jsonl`에서 그 계정 줄도 지움(`compactHistory`). 되돌릴 수 없음(다시 연결해야 하고 쌓인 기록은 사라짐).
- 안내(`HELP[8]`, 77줄): 「계정 줄의 ⋯을 누르고 「지우기」를 두 번 누르면 이 앱이 만든 로그인 폴더까지 지워요. 기존 로그인을 가져온 계정은 목록에서만 빠져요.」
- 지우는 것은 이 앱이 만든 로그인 폴더이지 공식 프로그램 자체의 로그인은 아님(기존 로그인을 가져온 경우 `folder`가 없음).

### 7-8. 02 「요금·결제일」 (`costSection`, 1059-1081줄)
- 설명 「넣은 요금을 먼저 쓰고, 넣지 않은 계정은 공식 요금으로 셈해요.」 또는 「월 구독료와 결제일을 넣은 구독이 모여요.」

- 「구독에 포함된 크레딧」 줄: Claude API 크레딧, GPT API 크레딧, Gemini API 크레딧, Flow 크레딧(영상·그림). 각 칸은 남은 금액 합, 매달 들어오는 금액, 먼저 사라지는 계정 등.
- 결제 목록: 서비스 이름표, 계정 이름과 크레딧 조각, 가격(「공식 요금」 또는 「가족 공유」), 「매월 n일 · D-n」/「연간 결제」/「결제일 없음」, 「고치기」(해당 계정 ⋯의 편집 양식을 엶). 비어 있으면 「계정 줄의 ⋯에서 「요금·결제일」을 넣으면 한 달 합계와 다가오는 결제를 여기서 알려 드려요.」

  - `opening`: 자동 「업데이트를 준비하고 있어요. 앱이 꺼지면 설치하고, 끝나면 다시 열려요.」, 수동 「설치를 준비하고 있어요. 앱이 꺼지면 열린 설치 파일에서 이어서 진행해 주세요.」
  - `error`: 코드별 네 갈래(`UPDATE_STORAGE_FAILED` 「설치 파일을 저장하지 못했어요. PC 저장 공간을 비운 뒤 다시 받아 주세요…」, 버전 불일치류 「지금 버전과 올라온 설치 파일이 맞지 않아요. synk.im에서 최신 설치 파일을 받아 다시 설치해 주세요…」, 무결성·서명류 「받은 업데이트 파일이 온전하지 않아요. 「최신 버전 확인」을 다시 눌러 주세요…」, 열기·설치류 「설치 파일을 열지 못했어요…」) + 기본 「업데이트를 받지 못했어요. 인터넷 연결을 확인한 뒤 「최신 버전 확인」을 다시 눌러 주세요. 지금 앱은 그대로 쓸 수 있어요.」
  - 기타(`idle`): Windows 「켤 때와 쓰는 동안 새 버전을 저절로 확인해요. 새 버전이 있으면 받아서 업데이트하고 다시 열어요.」, 맥 「켤 때와 쓰는 동안 새 버전을 저절로 확인하고 받아요. 받은 설치 파일을 열어 업데이트해 주세요.」
- 호출과 본체가 하는 일(`preload.cjs:50-54`, `main.cjs:572-574`, `platform-update.cjs`):
  - 「최신 버전 확인」 → `checkForUpdate`: 서명된 릴리스 목록(manifest)을 HTTPS로 받아 서명·버전을 검증(`platform-update.cjs:149`)
  - 「업데이트 받기」 → `downloadUpdate`: 설치 파일을 받아 해시·크기 검증하고 캐시 폴더에 저장(166줄)
  - 「앱 끄고 설치 파일 열기」 → 먼저 렌더러가 쓰던 메모 확인(`confirmUpdateInstall`, `launcher.mjs:179`: 메모가 있으면 「작성 중인 메모가 있어요」 + 「돌아가서 저장」/「저장 없이 나가기」, 문구 「돌아가서 저장하거나, 메모를 버리고 업데이트할 수 있어요.」). 통과하면 `installUpdate`: 무결성을 다시 검사하고(`UPDATE_INTEGRITY_FAILED`), Windows는 앱을 끄고 설치기를 넘김(`requestQuit`, 자동 설치면 넘김 쪽지 `prepareHandoff`), 맥은 `.dmg`만 열고 앱은 안 끔(`UPDATE_MANUAL_INSTALL`). 앱 종료와 설치는 되돌릴 수 없는 일.
  - 다른 일이 진행 중이면(`pending`, 확인·받기·열기) 단추 잠김. 동시에 두 번 눌러도 막음(57줄).
- 시작 창(`startup-update.*`)은 조사 대상이 아니어서 안 봤습니다. 같은 `platform-update.cjs`를 쓰고 `checkInBackground`(228-241줄)가 앱을 켜 두는 동안 주기적으로 확인·받기·(Windows) 자동 설치까지 이어 가는 것만 확인.

## 12. 새 화면을 지을 때 빠뜨리기 쉬운 것

드문 상태
1. 구독 화면 바깥 상태 다섯(PC 앱 아님, 로그인 안 함, 불러오기 실패, 아직 받는 중, 로그인 후 판 없음)과 「SIGN_IN_REQUIRED 때문에 잠깐 비어 있는 경우」(토큰 갱신 중 로그인 확인을 기다림). 홈 탭의 상태 글 세 가지.
2. 계정 상태 여덟 갈래(`ok·low·out·login·error·manual·unknown·away`)와 「다시 찼을 거예요」(예상, 숫자 없음)·`stale`(1시간)·`aging`(20분) 표기. 어림(`guess`) 창은 0% 사용이나 100% 남음을 확인한 숫자처럼 쓰지 말라는 규칙(`subscriptions-model.mjs:88-91`).
3. 크레딧형이 로그인 필요/오류면 옛 잔액을 정상처럼 보이지 말 것(`solio-today.mjs:120-122` 규칙도 같음).
4. Gemini의 「지금 로그인 안 됨」(away)과 「로그인된 계정 없음」(`awayReason:'none'`) 두 갈래. 이 계정들은 「바로 쓸 계정」·「손볼 것」에서 빠지고 따로 세어짐.
5. 요금제를 못 읽은 Claude Max(「Max · Ultra」)와 등급을 고르지 않은 Gemini Ultra → 금액 대신 「모름」 문구.
6. 요금표가 60일 넘게 오래됐으면 금액을 아예 말하지 않음. 30일 넘게 못 읽은 계정은 공식 요금·API 크레딧 계산에서 빠짐(`officialPrice`, `grantOf`).
7. 가족 공유 Gemini는 요금 ₩0이 아니라 「가족 공유」라고 말하고 결제일을 안 채움.
8. 연간 결제로 표시한 줄은 「매월 n일」 결제일을 숨기고 결제 알림·팁에서 뺌.
9. 모델별 토큰의 처음 세는 중(몇 분), 세다 멈춤, 끝까지 못 셈 경고, 못 읽은 파일 수, 일부 도구 기록이 기간 앞쪽에서 비는 경우.
10. 내 계정: 삭제 요청 중(학습 기록 연결 못 켬, 이름 바꾸기·내려받기 등 일부 단추 잠김), 삭제 처리 시작 후 취소 불가, 이름 저장 충돌(다른 곳에서 먼저 바꿈), 로그인 이메일 변경 대기(`identity.newEmail`), 계정 서버 판이 프로필 revision을 안 줄 때 이름 변경 불가 문구.
11. 업데이트: `disabled`(여기서는 못 받음), 맥과 Windows 문구 차이, 자동 설치 가능 여부, 끄기 취소(`UPDATE_EXIT_CANCELLED`).

확인 대화상자·두 번 누르기
- 계정 「지우기」는 두 번 누르기(대화상자 없음). 모델별 토큰 「끄기」는 두 번 누르기(띠). 내 계정의 「모두 로그아웃」·「지우기 요청…」은 `<dialog>` 확인, 마을 기록 단추도 서버가 주는 확인. 업데이트 설치는 쓰던 메모 확인(`leave-dialog`). 로그아웃도 같은 메모 확인. 설정의 「보기 설정 되돌리기」는 확인 없이 바로 실행.
- 「이름 바꾸기」 외의 되돌릴 수 없는 일: 로그아웃, 삭제 요청(7일 안은 취소 가능), 모델별 토큰 끄기(모은 숫자 삭제), 계정 지우기(로그인 폴더 삭제와 기록 삭제), 초기화권 「1장 썼어요」(기록만 줄임, 실제 초기화권은 사이트에서 따로 씀).

숨은 단축키·키보드
- 솔리오 전용 단축키는 없음. 앱 전체: Ctrl/⌘+K(빠른 검색, 설정 줄·솔리오 안 자리까지 검색), Alt+←/→(뒤로·앞으로), Ctrl/⌘+`+`/`-`/`0`(확대), 사용자가 정하는 전역 단축키(기본 비어 있음). 검정 구 얼굴이 보이는 동안(`isMenuBlocked`)은 검색·앱 메뉴·Alt 화살표가 막힘(`convenience.mjs:13-14`).
- 키보드 초점 규칙: 화면을 바꿀 때 제목에 초점(`#benefit-title` 또는 `#solio-title`, `launcher.mjs:263`), 다시 그려도 같은 단추·입력에 초점 유지(`focusKey` 1216-1224줄), 토큰 칸 갈아 끼우기 시 초점 모델 보존, 눌린 채 칸이 갈리지 않게 누르는 동안 실시간 알림 그리기 보류(`pressing`).
- 접근성 글: 막대·값마다 화면 읽기용 한 줄(`ms-sr`), 고리는 `aria-hidden`, 단추에 `aria-expanded`/`aria-pressed`, 계정 ⋯에 「{이름} 관리 열기」 라벨, 계정 요약에 live 영역(`ap-live`).

다른 화면으로 가는 길(새 화면에서도 이어져야 함)
- 구독 화면 → 솔리오 홈(「솔리오 홈」), 한눈에 보기 ↔ 계정 관리, 입구 「요금·결제일」(계정 관리 요금 칸으로 스크롤), 손볼 띠의 「계정 관리에서 모두 보기」, 로그인 안 함 상태의 「SYNK ID로 로그인」(내 계정/로그인 창).
- 구독 화면에서 브라우저를 여는 단추: `data-subs="help"`가 여는 25개 주소(`subscription-common.cjs:9-43`) — 요금제·설치 안내·Node.js·Claude 사용량 설정·Console 결제·OpenAI Credit grants·AI Studio 결제·개발자 프로그램 혜택·Flow·Higgsfield 요금·연간 안내·Typecast API 등 — 및 로그인 주소(`openLoginUrl`). 새 화면에서도 `help` 열쇠 목록(`preload.cjs:4`)만 넘기면 되고 주소를 렌더러가 만들지 않음.
- 내 계정 → 설정(「설정」 되돌아가기), 맞춤 정보(내 성향), 작업실, 브라우저의 SYNK ID, 로그인 창. 설정 → 내 계정, 회원 혜택, PULSE 이전 초안, 맞춤 대화상자.
- 검정 구 얼굴(`orb-face.mjs`)이 이 구독 화면과 내 계정·설정을 옛 화면으로 임시로 열어 줌(`launcher.mjs:465-466`, 주석 「임시로 여는 옛 화면(설계 9절). 2단계에서 같은 손으로 다시 짓는다」). 새 화면은 `showView('solio',{section:'subscriptions'})`와, 「계정 관리」 단추를 한 번 눌러 열어 주는 `extra.view==='manage'` 진입을 계속 받아 줘야 함. 해당 단추를 `#solio-subscriptions [data-subs="manage"]` 선택자로 찾으므로 새 화면에서 속성 이름이 바뀌면 이 진입이 조용히 끊김(60ms×25번 시도 후 포기).
- 솔리오 얼굴 쪽 문장 계산기(`solio-today.mjs`)는 같은 구독 판 계산(`serviceGroups`, `paceTip`, `balance`, `monthCredits`)을 재사용하고 새로 세는 것은 「쓰는 속도를 셀 기록이 사흘 됐는지」(`rate3`) 하나뿐입니다(주석 2-3줄). 모델 파일의 이름이나 반환 모양을 바꾸면 이 파일과 `site-visits-model.mjs`(`josa`를 가져감, 7줄)도 영향받음. 모델 파일은 `subscriptions.mjs`가 같은 이름으로 다시 내보내 기존 import와 시험이 그대로 되게 해 둠(10줄).
- 숨은 데이터 연결: 본체가 `main.cjs:189`의 2분 틱으로 계정판 자동 읽기·토큰 세기를 화면과 무관하게 돌림(판 파일이나 `token-usage.json`이 있거나 계정판을 한 번이라도 연 PC에서만). 새 화면을 열지 않아도 사용 기록이 쌓이므로 새 화면이 `snapshot.usage`·`check` 꼴을 바꾸면 안 됨.
- 저장 위치 목록: 판 `AiSubscriptions/board.json`, 기록 `history.jsonl`, 요금표 `prices.json`(synk.im 갱신본), 계정 폴더 `accounts/*`(로그인 정보, Typecast는 `key.bin` 암호화), 토큰 `token-usage.json`, 모두 앱 데이터 폴더(`main.cjs:178, 187, 189`).
