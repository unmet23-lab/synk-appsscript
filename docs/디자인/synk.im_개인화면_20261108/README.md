# synk.im 「개인화 엔진이 붙으면」 구역 시안 (2026-11-08)

유호님 11-08 「홈페이지 · LAB에 개인화 엔진을 붙여서 이렇게 바뀝니다, 사용자는 어떻게 만족을 느끼고 학습 효율 · 재미가 높아지는지 어필이 준비돼 있나」 → 점검 결과 부분 준비([점검 §10](../../_ops/qa/atlas-world-engine-20261108/README.md)). 회사 · 기술 쪽 설명은 있고 학습자 눈으로 본 변화, 효율의 논리, 실제 화면 증거가 없었다.

## 1. 무엇으로 이기나

읽은 학습 서비스 여섯(Speak · Busuu · Brilliant · Khanmigo · WaniKani · Duolingo 블로그)은 모두 개인화를 문구 한 줄과 장식용 화면 한 장으로 말한다. 항목마다 「무엇을 혼자 맞혔나」를 보여 주는 곳은 찾지 못했다. 사용자 불만은 「맞춤이라더니 같은 걸 또 낸다」 · 「복습이 쌓여 지친다」 · 「왜 틀렸는지 모르겠다」 쪽에 몰린다(검색 요약 경유 · 작은 표본 — 앱스토어 · 레딧 원문은 못 읽음).

그래서 말 대신 **학습자의 속말과 실제 화면**으로 잇는다. 효과 · 만족 · 재방문 숫자는 쓰지 않는다(학습자 0명).

## 2. 두 안

`node docs/디자인/synk.im_개인화면_20261108/시안/serve.cjs 4797`로 띄운다(원고 빌드 폴더는 `SYNK_SITE_DIST`). `/`는 지금 공개본과 나란히 놓은 비교 쪽이고, 원고 빌드에 구역을 끼워 실제 쪽 안에서 보인다. 어디서나 볼 수 있는 비교 쪽: https://claude.ai/artifact/FEo7pKavE1BEiCgEUWctVE

- **안 A 「학습자의 말」(흰 바탕).** 제목 「틀린 말은 1분 뒤에, 맞힌 말은 잊을 때쯤 돌아옵니다」(맹검 22개 후보 중 1등). 큰 글자 물음 여섯 — 오늘 뭐 하지? · 방금 그 말, 뭐였지? · 언제 또 봐야 하지? · 외운 걸까, 아는 걸까? · 나 늘고 있나? · 오늘은 공부하기 싫은데 — 를 고르면 답 한 줄과 그때의 실제 화면이 바뀐다. 휴대폰은 옆으로 넘기는 한 줄(모두 펼침). 아틀라스 쪽에는 아래에 「같은 자리, 달라지는 한 줄」 · 「표현 하나가 돌아오는 길」(30일 선 + 실제로 채워진 칸 셋) · 왜 더 남나 · 공부하러 들어오지 않아도 · 쌓이지 않게와 줄마다 맡는 곳(Core · Temper · Trail · SYNK WORLD 복습 일정)이 붙는다.
- **안 B 「한 문제, 30일」(검정 무대).** 실제 첫 레슨의 첫 문제를 쪽에서 바로 푼다. 틀리면 1분 뒤 새 장면 문제가 이어지고(또 틀리면 또 1분 뒤), 맞히면 내일 → 7일 뒤 → 30일 뒤 → 내 위치로 빨리 감는다. 단계마다 그때의 실제 화면과 30일 선의 지금 자리가 바뀐다. 틀린 동안에는 복습 선이 꺼져 있고 확인 선만 켜진다(틀린 답도 1 · 7 · 30일 확인의 첫 기록이다).

**시안 검수:** 독립 검수 P1 4 · P2 9 · P3 13. 큰 지적 반영 — 간판을 Atlas에서 SYNK WORLD로 · 소개에 아틀라스 몫과 앱 몫을 나눠 씀, 안 B의 틀려도 선이 다 켜지던 것 · 맞힌 뒤 전화기가 「1분 뒤」이던 것(맞힌 길을 따로 찍음), 다시 확인 글에서 「가린다」 뺌(화면 글 「한 번의 결과로 판단하지 않아요」와 맞춤), 카드 나열 뺌, 제목 크기를 쪽 h2로, 휴대폰은 옆으로 넘기기. 「잊을 때쯤」은 고정 간격이라는 지적(P3)이 있었지만 제목 맹검 1등이라 유호님 고르심에 맡긴다.

## 3. 그림 — 실제 화면

`experiences/synk-world-app/qa/site-learner-scene.mjs`가 시험용 손님 학습자로 앱을 끝까지 돈다(리허설 모드, 운영 접근 없음, 날짜는 브라우저 시계만 옮김). 첫 레슨 첫 문제를 일부러 틀림 → 복습 요약 → 1분 뒤 새 장면 → 둘째 레슨 → 내 위치 → 학습 목표 → 짧은 진단 16문항 → 환승 러시 한 판 → 하루 반 · 일주일 반 · 한 달 뒤. 「낱말 뜻 읽기」 카드의 1 · 7 · 30일이 실제 엔진으로 차례로 혼자 맞힘이 되는 것까지 찍혔다. `시안/그림.py`가 캡처를 `시안/img/`로 옮긴다. 화면이 바뀌면(WORLD 새 홈 등) 이 장면으로 다시 찍는다.
