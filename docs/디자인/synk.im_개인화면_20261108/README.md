## 1. 무엇으로 이기나

읽은 학습 서비스 여섯(Speak · Busuu · Brilliant · Khanmigo · WaniKani · Duolingo 블로그)은 모두 개인화를 문구 한 줄과 장식용 화면 한 장으로 말한다. 항목마다 「무엇을 혼자 맞혔나」를 보여 주는 곳은 찾지 못했다. 사용자 불만은 「맞춤이라더니 같은 걸 또 낸다」 · 「복습이 쌓여 지친다」 · 「왜 틀렸는지 모르겠다」 쪽에 몰린다(검색 요약 경유 · 작은 표본 — 앱스토어 · 레딧 원문은 못 읽음).

그래서 말 대신 **학습자의 속말과 실제 화면**으로 잇는다. 효과 · 만족 · 재방문 숫자는 쓰지 않는다(학습자 0명).

## 2. 첫 시안이 왜 기각됐고 무엇을 바꿨나

글 · 동작 검사와 시안 검수를 지났어도 틀 자체가 AI 템플릿이었다. 진단과 고침:

## 3. 그림

- **창가 사진 다섯(홈 · 아틀라스):** 같은 창가의 저녁 → 아침 → 오후 → 비 → 첫눈. GPT 이미지 2.6 구독, 지시문은 [창가사진_지시문.md](창가사진_지시문.md). 저녁 판 하나를 기준으로 나머지를 참고 굽기하고(11-10 둘째 판부터 방 전체를 그 순간의 빛으로) `그림.py`가 창틀 · 책상에 맞춰 옮긴다(창가 연작은 옮기기만). 책이 두 권에서 세 권으로 늘고(첫눈) 비 오는 날은 담요가 놓인다. 사람 · 글자 · 화면은 넣지 않았다.
- **교실 창가 넉 장(LAB):** 같은 교실의 오늘(늦은 오후) → 내일 아침 → 7일 뒤 비 → 30일 뒤 첫눈. 칠판에는 지운 자국만 있다 — 날마다 바뀌는 때는 사진 밖 왼쪽 칸(8절). 같은 지시문 문서 아래 절.
- **실제 화면 부품:** `experiences/synk-world-app/qa/site-learner-scene.mjs`가 시험용 손님 학습자로 앱을 끝까지 돈다(리허설 모드, 운영 접근 없음, 날짜는 브라우저 시계만 옮김). 첫 레슨 첫 문제를 일부러 틀림 → 복습 요약 → 1분 뒤 새 장면 → 둘째 레슨 → 내 위치 → 학습 목표 → 짧은 진단 16문항 → 환승 러시 한 판 → 하루 반 · 일주일 반 · 한 달 뒤. 「낱말 뜻 읽기」 카드의 1 · 7 · 30일이 실제 엔진으로 차례로 혼자 맞힘이 되는 것까지 찍힌다. 언어마다 돌리고 `.band.png`(부품 자리를 재서 찍은 띠)를 `그림.py`가 옮긴다. 화면이 바뀌면(WORLD 새 홈 등) 이 장면으로 다시 찍는다.
- **함정:** 환승 러시 결과는 판마다 달라 튜터 이유 문장도 달라진다(그게 개인화다). 사이트 튜터 카드에는 「최근 놓친 …」이 나온 날을 쓴다 — `그림.py`가 8일째 · 둘째 날 · 31일째 홈 차례로 그 문장이 나온 날을 고르고, 없으면 멈춘다(장면을 다시 돌린다). 8일째가 먼저인 까닭: 둘째 날은 추천도 「듣기 짧은 연습 · 듣고 세부 정보 찾기」라 카드 위아래 줄에 같은 말이 겹쳤다(맹검 6회). 11-09 판은 8일째 · 「바람길 · 짧은 지시 듣기」.
- **영어는 430px 폭으로 찍는다(`--폭 430`).** 390에서는 다시 확인 카드의 칸 꼬리표가 두 줄로 꺾이고 복습 화면 튜터 줄이 말줄임으로 잘렸다. 470은 넉넉하지만 사이트 휴대폰에서 조각 속 앱 13px 글이 9.7px로 줄었다 — 넓게 찍을수록 같은 칸에서 글이 작아진다. 430에서 꼬리표 한 줄 · 튜터 줄 전부 · 휴대폰 390에서 10.6px(한국어 11.7px).
- **가장자리 줄:** 부품을 요소 상자대로 찍으면 목록 테두리 · 카드 밑 테두리가 함께 들어온다. `그림.py`가 위 · 아래 46줄 안의 「가로로 고르게 이어진 줄」만 지우고(글자 · 반만 그은 밑줄 링크는 남음), 다시 확인 카드 위 여백에 걸린 앞 설명 글자의 꼬리도 비운다.
