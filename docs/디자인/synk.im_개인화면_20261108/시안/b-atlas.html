확인같은 항목, 처음 보는 문제

1일7일30일
SYNK WORLD 열기 ↗왜 이렇게 만들었나 →

화면은 시험용 손님 학습자로 풀고 브라우저 시계를 옮겨 찍었습니다. 복습 일정은 SYNK WORLD 생활 한국어의 규칙입니다. 이 쪽에서 고른 답은 어디에도 저장하지 않습니다.

같은 자리, 달라지는 한 줄

홈 튜터 카드의 이유 문장 — 실제 화면 그대로

  1. 첫날아직 연습 기록이 적어요. 짧게 해 보며 맞춰 갈게요.
  2. 레슨 둘 뒤생활 팩의 다음 레슨이에요. 아직 기록이 없는 표현을 새로 만나요.
  3. 복습이 돌아왔을 때복습할 시간이 된 내용이 있어요. 짧게 다시 만나 봐요.
  4. 게임에서 놓친 뒤최근 놓친 듣고 세부 정보 찾기를 조금 더 연습해 봐요. 고른 목표와 이어지는 활동이에요.

같은 시간, 왜 더 남나

몰아서 다시 읽으면 그날은 아는 것 같습니다. 간격을 두고 다시 꺼내 보면 더 오래 남는다는 것은 학습 연구가 되풀이해 보여 준 결과입니다. SYNK WORLD는 그 간격을 학습자 대신 기억하고, 같은 표현은 다른 장면에서, 같은 항목은 처음 보는 문제로 꺼냅니다.

연구: 간격 효과(Cepeda 외, 2006) · 떠올리기 효과(Roediger · Karpicke, 2006). 연구 결과이며 SYNK WORLD에서 잰 효과는 아닙니다.

공부하러 들어오지 않아도

복습 시간표를 따로 열지 않습니다. 튜터가 먼저 말을 걸고, 돌아온 표현은 새 장면으로 오고, 재확인은 말의 리듬 · 주문 폭주 같은 게임 안에서도 일어납니다.

쌓이지 않게

못 한 계획은 다음 주로 쌓지 않습니다. 복습은 한 번에 여섯 개까지 꺼내고, 날짜를 놓친 재확인은 「기간 지남」으로 남을 뿐입니다.
