# 디자인 기준

이 프로젝트의 화면·색·서체·부품은 [SYNK SNS 제작 키트](../README.md)가 원문이다. `assets/synk-kit/`은 `node tools/SNS키트_영상연결.js <이 폴더>`로 복사한 키트 사본이고, 고치려면 키트 원본을 고친 뒤 다시 복사한다.

- 계정 테마: `brief`(synkbrief, 청금석 `#3D6BC9` 색 면 + 흰 종이)
- 이 견본의 당시 서체는 한글·라틴 SUIT Variable, 라벨·숫자 DM Mono였다(키트 사본의 `fonts/`). 새 제작·키트 갱신은 [브랜드 폰트 정본](../../../브랜드_폰트_정본.md)의 한글 SUIT·라틴/키릴 Inter Tight·모노 라벨 DM Mono 역할을 따른다.
- 움직임: 키트 `motion.js`(SynkMotion) 프리셋만 쓴다. 규칙은 키트 README §9 모션.
- 개념 한 줄: 결과를 먼저 보여 주고, 펠트와 실땀이 장면을 꿰매듯 넘긴다.
