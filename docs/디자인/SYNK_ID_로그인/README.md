## 4. 범위 — 「내 SYNK 계정」은 고르신 갈래로 이어 그린다

유호님 말씀은 「로그인하는 프론트」다. 그런데 `id/` 한 쪽 안에서 로그인 뒤 「내 SYNK 계정」이 같은 스크랩북 양식으로 이어져, 로그인만 새 옷이면 로그인을 마친 순간 옛 옷으로 바뀐다. 그래서 **공개는 로그인과 계정을 한 번에** 한다. 다만 지금 시안의 `#account`는 위쪽 세 묶음(프로필 · 로그인과 보안 · 로그인한 곳)만 그린 미리 보기다(Fable P2-15). 지금은 로그인 뼈대만 고르시게 하고, 고르신 갈래로 계정 화면을 끝까지 — 학습 기록 켬 · 끔 · 요약, 마을 기록(PC와 같은 원천 `desktop/renderer/town-records-card.mjs`), 연습 기록 내려받기, 계정 삭제(위험 행동 · 확인 창), 계정 번호, 줄 안에서 열리는 폼(이름 · 이메일 · 비밀번호), 대기 중인 이메일 변경, 로그인한 곳 여럿 — 그려 같은 맹검 · 검수를 한 번 더 받는다. PC 앱 「내 계정」(`desktop/renderer/account-page.mjs`)이 이미 진열대 문법이라 셋째 꼴을 새로 짓지 않고 그 화면에 맞춘다. 같은 `style.css` · `scrapbook.css`를 쓰는 다른 화면(`client.html` · `local-world.html` · `teacher.html`)은 범위 밖이다.

## 5. 그대로 가져가는 것 · 구현 계약 (Fable P1-2 · P1-3 반영)

- 11-11에 정한 로그인 방법 한 쌍(같은 꼴 단추 둘 · 말 「Google로 로그인」 / 「이메일로 로그인」, 가입은 「○○로 가입」 · 이메일 칸은 고르면 열림 · 「최근 사용」 · 「이 기기에서 지우기」)과 인증 흐름.
- **새 CSS는 새 파일로** — `style.css`를 고치지 않고 새 스타일 파일을 `index.html` · `preview.html`만 부르게 한다(두 파일은 id가 한 벌이라 같은 커밋에서 같이 바꾼다). 모든 규칙은 `.sid` 아래. `?v=` 열쇠도 같이 바꾼다.
