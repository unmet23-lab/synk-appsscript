## 4. 범위 — 「내 SYNK 계정」까지 한 벌로 (제안)

유호님 말씀은 「로그인하는 프론트」다. 그런데 `id/` 한 쪽 안에서 로그인 뒤 「내 SYNK 계정」(프로필 · 로그인과 보안 · 로그인한 곳 · 학습 기록 · 마을 기록 · 내 데이터와 계정 삭제)이 같은 스크랩북 양식으로 이어져, 로그인만 새 옷이면 로그인을 마친 순간 옛 옷으로 바뀐다. 그래서 시안마다 `#account` 장면(위쪽 세 묶음)을 그렸고, **로그인과 「내 SYNK 계정」을 한 번에 같은 판으로** 바꾸기를 권한다(같은 `style.css` · `scrapbook.css`를 쓰는 WORLD 시트 · 교사 화면 등 다른 계정 쪽 화면은 이번 범위 밖 — 그 화면들은 지금 모습 그대로 두도록 새 규칙을 로그인 쪽 범위 안에만 건다).

## 5. 그대로 가져가는 것

- 11-11에 정한 로그인 방법 한 쌍(같은 꼴 단추 둘 · 말 「Google로 로그인」 / 「이메일로 로그인」, 가입은 「○○로 가입」 · 이메일 칸은 고르면 열림 · 「최근 사용」 · 「이 기기에서 지우기」).
- 인증 흐름과 JS(`src/portal.mjs` · `google-auth.mjs` · `portal-security.mjs` · `portal-account.mjs`)가 쓰는 요소 id · `data-view` · `hidden` 토글. 구현은 그리는 층(HTML 짜임 · CSS)을 바꾼다. `#notice`는 id 그대로 폼 칸 안으로 옮겨 한 번만 보이게 하고, 제목 · 안내 문구(`MODE_COPY`)를 줄인 곳은 시험을 같이 고친다.
- 문구: 시안의 글은 공개본 문구 그대로이고, 제목 한 줄만 새 뼈대에 맞춰 줄였다(A · B 「SYNK ID로 로그인」 · 「SYNK ID 만들기」, C 두 줄 제목). 고르신 판의 제목 문구도 같이 확인받는다.
