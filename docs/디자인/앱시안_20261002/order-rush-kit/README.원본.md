한국어 주문을 듣고 직접 음료를 조합하는 카페 미니게임의 첫 버전입니다. 로컬 실행: `node experiences/order-rush/server.mjs` → http://127.0.0.1:5203/ . 홈페이지 공개 게임은 현재 리듬게임이며 주문 폭주는 로컬 시제품입니다.

2026-10-02 공통 목표: [TOPIK I 1~2급 준비](../../docs/미니게임_TOPIK_I_학습기준.md). 주문 폭주는 생활 발화의 수량·온도·추가·제외·부정·변경 조건을 듣고 여러 세부 정보를 반영하는 연습을 맡습니다. 서빙 점수·콤보와 최초 제출의 조건 이해를 구분하며 공식 급수·합격 판정으로 사용하지 않습니다.

## 플레이

- 한가한 오픈: 8개 주문, 시간 제한 없음. 점심 러시: 90초, 최대 3명 대기, 손님은 42초 기다립니다. 음성을 듣는 동안, 일시 정지 중, 다른 탭으로 이동한 동안 게임 시간은 흐르지 않습니다.
- 커피·차·우유·얼음·설탕과 온도를 조합합니다. 커피 + 우유 = 라테. 컵은 기본으로 따뜻하며 얼음을 넣으면 차가워집니다. 얼음을 빼도 차가운 상태는 유지됩니다. 얼음 없는 차가운 음료는 온도 버튼으로 만듭니다. 두 잔이면 컵을 추가합니다.
- 재료 1–6, Q 컵 추가, Backspace 컵 제거/비우기, R 다시 듣기, Space 서빙, Esc 일시 정지. 컵과 모든 기능은 버튼으로도 조작합니다.
- 틀린 조건은 짧게 알려주며 고쳐서 서빙할 수 있습니다. 서빙 점수·콤보와 첫 제출 정확도를 구분합니다. 글로 보기 사용과 미응답을 별도로 기록합니다. 점수는 TOPIK 점수나 듣기 능력 측정값이 아닙니다.

## 학습 설계

주문 12종으로 수량·온도·추가·제외·부정·‘대신’·‘둘 다’·‘한 잔만’ 등의 조건을 듣고 행동으로 옮기는 연습을 합니다. 게임 이후 다른 조합의 주문 3종을 시간 제한 없이 시도합니다. 듣기 내용의 세부 정보 파악과 조건 이해를 목표로 하지만 학생 대상 학습 효과 검증과 TOPIK 점수 개선 검증은 하지 않았습니다. 시험 전체를 대체하지 않습니다.

`core.mjs`의 주문 조건만 채점하며 말하지 않은 얼음·설탕 조건을 정답으로 강요하지 않습니다. 두 잔의 순서는 무관하되 각 컵이 각각의 조건을 충족해야 합니다. 첫 제출과 수정 후 정답을 구분합니다. 서빙 점수·상세 주문 기록은 회차 안에서 유지하고, 아래 공통 학습 관측은 브라우저에 보존합니다. 학생 계정·다른 기기 저장·마이크 녹음은 없습니다.

## Atlas의 다음 주문 선택 · 로컬 연결

`learning.mjs`가 각 주문의 대표 능력(듣기 세부 정보·부정/변경·조건)과 언어 난도를 제공합니다. 한가한 오픈은 12개 주문 후보에서 8개를, 새 주문 연습은 별도 3개에서 고릅니다. 매 주문은 공통 `SynkLearning.recommend`가 결정하며 첫 응답을 기록한 다음 다음 주문을 고르므로 방금 관측한 결과가 반영됩니다. 로비·영업·결과 화면에서 그 이유를 보여 줍니다. 학생이 고른 영업 모드와 직접 음료를 조합하는 방식은 유지합니다.

음성은 실제 재생 완료 뒤에만 평가 가능한 입력으로 인정합니다. 미완료·재생 실패·미응답은 오답으로 집계하지 않습니다. 기본 재생과 추가 재청취, 글로 보기, 틀린 조건을 알려 준 도움을 구분합니다. 첫 오류 유형은 주문 회차 기록에 남기되 여러 조건이 섞인 한 오답으로 특정 세부 원인을 확정하지 않습니다. 도움을 받은 답과 같은 주문의 재시도는 새로운 독립 성공으로 올리지 않습니다.

공통 관측은 **현재 브라우저·현재 출처의 기기 기록**입니다. 동일 출처로 제공되는 다른 게임과 재사용되며, 서로 다른 포트·기기·학생 계정에는 자동 연결되지 않습니다. 로비의 ‘이 브라우저의 모든 게임 학습 기록 지우기’는 같은 출처의 공통 기록 전체를 초기화합니다. 저장 불가·엔진 오류 때도 기본 영업은 계속할 수 있습니다. 이 기능과 실제 학생 효과·TOPIK 합격 준비도 검증은 별개입니다.

공통 번들 `atlas-learning.js`는 저장소 루트에서 `node tools/build-game-learning.js`로 만들고 `--check`로 대조합니다. **단독 배포·ZIP에도 이 파일을 포함**해야 하며 생성 파일은 직접 수정하지 않습니다. `learning.test.mjs`는 실제 공통 API로 추천 주문 변경, 글 도움, 음성 실패의 평가 제외를 확인합니다.

## 그래픽과 소리

입구는 원본 AI 카페 일러스트, 플레이는 Three.js의 실제 입체 작업대입니다. 컵·액체·얼음·김·재료 조합·서빙 표시가 상태에 따라 변합니다. WebGL을 사용할 수 없으면 기본 평면 작업대로 전환합니다. 모션 감소 설정에서는 김과 붓기 효과를 줄입니다.

한국어 음성은 Windows `Microsoft Heami Desktop`의 합성 음성 15개입니다. `qa/voice-bank.json`과 `qa/generate-voice.ps1`에 원문·생성 절차를 보존했습니다. 원음의 제작과 재생은 자연스러운 사람 발화 검증과 별개입니다. 효과음은 Web Audio로 생성합니다.

Three.js와 폰트의 라이선스는 `vendor/THREE-LICENSE.txt`와 `assets/*OFL*`에 있습니다. 기존 Nintendo·Overcooked 캐릭터, 그래픽 또는 음악은 사용하지 않았습니다. 제작한 카페 이미지 원본은 `assets/cafe-original.png`, 최적화 파일은 `assets/cafe.webp`입니다. 이미지 프롬프트는 `qa/art-direction.json`에 보존했습니다.
