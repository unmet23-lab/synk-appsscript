- 전후 비교: [`비교/비교_모바일.jpg`](비교/비교_모바일.jpg)(390×844, DPR 2), [`비교/비교_데스크톱.jpg`](비교/비교_데스크톱.jpg)(1440×900). 상태는 다섯 가지다: 입구, 주문 중, 틀리게 서빙, 맞게 서빙, 결과.

## 실행

```
node docs/디자인/앱시안_20261002/order-rush-kit/server.mjs   # → http://127.0.0.1:5243/
```

- 처음 받은 포트는 5213이었다. 하지만 5213은 `experiences/story-classroom/server.mjs`의 기본 포트이고 실제로 그 서버가 떠 있었다. 그래서 기본값을 **5243**으로 바꿨다. `PORT=…`로 바꿀 수 있다.
- 원본과 나란히 보려면 원본을 다른 포트로 띄운다: `PORT=5223 node experiences/order-rush/server.mjs`
- 학습 기록은 브라우저 출처(포트)별로 저장되므로 원본과 시안의 기록은 섞이지 않는다.
- `audio/`, `vendor/`, `assets/SUIT-Variable.woff2`는 원본에서 복사한 큰 파일이라 `.gitignore`에 넣었다. 새로 받은 작업본에서는 `.gitignore` 첫 줄의 명령으로 다시 채운다.

## 그대로인 것

`core.mjs`(주문·판정·점수), `learning.mjs`, `audio.mjs`, `atlas-learning.js`는 원본과 같다. 입체 작업대의 논리도 그대로다(색만 위 표대로 바뀌었다). 합성 음성 15개, 키보드(1–6·Q·Backspace·R·Space·Esc)도 같다. 학습 설계도 지켰다: 주문 글은 기본으로 숨기고 ‘글로 보기’를 눌러야 보인다. 서빙 점수와 첫 제출 정확도를 구분하고, 결과 화면의 범위 안내 문장도 그대로다.

참고: 복사한 뒤 원본에서 `learning.mjs`·`atlas-learning.js`·`learning.test.mjs`가 또 바뀌었다(다른 세션이 `responseFormat`을 더함). 원본에 반영한다면 **표현 파일만** 옮긴다: `index.html`, `style.css`, `kit-fx.mjs`, `app.mjs`의 네 줄, `assets/`, `stage.mjs`의 색 상수.

## 2026-10-02 시안의 펠트 부품 구현(v3)

| 부품 | 쓰는 자리 | 방법 |
|---|---|---|
| 짧은 크림·블러시 판(2:1) | 재료 타일 | 배경 100% 100%. 타일을 2:1 근처(데스크톱 약 150×84, 휴대폰 약 114×54)로 맞춰 늘어남이 거의 없다 |
| 긴 크림·블러시·코랄 판(5.6:1) | 서빙·카페 문 열기·새 주문 연습·일시 정지 행동 단추, 컵 탭 | 9칸 `border-image`(70/80 조각, 가로 `stretch`). 테두리 폭을 높이에 맞춰(`--fh`) 모서리와 실땀이 늘 같은 배율로 보인다 |
| 짧은 판(9칸, 가로 `round`) | 다시 듣기·글로 보기·컵 추가/비우기·다시 문 열기 칩, 모드 타일, 러시 손님 탭 | 작은 조각을 이어 붙여 좁은 폭에서도 배율이 같다 |
| 블러시 알약 | HUD 칩, 모드 이름, 지금 컵 칩, 서빙 단추의 SPACE | 배경 100% 100% |
| 펠트 체크 배지 | 고른 모드, 맞게 서빙한 안내 | 그대로 |
| 코랄·크림 원판 | 행동 단추 끝 화살표, 순서 번호, 재료 단축키 번호, 일시 정지 | 원판 위에 살아 있는 글자·선 아이콘을 얹는다 |
| 크림 꼬리표 | 로고, ‘주문서’ 이름표 | `border-image` |
| 코랄·블러시 펠트 결 | 입구·결과 코랄 면, 계산대 판, 서빙 뒤 안내 판 | 리드 레슨 시안과 같은 덧칠 비율 |
| 펠트 재료 6개 | 재료 타일 아이콘 | 휴대폰 26px, 데스크톱 40px 높이 |

- 글자는 그림에 굽지 않는다. 펠트 판의 두꺼운 아래 가장자리 때문에 글자를 조금 위로 올렸다(윗면 가운데).
- 누르면 3px 가라앉고 그림자가 줄어든다. 비활성은 투명도 45%다.
- 처음 시험한 결과 버린 방법: 한 장을 100%로 늘이면 6:1을 넘을 때 둥근 끝이 퍼졌다. 9칸 가운데를 세로로 늘이면 섬유가 번졌다. 짧은 판을 여러 조각 이어 붙이면 넓은 컵 탭에서 이음매 띠가 보였다.

## 화면별로 바뀐 것

- **입구:** 코랄 펠트 결 면이다. 큰 제목 하나가 주인공이고 ‘내 손으로.’에 흰 크레용 밑줄 한 줄이 있다. 카페 그림은 흰 테두리 인화지로 −2.5° 기울였고, 몽글(본체)을 흰 칼선 스티커로 한 번 붙였다. 모드는 펠트 타일이다(고르지 않은 쪽 블러시, 고른 쪽 크림 + 모서리에 꿰맨 체크 배지). ‘카페 문 열기’는 긴 크림 펠트 단추에 코랄 원판 화살표다. 아래 순서 1·2·3은 코랄 펠트 원판 번호다.
- **영업:** 맨 위에 로고, 모드 이름 알약, 일시 정지 원판이 있다. 휴대폰에서는 그 아래에 HUD 펠트 알약 셋을 한 줄로 둔다(이름표 11px).
  - 손님 주문은 크림 종이 **주문서**에 있다(디제틱 UI): 펠트 꼬리표 ‘주문서’, `ORDER No.01`, 다시 듣기·글로 보기 펠트 칩, 펼친 주문 글.
  - 입체 작업대는 따뜻한 크림이다. 컵 탭과 재료 타일은 펠트이고, 넣은 재료는 블러시 펠트로 바뀐다.
  - **서빙 단추 바로 위에 가장 최근 안내**를 둔다. 데스크톱에서는 주문서 아래 오른쪽 열에, 휴대폰에서는 화면 아래에 붙어 따라온다(`.dock`). 서빙 단추는 코랄 펠트에 흰 글자다.
  - 한가한 오픈에서는 손님 줄을 숨긴다. 점심 러시에서는 손님 펠트 탭이 보이고, 기다림 막대는 펠트 아래 바깥에 둔다.
- **맞게 서빙:** 서빙 단추 위 안내가 블러시 펠트 판으로 올라온다. 왼쪽에 펠트 체크 배지, 오른쪽에 몽글 눈웃음이 한 번 붙고, 콤보 칩이 한 번 펀치된다.
- **틀리게 서빙:** 같은 판이 올라오고, 안내 문장 속 틀린 조건 낱말(예: ‘따뜻하게’)에 코랄 크레용 동그라미를 그린다. 흔들림이나 빨간 경고는 없다.
- **결과:** 코랄 펠트 결 끝 화면이다. 840px 폭으로 모아 왼쪽에 점수(두께가 보이는 큰 숫자), 오른쪽에 ‘오늘의 기록’ 크림 카드를 둔다. 몽글 눈웃음은 그 카드 모서리에 붙인다(빈 곳에 떠 있지 않게). 행동은 ‘새 주문 연습하기’ 하나(긴 크림 펠트)이고 ‘다시 문 열기’는 작은 펠트 칩이다. 새 주문 연습을 마친 결과처럼 연습 묶음이 숨으면 ‘다시 문 열기’가 큰 단추로 바뀐다.
- **안내·일시 정지 창:** 크림 종이에 코랄 펠트 원판 번호를 단다. 뒤를 흐리지 않는다(유리 효과 없음).

## 조잡 방지 자체 점검(키트 README §6)

펠트 판·알약·원판은 조작 부품 자체(단추의 재질)라 장식으로 세지 않았다. 장식은 스티커·크레용처럼 기능 없이 얹은 것만 셌다.

| 화면 | 주인공 | 장식(3 이하) | 유행 장치(1 이하) | 강조 | 기울임 |
|---|---|---|---|---|---|
| 입구 | 큰 제목 | 몽글 스티커, 크레용 밑줄 = 2 | 0 | 밑줄 한 곳 | 사진 −2.5°, 몽글 −6°(휴대폰 6°). 글자·카드 0 |
| 영업(평소) | 주문서 | 0 | 0 | — | 0 |
| 맞게 서빙한 순간 | 체크 배지 안내 | 몽글 = 1 | 0 | — | 몽글 6°만 |
| 틀리게 서빙한 순간 | 안내 문장 | 크레용 동그라미 = 1 | 0 | 동그라미 한 곳 | 0 |

## 약점 · 아직 아쉬운 점

- **흰 테두리:** 펠트 컷아웃 가장자리에 옅은 흰 테두리가 있다. 흰 바탕에서는 안 보이지만, 코랄 면 위(모드 타일·카페 문 열기·다시 문 열기)에서는 얇은 흰 칼선처럼 보인다. 스티커 느낌이라 두었지만 원본 컷아웃을 더 깨끗하게 다시 따면 더 좋다.
- **실땀 밀도:** 컵 탭이 둘일 때(휴대폰에서 각 약 175px) 긴 판이 가로로 줄어 실땀이 촘촘해진다. 이음매는 없지만 한 컵일 때와 실땀 간격이 다르다.
- **가득 찬 휴대폰 화면:** 390×844에서 ‘글로 보기’와 틀린 안내가 함께 열리면 화면이 딱 찬다. 더 낮은 휴대폰(예: 667px)에서는 아래에 붙은 안내·서빙 판이 맨 아래 재료 줄을 일부 덮는다(조금 스크롤하면 보인다). 휴대폰 입체 작업대도 124px로 작아졌다.
- **서빙 단추 대비:** 코랄 펠트 위 흰 글자는 굵은 17–18px에 그림자를 넣었지만 대비가 3:1 언저리다. 리드 지정대로 흰 글자로 두었다.
- **좁은 HUD:** 휴대폰 HUD의 ‘SERVE SCORE’는 칩 안에 몇 px만 남는다. 번역하거나 이름표가 길어지면 넘친다.
- **비는 자리:** 데스크톱 영업 화면은 왼쪽 열(작업대)이 오른쪽 계산대보다 짧아 아래가 조금 빈다. 결과 화면은 점수 오른쪽에 아직 여백이 있다(전보다 줄었다).
- **허락 밖 변경:** 바닥판 색을 바꾼 것은 리드가 허락한 범위(배경·빛) 밖이다. 컵 받침 쟁반(`0xd4deee`)은 여전히 옅은 푸른 회색이다.
- **원본과 다른 점:** 결과 점수는 키트 원형의 같은 색 엠보싱이 아니라 잉크색 + 코랄 두께 그림자다. 휴대폰 학습 이유 문장(`#game-learning`)은 플레이 영역 아래로 내렸다. 컵 설명은 화면에서 숨기고 화면 읽기 알림으로만 남겼다. 한가한 오픈에서 손님 줄을 숨겼다. 학습 설계 쪽 확인이 필요하다.
- **페이지 무게:** 펠트 사진 부품 때문에 페이지가 약 500KB 늘었다.
- **AI 생성 표시:** 펠트 부품은 리드가 GPT Image 2.5로 만든 것이다. UI 재질이라 ‘AI 예시 이미지’ 표시는 하지 않았다.
- **실기기 미확인:** 머리 없는 Chrome(WebGL은 SwiftShader)에서만 봤다. 실제 휴대폰 터치·성능은 확인하지 않았다.
