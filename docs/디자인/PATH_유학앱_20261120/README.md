### 기존 앱이 비워 둔 자리

1. **준비부터 취업까지 한 기록으로 잇는 곳이 없다.** 세계 유학 플랫폼은 출국에서 끝난다. 한국 민간 앱은 입국부터 시작한다. Study in Korea의 절차도 「비자 발급과 출국 준비」에서 끝난다.
2. **한국어 성적의 만료일과 다음 단계에 필요한 급수를 함께 챙기는 곳이 없다.** 일할 수 있는 시간, 거주 비자 점수, 발표된 재정 증명 면제가 모두 급수에 달려 있다.
3. **수수료가 보이지 않는다.** Yocket 앱스토어 리뷰에 고지받지 못한 「환불 불가」 불만이 있다. 교육부는 2026-09-08에 유학원이 환불 규정을 알리게 하는 조치를 발표했다.
4. **대학과 유학원의 검증 정보를 카드에 붙인 곳이 없다.** 교육부 인증 대학 명단은 Study in Korea에 따로 있다.
5. **「지금 내가 몇 시간 일할 수 있나」를 계산해 주는 곳이 없다.** 과정, 학년, 급수, 인증 대학 여부에 따라 한 주 10~35시간으로 갈린다.
6. **부모가 보는 화면이 없다.**

이 여섯 자리가 PATH가 다른 앱과 갈리는 곳이다.

## 화면

아래 탭은 다섯이다. 사업계획서의 다섯 단계와 같은 순서다.

| 탭 | 단계 | 화면 | 하는 일 |
|---|---|---|---|
| 오늘 | 모으기, 준비 | 오늘, 내 조건, 내 길 | 지금 할 일 하나, 다가오는 날, 조건 대조, 서류와 수수료 |
| 채널 | 모으기 | 채널, 채널 글 | 주제별 소식. 글마다 출처와 확인한 날. 글에서 내 일정으로 넣는다 |
| 대학 | 입학 | 대학, 대학 자세히 | 협력 대학(준비 중), 내 조건과 대조, 한 해에 드는 돈, 학교 주변 |
| 생활 | 유학 중 관리 | 생활, 4급 지키기 | 한 주에 한 번 안부, 꼭 해야 하는 일, 모임, 한국어 성적 유지 |
| 취업 | 졸업 뒤 | 취업 | 목표 자리까지 남은 칸, 내 기록 한 장, 직업 체험, 면접 연습 |

「물어보기」는 어느 화면에서나 머리 막대에 있다.

지금 PATH 앱의 세 카드(해외 준비, 유학 중, 취업 준비)는 그대로 쓴다. 카드에 따라 첫 탭이 달라진다. 해외 준비는 오늘, 유학 중은 생활, 취업 준비는 취업으로 연다.

화면 결은 2026-11-13에 고르신 「패스」를 잇는다. 흰 바탕, 줄에 매단 카드 한 장, 색은 결정 단추와 상태 표시에만 쓴다. 고리, 구멍, 빽빽한 점 무늬는 쓰지 않았다. 참고는 [참고 사이트 장부](../참고사이트/README.md)의 Linear, Nothing, Ramp, 토스와 Recent 상위의 「줄에 매단 카드」다.

## 지킬 선

- 입학, 비자, 취업을 약속하지 않는다. 화면은 판정이 아닌 대조를 보여 준다.
- 조건과 금액은 출처와 확인한 날이 있어야 화면에 나간다. 없으면 검사가 막는다.
- 제도가 바뀌는 중이다. 법무부가 2026-10-07에 재정 증명 면제(TOPIK 4급), 시간제 취업 기준, 구직 비자 기간, 해외 유학원 등록제를 계획으로 발표했고 시행일은 정해지지 않았다. 조건마다 「시행 중」과 「계획 발표」를 구분해 적는다.
- 협약 전에는 실제 대학을 「협력 대학」으로 부르지 않는다.
- 채용 공고와 알선은 법 확인과 유료직업소개 등록 뒤에 연다(2026-11-10 결정).
- 여권, 성적표, 잔고 증명 같은 파일은 공개 저장소에 두지 않는다. 받는 방식은 3단계 전에 따로 설계한다.

## 자료와 서버

| 자료 | 누가 읽나 | 어디에 두나 |
|---|---|---|
| 대학, 과정, 조건, 채널 글 | 누구나 | 저장소의 JSON 묶음으로 시작한다. 검사를 통과한 것만 synk.im 정적 파일로 나간다. 협약이 늘면 운영 화면에서 고치는 서버 표로 옮긴다 |
| 내 조건, 고른 대학, 받는 채널, 내 길 항목 | 본인 | 지금 계정 문서(`synk.path-app` 1판)를 2판으로 올린다. 저장 방식(판 번호 조건부 저장, 충돌 때 양쪽 보존)은 그대로 쓴다 |
| 서류 확인 상태, 수수료 세 번, 담당자, 모임 신청, 안부 답 | 본인과 담당자 | 서버 표와 함수(SYNK-talk). 학생은 자기 것만 본다 |

**조건 한 줄의 꼴**

```json
{
  "id": "d2-finance-local",
  "항목": "재정",
  "필요": { "종류": "은행잔고", "원": 16000000 },
  "적용": { "비자": "D-2", "대학지역": "지방" },
  "상태": "시행 중",
  "출처": "https://www.immigration.go.kr/bbs/moj/182/455427/download.do",
  "기준일": "2023-07-03",
  "확인한날": "2026-11-20"
}
```

**조건 대조기.** 입력은 내 조건과 과정의 조건 목록이다. 출력은 조건마다 「맞음」, 「부족」, 「확인 필요」와 까닭 한 줄이다. 화면과 떨어진 순수 함수로 만들어 `node --test`로 시험한다.

**검사.** 출처나 확인한 날이 없는 조건은 실패다. 확인한 날이 90일을 넘으면 운영 화면에 「다시 확인」으로 뜬다.

| 단계 | 만드는 것 | 끝난 모습 |
|---|---|---|
| 0 | 시안 고르심, Fable 설계 검토 | 유호님이 결과 탭 구성을 정하심 |
| 1 | 대학과 조건 자료 구조, 조건 대조기, 검사. 대학 탭과 내 조건 화면 | 로그인 없이 조건을 넣고 「준비 중」 대학과 대조한다 |
| 2 | 채널과 채널 글, 「내 길에 넣기」 | 글의 기한이 오늘 화면에 뜬다 |
| 3 | 내 길(서류, 기한, 수수료 세 번), 물어보기와 상담원 넘기기 | 계정에 저장되고 담당자가 서류를 확인한다 |
| 4 | 생활(안부, 꼭 해야 하는 일, 모임), 4급 지키기와 한국어 앱 연결 | 한국에 온 학생의 첫 화면이 생활이 된다 |
| 5 | 취업(남은 칸, 내 기록 한 장), 직업 체험 연결 | 고른 항목만 회사에 보이는 한 장이 나온다 |
| 6 | 운영 화면(workspace 연결), 부모님 화면, 몽골어 | 담당자가 학생마다 단계와 임박한 기한을 본다 |

1단계는 계정이나 개인정보 없이 만들 수 있어 먼저 한다. 공개는 단계마다 화면 검수를 거친다.

## 유호님이 정하실 것

1. **화면 결과 탭 다섯.** 시안 1판대로 갈지.
2. **대학 탭의 첫 자료.** 협약 전까지 예시만 둘지, 대학이 공개한 요강을 「공식 정보」로 넣을지. 추천은 전북 대학 몇 곳의 공개 요강을 「공식 정보」로 넣고 「협력」 표시는 협약 뒤에 붙이는 것이다.
3. **돌려받는 조건.** 수수료 세 번의 금액과 비자가 거절됐을 때 돌려주는 범위. 화면에 그대로 나간다.
4. **상담원과 매니저.** 「상담원에게 넘기기」와 「힘들어요」를 받는 사람이 누구인지. 정해지기 전에는 3단계와 4단계의 그 단추를 열지 않는다.
5. **2026-11-11의 「새 기능은 이 판에서 멈춤」.** 이번 말씀으로 풀린 것으로 이해했다.

## 확인한 것

- 휴대폰 크기(390)와 넓은 화면(1440)에서 열한 화면의 가로 넘침 0, 콘솔 오류 0을 확인했다. 실패 요청은 파비콘 하나다.
- 글꼴은 SUIT, Inter Tight, DM Mono가 실제로 불렸다.
- 조건 값은 [벤치마킹](벤치마킹.md)의 「한국 유학 조건」 표에서 가져왔다. 대학 이름, 금액, 날짜는 예시다.

- 그림 맹검(카본, `path-study-app-sian1-20261120`)은 네 장 모두 기각이었다(3~4점). 강점으로는 「지금 할 일」 하나로 모으는 짜임, 필요한 것과 내 것의 대조, 「힘들어요」 뒤에 사람이 연락한다는 약속, 비자 단계를 일상어로 푼 것을 꼽았다.
  - 고친 것: 글자를 넣은 네모 아이콘을 선 아이콘으로 바꿈, 화면 안의 기획 설명 문구를 뺌, 「예약하기」와 학교 주변 칸을 누르는 것으로 보이게 함, 앞뒤가 안 맞던 취업 화면 글을 맞춤.
  - 남긴 것: 「흰 바탕의 절제된 틀이라 조형미가 없다」는 지적과 대학 화면에 사진이 없다는 지적. 대학 사진, 모임 사진, 고유한 그림이 들어가야 풀린다. 유호님이 결을 정하신 뒤 2판에서 다룬다.
