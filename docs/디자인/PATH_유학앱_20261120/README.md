### 기존 앱이 비워 둔 자리

1. **준비부터 취업까지 한 기록으로 잇는 곳이 없다.** 세계 유학 플랫폼은 출국에서 끝난다. 한국 민간 앱은 입국부터 시작한다. Study in Korea의 절차도 「비자 발급과 출국 준비」에서 끝난다.
2. **한국어 성적의 만료일과 다음 단계에 필요한 급수를 함께 챙기는 곳이 없다.** 일할 수 있는 시간, 거주 비자 점수, 발표된 재정 증명 면제가 모두 급수에 달려 있다.
3. **수수료가 보이지 않는다.** Yocket 앱스토어 리뷰에 고지받지 못한 「환불 불가」 불만이 있다. 교육부는 2026-09-08에 유학원이 환불 규정을 알리게 하는 조치를 발표했다.
4. **대학과 유학원의 검증 정보를 카드에 붙인 곳이 없다.** 교육부 인증 대학 명단은 Study in Korea에 따로 있다.
5. **「지금 내가 몇 시간 일할 수 있나」를 계산해 주는 곳이 없다.** 과정, 학년, 급수, 인증 대학 여부에 따라 한 주 10~35시간으로 갈린다.
6. **부모가 보는 화면이 없다.**

이 여섯 자리가 PATH가 다른 앱과 갈리는 곳이다.

## 시안 2판(2026-11-21)

유호님이 1판을 보고 「디자인사이트 참고 제대로해서 제대로 기능이 맞게 훨씬 더 미학 신경써서 만들어줘」라고 하셨다. 1판은 화면을 다 지은 뒤에 참고 사이트 장부를 열었고, 누르면 안내 글만 뜨는 곳이 많았다.

**참고를 먼저 보고 지었다.** 본 것과 가져온 것은 [참고 사이트 장부 5-2절](../참고사이트/README.md)에 있다.

| 가져온 것 | 어디서 | 2판의 자리 |
|---|---|---|
| 그림 한 장과 문장 하나로 화면을 연다 | 토스, 당근, Monzo | 오늘, 생활, 취업의 첫 판 |
| 큰 숫자 하나와 숨김 없는 내역, 누르면 그 자리에서 다시 계산 | Wise, X Money | 대학 자세히의 「내가 낼 돈」, 내 조건 |
| 실물 탑승권 | Recent 「Boarding Pass Scanner」 | 오늘의 「한국까지 가는 길」 |
| 증서 같은 종이 한 장 | Recent 「IPO Allotment Status」 | 취업의 「내 기록 한 장」 |
| 알약 단추, 노랑 결정 단추 하나 | Wise, Monzo, Flighty | 모든 화면 |
| 한 주를 칸으로 채운다 | Duolingo | 4급 지키기 |

**인물과 그림.** synk.im 홈 「한 사람의 길」의 3D 학생을 그대로 잇는다. 홈의 장면 넷(방, 대학 문, 취업, 모임)을 다시 쓰고, 같은 참고 그림으로 장면을 새로 구웠다(공부, 대학 셋, 풋살, 등산, 공항 도착, 부모님, 취업. 서류 정물은 굽는 데 오래 걸려 쓰지 않았다). 지시문은 [지시문/](지시문/)에, 원본은 저장소 밖 `C:/Users/q1212/Documents/SYNK-보관함/연구/PATH_유학앱_20261120/판/`에 있다. 굽기는 `tools/그림굽기.js`(GPT 이미지 구독)다.

**색.** 브랜드 토큰만 썼다. 길잡이는 청금석, 결정 단추는 버터, 맞음은 메도우, 부족과 지금 차례는 코랄이다. 고리, 구멍, 빽빽한 점 무늬는 쓰지 않았다.

**실제로 동작한다.** 상태 하나를 모든 화면이 함께 쓴다.

- 내 조건에서 한국어, 성적, 준비한 돈을 누르면 지원할 수 있는 대학 수, 대학 카드의 「4개 중 몇 개 맞음」, 오늘의 할 일, 장학금과 내가 낼 돈이 따라 바뀐다.
- 대학을 고르면 탑승권의 도착지, 다가오는 날, 내 길, 물어보기의 답이 그 대학으로 바뀐다.
- 원과 투그릭을 바꾼다. 대학 두세 곳을 담아 나란히 본다.
- 채널을 받고 끊는다. 채널 글의 날짜를 내 길에 넣으면 오늘 화면에 생긴다.
- 서류를 끝냄으로 바꾸면 진행 줄이 차고, 여섯 개가 차면 원서 단추가 뜬다.
- 안부를 고르고, 모임을 신청하고, 학년과 급수로 일할 수 있는 시간을 계산한다. 외국인등록을 끝내면 건강보험도 끝난 것으로 바뀐다.
- 내 기록 한 장에서 회사에 보여 줄 항목을 고른다.

화면은 열네 장이다. 1판의 열한 장에 「나란히 보기」, 「부모님 화면」, 「아르바이트」를 더했다.

## 지킬 선

- 입학, 비자, 취업을 약속하지 않는다. 화면은 판정이 아닌 대조를 보여 준다.
- 조건과 금액은 출처와 확인한 날이 있어야 화면에 나간다. 없으면 검사가 막는다.
- 제도가 바뀌는 중이다. 법무부가 2026-10-07에 재정 증명 면제(TOPIK 4급), 시간제 취업 기준, 구직 비자 기간, 해외 유학원 등록제를 계획으로 발표했고 시행일은 정해지지 않았다. 조건마다 「시행 중」과 「계획 발표」를 구분해 적는다.
- 협약 전에는 실제 대학을 「협력 대학」으로 부르지 않는다.
- 채용 공고와 알선은 법 확인과 유료직업소개 등록 뒤에 연다(2026-11-10 결정).
- 여권, 성적표, 잔고 증명 같은 파일은 공개 저장소에 두지 않는다. 받는 방식은 3-2(파일 받기) 전에 따로 설계한다(2026-11-22 3단계 설계 검토).

## 자료와 서버

| 자료 | 누가 읽나 | 어디에 두나 |
|---|---|---|
| 대학, 과정, 조건, 채널 글 | 누구나 | 저장소의 JSON 묶음으로 시작한다. 검사를 통과한 것만 synk.im 정적 파일로 나간다. 협약이 늘면 운영 화면에서 고치는 서버 표로 옮긴다 |

**조건 한 줄의 꼴**

```json
{
  "id": "d2-finance-local",
  "항목": "재정",
  "필요": { "종류": "은행잔고", "원": 16000000 },
  "적용": { "비자": "D-2", "대학지역": "지방" },
  "상태": "시행 중",
  "출처": "https://www.immigration.go.kr/bbs/moj/182/455427/download.do",
  "기준일": "2023-07-03",
  "확인한날": "2026-11-20"
}
```

**조건 대조기.** 입력은 내 조건과 과정의 조건 목록이다. 출력은 조건마다 「맞음」, 「부족」, 「확인 필요」와 까닭 한 줄이다. 화면과 떨어진 순수 함수로 만들어 `node --test`로 시험한다.

**검사.** 출처나 확인한 날이 없는 조건은 실패다. 확인한 날이 90일을 넘으면 운영 화면에 「다시 확인」으로 뜬다.

## 유호님이 정하실 것

1. **화면 결과 탭 다섯.** 시안 1판대로 갈지.
2. **대학 탭의 첫 자료.** 협약 전까지 예시만 둘지, 대학이 공개한 요강을 「공식 정보」로 넣을지. 추천은 전북 대학 몇 곳의 공개 요강을 「공식 정보」로 넣고 「협력」 표시는 협약 뒤에 붙이는 것이다.
3. **돌려받는 조건.** 수수료 세 번의 금액과 비자가 거절됐을 때 돌려주는 범위. 화면에 그대로 나간다.
4. **상담원과 매니저.** 「상담원에게 넘기기」와 「힘들어요」를 받는 사람이 누구인지. 정해지기 전에는 3단계와 4단계의 그 단추를 열지 않는다.
5. **2026-11-11의 「새 기능은 이 판에서 멈춤」.** 이번 말씀으로 풀린 것으로 이해했다.

- 2판: 단추를 실제로 눌러 다른 화면이 따라 바뀌는지 21가지를 시험했고 모두 통과했다. 휴대폰 크기(390)에서 열네 화면의 가로 넘침 0, 깨진 그림 0, 콘솔 오류 0이다.

- 2판의 그림 맹검(카본, `path-study-app-sian2-20261121`)도 네 장 모두 기각이었다(2~3점). 네 장 가운데 세 장은 「무엇을 하라는 화면인지 안다」로 답했다. 강점은 1판과 같이 짜임과 정보 설계였다.
