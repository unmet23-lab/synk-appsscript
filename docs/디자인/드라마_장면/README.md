## 화면의 겹 (위에서 아래로)

1. **장면** — 영상(시범판은 사진)이 화면 위 약 74%를 채운다. 위는 어둡게, 아래는 바탕색으로 녹는 그라데이션, 아주 옅은 필름 입자.
2. **위 띠** — 회차 알약(고정폭 영문 대문자 `EP.01 · SCENE 2`, 유리) + 장면 진행 띠(여덟 칸, 찰 때 0.6초).
3. **자막** — 화면 가운데쯤. 말하는 사람(고정폭 영문 대문자, 옅은 보라) · 대사(굵은 23px, 그림자) · 뜻(작은 회색). 영상이 주인공이라 말풍선을 쓰지 않는다.
4. **아래 판** — 받아 적은 내 말(오른쪽 작은 유리 말풍선) · 대사 카드(유리, `YOUR TURN` + 한글 안내, 빈칸) · 음성 구.

## 음성 구 — Orbloom

- 공개 패키지 [`orbloom@0.1.0`](https://github.com/rickybharti/orbloom)(MIT, 의존성 없음, WebGL, 메인 스레드)을 그대로 쓴다. 직접 그린 그라데이션 공 · 소리 막대는 슬롭으로 읽혔다(유호님 11-02 「지금은 너무 슬롭티나네」).
- 테마: `createOrbTheme({ preset: "nebula-violet-02", id: "synk-drama", seed: 2.4, colors: { base: "#0d0b1c", interior: "#030208", accents: ["#8b7bff", "#6fd3ff", "#ffffff"] }, appearance: { intensity: 1, detail: .78, glass: .5, glow: .95 }, motion: { speed: .8, drift: .6 }, audioResponse: { brightness: 1.25, motion: .65, pulse: .95 } })`.
- 상태: 기다림 `idle`(TAP TO SPEAK) → 내 차례 `listening`(YOUR TURN) → 녹음 중 `speaking`(실제 앱은 `connectMicrophone()`, 시안은 `setAudioLevel`로 말소리 꼴 세기) → 통과 `success`(NICE). 패키지 CSS(`orb.css`)를 함께 넣고 지름은 약 104px.
- 마이크는 사용자 동작 뒤에만 열고, 소리는 브라우저 밖으로 보내지 않는다(Orbloom은 올리지 않는다). 받아쓰기로 보내는 녹음은 앱의 기존 동의 흐름을 따른다.

- 크롬 · 불꽃 · 형광을 해낸 순간 밖에서 쓰기.
