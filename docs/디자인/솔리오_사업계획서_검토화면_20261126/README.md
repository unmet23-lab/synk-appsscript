# 솔리오 사업계획서 검토 화면 새 시안

솔리오 사무실 기획부의 「사업계획서」 작업 화면을 다시 그린 시안이다. 유호님이 11-26에 흰 종이를 뺀 초안을 보시고 「전보다는 확실히 좋아졌는데 조금 더 트렌디하고 세련되고 기능적으로 간편했으면 좋겠어. 아직 조잡함이 꽤 남아있네」라고 하셨다.

- 원고: [검토화면.html](검토화면.html). 누르면 실제로 동작한다.
- 올린 것: [아티팩트](https://claude.ai/artifact/5wanXxQ95qetFqBajKp4ac). `node 아티팩트판.cjs <나갈 파일>`로 굽는다.
- 앱에는 옮기지 않았다.

## 짓기 전에 적은 것

1. **한 문장:** 파일을 놓으면 직원이 고칠 곳을 한 번에 하나씩 묻는다.
2. **강조 순위**
   - 놓기: 책상 위의 구, 맨 위 한 문장, 놓는 자리. 평가 기준과 직원은 놓는 자리 안의 알약으로 물러선다.
   - 고칠 곳: 지금 고칠 문장, 구가 하는 말, 「이렇게 고치기」. 앞뒤 문장은 흐리게 물러선다.
   - 끝: 고친 수, 저장.
3. **참고**

| 참고 | 가져온 것 |
|---|---|
| [솔리오 첫 팀 고르기](../솔리오_첫계정고르기_20261121/README.md)(유호님 「너무 훌륭해 깔끔하다」) | 검정 방, 구운 장면 한 장과 문장 하나 |
| [사업계획서 쓰기 시안](../솔리오_사업계획서_첫화면_20261123/README.md)(「프론트 느낌은 깔끔하고 좋은데」, 흰 종이 뺌) | 책상 장면 그림, 구의 눈, 마스코트만 해요체 |
| [참고 사이트 장부](../참고사이트/README.md) Attio · 채널톡 | 할 일을 한 칸에 모은 입력 자리 |
| 장부 Linear · Superhuman | 바뀐 것만 하나씩 보는 검토, 자판으로 넘기기 |
| 장부 Recent 「Agent Status」 · 「Liquid Stepper」 | 진행 상태를 글 하나로, 단계는 가는 막대로 |

4. **움직임마다 알게 되는 것**

| 움직임 | 알게 되는 것 |
|---|---|
| 구의 눈이 마우스와 파일을 본다 | 여기에 놓으면 된다 |
| 읽는 동안 눈이 종이를 좌우로 본다, 막대가 찬다 | 어디까지 읽었는지 |
| 고치면 문장이 흐려졌다가 새 문장으로 바뀐다 | 무엇이 어떻게 바뀌었는지 |
| 막대 한 칸이 초록으로 찬다 | 몇 곳이 남았는지 |

## 걷어 낸 것

| 지금 앱 | 시안 |
|---|---|
| 흰 종이, 문서 전체와 메모 목록 두 열 | 지금 고칠 문장 하나 |
| 파일 고르기, 자료 고르기, 평가 항목 둘, 직원 둘, 읽기 시작이 저마다 떨어져 있음 | 놓는 자리 하나. 나머지는 기본값이고 바꿀 때만 연다 |
| 단추 꼴 다섯(흰 알약, 빈 알약, 초록 알약, 밑줄 글, 화살표 줄) | 흰 알약 하나와 옅은 알약 |
| 가로줄로 나눈 칸 | 줄 없음 |
| 맨 위 두 줄 큰 글 | 큰 글 한 줄과 작은 글 한 줄 |

## 앱에 옮길 때 정할 것

- 직원의 말을 해요체 한 문장으로 받으려면 지시문을 고쳐야 한다. 지금 AI는 합니다체로 답한다.
- 한도가 풀리는 때(11월 30일 저녁 7시)는 Claude가 보내는 한도 글에서 읽어야 한다. 「GPT로 읽기」는 직원 고르기를 바꿔 다시 읽는 것이다.
- 읽는 중의 막대는 지금 앱이 아는 만큼(묶음 몇 번째)만 찬다.
- 「같이 쓰기」의 물음은 앱에서 항목마다 여럿일 수 있다. 시안은 하나씩 물었다.
- 예시 계획서와 메모는 11-23 시험 계획서와 그때 GPT 직원이 낸 것이다. 구의 말은 다듬었다.
