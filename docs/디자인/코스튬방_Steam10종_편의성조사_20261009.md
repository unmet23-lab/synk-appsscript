# 코스튬 방 Steam 10종 편의성 조사와 개선 목록

기준일은 **2026-10-09 한국 시간**이다. 우리 방의 다음 발전은 **찾는 시간을 줄이고, 바꾼 차림을 되돌리고, 저장 코디를 바로 입고, 촬영 구도를 유지하는 것**부터 시작하는 것이 좋다. 현재 의상 8개에서는 되돌리기·최근·즐겨찾기·빠른 착용·작업 상태 유지가 먼저이고, 옷이 늘어나면 다중 필터와 사용자 그룹을 확장한다.

> **2026-10-09 사용자 실행 승인:** 아래 22개 전체를 저장·구현하고, 완료 뒤 전체를 다시 확인하며 두 번째 수정·검증까지 진행한다. [구현과 두 회차 확인 기록](../../experiences/synk-world-app/qa/costume-convenience-20261009/README.md)에서 각 항목의 증거와 남은 일을 확인한다. 조사에서 제안한 순서는 제작 순서이며 후속 항목을 제외하는 범위 축소가 아니다.

## 조사 범위

패션 중심 Steam 게임 5종과 옷장·아바타 꾸미기가 중요한 생활 게임 5종을 같은 항목으로 비교했다. Steam 전체의 판매·인기 TOP 10 순위는 아니다. 선택한 10종의 공개 자료를 조사했으며, 게임을 설치해 모든 조작을 직접 시험한 결과와 구분한다.

검색·정렬·보유/새 항목·즐겨찾기·저장 코디·염색/레이어·시착/적용/복원·촬영·입력/접근성·저장 오류·획득 동선을 확인했다. 공식 상점, 날짜 있는 개발사 패치, Steam 뉴스 API와 개별 리뷰를 사용했다. 날짜 없는 현행 안내만으로 기준일의 세부 기능을 확정하지 않았다. 표의 **미확인**은 미지원이라는 뜻이 아니다.

리뷰는 작성·수정일이 기준일 이전인 사례를 사용한다. 과거 불편이 공식 패치로 고쳐졌으면 현재 결함으로 적지 않는다. 몇 개 리뷰의 의견을 전체 사용자 비율이나 합의로 확대하지 않는다. 가격·누적 리뷰 수로 편의성을 점수화하지 않는다. 공식 패치 게시일과 실제 업데이트일도 구분한다.

## 게임별 확인과 불편

### 1 Infinity Nikki

**확인된 편의성**

- 2025-06-12 업데이트(06-13 UTC 게시)는 옷장 등의 기본 정렬을 품질순으로 변경하고, 보유한 세트 전용 메이크업 자동 적용과 Favorite Outfit·Custom Look의 부위별 염색을 개선했다. [공식 패치](https://steamcommunity.com/games/3164330/announcements/detail/591773904875290645)
- 2026-01-06에는 디테일 변경 가능 의상 필터, 디테일 빠른 전환, 염색 부위 이동, 지도에서 옷 상점 구매 상태 확인을 추가했다. [공식 패치](https://steamcommunity.com/games/3164330/announcements/detail/535497844504657975)
- 2026-07-17 Scene Preview는 실제 위치에서 카메라·방향·네 가지 조명을 바꿔 시착하고 의상 효과를 켜고 끄게 한다. 같은 업데이트의 Ability Outfit Setup → Customize Outfit에서 저장 차림을 가져온다. 사용할 수 없는 부품 표시가 있고 손에 드는 액세서리는 가져오기에서 제외된다. [공식 패치](https://steamcommunity.com/games/3164330/announcements/detail/693140950130623042)
- 2025-09-01에는 염색 조합 저장 후 바로 옷장으로 이동해 착용하고 기본색으로 복원하는 흐름을 개선했다. 이 복원은 전체 코디 Undo와 다르다. [공식 패치](https://steamcommunity.com/games/3164330/announcements/detail/501708794524336754)
- 기준일 직전 2026-09-23 2.10은 촬영 중 날씨·바람·시간·조명 조절, 친구에게 앨범 사진 공유, 옷 상점 범주·미리보기·교환 종료 시간 표시를 보강했다. 촬영 종료 시 날씨는 복원되지만 선택 시간은 열린 세계에도 적용된다. [2.10 공식 공지](https://steamcommunity.com/games/3164330/announcements/detail/703279756977636355)

**사용자 사례:** 2026-09-28 리뷰 한 건은 코디 슬롯 7개를 부족하게 느꼈다. 슬롯 수는 이 리뷰의 경험이며 기준일 UI를 직접 집계한 값으로 쓰지 않는다. 2026-10-08 리뷰는 코디·촬영의 재미와 가챠·기간 한정 부담을 함께 언급한다. [슬롯 리뷰](https://steamcommunity.com/profiles/76561199136602315/recommended/3164330/), [꾸미기·획득 리뷰](https://steamcommunity.com/profiles/76561198044831603/recommended/3164330/)

**SYNK에 적합:** 실제 활동 장소에서 시착, 효과·색까지 보존하는 차림, 미착용 부품의 이유 표시, 획득처에서 바로 입기. **미확인:** 옷 이름 검색 범위, 아이템 별표, 전체 Undo, 진입 당시 상태로 취소하는 범위.

## 먼저 만들 개선 12개

아래는 **구현 전 제안**이다. 완료 기준은 후속 구현·검증의 기준으로 쓰며 현재 성능이나 효과의 측정값이 아니다.

| 순서 | 개선 | 사용자 행동 | 완료 기준 |
|---:|---|---|---|
| 1 | 되돌리기·다시 실행·원래 차림 | 옷 여러 개를 바꾸고 앞 단계로 복귀 | 초안의 모든 부위가 함께 복원. PC Ctrl+Z/Y와 휴대폰 버튼. 글 입력 중에는 단축키가 입력 자체를 방해하지 않음. 확정 전 네트워크 착용 요청 없음 |
| 2 | 즐겨찾는 코디 바로 입기 | 피팅룸의 코디 카드에서 명시적인 입기 | 피팅룸 시작 기준 기존 세 조작을 한 조작으로 줄임. 썸네일을 눌러 보는 것과 입기를 구분. 실패하면 실제 착용으로 표시하지 않음 |

| 7 | 초안 복구와 저장 상태 | 실수로 닫거나 통신 실패 뒤 다시 열기 | 복구할 초안·마지막 저장 상태가 보임. 시착 자동 보관과 실제 착용 확정을 구분. 서버 재시도/충돌 계약 보존 |

| 11 | 첫 화면과 썸네일 빠르게 | 방을 자주 열고 닫으며 옷 고르기 | 모델과 목록을 먼저 사용 가능하게 하고 필요한 썸네일부터 생성. 계정/의상/그래픽 버전별 캐시. 다시 열 때 불필요한 재생성 없음 |

1·4·7·10은 실수와 작업 손실을 줄이고, 2·3·5·6은 반복 탐색·화면 이동을 줄인다. 8·11은 좋은 그래픽을 빠르고 편하게 보는 데 필요하다. 9·12는 결과가 쌓였을 때도 다시 쓰기 쉽도록 한다.

저장 한도 12개를 바로 수백 개로 늘리는 것보다 빠른 슬롯과 보관 목록을 나누고 복제·삭제 복구를 먼저 제공한다. 이후 실제 사용량과 저장 크기를 보고 확대한다. 다른 게임의 슬롯 불만 한 건만으로 우리 한도를 결정하지 않는다.

## 권장 화면과 조작

**피팅룸:** 큰 몽글과 상시 보이는 되돌리기/원래 차림. 옆에는 내 옷·즐겨찾기·최근·새 옷의 짧은 목록과 검색. 현재 부위 카드는 착용/시착을 표시한다. 즐겨 코디를 작은 행거 카드로 두고 카드에는 보기와 입기의 역할을 명확히 나눈다. 하단에는 입기·코디 저장·촬영으로의 동작이 이어진다.

**룩북:** 코디 썸네일·이름·부위·입기. 복제·이름·순서·삭제는 보조 메뉴에 둔다. 여러 관리 버튼을 모든 카드에 동시에 붙이지 않는다.

**촬영실:** 카메라 조작과 사진 비율·조명, 코디 선택기, 찍고 저장, 이전 사진. 코디·조명 전환은 구도를 유지한다. 프리셋 전체 편집은 피팅룸에서 하되 촬영에 필요한 선택은 촬영실 안에서 한다.

세 탭은 유지하면서 캐릭터·초안·카메라·검색의 연속성을 높이는 것이 적합하다. 색·그룹·배치 같은 고급 조작은 필요할 때 펼친다. 새 단추·카드·배지는 [펠트 부품 기준](펠트부품/README.md)으로 실제 휴대폰 크기에서 검사한다.
