# 솔리오 사무실: 옮겨 갈 때의 움직임과 직원의 한마디 (2026-11-26)

유호님 11-26: 「솔리오 사무실에서 솔리오 (직원) 클릭하면 너무 띡 하고 이동하는데 애니메이션으로 이동하게 해줄수있어? 그리고 클릭하면 솔리오가 뭐 하고있었습니다... 또는 일을 주세요.. 이런식으로 상황을 한마디식 곁들이게 하면 좋을것같은데 니 생각은 어때?」

시안 1판 영상은 유호님께 보냈다(저장소에는 두지 않는다). 유호님이 11-26 「이대로 넣기」로 정하셨다. 직접 누르려면 `node desktop/tools/office-talk-preview.cjs 4993`을 띄우고 `http://127.0.0.1:4993/`을 연다(합성 자료).

## 움직임

| 무엇이 | 언제 | 얼마나 |
|---|---|---|
| 그림이 그 부서 책상으로 다가간다 | 대화 상대를 바꿀 때 한 번 | 0.62초, 1.12~1.35배. 「사무실」을 고르면 전체로 돌아온다 |
| 누른 직원이 일어서서 손 쪽을 본다 | 그림에서 직원이나 책상을 누를 때 | 0.34초, 구 반지름의 1.2배 높이 |
| 말풍선 | 같은 때 | 6.5초 뒤나 다른 곳을 누르면 사라지고 직원이 앉는다 |
| 앞 대화가 흐려지고 새 대화가 올라온다 | 대화 상대를 바꿀 때 | 0.12초, 이어서 0.3초 동안 8px |

저절로 도는 움직임은 없다. Windows의 움직임 줄이기가 켜져 있으면 다가가기와 일어서기 없이 말풍선만 뜬다.

## 한마디

AI를 부르지 않는다. 화면이 이미 아는 것(직원의 상태, 마지막 도구와 파일, 그 부서에 맡긴 일)만 말한다. 다시 누르면 다음 말을 한다.

| 직원의 상태 | 말 |
|---|---|
| 일하는 중 | 「블로그_11월.md 쓰고 있었습니다.」 하는 일을 모르면 「맡은 일을 하고 있었습니다.」 |
| 승인을 물음 | 「여쭌 것이 있어서 답을 기다리고 있었습니다.」 |
| 끝냄 | 「하던 일을 끝냈습니다. 확인해 주세요.」 |
| 하루 안에 끝낸 맡긴 일이 있음 | 「「합계를 고쳐 주세요」 일은 끝내 두었습니다. 다음 일을 주세요.」 |
| 조용함 | 「25분째 조용히 있었습니다. 일을 주세요.」 |

맡기기가 꺼진 배포판에서는 앱에서 일을 줄 수 없으므로 「일을 주세요」 대신 「Claude Code 창에서 말씀해 주세요.」라고 한다. 끝나면 알리겠다는 약속은 하지 않는다. 앱이 지키지 못하는 세션이 있다.

## 2판: 파일 이름 대신 하는 일(11-26)

유호님이 1판의 「블로그_11월.md 쓰고 있었습니다.」를 보시고 「이 안에 있는 내용을 요약해서 한줄로 알려주는거지」라고 하셨다.

- **먼저 쓰는 것:** 솔리오에서 맡긴 일이면 맡기신 말, 아니면 Claude Code가 기록에 적어 두는 그 일의 제목(`custom-title` · `agent-name` · `ai-title` · `summary` 줄)이다. 제목은 Claude가 스스로 붙인 한 줄 요약이라 새로 AI를 부르지 않는다. 손님의 요청 원문(`last-prompt` 줄)은 길고 남이 보면 안 될 말이 섞일 수 있어 쓰지 않는다.
- **둘 다 없으면:** 파일 이름을 사람 말로 바꾼다. 「블로그_11월.md」는 「‘블로그 11월’ 문서」, 코드는 「코드를 고치고」, 그림은 「그림을 만들고」다. 명령 이름(npm 따위)은 말하지 않는다.
- **조용한 직원:** 조용한 시간은 방 머리가 이미 말하므로 「마지막으로 「회의록 한 장으로 줄이기」 일을 했습니다. 일을 주세요.」가 먼저다.
- **파일 내용을 AI로 요약하지 않은 까닭:** 누를 때마다 몇 초 기다리고 구독 사용량을 쓰며, 틀린 요약이 나올 수 있고 회원 파일 내용을 AI에 보내야 한다.
- 지금 판은 훅을 빼서 기록만으로 직원을 세우므로 마지막 도구와 파일을 모르는 일이 많다. 그래서 1판의 실제 말은 대부분 「맡은 일을 하고 있었습니다.」였을 것이다. 제목이 이 빈자리를 채운다.

## 함께 찾은 흠

「사무실」을 고른 채 그림의 직원을 누르면 그 부서로 가지 못했다(맡기기가 켜진 판). 일 방이 먼저 다시 그리면서 보낼 부서를 앞 상대로 되돌린 탓이다. `office-room.mjs`의 `holdDept`로 고쳤고, 고침을 빼면 떨어지는 시험을 두었다.
