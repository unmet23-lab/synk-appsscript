## 한 장 요약: 셋은 늘 쓰고, 넷은 한 곳에만

**늘 쓰는 셋.** 2026 트렌드 보고서들이 가장 많이 겹쳐 짚은 ‘손으로 만든 것’이다. SYNK의 펠트와 실땀은 흉내가 아니라 실제 재료다.

1. **스케치북 콜라주**: 대표 펠트 그림 하나에 펠트 스티커 두세 장, 종이테이프 한 조각. 스티커만 살짝 기울인다(−12°~10°).
2. **가벼운 엠보싱**: 주 버튼은 펠트 두께(아래쪽 안 그림자)로 눌리고, 화면의 핵심 숫자 하나만 도드라진다.
3. **나이브 드로잉**: 제목마다 핵심 한 구절에 손그림 형광펜이나 밑줄을 긋는다. 화살표와 반짝이는 한 화면에 하나씩만 쓴다.

**한 곳에만 쓰는 넷.** 요즘 유행하는 표현이지만 반복하면 소란스러워진다. 한 페이지(한 문서)에 한 번씩만 쓴다.

| 표현 | 쓰는 곳 | 모양 |
|---|---|---|
| 옛 컴퓨터 창(웹코어) | 가장 중요한 복사 상자 하나 | 청금석 제목줄, 파란 테이프, 검은 윤곽 + 5px 그림자 |
| 카메라 화면 | 결과를 공개하는 머리 한 번 | 검은 화면(Night), 실땀 네 모서리, 날짜 도장 |
| 모양으로 자른 그림(마스킹) | 대표 그림 하나 | 아치 창(위는 둥글고 아래는 30px) |
| 컨페티 | 좋은 결과일 때만 | 청금석 계열 점 네 개, 움직이지 않음 |

**바탕은 흰 종이.** 본문은 흰 바탕에서 편하게 읽히게 둔다. 카드는 옅은 선이 기본이고, 검은 윤곽과 단단한 그림자는 핵심 카드·요청문 창·하단 바에만 쓴다.

## 화면을 짜는 순서

맞춤 도구에서 확정한 흐름이다. 소개·랜딩 페이지도 같은 순서를 줄여 쓴다.

1. **머리줄**: 흰 유리 띠, 아래에 가는 실땀.
2. **첫 화면**: 왼쪽에 모노 머리말, 형광펜 한 구절이 들어간 큰 제목, 짧은 설명, 칩 서너 개, 주 버튼과 코랄 화살표. 오른쪽(휴대폰은 위)에 콜라주.
3. **질문**: 한 번에 하나. 진행 막대도 실땀이다. 선택지는 유리 카드에 A·B·C 모노 번호, 고르면 펠트 체크, 고른 뒤 한 줄 설명.
4. **결과 머리**: 카메라 화면. 날짜 도장 → 형광펜 제목 → 한 줄 설명 → 오른쪽 아치 창 그림. 좋은 결과면 컨페티.
5. **결론 카드**: 벤토. 핵심 카드 하나만 두 칸 너비와 도드라진 숫자.
6. **요청문**: 옛 창 하나. 나머지 복사 상자는 옅은 카드.
7. **팁·확인표·출처**: 흰 바탕, 옅은 선. 팁 상자에 테이프.
8. **하단 바와 알림**: 요청문 복사, 내 결과 링크.

## 하지 않는 것

- 크림·베이지 바탕, 종이 질감을 화면 전체에 깔기
- CSS 점선이나 그려 넣은 가짜 실땀
- 모든 카드에 검은 윤곽과 단단한 그림자
- ‘REC’ 같은 녹화 표시(화면 낭독기가 읽고, ‘이 기기에만 저장’ 약속과 반대 신호를 준다), 창 제목줄의 가짜 단추
- 칩과 글자 기울이기. 기울이는 건 스티커뿐이다
- 한 제목에 형광펜 여러 곳, 한 페이지에 컨페티·카메라 화면·옛 창 여러 번
- 움직이는 컨페티, 흔들리거나 떠다니는 장식. 움직이는 부품마다 의미가 있어야 한다([명품 기준 · 동작](../../명품_기준_v1.md))
- 그림 위에 관계없는 글자 버튼 덧씌우기([명품 기준 · 글자](../../명품_기준_v1.md))

## 접근성과 움직임

- 글자 대비 4.5:1 이상. 흐린 글자는 `#6F747C`까지. 청금석 기본 위에는 흰 글자(5.07:1), 메도우·버터·코랄 기본 위에는 흰 글자를 올리지 않는다.
- 초점 표시는 청금석 그늘 3px. 하단 바가 있으면 `scroll-padding-bottom`으로 초점이 가려지지 않게 한다.
- 눌러야 할 곳은 44px 이상.
- 움직임은 체크 스티커가 한 번 톡 붙는 것과 복사 알림 정도다. ‘동작 줄이기’ 설정에서는 모두 멈춘다.
- 장식 그림은 `aria-hidden`. 복사 알림은 화면용이고, 낭독은 알림 줄(`aria-live`)이 한다.
- 휴대폰 375px에서 가로로 넘치지 않는다. 결과 머리의 아치 그림은 700px 아래에서 숨긴다.

## 새 페이지에서 쓰는 법

```html
<link rel="stylesheet" href="(이 폴더)/scrapbook.css">
<style>
  @font-face{font-family:'SUIT Variable';font-weight:100 900;src:url((docs)/브랜드_폰트/SUIT/SUIT-Variable.woff2) format('woff2')}
  @font-face{font-family:'Inter Tight';font-weight:400 600;src:url((docs)/브랜드_폰트/InterTight/InterTight-Medium.ttf)}
  @font-face{font-family:'Inter Tight';font-weight:700 900;src:url((docs)/브랜드_폰트/InterTight/InterTight-Bold.ttf)}
  @font-face{font-family:'DM Mono';font-weight:400 700;src:url((docs)/브랜드_폰트/DM_Mono/DMMono-Medium.ttf)}
  :root{--thread:url((자산)/thread-shift.webp);--sticker-check:url((자산)/sticker-check.webp)}
</style>
<body class="sb-page"> … <h1 class="sb-display">제목의 <span class="sb-mark">핵심 한 구절</span></h1> …
```

- 그림 경로(`--thread`, `--sticker-check`)는 그 값을 적은 스타일시트 기준으로 풀린다. 페이지 안 `<style>`에 적으면 페이지 기준이다.
- 스티커와 실땀 사진은 [맞춤 도구 assets](../../마케팅/맞춤도구/assets/)에 있다. 원본은 synk.im 승인 펠트 아이콘(`loom-*-20260918`)과 실땀 사진이다. 기존 일반 아이콘은 승인 자산을 재사용한다. 내용에 맞는 물건이 없으면 [펠트 부품](../펠트부품/README.md)의 기존 구독 경로로 새로 만든다. 마스코트는 [AI 운영 원칙](../../AI_운영원칙.md#비용과-권한)에 따라 정본을 생김새 참고로만 넣고 장면과 함께 새로 만든다.
- 파일 하나로 보내는 자립형 HTML은 글꼴을 [`tools/lib/브랜드폰트.js`](../../../tools/lib/브랜드폰트.js)로 심는다. 맞춤 도구는 빌드가 쓰인 글자만 남긴 글꼴을 만든다.
- 맞춤 도구는 `core/wizard.css`만 고치면 된다. 공통 부품을 바꿀 때는 이 폴더의 `scrapbook.css`를 고치고 두 도구를 다시 빌드해 캡처를 비교한다.

## 새 유행을 더할 때

1. 그 시점의 트렌드 보고서, 최근 수상작, 사용자가 보낸 레퍼런스 키워드를 조사한다.
2. ‘셋은 늘, 넷은 한 곳에만’ 안에서 자리를 정한다. 새 표현도 처음에는 한 곳에만 쓴다.
3. 토큰·부품은 `scrapbook.css`에, 근거와 날짜는 아래 ‘근거’에 남긴다.
4. 견본과 대표작을 다시 캡처하고 휴대폰·데스크톱에서 넘침·대비를 확인한다.
