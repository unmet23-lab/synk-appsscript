# synk.im 창업자 쪽 다시 짓기 (2026-11-26 밤 시작)

시안이다. 공개본(synk.im/founder/)은 아직 그대로다.

## 유호님 말씀 (11-26 밤, 지금 창업자 쪽 캡처와 함께)

「여기서 내 의견을 말하는것보다 우리 회사가 어떻게 흘러가는지 (자동화 ai 시스템) ai를 정말 잘 활용하는 회사라는게 어필됬으면 좋겠고 직원들 앱 (workspace)로 비효율적인 부분들을 개선하고있고 앞으로도 우리 사업 관련된 모든것들을 기술로 대체해서 새로운 시대에 가장 효과적인 시스템들을 만들어나가는 회사라는게 가장 크게 어필됬으면 좋겠어. 그리고 우리 workspace 로그인화면 (노란색바탕에 사원증있는) 프론트로 바꿔줬으면 좋겠어」

## 시안 첫 판

파일은 [시안/index.html](시안/index.html)이다. 글꼴 · 솔리오 그림 · 예시 카드 그림은 저장소의 PULSE 고객 앱과 워크스페이스 시안 파일을 상대 경로로 부른다. 대표 사진은 공개본의 것을 부른다.

- **겉.** [워크스페이스 시안 3 「사원증」](../워크스페이스_다시짓기_20261124/시안2/README.md)을 잇는다. 솔리오 노랑 `#FED027` 바탕, 목걸이 사원증(대표 사진 · 「창업자 · 시스템 설계」 · No. 001), 눈만 움직이는 솔리오, 큰 문장은 Noto Serif KR 300, 본문은 SUIT, 시각과 숫자는 Inter Tight다. 숫자 띠 한 곳만 먹 바탕이다.
- **짜임.** 첫 화면 「사업의 모든 일을 기술로 바꿉니다」 → SYNK의 하루(실제 예약 아홉과 쉬지 않고 도는 일 넷, 서울 지금 시각에 가까운 일을 먼저 보임) → 직원 앱(카드 더미, 누르면 그 카드가 앞으로) → 숫자 넷과 다음 차례 → 만든 사람(이력은 공개본 그대로, 학력 칸은 줄이기 시안처럼 뺌).
- **사실의 근거.** 하루의 시각과 하는 일은 [관문·자동화 한 장](../../_ops/관문_자동화.md)의 Windows 예약 · Claude 앱 예약 · 회사 서버 타이머에서 옮겼다. 「60가지가 넘는」은 같은 문서에서 정해진 주기로 도는 행을 센 값이다(11-26, 한 번짜리와 꺼진 것 뺌). 팔로워 2,703명은 11-26 사업계획서 붙임 1의 값이다.
- **빼 둔 것.** 공개본의 「시작한 이유」 글과 「지키는 세 가지」는 유호님 말씀(「내 의견을 말하는것보다」)에 따라 뺐다. 사업계획서가 「가동」으로 적었지만 아직 없는 기능(AI 상담원, 출결 · TOPIK 만료 추적)은 화면에 쓰지 않았다.

## 남은 일
