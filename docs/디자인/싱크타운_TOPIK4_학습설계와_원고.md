# 싱크타운 TOPIK 4급 학습 설계와 대표 원고

2026-10-02 · 설계·창작 원고 v1. 싱크타운의 생활을 즐기면서 한국어를 익히고, 원할 때 TOPIK II 4급 준비로 이어 가는 교육 제작 원문이다. [첫 생활 구간](싱크타운_첫생활구간_설계.md)의 네 경로와 [행동과 세계 변화](../싱크타운_행동과_세계변화_설계.md)의 학습·보상·개인화 경계를 따른다.

**이 문서에 있는 것:** 입장 이후 24단원 교육과정 지도, 현재 Atlas 15개 듣기·읽기 항목과의 대응, 실제 지문·대본·문항·정답 근거·도움·평가 기준이 있는 창작 대표 과제 20개, 단계별 재확인·제작 검수 기준. **아직 완성됐다고 하지 않는 것:** 전 단원 출시 문항 은행, 모든 시험 유형의 실전 모의고사, 녹음·화면·쓰기 채점기·Town 런타임, 교육 전문가 검수와 학생 학습 효과. ‘20개 과제 완료 = 4급’으로 환산하지 않는다.

## 1 공식 시험 범위와 싱크타운의 목표

2026-10-02에 확인한 [국립국제교육원 시험 안내](https://www.niied.go.kr/web/niied/contents/niied_topik)는 다음과 같다. 사이트의 최종 수정 표시는 2025-09-17이다.

| 구분 | 평가 영역·문항 수 | 총점·등급 |
|---|---|---|
| TOPIK I PBT | 듣기 30·읽기 40 | 200점, 1급 80–139·2급 140–200 |
| TOPIK I IBT | 듣기 26·읽기 26 | 400점, 1급 121–235·2급 236–400 |
| TOPIK II PBT | 듣기 50·읽기 50·쓰기 4 | 300점, 4급 150–189 |
| TOPIK II IBT | 듣기 30·읽기 30·쓰기 3 | 600점, 4급 291–360 |

TOPIK II는 3–6급 시험이다. 말하기 평가는 별도 시험이므로 NPC와 말한 횟수·발음·친밀도를 TOPIK II 점수로 계산하지 않는다. PBT와 IBT의 점수·문항 수·입력 방법을 섞지 않는다. [2026년 시행계획](https://www.niied.go.kr/convert/preview/1765176663798/index.html)도 PBT·IBT·말하기를 구분한다.

[공식 PBT 쓰기 안내](https://exam.topik.go.kr/nasdata/webnas/raonkeditordata/uploadId/2024/02/20240227_175504804_07236.pdf)는 문맥에 맞는 문장 완성, 자료를 이용한 200–300자 글, 생각을 논리적으로 전개하는 600–700자 글을 설명한다. 내용·구성·언어 사용을 함께 본다. 이 문서의 T15–T19는 이 능력을 연습하는 창작 과제이며 공식 문제를 옮긴 것이 아니다.

[공식 IBT 쓰기 체험](https://www.topik.go.kr/asset/vendor/tutorial/exam2/write_exam.html)에는 의견과 두 근거를 400–500자로 입력하는 연습이 있다. T20은 이 공개 체험의 입력 분량을 참고한다. 이것만으로 IBT 쓰기 3문항의 모든 형태·배점·분량을 확정하지 않으며, 미확인 형식은 실제 응시 회차의 공식 안내를 확인한 뒤 별도 제작한다.

싱크타운의 **TOPIK 1급+ 통과는 앱의 입장 조건**이다. 공식 성적표 제출을 새로 요구하지 않는다. 입장 뒤에는 글자를 많이 읽는 능력을 가정하지 않고 “여기예요”, “물 주세요”부터 시작한다. 아래 A–D는 콘텐츠 제작 단계이고 공식 급수 판정이 아니다. 목표 시험 방식은 학습 자리에서 선택·변경할 수 있으며 생활 권한을 바꾸지 않는다.

## 2 입장부터 4급 준비까지의 전체 교육과정 지도

### 단계와 전환

| 단계 | 생활에서 해보는 일 | 언어 범위 | 다음 단계 연습을 제안할 근거 |

승급 시험을 생활 사건 사이에 강제로 넣지 않는다. 특정 단계가 어렵다고 농사·메뉴·집·NPC 관계를 잠그지 않는다. 학습 경로를 바꾸거나 쉬면 마지막 완료 상태와 자기 글 초안을 보존한다. 장문·자료 쓰기는 집의 학습 자리 또는 메인에서 사용자가 직접 연다. 이동·제작 도중 글을 읽거나 쓰도록 요구하지 않는다.

목표가 같아도 현재 이야기의 결과·재료를 학습용 숫자에 맞춰 바꾸지 않는다. 아래 조사·재고·일정은 **연습 자료의 가상 설정**이다. 실제 Town 상태가 다르면 연습 자료라고 표시하고 학습 자리에서만 쓴다. 실제 생활 정보로 제공할 때에는 해당 장면의 검증된 자료로 별도 원고를 만든다.

한 하위 문항은 대표 능력 하나만 관측한다. 같은 대본의 여러 질문·숫자만 바꾼 문항은 같은 `familyKey`로 묶고 서로 독립인 새 증거처럼 늘리지 않는다. 표의 두 번째 능력을 정답 하나로 동시에 숙달 처리하지 않는다.

현재 추천은 `listening|reading`, `difficulty: 1|2|3`, `binary-choice|single-choice|cup-compose|action|unknown`을 받는다. **difficulty는 자체 언어 복잡도이며 1·2·3급이 아니다.** A–D를 단순히 이 세 숫자로 치환하지 않는다. T01–T04·T07–T11-a도 어휘·문장·보기 부담을 교육 검수한 뒤 각 후보의 난도를 지정한다. 이 문서만으로 교정된 난도값이 생기지 않는다.

- **현행 재사용:** 위 15개 능력의 검수된 듣기·읽기 단일 선택, 첫 응답, 도움·음성 전달·조작 혼입 기록, 다른 `familyKey`와 나중 회차의 재확인, 요청 시 도움 제공.
- **추가 지도·형식 필요:** T05의 화자 의도·태도, T06의 긴 발표·수치 통합, T11-b 추론, T12 복수 자료 비교, T13–T20 생산 쓰기·루브릭. 기존 ‘핵심’ 항목에 전부 몰아넣어 중급 능력을 증명하지 않는다.
- **쓰기 확장 계약:** `taskId/version/sourceIds/firstDraft/revisions/helpEvents/rubricVersion/dimensionResults/reviewerSource`와 자기 작성·대필·자동완성 구분이 필요하다. 이는 제안 필드이며 현재 `game-learning.js`에 그대로 넘기는 API가 아니다. 초안 원문 저장·삭제·계정 동기화는 기존 개인정보·계정 계약에 맞춰 별도 구현한다.
- **평가 경계:** 키워드 일치나 AI 한 번의 총점으로 쓰기를 공식 점수·급수로 환산하지 않는다. 초기에는 검수된 루브릭과 채점 예시를 사용하고, 교육 검수자 간 차이와 자동 피드백의 오판을 확인한다. 근거가 부족하면 ‘판단 보류’이며 낮은 능력으로 확정하지 않는다.
- **개인화 소비처:** 글이 어려우면 다음 장면의 길이·보기·뜻 도움을 조정한다. 사용자가 지금 요청한 도움은 즉시 제공한다. 관심 경로를 바꾸어도 동일 능력의 준비된 다른 활동을 제안하고, 미제작 후보는 추천하지 않는다. 학습 기록이 없다는 이유로 NPC가 못하는 사람처럼 대하지 않는다.

Core의 현행 `recent-independent`는 운영상 연습 우선순위다. 관측 조건이 충족된 새 계열·첫 응답인지 따지며 공식 숙달·합격 예측이 아니다. 오디오 실패·정답을 가리키는 화면·조작 실패·시범 실행은 독립 듣기 근거에서 제외한다. 자막·문제별 풀이·보기 축소를 사용하면 지원받은 수행으로 남긴다. 시험 형식상 정해진 반복 재생과 사용자의 추가 재생을 향후 시험 어댑터에서 구분하며, 현행 도움 기록을 몰래 무시하지 않는다.

<a id="authoring"></a>
## 4 원고·도움·평가의 공통 제작 규격

### 학생 경험

생활에서는 뜻을 묻거나 오답을 골라도 다시 짚어 확인해 같은 선택을 실행할 수 있다. 아래 평가 정답은 **언어 이해 기록**이고 차양·메뉴·식물·만남·NPC 존중을 지급하는 조건이 아니다. 연습을 닫으면 하던 생활로 돌아가며 불이익·재수락 팝업이 없다. 학습에서 쓴 가상 주문은 실제 재료를 소비하지 않는다.

처음에는 질문도 “어디예요?”, “무엇을 해요?”처럼 짧게 쓴다. A단계의 그림은 서로 같은 크기·강조로 제작한다. 도움을 쓰기 전부터 정답 물건만 움직이거나 빛나지 않는다. 긴 글은 사용자가 고른 학습 자리에서 읽는다. 기본 연습은 시간 제한이 없고 모의시험의 제한 시간은 별도 선택이다.

### 음성·읽기 원고 전달

T01–T06의 인물·내레이션 부분은 실제 녹음 대본이다. 제목·정답·근거·괄호 속 제작 지시는 읽지 않는다. 자연스럽고 또렷한 한국어로 문장 끝을 충분히 들려주며 정답 낱말만 과장하지 않는다. T05–T06은 문장 사이 자연스러운 쉼을 넣되 실제 길이는 녹음 후 기록한다. 현재 파일에는 음원이 없다. 음성 미제작/실패 시 듣기 평가를 시작하지 않고 글로 보기 지원을 고르면 듣기 독립 수행과 분리한다.

읽기 본문은 제시한 순서를 유지한다. 듣기와 동일한 대본을 바로 읽은 뒤 다시 듣는 경우 ‘새 듣기 평가’로 세지 않는다. 객관식 보기는 문항과 함께 처음부터 같은 크기·강조로 보여 준다. 정답 표시·해설·예시답만 최초 응답 전 숨기고, 스스로 열면 해당 도움을 남긴다. 문제 설명의 번역 지원은 허용하되 본문 정답 정보의 번역과 구분한다.

### 정답과 피드백

선택 문항은 하위 문항별 정답/오답/미응답으로 기록한다. 교사와 콘텐츠 검수자는 정답의 유일성과 오답이 왜 틀렸는지를 본문에서 확인한다. 학생에게는 점수 꾸짖기 대신 “세 시가 아니라 네 시로 바뀌었어요”처럼 근거 한 줄을 먼저 보여 준다. 아래 도움 H1은 주목할 정보, H2는 더 직접적인 뜻·구조 지원이며 강제로 연속 표시하지 않는다.

쓰기에는 정답 문자열 하나가 없다. 예시답과 뜻·요구 조건이 맞는 다른 답을 인정한다. 공통 내부 루브릭은 **내용 0–2 / 구성 0–2 / 언어 0–2**, 합계 6점이다.

| 차원 | 2 | 1 | 0 |
|---|---|---|---|
| 내용 | 그 과제의 필수 정보를 모두 담고 사실·요구를 왜곡하지 않음 | 일부 빠졌으나 과제의 주요 뜻은 전달 | 무응답·무관·핵심 반대 또는 자료의 중대한 오독 |
| 구성 | 해당 길이에 맞게 앞뒤·순서·근거가 이어짐 | 연결이 약하거나 반복되지만 따라갈 수 있음 | 문장 사이 관계를 파악하기 어려움 |
| 언어 | 해당 단계에서 뜻이 명확하고 필요한 표현·문체가 적절 | 오류가 있으나 뜻을 대체로 이해 | 오류 때문에 핵심 뜻을 이해하기 어려움 |

짧은 한 문장에 문단 구성을 요구하지 않는다. 장문에는 아래 과제별 체크 항목을 함께 적용한다. 분량·수치·조건 누락은 별도 관찰값으로 남기고, 공식 감점 공식을 임의로 만들지 않는다. 이 6점은 공식 TOPIK 배점이 아니다. 피드백은 **전달된 뜻 하나 → 고칠 핵심 하나 → 학생이 다시 써 볼 자리** 순서로 제시한다. 문법 전부를 한꺼번에 고치거나 AI가 글 전체를 대체하지 않는다.

## 5 창작 대표 과제 20개

아래 ‘단계’는 연습 위치다. 상위 단계 학습자가 쉬운 과제를 고를 수 있고 초급자에게 긴 과제를 자동 노출하지 않는다. 각 과제의 ‘다음 확인’은 새 원고를 제작할 구체 조건이다. 적힌 조건만으로 재확인용 본문까지 완성됐다고 세지 않는다.

<a id="t01"></a>
### T01 · 물과 자리 — A / 듣기 낱말·세부

**선수:** 물, 차, 의자, 옆. **문맥:** 쉬는 자리에서 물을 놓을 곳을 알아보기. 두 하위 문항은 별도 응답이며 같은 듣기 계열이다.

**대본**

> 사장님: 물이에요. 의자 옆에 놓아요.

**a. 무엇이에요?** ① 물 ② 차 ③ 빵  
**b. 어디에 놓아요?** ① 의자 위 ② 의자 옆 ③ 문 앞

**정답·근거:** a① ‘물이에요’; b② ‘의자 옆’. 차·빵은 말하지 않았고 위·문 앞은 위치가 다르다. a의 보기는 동등한 물·차·빵 그림으로 먼저 제작한다. b의 그림에는 같은 물잔과 가구를 쓰고 위치만 다르게 한다.

**도움:** H1 “무엇인지 먼저 들어요.” / “어디인지 들어요.” H2 낱말 뜻 그림과 ‘옆’ 위치를 보여 주고 다시 듣기.  
**평가:** a=ko.listening.word, b=ko.listening.detail. 도움 이후 정답은 지원 수행. 그림만 보고 정답을 알게 된 장면은 듣기 독립 근거 제외.  
**다음 확인:** 새 대본에서 ‘책/문 옆’으로 바꾸되 화면에 정답 위치를 미리 놓지 않는다.

<a id="t02"></a>
### T02 · 만나는 시간이 바뀌어요 — A→B / 듣기 변경

**선수:** 세 시, 네 시, 만나다. **대본**

> 공방 주인: 오늘 세 시에 만나요. 아, 미안해요. 네 시에 만나요.

**문제:** 몇 시에 만나요? ① 두 시 ② 세 시 ③ 네 시

**정답·근거:** ③. 마지막에 네 시로 고쳤다. 세 시는 처음 약속이고 두 시는 나오지 않는다.  
**도움:** H1 “마지막 말을 다시 들어요.” H2 세 시→네 시를 그림 시계로 보여 주고 “바뀌었어요.”  
**평가:** ko.listening.negation. ‘처음 들은 숫자 선택’과 ‘숫자 자체 구별 어려움’을 한 번의 오답으로 단정하지 않고 후속 확인한다.  
**다음 확인:** 시간 대신 ‘공방이 아니라 찻집’이라는 장소 변경을 처음 보는 대화로 확인한다. 실제 NPC 일정 변경 사건으로 자동 저장하지 않는다.

<a id="t03"></a>
### T03 · 먼저 씻어요 — A→B / 듣기 순서

**선수:** 딸기, 씻다, 컵, 넣다, 먼저, 그다음. **대본**

> 사장님: 먼저 딸기를 씻어요. 그다음 컵에 넣어요.

**문제:** 무엇을 먼저 해요? ① 딸기를 먹어요 ② 딸기를 씻어요 ③ 컵에 딸기를 넣어요

**정답·근거:** ②. ‘먼저’ 뒤의 행동이다. 먹기는 지시하지 않았고 넣기는 그다음이다.  
**도움:** H1 두 동작 그림을 보여 주고 순서 표현만 다시 듣기. H2 ‘먼저=처음’과 대본 제공.  
**평가:** ko.listening.sequence. 정답 그림이 먼저 움직이는 시범을 봤으면 지원 수행. 요리 진행은 실수 없이 다시 고를 수 있다.  
**다음 확인:** ‘받침 놓기→컵 놓기’의 새 상황에서 첫 행동을 고른다. 딸기 지문 반복을 새 계열로 세지 않는다.

<a id="t04"></a>
### T04 · 물을 줄 때 — B / 듣기 조건·이유·핵심

**선수:** 흙, 마르다, 젖다, 확인하다. **대본**

> 연구원: 이 화분은 흙이 말랐을 때 물을 주세요. 흙이 아직 젖어 있으면 오늘은 물을 주지 않아도 돼요. 물을 너무 많이 주면 뿌리가 상할 수 있거든요. 먼저 흙을 살펴보세요.

**a. 흙이 젖어 있으면 어떻게 해요?** ① 물을 더 줘요 ② 오늘은 물을 주지 않아도 돼요 ③ 화분을 버려요  
**b. 물을 너무 많이 주지 않는 이유는 무엇이에요?** ① 뿌리가 상할 수 있어서 ② 물이 너무 차가워서 ③ 화분이 작아서  
**c. 이 말의 중심 내용은 무엇이에요?** ① 새 화분을 사는 방법 ② 꽃을 선물하는 방법 ③ 흙을 살펴보고 물을 주는 방법

**정답·근거:** a② ‘젖어 있으면…주지 않아도’; b① 뿌리가 상할 가능성을 직접 말했다; c③ 흙 상태에 따라 물 주는 방법 전체를 설명한다. 다른 보기는 본문과 반대이거나 말하지 않은 이유·주제다.  
**도움:** H1 마른 흙/젖은 흙의 뜻, 조건과 이유 문장을 구분. H2 각 문장 뜻을 짧게 풀고 원음 재청취.  
**평가:** a=condition, b=reason, c=main. 같은 대본 노출과 도움 이력을 공유한다. 이 원고는 특정 화분의 연습 설명이며 모든 식물의 관리법이나 실제 작물 성장 규칙으로 적용하지 않는다.  
**다음 확인:** 새 도서관 안내에서 ‘예약이 있으면 먼저 확인’이라는 다른 조건·이유를 듣는다.

<a id="t05"></a>
### T05 · 음악을 없애자는 뜻일까요 — C→D / 듣기 의도·태도

**선수:** 공간, 소리, 줄이다, 시간대, 대안. **대본**

> 사장님: 쉼터에서 음악을 틀어 보니 좋다는 분이 많았어요. 다음 주에도 계속 틀까요?  
> 공방 주인: 분위기는 좋았어요. 그런데 책을 읽으러 온 분은 조금 힘들었을 것 같아요.  
> 사장님: 그럼 음악을 아예 없애는 게 나을까요?  
> 공방 주인: 꼭 그럴 필요는 없죠. 낮에는 소리를 낮추고, 사람들이 모이는 저녁에만 조금 크게 틀면 어떨까요?  
> 사장님: 좋네요. 그렇게 해 보고 이용하는 분들께 다시 물어볼게요.

**문제:** 공방 주인의 생각으로 가장 알맞은 것은?  
① 책을 읽는 사람은 쉼터를 이용하지 않아야 한다.  
② 음악을 항상 크게 틀어야 한다.  
③ 시간에 따라 음악의 크기를 조정하면 좋겠다.  
④ 음악을 앞으로 전혀 틀지 말아야 한다.

**정답·근거:** ③. 분위기의 장점을 인정하면서 낮/저녁 조정을 제안한다. ④는 사장님이 제시했다가 공방 주인이 부정한 방법이고 ①·②는 제안과 다르다.  
**도움:** H1 ‘그럼’ 뒤 제안과 ‘꼭 그럴 필요는 없죠’의 대답을 나누어 듣기. H2 인물별 주장 카드와 전체 대본.  
**평가:** ‘문제 제기=전면 반대’로 오해하는지 확인. 화자 의도·태도는 추가 중급 능력 지도와 검수 필요. 읽은 대본의 뜻을 고른 결과를 독립 듣기라고 기록하지 않는다.  
**다음 확인:** 학교 행사에서 ‘행사를 없애기’와 ‘시간 조정하기’를 구분하는 새로운 대화.

<a id="t06"></a>
### T06 · 쉼터 조사 발표 — C→D / 듣기 핵심·수치 통합

**선수:** 조사, 응답, 증가, 원인, 만족. **대본**

**인정 범위:** ㉠ 책 추천 요청/함께 읽을 책 제안 요청, ㉡ 참석 여부를 회신해 달라는 부탁. 금요일이라는 구체 기한은 본문이 강제하지 않으므로 다른 적절한 회신 부탁도 인정한다. ㉠에 ‘모임을 취소하겠습니다’는 앞뒤 목적을 바꾸며, ㉡에 책의 가격만 묻는 것은 의자 수 확인과 연결되지 않는다. 빈칸 앞뒤를 통째로 복사하도록 요구하지 않는다.  
**근거·평가:** 내용=각 빈칸의 목적; 구성=책 미정→추천, 의자 수→참석 확인; 언어=문장 완결과 안내에 맞는 공손한 문체. 각 빈칸의 관찰값을 남기고 공통 루브릭으로 과제 전체를 평가한다.  
**도움:** H1 앞 문장의 ‘정하지 못함/수 확인’에 주목. H2 ‘추천받다/알려 주다’ 뜻과 부탁 표현 지원.  
**피드백 예:** “참석 여부를 물어서 의자 준비와 잘 연결됐어요. 첫 빈칸에는 책을 어떻게 정할지 요청을 넣어 보세요.”  
**다음 확인:** 분실물 문의·행사 변경 등 목적이 다른 안내문. 초대문 표현 암기만 평가하지 않는다.

<a id="t16"></a>
### T16 · 안내의 길이 — C / 설명문 문장 연결

**문제:** ㉠과 ㉡을 각각 한 문장으로 완성하세요. 설명문 맥락을 잇는 창작 연습이다.

> 안내문에 정보가 많다고 해서 항상 이해하기 쉬운 것은 아니다. 정보가 너무 많으면 독자가 ( ㉠ ). 그러므로 안내문을 만들 때는 가장 중요한 내용을 먼저 보여 주는 것이 좋다. 다만 내용을 줄이는 데만 집중하면 꼭 필요한 정보까지 빠질 수 있다. 따라서 글을 짧게 고친 뒤에는 ( ㉡ ).

**보기:** 없음.  
**예시답**

> ㉠ 필요한 정보를 찾기 어려울 수 있다.  
> ㉡ 필요한 정보가 모두 들어 있는지 확인해야 한다.

**인정 범위:** ㉠ 핵심 찾기/이해가 어려움, ㉡ 필수 정보 누락 여부 점검. ㉠ ‘무조건 더 잘 이해한다’는 뒤 문장과 충돌하고, ㉡ ‘더 짧게만 써야 한다’는 주의를 해결하지 못한다.  
**근거·평가:** 내용=정보 과다의 문제와 지나친 축약의 보완; 구성=그러므로/다만/따라서의 논리; 언어=설명문에 맞는 ‘-다’와 의미 명료성. 고급 문법을 억지로 쓰지 않아도 적절한 표현을 인정한다.  
**도움:** H1 문제→방법→새 문제→보완 구조. H2 ‘핵심을 찾다/빠진 정보’ 단서 제공.  
**피드백 예:** “짧게 만드는 이유를 잘 연결했어요. 마지막에는 빠진 정보가 없는지 확인하는 행동이 필요해요.”  
**다음 확인:** 물건 공유의 장점과 관리 문제처럼 다른 설명문 구조에서 문장 완성.

<a id="t17"></a>
### T17 · 작은 제안문 — C / 의견글의 중간 다리

**문제:** 쉼터에서 열고 싶은 활동 하나, 좋은 이유 하나, 예상되는 어려움과 해결 방법을 100–150자로 쓰세요. 이 분량은 SYNK의 연습용 기준이며 공식 시험 분량이 아니다.  
**보기:** 없음. 실제 행사를 열거나 재료를 쓰는 주문이 아닌 가상 제안이다.

**예시답 — 본문 108자**

> 쉼터에서 책을 바꾸는 날을 열고 싶다. 읽지 않는 책을 가져오면 다른 사람의 책을 읽을 수 있기 때문이다. 다만 책이 너무 많으면 정리가 어려우므로 한 사람이 두 권까지만 가져오게 하면 좋겠다.

**인정 범위:** 책 교환 외의 활동도 요구 네 요소가 연결되면 인정. ‘좋기 때문이다’만으로 이유를 반복하면 구체성이 부족하다.  
**근거·평가:** 내용=활동·이유·어려움·해결 네 요소; 구성=제안→이유→문제와 해결; 언어=연결 표현과 뜻의 명확성. ‘두 권’은 예시의 운영 제안이며 Town의 확정 경제 규칙이 아니다.  
**도움:** H1 네 요소를 학생이 직접 메모. H2 ‘__하고 싶다 / __기 때문이다 / 다만 __ / 그래서 __’ 틀.  
**피드백 예:** “두 권으로 제한하는 방법이 정리 문제를 해결해요. 선택한 활동의 장점도 지금처럼 구체적으로 써 주세요.”  
**다음 확인:** 같은 틀을 보지 않고 다른 활동을 제안. AI 완성문을 복사하면 자기 작성 증거로 세지 않는다.

<a id="t18"></a>
### T18 · 쉼터 활동 자료 설명 — D / PBT 자료 쓰기 연습

**문제:** 자료를 바탕으로 조사의 대상, 두 해의 변화, 가장 큰 변화와 올해 가장 많은 활동을 200–300자로 설명하세요. 자료에 없는 변화의 원인을 만들어 쓰지 마세요. 제목은 쓰지 마세요. 이 원고는 공식 문항 복제가 아닌 창작이다.

**자료**

- 싱크타운이 같은 주민 100명에게 2025년과 2026년에 조사했다.
- 질문: ‘쉼터에서 가장 자주 하는 활동 한 가지’. 응답 누락 없음.
- 시설을 고친 뒤 이용 변화를 살펴보려 했으며, 변화의 이유·만족도는 조사하지 않았다.

| 활동 | 2025년 | 2026년 |
|---|---:|---:|
| 책 읽기 | 20명 | 35명 |
| 대화 | 50명 | 40명 |
| 휴식 | 30명 | 25명 |
| 전체 | 100명 | 100명 |

**보기:** 없음. **예시답 — 본문 254자**

> 싱크타운은 쉼터를 고친 뒤 이용 변화를 알아보기 위해 주민 백 명에게 가장 자주 하는 활동을 물었다. 책 읽기는 2025년 20명에서 2026년 35명으로 늘었고, 대화는 50명에서 40명으로 줄었다. 휴식도 30명에서 25명으로 감소했다. 책 읽기는 15명 증가하여 변화가 가장 컸지만, 2026년에도 가장 많은 사람이 고른 활동은 대화였다. 이 결과만으로 시설 변경이 변화의 원인이라고 단정할 수는 없다. 여러 이유를 확인하려면 추가 조사가 필요하다.

**수치 검산:** 두 해 각 100명; 독서 +15명, 대화 -10명, 휴식 -5명; 절댓값 최대 변화는 독서 15명; 올해 최다는 대화 40명. 같은 표본 크기여서 비율은 각각 20→35%, 50→40%, 30→25%이고 ‘15% 증가’와 ‘15%포인트 증가’는 구별한다. 예시답은 인원만 써서 혼동을 피했다.

**인정 범위·근거:** 대상·전체 추세·큰 변화·올해 최다를 정확히 설명한 다른 순서와 표현 인정. 이유 미조사 한계는 적절하지만 필수 수치를 빼고 그 설명만 길게 쓰지 않는다.  
**평가:** 내용=자료 충실성과 숫자 정확성; 구성=조사 소개→비교→요약; 언어=증가/감소/반면/가장 등 정확한 선택과 일관된 서술문. 창의적인 원인 추정은 이 과제의 근거가 아니다. 공통 6점과 분량·수치 오류를 별도 기록하며 공식 30점으로 환산하지 않는다.  
**도움:** H1 각 행 차이를 메모하는 표. H2 ‘__에서 __으로 늘었다/줄었다’와 도입 틀.  
**피드백 예:** “대화가 여전히 가장 많다는 점을 정확히 찾았어요. 20명에서 35명은 15명 늘어난 것이므로 변화량을 다시 확인해요.”  
**다음 확인:** T06을 먼저 들었다면 이 과제는 같은 자료를 다른 영역으로 옮긴 연습이다. 독립 쓰기 재확인은 다른 주제·수치·추세의 새 자료를 쓴다.

### T19 · 함께 쓰는 공간의 규칙 — D / PBT 의견 쓰기 연습

**문제:** ‘공공 공간의 이용 규칙’에 대해 600–700자로 자신의 생각을 쓰세요. 다음 내용을 모두 다루세요.

- 여러 사람이 쓰는 공간에 규칙이 필요한 이유는 무엇인가?
- 서로 다른 활동을 원하는 사람들을 위해 어떤 방법을 쓸 수 있는가?
- 규칙을 정하고 고칠 때 무엇을 고려해야 하는가?

**보기:** 없음. 찻집 경험에서 출발하지만 특정 NPC의 바람을 정답 의견으로 고정하지 않는다.

**예시답 — 본문 657자**

> 마을의 공공 공간은 주민 누구나 편하게 이용할 수 있어야 한다. 그러나 사람들이 원하는 활동이 서로 다르기 때문에 규칙 없이 운영하면 갈등이 생길 수 있다. 조용히 책을 읽고 싶은 사람과 친구를 만나 이야기하고 싶은 사람이 같은 자리를 이용하는 경우가 그 예이다. 따라서 다양한 활동을 보장하면서도 다른 사람에게 주는 불편을 줄이는 규칙이 필요하다.
>
> 우선 공간과 시간을 나누는 방법을 생각할 수 있다. 모든 곳에서 대화를 금지하기보다 조용한 자리와 대화할 수 있는 자리를 구분하면 주민이 자신의 목적에 맞는 장소를 선택할 수 있다. 공간이 좁아 구분하기 어렵다면 일부 시간에만 조용히 이용하도록 정할 수도 있다. 이때 그림과 쉬운 말로 규칙을 안내하면 처음 방문한 사람도 이해하기 쉽다.
>
> 또한 규칙을 정할 때는 이용자의 의견을 듣고 실제 불편이 줄었는지 확인해야 한다. 의견이 많은 쪽의 요구만 따르면 적은 수의 주민은 계속 불편을 겪을 수 있다. 어린이나 이동이 어려운 주민도 참여할 수 있는 방식으로 의견을 모으고, 일정 기간 운영한 뒤 문제점을 고치는 것이 바람직하다.
>
> 공공 공간의 규칙은 사람을 통제하기 위한 목적보다 함께 이용할 방법을 찾는 데 초점을 두어야 한다. 서로의 필요를 이해하고 규칙을 조정한다면 더 많은 주민이 그 공간을 오래 편하게 이용할 수 있을 것이다.

**인정 범위:** 시간 구분 대신 자리 예약·공간 배치·활동별 장소 안내 등 구체적인 대안을 논리적으로 제시할 수 있다. 규칙을 최소화하자는 입장도 세 요구를 다루고 근거가 있으면 인정한다. 예시의 주장과 같아야 점수를 받는 구조가 아니다.  
**근거·평가:** 내용=필요 이유·서로 다른 요구 조정·제정과 수정 기준; 구성=문제→방법과 사례→고려점→결론; 언어=관계·대조·조건을 분명히 연결하고 서술문 문체 유지. 관련 없는 긴 설명이나 외운 문장만 채우기는 과제 수행이 부족하다. 공통 6점은 공식 50점이 아니다.  
**도움:** H1 입장·이유·사례·반대 요구·보완을 스스로 메모. H2 문단 역할 안내, 학생 초안의 의미가 끊긴 한 곳만 질문. 예시답 공개는 가장 직접적인 도움으로 기록.  
**피드백 예:** “서로 다른 이용자를 고려한 점이 분명해요. ‘의견을 듣는다’ 뒤에 누구의 의견을 어떤 방법으로 들을지 한 예를 더하면 설득력이 높아져요.”  
**다음 확인:** 학교 공동 시설 또는 디지털 서비스 이용 규칙처럼 새로운 주제. 규칙적인 장문 연습은 선택한 학습 자리에서 계속하고 모든 생활 완료에 글쓰기를 붙이지 않는다.

<a id="t20"></a>
### T20 · 두 가지 안내를 함께 — D / IBT 의견 입력 연습

**문제:** 마을 도서관에서 종이 안내와 디지털 안내를 함께 제공하는 방안에 대해 자신의 의견을 400–500자로 쓰고, 서로 다른 두 근거를 포함하세요. [공식 IBT 체험의 공개 분량·의견 형식](https://www.topik.go.kr/asset/vendor/tutorial/exam2/write_exam.html)을 참고한 창작 연습이다.

**보기:** 없음. **예시답 — 본문 437자**

> 나는 마을 도서관에서 종이 안내와 디지털 안내를 함께 제공해야 한다고 생각한다. 디지털 안내를 도입하더라도 모든 사람이 같은 방식으로 정보를 확인할 수 있는 것은 아니기 때문이다.
>
> 첫째, 두 방법을 함께 사용하면 정보에 접근하기 어려운 주민을 줄일 수 있다. 휴대전화가 없거나 작은 화면을 보기 어려운 사람도 게시판에서 운영 시간과 행사 장소를 확인할 수 있다. 둘째, 상황에 따라 편리한 방법을 선택할 수 있다. 집에서는 디지털 안내로 변경 사항을 빠르게 확인하고, 도서관에서는 종이 안내를 보며 필요한 장소를 찾을 수 있다.
>
> 물론 두 안내를 관리하려면 일이 늘어날 수 있다. 따라서 내용을 따로 만들기보다 같은 원본을 사용하고, 변경할 때 두 안내를 함께 확인하는 담당자를 정하는 것이 좋다. 이처럼 정보를 일치시키면 편리함을 유지하면서도 더 많은 주민이 도서관을 이용할 수 있다.

**인정 범위:** 병행에 반대하거나 조건부 찬성해도 두 근거가 분명하고 독자에게 설명되면 인정한다. ‘편리하다/쓰기 편하다’처럼 같은 이유를 표현만 바꾼 것은 서로 다른 근거 둘로 보지 않는다.  
**근거·평가:** 내용=입장과 구별되는 두 근거; 구성=주장→근거와 사례→마무리, 추가 반론 대응은 선택; 언어=주장과 사례의 관계·서술문 문체. 한국어 입력·수정·스크롤의 조작 문제는 글쓰기 능력과 따로 기록한다. 공통 6점을 IBT 점수로 변환하지 않는다.  
**도움:** H1 ‘누가 이용하기 어려운가 / 언제 편리한가’의 질문. H2 두 근거의 차이를 학생이 한 줄씩 적게 돕는다.  
**피드백 예:** “접근하기 어려운 사람을 돕는다는 이유와 장소별 편리함이 서로 구별돼요. 결론도 이 두 이유와 이어지는지 확인해 보세요.”  
**다음 확인:** 디지털 예약만 받는 시설 등 다른 주제와 조건. IBT 전체 3문항 모의고사는 이 한 과제로 대신하지 않는다.

## 6 재확인·출시 원고 분량·검수

### 연습, 새 확인, 시험 전이의 분리

| 상황 | 기록과 다음 행동 |
|---|---|
| 처음 소개하며 그림·뜻·문형을 알려 줌 | 소개/지원 연습. 정확히 수행해도 새 독립 증거로 세지 않음 |
| 같은 원고를 다시 잘 해결함 | 복습 성과. 새 능력이나 다른 계열 증거 수를 늘리지 않음 |
| 처음 보는 본문·첫 응답·도움 없음·음성 정상·조작 혼입 없음 | 해당 능력·응답 형식의 독립 관측 후보. 한 번으로 숙달·급수 확정하지 않음 |
| 초안 뒤 피드백을 받고 고침 | 수정 능력과 사용한 도움을 보존. 첫 초안의 독립성에 수정본을 덮어쓰지 않음 |
| 장기간 뒤 다른 상황에서 다시 수행 | 지연 재확인. 단어·사건 이름만 바뀐 재탕을 새 계열로 세지 않음 |
| 평가를 건너뛰거나 시간 부족으로 닫음 | 미확인/중단. 오답·의욕 부족·관계 하락으로 기록하지 않음 |
| 시험 방식별 모의평가 | 표준화한 별도 원고·진행 조건·채점 검토. 공식 점수와 비교 가능한지 검증 전 합격 예측 금지 |

전 단원 출시 은행은 각 목표에 **설명 원고, 도움 연습, 서로 다른 의미 맥락의 독립 확인, 나중 회차용 보류 자료**를 갖춰야 한다. 현행 Core에서 최근 독립 수행 상태를 얻으려면 여러 고유 계열이 필요하므로 대표 한 문항만으로 상태를 채우지 않는다. 아래 수량은 제작량을 관리하는 초기 최소 기준이며 충분한 학습 효과를 뜻하지 않는다.

- 기존 15개 능력 × 검수해 사용할 각 난도·응답 방식: 독립 확인용 서로 다른 계열 최소 4개와 별도 보류 계열. 사전 소개·도움용 원고는 별도다. 모든 난도를 기계적으로 채우지 말고 실제 후보가 필요한 조합만 제작한다.
- 추가 중급 능력: 의도·태도, 추론, 장문 연결, 복수 자료, 어휘·문법 문맥, 문장 삽입·문단 순서 각각에 소개·연습·새 확인·보류 자료를 준비하고 지도·평가 경계를 검수한다.
- 쓰기: 문맥 완성·자료 설명·의견 전개·요약/메모의 형식별로 주제·자료가 다른 과제와 상·중·부분 수행 예시, 오류 유형별 피드백을 준비한다. 생산 쓰기의 상태 전환 기준은 현행 선택형의 4계열 기준을 복사하지 않고 평가자 일치도를 보고 정한다.
- D06: PBT/IBT별 전체 길이·문항 구성·입력·재생 조건을 확인한 모의평가와 보류 평가 자료를 제작한다. 본 문서의 단원을 다 거쳤다고 자동으로 ‘4급 준비 완료’를 표시하지 않는다.

현재 원고 수는 **듣기 6과제, 읽기 6과제, 쓰기 8과제, 합계 20과제**다. 한 과제의 a/b/c 질문을 새로운 이야기나 독립 계열 수로 부풀리지 않는다. T06과 T18처럼 공유 자료가 있으면 문항 관계표에 묶어 둔다. 각 단원의 ‘새 상황 전이’와 위 은행 기준은 다음 원고 제작 범위를 구체화한 것이며 제작 완료 목록이 아니다.

### 문자 수와 자료 검산

T17–T20 예시답은 NFC 정규화 후 **공백·문장부호를 포함하고 줄바꿈을 제외한 Unicode 문자 수**를 프로그램으로 확인했다. T17 108자, T18 254자, T19 657자, T20 437자다. 이는 본문 길이 검산이고 공식 PBT 원고지의 숫자·문장부호·문단 칸 배치까지 확인한 결과가 아니다. PBT 출력물 제작 때 [공식 원고지 사용 안내](https://exam.topik.go.kr/nasdata/webnas/raonkeditordata/uploadId/2024/02/20240227_175447974_51977.pdf)로 실제 칸 배치를 별도 확인한다. IBT 글자 수 표시는 구현 후 공식 체험의 입력 동작과 대조한다.

수치 검산: T06/T18 두 해의 응답 합은 각각 100명, 변화량 합은 0명이다. T12는 작년 100명·올해 120명, 올해 온라인 비율 75%다. 예시답은 조사되지 않은 만족도·원인을 사실로 추가하지 않았다. 과제의 가상 조사는 실제 학생·주민 자료를 수집했다는 주장이 아니다.
