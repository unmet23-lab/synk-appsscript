# 서울행 승급 오디션 시안 (2026-11-23)

설계는 [WORLD 승급 오디션 설계](../../WORLD_승급오디션_설계_20261123.md)에 있다. 이 폴더는 그 설계의 휴대폰 시안이다.

- **보는 곳:** https://claude.ai/artifact/N3aS3RvX2o9kTAtdBhV3z1 (비공개). 원고는 [시안.html](시안.html)이고, 저장소에서 열면 그림을 `experiences/seoul-arrival/assets/img/`에서 읽는다.
- **해 볼 수 있는 것:** 연습 일지 채우기 → 오디션 접수 → 공고 → 세 막(읽기 셋, 말하기, 듣기 셋) → 붙음(공고에 내 이름, 2급 구간이 열림) 또는 떨어짐(심사표, 놓친 칸의 연습 카드, 재오디션). 위의 「3급 오디션 자리」로 가안과 나안의 길을 견준다. 「첫 오디션 말하기를 놓쳐 보기」를 켜면 떨어지는 길이 나온다. 문제를 틀려도 떨어진다.
- **시안의 한계:** 말하기는 누르면 말한 것으로 친다. 듣기는 기기의 한국어 음성으로 읽고, 「글로 보기」가 있다. 배우 판만 지었다. 문항은 시안용으로 쓴 1급 문항이고 은행 문항이 아니다.

## 짓기 전에 정한 것

- **한 문장:** 급마다 오디션이 하나 있다. 붙으면 다음 급이 켜지고, 떨어지면 놓친 것만 연습해 다시 선다.
- **잇는 정본:** 지금 서울행 「내 길」(밤 남색, 가운데 선, 좌우로 엇갈린 칸, 꿈 장면은 그림 원)과 드라마 장면 정본(그림 위 자막, 아래 판, 흰 알약 하나)을 그대로 잇는다.
- **참고(장부 5-2 · 5-3):** 기록과 증명은 종이 한 장(Recent 「IPO Allotment Status」, 「Boarding Pass Scanner」 → 오디션 공고, 결과 공고, 심사표), 단계는 이름 붙은 가는 막대(「Liquid Stepper」 → 대기실 · 심사장 · 마지막 물음), 칸을 채워 가는 표시(Duolingo → 연습 일지 여섯 칸), 녹음 알약(「Live Audio Recorder」).

| 화면 | 첫눈 | 다음 둘 | 물러섬 |
|---|---|---|---|
| 내 길 | 지금 급의 오디션 공고 | 연습 일지 칸, 잠긴 다음 급의 이름 | 본 회차 |
| 오디션 | 지금 할 일 하나(문제 · 내 대사 · 말하기 단추) | 정 실장의 말, 세 막 막대 | 번호표, 해설 |
| 떨어짐 | 놓친 칸(심사표의 빨간 막대) | 연습 카드, 재오디션 단추 | 정 실장의 말 |

| 움직임 | 보고 알게 되는 것 |
|---|---|
| 연습 일지 막대가 차오름 | 무엇을 채웠나 |
| 세 칸째에 오디션 단추 둘레가 한 번 빛남 | 이제 오디션을 볼 수 있다 |
| 결과 공고에 내 이름이 한 자씩 찍힘 | 명단에 내가 올랐다 |
| 다음 급의 흐림이 걷히고 선을 따라 빛이 한 번 오름 | 어디가 열렸고 어디로 가나 |
| 놓친 칸이 연습 카드로 내려앉음 | 무엇을 연습하나 |
| 녹음 중 음량 막대 | 내 말을 듣고 있다 |
