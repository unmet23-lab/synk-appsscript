# SYNK 대용량 자산 보관과 제작

> 2026-09-10 유호님 지시: Google Drive 5TB를 앞으로 적극 활용하고, 큰 마스코트 자산부터 이동해 노트북 공간을 확보한다.

- 고해상도 원본·과거 후보·완료 결과는 회사 Google Drive에 보관한다. 승인본과 후보의 상태는 이동으로 바꾸지 않는다.
- 현재 제작 코드·회사 정본·자산 설명·확인값·작은 배포 자산은 로컬/Git에 둔다. 편집·렌더링에 필요한 큰 파일만 작업 중 로컬에 가져온다.
- 기존 자산 목록에 이름·용도·승인 출처·Drive 위치·SHA-256 확인값을 연결한다. 큰 원본을 새 작업 사본마다 통째로 복제하지 않는다.
- 파일이 많은 고해상도 원본은 원래 상대경로와 확인값을 담은 ZIP으로 보관할 수 있다. 필요한 원본만 정확한 기존 경로로 복원하며, 작은 실제 배포 자산은 계속 로컬에 유지한다.
- 원격 업로드 및 다시 읽기 검증 후 로컬 공간을 회수한다. 복사 성공만으로 원격 업로드 완료를 선언하지 않는다.
- 동기화된 G: 파일 삭제는 클라우드 삭제로 이어진다. 로컬 공간 회수 때문에 G: 원본을 삭제하지 않는다. 미전송 자료가 있을 수 있는 Drive 캐시를 수동으로 지우지 않는다.
- 기존 제작 경로를 확인한다. 대용량 원본을 필요할 때 복원하는 절차를 연결하고, 자산이 없어 대체 표현으로 바뀌는 것을 정상으로 보고하지 않는다.
- 사용 중인 AI 모델·UE 프로젝트·렌더 캐시·Git 저장소 전체는 로컬 제작 공간에 둔다. 종료된 작업 사본과 재생성 가능한 임시 파일은 보존 필요성을 확인한 뒤 정리한다.
- 새 강제 훅이나 예약을 추가하지 않는다. 기존 제작·납품 절차에 보관 위치와 실제 완료 증거를 남긴다.

- 목록·확인값·진행 증거: [`_ops/마스코트_Drive이관_20260910/`](./_ops/마스코트_Drive이관_20260910/)
- 실제 이관 상태는 위 결과 기록을 따른다. 정책 채택과 파일 전송 완료는 별개다.

## 원본이 필요한 작업

옷의 앱용 AVIF와 JSON 설명은 로컬에 유지한다. PNG 원본을 읽는 표정·누끼·틀맞추기 작업은 먼저 필요한 파일을 복원한다. 저장소 루트에서 다음 명령을 사용한다.

```text
python -B tools/drive-mascot-archive.py restore "GPT_표정_누끼_틀/실제파일명.png"
```

정확한 상대경로는 `옷_manifest.json`과 `pack-plan.json`에서 찾는다. 복원 도구는 Drive ZIP에서 해당 파일을 읽고 SHA-256이 같은지 확인한 뒤 기존 경로에 쓴다. 기존 파일은 덮어쓰지 않는다. 네트워크·Drive 연결이 없으면 원본 복원이 필요하다고 알리고 해당 제작을 보류한다. 작은 대체 이미지로 몰래 바꾸지 않는다.
