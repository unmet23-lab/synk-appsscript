### 마케팅 알고리즘 세팅의 핵심 판정 (유호님이 원한 "우리 학원 최적화 알고리즘"의 뼈대)

리서치가 확실도 높게 지지하는 방향만 추림. 상세 실행은 ⑤ 마케팅 트랙.
- **1차 채널 = 클릭투메신저(Click-to-Messenger) 리드 광고.** 왓츠앱 아님 — 몽골은 Messenger 도달 230만(대상군 89.9%)이 검증된 채널이고 왓츠앱 실사용률은 데이터 부재. "클릭투왓츠앱" 트렌드 기사를 그대로 이식하면 채널 오적용.
- **리드폼은 Higher Intent(검토단계 추가) 기본값.** 1인 창업자라 저품질 대량 리드를 소화할 여력이 없음 → 볼륨이 아니라 상담전환율을 최적화 지표로.
- **초기엔 '리드' 최적화 직행 금지.** 학습단계 졸업 = 광고세트당 주 50 이벤트인데 소액예산으로 리드 50건은 초기에 안 나옴 → 상위 퍼널 이벤트(폼 열람·영상 시청·페이지 참여)로 학습단계를 통과시킨 뒤 단계적으로 리드로 하강.
- **세트 1~2개 순차 테스트**(5세트 병렬 금지). 예상 예산이 표준 소액 구조 최소선보다도 작아 병렬 테스트하면 세트별 학습단계 졸업이 영영 안 되는 함정.
- **초기엔 수동/좁은 지역 타겟**(UB 특정 구역·연령), Advantage+는 데이터 누적 후. (저예산 저성과 %는 저신뢰라 수치 배제, 방향만.)
- **오가닉으로 실질 참여자 1,000명을 먼저 쌓아야 리타겟팅이 작동**(참여 커스텀 오디언스 매칭 최소 1,000명). → 준비기 앞 2~3개월 오가닉 집중, 뒤에 유료 리타겟팅.
- **릴스 오가닉 = 원본 세로영상 + 3초 훅 + DM공유 유도.** 재게시/워터마크 콘텐츠는 추천 배제(30일 10회+ 재게시 시 전면 배제) — 타 플랫폼 워터마크 잔존 클립 점검·제거.
- **광고계정은 지금부터 미리 개설**, 통화(currency)는 생성 시 1회 영구 고정(변경 불가)이니 국가/통화 설정 신중히, 소액 워밍업으로 신뢰도 축적.
- **결제는 국제카드(Visa/MC/Amex) 필수·MNT 미지원.** SocialPay 가상카드 우회는 이론상 가능하나 Meta 결제 승인 실증 없음 → 소액 테스트로 반드시 실측.
- **몽골 CPM/CPL 공식 벤치마크는 존재하지 않는다** — 그래서 "알고리즘 세팅"의 본질이 곧 **소액 실측으로 우리 학원의 로컬 단가·전환을 직접 세우는 것**이다. 이 리포트의 마케팅 트랙이 그 설계다.
