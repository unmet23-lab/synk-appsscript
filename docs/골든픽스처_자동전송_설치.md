> **무엇을 위한 것인가**
> 강사가 Glide 「골든셋」에서 답한 교정이 **2년 뒤 AI 모델을 고르는 채점표**가 됩니다.
> 그 채점표는 회화 앱 저장소(SYNK-talk)에 있어야 쓸 수 있는데, 지금은 그 사이를 사람이 옮겨야 합니다

>
> **유호님이 하실 일은 아래 1단계뿐입니다.** 나머지는 이미 만들어져 있습니다.
> ⚠ 토큰 값은 **저(AI)에게 보여주지 마세요.** 저는 값을 몰라도 시스템은 돕니다.

## 1단계 · GitHub에서 토큰 만들기

1. 크롬에서 **github.com** 에 로그인합니다(유호님 계정 `unmet23-lab`).
2. 오른쪽 위 **프로필 사진** 클릭 → 메뉴에서 **Settings**.
3. 왼쪽 메뉴를 **맨 아래까지** 내려서 **Developer settings** 클릭.
4. 왼쪽에서 **Personal access tokens** → **Fine-grained tokens** 클릭.
5. 오른쪽 위 **Generate new token** 버튼 클릭.
6. 화면을 이렇게 채웁니다:

   | 칸 | 넣을 값 |
   |---|---|
   | **Token name** | `SYNK 골든픽스처` |
   | **Expiration** | `1 year` (무기한은 고르지 마세요) |
   | **Resource owner** | `unmet23-lab` |
   | **Repository access** | **Only select repositories** 를 고르고 → 아래 목록에서 **SYNK-talk** 하나만 선택 |

7. 아래로 내려 **Repository permissions** 를 폅니다.
   목록에서 **Contents** 를 찾아 오른쪽 드롭다운을 **`Read and write`** 로 바꿉니다.
   다른 항목은 전부 `No access` 그대로 두세요 — 단 **Metadata `Read-only`는 예외**입니다.
   `Required` 배지가 붙어 GitHub이 자동으로 넣는 것이라 뺄 수 없습니다(**정상입니다**).
   다 되면 Permissions 칸이 **Repositories 2 · Account 0** 으로 보입니다 — 이게 맞는 모양입니다.
8. 맨 아래 **Generate token** 클릭 → 다음 화면에 **긴 문자열**이 한 번만 보입니다. **복사** 버튼을 누르세요.
   ⚠ 이 화면을 닫으면 다시 못 봅니다. 못 봤으면 그냥 6~8번을 다시 하면 됩니다.
9. **만들어졌는지 눈으로 확인합니다** — https://github.com/settings/personal-access-tokens
   목록에 **`SYNK 골든픽스처`** 가 보여야 합니다. **「No fine-grained tokens created」면 안 만들어진 것**입니다.
   > 왜 이 줄이 있나: 2026-08-04에 「만들었다」고 알고 2단계로 넘어갔는데 실제로는 **한 개도 없었습니다.**
   > 생성 화면은 중간에 닫아도 아무 경고가 없어서, 만든 것과 안 만든 것이 **같은 모양**입니다.

## 3단계 · 눌러서 확인

시트로 돌아와 상단 **SYNK** 메뉴 → **🚀 골든셋 → SYNK-talk 저장소로 바로 보내기**.

- 개원 전이라 지금은 **「골든셋이 비어 있습니다」** 가 뜨는 것이 **정상**입니다(빈 파일로 덮지 않습니다).
- 토큰이 안 들어갔으면 **「GitHub 토큰이 없습니다」** 가 뜹니다. 원인은 둘 중 하나입니다 —
  ①**속성 이름 오타**(앞뒤 공백 포함) ②**다른 프로젝트에 넣음**. 2단계 맨 위 주소로 다시 열어 확인하세요.
  ⚠ 넣은 쪽 화면은 둘 다 「저장됨」으로 똑같이 보입니다 — **여기서 뜨는 문구만이 실제 판정입니다.**
- 강사 응답이 쌓인 뒤 누르면 **「SYNK-talk에 픽스처 N건 올렸습니다」** 가 뜹니다.

## 알아두실 것

- **언제 누르나**: 정해진 주기는 없습니다. 강사 응답이 한 뭉치 쌓였을 때(대략 6개월에 한 번) 누르면 됩니다.
  자동 배치에 넣지 **않았습니다** — 바깥 저장소로 나가는 쓰기라, 사람이 누르는 것 자체가 승인입니다.
- **나가는 내용**: 학생 원문·교정·오류유형뿐입니다. **학생ID·연락처·강사 이름·날짜는 전부 잘려 나갑니다**
  (동의 v18.9의 「비식별 사용」 약속 · 목적지가 git이라 한 번 들어가면 이력에서 못 지웁니다).
  받는 저장소 **SYNK-talk은 비공개**임을 확인했습니다(2026-08-04).
- **덮어쓰지 않는 것**: 기존 합성 픽스처(`evals/픽스처.json`)는 그대로 둡니다. 실학생 것은
  `evals/픽스처_실학생.json` 으로 따로 올라갑니다 — 둘은 다른 질문에 답합니다
  (합성 = 「23개 오류 유형을 다 잡는가」 / 실학생 = 「우리 학생이 실제로 무너지는 곳을 잡는가」).
- **토큰이 만료되면**(1년 뒤) 「업로드 실패(401)」이 뜹니다 → 1단계를 다시 하고 2단계에서 **값만** 바꾸면 됩니다.
- **그만두고 싶으면**: 2단계의 스크립트 속성을 지우면 즉시 멈춥니다. GitHub에서 토큰을 삭제해도 됩니다.
