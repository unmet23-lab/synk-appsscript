# SYNK 시스템 대장 — 지금 무엇이 갖춰져 있나

> **정본.** 시간순 일지가 아니라 **현재형 부품 목록**이다 — 「언제·왜」의 전문은 git 과 `docs/버전_이력.md`가 안다(여기 다시 쓰지 않는다).
> 새 줄은 손이 아니라 **채번 게이트**가 붙인다: `node tools/bump-version.js --desc "…" --종류 신설 --시스템 "이름" --한줄 "대외 언어 한 줄" --구역 "구역명"` (수리·보강은 `--종류 수리|보강`, 보강에 `--시스템`을 주면 「최근」 칸이 따라온다).
> 렌더 = `node tools/시스템대장.js --render` → 바탕화면 `SYNK_지도` 2장: **내부판**(전 구역+기술 상세) · **대외판**(`(대외)` 구역만 — 노출은 구역 단위).
> ⚠ **형식을 지키는 기계는 없다**(실측 2026-08-20: `tests/시스템대장.test.js` 는 존재하지 않는다 — 압축 과정에서 걷혔다). 아래 표기는 사람이 지킨다. 상태: **🟢 라이브 · 🟡 반영 대기(사유를 상태 칸에) · ⚪ 설계만**. 소급 표기 `~v9.36` = 버전 이력 문서(v9.37~) 이전부터 있던 것.
> **상태 칸 뒤 `Glide 의존`** = 🟢인데도 **Glide 실물을 끄면 입력이 0이 되는** 줄이다 — 전수표·대체 입구·시점은 `docs/앱기능_역할별_전수분석.md`(⚰ 09-05 삭제 · 옛 판정표 · `git log --all -- docs/앱기능_역할별_전수분석.md`) §5-1. 내부 위험이라 **대외판엔 안 나간다**(누출 방지도 위 ⚠대로 **사람이 지킨다** — 짝 테스트는 08-19 정리에서 걷혔다).
> **§5-1의 전건이 여기 줄로 서 있는지도 지금은 사람이 대조한다**(짝 테스트 걷힘 — 두 문서가 갈리면 대장이 다시 위험을 감추니, §5-1을 고치면 이 대장을 같이 본다).
> **이미 라이브인데 대장에 줄이 없던 것**은 채번 없이 넣는다(코드가 안 바뀌니 태울 번호가 없다):
> `node tools/시스템대장.js --소급 --구역 … --시스템 … --한줄 … --시작 "[v9.38]" [--최근 …] [--상태 "🟢 …"]` — **새로 만드는 것에 쓰면 안 된다**(그건 위의 채번 게이트).
