# SYNK 시스템 대장 — Apps Script와 개발 도구 기록

> **2026-10-02 정리**: 유호님 결정 「1기는 안 열어, 학원 운영 시스템도 지워줘」에 따라 몽골 오프라인 학원을 구글 시트로 운영하던 시스템을 지웠다([v9.346]). 접수·상담(상담 AI 챗봇·회사 두뇌·크루카드 접수·접수 처리·급수 진단·제안 봉투), 수업 운영, 학부모 소통, 게임화·콘텐츠, 데이터·AI 수집층, 무인 감시·보호, 원장 운영석 구역의 행이 여기에 해당한다. 무엇을 왜 지웠는지는 [옛 시스템 정리 목록](_ops/옛시스템_정리목록_20261002.md), 옛 대장은 git 이력에 있다. 학습자 기록과 맞춤은 talk 앱과 Atlas가 맡는다.
> 시스템별 기능과 마지막 기록을 모은 목록이다. 변경 시점과 이유는 Git과 `docs/버전_이력.md`에서 확인한다. **상태는 해당 행을 갱신했을 때의 기록이며, 이번 문장 정리에서 현재 운영 상태를 다시 확인한 것은 아니다.**
> 이 대장의 Apps Script 버전 기록은 `tools/bump-version.js`가 관리한다. 수리·보강에 `--시스템`을 지정하면 「최근」 칸도 갱신한다. 모든 제품의 신설·개발을 이 채번 절차에 묶지 않으며, 플랫폼·WORLD·SHIFT·PULSE·PATH는 각 담당 원문과 릴리스 기록에서 확인한다.
> 렌더 = `node tools/시스템대장.js --render` → 바탕화면 `SYNK_지도` 2장: **내부판**(전 구역+기술 상세) · **대외판**(`(대외)` 구역만 — 노출은 구역 단위).
> 형식은 `node tools/시스템대장.js --check`가 검사한다. 이 검사는 표의 칸·중복·필수값만 보며 **🟢가 실제로 지금 작동하는지는 증명하지 않는다.** 상태: **🟢 행의 기록 시점에 작동 확인 · 🟡 일부 실패·확인 필요 · ⚪ 설계만**. 소급 표기 `~v9.36` = 버전 이력 문서(v9.37~) 이전부터 있던 것.
> 상태 뒤의 `Glide 의존`은 당시 Glide 입력에 의존하던 기능이다. 조사 근거는 삭제된 `docs/앱기능_역할별_전수분석.md` §5-1이며 `git log --all -- docs/앱기능_역할별_전수분석.md`로 찾을 수 있다. 현재 대체 경로는 해당 기능의 코드와 운영에서 확인한다. 내부 의존 정보가 대외판에 노출되지 않는지도 출력에서 확인한다.
> 이전 조사표와 이 목록을 자동으로 대조하던 시험은 08-19에 제거됐다. 과거 조사표를 현재 운영의 완전성 근거로 사용하지 않는다.
> 이미 배포한 기능이 목록에서 빠졌다면 버전을 새로 만들지 않고 추가한다:
> `node tools/시스템대장.js --소급 --구역 … --시스템 … --한줄 … --시작 "[v9.38]" [--최근 …] [--상태 "🟢 …"]` — 이미 존재한 기능의 이력을 추가할 때 사용한다.
