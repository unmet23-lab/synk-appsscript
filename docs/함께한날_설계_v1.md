# 「함께한 날」 — 7단계를 대신하는 성장 체계 · 정본 v1.1

## §0. 먼저 — 이 설계는 «새로 짓는 것»이 아니다

7단계를 걷어낸 자리에 무엇이 오는지는 **이미 승인된 설계가 답하고 있었다.**
`docs/앱기능_역할별_전수분석.md`(⚰ 09-05 삭제 · 옛 판정표 · `git log --all -- docs/앱기능_역할별_전수분석.md`) 가 그것이다. 이 문서의 v1.0(아래 §1~§8)은 엔진을 깊이 팠지만
그 문서를 안 열었다. 합치면 서로 다투지 않고 **장기가 다르다.**

### ㉠ 승급 게이지 N13 — 이미 «3층»이다

| 근거 | 무엇 |
|---|---|
| `전수분석:337` | **N13 승급 게이지** = 껍데기 여행지도(학29) × 엔진 진화 게이트(학16) · **급수 + 태그 해소 + 기여일수 3층** |
| `전수분석:285` | 🔑 「데이터 시각화는 임의 화폐보다 느리게 움직인다. 급수는 몇 주에 한 번 움직인다 → **매일 움직이는 층을 반드시 하나 둔다**」 |
| `전수분석:118` | 학29 여행지도 → N13 껍데기. 「급수 1→6 대신 **몽골→한국 목적지** 서사」 · 신규 그래픽 비용 0 |
| `전수분석:100` | 학16 — 「**진화 게이트의 기계는 100% 승계** — 승급 게이지의 엔진이 된다」 |
| `전수분석:104` | 학20 랭킹 **미이식** — 「남과 비교는 도달제 승급 축과 어긋난다. **자기 종단 비교**가 승계」 |
| `전수분석:090` | 학11 몬스터한마디 → **승급 게이지 넛지**(「오류태그 N개 해소하면 다음 단계」) |
| `전수분석:321` | **N8 말뭉치 기여 카드** — 「내 기여 문장 수 · 연속 기여일수」 · 「**뇌를 먹이는 행위 자체가 보상 표시**」 |

**그래서 05:296 이 경고한 「초급생 매일 동기」 구멍은 이미 메워져 있었다** — 「매일 움직이는 층을
반드시 하나 둔다」가 그 답이다. v1.0 이 독립적으로 도달한 「함께한 날 · 내가 맞힌 말」은
그 3층의 **아래 두 층과 같은 것**이다:

| 전수분석 N13 3층 | 이 문서 v1.0 | 판정 |
|---|---|---|
| 급수 (느림 · 몇 주) | 여행 게이지 여섯 칸 | **같다** |
| 태그 해소 (중간) | **내가 맞힌 말** | **같다** — v1.0 이 재료 정직성까지 파 내려갔다(§4-3) |
| 기여일수 (매일) | **함께한 날** | **같다** — v1.0 이 정의를 못 박았다(§4-2) |

⇒ **다투지 않는다. v1.0 은 승인 설계의 «산식과 배선»을 채운 것이다.**
다만 표시 방식이 갈린다 — 전수분석은 셋을 **한 게이지에 겹치고**, v1.0 은 **따로 읽는다.**
**둘 다 한다**가 답이다: 게이지가 «어디쯤인지»를, 몽글이 거리가 «오늘 움직였는지»를 낸다.

## 1. 한 장 요약

바트가 저녁에 앱을 연다. 화면 오른쪽 끝에 몽글이가 **반쯤 잘린 채** 서 있다 — 등록 첫날엔 그랬다. 지금은 화면 한가운데 앉아 바트 쪽을 보고 있다. 그 사이 바뀐 건 몽글이가 아니라 **거리**다.

밑에 한 줄. **「다음 만남까지 3일」** — 어제는 4일이었다. 오늘 학원에 왔기 때문에 하나 줄었다.

3일 뒤 바트가 앱을 열면 몽글이가 한 뼘 더 가까이 와 있고, 처음 보는 자세로 앉아 한마디 한다. 「바트야, 어제 그 문장 잘했어.」 — **날짜가 그 장면을 열었고, 바트가 이번 주에 「-았/었-」을 자기 손으로 맞힌 것이 그 대사를 채웠다.**

이게 전부다. 단계도, 등급도, 진화도 없다. **쌓이는 것은 함께한 날 하나, 열리는 조건은 「내가 맞힌 말」 하나.** 둘 다 남과 견줄 수 없다 — 시작한 날이 다르고, 익힌 내용이 다르니까.

## 2. 학생이 보는 것

### 이름 — 학생 화면에 실제로 뜨는 낱말

| 자리 | 낱말 | 까닭 |
|---|---|---|
| 탭 이름 | **우리** | 두 글자. 몽골어 «бид»와 1:1. 아이콘은 «고른 가이드 얼굴»이라 「우리 반」으로 안 읽힌다 |
| 시간 눈금 | **함께한 날** | 유호님 낱말 그대로 |
| 학습 눈금 | **내가 맞힌 말** | 🔴 「말할 수 있게 된 것」은 **쓰면 안 된다** — 지금 구조에서 말하기만으로는 이 수가 안 오른다(§8-⑤) |
| 마일스톤 | **장면** (학생 화면 문구는 「몽글이가 가까이 왔어요」) | |
| 하루 활동 | **오늘 몽글이와 한 것** | 「보낸 문장」 금지 — 숙제 1건·대화 1턴·녹음 1개가 단위가 달라 더하면 뜻 없는 수가 된다 |

「나의 성장」(현행 시안 탭 이름)은 한자어 추상명사 둘이다. 등록 2주차 몽골 학생이 못 읽는다.

### 네 시제 — 실제 화면 문구

**㉠ 오늘 (매일 움직인다)**

```
        [몽글이 — 화면 오른쪽에서 시작해 장면마다 왼쪽으로 온다]

              다음 만남까지  3일          ← 화면의 유일한 코랄
              오늘 몽글이와 한 것 · 2

        「오늘도 왔네.」
```

어제 이 줄은 「4일」이었다. **오늘 하나 줄었고, 왜 줄었는지 아이가 안다.** 옛 「진화까지 62P」는 강사가 왕관을 줘야 줄어서 아이가 언제 오는지 몰랐다.

**㉡ 이번 주**

```
  이번 주
  「-고 있다」를 세 번 맞게 썼어요.
  지난주엔 두 번 틀렸던 자리예요.
```
채택 시안에 이미 있는 카드다(`성장덧씌움.py:113-120`). 그대로 산다.

**㉢ 한 시즌 (8주)**

여행 게이지 여섯 칸 중 한 칸이 꿰매진다. 아래 한 줄:
```
  2급 — 다음 칸까지 8주
```
🔴 지금 시안의 「다음 칸까지 4개」는 **단위가 화면 어디에도 없다**. 이 칸은 8주 도달제이므로 단위는 «주»다.

그리고 시즌 사이 6주를 빈 화면으로 두지 않기 위해 바로 밑에 한 줄 더:
```
  이번 시즌에 새로 맞힌 말 · 9
```

**㉣ 9개월 (되돌아보기 — 눌러야 열린다)**

```
  몽글이와 걸어온 길

  ●●●●●●●●●○○○      ← 지나온 장면 9칸 · 꿰맨 단추 그대로
  함께한 날 139  ·  내가 맞힌 말 47 / 91   (그중 3급 이상 6)

  달마다 만난 날
  ▃▅▄▆▇▅▆█▅        ← 9칸. 출석 원장에서 직접 센다

  🎧 목소리
     3월 4일   「안녕하세요. 저는 아마라입니다.」
     11월 25일 「어제 친구랑 시장에 갔는데 사람이 너무 많았어요.」
     268일 사이의 두 순간이에요.

  ✍️ 내가 쓴 문장
     3월  「나 학교 가요」
     11월 「어제 학교에 갔는데 친구를 만났어요」

  📝 3월의 너는 이렇게 썼어
     「한국 가고 싶어요」 (3월 2일) → 「서울에서 디자인 공부하고 싶어요」 (9월 14일)
```

🔴 두 가지가 옛 설계와 다르다. **① 「자랐어요」라고 단정하지 않는다** — 지금 코드는 두 녹음의 길이·오류를 비교하지 않고 21일만 지나면 「자랐어요」를 붙인다(`교재연동.js:43,597-640`). 나빠져도 그렇게 뜬다. **② 「내가 쓴 문장」은 진짜 학생 문장이어야 한다** — ★확인함: 지금 성장 카드는 `hw_feedback` 5번째 칸을 읽는데(`Code.js:2539` `rG[4]`), 그 칸의 헤더는 **`고친문장`**이다(`엔진_수집.js:79`). 헤더 주석이 스스로 「교정문은 모델 출력물이다」라고 적어 뒀다. 지금 「성장 전/후」는 **AI 교정문 두 개**다. 4번째 칸(`제출문`)으로 고친 뒤에만 이 자리를 쓸 수 있다.

**문턱은 끝나지 않는다.** 목록이 아니라 간격 규칙이다 — 간격이 매번 하나씩 커진다(+2, +3, +4, +5 …).

| 2 | 3 | — | 1주차 |
| 3 | 7 | — | 2주차 |
| 4 | 14 | 2 | 4주차 |
| 5 | 25 | 5 | 6~7주 |
| 6 | 41 | 9 | 10주 |

주 4일 만난다고 보면 **9개월에 9번, 그중 4번이 첫 4주 안**에 온다.

- **30 · 60 · 100을 일부러 피했다** — 그 세 수는 이미 스트릭 업적 이름이다(「한 달의 약속 / 두 달의 전설 / 100일의 기적」, `엔진_운영배치.js:4009-4013`). 겹치면 같은 날 두 번 축하한다.
- **장면 1~3은 게이트 없음** — 옛 첫 진화가 무게이트로 「3주 내 훅」을 노렸던 것과 같은 정신.
