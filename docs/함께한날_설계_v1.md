# 함께한 날 — 승인된 뜻과 현재 설계의 연결

> 2026-10-17 정리. 2026-08-26 v1.1 전체 652줄은 [보존 원문](_ops/qa/document-cleanup-20261017/_archive/pass3-originals/docs/함께한날_설계_v1.md)에 그대로 남겼다. 당시 Apps Script·Glide 구현과 08-27 배포 기록은 [2026-10-02 옛 시스템 정리](_ops/옛시스템_정리목록_20261002.md) 이전의 이력이다.

## 유지하는 사용자 결정

2026-08-26 사용자 결정은 “7단계 캐릭터는 이제 없어. 마스코트로 대체될거야”, “함께한 시간으로 가되 성장했다는 걸 느낄 수 있고 만족할 수 있고 잘 확인할 수 있게 제대로 만들어줘”였다. 기존 몬스터 7종·진화 포인트를 복구하는 근거로 이 문서를 사용하지 않는다.

- 같이한 시간과 실제로 해낸 학습은 서로 다른 사실이다. 날짜가 지났다는 이유만으로 실력이 늘었다고 단정하지 않는다.
- 결석·실패·늦은 등록·복귀를 이유로 쌓인 성장과 관계를 깎지 않는다. 남의 순위보다 본인의 이전 기록과 지금 기록을 비교한다.
- 성장 전후에는 학생이 실제로 말하거나 쓴 원문을 사용한다. AI가 고친 문장을 학생의 성취로 바꿔 보여 주지 않는다.
- 마스코트의 표시·대사와 학습 사실의 기록·판정을 분리한다. 마스코트를 끄거나 표시가 실패해도 기본 기능과 자신의 기록은 볼 수 있어야 한다.

## 보존 원문을 읽을 때

원문에는 당시 화면 시안, 장면 문턱과 간격 실험, 교사·보호자 관점, 데이터 중복 처리와 원문 정직성 검토, 15가지 실패 사례가 있다. 새 구현을 검토할 때 재사용할 수 있는 설계 근거다. 전체를 없애거나 최신 구현으로 바꿔 쓰지 않았다.

다음은 그 옛 시스템 안에서만 성립한 실행 명세다. 현재 작업 목록이나 복구 지시로 가져오지 않는다.

- 급수·태그·기여일수를 겹친 3층 게이지와 8주 상품 화면
- AE/AF 등 시트 열 번호, GRAMMAR_GATE, scene_log 및 당시 함수·파일별 변경 표
- 단계별 Apps Script 배포, 구 몬스터 ID 복원, Glide 매핑과 데이터 열 삭제 절차
- “아직 파일을 안 고쳤다”, 남은 질문, 고정 검수 절차, 정본 그림만 써서 표정을 바꿀 수 없다는 당시 제약

원문 끝의 2026-08-27 배포 기록은 당시 결과의 증거로 보존한다. 현재 앱에 같은 기능이 구현·배포됐다는 증거는 해당 앱의 코드와 검증 결과에서 확인한다.
