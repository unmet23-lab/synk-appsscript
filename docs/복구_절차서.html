노트북이 고장 나거나 도난당해도 SYNK의 일은 사라지지 않습니다. 어디에 무엇이 있고, 새 컴퓨터에서 무엇부터 하면 되는지를 순서대로 적었습니다.

왜 여기 있나  복구 절차서가 복구 대상 안에만 있으면 정작 필요할 때 못 엽니다. 그래서 이 파일은 바탕화면(OneDrive)에 실물로 둡니다.

01 결론 — 거의 다 살아 있습니다

SYNK의 코드·문서·판단 기록은 인터넷에 자동으로 복사되고 있습니다. 컴퓨터가 없어져도 계정 로그인만 되면 전부 되찾습니다.

02 새 컴퓨터에서 할 일

순서대로만 하면 됩니다. 1·2번은 유호님이 직접, 3번부터는 AI에게 이 파일을 보여주시면 됩니다.

01

Microsoft 계정으로 로그인

새 컴퓨터에서 OneDrive 앱에 로그인합니다. 바탕화면이 통째로 돌아옵니다 — 이 파일도 그때 다시 나타납니다.

시작 → OneDrive 검색 → 로그인. 동기화가 끝날 때까지 몇 분 기다립니다.

02

GitHub 계정으로 로그인

브라우저에서 github.com 접속 → unmet23-lab 계정으로 로그인. 저장소 3개가 그대로 있는지 눈으로 확인합니다.

이 계정 하나에 SYNK의 코드·문서·AI 기억이 전부 들어 있습니다.

03

개발 환경 다시 깔기

Git · Node.js · Claude Code 를 설치하고, 저장소 3개를 새 컴퓨터로 내려받습니다.

AI에게 “이 파일 보고 새 컴퓨터 세팅해줘”라고 하시면 됩니다. 명령은 AI가 압니다.

04

열쇠 다시 발급

비밀번호·API 키는 일부러 백업하지 않습니다(백업하면 그게 유출 경로가 됩니다). 03번 목록대로 다시 발급합니다.

03 복구가 아니라 재발급인 것

이건 잃어버린 게 아니라 새로 만드는 것입니다. 컴퓨터를 도난당했다면 오히려 즉시 폐기하고 새로 발급해야 합니다.

새 컴퓨터에서 다시 만들 것

  • Apps Script 배포 열쇠 .clasprc.json — clasp login 다시 실행
  • GitHub 접근 토큰 — github.com 설정에서 새로 발급
  • Supabase · AI 벤더 키 — 각 서비스 대시보드에서 재발급. 도난이면 기존 키를 먼저 폐기
  • Claude Code 로컬 설정 .claude/settings.local.json · launch.json — AI가 다시 만듭니다

04 지금 미리 해두실 일

여기가 진짜 급소입니다. 모든 백업이 계정 두 개에 걸려 있습니다 — 그 로그인을 못 하면 백업이 멀쩡해도 못 꺼냅니다.

계정 복구 수단을 컴퓨터 밖에 두기

  • Microsoft 계정(OneDrive)과 GitHub 계정(unmet23-lab)의 2단계 인증 백업 코드를 인쇄하거나 폰에 저장해 두십시오.
  • 인증 앱이 그 노트북에만 깔려 있다면, 노트북과 함께 잃습니다 — 폰에도 등록해 두십시오.
  • 복구용 이메일·전화번호가 최신인지 두 계정 다 확인하십시오.
  • 이 세 줄이 안 돼 있으면, 위의 「안전」 표시는 전부 무효입니다.

왜 이게 급소인가 — GitHub 3곳과 OneDrive는 서로 다른 백업처럼 보이지만, 실제로는 온라인 계정 두 개에 매달려 있습니다. 계정을 못 열면 네 곳이 동시에 닫힙니다. 실제로 2026-08-09에 GitHub 무료 사용량이 소진돼 자동 검사가 계정 층에서 통째로 멈춘 적이 있습니다 — 계정 하나가 여러 곳을 동시에 끊는다는 것이 이미 한 번 증명됐습니다.

05 아직 아무도 안 지키는 것

01번 표의 회색 세 줄입니다. 이건 유호님이 배치하신 파일이라 제가 마음대로 옮기지 않았습니다 — 결정만 주시면 처리합니다.

결정이 필요한 셋

  • 내 PC「문서」폴더의 낱개 파일 4개 — 투자자 요약덱(0.98MB) · 사업진단 풀리포트 · 시간표 · profiles 백업.
    권고 OneDrive「문서」로 옮기면 자동으로 지켜집니다. 용량 부담 없음(합계 1.1MB).
  • 다운로드 폴더 6.2GB — 대부분 로고·이니셜 시안 이미지입니다.
    권고 전부 옮기지 말고 쓸 것만 골라 repo나 OneDrive로. 6.2GB를 통째로 올리면 OneDrive 무료 용량(5GB)을 넘깁니다.
  • 편집 중이던 작업 — 자동 저장 장치가 이미 돌고 있지만, 컴퓨터가 갑자기 죽으면 마지막 몇 분은 사라집니다. 이건 구조상 없앨 수 없는 위험입니다.

한 가지 더 — 온라인만으로는 축이 하나입니다. GitHub도 OneDrive도 인터넷 계정입니다. 계정 정지·해킹·서비스 장애면 네 곳이 같이 막힙니다. 값싼 USB 하나에 분기마다 한 번 저장소 3개를 통째로 복사해 두면, 인터넷과 무관한 독립 축이 하나 생깁니다. 필요하시면 그것도 명령 한 줄로 되게 만들어 두겠습니다.
