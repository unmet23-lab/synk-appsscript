# 사내 메신저·Google AI 구독 검토

> 2026-09-27 대화 종료 기록. 사용자: “일단 다음에 진행해볼게 … 커밋하고 종료해줘.”

## 상태

- 이번 대화에서는 요구사항과 선택지, 공개 공식 자료의 요금·혜택을 검토했다.
- 구현, 계정 연결, 결제, 자동삭제 설정, 배포, 영상·음성 생성은 하지 않았다.
- 제품 선택·구독·예산·보관 정책은 미확정이며 실제 작업은 다음으로 미뤘다.

## 사용자 요구와 검토 방향

- 수십 명이 종일 사용하는 사내 메신저: 개인·단체 채팅, 쉬운 파일 공유, 관리자 발급 코드로 가입.
- 현재 개인 Google Drive를 사용하며 Google AI 구독의 저장 공간 활용을 검토했다.
- Supabase는 필수가 아니다. 시트+Apps Script도 가능하지만 주력 메신저에는 실시간 연결·동시 사용·재접속 복구를 지원하는 데이터베이스 구성이 더 적합하다는 제안이다.
- 자체 제작 시 로그인·대화는 Supabase 또는 Firebase/Google Cloud, 첨부파일은 앱 저장소 또는 Drive 연동이 후보이다. 최종 구성은 미정이다.
- Slack 도입도 후보로 유지한다. 기본 채팅·공유가 목적이면 운영 부담까지 비교해야 한다.

## 비용을 구분할 것

- 대화에서 제시한 월 5~10만 원은 일반적인 소규모 자체 웹앱의 인프라 예산 추정이다. 보장된 총 유지비가 아니다.
- 초기 개발·테스트, 오류 수정·장애 대응에 드는 시간, Drive 구독, 추가 파일 백업·사용량 초과는 별도이다.
- 원화 환산 예시는 1달러=1,400원 가정이며 실제 환율·세금·결제 견적이 아니다.
- Google AI 구독의 Cloud 크레딧 적용 가능성을 확인한 뒤에는 Firebase/Google Cloud의 순수 추가 지출도 함께 계산해야 한다. Supabase 구독료에 Google Cloud 크레딧을 사용할 수는 없다.

## 구독 혜택 조사 메모

다음은 2026-09-27 대화에서 확인한 공개 안내다. 사용자 계정에 실제 부여됐는지 확인하지 않았으며, 재개 시 국가·계정·요금제·혜택 활성화·결제 조건을 다시 확인한다.

| 항목 | Google AI Pro 기본형 | Google AI Ultra 약 $200 / 20x |
|---|---:|---:|
| 저장 공간 | 5TB | 30TB |
| Flow 월 크레딧 | 1,000 | 25,000 |
| Flow Music 월 크레딧 | 10,000 | 30,000 |
| Google Cloud 월 크레딧 | $10 | $100 |

- 각 크레딧은 별도 사용처·한도를 가진다. Flow 안내에는 일일 50크레딧도 있고, Flow 일일·월 지급분은 이월되지 않는다.
- 영상은 Flow의 Veo/Gemini Omni, 영상 내레이션은 Google Vids, 음성 파일 생성은 Gemini-TTS/Cloud TTS, 음악은 Flow Music이 후보이다.
- 구독 앱 사용 한도와 API 과금은 다르다. Cloud 크레딧은 혜택 활성화·결제 계정 적용 및 대상 서비스 확인이 필요하다. 초과 사용은 별도 비용이 발생할 수 있다.
- 실제 한국어 발음·연기·캐릭터 일관성·음악 품질·자동화 가능성은 이번 대화에서 검증하지 않았다.

## 30일 파일 보관안

- 대용량 첨부파일을 업로드 후 30일에 자동삭제하는 방안을 논의했으나 설정하지 않았다.
- 30TB는 월 제공 전송량이 아니라 누적 보관 한도이고 Gmail·포토와 공유된다.
- 예시: 50명×하루 5GB×30일=7.5TB. 기존 자료·영구 보관·복사본·백업은 별도 계산한다.
- Drive 휴지통도 용량을 차지한다. 업로드 30일 후 휴지통으로 옮기기만 하면 최대 30일 더 남는다.
- 구현 시 만료 표시·사전 알림·보관 예외·실패 감지와 함께 메신저가 관리하는 해당 파일만 처리한다. 개인 Drive 전체 휴지통을 비우는 방식은 사용하지 않는다.

## 다음에 이어갈 일

1. 먼저 진행할 대상이 메신저인지 영상·음성 제작인지 사용자와 정한다.
2. 실제 구독 상태와 활성화 가능한 크레딧, 예상 월 보관량·다운로드량을 확인한다.
3. 제작은 짧은 영상·한국어 음성·음악 샘플로 품질과 재시도 비용을 측정한다.
4. 메신저는 Slack과 자체 제작 총비용을 비교한 뒤 선택한다. 제작하면 권한·다중 계정 채팅·첨부파일·재접속·동시 사용을 검증한다.
