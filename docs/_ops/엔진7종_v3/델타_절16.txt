세 대가를 따로따로 통과시켜도 남는 구멍이 하나 있습니다.
「감시감 때문에 응답을 피함(③) → 자료가 비어 감(①) → 응답한 학생만 남아 동의율이 좋아 보임(②)」.
동의율의 분모 n = 맞다 + 아니다(talk 동의율 19 는 무응답을 분모에서 빼고, 동의율표()의 총학생수도 응답 행에서만 나온다 · 43·93)는 그대로 두되, 따로 둘을 «나란히» 봅니다 — **응답한 대상 / 실제 노출 대상** · **실제 노출 대상 / 전체 대상**.
응답자의 동의율이 오르면서 전체 학생의 관계가 나빠지는 일이 동시에 가능합니다. 노출을 못 재면(§6 U6 노출↔반응 연결) 「관계가 괜찮다」는 판정도 닫지 못합니다.
