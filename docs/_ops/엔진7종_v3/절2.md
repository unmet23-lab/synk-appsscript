- **운영 성능과 물리 배선은 안 재봤다.** 라이브 데이터·학생 자료·형제 저장소 `SYNK-talk`는 열지 않았다. 무도움 수행의 확인 범위, 지연 도착 사건의 순서, 교실 개입 노출, 강사 작업시간 기록, Atlas 제외 후 재생성의 실행 결과는 생산자·소비자 코드와 비식별 검증 결과가 필요하다.
- **실제로 더 낫다는 결과는 없다.** 위 추가안은 검증 설계다. 몽골어 화자 발음 성능, 모어 원인 판정, Atlas의 추가 효용, 졸업 뒤 관측 편향을 판단하려면 동의 범위 안의 평가 자료와 독립 판정이 필요하다.
