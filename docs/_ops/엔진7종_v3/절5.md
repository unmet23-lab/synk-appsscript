## 안 재봤다

- **실기기 관측 품질:** 배경 전환 직후 종료, 오프라인 재시작, `reduce-motion`, 녹음 국면, Skia 대체 렌더의 봉투 보존율과 터치→소리·진동 지연. 개발 빌드와 합성 계정으로 로컬 확정 봉투와 서버 수신을 대조해야 한다. 코드 독해로 실측값을 대신하지 않았다.

- **Patina가 비교·낙인으로 읽히는지:** 실제 컷과 시간 순서가 있는 나란히 검수가 필요하다. U3의 `patina{자리, 색온도띠, 다림질}`만으로 **다림질할 교정 카드 하나를 어떻게 지목할지도 미확정**이다. 기존 `correction_id`와 연결할 응답 규격을 확인해야 한다.

- **신설물의 실행 동작:** 원문이 제안한 `docs/_ops/룸취향.jsonl`, `tools/룸눈.js`, `tools/토큰내보내기.js`, `../SYNK-talk/tools/시즌책재료.js`는 지정 경로에 없음을 확인했다. 저장·집계·거절·재현 성능은 아직 잴 구현이 없다. 미구현 자체를 결함으로 세지는 않았다.

- **외부 도구·계정 상태:** Blender 릴리스 페이지는 이번 조회가 실패했다. 설치본·굽기 픽셀, 이미지 모델의 실제 API 생존, Meshy 무료 API·다운로드 권한, GLB 반입 후 램·접지 그림자는 실행하지 않았다. 계정 권한과 승인된 시험 자산이 필요하다. 문서의 「부품변환」을 실제로 어느 코드에 연결하는지도 확인하지 못했다.

- **룸눈의 데이터 처리 조건:** 호출료와 약관상 `Paid Services` 여부는 같은 판정이 아니다. Gemini API 약관은 호출 프로젝트의 활성 billing 연결을 기준으로 구별한다. 실제 사용할 프로젝트의 조건은 확인하지 않았다. 실학생 지면 입력 금지를 완화할 근거로 사용하지 않았다. [Gemini API 약관](https://ai.google.dev/gemini-api/terms)
