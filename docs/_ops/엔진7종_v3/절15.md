- **원문·외부 분모.** MDPI는 이번에는 HTTP 429로 열리지 않았다. 법무부 페이지의 `18542`는 전체 행 수이며, 데이터 설명상 모집단은 한국에 체류하는 D-2·D-4-1·D-4-7 외국인 유학생이다. CSV 본문을 내려받아 시점·국적별 중복과 헤더를 대조하지 않았으므로, 아직 SYNK의 모집시장 분모로 사용할 수 없다. TOPIK 공식 조회 조건과 실제 진위확인 절차도 미확인이다. [법무부 데이터 설명](https://www.data.go.kr/data/15100039/fileData.do)

- **교육 효과의 이식.** 몽골어권 한국어 학습자에서의 효과, Brier 기준선, 발음 정답지, 보상모형의 한국어 일치율은 미측정이다. Khan 원문의 `%`와 percentage-point 서술도 통일되어 있지 않아 상대·절대 변화량을 임의 환산하지 않았다.

- **읽은 파일·안 본 것.** 관련 구간을 읽은 파일은 위에 인용한 설계문·코드·마이그레이션과 `AGENTS.md`, `docs/_ops/결정.md`, `docs/_ops/검수기각.jsonl`, `docs/SYNK_철학.md`, `계약/수집_교정_계약.json`, `tools/모델정책.js`, `Code.js`, `../SYNK-talk/AGENTS.md`, `../SYNK-talk/docs/이_저장소_규약.md`, `../SYNK-talk/docs/공용지침.md`, `../SYNK-talk/계약/수집_교정_계약.json`, `../SYNK-talk/lib/이벤트검증.js`다. 전체 저장소·인용 원문 전량 검수는 수행하지 않았다.
