## 안 재봤다

- **새 설계의 물리 규격:** `engine.atlas_summary`의 DDL·열·갱신 조건, 문장 제외의 안정적 참조 규격, 디코더 예측값 저장 위치, 후보별 배정확률 기록 필드는 확인하지 못했다. 이름을 새로 만들지 않았다. 해당 계약과 생산자·소비자 명세가 필요하다. `lib/관찰선택자.js`·`lib/처방정책.js`·`lib/요약채점기.js`도 확인한 `SYNK-talk/lib` 구현 검색 범위에서는 찾지 못했다.
