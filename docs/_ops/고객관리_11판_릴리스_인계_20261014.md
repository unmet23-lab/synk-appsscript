## 5. 조심할 것

- **공용 작업본에 `apply.cjs`를 얹지 않는다.** 작업본에는 이미 11판이 있고, 다른 세션의 미커밋 수정(고객 알림)이 같은 파일에 있다.
- 꾸러미에 시험 파일 46개가 들어 있다(부모 후보에도 시험이 있고 릴리스 담당이 후보 복사본에서 전체 시험을 돌린다). 이미지 목록에는 부모 목록에 있던 시험만 들어간다(prepare가 그렇게 센다).
- CRLF: `apply.cjs`는 대상 파일 줄 끝을 따른다. 작업본 파일을 직접 고칠 땐 `sed -i` 금지, 임시 파일 → 교체.
- 포스터 webp 7장과 `client-desk.css`는 **새 파일**이라 manifest·이미지 목록 둘 다에 들어가야 한다(prepare가 넣었다). 운영 `server.mjs`에 허용 목록 줄이 없으면 배포 뒤 404가 난다 → 덧붙이기 2개가 꼭 같이 가야 한다.
- 전체 시험 241파일 중 `server-background-jobs.test.mjs`·`marin-home-client.test.mjs`는 10-13 `3a59f559e`(GPT 판)부터 깨져 있었고 `content-engine.test.mjs`는 저장소 뿌리에서 돌려야 통과한다(cwd 의존). 후보 복사본에서 돌릴 때 이런 실패가 꾸러미 탓이 아닌지 부모 복사본과 비교한다.
