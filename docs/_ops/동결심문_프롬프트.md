## 배경과 적용 범위

SYNK는 LAB의 한국어 교육, SHIFT의 1인 기업 브랜딩·강의, PULSE의 음악·영상·이야기를 만든다. 대상이 어느 사업과 기능에 속하는지 먼저 구분한다. 수집·개인화 기능은 저장→자동 소비→출력 변화→수혜자 도달까지 확인한다. 홍보·안내·알림·작품에 학생 수집을 공통 의무로 붙이지 않는다. 계약·원본·복구는 해당 업무의 실제 규격으로 검토한다.

## 검토할 관점

1. **소급 불가 누락**: 실제 자료를 받기 전에 필요한 원본·맥락·출처·기준판·계보가 계약에 있는가. 첫 실제 입력일을 개원일이라고 가정하지 않는다.
2. **수집 기능의 단절**: 저장·엔진 자동 소비·판단 또는 다음 출력의 실제 변화·수혜자 도달 중 어디가 비었는가. 문서·화면·행 수를 실제 소비와 같다고 읽지 않는다.
3. **현재 기준과의 모순**: 적용되는 철학·제품방향·계약·최신 결정과 다른가. 옛 스냅샷과 현재 규칙을 구분한다.
4. **기술 실행 가능성**: 실제 저장·마이그레이션·검증·중복 방지·동시성·오프라인 재시도가 필요한 범위에서 성립하는가.
5. **사람과 데이터의 경계**: 실제 사용 시점에 필요한 식별자·원음·외부 처리·동의·철회·공개·권한 규격과 충돌하는가. 보호 경계를 미루는 옛 기록은 현행 면제가 아니다. 실제 결함 없이 일반 경고나 새 승인 단계를 만들지 않는다.
6. **조용한 실패**: 미실행·빈 값·부분 입력·미적용이 통과·완료와 같은 모양이 되는가.
7. **목적에 맞는 규모**: 당면 흐름을 완성하는 데 필요한 구조인가. 옛 ‘코드 0’·‘늦춤’·폐기 도구를 현재 요청의 금지로 쓰지 않는다. 실제 가드·계약을 편의를 위해 제거하지 않는다.
8. **받는 사람의 경험**: LAB 학습은 재미·한국어와 목표에 대한 도움·신선함을, 홍보는 제공 가치·정확한 약속·이용 경로를, 알림은 정확성·시점·이해를, SHIFT는 자기 일에 적용할 결과를, PULSE는 감상·표현의 완결을 확인한다. 내부 기반에는 재미나 학생 참여를 억지로 요구하지 않는다.

## 출력 형식

발견마다 [P0|P1|P2] 제목 — 파일·실제 줄 또는 절·재현 입력/상황·깨지는 동작·근거를 적는다. P0는 소급 불가 데이터·인증·라이브 손상, P1은 기능 또는 책임의 중대 오류, P2는 품질 문제다. 미확인 의심은 결함 수와 나누고 확인 방법을 적는다. 대외 약속·숫자·원본 데이터 변경을 봤다면 결과를 명시한다.

더 나은 대안 구조가 있을 때만 하나 제시한다. 읽은 원문과 읽지 못한 범위를 남긴다. 지적이 없으면 ‘지적 0건’이라고 적는다. 빈 답은 통과가 아니며, 필수 원문을 읽지 못했으면 첫 줄에 ‘확인 불가’를 적는다. 한국어로 답한다.
