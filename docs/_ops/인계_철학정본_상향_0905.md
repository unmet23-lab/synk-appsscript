## 밟은 함정(이 자리에서 나는 것)
- 결정 원장의 유호 확정 문장은 지우거나 고치지 않는다 — 정정은 «병기»(근거 칸). 행번호로 지목하지 않는다(줄이 움직인다 · 날짜+낱말로).
- 「없다」와 「안 재봤다」를 섞지 않는다. 양비론 금지 — 재료가 모자라면 무엇이 필요한지 밝힌다.
- 파일은 CRLF 다 — 셸 `sed -i` 금지 · python 은 바이트로 읽고 쓴다 · 긴 한글 편집은 스크립트 «파일»로(heredoc·`printf` 가 역슬래시를 먹는다 · 09-05 두 번). 원문→고친 글 짝으로 고치는 적용기 `tools/엔진7종_델타적용.js` 는 어느 .md 에도 쓸 수 있다(원문이 정확히 한 번이어야 돈다).
- 다른 세션의 미커밋(굽기 자산 · 공방 · 심문결과)은 건드리지도 커밋하지도 않는다 · `add -A`·`commit -a` 금지 · 공용 원장(트랙·결정)은 고치는 즉시 커밋.
- 문서 레인은 메인 트리에서 짓는다(워크트리 규약 §1 · 유호님이 커밋 전에 여신다).
- 유호님께 가는 답: 한 답에 주제 하나 · 두 목록을 한 답에 넣지 않는다 · 낯선 낱말은 그 자리에 뜻 · 결론 줄엔 기술 낱말 0.
