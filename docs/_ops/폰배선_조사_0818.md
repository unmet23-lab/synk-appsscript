## 7. 독립 검증이 잡은 것 (초판 → 이 판)

컨텍스트를 안 본 검증자가 실물로 전수 재측정해 **9건**을 잡았다. 큰 것 셋:

1. **乙(ㄴ)의 대가가 통째로 틀렸다.** 초판은 「진짜 클라우드 세션 id 는 셸에서 못 읽는다」고 썼는데, `CLAUDE_CODE_REMOTE_SESSION_ID` 가 그냥 환경변수로 있다. **유호님께 올릴 선택지의 비교표가 바뀌었다** — 검증 없이 올렸으면 잘못된 재료로 결정하실 뻔했다.
2. **`claude/*` = 클라우드 라는 등식이 반례로 깨졌다.** tip author 는 움직이는 값이다. F623 이 잡은 병(실물 안 보고 전제 승계)을 같은 자리에서 반복할 뻔했다.
3. **트레일러 숫자에 기준 ref·시각이 없었다.** 초판의 `147/285/159` 는 재던 시점의 `origin/master` 값이고 10분 뒤 이미 낡았다. 게다가 「방치」로 읽었는데 실측은 **커버리지 공백**(유호 계정 31건이 전부 머지)이었다.

나머지 6건은 인용 행번호(959≠961)·열 혼동(470 vs 393)·정의 없는 숫자(「실행되는 줄」)·과잉 단정(「이 창이 죽는다」) 등이다. 전부 이 판에 반영했다.
