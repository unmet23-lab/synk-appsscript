# 엔진 8종 표기 통일 · 2026-09-21

사용자 요청: “8종 기준으로 바뀌었으니까 7종이라고 적혀 있는 거 전부 8로 바꿔줘.”

## 현재 기준

Core·Loom·Vellum·Trail·Prism·Temper·Reed·Strata, 총 8종이다. 10-02 재확인한 [현행 Atlas 정의](../../아틀라스_설계.md#atlas-engine-ownership)에 따라 Atlas는 이 여덟 엔진의 총칭이며 별도 상위 엔진·작업 하네스가 아니다. 엔진 구성 확정과 각 기능의 구현·배포·효과는 별개다. 아래 Strata 소개·산출물과 구현 상태는 09-21 표기 통일 당시의 기록이다.

## 반영

- 현재 설계 원문을 `docs/엔진8종_상향설계_v3.md`로 옮기고 제목·실제 역할표·연결 설명을 8종으로 맞췄다. 옛 경로에는 새 정본 안내만 두어 이전 기록의 로컬 링크를 보존했다.
- Atlas·Strata·Core 설계의 표기 변경 대기를 해소하고 현재 정본 링크를 통일했다. 역사 커밋을 가리키는 고정 Git URL은 당시 파일 경로를 유지했다.
- 제품 방향·기업 소개·기업 마스터·사업계획·LAB 상세·FAQ·크루 핸드북·운영 시스템의 엔진 구성과 Atlas 정의를 맞췄다. Reed를 제외한 여섯만 Atlas라는 옛 설명도 현재 구조로 바꿨다.
- Strata 소개서를 추가하고 기존 지도에 실제 여덟 번째 링크를 연결했다. 원고 8개 소개서+지도 1개를 다시 생성했다. Strata 전용 새 이미지 제작은 하지 않았고 기존 공통 재질 표지를 쓴다고 표시했다.
- 최신 독립 엔진 지도의 근거 파일명·설명·줄 위치를 갱신했다. 기존 전체 로드맵·이해대장·소개서 지면·역사 히어로/부품 시안의 안내도 원본에서 재생성했다.
- 도구·CI·계약·현재 검사에서 새 정본 경로와 총수를 맞췄다. SYNK-talk 계약 사본도 일치시켰고 SYNK-website의 내부 문서명 노출 검사에는 구·신 경로를 모두 포함했다. 홈페이지 공개 엔진 목록은 이미 8종이었다.
- 현재 운영용 `횡단.json`의 첫 엔진 결정은 새 기준으로 바꾸고 이전 내용은 `previous_record`에 남겼다.
- 바탕화면의 엔진 지도와 기존 로드맵을 갱신했다. 새 앱 로드맵은 이미 같은 내용이라 동일성을 확인했다. `바탕화면확인.json`에 각각의 해시를 기록했다.
- 상담 브로셔의 해당 단락도 원고·HTML·PDF를 같은 8종 설명으로 맞췄다. [브로셔 검증 기록](../../발표물/qa/상담브로셔_엔진8종_20260921/RESULTS.md)에 페이지 비교와 해시를 남겼다. 12쪽을 유지했고 수정된 11쪽 외의 11개 페이지는 픽셀·텍스트가 동일하다. 기존 인쇄 색상 검사 문제와 원본 HTML/PDF의 아이콘 차이는 이 기록에 분리했다. 임시 검수 폴더 정리는 자동 승인 검토에서 차단되어 보존했으며 최종 산출물에는 영향이 없다.

## 확인

- 기존 관련 5개 시험 90/90, 계약동기 시험 1/1: 총 91개 통과.
- 계약 동기 검사: 두 계약이 SYNK-talk와 일치.
- 형제 저장소 선택 검사: talk 2개, website 1개 통과.
- 소개서 9개를 오프라인 Edge 390·1440px, 총 18개 보기에서 확인. 지도에는 실제 8개 소개서 링크가 있고 로컬 링크 대상·목차·가로 넘침·브라우저 오류 검사 통과. Strata와 전체 지도는 이미지로도 확인했다.
- 최신 엔진 지도·앱 로드맵은 각 기존 검증기를 다시 실행해 320·390·1440px, 내장 자산, 검색·전환·펼치기·인쇄 상태 복원을 확인했다.
- 이해대장 재생성 후 검사 통과. 운영 홈의 엔진 경로·절 선택은 정상이지만, 기존 가이드 문서의 ‘세 친구’ 절 누락 1건은 이번 표기 변경과 별개다. 점검 당시 운영 홈 Node 프로세스는 발견되지 않았다.

## 그대로인 기록

역사 리뷰·시험 로그·고정 커밋 URL·실제 7개 파일/히어로 자산 수는 8개를 구현한 것으로 고치지 않았다. 히어로 시안에는 당시 만든 자산 7개와 현재 전체 엔진 8종이 다르다는 설명을 붙였다. 추정 메타 7종·지도 소비자 6개처럼 엔진 총수가 아닌 수치도 유지했다. 날짜가 있는 과거 체크리스트는 당시 기록임을 분명히 하고 현재 지도로 연결했다.

문서·소개 산출물·검사 참조를 통일한 작업이다. 엔진 기능 개발·DB 변경·앱 빌드·제품 배포·외부 광고 게시를 완료한 것이 아니다. 다른 작업의 미커밋 변경은 보존했다.
