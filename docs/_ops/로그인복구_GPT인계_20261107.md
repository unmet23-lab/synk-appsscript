## 지킬 것

- **비밀번호 · 인증 코드 · 「본인입니다」 · 보안 확인 · 로봇 확인은 유호님 손이다.** GPT는 그 화면을 사용자가 보고 있는 탭에 준비해 두고, 무엇을 눌러야 하는지 알린다. 사용자 탭 찾기는 위 「로그인 인계 때 REPL의 새 탭과 사용자 일반 탭을 구분한다」 절을 따른다.
- 비밀번호 · 코드 · 쿠키 · 토큰은 읽지도, 기록하지도, 커밋하지도 않는다. 이 저장소는 **공개**다. 로그인 아이디(이메일)도 저장소에 적지 않는다.
- 로그인한 뒤에는 **게시하지 않는다.** 밀린 판은 다음 14시 「오늘 편 게시」 예약 작업이 건다. 21시 스레드도 그 예약이 건다. 설정 변경 · 계정 전환 뒤 원래 계정 되돌리기를 빠뜨리지 않는다.
- 새 계정을 만들지 않는다. 이번 사용자 정정에 따라 계정 장부에 지정된 기존 계정을 고르는 로그인은 GPT가 진행한다. 새 연결·권한을 부여하는 「동의 · 허용」(OAuth)과 직접 인증 화면에서는 멈춘다.
- 인스타 계정 전환은 2단계 인증을 다시 부를 수 있다(현장 노트 「인스타 웹에서 계정을 바꿨다가 돌아오면 2단계 인증이 다시 걸린다」). 바꾸기 전에 유호님께 「코드가 필요할 수 있다」고 먼저 말한다.
