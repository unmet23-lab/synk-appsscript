## 1. 유호님이 정할 것

### ① 1기 온라인 과정을 여는가

- 코드상 일정은 11월 30일 1기, 12월 5일 첫 수업, 1월 24일까지다(`엔진_운영배치.js` 56-59행).
- 이 결정에 걸린 기능은 다음과 같다.
  - 급수 진단(`/diag/`)
  - 자율일 묶음(talk `sunday-bundle`)
  - 시즌 회고(`/retro/`)
  - 명부 스윕
  - 퀴즈 수집
  - 숙제 서클 문서
  - 토요일 숙제 펼치기
- 지금 시트판에는 학생이 볼 화면이 없다. Glide는 폐기됐고, 퀴즈·대화 폼은 만들어진 적이 없다. 그래서 1기를 열더라도 시트판을 그대로 쓸 수는 없다.
- 열지 않는데 코드를 그대로 두면 12월 5일부터 매주 토요일 「1기 반이 비어 있습니다」 경고 메일이 나간다(`엔진_자율일.js` 340-342행).
- 열지 않으면 위 기능을 모두 지운다. 연다면 학생 화면은 talk 앱으로 하고, 시트 쪽에는 명부 연결만 남긴다.

### ② 학원 운영 시스템을 어떻게 할까

- 대상: 출석·결석, 반 편성, 차시 마감폼, 강사 지표, 학부모 메일, 리포트카드, 수강 만료, 포인트 경제 등. Apps Script 코드의 대부분이 여기에 해당한다.
- 선택지
  - **가. 지금 지우고, 개원할 때 교사 앱과 talk로 다시 만든다(추천).**
  - 나. 코드는 두고 트리거만 끈다.
- '가'를 추천하는 이유
  - 10월 2일에 교사 앱 MVP를 시작했고, 학원생 연결은 「로그인 뒤 학원 코드」로 정했다(결정 09-19).
  - 시트판을 살려 둘수록 철학과 어긋나는 잔재가 따라온다. 예를 들면 순위, 포인트, 학부모 메일 서명의 「뇌과학 기반」 문구다.
  - 지운 코드는 git 기록에 그대로 남아 있어 언제든 참고할 수 있다.

### 2-5. 지우는 순서 (순서가 틀리면 배치 전체가 멈춘다)

1. 공용 부품을 먼저 옮긴다.
   - `상담AI.js`에서 웹 입구와 셀 소독을 뗀다.
   - `엔진_콘텐츠AI.js`에서 문법 뱅크를 뗀다. Strata 지도가 이 파일 전체의 해시를 고정하고 있어서, 그냥 고치면 `tests/strata.test.js`가 실패하고 지도 판번호가 바뀐다.
2. 배선을 먼저 걷는다. 아침·밤·주간·월간·10분 배치가 단계 함수를 이름으로 부르기 때문에, 함수부터 지우면 그 배치 전체가 시작 단계에서 멈춘다.
3. 아래를 함께 고친다.
   - 트리거 목록과 재설치 코드
   - 시트 메뉴
   - 시트 골격(`sheetSkeleton_`)
   - 수집 도달 장부와 `tools/lib/시트도달.js`
   - `.claspignore`, `.clasp.json`, `tests/_engine-source.js`
   - 관련 시험
4. profiles 열은 지우지 않고 값만 비운다. 열 번호로 읽는 코드가 있다.
5. 라이브 반영(clasp 배포, 트리거 재설치, 공개 구글 폼 응답 닫기)은 따로 승인을 받아서 한다.
