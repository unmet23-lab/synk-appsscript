# 까몽 잔여 결함 — 원본과 파생 단계 분리

2026-09-09. `실물/연락판목록.json`의 번호를 사용했다. 새 생성·원본 교체·승인 4K 덮어쓰기는 하지 않았다.

## 꼬리 끝

| 번호·차림 | 실제 그림 판정 | 원본 경계의 어두운 픽셀: 하 / 우 | 누끼 본체 알파>128: 하 / 우 |
|---|---|---:|---:|
| #002 털모자 | 원본부터 꼬리 끝 아래·오른쪽이 직선으로 잘림 | 302 / 41 | 304 / 45 |
| #006 펠트헤드폰 | 원본·새 1024 모두 둥근 꼬리 끝 유지. 직선 잘림 확정 아님 | 0 / 0 | 0 / 30 |
| #013 3급왕관 | 원본부터 꼬리 끝 오른쪽이 직선으로 잘림 | 0 / 257 | 0 / 260 |
| #017 첫목소리목도리 | 원본부터 꼬리 끝 오른쪽이 직선으로 잘림 | 0 / 244 | 0 / 246 |

검사 경로는 각각 `docs/Loom_자산/옷/GPT/까몽_<차림>.png` → `GPT_누끼` → `GPT_표정/까몽_<차림>_본체.png` → `GPT_표정_누끼` → `docs/Loom_자산/라디오차림/까몽/<차림>_본체.webp`다. 네 차림의 모든 단계 크기·경계 픽셀을 읽고 원본과 새 파생본을 실제로 열었다.

원본은 흰 배경 RGB라서 알파가 아니라 RGB 세 채널 최댓값<150인 어두운 꼬리 픽셀을 셌다. 표정 RGB에서도 같은 경계 수가 유지됐다. 누끼 원본과 표정 누끼의 경계 수도 각각 같다. #006의 오른쪽 알파 접촉 30픽셀만으로 잘림이라 판정하지 않았다.

새 1024는 네 차림 모두 바깥 테두리의 알파>128이 0이며, 생성 기록의 새로 잘린 픽셀도 0이다. **이는 원본 꼬리가 복원됐다는 뜻이 아니다. 이미 잘린 실루엣을 여백 안에 보존했으므로 #002·#013·#017의 직선 끝은 남는다.** 이 셋의 복원은 원본 제작 단계의 수정이 필요하며 이번 작업에서 임의로 그리지 않았다.

## 새싹 두 조합

- **#029 앞치마+한달출석새싹:** 원본에 잎 두 장이 있고 표정·누끼·1024에서도 완전히 사라지지는 않았다. 다만 잎의 상당 부분이 표정 털과 섞여 어두워지는 실제 결함이다. 원본 좌표 `[580,450,770,560)` 안 초록잎 4,907픽셀 중 4,698~4,702픽셀이 14표정에서 원본과 달랐다. 최대 RGB 차이는 표정별 135~169다.
- **#041 여름델+한달출석새싹:** 원본 좌표 `[600,610,820,720)` 안 초록잎 7,752픽셀이 14표정 모두 원본 RGB와 정확히 같았다. 표정/누끼/1024 본체도 실제로 열어 잎을 확인했다. 연락판 축소에서 흰 배지가 더 두드러진 것으로, 잎 소실 결함으로 세지 않는다. 교체하지 않았다.

초록잎 측정은 지정 영역에서 `G>R+15` 및 `G>B+15`인 원본 픽셀을 사용했다. 이는 전체 이미지의 모든 옷 품질 판정이 아니라 잎 색 변화의 재현 가능한 검사다.

## #029 수정 범위

원인은 `tools/옷표정얹기.py`의 색옷 보호가 화면의 모든 초록을 눈으로 제외하던 규칙이다. 실제 두 눈 상자와 4픽셀 표본 오차 안의 초록만 홍채로 취급하도록 좁혔다. 기존 채도 기준과 안경 보호 방식은 유지했다. `--출력`은 승인 표정을 덮지 않는 별도 결과 폴더를 지원한다.

현 생성기로 표정 전체를 재계산하면 과거 승인본과 잎 바깥에도 재현 차이가 있고 얼굴 오른쪽 마스크 경계가 보여 그 전체 재계산판은 채택하지 않는다. 같은 맞춤값·창 기록만으로 승인 그림을 재현했다고 볼 수 없다. 라디오용 후보는 **기존 승인 표정의 눈·몸·알파를 유지하고 새로 보호할 잎 영역만 의상 원본 RGB로 되돌리는 보존형**이다. 잎은 원본 색 100%로, 바로 주위는 2픽셀의 부드러운 경계로 이어 흰 배지 일부에 단단한 이음매가 생기지 않게 했다. `새싹보존후보/GPT_표정`은 전체 재계산 비교용이며 채택 입력이 아니다. 실제 입력은 `새싹보존후보/GPT_표정_누끼`다.

최종 픽셀 검사와 원본 SHA-256 보존 결과는 `새싹후보검사.json`, 반복 실행 코드는 `새싹후보검사.py`, 전후 실물은 `새싹보존후보/새싹_전후확대.png`와 `까몽_전체전후.png`를 참조한다. 잘린 꼬리 원본과 흰 바탕 누끼의 가장자리 테는 별개 미해결 항목이며, 새싹 수정으로 해결됐다고 세지 않는다.

최종 후보 14컷은 모두 1290×1219 RGBA이며 서로 다른 표정 14개를 유지한다. 잎 4,907픽셀의 원본 RGB 차이 0, 새싹 영역 밖 RGBA 차이 0, 전체 알파 차이 0, 읽은 원본·승인 파일 132개 SHA-256 불변을 확인했다. #041·안경·안경+여름델의 14표정 공통 마스크는 수정 전후 전체 픽셀이 같았다. 새 초록 보호 회귀시험 6개와 기존 알파 보존 시험 5개가 모두 통과했다. 두 전후 실물도 수치 검사 뒤 직접 다시 열어 확인했다.

최종 본체 후보 SHA-256: `7186fa6a684abb89316a4af4ff3b8c13338c83cbdef06474f0fc6374305873ca`. 이 최종 RGBA 폴더만 라디오 담당에게 전달했으며, 라디오 1024 반영·브라우저 검사는 별도 담당의 실제 결과로 확인한다.
