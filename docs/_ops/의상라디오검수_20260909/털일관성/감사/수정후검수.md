# 털 고정 최종 후보 독립 검수

대표 차림 `여름델+전설의팻말`의 이번 수정은 **기술 검사와 실제 그림 비교에서 통과**했다. 다른 128차림의 털까지 고쳐졌다는 뜻은 아니다. 제작 코드를 수정하거나 생성 API를 호출하지 않았다.

- 후보 RGBA 버전: `f3ff384ff4523407` — 1290×1219, 8표정.
- 활성 라디오 버전: `65f92a753bb5416b` — 1024×1024 RGBA WebP, 8표정.
- 검사 코드/결과: `수정후검수.py`, `수정후검수.json`. 제작기의 `build`나 `derive` 결과를 다시 호출하지 않고 마스크·이동·눈 복구·축소를 독립 재구성했다.

## 확인한 사실

1. **넓은 얼굴 창이 아니라 실제 두 눈 윤곽만 변화한다.** 열린 눈의 명시 타원, 닫힌 눈 연결 초록과 1픽셀 경계를 재구성했다. 정렬 뒤 8표정 합집합은 37,088/1,572,510픽셀(2.3585%)이다. 이 영역 밖은 8표정 모두 RGBA 차이 0이다. 각 표정의 자기 눈 밖도 공통 털바탕과 완전히 같다.
2. **이마·미간·양 볼·코 자리 고정.** 따로 지정한 다섯 영역은 모든 표정에서 기존 기본 원본 RGBA와 같다. 원래 보이던 넓은 털 결 교체와 회색 코 유입을 실제 전후 8표정 연락판에서도 확인해 제거됐다고 판정했다.
3. **닫힌 눈 잔상 없음.** 눈감음·눈웃음·집중·안도에서 기존 열린 눈 자리 중 새 눈꺼풀 밖의 초록 잔상은 0픽셀이다. 해당 영역은 공통 털바탕과 같으며, 최종 눈감음 1024 그림에서도 초록 원형이나 검정 동공 잔상은 보이지 않는다.
4. **궁금함·응원의 열린 눈 보존.** 안쪽 경계 혼합을 제외한 동공은 원본 RGB와 완전히 같다. 궁금함의 어두운 동공 검사 픽셀은 좌 2,504/우 5,507, 응원은 좌 3,395/우 4,338이다. 응원 오른쪽은 동일 표정 4K 정본에서 기존 등록값으로 복구한 RGB와 일치한다. 좌우 복제나 새 생성이 아니다. 최종 1024 궁금함·응원을 직접 열어 검정 눈과 오른눈 외곽을 확인했다.
5. **원본·기본 파생본의 구분.** 원본 표정 8개는 이전 독립 감사의 SHA-256과 그대로 같았다. 추가 참조 3개는 의상 원본 1개와 4K 정본 2개이며 기록 지문과 같다. 다만 파생 기본 표정은 공통 눈바탕 사용 때문에 눈가 12,772픽셀이 달라졌다. 이 차이는 기존 두 눈의 작은 수리 영역 안에만 있고, 그 밖 RGBA와 전체 알파는 원래 기본과 같다. 정본 그림 파일을 바꾸지 않았다.
6. **최종 WebP 인코딩 손실 0.** 8개의 후보 PNG를 독립적으로 한 번 Lanczos 축소·빈 판 복사한 기대 RGBA와 최종 WebP를 다시 읽은 RGBA가 모든 픽셀에서 같다. 확대·축소 자체가 무손실이라는 뜻은 아니다. 실제 눈 마스크를 1024 좌표로 옮기고 Lanczos 반경 3 및 원본 1픽셀 표본 여유를 적용한 유한 지원 영역은 17,800픽셀이다. 그 밖은 8표정 모두 RGBA 차이 0, 전체 알파 차이 0이다. 새 파일들의 프레임 알파>128 접촉도 0이다.

## 다른 차림과 새싹 보존

다른 128차림은 현재 개별 기록 JSON이 목록의 출처와 같은지 확인하고, 기록된 입력·출력 SHA-256을 실제 1,024표정 파일과 전부 대조했다. 모두 일치했다. 검수 실행 중 개별 기록 파일도 바뀌지 않았다.

이전 128개 JSON의 바이트 지문 목록은 확보하지 않았으므로, 이번 털 수정 전후 기록 파일 자체의 역사적 불변까지 소급 인증하지는 않는다. 이 검사를 다른 128차림의 시각 합격이나 털 수정 완료로 셀 수 없다.

#029 새싹 보존 후보 14장은 이전 `새싹후보검사.json`의 SHA-256과 모두 같다. 활성 라디오 버전은 `84c41912778b469f`로 유지되며, 해당 8파일의 입력·출력 지문도 위 개별 기록 검사에서 일치했다.

## 시각 판정과 남은 경계

`표정8개_전후.png` 전체와 최종 라디오 눈감음·궁금함·응원 1024 실물을 직접 열었다. 털바탕은 안정되고 기존에 지적한 잔상·검정 눈 누락·오른눈 잘림은 보이지 않는다. synk-design 기준에 따라 같은 크기 비교와 수치 판정을 분리했다.

흰 누끼 테 등 다른 자산 결함, 다른 차림·캐릭터의 자연스러움은 이번 합격 범위가 아니다. 실제 브라우저의 전환·순환·자연 복귀는 주담당의 실사용 검사 결과와 합쳐 판단한다.
