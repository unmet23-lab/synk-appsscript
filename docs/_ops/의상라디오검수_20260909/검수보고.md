# 세 캐릭터 라디오 착용 검수

2026-09-09 · **검수와 코드 수정은 진행했지만, 세 캐릭터 전체 자유 착용의 방송 채택은 보류한다.** 원본에서 이미 잘린 부분과 몽글·마린의 미제작 통합 차림이 남았다. 로컬 실행 증거이며 송출 서버의 반영 보고가 아니다.

후속 교정: 사용자가 지적한 표정 전환의 얼굴 털 변화는 기존 눈 창 밖 검사로 놓친 실제 결함이었다. 현재 검수 화면의 까몽 `여름 델 + 전설의 팻말` 8표정은 공통 털 바탕과 개별 눈 윤곽 방식으로 수정했다. **다른 차림 전체의 털 고정 합격은 아니다.** [털 일관성 수정보고](털일관성/수정보고.md).

## 먼저 확인한 결론

의상 그림 재고가 많아도 세 캐릭터의 자유 착용이 구현된 상태는 아니었다. 기존 라디오는 까몽 `여름 델 + 전설의 팻말` 8컷을 고정 사용했다. 몽글·마린은 기존 옷 조각이 있지만, 의상 1벌 + 악세 1개를 함께 입은 통합 표정 세트는 없다.

| 캐릭터 | 의상 × 악세의 정확한 짝 | 단품 포함 차림 | 기존 통합 표정 AVIF | 이번 확인 |
|---|---:|---:|---:|---|
| 까몽 | 9 × 12 = 108 | 129 | 1,806 / 1,806 | 129차림 × 라디오 8표정 = 1,032개 별도 후보. 108짝의 864표정 실제 브라우저 표시 검사 |
| 몽글 | 10 × 12 = 120 | 142 | 0 / 2,130 | 기존 조각 120짝 정적 시각 검사. 후드 눈 가림·한복/모자 잘림 확인 |
| 마린 | 9 × 12 = 108 | 129 | 0 / 1,806 | 기존 조각 108짝 정적 시각 검사. 목도리 렌즈 가림·인사 때 헤드폰 불일치 확인 |

몽글의 단품 GPT 원본 15장은 존재한다. 완성 표정 세트 15벌이라는 뜻이 아니다. 까몽은 시험 4차림도 보존돼 실제 과거 가공본은 133차림 × 14표정 = 1,862장이다. 공식 1+1 선택 재고와 혼합하지 않았다. 전체 이미지 8,350장의 메타데이터 읽기 오류 0은 자연스러움 합격 수가 아니다.

알파 결함 재현: RGBA `(200,100,50,128)`이 `(100,50,25,64)`로 바뀌던 계산을 수정했다. 대표 까몽 2장에서 완전 불투명 픽셀 변화 0, 반투명 경계만 회복했다. **흰 배경을 제거한 털의 흰 잔색은 이 수정만으로 없어지지 않았다.**

새싹은 축소판에서 소실을 의심했으나 확대 대조로 정정했다. #041 여름 델+새싹은 잎이 보존돼 수정 대상이 아니다. #029 앞치마+새싹만 부분 어두워짐이 확인됐다. 전체 표정 재계산은 과거 승인 눈·털과 달라져 채택하지 않고 잎 영역만 복원하는 별도 후보를 사용한다. 수치·원본 불변 여부는 [새싹 검사](자산/새싹후보검사.json)에 기록한다.

최종 #029 후보는 14표정 모두 초록잎 4,907픽셀이 원본 RGB와 같고, 새싹 영역 밖 RGBA 및 전체 알파의 변화는 0이다. 원본·승인 파일 132개 SHA-256 불변을 확인했다. 잎 주변 2픽셀 경계를 부드럽게 이어 배지에 생기던 이음매도 다시 실물 확인했다. 독립 검토자도 후보 14개를 직접 읽어 잎·영역 밖·알파·SHA를 대조했다.

864상태는 실제 Chromium의 DOM·로드 이미지·표시 속성을 검사한 수다. **모든 픽셀을 눈으로 864번 합격시켰다는 뜻은 아니다.** 동작은 `여름 델 + 전설의 팻말`의 인사·정답·체크인·투표에서 0.1초마다 24시점씩 읽었다. 모음에는 앞 12시점이 들어 있다. 모든 차림의 모든 동작·각도·기기·방송을 전수 검사한 것은 아니다.

파생본 1,032개는 저장 후 다시 열어 RGBA·알파 인코딩 차이 0, 새 불투명 화소 잘림 0, 완전히 같은 표정쌍 0을 확인했다. 표정마다 동일 눈 등록값을 쓴다. 기존 눈 창 기록이 있는 92차림은 창 밖 알파 차이 0, 최대 RGB 채널 차이 2/255였다. 기록 없는 37차림은 같은 비교 미검사다. 과거 창 기록에 당시 입력 지문이 없어 원본 동일성 인증으로 사용하지 않았다.

마린 인사는 고개를 숙이는 별도 정본이다. 하단 영역의 36.95%가 채널차 12를 넘지만 자세 변화까지 포함하므로 이를 실패율로 부르지 않는다. 헤드폰이 정면 위치에 남는 문제는 실물에서 별도로 확인했다.

## 남은 결함 — 전체 완료를 막는 것

1. **몽글 120짝·마린 108짝 통합 착용 그림과 표정 경로가 없다.** 기존 눈 정렬도 까몽 초록 눈 전용이다. 색 찾기 하나만 바꿔 두 캐릭터의 몸·옷 보호까지 해결됐다고 말할 수 없다.
2. 몽글 후드는 오른눈을, 마린 목도리는 렌즈 하단을 가린다. 몽글 모자류·한복과 마린 왕관·겨울 델은 4K 입력 자체에서 잘린다. [품목·조합별 판정](기존층/시각판정.md)에 반복 범위와 끝줄 수치를 기록했다.
3. 까몽 털모자·SYNK 후드·3급 왕관·첫 목소리 목도리의 **원본 꼬리 절단선**이 남는다. 펠트 헤드폰은 확대 확인 결과 정상으로 정정했다. 새 파생 잘림 0을 원본 복원으로 해석하지 않는다. [원본 대조](실물/원본꼬리확인.json), [꼬리·새싹 단계별 판정](자산/까몽잔여결함.md).
4. 어두운 배경의 흰 털 테, 저해상도 원본의 일부 눈 잔상은 별도 보정·재제작과 사용 크기 시각 검사가 필요하다.
5. 실제 송출·OBS·시청자 기기의 화질과 장시간 메모리는 미검증이다.

새 의상은 **GPT Image 2.5 Sunburst만** 사용한다. 현재 일반 이미지 도구는 모델 선택을 노출하지 않아 2.5라고 추정해 호출하지 않았다. 로컬 모델 고정 스크립트는 종량제 API이며 구독 포함량과 다르다. 2.5 계정 접근·구독 포함 생성 통로·신규 지출을 확인 또는 승인받은 것으로 취급하지 않았다. 누락 228짝을 다른 모델이나 새 유료 대량 호출로 채우지 않았다.

## 원본·화질·다른 작업의 경계

승인 4K 몸과 기존 의상 PNG/AVIF는 보존했다. 새 1024 WebP는 `docs/Loom_자산/라디오차림/`의 **별도 검수후보**다. lossless는 축소된 RGBA를 WebP로 저장·복원할 때 동일하다는 뜻이며, 4K→1024 축소 자체가 무손실이라는 뜻은 아니다. 1254·2560픽셀 그림을 4K 틀에 담았다고 새 디테일이 생기지도 않는다.

`bots/오버레이/겹쳐송출.js`는 1920×1080 지면을 2/3로 캡처하고 1280×720 H.264/YUV420·2.5Mbps로 재압축한다. 원본 보존과 송출 무손실은 다른 주장이다. 실제 서버 설정·시청 화면은 이 작업에서 확인하지 않았다.

별도 「까몽이 옷 굽기 확인」 작업이 같은 로컬 HTML에 유휴 표정 리듬을 추가했다. 이 작업은 그 변경을 보존하고 결합 검사했다. 새 리듬의 라이브 반영·음악·배경 교체는 그 작업 범위이며 **이 차림 후보의 라이브 배포를 뜻하지 않는다.** 공개 GitHub 업로드·앱 배포·방송 재시작은 이 작업에서 하지 않았다.

## 실행 증거와 재현

관련 자동 시험은 **57개 통과**(Node 31 + 알파 5 + 파생 자산 15 + 초록 보호 6). 후보 저장 중 두 번째 인코딩 실패, 마지막 목록 게시 실패, 정상 게시도 실제 임시 파일로 재현했다. JS 구문·Python 컴파일 검사와 검수 화면의 로컬 링크 39개 검사도 통과했다. 저장소 전체 CI나 방송 QA를 통과했다는 뜻은 아니다.

최종 전량 브라우저 검사도 수정 #029를 포함해 **108짝·864표정·96동작 시점·오류 0**으로 통과했다. 새싹 8컷은 완성된 별도 버전 경로로 목록에 연결했다. 활성 파일 1,032개, 디스크에는 이전 #029 8개를 보존해 총 1,040개다. 기존 1,032 WebP·다른 128차림 기록·승인 #029 PNG 14컷은 그대로이며 #029 기록만 갱신됐다. 이 보존은 미완성을 승인했다는 뜻이 아니다.
