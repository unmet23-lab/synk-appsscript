# 기존 라디오 의상층: 독립 시각 판정

2026-09-09. **이 기존 레이어 묶음을 그대로 ‘자유 조합·모든 표정이 자연스러운 완성품’으로 채택할 수 없다.** 아래는 실물에서 재현한 문제다. GPT 통합 차림의 판정과 혼합하지 않는다.

## 실제 연 범위

모든 시트를 원본 해상도로 열어 보았다. 몽글 `짝_01`~`짝_08`의 **120짝 전부**, 마린 `짝_01`~`짝_07`의 **108짝 전부**, 그리고 후드+헤드폰 표정 시트의 몽글 **8컷**, 마린 **9컷**이다. 합계 17개 PNG, 228개 정적 조합과 대표 차림 17개 표정이다.

시트는 각 캐릭터를 320×320 타일에 그린 정적 진단이다. 모든 조합의 모든 표정·동작·OBS 송출·고배율 화면을 전수 검사한 것은 아니다. 시트 전부를 실제로 읽었지만, 작은 얼룩의 픽셀별 원인까지 모든 칸에서 확정한 것도 아니다.

번호는 `tools/라디오기존층검수.cjs`의 의상 목록 바깥 반복 × 악세 목록 안쪽 반복, 의상 하나당 12짝이다. 이번 원본 해상도 열람에서는 판정에 쓴 번호와 캡션을 확인할 수 있었다. 비슷해 보인다는 이유만으로 의상 이름을 추정하지 않았다.

마린 후드+헤드폰의 **정면 표정 8컷**은 본체·눈감음·눈웃음·궁금함·집중·안도·응원·놀람의 렌즈 변화가 각각 읽힌다. 이 정적 비교에서 후드나 헤드폰이 크게 튀어 옮겨가는 것은 보이지 않는다. 그러나 인사는 다른 자세이며, 이 정적 비교를 연속 움직임이나 매끄러운 전환의 합격으로 바꾸지 않는다.

마린의 나머지 정적 조합 다수는 작은 몸과 악세의 부착 관계가 읽히고 양쪽 렌즈도 보였다. 목도리·겨울 델·왕관 결함을 제외한 ‘모든 조합의 모든 표정 합격’은 아직 확인 범위가 아니다.

## 잘림은 시트만의 문제가 아님: 입력 끝줄 확인

시트의 잘림이 단순 배치 문제인지 구분하려고, 해당 레이어의 원본 4096 PNG와 라디오용 1024 WebP의 맨 윗줄/아랫줄 알파를 읽었다. 아래 값은 알파 128 초과 화소 수다. 시트뿐 아니라 **입력 레이어 자체의 가장자리에 불투명한 옷이 이어져 있다.** 따라서 화면에 여백만 더 주는 것으로 원본에서 없어진 부분을 복구했다고 할 수 없다.

## 판정과 범위

1. **몽글 후드, 마린 목도리의 얼굴 가림은 현재 확정 결함**이다. 표정 상태를 선택할 수 있다는 사실만으로 감정 표현이 구현됐다고 할 수 없다.
2. **몽글 모자류·한복과 마린 왕관·겨울 델은 원본 레이어 잘림까지 확인했다.** 자동 위치 조정이나 여백 추가로 빠진 원래 모양을 복구했다고 보고하면 안 된다.
3. **레이어를 함께 움직이는 것과 자연스럽게 착용되는 것은 다르다.** 고정된 얼굴 가림·조각 결손은 함께 움직여도 그대로 남는다.
4. 이 결과는 기존 레이어 재사용의 문제 위치를 가리킨다. GPT 통합 차림을 새로 생성하거나 기존 만족한 의상을 교체하라는 승인이 아니며, 어떤 새 모델도 호출하지 않았다.

코드·원본 수정, 새 이미지 생성, API 호출, 커밋, 배포는 하지 않았다. 이 Markdown 판정만 추가했다. 기존 브랜드 자산을 보존하면서 실제 사용 크기로 확인하고, 기술 수치와 시각 합격을 분리하는 SYNK 디자인 기준을 적용했다.
