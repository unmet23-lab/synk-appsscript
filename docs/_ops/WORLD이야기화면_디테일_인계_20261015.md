## 4. 시안 마무리(남은 손)

1. **글꼴 넣기** → 결과 `story-detail.html`. `/*FONTS*/` 자리에 @font-face를 data URI로(아티팩트는 Google Fonts 말고는 글꼴 주소를 못 쓴다). 「World SUIT」는 `experiences/brand-opening/assets/SUIT.woff2`(624KB 가변)를 src 파일에 쓰인 글자 + `U+0020-007E,U+00A0-00FF,U+2010-2027,U+2190-2199`로 자른다(fontTools 4.63 · brotli 있음: `pyftsubset … --text-file=chars.txt --unicodes=… --flavor=woff2 --layout-features='*'`, 가변 축 유지). 「World Latin」은 `SYNKLatin-{Regular,SemiBold,Bold}.woff2`를 `world-ui.css` 12–14행의 굵기 범위·unicode-range 그대로, 「World Mono」는 `assets/home/DMMono.woff2`. 함렛·고운바탕은 이미 Google Fonts 링크가 있다. `<title>`은 파일 첫 8KB 안에 있어야 하니 글꼴 블록은 맨 끝 그대로 둔다.
2. **소리 세기 맞추기(귀 대신 숫자).** 헤드리스로 열어 `await window.__soundLevels()` → `old:*`·`felt:*`·`blip:*`·`key`·`pencil`의 `peakDb`·`rmsDb`. 펠트가 지금 소리와 RMS ±3dB 안, 최고 −6dBFS 밑이 되게 `FELT`·`VOICE`·`keyTick`·`pencil` 게인을 고친다. playwright는 `C:/Users/q1212/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright`, `chromium.launch({channel:'msedge'})`(예: `.tmp/world-firstrun-20261014/live-story.cjs` 머리).
3. **한 번 보기**(390 폭·PC): 콘솔 오류·넘침·글꼴·이름표 자리·글자 나타나기·형광펜·표현 도움 창(B안 0.2초/0.16초).
