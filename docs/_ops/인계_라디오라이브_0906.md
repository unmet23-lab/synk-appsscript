## 3. 마스코트 인사 — 두 판을 어떻게 만들었나

### 판1 · 컷을 통째로 굽기 (동작 ✅ · 옷 ❌)

- 판 55 `마린_인사1`(15도 숙임) · 판 56 `마린_인사2`(30도 숙임). 4K 두 장 = 672원.
- 결과물 `docs/캐릭터/정본_4K_후보/마린_인사{1,2}.png` 와 `_누끼.png`.
- 흰 배경 걷기 = `python tools/흰배경걷기.py <파일> --흰바닥 254 --임계 50 --조각몫 0`
  🔴 마린 몸이 **크림색**이라 기본값으로 걷으면 몸이 벌집처럼 뚫린다. 위 처방을 반드시 쓴다.
- 틀 맞추기 = `python tools/마스코트틀맞추기.py <폴더> --낼곳 <폴더>` (배율 차 1.4%까지 좁혀졌다)
- 🔴 **결함** — 모델이 몸까지 새로 그려서 **가방 끈 방향·가방 크기·꽃 자리·팔 모양이 컷마다 갈렸다.**
  유호님이 눈으로 바로 잡아내셨다(「인사할때 마스코트 의상이 변하는게 보여」).

### 판2 · 헬멧만 기울이기 (옷 ✅ · 동작 ❌)
- 도구 `tools/마스코트고개숙이기.py` — 어두운 남색 덩어리를 헬멧으로 잡아 떼고, 목 자리를 축으로 돌린다.
  `python tools/마스코트고개숙이기.py <정본.png> <낼곳.png> --각도 13 --내림 0.016 --누름 0.975`
- 🔴 **결함 둘** — ⓐ 「까딱」(옆으로 갸웃)으로 보인다. 평면을 돌리는 것이라 숙일 때 정수리가 안 나온다.
  ⓑ **헬멧을 지운 자리를 회전본이 다 못 덮어 뒷배경이 비친다**(유호님 지적). `--넓힘 25` 로 지우고
  `--키움 1.012` 로 덮는데, 각도가 커질수록 모자란다.

## 5. 밟으면 다치는 것 (전부 09-06 실측)

1. 🔴 **`--default-background-color=00000000` 을 크로미움 «시작 옵션»으로 주면 브라우저가 통째로 굳는다.**
   붙자마자 `Page.enable` 조차 답이 없다. 투명 바탕은 붙은 «뒤» CDP 로 건다(90ms 에 답이 온다).
2. 🔴 **층이 아무것도 안 그리면 새 그림이 안 만들어져 그림 뜨기가 영영 멈춘다.**
   그래서 `방송층.html` 에 보이지 않는 1픽셀 맥박이 있다. **지우지 말 것.**
3. 🔴 **층의 시각을 벽시계에 맡기면 인사가 엉뚱한 때에 뜬다.** 초당 장수를 못 박아 흘려보낸다
   (못 뜬 순간은 직전 장을 다시 쓴다).
4. 🔴 **끝난 방송 자리는 되살릴 수 없다.** 유호님이 켰다 끄시면 새 자리를 만들어야 하고 **주소가 바뀐다.**
   새로 만들 때 = 만들고 → 스트림에 bind → `transition?broadcastStatus=testing`.
5. 🔴 **이 저장소는 `Bash(*sudo *)` 가 금지다**(`.claude/settings.local.json` deny). 서버 관리자 명령이
   필요하면 유호님께 「열어」를 받고, 끝나면 **되돌린다.** 오늘 두 번 열고 두 번 닫았다.
6. 🔴 `pkill -f <말>` 은 **자기 명령줄에도 걸려** ssh 세션째 죽는다. 포트로 죽인다(`fuser -k -n tcp <포트>`).
7. 🔴 서버 프로세스 목록에 **방송 열쇠가 그대로 보인다**(memory `radio-stream-key-in-ps`). `ps` 를 찍을 때
   `sed -E 's#(live2/)[A-Za-z0-9_-]+#\1****#g'` 를 붙인다. 오늘 한 번 새어서 열쇠를 갈았다.
8. 🔴 흰 배경 걷기의 크림 처방(§3 판1)을 빼먹으면 몸이 뚫린다.
