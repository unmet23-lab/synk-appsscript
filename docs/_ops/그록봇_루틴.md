# 그록봇 루틴

2026년 11월 14일에 시작했다. 유호님이 그록봇을 적극적으로 쓰고 싶다고 하셨고, Claude가 낸 방안에 「지금 알려준 방안들 다 좋다」고 하셨다.

그록봇은 xAI의 Grok Bot이다. 11월 2일에 1.0 정식판이 나왔다. 봇은 클라우드 컴퓨터에서 돌기 때문에 이 PC가 꺼져 있어도 일이 돈다. 계정은 unmet23(그록 Ultra)이다. 공식 문서는 [docs.x.ai/grok-bot](https://docs.x.ai/grok-bot/overview)에 있다.

봇은 grok.com 웹의 「봇」 칸에서 만들고 다룬다. 윈도우 앱은 설치하지 않았다. Claude는 ego의 「유호」 프로필로 grok.com에 unmet23 구글 로그인을 하고 봇과 대화해서 루틴을 건다. 유호님이 먼저 만들어 두신 봇(맹꽁이, 세팅봇, 삼식이, 강감찬, 핑핑이 등)의 대화와 루틴은 건드리지 않았다. 다만 11-15 0시에 유호님이 고르셔서 기본 봇을 맹꽁이에서 SYNK 비서로 바꿨다(아래 [Proactive](#proactive)).

11-14 밤에 1.0의 새 기능 여섯과 Proactive를 더했다. 무엇을 어떻게 걸었는지는 아래 [1.0 기능](#grokbot-1-0-features)에 있다.

## 맡기는 일과 맡기지 않는 일

그록봇에게는 공개 웹과 X를 읽고 보고하는 일만 맡긴다.

다음 일은 맡기지 않는다.

- 코딩, push, 배포. 11월 11일에 정한 「그록봇에게는 잡일만, 우리 코딩에는 손대지 않게」를 그대로 지킨다. 11월 눈가림 시험에서 그록은 GPT보다 결함을 덜 잡았다.
- 영상과 그림 제작. 저장소가 무겁고, 그록봇 컴퓨터는 직접 설치한 패키지를 보존하지 않는다.
- 여러 구글 계정으로 하는 작업과 SNS 게시. 클라우드 IP에서 로그인하면 보안 확인이 자주 뜨고 계정이 막힐 수 있다.
- 비밀값, 학생 정보, 손님 정보가 닿는 일. 문서에 따르면 봇끼리 컴퓨터를 같이 쓰고 그 사이에 보안 경계가 없다.

## 봇과 결과를 두는 곳

봇은 셋이다. 세 봇은 클라우드 컴퓨터 하나를 같이 쓴다.

| 봇 | 주소 | 맡은 루틴 |
|---|---|---|
| SYNK 조사 | https://grok.com/bot/7e69e5e0-81c5-4342-b64f-821bc30de6d1 | 1, 2, 5, 9, 11, 12 |
| SYNK 감시 | https://grok.com/bot/f80e96f8-2762-4e07-85ed-b80172518a22 | 3, 4, 7, 8, 10 |
| SYNK 비서 | https://grok.com/bot/8209a392-c976-4959-b665-59e712d482b6 | 6, 13 |

SYNK 비서는 11-15부터 이 계정의 기본 봇이다. 봇 메일 주소는 계정에 하나뿐이고 `unmet23-y86qbm@mail.grokbot.com`이다.

결과는 봇 컴퓨터의 `/workspace/synk-reports/` 폴더에 루틴마다 파일 하나로 쌓는다. 회차마다 파일 맨 위에 날짜와 시각 절을 더하고, 같은 내용을 봇 대화에도 짧게 남긴다. 처음에는 구글 문서에 쌓으려 했다. 그러면 구글 문서 연결 동의가 하나 더 들고, 문서 쓰기마다 승인 카드가 뜰 수 있다. 봇들이 컴퓨터를 같이 쓰니 파일로도 서로의 결과를 읽을 수 있어서 파일로 바꿨다. 유호님과 Claude는 봇 대화에서 결과를 본다.

루틴은 모두 승인 없이 끝나게 짠다. 루틴이 띄운 승인 카드는 30분 뒤 사라지고, 그러면 그 회차는 실패한다.

루틴 시각은 정각이 아니라 정한 시각 앞뒤 15분 안에서 시작한다(그록봇이 그렇게 잡는다).

## 모든 요청문 앞에 붙는 공통 지침

```
너는 SYNK의 잡일 담당이다. 읽고 보고만 한다.
어떤 사이트에도 글, 댓글, 가입, 결제, 보내기를 하지 않는다. 설정도 바꾸지 않는다.
로그인 창, 보안 확인, CAPTCHA가 뜨면 그 자리는 건너뛰고 「로그인 필요」라고 적는다. 돌아가는 길을 찾지 않는다.
출처 링크가 없는 내용은 쓰지 않는다. 열지 못한 곳은 「못 봄」이라고 적는다.
쉬운 한국어 문장으로 쓴다. 한 줄에 한 가지만 쓴다. 내부 번호나 파일 이름은 옮기지 않는다.
결과는 루틴마다 정한 파일 맨 위에 「YYYY-MM-DD HH:mm (한국 시각)」 절로 더한다. 파일은 이 컴퓨터의 /workspace/synk-reports/ 폴더에 둔다. 같은 내용을 대화에도 짧게 남긴다.
사람의 승인이 필요한 동작은 하지 않는다. 승인이 필요하면 그 동작을 건너뛰고 「승인 필요로 건너뜀」이라고 적는다.
시간은 모두 한국 시각(Asia/Seoul) 기준이다.
```

봇마다 첫 메시지로 이 지침을 보냈고, 루틴은 그다음 메시지에서 하나씩 만들었다.

### 2. 공모전과 지원사업

```
할 일: 지난 7일 동안 새로 올라온 공모전과 지원사업 공고를 모아 1차로 거른다.

볼 곳은 링커리어, 위비티, 콘테스트코리아, 씽유, K-Startup이다. 문화체육관광부, 과학기술정보통신부, 중소벤처기업부, 행정안전부, 법무부, 한국콘텐츠진흥원, 서울시, 전라북도의 공고 게시판도 본다.

고르는 기준은 상금보다 경력이다. 상금이 없어도 넣고, 상품권 이벤트만 뺀다. 상장 명의가 장관급, 광역 지자체, 공공기관장인 것을 기초 지자체나 협회보다 앞에 둔다. 공공 상영, 전시, 방송, 출판, 강사 인력풀 위촉이 걸린 것도 앞에 둔다.

공고를 사업 갈래로 나눈다.
- PULSE: 광고, 영상, IP(광고제, 영화제, 미디어파사드)
- SHIFT: AI 강사, AI 활용 공모
- LAB: 한국어, 교육 게임
- PATH: 외국인 정착 정책

영상 공모는 원문에서 AI 생성물 허용 조항과 직접 촬영 요구 조항을 찾아 그대로 옮긴다. 조항이 없으면 「조항 없음」이라고 적는다.
지원 자격(개인 지원 가능 여부, 사업자 요구, 지역 제한)은 원문대로 적기만 하고 판정하지 않는다.

공고마다 이름, 주최, 갈래, 마감일, 상장 명의, AI 조항, 지원 자격, 링크, 1차 판단을 적는다. 1차 판단은 「넣음」, 「뺌」, 「확인 필요」 가운데 하나와 까닭 한 줄이다.
결과 파일 위쪽에 「이번 주와 다음 주 마감」 목록을 따로 둔다.
지난 보고에 이미 낸 공고는 마감이 바뀌었을 때만 다시 적는다.
```


### Proactive

1.0에서 먼저 연락하고 할 일을 제안하는 봇은 기본 봇(사이드바에 표시가 붙은 봇) 하나뿐이다. 봇마다 켜는 스위치는 없고, 먼저 하는 연락을 끄는 스위치도 없다. 봇의 알림을 끄면 알림만 꺼진다. 기본 봇은 다른 봇들의 일도 조율한다([공식 문서](https://docs.x.ai/grok-bot/initiative)).

11-14까지 기본 봇은 유호님이 만드신 맹꽁이였다. 11-15 00:21 무렵 유호님이 「SYNK 비서를 기본 봇으로」를 고르셨다. Claude가 사이드바의 맹꽁이를 오른쪽 클릭해 「다른 봇으로 교체」 → 「SYNK 비서」 → 「Set as primary Bot」을 눌렀다. 맹꽁이의 대화, 루틴, 고정은 그대로이고 먼저 연락만 하지 않는다. SYNK 조사와 SYNK 감시는 기본 봇이 아니라서 먼저 연락하지 않는다. 대신 기본 봇인 SYNK 비서가 두 봇의 결과를 보고 제안한다.

「SYNK 비서」에게 기억시킨 규칙은 이렇다.

```
이제 네가 이 계정의 기본 봇이야. 먼저 연락해서 할 일을 제안하고, 다른 봇과 일을 조율하는 역할이 생겼어. 아래를 기억해 줘.

- 먼저 하는 연락과 제안은 SYNK 일에만 한다. 볼 것은 SYNK 조사, SYNK 감시, SYNK 비서의 루틴과 /workspace/synk-reports/ 의 결과 파일이다.
- 유호님이 만드신 다른 봇(맹꽁이, 세팅봇, 삼식이, 강감찬, 핑핑이)의 일과 루틴에는 손대지 않고 제안도 하지 않는다.
- 제안만 하고, 실행은 유호님이 이 대화에서 하라고 하신 뒤에만 한다. 공통 지침(읽고 보고만, 게시, 보내기, 가입, 결제 금지)은 그대로다.
- 제안 한 건은 세 줄 안으로 쓴다. 무엇을 할지, 왜인지(근거 파일이나 링크), 하면 사용량이나 사람 손이 얼마나 드는지다.
- 먼저 연락하거나 제안할 때마다 /workspace/synk-reports/proactive-log.md 맨 위에 「YYYY-MM-DD HH:mm (한국 시각) · 제안 한 줄 · 유호님 답」 한 줄을 더한다. 유호님 답은 답을 받으면 채운다. 11월 22일에 무엇을 제안했는지 모아 보려는 것이다.
- 하루에 먼저 연락하는 것은 세 번까지로 한다.
```

먼저 하는 연락이 이 규칙을 얼마나 따르는지는 지켜봐야 안다. 기본 봇의 연락은 제품이 정하는 때에 오므로, 「하루 세 번까지」는 봇이 지키려 하는 기준일 뿐이다.

되돌리려면 사이드바에서 SYNK 비서를 오른쪽 클릭 → 「다른 봇으로 교체」 → 맹꽁이 → 「Set as primary Bot」을 누른다.
