# 승인 로고의 현재 사용처 반영

> 2026-09-10. 사용자 요청: “관련된 모든 작업에 지금 이거 반영 먼저… 홈페이지나 이곳저곳”. 현재 제공하는 제작물·웹과 이를 만드는 코드를 함께 확인했다. 아래는 로고 반영 범위이며 오래된 사업 문구·일정까지 현행화했다는 의미가 아니다.

## 현재 음성 상태 — 09-10 추가 지시

현재 사용한 내레이션·대사·안내 음성은 모두 교체 대기다. 사용자는 다른 작업에서 DIVE와 본인 목소리를 활용할 음성을 정하고 있으며, 그 결과가 제작에 적용되면 음성 사용처 전반을 교체하도록 지시했다. 이번 세션에서 음성 생성·추가 보정은 진행하지 않는다. 아래 AAC 보존·재생 검사는 로고 작업 중 음성을 훼손하지 않았다는 확인이며 음성 품질 승인과는 별개다. 현재 제공 파일을 새 브랜드 음성의 최종 납품본으로 취급하지 않는다.

## 자료와 제작 경로

- 정적 홍보 4묶음: HTML 98개, 카드 72장, 소개서 20장·캐러셀 7장, PDF 10개/42쪽. 로고와 로고 설명만 좁게 변경하고 기존 본문·배치를 보존했다.
- 발표·상담: 설명회, 학부모 안내문, 상담 브로셔, 로드맵, 상담 결과 요약의 원본·HTML·PDF. PDF 5개/34쪽의 쪽 수와 추출 본문 동일, 로고 14자리 확인. 브랜드 킷 HTML과 색상판 PDF도 갱신했다.
- SNS 준비 파일: 현행 배너 5종, yuhobuilds 프로필, 해당 시안 보기. 실제 SNS 계정 업로드는 수행하지 않았다.
- 라디오: 배경·무대 덮개·썸네일의 로고. 배경 3종과 썸네일은 기존 영상·마스코트가 바뀌지 않도록 로고 영역만 조립했으며 영역 밖 RGBA 차이 0을 확인했다.
- 고유 영상 32편: 첫 게시물 7편, 릴 10편, 계정별 6편, 마케팅 9편(K-LOFI·공개수업·클리닉 포함). MP4 제공 파일은 동일 업로드 사본 1개를 포함해 33개다. 첫 게시물 이미지 48장·PDF 7개, 릴 표지·제공자료 20장도 갱신했다. 삽입 소개서와 실습 화면 캡처의 로고까지 대조했다.
- 생성 코드·공유 자산·복사 경로와 관련 시험을 함께 갱신했다. 본문 글자로 사업명을 붙이거나 `_개선`의 옛 로고를 기본으로 다시 선택하는 경로를 수정했다.

## 검증과 범위

- 로고 및 계정 컬렉션 관련 시험, 문서 빌드·구문 검사와 실제 PNG/PDF/브라우저/영상 프레임을 확인했다. 정적 담당의 계정 컬렉션 시험 8/8, 문서 담당의 로고 시험 13/13 및 발표물 빌드 확인 7개 통과.
- 영상의 기존 원고·장면 순서·길이·프레임 수와 원본 AAC 음성 스트림을 대조했다. 원본 영상의 음성 교체는 하지 않았다. 로고 합성 후 재인코딩한 영상 전체 픽셀 동일성을 주장하지 않는다.
- 공개수업의 웹 사본만 기존 호스팅의 파일당 25MiB 제한에 맞춰 1920×1080, 18,874프레임, 629.184초를 유지한 18,360,047바이트로 압축했다. 공개 사본의 음성은 AAC 96kbps로 재인코딩했으며, 원본 자료의 AAC는 보존했다. 전체 디코드·대표 프레임을 확인했다.
- 정적 홍보 ZIP 41개와 첫 게시물 ZIP 1개를 최종 출력으로 다시 묶고 재개봉·내부 파일 지문/CRC와 링크를 확인했다. 첫 게시물 ZIP은 368항목·409,426,556바이트이며 SHA256은 `cc605172d4c72f3cd4681064ca61632c7ee3a22e75db4b408f94a4963ce1bbbe`다. 계정별 ZIP에서 현재 페이지가 참조하지 않는 검수 원본·후보만 제외했다. 원래 미추적이던 큰 MP4·ZIP은 로컬 제공 파일로 유지하고 생성 코드·지문을 기록했다.
- SYNK-talk의 실제 화면·아이콘·스플래시는 내부 꺾쇠/`syn<`이므로 이번 외부 SYNK 로고 정책으로 교체하지 않았다. 앱 아이콘 관련 시험 10/10 통과. 앱 배포는 하지 않았다.
- 기존 공방 영상 2종은 실땀 워드마크 없이 얇은 활자 제목 `S Y N K L A B`를 쓰는 원본 영상이다. 원본과 옛 학원 소개·체험 일정은 보존했다. 이 문구의 별도 현행화는 이번 로고 교체에 포함하지 않았다.
- 과거 후보·비교 자료, 이미 인쇄·게시된 SNS 콘텐츠는 소급 변경하지 않았다. 확인한 현재 파일과 실제 게시된 웹을 구분한다.
