# 트랙 — 무엇이 남았나

> **결정.md 의 짝이다.** 결정.md 는 「무엇을 정했나」, 이 파일은 「그중 무엇이 아직 안 끝났나」.
> 만든 까닭(유호 지시 08-22 「지금 우리 할것들 전부 까먹지말고 제대로 인계문 부탁해」):
> 트랙 선언의 정본은 «열린 PR» 인데 **지금 열린 PR 이 0건**이라 남은 일을 적을 자리가 없었다.
>
> **낡음 방지 규율 — 이 파일을 살리는 유일한 조건이다**
> - 트랙을 끝낸 세션이 **그 커밋에서** 이 줄을 지운다. 「나중에」는 없다.
> - 새 트랙은 유호님이 정한 그 자리에서 한 줄 넣는다(결정.md `--추가` 와 한 벌).
> - **여기 적힌 상태와 실물이 어긋나면 실물이 이긴다.** 이 파일은 색인이지 증거가 아니다.
>   증거는 커밋·렌더·`node tools/결정.js` 다.
> - 열린 PR 이 있으면 **PR 본문이 이 파일보다 우선**한다(유호 확정 08-15 「PR = 작업 목록」).
>
> 마지막 갱신 = 2026-08-22 (커밋 b2a19949 시점 실측 · 요소 트랙 §2-B·2-C 현행화)

### 이어 하는 법 — 이 순서 그대로 (총 ≈ 1시간 20분, 사람 손 0)
```
1) node tools/세트굽기.js --세트 전부 --샘플 128 --너비 1000 --장치 GPU     # ≈45분 · 없는 36장만
2) node tools/요소부품굽기.js                                              # ≈25분 · 부품 10종 알파 두 층
3) python tools/룸자산화.py                                                # 초 단위 · 구운재질.json 갱신
4) node tools/요소시안.js --폭 240                                         # 판정 지면 재생성
5) node tools/lib/loom.js --시연 && node tools/이해대장.js                  # 지면재현 회귀가 요구한다
```
· 1)은 **없는 것만** 굽는다 — 끊겨도 같은 명령으로 이어진다(`--다시` 는 처음부터 다시라 쓰지 않는다).
· ⚠ 낡은 렌더를 «되살려» 두지 않는다: 있으면 건너뛰어 **옛 결과 새 결이 섞인 세트**가 조용히 나온다.
· 4) `docs/요소_시안.html` 은 지금 **낡은 93장 판**이다(새 천 결 아님).
· 5) `loom.js` 를 고치면 `docs/Loom_부품_시연.html`·`docs/이해대장.html` 이 **같은 커밋에** 있어야
  훅이 통과한다 — 안 그리면 그 뒤 모든 세션의 배포가 막힌다.

### ⚠ 굽기 전에 정할 것 하나 — 해상도
메모리 [felt-fur-sharpness-lever] 실측: 털 선명도의 **진짜 손잡이는 해상도**다
(900→1800px = +83.4% · 샘플 4배는 +15%뿐 · 디노이즈 설정은 no-op).
그런데 이 세트는 **1000px** 로 굽고 있다 — 이 세션에서 겪은 «숫자가 뭉갠다 · 견본이 씻긴다» 의
절반은 설계가 아니라 해상도였을 수 있다(끝까지 안 갈라봤다 — 「안 재봤다」).
- **그대로 1000px 로 마치는 쪽을 권한다**: ①이미 구운 67장이 1000px 이라 섞으면 세트가 갈린다
  ②부품 통로는 이미 1100px 이고 룸자산화가 96~256px 로 줄이므로(슈퍼샘플링) 부품 화질에는 무관하다
  ③1800px 로 통일하려면 103장 전부 다시 = 약 4시간.
- 유호님이 시안을 보고 «털이 뭉갠다» 하시면 그때 `--너비 1800` 로 전량 재굽기 한다.
