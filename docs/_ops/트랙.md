# 트랙 — 무엇이 남았나

> **결정.md 의 짝이다.** 결정.md 는 「무엇을 정했나」, 이 파일은 「그중 무엇이 아직 안 끝났나」.
> 만든 까닭(유호 지시 08-22 「지금 우리 할것들 전부 까먹지말고 제대로 인계문 부탁해」):
> 트랙 선언의 정본은 «열린 PR» 인데 **지금 열린 PR 이 0건**이라 남은 일을 적을 자리가 없었다.
>
> **낡음 방지 규율 — 이 파일을 살리는 유일한 조건이다**
> - 트랙을 끝낸 세션이 **그 커밋에서** 이 줄을 지운다. 「나중에」는 없다.
> - 새 트랙은 유호님이 정한 그 자리에서 한 줄 넣는다(결정.md `--추가` 와 한 벌).
> - **여기 적힌 상태와 실물이 어긋나면 실물이 이긴다.** 이 파일은 색인이지 증거가 아니다.
>   증거는 커밋·렌더·`node tools/결정.js` 다.
> - 열린 PR 이 있으면 **PR 본문이 이 파일보다 우선**한다(유호 확정 08-15 「PR = 작업 목록」).
>
> 마지막 갱신 = 2026-08-22 (커밋 b2a19949 시점 실측 · 요소 트랙 §2-B·2-C 현행화)

### ⚠ 겹침 규율 — 08-22 에 실물로 배웠다 (유호 지시 「겹치지않게 조심해」)
같은 굽기가 **세 세션에서 동시에** 돌았다(17:08). 내장 GPU 하나라 장당 **149초** 걸렸고(혼자면 31초)
셋이 같은 PNG 를 겨눴다. 그다음이 더 나빴다 — 두 세션이 «서로의 프로세스를 죽여» **둘 다 멈췄다**(17:16).

- **죽이기는 수렴하지 않는다.** 남의 굽기를 죽이지 않는다. 규칙은 하나뿐이다 —
  **이미 돌면 걸지 않고 물러난다.** 산출은 같은 폴더에 쌓이니 누가 굽든 결과는 하나다.
- **거는 쪽이 먼저 센다**: `Get-CimInstance Win32_Process -Filter "Name='node.exe'" | ? { $_.CommandLine -like '*굽기*' }`
  🔴 `tasklist | grep` 도 `tasklist /FI` 도 **쓰지 마라** — 한글 로케일·MSYS 경로 변환 때문에 **늘 0건**이다.
  블렌더 셋이 도는 중에도 「없음」이라고 답했다(그 오판이 이 사고의 방아쇠였다).
- 자리를 잡았으면 `send_message` 로 **먼저 알린다.** 알리기 전에 거는 것이 겹침의 시작이다.
- **끊긴 굽기는 성공처럼 보인다.** 도구 백그라운드로 건 굽기는 «남이 끊어도·잘려도» 알림이
  `completed · exit 0` 이고 로그 끝줄이 ✅ 라 완주와 구별이 안 된다(두 세션이 각각 겪었다:
  한쪽은 2분 반 뒤 한 장만 굽고, 한쪽은 130초 뒤 로그 안 `EXIT=127`). ⇒ **판정은 파일 수로 한다.**
- 공유 작업본이라 **남의 미커밋이 내 `git status` 에 뜬다.** 커밋은 언제나 `-- 경로` 로 못 박는다
  (지침 그대로 · `add -A`·`commit -a` 는 남의 반쯤 된 일을 통째로 담는다).

✅ `tools/요소굽기.py` 미커밋은 **해소됐다**(08-22 · 커밋 996f09aa + b2a19949). 그 299줄은 남의 것이
아니라 요소 트랙 본인의 것이었다 — `직물결()` 수리·조작 여섯·투명 모드.
⚠ 그래도 굽기 전에 `git status -- tools/요소굽기.py` 는 지킨다: **세트굽기는 항목마다 이 파일을
새로 읽는다.** 배치가 도는 중에 이 파일을 고치면 앞 렌더와 뒤 렌더가 갈리고, 갈린 세트는 못 알아본다.

| **도장의 천 결이 안 보인다** | Stone 으로 내리고 빛도 결광2 로 내렸지만 이 노출에서 밝은 천은 범프 명암이 갈 자리가 없다. 「손으로 판 인장」으로는 읽혀서 거기서 멈췄다 — 더 갈지는 유호님 몫 |
| **김밥 단면** | 여섯 판 거쳐 읽히게는 됐으나 음식 다섯 중 가장 평평하다 |

## 6. 기술 부채 — 알고 있고 안 고친 것

- **본문 층이 해상도에 묶여 있다** — `조합덧씌움3.py`·`성장덧씌움.py` 좌표가 1080px 절대값이다.
  700px 시험 렌더에 부으면 글이 카드 밖으로 나간다(실측: 대비 15.28 → 5.97). Expo 실장 때 상대 좌표로.

- **PIL 합성 목업이지 Expo 실장이 아니다** · AMOLED 실기 미확인.
- 화면 안 숫자·문구는 표본이다(12 / 7 / 3급) — 실데이터 배선 전.
