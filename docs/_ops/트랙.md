# 이어갈 작업

> 2026-10-10 정리. 새 역할과 작업 방식은 [AI 운영 원칙](../AI_운영원칙.md), 이번 정리 결과는 [시스템 경량화](시스템_경량화_20261010.md)에 둔다. 아래 상태는 연결된 기존 기록의 요약이며 이번 정리에서 운영·공개 화면을 다시 검증한 것은 아니다.

원문·결과 위치와 다음 할 일만 남긴다. 완료 과정·검사 수·후보별 해시는 담당 QA에서 읽고, 끝난 항목은 이 목록에서 뺀다. 재개할 때 현재 코드·실행본·기존 승인을 대조한다. 보류·설계만 승인된 항목은 이 목록에 있다는 이유로 자동 실행하지 않는다.

## 2. 먼저 막을 위험 — 잃거나 새는 것

- **Typecast 키:** 10-07 시험 오류에 실제 키가 출력된 기록이 있다. 새 키 발급과 기존 키 폐기, 로컬 보관 파일 유지 여부가 남았다. 값은 출력하지 않는다. [기존 확정·근거](결정.md).
- **AI 비용·튜터:** MVP의 낮춘 시험 한도와 운영 튜터 OFF를 유지한다. 과거 하드 상한·켜짐 스냅샷으로 되돌리지 않는다. 모델·한도·재평가 비용은 [AI 효율화](../SYNK_WORLD_AI_효율화_20261002.md)와 talk의 현행 설정을 확인하고 변경 승인을 받는다.
- **git 밖 원본:** `Documents/PC_백업_20261003/` 복원 목록과 Drive 해시 대조 기록을 보존한다. talk 미커밋 원본·다른 계정의 한강2126 자료는 별도로 확인한다. 백업 기록만으로 새 파일까지 보관됐다고 판단하지 않는다.
- **공용 작업본:** 다른 작업의 company/messenger/WORLD 및 talk 변경을 현재 HEAD와 대조해 자기 변경만 통합한다. `tools/company-messenger/QA.md`의 개인 주소를 통째로 공개 커밋하지 않는다. git 잠금은 [저장소 안내](../../AGENTS.md)를 따른다.
- **PC 공간·백업:** 이전 삭제·복원과 백업 결과는 기존 원본에서 확인한다. 설치본·최종 자산·복원 가능한 원본을 먼저 보존하고 중복 캐시만 정리한다. 저장소 이력이나 오래된 잔액을 현재 상태로 보고하지 않는다.
- **CI:** 자체 러너 설치·과거 Actions 분 한도는 현재 필요성을 확인할 때만 재개한다. [기존 설치 안내](자체러너_세우기.md)는 상시 의무가 아니다.
- **로컬 master·origin(10-11 새벽):** 로컬 master를 origin에 맞췄다. 옛 로컬 커밋 25개는 같은 내용이 origin에 있었고, PC 실계정 기록은 `2f9a297cf`로 올렸다. GPT 로컬 커밋 둘(WORLD 마루·카페, 경량화)과 7판 기록은 origin 위에 다시 쌓은 뒤 유호님 「가로 진행해」로 함께 올렸다(7판 커밋 둘은 이력에 같은 내용으로 두 번, 병합 하나). 이 push로 origin 트랙도 새 구조가 됐다. GPT WORLD는 origin `7b2318e5c`와 갈린 app-shell·server를 양쪽 살려 합치고 생활 키 한 줄을 더했다. 작업본의 WORLD·타운·옷장·회사 파일 22개는 주인 세션이 더 고친 판이라 그대로 뒀으니, 커밋할 때 지금 HEAD와 대조해 자기 변경만 올린다(목록 `.tmp/origin-sync-20261010/README.md`).

## 3. 앱·계정(WORLD)

- **플랫폼 시그널 2:** 웹·개인 PC의 최신 채택 화면과 WORLD 펠트 책을 보존한다. [디자인 원문](../디자인/플랫폼_시그널/README.md), [PC WORLD 책 반영](qa/platform-reinstall-worldbook-20261010/README.md). 후속은 실제 사용 불편을 중심으로 고도화한다.
- **플랫폼 계정 인수:** PC 로그인→로그아웃→동일 계정 메모/복구 기록 복원까지 확인된 기록이 있다. 완전 종료/재열기·PC↔웹 쓰기는 사용자 Esc로 중단돼 미실행이며 실교사/학생·물리 폰·OS 알림·IME도 별도다. [최신 실계정 기록](qa/platform-real-account-20261010/README.md), [통합 설치](qa/platform-account-integration-20261009/README.md).
- **PC 편의·출시:** 트레이·창 복원·검색·암호화 초안은 개인 PC에 적용했다. 물리 재부팅/절전/모니터 탈착은 미검증. 정식 서명·Mac 공증·공개 updater·운영 이용권은 [desktop 출시 목록](../../desktop/README.md)에서만 관리한다. [편의 기능 근거](qa/platform-convenience-20261009/README.md).
- **Google 가입·브랜드:** 실제 가입/같은 ID 재로그인·웹 SSO는 확인했다. 서비스 이름 SYNK는 브랜드 검증·Publish branding 뒤 실제 화면 대조가 남았으며 10-10 예약의 결과부터 확인한다. 키 교체는 사용자 취소, SMS는 출시 전으로 연기. [최신 후속](qa/google-followups-20261009/README.md), [브랜드 단계](qa/google-brand-label-20261009/README.md).
- **공통 계정·개인정보:** 운영 학습 기록과 계정 삭제(7일 취소 유예·30일 이내 처리)는 보존한다. 본문 승인·출시 전 법률 확인·공개 약관 연결이 남았다. [계정 구현](../SYNK_공통계정_구현검증_20261002.md), [약관 확인](../약관_처리방침_확인목록_20261003.md). 공유를 끈 동안의 기기 기록을 임의 이전하지 않는다.
- **WORLD 오프닝·마루:** 승인 자산과 Omni v9, 마루의 홈→게임→복귀를 보존한다. 공개/설치본·운영 로그인·실물 성능은 담당 증거를 대조해 이어간다. [마루 통합](../../experiences/synk-world-app/qa/maru-integration-20261010/README.md), [홈 원문](../../experiences/brand-opening/HOME.md).
