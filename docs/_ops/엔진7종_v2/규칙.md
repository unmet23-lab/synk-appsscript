# v2 옷 입히기 규칙 — 유호 확정 09-04 「B로 가자, 페이블로 v2 써줘」

너는 절 하나(§N)를 맡는다. 재료 셋은 이 폴더에 있다:
- `재료/을/§N.md` = **정본 몸통**(Fable 판 · `docs/엔진7종_상향설계_v1.md` 의 그 절). 내용의 정본이다.
- `재료/갑/§N.md` = Opus 판의 같은 절. **문장 자**의 본보기이고, «가져올 것»의 출처다. 내용의 정본이 아니다.
- `재료/심사_§N.md` = 눈가림 심사 셋이 이 절에 적은 것 — «합칠 것» 줄 · 렌즈별 까닭 · 「갑에서 가져올 것」 · 「틀림」 목록 · 읽힘·깊이 근거.
산출은 하나: `v2/§N.md`. 다른 파일은 만들지도 고치지도 않는다.

## 1. 지키는 것 — 기계 자(`자.js`)가 잰다. 하나라도 어기면 되돌아온다
1. **을의 것이 전부 산다.** 상향 항목 U 번호·제목 전량 · 유호 판정 D 번호 전량 · 실물 이름(파일·함수·표·칸 이름·커밋 해시·URL·모델 ID) 전량. 바꾸지 않고 «붙인다» — 실물 이름은 백틱째 그대로 두고 옆에 괄호로 뜻을 단다. 우리말로 갈아 끼우지 않는다(갑이 51 판정에서 그걸로 깎였다).
2. **항목마다 붙은 줄을 하나도 버리지 않는다** — 대가 · 닫을 것 하나 · 자 · 효력·닫히는 문 · 돈 · AI 두 배 자 · 유호님 자리(선택지·권고·마감). 수·날짜·「안 재봤다」·「추정」·「0/0」·「문서에 없음」도 그대로. 줄이는 것은 «말»이지 «재료»가 아니다.
3. **새로 지어내지 않는다.** 갑에서 가져오는 것은 `심사_§N.md` 의 「갑에서 가져올 것」에 적힌 항목뿐이고, 그것도 `재료/갑/§N.md` 원문에서 옮긴다. 갑에 없으면 안 가져온다. 갑의 틀린 수(심사 「틀림」 목록의 갑 항목)는 가져오지 않는다.
4. **시제 규약** — 새 장치는 전부 «짓는다/지을 것이다». 「돈다」는 지금 도는 것에만. `심사_§N.md` 「틀림」의 을 항목은 근거대로 고친다(없는 파일을 있는 시제로 쓴 자리엔 «(짓는다 · 지금 코드 0)» 표식 · 틀린 수는 근거의 수로 · 틀린 조항 번호는 근거의 번호로). 고칠 때도 이름은 지우지 않는다.

## 2. 옷 — 문장 자(갑이 증명한 것 · 심사 ⑤읽힘 갑 3.9 : 을 2.2)
- **장면이 먼저** 온다(「07:40 알림을 열면 홈에 몽글이 있습니다」). 구조·정찰·대가는 그 뒤.
- **한 문장 60자 안팎.** 한 줄(문단 한 줄 · 표 한 칸) 250자 안. 긴 줄표(—)로 문장을 잇지 않는다. 마침표로 끊는다. 나열은 「그래서 · 그런데 · 때문에」로 잇거나 글머리표로 내린다.
- **소제목(결론 줄)에 기술 낱말 0.** 「#### U1 「몸이 듣는다」 — 감각층을 «수집 자리»로」처럼 말로 선 한 줄. 식별자·키 이름·함수 이름은 그 아래 첫 줄에 괄호로.
- **낯선 낱말은 그 문장 안에서 뜻을 단다** — 「Brier(예측이 얼마나 맞았나를 0~1 로 재는 점수)」 · 「append-only(덧붙이기만 하고 지우지 않는다)」. 같은 절에서 두 번째부터는 안 달아도 된다. 뜻풀이로 안 서면 학원·수업·학생 쪽 물건에 빗댄다.
- **괄호 안 괄호 금지.** 괄호가 둘 겹치면 문장을 둘로.
- **표 칸은 한두 문장.** 칸이 길면 요지만 두고, 긴 설명은 표 밑 «읽는 법» 문단으로 뺀다. 표 머리 열 이름은 우리말.
- **합니다체**로 통일(갑의 문체). 결론 먼저.
- **「안 재봤다」와 「0건」을 가른다.** 수엔 자·분모·날짜를 붙인다(을이 이미 붙인 것은 그대로).
- 자기 사연(「앞 판은 …」 · 「이 판은 …」 · 「비평이 …」)은 본문에 넣지 않는다. 반박 이력 절(N-6)은 «무엇이 바뀌었나»만 짧게.

## 3. 뼈대 — 심사 다수결
- **갑 뼈대**(§0 · §3 · §4 · §5 · §10 · §11 · §12 · §16): 갑의 소절 순서·표 꼴을 따른다. 내용은 을 전량 + 갑에서 가져올 것.
- **을 뼈대**(§1 · §2 · §6 · §7 · §8 · §9 · §13 · §14 · §15): 을의 순서를 두고 문장만 갈아입힌다. 갑에서 가져올 것은 제자리에 넣는다.
- 절 제목 줄은 「## §N. …」 꼴을 유지한다(을의 제목을 두되, 제목의 기술 낱말은 아래로 내린다).
- 상향 항목 골격은 통일한다: 「#### U번호 말로 선 결론 줄」 → 장면 → 구조 → 정찰 근거 → 걷어내는 것 → 승계 제약 → 대가·닫을 것 하나 → 자 → 효력·닫히는 문 → 돈 → AI 두 배 자 → 유호님 자리. 을에 있는 줄은 다 있어야 한다. 을에 없는 줄은 「문서에 없음」이라 적지 말고 그냥 비운다(새 주장 금지).

## 4. 쓰는 법
- 큰 절은 한 번에 쓰지 않는다. 뼈대(소제목 전부)를 먼저 Write 로 저장하고, 소절 하나 완성할 때마다 Edit 로 채운다.
- 다 쓰면 `node docs/_ops/엔진7종_v2/자.js §N` 을 돌린다(저장소 루트에서). 🔴 이 있으면 그 목록을 고치고 다시 돌린다. ✅ 가 나올 때까지.
- 최종 답(반환값) = 한 단락: 「§N ✅ · v2 바이트 · 줄당 평균 · 갑에서 가져온 것(항목 이름) · 고친 틀림(을 항목) · 못 한 것(있으면 왜)」. 인사·서론 없음.
