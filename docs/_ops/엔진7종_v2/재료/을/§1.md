## §1. 자 — 이 설계가 통과한 자

결론: 「한 차원 위」는 «같은 축에서 더 많이·더 정확히»가 아니라 **아래 여섯 축 중 최소 하나에서 부호나 종점이 바뀌는 것**이다. 여섯은 전부 철학 정본에 이미 적힌 자이고, 판정지면 08-26 이 「지금 손이 가장 많이 가는 층이 3년 뒤 가장 평평해진다」로 실측한 것이 그 반례 목록이다.

**기호 열쇠**(같은 동그라미가 절마다 다른 뜻으로 쓰인다 — 첫 사용 «앞»에 한 번 푼다):

### §1-1. 「한 차원 위」 여섯 축

| 축 | 어디서 어디로 | 정본 근거 |
|---|---|---|
| ① 모델 축의 «부호» | 「AI 가 두 배 똑똑해지면 이 자산은 커지나」에 «커진다»로 답할 수 있어야 종류가 바뀐 것. 첨삭 정확도·태깅·유창함 측정·FSRS·편성 규칙은 모델↑에 격차↓. 분포(Prism)·개입-효과 짝(Temper)·졸업생 궤적(Trail)·일하는 방식은 모델↑에 값↑ | 철학 Ⅰ-2 · 불변식 5 · 대체불가 3문 ① |
| ② 재료 축의 «출처» | 인터넷에 있는 것 → 인터넷에 없는 것. 학생이 «말한 것»(대화 추출) → 학생이 «한 것»(오답 23유형·이탈 지점·집중 시간대·교실 검수·실제 발화·졸업 뒤 삶). 해자는 데이터의 양이 아니라 «축의 개수». 재료의 급(Ⅰ-8)이 이 축의 질 조건 | Ⅰ-1 · ㉡ 정의 · 선생님의 뇌 |
| ③ 흐름 축의 «종점» | 모였다 → 읽혔다 → «다음에 줄 것이 바뀌었다» → «30일 뒤 들었나 짝이 남았다». 종점이 한 칸 오른쪽으로 옮겨야 종류가 바뀐 것 | Ⅰ-3 ④ · 도달의 정의 · 불변식 3·6 · 세로줄 |
| ④ 수신자 축 | 내부 → 강사·학부모 → «학생 본인». 실측 08-29: 자동 발송 53 중 재학생 본인 0 — 이 축은 지금 0 칸 | Ⅰ-5 넷째 칸 · Ⅱ-8 |
| ⑤ 판정 축의 «갱신 방식» | 「지금 모델로 가장 잘 짓는 것」이 아니라 「모델이 바뀌면 스스로 재심되는 구조」(발동이 사람 손이 아니라 사건). 실측 = Ⅰ-9① 은 08-10 이후 0번 돌았다 → 이 축이 지금 가장 비어 있다 | Ⅰ-9 ① · past-decisions |
| ⑥ 자 축 | 손으로 적은 상태 → 도구가 내는 값 → 래칫. 「적혀 있었는데 그 순간 안 울었다」를 닫는 것. 자 없는 상향은 다음 날 낡는다 | Ⅰ-9 ③ · A-1 읽는 법 ②③ |

**판정문**: 어느 엔진의 설계 변경이 (a) 3문 ①의 답을 「작아진다→커진다」로 뒤집거나 (b) 관측 축을 하나 더 열거나 (c) 도달 종점을 오른쪽으로 옮기거나 (d) 수신자를 학생 본인까지 넓히거나 (e) 재심이 스스로 도는 구조를 세우거나 (f) 그 상태를 도구가 재게 만들면 «종류가 바뀐 것». 정확도·자산 개수·화면 다듬기·모델 갈아타기만 있으면 «같은 종류에서 더 나은 것»(그것도 버리지 않는다). 통합 계약 25(§3-4 표 행 수 · 통합.json shared_contracts 도 25) 중 축 a~f 가 붙은 것 20 / 배관 5 — 표의 「축」 열을 센 수.

### §1-2. AI 두 배 자와 대체불가 3문

- **두 배 자**(철학 Ⅰ-2 원문): 「기능·자산 하나마다 묻는다. 같이 좋아지는 것만 짓고, 무의미해지는 것(모델 약점 하드코딩 보정층·후처리 교정·특정 모델 전용 프롬프트)은 원칙적으로 안 짓는다. … 갈아탈지는 감이 아니라 «우리 학생이 실제로 틀린 문제로 만든 시험지»(102문항)로 판정.」
- **대체불가 3문**(엔진지도 §대체 불가 시험): ① 모델이 두 배 똑똑해지면 이 자산은 커지나 작아지나 ② 돈으로 살 수 있나 ③ 우리가 안 하면 다른 누가 할 수 있나. 핵심은 ①. 공통 원리 = 「모델은 인터넷에 없는 것을 영영 모른다: 우리 학생이 실제로 틀리는 것 · 우리가 개입한 결과 · 졸업 뒤 그 사람의 삶」. ②③은 (a)~(f)를 지난 뒤의 확인 문이다. Reed 는 셋 다 못 지나는 유일한 소개서였고 «뒤집는 문 하나 = 앱 자습 체류→㉡ 배선»이 예고돼 있었다(§10).
- 이 문서의 상향 항목마다 「AI 가 두 배 똑똑해지면 커지나」에 **「같이 커진다 / 같이 안 커진다」를 정직하게** 적었다(안 커지는 항목은 «규율·배관» — 그래도 짓는다 · 종류 변화라 부르지 않는다).

### §1-3. 승계한 제약 — 넘지 않는 것

- **㉡ 사람 손을 늘리는 해법 금지** — 「누가 매번 확인하면 된다」는 해법이 아니라 미룬 결함. 사람이 누르는 칸은 판단이 필요한 자리(검수 확정) 하나. 발동 조건을 사람 손에 거는 장치는 0번 돈다(실측). → 이 설계는 «리듬당 하나»로 셀지를 D20 으로 묻고, 판단 아닌 항목은 «기본값 자동 + 이의 창(옵트아웃)»으로 접었다.
- **㉢ 학생끼리 비교 금지** — 범위 = «학생에게 보이는 것»까지(유호 09-01). 내부 배치·운영 알고리즘이 값을 견주는 것은 위반 아님. 학생 화면·문서에 등수·평균·「다른 아이보다」·수·퍼센트·분모 0. 캐릭터 몸통 크기 축 없음(폰을 나란히 놓으면 견줄 수 있고 끌 수 없어서). 🔴 열린 판정 하나: 주간 리포트 «하위 3명»(원장 내부 계기판)이 ㉢ 문면상 금지에 걸리는가는 유호 판정 대기(철학 정본 다음 개정 때 · 횡단 09-02 등재) — 이 설계가 늘리는 내부 집계 넷(senior_paths · Prism 반 카드 · Temper 회고 표 · 보장 부채 계기판)도 그 판정이 서기 «전»엔 순위 열(하위 N명·등수) 0 · 셀 값과 분모만.
- **㉣ 식별자 반출 금지** — 「밖」은 벤더가 아니라 식별자가 가른다. 식별자(이름·연락처·student_id·생년·학교 · 소수 구간엔 날짜도)가 붙은 채 우리 저장소 밖의 «처리»(모델 API·외부 도구·외부 사람)로 나가면 위반. 음성 원본은 떼어낼 수 없는 식별자(통로 하나로 좁혀 유호 판정). 저장소 둘 다 PUBLIC(08-29 실측)이라 학생 행이 든 산출은 git 에 0.
- **Ⅰ-4 관찰 = 시스템 · 판정 = 사람** — 「목표에 가까워졌나」「통했나」「실현했나」는 시즌 회고의 사람. 실시간 자동 판정 금지(어기면 검증 불가 추천기). 강사 관찰은 «사람 자리»(08-26)로 제대로 짓는다.
- **자산층(쌓는 셋) 3규칙** — ① 자기 수집 통로를 새로 만들지 않는다(닿는 셋이 걷은 것을 읽기만) ② 학생 화면에 직접 닿지 않는다 ③ 분모 없는 숫자를 내지 않는다.
- **🚫의 «기술적 이유» 다섯을 형태로 푼다** — 미래정보 누출(→ as_of 절단: 그 시점 이후 사건은 안 읽는다) · 데이터 오염(→ 시험 학습자 표식 is_test · 판 지문 · 'sim' 값 없음) · 검증 불가(→ 시험지·홀드아웃·판 대조) · 낙인 고착(→ AI 추정은 시효 있는 파생 캐시뿐 · 라벨 저장 0 · «다음에 할 것» 문안) · 소급 불가(→ 첫 주 어휘는 첫 학생 전 · 계약 c17).
- **시제 규약 §0** — 없는 것을 있다고 쓰지 않는다. 「돈다」는 A-2 「이미 돌아간다」 칸에 있는 것만.
- **정지선 넷(돈·모델 픽·소급 불가·유호 확정 충돌)은 기각 사유가 아니라 «유호님께 요청할 자리»** — §12 로 모은다. 기회비용·매몰비용·「지금 바쁘다」는 이 설계 어디에서도 근거로 쓰지 않았다.

### §1-4. 정찰 게이트 3

만들 때마다 「지금 가장 새로운 방법이 뭔가」를 먼저 정찰했다(2026-09-02 · 9벌). 통과 조건 = ㉠ 우리 스택의 빈 칸이거나 «확실히 나은 대체»(대체는 걷어내기까지 한 벌 · 동점이면 기존) ㉡ AI 가 원격으로 짓고 고치고 검증 가능 ㉢ 대가를 적을 수 있을 것(틀릴 때 모습 + 닫을 것 하나). 통과분은 «수용»까지 한 벌 — ⏳로 쌓지 않는다. 나중 효력은 `docs/개원전_일괄판정_큐.md`에 «질문 + 당김 트리거»로. 전량은 §15.
