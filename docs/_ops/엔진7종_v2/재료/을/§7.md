## §7. SYNK Trail — 쌓는 엔진 1호 · 궤적(코드 = 엔진_궤적.js · 자산층)

**한 문장**: Trail 은 「입학 때 적은 의도 한 줄 × 면접폼 1원천 + 원장 수기 드롭다운을 규칙 표로 맞춰 보는 회고 장부(시트 2장 · 소비자 0 · 졸업/이탈 한 낱말)」에서 「시즌마다 다시 선언한 의도의 시계열(explicit) + 학생이 «한 것» 세 열(목표과제 제출일수·종료사유·진위확인 급수 · observed) × 사람이 말하는 모든 자리의 원문(append-only) 위에 판(모델 ID+프롬프트 지문)이 붙은 판정 층이 더해지고(모델이 바뀌면 시험지 통과 뒤 초안 행만 새 판으로 «더 붙는다» · 사람 손은 이의 제기 예외 1) × 종료구분·급수 이정표(강사 입력 서버사건)·몽골 전체 분모(운영층 적재 · 읽기만)」를 한 사람 위에 잇고, 그 파생이 «자기 것»(my_trail — 회고 병치·졸업 카드 두 자리)과 «내부 것»(비식별 집계 → 강사·원장 내부 재료 · 학생 접점 0)으로만 나가며, 시트 원장 → Supabase 읽기 사본(trail-sync) 한 문으로 소비자에 닿는 종단 데이터 엔진으로 종류가 바뀐다.
