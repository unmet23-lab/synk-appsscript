## §5. SYNK Loom — 닿는 엔진 2호 · 그래픽·재질 엔진(펠트 굽기·부품·율·배치 판단층·Patina · 학생 접점 면은 Vellum)

**한 문장**: Loom 은 «정본 사진을 어느 지면에든 같은 결로 재현하는 결정론 생산기(학생 데이터 0줄 · 판정자 유호 눈 하나 · 재심 발동 사람 손)»에서 «학생이 한 것을 읽어 그 학생만의 물건으로 굽고, 학생이 몸을 만진 것을 ㉡ 관측 열로 Core 에 주며, 유호 판정 장부를 자로 삼아 앞단 심판을 하고, 모델·도구 출시 사건에 스스로 재심되는 «관계의 몸» 엔진»으로 종류를 바꿀 것이다 — 정직하게: 대체불가 3문 ① 「커진다」는 U1·U3 단독이 아니라 U4 히어로 슬롯·U5 지각 자·U6 재심 고리 셋에서만 참이고, U1·U3 는 재료·수신자 축에서만 오른다.

### §5-2. 종류 변화 — 고리 넷

같은 결정론 불변층(Blender·자·정본·헌법 5조) 둘레에 고리 넷을 세울 것이다(아래 [새] 는 전부 미착수 · 09-02). ①재료 고리: Core·Trail 사건(읽기만·as_of)이 Patina 레시피를 거쳐 그 학생의 부품·지면에 «명목형 자국»으로 앉게 하고, 학생이 몸을 만진 것을 mascot.touched(observed·세션 집계 1행·만짐 0 인 세션도 1행)로 학습자상태의 «관측 열»에 닿게 한다 — Loom 이 처음으로 Core 에 준다. ②반응 고리: 몽글의 몸이 학생이 «한 것»(맺음·답장 도착·만짐)에 몸짓만으로 반응(립싱크 0·평가어 0·침묵 반응 0). ③심판 고리: 유호 판정이 판정 지면에서 append 되는 [새] `룸취향.jsonl`(09-03 실물 없음) 을 자로 VLM 지각 자(룸눈)가 앞단을 거르고(접힘·삭제 ✗) 유호가 최종. ④재심 고리: 출시 사건 감지를 세션 상주 자에 붙여 슬롯 6 시험지를 재채점하고 교체 «권고»까지(실행 유호 픽). 출력에 «시즌 책»(교실 A4 1보 → 학부모 창구·학생 본인)을 세워 세로줄의 출구를 맡긴다. 자는 먼저 갈 것이다(룸잉크 실측 밝기·DTCG 변환층).

층: L0 정본(디자인_토큰.json + [새] 「재질/시간(Patina)」 하위축 · 명목값만) · L1 굽기 결정론층(Blender 5.2.x LTS + Arc B390 · 밤 사슬 + [새] Patina 자리별 단계 컷 사전 굽기 · 형태 슬롯) · L2 부품층 · L3 율 9단 · L4 지면 프리셋 8 + [새] «리포트» · L4.5 배치 판단층 + [새] «데이터 원고 어댑터»(입력은 파일 둘만) · L5 강제층·자(지면방·룸잉크 실측 자·렌더린트 + [새] 룸눈.js·Patina 비교불가 회귀·토큰내보내기.js·rot-check 「자동 통로에 붙은 도구 수」 자) · L6 감각·관측층(talk src/마스코트.js 부착점 + [새] 만짐 집계기) · L7 반응 상태기계 · L8 Patina 물성 레시피층(서버 progress 가 as_of 로 집계 · 저장 0) · L9 슬롯 재심 고리.
