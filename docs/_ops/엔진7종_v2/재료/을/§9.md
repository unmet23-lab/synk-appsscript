### §9-5. 하지 않는 것

- 학생을 A/B 집단으로 가르지 않는다 — Thompson sampling·WAPTS·bayesdecide 밴딧 배분·균등 바닥(20%·10%)·다중기저선 «시작 시점 어긋내기» 전부 안 한다 · 탐색 바닥 0% · 재개 = 두 시즌 연속 「갈린 결정 하한 미달」일 때 유호 판정안으로만.
- 사전분석계획 지문을 policy_ver 재료에 넣지 않는다 · 회수판 지문을 md «글자 해시»로 만들지 않는다 · 계획 파일을 appsscript 에 두어 두 저장소가 한 값을 알게 하지 않는다(talk docs).
- 파생 상태를 저장하지 않는다 — learner_state · 집계 표·뷰 · 사후분포 «값» · cron 저장 전부 금지.

- CI 가 운영 짝을 읽어 재계산하지 않는다 · CI 시크릿에 벤더 API 키를 두지 않는다 — 재계산·감지는 로컬 도구가 세션 훅·배포 사건에 «말하며» 돈다(침묵 금지).
