## §13. 걷어내는 것

> 상향은 **더하기만이 아닙니다.** 「확실히 나은 대체」는 **걷어내기까지 한 벌**이어야 통과합니다(정찰 게이트 ㉠).

### 13-1. 통합에서 걷는 것 — **열넷**

| 걷는 것 | 무엇으로 |
|---|---|
| 감시기·재심 방아쇠 **일곱**(Core 폴링 · Loom 주 1회 fetch 넷 · Vellum 모델 ID 사건 · Trail 커밋 훅 · Prism CI · Temper 회차 · Reed diff) | **기존 감지기 확장 하나** · 🆕 «새 파일» 안 짓는다(같은 자리에 이미 도구·장부가 있다) |
| 별도 점수 장부 **셋**(룸 슬롯·Reed·처방판) | 엔진 점수 장부 **하나** + 엔진·갈래 열 |
| 돈 규칙 **여섯** | **두 줄**(1회성 월 상한 + 1인당 상시 단가) |
| 「V6」의 **네 정의** | 한 번호 안 **네 항(ⓐⓑⓒⓓ)**으로 모음(§3-5-1 임시 배정표) · 확정은 관통왕복 명세 v0.5 |
| 「하나만 돌려주는」 고르는 자 **셋** | 순수 함수 **하나**(시트층 재출제는 시트층 전용으로 남긴다) |
| 강사 카드 통로 **다섯** | 슬롯 규격 **하나** |
| 발화 검문·예산 상수가 엔진마다 | **함수 하나 · 정본 한 곳** |
| 밤 작업 스케줄 **셋** | 사슬 **하나**(날짜 파일 셋은 이력으로) |
| 몽골어 발주 **여섯** | 꾸러미 **둘** |
| 이해 대장에 절을 **따로 셋**(수신자 분포 · 판단 자리 · 도장) | **한 절 안의 표 셋** |
| 「팔 균등 확률로 개원」 · 그리디 코드 경로 · 「동률 바닥 20%」 이름표 | 결정론 판 + 도장 · 그림자 |
| 몽글이 자체 산문을 생성하는 형태 | 인코더 하나가 «생성» · 소비자마다 «조립» |
| 「빛 ← 자기신고」 · 「홈 몽글 터치 = 말풍선 반응」 동일시 | 코드 사실 도장 · 사건 둘로 갈라 |
| Atlas 설정 메뉴 새 화면 · 「반영 제외 두 시즌 자동 해제」 | 이미 매일 보는 자리 · 자동 해제 없음 |

### 13-2. 반박을 받아 «더» 걷은 것 — 스물다섯

산문을 원장에 사건으로 저장하는 안 · 출처 축의 'sim' 값 · 새 감시 파일과 새 목록 파일 ·
「소비자 전부 같은 커밋 없으면 판올림 금지」의 «한 커밋» 해석 · 「전량 소급 불가」 문구 ·
**공개 러너에 벤더 키 · 공개 러너가 실학생 판을 읽는 형태** ·
**학생 화면의 수·비율·분모 전량**(「4갈래」·「낸 날 3일」·「5일 중 4일」·「근거 N/분모」·「처음 해 본 것 1」) ·
Trail 조각의 학생 맥락 동승 · 관통 V8 의 학생 화면 판정 · 관통 V2·V5 재정의의 LLM 경유 ·
발화 검문의 런타임 문서 파싱(→ 빌드 생성물) · 어휘 자를 강사 문장에까지 거는 형태 ·
학생별 홀드아웃 5~10 으로 판을 자동 폐기 · 요약 인코더를 노트북 밤 사슬에 두는 형태 ·
회고 사람 칸 「셋뿐」(→ 학생 자기판정 포함 넷) · Prism 발음 파이프의 «Arc 전제»(→ CPU 실측 먼저) ·
Trail 이 제 적재 파이프를 갖는 형태 · 「2년 창」 단정(→ 출처 미확인 표기) ·
기준선의 「2배」·「제거일」 숫자(→ 출처·읽은 날 열) · 「출력 설정으로만」 문장 ·
**정정 병기의 줄번호 전량**(→ 문자열 앵커) · 「포트폴리오 주인 없음 6주째」·「구현 0곳」 문장(09-02 에 섰다) ·
「학생ID 종단 칸 넷이 0」 전제(생애 5칸·종료 원장 둘은 섰다) · 포트폴리오 «재시공».

### 13-3. 엔진별로 걷는 낡은 문장 — 요약

- **Core**: 되묻기 「오래 안 물은 축 먼저」 단일 정렬(2차 키로 격하) · 과제요약 «이름=값 50절단»의 벤더 재료 역할 · 「수요일 재심」 사람 절차 · 「하루 되묻기 2장」을 Core 가 따로 아는 상태.
- **Loom**: 「Loom 은 학생 데이터와 배선 0」 상태 · 「시간이 닫는 문은 Loom 이 가장 작다」 · 감각층 「코드 0줄」 · Patina 「이름·자리만」 · 「Loom 은 돌려주는 자리 없다」 · 룸잉크 폴백 자 · 손 조판 절차.
- **Vellum**: 「가이드 정본 = 기기 파일」(출처 확인 뒤 판정) · 축하 장치 둘 → 하나 · 「…자랐어요」 단정 카드 · 「자기설명 0건」 · 「자동 발송 53 중 0」 손 실측 · 지도 「닿는 셋 = ①②③④」.
- **Trail**: 「나갔다 = 한 낱말」 · 「원장 수기 5칸 필수」 절차 · 「절반은 원장이 손으로」 전제 · 하드 모델 ID · 「셋 다 지금 할 일이 0」 · 「졸업 = 계정 닫힘」 기본값 · 「3년 궤적」 효력(문자열 앵커로 정정 병기).
- **Prism**: 자산층 규칙 «문서 규율만» · 「축 9」 · 「집계층 = 개원 직후 · 앞당길 이유 없음」 판정줄(갈라 적기) · 「등장률을 사람이 센다」 · 「시험지 사람이 굽는다」 · 무응답 손 기록.
- **Temper**: 성과회수 머리말 산문 정본(계획 파일로) · 「개입 = 넷」 목록 · 「강사 관찰 = 임시 다리」 잔재 · 판별 «시간 순차 비교» · 「계기판 로컬 HTML 이 유일한 소비자」 · 「첫 시즌 개입 행이 있을 것」이라는 **말 없는 전제**.
- **Reed**: 「장부·편성·되돌아오는 축 코드 0」 · 앱 자습 = 유튜브 임베드 후보 · 「누가 얼마나 들었나 원리상 0」의 앱 판 부분 · 「Reed 는 가르치지 않는다」 · 곡 물량 두 값 · 코덱을 «용량·요금»으로 정한 줄(→ 귀 A/B 로).

### 13-4. 걷지 «않은» 것 — 되살린 문장 하나

🔴 지도의 **「Reed 는 Atlas 에 기여하지 않는다」 문장은 걷지 않습니다**(유호 확정 08-26).
통합 초안이 이 삭제를 목록에 넣었다가 **이번 수리에서 되살렸습니다.**
바꾸려면 D18 + 조건(D2 채택 ∧ 관통 V7 ✓ ∧ 도달 실측)입니다.
