## §14. 재는 자 — 무엇으로 재나

> **[실재]** = 지금 있는 도구 · **[짓는다·N]** = N걸음에서 세울 것 · **[첫 학생 뒤]** = 학생 0명이라 지금은 못 재는 것.
> 자가 서기 전의 「0건」은 **«안 재봤다»**입니다.

### 14-1. 세로줄과 도달

| 재는 것 | 자 | 분모 |
|---|---|---|
| 관통왕복 V1~V9 통과 수 (**번호의 뜻은 §3-5-1 임시 배정표** — 실물 명세 v0.4 에는 V1~V5 다섯뿐입니다) | [실재] 관통왕복 시험(리허설 학생 · LLM 0 · 과금 0 · 운영 무접촉) | 9 — 지금 v0.4 로 5/5 · 마지막 쌍 커밋에서 9/9 재실측 |
| 이해 대장 「엔진에 닿는 층」 | [실재] 이해 대장 도구 | 3 — 지금 **1/3** · 승급은 활성 + **첫 학생 뒤** |
| **㉡(사람) 층** 재료 종류 — 관측 / 밝힌 것 갈라 | [실재·절 신설] 이해 대장 ㉡(사람) 절에 «생산자»와 «자리»를 갈라 | 관측 6(제출·이탈·자습 체류·만짐·말풍선 반응·과정) / 밝힌 것 1(자기설명) — **지금 관측 2 · 밝힌 것 0** |
| 도달 래칫 넷 | [실재] 사건 검증 상수 · 새 생산자는 소비자 같은 커밋 | 도달 0 = 3 · 생산자 섰는데 도달 0 = 0 · **행동 안 바뀜 1→0** · 안 늘음 1 |
| 시트층 도달 래칫 + 🆕 새 탭·열 등재 수 | [실재] 시트 도달 상한 함수 · 등재→실측→상한 순서 | 표식 27종(골격 58) · 이 설계가 더하는 탭·열은 «서버 새 표 0» 문장과 **갈라** 적는다 |
