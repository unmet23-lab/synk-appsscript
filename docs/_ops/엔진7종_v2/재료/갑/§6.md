### 6-1. 종류 변화

**규칙 + 그림의 단방향 안내 면** → **관계 원장을 가진 양방향 면**.

③말풍선이 **«실제로 뜬 순간»**이 개입 사건으로 남아 「봤나 → 뒤 행동」 짝이 회수되고

⑤하루 네 자리(아침 홈 · 교실 강사 손 · 저녁 숙제 · 밤 라디오)에 **같은 기억**으로 서고

#### U1. 놀이 수집기 + 계약 한 판 — 말풍선 반응이 «분모와 함께» 남는다

**장면.** 07:30 학생이 폰을 켜면 까몽이 혼잣말을 합니다(소재 = 음식). 학생이 말풍선을 톡 칩니다.

「5번 나왔고 3번 반응」 꼴만 성립합니다.
몽골어 검수 전 한국어 줄 노출은 **«읽을 수 없음»으로 표시돼 축 입력에서 빠집니다.**

**구조.** 계약 한 판에 사건 1 + 키 전량(소재·줄 ID·화자·반응·보여준 시각·언어·읽을 수 있음·자기설명 보기·순간 코드·결)을
올리고, 읽는 부품은 **학습자상태 관심축의 «차원»**에 «혼잣말 소재»를 더합니다

검증기 규칙 둘 — **노출 없는 반응 = 빨강 · 읽을 수 있음 표식 없는 노출 = 빨강.**

**정찰 근거.** Praktika 영속 메모리(<https://openai.com/index/praktika/> · **09-02 재확인 실패 · 08월 판 인용**) ·

**걷어내는 것.** 「가이드 정본 = 기기 파일 하나」 · 학습자상태의 「이 축의 유일한 입구」 주석 ·
「혼잣말 «반응»을 선택 사건에 넣자」는 안(«선택»은 그 사건이 맞는 자리).

**승계 제약 처리.** 자산층 3규칙 → 새 수집면 0(통로 하나) · 🚫 데이터 오염 → 균등 노출 + 기운 뒤 제외 +

하지 않는 것 ㉢ → 반응률·소재 분포 학생 화면 0 · 하지 않는 것 ㉣ → 인덱스만 · **자유 서술 키 0** ·

#### U4. 발화 검문 «한 함수» + 몽글 시험지 + 모델 사건이 재심을 «준비»한다

#### U8. 자기설명을 Vellum 몫으로 + 재료의 급 자 넷 + **수신자 분포 자**

**장면.** 학생이 「어제」 화면을 열면 **왜 까몽이 어제보다 가까운지 아이가 압니다**(자기가 온 날) —
이것이 자기설명입니다. 그런데 소개서에 「자기설명」이 **0건**이고, 지도의 가름은 ①②③④ 에서 멈췄고,
귀 검수 답은 0 이고, Ⅰ-5 넷째 칸 0/53 은 **손 실측**입니다.
뒤에는 도구가 「자동 발송 N = 강사 a + 학부모 b + 학생 c + 내부 d」 꼴을 냅니다
(**합이 안 맞으면 «측정 불능»**).

**구조.** 분모 원천은 **발송 함수 정적 목록**입니다(운영 배치에 발송 원장이 0 이고 큐뿐이라 · 09-03 확인) —
함수마다 **수신자 태그 상수 한 곳**. 앱 테스트가 학생 화면 전수에 「첫 진입 한 줄」이 있는 수를 셉니다
(**렌더린트는 HTML 지면용이라 앱 화면을 못 봅니다**).
그리고 **서버→시트 읽기 통로 1**(서비스 키 입력 = 유호님 손 1회)이 시트 하류 셋의 **선행**입니다.

**정찰 근거.** 없음(외부 정찰 0).

**걷어내는 것.** 지도 「닿는 셋 = ①②③④」 · 「남은 것은 앱 입구」 · 소개서 옛 대장 표 ·
철학의 「53 중 0」 **손 실측 표식**(→ 도구 값으로) · 「발송 로그 파싱」(**로그가 없습니다**) ·
「자기설명 검수를 렌더린트에」(**앱 화면은 못 봅니다**) · **지어낸 수 하나**·손 수치 셋·인용 줄번호 셋.

**승계 제약 처리.** 재료의 급 → 「돌아간다」 ≠ 완성 · 귀 검수·눈 판정은 유호님 축 ·
자 축 → **값은 도구가 냅니다**(손으로 상태 안 적음) · **자기 분모 검사** → 합계 ≠ 갈래합이면 «측정 불능» ·
자격증명 → 서비스 키 입력은 유호님 손 · **커밋 0** · 소개서 → **원고가 정본 · 수치 손 기입 0**.

**대가.** 첫 진입 한 줄이 잔소리가 된다 · 값을 손으로 적어 낡는다 ·
**수신자 태그를 빠뜨린 발송 함수가 조용히 0 이 된다** · 통로 없이 하류 셋을 「0원」으로 적어 다음 세션이 오판한다
(**이번 수리가 잡은 것입니다**) · 소개서 ⑦⑩ 동행 누락.
→ **닫을 것 하나**: 수신자 태그 상수 + 이해 대장 절 + 앱 테스트 + **서버→시트 통로를 별도 걸음으로** +
매 착지 커밋에 ⑦⑩ 동행.

**자.** 자기설명 한 줄 없는 학생 화면 ÷ 전수(**지금 안 재봤다**) · 소개서 「자기설명」 0 → ≥1 ·
**수신자 분포(합계 = 갈래합 · 아니면 측정 불능)** · 귀 검수 0/5 → 5/5 · 소개서 수치 = 도구 값 ·
서버→시트 통로 0 → 1.
**효력**: **지금**. **닫히는 문**: 없음 — 단 **⑦⑩ 이 동행하지 않으면 정본이 「짓는 중」을 「없다」로 말합니다.**
