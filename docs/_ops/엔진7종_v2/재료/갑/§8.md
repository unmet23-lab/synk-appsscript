## §8. Prism — 쌓는 엔진 2호 · 대조

> **한 문장**: Prism 은 학생 하나의 교정을 **«몽골어 화자 일반은 여기서 틀린다»**는 분포로 쌓는 엔진입니다.
> 세로줄에서 Prism 은 **분모이자 자**입니다 — 「학생이 늘었다 / 모델이 바뀌었다 / AI 가 대신 썼다」를 가릅니다.

### 8-0. 지금(09-02 실측)

**돈다**: 재료 생산자(첨삭·검수)는 라이브.
**없다**: **집계층 코드 0** · 사전 분포 없음 · **산출 소비자 0** ·
태그가 **첨삭 모델의 자기보고**라 모델 판이 바뀌면 흔들립니다 ·
시험지 102문항은 **합성이고 사람이 굽습니다** · 재심은 08-10 이후 **0번** ·
자동 발음 판정 자 0(규격에 «후보» 설계만) · 자산층 규칙은 **문서 규율뿐**(어긴 날 아무도 못 봅니다) ·
받는 사람 = **내부** · 종점 = 사람이 읽는 지면.

### 8-1. 종류 변화

**기록(지도)** → **과학(예측 → 관측 → 대조 → 조준 → 심판)**.

⓪산출 계약과 접점 래칫이 문을 지키고 → ①첫 학생 «전»에 가설을 등록하고 →
②편집에서 태그를 «세고» → ③시즌마다 예측과 맞춰 보고(**판정 도장은 사람**) →
④다음 시즌 낱말·가중을 스스로 겨누고 → ⑤원음을 읽는 자를 세우고 →
⑥«왜» 틀리는지 원인층을 붙이고 → ⑦새 모델을 재채점하고 → ⑧강사에게 교안 카드로 돌아갑니다.

**수리에서 바뀐 뼈대 넷**: ①학생 행이 든 산출은 **공개 저장소에 0**(정본 = 비공개 버킷)
②시트↔도구 다리 = 시트가 이름 뗀 짝을 버킷으로 **밀어내고** 배치는 **구름에서** 돕니다
③유호 확정(낱말 11 · 6·3·2 배분)은 **«자»라 조준이 안 건드립니다**
④**음성은 외부 «사람»에게도 0**(정답지 화자 = 안의 성인).

### 8-2. 상향 아홉

---

#### U0. 산출 계약 검증기 + 접점 래칫 — **모든 뒤 상향이 지나는 문**

**장면.** 어느 밤 출제 가중치 입구가 「조사: 여격 4급 31%」를 읽으려 합니다 —
**기회 분모나 판이 없으면 거절되어 기본값으로 돕니다.**
같은 커밋에서 **학부모 주간 리포트 조립기**에 Prism 참조가 생기면 CI 가 빨개집니다.
유호님은 이해 대장 한 곳에서 「산출 행 N · 완비/전체 · 거절 N/M · 학생·학부모 접점 참조 0 · 등록 소비자 K」를 보십니다.

**구조.** 검증기({값·표본·분모·판·출처·키 출처} · **0 은 분모 동반** · 학생 행·원문 든 산출의 저장 경로 거절) +
**접점 등록층 파일**(갈래 학생·학부모·강사·내부 · 미등록 참조 빨강) +
래칫(**앱·서버 함수·시트 리포트 조립기 전부** · 학생·학부모 갈래 상한 0 ·
**«범위 안 파일 수 > 0» 을 먼저 확인** · 양성 대조 픽스처 1).

**정찰 근거.** 없음(내부 규율의 장치화).

**걷어내는 것.** 자산층 규칙의 **«문서 규율만» 상태** · 「자 없음」 줄 ·
대장 절 이름 「학생 접점 참조 0」 → **「학생·학부모 접점 참조 0」**.

**승계 제약 처리.** 하지 않는 것 ㉢ → 등록층 학생·학부모 갈래 참조 0(**내부 견줌은 통과** · 09-01 경계) ·
하지 않는 것 ㉣ → 저장 경로 거절 규칙(저장소 PUBLIC 실측) · 자산층 ③ → **분모 없는 행 거절** ·
Ⅰ-4 → 판정 칸은 사람 도장(**빈 값 허용**) · 🚫 0건 성공 얼굴 → 거절 N/M 과 «행 0» 을 가르고 파일 수를 먼저 셉니다.

**대가.** 등록층에 안 올린 새 소비자를 **영영 안 본다** ·
검증기가 엄해 초기 표본에서 전부 거절돼 **「0행 초록」**이 된다 · 경로 오기로 «못 본 0» 이 된다.
→ **닫을 것 하나**: 등록층 파일 + 래칫 범위 + **양성 대조 픽스처 1** + 저장 경로 거절 규칙을 한 커밋에.

**자.** 산출 행 완비율 · 거절 N ÷ 입력 M · **학생·학부모 갈래 참조 수(상한 0)** · 등록 소비자 수 · 범위 파일 수(>0).
**효력**: **지금**. **닫히는 문**: 없음 — 다만 **뒤 상향 전부가 이 문을 지나므로 첫 순서**입니다.
**유호님 판정 없음.**

#### U1. 가설 사전등록 + 외부 말뭉치 사전분포 — «예측 지도»로 개원한다

**장면.** 유호님 클릭 0 으로, 공개 통계 화면(오류 «위치» · 몽골어권)을 대응표로 24종에 사상하고
가설 여덟을 장부에 등록합니다 — **행마다 「재는 자(도구·판)」와 「조준 가능 시즌」이 필수**라
「겹받침 23.3%」는 「자 = 발음 파이프 자모열 비교 · 낱말 = 확정 11 안 둘 · 시즌 1」로 서고,
**재는 자가 없는 가설은 CI 가 등록을 거절합니다.**
**12월 파일럿이 실학생 제출을 낳는 순간이 문이 닫히는 날**이고, 그 뒤 등록 행은 «사후 등록» 표식으로 갈립니다.

**구조.** **두 판**으로 갈랐습니다 — «통계만으로 서는 판»(사전분포·대응표 · **신청 0**) /
«원시 문장 판»(30문장 검산 · 50문장 접붙임 · **이용 약관 확인 뒤**).
CI 자 = **등록일 < 첫 실학생 제출 사건 시각.** 사전분포는 **예측이지 규칙이 아닙니다.**

**정찰 근거.** 국립국어원 학습자 말뭉치 나눔터 — 오류 «위치» 주석의 국적별 통계 화면
(**몽골 항목 실재 · 층위·양상은 안 재봤습니다** · 통계 보기는 로그인 0 · 원시 자료는 신청·약관 뒤)
<https://kcorpus.korean.go.kr/service/goErrorAnnotArea.do> ·
(**낮춤**) 프랑스어 주석 논문은 **「주석자 일치도가 높아 유의하지 않을 수 있음 · 질적 관찰만」**이라
**대응표 검산 근거로 안 씁니다**.

**걷어내는 것.** 소개서 「몽골어 화자 데이터는 사실상 공백」(**쓴 것 축으로 좁힘**) · 「확인 전」 상태 서술 ·
**닫히는 문을 «달력»에 걸었던 옛 자**(→ 사건으로).

**승계 제약 처리.** 🚫 데이터 오염 → **사전분포는 출제·첨삭 초기값에 안 들어갑니다** ·
하지 않는 것 ㉣ → 외부 자료에 우리 식별자 0 · 자산층 ③ → 논문 값의 **분모 부재를 같이 적습니다** ·
늘리기만 → 대응표는 사상만 · 🚫 추정을 사실처럼 → **「위치 축 확인 · 층위·양상 안 재봤다」 표식**.

**대가.** **3축을 24종에 다대일로 사상하다 사전분포가 비틀려 «우리 학생이 다르다»가 대응표의 사실이 된다** ·
학원(영리) 신청이 막히면 원시 문장 판 둘이 같이 사라진다(→ 대체 자) ·
**파일럿 제출을 못 보고 달력에 걸면 2월 등록분이 사후 설명기가 된다.**
→ **닫을 것 하나**: 가설 행에 「재는 자·조준 가능 시즌」 필수 + **CI 자 = 첫 실학생 제출 사건** +
대응표를 **다른 세션이 검산**(≥24/30) + 사전분포 분모 미상 표기.

**자.** 사전등록 수(0→8) · **등록일 < 첫 제출 사건 = 전부** · 자 없는 가설 거절 수 ·
예측 행 ÷ 칸 수 · 대응표 일치율 · 시즌 1 «대조» 분포.
**효력**: 개원 전. **닫히는 문**: **첫 실학생 제출 사건**(파일럿이면 그날 · **안 재봤습니다**) —
그 뒤 등록은 «사후 등록»입니다. 24종에 빠진 축을 늘릴 자리도 같은 문이고,
외부 말뭉치 신청 리드타임은 **안 재봤습니다.**

#### U2. 편집 유도 태그 + 태거 정밀도 자 — **자기보고에서 «세는 것»으로**

**장면.** 검수 확정 밤, 시트 스윕이 **이름 뗀 짝**을 버킷으로 밀고, 배치가 어절 단위로 정렬해
편집 태그와 **«기회 수»**(조사 토큰 수 등)를 계산합니다.
「주세요→주시겠어요」 같은 **높임·어휘·화용 6종은 편집으로 못 세니 모델 라벨이 키**로 따로 섭니다.
개원 전 지면에 「결정론 18종 정밀도 0.87(합성 400)/0.71(실문장 50) · 해석 6종 따로 ·
분석 실패율 · 조사:기타 비율」.

**구조.** 정렬기는 형태소 분석기(모델 파일은 저장소 밖 캐시) · 실패 어절은 별도 값으로 **분모에 남깁니다**(24종 밖) ·
**사상표는 편집 태그 → 계약 오류 태그 «키» 매핑만**(24종 이름 정본은 계약 파일 · 회귀 = 치역 ⊆ 계약) ·
자기보고 태그는 **대조군 열** · 합성 벌 300~500 은 **평가 통로**로 굽고 시험 표식으로 격리 ·
검산 = 픽스처 62 일치 ≥56 + 분석 실패율 상한.

**정찰 근거.** 한국어 편집 유도 오류 주석 규격 2026-05-28 <https://arxiv.org/abs/2605.30545>
(**기능형태소·맞춤법·띄어쓰기·어순 네 갈래 — 높임·어휘·화용은 범위 밖**) ·
「불일치 ≠ 오류 · 분모 = 제출·기회」 <https://arxiv.org/abs/2605.07635> ·
L1 간섭 합성 벌 방식 <https://arxiv.org/html/2603.07366v1>.

**걷어내는 것.** **집계 키로서의 자기보고**(첨삭·검수 큐는 그대로) · 「같은 상수를 읽는다」 전제 ·
「값 목록은 사상표에서 파생」 문장 · 무료 티어 통로 문구.

**승계 제약 처리.** 자산층 ① → **새 수집 0**(짝의 재계산) ·
하지 않는 것 ㉣ → 짝은 이름 뗀 채 버킷(비식별 사본 · 우리 «안») · **공개 저장소에 실학생 원문 0** ·
하지 않는 것 ㉡ → 사람 칸 0 · 늘리기만 → 어휘 변경은 계약 판올림으로만 · 🚫 검증 불가 → 태그 판 + **키 출처 열** ·
🚫 오염 → 시험 표식 행은 집계·훈련·시험지 편입 금지 ·
이용 약관 → 외부 문장은 확인 뒤(재배포 불가면 저장소 밖 캐시 · **결과 표만 커밋 · 확인 날짜를 표 머리에**).

**대가.** 분석기가 초급 비문에서 실패해 실패 값이 쏠린다(→ 실패율 상한 · **분모에 남깁니다**) ·
**합성 오류가 «모델이 상상한 몽골 학습자»라 실학생 위 정밀도가 낮아도 자가 못 본다**(→ 실문장 정답지 나란히) ·
사상표와 계약이 갈린다(→ 치역 ⊆ 계약 회귀).
→ **닫을 것 하나**: 두 층 사상표(**매핑만**) + 키 출처 열 + 기회 수 열 + 실패 어절 규칙 + 치역 회귀를 **한 커밋**.

**자.** 정밀도·재현율 **두 층**(분모 = 합성/실문장 각각) · 픽스처 일치율 · 자기보고 불일치율 ·
분석 실패율 · 조사:기타 비율 · 기회 수 열 완비율.
**효력**: 개원 전. **닫히는 문**: 없음(짝 보존 · 소급 재계산) —
단 **계약 동봉(반 스냅샷·저작신뢰 등급)은 첫 실학생 행 «전»**이고, 두 저장소 어휘 분열도 그 전에 닫아야 재태깅이 1회입니다.
**돈**: 합성 500문장 ≈$1~3(**토큰 추정 · 실청구 안 재봤습니다**).

#### U3. 집계층 본체 = 가설 «대조»기 — **기계는 대조, 사람은 판정**

**장면.** 첫 시즌 종료 다음날 배치가 **시즌 판정 카드 한 장**을 냅니다 —
「조사: 예측 안(기회 대비 4.1% · 예측 3.8 · 제출 312 · **그중 덩어리 등급 41 은 별도 셀**) ·
어순: 예측 안 · 겹받침: 예측 밖(**자 미검증**) · 조사:기타 22% ▶ 새 축 후보 1 ·
조준 제안 2 · **「모델 변화를 못 걷어냈다」** · 문턱 30(**추정**)」.
유호님은 회고 자리에서 **«한 번»** 도장(지지/반증/미판정)·어휘 후보·거부권을 보십니다.
안 누르시면 **어휘는 안 늘고 제안은 반영되며** 계기판에 「사람 미판정 1시즌」이 뜹니다.

**구조.** 셀 = 유형 × 급수 × 과업 × 시즌 × 출처 · **중복 제거 키는 생산자별** ·
저장소 간 교차는 **출처별 분모 행**(합친 비율을 안 냅니다) ·
분모 셋 + 저작신뢰 셋(**덩어리·표식 제출은 별도 셀** · 등급 임계는 행에 안 굽고 재계산) ·
문턱은 **추정 표기** · 자연/조준/카드 뒤를 갈라 셉니다 · 정본은 버킷(**시트 없음**).

**정찰 근거.** 위 편집 태그 규격과 같은 자 · (**낮춤**) 정찰 범위에서 **L1 집단 축 제품은 못 찾았습니다** ·
제품 화면은 **안 재봤습니다**.

**걷어내는 것.** 「🕳 못 잡은 유형 N/23」 절 + **「6개월마다 열어본다」 손 절차**(같은 커밋 확정) ·
「Prism 집계층은 개원 직후」 판정줄(**갈라 적기**) · 「확인 전」 · 시트 표(정본 = 버킷) ·
**기계 열 이름 「판정」**(→ 「대조」).

**승계 제약 처리.** Ⅰ-4 → 기계 열은 «대조» · 사람 열은 «판정»(**빈 값 허용**) ·

**미판정이면 기본값으로 진행** · Ⅱ-9 → 저작신뢰 분모 셋 · **사람에 안 붙임** ·

**대가.** 생산자 넷이 같은 제출을 세 번 세어 **분모가 라벨 수로 부푼다**(→ 생산자별 키) ·

**정기 실행이 60일 무활동으로 꺼진다**(→ 48시간 자) · 미판정이 쌓여도 조용하다(→ 계기판).

**시즌 카드 한 장(기본값 규칙)** + 정기 실행 하나를 한 커밋에.

**자.** 채운 칸 ÷ 전체 칸 · 시즌별 대조 분포 · **사람 도장 ÷ 대조 행**(미판정 시즌 수) ·
어휘 후보 ≤1 · 배치 실행 ÷ 시즌 수 · 저작신뢰 별도 셀 수.
**효력**: 개원 전. **닫히는 문**: 없음(소급 재계산) —
단 **개원 전 코드가 없으면 첫 시즌 종료일의 첫 대조가 손으로 나가
「사람 손에 건 장치는 0번 돈다」가 재발합니다.**

#### U4. 능동 수집 조준 — **빈 칸이 다음 시즌 낱말을 바꾼다**

**장면.** 첫 시즌 종료 카드 끝에 조준 제안 —
「'맛있어요' 등장률 27%(제출 143 중 39) ▶ **같은 축(연음) 안** 갈아끼움 후보 '있어요' ·
숙제 뱅크 조사:여격 4급 ×1.5(예측 밖 셀)」.
유호님께 알림 한 줄 「**7일 안에 거부하지 않으면 반영됩니다**」 —
안 누르시면 둘째 시즌 첫 아침 낱말 하나가 바뀌어 있고 **숙제 카드 꼬리 한 줄이 그 낱말을 학생에게 «알립니다»**
(**짓는다 · 지금 코드 0**). 학생은 「왜」를 못 봅니다.

**구조.** 검증기 값 «안» = 갈아끼움(등장률 <30% · 시즌당 ≤3) + 가중(상한 ×2 · 하한 ×0.5) → **기본 반영** ·
값 «밖» = 총수 변경 · 축별 낱말 수 재배분 · 축 신설 → **승인 필수** ·
총수는 **상수 하나** · 읽는 입구 셋을 같은 커밋에.

**정찰 근거.** (**낮춤**) 대형 앱의 초급 회화 글에는 **공통 오류 패턴 언급이 0** 이었습니다 —
「정찰 범위에서 L1 집단 축 제품을 못 찾았다」로만 씁니다.

**걷어내는 것.** 「빈 칸 = 유도 숙제」 **손 전제** · 「정해졌다」의 «고정» · 「사람이 센다」 전제 ·
「사람 승인 1클릭」 형태 · **근거 없는 낱말 수 상한** · 「총수 11 고정」 계약값(**열린 유호 판정을 닫는 값**) ·
씨앗이 재실행마다 되살아나는 경로.

**걷지 않는 것.** 🔴 **「경음화 씨앗 +2」는 판정 대기 그대로 둡니다** —
08-31 배분 확정이 남긴 대기 항목(트랙 §0-발음 [유호] 줄)이라 **이 조준이 그 줄을 안 만집니다.**
배분은 «자»이고 조준은 «가중»이라, 대기가 풀리기 전에 조준이 먼저 손대면 자가 둘이 됩니다(§1-5).

**승계 제약 처리.** 유호 확정 승계 → 08-31 배분은 **«자»**라 **조준이 축별 낱말 수를 안 만집니다** ·
「낱말 11 은 AI 가 정한다」는 **고르는 손이지 배분 권한이 아닙니다** ·
하지 않는 것 ㉡ → 거부 한 칸(**사후 · 안 누르면 반영**) · 자산층 ① → 제안 행만 · 실행은 다른 자리 ·
하지 않는 것 ㉢ → 학생은 낱말만 봅니다 · 🚫 표본 0 규칙 → 제안은 관측 뒤 · 소급 오염 → **분모 불변 회귀**.

**대가.** **꼬리 한 줄 없이 첫 녹음이 쌓이면 목표 발화 기록이 「시켰다」로 거짓이 된다** ·
재실행이 옛 씨앗을 되살려 총수가 늘어난다 · **조준이 지도를 «만들어» 자화상이 된다**(→ 조준 여부 열) ·
거부권 알림이 묻혀 원치 않는 반영이 된다.
→ **닫을 것 하나**: **꼬리 한 줄 조판** + 씨앗 격리 + 총수 상수 하나 + 거부권 창 + 입구 셋을 같은 커밋에.

**자.** 반영 행 ÷ 제안 행(거부 따로) · 문턱 미달 칸 추이 · **축별 낱말 수 시계열(확정 무변)** ·
등장률(분모 = 지정 녹음) · 조준/자연 비율 · **학생 시간 0** · 꼬리 한 줄 도달.
**효력**: 첫 학생 뒤. **닫히는 문**: **«무엇을 말하게 했느냐»는 개원일부터 시즌마다 닫힙니다** —
꼬리 한 줄이 서기 전엔 **첫 녹음부터 거짓 기록**이라 **조준 배선보다 먼저**입니다.

#### U5. 발음 자 — **원음을 읽는 라벨러**(전사문 위 지도가 아니라)

**장면.** 개원 전 유호님·강사·검수자 **«본인»**이 낱말 11 을 세 번 읽고 **한 번은 일부러 틀리게** 읽습니다
(성인 · 본인 동의). 노트북 파이프가 **후보 둘을 나란히** 돌려 자모열을 내고,
**틀린 소리가 «틀리게» 남는지**를 받아쓰기 결과(「불고기」로 고쳐 씁니다)와 대조합니다 — 채택은 그 표로.
개원 뒤 원음 300건에 닿은 날, 시트 스윕이 이미 버킷에 복사해 둔 원음을 **예약 잡이 내려받아**
전량 초안을 사이드로 내고, **학원 소속 몽골쌤 귀 라벨**과의 축별 일치율을 같이 냅니다
(**외부 검수자에겐 음성 0**).

**구조.** 원음 → 시트 스윕 복사 → 내려받기 → 강제 정렬 → **인식 후보 둘** →
기대 자모열 **전량 비교** → 초안 키 사이드 파일 → 여는 판정 뒤에만 라벨 표에 ·
실행 장부(마지막 실행 · 원음 수/초안 수)를 대장 절에 · 굽기와 **잠금 파일 1**(램 충돌 방지).

**정찰 근거.** 강제 정렬기(Apache-2.0 · 한국어 포함) ·
비원어민 한국어 음소 인식 모델(**«영어 모어 화자의 한국어» 학습 데이터** — 그 한계를 그대로 적습니다) ·
「의도 vs 표면」(받아쓰기는 셀수록 오류를 «지웁니다») ·
(**안 재봤음 · 403**) 관련 논문 <https://www.mdpi.com/2076-3417/16/5/2426> ·
(**안 재봤음 · 표 미렌더**) 상용 발음 평가의 ko-KR 지원 — **둘 다 대조군이고 안 켭니다.**

**걷어내는 것.** 둘째 어휘 3값(→ 초안 키에 사상) · 규격의 «후보» 상태(→ 채택 실측) ·
「재전사 자 지금 없다」 · **「외부 검수자가 학생 소리를 귀로 라벨」 정답지** · 어휘 편향 방향.

**승계 제약 처리.** 🔴 **하지 않는 것 ㉣** 경계 ③ → **학생 음성은 모델 API·외부 도구·«외부 사람» 어디에도 0** —
정답지 화자 = **안의 성인**(본인 동의) · 개원 뒤 학생 소리 정답지는 **학원 소속 몽골쌤만** ·
버킷은 우리 «안» · 라벨 유예 → 초안은 사이드 · 어휘는 코드에 안 박고 키만 ·
「전사문에서 발음 안 뽑음」 · 하지 않는 것 ㉢ → 학생 화면 0 · 자산층 ③ → 노출 분모 · **«자 미검증» 도장** ·
램 → 분리 실행 + 잠금 파일.

**대가.** **인식기가 몽골 화자 소리를 «본 적 없는 소리»로 양방향 오인해 지도가 모델 무늬가 된다**
(→ 후보 둘 나란히 · 몽골어 모어 성인 오발음 벌) · 정렬이 자유 발화 속 낱말을 못 잘라 «없음»으로 쏠린다 ·
**노트북 꺼진 밤 = 실행 0회가 기본값**(→ 장부 · 계기판 빨강) · 스윕이 안 돌면 파이프가 빈손.
→ **닫을 것 하나**: 오디오 이동 통로 + **후보 둘 나란히 실측 표** + 초안 키 사이드 파일 + 예약 잡 + 실행 장부를 한 벌.
리허설 질문은 **「오류가 라벨에 남는가 · 받아쓰기 결과는 0 인가」**입니다.

**자.** 리허설 = 오발음이 자모열에 «남은» 수 ÷ 틀리게 읽은 수(후보 둘 각각) ·
축별 기계 vs 안의 귀 일치율 · 음소 오류율 · «없음»·«판정 불가» 비율 · 원음 수/사본 수/초안 수 ·
파이프 마지막 실행 시각.
**효력**: 개원 전. **닫히는 문**: **«첫 시즌 소리에 어느 자 판이 붙었나»**(시계열 첫 점) ·
**학생 음성 외부 반출은 첫 녹음 «전» 유호님 판정**(권고 = 안 내보냄) ·
개원 첫날 음성·전사 스윕이 라이브에서 켜졌는지는 **안 재봤습니다.**

#### U6. L1 전이 원인층 + «쓴 것 × 말한 것» 교차

**장면.** 시즌 2 뒤 교재 인계 지면 —
「4급 여격 → '에/에게' 31%(기회 대비 · n=203 · 예측 밖 · 원인 R03 · **자 미검증(정답지 전)**) /
같은 급수 말할 때 연음 미적용 44%(자모 비교 · 안의 귀 대비 0.78) /
**쓸 때 맞고 말할 때 무너지는 자리 = 받침 연음**」.
학생 답장은 Core 가 «자기 첨삭 한 건 안에서» 내는 「어제의 너」 규격이지 **Prism 사전을 읽지 않습니다.**

**구조.** 편집 태그가 **«먼저»** 서고 → 모델이 편집 태그·이름 뗀 원문·교정을 보고
**닫힌 규칙 ID 하나 + 근거 어절**(제출당 별도 호출 1 · **겸임 불가**) → 유형×원인×급수 집계 ·
사전(한국어 확정 · **몽골어는 검수 통과 행만**) · 교차는 **집단 단면만** ·
정답지 = **사람 라벨 텍스트 100문장**(**음성 0**) · 합성 벌 정밀도는 **«상한»으로만**.

**정찰 근거.** L1 간섭 규칙 목록 방식 <https://arxiv.org/html/2603.07366v1> ·
「원인 층만 모델이 편집 태그를 보고 덧붙이게 **순서 고정**」 <https://arxiv.org/abs/2605.30545>.

**걷어내는 것.** 「분포 ≠ 처방」 오독(**원인은 Prism · 통하는 법은 Temper**) ·
「대조 설명 사전 → 첨삭 정책층」 배선(**U0 래칫과 모순**) · 「첨삭 호출 겸임이면 0 추가」 문장 ·
「원인 정밀도 자 = 합성 벌」(→ 상한) · 소개서 「축 9」.

**승계 제약 처리.** 하지 않는 것 ㉣ → 원인 호출은 **이름 뗀 원문** · 정답지 100 도 이름 뗀 채(음성 아님) · 개인 행 0 ·
**하지 않는 것 ㉢**·자산층 ② → **소비자 셋 안에 학생 답장이 없습니다** · 미검수 몽골어 접점 금지 ·
🚫 Temper 경계 → 개입 열 없음 · 🚫 검증 불가 → 닫힌 목록 + 근거 어절 + 미분류 + **«자 미검증» 도장** ·
한 값 두 곳 → 첨삭 프롬프트의 그 절은 **사전에서 파생해 판올림**으로 갱신 ·
감정·태도 추론 0.

**대가.** **모델이 원인을 그럴듯하게 지어낸다**(→ 닫힌 목록·근거 어절·도장) ·
새 원인이 '미분류'로만 쌓인다(**그 비율이 늘리기 신호**) · 프롬프트 절과 사전이 두 판으로 갈린다 ·
교차 조인이 개인 행을 흘린다.
→ **닫을 것 하나**: **발주 항목 셋째(원인 정답지 100)** + «자 미검증» 도장 + 소비자 셋 명문 + 파생 판올림 규칙.

**자.** 원인 커버리지 · 사람 정답지 위 원인 정확도(**전에는 «미검증»**) · 합성 상한 · 미분류 비율 ·
몽골어 검수 통과율 · 교차 채운 칸 · 개인 행 0.
**효력**: 첫 학생 뒤. **닫히는 문**: 없음 —
다만 **규칙 목록·사전 골격은 교재 인계 시점, 정답지 항목은 10~11월 발주에 실어야** 첫 시즌으로 자를 검증합니다.
**돈**: 제출당 원인 호출 1 · 월 4,000제출 ≈$16(**토큰 추정 · 실청구 안 재봤습니다**).

#### U7. 모델 심판 고리 — **출시가 재채점을 돌린다**

**장면.** 새 모델 출시 다음날 「모델 출시」 항목이 서고, **중간 급이면 재채점이 저절로 돌아**
「후보 91/118 · 같은 판 재채점 현행 85/118 · 무응답 0 · 못 쟀다 0 · 비용 $1.8 · 모델 실측」이 앉습니다.
**상위 모델이면 「예상 $25/$49 · 클릭」 알림에서 멈춥니다.** 갈아탈지는 **유호님 픽.**

**구조.** 첫 커밋 = 평가 요청에 **`모델` 인자**(허용 목록은 기준선 파일 파생 · 밖은 거절) +
**응답 모델 실측 열** + 「배포판 ≠ HEAD」 실패를 **«못 쟀다» 행**(무응답과 다른 표식) ·

실학생 표집은 **승격 의사 ∩ 사용 동의** 층화 · 저장은 **버킷** ·

#### U8. 교안 카드 — 강사에게 돌아가는 첫 통로

**장면.** 몽골쌤이 그날 관찰을 확정하면 응답 꼬리에 카드 한 장 —
**머리 두 줄**: 「이 반 지난주 제출 38건에서 가장 많이 무너진 자리 하나예요 ·
**누가 틀렸는지는 세지 않았고 판정이 아니라 수업 재료예요** /
관찰 노트와는 별개 — **노트엔 이 카드를 옮겨 적지 않아요**」
→ 「처소 조사 14/38(기회 대비) · L1: 위치격이 «에·에서» 둘로 갈린다(검수자 확정) ·
오늘 서클 20분에서 이 문장 둘을」. **문턱 미달 주는 「이번 주 카드 없음」.**
그날 오후 학생은 「선생님이 딱 짚어 준다」고 느낍니다.

**구조.** 입력은 **반 단위 셀**(반 키 = 계약의 «반 스냅샷» 열) + 원인층(확정 표기만 · **자 미검증이면 L1 줄 생략**) ·
자리는 **관찰 확정 «뒤» 응답 꼬리**(새 화면 0 · **열람 = «응답 받은 사건»이지 «읽음»이 아님을 정직하게**) ·
저장은 전달 원장 + **개입 사건**(수신자 = 강사 · **「카드 없음」 주도 사건 = 대조군**) ·
관찰 오염 방지는 시각 가름 + **확증률 자**(겹침을 0 으로 만들지 않고 **셉니다**).

**정찰 근거.** 사람 튜터 감독형 AI 초안 — **승인율 76.4% · 새 주제 전이 66.2 vs 60.7(+5.5pp)**
<https://arxiv.org/abs/2512.23633> · 튜터 코파일럿(저평가 튜터 +9pp · 출처 갈라 적음) ·
「하나만» 돌려주는 형태.

**걷어내는 것.** 「주간 리포트 강사판 꼬리」(**실물 0** — 그 발송은 한 곳뿐) ·
「기존 자동 발송 원장에 강사 갈래 1 추가」(**그런 원장이 없습니다** · 53 은 호출 지점 수) ·
월요일 아침 장면(**관찰 «앞»**) · 「텍스트 축이라 관찰과 안 겹친다」(**겹칩니다**) ·
「닫히는 문 없음」 · 소개서에 «강사 교안 지면»이 **이름도 없던 것**.

**승계 제약 처리.** 하지 않는 것 ㉢ → 반 단위 · 이름·등수·학생별 값 0 · **문턱·빈 카드 규칙이 카드보다 먼저** ·
소수 반은 «없음» · 관찰 오염 → **관찰 입력 화면 표시 0** · 발송은 확정 «뒤» · **겹침은 확증률로 셉니다** ·

### 8-4. 하지 않는 것 (굵직한 것)

- **분모 없는 수를 내지 않습니다** — 0 도 분모 동반 · 문턱 미달은 **빈 칸** · 문턱은 **«추정» 표기**.
- **학생·학부모 접점에 Prism 산출이 닿지 않습니다** — 래칫이 참조를 이름째 거절합니다.
- **학생 행이 든 산출을 공개 저장소에 두지 않습니다** — 정본은 비공개 버킷.
- **학생 음성을 모델·외부 도구·«외부 사람» 어디에도 안 보냅니다** — 정답지 화자는 **안의 성인**.
- **자기보고 태그를 집계 키로 쓰지 않습니다** · 해석 6종을 편집으로 억지로 세지 않습니다.
- **기계 열을 «판정»이라 부르지 않습니다** — 기계는 «대조», 사람이 «판정»(**빈 값 허용 · 미판정이면 기본값 진행**).
- **축별 낱말 수(유호 확정 배분)를 조준이 만지지 않습니다** · 어휘는 **시즌당 ≤1 축**만 늘립니다.
- **시험지를 모델에 맞춰 고치지 않습니다** · 판 다르면 대조 금지 · **무응답·«못 쟀다»를 점수로 적지 않습니다.**
- **자동 재채점이 비싼 모델을 태우지 않습니다** — 중간 급만 자동, 상위는 알림 → 클릭.
- **원인을 열린 서술로 받지 않습니다** — **닫힌 규칙 목록 + 근거 어절 + 미분류** ·
  사람 정답지 전에는 **«자 미검증» 도장**.
- **감정·태도 추론 0.**
- **교안 카드를 관찰 «앞»에 보내지 않습니다** · 관찰 입력 화면에 표시 0 · **겹침을 0 으로 위장하지 않고 셉니다.**
- **새 수집면·새 폼·새 시트를 만들지 않습니다** — 짝의 재계산과 있는 자리의 꼬리뿐입니다.
