## §10. Reed — 무대층(셋째 줄) · 24시간 라디오 · 앱 자습 소리

> **한 문장**: Reed 는 **«배움이 일어나는 자리»**를 만드는 엔진입니다.
> 닿는 셋도 쌓는 셋도 아닌 **셋째 줄**이고, 유호 확정 08-26 에 따라 **Atlas 에 기여하지 않습니다.**

### 10-0. 지금(09-03 실측)

**돈다**: 곡 팩 8벌(69분)과 유호님이 읽는 곡 성적표.
**짓고 있다**: 판정층 넷(곡 장부·편성·판 규격·반응)은 섰습니다.
**없다**: **저장·실배선 0 · 곡시계 0**(복사 방식 루프는 시계를 모릅니다 · 앵커를 적는 열 0) ·
**앱 재생기 0**(부품 파일이 «앱에 없는 조작»이라고 스스로 적어 두었습니다) · **방송 0일** ·
**관측 축 0** · 대체불가 3문 **셋 다 못 지남** · 이해 대장 어느 칸도 안 채움 ·
받는 사람 = 내부(유호님) · **자 0**(곡 물량이 두 값으로 갈려 있습니다 — 69.0분 / 68.2분).
그리고 어휘가 갈렸습니다 — 같은 낱말 «결»이 한 곳에선 시간대, 다른 곳에선 장르입니다.

### 10-1. 종류 변화

**무대 도구** → **자리-엔진**.
입력이 «시계 하나»에서 **«시계 + 학원의 지금 + 그 학생의 띠» 셋**이 되고,
관측 축 하나 — **«앉아 있던 창의 길이와 위치»**(제출은 점, 청취는 구간 · **본인도 제 구간 길이는 모릅니다**) — 를 엽니다.

🔴 **정직하게**: Reed «자체»의 3문 ① 답은 **여전히 「작아진다」**입니다(편성·생성 도구는 시장에 있습니다).
「커진다」로 뒤집히는 것은 **Reed 가 자리를 내준 Core 의 ㉡(사람) 층 «언제 집중이 오르는가» 축**이고,
그 축의 **생산자는 Vellum 앱**, **소비자는 Core** 입니다 — **Reed 는 생산자가 아닙니다.**
그래서 지도의 「Reed 는 Atlas 에 기여하지 않는다」 문장을 **그대로 둡니다**(§13-4 · D8 ④).

#### U1. 곡시계 + 곡 장부 저장 — **그릇을 송출 첫날 «전»에**

**장면.** 송출 첫 밤 23:10, 봇이 60초마다 「지금 17명」을 적는데 **그 순간 어느 곡이 나갔는지 아무도 모릅니다** —
복사 루프는 시계를 모르고, 인코더가 죽었다 살면 목록은 1번 곡부터 다시 도는데 방송 주소는 그대로입니다.

**구조.** ①**앵커 = 인코더 프로세스 시작 시각**을 서비스가 파일에 적고 봇이 매 심박에 실어 보내
새 열 둘에 박습니다(재발견마다 방송 구간 행도 남깁니다).
🔴 **방송 «실제 시작 시각»은 앵커로 안 씁니다** — 재시작을 못 가릅니다.
②곡시계는 **순수 함수 하나**(앵커 + 목록 + 트랙 길이표 → 「이 시각의 곡·장르·바퀴」) ·
길이표는 목록 만드는 단계에 길이 재기를 더해 적습니다(**지금 0줄**).
③귀속은 **도구가 조인**합니다 — **데이터베이스 뷰로는 못 짓습니다**(JS·JSON 을 못 읽습니다) ·
**「앵커가 빈 심박 행은 귀속 분모에서 뺍니다」.**
④**어휘 통일** — «결»을 «장르»로 개명하고 장르 이름을 한 곳으로.

**정찰 근거.** 없음(내부 실물 정리).

**걷어내는 것.** 크레딧 문서의 «장부 대역» 역할(정본 → 파생) · 문서 직독 게이트 ·
«결» 낱말의 장르 뜻 · 소개서 「장부·편성·되돌아오는 축 코드 0」 문장(**참 문장 = 「판정층 넷은 섰고 저장·배선 0」**).

**승계 제약 처리.** 자산층 ① → **새 파이프라인 0**(심박에 앵커 «칸» 둘을 더할 뿐) ·
하지 않는 것 ㉢ → 관측은 「몇 명」뿐 · 식별 0 · 하지 않는 것 ㉣ → 익명 집계 ·
🚫 소급 불가 → **송출 시작 «전»에 앵커·곡시계·판 표식이 서야 첫날부터 귀속** ·
🚫 재현 불가 → **재현 칸 「모른다」는 거절** ·
0건 성공 얼굴 → **심박 빈 값과 앵커 빈 값을 둘 다 분모에서 뺍니다**.

**대가.** 앵커 파일이 없으면 귀속이 통째로 안 된다 · 재시작이 잦으면 바퀴가 밀린다 ·
어휘를 반만 통일하면 두 뜻이 남는다.
→ **닫을 것 하나**: 앵커 생산자·곡시계·판 표식·저장을 **한 커밋**에.

**자.** 곡 귀속 없는 심박 비율(앵커 빈 행 제외) · 곡당 관측 수 · 재현 칸 없는 채택 0 · 곡 검증 8/8.
**효력**: **지금**. **닫히는 문**: **송출 첫날** — 그릇 없이 튼 기간의 곡 단위 체류는 **영영 빈칸**입니다.

#### U2. 앱 자습 자리 — **자습 체류가 ㉡(사람) 층으로 간다**

**장면.** 밤 11시, 학생이 폰을 잠그고 책을 폅니다. 홈 화면 가이드 곁의 **«켜기 카드» 하나**를 눌렀을 뿐입니다 —
**별도 화면은 없습니다.** 라디오는 **내려받은 앱 판**이고 기기 안 곡시계가
「지금 방송에선 차분 3번 곡 2분 지점」을 계산해 **같은 곡**을 틉니다.
잠금 화면 카드에 펠트 무대 정지 그림 + 불빛 + 켜기 하나 · **글자 0.**
처음 켜면 가이드 효과음 하나 + **한 낱말 라벨**(몽골어 · 검수 게이트)이 «안내»입니다.
켠 시각·끈 시각·곡·끝 사유가 사건으로 남습니다.
다음 날 학습자상태 집중띠축이 그 행을 **«시각 재료»**로 읽어
「이 학생은 화·목 22~24시에 앉아 있다」가 실값으로 서고, 배달이 과제요약에 싣습니다.
**학생은 아무 숫자도 못 봅니다.**

**구조.** 새 사건 하나(**「봤다」 사건을 재사용하지 않습니다** — 그 사건은 부모가 필수라 검증기가 즉사시킵니다) ·
소비자는 **같은 커밋**에 · **두 겹 자**로 거릅니다(켜 두고 잔 시간이 «집중»으로 굳지 않게).

**정찰 근거.** 앱 오디오의 배경 재생 <https://docs.expo.dev/versions/latest/sdk/audio/>
(정찰 항목의 **앱 측 절반만** 씁니다 — 스트리밍 절반은 안 씁니다) ·
유튜브 임베드는 배경 재생이 유료 전용이라 **원리상 못 잽니다** ·
화면 없이 듣는 자리 사례(**도움말 실검 범위까지만 · 나머지는 안 재봤습니다**).

**걷어내는 것.** 「앱 자습 라디오 = 유튜브 임베드」 가능성 ·
「누가 얼마나 들었나는 원리상 0」의 **앱 판 부분** ·
🔴 **「새 수집 0 · 있는 값 보내기만」 문장**(→ **「새 사건 1 · 생산자 Vellum · 소비자 Core 같은 커밋」**으로 정직하게) ·
스트리밍 안 · 「앱 재생기 화면 1벌」(→ 손잡이·카드).

**승계 제약 처리.** 자산층 ① → **새 파이프라인 0**(원장 한 통로) · **새 화면 0**(카드 1) ·
생산자는 Vellum(닿는 셋이라 수집면을 세울 수 있습니다) · 소비자는 Core · **Reed 는 규격만** ·
하지 않는 것 ㉢ → 분·순위·평균·다른 학생 띠 0 · **불빛은 수 없는 불빛** ·
하지 않는 것 ㉣ → 우리 «안» · 모델 호출 0 · Ⅰ-4 → «앉아 있다»는 관측이고 **「밤형」 라벨 저장 ✗** ·
Ⅱ-8 → 별도 화면 0 · 🚫 소급 불가 → **재생기 + 사건 + 소비자 한 커밋** · 파일럿 첫 밤 전.

**대가.** 앱 오디오가 잠금 뒤 끊겨 **사건이 «조용히 0건»** · 켜 두고 잔 밤이 「저녁 띠 집중」으로 읽힌다(두 겹 자) ·
**판올림이 관통 시험을 깨면 세로줄 자가 빨개진다**(같은 커밋에서 재실측) ·
기기 시계가 틀리면 «함께» 위치가 어긋난다(**서버 앵커 한 값**) · 카드가 홈 화면을 계기판처럼 만든다.
→ **닫을 것 하나**: **회귀 세 축 동시** — ①리듬·끈기·자기인식 산출이 이 사건 유무에 **불변**
②**집중띠만 변함** ③라디오 통로 판별이 거짓이고 신뢰도가 불변.

**자.** 이해 대장 **㉡(사람) 층** 재료 종류 2→3 은 **Core 행에** 적고, **Reed 절에는 「앱 자습 켠 학생 ÷ 로그인 학생」**(자리 제공) ·
집중띠에 든 행 ÷ 전체 행(**두 겹 자 통과율** · 0 이면 축이 빈 것) · 관통 V2 에 집중띠 실값 ·
**행 수 ÷ 학습자상태가 읽은 행 수**(도달 래칫). **첫 값 = 파일럿 첫 주.**
**효력**: 개원 전. **닫히는 문**: **앱 자습을 트는 첫날부터 매일**(12월 파일럿 첫 밤 · 한 번뿐) —
그 전에 재생기 + 사건 + 소비자가 한 커밋으로 서야 그 기간의 리듬이 안 빕니다.
**돈**: 0원 · 데이터 = 1시간 팩 ≈55MB(**몽골 회선은 안 재봤습니다**) · 유호님 폰 개발 빌드 1회.

#### U3. «내 리듬» — 편성 입력이 시계에서 **그 학생의 띠**로

**장면.** 3주 뒤 같은 밤. A 는 22시에 켜고 23시 반에 제출이 잦습니다 —
A 의 앱에는 밤 결이 방송보다 **한 시간 «일찍»** 깔립니다.
B 는 23시에 켜서 새벽까지 앉습니다 — B 의 결은 방송 기준 그대로입니다
(**늦춤은 없습니다** — 편성이 늦은 밤을 따라가지 않습니다).
**둘 다 이유를 모릅니다.** 자습실 스피커 시간대엔 두 폰 다 «함께».

**구조.** 편성 함수의 입력이 **객체**가 되고 학생 띠가 빈 값이면 **지금과 같은 답**입니다.
조정 폭은 **«밤 결 도착 0~−60분(앞당김만)»과 «자연층 비중 ±»만**이고 **곡은 안 바꿉니다.**
계산은 서버에서 하고 **개입 도장은 값이 직전과 다를 때만 · 학생당 하루 ≤1**이며
**도장 없이는 편성이 안 바뀝니다**(회귀).
활성 게이트는 띠 수 ≥2 · 표본 ≥ 별도 상수(**첫 값은 30일 뒤** · 다른 자에서 빌리지 않습니다).

**정찰 근거.** 화면 없이 듣는 자리 사례(도움말 실검 범위까지만).

**걷어내는 것.** 편성 함수의 «시계만 읽는» 형태 · 소개서 「개인 성향은 원리상 못 잰다」의 **앱 판 부분** ·
**출처가 틀린 반례 하나**(그 글에 해당 내용이 없어 실검 뒤 지웠습니다).

**승계 제약 처리.** 하지 않는 것 ㉢ → 화면에 「왜 이 결인지」 0 · 학생 간 차이는 도착 시각·자연층 하나뿐 —
**경계 판정은 유호님 자리**로 올립니다 · Ⅰ-4 → 조정은 «맥락 싣기»이고 **«밤형» 저장 ✗ · 리포트에 안 나감** ·
안전·실현 거부권 → **앞당김만**(회귀) · 늦춤이 필요한지는 **회고 강사 열의 재료로만** ·
🚫 표본 0 → 인자만 받고 **게이트 전 무동작** · 🚫 검증 불가 → **도장 + 30일 짝 없이는 안 켭니다** ·
도장 빈도 상한으로 **「개입 1225 대 관측 1」 무늬를 막습니다.**

**대가.** 켜 두고 잔 시간을 «집중 피크»로 읽는다 · **학생마다 갈라져 「함께」 감각이 깎인다**(기본 «함께» + 스위치) ·
조정 사실이 리포트로 새어 낙인이 된다 · A/B 를 못 갈라 효과 0 인지 못 본다 ·
**게이트 상수를 표본 0 에서 박는 실수**(별도 이름 + 30일 뒤 첫 값).
→ **닫을 것 하나**: 활성 게이트 + **도장 회귀 한 벌**(띠 부족 → 빈 값 · 도장 없으면 편성 불변 ·
앞당김만 · 자습실 빈 값 · 하루 ≤1 · 읽기 요청에서 쓰기 0).

**자.** 도장 완비 · 30일 짝 연결률(**개입 갈래 축**) · 조정 뒤 같은 띠 «앉아 있음» 분 변화(**어제의 그 학생**) ·
회고 강사 열 「자습 자리가 맞았나」 채움 ÷ 회고 수 · 「내 자리」 켠 비율.
**효력**: 첫 학생 뒤. **닫히는 문**: 없음 — 단 **U2 의 행이 첫날부터 있어야 이 자리가 열립니다.**

#### U4. 편성이 방송에 «닿게» — 24시간 펼침 + 학원의 지금

**장면.** 새벽 3시의 방송. **지금은 1시간 목록이 24번 돌아 새벽에도 시티팝이 나옵니다.**
판정이 열리면: 21~06시는 차분 블록(자연층 변주를 번갈아), 06~21시는 시티팝, 경계엔 전환 계단.
**숙제 마감이 몰린 저녁·자습 체크인이 몰리는 시간대엔 차분 블록이 길어집니다.**

**구조.** 편성 정본이 목록을 **펼칩니다.** 「학원의 지금」은 **신설 순수 함수**로
①과제 마감 밀도 ②자습 체크인 시각 분포를 28일 굴림창으로 봅니다 —
**개인 칸 0 · 표본 하한 미만은 빈 값** · 「시험 D-일」은 **원천 표가 0 이라 첫 판에서 뺐습니다.**
🔴 승격 요약을 편성 입력으로 **안 씁니다**(그 함수는 기술별 응답·오답만 내고 입력이 0 입니다 — 오독 정정).

**정찰 근거.** 없음. 🔴 **24시간 펼침의 근거를 «정책 위험»으로 세우지 않습니다** —
실검 결과 그 정책은 **라이브를 표적으로 삼지 않습니다.** 근거는 **자 하나**(결 바닥이 «결마다 다르게» 서야 편성이 닿은 것).

**걷어내는 것.** 목록의 «차례 그대로 한 바퀴» 출력(판정 뒤) · 편성 결표의 «방송 미적용» 상태 ·
차례 상수의 «생산 비율» 역할 · **오독한 재사용 문장** · 정책 위험 근거 · 다른 송출 도구·실시간 생성 안.

**승계 제약 처리.** 유호 확정 09-02 「1시간 팩 24시간 무한반복」 → **뒤집지 않습니다** ·

#### U9. 세로 동시 송출은 **«우리가 안 굽는다»**

**장면.** 학생이 폰 세로 피드에서 라디오를 만납니다 —
세로 화면 가운데에 무대와 몽글, 각인이 **잘리지 않고** 있습니다. **송출 설정은 한 글자도 안 바뀌었습니다.**

**정찰 근거.** 방송 도구 공식 도움말(**시작 뒤 세로 제거 불가**) <https://support.google.com/youtube/answer/2474026> ·

**걷어내는 것.** 세로판 자체 인코딩 일감 · 오버레이 두 벌째 지면 · 「두 벌 vs 반응형」 판정 ·
🔴 **「가로 프레임 중앙 1080×1920 안전띠」 상수** — **720p 송출에선 존재하지 않는 띠**라
폭의 84% 를 통과시키는 **거짓 초록**이었습니다.

**승계 제약 처리.** 하지 않는 것 ㉡ → 유호님 클릭 1회(API 부재 · 상시 아님) ·

**잘못된 자로 닫지 않도록 실제 크롭 PNG 를 눈으로** 봅니다.

**대가.** 중앙 크롭이 마스코트·각인을 자른다(비율 게이트 + 크롭 PNG 가 잡습니다) ·

**자.** 안전띠 검사 통과 n/N · 크롭 PNG 확인 4/4 · 실물 1/1 · **세로 관련 코드 변경 0줄** · 세로 유입.
**효력**: **지금**. **닫히는 문**: **스트림 시작 «전»**(시작 뒤엔 세로를 못 뺍니다).

### 10-4. 하지 않는 것 (스물여섯 중 굵직한 것)
