## §14. 재는 자

값은 도구가 냅니다. 손으로 상태를 적지 않습니다. 다섯 묶음으로 나눠 읽습니다. 세로줄과 도달 · 개입과 효과 · 학생 접점 · 엔진별 · 작업 시스템과 사람과 돈.

> **[실재]** = 지금 있는 도구 · **[짓는다·N]** = N걸음에서 세울 것 · **[첫 학생 뒤]** = 학생 0명이라 지금은 못 재는 것.
> 자가 서기 전의 「0건」은 **«안 재봤다»**입니다. «0/0» 도 «안 재봤다»이지 0 이 아닙니다.

### 14-2. 개입과 효과

| 재는 것 | 계기(도구) · 상태 | 분모 · 언제 |
|---|---|---|
| 개입 스탬프 완비율 + arm 분산(상태셀당 distinct arm_id · 결정론 판 = 1 «대조 불능») | [성과계기판 실재 · test 5→7 걸음 3] talk `tools/성과계기판.js` · `tests/개입스탬프.test.js` | intervention.delivered 행. 08-24 손 값 4,468 은 안 재봤다. 과녁은 운영 첫 주. |
| 개입→효과 연결률 · 방향 적중 n/도래. intervention_kind 다섯을 갈라 셉니다(+report 는 D25). | [성과회수 실재 · v3 걸음 3] `lib/성과회수.js` v3 + 성과계기판 ① | 보상 창 닫힌 intervention_kind 노출 수 · 첫 학생 30일 뒤 |
| 섀도 대조: 갈린 결정 n/전체 · 판올림→활성 일수 | [걸음 16] lib/섀도대조(성과회수.js 안 함수) · 처방판재계산(성과계기판 --판사건 · 로컬) | 전체 결정. 하한 30 미만은 못 쟀다. 첫 판올림 뒤. |
| 요약 예측력(판×코호트 합산 홀드아웃 Brier vs 빈도 기준선) | [걸음 10] talk `lib/요약채점기.js` · 주 1회 | 합산 홀드아웃 n. n<100 이면 못 쟀다. 시뮬은 자만 검증합니다. |

읽는 법
- 개입 스탬프 = 개입 한 건마다 붙어야 할 도장. 완비율 = 도장이 다 붙은 비율. intervention.delivered = 개입이 실제로 나갔다는 사건 행.
- 리허설 n 은 성과계기판 실행 날짜·판과 함께 적습니다. 날짜 없는 수는 안 씁니다.
- arm_id = 실험 갈래 번호(A안이냐 B안이냐). arm 분산 = 한 상태칸에 서로 다른 갈래가 몇 개인가.
- 결정론 판은 늘 한 갈래만 내니 1 이 정직값입니다. 「대조 불능」이라는 뜻입니다. 그래서 완비율 100% 를 «대조 가능»으로 읽지 않습니다.
- intervention_kind = 개입 종류. 보상 창 = 효과가 나타나기까지 기다리는 기간. 창이 닫힌 뒤에만 셉니다.
- 갈래=과제는 «생성»과 «시트층 재출제»를 갈라 셉니다. 둘은 만든 곳이 다릅니다.
- 섀도 대조 = 새 판을 실제로 안 쓰고 옆에서 같이 돌려 답을 비교하는 것. 갈린 결정 = 옛 판과 새 판이 다르게 답한 자리.
- 코호트 = 같은 시기에 들어온 학생 무리. 홀드아웃 = 채점에만 쓰려고 빼 둔 몫.
- Brier = 예측이 얼마나 맞았나를 0~1 로 재는 점수(낮을수록 좋다). 빈도 기준선 = 그냥 평균으로 찍었을 때의 점수.

읽는 법

- ai_assist 표식률 = 「AI 도움 받았다」 표식이 붙은 제출의 비율. 「안 고름」은 0 이 아니라 미표식입니다.
- 발화검문 = 몽글이 말해도 되는 문장인지 거르는 검문. 런타임=시험지 = 실제로 도는 검문과 시험지가 같은 파일.
- 권유형 = 「~해 보세요」 꼴. 활성전약속 = 아직 안 켜진 기능을 약속하는 말.
- S20 = 힘든 날. 그 다음날엔 묻지 않습니다. 세층합류 §5 에 값 잔존 0 = 예산 값의 정본은 한 곳뿐이라는 뜻입니다.
- Patina = 학생의 사건이 부품·지면으로 바뀌는 층. 서수 = 「1등·2등」 같은 순위 말. 룸잉크 = 지면 밝기 자.
- DTCG diff = 디자인 값 표준 꼴 파일과 정본의 차이. 토큰내보내기 CI 가 셉니다.
- 산문 두 판 = 학생판과 강사판. 학생판에는 관찰 원문과 교실 개입이 비쳐서는 안 됩니다.
- RLS = 행 단위 접근 규칙. 누가 어느 행을 볼 수 있나를 DB 가 막습니다. 픽스처 학생 auth 계정 = 시험용으로 만든 학생 로그인 하나.
- my_trail = 학생 자신의 발자취 행. 횡단 갭 ⑫ = 정책 원문만 있고 실조회는 안 한 자리.
- 재미 자의 유호님 판정 = 펠트 컷·소리·몸짓을 나란히 놓고 고르십니다. 자만 세우고 값은 첫 시즌 뒤입니다.
