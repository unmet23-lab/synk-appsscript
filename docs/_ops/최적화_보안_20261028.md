# 2026-10-28 코드 최적화와 보안

사용자가 승인한 네 범위는 CI 체크아웃·의존성, 회사 게시물 성과 비교, PC 회원 화면 묶음, WORLD 초기 계정 묶음이다. Claude 주간 한도 때문에 이번 작업에 한해 GPT 구현과 독립 GPT 검수를 사용하도록 직접 승인받았다. 기본 모델 정책은 바꾸지 않고 `optimization-security-20261028`의 원천·후보 해시와 정확한 경로만 검수 도구에 연결했다.

바이트 수는 전송 압축 전 파일 크기다. 비교값은 각 기록의 줄끝·대상 목록을 고정해 측정했다. 원천 빌드와 실제 공개 후보의 수치를 서로 대신 쓰지 않는다.

최신 원격 `fa79b062`의 학습 원천까지 합친 통합본은 별도로 다시 생성했다. 같은 최신 원천의 최적화 전 묶음은 1,461,835바이트이고, 실제 의존 경로 주석 3,185바이트까지 포함한 최적화 후 묶음 1,055,984바이트에 공유 생활 콘텐츠 65,929바이트를 합친 1,121,913바이트는 23.25% 작다. 위 표의 최초 909,885바이트와 앞선 원격 통합 때의 909,899바이트는 각 당시 원천의 고정 비교값이다. 최신 원천 증가는 기존의 절대 1MB 시험 상한과 구별하며, 회귀 시험은 같은 원천의 최적화 전 빌드와 공유 모듈을 포함한 크기를 비교한다(2/2 통과).

## 보안과 검증

- Electron 44.5.1의 인증서 검증 관련 [GHSA-jr5w-w6x2-84p9](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9)를 확인해 44.10.0으로 올렸다. 현재 빌드 도구의 버전 고정값도 맞췄으며 과거 0.4.3 설치물 설명은 바꾸지 않았다. 의존성을 함께 갱신한 뒤 루트·계정·desktop `npm audit`는 취약점 0건이다.
- 회원 화면 회귀 263개, 생성물·공개 묶음 최종 대조 39개, 보안·인증·업데이트 관련 144개 시험을 통과했다. 겹치는 시험은 합산하지 않는다. 실제 Electron 최종 동결 후보 20/20: 늦은 계정 A 응답의 계정 B 침범 차단, 동의 분리, 로그아웃 정리, 초안 자동 전송 없음, 외부 요청·CSP 오류 없음.
- 1440·390폭은 넘침 없음. 320폭의 기존 좁은 회원 화면 넘침은 전후 동일하며 이번 변경의 개선으로 보고하지 않는다. 옛 제목을 기다리는 기존 native smoke의 실패는 보존하고 실제 변경 동작을 별도 격리 시험으로 확인했다.

- 회사 배포 후보는 완료된 이전 릴리스에 해당 원천 세 파일만 얹었다. 경로가 긴 Windows 임시 폴더에서 SQLite WAL 파일을 만들지 못한 첫 실패를 보존하고, 같은 후보·실행기·격리 조건의 짧은 경로에서 3,332/3,332개를 통과했다.
- 실제 Linux 격리 이미지에서도 선택 시험 3,332개와 이미지 호환 시험 2개, 총 3,334/3,334개를 통과했다. 운영 데이터 미장착·호스트 포트 미노출·외부 통신 차단 상태이며 소스 1,222개·이미지 입력 884개의 해시와 운영 서비스·설정 불변을 대조했다.

전체 저장소의 Windows 추적 실행은 모두 성공한 것으로 계산하지 않는다. 형제 저장소와 git 밖 자산 부재, 공급자 원본의 줄끝 해시, Git Bash 하위 명령 시간 초과 등이 남은 실행을 별도 기록했다. 최종 Linux CI와 운영 후보의 격리 시험을 각각 확인한다.

## 추가 요청: 플랫폼에서 PATH 숨김

사용자가 확정한 범위는 「플랫폼 목록·검색에서만 숨김」이다. 공개 PATH 웹페이지·직접 주소·이용 권한은 바꾸지 않고 플랫폼의 앱 목록·검색·트레이·추천에 적용한다. 기존 PATH 메모·할 일·즐겨찾기는 보존하고 즐겨찾기를 재정렬할 때도 숨겨진 항목의 자리를 유지한다. 웹 플랫폼 목록에는 이미 PATH가 없어 PC의 세 화면 모듈만 바꿨다.

원천·빌드 입력 독립 GPT 검수 지적은 0건이다. 제품 회귀 91/91·요청 범위를 고정하는 검수 정책 51/51·격리된 실제 Electron 46/46을 확인했다. 마지막 시험은 합성 IPC로 로그인 전후·설치 유무·검색·추천·기존 기록 보존을 확인한 것이며 실제 운영 계정 시험으로 확대하지 않는다. 1440·390폭의 넘침·콘솔 오류·외부 요청은 0건이었다. 390폭 그림만으로 가려진 앱 전체의 부재를 단정하지 않고 DOM 결과도 대조했다.

최종 원천 통합 중 원격 Atlas 정책 변경만 별도 보존 병합해 같은 독립 GPT가 새 지적 0건으로 확인했으며, 정책 파일 SHA256은 `252d3f824540bcbf052361b9608161cb0a9980cc93833936a53be32027fd80a3`이고 관련 정책 시험 187/187과 그 안의 PATH 51개 독립 재실행을 통과했다. 이 추가 판정은 해당 원천 정책 차이만 대상으로 하며, 기존 원천 7개·빌드 입력 4개·0.4.49 공개 후보의 승인 해시는 보존하고 실제 배포 바이트를 새 정책으로 다시 승인한 것으로 바꾸지 않는다.

PC 0.4.49의 빌드 입력은 `87252541ec86123692c82e399de538e4b7ddf733`, 원천 해시는 `8cf9116a868b6eddab56430fefb73986a344313c8e89decb0d89218c6c779164`다. [세 운영체제 빌드·실기 검사 40664576447](https://github.com/unmet23-lab/synk-policy/actions/runs/40664576447)는 모두 성공했다. 전체 설치물 SHA와 ASAR·원천 175개를 연결해 대조했으며 부속 앱은 앞선 0.4.48의 보안 패치 설치물을 그대로 사용한다. Mac 설치 안내의 초기/홈 화면 캡처와 Intel Mac 두 부속 앱의 어두운 DMG 캡처는 해당 화면의 시각 검증 근거로 쓰지 않는다. DOM·아이콘 파일 해시·밝은 화면의 확인과 구분하며 Dock 전체가 정상이라는 주장도 하지 않는다.
