# 까몽 표정의 털 고정 · 배경 경계 통합

2026-09-09 사용자 요청: 다른 작업에서 고친 털 고정을 실제 라디오에 적용하고, 앞으로 모든 마스코트의 표정 변경에 같은 기준을 유지한다. 배경에서 스티커처럼 도드라지는 경계도 완화한다.

## 적용

| Before | After | Why |
|---|---|---|
| 라이브는 예전 라디오DJ 표정 파일을 참조 | 승인된 `65f92a753bb5416b`의 공통 털 8컷 사용 | 눈이 바뀔 때 몸·털·옷이 갈리지 않도록 |
| 흰 바탕 잔색이 테두리에 남음 | 공통 기본 한 장에서 계산한 표시 전용 경계 보정을 8컷에 동일 적용 | 표정별 경계 변화 없이 배경에 부드럽게 연결 |
| 그림자가 몸보다 아래에 떨어짐 | 추석 까몽만 접지 높이 15.6% → 20.6%, 몸 크기·위치는 그대로 | 떠 보이는 인상 완화 |
| 작업별로 털 보존 기준이 흩어짐 | `캐릭터_생명감_설계.md` §1-a, DESIGN, 의상 제작 정본 및 명시 요청 기억에 기록 | 까몽·몽글·마린의 이후 작업에도 적용 |

- 원본 비트맵과 만족한 의상은 재생성·덮어쓰기하지 않았다. 새 AI 생성·결제 없음.
- 1차 6px 보정은 실제 수신에서 아랫배의 밝은 띠가 남아 최종 합격으로 처리하지 않았다. `감사/수신감사.json`에 보존했다.
- 최종 2차는 승인된 이 차림만 원본 1024의 바깥 12px 이내(송출 약 4px)를 점진적으로 감쇠한다. 옷고름 두 영역과 몸 안쪽을 보호한다. 몸 전체 흐림·반투명·프레임별 경계 재계산은 하지 않는다.
- 원래 밝은 털끝까지 검게 없애는 작업은 아니다. 좁은 밝은 털의 자연스러운 빛은 남는다.

## 확인 증거

- 실제 브라우저에서 최종 8컷 모두 기본과 비교한 **눈 영역 밖 RGBA 차이 0, 표정 간 알파 차이 0**. 표시 보정은 매 컷 동일한 29,213픽셀만 변경했고 보호한 몸 안쪽의 변경은 0. `브라우저검수_경계2.json`.
- 실제 크기 1280×720의 중앙을 확대 없이 잘라 기본·눈웃음을 확인했다. 보정 전후 이미지 배치 `translateY(-4.17%) scale(1)` 동일, CSS opacity 1 / filter none.
- 관련 Node 시험 61개 통과(가장자리 17개 포함). 주담당도 핵심 3파일 37개를 재실행해 통과를 확인했다. 합성 데이터/모의 브라우저 시험과 실제 비트맵 검사는 별개다.
- 실제 유튜브 90초 수신: 1280×720 H.264 + AAC 44.1kHz stereo, 7,562,726bytes. `유튜브수신_경계2.json`.
- 수신 음향 3,876패킷·디코드 프레임에서 1.1ms 초과 시각 불연속, 순서 역전, 디코드 경고, -45dB 이하 3ms 이상 무음 검출 0. `수신음향검수_경계2.json`. 직접 청취나 11곡 전체 순환 검증을 했다는 의미는 아니다.
- 최종 수신 20·50·85초를 1차와 같은 크기로 독립 대조했다. 아랫배의 연속적인 흰 선은 완화됐고, 귀·손·꼬리의 잘림이나 전체 흐림은 관찰하지 않았다. 주담당도 50초 실물과 전후 비교를 직접 확인했다. 남은 따뜻한 털빛까지 추가 제거하지 않는다. `감사/수신감사_경계2.json`, `감사/수신감사_경계2_전후.png`. 로컬 8표정 전수검사를 실제 방송에 8표정 모두 출현한 것으로 확대하지 않는다.
