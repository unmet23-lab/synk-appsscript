# SYNK 28류 상표 선행조사·출원 결정 기록

> 2026-09-11. KIPRIS 국내 상표 검색과 지식재산처 수수료 안내를 대조한 1차 기록이다. 상표 출원·결제는 아직 실행하지 않았다.

## 현재 결정

- **상표:** `SYNK`
- **상품류:** **28류**
- **우선 지정상품:** 피규어, 캐릭터 인형, 봉제인형
- **사용자 결정:** 28류를 우선 출원한다.
- **미완료:** 고시상품명칭의 최종 선택, 출원서 제출, 수수료 납부

## 선행조사 결과

2026-09-11 KIPRIS에서 28류를 대상으로 다음을 확인했다.

| 검색 범위 | 결과 | 해석 |
|---|---|---|
| `SYNK` 동일·포함 + 28류 | 0건 | 검색상 동일 영문 표장은 확인되지 않음 |
| `SYNC` 포함 + 28류 | 복합표장 다수 | `싱크 그랜드`, `싱크 듀얼 포스` 등은 확인됐으나, 확인된 활성 사례는 운동기구 중심 |
| `싱크` 포함 + 28류 | 10건 | 단독 `싱크` 등록이 확인된 것은 아니며 대부분 복합표장 |

검색 결과만으로 등록 가능성을 보장할 수는 없다. 심사에서는 표장의 외관·호칭·관념과 지정상품의 유사성을 함께 판단하므로, 실제 출원 전 고시상품명칭과 최종 유사군을 다시 확인한다.

## 비용 기준

- 특허청 고시상품명칭만 사용한 온라인 상표 출원: **1상품류당 46,000원**
- 한 상품류에서 지정상품이 10개를 초과할 때: 초과 1개마다 2,000원 가산
- 지정상품 3개라면 위 가산금은 발생하지 않는다.
- `피규어` 등의 표현이 고시명칭이 아닌 자유기재로 처리되면 기본 출원료가 달라질 수 있으므로 결제 직전 화면에서 확인한다.
- 등록결정 후 설정등록료와 지방세는 출원료와 별도다.
