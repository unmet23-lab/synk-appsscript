## 결과

**기존 출처 오류와 다른 유형의 조건 오류는 추가 확정하지 않았다.** 기존 출처 교정 검색에서 빠진 HW123 1건을 찾아 담당자에게 넘겼고, 담당자는 출처 교정 범위를 28건에서 29건으로 늘리기로 확인했다. 같은 결함을 별도 신규 오류로 중복 집계하지 않는다.

이는 아래의 제한된 조건 대조 결과다. 몽골어 전체 자연스러움, 모든 콘텐츠의 사실관계, 855개 전수 품질을 검증했다는 판정이 아니다.

## 확인 범위

- `한국어짝.json`: 한국어 원문이 연결된 506개 중 기존 `교정확정.json` 40개와 `출처정밀입력.json` 28개의 해당 ID를 제외한 **463개**를 대조했다. 두 제외 목록 전체 수를 506에서 단순히 빼지는 않는다. 한국어 짝이 없는 ID와 목록 간 범위 차이가 있기 때문이다.
- 463개는 수량·시간·행동 키워드에 걸리는 329개와 나머지 134개 모두를 읽었다. 숙제 본문과 팁은 각자의 한국어 원문 칸을 기준으로 비교했다. 여러 위치에서 쓰이는 동일 문구가 있어 실제 몽골어 위치는 467곳이다.
- `병렬한국어짝.json` 259개 중 기존 교정 대상 18개를 제외하고, 수량·시간·행동·보상 관련 한국어 후보 **61개**를 대조했다. 위 463개와 ID 중복은 없다. 후보에 운세·장면·문법 분류명이 섞여 있음을 감안해 실제 제출 조건으로 오인하지 않았다.
- 몽골어는 `조각과문맥.json`의 위치 정보를 이용해 **현재 `엔진_콘텐츠AI.js`의 실제 줄**을 다시 읽었다. 이 검토에서 선택된 몽골어 문구는 모두 이 파일에 있었다.
- 한국어 연결 506개의 `koreanRows.source`가 현재 읽은 소스의 실제 줄과 일치하는지 검사했으며, 불일치가 없었다. 병렬 후보 61개 중 `Code.js` 등의 요청 범위 내 현재 한국어 줄로 재확인 가능한 18개도 일치했다. 나머지 43개는 제공된 병렬 JSON의 한국어 원문을 기준으로 대조했다. 이 43개의 원본 위치인 `엔진_폼리포트.js`는 이번 별도 확인 범위에 넣지 않았다.
- `Code.js`, `엔진_콘텐츠AI.js`, `엔진_운영배치.js`를 현재 소스 기준으로 읽기 전용 조회했다. `엔진_운영배치.js`에 별도 조건 오류가 없다고 전수 판정한 것은 아니다. 이번 선정 짝의 몽골어 위치에는 포함되지 않았다.

조건 대조는 수량, 시간, 제출·녹음·보내기 의무, 발화자와 받는 사람, 필수 행동, 선택 가능한 재료, 실제 보상의 변경 여부에 한정했다. 같은 행동을 자연스럽게 표현한 차이는 오류로 세지 않았다.

## 기존 출처 교정 범위에 추가 인계한 1건

### HW123 / ID 0078 — 허용 재료가 오늘 읽은 글에서 교재로 바뀜

- 한국어: `엔진_콘텐츠AI.js:5264`

  > 발음이 비슷한 단어 한 쌍(달/딸 같은)을 사전이나 오늘 읽은 글에서 찾아 차이 메모.

- 검토 당시 몽골어: `엔진_콘텐츠AI.js:4118`

  > Дуудлага нь төстэй хос үгийг (달/딸 гэх мэт) сурах бичиг эсвэл толь бичгээс олж, ялгааг нь тэмдэглээрэй.

- 달라진 조건: 한국어는 **사전 또는 오늘 읽은 글**을 허용한다. 몽골어의 `сурах бичиг эсвэл толь бичгээс`는 **교재 또는 사전**을 뜻한다. 오늘 읽은 글을 활용할 수 있는 선택지가 교재로 대체됐다.
- 재현: 오늘 읽은 글은 있지만 교재가 없는 학생이 HW123의 몽골어만 읽으면, 한국어에서 허용한 읽기 자료를 선택할 수 있다는 안내를 받지 못한다.
- 기존 검색 누락 근거: 기존 출처 검색은 굴절형 `сурах бичг`를 찾았으며, 이 줄은 기본형 `сурах бичиг`이다.
- 인계 상태: `/root/night_audit`가 같은 원인임을 확인하고 기존 출처 수정 묶음 **28→29건**에 편입한다고 회신했다. 이 문서 작성자는 소스나 교정 장부를 수정하지 않았다. 실제 수정 완료 판정은 담당자의 후속 결과로 확인한다.
