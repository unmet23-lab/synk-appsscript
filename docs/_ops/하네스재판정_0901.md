## 5. 이 방향이 틀릴 때의 모습 (0820 §3 갱신)

1. **하네스 종속이 깊어진다** — 훅 9종을 더 들이면 판올림 한 번이 운영을 흔든다.

### 6-1. 짓는 도중 드러난 것 — 셋 다 «조용한 실패»였다

이 절이 이 문서에서 제일 값나가는 자리다. **새 훅 셋이 전부 «0건과 같은 얼굴»로 죽는 병을 갖고 태어났다.**

1. **cwd 형식** — Stop 훅이 미커밋 1건 앞에서 완전히 침묵했다. git 이 없어서가 아니라 cwd 가
   POSIX(`/c/Users/…`)로 들어와 Windows node 의 `spawnSync` 가 ENOENT 를 냈고, `catch` 가 그걸 삼켰다.
   → `.claude/hooks/lib/git길.js` 신설(경로 변환 + **못 쟀으면 «못 쟀다»로 운다**).
2. **스키마 거부** — `SessionEnd` 가 `hookSpecificOutput.hookEventName` 허용 목록에 없어 **출력 전체가 버려졌다.**
   공식 문서는 지원한다고 적는데 하네스 2.1.252 는 거부한다 — **문서보다 실측이 이긴다.**
   옆 세션(`synk-appsscript-9d`)이 `claude mcp list` 를 돌리다 그 오류를 보고 알려줬다.
   → 최상위 `systemMessage` 로. 같은 위험이 있는 `Stop` 은 스키마를 안 타는 `exit 2 + stderr` 로.
   ⚠ `Stop` 이 그 목록에 드는지는 **안 재봤다**(headless 실측이 OAuth 만료로 막혔다).
3. **셸이 종료코드를 삼킴** — `settings.json` 의 Stop 래퍼가 `| node "$H"; fi; exit 0` 이라 node 의
