## 🔴 es-hangul 이 틀리는 자리 — 직접 넣어 본 것

```
한국어를 공부해요  →  한꾸거를 공부해요     (표준은 [한구거를])
선생님 한국      →  선쌩님 한꾹          (어절 경계를 넘어 적용 · 「선생」은 [선생]이다)
우리 친구       →  우리 친꾸            (표준은 [친구])
문장 만들기      →  문짱 만뜰기          (표준은 [문장 만들기])
단계          →  단꼐               (표준은 [단계/단게])
언제          →  언쩨               (표준은 [언제])
```

**까닭**: 표준 발음법 제24항은 「**어간** 받침 ㄴ(ㄵ)·ㅁ(ㄻ) 뒤에 결합되는 **어미**」에만 적용된다(안고[안꼬]·감다[감따]).
es-hangul 은 이것을 **명사와 어절 경계에까지** 밀어 붙인다. 그래서 「문장」이 [문짱]이 된다.
⇒ 우리 자의 「경음화 포착률 36.5%」라는 첫 수는 **거짓**이었다. 못 본 219곳 중 대부분이 es-hangul 의 오류다.

## ✅ es-hangul 이 맞는 자리 — 대조군

```
국물 → 궁물 · 신라 → 실라 · 같이 → 가치 · 좋고 → 조코
옷이 → 오시 · 읽다 → 익따 · 색연필 → 생년필 · 십만 원 → 심만 원
```

9~20항 자체는 정확하다. 문제는 24항 하나다.

## 메운 구멍 — 12항 4호

> 제12항 4호 — ㅎ(ㄶ, ㅀ) 뒤에 'ㅅ'이 결합되는 경우에는, 'ㅅ'을 [ㅆ]으로 발음한다.

고침 **전**에는 이 자리가 전부 0 이었다:

```
않습니다[안씀니다] · 많습니다[만씀니다] · 싫소[실쏘] · 옳소[올쏘] · 괜찮습니다[괜찬씀니다]
```

ㅎ **홑**받침은 원래 장애음 표(ㄷ류)에 있어 「좋소[조쏘]」가 잡혔는데, **겹받침 둘만 빠져 있었다.**
`tools/발음밀도.js` 에 한 줄 넣고 `tests/발음밀도.test.js` 에 경계까지 못박았다(「않고」는 격음화지 경음화가 아니다).

## 이 검사를 다시 하려면

es-hangul 은 저장소에 안 넣었다(루트에 npm 꾸러미 얼개가 없고, 정본이 아니라 «가끔 대는 자»다).
스크래치패드에서 이렇게 다시 세운다:

```bash
npm install es-hangul
```

그리고 `tools/발음밀도.js` 를 `require` 해서 같은 문장을 두 자에 넣고 «바뀐 글자 수 vs 센 건수»를 대조한다.
판정 규칙은 위 3단계와 같다 — **헛셈이 있으면 우리 자가 과대 계상**, **놓침이 있으면 갈래를 직접 확인**(es-hangul 이 틀렸을 수 있다).
