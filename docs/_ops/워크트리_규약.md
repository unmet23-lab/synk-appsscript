# 워크트리 규약 — 세션마다 제 책상 (v1 · 2026-08-26)

> **왜 생겼나.** 세션 여섯이 **작업본 하나**를 함께 써서, 「내 몫만 커밋한다」고 해도 남의 미커밋이
> 함께 실려 갔다 — 오늘까지 **일곱 번**(마지막 셋이 08-26 하루). 잃은 글자는 0이지만 장부가
> 「누가 왜 했나」를 틀리게 적었고, **일곱째는 그 대비 절차를 «실행하는 도중»에 났다**(`index.lock`
> 경합). ⇒ 손 규율로는 못 이긴다. 자리를 갈라야 위험 자체가 없어진다.
>
> 실측 판정(08-26 · 트랙 §1 ⏭)은 **「쓸 수 있다」**로 끝났다. 이 문서는 그 «어떻게»다.

---

## 0. 한 문장

**코드를 만지는 레인은 제 워크트리에서 짓고, 유호님이 여시는 것을 만드는 레인은 메인에 남는다.**

---

## 1. 누가 쓰고 누가 안 쓰나 — 기준은 하나다

> **「유호님이 이 산출을 커밋 «전»에 여실 일이 있는가」**

실측(08-26): 유호님 바탕화면 바로가기 **44개가 전부 `docs/` 를 가리킨다.** 코드(`Code.js`·`엔진_*.js`·
`lib/`·`tools/`)를 가리키는 것은 **0개**다. 그래서 갈림이 깨끗하다.

| 레인 | 자리 | 왜 |
|---|---|---|
| **엔진·코드 트랙**(`Code.js`·`엔진_*.js`·`lib/`·`tools/`·`tests/`·talk 연동) | 🟢 **워크트리** | 유호님이 커밋 전에 여실 일이 없다 ⇒ 가시성 대가 **0** |
| **청소·구조 트랙** | 🟢 **워크트리** | 위와 같다 |
| **굽기 레인**(시안 PNG·HTML·영상) | 🔵 **메인** | 아침에 바탕화면으로 **바로** 보셔야 한다 |
| **문서·판정 지면 레인**(`docs/**.md`·`docs/**.html`) | 🔵 **메인** | 같은 이유 — 만드는 중에도 여신다 |
| **배포**(`/deploy`) | 🔵 **메인** | 라이브에 나가는 것은 master 에서만 (§5) |

⚠ **애매하면 메인이다.** 워크트리는 편의고, 유호님이 못 보시는 것이 손해다.

---

## 2. 어떻게 들어가나 — 새 도구를 안 짓는다

하네스에 이미 있다(CLAUDE.md 「새 운영 장치를 짓기 전에 하네스에 이미 있는지 본다」).

```
EnterWorktree({ name: "엔진/저작신뢰" })     ← 세션 첫머리에 한 번
ExitWorktree({ action: "keep" })              ← 일이 남았으면 keep · 끝났으면 remove
```

- **이름 규칙** = `<레인>/<트랙>` — `엔진/…` · `청소/…` · `코드/…`. 두 마디 이름은 **된다**(08-26 실측).
- 자리는 `.claude/worktrees/<이름>` — `.git/info/exclude` 에 있어 메인 눈에 안 띈다.
- 비용 = **954MB · 5.9초**(실측). 여섯이면 5.7G · 남은 디스크 110G.
- ⚠ 가지 기준은 `origin/master` 다(하네스 기본 `worktree.baseRef: fresh`). **안 민 로컬 커밋은 안 따라온다** — 들어가기 전에 `git log origin/master..master` 가 비었는지 본다.

## 3. 언제 합치나 — **커밋한 그 자리에서**

```
git push -u origin <내 가지>          # 내 것부터 남긴다
git fetch origin && git rebase origin/master   # master 를 당겨 얹는다
git push origin HEAD:master           # master 로 민다
```

🔴 **미루지 않는다.** 워크트리는 「내 것이 안 섞인다」를 사는 대신 **「안 합치면 아무 데도 없다」**를
같이 산다. 지금까지는 커밋만 하면 메인에 있었지만, 이제는 합쳐야 있다.
CLAUDE.md 「커밋과 push 는 한 벌이다」가 **커밋·push·합치기 한 벌**로 늘어난다.

---

## 4. 공용 원장(`트랙.md`·`결정.md`)은 어떻게 되나

**적는 방식은 그대로다.** 자기 트리에서 그 자리에 적고 합친다. 실측(08-26 · `git merge-file`):

| 두 세션이 | 결과 |
|---|---|
| **다른 절**에 적었다 | ✅ **자동으로 합쳐진다**(둘 다 살아남는다) |
| **같은 절, 떨어진 줄**에 적었다 | ✅ 자동으로 합쳐진다 |
| **정확히 같은 줄자리**에 적었다 | ⚠ **충돌 — 소리가 난다** |

🔑 오늘 사고 일곱 건은 **전부 다른 절**이었다 ⇒ 켰더라면 **일곱 건 다 자동으로 합쳐졌을 것**이다.
그리고 마지막 줄이 이 규약의 값이다 — 지금은 같은 자리를 만져도 **소리 없이** 한쪽이 실려 간다.

---

## 5. 검증 규율 — 이게 워크트리가 실제로 사 오는 것

**초록은 이제 «내 트리»에서 센다.** 지금까지는 남의 미커밋이 내 검사에 섞여 있었다. 실측(08-26):
`강사지식` 굽기 검사가 **남의 미커밋 `.txt` 14벌 때문에** 내 세션에서 빨갛게 떴고, 진단에 시간이 들었다.
🔴 **더 위험한 반대 방향** — 남의 미커밋이 내 결함을 **가려 초록으로 통과시킬 수 있다.** 증상이 없다.

- 워크트리에서는 그 오염이 **원리상 없다**. 초록이 내 것이면 정말 내 것이다.
- 그래서 「얼린 트리로 재기」(memory `frozen-tree-ci-measurement`)의 이유 절반이 사라진다.
- ⚠ 다만 **형제 저장소(SYNK-talk)는 여전히 한 책상**이다(§7).

---

## 6. 배포 — master 에서만

`/deploy`·`clasp push` 는 **메인 트리에서 master 로** 한다. 워크트리에서 배포하면 그 가지의 코드가
라이브로 나가고, 그건 아무도 안 본 판이다. **합치고 → 메인에서 배포한다.**

## 8. 알고 켜야 할 것 넷

1. **생 `grep -r` 은 오염된다** — 워크트리 사본이 **먼저** 나온다(실측: 첫 8건 전부 사본).
   하네스 Grep(ripgrep)과 저장소 도구(rot-check·테스트 580)는 **깨끗하다**(`.git/info/exclude` 를 읽는다).
   ⇒ 검색은 Grep 도구를 쓴다. 굳이 셸이면 `--exclude-dir=worktrees`.
2. **형제 저장소는 따로다** — appsscript 워크트리를 켜도 `SYNK-talk` 은 여전히 한 작업본이다.
   (talk 은 이미 워크트리를 하나 쓰고 있다 — codex 기준선 레인.) talk 을 함께 가를지는 별건.
3. **형제 자리를 «경로 모양»으로 짐작하지 않는다** — `.claude/hooks/lib/형제저장소.js` 하나가 답한다.
   08-26 에 아직 짐작하던 두 도구(`앱로고굽기.js`·`이해대장.js`)를 이전했다.
4. **굽기 산출은 메인에 있어야 한다**(§1) — 워크트리에서 구우면 유호님 바로가기에 안 뜬다.

## 9. 되돌리기

```
ExitWorktree({ action: "remove" })              # 세션이 스스로
git worktree remove --force .claude/worktrees/<이름>   # 밖에서
git worktree list                               # 지금 몇 개인가
```

규약을 접으려면 이 문서를 지우고 세션들이 메인에서 짓게 두면 된다 — **되돌리는 비용이 0인 변경이다.**
