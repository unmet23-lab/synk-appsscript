## 3. 아직 부족한 것 — 1차 담당이 보는 순서

1. **홈의 3D 방이 여전히 첫인상의 대부분인데 장면 미술은 그대로다.** 크림 벽·나무 아치 창·작은 소품, 위쪽 절반이 빈 벽, 평평한 조명, 창밖에 한강이 안 보인다(「한강 마루」 정체성이 타이틀에만 남음). 틀이 고급스러워질수록 방이 저예산처럼 보인다. → 조명·색 보정·창밖 한강·카메라 구도·방 소품을 [공통 3D 미술](../디자인/게임_풍경과_재질.md#world-graphics-20261009) 안에서 끌어올리기. 세 친구 형태·얼굴은 승인 정본이라 그대로.
2. **배우기 허브가 코랄 포스터 7장의 반복이다.** 같은 틀이 이어져 무겁고 단조롭다(10-13 「각 사진마다 너무 똑같아서 별로야」와 같은 함정). → 「지금 할 일」만 코랄, 팩은 어두운 카드 + 인화지 등 리듬을 준다.
3. **게임 안 미술이 새 UI와 따로 논다.** 말의 리듬 펠트 레인(파랑·분홍), 바람길 도로·하늘은 옛 그대로. 결과·보상 순간 연출도 약하다(조사 ⑦ 「결과 한 장·히어로 모멘트 두 곳」 미구현).
4. **움직임·전환이 거의 없다.** 시트가 올라오는 것뿐이라 화면 사이 연결감이 없다. 멀미 기준 안(회전·흔들림·스스로 반복 금지, 누를 때 ≤250ms)에서 페이드·크기·공유 요소 전환(View Transitions) 시안을 **만들어 보여 드리고 유호님이 고른다**(움직임을 더하는 안은 내 판단으로 통과시키지 않는다).
5. **소리·햅틱 체계가 없다.** 조사에서 칭찬이 더 많은 유일한 기능이 소리였다. 단추·정답·완료의 짧고 낮은 소리, 끄기 스위치(보상 연출·캐릭터 반응을 따로 끄는 두 스위치 — 조사 ⑤).
6. **PC 화면이 휴대폰 시트를 키운 모양이다.** 1440에서 시트 폭 480~520, 옆이 휑하다. → PC 전용 배치(오른쪽 패널, 두 단 레슨, 넓은 옷장).
7. **문구가 대부분 GPT판 그대로다.** 「나의 작은 세계」「편안하게 머물러요.」「어떤 놀이가 좋을까?」「작은 말로 시작하는 한국 생활」 같은 말투. 「GPT 원고는 다시 쓴다」 기준으로 화면 문구 전부를 자연스러운 해요체로(캐릭터 대사·소개 카드는 정본이라 유지). 1차에서 새로 넣은 팩 낱말(인사·카페·편의점·길 찾기·버스·약속)과 영문 라벨도 함께 본다.
8. **조사에서 채택했지만 안 한 것**(조사 §5-1): 쓸 때가 되면 생기는 기능 단추(첫날 홈은 튜터와 시작뿐), 카페 「점원 말 듣기 → 카운터 물건 집기」 주문, 마을이 끝낸 팩만큼 자라는 구조, 튜터가 지난 표현을 기억해 꺼내기·한 시간이면 쉬자 제안, 하루 할당·죄책감 연속 기록 없음 확인.
9. **옷장 무대가 빈 회색 스튜디오다.** 꾸미는 재미(배운 장소 배경, 사진 한 장으로 끝나는 짧은 꾸미기)가 약하다.
10. **실기기 확인을 안 했다.** S25·iPhone 15에서 손가락·글자·발열, 홈 3D 방이 전체 화면이 되며 늘어난 그리기 비용(픽셀 예산 상한은 그대로)을 잰다. 유호님이 실물 휴대폰 확인을 보류 중이면 그대로 둔다(트랙 §1).
11. **작은 것들:** 아틀리에 가로 화면(app-shell.css의 `.wardrobe-dialog .atelier-*`)에 9–12px 한글 / 한글 만나기 `assets/kit/*.webp`(약 600KB) 미사용 — 지울지 유호님 확인 / LAB 단독 말의 리듬 가로 「딱!」 위치 버그(WORLD 안에서만 고침) / WORLD 게스트가 한글 졸업 뒤 「미니게임 하러 가기」를 봄(HUB 로직) / 옛 미리보기 `synk-world-home/index.html`은 토큰을 안 실어 옷장이 무서식 / 계정 페이지 안 게임 틀(`.game-frame` 아님)은 LAB 모습 / 놀이 시트에서 「조작 연습」 ×가 게임 패널까지 닫는다(원래 동작).

## 5. 지킬 것

- 디자인 규칙은 [가이드](../디자인/월드_시그널/README.md) 그대로: 3D 세계 위 어두운 유리 캡슐, 근사 검정 판, 사업 색 코랄 하나, 화면마다 흰 알약 하나, 펠트 질감 그림을 단추·칩·탭·카드 바탕에 깔지 않기, 크림·베이지 바탕 금지, 한글 13px 이상·한글 든 라벨은 모노 금지, 화면마다 내용을 설명하는 다른 그림.
- **멀미**: 마스코트·장면에 스스로 움직이는 효과·회전·흔들림을 더하지 않는다. 움직임 안은 만들어 보여 드리고 유호님이 고른다. 눈 깜빡임은 예외로 괜찮다.
- 3D 방·캐릭터 형태·한강 타이틀 그림·승인 로고는 바꾸지 않는다(바꿀 땐 먼저 여쭌다). 학습·채점·저장·계정 계약과 `id`·`data-*` 고리는 그대로.
- 사이트·앱 화면에 AI 도구 이름·「AI 생성」 표시를 넣지 않는다. 유료 API 호출 없음(그림은 구독 경로).
- 커밋·푸시는 유호님이 말할 때만. 결정 표 줄은 Edit 도구로 구분선 바로 아래에(노드 도구는 이 하네스에서 실패).

## 6. 함정

- `synk-world-app/qa/*-static.test.mjs`·`account-browser.test.mjs`는 **저장소 qa 폴더의 report.json·failure.png를 덮어쓴다.** 공용 작업본에서 돌리지 말 것. 돌렸으면 `git show HEAD:<report.json>`으로 되돌리고 만든 png를 지운다(1차에 한 번 그렇게 되돌림).
- 홈 3D 방의 틀은 `home-scene.css`의 `--scene-lift`(위로 올림)·`--scene-span-portrait/landscape`(가로 폭)·`--scene-shift`(가로 화면 오른쪽 이동)로 정한다 — `living-home-scene.mjs`가 resize 때 읽어 `camera.setViewOffset`에 쓴다. 사진 찍기도 같은 틀로 찍힌다.
- 배우기의 다음 학습 알약 `#life-next-button`은 3D 방에서 숨긴 채 남아 있다(app-shell이 글을 갱신). 시험·스크립트는 배우기 탭 맨 위 「지금 할 일」 포스터의 `[data-life-lesson]`을 쓴다.
- 바람길·리듬 스킨은 `world-host.js`가 `frameElement.classList.contains('game-frame')`일 때만 `data-host=world`를 붙인다(데스크톱 CSP가 인라인 스크립트를 막아 파일로 둠). 두 `world-skin.css`의 공통부는 같은 글이라 고칠 때 둘 다 고친다.
- 마을 단독 서버 CSP(`img-src 'self'`)가 data URI를 막아 아이콘은 `synk-town/assets/ui/*.svg` 파일이다.
- Windows 줄끝: 공용 작업본의 일부 파일은 CRLF다(`home.css`·`home.mjs`). apply.cjs가 맞춰 쓴다. 손으로 옮길 땐 `tr -cd '\r' | wc -c`로 비교.
