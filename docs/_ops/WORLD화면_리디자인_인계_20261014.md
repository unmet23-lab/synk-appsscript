## 7. 함정

- `synk-world-app/qa/*-static.test.mjs`·`account-browser.test.mjs`는 저장소 qa 폴더의 report.json·png를 덮어쓴다. 공용 작업본에서 돌리지 말 것(돌렸으면 `git show HEAD:<report.json>`으로 되돌리고 png 삭제).
- 홈 3D 방: 창밖 그림은 `TextureLoader` 한 장을 `clone()`해 UV만 바꿔 쓴다. 이미지가 뒤늦게 로드되면 **클론의 `needsUpdate`를 다시 켜야** 그려진다(`viewClones`에서 처리). 벽은 `Shape`+`holes`로 구멍을 뚫은 ExtrudeGeometry(세로·가로 두 벌, `visible`로 전환). 카메라 틀은 `home-scene.css`의 `--scene-lift`·`--scene-span-*`·`--scene-shift`(resize 때 `setViewOffset`).
- 배우기의 다음 학습 알약 `#life-next-button`은 3D 방에서 숨긴 채 남아 있다. 시험·스크립트는 「지금 할 일」 포스터의 `[data-life-lesson]`을 쓴다.
- 바람길·리듬 스킨은 `world-host.js`가 `.game-frame` 안일 때만 `data-host=world`(데스크톱 CSP가 인라인 스크립트를 막음). 두 `world-skin.css` 공통부는 같은 글. LAB 단독 화면은 계산 스타일 차이 0 계약.
- 마을 단독 서버 CSP(`img-src 'self'`)가 data URI를 막아 아이콘은 `synk-town/assets/ui/*.svg` 파일.
- Windows 줄끝: 공용의 일부 파일은 CRLF(`home.css`·`home.mjs`·`결정.md`·`트랙.md`). apply.cjs가 맞춰 쓴다. 손으로 옮길 땐 `tr -cd '\r' | wc -c`로 비교.
- 서브에이전트는 브리프를 읽은 뒤 BEFORE 사진부터 찍느라 20~30분은 소스를 안 건드린다. 멈출 땐 `git status`로 실제 변경을 확인한다(2차는 0이었다).
