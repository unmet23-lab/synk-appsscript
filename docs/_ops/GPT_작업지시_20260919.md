## 1. 만들려는 것

- **목표(사용자 원문).** 아틀라스로 만든 한국어 게임과 공부를 한 사람이 「와.. 나를 이렇게 잘 알고 이렇게 센스있고 이렇게 공부를 편하고 재밌게 쉽게 할수있구나」라고 느끼는 것. 스스로 초개인화가 되도록 진화하는 시스템이다.
- **앱은 한국어를 배우고 싶은 모든 사람을 위한 것이다.** 몽골인 전용이 아니며, 첫 오프라인 학원의 출발이 몽골일 뿐이다. 학원생이 아니어도 구글·애플·이메일로 쓰고, 학원생은 코드로 학원 기능이 더해진다.
- **사람 손 없이 돈다.** 강사·검수자·운영자가 0명이어도 고리의 모든 단계가 돈다. 사람은 있으면 더 빠르고 확실하게 해 줄 뿐이다. 공개 사용자에게는 이것이 평소 상태다.
- **출시 순서.** 2~3주 뒤 비공개 테스트 출시(한국·몽골) → 넷이 서면 공개 출시(초급의 첫날 경험 · 사람 없는 교정 · 비용 상한 · 약관과 동의와 계정 지우기) → 첫 학원생 전에 학원 연결.

- **[확인]** — 2026-09-19에 코드·문서 원문에서 직접 본 사실이다. 앱 쪽은 talk **원격 master `9f723d6` 기준의 작업 사본**에서 봤다. 코드는 움직이므로 기대기 전에 다시 본다. 설계 문서의 talk 경로 `functions/deliver`는 실제로 `supabase/functions/deliver`다.
- **[제안]** — 설계의 제안이다. 만들기 전에 실물과 대조하고, 실물이 다르면 실물에 맞춘다. **설계와 다르게 만들었으면 그 문서를 같은 커밋에서 고치고 이유를 한 줄 남긴다.** 문서와 코드가 갈라진 채로 두지 않는다.
- **[사용자]** — 사용자 확인 없이는 진행하지 않는 자리다. 멈추고 묻는다.
- **설계값** — 출발 숫자다. 코드에 상수로 박지 않고 매개변수·설정으로 둔다(아틀라스의 점수 숫자는 `policy_params` — 구현 명세 §6-4).

## 5. 사용자가 그때 요청했을 때만 하는 것

운영·리허설 DB에 붓기 · Edge Function 배포 · 앱 빌드와 스토어 제출 · 홈페이지 게시 · 원격 push · 계약 판올림의 합류 · 동의 문구의 게시. 「만들었다」와 「배포했다」와 「효과가 있다」는 다른 증거다 — 섞어 보고하지 않는다.

하지 않는 것: 새 결제·구독·자동충전 · 자격증명과 학생 식별 정보의 출력과 공유 · 다른 작업의 미커밋과 원본을 덮는 일 · 별도 승인 단계나 검사표나 자동 훅을 새로 만드는 일. 개발자 계정을 만들고 값을 치르는 일은 사용자가 한다.

## 6. 깨면 안 되는 선

**기록과 신원**
- 앱이 서버에 쓰는 길은 `POST /v1/events` 하나다. 아틀라스를 위해 둘째 쓰기 통로를 내지 않는다. `intervention.delivered`·`task.assigned`는 서버 사건이다.
- 서버는 학습자를 **토큰에서** 확정한다. 앱은 자기가 누구인지, 오늘이 며칠인지 본문으로 주장하지 않는다. 학습자 행은 서버만 만든다. 결합은 게이트가 확정한다.
- 이해 봉투 · 본체 사건 · 외부 모델의 입력에 원문 · 음성 · 이름 · 학교 · 회사 · 식별자를 싣지 않는다. 제외 · 철회 · 지우기는 기기 사본과 늦게 끝난 계산까지 닿아야 한다.
- 소급할 수 없는 값(시드 · 확률 · 정책 판 · 매개변수 판 · 두 기준시각 · 동의의 범위)은 첫 실제 입력 **전에** 서 있어야 한다.

**판단**
- 평가의 의미(급수 판정 · 점수 · 부모와 강사에게 가는 말)는 자동으로 바꾸지 않는다. 손잡이로 등록할 수 없다.
- 본인이 직접 정한 설정이 어떤 관측 · 학습 · 비교 몫보다 앞선다. 「아니에요」라고 한 이해는 쓰지 않는다. 한 번 본 것은 확인 전에는 쓰지 않는다.
- 도움받은 결과는 혼자 해낸 것으로 세지 않는다. 값 없음은 실패도 효과 0도 아니다.
- 같은 입력이면 같은 선택이 나온다(시드). 비교 몫의 기본 회차는 관측 · 응답 · 배운 비중을 쓰지 않는다.
- 새 판은 「늘었나」가 첫째 잣대이고 「맞았나」 · 「편했나」는 나빠지면 안 되는 값이다. 다시 오는 비율과 머문 시간을 목표로 삼지 않는다. 알림을 돌아오게 하려고 최적화하지 않는다.
- 제안하는 쪽(Core · Prism)과 검사하는 쪽(Temper의 시험장 · 지킴이)을 한 모듈로 합치지 않는다. 지킴이의 한도는 점수식이 무엇이든 마지막에 거른다.

**경험**
- 연속 기록 · 목숨 · 등수 · 시간 제한 · 실패음 · 재촉 알림을 만들지 않는다. 쉬거나 빠진 날을 벌주지 않는다. 모은 것(글자 · 퀼트 · 간판 · 명패)은 줄지 않는다.
- 발음을 판정하지 않는다. 다른 학생과 견주지 않는다.
- 먼저 말 거는 것은 하루에 하나 · 손 내밀기는 회차에 한 번 · 알림은 한 주에 두 번. 잠금 화면에 개인 이야기를 띄우지 않는다.
- 앱의 말은 **눈높이 한국어의 틀 문장**이다. 도움 언어(출시 때 영어와 몽골어)는 **한글 단계에서만** 쓰고 검수된 문장만 보인다. 몽글의 시범과 그림이 글보다 먼저다.
- 초급에게 자유 답하기를 주지 않는다. 첫날 도입 과제와 교정문의 우선순위는 상태로 바꾸지 않는다.
- 화면의 펠트는 구운 자산만 쓴다(흉내 내어 그리지 않는다). 자산은 전부 「GPT 이미지 2.5」로 굽고 **구운 한글 글자는 표준 글꼴의 본과 대조해 통과한 것만** 쓴다. 글자 소리와 음성은 **확정된 하나의 목소리만**(후보 DIVE · 확정 전에는 소리 자산을 만들지 않는다).
- 움직임은 잔잔한 쪽이 기본이고 움직임 줄이기를 따른다.

**돈**
- 공개 사용자의 AI 비용은 한 사람 한 달 1,000원을 **하루 몫**으로 나눠 준다(사흘 치까지 이월). 비공개 테스트 동안 전체의 천장은 한 달 5만 원이다. 학원에 연결된 학생은 이 상한의 대상이 아니다. 상한에서도 호출 없는 경험은 돈다.

## 10. 세션을 나누는 법

- **한 세션 = 작업 묶음 하나(또는 붙어 있는 둘).** 문서 하나가 한 세션이 아니다 — 문서들은 서로를 가리키고, 지켜야 할 선은 이 문서에 있다.
- 매 세션의 처음에 **이 문서를 읽고**, 그 묶음에 필요한 문서만 더 읽는다(아래 표). 여섯 개를 매번 다 읽지 않는다 — 합치면 13만 7천 자쯤이고 그만큼 코드를 읽을 자리가 준다.
- 세션 사이의 기억은 문서에 둔다. 끝낼 때 §9의 보고를 쓰고 트랙을 고친다. 다음 세션은 트랙에서 이어받는다.
- 나란히 돌리는 세션은 둘셋까지. 각자 자기 작업 사본과 가지를 쓰고 같은 파일을 만지지 않는다. **계약(JSON · 검증기 · DDL)을 고치는 세션은 한 번에 하나만** 돈다.

## 11. 이 환경에서 밟기 쉬운 것

- Windows다. 파일은 UTF-8 · 줄바꿈 LF이고 한글 파일 이름이 많다. `sed -i`는 줄바꿈을 바꿔 놓는다 — 쓰지 않는다. 파일을 비우며 여는 쓰기는 실패해도 원본이 먼저 사라진다 — 임시 파일에 쓰고 바꾼다.
- 셸의 heredoc과 큰따옴표는 백슬래시와 백틱을 먹는다. 긴 글은 파일로 쓰고 도구로 넣는다. bash에서 한글 변수 이름은 실패한다.
- 밤 배치는 Edge 함수의 시간 벽이 있다(재적 800 안팎에서 걸린 기록). 사람 수에 비례해 길어지는 일을 배치에 더하지 않는다.
- 몽골 달력의 날짜 문자열을 로컬 시간대로 읽으면 하루 밀린다(`lib/게임배정.js`의 주석). 공개 학습자의 「오늘」은 그 학습자의 시간대로 서버가 정한다.
