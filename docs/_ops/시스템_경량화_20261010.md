## 2026-10-17 · 4차 과거 자료 전문 검토와 정리

3차에서 보존·참고·부분 대조로 남겼던 **981개 경로**를 끝까지 검토·대조했다. 현재 사업 정본을 바꾸는 새 결정을 만들지 않고, 과거 계획·검증·승인 기록과 지금 재사용할 지침을 구분해 정리했다. 이 차수는 기존 **157개 파일(Markdown 154개·HTML 3개)**을 정정·통합했고 공통 기술 참고 1개를 만들었다. 이 보고서·결정·트랙 갱신은 별도다.

### 읽은 범위

| 방법 | 경로 수 | 근거 |
|---|---:|---|
| 본문을 직접 끝까지 읽음 | 782 | 파일별 읽은 범위·판단·원문 해시 |
| 이미 전독한 기준과 전체 차이를 읽음 | 13 | 정확히 같은 본문·문단의 해시와 모든 고유 내용 대조 |
| 앞선 차수의 실제 전독 판을 재확인 | 85 | 당시 전독 증거와 현재 SHA-256 일치 |

같은 내용을 다시 읽은 횟수나 사본을 새 전문 독해로 부풀리지 않았다. [시작 목록](qa/document-cleanup-20261017/inventory-pass4-start.json), [파일별 장부](qa/document-cleanup-20261017/), [통합 검증](qa/document-cleanup-20261017/validation-pass4.json)에 범위·판단·해시·중복 대조를 남겼다. 장부는 `semantic-*-pass4.json`이며 직접 검토와 동등 사본을 따로 표시한다.

### 실제로 정리한 것

- **끝난 작업을 다시 실행시키던 안내:** Google 가입·공개·키 교체·설치 후보, Atlas 배포, WORLD·TOPIK 게시·받침 수정 인계와 PATH의 과거 미완료 상태를 후속 결과와 연결했다. 이미 취소한 키 교체와 오래된 고정 부모의 stage·commit·push 명령, 반복 질문은 현재 할 일에서 제외했다. 당시 검수 예외와 실패 기록은 소급해 성공으로 바꾸지 않았다.
- **옛 기획 원고:** 9월 본체 SYNK·채널 기획·룸조판 원고 3개를 핵심 결정과 보존 이유로 축약하고 해당 HTML 3개를 다시 생성했다. 고정 채널 수·시간표·말투·옛 예산을 현재 사업 운영 규칙으로 남기지 않았다. 원문과 당시 HTML 6개는 [압축 보관본](../_원고/기록_202609_기획과조판.zip)과 [목록·해시](../_원고/기록_202609_기획과조판.json)로 복구할 수 있다.
- **중복 영상 지침:** 12개 프로젝트의 같은 안내를 [기존 HyperFrames 기술 참고](../마케팅/HyperFrames_기존영상_참고.md)로 통합했다. 프로젝트별 고정 버전·실행 스크립트는 남겼다. 하위 외부 도구 문서 15곳의 반복 적용 범위도 각 입구로 묶었다.
- **외부 도구의 과한 지시:** 자동 가입·유료 전환·피드백 발송·업그레이드, 도구 실패를 승인으로 간주하는 문구, 강제 스타일·매 단계 승인·자동 장식 추가를 현재 SYNK 공통 절차에서 제외했다. 기술 옵션·코드 예제·라이선스·프레임 프리셋은 고유 재현 자료로 보존했다. 내레이션 예제에서 `99.999%`의 소수 두 자리가 빠진 발음도 고쳤다.

### 남겨 둔 기록

특허 연구·청구항·변리사 전달용 초안, 계약·급여·기존 약속, 사용자 승인·반려, 게임의 기준선 실패와 효과 없는 후보, 계정·클라우드의 날짜별 검증은 원문 가치가 있어 보존했다. 특허 초안을 출원·등록 완료로, 로컬 검증을 공개·실물기기·실사용 효과로 확대하지 않는다. 긴 결정 장부와 운영 QA, Atlas 과거 변경 기록도 이번 범위에서 끝까지 검토했다.

### 검증과 복구

- 원문 백업 SHA-256, 검토 장부와 현재 파일, 새 로컬 링크와 기존 절 연결, 변경 파일의 공백을 대조했다. 최종 수치와 결과는 [통합 검증](qa/document-cleanup-20261017/validation-pass4.json)에 있다.
- 압축 보관한 원본 6개는 읽어 낸 바이트의 SHA-256이 모두 같다. [복구 검증](qa/document-cleanup-20261017/archive-restore-pass4.json)
- 다시 생성한 HTML 3개는 원고의 현재 생성 결과와 일치하고 구조 결함이 없다. [원고·출력 대조](qa/document-cleanup-20261017/manuscript-reproduction-pass4.json)
- 문서 지도·지식 관리·운영 홈·비전·결정·설계 계약의 관련 기존 검사 결과는 [검사 기록](qa/document-cleanup-20261017/tests-pass4.json)에 남겼다.
- 수정 전 원문은 `qa/document-cleanup-20261017/_archive/pass4-originals/`에 원래 경로대로 보존했다. [백업 목록](qa/document-cleanup-20261017/backups-pass4.jsonl)의 해시로 확인할 수 있다. 이 복구본은 로컬·Git 제외 파일이며, 복원할 때 이후 변경을 덮어쓰지 않도록 필요한 부분만 골라 적용한다.
