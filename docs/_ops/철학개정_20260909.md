# 철학 v2.0 개정·검증 기록

> 2026-09-09 · 사용자 요청 1~6 반영. 정본은 [SYNK 철학](../SYNK_철학.md), 보기 쉬운 화면은 [철학 요약](../SYNK_철학_요약.html)이다. 이 기록은 개정의 범위와 증거를 남기며 별도의 상시 판단 정본이나 강제 절차가 아니다.

## 바뀐 구조와 이유

SYNK 공통 목적을 ‘사람을 이해하고 그 사람에게 남을 것을 만든다’로 두고 LAB·SHIFT·PULSE의 적용을 나눴다. 교육 앱의 정밀한 설계를 전사 사업의 필수 기능으로 확대하던 문제를 해결한다.

| 사용자 요청 | 반영 |
|---|---|
| 옛 기각이 새 발전을 막지 않게 | 당시 이유·달라진 전제·현재 증거·변경 범위로 재검토. 제목 일치나 14일 경과 여부만으로 막지 않는다 |
| 원료는 실제로 닿아야 한다 | 기존 LAB 숙제·퀴즈·발화와 수집 기능은 저장→엔진 자동 소비→실제 출력 변화→수혜자 도달을 각각 입증 |
| 학생·학부모 홍보·안내·알림 구분 | 접점의 목적을 먼저 평가한다. 그 안에서 새 자료를 수집해 개인화에 쓸 때 수집 부분에만 네 단계를 적용 |
| 철학과 구현값 분리 | 캐릭터 세 축·대사 비율·카드 횟수·성장 표현·시즌 등은 현재 적용 기준과 담당 설계로 연결. 이관은 폐기가 아님 |
| 회사별 성격 반영 | LAB 교육 / SHIFT 1인 기업 브랜딩·강의 / PULSE 음악·영상·이야기의 감상 가치. 기존 자격 사업은 유지 |
| 운동→학습 무기 유지 | 신체활동의 원리를 K컬처·댄스로 구현하는 교육 방향을 유지. 연구의 조건과 우리 학생 효과는 구분 |
| 압축과 추출 도구 | 긴 개정 이력·대외 문안 중복을 본문에서 걷고, 의미 구간으로 추출. 부분 누락·잘림은 전달 완료로 세지 않음 |

4급 케어의 앞선 검토는 사용자 설명에 따라 정정했다. 정규 오프라인 1년·TOPIK 4급 목표·과정 후 첫 시험 미달 시 학원 앱 계정 6개월 무료 온라인 케어는 같은 약속이다. 출석·숙제 미달로 케어에서 제외하지 않는 기존 조건도 보존했다. 무기한 지원이나 오프라인 추가 수업으로 확대하지 않았다.

## 독립 검토와 의미 보존

forge의 두 독립안 중 B의 전사 목적·사업별 적용 구조를 중심으로, A의 데이터 용도·관찰·학생 확인·철회 경계를 합쳤다. 통합 후 별도 의미 검토에서 세 가지를 보강했다: 무료 지원 조건, 외부 도구·사람의 처리 경계, 기존 LAB 학습 수집의 의무. 원본·관측·추정·학생 확인과 개인용·집계·훈련·평가·공개 용도를 구분했다.

철학의 직접 파생 19곳은 관련 조항의 영향 범위를 대조했다. 역사 심문 발췌는 현재 규칙으로 다시 쓰지 않도록 표시하고, 현행 엔진·조직·마케팅·교사 자료의 수집 강제·사업 범위·원문 연결을 동기했다. 엔진 전체 구현이나 19개 문서의 모든 사실·운영 효과를 새로 검증했다는 뜻은 아니다. 다른 상위 정본의 판번호를 일괄 갱신하지 않았다.

## 검증

- 새 본문·제품방향·적용 기준·문서 안내의 로컬 링크 95개: 파일 존재 확인, 깨진 링크 0.
- v1.24 원본 보존 파일: 개정 전 SHA-256과 일치.
- 이해대장 생성: A-1 세 층·A-2 표를 새 실물현황 경로에서 읽어 정상 생성. 관찰 기록과 오늘의 운영 증거를 구분해 표시.
- 작동대장 생성: 새 경로에서 정상 생성, 내부 두 회차 출력 동일. 이 도구는 실제 학생 효과를 측정하지 않음.
- 관련 기존 회귀 검사 61개: 모두 통과(이해대장 절·시트 도달·문서 지도).
- 상담 AI: 실행되는 설정·지식·금칙·봇 공개·인계 문장이 HEAD와 동일함을 실행 결과로 대조. 철학 참조 주석만 갱신.
- 요약 화면: 1440px·390px에서 실제 렌더, SUIT 로드와 가로 넘침 0 확인. 기존 시각 스타일을 보존. 인쇄 전용 린트는 내부 웹문서와 다른 조건으로 실패했으므로 합격 증거로 쓰지 않음.
- 추출·재심·결정 도구: 현재 작업본에 통합 후 핵심 회귀 54/54 통과. 네 역할 모두 5,077자 완전 전달, v1.24의 기존 5,672자 추출도 호환.
- 코드 작업 사본의 관련 회귀 244개: 242 통과·기존 실패 1·기존 skip 1. 실패는 tests/이종검수.test.js의 옛 clasp-guard deny 기대이며 수정 전 기준에서도 동일 재현했다. 현재 가드는 해당 절차를 알림으로 바꾼 상태다. 실제 가드나 이 시험 기대를 이번 변경에 맞춰 억지로 바꾸지 않았다.
- 코드 작성자와 별도 검토자가 9파일 및 실제 호출 경로를 검토했다. 재심은 미판정 제안만 만들며 자동 채택·실행·배포 권한을 주지 않음을 확인했다. 실제 외부 모델의 판단 품질은 호출·측정하지 않았다.
- 현재 운영 원문과 대상이 직접 참조한 결정 행을 사용한다. 개인 memory 환경변수·색인은 읽지 않는다. 내용이 없는 문서·구획 누락·중복·상한 초과·실제 입력 잘림을 전달 성공으로 세지 않는다. 새 훅은 설치하지 않았다.
- 대장검토 스킬의 기존 이름·호출 예시는 유지하고 현황 경로와 목적별 기준을 동기했다. 저장소와 설치 경로가 연결된 같은 내용임을 SHA-256으로 확인했다. YAML 파싱은 정상이며, 공용 quick_validate는 기존 Claude 메타데이터 argument-hint를 지원하지 않아 실패한다. 이 형식 제한을 스킬 내용 검증의 성공으로 보고하지 않았다.
- 옛 홈페이지 시안은 기존 빌드로 템플릿과 산출물이 일치함을 확인했다. 현재 4K 정본의 파생 webp 2개·좌표 JSON을 재생성했으며 원본 자산·CSS는 보존했다. ignored 시안.html은 로컬 산출만 갱신했다. 현재 홈페이지 정본인 병합판을 게시·배포한 것이 아니다.
- 최종 요약과 옛 시안을 Chrome의 390px·1440px에서 확인했다. 무료 케어 문단, 폰트·마스코트 로드, 가로 넘침 0을 확인했다.

## 남아 있는 경계

‘다 낸 날’의 전원 제출 조건과 재촉하지 않는 원칙 사이의 긴장은 적용 기준에 명시했다. 이 개정에서 임의로 바꾸거나 해결 완료로 표시하지 않았다. 실제 적용 전에 경험 설계에서 확인할 자리다.

과학 근거에서는 운동 뒤 학습의 방향과 K컬처·댄스 적용을 보존했다. 연구 대상·과제·운동 조건·효과를 우리 학생의 실측과 섞지 않는다. 과거 Diggs 탐색 결과의 확정 표현과 원문 확인이 안 된 Winter 추적 기간은 대외 사용에서 정리한다. 모든 운동·연령·학습 과제에 같은 향상률을 새로 약속하지 않는다.

이 작업은 문서·읽기 도구·로컬 화면의 개정이다. 실제 학생 데이터 이동·삭제, 외부 메시지 발송, 학원 앱 기능 변경, 라이브 서비스 배포·효과 검증을 수행한 것으로 보고하지 않는다. 개인 메모리 파일은 갱신하지 않았다.

## 종료 확인 — 2026-09-09

사용자의 종료·커밋 요청에 따라 기존 두 커밋과 작업본을 대조했고, 독립 검토에서도 철학 개정의 누락된 미커밋은 발견하지 못했다. 현재 트랙에 v2.0 개정 완료와 이전 앱 작업의 잔여 범위를 구분해 기록했다. 다른 작업의 미커밋은 보존했다. 원격에 미전송인 기존 다른 작업의 커밋이 함께 있어 이번 종료에서는 로컬 커밋까지만 수행하며 push·원격 CI·라이브 배포는 수행하지 않는다. 개인 메모리 갱신 요청은 없으므로 메모리는 변경하지 않았다.

종료 보조 검사에서 friction의 세션별 대조는 Git 호출 실패로 측정 불가였고, 별도 열린 항목 조회는 0건이었다. rot-check는 라이브 지문 차이·메모리 색인의 없는 파일·CLAUDE 상주 크기 설명 불일치 3건을 보고했다. 이 전역 진단을 이번 철학 개정의 시험 실패나 라이브 검증 성공으로 해석하지 않았으며, 종료 요청을 다른 작업의 배포·기억 수정으로 넓히지 않았다.
