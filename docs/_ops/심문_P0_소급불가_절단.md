## ✅ 유호님 확정 (2026-08-07) — WAV 로 간다 · AGC off 도 같은 커밋

「**wav 로 하자**」 + **상시 지시**: 「모든 수집·기능 설계는 **당장 개원에 쓸 수 있도록**,
수집 방법도 **개원에 바로 쓸 수 있도록**」.
🚫 내가 낸 「먼저 업로드 성공률을 재고 그 다음 전환」 **순서는 기각**됐다 — 실측은 전환을
미룰 이유가 아니다. 재는 것과 만드는 것을 같이 한다.

실측 프리셋(`node_modules/expo-audio/src/RecordingConstants.ts:69-73`):
현행 `.m4a`·44,100Hz·**2ch**·128,000bps = **16 KB/s** → WAV 16k/16bit/mono = **32 KB/s** (정확히 2배).

아래는 확정 전 판정 재료로 남긴다.

**음성 포맷을 m4a/AAC → PCM WAV 로 바꿀 것인가.**

- **왜 지금인가**: ① 14건 중 유일하게 저장소 밖이 바뀐다. 나머지 13건은 제가 그냥 합니다.
- **비용**: Expo 기본 녹음기는 raw PCM 을 안 준다 → 새 네이티브 의존성 + **dev build**
  (Expo Go 로는 더 이상 못 열고, 폰에 개발 빌드를 한 번 설치해야 한다). 확정 경로는
  A-2(스트림 캡처 + 헤더 조립)이고 m4a 후처리는 🚫 — 압축이 이미 지운 신호는 안 돌아온다.
- **안 하면**: 발음 판정·음소 정렬의 원신호가 첫날부터 손실 압축본이다. 나중에 WAV 로 바꿔도
  그 전에 쌓인 것은 영구히 압축본이다.
