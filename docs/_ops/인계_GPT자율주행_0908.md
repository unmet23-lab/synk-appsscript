## 0. 🔴 유호님이 이 트랙을 여신 진짜 까닭 — 이걸 놓치면 전부 헛돈다

**「토큰 때문에 GPT 에게 구현이랑 실행을 시키려는 것」**(유호 09-08).

즉 이 트랙의 성패는 「GPT 가 잘 짓나」가 아니라 **「클로드가 덜 쓰나」**로 잰다.

**앞 세션(판 1)의 실측**은 클로드 20,902,136 대 GPT 115,057 로 **182배**였다. 그 세션은 이 자를 통과하지 못했다.
까닭 둘. ⓐ 답이 너무 길었다 ⓑ 턴이 490개였고, 매 턴마다 그때까지의 대화 전체가 다시 실려 길어질수록 한 턴이 비싸진다.

### 이 세션(판 2)은 얼마나 썼나 — 🔴 **안 재봤다**

같은 잣대로 잴 자가 저장소에 없다(`tools/` 에 토큰 사용량을 재는 도구가 없다 · `토큰빌드.js` 는 디자인 값 빌더라 무관하다).
그래서 「줄었다」고 적지 않는다. 대신 **모양만** 적어 둔다.

| | 판 1 | 판 2 (이 세션) |
|---|---|---|
| 클로드 턴 | 490 | 30 안쪽 |
| GPT 가 지은 줄 | 161 | **1,010** |
| 클로드가 고친 파일 | 6 (다섯이 GPT 금지 경로) | 4 (발주서·트랙·인계문·CI 한 단계) |

⚠ **다음 세션이 할 일**: 재는 자를 세우든지, 아니면 이 칸을 계속 「안 재봤다」로 둔다. 🚫 안 잰 것을 「줄었다」로 적지 않는다.

### 지킬 규율 넷 (판 1 에서 그대로)

1. **답을 짧게.** 결론 위주. 한 답에 표는 하나까지.
2. **셸 명령을 묶어 부른다.** 한 턴에 하나씩 재지 않는다.
3. **재는 일도 발주서에 넣어 GPT 에게 시킨다.**
4. **한 트랙 끝나면 세션을 끊는다.** 길수록 비싸진다.

🔑 **다만 «발주서 고치기»는 줄일 자리가 아니다.** 이 세션에서 GPT 가 발주서를 **세 번** 돌려보냈고 그 지적이 전부 맞았다. 그 세 판이 이 통로의 값 자체다(§6).

## 3. 🔴 밟으면 다치는 것 — 앞 세션들이 실제로 밟았다

| 함정 | 무늬 | 처방 |
|---|---|---|
| **파이프가 종료코드를 덮는다** | `... \| tee` 를 붙였더니 「확인불가(2)」가 셸에서 0 으로 나왔고 유호님께 「완주입니다」로 잘못 보고했다 | 성패를 읽을 명령에 파이프를 붙이지 않는다 |
| 🆕 **배경 명령의 「exit code 0」도 시험 값이 아니다** | 파이프를 «안 붙였는데도» 밟았다. `node --test ... ; echo $? ; grep ...` 을 배경으로 띄웠더니 하네스가 「exit code 0」으로 알렸다. 그 0 은 **마지막 grep 값**이고 시험은 1(빨강)이었다. 하마터면 「전체 초록」으로 보고할 뻔했다 | 알림의 종료코드를 판정에 쓰지 않는다. **출력 파일을 열어 내가 `echo` 로 찍은 줄을 읽는다** |
| 🆕 **`grep "^# tests"` 가 0줄을 낸다** | 이 노드 판(v24)의 시험 요약 줄은 `# tests` 가 아니라 **`ℹ tests`** 다. 분모를 세려다 0줄이 나오면 자부터 의심한다 | `grep -E "^ℹ (tests\|pass\|fail\|skipped)"` |
| 🆕 **범위 밖 파일 하나면 그 라운드가 통째로 안 커밋된다** | 2라운드가 회귀 시험을 «범위 밖»에 만들었더니 도구가 그 라운드를 통째로 커밋하지 않고 멈췄다. 고침 자체는 워크트리에 그대로 남아 있다 | 워크트리를 읽고 사람이 정한다. 이번엔 그것이 검수 지적을 재현하는 회귀 시험이라 **받는 것이 맞았다** |
| 🆕 **워크트리 빨강은 임자보다 «밑판»부터** | 저장소 전체 시험이 빨갰는데 내 것도 옆 레인 것도 아니었다. 워크트리의 밑판이 master 보다 뒤져 있었고, master 에서 같은 시험은 15/15 초록이었다 | 워크트리 빨강은 **몇 커밋 뒤졌나**부터 잰다. 합치면 풀린다 |
| **만드는 자리가 둘이면 재는 자가 한쪽만 본다** | 한 판에 세 번 나왔다 | 조립 자리를 하나로 못 박는다. **자가 진짜인지는 «끊어보기»로 잰다** |
| **셸이 백틱을 먹는다** | heredoc 을 따옴표 없이 열어 파일 이름·커밋 번호 일곱이 사라졌다 | 소스·기억 편집은 Write/Edit 로. 넣은 뒤 `grep` 으로 되읽어 센다 |
| **벤더 한도 마커가 낡는다** | 「리셋 전」으로 막혔는데 실제로는 풀려 있었다 | `--한도무시` 한 번(성공 1회면 마커가 스스로 지워진다) |
| **날것 프롬프트 함수를 부르면 거짓 초록** | `제안프롬프트`·`기능체크프롬프트` 가 아직 내보내져 있다 | 새로 재는 코드는 **`…조립()`** 쪽을 부른다 |

🔑 **끊어보기가 이 세션에서 값을 했다.** GPT 가 「고쳤다」고 한 자리를 도로 떼어 보니 회귀 9벌이 빨개졌고, 되돌리니 초록이었다. 그래서 자도 결함도 진짜였다. **모델의 「고쳤습니다」를 그대로 적지 않는다.**

## 4. 인터넷을 왜 끊었나 (다음 세션이 「그냥 열면 되잖아」로 되돌리지 않도록)

울타리는 «쓰기»만 막고 «읽기»는 안 막는다. 그래서 실행자가 **홈의 열쇠 파일을 읽을 수 있다**(`.clasprc.json` = 라이브 배포 열쇠 · `.ssh/id_ed25519` = 깃허브 열쇠 · `.codex/auth.json`). 09-04 프로브로 확인됐다.

**지금 안전한 이유는 하나뿐이다 — 읽어도 나갈 길이 없다.** 열면 그 벽이 사라지고, 남는 벽(커밋 전 비밀 무늬 검사)은 «저장»을 막지 «전송»을 못 막는다.

- codex 는 «일부 주소만 열기»를 **지원하지 않는다**(09-08 실측). 전부 열거나 전부 닫거나.
- 그래서 **새 꾸러미는 실행자가 못 깐다.** 이미 깔린 것을 쓰는 것은 된다.
- 새 부품이 필요하면 **사람이 발주 «전»에 깔고** 발주서 `## 부품` 절에 이름만 적는다.

## 6. 발주서를 쓸 때 — 🔑 **이 통로의 값이 여기 있다**

**값은 «빨리 짓는 손»이 아니라 «짓기 전에 끊어보는 눈»이다.**
이 세션의 실측: 발주 검토가 **세 판**(v2·v3·v4)을 돌며 명세 구멍 **여섯**을 잡았고, 그동안 코드는 0줄이었다. 한 판이 5~7분이라 실행 뒤 수리보다 훨씬 싸다.

**굵은 것 셋** (전부 진짜였고, 안 잡혔으면 그대로 나갈 뻔했다)

1. 참조 찾는 정규식이 `[A-Za-z0-9_]` 라 **한글 이름을 통째로 못 봤다.** 실측에서 `prism_조사여격`·`prism_시험용` 둘 다 못 잡았다. 이 저장소는 이름을 한글로 짓는 곳이라, 그대로 뒀으면 **영원히 초록인 자**가 섰다.
2. 정본이 요구하는 「누구의·어떤 과업·어떤 조건·관측 기간」과 「독립 학습자 수·기여 편중」이 계약에 없었다. 그래서 **한 학생이 혼자 30번 낸 것과 서른 명이 한 번씩 낸 것을 같은 증거로 통과**시켰다.
3. 실제 저장소에 래칫을 돌리는 자동 경로가 없어 정본의 「같은 커밋에서 검사 빨강」이 안 섰다.

### 배운 것 넷

- 🔴 **발주서를 고칠 때는 «정본을 다시 열어» 대조한다.** v3 이 반려된 까닭이 그것이다. 정본이 요구하는 넷 중 둘만 넣고 「누구의」와 「관측 기간」을 빠뜨렸다. GPT 는 정본 줄 번호를 대며 잡았다.
- 실행자는 **철학 전문·기억·트랙·결정 이력·아는미완**을 못 받는다. 판단이 필요한 것은 발주서 안에서 끝낸다.
- 범위 안에 **이미 알려진 결함**이 있으면 `## 맥락` 에 적는다.
- **완주해도 끝이 아니다.** 가지를 읽고 뜻을 확인한 뒤 합치는 것은 사람 몫이다. 이번에 사람이 판정한 것 둘 = 범위 밖 회귀 시험 수용 · 자동 검사 배선(`.github/` 는 실행자 금지 경로라 GPT 가 못 한다).
