## 0. 🔴 유호님이 이 트랙을 여신 진짜 까닭 — 이걸 놓치면 전부 헛돈다

**「토큰 때문에 GPT 에게 구현이랑 실행을 시키려는 것」**(유호 09-08).

즉 이 트랙의 성패는 「GPT 가 잘 짓나」가 아니라 **「클로드가 덜 쓰나」**로 잰다.

🔴 **앞 세션은 이 자를 통과하지 못했다.** 실측(같은 잣대 · 실효 기준):

| | 실효 토큰 |
|---|---|
| 클로드 | **20,902,136** |
| GPT | 115,057 |
| | **182배** |

내역 = 유호님께 쓴 답 51.1% · 셸로 직접 잰 것 37.1% · 파일 고치기 9.0% · 나머지 2.8%.

**까닭 둘.** ⓐ 답이 너무 길었다(표를 겹겹이 쌓았다) ⓑ 턴이 490개였고, 매 턴마다 그때까지의 대화 전체가 다시 실려 **길어질수록 한 턴이 비싸진다.**

### 그래서 이 세션이 지킬 규율 넷

1. **답을 짧게.** 결론 위주. 표를 겹치지 않는다. 한 답에 표는 하나까지.
2. **셸 명령을 묶어 부른다.** 한 턴에 하나씩 재지 않는다.
3. **재는 일도 발주서에 넣어 GPT 에게 시킨다.** 클로드가 셸로 훑는 것이 37%였다.
4. **한 트랙 끝나면 세션을 끊는다.** 길수록 비싸진다.

⚠ 다만 앞 세션이 파일을 많이 고친 데는 까닭이 있다 — 만진 여섯 중 **다섯이 GPT 금지 경로**(도구·정본·훅)였다. 그건 원래 사람 몫이다. 진짜 구현(앱 코드)은 GPT 몫이니 다음부터는 비율이 뒤집혀야 정상이다.

## 1. 무엇이 섰나 (앞 세션 결과 · 전부 master 에 있다)

### ① 판단 정본이 GPT 네 역할 «전부»에 실린다

유호 확정 09-08 「철학 정본만 이식하자」. 그전에는 **검수자·심문자만 5,672자를 받고 실행자·발주검토자는 0자**였다 — 짓는 쪽이 「무엇이 좋은 산출물인가」를 모른 채 짓고 때리는 쪽만 그 자로 때렸다.

**재는 자:**
```
node tools/GPT철학대조.js          # 표 · 하나라도 0이면 종료 1 · 못 재면 2
node tools/GPT철학대조.js --json   # 기계용
```
지금 = 네 역할 다 5,672자 ✅. 자동 검사(CI)에도 이미 든다(`tests/GPT철학대조.test.js` 18개 · 리눅스 초록 실측).

### ② 실행자 레인 첫 완주

`tools/GPT철학대조.js`(161줄) + 시험 18개를 **GPT 가 지었다.** 발주서 = `docs/_ops/발주/GPT철학대조.md`(판 v5 · 부록에 회차별 지적·처방 표).

실측 = 합 8 · 제품 7 · **완주 1** · 못탐 6 (`node tools/ai스택점검.js` ③실행자 축).

### ③ 문서를 실물에 맞췄다

`docs/GPT_정본.md` 역할표에 **발주검토자 행**을 세웠고(실제로 도는데 표에 없었다), 「철학 전문 안 받음」을 「게이트는 받음」으로 정정했다. `docs/발주서_틀.md` 에 **`## 부품` 절**을 세웠다.

## 2. 🔴 밟으면 다치는 것 — 앞 세션이 실제로 밟았다

| 함정 | 무늬 | 처방 |
|---|---|---|
| **파이프가 종료코드를 덮는다** | `... \| tee` 를 붙였더니 도구의 「확인불가(2)」가 셸에서 0으로 나왔고, 유호님께 **「완주입니다」로 잘못 보고**했다. 같은 날 `\| tail -5` 로 한 번 더 밟았다 | 성패를 읽을 명령에 파이프를 붙이지 않는다. 남기려면 `> 파일 2>&1` 뒤 `$?` |
| **만드는 자리가 둘이면 재는 자가 한쪽만 본다** | 한 판에 **세 번** 나왔다. 확인용/모델용 조립이 따로였고, 검수 함수는 철학을 «인자»로 받아 밖에서 주입 가능했고, 발주서 문장 「둘 중 하나라도」가 누락을 덮었다 | 조립 자리를 하나로 못 박는다. **자가 진짜인지는 «끊어보기»로 잰다**(끊은 자리만 빨개지나) |
| **셸이 백틱을 먹는다** | 기억을 적다가 heredoc 을 따옴표 없이 열어 **파일 이름·커밋 번호 일곱이 통째로 사라졌다** | 소스·기억 편집은 Write/Edit 나 «파일로 쓴 스크립트»로. 넣은 뒤 `grep` 으로 되읽어 센다 |
| **벤더 한도 마커가 낡는다** | 첫 회차가 「리셋 19:00 전」으로 막혔는데 실제로는 풀려 있었다 | `--한도무시` 한 번(성공 1회면 마커가 스스로 지워진다) |
| **날것 프롬프트 함수를 부르면 거짓 초록** | `제안프롬프트`·`기능체크프롬프트` 는 아직 내보내져 있다 | 새로 재는 코드는 **`제안프롬프트조립()`·`기능체크프롬프트조립()`** 를 부른다 |

## 4. 인터넷을 왜 끊었나 (다음 세션이 「그냥 열면 되잖아」로 되돌리지 않도록)

울타리는 «쓰기»만 막고 «읽기»는 안 막는다. 그래서 실행자가 **홈의 열쇠 파일을 읽을 수 있다**(`.clasprc.json` = 라이브 배포 열쇠 · `.ssh/id_ed25519` = 깃허브 열쇠 · `.codex/auth.json`). 09-04 프로브로 확인됐다.

**지금 안전한 이유는 하나뿐이다 — 읽어도 나갈 길이 없다.** 열면 그 벽이 사라지고, 남는 벽(커밋 전 비밀 무늬 검사)은 «저장»을 막지 «전송»을 못 막는다.

- codex 는 «일부 주소만 열기»를 **지원하지 않는다**(09-08 실측 · GPT 가 「없다」로 답했다). 전부 열거나 전부 닫거나.
- 그래서 **새 꾸러미는 실행자가 못 깐다.** 이미 깔린 것을 쓰는 것은 된다(형제 저장소 `../SYNK-talk` 는 부품 17개가 이미 깔려 있다).
- 새 부품이 필요하면 **사람이 발주 «전»에 깔고** 발주서 `## 부품` 절에 이름만 적는다. 도구는 안 깐다.
