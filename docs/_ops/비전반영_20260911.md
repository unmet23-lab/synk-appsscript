# SYNK 네 브랜드 비전 반영

> 2026-09-11. 사용자가 통합 문안을 확인한 뒤 “웅 이거 꼭 기억해주고 전체적으로 반영해줘”라고 요청했다. 실제 사용 문구는 [비전 정본](../비전_정본.md) 한 곳에 둔다.

## 확정과 적용

- SYNK는 1번을 채택했다. LAB과 SHIFT는 3번을 전면에, 1번의 내용을 서브텍스트에 두었다. PULSE는 3번을 전면에 두고 다시 찾아갈 세계와 서로를 더 깊게 만드는 작품의 관계를 서브텍스트에 함께 담았다.
- 정본의 전면 문장·전체 서브텍스트는 사용자에게 제시한 통합 문안과 정확히 일치한다. 기존 철학·상품 조건·현재 제공 상태는 비전과 구분해 보존했다.
- 사용자의 명시적인 기억 요청에 따라 Codex 기억 확장 메모를 저장했다. 개인 기억의 기존 색인·과거 기록을 직접 덮어쓰지 않았다.

## 재생성과 검증

`tools/lib/비전정본.js`가 네 브랜드의 전면 문장과 전체 서브텍스트를 읽는다. `tools/비전동기화.js`는 GAS 상담 지식과 FAQ의 지정 구간만 재생성하고, `--check`는 읽기 전용이다. 소개서 생성기는 현재 JSON 원고의 다른 문단을 보존하고 비전 필드만 원문에서 주입한다.

- 상담·철학 관련 시험 12개 통과. 실제 상담 프롬프트 도달, 주변 원문 보존, 반복 실행, 잘못된 구간의 쓰기 중단을 확인했다.
- 기존 소개서 HTML은 1440·390px에서 세 탭과 별도 SHIFT 지면의 비전 전문·가로 넘침·실행 오류를 확인했다. 지면에서 UTF-8 선언과 관리 표식 표시 문제를 발견해 생성기에서 고쳤다.
- 네 PDF는 각 5쪽, 전체 20쪽을 렌더해 확인했다. 모아보기의 전면·서브텍스트 8쌍이 정본과 일치하고 PC·모바일 가로 넘침이 없다. 소개서·계정별·실행판 ZIP 40개는 재개봉·내용 지문과 해당 내부 링크를 확인했다.
- Field Notes는 사이트 빌드의 244파일·561개 내부 참조 검사를 통과했다. 기존 소스와 변경 대상 6파일을 대조한 뒤 v11로 게시했다. 게시 뒤에도 실제 화면을 다시 검사했다.
- 홈페이지는 42개 시험을 통과했다. 게시 담당이 공개 6파일과 개인정보 1파일의 SHA-256을 실제 사이트와 대조했고, 비전 담당도 공개 HTTP 응답의 전면·서브텍스트 전체 8개를 확인했다. 게시된 PC·모바일 화면을 다시 읽어 지면을 확인했다.
- Google Drive에서는 지정 계정의 비공개 폴더와 기존 파일 ID를 보존했다. 원격 10파일의 ID·크기·부모·소유·공유 상태를 재조회했고, 원격 비전 정본을 다시 읽어 전면·서브텍스트 8개가 모두 일치함을 확인했다.
- 상담 배포 담당이 원격 개인정보 커밋 `0653fa1b2`의 CI `34515966251` 성공을 확인한 뒤, 비전이 포함된 22개 소스를 기존 배포 @46에 반영했다. 프로젝트 HEAD·@46의 실제 원문 바이트 동일을 다시 확인했다. crewcard는 기존 @34·5개 동일 상태를 확인하고 변경하지 않았다.
- 전체 저장소 CI 모사는 기존·동시 편집 범위에서 3개 실패가 있었다. 이를 전체 통과로 보고하지 않는다. 해당 실패는 session-freshness 작업본 검사, 다른 문서의 식별자 검사, 개인정보 HTML 서체 검사이며 배포 담당에 구분해 전달했다. 배포 보안 표면 검사는 통과했다.

기계 확인과 실물 화면은 `docs/_ops/비전반영_20260911/`에 있다. 전체 저장소의 다른 작업 파일·스테이징은 보존했다. main과 origin/master가 갈라져 있어 원격 최신 기준의 독립 작업본에서 이번 변경만 통합했다.

Field Notes 게시 소스는 `8ea243ffdbeda4fbc9de56facac21b754ae36c51`, 사이트 v11이다. 원문·상담·기존 소개서 지면의 최초 로컬 커밋 `ea57be018d6524c1f7d2928449546cf798990b01`을 원격 최신 위에 충돌 없이 통합한 `09f950c495f2ff7d65bdcd0e3afdae116f7efdba`를 원격 master에 반영하고 `ls-remote`로 재조회했다. 두 커밋의 27파일 patch-id와 정본 원문이 동일하다.

공개 홈페이지의 비전 배포 커밋은 `38ab91068cd929fb8d07162f628c24141519463e`이며, 문서 후속을 포함한 최종 공개판 `871ee87e66bf420df3e66cb9bf2fbfa5c44fc279`의 Pages 게시 성공과 실제 원문 7파일의 SHA 일치를 확인했다. Windows 줄끝의 재현성을 맞춘 홈페이지 원본은 `a0a45622750305991417317d3f924dcb8324d3c9`이다. 비공개 [Sites 홈페이지](https://synk-conversations.unmet23.chatgpt.site)는 v17 게시 성공이다(`appgver_106da4eab1848191a1877ca8b43c3ff3`, 배포 `appgdep_6aa2fae52ca881919248983c4c8d0b88`). 공개판과 비공개판 모두 기존 공개 범위를 유지했다.

소개서·파생 자료·초기 결과 기록 79파일은 `126b0ba5c7f31e5e74fb7daef5e12a42ac436c32`로 만들고, 원격 개인정보 변경 위에 통합한 `5ea86499fab118dfadbdd60cec857fbb60340f84`를 원격 master에 반영했다. 결정.md는 원격 최신 결정에 비전 1줄만 보탰고 나머지 78파일의 Git blob은 전달 커밋과 같다. PDF 4개는 현재 실물과 바이트가 같으며 원격 재조회도 일치했다.

## 기록과 과거 산출물의 경계

이번에는 현재 공식 소개·지식·생성 경로·공유 자료를 갱신했다. 이전 소개서의 편집 과정을 설명하는 영상은 당시 제작 사례로 보존했다. 학습용 몽골어 캐러셀에 비전의 새 번역을 임의로 넣지 않았다. 이미 전달된 파일·게시물·인쇄물을 회수하거나 외부에 메시지를 재전송하지 않았으며, 새로운 음성·영상 제작과 실제 고객 효과를 완료로 표시하지 않는다.
