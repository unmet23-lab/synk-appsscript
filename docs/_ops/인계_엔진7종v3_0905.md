## 🔴 다음 세션이 밟지 않아야 할 것

1. **모델을 바꾸지 마라.** 절끼리 견주는 자가 깨진다.
2. **결과를 그대로 문서에 붙이지 마라.** 아스트라가 낸 것은 «제안»이다 — 실물 이름을 하나씩 열어
   대조한 뒤에 합친다(§7 에서 아홉 곳을 그렇게 검증했다).
3. **읽는 사람이 절마다 다르다**(유호 09-05 「내가 읽는건 지금 이 작업엔 상관없어 너랑 GPT가 읽으면 돼」).
   · §0·§12 = 유호님이 읽는다 → 쉬운 말 규칙을 건다(도구가 지시문에서 자동으로 가른다)
   · 나머지 = 나와 GPT 가 읽는다 → 실물 이름·줄 번호를 그대로 쓰게 한다
4. **한도가 마르면 장부에 「실패」로 남는다.** 「끝」으로 안 적으므로 `--다음` 이 그 절을 다시 집는다.
   내(클로드) 쪽이 마르면 알릴 입이 없다 — 그래서 절마다 파일과 장부를 남긴다.
5. **두세 절 돌린 뒤 남은 양을 재라.** 열일곱이 한 창에 안 들면 그때 멈추고 유호님께 알린다
   ([[workflow-stage-split-session-limit]] · 09-03 에 여덟 절이 그렇게 죽었다).
