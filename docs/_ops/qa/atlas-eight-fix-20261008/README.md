# Atlas 8종 적용 준비 보완 — 2026-10-08

**푸시 보존판:** 아래 875개 검증은 당시 공용 작업본의 결과다. 원격 최신판에서 이번 변경만 분리한 보존 브랜치는 851개 시험과 브라우저8경로를 따로 통과했다. 다른 진행 작업에 의존하는 세 수정은 연결 패치로 함께 보존했다. 범위·커밋·적용 조건은 [PUSH.md](PUSH.md)를 따른다. 화면 캡처 원본은 로컬 작업본에 남기고 검증 텍스트만 푸시한다.

요청한 네 묶음을 로컬 구현과 무료 검증까지 완료했다. [최초 점검](../atlas-eight-audit-20261008/report.json)의 재현 문제 F1~F8을 수정했고, 이번 범위에서 남은 결함은 없다. 전체 성능의 최적해나 실제 사용자 효과를 증명한 것은 아니다. 기계 판독 결과·최종 원본 140개 해시는 [report.json](report.json)에 있다.

## 모델 평가 준비

확정 `invalid` 응답은 요청 UUID·requestId·revision·실행판이 일치하는 서버 영수증을 확인한 뒤 실패 결과로 저장하고 다음 사례로 진행한다. 저장 중단 후에도 같은 요청을 중복 과금하지 않는다. 불확실 전송·pending·증명 없는 오류는 계속 중단한다. 거절·미완료·인용·모델 불일치·형식·사용량 초과는 고정 실패 분류로 기록한다.

정상 오류 형식으로 확인된 신규 제공자 401/403만 비용0으로 정산한다. 원예약과 UUID는 남기고 설정 오류에서 캡처를 중단한다. 기존 uncertain 예약은 소급 해제하지 않는다. 일반 서버의 Domain 선적재 순서도 고쳐 실행판 증명이 우회 옵션 없이 성립한다. 관련 실제 loopback 서버·모의 제공자 검증은 [capture-result.json](capture-result.json)에 있다.

기존 [동결판](freeze-before.json)을 보존하고 해시가 바뀐 `interpretation.mjs`·`atlas/domain.js`를 다시 봉인했다. 동결 문장 본문은 검토자가 열지 않았고 데이터 바이트·모델·한도는 그대로다. [해시 변경](freeze-refresh.json), [호출 없는 계획 검사](frozen-plan.json): 동결 검증 통과·외부 호출0. 실제 유료 평가와 제공자의 첫 응답 모델 확인은 계속 보류다.
