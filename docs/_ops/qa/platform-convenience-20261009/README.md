# SYNK 플랫폼 편의 기능 구현 · 2026-10-09

사용자 요청 「우리한테 맞는 거 전부 구현해. 억지로 조잡하게 하는 건 하지 말고」에 따라 [10개 플랫폼 조사](../../../디자인/플랫폼_시그널/편의성_10개플랫폼_조사_20261009.md)의 후보를 현재 제품 구조에 맞춰 구현했다. 기존 싱ㅋ 시그널 화면과 계정·설치·저장 동의 계약을 유지한다.

사용자 「이어서 해」와 중단 후 재개 요청에 따라 개인 PC의 **SYNK Platform Preview**를 새 설치본으로 갱신하고, 바탕화면 **SYNK 플랫폼** 바로가기를 설치 EXE에 연결했다. 기존 프로필로 실행해 X 닫기·같은 창 복귀·계정 라이브러리 읽기를 확인했다. 이후 자동 시작·창 복원 보강본을 재설치했으며, 마지막 「배포하고 종료해」 요청에서 현재 소스·후보·설치 파일·바로가기·설정의 일치를 재확인하고 개인 PC 배포를 마감했다. 공개 서버·웹 배포나 새 로그인은 수행하지 않았다. 공유 라이브러리의 웹·데스크톱 생성 번들은 로컬에서 갱신했다. ## 적용한 사용 흐름

- 창 위치·크기·최대화 상태와 계정별 마지막 화면·스크롤을 기억한다. 모니터가 사라지면 사용 가능한 화면 안으로 복원하고, 숨긴 자동 시작에서 창이 잠깐 나타나지 않도록 최대화 복원도 지연한다.
- **Ctrl+K**에서 앱·화면·설정·기기 메모의 제목/내용·계정 메모를 찾는다. 방향키/Enter/Esc와 한글 조합 입력을 지원한다. 앱은 기존 실행 권한·설치 검사에 연결하고, 메모는 해당 카드에 초점을 맞춘다.
- 뒤로/앞으로 버튼과 **Alt+←/→**로 화면과 스크롤을 되돌린다. 입력칸에서는 원래 키보드 동작을 유지한다. 계정 변경은 탐색 이력을 분리한다.
- 트레이 오른쪽 메뉴에 즐겨찾기·최근 앱을 최대 5개 표시한다. 라이브러리의 우클릭 또는 **Shift+F10**으로 즐겨찾기 추가/제거·순서 이동을 한다. 즐겨찾기 순서는 홈·즐겨찾기 목록·트레이와 계정 라이브러리에서 반영된다.
- 설정에서 닫기 버튼의 트레이 동작, Windows 자동 시작, 자동 시작 때 창 숨기기, 전역 호출 단축키와 80~150% 확대를 고른다. 자동 시작·전역 단축키는 기본 꺼짐이며 충돌한 단축키는 기존 설정을 보존한다. 숨긴 시작은 Windows 자동 실행에만 적용하고 직접 실행은 창을 연다.
- 설정 검색, 단축키 도움말, 개인정보를 제외한 진단 정보 복사를 제공한다. 진단 복사는 고정 IPC에서 허용 필드만 다시 검사하며 계정 ID·이름·메모·토큰·경로는 복사하지 않는다.
- 플랫폼 알림함은 **이 창에서 진행한 로컬 설치 파일 준비의 완료·실패**를 모은다. 클릭하면 설치·업데이트 화면으로 이동한다. 배너 켜기/끄기, 30분/1시간 쉬기, 매일/평일 조용한 시간 설정을 제공한다. 다른 앱의 메시지나 미연결 서버 알림을 만들어 표시하지 않는다.
- 내 홈의 기존 **할 일/결과 메모**와 계정 라이브러리에 검색·미완료/완료 필터를 추가했다. 계정 라이브러리의 기존 v1 문서 구조를 유지하고 즐겨찾기 배열 순서만 재정렬한다.
- **작성 중인 메모 복구**를 계정별로 켜면 두 입력창의 초안을 기기에 암호화한다. 복구 여부를 직접 고르며 자동으로 정식 메모를 저장하지 않는다. 7일 안에 복구할 수 있고 만료본은 다음 저장소 접근 때 정리한다. 기능 끄기·명시적 로그아웃은 해당 계정의 복구본과 동의를 지운다. OS 암호화가 불가능하면 평문 대체 저장을 하지 않는다.
- 창이 숨겨지면 장식 애니메이션을 멈추고 초안 저장을 마무리한다. 실제 설치 작업·기존 계정 동기화는 유지한다. CPU 절감률은 측정하지 않았다.

## 초안과 계정 경계

렌더러가 전달한 계정은 저장 대상 선택값이 아니라 **현재 계정과 일치해야 하는 조건**이다. 메인 프로세스의 확인된 계정과 다르면 읽기·쓰기·삭제·동의 변경을 거절한다. 계정 전환 알림이 늦게 도착하거나 이전 비동기 응답이 나중에 돌아와도 다른 계정의 복구본이 보이거나 덮이지 않게 검사한다.

삭제는 진행 중인 읽기를 무효화한다. 복원은 이전 입력의 예약 저장을 취소하고 고른 복구 내용을 보관한다. 명시적 초안 버리기 후 종료는 삭제 완료를 기다린다. 삭제 실패 시 원래 입력을 다시 보여 주고 종료 보호를 유지한다. 일반 네이티브 종료의 **저장 없이 나가기**는 복구 기능을 켰을 때 마지막 복구본이 남는다는 안내를 제공한다.

계정 라이브러리 메모가 다른 기기에서 바뀌었다면 복구한 입력으로 원문을 덮지 않고 새 메모로 확인하게 한다. 저장 여부와 충돌 안내는 기존 계정 노트북 기능을 재사용한다.

## 개인 PC 설치와 후속 확인

- 새 Preview 설치 파일의 SHA-256을 대조한 뒤 정상 종료한 앱에 적용했다. 설치 종료 코드 0, 설치 EXE·ASAR·100개 실행 원본 등 **6/6 대조**, 설치 EXE 격리 부팅 **16/16** 통과. [설치 기록](delivery/README.md).
- 실제 Windows API로 시작 프로그램 등록/조회/삭제, 두 프로세스의 단축키 충돌/해제/복원, 실제 모니터 영역으로 창 복원을 **23/23** 확인했다. QA 설정을 제거했고 기존 시작 프로그램 레지스트리의 전후 해시가 같다. [OS 기록](os-integration.md).
- 소스 앱의 실제 화면에서 **Ctrl+K → 한글 ‘닫기’ 검색 → Enter → 해당 설정**을 확인했다. 임시 전역 단축키 **Ctrl+Alt+Shift+S**로 다른 앱이 앞에 있을 때 숨겨진 SYNK 검색창이 열렸고, 확인 후 원래의 꺼짐 상태로 돌렸다.
- 설치된 앱에서 **트레이에 남기기 켜짐 → X → 창 숨김·메인 PID 유지 → 바탕화면 바로가기 → 동일 창 복귀**를 확인했다. 설정·스크롤도 유지됐고, 최종 트레이 유지 설정은 켜짐이다.
- 기존 로그인 상태로 **계정 라이브러리 연결**을 눌러 저장된 최근 실행 기록이 표시되는 것을 확인했다. 인증창 조작·새 로그인·새 메모 저장은 하지 않았다. 최종 화면은 연결된 내 홈이다.
- 사용자 요청에 따라 이번 실제 기기 확인은 **이 PC 한 대**로 한정했다. 두 기기 동기화, Windows 재로그인, 절전 복귀, 물리 모니터 탈착은 미검증이다. [직접 관찰 기록](actual-pc.json).

## 재부팅·화면 변경 경로의 후속 보강

사용자 「이어서 진행해」에 따라 이 PC의 작업을 끊지 않는 격리 검사로 세 가지 문제를 재현하고 수정했다.

- Windows 작업 관리자에서 시작 항목을 끄면 앱도 **자동 시작 꺼짐**으로 표시한다. 명시적으로 켤 때만 Windows 허용 상태를 바꾸고, 저장 실패 시 이전 등록 여부와 비활성 상태를 각각 복원한다. 다른 이름·다른 실행 인수의 등록이 SYNK 상태를 대신하지 않는 것도 실제 API로 확인했다.
- 최대화했던 창을 숨겨 시작한 뒤 크기 변경이 생겨도, 아직 보여 주지 않은 최대화 예약을 유지한다.
- 실행 중 화면 작업영역이 바뀌거나 창을 다시 표시하면 위치·최소 크기를 현재 화면에 맞춘다. 최소화·최대화 상태는 유지하고, 일반 창으로 복원할 때 좌표를 맞춘다. Windows의 1 DIP 반올림에는 반복 재배치하지 않는다.
