## 독립 검수와 실행 근거

- 문항·권장 관계 82건은 정답을 가린 독립 풀이 뒤 원안과 비교했다. 처음 확인한 주장 오류 9건과 해설 오류 3건을 고쳤다. 추가 찻집 요청 12개 틀은 L1/L2 전개 152문장과 각 18가지 컵 대안을 대조했다. 실제 증거는 `experiences/topik-items/review/reports/`에 보존한다.
- 새로운 주문 음성 11개는 무료 로컬 음성 생성, 로컬 받아쓰기 대조와 실제 HTMLAudioElement 재생 종료를 확인했다. 사람의 청취 검수를 했다는 뜻은 아니다.
- 독립 코드 검수에서 실제 WORLD의 combined map 판과 TOPIK-I 단독 판의 불일치로 모든 지연 문항이 거절되는 P1을 발견해 수정했다. 실제 WORLD coach와 kit를 함께 쓰는 회귀를 추가했다.
- Study 저장기는 독립 검수자가 실제 v2 tutor/semantic 함수로 만든 13개 스냅샷(500문항까지의 보존 한도 포함)을 새 서버 계약에 통과시켰다. 이는 계정 UI 연결 시험과 별개다.
- 실제 Study 브라우저에서 답 작성→기존 API→PostgreSQL 저장→별도 기기 저장소 복원을 확인했다. 서버 필드는 최소 진도 6개뿐이고 초안은 업로드하지 않았다. 독립 검수자가 발견한 동기화 401 뒤 앞 계정 초안이 남는 P1은 계정 전환 경계에서 고쳤다.
- 독립 최종 검수의 Town 「나중에」 문자열/숫자 비교 P1을 고쳤다. 실제 DOM dataset의 문자열 변환을 재현한 회귀는 같은 제안 숨김 유지·새 제안 허용·막힌 장면 억제를 검사한다.
- 전체 루트 회귀 첫 실행은 1,856개 출력 뒤 상위 실행 종료로 끝 요약을 받지 못해 완료로 세지 않는다. 그때 확인된 실패 8개는 각각 수정 후 관련 회귀를 통과했다. 배포 판정에는 완료된 관련 시험과 최종 고정 후보 검수를 사용한다.
- 브라우저 합성 기록에서 WORLD 지연 확인 → 새 읽기 문항 하나 → 답·해설 → 내 위치의 d1 관측 갱신, 주문 게임의 실제 음성 종료 → 컵 제출 → d1 관측 갱신을 확인했다. 1440/390 화면 확인은 로컬 fixture의 동작 근거이며 실제 학생 성과가 아니다.

## 운영 반영

원천·생성물·검수 후보를 통합 중이다. 최종 커밋·공개·함수/SQL 반영·라이브 대조 결과는 실제 실행 뒤 이 절에 기록한다. 지금의 시험 결과만으로 운영 반영 완료를 선언하지 않는다.
