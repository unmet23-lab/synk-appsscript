## 운영 반영

운영 함수는 `synk-account` v79, `synk-learning` v71, `synk-town` v32로 표준 원격 배포했다. 실제 배포 묶음을 다시 받아 HEAD의 모듈 18·16·1개와 각각 일치하고 환경 이름 누락이 없음을 확인했다. 계정·Study·Town의 유효한 읽기 경로는 비로그인 요청에 모두 `401 AUTH_REQUIRED`를 반환했다. 최초 Town 루트 주소의 404는 존재하지 않는 경로를 조회한 시험 오류로 보존하고 `/state`로 바로잡아 확인했다.

운영 기능 설정은 비밀 조회 API가 돌려주는 digest를 기존 표준 정책의 정확한 직렬화 바이트와 대조했다. `learningSync`는 enabled=true·100%·최소 contract 1/앱 0.2.0이고 Town 활성값은 정확한 `true`와 일치했다. 설정을 바꾸지 않았으며 비밀 원문·토큰·digest 값은 기록하지 않았다. 이는 기능 활성 설정 확인이며 실제 학생 계정으로 두 기기를 왕복한 증거는 아니다.
