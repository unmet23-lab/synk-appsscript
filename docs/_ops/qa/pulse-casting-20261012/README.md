# PULSE 모델·스타일 선택

2026-10-12. 초기 제작 기획에서 고객이 모델·헤어·메이크업·자켓·상의·하의·목소리 A/B/C·귀걸이·반지를 직접 고르는 요청을 로컬 구현했다. 운영 배포·고객 발송·새 이미지/영상/음성 생성은 하지 않았다.

**이 채팅 종료·이어받기:** 사용자 승인으로 「PULSE 제작 사전 선택 기능 찾기」 채팅(`01a12c6f-be3c-7c00-bdaa-6d16f4ee60b7`)에 변경 파일·보존할 동작·검증 결과를 전달했고, 상대 채팅이 모델 선택을 포함한 통합 검증을 이어가고 있음을 확인했다. 이쪽은 공통 소스 추가 편집을 마쳤다. 실제 PULSE 반영과 고객의 선택→저장→새로고침 복원→제작자 동일 선택 확인은 그 채팅에서 이어갈 후속 작업이며, 종료 자체를 배포 완료로 기록하지 않는다.

## 현재 구현

- 기존 `public/pulse-app/strategy-view.mjs`의 제작 설계 폼에 `casting-view.mjs`를 연결했다. 바로가기, 7명 카드, 광고/런웨이 준비 상태, 옵션과 기타 메모, 현재 선택 및 저장된 선택 요약을 제공한다.
- `casting-catalog.mjs`는 승인 정본의 이름·설명·목소리 방향을 사용한다. 6장의 대표사진은 `desktop/assets/pulse/models/`와 바이트가 같다. 지유(F04) 사진, 21개 음성 파일, 광고·런웨이 영상은 현재 연결되지 않아 준비 중으로 표시한다. 사진에 선택한 스타일을 자동 합성하지 않는다.
- 구조화된 `castingSelection`을 기존 프로젝트 제작 설계에 저장한다. 모델 변경은 목소리만 미정으로 돌리고 나머지 스타일과 메모를 유지한다. 프로젝트 revision·권한·CSRF·버전별 확인/히스토리 규칙을 사용한다. 이전 클라이언트가 필드를 생략해도 기존 선택은 보존한다.
- 새 정적 자산을 서버의 명시적 제공 목록과 PWA 공개 셸 캐시에 추가했다. 실제 프로젝트·초대·고객 자료는 새 캐시 대상에 넣지 않았다.

## 검증

다음 6개 파일의 **46개 시험 전부 통과**: `pulse-casting.test.mjs`, `pulse-casting-client.test.mjs`, `pulse-casting-server.test.mjs`, `pulse-demo.test.mjs`, `pulse-strategy.test.mjs`, `pulse-studio-server.test.mjs`.

- 격리 HTTP 서버에서 고객 선택 저장 → 제작자 조회 → 서버 재시작 복원 → 변경에 따른 현재 확인 해제·기존 선택 이력 보존을 확인했다. 잘못된 enum·권한·revision, 허용하지 않은 nested 필드, 이전 클라이언트 저장도 확인했다. 실고객 프로젝트를 쓰지 않았다.
- 새 모듈 2개·CSS·대표사진 6장: 익명 GET 200, 응답과 소스의 바이트 일치.
- 실제 앱의 로컬 체험 브라우저에서 유나/웨이브/내추럴/블레이저/셔츠/슬랙스/B/스터드/반지 없음/메모를 선택·저장했다. 새로고침 후 복원, 이안 변경 시 스타일 유지·목소리 초기화, 탭 이동 후 미저장 초안 유지, 재저장 후 핵심 메시지·근거·행동 보존을 확인했다.
- 390px·320px에서 캐스팅 영역 가로 넘침 0, 대표사진 6개 로드 성공. 휴대폰 크기로 조절한 PC 브라우저 검사이며 실물 휴대폰 인수는 아니다.
- 읽기 전용 폼은 disabled 필드를 FormData가 생략하는 문제를 찾아 form.elements로 읽도록 고쳤으며 회귀시험을 추가했다.
- 같은 폴더의 제작 설계 간소화·납품 규격·표현 샘플 작업과 병행 중이다. 그 변경을 보존하면서 저장한 모델 요약을 재연결했다. 최종 브라우저 검사 당시 새 핵심 입력 3개와 캐스팅이 함께 표시되며 관련 46개 시험을 통과했다.

## 남은 준비

지유 승인 대표사진 연결, 모델별 메인 광고 1편·런웨이 1편(합계 14편), 모델별 목소리 A/B/C 음원 21개와 실제 청취 확인, 스타일 옵션의 참고 이미지가 남았다. 음원 라벨의 근거는 기존 정본이며 파일이 재연결되면 라벨·음색 일치와 재생/오류/동시 재생을 확인한다. 영상과 음성은 이번 작업에서 제작하거나 재생 완료로 판정하지 않았다. 세부 옵션은 기획 희망을 수집하는 가안이며 상품별 제작 가능 조합·실제 결과를 보장하지 않는다.
