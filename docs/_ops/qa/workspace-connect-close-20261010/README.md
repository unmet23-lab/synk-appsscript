- Workspace는 반 관리·학생 케어·공통 계정에 필요한 소스와 직접 의존만 최신 원격 기준으로 합쳤다. 기존 고객·제작·업무실 변경을 유지했다. 관련 Node 시험 97개와 교사 화면 번들 대조가 통과했다.
- WORLD 계정 원문은 후행 별도 게임 작업을 제외하여 이번 공개본의 번들과 바이트 단위로 일치하게 보존했다. 계정/학생 연결 11개 및 OAuth 공개 등록 41개 시험을 통과했다. 후행 공유 원본은 덮어쓰지 않았다.

- 빌드 누락을 막기 위해 승인 브랜드 오프닝 13개와 화면의 직접 의존을 함께 보존했다. 공개 빌드는 참조 누락/소스 변동/제작 메타데이터 누출 없이 성공했다. 최신 원격 게임을 보존한 출력 1,663개는 이전 공개 537개와 동일한 릴리스가 아니며 새 공개 배포를 하지 않았다.
- 실제 공개 데모에서 수업 진입의 누락 함수를 재현했다. 한 파일의 3줄 추가·2줄 변경으로 초기 진입과 탭 이동을 고쳤고 기존 4개 탭을 포함한 9개 검사를 통과했다. 운영 최종 결과는 후속 인수 기록에 남긴다.
