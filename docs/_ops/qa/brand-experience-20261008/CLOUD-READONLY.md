## 남은 연결 사항

1. 진행 중인 클라우드 작업의 최종 검수 결과를 받아 동일 후보로 이어간다. 새 VM·새 버킷을 중복 생성하지 않는다.
2. 그 작업에서 준비 중인 `workspace.synk.im` DNS·공인 HTTPS·공개 80/443·최소 운영 권한을 적용하고, Caddy가 실제 Host를 보존하는지 확인한다. Node 4191은 외부에 직접 공개하지 않는다.
3. 원래 두 DB·키·첨부·계정 연결을 최종 일관 백업으로 옮기고 `/srv/synk/company`를 사용한다. 기존 클라우드 재개 문서의 PC PID 12888은 이전 기록이다. 이번 PC 반영은 PID 20072·4191/4197로 끝났으므로, 이전 작업을 재개할 때 현재 writer와 새 백업 기준을 다시 확인해야 한다.
4. 직원의 공인 콜백과 별도 고객 상담 OAuth는 클라우드 작업 담당자가 준비한 등록 절차를 따른다. **PULSE 고객 라운지 `/pulse/`는 초대 링크와 자체 고객 세션을 쓰며, `/consultation/`의 별도 고객 SYNK ID 로그인과 다른 흐름이다.** 모든 고객 접속을 OAuth 하나의 미완료로 묶지 않는다.
5. 비공개 자동 백업·복구 인수·권한·모니터링·알림 도착·백업 성공 누락 감시를 실제 운영 설정에서 확인한다. 이후 외부 고객 흐름과 PC를 끈 실물 휴대폰 접속을 검증한다.
