## 10-09 당시 이어서 확인할 것으로 남긴 항목

1·2번의 백업 관측·설치/로그인 후속은 [현재 회사 운영 기록](../../../마케팅/온라인마케팅지도/engagement/company/CLOUD-OPERATIONS.md)과 [후속 실제 설치·계정 확인](../platform-real-account-20261010/README.md)에서 확인한다. 아래 시각과 후보로 지금 관측기를 새로 설치하거나 재설치하지 않는다. 실제 고객 인수와 실물 기기 확인은 각 후속 증거의 범위대로 구분한다.

1. 상담 조건 없는 저장 수정과 부모 릴리스의 VM 재부팅 후 기록 복원을 확인했다. 현재 v3는 서비스 재시작·실제 직원/상담 고객 로그인·기존 기록·완료 백업의 독립 복구까지 확인했다. 다음 예정 백업은 10-09 03:31:22 KST, 기존 담당의 03:50 1회 관측기는 준비됐으나 아직 실행 전이다. 첫 백업·복구 성공을 예약 실행 관측으로 대체하지 않고 관측기를 중복 설치하지 않는다.
2. Messenger 클라우드 연결과 Platform의 등록 해시·동봉 설치본을 함께 반영했다. 사용자는 설치 Platform 로그인 성공을 알렸고, 이어 빈 앱 목록 문제를 고쳐 개발판 10개를 노출했다. Platform 로그인 보고를 Messenger 로그인 왕복으로 확대하지 않으며 후자와 WORLD 시작 차단 해결은 남아 있다. 정식 서명·공개 배포는 이번 개인 PC Preview 적용과 구분한다.
3. 사용자는 현재 휴대폰 사용이 어렵다고 답했다. 실물 검증은 미완료로 남긴다. 가능할 때 PC를 종료하고 휴대폰에서 클라우드 작업실 로그인 → 본인 메모와 첨부 열기 → 브라우저를 닫았다 다시 열어 같은 기록 확인 순서로 검사한다. 상담 화면에서도 시험 내용을 저장하고 재접속해 복원되는지 확인한다. 기종·운영체제·브라우저·확인 시각과 결과만 기록하고 계정·토큰·초대 링크를 공개 문서에 복사하지 않는다.
4. 실제 고객 초대·자료 전달·인수와 고객 만족·문의 감소·제작 시간·학습 효과는 운영 후 확인한다. 현재 시험 통과 수를 사업 성과로 사용하지 않는다.

공용 작업본의 기존 미커밋 변경은 보존했다. 승인한 쇼룸 7파일을 공개하고 개인 PC에 세 Preview 앱을 설치·업데이트했다. 실제 고객 메시지 전송·유료 AI 호출은 수행하지 않았다.
