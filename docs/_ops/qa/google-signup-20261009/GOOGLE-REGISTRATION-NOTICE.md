# Google 가입 안내 변경안 · 미공개

**최신 범위:** 사용자가 Google 로직을 먼저 완성하고 문자 서비스를 출시 직전으로 미뤘다. 현재 개발 가입 화면은 국가·만 나이·성별과 개인정보 안내 확인만 받는다. 새 휴대폰 번호를 보내거나 인증 완료로 간주하지 않는다. 인증 증거가 없는 계정은 미인증·인증 연기로 저장한다. 아래 문안은 문자 서비스를 연결할 때 사용할 이전 출시 초안이며 현재 화면의 수집 항목 설명으로 그대로 사용하지 않는다. [현재 구현·검증](../google-only-20261009/README.md).

Google/SMS 활성화와 함께 기존 `synk.im/privacy/#synk-id`에 반영할 문안이다. 현재 공개 안내를 변경하거나 문자 사업자를 확정하지 않았다. 기존 이메일 가입·학습 기록·삭제 정책은 유지하고 아래 정보를 추가한다. SMS 사업자의 계약 정보가 준비되면 위탁·처리 위치를 실제 설정에 맞게 확정한다.

## 가입 화면에 표시할 내용

Google로 가입하면 별도 SYNK 아이디와 비밀번호를 만들지 않습니다. Google에서 제공하는 계정 식별정보·이메일·기본 프로필(이름과 프로필 이미지가 있는 경우 포함)을 인증 서비스에서 처리하며, SYNK 서비스에서는 같은 내부 계정으로 연결합니다.

휴대폰 번호와 인증 상태, 직접 입력한 국가·만 나이·성별, 가입 안내 확인 시각과 판을 계정 관리와 서비스 제공에 사용합니다. 국가·나이·성별은 직접 입력한 정보이며, 휴대폰 인증으로 사실 여부나 법적 본인확인을 확인하는 것은 아닙니다. 생년월일은 받지 않고 만 나이는 입력 당시 기준일과 함께 보관합니다. 성별은 ‘응답하지 않음’을 선택할 수 있습니다.

휴대폰 인증은 같은 Google 인증 계정에 번호를 연결하는 방식입니다. 번호는 인증 서비스가 보관하고 SYNK 가입 정보에는 인증 성공 상태와 확인 시각을 보관합니다. 인증번호는 가입 정보나 SYNK 로그에 저장하지 않습니다. 나라·나이·성별을 일반 앱 프로필이나 Atlas 맞춤 요약에 자동으로 넣지 않습니다. 학습 기록 저장은 별도로 선택하고 언제든 끌 수 있습니다.

이 정보는 계정 삭제 처리까지 보관하고 기존 계정 삭제 절차에 따라 삭제합니다. 신규 Google 인증 사용자가 가입 입력을 완료하지 않은 경우 인증 서비스의 사용자는 먼저 만들어질 수 있지만, 내부 SYNK 계정과 앱 기록은 가입 완료 전 생성하지 않습니다. 휴대폰 번호를 보내기 전에 수집·이용 안내 확인이 필요합니다. ‘나중에 하기’는 브라우저 로그아웃이며 Google 인증 계정과 입력·인증한 번호는 가입을 이어갈 수 있도록 남습니다. 가입 대기 정보 삭제는 화면의 `hello@synk.im` 문의 링크로 요청할 수 있습니다. 실제로 운영되지 않는 자동 삭제 주기를 약속하지 않습니다.

## 공개 전 연결할 운영 정보

- Google 로그인 제공자의 처리 범위와 개인정보 안내 링크.
- 기존 Supabase 인증·저장 위치와 실제 SMS 발송 사업자의 법인명·처리 항목·처리 위치·보관 조건.
- 문자 공급자의 전송 로그에 포함되는 번호·전송 결과와 보관 설정. ‘SYNK 로그에 남기지 않음’을 외부 사업자 로그도 없다는 뜻으로 확대하지 않는다.
- 실제 이용 흐름과 공개 개인정보 안내의 일치 확인.

이 문서는 개인정보 처리 구현을 설명하는 추가 문안이다. 공급자 계약이나 국외 이전의 법률 판단이 완료됐다는 의미는 아니다.
