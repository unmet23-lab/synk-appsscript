# Atlas 재설계 단계 1(지도와 태그) — 끝 판 검수 배경

**무엇.** 새 엔진 `packages/atlas/`의 지도(Strata)를 지었다. 두뇌(단계 2)가 낱말 · 문형 · 생활 표현 · 한글 글자마다 기억을 따라가려면 ① 단위 목록과 이름 ② 문항마다 묻는 단위(첫째가 주 단위) ③ 덧붙이기만 하는 문항 · 계열 번호와 색인 판이 있어야 한다. 정본은 `docs/아틀라스_재설계_20261110.md` §3-1 · §4 · §9, 계획 · 기록은 `docs/_ops/qa/atlas-redesign-20261110/단계1_계획.md`(§2 꼴 · §3 번호와 판 · §5 태그 · §7 내기 · §12 Fable 설계 검토 16건과 처리).

**학습 판단에 닿는 곳(엔진급 검수 범위).**
- `src/map/index.mjs` `openMap` — 엔진 묶음에 드는 유일한 지도 코드. 두뇌가 받는 문항 꼴(`units` 첫째 = 주 단위, 태그 없으면 `family:<계열>`), 계열 줄(판마다 열쇠가 생기는 한글 · 드라마 — 제품이 넘긴 난도 · 꼴을 얹음), 색인 밖 문항, `familySkills`(단계 2 기기 얹기가 받는 값), 이름 사슬.
- `src/map/ledger.mjs` — 번호는 덧붙이기만. 번호가 다른 문항을 가리키게 되면 만난 표 · 다시 접기가 틀린다.
- `src/map/compose.mjs` — 원천의 앞뒤(태그 자료 > 규칙 > 제품 `conceptIds` > 없음), 멈춤 조건, 접기 칸(`FOLD_FIELDS`)과 바뀐 것 목록 `{ n | f, from, to }` — 단계 3 서버가 다시 접을 단위를 고르는 근거.
- `tools/map-build.mjs` — 색인 판은 접기 칸 해시가 바뀔 때만 오른다, 계열 이름 후보 · origin 장부가 앞서면 `--write`를 멈춘다.
- 태그 자료 `map/tags/*.json` — 1차 Opus 5.5 · 2차 아르곤 2중 검수를 거친 줄만(검수 판정 없는 줄은 빌드가 멈춤). 기준 글 `map/tags/rubric-r1.md`.

**학습 판단 밖(도구 · 시험).** `tools/map-sources.mjs`(제품 은행 읽기), `map-ship.mjs`(판 폴더로 내기 · 은행 조각), `map-tags.mjs` · `map-tags-content.mjs`(검수 통로 — `tools/lib/클로드키.js` · `제미나이구독호출.js`를 부른다), `tools/build.mjs` · `budget.mjs`의 지도 줄, 시험.

**지키는 것.** 12/10까지 라이브는 지금 판 — 제품 은행 · `atlas/` · `strata/`는 고치지 않았다(태그를 제품 은행에 쓰면 지금 엔진이 `conceptIds`를 읽어 공개 때 라이브가 바뀐다). 생성물(`map/index.json` 등)은 커밋하고 패키지 빌드는 그것만 낸다(제품 코드를 부르지 않는다).

**검수자에게 특히 볼 것.** ① 두뇌 계약(`단계2_계획.md` §2-1의 문항 꼴 · `src/fold/units.mjs`의 `family:`)과 읽기가 맞나 ② 번호 · 이름 바꾸기 · 은퇴에서 번호가 다른 문항을 가리키는 길 ③ 바뀐 것 목록이 서버 다시 접기(설계 §4 · §5-3)에 충분한가 ④ 생활 단위를 계열 71이 아니라 표현 23으로 좁힌 것(설계 §3-1과 다름 — 결정 표) ⑤ 판정 규칙(둘 다 통과 · 둘이 같은 고침 · 그 밖은 Opus 판정).
