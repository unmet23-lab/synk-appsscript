## 1. 시제품

제품 코드가 아니다. 새 두뇌(기억 · 작업 난도 · 고르기 · 이유)의 규칙이 검수의 결함 장면을 실제로 없애는지, 고정 사다리와 견줘 어떤지를 숫자로 보려고 만들었다. 구현 세션은 이 파일을 계약의 예로 읽고 `packages/atlas/`에 새로 짓는다. 지금 있는 것은 설계 검토 뒤 고친 2판이다.

| 파일 | 무엇 |
|---|---|
| [`prototype/brain.mjs`](prototype/brain.mjs) | 새 두뇌 시제품 2판(약 260줄). `ts-fsrs`의 기억 계산 위에 등급 대응 · 같은 자리 접기 · 작업 난도 · 예상 성공 확률 · 층으로 고르기(한도 · 셋에 하나 새것 · 살릴 수 있는 것부터 · 숨 고르기) · 이유 종류와 근거 칸 |

돌리는 법(저장소 어디서나):

```bash
node docs/_ops/qa/atlas-redesign-20261110/prototype/scenarios.mjs
```

```bash
node docs/_ops/qa/atlas-redesign-20261110/prototype/sim30.mjs
```

```bash
node docs/_ops/qa/atlas-redesign-20261110/prototype/sweep.mjs
```

- `sim30.mjs`의 기본값은 `POLICIES=current,ladder,ladderMix,brain` · `BASES=0.7,2` · `LEARNERS=40`이다. 지금 엔진(`current`)은 실제 코치를 돌리므로 가정 하나에 2분쯤 걸린다 — 빼려면 `POLICIES=ladder,ladderMix,brain`. 지금 엔진은 [검수의 재현 도우미](../atlas-fable-review-20261110/repro/core1/common.cjs)를 그대로 쓴다.
- `sweep.mjs`는 10~15분 걸린다(지금 엔진은 돌리지 않는다).

**가상 학습자의 가정.** 낱말마다 반감기가 있고, 어렵게 떠올릴수록 반감기가 크게 늘며, 놓치면 줄어든다. 못 떠올리면 넷 중 하나를 찍는다. 새 두뇌의 기억 모형(FSRS)과 다른 모형으로 만들어, 모형이 자기 자신을 맞히는 시험이 되지 않게 했다. `sweep.mjs`는 이 가정의 손잡이 넷(망각 속도 · 어렵게 떠올린 보람 · 놓쳤을 때 깎임 · 찍어서 맞힌 답이 기억을 깎는가)을 36가지로 바꿔 본다. 이 숫자는 규칙을 견주는 자료이고 실제 학습 효과의 증거가 아니다.

**견주는 조건.** 고정 사다리(1 · 3 · 7 · 14 · 30일)에는 새 두뇌와 같은 새것 한도(판 6 · 하루 20), 같은 「다시」 규칙(다른 문항 둘 뒤 · 한 판에 두 번), 같은 채우기 차례를 주었다. 사다리는 두 갈래다 — 돌아온 것이 남아 있으면 새것을 내지 않는 「복습 먼저」와, 새 두뇌처럼 「셋에 하나 새것」. 지금 엔진은 동점을 문항 번호 순으로 가르므로, 같은 낱말의 두 문항이 이웃해 나오지 않도록 문항 번호를 사람마다 섞었다.
