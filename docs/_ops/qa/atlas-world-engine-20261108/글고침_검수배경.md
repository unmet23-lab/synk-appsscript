## 고친 것
- **복습 세는 단위를 표현으로.** `life-progress.mjs` 요약에 `dueExpressions`(같은 글자의 표현은 하나, 글이 없는 복습은 세지 않고 다 없으면 장면 수)를 더했다. `dueCount`(장면 수)는 그대로 둔다. 홈 칩 · 튜터 단추 · 배우기 줄 · 복습 화면 큰 글 · REVIEW 라벨이 표현 수를 쓰고, 복습 화면 부제가 장면 수를 말한다. 여섯 장면을 넘게 밀리면 부제 「먼저 새 장면 6개에서 다시 골라요」 + 목록 머리 「먼저 만날 표현」으로 큰 글(전체)과 줄(이번 회차)의 범위를 가른다. 복습 회차의 1 / 6은 장면 기준 그대로다. 옛 묶음의 요약에는 칸이 없어 `??`로 장면 수로 돌아간다.
- **복습 목록.** 줄마다 같은 부가 설명을 없앴다(`reviewListShape`): 모든 줄의 때 · 곳이 같으면 목록 위 한 줄로, 장면 수가 다 같으면 줄에서 뺀다. 결과 화면은 표현마다 불 하나와 짧은 말(잘 기억했어요 · 조금 뒤 다시 나와요), 같은 설명은 목록 아래 한 줄, 머리는 「복습한 표현」, 잘 기억한 표현을 먼저 둔다. 결과의 표현 수는 `items.length||run.ids.length`.
- **내 위치의 방어 문장과 「칸」.** 소개 · 다시 확인 안내 · 먼저 볼 항목 안내에서 「…하지 않아요」 문장을 뺐다. 「칸을 정해요 · 칸에 세지 않은 답 · 세지 않음」과 「새 문제」를 「내 위치에 반영 · 새 문항」으로. 「급수를 판정하지 않는다」는 뜻은 ESTIMATE 칸(`position.estimate.basis`)에 남는다.
- **진도 줄의 뜻.** 「확인한 항목 1 / 8」이 바로 아래 「확인 중」과 부딪혀 「기록이 있는 항목 1 / 8」로(`row.checked`는 칸이 아직이 아닌 항목 수다). 다시 확인 카드 단추는 「다음 레슨을 열어 확인하기」 · 「새 장면 복습을 열어 확인하기」.
- **이번 주 계획.** 큰 제목이 위 막대와 같은 「이번 주 계획」이었다 → 「이번 주 연습 N번」(계획이 없으면 옛 제목), 이번 주 칸 머리는 「한 번에 N분쯤」. 계획 밖에 한 줄(주 N번에 들지 않은 생활 레슨 등)은 「계획 밖에 한 것」으로 아래에 가른다. 아래 칸 제목은 「다시 확인 일정」. 계정 묶음에 든 함수라 공개본 묶음은 앵커 셋으로 고친다(`글고침_공개묶음.cjs` — 함수 인자 이름은 공개본 줄에서 읽어 맞춘다, `글고침_공개검사.mjs`가 원천 판과 글자까지 대조).
- **홈 카드.** 「N / 22 학습 완료 · 이 기기의 진도」 → 「N / 22 레슨 완료」, 좌상단 부제에서 같은 수를 뺐다(세로 화면은 이 줄이 화면 읽기 전용이고 카드 진도 줄도 숨어 있어 화면 읽기에만 수를 남긴다), 링크 줄을 가운데로, 영어 · 몽골어 링크를 짧은 꼴로 한 줄에, 영어 · 몽골어 칩은 글 길이만큼, 몽골어는 돌아온 표현이 없을 때 칩에 「Давтлага」만.
- **평소 저장 상태 줄.** 「이 기기에 저장돼요」 · 계정 저장 끝을 화면에 말하지 않는다(`visibility:hidden` — 자리는 남아 글이 바뀌어도 들썩이지 않고, 저장 중 · 실패 · 충돌은 그대로 보인다).
- **숫자 글꼴.** 한글이 섞이는 작은 수 줄(이번 주 칸 수 · 기록이 있는 항목 · 진단 진행)을 모노에서 본문 글꼴로 — 빗금 친 0이 따로 놀았다. 근거 줄의 불은 첫 줄 앞으로. 근거 줄 날짜(12px 모노)와 한국어 화면의 항목 이름 라벨(진단 · 연습 · 시험 형식 문항 위, 연습 끝 화면 — 11px 모노 대문자)도 본문 글꼴 13px로(다른 세션 `world-finish-rows-20261109-b` F1을 넘겨받음, CSS만 — 이 화면들은 타이핑 움직임이 없다).
- 튜터 대사 「이어 가」 → 「이어가」(줄이 어절 사이에서 끊겼다). 영어 「Practice N times this week」 · 「Back to town」 · 「after a longer break」 · 「Re-check」.
- 몽골어 바뀐 줄은 세 겹 검문을 마쳤다(`experiences/brand-opening/qa/mn-check-20261109-copy/README.md`).
