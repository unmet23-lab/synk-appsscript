# SHIFT 운영 환경 확인

2026-10-07. [환경 조사 결과](environment-report.json)는 기존 로컬 회사 호스트와 앞으로 정할 운영 대상을 구분한다. 사용자는 운영 환경과 고객이 모두 미정이라고 답했다. 설치·배포·서버 재시작·계정 로그인·운영 데이터 변경은 하지 않았다.

현재 `http://127.0.0.1:4191/`는 준비 완료인 회사 워크스페이스이고 `4197`은 같은 프로세스가 메신저 주소로 이동시킨다. 이 주소는 현재 PC 안에서만 쓸 수 있으며 외부 직원이나 실제 휴대폰의 공용 접속 주소로 확인한 것이 아니다. 이전 `4299` 미리보기는 실행 중이지 않다.

현재 `/workroom-practice-sync.js`를 요청하면 `404`다. 공개 `/workroom-practice.js`의 HTTP 응답은 현재 원본과 SHA-256이 일치한다. 이 비교는 정적 파일 한 개의 일치만 확인하며, 준비 완료 응답·프로세스 시작 시각·정적 파일만으로 실행 중인 서버 판본 전체가 이번 검증 후보와 일치한다고 판단하지 않는다. 비로그인 실습 API의 `401`도 일반 보호 동작일 뿐 최신 기능 로드의 증거가 아니다. 보고서에 주소·확인 UTC·응답 상태와 공개 스크립트 해시를 남겼으며 사용자 응답 본문은 읽지 않았다.

공식 실행기의 회사 데이터 폴더는 `company/data`, 기존 통합 설정의 메신저 데이터 폴더는 `tools/company-messenger/data`이며 실행기 PID 표식이 실제 리스너와 일치한다. DB·32바이트 키·통합 설정 파일의 존재만 확인했다. 사용자 작성 본문과 키는 읽거나 출력하지 않았고 계정 ID도 출력하지 않았다. 실행 중인 프로세스의 환경값이나 DB 핸들까지 확인한 것은 아니다.

Docker·Podman은 PATH와 확인한 일반 설치 위치에서 찾지 못했다. WSL 2.7.13은 있지만 Linux 배포판이 0개여서 실제 Linux 컨테이너 검증을 수행할 환경이 없다. Node 24.18.0, SSH 클라이언트, 공식 Claude Code 2.1.291은 있다. SSH 목적지는 정해지지 않았고 Claude는 버전 확인만 했다. 로그인·필수 검수 모델 가용성·검수 실행을 확인한 결과가 아니다.

지금은 격리된 배포 파일 실행·합성 계정 백업 복구·첫 고객 비교와 비용 기록·두 번째 재사용 판정 자료를 마무리할 수 있다. 실제 운영에는 서버와 HTTPS 주소, 영구 데이터 위치, 담당자와 점검 시간, 실제 PC와 휴대폰이 필요하다. 공개로 나가는 결과는 [AI 운영 원칙](../../../AI_운영원칙.md)의 Claude Opus 5.5 최대 추론 최종 검수도 완료해야 한다. 이번 조사에는 설치나 유료 AI 호출을 포함하지 않는다.
