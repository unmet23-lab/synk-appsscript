# WORLD 게임 스킨 — 터치에서 탭 뒤에 남는 hover 고리 (2026-11-04)

**결함:** 휴대폰에서 시작 단추를 탭하면 `:hover`가 그대로 남아, 흰 알약 둘레에 코랄 고리(`box-shadow:0 0 0 5px …`)가 붙어 있었다. 터치 기기는 탭 뒤에도 그 요소를 hover 상태로 둔다. 주문 폭주 공개 때 Fable 검수가 찾아 주문 폭주만 고쳤고(`52d67dd7c`), 같은 블록이 다른 게임 스킨에 남아 있었다.

**고침:** 주문 폭주와 같은 꼴로, 각 스킨의 `:hover` 규칙을 그 자리에서 `@media (hover:hover){…}`로 감쌌다. 값 · 순서 · 선택자는 그대로다.

- 대상: 말의 리듬 9줄 · 바람길 6줄 · 빈칸 베기 3줄 · 바닷가 레이스 2줄 · 말 랠리 3줄(주문 폭주는 이미 고쳐져 있다)
- 빈칸 베기 `.next #r-again:is(:hover,:active)` 한 줄만 눌림 줄과 hover 줄 둘로 나눴다. 터치에서도 눌림은 남아야 해서다.
- `.dialog-toggles .chip-btn:is(:hover,:active){background:none;transform:none}`은 밖에 둔다(주문 폭주도 같다). 칠하는 줄이 아니라 지우는 줄이라 남아도 보이는 것이 없다.

**이번 공개 후보:** 빈칸 베기 · 바닷가 레이스 · 말의 리듬 · 바람길의 `world-skin.css` 넷과, 스킨을 토큰으로 부르는 말의 리듬 · 바람길 `index.html`의 `?v=` 둘. 말 랠리는 아직 공개 전 게임이라(공개본에 폴더가 없다) 소스만 고치고 그 게임이 공개될 때 함께 나간다. 후보의 스킨 넷은 공개본과 고치기 전 바이트까지 같았다.

**이미 잰 것(`docs/_ops/qa/world-skin-hover-20261104/터치고리재기.cjs`, 스킨 파일만 갈아 끼운 전 · 후):**
- 터치 390(hover 없음): 입구에 보이는 단추를 실제로 탭한 뒤 box-shadow · background가 탭 전과 같다. 전 판은 시작 알약에 코랄 고리가 남는다.
- 마우스 1440: 같은 단추에 올렸을 때 값이 전 · 후 같고, 시작 알약에 고리가 뜬다.
- 규칙 대조: 브라우저 해석기로 두 판을 펼쳐 견주면 「:hover 규칙만 쿼리 안으로 들어갔다」 말고 다른 규칙 · 순서 · 값이 같다. 화면에 안 나오는 단추(결과 · 멈춤 창)까지 이것으로 덮는다.
- LAB: 바뀐 줄은 모두 `:root[data-host=world]` 아래라 틀 없이 연 화면과 무관하다. 계산 스타일 · DOM · 픽셀 차이 0을 재었고, 이번 공개에 LAB 파일은 없다.

**같은 결함이 다시 들어오지 않게:** `tests/world-skin-hover.test.js`가 모든 게임 스킨에서 쿼리 밖 `:hover`를 잡는다. 새 게임은 앞 게임 스킨을 옮겨 쓰기 때문이다.

**볼 것:** 감싸다 괄호가 어긋나 뒤 규칙이 통째로 죽는 곳은 없는지 · 쿼리 밖에 남은 칠하는 hover가 있는지 · 터치에서 눌림 표시(`:active`)가 사라진 곳은 없는지.
