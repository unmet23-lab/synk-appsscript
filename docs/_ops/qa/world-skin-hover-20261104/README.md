# WORLD 게임 스킨 — 터치에서 탭 뒤에 남는 hover 고리 (2026-11-04)

휴대폰에서 단추를 탭하면 `:hover`가 그대로 남아, 흰 시작 알약에 코랄 고리가 붙어 있고 선 알약 · 소리 단추에는 눌린 색이 남았다. 주문 폭주에서 고친 꼴(`@media (hover:hover){…}`)을 나머지 스킨에도 옮겼다. [재는 도구](터치고리재기.cjs) · [지킴 시험](../../../../tests/world-skin-hover.test.js) · [검수 배경](검수배경.md).

- 빈칸 베기 `.next #r-again:is(:hover,:active)`는 터치에서도 눌림이 남아야 해서 `:active` 줄과 hover 줄로 나눴다.
- `.dialog-toggles .chip-btn:is(:hover,:active){background:none;transform:none}`은 칠하지 않고 지우는 줄이라 쿼리 밖에 둔다(주문 폭주도 같다).
- 화면에 안 나오는 단추(결과 · 멈춤 창)는 도구의 규칙 대조로 덮는다: 브라우저 해석기로 전 · 후를 펼치면 다른 규칙 · 순서 · 값이 같고 hover 규칙만 쿼리 안으로 들어갔다.
- 스킨 파일이 없는 게임 가운데 찰칵 낱말 · 환승 러시는 `:hover`가 없고, 한글 만나기는 이미 쿼리 안이다.
