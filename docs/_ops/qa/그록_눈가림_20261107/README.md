## 방법

- **그록:** grok 1.0.77 · grok-4.7 · 노력 high · 구독 로그인(unmet23). 파일 · 셸 · 고치기 · MCP · 웹 도구와 하위 에이전트를 막고(`tools/lib/그록호출.js`), 답 꼴은 `--json-schema`. 디자인은 그림을 사용자 폴더 밖 빈 폴더에 두고 `Read(C:/Users/**)` · `Read(D:/**)`를 막은 채 그림만 읽게 했다.
- **코드 10묶음:** `.tmp/검수/<이름>/묶음-*.txt`를 그대로 보냈다(커밋 서명 줄만 뺌). 놓친 결함이 나중에 드러난 묶음 A 4 · 검수자가 진짜 결함을 잡은 묶음 B 3 · 깨끗했던 묶음 C 3. 대표 실명이 든 서류 묶음 하나는 보내지 않았다. 「정답」은 뒤 커밋 · 지적표 · 현장노트로 고른 것이라, 등급은 커밋이 안 적은 것을 추정한 것이 섞였다.
- **디자인 12장:** 기각 8 · 채택 4(쌍 4). 파일 이름 · 설명에서 판정이 드러나지 않게 중립 이름 · 설명으로 바꿨다. 채택 넷 가운데 셋은 「이 판으로 바꿔」 · 「훨씬 낫네」 같은 비교 말씀이라 약한 채택이다. Fable은 Agent(그림 Read), 아르곤은 Gemini 웹(`tools/아르곤웹.js`, 4장씩 — 8장 한 번은 두 번 다 대화가 남지 않았다).
