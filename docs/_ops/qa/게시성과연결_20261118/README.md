## 제안 · 서버 글이 캡션이 아닌 등록

작업실 예약으로 올린 synkbrief · yuhobuilds 인스타는 서버 등록 제목이 그 편 준비.json 「제목」이다(이번 8건 모두 글자 하나까지 같았다). 캡션 자동 연결은 이 등록을 잇지 못하므로, 매일 두 판씩 「편 폴더 못 찾음」이 다시 쌓인다. 확실히 이을 수 있는 값은 둘이다.

- **작업실 작업 결과의 주소.** 같은 예약의 유튜브 줄은 `tools/작업실예약.js 상태 <편>`이 주소를 적는데, 인스타 줄은 「승인 대기」로 남았다. 인스타 작업이 끝난 뒤 상태를 한 번 더 읽어 주소를 적게 하면 가장 확실하다.
- **준비.json 「제목」과 등록 제목이 글자 그대로 같을 때.** 제목에 편 번호(B43 등)가 들어 있어 편마다 다르다. 계정이 같고, 그 편 게시결과에 그 계정의 작업실 줄이 있고, 같은 제목의 편이 하나일 때만 잇는다. 비슷한 제목은 잇지 않는다.

둘 다 이번에는 만들지 않았다. 어느 쪽으로 할지 정하면 그 세션이 만든다.
