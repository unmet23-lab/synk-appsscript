게임 원천의 21개 모듈을 나눠 비교했다. 공개판의 주석·공백 압축을 유지하면서 Trail과 Learning의 `spoken` 처리 및 공통 쓰기 권한을 원천과 맞췄다. 처음 공개 게임의 스크립트 SHA-256은 `370ec53f1678`, 수정본은 `51cebdb7efa4`다. 두 종류였던 도구 스크립트 `2e257b8ed9f1`, `df87fca694a1`은 `atlas/engine.js`의 `651759d8826d`로 맞췄다. 다른 탭에서 같은 기록을 여는 계정·연습 화면도 읽을 수 있도록 같은 옛 게임 엔진을 쓰던 여섯 자리에 반영했다.

## 학습자가 보는 차이

‘주문 폭주’에 처음 들어간 사람에게는 기본 주문을 듣고 음료와 온도를 알아보도록 안내한다. 세 가지 부정·변경 주문을 실제로 끝까지 듣고 첫 시도에서 놓친 합성 기록으로 다시 들어가면 “지난 주문에서 빼거나 바꿔 달라는 요청을 놓친 적이 있어요”라고 알려준다. 다음에 무엇을 들으면 좋은지는 입구에만 보인다. 다른 게임의 듣기 기록이 근거면 “지난 듣기 연습에서”라고 표현한다.

확인은 주문 `o07`·`o09`·`o11`의 표준 측정 자료를 사용했다. 다음에 새로 나온 주문 `o03`의 음성은 “따뜻한 차 한 잔 주세요. 설탕은 빼 주세요.”다. 화면을 통해 음성을 끝까지 듣고 글 힌트 없이 차 한 잔을 제출했을 때 정답 사건이 남았다. 오답이 한 번뿐이거나 모두 맞혔을 때, 글 도움을 받았거나 음성이 실패했을 때는 과거에 해당 요청을 놓쳤다고 말하지 않았다.

## 검증 범위

- 수정 전·후 14개 주소를 1,440px와 390px에서 열어 총 56회 확인했다. 연결된 엔진 응답, 가로 넘침, 페이지 실행 오류, 화면에 표시된 문구를 확인했다.
- 여덟 게임 각각 한 탭이 기록을 쓰는 사이 두 번째 탭을 열었다. 첫 탭을 닫자 두 번째 탭에서 새로고침 없이 대기 안내가 사라지고 입력 초점이 유지됐다. 주문 폭주에서는 자동 속도를 끈 뒤 새로고침해 선택이 유지되는 것도 확인했다.
- 바람길과 주문 폭주에서 다른 탭이 기록을 쓸 때 지우기를 확인하면, 거절 안내가 나오고 기존 사건은 모두 그대로 남았다. 먼저 쓰던 탭을 닫고 다시 눌렀을 때에만 완료 안내가 나오고 기존 사건이 없어졌다. 두 게임에서 각각 PC와 모바일 너비로 확인했다. 기본 저장 안내도 직접 연 브라우저와 연동된 계정을 구분한다.
- 여섯 도구에서 각각 3~7개의 질문을 거쳐 결과에 도달한 뒤 “너무 많아요”를 골랐다. 재방문해 처음부터 답하자 여섯 곳 모두 짧은 결과와 “지난번에 ‘너무 많아요’라고 하셔서 간단히 보여 드려요”라는 안내가 나왔다. 후보의 실행 파일·기존 기록 왕복·명시 피드백·부모와 자식 창 공유·HTML 캐시 참조 자동 시험 30개, 8개 게임의 학습·판정과 여섯 도구를 포함한 원천 회귀 361개가 통과했다.
- 합성 브라우저와 테스트 기록을 사용했다. 실제 회원의 계정 간 동기화, 학습자의 만족도, 며칠 뒤의 학습 향상은 이 확인에서 측정하지 않았다.

최종 화면 검수에서 빈칸 베기·말 랠리·입장 검사의 기록 지우기, 레이싱·말의 리듬의 실패 안내도 대조했다. 검수 당시 앞의 세 게임은 다른 탭이 기록을 쓰는 동안 지우기를 눌러도 원래 사건을 보존했지만, 화면은 요청 결과를 알려 주지 않았다. 계정 기록을 일부만 받은 상태를 모의한 주문 폭주에서는 답한 수가 0일 때 첫 연습 안내가 나왔다.

AI 컴퓨터 맞춤 추천·내 PC 이사 목록·AI 직원 매뉴얼 만들기의 삽화는 PC와 모바일에서 첫 화면과 첫 질문을 각각 열어 확인했다. 이미지 디코딩과 화면 전환이 끝난 뒤, 각 삽화의 사각형은 카드 안에 온전히 들어왔다.

수정 후보에서는 지우기 단추가 있는 일곱 게임에서 두 탭을 열어 390px·1,440px로 각각 확인했다. 쓰기 차례가 없는 탭에서 지우기를 누르면 단추 옆에 이유가 보였고, 과거 사건 ID는 그대로 남았다. 먼저 쓰던 탭을 닫고 ‘다시 지울 수 있어요’ 안내가 나온 뒤 취소해도 같은 기록이 남았고, 다시 동의했을 때만 과거 사건이 사라졌다. 레이싱에서도 지우기 전에 다른 게임의 학습 기록까지 포함된다는 확인창을 거친다. 주문 폭주는 기록을 다 받지 못한 계정에서 짧은 주문부터 확인하도록 안내하고, 말 랠리는 계정의 공유·삭제 위치를 표시했다. 이야기 교실은 계정 연결 제목과 실제 저장 위치를 따로 표시한다.

실제 학습자에게 확인할 때는 재방문한 첫 화면에서 “이 주문이 왜 나왔다고 느끼셨어요?”라고 묻는다. 본인이 놓쳤던 표현을 도움 없이 떠올리는지와, 다음 날 처음 듣는 같은 유형의 주문을 글 힌트 없이 처리하는지를 따로 기록한다.

공개 화면 28개(14개 주소 × 2개 너비)에서 페이지 실행 오류나 가로 넘침은 없었다. 여덟 게임의 탭 간 쓰기 차례와 지우기를 제공하는 일곱 게임의 취소·거절·완료를 확인했다. 여섯 맞춤 도구에서 두 번씩 질문을 끝냈고 이전에 고른 “너무 많아요”에 맞춰 짧은 결과가 나왔다. 주문 폭주의 일곱 기록 조합, 일부 기록만 받은 모의 계정, 세 도구의 삽화 12장도 공개 주소로 확인했다. 원천 회귀 361개, 공개 후보 시험 46개, 내려받은 공개 파일과 브라우저 실측을 대조한 시험 45개가 통과했다.

아르곤 검수에서 찾아낸 문제와 Fable의 기록 삭제 지적을 반영했다. Fable은 달라진 원천·공개 파일과 실측을 다시 대조해 원래 문제의 해결을 확인했다. 마지막 검수의 추가 지적은 0건이다.
