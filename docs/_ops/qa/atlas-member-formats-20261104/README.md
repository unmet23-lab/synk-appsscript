# 말하기를 함께 쓴 회원의 Atlas 학습 요약

2026년 11월 4일, 같은 합성 회원이 서로 다른 날에 OX·보기 고르기·조합·행동·말하기로 주문을 한 번씩 연습했다. Atlas의 정식 학습 이벤트를 계정 요약으로 집계하고 회원 화면을 열었다. 학습자는 도움 방식으로 단계별 도움을, 관심 주제로 AI 도구 활용을 직접 선택했다.

| 확인한 대상 | 네 가지 방식 | 말하기를 더한 다섯 가지 방식 |
| --- | --- | --- |
| 수정 전 원천 | 회원 요약 정상 | Trail이 만든 정상 기록 다섯 개를 Core 어댑터가 거절 |
| 현재 공개 웹 실행 파일로 연 합성 계정 | 주문 4일·AI 도구 활용 표시 | 첫 방문과 새로고침 모두 주문 행과 직접 고른 관심 주제가 빠짐 |
| 수정한 원천과 PC용 모듈 | 주문 4일, 선택한 설정 유지 | 주문 5일, 단계별 도움, AI 도구 활용 유지. 문제 방식의 선호는 미정 |
| 수정한 웹 빌드로 연 합성 계정 | 주문 4일 표시 | 첫 방문과 새로고침 모두 “주문 · 5일 동안 5번”, “AI 도구 활용”, “단계별로 도와줘요” 표시 |

PC용 모듈은 다섯 방식을 한 번씩 썼을 때 “현재 원하는 방식을 직접 고를 수 있어요”라고 안내한다. 반복된 방식이 없다는 이유로 연습한 날까지 없다고 설명하던 경우를 바로잡았다. 계정 관련 자동 시험 124개가 통과했다. Atlas 크기 기준 2개도 통과했고, 원천은 36개 파일, 총 7,415줄이다. 웹 검증은 390픽셀의 독립 브라우저에서 실행했다.

회원 요약의 허용 개수와 항목 검증을 [같은 계약](../../../../atlas/member-understanding-contract.js)에서 구한다. [회귀 시험](../../../../tests/atlas-member-understanding.test.js)에서 선언 전용 값, 모르는 값, 중복, 허용 개수 초과를 거절하고 학습 연결을 끄면 관찰을 제외하는 것도 확인한다.

공개 계정 파일을 교체하지 않았다. 변경 전 원천 `2cfb220e`의 `dist/platform.js`는 1,751,575바이트, 당시 [공개본](https://github.com/unmet23-lab/synk-policy/blob/a2a8a581d0ea1b1b9f081b2c01232d2291273b46/account/dist/platform.js)은 3,453,185바이트였다. 동일한 압축 조건에서도 내용이 달랐다. 공개 확인은 synk.im이 제공한 파일의 해시를 대조한 뒤, 그 파일을 격리 브라우저에서 가상 학습자 데이터로 실행했다. 실제 회원 데이터나 운영 계정을 사용하지 않았다.

미니게임의 실제 재방문 안내와 첫 문제는 [게임별 공개 플레이 기록](../atlas-seven-return-20261103/README.md)에 있다.
