# 말하기를 함께 쓴 회원의 Atlas 학습 요약

2026년 11월 4일, 같은 합성 회원이 서로 다른 날에 OX·보기 고르기·조합·행동·말하기로 주문을 한 번씩 연습했다. Atlas의 정식 학습 이벤트를 계정 요약으로 집계하고 회원 화면을 열었다. 학습자는 도움 방식으로 단계별 도움을, 관심 주제로 AI 도구 활용을 직접 선택했다.

| 확인한 대상 | 네 가지 방식 | 말하기를 더한 다섯 가지 방식 |
| --- | --- | --- |
| 수정 전 원천 | 회원 요약 정상 | Trail이 만든 정상 기록 다섯 개를 Core 어댑터가 거절 |
| 현재 공개 웹 실행 파일로 연 합성 계정 | 주문 4일·AI 도구 활용 표시 | 첫 방문과 새로고침 모두 주문 행과 직접 고른 관심 주제가 빠짐 |
| 수정한 원천과 PC용 모듈 | 주문 4일, 선택한 설정 유지 | 주문 5일, 단계별 도움, AI 도구 활용 유지. 문제 방식의 선호는 미정 |
| 수정한 웹 빌드로 연 합성 계정 | 주문 4일 표시 | 첫 방문과 새로고침 모두 “주문 · 5일 동안 5번”, “AI 도구 활용”, “단계별로 도와줘요” 표시 |

PC용 모듈은 다섯 방식을 한 번씩 썼을 때 “현재 원하는 방식을 직접 고를 수 있어요”라고 안내한다. 반복된 방식이 없다는 이유로 연습한 날까지 없다고 설명하던 경우를 바로잡았다. 계정 관련 자동 시험 124개가 통과했다. Atlas 크기 기준 2개도 통과했고, 원천은 36개 파일, 총 7,415줄이다. 웹 검증은 390픽셀의 독립 브라우저에서 실행했다.

회원 요약의 허용 개수와 항목 검증을 [같은 계약](../../../../atlas/member-understanding-contract.js)에서 구한다. [회귀 시험](../../../../tests/atlas-member-understanding.test.js)에서 선언 전용 값, 모르는 값, 중복, 허용 개수 초과를 거절하고 학습 연결을 끄면 관찰을 제외하는 것도 확인한다.

공개 계정 파일을 교체하지 않았다. 변경 전 원천 `2cfb220e`의 `dist/platform.js`는 1,751,575바이트, 당시 [공개본](https://github.com/unmet23-lab/synk-policy/blob/a2a8a581d0ea1b1b9f081b2c01232d2291273b46/account/dist/platform.js)은 3,453,208바이트였다. 줄끝을 LF로 통일하면 공개본은 3,453,185바이트다. 동일한 압축 조건에서도 두 파일의 내용이 달랐다. 공개 확인은 synk.im이 제공한 파일의 해시를 대조한 뒤, 그 파일을 격리 브라우저에서 가상 학습자 데이터로 실행했다. 실제 회원 데이터나 운영 계정을 사용하지 않았다.

미니게임의 실제 재방문 안내와 첫 문제는 [게임별 공개 플레이 기록](../atlas-seven-return-20261103/README.md)에 있다.

## 공개 파일에 직접 대조한 두 번째 후보

11월 4일 오후, 회원 혜택의 ‘내 성향’을 390px와 1440px에서 열었다. 일반 공개 페이지의 정적 자산을 사용하고 계정 응답만 합성했다. 후보에서는 바뀔 HTML과 실행 파일 두 개를 같은 주소에 끼웠다. 같은 회원이 네 가지 방식으로 연습한 뒤 말하기를 더하고, 새로고침한 경우와 탭을 닫고 다시 들어온 경우를 모두 확인했다.

| 같은 학습 기록 | 당시 공개 회원 웹 | 최종 후보 |
| --- | --- | --- |
| 네 방식으로 주문을 하루에 한 번씩 연습 | 주문 4일 4회, 관심사 ‘AI 도구 활용’, 단계별 도움 표시 | 같은 결과 |
| 다섯 번째 방식으로 말하기 추가 후 재방문 | 상단의 5일 통계와 단계별 도움은 보인다. 주문에 관해 답하는 행과 직접 알려 준 관심 주제가 빠지고 ‘고친 내역을 불러오지 못했어요’가 뜬다. | 주문 행에 ‘5일 동안 5번’과 ‘더 배우고 싶은 상황인가요?’가 보인다. 관심 주제와 도움 방식도 유지된다. |
| 말하기로 서로 다른 사흘 동안 답함 | — | ‘말로 답하기’, ‘3일 동안 3번’, ‘이런 문제가 나에게 편한가요?’를 보여 준다. 말하기가 한 번뿐이면 질문을 띄우지 않는다. |
| 학습 연결 끄기 | — | 연습으로 추론한 주문·말하기 행을 감추고 직접 고른 ‘AI 도구 활용’은 남긴다. |

공개 회원 파일에 있던 두 함수만 교체한 첫 후보도 말하기 기록을 읽지 못했다. 같은 번들에 든 두 계약 사본이 모두 10월 31일 말하기 추가 이전 상태였다. 두 사본의 응답 목록을 기존 원천과 바이트로 대조해 원본에 있는 ‘말로 답하기’ 한 항목씩을 보탰다. 바뀐 네 자리를 되돌리면 기존 공개 파일 전체의 SHA-256이 일치한다. 공개 도구가 바꾼 다른 부분은 페이지가 새 실행 파일을 받는 캐시 주소 한 곳이다. 공개 배포 후보 계획은 `3b48a8d431b3`이다. [두 원천과 공개 입력으로 후보를 재현하는 도구](prepare-public-web.cjs)

합성 계정 실측 원본 `public-web-check.json`과 모바일 화면 `candidate-return-mobile.png`는 이 폴더의 작업본에 보관했다. 두 파일의 SHA-256은 각각 `85141d454586b291b08b6f22cb505327cee2ddbfb8d3f41141ea79ab3ff7f48a`, `4c564d024655decf1c9a0ac6e1feb362e8ee8340bf576e1eb6141bfb09cc0d36`다.

엔진 시험 45개가 통과했다. 공개 주소에서 합성 계정으로 실행한 전후 시험에서는 가로 넘침과 스크립트 오류, 예상 밖 요청 및 계정 저장 요청이 모두 0건이었다. 사용자 선호나 학습 효과를 설문으로 측정한 결과는 없다.

PC 공개판 0.4.76은 공개 릴리스 목록과 동결 원천 176개 해시를 대조한 뒤 설치 없이 회원 모듈을 시험했다. 네 방식은 읽고 다섯 번째에서 오류가 났다. 다음 PC판은 우주선 경로 제거와 캠퍼스 게임 입구 변경도 반영해야 한다. 이 세션은 게임 개편과 겹치는 PC 출시를 중단했다. [우주선 처리 기록](../../트랙.md) · [동결한 PC 원천](https://github.com/unmet23-lab/synk-policy/blob/47561faf81fe5e2e99d36b21f612cf69cb790ed6/.github/desktop-preview/unified/release-input.json)

기존 공개 게임 8개와 맞춤 도구 6개가 각각 검수한 엔진을 불러오는 것을 같은 날 오후에 재확인했다. 일곱 게임의 진입 모듈과 재방문 기능 파일 37개도 앞선 실플레이 검증본과 일치했다. 새 WORLD 캠퍼스판의 검수는 게임 담당 작업에서 따로 한다. [게임별 첫 문제](../atlas-seven-return-20261103/README.md) · [여섯 도구의 피드백과 재방문](../atlas-public14-20261103/README.md)

## 실제 공개와 재방문 확인

11월 4일 16시 38분(KST)에 일반 회원 URL이 제공한 HTML과 JS가 검수 후보 두 파일의 SHA-256과 일치했다. 공개 커밋은 계정 실행 파일과 HTML의 캐시 주소 한 곳만 바꿨다. [내 성향](https://synk.im/account/platform.html#benefits/insight) · [공개 커밋](https://github.com/unmet23-lab/synk-policy/commit/e4fa3cd6753a9ca5e2c8f412cb5937464c47b209) · [Pages 배포 성공](https://github.com/unmet23-lab/synk-policy/actions/runs/41793407277)

공개 뒤에는 HTML과 JS도 HTTPS에서 받았다. 계정 인증과 API만 합성했다. 모바일과 데스크톱에서 네 방식의 주문 4일 4회 → 말하기를 더한 5일 5회 → 탭을 닫고 다시 연 5일 5회를 확인했다. ‘AI 도구 활용’과 ‘단계별로 도와줘요’가 유지됐다. 화면 오류, 가로 넘침, 계정 저장 요청은 없었다. 세 번 말한 계정에는 ‘이런 문제가 나에게 편한가요?’를 물었고 한 번 말한 계정에는 묻지 않았다. 학습 연결을 끄면 직접 고른 관심사만 남고 주문과 말하기 관찰 행은 사라졌다.

첫 실서비스 검사에서 데스크톱의 350ms 제한 단일 행 읽기가 한 번 실패했다. 그 결과를 보존한 뒤 약 0.6초 이상 같은 화면에 나타난 카드 값을 함께 읽어 두 폭 여섯 방문을 다시 확인했다. 같은 바이트로 첫 검사도 독립 재실행해 통과했다. 실제 공개 실측 원본 `public-web-live-check.json`(SHA-256 `890b45adaf651617d1bc9bc843c681f3e5e5cc565662618bb77a6aa0759c8385`)과 `live-return-mobile.png`는 공용 작업본의 이 폴더에 있다.

아르곤은 자료 10개를 확인했고 지적은 0건이었다. 사용자가 지정한 Max 구독에서 공식 Fable이 전후·차이 12장과 원천·후보를 검수했다. P0·P1·P2는 0건, P3는 3건이었다. 첫 후보의 실패 화면과 오류를 같은 입력으로 다시 확보해 1건을 반영했다. `first-candidate-5-failure.png`와 `first-candidate-5-failure.json`은 최초 측정과 구분한 재현 원본이다. 나머지 두 건은 다음 PC 릴리스에서의 회원 모듈 검증과 다음 웹 전체 빌드의 같은 시나리오 대조다. 이 후보의 공식 검수 ID는 `atlas-member-formats-web-live-20261104`다.

다른 팀의 PC 0.4.77 빌드는 성공했다. 17시 8분에 공개 피드는 아직 0.4.76이었고 0.4.77의 동결 목록도 확인했다. 이전 공개판과 달라진 26개 경로에 아틀라스 회원 요약과 공유 청크는 포함되지 않았다. 이 작업에서는 PC 릴리스를 하지 않았다. [별도 PC 0.4.77 빌드](https://github.com/unmet23-lab/synk-policy/actions/runs/41792971332)

첫 사이트 전체 점검은 다음 WORLD 게임 공개로 취소됐다. 후속 커밋 `06f8ffd2879b`에 회원 웹 두 파일이 검수 바이트 그대로 남은 것을 대조했고, 그 파일을 포함한 후속 사이트 전체 점검이 통과했다. 공개 도구도 운영 파일 2개 모두와 후속 점검 성공을 확인했다.
