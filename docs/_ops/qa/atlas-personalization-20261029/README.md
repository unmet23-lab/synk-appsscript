사용자 요청은 여덟 엔진 전체에서 사용자에게 실제로 맞는 도움을 만드는 수집·해석·기억·선택·전달·평가의 보완점을 찾고 고치는 것이다. 기존 여덟 역할과 제품별 동의 범위를 유지했다. 이 문서는 이번 구현·검증 기록이며 실제 사용자 만족도나 학습 효과의 실증 보고서가 아니다.

## 개인화에 쓰는 자료의 기준

- 직접 선택한 목적·도움·소리·표현 설정은 선언이다. 실제 수행·능력의 증거로 올리지 않는다. 목표급과 시험일도 능력 점수가 아니다.
- 행동 기록은 첫 노출·도움·소리 전달·같은 과업판·응답 형식·현재 사용 범위가 맞을 때만 해당 수행의 근거가 된다. 앱 열기·체류·클릭은 호감이나 성장으로 단정하지 않는다.
- 원문 해석과 집단 통계는 확인된 개인 사실과 별개다. 해석 원문·확인·정정·철회와 추정 근거의 시효를 보존한다.
- 오늘의 조건은 해당 제품의 임시 선언·만남 범위와 명시 기한으로 다룬다. 새로운 상시 수집이나 제품 간 자동 공유를 만들지 않는다.
- 완료·피드백·도움 뒤의 독립 수행을 나눠 읽는다. 무응답·미관측·자료 부족은 실패나 0점으로 바꾸지 않는다. 거절 후 같은 질문이나 도움을 반복하지 않는 기준을 유지한다.

## 재현과 성능

새 회귀의 첫 8개 중 고치기 전 7개가 실패했고, 기존 긴 출처 사슬의 의미 보존 1개는 통과했다. 이후 늦은 관측·같은 접수 시각의 조합을 한 건 더 보강했다. 원천 최종 관련 회귀는 89/89 통과했다. 8종 전체 회귀는 그 직전 판에서 2,058개 통과·실패 0·선택 Caddy 실기 검사 1개 건너뜀이다. 처음 3개 시험 파일의 형제 의존성 누락과 패키지판 미갱신을 해소하고 재검사했다.

독립 원천 검수 사슬은 `atlas-personalization-source-r1-20261029 → atlas-personalization-source-r2-20261029`다. GPT P1 1건과 Claude P3 2건을 반영했고 재검수에서 해당 P1 해결을 확인했다. 재검수의 Claude P3 1건은 발생 시각이 접수 시각보다 늦다는 입력을 전제로 했으나 기존 `Core.validate`가 `recorded before occurrence`로 거절해 재현되지 않았다. 최초 소스 전체 준비본은 경로 선택을 바로잡기 전 미전송 상태로 남겼으며 검수 실적으로 세지 않는다.

Claude 구독의 주간 한도 뒤 기존 검수용 무료 API 크레딧 통로(`tools/lib/클로드키.js`)로 Opus 5.5 high 검수를 받았다. 실제 두 응답은 입력 38,206·7,723토큰, 출력 9,274·5,271토큰이며 추정 사용액은 무료 크레딧 $0.474616다. 최초 응답의 한계 배열을 요구 자료형인 줄바꿈 문자열로만 정규화해 접수했으며 지적·완독 ID·끝 표식·검토 범위는 바꾸지 않았다. 원문과 접수 응답은 공용 작업본 `.tmp/검수/`에 보존한다. CLI 구독이나 실패한 호출을 검수 완료로 세지 않는다.
