## 검증 범위

- 고객은 초대받은 프로젝트의 공개 자료·답변만, 제작자는 현재 권한과 담당에 맞는 알림만 받는다.
- SSE에는 내용 없이 변경 revision만 전송하고 권한을 다시 검사한다. 연결 복귀와 저빈도 조회로 누락을 보완한다.
- 기기 푸시는 명시적으로 켜는 선택 기능이다. 작업공간 전체 알림과 PULSE 알림을 분리하고, 잠금 화면에는 이름·의견 본문을 싣지 않는다.
- 고객 푸시는 기존 고객 세션의 12시간과 초대의 유효 범위를 따른다. 만료 뒤 초대 재접속과 기기 알림 재등록이 필요하다.

## 로컬 합성 화면 확인

CUA로 분리된 제작자·고객 화면을 조작했다. 실제 운영 데이터·외부 고객을 사용하지 않았다.

1. 고객이 의견을 보내면 프로젝트 목록에 머문 제작자에게 새 알림이 왔다. 알림을 누르면 해당 프로젝트·영상·의견으로 이동하고 읽음 처리됐다.
2. 제작자의 공개 답변과 v2 MP4 업로드가 고객 알림함에 자동 도착했다. 입력 중에는 초점을 유지하며 새 내용 도착을 알리고, 입력창을 벗어나면 자동 반영됐다.
3. 작성 중인 글과 확인하던 v1은 유지됐다. 최신 시안과 이전 의견을 구분하고, 글을 최신 시안으로 옮기는 명시적 동작을 제공한다.
4. 고객 v2 승인 이후 제작자 화면의 승인 기록과 알림이 새로 불러오기 없이 갱신됐다.
5. 모두 읽음 이후 페이지를 새로 열어도 읽음 상태가 유지됐다. 390·320 CSS px에서 알림함의 가로 넘침이 없었다.
