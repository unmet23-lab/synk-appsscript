## 하루 한 번으로 바꿈(유호님 「응, 고쳐줘」)

- 원본창고에 `tmp미디어보내기.py`를 새로 만들었다. 공간 지킴이가 그날 처음 도는 점검에서 따로 띄운다(스위치 `상태/공간지킴이/tmp미디어보내기_켬`). 고르는 기준은 4번과 같고, 만족 사례 보존 목록이 가리키는 단위를 더 뺀다. 한 회차는 30GiB까지다. 25Mbps 올리기로 약 세 시간이라 05:30 매일 백업 전에 끝난다.
- 회차마다 창고 묶음 `tmp미디어보내기-<날짜>`로 올려 대조한다. 내려놓기 직전에 빼기 조건을 다시 재고, 지킴이의 `check` · `offload`로 내린다. 되살리기와 폴더 안내는 4번과 같다.
- 시험은 새 도구 14개와 지킴이 140개가 통과했다. 11-20 12시 미리 보기는 5개 0.01GiB를 골랐다. 고를 수 있던 몫은 4번이 이미 내렸기 때문이다.
- 검수: Opus 5.5 대체 검수(그때 Fable 주간 몫 100%). P1 2건 · P2 5건 · P3 여럿이 나왔다.

  - P1-2: 고른 뒤 파일이 사라지면 회차가 날마다 실패하며 멈췄다. 고르는 중인 회차는 회차마다 목록을 다시 짜고, 도구 탓 실패가 다섯 번이면 막힘으로 센다.
