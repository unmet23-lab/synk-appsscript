방법: 공개 커밋 C마다 C가 바꾼 파일(A·M)만 임시 폴더에 꺼내고 지운 파일은 `--지움`으로 준 뒤, `node tools/공개.js 올리기 --원본 <폴더> <경로…> --위에 C^ --json`(미리 보기)의 후보와 C의 `diff-tree`를 경로·blob id로 견준다. 「바뀐 파일만 넣으면 `?v=` 갱신까지 공개 때와 같은 후보가 나오는가」를 보는 재현이다. 스크립트는 [재현.cjs](재현.cjs).

```bash
node docs/_ops/qa/publish-tool-repro-20261019/재현.cjs . b7ed6f0 11617ab e9cf357
```
