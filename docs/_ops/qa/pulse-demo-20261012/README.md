## 구현과 경계

`?demo=coffee`에서만 로컬 체험 어댑터를 사용한다. 실제 초대 fragment가 있으면 실제 고객 연결을 우선한다. 실제 API와 파일 업로드로 넘어가지 않으며 단일 전용 localStorage 키 `synk-pulse-demo-coffee-v1`만 읽고 쓴다. 체험 초기화는 해당 키의 가상 상태만 초기화하며 로그인 쿠키와 다른 저장 키를 건드리지 않는다. PWA에는 공개 모듈만 추가하며 예시 영상·고객 데이터·API 응답은 캐시하지 않는다.

직접 선택·확인·의견·승인해야 다음 체험 단계가 준비된다. 자유 의견을 자동 반영했다고 주장하지 않고 미리 만든 CTA 개선본임을 단계 안내·영상 안내·대화에서 밝힌다. 기획 수정 후 확인 해제, 같은 시안의 미해결 의견이 있을 때 승인 차단, 승인 이후 최종 전달 규칙을 유지한다. 실제 고객 의견·시안·승인은 운영에 쓰지 않는다.
