Linux CI에는 Windows 기능, 로컬 자료와 도구가 없으므로 조건부 제외가 발생했다. CI의 제외 조건은 유지한다. 위 101건 통과는 그 CI 숫자를 통과로 바꿔 적은 것이 아니라, 필요한 환경을 마련한 별도 실행 결과다.

## 실행 중 고친 두 곳

1. WORLD 브라우저 시험의 공개 API 목록에 이미 구현된 `languageContext`가 빠져 있었다. 기존 단위 시험 및 실제 구현과 맞추고 반환 필드도 확인했다.
2. 로컬 리허설 서버가 학습 클라이언트의 `topik-items/holdout.mjs`와 그 JSON을 제공하지 못해 브라우저 자산 요청이 500으로 끝났다. 두 파일만 정확한 경로로 제공하고 그 밖의 문항 경로는 404로 막는다. 실제 HTTP 시험에서 파일 바이트·MIME·HEAD·POST·Windows 구분자·경로 우회와 거절할 파일이 실제 존재하는 경우까지 확인했다.

새 HTTP 회귀 시험은 GPU·형제 저장소·미디어 없이 일반 CI에서 돈다. 관련 계정·학습 동기화·정적 경로 회귀 **28건**도 통과했다. 수정 범위는 로컬 리허설 서버와 시험이며, 운영 원칙의 내부 도구·시험 기준에 따라 자체 점검과 시험으로 확인했다.
