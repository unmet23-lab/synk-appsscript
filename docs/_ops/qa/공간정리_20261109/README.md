- 이 노트북은 탐색기 기준 2.79TB이고, 쓰는 것만 약 1.36TB다(Windows · 프로그램 0.05 · 저장소 · 도구 · 대화 기록 0.25 · 세션 사본 · `.tmp` 0.25 · LoRA · 모델 · synk-vendor 0.26 · D: 통째 사본 0.55). 그래서 늘 비워 둘 수 있는 최대는 약 1.4TB이고, 2TB를 빈 칸으로 두려면 D: 통째 사본을 포기해야 한다 — 11-06 같은 고장 때 가장 빨리 되살리는 길이다.
