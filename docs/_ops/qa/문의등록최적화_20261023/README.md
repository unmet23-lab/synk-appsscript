## 공개 양식과 남은 반영

ego(lite)의 실제 소유자 편집 화면에서 Google Forms에 SHIFT 세 유형과 PATH 선택지를 반영했다. UB 공개 뒤 옛 SHIFT 유학 선택지를 제거하고 공개 viewform의 최종 7개(LAB·SHIFT 세 갈래·PATH·PULSE·출시 소식)를 확인했다. 질문 식별자·이메일 수집·개인정보 동의·기존 응답은 바꾸지 않았다.

UB 전송 유형·생성물·두 등록 화면의 폼 계약 시험을 갱신했다. `tools/공개.js`로 synk-policy `269b2277e7267a688b15b53a5b500336a775abd5`에 `ub/copy.js`와 그 파일의 index 캐시 토큰만 공개했다. ego 실제 공개 페이지의 상담 typeValue가 PATH인 것을 확인했다. 합성 기능 점검 표식을 넣어 실제 앱의 buildPayload로 만든 PATH 응답을 기존 formResponse에 한 번 보냈고, HTTP 200 및 소유자 응답 화면의 해당 시험 표식·PATH·응답 4→5를 확인했다(16:00 KST). 이는 폼 수신 증거이며 회사 서버 종단 수집 확인은 아직 아니다. 공개 배포 점검의 최종 결과는 이어 확인한다.

회사 서버는 사슬 25·26 합본·PULSE·SNS 등 앞선 릴리스가 진행 중이다. 전체 master를 배포하지 않고 실제 앞 판이 완료된 후보 위에 이번 8파일만 싣는다. 회사 반영 전 새 문의 유형은 기존 서버에서 「분류 확인」으로 접수될 수 있으며, 개선판은 조회 시 다시 분류하되 저장된 상태·초안·할 일을 보존한다. 로컬 후보·시험·원천 push는 회사 운영 반영을 뜻하지 않는다. 남은 일은 실제 앞 판의 passed·armed 확인과 이 판의 후보·배포·재무장·운영 종단 확인이다.
