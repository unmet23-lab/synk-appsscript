운영 워크스페이스에서 업무 등록부터 완료까지 실제 저장 흐름을 확인합니다.

해야 할 일
1. 나에게 메모에 유호 담당으로 등록하고 오늘 목록에 표시되는지 확인합니다.
2. 수락함으로 저장한 뒤 진행 중으로 변경합니다.
3. 실제 확인 결과를 같은 대화방에 별도 메모로 남기고 결과물 메시지로 연결합니다.
4. 완료로 저장한 뒤 오늘 목록에서 제외되는지 확인합니다.
5. 새로고침 후 전체 할 일에서 완료 상태와 요청·결과물 연결이 유지되는지 확인합니다.

완료 기준: 위 과정의 실제 화면과 저장 상태를 확인합니다. 검토자는 지정하지 않으며 다른 크루에게 요청·알림을 보내지 않습니다. 이 업무는 사용자 요청에 따른 운영 검증 기록입니다.
