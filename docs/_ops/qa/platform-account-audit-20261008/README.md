### 1차 검수 당시 남은 일

1. 이 수정의 공개 반영과 새 설치본은 별도 출시 단계다. 기존 규칙에 따른 최종 검수 후 배포할 때 실제 운영 계정으로 재로그인·저장·충돌·로그아웃을 확인한다. 이번 작업 중 실제 계정 데이터는 변경하지 않았다.
2. PC↔실물 휴대폰 왕복은 기존 사용자 보류를 유지한다. 자동 검사의 두 세션을 실물 두 기기 검증으로 표시하지 않는다.
3. 웹 바로가기는 계속 기기 저장이다. 계정 기록과 함께 동기화할지, 플랫폼에서 각 앱 기록의 요약을 어느 동의 범위로 보여줄지는 다음 제품 범위로 정해야 한다. 새 토큰 공유나 앱 간 자료 수집은 추가하지 않았다.
4. 후순위 기능 후보: 리허설의 명시 상대/목표별 추가 분기, 운세의 지난 7일 메모·실천 돌아보기, 플레저 연락처의 선택 가져오기. 이번에 구현·검증한 기능으로 표시하지 않는다.
