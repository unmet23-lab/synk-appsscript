## 실제 브라우저

[루프백 서버](round6-browser.mjs)는 실제 플레저 앱과 기존 정적 서버를 사용하고, 합성 계정·저장소·수첩만 메모리에 연결한다. 운영 설정·회원·음성 API 호출은 없다.

- 미저장 일정 제목 입력 → 계정 자료 새로고침 → 보호 확인창 → 취소 → 제목 유지.
- 표현 메모만 변경 → 같은 확인창 → 취소 → 메모 유지.
- 표현 기억하기 → 계정 자료 새로고침 → 불필요한 확인창 없이 저장된 메모 유지.
- 확인창의 320·390·1280px 표시가 화면 안에 있고 가로 넘침이 없었다. 수집한 콘솔 오류·경고는 0건이다. [화면](round6-care-unsaved-1280.png) · [검증 값](round6-browser-proof.json).
- 검수 탭과 4328 서버는 종료했다. 사용자 공개 플레저 탭은 유지했다.

## 확인 범위

합성 계정과 메모리 저장소·대역 HTTP로 검증한다. 실제 회원 인증·운영 저장소·실물 PC 알림·PC↔휴대폰 왕복은 미실행이다. 기존 실물 검증 보류는 유지하며 이번 결과를 공개판·새 설치본 검증으로 해석하지 않는다.

공통 notebook의 입력 세대 검사는 앱에서 `change()`로 접수한 문서 변경과 업로드 원본을 보호한다. 아직 문서에 반영하지 않은 원시 폼 입력은 각 앱의 입력 보호 영역이다. 브라우저 이탈 확인 창의 실제 표시 여부는 브라우저 정책에 따르며 자동 저장이나 새 클라우드 동기화 기능으로 판정하지 않는다.
