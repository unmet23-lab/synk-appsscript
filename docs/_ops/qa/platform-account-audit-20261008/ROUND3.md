# SYNK 플랫폼 계정·기록 3차 검수

2026-10-08. 사용자 후속 요청에 따라 로그인·계정·기록 연동을 계속 보완했다. 이 문서는 현재 공용 작업본의 로컬 구현과 검증이며 공개 배포·새 설치본·실제 회원 자료 변경을 포함하지 않는다. [이전 2차 결과](ROUND2.md).

## 재현과 수정

| 재현한 문제 | 수정과 확인 |
|---|---|
| 다른 기기에서 이름·소속·이용권·세션을 바꿔도 웹 복귀 시 ID와 동의가 같으면 화면이 갱신되지 않음 | 서버에서 확인한 최신 계정 응답을 계정 영역에 적용한다. 같은 계정·동의면 실행 중인 WORLD를 유지하며, 변경 없는 응답은 화면과 입력 초점을 다시 만들지 않는다. 계정/동의가 바뀌면 기존 재연결 절차를 사용한다. |
| 먼저 시작한 화면 복귀 조회가 늦게 도착하면, 이후 명시적으로 종료한 다른 기기 세션을 화면에서 되살릴 수 있음 | 명시적 계정 조회와 응답 반영의 순서를 확인하고 오래된 응답을 무시한다. |
| 인증 일시 중단 후 같은 계정으로 연결해도 문서 연결을 초기화하여 미전송 원본·기록이 서버 문서로 덮임 | 서버에서 같은 계정임을 확인하면 기존 문서 revision과 미전송 기록을 유지한다. 인증 확인 중 전송은 멈추고, 이전 연결의 늦은 전송 응답은 반영하지 않는다. 다른 계정·로그아웃은 기존 자료를 분리한다. 실제 revision 충돌도 그대로 안내한다. |
| 오래 걸린 앨범 원본 복원이 새 입력을 덮거나, 복원 중 인증이 끊기면 빈 앨범을 편집할 수 있음 | 최신 입력 뒤 도착한 복원 결과·오류를 무시한다. 중단된 초기 복원은 해당 문서를 보존한 재시도로 이어지며 복원이 끝날 때까지 편집을 잠근다. |
| 중앙 SYNK ID가 서버 로그아웃 응답을 기다리는 동안 이전 화면과 내보내기 응답이 살아 있음 | 클릭 즉시 기존 화면과 일반 요청의 반영을 막고 공식 SDK의 로컬 로그아웃을 시작한다. 서버 철회는 기존 토큰으로 따로 처리한다. 새 로그인 이후 늦은 종료 결과는 새 계정에 적용하지 않는다. |
| Atlas 요약이 없는 정상 응답에도 로딩 문구가 계속 보임 | 요약 없음 안내로 마무리하고 계정·연습을 계속 사용할 수 있음을 표시한다. |

중앙 포털의 SDK 저장소 삭제와 서버 종료는 각각 결과를 확인한다. 사용 중인 SDK가 서버 응답 후 저장소를 지우므로 **클릭 즉시 확인한 것은 계정 화면·일반 요청의 차단**이다. 영구 저장소의 즉시 삭제나 SDK 내부의 다른 탭 저장 경합까지 해결했다고 판정하지 않는다. SDK 종료가 진행 중인 이 탭에서는 새 로그인 제출을 잠그고 실패·시간 초과를 안내한다.

## 브라우저 확인

기존 [로컬 검수 서버](round2-browser.mjs)의 `/account-refresh`에서 실제 계정 화면 모듈과 Atlas를 사용하고 합성 응답만 넣었다. 이름·학생 소속·이용권·종료된 휴대폰 세션이 화면에 반영되고, 요약 없음 안내가 표시되는 것을 확인했다. 이 경로는 검증된 응답의 렌더링을 확인하며 실제 로그인이나 화면 복귀의 운영 통신을 대신하지 않는다. 실제 클라이언트의 복귀 처리와 응답 경합은 자동 시험으로 확인했다.

- 320·390·1280 폭: 가로 넘침 없음, 누락 이미지 0, 콘솔 오류·경고 0.
- [PC 1280 화면](round3-account-updated-1280.png), [모바일 390 화면](round3-account-updated-390.png)을 실제 렌더로 확인했다.
- 검수 서버는 합성 자료만 사용하며 운영 자격·회원 기록·유료 AI를 호출하지 않는다.

## 남은 운영 확인

이번 변경의 공개 반영, 설치 패키지 생성·재설치, 실제 회원 로그인, 인증한 PC·휴대폰 두 실물 기기의 기록 왕복은 실행하지 않았다. 기존 실물 왕복 보류를 유지한다. 합성 브라우저·자동 시험의 통과를 운영 동기화 완료로 보고하지 않는다.
