## 실제 브라우저

[루프백 QA](round7-browser.mjs)는 실제 플레저 화면과 정적 서버에 합성 계정·메모리 저장소만 연결한다. 운영 설정·실회원·음성 API는 호출하지 않는다.

- 미저장 일정 제목과 사람 수정 이름 입력 → 합성 재인증 실패 → 수첩과 열린 수정창 모두 숨김. 입력값은 메모리에 유지.
- **계정 연결 다시 확인** → 같은 계정 확인 → 일정과 이름 유지, 수정창 다시 열림.
- 실패 뒤 다른 계정으로 전환 → 이전 이름·일정 입력과 수정창 정리, 새 계정의 사람만 표시.
- 최종 소스를 다시 열어 보호·복구를 재확인. 320·390·1280px에서 복구 버튼이 화면 안에 있고 가로 넘침 없음. 수집 콘솔 오류·경고 0건.
- [보호 화면](round7-care-protected-1280.png) · [복구 화면](round7-care-restored-1280.png) · [검증 값](round7-browser-proof.json).

입력 보존은 현재 화면 메모리의 복구다. 브라우저 새로고침·종료 후 원시 입력까지 자동 복구하거나 서버 저장을 완료했다는 뜻은 아니며 화면에도 이 한계를 표시한다. 검수 후 임시 탭과 4328 서버를 종료하고 사용자 공개 플레저 탭은 유지했다.
