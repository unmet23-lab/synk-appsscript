## 실제 브라우저

[루프백 QA](round8-browser.mjs)는 실제 가족 앨범 화면·정적 서버에 합성 계정과 메모리 저장소, 검수 전용 IndexedDB를 연결한다. 운영 인증·회원 저장소·실제 마이크·유료 API는 호출하지 않는다.

- 제목·본문·작성자 입력 → 합성 계정 연결 실패 → 본문 숨김과 입력값 메모리 보존 확인.
- **계정 연결 다시 확인** → 같은 계정 복구 → 세 입력 유지 및 계정 저장 안내 확인.
- 실제 앱의 `beforeunload` 처리에 취소 가능한 사건을 보내 미저장 보호가 계속 작동함을 확인. 네이티브 브라우저 종료 확인창을 관찰한 검증과는 구분한다.
- **앨범에 한 장 남기기** → 상세 화면의 제목·본문·작성자 유지 및 **계정에 저장했어요** 표시. 합성 저장소 revision 1·저장 1회 확인.
- 320·390·1280px에서 가로 넘침 없음. 수집 콘솔 오류·경고 0건. [검증 값](round8-browser-proof.json) · [복구 후 저장 화면](round8-album-recovered-1280.png).
- 마지막 공통 수첩 수정 후 새로 열어 보호→복구→이탈 보호→저장을 다시 확인했다. 브라우저가 받은 앱·공통 수첩·계정 연결기 3개는 [현재 원본과 바이트·해시 일치](round8-served-source.json)를 확인했다.

입력 보존은 현재 페이지 메모리의 복구이며 새로고침·종료 뒤 원시 입력 자동 복구를 뜻하지 않는다. 재연결 클릭은 도구 입력 시간 초과를 보고했으나 이후 화면과 합성 계정 상태에서 성공을 확인했다. 확인창 자체의 표시·수락 장면을 직접 관찰한 증거로 사용하지 않는다. 실제 회원 인증·운영 저장·물리적 PC↔휴대폰 왕복은 이번 검증에 포함하지 않는다. 기존 실물 검증 보류를 유지한다.
