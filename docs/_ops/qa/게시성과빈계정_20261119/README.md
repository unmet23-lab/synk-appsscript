<a id="vk-곁-세션"></a>
VK 클립과 네이버 블로그의 서버 규칙은 곁 세션 「VK 클립 · 네이버 블로그 게시물별 값을 서버가 받게 하기」가 맡는다. 링크드인 원장과 게시물 분석 화면 규칙은 그 건에 싣지 않기로 했다(11-19 그 세션 답: master 원장이 운영판과 갈라져 남의 미출시 변경이 함께 나가고, 화면 규칙에 GPT P1이 있었다). 원장 동기화 회사 판을 따로 맡을 세션이 필요하다.

**곁 세션 결과(11-19).** 서버 `external-observations.mjs`가 VK 클립 주소와 VK 커뮤니티 공개 클립 목록(공개 화면)을 받게 고쳤다. VK 글과 클립은 주소의 소유자 번호가 이 채널의 커뮤니티 번호여야 한다. 원장에 VK 커뮤니티 번호 칸이 없어 서버 코드의 `VK_COMMUNITY_IDS` 표에 두었다. 클립 목록 출처로는 게시물 누적값만 받는다. 새 회사 시험은 `server-external-vk.test.mjs`다.

네이버 블로그 주인 글 목록 규칙은 이 건에서 뺐다. GPT 다시 검수가 회차마다, 이 판 전 운영 코드가 공개 화면 출처로 남겼을 수 있는 네이버 글 기록과 새 규칙이 엇갈리는 경우를 새로 찾았다. 운영 서버에 그런 기록이 실제로 없으면 옛 기록 복구 없이 단순한 판으로 실을 수 있다. 네이버까지 담은 마지막 판과 검수 기록은 공용 작업본의 `.tmp/검수/vk-naver-server-20261119-l`에 있다.

- 수집기의 VK 길은 회사 판 76이 운영에 오른 11-20에 켰다. 네이버 길은 서버 규칙을 싣기 전까지 `live:false`로 꺼 둔다. 링크드인 길은 부모 세션 판대로 켜져 있지만, 원장이 운영에 오르기 전에는 서버에 이 계정 채널이 없다.
