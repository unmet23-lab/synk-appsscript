고객과 제작자가 같은 서버 프로젝트로 취향 전달→콘셉트 선택→장면 검토→영상 수정 의견→시안 승인→최종 파일 전달을 수행하는 독립 앱이다. 공개 운영 배포와 실제 HTTPS 화면 검증, 현재 PC 플랫폼 재설치를 완료했다. 설치된 exe에서 PULSE 클릭으로 운영 독립 창이 열리는 것까지 **7/7**, 같은 설치 exe에서 최종 웹앱의 참고/업로드 이미지·확대·출처 정책·외부 활성 콘텐츠 차단 **13/13**을 확인했다. 검증 창은 정상 종료했고 평소 쓰는 플랫폼을 다시 실행해 응답 중인 창을 확인했다. ## 사용 흐름

| 단계 | 고객 | 제작자 |
|---|---|---|
| 방향 정하기 | 브랜드·목표·대상·분위기·필수/피할 요소·메모, 참고 이미지·링크와 선호 이유 저장 | 같은 자료를 확인하고 제작 범위·일정·현재 단계 안내 |

| 영상 확인 | MP4/WebM 재생, 현재 재생 위치의 수정 의견, 이전/현재 시안 비교 | 시안 업로드, 공개 답변, 원수정 요청과 수정본 연결, 지정 검토자 검토 |

## 현재 제한

파일당 **100MiB**, PNG/JPEG와 MP4/WebM을 지원한다. 취향 보드에는 이미지 또는 참고 링크를 올린다. 영상 생성·렌더·변환·이어 올리기·프레임 위 그림 주석·콘티 자동 재생은 제공하지 않는다. 실제 제작은 제작자가 기존 제작 도구에서 하고 시안을 업로드한다.

협업 데이터는 서버에 저장하므로 연결이 필요하다. 상대방 변경은 **최신 내용 불러오기**로 확인한다. PWA는 공개 앱 화면만 캐시하고 프로젝트 API·초대·고객 파일은 캐시하지 않는다. 미전송 초안은 열린 화면의 메모리에만 유지하므로 종료를 넘는 오프라인 저장으로 안내하지 않는다. 승인은 특정 최신 시안을 기준으로 최종 제작을 진행하는 승인이고, 별도의 납품 파일 인수 승인·전자 계약·결제는 없다.

작업 중 문의한 이 PC의 간헐적 입력 지연은 [별도 측정 기록](pc-performance.md)에 남겼다. 메모리 압박을 관측했지만 정확한 10분 주기 원인은 확정하지 않았다.
