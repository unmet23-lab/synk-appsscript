## 막힌 것과 고친 것

- 다섯째 사본에서 옮기기가 「경로를 찾을 수 없음」으로 멈췄다. 사본끼리 `desktop/node_modules` 연결로 서로를 가리키고 있었는데, 그 대상 사본을 바로 앞에서 옮긴 뒤였다. 멈춘 사본은 복사와 대조까지 끝났고, C: 원본과 git 등록은 그대로였다.
- 도구가 앞서 옮긴 사본을 가리키는 연결을 새 자리로 잇고, 이을 수 없는 연결이 있으면 옮기기 전에 남기게 고쳤다. 멈춘 사본은 `마저옮기기.py`로 마저 옮겼고, 이미 옮긴 첫째 사본의 깨진 연결은 `연결다시잇기.py`로 새 자리에 다시 이었다. 원인과 고침은 [현장 노트 · 윈도우](../../../현장노트/윈도우_셸.md) 「GPT 사본끼리 `desktop/node_modules` 연결로 서로를 가리켜」 절에 있다.
- 처음 돌린 `.tmp` 미리 보기는 출력 없이 끝났다. 끊긴 세션이 남긴 같은 미리 보기 프로세스와 겹쳐 돌았기 때문으로 보지만 확인하지는 않았다. 다시 돌린 미리 보기는 597곳 18.16GB를 골랐고, 실행 때는 다시 골라 669곳 18.27GB를 옮겼다.
