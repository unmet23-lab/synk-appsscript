## 증거와 사용

- `maker-customer-preferences.jpg`: 제작자에게 표시된 고객 취향·선호.
- `client-v1-revision.jpg`: 고객 시간 의견과 동일 시안 승인 차단.
- `client-versions-compare.jpg`: 이전·새 시안 비교 화면.
- `client-v2-approved.jpg`: 고객 v2 승인 기록.
- `maker-approved-history.jpg`: 제작자 기획 확인·콘셉트·장면·의견·승인·최종 파일 이력.
- `maker-revision-resolved.jpg`: v1 수정 요청 처리 완료.
- `client-ready-for-user.jpg`: 사용자가 직접 의견·승인을 남길 새 검토 버전.

제작자 공간에서 위 프로젝트를 선택하고 **최신 내용 불러오기**를 누르면 고객의 새 입력을 확인한다. 새 수정 의견에는 수정본 파일을 업로드한 뒤 **수정본 고객 확인 대기**에서 그 파일을 연결한다. 고객은 목록에서 최신 시안을 선택하고 승인한다. 서버 저장·파일 전송에는 네트워크가 필요하며 상대방 변경을 자동 푸시하는 기능으로 안내하지 않는다.

기존 테스트의 승인·최종 파일은 이력에 남는다. 새 직접 체험용 시안을 승인한 뒤 다시 납품하려면 그 시안에 연결한 새 최종 파일을 올린다. 영상은 960×540, 24fps, 15초의 무음 가상 브랜드 예시이며 자유 의견을 자동으로 영상에 반영하는 기능은 아니다. 외부 고객에게 메시지·메일을 발송하지 않았다.
