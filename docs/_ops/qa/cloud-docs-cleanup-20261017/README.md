## 트랙 정리 방식

- 항목 하나 = 원래 판의 `- **제목:**` 줄 하나(이어지는 들여쓴 줄 포함). ID `tN-NN`은 절 번호와 절 안 순서다.
- §1 유호님 차례·§2 위험은 **한강2126 줄(t1-16)만** 줄였다(1차에서 제안하고 「전부 진행」으로 적용). 판마다 적힌 「남은 일」은 다음 판이 대신했으므로 지금 남은 일(v33 수정, 마감 확인)만 남겼다. 나머지 §1·§2 줄은 글자 그대로다.

- 줄인 항목의 원래 줄은 [트랙 보관](../../트랙_보관_20261017.md)에 ID 앵커와 원래 줄 번호를 달아 글자 그대로 옮겼다(옮긴 줄이 보관에 그대로 있는지 스크립트로 확인). 보관 안 링크는 같은 폴더라 원래대로 이어진다. 트랙 새 줄·보관에 새로 깨진 링크는 0건이다.

### 로컬 미푸시 수정과 3방향으로 합칠 때

기준(BASE)은 `1676291a:docs/_ops/트랙.md`다.

1. 로컬에서 고친 줄이 아래 표의 「그대로」 항목이면 보통 3방향 병합이 충돌 없이 들어간다(§1·§2는 t1-16 말고 전부 「그대로」).
2. 로컬에서 「줄임」 항목의 원래 줄을 고쳤으면 그 줄에서 충돌한다. 로컬 판과 BASE 판의 그 줄 차이(새 결과·새 남은 일)를 새 판의 짧은 줄에 옮기고, 보관은 BASE 그대로 둔다.
3. 로컬에서 새 항목을 더했으면 위치만 맞춰 그대로 넣는다.
4. 트랙은 LF다. 합친 뒤 `tr -cd '\r' < docs/_ops/트랙.md | wc -c`가 0인지 본다([줄끝 노트](../../../현장노트/git_줄끝_잠금.md)).
