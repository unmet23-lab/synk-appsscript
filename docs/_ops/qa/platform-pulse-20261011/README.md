# Platform PULSE 클라이언트 공간·재설치 — 2026-10-11

사용자 요청으로 현재 PC의 Platform Preview 0.4.0을 다시 설치했다. 왼쪽 목록의 회원 혜택 중복 네 항목을 제거하고, PULSE의 준비 중 화면을 모델·포트폴리오·제작 요청 정리 공간으로 바꿨다. 현재 설치된 묶음에서 화면 검사까지 통과했고 기존 플랫폼을 다시 열어 창 생성을 확인했다.

## 이번 기능

- 공개 캐스팅 모델 6명의 대표 사진 확대, 성별·이름·분위기 검색, 후보 담기·모아보기.
- 공개 모델 이미지 작업 1건 안의 사진 6장을 포트폴리오로 표시. 가상 모델 5명과 창업자 본인 기반 이미지를 구분한다.
- 고른 모델·작업과 브랜드/제품·제작 목적·사용 채널/규격·희망 일정·기타 메모를 요청문으로 복사한다.
- 직접 누른 임시 저장만 현재 기기·계정에 적용한다. 계정 전환 시 화면의 이전 초안을 비우고, 저장하지 않은 작성 내용의 정상 종료 보호를 연결했다.
- 제작 중 뮤직비디오·기업 영상은 사용자가 완성 후 알리면 추가한다. 자동 접수·외부 발송·실시간 협업·결제·다른 기기 동기화를 구현한 것은 아니다.
