# PULSE 제작 설계 — 2026-10-11

사용자가 제시한 광고 제작 철학·절차를 기존 독립 PULSE의 제작 설계와 장면 연결로 구현했다. 사용자는 초안을 **확정되지 않은 가안**으로 지정했으므로 5일·14일·수정 1회·무제한 수정은 확정 상품 조건으로 넣지 않았다. 담당 원문과 조사 근거는 [PULSE 5-7](../../../마케팅/PULSE.md#5-7-광고-제작-철학을-고객의-제작-설계로-연결--2026-10-11)에 있다.

## 실제 기능

- 목적·소개할 대상·성공을 확인할 지표/기간/자료 출처, 고객 상황·구매 장벽을 정리한다.
- 중심 약속 하나와 핵심 가치 2~3개·각 근거, 기억할 요소·다음 행동을 기록한다.
- 여러 노출 채널·희망 형식·표현·대사·목소리·인물·의상·자막·강조 문구를 구분한다.
- 제작비/노출비·필요 결과물·권리·희망일·수정 협의를 기록한다. 미정 항목은 비워 둘 수 있다.
- 저장한 기획의 확인 요청과 고객의 해당 버전 확인을 기록한다. 변경하면 이전 확인은 과거 버전에 남고 현재 확인은 해제된다. 최근 20개 이전 버전의 전체 원문을 다시 볼 수 있다.
- 텍스트 콘티부터 작성하고 장면의 역할과 핵심 가치를 연결한다. 저장 당시 가치 문구·기획 버전을 보존하며 이후 변경을 알린다. 장면 합계와 희망 길이도 비교한다.

기획 확인은 영상 승인·견적·납기·수정 조건 확정과 다르다. 기존 취향 보드·영상 수정 의견·승인·납품 기능을 유지한다. 실제 캠페인 성과 수집·인과 효과 검증·자동 집행·자동 영상 생성은 구현 범위가 아니다.

최초 브라우저 시도에서 서버 저장을 본 직후 UI 갱신 전 승인 버튼을 검사한 타이밍 문제가 있었다. UI 갱신 대기로 보완한 최종 실행에서 승인 차단을 확인했다. 최종 실행 말미의 기존 검사 또한 프로그램으로 초점을 주는 것을 키보드 입력으로 간주해 `:focus-visible` 판정에서 중단됐다. 실제 Tab 입력→본문 링크 사용을 별도 후속 검사로 확인했고 남은 오프라인 항목도 통과했다. 원본 보고서의 중단 상태를 지우지 않고 [전체 흐름](browser-flow.json)과 [후속 검사](browser-accessibility-offline.json)를 함께 보관한다. 브라우저 예외·외부 요청은 0건이다.

모든 고객·제작자 조작은 합성 프로젝트와 격리 서버에서 수행했다. 운영 고객 프로젝트·의견·승인은 작성하지 않았다. PC 부하를 줄이기 위해 서버 검사는 원격 격리 컨테이너에서, 브라우저는 직렬로 실행하고 종료했다. 새 설치파일 생성은 필요 없다.
