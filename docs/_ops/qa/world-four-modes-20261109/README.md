# WORLD 네 갈래 · 맞춤 연습 실측 (2026-11-09)

[검토 문서](../../../WORLD_네갈래_구조_검토_20261109.md)의 숫자를 다시 내는 스크립트다. 모두 읽기 전용이고 기록은 메모리에만 둔다. 사람의 실제 기록은 쓰지 않는다.

| 파일 | 하는 일 | 실행 |
|---|---|---|
| `학습자별추천.mjs` | 실제 계획 코드(`createWorldLearningPlan`)와 실제 WORLD 코치(Core)로 학습자 15유형 + 설정 13가지를 돌린다. 시험 목표는 화면처럼 진단 · 이번 주 계획까지 넣고, 공개 은행 `world-topik-items.json`을 불러온다. ⑪~⑮는 진도만 있고 코치 기록이 빈 판이다 | `node 학습자별추천.mjs <저장소 경로>` → [결과](결과_학습자별추천.txt) |
| `검수뒤_재측정.mjs` | 검수 지적 뒤 다시 잰 것 — 레슨 22개를 코치에 실제로 답한 기록 · 틀린 답 · 소리 끔 · 화면의 시간 3 · 5 · 10분 · 손님 · 이유 문장 세 언어 | `node 검수뒤_재측정.mjs <저장소 경로>` → [결과](결과_검수뒤_재측정.txt) |
| `목표별_끝난뒤.mjs` | 레슨을 다 마친 학생이 목표마다 받는 것(진도만 있는 판) | → [결과](결과_목표별_끝난뒤.txt) |
| `이야기기록_맞춤으로.mjs` | 드라마 말하기 능력이 WORLD 코치 지도 · 요약에 있는지 | → [결과](결과_이야기기록_맞춤으로.txt) |
| `게임후보검증.mjs` | 추천 밖 7게임의 문항 메타를 Core 후보로 넘겨 본다(Fable 검수가 만듦) | → [결과](결과_게임후보검증.txt) |
| `칸별문항.mjs` | 연습 은행 + 후보 게임 + 생활 문항을 능력 칸(능력 · 난도 · 응답 꼴)별로 센다 | `node 칸별문항.mjs <저장소 경로>` → [결과](결과_칸별문항.txt) |
| `콘텐츠양.mjs` | 생활 레슨 · 게임 · 쓰기 · 말하기 · TOPIK 은행 수 | `node 콘텐츠양.mjs <저장소 경로>` |
| `후기받기.cjs` · `후기분류.cjs` · `후기정독.cjs` | App Store 공개 후기 RSS를 받아 낱말로 묶고 읽는다. **원문은 저장소에 넣지 않는다** — 첫 인자로 저장소 밖 폴더를 준다 | `node 후기받기.cjs <밖 폴더>` |

아르곤 · Fable 두 차례 검수의 처리는 검토 문서의 「검수 기록」에 있다. 2차 지적을 반영한 v0.3은 다시 검수받지 않았다(문서만 바꾼 의견, 두 쪽 모두 P0 없음).

후기 묶음 수(낱말 어림, 9앱 4,300건): 안내 · 맞춤 칭찬 41건(평균 3.49) · 수준 61건(평균 2.74, 별 1~2개 28건) · 고를 자유 53건(평균 2.85) · 찾기 40건(평균 2.92). 낱말이 뜻과 어긋나는 글이 섞여 있어(「advanced」 칭찬, 결제 강요 등) 수만으로 판단하지 않고 표본을 읽어 확인했다.
