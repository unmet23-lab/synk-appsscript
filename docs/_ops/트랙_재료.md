## 과거 기록으로만 남긴 것

v9.311 배포 막힘·crewcard 옛 지문·시트 첫 확인 예약 실패는 이후 배포·실측과 충돌해 현행 대기에서 제외했다. 음악의 옛 단가·크레딧·ZeroGPU 잔량·Minimax 생성 명령과 WMI 전용 실행법도 현재 지시가 아니다.

철학 심문 회차·엔진 합침·소개서 37곳 수정·쉬운말 개정·완료된 7단계 교체의 전문은 위 고정판과 기존 결과로 읽는다. 옛 발전안은 현재 작업 규칙이 아니며, G2 전원 압박·G3 외부 출구·FSRS·캐릭터 포화의 현재 계약은 [철학 적용 기준](../철학_적용기준.md)과 해당 원문이 맡는다.

09-04 구현 늦춤·‘실물 판정을 나중에 한 번에’·‘새 세션은 먼저 규모를 물어라’ 같은 당시 맥락을 현재 직접 지시 위에 놓지 않는다. 트랙의 현재 잔여를 먼저 보고 필요한 과거 근거만 고정판에서 연다.
