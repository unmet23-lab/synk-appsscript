- 레이싱 `qa/play.cjs`는 RACING_URL과 상관없이 `/try/racing/**`를 **스크립트 폴더의 원본 파일**로 내준다. 공개 후보를 시험하려면 그 스크립트를 후보 폴더(`cand/try/racing/qa/`)에 복사해 돌리고, 공개 전에 그 `qa/`를 지운다.
- `git status --porcelain` 출력을 통째로 strip하면 첫 줄 경로 첫 글자가 잘린다. 경로가 수천 개면 명령 길이 한도 — 상위 폴더로 묻고 `--pathspec-from-file`.
- 공용 작업본에 주인 없는 `index.lock`이 몇 분마다 생긴다 → `node tools/git잠금.js --정리`(주인 없는 것만).
- 트랙·결정 작업본은 줄바꿈이 섞여 있다(CRLF·LF). 줄마다 원래 줄바꿈을 지키며 고친다(`scripts/record11.py`의 Doc 방식).
- 큰 push가 GitHub 500으로 거절되면, origin이 그대로인지 보고 만든 커밋을 그대로 다시 push한 뒤 로컬 master에 「트리 그대로」 병합 커밋.
