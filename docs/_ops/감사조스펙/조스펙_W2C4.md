## D5-13

**현장(감사 원문)**: 전 화면 pressed 스타일 — 눌림 불투명도가 다섯 벌(0.82 검수·답장 / 0.75 말하기·교수멘탈·알바변명 / 0.7 강사·나침반·검수문 / 0.65 도착확인, 자 = grep pressed) + 테마 색.눌림(Coral 3 «눌린 면 전용») 소비 0

**시공 지시서**: ①테마.js 색.눌림(40행) 곁에 `export const 눌림감 = Object.freeze({ 면: 0.82, 글: 0.7 });` — 색.눌림에는 「소비 0 · 코랄 면 버튼 소멸로 유물 — 새 소비 금지」 봉인 주석. ②전 화면의 pressed 리터럴을 기계 치환: 면 버튼(주버튼·칩·저장·확정·표정칸 등) → `opacity: 눌림감.면`, 글자 링크(back·곁길·줄버튼·연한단추) → `opacity: 눌림감.글`. 현행 여섯 벌 실측(0.6 원장초기화97·인증300 / 0.65 도착확인×14·반피드백441 / 0.7 다수 / 0.75 게임·말하기 다섯 / 0.8 관찰293 / 0.82 검수화면936·답장341·원장127·인증359·문구감수235) — 감사의 다섯 벌보다 한 벌 더 갈라져 있다. 게임 화면 0.75는 면 쪽(0.82)으로 접는다 — 얕은 단을 남길 근거가 코드에 없다. ③도착확인.js·관찰화면.js 는 피어 커밋 뒤 같은 규칙으로 치환. ④디자인 토큰(apps:docs/디자인_토큰.json) 등재는 별도 커밋으로 제안만.

**실물 근거(정찰)**: grep 실측: pressed opacity 리터럴이 0.6/0.65/0.7/0.75/0.8/0.82 여섯 벌 · 색.눌림 소비 0건(정의 테마.js:40뿐). 도착확인.js(0.65×14곳)·관찰화면.js가 피어 영토.

**시험**: tests/테마면.test.js. 회귀 1건: src 전체에서 pressed 곁 opacity 숫자 리터럴 0건(눌림감 참조만) — grep형 소스 시험.
