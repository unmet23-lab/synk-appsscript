## 3. 아침에 할 일 — 순서대로

**① 몇 장 났나 본다**
```
Get-Content "C:\Users\q1212\AppData\Local\Temp\synk-밤굽기\밤굽기-20260907-0347-b.log" -Tail 30
```
🔴 **세 장 잇달아 실패하면 30분 쉬고, 두 번째면 그만두는** 규율이 도구에 들어 있다. 끝줄이 그 사유를 쥔다.

**② 🔴 함정을 먼저 막는다 — 이걸 안 하면 부품이 조용히 빠진다**
`tools/룸자산화.py` 는 `docs/Loom_자산/구움/<규격키>.png` 를 읽어 base64 로 JSON 에 넣는다.
**그 PNG 가 없는 키는 그냥 건너뛴다.** 09-07 새벽 실측으로 규격 키 47 중 **21개가 그 상태**였고,
지금은 `구운재질.json` 안의 base64 가 **유일한 사본**이다.
⇒ 밤에 못 구운 것이 하나라도 있으면 그 부품이 JSON 에서 사라진다. 그런데 **지면은 CSS 흉내로 되돌아가고
`node tools/lib/loom.js --분모` 는 그래도 초록을 낸다**(그 검사기는 「구현됐나」만 보고 「최신인가」는 안 본다).
**처방** = `룸자산화.py` 에 「원본 없는 키는 기존 JSON 값을 그대로 유지하고, 유지한 수를 보고한다」를 넣는다.
✅ 잃지는 않는다 — `구운재질.json` 은 09-04 커밋에 들어 있다. 위험은 «빠진 줄 모르고 지나가는 것»이다.

**③ 배선을 갈아 끼운다**
```
python tools/룸자산화.py
node tools/lib/loom.js --분모
```

**④ 지면을 다시 굽는다**
```
node tools/룸조판.js docs/_원고/<원고>.md      # 조판 지면
node tools/지면얹기.js --적용                    # 손 HTML
```
그다음 커밋. 새 자산은 미추적이 많으니 `git add -- docs/Loom_자산/구움/ docs/공방/` 를 먼저 한다.

## 6. 표지 「합주」가 무엇인가

문서 지면 맨 위 표지에 깔리는 **그림 한 장의 이름**이다. 부품 여럿을 한 화면에 같이 세운 장면이라 그렇게 붙었다.
지금까지 `tools/룸장면.py` 의 `합주세우기()` 가 **블렌더로** 유리 구·펠트 구·레진 구 셋을 세워 구웠다(09-01 판).

🔴 **09-03 확정이 부품에는 닿고 이 장면에는 안 닿았다.** 그래서 「유리·레진은 나간다」 뒤에도 표지에만 구슬이 남았다.
이번 배치가 그 자리를 **펠트 구슬 셋**으로 다시 굽는다(코랄·크림·짙은 무채 · 실땀 한 줄 · 투명 0).
⚠ 굽고 나면 **`룸장면.py` 의 `합주세우기()` 도 같이 은퇴시킨다** — 안 그러면 다음에 누가 그 함수를 돌려 구슬이 되돌아온다.

## 7. 안 재본 것 — 지어내지 않는다

- **1,466장을 눈으로 다 보지 않았다.** 부품 후보 무리(A·B·C·D·E·P) 40여 장만 대조판으로 봤다. 색 천 견본과 마스코트 판은 안 봤다.
- **새로 구운 42장이 실제로 지면에서 어떻게 보일지** 아직 아무도 안 봤다. 44px·24px 실크기 줄이 진짜 자다(계획.json 규율).
- 원본 PNG 21개가 **언제 왜 사라졌는지** 안 쫓았다. `docs/캐릭터/*공방*` 아래를 안 뒤졌다.
- **앱(SYNK-talk)과 캐러셀 쪽 배선**은 안 건드렸다. 여기서 잰 것은 «문서 지면» 층이다(다만 셋이 같은 `구운재질.json` 을 읽으므로 ③을 돌리면 함께 갈린다).
- 밤 배치가 **끝까지 돌지** 안 봤다. 09-07 03:47 에 띄웠고 이 문서는 03:50 에 썼다.
