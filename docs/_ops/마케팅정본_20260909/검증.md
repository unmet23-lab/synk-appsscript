# 마케팅 정본 — 통합·검증 기록

> 2026-09-09 · 대상 `docs/마케팅_정본.md`. 전략 문서 작성의 증거이며 콘텐츠 게시·서비스 출시·고객 효과 확인 기록이 아니다.

## 1. 수행 범위

- 새 정본: 네 브랜드의 타겟·제공 경험·시그니처·채널 지도·자산 활용·엔진 효용·제작 기획서·관찰 눈금·90일 적용 설계.
- 기존 문서 연결: 공통 AI 운영 원칙의 마케팅 행, 문서 지도, 명품 기준, 브랜딩 v2, 회사별 마케팅 v1, 트랙의 해당 절.
- 기존 약속·가격·환불·정원·일정·설계/실행 코드·색/폰트/마스코트 값은 수정하지 않았다. 옛 상태는 지우지 않고 현재 기획에서의 해석을 구분했다.
- 새 외부 게시·계정 개설·메시지·유료 광고·신규 결제·모델 기억 갱신 없음.

## 2. 실제 읽은 자료

|---|---|---|
| 주담당 | AGENTS·공통 AI 운영 원칙, 철학 1~337행 전량(긴 출력이 잘린 곳 별도 재독), 기존 회사별 마케팅 1~381행 전량, 명품 기준, 브랜딩 v2 전량, 09-09 명품 조사, DESIGN, 학생 페르소나, 09-09 네 브랜드 소개서 문안·설명·로고 문법, 폰트·사운드 킷 관련 정본 | 라이브 학생 데이터·로그인 채널을 조사하지 않음. 원본 전체 자산을 시각 재검수한 것은 아님 |

| 독립 B | 로드맵 전체 가시 본문(스크립트·스타일 제외, 출력 잘림 재독), 조직계보, SYNK·LAB·SHIFT 원문 소개서 txt 전량, 09-09 네 브랜드 소개서 문안/자산명세, 기존 회사별 마케팅·명품 기준·DESIGN | 소개서/로드맵의 옛 현재형은 현재 서비스의 증거로 쓰지 않음 |
| 독립 조사 | 공식 타겟 자료·명품 활동·플랫폼 문서의 원문, 기존 명품 조사 대조 | 출처별 날짜·표본·실제 읽은 쪽·접근 실패를 `조사_근거.md`에 명시. 몽골 청소년 인터뷰 없음 |

주담당은 독립 A/B 본문을 읽고 원천의 충돌을 대조했다. 채널 실행지·결정·트랙·제공물/진단/학생 기록 설계 등은 해당 관련 절을 읽었으며, 이를 전 저장소 전량 독서라고 보고하지 않는다. 새 결과를 만들 때 필요한 원본은 경로만 전달하는 것이 아니라 실제로 읽는다는 운영 원칙을 유지한다.

사용 스킬: `forge`는 독립 A/B→별도 하드 게이트→통합을 적용했다. `synk-design`은 승인 소개서와 킷 우선, `synk-brand`·`synk-content`는 학생의 사고 수준·말투·제작 원형에 반영했다. 학생 접점 최종 몽골어 원고는 이번에 발행하지 않았다. 승인 소개서 표지 미리보기는 주담당이 실제로 확인했다. 이미지·영상·웹을 새로 생성하지 않았으므로 이번 작업의 시각 렌더/음원 실청취 완료를 주장하지 않는다.

## 3. 독립 검토와 반영

- A/B는 서로 보지 않고 작성했다. 별도 조사/검토자가 내부 전략안의 사실·약속·학생보호 하드 게이트를 판정했고 둘 다 합격했다.
- 두 안의 중심이 수렴해 인위적인 혼합을 하지 않았다. A의 대상·증거 구조에 B의 세밀한 상황·조용한 참여·몽골 자기표현·인수 레시피를 통합했다.
- 통합본은 조사 담당, 엔진 담당, 로드맵/소개서 담당이 각각 검토했다. 중요한 방향·사실·약속의 기각 사유는 없었다.
- 보완 채택: ① Core와 Atlas를 구분 ② PULSE 제작/SHIFT 계약·청구·정산 및 우리 IP/고객 소유 구분 ③ 학생 실물 3게이트 명시와 실제 사례 표의 연결 ④ 공방 계획의 옛 재염색 지시를 현행 승인 자산 원천보다 우선하지 않도록 명시.
- 소프트 권고: synkbrief는 AI/유학/기관 고객이 섞이므로 첫 제작에서 대상별 표지·도착 페이지 구분을 우선 확인한다. 본문 §4-4·§7·§10에 설계되어 있다.
- 해시·행 증거·판정의 정확한 범위는 [하드 게이트](하드게이트.md)에 있다. 학습 효과·영업 준비·외부 발행의 합격 판정은 아니다.

## 4. 로컬 검사

- 본문 15개 최상위 절(§0~14), 19개 표의 열 수 일치. 필수 브랜드/채널/자산/엔진/실행 절 누락 없음, 깨진 대체 문자 없음.
- 본문의 Markdown 로컬 링크는 56개, 중복 제거 51개. 첫 검사에서 작성 예정인 이 `검증.md` 하나만 미존재였고 나머지 모두 존재했다. 이 파일 생성 후 같은 검사를 재실행해 **미존재 0개**를 확인했다. 조사·하드 게이트·검증 기록의 로컬 링크도 미존재 0개다.
- `git diff --check` 대상 파일 검사: 오류 없음. Windows 줄바꿈 정규화 안내는 내용 결함과 구분했다.
- 외부 수치 대조: Study in Korea 과정별 합계가 15,270과 일치. KOFICE 표본에 몽골이 없음을 보존. 글로벌/다른 연령의 비율을 타겟 비율로 옮기지 않았다.
- 계정 현황은 기록일을 명시했다. 실시간 송출·프로필·게시 수·팔로워·성과를 새로 확인했다고 쓰지 않았다.

## 5. 동시 작업 보존

작업 중 같은 저장소의 다른 세션에서 운영 원칙·자료 지도·개발 도구 등을 수정했다. 중요한 편집 전 최신 상태를 재조회했고, `session-freshness.js`가 한 차례 `unavailable`을 반환한 시점은 직접 `git log/status/diff`로 보완했다. 원격 서버 최신과 로컬 기준을 구분했다.

다른 담당의 변경을 되돌리지 않았다. 공통 문서에는 마케팅 진입 링크 한 줄만 추가/수정하고 다른 내용은 보존한다. 커밋 시 해당 연결 변경과 이 작업의 정본·조사·검수 자료만 분리한다. `.gitattributes`, `.gitignore`, 코드·영상·언어 검수 등 남의 변경은 이 작업 소유가 아니다.

## 6. 다음 실행에서 실제 확인할 것

타겟 인터뷰와 콘텐츠 사용 시험, 게시용 몽골어 검토, 실제 계정·도착 화면, 새로운 SHIFT 서비스의 계약/담당/권리, 모집·진단·환불·수업 달력의 정합, 신규 콘텐츠의 제작·게시·성과 측정은 각 실행 작업에서 확인한다. 이 목록은 전략 정본의 미완성 초안을 뜻하지 않고, 설계와 사업 결과를 구분하는 운영 인수 사항이다.
