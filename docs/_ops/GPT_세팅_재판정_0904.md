## 1. 새 그림 — 역할 넷과 흐름

```
클로드(설계·발주서) ─▶ GPT 실행자(구현·시험) ─▶ GPT 검수자(다른 세션·적대) ─▶ 클로드(의미·통합) ─▶ 유호님(운영 승인)
                              └── 도구 하나가 이 셋을 사람 손 없이 잇는다: node tools/codex-build.js --발주 <발주서>
```

| 역할 | 하는 일 | 받는 것 | 일부러 안 받는 것 | 도구 |
|---|---|---|---|---|
| **실행자** | 발주서를 그대로 구현하고 시험을 붙인다 | 공통 규율 + 실행자 절 + 발주서 전문 + 저장소 `AGENTS.md` | 철학 전문 · 기억 · 트랙 · 결정 이력 | `codex-build.js` |
| **검수자** | 커밋 하나를 적대적으로 본다 | Code Review Rules + 제품 방향 발췌 + 철학 게이트 카드 + 기각 이력 | 실행자의 프롬프트·발주서(수용 대조 단계에만 «수용 기준»만) | `codex-review.js` |
| **심문자** | 설계 문서를 동결 전에 공격한다 | 템플릿 + 철학 게이트 + 닫힌 결정 + 문서 전문 | 나머지 전부 | `codex-review.js --심문` |
| **뜻 대조** | 몽골어 역번역이 원문과 같은 뜻인지 | 한국어 문장 둘 | 몽골어 · 맥락 | `몽골어대조.js` ⑤ |

🔑 유호님이 「역번역도 잘 쓰고 있다」고 하신 자리는 정확히 말하면 «역번역은 제미나이가 만들고, 그것이 원문과 같은 뜻인지는 코덱스가 본다»다. 만든 쪽이 제 답을 채점하면 늘 「같다」라서 코덱스에게 준 층이다. 그 자리는 그대로 두었다.

**한 벌이 도는 순서**(`codex-build.js`): ⓪발주서 형식 검사 → ①발주 검토(코덱스 · 읽기 전용 · 구멍 찾기 · «막힘»이면 클로드에게 돌려준다) → ②실행(코덱스 · 워크트리에 쓰기 · 네트워크 없음) → ③범위·비밀 검사 + 시험을 도구가 직접 돌린다 → ④범위 안 파일만 커밋 → ⑤검수(새 세션 · 읽기 전용) → ⑥수용 기준 대조 → 차단급·미충족·시험 실패면 ⑦수리 라운드(상한 2) → ⑧장부 `docs/_ops/실행기록.jsonl` + 보고. 던져 두려면 `--던지기`(세션을 다시 열면 훅이 알린다).

**정본 전부를 주지 않는 이유**(유호님 지적 그대로): 검수자가 발주서를 받으면 「시켜서 그렇게 했다」를 이유로 삼는다. 그래서 검수자는 코드가 하는 일만 보고, 실행자와 다른 세션에서 돈다. 실행자만 더 받는다(설계 불변식 7 · 데이터 원칙 · 저장소별 손버릇 — `docs/GPT_정본.md` §2).

## 6. 대가와 남은 것 — 숨기지 않는다

- **배포 도장이 두 번 든다.** 실행자 레인의 검수는 워크트리 기준이라 배포 지문이 안 붙고, master 에 합친 뒤 `/deploy` 가 한 번 더 검수한다(코덱스 5~8분 더). 붙이려면 배포 지문을 재는 자리(F335 계열)를 고쳐야 해서 따로 판정 뒤에만.
- **수용 대조·발주 검토는 모델의 판정이다.** «충족»이 사실이라는 보장이 아니다. 자는 시험 종료코드 하나다 — 그래서 시험 없는 발주서는 도구가 거절한다.
- **읽기는 못 막는다.** 실행자가 홈의 열쇠 파일을 읽을 수는 있다. 밖으로 나갈 길(네트워크)이 없고, 커밋 전 비밀 무늬 검사가 마지막 벽이다.
- **제품 저장소 발주는 아직 0.** 첫 실측은 스크래치 저장소다.
- SYNK-talk 의 `docs/공용지침.md` 는 08-03 판 사본이라 낡았다(포인터 한 줄로 막아 뒀다).
- 코덱스 한 벌 = 호출 다섯(검토·실행·검수 두 단계·대조). Plus 5시간 창은 절반 남으면 코덱스가 경고한다(09-03 판).

- 실행자 모델·효력: `tools/모델정책.js` 의 `실행선택지` 한 줄.

- **`gpt-6-astra`** 는 2026-09-03 에 나온 실물이다(만든 곳 개발자 문서 · 문맥 105만 · 효력 `low`~`max` · 입력 $10 / 출력 $50 per MTok). 옆 세션 지면이 「Astra」와 「GPT-6」을 다른 것처럼 적었는데 **같은 모델**이다.
- 배포가 단계적이다 — **Trusted Access · Daybreak 기업 먼저**, 「Plus·Pro·Business·Enterprise 는 며칠 안에」가 문서 문면이다. ⇒ **등급이 아니라 시간이 막고 있다.**
- 09-04 실측(토큰 새로 받은 직후): 코덱스 모델 목록에 **gpt-6 계열 0개** · `-m gpt-6-astra` 거절.

### 🔴 거절 문면은 근거가 아니다 — 대조군이 뒤집었다

옆 세션은 `The 'gpt-6' model is not supported when using Codex with a ChatGPT account.` 를 읽고 「계정 통로가 막는다 = 열리면 된다」로 갔다. **존재하지 않는 이름**(`gpt-9-zzz-nonexistent`)을 던지니 **글자 하나 다르지 않은 문면**이 왔다. 반대로 카탈로그 «안»의 옛 모델(`gpt-5.4-mini`)은 정상 응답했다.

⇒ 그 문면이 가르는 것은 «카탈로그 안이냐 밖이냐» 하나뿐이고, **모델의 실재도 요금제도 안 말한다.** 🚫 이 문면을 근거로 「Pro 로 올리면 열린다」를 말하지 않는다.

## 10. 그날 밤의 로그인 사고 — 되돌릴 수 없는 것을 되돌리려 했다

**무슨 일**: 유호님이 결제 등급을 올리셨는데 토큰의 등급 칸이 `plus` 그대로였다(발급 08-28). 새 등급을 실으려고 내가 `codex login` 을 돌렸고, 브라우저에 **다른 계정(77yuhbs)** 이 로그인돼 있어 그쪽으로 들어갔다(등급 `free`).

**내가 틀린 자리**: auth.json 을 백업해 뒀으니 되돌릴 수 있다고 봤다. **아니었다** — 새 로그인이 옛 refresh token 을 **서버에서 취소**한다. 파일을 되돌려도 `refresh token was revoked` 로 죽는다. ⇒ 그 사이 코덱스가 통째로 멈췄고(검수·심문·실행자 셋), 유호님이 올바른 계정으로 다시 로그인하셔서 되살았다.

🔑 **배운 것**: **재로그인은 가역이 아니다.** 파일 백업은 「되돌릴 수 있다」의 증거가 못 된다 — 서버 쪽 상태가 함께 움직이는 일은 로컬 백업으로 못 되돌린다. ⇒ 다음부터 `codex login` 전에 **브라우저가 어느 계정으로 로그인돼 있는지 먼저 확인**한다(그 한 줄이 이 사고 전체를 막는다).

📏 실측 남김: 새 토큰(20:04:52 · unmet23)의 등급은 여전히 **`plus`** 다. 즉 유호님이 하셨다는 업그레이드가 이 계정에 **아직 안 붙었다**(다른 계정에 갔거나, 결제가 안 끝났거나, 반영 지연).

## 11. 배치표에서 내가 고친 것 — 격차 셋 중 하나는 우리 과녁 밖이다

옆 세션이 「10%p 넘게 갈리는 자리 셋」을 배치 근거로 썼다. 그중 하나를 뺀다.

| 옆 세션이 든 격차 | 실제 시험 | 우리 판정 |
|---|---|---|
| 여러 앱 오가는 업무 +10.0 | 업무 자동화 벤치 | ✅ 산다 — 화면·계정·폼 레인의 근거 |
| **부품 설계 코드 +11.6** | **기계 부품 CAD 프로그램 생성** | 🔴 **뺀다** — 우리는 CAD 를 안 짓는다. 그 격차는 우리 일감으로 안 옮겨진다 |
| 제미나이 명령창 −38.6 | 터미널 작업 벤치 | ✅ 산다 — 제미나이 금지의 근거 |

⇒ 남는 격차는 **둘**이다. 그래도 배치는 안 바뀐다 — 검수·심문·실행자의 임자를 정하는 것은 성능이 아니라 「지은 자가 검사하지 않는다」이기 때문이다.

⚠ 숫자 하나도 정정: 옆 세션의 「한 덩어리 코드 73.8」은 공개값이 **73.7** 이다(1등 74.1). 방향은 같다.

## 13. 콘텐츠 초벌을 제미나이로 — 지금은 못 넘긴다

옆 세션이 「하루 소모량을 재봐야 한다」고 남긴 자리를 쟀다.

- **지금 소모는 거의 0이다** — 몽골어 검문 장부 49행 중 09-03~04 는 0행, 검수 둘째 벤더 회차는 통틀어 3행.
- **그런데 초벌 한 판이 80요청이다**(시험지 40사례 × 2회). 공짜 몫은 **하루 20발** ⇒ **첫 판에서 넘긴다.**
- ⇒ 그 역할만 `돈열쇠필요: true` 로 갈랐다. 크레딧을 충전하는 날 열린다(유호님 손 · 지금 막히는 일은 없다).
