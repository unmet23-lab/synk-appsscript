# 도구 보관 목록

`tools/`에서 지운 도구의 이름·마지막 판·지운 이유·대체를 적는다. 지운 파일은 git 이력에 그대로 있다.

- 되살리기: `git show <판>:tools/<이름> > tools/<이름>` · 폴더는 `git restore --source=<판> -- tools/<폴더>`.
- 「옛 판」은 폐기 안내만 남기기 전의 마지막 실제 코드다.
- 기록(날짜가 붙은 폴더·파일, `docs/_ops/qa`, `*.jsonl`, 결정·트랙의 지난 줄, 그 도구가 낸 시안·지면·계기판 HTML, 자료 JSON의 생성기·자 칸)은 그때의 사실이라 고치지 않았다. 거기서 본 이름은 이 표에서 찾는다. 지금 쓰는 코드·안내에 남은 언급에는 「10-20 보관」을 붙였다.
