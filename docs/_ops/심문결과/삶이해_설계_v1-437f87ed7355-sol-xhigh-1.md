1. 기존 일일 레일 하나에서 질문 `assigned → viewed/skipped → submitted`를 기록하고, 질문 원문·판·선정 규칙·목표/급수 스냅샷을 배정 사건에 굳힌다.
2. 말·글은 같은 부모 질문과 공통 L0 봉투를 쓰고, `task_format`·응답 언어·원문·전사 상태만 방식별로 가른다.
3. 주간 지향 카드는 새 원장이 아니라 근거 사건과 `as_of`를 가진 append-only AI 추정으로 만들고, 학생 확인 전에는 과제 생성에 쓰지 않는다.
4. 확인된 카드/`season_goal`을 사용한 모든 과제는 `reads.life`와 `intervention_id`에 정확한 값·판을 남겨 배정·열람·제출·성과까지 잇는다.
5. 시즌 끝에는 기존 `season_compass`·`season_review` 구조를 유지해 학생 자가판정 먼저, AI 초안 다음, 강사가 정확한 초안판을 확정한 뒤 원자적으로 공개한다.
6. 학생 화면에는 오늘 답에 대한 즉시 반응과 다음 질문을 넣고, 주간 카드까지 기다리지 않아도 한 번의 짧은 한국어 대화가 완결되게 한다.
