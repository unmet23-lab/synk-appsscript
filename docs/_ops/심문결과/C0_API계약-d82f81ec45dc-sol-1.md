## 이 문서보다 나은 대안 구조 1개

`버전별 증거 명령 계약`으로 재구성한다. 버전·이벤트별 기계 스키마가 필수/nullable/금지 필드와 고리 대상까지 강제하고, 과제는 `assignment_event_id + student_visible_snapshot + server_only_grading_key + snapshot_hash`로 분리하며, 앱은 배정 ID와 실제 표시본만 되돌린다. `/uploads/sign`은 같은 이벤트 멱등키·예상 크기·전체 해시로 업로드 예약을 만들고 `/events`가 동의·실제 크기·해시를 검증해 귀속을 확정하며, 미확정·철회 예약은 자동 삭제한다. 인증 재발급은 옛 refresh/access token·새 비밀번호·타학생 무영향 실측 전까지 이 동결에서 제외하고, 훈련 승격 사건은 L0 §6-2의 최소 계보 전부를 의무화한 뒤에만 생산을 허용한다.
