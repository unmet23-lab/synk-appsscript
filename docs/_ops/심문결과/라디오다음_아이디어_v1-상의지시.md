# 이것은 심문이 아니다 — 같이 아이디어를 내는 자리다

당신은 반대심문자가 아니다. **공동 기획자**다. 결함 지적은 다른 회차가 따로 하고 있으니, 여기서는 **새 안을 내는 데 힘을 쓰라.** 칭찬도 필요 없다. 필요한 것은 우리가 못 낸 물건이다.

## 이 자리의 사연

몽골 울란바토르에 게임화 한국어 학원을 1인으로 세우는 원장이 있다(비개발자). 그가 직접 낸 아이디어가 「24시간 유튜브 라이브 한국어 라디오」였다. 교육업계에서 아무도 안 하는 형식이라 통했다. 그가 지금 **「이런 신박하고 트렌디한 것을 더 구상하고 싶다」**고 했고, 세션이 후보 일곱을 냈다. 아래 문서가 그것이다.

당신에게 청하는 것은 **여덟째·아홉째를 같이 내는 것**이다.

## 전제 (사실로 받아라)

- **개원 2027-02-25.** 지금 학생 0명. 1기 첫 수업 11-30. 12월 파일럿(가짜 학생) 리허설 12-07.
- 과녁 = 한국 대학에 다니는(또는 갈) **몽골 유학생**. TOPIK 4급이 졸업 요건.
- **1년 TOPIK 4급 보장**을 대외로 약속했다(못 지키면 무료 케어 = 부채).
- **1인 운영.** 사람이 매일 손을 대야 하는 것은 원리상 죽는다.
- 새 고정비를 잘 못 늘린다. 대신 구글 클라우드 크레딧 ₩414,984(시한 2026-12-05)가 있고, 그림·소리·글을 굽는 기계가 이미 돈다.
- **몽골의 국민 통로는 페이스북 메신저다**(인구의 84.3%). 텔레그램·디스코드가 아니다.
- 브랜드 재질 = **펠트**(양모 천). AI 가 흉내내기 어려운 결이라 골랐다. 마스코트 셋(몽글·까몽·마린)이 펠트 인형으로 이미 구워져 있다.
- 🚫 마스코트에 **움직임을 더하는 안은 내지 마라** — 원장이 멀미를 한다(두 번 교정됨). 눈 깜빡임만 예외.
- 🚫 학생을 식별하는 데이터(실명·연락처·사진·음성 원본)를 밖으로 내보내는 안은 내지 마라.

## 재는 자 다섯 (라디오가 통한 까닭)

① 켜두면 혼자 돈다(사람 손 0) · ② 늘 거기 있다 · ③ 노는 것이 곧 재료다(참여가 그대로 학습 데이터) · ④ 광고가 아니라 증거다 · ⑤ 교육 밖에서 훔쳐온 형식이다

## 당신에게 묻는 것 다섯

1. 🔴 **여덟째·아홉째 안을 내라 — 최소 셋.** 위 자 다섯을 **넷 이상** 만족해야 하고, 아래 문서의 일곱과 겹치면 안 되고, 문서 §5 가 이미 버린 셋(AI 통화·마스코트 실시간 방송·디스코드 마을)도 안 된다. 각각에 대해 **어느 업계에서 훔쳐온 형식인지** 밝혀라. 짧아도 좋으니 구체적이어야 한다 — 「게임화를 강화하라」 같은 방향어는 답이 아니다.
2. **일곱 중 지금 당장 버려야 할 것 하나**를 고르고 왜인지 대라.
3. **자 다섯이 틀렸다면** 무엇을 빼고 무엇을 넣어야 하는가? (라디오는 아직 정식 송출 0 · 청취자 0 이다 — 성공한 적 없는 물건에서 자를 뽑은 것이 순환 논증 아닌가?)
4. **1등이 「오늘 몽골, 한국어로」가 아니라면** 무엇이어야 하는가? 순서를 다시 매겨라.
5. 🔴 **몽골이라는 자리 때문에만 되는 것**이 이 목록에 하나라도 있는가? 없다면 그것 자체가 결함이다 — 어디서든 되는 아이디어는 해자가 아니다. 있다면 어느 것인지, 없다면 **몽골이어서 되는 안을 새로 하나** 내라.

## 답의 모양

한국어로. 등급 표기 없이 산문으로. **1번에 가장 많은 분량을 쓰라** — 그것이 이 청탁의 값이다.
