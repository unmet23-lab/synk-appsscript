[P0] 소급 불가 구멍: 식별자 불일치로 인한 조용한 연결(마이그레이션) 실패 — 문서 ⑥-㉡
진단 세션을 실제 학생 계정과 잇는 유일한 열쇠를 「시작 전 입력받은 이메일 또는 전화(⑥-㉠)」 하나로만 두었다. 미인증 웹 진단 시 입력한 연락처에 오타가 있거나, 진단은 전화번호로 받고 실제 학원 등록(계정 발급)은 이메일로 진행할 경우, 두 데이터는 영원히 이어지지 않는다. 마이그레이션이 실패해도 시스템은 이를 알지 못하며, 8주 뒤 끝 진단 시 비교할 「시작점」이 증발하여 환불/연장 보장 조건 자체가 무너진다.
대안: 진단 완료 시 화면에 「고유 진단 코드(6자리 등)」를 발급하여 노출하고, 학원 등록 시 이 코드를 입력하거나 원장이 대조할 수 있는 수동 연결 창구를 배관(마이그레이션) 설계에 포함할 것.

[P0] 학습 사슬 단절: 쓰기 문항 AI 태깅 결과의 저장소 스키마 누락 — 문서 ④-㉤, ⑥-㉠
④-㉤은 쓰기 문장을 「오류 태그 23종으로 태깅하여 약한 자리 카드의 재료로 쓴다」고 명시했다. 그러나 ⑥-㉠의 『진단 세션 보관 그릇』 칸 목록에는 「문항 스냅샷」과 「답(쓴 문장)」만 있을 뿐, AI가 판정한 **「태깅 결과(오류 23유형)」를 담는 칸이 없다.** 스냅샷 규칙상 나중에 다시 채점할 수 없으므로, 이 상태로 학생 표(learning_events)로 마이그레이션되면 쓰기 산출물은 텍스트만 남고 정작 엔진이 읽어야 할 『실력 이해(무엇을 틀렸는가)』 데이터는 영구 유실된다.
대안: ⑥-㉠의 표 구조에 「AI 판정 태그 결과」 칸을 명시적으로 추가할 것.

[P1] 학생 경험 누락: 「신선함(생명감)」 검사의 자의적 회피 — 문서 ⑦
판단 정본 ①기본 게이트는 학생이 만나는 화면의 신선함을 「살아 있는 자리 검사 여섯」으로 재며, "하나라도 빠지면 미완성"이라고 닫아두었다. 그러나 ⑦항은 마스코트 표정 하나와 결과 카드 한 줄만 넣은 뒤 나머지 4개 검사(문, 만지면 움직이나, 시간이 흐르나, 나를 알고 챙기나)를 "해당 없음으로 적는다. 통과시키려고 덧그리지 않는다"며 의도적으로 방치했다. 이는 미끼 상품(첫인상) 화면을 타 학원의 흔한 정적 웹 폼과 다를 바 없는 죽은 화면으로 만들며, 학생이 이 진단에 흥미를 느끼고 끝까지 완료할 이유(재미/신선함)를 완전히 빠뜨린 결함이다.
대안: 없음 (해당 4개 검사를 통과할 수 있도록 진단 UI 자체를 대화형 챗이나 인터랙티브 노드로 재설계해야 함).

[P1] 기술 실행 가능성: 비로그인 상태의 세션 연속성 파괴 — 문서 ⑨
수용 기준 ⑨-2는 "같은 사람이 같은 세션 번호로 다시 열면 같은 문항이 나온다"고 요구한다. 그러나 진단 대상자는 아직 앱 계정이 없고 토큰도 없는 상태(③-㉢)다. 브라우저 로컬 스토리지나 쿠키에 의존한다면, 학생이 모바일 인스타그램 인앱 브라우저로 열었다가 사파리로 다시 열 때 세션이 끊어져 ⑨-2는 즉시 실패한다. 서버 측에서 비로그인 사용자의 세션을 어떻게 발급하고 재개할 것인지에 대한 식별/복구 배관 설계가 전무하다.
대안: 연락 통로(이메일/전화)를 진단 시작 시점이 아니라 진단 진입 즉시 입력받아 이를 PK로 하는 임시 세션 토큰을 URL에 물려주거나 발급할 것.

[P2] 문서 간 모순: 결과 문안 표기 정책과 실제 엔진 코드 간의 충돌 — 문서 ⑧, tests/토픽등반.test.js
문서 ⑧은 "「TOPIK 3급입니다」라고 말하지 않는다"며 공식 급수와 내부 급수를 분리하겠다고 명시했다. 그러나 채점에 동일하게 사용하겠다고 선언한 기존 엔진(`토픽등반_`)의 테스트 코드(`테스트 파일 175행: assert.ok(t.indexOf(String(E.TOPIK_PEAK_TARGET) + '급') > -1)`)를 보면, 엔진이 뱉어내는 HTML 카드에는 태생적으로 「목표 급수(숫자+급)」 글자가 하드코딩되어 박혀서 출력된다. 같은 자(엔진)를 쓰면서 문서에서만 표기를 막겠다고 하는 것은 실행 불가능한 모순이다.
대안: ⑧의 금지 조항을 삭제하고 내부 진단임을 명시하는 조건 하에 엔진의 출력(`N급`)을 수용하거나, 엔진의 카드 HTML 생성부(`등반카드HTML_`)에서 외부 노출용 마스킹 옵션을 처리하도록 엔진 코드를 수정할 것.
