이 문서보다 나은 대안 구조 1개: **이벤트별 단일 실행 계약 매트릭스**로 바꾼다. 각 행에 발생 주체·허용 인증·정확한 JSON 타입·필수/null/금지·클라이언트/서버 소유권·동의 판정·인과 참조·버전 변환·오류를 두고, 여기서 문서·앱/서버 검증기·DB 왕복 픽스처를 빌드 시 생성한다; 기존 `task_id`·`intervention_id`·`correction_id`와 로컬 큐 소유자·요청 해시를 명시적으로 결속하고, 실제 DB/Auth/Storage 왕복을 통과한 사건 슬라이스만 동결한다.
