C16에는 `task_type='일기'`를 정식 추가하고 `task_snapshot`에 물음 안정 ID·실제 표시 원문·목록 판·현지 날짜·시즌을 보존하며, 녹음 뒤 `한국어/몽골어/섞임`을 한 번 고르게 해 몽골어·혼합 음성은 현행 `ko` 전사 큐에 넣지 않는다. 한국어 산출은 교정·어휘 지도와 학생의 날짜 목록으로 즉시 돌려주고, 노출·제출·매체·시간 신호는 학습자 모델의 ㉡ 사람 이해 칸에 정기 소비시키며, 목록은 커서 페이지 처리하고 인쇄는 기존 4칸 기록장이 아닌 별도 시즌 일기 조판기로 만든다. 이 레일의 저장·소비·학생 반환을 실제 시험한 뒤에만 `모였나·닿았나·늘었나·누구에게` 네 칸을 종결 기록한다.
