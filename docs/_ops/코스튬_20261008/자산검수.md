# 코스튬 첫판 자산 검수 — 2026-10-08

까몽의 기존 통합 착용 이미지에서 **목도리·앞치마·여름 델·겨울 델·펠트 헤드폰 5차림**을 기본 정면 사용 후보로 선별했다. 무의상 정본도 함께 파생했다. `costume-assets.json`에 원본 절대경로·SHA256·차림 ID·표시 이름·파생 파일·검수 범위를 기록한다.

## 실제 확인

- `costume-candidates-contact.png`: 무의상 정본과 기존 단품 21종을 나란히 실제 이미지로 확인했다. 5차림은 의복/악세사리 차이가 뚜렷하고 얼굴의 눈, 귀, 양쪽 앞발, 꼬리의 주요 형태가 보인다. 손으로 그린 신규 의상이나 외부 그림은 쓰지 않았다.
- `expressions-contact.png`: 위 5차림의 단품 기본, 표정판 기본, 눈감음, 눈웃음을 비교했다. 눈 이외의 미간과 볼 털이 넓게 바뀌는 모습이 있어 표정판은 채택하지 않았다. 파일 알파 동일성만으로 재질 고정 통과를 주장하지 않는다.
- `selected-light-dark.png`: 실제 앱에 넘길 768px 파생을 288px로 밝은 배경과 어두운 배경에 놓아 직접 확인했다. 밝은 크림 배경에서는 자연스럽게 읽힌다. **짙은 남색 배경에서는 기존 누끼의 밝은 테가 드러나므로 직접 적용하지 않는다.** 옷장·사진 카드의 마스코트 배경은 밝은 크림 계열로 제한한다. 투명 영역을 유지하고 원본 프레임을 크롭하지 않는다.
- 털모자는 단품 시트에서 꼬리 하단 끝이 잘린 모양으로 보여 제외했다.

## 사용 범위

- 기본 정면 이미지의 옷장 미리보기, 같은 차림 유지, 저장·불러오기, 고정 포즈 사진 카드에 사용할 수 있다.
- 이 평가는 밝은 크림 배경에서의 사용을 뜻한다. 짙은 배경은 별도 가장자리 품질 개선과 재검수 없이 사용할 수 있다고 확대하지 않는다.
- 검수된 표정 목록은 **기본 한 가지**다. 기존 얼굴을 편집하거나 무검수 눈감음/눈웃음으로 교체하지 않는다.
- 착용 반응은 같은 이미지 전체의 짧은 이동·기울임·확대축소와 짧은 글로 구성할 수 있다. 이는 표정 자산 전환 검수와 구분한다.
- 의상과 액세서리의 임의 조합은 이 5단품을 겹쳐서 만들지 않는다. 통합된 해당 조합 이미지가 별도로 검수돼야 한다.
- 몽글·마린, 다른 차림, 염색, 새로운 포즈, 공개 배포 검수는 이번 확인 범위에 포함하지 않는다.

## 파생 방식

`prepare_assets.py`는 원본을 읽어 768×768로 Lanczos 축소하고 무손실 WebP를 만든다. 원본 파일은 수정하지 않는다. 원본 캔버스의 위치와 비율을 유지하고, 의상·눈·몸을 다시 그리거나 합성하지 않는다. `inspect_assets.py`와 `inspect_expressions.py`는 기존 파일 비교 시트와 읽기 전용 측정 기록만 만든다.
