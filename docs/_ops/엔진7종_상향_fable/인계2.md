## 4. 오늘 밟은 함정 (같은 데 안 밟게)

- 🔴 **git 이력에서 꺼낸 스크립트는 CRLF 다** → 워크플로 도구가 「제어문자」로 거절한다. 띄우기 전에 LF 로(node 로 `\r` 제거). `node --check` 는 최상위 return 때문에 안 되니 vm 으로 잰다(`scripts/*.js` 는 지금 LF).
- 🔴 **`node -e '…'` 인라인에 정규식·`\|`·`\d` 를 넣으면 셸이 백슬래시를 먹는다** → 파일이 안 바뀌거나 스크립트가 깨진다(오늘 두 번). 정규식 든 코드는 Write 로 파일을 만들고 `node 파일` 로 돈다.
- **워크플로 동시 실행 상한 = 14/워크플로**(노트북 CPU−2). 51 을 한 런에 넣으면 세 물결 · 한 창(≈8~9M)에 51 이 안 든다(1차 런은 15/51 에서 한도). 두 런으로 가르되, **같은 짝을 두 런에 겹치지 않는다.**
- **한도로 죽은 에이전트는 산출 0** · 살았는지는 저널의 `{"type":"result"}` 줄 · 저널은 이 노트북·이 세션 폴더에만 있다.
- **집필·종합처럼 큰 글은 «나눠 쓰기»**(뼈대 Write → 절마다 Edit) — Fable 집필이 한도 «직후»에 죽었는데 파일이 온전히 남은 까닭.
- **한글 경로 `git commit -- 경로` 는 bash 에서 pathspec 을 못 잡을 때가 있다** → PowerShell 로.
- **다른 세션이 파일을 건드리면 CRLF 로 바뀐다**(Fable 판이 한 번 그랬다) — 최종 커밋 전 LF 로 되돌린다.
- **비교준비.js 는 짝을 동전으로 새로 뽑는다** — 심사 뒤에 다시 돌리면 갑/을이 뒤집힐 수 있다(§3 ⓞ 참고).
