# 작업 대기열 — AI가 다음에 집을 것

> **상태**: ✅**확정** · 2026-08-09 — 자율 진행 모드의 실행 순서 정본(메모리 `autonomous-build-mode`).
>
> **왜 이 파일인가**: 유호님이 새 세션에 「이어서 해」만 입력해도 굵직한 것부터 지어지게 하려면, **다음에 무엇을 집을지가 한 곳에 있어야 한다.** 인계문은 「직전에 뭘 했나」, 보드는 「지금 누가 뭘 잡았나」, 결정큐는 「유호님이 답할 것」이라 셋 다 이 자리를 못 채운다.
>
> **쓰는 법(세션)**: ①맨 위부터 훑어 **아직 아무도 안 잡은 것**을 고른다(`node tools/board.js` 로 대조) ②내 보드 파일에 트랙 선언 ③끝나면 여기서 그 줄을 지우고 커밋. **남의 보드 줄과 겹치면 다음 것으로 내려간다.**
>
> **고치는 법**: 새 일감을 발견하면 근거와 함께 해당 층에 **추가**한다(자율 모드 — 유호님께 안 묻는다). 순서를 크게 뒤집는 것은 유호님 판정.
>
> 🚫 유호님이 답해야 하는 것을 여기 넣지 않는다(그건 `node tools/decision-queue.js`) · 🚫 완료한 줄을 ✅로 남겨 두지 않는다(지운다 — 이력은 git).

## P0 — 개원을 막는 것

- [ ] **🔴 일괄 명부 통로가 「시트를 그대로 먹는다」는데 실제 시트를 못 먹는다 — 결함 2건**(`명부등록.js` talk `a468748` · 지적·근거 = `local_4cd29e93` · 내가 `Code.js` 로 대조 확인). 첫 실사용(유호님이 `profiles` 를 CSV 로 받아 그대로 먹이는 경로)에서 **둘 다 터진다**:
  - **①`열별칭.번호` 에 `user_id` 가 없다 → 파일 통째 거절.** `profiles` 열 지도 정본 `Code.js:955-957` = `1 user_id · 2 이름 · 3 이름_몽골 · 4 role · … · 8 연락처`. `열키()` 가 `_` 를 지워 `userid` 가 되는데 별칭에 없다(`연락처` 는 있어서 「번호 ✗ · 전화 ✓」로 뜬다). 처방 = 별칭에 `user_id` 한 줄 추가.
  - **②`role` 열 처리 0 → 강사·학부모 행이 학생 명부에 섞인다.** `profiles` 는 학생 전용 표가 아니다(`Code.js:3727`·`3873` 이 4번째 열 `role` 로 `teacher` 를 가른다 — 값은 `student`·`teacher`·`parent`). 강사 번호가 `SYNK-NNN` 이면 **강사 계정으로 첫 등록이 열리고**, 아니면 거절 목록에 떠서 화면이 「파일을 고쳐 다시 돌려라」로 시킨다 → 운영자가 **강사에게 SYNK 번호를 붙이는 것**이 처방을 따르는 행동이 된다(F103 모양). 처방 = `role`/`역할`/`구분` 열이 있고 **값이 하나라도 차 있으면** `student`·`학생` 만 통과, 나머지는 **거절이 아니라 건너뜀**(강사는 고칠 대상이 아니라 대상이 아닌 행) · 열이 있는데 **전량 비면 그 열을 무시**(안 그러면 전원 거절로 도구가 무용지물) · 건너뛴 수는 **화면에 세어 보인다**(F207).
  - ⚠ 회귀 픽스처는 **실제 시트 머리글 그대로**(`user_id,이름,이름_몽골,role,class_name,…,연락처`)를 쓴다 — 축약 머리글로 검사하면 이 자리가 영원히 초록이다.
  - ➕ 곁들여 BOM 회귀 강화: 지금 검사는 **우연히** 초록일 수 있다(`\s` ⊇ U+FEFF 라 `열키`·`trim` 이 대신 벗긴다) — 파서가 낸 칸 그대로(`표파싱(원문)[0][0] === '학생번호'`)를 봐야 그 층이 잠긴다.
  - 🚫 별도 `명단동기화.js`·`lib/명단.js` 신설 재제안 금지(08-09 에 두 세션이 동시에 지었고 `local_4cd29e93` 이 비켜나며 걷었다 — 붓는 자리는 하나여야 한다) · 🚫 「과녁 게이트 흡수」(이미 `자격증명.읽기` 로 있다 — 08-09 철회됨)
- [ ] **운영 `engine.learners` 적재 0** — 통로는 섰지만 운영 명부는 여전히 비어 있다(`local_4cd29e93` 실측 · 리허설 156행이라 왕복시험은 내내 초록이었다). ⚠ **선행 = 유호님의 실제 명부 한 장**(학생번호·전화) — 개원 전엔 채울 재료가 없다. 근거=[[l0-auth-code]]
