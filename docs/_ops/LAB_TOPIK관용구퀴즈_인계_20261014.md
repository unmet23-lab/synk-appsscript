## 3. 알아 둘 함정

- **구독 통로(agy):**
  - `proto: … string_value contains invalid UTF-8`로 죽으면 전역 훅 탓이다. 훅이 CP949 오류문(「지정된 경로를 찾을 수 없습니다」)을 내면 그렇게 된다. 구조화 답(`--json-schema`)은 `finish` 도구를 타므로, 이 경우 훅을 반드시 지난다.
  - 어느 단계에서 깨졌는지는 `~/.gemini/antigravity-cli/brain/<대화>/.system_generated/logs/transcript_full.jsonl`에서 볼 수 있다.
  - agy 로그의 「You are not logged into Antigravity」 줄은 호출이 성공해도 나온다.
- **Typecast는 몽골어를 지원하지 않는다**(`language: mon` → LANGUAGE_NOT_SUPPORTED). 몽골어판 나레이션은 한국어뿐이다. 「TOPIK」을 영문으로 쓰면 글자를 하나씩 읽어서 「토픽」으로 쓴다.
- **몽골어 글꼴:** Inter Tight에는 키릴(Ө·Ү 포함)이 있다. DM Mono·SUIT에는 없어서 몽골어 자리에는 모노를 쓰지 않는다(`ui.monoFallback`).
- **`git apply -R`로 되돌린 파일:** autocrlf가 CRLF로 다시 써서, 내용이 HEAD와 같아도 status에 M이 남는다. `git show HEAD:파일`의 바이트를 그대로 써 넣으면 깨끗해진다.
- **`git hash-object`:** `--path`와 `--no-filters`는 같이 못 쓴다. 공용 문서 blob은 `--no-filters --stdin`으로 만든다.
