1. **바탕은 «띠»가 아니라 «천»** — `DK1_띠_잉크천` 은 가로 밴드라 깔면 회색 줄이 생긴다.

3. **세로 자리를 손으로 박지 않는다** — 앞 요소가 끝나는 자리에서 사슬로 푼다. 몽글 자산은
   정사각 칸 안에 몸이 떠 있어(위 10% 가 빈 곳) 상자 기준으로 잡으면 글자와 겹친다.

4. **천 참조는 `.avif`** — 구움 폴더의 png 는 .gitignore 가 막는다. png 를 가리키면 이 기계에서만 돈다.
