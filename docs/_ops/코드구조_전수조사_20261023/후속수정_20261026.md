## 최종 Claude 판정에서 찾은 원천 연결 누락

공개판에서만 제외해야 할 수업 쓰기 진입·내지 않은 원고 닫기 확인, 계정 한글 진도 읽기, 손님 한글 기록 옮기기 연결이 정본 app-shell에서도 빠져 있었다. 거절된 원천이 공개 후보의 import 경로 6곳만 되돌린 바이트와 같았고, 최초 E01 원천에는 세 연결이 모두 있었다. 최신 원격 변경 자체의 문제가 아니라 공개용 판을 원천에 역이식한 경로 혼동으로 확인했다. 공개 후보는 별도 승인한 정상 범위다.

사용자가 허용한 E01 범위에서 GPT가 세 연결을 복원했다. 원고는 sheetResource의 hasDraft/dispose로 묶고, 한글 기록 포트는 생활 세션 폐기·계정/세대 변경·늦은 준비 완료 때 정리한다. 새 연결 회귀는 수정 전 1/14에서 수정 후 14/14로 통과했고, 기존 관련 86통과/1제외의 제외 항목도 올바른 Talk 사본을 지정해 실제 1/1 통과했다. 실제 계정 저장 포트와 CAS를 거치는 합성 기록 이전 시험을 포함하며 운영 자료나 브라우저 화면 검증을 뜻하지 않는다. 나머지 추적 40파일에서는 추가 upstream 기능 손실을 찾지 못했다. 전체 추적 41파일의 대조·복원 근거는 `source-upstream-repair-v1/`에 있다.
