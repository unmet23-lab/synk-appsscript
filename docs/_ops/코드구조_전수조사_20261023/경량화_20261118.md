## 조사 범위

SYNK-appsscript의 `4c8209e999`에서 추적 파일 55,861개의 경로와 Git 객체를 조사했다. 그중 코드·스타일·HTML·스크립트 확장자는 12,027개다. 내용이 완전히 같은 묶음은 435개였고, 각 묶음의 첫 파일을 뺀 사본은 1,491개였다. 가장 큰 묶음에는 체험별로 따로 제공하는 Three.js와 빌드 도구가 동기화하는 Atlas가 있다. 제작 원본, 벤더 파일, 개별 배포에 필요한 사본은 유지했다.

`3285b2eb61`의 추적 JavaScript 7,249개와 Python 1,314개를 모두 파싱했다. 실행할 수 없는 문장, 중복 키, 동일한 분기 등을 찾는 검사에서 후보 33건이 나왔다. 여기에는 Three.js 배포 사본 두 곳의 같은 문장도 들어 있다. TypeScript와 HTML 내부 스크립트는 이 구문 검사 범위 밖이다.
