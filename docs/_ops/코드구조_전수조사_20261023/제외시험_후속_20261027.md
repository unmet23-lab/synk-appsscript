## 빠졌던 이유와 마친 검증

CI에는 Windows/Python·로컬 암호화 모듈, 형제 저장소의 전체 서버·UI, Git 밖 모델·미디어·출시 사본·기존 Git 이력이 없다. 이 환경에 맞춰 제외한 것이 대부분이었다. 읽기 전용 자료를 해시로 복원한 격리 사본에서 백업·복원, 실제 Caddy TLS와 민감 URI 가림, 모델/미디어 경로와 바이트, 학생/교사 계약, WORLD 계정·Town·기본 게임·등록·로그아웃과 실제 두 탭 계정 분리를 검증했다. 운영 DB·고객 데이터는 쓰지 않았다.

수업 시트 캡처가194.64px 높이를193px로 잘라 실패하는 것을 재현했다. 캡처의 양끝 픽셀 경계를 맞추고 전체 높이 포함 조건은 오히려 정확하게 유지했다. 제품 화면을 바꾸지 않고 모든 상태·세 폭 캡처와 계정/탭 복귀 시험을 통과했다.
