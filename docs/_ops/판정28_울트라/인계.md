# 판정 재기 — 인계문 (2026-09-03 밤)

> **한 줄**: 유호님 앞에 걸린 판정 51건 가운데 「사실은 내가 재면 되는 것」을 재서, 유호님이 **30초에 답할 수 있는 한 줄**로 바꾸는 일이다. 28건 중 **9건이 끝났고 19건이 남았다.**
>
> 🔴 **유호 판정 09-03 밤 = 「울트라 써도 돼. 근데 내가 조절을 잘 해볼게. 근데 지금 말고 이따가 하자」**
> ⇒ **이어받는 세션은 규모를 스스로 정하지 않는다.** 유호님께 「몇 건을 돌릴까요」를 먼저 여쭙는다.

## 1. 왜 이 트랙이 열렸나

08-26 에 설계 문서 여섯의 판정 절을 한 자리로 모은 색인이 섰다(`docs/판정대기_한자리_2026-08-26.html`).
그 지면이 51건을 넷으로 가르며 「제가 더 재서 다시 여쭙니다 = 28건」이라 적었는데,
**그 28건의 이름이 저장소 어디에도 없었다.** 지면에 이름이 적힌 것은 §04 의 아홉과 강사 §13-3 의 다섯뿐이고 나머지 열넷은 가려진 적이 없다.
그래서 첫 단계가 「다시 가르기」가 됐다.

## 2. 🔴 가르는 자 — 이 트랙의 심장

「유호님만 아시는가」가 아니라 **「내가 재고 나면 유호님은 고르기만 하면 되는가」**로 가른다.

**유호님 앞에 남기는 것은 재도 답이 안 나오는 다섯뿐이다:**
① 돈을 **얼마 쓸지 정하는** 것 ② 사업 방향(무엇을 약속하나) ③ 유호님 머릿속·바탕화면·오프라인
④ 유호님 **눈**이 판정 축인 것(색·질감) ⑤ 사람 관계(누구를 쓰나)

🔑 **되던질 사유가 «아닌» 것 둘** — 이 둘로 밀면 유호님 시간만 쓰고 답이 안 나온다.
- **「돈이 걸렸다」** — 배상책임보험은 내가 몽골 시세를 재서 갈래 셋을 만들면 유호님은 고르기만 한다.
- **「저장소 0건이라 모른다」** — 그건 내가 안 재본 것이지 유호님만 아는 게 아니다.

- `ending-2`: 「변호사에게 물어볼까」였는데 **묻기 전에 몽골 민법 원문을 열었다.** 제367조의 제목이 영어 번역본 «둘 다»에서 통째로 빠져 있어 몽골어 원문을 봐야 조건이 보였다. 정직하게 남긴 것 = 우리 수강계약이 민법 몇 장에 앉는지 조문을 다 읽고도 **둘 다 안 맞았다**(그게 변호사에게 물을 한 줄이 됐다).

## 6. 다음 명령 — 그대로 친다

**먼저 유호님께 「몇 건을 돌릴까요」를 여쭌다.** 그다음:

```
Workflow({scriptPath: "docs/_ops/판정28_울트라/scripts/단계B_재기.js",
          args: <scripts/B2a_args.json 의 내용>})
```

끝나면 재료로 가른다(저널 경로는 워크플로 결과가 알려 준다):

```
node docs/_ops/판정28_울트라/scripts/분배.js <journal.jsonl> B
```

`단계B_재기.js` 는 **재기 → 반박 → 수리** 세 단을 건별로 끊기지 않게 잇는다.
1차는 재기+반박만 돌리고 수리를 `단계C_수리.js` 로 따로 돌렸는데, 그 둘을 합친 판이 지금 스크립트다.

## 7. 🔴 함정 — 이미 밟은 것들

1. **한도로 죽은 에이전트는 산출 0으로 죽는다.** 2차 일곱이 그렇게 갔다. 읽기값만 태우고 답을 쓰기 전에 멈춘다.
   ⇒ **한 런은 일곱 건(에이전트 21) 안쪽으로.** 그래서 `B2a`·`B2b`·`B3a`·`B3b` 로 쪼개 뒀다.
2. **옛글자 가드가 세 번 커밋을 막았다.** 에이전트 산출에 옛 글자가 섞여 온다.
   손으로 고쳐도 저널에서 다시 뽑으면 되살아나므로 `분배.js` 가 «쓸 때» 씻는다.
   🔑 **가드는 소스도 본다** — 그 씻는 코드 «안»에도 옛 글자를 못 쓴다(표의 키도 주석도 코드 번호로).
   🔑 **지우기만 하면 뜻이 죽는 자리가 있다.** 「일할」은 괄호 속 옛 글자를 걷으면 「일을 할」로 읽혀 뜻이 정반대가 된다
   ⇒ 낱말째 푸는 표(`낱말표`)를 먼저 걸었다. 표에 없는 옛 글자가 오면 경고가 뜨니 그때 뜻을 보고 더한다.
3. **반박의 `target` 칸에 산문이 실려 온다.** 파일 이름으로 쓰면 죽는다 — `안전이름()` 이 앞의 부호만 뽑는다.
4. **공용 원장(트랙·결정)은 파일 단위로 못 가른다.** 09-03 에 옆 세션이 커밋하며 이 트랙이 쓰던 §4-F 한 줄을 함께 삼켰다(그 세션이 커밋 메시지에 밝혔다). 고치면 «그 자리에서» 커밋한다.
5. **`git add -A` 는 가드가 막는다.** 경로를 줘도 막힌다 — `git add -- <경로>` 뒤 `git commit -- <경로>`.

## 8. 재기 프롬프트가 노리는 것

1차 반박이 사실 오류 **40건**을 잡았고 네 무늬로 갈렸다. 그 넷을 2차 프롬프트에 그대로 박아 뒀다.

1. **절 제목만 보고 본문을 추정한다** — 실제 사고: 제목의 「이름이 없다」가 문패가 아니라 «반 걸이판»의 이름 칸이었다
2. **같은 낱말이 두 곳에서 다른 것을 가리키는데 한 낱말로 붙인다**
3. **수를 옮겨 적고 다시 안 센다** — 문패 4벌인데 이름 지을 반은 24개
4. **「막혀 있다」를 확인 없이 쓴다**

그리고 갈래·권고에도 근거를 붙이게 했다(전엔 「잰 것」 칸에만 출처를 요구했다).
