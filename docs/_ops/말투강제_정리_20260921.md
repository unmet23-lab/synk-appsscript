- 콘텐츠 색인·제작 인수 기준·영상 안내와 파서 내부를 참조하던 주석을 현재 상태에 맞췄다. 같은 편수로 새 원고를 채우는 작업은 하지 않았으며 새 콘텐츠는 실제 제작할 프로젝트와 학습 상황에 맞춰 작성한다.
