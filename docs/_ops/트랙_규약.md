# 트랙 유지법

> 2026-09-10. 실행 권한·분업·최신 상태·게시·배포·기억은 [AI 운영 원칙](../AI_운영원칙.md)을 따른다. 이 파일은 [트랙](트랙.md)을 짧고 정확하게 유지하는 방법만 둔다.

## 적는 것

현재 목표, 실제 남은 행동, 담당, 필요한 시점과 원천 링크를 적는다. `[기계]`는 현재 권한 안에서 실행할 일, `[유호]`는 실제 선택·본인 확인, `[사람]`은 원어민·현장·기관 확인이다. 태그가 새 승인 절차를 만드는 것은 아니다.

완료·폐기한 일은 같은 작업에서 정리한다. ✅ 문장 안의 미구현·배포 대기·사람 판정을 먼저 꺼내 남긴다. 설계·로컬 제작·실제 게시·실학생 효과를 한 상태로 합치지 않는다. 실행 중인 세션 목록이나 새 중앙 장부는 만들지 않는다.

값·예외는 위 원문에서 읽는다. 옛 트랙 규약의 수치·발언·도구 제약을 현재 규칙으로 다시 복제하지 않는다. 코드에 칸·씨앗이 있다는 사실은 운영 시트에 반영됐다는 뜻이 아니며, 파일·렌더·게시 결과도 구분한다.

## 확인과 보존

`node tools/트랙위생.js`는 불릿 900바이트·곁줄 3줄·절 머리 2400바이트 초과를 알린다. 절 전체 크기를 제한하지 않으며 알림은 새 강제 훅이 아니다. 초과하면 긴 완료 경위는 기존 결과·Git으로 연결하고 미완료 행동과 고유 계약은 남긴다. 다른 대형 MD로 그대로 복사해 수치만 줄이지 않는다.

`node tools/lib/트랙수대조.js`는 문서에 적힌 수와 원재료를 대조한다. 옛 숫자는 당시 시점·분모를 표시하고 실제 현재 값을 재측정한다. 못 읽음은 0건이 아니다. 문구·위치를 바꾸면 이 도구를 포함한 직접 소비자도 맞춘다.

[09-10 압축 전 규약](https://github.com/unmet23-lab/synk-appsscript/blob/dcb97bb4a6c48b073fbcb5e896767bdc7f4ce344/docs/_ops/트랙_규약.md)은 과거 점검 근거다. 종료된 배포 장애·낡은 라이브 지문·09-04 구현 늦춤·기억 감시·고정 모델 순서·플랫폼 발행 권한을 현재 작업 규칙으로 되살리지 않는다. 해석이 갈릴 때만 당시 기록과 최신 직접 지시를 대조한다.
