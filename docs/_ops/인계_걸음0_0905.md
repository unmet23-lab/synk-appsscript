## 밟은 함정(09-04·09-05 두 세션)
- 「없다」와 「안 재봤다」를 섞지 않는다. 라이브·DB·바깥은 «못 재면 안 재봤다»다. 장부 ⑦「실제 행 수는 안 재봤다(DB 조회 권한 밖)」이 그 무늬.
- 장부의 줄 번호는 v2 기준이다. v3 는 09-05 에 델타 수십 벌이 들어가 줄이 움직였다 — 낱말(함수 이름·문장)로 찾는다. v3 안의 «파일 이름 뒤 숫자»(학습자상태 258 꼴)도 09-05 심문 시점 자리표지 앵커가 아니다(v3 §1-5).
- `git show <판>:<경로>` 는 Git Bash 에서 빈 출력으로 죽는다(기억 git-show-rev-path-dies-in-bash) — 파일로 받거나 python 으로 읽는다. 얕은 체크아웃에선 `git log -1 -- 파일` 이 HEAD 로 보인다.
- 라이브 시트 칸은 코드를 안 따라온다(`ensureSheet` 는 탭이 없을 때만 쓴다) — ②⑤⑧ 은 «코드에 있다»와 «라이브에 있다»를 갈라 적는다.
- 다른 세션의 미커밋 파일(`docs/_ops/심문기록.jsonl` · 마린·까몽 굽기 · 공방 자산 · 홍보영상 도구)은 건드리지도 커밋하지도 않는다. `git add -A`·`commit -a`·`clean` 금지.
- 결정 원장의 유호 확정 문장은 지우거나 고치지 않는다(정본 수리 1 은 근거 칸에 덧붙이기만).
- 셸 heredoc 으로 긴 한글 편집 스크립트를 넣으면 따옴표에서 죽을 수 있다(09-05 저녁 두 번) — 스크립트는 파일로 써서 `python3 파일` 로 돈다. `sed -i` 는 CRLF 를 LF 로 바꾼다 — python 으로 `newline=''` 읽고 쓴다.
- 유호님께 가는 답: 한 답에 주제 하나 · 두 목록을 한 답에 넣지 않는다(뒤 목록을 못 보신다) · 낯선 낱말은 그 자리에 뜻 · 결론 줄엔 기술 낱말 0.
