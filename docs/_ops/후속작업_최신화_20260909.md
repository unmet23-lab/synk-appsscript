# 후속 작업의 최신 원본 연결 — 2026-09-09

사용자 요청에 따라 Codex 훅을 공식 신뢰 승인하고, 두 저장소의 지침과 후속 자료 생성 경로를 보완했다. 최신 알림을 전달하는 것과 AI가 관련 원문을 읽고 결과에 반영하는 것은 구분한다. 현행 사용법은 [공통 운영 원칙](../AI_운영원칙.md#세션-사이-최신-상태) 하나에서 유지한다.

## 바꾼 범위

- `tools/session-freshness.js`: SYNK-appsscript·SYNK-talk와 두 저장소의 별도 작업 사본을 구분한다. 현재/정본 커밋과 양쪽 미커밋 변경·새 파일 수를 알린다. 로컬 기준 가지가 같아도 정본 작업본의 실제 커밋이 다르면 따로 표시한다.
- 작업본 지문은 파일 속성 변화 신호다. 실제 사용할 문서·이미지·PDF·음성·영상 등은 수동 `--files <상대경로>`로 내용 지문을 대조한다. 미커밋 원본의 변경과 신규 파일도 다루며, 시간·파일 수·크기 상한을 넘으면 미확인으로 표시한다.
- 자동 알림은 짧은 읽기 전용 관찰이다. 무관한 저장소는 제외하고, 조회 실패는 성공으로 위장하지 않는다. 명령 차단·자동 pull/stash/rebase·새 중앙 장부·상시 감시는 추가하지 않았다.
- Codex·Claude·Gemini의 개인/프로젝트 진입 지침을 회사 공통 원문으로 연결했다. 작업 시작·재개·중요한 수정 전에는 관련 원문을 실제로 읽고, 인계에는 사용한 원본·커밋·미커밋 원본의 내용 지문과 완료 증거를 남긴다.
- SYNK-talk 문서 7개를 477줄에서 211줄로 압축했다. 오래된 공용지침 사본, 고정된 모델 역할·발주 순서, 이미 허용된 행동의 재승인 요구를 정리하고 제품·동의·원본 음성·데이터 계약은 유지했다.
- 공용 트랙의 08-26 담당표와 자동 autostash/pull 지시를 현행 원칙으로 교체했다. 대체 완료된 옛 릴 45편·92개·보류 26화의 열린 지시는 보관 이력으로 압축했다. 실제 밤 일감이나 다른 담당의 작업은 새로 실행하지 않았다.
- `geminilm-export.js`·`이어하기꾸러미.js`와 회사별 자료 안내를 현행 원문으로 연결했다. 공유 사본에는 원본 내용 지문을 남기고, 생성기의 고정된 옛 역할 설명·개인 기억 일괄 반출·기존 폴더 전체 삭제를 제거했다. 제외된 식별정보·자격증명 원문이 제외 목록이나 로그로 재출력되는 경로도 제거했다.
- `rot-check.js`의 공유 자료 점검은 날짜나 파일 시각만으로 최신이라고 판정하지 않는다. 원본과 생성 파일의 내용 지문을 대조하며, 깨진 최신 생성본을 이전 정상본으로 감추지 않는다.

## Claude·Gemini 보완판 실제 검증 및 지침 압축

후속 사용자 요청에 따라 두 제품도 실제 실행으로 확인했다. Claude Code 2.1.261은 기존 claude.ai Max 인증을, Antigravity 1.1.27은 저장된 Google 로그인을 사용했다. 모델·계정 설정과 보호 절차를 바꾸지 않고 평소의 기본 선택으로 시험했다.

개인 지침 2개와 appsscript·talk 진입 지침 4개를 보완판으로 교체했다. 6개 합계 **91줄 → 59줄**, UTF-8 파일 크기 12,582 → 7,998바이트로 줄였다. 역할 설명·조사 규칙·재승인·인계의 중복은 공통 운영 원문으로 모았다. 독립 검토에서 제품·동의·철회·원본 음성·비밀 보호와 최신 원문 확인 계약이 유지됨을 확인했다.

시험 프롬프트에는 커밋 정답이나 변경 수를 주지 않았다. 파일·셸·웹·MCP 조회를 금지하고 이미 주입된 최신 상태 알림에서 값을 답하게 했다.

Claude는 실제 훅 이벤트와 응답을 함께 확인했다. Antigravity는 첫 호출에 주입된 내용의 정확한 답변으로 확인했으며 별도 훅 수명주기 이벤트가 출력됐다고 주장하지 않는다. 최초 Antigravity 계획 모드 시험은 대기 시간을 넘겼고, 공통 지침에 적힌 일반 비대화 형식으로 재실행해 두 폴더 모두 성공했다. 시간 초과의 원인을 계획 모드로 확정한 것은 아니다.

두 제품의 기존 최신 상태 알림은 현재 `tools/session-freshness.js` 하나와 두 저장소 경로를 가리킨다. 중복 알림·새 강제 관문을 추가하지 않았다. 이번 결과는 새 세션의 실제 전달 확인이며, 이미 진행 중인 세션의 문맥을 강제로 갈아끼운 것은 아니다. 그 세션은 새 요청·재개·중요한 수정 전에 현재 원문을 다시 읽는다.

- 기존 진행 작업 「까몽이 옷 굽기 확인」·「온라인 마케팅 구성 파악」·「밤굽기 일정 찾기」에 이번 원문 연결·재확인 지침을 전달했다. 수신한 모든 모델이 해당 문서를 끝까지 읽고 산출물까지 갱신했다는 검증과는 구분한다.

## 확인의 경계

이 변경은 후속 작업의 진입 지침·알림·자료 생성 경로를 갱신한 것이다. 이미 실행 중인 모든 대화의 문맥이 소급 교체되거나 모든 완성작이 자동 재제작되는 것은 아니다. 새 요청·재개 또는 중요한 수정 전에 현재 원문을 읽고 영향을 받는 부분을 갱신한다.

기존 작업 사본의 고유 커밋·미커밋, 승인된 자산, 제품 계약은 보존했다. 개인 기억은 읽어 반출하거나 갱신하지 않았다. 외부 노트북·웹 채팅의 계정별 자료가 전부 동기화됐다고 주장하지 않으며, 앱 배포나 SNS 게시를 수행한 것도 아니다.
