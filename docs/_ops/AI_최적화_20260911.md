## 적용 기준과 결론

## 수리한 구조

### 모델 선택과 실제 호출의 일치

- Codex 개인 설정: `forced_login_method = "chatgpt"` 추가, ChatGPT 로그인 확인. 최종 재조회에서 개인 모델이 Luna/medium으로 동시 변경돼 의도 확인 중이며 이를 Astra/Ultra 적용 완료로 보고하지 않는다. 자동화의 Astra/xhigh 정책은 별도로 유지한다.
- Claude 개인 설정: `model = claude-opus-5`, `effortLevel = xhigh`. Fable을 비대화형 기본으로 올리지 않는다. 이 모델은 포함 크레딧 외 추가 비용 가능성이 있고 현재 업무 품질 비교도 없다.
- Gemini 구독 호출기는 API-key 공급자나 G1 추가 크레딧 전환 설정을 거부한다. Claude 호출기는 구독 OAuth를 확인하고 API-key·Vertex·Bedrock을 제거하지만 계정 서버의 초과 크레딧 설정까지 증명하지는 못한다. Vertex/유료 API 실패를 구독 성공으로 보고하지 않는다.
- GPT 발주 실행자의 독립 검수 모델이 정책 이름뿐 아니라 실제 Claude Code 호출로 연결되도록 수정한다. 도구 실행·프로젝트 쓰기 권한 없이 대상 diff를 검수하며 자격·쿼터·모델 불일치·형식 오류는 확인 불가로 반환한다.
- Gemini는 HTTP 성공만으로 검수 성공이 되지 않는다. 모델 일치·정상 종료·최종 텍스트를 요구하고 내부 사고 블록·잘린 응답·빈 답변을 결과에서 제외한다.

### 비용과 계정

- 로컬 Gemini 검수·설계심문은 구독, 로컬 몽골어검문·eval·일반 API 및 GitHub 예약 평가는 무료 API 기본, Vertex는 명시 선택이다. `--유료-api`는 실제 종량제/크레딧 경로를 의식적으로 선택하는 표시이며 새 결제를 실행하는 명령이 아니다.
- Vertex 자격 파일 누락 시 clasp의 옛 유료 계정으로 넘어가던 경로와 전계정 공용 토큰 캐시를 정리한다. 계정·프로젝트를 명시하고 자격별 캐시를 사용한다.
- `구글크레딧.js`의 토큰 총량×이미지 단가 계산은 실제 청구액이 아니다. 모델별 사용량과 결제 잔액을 분리하고 확인하지 못한 비용/잔액은 미확인으로 표시한다.
- Google 무료 체험판은 Gemini AI Studio나 Claude 파트너 모델 비용에 사용할 수 없다. Google Cloud 무료 체험판·일반 유료 계정은 서로 다른 상태다.
- Claude Code 구독 OAuth와 Anthropic Console 제품 API는 다른 과금 통로다. API 잔액 부족을 구독 호출로 몰래 우회하지 않는다.

### 교정 품질과 재현성

- 과거 교정 프롬프트 파일에는 현재 지시와 수정 이력이 함께 있었다. 현재 지시만 요청에 보내고 이력은 파일에 보존한다.
- 현재 지시, JSON schema, 요청 계약이 바뀌면 `v7-q1-<요청 지문>`이 바뀌도록 연결한다. 같은 `v7` 이름으로 서로 다른 요청을 같은 실험으로 비교하지 않는다.
- 교정 요청 버전만 바꾸며 생성에서 쓰는 기존 `vN` 버전 추출 계약을 유지한다.
- correct/companion/teach/deliver/deliver-one의 CJS 동봉 관계를 대조한다. 코드 수정·동봉·배포·실제 API 교정 성공은 별도 상태다.

### CI와 자산

- 원격 CI의 계정 컬렉션 시험은 소개서 원본이 바뀐 뒤 파생 이미지/출처 지문이 낡아 실패했다. synk-design의 현재 승인 원본 우선 규칙에 따라 기존 로고갱신 생성기로 파생 자산을 다시 만들었으며, 디자인을 새로 생성하지 않았다.
- 바뀐 범위는 계정별콘텐츠 폴더의 파생 이미지 3개와 지문 기록 2개다. 해당 시험 8/8 통과. 인쇄물/외부 게시본까지 새로 전달했다고 주장하지 않는다.
- clasp 경고 정책과 옛 차단 시험의 충돌은 현재 코드에서 이미 해결된 상태여서 재수리하지 않는다. 기존 검토 경로와 몽골어 점검의 현행 원문 여부는 별도 검사 결과로 확인한다.

## 실제 남은 제약

- 확인 가능한 Anthropic Console 계정의 잔액 부족으로 제품 API 재가동/동일 모델 전량 평가는 막혀 있다. 새 충전·키 발급/교체는 임의 처리하지 않는다.
- Apps Script의 기존 Claude 키는 결제 조직 소유를 확인하지 못했다. 다른 계정의 잔액을 이 키의 잔액으로 간주하지 않는다.
- Claude Code와 현재 Chrome Claude 화면의 로그인 조직이 달랐다. 브라우저 한 계정의 추가 사용 꺼짐을 CLI 계정의 설정으로 확대하지 않는다. API-key 자동 전환 차단과 계정의 초과 크레딧 설정 확인은 별도다.
- 로컬 무료 Gemini 키 프로브는 429 한도 응답이다. 스택 점검의 적색 5줄은 이 한 건의 설명이며 결함 5개가 아니다. [GitHub 몽골어 최근 run](https://github.com/unmet23-lab/synk-appsscript/actions/runs/34480176844)은 기존 평가를 재사용해 실제 호출 0건으로 성공했다. 원격 시크릿의 새 호출 성공이나 실패는 별도 미확인이며, 로컬 구독·Vertex 성공으로 대신하지 않는다.
- 모델 정책의 고유 역할 36개 중 가동 표기 28·미배선 8이다. 가동에는 수동 호출·역할 배정도 포함돼 자동 완주율이 아니다. 미배선은 과제글·되돌림말·채점분류·오류태깅·발음채점·성향뽑기·삶이해·일기맞장구의 제품 소비자/데이터 계약 영역이며, 크레딧 연결만으로 구현됐다고 표시하지 않는다.
- Apps Script Google STT 코드 존재는 가동/청구 증거가 아니다. 현재 전용 서비스계정 속성이 없으며 실제 음성·confidence 계약 검증 없이 새 모델로 교체하지 않는다.
- 정확도·지연의 절대 최고는 아직 증명되지 않았다. 이번 구성은 확인된 성능을 유지하면서 발견된 호출·형식·격리·과금 경계 결함을 제거하는 선택이다.
