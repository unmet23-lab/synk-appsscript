## 1. 철학이 준 판정 렌즈 (우선순위 순)

1. **하지 않는 것 넷** — 걸리면 즉시 기각·수정. ㉠실물 없이 말 먼저 ✗ · ㉡사람 손 늘리는 해법 ✗ · ㉢학생끼리 비교 ✗ · ㉣식별 데이터 외부 ✗
2. **A-1 읽는 법 ①** — 새 기능은 **가장 비어 있는 칸부터**. 지금 그 칸 = **㉡ 사람 이해**
3. **A-1 읽는 법 ②** — 「돈다」 초록인데 **「엔진에 닿는가」 빨강**인 칸이 가장 위험(다 된 것처럼 보이는데 미완성)
4. **㉢ 삶 = 소급 불가** — 첫 시즌 답은 그날에만 존재한다. **깃발이지 배경이 아니다**
5. **Ⅰ-8 재료가 곧 철학** — 효율 눈금은 유예. 지금 유일한 눈금은 **재료의 급**(BGM·햅틱·여백까지)
6. **3층 게이트 적용 대상** — 학생·학부모가 닿는 것 = ①②③ 전부 / **배관 = ③만**
7. **Ⅰ-4 관찰/판정 분리** — 관찰·수집 = 시스템 / 판정·의미부여 = 사람(강사). 강사 입력이 남아 있으면 그것은 **임시 다리**이고 배선이 서면 걷어낸다
