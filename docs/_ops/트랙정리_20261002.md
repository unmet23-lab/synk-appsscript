## 여러 묶음에서 공통으로 나온 것

1. **원본이 git 밖에 있다** — 공개 게임 7종 중 6종, `desktop/`, SNS 키트, 계정·플랫폼 설계 원문, 사내 메신저, 오프라인 설계 등. 트랙 자체도 항목 대부분이 커밋된 적이 없었다. → 새 트랙 §2 첫 줄.

4. **같은 일이 여러 벌** — 개인정보 처리방침(PW6·`/privacy/`·브라질 동의·측정), 실기기 확인(30곳 남짓), 교원 검수, SNS 게시 승인, SNS 측정 도구 둘. 각각 한 줄로 합쳤다.
5. **옛 계획에 묶인 일** — 1기 온라인 과정, 학원 운영 시스템, Glide, Orca, 옛 SNS 양식, 옛 게임 G1~G4, 두 나라 달력 같은 전제는 뒤 결정이 대체해 지웠다.
6. **주인 없는 git 잠금** — 정리 중에도 `.git/index.lock`이 여러 번 남아 커밋을 막았다. → §2.
