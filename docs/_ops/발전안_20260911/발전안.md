### Apps Script 운영 반영

GAS는 main의 검증된 커밋 `cc2aabba07589a783c95e358fa1276239e82e227`에서 추출한 루트 **21개 JavaScript + appsscript.json 1개**를 배포했다. 통합 커밋 `21af9b13b80129ff9f954c00f6e6809606190ab9`과 이 22개 원문은 모두 같다. 이후 다른 담당이 커밋한 `상담AI.js`·`만족도팩.js` 변경은 이번 배포에서 제외했다. main 작업본 전체가 라이브와 같다고 주장하지 않는다.

별도 `.clasp.json`과 `.claspignore`를 지정한 기존 clasp를 main cwd에서 실행해 정확히 이 22개만 push하고 기존 배포 ID를 **@47**로 갱신했다. 새 배포 ID는 만들지 않았다. 지문은 **`#fp:24ea8f30`**이다. 프로젝트 HEAD와 고정 @47을 각각 다시 읽은 결과는 모두 **22/22 원문 바이트 동일 · 다름 0 · 누락 0 · 표기차이 0**, 검사 종료 0이다.

기존 main 설정·원본·다른 담당의 변경을 보존했다. main `tmp/engine-integration-20260911/` 아래의 `gas-release-manifest.json`·`gas-release-clasp-status.json`·`gas-release-clasp-collection.json`에 출처, 파일별 SHA-256, 실제 선택 파일과 업로드 순서 증거를 남겼다. 이전 작업본 지문 `dfd6eb05`와의 차이는 LF/CRLF이며 같은 파일 내용으로 이전 값을 재현했다.

실제 운영의 **`오류사전_OFF=1` 저장을 완료**했다. 이 설정은 오류사전 갈래의 후속 실행을 중지하는 것이며, 기존 오류 자산 삭제·Prism 소비자 구현·이미 발생한 비용 환급을 뜻하지 않는다. 실제 절감액은 별도 지출 조회 전까지 미확인이다.

### 실제 화면과 APK

초기 합성 브라우저에서 `리듬:여유제출` 카드 → ‘아니에요’ → 감사 반응 → 서버의 `집중띠:주로새벽` 카드 → 같은 화면 재진입 후 여유제출 재노출 없음을 확인했다. 합성 서버의 수신 순서는 `progress → estimate.received → progress`였다. 실제 교수멘탈화면·게임큐·조회 어댑터를 사용했지만 원격 DB·실기기·실학생 사용을 한 번에 검증한 것으로 세지 않는다.

후속 UI는 유호가 선택한 「색과 캐릭터가 살아 있는 스튜디오」로 완성하고 마린의 여분 팔을 고쳤다. 사용자가 만족을 확인한 **1672×941** 장면을 유지하며 4K 원본으로 표기하지 않는다. 로컬 미리보기, 관련 13파일 113/113, 작은 화면과 넓은 화면, 작성→전송→편지 복원, 부정 카드 제외를 확인했다. 승인과 실제 자산·해상도·시험 범위의 상세는 Talk `docs/교수멘탈_UI_20260911.md`에 있다.

Android **[preview APK 빌드 `e8014e62`](https://expo.dev/accounts/unmet23s-team/projects/synk-talk/builds/e8014e62-b567-46bb-8662-3e5fd8f33103)는 무료 대기열에서 대기 중**이다. 같은 작업의 후속 자동화 `synk`가 10분 간격으로 완료·실패를 확인하고, 완료 시 실제 설치 링크와 결과를 인수한다. 중복 빌드나 유료 전환은 하지 않는다. 빌드 신청을 APK 완성·배포 링크 확보·실기기 검증으로 세지 않는다. 학생 G1 진입은 계속 `검수확정=false`다.

## 5. 완료와 별도로 유지하는 경계

- **c17:** 실행 계약은 c16이다. 예약 블록만 준비했으며 새 사건·물리 열·생산자·소비자·동의·최소 기록 경로의 c17 완성은 별도다. 첫 실제 입력 전에 필요한 소급 불가 규격을 준비한다.
- **운영 생성과 G1:** 운영 생성 경로를 임의로 활성화하지 않았다. `gen_active_from`의 리허설 임시 게이트는 청소했고, 학생 G1의 `검수확정=false`도 유지한다. G1 팩의 몽골어 번역·문화 적합성 감수와 `g1문항.v2` 문항판 확정이 남아 있다. 관련 코드 배포가 이 게이트들의 개방을 뜻하지 않는다.
- **실학생·효과:** 합성 회귀·서버 원문 일치·로컬 UI 확인은 실제 발송·열람·학습 효과 건수가 아니다. APK 설치 후 실기기 확인과 실제 학생 효과는 미확인이다.
- **Prism·궤적:** 오류사전 OFF의 운영 적용을 소비자 구현 완료로 세지 않는다. 궤적의 자산층 분류와 실제 소비 범위를 유지하며 검사 숫자를 위해 부재를 숨기지 않는다.
- **철학·회고:** ‘세 힘’·‘자 넷’은 담당 설계의 기준으로 읽으며 전사 수집 의무로 복원하지 않는다. 몽골어 회고 문안의 감수와 과거 소실 기록 복구는 이번 코드 시험으로 대체하지 않는다.
- **UI·BGM:** 특정 UI 결과에 대한 사용자의 만족을 모든 작업의 해상도·배치 고정 규칙으로 넓히지 않는다. BGM이 필요한 때는 AI가 기존 보유 곡에서 고르고 유호가 추가하는 Suno 곡도 후보로 삼는다. 현재 G1 읽기·쓰기 화면은 무음이다. 담당 기준은 `docs/음악자산_장부.md`다.
