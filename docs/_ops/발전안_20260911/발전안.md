엔진 보완 코드는 발전안 가지에 있고 master 병합·운영 배포는 수행하지 않았다. 이 결과 문서와 v3 본문 현행화는 main 작업본의 문서 변경이며, main의 다른 미커밋·스테이징을 보존한다. main은 원격과 갈라져 있어 이 문서 마무리에서 rebase·강제 push·일반 push를 하지 않는다.

이후 master 통합 때는 두 저장소의 현재 변경을 다시 대조한다. `계약동기화.js`의 방향은 **appsscript → talk**이며, c17 예약 블록을 포함한 원천을 먼저 준비해야 한다. 이미 확인한 발전안 두 사본의 일치를 main 통합 완료로 해석하지 않는다.

PowerShell에서 임시 환경변수는 `$env:SUPABASE_PROJECT_REF` 형식으로 지정한다. POSIX 셸의 `NAME=value command`를 Windows 명령으로 그대로 붙여 넣지 않는다. 인증값은 출력·문서·커밋에 넣지 않는다.
