## 과거 원본이 필요한 경우

삭제 전 기준 커밋은 **a02539a2b930492b1cc57c21cca105d774ce8102**다. 삭제한 추적 문서는 그 판에서 찾을 수 있다. 현재 폴더 안에 옛 정본 사본을 다시 쌓지 않는다.

```text
git show a02539a2b930492b1cc57c21cca105d774ce8102:docs/예전문서.md
```

위 경로는 예시이며 실제 삭제 경로는 이번 커밋의 삭제 목록을 따른다. 과거 판단의 증거를 인용하던 링크는 해당 고정판으로 연결해 현재 문서가 과거 검토를 받은 것처럼 바꾸지 않았다.

시작 시 저장 공간 부족으로 원자적 저장이 중단되었다가 여유 확보 후 재개했다. 임시 빌드 폴더와 일괄 셸 삭제는 자동 승인 검토에서 차단되었으며, 구문서 삭제는 파일별 경로가 명시된 변경안으로 승인 검토를 거쳐 수행했다. 차단된 임시 빌드 폴더 삭제가 실행됐다고 보고하지 않는다.

## 후속 — 지식 조회와 작업본 위생 (2026-09-10)

사용자 요청은 현재 지식관리·작업본 위생의 부족분 보완이다. 기준은 현재 `AI_운영원칙.md`의 원문 한 곳·필요한 절만 조회·진행 작업 보존 원칙이며, 새 강제 훅·중앙 큐·개인 기억 갱신은 하지 않는다.

### 실제 반영

- `tools/문서상태.js`: 옛 이모지 상태뿐 아니라 머리의 현행 기준·현행 진입점·정본 선언·초안 문구를 분리 조회한다. `--찾기`는 파일명·절 제목, `--목차`는 원문 줄 위치를 반환한다. 미표기·현행·커밋을 사용자 확정으로 바꾸지 않는다.
- `tools/doc-graph.js`: Git 제외 규칙을 존중하고 읽기 실패를 공개한다. 일반 링크, 명시 파생, 단순 이름 언급의 쌍 수·문서 수를 분리했다. 미추적 작업 문서의 색인 누락은 추적 문서와 별도다. 큰 자체 포함 HTML의 이미지 데이터는 검색 사본에서만 제외한다.
- `tools/session-freshness.js`: 512KiB로 제한돼 대량 파일 목록을 읽지 못하던 상태 조회를 16MiB로 확장했다. 수동 `--timeout-ms`만 최대 30초이며 자동 알림의 1.7초 상한은 유지한다. 2,048개 초과 작업본은 개수 조회와 전체 지문 미확인을 구분한다.
- `tools/worktree-hygiene.js`: NUL 구분 Git 목록으로 한글·공백·이름 변경을 정확히 세고 폴더·유형별로 집계한다. 브라우저 프로필 경로는 가리고 조사 후보로만 표시한다. 파일 내용 읽기·이동·삭제 기능은 없다.
- `.gitignore`: 첫 게시물 검토의 두 `render-temp` 위치에서 확인된 Puppeteer 프로필 3폴더·689파일만 추적 후보에서 제외했다. Chromium 상태·기본 프로필 존재를 확인하고 해당 경로의 추적 파일 0개를 확인했다. 원본·렌더 결과는 보존하며 다른 미추적 자료·미확정 런타임 후보를 일괄로 숨기지 않는다. 삭제·공간 회수는 하지 않았다.
- 실제 낡은 인용 1건은 생명감 v1.4 §1-a와 말할 순간 표의 범위를 대조해 수정했다. 발화 조건·그림 자산·기존 전량 검수 상태는 바꾸지 않았다. 새로 추적된 법률지원 질문은 상세 색인에서 상담 준비 자료로 연결했다.
