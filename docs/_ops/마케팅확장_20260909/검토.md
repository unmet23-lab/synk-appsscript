# 마케팅 확장 — 공식 기능 조사와 독립 검토

> 확인일: 2026-09-09 · 독립 검토자: Codex research_gate. 이 문서는 전략 정본이 아니라 원문 대조와 forge 판정 기록이다.
> 사용자 최신 결정: SHIFT의 메인은 1인 기업 브랜딩과 강의. 홍보 릴스는 유지하며 공개 콘텐츠 자체의 실용 가치와 끝의 관련 자료·팁을 함께 설계한다. 제작 속도·자산 수를 전략의 제약으로 삼지 않는다.
> 공식 문서를 검색한 뒤 본문을 열어 확인했다. 실제 SYNK 계정의 기능 활성화, 발행·가입·결제·자료 배포는 실행하거나 확인하지 않았다. 아래 적용 방향은 내부 편집 제안이며 효과·수익 보장이 아니다.

## 1. 실제 활용할 기능 6묶음

### 1-1. Shorts에서 같은 채널의 본편으로 이어 주기

- **공식 확인:** 관련 영상은 자기 채널에서 선택하며 공개 또는 일부 공개여야 한다. 채널의 고급 기능 접근이 필요하다. 시청자에게 채널 핸들 아래 클릭 가능한 연결이 표시된다. [YouTube — Add a related video](https://support.google.com/youtube/answer/14075157?hl=en)
- **연결 경로의 차이:** Shorts 설명·댓글에 쓴 일반 URL은 클릭되지 않는다. 채널 프로필 링크와 Shorts 관련 영상 링크는 클릭 가능하다. 롱폼 설명·댓글의 클릭형 외부 링크도 고급 기능 접근 조건이 있다. [YouTube — Sharing links](https://support.google.com/youtube/answer/13748639?hl=en)
- **SYNK 적용 해석:** `yuhobuilds` Shorts는 `yuhobuilds` 본편, `synkbrief` Shorts는 `synkbrief` 사용법 영상으로 연결할 수 있다. `synkbrief`의 관련 영상 기능으로 다른 채널 `yuhobuilds` 본편에 바로 연결한다고 쓰면 사실 오류다. 공개 자료는 실제 채널 프로필의 자료실 경로를 별도로 안내한다. 짧은 영상 안에도 독립적으로 쓸 팁을 남긴다.
- **미확인:** 두 실제 채널의 고급 기능 활성화, 설정된 프로필 링크, 공개 자료 URL의 현재 접근성. 이 확인 전에는 ‘지금 아래 링크를 누르면 받는다’는 완료형 안내를 쓰지 않는다.

### 1-2. 롱폼의 마지막을 관련 수업·자료로 마무리하기

- **공식 확인:** 엔드스크린은 영상의 마지막 5~20초에 넣고 영상 길이는 최소 25초여야 한다. 영상·플레이리스트 등을 연결할 수 있다. 외부 웹사이트 연결 요소는 YouTube 파트너 프로그램 참여 조건이 있다. 아동용으로 설정된 영상에는 사용할 수 없으며 시청 환경 등에 따라 항상 보이지는 않는다. [YouTube — Add end screens](https://support.google.com/youtube/answer/6388789?hl=en)
- **SYNK 적용 해석:** 본편 끝은 ‘이번에 배운 것을 자기 일에 바꿔 볼 질문 → 관련 공개 자료 → 다음 수업’으로 편집한다. 실제 엔드스크린은 다음 관련 수업·플레이리스트를 맡고 자료실은 확인된 프로필 또는 롱폼 설명 경로를 쓴다. 인터랙티브 요소가 안 보이더라도 화면·발화의 짧은 팁은 남는다.
- **미확인:** 실제 채널의 파트너 프로그램 참여와 영상별 시청자 설정. 외부 다운로드 버튼을 모든 채널에서 쓸 수 있다고 약속하지 않는다. 이는 교육 영상 제작을 미루는 이유가 아니다.

### 1-3. 검색으로 다시 찾는 공개 수업과 순서 있는 수업 목록

- **공식 확인:** YouTube 검색은 검색어와 영상의 관련성, 참여, 품질 등을 본다. 제목·설명·영상 내용의 문제 일치를 점검할 근거이지 검색 상단이나 장기 조회를 보장하는 공식이 아니다. 누구나 일반 플레이리스트를 만들고 공유할 수 있다. [YouTube — Search and discovery](https://support.google.com/youtube/answer/9962575?hl=en), [YouTube — Create and manage playlists](https://support.google.com/youtube/answer/57792?hl=en)
- **Courses의 별도 조건:** 고급 기능 접근이 있는 적격 제작자에게 제공한다. 데스크톱 Studio에서 만들고 관리한다. 실제로 가르치는 비연령제한 영상 3개 이상이 필요하며 반복 영상이나 다른 채널 영상을 포함할 수 없다. 기존 플레이리스트를 Course로 바꿀 수도 있다. [YouTube — Create a Course](https://support.google.com/youtube/answer/15128409?hl=en)
- **자료 첨부 조건:** Course PDF는 영상당 최대 5개이며 채널과 같은 이메일 계정의 Google Drive 파일을 링크가 있는 사람에게 공개해야 한다. 공개 전 파일 내용과 공유 범위를 점검해야 하며 학생 원문·개인정보를 첨부하는 통로가 아니다. 위 Course 도움말의 Resources 절을 확인했다.
- **SYNK 적용 해석:** SHIFT는 ‘소개 문장 → 제안 → 강의 실습 → 납품·인수’처럼 실제 일을 완성하는 공개 수업을 검색 가능한 정확한 제목과 순서로 묶는다. Courses 버튼의 실제 사용 가능 여부와 별개로 일반 플레이리스트와 자료실로 같은 학습 순서를 제공할 수 있다. LAB 수업 묶음과 PULSE 감상 목록은 목적을 분리한다. 공개 강의 목록을 공인 교육·자격·수료 보장으로 표현하지 않는다.

### 1-4. Instagram의 새 형식 시험과 실제 공동 제작

- **Trial Reels 공식 확인:** 비팔로워에게 먼저 보여 주고 모두에게 공유하기 전에는 기본 프로필 그리드·Reels 탭에 나타나지 않는 방식이다. 그러나 공유 DM이나 같은 오디오·위치·필터 경로 등으로 팔로워가 볼 수도 있으므로 비공개 검토실이 아니다. 전체 공개 자동 전환은 선택 설정이다. [Meta — Trial Reels](https://about.fb.com/news/2024/12/trial-reels-try-content-non-followers-first-see-what-perfoms-best/)
- **가용 범위의 날짜:** 2025-06-12 발표에서 모든 사람에게 제공했다고 안내했다. 이 발표는 2025-06-26 수정 표기가 있다. 현재 도움말의 세부 적격 조건은 읽기 도구 오류로 확인하지 못했고 실제 계정의 Trial 스위치도 미확인이다. 따라서 ‘우리 계정에서 지금 사용 가능’으로 확정하지 않는다. [Meta — Inspiring Creativity](https://about.fb.com/news/2025/06/inspiring-creativity-that-brings-people-together/)
- **Collabs 공식 확인:** 피드 글·캐러셀·Reel의 공동 작성 초대를 상대가 수락하면 공동 계정에 나타난다. 비공개 계정에서 초대할 때에는 상대의 맞팔로우 조건을 설명한다. 2023 발표의 초대 가능 인원 수를 2026 현재 상한으로 재사용하지 않는다. [Meta — Music and Collabs](https://about.fb.com/news/2023/08/music-and-collabs-on-instagram/)
- **SYNK 적용 해석:** 홍보 릴스의 실물 장면·도입·팁 끝맺음을 Trial로 시험하되 성과 보장이나 무작위 실험이라고 부르지 않는다. 공동 제작은 실제 합의한 성인 전문직과 공개용 허구 예시 하나를 함께 고치는 방식으로 검토한다. 학생에게 공개 계정 전환·친구 태그·공동 게시를 자료 제공 조건으로 요구하지 않는다. 계정별 역할을 무시한 전사 동시 재게시가 목적이 아니다.

### 1-5. 웹 자료실과 선택형 후속 뉴스레터

- **Substack 공식 확인:** 글을 웹에만 게시하거나 이메일·앱으로 함께 보낼 수 있다. 기본 게시 동작에 이메일·앱 발송이 포함되므로 웹 전용이면 해당 발송 옵션을 해제해야 한다. 독자 범위도 선택한다. [Substack — Publish a new post](https://support.substack.com/hc/en-us/articles/360037831771-How-do-I-publish-a-new-post-on-Substack)
- **탐색 기능:** 내비게이션에 내부·외부 링크를 추가할 수 있고 기본 Archive 외에 사용자 페이지·태그를 연결할 수 있다. [Substack — Organize the navigation bar](https://support.substack.com/hc/en-us/articles/20512194655892-How-do-I-organize-the-navigation-bar-on-my-Substack-publication)
- **SYNK 적용 해석:** 실제 자사 자료실을 공개 원본의 주소로 두고 업무별 찾기·채운 예시·수정 원본·사용법·개정일을 묶는다. 뉴스레터는 관심 업무의 사용 예외와 개정 이유를 다시 받으려는 사람만 선택한다. 기본 실용 가치를 이메일 제출 뒤에 숨기지 않는다. LAB와 창업 갈래의 동의·관심사를 섞지 않는다.
- **미확인:** 현재 자사 공개 자료실의 실제 메뉴·파일·접근성, Substack 계정 활성화·발송 설정·구독 동의 상태. 이번 작업에서 계정 개설·테스트 발송·발행을 하지 않았다. 이 절은 실제 서비스 운영 보고가 아니다.

### 1-6. 청소년 보호 기능을 존중하는 LAB의 다음 행동

- **Meta 공식 확인:** Instagram Teen Accounts는 비공개·엄격한 메시지 수신·태그 등의 기본 보호 설정을 적용한다. 16세 미만이 덜 엄격하게 바꾸려면 보호자 허용이 필요하다. 공식 문서는 2025-06-11 전 세계 적용을 알렸다. [Meta — Instagram Teen Accounts](https://about.fb.com/news/2024/09/instagram-teen-accounts/amp/)
- **현행 확대 확인:** 2026-04-09 발표는 13+ 콘텐츠 등급 기준과 Limited Content 설정의 국제 확대를 설명하며 2026-05-15 수정 표기가 있다. 보호 설정이 모든 유해 콘텐츠를 완전히 차단한다는 뜻은 아니다. [Meta — Teen Accounts 13+ expansion](https://about.fb.com/news/2026/04/instagram-expands-teen-accounts-inspired-by-13-content-ratings/)
- **YouTube 분류 구분:** ‘10대 대상’이라는 말만으로 모든 LAB 영상을 아동용으로 일괄 분류하지 않는다. YouTube는 청소년 이상을 의도한 일반 시청자 콘텐츠와 아동 지향 콘텐츠를 구별하며 실제 의도·주제·표현을 종합하라고 안내한다. 이 문서는 법률 자문이나 개별 영상의 시청자 설정 판정이 아니다. [YouTube — Determining made for kids](https://support.google.com/youtube/answer/9528076?hl=en)
- **SYNK 자체 보호 원칙:** 학생용 기본 CTA는 읽기·저장·복사·혼자 연습하기로 가치가 끝난다. DM을 열거나 공개 계정으로 바꾸게 하지 않는다. 이름·학교·현위치·연락처·비자·가족 사연·얼굴·목소리 증명을 공개 댓글에 받지 않는다. 학교 수업 참여와 마케팅 동의를 구분한다. 실학생 사례는 현행 마케팅 정본의 비식별·적정 서면 동의/철회·학습과 홍보의 두 층 분리 및 위유호 판정 조건을 따른다. 보호자용 확인 자료·상담 입구는 학생 연습과 분리한다.
- 이 CTA 방향은 내부 안전 설계의 판단이다. Meta나 YouTube가 ‘기본 자료는 무조건 무료여야 한다’고 규정했다는 인용이 아니다. 몽골 법률상 모든 의무를 검토 완료했다는 뜻도 아니다.

## 2. 출처 대장과 읽은 범위

모두 2026-09-09에 공식 1차 출처를 검색한 뒤 원문 본문을 열어 확인했다. 웹 도구의 수집 날짜를 문서 발행일로 바꾸어 쓰지 않았다. ‘표시 없음’은 본문에서 발행·개정 날짜를 특정하지 못했다는 뜻이다. 성과·수익 통계는 채택하지 않았다.

### 4-2. 합격과 별도로 남긴 작은 문구 권고

1. 통합안 **39행**의 네이버 ‘계정 미개설’은 이번 실계정 감사가 없으므로 ‘개설 기록·현재 상태 미확인’으로 적으면 부재를 현재 사실로 단정할 여지를 줄인다. 신규 후보의 가안 상태는 이미 3·14행과 §3에서 구별되어 있어 기각 사유로 세지 않았다.
2. 통합안 **94행**에 ‘기본 자료는 댓글·팔로우·이메일 제출 없이 열고, 후속 구독은 별도 선택’이라는 문장을 보태면 A86/B59·74의 무조건 기본 제공 원칙이 더 명확하다. 현재 글도 가입을 필수로 요구하지 않고 83행에서 자료실 직접 진입을 허용하므로 기각이 아닌 명확화 권고다.

최종 원고의 내부 상대경로 링크는 존재 여부를 읽기 전용으로 점검했다. 링크가 가리키는 문서의 존재와 실제 공개 사이트에서 자료가 열리는 것은 별개이며, 계정의 클릭 동선·라이브 스트림·자료 다운로드 실사는 이번에 하지 않았다. 최종안에서 le19M의 미열람 행사 내용을 별도 사실 주장으로 채택하지 않아 §3-2의 독립 열람 한계가 최종 본문의 근거 공백으로 이어지지 않았다.
