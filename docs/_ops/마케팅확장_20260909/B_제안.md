# forge B — 공개 제작실에서 내 사업의 한 부분을 가져간다

> 2026-09-09 · 독립 기획 제안. A안 미열람. 원래 소개서·계정별 콘텐츠·코드는 수정하지 않는다.
> 최신 사용자 결정: SHIFT의 메인은 **1인 기업 브랜딩과 강의**. 기존 홍보릴스는 유지하고 실용 콘텐츠·관련 자료·체험을 더한다.
> 아래 형식·편성·타겟 세부는 추천안이며 운영·고객 반응·서비스 출시 완료 보고가 아니다. 제작 속도와 자산 준비량은 병목으로 두지 않았다.

## 1. B의 결론 — 노하우를 구경한 뒤, 자기 사업이 조금 달라져야 한다

SHIFT의 공개 콘텐츠를 **시청자의 작은 작업이 끝나는 공개 제작실**로 만든다. 유호의 결과물은 자랑의 종착점이 아니라, 관객이 자기 것을 만드는 출발 재료다.
내부 포지셔닝은 ‘혼자 일하는 사람이 자기 일의 가치를 설명하고, 보여주고, 다른 사람에게 가르칠 수 있게 돕는 곳’. 새 공식 슬로건은 아니다.
본편마다 **실제로 만든 예시 / 내가 채울 원본 / 달라진 조건에서 고치는 법**을 한 세트로 건넨다. 보기 좋은 PDF만 쌓이는 정보 채널과 여기서 갈린다.
가령 ‘로고 만드는 법’에서 끝내지 않고, 그 로고가 들어갈 소개 첫 화면과 실제 고객이 확인할 증거를 함께 맞춘다. 모든 문제를 디자인 문제로 오진하지 않는다.
긴 제작 기록도 유지한다. 다만 관객은 유호를 따라 하기만 하는 사람이 아니라, 다른 상황에서 다른 결정을 내릴 수 있는 동료다.

## 2. 무엇이 확정이고 무엇이 가정인가

- 확정: 메인 사업 설명은 1인 기업 브랜딩과 강의로 옮긴다. 공개 콘텐츠에서도 실제 필요한 도움을 먼저 준다.
- 유지: 유학·AI 강사 에이전시·대학 알선/협력·기관 교육의 사업 범위와 장기 연구는 지우지 않는다. 메인 피드의 매회 주인공에서 내려 관련 자료의 별도 입구로 둔다.
- 추천가정: 첫 시험 상대는 **한국어로 일하는 한국 성인 지식·서비스형 1인 기업자**다. 현재 고객 구성이나 사용자 확정 국적이 아니다.
- 이유: 자기 전문 설명, 작업 견본, 제안·인수, 강의화라는 과제가 현재 SYNK의 공개 가능한 실물과 직접 만난다. 시장 규모·지불 의향을 확인했다는 뜻은 아니다.
- 아직 모름: 창업 전/운영 중 어느 쪽이 더 절실한지, 맡기기/배우기 중 무엇을 원하는지, 어떤 조건의 강의를 선택하는지. 실제 대화와 자료 사용 관찰로 수정한다.
- 첫 시험에서 분리: 매장형 자영업·재고 판매·투자·세무·법무. 전문성과 거래 구조가 달라 지식·서비스형의 해법을 그대로 일반화하지 않는다.

## 3. 사람을 나이보다 ‘지금 바꾸고 싶은 장면’으로 나눈다

| 타겟 기둥·상황 가설 | 당사자가 원하는 변화 | 먼저 손에 남길 것 | 본편이 다룰 판단 |
|---|---|---|---|
| 첫 소개: 하는 일은 있는데 한마디로 설명이 길어짐 | 고객이 자신과 관련 있는 일인지 알 수 있음 | 대상·필요한 순간·받는 결과를 담은 소개 첫 화면 | 누구에게 필요한지부터 바꿀까, 결과를 보여줄까 |
| 첫 증거: 경력·작품이 있어도 무엇을 믿어야 할지 흐림 | 허세 없이 맡길 이유를 보여줌 | 목적·선택·확인 범위를 붙인 사례 한 장 | 실적이 없는 자리에는 무엇을 예시로 보여줄까 |
| 첫 거래: 문의를 받았는데 서로 다른 결과를 생각함 | 사용처·범위를 함께 이해한 대화 | 요청 전 확인표와 인수 안내 견본 | 더 묻고 시작할 것과 맡지 않는 것을 어떻게 나눌까 |
| 첫 강의: 할 줄은 알지만 남이 따라 하기 어려움 | 초보자도 자기 결과물을 완성함 | 시작 재료·완성 예시·검사 기준이 있는 짧은 실습 | 설명을 더할까, 입력 재료와 연습 순서를 바꿀까 |
| 지속 운영: 채널마다 다르고 매번 처음부터 설명함 | 같은 기준으로 다음 일을 이어감 | 상황별 사용법·편집 원본·변경 이유가 남는 작은 묶음 | 반복해야 할 기준과 이번만 달라질 표현은 무엇인가 |

각 기둥은 같은 사람이 이동하는 상태다. ‘AI 초보=사업 초보’로 묶거나 수입·심리 상태를 추정해 사람을 분류하지 않는다.
브랜딩 기둥과 강의 기둥은 따로 놀지 않는다. **내 일의 가치가 읽히는 결과물을 만들기 → 다른 사람도 해볼 수 있게 설명하기**로 이어진다.

## 4. 네 형식을 하나의 회차로 묶는다

| 형식 가칭 | 화면에서 일어날 일 | 독자가 가져갈 결과 | 평범한 팁 영상과 다른 점 |
|---|---|---|---|
| 공개 제작실 | 완성물 → 요구 하나 → 실제 선택 두 가지 → 선택한 이유 → 직접 확인 | 같은 기준으로 자기 것을 고치는 작업지 | 도구 조작보다 결정이 보이며, 안 고른 안도 조건에 따라 쓸 수 있음을 설명 |
| 사업 한 칸 | 소개·증거·요청·인수 중 한 칸을 독자가 직접 채움 | 빈 양식이 아니라 자기 문장/선택이 들어간 한 칸 | 작은 완료 자체가 가치. 다음 편·결제 없이도 한 칸은 끝남 |
| 상황별 클리닉 | 같은 자료를 처음 보는 고객/이미 아는 고객에 놓고 한 부분만 바꿈 | 내 상황에 맞는 수정 기준과 수정 예시 | 사람을 공개 평가하지 않음. 예쁘다/별로다 대신 사용 조건이 판정을 만듦 |
| 상황별 서가 | 필요 순간을 고르면 관련 원본·예시·사용법·예외가 함께 나옴 | 다시 쓸 수 있는 자료와 최신 판의 위치 | 도구 이름·유행 날짜가 아니라 ‘소개를 보내기 전’ 같은 일의 순간으로 찾음 |

서가는 우선 기존 웹·고정글·자료 링크에 붙이는 **편집 구조 제안**이다. 새 서비스·검색기·자동 발송 시스템을 구현하거나 가동했다고 말하지 않는다.
클리닉은 처음에는 공개용 허구 사례나 SYNK 자체 자료로 만든다. 실제 사연을 받은 척하지 않으며, 실제 제보를 쓸 때는 당사자·권리·비식별·철회 범위를 확인한다.
관객이 고른 A/B가 다음 설명의 순서를 바꿀 수 있다. 그러나 댓글 수로 어느 사업자가 더 잘했는지 순위를 매기지 않는다. 혼자 종이에 고르는 참여도 같은 완성에 도착한다.

## 5. 첫 회차를 실제로 기획하면 — 같은 소개서, 두 읽는 자리

1. 원천은 승인된 SYNK SHIFT 소개서다. 실제 완성 지면을 먼저 보여주고 ‘서비스 개시 전 소개 자료’라는 현재 상태를 함께 읽는다.
2. 장면은 **처음 연락받은 사람이 휴대폰으로 펼침 / 이미 아는 사람이 관련 작업을 다시 찾음** 두 가지다. 인터뷰에서 확인한 행동이 아니라 비교용 시연 조건이다.
3. 완성물에서 대상·필요한 결과·확인 근거 세 부분을 찾는다. 멋진 표지보다 어디서 무엇을 찾는지 먼저 보여준다.
4. 공개용 별도 예시에 같은 내용을 넣어 첫 읽힘만 바꾼다. 원본을 몰래 나쁜 판으로 되돌려 ‘실제 개선 전’이라고 연출하지 않는다.
5. 시청자는 자신의 문서에서 **누가 어떤 순간에 읽는가 / 처음 알아야 할 것 / 다음에 확인할 실물**을 직접 적는다.
6. 제공 세트는 ‘소개 첫 화면 설계지’의 빈 원본, SYNK 적용 예시, 허구 1인 서비스 사례, 작성 후 스스로 확인할 질문으로 구성한다. 강의 구매 없이도 사용할 수 있다.
7. 마지막 30초는 실제 완성물 원칙을 살려 **읽는 자리에 맞춘 결과와 시청자가 완성할 빈칸**을 나란히 둔다. 새로운 서비스 보장이나 매출 주장을 넣지 않는다.
8. 끝의 CTA, 즉 다음 행동 안내는 ‘설명글의 설계지에서 내 첫 화면을 만들어 보기’ 한 가지다. 댓글·팔로우·이메일 제출을 자료의 대가로 요구하지 않는다.
9. 확인 범위는 실제 크기 가독성, 내용 보존, 파일 열림, 자기 자료에 적용 가능 여부다. 문의 증가·신뢰 상승·매출은 실제 관측 전까지 미확인이다.

## 6. 콘텐츠의 마지막은 ‘관련 있는 좋은 다음 경험’이어야 한다

| 지금 본 내용 | 바로 줄 것 | 다음 행동 하나 | 이후 강의와 연결하는 조건 |
|---|---|---|---|
| 소개 첫 화면의 읽는 순서 | 예시와 편집 가능한 설계지 | 자기 문서 첫 화면 작성 | 작성한 것을 직접 확인하는 실습 목표·강사·범위가 실제 준비됐을 때 |
| 실적 없이도 정직한 사례 구성 | ‘제작 사실/확인한 것/미확인’ 사례 양식 | 자신의 공개 가능한 작업 하나 정리 | 허구 실적 대신 실제 근거를 만드는 연습이 수업에 있을 때 |
| AI 결과를 내 브랜드 말투로 고치기 | 목적·대상·근거 입력 예시와 수정 비교 | 민감정보 없는 자기 예시로 한 번 적용 | 필요한 도구 접근·비용 조건·검사법이 먼저 보일 때 |
| 강의를 들은 뒤 남는 것 설계 | 시작 재료·끝 결과·직접 확인의 실습 틀 | 설명 한 구간을 짧은 실습으로 바꾸기 | 완성물·사전 능력·질문 대응 범위를 확인한 과정만 안내 |
| 인수 후 무엇을 바꿀지 정하기 | 파일 역할·변경 범위·문의 자리 견본 | 현재 납품 묶음의 사용 안내 적기 | 실제 판매 범위·권리·수정 조건이 준비된 서비스만 연결 |

기본 내용은 게시물·설명글에서도 이해되고 복사 가능해야 한다. 보조 파일은 클릭한 자리에서 같은 이름으로 바로 열리게 한다.
자료가 아직 없다면 ‘받아가세요’라는 CTA를 먼저 발행하지 않는다. 도착 화면에 무엇을 받는지·쓰는 순서·예시와 실제 서비스의 차이를 적는다.
자발적 질문·뉴스 구독·협업 문의는 별도 선택이다. ‘댓글을 남기면 검토해 드린다’는 실제 담당·범위가 없는 약속을 기본값으로 넣지 않는다.

새 계정은 전제하지 않는다. 기존 핸들·권한·외부 링크는 발행 직전 실행지로 확인한다. 플랫폼 기능·알고리즘·성과에 관한 최신 보장은 이 제안에 없다.
기존 홍보릴스는 **작품과 브랜드의 인상**을 담당한다. 실용편은 **관객 자신의 변화**를 담당한다. 한 릴에 광고·도구·모든 사업 설명을 억지로 합치지 않는다.
제작량 제약이 없더라도 매체마다 다른 도움을 만들 이유가 있어야 한다. 전용 제작도 필요하면 선택하지만, 같은 도움의 반복 게시를 신선함으로 세지 않는다.

|---|---|---|---|
| LAB | ‘한국의 하루, 내 대사’에서 내 역할·취향을 고름 | 상황별 한국어 표현과 변형 카드 → 학생 Telegram/웹의 다음 표현 | 한국어 초급을 낮은 사고 수준으로 취급하지 않음. 공개 얼굴·댓글 없이도 동일 자료 |
| LAB 보호자·성인 | 학생의 선택과 보호자의 확인 질문을 다른 면에서 읽음 | 학생용 자기 말 / 보호자용 수업 확인 / 성인용 실제 생활 표현 분리 | 학생 꿈을 부모의 불안 소재로 바꾸지 않음. 진단·학습 효과를 홍보 반응으로 추정하지 않음 |
| SHIFT | 내 사업의 소개·증거·첫 실습을 직접 고침 | 편집 원본·완성 예시·조건별 보정 → 준비된 강의/협업 | 현재 없는 강의·강사·기관 계약을 있는 듯 표시하지 않음 |
| PULSE | 작품을 고르고 자기 시간 곁에 둠 | 완결된 곡·장면·작품명과 다시 찾을 자리 | 감상 자체가 완성. 매번 템플릿·등록·업무 팁 CTA를 붙이지 않음 |
| SYNK | 완료물에서 회사가 지킨 결정 하나를 확인 | 실제 실물·현재 범위·관련 작업 기록 → 구체적 협업 질문 | 일곱 엔진·모든 사업의 과시장이 아님. 월간 기록과 희망 핸들의 미확인 상태 구분 |

같은 ‘읽는 순서’ 작업도 LAB에는 내 뜻이 전달되는 표현, SHIFT에는 자기 소개 설계지, SYNK에는 완료한 판단 기록으로 편집한다. PULSE 감상에 그 설명을 끼워 넣을 이유는 없다.

## 9. 첫 4주 — 사용해본 사람이 자기 결과를 얻는 네 회차

| 주 | SHIFT 원작 회차 | 완성해 가져갈 것 | 연결·확인 |
|---|---|---|---|
| 1주 | 같은 소개서, 두 읽는 자리 | 자기 소개 첫 화면 설계지 | 승인 소개서를 실제 증거로 사용. 독자가 누구에게 무엇을 주는지 설명하는지 확인 |
| 2주 | 실적이 없는 칸을 정직한 증거로 채우기 | 자기 작업 사례 한 장 | 실제 제작·허구 시연·고객 실적을 구분. 관련 홍보릴스와 사례 원본을 서로 연결 |
| 3주 | 아는 것을 가르칠 수 있는 첫 실습으로 바꾸기 | 시작 재료·끝 결과·확인법 한 세트 | 짧은 무료 실습 견본. 다른 사람이 안내만으로 작업을 해보는지 관찰 |
| 4주 | 한 작업을 여러 접점에서 같은 브랜드로 쓰기 | 소개·사례·실습·인수의 사용 지도 | 앞 회차 자료를 상황별 서가로 묶고 실제 질문/관찰에 근거해 한 부분 수정 |

권장 시험 편성은 주별 실용 원작 1편과 관련 제공물 1세트, 조건 하나를 다루는 짧은 클리닉 1편이다. 나머지 채널은 해당 회차의 역할별 편집이며 전 계정 매일 발행 약속이 아니다.
기존 홍보릴스는 이 편성과 병행한다. 관심을 얻은 편에는 실제 관련 자료를 안내하고, 감상형·소개형으로 충분한 편은 그 목적을 보존한다.
LAB은 현행 도움 제공형 릴을 자기 선택·변형 자료로 이어 붙이고, PULSE는 기존 감상의 마감·재탐색, SYNK는 이미 끝난 작업의 월간 기록에 적용한다.
이 4주는 착수 이후의 시험안이다. 발행·인터뷰 완료 날짜, 판매 일정, 유료 광고 집행을 뜻하지 않는다.

## 10. 명품 방식이 바꾸는 실제 디테일과 위험

- 실연·참여·수선을 함께 놓는 공식 사례는 확인된다. 이를 ‘만드는 사람의 판단 → 관객의 실습 → 사용 뒤 수정’으로 번역한 것은 B의 추론이지 성과 입증이 아니다. [Hermès Istanbul 2025](https://www.hermes.com/us/en/content/340839-hermes-in-the-making-turkey/), [le19M Mains d’avenir 2026](https://www.le19m.com/en/agenda/mains-davenir-the-metiers-dart-within-reach) (2026-09-09 확인).
- 시각은 승인 스티치·소품·재질을 사용하되 본문은 읽히는 글자로 둔다. 예시를 읽는 순간에는 지면의 해당 부분을 크게 보여주고 장식이 선택 기준을 가리지 않게 한다.
- 자료의 고급스러움은 표지 이후에도 이어진다. 빈 원본·채운 예시·적용 예외·사용 안내·판본과 실제 제공 조건이 맞아야 한다. ‘수선’이라는 비유로 무제한 지원을 약속하지 않는다.
- 반대로 모든 자료를 3칸 템플릿으로 만들지 않는다. 소개는 문장, 비교는 기준, 강의는 실습, 감상은 작품처럼 **결과의 모양도 목적이 정한다**.
- 주 위험은 예쁜 제작담만 남아 관객의 일이 바뀌지 않는 것, 다른 업종에 해법을 일반화하는 것, 무료 자료와 판매 과정의 실제 내용이 끊기는 것이다.
- 학생·거래처 원문·금융 화면·엔진 내부를 공개 사례로 쓰지 않는다. 클리닉의 허구 사례·합성 이미지·미확인 성과를 처음 보이는 위치에서 분리한다.
- 도구 기능·가격·대학 요강·권리는 쓰는 날 공식 원문으로 확인한다. 이번에는 새 구독·자동 수집·댓글 DM·웹 자동화·계약 조건을 구현하거나 확정하지 않는다.
- 성공의 첫 증거는 자료를 받은 사람이 자기 결과를 완성하고 선택 이유를 설명하는 것이다. 다운로드·좋아요·작성 건수를 고객 수·학습 효과·매출로 바꾸지 않는다.
