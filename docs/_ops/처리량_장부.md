# 처리량 장부 — «세션 수 ≈»를 실측으로 바꾸는 자

> 2026-09-05 세움(엔진 설계 v3 걸음 0 ⑯ · 심문④ 아스트라 11-9). 설계 v3 §11 의 «≈63덩이 ÷ 89일»은 근거가 0 이었다 — 이 장부가 서기 전의 세션 수는 전부 «≈»(어림)다.
> **적는 법**: 한 일이 끝날 때 한 줄. 시작·끝은 **커밋 시각(또는 도구가 찍은 시각)**으로 적는다. 세션이 열린 시각처럼 못 재는 것은 「안 재봤다」로 둔다.
> 낱말: 재작업 = 같은 산출을 다시 만든 횟수 · 외부 대기 = 사람·바깥 서비스(심사·발급·승인)를 기다린 시간 · 돈 = 그 일에 든 크레딧.
> 대표 작업 셋(계약 한 판 · 앱 화면 한 장 · 시트 배치 한 벌)은 그 일을 **할 때** 적는다 — 미리 어림해 넣지 않는다(어림을 적으면 자가 어림을 되읽는다 · 기억 ledger-edit-is-not-measurement).

## 가용 작업일
- **안 재봤다.** 있는 것은 달력일뿐(09-03 기준 12-01 까지 89일 · v3 §11). 하루에 몇 시간이 이 일에 가는지는 표본이 쌓여야 나온다.
- 세션 한도 = ≈8~9M 토큰/5시간 창(기억 workflow-stage-split-session-limit) — 「세션」≠「5시간 창」(기억 implementation-deferred-marketing-first).

## 이 장부가 답하려는 물음
- 「덩이 하나에 세션이 몇 개 드나」 — 표본 2·3·4 가 서면 v3 §11 의 걸음별 «≈» 를 실측 배수로 바꾼다.
- 「밀렸을 때 무엇을 먼저 버리나」(v3 6244) — 그 판정의 재료가 이 표다.
