# 인계 — 옷 조합을 정액제 ChatGPT 창으로 굽기 (2026-09-08)

> 이 문서 하나로 이어받는다. 앞 대화를 안 읽어도 된다.
> **밤굽기(제미나이) 사슬과 같은 세션에서 겹치지 않는다** — 랙이 걸린다(유호 확정 09-08).

## 무엇을 하나

까몽이 «의상 하나 + 악세 하나»를 입은 그림을 **106장** 굽는다. 다 굽히면 학생이 무엇을 골라도
미리 구워 둔 한 장을 꺼내 보여 줄 수 있어서, 조합이 무작위여도 늘 자연스럽다.

    node tools/옷조합목록.js              # 남은 것 몇 개인가
    node tools/옷조합목록.js --다음 10    # 다음에 구울 열 개

한 장에 3~5분이라 106장이면 **약 일곱 시간**이다. 돈은 0원이다(정액제 안).

## 왜 열쇠(종량제)를 안 쓰나

앱 화면에서 띄울 크기(400~1100점)로 줄여 견주니 정액제 1254 와 열쇠 2560 이 **구별되지 않았다.**
손가락으로 확대하는 자리는 앱에 없다(유호 확정 09-08). 그래서 4만 3천원을 아낀다.
대가는 시간과 손이다 — 브라우저를 하나하나 몰아야 하고, 세션이 끊기면 그 자리에서 멈춘다.

## 굽는 절차 (한 장)

준비물은 이미 다 있다.

| 무엇 | 어디 |
|---|---|
| 몸 참조 | `docs/Loom_자산/옷/GPT참조/_몸_까몽.jpg` |
| 옷 참조 | `docs/Loom_자산/옷/GPT참조/까몽/<옷이름>.jpg` (빈칸 뺀 이름) |
| 낼 곳 | `docs/Loom_자산/옷/GPT정액시험/까몽_<옷토막>.png` |

이름은 `tools/lib/옷목록.js` 의 `옷토막()` 이 정한다. **목록에 적힌 차례로** 잇는다
(「목도리+3급왕관」과 「3급왕관+목도리」가 둘 다 나면 자산 절반이 미아가 된다).

    node -e "const L=require('./tools/lib/옷목록.js'); console.log(L.옷토막('까몽',['앞치마','목도리']))"

### 브라우저에서

1. `https://chatgpt.com/` 로 간다. 로그인은 이미 돼 있다(양유호 Pro).
2. 입력칸에 지시문을 넣는다. 🔴 **`type` 액션은 이 페이지에서 안 먹는다.** `execCommand('insertText')` 를 쓴다.
3. 그림 셋(몸 + 옷 둘)을 올린다. `find` 로 `file` 입력을 찾아 `file_upload` 에 `ref` 를 준다.
   🔴 **한글 경로를 브라우저 도구에 넘기지 않는다** — 로마자 이름으로 복사해서 올린다.
4. 전송은 `button[data-testid="send-button"]` 을 `click()`.
5. 3~5분 기다린다. ChatGPT 가 **A/B 두 장**을 내고 고르라 할 때가 있다(둘 중 나은 것을 쓴다).
6. 캔버스로 떠서 `<a download>` 로 받는다.

### 지시문 뼈대

`window.__P(a,b,d)` 를 페이지에 한 번 심어 두면 옷 이름 둘과 설명만 넘기면 된다.
설명은 `tools/lib/옷목록.js` 의 `설명` 필드를 이어 붙인 것이다.

    node -e "const L=require('./tools/lib/옷목록.js');const v=L.목록('까몽');
    const f=n=>v.find(x=>x.이름===n).설명;
    console.log(f('앞치마')+' '+f('목도리'))"

뼈대에 반드시 들어가야 하는 줄 (09-08 실측으로 굳은 것):
- `Both pieces must be clearly visible and must not collide with each other` — 안 넣으면 둘이 겹쳐 뭉갠다.
- `including the two front paws held out to the SIDES at mid height` — 안 넣으면 팔이 만세로 올라간다.
- `sharp focus on the individual wool fibres` — 펠트 결이 브랜드 컨셉이다.

## 🔴 밟으면 다치는 것 넷

1. **연달아 빨리 받으면 크롬이 막는다.** 영구 차단이 아니다 — 사이를 두거나 페이지를 새로고침하면 통과한다.
   유호님 프로필의 허용 목록에는 `gemini.google.com`·`suno.com` 만 있고 chatgpt 는 없지만, 설정을 고칠 필요는 없다.
2. **같은 그림을 다시 받는 사고.** `ims[ims.length-1]` 로 마지막 그림을 잡았는데 새 그림이 아직 안 떠서
   앞 그림을 받아 새 이름으로 저장했다(09-08). 받은 뒤 **지문(md5)으로 앞 장과 다른지 센다.**
3. **크기는 1254 가 천장이다.** 지시문에 「가장 큰 해상도로」를 넣어도 안 올라간다.
4. **같은 대화에 이어서 요청하면** 앞 그림에 끌린다. 지시문 첫 줄에
   `🔴 Ignore every earlier image and instruction in this conversation. Use ONLY the 3 reference images attached to THIS message.` 를 넣는다.
