## 결론

1. **SYNK 35류는 광고·마케팅(유사군 S0101) 10개만 넣어서 지금 출원한다.** 35류의 SYNK 계열 상표 셋은 모두 다른 유사군이라 겹치지 않아요.
   - SynK AICC 플랫폼: 등록, S123301(데이터 처리)
   - SYNKY: 출원, S123101(사업중개)
   - 엣지싱크: 출원, S123101
   - 경영컨설팅(S123101)은 SYNKY와 같은 유사군이라 넣지 않아요.
2. **「WORLD」 단독이 아니라 「SYNK WORLD」로 낸다(10-05: 지금은 내지 않고 SYNK 심사 뒤에 정함).** WORLD는 9·41·42류에 4,001건이고 41류에 「WORLD」 단독 등록이 있어요. 「SYNK WORLD」·「싱크월드」는 0건이에요. 비용 문서도 처음부터 SYNK WORLD로 잡혀 있었어요.
3. **SYNK WORLD를 낼 때는 기존 SYNK 출원과 같은 9·41·42류 21개로 낸다.** 류마다 10개 이내라 추가 수수료가 없어요.
   - 41류(교육)는 걸리는 상표가 없어요.
   - 9·42류는 아래 「위험」이 SYNK와 같이 적용돼요.
4. **SYNK TOWN은 지금 걸리는 게 없다.** 싱크타운은 35류에 소멸한 상표 1건뿐이에요. 이름이 확정되면 내면 돼요.
5. **Atlas는 단독으로 내지 않는다.** ATLAS는 9·41·42류에 123건이고 9류 등록이 여럿이에요. 아틀라스어학원·유학원은 41류에서 거절됐어요. 공개 상품 이름으로 쓰게 되면 「SYNK ATLAS」 결합으로 다시 봐요.

## 위험 — 기존 SYNK 출원(40-2026-0165300)과 SYNK WORLD의 9·42류

- **Synkey**(40-2025-0244862, 등록, 주식회사 신기그룹)
  - 9류 G390802(금융 소프트웨어·펌웨어)와 G390803(컴퓨터)을 지정했어요.
  - 저희 9·42류 지정상품도 G390802라서, 「싱크 vs 싱키」가 비슷하다고 보면 의견제출통지가 올 수 있어요.
- **SynK AICC 플랫폼**(40-2024-0048152, 35류 등록, 주식회사 케이엘큐브)
  - 지정 유사군 S123301이 저희 42류 지정상품(G390802·S123301)과 겹쳐요.
  - 같은 회사의 9류(0048151)·42류(0048153) 출원은 거절됐어요.
- 판단:
  - 41·16류는 깨끗해요. 의견제출통지가 오면 걸린 지정상품만 빼거나 다르다고 다툴 수 있어요.
  - 몽골 우선권은 한국 출원의 등록 여부와 상관없이 출원일로 성립해요.
  - SYNK 심사 결과(보통 출원 뒤 반년 이상)를 보고 SYNK WORLD 9·42류를 조정해도 돼요.
