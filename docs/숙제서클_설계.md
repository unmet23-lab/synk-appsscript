# 숙제 서클 — 조별 말하기에 재사용하는 활동 설계

## 현행 수업과의 관계

숙제에서 자기 표현을 골라 조원에게 말하고, 질문을 주고받은 뒤 오늘 연습할 것을 정하는 활동이다. 현재 90분 수업은 **열기5·제시20·통제연습15·그룹발화30·공유10·닫기10분**이며 [커리큘럼](커리큘럼_정본_v1.md)·[오프라인 운영 기준](오프라인_공간설계/오프라인_운영기준_20261002.md)이 정본이다. 옛 「첫20분 고정」「기존 소그룹 폐지」를 적용하지 않는다. 실제 출석 인원에 맞춘 [반편성](반편성_정본_v2.md) 안에서 목적·시간·교사 업무를 맞춰 이 활동을 사용할 수 있다.

이 문서는 활동 설계이며 자동 인쇄·순회 중 검수 완료·학생 발화량이나 학습 효과의 보장이 아니다. 08월의 Apps Script 조판·출석·메일 배치는 [10-02 옛 시스템 정리](_ops/옛시스템_정리목록_20261002.md)로 종료됐고 숙제 포인트도 [BM 목록](BM_목록.md)에서 보류됐다. 과제15점 자동 지급·삭제된 함수 실행·옛 대기열/고정 검수 회차를 다시 요구하지 않는다.

## 보존할 학습 경험

| 단계 | 학생이 하는 일 | 확인할 것 |
|---|---|---|
| 짧은 열기 | 자기 수준에 맞는 질문에 한 문장으로 답한다 | 질문 이해와 모든 학생의 참여 기회 |
| 자기 표현 설명 | 자신이 쓴 문장과 다시 확인할 부분을 말한다 | 원문을 마음대로 고쳐 학생의 말처럼 보이지 않게 함 |
| 질문과 답 | 조원이 이유·다른 예·의미를 묻고 답한다 | 질문을 위한 질문이나 긴 받아쓰기로 침묵하지 않는지 |
| 오늘 연습할 것 | 방금 확인한 표현 중 하나를 정하고 옆 사람이 이해한 뜻을 말한다 | 실제로 들은 의미와 학생의 선택이 연결되는지 |
| 수업 끝 돌아보기 | 선택한 표현을 다시 해 보고 자신이 확인한 것을 남긴다 | 종이 보관·미제출·발화량을 공개 순위로 만들지 않음 |

08-13의 2분 열기·10분 브리핑·3분 목표·5분 전환은 당시 비교 모형이다. 현재 30분 그룹발화 전체를 자동으로 대체하거나 별도20분을 더하지 않는다. 실제 수준·인원·교실 소음·교사의 도움을 포함해 시험한다.

진행·기록·발표·질문의 역할은 모든 학생이 말하고 듣게 돕는 방법이다. 실제 인원과 활동에 맞춰 나누고 회전하며 고정4인·항상4조나 삭제된 역할 함수의 값을 전제하지 않는다. 학생의 필요에 따라 다시 설명하거나 활동을 조정할 수 있다. 옛 「교사 변주 금지」·고정 구호·금칙어·대체어를 공통 말투 지침으로 쓰지 않는다.

## 인쇄물을 쓸 때

조별 한 장에서 각자 자기 부분을 가져가는 종이 경험은 보존한다. 08월의 A4세로·조당1장·머리+학생4칸·점선 분리안과 수준별 문장 틀은 재사용 후보이며, 현재 인원과 원문 길이에 맞춰 실물 크기에서 확인한다.

- 자기 문장은 원문으로 보여 준다. 자동 교정문을 원문처럼 제시하거나 문장 중간을 잘라 인쇄하지 않는다. 길 때는 보조 설명을 줄이거나 다른 레이아웃을 선택하고 누락을 드러낸다.
- 도움말은 확인된 오류·기존 수행 근거와 연결한다. 지난주에 실제로 없었던 문제를 「지난주에도 나왔다」고 쓰거나 모르는 수준을 초급으로 채우지 않는다.
- 미제출·신규·결석·지각의 차이를 공개 낙인으로 만들지 않는다. 최근에 한 표현이나 현재 수준의 시작 문장으로 활동에 참여할 수 있게 한다.
- 이름도 학생 식별 정보다. 같은 조에서 읽는 범위·강사 접근·종이 전달·폐기를 실제 동의와 운영에 맞춘다. 이름만 있으면 개인정보가 없다는 과거 판정을 쓰지 않는다.
- 점수·등수·제출 순위·조별 완료 현황을 종이에 추가하지 않는다. 학생에게 기록을 돌려주는 일과 회사 외부 공개는 구분한다.
- 프린터가 실패해도 구두 질문과 기억나는 표현으로 활동을 이어 갈 수 있게 준비한다. 인쇄·배포·회수·권한 확인의 사람 일을0분으로 계산하지 않는다.

## 교사의 관찰과 앱 연결

교사가 순회하며 발화를 듣는 일과 AI 교정 초안을 확인하는 일은 다른 업무다. 둘을 동시에 하면 자동으로 준비 시간이 사라진다는 가정을 두지 않는다. 실제 한 학생·한 조에 쓸 수 있는 시간을 재고, 특정 조·역할이 계속 관찰에서 빠지지 않는지 확인한다. 08월의 순회 위상 보정식과 시간표는 아래 보존본에 남긴 참고다.

이 활동은 새 데이터 수집 없이도 성립한다. 새 녹음·폼·점수표를 활동의 필수 조건으로 만들지 않는다. 기존 과제 검수나 필요한 교사 관찰을 연결한다면 현재 앱 계약·동의·권한·실제 소비처를 확인하고, 관찰을 성격이나 능력의 단정으로 저장하지 않는다. 과거 코드·마이그레이션 존재를 운영 연결의 완료로 세지 않는다.

시즌은 달력8주이며 학생의 목표와 확인한 변화는 [시즌 회고](시즌회고_설계.md)와 연결한다. 학생이 원하지 않는 보관·배지·연속 일수·보상을 추가하지 않는다.

## 시행 전 확인과 보존 원문

현재 시간표 안에서 학생의 설명·질문·듣기·재시도가 가능한지, 교사 관찰과 검수 업무가 실제로 가능한지, 미제출/신규 학생도 참여하는지, 소음과 프린터 실패를 감당하는지 시험한다. 예전 채용월·부트캠프월·학생0명·종결 판번호는 현재 일정이나 검증 결과가 아니다.

08-13 활동 원문·레벨별 문장 예시·4인 모형·순회식·종이 높이 실측·긴 문장 잘림과 중복/실패 복구 사례·폐기안의 선택 이유는 [정리 전 원문](_ops/qa/document-cleanup-20261017/_archive/pass2-originals/docs/숙제서클_설계.md)에 모두 보존한다. 구현 교훈은 다시 사용할 수 있지만 삭제된 GAS 조판·메일·출석 함수를 현행 실행 지시로 중복 유지하지 않는다.
