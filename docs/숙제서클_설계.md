## 3. 인쇄물 1장 명세

**규격**: A4 세로 1장 · 단면 · 조당 1장(반당 4장/차시) · 흑백 가능 · 가로 점선(손으로 찢어지는 굵은 파선)으로 5구역 = 머리 1 + 학생 칸 4 · 조 번호·차시가 각 학생 칸 귀퉁이에 반복 인쇄(뜯어도 「N조 12차시」가 남는다). ⚠칸당 ~59mm에 들어가는지 **실물 조판 1장 실측이 구현 인수 조건**이다(§10).

**머리(조 공통)**: 조 번호 · 차시 · 역할 4명 배정 · 오늘의 질문 카드 1장 · 말하는 순서(좌석 순번 — 차시마다 한 칸씩 밀림) · ✍️기록이 손으로 쓰는 「오늘 조에서 나온 질문 한 개」 빈칸 1줄.

**학생 칸(×4 · 엔진이 채워 인쇄 — 학생은 읽고 말한다)**:
- **잘 된 문장** — 어젯밤 숙제에서 검수 확정된 정답 산출 중 최근 1개, **학생 원문 그대로**(다듬는 순간 내 문장이 아니게 된다).
- **한 번 더 볼 자리** — 오류 태그 1개(학생이 읽는 한국어 표현으로) + 자기 이력 대조 한 줄(`trend_line`).
- **다음에 맞힐 문제** + 확인 동그라미 ( ) — 오늘 목표의 재료이자 마무리 ⑥의 회수 자리.
- 레벨별 문장 틀 · 질문 틀(아래).

**`circle_sheet` 계약 초안** (읽기 전용 조회로 조립 · 새 event_type·새 시트·새 폼 0 · 인쇄 페이로드에 학습자 식별자 0 — 이름만):

```
circle_sheet { class_id · session_no · group_no(1..4) · warmup_question
  members[4] { display_name · role(정본 ROLE_NAMES 한글 그대로 — '진행'·'기록'·'발표'·'질문' · 영문 enum 사본 금지)
               kept{text} · shaky{text, trend_line} · next_one{text} } }
```

⚠ 배달 배치(`deliver`)는 **학생 1명당**으로 돈다 — 조별 A4 1장은 4명을 묶는 **조 단위 조립 계층이 신규 구현**이다(「새 배치 0」 주장은 게이트에서 기각). 구현 = 대기열 P1 「숙제 서클 실물화」.

**선정 규칙** (위에서 먼저 맞는 것 하나):

| 칸 | 우선순위 | 없을 때 |
|---|---|---|
| `kept` | ①지난번에 틀렸다가 이번에 맞은 자리(어제의 나 대조) ②최근 반복 오류 태그와 같은 영역에서 맞은 것 ③이번에 맞은 것 아무거나 ④끝까지 제출한 것 자체(얻는 쪽에서 센다) | 최근 3회로 넓힘 → 그래도 없으면 **줄을 인쇄하지 않는다**(빈 줄 금지) |
| `shaky` | ①이번 회차 오류 태그 최다 1개 ②동률=최근 반복 많은 쪽 ③동률=발음 축 우선(받침·경음/격음·유음화 — 몽골 학습자 전 레벨 지속 난점 · 매뉴얼 §2-2) ④오류 0건=다음 단계 자리 1개 | 최근 3회로 넓힘 |
| `trend_line` | **두 갈래 고정 문형만**(자유 생성 금지): ⓐ줄었으면 「지난주보다 줄었어요.」 ⓑ아니면 「이 자리는 지난주에도 나왔어요 — 오늘 한 번 더 봐요.」 (숫자 노출 금지 — 늘어난 학생에게 기죽임이 된다) | 이력 1주 미만 = 줄 생략 |
| `next_one` | `shaky`에 대응하는 오늘 항목 1개 | 고정 문장 「오늘 수업에서 이 자리를 한 번 더 봐요.」 |

**예외**: 숙제 미제출 = `kept`/`shaky` 대신 최근 이력에서 고른 「오늘 볼 것」 한 줄 — **칸 모양·위치가 제출자와 동일**(종이 위 제출/미제출 표시 0 · 빈 칸은 낙인이다). 결석 = 종이는 QR 출석 확정 뒤 인쇄되므로 그 칸이 아예 없다 — 조는 3인 운행, **❓질문 역할이 빠진다**(코드 실측: `roleOfSeat_`는 앞 3개만 돌린다 · 「진행이 겸임」은 정본에 없어 기각). 지각(워밍업 후 도착) = 칸이 없어도 서클에 바로 합류해 **「오늘 볼 것」을 입으로만** 말한다 — 진행은 카드를 다시 읽지 않는다(되감으면 15분이 깨진다). 이력 0(첫날·신규) = 레벨별 시작 문장 1개(§6).

**인쇄 금지 계약**: 점수·정답률·정답 개수·등수·난도 라벨 0 · 조 안 항목을 난도순·개수순 정렬 금지(순서는 좌석 회전만) · 오류 태그 코드 문자열 노출 금지 · 한자 글자 0(커리큘럼 정본 §6-2) · 교사 기입 칸 0.

## 4. 교사 동선 — 4조 × 5분 순회 (검수 ∥ 듣기)

**병렬이 성립하는 이유**: 검수(AI 채점 초안을 확정/수정하는 탭)는 말이 필요 없는 일이고, 듣기는 손이 필요 없는 일이다. 교사는 조 옆에 앉아 손으로는 그 조 4명의 초안을 넘기고, 귀로는 브리핑을 듣는다. **조 안으로 들어가 지도를 시작하지 않는 것이 이 5분의 규칙** — 끼어드는 예외는 둘뿐(①모국어 이탈 ②30초 넘는 침묵), 각각 한 문장으로 끝낸다("한국어로 한 번 더 해 볼까요?" / "질문 역할이 먼저 물어볼까요?").

| 순회 자리 | 창 시각 | 그 조의 상태 | 교사가 듣는 것 |
|---|---|---|---|
| 1번 | 0–5분 | 몸풀기+브리핑 앞 | 브리핑 ~3분 |
| 2번 | 5–10분 | 브리핑 한복판 | 브리핑 5분 전부 — 가장 좋은 자리 |
| 3번 | 10–15분 | 브리핑 끝+목표 | 브리핑 ~2분 + 목표 |
| 4번 | 15–20분 | 전환 | 브리핑 0분 — 단 브리핑이 밀린 조라면 **목표가 이 창에 걸려 들린다**. 이 5분의 성격은 「검수 마무리 + 오늘 목표 듣기」다 |

**정직 고지**: 매 차시 4조 중 1조는 교사가 브리핑을 못 듣는다 — 산술의 결과라 없앨 수 없고, 감추지 않는다. 처방은 회전이다.

**순회 시작 조** = `((차시−1) + ⌊(차시−1)/4⌋) % 4 + 1`.
- 앞 항은 v9.99 `focusGroupOf_`와 같은 4차시 회전 — 4차시면 모든 조가 네 자리를 한 번씩 지난다.
- **주차 항 `⌊(차시−1)/4⌋`은 게이트가 잡은 구조 결함의 처방이다**: 역할 회전과 순회 회전이 같은 차시 번호에 위상 고정되면 **한 학생은 자기 조가 「브리핑 0분」 자리일 때마다 언제나 같은 역할을 든다**(조 단위 공평이 학생 단위로는 거짓). 주차 항이 4차시마다 위상을 한 칸 더 밀어 이 고정을 푼다. 새 저장 0 — 여전히 차시 번호의 순수 함수다.
- 무수정 통과율 계측은 관찰 태그 계약(⏳유호)이 열린 뒤의 일이다 — **「이미 세고 있다」고 쓰지 않는다**(게이트가 잡은 허위 인용).

**말해야 할 때의 화법** (기죽임 없이 · §4-2 직설 원칙): 미제출을 언급하지 않는다 — 굳이 말해야 하면 "이번 숙제, 아직 열어 뒀어요."(브랜드 반례 표 3행 허용 표현). 결석 복귀 = 지난 차시 언급 0. 이유는 묻지 않는다(조 앞에서 답하게 하는 순간 비교가 성립). 연속 미제출은 서클 밖 1:1로.

## 5. 신선도 — 형식 고정 · 내용 회전

**고정**: 뼈대 2·10·3 · 레이아웃 · 문장 틀 · 시작/끝 신호. 고정이 신선도의 조건이다 — 형식이 바뀌면 설명 시간이 생기고, 설명 시간이 생기면 15분이 깨진다. 교사 재량의 「오늘은 특별히」 변주 금지 — 확장은 언제나 **카드 풀에 카드를 더하는 것**뿐이다.

**회전(전부 앱 자동 · 클릭 0)**: ①질문 카드 — 결 4종(사실/선택/상상/설명)을 차시로 돌리되 **각 결의 카드 풀은 계속 늘린다**(신선도의 원천은 조합 수가 아니라 풀과 ②다) · 워밍업 소재와 이어지는 카드 우선 ②학생 칸 내용 — 어젯밤 숙제가 매일 다르므로 저절로 매일 다르다(가장 싼 신선도) ③말하는 순서 — 좌석 순번 한 칸씩 밀림 ④역할 — 4차시 로테이션 ⑤순회 자리 — §4의 위상 오프셋 포함.

**시즌 리듬**(시즌=달력 8주≈2달 · 유호 확정 09-04 가 08-12 「교재 1권」을 뒤집었다): 첫 차시 몸풀기 = 새 조 인사(각자 「저는 ___를 잘하고 싶어요」 1문장) · 마지막 차시 목표 3분 = 시즌 회고 한 문장("이번 시즌에 제일 달라진 건 「…」예요" — 기존 시즌 회고 그릇과 정합). 요일 리듬은 값을 정하지 않는다 — 주당 차시 수가 [운영 확정] 대기라, 회전은 전부 차시 번호로 구현하고 수업표 확정 시 매핑만 한다.

**「오늘 목표」가 낭독으로 죽지 않게 하는 장치 셋**: ①목표를 새로 짓지 않는다(재료=방금 말한 「다음에 맞힐 문제」 줄) ②수신자를 만든다(오른쪽 조원에게 말하고, 들은 사람이 3인칭 한 문장 되받기 — 되받으려면 들어야 한다) ③70분 뒤 회수한다(마무리 ⑥에서 자기 조각의 동그라미에 확인 표시 — 아침에 말한 것이 그날 안에 한 번 돌아온다. 데이터 아님·회수 안 함).

## 7. 엔진 연결 — 옵션 · 기존 통로만

새 수집 채널 금지: 종이 회수·스캔·학생 폰 입력·새 폼·새 시트·새 event_type·조별 달성률 표·발화 녹음 전부 하지 않는다(녹음은 별도 트랙 — v9.99 §5 판단 승계). **둘 다 안 켜져도 서클은 그대로 돈다.**

- **통로 1 · 검수 확정(열려 있다)** — 교사가 순회 중 확정/수정한 것이 기존 경로로 들어간다. 서클이 얻는 것은 재료가 아니라 **시각**이다(검수가 「따로 앉은 시간」에서 「수업 20분 안」으로) — ③운영의 승리지 ②엔진의 승리가 아니다. 이 구분을 흐리지 않는다. 과제 포인트(15)는 검수 확정 시 자동 — 매뉴얼 §1-2가 이미 그렇게 적고 있다. 강사는 숫자를 말하지 않는다(§4-3).
- **통로 2 · 관찰 태그(⏳유호 — 계약 미확정)** — `observation.noted` · `source_kind='teacher'` 계약 판정이 선행한다. 열리면 순회 중 「관찰 한 줄」(옵션 · 안 적어도 흐름 안 깨짐)이 그 칸으로 가고, ㉡사람 이해(조 안에서 언제 말이 늘어나는가 — 좌석·역할·자리가 전부 차시에서 계산되므로 맥락은 결정론, 사람이 적을 것은 한 줄뿐)의 재료가 된다. 열리기 전엔 이 단계가 아예 없다.

종이를 쓸 사람이 못 받는다. 반별 메일 정본은 `teacherEmailMap_`(profiles `role=teacher`)다(⚠08-14 정정: 첫 판은 운영자에게만 보냈고, 나는 「이 저장소에 강사 메일 정본이 없다」는 **틀린 근거로 그 지적을 기각했다** — 담당강사가 이름 문자열인 것만 보고 안 찾아본 채 단정했다 · 검수 P1 `e4c00b45`). 파일에 **열람 권한도 같이 준다** — Drive 파일은 만든 계정 것이라, 강사 계정이 다르면 메일은 도착하는데 링크를 열면 「액세스 요청」이 뜨고 거기서 자동 인쇄가 끝난다(P1 `657feff6`). 그 권한 부여가 실패하면 **삼키지 않고 이름으로 보고한다**(P1 `2ce886d2`) — 조용히 넘어가면 안 열리는 링크만 **설계를 그대로 안 쓴 자리 2곳** (구현이 연 것 · 둘 다 종이가 거짓말하는 것을 막는다):
- §3 `trend_line` ⓑ「아니면」 → **지난주에 그 태그가 실제로 있었을 때만** 낸다. 없던 자리에 「이 자리는 지난주에도 나왔어요」를 붙이면, 늘어난 자리에서 종이가 거짓이 된다(그리고 그 거짓은 학생만 읽는다).
- 레벨 어휘(profiles 「한국어수준」 = 기초·초급·중급) → Lv 매핑을 **추측하지 않는다**. 못 읽으면 `-1`(모름)을 내고 조립 보고가 말한다 — 조용히 Lv1~2 로 접으면 상급반 종이가 통째로 초급 문장 틀로 나가고 어디서도 안 빨개진다. 매핑 정본 = `app_state` 한 칸(`key='레벨어휘'` · `value='기초=1,초급=2,중급=4,고급=6'`), 유호님이 코드를 안 거치고 정한다.<br>⚠ **08-13 정정 — 이 규약은 세 자리 중 한 자리에서만 지켜지고 있었다**(배포 검수가 잡았다). `circleBandOf_` 는 옳게 `-1` 을 냈는데, 그 값을 받는 쪽 둘이 `-1` 을 조용히 `0`(Lv1~2)으로 접었다: 질문 카드(`circleWarmupOf_` 의 `? band : 0`)와 첫날 시작 문장(`CIRCLE_START_LINES[band] || [0]`). 문장 틀(`CIRCLE_FRAMES[-1]`=null)만 맞아 있었다 — 그래서 상급반 조 머리에 초급 질문이 인쇄되고 어디서도 안 빨개졌다. 이제 셋 다 **안 낸다**(빈 질문 상자도 안 그린다 — 테두리만 남은 칸은 「오늘은 질문이 없다」로 읽힌다). 조립 보고에 `질문없는조` 가 붙어 어느 조의 머리가 비는지 이름으로 말한다.

**착수 전 확인 1건**(라이브에 실물이 도는 조건): 위 `app_state` 한 칸 + 시즌 시작일(`setSeasonStart`) + 조 편성(`assignGroupsAll`). 셋 중 하나라도 없으면 `printCircleSheets` 가 «무엇이 없는지»를 이름으로 말한다(빈 종이를 조용히 굽지 않는다).
