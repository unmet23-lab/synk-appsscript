# Loom 굽기 규약 — 다음 굽기가 밟는 것

> **상태**: 정본 · 2026-09-06 신설. 트랙 §2 Loom 이 색인으로 부풀어(12.5KB) 규칙·자 블록을 여기로 옮겼다(트랙 §7 의 처방 ⓑ).
> **이 문서가 규칙의 정본이다** — 트랙에는 포인터 한 줄만 둔다. 두 곳에 적으면 한쪽이 조용히 낡는다.
> 닫힌 회차의 «이야기»는 여기 안 적는다. 여기 남는 것은 **다음 굽기가 실제로 밟는 것**뿐이다.

- 🔑 **굽기 전에 「달라지나」를 먼저 잰다** — `node tools/재굽기값.js --화면|--형태 <이름>`. 09-03 에 화면 열넷을 이 자로 재서 **0/14**(닿는 코드가 08-26 굽기 뒤 한 줄도 안 바뀌었다) → 14잡을 8분 만에 걷었다. 손으로 세지 않는다.
- 🌩 **클라우드 통로**(장당 ≈9.5분·0.5센트 · 램은 저쪽 32GB) — `hf.exe jobs run --flavor cpu-upgrade --timeout 40m -v ./올릴것:/work:ro -v ./받을것_<이름>:/out:rw -d linuxserver/blender:5.2.1 sh -c "blender -b -P /work/tools/<굽기>.py -- …"`
  🔴 `sh -c` 로 감싸야 `--` 뒤 인자가 산다 · 이름·bash 변수는 로마자 · 재료 버킷 `q121235/jobs-artifacts/올릴것-5a8f3c5d` · 산출은 버킷에 남는다(`hf buckets cp` 로 되받는다) · 화면 전용 통로 = `tools/화면클라우드굽기.js`
  🪤 저쪽 실패는 원인을 안 가린다 — 볼륨 마운트 401 이 코드 오류처럼 보였고 «그대로 다시 걸자» 1분에 났다
- 🎨 **색 자** = AgX+Punchy(요소·NPC) · **화면 열넷만 옛 AgX 맨판**(유호 08-24 「그대로 가자」 · 상수는 `명품재굽기.js` 화면자)
  🔴 `Khronos PBR Neutral` 은 쓰지 않는다 — 08-24 에 222장을 태웠고 09-03 히어로 첫 판이 유호 반려(「왜 이렇게 쨍하게 나와」)됐다. 되돌리자 «쨍함»과 «게이지 안개»가 함께 풀렸다
  🪤 `토큰=` 을 빠뜨리면 7초에 죽는다 · `TaskStop` 이 파이프 안 자식을 못 죽여 같은 장을 두 번 구울 수 있다
- 🔢 **번호 부품은 원판과 셈이 다르다** — 번호가 그림에 수놓여 있어 쓰는 번호만큼 낱장이 든다(실측 절 최대 34·목록 항목 최대 53) ⇒ **01~12 만 굽고 13번부터는 민판 + CSS 글자**(12 넘는 지면 = 64벌 중 4). counter 값으로는 그림을 못 고르므로 `펠트문서.js` 가 `.번호` 에 `data-n` 을 박는다.
- 🎯 **대비는 «둘 중 나쁜 쪽»으로 잰다** — 한 바닥만 재면 옛 기본값이 이긴다(밝은 Ash Wool 은 흰 종이에서 2.62:1 로 무너졌고 Deep Wool 이 화면 4.62·종이 4.09 로 이겼다). 확정 = 불릿 짙은무채 · 단추 번호 잉크(결정.md 09-03).
- 🚫 **철칙 ④ — 반복되는 것은 무채**(`요소굽기.py:5113` 「수십 개가 코랄이면 신호 1점이 죽는다」). 불릿을 산호로 바꾸는 판정은 이 철칙과 기본 염료를 «함께» 걷는 일이다.
- 🚫 **분류 칩에 배경을 두지 않는다**(유호 확정 09-03 「4번이 제일 낫다」) — 실측이 갈랐다: 밝은 천 7.41 · 어두운 천 11.2 · 본문 15.08 이고 **밝은 바탕은 상한이 9.4** 라 구조적으로 못 넘는다. 배경을 빼면 칩 글자가 본문 대비를 그대로 쓴다.
- 🔴 **`tools/lib/loom.js` 를 고친 커밋은 «같은 커밋에서» `node tools/지면얹기.js --적용`** — 손 HTML 12벌은 안 돌리면 옛 CSS 로 남는다(증상은 exit 1 뿐).
  🚫 «줄끝 때문에» 돌리지 않는다(판정은 09-03 부터 줄끝을 접어서 잰다 · `tools/lib/loom얹기.js` 의 `최신`) · ⚠ `--제자리` 는 **없는 플래그**다(도구가 아는 것은 `--적용` 뿐)
  🗂 **지면 전량 재생성 통로는 «여덟»이고, 그 뒤에 사본 동기화가 한 번 더 붙는다**(09-04 실측 · 세 차례 되짚어 세었다 — 다섯→여섯→일곱→여덟로 늘 때마다 «빠진 지면»이 먼저 울었다):
  ①`펠트문서.js --전량`(엔진 소개서 7) ②시안 도구 열(`{릴,마린,부품색,부품형태,숫자크기,오브,와펜,요소,화면,히어로}시안.js`)
  ③`NPC시트.js`·`까몽시트.js` ④`앱감사지면.js`·`이해대장.js`·`작동대장.js` ⑤`룸조판.js <원고> --내놔 <지면>`(원고방 = `docs/_원고/`)
  ⑥`크루카드굽기.js`(라이브 접수 폼 둘) → 🔴 **그 다음 반드시 `크루카드사본.js`** — 정본 `crewcard/` 과 사본 `docs/크루카드/` 는
  «바이트 동일»을 시험이 문다. 09-04 에 `지면얹기.js --적용` 과 `크루카드굽기.js` 가 각각 한쪽만 만져 **줄끝 한 바이트로 갈렸고**
  `tests/크루카드.test.js` 가 그 자리에서 죽었다. 방향은 한쪽뿐이다 — 정본 → 사본.

  🔑 **인쇄물은 따로다** — `발표물빌드.js --pdf`(7종). 화면본만 고치고 PDF 를 빠뜨리면 아무 자도 안 운다(09-04 에 그렇게 84분 뒤처져 있었다).
