# SYNK 조직과 권리

사업 역할은 [마케팅](마케팅_정본.md)에 있다. 네 브랜드가 네 법인이나 이미 운영 중인 네 서비스를 뜻하지 않는다.

2026-10-05 사업 확장: 기존 LAB·SHIFT·PULSE·PATH 체계를 유지한다. 시장조사·제품 테스트는 SHIFT, 스튜디오·장비 대여는 PULSE, 주거·정착 지원과 방문·문화 체험은 PATH에 편성한다. 상품 판매는 SYNK 홈페이지의 상품 메뉴에 둔다. 별도 계열사·브랜드를 추가하지 않으며, 실제 제공 조건·출시 여부·계약 및 권리 주체는 이 사업 배치와 구분한다. PATH의 새 서비스는 초기에는 제휴 운영사 연결 방식으로 준비한다.

2026-10-06 SHIFT 범위 집중: 현재 신규 사업·BM은 [개인화 서비스 도입·운영 → 반복 공급 검증 → API·엔진 라이선스 확장](마케팅/SHIFT.md#shift-bm)을 따른다. 교육·컨설팅·자동화·브랜딩·시장조사·제품 테스트는 해당 도입 지원 범위다. 아래의 자격·대외 판매 구상은 이력으로 읽고 현재 신규 영업 범위로 적용하지 않는다. 기존 계약·약속과 실제 계약·청구·권리 주체, 다른 브랜드 역할을 변경하는 결정은 아니다.

2026-10-06 PATH 확장 방향: 방문·문화 체험을 나라별 개인화 여행으로 강화한다. 여행자의 조건에 맞는 식당·숙소·경험·일정과 제휴 운영 연결은 PATH, 공통 Atlas 기술은 SYNK가 맡는다. 새 브랜드·법인 신설 없이 [개인화 여행 설계](PATH_개인화여행_설계.md)에서 구체화하며, 출시 국가·가격·예약 운영은 미확정이다.

## 내부 미래사업개발실

2026-10-12 사용자 확정: **SYNK NEXT(미래사업개발실)**를 미공개 시스템·제품·사업을 연구하고 개발·검증·사업화하는 내부 부서로 둔다. 첫 사업은 **개인화 돌봄 AI 로봇**과 **AI 개인화 쇼핑 플랫폼**이다. 공통 Atlas 기술은 SYNK가 관리하고 NEXT가 제품 개발과 검증을 맡는다. 기존 네 브랜드와 고객 약속은 유지하며, 판매·운영 담당과 계약 주체는 사업화 시 별도로 정한다.

**대외 비공개.** 부서·두 사업의 상세 역할, 개발 순서, 미확정 사항과 공개 경계는 [NEXT 내부 원문](_ops/NEXT/README.md)에서 관리한다. 이 항목을 홈페이지·공개 조직도·SNS·영업 자료에 옮기지 않는다. 이번 결정은 별도 법인·공개 브랜드 설립이나 제품 출시가 아니다.

## 4. 소유권 규칙 — 중복을 막는 네 줄 (v1.5 에 한 줄 늘었다)

같은 대상이 여러 조직에 걸칠 때는 이 규칙으로 판정한다:

1. **LAB은 기록을 만든다** (데이터·내부): 성장 기록·포트폴리오 데이터의 원본 소유.
2. **PULSE는 만들고 내보낸다** (제작·외부 공개): 🆕 v1.5 에서 넓어졌다 — 학원 기록을 콘텐츠로 만드는 활동 **그리고** 기록 없이 태어나는 창작물(노래·가상 가수·드라마)까지.
3. **IP는 자산으로 등재한다** (등기부): 반복 사용·판매·라이선스 가능한 형태로 축적.
4. 🆕 **SHIFT는 방법을 판다** (대외 판매·검정): IP 에 쌓인 자산을 밖에 파는 활동. 자격 검정도 여기.

> **09-07 계약·정산 계획 이력 — 돈은 SHIFT로 들어오게 한다**(당시 사용자 확정 「수익은 synk shift로 들어오게 만들게」).
> PULSE 가 만든 것에서 나오는 수익 전부가 그렇습니다 — 곡·영상·드라마·가상 가수·고객사 광고.
> 당시 **계약서·청구서·정산의 이름을 SHIFT로 둔다는 계획**이며, 실제 명의와 권리는 준비된 법적 주체·기존 계약으로 확인합니다.
> 09-15 현재 광고 문의·제작은 PULSE로 안내하며, 이 계약·정산 계획을 브랜드 문의 창구의 제한으로 적용하지 않습니다.
> 🔑 **곁딸린 이득이 하나 있습니다** — 41류에 「싱크펄스(SYNCPULSE)」가 등록돼 있는데(09-07 실측 ·
> `docs/상표_선점_실행지.md` §2-b), PULSE 라는 이름이 **파는 자리에 서지 않으면** 그 등록과 부딪히는 면이 줄어듭니다.
> ⚠ **안 덮이는 자리 하나** — 음원 유통사에 곡을 올릴 때의 **레이블·아티스트 이름**은 스포티파이·유튜브 뮤직에
> 그대로 걸립니다. 거기에 PULSE 를 적을지는 첫 곡을 낼 때 따로 정합니다.

적용 예 —
- **포트폴리오**: 데이터 = LAB Record · 발신 = PULSE Student Story.
- **브랜드**: 자산(로고·세계관) = IP Brand IP · 활동(브랜드 콘텐츠) = PULSE Brand Story.
- 🆕 **가상 가수**: **만드는 것은 PULSE, 소유는 IP Brand IP** 다. 캐릭터·목소리·세계관은 나중에 빌려주거나 팔 수 있는 자산이라 등기부에 올린다. 이 한 줄을 안 적어 두면 나중에 「이 캐릭터가 누구 것이냐」가 학원 하나에 묶여 버린다(§3-1 이 IP 를 브랜드 밑에 안 넣는 바로 그 까닭).
- 🆕 **라디오에 깔 곡**: 만드는 것 = PULSE · 트는 곳 = LAB 의 학습 표면 · 곡 자체의 자산 등재 = IP Content IP. **한 물건이 세 칸에 걸치는 첫 사례**라 여기 적어 둔다.
- **고객사 광고·브랜딩**: 현재 광고 문의·제작은 PULSE, 교육·컨설팅·브랜딩은 SHIFT가 맡는다. 실제 계약·청구·정산 명의와 소유·이용권은 준비된 법적 주체 및 기존 계약에 따른다. 고객사 소유 납품물은 우리 IP 등기부에 올리지 않으며, PULSE의 광고 역할이 고객 소유 산출물을 우리 자산으로 바꾸지는 않는다.
