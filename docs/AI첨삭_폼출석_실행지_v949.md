## STEP 0. Claude API 키 준비 (유호님, 1회 · ~5분)

첨삭 기능의 유일한 외부 준비물. **키가 없으면 첨삭 배치는 조용히 스킵**되고 나머지(폼 출석)는 무관하게 작동한다.

1. 브라우저에서 `console.anthropic.com` 접속 → 구글 계정으로 가입/로그인
2. 좌측 메뉴 **API Keys** → **Create Key** → 이름 `SYNK-feedback` → 생성된 키(`sk-ant-…`)를 **복사**
3. 같은 화면의 **Billing**에서 결제 수단 등록 + 최소 크레딧 충전(예: $5 — 월 예상 사용액 $1~3 수준이라 수개월분)
4. Apps Script 편집기(구글시트 → 확장 프로그램 → Apps Script) → 좌측 **⚙️ 프로젝트 설정** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
   - 속성: `CLAUDE_API_KEY` / 값: 복사한 키 붙여넣기 → **저장**
5. ⚠️ 키는 이 스크립트 속성에만 두고, 채팅·문서·시트에는 절대 붙여넣지 않는다

## STEP 2. Glide 조립 (유호님 손 · ~15분)

> Glide 데이터 편집기에서 시트 재동기화(⟳) 후 진행 — `hw_feedback` 테이블과 profiles 새 열 3개가 잡혀야 한다.

**2-A. 출석 버튼 교체** (학생 홈)
- 기존 GPS 출석 컴포넌트(조립가이드 v947 §6-0) 자리에 **Button** 추가 → Label `✅ 출석하기` → Action **Open Link** → Data = profiles **출석폼URL**
- 학생 경험: 버튼 탭 → 폼 열림(ID 자동 입력) → [보내기] 탭 = 끝. 10분 내 attendance 반영·보드 표시
- GPS 컴포넌트는 폼 방식이 안정 확인된 뒤 삭제(1~2주 병행 가능 — 같은 날 중복은 엔진이 자동 스킵)

**2-B. 숙제 제출 버튼** (학생 홈 또는 숙제 카드 아래)
- **Button** → Label `✏️ 숙제 제출` → **Open Link** → Data = profiles **숙제폼URL**

**2-C. 첨삭 카드 화면** (학생)
- 학생 홈에 **Inline List** 추가 → Source `hw_feedback` → Filter: `student_id` is `user's user_id` **AND** `상태` is `노출`
- 리스트 아이템: Title=`제출일`, Detail=`고친문장`
- 상세 화면 구성(위→아래): `제출문`(내가 쓴 문장) → `고친문장` → `오늘의포인트`(몽골어) → `칭찬` → `다음미션`
- 상세 화면 맨 아래 **Button** `👌 확인했어요 (+5P)` → Action **Set Column** → `학생확인` = **Current date/time** → Visibility: `학생확인` is empty
- 홈 배지(선택): Notice/Hint 컴포넌트 `📬 새 첨삭이 도착했어요!` → Visibility: profiles `새첨삭수` is not empty

**2-D. 원장 검수함** (원장 탭 — AUTOPUBLISH 켜기 전까지)
- 원장 화면에 **Inline List** → Source `hw_feedback` → Filter: `상태` is `대기`
- 상세 화면에서 `상태`를 **Choice**(옵션: 대기/노출)로 편집 허용 → 내용 확인 후 `노출` 선택 = 학생에게 공개
- (시트에서 I열을 직접 바꿔도 동일하게 동작)

## STEP 3. 작동 검증 체크리스트 (첫 주)

- [ ] 학생(테스트 계정)이 출석 버튼 → 폼 제출 → **10분 내** attendance에 `출석(폼)` 행 + 출결 보드 시각 표시
- [ ] 숙제 제출 → **다음날 아침** 원장 브리핑 메일에 "🤖 AI 첨삭 N건 생성" + hw_feedback에 `대기` 행
- [ ] 검수함에서 `노출` 전환 → 학생 앱에 카드 표시
- [ ] `확인했어요` 탭 → **10분 내** +5P (`첨삭확인`) 지급 + 버튼 사라짐
- [ ] 몽골어 설명 품질이 2주간 안정적이면 Code.js `AI_FEEDBACK_AUTOPUBLISH`를 `true`로 → 검수 단계 생략(/deploy)

## 운영 메모

- **비용**: Sonnet 5 기준 첨삭 1건 ≈ ₩5~15. 30명×월 20건 ≈ 월 $2~6. 야간 상한 30건/일(`AI_FEEDBACK_MAX_PER_RUN`).
- **update 소비**: 폼 제출·첨삭 생성 = 인바운드 sync(묶음당 1)로 사실상 0. 유일한 아웃바운드는 `확인했어요` 탭(건당 1)과 검수 `노출` 전환(건당 1) — 30명 기준 월 수백 건 한도 내.
- **실패 시**: API 오류가 나면 그 행부터 멈추고 다음 밤 자동 재시도(제출 유실 없음). 원장 메일로 오류 통보.
- **회귀 장치**: `tests/safety.test.js`에 v9.49 테스트 6종(골격·지급 순서·키 스킵·포인터·사유 등록·트리거 편입) — /deploy 시 자동 검증.
