### ⏳ 유호님 몫 = DNS 한 번 (도메인 산 곳에서 ~2분)

`synk.im` 을 산 곳(가비아·GoDaddy·Cloudflare 등)에 로그인 → **DNS 설정**(DNS 관리·레코드 편집) 화면:

1. 지금 있는 **A 레코드 1개**(값 `118.67.131.217`)를 **삭제**
2. **A 레코드 4개**를 추가 — 호스트/이름 칸은 `@` 또는 비워 둠:

   | 종류 | 이름 | 값 |

   | A | `@` | `185.199.108.153` |

   | A | `@` | `185.199.111.153` |

1. `상담로그`에 실제 질문이 쌓이면 → **FAQ 정본의 가설 목록을 실제 질문으로 교체**합니다(지금 목록은 로그 0건 상태의 추정입니다).
2. 봇이 넘긴 질문 = **다음에 확정해야 할 것의 우선순위**입니다. 빈도순으로 정리해 드립니다.
3. 몽골어 답변 20건쯤 쌓이면 원어민 검수에 함께 넘깁니다(동의 문구 검수와 한 묶음).
