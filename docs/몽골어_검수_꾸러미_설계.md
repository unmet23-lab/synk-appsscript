## 1. 판정 — 구글 시트 한 벌 + 몽골어·영어 병기 안내 + 자동 회수

### 채택안

**검수자가 받는 것은 링크 하나다.** 구글 시트 한 벌이고, 그 안에 안내도 진행률도 다 있다.
별도 문서를 안 연다. 채우면 우리가 **기계로** 회수한다.

### 왜 구글 시트인가 — 근거 넷

1. **검수자가 이미 아는 도구다.** 이게 가장 큰 근거다. 새 도구를 배우게 하는 것 자체가
   유호님이 말한 「대충 던지는 것」의 한 형태다 — 우리가 편한 형식을 주고 학습 비용을 상대에게 떠넘기는 것.
2. **우리 인프라가 이미 시트다.** Apps Script 가 시트를 읽고 쓴다(`Code.js`·`엔진_운영배치.js` 전부).
   회수 배선에 **새 인프라가 0**이다.
3. **모바일에서 된다.** 몽골 프리랜서 작업 환경을 우리가 모른다 — 폰만 있어도 돌아가는 쪽을 고른다.
4. **되돌림이 싸다.** 시트는 판 이력이 있어 검수자가 잘못 지워도 복구된다. md 파일엔 그게 없다.

### 기각한 후보

| 후보 | 왜 기각 |
|---|---|
| **웹 검수 콘솔 신축** | UX 는 최고다. 그런데 인증·호스팅·배포가 새로 필요하고, **검수자가 0명인 지금** 그 인프라를 세우면 검수자 오는 날까지 놀면서 낡는다. 앱 안 검수 화면(`talk/src/검수화면.js`)은 **AI 교정 검수**용이라 대상이 다르다 — 재사용이 아니라 신축이다 |
| **워드·PDF 로 주고받기** | 벽 ④가 그대로 남는다. 받는 모양이 매번 달라 회수가 영구히 손일이다 |
| **md 그대로 + 안내만 번역** | 벽 ②③이 안 풀린다. 마크다운 표를 못 여는 것은 안내를 번역해도 못 연다 |

### 🔥 도전안 (병기 — 채택 아님)

**표를 주지 않고 «대화»로 받는다 — 텔레그램 봇이 한 조각씩 보내고 검수자는 답장만 한다.**

발주서가 이미 「연락 창구 = 텔레그램」이라 적었고, 몽골에서 텔레그램은 일상 도구다. 학습 비용이
**0**이다(답장은 이미 할 줄 안다). 진행률·회수가 자동으로 따라온다.

그런데 **지금은 채택하지 않는다**: 21~35조각짜리 표를 대화로 받으면 되돌아가 고치기가 어렵고
(검수는 앞 문장을 보며 뒤를 맞추는 일이다), 봇 인프라가 새로 필요하다.
**다만 §E(정기 감수 — 주 1회 20건)는 대화형이 더 맞다** — 그건 표가 아니라 흐르는 물량이고,
매주 시트를 새로 여는 것보다 답장 한 번이 싸다. ⏳ **유호님 자리**(§7-③).

## 2. 검수자 여정 — 다섯 걸음, 각 걸음의 인수 조건

> 원칙: **한 걸음에서 막히면 그 뒤는 전부 안 일어난다.** 그래서 걸음마다 「막히지 않았음」을 무엇으로 아는지 적는다.

### 걸음 1 — 받는다

받는 것 = **링크 1개 + 메시지 3줄**(텔레그램). 첨부 파일 없음, 다운로드 없음.

- 🔑 발주서 36KB 를 먼저 보내지 않는다. 그건 **유호님이 사람을 고를 때 쓰는 문서**이지
  뽑힌 사람이 매번 여는 문서가 아니다. 뽑힌 뒤에 필요한 것은 「오늘 무엇을 하면 되는가」다.
- 인수: 링크를 눌러 시트가 열린다(로그인 없이 볼 수 있게 링크 공유 · 쓰기는 계정 지정).

### 걸음 2 — 이해한다 (5분 안에)

시트 **첫 탭 = `Эхлэх`(시작)**. 여기서 안 넘어가면 나머지가 안 열린다.

- **몽골어 + 영어 병기.** 한국어는 원문 대조용으로만 남기고 안내에는 안 쓴다(벽 ①).
- 첫 줄에 이것을 적는다 — 🔑 **이 안내문 자체가 어색하면 알려 주세요.**
  발주서 §0 이 이미 쓴 수법이다(「이 글을 고쳐서 답하는 사람이 우리가 찾는 사람이다」).
  안내문의 몽골어는 **미검수 AI 초안**이라 이 한 줄이 정직성이자 판별법이다.
- 담는 것 넷: ⓐ우리가 사는 것은 번역이 아니라 「울란바토르 학부모가 읽었을 때의 느낌」이다
  ⓑ고칠 게 없으면 그대로 두는 것도 답이다 ⓒ애매하면 「애매」로 표시하고 넘어가도 된다
  ⓓ **중괄호 `{이름}`·`{N}` 는 손대지 않는다**(실제 이름을 적으면 모든 학부모에게 같은 이름이 나간다).
- 인수: 검수자가 첫 조각을 채우기까지 **다른 문서를 안 연다**.

### 걸음 3 — 작업한다

탭 하나 = 묶음 하나(A 동의서 / L 게임문항 / M 학부모메일 …). **한 행 = 한 조각.**

| 열 | 이름(mn) | 누가 | 비고 |
|---|---|---|---|
| A | `№` | 기계 | 회수 열쇠 — **검수자가 안 건드린다** |
| B | `Солонгос эх`(한국어 원문) | 기계 | 대조용. 한국어를 모르면 C 를 본다 |
| C | `AI ноорог`(AI 초안) | 기계 | **미검수 기계 번역**임을 열 머리에 적는다 |
| D | **`Монгол — баталгаажсан`**(몽골어 확정) | **검수자** | **여기만 채운다.** 비면 코드에 안 들어간다 |
| E | `Итгэлтэй эсэх`(확신도) | 검수자 | `Тийм`(확실) / `Эргэлзээтэй`(애매) 드롭다운 |
| F | `Тайлбар`(왜 고쳤는지) | 검수자 | 한 줄. 선택 |

- 🔑 **D 열이 비면 「통과」가 아니라 「미작업」이다** — 검수표 2벌이 이미 그렇게 못박았고 그 규칙을 그대로 승계한다.
  AI 초안을 그대로 쓰겠다면 **D 로 옮겨 적는 것**이 확정 행위다(읽지 않은 문장은 확정이 아니다).
- 자리표시자 보호: `{…}` 가 B 에 있는데 D 에 없으면 **셀이 붉게 선다**(조건부 서식). 검수자가 실수로 이름을 적어 넣는 것을 그 자리에서 잡는다.
- 인수: 검수자가 「지금 어느 칸을 채워야 하나」를 묻지 않는다.

### 걸음 4 — 진행을 본다

`Эхлэх` 탭 위쪽에 묶음별 **`채운 수 / 전체`** 와 막대. 수식이라 자동이다.

- 🔑 이건 우리를 위한 게 아니라 **검수자를 위한 것**이다. 182조각(§5)을 한 번에 보면 압도되지만
  「M: 21 중 13」은 끝이 보인다. 끝이 보이는 일과 안 보이는 일은 다른 일이다.
- 인수: 검수자가 「얼마나 남았어요?」를 묻지 않는다. 우리도 묻지 않는다(㉡ — 물어보는 것도 사람 손이다).

### 걸음 5 — 우리가 회수한다 (사람 손 0)

`node tools/검수회수.js` 한 번 → 시트 → JSON → 코드 상수/팩.

- **사람이 누르는 칸은 검수자의 「확정」 하나뿐이다**(CLAUDE.md 역할 §「수집은 엔진 도달까지가 한 벌」).
- 🔴 **회수기가 없으면 이 설계는 미완성이다.** 벽 ⑤가 그대로 남고 게이트 ④「닿았나」가 ✗다 — §4.

## 3. 꾸러미는 «생성»한다 — 손으로 만들지 않는다

검수 대상은 **지금도 늘고 있다**(08-12 하루에만 L·M 두 묶음이 새로 섰다). 시트를 손으로 만들면
만든 날 낡기 시작한다. 그래서 **꾸러미 생성기**를 둔다.

```
정본(코드·검수표·문서)  →  node tools/검수꾸러미.js  →  묶음별 TSV + 안내문
                                                        ↓ (구글 시트에 붙여넣기 / 가져오기)
                                                     검수자가 채운다
                                                        ↓
                              node tools/검수회수.js  →  코드 상수·팩·JSON
```

- 🔑 **TSV 로 낸다**(CSV 아님) — 검수 문장에 쉼표가 흔하고, 탭은 안 흔하다. 구글 시트는 TSV 붙여넣기를 그대로 표로 편다.
- 🔑 **생성기는 정본에서 판다** — 검수표 md 를 다시 베끼지 않는다. 베끼면 그 순간 두 벌이 되고
  갈라지는 방향은 조용하다(CLAUDE.md 가드 맹점 ④: 같은 판정을 두 곳에 적으면 목록이 갈린다).
- ⚠ **이미 사람이 공들여 만든 검수표 2벌은 버리지 않는다** — 그 판단(무엇을 왜 조각내는가 · G1 v2 의
  「세부는 틀과 한 덩어리」)은 기계가 못 낸 것이다. 생성기는 **그 표를 읽어** TSV 로 편다.

### ⚠ 반박이 잡은 것 — md 표 파싱은 «깨지라고 생겼다» (자기 반박 1패스 · 층 = 컨텍스트 독립 아님)

생성기가 md 표를 읽는다면 구분자가 `|` 인데, **검수 대상 문장 안에 `|` 가 실제로 들어 있다** —
`주간리포트_몽골어_검수표.md:36` 이 `TAG_MN[t] \|\| t` 를 이스케이프해 담고 있다.
소박한 `split('|')` 은 그 행에서 열이 밀리고, **밀린 결과는 오류가 아니라 「이상한 문장」**이라
검수자에게 그대로 나간다(새는 방향이 조용하다).

→ 처방 셋을 규격에 못박는다: ①`\|` 이스케이프를 먼저 되돌린 뒤 자른다 ②열 수가 머리와 다르면
**그 행을 건너뛰지 말고 세워서 알린다**(건너뛰면 조각이 조용히 사라진다) ③생성기는 **낸 조각 수를
정본의 선언값과 대조**한다 — M=21·L=35 가 안 맞으면 빨개진다(회귀가 그 숫자를 문다).

## 4. 회수 배선 — 게이트 ④「닿았나」를 여기서 통과시킨다

| 묶음 | 확정된 것이 앉을 자리 | 회수 모양 |
|---|---|---|
| **M** 학부모 메일 21 | `엔진_운영배치.js` 고정 문안 + `TAG_MN` 매핑 | 상수 치환 (Apps Script) |
| **L** G1 문항팩 35 | `talk/contents/교수멘탈문항.js` 의 `mn` + `검수확정 = true` | 팩 개정 1커밋 |
| **A** 동의문 | `talk/contents/문구_동의.js` 의 빈 `mn` 2칸 | 상수 치환 |
| **I** 제도 명칭 4 | 대외 문구 전반 | 낱말 장부 |
| **K** 인쇄물 94칸 | `docs/인쇄본/*_src` | ⚠ `_src` 재갱신 🚫(메모리 marketing-philosophy-overhaul) — **인쇄 판만** |
| **B·C** 챗봇 | 상담 AI 지식 | 지식 파일 |

- 🔴 **L 은 회수가 「상수 치환」으로 안 끝난다** — `검수확정 = false` 게이트가 같이 열려야 하고,
  그건 **문항판 인상과 한 벌**이다(메모리 minigame ⓒ). 회수기는 그 셋을 **한 커밋으로** 낸다(F302).
- ⚠ **회수기는 D 열이 빈 행을 조용히 건너뛰지 않는다** — 몇 행이 비었는지 **숫자로 낸다**.
  「초록은 분모와 함께만 읽는다」(CLAUDE.md 신뢰성) — 0건 회수와 전건 회수가 같은 모양이면 그 도구는 있으나 마나다.

### ⚠ 반박이 잡은 것 — 「시트를 기계가 읽는다」에 배선 벽이 하나 있다

회수기가 구글 시트를 **직접** 읽으려면 그 계정의 API 자격이 필요하다. 그런데 시트가 설
계정(§7-①)과 도구가 도는 자리가 같다는 보장이 없다. 이걸 안 적으면 「회수 자동」이 설계에만 있고
검수자 오는 날 손일로 되돌아간다(그게 정확히 벽 ⑤다).

→ **회수를 두 갈래로 낸다. 기본은 자격증명이 필요 없는 쪽이다.**
  - **㉠ 붙여넣기 회수(기본 · 지금 선다)** — 검수자가 다 채우면 시트에서 **전체 선택→복사**해 온
    TSV 를 파일로 저장하고 `node tools/검수회수.js <파일>`. 자격 0 · 계정 0 · 지금 구현 가능.
  - **㉡ API 회수(나중 · 계정 정해진 뒤)** — 같은 회수기에 입력만 갈아 끼운다.
    🔑 **파싱·치환·대조는 ㉠㉡이 같은 코드를 쓴다** — 갈래를 입력 한 곳에만 두면 나중에 ㉡을 붙여도
    회수 규칙이 두 벌로 안 갈린다.

## 6. 회차 — 무엇을 먼저 주나

| 회차 | 묶음 | 조각 | 왜 이 순서 |
|---|---|---|---|
| **1회차** | **M + L** | 56 | 둘 다 **표가 이미 조립돼 있고**(사람이 공들인 판) 초안 규칙이 갈린다는 것까지 정리됐다. 그리고 **막고 있는 것이 가장 크다** — L 은 게임 문항이 학생에게 한 개도 안 나가는 `검수확정=false` 게이트, M 은 매주 자동으로 나가는 메일이 아직 한국어인 자리 |
| **2회차** | **A + I + B** | ~9 | 짧고, A 는 소급 불가라 신중해야 한다. I 는 10~15분 |

🔑 **1회차를 M+L 로 묶는 근거는 발주서가 이미 적었다** — 「병목은 선생님 한 분이고, 따로 부르면
같은 병목을 두 번 겪는다」(§M 머리말). 그 논리를 회차 전체로 확장한 것뿐이다.
