# 영업 명단

> 2026-09-18 · 누구에게 무엇을 보냈고 답이 왔는지 한 곳에 적는다. 브랜드별 대상과 제공물은 [마케팅 정본](마케팅_정본.md)을 따른다.

## 적는 규칙

- 한 줄에 상대 기관·회사 하나를 적는다. 같은 곳에 다른 브랜드로 연락하면 줄을 나눈다.
- 개인 이름·이메일·전화번호는 적지 않는다. 창구는 부서·직함으로 적고, 연락처 원본은 메일함과 연락처 앱에 둔다. 되찾을 때는 「메일 찾는 말」 칸의 메일함 검색어를 쓴다(예: `to:@example.ac.kr 협력`).
- 실제로 연락한 사실만 적는다. 계약·협약이 없는 곳을 제휴처로 적지 않으며, 이 명단을 대외 자료의 고객·협력 사례로 쓰지 않는다.
- 계약·청구 주체는 건별로 확인한다([조직과 권리](조직계보_정본_v1.md)).
- 다음 할 일에는 날짜를 붙인다. 날짜가 지난 줄부터 챙긴다.

**상태:** 찾음(연락 전) → 연락함 → 답 옴 → 만남 → 제안함 → 계약. 중간에 멈추면 멈춤, 거절이면 거절.

## 브랜드별 영업 상대

| 브랜드 | 상대 | 제안할 것 |
|---|---|---|
| SHIFT | 특정 업무에 개인화를 도입하려는 기업·기관 | 한 업무의 개인화 서비스 도입·운영. 교육·컨설팅은 도입을 지원하며 반복 공급 검증 뒤 API·엔진 라이선스로 확장 |
| PATH | 교육기관·외국인 인재 채용 기업, 방문·체류 및 개인화 여행의 협력 후보 | 유학·취업 준비, 주거·정착·방문 체험과 개인화 여행. 실제 소개·제휴·예약 범위를 건별 확인하며 독립 마케팅 채널은 만들지 않음 |
| PULSE | 광고·모델 영상을 의뢰하는 브랜드, 작품·IP 협력사와 이용처 | 의뢰 광고·브랜드필름·AI 모델·룩북 제작과 자체 콘텐츠·IP 협업. 공간·장비 대여는 준비 상태를 확인한 범위만 안내 |
| LAB | 학교·기관 제휴 | 과정 안내 (상담 폼의 인지채널 「학교제휴」와 같은 갈래) |
