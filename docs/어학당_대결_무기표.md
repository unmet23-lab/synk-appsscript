## 2. 🔴 어학당이 「기본으로」 주는 것은 정확히 무엇인가

유호님 물음: **「어학당이 제공하는 범위가 TOPIK 자격증으로 어디까지 기본인가.」**

답: **어학당은 TOPIK 급수를 «하나도» 주지 않는다.** 어학당이 주는 것은 **자기 학교 이름이 박힌 수료증**이다.

### ㉠ 두 사다리는 다른 물건이다

| | 대학 부설 한국어학당 | TOPIK |
|---|---|---|
| 주는 이 | **각 대학이 따로** (연세·고려·이화가 다 다름) | 교육부 국립국제교육원 **하나** |
| 매기는 법 | 출석 + 시험 + 과제 (연세: 출석 **80%** 이상이라야 진급) | **시험 1회 점수만** |
| 한 급수에 걸리는 시간 | **10주 200시간** | 하루 |
| 유효기간 | 없음 | **2년** |
| **법무부 문서에서** | **안 쓰임** | 쓰임 |

### ㉡ 학교가 스스로 부인한다

연세대 한국어학당은 자기 홈페이지에 학당 급수와 TOPIK 급수 대응표를 올려 두었다. 그 표에서 **학당 3급은 「TOPIK 2급 또는 3급」**이다. 그리고 표 밑에 이렇게 적었다.

> 「※ 위는 **대략적인 레벨이며, 실제 시험 점수를 보장하지 않습니다.**」

같은 학교가 반대 방향도 못박았다.

> 「**TOPIK 성적은 한국어학당 급수 배정에 반영되지 않습니다.**」

### ㉢ 그래서 어학당 4급 수료증으로 할 수 있는 일

| 하고 싶은 것 | 어학당 4급 수료증으로 되나 |
|---|---|
| 아르바이트 주 25시간 | ❌ **안 된다** (법무부 목록에 없다) |
| 제조업 아르바이트 | ❌ 안 된다 |
| 구직비자 D-10 점수제 면제 | ❌ 안 된다 |
| 거주비자 F-2-R | ❌ 안 된다 |
| 요양보호사 → 취업비자 | ❌ 안 된다 |
| 사회통합프로그램 단계 배정 | ❌ 안 된다 |
| **그 대학 학부 입학** | ⭕ **된다** (그 학교 안에서만) |
| **다른 대학 입학** | △ 학교마다 다르다. 연세대는 자기 학당만 인정한다 |

> 🔑 **한 줄**: 어학당 수료증은 **그 학교 담장 안에서만** 통한다. 담장 밖으로 나가는 순간 0원이다.

## 3. 🔴 그럼 TOPIK 4급까지 가려면 추가로 얼마가 드나

### ㉠ 서울 상위권 어학당은 TOPIK 대비를 «따로 판다»

🔴 **이 절에는 반드시 「서울 주요 대학 기준」을 붙인다.** 지방 어학당 넷(배재대·계명대·영남대·조선대)은 TOPIK 대비를 **수업료 안에 넣고 그것을 광고한다.** 단서 없이 「어학당은 TOPIK 대비를 따로 판다」고 쓰면 그 넷이 통째로 반박한다.

| 경희대 한국어센터 | 듣기 / 읽기 / 어휘문법 각각 · 쓰기 | 각 **150,000원** · 쓰기 **250,000원** (넷 다 사면 **700,000원**) |
| 성균관대 | TOPIK 특강 2주 6회 | 중급 **120,000원** / 고급 **160,000원** |
| 서울대 | TOPIK 준비반(3·4급 / 5·6급) | 유료 (금액 미공시) |
| 중앙대·성신여대·청주대 | 정규과정 안내에 TOPIK 항목이 **없다** | 확인 못 함 |

|---|---|

**TOPIK 응시료도 학생 몫이다** — 4만~9.5만원(PBT/IBT). 떨어지면 또 낸다.

## 7. 🎯 실제로 쓸 공격 문안

### 문안 ① — 「담장 밖에서 0원」

>

### 문안 ② — 「학교가 직접 말합니다」

> 연세대 한국어학당 홈페이지에 이렇게 적혀 있습니다.
> **「TOPIK 성적은 한국어학당 급수 배정에 반영되지 않습니다.」**
> 그리고 학당 급수와 TOPIK 급수를 견준 자기 표 밑에는 이렇게 적었습니다.
> **「대략적인 레벨이며, 실제 시험 점수를 보장하지 않습니다.」**
>
> 어학당은 **학교가 주는 성적표**입니다. TOPIK은 **나라가 주는 자격증**입니다.
> 비자도, 아르바이트도, 취업도 나라가 주는 쪽만 봅니다.

### 문안 ③ — 「누가 값을 내는가」

### 문안 ④ — 「정부가 요구하는 최저선」

## 8. ⚠ 공격할 때 반드시 지킬 것 넷

1. **「서울 주요 대학 기준」을 꼭 붙인다.** 1,700만원은 서울 상위권에 원룸일 때만 맞다. 가장 싼 길은 조선대 690만원이고, 몽골 학생이 가장 많이 가는 신한대는 705만원이다(§4 표). 이 단서를 빼면 상대가 「우리는 안 그렇다」로 통째로 반박한다.
   🔴 **「신한대·가천대는 1년 520~560만원」이라고 쓰면 안 된다.** 그것은 **학비만** 센 값이고, 기숙사를 넣으면 신한대 705만원 · 가천대 872만원이다. 우리에게 불리해 보이지만 정확한 값을 써야 반박을 막는다.
2. **어학당 값에는 비자가 들어 있다.** 우리는 그것을 못 판다. 값만 견주면 정직하지 않고, 들키면 신뢰가 통째로 날아간다.
3. **감정을 넣지 않는다.** 「사기」·「돈만 받는다」 같은 말은 쓰지 않는다. 숫자와 인용만으로 이긴다.
4. **맺는 말은 항상 문안 ⑨다.** 공격으로 열고 **안내로 닫는다.** 명품은 남을 깎아서 서지 않는다.
