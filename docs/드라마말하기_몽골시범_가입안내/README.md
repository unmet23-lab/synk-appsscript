## 어떻게 찍었나

운영 계정을 만들지 않았다. 브라우저는 로컬 서버 밖으로 나가는 요청을 막았고 막힌 요청은 0건이다.

- 1 · 2: 계정 포털 묶음을 합성 Auth 앞에 세운 리허설(`example@example.com`, 가짜 비밀번호). 화면의 `hello@synk.im`은 회사 공개 주소다.
- 3 · 4: WORLD 서버 계정 모드 + 가짜 계정 API(`experiences/synk-world-app/qa/account-browser.test.mjs` 꼴). 「나」 머리에 이름 · 메일 · 계정 id가 보이지 않는다. 4번 아래 「우리 반 수업」 칸은 몽골어 화면에서도 한국어로 나와 그림에서 잘랐다.
- 5 · 6: 드라마 틀 시험 `experiences/drama/qa/WORLD올리기-20261102/틀시험.mjs`(합성 부모 창 · 가짜 마이크), 화면 언어 mn.
