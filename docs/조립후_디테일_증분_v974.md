**중단 사유**: Glide 편집기 탭이 백그라운드(`visibilityState: hidden`)가 되면 크롬이 렌더링을 멈춰 **스크린샷 캡처가 타임아웃**되고, 그러면 클릭 좌표를 검증할 수 없다(캡처 폭÷innerWidth로 배율을 매번 재계산해야 하는데 캡처가 안 됨). 검증 없이 클릭하면 메모리 `glide-remote-assembly`에 기록된 오폭 사고(컴포넌트 통째 교체·인접 항목 삭제)가 재발한다.
**재개 조건**: Glide 편집기 탭을 **화면 앞에 둔 채로**(다른 탭·다른 창으로 전환하지 않고) 두면 이어서 자동 진행 가능.

**이번 세션에서 확립한 조립 요령(다음에 그대로 씀)**
- 새 컴포넌트는 항상 **목록 맨 아래**에 생긴다. 위치 이동은 우클릭 → Move Up/Down 반복이 아니라 **Cut(Ctrl+X) → 목표 위치 컴포넌트 선택 → Paste(Ctrl+V)** 가 빠르다 — **Paste는 선택한 컴포넌트 "앞"에 삽입**된다(실측). 18칸 이동이 2클릭으로 줄었다.
- 같은 유형 카드를 하나 더 만들 땐 **우클릭 → Duplicate**(바로 아래에 복제) 후 CONTENT만 교체가 가장 빠르다.
- CONTENT 바인딩: 토큰칸 우측 ⋮⋮ → **Search 칸을 반드시 클릭한 뒤** 타이핑(자동 포커스 아님 — 안 누르면 입력이 통째로 유실된다) → 결과에서 **`profiles` 그룹**(실값 미리보기 있는 쪽) 선택. `User profile` 그룹은 다른 것.

## 1. 학생 홈 — 숙제·퀴즈 카드 교체 (STEP 1)

1. ~~기존 숙제 조각 삭제~~ → **역순 권장**: 새 카드를 먼저 만들어 렌더를 확인한 뒤 옛 조각을 지운다(중간에 멈춰도 화면이 비지 않는다).
2. ✅ **완료됨** — 액자HTML 뒤에 **Rich Text ← profiles `숙제카드HTML`**(DH112).
3. ⬜ **이어서 할 일 ①**: 그 아래 **빈 Rich Text**(숙제 카드 복제본)를 선택 → CONTENT ⋮⋮ → Search 클릭 → `퀴즈카드` → **profiles 그룹**의 `퀴즈카드HTML`(DI113) 선택.
4. ⬜ **이어서 할 일 ②**: 옛 조각 4개를 위에서부터 삭제 — `Title` · `Text 내숙제` · `Text 내숙제팁` · `Text 오늘의퀴즈문제`. 각각 **좌클릭으로 먼저 선택해 우측 패널에서 정체 확인** 후 라벨 글자 위에서 우클릭 → Delete(메모리 규칙: 우클릭 Delete는 커서 y 기준이라 인접 항목 오폭 위험).
5. 버튼 **"🔮 정답 공개!"**는 유지하되 열어서 **Actions 목록 확인 → Show notification(오늘의퀴즈정답 CK89) 1개만 남기고 나머지 전부 삭제** ← 정답 칩이 2번 뜨던 원인.
6. 순서 확인: 숙제카드 → 퀴즈카드 → 🔮 버튼 → (첨삭 카드) → 나의 목표(드림한줄).

✅ 검증: Preview as 학생 계정 — ① 숙제 카드에 "📚 오늘의 숙제 / 유형 칩 / 할 일 / 👀 선생님이 이걸 봐요 / 제출 안내"가 **한 카드 안에** 보임 ② 퀴즈가 "🧠 오늘의 퀴즈" 제목의 **별도 카드**로 보임 ③ 🔮 버튼 탭 시 정답 토스트가 **1번만** 뜸 ④ 카드 어디에도 정답이 미리 보이지 않음.

## 2. 강사 출퇴근 — 중복 탭 차단 (STEP 2)

1. 강사 「출퇴근」 탭 — 출근/퇴근이 폼 버튼 1개(구분 Choice)라면 **폼 버튼 2개로 분리**(각각 구분 고정값 `출근`/`퇴근`, 이름=내 이름, 시각=제출시각).
2. Visibility 설정:
   - `출근` 버튼: **오늘출근(DK115) is empty**
   - `퇴근` 버튼: **오늘출근(DK115) is not empty** AND **오늘퇴근(DL116) is empty**
3. (선택) 상태 줄: 작은 Text "오늘 출근 " + DK115 (is not empty일 때만) · "퇴근 " + DL116 (동일).

✅ 검증: Preview as 강사 — 출근 탭 후(최대 10분 내) 출근 버튼이 사라지고 퇴근 버튼이 나타남. 하루 끝나면(자정 후 첫 스위프) 두 열이 비워져 다음 날 다시 출근 버튼만 보임.
ℹ 열 갱신은 10분 주기라 탭 직후 잠깐 버튼이 남을 수 있음 — 그 사이 중복 탭은 코드가 무해화(보드 = 첫 출근·마지막 퇴근, 응원 메일 = 당일 1회).
