4. 학생 행 ⋯ 메뉴에 Edit/Delete 남았으면 제거(보통 3에서 같이 꺼짐).
5. ✅ 검증: Preview as 강사 → 반 상세에서 Edit·+ Add·⋯ 편집이 전부 안 보여야 함. **같은 요령으로 출결·운영 탭의 행 탭 상세도 2단계 점검**(위 회귀 장치 체크리스트).

강사 로그인(또는 Preview as 강사)으로 **화면마다** 아래 2종 점검 — 학생·학부모 탭은 v9.69에서 완료, **강사·원장 탭이 미점검 잔여**(유호 07-28 "강사 Edit 가려달라" 확정):
1. **컬렉션 플래그**: 반 목록·학생 리스트·보드 등 모든 Collection → 우측 패널 Actions/Options에서 **Allow add/edit/delete 전부 OFF**.
2. **상세 화면 Title 액션**: 학생 상세·반 상세 등 Title 컴포넌트 → Action에 **Show edit screen이 걸려 있으면 None으로**.
3. 원장 탭도 같은 요령(원장은 유호님 본인이라 우선순위 낮음 — 시간 남으면).
