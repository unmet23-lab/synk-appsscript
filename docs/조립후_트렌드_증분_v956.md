## STEP 1. 시즌 패스 트랙 켜기 (시트 입력 1칸 — 개강 때)

1. 구글시트 → **app_state** 탭 → A열에서 **`시즌트랙입력`** 행 찾기 (내일 14시 계산 후 자동 생성됨. 없으면 맨 아래 행 A칸에 직접 `시즌트랙입력` 입력)
2. 그 행의 **B칸**에 아래 형식으로 입력:
   ```
   1|첫 목소리|2027-02-01
   ```
   (시즌 번호 | 시즌 이름 | 시작일. 칸막이는 세로줄 `|`)
3. 다음 계산(매일 14시·22시)부터 **전 학생 여정 카드 맨 위**에 8칸 트랙이 뜹니다. 8주차가 되면 자동으로 「🏁 승급 도전 주간」 + 시즌 랩업(공유용 기록 카드)이 붙습니다.
4. 시즌이 끝나고 다음 시즌을 열 때는 같은 칸의 숫자·이름·날짜만 바꾸면 됩니다. **비우면 트랙이 화면에서 사라집니다**(안전).

## STEP 2. 교실 스크린 모드 (Glide 조립 — 탭 1개, ~10분)

교실 TV/프로젝터용. 10분마다 자동 갱신되는 한 장짜리 라이브 보드(오늘 수업·등원 수·레이드 바·리그).

1. 구글시트 **profiles**에 스크린 계정 1행 추가: user_id `SYNK-SCR1` · 이름 `교실스크린` · role **`screen`** · email은 TV에서 로그인할 구글 계정
2. Glide → Layout → 하단 `+` → **Custom** 화면 → 라벨 「스크린」 → **표시조건 `role is screen`** (⚠ 생성 직후 바로 — 전원 노출 방지)
3. 컴포넌트 **Rich Text** 1개 추가 → Data = app_state → **`교실스크린HTML`** 키의 value (콕핏 카드와 같은 요령: app_state를 소스로 두고 key=교실스크린HTML 행의 value 바인딩)
4. TV의 브라우저에서 앱 열고 스크린 계정으로 로그인 → 「스크린」 탭 전체화면(F11)
