## STEP 1. 시즌 패스 트랙 켜기 (시트 입력 1칸 — 개강 때)

1. 구글시트 → **app_state** 탭 → A열에서 **`시즌트랙입력`** 행 찾기 (내일 14시 계산 후 자동 생성됨. 없으면 맨 아래 행 A칸에 직접 `시즌트랙입력` 입력)
2. 그 행의 **B칸**에 아래 형식으로 입력:
   ```
   1|첫 목소리|2027-02-01
   ```
   (시즌 번호 | 시즌 이름 | 시작일. 칸막이는 세로줄 `|`)
3. 다음 계산(매일 14시·22시)부터 **전 학생 여정 카드 맨 위**에 8칸 트랙이 뜹니다. 8주차가 되면 자동으로 「🏁 승급 도전 주간」 + 시즌 랩업(공유용 기록 카드)이 붙습니다.
4. 시즌이 끝나고 다음 시즌을 열 때는 같은 칸의 숫자·이름·날짜만 바꾸면 됩니다. **비우면 트랙이 화면에서 사라집니다**(안전).
