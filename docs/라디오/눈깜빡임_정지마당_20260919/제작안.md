# 해 질 녘, 작은 연

2026-09-19. 사용자가 라디오를 먼저 끄고, 고품질 정지 사진에 눈 깜빡임만 더한 장면을 적용·검토한 뒤 다시 켜 달라고 요청했다. 함께 고른 설정은 **해 질 녘 + 작은 연 하나**다. 현재 반영 상태와 확인 시점은 `manifest.json`을 따른다.

## 장면과 움직임

- 세 친구가 평상에 앉아 쉬는 기존 사진을 참조해 노을 조명으로 편집했다. 기준 원본은 `해질녘_원본.png`(1667×944)이며, ImageGen 생성 프롬프트를 원본과 함께 보관한다.
- 카메라, 몸, 털, 건물, 지면, 조명은 움직이지 않는다. 몽글의 수놓은 눈웃음은 그대로 둔다.
- 까몽은 1분에 다섯 번 짧게 깜빡인다. 눈을 감은 참고 그림을 생성하고, 그중 눈꺼풀만 원래 눈 윤곽에 맞춰 합성했다. 첫 공개 수신 화면을 확대해 보니 깜빡이는 도중에 눈동자가 비쳤다. 그래서 불투명한 눈꺼풀로 눈동자를 덮고, 눈이 완전히 닫힌 짧은 구간을 두도록 고쳤다. 첫 검토 파일은 `1차_수신검토/`에 보관한다.
- 마린은 원래의 노란 펠트 렌즈 안에서만 밝기가 짧고 약하게 바뀐다. 피부 눈꺼풀이나 동공은 새로 만들지 않는다.
- 작은 한지 연 하나가 먼 하늘에서 천천히 흔들린다. 꼬리는 연 아래쪽에 붙어 있고, 연줄은 담장 뒤로 이어진다. 폭죽이나 화면 전체가 번쩍이는 효과는 없다.
- 60초 주기로 정방향 반복한다. 0초와 60초의 합성 프레임은 같다. 합성 전후를 비교하면 눈과 연에 허용한 영역 밖에서 바뀐 픽셀은 0개다. 이 수치는 압축 전 기준이다.

## 파일과 재현

- `노을눈자산.py`: 눈꺼풀 참조 정렬, 원본 크기 합성, Real-ESRGAN general-x4v3 업스케일, 눈 영역 밖이 원본과 같은지 검사.
- `정지라디오.py qa`: 정지 컷과 영역 검사. `broadcast`: 1280×720·12fps·60초. `master`: 3840×2160·24fps·60초.
- 보관본은 **AI 업스케일 4K**다. 네이티브 4K로 생성했다거나 4K로 라이브 송출한다고 표시하지 않는다.
- 라이브 송출은 기존 서버 처리량에 맞춘 720p·12fps다. 승인된 음악, 재생 목록, 송출 엔진, 오버레이 각인, 조율은 그대로 둔다.

## 문구와 홈페이지

제목은 「SYNK Radio | 음악은 켜 두고 · lofi & chill」, 소개는 「일할 때도, 쉴 때도 가볍게 틀어두는 음악. / 몽글·까몽·마린과 해 질 녘 마당에서 잠시 쉬어가요.」로 맞췄다. 영어 소개는 `quiet moments`로 바꿨다. 실행 원본은 `bots/오버레이/라디오간판.js`다.

썸네일을 만드는 실행 원본 `tools/라디오썸네일지면.cjs`는 새 `최종정지컷.png`를 읽는다. 승인된 Paper 로고와 「음악은 켜 두고」는 그대로 둔다. YouTube 메타데이터는 API로 다시 조회해 확인했고, 공개 썸네일은 실제 이미지를 보고 확인했다.

홈페이지의 PULSE 라디오 카드와 `/listen/`에서 달빛 마당을 해 질 녘 마당으로 바꿨다. 공개 커밋은 `465101e4a9363096569bff850c1b676c65022268`이고, Pages 실행 `35436111626`은 성공했다. 공개된 두 파일은 배포 커밋과 바이트 단위로 일치한다. 390px 모바일 화면에서 문구 줄바꿈 문제와 가로 넘침이 없음을 확인했다. 홈페이지 정본 작업본의 모듈과 파생 HTML 두 개도 갱신했으며, 다른 작업의 미커밋 변경은 그대로 두었다.

## 반영과 검수

작업 순서는 송출 중지 → 자산 제작 → 꺼진 서버에 파일 반영 → 로컬 마감 검토 → 송출 시작 → 공개 수신 검토다. 공개 수신 검토에서 발견한 눈꺼풀 전환 문제는 송출을 다시 잠시 멈추고 고쳤다. 서비스는 삭제하거나 비활성화하지 않았다.

`송출반영.cjs`는 이번 교체를 실행하고 기록하는 도구다. 교체 직전에 해시를 대조하고 기존 파일을 백업한다. `마감검수.json`은 사용자가 요청한 이번 마감 검토의 기록이며, 공통 승인 절차를 새로 만든 것은 아니다.

`서버적용.json`, `송출재개.json`, `최종상태.json`, `공개수신.json`, `수신눈검수.json`을 함께 확인한다. 이전의 달빛 호흡 영상은 제작 이력과 복구용으로 남겨 두며, 자동으로 복원하지 않는다. 사용자의 멀미감이 해소됐는지는 아직 확인하지 않았다.
