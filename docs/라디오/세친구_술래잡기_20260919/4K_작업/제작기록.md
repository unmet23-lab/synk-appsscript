# 몽글 눈웃음과 4K 마감

2026-09-19. 사용자가 첫 H3 영상의 몽글 표정이 굳어 있다고 지적하고, 표정 개선과 4K급 화질을 요청했다.

## 표정

현재 DESIGN이 가리키는 `docs/캐릭터/정본_4K/몽글_눈웃음.png`와 생명감 설계의 국소 눈 변화 기준을 확인했다. 새 연출은 눈웃음 두 구간, 중간에 원래 구슬 눈을 뜨기, 낮은 점프와 몸 기울임이다. 입·코·팔·다리·볼 장식을 추가하지 않는다. 시작·끝 프레임은 기존 교정본을 유지했다.

H3 공개 워크플로에서 computer-use로 생성했다. 큐 2820, 히스토리 2822, 서버 원본 `2026_09_19_075815_jdg7l5.mp4`. 생성 결과는 1376×768, 48fps, 247프레임이다. H3의 사용자 지정 크기는 1MP 값으로 제한됐고, 최종 제출에는 16:9 / 1024p 프리셋을 사용했다. 4K 네이티브 생성으로 표시하지 않는다.

## 화질 비교와 출력

원본 프레임을 단순 Lanczos 확대, Real-ESRGAN x4plus, animevideov3, general-x4v3로 비교했다. animevideov3는 표면과 밑단을 지나치게 매끈하게 만들어 채택하지 않았다. x4plus는 작은 질감을 더 남기며 처리 시간이 길고, general-x4v3는 조금 더 부드럽지만 원본 색·눈 형태·밑단을 유지했다. 전체 영상에는 general-x4v3를 사용해 모든 원본 프레임을 4배 보정한 뒤 3840×2160으로 줄여 출력한다. 확대가 생성 원본에 없던 실제 섬유 정보를 복구한다는 뜻은 아니다.

원래 48fps와 247프레임을 그대로 유지하며 인위적인 프레임 보간은 하지 않는다. 추가 확대·중앙 크롭으로 정확한 16:9를 맞춘다. 음원은 제거하고 H.264 / yuv420p / CRF 16 / slow / faststart로 저장한다. 모델 런타임과 중간 프레임은 로컬 캐시에 있으며, 새 클라우드 업로드·구독·결제는 없다.

## 재현

- `H3_눈웃음_영상프롬프트.txt`: 실제 제출 연출.
- `prepare_general_model.py`: 공식 가중치를 pnnx로 로컬 NCNN 모델로 변환. 등록용 BasicSR 데코레이터만 제거하며 네트워크 계산은 공식 구현을 따른다.
- `render_4k.py`: 원본 프레임 추출, GPU 보정, 4K 무음 출력과 메타데이터 기록.
- `render-result.json`: 완료 뒤 실제 프레임 수·해상도·코덱·소요 시간.
