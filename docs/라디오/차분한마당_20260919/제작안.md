# 음악은 켜 두고

> 후속 변경: 사용자가 몸까지 고정한 사진과 눈 깜빡임, 해 질 녘·작은 연을 선택했다. 현재 장면은 [정지 마당 제작안](../눈깜빡임_정지마당_20260919/제작안.md)과 그 폴더의 manifest를 따른다. 아래는 이전 달빛 영상의 제작 이력이다.

2026-09-19. 사용자가 빠른 반복 영상에서 멀미감을 느낀다고 알려 와서, 달빛 마당에서 세 친구가 평상에 앉아 쉬는 장면으로 새로 만들었다. 이번 변경은 화면과 라디오 문구에만 해당한다. 공통 말투 규칙은 만들지 않는다.

## 장면

- 새 기준 이미지: ImageGen으로 만든 `세친구_쉬는마당.png`. 세 친구의 기존 정체성과 몽글의 눈웃음을 참조했다.
- 영상: 사용자가 지정한 CoNAI H3 화면에서 FL2VA로 생성했다. 시작과 끝 이미지가 같고 5초, 1376×768이다. 생성 기록은 2823이다. 원본은 247프레임·48fps다.
- 마감: 배경은 한 프레임으로 고정하고 캐릭터 영역의 움직임만 남겼다. 합성 원본에서 전체 1,056,768픽셀 중 904,833픽셀이 모든 프레임에서 같다. 이 수치는 압축과 업스케일 전에 검증한 값이다.
- 원본의 32~223프레임을 순방향으로 재생하고, 끝의 32프레임은 움직임을 0~31프레임에 맞춰 이어 붙였다. 24fps로 재생하면 한 바퀴가 8초다. 역재생은 쓰지 않았다.
- 보관본: 3840×2160·24fps, Real-ESRGAN general-x4v3 업스케일. 네이티브 4K로 생성한 것은 아니다.
- 송출본: 1280×720·12fps·72초. 기존 서버의 처리량을 유지한다. 별도의 마린 중복층은 계속 넣지 않는다.
- 소리: 기존에 승인된 음악 팩과 재생 목록을 그대로 쓴다.

제목·소개·검색어의 원본은 `bots/오버레이/라디오간판.js`, 썸네일의 원본은 `tools/라디오썸네일지면.cjs`다. 기존 `tools/라디오배경굽기.js --썸네일`도 새 장면을 다시 만들도록 연결했다. 채널 프로필이나 다른 SNS 작업은 수정하지 않는다.

## 검수와 반영 증거

현재 상태는 `manifest.json`을 따른다. `라이브반영.json`에는 서버 파일 해시, 백업, 실제로 열린 영상과 음악이 기록되어 있다. `유튜브반영.json`에는 제목·소개·검색어를 API로 다시 조회한 결과와 썸네일 업로드 응답이 있다. `공개수신.json`과 `최종상태.json`에는 실제 공개 수신과 방송 상태를 확인한 시점이 있다.

이전 3.5초 술래잡기 장면은 제작 이력과 복구용으로 보관한다. 사용자의 멀미감이 해소됐다는 판단은 사용자가 다시 확인하기 전까지 내리지 않는다.

## 홈페이지 동기화

PULSE의 라디오 카드와 `/listen/` 안내도 현재 제목과 소개에 맞췄다. 홈페이지 소스 `c5c2852`, 공개 `7bfc378`, Pages 실행 `35434695693` 성공. 기존의 다른 작업 변경은 그대로 두고, 라디오 문구가 있는 공개 파일 두 개만 게시했다. 빌드와 시험 79개가 통과했고, 두 파일의 공개 응답이 배포 커밋과 바이트 단위로 일치한다. 자세한 내용은 `홈페이지반영.json`을 참조한다.
