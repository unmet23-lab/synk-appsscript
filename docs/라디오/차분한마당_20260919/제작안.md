> 후속 변경: 사용자가 몸까지 고정한 사진과 눈 깜빡임, 해 질 녘·작은 연을 선택했다. 현재 장면은 [정지 마당 제작안](../눈깜빡임_정지마당_20260919/제작안.md)과 그 폴더의 manifest를 따른다. 아래는 이전 달빛 영상의 제작 이력이다.

2026-09-19. 사용자가 빠른 반복에서 멀미감을 느낀다고 알려, 달빛 마당에서 세 친구가 평상에 앉아 쉬는 장면으로 새로 제작했다. 이번 변경은 화면과 라디오 문구에 한정한다. 공통 말투 규칙을 만들지 않는다.

## 장면

- 새 기준 이미지: ImageGen, `세친구_쉬는마당.png`. 세 친구의 기존 정체성과 몽글 눈웃음 참조.
- 영상: 사용자가 지정한 CoNAI H3 화면에서 FL2VA, 같은 시작·끝 이미지, 5초, 1376×768. 생성 기록 2823. 원본 247프레임·48fps.
- 마감: 배경을 한 프레임으로 고정하고 캐릭터 영역만 남겼다. 합성 원본에서 총 1,056,768픽셀 중 904,833픽셀이 모든 프레임에서 동일하다. 이 수치는 압축·업스케일 전 검증이다.
- 원본 32~223프레임을 순방향 재생하고 끝 32프레임은 0~31프레임으로 움직임을 정렬해 연결했다. 24fps로 재생해 한 바퀴 8초. 역재생 없음.
- 보관본: 3840×2160·24fps, Real-ESRGAN general-x4v3 업스케일. 네이티브 4K 생성은 아니다.
- 송출본: 1280×720·12fps·72초. 기존 서버의 처리량을 유지한다. 별도 마린 중복층은 계속 제외한다.
- 소리: 기존 승인 음악 팩과 재생 목록 유지.

## 검수와 반영 증거

현재 상태는 `manifest.json`을 따른다. `라이브반영.json`은 서버 파일 해시·백업·실제 열린 영상과 음악을 기록한다. `유튜브반영.json`은 제목·소개·검색어의 API 재조회와 썸네일 업로드 응답이다. `공개수신.json`과 `최종상태.json`은 실제 공개 수신·방송 건강의 확인 시점이다.

이전 3.5초 술래잡기 장면은 제작 이력·복구용으로 보관한다. 사용자의 멀미감이 해소됐다는 판단은 사용자 재확인 전까지 내리지 않는다.
