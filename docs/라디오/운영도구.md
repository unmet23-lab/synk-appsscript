# 라디오 운영 도구

> 2026-10-17. 유호님 「라디오는 당분간 진행한다. 계속 유지할지, 방식을 바꿀지(일반 팝 대신 SYNK LAB의 한국어 학습 노래를 넣을지)는 아직 모른다.」 그때까지 아래 도구를 남긴다. 송출 코드와 설치 절차의 원문은 SYNK-talk `bots/송출/`과 talk README에 있다.

모두 유호님 PC의 저장소 뿌리에서 돌린다. 서버 접속 열쇠는 `~/.ssh/synk_radio`, 곡 팩 원본은 형제 폴더 `SYNK-talk/팩`·`팩2`다. 방식이 바뀌면 쓰지 않게 되는 도구는 그때 이 표와 함께 지운다.

| 하는 일 | 도구 | 어디서 |
|---|---|---|
| 서버 세우기·지우기(구글 클라우드 무료 등급) | `node tools/라디오서버세우기.js --점검`, `--세우기`, `--지우기` | PC |
| SSH 공개키 넣고 문 열기 | `node tools/라디오서버열쇠.js --붙이기` | PC |
| talk `.env`의 값을 서버로 옮기기 | `node tools/라디오자격넣기.js`(점검), `--넣기` | PC |
| 송출 설치·되돌리기(talk `개통.sh --설치`) | `node tools/라디오설치.js --설치`, `--걷기` | PC → 서버 |
| 곡 팩(.ts) 하나씩 올리고 크기 검산 | `bash tools/라디오팩올리기.sh <팩파일…>` | PC → 서버 `/home/synk/팩` |
| 팩이 다 올라가면 재생목록·설치까지 잇기 | `bash tools/라디오설치잇기.sh` | PC |
| 새 곡 더하기(인코딩 → 올리기 → 재생목록 → 송출 다시 켜기) | `bash tools/라디오곡더하기.sh <곡폴더> <팩폴더>` | PC |
| 방송을 끊지 않고 팩 갈아 끼우기 | `tools/라디오팩갈기.sh`를 서버에 올려 `bash /tmp/라디오팩갈기.sh <옛판폴더> <파일…>` | 서버 |
| 오버레이(`bots/오버레이`)와 DJ 그림 올리고 서버에서 구문 재기 | `bash tools/라디오지면올리기.sh`, `--재기만` | PC → 서버 |
| DJ 표정 세트를 1024 WebP로 줄이기 | `python tools/라디오DJ층작게.py` | PC |
| 무대 그림의 빛 자리(등·창·물) 재기 | `python tools/무대빛재기.py [무대이름 …]` | PC |

송출이 멈췄을 때의 복구 기록은 [송출 복구 20261005](송출복구_20261005/README.md)에 있다.
