# 라디오 곡 제목과 19곡 모음집 · 2026-09-27

> 후속 수정: 원래 SYNK 마크 복원, 제목 오른쪽 위 배치, 두 곡 개명 및 모음집 교체. 최신 제작·검증은 [revised/README.md](revised/README.md). 아래 첫 배포 검증 파일은 당시 이력이다.

[라이브](https://www.youtube.com/watch?v=mP3T7Sabeh4) · [일부공개 모음집](https://youtu.be/_eZztHpxPeI)

- 라이브 화면 오른쪽 위에 현재 곡이 상시 표시된다. FFmpeg 출력 시각과 곡별 시간표를 연결하므로 서비스 재시작과 전체 반복 때도 첫 곡부터 맞춘다.
- 현행 19곡을 같은 방송 음원·순서로 모아 58분 41초 영상으로 만들었다. YouTube 처리는 완료됐으며 일부공개다. 19개 시간 링크·챕터가 생성됐고, 03:26을 눌러 두 번째 곡으로 이동하는 동작을 확인했다.
- 라이브 설명란 맨 위의 모음집 링크도 실제 YouTube 페이지에서 확인했다.
- `public-final-transition.mp4`는 공개 YouTube에서 받은 55초 영상이다. 첫 곡에서 두 번째 곡으로 제목이 바뀌는 전후 화면을 확인했고, 수신 음원을 원본과 대조한 상관계수는 0.979 / 0.974다. 최종 서버 active, 재시작 0, 0.998배속, 프레임 누락/복제 0. 라이브 한 바퀴 전체를 장시간 관찰한 것은 아니다.
- `verification.json`은 최종 검증, `now-playing.json`은 실제 방송 시간표, `chapters.txt`는 모음집 설명란 시간표다. 새 8곡의 3초 크로스페이드와 기존 11곡의 6초 크로스페이드·첫 구간 잘림을 반영했다. `시티팝 1`은 `노을빛 드라이브`, `시티팝 2`는 `너와 걷던 여름밤`으로 개명했다.
- `youtube-before.json` / `live-description-after.json`은 설명란 변경 전후, `deployed.json` / `layout-deployed.json`은 서버 반영·백업 근거다. 서버 기존 배경 관련 코드 차이는 보존하고 이번 제목 변경만 적용했다.
- 렌더 파일 `SYNK-Radio-19-songs.mp4`: 1280×720, 12fps, AAC 192kbps. 전체 디코딩 오류 없음. 관련 Node 시험 13개 통과.

## 다음에 곡을 바꿀 때

서버 소리 목록과 `now-playing.json`을 함께 갱신해야 한다. 제목 표시기는 소리 목록 SHA-256이 시간표와 다르면 잘못된 제목 표시를 거절한다. 모음집은 현재 편성의 고정 영상이므로 나중에 편성이 바뀌어도 이 영상의 시간표를 새 편성으로 덮어쓰지 않는다.
