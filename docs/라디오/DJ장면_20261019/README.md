# 라디오 무대 · 세 친구 장면째 굽기 · 2026-10-19

10-19 유호님 결정(「옛 자료는 지금 필요 없고, 필요한 건 GPT 2.5로 최신판으로 새로 만드는 게 낫다」)과 10-14 마스코트 규칙(정본은 생김새 참고로만, 장면과 한 장으로 굽는다)에 따라 라디오 오버레이의 마스코트를 누끼 겹치기에서 장면째 굽기로 바꿨다. 처음에는 DJ 까몽 혼자로 시작했고, 1차 시안을 보신 유호님 말씀으로 지금 방송처럼 세 친구가 함께 나오는 장면이 됐다.

## 시작할 때의 상태 (10-19 읽기만 한 확인)

- **방송(서버 `synk-radio`, radio-live 10-19 17:42 KST부터 가동):** 무대는 `무대차례/still-dusk-kite-20260919-3d54fb291a54.mp4` 60초 되풀이 영상이다. 해 질 녘 한옥 마당에 마린·몽글·까몽 셋이 한 장면으로 앉아 있고, 카메라·몸은 고정이며 까몽 눈 깜빡임과 마린 렌즈 반응만 얼굴 자리에 합성했다([09-19 기록](../눈깜빡임_정지마당_20260919/manifest.json)). 그 위에는 전광판(지금 곡 제목)과 「synk radio」 각인만 얹힌다.
- `방송층.html`은 기본값(`영상마스코트`)에서 마스코트 층을 빼고, 송출 층 목록에 `무대.html`도 없다. 그래서 까몽 8컷 오버레이와 무대 층은 09-19부터 방송에 나가지 않았다. 서버 `방송층.html`은 로컬과 같은 바이트(sha256 `7692ffc7…`), 서버 `마스코트.html`은 09-17 판으로 읽히지 않는다.
- 로컬 `마스코트.html`은 까몽 8컷을 10-10 공간 정리로 비워진 `docs/Loom_자산/라디오차림/까몽/_후보/여름델+전설의팻말/65f92a753bb5416b/`에서 읽고 있었다.
- 결(장르) 넷 가운데 반딧불노을들판은 10-05에 방송 배경으로 바꿨다가 유호님이 거절했다([10-05 기록](../배경제목재수정_20261005/README.md)).

## 굽기

- GPT 이미지 2.5(ChatGPT 구독 · Codex CLI)를 `node tools/codex계정.js exec`로 불렀다. [굽기.cjs](굽기.cjs)가 지시문을 표준입력으로 넣고 구운 PNG를 `구운판/`에 옮긴다. Codex CLI에서는 GPT Image 2.5의 Sunburst · max 설정을 고를 수 없어 그 설정을 썼다고 보장하지 않는다.
- 참고 그림은 [참고만들기.py](참고만들기.py)가 `참고/`에 만든다: 정본 마린·몽글(눈웃음)·까몽(흰 바탕 JPEG), 방송 장면 속 세 친구(크기 비율·재질), 표정 판용 정본 까몽 눈감음·눈웃음 얼굴, 거울 수면 결의 옛 무대(분위기). 1차의 DJ 차림 참고는 쓰지 않았다.
- 16:9 한 장, 오른쪽 위(곡 제목 카드)와 왼쪽 아래(각인)는 비워 두게 했다. 셋은 「화면 높이의 4분의 1」로 적었고 30~40%로 나왔다.
- 모두 11장, bake2 계정, 장당 81~106초, 주간 사용률 16% → 24%(10-19 21시 확인). bake1·예비(본 계정)는 이미 100%라 10-25까지 쓸 수 없었다.

## 얼굴 조각

[얼굴조각.py](얼굴조각.py)가 [장면표.json](장면표.json)을 읽어 `docs/Loom_자산/라디오장면/<결>/`에 `장면.webp`·조각 webp 셋·`판.json`을 낸다.

1. 장면에서 까몽 두 눈(연두 구슬)을 색으로 찾는다. 밤 장면은 홍채 아래가 누렇게 어두워져 색상 22까지 받는다.
2. 표정 판에서 까몽 머리를 찾아 자리·배율을 맞춘다(맞춤 점수 0.90~0.98, 배율 0.995~1.005).
3. 눈 타원(눈감음 1.35배, 눈웃음 1.55배)만 장면 좌표로 옮겨 붙이고, 눈 둘레 털의 밝기를 장면에 맞춘다. 타원 밖 픽셀은 장면 그대로다.
4. 마린 렌즈는 노란 덩어리 가운데 가장 큰 둘(두 렌즈)만 골라 ×1.08 + (12,10,2)로 밝힌다(데이지·감·물에 비친 렌즈는 뺀다).

`무대.html`의 `장면조각` 표는 `file://`로도 뜨게 `판.json`의 자리를 옮겨 적은 것이다. 조각을 다시 만들면 표도 같은 커밋에서 고친다(시험이 대조한다).

## 남은 것

- **방송 반영**(유호님이 따로 말씀하실 때): 서버는 무대를 ffmpeg 영상으로 튼다. 결마다 60초 되풀이 영상(깜빡임·눈웃음·렌즈를 정해진 초에)으로 구워 `무대차례/`에 올리고 `목록.txt`·`조율.json`의 장면차례를 바꾼다. 지금 방송 장면(09-19 한옥 마당)을 바꾸는 일이다. 송출 도구의 결 이름 넷(반딧불노을들판 포함)은 서버 조율과 맞추려 그대로 두었다.
- 새 장면의 빛 지도(가로등·창·네온 깜빡임)는 아직 안 쟀다. 재면 `무대.html`의 `무대빛`에 넣는다.
