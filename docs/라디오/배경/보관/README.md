# 보관 — 쓰지 않지만 살려 두는 배경

> 🔑 **여기 있는 것은 방송에 «안» 나간다.** 굽는 도구가 곡 이름의 결(`-<결>-air`)로
> 윗 폴더(`docs/라디오/배경/<결>.png`)에서만 배경을 찾기 때문이다.
> 이 폴더는 그 규칙 밖이라 실수로 섞일 자리가 없다.

## 왜 지우지 않았나

유호 확정 2026-09-06 「마린은 두 버전 다 하자. 두 버전 다 너무 마음에 들어. 보관해줘 하나는」.

| 파일 | 무엇 | 언제 |
|---|---|---|
| `전자_네온물가.png` | 마린이 네온 비친 물가에 선 판. 뒤에 도시 실루엣과 분홍·파랑 반사. | 09-05 에 마린이 처음 무대에 서며 만든 첫 판(`f87be6108`). 09-06 에 밤 도시로 갈리며 이 자리로 내려왔다. |

바탕 무대(마스코트 없는 것)는 `docs/라디오/무대/보관/전자_네온물가.png`.

## 다시 쓰려면

윗 폴더의 `house.png` 를 이것으로 덮으면 그날부터 방송 화면이 바뀐다.
둘을 «같이» 쓰려면 결을 나눠야 한다 — 곡 이름 꼬리가 배경을 고르므로, 한 결에 배경은 하나다.
