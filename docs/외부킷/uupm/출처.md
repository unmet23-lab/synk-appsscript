## 🔴 안 들인 것 — 그리고 그게 «스스로 집행»된다

`colors.csv`(192행) · `typography.csv`(74행) · `google-fonts.csv`(1,934 패밀리) ·
`google-font-licenses.json` — 합계 1.21MB. 유호님 08-26 확정 그대로 제외했다.

**파일이 없으므로 `--domain color` · `--domain typography` 는 「File not found」로 죽는다.**
막히는 것이 정상이고, 그게 「팔레트·폰트 층은 안 들인다」가 문서 약속이 아니라 **기계 상태**라는 증거다.

```
python docs/외부킷/uupm/scripts/search.py "palette" --domain color
→ Error: File not found: …/data/colors.csv        ← 이게 통과다
```

> ⚠ **단 이 명령은 종료코드 0 으로 끝난다**(실측). 나중에 이걸 스크립트로 감쌀 일이 있으면
> `rc == 0` 을 통과로 읽으면 안 된다 — **출력 문자열**을 봐야 한다.

## 🔴 `--design-system` 과 `--persist` 는 영구 금지다

이 반입에서 제일 위험한 실측이다. 팔레트 CSV 를 **지운 채로** 그 모드를 돌렸더니
에러 0 · 종료코드 0 으로 「Primary #2563EB / Accent #F97316 / Inter」를 **검색 결과인 척** 찍었다.
`design_system.py` 안에 하드코딩된 폴백이다.

즉 **파일을 안 들이는 것으로는 안 막힌다.** 막는 것은 플래그 금지뿐이다.
`--persist` 는 거기에 더해 `MASTER.md` 라는 «두 번째 정본»까지 만든다.

## 차트 데이터는 «손을 댔다» — 그 사실을 여기 적어 둔다

원본 `charts.csv` 는 25행 중 13행의 `Color Guidance` 칸에 남의 hex 를 박고 있었다
(#0080FF 5회 · #EF4444 3회 · #2563EB … 고유 24색 · 등장 34회).
그대로 두면 「차트 층만 들이고 팔레트는 안 들인다」가 **데이터 수준에서 안 지켜진다** —
어긴 줄 모르고 어기는 자리다.

그래서 반입하면서 hex 34곳을 전부 `〈킷색〉` 으로 **치환했다.** 색 «규칙»(시리즈 상한·역할 구분)은
남고 색 «값»만 사라진다. 원본을 다시 뜰 일이 있으면 이 치환을 다시 해야 한다.

## 쓰는 법

```bash
python docs/외부킷/uupm/scripts/search.py "<두세 낱말>" --domain ux
python docs/외부킷/uupm/scripts/search.py "<두세 낱말>" --domain chart
python docs/외부킷/uupm/scripts/search.py "<두세 낱말>" --domain gsap    # ← motion.csv 의 도메인 이름은 `gsap` 이다(파일명과 다르다)
```

⚠ `--domain` 을 **생략하지 않는다.** 생략하면 자동 감지가 엉뚱한 데이터로 떨어진다.

**언제 이걸 열고 언제 킷을 여는지는 `.claude/skills/synk-design/SKILL.md` 2-b 가 정한다.**
그 순서가 정본이고, 이 문서는 «무엇이 여기 있나»만 안다.
