# 앱 로드맵 감사 — 시작 · 개인화 · 글로벌 플랫폼

2026-09-21 현재 로컬 정본과 SYNK-talk 소스를 대조했다. 소비자에게 보여 줄 미래 경험과 현재 구현을 분리하기 위한 자료다. 운영 서버·스토어·실기기·실학생 자료는 조회하지 않았으며, 이번 작업에서 코드 실행·배포·결제를 하지 않았다.

## 9월 21일 당시 — 읽는 기준

이 절 아래 기능 상태·제작 제안은 9월 21일 감사 결과다. 이후 구현을 미구현으로 되돌리거나 당시 제안을 새 작업 지시로 적용하지 않는다. 현행 기능별 담당 원문은 [문서 지도](../문서_지도.md)에서 확인한다.

- **앱 연결 있음:** 실제 앱 화면과 코드가 연결돼 있다. 운영 배포나 사용자의 이용 가능 상태를 뜻하지 않는다.
- **일부 준비:** 선택 화면·기존 기록 등 바탕은 있으나, 소개하는 경험 전체는 아직 작동하지 않는다.
- **개발 예정:** 방향 또는 상세 설계가 준비됐다. 현재 제공 중인 상품으로 소개하지 않는다.
- `data-platform.json`의 `connected`, `prototype`, `planned`도 위 의미다. 모든 카드에 현재 범위를 별도로 적었다.

## 1. 시작 — 나와 맞는 친구, 나에게 열리는 첫 활동

### SYNK 홈: 여러 경험을 만나는 한곳

**사용자에게 보여 줄 경험:** 앱을 열면 내 마스코트, 이어 할 활동, 내가 만든 것과 남겨 둔 기록이 한곳에 보일 예정이다. 공부를 해야만 다른 곳에 들어갈 수 있는 구조 대신, 오늘의 관심과 시간에 맞는 콘텐츠로 들어가는 방향이다. 공통 계정과 내 기록, 콘텐츠 입구를 기존 앱 안에 먼저 만든다.

**현재:** 기존 학생 화면과 로그인·학습 기록은 있다. 새 SYNK 플랫폼 홈은 미완료다. 기존 학생 홈이나 로드맵 HTML을 새 플랫폼 출시로 표현하면 안 된다. 예전 재설계의 방·책상·편지함·옷장은 공간으로 느껴지는 앱의 디자인 기반이며 모든 항목의 구현 완료 목록이 아니다.

**다음:** 기존 앱의 홈·계정·내 기록·콘텐츠 입구를 실제로 연결한다. 전용 PC 런처를 먼저 만드는 순서가 아니다.

근거: `docs/SYNK_플랫폼_계정과_연결_설계.md:57–77`, `docs/앱재설계_v2.md:8–23,41–64,138–143`.

### 온라인 학습자도 스스로 시작

**사용자에게 보여 줄 경험:** 학원에 다니지 않아도 가입하고, 설명을 읽기 편한 언어와 한국어 경험·목표를 고른 뒤 시작할 예정이다. 초보자는 처음부터, 이미 공부한 사람은 본인에게 맞는 연습 수준에서 시작한다. 본인이 정한 연습 수준을 공식 TOPIK 급수로 표시하지 않는다.

**현재:** 학생번호·비밀번호와 기존 학생 등록 경로가 중심이다. Google·Apple 일반 공개 가입과 새 온라인 시작 질문은 아직 구현되지 않았다. Google 로그인에 공통 SYNK ID를 연결하는 방식은 가능한 구조 제안이며 인증 업체 선정이나 계정 통합 완료가 아니다. 로그인 없는 체험도 출시 확정 기능으로 표현하지 않는다.

**다음:** 공개 가입·동의·온라인 질문·본인 수준 선택·탈퇴를 한 흐름으로 만들고 기존 학원 계정과 구분한다.

근거: `docs/공개판_설계.md:69–105,150–182`, `docs/SYNK_플랫폼_계정과_연결_설계.md:34–55`; talk `src/인증화면.js:124–138`, `supabase/functions/auth/index.ts:377`.

### 몽글 · 까몽 · 마린: 추천보다 내 선택이 먼저

**사용자에게 보여 줄 경험:** 함께 시도하고 기뻐하는 몽글, 장난 속에서 챙겨 주는 까몽, 다음 행동을 차분히 짚어 주는 마린 중 함께하고 싶은 친구를 고른다. 원하면 짧은 상황 선택으로 친구를 추천받되 추천을 거절하거나 건너뛰어도 시작할 수 있게 한다. 예문을 먼저 볼지, 혼자 시도할지는 외형 취향과 별개다.

**현재:** 실제 첫 등록 화면에 몽글·까몽 선택이 있고 마린은 ‘곧 와요’로 비활성이다. 선택은 서버 계정이 아닌 기기 파일에 저장된다. 4막 12장면 첫 만남은 설계안이며 실제 3~4분 소요나 추천 적합성을 검증하지 않았다. 추천 설문으로 성격을 정확히 안다고 표현하지 않는다.

**다음:** 세 친구 선택과 계정 저장을 연결하고, 추천 거절·건너뜀·나중 변경에도 기록이 이어지도록 구현한다.

근거: `docs/첫로그인_마스코트추천_개인화_설계_v1.md:3–34,109–133`; talk `src/인증화면.js:49–55,134–137,223–228`, `src/저장.js:189–221`, `App.js:209–215`.

### 익숙한 재미와 새로운 발견

**사용자에게 보여 줄 경험:** 내 목표·시간·선호와 콘텐츠의 난도·활동 시간을 함께 보고 입구를 안내할 예정이다. 꾸미기를 좋아한다고 늘 꾸미기만 보게 하지 않고, 익숙한 활동 옆에 새로운 문화를 경험할 기회를 둔다. 한국어가 늘면 시험 대비뿐 아니라 한국어로 즐기는 이야기와 관계로 이어지는 방향이다.

**현재:** 공통 추천 방향과 콘텐츠 정보 정리 원칙이 준비됐으며 여러 콘텐츠가 연결된 개인화 홈은 미완료다. 클릭이 많다는 이유만으로 ‘공부에 도움이 됐다’고 판단하지 않는다.

근거: `docs/SYNK_플랫폼_계정과_연결_설계.md:7–18,61–71`.

## 2. 개인화 — 말투보다 실제 도움이 달라지는 친구

### 첫 기억: 편지 연습에서 원하는 도움을 이어 쓰기

**사용자에게 보여 줄 경험:** ‘하나씩 살펴보기’를 고르면 점검을 한 칸씩 보고, ‘먼저 혼자 해 보기’를 고르면 점검을 접은 채 시작한다. 다음 실행에서도 내가 정한 방식이 이어지도록 연결했다. 나중에 마음이 바뀌면 다시 고르거나 기본 안내로 되돌릴 수 있다.

**현재:** 공통 모듈·인증된 서버 저장/읽기·앱 도움 표시가 로컬 구현됐다. 단 하나의 명시적 편지 도움 설정이며 글·음성·전체 대화를 저장하는 장기 기억이 아니다. 계정 없는 체험은 기존 세션 경험을 쓴다. `기본 안내로 되돌리기`는 이전 선호 적용 중단이지 원본 기록 전체 삭제가 아니다.

**검증:** 구현 기록에 공통 41개·앱 295개, 관련 336개 시험 통과가 있다. SQL·인증 대역을 사용하는 합성 시험이 포함돼 실제 PostgreSQL 잠금·두 실기기·운영 환경 검증과 같지 않다. 미커밋 새 파일 때문에 HEAD 기반 배포 시험 6건이 별도 실패했으며 우회하지 않았다. 이 수치를 소비자에게 ‘336개 실사용 검증’으로 소개하면 안 된다.

**다음:** 배포 가능한 묶음 검토 → 리허설 실제 저장·계정 변경·두 기기 충돌 확인 → 두 번째 콘텐츠에서 도움 연결의 유용함 확인.

근거: `docs/아틀라스_첫지속기억_20260921.md:3–22,24–55`; talk `src/아틀라스게임.js:57–94`, `src/교수멘탈화면.js:266,344`, `lib/atlas-session.js:33–38`.

### 대화는 짧은 장면부터, 내 말로 조금씩

**사용자에게 보여 줄 경험:** 인사나 주문처럼 이해할 수 있는 장면에서 보기 고르기 → 문장 조립 → 내 단어 넣기 → 내 말로 답하기로 넓혀 갈 예정이다. 어려우면 보기로 돌아올 수 있고, 말이 잘 전달되지 않으면 되묻거나 표현을 제안한다. 더 자유롭고 긴 AI 대화는 별도의 고급 기능 방향이다.

**현재:** 마스코트의 상황별 말·반응 코드와 대화 설계가 있다. 학습자의 말을 받고 주고받는 NPC 대화 전체 화면은 아직 없다. 기기 안에서 처리하는 대화와 주제 없는 AI 자유 대화를 구분한다. 음성 인식 준비가 있어도 기기별 정확도·실제 대화 흐름은 미검증이다. 기존 교사용 몽글 지식 질문 기능을 학습자용 자유 대화로 소개하지 않는다.

**다음:** 한 주제의 짧은 대화부터 이해 실패·보기 복귀·직접 입력을 연결하고 실기기로 확인한다. 여러 NPC에게 같은 사적 기억을 자동 전달하지 않는다.

근거: `docs/대화_설계.md:6–40` 및 §3·§14·§16; talk `lib/마스코트생명.js`, `src/마스코트.js`, `src/온디바이스전사.js`.

### ‘SYNK가 기억하는 나’를 내가 확인하고 고치기

**사용자에게 보여 줄 경험:** 내가 직접 정한 목표, 실제로 해낸 일, 아직 확인이 필요한 제안을 구분해 볼 예정이다. ‘지금은 이게 아니야’라고 고치고, 무엇을 다른 콘텐츠에 이어 쓸지 선택한다. 마스코트가 생각한 나와 실제 내가 다르면 내 수정이 다음 도움에 반영되는 방향이다.

**현재:** 확인·정정·삭제·공유 선택은 승인된 장기 방향이다. 전체 기억 관리 화면과 원본 물리 삭제는 미완료이며, 현재 수정 가능한 첫 연결은 편지 도움 설정에 한정된다. 게임에서 오래 머물렀거나 재시도했다고 성격·의욕을 확정하지 않는다.

**다음:** 기억의 근거·시점·범위를 표시하고 정정·삭제·연결 해제가 다음 추천과 저장된 파생 정보에까지 반영되는지 검증한다.

근거: `docs/SYNK_플랫폼_계정과_연결_설계.md:11–32,67–77`.

### 작품과 성취: 숫자 밖에 남는 내 시간

**사용자에게 보여 줄 경험:** 첫 정원, 직접 꾸린 가게, 처음 혼자 마친 한국어 대화를 개인 기록 공간에서 다시 볼 예정이다. 실제로 내가 한 일에 맞춰 친구가 반응하고, 공개 축하보다 조용한 인사를 원하면 그 방식을 존중하는 방향이다. 게임의 레벨과 실제 한국어 능력·공식 시험 결과는 섞지 않는다.

**현재:** 작품·성취 공간과 공통 기억 연결은 계획이다. NPC가 무엇을 알 수 있고 어떤 근거로 인정할지의 상세 설계가 있다. 만나지 않은 NPC가 내 모든 사적 활동을 아는 식의 연출은 하지 않는다.

근거: `docs/SYNK_플랫폼_계정과_연결_설계.md:11–18,20–32`; `docs/온라인학습자_20개국_확장방향_20260920.md:9,20,40–52`.

## 3. 글로벌 — 사는 곳은 달라도 같은 SYNK

### 약 20개국의 온라인 학습자를 향해

**승인 방향:** 전 세계 한국어 학습자가 대상이며 몽골은 그중 하나다. 약 20개국 동시 공개 출시를 목표로 하고 온라인 경험 개발을 우선한다. 정확한 국가·지원 언어·일정은 미정이다. 작은 비공개 테스트와 동시 공개 출시 목표는 별개다.

**사용자 경험:** 국적 대신 본인이 편한 도움 언어를 선택하고, 시간대와 학습 수준에 맞게 시작할 예정이다. 국가 수를 그대로 번역 언어 수로 세지 않는다. 같은 마을이어도 같은 실력으로 취급하지 않는다.

**현재:** 기존 언어 자료와 학원 중심 앱 기반이 있으며 세계 공개 가입·언어별 초급 첫날·지원 운영은 준비해야 한다. 기존 한·몽 자료를 삭제할 이유는 없지만 그것으로 20개국 지원 완료를 선언할 수 없다.

근거: `docs/온라인학습자_20개국_확장방향_20260920.md:5–22,49–52,86–94`, `docs/공개판_설계.md:3,212–220`.

### 같은 앱, 함께 머물 마을, 학원생만의 수업 연결

**승인 방향:** 일반 사용자와 학원생 모두 정원 16명의 마을에 소속된다. 16명이 동시에 접속하거나 협동해야 활동이 열리는 것은 아니다. 온라인 사용자는 주 1회 활성 마을로 옮길 수 있게 하고, 학원생은 실제 반 구성원과 고정된다. 정확한 주간 계산·활성 기준은 미정이다.

**사용자 경험:** 친구가 없어도 NPC·내 활동을 즐기고, 원하면 이웃과 이야기한다. 학원에 다니면 같은 앱에 출석·교사 확인·반 관리가 연결될 예정이다. 일반 마을 가입이 교사 권한을 만들거나 사적인 학습 기록을 친구에게 공개하지 않는다.

**현재:** 마을 시제품과 기존 학원 역할 코드가 있으나 공통 계정·실제 16인 서비스·온라인/학원 권한의 전체 연결은 미완료다. 현재 직원 메뉴 노출과 서버 권한 검사를 구분해야 하며, 온라인 학습자 기록이 학원 조회에서 완전히 분리됐다고 미검증 주장을 하지 않는다.

근거: `docs/공개판_설계.md:8–48`, `docs/온라인학습자_20개국_확장방향_20260920.md:12–18,26–38,49–52`.

### 기본 즐거움은 넓게, 더 깊은 도움과 꾸미기는 선택으로

**현재 상품 방향:** 기본 한국어 학습·계산 기반 개인화·마을 활동·준비된 주민 대화는 무료 가치를 넓힌다. 고급 1:1 AI 코칭·자유 대화·심화 교정·최신 형식 모의시험은 구독 또는 별도 상품 방향이며, 가구와 의상은 원하는 것을 고르는 고정 가격 판매를 구상한다. 기관 단위 이용도 별도 후보로 정리돼 있다.

**사용자 경험:** 좋은 기본 차림으로도 지낼 수 있고 마음에 드는 물건을 골라 살 수 있게 한다. 구독이 끝나도 기억과 이미 산 물건을 인질로 잡거나 마을에서 쫓아내지 않는 방향이다. 친구의 신뢰·성적·합격을 구매하는 상품으로 만들지 않는다.

**현재:** BM 방향과 후보 목록이다. 결제·계정 소유권·환불·구독 검증이 완성된 판매 서비스가 아니다. 최종 가격·통화·국가별 구성·대화량·체험 기간은 미정이다. 숙제 포인트는 보류, 광고 여부는 확인이 남았다. 계산 기반 기능의 모델 호출 0은 서버·저장·운영 비용 0과 다르다.

### 하나의 계정, 필요한 기억만 연결

**사용자 경험:** 허용한 도움과 기록은 다음 콘텐츠에서도 이어 쓰되, 각 게임의 농작물·돈·NPC 관계까지 무조건 섞지는 않는다. 연동을 거절해도 콘텐츠를 정상 이용할 수 있게 한다. 공동 계정이 모든 정보 제공 동의가 되는 구조를 피한다.

**현재:** SYNK ID는 승인된 플랫폼 방향이다. Google 인증과 내부 계정을 결합하는 방식은 제안이며 공개 계정·여러 로그인 수단 연결은 미구현이다. 이메일이 같다는 이유만으로 계정을 자동 합치지 않는다. LAB 기록이 SHIFT·PULSE 같은 다른 서비스로 자동 넘어간다는 약속도 없다.

## 9월 21일 승인 개발 순서 이력 — 임의 기한 없음

1. **기존 앱에 SYNK 홈·공통 계정·내 기록·콘텐츠 입구.** 작은 편지 도움 기억 연결은 이 기반의 첫 작업이다. 전체 플랫폼·그래픽 완성을 기다리며 기억을 미루지 않는다.
2. **실제 콘텐츠 두 개에서 기억과 도움을 연결.** 매번 재설정하는 부담이 줄고 도움이 적합해지는지 확인한다. 연결을 원하지 않는 이용도 정상 지원하는 방향이다.
3. **PC 설치·업데이트 수요가 생기면 전용 런처.** 자체 상점과 큰 커뮤니티는 실제 필요에 맞춰 넓힌다. 첫 공개를 위한 선행 필수 조건이 아니다.

공개 전에는 일반 가입, 초보 첫날, 저장·정정, 계정과 역할 분리, 실패·비용 상한, 동의·탈퇴, 언어별 안내, 스토어·지원 운영을 함께 확인해야 한다. 작은 비공개 테스트 통과를 약 20개국 공개 준비 완료로 바꾸지 않는다.
