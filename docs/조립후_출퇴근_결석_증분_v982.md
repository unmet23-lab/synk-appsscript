## STEP 1 · 강사 탭 「출퇴근」 — 오늘의 근무 카드 얹기  ✅ **07-31 원격 실행 완료(잔여 1)**

완성 모습: **오늘의 근무 카드**(출근/퇴근 시각 · 상태 필 · 이번 주 월~토 스트립 · 요일 인사말) + 기존 구성.

> ⚠ **문서 전제 정정(07-31 라이브 실측)**: 이 탭은 낱개 Text 2개가 아니라
> **Collection(teacher_checkins — 내 출퇴근 이력) + Button Block(출근/퇴근 2액션)** 구성이었습니다.
> 07-22 조립 당시 List+추가 버튼으로 만든 것이 정본입니다. 따라서 **삭제할 Text는 없습니다.**

1. Glide 편집기(`/layout`) → 강사 탭 **「출퇴근」** 클릭.
2. 좌측 COMPONENTS의 **`+`** → 검색 `rich` → **Rich Text** 클릭.  ✅완료
3. 우측 CONTENT 칸의 **⋮⋮** → **`User profile` 그룹**(첫 줄, `>` 화살표) → `출퇴근HTML` 선택.  ✅완료
   - ⚠ 이 화면 소스는 **teacher_checkins**입니다. 그룹에 들어가지 않고 바로 뜨는 목록(이름·구분·시각…)은
     그 시트의 열이라 **로그인한 강사가 아니라 첫 행**을 가리킵니다(07-28 수업준비 탭 실사고와 같은 함정).
     제대로 되면 CONTENT 토큰이 **`User / 출퇴근HTML`** 로 보입니다 — 이 표기가 검증 기준입니다.
4. 순서: 현재 **Collection → Rich Text → Button Block** (Move Up 1회 완료분).
   **잔여** — 카드를 맨 위로 올리려면 Rich Text를 **좌클릭으로 먼저 선택**(우측 패널이 `Rich Text`인지 확인)
   → 라벨 글자 위 우클릭 → **Move Up** 1회. (지금 상태로 둬도 기능은 정상 — 이력 아래에 카드가 옵니다.)
5. **출근·퇴근 버튼과 Visibility 조건은 그대로 둡니다**(오늘출근 DK115 / 오늘퇴근 DL116 — 변경 없음).

✅ 검증: 좌상단 **Viewing as**를 강사 계정으로 바꾸면(학생 계정이면 "This screen's visibility condition is
false"가 정상) 카드에 오늘 날짜·「출근 전」 필·주간 스트립·요일 인사말이 보입니다.

## STEP 2 · 학부모 탭 「결석 신고」 — 폼 단독 → 카드 + 폼 버튼 (7분)

완성 모습: **결석 미리 알리기 카드**(내 신고 접수 확인 ✅ · 다음 수업일 · 작동 안내 몽골어 병기) 위에,
**🙏 결석 미리 알리기 버튼**이 폼을 엽니다. 다자녀 가정도 정확한 자녀 1명을 고를 수 있게 폼을 재구성합니다.

### 2-A. 화면 구성
1. 학부모 탭 **「결석 신고」** 선택 → 우측 패널에서 화면이 폼 단독이면, 탭 스타일을 **Custom**(일반 화면)으로.
   - 탭 Source는 **profiles**. (기존 폼 탭을 지우고 새 탭을 만들어도 됩니다 — Visibility `role is parent` 유지)
2. **Rich Text** 추가 → CONTENT ⋮⋮ → 검색 `결석신고HTML` → **`User profile` 그룹** 선택(STEP 1과 같은 함정 주의).
3. **Button** 추가 → 라벨 `🙏 결석 미리 알리기` → ACTION: **Show form screen** → 대상 **absence_notice**.

### 2-B. 폼 필드 (★다자녀 수리의 핵심)
폼 화면 안에 아래 4개만 두고, 나머지 자동 토큰은 전부 비웁니다(⋮⋮ → Clear value):
1. **자녀** — **Choice** 컴포넌트: 기록 대상 열 = `student_id` · Source = **profiles** ·
   Filter = `role is student` **AND** `user_id is included in` → ⋮ → **User Profile → parent_of** ·
   표시 = `이름` · **값(value) = `user_id`** · Required ON.
   - 구 방식(`student_id = User's parent_of` 자동 기입)은 **삭제** — 다자녀면 `"SYNK-001,SYNK-002"`가
     통째로 기록돼 엔진 3곳(미출석 알림 제외·강사 브리핑·접수 카드)이 전부 조용히 불발됩니다.
2. **날짜** — Date picker · 기록 열 `날짜` · Required ON.
3. **사유** — Text · 기록 열 `사유` (선택 입력).
4. **등록시각** — 값 ⋮ → **Current date/time** · 기록 열 `등록시각`.
- `반` 열은 **폼에 넣지 않습니다**(엔진이 profiles의 반을 우선 사용 — 가이드 7-3 규약 유지).

✅ 검증(실연 1회): 학부모 프리뷰로 내일 날짜 신고 제출 → 시트 absence_notice의 student_id가
`SYNK-xxx` 단일값인지 확인 → **10분 내** 카드에 `✅ 접수됨 · Бүртгэгдсэн` 표시.
당일 날짜로 내면 그날 미출석 메일이 억제되고 강사 브리핑 메일에 「오늘 결석 예정」으로 뜹니다.
