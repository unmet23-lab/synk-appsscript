# 출시 나라·지원 언어

> 10-03에 채택한 나라·언어 배치와 이후 AI 예산 변경을 함께 읽는 입구다. 아래 표는 출시 준비 범위이며 번역·검수·스토어 등록·배포 완료 목록이 아니다. 정확한 출시일은 확정하지 않았다.

## 1. 현재 채택한 공개 순서

10-03 사용자가 추천안 ①~⑤를 MVP 기준으로 채택했다. 09-20의 약 20개국 동시 출시 목표는 **첫 12개국과 나머지 7개국을 같은 출시 기간 안에서 언어 검수에 따라 순차 공개**하는 방향으로 구체화됐다. 한국·몽골의 비공개 시험과는 다른 범위다. 근거는 [결정](_ops/결정.md)의 2026-10-03 출시 나라·도움 언어 결정이다.

| 묶음 | 나라 | 준비에 쓸 언어·조건 |
|---|---|---|
| 첫 공개 12개국 | 미국·캐나다·호주·뉴질랜드 | 영어. 캐나다 프랑스어권의 권리 안내 등 실제 적용 범위는 별도 확인 |
| 첫 공개 12개국 | 말레이시아·필리핀·인도·스리랑카 | 영어로 시작하는 계획. 영어 통용을 모든 이용자의 이해로 간주하지 않음 |
| 첫 공개 12개국 | 브라질 | 포르투갈어. 미성년 보호·권리 안내 등 출시 준비 조건을 확인한 뒤 공개 |
| 첫 공개 12개국 | 멕시코·파라과이 | 앱은 중남미 공통 스페인어(tú). SNS의 vos와 구분 |
| 첫 공개 12개국 | 몽골 | 몽골어 사람 검수. 오프라인 학원 첫 시장·비공개 시험국이라는 역할과 구분 |
| 언어 검수 후 7개국 | 일본·대만·태국·베트남·인도네시아·미얀마 | 일본어·중국어 번체·태국어·베트남어·인도네시아어·미얀마어. 검수자를 확보한 언어부터 |

| 보류 | 중국·러시아 | 스토어·결제 제약 등 실제 출시 조건 확인 전. SNS 계획을 취소하는 결정이 아님 |
| 2차 후보 | 카자흐스탄·우즈베키스탄·네팔·캄보디아·방글라데시 | 필요한 언어의 검수자를 확보한 뒤 구체화 |

「첫 공개」는 준비 우선순위다. 실제 동의·개인정보·계정 삭제·결제 안내와 운영 대응을 이용자가 이해할 수 있는 언어로 제공하고 검수해야 한다. 영어를 쓸 계획이라는 이유로 해당 나라의 준비 완료를 표시하지 않는다. 나라와 언어는 일대일이 아니다.

## 2. 앱과 도움 언어

앱은 하나이며 학습 언어는 한국어다. 영어·몽골어·스페인어·포르투갈어(브라질)는 채택한 도움 언어다. 10-03 저녁에 정한 **한글 단계 MVP는 도움 언어 없이 한국어로 먼저 구현**하는 범위이며, 이후 도움 언어를 붙이는 계획과 구분한다. 현재 구현은 [한글 단계](../experiences/hangul-stage/README.md)와 [한글 단계 설계](한글단계_설계.md)에서 확인한다.

한국어 학습 화면과 동의·권리 행사 문안의 언어는 다르다. 한글 MVP가 한국어라는 이유로 권리 안내의 번역·검수를 생략하지 않는다. 힌디어·싱할라어·말레이어 등의 추가는 실제 이용 자료를 보고 정한다.

## 3. 가격 묶음과 AI 비용

- 10-03에는 [BM 목록](BM_목록.md)의 **나라 배정**(㉮ 6·㉯ 4·㉰ 9개국)만 채택했다. 옛 달러 가격은 현재 정액·통합 구독 판매가가 아니다. 최종 BM·가격·제공량은 미확정이다.
- **AI 예산은 10-04·05 결정이 우선한다.** 실제 시험 한도는 학생 무료 월 $0.30·검증된 유료 월 $0.50·일 $0.05이며, DB의 무료 $0.50·유료 $3은 하드 상한이다. 운영 AI 회화 튜터는 OFF이고 재개는 별도 결정이다. 현재 설정과 검증 범위는 [AI 효율화](SYNK_WORLD_AI_효율화_20261002.md)를 따른다.
- 09-19~10-03의 1인 월 1,000원·하루 배분·사흘 이월·순매출 30%+10만원·전체 월 5만원은 이전 예산 이력이다. 현재 호출 조건이나 공개 상품의 보장 제공량으로 쓰지 않는다. 출시에 사용할 최종 무료·유료·학원·회사 예산은 실제 사용량을 보고 다시 정한다.
- 미니게임의 무료 범위와 AI 사용은 현행 [제품방향](제품방향.md)·BM 및 각 제품 코드에서 확인한다. 국가 표가 결제나 호출을 시작할 권한은 아니다.

## 4. SNS와 출시 준비의 차이

LAB SNS의 국가별 계정 계획과 앱의 공개 나라 목록은 서로 다르다. 현재 계정·번역·게시 상태는 [온라인 마케팅 지도](마케팅/온라인마케팅지도/README.md)에서 확인하고, 과거 23개국·25개국 계획 수를 실제 생성·연결·게시 수로 쓰지 않는다.

나라별 스토어 가격·수수료·세금·구독 안내·미성년 보호·AI 표시·번역 검수·운영 대응은 실제 출시 준비 시점에 확인한다. [브라질·멕시코 전략](마케팅/LAB_브라질_멕시코_전략_20261002.md)의 조사와 [약관 확인 목록](약관_처리방침_확인목록_20261003.md)은 검토 출발점이며 이 문서 정리가 법률 적합성 확인을 뜻하지 않는다. 나라별 한국어 학습 수요와 번역 품질·이용 가능성도 별도 검증 대상이다.

10-03의 선택지·추천 이유·당시 나라별 언어 표·법률 확인 후보·비용 비교는 [정리 전 원문](_ops/qa/document-cleanup-20261017/_archive/pass2-originals/docs/출시나라_지원언어_후보표_20261003.md)에 보존한다. 현재 채택 결과와 대체된 예산안을 한 문서 안에서 다시 선택하게 만드는 중복을 제거했다.
