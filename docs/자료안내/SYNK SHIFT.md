# SYNK SHIFT — 제작·운영 방법

SYNK LAB을 준비하며 쌓은 제작·운영 방법을 협업과 상품으로 연결합니다. [현재 소개서](../홍보물/브랜드소개_20260909/shift.html)는 광고 콘텐츠 제작과 브랜딩 교육 준비를 중심으로 설명합니다. 직장 적응·대학 유학생 관리 등 후속 연구를 이미 제공하는 서비스처럼 섞지 않습니다.

## 지금 작업을 이어갈 때

계정 개설·단장·소개문 관련 기록은 [계정 실행지](../SHIFT/계정개설_실행지.md) 한 곳에서 봅니다. 계정별로 **무엇을 올릴지**는 [콘텐츠 배분](../SHIFT/콘텐츠_배분_v1.md), **어디까지 공개할지**는 [영상 공개선](../SHIFT/영상_공개선.md)이 정합니다.

개인 계정은 회사를 짓는 사람과 과정을, 정보 계정은 다른 사람도 이어받아 쓸 정보를 보여 줍니다. 작업을 설명할 때는 목적 → 선택한 이유 → 실제 확인한 결과를 한 흐름으로 묶습니다. 도구 목록이나 미래 사업 계획을 앞에 늘어놓지 않습니다.

## 단장 재료를 꺼낼 때

- 정보 계정의 프로필: [현재 펠트 도장](../SHIFT/프로필/synkbrief_펠트_프로필.png).
- 개인 채널의 배너: [yuhobuilds 배너](../SHIFT/배너/yuhobuilds_배너.png).
- 학원 계정의 프로필·배너는 SYNK LAB의 홍보 업무입니다. 같은 파일을 두 브랜드에 복사하지 않습니다.

개인 얼굴 원본과 선택 사진은 바탕화면 `SYNK PULSE/인물`에서 찾습니다. 옛 프로필 네 안·배너 세 안·마케팅 정찰 바로가기를 따로 열지 않아도 현재 선택과 실행 기록을 위에서 이어갈 수 있습니다.

## 상품·협업을 구체화할 때

사용할 자리, 필요한 결과물, 검토와 인수 방법을 먼저 맞춥니다. 계약·서비스 개시 상태와 제공 범위는 그때 확인합니다. 후속 연구의 실물은 [외국인 직원 첫 30일 체크리스트](../SHIFT/첫30일_체크리스트_v1.md)에서 봅니다. 초안 인증서가 완성된 자격 제도를 뜻하지는 않습니다.

음악·영상·캐릭터 제작은 SYNK PULSE와 연결합니다. 브랜드 공통 기준과 엔진은 SYNK에서 함께 씁니다.
