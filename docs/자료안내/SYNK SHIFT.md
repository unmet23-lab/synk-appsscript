# SYNK SHIFT — 제작·운영 방법

SYNK SHIFT의 주력은 **1인 기업 브랜딩·강의**입니다. 공개 콘텐츠도 1인 기업이 자기 일에 적용할 방법·정보·자료를 제공합니다. 대상·제공물·채널 역할은 [마케팅 정본](../마케팅_정본.md)에서 읽습니다. [소개서 제작 원본](../홍보물/브랜드소개_20260909/shift.html)은 사용 전에 현재 결정과 대조하며, 후속 연구를 이미 제공하는 서비스처럼 섞지 않습니다.

AI 작업은 [공통 운영 원칙](../AI_운영원칙.md)과 관련 정본·최근 변경을 실제로 읽고 시작합니다. 바탕화면·OneDrive·Drive의 파일은 공유 사본이며 현재 제작 원본을 대신하지 않습니다.

## 지금 작업을 이어갈 때

현재 전략은 [SHIFT](../마케팅/SHIFT.md), 계정별 역할과 게시 분담은 [채널과 발행](../마케팅/채널과_발행.md), 수업은 [공개수업](../마케팅/SHIFT_공개수업.md)에서 확인합니다. [계정 실행지](../SHIFT/계정개설_실행지.md)는 해당 계정의 처리 기록이며 [영상 공개선](../SHIFT/영상_공개선.md)은 공개 범위를 정합니다. 과거 개설 순서를 모든 새 콘텐츠의 절차로 반복하지 않습니다.

개인 계정은 실제 작업을 1인 기업자가 적용하도록 가르치는 수업·판단을, 정보 계정은 일을 시작하거나 막힌 부분을 푸는 짧은 실용 자료를 제공합니다. 작업을 설명할 때는 독자의 문제 → 선택한 이유 → 실제 확인한 결과 → 자기 일에 적용할 방법을 한 흐름으로 묶습니다.

## 단장 재료를 꺼낼 때

- 정보 계정의 프로필: [현재 펠트 도장](../SHIFT/프로필/synkbrief_펠트_프로필.png).
- 개인 채널의 배너: [yuhobuilds 배너](../SHIFT/배너/yuhobuilds_배너.png).
- 학원 계정의 프로필·배너는 SYNK LAB의 홍보 업무입니다. 같은 파일을 두 브랜드에 복사하지 않습니다.

개인 얼굴 원본과 선택 사진은 바탕화면 `SYNK PULSE/인물`에서 찾습니다. 옛 프로필 네 안·배너 세 안·마케팅 정찰 바로가기를 따로 열지 않아도 현재 선택과 실행 기록을 위에서 이어갈 수 있습니다.

## 상품·협업을 구체화할 때

사용할 자리, 필요한 결과물, 검토와 인수 방법을 먼저 맞춥니다. 계약·서비스 개시 상태와 제공 범위는 그때 확인합니다. 후속 연구의 실물은 [외국인 직원 첫 30일 체크리스트](../SHIFT/첫30일_체크리스트_v1.md)에서 봅니다. 초안 인증서가 완성된 자격 제도를 뜻하지는 않습니다.

음악·영상·캐릭터 제작은 SYNK PULSE와 연결합니다. 브랜드 공통 기준과 엔진은 SYNK에서 함께 씁니다.
