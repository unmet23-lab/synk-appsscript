# SYNK PULSE — 음악·영상·캐릭터

음악과 장면, 인물과 이야기를 만드는 자료입니다. [현재 소개서](../홍보물/브랜드소개_20260909/pulse.html)로 창작 부문을 설명하고, 실물은 **음악 · 인물 · 캐릭터** 세 폴더에서 꺼냅니다.

## 음악

`음악/수노_받은것`에 새로 받은 수노 파일을 넣습니다. 장르를 아는 경우 시티팝·차분·전자 폴더를 사용하고, 애매하면 분류를 단정하지 않습니다. `_올린것`은 처리한 원본, `_방송판`은 방송에 맞게 만든 음원입니다. 이미 처리한 파일을 새 입력으로 다시 넣지 않습니다.

`이전 방송곡`은 앞서 편성용으로 만든 파일, `참고곡`은 선택해 둔 참고 원본, `뮤직비디오곡`은 인물 영상에 쓰는 곡입니다. **파일명이 방송용이라고 해서 현재 송출 중이라는 뜻은 아닙니다.** 편성·권리·가공 기록은 [음악 자산 장부](../음악자산_장부.md)에서 확인합니다.

길이 늘리기·이어붙이기·다른 생성 모델 비교·시험 배경 합성은 현재 사용할 음원과 분리해 판단하고, 선택이 끝나면 시험판을 걷습니다. 원본을 잃으면 같은 설정으로 똑같이 재생성할 수 있다고 가정하지 않습니다.

## 인물

처음에는 `선택 사진`과 `완성 영상`부터 봅니다. `원본 사진`과 `원본 영상`은 다시 자르거나 편집할 때 씁니다. 영상에서 자동으로 수백 장 뽑아 둔 중간 사진은 원본 영상과 선별 사진이 있어 걷었습니다.

학습을 다시 할 때만 `학습 자료`를 엽니다. `원본 묶음`은 선별한 학습 원본, `업로드 묶음`은 업로드용으로 준비한 판, `새 사진 후보`는 후속 선택이 반영된 후보입니다. 서로 역할이 달라 크기가 작다는 이유만으로 원본과 업로드판을 바꾸지 않습니다.

새 후보를 고를 때는 얼굴이 크고 선명하며 각도·표정·조명이 다양한 사진을 남깁니다. 다른 사람이 중심인 컷, 흐린 컷, 많이 가린 컷은 제외합니다. 개인 사진과 음성·영상 원본은 공개 저장소에 올리지 않습니다.

## 캐릭터와 시각 요소

`캐릭터`에는 실물 제작에 쓰는 자료를 둡니다. 공통 요소와 브랜드 킷은 바탕화면 `SYNK/엔진·브랜드`를 통해 가져옵니다. 캐릭터의 모습과 표정은 정본을 따르고, 낮은 해상도로 늘린 사진이나 뜯긴 가장자리 시험판을 완성물에 쓰지 않습니다.

제작 협업의 범위와 권리는 SYNK SHIFT와 확인합니다. 폴더를 새로 늘릴 때는 현재 작품에 쓰는 원본·선택본·완성본 중 어디에 해당하는지 먼저 정합니다.
