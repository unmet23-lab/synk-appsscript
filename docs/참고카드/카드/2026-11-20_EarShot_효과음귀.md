## 무엇인가
EarShot(github.com/Leonxlnx/earshot)은 코딩 에이전트에게 「귀」를 달아 주는 무료 오픈소스 도구다. 코드는 MIT 라이선스다.
- 듣는 방법: 내 컴퓨터의 CPU에서 공개 모델 둘을 돌린다. CLAP(`laion/larger_clap_general`, Apache-2.0)은 글과 소리를 견주고, AST(AudioSet 분류기, BSD-3)는 소리에 이름표를 붙인다. 모델은 처음에 약 1.1GB를 내려받는다. API를 부르지 않는다(Gemini를 쓰는 `llm` 명령만 예외다).
- 명령: `describe`(이 파일이 무슨 소리인지), `rank`(설명에 맞는 순서로 폴더 줄 세우기), `timeline`·`critique`·`measure`(완성 소리 점검), `forge`(코드로 새 소리 만들기), `sfx`(내장 252개에서 꺼내기), `kit`(편 전용 사운드 키트).
- Claude Code에는 MCP 서버(`claude mcp add earshot -- earshot mcp`)와 스킬 두 개(`earshot`, `real-sound`)로 붙는다.
- 내장 소리 252개 가운데 15개는 CC0 녹음을 본떠 만들었다. 묶음 전체의 라이선스는 저장소에 적혀 있지 않다.
- Windows 지원은 따로 밝히지 않았다. Python 3.10 이상과 ffmpeg가 필요하다.

## 가져올 것
1. `rank` — 장면 설명 한 줄로 그 편의 효과음 폴더를 귀로 줄 세운다. 파일 이름으로 하던 짐작을 대신한다.
2. `timeline`·`critique` — 완성 믹스에서 효과음이 어느 초에 무슨 소리로 들리는지 로컬에서 잰다. Gemini에게 들려 단정하던 확인을 보탠다.
3. `forge`·`kit` — 폴더와 내장 소리 어디에도 맞는 것이 없을 때 코드로 만든다. 브랜드 사운드킷(`tools/사운드킷빌드.js`)과 같은 방식이다.

## SYNK 적용
- 지금 모습: 효과음은 편마다 회차 폴더에서 고른다(`docs/마케팅/콘텐츠_제작방식_v2_20261002.md` 313행). synk-video 스킬에는 효과음 고르는 절차가 없다. 11-07에 LAB 「달리며 건너뛰는 한국」 편에서 로컬 CLAP(`laion/clap-htsat-unfused`)으로 후보를 걸렀다. 그 스크립트는 편과 함께 지워졌고, 잎 바스락·종이·비닐을 가르지 못했다(`docs/현장노트/AI_CLI.md` 213행). 완성 믹스를 Gemini에게 들렸을 때는 없던 지지직이나 1초 어긋남을 단정한 적이 있다(`docs/현장노트/gemini_사진.md` 1333행).
- EarShot이 나은 점: CLAP 모델이 더 크고, AudioSet 이름표(AST)를 함께 본다. 그래서 우리 스크립트가 못 가르던 재질 소리를 가를 가능성이 있다. 편마다 다시 짜던 거르기를 공용 명령 하나로 쓸 수 있다. 완성본 확인도 로컬에서 재므로 지어낸 답이 없다.
- 넣을 자리: Claude Code 사용자 MCP와 `~/.claude/skills/`, synk-video 스킬의 편집 단계에 「효과음은 `earshot rank`로 고르고 완성 믹스는 `timeline`으로 본다」 한 줄.

## 확인할 것
- 11-07에 CLAP이 못 가른 잎·종이·비닐 소리를 EarShot `rank`가 가르는지.
- 완성본 한 편에서 `timeline`이 낸 효과음 시각이 컷표의 효과음 시각과 맞는지.
- Windows에서 설치와 MCP 연결이 되는지, CPU에서 폴더 20개를 듣는 데 얼마나 걸리는지.

## 적용 요청문
EarShot(github.com/Leonxlnx/earshot, MIT)을 이 PC의 Claude Code에 붙이는 시안을 만들어 줘.
1. 저장소 밖 도구 폴더에 `uv tool install`로 설치하고 `earshot doctor --fetch`로 모델(약 1.1GB)을 받는다. 무료이고 가입이 없다. Windows에서 막히면 막힌 자리와 해결을 `docs/현장노트/AI_CLI.md`에 남기고 멈춘다.
2. 효과음 폴더가 있는 최근 편 하나(LAB 또는 PULSE)를 고른다. 컷표의 효과음 설명마다 `earshot rank "<설명>" <폴더> --top 5`를 돌린다. 그 편에서 실제로 고른 파일과 나란히 놓는다. 11-07 CLAP이 헷갈린 잎·종이·비닐 시험도 같이 돌린다.
3. 그 편의 완성본에 `earshot timeline`을 돌려 컷표의 효과음 시각과 견준다.
4. 결과를 표 한 장(설명, 고른 파일, EarShot 1~3위, 맞음 여부, 걸린 시간)으로 `.tmp/`에 만들어 유호님께 보인다. 이것이 시안이다.
5. 유호님이 「적용」하시면 그때 `claude mcp add earshot --scope user -- earshot mcp`로 연결하고, synk-video 스킬 편집 단계에 한 줄을 넣는다. 현장노트에도 「먼저 볼 것」 한 줄을 남긴다.
- 작업량: 설치와 모델 내려받기 30분, 비교표 한 시간 안팎.
- 위험: 내장 소리 252개 묶음의 라이선스가 밝혀져 있지 않다. 그래서 게시물에는 우리 폴더의 소리와 `forge`로 만든 소리만 쓰고, 내장 소리는 라이선스를 확인한 뒤에 쓴다. 모델 1.1GB는 C: 공간 기준(`docs/_ops/트랙.md`의 PC 공간 절)을 보고 D:에 둘지 정한다.
