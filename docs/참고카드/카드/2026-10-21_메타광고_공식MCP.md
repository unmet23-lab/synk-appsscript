## 가져올 것

1. **공식 주소 하나만.** 영상은 「구글 첫 번째 링크」를 따라가라며 주소를 가렸다. 검색 결과에는 남이 운영하는 광고 MCP도 섞여 있고, 그쪽도 광고 계정 권한을 달라고 한다. 우리는 메타 개발자 문서에 적힌 `https://mcp.facebook.com/ads`만 쓴다.
2. **꺼진 채 만들고, 켜기는 확인 뒤.** 공식 쓰기 도구가 이미 이렇게 생겼고, 우리 원칙(실제로 돈이 나가는 일은 유호님 승인 — AI 운영 원칙 「비용과 권한」)과 그대로 맞물린다. Claude는 예산·기간·나라·나이까지 넣은 꺼진 초안을 만들고, 유호님 「켜」 한마디 뒤에 `ads_activate_entity`를 부른다.
3. **광고 숫자를 화면이 아니라 표로.** 지금 Meta 숫자를 읽는 길은 Business Suite 화면(ego)과 회사 서버의 성과 자동 수집(유기)뿐이다. 광고를 돌리게 되면 광고 관리자 화면을 긁지 않고 `ads_get_ad_entities`(날짜 범위·나눔)로 받아 72시간 판정 표 옆 칸에 둔다.

## SYNK 적용

| | 지금 | 공식 커넥터를 붙이면 |
|---|---|---|
| 유기 숫자(조회·도달·보내기·저장) | 성과 자동 수집(인스타 Graph `/{media}/insights`, 페북 페이지 인사이트) + 72시간 앱 예약 + Business Suite 화면(ego) | 그대로 — 커넥터에는 유기 지표가 없다 |
| 광고 숫자 | 없음(유료 광고를 돌리지 않음) | `ads_get_ad_entities` · `ads_insights_performance_trend` |
| 광고 만들기·켜기 | 없음 — 한다면 광고 관리자 화면을 손으로 | 꺼진 초안 → 유호님 확인 → `ads_activate_entity` |
| 권한 | 브라우저는 로그인한 계정 전부 | 고른 권한만(`ads_read`부터) |

- **SNS·영상 — 첫 유료 광고 때:** §6 판정은 지금 「상위 25% → 같은 형식 세 편 더 · 현지어판 · 맞춤 프로그램」으로 넓힌다. 여기에 「소액 부스트」를 더할지는 돈이라 유호님이 정한다. 정하면 이렇게 돈다: 금요일 판정 → Claude가 `ads_get_ig_media`로 그 릴스를 찾아 `ads_boost_ig_post`로 꺼진 초안 → 유호님 「켜」 → 72시간 뒤 광고 숫자를 같은 회차 `성과.json`에 「광고」 칸으로. 몽골은 페이스북 광고 도달 270만 명이 주 시장이고(§4-1 표) LAB 몽골 편은 인스타 @synk.mn·페북 SYNK에 교차 게시하니, 인스타 게시물로 부스트하고 광고 위치는 초안에서 확인한다.
- **PULSE — 납품 뒤 성과를 붙일 때:** 고객이 「유료 광고 노출」을 고른 프로젝트(`client-changes.mjs`의 distribution `paid`·`mixed`)는 고객 광고 계정의 파트너 권한을 받으면 납품한 컷별 성과를 `ads_get_ad_entities`로 읽어 다음 판의 근거로 쓸 수 있다. 조사 도구(`creative-research.mjs`)가 광고 라이브러리 사례에 성과 숫자를 못 넣게 막는 것은 남의 광고라서 맞고, 고객 자기 광고는 경우가 다르다. 남의 계정에 접근하는 일이라 고객 동의와 유호님 결정 뒤다.
- **AI 작업 방식 — 연결:** 대화(claude.ai·데스크톱 앱)는 사용자 지정 커넥터로 앱 없이 붙이고, Claude Code·예약 작업은 공식 명령을 쓴다(메타 앱 ID 필요 — 성과 자동 수집이 쓰는 메타 앱에 「Create & manage ads with ads MCP server」 사용 사례를 더하는 쪽). 로그인과 권한 승인은 유호님 손이고(운영 원칙 — 로그인·권한 부여), 연결 뒤 확인은 Claude가 한다.
- **쓰지 않는 곳:** 광고 켜기·예산 올리기를 Claude 혼자 하지 않는다. 켠 뒤 학습 단계 동안 자잘하게 고치지 않는다. 유기 숫자를 커넥터에서 찾지 않는다.

## 확인할 것

연결은 로그인·권한 승인이 필요해 이번에 해 보지 않았다. 그 작업 때 이 순서로 본다.

1. 연결 직후 읽기만(`ads_read`): 광고 계정 목록, 지난 28일 지출(0이 정상), `ads_get_ig_media`에 @synk.mn 릴스가 나오는지.
2. 꺼진 초안 하나(`ads_management`로 넓힌 뒤): 72시간 판정 상위 편으로 `ads_boost_ig_post` → 광고 관리자에서 「꺼짐」인지 눈으로 본다. 지우는 도구가 없으니 쓰지 않을 초안은 광고 관리자에서 유호님이 지운다.
3. 켠 뒤(유호님 「켜」): 72시간에 `ads_get_ad_entities` 숫자가 광고 관리자 화면 숫자와 같은지, 활동 기록에 Claude가 한 일만 남았는지.
