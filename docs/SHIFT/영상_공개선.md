# SYNK SHIFT 영상 — 실제 AI 작업을 공개하는 기준

> 현행 2026-09-10 · 유호의 실제 이야기와 AI로 혼자 회사를 만드는 과정을 중심으로 한다. 이야기·채널 편성은 [SHIFT 마케팅](../마케팅/SHIFT.md), 이 문서는 실제 화면·입력·결과를 공개하는 범위를 맡는다. 현재 사용자 요청이 과거 촬영안보다 우선한다.

## 1. 무엇을 보여주는가

실제 회사에서 부딪힌 문제, AI에 맡긴 일, 실제 입력과 출력, 실패와 수정, 유호의 선택, 지금 확인한 결과를 깊이 보여준다. 얼굴·목소리·작업 공간과 함께 실제 작업 화면을 사용할 수 있다. 특정 도구나 코드 파일 이름만으로 공개 가능 여부를 판정하지 않는다.

| 화면과 재료 | 현재 공개 기준 |
|---|---|
| 유호의 실제 이야기·얼굴·목소리·작업 공간 | 해당 실제 기록을 사용한다. AI가 만든 대본·음성을 유호의 실제 발언이나 촬영처럼 표시하지 않는다 |
| AI 대화·프롬프트·생성 결과·도구를 사용하는 화면 | 실제 사용한 입력과 결과, 재시도와 고친 부분을 보여준다. 도구·모델이 바뀌어도 같은 기준을 적용한다 |
| 자기 회사의 문서·디자인·코드·자동화·앱 시연 | 과정을 설명할 만큼 구체적으로 공개한다. 자격증명·학생 식별정보·타인 원자료를 제거한 공개판을 쓴다. 엔진·contents·DB라는 이름 자체로 막지 않으며, 공개하기로 하지 않은 제품 계약·학습 원본·독점 자료는 분리한다 |
| 합성 데이터나 재현 화면 | 예시·재현임을 표시하고 당시 실제 화면과 구분한다. 잘된 결과를 다시 만들어 실제 첫 시도처럼 편집하지 않는다 |
| 실패·비채택·사람이 개입한 결과 | 이유와 실제 비교를 남긴다. 특정 후보의 실패를 해당 기술 전체의 실패로 확대하지 않는다 |
| 실제 학생·학부모의 행·얼굴·목소리·글, 타인의 미공개 자료 | 이번 과정 공개 승인에 포함되지 않는다. 실제 원본을 가리는 방식 대신 처음부터 공개용 예시를 사용한다. 학습 이용 동의를 홍보 동의로 바꾸지 않는다 |
| 비밀번호·키·토큰·로그인/금융 계정 화면 | 공개하지 않는다. 녹화 전 공개용 작업 화면에서 제거한다 |
| 직원·협업자의 얼굴·목소리·회신 원문 | 당사자의 공개 범위·동의를 확인한다. 동의 없는 원문 대신 출처와 범위를 지킨 요약·공개 예시를 사용한다 |
| 개인 매출·수익·투자금·금융 내역 | 이번 방향 승인으로 공개 범위를 확대하지 않는다. 이미 공개된 상품의 가격·지원 조건과 개인 금융 화면은 구분한다 |
| 작업량·실제 결과·진행 상태 | 확인한 수치와 범위를 쓴다. 작업량을 고객 효과나 매출로 환산하지 않고, 제작·시험·배포·사용·효과를 구분한다 |

## 2. 깊이 공개하고 읽히게 편집한다

한 편은 실제 사건을 따라간다. 무엇을 하려 했고, AI와 어떻게 시도했으며, 어떤 결과 때문에 판단이 바뀌었고, 지금 어디까지 왔는지 보여준다. 모델 화면만 빠르게 넘기는 장면으로 과정 설명을 대신하지 않는다.

긴 대기·중복 대화·같은 오류 반복은 편집할 수 있다. 실패, 사람이 고친 부분, 아직 안 되는 범위를 지워 전 과정이 자동 성공한 것처럼 만들지 않는다. 실제 기록 일부를 확대하거나 예제로 바꾸면 그 차이를 알린다. 매편 모든 작업 로그·코드·프롬프트의 전량 공개를 요구하지 않는다.

완성된 일은 완료형으로, 진행 중인 일은 현재 상태로, 앞으로 할 일은 계획으로 말한다. 미공개·미운영 결과에 완료 표현을 붙이지 않고 모든 결과를 ‘짓고 있습니다’라는 한 시제로 제한하지도 않는다.

과정에서 나온 팁과 방법은 본편 안에서 이해할 수 있게 전달한다. 관련 원본·자료·재현법은 도움이 될 때 잇고 모든 이야기를 강의나 작업지로 끝내지 않는다. 타인의 적용 수요가 생기면 [후속 교육 기준](../마케팅/SHIFT_공개수업.md)에 따라 직접 도울 수 있는 범위를 정한다.

## 3. 실제 회사의 다음 단계로 이어간다

앱·마스코트·브랜드·음악은 실제 회사의 목적과 연결된 사건으로 고른다. 제작물의 양에 머물지 않고 실제 사용·모집·고객 질문·운영에서 확인한 변화도 이야기의 재료로 쌓는다. SHIFT 시청 반응을 LAB 학생 수요나 회사 수익의 증거로 합치지 않는다.

현재 증거가 있는 첫 사례 후보는 [까몽 3D 비채택 이야기](../홍보물/까몽_제작이야기_20260909/기획과사용법.md)다. 기존 일반 합성음성의 가상 실습 영상은 보조 교육 자산이며 유호의 실제 과정 기록으로 바꾸어 부르지 않는다. 실제 첫 본편은 사용할 작업 기록과 유호의 실제 설명을 확인해 편집한다. 새 편수·발행 비율·고정 일정은 이번 방향으로 정하지 않는다.

과거 12칸·첫 10편 초안과 당시 판단은 Git 이력에 남아 있다. 현행 촬영·편성에 옛 관객 단정이나 파일명별 일괄 금지를 다시 적용하지 않는다. 계정과 게시 업무 분담은 [채널과 발행](../마케팅/채널과_발행.md)을 따른다.
