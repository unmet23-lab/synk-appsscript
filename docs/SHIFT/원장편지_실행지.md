- **섹션** — 한 발행물 안에서 갈래를 나누고 구독자가 갈래를 고른다. ✅ 09-03 에 실물로 확인했다(설정 → 섹션 → 섹션 추가).

- ✅ **09-03 에 닫힌 것 셋**(09-02 에 「안 재봤다」로 적어 둔 자리): ㉠섹션 기능 **있다** ㉡**자동 번역**이 기본으로 켜져 있다 — 몽골 독자가 한국어 편지를 제 언어로 읽는다 ㉢**소유권을 통째로 이전**할 수 있다(위험 구역) — 나중에 직원·법인에 넘기는 길이 열려 있다.

- **순번(#001…)을 섭스택이 대신 낼 수 있는지** — 「구독자 추천 설정」은 있으나 순번은 아니다. 크루카드가 진다.
