### 7-1-B. 왜 한때 `synklab` 이었나 (역사)

**이미 있는 계정을 씁니다.** 같은 날 앞서 세운 `synklab` 확정을 이걸로 대체했습니다.

🔑 **제 오판을 적어 둡니다** — `synklabmn` 을 기각한 근거(「나라를 박으면 테라포밍하는 날 거짓말이 된다」)는 **SHIFT 에는 맞지만 LAB 에는 안 맞습니다.**
SHIFT 는 «사람·브랜드»가 나라를 옮기는 층이고, **LAB 은 «지역 학원»이라 그 계정이 옮겨갈 일이 없습니다**(베트남에 가면 그날 새 계정을 엽니다). 층을 안 가르고 같은 자를 댄 것이 잘못이었습니다.
- 잃은 것 0 — `synklab` 은 아직 아무 데도 안 잡았습니다.
- 틱톡·페이스북 사용자 이름도 **`synk.mn` 으로 맞춥니다**(한 이름으로 통일하는 값은 그대로입니다).
- ⛔ 유튜브 `@synklab` 은 여전히 남의 것이고 **LAB 유튜브는 포기** 그대로입니다.

## 🔴🔴 붙여도 «단장»은 제가 못 합니다 — 09-01 실측으로 확정

**계정 센터 연결이 사는 것은 «로그인 편의»뿐입니다.** Meta 는 **값을 바꾸는 행위마다 재인증**을 걸고,
**그 재인증이 제가 채운 값을 날립니다.**

실측 — `@yuhobuilds` 표시 이름을 확정 문안으로 바꾸려 했습니다:
  ① 계정 센터 → 프로필 → 이름 → **제가 값을 채웠습니다**(화면에도 보였습니다)
  ② 「완료」 → **「회원님이 맞는지 알려주세요 — 보안을 위해 비밀번호를 입력해주세요」**
  ③ 유호님이 비밀번호 입력 → **원래 화면으로 안 돌아가고 닫혔습니다**
  ④ 재확인: 이름이 **여전히 「유호」**. **채운 값이 재인증을 지나며 날아갔습니다.**

🔴 **제가 09-01에 「붙으면 단장은 제가 하겠습니다」를 여러 번 말했고, 그건 틀렸습니다.**
   ⇒ **같은 약속을 다시 하지 않습니다.**

| 무엇 | 제가 |
|---|---|
| 화면 열기 · 어디를 눌러야 하는지 찾기 · 읽기 · 검증 | ✅ 됩니다 |
| 값 «채우기» | ✅ 되지만 **재인증을 지나면 날아갑니다** |
| **값을 «저장»하기** | 🔴 **재인증 벽을 못 넘어 원리상 못 합니다** |

▶ **남은 단장은 유호님이 폰 앱에서** 하십니다. 제 몫은 **문안 준비까지**입니다(문안 = §2).

### 7-4. 소개글은 왜 비워 뒀나

▶ **이름과 사진이 먼저입니다** — 그건 되돌릴 수 없는 자산이고, 소개글은 언제든 바뀝니다.
