## 7. LAB(학원) 계정 — ✅ `synk.mn` (유호 확정 09-01)

> SHIFT 와 **관객이 다릅니다** — 여기는 몽골 학생·학부모입니다.
> 🔑 경쟁실사(08-28) 서열: **페이스북 압도 → 인스타·틱톡은 사실상 공백**(한국어 학원 중 인스타 1,000팔로워 0곳 · 틱톡 검색 0건).

### 7-1. 이름 — `synk.mn` 그대로 간다 (`synk.im` 은 막혔다)

🔴 **09-01 실측 — 인스타 사용자 이름 변경 화면이 유일한 자입니다.** 도메인 `synk.im` 이 이미 돌고 있어(A 4벌 GitHub Pages · MX Workspace) 「핸들 = 도메인 한 글자」를 노렸는데, 변경 화면이 **거부**했습니다.

| 후보 | 변경 화면 판정 |
|---|---|
| `synk.im` | ❌ 사용할 수 없는 사용자 이름 |
| `synklab` | ❌ 사용할 수 없는 사용자 이름 |
| `synk.lab` | ❌ 사용할 수 없는 사용자 이름 |
| `synkkorean` | ✅ 쓸 수 있다 |
| `synk.academy` | ✅ 쓸 수 있다 |
| *(무작위 대조군)* | ✅ — **자가 살아 있음을 이걸로 확인했습니다** |

⇒ **도메인 일치가 원천 불가능해졌으므로 `synk.mn` 을 버릴 이유가 사라졌습니다.** `.mn` 은 오히려 LAB 의 관객(몽골 학생·학부모)에게 **몽골 학원임을 즉시 말합니다.**

🔴 **남는 결함 하나** — `synk.mn` 은 **NXDOMAIN**(없는 도메인)입니다. 전단·간판에 도메인처럼 적으면 죽은 주소가 됩니다.
▶ **표기 규칙**: 인스타는 반드시 **`@synk.mn`** 으로 `@` 를 붙이고, **웹 주소 자리에는 `synk.im`** 을 적습니다.
⏳ **유호님 픽으로 남깁니다** — `.mn` 도메인 구매. 사면 인스타·웹이 같은 글자가 되어 이 결함이 사라집니다(값은 안 재봤습니다 · 돈 드는 항목은 모아서 나중에).

### 7-1-B. 왜 한때 `synklab` 이었나 (역사)

**이미 있는 계정을 씁니다.** 같은 날 앞서 세운 `synklab` 확정을 이걸로 대체했습니다.

🔑 **제 오판을 적어 둡니다** — `synklabmn` 을 기각한 근거(「나라를 박으면 테라포밍하는 날 거짓말이 된다」)는 **SHIFT 에는 맞지만 LAB 에는 안 맞습니다.**
SHIFT 는 «사람·브랜드»가 나라를 옮기는 층이고, **LAB 은 «지역 학원»이라 그 계정이 옮겨갈 일이 없습니다**(베트남에 가면 그날 새 계정을 엽니다). 층을 안 가르고 같은 자를 댄 것이 잘못이었습니다.
- 잃은 것 0 — `synklab` 은 아직 아무 데도 안 잡았습니다.
- 틱톡·페이스북 사용자 이름도 **`synk.mn` 으로 맞춥니다**(한 이름으로 통일하는 값은 그대로입니다).
- ⛔ 유튜브 `@synklab` 은 여전히 남의 것이고 **LAB 유튜브는 포기** 그대로입니다.

### 7-4. 소개글은 왜 비워 뒀나

**LAB 은 관객이 몽골 학생·학부모라 소개글이 몽골어여야 합니다.** 제가 초안을 쓸 수는 있지만 **감수를 거치지 않은 몽골어를 학생 접점에 올리지 않습니다**(저장소 관례 · 통로 = `gemini-mn-check` · 발주서 §B).
▶ **이름과 사진이 먼저입니다** — 그건 되돌릴 수 없는 자산이고, 소개글은 언제든 바뀝니다.
