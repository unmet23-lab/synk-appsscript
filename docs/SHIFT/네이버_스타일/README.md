# SYNK SHIFT 네이버 블로그 스타일

현재 공개 화면의 `눈사람` 스킨을 교체하기 위한 적용 원본이다. 글이나 계정 정보는 건드리지 않고, 공개 화면의 스킨·레이아웃·글 스타일만 바꾼다.

## 적용값

- 스킨 바탕: `synkshift_네이버_스킨.png` · 가운데 위 · 반복 없음
- 배경색: Paper `#FBF7F0`
- 본문 글자: Ink `#2B2320`
- 보조 글자: Deep Wool `#575046`
- 링크·안내: Lapis Deep `#24448C`
- 행동 신호: Coral `#F96859`, 작은 면에만 사용
- 레이아웃: 가운데 정렬 · 글 영역 넓게 · 한 단
- 공개 구성: 블로그 제목 중복 표시 끔 · 프로필·카테고리·검색만 남김 · 블로그씨·안부·서재·불필요 RSS 표시 숨김
- 제목: 사용 가능한 산세리프 중 가장 단정한 `나눔스퀘어` 우선, 없으면 `나눔고딕` · 굵게
- 본문: `나눔고딕` 또는 기본 산세리프 · 16px 상당 · 줄간격 1.7 · 왼쪽 정렬
- 게시물 강조: 본문에 밝은 Coral 글자를 쓰지 않고 Ink 굵기 또는 Coral 3 계열로 제한

네이버 스킨에는 SUIT Variable을 웹폰트로 직접 설치할 수 없으므로, 헤더 이미지에는 실제 SUIT Variable을 구워 넣고 편집기 본문은 네이버가 제공하는 가장 가까운 산세리프를 사용한다. 폰트 이름만 비슷하게 적어 놓고 적용 완료로 세지 않는다.

## 작업·검수

```powershell
node tools/네이버스킨굽기.js
```

적용 뒤 PC 공개 주소와 모바일 공개 주소를 각각 비로그인 상태로 확인한다. 제목 중복, 1,000px 안쪽의 로고·문안 잘림, 본문 대비, 사이드바 과밀, 가로 스크롤이 있으면 완료로 세지 않는다.
