# SHIFT 내부 시범 — 소개 원고 검수

2026-10-07. 실제로 쓰이는 로컬 SHIFT 소개 원고 5구간을 같은 정본과 대조했다. 기존 방식과 Atlas 개인화 방식으로 독립 AI 작업자가 한 번씩 수행했고, 두 결과 모두 현재 원고 유지 판정이다. **실제 사람의 사용성·시간 절감·만족도나 고객의 성과를 검증한 시범은 아니다.**

## 실제 업무와 두 방식

- 업무: 현재 소개의 한 업무 범위, 네 적용 후보, Atlas·SHIFT 책임, 도입 지원, 반복 공급 뒤 API·라이선스 순서 검수.
- 입력: 현재 로컬 홈페이지 JSON과 SHIFT 사업 정본을 해시로 고정한 [원문 묶음](input/common.json). 준비 상태와 미검증 조건을 설명하는 `note`를 포함했고 오류를 심지 않았다. 공개 홈페이지의 현재 상태는 확인하지 않았다.
- 기존: 원고 순서 C1 → C2 → C3 → C4 → C5, 공통 판정 기준.
- 개인화: 기존 Core `domain.js`가 현재 대화에서 사용자가 명시한 공통/전문 책임, 사업 범위 집중, 이후 라이선스 확장 방향을 반영해 C3 → C5 → C1 → C2 → C4 순서를 선택했다. [원결정·근거](input/atlas-decision.json)를 함께 전달했고, 모든 구간의 판정 기준은 같게 유지했다.
- 검수 의미·후보와 중요도 2/1/1은 이번 SHIFT 업무 정책이다. Atlas 원본을 바꾸거나 사용자 능력·성향·선호 강도로 저장하지 않았다. 계정 프로필과 운영 DB를 만들거나 변경하지 않았다.

[사전 입력·판정 기준과 실행 경계](protocol.json)는 결과를 보기 전에 준비했다. 실행 중 시간 경계 설명을 각 작업자에게 전달한 지시와 일치시키는 정정을 기록했다. 원고·정본·6개 판정 기준·완료 조건은 그대로 유지했다.

## 확인 결과

| 항목 | 기존 | 개인화 |
|---|---:|---:|
| 검수한 실제 구간 | 5 | 5 |
| AI 과업 완료 | 1 / 1 | 1 / 1 |
| 검수 결과의 실질 오류 | 0 | 0 |
| 필수 원고 수정 | 0 | 0 |
| AI 경과시간 | 99초 | 77초 |
| 사람 전환·사람 작업시간·만족도 | 미측정 | 미측정 |

오류 수는 원고에서 찾아낸 문제 수가 아니라, 완성된 검수 결과가 사전 기준·완료 조건을 어긴 실질 오류 수다. 두 결과 모두 근거 있는 ‘문제 없음’으로 완료했다. [별도 결과 검수](results/independent-assessment.json)에서 6개 기준과 전체 구간을 다시 확인했다.

시간은 각 작업자의 첫 시각 확인 도구부터 결과 저장 직전까지이며, 입력 읽기·추론·도구와 서비스 지연을 포함한다. 대표의 준비·최종 검증 시간과 배정 전 대기는 빠져 있다. 방식별 한 번이고 개인화에는 추가 입력이 있으므로 22초 차이를 개인화의 시간 절감, 인간 생산성 또는 모델 성능 우위로 주장하지 않는다. 초 단위 도구 시각의 기록 정밀도에도 한계가 있다.

두 방식이 같은 필수 판정을 내렸으므로 이번 비교에서 추가 품질 이득은 확인하지 못했다. **검토 우선순위가 요청에 따라 달라진 것은 확인했고, 결과가 더 좋아졌다는 주장은 보류한다.**

이번 원고는 앞선 정본 정리와 검증을 거친 자료라 두 방식 모두 잘 끝내기 쉬웠다. 이 한 건은 새로운 문제 발견이나 사용자 부담 감소를 판별하기에 충분한 과제가 아니다. 다음 사람 시범에서는 실제 초안 작성·근거 확인·수정까지 필요한 업무와 난이도 차이를 함께 기록해야 한다.

## 다음 판단

이번 결과로 공통 Atlas 기능 추가나 전면 재개발을 정당화하지 않는다. 이 시범의 검수 정책은 SHIFT에 두고 기존 공통 Core를 재사용한다. 현재 원고를 유지하고, 실제 사람이 수행할 업무에서 질문 반복·누락·필수 수정과 업무 완료 시간을 비교할 필요가 있다. 첫·두 번째 외부 고객, 운영 환경, 가격·출시·인수 기준은 여전히 미정이다.

`prepare.mjs`는 고정 자료를 한 번 준비한 원본이며 기존 시범이 있으면 재실행을 거부한다. `verify.mjs`는 이번 고정 입력과 실제 결과만 검증한다. 기존 빈 계산표, 홈페이지 원고, 회사 서버·계정·운영 자료와 공통 엔진은 보존했다. 배포·외부 연락은 실행하지 않았다.
