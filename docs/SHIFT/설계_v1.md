# SYNK SHIFT — 현재 담당과 장기 설계의 입구

## 현재 사업과 제품

현재 신규 사업·BM은 **범위가 분명한 기업용 개인화 서비스의 도입·운영**이다. 고객사 한 업무에서 시작해 같은 유형의 반복 공급·고객 효과·수익성을 확인한 뒤 API·엔진 라이선스로 확장한다. 교육·컨설팅·자동화·브랜딩·시장조사·제품 테스트는 그 도입·활용·검증을 돕는 범위다. 확정 범위·적용 후보·단계는 [SHIFT 사업·BM 정본](../마케팅/SHIFT.md#shift-bm)에서 관리한다.

공통 Atlas 기술은 SYNK, 기업 대상 판매·도입·운영은 SHIFT가 맡는다. 기업의 한 업무에 필요한 전문 정책·고객 설정·권한·자료 연결과 공통 엔진을 구분한다. 기존 계약·약속과 실제 계약·청구·권리 주체는 개별 근거로 확인한다. 브랜드 방향 채택을 법인 설립·고용·고객 운영·매출·효과의 증거로 삼지 않는다.

[내부 시범](내부시범_20261007/README.md)은 실제 원고를 대상으로 한 AI 작업 비교이며 사람 생산성·외부 고객 성과를 입증하지 않았다. [한 업무 실증과 반복 공급](실증_20261007/README.md)은 빈 측정 도구다. 고객·가격·인수·지원 조건을 그 도구의 존재만으로 확정하지 않는다.

## 다른 브랜드와의 관계

- **LAB:** 한국어 학습과 학원 운영. 옛 고정 개원일·자동화 41종·시트 배치가 현재 운영 중이라는 문구는 적용하지 않는다. [현재 학원 운영](../오프라인_공간설계/오프라인_운영기준_20261002.md)을 따른다.
- **PATH:** 유학·취업·주거·정착 및 개인화 여행의 담당 브랜드다. 08월의 「첫 학생이 한국에 간 뒤 PATH를 꺼낸다」는 조건은 09-18 이후의 브랜드 분리로 대체됐다. 실제 제공 범위는 [사업 발전](../사업발전_정본.md)·[개인화 여행](../PATH_개인화여행_설계.md)을 따른다.
- **PULSE:** 의뢰받는 광고·모델·룩북 제작과 자체 콘텐츠·IP를 함께 맡는다. SHIFT의 기업 도입 지원과 구분한다.
- **개인 콘텐츠:** 실제 회사를 만드는 경험·판단·결과를 보여 주는 활동이다. 브랜드의 영업 범위나 고정 말투를 대신하지 않으며 [제작 방식](../마케팅/콘텐츠_제작방식_v2_20261002.md)을 따른다.

## 유지하는 장기 연구

08-27에 채택한 **SYNK 인증과 국가공인 민간자격 발급 기관이라는 장기 목표**, 직무·한국어를 함께 연습하고 확인하는 구상은 보존한다. 다만 현재 SHIFT 신규 영업의 범위·필수 선행 과제로 부활시키거나 등록·공인·취업 효과를 획득했다고 소개하지 않는다.

| 보존할 구상 | 현재 적용할 경계 |
|---|---|
| 직원에게 반복 업무와 판단 근거를 인계할 수 있는 구조 | 채용 인원·직원 능력·교육 효과·업무 시간은 실제 확인. 촬영·공개는 별도 동의 |
| 지시 수용·되묻기·보고·안전·관계 언어의 상황 연습 | 실제 장면과 전문 검토로 기준을 만들며 접속량·반응시간 하나로 실무 능력을 확정하지 않음 |
| 컴퓨터·폰·VR 등 복수 통로와 접근성 | 같은 능력을 측정하는지 별도 검증. 특정 장비나 07월의 단계 순서를 모든 개발의 전제 조건으로 두지 않음 |
| 졸업 후 같은 계정과 직장 모드 | [제품방향](../제품방향.md)의 대상·지원 준비를 따른다. 학습 기억·연락·취업 결과의 사용은 동의·맥락·권한별로 구분 |
| 처음 목표와 이후 실제 결과의 대조 | [궤적](../궤적_원장기록_실행지.md)의 현재 원문·코드로 연결한다. 삭제된 GAS 원장·폼을 복원하지 않음 |
| 자격의 종목·등급·검정·재응시·본인 확인 연구 | 등록·공인 요건과 허용 직무·시행 지역을 실제 추진 시 공식 근거·전문 검토로 재확인. 옛 조사에 「다시 조사 금지」를 적용하지 않음 |

현재 VR 면접·직업체험의 목적·제작·검증은 [VR 상세 설계](VR직업체험_설계_v1.md#path-vr-mvp-20261011)와 [PATH 실제 구현](../../experiences/path-vr/README.md)을 따른다. 옛 면접 경험 폼의 라이브 표시나 코드 0 선언을 현재 상태로 복사하지 않는다.

## 보존한 과거 자료

08~09월의 구술, 20년 사업 구상, 채용·인계·교육 아이디어, 자격 하나·등급 세 단계, 당시 제도 조사와 시행 순서, 상호 검색·제한시간 사례, 개원·설립 일정 가정은 [정리 전 원문](../_ops/qa/document-cleanup-20261017/_archive/pass2-originals/docs/SHIFT/설계_v1.md)에 모두 남겨 두었다. 고유 연구는 폐기하지 않았으며 현행 사업·권리·법률 상태와 구분해 재사용한다.

옛 「유학생 이탈 예측」·「위조 불가능한 증빙」·「졸업생은 영업망」 표현은 현행 제품 약속이 아니다. 기록은 관측한 사실과 확인된 결과를 구분하고 학생을 고정 평가하거나 고객 명단에 자동 편입하지 않는다. 개원일·공인 연도·직원/고객 수·매출 0 같은 옛 시점의 수치와 도메인 되돌리기 명령도 현재 실행 지시에서 제외했다.
