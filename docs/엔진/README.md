# SYNK 엔진 소개서

Atlas는 기존 8개 엔진의 총칭이다. 새 활용·발전 작업은 [담당 엔진의 원문·코드](../엔진8종_상향설계_v3.md#engine-owner-sources)와 [현재 정의·완료 기준](../아틀라스_설계.md#atlas-engine-ownership)에서 시작한다.

**Atlas 연결을 직접 탐색하는 화면:** [입체 인터랙티브 시안](atlas-constellation-20260921/index.html) · [원본·실행·확인 범위](atlas-constellation-20260921/README.md). 8개 엔진의 설계 관계를 시각화한 독립 시안이며, 실제 구현 상태 지도와 구분한다.

**2026-09-21 기준 8개 엔진의 상태를 보려면 [Atlas 엔진 지도 · 2026-09-21](지도_20260921/SYNK_Atlas_엔진지도_20260921.html)을 연다.** 역할·설계·코드·앱 연결·배포 기록을 구분한 독립 HTML이며 [근거와 재생성 안내](지도_20260921/README.md)가 있다. 바탕화면에도 같은 파일을 둔다. 최신 구현 여부는 담당 원문·코드에서 확인한다. 아래는 기존 소개서의 제작 안내와 과거 확인 기록이다.

2026-09-21에 현재 표기를 8종으로 통일하고 [Strata 소개서](SYNK_Strata_소개서.html)를 추가했다. 지금 소개서는 8개이며 전체 지도까지 9개다. 지도에 Strata를 연결하고 모든 원고에서 다시 생성했다. 9개 화면의 390·1440px 총 18개 보기, 내부 링크·가로 넘침·브라우저 오류를 확인했다. 아래 09-09의 7개 소개서 검수 수치는 당시 제작 이력이다. Strata 표지는 기존 공통 재질을 사용하며, Strata 자체는 설계·준비 단계다.

2026-09-13 · 입구는 `SYNK_엔진_지도.html`이다. 소개서의 역할 설명은 유지하며 현재 제작·제품 계약은 [엔진 8종](../엔진8종_상향설계_v3.md)과 그 문서의 담당 정본에서 읽는다. 아래 09-09 소개서 검사 기록을 현재 구현·배포 확인으로 사용하지 않는다.

Loom의 움직임 지원 결과물은 [현재 표현 기준](../Loom_실시간장면_표현기준.md)을 기본 적용한다. 과거 설계에 기록된 모델 비교·도입 순서·당시 미구현을 새 작업의 금지나 추가 승인 조건으로 되살리지 않는다.

[09-13 지침 정리 결과](../_ops/엔진지침정리_20260913.md)에 압축 범위와 보존한 계약·검증·통합 상태를 기록했다.

원고는 `_원고/`에 있고, 완성 HTML은 이 폴더에 둔다. 원고를 고친 뒤 다음 명령으로 다시 만든다.

```
node tools/펠트문서.js --굽기 docs/엔진/_원고/SYNK_Core_소개서.html docs/엔진/SYNK_Core_소개서.html
```

다른 엔진과 지도도 같은 통로를 쓴다. 완성 HTML을 직접 고치지 않는다.

공통 지면은 Loom의 `엔진전시()`를 사용한다. `엔진전시` 클래스가 있는 원고만 고해상도 표지와 전시 레이아웃을 받으며, 기존 지면의 기본값은 유지한다. 표지는 `docs/Loom_자산/구움/히어로_<엔진>_4K.avif` 제작 원본을 그대로 넣는다. 투명 여백을 잘라 둔 자산이므로 실제 크기는 엔진마다 다르며, 모든 그림이 3840×2160이라는 뜻은 아니다. 한글과 영문 글꼴을 함께 내장했다.

소개서 재작성 때의 확인: 원고 7/7 전체 내용 대조, 설계 링크 48/48 대상 존재. 지도까지 8개 화면을 390·1440·3840픽셀 폭에서 검사해 24/24에서 가로 넘침과 끊긴 목차 링크가 없었다. 대표 화면의 실제 이미지도 확인했다. 관련 기존 시험 112/112 통과. 브랜드 렌더 검사에서 8/8 문서의 색·서체·색 직책 위반은 발견되지 않았다. 대비는 텍스트 요소 445개 중 383개를 판정했고, 그라디언트 위 62개는 자동 판정 대상에서 빠진다.

소개서는 구현 상태를 새로 측정한 보고서가 아니다. 문서에 기록된 기반, 채택된 확장 설계, 교육 효과를 구분해서 읽는다. Reed는 앱 개인 청취 수집을 포함하지 않으며, 유튜브 연결과 방송 설계, 앱 소리 자리 규칙을 구분한다.

바탕화면의 입구는 `SYNK`, `SYNK LAB`, `SYNK SHIFT`, `SYNK PULSE` 네 폴더다. 엔진은 `SYNK/엔진·브랜드`에서 연다. 현재 자료 안내는 `docs/문서_지도.md`, 새 파일을 놓는 경로는 `tools/운영자료.js`가 관리한다.

숫자 단추 후속 개선(2026-09-09): Codex 기본 생성 01~06을 제목 46/46곳에 적용했다. 제작 원본은 1254×1254이며 기존 01의 4K 시제품도 보존했다. 자세한 제작 방식과 프롬프트는 [단추 제작 기록](단추/README.md)에 있다. 교체 후 24/24 화면 검사와 기존 시험 100/100개를 통과했다. 브랜드 렌더 검사는 8/8문서에서 위반을 찾지 못했으며, 텍스트 399개 중 대비 판정 383개·그라디언트 제외 16개다. 이미지 내부 자수의 품질은 이 자동 검사 대상이 아니므로 실제 화면을 따로 확인했다.
