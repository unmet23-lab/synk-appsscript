BEHIND THE CONNECTIONS

여덟 개의 능력.
하나의 Atlas.

Atlas는 Core·Strata·Loom·Vellum·Trail·Prism·Temper·Reed의 능력을 연결하고, 한 사람에게 필요한 경험에 적용하는 중심입니다.

이 화면은 현재 엔진 설계에서 중요한 관계를 골라 표현한 시안입니다. 중앙에서 빛이 흐르는 광원은 Atlas를 나타냅니다. 평소에는 은백색으로 이어지며, 엔진에 포인터를 올리거나 키보드 초점을 옮기면 해당 브랜드색이 연결을 따라 번졌다가 벗어나면 돌아옵니다. 클릭하거나 터치하면 선택이 고정되고, 선택한 관계에만 스티치가 나타납니다. 기능 점이나 이름에 포인터를 올리면 점이 살짝 움직이고, 연결된 주변 점과 선이 탄력 있게 따라옵니다. 점의 수와 움직임은 실제 이용자 수나 실시간 처리량을 뜻하지 않습니다. 작은 점은 주변 개념을 표현하는 시각 요소입니다.

화면 가장자리의 옅은 연결은 공간의 깊이를 표현하며 별도 엔진이나 데이터를 뜻하지 않습니다. Strata는 설계·준비 단계이며, 전체 연결의 라이브 운영을 나타내지 않습니다.
