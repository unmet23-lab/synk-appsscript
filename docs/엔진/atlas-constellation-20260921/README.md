# Atlas — 연결이 경험이 되는 곳

2026-09-21~22에 제작한 독립 시각화 원형과 검증 기록이다. 중앙 Atlas가 여덟 엔진의 능력을 연결하는 모습을 탐색한다. 현재 제품의 담당·실제 구현은 [엔진 8종 원문·코드](../../엔진8종_상향설계_v3.md#engine-owner-sources)를 따른다. 이 시각화와 당시 홈페이지 게시 기록을 엔진 전체의 운영 증거로 쓰지 않는다.

[현재 시안 열기](index.html). 폰트·로고·스타일·스크립트를 모두 내장한 약 1.73MB HTML이며 파일을 브라우저에서 직접 열어도 작동한다. 현재 광원은 실시간으로 그리며 실뭉치 이미지를 내장하지 않는다. 이 파일은 제작 원형이며, 2026-09-22 승인 스냅샷을 [공개 Atlas](https://synk.im/atlas/)로 게시했다. 당시 synk.im 일반 접속의 첫 화면으로 게시했고 자수 SYNK 버튼을 기존 홈페이지로 연결했다. 현재 공개 라우팅은 웹사이트 원천·실제 공개 화면에서 별도로 확인한다.

## 표현과 조작

2026-09-22 후속 요청으로 화면의 정지/재생 버튼과 구분선, 설명 창의 ‘디자인 참고’ 제목·외부 링크 두 개를 제거했다. 확대·축소·초기화, 엔진 선택과 시스템의 움직임 감소 설정은 유지한다. 실제 브라우저에서 버튼 부재·참고 링크 0개·Core 선택·일반 재생·움직임 감소 시 정지를 확인했다. 아래 수동 정지 검증은 버튼 제거 전 이력이며 렌더러의 정지 API는 유지한다. 홈페이지 통합은 2026-09-22 완료했다. 웹사이트 저장소의 `src/atlas-landing.html`이 공개 스냅샷이고 `compose-atlas.mjs`가 생성한다. [배포·검수 기록](../../../../SYNK-website/qa/RESULTS.md).

- Core·Strata·Loom·Vellum·Trail·Prism·Temper·Reed 8개 군집을 중앙 Atlas와 연결한다. 정본의 의미 있는 교차 관계 15개를 바탕으로 292개 점과 621개 선/곡선을 구성했다. 이 수는 시각화 구성 수이며 실제 이용자·데이터·처리량이 아니다.
- 사용자가 승인한 현재 방향은 **은백색 연결망과 살아 있는 실버 유리 광원에서 시작해, 다가간 엔진의 브랜드색이 연결을 따라 순차적으로 번지는 표현**이다. 엔진 위에 마우스·펜 포인터를 올리거나 아래 엔진 버튼에 키보드 초점을 옮기면 허브에서 연결선, 중앙 광원 순으로 색이 닿는다. 선택한 관계의 스티치와 깊이가 있는 투영·연속적인 관성을 유지한다. 평상시 GPU 그리기 3회, 스티치가 표시될 때 4회로 묶어 처리하며 글자는 캐시된 Canvas 이미지로 합성한다. WebGL을 쓰지 못하면 Canvas로 광원·연결·스티치를 그린다.
- 점/이름 또는 아래 엔진 버튼을 클릭·터치하면 선택이 고정되고 주변 관계와 개념을 강조한다. 고정한 선택이 없으면 포인터·키보드 초점이 떠날 때 은백색으로 돌아온다. 선택한 엔진 버튼을 다시 누르거나 초기화하면 고정을 해제한다. 드래그로 시점을 바꾸고 확대·축소할 수 있다.
- 기능 이름·점에 마우스나 펜을 올리면 작은 세포를 건드리듯 **점이 약 9CSSpx 밀리고 연결된 이웃 점들이 더 작고 느리게 따라온다**. 모든 선의 끝은 움직인 점에 붙어 함께 늘어나고 돌아온다. 포인터가 머무는 동안 약 1px의 느린 움직임을 더하고, 이탈하면 원래 위치로 수렴한다. 기존의 스티치가 선을 따라 흘러가는 효과와 기능 점의 고리 강조는 제거했다. 판정에 원래 위치와 라벨 영역을 함께 사용해 점이 스스로 hover를 끊지 않는다. 글자가 숨겨진 기능 점도 직접 가리킬 수 있다. 수동 정지는 현재 변형을 고정하고 움직임 감소에서는 변위를 0으로 한다. 기능 이름을 클릭하면 해당 엔진의 선택을 유지한다. 40개 문구는 [기능별 소스 근거](feature-sources-20260922.md)와 대조했다.
- 상단의 모드 전환 두 버튼을 **SYNK 살펴보기 ↗** 링크 하나로 바꿨다. 사용자 후속 요청에 따라 잔털이 보이는 흰색 자수와 글자 가장자리의 파랑·노랑·초록·분홍 스티치를 중심에 두고 작은 ‘살펴보기’와 열린 화살표를 배치했다. 어두운 투명 바탕·얇은 테두리와 hover의 1px 상승으로 질감을 강조한다. 같은 탭에서 `https://synk.im/`의 기존 홈페이지로 이동한다. 연결망은 엔진 탐색 상태로 유지하고 기존 시나리오 원본은 보존한다. 이 시안을 운영 홈페이지 첫 장면에 통합·배포한 것은 아니다. 공식 로고는 바꾸지 않고 이 진입 버튼에만 별도 자수 표현을 쓴다.
- 원경 세 층과 화면 밖으로 이어지는 옅은 전경으로 깊이를 더했다. 중앙 광원은 더 크게, 안쪽 광체와 굴절된 빛을 겹쳐 표현한다. 중앙에서 주변으로 퍼지는 응답 파동은 제외한다. 후속 승인에 따라 엔진에 잠시 머무르면 **구체 안쪽의 빛만 한 번** 은은하게 밝아졌다 돌아온다. 같은 엔진을 계속 가리키면 반복하지 않는다. 첫 등장은 약 2.15초 동안 중앙 광원→연결망→이름표 순서로 나타나며 조작하면 즉시 완료한다. 장식용 원경 150점·201선, 전경 10점·7선은 위의 엔진 관계 수에 포함하지 않으며 선택 대상도 아니다.
- 키보드 Tab·방향키·Home/End·Enter, 움직임 감소, 수동 정지, 화면 밖·숨긴 탭 렌더 중단을 지원한다.

시안 제작 당시 Strata는 준비 단계였으나 이후 공통 지도·조회와 TOPIK I 자료가 구현됐다. [현재 Strata 범위](../../Strata_설계.md)를 따른다. 시각화의 정본 근거와 설계 예시는 `atlas-data.js`에 있으며, 화면 완성을 전체 엔진 통합의 라이브 운영이나 개인별 효과 검증으로 확대하지 않는다. [첫 지속 기억 기록](../../아틀라스_첫지속기억_20260921.md)도 그 날짜의 구현 기록이다.

공통 GPU 광원의 `nucleus(x, y, radius, time, energy, rgb, 'silver', innerLight)`는 여섯 번째 RGB 인자로 선택색, 일곱 번째 인자로 실버 유리 마감, 선택적인 여덟 번째 인자로 내부 밝기 0–1을 받는다. 내부 밝기 기본값은 0이므로 기존 다섯·여섯·일곱 인자 호출은 종전 표현을 유지한다. 컨텍스트 복구와 Canvas 대체 경로도 같은 값을 사용한다.

## 은백색에서 드러나는 브랜드색 · 2026-09-22

사용자 요청으로 실뭉치와 브랜드 스티치 시안을 제작했다. [디자인 토큰](../../디자인_토큰.json)의 실 4계열과 Coral을 사용한다. Core Coral `#F96859`, Strata Meadow `#7DB45A`, Loom Butter `#F5C445`, Vellum Pop `#E05C97`, Trail Lapis `#3D6BC9`, Prism Lapis Soft `#C5D6F5`, Temper Meadow Soft `#D3E8BE`, Reed Pop Soft `#F8C7DE`. 이번 시안용 구분이며 영구 엔진 색을 확정한 것은 아니다.

실뭉치는 내장 `image_gen`으로 새로 생성했다. [정확한 생성 프롬프트](assets/yarn-prompt.txt), [1254×1254 PNG 원본](assets/atlas-yarn-master.png), [1024×1024 WebP 파생본](assets/atlas-yarn.webp), [제작 기록](assets/yarn-provenance.json)을 보존한다. 축소·압축만 했으며 알파를 유지했다. 새 시안 자산으로 기존 승인 로고·마스코트를 재생성한 것이 아니다.

스티치는 GPU에서 캡슐 단면·3가닥 꼬임·빛과 그림자를 계산하고 곡선 전체 길이를 따라 간격을 유지한다. 사용자는 실뭉치 비교 뒤 중앙 광원과 선택 관계의 스티치를 채택했으며, 이어 **은백색 기본 화면에서 포인터·키보드 초점에 반응해 해당 엔진의 브랜드색이 순차적으로 드러나고 클릭·터치로 고정되는 방향**을 승인했다. 현재 `index.html`에 이 표현을 구현했다. 아래 엔진 표식과 연결 버튼도 기본은 은백색이며 미리보기·선택 상태에서 해당 색을 드러낸다. 중앙 광원은 실버 유리 마감을 쓰며 연결을 따라 도달한 선택색을 내부의 빛에 반영한다. 이후 추가했던 중앙→주변 응답 파동은 사용자 요청으로 제외하는 방향이다.

[색이 항상 보이는 광원판](variants/atlas-brand-light-20260922.html)과 [실뭉치 비교본](variants/atlas-yarn-20260922.html)을 각각 보존했다. 실뭉치 이미지·프롬프트도 남겼으며 현재 빌드에는 해당 이미지를 내장하지 않는다. 승인 팔레트 값은 바꾸지 않았다.
