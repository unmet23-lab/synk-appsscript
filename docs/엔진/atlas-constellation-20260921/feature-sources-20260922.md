## 해석 범위

- **Core:** 공통 판단 시제품의 능력이다. 위 코드가 모든 제품의 학습 기록과 운영 서버에 연결됐다는 뜻은 아니다. ‘도움 반응 학습’은 해당 사람의 응답을 선택 비중에 반영하는 기능이며 모델 재훈련을 뜻하지 않는다.
- **Strata:** 다섯 라벨은 실제 존재하는 기존 학습 자료와 변환 기능을 가리킨다. 이를 하나로 묶는 Strata 본체·통합 조회·학습 경로는 설계 단계다. `A/docs/Strata_설계.md:18-30`, `:145-147`. 확인 시 `A/strata/`와 `A/tools/strata-build.js`는 없었다.
- **Loom:** 실제 렌더링·움직임 코드의 표현 능력이다. 유리 표현은 셰이더 연출이며 물리 광학의 정확도를 입증한 시뮬레이션은 아니다. 바람·마스코트 예시는 기존 Loom 장면의 기능이고, 모든 기능이 이 Atlas 그래프에서 동시에 사용되는 것은 아니다.
- **Vellum:** 만남과 재회는 기기의 로컬 기록을 사용한다. 계정·다른 기기·모든 NPC 사이에 공유되는 장기 기억으로 설명하지 않는다. `T/src/마스코트.js:117-145`, `:389-405`. 캐릭터의 성격 설정을 따르는 반응이지 사용자의 성격이나 감정을 자동 판정하는 기능이 아니다.
- **Trail:** 자기 기록 비교·시즌 목표·회고·내부 진로 결과 연결의 기존 구현을 표현한다. 기록 수의 변화가 한국어 실력 증가를 뜻하지 않으며 회사 전체의 기억이 통합됐다는 뜻도 아니다.
- **Prism:** 산출 계약 검사는 **입력된 수치와 항목의 검증**이다. 독립 인원 자동 집계·편중 자동 분석·최소 표본 충족·통계적 대표성을 계산하거나 보장하지 않는다. 집단 비교 점검도 지정 표현의 검사다. `A/tools/lib/prism계약.js:2-8`. 오류사전 생산 코드는 현재 몽골어 화자 대상이며 이것을 글로벌 전체의 관측 결과로 확대하지 않는다.
- **Temper:** 개입과 후행 기록을 연결·계산하는 기능이다. 도움의 인과 효과 입증이나 정책의 자동 개선 완료가 아니다. 열람 기록이 없다는 사실은 미열람과 관측 생산자 미연결을 구분하지 못한다. `T/lib/성과회수.js:132-136`.
- **Reed:** 승인 자산 선택·재생 제어·곡 편성의 구현이다. 사용자의 감정을 읽어 음악을 추천하거나 개인 청취를 추적하는 기능이 아니다. 해당 코드가 현재 공개 방송에 적용됐는지는 별도 배포 근거가 필요하다.
