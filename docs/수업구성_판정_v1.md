## ⓪ 한 줄

**정규 과정은 합리적이고 값도 선다. 올액세스는 지금 «팔 수 없는 상태»다** — 파는 것 셋 중 둘은 들어오는 문이 없고, 하나는 시간표에 자리가 없다. **가격이 잘못된 게 아니라, 값이 가리키는 물건이 아직 안 서 있다.**

## ① 정규 과정 — 합리적이다

**구성** 한국어 코어 주5×90분 + K컬처 곁수업 무료 + 담임 1:1 + 게임화 앱

| | 값 |
|---|---|
| 월 수업 시간 | 30시간 (주 7.5h × 4주 · 연 48주÷12) |
| 6개월권 | 420,000₮ → **시간당 14,000₮** |
| 1개월권 | 550,000₮ → 시간당 18,300₮ |
| 반 정원 | 16명 → 시간당 반 매출 224,000₮ |
| 강사 원가 | 15,000₮/시간 → **원가율 6.7%** |

**판정 ○** — 주 5일 대면 30시간에 담임 1:1과 앱이 붙고 K컬처가 공짜로 얹힌다. 이 구성에 42만₮은 촘촘하다. 기간권 할인(55→47→42)도 선납 유도로 자연스럽다.

### ⚠ 다만 값의 «비교 기준»이 헐겁다

정본은 「UB 그룹반의 1.3~4.3배 = 시장 최고가」로 값을 방어한다. 그런데 **그 비교는 «월 단가»이고, 어느 문서도 시장 학원의 «시수»를 안 적었다.**

- 시장이 주 2회 × 90분(월 12시간)에 24만₮이면 → 시간당 20,000₮ → **SYNK가 30% 싸다**
- 시장이 주 5회면 → SYNK가 비싸다

**즉 지금 우리는 우리가 비싼지 싼지 모른다.** 「최고가 포지션」이라는 서사 전체가 이 미지수 위에 있다.

그리고 **같은 시장 값을 두 자가 다르게 잰다**:

| 자 | 값 |
|---|---|
| 집필 규범 §가격 지형 | 로컬 학원 **13~28만₮** |
| 급여 인센티브 정본 §12 | UB 그룹반 **16~32만₮** |

한 값을 두 곳이 알면 반드시 갈린다. 실측할 때 한 곳으로 모은다.

## ② 올액세스 — 구멍 셋 🔴

올액세스가 파는 것 = 정규 과정 전부 **+ 원어민 회화 + 글로벌 영어 + TOPIK 집중** (6개월권 기준 +130,000₮/월)

### ① 셋 중 둘에 «문»이 없다 — 그리고 그게 코드에 박혀 있다

| 언제 | 무엇 |
|---|---|
| 2026-07-19 | `Code.js:640` — 「위성(댄스·보컬·뷰티·**원어민 회화·글로벌 영어**)은 출석 체크 없음(유호 확정) → schedule 미등록」 |
| 2026-08-04 | 상세서 — 「위성 = 출석 체크 없음·앱 미등록·자유 참여. ✅ 이 「미등록」 정의가 **정본**이다」 |
| 2026-08-04 | 소개서 — 「**자유 클래스** — 댄스·**원어민 회화·글로벌 영어** 등. 출석 체크도 성적도 없는 자유 참여」 |
| **2026-08-26** | 가격 확정 — **그 둘이 올액세스의 유료 차별점이 됐다** |

**출석을 안 세고 앱에 등록도 안 되는 방을, 13만₮ 받고 판다.**

- 막지 않으면 → 정규 과정 학생이 그냥 들어와 앉는다. 13만₮ 낼 이유가 없다
- 막으면 → 07-19·08-04 정본 둘을 깬다. 그리고 **막을 장치가 코드에 없다**

22일 사이에 난 충돌이고, 지금까지 아무도 안 봤다.

### ② TOPIK 집중은 시간표에 자리가 없다

사업계획서에 「TOPIK」은 13번 나온다. 그중 **슬롯·담당·정원을 말하는 것은 0건**이다. 곁수업 12칸을 채운다고 적힌 목록은 「댄스·뷰티·보컬 + 원어민 회화·글로벌 영어」 — **TOPIK 집중이 빠져 있다.**

**값에는 있고 시간표에는 없다.** 지금 팔면 못 준다.

### ③ 엔진이 «누가 올액세스인지» 모른다

학생 레코드가 `{학생ID · 이름 · 반}` 셋뿐이다. **등록 갈래 칸이 없다.**

⇒ 배송을 증명할 수도, 채택률을 잴 수도 없다. 그런데 **손익분기 117명이 「애드온 채택률 50%」 위에 서 있고**, 정본 스스로 그것을 「전환율 25% 다음으로 비싼 미실측 가정」이라 쓴다.

**잴 장치가 없는 가정이 손익분기를 떠받치고 있다.**

## ③ 가격 구조 — 두 곳이 서로 반대를 가리킨다

### 낱개가 허수다

| | 값 | 시간당 |
|---|---|---|
| 회화만 낱개 | 120,000₮ | 30,000₮ (월 4시간 가정) |
| 영어만 낱개 | 90,000₮ | 22,500₮ |
| TOPIK만 낱개 | 80,000₮ | 20,000₮ |
| **낱개 셋 합** | **290,000₮** | |
| **올액세스 추가분** | **130,000₮** | **10,800₮** |

**회화 하나 = 12만₮ / 셋 다 = 13만₮.** 1만₮ 차이로 세 배다. 낱개를 고르는 사람은 벌을 받는다.

업셀 설계로는 교과서적이다. 그런데 **눈치챈 학부모에게는 「낚였다」로 읽힌다** — 우리가 파는 서사가 「숨기지 않는다(투명성)」인데 여기서 부딪힌다.

### 그리고 가격이 미는 방향에 용량 벽이 있다

원어민 회화는 **유호님 전담**, 글로벌 영어는 **재헌님 전담**(추가 채용 0). 곁수업 슬롯은 하루 3개(10:00·13:00·17:00 · 각 60분).

| | 계산 | 결과 |
|---|---|---|
| 유호님 최대 | 3칸/일 × 5일 × 16석 | **240 석-회/주** |
| 평일 좌석 전원이 주1회 | 256명 | **256 > 240 — 막힌다** |
| 채택 50%(모델값) | 128명 | 53% 가동 — 여유 |

**모델은 50%를 쓰는데 가격 구조는 100%를 민다.** 그 둘이 만나는 자리에 벽이 있다.

그리고 240 석-회는 **유호님이 매주 15시간을 «매주» 가르친다**는 뜻이다 — 원장·창업·SHIFT·법인·자격증을 동시에 하시면서. 재헌님도 영어로 같은 15시간이다.

⇒ **올액세스의 유료 차별점 둘이 «원장 2인 단일 장애점» 위에 있다.** 한 사람이 빠지면 유료 상품이 멈춘다.

> ⚠ **안 재봤다** — 곁수업 12칸 중 회화·영어에 «몇 칸»이 가는지는 어느 문서에도 없다. 위 240은 «유호님이 전 슬롯을 회화로 쓴다»는 상한이다. 균등 분배(5과목 12칸)면 회화는 주 12칸 = 192 석-회로 내려가고, 그러면 50% 채택에서도 67% 가동이 된다.

### 주말 128석은 업셀 경로가 0이다

토요일 시간표는 코어 2슬롯 + 크루 광장뿐 — **곁수업 슬롯이 아예 없다.** 그래서 「주말생에게 올액세스를 안 판다」는 합리적 결론이다.

다만 그 뜻은 **전체 좌석의 3분의 1이 지불 상한 42만₮에 고정**된다는 것이다. 설계상 의도된 것이지만, 성장 여지가 0인 좌석이 33%라는 것은 적어 둘 값이다.

## ④ 안 재본 것 (추측으로 메우지 않는다)

1. **시장 학원의 시수** — 값 판정의 유일한 미지수. 3~4곳의 「월 얼마 / 주 몇 회 / 몇 분」
2. **곁수업 칸 배분** — 회화·영어에 몇 칸인지 문서에 없음
3. **곁수업 정원** — 코어는 16, 위성은 미기재
4. **지불의사(WTP)** — 정본이 스스로 미실측이라 적음
5. **낱개 애드온의 실제 시수** — 위 표의 「월 4시간」은 내 가정이다
