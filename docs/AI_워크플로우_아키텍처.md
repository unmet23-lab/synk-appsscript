# SYNK 작업의 연결 구조

> 현행 구조 · 2026-09-10. 작업 원칙은 [AI 운영 원칙](AI_운영원칙.md), 기존 도구 사용법은 [AI 스택 가이드](AI_스택_가이드.md)에 있다. 날짜별 설치·모델·호출 시험 기록은 Git 이력이며 현재 인증·연결 상태의 증명이 아니다.

## 책임과 자료의 흐름

사용자 요청 → 현재 주담당 → 필요한 기준 원문·승인 자산 → 제작·독립 작업 → 실제 결과 검증 → 요청된 게시·배포 → 결과와 남은 일.

주담당은 사용자가 모델 간 인계를 조립하도록 요구하지 않는다. 독립 작업에는 실제 작업 사본, 같은 원본 경로, 목표·수용 조건을 전달하고 받은 실물·증거를 확인한다. 한 모델의 실행은 다른 모델의 실행·독해를 뜻하지 않는다.

| 층 | 관리하는 것 | 원천 |
|---|---|---|
| 작업 원칙 | 자율 실행·최신 확인·분업·계정·완료 | AI_운영원칙.md |
| 업무 기준 | 철학·제품·마케팅·디자인·품질 | 문서_지도.md가 연결한 담당 원문 |
| 실행 입력 | 자산·색·서체·데이터·API 계약 | 담당 코드·토큰·승인 명세 |
| 결과 | 실제 적용·시험·게시와 남은 일 | 제작물별 기존 결과·QA·PR·트랙 |

문서 값·마스코트 경로·로고 선택을 모델별 폴더에 복사하지 않는다. 필요할 때 기준 원문에서 읽어 제작 입력으로 연결한다. 기술 파일의 존재와 올바른 용도 선택은 별도로 확인한다.

## 세 종류의 최신 확인

- **작업본:** session-freshness.js와 관련 diff로 기준·미커밋·변경된 원문을 확인한다. 알림은 변화 신호이며 내용 이해·원격 최신·배포 확인이 아니다.
- **제작물:** 사용한 승인본과 현재 기준을 비교한다. 로고·색·서체 같은 고정 자산은 내용 지문과 실제 참조를, 대상·경험·말투·밀도는 문안·화면으로 확인한다.
- **게시물:** 요청된 반영 뒤 실제 주소·배포 버전·화면·동작을 재조회한다. 로컬 제작·소스 push·게시·성과를 구분한다.

신규 제작 때 담당 도구가 현재 승인 원천을 받는지 확인한다. 승인 기준이 바뀌면 직접 소비하는 도구와 현재 관리 결과의 영향을 좁혀 갱신한다. 과거 인쇄물·게시 기록까지 조용히 다시 만들거나 자동 공개하지 않는다.

## 매체별 실제 확인

| 결과 | 확인할 것 |
|---|---|
| 기업 웹·앱 | 목적·첫 읽힘·사용 위치의 승인 자산·PC/모바일·키보드·입력·오류·근거·게시 화면 |
| 홍보물 | 해당 회사의 대상·제공물·경험·말투·현재 제공 범위·필요한 다음 행동·실제 게시 크기 |
| 영상·소리 | 실제 재생·음량·끝 음절·자막·표정·반복 이음매·표지·전달 안내 |
| 문서·인쇄 | 렌더·줄바꿈·폰트·본문/이미지 관계·링크·사용 조건 |
| 엔진·데이터 | 현행 계약·원본 보존·저장·소비·출력·수혜자 도달의 증거 |

세부 판정은 [명품 기준](명품_기준_v1.md)을 따른다. 모든 매체에 같은 배치·행동 요청·데이터 수집을 강제하지 않는다.

## 연결·중단·재개

설치·로그인·실제 호출·업무 품질은 다른 상태다. 현재 환경의 공식 앱·CLI·커넥터를 확인하고 기존 인증을 재사용한다. CLI의 모델 목록·구독 상태·가격을 문서의 과거 스냅샷으로 고정하지 않는다.

Antigravity 비대화 실행은 `--add-dir`로 실제 폴더를 전달한다. Codex·Claude의 네이티브 작업·서브에이전트·재개를 우선한다. 로컬 작업은 연결된 기계가 필요하며 원격 화면 제어와 클라우드 실행을 구분한다.

재개에는 작업 사본·브랜치·커밋·미커밋 범위·현재 실행 상태·시험·남은 일을 넘긴다. 브라우저·로컬 프로세스가 다른 하네스로 자동 이전되지 않는다. 이미 실행 중인 다른 작업을 일괄 종료하거나 문서 개정으로 권한을 바꿨다고 주장하지 않는다.
