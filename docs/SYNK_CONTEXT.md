# SYNK 공용 컨텍스트

> 마지막 갱신: 2026-07-11
> 목적: Codex 새 작업이 이전 대화 원문 없이도 유호님과 SYNK의 핵심 맥락을 복원하기 위한 짧은 정본이다.

## 유호님

- 사용자는 유호님이다. 항상 "유호님"으로 호칭하고 기본 응답은 한국어로 한다.
- 몽골 울란바토르에서 SYNK를 구축하는 비개발자 1인 기업가다.
- 자연어로 지시하면 AI가 파일 수정·검증·원격 실행·배포까지 완료하는 방식을 가장 선호한다.
- 효율과 퀄리티를 모두 중시한다. 유료 도구는 가격 자체가 아니라 작업 스타일 적합성과 확실한 성과·능률 상승으로 판단한다.
- "트렌디"는 유행을 좇는 것이 아니라 성능·효율이 앞서 사람들이 따라오게 만드는 것이다.

## SYNK

- SYNK는 6개 부문을 운영할 1인 기업이다: SYNK LAB, SYNK STUDIO, SYNK FASHION, SYNK F&C, SYNK ABROAD, SYNK PUBLISH.
- 현재 핵심은 SYNK LAB: 몽골 학생 대상 게임화 한국어 학원이며 영어 교육도 포함한다.
- 몽골어 최종 감수는 AI가 아니라 현지 원어민 사람이 담당한다.
- 디자인 최종 조립은 Canva, 운영·콘텐츠 검수는 Notion을 주로 사용한다.
- 앱 백엔드는 Google Apps Script + Google Sheets이며 저장소는 `SYNK-appsscript`다.

## AI 역할 분담

- Claude Max 20x는 기존 메인 엔진이다: 기업·서비스 설계, 브랜드·커리큘럼, 복잡한 핵심 코드, 난해한 판정.
- ChatGPT Pro/Codex는 운영·검증·원격 실행 담당이다: 일반 가역 코드, 테스트, 데이터·문서, 브라우저·PC 작업, 플러그인, 예약 작업, Sites.
- 기억 규칙: "무엇을 만들고 왜 해야 하는지"는 Claude, "확인하고 정리하고 실제로 움직이는 일"은 Codex.
- 한 작업은 한 AI가 처음부터 끝까지 소유한다. 같은 시간에 두 AI가 같은 코드를 수정하지 않는다.
- 기본 작업 위치는 로컬 `master`; worktree·PR·클라우드 코딩은 특별한 필요가 있을 때만 쓴다.
- 코드를 수정한 AI 한 곳에서만 `/deploy`를 실행한다.
- 되돌릴 수 있는 작업은 담당 AI가 가볍게 검증하고, 돈·계약·외부 발행처럼 되돌리기 어려운 일만 다른 AI의 독립 검토를 붙인다.
- 대화 전체를 다른 AI에 복사하지 않는다. 코드 인계는 `git diff`, 업무 인계는 `docs/CURRENT_HANDOFF.md`를 사용한다.

## 작업·모델 원칙

- 단순하고 가역적인 작업에는 과도한 심층검증을 돌리지 않는다.
- 복잡한 코드·핵심 판정에만 최상위 모델과 높은 추론을 사용한다.
- 모르면 지어내지 말고 모른다고 말한다. 결론은 먼저, 근거는 뒤에 둔다.
- 유호님이 직접 해야 하는 단계는 최소화하고 꼭 필요할 때만 클릭 단위로 안내한다.

## 유지 규칙

- 이 문서에는 여러 달 유지될 사실·결정만 기록한다. 대화 전문, 임시 아이디어, 장황한 작업 로그는 넣지 않는다.
- 낡은 내용은 누적하지 말고 최신 결정으로 교체한다.
- 현재 진행 중인 한시적 상태는 `docs/CURRENT_HANDOFF.md`에 기록한다.
