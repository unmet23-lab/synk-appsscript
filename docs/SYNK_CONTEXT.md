## 유호님

- 사용자는 유호님이다. 항상 "유호님"으로 호칭하고 기본 응답은 한국어로 한다.
- 몽골 울란바토르에서 SYNK를 구축하는 비개발자 1인 기업가다.
- 자연어로 지시하면 AI가 파일 수정·검증·원격 실행·배포까지 완료하는 **자동화 시스템 구축을 가장 선호**하고, 요구 충족 지점에서 멈추지 않고 꼬리에 꼬리를 무는 집요한 최상을 추구한다(07-31 직접 선언).
- 효율과 퀄리티를 모두 중시한다. 유료 도구는 가격 자체가 아니라 작업 스타일 적합성과 확실한 성과·능률 상승으로 판단한다.
- "트렌디"는 유행을 좇는 것이 아니라 성능·효율이 앞서 사람들이 따라오게 만드는 것이다.

## 현재 AI 운영을 찾는 곳

역할·권한·모델 선택·검증·인계·최신 상태 확인은 [공통 운영 원칙](AI_운영원칙.md) 한 곳에서 읽는다. 적용 상태와 제품별 차이는 [워크플로우 아키텍처](AI_워크플로우_아키텍처.md), 기존 실행 도구를 명시적으로 선택할 때의 안내는 [AI 스택 가이드](AI_스택_가이드.md)에 있다.

이전 판의 Claude 단독 허브·GPT 제한 역할·로컬 master 고정은 현행 지침이 아니다. 삭제된 큐·훅·옛 도구를 배경 기록만 보고 복원하지 않는다. 과거 운영 설명이 필요한 경우 Git 이력에서 해당 시점의 이 문서를 확인한다.

## 유지 규칙

- 이 문서는 배경과 정본으로 가는 길만 유지한다. 새 결정·상태를 여러 문서에 복제하지 않는다.
- 현재 진행 상태는 [남은 일](_ops/트랙.md)과 관련 작업·PR의 증거에서 확인하고, 사용자 결정은 [결정 기록](_ops/결정.md)에 남긴다. 종료 시점까지 기록을 미루지 않는 절차는 공통 운영 원칙을 따른다.
