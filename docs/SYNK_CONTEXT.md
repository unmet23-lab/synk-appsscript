- **조직 표기는 조직도가 아니라 로드맵이다(v1.1)**: 지금 여는 것 = LAB / 지금 쌓는 것 = STUDIO·IP·COMMON SYSTEM / 준비 중인 것 = Wear·Pantry. 세로로 읽으면 시간, 꼬리표(브랜드·레이어)를 읽으면 성격. 조직·브랜드를 언급하는 문서를 쓸 때는 이 축을 먼저 쓴다.
- **Wear·Pantry 표기 규칙(v1.2)**: 언제나 「준비중」 라벨과 함께 쓴다 — 라벨 없는 노출은 원칙 위반. 고객·학부모·크루 대면물에는 올리지 않고, 투자자·파트너 자료에만 노출(제품 사진·출시 시점·가격 금지). 구 우산명 **「SYNK LIFE」는 표기에서 하차**(폐기 아님 — 내부 트랙명·기존 파일명·폴더명으로만 존치, 새 문서에서 미사용).
- **「준비중」은 완곡어가 아니라 사실이다**: Wear는 앱 포인트 상점(`setupStore`)에 자체 의류 4종·굿즈 5종이 SKU·포인트 가격까지 확정돼 라이브이며, 개원과 동시에 초기 수요·만족도 데이터가 붙는다. Pantry는 구상 진행 중 + 상점 간식 4종이 수요·가격 신호. **⚠ 양방향 금지선**: "제품 0·가설뿐"은 준비의 실체를 지우므로 부정확하고, "지금 테스트 진행 중"은 재학생 0명이라 과장이다. 정확한 문장 = **"장치가 이미 깔려 있고 개원과 동시에 작동한다"**.
- 현재 핵심은 SYNK LAB: 몽골 학생 대상 게임화 한국어 학원이며 영어 교육도 포함한다. **일정 확정(2026-08-04 유호님)**: 시즌·2주 무료 파일럿 시작 **2027-02-11(목)** → 정식 개원 **2027-02-25(목)**. `app_state`의 `시즌시작일` = `2027-02-11`(파일럿 포함). ⚠첫 시즌은 유료가 6주다(파일럿 2주 무료) — 매출·BEP를 정상 시즌과 같게 잡지 말 것. 정본 = memory `opening-roadmap-2027feb`.

- 구 「Claude 단일」(07-31)·cowork 병용은 폐기됨 — cowork 사본(`docs/COWORK_지침.md`)은 **⛔동결**(재사용 통보 전까지 갱신·전파 대상 아님).
- 한 작업은 한 세션이 처음부터 끝까지 소유한다. 같은 시간에 두 세션이 같은 코드 구역을 수정하지 않는다(`docs/세션보드.md` 선언 — 멀티 세션 규약은 `CLAUDE.md`).
- 기본 작업 위치는 로컬 `master`; worktree·PR·클라우드 코딩은 특별한 필요가 있을 때만 쓴다. 코드를 수정한 세션에서만 `/deploy`를 실행한다.
