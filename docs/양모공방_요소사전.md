## 0. 🔑 통일 문법 — 「모든 상태는 바느질 단계다」

앱의 모든 사물이 같은 5단계를 지난다. 화면마다 은유를 새로 짓지 않는다 — **이 사다리 위 어디인지만 정한다.**

| 단계 | 실물 | 뜻 | UI 상태 |
|---|---|---|---|
| ⓪ 빈 구멍 | 바늘구멍 두 점 | 아직 아무것도 | 미시작·미방문·잠김 |
| ① 밑그림 | 분필 점선 도안 | 자리는 잡혔다 | 로딩·스켈레톤·예정·빈 상태 |
| ② 시침 | 성긴 긴 땀(듬성) | 임시로 붙였다 | 드래프트·임시저장·미확정 답 |
| ③ 꿰맴 | 러닝 스티치(고른 땀) | 확정됐다 | 완료·제출·확정·방문함 |
| ④ 와펜 | 자수 패치 | 완성을 «달았다» | 성취·급수·마스터 |

- 오답·수정은 **④→③이 아니라 ③→②로 «되돌아감»**이다 — 실을 자르는 그림은 어디에도 없다(실패음 없음·빨강 금지와 같은 축: **이 공방에서 실은 잘리지 않고 풀렸다 다시 꿰매진다**).
- 스트릭(연속 학습)도 이 문법이다: 하루 = 땀 하나, 이어진 줄이 보인다. 하루 빠짐 = **빈 구멍 하나** — 줄은 계속된다(끊긴 실 그림 금지).

### 1-d. 교보재 — 「우리가 가르치는 것」 자체를 굽는다

> 이 절은 08-22 에 생겼다. 앞 절들은 «앱의 부품»을 적었는데, 우리 학원의 요소 목록에 **가르치는 대상**이
> 빠져 있었다 — SYNK 는 UI 회사가 아니라 한국어 학원이다. 자모가 실물이면 그것이 곧 교보재다.

| 부품 | 실물 | 쓰이는 자리 |
|---|---|---|
| 한글 낱자 | **자수 자모** ✅구움 — 자음 19(ㄱ~ㅎ·쌍자음 5) · 모음 12 | 앱 학습 화면 · 교재 표지 · 인쇄 카드 · SNS |
| 숫자 | **자수 숫자** ✅구움 — 0~9 낱장(조합용) · 01~12 통짜 · 「/ · % +」 | 단락 머리 · 절번호 · 진행 표기(3/10 · 85%) · 월 표기 |
| 요일 | **자수 요일** ✅구움 — 월~일 | 출석 달력 · 시간표 |
| 칭찬 도장 | **참 잘했어요 도장** ✅구움 — 다린 천에 찍힌 코랄 인장 | 출석 · 숙제 확인 · 리포트 도장칸 |
| 음식 낱말 | **펠트 음식** ✅구움 — 귤·도넛·만두·김밥·붕어빵 | 낱말 카드 · 보상 · K컬처 접점 |

- 🔑 **낱장이 통짜보다 강하다** — 0~9 열 장이면 어떤 수든 나열로 선다. 통짜 01~12 는 자간에 손맛이
  필요한 자리(단락 머리·월)에만 둔다. 굽기가 장당 몇 분이라 «필요할 때마다 다시 굽기»는 비싸다.
- 자모는 **획이 가는 글자**라 복셀 리메시(0.018)가 획을 뭉갤 수 있다 — ㅡ·ㅣ 같은 홑획은 굽고 나서 눈으로 본다(함정 ①).

- 🪤 **굽기 함정 다섯**(08-22 세트 굽기 실측 — 글자공방 「함정 5」의 형태 층 짝. 전부 렌더로 확인한 것이고, 코드 정본에도 같은 주석이 박혀 있다):
  1. **털 위에 털을 올리면 뭉갠다.** 채택판 자수글자가 사는 까닭은 «매끈한 밤천 위의 털»이라는 대비다. 만두 도우·김밥 밥·넘버 쿠키에서 세 번 같은 병을 겪었다 — 밀도·색·높이를 아무리 맞춰도 안 됐고, 바닥의 털을 걷자 한 번에 풀렸다.
  2. **털 밀도는 «단위 넓이당»으로 잰다.** 오브 = 1,375가닥/단위²가 기준선이다. 좁은 조각에 같은 개수를 쓰면 7배가 되어 셰기 파일이 된다.
  3. **`직물결`의 「규모」는 세계 단위가 아니라 물체 바운딩 박스 기준이다.** 작은 물체에 큰 규모를 주면 범프 기울기가 폭발해 법선이 뒤집힌다. 어림자 = 규모 ÷ 물체 지름 ≲ 250.
  4. **작은 원기둥에 «베벨 + 스무딩»을 쓰면 뚜껑이 뒤집혀 화소값 정확히 (0,0,0)이 된다.** 검은 무대라 «구멍»으로 보인다. 같은 장면의 구는 멀쩡했다 — **작은 부품은 구로 만든다.**
  5. **내려보는 카메라에서 띄운 물건은 먼 쪽으로 밀려 보인다**(투영 기어듦 · Δz × tan(내려본 각)). 눈으로 맞추면 판마다 어긋난다 — 계산으로 당겨 앉힌다.
