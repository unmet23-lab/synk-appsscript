## 0. 🔑 통일 문법 — 「모든 상태는 바느질 단계다」

앱의 모든 사물이 같은 5단계를 지난다. 화면마다 은유를 새로 짓지 않는다 — **이 사다리 위 어디인지만 정한다.**

| 단계 | 실물 | 뜻 | UI 상태 |
|---|---|---|---|
| ⓪ 빈 구멍 | 바늘구멍 두 점 | 아직 아무것도 | 미시작·미방문·잠김 |
| ① 밑그림 | 분필 점선 도안 | 자리는 잡혔다 | 로딩·스켈레톤·예정·빈 상태 |
| ② 시침 | 성긴 긴 땀(듬성) | 임시로 붙였다 | 드래프트·임시저장·미확정 답 |
| ③ 꿰맴 | 러닝 스티치(고른 땀) | 확정됐다 | 완료·제출·확정·방문함 |
| ④ 와펜 | 자수 패치 | 완성을 «달았다» | 성취·급수·마스터 |

- 오답·수정은 **④→③이 아니라 ③→②로 «되돌아감»**이다 — 실을 자르는 그림은 어디에도 없다(실패음 없음·빨강 금지와 같은 축: **이 공방에서 실은 잘리지 않고 풀렸다 다시 꿰매진다**).
- 스트릭(연속 학습)도 이 문법이다: 하루 = 땀 하나, 이어진 줄이 보인다. 하루 빠짐 = **빈 구멍 하나** — 줄은 계속된다(끊긴 실 그림 금지).

## 1. 앱 공통 부품 사전 (SYNK-talk · 다크 단일 무대)

### 1-a. 조작(컨트롤)

| 부품 | 실물 | 디테일 |
|---|---|---|
| 주 버튼 | **코랄 짧은 퍼 알약** | 글자는 HTML 층 Ink(ⓐ) · 눌림 = scale .96 + 털이 눌린 자국 |
| 보조 버튼 | 무채(Chalk 계) 퍼 알약 | 위계는 색이 아니라 «털의 유무·밀도» |
| 비활성 버튼 | 솜 빠진 납작 알약 | 40% 불투명 대신 **부피가 꺼진다**(감각 §8 개정 후보) |
| 토글 | **꿰맨 단추(4구)** ✅굽는 중 | 켬 = 코랄 실 X(신호 1점) / 끔 = 빈 구멍 |
| 체크박스 | 스냅 단추(똑딱이) | 체크 = 눌려 잠김 · 다중 선택은 스냅, 단일 확정은 단추 |
| 라디오 | 단춧구멍 한 벌 중 하나에 실 | 고른 곳만 꿰매진다 |
| 슬라이더 | 털실을 당겨 감기 | 트랙 = 털실진행바 문법 · 손잡이 = 작은 폼폼 |
| 스테퍼(수량) | 땀 수 | +1 = 땀 하나 더 |
| 텍스트 필드 | **단춧구멍 슬롯** | 감침질 테두리 · 힌트 = 초크 마킹(무채 — 「아직 확정 아님」) · 포커스 링 = 코랄(정본 유지) |
| 스와이프 액션 | 실 당김 | 당긴 만큼 실이 따라온다(소리 짝: 사각) |
| 풀다운 새로고침 | 실을 당겼다 놓기 | 놓으면 실패(보빈)가 감으며 새로고침 |
| 드래그&드롭 | 벨크로 조각 | 놓는 자리가 결로 보인다 |

### 1-b. 표시·정보

| 부품 | 실물 | 디테일 |
|---|---|---|
| 구분선 | **러닝 스티치** ✅채택 | 실금의 실물판 · 무채 실 기본 |
| 카드 테두리 | 블랭킷 스티치 감침질 | 카드 = 감쳐진 천 조각 |
| 대면적 카드 바닥 | **다린 무광 천**(기본 · 08-20) / 퀼팅·뜨개는 «꾸민» 카드 한정 | 결을 눕힌 무채 천 — 정보가 앉는 바닥은 조용해야 한다 |
| 대시보드 그리드 | **조각보(패치워크)** | 카드들이 조각보로 이어짐(몽골·한국 서사) |
| 알림 점·카운터 | 폼폼 + 자수 숫자 뱃지 | 자수 «글자»는 뱃지 한정 규정 |
| 태그·칩 | 직조 라벨(로고 미니) · 가격표 실 태그 | 첨부물엔 실이 달린다 |
| 페이지네이션 | **바늘땀 점** ✅굽는 중 | 지나옴 = 땀 / 지금 = 코랄 땀(신호 1점) / 남음 = 빈 구멍 |
| 진행바 | **털실진행바** ✅굽는 중 | 앱 성장층(XP)은 Lime 실 변형(성장색 정본) |
| 원형 진행 | 블랭킷 게이지 | 감침질이 원을 감아간다 |
| 로딩 스피너 | 실패(보빈) — 실이 풀린다 | 업로드·동기화는 반대로 «감는» 릴 |
| 스켈레톤·빈 상태 | **밑그림 점선** ✅굽는 중 | 빈 상태엔 몽글이 바늘을 들고 옆에(마스코트 정본 그대로) |
| 토스트·스낵바 | 실에 매달려 내려오는 태그 | 300ms 상한·transform만(감각 §8) |
| 모달·바텀시트 | 주머니에서 꺼낸 천 조각 | 닫기 = 시접선 따라 도로 접힘 |
| 탭 전환 | 천 견본 고리 넘기기 | 테마·갤러리 선택도 같은 문법 |
| 코치마크·튜토리얼 | 시침핀 + 초크 마킹 | 「임시로 짚어 준다」 — 배우면 핀을 뺀다 |
| 지도 핀·북마크 | **시침핀** | 바늘머리 = 레진 구슬(레진 1점 셈) |
| 읽음·방문 표시 | 다림질 자국 | 눌린 자국 = 지나간 자리 |
| 여백·정렬(에디터) | 시접 가이드선 | 율(§2-d)의 실물 은유 |

## 2. SYNK-talk 화면별 적용 (학생 접점 — 철학 ①②③④ 게이트 대상)

| 화면 | 이 사전의 적용 |
|---|---|
| 홈(오늘) | 오늘 카드 = 조각보 첫 조각 · 스트릭 = 이어진 땀 줄(§0) · 알림 = 폼폼 |
| 학습·숙제 풀이 | 문제 판 = **패턴지(재단지)**(굽는 중인 유리 대체 «후보» · 은퇴 미확정 08-20 — 반투명 «도면 종이»가 정보를 담는다: 공방 은유 안에서 내용 vs 장식이 갈린다) · 답 제출 = 꿰매짐 · 오답 = 시침으로 되돌아감 · 완료 = 자수 체크 |
| 답장(교정) | 오류 태그 = 코랄 «글자» 정본 유지(재질 안 입힘 — 글자 불가침) · 교정 반영 = 땀 하나 |
| 녹음 | 녹음 오브 3상태는 별도 트랙 소관(`1cfa648d` 계열) — 이 사전은 «펠트 정본을 입는다»는 접점만 확인 |
| 성장(XP·리그) | XP 바 = **Lime 실 털실진행바** · 리그 승급 = 와펜 수여(「달아 준다」 모션 1회) · 레벨 = 자수 숫자 |
| 성취 컬렉션 | 실 색 수집 — 새 성취 = 새 색 실타래(수집 서사) |
| 시즌(교재 1권≈2달) | 🔑**자수 도안 시즌 맵** — 시즌 = 큰 도안 하나, 매일 학습 = 땀 하나, 시즌 회고 = 완성 도안을 함께 봄(㉢ 삶 이해 접점 — **기능급이라 별도 기획 판정 필요**) |
| 프로필 | 이름 와펜(개인화 · ㉡ 접점) · 완성도 = 헝겊 인형 채우기 · 드림맵 카드 = 조각보에 조각 붙이기 |
| 온보딩 | 나침반 3문항 = 시침핀으로 «내 방향» 꽂기 · 단계 = 바늘땀 점 |
| 설정 | 토글 일괄 = 꿰맨 단추 · 위험 동작 없음(빨강 금지 그대로) |
| 오류·오프라인 | 「잠시 내려놓은 바늘」 — 실 끊김·경고색 없이(문구 톤 = synk-brand 몫) |

## 5. 집행 — 굽는 순서와 통로

- ✅구움: 오브·알약·아이콘·스티치(자수)·털실진행바 + 단추토글·밑그림·페이지점(굽는 중) — `tools/요소굽기.py` 8형태
- ▶다음 굽기: ✅폼폼·시침핀 → 와펜·블랭킷·실패 스피너·직조 라벨(굽는 중) → **패턴지 판·다린 천 판**(유리 대체 «후보» · 굽는 중 · 은퇴 미확정 08-20) → 단춧구멍 필드·스냅·조각보 타일 → 매듭(난도 최상)
- 앱 반입 = SYNK-talk 테마·컴포넌트 트랙(형제 저장소 — 여기 CI 밖) · 지면 반입 = Loom 부품표 합류
- **기능급 판 셋**(자수 도안 시즌 맵 · 실 색 수집 · 이름 와펜)은 요소가 아니라 기획이다 — 철학 ①② 게이트를 정본으로 지나는 **별도 기획 트랙**으로 올린다(⏳유호 판정).
