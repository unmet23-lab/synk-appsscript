# 몽글 참조와 말로만 생성한 결과의 비교 기록

2026-09-10에 09-08의 기존 실험 결과와 선택 기록을 연결했다. 새 이미지·영상을 생성하지 않았다.

<a id="feedback-reference"></a>
## 대표 판단 사례 — 승인된 캐릭터의 정체성 유지

- **사용자 실제 말의 기록:** [결정 정본](../_ops/결정.md)의 2026-09-08 실험 행에 「맨위 우리 펠트 몽글을 넣고 구운거 좋네 · 말로만 시킨건 기각하자 아예 달라지네」가 인용되어 있다. 이번에는 당시 대화 원문을 확인하지 못했으며 결정 문서의 인용임을 밝힌다.
- **직접 본 실물:** [기존 실험 대조 PNG](실험_굽기결과_대조_2026-09-08.png). 위쪽은 코랄 펠트·검은 구슬 눈·밑단 실땀의 몽글, 가운데는 갈색 뜨개·입·홍조가 있는 다른 인형이다. 아래 개별 생성 결과도 기존 자산과 몸·눈·재질이 갈라진다. 영상 파일의 존재와 이번 정적 관찰을 영상 재생 품질 검증으로 합치지 않는다.
- **AI 추정:** 기존 캐릭터를 변형하는 작업에서는 묘사한 낱말보다 승인 실물의 형태·재질·정체성이 이어지는 것을 중시한 선택으로 해석한다. 보기 좋은 다른 인형을 만들었더라도 해당 목적을 충족한 것은 아니다.
- **다음 적용:** 현재 [DESIGN](../../DESIGN.md)과 `tools/lib/마스코트자산.js`에서 승인 원본을 찾고, 기존 마스코트의 장면·의상·영상 변형에는 그 원본을 참조한다. 결과와 원본을 함께 열어 몸·눈·재질·고유 디테일이 목적에 맞게 이어지는지 확인한다. 모델 이름이나 옛 프롬프트를 영구 고정하지 않는다.
- **범위와 다시 판단할 조건:** 기존 마스코트 변형의 사례다. 새로운 캐릭터를 설계하라는 요청이나 최신 정본 교체까지 금지하는 규칙으로 확대하지 않는다. 새 생성 도구의 실제 성능·표현 목적·사용자 방향이 바뀌면 당시 실패와 새 실물을 비교한다.
- **확인 상태:** 기존 선택 기록과 대조 PNG 직접 확인. 새 변형의 성공률·사용자 만족·현재 영상/앱/방송 적용은 이번 확인 범위 밖이다.
