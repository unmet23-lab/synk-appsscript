# 온라인 한국어 학습자 · 약 20개국 동시 출시 방향

2026-09-20 사용자 전달 내용과 현재 설계를 대조한 후속 문서다. 사용자 결정과 구현 제안을 구분한다. 앱·서버·마을·결제의 구현 완료나 배포를 뜻하지 않는다.

## 1. 이번에 확정한 방향

- 대상은 전 세계 한국어 학습자다. 몽골은 약 20개 출시 대상국 중 하나이며, 몽골어 중심 제품으로 설계하지 않는다.
- 공개 출시는 약 20개국 동시 출시를 목표로 한다. 정확한 국가 목록·지원 언어·출시일은 아직 이 대화에서 정하지 않았다. 이전에 제안한 국가별 순차 공개를 사용자 결정으로 적용하지 않는다. 비공개 시험 범위와 공개 출시 범위는 다르다. **2026-10-02 사용자 결정:** 브라질·멕시코를 출시 목록에 넣는다(스페인어·포르투갈어 지원). 브라질은 미성년 보호법 대비가 출시 전에 필요하다([브라질·멕시코 전략](마케팅/LAB_브라질_멕시코_전략_20261002.md), [공개판 설계 §8-1](공개판_설계.md#brazil-eca-digital)).
- 목적은 한국어를 재미있게 배우고 TOPIK 취득까지 이어가는 것이다. 마을이나 게임의 성장은 실제 한국어 실력·공식 급수와 구분한다.
- 아틀라스는 학습·숙제 수행 방식·선택·응답을 이해하고 다음 경험에 반영한다. 마스코트는 그 이해가 사용자에게 느껴지는 얼굴이며, 소통과 대화를 핵심 경험으로 발전시킨다.
- 당분간 온라인 학습자 개발을 우선한다. 오프라인은 기존 설계와 관리 기능을 유지한다. 사용자가 오프라인 설계는 충분히 준비됐다고 판단한 것이며, 모든 오프라인 기능의 구현 완료를 확인했다는 뜻은 아니다.
- 한 반의 정원 16명 = 한 마을의 정원 16명이다. 온라인과 오프라인 모두 적용한다. 파티·길드 같은 소속이며 협동이나 16명 동시 접속은 활동의 필수 조건이 아니다.
- 꾸미기·소통·놀이·학습·성취가 이어지고, 아름다운 배경 자체가 머물 이유가 되어야 한다. 혼자 접속해도 NPC와 장치로 할 일이 있다.
- 기존 시각 방향인 가까운 펠트 재질, 열린 회화적 원경, 미래 한국의 명소, 팔 없는 몽글은 유지한다.
- 꾸미기는 앞서 정한 주요 BM 중 하나다. 소통을 확장하면서 API 원가와 BM을 함께 설계한다. 상품 가격이나 대화 제공량을 이번 전달만으로 확정하지 않는다.
- 국가별 활발한 SNS에서 릴스·캐러셀 등을 현지화해 앱과 회사를 알린다. 계정 준비·프로필 반영·콘텐츠 게시·앱 출시를 구분한다. 게임·콘텐츠 기획은 GPT와 함께 이어간다.

기존 일반 사용자 주 1회 활성 마을 이동, 학원 반 고정, 교사 관리 경계도 유지한다. 주간 이동의 정확한 기준은 [코어 인계](../experiences/dokkaebi-express/art-direction/village-20260919/CORE-HANDOFF.md)에서 여전히 미정이다.

2026-09-21 마을 후속: 사용자는 농사·가게·대화 등 모든 활동을 매일 강제하지 않고 각자 좋아하고 잘하는 활동으로 발전하는 방향을 승인했다. NPC가 플레이어별 성과를 이해해 다양한 방식으로 성취감을 전하도록 요청했으며, [NPC 성과 인정 설계](디자인/마을_NPC_성과인정_설계_20260921.md)에 근거 있는 사건·개인 기여·NPC별 인지·전달 선호·실제 행동과 공간 변화·지속 기록·제한된 AI 사용을 제안했다. 현행 코어를 대체하거나 지속 기억의 구현 완료를 선언한 것이 아니다.

2026-09-21 Atlas 장기 후속: 사용자는 개인화와 학습 설계를 Atlas 자체의 공통 능력으로 발전시키고 SYNK ID를 통해 여러 콘텐츠에 이어 쓰는 방향을 승인했다. [장기 기억·콘텐츠 연결 계획](SYNK_플랫폼_계정과_연결_설계.md)에 기억의 범위·사용자 정정/삭제·작품과 성취·새로운 발견·학습 이후 경험·단계적 검증을 기록했다. 전체 시스템은 아직 미완성이며 Google 로그인과 내부 계정을 결합하는 구조는 이번에 조사한 제안이다. 인증·저장소 업체 선정이나 실제 구현은 하지 않았다.

## 3. 마스코트가 나를 이해한다고 느끼는 경험 — 제안

핵심은 기억을 말로 과시하는 것보다 실제 도움을 바꾸는 것이다.

예를 들어 사용자가 어제 요청 표현 과제에서 힌트 뒤에는 답했지만, 혼자 다시 말하기는 어려웠다고 하자. 오늘 정원 가게에서 같은 기능을 쓰는 짧은 부탁을 제안하고, 사용자가 원하면 한 단계 힌트를 준다. 며칠 뒤 새 상황에서 혼자 표현했는지 확인해 다음 난이도를 바꾼다. 단순 접속 시간·수정 횟수를 성격이나 실력으로 단정하지 않는다.

- 대화 맥락: 지금 누구와 무엇을 이야기하는지, 마지막 미완료 대화, 오늘 사용자가 고른 목적.
- 개인 이해: 본인이 확인한 목표·선호와 근거 있는 학습 관측. 틀린 기억을 고치거나 잊게 할 수 있다.
- 다음 행동: 말만 달라지는 것이 아니라 과제·힌트·NPC 활동·복습 시점이 달라진다.
- 공개 범위: 개인 마스코트 대화와 마을 공개 대화는 구분한다. 친구 앞의 NPC가 개인 고민·약점·숙제 내용을 공개하지 않는다. NPC를 실제 친구의 접속·발언으로 위장하지 않는다.
- 학습 결과: 힌트 유무·재시도·낯선 상황의 독립 수행·시간이 지난 뒤의 유지 여부를 함께 본다. 게임 레벨과 TOPIK 능력 증거는 다르다.

16명 소속은 관계의 범위이지 같은 실력이라는 뜻이 아니다. 같은 장소와 이야기 속에서도 각자의 과제 난이도는 달라질 수 있다. 온라인 마을 배정에는 접속 시간대·희망하는 교류 언어 등을 후보로 검토하되 국적만으로 고정 배정하지 않는다.

|---|---|---|
| 풍경 산책과 전망 벤치 | 같은 장소가 아침 안개·비 뒤의 빛·노을로 달라진다. 대화를 끄고 감상만 해도 된다 | 원할 때 눈앞 풍경을 한 문장으로 표현하고 마스코트와 짧게 이야기한다. 모든 걸음을 퀴즈로 막지 않는다 |
| 작은 찻집·정원사·우체국 NPC | 저마다 이어지는 생활과 짧은 이야기가 있고, 지난 상호작용 다음 장면이 열린다 | 부탁·취향·계획·이유 말하기를 상황 속에서 사용한다. 공통 이야기는 제작해 두고 개인에 맞는 대화만 제한적으로 생성한다 |
| 기억 정원·사진첩 | 내가 고른 표현·사진·혼자 해낸 일이 집과 정원에 남는다 | 예전 표현을 새로운 장면에서 다시 사용한다. 체류 시간만으로 언어 능력 보상을 주지 않는다 |
| 마을 우편함·풍경 엽서 | 친구가 없어도 짧은 엽서를 남기고 다음 접속 때 답을 읽는다. NPC 편지는 NPC임을 표시한다 | 초급은 문장 조각을 고르고, 익숙해지면 직접 쓴다. 답장 강요·미응답 벌점은 두지 않는다 |
| 공방과 개인 집 | 배운 표현으로 내가 원하는 모양과 배치를 골라 작은 공간을 완성한다 | 위치·색·비교·설명 표현을 사용한다. 친구가 없는 시간에도 개인 작업을 끝낼 수 있다 |
| 동네 소식과 선택형 행사 | 혼자 끝내도 의미가 있고, 접속한 친구와 함께하면 다른 장면이 열린다 | 안내 듣기·순서 파악·역할 대화를 섞는다. 결석 때문에 남의 진행이 막히지 않는다 |

아름다움은 첫 체류 이유, 이어지는 이야기와 내 흔적은 재방문 이유, 사람이 남긴 반응은 관계의 이유라는 가설이다. 실제 반응을 시험해야 한다. 체류 시간만 최대화하지 않고 학습 전이·자발적 재방문·대화 만족을 같이 확인한다.

## 5. API 비용을 통제하는 구조 — 제안

- 이동·장식 배치·인벤토리·정답이 있는 채점·복습 선택·기본 인사는 생성형 AI 호출 없이 처리한다. 이때도 서버·저장·전송 비용은 별도다.
- NPC의 공통 이야기·언어별 안내·고정 음성은 제작·검수 후 재사용한다. 사용자마다 전체 이야기를 다시 생성하거나 모든 채팅을 자동으로 여러 언어로 번역하지 않는다.
- 개인 자유 대화·답변 설명에만 필요한 모델을 부른다. 간단한 응답과 복잡한 작문·교정의 품질을 따로 평가하고, 더 비싼 처리는 필요할 때만 쓴다.
- 긴 원문 대화 전체를 매번 보내지 않는다. 현재 장면·최근 발화·이번 대화에 필요한 확인된 기억만 전달한다. 요약·기억 추출 자체의 비용도 센다. 개인 내용은 공용 응답 캐시에 넣지 않는다.
- 글 대화와 음성 대화의 원가를 분리한다. 음성 인식·생성·재시도까지 합산한다. 개인별·기능별·서비스 전체 예산을 호출 전에 예약하고 결과 후 실제 사용량과 맞춘다. 중복 요청과 무제한 재시도를 막는다.
- 상한에 가까워지면 안내하고 가능한 대화 길과 학습·산책·꾸미기를 남긴다. 준비된 선택형 대화로 바뀐 것을 숨기거나, 마스코트가 사용자를 잊었다고 연출하지 않는다.
- 사람이 없는 마을은 저장된 상태로 남고 접속 시 다시 연다. 서버 권한·구매 검증은 유지하되 빈 마을의 시뮬레이션이나 NPC 모델 호출을 계속 돌리지 않는다.

운영 판단은 `결제 후 남는 수익 − AI·음성·실시간 서버·저장·전송·지원의 변동비`로 본다. 결제하지 않는 사용자의 비용까지 포함한다. 평균뿐 아니라 많이 쓰는 이용자의 비용, 국가·언어별 오류·재시도, 무료 이용자와 유료 이용자의 분포를 측정한다. 아직 가격·사용량 실측이 없으므로 수익성이나 무제한 대화의 지속 가능성을 보장하지 않는다.

## 6. BM 연결 — 제안, 가격 미정

- 공통의 아름다운 세계와 기본 관계 경험을 충분히 제공하고, 의상·액세서리·개인 집과 정원의 표현으로 꾸미기 상품을 설계한다.
- 구독을 추가한다면 심화 학습 도구·확장된 피드백·측정 가능한 대화/음성 제공량처럼 실제 비용과 가치가 있는 구성을 비교한다. 무제한 AI를 먼저 약속하지 않는다.
- 기억을 인질로 삼는 과금, 미결제로 친구 관계를 끊는 연출, 성적·TOPIK 합격 구매는 제안하지 않는다. 꾸미기 매출이 대화 원가를 항상 보전한다고 가정하지 않는다.
- 반 이동 때 아이템 소유·개인 집 배치가 이어져야 꾸미기 구매의 가치가 유지된다. 공용 공간 편집 권한·공유 장식의 귀속은 별도로 정한다.

## 7. 다음 구현의 우선순위 제안

1. 공개 가입·개인 계정·언어 선택·기억 지속·비용 계측을 하나의 사용자 경험으로 연결한다. 국가는 언어가 아니므로 약 20개국 목록과 지원 언어 표를 따로 확정한다.
2. 마스코트 한 명과 짧은 대화 → 근거 있는 기억 → 다음 날 도움 변화 → 본인의 정정까지 만든다.
3. 아름다운 마을 한 구역에 혼자 가능한 NPC 활동 하나와 비동기 엽서를 붙인다. 장소·학습 목표·발화·보상 계약을 공통으로 두어 콘텐츠를 늘릴 때 새 시스템을 매번 만들지 않는다.
4. 같은 소속 16명의 실제 접속·대화·착용·재접속·마을 이동을 연결하고 모바일 성능을 검증한다. 개인 학습 기억과 공개 마을 상태는 섞지 않는다.
5. 출시 대상 언어별 초급 첫날 경험·동의/결제 안내·운영 대응을 검증하고 약 20개국 공개 출시로 연결한다. 작은 비공개 검증은 동시 공개 출시 목표와 양립한다.

마스코트 관계·마을 체류의 효과와 실제 한국어 향상을 별도로 평가한다. 이번 작업에서는 제품 방향과 간극을 문서화했으며 앱 코드·실시간 서버·결제·SNS 게시·엔진 실행은 변경하지 않았다.
