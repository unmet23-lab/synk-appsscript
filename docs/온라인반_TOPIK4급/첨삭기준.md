# TOPIK II 4급 온라인 반 · 첨삭 기준

[쓰기 과제](쓰기과제.md)를 돌려줄 때 쓰는 기준이다. 목적은 학생이 **다음 글을 더 잘 쓰게 하는 것**이다. 모든 오류를 고치지 않고, 점수·급수를 매기지 않는다. 판단 근거는 공식 쓰기 평가 범주의 말로 설명한다.

<a id="order"></a>
## 1. 보는 순서

[공식 PBT 쓰기 안내](https://exam.topik.go.kr/nasdata/webnas/raonkeditordata/uploadId/2024/02/20240227_175504804_07236.pdf)가 보는 범주를 따라 위에서부터 본다. 위가 무너지면 아래는 짧게 본다.

| 문항 | 공식 범주 | 먼저 볼 것 |
|---|---|---|
| 51·52 | 내용 및 과제 수행 · 언어 사용 | 빈칸 앞뒤와 이어지는가 → 문장을 끝맺었는가 → 글의 문체와 같은가(51은 그 글의 문체를 따른다 — 안내문·공식 이메일이면 「-습니다」, 친구에게 쓰는 글이면 「-아요」. 52는 「-다」) |
| 53 | 내용 및 과제 수행 · 글의 전개 구조 · 언어 사용 | 자료의 모든 항목을 썼는가 → 숫자가 정확한가 → 자료에 없는 원인·의견을 만들지 않았는가 → 소개 → 결과 → 정리 순서인가 → 증감·비교 표현 |
| 54 | 내용 및 과제 수행 · 글의 전개 구조 · 언어 사용 | 질문 셋에 모두 답했는가 → 입장이 분명한가 → 문단마다 중심 문장과 근거·예가 있는가 → 결론이 앞과 이어지는가 → 4급 표현·「-다」체 |

내부 기록에는 [TOPIK 4급 학습 설계 §4](../디자인/싱크타운_TOPIK4_학습설계와_원고.md#authoring)의 6점 루브릭(내용·구성·언어 각 0~2)을 그대로 쓴다. 이 6점을 공식 점수나 급수로 바꿔 말하지 않는다. 학생이 「몇 점이에요?」라고 물으면 「4급 글에 필요한 것 가운데 무엇이 됐고 무엇이 남았는지」로 답한다.

<a id="amount"></a>
## 2. 얼마나 고치나

- 한 편에 **고칠 곳 기호는 다섯 곳까지**(〔+〕는 따로 한 곳 이상), 한마디는 **세 줄**(아래 4절)이다.
- 같은 오류가 여러 번 나오면 처음 한 곳만 표시하고 「같은 실수 세 번」처럼 적는다.
- 글 전체를 다시 써 주지 않는다. 고친 문장 예시는 「다시 써 볼 곳」 하나에만 준다.
- 51·52는 빈칸마다 「인정 · 부분 · 다시」 셋 중 하나와 한 줄 이유면 된다.

<a id="codes"></a>
## 3. 첨삭 기호

| 기호 | 뜻 | 예 |
|---|---|---|
| 〔체〕 | 문체가 섞임 | 「조사했습니다. … 증가했다.」 → 글 전체를 「-다」로 |
| 〔조〕 | 조사 | 「63%이」 → 「63%가」(퍼센트로 읽는다) |
| 〔어〕 | 어미·활용, 앞뒤 호응 | 「이유는 도로가 많아졌다」 → 「이유는 도로가 많아졌기 때문이다」 |
| 〔낱〕 | 낱말 선택 | 「15% 증가」 → 「15%포인트 증가」, 글에서 「너무」 → 「지나치게」 |
| 〔맞〕 | 맞춤법 | 「됬다」 → 「됐다」, 「몇일」 → 「며칠」 |
| 〔띄〕 | 띄어쓰기 | 「할수 있다」 → 「할 수 있다」, 「안한다」 → 「안 한다」 |
| 〔연〕 | 문장 연결 | 짧은 문장 나열 → 「-(으)며, -지만, 또한, 이처럼」으로 잇기 |
| 〔근〕 | 근거·예 부족 | 「좋다고 생각한다」만 있고 왜 좋은지가 없음 |
| 〔빠〕 | 요구 내용 빠짐 | 54번 질문 하나, 53번 원인·전망 하나가 없음 |
| 〔자〕 | 자료와 다름(53) | 자료에 없는 원인, 틀린 숫자, 단위 빠짐 |
| 〔+〕 | 잘 쓴 곳 | 한 편에 한 곳 이상 꼭 표시한다 |

<a id="comment"></a>
## 4. 한마디 세 줄

학생에게는 짧은 해요체로 쓴다. 꾸짖지 않는다.

- **잘된 점:** 이 글에서 정확히 해낸 것 하나. (예: 「두 해의 비율을 정확히 옮겼어요.」)
- **고칠 핵심:** 다음 글에서 점수에 가장 크게 걸리는 것 하나. 기호를 함께 적는다. (예: 「물가 이야기는 자료에 없는 내용이에요.〔자〕」)
- **다시 써 볼 곳:** 학생이 직접 다시 쓸 문장 하나와 쓸 표현. 다음 과제와 함께 낸다. (예: 「두 문장을 『-에서 -로 증가했다』로 이어 보세요.」)

「고칠 핵심」은 1절의 순서에서 가장 위에 걸린 것으로 고른다. 질문 하나가 빠진 54번 글에 맞춤법을 핵심으로 쓰지 않는다.

<a id="common-errors"></a>
## 5. 몽골 학습자에게 잦은 오류

[커리큘럼 정본 §6](../커리큘럼_정본_v1.md)의 난점(한자어, 높임과 문체)과 쓰기 과제에서 자주 나오는 것을 모았다. 수업의 「지난 쓰기 돌려보기」에서 이 목록의 번호로 말하면 학생이 자기 오류 목록에 옮기기 쉽다.

1. **문체 섞기** — 한 글에 「-아요/-습니다/-다」가 섞인다. 53·54는 처음부터 끝까지 「-다」.
2. **「-다」 활용** — 동사는 「-ㄴ다/-는다」(증가한다, 늘어난다), 형용사는 「-다」(많다), 명사는 「-이다」. 「많는다」, 「증가하다.」(문장 끝)처럼 쓰지 않는다.
3. **숫자 뒤 조사** — 읽는 소리에 맞춘다. 「63%가」(퍼센트), 「1만 건이」, 「15명이」.
4. **비슷한 한자어** — 증가/증대, 감소/감축, 원인/이유, 영향을 주다/받다/미치다. 53은 「증가하다·감소하다·차지하다·영향을 미치다」로 충분하다.
5. **피동** — 「조사가 되었다」보다 「조사되었다」나 「조사하였다」. 전망은 「예상한다」보다 「예상된다」, 「-(으)ㄹ 것으로 보인다」.
6. **앞뒤 호응** — 「이유는 ~다」는 「이유는 ~기 때문이다」, 「원인으로는 ~을 들 수 있다」.
7. **연결 없는 나열** — 짧은 문장을 「그리고」로만 잇는다. 「-(으)며, -지만, 반면에, 또한, 이처럼, 따라서」를 뜻에 맞게.
8. **맞춤법** — 됬다→됐다, 몇일→며칠, 안/않(「안 한다」, 「하지 않는다」), 되/돼(「되어」를 줄이면 「돼」).
9. **띄어쓰기** — 의존 명사 앞: 「할 수 있다」, 「먹을 때」, 「쓴 것」. 「안 하다」, 「못 가다」.
10. **말하는 낱말** — 너무 → 지나치게(나쁜 쪽으로 심할 때)·매우, 진짜·엄청 → 매우·상당히(「진짜 문제」처럼 「실제」 뜻이면 「실제」), 근데 → 그런데·그러나. 「정말」은 글에서도 쓸 수 있다. 줄어들다·늘어나다 같은 변화 동사 앞에서는 「매우」보다 「크게」가 자연스럽다(크게 줄어든다).
11. **54번 구성** — 질문 하나 빠뜨리기, 결론에서 새 주장, 문제 문장 그대로 옮기기, 같은 말을 되풀이해 분량 채우기.
12. **53번 자료** — 자료에 없는 원인 만들기, 「%」와 「%포인트」 혼동, 단위(건·명·만 원) 빠뜨리기, 제목 쓰기.

## 6. 한 주의 흐름

| 언제 | 누가 | 무엇을 |
|---|---|---|
| 토요일 수업 끝 | 선생님 | 이번 주 과제(W번호)와 마감·내는 법 안내 |
| 수요일 23:00 | 학생 | 과제 마감. 지난주 「다시 써 볼 곳」 한 문장도 함께 낸다 |
| 금요일까지 | 선생님 | 기호 표시와 한마디 세 줄로 돌려준다 |
| 토요일 수업 앞 20분 | 선생님 | 이번 주 공통 오류 셋(5절 번호로), 잘 쓴 문장 둘을 이름 없이 화면에 보인다 |

- **시간 어림(한 사람):** 51·52 한 문항 1~2분, 53 한 편 약 5분, 54 한 편 8~10분, 지난주 「다시 써 볼 곳」 한 문장 1분이다.
  - 개강 인원 10명이면 1~5주는 주 1시간 안팎, 54번 주(6·8주)는 2시간 안팎이다. 네 문항을 다 보는 모의 주(7주)는 3시간 20분쯤 든다.
  - 16명이면 각각 1시간 반 안팎, 3시간, 5시간 20분쯤이다.
  - 7주는 51~53을 금요일까지 먼저 돌려주고, 54는 다음 주 화요일까지 돌려준다(8주 고쳐 쓰기 마감 전에 받도록).
  - 실제 시간은 첫 기수에서 재고 고친다.
- **늦게 낸 글:** 다음 주 과제와 함께 본다. 이 반은 보장·벌점이 없으므로 늦었다고 불이익을 주지 않는다.
- **AI로 1차안을 만들 때:** 선생님이 참고용 1차안을 쓸 수 있다. 학생에게 나가는 기호와 한마디는 선생님이 확인하고 고친 것만 보낸다. 53은 숫자를 자료와 직접 대조한다. 1차안만으로 점수·급수를 말하지 않는다.

<a id="manuscript"></a>
## 7. 원고지(PBT)

PBT를 볼 학생은 6주부터 53·54를 원고지에 쓴다. 자주 틀리는 것만 적는다. 세부는 [공식 원고지 안내](https://exam.topik.go.kr/nasdata/webnas/raonkeditordata/uploadId/2024/02/20240227_175447974_51977.pdf)로 확인한다.

- 문단을 시작할 때 첫 칸을 비운다.
- 숫자는 한 칸에 두 자씩 쓴다.
- 마침표·쉼표 같은 문장 부호도 한 칸을 쓴다.
- 53·54에 제목을 쓰지 않는다.

<a id="privacy"></a>
## 8. 학생 글 다루기

- 이 저장소는 공개 저장소다. 실제 학생의 글·이름·연락처·첨삭 기록을 Git에 올리지 않는다. 이 폴더의 「가상 학생 초안」만 예시로 쓴다.
- 수업 화면에 학생 글을 보일 때는 이름을 지우고, 본인이 괜찮다고 한 문장만 보인다. 수업 영상은 녹화되어 반 복습 영상이 된다는 점을 생각한다.
