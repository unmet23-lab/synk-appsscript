# 유호 본인 목소리 자동화 — 2026-09-10 조사와 실행 제안

**추천은 깨끗한 한국어 원본 녹음 → 전문 음성 복제 → 고정된 화자·모델로 대본 합성 → 가벼운 소리 보정이다.** ElevenLabs Professional Voice Cloning(PVC, 본인 녹음을 학습하는 전문 복제)을 기준 후보로, Fish Audio S2.1과 MiniMax Speech 2.8 HD를 비교한다. 아래 순서는 품질과 운영 조건을 함께 고려한 조사 판단이며, 유호 목소리의 실제 청취 순위가 아니다.

사용자 확정: 여자 목소리는 DIVE 나나. 남자 목소리는 가급적 유호 본인 목소리이며 DIVE에 한정하지 않는다. 남성 공급자·유료 플랜은 미선택이다. 나나의 좋은 공개 샘플을 다른 사람의 복제 품질 증거로 쓰지 않는다. [결정 정본](../../_ops/결정.md)

조사 기준일: 2026-09-10 KST. 공식 사이트·API 문서·GitHub/Hugging Face를 읽었다. 원본 파일과 실제 요청 시각·응답 날짜·SHA256은 [수집 목록](조사/본인목소리_20260910/crawl-manifest.json)에 있다. 이번에는 음성 업로드·복제·생성·신규 결제·자동화 연결을 하지 않았다.

## 1. 무엇을 자동화할지

| 방식 | 유호가 매번 해야 할 일 | 얻는 것과 한계 |
|---|---|---|
| **본인 목소리로 텍스트 합성 — 주력 제안** | 최초 원본 녹음과 본인 확인, 이후 대본 확인 | 매번 녹음하지 않아도 새 문장을 읽는다. 음색과 말투의 일관성은 실제 대본으로 검증해야 한다. |
| 직접 말한 음성의 자동 정리 — 중요한 문장의 보완책 | 사용할 문장을 직접 말하기 | 실제 말끝·웃음·호흡을 가장 직접적으로 보존한다. 매번 말해야 하므로 완전한 대본 자동 생성과는 다르다. |
| 음성 변환 — 선택적 비교 | 연기·억양을 담은 가이드 녹음 | 가이드의 전달 방식을 목표 음색으로 옮긴다. 추가 합성 과정이므로 음질 개선을 보장하지 않는다. |

ElevenLabs 음성 변환 API는 입력 오디오가 내용·감정을 제어하고, 배경 잡음 제거 옵션도 제공한다. 자기 목소리의 자연스러운 연기를 보존하려는 경우에는 원본을 가볍게 정리한 버전을 먼저 기준으로 삼는 것이 나의 제안이다. [음성 변환 API](https://elevenlabs.io/docs/api-reference/speech-to-speech/convert)

## 4. 스튜디오 같은 결과를 위한 녹음 절차

다음은 원본을 재사용하기 위한 나의 제작 제안이다. 장시간 녹음 전에 짧게 확인한다.

1. **2~3분 시험 녹음.** 평소 상대에게 설명하듯 말한다. 같은 마이크와 거리를 유지하고, 방 울림·팬 소리·입김·갈라지는 소리를 확인한다. 여성 나나의 말투를 남성 목소리에 복제하려 하지 않고 유호의 실제 설명 말투를 기준으로 삼는다.
2. **원본 환경 확정.** 품질이 우선이면 흡음된 녹음실에서 마이크·팝필터·거리·게인을 한 번 맞추는 방법을 권한다. 기존 장비로 충분한지는 시험 녹음을 보고 판단한다. 조용한 원본을 확보하는 것이 과도한 AI 잡음 제거보다 우선이다.
3. **쓸 수 있는 발화부터 확보.** 나의 단계 제안은 일관된 한국어 발화 30~60분을 먼저 확보하는 것이다. ElevenLabs PVC 최적화에 더 필요하면 공식 권장 범위인 2~3시간까지 추가한다. 녹음실 대여 시간이 아니라 편집 후 실제 발화 시간을 센다.
4. **보관본과 업로드본 분리.** 보관 원본은 WAV 48kHz/24bit mono를 제안한다. 배경음·리버브·피치 변경 없이 보존한다. 서비스별 업로드 조건에 맞춰 별도 사본을 만든다. ElevenLabs는 192kbps 이상 MP3를 권하며 WAV 업로드 자체가 복제 품질을 높이지는 않는다고 설명한다.
5. **같은 녹음에서 공급자별 자료를 준비.** Fish PVC는 1분 미만 조각들로 총 10분 이상, MiniMax는 조건에 맞는 짧은 구간, ElevenLabs PVC는 충분한 전체 발화 자료를 사용한다. 모든 서비스에 같은 길이 파일을 억지로 넣지 않는다.

노래·통화·배경음이 깔린 영상·잡음 제거가 심하게 적용된 소리를 섞어 분량만 늘리지 않는다. 마이크 브랜드나 48kHz라는 숫자만으로 스튜디오 품질을 보장하지 않는다. 녹음과 모델 출력의 해상도는 별개다. [ElevenLabs 원본 품질 안내](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning), [Fish 입력 조건](https://fish.audio/blog/professional-voice-cloning/), [MiniMax 입력 조건](https://platform.minimax.io/docs/api-reference/voice-cloning-uploadcloneaudio)

## 5. 대본만으로 제작하는 자동화 설계

**확정 대본 → 고정 voice ID·모델·설정 → 문맥이 이어지는 단위로 합성 → 원음 저장 → 발음·누락 확인 → 가벼운 보정 → 영상 믹싱**으로 연결한다. 아래는 구현 계획이며 연결 완료가 아니다.

- 화자·모델·참조 파일과 설정의 버전을 기록한다. 같은 대본·같은 설정의 완성 음원은 재사용하고, 필요 없는 재생성을 줄인다.
- 브랜드명·숫자·영문 약어는 읽을 형태를 먼저 정한다. 문장을 지나치게 잘게 나눠 억양이 끊어지지 않게 한다. ElevenLabs는 앞뒤 문장·요청 ID로 연결 문맥을 제공할 수 있다.
- 시작 비교값은 ElevenLabs Multilingual v2의 stability 0.5, similarity 0.75, style 0, speed 1.0이다. 고정값은 출발점이며 유호에게 검증된 최적값이 아니다. 유사도를 무조건 최대로 올리면 원본 잡음까지 따라올 수 있다.
- 모든 후보를 같은 청취 음량으로 맞춰 들어본다. 비교용 음량과 최종 영상의 음량은 별개다. 영상에서는 나나·유호·음악의 체감 균형을 함께 맞춘다.
- 보정은 필요한 부분의 잡음·치찰음·음량 차이를 가볍게 줄인다. 합성 말투의 어색함이나 잘못된 발음을 EQ/음량 조절로 해결했다고 보고하지 않는다.
- 결과의 음량, 클리핑, 무음, 발음·단어 누락을 검사하고, 의심 구간은 실제로 듣는다. 자동 받아쓰기 일치나 화자 유사도 점수는 사람의 자연스러움 판정을 대신하지 않는다.

근거: [ElevenLabs 설정](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [합성 API·문맥·재현성 한계](https://elevenlabs.io/docs/api-reference/text-to-speech/convert). 같은 seed를 넣어도 완전히 동일한 출력은 보장되지 않는다. 같은 파일을 재사용하는 경우와 새로 합성하는 경우를 구분한다.

## 6. 실제 선택을 위한 짧은 비교

아래는 나의 청취 시험 제안이다. 모델 홍보 영상이나 기존 여성 성우 순위로 남성 본인 복제를 확정하지 않는다.

- 평소 설명, 짧은 도입, 질문, 조용한 마무리, 숫자·브랜드명을 포함한 문장, 45~60초 연결 문단을 준비한다.
- 원본 녹음에 없던 대본으로 생성한다. 화자별로 서비스명 대신 A/B/C를 붙여 같은 음량에서 듣는다.
- 대표 문장 하나는 같은 설정으로 3회 생성해 음색·말끝 변동을 별도로 확인한다. 전체 영상마다 3회 생성해야 한다는 운영 규칙은 아니다.
- 평가할 것은 **유호를 닮았는지 / 한국어 말투가 자연스러운지 / 음질이 깨끗하고 풍부한지 / 여러 문장에서도 같은 사람으로 들리는지**다.
- 짧은 참조 복제 결과로 전문 복제 결과까지 단정하지 않는다. 반대로 전문 복제라는 상품명만으로 다른 서비스보다 낫다고 단정하지 않는다. 만족한 후보만 실제 LAB·SHIFT 대본에 적용한다.

## 8. 증거와 남은 일

- 공개 1차 자료 URL **29개**를 한정 수집해 **25개 HTTP 200 원문**을 보관했고 SHA256 재대조가 모두 일치했다. 4개는 로컬 TLS 인증서 확인 실패를 그대로 기록했다. 인증서 검증을 끄지 않았다. ElevenLabs 도움말·DIVE 문서는 웹 도구로 읽었으며 Fish 코덱은 독립 조사자가 공식 GitHub 화면으로 확인했다.
- GitHub/Hugging Face 조사와 상용 대안 조사를 독립적으로 나눠 확인한 뒤 통합했다. 업체 자체 평가, 영어 비교, 일반 성우 TTS 순위를 유호의 한국어 본인 복제 실측 순위로 바꾸지 않았다.
- 실제 녹음 환경·사용할 유호 원본·후보별 본인 유사도·한국어 말투는 미확인이다. 최고 후보를 확정하려면 위 비교가 필요하다.
- **다음 실제 준비는 2~3분 시험 녹음**이다. 이 단계에서 방 울림·잡음·자연스러운 말투가 맞는지 먼저 확인하고 장시간 자료를 준비한다. 유료 복제 등록·자동화 구현·영상 교체는 이번 조사에서 실행하지 않았다.
