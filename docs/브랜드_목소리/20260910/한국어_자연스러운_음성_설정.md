## 확정 화자: DIVE 나나 — 세부 설정은 시작 제안

아래는 공식 Standard API 항목이다. 서비스 화면이 모든 항목을 제공한다는 뜻은 아니다.

| 항목 | 시작값 |
|---|---|
| 화자 | 나나 |
| 감정 | neutral |
| 언어 | ko |
| 속도 speed | 1.0 |
| 음높이 pitch | 0 |
| 출력 볼륨 volume | 50 |
| 문장 사이 추가 무음 sentenceSilenceSec | 0.4초 |
| 출력 outputFormat | wav_48000 |

나나의 neutral은 공개 평가 코드의 구성이다. 나머지는 공식 기본값이다. 문장 사이 0.4초는 문장 오디오 사이에 시스템이 추가하는 간격이며, 음성 안에 포함된 숨이나 쉼 전체를 뜻하지 않는다. 선택 후 템포가 늘어질 때만 0.25~0.30초 비교를 제안한다. 이 축소값은 나의 편집 제안으로, 검증된 최적값이 아니다. [Humelo 공식 문서](https://console.humelo.com/docs/dive)

## ElevenLabs를 사용할 때

Voices → Explore에서 **Language: Korean / Gender: Female / Category: Conversational / Quality: Studio Quality**로 찾는다. 원하는 성인 여성 음색을 고르되 Age는 후보가 부족하면 제한하지 않는다. Studio Quality는 장비·잔향·왜곡 등을 검수한 녹음 품질 분류이며 말투의 자연스러움을 보증하는 표시는 아니다. 한국어 필터에는 한국어 수행이 좋다고 평가된 다국어 화자도 섞일 수 있어 실제 한국어 미리듣기로 확인한다. [Voice Library 공식 안내](https://elevenlabs.io/docs/eleven-creative/voices/voice-library)

| 항목 | 시작값 |
|---|---|
| 모델 | Eleven Multilingual v2 |
| Stability — 말투 변동 정도 | 50% |
| Similarity — 원래 화자와의 유사도 | 75% |
| Style Exaggeration — 표현 과장 | 0% |
| Speed — 속도 | 1.0 |
| Speaker Boost — 화자 유사도 보강 | 켜짐(API 기본값) |
| 감정·웃음 태그 | 넣지 않음 |

50·75·0은 공식 문서의 시작 권장값이다. 너무 단조로울 때 Stability 45를 비교하고, 억양이 흔들리면 55를 비교하는 것은 나의 소폭 조정 제안이다. 수치를 올리는 것만으로 해상도나 자연스러움이 높아지지는 않는다. 특히 Similarity를 무조건 100으로 높이지 않는다. [설정 설명](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [API 기본값](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)

Professional Voice Clone(PVC)은 실제 화자의 녹음으로 정교하게 학습한 음성이다. 공식 Voice Design 문서는 PVC의 품질·일관성을 높게 평가하며, 현재 FAQ에는 v3의 PVC 지원 제한이 남아 있다. 그래서 이번 용도에서는 PVC와 Multilingual v2를 기본 조합으로 제안한다. 이것이 v2가 모든 한국어 화자에서 v3보다 낫다는 증거는 아니다. [공식 Voice Design 문서](https://elevenlabs.io/docs/eleven-creative/voices/voice-design)

v3는 2026-02-02 일반 공개로 전환됐지만 일부 안내에 연구 미리보기 표현이 남아 있다. 비교할 때는 **Stability: Natural**, 우선 감정 태그 없이 시작한다. 현재 제품 문서상 v3에는 Speed·Similarity·Speaker Boost가 없다. v2 슬라이더 조합을 그대로 복사하지 않는다. [공개 발표](https://elevenlabs.io/blog/eleven-v3-is-now-generally-available), [v3 가이드](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)

API를 쓸 때 Multilingual v2에는 `language_code`가 지원되지 않는다고 현재 스키마에 명시돼 있다. 한국어 대본·화자를 사용하고, 해당 필드를 억지로 넣지 않는다. 음성 선택을 끝낸 뒤 출력 원본을 확보한다. 공식 API는 44.1kHz PCM/WAV에 Pro 이상 조건을 명시한다. 화면의 History에서도 WAV를 내려받을 수 있지만, 파일 확장자만으로 원래 생성 해상도나 무압축 생성 경로를 증명할 수는 없다. [현재 API 스키마](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)

## Typecast 비교 기준

자인은 공개 평가에서 사용한 화자다. 공식 API 기준 `ssfm-v30`, 감정 preset `normal`, 감정 intensity `1`, tempo `1`, pitch `0`을 기본으로 둔다. 감정이 과하면 intensity `0.5` 비교를 제안한다. 공식 문서는 0.5를 은은한 표현으로 설명한다. 일반 합성 WAV 출력은 44.1kHz·모노·16비트다. [Typecast 공식 문서](https://typecast.ai/docs/api-reference/text-to-speech/text-to-speech)

## 대본과 비교 방법

감정 지시는 과하게 붙이지 않고, 생활 대화로 먼저 말끝을 확인한다. 아래는 모델 간 비교를 위한 새 시험 문안이다. 기존 게시물 대본을 변경한 것이 아니다.

> 같이 들어볼까요? 이번에는 말끝만 조금 바꿔볼게요. 같은 문장인데도 느낌이 꽤 달라지죠? 마음에 드는 쪽을 골라주세요.

한 문단을 함께 생성하고 같은 재생 음량에서 듣는다. ‘상큼함’은 기본 음색이 밝은 화자로 확보하는 것을 우선한다. 말끝을 매번 올리거나 웃음·감탄 태그로 꾸미는 지시는 시작 비교에서 제외하는 것이 나의 제안이다. 나나는 확정됐으므로 실제 LAB·최신 SHIFT 문장에서 말투·템포·음량을 조정한다.

## 확인 범위와 수집 기록

- 공식 문서·공개 평가 11개 URL을 한정 수집했다. 인터넷 전체를 전수 조사했다는 뜻은 아니다.
- 10개는 로컬 HTTP 200 응답과 원문·시각·SHA256을 저장했다. Humelo는 웹 도구로 공식 본문을 확인했으나 별도 Python 수집은 인증서 체인 오류로 실패했다. 인증서 검증을 끄지 않았다.
- 저장 위치: `조사/한국어_설정_20260910/crawl-manifest.json`. CDN 응답 날짜와 실제 요청 시각을 따로 기록했다.
- 공개 평가 실행 코드의 화자·16kHz 변환은 독립 조사자가 오늘 원문으로 확인했다. 실제 배포 환경변수는 확인 불가다.
- 위 수집 당시 계정 로그인·신규 결제·음성 생성·설정 적용·청취 검증은 수행하지 않았다. 이후 공식 공개 샘플 청취와 나나 확정은 문서 첫머리에 반영했다. Higgsfield 음성 생성 중단은 유지한다. 나머지 6편은 확정 화자와 우리 대본의 음성 연결·검증 뒤 제작을 잇는다.

## 유호 본인 목소리 자동화 — 2026-09-10 제안, 미실행

사용자는 남성 본인 음성에 DIVE를 꼭 쓸 필요가 없다고 추가로 정했다. 최신 방법·상용 및 공개 모델 비교·녹음 절차·비용·수집 증거는 [본인 목소리 자동화 조사](본인목소리_자동화_조사.md)에서 확인한다. 아래는 그에 앞선 초기 제안이며 공급자 확정이 아니다.

- 품질 우선의 시작 제안은 깨끗한 한국어 녹음 원본을 준비한 뒤 ElevenLabs Professional Voice Cloning(본인 녹음을 학습하는 전문 음성 복제)과 DIVE 저장 음성을 실제 새 대본으로 비교하는 것이다. 여성 프리셋의 선호를 남성 복제 품질의 증거로 일반화하지 않는다.
- 녹음은 먼저 2~3분 시험으로 잔향·잡음·파열음·원하는 말투를 확인한다. 합격한 환경에서 같은 마이크·거리·자연스러운 설명 톤을 유지한다. 원본 보관은 WAV 48kHz/24bit를 제안하되 파일 형식만으로 복제 품질이 높아지지는 않는다. 이것은 녹음 원본 기준이며 제공사의 생성 원본 해상도 보장이 아니다.
- ElevenLabs는 한국어 전문 복제와 Multilingual v2 학습을 지원한다. 공식 최소 권장 녹음은 30분, 최적 권장은 2~3시간이다. 본인 계정에서 목소리 확인 절차를 거친다. Creator는 전문 복제 1개를 포함하며 월 $22, 첫 달 $11(세금 별도)이다. [전문 복제](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/professional-voice-cloning), [요금](https://elevenlabs.io/pricing)
- DIVE 저장 음성은 2~20초 원본과 정확한 전사를 받아 재사용하지만 사전 승인된 조직용이다. Starter 포함 여부·개별 조건은 미확인이다. [공식 등록 문서](https://console.humelo.com/docs/saved-voices)
- 제안하는 제작 흐름은 확정 대본 → 고정 화자·모델·설정으로 생성 → 원음 보존과 가벼운 음량·치찰음 보정 → 발음·누락·왜곡 확인 → 영상용 믹싱이다. 미세한 감정 연기가 중요한 문장은 직접 녹음 후 정리하는 방법도 남긴다. 대본과 설정이 같은 완성 음원은 재사용하고 어색한 부분만 수정한다.
- 본인 음성 원본 탐색·업로드·학습·결제·자동 생성 코드 연결·사람 청취 검증은 수행하지 않았다. 실제로 유호와 얼마나 닮았는지, 한국어 말투와 음색이 얼마나 일관되는지는 원본을 이용한 비교가 남았다.
