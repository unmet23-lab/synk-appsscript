# 유호 목소리 — 한국어 말하기 시험 01

2026-09-10 사용자 요청: "이걸 적용해서 한번 우리 목소리를 만든다면 어떻게 표현될지 만들어봐줄래?"

**현재: A 음질 보정 방식은 필요한 콘텐츠의 임시 남자 목소리로 사용자 승인됐다. 유호 본인 목소리가 준비되면 교체한다. 여자 목소리는 DIVE 나나를 유지한다.** 후속 직접 요청 “남자 목소리만 당분간 이걸 쓰고 내 목소리가 나오면 교체할거야”가 앞선 후보 상태를 갱신한다. [현재 음성 선택](../../한국어_자연스러운_음성_설정.md)을 따른다.

수노의 기존 `My Voice - Sep 8`을 선택해 한국어 소개 음성 두 개를 생성했다. A는 파일 확보·검사를 마쳤고, B는 수노에서 재생할 수 있다. 처음에는 “이 목소리 좋은데 목소리 음질만 좀 좋으면 좋을것같은데?”라는 피드백에 따라 직전 인라인 A를 보정했다. 이어 사용자가 보정본에 호감을 밝히고 기존 콘텐츠 한 편 적용을 요청했으며, 위 임시 사용 범위를 명시했다.

추출한 노래 보컬 WAV를 외부 복제 모델에 넣은 결과는 아니다. Suno 생성 결과의 다른 AI 이용 제한을 이미 안내했으므로, 같은 서비스 안의 저장된 Voice로 말하기 가능성을 먼저 시험했다. 임시 사용 승인과 실제 본인 음성 제작·승인은 구분한다.

## 후속 음질 보정 v1

사용자가 마음에 든 목소리를 바꾸지 않고 음질을 조절해 달라고 요청한 범위다. A 다운로드 WAV를 직접 읽어 로컬에서 주파수별 크기와 스테레오 폭을 조절했다. 재생성·다른 성우·음높이·속도·문장 간격·끝부분 자르기는 적용하지 않았다. 기존 A 원본과 듣기용 WAV/MP3는 보존했다.

- 실제 원본 측정: 좌우 상관 0.9345, 중앙 대비 측면 신호 −14.61dB. 샘플 피크 −3.56dBFS이며 100ms 기준 매우 조용한 구간은 −62~−72dBFS였다. 강한 잡음 제거·게이트·압축이 필요한 측정 근거는 없었다. 이 수치가 음질 원인이나 잔향을 확정하지는 않는다.
- 보정: 45Hz 아래 감쇄, 190Hz −1.2dB, 2.3kHz +1.1dB, 6.5kHz −0.6dB. 측면 신호 0.65배. 저음 밀집을 조금 줄이고 발음 대역을 돕기 위한 보수적인 값이다. 후속 사용자 청취 호감과 임시 사용 승인은 문서 첫머리에 반영했다.
- 결과: 평균 **−23.00 LUFS**, true peak **−9.03dBTP**. 기존 듣기용 원본과 평균 음량을 같게 맞췄다. 고정 음량만 적용하며 동적 압축은 하지 않았다.
- 원본과 동일한 **48kHz·652,800샘플·13.60초·2채널**. 24bit WAV는 연산 결과 저장 형식이며 손실된 세부 소리를 복원했다는 뜻이 아니다. 원본에 들어 있는 합성 특유의 질감까지 스튜디오 녹음처럼 복원했다고 보장하지 않는다.
- 재현: [polish_audio.py](polish_audio.py). 실제 측정·SHA256·디코딩 검사: [음질보정_v1_검사.json](음질보정_v1_검사.json). 출력 전체 디코딩 통과, 원본 두 WAV의 지문 유지 확인. 독립 기술 검토에서도 강한 처리 없이 비교하는 방향에 뚜렷한 문제를 찾지 못했다.
- **모델의 직접 청취 확인 불가:** 현재 하네스가 오디오 입력 청취를 지원하지 않아 직접 더 좋아졌다고 판정하지 않는다. 사용자는 비교 후 임시 사용을 승인했다. 이전 A 자동 전사의 이름 명료도 확인 항목까지 해소됐다고 확대하지 않는다.

현재 참조 조사에서 시험 파일은 이 기록과 상위 보관 기록·운영 트랙으로 연결돼 있었다. 이번 보정은 동일 생성 경로의 스크립트와 새 결과를 함께 보관했다. 다른 영상·SNS 게시본에서 이 시험 파일을 사용하는 참조는 검색에서 발견하지 못했으며, 전체 영상 교체나 게시 반영은 이번 작업 범위에 포함하지 않았다.

## 입력과 설정

사용한 기존 Voice: https://suno.com/voice/d17ee0bd-81c2-4308-86a7-4184f999044d

이 Voice는 라이브러리에서 `Happy, Happy Gangster`와 연결돼 있었다. 생성 직전 화면과 생성 후 두 결과의 Voice 배지에서 같은 프로필을 확인했다. 프로필을 새로 학습하거나 수정하지 않았다.

말할 내용:

> 안녕하세요. 유호입니다.
> 저는 에이아이와 함께 회사를 만들고 있어요.
> 직접 해보고, 막히면 고치고, 쓸 만한 방법을 함께 나눌게요.
> 오늘은 우리 목소리부터 만들어볼까요?

가사 입력 앞에 `[Spoken word, conversational Korean, no singing]`, 끝에 `[End]`를 붙였다. SHIFT의 현재 원문 `docs/마케팅/SHIFT.md`에 있는 실제 AI 회사 만들기·시도·수정·방법 공유 방향을 짧은 시험 문장으로 사용했다. 게시 문안 확정이나 서비스 판매 약속은 아니다.

- 모델: 생성 화면과 결과 모두 `v6`.
- 길이 요청: 30초. 실제 결과 A는 13.60초, B는 수노 목록 약 16초였으며 길이 요청이 고정 길이를 보장하지 않았다.
- 보컬 성별: 남성. 기이함 15, 스타일 영향 80, 오디오 영향 65, 다양성 보통(값 1), 개인화 끔. 이번 실험값이며 최적 설정으로 확정하지 않는다.
- 생성 버튼 1회로 결과 2개. 사용 크레딧 차감량은 확인하지 못했다. 신규 결제 없음.
- 스타일 요청: `Korean spoken-word narration. Use the selected male voice. Completely spoken, free conversational timing, no melody, no singing, no rapping. Friendly founder explaining to one listener, lightly smiling, natural connected Korean pronunciation, warm full-bodied clear voice, lively sentence endings. Dry close studio microphone, solo voice only, no instruments, no beat, no music, no chorus, no reverb, no echo. Start speaking immediately, read the Korean text exactly once, finish cleanly.`
- 제외: `singing, melody, rap, beat, instruments, background music, backing vocals, harmony, chorus, reverb, echo, autotune`.

## 확인한 것과 남은 것

A 다운로드 원본은 PCM 48kHz/16bit 스테레오, 13.60초, 2,625,040바이트다. 원본 메타데이터의 곡 ID는 A 결과 링크와 일치했다. 다운로드 원본과 보관 사본의 SHA256이 같고 전체 디코딩 오류가 없었다.

소리 크기만 -6.23dB 조절했다. 듣기용 WAV 측정값은 평균 -23.00 LUFS, true peak -9.79dBTP다. 원본은 -16.77 LUFS, -3.56dBTP였다. 말하는 속도·음색·문장 사이 간격은 고치지 않았다. 48kHz를 유지하며 듣기용 WAV를 24bit로 저장한 것은 연산 사본의 형식이고, 원본 음질이 향상됐다는 뜻은 아니다. MP3는 듣기용 WAV에서 192kbps로 만들었다.

기존 설치·캐시의 faster-whisper-small을 CPU int8, 2 threads, 한국어 지정, beam 5, VAD로 실행한 독립 로컬 전사:

| 구간 | 자동 인식 |
|---|---|
| 0–2.00초 | 안녕하세요 요호입니다 |
| 2.00–5.16초 | 저는 AI와 함께 회사를 만들고 있어요 |
| 5.16–9.68초 | 직접 해보고 막히면 고치고 쓸만한 방법을 함께 나눌게요 |
| 9.68–12.28초 | 오늘은 우리 목소리부터 만들어 볼까요 |

**이름을 ‘요호’로 인식했다.** 이는 실제 발음 오류 확정이 아니라 ‘유호’의 명료도를 귀로 확인할 항목이다. 자동 전사는 말투의 자연스러움·반주 부재·본인 유사도를 증명하지 않는다. 현재 하네스는 오디오 입력 청취를 지원하지 않아 직접 들었다고 보고하지 않는다. 사용자가 최종 파일에서 음색·발음·말투를 판단해야 한다.

Higgsfield·외부 음성 복제 업로드·추가 대형 모델 설치·SNS 게시·기존 영상 교체는 하지 않았다. 원본 본인 발화 확보와 전문 말하기 복제 비교는 여전히 별도 미완료다.
