# 모든 사용자를 위한 SYNK 개인화 기반

2026-10-02에 확정한 공통 개인화 계약과 최초 구현 기록이다. 이후 플랫폼 계정·회원 성향과 WORLD가 각각 발전했으므로 이 문서의 초기 검증 수치·제품 목록·미완료를 현재 상태로 쓰지 않는다. 제품의 현재 구현·배포·남은 일은 [플랫폼 계정](SYNK_플랫폼_계정과_연결_설계.md)과 [WORLD](../experiences/synk-world-app/README.md)에서 확인한다.

## 회사 방향과 첫 구현

**SYNK는 각자의 목표와 상황에 맞는 도움을 만드는 개인화 회사다. LAB 학생의 학습은 첫 적용 분야다.** 교사, 클라이언트, 기관 담당자, 직장인, 30·40대와 고령자 등 이용자의 연령이나 역할이 달라도 사용할 수 있는 기반을 갖춘다. 나이가 같다고 같은 설명·기능을 강제하지 않는다. 학생의 학습 모델을 모든 사람에게 적용하는 대신, 공통 선택·출처·동의·정정 계약 위에 제품별 목적과 결과를 연결한다.

공통 입력은 **원하는 결과, 지금의 시간과 환경, 익숙함의 자기보고, 원하는 도움, 편한 표현 방식**이다. 개인화의 완료 기준은 정보 수집량이 아니라 그 선택이 실제 도움을 바꾸는지다. 교사도 학생 자료를 입력하는 역할만이 아니라 수업 준비와 판단을 도움받는 사용자다.

## 학생에게 무엇을 맞출 수 있는가

| 기준 | 실제 달라지는 것 | 현재 적용·경계 |
|---|---|---|
| 독립 한국어 문항 수행 | 듣기·읽기 안에서 다음에 확인할 영역과 추천 근거 | 기존 Core·Trail·Strata 활용. 교사 MVP 합성 기록에서 학생별 추천이 다름 |
| 첫 노출·같은 문항 계열·오래된 기록·도움 여부 | 반복 회피, 재확인, 도움 받은 수행과 독립 수행 구분 | 같은 문항을 다시 맞혔다고 독립 표본이나 실력을 부풀리지 않음 |
| TOPIK I 준비·생활 한국어 목표 | 연습에 접근하는 순서와 상황 안내 | 목표 선택 자체를 급수나 능력 증거로 쓰지 않음 |
| 3·5·10분과 소리 사용 가능 여부 | 가능한 시간의 후보, 소리 없이 할 수 있는 읽기 후보 | 학생 과제 체험의 추천 후보를 실제 제한함 |
| 한 단계씩·먼저 혼자 풀기 | 연습 방법과 안내 순서 | 같은 TOPIK 목표에서도 선택한 도움 방식이 실제 바뀜 |
| 글자 크기·설명량·움직임 | 읽기 편한 화면과 안내 길이 | 선택·수정·끄기·삭제 가능. 정답 근거는 숨기지 않음 |
| 사용 뒤 명시적 의견 | 다음에 제안하는 방법 | 사용 확인과 만족 의견을 나눔. 학습 효과 측정으로 표현하지 않음 |

레이싱의 조작 성공, 리듬의 타이밍, 장치·오디오 실패는 한국어 실력과 분리한다. 이미 잘하는 듣기만 반복하는 대신 언어 수행 근거와 현재 가능한 활동을 함께 본다. 현재 교사 앱에서 실제 배정·제출 가능한 활동은 **읽기 3개×각 3문항**이다. 레이싱·리듬의 듣기 추천 표시는 있으나 게임 과제 배정·완료 사건의 운영 WORLD 연결은 아직 없다. 모든 게임에 새 첫 설정을 연결했다고 보고하지 않는다.

## 교사에게 첫 설정부터 돌려주는 도움

실제 정식 가입은 MVP 이후 연결한다. 지금 구현한 첫 이용 설정을 향후 가입 후 선택 단계에 재사용한다. 개인정보를 더 많이 받는 방향보다 필요한 정보를 선택해 바로 도움을 확인하는 방향이다.

| 선택 정보 | 교사가 바로 받는 것 |
|---|---|
| TOPIK I·생활 한국어 | 수업 첫 단계의 목표와 적용 상황 |
| 반 수업·개별 수업 | 수업 진행 안내와 과제 기본 마감 3일·1일 |
| 20·40·60분 수업 | 합계가 수업 시간에 맞는 단계별 시간 |
| 5·15·30분 준비 | 준비된 활동을 바로 쓰거나 반·학생 근거를 더 살피는 준비 안내 |
| 수업을 맡은 경험 | 처음 맡을 때의 진행 순서 안내. 교사 평가·인사 점수로 쓰지 않음 |
| 약점 묶기·개별 과제·자료 설명 도움 | 서로 다른 수업안의 추천 |
| 설명량 | 실제 과제 작성창에 들어가는 학생 안내문 |
| 큰 글자·적은 움직임 | 교사 자신의 사용 환경 |
| 사용 뒤 도움 됨·다른 방법 요청 | 다음 수업안 선택의 변경과 이유 |

각 항목은 선택 사항이다. 답하지 않은 값은 본인 답변으로 저장하지 않고 기본값은 계산에만 사용한다. 학생의 기록으로 교사의 성향을 추정하지 않는다. 기관·담당 반 권한과 교사 개인 설정의 동의는 별개다. 교사는 안내를 검토·고쳐 실제 과제를 보내며 자동으로 전체 반에 배정하지 않는다.

## 공통 기반과 엔진의 책임

| 담당 | 이번에 사용·보강한 것 | 남아 있는 제품별 작업 |
|---|---|---|
| Core | `atlas/personalization.js`의 명시 선택·출처·동의·수정·삭제 계약과 기존 `engine.js`의 후보 선택. SYNK 공통 도메인, 시간·소리·도움 조건, 다른 방법 요청 반영 | 실제 상품별 목표와 후보를 호스트가 제공해야 함 |
| Trail | 기존 문항 출처·시각·도움·반복 근거를 학생 추천에 재사용 | 업무·일상 수행을 교육 문항 사건으로 억지 변환하지 말고 각 제품의 사실 계약을 정의 |
| Strata | TOPIK I 내용 지도를 학습 영역·콘텐츠 연결에 재사용 | 다른 직무·생활 분야의 검수된 내용 지도는 별도 필요 |
| Vellum | 기존 학습 추천 이유를 재사용하고 제품 화면에서 자기보고 근거와 안내를 표현 | 모든 분야의 자유 대화·전문 코칭이 완성된 것은 아님 |
| Loom | 승인 색·실제 펠트·서체를 화면에 적용하고 큰 글자·줄바꿈·정지 표현 검사 | 이번 CSS 변경을 Loom 엔진 자체의 신규 능력으로 주장하지 않음 |
| Temper | 수행 조건·도움·노출을 분리하는 기존 측정 경계 유지 | 교사 준비 시간 감소·학생 학습 향상은 실제 이용자 자료로 따로 검증 |
| Prism | 집단 근거의 분모·조건 검증 기준 유지 | 연령·직업 집단별 효과나 성격을 이번 합성 시험으로 추정하지 않음 |
| Reed | 현재 소리 환경 선택을 후보 필터에 사용. 음성 신호를 새로 수집하지 않음 | 새 음성 콘텐츠의 실제 청취·기기 검증은 해당 제품 작업 |

Atlas는 위 **기존 8개 엔진의 총칭**이다. 공통 첫 설정 모듈은 Core의 어댑터이며 아홉 번째 판단 엔진이나 LLM 실행기가 아니다. 이번에 실제 개선한 엔진은 Core다. 다른 엔진은 필요한 기존 기능과 경계를 재사용했다.

## 같은 사람, 다른 맥락

- 프로필 범위: `personId × productId × contextId × domain`. 같은 사람이 학생·교사·고객으로 이용해도 서로의 답변·사건을 자동 합치지 않는다.
- 공통 플랫폼은 `SYNK`, 브랜드 활동은 `LAB/SHIFT/PATH/PULSE`를 쓴다. 플랫폼 자체를 PATH 사업으로 분류하지 않는다.
- 출처는 자기보고·시각·수정판으로 남긴다. 미응답, 명시적 선택, 관측된 행동, 실제 결과를 구분한다. 나이·성별은 이번 선택 모듈의 입력이 아니다.
- 건너뛰어도 기본 기능을 쓸 수 있다. 끄기·삭제 후 과거 설정이나 피드백이 추천에 되살아나지 않으며 수정 충돌을 검사한다.
- 개인화 삭제는 해당 답변·추천 피드백을 지운다. 별도 목적의 수업·과제·제출 기록까지 같이 삭제하는 동작은 아니다. 화면에서 이 범위를 알린다.
- PULSE는 직접 선택한 제작 조건을 사용할 수 있지만 관객의 개인 행동 관찰·피드백 학습 금지는 유지한다.
- 서버의 인증과 실제 권한이 앞선다. 클라이언트가 `personId`를 적는 것으로 다른 사람의 설정을 읽을 수 있게 만드는 계약이 아니다.

## 제품과 브랜드에 적용하는 범위

플랫폼은 계정과 앱 입구, WORLD는 학습·생활·놀이, 회사 메신저는 회사 업무와 대화의 제품이다. 인증을 함께 쓴다는 이유로 한 제품이나 하나의 학습자 모델로 합치지 않는다. 실제 등록 앱·권한·실행 상태는 플랫폼 카탈로그와 [계정 설계](SYNK_플랫폼_계정과_연결_설계.md)를 따른다. 10-02의 여덟 등록 앱 목록이나 당시 색 배치를 현재 UI의 고정 규칙으로 사용하지 않고, 표현은 [DESIGN](../DESIGN.md)과 제품별 최신 승인 기준에서 찾는다.

플랫폼에서는 서버가 확인한 소속·이용권으로 먼저 표시할 앱을 좁히고, 직접 고른 이용 맥락과 목적이 그 안에서 순서·추천 이유를 바꾼다(같은 날 후속 사용자 요청). 보기·맞춤 설정은 안정적인 SYNK ID별 이 기기 저장이며 로그인 전 설정을 다른 계정에 자동 복사하지 않는다. 교사 앱에서는 수업안·과제 안내, 학생 과제 화면에서는 연습 방법·후보·표현을 바꾼다. 준비 상태의 나머지 앱에 기능이 완성됐다고 표시하지 않는다. 이 문단은 10-02의 기기 저장 범위다. 이후 운영 계정·PC 연결 기록과 제품별 동기화 범위는 [계정별 라이브러리 계약](SYNK_플랫폼_계정과_연결_설계.md)을 따른다. 일반 계정 연결의 완료를 모든 개인화 설정의 기기 간 동기화 완료로 확대하지 않는다.

## 설계 참고와 실제 효과의 구분

- [W3C 고령 이용자의 접근성](https://www.w3.org/WAI/older-users/): 다양한 나이의 이용자에게 읽기·조작의 접근성을 제공한다. 나이만으로 글자 크기나 도움 수준을 단정하는 근거가 아니다.
- [W3C 익숙한 인터페이스 개인화](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o8p04-interface/): 글자·간격 등 조절 가능한 표현과 익숙한 환경으로 돌아가는 선택을 권한다. 기본 화면 자체도 읽을 수 있어야 한다.
- [CAST UDL 3.0](https://udlguidelines.cast.org/): 선택·다양한 제시 방식·도전과 도움 조절을 설계에 참고했다. 사람을 고정된 시각형·청각형으로 분류하지 않는다.
- [EEF 교사 피드백 지침](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/feedback): 다음 학습 행동과 연결되는 피드백을 참고했다. 이 자료의 학교 연령 대상과 성인 한국어 학습의 차이를 유지하며 우리 제품의 효과 증거로 대신하지 않는다.

## 검증과 후속 경계

공통 계약은 `tests/atlas-personalization.test.js`, 교사 모델·HTTP 계약은 `experiences/teacher-world/personalization.test.mjs`, 실제 화면은 `qa-ui.cjs`와 `qa-personalization.cjs`로 검증한다. 플랫폼 검증은 `desktop/README.md`의 현재 절을 따른다. 시험은 격리된 합성 자료를 사용한다.

교사의 실제 준비 시간, 학생의 새 독립 문항 수행, 고객의 과업 완료, 이용자의 설명 이해는 각 제품에서 구체적으로 측정해야 한다. 이번 변경으로 모든 사람에게 효과가 입증됐다고 말하지 않는다. 정식 SSO·기관/학생 연결·동기화·공개 업데이트·패키지·설치는 10-02 당시 후속 항목이었다. 이후 완료된 계정·설치 작업을 다시 승인 대기로 올리지 않고, 제품별 최신 기록에서 실제로 남은 범위를 확인한다.
