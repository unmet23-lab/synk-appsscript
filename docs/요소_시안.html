요소 공방

유호님 08-22 「전부 해줘」 — 앱·교재·PDF 에 설 요소를 세트 단위로 구웠다. 전부 같은 통로(요소굽기.py) · 같은 재료(펠트·실) · 같은 조명이라 한 세계의 물건이다.

자동 생성 · node tools/세트굽기.js --세트 전부 → node tools/요소시안.js · 렌더 93장 · 지면 = Loom L4 · 색 = 디자인_토큰.json

도안은 함수가 아니라 «점 목록»이다 — 기호 여덟(체크·별·하트·집·책·차트·사람·말풍선)은 같은 함수 하나가 낸다. 새 기호를 더하는 값은 점 목록 한 줄이고, 리메시·실땀·조명 규율은 판마다 안 갈린다. 요소가 늘 때마다 굽기 함수가 늘면 그 규율이 먼저 갈린다 — 그게 진짜 비용이다.

01 숫자 — 26장

0~9 낱장은 조합용(어떤 수든 나열로 선다) · 01~12 통짜는 자간에 손맛이 필요한 자리(단락 머리·월).

「/ · % +」 는 진행 표기(3/10 · 85%)를 위한 것이다.

02 넘버쿠키 — 10장

번호의 «요리 플레이팅»판 — 표지·특별면의 한 점용(본문 자동 번호는 CSS counter 몫 그대로).

03 자모 — 31장

우리는 한국어 학원이다 — 자모가 실물이면 그 자체가 교보재다.

획이 가는 홑획(ㅡ·ㅣ)은 복셀 리메시가 뭉갤 수 있어 눈으로 본다(글자공방 함정 ①).

04 기호 — 8장

정답·보상·좋아요와 하단 탭 넷 — 학생이 하루에 가장 여러 번 보는 픽셀이다.

도안 여덟은 함수가 아니라 «점 목록»이라(요소굽기.py 도안들) 새 기호는 한 줄로 는다.

05 요일 — 7장

출석 달력·시간표 — 반복 노출이 많은 자리다.

06 살림 — 6장

도장 = 찍힌다는 «행위»가 곧 보상 · 게이지 고리 = 털실이 12시부터 시계 방향으로 감겨 차오른다.

직선 진행바가 이미 털실이라 원형도 같은 재료여야 학생이 두 번 안 배운다.

07 음식 — 3장

플레이팅 갈래 — 만두(몽골 부즈와 한국 만두가 겹치는 음식) · 김밥(단면) · 붕어빵(겨울 낱말).

08 음식되굽기 — 2장

접시가 평평한 원반 → 그릇(바닥판+림) 으로 올라간 뒤의 1호·2호. 옛 v1 은 그 전 판이다.
