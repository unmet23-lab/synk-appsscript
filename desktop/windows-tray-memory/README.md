# Windows 트레이 메모리 도구

Windows x64 Platform이 트레이에 숨은 지 30초가 지나면 한 번 실행한다. 실행 중인 Platform이 넘긴 프로세스 번호와 생성 시각을 Windows 기록에 대조한다. 실제 부모 앱과 그 앱에 등록된 직접 자식 가운데 같은 설치 파일로 실행된 프로세스만 대상으로 삼는다. 다시 열기나 업데이트가 먼저 오면 예약을 취소한다. 회수가 시작됐으면 메인 루프가 짧게 기다려 회수와 화면 열기 또는 업데이트가 겹치지 않게 한다.

공식 실행 파일은 `desktop/src/native/tray-memory-win-x64.exe`다. 이 판은 Rust 1.99.1, MSVC 도구 모음 14.44.35207, 링커 14.44.35229.0과 Windows SDK 10.0.22621.0에서 빌드했다. C 런타임은 정적으로 연결한다.

Windows PowerShell에서 이 폴더의 `./build.ps1`을 실행하면 앱이 패키지에 넣을 파일을 갱신한다. `./build.ps1 -Verify`는 다시 빌드한 파일의 SHA-256을 패키지 원천과 대조하고 MSVC dumpbin으로 필요한 DLL이 Windows 기본 구성인지 확인한다. 의존성은 Cargo.lock을 따른다. 컴파일러나 링커를 바꿀 때는 새 실행 파일을 다시 검수한다.
