# Windows 트레이 메모리 도구

Windows x64 Platform 창을 트레이로 닫고 30초가 지나면 앱이 Rust 모듈을 불러온다. 모듈은 Windows 기록에서 앱 본체와 직접 자식의 프로세스 번호, 생성 시각, 실행 파일 경로를 대조하고 해당 프로세스의 핸들을 보관한다. Windows에 한 번에 한 프로세스의 상주 페이지 회수를 요청한 뒤 다음 차례를 메인 이벤트 루프에 넘긴다. 회수 대상에는 공유 페이지도 포함된다. 전후 비교에서는 앱이 전용으로 쓰는 물리 RAM을 잰다. 본체는 마지막에 처리한다. 다시 열기, 미디어 사용, 업데이트 또는 종료가 끼어들면 남은 핸들을 놓는다. 실제 창이 보이는지도 매 차례 확인한다.

공식 모듈은 `desktop/src/native/tray-memory-win-x64.node`다. 앱은 로드하기 전에 패키지에 기록된 SHA-256과 파일을 대조한다. Windows의 Electron 실행 파일이 제공하는 Node-API로 모듈을 부른다. 이 판은 Rust 1.99.1, MSVC 도구 모음 14.44.35207, 링커 14.44.35229.0과 Windows SDK 10.0.22621.0에서 빌드했다. C 런타임은 정적으로 연결한다.

Windows PowerShell에서 이 폴더의 `./build.ps1`을 실행하면 모듈과 해시 파일을 갱신한다. `./build.ps1 -Verify`는 재빌드한 모듈의 바이트를 대조하고 MSVC dumpbin으로 필요한 DLL을 검사한다. Node에서 모듈을 실제로 로드한 뒤 일반 Node 프로세스의 메모리 회수가 거절되는지도 확인한다. 의존성은 Cargo.lock을 따른다.
