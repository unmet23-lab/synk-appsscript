# 캐러셀 — 원고 md를 SNS 키트 캐러셀로 굽는 통로

> 유호님 확정 2026-08-27: 개인 계정 축 셋 중 **코너 B(AI 뉴스 + 내 회사 판정)**의 생산 통로로 시작했다.
> 2026-10-01 사용자 확정 「니가 바꿔준게 정말 훨씬 나아. 전에 쓰던 양식 이걸로 전부 다 교체해줄래?」에 따라 판을 [SNS 제작 키트](../docs/디자인/SNS키트/README.md)로 바꿨다. 옛 검은 정사각형 카드(Loom 캐러셀 CSS)는 쓰지 않고 git 기록에만 남는다. 원고 형식과 매일 흐름은 그대로다.

## 매일 흐름 (유호님 5분)

```
① node 캐러셀/수집.js          → 캐러셀/오늘의후보.md (소스 6곳 · 이미 다룬 건 제외)
② AI 가 후보를 읽고 원고 초안   → 캐러셀/원고/NNN_이름.md
③ 유호님이 고르고 판정 한 줄
④ node 캐러셀/굽기.js <원고>    → out/NNN_이름/01_feed34_cover.png … → 인스타
⑤ node 캐러셀/수집.js --다룸 3  → 그 뉴스를 장부에 (다음부터 안 뜬다)
```

**소스 6곳**(08-27 실측 전부 살아 있음): Hacker News(AI 100점+) · TechCrunch AI · VentureBeat AI · OpenAI · Google AI · AI타임스(한국).
· 한 곳이 죽어도 안 멈춘다 — 결과 머리에 「몇 곳 중 몇 곳」이 분모와 함께 찍힌다(ZDNet Korea 는 404 라 뺐다).
· 순위는 **신선도 × 소스 가중치**일 뿐 판정이 아니다 — **고르는 것은 사람**이다.
· 영어 제목은 기계 번역하지 않는다 — 뉘앙스가 곧 판정의 재료다.

## 굽는 법

1. `캐러셀/원고/` 에 `NNN_이름.md` 를 쓴다 (아래 형식).
2. 터미널에서:
   ```
   node 캐러셀/굽기.js 캐러셀/원고/NNN_이름.md
   ```
   원고 전부를 다시 구울 때는 `node 캐러셀/굽기.js --전부`. 링크드인 문서 PDF가 필요하면 `--pdf`.
3. `캐러셀/_빌드/NNN_이름.kit.html`(키트 원고 HTML, 손으로 고치지 않는다)을 거쳐 `캐러셀/out/NNN_이름/`에 나온다.
   - `01_feed34_cover.png …`: 3:4(1080×1440) 장. 인스타·페이스북 캐러셀에 그대로 올린다.
   - `*_4x5.png`: 4:5(1080×1350). 예약 도구·API가 3:4를 못 받을 때.
   - `_시트.png`·`검사.json`: 확인용. 장별 PNG는 git에 넣지 않는다(원고에서 언제든 다시 굽는다).
4. 굽기는 `tools/SNS키트굽기.js`의 검사(장식·유행 장치·형광펜·글자 크기·안전영역·넘침·서체·깨진 그림)를 지난다. 걸리면 종료 코드 1이다. **통과는 규칙을 지켰다는 뜻일 뿐이고, 판정은 사람 눈이 한다** — `_시트.png`를 연다.

## 원고 형식

```md
# 편 제목 (표지 큰 글씨, **한 곳**을 굵게 하면 형광펜)
훅: 표지 아래 한 줄 (선택)
언어: ko | mn | en        ← 없으면 ko (선택)
계정: lab | brief | builds | synk | pulse | path   ← 없으면 LAB으로 시작하는 원고는 lab, 나머지는 builds (선택)
시리즈: 머리줄 왼쪽 이름   ← 없으면 계정 이름 (선택)
끝말: / 끝잔:              ← 끝 장 문구를 바꿀 때 (선택)
마무리: 끄기               ← 자동 끝 장을 뺄 때만 (선택)
---
## 장 제목
본문. 빈 줄이 문단 구분. **굵게** 는 굵은 글자.
---
🔑 판정 제목             ← 🔑 로 시작하면 «내 판정» 장 (칩 + 큰 문장 + 실땀 모서리 상자)
**본문 첫 문단을 통째로 굵게 쓰면 그 문장이 큰 제목이 되고, 판정 제목은 칩으로 내려간다.**
본문
```

- 표지(계정 색 면 + 큰 제목 + 주인공 하나 + 실땀 네 모서리)와 끝 장(계정 색 면 + 로고 + 저장 행동)은 자동으로 붙는다. 안쪽 장은 흰 종이이고, 본문 아래 자리가 남으면 계정의 펠트 스티커(LAB은 몽글 표정) 하나가 그 자리에 맞춰 들어간다.
- 계정별 색·로고·주인공은 키트 README §4를 따른다. yuhobuilds 표지의 얼굴은 실제 인터뷰 사진이다.
- 장 수 권장 4~7 (표지+본문 2~5+판정+마무리).
- 정보형 편은 [개인화 프로그램이 기본값](../docs/마케팅/콘텐츠_제작양식.md#개인화-프로그램이-기본값--업로드도-이-편-먼저)이다. 원고를 쓸 때 맞춤 도구·맞춤 틀을 함께 정하고, 끝 장 문구(`끝말:`·`끝잔:`)로 그 결과와 행동 하나를 보여 준다.

## 원고의 규율 — 공개선 12칸이 진다

정본 = `docs/SHIFT/영상_공개선.md` §2 (유호님 확정 08-27). 캐러셀에서 자주 걸리는 칸:
- ✗⑩ **돈** — 매출·수익·수강료·비용 절감액
- ✗③ 시스템의 «속» — 엔진 배선·코드·콘솔 화면 (원리·방법론 수준은 ○)
- ✗⑥⑨ 학생 데이터·얼굴 — 한 행도
- ✗⑫ 날짜 약속·「곧 나옵니다」 — 기본 시제는 **「짓고 있습니다」**
- ○⑪ 일의 숫자 — 「시험지 102문항」류 팩트는 좋다 (유호 확정 「팩트라 좋아」)

## 콘텐츠의 틀 — 뉴스가 아니라 «판단»을 판다

`뉴스 요약` → `그게 왜 우리 얘기인가` → `🔑 내 회사엔 이렇다` — 마지막 장이 없으면
수백 개 AI 뉴스 계정과 구별되지 않는다. **판정할 자기 회사가 있다는 것이 유일한 차별점이다.**
