# 캐러셀 — AI 뉴스 «내 판정» 굽기 통로

> 유호님 확정 2026-08-27: 개인 계정 축 셋 중 **코너 B(AI 뉴스 + 내 회사 판정)**의 생산 통로.
> 색·글씨체·부품은 전부 **Loom 킷**에서 온다 — 손 CSS·손 색 금지(굽기.js 가 통로에서 조립).

## 굽는 법 (클릭 단위)

1. `캐러셀/원고/` 에 `NNN_이름.md` 를 쓴다 (아래 형식).
2. 터미널에서:
   ```
   node 캐러셀/굽기.js 캐러셀/원고/NNN_이름.md
   ```
3. `캐러셀/out/NNN_이름/01.png … NN.png` 가 나온다 → 그대로 인스타 캐러셀에 올린다.
4. **판정은 사람 눈이 한다** — PNG 는 브랜드렌더린트가 원리상 못 잰다(영상과 같은 지면).

## 원고 형식

```md
# 편 제목 (표지 큰 글씨)
훅: 표지 아래 한 줄 (선택)
마무리: 끄기            ← 자동 마무리 장을 뺄 때만 (선택)
---
## 장 제목
본문. 빈 줄이 문단 구분. **굵게** 는 코랄 강조.
---
🔑 판정 제목             ← 🔑 로 시작하면 «내 판정» 장 (코랄 신호 카드)
본문
```

- 표지·마무리 장은 자동으로 붙는다(로고 = 로고정본 「단색다크」 · 진행점·순번·물표 자동).
- 장 수 권장 4~7 (표지+본문 2~5+판정+마무리).

## 원고의 규율 — 공개선 12칸이 진다

정본 = `docs/SHIFT/영상_공개선.md` §2 (유호님 확정 08-27). 캐러셀에서 자주 걸리는 칸:
- ✗⑩ **돈** — 매출·수익·수강료·비용 절감액
- ✗③ 시스템의 «속» — 엔진 배선·코드·콘솔 화면 (원리·방법론 수준은 ○)
- ✗⑥⑨ 학생 데이터·얼굴 — 한 행도
- ✗⑫ 날짜 약속·「곧 나옵니다」 — 기본 시제는 **「짓고 있습니다」**
- ○⑪ 일의 숫자 — 「시험지 102문항」류 팩트는 좋다 (유호 확정 「팩트라 좋아」)

## 콘텐츠의 틀 — 뉴스가 아니라 «판단»을 판다

`뉴스 요약` → `그게 왜 우리 얘기인가` → `🔑 내 회사엔 이렇다` — 마지막 장이 없으면
수백 개 AI 뉴스 계정과 구별되지 않는다. **판정할 자기 회사가 있다는 것이 유일한 차별점이다.**
