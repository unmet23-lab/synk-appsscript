## 기존 출력 재현

원본과 결과를 확인할 필요가 있을 때만 명시적으로 재현한다. 출력 파일이 생기거나 검사를 통과해도 게시 승인·현재 사실 확인이 되지는 않는다.

```powershell
node 캐러셀/굽기.js 캐러셀/원고/001_새AI가나오면.md --기록재현
```

- `굽기.js`는 원고를 `_빌드/<편>.kit.html`로 만들고 `tools/SNS키트굽기.js`에 넘긴다. 장별 PNG·4:5 사본·확인 시트는 `out/<편>/`에 나온다. 해당 편의 기존 출력은 재생성되므로 별도 수작업 결과가 있으면 먼저 보존한다.
- `--pdf`·`--webp`는 해당 형식을 추가한다. `--전부`는 보관 표시가 없는 원고만 선택하며 현재 보관 묶음만 있으면 종료 코드 2로 끝난다.
- 현 렌더러의 LAB 마스코트는 과거 정본 사본을 사용한다. 새 마스코트 콘텐츠에는 10-14의 **장면과 함께 새로 생성** 기준을 적용해야 하므로 이 렌더를 그대로 새 제작 양식으로 사용하지 않는다. [SNS 키트](../docs/디자인/SNS키트/README.md)와 [AI 운영 원칙](../docs/AI_운영원칙.md)을 따른다.

## 원고 형식과 수집 도구

장 구분은 `---` 단독 줄이다. 머리의 `# 제목`, `훅:`, `언어: ko|mn|en`, `계정: lab|brief|builds|synk|pulse|path`, `시리즈:`, `끝말:`, `끝잔:`, `마무리: 끄기`를 기존 렌더러가 읽는다. `🔑`로 시작하는 장 제목은 판정 장이다. `상태: 보관`은 렌더 제외 표지이며 콘텐츠에 표시하지 않는다.

`수집.js`는 기존 6개 RSS 후보를 모으는 보존 도구다. 8-27 접속 기록은 현재 가동 증거가 아니다. 수집 성공 수·실제 원문·날짜를 확인하며 순위는 자동 발행 결정이 아니다. 인터넷 조사 통로는 현재 [AI 운영 원칙](../docs/AI_운영원칙.md)을 따른다. 삭제된 `docs/SHIFT/영상_공개선.md`와 옛 고정 말투·시제 규칙은 현재 제작 기준으로 복원하지 않는다.
