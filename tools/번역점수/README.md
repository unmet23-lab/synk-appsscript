# 번역 점수 자 — 몽골어 검수 여섯째 겹 후보 (2026-09-07 조사)

> **왜 이 폴더가 있나.** 유호님 지시(09-07 「몽골어 검수 시스템도 더 정교하게 할 방법 조사」)로
> 바깥에서 데려올 자를 둘 재봤다. 하나는 탈락했고 하나는 붙일 값이 있다.
> 🔴 **결론부터**: COMETKiwi 는 못 쓴다 · MetricX 는 «같은 원문 안 비교»로만 쓴다.

## ⓪ 한 줄

지금 검수는 다섯 겹인데 그중 **셋이 큰 모델이라 같은 글에 다른 판정을 낸다.**
그래서 겹을 더 쌓는 대신 **안 흔들리는 자**를 찾았다. MetricX 가 그 후보다.

## ① 자 시험 — 자를 믿기 전에 자를 쟀다

정상 셋과 일부러 부순 넷을 섞어 일곱 쌍을 만들었다(`시험세트.json`).
부순 무늬는 전부 우리가 실제로 겪은 것이다.

### 급소 = 4번 (같은 원문, 낱말 하나만 바꿈)

원문은 넷 다 「울란바토르에 한국어 학원입니다」다.

| 몽골어 | 실제 | COMETKiwi (높을수록 좋음) | MetricX (낮을수록 좋음) |
|---|---|---:|---:|
| …**солонгос** хэлний… | ✅ 맞음 | 0.465 | 9.93 |
| …**англи** хэлний… (영어 학원) | ❌ 뜻이 바뀜 | **0.574** 🔴 | **13.42** ✅ |
| …**сургалтин**… (철자 깨짐) | ❌ | 0.523 🔴 | 9.33 🔴 |
| 오늘 날씨가 좋습니다 | ❌ 딴 말 | 0.436 ✅ | 16.28 ✅ |

🔴 = 틀린 번역을 맞는 것보다 **좋게** 봤다.

🔑 **이 4번이 2026-09-02 에 우리 다섯 겹을 «전부» 지나 통과 도장을 받았던 무늬다**
(шалгалтын→хуримын · 시험장→결혼식장). **MetricX 가 그걸 잡았다.**

## ② 판정 셋

1. 🔴 **COMETKiwi 는 안 쓴다.** 급소에서 뒤집혔고 정상끼리도 0.465~0.804 로 널뛴다.
2. 🟡 **MetricX 의 «절대 점수»도 못 쓴다.** 정상 셋이 3.4·9.9·16.4 라 「몇 점 넘으면 불통과」라는
   문턱이 안 선다 — 2번 정상(16.4)이 4번 부순 것(13.4)보다 나쁘게 나온다.
3. ✅ **MetricX 의 «같은 원문 안 비교»는 선다.** 같은 한국어에 번역 후보 둘을 놓고 어느 쪽이
   나은지 고르는 일에는 정확했다.

### 자를 먼저 의심했고, 자는 멀쩡했다

COMETKiwi 의 낮은 점수가 우리가 잘못 쓴 탓인지 확인했다. 모델 카드가 적어 둔 예시
(`Hello world!</s></s>Bonjour le monde`)를 그대로 넣으니 **0.8639731** 이 나왔고
카드에 적힌 값은 **0.8640** 이다. 소수점 넷째 자리까지 같다.
⇒ 점수가 뒤죽박죽인 것은 우리 잘못이 아니라 **한국어→몽골어 쌍에서 그 자가 안 서기 때문**이다.

## ③ 🔴 부품 판 함정 — 여기서 세 번 헛돌았다

MetricX 저장소의 `requirements.txt` 는 **`transformers==4.30.2`**(2023년)를 요구한다.
그 말을 「너무 옛것이라 안 될 것」으로 미루고 새 판부터 시도해서 세 번 부딪혔다.

| 파이썬 | transformers | 무엇이 걸렸나 |
|---|---|---|
| 3.14 | 5.16 | `__HEAD_MASK_WARNING_MSG` 가 사라짐 → 메웠더니 `MT5Stack.__init__()` 인자 수가 안 맞음 |
| 3.11 | 4.57 | `The size of tensor a (32) must match tensor b (31)` — 디코더 마스크를 직접 줘도 같음 |
| 3.11 | **4.30.2** | ✅ **돈다** |

🔑 **적혀 있는 판을 먼저 써 봤으면 한 번에 끝났다.**

딸린 함정 둘:
- COMETKiwi 원본 `Unbabel/wmt22-cometkiwi-da` 는 **gated**(승인 목록) 라 403 이 난다.
  승인 신청은 약관 동의라 유호님 자리다. ⇒ 같은 무게를 옮긴
  **`vince62s/wmt22-cometkiwi-da-roberta-large`** 를 썼다(승인 불필요 · 원본과 점수 일치 확인).
- `unbabel-comet` 은 **파이썬 3.14 에서 설치가 안 된다**(옛 numpy 가 3.14 용으로 안 빌드된다).
  이 기계의 파이썬 3.11(`py -V:Astral\CPython3.11.15`)로 방을 따로 만들어야 한다.

---

## ④ 다시 돌리는 법

```bash
# 방 만들기 (파이썬 3.11 이어야 한다)
py "-V:Astral\CPython3.11.15" -m venv .venv-comet
.venv-comet/Scripts/python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv-comet/Scripts/python.exe -m pip install "transformers==4.30.2" sentencepiece protobuf unbabel-comet

# MetricX 코드 받기 (pip 로는 안 된다 — 저장소에 setup.py 가 없다)
git clone --depth 1 https://github.com/google-research/metricx

# 돌리기
PYTHONPATH=./metricx PYTHONIOENCODING=utf-8 .venv-comet/Scripts/python.exe \
  tools/번역점수/metricx.py tools/번역점수/시험입력.jsonl 결과.jsonl
```

⚠ `.venv-comet` 과 `.venv-mn` 은 `.gitignore` 에 있다. 폴더만 지우면 흔적이 없다.

## ⑤ 아직 안 한 것 — 붙이지 않았다

이 조사는 **재기만 했고 검문기에 안 붙였다.** 붙이려면 정할 것이 남는다.

- **어떻게 쓸 것인가.** 절대 문턱이 안 서므로 「점수 몇 점」으로는 못 건다.
  후보 = 검문 통과분에 대해 «한 낱말 바꾼 판»을 하나 만들어 같이 재고, 원본이 지면 사람에게 보낸다.
  🔴 이 방식 자체가 아직 검증 안 됐다(자 시험을 한 번 더 지어야 한다).
- **어느 층에 앉힐 것인가.** ⑤(뜻 대조)를 대신할지, 여섯째 겹으로 더할지.
- **모델을 언제 여는가.** 27초가 매번 붙으면 검문이 느려진다. 상주시킬지 그때그때 열지.
