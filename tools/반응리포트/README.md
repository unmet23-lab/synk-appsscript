# 광고 반응 리포트

PULSE가 납품한 광고의 1주 · 4주 반응을 한 장으로 만든다 — ① 플랫폼 숫자(조회 · 평소 대비 · 시청 유지) ② 랜딩 반응(평균적으로 어디까지 내려 봤나 · 머문 시간 · 막힌 신호) ③ 댓글이 묻는 것 → 다음 편에서 바꿀 셋. 납품 전 [업종 반응 브리핑](../업종브리핑/README.md)의 짝이고, 그 도구의 나누기 · 글 검사 · 그리기를 그대로 쓴다. 숫자는 코드가 세고, Claude(API 크레딧)는 댓글 나누기와 글만 한다(글에는 `{{지표}}`만, 검사로 막는다).

- 설계 · Fable 설계 검토 반영: [반응리포트_설계.md](../../docs/마케팅/PULSE_반응브리핑/반응리포트_설계.md)
- 첫 시험판(LAB 쇼츠 세 편, 1주): [아티팩트](https://claude.ai/artifact/GXFEh3AxH8w3BkjqBE1YhP)

## 쓰는 법

```
node tools/반응리포트/리포트.js 돌리기 <캠페인> [--시점 1주|4주] [--날짜 YYYY-MM-DD] [--다시 <단계>] [--건너뛰기 댓글,랜딩] [--서버안읽음]
node tools/반응리포트/리포트.js 검사 <캠페인> [--시점 …] [--날짜 …]     네트워크 없이 다시 세어 지표 · 글 · 페이지 대조
node tools/반응리포트/리포트.js 랜딩받기 <캠페인>|--전부                Clarity 지난 24시간 숫자를 하루 장부에(23시간 안에 받았으면 건너뜀, 받을 때마다 쪽에 측정 코드가 있는지 본다)
node tools/반응리포트/리포트.js 칸지도 <캠페인>                        랜딩 칸 위치를 휴대폰 · PC 폭에서 다시 잰다(Playwright, 14일 지나면 저절로)
node --test tests/반응리포트.test.js
```

단계는 플랫폼 → 댓글 → 랜딩 → 나누기 → 집계 → 글 → 그리기. 결과는 `<공용 작업본>/.tmp/반응리포트/<캠페인>/<시점>-<기준일>/`(git 밖)에 단계마다 JSON으로 남고, 한 단계가 새로 돌면 그 뒤는 모두 다시 돈다. 마지막에 `리포트.html`(혼자 여는 판) · `리포트_조각.html`(아티팩트로 올리는 판).

| 단계 | 쓰는 것 | 막히면 |
|---|---|---|
| 플랫폼 | 게시 성과 장부(`docs/_ops/게시성과.jsonl`, 읽기만) → 회사 서버 하루 숫자(`tools/lib/게시성과읽기.cjs`, 읽기 전용 SSH) → 손 입력 → 유튜브 `videos.list` | 그 게시물 줄에 까닭 |
| 댓글 | 유튜브 `commentThreads`(수요 스캔 `API부르개`, 댓글 0인 편은 안 부름). 인스타 · 페이스북 · 틱톡은 장부의 댓글 수만 | 「못 읽음」 |
| 랜딩 | Clarity 하루 장부(`.tmp/반응리포트/_clarity/<프로젝트>.jsonl`) + 칸 지도 | 「측정 전」 — 칸 지도만 보인다 |
| 나누기 · 글 | Claude Opus 5.5(나누기 low · 글 high), 무료 크레딧 키 | 낱말 규칙 · 숫자만 담은 페이지 |

## 캠페인 설정 — 고객사 것은 git 밖

`.tmp/반응리포트/<캠페인>/설정.json`을 먼저 읽고, 없으면 `설정/<캠페인>.json`(SYNK 자기 캠페인만 — 공개 저장소). 고객사 이름 · 게시 주소 · 랜딩 주소는 저장소에 넣지 않는다.

`이름` · `제목` · `업종` · `받는사람` · `납품일` · `시험판?` · `광고[{키(한글 · 영문만 — 지표 이름에 든다), 이름, 주소[]}]` · `랜딩{주소, 도구: "clarity", 프로젝트, 칸이름{section id: 짧은 이름}, 캠페인낱말[]?}` · `주제{댓글고유[{이름, 설명, 낱말[]}]}` · `제안관점`.

손 입력(`<실행 폴더>/플랫폼_손입력.json`, 고객 광고 계정 · 스튜디오에서 읽은 숫자): `[{주소, 시점: "1주"|"4주", 조회, 도달, 좋아요, 댓글, 공유, 저장, 앞3초유지, 본비율, 평균시청, 평균조회율, 완주율, 나이일, 게시때, 평소중앙?, 평소편수?, 평소정의: "같은 나이"?, 출처: "메타 광고 관리자" 따위, 읽은날}]`. 평소는 준 사람이 같은 나이끼리 견준 값이라고 밝힌 것만 쓴다.

## 숫자의 뜻

- 평소 대비 = 이 편 조회 ÷ 같은 계정 · 같은 형식에서 이 편 앞에 올린 최근 12편이 같은 나이(7일째 · 28일째, ±13시간)에 낸 조회의 중앙값(이 편 뺌, 4편부터). 같은 계수기끼리만 견준다(장부 숫자는 장부끼리, 서버 하루 숫자는 서버끼리). 장부의 `multiple`(그 관측 때 최근 12편의 그때까지 조회)은 어린 편이 섞여 부풀어 쓰지 않는다.
- 시청 유지는 칸마다 그 칸이 있는 가장 늦은 판정에서 고르고 출처(72시간 판정 · 서버 어림값 · 게시 뒤 3일 창 · 화면에서 N일째)를 붙인다.
- 랜딩 평균 스크롤은 평균이라 「대부분이 여기서 멈췄다」가 아니다 — 글 검사가 「멈췄다」를 막는다. 날마다 센 사람 수는 더하지 않는다(같은 사람이 겹친다).
- 바꿀 것은 그 갈래의 약한 신호(평소보다 낮음 · 계정 안 하위 25% · 본 비율 · 앞 3초 유지 50% 아래 · 완주율 30% 아래 · 평균 스크롤 50% 아래 · 막힌 신호 5% 넘음 · 헷갈림 · 불신 댓글 · 댓글 0)가 근거에 있어야 하고, 영상 앞부분 · 길이를 말하면 시청 유지 지표가 있어야 한다. 지킬 것은 센 신호. 문턱은 `글.js`의 `문턱`.

## Clarity 켜기(처음 한 번)

SYNK 프로젝트: `z67ez8kfp3`(이름 SYNK · synk.im · B2B 서비스, unmet23@gmail.com 구글 로그인 — 10-31 유호님 가입 · Claude가 ego에서 만듦). 아래 1~4는 10-31에 끝났다(공개 synk-policy `4841c3d`, 토큰 이름 `synk-report`, 예약 「SYNK 반응 리포트 랜딩 받기」 — 기록 `output/반응리포트/예약실행.log`). 다시 등록하려면 운영 사본에서 `pwsh -NoProfile -File tools/반응리포트/예약/install-task.ps1 -TaskName "SYNK 반응 리포트 랜딩 받기"`(끄기는 `-Remove`, 자동 모드 판정기가 예약 등록을 막으니 유호님 말이 있어야 한다). 마스킹은 기본 「균형」에 질문창 가림 — 까닭과 실측은 [설계](../../docs/마케팅/PULSE_반응브리핑/반응리포트_설계.md).

1. 유호님: [clarity.microsoft.com](https://clarity.microsoft.com)에 가입하고 프로젝트를 만든다(주소 https://synk.im). 설정 › Data Export › 새 토큰을 만들어 복사한다. ego의 구글 계정 목록에 그 계정이 있으면 프로젝트 만들기는 Claude가 해도 된다(비밀번호 없이 계정 고르기로 들어간다).
2. Claude: 토큰을 `~/SYNK_보안/clarity_<프로젝트 id>.txt`에 둔다(출력 · 기록하지 않음). 캠페인 설정 `랜딩.프로젝트`에 id를 적는다.
3. Claude: 측정 코드를 synk.im/pulse 쪽에만 넣고, 개인정보처리방침의 「외부 방문자 분석 서비스를 설치하지 않았습니다」를 Clarity(Microsoft · 국외 처리 · 쿠키 · 세션 재생) 안내로 바꿔 같은 `node tools/공개.js` 회차로 올린다(화면 검수 규칙 그대로). 방문자가 글을 적는 칸은 `data-clarity-mask="True"`로 가리고 나가는 내용을 풀어 재 본다.
4. Claude: 하루 받기(`랜딩받기 --전부`)를 Windows 예약 작업 하나로 켜고 [관문 · 자동화 한 장](../../docs/_ops/관문_자동화.md)에 적는다. 첫 주에 실제 응답으로 칸 이름 · 봇 세션 처리를 확인해 시험 견본을 갈아 끼운다.

고객 랜딩은 고객이 자기 Clarity 프로젝트에 우리를 관리자로 넣거나 토큰을 주고, 측정 고지는 고객 사이트 방침 몫이다.

## 안전

- 남의 댓글 원문 · Clarity 원자료는 실행 폴더(git 밖)에만. 페이지에는 뜻 옮김과 집계 숫자만.
- 아티팩트는 비공개지만 링크를 받은 사람은 열 수 있다 — 고객 이름 · 광고 이름 · 랜딩 주소가 들어간다.
- 남에게 보내기 · 게시는 도구가 하지 않는다. 실제 고객에게 처음 보내는 페이지는 화면 검수(아르곤 → Fable 조건부)를 한 번 받는다.
