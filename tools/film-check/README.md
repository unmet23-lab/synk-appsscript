# 실사 영상 제작 체크

[완성 HTML 열기](dist/SYNK_실사영상_제작체크.html). HTML을 Chrome/Edge 등 브라우저에서 열면 설치나 로그인 없이 쓴다. 빌드된 파일에는 코드·폰트·이미지가 모두 들어 있다.

## 사용하는 순서

1. `20초 제품 광고 예시 보기`로 구조를 보거나 작품 기획부터 채운다. 예시는 실제 생성·검수를 하지 않은 가상 계획이다.
2. 샷별로 실제 소스/인물·제품/스타일 참조, 시작·행동·끝, 빛·카메라·소리를 적는다.
3. 선택한 생성 화면의 현재 견적과 예정 횟수를 기록한다. 힉스필드 크레딧만 합산한다. 다른 서비스의 크레딧·원·달러를 넣지 않는다.
4. 샷별 지시문을 GPT·Claude에 복사하고 참조 원본은 따로 첨부한다.
5. `영상 보며 검수`에서 기준 이미지와 결과 영상을 로컬로 열어 대조한다. 정상 속도로 전체 구간을 보고 소리를 듣는다. 해당 없음은 이유가 필요하다.
6. 실제 차감 총액, 채택 파일과 구간, 검수자·일시를 기록한다. 최종 편집본도 따로 재생·검수한다.
7. `작업 JSON 저장`으로 프로젝트를 보관한다. 다운로드를 지원하지 않는 앱 내 브라우저에서는 `작업 JSON 복사`로 보관하거나 HTML 파일을 Chrome/Edge에서 연다. `작업 JSON 가져오기`로 이어 하거나 기존 PULSE 제작 전달 JSON을 불러온다. `검수표 내려받기`는 검토·전달용 Markdown이다.

## 저장과 판정의 범위

- 자동 저장은 브라우저별 로컬 저장소의 마지막 프로젝트 한 개다. 여러 프로젝트는 JSON으로 따로 보관한다. 파일 위치/브라우저/접속 주소가 달라지면 저장소가 달라질 수 있다.
- 사진과 영상은 이 브라우저에서만 열린다. 업로드·유료 생성·API 요청을 하지 않는다. JSON에는 원본 미디어가 포함되지 않으므로 다시 열 때 파일을 재선택한다.
- 해상도와 재생 길이를 표시한다. FPS·중복 프레임·AI 사용 여부·연기·물리를 자동 판정하지 않는다.
- 완료 표시는 계획과 사람의 검수 기록이 채워졌다는 뜻이다. 실제 품질·인물 동일성·공개 게시를 인증하지 않는다.
- 계획/참조/생성 조건 변경은 해당 검수를 초기화한다. 결과 파일 변경은 영상 검수를, 샷 순서·삭제는 연결 검수를 다시 요구한다. 이전 관찰 메모는 남긴다. 예산·차감 기록만 변경하면 검수는 유지한다.
- 현재 클라이언트 발주서는 바꾸지 않는다. 기존 전달 JSON은 읽기만 하고 이 도구 형식으로 저장한다.

## 제작 기준과 관리

[실사 시네마틱 제작 원문](../../docs/마케팅/제작양식/실사_시네마틱_영상_제작과_비용절감.md)은 이 도구의 계획·검수 배경이다. 현재 광고·홍보 제작은 [AI 광고영상 제작 규칙](../../docs/마케팅/제작양식/AI광고영상_제작규칙.md)과 [만족 사례 장부](../../docs/마케팅/제작양식/만족사례_장부.md)를 먼저 따른다. 도구의 예시·옛 구독 비교·크레딧 입력칸을 현행 모델 선택이나 유료 실행 승인으로 사용하지 않는다.

```powershell
node tools/film-check/build.cjs
node --test tools/film-check/core.test.cjs
node tools/film-check/preview.cjs
```

미리보기는 `http://127.0.0.1:4209/`이며 이 컴퓨터에서만 열린다. 실제 소스는 `template.html`, `style.css`, `app.js`, `core.js`다. `dist`는 빌드 출력이므로 소스를 수정한 뒤 다시 빌드한다. 검사 기록은 [QA.md](QA.md)에 남긴다.
