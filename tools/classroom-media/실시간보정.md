# 수업 영상·음성 실시간 보정

공간·카메라·라이브·복습을 함께 보는 현재 문서는 [공간과 촬영 통합 설계](../../docs/오프라인_공간설계/평면도_20260929/공간과_촬영_통합설계.md)다. 이 파일은 필터 설정과 시험 출발값의 상세 원문으로 유지한다.

2026-09-29 수정. 사용자 승인에 따라 **교재·전자판서 디지털 원본을 메인으로, 교사 상반신을 작은 사각형 창으로 합성**한다. OBS 무료 기본 필터로 교사 영상과 음성을 보정하고 라이브·녹화·복습에 함께 적용하는 설치안이다. **실제 교실·카메라·마이크가 아직 없어 아래 값은 조정 출발점이며, 실장비에 적용하거나 보정 결과를 검증한 상태는 아니다.** 추가 플러그인 구독이나 외장 그래픽카드 구매를 전제로 하지 않는다.

## 적용 경로

```text
PC 교재·판서 앱 ─ 창 캡처(글씨·필기 원본) ─┐
교사 카메라 ─ 노출·초점·색보정 ─────────┼─ OBS 합성 ─ YouTube 라이브 / 로컬 녹화
교사 마이크 ─ 입력·필요한 음성 필터 ────┤
교재 듣기 음원 ─ 중복 없는 별도 입력 ────┘
```

교실 TV·전자칠판에는 PC 교재·판서 원본을 보여 주고 온라인으로는 OBS 합성 화면을 보낸다. TV+PC, 전자칠판의 PC 터치 입력, 자체 OS/HDMI OUT 캡처는 [교실 세팅의 연결 분기](교실세팅.md#교재전자판서-원본을-받는-세-가지-연결)를 따른다. 전자칠판 자체 필기·주석이 PC 창 캡처에 들어온다고 가정하지 않는다. 교실 화면이나 OBS 미리보기를 다시 잡는 반복 캡처도 피한다.

같은 OBS 최종 화면과 같은 오디오 트랙을 표준 송출·녹화에 사용한다. YouTube는 보정된 방송을 받아 아카이브하므로 복습 영상도 그 보정 결과를 담는다. 녹화 전용 수업에서도 보정된 파일이 만들어지고 기존 완료 이벤트 업로더가 그 파일을 올린다. YouTube 재인코딩이 있으므로 로컬 파일과 음질·화질이 비트 단위로 동일하다는 뜻은 아니다. [OBS 처리 구조](https://docs.obsproject.com/backend-design)

수업이 끝날 때까지 기다렸다가 보정하는 단계가 없어지는 것이다. 필터·카메라·인코딩의 처리 시간과 YouTube 라이브 전송 지연은 여전히 있다. 카메라를 YouTube 앱에서 직접 송출하면 PC의 OBS 필터를 거치지 않는다.

## 세 장면과 소스 구분

| OBS 장면 | 화면 구성 | 보정·음성 원칙 |
|---|---|---|
| 기본 — 교재+교사 | 디지털 교재·판서를 크게, 교사 상반신은 작은 사각형 창 | 교재의 빈 구역 또는 별도 여백에 교사 창을 배치. 문제·정답·필기·자막을 가리지 않음 |
| 발음 — 교사 크게 | 얼굴과 입 모양을 확인할 수 있게 교사 영상을 크게 | 같은 카메라 소스·보정을 사용하고 원본 해상도·초점 확인. 확대가 세부 정보를 새로 만들지는 않음 |
| 판서 전체 | 디지털 교재·판서를 전체 화면으로, 교사 창은 숨김 | 교사 음성과 교재 음원은 유지. 일반 칠판을 카메라로 찍는 장면과 구분 |

교사 카메라·교재·오디오를 따로 만들고 장면 간에는 기존 소스를 참조해 재사용한다. **카메라용 색보정/LUT는 교사 카메라 소스에만 둔다.** 교재 소스나 최종 합성 장면 전체에 피부색용 필터를 걸어 흰 배경·색상 구분·필기 선을 바꾸지 않는다. OBS는 소스를 장면 안에서 배치하고 소스 또는 장면에 필터를 적용할 수 있으므로 적용 대상을 구분한다. [OBS 소스 안내](https://obsproject.com/kb/sources-guide), [OBS 화면·필터 안내](https://obsproject.com/kb/obs-studio-overview)

교사가 장면 선택 또는 설정한 단축키로 전환한다. 자동 발음 감지·장면 전환 기능은 현재 구현하지 않았다. 장면 전환마다 마이크를 새로 켜는 운영은 피하고, 세 장면에서 같은 입력이 한 번씩만 출력되는지 확인한다.

## 영상: 교사 피부색과 디지털 글씨를 따로 맞추기

1. **교사 조명과 카메라부터 조정한다.** 평상시 교실 조명에서 설명할 자리의 얼굴·흰 종이를 본다. 역광을 줄이고 카메라 지원 범위에서 화이트밸런스·노출·얼굴 초점을 맞춘다. 가능하면 안정된 조명 아래 값을 고정한다. 시간대별 햇빛이 크게 달라지면 커튼/조명 또는 주간·야간 설정을 따로 맞춘다. 카메라 높이와 거리는 교사 상반신 구도로 정하며 옛 칠판2~3m·천장 고정안을 기본으로 복제하지 않는다.
2. **OBS → 교사 카메라 소스 우클릭 → 필터 → 효과 필터 → 색 보정**을 추가한다. 감마·대비·밝기·채도·색조는 중립값에서 시작해 필요한 항목만 조금 조절한다. 현장을 보지 않고 고정 숫자를 모든 교실에 복제하지 않는다. 피부·흰 셔츠가 날아가거나 얼굴 그림자가 뭉개지지 않도록 한다. [색 보정 필터](https://obsproject.com/kb/color-correction-filter)
3. 색감 조정표인 **LUT**도 실시간 적용할 수 있다. 해당 카메라·조명·SDR 입력에 맞춰 만든 LUT만 선택적으로 쓴다. 영화용 룩이나 Log 변환 LUT를 일반 웹캠 화면에 무조건 적용하지 않는다. 처음에는 LUT 없이 기본 보정부터 확인한다. [LUT 필터](https://obsproject.com/kb/apply-lut-filter)
4. 배경 흐림·미백·과한 선명도·자동 줌은 기본으로 끈다. 작은 창과 발음용 큰 창 모두에서 피부색·입 모양·손동작이 자연스럽게 보이는지 확인한다. 교사가 화면 쪽으로 돌아 필기한 뒤 설명 자리로 돌아오는 동선에서도 얼굴이 화면 밖으로 나가지 않아야 한다.
5. **교재는 원본 앱에서 글씨·펜 굵기·색 대비·확대율을 조정한다.** 창 캡처의 필기·커서·페이지 전환이 실제 반영되는지 확인한다. 교재를 찌그러뜨려 맞추지 말고 종횡비를 유지하며, 작은 글씨는 판서 전체 장면 또는 앱 확대를 사용한다. 디지털 원본이라도 축소·압축 뒤 학생 휴대전화에서 반드시 읽히는 것은 아니다. [OBS 창 캡처](https://obsproject.com/kb/window-capture-sources)

초점이 틀렸거나 너무 어둡게 찍힌 교사 영상을 색 필터만으로 복구할 수는 없다. 일반 칠판 촬영을 별도 대안으로 사용한다면 그때는 반사·판서 초점·노출을 다시 맞춘다. 이미 하얗게 날아간 글씨를 필터만으로 복구할 수 없으며, 디지털 창 캡처와 같은 품질을 보장하지 않는다.

## 음성: 발음을 보존하는 필터 순서

**OBS 오디오 믹서 → 교사용 마이크 → 필터**에서 아래 순서로 검토한다. 교재 듣기 음원에는 말소리용 억제 필터를 일괄 적용하지 않는다.

| 순서 | 필터/설정 | 현장 조정 출발점 |
|---|---|---|
| 입력 | 마이크 위치·수신기 입력 음량 | 옷 쓸림을 피하고 평소 말하기/큰 발화 모두 녹음. 입력 단계에서 찌그러지지 않게 조정 |
| 1 | 소음 억제 — RNNoise | 지속적인 팬 소음 등이 있을 때만 켜서 비교. RNNoise에는 Speex의 억제 dB 슬라이더를 적용하지 않음 |
| 2 | 3밴드 EQ | 처음 저·중·고음 모두 0dB. 저음이 과하게 울릴 때만 저음 소폭 감소. 발음이 약하다고 고음을 일괄 증폭하지 않음 |
| 3 | 컴프레서 | 비율 3:1, 임계값 −18dB, 어택 6ms, 릴리스 100ms, 출력 게인 0dB로 시험. 목소리 크기에 맞춰 조정 |
| 선택 | 익스팬더 | 말하지 않을 때 잔여 잡음이 거슬리는 경우만. 임계값을 작은 말소리·말끝 아래로 맞춤. 처음에는 끔 |
| 마지막 | 리미터 | 임계값 −3dB, 릴리스 60ms로 시험. 뒤에 추가 증폭 필터를 넣지 않음 |

위 숫자는 이 설치안의 **시험용 제안**이며 OBS가 모든 수업에 권장하는 표준값이 아니다. 최종 말소리 피크는 대략 −12~−6dBFS 범위에서 먼저 시험하고, 실제 학생 폰에서 작지 않은지 듣는다. 컴프레서 이후 너무 작아지면 출력 게인을 조금 보완하되 리미터가 계속 눌리는 상태로 만들지 않는다. 교재 음원과 합쳐진 최종 출력도 별도로 확인한다. 소스 리미터 하나가 모든 소스를 합친 출력의 과부하를 방지하는 것은 아니다.

공식 근거: [RNNoise·Speex 소음 억제](https://obsproject.com/kb/noise-suppression-filter), [컴프레서](https://obsproject.com/kb/compressor-filter), [익스팬더](https://obsproject.com/kb/expander-filter), [마지막에 두는 리미터](https://obsproject.com/kb/limiter-filter).

- 마이크 자체의 강한 노이즈 캔슬링과 OBS 억제를 동시에 켜는 방식부터 시작하지 않는다. 한 군데씩 켜고 끄며 발음을 비교한다.
- 한국어 수업은 작은 자음·받침·호흡·문장 끝이 남는지 확인한다. 강한 노이즈 게이트로 조용한 말이 통째로 잘리지 않게 한다. 과한 억제로 물속 같은 소리가 나면 억제를 줄이거나 끈다.
- 소음 억제는 가벼운 배경 잡음에 적합하다. 교실의 큰 울림, 주변 대화, 옷 쓸림, 수신 끊김이나 입력에서 이미 깨진 음성을 모두 복구하는 도구가 아니다. 필요하면 마이크 위치·커튼 등 현장 조건을 먼저 개선한다.
- 무선 수신기의 스테레오 모드에서 교사 음성이 한쪽에만 들어가면 출력 채널 설정을 바로잡는다. 학생 폰·이어폰 양쪽에서 들리는지 확인한다.
- 교사용 핀마이크를 사용하는 동안 카메라·노트북 내장 마이크가 같은 목소리를 중복으로 받지 않도록 해당 입력을 음소거한다. 교재 소리는 앱 캡처 또는 캡처 장치 중 한 경로로 받고 데스크톱 오디오에서 다시 수집하지 않는다. 화면을 바꿔도 교사 마이크·교재 소리는 각각 한 번만 출력되어야 한다.
- 현장 TV 스피커의 듣기 음원이 핀마이크로 다시 들어가 메아리가 생기는지 확인한다. 스피커와 마이크 위치·음량을 먼저 조정하며 억제 필터가 이를 모두 해결한다고 보지 않는다. 교사 마이크를 현장 스피커로 되돌려 모니터링하지 않는다. 온라인 재생 확인은 송출 PC의 스피커 대신 별도 기기·이어폰으로 한다.

## 다음 수업에도 자동으로 유지하기

- **장면 모음**: 교실별 교재 캡처·교사 카메라·오디오 소스, 세 장면의 배치와 필터를 저장한다. 예: `SYNK 교실 1`. 카메라 필터와 교재 레이어가 분리됐는지도 기록한다.
- **프로필**: 교실별 송출 키·해상도·비트레이트·녹화 출력 설정을 저장한다. 장면 모음과 별도로 관리한다.
- 설치 완료 시 둘 다 내보내 백업한다. 카메라 제조사 앱/장치에 저장한 노출·화이트밸런스는 OBS 백업만으로 복원된다고 가정하지 않고 따로 기록한다. LUT를 사용한다면 파일도 함께 보관한다.
- PC 재부팅·USB 재연결 후 같은 교실의 장면 모음·프로필과 실제 장치가 선택되는지 확인한다. 이름만 같고 다른 마이크가 연결되지 않게 한다. 교재 앱 재실행·외부 화면 재연결 후 캡처 대상, 화면 배율, 터치 입력 위치도 확인한다. 장면 전환 단축키를 쓰면 중복 지정과 실제 동작을 함께 확인한다.

[장면 모음 공식 안내](https://obsproject.com/kb/scene-collections), [프로필 공식 안내](https://obsproject.com/kb/profiles).

같은 카메라·마이크 모델의 필터 순서는 다른 교실에 복제할 수 있다. 밝기·색온도·목소리·소음은 교실마다 달라 수치는 다시 맞춘다. 선생님이 수업마다 필터를 새로 조작하는 운영은 피한다.

## 적용 확인과 백업 구분

1. 5분 시험: 일반 발화, 작은 말소리·받침, 큰 발화, 화면 쪽 필기 후 설명 자리로 돌아오기, 박수, 팬 켜짐/꺼짐을 녹화한다. 같은 음량으로 보정 전후를 비교한다. 교재의 쓰기·지우기·페이지 전환과 세 장면 전환도 넣고, 교사 창이 내용을 가리지 않는지 확인한다.
2. 입력 하나씩 필터를 켜고 끄며 효과를 확인한다. 박수로 영상·소리 시간차를 확인하고 OBS 동기화 오프셋을 맞춘다. 모든 교실에 같은 지연값을 넣지 않는다.
3. 실제 수업 길이로 교재 앱·원본 캡처·교사 합성을 함께 실행하며 연속 송출·녹화해 OBS 인코딩/렌더링 지연, 팬 소음, 발열, 입 모양과 소리의 어긋남을 확인한다. 학생 휴대전화에서 세 장면의 글씨·필기·발음·오디오 중복 여부를 확인하고 YouTube 라이브와 종료 후 아카이브도 재생한다.
4. **표준 OBS 로컬 녹화도 보정 적용본**이다. 무보정 원본이 추가로 필요하면 별도 원본 캡처 경로를 설계한다. 같은 필터 소스를 녹화 트랙 하나 더 선택하는 것만으로 무보정 음성이 생기지 않는다. 마이크 자체 내부 녹음이 있는 모델의 백업 파일도 영상과 자동 합쳐지지 않는다.

현재 완료된 것은 합성·보정 설정 방법과 시험 기준 정리다. 교실별 캡처 경로·장면 배치·최종 수치·LUT·실제 OBS 저장 설정과 시청·청취 검증은 장비 설치 후 수행한다.
