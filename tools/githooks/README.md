# 과거 Git 훅 구현

2026-09-09 운영 변경으로 자동 사용하지 않는 소스다. 이 폴더에 파일이 있다는 사실은 Git에 훅이 등록됐다는 뜻이 아니다. 현재 작업 지침은 [AI 운영 원칙](../../docs/AI_운영원칙.md)을 따른다.

- `pre-commit`: 과거 커밋 전 검사 호출과 소요 시간 기록.
- `commit-msg`: 과거 커밋 메시지 제어문자 검사 호출.
- `prepare-commit-msg`: 과거 세션 식별 트레일러 기록.

기존 구현·사고 이력을 대조할 수 있도록 경로와 코드를 보관했다. 이 소스와 관련된 실제 검사 함수는 `tools/`에도 있으므로, 훅을 해제했다는 이유로 검사 도구 전체를 폐기하지 않는다. 이 세 스크립트의 주석에 적힌 당시 절차를 현재의 필수 작업 순서로 읽지 않는다.

없어진 `tools/install-githooks.js`나 `tests/커밋트레일러.test.js`를 자동 복원하지 않는다. `.git/hooks/`에 복사하거나 `core.hooksPath`를 설정하지 않는다. 세션 최신 상태의 읽기 전용 알림은 별도의 `tools/session-freshness.js`이며 이 폴더를 실행하지 않는다.
