# SYNK 공모전 찾기

지금 접수할 수 있는 공모전과 대회를 찾는다. 찾은 공고는 SYNK가 영상과 기획서를 내는 데 쓴다. 웹 검색과 웹 페이지 읽기만 쓰고, 파일을 만들거나 명령을 돌리지 않는다. 로그인, 회원가입, 신청서 제출은 하지 않는다.

## 찾을 곳

- 모음 사이트: 콘테스트코리아, 위비티, 링커리어, 씽굿, 씽유, 올콘, 대티즌, 캠퍼스픽, 온오프믹스.
- 국내외 AI 영상 · 광고 · 숏폼 · 숏드라마 · 웹드라마 · 뮤직비디오 · 애니메이션 공모와 온라인으로 낼 수 있는 AI 영화제.
- 창업 아이디어 공모, 한국어교육 · 외국인 정착 관련 공모.
- 주최사 공식 사이트, 지역 문화재단과 도청 · 시청 게시판, 해외 공모 사이트에서도 따로 찾는다. 모음 사이트에 늦게 올라오는 공고가 많다.

AI로 만든 영상을 낼 수 있는 공모를 가장 먼저 찾는다.

## 거르는 기준

- 마감이 지난 공고와 원문에서 생성형 AI를 금지한 영상 공모는 넣지 않는다.
- 아래 「이미 아는 공고」에 있는 공고는 다시 넣지 않는다. 같은 공고가 이름만 다르게 올라온 경우도 넣지 않는다.
- 공고번호, 주최사, 회차, 공식 주소가 같으면 한 공고다. 전체 대회와 특정 부문의 신청 페이지는 구분한다. 여러 공고를 소개한 기사 주소로 서로 다른 공고를 합치지 않는다.

## 적는 것

- 주최사 원문에서 생성형 AI 허용, 조건부 허용, 금지를 확인한다. 명시한 조항이 없으면 `unconfirmed`로 둔다. 주최사가 수상작을 AI로 만드는 것과 응모자의 AI 사용을 구분한다.
- 마감 날짜와 원문에 적힌 시각을 확인한다. 시각이 없으면 23:59를 지어 넣지 않는다. 단계별 마감이 있으면 같은 부문의 최종 접수 마감을 적는다.
- 영상, 기획서, 동의서, AI 사용 공개 서류처럼 필수 제출물을 원문에 있는 대로 적는다.
- AI 조항, 마감, 제출물 세 칸에는 각각 그 내용을 직접 보여 주는 공식 주소와 원문 그대로의 짧은 인용(5자 이상)을 붙인다. 모음 사이트의 설명은 `discoveryUrl`에만 적는다. 요강이 PDF · HWP · 펼침 메뉴 안에 있으면 그 원문까지 읽는다. 원문을 못 열면 그 칸을 비우고 `unavailable`에 이유를 적는다.
- 저작권이나 권리를 주최사에 넘기는 조항이 있으면 `rights`에 짧게 적는다.

## 답 꼴

설명 없이 아래 꼴의 JSON 한 개만 답한다. 찾은 공고가 없으면 `items`를 빈 배열로 둔다. 공고는 30개까지 적는다.

```json
{
  "checkedAt": "확인을 마친 때(ISO 8601, +09:00)",
  "reports": ["찾아본 출처와 검색어를 한 줄씩"],
  "unavailable": ["열지 못한 출처와 까닭"],
  "items": [
    {
      "title": "공고명",
      "organizer": "주최사",
      "edition": "연도나 회차",
      "noticeId": "공고번호, 없으면 빈 문자열",
      "video": true,
      "discoveryUrl": "처음 찾은 주소",
      "officialUrl": "주최사 공식 공고 주소",
      "ai": { "status": "allowed | conditional | prohibited | unconfirmed", "url": "", "quote": "" },
      "deadline": { "date": "YYYY-MM-DD", "kst": "YYYY-MM-DDTHH:mm+09:00 또는 빈 문자열", "url": "", "quote": "" },
      "deliverables": { "items": ["제출물"], "url": "", "quote": "" },
      "rights": "권리 양도 조항 요약, 없으면 빈 문자열"
    }
  ]
}
```
