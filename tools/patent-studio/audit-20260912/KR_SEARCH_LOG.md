# 국내 검색 접근·문헌 식별 확인 로그

2026-09-12 · 읽기 전용 후속 확인 · KIPRIS 직접 검색과 Google Patents 원문 표시를 구분

## 결론

**KIPRIS 공식 검색 UI에서 결과 목록·상세 화면·심사서류까지 읽는 단계는 이번 실행에서 완료하지 못했다.** 사이트의 로그인 요구나 접근 차단을 확인한 것이 아니라, 먼저 브라우저 도구의 새 탭 생성이 실패했다. 이를 국내 검색 0건 또는 관련 특허 없음으로 해석하지 않는다.

대신 공식 홈페이지의 웹 접근과 국내 공보 두 건의 한국어 텍스트를 확인했다. 아래 한국어 공보 확인은 **Google Patents가 표시하는 문헌**을 읽은 결과이며, KIPRIS 직접 조회·현재 등록원부 확인·심사관의 의견서 열람과 다르다. **두 문헌 모두 심사이력 미확인**이다.

## 1. 공식 UI 접근 시도

대상: [KIPRIS 지식재산정보 검색서비스](https://www.kipris.or.kr/).

| 실행 | 실제 결과 | 판단 |
|---|---|---|
| CUA의 새 in-app 탭 생성 | `Browser is not available: iab` | 해당 통로 미제공. 사이트 장애로 판단하지 않음. |
| 연결된 Chrome의 새 탭 생성 | `Owl extension-created tabs must be active` | 새 탭 생성 단계 오류. KIPRIS 페이지가 열린 결과가 아님. |
| 문서에 있는 visible 옵션을 사용한 생성 | `Capability is not available: visibility` | 옵션 미지원. 보안 설정·브라우저 보호를 변경하지 않음. |
| 브라우저를 선택하고 문서의 `tabs.new()` 사용 | 같은 새 탭 생성 오류 | 같은 실패를 계속 반복하지 않음. |
| 기존 작업실에서 새 탭 키 입력 뒤 탭 목록 확인 | 작업실 외 새 탭 확인 안 됨 | 기존 작업실 URL·내용을 변경하지 않음. |
| 웹 도구로 공식 홈페이지 열기 | 홈페이지 제목은 확인되나 추출 텍스트 0줄 | 실제 검색 UI·검색 결과 확인 아님. |

CAPTCHA·로그인 화면·심사서류 접근 권한 요구는 실제로 보지 못했다. 따라서 “KIPRIS가 로그인 때문에 막혔다” 또는 “KIPRIS에서 검색할 수 없다”는 일반 결론도 내리지 않는다. 정확한 경계는 **이번 브라우저 통로에서 공식 검색 화면 조작을 완료하지 못함**이다.

## 2. 실행한 검색과 실행하지 못한 검색

다음은 외부 웹 검색 도구에서 실제 실행한 식이다. KIPRIS 검색창에 입력한 식으로 세지 않는다.

| 외부 검색식·필터 | 실제 반환 범위 | 특허 조사에 사용할 수 있는 정도 |
|---|---|---|
| `site.kipris.or.kr "KR20010013236"` | 검색기가 Google Patents와 번호가 겹치는 다른 문헌까지 반환 | 문헌 식별의 출발점. 공식 검색 결과 수가 아님. |
| `site.kipris.or.kr "102213478"` | 뤼이드의 Google Patents 결과와 무관한 번호 일치 결과 | 뤼이드 공보 번호·명칭을 직접 원문 링크에서 다시 확인. |
| `학습 도움 기록 지연`, domains=`kipris.or.kr` | KIPRIS Plus 데이터 설명·공지 등이 반환 | 관련 국내 특허 결과 목록을 얻지 못함. 부재 증거 아님. |
| `음성 학습 힌트 수행 평가`, 같은 필터 | 데이터 서비스·가이드 등 반환 | KIPRIS 자체 특허 검색과 구분. |
| `학습 데이터 기여 정정`, 같은 필터 | 데이터 정정 공지 등 반환 | 기술의 선행 검색 결과로 채택하지 않음. |

공식 UI에서 **실행하지 못한** 후속 검색 대상은 공개번호 `10-2001-0013236`, 출원번호 `10-1999-7011227`, 등록번호 `10-2213478`, 출원번호 `10-2020-0057446`이다. 번호 형식은 아래 실제 공보의 공개번호·출원번호를 구별해 준비했다. 최종 KIPRIS 입력 필드 형식은 실제 UI에서 확인해야 한다.

## 3. 한국어 국내 공보를 직접 읽어 확인한 내용

### KR20010013236A — 읽기 및 발음 교습기

[한국어 공보 텍스트](https://patents.google.com/patent/KR20010013236A/ko)를 열어 서지·청구항 1~18, 19의 일부, 38·39의 표시 구간과 동족 연결을 확인했다. 공개일은 2001-02-26, 표시 출원번호는 `KR19997011227A`, 발명자는 잭 모스토우, 출원인 표시에는 카네기 멜론 유니버시티 등이 있다.

청구항에는 음성 포획·인식·평가·응답 생성과 품질 제어를 통한 저장, 재생한 발음의 허용 여부를 응답으로 받는 구성이 있다. 음성을 교육에 사용하면서 품질 조건을 충족한 자료를 저장·재사용한다는 넓은 개념과 대조해야 한다. 페이지의 동족에는 `EP0986802B1`, `US5920838A`, `WO1998055980A1`이 연결되어 있다.

Google의 상태 표시는 법적 결론이 아니라는 주의가 붙어 있다. 이 표시에 근거해 현재 한국 권리상태나 심사 종료 사유를 확정하지 않았다. **KIPRIS 상세·심사서류·등록원부는 미확인**이다.

외부 번호 검색은 `KR20010013236A`를 출원번호의 일부로 포함하는 다른 분야 문헌도 반환했다. 정확한 공개번호 URL의 명칭이 “읽기 및 발음 교습기”임을 확인해 혼동을 제외했다.

### KR102213478B1 — 인공 지능 학습 기반의 사용자 지식 추적 시스템 및 그것의 동작 방법

[한국어 공보 텍스트](https://patents.google.com/patent/KR102213478B1/ko)를 열어 서지·청구항 1~6·도13 설명·분할/동족 연결을 확인했다. 표시 출원번호는 `KR1020200057446A`, 출원일은 2020-05-14, 등록공보 공개일은 2021-02-08, 출원인은 `(주)뤼이드`다.

청구항은 문제 정보를 받는 인코더와 응답 정보를 받는 디코더, 가중치·어텐션을 통한 지식 추적 학습을 중심으로 한다. 종속항 4에는 미래 위치 정보가 예측에 들어가지 않도록 하는 마스킹이 있다. “미래 정보로 과거를 오염시키지 않는다”는 추상적인 설명만으로 차이를 주장하기보다, 실제 자격 레코드·시간 범위·기여 정정 구성을 비교해야 한다는 조사상 단서다.

표시된 관련 분할은 `KR1020210014456A / KR20210141320A`, 미국 연결은 `US20210256354A1`이다. 이 페이지의 표시는 해당 관계를 추가 조사할 출발점이며 전체 동족의 청구항·현재 상태를 모두 확인한 결과가 아니다. **KIPRIS 상세·심사관 의견·보정서·거절/등록 이유는 미확인**이다.

## 4. 남은 확인의 정확한 범위

공식 검색 화면 접근이 되는 통로에서 두 공보의 출원번호로 상세를 열고, 국내 청구항·행정처리·공개된 심사문서를 실제 읽어야 한다. 이어 학습 도움·지연 사건·용도별 저장·기여 정정에 대해 동의어와 분류를 확장한 검색을 수행하고, 가까운 문헌의 인용·동족을 따라가야 한다.

이 로그에서 확인한 것은 **국내 공보 두 건의 문헌 식별과 한국어 표시 내용, 공식 검색 UI 접근의 미완료 경계**다. 관련 국내 선행이 전부 검색되었다거나, 전체 결합이 어느 문헌에도 없다는 보장, 침해 여부 판단으로 사용하지 않는다.
