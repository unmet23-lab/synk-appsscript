## 검수 증거

- 별도 담당이 기존 7개 근거 묶음·38판본을 실제 재현하여 유효함을 확인했다.
- 기존 합성 WAV를 임시 SQLite 0.5 세션에 붙여 6판본과 파일 바이트 보존을 추가 확인했다. 실제 마이크·새 전사·외부 API는 쓰지 않았다.
- 회사 후보 담당은 실제 소스를 읽고 Loom 보조 함수 시험 6개를 실행했다. 회사 전체 구현 전수 감사나 모든 후보의 동일 깊이 선행 검색은 아니다.
- 선행 담당은 국내 3건의 한국어 청구항·명세서를 읽었다. KIPRIS 직접 상세·심사서류는 브라우저 도구 단계 실패로 확인하지 못했다. 검색 미발견을 선행 부재로 쓰지 않았다.
- 통합 문안을 별도 담당이 다시 읽어, 읽기 튜터의 교습용 녹음 재사용과 ASR 자료 재사용을 같다고 쓴 한 문장을 교정했다. 접근 허락과 증거 적격성도 구별했다.
- 10쪽 PDF 전 페이지 PNG·서체 포함·페이지 넘침을 확인했다. HTML은 390px 너비에서 가로 넘침·목차 이동·이미지·세 서체 로드를 검사했다. 문서 열람 시 외부 요청 0건이다.

## 생성과 통합

`content.cjs`가 종합 본문 원천이며 `build.cjs`가 현행 자산 지문을 확인하고 승인된 미팅 지면 스타일로 HTML/PDF/REPORT.md를 만든다. `integrate.cjs`는 현재 미팅의 첫 카드와 안내·지문 목록을 갱신한다. `verify_pdf.py`는 Poppler로 만든 전 페이지 PNG와 PDF 서체 포함을 확인한다. 소스 상세 5개와 출력 사본은 파일 지문으로 대조한다.

```powershell
node tools/patent-studio/audit-20260912/build.cjs
node tools/patent-studio/audit-20260912/integrate.cjs
```

새 기능·학생 데이터·운영 배포는 이번 검토에서 변경하지 않았다. 이전 0.4/0.5 구현·증거 자료는 각 판본의 설명으로 보존하고 최신 판단은 이 검수에서 읽는다.
