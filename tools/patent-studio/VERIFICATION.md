# 근거 작업실 구현·검증 기록

2026-09-11 KST · 판단 코어 0.3.0 · 현재 기계의 로컬 실행 검증.

펠트 엔진의 근거 판단을 실제 원음·도움 제시·새 응답·저장까지 연결한 작업실이다. 로컬 주소는 `http://127.0.0.1:4318`, 실행은 저장소 루트에서 `node tools/patent-studio/server.cjs`다. 창을 닫거나 컴퓨터를 재시작했으면 `start.ps1`로 다시 연다. 기록은 사용자 로컬 앱 데이터의 SQLite에 남는다.

## 브라우저에서 끝까지 실행

`browser-qa.cjs`가 실제 Chrome에서 화면·HTTP·SQLite를 연결했다. 테스트의 오디오 입력은 자체 생성한 한국어 합성 WAV를 Chrome의 시험용 장치에 공급했다. 실제 사용자의 물리적 마이크나 학생 녹음을 시험한 것은 아니다. 외부 전사는 이 시험에서 호출하지 않았다.

청취 문장과 확인 체크는 자동 시험이 입력한 조건이다. 사람의 독립 청취 정확도나 학생의 실제 수행을 검증한 결과로 세지 않는다.

- 예제: 음성 자료·조사 칸 보류, 독립 조건의 과거형 칸 반영.
- MediaRecorder로 4.5초 WebM 생성 → 업로드 → 원음 재생·브라우저 디코딩 확인.
- 원음 청취 확인 → 실제 도움 화면 표시 → 사건 저장 → WAV로 새 응답 첨부 → 사람 청취·상대 시점 확인.
- 최종 6개 반영·1개 제외. 새 응답을 처음 독립 수행에 소급하는 칸이 제외됨.
- 비교 화면 다섯 행에서 시점 경계를 제거할 때 해당 한 칸이 달라짐.
- 원음 2개·사건 6개를 포함한 JSON 내려받기, 새로고침 후 같은 원음 지문 복원.
- JavaScript 오류 0, 누락 이미지 0, 390px 화면의 가로 넘침 0.
- 실제 글리프 렌더러에서 SUIT Variable과 Inter Tight 사용 확인. 이름만 선언한 서체 검사가 아님.

UI 담당의 별도 검증은 판본 충돌 뒤 재시도, 실제 녹음 구간 헤더, 파일의 시점 미확인 → 사람 확인 전환도 검사했다. 헤더가 존재한다는 사실은 외부 기기의 시간 진실성을 인증하지 않는다.

증거 파일은 로컬 `qa-output/browser-checks.json`, `evidence-export.json`, `01-start.png`~`06-full-flow.png`다. 개발 결과와 녹음 바이트는 Git에 넣지 않는다. 화면은 데스크톱·모바일 렌더를 실제로 열어 확인했다.

## 계산 규모

`benchmark.cjs`로 같은 통제 예제를 확장하고 코어 전체 계산과 네 비교를 한 번씩 실행했다. 준비 실행 후 3회의 중앙값이며 데이터베이스·음성 인식·통신·동시 사용자 시간은 제외한다. Node v24.18.0, 현재 기계의 한 번 측정값이다.

| 새 응답 수 | 해석 후보 합계 | 본 판정 칸 | 계산 중앙값 | 전체 분석 JSON 크기 |
|---:|---:|---:|---:|---:|
| 0 | 2 | 3 | 0.742ms | 49,633 bytes |
| 10 | 22 | 43 | 1.844ms | 253,898 bytes |
| 100 | 202 | 403 | 10.965ms | 2,108,839 bytes |
| 1,000 | 2,002 | 4,003 | 206.880ms | 20,812,860 bytes |

현재 계산은 세션 전체 재계산이며, 비교에서 칸을 반복 검색하는 부분이 있다. 응답 수 증가에 비례하는 선형 성능이나 대규모 운영 성능을 주장하지 않는다. 1,000개 응답에서는 설명·근거·네 비교를 포함한 JSON만 약 20.8MB가 된다. 제품 통합 시 세션 크기, 페이지 조회, 비교의 필요 시 계산, 영향받는 파생 결과만 갱신하는 구조를 다뤄야 한다. 이번 수치는 해당 개선이 이미 끝났다는 증거가 아니다.

## 실제 자동 전사 연결 상태

사용자가 승인한 자체 합성 `original.wav`만 기존 Gemini 경로로 시험했다. WAV 131,196 bytes, SHA-256 `d9e45d3fb33a6060c3d9cde162a2ac1c395ee84c6cca0c14bc2d8e235328955b`. 실행 환경의 `EACCES`가 외부 연결을 막아 Google HTTP 응답과 실제 전사 결과를 얻지 못했다. 사용자 승인은 해결됐지만 통신 문제는 남아 있다.

따라서 **실제 자동 받아쓰기 성공은 확인 불가**다. 설정 준비·모의 응답 시험 통과를 실제 연결 성공으로 표시하지 않는다. 지금 실행 가능한 경로는 원음 저장 후 사람이 듣고 전사를 확인하는 방식이다. 로컬 음성 인식 대안 역시 현재 환경에서 설치·실행이 막혀 사용 가능 기능에 넣지 않았다. 상세 근거와 제품 연결 위치는 INTEGRATION.md에 있다.

인수 시 서버는 `SYNK_PATENT_STT_PROVIDER=manual`로 실행했다. 미팅용 안내도 이 모드를 사용하므로 알려진 통신 실패 때문에 매번 기다리지 않고 원음 저장과 사람 확인을 바로 진행한다. 기본 Gemini 어댑터 설정을 삭제하거나 다른 과금 통로로 바꾸지는 않았다.

## 적용한 원천과 남은 제품 범위

- 현재 DESIGN.md의 SUIT·Inter Tight·DM Mono, 현행 색 토큰과 Loom 스타일, 승인 SYNK LAB 로고, 마스코트 자산 모듈의 몽글 ‘궁금함’을 사용했다. `assets.cjs`가 생성하며 `public/assets/manifest.json`에 원천과 지문을 남긴다.
- 코어 SHA-256: `fef5fe0cda969305e9436f5785aaf1cdf9d2886319a88ec44fd59b11bcf77dcf`.
- 순수 판단 코어·영구 저장·전사 어댑터·브라우저는 분리돼 있다. 기존 앱의 `audio_ref`, 기계/사람 전사 분리, 도움 조회와 재응답, 시점별 상태 계약을 대조하고 연결 위치를 문서화했다.
- **제품 학생 DB·Apps Script·Supabase 운영 경로에 배포하거나 연결하지 않았다.** 이 작업실이 운영 제품을 변경하거나 학생의 능력 상태를 갱신하지 않는다.
- 문법 의미 판정은 지정된 통제 문장의 조사·역할·과거형 범위다. 임의 문장의 음성–청취 전사 자료 자격은 별도로 처리한다. 학습 효과·모델 정확도·특허 등록 가능성을 이 시험 수치로 입증하지 않는다.
- 도움 노출은 진행자 작업실에서 실제 표시한 앱 내 사건이다. 별도 학생 기기와 동기화된 도움 전달, 앱 밖 도움의 부재, 모든 가능한 해석의 완결성을 확인한 것은 아니다.

기존 발표물의 합성 실험 A/B는 설명 자료로 남는다. 이번 실행 작업실의 구현·시험 결과와 합쳐서 같은 실험의 성과로 세지 않는다.
