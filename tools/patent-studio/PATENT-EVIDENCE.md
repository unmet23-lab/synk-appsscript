## 보호를 검토하는 구체적 관계

| 관계 | 입력 → 처리 → 출력 |
|---|---|
| C1 사건·시점 | 원음·발화 사건·녹음 구간 또는 확인 순서와 도움 사건 연결. 발생 순서와 수신 순서를 구분 |
| C2 해석·미확인 | 지원하는 복수 해석과 능력별 관련 미확인 범위를 보존 |
| C3 용도별 자격 | 용도×능력×평가 대상 발화마다 자격을 검사하고 후보별 효과값이 일치하는 적격 관측을 반영 |
| C4 목표 관측 | 보류된 목표 칸에 관련되는지, 원래 평가 대상 발화를 보존할 수 있는지로 확인 행동의 적격성을 제한 |
| C5 실제 사건 | 예상 결과와 실제 수신을 구분. 재청취는 기존 발화의 해석, 도움 뒤 응답은 별도 새 발화로 반영 |
| C6 선택 정정 | 늦은 도움의 시점·능력 범위로 기존 기여를 다시 판단하고 영향 기여를 철회·보류하며 적격인 다른 용도를 유지 |

C3의 자격과 보류가 C4를 제한하고, 실제 실행 사건을 C5로 수신한 뒤 C1·C2로 C3을 재계산하여 C6의 기여 변화를 기록하는 연결이다. 일반 해시·캐시·원장·음성 인식기 각각의 새로움을 주장하지 않는다.

현 구현은 지정 문장의 조사·역할·과거형, 사람 확인 입력과 고정된 관측 후보·가정 비용을 사용한다. 모든 자연어 해석의 완결·범용 최적 관측·실제 숙련 정확도를 입증하지 않았다. 반영은 정답이나 숙련 상승이 아니라 해당 관측 기록의 사용 자격이다.

## 가장 강한 반론과 남은 검토

Beck 외(2008)는 음성 튜터에서 도움의 즉시 수행 지원과 지속 지식을 구분한다. Adobe US10943497B2는 지식·힌트 예측과 실제 도움에 따른 갱신을 연결한다. EP0986802B1은 음성 평가와 품질 조건·사람 확인을 거친 자료 재사용을 함께 다룬다. ATMS(1986)는 가정 의존 결과의 유지·철회와 다음 측정을 설명한다. 따라서 넓은 '도움 전후 평가', '판단과 다음 행동의 연결', '용도별 품질', '부분 정정' 자체로 최초성을 말하기 어렵다.

읽은 단일 자료에서 C1~C6의 정확한 전체 관계를 찾지 못한 상태다. 해당 관계가 없다는 증명은 아니다. 선행의 청구항·실시예와 하나씩 구성 전체를 비교하고, 알려진 처리들을 결합할 동기·호환성·구체 변경과 효과를 검토해야 한다. 국내 대응·동족 전체·심사 경과까지 전수 검토한 것은 아니다.

## 공식 요건의 현재 위치

실용적 용도와 구체 연산의 근거는 있다. 명세서에 입력 사전·처리 순서·예외·완전한 입출력 실시예를 옮기고, 뒷받침되는 청구 범위를 정해야 한다. 신규성과 진보성은 위 선행 대조가 남았다. 사용자는 단독 설계라고 확인했으며, 구체적인 사람의 기여와 개인·회사 출원 관계를 임의로 확정하지 않는다.

이번에 일반 심사기준 2026.03.12판 및 기술분야별 가이드 2026.03판의 전체 PDF를 실제 확보했다. AI 분야는 2026.01 추록이다. 관련 절만 정독했으며 전체 854쪽·1,278쪽 정독을 주장하지 않는다. 이전 전문 다운로드 실패 기록은 현재 확보 상태로 갱신한다. 직접 출처와 쪽수는 PATENT-REQUIREMENTS.md에 있다.

## 준비된 시연과 추가 비교

1. 합성 실제 받아쓰기: 기계 전사 0반영·3보류 → 실제 들린 말 청취 입력만 확인하면 1반영·2보류. 파일의 수행 시점을 확인하지 않는다.
2. 두 해석의 통제 예제: 1반영·2보류 → 친구가로 가상 청취 결과를 정하면 3반영, 역할 값은 관계 재확인.
3. 늦은 도움 정정: 3반영 → 발화 전 조사 도움 추가 → 1철회·2유지. 발화 구간·조사만 영향·과거형 독립 조건의 예제다.
4. 별도 전체 합성 시험: 두 원음, 6반영·1제외, v0~v9 10판본 재현. 합성 출처와 자동 시험의 확인 가정을 보존한다.

연결 제거 비교는 코드 계약을 설명하는 진단이다. 기존 경쟁 기술의 성능을 재현한 비교가 아니다. 같은 현실적 관측 후보·같은 비용과 독립 정답표를 주어 잘못된 반영·유효 자료 보존·원래 목표의 실제 해소·정정 범위·비용을 함께 비교하는 것이 다음 증거다. 엔진 출력을 정답표로 거꾸로 쓰지 않는다.
