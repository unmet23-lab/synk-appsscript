실행기는 저장소 위치에서 사용합니다. 문서 폴더의 스크립트 사본만 다른 기기로 옮겨 독립 실행하는 패키지는 아닙니다. HTML/PDF는 자체 포함 자산으로 오프라인에서 읽을 수 있습니다. 작업실 링크는 같은 기기의 로컬 서버를 가리킵니다.

모든 새 시연 입력은 합성 사건입니다. 녹음 경계·발생 가능 범위·출처도 명시된 가정입니다. 실제 학생, 마이크 녹음, 외부 전사 호출, 운영 DB 반영, 학습 효과 측정은 이번 확장 범위가 아닙니다. 신규성·진보성 확정이나 등록 보장은 이 결과에 포함하지 않습니다.
