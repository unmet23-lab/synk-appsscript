# B안 — LOOM 공통 바탕·국소 표정 합성의 대체 등록 주안 검토

2026-09-13 · 독립 조사 1차 · 실제 코드·현재 승인 원문·특허 원문 대조

## 결론

**Core를 대체할 한 후보로는 LOOM의 ‘공통 복원 바탕과 표정 변화 영역을 분리하는 영상 합성 방법’을 남긴다. 그러나 현재 증거로 Core보다 등록 가능성이 높다고 판단하지 않는다.** 가까운 선행은 얼굴 일부 교체, 특징점 정렬, 보호 화소, 색·공간 결합 마스크, 경계 혼합을 이미 설명한다. 현행 구현도 수동 검수한 눈 윤곽과 알려진 영상 연산을 결합한 부분이 커서 진보성 반론이 강하다.

이 대안의 장점은 문제와 출력 차이를 직접 보여줄 수 있다는 점이다. 녹음 지연 같은 가정을 추가하지 않아도 표정마다 털이 바뀌고, 눈이 잘리며, 안경이 사라졌던 실제 제작 문제가 있다. **이 장점은 설명·실시예 준비의 장점이지 등록 확률의 증거가 아니다.** 지금 이 후보로 방향을 전환하는 것보다 아래의 강한 비교 방식에서도 차이가 남는지 먼저 확인하는 편이 낫다.

## 이전 후보표의 중요한 정정

`audit-20260912/COMPANY_CANDIDATES.md`는 `tools/옷표정얹기.py`의 ‘공통 큰 눈 창 → 털/눈 영역 복사 → 의상 재잠금’을 Loom 예비안으로 읽었다. 이 코드는 현재도 존재하고 색옷 씨앗 시험도 통과하지만, 이것을 현행 승인된 표정 전환 방식 전체로 소개하면 안 된다.

현재 `DESIGN.md:39`와 `docs/캐릭터/캐릭터_생명감_설계.md` §1-a는 **표정마다 넓은 얼굴 창을 복사하여 미간·볼·이마 털을 바꾸는 합성을 금지**한다. 기준은 공통 바탕, 좁은 눈·눈꺼풀·렌즈 윤곽, 공통 전체 알파, 원본 크기와 사용 크기에서의 비교다. `docs/_ops/의상라디오검수_20260909/털일관성/수정보고.md`가 해당 결함과 새 방식을 연결한다.

확인된 현재 실물은 **까몽 / 여름 델+전설의 팻말 / 8표정**이다. 다른 128차림과 모든 캐릭터의 자동 합성 완료로 확대하지 않는다. 기존 코드의 ‘창 밖 100% 동일’은 창 안 털이 바뀌는 문제를 놓쳤다. 이 실패를 기술 문제로 사용하는 것은 타당하지만, 같은 검사를 더 강하게 썼다는 이유만으로 새 발명이라고 주장하지 않는다.

## 심사자가 제기할 가장 강한 결합 반론

다음은 실제 거절이 아니라 이번 조사자의 예상 반론이다.

> 얼굴 부분을 정렬·교체하는 D1에서 털과 의상이 변하지 않게 하려면 D2의 보호 합성과 D3의 얼굴 영역 마스크를 적용할 수 있다. 여러 표정에 같은 배경 레이어를 재사용하고 눈만 바꾸는 것은 반복 제작의 통상 설계다. 경계 블러가 보호 영역을 침범하면 안쪽 경계만 혼합하거나 보호 화소를 다시 복사하면 된다. 수동 눈 윤곽·해시 검사·무손실 출력·시험 추가는 품질 확보 수단이며 그 결합 결과도 예상 가능하다.

**현재 B안은 이 반론을 해소했다고 말할 수 없다.** 특히 D1은 타깃에서 직접 복사할 화소, 소스에서 직접 복사할 화소, 사이의 혼합 영역까지 설명한다. ‘화소 불변’ 자체를 새로운 원리로 내세우면 너무 넓다. 동물형 마스코트·펠트·까몽의 초록 홍채라는 적용 대상 차이만으로 통상 합성 반론을 넘을 수도 없다.

## 남길 최소 구성과 새로 필요한 것

상담용 명칭 후보: **공통 복원 바탕과 표정 변화 영역을 분리하여 복수의 캐릭터 영상을 합성하는 방법**.

이는 확정 청구항이 아니라 필수 관계를 검토하기 위한 초안이다.

1. 같은 각도·자세의 기본 영상과 복수 표정 영상에서 눈의 실제 윤곽을 입력받는다.
2. 기본 눈을 지울 때 필요한 복원 영역을 정하고, 기본 영상의 별도 털 표본을 사용하여 공통 바탕을 한 번 생성한다.
3. 복원 영역과 별개로 각 표정의 이동된 눈 윤곽을 정하고, 이 윤곽 안쪽의 혼합 가중치로 눈만 공통 바탕에 합성한다. 기본 표정도 같은 공통 바탕에 합성한다.
4. 합성 중 전체 알파를 바탕과 같게 유지하며, 동적 변화 영역은 최종 눈 윤곽들의 합집합으로 정한다. 복원용 넓은 구멍을 동적 변화 영역으로 확대하지 않는다.
5. 같은 표시 변환을 적용한 파생 영상에서, 그 변환의 표본 영향 범위를 포함한 허용 영역 밖 불변성과 눈 내부의 실제 표정 차이를 함께 확인한다.

1–4는 대표 차림 프로필에서 구현돼 있다. 5는 관련 파생·독립 검사 기록이 있지만, 임의 크기·회전·연속 리샘플링 경로를 스스로 추적하는 범용 생산 계약까지 구현됐다고 확인하지 않았다. 그 자동화가 필요하더라도 ‘변환의 영향 영역을 계산한다’는 통상 영상 처리와 별도로 대조해야 한다.

등록 주장을 위해 새 기능을 무작정 더 붙이지 않는다. 우선 필요한 추가 작업은 다음 두 가지다.

- **강한 기존 방식과의 공정 비교:** 같은 수동 윤곽·같은 바탕 복원 입력까지 허용한 통상 레이어 합성이 동일 결과를 내는지 확인한다. 입력 우위를 발명 효과로 착각하지 않는다.
- **필요한 관계의 제거 비교:** 기본 표정까지 공통 바탕을 쓰는 관계, 복원 영역/동적 영역 구분, 윤곽 안쪽 feather를 각각 제거했을 때 어떤 오류가 생기는지 기록한다. 한 요소를 빼서 나빠진 결과만으로 그 요소가 비자명하다고 결론 내리지는 않는다.

같은 공통 복원 바탕·수동 윤곽·조건을 제공한 레이어 합성이 동일하게 해결하면, 그 실험에서는 우리 방식의 우월한 효과가 입증되지 않은 것이다. **그 실험만으로 B를 등록 우선 후보로 승격하지 않는다.** 다만 비교군에 이미 제공한 입력 관계를 선행기술에서 쉽게 도출할 수 있었다는 법적 결론도 아니다. 결합할 동기, 필요한 구조 변경, 우리 설계를 알고 난 뒤 끼워 맞춘 판단인지 여부는 별도로 대조한다. 더 복잡한 최적화나 AI를 붙여 후보를 억지로 유지하지 않는다.

## 필요한 대조 실험

입력은 학생 자료가 아닌 기존 회사 캐릭터 자산을 사용한다. 1차는 현재 승인 대표 8컷, 확장은 다른 차림 6종×8표정으로 사전에 고정한다. 확장 차림은 무악세, 눈 위 가림, 눈 아래 의상, 홍채와 같은 색 악세, 넓게 움직이는 표정, 어두운 의상과 털의 색 충돌을 포함한다. 실제 해당 자산 존재와 승인 상태를 확인한 뒤 목록을 고정해야 한다.

| 비교군 | 목적 |

| 넓은 얼굴 창+일반 feather | 이미 겪은 털 교체·의상 침범의 재현. 약한 비교군임을 명시한다. |

측정치는 독립 검수자가 만든 의상/털/눈 영역으로 계산한다. 제작기가 낸 허용 마스크 하나만 사용하면 넓은 창을 만들어 결함을 통과시킬 수 있다.

- 고정 털·의상 영역의 컷 간 RGBA 변경 화소 수와 최대 채널 차이.
- 눈 윤곽 내부의 잘린 동공·반사광·흰자, 눈을 감았을 때 남은 이전 동공 흔적.
- 전체 알파 차이, 지정 출력 크기에서의 리샘플링 영향 범위 밖 차이.
- 전환 시 고정 영역의 시간적 변화량, 실제 사용 배경·크기에서 표정의 구별 가능성. 회색 지문이 서로 다르다는 사실을 사람이 감정을 읽는 정확도로 대체하지 않는다.
- 처리 시간·메모리·수동 윤곽 작업 시간. 생성 API 비용·13배 절감 등 과거 주석값은 이번 실측으로 쓰지 않는다.

명세서에는 개선된 측정값과 그 처리 관계를 함께 넣는다. 수치가 나오기 전에는 ‘재질 불변 보장 범용 엔진’·‘자연스러움 향상 입증’·‘등록 가능성 대폭 증가’를 쓰지 않는다.

## 이번에 실제 확인한 증거와 한계

2026-09-13 현재 파일의 producer/consumer 참조를 읽었다. 별도 합성·생성·배포·학생 데이터 처리·유료 API 호출은 하지 않았다.

1. `tests/옷표정초록보존_test.py` 6개는 다시 실행해 통과했다. 이는 과거 합성 코드의 색 씨앗/출력 경로 시험이다. 현행 전체 표정 합성 검증으로 세지 않는다.
2. 현행 `라디오털고정_test.py`·`라디오눈윤곽_test.py`를 번들 Python에서 다시 실행하려 했으나 OpenCV(`cv2`)가 없어 실행되지 않았다. `unittest discover`가 0개를 찾은 결과도 통과로 세지 않았다. 환경 설치·다른 결과 파일 변경을 시작하지 않았다.
3. 대신 Pillow+NumPy로 **현재 저장된 대표 RGBA 8컷을 직접 열어**, 제작기 함수를 호출하지 않고 기본 출력과 대조했다. 현재 허용 마스크 37,088화소 밖 1,535,422화소의 RGBA 차이는 8컷 모두 0, 전체 알파 차이도 모두 0이었다. 이는 출력의 국소 불변성을 재확인한 것이다. 허용 마스크 자체의 적절성·실시간 자연스러움·기존 기술 대비 우위는 입증하지 않는다.
4. 현재 `목록.json`과 `bots/오버레이/마스코트.html`은 같은 대표 WebP 버전 `65f92a753bb5416b`를 참조한다. 로컬 참조 확인이며 라이브 방송 확인으로 확대하지 않는다.

## 미팅에서 내릴 결정

변리사에게는 현재 대표 8컷의 전후와 D1의 [0068]–[0078]을 나란히 제시한다. **‘공통 복원 바탕에 기본까지 다시 합성하고, 복원 구멍을 동적 영역과 분리한다’는 관계가 통상 레이어 합성을 넘어서는가**를 묻는다. 없으면 B는 제작 기술의 설명 자료로 남기고 첫 출원의 주안을 바꾸지 않는다. 남는 관계가 특정되면 그 관계만 청구항·도면·비교 실험으로 연결한다.

이번 B안은 과거 자료의 승인 상태 혼동을 바로잡고 현행 대체 후보를 정확히 특정했다. **회사에서 낼 수 있는 가장 높은 등록 확률의 기술을 확정한 것은 아니며, Core보다 쉽다는 근거는 아직 없다.**
