## 결합 동기와 실제로 필요한 변경

**문헌에서 출발하는 결합 동기:** E는 시간 순서에 의존하는 학습 분석을 직접 대상으로 삼는다. H도 상호작용 이력과 도움을 이용해 상태를 갱신한다. 따라서 H에 공급되는 이력의 지연·누락으로 순서가 어긋나는 문제에 E를 연결하는 것은 기술적으로 납득되는 경로다. 이는 완성된 P1을 이미 알고 있다는 전제 없이 설명 가능한 동기다. 다만 ‘그 결과 모든 P1 조건이 나온다’까지 문헌이 말하는 것은 아니다.

**우선 필요한 접속 변경:** 학생·문항별 사건을 H의 입력 형식으로 변환하고, 늦게 삽입된 사건 이후의 상태를 재계산할 기준 판본과 재실행 범위를 정해야 한다. 서로 다른 처리기가 어떤 사건을 읽는지도 결정해야 한다. 이 정도의 연결만으로는 현재 P1의 원음별 자격 원장이 생기지 않는다.

**P1까지 가려면 추가로 정할 것:** 원음·시도·발화 구간의 고정 관계, 도움 내용과 대상 능력의 대응, 발생 범위가 겹치거나 불명인 경우의 상태, 다수 사유가 함께 있을 때의 선택 규칙, 목적별 기여 값과 판본 전이를 정의해야 한다. 또한 과거형 유지에 사용하는 독립 확인값과 후보 집합의 의미를 입력 계약으로 명시해야 한다. 현재 문안은 그 독립성을 엔진이 발견하는 방식이 아니다.

## 반론·재반론과 현재 판단

강한 반론은 위 추가 사항이 사건 처리기의 분야별 데이터 형식과 판정 규칙에 불과하다는 것이다. 필드를 늘리고 조건을 세밀하게 열거했다는 사실, 또는 원문에 같은 순서의 긴 목록이 없다는 사실만으로 기술적 곤란이나 새로운 효과가 입증되지는 않는다. 특히 P1-05의 전체 순서가 효과에 필수인지, P1-06의 전후 값 비교가 보통의 결과 비교를 넘어서는지 설명해야 한다.

재반론의 중심은 결과 단위다. P1은 전체 학습 상태를 다시 추정하는 데 그치지 않고, 같은 원음의 용도별 자격과 관측값을 별도로 다룬다. H의 지식추적 손실이 0이라는 사실은 원음–전사 자격이나 과거형 관측값이 불변이라는 증명이 아니다. 공유 가중치가 있으므로 한 목적의 학습 제외를 다른 출력의 완전한 보존과도 동일시할 수 없다. 그러나 이 차이만으로 예상 밖의 효과가 확인된 것도 아니다.

결론적으로 **두 문헌의 결합은 현실적인 반론이지만 P1 전체의 직접 대응표는 완성되지 않는다.** 다음 판단에서는 P1-04~06이 공동으로 필요해지는 구체 입력, 각 조건을 제거했을 때 잘못 철회되거나 잘못 유지되는 기록, 그리고 통상의 사건 재처리기에 같은 규칙을 연결한 결과를 나란히 제시해야 한다. 동일 결과와 다른 결과를 모두 기록하되, 계산·출력 대조를 법적 진보성 판단과 혼동하지 않는다.

별도 검토자가 다음 두 지정 문헌의 관련절을 직접 읽고 보충했다. 추가 키워드 검색을 한 것은 아니다.

- [US11144665B2](https://patents.google.com/patent/US11144665B2/en), 청구항 1·2·5·6, 도2B 단계260~280: 목적별 접근 경로를 나누고 한 목적을 철회하면서 다른 목적의 접근을 유지한다. 이것을 이미 반영한 원음별 능력 관측값의 철회와 동일시할 수는 없다. 접근 허용표를 자격·관측값 계산에 연결하는 변경이 필요하다.
- [US20030004724A1](https://patents.google.com/patent/US20030004724A1/en), [0010]~[0011]·[0098]~[0109]: 실제 발화의 전사와 최종 문장의 분리, 전사 차이의 원음 확인, 두 수정 결과의 연동·분리 갱신을 설명한다. 전사 자료를 따로 보존한다는 점만으로 차별성을 주장하기 어렵다.

이 보충에서 남는 판단은 **접근 제어·문서 수정과 다른 자격/관측값 처리를 만들 때, 시간·범위·전후 기여의 결합이 통상적인 정책 설정으로 도출되는가**다. 현재 P1은 개별 관측값의 철회이며, 운영 통계 전체의 정정이나 이미 학습한 모델 가중치의 역갱신까지 청구·실증한 것이 아니다.
