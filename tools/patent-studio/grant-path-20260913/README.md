# 결합 반론 대응 구성 · 2026.09.13

현재 주안의 추가 검토 후보는 **판정 차이에서 원음 확인 범위와 결과 귀속 조건을 함께 생성하고, 실제 결과를 같은 계약으로 검사하는 관계**입니다. [통합 보고서](REPORT.md)에 쉬운 예시, 강한 결합 반론, 구성·명세서 전략, 구현·미구현 및 미팅 대본을 담았습니다.

기존 09.12 공보형 초안·Core 0.5·운영 DB는 보존했습니다. 이 폴더는 출원 확정안이나 등록 가능성이 개선됐다고 검증된 최종안이 아닙니다.

5. [FACT_GATE.md](FACT_GATE.md): A/B의 사실·법적 주장 경계 독립 검수. 통합 REPORT는 별도 후속 검수에서 전체 행동 조건 생성이 미구현임을 더 분명히 보완.

## 실험과 증거

- [lab/VERIFICATION.json](lab/VERIFICATION.json): 22개 테스트 통과, 최신 실행시각·코드 지문. [TAP 원문](lab/TESTS.tap).
- [lab/RESULTS.json](lab/RESULTS.json): 6개 합성 시나리오, 계약·결과·앞뒤 기록, 기존 합성 WAV 크기/길이/내용 지문.
- 같은 원음·시도·목적 정책을 준 일반 검사와 표지 라우팅의 9쌍 결과는 동일합니다. 이 비교에서 우월한 출력 효과는 입증되지 않았습니다. 동일 출력만으로 계약 도출의 용이성이 증명되는 것은 아닙니다.
- 단어 시각·후보·도움 조건은 수동 시험 입력입니다. 실제 청취·정렬 정확성·학생 효과·등록 확률의 측정이 아닙니다.

## 다시 만들기

저장소 루트에서 실행합니다. 외부 API·학생 자료·운영 DB를 사용하지 않습니다. 기존 합성 WAV가 해당 PC 앱 데이터 경로에 있어야 합니다. 출력은 기존 미팅 자료 하위 `등록성_보강_20260913`에 생성합니다.

```powershell
node tools/patent-studio/grant-path-20260913/lab/verify.cjs
node tools/patent-studio/grant-path-20260913/build.cjs
```

`build.cjs`는 현재 승인 폰트·토큰·로고 원본 지문을 대조하고, 실제 브라우저에서 6개 결과 선택·이전/다음·모바일 폭·외부 요청 없음·글꼴 로드를 검사합니다. PDF는 A4 8쪽으로 생성했으며 8쪽 전부 Poppler 렌더와 텍스트·글리프 임베드를 확인했습니다. 출력/검수 폴더의 JSON과 PNG에 근거가 있습니다. 본문 수정 뒤에는 PDF 재렌더 및 `pdf-qa.py`를 다시 수행합니다.

## 남은 범위

행동의 실제 답 노출·새 수행 이력에서 목적별 허용 조건을 공동 생성하는 부분, 실제 단어 정렬과 원음 재생·계약 저장·결과 수신 UI 연결, 전체 사건 본문을 보존하는 저장·재생은 미구현입니다. 현재 허용 종류는 원음 재검토로 고정돼 있습니다. 새 응답은 기존 별도 경로에 저장해야 하며 이 어댑터가 그 저장까지 담당하지 않습니다.

최종 청구항의 가장 가까운 선행·결합 동기·필요 변경을 추가 대조하고, 최초 명세서에 실제 연결·예외·한정안을 반영해야 합니다. 회사 최고 등록 후보·등록 확률 상승·등록 완료는 확인하지 않았습니다.
