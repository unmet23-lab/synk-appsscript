기존 09.12 공보형 초안·Core 0.5·운영 DB는 보존했습니다. 이 폴더는 출원 확정안이나 등록 가능성이 개선됐다고 검증된 최종안이 아닙니다.

## 남은 범위

행동의 실제 답 노출·새 수행 이력에서 목적별 허용 조건을 공동 생성하는 부분, 모든 후보의 유효한 단어 정렬과 원음 재생·계약 저장·결과 수신 UI 연결은 미구현입니다. 기존 작업실은 전체 사건 본문을 이미 저장·내보내며, 새 어댑터의 계약·결과까지 이 경로에 연결하는 작업이 남았습니다. 현재 허용 종류는 원음 재검토로 고정돼 있습니다. 새 응답은 기존 별도 경로에 저장해야 하며 이 어댑터가 그 저장까지 담당하지 않습니다.

최종 청구항의 가장 가까운 선행·결합 동기·필요 변경을 추가 대조하고, 최초 명세서에 실제 연결·예외·한정안을 반영해야 합니다. 회사 최고 등록 후보·등록 확률 상승·등록 완료는 확인하지 않았습니다.
