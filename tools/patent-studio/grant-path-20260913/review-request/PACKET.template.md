## 1. 해결하려는 문제와 현재 처리

학습자의 녹음을 처음에는 도움 없는 수행으로 반영했는데, 그 녹음 전에 조사 답을 보여 준 기록이 뒤늦게 도착할 수 있습니다. 이때 녹음 전체를 버리거나 모든 능력의 근거를 그대로 두는 대신, 도움의 발생 시점과 대상 능력을 대조해 자격과 기여를 다시 계산합니다.

여기서 **기여**는 원음과 전사의 대응 자료 또는 특정 능력의 사용을 뒷받침하는 개별 관측값입니다. 이미 학습된 신경망 가중치에서 그 영향까지 제거했다는 뜻은 아닙니다.

| 처리 단계 | 입력과 출력 |
|---|---|
| 기존 기록 | 원음·발화 구간·전사와 용도/능력별 자격·기여를 연관 저장 |
| 늦은 도움 | 발생 시간정보와 수신 기록을 구분하고 답 노출·능력 범위를 읽음 |
| 재판정 | 도움의 선후·겹침·불명과 능력 범위를 계산하고, 다른 보류 조건도 함께 검사 |
| 기여 갱신 | 반영→보류/제외는 철회. 전후 반영이고 값이 같으면 유지. 값이 달라지면 교체 |
| 전이 기록 | 원인 사건, 전후 판본·자격·기여, 철회·유지를 연결해 저장 |

**현재 구현의 범위:** 한국어 통제 문장 ‘친구를/친구가 만나서 카페에 갔어요/가요’의 조사·과거형 관측과 원음–전사 자료를 다룹니다. 도움 범위와 독립 확인값은 외부 입력입니다. 엔진이 실제 도움의 인지적 영향이나 모든 한국어 능력을 자동 측정하지 않습니다.
