## 검수 중 수정한 두 곳

1. **A의 기준선 표:** ‘간단한 결합만으로 같은 결과’ 및 ‘차이가 남는 경우만 분석’은 우리 완성 계약을 미리 받은 실행 비교와 기존 기술자의 설계 도출 과정을 혼동시킬 수 있었다. 생성자가 이를 ‘우리 계약을 주입한 실행 구성’으로 명시하고 차이·동일성을 함께 분석하도록 수정했다. 현재 `A_CORE.md` 144·146행을 직접 다시 읽었다.
2. **B의 채택 기준:** ‘단순 레이어 합성이 동일하게 해결하면 등록 우선 승격하지 않음’은 진보성 판단을 출력 우월성에만 연결하는 뜻으로 읽힐 수 있었다. 생성자가 동일 입력을 준 실험의 우월 효과 미입증과, 그 입력 관계의 선행 도출 용이성 판단을 분리했다. 현재 `B_ALTERNATIVE.md` 76행을 직접 다시 읽었다.

두 경우 모두 결과 차이가 없다는 사실은 해당 실험의 효용을 제한한다. 그 사실 하나만으로 법적 진보성이 부정되는 것은 아니다. 반대로 개별 관계가 새 이름을 가졌다는 사실도 진보성의 증거가 아니다. 공식 심사기준 제3부 제3장 §7(책쪽 3324~3326/PDF 322~324), §9(1)(책쪽 3329/PDF 327)의 전체 결합·동기·사후적 고찰 기준을 적용해야 한다.

## 통합 시 유지할 내용

- A에서는 원래 음성 파형의 전사 확인과 학생의 현재 의도 확인이 서로 다른 자료라는 문제 정의, 목적·시도별 결과 귀속 계약, 필요한 구조 변경표를 유지한다.
- B에서는 옛 넓은 얼굴 창이 현재 승인 방식이라는 오해를 수정하고, 공통 바탕·기본 표정 재합성·복원 영역과 변화 영역의 분리를 유지한다.
- 공정한 입력을 제공한 강한 비교군, 합성/실제 사례 구분, 미구현·미측정·미확인 범위를 유지한다.
- ‘등록률 상승 확인’, ‘결합 반론 극복’, ‘회사 최고의 등록 후보 확정’이라는 문구로 바꾸지 않는다.
- 개발 우선순위의 근거와 법적 등록성 판단을 분리한다. 개발은 실제 사업 문제와 설명 가능한 처리 관계를 구체화하는 수단이지 등록성의 대체 점수가 아니다.
