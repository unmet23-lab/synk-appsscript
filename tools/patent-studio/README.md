# SYNK 근거 작업실

펠트 엔진의 근거 판단을 원음 입력 → 용도별 반영·보류 → 실제 도움 제시 → 새 응답 → 정정·저장·재현까지 연결했습니다. 현재 판단 코어는 0.4.0입니다.

## 지금 열기

현재 Windows PC에서 **[start.cmd](start.cmd)를 실행**하면 숨김 서버를 켜고 실제 로컬 받아쓰기까지 검사한 뒤 브라우저를 엽니다. 이미 실행 중이면 [근거 작업실](http://127.0.0.1:4318)을 엽니다. 터미널에서는 `powershell -NoProfile -File tools/patent-studio/start.ps1`을 실행합니다.

기본 받아쓰기는 **기기 안에서 · 인터넷 없이**입니다. 준비한 모델과 별도 Python 환경을 사용합니다. 화면의 **시연 준비 확인**에서 저장·자산·합성 원음·실제 로컬 전사·판단 예제 다섯 항목을 확인할 수 있습니다. 마이크와 스피커는 짧은 녹음·재생으로 확인합니다.

## 미팅에서 따라갈 순서

1. **예제로 보기 → 조사는 보류, 과거형은 보존 → 이 예제로 시작.** 통제 예제의 1개 반영·2개 보류를 설명합니다. 후보와 조건은 시연용 가정입니다.
2. **원음을 다시 듣고 확정하기.** 예제에서 정한 청취 결과 `친구를 만나서 카페에 갔어요`를 입력·확인하면 3개 반영으로 바뀝니다. 실제 녹음에서는 먼저 원음을 듣습니다.
3. **도움 문장 보여 주고 기록.** 실제 팝업 표시 후 사건을 저장합니다. **새 응답 녹음 / 파일 선택**으로 새 음성을 추가하고 별도로 청취 확인합니다.
4. 새 응답의 음성 자료와 도움 뒤 수행은 자격에 맞게 판단하지만 **이 응답으로 처음의 독립 수행 확정**은 제외됩니다.
5. 오른쪽 **근거가 바뀐 기록 → 저장 기록 재현 확인**을 엽니다. 원인 사건·앞뒤 판본·유지와 철회, 사건을 다시 적용한 결과의 일치를 확인합니다.
6. **연결을 뺐을 때와 비교하기 → 기록 내려받기.** 원음 바이트·전사 시도·사건·효과 원장·재현용 입력을 가져갑니다. 새로고침하거나 다시 실행해도 기록이 남습니다.

실제 받아쓰기는 **직접 녹음 → 합성 음성으로 시작** 또는 새 녹음에서 확인합니다. 기계가 받아쓴 말은 사람 확인과 구분하며, 파일 업로드 시각을 발화 시각으로 쓰지 않습니다. 확인되지 않은 문항·도움 범위·발화 시점은 체크하지 않습니다.

## 받아쓰기 방식

| 선택 | 실제 동작 |
|---|---|
| 기기 안에서 | Whisper small로 로컬 추론. 실패해도 외부 전송 없음 |
| Gemini | 기존 Gemini 경로로 전송. 실제 성공·실패·응답을 기록 |
| Gemini 실패 시 기기에서 | 명시 선택한 경우 외부 실패 후 같은 바이트를 로컬에서 처리. 두 시도 모두 보존 |
| 직접 청취 | 원음 저장 후 사람이 듣고 입력 |

다음 업로드·재시도부터 적용됩니다. 기존 전사와 사람 확인을 삭제하지 않습니다. 전사 실패도 원음 제출 실패가 되지 않습니다. 새 결제·구독·계정 전환은 없습니다. 실제 연결 결과는 [검증 기록](VERIFICATION.md)에 있습니다.

## 저장·재현·계산

자료는 저장소 밖 사용자 앱 데이터의 SQLite에 남습니다. `SYNK_STUDIO_DATA` 또는 `.runtime/studio.json`으로 위치를 지정합니다. 현재 PC의 앱 경로 차이는 실제 파일 경로를 확인해 연결했습니다. 원음·사건·판정·효과 원장의 갱신은 한 트랜잭션으로 처리합니다.

효과 원장은 어떤 사건이 어느 판본의 근거를 유지·철회·정정했는지 기록합니다. 앞뒤 내용 지문을 연결해 기록 간 일관성을 검사합니다. 외부 서명·신뢰 시각 인증은 아닙니다. 내려받은 파일은 서버 없이 재현할 수 있습니다.

```powershell
node tools/patent-studio/projection-replay.cjs '내려받은-기록.json'
```

판정 코드와 관련 입력 지문이 같을 때만 이전 효과 결과를 재사용합니다. 입력 지문 비교·관측 계획·저장까지 사라지는 것은 아닙니다. 측정 범위는 [검증 기록](VERIFICATION.md)을 따릅니다.

## 개발·다른 PC 준비

Node.js 24 이상, 승인 자산 원천과 package.json 의존성이 필요합니다. `node tools/patent-studio/server.cjs`로 직접 실행할 수도 있습니다. 다른 PC에서는 호환 Python 환경과 모델 파일을 먼저 준비합니다. 현재 사용판은 faster-whisper 1.2.1, CTranslate2 4.8.2, PyAV 18.1.0, Python 3.12.14입니다.

```powershell
node tools/patent-studio/prepare-local.cjs --python 'Python실행파일' --model '모델폴더' --data '자료폴더'
node tools/patent-studio/verify-runtime.cjs
npm test --prefix tools/patent-studio
node tools/patent-studio/browser-live-qa.cjs
node tools/patent-studio/projection-benchmark.cjs
```

prepare-local은 이미 설치된 파일을 검사·연결하며 설치나 모델 다운로드를 대신하지 않습니다. 안내 파일만 복사하면 실행 환경이 함께 이동하지 않습니다. 합성 샘플 생성은 `make-samples.ps1`입니다. 런타임 설정·음성·검증 출력은 Git에서 제외합니다.

| 파일 | 책임 |
|---|---|
| core.cjs / projection.cjs | 용도·능력·시점별 판단 / 영향받은 효과 계산·전후 기록·재현 |
| store.cjs | 원음 불변 참조, SQLite 저장, 판본·중복 방지, 효과 원장 |
| transcriber.cjs / resilient-transcriber.cjs | 기존 외부 전사 계약 / 명시한 경로 선택·실패 처리 |
| local-transcriber.cjs / local-stt-worker.py | 실제 로컬 인식, 원음·모델 지문 검증 |
| server.cjs / public/ | HTTP·사전검사 / 녹음·확인·도움·판정 화면 |
| API.md / INTEGRATION.md | 데이터 계약 / 기존 제품의 연결 위치와 남은 범위 |
| PATENT-EVIDENCE.md / VERIFICATION.md | 선행기술 대조·출원 설명 후보 / 현재 구현·검증 증거 |

의미 판정은 지정된 한국어 통제 문항의 조사·역할·과거형 범위입니다. 제품 학생 DB·Apps Script·Supabase에는 아직 연결하지 않았습니다. 학습 효과·음성 인식 정확도·특허 등록 가능성을 시험 통과 수로 측정하지 않습니다.
