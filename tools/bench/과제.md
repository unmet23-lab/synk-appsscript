# 과제 — 녹화 파일 요약 함수

이 저장소(ARC-AGI-3-Agents)에 새 파일 **`agents/recordings_summary.py`** 를 만들어라.

## 만들 것

공개 함수 **하나**:

```python
def summarize_recordings(recordings_dir: str) -> dict:
```

## 입력

`recordings_dir` 안에서 **`.recording.jsonl`로 끝나는 파일만** 대상으로 한다(다른 파일·하위 디렉터리는 무시).

각 파일은 JSONL이다 — 한 줄에 JSON 객체 하나이고, 형태는 `{"timestamp": "...", "data": {...}}` 이다.

파일명 규칙은 이 저장소의 `agents/recorder.py`가 만드는 것을 따른다:

```
<game>.<agent>.<count>.<guid>.recording.jsonl
```

앞부분에 점이 더 있을 수 있다. `guid`는 확장자를 뺀 뒤 **뒤에서 세 번째 조각**이고, `game`은 **첫 조각**이다.

## 반환값

```python
{
  "files": int,        # 처리한 .recording.jsonl 파일 수
  "events": int,       # 성공적으로 파싱한 줄의 총합
  "malformed": int,    # JSON 파싱에 실패한 줄의 총합
  "games": dict,       # {게임이름: 그 게임의 파일 수}
  "sessions": list,    # 아래 형태, "file" 기준 오름차순 정렬
}
```

`sessions`의 각 항목:

```python
{"file": 파일명, "game": str, "guid": str, "events": int}
```

## 규칙 (채점 대상)

1. **깨진 줄이 있어도 예외를 던지지 않는다.** 건너뛰고 `malformed`로 센다.
2. **빈 줄·공백뿐인 줄은 무시한다** — `malformed`로 세지 않는다.
3. **디렉터리가 없으면 예외 대신** 모든 값이 0/빈 값인 dict를 반환한다.
4. **표준 라이브러리만 쓴다.** 새 의존성을 추가하지 않는다.
5. **파일명 파싱을 새로 짜지 말고**, 이 저장소에 이미 있는 `Recorder`의 기존 클래스메서드를 **재사용**한다.
6. 파일 하나를 읽다 실패해도(권한·인코딩 등) 나머지 파일 처리는 계속한다.

## 제출

- 파일 하나만 추가한다: `agents/recordings_summary.py`
- 기존 파일은 수정하지 않는다.
- 완료되면 끝낸다. 커밋은 하지 않아도 된다.
