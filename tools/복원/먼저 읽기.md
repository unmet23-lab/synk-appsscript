# 노트북을 잃어버렸을 때 — 먼저 읽기

이 꾸러미는 유호님과 AI가 쌓은 작업 방식(메모 · 설정 · 스킬 · 문서 · 복원 도구)입니다. 평문이라 복호화 암호를 잊어도 읽을 수 있습니다. 비밀번호와 키는 여기 없습니다.

## 잃어버린 직후 30분 (도난이면 복원보다 먼저)

휴대폰이나 다른 기기로 합니다.

1. **구글 두 계정**(unmet23 · 77yuhbs): 계정 → 보안 → 내 기기 → 그 노트북 로그아웃. 복구 연락처와 비밀번호도 확인합니다.
2. **GitHub**: Settings → Sessions에서 그 기기 세션을 끊고, SSH and GPG keys에서 그 노트북 키를 지웁니다.
3. **Microsoft · Claude · ChatGPT**: 계정의 기기 · 세션 목록에서 로그아웃합니다.
4. 노트북이 켜진 채 없어졌다면 **서버 SSH 키와 API 키 교체**도 합니다. 새 노트북에서 복원한 뒤 Claude에게 「키 교체해줘」라고 하면 `SYNK_보안` 목록대로 진행합니다. 꺼진 채 없어졌다면 C: · D:는 BitLocker로 잠겨 있습니다.

## 새 노트북에서

1. **Windows를 같은 Microsoft 계정으로 설치합니다.** 사용자 폴더가 `C:\Users\q1212`여야 도구 경로가 그대로 맞습니다.
2. **이 꾸러미를 받습니다.** 둘 중 하나면 됩니다.
   - GitHub `unmet23-lab/synk-memory` → Code → Download ZIP
   - 구글 드라이브 unmet23 → `SYNK_복원/작업방식/작업방식-최신.zip`
3. **압축을 풀고 `복원 시작.cmd`를 더블클릭합니다.** 프로그램 설치 → GitHub · 드라이브 로그인 → 저장소 받기 → 메모 · 설정 제자리 → 열쇠 풀기(복호화 암호 한 번) → 비공개 문서 받기 → 예약 작업 등록(꺼진 채) → 점검표 순서로 돕니다. 여러 번 돌려도 되고, 있는 파일은 덮지 않습니다.
4. **Claude 앱에 로그인하고 `Documents\SYNK-appsscript`에서 세션을 엽니다.** 메모가 그대로 읽힙니다. 남은 일은 Claude에게 맡기면 됩니다.
5. **옛 노트북이 안 도는 것을 확인한 뒤 예약 작업을 켭니다.** `복원 시작.cmd -예약켜기`. 둘 다 돌면 SNS가 두 번 나갑니다.

대화 기록(약 32GB)은 시간이 있을 때 `복원 시작.cmd -대화기록`으로, 회사 서버를 배포해야 하면 `복원 시작.cmd -릴리스계보`(약 8GB)로 받습니다. 큰 원본(영상 · LoRA 등)은 필요할 때 받습니다(`SYNK_원본창고` 복원 목록). 헤르메스 상태는 `SYNK_원본창고/헤르메스-백업`의 최신 암호문을 풀어 `%LOCALAPPDATA%\hermes`에 놓고 `tools/hermes-synk`의 `install-automation.cjs --apply`를 돌립니다.

## 어디에 무엇이 있나

| 묶음 | GitHub 비공개 `synk-memory` | unmet23 `SYNK_복원` | 77yuhbs `SYNK_복원` |
|---|---|---|---|
| 작업 방식(이 꾸러미) | 평문 · 이력 · 30분마다 | 평문 zip · 3시간마다 · 날짜별 | 암호 zip · 3시간마다 · 날짜별 |
| 열쇠(키 · 자격 · 환경 변수) | 없음 | 암호문 · 바뀔 때 | 암호문 · 바뀔 때 |
| 비공개 문서(보관함 · 메일 · 서류) · 창고 장부 | 없음 | 암호문 · 매일 | 암호문 · 매일 |
| 작업 기록(커밋 전 소스 포함) · 릴리스 계보 · 대화 기록 | 없음 | 없음 | 암호문 · 매일 |
| 큰 원본 | 없음 | 금고 몫만(`SYNK_금고`) | `SYNK_원본창고` |

복호화에는 `비밀키_잠금.json`(드라이브 `SYNK_복원/열쇠`, `SYNK_금고/열쇠`에 있음)과 **유호님이 아는 암호**가 필요합니다. 암호를 잊으면 암호문은 풀 수 없고, 작업 방식 층만 남습니다.

자세한 내용은 `문서/SYNK-appsscript/docs/컴퓨터를 잃어버렸을 때.md`에 있습니다.
