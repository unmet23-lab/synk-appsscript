# 업종 반응 브리핑

PULSE가 상담 전에 클라이언트 업종을 미리 알고 들어가고, 클라이언트에게 첫 선물로 주는 한 장짜리 「업종 반응 브리핑」을 만든다. 숫자는 코드가 공개 자료에서 세고, Claude(API 크레딧)는 댓글·제목·광고 문구 나누기와 해석 글만 한다. 글에는 숫자를 직접 못 쓰고 `{{지표}}` 자리표시자만 넣는다(검사로 막는다).

- 처음 견본과 결과: [docs/마케팅/PULSE_반응브리핑/README.md](../../docs/마케팅/PULSE_반응브리핑/README.md)
- 설계 · Fable 설계 검토 반영: [도구_설계.md](../../docs/마케팅/PULSE_반응브리핑/도구_설계.md)

## 쓰는 법

```
node tools/업종브리핑/브리핑.js 돌리기 <설정 이름> [--받는사람 "…"] [--날짜 YYYY-MM-DD] [--다시 <단계>] [--건너뛰기 네이버,메타] [--한도무시]
node tools/업종브리핑/브리핑.js 검사 <설정 이름> [--날짜 …]          네트워크 없이 다시 세어 지표 · 글 · 페이지 대조
node tools/업종브리핑/브리핑.js 분류찾기 <낱말…> [--새로]             네이버 쇼핑 분류 id(처음 한 번 분류 나무를 ego로 받아 둔다)
node tools/업종브리핑/브리핑.js 새업종 "<업종>" [--이름 <파일 이름>]   설정 초안(Claude) → .tmp/업종브리핑/_설정초안/, 확인 뒤 설정/로 옮긴다
node --test tests/업종브리핑.test.js
```

단계는 유튜브 → 네이버 → 메타 → 나누기 → 집계 → 글 → 그리기. 결과는 `<공용 작업본>/.tmp/업종브리핑/<설정 이름>/<날짜>/`(git 밖)에 단계마다 JSON으로 남는다. 이미 끝난 단계는 건너뛰고, 한 단계가 새로 돌면 그 뒤는 모두 다시 돈다. 마지막에 `브리핑.html`(혼자 여는 판)과 `브리핑_조각.html`(아티팩트로 올리는 판). 페이지 꼴(10-31): 상자 없이 크기 · 회색 · 얇은 선(결), 그래프는 [그래프 문법](../../docs/디자인/그래프_문법.md) — 연령 · 튄 비율 · 광고 문구는 빗금 막대(튄 비율은 전체 평균 점선), 주별 검색은 첫 검색어만 PULSE 베리(좁은 판에는 너비 360 판을 따로), 「가장 크게 튄 영상」은 좁은 판에서 두 줄 카드. 결 · 빗금 막대 · 조사 맞춤(자리표시자 뒤 조사를 값의 끝소리로)은 `그리기.js`에 있고 반응 리포트가 같이 쓴다. 시험판: [여성 겨울 아우터](https://claude.ai/artifact/EVzzWbEdVKf5ihXxfMBDY3).

| 단계 | 쓰는 것 | 막히면 |
|---|---|---|
| 유튜브 | YouTube Data API(수요 스캔 `API부르개`, LAB 자격, 읽기만) | 「못 읽음」 — 영상 · 댓글 칸이 빈다 |
| 네이버 | ego(lite) 안 데이터랩 `page.fetch`(10분 상한) | 쇼핑 · 검색 갈래마다 따로 「못 읽음」 |
| 메타 | ego(lite) 안 광고 라이브러리(6분 상한) | 광고 칸이 빈다 |
| 나누기 | Claude Opus 5.5 effort low, 지문 캐시 | 반으로 쪼개 다시 → 끝내 안 되면 낱말 규칙(페이지에 수를 밝힘) |
| 글 | Claude Opus 5.5 effort high, 검사 세 번 | 숫자만 담은 페이지 + 까닭 |

## 설정(`설정/<이름>.json`) — 업종 몫만

`업종` · `유튜브{검색어[≤15], 창일, 최소조회, 제외낱말[], 댓글영상}` · `네이버{성별, 검색어묶음[≤5]{이름, 낱말[]}, 분류{cid, 이름, 하위[]}, 강조연령?}` · `메타{검색어[], 플랫폼낱말[]}` · `주제{댓글고유[], 영상고유[], 광고고유[]}`(각 `{이름, 설명, 낱말?}`) · `제안관점`.

받는 사람(고객사 이름)은 넣지 않는다 — 공개 저장소다. `--받는사람`으로 주면 그 실행 폴더에 남는다.

## 몫과 안전

- 유튜브: LAB 프로젝트 하루 1만 단위를 업로드 · 수요 스캔과 나눠 쓴다. 한 번에 1,500 안팎(검색어 × 100이 대부분), 같은 날 다시 돌리면 검색은 캐시로. 이 도구 몫은 태평양 날짜 하루 3,000단위까지(장부 `.tmp/업종브리핑/_유튜브단위.jsonl`).
- Claude: `tools/lib/클로드키.js` 크레딧 키(무료 몫). 나누기 10번 안팎 + 글 1~3번.
- 남의 자료: 페이지에는 영상 제목 · 채널명 · 숫자 · 주소 · 광고주 이름 · 게재 일수까지. 댓글 원문 · 광고 문구 · 쓴 사람 · 영상 설명은 실행 폴더(git 밖)에만, 댓글 예시는 뜻만 옮긴다.
- 남에게 보내기 · 게시는 도구가 하지 않는다. 실제 고객에게 처음 주는 페이지는 화면 검수를 한 번 받는다.
- 수집 함정은 [현장 노트 · 수집](../../docs/현장노트/수집_yt-dlp.md#네이버-데이터랩).
