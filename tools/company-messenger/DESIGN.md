# 메신저 화면 개편 · 2026-09-27

사용자가 기존 화면의 장식과 구성이 조잡하다고 평가하고, Recent의 디자인 사례를 참고한 전체 개편과 홈페이지에서 작업 중인 ‘싱ㅋ’ 타이포그래피 적용을 요청했다.

## 직접 확인한 참고 화면

- [Recent Interface](https://recent.design/?category=interface): 여백으로 나눈 탐색, 읽기 쉬운 작은 제목과 명확한 현재 위치.
- [Sidebar Active State](https://recent.design/i/9e89xf0-design-guidelines-app-ui): 내비게이션의 정렬, 절제된 선택 면, hover와 선택 전환. 상세 페이지의 화면과 설명을 브라우저에서 확인했다.
- [Linear UI Components](https://recent.design/i/e58rcty-linear-ui-components): 일관된 아이콘 크기, 도구를 묶는 간격, 간결한 상태 표시. 어두운 색 구성 대신 조작부의 위계와 밀도를 참고했다.

참고 작품의 이미지와 코드를 가져오지 않는다. 흰색·검정·중성 회색을 바탕으로 채팅을 읽고 파일을 보내는 동작에 맞게 직접 구현한다. 정보 구분은 여백과 정렬을 먼저 쓰고, 카드·테두리·색·그림자의 중복을 줄인다.

`public/assets/synk-ko.svg`는 `C:/Users/q1212/Documents/SYNK-website/compose-sites.mjs`의 `.hangul-wordmark` SVG에 있는 4개 path를 그대로 옮긴 것이다. 원본 viewBox `0 0 560 328`, 색 `#090a09`, 가로세로 비율을 유지한다. 서체로 비슷하게 재현하거나 첨부 이미지를 잘라 쓰지 않았다.

이 사용 승인은 이번 메신저 화면과 현재 홈페이지 시안에 해당한다. 전사 브랜드 정본이나 공개 홈페이지의 배포 상태를 변경하지 않는다. 본문은 기존 로컬 SUIT·Inter Tight, 숫자는 DM Mono를 사용한다.

## 구성 기준

- 탐색: 워드마크, 워크스페이스, 검색, 채널, 프로필을 분명한 층위로 구분한다.
- 대화: 제목과 도구모음은 간결하게, 메시지와 작성 영역은 충분한 읽기 폭으로 구성한다. 빈 화면의 중복 환영 카드는 없앤다.
- 파일·검색: 파일 이름과 대화 문맥을 우선하고, 저장 위치·크기·시간은 보조 정보로 표시한다.
- 설정: 통계와 Drive 계정·용량·저장소 선택을 차례로 읽을 수 있게 정돈한다.
- 인증: ‘싱ㅋ’ 타이포그래피와 하나의 명확한 입력 폼으로 구성한다.
- 상태: hover·키보드 초점·오류·로딩·비활성·선택 상태를 구분하며 `prefers-reduced-motion`을 지원한다.

실제 대화·계정·Drive 연결은 기존 데이터를 유지한다. 검사용 내용은 임시 DB에만 넣고, 기능과 화면 검증은 [QA.md](QA.md)에 기록한다.
