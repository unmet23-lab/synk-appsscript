## 어떻게 일하나 — 실수는 기계가 막는다

이 저장소의 코드는 대부분 **AI 코딩 도구가 썼고, 방향과 판정은 사람이 쥔다.**
그래서 「AI 가 실수하면 어떻게 되나」를 사람의 주의력이 아니라 **기계로** 막는다.

### 기계가 막는 넷

| 무엇 | 왜 |
|---|---|
| **배포 통로 하나** | 라이브로 가는 길은 `/deploy` 하나뿐. 손으로 올리는 명령은 훅이 차단한다 |
| **커밋 범위 못박기** | 경로를 지정하지 않은 커밋을 막는다 — 여러 작업이 동시에 도는 저장소라 남의 파일이 섞이면 안 된다 |
| **자격증명 화면** | 비밀번호·토큰 입력 화면에 AI 가 손대지 못하게 한다 |
| **학생 접점 말투** | 학생·학부모가 읽을 글을 고칠 때 브랜드 말투 규칙을 검사한다 |

훅 실물은 [`.claude/hooks/`](.claude/hooks) · 규칙은 [`.claude/rules/`](.claude/rules) 에 있다.

### 그 밖의 규율

- **지침이 코드처럼 산다** — [`CLAUDE.md`](CLAUDE.md) 가 작업 규칙의 정본이고, 경로별 규칙은 그 경로를 만질 때만 실린다.
- **다른 회사 AI 로 교차 검수** — 배포 전에 다른 벤더의 도구가 같은 변경을 다시 본다(`tools/codex-review.js`).
- **수는 자와 함께 적는다** — 「몇 건」을 적을 때 «무엇으로 셌는지»를 같이 적는 것이 이 저장소의 규율이다. 못 잰 것은 「없다」가 아니라 「안 재봤다」로 적는다.
- **여러 작업이 동시에 돈다** — git worktree 로 갈라 짓고, 공용 장부는 고치는 즉시 커밋한다.

## 처음 여는 사람

```bash
node tools/test-ci.js          # 회귀 시험 전량 (CI 와 같은 것)
node --test tests/             # 시험만 빠르게
node tools/결정.js              # 무엇이 확정돼 있나
```

라이브 배포는 `/deploy` 하나로만 한다 — 손으로 `clasp push` 하면 훅이 막는다.

## 여기 없는 것

이 저장소는 **만드는 일**을 담는다. 담지 않는 것이 셋 있다.

- **학생을 식별하는 데이터** — 어떤 이유로도 저장소에 들어오지 않는다.
- **자격증명** — 열쇠·토큰은 git 의 눈 밖에 있고, 커밋 훅이 실수로 들어오는 것을 막는다.
- **사업 수치** — 매출·수강료 같은 것은 이 저장소가 보여주려는 것이 아니다.
