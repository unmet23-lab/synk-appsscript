# 몽골어 문법 평가 — 기존 시험과 측정 이력

14개 문항으로 제품용 몽골어 문법 검사의 결함 탐지와 헛경보를 비교하던 평가 묶음이다. GPT·Claude의 작업 모델 선택기나 새 작업의 필수 검수 절차가 아니다. 현재 역할·하네스·비용은 [AI 운영 원칙](../docs/AI_운영원칙.md)을 따른다. 모델·요금·할당량·예약의 과거 관측은 오늘 가동하거나 무료라는 증거가 아니다.

## 보존하는 계약

- 실제 수정 이력의 고치기 전 7개와 고친 뒤 7개를 사용한다. 각 YAML 문항의 커밋·파일·기대 판정을 보존한다. 사람이 확정한 새 사례는 원문 근거와 함께 추가할 수 있다.
- JSON 모양, 정상/어색/파손 판정, 입력에 실제 존재하는 키릴 문장 인용을 결정적으로 채점한다. 답·결과 파일이 없으면 통과가 아니라 확인 불가다. AI 심판은 사용하지 않는다.
- 이 시험의 정답은 과거 수정 판단이며 원어민의 전체 감수·학생 학습 효과를 대신하지 않는다. 14문항의 차이나 단일 회차로 모델 전반의 우열을 확정하지 않는다.
- 모델·인증 경로는 제품용 `tools/모델정책.js`, 프롬프트·스키마는 `tools/몽골어대조.js`에서 읽는다. 보존한 promptfoo 판은 0.122.2다. 다른 작업용 모델 설정을 이 값으로 덮지 않는다.
- 과거 말투 검사·세션 훅·자동 반복 시험을 복원하지 않는다. 새 호출이나 예약은 해당 요청 범위와 현재 비용 기준을 따른다.

## 실행과 부작용

| 명령 | 범위 |
|---|---|
| `node evals/검문자.js --자체점검` | 프롬프트·스키마의 로컬 일치 확인. 외부 모델 호출 없음 |
| `node evals/의심줄.js` | 기존 결과에서 판정 불일치·모델 간 차이·결과 없음·근거 채점 실패를 표시. 누락 결과를 0건 성공으로 바꾸지 않음 |
| `node evals/돌리기.js` | 기존 AI Studio 경로로 실제 API를 호출. 모델·현재 한도·자격 및 실행 범위 확인이 필요 |
| `node evals/돌리기.js --재보기` | 텍스트 추론 프로브 1회. 읽기 전용 상태 조회가 아님 |
| `node evals/돌리기.js --문항 4` | 앞 4개 문항으로 실제 호출 범위를 제한 |
| `node evals/돌리기.js --돈 --유료-api` | Vertex 종량제/크레딧을 쓰는 명시 실행. 예상 비용과 사용자 승인 확인 후에만 실행 |

실행기는 정본 일치→실제 프로브→예상 호출 수를 확인한다. 재실행은 새 호출이며 promptfoo 캐시를 쓴다고 가정하지 않는다. 예전 20회 관측값은 현재 할당량이 아니다. 프로브 성공도 크레딧 잔액·카드 청구·무료 여부의 증거가 아니다. 자격값·토큰을 출력하거나 저장소에 넣지 않는다.

`_결과/`의 응답 전문은 Git에서 제외한다. `_판정/gemini-3.8-flash.json`의 숫자는 한 회차 표지이며 다른 회차와 변동성을 지우는 최종 성적표가 아니다. 이 README나 옛 코드 주석만으로 Windows 예약 작업·GitHub Actions가 지금 등록·활성 상태라고 판단하지 않는다.

평가하지 않은 범위는 역번역 전체, 원어민 감수의 전체 정답지, 실제 학생 효과, 현재 분당·일일 한도다. 폐기된 말투 검사층은 평가할 누락 기능으로 되살리지 않는다.
