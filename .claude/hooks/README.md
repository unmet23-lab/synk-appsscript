# 남아 있는 공용 코드

2026-09-21 현재 프로젝트 `.claude/settings.json`은 `{}`이며 이 폴더의 SYNK 훅을 자동 등록하지 않는다. 폴더가 있다는 이유로 세션 훅을 복원하지 않는다.

- `clasp-guard.js`·`credential-guard.js`·`git-scope-guard.js`: 기존 수동 검사와 회귀 시험에서 사용하는 코드다.
- `philosophy-card.js`·`review-runs.js`: 선택해서 실행하는 검수 도구와 시험이 사용한다.
- `lib/`: 배포 대상·형제 저장소·작업본·검수 기록을 다루는 공용 모듈이다. 현재 배포·자산·계약 검사 도구의 의존성이 있어 보존한다.

자동으로 GPT·Claude 역할을 나누거나 작업 승인을 요구하는 시스템이 아니다. 공통 작업 기준은 [AI 운영 원칙](../../docs/AI_운영원칙.md), 삭제·보존 내역은 [점검 결과](../../docs/_ops/협업장치_정리_20260921.md)를 읽는다.
