# /close — 세션 끊기 파이프라인

> 2026-08-21 압축판 — 대개편(08-19~20) 이후 낡은 배선(죽은 훅 언급·보드 철거 사연·옛 인계문 절차)을 걷었다. 이전 판과 실측 근거 전문은 git 이력에 있다.

**끊을지는 유호님이 정한다. 이 스킬은 「끊기로 했다」 다음부터를 맡는다.**

세션 간에 넘어가는 것은 셋뿐 — ①커밋 ②PR 본문(안 끝난 트랙의 다음 할 일) ③메모리. 대화 맥락은 안 넘어간다. 인계문 파일은 없다: 다음 세션은 «받는» 게 아니라 하네스로 «찾는다»(`list_sessions` · `search_session_transcripts` · `send_message`). 그래서 이 스킬이 채우는 것은 위 셋 + 찾을 단서(세션 제목)다. **하나라도 비면 다음 세션이 처음부터 다시 판단한다.**

## 절차 (순서 엄수)

### 1. 상태 실측
`git status` **전문** — `--short` 금지(rebase 진행 중을 감춘다 · F035). rebase·merge 중이면 멈추고 유호님께 보고 — 끊으면 안 되는 상태다. 이어 `git log --oneline -10`으로 다른 세션이 그 사이 밀어넣은 커밋을 본다.

### 2. 내 것과 남의 것을 가른다
미커밋 전부를 내 것으로 가정하지 않는다. 판별 순서: `list_sessions`로 지금 도는 세션을 본다(그 세션이 만지는 자리면 남의 것, 손대지 않는다) → 이 대화에서 내가 편집한 파일이면 내 것 → 애매하면 `git diff <파일>`로 보고, 그래도 애매하면 유호님께 묻는다. 남의 미커밋은 그대로 두고 보고에 1줄로 명시한다.

### 3. 커밋 — 범위를 못 박는다
```bash
git commit -F <메시지파일> -- 경로1 경로2
```
- 메시지는 스크래치패드에 파일로 쓰고 `-F`로 넘긴다(여러 줄·따옴표를 셸에 맡기지 않는다). `add`/`commit`을 나누지 않는다 — 그 틈에 남의 스테이징이 얹힌다(`add -A`·`commit -a`는 git-scope-guard가 차단).
- 성격이 다른 변경이 섞였으면 `git diff --stat` 전량을 보고 분리 커밋한다.
- **Apps Script 코드(Code.js·contents_*.js)를 고쳤으면 여기서 멈추고 `/deploy`를 먼저 돌린다** — 커밋만 하면 GitHub과 라이브가 어긋난다.
- 커밋 뒤 `git log -1`로 내 것이 실제로 들어갔는지 확인한다 — 동시 세션이 있으면 커밋이 조용히 no-op이 될 수 있다(F071).
- push 뒤 `node tools/원격ci.js` — 결과(초록·적색·대기·미검증)를 마지막 보고에 그대로 적는다. 초록이 아닌 채 닫으면 다음 세션이 그 상태를 물려받는다(F175: run 0건은 화면에서 초록과 같은 모양이다).

### 3-b. SYNK-talk 배포와 갈렸나 — 「종결」을 적기 전에
이 세션이 `supabase/functions/**`나 동봉으로 나가는 것(`lib/*.js`·`계약/*.json`)을 커밋했으면:
```bash
node -e "const p=require('./.claude/hooks/lib/형제저장소.js').형제경로(process.cwd()); require('child_process').execFileSync(process.execPath,[p+'/tools/배포빚.js'],{stdio:'inherit',cwd:p})"
# ⚠ `cd ../SYNK-talk` 로 적지 않는다 — 워크트리에서는 `..` 이 `.claude/worktrees/` 라 «없는 폴더»로 죽는다(08-26 실측)
```
- **「낡음 0」은 그 판 하나의 0이다** — `⚠ 이 실행이 안 본 판` 줄까지 읽는다(F207: 한 판의 초록을 두 판의 초록으로 읽으면 그 「종결」이 거짓이 된다).
- 낡은 판이 **있을 때만** `node tools/배포대조.js`로 바이트 실측한다(운영은 `SUPABASE_PROJECT_REF=<운영REF>` — 읽기에 `--운영`(쓰기 승인 키)을 붙이지 않는다 · F462). 종료코드 0=같다 · 1=낡았다 · 2=미측정. 「모름」 중 「라이브에 없다」(404)는 다시 재도 같다 — 처방은 대조가 아니라 배포다(F579).
- 다르면 그건 「종결」이 아니다 — 재배포하거나, 못 하면 **마지막 보고와 열린 PR 본문에 「⛔배포 0」과 막힌 이유**를 적는다. 못 쟀으면(2) 「초록」이 아니라 「못 쟀다」로 적는다 — 미실행과 통과는 같은 모양이다.

### 3-c. 워크트리에서 일했으면 열린 PR을 닫는다
```bash
node tools/작업가지.js --닫기    # push → merge → 원격 가지 거둠 · 끝나면 ExitWorktree(remove)
```
- 미커밋이 있으면 도구가 거절한다 — 3단계로 돌아가 커밋한다(그 거절이 F403 워크트리 갇힘을 막는다).
- **트랙이 안 끝났으면 닫지 않는다** — PR을 연 채 **본문 첫 줄에 다음 할 일 1줄**을 적는다. 열린 PR이 트랙 선언의 정본이고(유호 확정 08-15 「PR = 작업 목록」), 다음 세션은 `gh pr list`와 `list_sessions`의 `prNumber`로 본다. 단발 편집(master 직발)은 선언할 자리가 없는 게 맞다 — 끝난 일은 커밋 메시지가, 안 끝난 일은 마지막 보고의 1줄이 진다.
- ⚠ 세션이 죽으며 열어둔 채 남긴 PR을 짖는 훅은 **지금 없다**(08-21 실측: SessionStart 훅은 결정.js 요약 하나뿐). 닫거나 다음 할 일을 적는 자리는 여기뿐이다.

### 4. 메모리 — 굵직한 판정만
이 세션에서 **유호님 확정** · **재제안 금지 기각** · **방향을 바꾼 발견**이 있으면 메모리 파일에 쓰고 `MEMORY.md`에 한 줄 추가한다. 없으면 건너뛴다 — 대화에서만 의미 있는 것은 쓰지 않는다.
- 이미 있는 토픽이면 새 파일 말고 **그 파일을 제자리에서 갱신**한다 — 답 받은 대기(⏳)가 있으면 새 절을 덧붙이지 말고 그 줄 자체를 닫는다. 앞 절이 낡은 채 남으면 다음 세션이 그걸 현행으로 읽는다(F108).
- 유호님이 이 세션에서 정한 것이 `docs/_ops/결정.md`에 아직 없으면 지금 `node tools/결정.js --추가` — 원칙은 「정해진 그 자리에서」지만, 여기가 마지막 그물이다.

### 5. 장부 둘 — 각 15초
```bash
node tools/friction.js --이세션
```
종료코드 0=겹치는 행 없음 · 1=판정할 행 있음 · 2=못 쟀다(0건이 아니다). **1이면 행마다 셋 중 하나로 판정한다** — 「나중에」는 답이 아니다:
- **다 고쳤다** → 닫기 전 `node tools/변이.js <계획>`으로 신고 원문의 결함을 되넣어 회귀가 빨개지는지 본다(F083). 통과하면 `node tools/friction.js resolve F0NN "무엇이 실제로 막았나"`.
- **안 고쳤지만 지금 안 닫는다** → `node tools/friction.js defer F0NN "왜 지금 안 닫나"`.
- **파일만 겹쳤지 내 일이 아니다** → 지나간다(알림이지 차단이 아니다).

출력의 분모(「안 지목한 N」)가 크면 `--open`으로 직접 본다 — 파일을 안 적은 신고는 이 통로가 원리상 못 본다.

```bash
node tools/rot-check.js
```
「수리 필요 N건」이 **세션 시작 때보다 늘었으면** 늘어난 것만 그 자리에서 걷는다 — 대부분 내가 지운 파일을 가리킨 채 남은 문서다(깨진 링크·낡은 인용). 기존분은 내 것이 아니다 — 세지 말고 넘어간다.

### 6. 제목 + 마지막 보고
1. `set_session_title`로 짧고 특정적인 제목을 단다(예: 「마스코트 정본 경로 수렴」) — 다음 세션이 `list_sessions`로 이 세션을 찾는 유일한 단서다.
2. 유호님께 마지막으로 보고한다:
   - 커밋한 것(해시 + 한 줄) · 원격 CI 결과
   - 트랙 상태(PR을 닫았는지 · 열어 뒀으면 다음 할 일 1줄을 어디에 남겼는지)
   - 메모리 저장 여부 · 남의 미커밋이 남아 있으면 그 사실
   - **「이제 창을 닫고 새로 여세요(또는 `/clear`)」** — 붙여넣을 인계 블록은 없다.

## 금지
- 미커밋을 남긴 채 「끊어도 된다」고 말하기 — 미추적 파일은 이력·stash·reflog 어디에도 없는 유일한 무보호 상태다(F025).
- 남의 미커밋 변경을 내 커밋에 쓸어담기.
- 끝난 트랙을 **말로만** 끝내기 — 커밋 메시지나 PR 본문에 안 남은 종결은 다음 세션에게 없는 일이다.
- 세션을 자동으로 끄려 시도하기 — 훅도 AI도 세션을 못 끈다(`continue:false`도 턴만 멈춘다). 마지막은 유호님이 창을 닫는다.

## 왜 컴팩트가 아니라 종료인가
실측(08-04, 08-20 압축 후 재확인)으로 컴팩트 도달점이 새 세션 시작점보다 컸고 요약 손실까지 붙는다 — 이 저장소에서 컴팩트는 세션 재시작보다 열등하다.
