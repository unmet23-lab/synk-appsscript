## 🤖 이제는 알아서 알려준다 — 사람이 안 물어도 된다

`tools/스킬판점검.js` 가 **세션을 열 때마다** 걸린다. 하는 일은 하나 — 위 표의 저장소·폴더를
상류에 물어 **「그 폴더가 마지막으로 바뀐 커밋」**을 받아 우리 기준선과 견준다.

- **평소에는 아무 말도 안 한다.** 7일 안에 이미 쟀으면 바깥에 묻지도 않는다(세션이 안 느려진다).
- **원본이 움직이면 그때만 운다** — 「스킬 N벌의 원본이 움직였다」 한 줄. **막지는 않는다.**
- **못 재면 「없다」가 아니라 「확인 불가」라고 말한다.** 도구가 없거나 인터넷이 안 되면
  「다 최신」이라고 거짓말하지 않는다.

봤고 처리했으면 도장을 찍어 기준선을 지금으로 옮긴다:

```bash
node tools/스킬판점검.js --도장
```

지금 당장 전부 보고 싶으면 인자 없이 부른다:

```bash
node tools/스킬판점검.js
```

기준선 장부 = `docs/_ops/스킬판장부.json`(기계가 쓴다 · 손으로 고치지 않는다).

🔴 **판번호를 믿지 않는 까닭**: 우리 `last30days` 는 `3.18.4` 라 적혀 있었지만 상류 딱지 `v3.18.4` 와
22벌이 달랐다 — 딱지가 아니라 **그때의 최신본**을 떴기 때문이다. 그래서 이 자는 번호가 아니라
**커밋**을 견준다.

## 다시 재는 법 — 셋이면 끝난다

**① 상류를 임시 폴더에 받는다** (저장소 안에 받지 않는다):

```bash
cd "$(node -p 'require("os").tmpdir()')" && git clone --depth 1 https://github.com/emilkowalski/skills 대조용
```

remotion 처럼 큰 저장소는 필요한 폴더만:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/remotion-dev/remotion r && cd r && git sparse-checkout set packages/skills
```

**② 줄끝을 고르고 지문을 견준다.** 이 저장소는 작업본이 CRLF 라, 그냥 견주면 **내용이 같아도 전부 다르게 나온다**:

```bash
diff <(tr -d '\r' < 우리것) <(tr -d '\r' < 원본것)
```

**③ 다른 파일이 나오면 「누가 고쳤나」를 가른다.** 우리 손인지 상류 변화인지는 git 이력이 답한다:

```bash
git log --format="%h %ci %s" -- .claude/skills/<스킬>/<파일>
```

반입 커밋 하나만 나오면 **우리는 안 고쳤다** → 상류 변화이니 받아온다.
그 뒤 커밋이 더 있으면 우리 개조다 → 골라서 옮기고, 이 표의 「우리가 고친 것」 칸을 갱신한다.
