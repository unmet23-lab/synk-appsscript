# /missed — 놓친 작업만 회수

`/afk` 의 자매 스킬. **다른 건 딱 하나 — 일감 후보를 「놓친 것」으로만 좁힌다.**
실행 규약은 **`/afk` 의 §1(비켜서기) · §3(정지선·벽 기록) · §4(커밋) · §5(인계)** 를 그대로 따른다. 여기에 다시 적지 않는다 — 같은 판정을 두 곳에 적으면 갈라진다(CLAUDE.md 신뢰성 ④).
⚠ **§1 을 빠뜨리지 말 것** — 이 스킬은 `🎫`(남이 놓은 줄)를 집으므로 남의 작업본과 겹칠 확률이 `/afk` 보다 높다.

## 🔴 0. 반복은 `/loop` 이 만든다

```
/loop /missed 90        ← 실제로 90분을 채우는 형태
```

`/missed` 만 치면 일감 몇 개 하고 턴이 끝난다(`/afk` §0 과 같은 자리).

## 1. 「놓친 것」의 정의 — 기계적으로 못박는다

**이 넷이 뱉는 것만이 놓친 것이다.** 그 밖은 아무리 좋아 보여도 안 집는다 — 정의가 느슨해지는 순간 이 스킬은 `/afk` 의 복사본이 되고, 유호님이 「놓친 것만」이라고 못박은 이유가 사라진다.

```bash
gh pr list --state open                      # ① 열린 트랙 — 🎫 놓인 것 · 안 끝난 것
node tools/friction.js                       # ② 살아있는 마찰 F0NN (신고됐는데 미해소)
node tools/rot-check.js                      # ③ 수리 필요 · 낡음 · 인덱스 누락
node tools/원격ci.js                         # ④ 미검증·적색으로 남은 커밋 (옛 ④⑤ 결정 큐 갈래는 08-20 소멸)
```

🚫 **새 일감을 찾지 않는다.** 코드를 읽다 발견한 개선점·리팩터 기회는 이 스킬의 대상이 아니다(그건 큐에 기름을 붓는 쪽이다 · `loop-trigger-layer` 기각분).
🚫 **⏳ 유호님 답 대기는 「내가 놓친 것」이 아니다** — 그건 유호님 몫이라 정상적으로 기다리는 중이다. ④⑤ 만 예외인데, 그건 **유호님께 도달조차 못 한 것**이라 내 배달 실패다.

## 2. 집기 전에 — **왜 아직 안 됐나**부터 1줄

이 스킬의 급소다. 놓친 데는 이유가 있다. 이유를 안 보고 다시 집으면 **같은 벽에 또 막혀 창을 통째로 태운다**(그리고 다음 회수 때 또 집는다).

| 판정 | 처분 |
|---|---|
| **이유가 사라졌다** (남의 작업본이 풀렸다 · 적색 주인이 고쳤다 · 선행 트랙이 끝났다) | **최우선으로 집는다** — 지금이 유일하게 값싼 순간이다 |
| **이유가 그대로다** (여전히 승인 대기 · 여전히 남이 잡고 있다) | 집지 말고 **벽 기록만 갱신**(🎫·⏳). 다시 집으면 같은 실패의 반복이다 |
| **유효하지 않다** (전제가 죽었다 · 이미 다른 방식으로 해결됐다) | **닫기를 제안**한다 — 판정은 유호님 |

🚫 **나이로 자동 판정하지 않는다** — 자동 소멸·나이 만료·키워드 겹침 자동판별은 전부 기각됐다(memory `cleanup`). 오래됐다는 건 순위 재료지 처분 사유가 아니다.
🚫 **내가 닫지 않는다.** 「유효하지 않다」는 제안까지고, 실제로 죽이는 건 유호님 판정이다.

## 3. 회수한 것 / 못 한 것

- 회수 성공 → 그 항목을 **원래 장부에서 닫는다**(`friction.js` 해소 · rot-check 재실행으로 사라짐 확인 · `--버려진 --확인`). 고쳐놓고 장부를 안 닫으면 **다음 회수가 같은 걸 또 집는다.**
- 회수 실패 → `/afk` §3 그대로: 유호님 판정이 필요하면 **세션 끝 보고**에, 다른 세션이 이어받을 수 있으면 `🎫` 로 보고에(내 PR 이 열려 있으면 본문에도).
- **둘 다 아닌 채로 넘어가지 않는다** — 그러면 이 스킬이 「놓친 작업」을 새로 만드는 장치가 된다.

## 4. 마감 한 장

```
[MISSED 마감] 90분 · 후보 N건
✅ 회수 <건> — 장부도 닫았다
🔄 이유 그대로 <건> — 벽 갱신만(집지 않았다)
💀 닫기 제안 <건> — 유호님 판정
```

**분모를 밝힌다** — 「N건 중 몇 건」. 후보를 몇 개 봤는지 안 밝히면 0건 처리와 전량 처리가 같은 모양이다(CLAUDE.md: 초록은 분모와 함께만 읽는다).
