# 괜찮아요: 상황으로 읽기

- 상태: 제작 시안. 몽골어 원어민 감수 전이며 발행하지 않음.
- 브랜드: SYNK LAB. 인스타그램 4:5 캐러셀.
- 기존 「괜찮아요 다섯 뜻」 원고를 덮어쓰지 않는 별도 시안.
- 디자인: tools/캐러셀굽기.js의 현행 펠트 바탕·진행점·마스코트와 레이아웃을 재사용. 장식은 표지, 마스코트는 표지와 마지막 장.

## 카드 구성

1. 커피를 권했는데 “괜찮아요.” 마신다는 뜻일까요? 다음 장에서 상황을 확인.
2. 사양: 커피 드릴까요? / 아니요, 괜찮아요. 지금은 받지 않겠다는 뜻.
3. 받고 싶다면: 네, 주세요. “괜찮아요”만 말하는 것보다 뜻이 분명해져요.
4. 사과에 대한 답: 늦어서 미안해요. / 괜찮아요. 이때는 상대를 안심시키는 말.
5. 안부: 괜찮아요? / 네, 괜찮아요. 질문은 상대 상태를 묻고, 답은 자기 상태를 말해요.
6. 장면 선택: 더 드릴까요? 배가 부를 때 A 네, 주세요. B 아니요, 괜찮아요. 상황에 맞는 답을 선택.
7. 정답 B. 같은 표현도 상황과 앞뒤 말로 뜻이 달라져요. 커피를 권받으면 뭐라고 답할까요? 몽골어로 답해도 좋아요.

## 한국어 확인용 캡션

커피를 권받고 “괜찮아요”라고 하면, 마신다는 뜻일까요?

1. “커피 드릴까요?”에 “아니요, 괜찮아요.”라고 답하면 정중한 사양이에요.
2. 커피를 받고 싶다면 “네, 주세요.”라고 말해 보세요. 뜻이 더 분명해져요.
3. “늦어서 미안해요.”에 답하는 “괜찮아요.”는 상대를 안심시키는 말이에요.
4. “괜찮아요?”는 상대의 상태를 묻는 질문이에요.

표정 하나만으로 뜻을 정하지 말고, 상황과 앞뒤 말을 함께 보세요. 헷갈릴 때 다시 볼 수 있게 저장해 두세요.
커피를 권받으면 뭐라고 답할까요? 몽골어로 답해도 좋아요.

## 몽골어 캡션 초안

Танд кофе санал болгоход “괜찮아요” гэж хариулбал ууна гэсэн үг үү?

1. “커피 드릴까요?” гэсэн асуултад “아니요, 괜찮아요.” гэж хариулбал эелдгээр татгалзаж байна.
2. Кофе авахыг хүсвэл “네, 주세요.” гэж хэлээрэй. Ингэвэл санаа тань илүү тодорхой болно.
3. “늦어서 미안해요.” гэсний хариуд “괜찮아요.” гэж хэлбэл нөгөө хүнээ тайвшруулж байна.
4. “괜찮아요?” гэж асуувал нөгөө хүнийхээ бие, байдлыг асууж байна.

Зөвхөн нүүрний хувирлаар утгыг нь бүү шийдээрэй. Нөхцөл байдал болон өмнөх, дараах үгийг хамт анзаараарай. Дараа дахин харахын тулд хадгалаарай.
Танд кофе санал болговол та юу гэж хариулах вэ? Монголоор хариулж болно.

## 확인 범위

- 포맷 수요 검증: 공개 검색에서 반응 수치까지 확인 가능한 같은 포맷 사례를 확보하지 못함. 기본 캐러셀 형식을 사용함. 조회·저장·공유 수치를 지어내지 않음.
- 한국어 예문은 이 시안을 위해 작성함. 수락을 웃음만으로 판정하는 기존 예시는 사용하지 않음.
- 기존 원고의 원어민 감수 대기 조건은 해제하지 않음.
- 생성 이미지가 아니라 현행 카드 제작 도구의 자산을 조립함.
