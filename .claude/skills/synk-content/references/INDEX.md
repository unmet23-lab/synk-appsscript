# SYNK 콘텐츠 참고 자료

> **지위:** 이 폴더는 현재 제작 계획이 아니라 기존 원고·형식·작업 사례의 보관소다. 45개 리드크루 클립, 총 62편 묶음, 12개월 시즌표를 현재 편수·발행 주기·연간 일정으로 사용하지 않는다.

## 현재 작업의 출발점

1. `docs/마케팅_정본.md`에서 회사와 상대를 고른다.
2. `docs/마케팅/제작_인수기준.md`에서 현재 제작 방향과 기존 릴의 재사용 조건을 확인한다.
3. `docs/마케팅/채널과_발행.md`에서 계정 역할, 캡션, 게시 분담을 확인한다.
4. 행사라면 `docs/마케팅/LAB_행사.md`, 학생 글은 `synk-brand`, 시각물은 `DESIGN.md`를 적용한다.

장기 45편 추가 제작은 2026-09-09에 도움 제공형 릴 10편으로 교체됐다. 현재 결과와 제공물은 `docs/홍보물/릴10편_20260909/읽어주세요.md`에서 확인한다. 편수·형식·댓글 방식을 다른 작업의 영구 규칙으로 확대하지 않는다.

## 현재 결과와 가까운 참고물

- `계정별_20260909.md`: 계정별 원고. 실제 게시 여부와 분리한다.
- `까몽_제작이야기_20260909.md`: SHIFT 제작 이야기의 한국어 원고.
- `숏폼/`: 날짜가 붙은 최근 숏폼 원고. 해당 결과 문서와 함께 읽는다.
- `캐러셀/`: 개별 캐러셀 원고. 현재 회사·타겟·디자인 원문을 다시 확인한다.
- `페이스북카드_어학당대결_v1.md`: 해당 카드 작업을 이어갈 때만 읽는다.

## 역사적 재고 — 요청이나 현재 원문의 재사용 지시가 있을 때만

- `리드크루클립/`: 과거 45편 대본 재고. 현재 제작량이 아니다.
- `챌린지/월별_챌린지_12.md`: 과거 월별 기획. 모든 행사에 학습 산출을 강제하지 않는다.
- `시즌로테이션_12개월.md`: 폐기된 고정 연간 배치안. 현재 발행 캘린더가 아니다.
- `멀티유즈_앱퀴즈_40.md`: 과거 파생 퀴즈 재고. 현재 코드·스키마 확인 뒤에만 재사용한다.
- `제작가이드/`: 과거 형식별 제작 메모. 현재 제작 기준은 해당 폴더의 `INDEX.md`가 가리키는 원문이 우선한다.
- `카운트다운/`, `캐러셀/캐러셀_5세트.md`, `캐러셀/캐러셀_주제은행.md`: 아이디어 재고. 현재 발행 의무가 아니다.

재사용할 때는 문구·번역·권리·캐릭터·플랫폼 조건을 현재 원문으로 다시 검수하고, 로컬 원고를 게시 또는 성과로 보고하지 않는다.
