# SYNK 콘텐츠 참고 자료

현재 제작 원문은 [마케팅 정본](../../../../docs/마케팅_정본.md)과 해당 콘텐츠 프로젝트에서 찾는다. 이 폴더에 파일이 있다는 이유로 새 콘텐츠의 기본 원고나 제작 규격으로 사용하지 않는다.

## 2026-09-22 원고 정리

옛 리드크루 45편, 파생 카운트다운 2편, 앱 퀴즈 40문항과 해당 제작 가이드는 현재 재고에서 제거했다. 옛 계획을 같은 편수의 새 원고로 자동 교체하지 않는다. 새 콘텐츠는 실제 제작 목적·사용 화면·학습 상황에 맞춰 작성한다.

원문·파생 데이터·도구의 작업 전 사본은 Git과 로컬 비활성 백업에 남긴다. 복구용이며 현재 제작 입력으로 다시 읽지 않는다. 처리 범위는 [정리 기록](../../../../docs/_ops/말투강제_정리_20260921.md)에 있다.

## 남아 있는 개별 자료

- 날짜가 붙은 `숏폼/`·계정별 원고·제작 이야기: 해당 작업을 이어갈 때 현재 결과·게시 상태와 함께 확인한다.
- `캐러셀/`·페이스북 카드: 해당 카드의 과거 원고다. 지금 사용할지는 현재 요청과 제공 정보에 맞춰 판단한다.
- `제작가이드/`·월별 챌린지·시즌표: 과거 참고 자료이며 현재 편수·발행 주기·연간 계획이 아니다.

현재 다른 프로젝트의 원고와 실제 앱 문항은 별도 자료다. 이번에 제거한 옛 파생 퀴즈를 앱 전체 문항과 혼동하지 않는다.
