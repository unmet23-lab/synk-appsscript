## 1. SHIFT yuhobuilds — 제작 이야기 본문

SYNK는 까몽을 3D로 만들어 보는 실험을 했습니다. 이번 후보는 앱에 넣지 않기로 했습니다.

원래 2D 그림은 그대로 두고, 이 모델의 깊이 정보를 빌리면 고개를 돌리는 모습이 더 자연스러워질지 확인하고 싶었습니다.

먼저 잘려 있던 꼬리가 모두 보이도록 다시 출력했습니다. 바깥선은 더 잘 맞았지만 눈 간격에는 차이가 남았습니다. 털을 제외한 모델 표면을 측정했을 때, 원본 그림의 일부 비교 지점에서는 깊이를 얻지 못했습니다. 앱과 같은 움직임 계산을 적용한 별도 화면에서도 기존보다 덜 찌그러진다는 증거를 얻지 못했습니다.

그래서 이번 후보는 채택하지 않았습니다. 기존 2D 원본·깊이·앱·옷 자산은 그대로입니다. 실제 휴대전화 앱에서 시험한 결과도 아닙니다. 끝낸 것은 이 후보의 시험과 판단이지, 실사용 3D 캐릭터 제작이 아닙니다.

생성한 이미지나 3D 결과를 내 작업에 쓰기 전에는 세 가지를 물어보세요.

1. **형태:** 원본과 같은 크기·각도로 놓았을 때, 꼭 지켜야 할 특징이 맞나요?
2. **동작:** 쓰려는 움직임을 같은 조건으로 비교했을 때, 기존보다 좋아진 부분이 실제로 보이나요?
3. **적용 상태:** 지금 받은 것은 시안인가요, 비교 시험을 끝낸 파일인가요, 실제 사용할 곳에 적용한 결과인가요?

이번 실험 자료는 제작 과정을 설명하고 다음 제작자가 차이를 확인하는 참고로 남깁니다. 세 질문은 이 글 안에 있으니 댓글이나 DM 없이 복사해서 자기 작업에 써보셔도 됩니다.

지금 만들고 있는 것에는 어떤 질문부터 적용해 보고 싶으세요? 답을 남기는 것은 선택이에요.

## 2. SHIFT synkbrief — 점검표 파생 본문

작업자는 결과물을 쓰기 전에 세 가지를 확인할 수 있습니다.

1. **원본에서 무엇을 지켜야 하나요?** 원본과 후보를 비율을 유지한 같은 크기·각도로 놓고 눈 간격·몸의 비율·색·재질 등 필요한 특징을 비교하세요.
2. **쓰려는 동작에서 실제로 나아졌나요?** 기존 결과와 후보를 같은 조건으로 움직여 보세요. 정면 그림과 움직이는 모습은 따로 확인하고, 비교 화면과 실제 기기 시험을 구분하세요.
3. **지금 끝난 것은 어디까지인가요?** 시안이 나온 것, 비교 시험을 끝낸 것, 실제 사용할 곳에 적용한 것을 나눠 적으세요. 아직 확인하지 않은 단계는 남은 일입니다.

SYNK의 까몽 3D 시험에서는 원본과 눈 간격 차이가 남았고, 같은 움직임 계산에서 개선 근거를 얻지 못했습니다. 그래서 이 후보는 채택하지 않았습니다. 기존 2D·앱·옷은 그대로이며 실제 휴대전화 검증을 마친 3D 캐릭터도 아닙니다.

위 세 질문을 복사해 각 항목 아래에 ‘확인한 것 / 아직 모르는 것’을 적어보세요. 댓글·DM·연락처 제출 없이 이 글만으로 사용하실 수 있습니다. 이 점검표가 모든 품질·권리·안전 검토를 대신하는 것은 아닙니다.

어떤 작업에 써보고 싶으세요? 답을 남기는 것은 선택이에요.

## 3. SYNK 본체 — 기존 월간 기록용 요약

SYNK는 까몽 3D 후보의 비교 시험을 마쳤습니다. 결과는 현 후보 비채택입니다.

기존 2D 그림의 고개 돌림에 모델의 깊이를 빌릴 수 있을지 확인했지만, 눈 간격 차이가 남았고 같은 움직임 계산에서 개선 근거를 얻지 못했습니다. 기존 원본·깊이·앱·옷 자산은 유지했습니다.

이번에 끝낸 것은 실사용 3D 제작이 아니라 이 후보를 쓸지 판단하는 시험입니다. 실제 휴대전화 검증은 아니며, 실험 자료는 선택 이유를 설명하고 다음 제작자가 비교할 참고로 남깁니다.

## 내부 사용 지침 — 게시문에 넣지 않음

- 1은 원작, 2와 3은 같은 사례의 목적별 파생이다. 세 편을 모두 새로 만들거나 동시에 발행할 의무가 아니다.
- 원본/실험 후보를 같이 보여주며 후보에는 ‘실험용·미채택’을 표시한다. 이 파일 자체에는 새 시각 자산이 없다.
- 95.5% 수치는 짧은 본문에서 제외했다. 자세한 설명에 쓸 때만 ‘바깥선 IoU: 두 영역의 교집합/합집합’과 비교 조건을 함께 쓴다. 완성도 점수가 아니다.
- 공개 원고에는 내부 HTML·코드·계정 화면·학생 정보·로컬 파일 경로를 덧붙이지 않는다. 공개 자료 링크는 아직 발급하지 않았다.
- LAB 도움 제공형 릴 10편은 수정하지 않는다. 학생용 재작성과 몽골어 번역·감수는 별도이며 이 한국어 원고를 바로 몽골 학생에게 내보내지 않는다.
- 형식은 기존 SHIFT ‘한 일을 끝내는 방법’을 적용했다. 새 수요 조사나 흥행 검증을 거친 포맷으로 주장하지 않는다.
- 새 영상의 실제 크기·음성·자막·플랫폼 검토, 게시, 반응 확인은 아직 수행하지 않았다.
