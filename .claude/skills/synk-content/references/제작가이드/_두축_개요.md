# 두 축 — 과거 기획 배경

> **지위:** 2026-07 Notion 기획에서 가져온 배경 설명이다. 현재 제작의 선행 필수문서나 발행 일정이 아니다. 회사·채널·제공물의 현재 구조는 아래 원문이 우선한다.

- 회사별 목적·상대: `docs/마케팅_정본.md`
- 현재 제작 방식: `docs/마케팅/제작_인수기준.md`
- 채널 역할·발행 분담: `docs/마케팅/채널과_발행.md`

당시 기획은 콘텐츠를 두 역할로 나눴다.

- **발견을 돕는 콘텐츠:** 짧고 이해하기 쉬운 상황·정보·도움으로 처음 만나는 사람에게 닿는다.
- **신뢰를 쌓는 콘텐츠:** 실제 학생 성장, 회사가 만든 과정, 선택 이유처럼 깊이 있는 이야기로 판단 근거를 준다.

두 역할은 참고할 수 있지만, 꾸준함·완성도라는 말만으로 고정 빈도·대량 제작·재사용 캘린더를 정하지 않는다. 현재 콘텐츠는 실제 사건, 학생이 받을 것, 채널 역할, 권리와 후속 경험을 기준으로 선택한다.
