# 제작가이드 참고 색인

> **지위:** 이 폴더는 2026-08에 만든 형식별 제작 메모다. 현재 제작 정본이나 촬영 전 공통 필수문서가 아니다. 옛 45편·62편·12개월 계획과 고정 발행 주기를 되살리지 않는다.

## 먼저 볼 현재 원문

- 제작 방향·인수 기준: `docs/마케팅/제작_인수기준.md`
- 채널 역할·캡션·발행 분담: `docs/마케팅/채널과_발행.md`
- 회사별 목적과 상대: `docs/마케팅_정본.md`가 연결한 해당 회사 문서
- 행사·챌린지: `docs/마케팅/LAB_행사.md`
- 브랜드·시각 품질: `synk-brand`, `docs/명품_기준_v1.md`, `DESIGN.md`

현재 요청과 원문에서 제공물·전달 경로·형식을 정한 뒤, 아래 메모가 실제로 필요한 경우에만 읽는다.

## 형식별 역사 메모

| 요청 | 참고 파일 | 사용 경계 |

| 옛 리드크루 클립 재사용 | `리드크루클립.md` | 고정 길이·대본 수·질문 CTA를 현재 의무로 쓰지 않음 |
| 캐러셀 원고 재사용 | `캐러셀.md` | 카드 수·강조·마지막 장을 현재 내용에 맞춰 다시 편집 |
