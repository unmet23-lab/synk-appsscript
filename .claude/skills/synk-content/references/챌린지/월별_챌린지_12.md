# SYNK K컬처 월별 챌린지 12 (1~12월)

> **용도**: SYNK LAB 연간 K컬처 챌린지 캘린더. 몽골 10~20대 크루 대상, 계절·시즌 연동.
> **유형 배분**: 댄스 3 · 드라마 3 · 보컬 2 · 뷰티 2 · 음식 2
> **공통 규칙**
> - 학습 표현 자막은 항상 **한국어 + 몽골어 병기** (몽골어 용어집 기준, 학생 = чи체)
> - 도전·성장·포인트 연계는 **지급 판정을 앱이 한다** — 콘텐츠에서 구체 수치를 약속하지 않는다
> - 비교 대상은 오직 "어제의 나". 모든 크루가 주인공.
> - 참여 인증 공통 해시태그: **#SYNKLAB #싱크온** (+ 챌린지별 태그 3개)

## 1월 🎤 보컬 — "새해 첫 소절 챌린지"

- **컨셉 한 줄**: 새해 다짐을 한국어 한 문장으로 말하고, 좋아하는 K발라드 한 소절로 이어 부르는 새해 오프닝 챌린지.
- **참여 3스텝**:
  1. 카메라 앞에서 새해 다짐 한 문장 — "올해는 ○○하고 싶어요!"
  2. 좋아하는 K발라드·새해 느낌 곡 한 소절(10초)을 이어서 부르기
  3. 한·몽 자막을 달아 업로드 + 다음 크루 1명 태그
- **한국어 학습 포인트**: `~고 싶어요` = `~маар/мээр байна`
  - 예문: "올해는 한국어를 잘하고 싶어요." = "Энэ жил солонгос хэлээ сайн сурмаар байна."
- **도전·성장/포인트 연계**: 인증 영상 = 이달의 미션(даалгавар) 완료 처리 → 포인트 적립 대상. 다짐 문장이 가장 또렷한 크루는 "오늘의 성장" 후보. (지급 판정은 앱)
- **해시태그**: #SYNKLAB #싱크온 #새해첫소절 #ШинэЖил #KVocal

## 2월 🍲 음식 — "차강사르 × 설날 한 상 챌린지"

- **컨셉 한 줄**: 차강사르 상차림 옆에서 한국 설날 인사를 건네는 두 나라 명절 크로스오버 챌린지.
- **참여 3스텝**:
  1. 차강사르 음식(보쯔 등) 또는 한국 설 음식(떡국 등) 한 가지를 화면에 담기
  2. 카메라를 보고 "새해 복 많이 받으세요!" 인사 — 천천히 1번 + 자연 속도 1번
  3. 우리 집 명절 음식 이름을 한·몽 자막으로 소개하고 업로드
- **한국어 학습 포인트**: "새해 복 많이 받으세요" = "Шинэ жилийн мэнд хүргэе" / "많이 드세요" = "Их идээрэй"
- **도전·성장/포인트 연계**: 가족과 함께 찍은 인증은 명절 스페셜 미션으로 접수 → 포인트 적립 대상 + 이달의 도전 기록 후보. (지급 판정은 앱)
- **해시태그**: #SYNKLAB #싱크온 #설날인사 #ЦагаанСар #KFood

## 3월 💃 댄스 — "새학기 자기소개 포인트 안무"

- **컨셉 한 줄**: 새 학기 첫인사를 K-pop 포인트 안무 4카운트에 실어 자기소개하는 개강 시즌 챌린지.
- **참여 3스텝**:
  1. 이달의 지정곡 포인트 안무 4카운트(약 5초)를 따라 추기
  2. 안무 끝 포즈에서 "안녕하세요! 저는 ○○예요. 잘 부탁해요!" 자기소개
  3. 반 친구(크루) 1명과 함께 찍으면 듀오 인증 — 함께 업로드
- **한국어 학습 포인트**: "저는 ○○예요. 잘 부탁해요!" = "Би ○○. Сайхан танилцъя!"
- **도전·성장/포인트 연계**: 듀오 인증은 클래스 레이드 연료(түлш)에 힘을 보태는 참여로 집계 → 포인트 적립 대상. (지급 판정은 앱)
- **해시태그**: #SYNKLAB #싱크온 #새학기챌린지 #KPopDance #자기소개

## 4월 🎬 드라마 — "봄 명대사 립싱크 챌린지"

- **컨셉 한 줄**: 벚꽃 시즌 감성으로, 봄 로맨스 K드라마 명대사 한 줄을 립싱크 또는 직접 연기로 재현하는 챌린지.
- **참여 3스텝**:
  1. 이달의 명대사 3종 중 하나 선택 (예: "보고 싶었어요.")
  2. 야외(봄 배경)에서 립싱크 또는 자기 목소리로 연기 — 천천히 1번 + 감정 실어 1번
  3. 한·몽 자막을 달아 업로드 + "어떤 장면인지" 한 줄 코멘트
- **한국어 학습 포인트**: "보고 싶었어요" = "Чамайг санасан шүү"
  - 과거형 감정 표현 `~았/었어요` 맛보기
- **도전·성장/포인트 연계**: 자기 목소리 연기 인증은 스피킹 미션으로 접수 → 포인트 적립 대상 + 발음이 또렷한 크루는 "Дуудлага↑(발음 상승)" 칭찬 태그 후보. (지급 판정은 앱)

## 5월 💄 뷰티 — "피크닉 GRWM 한국어 챌린지"

- **컨셉 한 줄**: 야외 나들이 준비(GRWM) 과정을 한국어 순서 표현으로 내레이션하는 봄 피크닉 뷰티 챌린지.
- **참여 3스텝**:
  1. 나들이 준비 3단계(스킨케어→베이스→포인트 등 자유)를 찍기
  2. 각 단계마다 "먼저 ~해요 → 그다음 ~해요 → 마지막으로 ~해요" 내레이션
  3. 완성 룩으로 "싱크 온!" 마무리 포즈 + 업로드
- **한국어 학습 포인트**: "먼저 / 그다음 / 마지막으로" = "Эхлээд / Дараа нь / Эцэст нь"
  - 뷰티 동사: 바르다 = түрхэх, 그리다 = зурах
- **도전·성장/포인트 연계**: 순서 표현 3개를 모두 말한 인증은 미션 완료 처리 → 포인트 적립 대상. (지급 판정은 앱)
