# 리드크루 클립 07 — 여행·길찾기 (숏폼 5편)

> **유형**: 숏폼 리드크루 클립 · **장면형 18초** · 몽골 10~20대 타겟
> **형식**: `상황 → 실수 → 반응 → 표현 → 짧게 → 따라하기 → 참여` (유호 확정 08-27 · 08-28 ㉯) · 「쓰임」(예문) 칸은 홍보 릴에서 뺐다.
> **공통 규칙**: 음성 몽골어 최대 2곳(오프닝 인사·뜻 확인 1회) / 학습 표현 자막 = 한·몽 병기 / 학습 표현 2회 이상 발화 / 뇌과학 은유 클립당 최대 1회 / 이모지 클립당 최대 2개
> 🔴 **몽골어는 「표현」 칸에만 있다** — 옛 판에서 그대로 옮겨 왔고 새 줄은 지어내지 않았다(감수 큐 Q).
>
> **이 편의 실수 축 = 「급해서 낱말만 던진다」** — 길 위에서는 시간이 없어서 명사 하나로 줄어든다. 그러면 상대가 «무엇을 묻는지»를 못 알아듣는다. 다섯 편이 그 낱말에 문장 한 벌을 입힌다.
> 🔴 **09-08 전면 개정** — 아스트라·제미나이 두 심문이 짚은 것:
> ① **「카드가 안 열려요」를 고쳤다**(3편 세 곳) — 열리는 것은 문이고 카드는 대는 것이다. 초급 학생이 그대로 익힌다.
> ② **「거리 얼마예요?」를 요금 질문으로 단정하던 자리를 고쳤다**(5편) — 거리 문맥에서 「얼마」는 거리의 양도 묻는다.
> ③ **과장을 걷었다** — 「한국 지하철은 다 뚫려요」·「거의 다 멈춰 서서 알려 줘요」·「분위기가 확 굳어요」.
> ④ **「싱크 온!」을 걷고** 훅을 «물음»으로 바꾸고 대사를 덜었다.
> ⑤ **클로징을 형태 다섯으로** 갈랐다(몽골어 답하기 · 집계 · 한 낱말 · 갈리는 선택).

## 제작 메모
- **실수 축 = 「급해서 낱말만 던진다」** — 명동? / 경복궁 어디? / 돈 넣어 주세요 / 비켜요! / 거리 얼마예요?. 길 위에서는 시간이 없어 명사 하나로 줄어들고, 그러면 «무엇을 묻는지»가 사라진다.
- 🔴 **「카드가 안 열려요」를 「카드를 댔는데 문이 안 열려요」로**(09-08). 열리는 것은 문이고 카드는 대는 것이다. 옛 판은 훅·오프닝·상황 자막 세 곳에 같은 오류가 있어 초급 학생이 그대로 익힐 자리였다.
- 🔴 **「거리 얼마예요?」도 성립한다**(09-08). 거리 문맥에서 「얼마」는 거리의 양을 묻는다. 반응 칸은 «더 짧고 자주 쓰는 말이 있다»만 짚는다.
- 🔴 **과장을 걷었다**(09-08) — 「한국 지하철은 다 뚫려요」·「거의 다 멈춰 서서 알려 줘요」·「분위기가 확 굳어요」. 표현 하나에 성공을 약속하지 않는다.
- **「짧게」 칸이 셋에 있다**(2·3·4편) — 길 위에서는 진짜로 짧은 판이 필요하기 때문이다. 1·5편은 원래 문장이 이미 짧아서 안 붙였다.
- 뇌과학 은유 0회.
- 몽골어 음성은 편당 2곳(오프닝 "Сайн уу, 크루!" + 뜻 확인 1회)으로 고정.
- 신규 몽골어 자막 문장은 원어민 감수 대상(용어집 §7 관행).
