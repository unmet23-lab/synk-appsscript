# 리드크루 클립 — 04 K-드라마 유행 표현 (숏폼 5편)

> **유형**: 숏폼 (리드크루 클립) · 15~30초 · 몽골 10~20대 타겟
> **캐논**: 리드크루 바이블 Phase 0 준수 — 배역 페르소나(고유 이름 없음), 밝은 해요체 + 훅·구호만 반말, 음성 몽골어 최대 2곳(오프닝 인사·뜻 확인), 학습 표현 자막 한·몽 병기, 학습 표현 2회 발화(천천히 1번 + 자연 속도 1번), 뇌과학 은유 클립당 최대 1회.
> **저작권**: 특정 드라마 제목·장면·대사 인용 없음 — 드라마 전반에서 자주 들리는 **일반화된 유행 표현**만 다룬다.
> **몽골어 표기**: 몽골어 용어집 v0.1 기준(학생 = чи체, 키릴 표기). ⚠ 표시 자막은 원어민 감수 후 확정.
