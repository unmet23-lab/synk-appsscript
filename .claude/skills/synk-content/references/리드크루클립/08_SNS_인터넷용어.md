# 리드크루 클립 08 — SNS·인터넷 용어 (숏폼 5편)

> **유형**: 숏폼 리드크루 클립 · **장면형 18초** · 몽골 10~20대 타겟
> **형식**: `상황 → 실수 → 반응 → 표현 → 짧게 → 따라하기 → 참여` (유호 확정 08-27 · 08-28 ㉯) · 「쓰임」(예문) 칸은 홍보 릴에서 뺐다.
> **공통 규칙**: 음성 몽골어 최대 2곳(오프닝 인사·뜻 확인 1회) / 학습 표현 자막 = 한·몽 병기 / 학습 표현 2회 이상 발화 / 뇌과학 은유 클립당 최대 1회 / 이모지 클립당 최대 2개
> 🔴 **몽골어는 「표현」 칸에만 있다** — 옛 판에서 그대로 옮겨 왔고 새 줄은 지어내지 않았다(감수 큐 Q).
>
> **이 편의 실수 축 = 「받아치지 못한다」** — 채팅은 뜻보다 **박자**다. 뜻을 몰라 멈추거나, 격식을 차리다 박자를 놓치면 대화가 그 자리에서 끝난다.

## 제작 메모
- **실수 축 = 「받아치지 못한다」** — ? / 무슨 뜻이에요? / 동의합니다 / 왜 조용해요? / 재미있습니다. 앞 둘은 «뜻을 몰라 멈춤», 뒤 셋은 «격식 차리다 박자를 놓침». 채팅은 뜻보다 박자라는 것이 이 편의 주장이다.
- **「짧게」 칸을 한 편도 안 뒀다** — 3편에 「ㅇㅈㅇㅈ」(강조), 5편에 「노잼」(반대말)을 넣어 봤다가 **둘 다 뺐다.** 그 칸의 화면 라벨이 「급하면」이라 «더 센 말»이나 «반대말»을 얹으면 라벨이 거짓말한다. 강조·반대말은 대사가 진다 — 규칙은 하나다: **「짧게」에는 «같은 뜻의 더 짧은 판»만 온다.**
- 자음 표현(ㅋㅋ·ㄹㅇ·ㅇㅈ)은 **소리 내어 읽는 법**을 따라하기 칸이 진다 — 자음만 보면 발음을 못 하는 것이 학습자의 실제 벽이다.
- 뇌과학 은유 0회.
- 몽골어 음성은 편당 2곳(오프닝 "Сайн уу, 크루!" + 뜻 확인 1회)으로 고정.
- 신규 몽골어 자막 문장은 원어민 감수 대상(용어집 §7 관행).
