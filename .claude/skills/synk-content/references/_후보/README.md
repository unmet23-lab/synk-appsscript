# _후보 — 교차검증 대기소 (GPT·Claude 둘 다 만든 안을 비교·정착)

> 이 폴더는 **아직 확정 안 된 콘텐츠 후보**만 둔다. 확정된 정본은 여기 없다 —
> 리드크루클립/·챌린지/·캐러셀/ 로 **승격**되어야 정본이다.

## 왜 여기서 만드나 (로컬인 이유)
SNS 콘텐츠 원본은 로컬 `references/`가 정본이라, **GPT(Codex)·Claude 둘 다 여기 직접 읽고 쓴다.**
그래서 "둘 다 만들고 → 비교 → 정착" 교차검증에 로컬이 가장 편하다(Notion은 검수·발행 관리용).

## 폴더 규칙
```
_후보/
└── 2026-08_겨울챌린지/          ← 주제·시점별 하위 폴더
    ├── claude안.md              ← Claude가 만든 후보
    ├── gpt안.md                 ← GPT가 만든 후보
    └── (판정메모.md)            ← 비교·병합 결과 (선택)
```
- **후보 단계에만 `claude안`/`gpt안` 출처를 파일명에 붙인다** (비교용). 확정본엔 출처를 뗀다.
- 여긴 뒤죽박죽이어도 된다 — 어차피 버릴 것들이니까.

## 4단계 흐름
1. **후보 넣기** — 한 주제에 GPT안·Claude안 둘 다 이 폴더에 만든다.
2. **교차검증** — 한 창에 시킨다:
   `_후보/○○의 claude안·gpt안 비교해줘. synk-brand 규칙(금칙어·톤·타겟) 기준으로 뭐가 낫고, 둘을 섞으면 더 좋은지 판정해줘.`
   (이게 /forge 스킬이 하는 일 — A/B → 하드게이트 → 병합)
3. **승격** — 이긴 것(또는 병합본) 하나만 해당 종류 폴더(리드크루클립/·챌린지/·캐러셀/)로 옮기고,
   **INDEX.md의 표·총계·중복 목록을 갱신**한다(INDEX 사용법 3번).
4. **정리** — 승격 끝난 주제 폴더는 `_후보/`에서 지운다. 이 폴더엔 "정착 안 된 것"만 남는다.

## 승격 후 그다음
확정본이 종류 폴더에 들어가면 → 기존 발행 파이프라인을 그대로 탄다:
Notion 📦 주간 검수함 → 🎬 퍼포먼스 플랜 스케줄(촬영→편집→완료).
