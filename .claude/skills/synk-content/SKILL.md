# SYNK 콘텐츠 제작 시작점

1. [콘텐츠 제작 방식 v2](../../../docs/마케팅/콘텐츠_제작방식_v2_20261002.md)를 읽고 그 순서대로 한다. 트렌드·질문·달력·실화 가운데 트리거가 없으면 만들지 않는다. 「이번 주 콘텐츠」 요청이면 v2 §9대로 후보 5~7개 표부터 드린다.
2. 볼 이유·진정성·개인화 프로그램 기준은 [콘텐츠 제작 양식](../../../docs/마케팅/콘텐츠_제작양식.md), 맞춤 프로그램은 [제작 절차](../../../docs/마케팅/맞춤도구/제작절차.md), 채널 대상·언어는 [채널과 발행](../../../docs/마케팅/채널과_발행.md)에서 필요한 부분만 읽는다.
3. 표지·자막·모션은 [SNS 제작 키트](../../../docs/디자인/SNS키트/README.md)로 만든다. references의 옛 지시(Loom 캐러셀 CSS, `tools/캐러셀굽기.js`, 영상별 자막·표지 틀)는 따르지 않는다(2026-10-01 사용자 확정 “전에 쓰던 양식 이걸로 전부 다 교체”).
4. `references/`는 옛 콘텐츠 재고다. 특정 원고가 필요할 때만 읽으며 과거 말투·검수표·발행 편수를 새 작업에 적용하지 않는다. 브랜드·채널 자료는 `docs/마케팅_정본.md`에서 찾는다.
5. 게시는 사용자 승인 뒤에만 한다. 확인하지 않은 전달 경로(댓글→DM 등)를 게시물에서 약속하지 않는다.
