# SYNK 콘텐츠 제작 시작점

이 스킬을 전역 연결 경로에서 읽었다면 아래 상대 링크는 실제 원본 폴더 `C:/Users/q1212/Documents/SYNK-appsscript/.claude/skills/synk-content`를 기준으로 찾는다.

1. [제작 절차](../../../docs/마케팅/기획장부/제작절차.md)를 처음부터 끝까지 따른다 — 핵심 셋(한 문장 · 알아듣기 · 낯선 사람 이해 시험), 순서, 지킬 것. 다른 문서와 어긋나면 제작 절차가 맞다.
2. 무엇을 만들지는 [기획 장부](../../../docs/마케팅/기획장부/README.md)의 「고름」 줄이고, 브랜드 규칙은 각 장부 머리말 「이 브랜드에서만」이다. 고른 줄이 없는데 요청을 받으면 월요일 수요 스캔과 같은 방법(근거가 있는 한 장 기획 + 순위)으로 후보를 드리고 고르시게 한다.
3. 배경 · 칸 설명은 [제작 방식 v2](../../../docs/마케팅/콘텐츠_제작방식_v2_20261002.md), 표지 · 자막 · 모션은 [SNS 키트](../../../docs/디자인/SNS키트/README.md), AI 영상 · 그림은 [만족 사례 장부](../../../docs/마케팅/제작양식/만족사례_장부.md)에서 필요한 부분만 본다. `references/`는 옛 재고라 새 작업에 쓰지 않는다.
4. 게시는 유호님 승인 뒤에만 한다.
