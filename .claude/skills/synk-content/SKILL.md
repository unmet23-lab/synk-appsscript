# SYNK 콘텐츠 생성기

**먼저 `synk-brand` 규칙(톤·금칙어·타겟·세계관)을 반드시 적용.** 그다음 아래 유형에 맞춰 생성한다.

> 🎬 **촬영·제작까지 묻는 요청이면** `references/제작가이드/INDEX.md`를 함께 읽는다 — 이 SKILL은 **무엇을 말하는가**(대본 형식)만 정의하고, **어떻게 찍는가**(재미 장치·출연·스타일링·배경·자막·운영 주기)는 그쪽에 있다.
> 🎨 **색을 물으면 여기서 정하지 않는다** — 킷 색의 정본은 `docs/디자인_토큰.json` 하나다(색 수·구성도 그 파일과 `DESIGN.md`가 센다 — 여기 박으면 같이 낡는다). 킷 밖 hex 임의 지정 금지.
> 🧵 **실물(이미지·캐러셀·자막·썸네일)을 굽는 건 Loom 통로 하나** — `node tools/lib/loom.js --css 캐러셀` (유호 확정 08-27 · 결정.md). 손 CSS·손 색·바깥 템플릿 팔레트 금지. AI 뉴스 «내 판정» 캐러셀(개인 계정 코너 B)은 `캐러셀/굽기.js`(절차 = `캐러셀/README.md`).

## 1) 요청 파악 (짧게)
필요하면 1~2개만 물어 확정: **유형 · 개수 · 주제/한국어 표현 · 플랫폼**. 이미 충분하면 바로 생성.

## 1.5) 제작 전 수요 검증 — 소계정 아웃라이어 (유호 채택 08-14 · git 3630a4146)
SNS에 새로 내는 공개물(숏폼·캐러셀·챌린지·FB/IG 게시물)은 만들기 전에 **검증된 포맷부터 찾는다.** 성장 스토리(우리 학생 실화 — 포맷 차용 무의미)와 앱 내 콘텐츠(숙제·퀴즈)는 제외:
- **아웃라이어 찾기**: 몽골·한국어학습 니치에서 **팔로워 대비 반응(조회·저장·공유)이 터진 게시물**(영상·카드 모두 · 예: 팔로워 3만 이하 계정에서 조회 10만+)을 찾는다 — 계정 힘이 아니라 **아이디어 자체의 수요**가 검증된 것.
- **판정**: 같은 포맷 사례 **2개 이상**이면 그 포맷을 빌린다 — 빌린 포맷이 §2 기본 구성과 다르면 **빌린 쪽을 따른다**(§2는 기본값). **1개 이하면** 「검증 못 함」이라 쓰고 §2 기본 포맷으로 간다 — 이 단계는 제작을 막는 게이트가 아니라 조준이다.
- **증거 동봉**: 찾은 사례의 URL·팔로워·반응 수치를 산출물에 표로 남긴다(수치를 못 본 칸은 「못 봤다」고 쓴다 — 지어내기 금지). 탐색은 니치 해시태그·계정 서너 곳까지만 — 없으면 거기서 접는다.
- **알파 주입**: 빌린 포맷에 우리 실물(정원 프레임·마스코트·엔진 실측 — 그날 값은 synk-brand 가 가리키는 집필 규범 §5에서 확인)을 넣는다 — 뻔한 정보 재탕이면 실격(「문서=어필+눈높이」 확정 그대로).

## 2) 콘텐츠 유형별 형식

### 🎬 숏폼 (리드크루 클립) — 한국어 표현 하나를 짧고 재밌게
- 15~30초. 구성: **훅 → 표현 → 예문 2개 → 따라하기 → CTA**
- 출력:
  - `[훅 자막]` (첫 2초, 궁금·공감 유발)
  - `[대사]` (진행 멘트)
  - `[화면 자막]` (표현·뜻·예문)
  - `[캡션]` (정보성이면 §3 형식 기준선대로 — 훅 1줄+번호 단계 전문+저장 유도)
  - `[해시태그]` **0개** — 유호 확정 09-02(결정.md · 마케팅 정찰 픽 ④ · 해시태그가 뷰 -31.7%). 캡션 규칙 둘: ①첫 문장의 주어는 사람(보기 = 「학생마다 자기만의 선생님이 한 명씩 있습니다」 · 낱말 「부리다」는 유호 09-03 에 걷었다) ②마지막 줄은 질문 하나(댓글 +36.7%)
- 예) 표현 "대박": 훅 "몽골 친구들 이거 하나면 한국인 친구 생겨요 😳"

### 🖼️ 캐러셀 카드뉴스 — 저장하고 싶은 정보성
- 5~8장. **1장 표지(후킹) · 중간 핵심 3~5개 · 마지막 장 = «친구에게 보내는 한 장»**(요약+CTA · 인스타 최강 신호가 DM 보내기라서 — 유호 확정 09-02)
- 각 장: `제목(≤10자)` + `본문(≤2줄)` 형식 · 업로드 `[캡션]`은 §3 형식 기준선대로 함께 낸다(해시태그 0 · 캡션 규칙 둘은 숏폼과 같다)

### 💃 K컬처 챌린지 (댄스/드라마/보컬/뷰티)
- 컨셉 한 줄 · 참여 3스텝 · **한국어 학습 포인트** · 도전·성장/포인트 연계 · 해시태그 0

### 📝 숙제 (앱 contents 시트 · 유형 homework)
- 스키마 행: `[ID, 'homework', 유형, 숙제내용, 팁, 요일코드]` (요일코드 = 요일1~7 × 100 + n · 정본 = `엔진_콘텐츠AI.js` `setupHomework`)
- 요일 테마 · 초급도 5분 내 · **실사용 중심** · 부담 0. 부정어 없이 격려형.

### ⚡ 퀴즈 (앱 · 유형 quiz) — `문제|정답` 형식, 객관식·정답공개형(노출 학습 · 정본 = `setupQuiz`)

### 📖 성장 스토리 — 인터뷰(정성) + 앱 데이터(정량) 결합
- 재료: **앱 `profiles` 시트**의 급수·캐릭터진화·도전 기록·성장 기록·총포인트 + **4주 인터뷰** 답변(질문지 = `references/제작가이드/성장스토리_*.md`)
- 구성: 훅 → 변화(전/후) → **데이터 근거**(숫자) → 학생 목소리(인용) → CTA
- 프레임: "숫자로 본 성장 + 말로 들은 성장" (모든 학생이 주인공)

## 3) 출력 원칙
- **형식 기준선 (유호 확정 08-14 「최소 이 이상」 · git 3630a4146)**: **정보성 게시물**(단계·목록·팁을 주는 것 — 유머·감성 클립은 비대상)은 **캡션만으로 완결**되게 쓴다 — ①훅 첫 줄 ②번호 단계 전문(따라할 수 있는 리스트 — 영상을 안 봐도 저장 가치가 선다) ③「저장해두고 따라하세요」류 저장 유도. 캡션이 영상 요약 한 줄에 그치면 미달.
- **바로 쓸 수 있게** (플랫폼별 자막 포함 · 해시태그는 0 — 유호 확정 09-02)
- 여러 개 요청 시 번호 매겨 일괄 생성
- 끝에 검수 1줄: `synk-brand 검수: 금칙어 0 · 반례 표 전 행 대조 · 접점 눈금 일치 ✅`
  (⚠ 금칙어 0개는 통과의 절반이다 — synk-brand 「반례」 표가 나머지를 잡는다)
