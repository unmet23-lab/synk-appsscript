# /afk — 자리 비움 실행 루프

목적: **자리 비움 시간을 희소 자원으로 쓴다.**
짧은 일감은 유호님이 화면 앞에 있어도 된다. 자리를 비운 그 시간에만 할 수 있는 것은 **긴 것**이다.
그래서 이 스킬은 쉬운 것부터 치우지 않는다 — **긴 것부터 집는다.**

## 이건 「일감 발견 루프」가 아니다 (기각분과의 경계선)

2026-08-03 **자율 일감 발견 루프는 기각됐다** — 유호님 병목은 발견이 아니라 **결정 대기**라, 일감을 더 찾는 루프는 큐에 기름을 붓는다(`loop-trigger-layer`).
이 스킬은 그 반대다: **이미 큐에 있는 것을 비운다.**

🚫 AFK 중 **새 결정 항목을 큐에 쌓지 않는다.** 벽에 닿으면 기존 줄에 붙이고, 새 줄은 정말 없을 때 하나만.

## 🔴 0. 이 스킬은 **스스로 반복하지 않는다** — 반복은 `/loop` 이 만든다

턴은 도구 호출을 멈추는 순간 끝난다. 시계를 보고 버티는 장치는 없다. **`/afk 2시간` 만 치면 일감 몇 개 하고 턴이 끝나고, 남은 시간은 0분 돈다.**

```
/loop /afk 2시간          ← 실제로 2시간을 채우는 형태
```

`/loop` 이 예산이 끝날 때까지 이 스킬을 다시 부른다. 유호님이 `/afk` 만 치셨는데 자리를 오래 비우신다면 **첫 줄에 이 형태를 안내하고 시작한다**(대신 걸어 드리지 말 것 — 루프는 유호님이 거는 것이 안전하다).
매 wake 는 **한 일감**만 한다. 깨어나면 §1 비켜서기부터 다시 — 그 사이 남이 착지했을 수 있다.

## 시작 — 예산부터

`/afk 60` (분) · `/afk 2시간` · 예산을 안 주면 **60분**.

```bash
date            # 시작 시각을 박는다. 예산은 벽시계로 잰다(추정 금지)
```

시작 직후 **1줄만** 보고한다: `잡은 일감 · 추정 · 정지선`. 그 다음부터 유호님은 화면을 안 본다 — 중간 보고를 쓰지 않는다.

## 1. 비켜서기 (착수 전 · 매 일감마다)

```bash
node tools/작업본소유자.js
git log --oneline -10
node tools/board.js
```

남이 잡은 파일·트랙과 겹치면 **내가 비켜난다**(F073·F165·F170). 남의 줄을 이어받지 않는다.
자리를 비운 동안 겹침이 나면 물어볼 사람이 없다 — **애매하면 무조건 비켜난다.**

## 2. 일감 순위 — 긴 것부터

후보를 **새로 찾지 않는다.** 이미 발화하는 이 넷이 뱉는 것만 쓴다:

```bash
node tools/rot-check.js       # 수리 필요 · 낡음
node tools/friction.js        # 살아있는 마찰 F0NN
node tools/board.js           # 🔴 잔여 · ▶다음
node tools/원격ci.js          # 적색 (주인이 살아있으면 남의 것 — 손대지 않는다)
```

**긴 것** = ①네트워크 왕복(리허설 실측·왕복시험 5종) ②전 스위트·원격 CI 대기(실측 3분+) ③여러 파일을 지나는 트랙.
**짧은 것**(깨진 링크 1개·인덱스 1줄·오타)은 **AFK 예산에 넣지 않는다** — 유호님 옆에 있을 때 껴 넣으면 되는 것에 희소한 창을 쓰지 않는다.

대기가 긴 명령은 `run_in_background` 로 띄우고 그 동안 다른 일감을 진행한다. **띄워놓고 자지 않는다.**

## 3. 정지선 — 하드 (못 넘는다)

자리를 비운 동안엔 **승인을 받을 수 없다.** 승인이 필요한 자리에 닿으면 실행하지 말고 **벽으로 적고 다음 일감으로.**

**⚠ 벽은 적기 전에는 버려진 것이다.** 그냥 넘어가면 그 일감은 아무 데도 안 남는다 — 실패가 에러가 아니라 침묵으로 나온다. 벽은 두 종류고 통로가 다르다:

| 벽 | 어디에 적나 | 누가 푸나 |
|---|---|---|
| **유호님 판정이 필요** (배포·방향·돈) | 벽으로 적고 다음 일감으로 — 세션 끝 보고에 벽 목록을 그대로 싣는다 | 유호님 — 보고에서 직접 보고 정하면 `docs/_ops/결정.md`에 `node tools/결정.js --추가`로 적는다(옛 결정 큐는 08-20 소멸) |
| **다른 세션이 이어받을 수 있음** (남의 작업본·남의 적색이 잡고 있음) | **내 보드 줄 상태 칸에 `🎫`** + 무엇이 막았나 | 아무 세션이나 |

`🎫` 는 「남의 줄은 이어받지 않는다」(F073·F165·F170)의 **유일한 예외**다 — 주인이 「나는 이걸 안 한다」고 스스로 놓은 표식. 인계문에 예외 문구가 같이 나간다(회귀는 압축 08-20으로 철거).
🚫 남이 안 놓은 줄에 내가 `🎫` 를 달지 않는다. 🚫 `🎫` 를 집을 때 남의 보드 줄을 고치지 않는다 — **내 파일에 내 줄**을 새로 선언한다.

⛔ 라이브 배포 — `/deploy` · clasp · 운영 DB 적용
⛔ 외부 발송·발행 · 대량 삭제 · 공유물 덮어쓰기
⛔ 유호님이 배치한 파일·폴더·환경의 변경
⛔ 방향을 바꾸는 판정(제품·계약·가격·범위) — 발견하면 **판정안만 써 둔다**
⛔ 남의 작업본 편집 · 남의 적색 수리 · 남의 보드 파일
⛔ **같은 방법 3연속 실패** → 접고 다음으로. 접기 전에 원인 후보 1개를 적는다(N회 실패 = 원인 미특정)

✅ 가역 내부 편집(코드·테스트·문서) · 리허설 환경 실측 · 커밋·push · 보드·장부 갱신

## 4. 한 일감 = 한 커밋

```bash
git commit -m "..." -- 경로들      # 범위를 못 박는다
```

끝내지 못했어도 **미완인 채로 커밋한다** — 미추적·미커밋은 이력·stash·reflog 어디에도 없는 유일한 무보호 상태다(F025). 자리를 비운 사이 남의 `rebase --abort` 에 쓸리면 통째로 사라진다(F037).
커밋 뒤 내 보드 줄의 상태 칸을 갱신하고 다음 일감으로.

## 5. 예산 소진 → 인계 한 장

돌아온 유호님이 읽는 건 **이 한 장뿐이다.** 길게 쓰지 않는다.

```
[AFK 마감] 60분 · 3건
✅ <일감> — <커밋 해시>
⏳ <유호님 판정이 필요한 벽> — 메모리에 적었다(다음 세션 시작에 뜬다)
🎫 <다른 세션이 이어받을 벽> — 보드 줄에 놓았다
```

**알림은 안 보낸다**(유호님 확정 08-09) — 중간에 방해받지 않는 게 이 창의 조건이다. 대신 벽이 **전부 적혀 있어야** 그 조건이 성립한다: 안 적힌 벽은 유호님이 돌아와도 못 보고, 다른 세션도 못 집는다.

굵직한 판정은 메모리에. 순서 보장이 필요하면 `/close`.

## 비용 — 이 스킬의 진짜 상한

루프는 **한 세션 안에서** 돈다. CLAUDE.md 실측: 1,500턴 넘긴 세션은 턴당 336~526k(짧은 세션 58k의 **8배**).
**2시간을 넘기지 않는다.** 더 길게 비우면 그 시간의 이득보다 컨텍스트 몫이 커진다.
