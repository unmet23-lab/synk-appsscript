# forge(결과물 도출 스킬) 설계 근거 — v1 (2026-07-10)

> 유호님이 직접 작성한 최종 확정 스펙 원문 + AI 보완 5건의 기록. SKILL.md는 이 문서의 실행 지침 압축본이다.

## 왜 지침이 아니라 스킬인가 (유호님 결정)

"모든 대화마다 적용시켰을 때 제대로 된 효과를 볼 수 있다면 지침으로 해도 되지만, 효과적이지 않고 낭비되는 게 생각보다 많을 것" — 대화 초반에 "지침에 검증 루프를 박아두면 단순 질문에도 매번 적용돼 낭비"라는 문제를 먼저 진단했고, 이 스킬을 기본값으로 깔면 같은 실수를 반복하게 된다. 스킬은 손전등처럼 "필요할 때만 켜는" 도구라야, 단순 질문은 가볍게 두고 중요한 것만 무겁게 다룰 수 있다.

공용 지침(CLAUDE.md)과의 역할 분담: **산출물(콘텐츠·기획안) 도출 = forge / 판정·평가·진단·지출 결정 = 지침의 자기검증 루프(최대 3회)**. A/B 접근 다양화는 산출물에 맞고, 진단은 정답 수렴형이라 반박 검증(루프)이 맞다.

## 단계별 설계 근거 (유호님 원문)

- **0단계 · 애매성 사전 확인**: 방향이 잘못 잡힌 채 2개 버전을 만들면 둘 다 헛수고. "느낌 있게 만들어줘"처럼 해석이 갈리는 요청은 사후 비교보다 사전에 방향을 한 번 좁히는 게 효율적. 단 매번 하면 그 자체가 또 다른 "기본값 낭비"이므로 애매성이 임계치를 넘을 때만.
- **1단계 · 의도 파악**: 이후 모든 단계가 이 이해를 기준으로 움직인다. 여기서 잘못 짚으면 뒤의 정교한 단계들이 전부 엉뚱한 방향으로 정밀해진다.
- **2단계 · 다른 접근 2버전 병렬 생성**: "같은 접근으로 두 번 만들기"는 미묘한 표현 차이만 낼 뿐 품질 향상이 거의 없다(반복 검증의 수확체감과 같은 원리). 진짜 비교 가치는 서로 다른 각도에서 나온다. 동시 생성은 품질 영향 없이 대기 시간만 줄이는 비용 없는 개선.
- **3단계 · 하드 게이트**: 이전 설계는 리스크를 다른 3개 기준과 같은 비중의 점수로 합산했는데, 그러면 톤·완성도가 뛰어난 버전이 점수 총합으로 리스크 있는 내용을 이길 수 있다 — "화려하지만 틀린 통계(핀란드 20년 1위 등)"가 정확히 이 함정. 리스크는 타협 대상이 아니므로 점수화하지 않고 먼저 걸러내는 문(gate)으로 분리.
- **4단계 · 고정 루브릭**: 고정된 기준으로 매번 같은 방식으로 판단해야 "왜 이걸 골랐는지"가 감으로 바뀌지 않고 일관성이 생긴다.
- **5단계 · 수렴 체크**: 다른 각도로 시도해도 결과가 수렴하는 경우, 억지로 "병합했습니다"라고 하면 작업을 부풀려 보고하는 셈. 정직하게 "차이가 없었다"고 말하는 게 신뢰를 지키고 병합 작업도 생략돼 효율적.
- **6단계 · 하이브리드 병합**: "둘 중 하나를 통째로 고르기"보다 "둘의 최선을 합치기"가 품질 상한을 실제로 끌어올린다. 서로 다른 버전이 서로 다른 강점을 가질 때 하나를 버리는 건 낭비.
- **7단계 · 창의적 대안**: A/B가 이미 톤 차이를 다루므로 대안이 또 톤만 다르면 차별성이 없다. 형식 전환이라는 별도의 축을 명시해야 "의도를 벗어난 창의성"이 실제 새로운 값어치를 낸다.
- **8단계 · 최종 보고**: 판단 과정을 짧게라도 항상 노출해야 기준에 동의하지 않을 때 바로 피드백 가능. 보고 자체는 결과 중심으로 압축("결론부터, 그다음 근거").

## AI 보완 5건 (v1 반영분)

1. **게이트 판정자 분리** — 생성한 주체가 자기 산출물을 검사하면 자기확증으로 통과 위험. 검사는 생성과 분리된 별도 패스/에이전트로.
2. **둘 다 탈락 경로** — 원 스펙에 없던 케이스. 사유 반영 1회 재생성 → 재실패 시 실패 사실 그대로 보고(억지 통과 금지).
3. **창의적 대안의 게이트 통과 의무** — 7단계가 하드 게이트의 우회로가 되는 것 방지.
4. **지침 루프와 이중 실행 금지** — 스킬 자체가 검증 구조이므로 공용 지침의 자기검증 루프를 중복으로 돌리지 않는다.
5. **트리거 주어 명확화** — 유호님 명시 호출 + AI 자동 적용은 굵직 기준(외부 공개물 확정본·굵직한 기획안) 충족 시만, 자동 적용 시 "forge 적용" 1줄 표시. (원문 "명시 호출만"에서 절충 — 유호님이 스킬 존재를 잊었을 때 검증 0이 되는 것 방지. 유호님이 수동 전용을 원하면 이 항목만 되돌리면 됨.)
