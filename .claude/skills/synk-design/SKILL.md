# SYNK 자산 찾기

`DESIGN.md`에서 이번 작업에 필요한 자산의 원천을 찾는다.

- 색 값은 `docs/디자인_토큰.json`, 서체는 `docs/브랜드_폰트_정본.md`.
- 로고는 `docs/로고_중립색_정본_v1.md`, 마스코트 파일은 `tools/lib/마스코트자산.js`.
- 기존 생성물을 고치는 경우 DESIGN의 제작 통로에서 원고와 생성기를 확인한다.

현재 요청에 필요한 링크만 읽는다. 이 스킬은 다른 스킬의 실행 순서나 콘텐츠 형식을 정하지 않는다.
