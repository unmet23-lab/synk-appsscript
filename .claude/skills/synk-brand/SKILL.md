# SYNK LAB 학생 접점 보이스

학생이 실제로 읽는 글을 짧고 따뜻하며 정확하게 만든다. 이 스킬은 정본을 요약해 대신하지 않는다. 작업 직전에 필요한 현재 원문만 읽고, 옛 사례·날짜별 수치·과거 칭찬을 영구 규칙으로 확대하지 않는다.

## 먼저 읽을 현재 원문

- 사실·금칙어·전사 목소리: `docs/정본/SYNK/SYNK 집필 규범.txt`의 관련 절
- 학생 경험과 제출 품질: `docs/명품_기준_v1.md` §2~§4
- 캐릭터 성격·말투·학생을 향한 말: `docs/캐릭터/가이드_정본.md`의 해당 캐릭터 절
- 색·서체·승인 자산: `DESIGN.md`
- 회사·채널·제공물: `docs/마케팅_정본.md`와 연결된 현재 업무 문서

원문끼리 다르거나 작업 결과가 사용한 원본과 지금 원본이 다르면 `docs/AI_운영원칙.md`의 최신 상태 확인을 따른다. 사실과 사용자의 실제 말, AI의 해석을 구분한다.

## 학생에게 쓰는 기준

- 결과와 다음 행동을 먼저 쓴다. 짧은 문장과 초급 어휘를 쓰되 고등학생의 사고 수준을 낮추지 않는다.
- 불리한 조건·미확인·실패 상태를 숨기거나 없는 사실·수치·성과를 만들지 않는다.
- 다른 학생과 비교하거나 마감·희소성·불안으로 몰아붙이지 않는다. 비교가 필요하면 학생 자신의 이전 기록과 비교한다.
- 사람이 하는 일은 사람을 주어로 쓴다. 기능 목록처럼 시스템을 가리키는 자리까지 억지로 의인화하지 않는다.
- 오류·빈 상태는 상황과 다음 행동이 첫 독해에 보여야 한다. 실제 재시도 통로가 없는데 진행 중이라고 쓰지 않는다.
- 몽골어 번역이 필요한 결과는 한국어 확정과 번역·원어민 검수를 구분한다.

## 캐릭터

- 현재 선택지는 **몽글·까몽·마린 세 캐릭터**다. 셋은 독립된 존재이며 말의 방향과 성격이 다르다. 특정 학생이나 현재 결과에 선택 근거가 없으면 몽글을 자동 기본값으로 정하지 않는다.
- 셋 다 학생을 향해 응원하고 소통한다. `무언의 선생님`은 TTS와 낱말 소리가 없다는 뜻이며, 학생에게 말하지 않는다는 뜻이 아니다. 말은 말풍선으로 한다.
- 실제 문구는 `docs/캐릭터/가이드_정본.md`의 최신 성격·문장 지문·학생을 향한 말 절에서 가져온다. 옛 단일 마스코트 규칙이나 과거 이름 보류 상태를 되살리지 않는다.
- 캐릭터의 색·몸·재질을 글 장식 규칙으로 확대하지 않는다. 시각 자산은 `DESIGN.md`와 승인 원본을 따른다.

## 접점에 맞춘다

- SNS: 장면과 실제 제공 가치를 먼저 보여 준다. 질문·댓글 요청은 내용에 필요할 때만 쓴다.
- 앱 UI·알림: 이미 온 학생에게 다시 설득하지 않는다. 상태와 다음 행동을 짧게 알린다.
- 숙제·퀴즈: 초급 학생이 혼자 시작할 수 있게 전체 목적, 재료 연결, 제출 방법을 보인다.
- DM·상담: 모르는 조건은 추정하지 말고 확인이 필요한 담당 원문이나 사람에게 넘긴다.

## 검수

1. 현재 회사·채널·캐릭터 원문을 실제로 읽었는가.
2. 첫 독해에 상황·가치·다음 행동이 보이는가.
3. 쉬운 한국어가 유아어·내용 없는 감탄·초등 소품으로 변하지 않았는가.
4. 학생을 평가·비교·재촉하거나 성과를 보장하지 않는가.
5. 캐릭터 화법이 몽글·까몽·마린 중 누구인지 문장만으로도 구분되는가.
6. 제작·번역·게시·성과 확인을 각각 실제 확인한 범위대로 구분했는가.
