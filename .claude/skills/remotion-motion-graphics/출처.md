## 왜 이걸 들였나 — 공식 스킬과 자리가 다르다

공식 5종(`remotion-markup` 등)은 **「Remotion API 를 맞게 쓰는 법」**을 가르친다.
이것은 그 자리에 **「보기 좋게 만드는 판단」**을 채운다:

- 장면 리듬 — HOOK → CONTEXT → BODY → PAYOFF → CTA
- 스태거·스프링 안무, 컬러그레이드, 필름 그레인, Ken Burns
- 「렌더 → 프레임 뽑아 → 눈으로 보고 → 고친다」 강제 루프
  (이 저장소가 `영상/프레임뽑기.js` 로 실물화한 바로 그 규율이다)

유료 의존성이 0이고 효과음마저 node 내장 모듈로 합성한다 — 돈 드는 자리가 없다.

반입하면서 **같은 커밋에서** 셋을 갈아끼웠다. 남겨두면 반드시 다시 참조된다
(마스코트 실물 08-19: 유호님 확정판 6회 대 옛판 20회).

| 자리 | 원본에 있던 것 | 처분 |
|---|---|---|

| `assets/theme.ts` | `fonts` 3개 (Clash Display · Inter · JetBrains Mono) | 블록째 삭제 → `영상/src/킷/폰트.ts` 로 안내 |

**가장 위험했던 것**: 원본이 권하던 「Warm editorial hero `#D97757`」은 SYNK 코랄 `#F96859` 과
**눈으로 구분이 안 된다.** 킷 밖 색인데 비슷해서 더 위험하다 — 섞여 들어와도 아무도 못 알아챈다.

남긴 것: `theme.ts` 의 `ease`·`spring`. 이건 **영상 연출값**이라 킷 `감각.가안`(UI 모션: 눌림·시트·툴팁)과
축이 다르고, 그 블록은 아직 「가안」이라 DESIGN.md §8 이 새 산출물의 인용을 막아 두었다.

### 기계로 확인하는 법

```bash
grep -rn "Clash Display\|JetBrains Mono\|#7C3AED\|#D97757\|#0A0A0F\|#22D3EE"   .claude/skills/remotion-motion-graphics/ --include="*.ts"
```
**0건이어야 한다.** `--include="*.ts"` 가 붙은 이유가 있다 — `.md` 쪽에는 「무엇을 지웠나」를
적어 둔 «기록»이 일부러 남아 있고, 검사가 그걸 매번 잡으면 거짓양성에 무뎌져 진짜를 놓친다.
검사는 **실행되는 코드**만 본다.

## `skills-lock.json` 에는 없다 — 일부러 그렇다

그 파일은 `npx skills add` CLI 가 관리한다(공식 5종은 거기서 받아 자동 등재됐다).
이것은 tarball 에서 손으로 뽑아 **내용까지 고친** 반입본이라 CLI 규약에 넣지 않는다.
⚠ lock 의 `computedHash` 가 어떤 값의 해시인지는 **안 재봤다** — 파일 내용의 sha256 도,
줄바꿈 정규화판도 아니었다(등재된 6개 전부 안 맞았다. 손대지 않은 `last30days` 포함).
그래서 그 파일은 손으로 건드리지 않는다.

## 언제 이걸 여나
