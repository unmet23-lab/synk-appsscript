# 굽기·밤 작업 도구를 만질 때

- 굽기는 자산과 실행 환경이 준비된 작업 위치에서 진행하고 산출물을 직접 확인해 미리보기를 제공한다.
- 낮에는 `tools/밤일감.js` 장부에 적재만 한다. 실제 밤 실행은 사용자가 취침 시작을 알린 뒤 기존 `--띄우기` 통로로 시작하고, 프로세스·로그·산출물을 각각 확인한다.
- `tools/밤샘_*.js`는 현행 진입로가 아니다. 이름만 보고 보호하거나 복구하지 않으며, 수정·정리 요청이 있으면 현재 참조, 실행 중 프로세스, 산출물 복구 가능성을 먼저 확인한다.
- 오래 걸리는 굽기를 세션에 묶인 임시 프로세스로 새로 띄우지 않는다. 기존 밤일감 통로가 제공하는 분리 실행과 절대 로그 경로를 사용한다.
- 자산 경로의 정본은 `tools/lib/마스코트자산.js` 하나다. 같은 경로 값을 다른 파일에 복제하지 않는다.
- 다른 작업의 실행·미커밋 자산을 보존하고, 이미 맡은 범위는 단계별 재승인으로 멈추지 않는다.
