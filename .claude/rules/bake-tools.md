# 굽기 도구를 만질 때

- 굽기 레인은 메인에 남는다(워크트리 ✗) — 유호님이 커밋 «전»에 산출물을 여신다.
- 도는 밤은 건드리지 않는다. 오늘 밤 사슬이 승계 중인 `밤샘_*.js` 는 걷지 않는다(09-01 실사고: 「끝난 밤」으로 보고 걷은 파일을 둘이 `require` 하고 있었다 — 하네스재판정_0901 §7-2-a).
- 걷을 때 「아무도 안 부른다」의 분모는 저장소 전체다 — `git grep -- .` 로 재고, 걷은 «뒤» 한 번 더 잰다. 걷은 파일을 부르던 자리엔 「⚠삭제됨」을 단다.
- 자산 경로의 정본은 `tools/lib/마스코트자산.js` 하나 — 경로를 다른 파일에 새로 적지 않는다(옛판이 여럿이면 옛판이 더 많이 참조된다 · 08-19 실측).
- 밤샘 굽기는 세션에 매인 프로세스로 띄우지 않는다 — 떼어 띄운다(WMI `CreateFlags=520` · 세션의 Start-Process 는 못 뗀다). 고아 blender 는 램을 먹는다.
