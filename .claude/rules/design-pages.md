# 시각 산출물의 제작과 확인

- synk-design → DESIGN.md에서 용도별 현재 승인 원본을 선택한다. 색·서체 값은 디자인_토큰.json, 로고는 로고_중립색_정본_v1.md, 학생 문안은 synk-brand를 따른다.
- 사진형 로고·사업명은 승인된 완성 조합을 쓴다. 옛 시안에 박힌 로고나 임의 서체 조립을 최신 원본으로 삼지 않는다.
- 원고와 생성 결과를 구분한다. 발표물의 _src_*.html은 원고이며 tools/발표물빌드.js로 다시 굽는다. 원고·생성물의 갱신을 혼동하지 않는다.
- 실제 크기에 충분한 해상도의 파생 자산을 승인 원본에서 만든다. img·svg의 크기 규칙, 로드·디코딩 완료, 투명 가장자리·잘림·배경과 접지감을 확인한다. 원본 4K는 보존한다.
- 브랜드 서체의 실제 로드를 확인한다. 자립형 HTML은 tools/lib/브랜드폰트.js로 산출물에 심고, 웹앱은 해당 제작 환경의 로드 경로를 검증한다. 폴백으로 그럴듯하게 보이는 것은 승인 서체 반영의 증거가 아니다.
- 원본은 재사용 가능한 파일로 유지하고 외부 전달용 파생물만 해당 매체의 실제 용량·포맷에 맞춘다. 옛 뷰어 한도를 모든 제품에 고정하지 않는다.
- 완성물은 실제 렌더·미리보기로 확인한다. 브라우저·촬영 도구는 현재 제공된 통로를 쓰고, 백그라운드 탭의 재생 지연과 파일 오류를 구별한다. 자동재생 조건을 바꾼 시험을 실제 방문 조건의 성공으로 보고하지 않는다.
- 품질 판단은 명품_기준_v1.md §3·§4, 홍보는 마케팅_정본.md와 마케팅/제작_인수기준.md, 약속은 마케팅/약속과_실행.md를 적용한다. 중복 검사표를 늘리지 않는다.
- 사용 원본·실제 반영 위치·확인 결과를 기존 결과 기록에 짧게 남긴다. 게시·배포가 요청됐으면 게시된 결과까지 확인하고, 이미 맡긴 작업을 매번 재승인 요청으로 멈추지 않는다.
