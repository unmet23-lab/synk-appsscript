# 시각 파일의 기술 정보

- 발표물의 `_src_*.html`이 원고이며 `tools/발표물빌드.js`가 출력 파일을 만든다. 생성 파일만 고치면 다음 빌드에서 사라진다.
- 자립형 HTML의 폰트 삽입은 `tools/lib/브랜드폰트.js`를 사용한다. CSS에 폰트 이름만 적으면 실제 파일이 로드되지 않을 수 있다.
- 마스코트 4K 원본은 파생 이미지와 구분한다. 투명 영역·해상도와 `img`·`svg`의 표시 크기는 실제 배경에서 확인한다.
