# 공용 원장(docs/_ops)을 만질 때

- `결정.md` = 무엇을 정했나(유호님 확정만 · 근거·인용을 붙인다 · `node tools/결정.js --추가`) · `트랙.md` = 무엇이 남았나(색인 · 절 하나 ≤5KB · ✅ 서사는 안 적는다). 열린 PR 본문이 트랙.md 보다 우선한다.
- **고치는 즉시 커밋한다** — `git commit -m "..." -- docs/_ops/결정.md`. 같은 파일을 두 세션이 쓰면 경로 못박기가 못 지킨다(사고 여덟 = 워크트리_규약.md 머리). Stop 훅(turn-end-ledger)이 미커밋 공용 원장을 세션당 한 번 exit 2 로 막는다 — 그 자리에서 커밋한다.
- 트랙을 끝낸 세션이 그 커밋에서 트랙.md 의 그 줄을 지운다 — 안 지우면 다음 세션이 끝난 일을 다시 한다.
- 결정.md 성격은 둘뿐 — `안전`(영구 · 손으로만 적는다) / `확정`(기본값 · 재제안 금지가 14일 뒤 풀린다). 성격 칸을 비우면 `확정`으로 읽힌다.
- 판정 지면(`*판정*.md`·`*재판정*.md`)은 메인 레인 — 유호님이 커밋 «전»에 여신다. 표를 대체하면 새 표에 「이 표가 현행 정본」을 못 박고 옛 표는 그날의 기록으로만 읽는다.
