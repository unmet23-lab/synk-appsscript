# 공용 원장(docs/_ops)을 만질 때

- `결정.md` = 무엇을 정했나(유호님 확정만 · 근거·인용을 붙인다 · `node tools/결정.js --추가`) · `트랙.md` = 무엇이 남았나(색인 · 절 하나 ≤5KB · ✅ 서사는 안 적는다). 열린 PR 본문이 트랙.md 보다 우선한다.
- **고치는 즉시 커밋한다** — `git commit -m "..." -- docs/_ops/결정.md`. 같은 파일을 두 세션이 쓰면 경로 못박기가 못 지킨다(사고 여덟 = 워크트리_규약.md 머리). 커밋 직전에 변경 내용을 다시 확인해 남의 미커밋을 섞지 않는다.
- 트랙을 끝낸 세션이 그 커밋에서 트랙.md 의 그 줄을 지운다 — 안 지우면 다음 세션이 끝난 일을 다시 한다.
- 결정.md의 기존 기록 분류는 `안전` / `확정`이고, 빈 성격은 기존 도구가 `확정`으로 읽는다. 영구·14일 표시는 `tools/결정.js`가 해석하는 기록 값이며 이 규칙에서 바꾸지 않는다. 이를 현재 사용자 요청이나 근거 있는 재제안을 막는 별도 권한 제한으로 적용하지 않는다. 현행 판단은 공통 운영 원칙을 따르고, 이전 결정과 달라지는 이유를 함께 남긴다.
- 판정 지면(`*판정*.md`·`*재판정*.md`)은 확인 가능한 결과로 제공한다. 이미 맡긴 범위의 작업은 확인 요청으로 멈추지 않는다. 표를 대체하면 새 표에 「이 표가 현행 정본」을 못 박고 옛 표는 그날의 기록으로만 읽는다.
