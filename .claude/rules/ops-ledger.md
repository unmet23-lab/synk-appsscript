# 공용 운영 기록을 만질 때

- `결정.md`는 사용자가 실제로 확정한 결정과 근거를, `트랙.md`는 현재 목표와 남은 일만 담는다. 과거 서사나 자동 생성 장부를 새 중앙 체계로 늘리지 않는다.
- 수정 전후의 실제 diff를 확인하고 이번 작업이 소유한 조각만 갱신한다. 다른 작업의 미커밋·스테이징을 파일 전체 stage로 섞지 않는다.
- 끝낸 트랙은 그 일을 끝낸 작업에서 정리하고, 미완료면 현재 원문·작업 사본·검증·다음 행동을 짧게 연결한다. 문서 크기 자체를 완료 조건이나 강제 게이트로 삼지 않는다.
- 기존 기록의 `안전`·`확정`·기간 표시는 당시 도구의 값이다. 최신 사용자 요청과 현재 증거를 우선하고, 이전 결정과 달라졌다면 이유를 남긴다.
- 개인 기억은 사용자의 명시 요청이 있을 때만 해당 환경의 공식 절차로 갱신한다. `MEMORY.md`를 직접 편집하지 않는다.
- 판정 문서는 확인 가능한 결과로 제공한다. 이미 맡은 범위는 불필요한 재승인으로 멈추지 않으며 [공통 운영 원칙](../../docs/AI_운영원칙.md)을 따른다.
