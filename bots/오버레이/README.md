# 라디오24 오버레이 — 마스코트 상주 층 · P3 전광판 층

> **유호 확정 2026-08-14 「라디오 화면에 마스코트를 세워서 자동으로 움직이고 반응하게」** (Claude FM 오마주).
> 모션 명세 = `tools/마스코트모션.py`(앱 구현 방식과 동형 — 스프라이트 교체 + 트랜스폼, **색 연산 0**) ·
> 그림 정본 = `docs/캐릭터/펠트코랄_0815/`(유호 확정 13컷 · 상대 경로 참조라 **사본 0**).
> 송출과 무관하게 서 있는 «부품»이다 — 채널 게이트(⏳유호)는 이 폴더가 안 건드린다.

## 파일

| 파일 | 역할 |
|---|---|
| `마스코트.html` | OBS 브라우저 소스용 투명 오버레이. 대기(부유·숨·깜빡임)·반응 5종·밤 모드·데모 모드 |
| `전광판.html` | 같은 규격의 두 번째 소스. **기본 화면 = 학원 합산 전광판**(설계 §8) + 퀴즈 라운드 카드 + 명령 피드백 토스트 |
| `전광판판정.js` | 전광판이 **무엇을 싣고 뺄지** 정하는 순수 판정층. 브라우저와 Node 회귀가 같은 파일을 쓴다 |

두 html 은 서로를 모른다 — 봇이 사건을 한 번 보내면 마스코트는 모션을, 전광판은 문안을 각자 집는다.
OBS 에는 **브라우저 소스 두 개**로 얹는다(겹쳐도 서로 안 가린다: 마스코트=우하단, 전광판=상단·좌하단).

## 보는 법 (지금 · 방송 없이)

저장소 루트에서 정적 서버를 열고 브라우저로 연다(`전광판.html` 은 스크립트를 하나 더 읽어서
`file://` 직접 열기로는 판정층이 안 붙는다 — 반드시 서버로 연다):

```bash
npx serve .
```

- 마스코트 데모: `bots/오버레이/마스코트.html?무대=1&demo=1`
- 전광판 데모: `bots/오버레이/전광판.html?무대=1&demo=1`
- 파라미터(공통): `무대=1`(Navy 2 무대 — 방송 합성 대신 눈으로 검수) · `demo=1`(자동 시나리오+계기판)
- 마스코트 전용: `크기=0.22` · `자리=우하|좌하|우상|좌상` · `밤=1|0`
- 전광판 수동 시험(콘솔): `전광판사건({종류:'정답', 정답:'B', 분포:{A:3,B:9}, 응답수:12})`

## 사건 계약 — 들어오는 문 (봇·P3·데모가 같은 문)

`BroadcastChannel('라디오오버레이')` 또는 `postMessage({채널:'라디오오버레이', 종류:'…'})`.

| 종류 | 실리는 것 | 마스코트 | 전광판 |
|---|---|---|---|
| `인사` | — | 탭 스프링 300ms | 「SYNK 라디오」 토스트 |
| `합산` | `맞힌문제`·`진화레벨합`·`체크인주간` | (모름 — 무시) | 기본 화면 3지표 갱신 |
| `라운드` | `round_id`·`지시문`·`보기들[{option_id,label}]`·`마감초` | 놀람(은은)+소홉 | 라운드 카드 + 카운트다운 |
| `마감` | `round_id` | (모름 — 무시) | 카운트다운 0 · 「응답 마감」 |
| `정답` | `round_id`·`정답`·`분포{option_id:n}`·`응답수` | 기쁨+통통 튐→눈웃음 | 정답 1점 강조 + 집단 분포 |
| `체크인` | `닉네임` | 눈웃음 눈인사 | 「자습 체크인 — 닉네임」 |
| `연동` | `닉네임` | 인사 | 「연동 완료 — 닉네임」 |
| `투표` | `선택`·`합계` | 몸 살랑 | 「신청 반영 — 선택」 |

- 마스코트는 자기 허용목록(`인사·라운드·정답·체크인·투표`) 밖이면 조용히 무시한다 — `합산`·`마감` 이 그 자리다.
- 두 파일의 어휘가 갈리면 조용히 안 반응한다 → `tests/오버레이전광판.test.js` 가 **두 파일을 대조**한다.

## 사건 계약 — 나가는 문 (전광판 → 봇)

`BroadcastChannel('라디오전광판')` · 부모 창이 있으면 `postMessage` 도 함께.

| 종류 | 실리는 것 | 언제 |
|---|---|---|
| `노출` | `round_id`·`at`(ISO) | 라운드 카드를 **실제로 그린** 시각 |
| `마감확인` | `round_id`·`at` | 보낸 쪽이 확정한 마감을 그린 시각 |

🔑 **이게 규격의 급소다.** `radio.quiz_round.shown_at` 은 「화면에 나간 시각」이고 `not null` 이라,
라운드를 **만든** 쪽이 그 값을 지어내면 «안 보여준 것을 보여줬다고 적는 행»이 된다(설계 §4-1 · 08-13 판정).
화면만이 「그렸다」를 안다 — 그래서 원장에 적는 쪽은 이 확인을 받고 적는다.
(시간 만료로 스스로 카운트다운이 0 이 된 것은 화면의 «추정»이라 `마감확인` 을 안 보낸다.)

## 안 하는 것 (넓히기 전에 원문을 연다)

- **별눈 컷 금지**(마스코트) — 발동 닫힌 목록(`펠트코랄_0815/README.md`)에 라디오 사건이 없다.
- **슬픔 계열 금지** — 슬럼프 신고는 공개 화면에 되쏘지 않는다(`라디오24_설계.md` §2 I-2).
  전광판도 같다: `슬럼프` 는 허용 목록에 **없다**(회귀가 문다).
- **학생코드·실명·급수 금지**(§3 철칙) · **개인 순위·성적·정답률 금지**(§8) — 판정층 `금지칸` 이
  걸리면 **사건 전체를 버린다**. 그 칸만 지우고 그리면 보낸 쪽의 결함이 화면에선 정상으로 보인다.
- **라운드 열림에 정답 금지** — 실려 오면 떼고 **경고를 띄운다**(침묵 금지).
- **`innerHTML` 금지** — 채팅 원문(`command_arg`)이 그대로 오는 자리라 `textContent` 만 쓴다.
- **몽골어 지어내기 금지** — 문안 14칸 전부 검수 대기라 지금은 **한국어만** 그린다(자막카드 팩과 같은 규칙).
- **마스코트 이미지에 색 연산 0** — CSS filter·blend 금지(무손상 규격 승계).

## OBS 등록 (송출 트랙이 열릴 때 — 지금 실행하지 않는다)

1. OBS → 소스 「+」 → **브라우저** → 새로 만들기.
2. 전광판은 **로컬 파일이 아니라 URL** 로 넣는다(`http://localhost:<포트>/bots/오버레이/전광판.html`) —
   `file://` 로 열면 판정층 스크립트가 안 붙어 화면이 빈 채로 나간다.
   마스코트는 「로컬 파일」로 넣어도 된다(외부 스크립트가 없다).
3. 폭 1280 · 높이 720(방송 규격 720p와 동일) → 확인. 배경이 투명이라 방송 화면 위에 그대로 얹힌다.
4. 반응·문안 배선은 후속(원장 폴링 → BroadcastChannel 브리지 — 봇 트랙 몫).

## 틀릴 때의 모습 · 대가 (새 장치 조항)

- **틀릴 때**: 컷 경로가 깨지면 방송에 마스코트가 조용히 «없음»으로 나간다 → 로드 실패는 콘솔 에러 +
  무대/데모 모드 화면 경고로 드러낸다(침묵 실패 금지). 전광판은 판정층 파일을 못 읽으면 **아무것도 안 그린다**
  (판정 없이 그리는 것보다 빈 화면이 낫다). 반응 이벤트가 영영 안 오면 «대기 모션만 도는 화면»인데,
  그건 이 층이 아니라 배선(봇 브리지) 부재다 — 배선 트랙이 닫는다.
- **닫는 것**: 없음 — 신설 층이고 대체하는 기존 장치가 없다(오버레이 코드 0벌이던 자리 · P3의 선행 실물).
- **브랜드 렌더 린트 미등록**(실측 2026-08-15): `node tools/브랜드렌더린트.js bots/오버레이/전광판.html` 은
  대비 위반 3건을 내지만 그 바닥 `#3A4155` 는 **어디에도 없는 색**이다 — 카드 바닥 `rgba(15,23,48,.82)` 를
  린트의 **흰 페이지** 위에 합성한 값이다. 방송 바닥(Navy 2 `#0F1730`)에서 같은 글자는 **5.71** 로 기준(4.5)을
  넘는다. 그래서 등록층에 안 넣었다(마스코트와 같은 사유). 잰 3건은 전부 합산 카드의 「—」 자리이고,
  실문안·라운드 카드는 로드 시점에 비어 있어 린트가 **애초에 못 잰다** — 이 파일의 초록은 「안전하다」가
  아니라 「못 쟀다」다. 판정을 대신 지는 것 = `tests/오버레이전광판.test.js`(회귀 20 · 변이 8/8 물림).
  ⚠ `tools/브랜드렌더린트.js` 의 제외 목록에는 **아직 못 적었다** — 그 파일을 다른 세션 둘이 잡고 있다(F073).
  푸는 조건은 「투명 오버레이를 합성 바닥과 함께 재는 통로」이고, 서면 마스코트·전광판을 함께 등재한다.
