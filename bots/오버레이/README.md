# 라디오24 오버레이 — 마스코트 상주 층

> **유호 확정 2026-08-14 「라디오 화면에 마스코트를 세워서 자동으로 움직이고 반응하게」** (Claude FM 오마주).
> 모션 명세 = `tools/마스코트모션.py`(앱 구현 방식과 동형 — 스프라이트 교체 + 트랜스폼, **색 연산 0**) ·
> 그림 정본 = `docs/캐릭터/마스코트_렌더/`(유호 확정 13컷 · 상대 경로 참조라 **사본 0**).
> 송출과 무관하게 서 있는 «부품»이다 — 채널 게이트(⏳유호)는 이 폴더가 안 건드린다.

## 파일

| 파일 | 역할 |
|---|---|
| `마스코트.html` | OBS 브라우저 소스용 투명 오버레이. 대기(부유·숨·깜빡임)·반응 5종·밤 모드·데모 모드 |

## 보는 법 (지금 · 방송 없이)

저장소 루트에서 정적 서버를 열고 브라우저로 연다:

```bash
npx serve .
```

- 데모(무대+자동 시나리오): `bots/오버레이/마스코트.html?무대=1&demo=1`
- 방송 합성 상태 그대로(투명): `bots/오버레이/마스코트.html`
- 파라미터: `크기=0.22`(화면 폭 대비) · `자리=우하|좌하|우상|좌상` · `밤=1|0`(강제) · `무대=1`(Navy2 무대)

## 이벤트 계약 (봇·P3 전광판·데모가 같은 문)

`BroadcastChannel('라디오오버레이')` 또는 `postMessage({채널:'라디오오버레이', 종류:'…'})` 또는 콘솔 `마스코트반응('…')`.

| 종류 | 컷·모션 | 발원(후일 배선) |
|---|---|---|
| `인사` | 탭 스프링 300ms | 시작·수동 |
| `라운드` | 놀람(은은)+소홉 | 퀴즈 라운드 열림 |
| `정답` | 기쁨+통통 튐(감쇠)→눈웃음 | 정답 공개(정답자 있음) |
| `체크인` | 눈웃음 눈인사+소홉 | `!출석` 접수 |
| `투표` | 몸 살랑(표정 기본) | `!빗소리`·`!asmr` 반영 |

- 반응 중 수신분은 대기열 3까지, 초과는 버리고 콘솔에 남긴다(방송이 밀리는 것보다 반응을 버리는 쪽).
- **밤 모드**(03~06시 로컬): 잔잔 감음으로 잠 — 이벤트가 오면 깨서 반응한다(24시간 «살아있는 존재» 연출).

## 안 하는 것 (넓히기 전에 원문을 연다)

- **별눈 컷 금지** — 발동 닫힌 목록(`마스코트_렌더/README.md`)에 라디오 사건이 없다. 컷을 로드조차 안 한다.
- **슬픔 계열 금지** — 슬럼프 신고는 공개 화면에 되쏘지 않는다(`라디오24_설계.md` §2 I-2). 허용 목록 밖 이벤트는 코드가 무시한다.
- **텍스트·닉네임·숫자 표시 없음** — 명령 피드백·전광판 문안은 P3 몫. 이 층은 마스코트만. (닉네임 원칙·㉢비교 금지는 P3 렌더러가 진다.)
- **마스코트 이미지에 색 연산 0** — CSS filter·blend 금지(무손상 규격 승계).

## OBS 등록 (송출 트랙이 열릴 때 — 지금 실행하지 않는다)

1. OBS → 소스 「+」 → **브라우저** → 새로 만들기.
2. 「로컬 파일」 체크 → `bots/오버레이/마스코트.html` 선택(저장소를 그 기계에 클론해 두면 컷 상대 경로가 그대로 산다).
3. 폭 1280 · 높이 720(방송 규격 720p와 동일) → 확인. 배경이 투명이라 방송 화면 위에 그대로 얹힌다.
4. 반응 배선은 후속(원장 폴링 → BroadcastChannel 브리지 — 봇 트랙 몫).

## 틀릴 때의 모습 · 대가 (새 장치 조항)

- **틀릴 때**: 컷 경로가 깨지면 방송에 마스코트가 조용히 «없음»으로 나간다 → 로드 실패는 콘솔 에러 + 무대/데모 모드 화면 경고로 드러낸다(침묵 실패 금지). 반응 이벤트가 영영 안 오면 «대기 모션만 도는 화면»인데, 그건 이 층이 아니라 배선(봇 브리지) 부재다 — 배선 트랙이 닫는다.
- **닫는 것**: 없음 — 신설 층이고 대체하는 기존 장치가 없다(오버레이 코드 0벌이던 자리 · P3의 선행 실물).
